# Published supplement subset

This repository folder contains the complete [revision-two evidence and repair packet](update_20260923/README.md). The complete historical datasets, original source files, and historical reproduction controls are included in `source.zip` in the Math Brain publication folder at `papers/pseudo-cognitive-dynamics-2026-09-23/revision-2/`.

Extract the source archive to reproduce the full paper. Its supplement README defines all 45 earlier contrast rows, the 1,391-record catalogue, usage-ledger boundaries, and previous controls. The new packet preserves those historical definitions and does not add model trials from software fixtures.
