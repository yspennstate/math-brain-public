## Read and build

The delivered PDF is the formatted paper. `main.tex` is the Overleaf entry point. Upload this source package, select `main.tex`, and compile with pdfLaTeX. All required source sections, bibliography records, and the numeric bibliography style are included.

Locally, with TeX Live and latexmk installed:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

`pcd_numeric.bst` is a numeric, URL-preserving adaptation of `unsrtnat.bst`; its original LaTeX Project Public License notice is retained. It removes unnecessary author-year suffix generation for the large set of same-year archive citations.
