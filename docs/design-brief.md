# Design brief

Build a mathematical version of the existing research-memory methodology,
focused exclusively on mathematics. It must contain no trading project data,
financial or options theory, company intellectual property, unrelated project
material, or other private computer data. Those sources are out of scope and
must never leak into this repository.

The system should preserve the useful research methodology: a robust typed
graph, mistake detection, verification layers, numerical replication, proof
checking, retrieval triggers, and consolidation. Extend it for mathematics with
Lean integration, mathematical dreaming and replay, citation checking, and
source-level verification that authors actually support the claims attributed
to them.

Use the system locally to audit explicitly approved mathematical work without
committing source material or derived private content. Build a large benchmark
of genuine problems and solutions paired with subtly faulty solutions, ranging
from elementary exercises through undergraduate and qualifying-exam material to
research-style and conjecture-awareness tasks. Faults should include both small
typographical changes with mathematical consequences and fundamental errors.

Evaluate the system causally: independent solvers should attempt the same hidden
items under matched conditions, once with the research brain and once without
it. Repeat across multiple agents and problem strata, record failures as well as
successes, and keep improving the system based on measured error detection rather
than intuition alone.

The repository is private during development and is intended for eventual public
release after privacy, provenance, licensing, and reproducibility gates pass.
