[card] The Bessel Scale Function, and Recurrence Versus Transience by Dimension  (id: claim_28ae49b4849a217435a2f33e1bff7911ba62b44c71425000ee08e45fdab6ac40; claim)
    Let X be a Bessel process of dimension delta > 0 started at x > 0, solving dX_t = dW_t + ((delta - 1)/(2 X_t)) dt on (0, infinity). Its SCALE FUNCTION is s(x) = x^{2 - delta}/(2 - delta) for delta != 2 and s(x) = log x for delta = 2. Consequently: for delta > 2 the process is TRANSIENT, never hits 0 from x > 0, and X_t -> infinity almost surely; for delta = 2 it never hits 0 and is NEIGHBOURHOOD RECURRENT, visiting every interval (a,b) with 0 < a < b at arbitrarily large times almost surely, while X_t -> infinity fails and liminf X_t = 0 with limsup X_t = infinity; for 0 < delta < 2 the process reaches 0 almost surely in finite time. Specialising to integer delta = d and using that |B| is BES^d recovers the classical dichotomy for Brownian motion in R^d: recurrent for d = 1 (point recurrent) and d = 2 (neighbourhood recurrent, never hitting a fixed point), transient for d >= 3. The critical dimension is exactly 2 and the transition is driven by whether the integral of s' diverges at 0 and at infinity. [standard; e.g. Revuz and Yor, Continuous Martingales and Brownian Motion, 3rd ed., Chapter XI, Proposition 1.5] delta > 0, started at x > 0 the diffusion is considered on (0, infinity) up to the hitting time of 0 the integer case delta = d transfers to Brownian motion in R^d through the radial part
