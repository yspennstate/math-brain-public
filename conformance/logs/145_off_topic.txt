T is symmetric (Hermitian) if it is densely defined and ⟨Tx, y⟩ = ⟨x, Ty⟩ for all x, y ∈ D(T), i.e. T ⊂ T*. T is self-adjoint if T = T*, which includes the equality of domains D(T) = D(T*).     Load-bearing hypothesis: 'the operator −Δ' or 'the Schrodinger operator H = −Δ + V' is not defined by its formula; the domain is part of the data, and essential self-adjointness on a chosen core is a theorem, not a convention. What fails without it: two different self-adjoint operators can agree on a common dense domain, with different spectra, different semigroups and different dynamics; semiboundedness does not select a unique extension either. Counterexamples. (1) −d²/dx² on C_c^∞(ℝ) is essentially self-adjoint with closure the operator on H²(ℝ); but −d²/dx² on C_c^∞(0, ∞) in L²(0, ∞) has deficiency indices (1, 1), and its self-adjoint extensions are the Dirichlet realization {f ∈ H²(0,∞) : f(0) = 0} and the Robin family {f ∈ H²(0,∞) : f'(0) = α f(0)}, α ∈ ℝ. All extend a nonnegative symmetric operator, yet for α < 0 the Robin extension has the eigenvalue −α² with eigenfunction e^{αx}: the lower bound 0 valid on C_c^∞(0,∞) is not inherited by every self-adjoint extension. The Friedrichs extension (here the Dirichlet realization) is the one that always inherits the lower bound; the Robin extensions with α ≥ 0 happen to stay nonnegative as well, so the lower bound alone singles out nothing. (2) −d²/dx² on C_c^∞(0, 1) has deficiency indices (2, 2); the Dirichlet, Neumann and periodic realizations are distinct self-adjoint extensions with eigenvalues {(kπ)² : k ≥ 1}, {(kπ)² : k ≥ 0} and {(2πk)² : k ∈ ℤ} respectively. (3) −Δ on C_c^∞(ℝⁿ ∖ {0}) is essentially self-adjoint if and only if n ≥ 4; for n ≤ 3 removing a single point changes the operator, and the extensions in n = 3 are the point-interaction ('delta potential') Hamiltonians.
