# Round 236

Round 236 splits exact-level same-sphere congestion into tangential run
alternatives.

For a fixed level \(u\), a tangential run is a maximal interval of the path
that stays inside the exact sphere \(S_u(x)\) and has positive length.  Let
\(T_x^u(\gamma)\) be the longest such run length and \(R_x^u(\gamma)\) the
number of such runs.

If \(H_x(\gamma;\{u\})>K\), then for every \(L\ge1\) either
\[
  T_x^u(\gamma)>L
\]
or
\[
  R_x^u(\gamma)>\lfloor K/L\rfloor .
\]
Thus the exact-level same-sphere congestion profile is bounded by a long-run
profile plus a many-run profile.

The tangentially localized ladder replaces the exact-level same-sphere
congestion family in Round 235 by two sharper targets: long tangential runs
inside one sphere, and many tangential runs at one exact level.
