# Round 393

Round 393 splits the fifteenth confined bridge profiles from Round 392 into
inward-free bridge profiles plus a new bridge-return spread family.

Round 392 left
\[
  P^{\rm pre,br,recbr,\ldots,recbr,ch}_{i,j,h}
\]
with confined bridge scale
\[
  K_i^{\rm gap,br,recbr,\ldots,recbr,ch}
\]
and finite height range
\[
  1\le h\le
  B_i^{\rm br,recbr,\ldots,recbr,ch}.
\]
Applying the confined-bridge dichotomy gives, for each \(i,j,h\),
\[
  P^{\rm pre,br,recbr,\ldots,recbr,ch}_{i,j,h}
  \le
  P^{\rm pre,br,free,recbr,\ldots,recbr,ch}_{i,j,h}
  +
  R^{\rm spr,br,recbr,\ldots,recbr,ch}_{i,j,h}.
\]
The new inward-free and bridge-return profiles use the doubled threshold
\[
  2K_i^{\rm gap,br,recbr,\ldots,recbr,ch},
\]
so their profile superscripts carry fifteen \({\rm recbr}\) markers while the
inherited gap scale carries fourteen.

Substitution into the Round 392 finite ladder replaces the confined bridge
sum under the unchanged coefficient
\[
  D_i^{\rm rec,br,recbr,\ldots,recbr,ch}
\]
by two finite sums over the same height range: the fifteenth inward-free
bridge profiles and the fifteenth bridge-return spread profiles.  The adjacent
fifteenth return-spread family, fourteenth bridge-return spread family,
adjacent fourteenth return-spread family, thirteenth retained spread families,
older retained return-spread and bridge-return families, long-run profiles,
enlarged spread-return profiles, and exact-level return profiles are retained.

The radial-tail and subdivision criteria now use the fifteenth inward-free
bridge and fifteenth bridge-return profile hypotheses.  The next internal move
is to absorb the inward-free bridge profiles into a prefix-record family while
retaining the new bridge-return spread family, paralleling the previous
inward-free bridge absorption.

No external literature refresh was performed in this round; the targeted
post-Round 382 source check remains the latest external status recorded by
this project.
