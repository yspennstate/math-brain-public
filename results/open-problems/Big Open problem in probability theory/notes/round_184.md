# Round 184

Round 184 formalizes the optimized support-profile gate escape.

Round 183 proved that the capped branch is impossible whenever
\[
  \delta(\theta,U,\omega)
  =
  2-6\theta-15\theta\alpha_\omega-6U\alpha_\omega>0,
  \qquad
  \alpha_\omega=\log_\Delta\omega.
\]
Letting \(\theta\downarrow0\), this condition becomes
\[
  2-6U\alpha_\omega>0,
\]
or
\[
  U<\frac{1}{3\alpha_\omega}.
\]

The manuscript now records the optimized support-profile version explicitly:
if \(\alpha_\omega>0\), then for every
\[
  0<U<\frac{1}{3\alpha_\omega}
\]
the expanded gate-annulus obstruction can be forced to satisfy
\[
  2^j>U\log_\Delta\bar\chi_p.
\]
If \(\alpha_\omega=0\), the same conclusion holds for every finite \(U>0\).

This has the same optimized range as the Schur-calibrated argument from
Rounds 178--179, but the proof now runs through the finite gate set \(A\), the
support set \(Y\), and the annular square-profile size bound.  It is therefore
a genuine two-replica/support-volume explanation of the current barrier.
