# Round 241

Round 241 absorbs the crossing-generated exterior-return profiles into the
ordinary repeated-return profiles.

The return-only ladder from Round 240 contains ordinary return profiles
\[
  B_{i,j}^{\times}
  =
  \mathfrak X_{Q,\lambda_i,\sigma_i,\beta_i,j,K_i^\times}^{G\to H,
    {\rm rad,ret}},
  \qquad
  K_i^\times=\left\lfloor\frac{\lfloor M_i/L_i\rfloor-2}{4}\right\rfloor-1.
\]
If the parameters are chosen so that
\[
  K_i^\times\ge K_i,
\]
then monotonicity of the event \(\mathcal X_{u,K}\) in \(K\) gives
\[
  B_{i,j}^{\times}
  \le
  \mathfrak X_{Q,\lambda_i,\sigma_i,\beta_i,j,K_i}^{G\to H,{\rm rad,ret}}.
\]
Thus the crossing-generated return family requires no separate estimate.

The threshold-dominated ladder now depends only on:
finite-defect bins, near-tail bins, a terminal far tail, same-sphere spread,
long tangential runs, spread exterior returns, and ordinary exact-level
exterior returns, with one extra finite boundary slab in the final return
family.
