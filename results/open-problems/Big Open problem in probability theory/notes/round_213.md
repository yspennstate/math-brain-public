# Round 213

Round 213 sharpens the bipartite inward-tail target.

The previous bipartite route inherited the generic radial split and therefore
asked for the inward tail above
\[
  b>K_{\rho,p}/4.
\]
But in a bipartite graph there are no same-sphere steps, so \(h=0\) and
\[
  k=2b.
\]
The exact long-excess condition \(k>K_{\rho,p}\) is therefore
\[
  b>K_{\rho,p}/2.
\]

The new profile is
\[
  \mathfrak L_{q,\rho}^{\rm in,saw}(s,p)
  =
  \sup_n\sum_{b>K_{\rho,p}/2}q^{2b}
  \mathfrak M_{n,b,0}^{\rm rad,saw,sph}.
\]
If this has the Round 203 exponent margin, together with the finite-excess
hypothesis, then the bipartite criterion closes.

The subdivision criterion now points to this sharper exact bipartite inward
tail.
