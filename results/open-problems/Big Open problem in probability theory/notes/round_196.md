# Round 196

Round 196 packages the exact-sphere average from Round 195 into an intrinsic
spherical-average two-point profile.

Define
\[
  \bar\tau_p^{\rm sph}(n)
  =
  \sup_{x:\ S_n(x)\ne\varnothing}
  \frac{1}{|S_n(x)|}\sum_{a\in S_n(x)}\tau_p(x,a),
  \qquad
  S_n(x)=\{a:d(x,a)=n\}.
\]
with the value \(0\) if no such sphere exists.
Then the residual branch can be stated without naming the root selected by the
obstruction: if the finite-set obstruction survives and the
super-half-log alternative fails, then for some
\[
  n\in I_{j,p}^{\rm gate}\cap\mathbb N
\]
one has
\[
  \bar\tau_p^{\rm sph}(n)
  \ge
  D_{\epsilon,\eta,J,\lambda,C_{\rm vol},\omega}
  L^{-3\eta}
  \bar\chi_p^{-2\lambda\alpha_\omega-2\theta-5\theta\alpha_\omega}.
\]

Thus the current localized residual target is a profile bound: exclude
super-half-log expanded gate-annulus data and prove that the spherical-average
profile stays below this polynomial threshold on the corresponding
near-half-log window.
