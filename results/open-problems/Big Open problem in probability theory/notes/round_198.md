# Round 198

Round 198 converts the dyadic-free profile threshold from Round 197 into a
logarithmic exponent condition.

For the remote window
\[
  (B-\theta)L<n\le
  \left(\frac{1}{\alpha_\omega}+2\lambda+\theta\right)L,
  \qquad
  L=\log_\Delta\bar\chi_p,
\]
define
\[
  \Phi_p(B,\lambda,\theta)
  =
  \sup \bar\tau_p^{\rm sph}(n)
\]
over integers \(n\) in that window, with empty supremum equal to \(0\).  Put
\[
  A_{\lambda,\theta}
  =
  2\lambda\alpha_\omega+2\theta+5\theta\alpha_\omega.
\]
If the super-half-log expanded gate data are excluded and
\[
  \limsup_{p\uparrow p_c}
  \frac{\log_\Delta \Phi_p(B,\lambda,\theta)}
       {\log_\Delta\bar\chi_p}
  <
  -A_{\lambda,\theta},
\]
then the polylogarithmic and constant losses in the obstruction threshold are
absorbed near criticality, so the dyadic-free spherical-profile criterion
applies.
