# Round 179

Round 179 optimizes the Schur-calibrated escape range from Round 178.

Write
\[
  \alpha_\omega=\log_\Delta\omega .
\]
The Round 176 exponent is
\[
  \beta(\theta,U,\omega)
  =
  2-4\theta-8\theta\alpha_\omega
  -3U\alpha_\omega-\frac32\theta\alpha_\omega .
\]
For fixed \(U\), choosing \(\theta>0\) very small makes
\[
  \beta(\theta,U,\omega)>1
\]
exactly when \(3U\alpha_\omega<1\).  Therefore, in the volume-sensitive
counterexample branch, the expanded gate-annulus obstruction can be forced to
have
\[
  2^j>U\log_\Delta\bar\chi_p
\]
for every
\[
  U<\frac{1}{3\alpha_\omega}
\]
when \(\alpha_\omega>0\).  If \(\alpha_\omega=0\), the same conclusion holds
for every finite \(U>0\).

This is a genuine scale-amplification statement for the mass-bearing expanded
gate-annulus data.  It does not solve the problem, because the scale may still
stop near the optimized barrier \(1/(3\alpha_\omega)\), but it gives the sharp
range where the capped-operator branch is ruled out by Schur alone.
