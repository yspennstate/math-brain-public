# Round 197

Round 197 audits the near-half-log profile criteria and restores the lower
scale inherited from the volume-sensitive weighted separated fan:
\[
  2^j>B\log_\Delta\bar\chi_p.
\]
This matters for the exact-sphere and pointwise formulations.  Without this
lower cutoff, a widened gate interval could contain bounded radii, where any
upper bound tending to zero is impossible because geodesic connections give
fixed positive lower bounds.

The corrected profile window is
\[
  B L<2^j\le
  \left(\frac{1}{2\alpha_\omega}+\lambda\right)L,
  \qquad
  L=\log_\Delta\bar\chi_p.
\]
Since \(r_p\le\theta L\), every obstructing exact radius satisfies
\[
  (B-\theta)L<n\le
  \left(\frac{1}{\alpha_\omega}+2\lambda+\theta\right)L.
\]
The new dyadic-free spherical-profile criterion therefore asks only for
\(\bar\tau_p^{\rm sph}(n)\) to stay below the Round 196 threshold on this one
remote linear window, plus exclusion of the super-half-log expanded gate data.
