# Round 258

Round 258 splits the two-level outward staircase residual into locally short
staircases and the already present long-run family.

For a staircase with total cutoff \(2L+1\), if either component run has length
larger than \(L\), then a long tangential run occurs at level \(u\) or
\(u+1\).  Both of these levels lie in \(A_{j,p}\), so
\[
  P^{\rm pre,stair,sh}_{j,K,2L+1}
  \le
  W_{\beta,p}T^{\rm long}_{j,L}
  +
  P^{\rm pre,stair,loc,sh}_{j,K,L}.
\]

The finite ladder now uses locally short two-level staircase profiles
\[
  P^{\rm pre,stair,loc,sh}_{i,j}
  =
  \mathfrak P_{Q,\lambda_i,\sigma_i,\beta_i,j,256M_iB_i,L_i}^{
    G\to H,{\rm rad,tan,pre,out,per,stair,loc,short}},
\]
together with confined fixed-gap bridge profiles for \(2\le h\le B_i\).  The
long-run coefficient increases from \(2\) to \(3\), which does not affect the
exponent criterion.
