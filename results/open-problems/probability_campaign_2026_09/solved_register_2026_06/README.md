## Current status

The first high-value target, Randomstrasse/Balan-Wang Gaussian phase-retrieval
stability at the real threshold, has a complete manuscript, numerics, and Lean
combinatorics support in `phase_retrieval_omega`.

The active frontier is no longer the solved Gaussian theorem. It is the next
set of harder extensions:

1. Non-Gaussian bounded-density universality for the same extremal-submatrix
   stability scale.
2. Deterministic Balan-Wang exponential conjecture via the order-statistic
   width `K_m`.
3. Exact subexponential law for the Gaussian minimum.
4. Complex phase retrieval at the true complex threshold.

Use `candidate_ladder.md` for the easy-to-hard list and `status.md` for the
current proof state.
