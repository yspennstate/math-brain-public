# Round 233

Round 233 converts the spread-inward slab term into exterior-return language.

The exact-level return property now allows \(K=0\), meaning at least one
exterior return through level \(u\).  Define the spread-return property
\[
  \mathcal X^{\rm spr}_{j,K,p}(x,\gamma):
  \#\{u\in A_{j,p}\cap\mathbb N:u\ge1,\ \mathcal X_{u,0}(x,\gamma)\}
  >
  \frac{\theta_{\lambda,\sigma,\beta}}{4K}L_H .
\]
If a path has an inward token at level \(u\), the exterior-return lemma gives
\(\mathcal X_{u,0}\).  Hence
\[
  \mathfrak V^{\rm rad,in,spr}_{j,K}
  \le
  \mathfrak X^{\rm rad,ret,spr}_{j,K}.
\]

The resulting ladder is
\[
  \mathfrak Y_{\lambda_0}
  \le
  \mathfrak Y_{\lambda_N}
  +
  \sum_{i,j}\mathfrak V_{i,j}^{\rm hor}
  +
  \sum_{i,j}S_{i,j}^{\rm ret}
  +
  \sum_{i,j}W_{\beta_i,p}X_{i,j}^{\rm ret}.
\]
So the nonterminal localized obligations are now horizontal-heavy slabs,
spread exterior returns, and exact-level repeated exterior returns.
