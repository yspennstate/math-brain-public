# Round 111 log

## Goal

Turn annular square mass into actual remote vertex layers.

## Result

Added `def:annular-root-layers`, `lem:annular-root-layer-extraction`, and
`prop:weighted-root-layer-obstruction`.

For
\[
  Z_p^I(K,\lambda)=
  \left\{z:\sum_{\substack{x\in K\\d(x,z)\in I}}\tau_p(x,z)
  \ge \lambda\bar\chi_p\right\},
\]
we have
\[
  \frac{\mathcal R_p^I(K)}{\bar\chi_p}
  \le
  \lambda+\frac{|Z_p^I(K,\lambda)|}{|K|}.
\]

Consequently, failure of far-leg tightness forces, on arbitrarily remote
dyadic tails, a weighted family of annular root layers with total size
bounded below relative to the macroscopic witness set \(K\).

## Interpretation

The obstruction is now geometric rather than purely quadratic: a
counterexample must produce many remote vertices that each receive a
threshold fraction of the near-critical susceptibility from the same finite
test set through prescribed distance annuli.
