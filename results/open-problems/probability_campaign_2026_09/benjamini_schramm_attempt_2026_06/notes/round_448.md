# Round 448 jump endpoints cannot be counted as clique edges

Round 448 records a serious caveat for the jump-skeleton strategy from
Round 447.

After deleting a root return interval, the skeleton has a formal same-sphere
jump \(a\leadsto b\).  It is tempting to count these skeletons by adding a
complete graph on each sphere and treating every jump as one horizontal edge.
This is far too expensive.

At the relevant radii \(u\asymp L_H\), spheres can have exponential size:
\[
  |S_u(x)|\le D_H^{O(L_H)}.
\]
An arbitrary same-sphere jump would therefore have endpoint entropy
\[
  \log |S_u(x)| = O(L_H)
\]
per jump.  If the few-root branch allows \(m\le\kappa L_H\) jumps, the naive
clique-skeleton count can lose
\[
  O(\kappa L_H^2)
\]
in the logarithm, which is much larger than the \(O(L_H)\) exponent budget.

Thus the jump-skeleton lemma cannot be a crude augmented-graph counting
statement.  It must keep the endpoint choices coupled to the annular return
transfer kernels.  Equivalently, the deleted intervals should be treated as
weighted operators between the endpoint distributions generated by the
ordinary skeleton, not as free jumps.

The few-root coverage split still helps, but only in the radial-coordinate
entropy:

* the coverage intervals have low level entropy when \(m\le\kappa L_H\);
* the vertex endpoint entropy remains dangerous;
* controlling it requires the same cut/subset boundary-energy estimates from
  Rounds 441--442, now applied to a smaller number of longer root intervals.

The corrected conclusion is that the few-root branch is not purely
deterministic.  The deterministic coverage argument pays for choosing which
levels are covered, while an analytic annular-transfer estimate must still
control which boundary vertices carry the corresponding jumps.
