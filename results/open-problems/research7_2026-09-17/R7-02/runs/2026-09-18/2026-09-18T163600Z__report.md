## 3. B18 — exact failure-kernel reformulation

Let `pi` denote the percolation configuration and

`S(omega) = {b in B : o<->b in omega}`,  `C={S!=empty}`.

For each admissible source event define

`f_b(omega)=P(E_b | pi=omega)`,  `q_b(omega)=1-f_b(omega)`.

Then `q_b` is decreasing, `0<=q_b<=1`, and

`E q_b=P(E_b^c)<=epsilon`.

Let `F` be source failure, namely `C` occurs but no connected boundary point has its event `E_b`. Conditional on `pi=omega`, failure requires all `E_b^c` for `b in S(omega)`. Therefore

`P(F | pi=omega) <= min_{b in S(omega)} q_b(omega)`

and hence

`P(F)/P(C) <= E[1_C min_{b in S}q_b]/P(C).`      (3.1)

This bound is sharp over all allowed extra randomness. Given any decreasing functions `(q_b)` with `E q_b<=epsilon`, add one common independent `U~Unif[0,1]` and set

`E_b={U>q_b(pi)}`.

Then `P(E_b|pi=omega)=1-q_b(omega)` is increasing and the conditional probability that all connected `E_b` fail is exactly

`P[U<=min_{b in S}q_b(omega)]=min_{b in S}q_b(omega)`.

Thus if

`R_*(epsilon) := sup E[1_{S!=empty} min_{b in S}q_b]/P(S!=empty)`,

where the supremum runs over all finite source instances and all decreasing `(q_b)` with means at most `epsilon`, then the source conjecture is exactly equivalent to

`R_*(epsilon) -> 0` as `epsilon -> 0`.

This removes auxiliary-randomness dependence with no loss and identifies a single exact product-lattice variational quantity.

## 4. B30 — complete bounded-contact theorem

For `C_b={o<->b}`, `1_{C_b}` is increasing while `q_b` is decreasing. Harris-FKG therefore gives

`E[1_{C_b}q_b] <= P(C_b) E[q_b] <= epsilon P(C_b).`

Pointwise on `C`,

`min_{b in S}q_b <= sum_b 1_{C_b}q_b`.

Summing the FKG bounds yields

`E[1_C min_{b in S}q_b] <= epsilon sum_b P(C_b)=epsilon E|S|`.

Consequently

`R(G,p,o,B;q) <= epsilon E[|S| | S!=empty].`      (4.1)

So every class with conditional boundary-contact mean at most `M` satisfies the source conclusion with

`phi_M(epsilon)=max(0,1-M epsilon)`.

In particular `|B|<=m` gives `phi=max(0,1-m epsilon)` on arbitrary finite graphs. This is a full proof of a restricted theorem, not a full-source solution. It sharpens the admission diagnosis: the unresolved regime is precisely the one in which the number of boundary contacts can grow and one must exploit the `min` in (3.1) rather than pay its first moment.

## 5. B20 — exact gluing failure of a monotone-selector proof

The obvious way to try to remove the contact factor in (4.1) is to construct nonnegative weights `h_b(omega)` supported on connected boundary vertices, summing to `1_C`, with each `h_b` increasing. Then FKG would give

`E[h_b q_b] <= epsilon E[h_b]`

and summation would prove the source with `phi=1-epsilon`.

This architecture is impossible already on a two-edge star. At configuration `(1,0)`, support and the partition identity force `h_1=1`; monotonicity forces `h_1(1,1)>=1`. Likewise `(0,1)` forces `h_2(1,1)>=1`, contradicting `h_1+h_2=1` at `(1,1)`.

More generally, on the `m`-edge star, any nonnegative monotone cover supported on connected arms and satisfying `sum h_b>=1` on every nonempty configuration has total mass at least `m` at the all-open configuration: each singleton-arm configuration forces its own `h_b>=1`, and monotonicity propagates all `m` inequalities upward. Hence a direct monotone partition-of-unity/FKG proof necessarily suffers an unbounded gluing cost. This is a real obstruction, not a missing algebraic manipulation.
