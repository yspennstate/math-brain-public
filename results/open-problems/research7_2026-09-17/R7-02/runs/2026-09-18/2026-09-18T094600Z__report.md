## 4. B6 — deform the solved losange by an arbitrary series length

Fix `m>=2`. Replace the left terminal edge `s-a` of the five-edge losange by a chain of `m` unit-initialized edges. Retain `a-t`, `s-b`, `b-t`, and bridge `a-b`. The right path `R=s-b-t` is the unique geodesic of length two; every other edge is non-geodesic.

There are four possible loop-erased simple paths. Let their counts after `n` ants be `L,A,B,R`, with `L+A+B+R=n`, where:

- `L` is chain + `a-t`;
- `A` is chain + `a-b-t`;
- `B` is `s-b-a-t`;
- `R` is the unique geodesic `s-b-t`.

Define raw edge weights

`u=1+L+A`, `v=1+L+B`, `w=1+A+B`, `d=1+R+B`, `e=1+R+A`,

and `t=n+2`. Then

`u+d=t`, `v+e=t`.

All chain edges always reinforce together and keep common weight `u`. Series suppression in the weighted spanning-tree law therefore replaces the chain by one effective edge of conductance

`g=u/m`.

When the chain is reinforced, `g` increases by `1/m`. Thus the original source process is exactly an anisotropically reinforced five-edge losange with conductances `(g,v,w,d,e)`.

The weighted spanning-tree partition function is

`Z_m = gvw + gvd + gve + gwe + gde + vwd + vde + wde`,

and the four exact UST-path probabilities are

`q_L = gv(w+d+e)/Z_m`,

`q_A = gwe/Z_m`,

`q_B = vwd/Z_m`,

`q_R = de(g+v+w)/Z_m`.

The exact symbolic checker verifies that these sum identically to one.

## 5. Strict Lyapunov drift for every m>=2

Set

`S=u+v+w`, `V=S/t`.

Every non-geodesic path `L,A,B` increments exactly two of `u,v,w`; the geodesic path `R` increments none. Therefore

`S=3+2(L+A+B)=2n+3-2R`,

and hence

`V = 2 - (2R+1)/t`.

Let

`Delta_m := q_R - (R+1/2)/t`.

A one-step calculation gives

`E[V_{n+1}-V_n | F_n] = -2 Delta_m/(t+1)`.

The key exact algebraic identity is

`Delta_m = N_m(L,A,B,R)/(2 m t Z_m)`,

with

`N_m = N_2 + (m-2)(B+R+1) Q_0`,

where both `N_2` and `Q_0` have strictly positive integer coefficients. The explicit `Q_0` and the exact decomposition are written in the theorem artifact. Since all path counts are nonnegative and `m>=2`,

`Delta_m > 0`

at every finite state.

Consequently `V_n` is a bounded nonnegative supermartingale, so

`V_n -> V_infty` a.s.

and its predictable compensator satisfies

`sum_n Delta_m(n)/t_n < infinity` a.s.

Also

`q_R = (R+1/2)/t + Delta_m > 1/(2t)`,

so conditional Borel–Cantelli yields

`R_n -> infinity` a.s.

This already improves the once-subdivided analysis: the full infinite family is controlled by one exact positive drift polynomial rather than separate case estimates.

## 8. Supercritical-birth exclusion and the family theorem

The remaining stochastic step is a self-contained lemma.

Let an integer-valued nondecreasing process `N_n` have Bernoulli increments with conditional probability `p_n`, and let `t_n=n+O(1)`. There is no event on which all three hold:

1. `N_n -> infinity`;
2. `N_n/t_n -> 0`;
3. eventually `p_n >= c N_n/t_n` for some `c>1`.

Proof: with harmonic numbers `H_j`,

`H_{N_{n+1}}-H_{N_n}=Y_{n+1}/(N_n+1)`.

Hence

`H_{N_n}=H_{N_0}+M_n+sum_{k<n} p_k/(N_k+1)`.

The martingale quadratic variation is summable because

`E sum p_k/(N_k+1)^2 = E sum Y_{k+1}/(N_k+1)^2 <= sum_{j>=N_0} 1/(j+1)^2 < infinity`.

Thus `M_n` converges a.s. If `1<c'<c`, then on the alleged event and for large `n`,

`p_n/(N_n+1) >= c'/t_n`.

So `H_{N_n} >= c' log n + O(1)`, whereas `N_n<=N_0+n` gives `H_{N_n} <= log n + O(1)`, contradiction.

Apply this lemma with `N_n=R_n`. Under the bad alternative, the projective calculation gives eventually `q_R >= cR/t` for any fixed `1<c<3/2`, contradicting the lemma. Therefore

`V_infty=0` a.s.

Since `V=(u+v+w)/t` and all three summands are nonnegative,

`u/t -> 0`, `v/t -> 0`, `w/t -> 0`.

Thus every edge of the `m`-edge chain, `a-t`, and `a-b` has sublinear weight. From `u+d=t` and `v+e=t`,

`d/t -> 1`, `e/t -> 1`.

Therefore for every integer `m>=2`, on this non-series-parallel graph family the source loop-erased process almost surely finds the unique geodesic in the full source sense: every non-geodesic edge has `o(n)` weight and the two geodesic edges have normalized weight tending to one.
