## 4. Exact blocking formula I — bad loop-erased boundary faces really exist

For the loop-erased rule, a single ant's reinforced path has the law of the `s`–`t` path in a weighted UST. Therefore every boundary state supported on a single simple `s`–`t` path is a fixed point of the mean ODE: if all off-path conductances vanish, the UST path is that path with probability one, even if the path is not globally shortest.

So the full theorem cannot be proved by showing that the deterministic vector field has no bad boundary equilibria. It does have them. The needed statement is instead a **boundary nonconvergence theorem**: every fixed point supported on a non-geodesic path must be repelling in an accessible transverse direction strongly enough that the stochastic process almost surely cannot converge to it.

This is the first exact conceptual blocker.

## 5. Exact blocking formula II — the local path-invasion exponent

The cleanest local model is unicyclic. Start with a simple `s`–`t` support path `P`. Choose two vertices `u,v` on `P` whose segment in `P` contains `d` edges, each of conductance one. Add an internally disjoint alternate `u`–`v` path `Q` of `r` edges, each of conductance `epsilon>0`. All other edges of `P` lie outside the unique cycle and play no role in the comparison.

A weighted spanning tree is obtained by deleting one edge of that unique cycle. If a `P`-segment edge is deleted, the `s`–`t` UST path must use all of `Q`; there are `d` such deletions, each of tree weight proportional to `epsilon^r`. If a `Q` edge is deleted, the UST path uses the original `P` segment; there are `r` such deletions, each of weight proportional to `epsilon^(r-1)`. Hence the formula is exact:

`P(UST path uses Q) = d epsilon / (r + d epsilon)`.

Every edge of `Q` is reinforced exactly on that event, so

`p_Q(epsilon) / epsilon = d / (r + d epsilon) -> d/r`.

Consequently the normalized mean drift transverse to the bad path is

`dot epsilon = epsilon * (d/r - 1) + O(epsilon^2)`.

Thus:

- if `r<d`, a strictly shorter bypass has positive linear invasion exponent `d/r-1`;
- if `r=d`, the first-order direction is neutral;
- if `r>d`, the bypass is locally contracting.

This gives the exact local reason a non-geodesic path should be unstable: somewhere it admits a shorter replacement, and in the isolated-cycle model that replacement invades.

For unequal conductances `q_1,...,q_r` on `Q`, the same exact enumeration gives effective series conductance

`g_Q = (sum_i 1/q_i)^(-1)`

and

`P(UST path uses Q) = d g_Q / (1+d g_Q)`.

The coordinatewise ratio is then `p_i/q_i = [d g_Q/(1+d g_Q)]/q_i`, so the radial direction depends on the projective ratios `q_i/g_Q`. This is the first concrete gluing failure: a scalar `epsilon` invasion coefficient is not enough once multiple small edges can approach a boundary at different rates or overlapping bypasses share edges. A full proof needs a projective/blow-up control, not just the sign of one Jacobian entry.

## 6. Exact blocking formula III — why distance two was special in the suspension proof

For every simple reinforced path, exactly one edge incident to `s` and one edge incident to `t` are reinforced. With the source-standard all-ones initialization and the common terminal normalization, each terminal cut has total normalized conductance one. Thomson's principle therefore gives the universal bound

`R_st >= 1 + 1 = 2`,

because the two terminal cuts are disjoint and every unit flow pays at least one unit of energy on each.

On a distance-two suspension, `2` is exactly the geodesic resistance baseline, and equality leaves no energy for the internal non-geodesic edges. That coincidence is what allowed the previous resistance Lyapunov to identify the desired face.

For graph distance `d>2`, the same terminal argument still gives only `R_st>=2`, while a unit-conductance geodesic of length `d` has resistance `d`. The missing `d-2` units are interior geometry; terminal conservation alone does not control them. Equivalently, for the BFS cutsets `C_k = delta({v: dist(s,v)<=k})`, `k=0,...,d-1`, the cutsets are edge-disjoint and Nash-Williams gives

`R_st >= sum_k 1/m_k`, where `m_k = sum_{e in C_k} c_e`.

Only the first cut mass is automatically the fixed terminal mass in this particular family; the internal `m_k` are increased by the number of times the reinforced simple path crosses the corresponding layer cut and need not stay one. A reverse BFS family gives the analogous terminal control from `t`. Hence there is no automatic source-wide `R_st>=d` Lyapunov with equality characterizing geodesic support.

This is the exact formula explaining why the prior stochastic proof does not merely need a technical extension from distance two to arbitrary distance: it is missing an interior cut/energy invariant.

## 7. Separate blocker for the uniform-geodesic source rule

Let `T` be the edge set visited by one stopped random walk. Write `G(T)` for the set of shortest `s`–`t` paths contained in that trace, `N(T)=|G(T)|`, and `N_e(T)` for the number of those shortest trace-paths using edge `e`. The uniform-geodesic rule has the exact selection probability

`p_e^UG(c) = E_c[ N_e(T) / N(T) ]`.

The denominator is a global functional of the entire random trace. Unlike the loop-erased rule, there is no available UST/two-forest deletion identity that converts this expression into a local conductance ratio. Multiple shortest trace-paths can coexist and the factor `1/N(T)` couples them nonlocally. The 2022 paper's special five-edge losange argument exploits the fact that this trace ambiguity is unusually constrained there; the same paper does not prove the uniform-geodesic rule on all series-parallel graphs.

Therefore one should not pretend the forest machinery solves both halves of P0072. The two source rules presently require different missing ingredients.

## 8. Simplest unresolved finite case to attack next

The clean recovery case for the loop-erased half is obtained by taking the five-edge losange and subdividing one terminal edge once. Concretely, with terminals `s,t`, interior vertices `x,a,b`, take edges

`s-x, x-a, a-t, s-b, b-t, a-b`.

The global geodesic is `s-b-t` of length two. The subdivided left branch has length three, so `s-x`, `x-a`, and `a-t` are non-geodesic; the bridge `a-b` is also non-geodesic. This graph lies outside the previous suspension theorem because `x` and `a` are not each adjacent to both terminals. Suppressing the degree-two vertex `x` recovers the five-edge Wheatstone/losange obstruction, so this is also outside the two-terminal series-parallel class solved by Kious–Mailler–Schapira.

This is not claimed as an exhaustive graph-isomorphism minimality theorem. It is the smallest clean one-subdivision case that simultaneously leaves both solved loop-erased classes while retaining exact tractability.

There is an important exact reduction. The two series edges `s-x` and `x-a` are always used together by a simple path, and from equal initial weights their raw weights remain equal, say `u`. Series suppression replaces them in the weighted spanning-tree law by one effective edge of conductance

`g = u/2`.

Whenever that effective branch is reinforced, `u` increases by one, so `g` increases by `1/2`; all ordinary losange edges still increase by one. The once-subdivided source graph is therefore exactly a **losange with anisotropic reinforcement amplitude** `lambda=1/2` on one effective edge, rather than the standard `lambda=1` process already solved in this root.

This isolates a one-parameter deformation from the solved point.

A useful repair also appears immediately at the level of the previous harmonic-number method. For an edge of conductance `x` reinforced by a fixed amount `lambda`, define

`F_lambda(x) = (1/lambda) psi(x/lambda)`,

where `psi` is the digamma function. The recurrence `psi(z+1)-psi(z)=1/z` gives exactly

`F_lambda(x+lambda)-F_lambda(x)=1/x`.

Thus every ratio identity of the form `sum_e sigma_e p_e/c_e=0` still lifts to an exact martingale after replacing ordinary harmonic numbers by the appropriate `F_lambda`. For `lambda=1`, this is harmonic number plus an irrelevant constant; for the subdivided effective edge `lambda=1/2`, it is the corresponding half-step potential. This shows that subdivision does not destroy the martingale philosophy; it changes the step size and exposes precisely where a projective/boundary argument must be redone.

At the bad boundary path `s-x-a-t`, the shorter branch `s-b-t` has `d=3`, `r=2` in the isolated invasion calculation, hence positive exponent

`d/r - 1 = 1/2`.

So this first unsolved geometry has a concrete repelling mode rather than a merely heuristic one.
