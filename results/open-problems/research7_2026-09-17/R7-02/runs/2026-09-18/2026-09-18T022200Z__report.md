## 3. B4 — exact source-specific 3 x 2 product theorem

The previous diagnosis identified one stale package interface: the old paper still contained a superseded bi-infinite formal-series cancellation inside a stronger distinct-prime product theorem. An earlier artifact had already repaired the stronger theorem by fibres, but the source does not require that stronger result. B4 therefore asks for the smallest complete theorem that closes the actual six-cell branch.

### Theorem

Let `A,B subset Z` satisfy

- `A` is a complete residue system modulo `3` and `gcd(A-A)=1`;
- `B` is a complete residue system modulo `2` and `gcd(B-B)=1`.

Then every `(A x B)`-tiling `T` of `Z^2` has one of the coordinate periods `(3,0)` or `(0,2)`.

### Proof

Define row and column fibres

`S_y={x:(x,y) in T}`, `T_x={y:(x,y) in T}`.

Khetan Lemma 3.6 gives

`R_n = disjoint_union_{b in B} S_{n-b}` an `A`-tiling,

`C_m = disjoint_union_{a in A} T_{m-a}` a `B`-tiling.

Corollary 3.4 therefore gives residue profiles

`R_n=3Z+r_n`, `r_n in Z/3Z`,

`C_m=2Z+s_m`, `s_m in Z/2Z`.

**Case 1: `s` constant.** Every nonempty row has the one parity represented by `s`. For a nonempty row `S_y` and any `b in B`, put `n=y+b`. If another summand `S_{n-b'}` in `R_n` is nonempty, then `n-b'` has the same parity as `y=n-b`, so `b'=b (mod 2)`. Because `B` is a complete residue system modulo 2, `b'=b`. Hence `S_y=R_n`, a full coset of `3Z`. Every row is therefore horizontally 3-periodic and `(3,0)+T=T`.

**Case 2: `s` nonconstant.** Its codomain is `Z/2Z`, so `Image(s)=Z/2Z`. A row is nonempty exactly when its parity is in `Image(s)`, hence every row is nonempty. Write `B={b_0,b_1}`. Since `gcd(B-B)=1`, `b_1-b_0=+/-1`. For every `y`, the same nonempty set `S_y` lies inside both `R_{y+b_0}` and `R_{y+b_1}`. Distinct `3Z` cosets are disjoint, so

`r_{y+b_0}=r_{y+b_1}` for all `y`.

The two indices differ by one, hence `r_n` is constant. It follows that every nonempty column has one fixed residue modulo 3. In the decomposition of `C_m`, completeness of `A` modulo 3 makes a chosen nonempty column the unique nonempty summand, so that column equals the full coset `C_m=2Z+s_m`. Every column is vertically 2-periodic, hence `(0,2)+T=T`.

This proves the exact product endpoint required by the source. It uses neither the old formal-series cancellation nor Khetan Lemma 3.7.

## 4. B12 — the conserved finite object is the pair of residue profiles

The product endpoint has an exact finite invariant that had been obscured by the stronger algebraic proof.

Each horizontal fibre union carries one residue `r_n in Z/3Z`; each vertical fibre union carries one residue `s_m in Z/2Z`. The binary profile `s` has only two possibilities:

1. `|Image(s)|=1`: uniqueness in the `B` decomposition makes every occupied row itself a complete `3Z` coset;
2. `|Image(s)|=2`: every row is occupied and the two `B` shifts, differing by one, force `r_n=r_{n+1}` for all `n`.

Thus one coordinate fibre system must collapse to a periodic coset structure. This identifies the actual conservation mechanism at cardinality six.

It also explains the sporadic simplification. For a general `p x q` product with `q>2`, a nonconstant `s:Z->Z/qZ` need not be surjective, so not every row need be occupied and adjacent propagation of the other profile does not follow. Six cells are special because the two-point factor turns nonconstant into surjective automatically.
