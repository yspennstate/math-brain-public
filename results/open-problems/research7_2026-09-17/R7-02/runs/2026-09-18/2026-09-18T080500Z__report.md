## 4. The new stochastic theorem

Consider a finite two-terminal suspension graph: terminals `s,t`, a finite interior set `I`, both terminal edges `si,it` for every `i`, and an arbitrary internal graph `H` on `I`. Every internal edge is non-geodesic because every interior vertex already supplies a length-two route `s-i-t`.

For the loop-erased reinforcement process, let raw terminal weights be

\[
L_i(n)=W_{si}(n),\qquad R_i(n)=W_{it}(n).
\]

Every simple reinforced path uses exactly one `s`-terminal edge and one `t`-terminal edge, so

\[
S_n:=\sum_iL_i(n)=\sum_iR_i(n)=S_0+n.
\]

Normalize

\[
l_i=L_i/S_n,\qquad r_i=R_i/S_n,\qquad h_e=W_e/S_n,
\]

and write

\[
D_n=\|l(n)-r(n)\|_1.
\]

### Theorem proved in this run

For positive integer initial weights, in particular the source normalization with every initial edge weight one,

\[
\boxed{D_n\to0\quad\text{a.s.}}
\]

and for every internal edge `e`,

\[
\boxed{h_e(n)=W_e(n)/S_n\to0\quad\text{a.s.}}
\]

Hence

\[
\boxed{W_e(n)=o(n)\quad\text{a.s. for every internal non-geodesic edge}.}
\]

This proves the source conclusion for the **loop-erased rule on the full suspension class**, not on arbitrary finite graphs and not for the uniform-geodesic rule.

## 5. B13 — exact stochastic Lyapunov quantity: integrated excess resistance

Let `R_n` denote the raw effective resistance between `s,t`, and let

\[
\rho_n=S_nR_n
\]

be the resistance in the normalized network. The prior exact terminal-pair identity gives, for every fixed interior vertex `i`,

\[
\frac{p_{si}}{L_i}+\frac{p_{it}}{R_i}=R_n.
\]

Define

\[
A_i(n)=H_{L_i(n)-1}+H_{R_i(n)-1}.
\]

Then exactly

\[
\mathbb E[\Delta A_i(n)\mid\mathcal F_n]=R_n.
\]

Thomson's principle applied separately to the two terminal cuts gives

\[
R_n\ge\frac2{S_n},\qquad \rho_n\ge2.
\]

Since `L_i,R_i <= S_n`, one has `A_i(n) <= 2H_{S_n-1}`. Summing expectations and subtracting the exact harmonic series

\[
\sum_{k<n}\frac2{S_k}=2(H_{S_n-1}-H_{S_0-1})
\]

gives a uniform finite expectation bound on the nonnegative partial sums. By monotone convergence,

\[
\boxed{
\sum_{n\ge0}\frac{\rho_n-2}{S_n}<\infty\quad\text{a.s.}
}
\]

This is the stochastic replacement for the deterministic ODE Lyapunov argument.

The resistance excess quantitatively controls terminal imbalance. If `f` is the normalized energy-minimizing unit flow, with terminal-flow vectors `a,b` and internal flows `g`, then the terminal energies decompose exactly as

\[
\sum_i\frac{a_i^2}{l_i}=1+\sum_i\frac{(a_i-l_i)^2}{l_i},
\]

and analogously on the right. Since the normalized total internal conductance is uniformly bounded by a deterministic finite constant `M_H`, flow conservation and Cauchy–Schwarz yield

\[
\boxed{D_n^2\le(2+4M_H)(\rho_n-2).}
\]

Therefore

\[
\sum_n\frac{D_n^2}{S_n}<\infty\quad\text{a.s.}
\]

while a single ant changes `D_n` by only `O(1/S_n)`. The elementary excursion lemma for such slowly moving sequences then forces

\[
\boxed{D_n\to0\quad\text{a.s.}}
\]

This is genuine pathwise stochastic progress: the two normalized terminal distributions asymptotically coincide in total variation distance.

## 6. B27 — one uniform contraction inequality for every internal edge

The successful quantifier swap is to avoid classifying every possible bad boundary face. Instead, derive one statewise inequality that controls every internal edge whenever the terminal imbalance `D` is small.

For an internal forest `F` with components `C`, define

\[
L(C)=\sum_{i\in C}l_i,\qquad
R(C)=\sum_{i\in C}r_i,\qquad
M(C)=L(C)+R(C).
\]

A full `s-t` separating two-forest lying above `F` is obtained by attaching each internal component to exactly one terminal by exactly one terminal edge. Thus the total full two-forest weight over `F` factors as

\[
\left(\prod_{f\in F}h_f\right)
\prod_C M(C).
\]

Fix an internal edge `e=uv`. If `u,v` are in distinct components `C,D` of `F`, pair `F` with `F+e`. Put

\[
a=M(C),\quad b=M(D),\quad d_C=L(C)-R(C),\quad d_D=L(D)-R(D).
\]

The numerator contribution in which `u,v` are on opposite full terminal sides is

\[
\frac{ab-d_Cd_D}{2},
\]

whereas the paired denominator contribution is

\[
ab+h_e(a+b).
\]

Using

\[
|d_C|\le\min(a,D),\qquad |d_D|\le\min(b,D),
\]

and `a+b <= 2`, the paired ratios give the uniform bound

\[
\boxed{
\Pr_{\mathbb F_{s,t}}(u,v\text{ on opposite full sides})
\le
\frac1{2(1+2h_e)}+\frac{D}{4h_e}.
}
\]

The direct parallel length-two branches have total conductance

\[
C_0=\sum_i\frac{l_ir_i}{l_i+r_i}
\ge\frac12-\frac D4,
\]

so the normalized effective resistance satisfies

\[
\rho\le\frac2{1-D/2}.
\]

Combining this with the exact spanning-two-forest duality from the previous run gives the central new inequality

\[
\boxed{
\frac{p_e}{h_e}
\le
\frac1{1-D/2}
\left[
\frac1{1+2h_e}+\frac{D}{2h_e}
\right].
}
\]

For any fixed `epsilon > 0`, the right side is strictly below one whenever `h_e >= epsilon` and

\[
D<\frac{4\varepsilon^2}{(1+\varepsilon)(1+2\varepsilon)}.
\]

Since B13 proved `D_n -> 0`, for every `epsilon` there is eventually a uniform constant `q_epsilon < 1` such that

\[
\boxed{p_e(n)\le q_\varepsilon h_e(n)
\quad\text{whenever }h_e(n)\ge\varepsilon.}
\]

This explicit stripwise inward drift is the missing boundary-avoidance mechanism from the prior run.

## 7. B21 — stochastic-approximation analogy, reduced to a self-contained martingale-tail proof

The exact normalized recursion is

\[
h_e(n+1)-h_e(n)
=\frac{p_e(n)-h_e(n)}{S_n+1}
+\frac{\xi_e(n+1)}{S_n+1},
\]

where `xi_e = I_e-p_e` is a bounded martingale difference. Therefore

\[
M_e(n)=\sum_{k<n}\frac{\xi_e(k+1)}{S_k+1}
\]

converges almost surely because `sum (S_k+1)^(-2) < infinity`.

The classical Pemantle/Benaim/Raimond–Tarres nonconvergence results suggested treating bad boundary faces as unstable traps, but the suspension boundary is a nonisolated family and verifying a general theorem's full noise hypotheses would add unnecessary risk. The explicit inequality from B27 is stronger for this problem.

If `h_e >= epsilon` eventually, the accumulated negative drift is bounded above by a negative constant times `sum 1/S_n = infinity`, contradicting boundedness of `h_e` because the martingale term converges. Otherwise, any positive limsup would force infinitely many upcrossings from `epsilon` to `2 epsilon`; on each sufficiently late upcrossing the drift is nonpositive, so a fixed positive increment would have to come from a tail increment of the convergent martingale, which is impossible. Hence

\[
\boxed{h_e(n)\to0\quad\text{a.s.}}
\]

for each internal edge, and finiteness of `E_H` makes the conclusion simultaneous.
