# 4. Idea before code: change category from mixing coefficients to channel contraction

No checker was written. The new step is analytic and theorem-sized.

The previous proof converted the conditioned row-diameter estimate into a maximal-correlation estimate by first bounding a conditional phi coefficient and then using Bradley's generic inequality `rho <= 2 sqrt(phi)`. That loses a factor two.

The more natural object is the **Dobrushin diameter of the actual Markov channel**. A Dobrushin diameter controls chi-square contraction, and chi-square contraction is exactly squared maximal correlation at the infinitesimal level. This avoids passing through a second phi coefficient.

This run therefore asks a stronger question:

> If every pair of rows of a channel is within total-variation distance `delta`, what is the largest possible maximal correlation under an arbitrary input law?

The answer is `sqrt(delta)`, and the exponent is sharp. Once this is inserted into the already-validated alternating-block/Peyre argument, the full source theorem survives with a factor-two better constant.

# 5. B1 — change category: Dobrushin diameter and strong data processing

## 5.1 Obstruction first: a linear-in-delta local bound is impossible

Before proving a new inequality, test the strongest tempting version. Could one hope for

`rho(U,V) <= C delta(K)`

uniformly over all channels and input laws?

No. Take a binary erasure channel with erasure probability `1-delta`: with probability `delta` the output reveals the input exactly, and otherwise it outputs a common erasure symbol. The two channel rows have total-variation distance exactly `delta`.

With symmetric Bernoulli input and any centered input function `h`, conditional expectation is

- `h(U)` on the reveal event,
- `0` on the erasure event.

Hence

\[
\|\mathbb E[h(U)\mid V]\|_2^2
=\delta\,\|h\|_2^2,
\]

so

\[
\rho(U,V)^2=\delta,
\qquad
\rho(U,V)=\sqrt\delta.
\]

Thus the square-root dependence is unavoidable if one uses row diameter alone. This is a useful obstruction: any later improvement must exploit stationarity/Markov structure beyond a single channel, or improve the global path step, not the universal local conversion.

## 5.2 The local theorem

Let `(U,V)` take values in standard Borel spaces. Let `K(u,.)` be a regular conditional law of `V` given `U=u`. Suppose that on a full-input-measure set,

\[
\sup_{u,u'}\|K(u,\cdot)-K(u',\cdot)\|_{TV}\le\delta.
\]

Then

\[
\boxed{\rho(U,V)^2\le\delta.}
\]

Moreover, the same bound holds if the input distribution of `U` is changed arbitrarily while remaining supported on that same row-good set.

### Proof, finite case

For a finite stochastic matrix `K`, let `eta_chi2(K)` be the chi-square contraction coefficient. The Cohen--Iwasa--Rautu--Ruskai--Seneta--Zbaganu contraction theorem gives

\[
\eta_{\chi^2}(K)\le\delta(K).
\tag{5.1}
\]

Now let `lambda` be the input law, let `h in L^2_0(lambda)` be bounded, and for sufficiently small `epsilon` define

\[
d\lambda_\epsilon=(1+\epsilon h)d\lambda.
\]

If `nu=lambda K`, then a direct conditional-expectation calculation gives

\[
\frac{d(\lambda_\epsilon K)}{d\nu}(v)
=1+\epsilon\mathbb E[h(U)\mid V=v].
\]

Therefore

\[
\frac{\chi^2(\lambda_\epsilon K\|\nu)}
     {\chi^2(\lambda_\epsilon\|\lambda)}
=
\frac{\|\mathbb E[h(U)\mid V]\|_2^2}{\|h\|_2^2}.
\tag{5.2}
\]

By (5.1), the left side is at most `delta(K)`. Taking the supremum over bounded centered `h` and using density of bounded functions in `L^2` gives

\[
\rho(U,V)^2
=
\sup_{h\in L^2_0(\lambda)}
\frac{\|\mathbb E[h(U)\mid V]\|_2^2}{\|h\|_2^2}
\le\delta(K).
\]

### Passage to standard Borel spaces

Approximate arbitrary centered `L^2` test functions of `U` and `V` by bounded simple functions. They induce finite partitions and hence a finite channel.

Each row of that finite channel is a push-forward of a convex mixture of rows of the original channel. If all original rows lie in a TV-diameter-`delta` set, any two convex mixtures still differ by at most `delta`, because

\[
\left\|\int K(u,\cdot)d\alpha(u)-\int K(u',\cdot)d\beta(u')\right\|_{TV}
\le
\iint\|K(u,\cdot)-K(u',\cdot)\|_{TV}\,d\alpha(u)d\beta(u')
\le\delta.
\]

A finite push-forward can only decrease TV. The finite theorem therefore bounds the correlation of the simple approximants by `sqrt(delta)`, and the `L^2` limit gives the result.

Because this proof uses only the row family, not closeness to any fixed output marginal, it survives an arbitrary change of input law on the row-good set. This is exactly what conditioning the earlier Markov history does.

**B1 outcome:** success. The conditional local step is sharpened from `2 sqrt(2 phi)` to `sqrt(2 phi)`.

# 6. B3 — prove something stronger: an intrinsic row-diameter theorem

The source uses phi, but the block proof really needs only an intrinsic channel quantity.

For `s<t`, let `K_{s,t}` be the Markov transition kernel and define its essential row diameter

\[
\delta_{s,t}
:=
\operatorname*{ess\,sup}_{x,x'}
\|K_{s,t}(x,\cdot)-K_{s,t}(x',\cdot)\|_{TV},
\]

where the essential support is with respect to the actual law of `X_s`. Define

\[
\Delta(n):=
\sup_{s<t:\ t-s\ge n}\delta_{s,t}.
\tag{6.1}
\]

## Theorem 6.1 — intrinsic Markov interlacing bound

For the real-state Markov chain in Bradley's Section-3 setting,

\[
\boxed{
\rho^*(n)\le\min\{1,2\sqrt{\Delta(n)}\}.
}
\tag{6.2}
\]

### Proof

Take finite disjoint index sets `S,T` with `dist(S,T)>=n`. Order `S union T` chronologically and merge consecutive selected indices of the same color into maximal monochromatic blocks. The blocks form an alternating path.

Enumerate the `S`-blocks chronologically as `S_1,...,S_I` and the `T`-blocks as `T_1,...,T_J`, and write

`U_i=(X_k)_{k in S_i}`, `V_j=(X_k)_{k in T_j}`.

For Peyre's Theorem 3.3.1, in the Section-3.4(a) minimal-hypothesis form, the subjective pair `(U_i,V_j)` is viewed after conditioning only on earlier `S`-blocks and earlier `T`-blocks.

### Nonadjacent blocks

If `U_i,V_j` are nonadjacent in the chronological block path, the prescribed conditioning field contains an intervening block. In particular it contains a state at a time separating the two tested blocks. The Markov property makes past and future conditionally independent given that separator. Conditioning on additional variables on the past side does not destroy that separation. Hence the subjective maximal correlation is exactly zero.

### Adjacent blocks

If the two blocks are adjacent, let `s` be the final time of the earlier block and `t` the first time of the later block. Then `t-s>=n`.

Conditioning on the prescribed earlier blocks changes the input distribution of `X_s` but leaves the transition kernel `K_{s,t}` unchanged. If `A` is a `Law(X_s)`-null set, then the conditional probability of `X_s in A` is zero almost surely, since its expectation is zero. Thus the conditioned input remains on the same row-good set.

By the local Dobrushin lemma,

\[
\rho(X_s,X_t\mid\hbox{earlier blocks})
\le\sqrt{\delta_{s,t}}
\le\sqrt{\Delta(n)}.
\]

Markov data processing along

\[
U_i\to X_s\to X_t\to V_j
\]

under that conditional law gives the same bound for the adjacent block pair.

Therefore Peyre's subjective-correlation matrix has the sparsity pattern of a path and all nonzero entries at most `sqrt(Delta(n))`. Every row and every column has at most two nonzero entries, so

\[
\|E\|_{2\to2}
\le\sqrt{\|E\|_1\|E\|_\infty}
\le2\sqrt{\Delta(n)}.
\]

Peyre's theorem proves (6.2) for finite interlacings. Infinite index sets follow from finite-coordinate `L^2` approximation of their generated sigma-fields. QED.

This theorem is stronger than the source statement because it does not mention phi at all.

**B3 outcome:** success. The source implication is now a corollary of a more intrinsic row-diameter theorem.

# 7. B18 — translate back to Bradley's phi coefficient

The previous run proved the row-to-unconditional-marginal estimate: for fixed `s<t`, putting `g=t-s`, there is a full-`Law(X_s)` set on which

\[
\|K_{s,t}(x,\cdot)-Law(X_t)\|_{TV}\le\phi(g).
\tag{7.1}
\]

The proof is exact: for each Borel `B`, if

`h_B(x)=K_{s,t}(x,B)-P(X_t in B)`,

then the defining phi bound applied to every event `{X_s in D}` forces `|h_B(x)|<=phi(g)` almost everywhere; a countable generating algebra plus a monotone-class argument gives one common null set for all Borel `B`.

Triangle inequality in (7.1) gives

\[
\delta_{s,t}\le\min\{1,2\phi(t-s)\}.
\]

Since phi is nonincreasing in lag,

\[
\Delta(n)\le\min\{1,2\phi(n)\}.
\tag{7.2}
\]

Combining (6.2) and (7.2),

\[
\boxed{
\rho^*(n)
\le
\min\{1,2\sqrt{2\phi(n)}\}.
}
\tag{7.3}
\]

This improves the previous run's coefficient by a factor of two:

\[
4\sqrt{2\phi(n)}
\quad\longrightarrow\quad
2\sqrt{2\phi(n)}.
\]

In particular,

\[
\phi(n)\to0
\quad\Longrightarrow\quad
\rho^*(n)\to0,
\]

so the candidate source-level affirmative answer remains intact under the sharper proof.

**B18 outcome:** success. The channel-contraction formulation translates cleanly back to Bradley's source coefficient.

# 8. Stress tests, noncircularity, and what remains unproved

## 8.1 The local square-root exponent is genuinely sharp

The binary erasure channel above attains `rho^2=delta`. Therefore no theorem using only the row diameter can replace the local `sqrt(delta)` by `o(sqrt(delta))` uniformly.

This does **not** show that the global coefficient `2` in (6.2) is sharp inside the class of stationary Markov chains. It only rules out improving the local channel conversion in that level of generality.

## 8.2 The path factor is a separate issue

The factor two in (6.2) comes from the norm of a long weighted path. Abstractly, path adjacency matrices have norm approaching twice the edge weight as the path length grows. However, not every abstract subjective-correlation path need be exactly realizable by one stationary Markov chain with a prescribed Dobrushin profile. Thus I do **not** claim sharpness of the global constant.

## 8.3 Peyre conditioning was rechecked, not assumed

The dangerous point in the previous proof was the possibility that Peyre might require conditioning on a larger sigma-field than the Markov separator argument tolerates. Re-reading Theorem 3.3.1 together with Section 3.4(a) confirms the opposite: the minimal hypotheses permit precisely the earlier-variable conditioning used in the chronological block ordering.

For a nonadjacent pair, an intervening opposite-color block has lower index in its own color and is therefore present in the prescribed conditioning field. It contains a time-state separator. No future variable beyond the tested later block is inserted.

## 8.4 No circular dependency

- Bradley 1997 proves the result only from lower-psi mixing, a stronger hypothesis.
- Cohen et al. 1993 prove a channel contraction theorem and do not assume any interlaced-mixing conclusion.
- Peyre 2010 proves a general maximal-correlation tensorization theorem and does not assume Bradley Question 5.

The dependency graph therefore does not feed the target conclusion back into itself.
