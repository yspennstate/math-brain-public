# 3. B24 — extremal-object attack: finite-state counterexamples are impossible

The first useful result is a complete restricted theorem. I do **not** claim novelty; it is a clean consequence of Bradley’s lower-psi machinery and is recorded because it sharply localizes any source counterexample.

## Theorem 3.1 — finite-state phi-mixing Markov chains are rho*-mixing

Let `(X_k)_{k in Z}` be a strictly stationary Markov chain on a finite state space `S`, with stationary law `pi`, restricted to its stationary support. If the chain is phi-mixing, then it is rho*-mixing.

### Proof

Write `P` for the transition kernel. Since we work on the stationary support,

`pi_min := min_{x in S} pi(x) > 0`.

For a stationary Markov chain, taking the past event `{X_0=x}` in the definition of the phi coefficient gives, for every `x` with `pi(x)>0` and every subset `A subset S`,

`|P^n(x,A) - pi(A)| <= phi(n)`.

Indeed `{X_0=x}` has positive probability and, by the Markov property, the conditional law of `X_n` given `X_0=x` is `P^n(x,.)`.

Because `phi(n) -> 0`, choose `m` with

`phi(m) < pi_min/2`.

If `pi(A)>0`, then `pi(A) >= pi_min`, hence for every `x` in the stationary support,

`P^m(x,A) >= pi(A) - phi(m) >= pi(A) - pi_min/2 >= pi(A)/2`.

Thus the entire `m`-step kernel satisfies the measure minorization

`P^m(x,.) >= (1/2) pi(.)`                                                      (3.1)

for every stationary-support state `x`.

The following elementary lemma upgrades a single stationary-law minorization into lower-psi mixing.

### Lemma 3.2 — stationary-law minorization bootstraps geometrically

Suppose a stationary Markov kernel satisfies, for some `m>=1` and `c in (0,1]`,

`P^m(x,.) >= c pi(.)`                                                          (3.2)

for `pi`-a.e. `x`. Then along multiples of `m`,

`P^{km}(x,A) / pi(A) >= 1-(1-c)^k`                                             (3.3)

for every `A` with `pi(A)>0`, for `pi`-a.e. `x`. In particular the chain is lower-psi-mixing.

#### Proof of Lemma 3.2

Let `Pi` denote the rank-one stationary kernel `Pi(x,.)=pi(.)`. From (3.2), define

`R(x,.) := [P^m(x,.) - c pi(.)]/(1-c)`

when `c<1` (the case `c=1` is immediate). This is a Markov kernel. Stationarity of `pi` for `P^m` gives

`pi R = pi`,

so as kernels

`Pi R = R Pi = Pi`.

Therefore

`P^m = c Pi + (1-c) R`.

Using `Pi^2=Pi` and the two commutation identities above, induction gives

`P^{km} = [1-(1-c)^k] Pi + (1-c)^k R^k`.                                      (3.4)

The second term is nonnegative, so for every positive-`pi` event `A`,

`P^{km}(x,A) >= [1-(1-c)^k] pi(A)`,

which is (3.3). Hence the lower-psi coefficient tends to one along multiples of `m`, and monotonicity fills the remaining lags. QED.

Returning to Theorem 3.1, (3.1) supplies Lemma 3.2 with `c=1/2`. Bradley’s theorem that every lower-psi-mixing Markov chain is interlaced-rho-mixing then yields `rho*(n)->0`. QED.

### Consequence 3.3

A source-valid counterexample to D0033 cannot have a finite stationary support. More generally, it cannot satisfy a stationary-law minorization `P^m >= c Pi` at even one lag.

This is a meaningful narrowing of the search space, but it is **PARTIAL** and leaves `C_phi_rhostar=0`.

# 4. B11 — dual/operator reformulation: the exact missing property is a relative-probability lower bound

The preceding proof reveals a more useful general reduction.

## Proposition 4.1 — one pi-minorization is enough

For an arbitrary strictly stationary Markov chain, if there exist `m>=1` and `c>0` with

`P^m(x,A) >= c pi(A)`                                                         (4.1)

for `pi`-a.e. `x` and every measurable `A`, then the chain is rho*-mixing.

The proof is exactly Lemma 3.2 plus Bradley’s lower-psi theorem. No finite-state assumption is used.

Thus a counterexample to D0033 must satisfy the sharp necessary condition

`inf_{x,A: pi(A)>0} P^m(x,A)/pi(A) = 0`                                       (4.2)

for **every** lag `m`.

That condition is much stronger than merely being infinite-state.

## Proposition 4.2 — deep relative holes are forced onto tiny stationary sets

Assume phi-mixing. Fix `m` and `0<=a<1`. If some `x,A` satisfy

`P^m(x,A) <= a pi(A)`,                                                         (4.3)

then

`pi(A) <= phi(m)/(1-a)`.                                                       (4.4)

### Proof

From (4.3),

`pi(A)-P^m(x,A) >= (1-a)pi(A)`.

The Markov-chain phi bound gives

`pi(A)-P^m(x,A) <= |pi(A)-P^m(x,A)| <= phi(m)`.

Combining proves (4.4). QED.

In particular, if D0033 is false, then for every large `m` one can find a state/event pair `(x_m,A_m)` with, say,

`P^m(x_m,A_m) < (1/2)pi(A_m)`

and necessarily

`pi(A_m) <= 2 phi(m) -> 0`.                                                    (4.5)

This gives an exact structural description of what a counterexample must exploit: **arbitrarily deep relative holes whose stationary mass shrinks at the same scale as the additive phi error**.

### Density formulation

By stationarity, for every `m`, `P^m(x,.) << pi(.)` for `pi`-a.e. `x`: if `pi(A)=0`, then

`0 = pi(A) = integral P^m(x,A) pi(dx)`,

so `P^m(x,A)=0` for `pi`-a.e. `x`.

Let

`k_m(x,y) = dP^m(x,.)/dpi (y)`.

For the relevant essential states, phi-mixing provides additive convergence of the rows to stationarity, i.e. uniform `L1(pi)` control of `k_m(x,.)-1` (up to the conventional factor between total variation and the `L1` norm). By contrast, Proposition 4.1 would follow from a positive **uniform lower bound** on `k_m` at a single lag.

So the source problem can be viewed as asking whether the **Markov semigroup structure plus uniform additive row convergence** is enough to prevent the lower tails of `k_m(x,.)` from repeatedly collapsing on smaller and smaller `pi`-sets in a way that survives arbitrary interlacing.

Finite state closes the gap because `L1` control upgrades to a relative lower bound using `pi_min`. Infinite state has no such upgrade.

This is the cleanest obstruction found this run.

# 5. B2 — attack the negation: eliminate the obvious rare-state counterexample family

The most natural attempted counterexample is a “sticky refresh” chain: with probability `1-r`, redraw exactly from stationarity, and with probability `r` retain/evolve the old state. On an infinite or nonatomic state space this creates very sharp transition-density spikes on tiny sets, so it looks superficially suited to (4.5).

But it cannot be a counterexample.

More generally, suppose

`P = c Pi + (1-c) Q`                                                          (5.1)

for some `c>0` and a `pi`-stationary Markov kernel `Q`. Then already at lag one,

`P(x,.) >= c pi(.)`,

so Proposition 4.1 applies. Therefore **every exact stationary-refresh mixture is rho*-mixing**, regardless of whether the state space is finite, countable, or nonatomic.

This kills the simplest construction in which a small “no refresh” probability carries rare but exact memory.

### What a genuine negative construction must do

A counterexample must simultaneously have:

1. uniform additive mixing: `phi(m)->0`;
2. no stationary refresh component at any finite lag: (4.2) for every `m`;
3. deep holes on `pi`-sets of mass `O(phi(m))`, by (4.5);
4. an interlaced family of `L2` observables concentrated on those moving tiny sets whose normalized correlation stays bounded away from zero despite each individual past/future cut decorrelating.

This is substantially more constrained than the historical “fast rho but not rho*” requirement. In particular, a rare-state construction cannot merely hide memory on a low-probability state: phi takes a supremum over conditioning events, so the memory must be small in **absolute conditional-probability error from every starting event**, while the failure of rho* must arise only after L2 normalization and interlacing.

No source-valid counterexample was produced this run.

# 6. Why this does not solve the source

One might hope that phi-mixing (equivalently, the relevant uniform-ergodicity property for stationary Markov chains) automatically gives a Doeblin minorization and therefore (4.1). The standard Doeblin theorem, however, only supplies a common minorizing probability measure `nu`:

`P^m(x,.) >= eps nu(.)`.

It does **not** automatically identify `nu` with the stationary law `pi`, and additive closeness of `nu P^k` to `pi` does not by itself imply a lower bound relative to `pi` on arbitrarily small sets. Precisely this relative-versus-additive gap is where the argument stops.

Thus the remaining source-level bottleneck can be stated sharply:

> **Core blocker.** Does phi-mixing of a stationary Markov kernel force enough stationary-law minorization, perhaps after a different argument than pointwise density domination, to control maximal correlation uniformly over arbitrarily many interlacings? If not, can one build a uniformly additive-mixing kernel with the deep-hole structure (4.5) and use those holes to keep rho* bounded away from zero?

This is not resolved by the finite-state theorem or by ordinary uniform ergodicity alone as used here.
