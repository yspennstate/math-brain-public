# 5. Exact blocking formula: the audit-sensitive conditional path matrix

Take finite disjoint index sets `S,T` with `dist(S,T)>=n`. Order `S union T` chronologically and merge consecutive selected indices of the same color into maximal monochromatic blocks. Enumerate the S-blocks as

\[
U_1,\ldots,U_I
\]

and the T-blocks as

\[
V_1,\ldots,V_J.
\]

Peyre's Section 3.4(a) minimal-hypothesis formulation asks for a subjective pair bound for `(U_i,V_j)` after conditioning on

\[
\mathcal H_{ij}
=
\sigma(U_{i'}:i'<i,\;V_{j'}:j'<j).
\tag{5.1}
\]

Define the conditional subjective coefficient, schematically,

\[
\epsilon_{ij}
=
\operatorname*{ess\,sup}_{h}
\rho(U_i,V_j\mid \mathcal H_{ij}=h).
\tag{5.2}
\]

The candidate proof requires the exact path statement

\[
\boxed{
\epsilon_{ij}
\le
\kappa(n)\,
\mathbf 1\{U_i\text{ and }V_j\text{ are adjacent in the chronological block path}\},
}
\tag{5.3}
\]

where `kappa(n)` is the robust local HGR coefficient of the relevant Markov transition family. The local channel work proved

\[
\kappa(n)^2\le \Delta(n)\le 2\phi(n).
\tag{5.4}
\]

If (5.3) holds with exactly Peyre's required conditioning convention, the rest is mechanical. The subjective-correlation matrix is a bipartite path matrix; the `Z against Z` arcsine theorem yields

\[
\arcsin\rho(\sigma(X_s:s\in S),\sigma(X_t:t\in T))
\le
\left(2\arcsin\kappa(n)\right)\wedge\frac\pi2,
\tag{5.5}
\]

hence

\[
\rho^*(n)
\le
\Psi(\kappa(n)),
\qquad
\Psi(r)=\sin\!\left((2\arcsin r)\wedge\frac\pi2\right),
\tag{5.6}
\]

and therefore `rho_star(n)->0` whenever `phi(n)->0`.

So the exact audit-sensitive blocker is not a long calculation. It is the universal validity of (5.3), with **all three of the following simultaneously correct**:

1. the conditioning field in (5.1) is exactly the one allowed by Peyre, not a stronger field chosen for convenience;
2. for a nonadjacent pair, that prefix field contains a genuine chronological Markov separator, giving conditional correlation zero;
3. for an adjacent pair, arbitrary prefix conditioning changes only the input law of the boundary state, not the transition kernel, and the conditional input remains supported on the same row-good set on which (5.4) holds.

No counterexample to these three statements has been found in the track. But because they are the bridge between an external tensorization theorem and the source proof, they are the correct place for adversarial validation instead of further constant optimization.

# 6. Simplest unresolved audit case

The first block pattern where the prefix-conditioning geometry is genuinely nontrivial is four alternating blocks

\[
U_1 < V_1 < U_2 < V_2.
\tag{6.1}
\]

For this pattern, Peyre's prescribed prefix fields are

\[
\mathcal H_{11}=\{\emptyset,\Omega\},
\qquad
\mathcal H_{21}=\sigma(U_1),
\]

\[
\mathcal H_{12}=\sigma(V_1),
\qquad
\mathcal H_{22}=\sigma(U_1,V_1).
\tag{6.2}
\]

The claimed subjective matrix has the shape

\[
E=
\begin{pmatrix}
\le\kappa & 0\\
\le\kappa & \le\kappa
\end{pmatrix}.
\tag{6.3}
\]

The critical entry is `E_12=0`: after conditioning only on `V_1`, the past block `U_1` must be independent of the future block `V_2`. The Markov separator is the terminal state of `V_1`; the unobserved block `U_2` lies later and is simply part of the future evolution. The critical adjacent entry is `E_22`: conditioning on `(U_1,V_1)` must leave the `U_2 -> V_2` transition kernel unchanged while allowing an arbitrary input law on the boundary state.

If an exact finite-state countermodel can violate either assertion under Peyre's actual definition of subjective correlation, the present proof has a gap. If the four-block case is version-safe and the argument is written in a form that obviously iterates, it isolates the only genuinely delicate interface in the proof.

This is the **simplest unresolved validation case**. It is not a new source subproblem and does not redefine the metric.
