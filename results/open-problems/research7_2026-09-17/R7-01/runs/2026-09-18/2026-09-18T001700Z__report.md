# 3. B1 — change category: reduce the source to a robust channel coefficient

For `s<t`, let `K_{s,t}(x,.)` be a regular transition kernel and let `mu_s,mu_t` be the one-time laws. The existing row argument can be packaged as a channel coefficient rather than an event-by-event mixing statement.

Define `A_{s,t}` to be a common full-`mu_s` set on which

\[
\|K_{s,t}(x,\cdot)-\mu_t\|_{TV}\le \phi(t-s).
\tag{3.1}
\]

Such a common set exists: for each Borel `B`, if

\[
h_B(x)=K_{s,t}(x,B)-\mu_t(B),
\]

then for every positive-`mu_s` Borel `D`, the definition of `phi(t-s)` gives

\[
\left|\frac1{\mu_s(D)}\int_D h_B\,d\mu_s\right|\le\phi(t-s).
\]

A positive-mass set on which `h_B>phi+epsilon` or `h_B<-phi-epsilon` would contradict this. A countable generating algebra followed by monotone class removes the `B`-dependent null set. Hence for `x,x' in A_{s,t}`,

\[
\|K_{s,t}(x,\cdot)-K_{s,t}(x',\cdot)\|_{TV}
\le 2\phi(t-s).
\tag{3.2}
\]

Now define the robust local HGR coefficient

\[
\kappa(s,t)=\sup_\lambda \rho(U,V),
\]

where `U~lambda`, `V|U=x~K_{s,t}(x,.)`, and `lambda` ranges over all input laws supported on `A_{s,t}`. Put

\[
\kappa(n)=\sup_{t-s\ge n}\kappa(s,t).
\]

For any such input law, the law of `V` conditional on an event of `U` and the unconditional law of `V` are two convex mixtures of the same row family. Equation (3.2) therefore gives

\[
\phi(\sigma(U),\sigma(V))\le 2\phi(t-s).
\]

Bradley's standard two-sigma-field comparison gives

\[
\rho(U,V)\le 2\sqrt{2\phi(t-s)},
\]

hence

\[
\boxed{\kappa(n)\le \min\{1,2\sqrt{2\phi(n)}\}.}
\tag{3.3}
\]

This formulation is robust under every past-prefix conditioning needed later: if `G` is generated by coordinates no later than `s`, then `Law(X_s|G)` remains supported on `A_{s,t}` almost surely, and the Markov property leaves `K_{s,t}` unchanged. Thus the difficult-looking conditional HGR estimates are all instances of one channel norm bound.

The source question has therefore been moved into a clean operator statement:

> **If `kappa(n0)<1/2` at one lag, then the interlaced problem is source-solvable.**

The next two methods prove exactly that statement and identify why `1/2` is the natural abstract threshold.

# 4. B21 — import d-separation and the one-dimensional Dobrushin matrix

Fix finite disjoint `S,T` with `dist(S,T)>=n`. Chronologically merge selected times of the same color into maximal blocks

\[
B_1<B_2<\cdots<B_m.
\]

They alternate in color. Enumerate the `S`-blocks as `U_i` and `T`-blocks as `V_j`. Peyre's minimal-hypothesis prefix field is

\[
\mathcal H_{ij}=\sigma(U_{i'}:i'<i,\;V_{j'}:j'<j).
\tag{4.1}
\]

The preceding R7-01 recovery established the required version-safe conditioning lemma: if two sides are conditionally independent given a separator `R`, then conditioning further on a statistic of the left side and a statistic of the right side preserves their conditional product structure. Applying that lemma to the Markov path gives the exact subjective-correlation graph:

\[
\boxed{
\{U_i:V_j\}_{\mathcal H_{ij}}
\le \kappa(n)\mathbf 1\{U_i,V_j\text{ adjacent in the chronological block path}\}.
}
\tag{4.2}
\]

For adjacent blocks, all prescribed prefix variables occur before the earlier block boundary, so conditioning changes only the input law of the boundary state and (3.3) remains valid. For nonadjacent blocks, an intervening prefix block contains a Markov separator; after splitting the rest of the prefix into left-side and right-side coordinates, the side-separated conditioning lemma gives exact conditional independence.

This is precisely the interdependence matrix of a one-dimensional path. If all edge weights equal `a`, the full symmetric path adjacency matrix has spectral radius

\[
2a\cos\frac{\pi}{m+1}.
\]

Its bipartite off-diagonal block therefore has singular norm

\[
\boxed{\|E_m\|_{2\to2}=2a\cos\frac{\pi}{m+1}<2a.}
\tag{4.3}
\]

If the actual nonnegative edge weights are merely bounded by `a`, entrywise domination gives the same upper bound. As `m` tends to infinity these norms tend to `2a`.

So the factor two has an exact geometric meaning: it is the limiting spectral radius of the alternating-block path. In the abstract prefix-correlation model the uniform threshold `a<1/2` is exact. At `a=1/2`, every fixed finite path has norm strictly below one, but the supremum over arbitrarily long interlacings reaches one. Any improvement beyond this threshold must use additional compatibility among Markov channels, not merely the sparse path support.

# 5. B4 — prove only one strict lag, then invoke Bradley's own theorem

This is the main new simplification.

## Theorem 5.1 — one-lag strict contraction

For any not-necessarily-stationary Markov chain in Bradley's Section 3 setting, if

\[
\phi(n_0)<\frac1{32}
\]

for some lag `n0`, then

\[
\boxed{\rho^*(n_0)\le 4\sqrt{2\phi(n_0)}<1.}
\tag{5.1}
\]

Consequently the chain is `rho*`-mixing, with exponential decay supplied by Bradley Theorem 3.3(6).

### Proof

Set

\[
a=2\sqrt{2\phi(n_0)}<\frac12.
\]

For each finite admissible interlacing, (4.2) gives Peyre's subjective-correlation matrix supported on the alternating block path and bounded edgewise by `a`. Peyre Theorem 3.3.1 and (4.3) yield

\[
\rho(S,T)
\le \|E\|_{2\to2}
\le 2a
=4\sqrt{2\phi(n_0)}<1.
\tag{5.2}
\]

The right side does not depend on the number or sizes of blocks. For arbitrary countable `S,T`, approximate square-integrable functions of the two full coordinate sigma-fields by conditional expectations onto increasing finite coordinate sets. Covariance and variance converge in `L^2`, so (5.2) passes to the full sigma-fields. Taking the supremum over admissible `S,T` proves (5.1).

Bradley Theorem 3.3(6) then converts the one-lag strict inequality into `rho*(n)->0` at least exponentially. QED.

## Corollary 5.2 — source-level candidate answer

If the chain is phi-mixing, then `phi(n)->0`, so some `n0` satisfies `phi(n0)<1/32`. Theorem 5.1 then gives `rho*`-mixing.

This proof uses no stationarity and no direct asymptotic tensorization estimate. It also removes the classical Dobrushin-to-chi-square SDPI theorem from the minimum dependency chain. The only post-2005 ingredient is Peyre's 2010 tensorization theorem with its minimal-prefix hypothesis.

The stronger existing package remains useful: its SDPI estimate improves the sufficient one-lag numerical threshold to `phi(n0)<1/8`, and its arcsine theorem gives a better quantitative bound. Neither strengthening is needed for Bradley's yes/no question.
