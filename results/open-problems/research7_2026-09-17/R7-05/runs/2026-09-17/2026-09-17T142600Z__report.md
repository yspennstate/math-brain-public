## 4. B2 — attack the negation: the historical search imposed an unnecessary endpoint-stability constraint

Let `lambda_A(r)` denote the top radial exponent of the symmetric two-state Markov-switched system

`dX_t/dt = A_{I_t} X_t`,

where `I_t` switches `0 <-> 1` at common rate `r`.

Write

`A_i = s_i I + B_i`, with `s_i = tr(A_i)/2` and `tr(B_i)=0`.

Because the scalar part commutes with every matrix,

`X_t = exp( integral_0^t s_{I_u} du ) Y_t`,

where `Y` is driven by the traceless pair `(B_0,B_1)`. The symmetric two-state chain spends asymptotic fraction `1/2` in each mode, hence exactly

`lambda_A(r) = (s_0+s_1)/2 + lambda_B(r)`

for every `r>0`. Equivalently,

`lambda_A(r) = [tr(A_0)+tr(A_1)]/4 + lambda_B(r)`.

Thus scalar traces move the entire rate-response curve vertically and do not change its shape.

### Exact reformulation

For a continuous traceless response `F(r)=lambda_B(r)`, the literal source question has a positive answer iff some horizontal superlevel set `{r:F(r)>h}` is disconnected. In one dimension this is equivalent to failure of quasi-concavity, i.e. to the existence of

`0 < r_1 < r_2 < r_3`

such that

`F(r_2) < min(F(r_1),F(r_3))`.

Indeed, choose any `h` strictly between `F(r_2)` and the smaller endpoint value and set `A_i=B_i-hI`.

This corrects the overstrong statement in historical `E0018-A001` that two disjoint instability intervals necessarily require four sign changes and two interior local maxima. That conclusion is valid only after imposing stable slow/fast endpoints, for example by requiring the individual matrices and their average to be Hurwitz. **The literal source question does not state that extra hypothesis.** A single certified valley is enough.

### Additional invariances

Two further exact identities reduce the shape search:

- simultaneous similarity `B_i -> S B_i S^{-1}` leaves `lambda_B(r)` unchanged;
- common positive scaling obeys `lambda_{cB}(r)=c lambda_B(r/c)`.

For traceless `2 x 2` matrices the basic simultaneous-conjugacy invariants are

`x = (1/2) tr(B_0^2)`, `y = (1/2) tr(B_1^2)`, `z = (1/2) tr(B_0 B_1)`,

with Cayley–Hamilton relations

`B_0^2=xI`, `B_1^2=yI`, `B_0B_1+B_1B_0=2zI`.

Modulo generic simultaneous similarity and common scale, the response-shape problem therefore has only two continuous moduli (plus degenerate/discrete real-orbit strata). The old four-parameter numerical search carried redundant coordinates.

## 6. B11 — dualize: a pointwise corrector certificate bounds the Lyapunov exponent pathwise

Let `u(theta)=(cos theta,sin theta)` and `u_perp(theta)=(-sin theta,cos theta)`. For the traceless pair define

`a_i(theta) = <B_i u(theta),u(theta)>`,

`b_i(theta) = <B_i u(theta),u_perp(theta)>`.

The projective-angle/mode process has generator

`(L_r phi)(theta,i) = b_i(theta) d_theta phi(theta,i) + r[phi(theta,1-i)-phi(theta,i)]`.

The radial equation is

`d/dt log ||Y_t|| = a_{I_t}(Theta_t)`.

### Corrector lemma

Let `phi(theta,i)` be any bounded `C^1`, `pi`-periodic function. If for some real `c`

`a_i(theta)+(L_r phi)(theta,i) <= c`

for both modes and every angle, then the top radial exponent is at most `c`. If the inequality is reversed, the exponent is at least `c`. Strict pointwise inequality on the compact projective state space gives a strict exponent inequality.

**Proof.** Dynkin's formula gives the martingale

`M_t = phi(Theta_t,I_t)-phi(Theta_0,I_0)- integral_0^t (L_r phi)(Theta_s,I_s) ds`.

The corrector is bounded and its switch jumps are bounded; the switching rate is finite, so the martingale quadratic variation is `O(t)` and `M_t/t -> 0` almost surely. Also

`log(||Y_t||/||Y_0||) = integral_0^t a_{I_s}(Theta_s) ds`.

Therefore

`(1/t)log(||Y_t||/||Y_0||)`

`= (1/t) integral_0^t [a+L_r phi](Theta_s,I_s) ds`

`  - [phi(Theta_t,I_t)-phi(Theta_0,I_0)]/t + M_t/t`.

The last two terms vanish. The pointwise bound gives the claimed limsup/liminf inequality. This argument does not require uniqueness of the projective invariant law. QED.

For the shifted source matrices `A_i=B_i-hI`, the radial observable is `a_i-h`, so a certificate

`a_i + L_r phi > h`

proves exponential instability, while

`a_i + L_r phi < h`

proves exponential stability.

Put `T=tan(theta)`. Every `cos(2k theta)` and `sin(2k theta)` becomes a rational function of `T`. For a degree-`K` Fourier corrector, multiply the signed residual by `(1+T^2)^(K+1)`. The result is a polynomial `P_i(T)` with exact rational coefficients. Since the denominator is strictly positive, the corrector inequality is equivalent to `P_i(T)>0` for all real `T`, together with the projective point `T=infinity`.

For every polynomial below the exact Sturm count gives zero real roots, `P_i(0)>0`, and the leading coefficient is positive. Hence `P_i(T)>0` on the entire real line and at infinity.

## 9. B5 — rate parameter / derivative structure

Although the finite corrector certificate already decides the literal target, the rate-derivative structure is useful for the stronger Hurwitz-stable variant.

Write the projective generator as

`L_r = V + r K`,

where `K phi(theta,i)=phi(theta,1-i)-phi(theta,i)`, and let `F(r)=mu_r(a)` in a regime where a unique invariant law `mu_r` and differentiable Poisson solutions exist.

Choose centered `phi_r` satisfying

`L_r phi_r = F(r)-a`.

Differentiating the invariant relation `mu_r L_r=0` gives the exact linear-response identity

`F'(r)=mu_r(K phi_r)`.

If `psi_r` solves

`L_r psi_r = F'(r)-K phi_r`,

then differentiating once more gives

`F''(r)=2 mu_r(K psi_r)`.

There is no evident fixed sign because the projective transport makes `L_r` non-self-adjoint. This is the structural reason a general unimodality theorem is not automatic. For the stronger all-Hurwitz version, two bounded instability windows would require genuine interior oscillation of this response, rather than the endpoint-positive construction used here.

These derivative identities are not needed for the exact certificate and are recorded as a next-route tool, not as an assumption in the proof above.
