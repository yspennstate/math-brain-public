Exact locator: Theorem 3.5(ii) and Remark 3.6 in Section 3.2, with Theorem 3.1 and equation (3.1) supplying the firework comparisons used below.

The source assumptions relevant here are:

1. iid site counts `(eta_x)` with `0 < E[eta_0] < infinity`;
2. independent survival parameters `pi in (0,1)` whose density satisfies the source's regularly varying hypothesis near one,
   `f_pi(u) ~ (1-u)^(beta-1) ell((1-u)^(-1))`;
3. symmetric integer-valued random-walk increments;
4. either the stable regime `1 < alpha < 2` with `P(|xi_1|>n) ~ c_xi n^(-alpha)` and `r=alpha`, or the mean-zero finite-variance regime with `r=2`;
5. the critical line `beta=1/r`.

Writing `D^->` for the one-sided maximum of one frog before its geometric lifetime and `kappa` for the source's critical constant, the source proves

`n P(D^-> >= n) / ell(n^r) -> kappa`.

At this line, Theorem 3.5(ii) gives the two sufficient criteria

`liminf ell(n^r) > 1/(E[eta_0] kappa)  => survival with positive probability`,

`limsup ell(n^r) < 1/(4 E[eta_0] kappa) => extinction almost surely`.

## 6. Method B2 — attack the negation: the factor four is not intrinsic

The source upper comparison is the bidirectional one-radius firework process obtained by placing at each site

`I_x^* = max_{1 <= i <= eta_x} D^*_{x,i}`,

where `D^*` is the maximum absolute displacement of a frog during its lifetime. Every frog path from `x` stays inside `[x-I_x^*, x+I_x^*]`, so the actual activated set is pathwise contained in this upper firework informed set.

The source's extinction proof invokes a sufficient condition for this upper process that effectively demands tail coefficient below `1/2`. B2 asked whether that `1/2` is a true threshold of the upper process. The answer is no: the upper process itself admits a barrier-series criterion with coefficient-one boundary. Therefore one whole factor of two in the source extinction constant is an artifact of a coarse upper-process criterion, without yet needing to understand the much harder actual asymmetric left/right frog front.

This is an obstruction result against the idea that `1/4` might be structurally sharp.

## 7. Method B11 — dualize to a barrier product

For an iid nonnegative integer radius `I`, put

`q_j = P(I_0 > j)`

and

`a_n = prod_{j=0}^n (1-q_j) = prod_{j=0}^n P(I_0 <= j)`.

The exact bidirectional one-radius barrier criterion is

`P(infinite informed cluster)=0  iff  sum_{n>=1} a_n = infinity`.

Only the extinction direction is needed for the main theorem. The elementary coefficient lemma is as follows.

### Lemma 7.1

If `limsup_{j->infinity} j q_j < 1`, then `sum_n a_n = infinity`, so the iid bidirectional one-radius process dies out almost surely.

### Proof

Choose `theta<1` and `J` such that `q_j <= theta/j` for all `j>=J`, and increase `J` so that `q_j<=1/2`. For `0<=x<=1/2`,

`log(1-x) >= -x-x^2`.

Hence

`log a_n >= C_0 - sum_{j=J}^n q_j - sum_{j=J}^n q_j^2`.

The square sum is bounded and the first sum is at most `theta log n + O(1)`, so

`log a_n >= C_1 - theta log n`,

therefore

`a_n >= C n^(-theta)`.

Because `theta<1`, the series diverges. Apply the barrier criterion. QED.

### Random site maxima

Let `p_n=P(D^*>=n)` and `Q_n=P(I_0^*>=n)`. Conditioning on the site count gives the exact identity

`Q_n = E[1-(1-p_n)^(eta_0)]`.

Writing `m=E[eta_0]`, the union bound yields

`Q_n <= m p_n`.

Moreover, because `p_n->0`, dominated convergence applied to

`[1-(1-p)^k]/p -> k`, with `[1-(1-p)^k]/p <= k`,

gives `Q_n ~ m p_n` whenever `p_n` itself has an asymptotic.

### Theorem 7.2 — universal factor-two improvement

Under the full hypotheses of source Theorem 3.5 at `beta=1/r`,

`limsup ell(n^r) < 1/(2 E[eta_0] kappa)`

implies almost-sure extinction of the interval-activation frog model.

### Proof

The source critical asymptotic is

`n P(D^->>=n) / ell(n^r) -> kappa`.

Source equation (3.1) gives

`P(D^*>=n) <= 2 P(D^->>=n)`.

Therefore, with `m=E[eta_0]`,

`P(I_0^*>=n) <= m P(D^*>=n) <= 2m P(D^->>=n)`.

The stated hypothesis implies

`limsup n P(I_0^*>=n) < 1`.

After the harmless integer index shift between `>=n` and `>j`, Lemma 7.1 forces extinction of the upper iid bidirectional firework process. The source pathwise coupling places every frog-activated site inside that upper informed set, so the frog model also becomes extinct almost surely. QED.

## 9. Method B5 — add a parameter and differentiate: second-order coefficient boundary

To see what information is needed at coefficient exactly one, parameterize an iid radius by

`q_n = P(I_0>n) = 1/n + b/(n log n) + O(1/[n(log n)^(1+delta)] + 1/n^2)`

for some `delta>0`.

Since `sum q_n^2<infinity`,

`log a_n = sum_{j<=n} log(1-q_j) = -sum_{j<=n} q_j + O(1)`.

Using

`sum_{j<=n} 1/j = log n + O(1)`

and

`sum_{j<=n} 1/(j log j) = log log n + O(1)`,

one obtains

`a_n asymp 1/[n (log n)^b]`.

Therefore the exact bidirectional barrier criterion gives extinction for `b<=1` and positive percolation for `b>1`.

This is a precise obstruction to any attempted source proof that uses only the first-order coefficient at equality: `n q_n -> 1` by itself is insufficient. At coefficient one, the source-specific second-order slowly varying structure matters.

## 10. Stronger restricted theorem in the finite-variance branch

The universal proof deliberately retains only the source inequality `P(D^*)<=2P(D^->)`. In the finite-variance branch the critical two-sided constant can be computed from Brownian passage transforms.

Let

`tau_+ = inf{t>=0 : sigma B_t >= 1}`,

`tau_* = inf{t>=0 : |sigma B_t| >= 1}`.

Their Laplace transforms are

`E exp(-s tau_+) = exp(-a sqrt(s))`,

`E exp(-s tau_*) = sech(a sqrt(s))`,

with `a=sqrt(2)/sigma`.

At `beta=1/2`, the critical mixture in the source proof weights the limiting passage transform by `s^(-1/2) ds`. The ratio of the two-sided to one-sided constants is therefore

`R_B = [int_0^infinity s^(-1/2) sech(a sqrt(s)) ds] / [int_0^infinity s^(-1/2) exp(-a sqrt(s)) ds]`.

Set `t=sqrt(s)`. Then

`R_B = [2 int_0^infinity sech(a t) dt] / [2 int_0^infinity exp(-a t) dt]`.

The two integrals are `pi/(2a)` and `1/a`, so

`R_B = pi/2`.

For the discrete walk, let `tau_n^*=inf{k:|S_k|>=n}`. Donsker convergence gives `tau_n^*/n^2 => tau_*`. The domination needed to repeat the source's critical-mixture integral argument follows from

`u^(tau_n^*) = u^min(tau_n^+,tau_n^-) <= u^(tau_n^+) + u^(tau_n^-)`, `0<u<1`,

plus symmetry, so the source's one-sided integrability bounds transfer up to a factor two. Hence, at the source critical mixture scale in the finite-variance branch,

`P(D^*>=n) ~ (pi/2) P(D^->>=n)`.

Using `P(I_0^*>=n)~m P(D^*>=n)` then yields the restricted extinction theorem

`limsup ell(n^2) < 2/(pi m kappa) => extinction almost surely`.

Because `2/pi > 1/2`, this strictly improves Theorem 7.2 within the finite-variance branch. It is deliberately labeled **restricted / PARTIAL** and does not move the frozen full-source metric below `2`, because that metric ranges simultaneously over the stable and finite-variance source regimes.

This calculation also falsifies the old memo's informal universal ratio `P(D^*)~2P(D^->)` in the Brownian critical mixture: the correct ratio there is `pi/2`.
