## 3. B15 — break symmetry on purpose: unequal scalar shifts have an exact feasibility criterion

The previous literal witness used a common scalar shift. The first question for the stronger contextual scope is whether *unequal* scalar shifts can rescue the same traceless shape pair.

Let `B_0,B_1` be arbitrary real traceless `2 x 2` matrices and define

`F(r) := lambda_B(r)`,

the top Lyapunov exponent of the symmetric two-state Markov-switched traceless pair at common jump rate `r`.

Let

`A_i = B_i + s_i I`, `i=0,1`,

with arbitrary real scalar shifts `s_0,s_1`. Since the mode chain is symmetric, its occupation fractions converge to `1/2,1/2`, and the scalar part commutes with everything. Hence, exactly,

`lambda_A(r) = F(r) + (s_0+s_1)/2`.

Set

`h := -(s_0+s_1)/2`.

Then instability of the shifted system is exactly `F(r)>h`.

For a real matrix `M`, write `alpha(M)` for its spectral abscissa. Put

`beta_0 := alpha(B_0)`,

`beta_1 := alpha(B_1)`,

`beta_bar := alpha((B_0+B_1)/2)`.

Because the `B_i` are traceless real `2 x 2` matrices, each `beta_i>=0`.

### Theorem 3.1 — exact scalar-shift feasibility

For fixed traceless shapes `B_0,B_1` and a prescribed mean threshold `h`, there exist real shifts `s_0,s_1` satisfying

1. `s_0+s_1=-2h`,
2. `A_0=B_0+s_0I` is Hurwitz,
3. `A_1=B_1+s_1I` is Hurwitz,
4. `(A_0+A_1)/2` is Hurwitz,

if and only if

`h > beta := max( (beta_0+beta_1)/2, beta_bar )`.

**Proof.**

`A_i` is Hurwitz exactly when

`s_i < -beta_i`.

The average is

`(A_0+A_1)/2 = (B_0+B_1)/2 - h I`,

so it is Hurwitz exactly when `h>beta_bar`.

There exist `s_0<-beta_0` and `s_1<-beta_1` with `s_0+s_1=-2h` exactly when

`-2h < -(beta_0+beta_1)`,

or equivalently

`h>(beta_0+beta_1)/2`.

This proves necessity.

For sufficiency, let

`epsilon := h-(beta_0+beta_1)/2 > 0`

and choose

`s_i = -beta_i-epsilon`.

Then each shifted matrix is strictly Hurwitz and

`s_0+s_1 = -(beta_0+beta_1)-2epsilon = -2h`.

The additional inequality `h>beta_bar` makes the average strictly Hurwitz. QED.

### Consequence

Breaking scalar-shift symmetry does *not* provide extra freedom beyond the single threshold `h` plus the necessary lower bound `h>beta`. It can redistribute damping between the two modes, but it cannot lower the all-Hurwitz threshold below `beta`.

This is the precise obstruction that the earlier numerical search was implicitly imposing through its endpoint baseline.

## 4. B24 — find the extremal object: a necessary-and-sufficient contextual score

Fix traceless shapes `B_0,B_1` and three rates

`0<r_1<r_2<r_3`.

Define the all-Hurwitz three-rate score

`S_H(B_0,B_1;r_1,r_2,r_3)`

`:= min(F(r_1),F(r_3)) - max(F(r_2), beta)`,

where

`beta=max((beta_0+beta_1)/2,beta_bar)`.

### Theorem 4.1 — exact contextual witness criterion

There exist scalar shifts `s_0,s_1` such that

- `A_0=B_0+s_0I` is Hurwitz,
- `A_1=B_1+s_1I` is Hurwitz,
- `(A_0+A_1)/2` is Hurwitz,
- `lambda_A(r_1)>0`,
- `lambda_A(r_2)<0`,
- `lambda_A(r_3)>0`,

if and only if

`S_H(B_0,B_1;r_1,r_2,r_3)>0`.

**Proof.**

By Theorem 3.1 and `lambda_A(r)=F(r)-h`, such shifts exist exactly when one can choose a real `h` satisfying simultaneously

`h>beta`,

`h>F(r_2)`,

`h<F(r_1)`,

`h<F(r_3)`.

Such an `h` exists exactly when

`max(F(r_2),beta) < min(F(r_1),F(r_3))`,

which is precisely `S_H>0`. QED.

This gives an exact finite objective for the stronger contextual problem. It also rigorously explains the historical `e0018h.py` score: the old search was not merely adding an arbitrary endpoint condition; it was searching for a threshold above the slow/fast Hurwitz baseline.

one has exactly

Moreover

The literal construction uses `h=1/3`, and

The previous run certified three individual rates. A literal reading of “union of several intervals” is cleaner if the proof exhibits actual nondegenerate intervals directly, rather than invoking a separate continuity theorem for the Lyapunov exponent.

The same pointwise correctors already provide this stronger statement.

For a fixed corrector `phi`, mode `i`, and angle `theta`, define the lower residual

`R_i(theta;r) = a_i(theta)+b_i(theta) phi_i'(theta)`

`                 + r(phi_{1-i}(theta)-phi_i(theta)) - h`,

or the upper residual with the opposite sign. For fixed `(theta,i)`, this residual is **affine in `r`**. Hence for any `r=(1-t)r_-+t r_+`,

`R_i(theta;r)=(1-t)R_i(theta;r_-)+tR_i(theta;r_+)`.

Thus if the same signed residual is strictly positive for every projective angle at both endpoints, it is strictly positive throughout the whole rate interval.
