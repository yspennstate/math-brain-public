## 3. Obstruction first: the obvious local-drift inference is false

A tempting proof route would be

`positive speed => uniformly positive one-step drift => exponential supermartingale => (T)`.

The first implication is false even in one-dimensional i.i.d. uniformly elliptic RWRE.

Take independent site types:

- with probability `4/5`, `p_x=9/10`, `q_x=1/10`, so `rho_x=q_x/p_x=1/9`;
- with probability `1/5`, `p_x=2/5`, `q_x=3/5`, so `rho_x=3/2`.

The environment is uniformly elliptic with constant `1/10`, and

`E[rho]=(4/5)(1/9)+(1/5)(3/2)=7/18<1`.

The standard exact one-dimensional RWRE speed formula gives

`v=(1-E[rho])/(1+E[rho])=11/25>0`.

Yet every second-type site has local drift

`p_x-q_x=-1/5<0`.

This is **not** a counterexample to P0487 because the source assumes `d>=2`. It is a rigorous route obstruction: positive velocity cannot simply be replaced by a pointwise drift margin without additional genuinely global input.

## 4. B8 — discretize: an explicit finite-slab theorem under a uniform drift margin

Let

`d_omega(x)=sum_{|e|=1} omega(x,e)e`

and assume the strictly stronger source-valid hypothesis

`d_omega(x).ell >= delta>0` for every x.                     (4.1)

### Theorem 4.1

For every unit `ell'` satisfying

`|ell'-ell|<=delta/2`

and every `L>0`,

`P_omega(H_{-L}^{ell'} < H_{+L}^{ell'}) <= exp[-delta L/(2e)]`,  (4.2)

where

`H_{-L}^{ell'}=inf{n: X_n.ell'<=-L}`

and

`H_{+L}^{ell'}=inf{n: X_n.ell'>=L}`.

### Complete proof

Since `|d_omega(x)|<=1`,

`d_omega(x).ell' >= delta-|ell'-ell| >= delta/2`.

Put

`eta=delta/2`, `theta=eta/e=delta/(2e)`.

For the projected one-step increment

`Z=(X_{n+1}-X_n).ell'`

we have `|Z|<=1` and `E[Z|F_n]>=eta`. For every `z in [-1,1]`, Taylor's formula with integral remainder gives

`exp(-theta z) <= 1-theta z + theta^2 exp(theta)/2`.

Because `theta<=1/e`,

`E[exp(-theta Z)|F_n]
 <= 1-theta eta + theta^2 e/2
 = 1-theta eta/2
 <1`.

Thus

`Y_n=exp(-theta X_n.ell')`

is a nonnegative supermartingale. Stop at

`tau=H_{-L}^{ell'} wedge H_{+L}^{ell'}`.

For every N,

`E[Y_{tau wedge N}]<=1`.

On the event that the backward level is hit first by time N,

`Y_tau>=exp(theta L)`.

Therefore

`P(H_{-L}^{ell'}<H_{+L}^{ell'}, tau<=N)<=exp(-theta L)`.

Let `N->infinity`. This proves (4.2) without requiring an a priori assertion that `tau` is finite. QED.

The theorem is stronger than needed in one direction: it is quenched and does not require the environment to be random. In the uniformly elliptic i.i.d. source class it supplies exponential wrong-way slab control in a neighborhood of `ell`, i.e. the mechanism of `(T)|ell`. Guerra--Ramírez then gives `(P)_M` in the standard range.

This is a complete restricted theorem, not source closure, because positive velocity alone does not imply (4.1).

## 5. B12 — conserved quantity: the exact exponential martingale

In the homogeneous biased model, the preceding supermartingale comes from an exact harmonic function.

Take `ell=e_1` and a constant kernel with probabilities

- `p` for `+e_1`,
- `q` for `-e_1`,
- total `r=1-p-q` for transverse moves,

where `p>q>0`. Set

`rho=q/p`.

Then

`f(x)=rho^(x_1)`

is harmonic because

`p rho + q rho^(-1)+r = q+p+r=1`.

Hence

`rho^(X_n.e_1)`

is a true martingale. This is the exact conserved exponential quantity. The uniform-drift theorem deforms it into a superharmonic Lyapunov function.

The source-level missing ingredient can therefore be stated sharply: **construct a block-scale or random analogue of this exponential Lyapunov object from positive limiting velocity alone, without assuming the desired slab estimate.**

## 6. B26 — sporadic exact case: sharp homogeneous wrong-way exponent

In the same homogeneous model, let `tau` be the first time the `e_1` coordinate hits `-L` or `+L`, and let

`h_L=P_0(X_tau.e_1=-L)`.

Optional stopping gives

`1=h_L rho^(-L)+(1-h_L)rho^L`,

`boxed[ h_L = rho^L/(1+rho^L) = (q/p)^L/(1+(q/p)^L) ]`.       (6.1)
