## D. B12 — exact marked prefix conservation

Use source marks `a in {0,1}` and target marks `b in {2,3}`. Let `N_a,M_b` be horizontal sample counts and `N_ab` matched cell counts.

The whole contingency table is determined by

`k=N_02`,

with

`N_03=N_0-k`,

`N_12=M_2-k`,

`N_13=N_1-M_2+k`,

and feasible interval

`max(0,N_0+M_2-n) <= k <= min(N_0,M_2)`.

For a vertical cut `y`, define

`A_ab(y)=# cell-(a,b) edges whose source endpoint is <=y`,

`B_ab(y)=# cell-(a,b) edges whose target endpoint is <=y`,

`F_ab(y)=A_ab(y)-B_ab(y)`.

If `S_a(y),T_b(y)` are the corresponding marked empirical prefix counts, then exactly

`A_02+A_03=S_0`, `A_12+A_13=S_1`,

`B_02+B_12=T_2`, `B_03+B_13=T_3`,

so

`sum_ab F_ab = (S_0+S_1)-(T_2+T_3)`.

More importantly,

`S_0-T_2 = F_02 + A_03-B_12`,

`S_1-T_3 = F_13 + A_12-B_03`.

These are the exact marked conservation identities that the smooth tangent model compressed. Cross-horizontal assignments are not merely a nuisance: they are the control terms that can absorb type-specific prefix imbalance before the remaining discrepancy is carried as vertical flux in a diagonal cell.

In the balanced case `N_0=N_1=M_2=M_3=m`, if `r=N_03=N_12`, then

`|S_0(y)-T_2(y)-F_02(y)| <= r`

for all `y`, hence

`r >= sup_y ( |S_0(y)-T_2(y)|-|F_02(y)| )`.

This gives a clean discrete explanation for why a limiting endpoint kernel may still require `O(sqrt(n))` off-kernel edges at tangent scale.

## E. B19 — exact min-cost-flow representation and a warning against a false DP

For a fixed horizontal cell with gap `D`,

`c_D(s,t)=sqrt(D^2+(t-s)^2)`

satisfies

`partial_s partial_t c_D = -D^2/(D^2+(t-s)^2)^(3/2)<0`.

Therefore, once cell membership is fixed, the optimal matching **inside that cell** is vertically order-preserving. Every global optimum may be taken blockwise monotone.

However the full two-bin matrix is not globally Monge. An exact counterexample is

`x_1=(0,0)`, `x_2=(1,1/4)`,

`y_1=(2,1/2)`, `y_2=(2,1)`.

The vertically order-preserving cost is

`sqrt(17)/2+5/4 = 3.3115528128...`,

while crossing costs

`sqrt(5)+sqrt(17)/4 = 3.2668443839...`.

Thus I did **not** assert the tempting one-dimensional prefix recurrence; it would silently use a false global Monge property.

The exact algorithmic representation is instead the integral bipartite min-cost flow on the actual `n x n` assignment graph. To expose the horizontal selector, add penalty `theta` to every `0->2` edge and define

`Phi_n(theta)=min_sigma [ sum_i c_{i,sigma(i)} + theta N_02(sigma) ]`.

`Phi_n` is concave and piecewise affine. At differentiability points,

`Phi_n'(theta)=N_02(sigma_theta)`.

With the almost-surely unique unpenalized empirical optimum,

`Phi_n'(0)=k_n`,

so

`p_n=k_n/n=Phi_n'(0)/n`.

This is an exact sensitivity representation of the two-bin selector. Combining it with cellwise Monge structure gives an equivalent description as four interlocking selected subsequences, each matched in vertical order inside its cell.

## F. B30 — one macroscopic block is still random

I first froze the horizontal counts to the balanced surrogate: exactly `m` source samples on each of horizontal lines `0,1`, exactly `m` target samples on each of `2,3`, with four independent iid uniform vertical samples.

If `R_M^(m),R_C^(m)` are total Euclidean excesses over the matching-independent horizontal baseline, then

`R_M^(m)-R_C^(m) => Delta`,

where

`Delta=(1/2)I_+-(5/6)I_-`

and `I_+,I_-` are iid copies of

`I=int_0^1 B(u)^2 du`

for a standard Brownian bridge.

The proof is complete in the artifact. It uses the uniform quantile-process CLT and the fact that the quartic remainder in

`e_D(h)=h^2/(2D)+O(h^4)`

sums to `o_P(1)`. The resulting four-bridge quadratic form has the same nonzero eigenvalues as the previous exact Gaussian microcell, namely `1/2` and `-5/6`.

The Karhunen-Loeve expansion of `I` gives

`E[I]=1/6`, `Var(I)=1/45`,

`E[Delta]=-1/18`,

`Var(Delta)=17/810`.

Also

`P(Delta<0)>1/2`

`P(Delta>0)>0`.

So the pure monotone plan has the lower expected residual and wins more often, but **one macroscopic block has a genuinely random sign**. This eliminates a too-quick route from the expected microcell functional `J` to a pathwise selector.

## G. B30 — conditioned Brownian innovations do self-average

The important positive result appears after coarse prefix information is frozen.

Take four independent standard Brownian bridges and partition `[0,1]` into `K` equal intervals. Condition on all bridge values at the partition points and subtract linear interpolation inside each interval. The residual innovations are independent Brownian bridges on intervals of length `1/K`.

Define the innovation-only monotone and crossed quadratic residuals by the same gap weights `1/4,1/4` and `1/6,1/2` as above. If `Delta_1,...,Delta_K` are iid copies of the one-block variable, then exactly

`G_M(K)-G_C(K) =_d K^(-2) sum_{q=1}^K Delta_q`.

Therefore

`E[G_M-G_C]=-1/(18K)`,

`Var(G_M-G_C)=17/(810 K^3)`,

and

`K(G_M-G_C) -> -1/18`

in `L^2`.

This is the first rigorous homogenization mechanism seen on P0336: **once the coarse marked flux is conditioned out, the strict local Monge bias self-averages and its random fluctuation is smaller than its mean by a factor `K^(-1/2)`.**
