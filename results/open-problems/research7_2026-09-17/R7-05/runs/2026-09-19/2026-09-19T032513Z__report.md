## 3. B4 — prove something weaker, completely: separable amplitude profiles

### Theorem 1

Let `E=(epsilon_ij)` be iid centered unit-variance noise from any law covered by the Tao–Vu/Jain high-confidence shifted-iid invertibility theorem. Let

`A_ij=r_i c_j`

with deterministic factors satisfying

`0<a<=|r_i|,|c_j|<=b<infinity`.

Let `D` be any deterministic complex `n x n` matrix with `||D||<=n^C`. Then for every desired `L>0` there is a finite `B` such that

`P{s_min(D+A circ E)<=n^{-B}} <= n^{-L}`

for all large `n`.

### Proof

Write `R=diag(r_i)` and `C0=diag(c_j)`. Then exactly

`A circ E = R E C0`,

so

`D+A circ E = R [R^{-1} D C0^{-1}+E] C0`.

The transformed deterministic core satisfies

`||R^{-1}DC0^{-1}||<=a^{-2}n^C`,

and `s_min(R),s_min(C0)>=a`. The shifted-iid theorem therefore gives, for arbitrary `L`, a polynomial threshold `n^{-B0}` with failure at most `n^{-L}` for the middle factor. Since

`s_min(PMQ)>=s_min(P)s_min(M)s_min(Q)`,

we have

`s_min(D+A circ E)>=a^2 s_min(R^{-1}DC0^{-1}+E)`.

Absorb the fixed `a^2` into the exponent. QED.

This proves that constant, row-constant, column-constant, and every bounded multiplicatively rank-one amplitude profile already have the required arbitrarily high polynomial confidence. The genuine new obstruction in the discrete-Pareto reduction is therefore **non-separable entrywise modulation**, not merely non-identical variance.

## 4. B20 — find why the obvious algorithm fails

### 4.1 No independent unit-Rademacher factor for discrete Pareto

The preceding run's independent-smoothing theorem would swallow the benchmark immediately if one could write

`xi=Y+epsilon`

with `epsilon` an independent fair unit Rademacher. That is impossible for the discrete-Pareto atom, and in fact under a much weaker hypothesis.

### Proposition 2

Suppose an integer-valued `xi` has

`P(xi=0)=0`, `P(xi=2)=p_2>0`, and `P(xi=4)=p_4<p_2`.

Then there do not exist independent `Y` and fair `epsilon in {-1,+1}` with `xi=Y+epsilon`.

### Proof

Let `q_j=P(Y=j)`. From

`0=P(xi=0)=(q_{-1}+q_1)/2`

we get `q_{-1}=q_1=0`. Next,

`p_2=(q_1+q_3)/2=q_3/2`,

so `q_3=2p_2`. Then

`p_4=(q_3+q_5)/2`

forces

`q_5=2p_4-q_3=2(p_4-p_2)<0`,

a contradiction. QED.

For symmetric discrete Pareto, `p_k=c_alpha k^{-1-alpha}`, so `p_4<p_2`; the proposition applies. Thus the `{1,2}` state-dependent amplitude in the exact fair edge-flow decomposition is not merely removable by the simplest constant-amplitude independent convolution decomposition.

### 4.2 Where the iid high-confidence algorithm actually breaks

For any **fixed** vector `x`, each row

`sum_j k_ij epsilon_ij x_j`

is still an ordinary weighted Rademacher Littlewood–Offord sum. Thus basic one-row anti-concentration survives a bounded profile.

The failure occurs at the inverse/counting stage. An iid proof can classify one arithmetic object associated with `x` and reuse that structure across all rows. A non-separable profile replaces `x` in row `i` by

`K_i circ x`.

The relevant arithmetic structure is therefore row-dependent. A naive scheme assigning an inverse-Littlewood–Offord certificate independently to each possible `{1,2}` row modulation faces exponentially many modulation patterns and loses the common low-complexity object required by the high-confidence counting argument.

Theorem 1 gives the exact boundary where this problem disappears: if `K_ij=r_i c_j`, diagonal conjugation reduces all row modulations simultaneously to the same iid problem.

This is not a proof that a general bounded-profile theorem is false. It identifies the missing mechanism: a successful proof needs a **profile-stable arithmetic complexity/counting invariant**, or it must exploit randomness of the profile before conditioning.

## 5. B28 — replace `for all profiles` by `for a typical profile`

In the exact edge-flow representation, the latent variables are iid entrywise. Marginally the amplitude matrix is iid two-valued. Write

`P(K_ij=1)=p`, `P(K_ij=2)=1-p`, `p_*=max(p,1-p)<1`.

### Proposition 3 — no large monochromatic iid core

For every

`C>2/|log p_*|`,

almost surely, for all sufficiently large `n`, the profile contains no constant-amplitude `k x k` submatrix with `k>=C log n`.

### Proof

For fixed `I,J` of size `k`,

`P(K_{I,J} constant)=p^{k^2}+(1-p)^{k^2}<=2p_*^{k^2}`.

Hence

`P(exists constant k x k block)
 <= 2 binom(n,k)^2 p_*^{k^2}
 <= 2 exp(2k log(en/k)+k^2 log p_*).`

For `k=ceil(C log n)`, the `(log n)^2` coefficient is

`2C+C^2 log p_*<0`.

The failure probability is therefore `exp(-c(log n)^2)`, which is summable. Borel–Cantelli proves the claim. QED.

Thus a typical profile does not contain a linear- or polynomial-sized constant block to which the iid theorem could simply be applied.

### Proposition 4 — typical profiles are nevertheless macroscopically balanced

For every fixed `delta>0`, with probability at least `1-exp(-c n^2)`, every pair `I,J subset[n]` with `|I|,|J|>=delta n` has the empirical fraction of `K_ij=1` entries uniformly close to `p`.

For each fixed `I,J`, Chernoff gives `exp(-c_0 n^2)` failure because `|I||J|>=delta^2n^2`. There are at most `4^n=exp(O(n))` subset pairs, so a union bound still leaves `exp(-c n^2)`. QED.

The profile is therefore typically dense and quasirandom at every macroscopic scale while simultaneously lacking a large monochromatic iid core. This rules out a natural extraction algorithm and suggests that profile randomness must be used directly, rather than discarded by conditioning and then attacked by a worst-case theorem.
