# 1. Inherited bottleneck and change of method

The preceding run proved an entropy anti-selection inequality for recycled slab attempts. It showed that raising a fresh one-attempt downward-crossing probability `p_s(U)` to order one requires posterior information of order `log(1/p_s(U))`. It also proved that the naive combination

`fresh rarity + a uniform geometric retry floor`

cannot contract, because the same forced path that supplies the retry floor is itself part of the fresh success event.

The unresolved mechanism was therefore arbitrary-time recycling: a path may spend an enormous amount of time repeatedly probing already exposed regions before eventually making a wrong-way crossing.

This run uses a different object. Instead of charging *time* spent in recycled regions, construct an exact finite-horizon additive corrector from the quenched `N`-step mean velocity. This yields a quenched martingale with positive drift away from a sparse finite-range defect set. The key new point is then to **erase arbitrarily long residence times inside one connected defect component**. Only the spatial diameter of each defect-component traversal is charged.

This gives a new source-facing reduction that is insensitive to the creeping-time obstruction isolated in earlier runs.

# 2. Exact finite-horizon Poisson corrector from positive velocity

Fix a unit direction `u`. Write

`a_u := max_{|e|_1=1} |e.u| <= 1`.

Let `theta_x` be the environment shift and let the environment-seen-from-the-particle Markov operator be

`(Kf)(omega) := sum_{|e|_1=1} omega(0,e) f(theta_e omega)`.

Define the one-step directional drift

`d_u(omega) := sum_e omega(0,e) (e.u)`.

Then `|d_u|<=a_u`.

For an integer `N>=2`, define the quenched `N`-step average drift

`b_{N,u}(omega) := (1/N) sum_{j=0}^{N-1} K^j d_u(omega)`.

By the Markov property,

`boxed{ b_{N,u}(omega) = (1/N) E_{0,omega}[X_N.u]. }`                 `(2.1)`

Now define

`phi_{N,u}(omega)`

` := (1/N) sum_{j=0}^{N-2} (N-1-j) K^j d_u(omega).`                 `(2.2)`

### Lemma C04.22 — exact finite-horizon Poisson identity

For every environment,

`boxed{ d_u + K phi_{N,u} - phi_{N,u} = b_{N,u}. }`                 `(2.3)`

Moreover

`boxed{ ||phi_{N,u}||_infty <= C_N(u):=a_u(N-1)/2. }`              `(2.4)`

#### Proof

From (2.2),

`K phi = (1/N) sum_{j=1}^{N-1} (N-j) K^j d_u`.

Subtracting `phi`, the coefficient of `d_u` is `-(N-1)/N`, while every `K^j d_u`, `1<=j<=N-1`, has coefficient `1/N`. Adding `d_u` leaves exactly

`(1/N) sum_{j=0}^{N-1}K^j d_u=b_{N,u}`.

For the norm,

`|phi| <= (a_u/N) sum_{r=1}^{N-1}r = a_u(N-1)/2`.

This proves (2.3)--(2.4). `square`

### Corrected coordinate

Put

`Y_n^u := X_n.u + phi_{N,u}(theta_{X_n}omega).`

For the quenched path filtration,

`E_{0,omega}[Y_{n+1}^u-Y_n^u | F_n] = b_{N,u}(theta_{X_n}omega).`    `(2.5)`

Hence

`M_n^u := Y_n^u-Y_0^u - sum_{k=0}^{n-1}b_{N,u}(theta_{X_k}omega)`    `(2.6)`

is a quenched martingale.

Its increments obey the deterministic bound

`boxed{ |Delta M_{n+1}^u| <= R_N(u):=a_u(N+1). }`                  `(2.7)`

Indeed `|Delta Y|<=a_u+2C_N=a_u N` and `|b_{N,u}|<=a_u`.

This is an infinite-environment analogue of the old periodic Poisson/corrector mechanism, but it exists for every finite `N` with no spectral assumption.

# 3. Positive velocity makes the finite-range defect field sparse

Let `U` be a compact neighborhood of `ell` chosen so that

`c_0 := inf_{u in U} v.u > 0`.                                     `(3.1)`

The ballistic law of large numbers gives

`X_N/N -> v` almost surely and, because nearest-neighbour increments are bounded, also in `L^1(P_0)`.

Set

`eps_N := E_0[ |X_N/N-v| ] -> 0`.                                  `(3.2)`

Using (2.1) and conditional Jensen,

`sup_{u in U} E_P |b_{N,u}-v.u| <= eps_N`.                          `(3.3)`

Define

`c := c_0/2`

and the bad local-velocity set

`B_{N,u}:={omega: b_{N,u}(omega)<c}.`                               `(3.4)`

Then

`boxed{ sup_{u in U} P(B_{N,u}) <= eps_N/c -> 0. }`                 `(3.5)`

The field

`1_{B_{N,u}}(theta_x omega), x in Z^d,`

has finite dependence range: its value at `x` depends only on the environment in the `l^1` ball of radius `N-1` around `x`. Thus sites separated by more than `2(N-1)` have independent badness indicators.

Important limitation: (3.5) supplies no quantitative relation between the bad marginal and the increasing dependence radius `N`. Therefore a direct appeal to subcritical finite-range percolation would silently require a rate not furnished by the ballistic LLN. The next lemmas avoid making that unsupported step.

# 4. First source-facing consequence: any low-bad-occupation backtrack is exponentially unlikely

For a path define the bad occupation count

`B_n^{(N,u)} := sum_{k=0}^{n-1} 1_{B_{N,u}}(theta_{X_k}omega).`       `(4.1)`

Since `b_{N,u}>=c` on a good site and always `b_{N,u}>=-a_u`,

`sum_{k<n}b_{N,u}(theta_{X_k}omega)`

` >= c(n-B_n)-a_u B_n`

` = cn-(c+a_u)B_n.`                                                  `(4.2)`

Put

`eta_u := c/[2(c+a_u)]`.                                            `(4.3)`

On `{B_n<=eta_u n}` we therefore have

`sum_{k<n}b_{N,u}(theta_{X_k}omega) >= cn/2`.                       `(4.4)`

Let

`T^-_{bL}(u):=inf{n:X_n.u<=-bL}`.

At any `n` with `X_n.u<=-bL`, (2.4) gives

`Y_n^u-Y_0^u <= -bL+2C_N(u)`.                                      `(4.5)`

Combining (2.6), (4.4), and (4.5), on the event

`X_n.u<=-bL,  B_n<=eta_u n,`

we have

`M_n^u <= -(bL-2C_N)-cn/2`.                                        `(4.6)`

### Lemma C04.23 — arbitrary-time low-defect backtracking bound

For `L>2C_N/b`,

`boxed{`

`P_0( exists n>=0: X_n.u<=-bL and B_n^{(N,u)}<=eta_u n )`

` <= exp{ - [c/(2R_N(u)^2)] [bL-2C_N(u)] }.`

`}`                                                                  `(4.7)`

#### Proof

By Hoeffding's conditional lemma and (2.7), for every `lambda>0`,

`Z_n:=exp{-lambda M_n^u - lambda^2 R_N(u)^2 n/2}`

is a nonnegative supermartingale starting at one.

On (4.6),

`Z_n >= exp{ lambda(bL-2C_N)`

`             + n[lambda c/2-lambda^2R_N^2/2] }`.

Take `lambda=c/(2R_N^2)`. The coefficient of `n` is `c^2/(8R_N^2)>0`. Ville's inequality then gives (4.7). `square`

### Meaning

Earlier work had separated finite-speed wrong-way paths from arbitrarily slow creeping paths. Lemma C04.23 removes that time cutoff entirely: **at every possible hitting time**, a wrong-way displacement is exponentially unlikely unless the path has spent a fixed positive fraction of all its time at locations whose quenched `N`-step expected velocity is anomalously small.

However, bad *occupation time* is still too pessimistic because a single localized trap can hold the walk for a very long time. The next step erases this residence time.

# 5. New spatial-erasure theorem: long residence in one bad component is free

Fix `N,u,omega`. Let

`mathcal B = {x in Z^d: theta_x omega in B_{N,u}}`                  `(5.1)`

and take nearest-neighbour connected components of `mathcal B`.

For a component `C`, define its directional diameter

`diam_u(C):=sup_{x,y in C}|(x-y).u|`.                               `(5.2)`

Consider a finite path segment `X_0,...,X_n`. Partition the departure times `0,...,n-1` into maximal **bad runs** `[r_i,s_i)`: for every `k in [r_i,s_i)`, `X_k in mathcal B`, and the run is maximal. During a run all bad departure sites belong to a single bad component `C_i`; at the terminal step the walk is either still in that component or moves to a nearest-neighbour good site.

Therefore

`(X_{s_i}-X_{r_i}).u >= -diam_u(C_i)-a_u`.                          `(5.3)`

Using the corrector bound as well,

`Y_{s_i}^u-Y_{r_i}^u`

` >= -[diam_u(C_i)+a_u+2C_N(u)]`.                                  `(5.4)`

Since `a_u+2C_N(u)=a_u N`, define the spatial bad-run charge

`J_n^{(N,u)} := sum_{bad runs i before n} [diam_u(C_i)+a_u N].`     `(5.5)`

Crucially, `J_n` is **independent of the amount of time spent inside a bad component during one run**.

Let

`G_n := # {0<=k<n: X_k notin mathcal B}`                            `(5.6)`

be the number of good departure times, and define the predictably thinned martingale

`M_n^{G,u}`

` := sum_{k=0}^{n-1} 1_{X_k notin mathcal B}`

`       * [ (Y_{k+1}^u-Y_k^u)-b_{N,u}(theta_{X_k}omega) ].`         `(5.7)`

It is again a quenched martingale, now with increments zero during bad runs and bounded by `R_N(u)` otherwise.

Summing good increments and using (5.4),

`boxed{ Y_n^u-Y_0^u >= c G_n + M_n^{G,u} - J_n^{(N,u)}. }`          `(5.8)`

### Theorem C04.24 — spatial-erasure backtracking bound

For all sufficiently large `L` (for example `2C_N(u)<=bL/4`),

`boxed{`

`P_0( exists n>=0:`

`       X_n.u<=-bL and J_n^{(N,u)}<=bL/4 )`

` <= exp{ - c b L/[2R_N(u)^2] }.`

`}`                                                                  `(5.9)`

#### Proof

At a time `n` in the event, (4.5) and (5.8) give

`M_n^{G,u}`

` <= -bL+2C_N+J_n-cG_n`

` <= -bL/2-cG_n`.                                                    `(5.10)`

For `lambda>0`, conditional Hoeffding applied only on good departure times shows

`Z_n^G:=exp{-lambda M_n^{G,u}-lambda^2R_N^2G_n/2}`

is a nonnegative supermartingale. On (5.10),

`Z_n^G >= exp{lambda bL/2`

`             +G_n[lambda c-lambda^2R_N^2/2]}.`

Choose `lambda=c/R_N^2`; the coefficient of `G_n` is `c^2/(2R_N^2)>0`. Ville's inequality yields (5.9). `square`

### Why this is materially stronger than the occupation-time reduction

A path may spend `10^100` steps inside one bounded bad trap. Lemma C04.23 would count all of those steps as adverse. Theorem C04.24 charges that entire residence by only

`diam_u(C)+a_uN`.

Thus the zero-velocity slowdown mechanism identified in the origin-LDP literature no longer defeats the estimate merely by producing a huge holding time. To support a subexponential macroscopic wrong-way event, the trajectory must accumulate **linear spatial defect charge**.

# 6. Exact corridor-or-reuse dichotomy

Let `R_n^{bad}` be the number of maximal bad runs up to time `n`. From (5.5),

`J_n = sum_i diam_u(C_i) + a_uN R_n^{bad}.`                          `(6.1)`

Hence

`J_n>bL/4`

implies at least one of

`sum_i diam_u(C_i) > bL/8`,                                        `(6.2)`

or

`R_n^{bad} > bL/(8a_uN)`.                                          `(6.3)`

Combining this deterministic split with Theorem C04.24 gives

`boxed{`

`P_0(T^-_{bL}(u)<T^+_L(u))`

` <= exp(-c_{N,U,b}L)`

`    + P_0(W_L(u,b), sum_i diam_u(C_i)>bL/8)`

`    + P_0(W_L(u,b), R_{T^-_{bL}}^{bad}>bL/(8a_uN)).`

`}`                                                                  `(6.4)`

Here `W_L(u,b)={T^-_{bL}(u)<T^+_L(u)}`.

This is the new source-facing bridge.

A counterexample to the desired ballisticity condition can no longer be explained merely by:

- finite-speed backtracking;
- arbitrarily long residence in one localized trap;
- or ordinary positive-density good-site dynamics.

For every fixed large `N` for which the bad local-velocity marginal is small, the remaining wrong-way mass must use one of two mechanisms:

1. **corridor branch:** accumulate order-`L` total directional diameter through connected components of the sparse finite-range low-velocity field; or
2. **reuse branch:** make order-`L/N` separate entries into bad components.

Repeated visits to one small component are therefore isolated explicitly as a *spatial reuse* problem rather than being hidden inside arbitrary elapsed time.

# 7. Relation to the preceding entropy/recycling theorem

The previous report's entropy inequality remains complementary rather than superseded.

- The new additive corrector says a wrong-way trajectory must repeatedly exploit sites/regions at which the quenched `N`-step velocity is atypically low.
- The entropy theorem says an adaptive path cannot turn a fresh low-probability slab event into an order-one predictive event without either gathering substantial information or making many retries.

The reuse branch (6.3) is therefore the natural place to reconnect the entropy argument: repeated bad-component entries generate a sequence of adaptive local observations. The corridor branch (6.2) is the natural place to use spatial iid packing: a long total bad-component diameter should force many separated low-velocity witnesses unless the same components are recycled.

This is a cleaner division of labor than trying to make raw posterior overlap control the entire wrong-way event.

# 8. What is still missing; no false closure

The full-source implication is **not proved**.

The missing estimate is now:

`prove that the two residual probabilities in (6.4) have at least source-valid polynomial decay (degree > d-1 would already feed Guerra's theorem), uniformly for u in a neighborhood of ell.`

A tempting but invalid shortcut would be:

`P(B_{N,u}) small + finite dependence => bad clusters are automatically harmless.`

The ballistic LLN only gives `P(B_{N,u})->0` as `N->infinity`; the dependence range also grows like `N`, with no rate relating the two. A percolation domination theorem whose threshold deteriorates with the dependence range cannot simply be invoked without proving the needed relation. This rate issue is exactly analogous to the earlier failure of the naive sparse-defect argument.

Theorem C04.24 nevertheless removes the worse obstacle: *trap residence time*. Any future proof only needs spatial control of defect-component diameters and repeated component entries.

## Route A — first-entrance packing for the corridor branch

For each bad component contributing to (6.2), expose the component only at its first entrance and greedily extract witness sites whose radius-`N` dependence neighborhoods are disjoint. The target lemma is a **path-adaptive packing inequality** in which the cost is attached to first entrance into previously unexposed `N`-blocks, not to arbitrary bad sites. A successful estimate of the form

`P(total first-entrance bad diameter >= r) <= exp(-c_N r)`

for fixed `N` would immediately close the corridor branch exponentially.

## Route B — entropy charge for the reuse branch

For a fixed bad component entered many times, use the previous posterior entropy inequality on the sequence of exit/re-entry experiments. The target is an `escape-or-information` lemma:

`many re-entries into the same finite low-velocity component`

must either produce an exponentially unlikely sequence of good-region return excursions or accumulate posterior KL of order the number of effective re-entries. Because distinct slab/block environments are iid, linear KL across `Theta(L/N)` effective re-entries would force exponential annealed cost.

`P_0(W_L(u,b), J_{T^-_{bL}}^{(N,u)}>bL/4) <= L^{-m}`
