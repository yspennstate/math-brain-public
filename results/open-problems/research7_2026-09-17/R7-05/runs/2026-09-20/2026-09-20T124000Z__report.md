# 1. Inherited theorem and the remaining defect

The preceding run constructed, for every fixed horizon `N`, the finite-horizon Poisson corrector

`Phi_N(omega)=(1/N) sum_{j=0}^{N-2}(N-1-j) K^j d(omega)`

for the vector one-step drift `d(omega)=sum_e omega(0,e)e`, with

`d+K Phi_N-Phi_N = beta_N`,

where

`beta_N(omega)=(1/N)E_{0,omega}[X_N]`.

Positive velocity makes `beta_N` close to `v` in `L^1(P)`. The previous spatial-erasure theorem then showed that a wrong-way displacement is exponentially unlikely unless the path accumulates linear spatial charge from connected components where `beta_N.u` is anomalously small. However, the charge assigned an additive `O(N)` corrector penalty to **every** bad-component run. That is too crude: the dependence radius also grows like `N`, while the ballistic LLN gives no rate relating the bad marginal to `N`.

The new observation is that the deterministic linear part of `Phi_N` can be removed. The **centered** corrector is `o(N)` in `L^1(P)`. By incorporating small corrector values at the neighbours into the definition of a robust good site, every completed bad excursion has small corrector values at both endpoints. The per-run correction cost becomes `o(N)`, not `O(N)`.

This is a genuine infinite-environment improvement and does not use another periodic model.

# 2. Exact representation and an `L^1`-sublinear centered corrector

Let

`epsilon_m := E_0[ |X_m/m-v|_2 ]`.

The ballistic law of large numbers plus bounded increments gives

`epsilon_m -> 0`.                                                   `(2.1)`

The corrector has the exact vector representation

`boxed{ Phi_N(omega) = (1/N) sum_{m=1}^{N-1} E_{0,omega}[X_m]. }`    `(2.2)`

Indeed, writing

`Delta_j(omega)=K^j d(omega)=E_{0,omega}[X_{j+1}-X_j]`,

one has

`sum_{m=1}^{N-1}E_{0,omega}X_m`

` = sum_{j=0}^{N-2}(N-1-j) Delta_j`,

which is exactly `N Phi_N`.

Define the centered vector corrector

`Psi_N(omega) := Phi_N(omega)-[(N-1)/2]v`.                           `(2.3)`

The constant subtraction leaves the Poisson identity unchanged:

`boxed{ d+K Psi_N-Psi_N = beta_N. }`                                `(2.4)`

### Lemma C04.25 — rate-free `L^1` sublinearity

Set

`q_N := (1/N) E_P[|Psi_N|_2]`.

Then

`boxed{ q_N <= (1/N^2) sum_{m=1}^{N-1} m epsilon_m -> 0. }`          `(2.5)`

#### Proof

By (2.2)--(2.3),

`Psi_N=(1/N) sum_{m=1}^{N-1}`

`       [E_{0,omega}X_m-mv]`.

Conditional Jensen gives

`E_P |E_{0,omega}X_m-mv|_2`

` <= E_0 |X_m-mv|_2 = m epsilon_m`.

Therefore

`E_P|Psi_N|_2 <= (1/N)sum_{m<N}m epsilon_m`.

Divide by `N`. Since `epsilon_m ->0`, the weighted Cesaro average on the right tends to zero. `square`

There is also the deterministic bound

`boxed{ |Psi_N(omega)|_2 <= N-1 }`                                  `(2.6)`

because both `|Phi_N|` and `[(N-1)/2]|v|` are at most `(N-1)/2`.

Choose

`A_N := N sqrt(q_N)` when `q_N>0`, and `A_N:=0` when `q_N=0`.         `(2.7)`

Then

`boxed{ A_N/N ->0, }`                                                `(2.8)`

and Markov's inequality yields

`boxed{ P(|Psi_N|_2>A_N) <= sqrt(q_N) ->0. }`                        `(2.9)`

This is stronger than the old uniform `O(N)` oscillation estimate in the only rate-free sense available from the LLN: outside a set of vanishing `P`-probability, the centered corrector itself is `o(N)`.

# 3. A common robust-good field for every nearby direction

Choose a compact neighbourhood `U` of `ell` such that

`c_0 := inf_{u in U} v.u >0`.                                       `(3.1)`

The vector block drift satisfies

`E_P |beta_N-v|_2 <= epsilon_N`.                                    `(3.2)`

Define a site `x` to be **robust good at scale `N`** if both

`|beta_N(theta_x omega)-v|_2 <= c_0/4`,                             `(3.3)`

and

`|Psi_N(theta_y omega)|_2 <= A_N`

for every `y` with `|y-x|_1<=1`.                                   `(3.4)`

Let `mathcal B_N` be the complement, the robust-bad field. Importantly, this field is defined once in vector form and works simultaneously for all `u in U`.

By (2.9), (3.2), a union bound, and Markov,

`boxed{`

`p_N:=P(0 in mathcal B_N)`

` <= 4 epsilon_N/c_0 +(2d+1)sqrt(q_N) ->0.`

`}`                                                                  `(3.5)`

For every robust-good site and every `u in U`,

`beta_N(theta_x omega).u`

` >= v.u-|beta_N-v|_2`

` >= 3c_0/4.`                                                       `(3.6)`

Fix henceforth the uniform drift floor

`c:=c_0/2`.                                                         `(3.7)`

The field `mathcal B_N` remains finite-range: membership at `x` depends only on environment variables in an `O(N)` neighbourhood of `x`. No unsupported percolation step is taken from (3.5); the point of the next theorem is instead that the **cost per repeated bad run is now sublinear in that dependence radius**.

# 4. Robust endpoints reduce every completed bad-run correction cost to `o(N)`

Fix `u in U` and write

`psi_N^u(omega):=Psi_N(omega).u`.

Set

`Y_n^u:=X_n.u+psi_N^u(theta_{X_n}omega)`.                            `(4.1)`

Then

`M_n^u:=Y_n^u-Y_0^u`

`       -sum_{k=0}^{n-1} beta_N(theta_{X_k}omega).u`                 `(4.2)`

is a quenched martingale. By (2.6), its increments are bounded by

`boxed{ |Delta M_{n+1}^u| <= R_N:=2N. }`                            `(4.3)`

Now partition the bad departure times `0,...,n-1` into maximal bad runs `[r_i,s_i)`. During run `i`, all departure sites belong to one nearest-neighbour connected component `C_i` of `mathcal B_N`. Define

`diam_u(C):=sup_{x,y in C}|(x-y).u|`.                               `(4.4)`

For an **interior completed run** (`r_i>0` and `s_i<n`), maximality gives `X_{r_i-1}` robust good and `X_{s_i}` robust good. By the neighbour clause (3.4),

`|Psi_N(theta_{X_{r_i}}omega)|_2 <= A_N`,                           `(4.5)`

while robust goodness at the exit gives

`|Psi_N(theta_{X_{s_i}}omega)|_2 <= A_N`.                           `(4.6)`

Furthermore, the last bad site lies in `C_i` and the exit is one nearest-neighbour step away, so

`(X_{s_i}-X_{r_i}).u >= -diam_u(C_i)-1`.                            `(4.7)`

Hence

`boxed{`

`Y_{s_i}^u-Y_{r_i}^u`

` >= -[diam_u(C_i)+1+2A_N].`

`}`                                                                  `(4.8)`

This is the central new estimate. The old runwise correction penalty was order `N`; the new endpoint penalty is `2A_N=o(N)`.

An initial bad run and a final incomplete bad run may have one endpoint without the robust bound. There are at most two such endpoints, and (2.6) charges them by a single deterministic boundary error of at most `2(N-1)` in total.

# 5. Strengthened spatial-erasure theorem

Define the robust bad-run charge up to time `n` by

`J_n^{N,u}`

` := sum_{bad runs i before n}`

`       [diam_u(C_i)+1+2A_N].`                                     `(5.1)`

Let

`G_n^N := # {0<=k<n: X_k notin mathcal B_N}`                        `(5.2)`

and thin the martingale at robust-good departure times:

`M_n^{G,u}`

` := sum_{k=0}^{n-1} 1_{X_k notin mathcal B_N}`

`      *[(Y_{k+1}^u-Y_k^u)-beta_N(theta_{X_k}omega).u].`            `(5.3)`

The indicator is predictable, so `M_n^{G,u}` is a quenched martingale with nonzero increments bounded by `R_N=2N`.

Summing (3.6) over good departures and (4.8) over bad runs, with the two possible endpoint exceptions just noted, gives the deterministic pathwise inequality

`boxed{`

`Y_n^u-Y_0^u`

` >= c G_n^N + M_n^{G,u}-J_n^{N,u}-2(N-1).`

`}`                                                                  `(5.4)`

### Theorem C04.26 — robust-endpoint spatial erasure

For every fixed `N`, every `u in U`, every `b>0`, and all

`L >= 16(N-1)/b`,

`boxed{`

`P_0( exists n>=0:`

`       X_n.u<=-bL and J_n^{N,u}<=bL/4 )`

` <= exp{ - c b L/(2R_N^2) }`

` <= exp{ - c b L/(8N^2) }.`

`}`                                                                  `(5.5)`

#### Proof

At a time with `X_n.u<=-bL`, the deterministic corrector bound (2.6) gives

`Y_n^u-Y_0^u <= -bL+2(N-1)`.                                       `(5.6)`

Combine (5.4)--(5.6). If `J_n<=bL/4` and `4(N-1)<=bL/4`, then

`M_n^{G,u} <= -bL/2-cG_n^N`.                                       `(5.7)`

By conditional Hoeffding,

`Z_n=exp{-lambda M_n^{G,u}`

`        -(lambda^2R_N^2/2)G_n^N}`                                 `(5.8)`

is a nonnegative quenched supermartingale. On (5.7),

`Z_n >= exp{lambda bL/2`

`            +G_n^N(lambda c-lambda^2R_N^2/2)}.`

Take `lambda=c/R_N^2`. The coefficient of `G_n^N` is positive. Ville's inequality therefore gives

`P_0(event) <= exp{-lambda bL/2}`,

which is (5.5). `square`

Because a source wrong-face slab exit is contained in the event that the walk ever reaches the corresponding back level, (5.5) applies directly to the source wrong-way event after intersecting with the low-charge event.

The theorem is uniform over the required nearby directions: `mathcal B_N` itself is common to all `u in U`, `c` is common, and `R_N=2N` is direction-free.

# 6. New corridor-or-high-multiplicity dichotomy

Let `R_n^N` be the number of robust-bad runs up to time `n`. From (5.1),

`J_n^{N,u}`

` = sum_i diam_u(C_i)`

`   +R_n^N(1+2A_N).`                                                `(6.1)`

Hence on `{J_n>bL/4}` at least one of

`sum_i diam_u(C_i)>bL/8`,                                          `(6.2)`

or

`R_n^N > bL/[8(1+2A_N)]`                                           `(6.3)`

must occur.

Define

`eta_N := (1+2A_N)/N`.                                              `(6.4)`

By (2.8),

`boxed{ eta_N ->0. }`                                               `(6.5)`

Therefore (6.3) is equivalently

`boxed{`

`R_n^N > [b/(8 eta_N)] (L/N),`

`}`                                                                  `(6.6)`

and the multiplicative factor `1/eta_N` tends to infinity.

### Corollary C04.27 — scale-normalized obstruction

For every sufficiently large fixed scale `N`, except for probability `exp{-c_N L}`, a wrong-way displacement of order `L` must satisfy at least one of:

1. **corridor branch:** the sum of directional diameters of robust-bad components traversed by the path is order `L`; or
2. **high-multiplicity reuse branch:** the number of separate robust-bad runs is at least

   `[b/(8 eta_N)](L/N)`,

   where `eta_N ->0` as `N->infinity`.

Thus positive velocity forces a hypothetical subexponential wrong-way path to recycle anomalous regions at an **unbounded multiplicity per coarse spatial scale**, unless it traverses a linear bad corridor.

This is strictly sharper than the previous run's `Theta(L/N)` reuse alternative. The improvement is rate-free and comes solely from centering the finite-horizon corrector and forcing robust endpoint control.

# 7. What this does and does not solve

What is now proved:

* an exact infinite-environment finite-horizon Poisson corrector;
* an `L^1`-sublinear centered version `Psi_N` with `E|Psi_N|/N ->0`;
* a single finite-range robust-good field valid simultaneously for all nearby directions, with bad marginal `p_N->0`;
* arbitrary holding time inside one bad component is erased;
* the corrector surcharge per bad-component run is `o(N)` instead of `O(N)`;
* consequently the reuse branch requires a number of runs that is `omega(L/N)` as `N->infinity`.

What is **not** proved:

* `p_N->0` still comes without a quantitative relation to the dependence radius `N`; therefore one may not invoke a finite-range percolation theorem uniformly in `N` without extra work;
* the corridor branch (6.2) is not yet shown to have polynomial or exponential annealed tail;
* arbitrarily many re-entries into already exposed bad components remain possible in principle, and the argument above does not yet give a source-valid tail for that branch;
* therefore `(T)` and `(P)_M` are not claimed.

The fixed full-source metric remains `0 -> 0`.

Because the required number of re-entries is now `omega(L/N)`, it is enough to prove a cumulative `escape-or-information` inequality whose information charge per anomalously successful recycled entry is only `o(log(1/p_N))`; a constant-size endpoint-corrector loss is no longer being paid at every run.

**B. Corridor branch — first-entrance packing with robust endpoints.** Along a component contributing directional diameter `D`, greedily mark first-entrance points separated by more than the dependence radius. At those marks, split the environment ball into the already exposed portion and the still-fresh portion. The needed new lemma is not a generic finite-range percolation bound; it is an adaptive packing estimate showing that either a positive fraction of the marked balls retain a fixed fresh volume (allowing iid multiplication), or the path has already accumulated the high-overlap/reuse complexity treated in branch A.

This is a genuinely different next step from another periodic model or another raw marginal-percolation estimate.
