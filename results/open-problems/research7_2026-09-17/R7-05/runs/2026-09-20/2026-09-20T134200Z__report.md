# 1. Inherited result and the rate-versus-range obstruction

The preceding run centered the finite-horizon Poisson corrector and obtained a robust-bad field `B_N` satisfying

`P(0 in B_N) -> 0`

and a pathwise spatial-erasure theorem: a macroscopic wrong-way displacement is exponentially unlikely unless the trajectory accumulates linear spatial charge from robust-bad components or re-enters those components many times. The improvement there was that the corrector surcharge per bad run is `o(N)` rather than `O(N)`.

The remaining difficulty was quantitative: membership in `B_N` depends on environment in an `O(N)` region, while the ballistic LLN gives no rate forcing `P(0 in B_N)` to beat a percolation threshold that may itself deteriorate with `N`.

This run attacks exactly that mismatch. Instead of using the full `N`-ball needed by the unrestricted quenched `N`-step expectation, localize the *failure event* to a narrow tube around the deterministic ballistic ray. The tube aspect ratio is chosen first; only afterwards is `N` taken large. This permits arbitrarily strong polynomial smallness in the aspect parameter without assuming any rate of the LLN in `N`.

# 2. Functional LLN in a rate-free diagonal form

Fix a compact neighbourhood `U` of `ell` with

`c_0 := inf_{u in U} v.u > 0`.                                      `(2.1)`

Because the walk has bounded increments and `X_n/n -> v` almost surely,

`boxed{ max_{0<=j<=N} |X_j-jv|_2 / N -> 0  a.s. }`                  `(2.2)`

Indeed, for every `epsilon>0`, after a random finite index `J`,

`|X_j-jv| <= epsilon j <= epsilon N`

for all `J<=j<=N`, while the finitely many terms `j<J` divided by `N` vanish.

This elementary strengthening is important because it permits a diagonal choice with an externally prescribed error scale.

### Lemma C04.27 — arbitrarily thin ballistic tubes with arbitrarily strong polynomial annealed error

Fix any exponent `Q>0`. For every sufficiently large integer `r`, there exists an integer horizon `N_r` such that

`N_r >= r`,                                                         `(2.3)`

and, with

`A_r := { max_{0<=j<=N_r} |X_j-jv|_2 <= N_r/r },`                  `(2.4)`

one has

`boxed{ P_0(A_r^c) <= r^(-2Q). }`                                   `(2.5)`

#### Proof

For fixed `r`, (2.2) implies

`P_0(max_{j<=N}|X_j-jv|_2 > N/r) -> 0`

as `N->infinity`. Choose `N_r` so large that the probability is at most `r^(-2Q)`. No rate in `N` is used. `square`

The key point is the order of quantifiers: `r` is chosen first and `N_r` may be arbitrarily large. Thus one can demand any polynomial power in `r` without claiming any polynomial convergence rate in physical scale `N_r`.

# 3. A tube-local defect field implying positive full block drift

Fix `Q` and a pair `(r,N_r)` from Lemma C04.27. Write `N=N_r`.

Define the deterministic forward tube

`T_r := { z in Z^d : dist_2(z,{tv:0<=t<=N}) <= N/r + 2 }`.          `(3.1)`

Let

`R_r(omega) := P_{0,omega}(A_r^c)`.                                 `(3.2)`

To decide whether `A_r` fails one only needs transitions up to the first exit from the tube in (2.4). Consequently `R_r` is measurable with respect to the environment variables in `T_r` (the harmless `+2` absorbs the final nearest-neighbour exit step). In particular this is an **anisotropic local observable**: longitudinal size `O(N)` but transverse width `O(N/r)`.

By Fubini and (2.5),

`E_P R_r = P_0(A_r^c) <= r^(-2Q)`.                                 `(3.3)`

Define a site `x` to be tube-good when

`R_r(theta_x omega) <= r^(-Q)`,                                    `(3.4)`

and tube-bad otherwise. Let `D_r` denote the tube-bad set. Markov gives

`boxed{ p_r := P(0 in D_r) <= r^(-Q). }`                            `(3.5)`

This is the promised decoupling: the bad marginal can be made smaller than **any prescribed polynomial in the aspect parameter `r`**, while no convergence rate in the physical horizon `N_r` has been assumed.

Now define the true, unrestricted `N`-step quenched block drift

`beta_N^u(omega) := (1/N) E_{0,omega}[X_N.u]`.                      `(3.6)`

Although `beta_N^u` itself depends on the full `N`-ball, tube-goodness already forces it to be positive.

### Lemma C04.28 — tube-good implies uniformly positive full block drift

For all sufficiently large `r`, every tube-good site satisfies, simultaneously for all `u in U`,

`boxed{ beta_N^u(theta_x omega) >= c_0/2. }`                        `(3.7)`

#### Proof

On `A_r`,

`X_N.u >= N(v.u-1/r) >= N(c_0-1/r)`.

On `A_r^c`, nearest-neighbour bounded increments imply `X_N.u >= -N`. Hence, writing `a=r^(-Q)` and using tube-goodness,

`beta_N^u`

` >= (c_0-1/r)(1-R_r)-R_r`

` >= (c_0-1/r)(1-a)-a`.

The final expression is at least `c_0/2` for all sufficiently large `r`, uniformly in `u in U`. `square`

Thus positive velocity has produced a **genuinely infinite-environment, renormalized block drift field** whose defect event is localized to a narrow forward tube and whose marginal can be tuned in an independent aspect parameter.

# 4. Skeleton spatial erasure without any corrector

The tube field also allows a cleaner spatial-erasure argument at block times.

Fix a sufficiently large `r`, let `N=N_r`, and define the block skeleton

`Z_k := X_{kN}`.                                                     `(4.1)`

For `u in U`, write

`mu_k^u := E[(Z_{k+1}-Z_k).u | F_{kN}]`

`        = N beta_N^u(theta_{Z_k}omega)`.                           `(4.2)`

At every tube-good skeleton start, Lemma C04.28 gives

`mu_k^u >= cN`,                                                      `(4.3)`

where from now on

`c := c_0/2`.                                                        `(4.4)`

Set

`xi_k^u := (Z_{k+1}-Z_k).u-mu_k^u`.                                 `(4.5)`

Then `(xi_k^u)` are martingale differences and

`|xi_k^u| <= 2N`.                                                    `(4.6)`

Make the tube-bad set `D_r` into a graph by joining two bad sites whenever their `l^1` distance is at most `N`. Consecutive bad skeleton starts are necessarily in the same connected component of this graph because `|Z_{k+1}-Z_k|_1<=N`.

Partition the tube-bad skeleton indices before time `m` into maximal consecutive bad runs. If run `i` lies in bad component `C_i`, define

`diam_u(C_i):=sup_{x,y in C_i}|(x-y).u|`.                           `(4.7)`

Let

`G_m := #{0<=k<m: Z_k notin D_r}`,                                  `(4.8)`

and define the spatial bad-run charge

`J_m^{r,u} := sum_{bad runs i before m} [diam_u(C_i)+N]`.            `(4.9)`

A bad run can last arbitrarily many block times. Its whole net displacement is nevertheless bounded below by `-[diam_u(C_i)+N]`: all bad starts lie in `C_i`, and the endpoint after the last bad block is at `l^1` distance at most `N` from the last bad start. Therefore, if

`M_m^{G,u}:=sum_{0<=k<m, Z_k notin D_r} xi_k^u`,                    `(4.10)`

then pathwise

`boxed{ Z_m.u-Z_0.u >= cN G_m + M_m^{G,u} - J_m^{r,u}. }`           `(4.11)`

This erases arbitrarily long holding times inside a tube-bad component **without using the Poisson corrector at all**.

# 5. A stronger all-time exponential alternative retaining the number of good blocks

The preceding reports bounded wrong-way motion whenever the spatial bad charge was at most a fixed fraction of the target displacement. At block scale one can keep the positive contribution of every good block explicitly.

### Theorem C04.29 — thin-tube skeleton erasure

For fixed sufficiently large `r`, `N=N_r`, every `u in U`, every `B>0`,

`boxed{`

`P_0( exists m>=0:`

`       Z_m.u <= -B,`

`       J_m^{r,u} <= B/2 + (cN/2)G_m )`

` <= exp{ - c B/(8N) }.`

`}`                                                                  `(5.1)`

#### Proof

On the displayed event, (4.11) gives

`M_m^{G,u} <= -B/2-(cN/2)G_m`.                                     `(5.2)`

Since the selected martingale differences are bounded by `2N`, conditional Hoeffding implies that for every `lambda>0`,

`S_m:=exp{-lambda M_m^{G,u}-2lambda^2N^2G_m}`                       `(5.3)`

is a nonnegative supermartingale.

Choose

`lambda=c/(4N)`.                                                     `(5.4)`

On (5.2),

`-lambda M_m^{G,u}-2lambda^2N^2G_m`

` >= lambda B/2`

`    +G_m[lambda cN/2-2lambda^2N^2]`

` = lambda B/2`,                                                     `(5.5)`

because the bracket is zero at (5.4). Ville's inequality therefore gives

`P_0(event) <= exp{-lambda B/2}=exp{-cB/(8N)}`. `square`

For an arbitrary-time back hit, if `X_t.u<=-bL` and `m=floor(t/N)`, then

`Z_m.u<=-bL+N`.

Hence, for `bL>=2N`, any such hit forces a skeleton point below `-bL/2`. Applying (5.1) with `B=bL/2` yields

`boxed{`

`P_0( exists t>=0: X_t.u<=-bL,`

`       J_floor(t/N)^{r,u}`

`       <= bL/4 +(cN/2)G_floor(t/N) )`

` <= exp{-c bL/(16N)}.`

`}`                                                                  `(5.6)`

The source wrong-face event is a subset of the arbitrary back-hit event, so (5.6) is source-facing. It also covers the superlinear-time creeping trajectories that survive a fixed-speed large-deviation argument.

The exponent `L/N` is stronger than the `L/N^2` exponent in the preceding corrector-based erasure theorem; the tradeoff is that each repeated bad run now carries an `N` surcharge rather than the previous `o(N)` robust-corrector surcharge.

# 6. Fresh-tube testing and the exact residual selection mechanism

The localization in Section 3 provides one more exact tool that the full-ball defect field did not have.

Suppose a skeleton start `x` is reached at a stopping time and, before inspecting its tube-bad indicator, the translated dependency tube `x+T_r` is disjoint from all environment sites revealed so far. Under iid, conditional on the entire past path and revealed environment,

`boxed{ P(x in D_r | past) <= p_r <= r^(-Q). }`                     `(6.1)`

The same remains true for a predictable sequence of tests if each new tube is disjoint from the previously revealed test tubes. Consequently the bad indicators at such certified-fresh tests are stochastically dominated by Bernoulli variables of parameter `p_r`; in particular, for `delta>p_r`,

`P( at least delta K of first K certified-fresh tests are bad )`

` <= exp{-K D(delta || p_r)}`.                                      `(6.2)`

This is an adaptive statement: the test locations may depend on the past walk. The only requirement is freshness of the dependency tube at the moment the test is made.

Therefore the unresolved high-charge event in (5.6) has an exact geometric obstruction. A tube-bad skeleton start can avoid the fresh-test penalty only if its forward dependency tube intersects already revealed environment. If `R_k` denotes the set of departure sites visited before block `k`, staleness means

`(Z_k+T_r) intersect R_k != empty`.                                 `(6.3)`

Equivalently, there are `s<kN` and `0<=t<=N` such that

`|X_s-(Z_k+tv)|_2 <= N/r+2`.                                       `(6.4)`

Thus repeated selected bad blocks must produce **oriented self-overlap at transverse scale `N/r`**, unless the path keeps discovering fresh narrow tubes and pays the Bernoulli large-deviation cost (6.2).

This is considerably sharper than the earlier generic radius-`N` recycling statistic: (6.4) records overlap specifically with a ballistic forward tube, and the aspect parameter can be taken arbitrarily large while retaining an arbitrarily small polynomial fresh-bad probability.

# 7. What changed and what remains

## New proved partial statements

1. **Rate-free thin-tube diagonalization.** For any polynomial power `Q`, one can choose aspect parameter `r` first and then a horizon `N_r` so that leaving the `N_r/r` ballistic tube before time `N_r` has annealed probability at most `r^(-2Q)`.

2. **Localized positive block drift.** The tube-failure observable is supported on an anisotropic tube of length `O(N_r)` and width `O(N_r/r)`. Its tube-bad marginal is at most `r^(-Q)`, while tube-goodness forces the *full unrestricted* quenched `N_r`-step drift to be at least `c_0/2` in every nearby source direction.

3. **Block-scale spatial erasure.** At `N_r`-step skeleton times, arbitrary residence time inside a connected bad component is erased exactly. The all-time exponential alternative (5.1) retains the number of good blocks and has exponent `exp{-cB/(8N_r)}`.

4. **Fresh-tube adaptive domination.** At stopping-time starts whose narrow dependency tubes are fresh, badness has conditional probability at most `r^(-Q)`; many bad fresh tests obey an ordinary Bernoulli Chernoff bound despite adaptive test locations.

These statements provide a genuine iid infinite-environment / renormalized-block counterpart to the old finite-periodic corrector mechanism.

## Remaining gap

The full source implication is **not** proved. To close it one still needs to control the high spatial-charge side of (5.6). The remaining trajectories must organize either

- a long corridor of tube-bad components, or
- many re-entries into such components,

and, by Section 6, must do so either through many certified-fresh bad tubes (which is exponentially costly in the number of fresh tests) or through extensive oriented tube overlap of the form (6.4).

The current proof does **not** yet convert oriented overlap into the source-valid polynomial wrong-way tail, nor into Guerra's finite seed `(W_{c,M})`. In particular, no claim is made that the tube-bad field is subcritical merely from `p_r<=r^(-Q)`; an adaptive path can revisit already exposed tubes many times.

## Next attack

The next useful lemma is now precise: prove an **oriented packing-versus-overlap inequality** for the skeleton bad-run entry tubes. Given `K` bad-run entries before a wrong-way displacement, either extract `theta(K)` certified-fresh pairwise-disjoint forward tubes (to which (6.2) applies), or prove a lower bound `Omega(KN/r)` on an oriented self-intersection/local-time functional generated by (6.4). The latter should then be charged using the earlier posterior-relative-entropy identity rather than the exponentially wasteful `kappa^{-overlap}` bound.

That is a different method from another finite-periodic model and directly targets the remaining iid spatial-selection mechanism.
