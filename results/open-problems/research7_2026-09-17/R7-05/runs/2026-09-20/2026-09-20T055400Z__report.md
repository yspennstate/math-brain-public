## New proof 1 — exact weighted-defect martingale

This run keeps the exact defect size. Put

`a=max_{|e|_1=1}|e.u|`,

`s_alpha=(1-exp(-alpha a))/(alpha a)`,

`t_alpha=(exp(alpha a)-1)/(alpha a)`.

For every environment,

`n s_alpha <= H <= n t_alpha`,

and `t_alpha/s_alpha=exp(alpha a)`. Also

`K H = H-1+Z`.

Define

`r=(K H)/H=1+(Z-1)/H`,

`c=log r`, `g=[c]_+`.

Then

`M_m = exp(-theta X_m.u) H(tau_{X_m}omega)
       exp(-sum_{k<m} c(tau_{X_k}omega))`

is an **exact quenched martingale**. This improves the preceding bad-count supermartingale because negative defects are retained as useful contraction rather than discarded.

Moreover,

`g <= (Z-1)_+/(n s_alpha) <= Z/(n s_alpha)`,

so the mesoscopic LLN contraction gives

`E_P[g] <= rho/(n s_alpha)`.                                  (1)

The deterministic maximum satisfies

`g_max <= log(1+alpha a exp(alpha a)/n)`,

hence

`n g_max <= alpha a exp(alpha a)`.                            (2)

Thus the static positive defect potential has mean order `rho/n`, while the spatial tilt itself has size `theta=alpha/n`.

## New proof 3 — exact posterior anti-selection identity

For a finite annealed path `x_0,...,x_t`, let `N_{z,e}` be the number of departures from site `z` in direction `e`. Because the environment law is the product `mu^{otimes Z^d}`, the path likelihood factors site-by-site, and conditional on the observed path the site environments remain independent with posterior density

`d mu_{N_z}/d mu (p)
 = product_e p(e)^{N_{z,e}}
   / int product_e q(e)^{N_{z,e}} mu(dq)`.

If `S` is a finite set and `N_S` is the number of prior departures from sites of `S`, uniform ellipticity gives the exact distortion bound

`E[F | path] <= kappa^{-N_S} E_P[F]`                           (4)

for every nonnegative `F` depending only on `omega|_S`.

The defect `g(tau_x omega)` depends only on the radius-`n-1` dependency set

`S_x={z:|z-x|_1<=n-1}`.

Define the prior exposure of the current dependency neighbourhood by

`E_t^(n)=sum_{k<t} 1_{ {X_k in S_{X_t}} }`.

Then

`E[g(tau_{X_t}omega) | sigma(X_0,...,X_t)]
 <= kappa^{-E_t^(n)} E_P[g]`.                                 (5)

This is a quantitative anti-selection theorem: adaptive bias can only inflate the static defect law after the walk has already accumulated substantial local environmental exposure.

## New proof 4 — wrong-way exit reduced to pure path recycling

Fix an exposure threshold `m`. Call a time light if `E_t^(n)<=m` and recycled otherwise. For a stopping time `T<=N`, the tower property and (5) give

`E[G_T^light] <= kappa^{-m} E_P[g] E[T]`.                     (6)

The heavy contribution is bounded by

`G_T^heavy <= g_max R_N^(n,m)`,

where

`R_N^(n,m)=sum_{t<N}1_{ {E_t^(n)>m} }`.

Take `N=floor(A L)`. Combining (1)--(3), Markov's inequality and (2) yields

`P_0(A_L^u)

## Failed route that teaches something

I also checked the suggested sparse-cluster/residence route. A finite-range defect field can indeed be coarse-grained to exponentially small cluster-size tails, and uniform ellipticity gives an escape chance at least `kappa^{O(D)}` from a physical cluster of diameter `D`. But for the present rate-free LLN construction the dependence range is order `n`, while the contraction parameter is obtained only as `rho roughly exp(-alpha c_U)` at some uncontrolled horizon `n=n(alpha)`. A worst-case cluster-residence proof therefore needs a relation schematically like

`-log p >> n log(1/kappa)`,

which the LLN alone does not provide because it gives no quantitative lower bound on `alpha/n`. This does not obstruct P0487; it shows why that crude cluster argument silently asks for a large-deviation rate that is not among the hypotheses. The posterior route avoids this unnecessary worst-case escape payment.
