# 1. Inherited resolvent mechanism and the precise new target

Write

`(Kf)(omega)=sum_{|e|_1=1} omega(0,e) f(tau_e omega)`,

`d(omega)=sum_e omega(0,e)e`,

and fix `lambda in (0,1/2)`, `q=1-lambda`. The inherited Abel objects are

`b_lambda=lambda sum_{j>=0} q^j K^j d`,

`phi_lambda=q sum_{j>=0} q^j K^j d`,

`Psi_lambda=phi_lambda-(q/lambda)v`.

They satisfy the exact Poisson identity

`d+K Psi_lambda-Psi_lambda=b_lambda`.                       `(1.1)`

Let `U` be a compact neighborhood of `ell` such that

`c0:=inf_{u in U} v.u>0`, and put `c:=c0/2`.               `(1.2)`

The inherited estimates are

`E_P|b_lambda-v| ->0`,                                      `(1.3)`

`lambda E_P|Psi_lambda| ->0`.                               `(1.4)`

Set

`R_lambda:=1+2q/lambda`,

`eta_lambda:=c/R_lambda^2`,

`g_lambda:=c^2/(2R_lambda^2)`.                              `(1.5)`

For `u in U`, define the positive corrector

`F_u(omega):=exp{-eta_lambda Psi_lambda(omega).u}`           `(1.6)`

and the spatial function in a fixed environment

`f_u^omega(x):=exp{-eta_lambda x.u}F_u(tau_x omega)`.        `(1.7)`

Whenever `b_lambda(tau_x omega).u>=c`, Hoeffding applied to the corrected one-step increment gives

`E_{x,omega}[f_u^omega(X_1)] <= exp{-g_lambda} f_u^omega(x)`. `(1.8)`

The 16:40 checkpoint used the global oscillation of `F_u`, which costs order `lambda` each time a path leaves and re-enters the sparse defect set. Since `g_lambda` is only order `lambda^2`, repeated local re-entry remained too expensive to erase.

The new idea is to enlarge the sparse defect field by an **amplitude defect** chosen from the centered `L^1` estimate (1.4). Outside this enlarged field, `F_u` is not merely globally near-flat: it is flat on the much smaller scale `delta_lambda=o(lambda)`. This allows maximal bad excursions to be collapsed in one step, completely erasing their residence time and reducing the per-re-entry surcharge from `O(1/lambda)` spatial units to `o(1/lambda)`.

# 2. A finite-range robust field with corrector amplitude `o(lambda)`

Define

`s_lambda:=lambda E_P|Psi_lambda| ->0`,                      `(2.1)`

`t_lambda:=sqrt(s_lambda)+lambda ->0`,                        `(2.2)`

`delta_lambda:=lambda t_lambda=o(lambda)`.                    `(2.3)`

Choose an integer `J=J(lambda)` so large that

`q^J <= min{c0/8, t_lambda^2}`.                               `(2.4)`

Define the truncated finite-range fields

`b_lambda^J:=lambda sum_{j=0}^{J-1}q^jK^jd`,                 `(2.5)`

`phi_lambda^J:=q sum_{j=0}^{J-1}q^jK^jd`,                    `(2.6)`

`Psi_lambda^J:=phi_lambda^J-(q/lambda)v`.                     `(2.7)`

They depend only on environment variables in the `J`-step reachable ball. The deterministic tails satisfy

`||b_lambda-b_lambda^J||_infty <=q^J`,                       `(2.8)`

`||Psi_lambda-Psi_lambda^J||_infty <=q^{J+1}/lambda`.        `(2.9)`

Because `eta_lambda/lambda^2` stays bounded above and below by positive constants depending only on `c` for small `lambda`, (2.4) gives

`eta_lambda ||Psi_lambda-Psi_lambda^J||_infty`

` <= C lambda q^J <= C lambda t_lambda^2=o(delta_lambda)`.   `(2.10)`

Define the amplitude defect

`A_lambda:={omega: eta_lambda |Psi_lambda^J(omega)|>delta_lambda}`. `(2.11)`

### Lemma C04.41 — sparse robust-amplitude defect

`P(A_lambda)->0`.                                             `(2.12)`

Moreover, outside `A_lambda`, for all sufficiently small `lambda`,

`eta_lambda|Psi_lambda(omega)|<=2delta_lambda`.               `(2.13)`

#### Proof

By Markov and (2.9),

`P(A_lambda)`

` <= (eta_lambda/delta_lambda)(E|Psi_lambda|+q^{J+1}/lambda)`

` = (eta_lambda/lambda^2) * (s_lambda+q^{J+1})/t_lambda`

` <= C(s_lambda/t_lambda+t_lambda)`

` <= C(sqrt(s_lambda)+t_lambda)->0`.                          `(2.14)`

Equation (2.13) follows from (2.10). `square`

For each `u in U`, define the finite-range low-drift defect

`D^0_{lambda,u}:={omega:b_lambda^J(omega).u<5c0/8}`.          `(2.15)`

If `omega in D^0`, then by (2.8),

`b_lambda.u<3c0/4`,

while `v.u>=c0`; hence

`P(D^0_{lambda,u}) <= (4/c0) E|b_lambda-v| ->0`               `(2.16)`

uniformly in `u in U`.

Now enlarge the defect by one lattice layer around the amplitude defect. In spatial notation, write

`A_lambda(omega):={x:tau_x omega in A_lambda}`

and declare

`D_{lambda,u}(omega)`

` := {x:tau_x omega in D^0_{lambda,u}}`

`    union A_lambda(omega)`

`    union {x: exists y in A_lambda(omega), |x-y|_1=1}`.      `(2.17)`

This is a finite-range stationary field with dependence radius at most `J+1`, and

`sup_{u in U}P(0 in D_{lambda,u})`

` <= sup_u P(D^0_{lambda,u}) +(2d+1)P(A_lambda)->0`.          `(2.18)`

If `x notin D_{lambda,u}`, then:

1. `b_lambda(tau_x omega).u>=c`, so the strict one-step contraction (1.8) holds at `x`;
2. `x` and **every nearest neighbor of `x`** lie outside `A_lambda`, so by (2.13)

`|log F_u(tau_y omega)|<=2delta_lambda`                       `(2.19)`

for `y=x` and for every neighbor `y` of `x`.

The one-layer thickening in (2.17) is the key device that makes the entry point of every bad excursion amplitude-controlled even though the interior of that excursion can contain arbitrarily extreme corrector values.

# 3. Trace-chain erasure of an arbitrary bad excursion

Fix `lambda`, `u`, and an environment `omega`. Let

`G:=Z^d\D_{lambda,u}(omega)`                                  `(3.1)`

be the robust-good set.

Start at `x in G`. Make one original walk step. If `X_1 in G`, set `sigma=1`. If `X_1 in D`, set

`sigma:=inf{n>=1:X_n in G}`.                                  `(3.2)`

On `{X_1 in D, sigma<infty}`, let

`y:=X_1`, `z:=X_sigma`,

`a:=[-(z-y).u]_+`.                                             `(3.3)`

Because `x in G`, the first bad point `y` cannot belong to the amplitude defect itself: otherwise `x` would lie in its one-neighbor enlargement and would not be in `G`. Thus both `y` and the exit point `z` satisfy the amplitude bound (2.19). Consequently

`F_u(tau_z omega)/F_u(tau_y omega)<=exp{4delta_lambda}`.       `(3.4)`

From (1.7),

`f_u^omega(z)/f_u^omega(y)`

` =exp{-eta_lambda(z-y).u}`

`  *F_u(tau_z omega)/F_u(tau_y omega)`

` <=exp{eta_lambda a+4delta_lambda}`.                         `(3.5)`

Crucially, neither the number of steps spent in `D`, nor the lateral diameter of the visited bad region, appears in (3.5). Only the **actual net backward displacement of the whole bad excursion** appears.

If the first step stays in `G`, give it charge zero. If it enters `D` and later exits, give the collapsed transition the charge

`C:=eta_lambda a+4delta_lambda`.                              `(3.6)`

Then (3.5) and the good-site contraction (1.8) imply

`E_{x,omega}[ exp{-C} f_u^omega(X_sigma); sigma<infty]`

` <= E_{x,omega}[f_u^omega(X_1)]`

` <=exp{-g_lambda} f_u^omega(x)`.                            `(3.7)`

This is the new bridge inequality. It is quenched and exact for every fixed environment.

# 4. A supermartingale for the robust-good trace

Iterate the construction. Let `Y_0=x in G` and let `Y_k` be successive visits of the collapsed chain to `G`, killing the trace if a bad excursion never returns to `G`. Let

`R_k:=number of collapsed bad excursions among the first k trace transitions`, `(4.1)`

and let

`A_k:=sum_{i<=R_k} a_i`                                      `(4.2)`

be their total **actual net backward displacement**, not their residence time and not the diameters of their environment-defined components.

By repeated use of (3.7),

`M_k:=exp{g_lambda k-eta_lambda A_k-4delta_lambda R_k}`

`     * f_u^omega(Y_k)`                                      `(4.3)`

is a nonnegative killed supermartingale, with `M_0=f_u^omega(x)`.

This yields the following all-trace-time bound.

### Theorem C04.42 — robust trace backtracking inequality

For every `x in G`, every `B>0`, and every fixed environment,

`P_{x,omega}( exists k>=0:`

`   Y_k.u <= x.u-B,`

`   eta_lambda A_k+4delta_lambda R_k-g_lambda k <= eta_lambda B/2 )`

` <= exp{4delta_lambda-eta_lambda B/2}.`                      `(4.4)`

#### Proof

At a trace point `Y_k in G`, (2.19) holds both at `Y_k` and `x`. Hence

`f_u^omega(Y_k)/f_u^omega(x)`

` >= exp{eta_lambda B-4delta_lambda}`                         `(4.5)`

whenever `Y_k.u<=x.u-B`.

On the event inside (4.4), (4.3)--(4.5) give

`M_k/M_0 >=exp{eta_lambda B/2-4delta_lambda}`.                 `(4.6)`

Ville's inequality for the nonnegative supermartingale proves (4.4). `square`

Dropping the favorable term `-g_lambda k` gives the simpler, weaker but very transparent consequence

`boxed{`
`P_{x,omega}( exists k:`
` Y_k.u<=x.u-B,`
` A_k+rho_lambda R_k<=B/2 )`
` <=exp{4delta_lambda-eta_lambda B/2},`
`}`                                                            `(4.7)`

where

`rho_lambda:=4delta_lambda/eta_lambda`.                       `(4.8)`

Since for small `lambda`, `eta_lambda >= c_*lambda^2`,

`rho_lambda <= C t_lambda/lambda`,                            `(4.9)`

and therefore

`boxed{ lambda rho_lambda ->0. }`                             `(4.10)`

Equivalently,

`rho_lambda=o(1/lambda)`.                                    `(4.11)`

This is the new quantitative gain over the preceding resolvent-defect argument: the natural resolvent spatial scale is `1/lambda`, but one complete leave/re-enter cycle of a defect region now costs only `o(1/lambda)` in the backtracking budget.

# 5. What has actually been erased

Theorem C04.42 is stronger than a bad-occupation estimate in three ways.

First, if the walk spends `10^100` consecutive steps inside one defect region and then exits near its entrance, that entire residence contributes **zero time charge** and essentially zero spatial charge. The proof does not see the holding time.

Second, a huge lateral excursion inside the defect region is irrelevant unless it creates net backward displacement in direction `u`.

Third, repeated use of the same learned environment is no longer charged by posterior information once per step. It is charged only once per completed leave/re-enter excursion, through `rho_lambda`, and `rho_lambda` is sub-resolvent:

`lambda rho_lambda ->0`.                                     `(5.1)`

Thus the Bernoulli-posterior obstruction from the previous run (a finite amount of information can be reused indefinitely) no longer blocks this estimate: indefinite **residence** is free, while actual repeated **boundary crossings** are counted geometrically.

The stronger version (4.4) retains the reward `g_lambda k`. Therefore robust-good trace steps actively compensate defect excursions. I have not dropped this term in the theorem; (4.7) is only a convenient corollary.

# 6. Source-facing consequence and remaining obstruction

Fix a small `lambda>0`, hence fixed `J`, `eta_lambda>0`, and a finite-range defect field with arbitrarily small marginal when `lambda` is chosen small enough.

Consider any macroscopic wrong-way path. Decompose it into maximal visits to `D_{lambda,u}` and the robust-good trace between them. For every completed bad visit record its actual net backward displacement `a_i`.

Whenever the robust-good trace itself accumulates backward displacement `B=Theta(L)`, Theorem C04.42 says that, outside an `exp{-c_lambda L}` event, one must have

`A_k+rho_lambda R_k > B/2`                                   `(6.1)`

(or the still stronger inequality retaining `g_lambda k`).

Thus, after erasing arbitrary holding times, the unresolved wrong-way mass is confined to two genuinely spatial mechanisms:

1. **bad-corridor displacement:** maximal defect visits themselves carry a linear total amount of actual backward displacement; or
2. **super-coarse re-entry:** the number of completed defect excursions is at least of order

`L/rho_lambda >= c (lambda/t_lambda)L`,                      `(6.2)`

which is larger than the natural resolvent-scale count `lambda L` by the diverging factor `1/t_lambda`.

Since `t_lambda->0`, (6.2) is an `omega(lambda L)` re-entry requirement as `lambda` is taken down the proof hierarchy.

Initial or terminal partial defect visits can be separated in the same way: if one of them alone creates a fixed fraction of the macroscopic backward displacement, it belongs to mechanism 1; otherwise the intervening robust-good trace must create a fixed fraction of the displacement, where Theorem C04.42 applies. I am **not** claiming that the rare finite-range field is already controlled strongly enough to eliminate mechanisms 1 and 2. Doing so without a quantitative relation between its marginal and its growing dependence radius is precisely the remaining iid geometry problem.

What is new is that **slowdown itself is gone** from that problem. A counterexample can no longer hide behind an arbitrarily long residence in a small trap: after trace erasure, it must produce either linear backward travel while actually inside sparse defects, or an anomalously large number of exits and re-entries.

# 7. Why this does not secretly assume the missing theorem

No percolation threshold for the defect field is used. In particular, I do not assume

`P(0 in D_{lambda,u}) * J(lambda)^d <<1`,

which positive velocity does not presently provide.

No rate of convergence in the ballistic LLN is used. The only quantitative inputs are the rate-free limits (1.3)--(1.4), after which `lambda` and then the finite truncation radius `J(lambda)` are fixed.

No independence is asserted for adaptively revisited defect components. The trace inequality is quenched and pays for actual excursions directly.

No finite-periodic approximation is used.

The result therefore genuinely advances the infinite-environment bridge while preserving the open source gap.

# 8. Next concrete attack

The next target is a **directed packing-versus-return-depth lemma for the robust defect trace**, using the stronger inequality (4.4), not the discarded bad-time occupation bound.

For mechanism 1, mark first-passage levels of each bad excursion at spacing `J(lambda)`. Either one extracts many spatially separated first discoveries of the finite-range defect field, where iid multiplication is legitimate, or a linear amount of the bad-corridor displacement occurs inside previously exposed `J`-neighborhoods. The latter produces a genuine directed return-depth functional rather than residence time.

For mechanism 2, use the fact that `R=omega(lambda L)` while a new independent `J`-block can be acquired only after spatial displacement of order `J`. If most re-entries are spatially new, first-entrance packing should give an iid cost. If most are not new, then the path must make `omega(lambda L)` returns into a bounded collection of exposed `J`-neighborhoods. The next lemma should charge the **depth of those returns**, not their duration and not posterior KL repeatedly.

A successful estimate of either form with a fixed contraction at one selected `lambda` would combine with (4.4) to produce an exponential wrong-way slab tail, hence `(T)|ell`, and therefore the source-effective `(P)_M|ell` for every standard `M>15d+5`. That final packing/return-depth estimate is not yet proved.
