# 1. Inherited theorem and the precise point improved here

The preceding run fixed an aspect parameter `r`, then chose a block horizon `N=N_r` by a rate-free diagonal LLN argument so that the event of leaving an `N/r` tube around the ballistic ray before time `N` has annealed probability at most `r^(-2Q)`. Writing `D_r` for the corresponding tube-bad field, it proved

`P(0 in D_r) <= r^(-Q)`,

while every tube-good skeleton start has quenched `N`-step drift at least

`c N`, where `c:=c_0/2` and `c_0=inf_{u in U} v.u>0`,

uniformly over a compact source-neighborhood `U` of `ell`.

For the block skeleton

`Z_k:=X_{kN}`,

the preceding spatial-erasure theorem charged a maximal bad run by the diameter of the **entire environment-defined bad component** containing that run. That is safe but unnecessarily loose: a remote branch of the bad component can make the charge huge even when the walk never traverses it.

This run first removes that looseness completely. It then combines the tube localization with the exact iid posterior factorization to show that a long *spatially distributed* bad corridor has an exponential cost unless the actual path has already performed distributed search or accumulated order-one Bayesian information in linearly many pairwise disjoint forward tubes.

# 2. Actual-span spatial erasure

Fix a sufficiently large `r`, put `N=N_r`, and fix `u in U`.

Call skeleton index `k` good when `Z_k notin D_r` and bad otherwise. Partition the bad indices before a skeleton time `m` into maximal consecutive runs

`I_i=[a_i,b_i] intersect Z`.

For run `i`, define its **actual directional span**

`d_i^u := max_{a_i<=k<=b_i} Z_k.u - min_{a_i<=k<=b_i} Z_k.u`.       `(2.1)`

Define

`G_m := #{0<=k<m: Z_k notin D_r}`                                  `(2.2)`

and the actual-run charge

`Jhat_m^u := sum_{bad runs i before m} (d_i^u+N)`.                   `(2.3)`

For a good start `Z_k`, let

`mu_k^u := E[(Z_{k+1}-Z_k).u | F_{kN}, omega] >= cN`,                `(2.4)`

and

`xi_k^u := (Z_{k+1}-Z_k).u-mu_k^u`,                                 `(2.5)`

so `|xi_k^u|<=2N`.

### Lemma C04.32 — a bad run costs only its traversed span

For every maximal bad run `[a_i,b_i]`,

`boxed{ (Z_{b_i+1}-Z_{a_i}).u >= -(d_i^u+N). }`                     `(2.6)`

#### Proof

The bad skeleton starts `Z_{a_i},...,Z_{b_i}` themselves have directional spread `d_i^u`, hence

`Z_{b_i}.u-Z_{a_i}.u >= -d_i^u`.

The final block from the last bad start has directional displacement at least `-N`, because the walk is nearest-neighbor and `u` is a unit vector. Add the two inequalities. `square`

Therefore, with

`M_m^{G,u}:=sum_{0<=k<m, Z_k notin D_r} xi_k^u`,                    `(2.7)`

one has the pathwise inequality

`boxed{ Z_m.u-Z_0.u >= cN G_m + M_m^{G,u} - Jhat_m^u. }`            `(2.8)`

This is strictly sharper than the preceding component-diameter version: `Jhat` depends only on the skeleton points the walk actually traversed.

### Theorem C04.33 — actual-span all-time erasure

For every `B>0`,

`boxed{`
`P_0( exists m>=0:`
`       Z_m.u <= -B,`
`       Jhat_m^u <= B/2 + (cN/2)G_m )`
` <= exp{-cB/(8N)}.`
`}`                                                                  `(2.9)`

#### Proof

On the displayed event, (2.8) gives

`M_m^{G,u} <= -B/2-(cN/2)G_m`.                                     `(2.10)`

Conditional Hoeffding for the selected good-block martingale implies that for every `lambda>0`,

`S_m=exp{-lambda M_m^{G,u}-2 lambda^2 N^2 G_m}`                    `(2.11)`

is a nonnegative supermartingale. Take `lambda=c/(4N)`. On (2.10),

`-lambda M_m^{G,u}-2lambda^2N^2G_m >= lambda B/2`,                 `(2.12)`

because the coefficient of `G_m` is zero. Ville's inequality gives

`P(event)<=exp{-lambda B/2}=exp{-cB/(8N)}`. `square`

Exactly as in the preceding run, an arbitrary-time hit `X_t.u<=-bL` yields a skeleton point below `-bL/2` once `bL>=2N`. Thus (2.9) is source-facing after setting `B=bL/2`.

# 3. A deterministic union-versus-reuse decomposition

For each bad run `i`, put

`a_i^u:=min_{k in I_i} Z_k.u`,

`b_i^u:=max_{k in I_i} Z_k.u`,

and define the expanded interval

`H_i^u := [a_i^u-N/2, b_i^u+N/2]`.                                 `(3.1)`

Its length is exactly

`|H_i^u|=d_i^u+N`.                                                   `(3.2)`

Let

`U_m^u := measure( union_i H_i^u )`                                 `(3.3)`

and define the directional reuse excess

`E_m^u := Jhat_m^u-U_m^u >=0`.                                     `(3.4)`

Hence

`boxed{ Jhat_m^u = U_m^u+E_m^u. }`                                 `(3.5)`

Consequently, if `Jhat_m^u>B/2`, then necessarily

`boxed{ U_m^u>B/4  or  E_m^u>B/4. }`                               `(3.6)`

The two branches have distinct meanings:

- `U_m^u>B/4`: bad runs occupy a genuinely new linear amount of directional space;
- `E_m^u>B/4`: the same directional bands are covered repeatedly by distinct bad runs, i.e. a linear spatial-reuse excess.

This separates a real bad corridor from repeated recycling of the same corridor. It does not use the size or topology of the full bad environment cluster.

# 4. Posterior factorization on a fixed realized path

The new probabilistic input is the exact iid posterior, applied to the **thin forward tubes** rather than to radius-`N` neighborhoods.

Let a finite realized path be

`gamma=(x_0,...,x_T)`.

For each site `z`, let `N_z(e)` be the number of departures from `z` in direction `e` along `gamma`, and let `mu` be the iid one-site environment law. Define the one-site posterior

`d mu_{N_z}/d mu (p)`

` = prod_e p(e)^{N_z(e)} / int prod_e q(e)^{N_z(e)} mu(dq)`.         `(4.1)`

Because the likelihood of the whole path factorizes by departure site, the conditional environment law given `gamma` is exactly

`boxed{ Pi_gamma = tensor_{z in Z^d} mu_{N_z}. }`                  `(4.2)`

This remains valid when `T` is a finite hitting time, after conditioning on the exact stopped path.

For a skeleton center `x`, let

`S_x:=x+T_r`                                                        `(4.3)`

be the deterministic dependency tube from the preceding run. Recall that the tube-bad event

`D_x:={x in D_r}`                                                    `(4.4)`

is measurable with respect to environment in `S_x`, and

`P(D_x)<=p_r<=r^(-Q)`.                                               `(4.5)`

Define the path-posterior information in that tube by

`I_gamma(x):=D( Pi_gamma|_{S_x} || P|_{S_x} )`.                     `(4.6)`

By (4.2),

`boxed{ I_gamma(x)=sum_{z in S_x} D(mu_{N_z}||mu). }`               `(4.7)`

In particular only sites actually departed from along `gamma` contribute.

Let

`q_gamma(x):=Pi_gamma(D_x)`.                                        `(4.8)`

Binary data processing for relative entropy gives

`I_gamma(x)>=d(q_gamma(x)||P(D_x))`

`           >=q_gamma(x) log(1/P(D_x))-log 2`.

Using (4.5),

`boxed{ q_gamma(x) <= [I_gamma(x)+log 2]/[Q log r]. }`              `(4.9)`

This is the key quantitative bridge: a path can make a prior `r^{-Q}` bad tube predictive only by having accumulated posterior information in that actual spatial tube.

# 5. Disjoint directional bins restore conditional independence

For sufficiently large `r` and `N`, the `u`-projection of every dependency tube `S_x` has length at most `2N`: indeed `|v.u|<=1` and the transverse tube radius is `N/r+2=o(N)`.

Partition the real line into bins

`C_j=[8Nj,8N(j+1))`, `j in Z`.                                     `(5.1)`

Bins with the same residue class modulo `3` are separated by a gap of at least `16N`. Therefore:

### Lemma C04.34 — same-color candidate tubes are disjoint

If `x.u in C_j`, `y.u in C_k`, `j=k mod 3`, and `j!=k`, then

`boxed{ S_x intersect S_y = empty. }`                               `(5.2)`

for all sufficiently large `r,N`.

Thus, conditional on a fixed path `gamma`, every collection of tube-bad events whose centers lie in distinct same-color bins is independent under `Pi_gamma`, by the product posterior (4.2).

We next connect the large-union branch in (3.6) to many active bins.

During one bad run, consecutive bad skeleton starts change their `u`-coordinate by at most `N`. Hence every point of `[a_i^u,b_i^u]` lies within distance `N` of the `u`-coordinate of an actual bad skeleton start in that run. It follows that every point of `H_i^u` lies within distance `3N/2` of an actual bad skeleton start.

Therefore a union of expanded bad-run intervals of length `U_m^u` forces at least

`boxed{ K_act >= U_m^u/(16N) }`                                    `(5.3)`

coarse bins `C_j` to contain a bad skeleton start (the constant `16` is deliberately loose). One residue class modulo `3` then contains at least

`K_col >= U_m^u/(48N)`                                              `(5.4)`

active bins.

On `U_m^u>B/4`,

`boxed{ K_col >= B/(192N). }`                                      `(5.5)`

These bins are spatially separated strongly enough that **all** candidate tubes based at skeleton starts in different selected bins are disjoint.

# 6. Low-search, low-information active bins are exponentially unlikely

Now specialize to the source wrong-face event

`W_L(u,b):={ T_{-bL}^u < T_L^u }`.                                 `(6.1)`

Before this exit, the walk's `u`-coordinate stays in a deterministic interval of length `O_b(L)` (up to one nearest-neighbor overshoot), so the number of coarse bins that can contain skeleton starts is at most

`J_L <= C_b L/N + C_b`                                              `(6.2)`

for a deterministic `C_b<infinity`.

Fix an integer search cap `A>=1` and an information threshold `a>0`.

For a realized stopped path `gamma` on `W_L(u,b)`, call a coarse bin:

- **search-heavy** if it contains more than `A` skeleton starts before the wrong exit;
- **information-heavy** if at least one of its first `A` skeleton starts `x` satisfies `I_gamma(x)>a`;
- **low-search / low-information** otherwise.

If a low-search / low-information bin is active, one of at most `A` path-determined candidate starts in that bin must be tube-bad. By (4.9), conditional on `gamma`,

`Pi_gamma(bin active)`

` <= A (a+log 2)/(Q log r)`

` =: rho.`                                                          `(6.3)`

For bins in one fixed color class, the corresponding candidate-tube unions are pairwise disjoint, so these bin-activity events are conditionally independent under `Pi_gamma`.

Choose parameters in the following legal order:

1. fix `A`;
2. choose a small constant `epsilon=epsilon(b,c)>0`;
3. choose `Q` and then `r` so large that `A log 2/(Q log r)<=epsilon`;
4. set `a:=epsilon Q log r/A`;
5. only then choose the diagonal horizon `N=N_r` from the inherited thin-tube lemma.

Then

`rho<=2epsilon`.                                                     `(6.4)`

### Theorem C04.35 — distributed bad corridors require distributed search or information

There are constants `theta=theta(b)>0` and `c_1=c_1(b,c,A,epsilon,N)>0` such that, for all sufficiently large `L`,

`P_0( W_L(u,b),`
`     U_m^u>B/4 for the skeleton time m preceding the wrong exit,`
`     fewer than theta L/N active same-color bins are search-heavy,`
`     fewer than theta L/N active same-color bins are information-heavy )`

` <= exp{-c_1 L/N}.`                                                `(6.5)`

Here `B=bL/2`, as in the arbitrary-time-to-skeleton reduction.

#### Proof

By (5.5), the large-union branch supplies `K_col>=B/(192N)=bL/(384N)` active bins in one color class. If fewer than one third of these are search-heavy and fewer than one third are information-heavy, at least

`K_low >= K_col/3 >= bL/(1152N)`                                   `(6.6)`

are active low-search / low-information bins.

Fix the realized path `gamma`. Among at most `J_L` possible same-color bins, conditional independence and (6.3) give

`Pi_gamma( at least K_low low/low bins are active )`

` <= binom(J_L,K_low) rho^{K_low}`.                                 `(6.7)`

By (6.2), the ratio `J_L/K_low` is bounded by a constant depending only on `b`. Hence

`binom(J_L,K_low) <= (e J_L/K_low)^{K_low} <= C_b'^{K_low}`.        `(6.8)`

Choose `epsilon`, and hence `rho<=2epsilon`, so that `C_b' rho<1`. Then the right side of (6.7) is at most `exp{-c K_low}`, uniformly in `gamma`. Integrating over the stopped path gives (6.5). `square`

The theorem is deliberately retrospective: `I_gamma(x)` is computed from the exact stopped path posterior. That makes (4.2) exact and avoids any unjustified independence assumption under adaptive exploration.

# 7. Combined source-facing trichotomy

Combine Theorem C04.33 with (3.6) and Theorem C04.35.

Apart from probability `exp{-cL/N}`, a source wrong-face exit must satisfy at least one of the following:

### Branch R — linear directional reuse excess

`boxed{ E_m^u > c_R L }`                                           `(7.1)`

for a fixed `c_R=c_R(b)>0`.

This means bad-run directional intervals are being traversed repeatedly; a single localized holding time does not create this charge unless it is accompanied by repeated bad-run re-entry.

### Branch S — distributed search

There are

`boxed{ Omega(L/N) }`                                               `(7.2)`

pairwise well-separated directional bins, each of which is visited by more than `A` skeleton starts before a bad start needed by the corridor is found.

Thus a hypothetical counterexample must perform **distributed creeping/search in linearly many distinct directional bands**, not merely spend a huge time in one trap.

### Branch I — distributed path-posterior information

There are

`boxed{ Omega(L/N) }`                                               `(7.3)`

pairwise separated bins containing candidate centers `x` with

`boxed{ I_gamma(x) >= a = epsilon Q log r/A. }`                     `(7.4)`

Because same-color tube supports are disjoint, these are genuinely distinct spatial information regions. Summing (4.7) over an information-heavy subcollection gives the lower bound

`boxed{`
`sum_{selected disjoint tubes S_x}`
`  sum_{z in S_x} D(mu_{N_z}||mu)`
` >= c_I (L/N) log r,`
`}`                                                                  `(7.5)`

with `c_I>0` after fixing `A,epsilon,Q`.

This is the strongest new bridge of this run. The earlier entropy argument allowed one highly recycled trap to be counted again and again. Equation (7.5) instead forces information to be spread across **linearly many disjoint forward tubes** whenever the bad corridor itself occupies linear new directional space and the path does not spend many search visits in those bins.

# 8. What this removes, and the exact remaining obstruction

The previous checkpoint left the residual event as a generic oriented self-overlap of forward tubes. The present theorem separates that residual into three much more rigid mechanisms:

1. **reuse of directional bad-run coverage** (`E_m^u` linear);
2. **distributed active search** (more than `A` skeleton visits in `Omega(L/N)` separated bands);
3. **distributed Bayesian learning** (`Omega(log r)` posterior information in `Omega(L/N)` pairwise disjoint tubes).

The low-search, low-information, spatially expanding bad corridor is now exponentially small in `L/N`.

The full source implication is still **not proved**. Positive velocity by itself has not yet been shown to rule out Branch R, S, or I at the polynomial level required by `(P)_M`. In particular, an exceptionally rare path could in principle spend enormous time learning transition biases in many separated regions. What has changed is that a single local trap, a single high-information site, or a remote branch of an environment-defined bad component can no longer masquerade as the remaining obstruction.

A useful deterministic one-site bound for the next step is

`D(mu_{N_z}||mu) <= |N_z| log(1/kappa)`,                            `(8.1)`

because the posterior likelihood ratio is at most `kappa^{-|N_z|}` under uniform ellipticity. Hence (7.5) already implies a linear lower bound on actual departures made inside the disjoint information-heavy tubes. That alone does not close the problem because time may be superlinear, but it converts Branch I into a **distributed local-time** requirement rather than an abstract posterior quantity.

# 9. Next concrete attack

The next method should target Branches R/S/I jointly with a last-departure or regeneration decomposition.

For each separated directional bin, erase all holding time before the **last departure from that bin toward the wrong side**. The desired lemma is:

> either the last-departure pieces contain a linear number of fresh lower-halfspace excursions, giving the inherited fresh-slab Chernoff cost, or the distributed local-time/information lower bound from (7.5)--(8.1) forces a linear number of spatially distinct recycled sites whose last exits are directed against the positive velocity.

The latter is a better target for a regeneration estimate than raw occupation time, because one localized trap can contribute only one last departure per directional bin. A proof with a fixed contraction per separated bin would immediately turn the present `Omega(L/N)` spatial decomposition into an exponential wrong-face bound and hence imply the source polynomial condition for every `M>15d+5`.

If that last-departure contraction fails, the failure itself should identify a source-valid countermechanism much sharper than generic slowdown.
