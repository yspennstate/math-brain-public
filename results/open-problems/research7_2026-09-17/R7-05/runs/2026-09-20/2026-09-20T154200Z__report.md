# 2. Inherited finite-horizon exponential corrector

Fix a unit direction `u` with `v.u>0`. Let

`K_{theta,u} f(omega)
 := sum_{|e|_1=1} omega(0,e) exp(-theta e.u) f(tau_e omega)`.

For an integer `n>=1` and `theta=alpha/n`, define

`H(omega):=sum_{j=0}^{n-1} K_{theta,u}^j 1(omega)`,

`Z(omega):=K_{theta,u}^n 1(omega)`.

Then the exact telescoping identity inherited from the earlier run is

`K_{theta,u} H = H + Z - 1`.                                      `(2.1)`

Put

`r(omega):=(K_{theta,u}H)(omega)/H(omega)
          =1+(Z(omega)-1)/H(omega)`.                               `(2.2)`

If

`a_u:=max_{|e|_1=1}|e.u|<=1`,

then every `j<=n` step displacement has absolute `u`-projection at most `na_u`, and hence

`n exp(-alpha a_u) <= H <= n exp(alpha a_u)`,                       `(2.3)`

`exp(-alpha a_u) <= Z <= exp(alpha a_u)`.                           `(2.4)`

Consequently

`|r-1| <= C_{alpha,u}/n`,                                          `(2.5)`

where one may take

`C_{alpha,u}=exp(alpha a_u)(exp(alpha a_u)-1)`.

Positive velocity also gives a strict **static** mean defect. Indeed, since `X_n/n -> v` almost surely and the exponential below is uniformly bounded,

`E_P Z
 = E_0 exp{-alpha (X_n/n).u}
 -> exp{-alpha v.u}<1`.                                             `(2.6)`

For a compact neighborhood `U` of `ell` with `c_0:=inf_{u in U}v.u>0`, the convergence in (2.6) is uniform in `u`: the map `u -> exp{-alpha x.u}` is uniformly Lipschitz for `|x|<=1`. Thus one can choose **one finite `n`** such that

`sup_{u in U} E_P Z_{n,u} <= q<1`.                                 `(2.7)`

By (2.1),

`E_P[ H(r-1) ] = E_P[Z-1] <= -(1-q)`.                              `(2.8)`

The hard point is that the environment process does not sample `r` according to `P`; the adaptive selection of positive defects is exactly what the later posterior-packing reports isolated.

# 3. New theorem: an exact critical defect gauge

The periodic Perron--Frobenius mechanism suggests correcting the multiplicative defect `r`. There is an exact infinite-state construction which does this at the **critical eigenvalue 1**.

Define the `H`-Doob kernel

`Khat f(omega)
 := K_{theta,u}(H f)(omega) / (K_{theta,u}H)(omega)
  = K_{theta,u}(H f)(omega)/(r(omega)H(omega))`.                    `(3.1)`

Because the denominator is `K_{theta,u}H`, `Khat 1=1`; thus `Khat` is a Markov kernel on environments.

Let `(Omega_j)_{j>=0}` denote the chain with kernel `Khat`, started from `Omega_0=omega`, and define the additive defect

`C_m:=sum_{j=0}^{m-1} log r(Omega_j)`, `C_0:=0`.                    `(3.2)`

Define the **critical defect gauge**

`G(omega)
 := Ehat_omega[ exp{ sup_{m>=0} C_m } ] in [1,infinity]`.           `(3.3)`

### Theorem C04.37 — gauge absorption lemma

On every state for which the right side of (3.3) is finite,

`boxed{ r Khat G <= G. }`                                          `(3.4)`

Consequently, with

`F:=H G`,                                                           `(3.5)`

one has the tilted superharmonic inequality

`boxed{ K_{theta,u}F <= F. }`                                      `(3.6)`

#### Proof

By the Markov property,

`r(omega) Khat G(omega)
 = Ehat_omega[ exp{ log r(Omega_0)
                    + sup_{m>=0} sum_{j=1}^{m} log r(Omega_j) } ]`

` = Ehat_omega[ exp{ sup_{m>=1} C_m } ]`

` <= Ehat_omega[ exp{ sup_{m>=0} C_m } ]
 = G(omega)`.

This proves (3.4). Multiplying by `H` and using (3.1),

`K_{theta,u}(HG)=rH Khat G <= HG`,

which is (3.6). `square`

### Snell-envelope interpretation

Equivalently one may define

`G_*(omega)=sup_tau Ehat_omega[exp(C_tau)]`,                         `(3.7)`

where the supremum is over finite stopping times of the `Khat` chain. Dynamic programming gives

`G_* = max{1, r Khat G_*}`                                          `(3.8)`

whenever the value is finite. Thus (3.3) is a convenient explicit majorant of the minimal multiplicative Snell envelope.

This is the genuinely new bridge: the old pathwise defect `sum log r` is not merely an error term. Its running positive maximum canonically generates the missing positive critical corrector.

# 4. Integrable critical gauge implies source-valid wrong-way exponential tails

The gauge need **not** be bounded. Annealed integrability is already sufficient because the finite-horizon factor `H` has a deterministic positive lower bound and `G>=1`.

### Theorem C04.38 — `L^1` critical gauge criterion

Assume, for some `theta>0`, that the gauge in (3.3) is finite on a shift-invariant full-`P` set and

`E_P[H G]<infinity`.                                                `(4.1)`

Then for every `b>0` and `L>0`,

`boxed{
P_0( Ttilde_{-bL}^u < T_L^u )
 <= [ E_P(HG) / (n exp(-alpha a_u)) ] exp(-theta bL).
}`                                                                    `(4.2)`

In particular `(T)|u` holds.

#### Proof

By (3.6), for fixed environment,

`M_m:=exp(-theta X_m.u) F(tau_{X_m}omega)`                          `(4.3)`

is a nonnegative quenched supermartingale. Let

`tau=Ttilde_{-bL}^u wedge T_L^u`.

Apply optional stopping to `tau wedge m`. On the event that the back face is hit first by time `m`,

`exp(-theta X_tau.u) >= exp(theta bL)`

and, from (2.3) and `G>=1`,

`F(tau_{X_tau}omega)>=n exp(-alpha a_u)`.

Therefore

`P_{0,omega}(Ttilde_{-bL}^u<T_L^u, tau<=m)
 <= F(omega) [n exp(-alpha a_u)]^{-1} exp(-theta bL)`.

Let `m->infinity` and then average over `P`; (4.1) yields (4.2). `square`

### Cone-uniform version

Let `U` be a compact neighborhood of `ell` with `inf_{u in U}v.u>0`. As noted in (2.7), one may choose one `alpha,n`, hence one `theta=alpha/n>0`, for every `u in U`. If in addition

`sup_{u in U} E_P[H_u G_u] < infinity`,                             `(4.4)`

then (4.2) is uniform on `U`. This is condition `(T)|ell`, hence by the established ballisticity equivalences it yields the source polynomial condition `(P)_M|ell` for every standard `M>15d+5`.

Thus P0487 has now been reduced to a concrete infinite-environment statement:

> prove `L^1(P)` finiteness, uniformly on a source neighborhood of `ell`, of the critical running-defect gauge (3.3).

This is strictly weaker than asking for a bounded Perron--Frobenius eigenfunction.

The change of measure in (3.1) is not ad hoc. For a path of environment shifts `Omega_j=tau_{X_j}omega`, its Radon--Nikodym derivative relative to the original quenched walk is

`d Phat_omega / d P_{0,omega} | F_m
 = exp(-theta X_m.u) H(Omega_m)/H(omega) * exp(-C_m)`.               `(5.1)`

The right side is exactly the normalized defect-compensated martingale constructed in the earlier run.

Also,

`Ehat_omega[ exp(C_m) ]
 = K_{theta,u}^m H(omega)/H(omega)`.                                `(5.2)`

Hence the new gauge is the maximal version of the previously isolated defect process. Equation (3.3) asks whether its *positive excursions*, under the natural tilted environment dynamics, have an integrable exponential running maximum.

# 6. New decisive obstruction: strict bounded Perron closure is impossible in the zero-rate regime

The 2026 origin-LDP result clarifies why the finite-periodic mechanism cannot be transplanted by simply seeking a globally controlled eigenfunction with eigenvalue strictly below one.

Suppose for some fixed `theta>0` there exists a positive `F` with finite essential oscillation

`R:=ess sup F / ess inf F < infinity`                               `(6.1)`

and

`K_{theta,u}F <= rho F`                                             `(6.2)`

for a fixed `rho<1`.

Iterating (6.2) gives

`E_{0,omega}[ exp(-theta X_m.u) ] <= R rho^m`.                      `(6.3)`

Therefore, for every `epsilon>0`,

`P_0( |X_m|<=epsilon m )
 <= R exp{ m(log rho + theta epsilon) }`.                           `(6.4)`

The annealed LDP lower bound in a ball around the origin and continuity of the rate function at `0` then imply

`I_a(0) >= -log rho >0`.                                            `(6.5)`

The same argument shows more generally that a family `F_m` satisfying (6.2) with the same `rho<1` cannot have subexponential oscillation `log R_m=o(m)`.

Now suppose the convex hull of the support of the one-site law contains a zero-drift kernel `p_0`; this includes the nestling and marginally nestling regimes. Varadhan's formula, restated in Drewitz--Ramirez--Saglietti--Zheng, is

`I_a(0)
 = -log inf_zeta sup_{p in K_P} sum_e exp(zeta.e) p(e)`.             `(6.6)`

For every `zeta`, Jensen's inequality and `sum_e e p_0(e)=0` give

`sum_e exp(zeta.e)p_0(e)
 >= exp{ zeta.sum_e e p_0(e) }=1`.                                 `(6.7)`

At `zeta=0` the supremum equals one. Hence

`boxed{ I_a(0)=0 }`                                                 `(6.8)`

throughout this zero-drift-convex-hull regime.

Combining (6.5) and (6.8):

`boxed{
In the nestling/marginally-nestling regime, no globally bounded
(or subexponentially oscillating) positive corrector can satisfy
K_{theta,u}F <= rho F with fixed theta>0 and fixed rho<1.
}`                                                                    `(6.9)`

This is a decisive obstruction to the naive infinite-state extension of the finite-periodic Perron--Frobenius proof.

Crucially, it does **not** obstruct the critical inequality

`K_{theta,u}F <= F`,                                                `(6.10)`

which is exactly what the new gauge constructs. A critical corrector is also exactly enough for the spatial wrong-face estimate (4.2). This identifies the correct spectral target: **eigenvalue one, not a strict global contraction**.
