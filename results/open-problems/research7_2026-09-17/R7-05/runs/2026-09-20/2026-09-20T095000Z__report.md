## 1. Inherited result and exact remaining obstruction

`c_U := inf_{u in U} v.u > 0`,

for all large `L`. Hence a failure of `(T)` must be carried by **creeping backtracks** with `T_{-bL}^u/L -> infinity` along a subsequence.

# 2. Fresh lower half-spaces at first descending levels

Fix a unit direction `u`. Put

`a(u) := max_{|e|_1=1} |e.u| <= 1`.

Choose a slab width `s>2a(u)`. Define descending first-passage times

`sigma_j := inf{ n>=0 : X_n.u <= -j s },      j=0,1,2,...`,

with `sigma_0=0`. On `{sigma_j<infinity}`, define the first return above that newly reached level

`rho_j := inf{ n>sigma_j : X_n.u > -j s }`.

Call block `j` a **fresh first-attempt descent** if

`F_j := { sigma_{j+1} < rho_j }`.

The point of this definition is exact freshness. Before `sigma_j`, no site with `x.u<=-js` has been departed from. At time `sigma_j`, the arrival site's transition probabilities have not yet been used. Until `sigma_{j+1} wedge rho_j`, every departure site lies in the strip

`S_j(u,s) := { x in Z^d : -(j+1)s < x.u <= -js }`.

The terminal arrival site at either boundary contributes no departure environment to this attempt. Thus the whole first attempt uses only environment in `S_j(u,s)`, and these strips are pairwise disjoint in `j`.

This remains true even if all earlier, higher strips have been revisited arbitrarily often.

# 3. New theorem C04.16 — adaptive fresh-slab Bernoulli domination

Assume

`X_n/n -> v` almost surely under `P_0`,

and let `U` be a compact neighborhood of `ell` satisfying

`inf_{u in U} v.u = c_U >0`.

Define the maximal backward radius over the whole cone of nearby directions

`R_U := sup_{n>=0} sup_{u in U} (-X_n.u)_+`.

Then

`boxed{ R_U < infinity  almost surely. }`                                      `(3.1)`

Indeed, almost surely `|X_n/n-v|->0`. Hence uniformly in `u in U`,

`X_n.u/n >= c_U/2`

for every sufficiently large `n`; only finitely many initial times can contribute to `R_U`.

Let

`p_s(U) := P_0( R_U >= s-1 )`.

Then

`boxed{ p_s(U) -> 0 as s->infinity. }`                                         `(3.2)`

For every `u in U`, every `j`, and the annealed exploration filtration up to `sigma_j`,

`boxed{ P_0(F_j | G_{sigma_j}) <= p_s(U) }`                                    `(3.3)`

on `{sigma_j<infinity}`.

Consequently, if

`S_k := sum_{j=0}^{k-1} 1_{F_j}`,

then for every `delta in (p_s(U),1)`,

`boxed{ P_0(S_k >= delta k) <= exp[-k D(delta || p_s(U))], }`                   `(3.4)`

where

`D(delta||p)=delta log(delta/p)+(1-delta)log((1-delta)/(1-p))`.

The bound is uniform in `u in U`.

### Proof of the conditional bound

Fix `u,j` and condition on the complete explored history up to `sigma_j`. Let

`x = X_{sigma_j}`.

Nearest-neighbor overshoot gives

`-js-a(u) <= x.u <= -js`.

Set

`delta_x := -js-x.u in [0,a(u)]`.

Translate space by `x`. Because all sites with projection at most `-js` are unvisited before the arrival at `x`, the environment used by the first attempt is an independent i.i.d. copy of the original environment in the lower strip. Under this translation, fresh success requires the translated walk to reach projection

`<= -(s-delta_x)`

before it first exceeds `delta_x`.

Discarding the upper stopping condition can only increase this probability. Since

`s-delta_x >= s-a(u) >= s-1`,

we obtain

`P_0(F_j | G_{sigma_j})`

`<= P_0( inf_{n>=0} X_n.u <= -(s-a(u)) )`

`<= P_0( R_U >= s-1 ) = p_s(U)`.

This proves (3.3).

For (3.4), the indicators are not asserted to be independent after arbitrary recycling. Independence is unnecessary. Equation (3.3) gives adaptive Bernoulli domination: for every `lambda>0`, iterating conditional expectation at the first-passage levels yields

`E exp(lambda S_k) <= (1-p_s+p_s exp(lambda))^k`.

The standard Chernoff optimization gives (3.4). `square`

### Why this is an infinite-environment result

No periodic approximation, finite-state reduction, or rate assumption appears here. The theorem uses exactly the i.i.d. spatial environment at the previously untouched lower half-space, and it remains valid after arbitrary complicated exploration above the current first-passage level.

# 4. New theorem C04.17 — a wrong-way path is exponentially unlikely unless almost every slab is recycled

Fix `b>0`, `delta in (0,1)`, and the compact neighborhood `U` above. Choose a **fixed** slab width `s=s(delta,U)` so large that

`p_s(U) < delta/2`.

For scale `L`, put

`k_L := floor(bL/s)-1`.

On the wrong-way event

`W_L(u,b):={T_{-bL}^u<T_L^u}`,

all levels `sigma_1,...,sigma_{k_L+1}` are reached before the back face. For each `j<k_L`, exactly one of the following happens before the first hit of the next deeper level:

1. `F_j`: the next lower block is reached on the first fresh attempt, without first returning above `-js`;
2. `R_j`: the path first returns above `-js`, and only later reaches the next lower level.

Call case 2 a **recycled slab crossing** and write

`N_rec(k_L):=sum_{j=0}^{k_L-1} 1_{R_j}`.

On `W_L`,

`N_rec(k_L)=k_L-S_{k_L}`.

Therefore Theorem C04.16 gives a constant `c=c(b,delta,U,s)>0` such that, uniformly for `u in U`,

`boxed{`

`P_0( W_L(u,b), N_rec(k_L) < (1-delta) k_L ) <= exp(-cL).`

`}`                                                                         `(4.1)`

### Proof

The exceptional event in (4.1) implies

`S_{k_L} > delta k_L`.

By (3.4),

`P_0(S_{k_L}>delta k_L)`

`<= exp[-k_L D(delta||p_s(U))]`.

Since `k_L >= bL/(2s)` for large `L`, this is at most `exp(-cL)` with

`c=(b/(2s))D(delta||p_s(U))>0`. `square`

### Interpretation

At every sufficiently large fixed mesoscopic width `s`, a source-relevant backtrack can avoid an exponential cost only if **almost every slab is crossed after its first fresh descent attempt has already failed and the walk has returned to the previously explored side**.

This is stronger than saying the path is slow. It says the hard mass must repeatedly convert fresh i.i.d. slabs into history-dependent, recycled slabs before continuing backward.

# 5. Combination with the previous fast-exit theorem

The previous report proved that a failure of `(T)` forces the wrong-way mass into the slow sector. Combining that theorem with (4.1) gives the following exact obstruction.

Suppose for some nearby `u` and `b>0`,

`limsup_{L->infinity} L^{-1} log P_0(W_L(u,b)) = 0`.

Then for every finite `A` and every `delta in (0,1)`, after choosing `s=s(delta,U)` as above,

`boxed{`

`limsup_{L->infinity} L^{-1} log P_0(`

` W_L(u,b),`

` T_{-bL}^u > A L,`

` N_rec(k_L) >= (1-delta) k_L`

`) = 0.`

`}`                                                                         `(5.1)`

Indeed, the complement inside `W_L` is the union of the finite-speed event from C04.14 and the insufficient-recycling event from (4.1), both exponentially small. Subtracting exponentially small mass from a subexponential subsequence leaves subexponential mass.

Thus any counterexample to the desired ballisticity implication must simultaneously be:

- **creeping:** back-hitting time divided by `L` diverges;
- **densely recycled:** at any prescribed sufficiently large fixed slab width, an arbitrarily high fraction of the descent blocks are not crossed on their first fresh attempt.

A diagonal choice of `A_m->infinity`, `delta_m->0`, and corresponding fixed widths `s_m` shows that a hypothetical counterexample admits a subsequence on which these two properties hold at every one of the first `m` prescribed scales.

This is a new multiscale structural constraint on any failure mechanism.

# 6. Why the obvious multiplicative fresh-slab proof still fails

Theorem C04.16 does **not** say the eventual block crossings are independent. It says only that their **first clean attempts** are fresh and adaptively dominated.

After a first attempt fails, the walk has exposed part of that slab. A later re-entry can select its entrance location and route using information accumulated from previous excursions. With unlimited time, repeated returns can turn a small one-attempt crossing probability into a much larger eventual crossing probability. Therefore the tempting estimate

`P(cross k lower slabs) <= p_s^k`

is false without an additional anti-recycling input.

This is precisely the missing theorem now. The finite-speed LDP controls all trajectories that perform the recycled crossings in only `O(L)` total time. The remaining source difficulty is the joint event of **dense slab recycling plus superlinear total time**.

That is a substantially narrower target than generic slowdown or generic backtracking.

# 7. Conditional closure lemma

The new reduction gives a clean sufficient theorem for finishing the source implication.

Assume that for every `b>0` there exist a compact `U` around `ell`, some `delta<1`, some fixed sufficiently large `s`, and `c_rec>0` such that

`sup_{u in U} P_0(`

` T_{-bL}^u<T_L^u,`

` N_rec(k_L) >= (1-delta)k_L`

`) <= exp(-c_rec L)`

for all large `L`.

Then (4.1) controls the complementary wrong-way paths exponentially, so

`sup_{u in U} P_0(T_{-bL}^u<T_L^u) <= exp(-cL)`.

Hence `(T)|ell` follows, and the established equivalence machinery yields the source polynomial ballisticity conclusion in the standard threshold regime.

The open task has therefore been reduced to an **anti-recycling estimate** for a positive density of mesoscopic first-passage slabs.
