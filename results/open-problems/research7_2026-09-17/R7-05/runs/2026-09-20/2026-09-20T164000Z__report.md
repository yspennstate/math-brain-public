# 1. Why change the corrector again?

The 15:42 checkpoint constructed an exact critical multiplicative gauge from the finite-horizon tilted defect. That reduction is useful, but the unresolved quantity

`E_P Ehat_omega exp{sup_m sum_{j<m} log r(Omega_j)}`

still hides which environments can generate positive defect excursions.

The present run makes that obstruction explicit. Instead of fixing one deterministic horizon `N`, use an Abel/resolvent corrector. Positive velocity then gives simultaneously:

1. an exact infinite-environment Poisson identity;
2. a centered corrector whose `L^1` size is `o(1/lambda)`;
3. a **bounded positive exponential corrector whose oscillation tends to one**;
4. strict tilted contraction away from a defect set whose `P`-marginal tends to zero;
5. an exact theorem that every wrong-way path not already exponentially unlikely must spend a fixed positive fraction of a prefix in that sparse defect set.

This is a genuine infinite-environment counterpart of the finite-periodic positive corrector. The remaining problem is no longer existence or oscillation of a positive corrector: it is adaptive occupation of its sparse defects.

# 2. Exact Abel/resolvent Poisson corrector

Let

`(Kf)(omega):=sum_{|e|_1=1} omega(0,e) f(tau_e omega)`

be the environment-seen-from-the-particle operator and let

`d(omega):=sum_e omega(0,e)e in R^d`

be the one-step quenched drift vector. Thus `|d|<=1`.

Fix `lambda in (0,1/2)` and write

`q:=1-lambda`.

Define the Abel-averaged drift and resolvent corrector

`b_lambda := lambda sum_{j>=0} q^j K^j d`,                          `(2.1)`

`phi_lambda := q sum_{j>=0} q^j K^j d`.                            `(2.2)`

Both series converge uniformly because `|d|<=1`. In particular

`||phi_lambda||_infty <= q/lambda`.                                `(2.3)`

### Lemma C04.39 — exact resolvent Poisson identity

For every environment,

`boxed{ d + K phi_lambda - phi_lambda = b_lambda. }`                `(2.4)`

#### Proof

From (2.2),

`K phi_lambda = sum_{m>=1} q^m K^m d`,

while

`phi_lambda = q d + sum_{m>=1} q^{m+1}K^m d`.

Therefore

`K phi_lambda-phi_lambda`

` = -q d + lambda sum_{m>=1}q^mK^m d`.

Adding `d` gives

`lambda d + lambda sum_{m>=1}q^mK^m d=b_lambda`.

`square`

This is an exact infinite-state corrector, not a periodic approximation.

# 3. Positive velocity controls both the Abel drift and the centered corrector

Put

`A_m(omega):=E_{0,omega}X_m`.

Since

`K^j d=A_{j+1}-A_j`,                                                `(3.1)`

summation by parts gives the two exact representations

`boxed{
 b_lambda=(lambda^2/q) sum_{m>=1} q^m A_m,
}`                                                                   `(3.2)`

and

`boxed{
 phi_lambda=lambda sum_{m>=1}q^m A_m.
}`                                                                   `(3.3)`

Let

`eps_m:=E_0 |X_m/m-v| ->0`.                                        `(3.4)`

The convergence is in `L^1` because the walk has bounded speed.

The weights

`w_m(lambda):=(lambda^2/q)m q^m`

sum to one. Hence (3.2) and conditional Jensen imply

`E_P|b_lambda-v|`

` <= (lambda^2/q) sum_{m>=1}m q^m eps_m ->0`                        `(3.5)`

as `lambda downarrow0`.

Now center the resolvent corrector by

`Psi_lambda:=phi_lambda-(q/lambda)v`.                               `(3.6)`

The constant does not alter (2.4), so

`d+K Psi_lambda-Psi_lambda=b_lambda`.                               `(3.7)`

Using (3.3) and `lambda sum_{m>=1} m q^m=q/lambda`,

`boxed{
 Psi_lambda
 =lambda sum_{m>=1}q^m(A_m-mv).
}`                                                                   `(3.8)`

Therefore

`lambda E_P|Psi_lambda|`

` <= lambda^2 sum_{m>=1}m q^m eps_m ->0`.                           `(3.9)`

The last limit is rate-free: the weights `lambda^2 m q^m` have uniformly bounded total mass and escape to infinity, while `eps_m->0`.

### Interpretation

The deterministic resolvent scale is `1/lambda`. Equation (3.9) says that after subtracting the ballistic linear part, the infinite-environment corrector has only

`boxed{ o(1/lambda) }`

size in `L^1(P)`.

This is the Abel analogue of the centered finite-horizon corrector from the 12:40 checkpoint, but it has exponentially decaying rather than hard finite-horizon memory.

# 4. A near-flat positive multiplicative corrector

Choose a compact neighborhood `U` of `ell` such that

`c_0:=inf_{u in U}v.u>0`,                                          `(4.1)`

and put

`c:=c_0/2`.                                                         `(4.2)`

For `u in U`, define the defect set

`B_{lambda,u}:={omega:b_lambda(omega).u<c}`.                        `(4.3)`

By (3.5), uniformly in `u in U`,

`boxed{
 P(B_{lambda,u})
 <= (2/c_0)E_P|b_lambda-v|
 ->0.
}`                                                                   `(4.4)`

Now define

`R_lambda:=1+2q/lambda`                                             `(4.5)`

and

`eta_lambda:=c/R_lambda^2`.                                        `(4.6)`

For each `u in U`, set

`F_{lambda,u}(omega)
 :=exp{-eta_lambda Psi_lambda(omega).u}`.                            `(4.7)`

Because the centering constant in `Psi_lambda` cancels between environments and `||phi_lambda||_infty<=q/lambda`,

`osc_omega(Psi_lambda.u)<=2q/lambda`.

Consequently

`boxed{
 esssup F_{lambda,u}/essinf F_{lambda,u}
 <= exp{2 eta_lambda q/lambda}
 ->1.
}`                                                                   `(4.8)`

Thus positive velocity has produced a genuinely positive infinite-environment corrector whose deterministic oscillation becomes arbitrarily small.

# 5. Strict tilted contraction off a sparse defect set

For one step `e`, write

`D_e(omega)
 :=e.u+[Psi_lambda(tau_e omega)-Psi_lambda(omega)].u`.               `(5.1)`

By (3.7), its quenched conditional mean is

`sum_e omega(0,e)D_e=b_lambda.u`.                                  `(5.2)`

Also

`|D_e|<=R_lambda`.                                                  `(5.3)`

Let

`K_{eta,u}f(omega)
 :=sum_e omega(0,e)e^{-eta e.u}f(tau_e omega)`.

Dividing by `F_{lambda,u}` and using (5.1),

`K_{eta_lambda,u}F_{lambda,u}/F_{lambda,u}`

` =E_{0,omega}[exp{-eta_lambda D_{X_1}}]`.                           `(5.4)`

Hoeffding's bounded-variable lemma gives

`log [K_eta F/F]`

` <= -eta_lambda b_lambda.u`

`    +eta_lambda^2 R_lambda^2/2`.                                  `(5.5)`

On `B_{lambda,u}^c`, `b_lambda.u>=c`, so, by (4.6),

`boxed{
 K_{eta_lambda,u}F_{lambda,u}
 <= exp{-g_lambda}F_{lambda,u},
}`                                                                   `(5.6)`

where

`g_lambda:=c^2/(2R_lambda^2)>0`.                                   `(5.7)`

Globally `b_lambda.u>=-1`, and hence

`boxed{
 K_{eta_lambda,u}F_{lambda,u}
 <= exp{h_lambda}F_{lambda,u},
}`                                                                   `(5.8)`

with

`h_lambda:=(c+c^2/2)/R_lambda^2`.                                  `(5.9)`

Both `g_lambda` and `h_lambda` are of order `lambda^2`, but their ratio is fixed. In particular, outside an arbitrarily sparse defect field the positive corrector is a strict tilted superharmonic function.

This is the closest infinite-environment analogue obtained so far to the old finite-periodic Perron function: the only loss is the sparse defect set.

# 6. Exact low-defect wrong-way exponential bound

Define

`s_{lambda,u}(omega)
 :=K_{eta_lambda,u}F_{lambda,u}(omega)/F_{lambda,u}(omega)`.         `(6.1)`

For a path, let

`N_m^{bad}
 :=sum_{j=0}^{m-1}1_{B_{lambda,u}}(tau_{X_j}omega)`.                `(6.2)`

From (5.6)--(5.9),

`sum_{j<m}log s_{lambda,u}(tau_{X_j}omega)`

` <= -g_lambda(m-N_m^{bad})+h_lambda N_m^{bad}`.                    `(6.3)`

Set

`beta:=g_lambda/(g_lambda+h_lambda)
      =c/[2(1+c)]`.                                                 `(6.4)`

Importantly, `beta>0` is independent of `lambda`.

If `N_m^{bad}<=beta m`, then the right side of (6.3) is nonpositive.

For fixed environment,

`L_m
 := exp{-eta_lambda X_m.u}
    * F_{lambda,u}(tau_{X_m}omega)/F_{lambda,u}(omega)
    * exp{-sum_{j<m}log s_{lambda,u}(tau_{X_j}omega)}`              `(6.5)`

is a nonnegative quenched martingale of mean one. This follows directly from the definition (6.1).

Let

`R_F(lambda):=esssup F_{lambda,u}/essinf F_{lambda,u}`.

At any time `m` with

`X_m.u<=-bL`

and

`N_m^{bad}<=beta m`,                                                `(6.6)`

(6.3)--(6.5) imply

`L_m >= exp{eta_lambda bL}/R_F(lambda)`.

Ville's inequality therefore gives the following all-time result.

### Theorem C04.40 — near-flat positive-corrector backtracking bound

For every `u in U`, `b>0`, and `L>0`,

`boxed{
P_0( exists m>=0:
      X_m.u<=-bL,
      N_m^{bad}<=beta m )
 <=R_F(lambda) exp{-eta_lambda bL}.
}`                                                                   `(6.7)`

Moreover

`R_F(lambda)->1`,                                                   `(6.8)`

while

`sup_{u in U}P(B_{lambda,u})->0`.                                  `(6.9)`

### Meaning

For every desired static defect rarity, positive velocity supplies one fixed `lambda>0` and one positive corrector with almost no oscillation such that **every arbitrary-time macroscopic wrong-way excursion is exponentially unlikely unless some prefix spends at least the fixed fraction `beta` of its time in the sparse low-resolvent-drift set**.

This is stronger structurally than merely producing an additive martingale: the finite-periodic positive eigenfunction survives in infinite volume as a near-flat positive function with sparse localized failures.

It still does not solve P0487, because sparse environment under `P` need not be sparsely occupied by an adaptively selected path.

# 7. The defect set has an explicit finite-range envelope

Although `b_lambda` is infinite-range, its dependence is exponentially quasilocal. Define

`b_lambda^{(J)}
 :=lambda sum_{j=0}^{J-1}q^jK^j d`.                                `(7.1)`

Then

`boxed{ ||b_lambda-b_lambda^{(J)}||_infty<=q^J. }`                  `(7.2)`

Choose

`J=J(lambda)`

so that

`q^J<=c_0/8`.                                                       `(7.3)`

Define the finite-range envelope

`Btilde_{lambda,u}^{(J)}
 := {omega:b_lambda^{(J)}.u<5c_0/8}`.                              `(7.4)`

Then

`B_{lambda,u} subset Btilde_{lambda,u}^{(J)}`.                      `(7.5)`

Conversely, on `Btilde`, (7.2) gives

`b_lambda.u<3c_0/4`,

so

`boxed{
P(Btilde_{lambda,u}^{(J)})
 <=(4/c_0)E_P|b_lambda-v|
 ->0.
}`                                                                   `(7.6)`

The field

`1_{Btilde_{lambda,u}^{(J)}}(tau_x omega)`

has dependence radius at most `J`, because `K^j d` only uses environment in the `j`-step reachable ball.

Thus Theorem C04.40 can be weakened, without losing validity, by replacing `B` with a **finite-range rare envelope**. If a wrong-way path is not in the exponential event (6.7), then some prefix spends at least fraction `beta` inside this finite-range rare field.

The known rate-free difficulty remains: the ballistic LLN gives no quantitative relation between the small marginal in (7.6) and the growing range `J(lambda)~lambda^{-1}`. I do not invoke a finite-range percolation theorem across that missing rate.

# 8. The transformed path remains uniformly elliptic

The positive corrector does not create a new singular dynamics. Define its Doob transition kernel

`pbar_{lambda,u}(omega,e)`

` := omega(0,e)e^{-eta_lambda e.u}`

`    *F_{lambda,u}(tau_eomega)`

`    /[s_{lambda,u}(omega)F_{lambda,u}(omega)]`.                    `(8.1)`

Uniform ellipticity of the source environment and the deterministic bounds above imply

`pbar_{lambda,u}(omega,e)`

` >= kappa exp{-eta_lambda R_lambda-h_lambda}`.                     `(8.2)`

Since

`eta_lambda R_lambda=c/R_lambda->0`

and `h_lambda->0`,

`boxed{
 inf_{omega,e,u in U}pbar_{lambda,u}(omega,e)
 >= kappa e^{-o(1)}.
}`                                                                   `(8.3)`

So the transformed walk which governs multiplicative defect excursions is itself uniformly elliptic, with ellipticity tending back to the original `kappa` as `lambda downarrow0`.

This will matter in the next spatial escape argument: repeated use of a defect component cannot be blamed on the Doob transform creating vanishing transition probabilities.

# 9. Decisive obstruction: posterior information cannot be charged once per reuse

The 14:40 posterior-information work remains useful for **newly selected** spatial regions, but it cannot by itself control arbitrarily many reuses of one learned trap. There is a simple exact Bayesian obstruction.

Let a latent Bernoulli parameter `P` equal `p_+` or `p_-` with prior probability `1/2` each, where

`0<kappa<=p_-<p_+<=1-kappa`.

Conditional on `P`, observe iid Bernoulli departures `Y_1,Y_2,...` with parameter `P`. Let `nu_k` be the posterior law of `P` after `k` observations and `nu_0` the prior.

Because the latent state has only two values,

`boxed{ D(nu_k || nu_0)<=log 2 }`                                  `(9.1)`

for **every data history and every `k`**.

However, on the history

`Y_1=...=Y_k=1`,

`nu_k(P=p_+)`

` =p_+^k/(p_+^k+p_-^k) ->1`,                                      `(9.2)`

and the posterior predictive success probability tends to `p_+`. After the type has been learned, the same order-one predictive bias can be exploited for arbitrarily many subsequent departures while the total posterior KL remains bounded by `log 2`.

Therefore no argument of the form

> every reused favorable prediction must pay a new fixed amount of posterior information

can be valid in general. This is not an RWRE counterexample; it is a proof obstruction. A finite amount of information can support indefinitely many reuses of one already learned local environment.

The high-reuse branch must therefore be charged **geometrically** (escape, component span, return depth, or a fresh-region event), not by repeatedly recharging the same posterior entropy.

This corrects the most optimistic interpretation of the earlier `escape-or-information` idea while preserving the information bound for genuinely new spatial selections.

The 15:42 checkpoint reduced the problem to integrability of a critical multiplicative gauge. The present run resolves two pieces of that abstraction.

   `esssup F/essinf F ->1`.

3. Its tilted defect is strictly negative outside a set whose `P`-marginal tends to zero.

So the missing bridge is now narrower than `find an integrable positive corrector`: **the positive corrector exists and is near-flat; what remains is a geometric occupation theorem for its rare defects.**

# 11. Remaining gap and next attack

The fixed source implication remains unproved.

A full solution would follow from a source-valid statement of the following kind for one sufficiently small fixed `lambda`:

`P_0( exists m before a wrong slab exit:
      # {j<m: tau_{X_j}omega in Btilde_{lambda,u}^{(J)}}
      >= beta m )`

having an exponential, stretched-exponential, or sufficiently high polynomial spatial tail uniformly over the source neighborhood `u in U`.

The next attack should **not** charge posterior KL once per revisit. Instead:

1. work under the uniformly elliptic Doob kernel (8.1);
2. decompose high defect occupation into maximal excursions inside connected components of the finite-range envelope `Btilde`;
3. collapse repeated residence in one component by an actual-span/exit-depth argument, reusing the spatial-erasure idea rather than occupation time;
4. only when the walk enters a genuinely new, well-separated defect component use iid/freshness or posterior selection bounds;
5. prove a deterministic packing lemma showing that a macroscopic wrong displacement with high defect occupation either accumulates linear **new component span** or makes many returns across already traversed good gaps. The latter returns should themselves contain source-oriented wrong-way segments and can be attacked recursively.

The key new advantage is that the multiplicative corrector itself now has oscillation `1+o(1)`, so no `O(N)` corrector surcharge is needed in this geometric decomposition.
