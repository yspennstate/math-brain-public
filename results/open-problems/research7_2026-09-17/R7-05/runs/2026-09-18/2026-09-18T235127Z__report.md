## B3 — move the solved boundary from polynomial to stretched-exponential scale

Set

`q_* = min(gamma,1/2)`.

### Theorem A

For every fixed `z` and every `q` with `0<q<q_*`, almost surely,

`lim_{J->infinity} limsup_{n->infinity}
 (1/n) sum_i log(1/s_i)
  1_{e^{-n^q} <= s_i < e^{-J}} = 0`.                        (3)

### Proof

The contribution from `t_n<=s_i<e^{-J}` tends to zero in the iterated limit by the dyadic layer-cake identity and (2).

For the remaining range `e^{-n^q}<=s_i<t_n`, every summand satisfies

`log(1/s_i)<=n^q`,

while the number of such singular values is at most `n F_{n,z}(t_n)`.  Hence

`0 <= (1/n) sum_i log(1/s_i)1_{e^{-n^q}<=s_i<t_n}
   <= n^q F_{n,z}(t_n)`

and (1) gives

`n^q F_{n,z}(t_n)
 <= C n^{q-gamma}
    + C n^{q-1/2}sqrt(log n)
    + C n^q exp(-n^delta) -> 0`

because `q<gamma` and `q<1/2`.  Adding the mesoscopic contribution proves (3). QED.

Define the **ultra-hard-edge defect**

`U_{n,q}(z)
 = (1/n) sum_i log(1/s_i) 1_{s_i<e^{-n^q}}`.                (4)

Theorem A shows that for any fixed `q<q_*`, the entire remaining lower-log issue is now concentrated in (4).  Thus a sufficient source-level completion is

`U_{n,q}(z) -> 0`                                           (5)

on one probability-one event for Lebesgue-a.e. `z`.  A stronger but simpler sufficient condition is

`s_min(A_n(z)) >= e^{-n^q}` eventually                       (6)

This is a real localization improvement: the proof no longer needs a polynomial floor.  Every singular value down to the much smaller stretched-exponential scale is already harmless.  Only values below `e^{-n^q}` remain.

## B14 — quantify the source's nonsummable exceptional dimensions

Let `E_n(z)` be failure of the source polynomial least-singular floor used in the preceding run.  The weak invertibility estimate supplies

`P(E_n(z)) <= C sqrt(log n/n)`                               (8)

for fixed `z`.

### Theorem B (dyadic sparsity, no independence assumed)

For every fixed `z` and every `epsilon>0`, almost surely eventually,

`#{n in [2^k,2^{k+1}):E_n(z)}
 <= C_epsilon 2^{k(1/2+epsilon)}sqrt(k)`.                    (9)

Consequently,

`#{n<=N:E_n(z)}
 = O_epsilon(N^{1/2+epsilon}sqrt(log N))`                    (10)

almost surely.

### Proof

Let

`K_k=sum_{n=2^k}^{2^{k+1}-1}1_{E_n(z)}`.

By (8),

`E K_k <= C 2^{k/2}sqrt(k)`.

Markov's inequality gives

`P(K_k>2^{k(1/2+epsilon)}sqrt(k)) <= C2^{-k epsilon}`,

which is summable in `k`.  Borel-Cantelli proves (9); summing the dyadic estimates yields (10). QED.

Thus the source's nonsummable one-dimension bound does **not** mean polynomial-floor failures can occupy a positive density of dimensions on a typical nested realization.  They are quantitatively sparse even with arbitrary cross-dimension dependence.

But this cannot finish the full sequence: one sparse exceptional dimension may contain a singular value with arbitrarily huge logarithmic depth.  The exact missing object remains `U_{n,q}` rather than the density of the exceptional set.

### What causes the `n^{-1/2}` plateau

The source Appendix-A route passes through a Berry-Esseen-type one-dimensional concentration step, which naturally leaves an `n^{-1/2}` term.  That size is genuinely attained for arithmetically structured coefficient vectors, e.g. near-equal lattice coefficients.  The vector relevant to invertibility, however, is a random normal to a random span.  Modern square invertibility proofs gain much more by showing such normals are arithmetically unstructured via LCD/RLCD-type parameters.

The fresh literature check shows why that import is not plug-and-play here: the sharp square results readily applicable from Rebrova-Tikhomirov / Livshyts-Tikhomirov-Vershynin use finite-variance or Hilbert-Schmidt second-moment budgets, whereas C0031 permits fixed `alpha<2` stable-domain laws.  Random-rounding technology weakens assumptions but its standard fixed-law consequences still do not immediately cover this infinite-variance source class at the required normalization.

Theorem A therefore identifies the source-matched arithmetic milestone: a tail-robust random-normal anti-structure estimate need only exclude singular values below `e^{-n^q}` for one `q<q_*`, or directly force `U_{n,q}->0`; it need not rebuild the mesoscopic hard edge.

## B29 — test the square boundary and the three-step analogue

### Rectangular augmentation is not a bridge

If one appends a row `r^*` to a square matrix `A`, then

`A_tilde^*A_tilde=A^*A+rr^* >= A^*A`,

hence

`s_min(A_tilde)>=s_min(A)`.                                 (11)

The direction is useless for transferring a lower bound *back* to the square matrix: the extra row can repair an almost-null square direction.  Therefore strong strict-rectangular results cannot close C0031 merely by adding rows and deleting them again.

This rules out the naive way of importing Yi Han's Lévy theorem (`N/n -> a>1`) or the Dabagia-Fernandez rectangular/almost-square estimates.

### Louvaris is a near analogue, not source closure

The fresh check of Louvaris, arXiv:2204.06399, confirms a square exact-stable least-singular theorem: for almost all stable exponents, the normalized least singular value has the Gaussian hard-edge law and is of polynomial (`N^{-1}` after stable normalization) size.  That is much stronger than the stretched-exponential floor (6).

However, the final least-singular theorem is for the unshifted exact-stable model.  C0031 requires the general stable-domain class and the shifted matrices `a_n^{-1}X_n-zI` for the Hermitization parameter `z`.  I therefore do not treat Louvaris as source-matching closure.

The useful conclusion is methodological: after Theorem A, a three-step comparison need only establish the ultra-hard-edge statement

`sum_n P(s_min(A_n(z))<e^{-n^q})<infinity`                   (12)

for some `q<q_*` and Lebesgue-a.e. fixed `z`, or directly bound (4).  Under (12), Borel-Cantelli gives (6), Theorem A supplies every remaining scale, and the source Hermitization proof closes.  This is a much narrower target than full least-singular universality.
