## 4. New source-valid subclass

Let `S={1,...,d}` be finite, and let the spatial stack state `(S_x)_{x in Z}` be a stationary irreducible aperiodic Markov chain with transition matrix `K` and stationary law `pi`:

\[
\pi K=\pi,
\qquad \pi_s>0.
\]

State `s` carries a deterministic positive elliptic stack of finite height `M`, padded with neutral cookies:

\[
\omega_s=(p_{s,1},\ldots,p_{s,M},1/2,1/2,\ldots),
\qquad \frac12\le p_{s,i}<1.
\]

Set

\[
\alpha_{s,i}=2p_{s,i}-1,
\qquad
\delta_s=\sum_{i=1}^M\alpha_{s,i},
\qquad
\bar\delta=\sum_s\pi_s\delta_s,
\]

and assume

\[
\boxed{\bar\delta>1.}
\tag{4.1}
\]

This is a genuine finite-state spatially dependent subclass of the positive stationary-ergodic transient source regime.

For each stack state define

\[
T(z)=\frac1{2-z},
\qquad
B_s(z)=\prod_{i=1}^M\big((1-\alpha_{s,i})+\alpha_{s,i}z\big).
\tag{4.2}
\]

The cumulative one-site theorem says that the forward branching law at state `s` has, whenever the current population `k>=M`, pgf

\[
P_s(k;z)=T(z)^kB_s(z).
\tag{4.3}
\]

Declare (4.3) for all `k>=0` to define an auxiliary kernel. Because all cookies here are positive and elliptic, this auxiliary kernel is itself stochastic.

On the positive-population chain killed at population zero, the true and auxiliary kernels differ only on the finite set

\[
\boxed{\mathcal B=\{(s,k):1\le k<M\}.}
\tag{4.4}
\]

In a boundary row `(s,k)`, the discrepancy can only reach population coordinates `0<=j<=M-k`. The zero population rows themselves are a separate boundary set

\[
\mathcal Z=\{(s,0):s\in\mathcal S\}.
\tag{4.5}
\]

The first version of the new artifact stated the finite-defect support without explicitly qualifying it to the killed positive-population kernel. Exact-SHA readback exposed that wording issue; the immutable erratum at commit `60d1614...` records the correction. All subsequent arguments stop at `B union Z`, so no downstream formula changes.

## 5. B1 — change category: the dependent problem is a finite matrix cocycle

Lift the spatial state into the forward chain. If the current stack state is `r`, the next stack state is `s`, and the population is `k`, define the auxiliary annealed kernel by

\[
\mathsf Q((r,k),(s,j))
=K(r,s)[z^j]\,T(z)^kB_s(z).
\tag{5.1}
\]

Let `D_B(z)=diag(B_1(z),...,B_d(z))`. For the row vector of terminal-state pgfs, an exact induction gives

\[
\boxed{
 f_n^{(r,k)}(z)
 =T^n(z)^k e_r^T
 K D_B(T^{n-1}(z))
 K D_B(T^{n-2}(z))\cdots
 K D_B(z).
}
\tag{5.2}
\]

Now use the parabolic coordinate

\[
u=(1-z)^{-1},
\qquad T^m(z)=1-\frac1{u+m},
\]

and put

\[
b_s(v)=B_s\left(1-\frac1v\right),
\qquad D(v)=\operatorname{diag}(b_s(v)).
\]

The nontrivial transfer object becomes the finite but noncommutative product

\[
\boxed{
A_n(u)=K D(u+n-1)K D(u+n-2)\cdots K D(u).
}
\tag{5.3}
\]

Thus finite-state Markov dependence is not an infinite-dimensional obstruction: it is a finite matrix cocycle.

### Exact reversal identity

Let

\[
K^*(a,b)=\frac{\pi_bK(b,a)}{\pi_a}
\]

be the stationary time reversal. If `(R_j)` is the reversed chain started at `R_0=t`, direct path reversal gives

\[
\boxed{
[A_n(u)]_{r,t}
=\frac{\pi_t}{\pi_r}
E_t^*\left[
\mathbf1_{\{R_n=r\}}
\prod_{j=0}^{n-1}b_{R_j}(u+j)
\right].
}
\tag{5.4}
\]

This converts the noncommutative cocycle into a weighted additive functional of a finite Markov chain.

## 6. B12 — conserved stationary drift and a Poisson coboundary give the exact exponent

Uniformly in the finitely many stack states,

\[
\log b_s(v)=-\frac{\delta_s}{v}+O(v^{-2}).
\tag{6.1}
\]

Write

\[
f(s)=\delta_s-\bar\delta.
\]

Since `pi f=0`, finite-state irreducibility gives the mean-zero Poisson solution

\[
\boxed{(I-K^*)g=f,\qquad \pi g=0.}
\tag{6.2}
\]

With `a_j=(u+j)^{-1}` and martingale difference

\[
D_{j+1}=g(R_{j+1})-(K^*g)(R_j),
\]

we have

\[
f(R_j)=g(R_j)-g(R_{j+1})+D_{j+1}.
\]

Summation by parts yields the exact identity

\[
\begin{aligned}
\sum_{j=0}^{n-1}a_jf(R_j)
={}&a_0g(R_0)-a_{n-1}g(R_n)\\
&+\sum_{j=1}^{n-1}(a_j-a_{j-1})g(R_j)
+\sum_{j=0}^{n-1}a_jD_{j+1}.
\end{aligned}
\tag{6.3}
\]

The first three terms converge because `g` is bounded and the coefficient variation is summable. The martingale term converges because

\[
\sum_j a_j^2<\infty,
\]

and its exponential moments are uniformly controlled by conditional Hoeffding bounds for bounded martingale differences.

For

\[
W_n(u)=\prod_{j=0}^{n-1}b_{R_j}(u+j),
\]

(6.1)--(6.3) give

\[
\log W_n(u)
=-\bar\delta\sum_{j<n}\frac1{u+j}
-\sum_{j<n}a_jf(R_j)
+O(1),
\]

with a convergent random `O(1)` term. Therefore

\[
\boxed{
n^{\bar\delta}W_n(u)\longrightarrow L_t(u)\in(0,\infty)
}
\tag{6.4}
\]

almost surely and in `L^q` for each fixed finite `q`. In particular,

\[
E_t^*W_n(u)\sim C_t(u)n^{-\bar\delta},
\qquad C_t(u)>0.
\tag{6.5}
\]

Approximating the limit by a finite path prefix and using finite-state mixing at the remote endpoint in (5.4) gives the rank-one limit

\[
\boxed{
n^{\bar\delta}[A_n(u)]_{r,t}
\longrightarrow \pi_tC_t(u),
}
\tag{6.6}
\]

or, in matrix form,

\[
n^{\bar\delta}A_n(u)\to\mathbf1v(u)^T.
\]

This proves that the same spatially averaged drift exponent governing the periodic scalar product survives genuine stochastic Markov dependence.

## 7. Low-state Green kernel: the missing potential estimate is now proved for this class

For every fixed derivative order `m>=1`, finite depth and ellipticity imply

\[
\left|\frac{d^m}{dv^m}\log b_s(v)\right|
\le C_m v^{-m-1}.
\tag{7.1}
\]

Consequently fixed `u`-derivatives of `W_n` are bounded by a constant times `W_n`, and the same is true entrywise for the transfer product. Passing back through `u=(1-z)^{-1}` and extracting any fixed coefficient gives

\[
\boxed{
\mathsf Q^n((r,k),(t,j))=O(n^{-\bar\delta})
}
\tag{7.2}
\]

for every fixed start and fixed finite-population target. Since `bar(delta)>1`,

\[
\boxed{
G(x,y)=\sum_{n\ge0}\mathsf Q^n(x,y)<\infty
}
\tag{7.3}
\]

for every fixed low-state target `y`.

This is exactly the potential-kernel input that the preceding spatial-periodic report identified as missing for a finite-state Markov extension.

## 8. B28 — typical environments: dependence changes the prefactor, not the power

The proof of (6.4) is pathwise under the stationary reversed Markov environment. Thus for almost every such environment trajectory,

\[
\boxed{
 n^{\bar\delta}
\prod_{j=0}^{n-1}
B_{R_j}\left(1-\frac1{u+j}\right)
\longrightarrow L(u,R)\in(0,\infty).
}
\tag{8.1}

The exponent is therefore a typical-environment statement, not merely an annealed cancellation. Markov dependence appears in the random multiplicative prefactor; it does not change the critical power `bar(delta)`.

The spatial-periodic theorem is recovered as the special case where the environment trajectory is deterministic up to a finite phase.

## 9. Exact finite escape formula, with no hidden uniqueness lemma

Let

\[
\mathcal A=\mathcal B\cup\mathcal Z.
\]

The low-state Green estimate makes the finite block `G_AA` entrywise finite. First-return decomposition on this finite transient set gives an invertible block, and for `x notin A` the exact first-entrance vector is

\[
\boxed{H_A(x,\cdot)=G_{xA}G_{AA}^{-1}.}
\tag{9.1}
\]

For `b in B`, define `H(x,b)` as the probability for the auxiliary chain to first enter `A` through `b`, with the natural boundary values `H(b,b)=1` and `H(z,b)=0` for `z in Z`. Define

\[
r(x)=P_x^{\mathsf Q}(\tau_A=\infty).
\]

Before the first entrance to `A`, the true killed kernel and auxiliary killed kernel coincide. Therefore the true forward survival probability satisfies the exact first-defect identity

\[
\boxed{
s(x)=r(x)+\sum_{b\in B}H(x,b)s(b).}
\tag{9.2}
\]

Now take one **true** step from each finite boundary state `b`. Put

\[
a_b=\sum_y\mathsf K(b,y)r(y),
\qquad
M_{bc}=\sum_y\mathsf K(b,y)H(y,c).
\tag{9.3}
\]

Then

\[
\boxed{(I-M)s_B=a.}
\tag{9.4}
\]

This finite system is automatically nonsingular. Indeed ellipticity and finiteness of `B` give

\[
\varepsilon_0=
\min_{b\in B}P_b^{\mathsf K}(U_1=0)>0,
\]

and every row sum of `M` is at most `1-epsilon_0`. Hence

\[
\rho(M)<1,
\qquad
\boxed{s_B=(I-M)^{-1}a=\sum_{m\ge0}M^m a.}
\tag{9.5}
\]

No asymptotic boundary-condition uniqueness theorem is needed.

Finally, if the origin's stack state is `r~pi`, never returning in the right-transient regime requires a first step to the right. Conditional on that first step, site `1` has stack state `s` with probability `K(r,s)`. Therefore

\[
\boxed{
 p_{\rm esc}
 =\sum_r\pi_r p_{r,1}
 \sum_s K(r,s)
 \left[
 r((s,1))
 +\sum_{b\in B}H((s,1),b)s_B(b)
 \right].
}
\tag{9.6}
\]

Every `H` and `r` term is computed from the convergent transfer-Green series (5.2), (7.3) and finite matrix inversion (9.1); the series terms decay as `O(n^{-bar(delta)})`. Thus (9.6) is an exact convergent finite-dimensional computation of the requested escape probability for the entire finite-state spatial-Markov, bounded, positive elliptic subclass.
