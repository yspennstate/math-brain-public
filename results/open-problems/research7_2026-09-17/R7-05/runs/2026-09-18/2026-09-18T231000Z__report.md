## B18 — translate the lower logarithm into an exact dyadic energy

For integer `J>=0`, monotonicity of `u -> F_{n,z}(e^{-u})` gives

`sum_{m>=J+1} F_{n,z}(e^{-m})
 <= int_J^infinity F_{n,z}(e^{-u}) du
 <= sum_{m>=J} F_{n,z}(e^{-m})`.

Thus the lower-log problem is, up to one bin and universal constants, the tail of

`Q_n(z;J)=sum_{m>=J}F_{n,z}(e^{-m})`.

This translation matters because the source already has a strong estimate for *intermediate* small singular values even though its bound for the very least singular value is nonsummable.

## B25 — double-count the singular-value tail using the source Lemma 6.5

Write the source intermediate-singular exponent as

`beta = 1 + 2/alpha`

and define

`kappa = 2/beta = 2 alpha/(alpha+2)`.

The source proof supplies a `gamma>0`, exponentially likely good events `G_n(z)`, and

`E[s_{n-i}^{-2} | G_n(z)] <= C (n/i)^beta`

for every `i>=n^(1-gamma)`.  The detailed Bordenave–Caputo–Chafaï proof records `P(G_n^c)<=C exp(-n^delta)` for some `delta>0`.

Let

`N_n(t)=n F_{n,z}(t)`.

For `r>=n^(1-gamma)`, the event `N_n(t)>=r+1` forces `s_{n-r}<=t`, hence Markov gives

`P(N_n(t)>=r+1 | G_n) <= C t^2 (n/r)^beta`.

Now use the exact tail-sum formula

`E[N_n(t)|G_n]=sum_{r=0}^{n-1}P(N_n(t)>=r+1|G_n)`.

Choose `q=t^kappa` and `r0=ceil(nq)`.  If

`t >= n^(-c_*)`,

where

`c_* = gamma/kappa = gamma(alpha+2)/(2alpha)`,

then `r0>=n^(1-gamma)`, so

`E[N_n(t)|G_n]/n
 <= q + C t^2 q^(1-beta)
 = O(t^kappa)`.

Removing the exponentially rare `G_n^c` gives the complete estimate

`E F_{n,z}(t) <= C t^kappa + C exp(-n^delta)`

uniformly for

`n^(-c_*) <= t <= 1`.

This is a genuine aggregate hard-edge estimate extracted from the existing source machinery: the expected *fraction* of small singular values obeys a power law on the full mesoscopic range.

## B18 + concentration — an all-dimensions a.s. mesoscopic theorem

The source bounded-variation concentration lemma for empirical singular laws gives, for every threshold `t`,

`P(F_{n,z}(t)>E F_{n,z}(t)+u) <= 2 exp(-c n u^2)`.

Put

`M_n=floor(c_* log n)`

and take `u_n=A sqrt(log n/n)` with `A` large.  There are only `O(log n)` thresholds `t=e^{-m}` with `m<=M_n`, so a union bound followed by Borel–Cantelli yields, almost surely, eventually simultaneously for every such `m`,

`F_{n,z}(e^{-m})
 <= C e^{-kappa m} + C exp(-n^delta) + u_n`.

Summing from a fixed `J` to `M_n`,

`sum_{m=J}^{M_n}F_{n,z}(e^{-m})
 <= C_kappa e^{-kappa J}
   + O(log n exp(-n^delta))
   + O(log n sqrt(log n/n))`.

Therefore

`lim_{J->infinity} limsup_{n->infinity}
 sum_{m=J}^{floor(c_*log n)}F_{n,z}(e^{-m}) = 0`

almost surely for every fixed `z`.

Equivalently, **under the full source hypotheses, with no density assumption, the lower logarithm is already uniformly integrable almost surely down to the polynomial scale `n^(-c_*)` for all dimensions.**

This is the main localization result of the run.  It proves that the source's nonsummable least-singular-value estimate is only needed for the extreme bottom tail; it is not needed to control a macroscopic range of lower singular values.

## B6 — a rigorous no-go for the naïve smoothing route

The previous run proved fixed-`eta` stability under Gaussian entry smoothing.  A tempting completion would smooth by variance `sigma_n`, use the source bounded-density least-singular bound, and transfer to the original matrix by Weyl.  The powers are incompatible.

Gaussian convolution gives density norm

`||phi_sigma||_infinity <= C sigma_n^(-2)`.

The source bounded-density row-distance estimate implies, for unnormalized matrices,

`P(s_n <= r_n) <= C n^(5/2) (r_n/sigma_n)^2`.

For this upper bound itself to be summable with a power margin one needs

`r_n/sigma_n <= n^(-7/4-epsilon)`.

But the Gaussian perturbation has operator norm `asymp sigma_n sqrt(n)`, so direct Weyl transfer of a lower bound `r_n` needs

`r_n/sigma_n >> sqrt(n)`.

These requirements are incompatible.  In the power parametrization `sigma_n=n^(-K)` and `r_n=n^(-b-1/2)`, the two requirements are respectively

`b > K + 5/4`

and

`K > b + 1`.

No pair satisfies both.  Therefore **Gaussian smoothing + the source bounded-density small-ball estimate + direct Weyl perturbation cannot close C0031.**  This does not rule out a three-step/Green-function comparison or another dynamical smoothing argument.
