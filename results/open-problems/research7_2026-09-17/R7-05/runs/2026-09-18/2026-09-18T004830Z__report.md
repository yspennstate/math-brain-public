## 4. New mathematical idea

The preceding run found that for a fixed candidate interval the probability of being closed has leading order `A_n^2`, where

`A_n=prod_{k=0}^n (1-q_k)`,

and `q_k` is the marginal tail of a site reach. At critical coefficient `c<1`, a single fixed interval is too unlikely to yield extinction directly.

The new idea is to use both free boundary locations. At scale `N`, there are order `N^2` candidate intervals `[-i,j]` with `N<=i,j<=2N`. Their expected closed count is order `N^2 A_N^2`. More importantly, for two candidate intervals, the event that both are closed decomposes into:

1. a closed **intersection core**;
2. a left wing controlled only by one-sided left reaches;
3. a right wing controlled only by one-sided right reaches.

Those three pieces use disjoint site sets. This produces a second moment of the same order as the square of the first moment. Paley-Zygmund then gives a scale-uniform positive chance of a trap, and a tail zero-one argument upgrades this to arbitrarily large traps almost surely.

This is exactly the conditional gluing mechanism missing from the previous run.

## 5. Method B3 — prove the stronger abstract directed theorem

Let `(L_x,R_x)_{x in Z}` be iid copies of an almost surely finite nonnegative integer-valued pair `(L,R)`, allowing arbitrary dependence between `L` and `R` at the same site. Assume equal marginal tails

`q_n=P(L>n)=P(R>n)`

and `P(L=0,R=0)>0`. Site `x` contributes

`J_x=[x-L_x,x+R_x] cap Z`.

A finite interval is closed if every site mark centered inside it stays inside it.

### Theorem proved this run

If

`limsup_{n->infinity} n q_n < 1`,

then almost surely there are arbitrarily large finite closed intervals containing zero. Consequently the directed interval-activation cluster from zero is finite almost surely.

The proof is fully written in the immutable artifact created this run. The key ingredients are reproduced below.

Define

`f_n=1-q_n`, `A_n=prod_{k=0}^n f_k`, `A_{-1}=1`,

and

`p_n=P([0,n] closed)`.

If `F(u,v)=P(L<=u,R<=v)`, then exactly

`p_n=prod_{k=0}^n F(k,n-k)`.

Choose `c` with

`limsup n q_n < c <1`.

Eventually `q_n<=c/n`.

First, uniformly for large `n`,

`p_n asymp A_n^2`.    (5.1)

The upper bound follows from

`F(k,n-k)<=min(f_k,f_{n-k})`

and splitting at `n/2`.

For the lower bound, writing

`j_{u,v}=P(L>u,R>v)`, one has

`F(u,v)=1-q_u-q_v+j_{u,v}`

and therefore

`F(u,v)>=f_u f_v-q_u q_v`.

Since `f_u,f_v>=f_0>0`, the relative loss from replacing `F(u,v)` by `f_uf_v` is at most a constant times `q_uq_v`. Along `u=k,v=n-k`,

`sum_{k=0}^n q_k q_{n-k}=O((log n)/n)`.

Thus the full product loses only a bounded factor (indeed a factor tending to one), proving (5.1). This argument is deliberately dependence-robust: the joint exceedance `j_{u,v}` only helps.

Second, the strict exponent `c<1` gives the summation estimate

`sum_{d=0}^N A_{d-1} <= C N A_N`,    (5.2)

because

`A_{d-1}/A_N <= C (N/(d+1))^c`.

Also `A_m asymp A_N` uniformly for `N<=m<=4N` up to constants depending only on the eventual tail bound.

These two estimates are all that the second moment requires.

### B3 outcome

This stronger theorem is not tied to stable/Brownian scaling, regular variation, or the detailed frog construction. It is a general extinction theorem for iid directed interval marks with symmetric marginal tails and arbitrary within-site dependence. It supplies exactly the form needed by H0024.

## 6. Method B19 — explicit two-boundary trap-finding algorithm

At scale `N`, inspect the finite family

`I_{i,j}=[-i,j]`, `N<=i,j<=2N`,

and define

`Z_N=# { (i,j): I_{i,j} is closed }`.

There are order `N^2` candidates. By (5.1), for every such pair `i+j in [2N,4N]`,

`P(I_{i,j} closed) >= c_0 A_N^2`,

so

`E Z_N >= c_1 N^2 A_N^2`.    (6.1)

This is a concrete finite search procedure at each scale. No simulation is used and no checker was manufactured: its success probability is handled exactly in B21.

### B19 outcome

## 7. Method B21 — import second-moment / renewal-barrier geometry and close the gluing step

Take two candidates `I_{i,j}` and `I_{i',j'}`. Put

`i_0=min(i,i')`, `j_0=min(j,j')`, `d=|i-i'|`, `e=|j-j'|`.

If both are closed, their intersection `[-i_0,j_0]` is closed. The sites in the excess left wing must satisfy the one-sided constraints

`L<=0, L<=1, ..., L<=d-1`,

whose probability is `A_{d-1}`. The right wing contributes at most `A_{e-1}`. Core and wings are disjoint site sets, so iid site independence gives the exact useful upper bound

`P(I_{i,j} and I_{i',j'} closed)
 <= p_{i_0+j_0} A_{d-1} A_{e-1}`.    (7.1)

Since `i_0+j_0>=2N`, the half-product bound gives `p_{i_0+j_0}<=C A_N^2`. Summing (7.1) over all pairs and using (5.2),

`E Z_N^2 <= C N^4 A_N^4`.    (7.2)

Together with (6.1), Paley-Zygmund yields a `delta>0` independent of `N` such that

`P(Z_N>0)>=delta`    (7.3)

for all large `N`.

Now take dyadic `N_m=2^m`. The event

`E_infty={Z_{N_m}>0 infinitely often}`

has probability at least `delta`. It is invariant under changing finitely many site marks: all marks are finite almost surely, while both candidate boundary distances tend to infinity, so sufficiently large closed intervals remain closed after any fixed finite modification, and conversely. Hence `E_infty` belongs to the iid tail sigma-field. Kolmogorov zero-one implies

`P(E_infty)=1`.

Thus almost surely a finite closed interval containing zero exists (indeed infinitely many do), and the deterministic closure characterization from the previous R7-05 run gives extinction.

### B21 outcome

The exact blocker from the previous run is closed. The second-moment intersection/wing decomposition turns static scale abundance into almost-sure trapping without replacing the actual directed H0024 site law by independent left/right samples or by the lossy symmetric envelope `D*`.

Roy-Saha's product barrier criterion is the nearest solved analogue located in the bounded search, but the present mechanism is different: they create independent time-layer barriers for a symmetric radius; here the independence is spatial and appears only after the intersection-plus-wings decomposition.

## 8. H0024 application and metric movement

For H0024 define the site right and left extrema

`R_x=max_{1<=i<=eta_x} D^->_{x,i}`,

`L_x=max_{1<=i<=eta_x} D^<-_{x,i}`.

The pairs are iid over sites and have equal marginals by symmetry. Let

`s_n=P(D^-> >= n)`.

Then

`q_n=P(R_0>n)=1-E[(1-s_{n+1})^{eta_0}]`.

Since

`[1-(1-s)^eta]/s -> eta`

pointwise and is bounded above by `eta`, dominated convergence using `m=E[eta_0]<infinity` gives

`q_n/s_{n+1} -> m`.    (8.1)

The source critical asymptotic is

`n s_n/ell(n^r) -> kappa`.    (8.2)

Slow variation absorbs the unit shift, so

`n q_n/ell(n^r) -> m kappa`.    (8.3)

The required atom `P(L_0=0,R_0=0)>0` also holds: conditional on any finite number of frogs, there is positive probability that every frog dies before taking its first step; `eta_0<infinity` almost surely under the finite-mean assumption.

Therefore

`limsup ell(n^r) < 1/(m kappa)`

`limsup n q_n <1`,
