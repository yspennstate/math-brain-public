# Mathematical research

## Idea before code

The strict coefficient is already sharp, so the remaining source difficulty is not another first-order constant. The equality regime must be attacked through a cumulative quantity. The new idea is to stop following the two active fronts and instead count **all finite absorbing hulls** containing the origin. Almost-sure extinction would force infinitely many such hulls by a deterministic union construction. Therefore, finite expected hull count is a rigorous obstruction to extinction. That turns the equality question into a summability problem and exposes second-order logarithmic structure.

No code is required: all claims in this run are theorem-sized and are proved on the page.

## B18 — say it in another language: finite closed-hull intensity

Let `((L_x,R_x))_{x in Z}` be iid finite directed interval marks. When `x` activates it activates

`J_x=[x-L_x,x+R_x] cap Z`.

A finite interval `I` is **closed** if `J_x subseteq I` for every `x in I`. In the interval-activation frog model this is an exact representation, not merely a comparison: all individual frog path-intervals based at one site share that site, so their union is `[x-L_x,x+R_x]` for the sitewise maxima.

For `n>=0`, set

`p_n=P([0,n] is closed)`.

With

`F(u,v)=P(L<=u,R<=v)`,

site independence gives

`p_n = prod_{k=0}^n F(k,n-k)`.                                    (1)

Now count all closed intervals containing the origin:

`N_0 = # { (i,j) in N_0^2 : [-i,j] is closed }`.

Translation invariance gives the exact first moment

`E[N_0]=sum_{i,j>=0}p_{i+j}=sum_{n>=0}(n+1)p_n`.                  (2)

### Theorem 1 — finite closed-hull intensity forces survival

If

`sum_{n>=0}(n+1)p_n < infinity`,                                  (3)

then the directed interval process survives from the origin with positive probability.

### Proof

Assume instead that the origin process is finite almost surely. Translation invariance gives the same probability-one statement from every fixed site, and countability gives a single full-probability event on which **every** site has a finite activation hull.

For a site `x`, let `H(x)` be that finite hull. It is closed: if an activated site's mark left the final hull, the outside point would have been activated.

Construct closed intervals recursively. Let

`I_0=H(0)=[a_0,b_0]`.

If `I_k=[a_k,b_k]` is finite and closed, consider the adjacent site `b_k+1` and its finite closed hull

`H(b_k+1)=[c_k,d_k]`.

Because it contains `b_k+1`, one has `c_k<=b_k+1<=d_k`. Hence `I_k` and `H(b_k+1)` overlap or are adjacent. Their union is an interval and is closed, because every site's mark is already contained in whichever constituent closed interval contains that site. Define

`I_{k+1}=I_k union H(b_k+1)`.

Its right endpoint is at least `b_k+1`, so the intervals are strictly increasing and all contain zero. Therefore `N_0=infinity` almost surely.

But (3) and (2) imply `E[N_0]<infinity`, hence `N_0<infinity` almost surely. Contradiction. Thus survival has positive probability. QED.

This proves the rigorous necessary condition for almost-sure extinction

`a.s. extinction => sum_n(n+1)p_n=infinity`.                      (4)

No converse is claimed.

## B27 — swap the quantifiers: a cumulative tail condition instead of a strict pointwise gap

Assume equal marginal tails

`q_n=P(L>n)=P(R>n)`, `f_n=1-q_n`,

and define

`A_m=prod_{k=0}^m f_k`, `A_{-1}=1`.

Because

`F(u,v) <= f_{min(u,v)}`,

(1) gives

`p_{2m+1} <= A_m^2`,

`p_{2m} <= f_m A_{m-1}^2 <= A_{m-1}^2`.                          (5)

Therefore

`sum_{n>=1} n A_{floor((n-1)/2)}^2 < infinity`                    (6)

is a sufficient survival criterion. This is genuinely different from requiring an eventual strict inequality `n q_n>1+delta`: it asks only that the **accumulated** tail mass make a product series summable. It allows the coefficient to converge to one, and can also tolerate nonuniform pointwise behavior.

When `q_n=O(1/n)`,

`A_n=exp(-sum_{k<=n}q_k+O(1))`,                                  (7)

since `sum q_k^2<infinity`. Thus the cumulative form is

`sum_n n exp(-2 sum_{k<=n/2}q_k)<infinity`.                       (8)

A useful boundary corollary follows immediately. If

`q_n=(1/n)(1+a/log n+O(1/(log n)^2))`                             (9)

with `a>1/2`, then

`sum_{k<=n}q_k=log n+a log log n+O(1)`

and

`A_n asymp 1/(n(log n)^a)`.

Hence `(n+1)p_n <= C/[n(log n)^(2a)]`, whose sum converges. Therefore the process survives with positive probability.

So the first-order equality

`n q_n -> 1`

**does not by itself force extinction**.

The number `1/2` here is the exact convergence threshold of this proved closed-hull mechanism; it is not claimed to be the full process threshold.

## B4 — prove something weaker, completely: a source-valid H0024 equality family

The abstract boundary theorem can be realized under the literal source assumptions.

Take:

- `eta_x=1` deterministically, so `m=E eta_0=1`;
- simple symmetric nearest-neighbour walk, hence finite variance `sigma^2=1`, `r=2`, and source constant `kappa=sqrt(2)`;
- critical `beta=1/2`;
- any fixed `a>1/2`;
- a slowly varying function that for large `x` is

`ell(x)=(1/sqrt(2))(1+2a/log x)`.                                 (10)

Near `p=1`, choose the survival-parameter density exactly as

`f_pi(p)=(1-p)^(-1/2) ell((1-p)^(-1))`,                           (11)

and complete it on a compact interval away from one to make a probability density. This is possible by taking the tail neighbourhood sufficiently small. It satisfies the source density hypothesis and

`ell(x)->1/sqrt(2)=1/(m kappa)`.                                  (12)

Thus the source's strict `liminf` survival condition is not applicable.

For simple symmetric random walk let `tau_n^+` be the first hit of `n`. The standard difference equation

`u_j=(p/2)(u_{j-1}+u_{j+1})`, `u_n=1`

gives

`E[p^(tau_n^+)]=lambda(p)^n`,                                     (13)

where

`lambda(p)=(1-sqrt(1-p^2))/p=exp(-arcosh(1/p))`.

Because a geometric lifetime with survival parameter `p` satisfies `P(L>=k|p)=p^k`,

`s_n:=P(D^->>=n)=integral_0^1 lambda(p)^n f_pi(p)dp`.              (14)

Set `theta=arcosh(1/p)`, so `p=sech theta` and `lambda=e^-theta`. As `theta downarrow0`,

`1-sech theta=theta^2/2+O(theta^4)`,

and

`(1-sech theta)^(-1/2) sech(theta)tanh(theta)
 = sqrt(2)(1+O(theta^2))`.                                        (15)

Using (10)-(11), the transformed density is therefore

`[1+2a/log(1/(1-sech theta))+O(theta^2)]dtheta`.                  (16)

Also

`log(1/(1-sech theta))=log(2/theta^2)+O(theta^2)`.                (17)

After `z=n theta`, the Laplace integral in (14) gives

`n s_n
 = integral_0^infinity e^-z [1+a/log n+O((1+|log z|)/(log n)^2)] dz
   + O(1/(log n)^2)`.

The tail part with `p` bounded away from one is exponentially small, and `integral e^-z |log z| dz<infinity`, so

`s_n=(1/n)(1+a/log n+O(1/(log n)^2))`.                            (18)

Since there is one frog per site,

`q_n=P(R_0>n)=s_{n+1}`,

so (9) holds. The left and right reaches of that frog are dependent, but Theorem 1 and (5) require no within-site independence. The exact frog model therefore survives with positive probability.

### Source-valid boundary theorem

For every `a>1/2`, there is a literal H0024 nearest-neighbour model satisfying all source assumptions and

`ell(n^2) -> 1/(E[eta_0] kappa)`

for which the frog model **survives with positive probability**.

This is a genuine theorem on the source's previously unresolved first-order equality boundary.
