## 4. The all-depth i.i.d. theorem recovered from the in-flight artifact

Let a fresh i.i.d. site stack have deterministic bound `M`, put `alpha_i=2p_i-1`,

\[
T(z)=\frac1{2-z},
\qquad
B(z)=\mathbb E\prod_{i=1}^M((1-\alpha_i)+\alpha_i z),
\qquad B'(1)=\delta.
\]

For the forward branching-like chain, every high row `k>=M` has exact pgf

\[
\boxed{P_k(z)=T(z)^kB(z).}
\tag{4.1}
\]

Declare the same expression at all rows to obtain a signed auxiliary kernel. The true/auxiliary discrepancy is supported only in rows `1,...,M-1` and, in row `k`, only in columns up to `M-k`.

Conjugating `T` by `u=1/(1-z)` turns iteration into translation. If

\[
\mathcal C(u)=u^MB(1-1/u)=\prod_{a=1}^M(u-\rho_a),
\]

then `sum rho_a=delta` and

\[
\prod_{\ell=0}^{n-1}B(1-1/(u+\ell))
=
\frac{\prod_a(u-\rho_a)_n}{(u)_n^M}.
\tag{4.2}
\]

For `delta>1`, all fixed low-state Green entries converge absolutely and are finite combinations of generalized-hypergeometric values/derivatives. If `G` is this signed auxiliary Green kernel, define

\[
h_k=G_{k0}/G_{00},\qquad s_k^*=1-h_k,
\]

and the Dirichlet columns

\[
U_{kj}=G_{kj}-h_kG_{0j}.
\]

If `R_B` is the finite boundary defect and `x=(s(1),...,s(M-1))^T`, then

\[
\boxed{(I+U_BR_B)x=s_B^*,}
\tag{4.3}
\]

and the cumulative optional-stopping uniqueness argument proves this matrix is nonsingular. Thus

\[
\boxed{

 =\mathbb E[p_1]\,
 e_1^T(I+U_BR_B)^{-1}s_B^*
}
\tag{4.4}
\]

for right transience; spatial reflection gives the left-transient formula. This computes the entire source branch `(IID)+(BD)+(WEL)`.

## 6. B3 — phase lifting preserves finite-rank localization

Take a finite spatial period `L`. At phase `a`, let

\[
\omega_a=(p_{a,1},...,p_{a,M_a},1/2,1/2,...),

Randomize the spatial phase uniformly. The resulting finite orbit is stationary and ergodic under shift and satisfies `(POS_1)`. Write

\[
\delta_a=\sum_i(2p_{a,i}-1),

\bar\delta=L^{-1}\sum_a\delta_a.

For the positive source branch, `bar(delta)>1` is the right-transient regime.

For each phase define

\[
B_a(z)=\prod_i((1-\alpha_{a,i})+\alpha_{a,i}z).

## 7. B19 — exact spatial transfer semigroup and critical exponent

Starting from `(a,k)`, the auxiliary `n`-step population pgf is exactly

\[
\boxed{
F_{a,k}^{(n)}(z)
=T^n(z)^k
\prod_{m=0}^{n-1}
B_{a+m}(T^{n-1-m}(z)).
}
\tag{7.1}
\]

The proof is a one-line induction using

\[
F^{(n+1)}(z)=B_{a+n}(z)F^{(n)}(T(z)).
\]

Conjugate by `u=1/(1-z)`. If

\[
u^{M_a}B_a(1-1/u)=\prod_{r=1}^{M_a}(u-\rho_{a,r}),
\]

then `sum_r rho_{a,r}=delta_a`. For `n=qL`, grouping reverse-time factors by residues `h mod L` gives the exact step-L Pochhammer product

\[
\boxed{
\Pi_{a,qL}(u)
=\prod_{h=0}^{L-1}\prod_{r=1}^{M_{b_h}}
\frac{((u+h-\rho_{b_h,r})/L)_q}{((u+h)/L)_q},
\quad b_h=a-1-h\pmod L.
}
\tag{7.2}
\]

Gamma-ratio asymptotics yield, for every fixed derivative order,

\[
\boxed{\partial_u^r\Pi_{a,qL}(u)=O_r(q^{-\bar\delta}).}
\tag{7.3}
\]

There is no derivative `log q` loss because numerator and denominator Pochhammers are phasewise balanced. The same estimate holds for all residue classes `n=qL+s`. Therefore every fixed low-population auxiliary Green entry is absolutely summable as soon as `bar(delta)>1`.

Moreover these entries are explicit: split `n` into its `L` residue classes and extract only finitely many derivatives at `u=1`. Each residue-class series is generalized hypergeometric because its successive-term ratio is rational in `q`.

This identifies the exact exponent controlling the transfer product as the **spatially averaged drift `bar(delta)`**, with no independence assumption.

\[
\boxed{

\boxed{
U(x,b)=G(x,b)-G_{xZ}G_{ZZ}^{-1}G_{Zb}.}

With `R_B` the finite true/auxiliary defect, the true survival boundary vector obeys the exact finite gluing system
