## 4. Method B4 — PROVE SOMETHING WEAKER, COMPLETELY: determine `t_cov` through order `k^2`

The first target is not another fluctuation inequality.  It is the mean itself.

By Cauchy--Schwarz, (3.5)--(3.7) imply

`E_s D_k <= sqrt(E_s D_k^2)`

`<= sqrt(24 P_s(D_k>0)) t_cov(G_k)`

`= O(k^2 log k sqrt(log k/k))`

`= O(k^(3/2) (log k)^(3/2))`

`= o(k^2)`.                                                (4.1)

Hence

`E_s tau_cov`

`= (k^2+k+2)H_k - 1 + o(k^2)`.                           (4.2)

Now choose any non-gateway clique vertex `q`.  The exact first-step computation from the preceding package gives

`E_q T_s = k^2`.                                          (4.3)

Before the first visit to `s`, no leaf can have been visited.  At `T_s`, all `k` leaves therefore remain.  By the strong Markov property, the subsequent time merely to collect all leaves is a fresh copy of `Lambda_k`.  Since complete covering cannot precede leaf completion,

`E_q tau_cov >= k^2 + E Lambda_k`

`= k^2 + (k^2+k+2)H_k - 1`.                              (4.4)

Therefore the right side is a lower bound for `t_cov`.

For the converse, start from an arbitrary vertex `x` and stop at `T_s`.  The pre-`T_s` visited set can only make the remaining cover task easier than a fresh start from `s`, so

`E_x tau_cov <= E_x T_s + E_s tau_cov`.                   (4.5)

The exact hitting-time table gives

`max_x E_x T_s = k^2`.                                    (4.6)

Maximizing (4.5) and using (4.2),

`t_cov <= k^2 + (k^2+k+2)H_k - 1 + o(k^2)`.              (4.7)

Together with (4.4),

`boxed: t_cov(G_k) = k^2 + (k^2+k+2)H_k - 1 + o(k^2).`   (4.8)

Since

`H_k = log k + gamma + O(1/k)`,

this yields the two-term expansion

`boxed: t_cov(G_k)=k^2 log k + (1+gamma)k^2 + o(k^2).`    (4.9)

Using (3.1),

`boxed: t_cov(G_k)/h_k = (1/2)log k + (1+gamma)/2 + o(1).` (4.10)

This also proves that any non-gateway clique start is asymptotically worst through `o(k^2)`:
