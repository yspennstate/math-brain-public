## Method B14 — quotient a symmetric family: exact spider / coupon-collector reduction

Let `Sp(k,L)` be the tree consisting of `k>=2` paths of length `L` meeting at one centre. A complete proof in the artifact establishes

` t_hit = 2 k L^2 `

and, for centre start,

` t_cov = 2 k L^2 H_k - L^2 `.

More sharply, for a start at depth `d` on any arm,

` E_x tau_cov = t_cov - d^2 `,

so the centre is exactly the worst start.

The proof quotients centre-to-centre excursions by radial depth. An excursion hits its endpoint with probability `1/L`; grouping raw excursions until one endpoint hit produces iid success blocks `Z_j` whose successful arm labels are iid uniform and independent of their durations. If `N_k` is the ordinary coupon-collector count of successful labels, and `T^+` is the return to the centre after the success that completes all arms, then

` T^+ = sum_{j=1}^{N_k} Z_j `,

with

` E Z_j = 2L^2,   E Z_j^2 = O(L^4) `

uniformly in `L`. The actual cover time differs from `T^+` only by the final endpoint-to-centre return segment, whose first two moments are `L^2` and `O(L^4)`.

Combining this with the coupon-collector limit gives, for **every sequence** `L=L_k>=1`,

` (tau_cov - t_cov)/t_hit  ==>  G - gamma `,

where `G` is standard Gumbel. Consequently

` SD(tau_cov)/t_hit -> pi/sqrt(6) = 1.282549830... `.

Thus the DLP `t_hit` scale, if universal, is exactly sharp already on an elementary family satisfying

` t_cov/t_hit = H_k - 1/(2k) ~ log k -> infinity `.

It also improves the necessary universal coefficient calibration from the previous finite `>1.043303...` witness to

` C >= pi/sqrt(6) `

for any putative universal `SD<=C t_hit` estimate. Because the Gumbel upper tail is asymptotic to `e^{-x}`, any fixed-prefactor universal exponential-tail inequality under this exact normalization cannot have rate parameter strictly larger than `1`. The source asks only for some positive rate, so this is sharpness information, not closure.

## Method B20 — locate the failure of the raw unvisited-vertex algorithm

The previous run had shown conditionally that a universal near-threshold estimate

` Var(U_t) <= C E U_t `,   `U_t=# {v:T_v>t}`,

would imply `t_hit`-scale tails. This run proves that this raw-vertex condition is false.

Take the dumbbell `D_r`: two copies of `K_r` joined by a single bridge `a-b`, start at a nonbridge vertex of the left clique, and set `t_r=floor(alpha r^2)` for fixed `alpha>0`.

Until the bridge endpoint `b` is hit, the killed walk in the left clique lumps to the two-state substochastic matrix

`Q_r = [[0,(r-1)/r],[1/(r-1),(r-2)/(r-1)]]`.

Its dominant eigenvalue is

`lambda_r = 1 - 1/r^2 + O(r^-4)`,

while the other eigenvalue is `O(1/r)`. Hence

`P(T_b>t_r) -> e^{-alpha}`.

A complete middle-window argument then shows that with probability `1-o(1)` the left clique is fully covered before a nonexceptionally early crossing, and after a nonexceptionally late crossing the right clique is fully covered before a recross. The complete-graph cover mean `O(r log r)`, a `r^(3/2)` safety window, and an `O(log^2 r/r)` bridge-recross bound suffice.

Therefore

` U_{t_r}/r - 1_{T_b>t_r} -> 0 ` in `L^2`,

so

` E U_{t_r} ~ r e^{-alpha} `,

` Var(U_{t_r}) ~ r^2 e^{-alpha}(1-e^{-alpha}) `,

and

` Var(U_{t_r}) / E U_{t_r} ~ r(1-e^{-alpha}) -> infinity `.

This fully kills the raw universal second-moment ansatz. It does **not** refute DLP Question 5.2: on the dumbbell both `t_cov` and `t_hit` are `Theta(r^2)`. Its value is structural: late vertices can survive as one metastable block, so the proof object must quotient them into hitting-scale clusters rather than count vertices independently.

## Method B5 — add a bottleneck parameter and track it

The spider arm length `L` is a clean bottleneck parameter. The B14 proof was deliberately uniform in arbitrary `L=L_k`; both success-block mean and maximal hitting time scale by `L^2`. Therefore lengthening the late clusters does not inflate normalized cover fluctuations:

` SD(tau_cov)/t_hit -> pi/sqrt(6) `

for every choice of arm lengths `L_k>=1`, while `t_cov/t_hit~log k` remains divergent.

This distinguishes two effects:

- raw cluster size can destroy vertex-level variance bounds (B20);
- symmetric hitting-scale clusters themselves need not destroy the `t_hit` fluctuation scale, because the bottleneck slowdown is already absorbed into `t_hit` (B5).

The natural replacement object is therefore the number of **effective late blocks** in hitting geometry, not the number of late vertices.
