## 3. Idea before code

The preceding B1/B11/B14 run showed that all pair dependence in the root degree is carried by the unique shared edge between two selected neighbors. The new idea is to stop using that fact only as an asymptotic bound and instead **integrate it exactly**.

With

\[
r=n-1-k,
\quad X\sim\mathrm{Beta}(k+1,r),
\quad T\sim\mathrm{Beta}(k,r),
\]

let

\[
F(x)=P(T\le x),
\qquad
Q(x)=x^{-1}\int_0^x F(u)\,du,
\qquad
M(x)=kQ(x)=E(H\mid X=x),
\]

where `H=k-D` is the degree deficit. The shared-edge ANOVA projection from the previous run gives an exact conditional pair covariance `b(x)`. Because `F` is a polynomial for integer beta parameters, the entire finite variance becomes an exact finite rational integral rather than merely an asymptotic quantity.

## 4. Method B3 — prove something stronger: exact finite-`n` variance

For two selected neighbors, define

\[
J_1(x)=\int_0^x(F(x)-F(w))\,dw,
\]

\[
J_2(x)=\int_0^x(F(x)-F(w))^2\,dw.
\]

The unique-shared-edge identity gives

\[
\boxed{
 b(x)=\frac{J_2(x)-J_1(x)^2}{x^2(n-2)^2}.
}
\]

Conditional exchangeability then yields

\[
\operatorname{Var}(H\mid X=x)
=kQ(x)(1-Q(x))+k(k-1)b(x).
\]

Let `f_X` be the `Beta(k+1,r)` density and let

\[
\delta_{n,k}=E[H]
=\frac{2B(n-1,n-1)}{B(k,k)B(r,r)}
\]

be the exact beta-Gini mean deficit from the earlier run. The law of total variance now gives the exact finite identity

\[
\boxed{
\operatorname{Var}(D_{n,k})
=\delta_{n,k}-\delta_{n,k}^2
+k(k-1)\int_0^1\{Q(x)^2+b(x)\}f_X(x)\,dx.
}
\tag{V}
\]

For integer `k,r`,

\[
F(x)=\sum_{j=k}^{n-2}\binom{n-2}{j}x^j(1-x)^{n-2-j},
\]

so `Q,J_1,J_2,b` are polynomial expressions and every outer integral in (V) is a finite beta integral. Therefore `Var(D_{n,k})` is **exactly rational and exactly computable for every finite `(n,k)`**. This is stronger than the source's asymptotic request and directly addresses its stated variance obstruction.

## 5. Method B27 — swap the quantifiers: one inequality for all finite `(n,k)`

Write

\[
V_{\rm cut}:=\operatorname{Var}(M(X)),
\qquad
C_{n,k}:=k(k-1)E[b(X)].
\]

The exact decomposition is

\[
\operatorname{Var}(D)
=V_{\rm cut}+\delta_{n,k}-\frac{E[M(X)^2]}{k}+C_{n,k}.
\tag{P1}
\]

The shared-edge theorem from the previous run gives

\[
0\le C_{n,k}\le\frac{n-1}{4(n-2)}.
\tag{P2}
\]

The new point is that the negative correction in (P1) is also uniformly bounded. Put `N=n-1=k+r` and `mu=k/N`. Jensen gives

\[
M(X)^2
\le \frac{k^2}{X^2}E[(X-T)^2\mid X].
\]

Using

\[
\operatorname{Var}(T)=\frac{kr}{N^2(N+1)},
\quad
E[X^{-1}]=\frac Nk,
\quad
E[X^{-2}]=\frac{N(N-1)}{k(k-1)},
\]

one obtains exactly

\[
E\frac{(X-\mu)^2}{X^2}=\frac{r}{N(k-1)}
\]

and hence

\[
\boxed{E[M^2]\le\frac{2k^2r}{n(k-1)}.}
\tag{P3}
\]

Therefore, simultaneously for every `n>=4`, `2<=k<=n-2`,

\[
\boxed{
\operatorname{Var}(D)=V_{\rm cut}+\delta_{n,k}+\varepsilon_{n,k},
}
\]

with

\[
\boxed{
-\frac{2kr}{n(k-1)}
\le\varepsilon_{n,k}
\le\frac{n-1}{4(n-2)}.
}
\tag{P4}
\]

In particular `-4<epsilon<1/2` uniformly over the entire finite parameter range. This says that all graph dependence beyond the random root cutoff contributes **the exact mean deficit plus only a bounded additive error**.

A beta-Gini/Cauchy bound gives

\[
\delta_{n,k}\le\sqrt{\frac{kr}{2n}}.
\]

Thus, with `s_n^2=k(n-k)/n`,

\[
\boxed{
0\le \operatorname{Var}(D)-V_{\rm cut}
\le \frac{s_n}{\sqrt2}+\frac{n-1}{4(n-2)}.
}
\tag{P5}
\]

Equivalently,

\[
\boxed{
\left\|(H-M(X))/s_n\right\|_2^2
\le\frac1{\sqrt2 s_n}
+\frac{n-1}{4(n-2)s_n^2}.
}
\tag{P6}
\]

Outcome B27: **successful**. A sequence-by-sequence negligibility argument is replaced by one finite inequality valid over the full parameter rectangle.
