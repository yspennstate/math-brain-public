## New proof: arbitrary block Schur decoupling

For a finite split `E=F sqcup B`, write in the strict case

`Q=[[A,X],[X*,D]]`

and define the Schur complement

`C=D-X* A^{-1} X`.

The new theorem is

`P^{A direct-sum C} <= P^Q`, with `det(A direct-sum C)=det Q`.

The proof is full-process. Under `P^Q`, the marginal on `F` is `P^A`. If the exact observed configuration on `F` is `S` and `Z=F\S`, then conditioning `S` present and `Z` absent gives a conditional kernel on `B` at least

`C_S=D-Q_{B,S} Q_S^{-1} Q_{S,B}`.

A block-inverse identity gives

`C_S-C = U R^{-1} U* >=0`,

where

`R=A_Z-A_{Z,S}A_S^{-1}A_{S,Z}` and `U=Q_{B,Z}-Q_{B,S}A_S^{-1}A_{S,Z}`.

Hence the true conditional DPP on `B` given any exact `F`-configuration stochastically dominates `P^C`. Sample the same `F`-configuration, independently sample `P^C`, and use the conditional monotone coupling on `B`; this couples `P^{A direct-sum C}` below `P^Q`. Boundary contractions follow by regularization. This proof avoids the prior local Hessian/spectral-expansion route entirely.

## Explicit ordered-factorization consequence

For any ordered partition `E=B_1 sqcup ... sqcup B_k`, let `L_j` be the successive block Schur pivots. Iteration gives

`P^{L_1 direct-sum ... direct-sum L_k} <= P^Q`,

with

`det Q = product_j det L_j`.

For singleton blocks in order `e_1,...,e_n`, with `P_j={e_1,...,e_j}`,

`d_j = det Q_{P_j}/det Q_{P_{j-1}}`

and therefore

`tensor_j Ber(d_j) <= P^Q`, `product_j d_j=det Q`.

Applying the same theorem to `I-Q` gives the corresponding explicit upper product via vacancy pivots. Thus the finite-DPP peeling parameters can be chosen as ordinary principal-minor/LDL pivots, a stronger and more usable statement than the preceding geometric-midpoint recursion.

## New normal-subgroup reduction

Let `H normal Gamma` be finite, `|H|=m`, `[Gamma:H]=k`, and assume the lower Lyons theorem is available on `H`. Order the `H`-cosets. Because each coset union is left-`H` invariant and `Q` is `Gamma`-equivariant, every successive block Schur pivot is `H`-equivariant. Applying the `H` theorem to each pivot gives, for **every** `Gamma`-equivariant `Q`,

`tensor_{j=1}^k Ber(p_j)^{coset_j} <= P^Q`,

where

`product_j p_j = p^k`, `p=(det Q)^(1/|Gamma|)`.

The same reduction applies to `I-Q` for the upper side. No centrality, constant-coset, mean-zero, hidden-cyclic, or low-rank active-sector assumption is used. The remaining problem is now quotient uniformization of these coset densities while retaining enough information lost by Schur factorization.
