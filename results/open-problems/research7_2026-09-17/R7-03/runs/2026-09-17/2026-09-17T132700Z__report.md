## 4. B2 — attack the negation first

Assume for the rest of the derivation that `G` is a hypothetical SSNC counterexample with

`|V| = 19,   delta^+(G) = 8`.

For every vertex `v`, write

`d^+(v) = 8 + r_v`, with `r_v >= 0`.

Let

- `N1(v) = N_1^+(v)`,
- `N2(v) = N_2^+(v)`, exact second out-neighborhood,
- `U(v) = V \ ({v} union N1(v) union N2(v))`, the vertices not reachable from `v` in at most two directed steps.

Because the graph is assumed to have **no Seymour vertex**,

`|N2(v)| <= d^+(v)-1`.

Hence

`|U(v)| = 18 - d^+(v) - |N2(v)| >= 19 - 2 d^+(v)`

and therefore

`|U(v)| >= max(0, 3 - 2 r_v)`.

In particular:

- degree 8 (`r_v=0`) implies `|U(v)| >= 3`;
- degree 9 (`r_v=1`) implies `|U(v)| >= 1`;
- degree at least 10 has no nontrivial lower bound from this inequality alone.

### 4.1 Target-side trap notation

Fix a target vertex `x`. Define

`P(x) = { v : x in U(v) }`.

Thus `P(x)` is the set of sources that cannot reach `x` in one or two steps.

Define the trap

`T(x) = { y != x : y not-> x }`,

where `y not-> x` means there is no arc `y -> x`.

Let `a_x` be the number of vertices nonadjacent to `x` in the underlying simple graph. Since

`|T(x)| = d^+(x) + a_x`,

write

`q_x := |T(x)| - 8 = r_x + a_x`.

So `q_x >= 0`, and `q_x=0` iff `r_x=0` and `a_x=0`, i.e. `x` has outdegree eight and is adjacent to all eighteen other vertices.

### 4.2 Fixed-target capacity lemma

**Lemma.** If `p:=|P(x)|>0`, then

`p <= 2 q_x - 1`.

Moreover, if equality holds, then every source in `P(x)` has outdegree exactly eight, `G[P(x)]` is a tournament, and every possible arc from `P(x)` to `T(x)\P(x)` is present and oriented out of `P(x)`.

**Proof.** If `v in P(x)`, then `x` is not reachable from `v` in one step, so `v not-> x`. More strongly, if `v -> y` and `y -> x`, then `v` would reach `x` in two steps. Hence every out-neighbor of `v` lies in `T(x)`. Therefore every `v in P(x)` has all of its at least eight outgoing arcs inside `T(x)`.

Count arcs whose tail lies in `P=P(x)` and whose head lies in `T=T(x)`. We have the lower bound

`8p <= e(P,T)`.

For the upper bound, split the heads into `T\P` and `P`. There are at most

`p(|T|-p)`

arcs from `P` to `T\P`, and because the graph is oriented there are at most

`binom(p,2)`

arcs internal to `P`. Thus

`8p <= p(|T|-p) + binom(p,2)`.

Since `|T|=8+q_x`, divide by positive `p` and simplify:

`8 <= 8+q_x-p+(p-1)/2`,

so

`0 <= q_x - (p+1)/2`,

hence

`p <= 2q_x-1`.

If equality holds, then both inequalities in the count must be equalities. Hence every `v in P` has exactly eight outgoing arcs, every possible pair inside `P` contributes one oriented arc (so `G[P]` is a tournament), and every possible arc from `P` to `T\P` is present and directed out of `P`. QED.

This target-capacity inequality is the main local ingredient retained from the dense-case architecture, but here we keep all equality slack explicitly rather than discarding it.

## 5. B6 — deform the dense proof by one vertex

The dense theorem closes at `n=2 delta+2`. The present boundary is exactly one vertex beyond that:

`19 = 2*8 + 3`.

The useful question is therefore: **what is the exact algebraic slack introduced by that one extra vertex?**

Define degree classes

- `n0 = #{v : r_v=0}`,
- `n1 = #{v : r_v=1}`,
- `h  = #{v : r_v>=2}`.

Let

`E = sum_{r_v>=2} (r_v-2)`

be the excess above degree ten among high-outdegree vertices. Then

`sum_v r_v = n1 + 2h + E`.

The number of arcs is

`|A| = 19*8 + sum_v r_v = 152 + n1 + 2h + E`.

Now define the global target-slack sum

`Q := sum_x q_x`.

Because `q_x = |T(x)|-8` and `sum_x |T(x)| = 19*18 - |A|`,

`Q = 19*(18-8) - |A| = 190 - |A|`.

Substituting the arc count gives

`Q = 38 - n1 - 2h - E`.

### 5.1 Source-side slack

Let

`L := sum_v ( |U(v)| - max(0,3-2r_v) ) >= 0`.

Then the double-counted incidence number

`I := sum_v |U(v)| = sum_x |P(x)|`

satisfies the exact source-side expression

`I = 3 n0 + n1 + L`.

Since `n0 = 19-n1-h`,

`I = 57 - 2 n1 - 3h + L`.    (1)

### 5.2 Target-side slack

Let

`z := #{x : q_x=0}`.

For every target with `q_x>=1`, define the nonnegative capacity slack

`c_x := (2q_x-1) - |P(x)| >= 0`,

and set

`C := sum_{x:q_x>=1} c_x >= 0`.

If `q_x=0`, the capacity lemma implies `P(x)=empty`, so those `z` targets contribute zero. Therefore

`I = sum_{q_x>=1} (2q_x-1-c_x)`

`  = 2Q - (19-z) - C`.

Substitute the expression for `Q`:

`I = 57 - 2n1 - 4h - 2E + z - C`.    (2)

Equating (1) and (2) gives the exact identity

`z = h + 2E + L + C`.    (★)

This is the main new finite-boundary reduction obtained in this run.

### 5.3 Meaning of the identity

Each term on the right is nonnegative. Consequently

`z >= h + 2E`.

Thus every vertex of outdegree at least ten requires compensating degree-eight vertices that are adjacent to everybody:

- each degree-at-least-ten vertex costs at least one unit of `z`;
- each extra unit of outdegree beyond ten costs two additional units of `z`;
- any slack in the source lower bounds `|U(v)| >= max(0,3-2r_v)` costs additional `z`;
- any slack in the target capacity bound `|P(x)| <= 2q_x-1` also costs additional `z`.

In this sense (★) is the exact bookkeeping for the one-vertex failure of the dense contradiction.

## 6. B30 — localize the gluing obstruction

The identity (★) gives two sharply different branches.

### 6.1 Equality branch: `z=0`

If `z=0`, then every term on the right side of (★) vanishes:

`h=0`, `E=0`, `L=0`, `C=0`.

So every vertex has outdegree 8 or 9, every source lower bound is tight, and every positive-q target capacity bound is tight.

Now suppose there were a degree-nine vertex `v`. Since `L=0`, its source lower bound is tight and

`|U(v)|=1`.

Choose the unique `x in U(v)`. Then `v in P(x)`. Since `C=0`, the target `x` attains equality in the capacity lemma. But equality in the lemma forces **every source in `P(x)` to have outdegree exactly eight**, contradicting `d^+(v)=9`.

Therefore:

**Proposition. If `z=0`, every vertex has outdegree exactly eight.**

Consequently every vertex has exactly three unreachable vertices:

`|U(v)|=3` for all `v`.

Also `q_x=a_x` because `r_x=0`. Since `z=0`, every vertex has at least one nonneighbor, so `a_x>=1`. Capacity equality gives the exact local formula

`|P(x)| = 2 a_x - 1`.

Moreover, for every `x`, `P(x)` induces a tournament and every arc from `P(x)` to `T(x)\P(x)` is present and directed out of `P(x)`.

There are exactly

`binom(19,2) - 152 = 171 - 152 = 19`

missing unordered pairs, hence

`sum_x a_x = 38`.

Thus the entire `z=0` branch reduces to an oriented 19-vertex, 8-outregular graph whose missing-edge graph has exactly 19 edges, minimum missing degree at least one, and whose target-preimage sets satisfy the rigid odd-size rule `|P(x)|=2a_x-1` plus tournament/domination equality structure.

This is now a finite structural classification problem, not the full original search space.

### 6.2 Positive-slack branch: `z>0`

For `z>0`, equation (★) is an exact slack budget:

`z = h + 2E + L + C`.

So fixing small `z` immediately bounds:

- the number of vertices of degree at least ten;
- how far any degree can exceed ten;
- total excess in all source lower bounds;
- total failure of target capacity equality.

This suggests a finite classification by `z=1,2,...`, with the equality branch `z=0` handled separately. The next run should classify the smallest `z` patterns rather than launch another unconstrained all-or-nothing search.
