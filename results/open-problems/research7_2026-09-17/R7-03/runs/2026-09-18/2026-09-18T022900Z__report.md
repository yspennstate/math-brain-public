## 2. Exact outside source and source scope

The source asks for a **countable measured group** `(G,mu)` and an **infinite-index subgroup** `H<G` such that `G/H` admits **no nonconstant left (quasi-)mu-harmonic functions whatsoever**.  The source definition of measured group requires `supp(mu)` to generate `G` as a semigroup.  The source discussion includes unbounded harmonic functions, so bounded Liouville is not enough.

The admitted symmetric construction is

\[
X=\mathbb N_0,
\qquad
G=\operatorname{Sym}_{\mathrm{fin}}(X),
\qquad
H=\operatorname{Stab}_G(0),
\]

with star transpositions `tau_n=(0 n)` and any positive probability vector `(p_n)`, `mu(tau_n)=p_n`.  Under `G/H ~= X`,

\[
(Pu)(0)=\sum_{n\ge1}p_nu(n),
\tag{2.1}
\]

\[
(Pu)(n)=p_nu(0)+(1-p_n)u(n),\qquad n\ge1,
\tag{2.2}
\]

and source validity at the center is exactly

\[
\sum_{n\ge1}p_n|u(n)|<\infty.
\tag{2.3}
\]

## 3. B3 — prove something stronger: characterize the full Poisson range

Define

\[
\mathcal D_p
:=
\left\{u:X\to\mathbb C:\sum_{n\ge1}p_n|u(n)|<\infty\right\},
\]

and

\[
\ell^1_0(X)
:=
\left\{d=(d_0,d_1,\ldots):
\sum_{n\ge1}|d_n|<\infty,
\ d_0+\sum_{n\ge1}d_n=0
\right\}.
\]

### Theorem 3.1 — exact range and kernel

\[
\boxed{
\operatorname{Ran}\bigl((P-I)|_{\mathcal D_p}\bigr)=\ell^1_0(X)
}
\tag{3.1}
\]

and

\[
\boxed{
\ker\bigl((P-I)|_{\mathcal D_p}\bigr)
=\{\text{constants}\}.
}
\tag{3.2}
\]

#### Proof

If `d=(P-I)u`, then from (2.2)

\[
d_n=p_n(u(0)-u(n)),\qquad n\ge1.
\tag{3.3}
\]

Hence

\[
\sum_{n\ge1}|d_n|
\le |u(0)|+\sum_{n\ge1}p_n|u(n)|<\infty.
\tag{3.4}
\]

At the center,

\[
d_0=\sum_{n\ge1}p_nu(n)-u(0).
\tag{3.5}
\]

Absolute convergence lets us sum (3.3):

\[
\sum_{n\ge1}d_n
=u(0)-\sum_{n\ge1}p_nu(n)
=-d_0.
\tag{3.6}
\]

Thus every range vector lies in `ell^1_0(X)`.

Conversely take any `d in ell^1_0(X)` and arbitrary `a in C`, and define

\[
u(0)=a,
\qquad
u(n)=a-\frac{d_n}{p_n}.
\tag{3.7}
\]

Then

\[
\sum_{n\ge1}p_n|u(n)|
\le |a|+\sum_{n\ge1}|d_n|<\infty,
\tag{3.8}
\]

so `u in D_p`.  The leaf equations give `(P-I)u(n)=d_n`, while the center gives

\[
(P-I)u(0)
=-\sum_{n\ge1}d_n=d_0.
\tag{3.9}
\]

This proves (3.1).  If `d=0`, (3.3) and `p_n>0` force `u(n)=u(0)` for every `n`, proving (3.2). ∎

A source quasi-harmonic defect is constant, `d_x=c` for all `x`.  For `c!=0`, its leaf sequence is not `ell^1`; hence it is outside the exact range (3.1).  Therefore `c=0`, and (3.2) then forces `u` constant.  So the source theorem is now a one-line corollary of an exact Poisson-range classification.

The same theorem gives the explicit quotient isomorphism

\[
\mathcal D_p/\mathbb C
\cong
\ell^1_0(X),
\tag{3.10}
\]

with inverse given by (3.7).

**B3 outcome: SUCCESS.**  The constant-defect rigidity is strengthened to the complete source-integrable Poisson equation.

## 4. B15 — break symmetry deliberately

The original example used a symmetric law on involutions.  To determine whether that is essential, define

\[
G^\sharp=C_3\times\operatorname{Sym}_{\mathrm{fin}}(\mathbb N_0),
\qquad
H^\sharp=C_3\times\operatorname{Stab}(0),
\tag{4.1}
\]

and for every `n>=1`

\[
g_n=(1,\tau_n),
\qquad
\mu^\sharp(g_n)=p_n.
\tag{4.2}
\]

Each `g_n` has order six and

\[
g_n^{-1}=(2,\tau_n)\notin\operatorname{supp}(\mu^\sharp),
\tag{4.3}
\]

so the measure is genuinely non-symmetric and its supported generators are not involutions.

Nevertheless

\[
g_n^2=(2,e),\qquad
g_n^3=(0,\tau_n),\qquad
g_n^4=(1,e).
\tag{4.4}
\]

Thus the support semigroup contains the whole central `C_3` and every pure star transposition.  Because

\[
\tau_i\tau_j\tau_i=(i\ j),
\]

the star transpositions generate all finitary permutations.  Hence `supp(mu^sharp)` semigroup-generates `G^sharp`, so this is a valid measured group.

The quotient `G^sharp/H^sharp` again identifies with `N_0`.  Björklund's left operator uses `check(mu^sharp)`, supported on `(2,tau_n)`.  The `C_3` coordinate belongs to `H^sharp` and disappears on the quotient, so each inverse acts there exactly as `tau_n`.  Therefore the quotient operator is still precisely (2.1)-(2.2), with the same integrability condition (2.3).

Theorem 3.1 therefore proves that this **non-symmetric, non-involutive** measured group also solves the literal source problem.

**B15 outcome: SUCCESS.**  Ambient symmetry, reversibility and involutivity are not essential.  The rigidity lives in the quotient star channel plus semigroup generation upstairs.

## 5. B29 — add the point at infinity and identify the boundary charge

Since `(p_n)` is summable and positive,

\[
p_n\to0.
\tag{5.1}
\]

For a formal star function define

\[
z_n:=p_n(u(n)-u(0)).
\tag{5.2}
\]

Then by (3.3)

\[
(P-I)u(n)=-z_n.
\tag{5.3}
\]

If `u in D_p`,

\[
\sum_{n\ge1}|z_n|
\le |u(0)|+\sum_{n\ge1}p_n|u(n)|<\infty,
\tag{5.4}
\]

so `z_n->0`.  Thus all source-valid functions have zero normalized trace at the added point at infinity:

\[
\boxed{
\operatorname{Tr}_\infty(u)
:=\lim_n p_n(u(n)-u(0))=0.
}
\tag{5.5}
\]

Conversely, suppose formal leaf defects

\[
d_n=(P-I)u(n)\to\delta\ne0.
\tag{5.6}
\]

Then

\[
p_n(u(n)-u(0))\to-\delta,
\tag{5.7}
\]

so `u(n)` escapes at the exact `1/p_n` scale and cannot belong to `D_p`.

The divergence is visible directly in the truncated center mass

\[
A_N:=\sum_{n=1}^Np_nu(n),
\qquad
S_N:=\sum_{n=1}^Np_n.
\]

Since `u(n)=u(0)-d_n/p_n`,

\[
\boxed{
A_N=u(0)S_N-\sum_{n=1}^Nd_n.
}
\tag{5.8}
\]

If `d_n->delta`, then

\[
A_N=-N\delta+o(N)+u(0).
\tag{5.9}
\]

For a genuine quasi-harmonic defect `d_n=c`, this sharpens to

\[
A_N=u(0)S_N-Nc.
\tag{5.10}
\]

So a formal nonzero quasi-harmonic defect is exactly a nonzero boundary charge at infinity, and source integrability excludes it.

**B29 outcome: SUCCESS.**  The nonintegrable formal escape profiles have a precise compactified boundary interpretation, rather than being an unexplained divergence in the center equation.
