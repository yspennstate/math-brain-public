## 4. B11 — DUALIZE: exact weighted Hahn–Banach criterion

Let `v:X->[1,infinity)` satisfy

\[
Pv(x)=\sum_yP(x,y)v(y)<\infty\qquad\text{for all }x.
\]

For a signed sequence `z`, define

\[
\|z\|_{1,v}=\sum_y|z_y|v(y).
\]

For finitely supported signed `a`, let

\[
Ta=aP-a.
\]

### Theorem 1

For `C<infinity`, the following are equivalent:

1. there exists `u:X->R` with
   \[
   Pu-u=1,
   \qquad |u(y)|\le C v(y)\ \forall y;
   \]
2. every finitely supported signed `a` obeys
   \[
   \boxed{\left|\sum_xa_x\right|\le C\|aP-a\|_{1,v}.}
   \]

Equivalently, if

\[
\kappa_v=
\inf\left\{\|aP-a\|_{1,v}:a\in c_{00}(X),\ \sum_xa_x=1\right\},
\]

where signed `a` are allowed, then

\[
\boxed{\kappa_v>0}
\]

if and only if there exists a `v`-controlled forbidden quasi-harmonic solution with defect `1`.

### Proof

First, `T` is injective on `c_00(X)`. If `Ta=0`, then for every `y`,

\[
a_y=\sum_xa_xP(x,y)
=\int_G a_{s^{-1}y}\,d\check\mu(s).
\]

If `M=max a>0`, choosing `y` with `a_y=M` expresses `M` as a convex combination of numbers at most `M`; hence `a_{s^{-1}y}=M` for every `s` in the support. The generating assumption propagates `M` through the full transitive orbit `X`, contradicting finite support because `X` is infinite. If the maximum is zero and `a` is nonzero, the same argument at its negative minimum gives a contradiction. Thus `a=0`.

Assume (1). Since `a` has finite support and every row has finite `v`-moment,

\[
\sum_xa_x
=\sum_xa_x(Pu-u)(x)
=\sum_y(aP-a)_yu(y),
\]

and therefore

\[
\left|\sum_xa_x\right|
\le C\sum_y|(aP-a)_y|v(y)
=C\|aP-a\|_{1,v}.
\]

Conversely assume (2). Injectivity makes

\[
L(Ta)=\sum_xa_x
\]

a well-defined linear functional on `T(c_00(X))`, and (2) bounds its weighted `ell^1` norm by `C`. Hahn–Banach extends `L` continuously to all of `ell^1_v(X)`. The dual is represented by a function `u` with

\[
\sup_y\frac{|u(y)|}{v(y)}\le C.
\]

For each `x`,

\[
1=L(r_x)
=\sum_y(P(x,y)-\delta_x(y))u(y)
=Pu(x)-u(x).
\]

The rowwise absolute convergence follows from `|u|<=Cv` and `Pv(x)<infinity`. Thus `u` is source-admissible. `square`

**Outcome of B11.** The infinite-support continuation is now an exact coercivity problem, not a vague integrability warning. The missing gluing condition is precisely positivity of `kappa_v` for some row-integrable growth weight.

## 5. B12 — FIND WHAT IS CONSERVED: ordinary `ell^1` coercivity is universally zero

The unweighted choice `v=1` cannot work, for a reason stronger than “bounded defect-one functions are impossible.”

### Theorem 2

For every stochastic kernel `P` on a countable state space and every starting state `o`, there exist finitely supported probability vectors `a_n` such that

\[
\boxed{\|a_nP-a_n\|_1\to0.}
\]

Hence `kappa_1=0` for every such kernel.

### Proof

Take the Cesaro occupation measures

\[
b_n=\frac1n\sum_{k=0}^{n-1}\delta_oP^k.
\]

Then

\[
b_nP-b_n=\frac{\delta_oP^n-\delta_o}{n},
\]

so

\[
\|b_nP-b_n\|_1\le 2/n.
\]

Choose a finitely supported probability vector `a_n` with

\[
\|a_n-b_n\|_1\le1/n.
\]

Because a Markov operator contracts total variation,

\[
\begin{aligned}
\|a_nP-a_n\|_1
&\le\|b_nP-b_n\|_1
 +\|(a_n-b_n)P\|_1
 +\|a_n-b_n\|_1\\
&\le4/n.
\end{aligned}
\]

This tends to zero. `square`

**Outcome of B12.** The finite-support row functional from the previous run is necessarily discontinuous in ordinary `ell^1` once one passes to infinite rows. The mass-preserving Markov dynamics manufacture finite approximate stationary measures at rate `O(1/n)`. Any useful dual certificate must therefore pay for escape to infinity with a genuine growth weight `v`.

## 6. B30 — LOCALIZE: a second infinite-support obstruction from descending characters

The weighted criterion localizes one escape mechanism. A separate exact obstruction rules out a large class of infinite-support quotient constructions without solving any coercivity problem.

### Theorem 3

Suppose there is a nonzero homomorphism

\[
\chi:G\to\mathbb R
\]

with `chi(H)=0` and

\[
\int_G|\chi(s)|\,d\mu(s)<\infty.
\]

Then `(G,mu,H)` cannot solve Björklund Problem 2.

### Proof

Define

\[
u(gH)=\chi(g).
\]

It is well defined because `chi(H)=0`, and nonconstant because `chi` is nonzero on the quotient. Absolute integrability gives

\[
\begin{aligned}
Pu(gH)
&=\int_Gu(sgH)\,d\check\mu(s)\\
&=\chi(g)+\int_G\chi(s)\,d\check\mu(s)\\
&=u(gH)-\int_G\chi(t)\,d\mu(t).
\end{aligned}
\]

Thus `u` is a nonconstant source-valid left quasi-harmonic function. `square`

If `G` is finitely generated and `mu` has finite first word-moment, every real character is word-Lipschitz and hence `mu`-integrable. Therefore a necessary condition for a candidate is

\[
\boxed{\operatorname{Hom}(G/\!\langle\!\langle H\rangle\!\rangle,\mathbb R)=0.}
\]

For finitely generated `G/<<H>>`, this forces its abelianization to be finite. In particular, no infinite normal abelian quotient with finite first moment can solve the source problem.

I do **not** claim novelty for this character observation; it is a direct source-compatible necessary condition. Its value here is that the previous finite-support theorem has forced attention to infinite-support measures, where this obstruction still survives.

**Outcome of B30.** The remaining escape regime is now sharply localized: a viable example must use infinite support, kill the bounded harmonic sector, avoid every integrable real character annihilating `H`, and have `kappa_v=0` for every admissible growth weight that could control a defect-one solution.
