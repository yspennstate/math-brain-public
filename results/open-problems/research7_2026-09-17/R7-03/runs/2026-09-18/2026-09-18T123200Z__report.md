## 4. New mathematics: the full multiplicative inequality on every unique-`o`--`b`-path graph

Although G0005 cannot be admitted, its boundary structure is sharp enough to support substantive source-shaped admission mathematics.

### Theorem

Let `G=(V,E)` be a finite graph with independent Bernoulli bond percolation, with arbitrary edge probabilities `p_e in [0,1]`. Fix vertices `o,b in V` and a nonempty set `A subseteq V`.

Assume the underlying deterministic graph has a **unique simple path from `o` to `b`**.

Then

`P(o<->b) >= P(o<->A) min_{a in A} P(a<->b)`.

Thus the stronger Kozma--Nitzan Conjecture 1 is true on this class. The class contains all finite trees but is strictly larger: arbitrary cyclic decorations may be attached to the unique `o`--`b` backbone as long as they do not create a second simple `o`--`b` path.

### Proof

Write the unique path as

`v_0=o, v_1, ..., v_m=b`,

and denote the edge `{v_{i-1},v_i}` by `e_i`, with open probability `p_i`.

First, every connected component of `G \ V(P)` can meet the backbone at at most one vertex. If one such component met two distinct backbone vertices `v_i` and `v_j`, a path through that component from `v_i` to `v_j`, combined with the backbone prefix from `o` to `v_i` and suffix from `v_j` to `b`, would create a second simple `o`--`b` path.

Hence every vertex `a` has a well-defined projection `rho(a)=v_{j(a)}` onto the backbone: if `a` lies on the backbone, this is `a`; otherwise it is the unique backbone vertex to which the component containing `a` attaches.

Define prefix and suffix reliabilities

`S_j = prod_{i=1}^j p_i`,

`T_j = prod_{i=j+1}^m p_i`.

Because the backbone is the unique `o`--`b` path, every backbone edge is an `o`--`b` bridge and

`P(o<->b)=S_j T_j`

for every `j`. Also

`P(o<->v_j)=S_j`,

`P(v_j<->b)=T_j`.

For `a in A`, let `r_a` be the probability that `a` connects to its projection `rho(a)` through its attached component. Since every `a`--`b` path must first reach `rho(a)` and then traverse the unique suffix,

`P(a<->b)=r_a T_{j(a)} <= T_{j(a)}`.             (1)

Choose `a_* in A` with minimal projection index

`j_* = min_{a in A} j(a)`.

Whenever `o` connects to any vertex of `A`, it must traverse the backbone at least through `v_{j_*}`. Therefore

`{o<->A} subseteq {o<->v_{j_*}}`

and hence

`P(o<->A) <= S_{j_*}`.                          (2)

Set

`q = min_{a in A} P(a<->b)`.

Using the particular relay `a_*` in (1),

`q <= P(a_*<->b) <= T_{j_*}`.                   (3)

Multiplying (2) and (3) gives

`P(o<->A) q <= S_{j_*} T_{j_*} = P(o<->b)`.

This is exactly the full multiplicative source inequality. `QED`.

## 5. Sharp continuity modulus on the same graph class

Under the weaker G0005 hypotheses,

`P(o<->A)>1-delta`

and

`P(a<->b)>1-delta` for every `a in A`,

the theorem gives

`P(o<->b) > (1-delta)^2`.

Therefore the exact admissible modulus on this class is

`delta_*(eta)=1-sqrt(1-eta)`.

Indeed, if `delta<=delta_*(eta)`, then `(1-delta)^2>=1-eta`, and the strict hypotheses yield `P(o<->b)>1-eta`.

This is sharp already on the path `o--v--b` with `A={v}` and both edges open independently with probability `r`. Then

`P(o<->A)=r`,

`P(v<->b)=r`,

`P(o<->b)=r^2`.

For any `delta>delta_*(eta)` choose

`1-delta < r < sqrt(1-eta)`.

Both premises hold, while `P(o<->b)=r^2<1-eta`. Thus no larger universal `delta(eta)` works even on three-vertex paths.

This exact sharp parameter is new work in the present run. It is a **restricted-class theorem**, not a proof of the full source statement and not a publication-novelty claim.

## 6. Section-B methods and outcomes

### B2 — attack the negation first

I tried to produce a counterexample inside the smallest class that still allows arbitrary local cycles but retains one global bottleneck: graphs with a unique `o`--`b` path.

The counterexample search collapses because all relays project to a totally ordered deterministic backbone. The earliest projected relay forces a common prefix event and its own `b`-connection bounds the complementary suffix. The negation therefore turns into a complete proof of the stronger multiplicative inequality on this class.

**Outcome:** full restricted theorem plus exact sharp `delta_*(eta)`; no source-level closure.

### B6 — deform from a solved case

The natural solved case is a tree. The proof shows that tree acyclicity is far stronger than needed. One may insert arbitrary cycles and arbitrary finite internal structure into components hanging from a single backbone vertex. Those components contribute only factors `r_a<=1`, so the argument survives unchanged.

**Outcome:** exact deformation from trees to the maximal obvious class characterized by uniqueness of the simple `o`--`b` path.

### B30 — localize the gluing failure

The unique-path proof uses exactly one feature that disappears when a second `o`--`b` route is added: relay projections are no longer ordered along a deterministic common backbone, so there need not exist a single deterministic prefix event containing every realization of `{o<->A}`.

Thus the genuine cyclic obstruction is **not** local branch reliability. It is the loss of a deterministic first relay/common prefix. The September 2026 claimed formal proof attacks exactly this point by replacing the deterministic first relay with a conditioned random first-relay/slack-surplus construction that does not pay an error once for every element of `A`.

**Outcome:** the gluing failure is isolated to the random-relay selection step on genuinely multiply connected graphs.
