## 5. Deep source check: E0070 / Björklund Problem 2

### 5.1 Exact outside source

- Author: **Michael Björklund**.
- Title: **Five remarks about random walks on groups**.
- Year: **2014**.
- Primary source: arXiv **1406.0763**.
- Exact source problem: **Problem 2** in the homogeneous-space discussion (§6.1 in the paper; intake locator `Problem 2, PDF p. 24`).
- Source statement:

> Construct a countable measured group `(G,mu)` and an infinite-index subgroup `H<G` such that `G/H` admits no nonconstant left `(quasi-)mu`-harmonic functions whatsoever.

The source defines a left quasi-`mu`-harmonic function by a constant-defect equation: with `P_mu u(g)=int u(sg)dmu(s)`, one has

```text
P_mu u(g) = u(g) + c
```

for a constant `c` (in the paper's construction `c=int u(s)dmu(s)`). Thus an everywhere-defined solution of `P_mu u-u=1` is already a forbidden nonconstant quasi-harmonic function.

The old intake attempt `E0070-A001` suggested large-subgroup / wreath-product Liouville quotients and correctly noticed that killing bounded harmonic functions does not kill quasi-harmonic ones. The new argument below shows a stronger obstruction: **no finitely supported generating measure can ever solve Problem 2**, regardless of how cleverly `G` and `H` are chosen.

## 6. B2 — attack the desired construction by proving a finite-support impossibility theorem

### Theorem (finite-support obstruction for Björklund Problem 2)

Let `G` be a countable group, let `mu` be a **finitely supported** probability measure whose support generates `G` as a semigroup, and let `H<G` have infinite index. Put `X=G/H` and define the left Markov operator

```text
(Pu)(x) = sum_s mu(s) u(sx).
```

Then there exists a nonconstant real function `u:X->R` such that

```text
Pu = u + 1.
```

In particular `G/H` always admits a nonconstant left quasi-`mu`-harmonic function. Hence **every solution of Björklund Problem 2 must use an infinitely supported measure `mu`.**

### Proof

Let `R^(X)` denote the free real vector space on basis `{e_y : y in X}`, i.e. the finitely supported real functions on `X`. For every `x in X` define the finite row vector

```text
r_x := sum_s mu(s) e_{sx} - e_x.
```

The key point is that the family `{r_x}_{x in X}` is linearly independent.

Suppose, to the contrary, that a finite relation exists:

```text
sum_x a_x r_x = 0,
```

where `a:X->R` is finitely supported and not identically zero. Looking at the coefficient of `e_y` gives

```text
a_y = sum_s mu(s) a_{s^{-1}y}                     (1)
```

for every `y in X`.

Because `a` is finitely supported, it attains a maximum `M` and a minimum `m`, and it vanishes outside a finite set. If `M>0`, choose `y` with `a_y=M`. Equation (1) writes `M` as a convex combination of numbers all at most `M`. Therefore

```text
a_{s^{-1}y}=M
```

for every `s` with `mu(s)>0`. Iterating, `a_{g y}=M` for every `g` in the semigroup generated by `supp(mu)^{-1}`. Since `supp(mu)` generates `G` as a semigroup, `supp(mu)^{-1}` does as well, so the whole orbit `G y=X` has value `M`. But `X` is infinite and `a` has finite support, contradiction. If instead `M=0` and `a` is nonzero, then `m<0`; applying the same convexity argument at a minimum gives the same contradiction. Thus `a=0` and the rows are linearly independent.

Let

```text
W := span{r_x : x in X} subset R^(X).
```

Because the rows are independent, the assignment

```text
Lambda(r_x)=1  for every x
```

defines a well-defined linear functional `Lambda:W->R`. Extend `Lambda` linearly to all of `R^(X)` (choose a vector-space basis extending the independent family `{r_x}`). Define

```text
u(y):=Lambda(e_y),  y in X.
```

Then, for every `x`,

```text
(Pu)(x)-u(x)
 = sum_s mu(s)Lambda(e_{sx}) - Lambda(e_x)
 = Lambda(r_x)
 = 1.
```

Since `mu` has finite support, every sum above is finite, so `u` satisfies the source's integrability requirement automatically. A constant `u` would have `Pu-u=0`, hence this `u` is nonconstant. This proves the theorem. `□`

### Consequence for the old attempted route

Any candidate based on a finitely supported walk on a wreath product, finitely generated Schreier graph, or other locally finite quotient is dead **before** Poisson-boundary analysis: the affine Poisson equation itself forces a nonconstant quasi-harmonic function. The only remaining source-valid regime is genuinely infinitely supported `mu`, where the row vectors no longer lie in the free vector space and the extension argument does not automatically produce a `mu`-integrable solution.

This is a sharp structural narrowing, not a solution of the full source problem.

## 7. B6 and B18 — deform the solved finite-support regime and translate the residual problem

### B6: deform from finite support to the only possible escape regime

The theorem above identifies an exact boundary:

```text
finite support  =>  Problem 2 impossible,
infinite support =>  only possible remaining regime.
```

This kills the tempting strategy “first make the quotient Liouville, then hope all unbounded/quasi-harmonic functions disappear” whenever the walk is finitely supported. In fact, bounded Liouville behavior is orthogonal to the obstruction: the constructed `u` can be unbounded and is forced purely by finite-row algebra.

For an infinitely supported `mu`, two things break simultaneously:

1. `r_x = sum_s mu(s)e_{sx}-e_x` is no longer an element of `R^(X)`;
2. an algebraic solution to a formal Poisson equation need not be `mu`-integrable, while the source's harmonicity definition requires the convolution to make sense.

Thus the full problem is not a minor perturbation of the finite-support case. A source-level construction must exploit **integrability failure** strongly enough that every nonconstant formal harmonic or constant-defect solution is excluded, while still leaving a legitimate measured-group random walk.

### B18: operator translation

Problem 2 can be reformulated as a simultaneous kernel/range rigidity question for the Markov operator on its natural `mu`-integrable domain `D(P)`:

```text
ker(P-I) = constants,
(P-I)^{-1}(R * 1) = constants only.
```

More explicitly, after quotienting out constants, the desired example requires both

```text
ker(P-I | D(P)/R)=0
```

and

```text
1 notin (P-I)(D(P))
```

(up to nonzero scalar multiples of `1`). The finite-support theorem proves the exact opposite of the second condition: `P-I` is algebraically onto all real functions on `X` in the constant right-hand-side direction, indeed the row-independence proof gives a solution for **any prescribed right-hand side** by replacing `Lambda(r_x)=1` with `Lambda(r_x)=b_x`.

Therefore an admissible E0070 construction would need an infinite-support measure for which the natural integrability domain is small enough to destroy this surjectivity, but not so degenerate that the measure ceases to generate the group. That is a nonlocal functional-analytic construction problem, not a finite certificate/sharp-boundary problem. This is the decisive reason I do **not** classify E0070 as CLOSABLE for R7-03.

As a prior-art sanity check, a fresh search also recovered work on surjectivity of combinatorial Laplacians on infinite graphs (including Coornaert's exposition of the locally finite case and examples due to Trofimov where ordinary harmonic functions can all be constant). That is conceptually consistent with the theorem above: killing the harmonic kernel does not kill affine/quasi-harmonic solutions. I am not claiming the general finite-support coset theorem above as publication-novel on the basis of a search miss.
