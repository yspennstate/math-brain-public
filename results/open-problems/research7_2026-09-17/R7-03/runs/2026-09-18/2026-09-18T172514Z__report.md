## 3. B18 — non-vacuous quantifier reconciliation

## 4. B24 — exact extremal support-floor theorem

Let

```text
D_n = max{|det A| : A in {−1,+1}^{n x n}}
p_n = P(det M_n=0).
```

Divisibility implies that the number of positive nonzero determinant values is at most

```text
floor(D_n / 2^{n-1}).
```

Flipping one row is a measure-preserving involution and negates the determinant, so positive determinants carry total mass `(1-p_n)/2`. Pigeonholing that mass gives the exact finite bound

```text
Delta_n
>= (1-p_n) / (2 floor(D_n/2^{n-1})).          (4.1)
```

Hadamard's inequality `D_n <= n^{n/2}` yields

```text
Delta_n >= (1-p_n) 2^{n-2} n^{-n/2}.         (4.2)
```

Since `p_n=o(1)`, this is

```text
Delta_n >= n^{-(1/2+o(1))n}.                 (4.3)
```

Hence the `1/2` exponent in Conjecture 6.8 is **forced and asymptotically optimal** for the only non-vacuous uniform formulation. No uniform exponent `1/2+epsilon` can hold. This calibration comes purely from determinant lattice spacing, sign symmetry, and the maximal determinant range.

For `n=2`, the bound is exact: the determinant support is `{−2,0,2}`, `p_2=1/2`, and each nonzero atom has probability `1/4`.

## 5. B25 — determinant-collision floor

For two independent Rademacher matrices `M_n,M_n'`, let

```text
C_n=P(det M_n=det M_n' != 0).
```

If `q_x=P(det M_n=x)`, Cauchy–Schwarz over the at most `2 floor(D_n/2^{n-1})` nonzero support points gives

```text
C_n
= sum_{x != 0} q_x^2
>= (1-p_n)^2 / (2 floor(D_n/2^{n-1}))
>= (1-p_n)^2 2^{n-2} n^{-n/2}.                (5.1)
```

This is another exact calibration at the same exponent scale. It is not the missing upper bound.
