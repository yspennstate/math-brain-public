## Complete source-matching derivation

Let

`A=[a_1 ... a_n]`

be any matrix allowed by Bandeira's source. Then `a_i in R^n` and `||a_i||_2=1` for every `i`. Guo–Fang–Lu gives signs `epsilon_i in {±1}` for which

`||sum_i epsilon_i a_i||_∞ < 3 sqrt(2 pi)`.

Since

`sum_i epsilon_i a_i = A epsilon`,

we get

`disc(A) = min_{x in {±1}^n} ||A x||_∞ <= ||A epsilon||_∞ < 3 sqrt(2 pi)`.

Thus the exact source conjecture is true with the explicit universal choice

`K = 3 sqrt(2 pi) < 7.52`.

Karingula–Lovett separately supplies the still-source-closing choice `K=36`.

This is a full implication, not a restricted case: Guo–Fang–Lu permits arbitrary finite dimension/family size and column norms at most one, which strictly contains the square, unit-column class in I0091. The fact that the optimal Komlós constant is not known is irrelevant to closure of Bandeira's Conjecture 10, because the source asks only for existence of some universal `K`.

### B18 — SAY IT IN ANOTHER LANGUAGE

### B11 — DUALIZE

For every signing,

`||A epsilon||_∞ = max_j |<e_j,A epsilon>| = max_{u in {±e_1,...,±e_n}} sum_i epsilon_i <u,a_i>`.
