## 4. B27 — exact quotient/pullback equivalence in both directions

The live paper says that the group equation descends to the quotient.  This run isolated the exact if-and-only-if statement so an auditor does not need to infer the converse.

### Proposition 4.1

Let `mu` be symmetric, let `X=G/H`, and for `u:X->C` define

\[
\Phi_u(g)=u(gH).
\]

Then `u -> Phi_u` is a bijection between functions on `G/H` and right-`H`-invariant functions on `G`.  Whenever the sums exist,

\[
\sum_s\mu(s)\Phi_u(sg)
=
\sum_s\mu(s)u(sgH),
\tag{4.1}
\]

and the left side is right-`H`-invariant as a function of `g`.  Consequently, for every constant `c`,

\[
\int_G\Phi_u(sg)d\check\mu(s)=\Phi_u(g)+c\quad\forall g
\tag{4.2}
\]

if and only if the induced quotient function satisfies

\[
P_Xu=u+c.
\tag{4.3}
\]

In the star construction, source `mu`-integrability of the pullback is exactly

\[
\sum_{n\ge1}p_n|u(n)|<\infty,
\tag{4.4}
\]

and (4.4) makes every quotient convolution absolutely finite.

### Proof

Right-`H`-invariance is immediate:

\[
\Phi_u(gh)=u(ghH)=u(gH).
\]

Conversely, a right-`H`-invariant function `Phi` defines `u(gH)=Phi(g)`; this is well-defined because `gH=g'H` implies `g'=gh` for some `h in H`.  This proves the bijection.

If `g'=gh`, then for every `s`,

\[
\Phi_u(sg')=u(sghH)=u(sgH)=\Phi_u(sg),
\]

so the convolution depends only on the coset `gH`, proving (4.1) and the descent.  Since the actual measure is symmetric, `check(mu)=mu`; substituting (4.1) into the source equation gives (4.3), and every step is reversible, giving the converse.

For the star law, `tau_nH` is quotient point `n`, so source integrability at the identity is precisely (4.4).  At a leaf `k`, all generators other than `tau_k` fix `k`, and

\[
\sum_n p_n|u(\tau_nk)|
=p_k|u(0)|+(1-p_k)|u(k)|<\infty.
\]

Thus the group and quotient domains coincide exactly for this example. ∎

**Outcome B27:** the source theorem can now be stated equivalently as

\[

=
\mathbb C\mathbf1.
\]

No missing converse, coset-orientation ambiguity, or hidden quotient integrability condition remains.

## 5. B21 — Schreier/Markov-chain translation and a stronger summability obstruction

Under (3.2), the weighted Schreier kernel is the infinite star

\[
P(0,k)=p_k,
\qquad
P(k,0)=p_k,
\qquad
P(k,k)=1-p_k.
\tag{5.1}
\]

It is symmetric, so counting measure is reversible.  From leaf `k`, the hitting time of zero is geometric with parameter `p_k`; hence every leaf returns to the center almost surely.  Starting from zero, the first step picks `K` with law `p`, then returns almost surely, so the chain is recurrent.

Moreover, if `T_0^+` is the first positive return time to zero,

\[
\mathbb E_0T_0^+
=1+\sum_{k\ge1}p_k\frac1{p_k}
=\infty.
\tag{5.2}
\]

Thus the quotient is an irreducible **null-recurrent** weighted Schreier chain.

The harmonic equation itself is even simpler: at every leaf,

\[
p_k(u(0)-u(k))=0,

For a nonzero quasiharmonic defect `c`, (3.4) gives

\[
p_ku(k)=p_ku(0)-c\longrightarrow-c.
\tag{5.3}

Therefore the center series `sum p_k u(k)` cannot converge even conditionally when `c != 0`, because its summands do not tend to zero.  The source assumes the stronger absolute `mu`-integrability, so the source contradiction is strictly inside this stronger obstruction.

## 6. B4 — minimal fixed `p_n=2^{-n}` literal-source proof

To ensure no nonessential generalization hides an assumption, specialize completely:

\[

\]

Let `u` be a source-valid left quasiharmonic function on the quotient, with defect `ell`.  The leaf equation is

\[
2^{-k}u(0)+(1-2^{-k})u(k)=u(k)+\ell,
\]

hence

\[
u(k)=u(0)-2^k\ell.
\tag{6.1}
\]

Source integrability is

\[
\sum_{k\ge1}2^{-k}|u(k)|<\infty.
\tag{6.2}

\[
2^{-k}|u(k)|=|2^{-k}u(0)-\ell|\longrightarrow|\ell|>0,
