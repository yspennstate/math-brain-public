Exact locator: Appendix II, §7.1, **Problem 2**, printed PDF p. 24 (PDF page index 23).

The source first defines a **measured group** `(G,mu)` to mean a countable group `G` together with a probability measure `mu` whose support generates `G` as a semigroup. For a `mu`-integrable complex-valued function the source defines left `mu`-harmonicity using convolution by the reflected measure `check(mu)`. Earlier in §1.1 it defines a left quasi-`mu`-harmonic function by a constant-defect convolution equation

`∫ u(sg) d check(mu)(s) = u(g) + ∫ u(s) d check(mu)(s)`.

Problem 2 asks:

> Construct a countable measured group `(G,mu)` and an infinite-index subgroup `H<G` such that `G/H` does not admit any nonconstant left `(quasi-)mu`-harmonic functions whatsoever.

The source discussion immediately preceding the problem explicitly includes **unbounded** left harmonic functions, so bounded Liouville alone is not source closure.

### Source-level closure criterion

Produce one explicit countable measured group `(G,mu)` and one infinite-index subgroup `H<G`, verify that `supp(mu)` semigroup-generates `G`, and prove that every complex-valued source-valid left quasi-`mu`-harmonic function on `G/H` is constant. Since harmonic functions are the zero-defect special case, this also disposes of all nonconstant left harmonic functions.
