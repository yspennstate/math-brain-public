## 4. B13 — a monotone record process gives exponential fixed-time radial persistence

### Idea

The monotone object is not `Y(t)` itself, which can retreat. It is the running record

```text
M(t) = max_{0<=s<=t} Y(s).
```

Every new level of `M` is a new record. Lemma 6.4 says records are accumulated linearly fast with an exponential tail. Lemma 6.5 says that, once a high record is reached, a macroscopic retreat before the next record is exponentially unlikely. A union bound over the *possible terminal record* converts those two facts into a fixed-time estimate for `Y(t)` itself.

### Proposition 4.1 — exponential lower tail for the current infection radius

Fix `q in (0,1)` and start the one-dimensional FA-1f process from the single-infection configuration at the origin, as in the normalization used in the proof of source Lemma 6.4. Let `Y(t)` be the source's Section 6 radius variable.

There exist constants

```text
a=a(q)>0,
c0=c0(q)>0,
C=C(q)<infinity,
t0=t0(q)<infinity
```

such that for every `t>=t0`,

```text
P_eta( Y(t) < a t ) <= C exp(-c0 t).                (4.1)
```

Equivalently, the process is not merely radially ballistic almost surely: failure of a linear-radius lower bound at a fixed large time has an exponential tail.

### Proof

Take the constants `kappa_+` from source Lemma 6.4 and choose one fixed `epsilon in (0,epsilon_0]` and the corresponding `c>0` from source Lemma 6.5. Increase an integer threshold `n0` so that both source estimates hold for every `n>=n0`:

```text
P_eta(tau_n > kappa_+ n) <= e^{-n},                 (4.2)
P_eta(tau_{epsilon n} < tau_{n+1}) <= e^{-c n}.     (4.3)
```

Here `tau_{epsilon n}` is the source's post-`tau_n` first hitting time of `floor(epsilon n)`.

For a deterministic time `t`, define

```text
n = floor( t/(2 kappa_+) ).
```

For `t` large enough, `n>=n0` and `kappa_+ n <= t`. Therefore (4.2) gives

```text
P_eta(tau_n > t)
 <= P_eta(tau_n > kappa_+ n)
 <= e^{-n}.                                         (4.4)
```

It remains to control a retreat after the process has reached level `n`.

Let

```text
M_t = max_{0<=s<=t} Y(s).
```

On the event `{tau_n <= t}`, one has `M_t>=n`. Suppose also that

```text
Y(t) < floor(epsilon n).
```

Set `m=M_t`. Then `m>=n`, `tau_m<=t`, and level `m+1` has not been reached by time `t`. Since `epsilon m >= epsilon n`, the final value is below `floor(epsilon m)` up to the harmless integer-floor convention.

The radius cannot jump downward across all intermediate integer levels. Indeed, an extreme infected site can become healthy only when a nearest neighbor is infected, so loss of an extreme changes the relevant extreme by at most one lattice step; consequently a downward passage from level `m` to below `floor(epsilon m)` hits `floor(epsilon m)`. Hence, after `tau_m` and before `t`, the path realizes

```text
tau_{epsilon m} < tau_{m+1}.
```

Therefore

```text
{tau_n <= t, Y(t) < floor(epsilon n)}
 subset Union_{m>=n} {tau_{epsilon m} < tau_{m+1}}.
```

By (4.3) and the union bound,

```text
P_eta(tau_n <= t, Y(t) < floor(epsilon n))
 <= Sum_{m=n}^infinity e^{-c m}
 = e^{-c n}/(1-e^{-c}).                             (4.5)
```

Combining (4.4) and (4.5),

```text
P_eta(Y(t) < floor(epsilon n))
 <= e^{-n} + e^{-c n}/(1-e^{-c}).                   (4.6)
```

For all sufficiently large `t`,

```text
floor(epsilon n) >= epsilon t/(4 kappa_+).
```

Thus one may take, for example,

```text
a  = epsilon/(4 kappa_+),
c0 = min(1,c)/(4 kappa_+),
```

and enlarge `C` to absorb the floors and finitely many small times. This proves (4.1). `QED`

### Corollary 4.2 — linear record count with exponential lower tail

If `N_rec(t)` denotes the number of distinct positive radius levels first reached by time `t`, then up to the initial finite offset `N_rec(t)=M_t`. Equation (4.2) alone already gives constants `a_rec,c_rec>0` such that

```text
P_eta(N_rec(t) < a_rec t) <= exp(-c_rec t)
```

for all large `t`.

Thus there really is a monotone opportunity **count** growing linearly with an exponential lower tail. What is missing is not the number of graphical record opportunities; it is a theorem converting a positive fraction of those moving-front records into local reset attempts near a prescribed observable support.

### Scope / prior-art qualification

This proposition is a direct new deduction from the exponential estimates already displayed in source Lemmas 6.4 and 6.5. The source states the almost-sure linear-growth conclusion obtained by Borel--Cantelli. I did not locate an explicit displayed fixed-time estimate of the form (4.1) in the bounded check, but **no novelty claim is made**: the deduction may be implicit or routine to the authors.

**B13 outcome:** complete theorem. It removes “lack of exponential all-`q` radial persistence” from the list of possible obstructions, but it does not move the frozen source metric.

## 5. B4 — prove an all-q source-valid subclass completely

### Idea

The infinite-volume FA-1f process has a positive `L^2(pi)` spectral gap for every `q>0`. That does not directly control deterministic or singular initial laws, which are exactly the difficult out-of-equilibrium inputs. But it completely settles the source conclusion for every admissible initial law whose density relative to equilibrium lies in `L^2(pi)`.

This gives a clean boundary between the easy stationary-functional-analytic regime and the hard singular-start regime.

### Proposition 5.1 — all-q exponential convergence for `L^2(pi)` initial densities

Fix `q in (0,1)` and let `(P_t)` be the infinite-volume one-dimensional FA-1f semigroup, reversible with respect to `pi`. Let `gamma(q)>0` be its spectral gap. Suppose

```text
nu << pi,
h = d nu/d pi in L^2(pi).
```

Then for every local `f in L^2(pi)` and every `t>=0`,

```text
| nu(P_t f) - pi(f) |
 <= exp(-gamma(q) t)
    ||h-1||_{L^2(pi)} sqrt(Var_pi(f)).               (5.1)
```

In particular, if `nu` also satisfies the source's exponential infection-gap condition, then Conjecture 2 holds for that `nu` for every `q>0`.

### Proof

Set `g=f-pi(f)`. Since `pi` is invariant and `P_t` is reversible,

```text
nu(P_t f)-pi(f)
 = integral h P_t g d pi
 = integral (h-1) P_t g d pi,
```

because `pi(P_t g)=pi(g)=0`.

By Cauchy--Schwarz,

```text
|nu(P_t f)-pi(f)|
 <= ||h-1||_2 ||P_t g||_2.                           (5.2)
```

The spectral-gap inequality for the reversible semigroup gives exponential `L^2` contraction on mean-zero functions:

```text
||P_t g||_2 <= exp(-gamma(q)t) ||g||_2.              (5.3)
```

Finally `||g||_2=sqrt(Var_pi(f))`. Substituting (5.3) into (5.2) proves (5.1). `QED`

### Concrete source-admissible example

Let

```text
A = {the origin is infected}
```

and set `nu=pi(.|A)`. Then the source gap-tail condition is trivially satisfied because every interval `[-ell,ell]` contains the infected origin under `nu`. If `pi(A)=q` in the source convention, then

```text
h = 1_A/q,
||h-1||_2 = sqrt((1-q)/q),
```

and (5.1) becomes an explicit all-`q` exponential relaxation estimate.

The same applies to any finite-cylinder conditioning of positive `pi`-probability that forces at least one infection in a fixed neighborhood of the origin.

### Why this does not close the source

A deterministic finite-infection configuration on the infinite lattice is singular with respect to product equilibrium, so it has no `L^2(pi)` density. More generally, the source exponential-gap hypothesis does not imply `nu<<pi`, much less an `L^2` density. The source deliberately includes precisely these singular/nonstationary regimes.

Thus the spectral gap is already sufficient on the absolutely continuous side; the missing mechanism is a **smoothing/coupling bridge from singular initial laws into a local equilibrium component with exponentially small residual mass**.

**B4 outcome:** complete all-`q` theorem for a nontrivial source-valid subclass, but no source-level metric movement. This is a standard spectral-gap consequence, not claimed novel.
