## 1. New theorem: arbitrary consecutive M-record spans have a positive factor-two coefficient

Write

`S(a)=P(X>a)`, `N(a)=E[(X-a)^+]`, `c=1-rho`,

`A(a)=1-lambda E[X wedge a]=c+lambda N(a)`.

Take any finite consecutive M-SERPT record span

`a_0<a_1<...<a_k`.

Set

`x_j=S(a_j)`, `y_j=lambda N(a_j)`, `A_j=c+y_j`,

`p_j=x_{j-1}-x_j`, `P=x_0-x_k`.

At M-SERPT records, `y_j/x_j` is nondecreasing, while `y_j` is nonincreasing. Define

`Sigma=sum_{j=1}^k p_j/(A_{j-1} A_j)`

and

`K_{0,k}=2P/(A_0 A_k)-Sigma`.

The new exact theorem is

`K_{0,k}>0`

for **every nonempty consecutive finite M-SERPT record span**, regardless of how many support points or record intervals are present.

More sharply, put

`r0=y_0/x_0`, `xi=y_k/r0`, `L=x_0-xi`, `R=xi-x_k`.

Then `x_k<=xi<=x_0` and

`Sigma <= L/(A_0 A_k)+R/A_k^2`,

so

`K_{0,k} >= R/(A_0 A_k) + L(c+r0 x_k)/(A_0 A_k^2) > 0`.

The terminal case `x_k=y_k=0` is obtained by `xi=R=0`.

### Proof mechanism

The record inequalities give

`y_j >= max(r0 x_j, y_k)`,

hence

`A_j >= phi(x_j):=c+max(r0 x_j,y_k)`.

Replacing the true denominators by this lower envelope can only increase `Sigma`. Refine the survival mesh once at `xi=y_k/r0`. On `[xi,x_0]`, `phi=c+r0 x`, so

`(x_{j-1}-x_j)/[(c+r0 x_{j-1})(c+r0 x_j)]`

`= (1/r0)[1/(c+r0 x_j)-1/(c+r0 x_{j-1})]`

and the whole linear piece telescopes to `L/(A_0 A_k)`. Below `xi`, `phi=A_k`, contributing `R/A_k^2`. The displayed lower bound for `K` follows from `P=L+R` and `A_0-A_k=r0 L`.

This is the first run in this line where the crucial coefficient is controlled for an **arbitrary-length** M-record chain rather than a fixed atom count.

## 2. Exact waiting-reserve decomposition for one merged Gittins valley

Let

`V_j=E[(X wedge a_j)^2]`.

When one Gittins valley merges these consecutive M-SERPT blocks, the source Proposition-4.7 coarse waiting surrogate uses `V_k`, while M-SERPT uses the refined `V_j`. Exact algebra gives

`2 P V_k/(A_0 A_k) - sum_j p_j V_j/(A_{j-1}A_j)`

`= K_{0,k} V_k + sum_{j<k} p_j(V_k-V_j)/(A_{j-1}A_j)`.

Every term on the right is nonnegative. Restoring the common `lambda/2` factor,

`2 Qbar_G(a_0,a_k)-Q_MS(a_0,a_k) >= (lambda/2) K_{0,k} V_k > 0`.

Thus a Gittins valley may skip arbitrarily many M-SERPT records without creating a sign problem in the **factor-two waiting reserve itself**. The genuinely difficult quantity is the residence excess that this reserve must pay.

This gives a precise finite-chain counterpart to P01-B's prefix-compensation program.

## 3. New arbitrary-length scalar collapse of the combined target

Now specialize to an initial Gittins valley that merges the first `m` M-SERPT blocks and ends at a shared record. Put

`a=A_m`, `P=sum_{j<=m}p_j`, `r=1-P`, `y=1-a`,

`q_j=lambda E[X 1_{block j}]`, `u=sum_{j<=m}q_j`,

`w_j=1/A_{j-1}`, `wbar=P^{-1}sum p_j w_j`,

`sigma_w^2=sum p_j(w_j-wbar)^2`,

`K=2P/a-sum p_j/(A_{j-1}A_j)`,

`C=K+r/(ac)`.

For

`H=2 Qbar_G-Q_MS+2E[X]-R_MS`,

blockwise Cauchy gives

`lambda^2 V_m >= sum q_j^2/p_j + (y-u)^2/r`,

`lambda^2 E[X^2] >= sum q_j^2/p_j + (rho-u)^2/r`.

After dropping only the already-proved nonnegative `V_m-V_j` waiting terms, the remaining `m`-dimensional expression is a convex quadratic in the `q_j`. At fixed `u` its exact unconstrained minimizer is

`q_j^*=p_j[u/P+(w_j-wbar)/C]`.

Completing squares yields

`lambda H >= B(q) = B_*(u) + (C/2) sum (q_j-q_j^*)^2/p_j`,

where

`B_*(u)=2rho-rho/a + u(1/a-wbar) - sigma_w^2/(2C)`

`        + C u^2/(2P) + K(y-u)^2/(2r) + (rho-u)^2/(2ac)`.

Therefore **an arbitrary number of skipped prefix records compresses to one scalar convex quadratic**, plus an explicit nonnegative square. This is a genuine dimensional collapse; no atom-by-atom response expression remains.

For `m=2` the formula reproduces the architecture already closed by the previous two-record theorem. For `m>=3` it isolates the first unresolved multi-record prefix obstruction.

## 4. New coupling between the negative variance term and the positive record coefficient

Because `w_{j+1}>=w_j`,

`sum p_j w_j^2 <= sum p_j w_j w_{j+1} = 2P/a-K`,

with `w_{m+1}=1/a`. Therefore

`sigma_w^2 <= 2P/a-K-P wbar^2`.

So the only negative term in `B_*(u)` is quantitatively coupled to the same positive `K` that controls the waiting reserve.

The final M-record condition additionally gives

`rho P >= 1-a`.

Writing `t=(1-a)/rho` and `R=P-t`, the record-span theorem specializes to

`K >= R/a+t(c+rho r)/a^2`

`  = P/a-(1-a)R/a^2`.

These two inequalities are support-cardinality independent and are the cleanest current finite-law interface to P01-B's endpoint primitive.
