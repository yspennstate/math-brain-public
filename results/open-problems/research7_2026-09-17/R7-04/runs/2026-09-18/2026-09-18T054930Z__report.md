# Mathematics

Let `A` be a proper nonempty up-class with distinct minimal witnesses

`B_1,...,B_m`,

so

`A=union_j H_{B_j}`.

Write

`k_j=|B_j|`,
`S_p=sum_j p^{k_j}`,
`g(alpha)=-alpha log(1-alpha)`.

## B11 — exact LP duality identifies the obstruction norm

Put

`r=alpha p`,
`m_A=mu_p(A)`,
`theta_J=theta_{J,alpha}(A)`.

Talagrand's dual kernel is

`h(I,J)=r^{-|I|} 1_{I subseteq J}`,

with `h(emptyset,J)=1`.

Consider

`C_{r,A}=min sum_I w_I`

subject to `w_I>=0` and

`sum_{I subseteq J} r^{-|I|} w_I >= theta_J/m_A`

for every `J subseteq S`.

The finite LP dual is

`maximize (1/m_A) sum_J theta_J lambda_J`

subject to `lambda_J>=0` and

`sum_{J supseteq I} lambda_J <= r^{|I|}`

for every `I`.

The `I=emptyset` constraint says `sum_J lambda_J<=1`. Padding missing mass at `emptyset` turns `lambda` into an `r`-spread probability law without changing the objective because a proper up-class does not contain the empty set and therefore `theta_{emptyset,alpha}(A)=0`.

Hence finite-dimensional LP duality gives the exact identity

`C_{r,A} = (1/m_A) sup_{nu r-spread} W_alpha(nu)(A)`.

Therefore the source statement at a fixed `alpha` is equivalent to

`C_{alpha p,A}<=1`

for every finite `S`, `p`, and proper nonempty up-class `A`.

This is stronger than merely restating Talagrand's Hahn-Banach direction: it isolates a scalar obstruction norm whose value can be bounded directly from witness geometry.

## B21 — a rigorous positive-overlap theorem

Define the ordered Janson overlap sum

`Delta_p = sum_{i != j, B_i cap B_j != emptyset} p^{|B_i union B_j|}`.

### Theorem

For every `0<alpha<1`, every `0<p<1`, and every `alpha p`-spread `nu`,

`W_alpha(nu)(A^c) >= exp(-g(alpha) S_p)`.

Consequently, if

`Delta_p/2 <= (1-g(alpha)) S_p`,

then

`W_alpha(nu)(A) <= mu_p(A)`.

### Proof

Sample `J~nu` and then independently retain each element of `J` with probability `alpha`, producing `K`.

Conditional on `J`, for each witness with `B_j subseteq J`, the event

`{B_j not subseteq K}`

is decreasing in the independent retention bits. Harris/FKG for product measure therefore gives

`P(K notin A | J)
 >= product_{j:B_j subseteq J}(1-alpha^{k_j}).`

Set

`lambda_j=-log(1-alpha^{k_j})`.

Then

`P(K notin A | J)
 >= exp(-sum_j lambda_j 1_{B_j subseteq J}).`

Average over `J`. Since `exp(-x)` is convex, Jensen gives

`W_alpha(nu)(A^c)
 >= exp(-sum_j lambda_j nu(H_{B_j})).`

Spreadness yields

`nu(H_{B_j}) <= (alpha p)^{k_j}`,

so

`W_alpha(nu)(A^c)
 >= exp(-sum_j g(alpha^{k_j})p^{k_j}).`

The function `g(x)=-x log(1-x)` is strictly increasing on `(0,1)`, because

`g'(x)=-log(1-x)+x/(1-x)>0`.

Since `k_j>=1`,

`g(alpha^{k_j})<=g(alpha)`,

and therefore

`W_alpha(nu)(A^c)>=exp(-g(alpha)S_p)`.

Under `mu_p`, standard Janson inequality with the ordered-pair convention gives

`mu_p(A^c) <= exp(-S_p+Delta_p/2)`.

If

`Delta_p/2 <= (1-g(alpha))S_p`,

then

`exp(-g(alpha)S_p) >= exp(-S_p+Delta_p/2)`.

Thus

`W_alpha(nu)(A^c)>=mu_p(A^c)`,

which is equivalent to the claimed domination on `A`. `QED`

### Consequence for any genuine counterexample

For every `alpha<alpha_*`, `g(alpha)<1`. Therefore a source counterexample at this `alpha` must satisfy the strict weighted-density obstruction

`Delta_p > 2(1-g(alpha))S_p`.

So below `alpha_*`, overlap by itself is no longer enough: a counterexample must have explicitly **dense weighted overlap**.

Combining the theorem with the B11 norm identity also gives, when `S_p>Delta_p/2`,

`C_{alpha p,A}
 <= [1-exp(-g(alpha)S_p)]/[1-exp(-S_p+Delta_p/2)].`

The right side is at most one under the theorem's overlap condition.

## B30 — nontrivial-core sunflowers are safe up to a stronger constant

Now localize to a sunflower:

`B_j=C union P_j`,

where `P_1,...,P_m` are pairwise disjoint nonempty petals, disjoint from the common core `C`. Put

`c=|C|>=1`,
`k_j=|P_j|`,
`q=alpha^2p`,
`T=sum_j p^{k_j}`.

### Theorem

If

`alpha <= sqrt(alpha_*) = 0.8606704615308318...`,

then every `alpha p`-spread `nu` satisfies

`W_alpha(nu)(A) <= mu_p(A)`

for every `p` whenever the minimal witnesses of `A` form a sunflower with nonempty common core.

Together with the previous run's sharp theorem for pairwise disjoint witnesses (`C=emptyset`), this implies that **every sunflower witness family is safe throughout the entire source-relevant range `alpha<=alpha_*`**.

### Proof

Occurrence of `A` after thinning requires the whole core to survive, hence

`W_alpha(nu)(A)
 <= alpha^c nu(H_C)
 <= alpha^c(alpha p)^c
 = q^c.`

The union bound over full witnesses also gives

`W_alpha(nu)(A)
 <= sum_j alpha^{c+k_j}nu(H_{B_j})
 <= q^c sum_j q^{k_j}`.

Therefore

`W_alpha(nu)(A)
 <= q^c min(1,sum_jq^{k_j})`.

Since each `k_j>=1`,

`sum_j q^{k_j}
 = sum_j alpha^{2k_j}p^{k_j}
 <= alpha^2T`.

Thus

`W_alpha(nu)(A)
 <= alpha^{2c}p^c min(1,alpha^2T)`.

Under `mu_p`, core and petals are independent and petals are mutually independent, so exactly

`mu_p(A)=p^c[1-product_j(1-p^{k_j})]`.

Using `product_j(1-x_j)<=exp(-sum_jx_j)` gives

`mu_p(A)>=p^c(1-exp(-T))`.

Set `x=alpha^2`. Because `c>=1`, it is enough to prove

`x min(1,xT) <= 1-exp(-T)`

for every `T>=0`.

For `T<=1/x`, the left side is `x^2T`, and `(1-exp(-T))/T` is decreasing, so the worst point is `T=1/x`. For `T>=1/x`, the left side is `x` and the right side is increasing, so the same endpoint is again worst. Both ranges reduce to

`x <= 1-exp(-1/x)`,

which is equivalent to

`-x log(1-x)<=1`.

Since `g` is increasing and `g(alpha_*)=1`, this is equivalent to

`x<=alpha_*`,

i.e.

`alpha<=sqrt(alpha_*)`. `QED`

## Combined structural reduction

At any `alpha<alpha_*`, a source counterexample must now satisfy both:

1. `Delta_p > 2(1-g(alpha))S_p`, so the witness system is weighted-overlap dense; and
2. its minimal witnesses are not a sunflower family, because every sunflower is safe at least through `alpha_*` (indeed nontrivial-core sunflowers are safe through `sqrt(alpha_*)`).

Thus the unresolved source geometry has been reduced to **dense-overlap, non-sunflower witness hypergraphs with incompatible overlap cores**.

This is a substantive narrowing of the gluing obstruction, but it is not a universal theorem.
