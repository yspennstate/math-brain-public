## 4. B30 — promotion theorem: the true pair law is only a polynomial tilt of the rank-2 law

Retain the preceding run's descending-reveal language.  On any finite connected graph `G=(V,E)`, `|V|=N`, a birth is a revealed vertex with no earlier neighbor, and births are exactly peaks.

For a nonempty seed set `T`, let `F(T)` be the number of orders of `V\T` that can be appended with no new birth.  Thus

`F(V)=1`,

and

`F(T)=sum_{x in partial T} F(T union {x})`,

where `partial T` is the set of unrevealed vertices adjacent to `T`.

For ordered nonadjacent vertices `(r,v)`, let `W(r,v)` be the number of full descending orders with exactly two births, first `r` and second `v`, with no restriction on the rank of `v`.

### Theorem 4.1 — rank-2 promotion

For every such `(r,v)`,

`F({r,v}) <= W(r,v) <= (N-1) F({r,v})`.      (4.1)

**Proof.**  Take an order counted by `W(r,v)` in which the second birth `v` occurs at position `k`:

`(r, x_2, ..., x_{k-1}, v, x_{k+1}, ..., x_N)`.

Because `v` is a birth, it has no neighbor among the vertices preceding it.  Move `v` to position 2.  Every `x_j` originally before `v` already had an earlier neighbor not using `v`, so it stays a nonbirth.  Every vertex originally after `v` has exactly the same set of earlier vertices after the move.  Since `r` and `v` are nonadjacent, `v` is still a birth at position 2.  Hence promotion maps every order counted by `W(r,v)` onto a valid rank-2 completion counted by `F({r,v})`.

Every rank-2 completion is itself a preimage, so the map is surjective.  For any promoted order, a preimage is determined by the position `k=2,...,N` to which `v` is demoted.  Therefore each fiber has size between 1 and `N-1`, proving (4.1).  QED.

For the unordered pair weight

`H({r,v}) := W(r,v)+W(v,r)`,

symmetry of `F({r,v})` gives

`2 F({r,v}) <= H({r,v}) <= 2(N-1) F({r,v})`.     (4.2)

There is also an exact fiber statistic.  For a rank-2 completion

`sigma=(r,v,u_3,...,u_N)`,

define `J_v(sigma)` to be the first `t>=3` at which either `u_t` is adjacent to `v`, or `u_t` has no earlier neighbor in `{r,u_3,...,u_{t-1}}`.  Demoting `v` to position `k` is valid exactly for `k=2,...,J_v-1`, so the promotion fiber has size `J_v-2`.  Consequently

`W(r,v)=F({r,v}) E[J_v-2]`                         (4.3)

under the uniform rank-2 completion law for `(r,v)`.

### Pair-law consequence

Let `Q_G` be the probability law on unordered nonadjacent pairs with weight `F({r,v})`, and let `P_G` be the actual unordered pair of peaks conditioned on exactly two peaks.  From (4.2), for every pair event `A`,

`Q_G(A)/(N-1) <= P_G(A) <= (N-1) Q_G(A)`.        (4.4)

This is the key new reduction.  On the `n x n` square, `N=n^2`.  Therefore if, for some fixed `eps>0`,

`Q_n{d(r,v) <= eps n} = o(n^-2)`,                 (4.5)

then the actual conditioned law satisfies

`P{rho_n <= eps n | two peaks} -> 0`,

and hence `liminf E[rho_n/n | two peaks] >= eps`, refuting the source.  Conversely, sufficiently strong rank-2 concentration near the diagonal transfers to a YES proof.  Any exponential-rate large-deviation statement for `Q_n` survives the `n^2` promotion loss automatically.

Thus the uncontrolled rank of the second peak is no longer an exponential-scale obstruction.

## 5. B6 — exact solved deformation on the path

Take the path `P_N={1,...,N}` and two nonadjacent seeds `i<j`.  Set

`L=i-1`, `g=j-i-1`, `R=N-j`, `m=N-2`,

so `L+g+R=m` and `g>=1`.

### Theorem 5.1 — exact rank-2 path completion count

`F_{P_N}({i,j}) = (N-2)! 2^(g-1) / (L! g! R!)`.  (5.1)

**Proof.**  The left tail can only be added in the forced order `i-1,i-2,...,1`; the right tail in the forced order `j+1,j+2,...,N`.  In the middle gap, until the last gap vertex is filled one may choose to advance from the left or right seed component, giving exactly `2^(g-1)` internal middle-gap orders.  For each such order, the left/middle/right sequences of lengths `L,g,R` can be interleaved in `m!/(L!g!R!)` ways.  Multiply.  QED.

Summing over all seed pairs yields

`sum_{i<j-1} F({i,j}) = (4^m-2^m)/2`.             (5.2)

Under the rank-2 pair law `Q_{P_N}` the gap has exact distribution

`Q(g=q)=binom(m,q)/(2^m-1), q=1,...,m`,           (5.3)

which is `Binomial(m,1/2)` conditioned on being positive.

Because the true two-peak pair law differs from `Q_{P_N}` by at most the polynomial factor `N-1`, Hoeffding gives, for every fixed `eps>0`,

`P_2(|rho_N/N-1/2|>eps)`

` <= (N-1) * 2 exp(-2 eps^2 N^2/(N-2)) / (1-2^(-(N-2))) -> 0`.     (5.4)

Hence

`rho_N/N -> 1/2` in probability under the true exactly-two-peak path law.  This is a solved-case mechanism check, not a claim of new one-dimensional literature: the prior random-permutation/peak literature already records macroscopic separation on the line.

The important transfer lesson is that an exponential spatial preference in the rank-2 law dominates the entire polynomial promotion tilt.

## 6. B21 — exact frontier-growth Feynman–Kac representation

For any nonempty seed set `T`, introduce an **auxiliary** frontier process.  Starting at `S_0=T`, choose each next vertex uniformly from `partial S_k` and set `S_{k+1}=S_k union {X_{k+1}}`.

This auxiliary process is not the actual conditional labeling law.  It is only a proposal measure.

Every valid no-further-birth completion path has proposal probability

`prod_k |partial S_k|^-1`.

Therefore multiplying by the reciprocal Radon–Nikodym weight and summing paths gives the exact identity

`F(T) = E_T^fr [ prod_{k=0}^{N-|T|-1} |partial S_k| ]`.            (6.1)

Equivalently, `F(T)` is a discrete Feynman–Kac partition function with potential

`V(S)=log |partial S|`.                                            (6.2)

For the square source, the remaining object is now a two-root free energy as a function of seed displacement.

This route also diagnoses why the naive next lemma proposed in the previous report was too optimistic.  A one-step move of a seed changes only local initial geometry, but the product (6.1) can alter boundary potentials for `Theta(N)` future steps.  The path formula (5.1) is an exact witness: local seed relocation can lead to exponentially large completion-weight changes after accumulation.  So a bounded-degree argument alone cannot yield the desired global pair-weight ratio.
