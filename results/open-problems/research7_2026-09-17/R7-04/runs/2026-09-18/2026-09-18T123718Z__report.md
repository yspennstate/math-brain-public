## 3. Counterexample-first obstruction

The source scope itself supplies a decisive obstruction to pretending that `D0101` is the universal theorem “positive odometer forces an infinite odometer.”

### Lemma

At sleep rate `lambda = infinity`, start from the deterministic translation-ergodic state with exactly one **active** particle at every site of `Z^d`. Then

`m(x) = 1` for every `x` almost surely.

### Proof

For `lambda = infinity`, a lone active particle that legally topples executes a sleep action with probability one. Initially every site contains exactly one active particle and therefore is unstable. Stabilize any finite set `V`. Topple every site of `V` once. Because each first toppling is a sleep action, no particle jumps; each toppled site changes from one active singleton to one sleeping singleton and is stable. Thus the configuration on `V` is stable after exactly one toppling per site. By the abelian property, the finite-volume stabilizing odometer is identically one on `V`. Passing to the standard increasing-volume definition gives `m(x)=1` for every fixed site `x`. Consequently

`P(m(0) >= 1) = 1`, but `P(m(0) = infinity) = 0`.

This is an exact mathematical obstruction, not a simulation. It shows that any full answer to the literal source must specify nontrivial conditions excluding this regime; silently changing `D0101` into a universal implication would change the problem.
