# Exact blocking formula

The previous B11 reduction gives an exact finite obstruction norm. Fix `alpha,p,A`, put

`r=alpha p`, `m_A=mu_p(A)`, `theta_J=theta_{J,alpha}(A)`.

Then

`C_{r,A} = min sum_I w_I`

subject to

`w_I >= 0`,

`sum_{I subseteq J} r^(-|I|) w_I >= theta_J/m_A` for every `J subseteq S`.

Its finite LP dual is

`maximize (1/m_A) sum_J theta_J lambda_J`

subject to

`lambda_J >= 0`,

`sum_{J supseteq I} lambda_J <= r^{|I|}` for every `I subseteq S`.

Padding unused mass at the empty set identifies the dual feasible region with `r`-spread probability laws, so

`C_{r,A} = (1/m_A) sup_{nu r-spread} W_alpha(nu)(A)`.

Therefore the full source at a fixed `alpha` is exactly

`C_{alpha p,A} <= 1`

for every finite `S`, every `p`, and every proper nonempty up-class `A`.

The most recent B27 cover construction is a special feasible primal solution. With

`q=alpha^2 p`

and a principal-upset cover `C` of `A`, it spends nonempty dual mass

`sum_{I in C} q^{|I|}/mu_p(A)`.

Writing

`Phi_q(A) = min_C sum_{I in C} q^{|I|}`,

that construction closes the instance whenever

`Phi_q(A) <= mu_p(A)`.

The exact blocker is now:

> **Shared-mass dual gap.** Prove `C_{alpha p,A}<=1` even when `Phi_{alpha^2p}(A)>mu_p(A)`, by finding dual mass that simultaneously services many `J`-constraints; or exhibit an exact instance for which the full LP value `C_{alpha p,A}>1`.

The cover condition is sufficient, not necessary. Failure of `Phi_q(A)<=mu_p(A)` is therefore a failure of the current construction, **not** a source counterexample.

# Simplest explicit cover-resistant stress test

The previous report's witness-count barrier showed only that a two-uniform counterexample needs at least four minimal witnesses; it did **not** prove that four witnesses are actually dangerous. The natural first cycle tests make that distinction visible.

Let `A_{C_m}` be the up-class whose minimal witnesses are the `m` edges of a cycle `C_m`. For a principal-upset cover of this two-uniform class, every minimal edge must contain either a selected singleton endpoint or itself as a selected edge. Thus for a chosen vertex set `U`, the cheapest completion has cost

`q |U| + q^2 e(C_m[V\U])`.

When `q<1/2`, selecting one vertex can replace at most two edge terms and changes the cost by at least

`q - 2q^2 = q(1-2q) > 0`.

So in that regime

`Phi_q(A_{C_m}) = m q^2`.

In the nontrivial source regime `p<alpha<=alpha_*<3/4`,

`q=alpha^2p < alpha^3 < 27/64 < 1/2`,

so this formula applies.

### Why the anticipated four-cycle is not the blocker

For `C_4`, the Bernoulli probability is exactly

`mu_p(A_{C_4}) = p^2(2-p)^2`.

The cover criterion becomes

`4 alpha^4 p^2 <= p^2(2-p)^2`.

Since `p<alpha<3/4`, it is enough that

`2 alpha^2 <= 2-alpha`,

and indeed

`2 alpha^2 + alpha < 2*(3/4)^2 + 3/4 = 15/8 < 2`.

Thus the obvious four-witness cycle is still handled by the existing cover certificate throughout the only source-relevant `alpha` range.

For `C_5`, independent-set counting gives

`mu_p(A_{C_5}) = p^2(5-5p+p^3)`.

Again `Phi_q=5alpha^4p^2`. The function `5-5p+p^3` is decreasing on `[0,1]`, and for `p<alpha<3/4`,

`5-5p+p^3 > 5-5*(3/4)+(3/4)^3 = 107/64`,

whereas

`5 alpha^4 < 5*(3/4)^4 = 405/256 < 428/256 = 107/64`.

So `C_5` is also cover-certified in the nontrivial regime.

# Attempted routes and why each stopped

1. **Singleton negation family (B2).** It rigorously gives `alpha_dom<=alpha_*`, but cannot provide a positive lower bound on `alpha_dom`.

2. **Chen-Li two-product bridge (B18).** `W_alpha(nu)` is `alpha^2p`-spread, and Li supplies a cover by two product-Bernoulli marginals. The missing independence/one-product compression is exactly the same sharing issue in another form. Independence is false for arbitrary spread laws, so any proof must exploit the special thinning representation.

3. **Disjoint-witness Jensen argument (B25).** Complete and sharp on pairwise disjoint minimal witnesses; it fails precisely when witness survival events overlap.

4. **Exact dual LP (B11).** It identifies `C_{r,A}` without supplying a dimension-free upper bound in the dense-overlap regime.

5. **Harris/Janson route (B21).** It proves domination when the weighted overlap sum is small enough. A counterexample, if any, must lie beyond that sparse-overlap inequality, so repeating Janson with altered constants is not a route.

6. **Sunflower localization (B30).** All sunflower witness families are safe through the source-relevant range. Arbitrary dense overlap has incompatible cores and does not decompose without interaction loss.

7. **Symmetry reduction (B14).** Powerful when `A` has a large automorphism group, but generic witness systems can have trivial symmetry. It is nevertheless useful for the selected cycle recovery because `C_6` has dihedral symmetry.

8. **Exact triangle extremizer (B24).** The smallest dense non-sunflower two-uniform geometry is safe all the way to `alpha_*`; it removes rather than identifies the blocker.

9. **Parameter/Russo flow (B5).** The individual gap decreases along fixed spread scale, but there is no dimension-free barrier preventing a first zero crossing.

10. **Asymmetric three-edge path (B15).** Also safe on a stronger parameter range; three-witness geometries are exhausted as candidates by the later witness-count theorem.

11. **Reliability/inclusion-exclusion translation (B18).** It exposes the obstruction: spreadness only gives upper bounds on union marginals, which have the wrong direction for the negative even-cluster terms. It does not manufacture the missing lower information.

12. **Principal-cover dual construction (B27).** It gives an explicit universal `eta` whenever `Phi_q(A)<=mu_p(A)` and yields the witness-count barrier. The exact six-cycle calculation above shows that this sufficient condition genuinely fails inside the viable parameter region, so merely optimizing the same cover weights cannot close the source.

# Missing ingredient

The missing object is not another local overlap estimate. It is a **shared-mass dual construction**.

A successful positive proof needs a rule that assigns a single probability measure `eta_A` on subsets `I` so that

`theta_{J,alpha}(A)
 <= mu_p(A) * integral h(I,J) d eta_A(I)`

for **all** `J` simultaneously, while reusing the same mass across many witness constraints. The six-cycle stress point shows why paying independently for every minimal witness can exceed total mass one. The exact LP says the only honest alternatives are:

- exploit smaller sets `I` whose mass contributes to several `J`-constraints at once;
- exploit empty-set mass where the right-hand side can be shared globally;
- or prove the full LP infeasible and thereby produce a source-valid counterexample.

The special `alpha`-thinning representation has not yet been converted into the required correlation/sharing inequality. That is the missing ingredient.

### External analogue
