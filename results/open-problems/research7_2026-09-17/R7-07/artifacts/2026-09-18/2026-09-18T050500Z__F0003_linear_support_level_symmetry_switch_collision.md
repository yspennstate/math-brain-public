## 1. Idea before code

The previous run proved that every kernel support is a failure of unique-neighbour expansion and used a coarse witness count to exclude supports `3 <= k <= n^(1/20)` at the source scale. That exponent `1/20` was not intrinsic. The matching obstruction has a much cleaner combinatorial encoding: every half-edge of the support belongs either to an internal matched pair or to a group of at least two support half-edges which land at one outside vertex. Thus the `dk` support half-edges admit a set partition into blocks of size at least two.

Counting these **witness partitions before counting graphs** gains the missing factorial and pushes the support reduction from a tiny power of `n` all the way to a fixed positive fraction of `n`.

The second idea is to quotient a kernel vector by its coordinate-level symmetry. In the cubic case an exactly two-valued kernel vector forces a rigid `1:2` equitable partition, which can be counted exactly in the configuration model and is exponentially unlikely.

Finally, the two-switch action admits an exact collision statistic on oriented edge-types. This turns “most switches destroy a diffuse kernel vector” into a deterministic count, while also isolating the remaining rank-versus-certificate gap honestly.

## 2. B27 — swap the quantifiers: count support witnesses first

### Lemma 2.1 — canonical witness partition

Let `G` be a graph generated by the fixed-`d` configuration model, let `S` be a vertex set of size `k`, and let the `h=dk` half-edges incident to `S` be labelled. Suppose `S` is unique-neighbour-bad, meaning that no vertex of `S^c` receives exactly one edge from `S`.

Then the `h` labelled half-edges of `S` possess a canonical partition into blocks of size at least two:

1. every configuration edge with both half-edges in `S` contributes the two `S` half-edges as one block;
2. for every outside vertex `v` touched by `S`, the set of all `S` half-edges paired to half-edges at `v` is one block.

Every block in (2) has size at least two by unique-neighbour-badness. Hence, if the partition has `g` blocks,

`g <= floor(h/2)`.

This partition is determined by the matching, so union-bounding over possible witness partitions loses no logical information.

### Lemma 2.2 — weighted count for one fixed support

Fix `d>=3`. There is an absolute constant `C>1` such that, whenever `k/n` is sufficiently small (uniformly in `n`) and `S` is a fixed `k`-set,

`P_config(S is unique-neighbour-bad) <= h [ C^2 h/n ]^(h/2) C^h`,

and therefore, after absorbing constants,

`P_config(S is unique-neighbour-bad) <= h C_0^h (h/n)^(h/2)`

for an absolute `C_0`.

#### Proof

Fix a set partition `pi` of the `h` labelled `S` half-edges into `g` blocks of sizes at least two. To realize `pi` as the canonical witness partition, some size-two blocks are internal matching edges and every other block is assigned to an outside vertex.

Let `e` be the number of blocks designated internal. There are at most `2^g` ways to choose the internal designation; allowing impossible designations only overcounts. Then:

- the `e` internal blocks prescribe `e` matching pairs;
- the `g-e` external blocks may be assigned outside vertices in at most `n^(g-e)` ways, where we deliberately drop the distinctness requirement;
- if the external blocks contain `h-2e` source half-edges in total, each may choose one of at most `d` target half-edges at its assigned outside vertex, giving at most `d^(h-2e)` assignments.

For every valid choice with disjoint target half-edges, the number of prescribed matching pairs is

`q = e + (h-2e) = h-e`.

Write `N=dn` for the total number of configuration half-edges. If `k/n <= 1/4`, then `q<=h<=N/4`, and the probability that a given set of `q` disjoint pairs occurs in a uniform perfect matching is

`1 / [(N-1)(N-3)...(N-(2q-1))] <= (2/N)^q`.

Hence the probability contribution of the fixed partition `pi`, summed over all internal/external designations and all outside assignments, is at most

`2^g n^(g-e) d^(h-2e) (2/(dn))^(h-e)`

`= 2^(g+h-e) d^(-e) n^(g-h)`

`<= 2^(3h/2) n^(g-h)`,

because `g<=h/2`.

It remains to count partitions with `g` blocks without throwing away another factor `h^h`. Every partition has a canonical root in each block, namely its least label. Encode the partition by (i) its set of non-roots and (ii) for every non-root, the label of its block root. There are at most `2^h h^(h-g)` such encodings. Therefore the total contribution of all `g`-block partitions is at most

`2^h h^(h-g) * 2^(3h/2) n^(g-h)`

`= 2^(5h/2) (h/n)^(h-g)`.

Since `h-g >= h/2`, and since `h/n<1` after choosing the eventual linear cutoff sufficiently small, this is at most

`2^(5h/2) (h/n)^(h/2)`.

Summing over at most `h` possible values of `g` proves the claim with `C_0=2^(5/2)` (or any larger absolute constant). QED.

### Theorem 2.3 — linear-support suppression at the source scale

Fix `d>=3`. There exists a constant `delta_d>0` such that, for a uniformly random simple `d`-regular graph `G_{n,d}`,

`P(exists 0 != x in ker A_{n,d} with 3 <= |supp x| <= delta_d n) = o(n^(2-d)).`

Equivalently, modulo the support-two twin event, every singularity mechanism capable of contributing at the source scale `n^(2-d)` must have **linear support**.

#### Proof

Let `U_k` be the event that some `k`-set is unique-neighbour-bad. By Lemma 2.2, with `h=dk`,

`P_config(U_k)`
`<= binom(n,k) * dk * C_0^(dk) * (dk/n)^(dk/2)`
`<= dk [ K_d (k/n)^(d/2-1) ]^k`

for a constant

`K_d = e C_0^d d^(d/2)`.

Choose `delta_d>0` so small that

`delta_d <= min{1/(2d),1/4}`

and

`K_d delta_d^(d/2-1) <= 1/4`.

Then the displayed bound is valid and has geometric base at most `1/4` for every `k<=delta_d n`.

Put

`a=(d/2)-1=(d-2)/2 >0`.

Split the sum over `3<=k<=delta_d n` at `L=C_d' log n`, where `C_d'` is chosen large enough that `4^(-L)=o(n^{-(d-2)})`.

For `k>=L`,

`sum_{k=L}^{delta_d n} P_config(U_k) <= O_d(sum k 4^(-k)) = o(n^{-(d-2)}).`

For `3<=k<L`, use `k<=L` in the base:

`P_config(U_k) <= dk [ K_d (L/n)^a ]^k`.

The largest contribution on the polynomial scale occurs at the smallest possible `k`, so

`sum_{k=3}^{L-1} P_config(U_k)`
`<= n^{-3a+o(1)}`
`= n^{-3(d-2)/2+o(1)}`
`= o(n^{-(d-2)}).`

For fixed `d`, the probability that the configuration model is simple tends to a positive constant, so conditioning on simplicity changes all these upper bounds by only a fixed multiplicative factor.

Finally, every support of a kernel vector is unique-neighbour-bad by the previous run's Lemma 2.1. This proves the theorem. QED.

## 3. B14 — quotient by coordinate-level symmetry

The two-switch heuristic says that kernel vectors with few coordinate levels are the highly atomic case. The first nontrivial case can be classified and counted exactly.

### Lemma 3.1 — exact classification of two-valued cubic kernel vectors

Let `G` be a finite simple 3-regular graph and suppose `0 != x in ker A(G)` takes exactly two values `{a,b}` on all vertices.

Then neither value is zero, and after possibly interchanging the labels there is a partition

`V(G)=S disjoint_union T`,

with

`|S|=n/3`, `|T|=2n/3`,

such that every vertex has exactly one neighbour in `S` and two neighbours in `T`. Moreover the two coordinate values satisfy

`a+2b=0`.

Conversely, every such equitable partition produces a one-dimensional family of two-valued kernel vectors by assigning `a` to `S`, `b` to `T`, with `a+2b=0`.

#### Proof

If one value were zero, say the values were `{0,a}` with `a!=0`, then for every vertex the row equation would be

`(# of a-valued neighbours)*a = 0`.

Thus no vertex could have an `a`-valued neighbour, impossible if any vertex itself has value `a` in a 3-regular graph. Hence `a,b` are both nonzero.

Let `k(v)` be the number of neighbours of `v` carrying value `a`. The row equation at every vertex is

`k(v) a + (3-k(v)) b = 0`.

Because `a!=b`, the left side is affine in the integer `k(v)` with nonzero slope, so there is at most one possible value `k` common to every vertex. Since both `a,b` are nonzero, `k` cannot be `0` or `3`; hence `k=1` or `k=2`.

If `k=1`, every vertex has exactly one neighbour in the `a`-class `S`. A vertex of `S` therefore has one neighbour in `S` and two in `T`, while a vertex of `T` has one neighbour in `S` and two in `T`. Counting cross edges from the two sides gives

`2|S| = |T|`,

so `|S|=n/3`, `|T|=2n/3`, and the row equation is `a+2b=0`.

If `k=2`, interchange the names of the two value classes to obtain the same description. The converse is immediate. QED.

### Theorem 3.2 — two-valued cubic kernel vectors are exponentially rare

For a uniformly random simple cubic graph `G_{n,3}`, the probability that `A(G_{n,3})` has a nonzero kernel vector taking exactly two values on all vertices is

`exp(-(c_2+o(1)) n)`

up to an upper bound, where

`c_2 = log(3) - (4/3)log(2) > 0`.

More explicitly,

`P(exists a two-valued kernel vector) <= exp((log(2^(4/3)/3)+o(1)) n)`,

and

`2^(4/3)/3 = 0.839947... < 1`.

#### Proof

By Lemma 3.1 it suffices to count partitions `S,T` with `|S|=n/3`, `|T|=2n/3` such that every `S` vertex has one neighbour in `S` and every `T` vertex has one neighbour in `S`.

Write `n=3m`. Such a partition is impossible unless `m` is even; otherwise the induced 1-regular graph on `S` cannot exist. Assume `m` even and work in the cubic configuration model, which has `9m` half-edges.

For a **fixed** partition with `|S|=m`, `|T|=2m`, the number of perfect matchings realizing the required degree pattern is exactly

`3^(3m) (m-1)!! (2m)! (4m-1)!!`.

Indeed:

1. at each `S` vertex choose the one half-edge used inside `S`: `3^m` choices;
2. at each `T` vertex choose the one half-edge used across to `S`: `3^(2m)` choices;
3. pair the selected `S` half-edges internally: `(m-1)!!` choices;
4. biject the remaining `2m` `S` half-edges to the selected `2m` `T` half-edges: `(2m)!` choices;
5. pair the remaining `4m` `T` half-edges: `(4m-1)!!` choices.

The total number of configuration matchings is `(9m-1)!!`. Hence the expected number `Z` of such vertex partitions is exactly

`E_config Z = binom(3m,m) 3^(3m) (m-1)!! (2m)! (4m-1)!! / (9m-1)!!`.

Stirling's formula gives

`(1/n) log E_config Z`
`= -log 3 + (4/3)log 2 + o(1)`
`= log(2^(4/3)/3) + o(1)`.

Since `2^(4/3)/3<1`, Markov's inequality yields the exponential upper bound in the configuration model. Conditioning on simplicity costs only a fixed multiplicative factor for cubic graphs and therefore does not change the exponential rate. QED.

### Interpretation

The atomic extreme “kernel vector with only two global coordinate values” is exponentially smaller than the conjectural twin scale `n^{-1}`. Consequently, if the sharp exponent fails because of a linear-support kernel vector, that vector must either have at least three global coordinate values or lie in a more subtle near-equitable regime.

This is a source-relevant narrowing, not a proof that all bounded-level vectors are negligible.

## 4. B10 — derandomize certificate destruction under two-switches

The previous run proved that for a legal switch

`ab, cd -> ac, bd`,

a fixed kernel vector `x` survives iff

`x_b=x_c` and `x_a=x_d`.

The following packages that identity into an exact group-action statistic.

### Definition 4.1 — oriented edge-type collision

Let `G` be a simple `d`-regular graph and `x` any real vector on its vertices. Sample a uniformly random oriented edge `(u,v)` from the `dn` oriented edges. For coordinate values `r,s`, define

`q_x(r,s) = P(x_u=r, x_v=s)`.

Because every undirected edge contributes both orientations,

`q_x(r,s)=q_x(s,r)`.

Define the collision statistic

`C_edge(x) = sum_{r,s} q_x(r,s)^2`.

The sum is over the finitely many coordinate values actually taken by `x`.

### Theorem 4.2 — exact asymptotic switch-survival fraction

Fix `d`. For any simple `d`-regular graph `G` on `n` vertices and any vector `x`, among ordered pairs of oriented edges which form a legal two-switch, the fraction for which the switch preserves `x` is

`C_edge(x) + O_d(1/n)`.

Consequently, if `C_edge(x) <= 1-eta`, then for all sufficiently large `n` there are

`Omega_d(eta n^2)`

ordered legal two-switches which **destroy this particular kernel certificate**.

#### Proof

Choose two oriented edges `(a,b)` and `(c,d)` independently and uniformly from the `dn` oriented edges, ignoring legality for the moment. By the exact switch-preservation identity, `x` survives the cross-switch iff

`x_b=x_c` and `x_a=x_d`.

If the first oriented edge has type `(r,s)`, the second must have type `(s,r)`. Therefore the preservation probability over all ordered oriented-edge pairs is exactly

`sum_{r,s} q_x(r,s) q_x(s,r)`
`= sum_{r,s} q_x(r,s)^2`
`= C_edge(x)`.

Now remove illegal pairs. For a fixed first oriented edge, only `O_d(1)` second oriented edges share an endpoint with it, and only `O_d(1)` second oriented edges make one of the proposed cross edges already present. Thus only `O_d(n)` of the `d^2 n^2` ordered pairs are illegal. Removing them changes both numerator and denominator by `O_d(n)`, hence changes the fraction by `O_d(1/n)`.

If `C_edge(x)<=1-eta`, the destroyed fraction is at least `eta-O_d(1/n)`, which yields `Omega_d(eta n^2)` legal certificate-destroying switches. QED.

### Example 4.3 — the two-valued equitable vector

For the partition in Lemma 3.1, the oriented edge-type masses are

`q(a,a)=1/9`,
`q(a,b)=q(b,a)=2/9`,
`q(b,b)=4/9`.

Thus

`C_edge(x) = (1+4+4+16)/81 = 25/81`.

So asymptotically a fraction `56/81` of legal two-switches destroy that kernel vector. Theorem 3.2 shows independently that graphs carrying this exact atomic pattern are already exponentially rare.
