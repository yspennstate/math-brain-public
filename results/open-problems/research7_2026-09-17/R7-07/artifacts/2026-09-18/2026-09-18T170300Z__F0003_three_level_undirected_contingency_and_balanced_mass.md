## 1. B22 — exact point where the directed argument stops transferring

Nguyen--Pan's directed configuration model is generated by a uniformly random permutation of outgoing onto incoming stubs. For a fixed residue profile their Claim 2.1 turns the null-row count into a probability for a sum of **independent** local zero-sum multiplicity vectors. Their inverse characteristic-function theorem (Theorem 3.3) then identifies the structured phase centers responsible for slow decay.

For an undirected configuration there is only one set of half-edges and one perfect matching. If `H_ab` denotes the number of half-edges from residue class `a` paired to residue class `b`, then necessarily

\[
H_{ab}=H_{ba}.
\]

Thus the directed iid-walk factorization does not survive. What does survive is the local multiplicity-vector language. In the undirected model it becomes a **symmetric contingency problem**, which can be counted exactly.

## 2. B18 — exact finite-support contingency formula

Work in the cubic configuration model on `n` labelled vertices. Fix distinct residues `z_1,...,z_k in Z/QZ` and a deterministic row `y`. Put

\[
V_a=\{i:y_i=z_a\},\qquad N_a=|V_a|.
\]

The allowed local neighbour-color types are

\[
\mathcal T=\left\{m=(m_1,...,m_k)\in\mathbb Z_{\ge0}^k:
\sum_bm_b=3,\quad \sum_bm_bz_b=0\pmod Q\right\}.
\tag{2.1}
\]

For each source class `a` and type `m`, let `x_{a,m}` count source vertices of that type. Define

\[
H_{ab}(x)=\sum_{m\in\mathcal T}x_{a,m}m_b.
\tag{2.2}
\]

Call `x` feasible if

\[
\sum_mx_{a,m}=N_a,\qquad H_{ab}=H_{ba}\ (a\ne b),\qquad H_{aa}\text{ is even}.
\tag{2.3}
\]

### Theorem 2.1

The number `F(y)` of perfect matchings of the `3n` labelled half-edges for which `Ay=0 mod Q` is

\[
\boxed{
F(y)=\sum_{x\ {m feasible}}
\left[\prod_a\frac{N_a!}{\prod_mx_{a,m}!}\right]
\left[\prod_{a,m}\left(\frac{3!}{\prod_bm_b!}\right)^{x_{a,m}}\right]
\left[\prod_{a<b}H_{ab}!\right]
\left[\prod_a(H_{aa}-1)!!\right].
}
\tag{2.4}
\]

Hence

\[
\boxed{\Pr_{\rm conf}(Ay=0)=F(y)/(3n-1)!!.}
\tag{2.5}
\]

#### Proof

Every pairing satisfying `Ay=0` uniquely determines the local multiplicity type of every vertex, hence a feasible table `x`. Conversely fix such an `x`. First choose, in source class `a`, which vertices receive each type; this gives `N_a!/prod_m x_{a,m}!`. At a type-`m` vertex, assign its three labelled stubs to target colors in `3!/prod_bm_b!` ways. For `a<b`, feasibility provides equal sets of `H_ab=H_ba` stubs and they can be bijectively paired in `H_ab!` ways. The `H_aa` same-color stubs can be paired in `(H_aa-1)!!` ways. These choices are disjoint across tables and reconstruct every null pairing exactly once. Dividing by the `(3n-1)!!` perfect matchings gives (2.5). ∎

This is the exact undirected replacement for the directed independent-walk formula. For fixed support size it converts modular nullity into finite-dimensional entropy optimization; uniform control when support grows with `Q` is still missing.

## 3. B9 — solve the STUCK1 balanced three-level test exactly

Assume

\[
n\equiv0\pmod6,\qquad Q>6,\qquad \gcd(Q,6)=1,
\]

and fix a unit `u mod Q`. Consider rows with

\[
y_i\in\{-u,0,u\},\qquad N_-=N_0=N_+=N:=n/3.
\tag{3.1}
\]

Because a sum of three labels from `{-1,0,1}` lies in `[-3,3]`, zero modulo `Q>6` means literal integer zero. The only allowed local multisets are

\[
\{0,0,0\},\qquad\{-1,0,1\}.
\tag{3.2}
\]

Let `a_s` be the number of `000` vertices in source class `s`. A source class of size `N` then sends

\[
H_{s0}=N+2a_s,\qquad H_{s,-}=H_{s,+}=N-a_s.
\tag{3.3}
\]

Undirected balance between minus and zero gives

\[
N+2a_-=N-a_0,
\]

so `2a_-=-a_0`. Nonnegativity forces `a_-=a_0=0`; balance between plus and zero then forces `a_+=0`.

### Lemma 3.1

For a balanced three-level row, `Ay=0` iff **every vertex has exactly one neighbour in each of the three residue classes**.

This makes the count explicit.

### Theorem 3.2 (fixed-row exact probability)

For every fixed balanced row (3.1),

\[
\boxed{
\Pr_{\rm conf}(Ay=0)=
\frac{6^n((N-1)!!)^3(N!)^3}{(3n-1)!!}.
}
\tag{3.4}
\]

Every pairing counted in the numerator is simple.

#### Proof

Each vertex has one stub aimed at each color class, giving `3!=6` assignments per vertex. Within each of the three classes the `N` internally aimed stubs form a perfect matching, giving `(N-1)!!` each. Between every pair of distinct classes, the `N` aimed stubs on each side are matched by a bijection, giving `N!`; there are three cross pairs. This yields the numerator.

A loop would require two same-target stubs at one vertex, impossible because each vertex has only one stub aimed at its own class. Parallel edges are likewise impossible because a vertex has only one stub aimed at any fixed target class. ∎

Conditioning the cubic configuration model on simplicity yields the uniform simple cubic graph, so

\[
\Pr_{\rm simple}(Ay=0)=\frac{1}{P_{\rm simple}(n,3)}
\frac{6^n((N-1)!!)^3(N!)^3}{(3n-1)!!},
\tag{3.5}
\]

and the standard fixed-degree configuration theorem gives `P_simple(n,3)->e^{-2}`.

## 4. Aggregate mass of all balanced AP rows

There are `n!/(N!)^3` ordered partitions into minus/zero/plus classes and `phi(Q)` units `u`. The representation is exactly two-to-one under

\[
(u,V_-,V_0,V_+)\leftrightarrow(-u,V_+,V_0,V_-),

\[
\frac{\varphi(Q)}2\frac{n!}{(N!)^3}.
\tag{4.1}

\[
\boxed{

\frac{\varphi(Q)}2

\tag{4.2}

\[
\boxed{
\mathbb E_{\rm conf}S_{Q,bal3}(A)
\sim \varphi(Q)\sqrt{2\pi n}\left(\frac23\right)^n,

\tag{4.3}

\[
\boxed{

\tag{4.4}

Hence for every polynomially bounded modulus `Q=n^{O(1)}` this entire balanced three-level stratum has expected mass `e^{-Omega(n)}`.

## 5. The entire symmetric three-level AP family collapses to one parameter

\[
