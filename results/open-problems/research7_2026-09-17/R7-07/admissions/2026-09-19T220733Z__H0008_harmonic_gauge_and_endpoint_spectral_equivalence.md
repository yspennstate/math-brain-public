# Part I. B12 — the Renyi tilt is an exact harmonic coboundary

## 2. A one-edge conservation identity

For every positive-conductance child `u` of `v`, (1.1) gives

\[
\boxed{
1-B_v
=p_v(u)\frac{B_v}{B_u}.
}
\tag{2.1}
\]

Indeed

\[
p_v(u)\frac{B_v}{B_u}
=\frac{B_u}{S_v}\frac{S_v}{(1+S_v)B_u}
=\frac1{1+S_v}
=1-B_v.
\]

This identity is the conserved quantity missed by the row-mass form (1.5).

## 3. Exact harmonic-gauge theorem

### Theorem R7-07-H0008-G1

For every real `epsilon` for which the displayed expressions are finite,

\[
\boxed{
(\widehat P_\epsilon f)(v)
=(1-B_v)\sum_up_v(u)
\left(\frac{B_v}{B_u}\right)^\epsilon f(u).
}
\tag{3.1}
\]

If `X_0=o,X_1,...` is a harmonic ray generated by `K_H`, then for every integer `n>=1`,

\[
\boxed{
\widehat P_\epsilon^nf(o)
=B_o^\epsilon E_H^o\!\left[
\prod_{r=0}^{n-1}(1-B_{X_r})
\,B_{X_n}^{-\epsilon}f(X_n)
\right].
}
\tag{3.2}
\]

Equivalently, if `theta(v)` is the harmonic cylinder mass of a level-`n` vertex,

\[
\boxed{
\widehat P_\epsilon^n1(o)
=B_o^{1+\epsilon}
\sum_{|v|=n,\,B_v>0}
\frac{\theta(v)^2}{B_v^{1+\epsilon}}.
}
\tag{3.3}
\]

### Proof

From the definition,

\[
\begin{aligned}
(\widehat P_\epsilon f)(v)
&=B_v^{1+\epsilon}
\sum_u\frac{B_u^2}{S_v^2}B_u^{-1-\epsilon}f(u)\\
&=\sum_u
\frac{B_v^{1+\epsilon}B_u^{1-\epsilon}}{S_v^2}f(u).
\end{aligned}
\]

Using `B_v/S_v=1-B_v` and `p_v(u)=B_u/S_v`, this is exactly (3.1).

Iterating (3.1) along a harmonic ray multiplies the edge factors

\[
(1-B_{X_r})
\left(\frac{B_{X_r}}{B_{X_{r+1}}}\right)^\epsilon.
\]

The power factors telescope:

\[
\prod_{r=0}^{n-1}
\left(\frac{B_{X_r}}{B_{X_{r+1}}}\right)^\epsilon
=\left(\frac{B_o}{B_{X_n}}\right)^\epsilon,
\]

giving (3.2).

For a fixed ray ending at `v`, (2.1) itself telescopes to

\[
\boxed{
\prod_{r=0}^{n-1}(1-B_{X_r})
=\theta(v)\frac{B_o}{B_v}.
}
\tag{3.4}
\]

Taking harmonic expectation in (3.2), whose path probability is another factor `theta(v)`, gives (3.3). `square`
