### 3.4 Terminal-run B3 theorem: one scalar controls rainbow closure

For a properly edge-colored graph, let

\[
P=v_0\cdots v_\ell
\]

be a rainbow path terminally maximal at endpoint `x=v_ell`, and let

\[
h(P,x)=\#\{e\ni x:\chi(e)\in C(P)\}
\]

be the number of incident endpoint edges whose colors have already appeared on the path. If `D=deg(x)` and `D-h>=2`, then there is a rainbow cycle of length at least

\[
\boxed{D-h+1.}
\]

Proof: every fresh-color endpoint edge lies inside the path. If no cycle of length at least `L=D-h+1` existed, every fresh chord would have to hit one of only `L-2` terminal path vertices; then `D<=h+L-2=D-1`, contradiction.

Thus a terminally maximal endpoint of degree `Omega(d)` with `h=o(d)` closes the cycle problem in the cross-core laboratory.

## 4. Exact unresolved bridge

The residual cross-core lemma is now:

`DEFERRED-MAXIMAL-ENDPOINT`.

Construct or certify a terminally maximal rainbow path `P` with all three properties:

1. `|P|=O(d)`;
2. the final endpoint `x` has projected degree `Omega(d)` and is terminally maximal with respect to fresh colors;
3. incidences between `x` and the previously used witness colors remain unexposed when `x` is selected.

If these hold, the binomial capture estimate and endpoint theorem give the required `Omega(d)` rainbow cycle inside the cross core.

The obstruction is **adaptivity**: the existing global minimum-degree core and a longest path in it are chosen after seeing the realized projection and can select precisely the rare high-capture endpoints that the deferred bound would rule out for a nonadaptive endpoint.
