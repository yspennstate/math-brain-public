## 4. Method B17 — exact finite-field complete-splitting formula

Let `q` be any prime power. Define

\[
F_q(m)=\prod_{j=1}^{m}(1-q^{-j}),
\qquad
F_q(0)=1,
\qquad
F_q(\infty)=\prod_{j=1}^{\infty}(1-q^{-j}).
\tag{4.1}
\]

Let `A` be uniform in `M_n(F_q)` and let

\[
T_{n,q}=\{\chi_A\text{ splits completely over }\mathbf F_q\}.
\tag{4.2}
\]

### Theorem 4.1

For every `n>=0` and every prime power `q`,

\[
\boxed{
\Pr(T_{n,q})
=
q^{-n}F_q(n)
\sum_{\substack{(m_a)_{a\in\mathbf F_q}\in\mathbf Z_{\ge0}^{q}\\
\sum_a m_a=n}}
\prod_{a\in\mathbf F_q}F_q(m_a)^{-1}.
}
\tag{4.3}
\]

#### Proof

Every split monic degree-`n` polynomial has the unique form

\[
f(x)=\prod_{a\in\mathbf F_q}(x-a)^{m_a},
\qquad
m_a\ge0,\quad\sum_a m_a=n.
\tag{4.4}
\]

Reiner's fixed-characteristic-polynomial formula says that for

\[
f=\prod_\phi \phi^{m_\phi}
\]

factored into distinct monic irreducibles,

\[
\Pr(\chi_A=f)
=
q^{-n}F_q(n)
\prod_\phi F_{q^{\deg\phi}}(m_\phi)^{-1}.
\tag{4.5}
\]

In the split case all irreducible factors are linear, so (4.5) becomes

\[
\Pr(\chi_A=f)
=
q^{-n}F_q(n)
\prod_{a\in\mathbf F_q}F_q(m_a)^{-1}.
\tag{4.6}
\]

Summing (4.6) over all weak compositions `(m_a)` proves (4.3). QED.

There are exactly

\[
\binom{n+q-1}{n}
\tag{4.7}
\]

such weak compositions. Thus the complete-splitting probability of a uniformly random monic degree-`n` polynomial is exactly

\[
R_{n,q}=q^{-n}\binom{n+q-1}{n}.
\tag{4.8}
\]

The next theorem shows that the **uniform random matrix** complete-splitting probability is within an absolute constant factor of this random-polynomial probability, uniformly in both `n` and `q`.

### Theorem 4.2 — absolute comparison

Set

\[
c_0:=F_2(\infty)=\prod_{j\ge1}(1-2^{-j})>0.
\tag{4.9}
\]

Then

\[
\boxed{
 c_0R_{n,q}
 \le
 \Pr(T_{n,q})
 \le
 e^4R_{n,q}
}
\tag{4.10}
\]

for all `n` and all prime powers `q>=2`.

#### Proof

For every `m`,

\[
F_q(\infty)\le F_q(m)\le1.
\tag{4.11}
\]

Therefore each multiplicity-vector weight in (4.3), including the common numerator, lies between

\[
F_q(\infty)
\quad\text{and}\quad
F_q(\infty)^{-q}.
\tag{4.12}
\]

The lower endpoint uses `F_q(n)>=F_q(infinity)` and all reciprocal denominator factors at least one. The upper endpoint uses `F_q(n)<=1` and at most `q` factors, each at most `F_q(infinity)^{-1}`.

Since `F_q(infinity)` is increasing in `q`,

\[
F_q(\infty)\ge c_0.
\tag{4.13}
\]

For the upper constant,

\[
\begin{aligned}
-\log F_q(\infty)
&=\sum_{j\ge1}-\log(1-q^{-j})\\
&\le\sum_{j\ge1}\frac{q^{-j}}{1-q^{-j}}\\
&\le\frac1{1-q^{-1}}\sum_{j\ge1}q^{-j}\\
&=\frac{q}{(q-1)^2}.
\end{aligned}
\tag{4.14}
\]

Hence

\[
F_q(\infty)^{-q}
\le
\exp\!\left(\frac{q^2}{(q-1)^2}\right)
\le e^4.
\tag{4.15}
\]

Multiplying these weight bounds by the number (4.7) of split polynomials proves (4.10). QED.

Equivalently,

\[
\boxed{
-\log_2\Pr(T_{n,q})
=
\log_2\!\frac{q^n}{\binom{n+q-1}{n}}+O(1),
}
\tag{4.16}
\]

where the `O(1)` is absolute.

### Consequence 1: fixed fields carry only linear information

For fixed `q`,

\[
\binom{n+q-1}{n}
=
\frac{n^{q-1}}{(q-1)!}(1+O_q(n^{-1})),
\]

so

\[
\boxed{
-\log_2\Pr(T_{n,q})
=
 n\log_2q-(q-1)\log_2n+O_q(1).
}
\tag{4.17}
\]

Thus a fixed finite field contributes only `Theta(n)` complete-splitting bits in the uniform finite-field benchmark.

### Consequence 2: even a growing field contributes at most `log_2(n!)+O(1)` benchmark bits

Because

\[
\binom{n+q-1}{n}
=
\frac{q(q+1)\cdots(q+n-1)}{n!}
\ge
\frac{q^n}{n!},
\tag{4.18}
\]

Theorem 4.2 gives

\[
\Pr(T_{n,q})\ge\frac{c_0}{n!},
\]

hence

\[
\boxed{
-\log_2\Pr(T_{n,q})
\le
\log_2(n!)-\log_2c_0.
}
\tag{4.19}
\]

For `q>=n^2`,

\[
\frac1{n!}
\le
R_{n,q}
=
\frac1{n!}\prod_{j=0}^{n-1}\left(1+\frac jq\right)
\le
\frac{e^{1/2}}{n!},
\tag{4.20}
\]

so in this large-field regime the complete-splitting surprise is exactly

\[
\boxed{
\log_2(n!)+O(1)
=
 n\log_2n-(\log_2e)n+O(\log n).
}
\tag{4.21}
\]

This exact calibration is the main mathematical output of B17.

## 5. Method B22 — quantify what the adjacent successful literature does not supply

Eberhard's theorem is powerful at the **qualitative typical-event** level: under ERH, the iid sign/integer-entry characteristic polynomial is irreducible and has very large Galois group with probability tending to one. \[

\[

\[
\boxed{

\tag{5.3}

If the primes stay in bounded fields, (4.17) gives only `Theta(n)` bits per test, and even the ideal independent model needs `Omega(n)` tests.

This is not asserted for the Bernoulli reductions themselves. The point of (5.3) is a **calibrated no-go for a bounded-prime or few-prime strategy**: even the clean independent uniform benchmark does not reach quadratic entropy with `o(n/log n)` large-field-equivalent tests.

Thus an Eberhard-style local/global argument capable of moving `u_GI` must contain a genuinely many-prime quantitative dependence theorem, not merely a strengthened one-prime irreducibility statement.

### Why CRT alone cannot supply the missing independence

For one sign entry `epsilon in {+1,-1}`, the entire residue vector

\[

contains exactly one input bit. Across all moduli, the full matrix still contains exactly `n^2` independent source bits. Chinese remaindering changes the arithmetic representation but manufactures no new entrywise randomness.

Therefore any successful many-prime proof must show that distinct complete-splitting predicates extract fresh **conditional information** from the same bits. Multiplying one-prime probabilities without such a theorem would be circular.

## 6. Method B9 — randomize the prime family, not the matrix

### Lemma 6.1 — randomized-prime sieve reduction

Let `mu_n` be any probability distribution on finite sets `P` of rational primes satisfying `p==1 mod 4`. Then

\[
\boxed{
\Pr(E_n)
\le
\mathbf E_{P\sim\mu_n}
\Pr\!\left(\bigcap_{p\in P}S_p\right).
}
\tag{6.1}
\]

#### Proof

For every deterministic `P`, (3.2) gives pointwise

\[
1_{E_n}(M)
\le
\prod_{p\in P}1_{S_p}(M).
\]

This yields an exact source-movement criterion.

### Corollary 6.2

If for some fixed `delta>0` one can construct distributions `mu_n` satisfying

\[
\boxed{
\mathbf E_{P\sim\mu_n}
\Pr\!\left(\bigcap_{p\in P}S_p\right)
\le
2^{-(\delta+o(1))n^2},

\tag{6.2}

then

### Ordered conditional-information version

For an ordered list `p_1,...,p_k`, write

\[
Q_j
=
\Pr\!\left(
S_{p_j}
\mid
\bigcap_{i<j}S_{p_i}
\right).
\tag{6.4}
\]

Then the exact chain rule is

\[
\Pr\!\left(\bigcap_{j=1}^{k}S_{p_j}\right)
=\prod_{j=1}^{k}Q_j.
\tag{6.5}
\]

Consequently, any proof of

\[
Q_j\le2^{-\eta_{n,j}}

\[
\boxed{
\Pr(E_n)
\le2^{-\sum_j\eta_{n,j}},
\qquad
u_{GI}
\ge
\liminf_n\frac{\sum_j\eta_{n,j}}{n^2}.
}
\tag{6.6}
\]

At the benchmark-critical number `k~n/log n`, a positive quadratic exponent requires average conditional surprise of order `n log n` bits per prime, which is already the maximum local scale in the uniform benchmark. Thus that sparse-prime regime has almost no tolerance for dependence loss. A denser choice `k~n` needs only order-`n` surprise per prime but demands control across a linearly growing family.

This is the concrete B9 output. It is a valid source-level reduction but not yet the needed Bernoulli joint-probability theorem.
