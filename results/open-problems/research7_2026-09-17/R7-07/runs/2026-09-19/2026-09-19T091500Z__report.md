## 3. Idea before calculation

The first SOURCE-SPLIT-SIEVE run deliberately threw away the complex size of a Gaussian-integral eigenvalue and retained only complete splitting modulo `p`. That led to an apparent need for many primes, because generic complete splitting in a large field carries at most about `log_2(n!)` bits.

The new idea is to **keep the archimedean restriction before reducing modulo a prime**.

A sign matrix has Frobenius norm `n`. Schur triangularization therefore forces

\[
\sum_j|\lambda_j|^2\le n^2.
\tag{3.1}
\]

If all eigenvalues are Gaussian integers, each lies in the Gaussian lattice disk

\[
D_n=\{z\in\mathbf Z[i]:|z|\le n\},
\qquad |D_n|=O(n^2).
\tag{3.2}
\]

For a split prime `p=1 (mod 4)` with `p>4n^2`, reduction `Z[i] -> F_p` is injective on that disk. Hence an exceptional matrix does not merely have a characteristic polynomial that splits over all `p` field elements: all of its reduced roots lie in one specified `O(n^2)`-point subset of `F_p`.

That turns the many-prime problem into a plausible **single-prime characteristic-polynomial entropy problem**.

## 4. Method B30 — one prime, one scale, one direction

### 4.1 Spectral-energy lemma

For any complex matrix `M`, write a Schur decomposition `M=UTU*`. Then

\[
\|M\|_F^2
=\|T\|_F^2
=\sum_j|\lambda_j|^2+\sum_{a<b}|T_{ab}|^2
\ge\sum_j|\lambda_j|^2.
\tag{4.1}
\]

For a sign matrix, `||M||_F^2=n^2`, proving (3.1).

### 4.2 Large split primes separate all admissible Gaussian roots

Take `p=1 (mod 4)` and a root `r in F_p` of `r^2=-1`. The map

\[
\rho_{p,r}(a+bi)=a+br
\tag{4.2}
\]

has kernel a Gaussian prime ideal of norm `p`.

If `z,w in D_n` have the same image, then `z-w` belongs to that prime ideal, so `p` divides the integer norm `|z-w|^2`. But if `z != w`,

\[
0<|z-w|^2\le4n^2<p,
\]

which is impossible. Thus `rho_{p,r}` is injective on `D_n`.

Define

\[
A_{n,p}=\rho_{p,r}(D_n),
\qquad |A_{n,p}|=O(n^2).
\tag{4.3}
\]

Then

\[
\boxed{
E_n\Longrightarrow
\chi_{M_n}\bmod p\text{ has every root in }A_{n,p}.
}
\tag{4.4}
\]

This is strictly stronger than generic complete splitting.

### 4.3 Exact uniform finite-field benchmark for a restricted root set

Let `X` be uniform in `M_n(F_q)`, and let `A subset F_q` have `m` elements. Put

\[
T_{n,q}(A)=\{\text{all roots of }\chi_X\text{ lie in }A\}.
\]

Using Reiner's fixed-characteristic-polynomial formula exactly as in the previous run gives

\[
\Pr(T_{n,q}(A))
=q^{-n}F_q(n)
\sum_{\substack{(m_a)_{a\in A}\\\sum_a m_a=n}}
\prod_{a\in A}F_q(m_a)^{-1},
\tag{4.5}
\]

where

\[
F_q(k)=\prod_{j=1}^k(1-q^{-j}).
\]

There are `binom(n+m-1,n)` weak compositions. Since `F_q(infinity)<=F_q(k)<=1`, and `m<=q`, the uniform absolute comparison is

\[
\boxed{
 c_0 q^{-n}\binom{n+m-1}{n}

 e^4 q^{-n}\binom{n+m-1}{n},
}
\tag{4.6}
\]

with `c_0=prod_{j>=1}(1-2^{-j})>0`.

Apply this with `A=A_{n,p}`. Since `m=O(n^2)`,

\[
\log_2\binom{n+m-1}{n}=O(n\log n).
\tag{4.7}
\]

Therefore, for any split-prime sequence with

\[
\log_2 p_n=\alpha n+o(n),

the uniform finite-field benchmark satisfies

\[
\boxed{

}
\tag{4.8}
\]

## 6. Method B3 — stronger theorem and exact uniform collision benchmark

Instead of estimating complete splitting, ask for the stronger property that the complete characteristic polynomial retains essentially all `n^2` input bits in Renyi-2 entropy.

For a uniform finite-field matrix this can be proved exactly enough for comparison.

### Proposition 6.1

Let `X` be uniform in `M_n(F_q)`. For every monic degree-`n` polynomial `f`,

\[
\Pr(\chi_X=f)
\le q^{-n}\exp\left(\frac{4n}{q-1}\right).
\tag{6.1}
\]

Therefore its characteristic-polynomial collision probability satisfies

\[
\boxed{
q^{-n}
\le
\Pr(\chi_X=\chi_{X'})
\le
q^{-n}\exp\left(\frac{4n}{q-1}\right),
}
\tag{6.2}
\]

for independent uniform `X,X'`.

#### Proof

Factor

\[
f=\prod_\phi\phi^{m_\phi}
\]

into distinct monic irreducibles of degrees `d_phi`. Reiner gives

\[
\Pr(\chi_X=f)
=q^{-n}F_q(n)\prod_\phi F_{q^{d_\phi}}(m_\phi)^{-1}.
\tag{6.3}
\]

Discard `F_q(n)<=1`. For every `d,m`,

\[
-\log F_{q^d}(m)
\le\sum_{j\ge1}\frac{q^{-dj}}{1-q^{-dj}}
\le\frac{q^{-d}}{(1-q^{-d})^2}
\le4q^{-d}.
\tag{6.4}
\]

At most `n/d` distinct degree-`d` factors can occur, so

\[
\log\prod_\phi F_{q^{d_\phi}}(m_\phi)^{-1}
\le4n\sum_{d\ge1}\frac{q^{-d}}d
=4n[-\log(1-q^{-1})]
\le\frac{4n}{q-1}.
\tag{6.5}
\]

This proves (6.1). Since there are `q^n` monic degree-`n` polynomials, Cauchy-Schwarz gives collision probability at least `q^{-n}`; the upper bound follows from `sum nu(f)^2 <= max nu(f)`. QED.

Hence if `log_2 q=n+o(n)`, the uniform finite-field characteristic polynomial has collision entropy

\[
\boxed{
-\log_2\Pr(\chi_X=\chi_{X'})=n^2+o(n^2).
}
\tag{6.6}
\]

This is exactly the exponent required in (5.7).

The transfer gap is now unambiguous. A Rademacher matrix modulo an exponentially large prime is not entrywise near uniform: each entry remains supported on only `{+1,-1}`. Existing fixed-field universality and Eberhard's qualitative irreducibility/Galois results do not imply (5.7).

Also, CRT on the entry vector is the wrong mechanism. Reduction of `{+1,-1}^{n^2}` modulo any odd prime is already injective coordinatewise, so combining primes creates no new entry-level entropy. Any successful large-sieve argument has to act **after the nonlinear map `M -> chi_M`**, or equivalently on the pair equation `chi_M=chi_M'`.
