## 4. B5 — add a parameter and differentiate/classify it: signed diagonal shears

### Idea before code

The previous run fixed the shear

`S = [[I,0],[I,I]]`.

Instead, allow the lower-left shear to vary diagonally. The off-diagonal triangularity equations may force most parameters to discrete values, but any surviving parameter orbit can multiply the size of the counterfamily. The terminal coordinate is especially promising because it is not pinned by an off-diagonal zero.

### Even-dimensional calculation

Let `n=2m` and write

`M = [[A,B],[C,D]]`

in `m x m` sign blocks. For a diagonal `R`, put

`S_R = [[I,0],[R,I]]`.

Then exactly

`S_R^{-1} M S_R`

`= [[A+BR, B], [C+DR-RA-RBR, D-RB]].`                    (4.1)

Take

`R = diag(epsilon_1,...,epsilon_{m-1},tau)`,

with `epsilon_j in {+1,-1}` and initially arbitrary terminal `tau`. Impose

`A+BR` upper triangular,

`C+DR-RA-RBR = 0`,

`D-RB` lower triangular.                                      (4.2)

For `i>j`, equation (4.2) gives

`a_ij+b_ij epsilon_j=0`,

then

`c_ij+d_ij epsilon_j=0`;

there are exactly `4` choices.

For `i<j`, it gives

`d_ij-epsilon_i b_ij=0`,

then

`c_ij-epsilon_i a_ij=0`;

again exactly `4` choices.

For a nonterminal diagonal coordinate the equation is

`c + epsilon(d-a) - b = 0`,

which has exactly `6` sign solutions for each fixed `epsilon`.

At the terminal coordinate the equation is

`c + tau(d-a) - b tau^2 = 0`.                              (4.3)

The two terminal triangular eigenvalues are `a+b tau` and `d-b tau`. If these are Gaussian integers then `tau` itself is a Gaussian integer. Equation (4.3), after division by `-b`, is a monic quadratic over `Z` with constant term the Gaussian unit `-c/b in {+1,-1}`. Its other root is also in `Z[i]`; the product of the roots is a unit. Hence `tau` must itself be a Gaussian unit:

`tau in {+1,-1,+i,-i}`.                                   (4.4)

Thus the parameter search closes exactly rather than introducing an uncontrolled continuum.

For `tau=+1`, the diagonal sign condition has `6` solutions. For `tau=-1`, it has `6`; their intersection is `a=d,c=b`, of size `4`, so the real-unit union has size `8`.

For `tau=+i` or `-i`, equation (4.3) is equivalent to

`d=a, c=-b`.

Both imaginary units yield the same `4` sign quadruples, disjoint from the real-unit union. Therefore the terminal unit-union contains exactly `12` sign quadruples.

For every `j<m`, the matrix itself recovers the sign parameter from any below-diagonal position, for instance

`epsilon_j = -a_{j+1,j}/b_{j+1,j}`.

Consequently different prefixes `(epsilon_1,...,epsilon_{m-1})` give disjoint matrix families. The exact even-dimensional union size is

`N_{2m}`
`= 2^{m-1} 4^{m(m-1)} 6^{m-1} 12`
`= 2^{2m^2} 3^m`.                                          (4.5)

Every matrix counted by (4.5) has Gaussian-integer spectrum: all nonterminal diagonal eigenvalues are in `{-2,0,2}`, while the terminal pair is either integral or of the form `a +/- i b`.

Therefore

`P(E_{2m}) >= 3^m 2^{-2m^2}`.                              (4.6)

**B5 outcome:** the fixed shear was not entropy-optimal even inside its local mechanism. The full admissible Gaussian-unit endpoint and all signed nonterminal diagonal parameters increase the family to exactly `2^{2m^2}3^m` matrices.

## 5. B15 — break the symmetry: rectangular shear for every odd n

### Idea before code

The previous construction used an equal `m+m` split and hence only refuted Vu's asymptotic on the even subsequence. Break the block-size symmetry by using an `m+(m+1)` decomposition. The extra row/column can simultaneously force the shear signs to be identifiable and contribute free sign choices.

Let `n=2m+1` and split

`M = [[A,B],[C,D]]`

with block sizes `m` and `m+1`. Let `R_epsilon` be the `(m+1) x m` matrix with top block `diag(epsilon_1,...,epsilon_m)` and last row zero. The same unipotent block shear gives

`S^{-1}MS`
`= [[A+B R_epsilon, B],`
`   [C+D R_epsilon-R_epsilon A-R_epsilon B R_epsilon, D-R_epsilon B]].`   (5.1)

Impose the same upper / zero / lower conditions.

The `m x m` core contributes

`4^{m(m-1)}6^m`.                                           (5.2)

The extra column contributes `2^m` choices because

`d_{i,m+1}=epsilon_i b_{i,m+1}`.

The extra bottom row contributes another `2^m` because

`c_{m+1,j}+d_{m+1,j}epsilon_j=0`.

The bottom-right entry of `D` is an arbitrary sign, giving another factor `2`.

For fixed `epsilon`, the count is therefore

`4^{m(m-1)}6^m 2^{2m+1}`.                                 (5.3)

Crucially, the extra column recovers every parameter uniquely:

`epsilon_i = d_{i,m+1}/b_{i,m+1}`.

Thus all `2^m` parameter families are pairwise disjoint, and

`N_{2m+1}`
`= 2^m 4^{m(m-1)}6^m2^{2m+1}`
`= 2^{2m^2+2m+1}3^m`.                                     (5.4)

All diagonal eigenvalues are ordinary integers (`0,+/-2` on the paired coordinates and `+/-1` on the extra coordinate), hence Gaussian integers. Dividing (5.4) by the `2^{(2m+1)^2}` sign matrices gives

`P(E_{2m+1}) >= 3^m 2^{-(2m^2+2m)}`.                      (5.5)

**B15 outcome:** the construction now works in every odd dimension with an exact count and no asymptotic patching.
