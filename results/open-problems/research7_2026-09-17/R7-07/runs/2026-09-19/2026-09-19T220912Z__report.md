# 5. B12 — exact conserved/gauge structure

## 5.1 One-edge identity

For every positive-conductance child `u` of `v`,

\[
\boxed{
1-B_v=p_v(u)\frac{B_v}{B_u}.
}
\tag{5.1}
\]

This follows immediately from `B_v=S_v/(1+S_v)` and `p_v(u)=B_u/S_v`.

## 5.2 Harmonic-gauge theorem

Substituting (4.1) into (4.4),

\[
\begin{aligned}
(\widehat P_\epsilon f)(v)
&=B_v^{1+\epsilon}
\sum_u\frac{B_u^2}{S_v^2}B_u^{-1-\epsilon}f(u)\\
&=(1-B_v)\sum_up_v(u)
\left(\frac{B_v}{B_u}\right)^\epsilon f(u).
\end{aligned}
\]

Thus

\[
\boxed{
(\widehat P_\epsilon f)(v)
=(1-B_v)K_H\!\left[
\left(\frac{B_v}{B_{child}}\right)^\epsilon f
\right](v).
}
\tag{5.2}
\]

If `X_0=o,X_1,...` is a harmonic ray, iterating gives

\[
\boxed{
\widehat P_\epsilon^nf(o)
=B_o^\epsilon E_H^o\!\left[
\prod_{r=0}^{n-1}(1-B_{X_r})
B_{X_n}^{-\epsilon}f(X_n)
\right].
}
\tag{5.3}
\]

The entire `epsilon`-dependent path factor telescopes:

\[
\prod_{r<n}
\left(\frac{B_{X_r}}{B_{X_{r+1}}}\right)^\epsilon
=\left(\frac{B_o}{B_{X_n}}\right)^\epsilon.
\tag{5.4}
\]

So the positive Renyi tilt is an exact endpoint **coboundary/gauge transform**, not a new extensive bulk potential.
