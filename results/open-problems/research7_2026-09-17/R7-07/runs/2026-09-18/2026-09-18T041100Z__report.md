### B2 — attack the negation first

Let `0 != x in ker A` and `S=supp(x)`. Every vertex outside `S` must have either zero or at least two neighbours in `S`; an outside vertex with exactly one support neighbour would have a nonzero row equation. This is the basic **unique-neighbour obstruction**.

I proved exactly that support two is equivalent to a pair of nonadjacent twins: if `x=a e_u+b e_v`, an edge `uv` is impossible, every outside vertex must see both or neither, hence `N(u)=N(v)`, and any common neighbour forces `a+b=0`. ### B1 — change mathematical category

The decisive new theorem is a configuration-model unique-neighbour expansion bound.

**Theorem.** For every fixed `d>=3`,

`P(exists 0 != x in ker A_{n,d} with 3 <= |supp x| <= n^{1/20}) = o(n^{2-d}).`

For a fixed `k`-set `S`, write `h=dk`. If `S` is unique-neighbour-bad, let `e` be the number of internal configuration pairs, `r=h-2e` the crossing half-edges, and `t` the number of outside vertices receiving them. Necessarily `t<=floor(r/2)`. Overcounting all such partial pairings gives

`P(S bad) <= h^2 (2h)^h n^{-ceil(h/2)}`.

Union over `S` yields

`P(U_k) <= d^2 k^2 [ e (2d)^d k^{d-1} n^{1-d/2} ]^k`.

For `k<=n^{1/20}` the bracket is at most `C_d n^{-(9d-19)/20}`, so

`sum_{k=3}^{n^{1/20}} P(U_k) = O_d(n^{-3(9d-19)/20})`.

Since

`3(9d-19)/20 - (d-2) = (7d-17)/20 > 0`,

this is `o(n^{2-d})`. Conditioning the fixed-degree configuration model on simplicity changes the estimate by only a bounded factor.

In particular, every fixed support size `k>=3` contributes at most `O(n^{1-d})`, one full polynomial order below the twin scale.

Define `T_d` = twin event and

`G_d^global = {there is a kernel vector with support > n^{1/20}}`.

The source problem now has the rigorous reduction

`P(A_{n,d} singular) <= P(T_d) + o(n^{2-d}) + P(G_d^global).`

Thus any non-twin mechanism capable of changing Vu's exponent must be genuinely global.

### B21 — import sparse-rank / switching machinery

The sparse Erdos-Renyi exact-rank literature suggests isolating local dependencies and then rank-boosting away global deficiency. In the regular model, degree-preserving two-switches give a clean exact identity.

For a legal switch

`ab,cd -> ac,bd`,

if `Ax=0`, the same `x` remains in the switched kernel iff

`x_b=x_c` and `x_a=x_d`.

This follows by writing the four coordinates of `(A'-A)x` explicitly. Therefore a large-support kernel vector with many coordinate classes is destroyed by most switchings, while few coordinate classes force strong equitable-partition constraints.

The exact failure is also clear: destroying one *particular* kernel vector does not prove the switched matrix nonsingular because another kernel vector may survive or appear. A valid source-level switching argument still needs a rank-sensitive injection/preimage bound or a canonical kernel certificate whose destruction provably raises rank.
