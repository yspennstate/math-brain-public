## 4. B15 — break the finite-field symmetry on purpose

Huang's third class is special: its vectors have very few nonzero coordinates. Counting these vectors value-by-value pays a large residue-label multiplicity, producing the `p^(2d)` factor in (4.43). For singularity probability we do not need that multiplicity. We only need to know whether **some** vector in the sparse class exists.

### Lemma 4.1 — support obstruction is field independent

Let `G` be any finite simple graph, `K` any field, and `0 != x in K^{V(G)}` satisfy `A(G)x=0`. Put `S=supp(x)`. No vertex in `V(G)\S` can have exactly one neighbour in `S`: if `v` had unique support neighbour `u`, then its row equation would be `(Ax)_v=x_u=0`, contradicting `u in S`.

Therefore the preceding R7-07 counting theorem, which bounds the **field-free event** that such a unique-neighbour-bad set `S` exists, applies uniformly to `K=F_p`, even when `p=p_n` varies with `n`:

`P(exists 0 != x in ker_Fp(A), 3 <= |supp x| <= delta_d n) = o(n^(2-d)).`

There is no union over `p`; the same bad-support event contains all these possibilities simultaneously.

### Lemma 4.2 — support two is exactly twins in the simple model

If a nonzero kernel vector is supported on exactly `{u,v}`, the row equation at `u` rules out `u~v`. Every outside vertex seeing exactly one of `u,v` would violate Lemma 4.1, hence the two vertices have the same neighbourhood. Conversely a nonadjacent twin pair gives `e_u-e_v` in the kernel over every field. For fixed `d`, a fixed pair is twin with probability `O(n^{-d})`, so by a union bound

`P(twins exist)=O(n^(2-d)).`

### Sparse class sieve

Huang's third class has precisely

`r = n - n_0(M) = |supp x|`

and

`2 <= r <= R_n := b p^3 log n/d`.

Take `p << n^(1/8)`. Then

`R_n = n^(3/8+o(1)) = o(n)`,

hence eventually `R_n <= delta_d n`. Let `E_sp(p)` be the event that a nonzero finite-field kernel vector lies in this class. Split on support size:

- `r=2`: probability `O(n^(2-d))` by the twin lemma;
- `3<=r<=R_n`: probability `o(n^(2-d))` by the field-independent support theorem.

Thus

`P(E_sp(p)) = O(n^(2-d))`

uniformly for the entire local-CLT range `p << n^(1/8)`.

This removes the `p^(2d)` loss without altering the source event.

## 6. Non-sparse finite-field vectors remain bounded in expectation up to p << n^(1/8)

Work first under Huang's undirected configuration model. Let `N_ns(G)` be the number of nonzero `F_p` kernel vectors outside the sparse third class.

For odd `p << n^(1/8)`:

- Proposition 4.1 contributes `1+o(1)` from the equidistributed class;
- the other non-equidistributed classes (1, 2, and 4 in Huang's proof decomposition) contribute `o(1)` by their displayed exponential estimates.

Therefore

`E_conf N_ns = O_d(1)`.

Let `Simple` denote the event that the configuration pairing yields a simple graph. For fixed `d`, `P_conf(Simple)` tends to a positive constant, so

`E[N_ns | Simple] <= E_conf N_ns / P_conf(Simple) = O_d(1)`.

This conditioning is deliberate: the twin classification is invoked only for the final uniform **simple** graph, not for configuration multigraphs.

## 7. Finite-field singularity inequality

Outside `E_sp(p)`, if the simple adjacency matrix is singular over `F_p`, its nonzero kernel contains at least `p-1` vectors, all counted by `N_ns`. Hence

`(p-1) 1_{singular mod p and E_sp^c} <= N_ns`.

Taking expectations under the uniform simple graph law,

`P(A singular mod p)`
`<= P(E_sp(p)) + E[N_ns | Simple]/(p-1)`
`<= O(n^(2-d)) + O_d(1/p)`.

Because the adjacency matrix has integer entries, real singularity implies determinant zero as an integer, hence singularity modulo every prime. Therefore

`P(A_{n,d} singular over R) <= O(n^(2-d)) + O_d(1/p)`

for odd primes `p` with `p not| d` and `p << n^(1/8)`.

This is the central new inequality of the run.

## 8. B5 — optimize the prime parameter

Write heuristically `p=n^theta/L(n)`. Once class 3 is removed as an event:

- Huang's equidistributed local CLT imposes the first active restriction `theta<1/8`, through its error `p^4(log n)^(3/2)/sqrt(n)`;
- the sparse support cutoff only requires `p^3 log n=o(n)`, i.e. `theta<1/3`;
- Huang's far class remains negligible at least through `theta<1/4`;
- the other non-equidistributed classes are exponentially small in `p^2 log n`.

Choose

`x_n=n^(1/8)/(log n)^2`

and, by Bertrand's postulate, an odd prime `p_n in [x_n,2x_n]`. For fixed `d`, eventually `p_n>d`, so `p_n not|d`; moreover

`p_n << n^(1/8)` and `1/p_n=n^(-1/8+o(1))`.

Substitution gives

`P(A_{n,d} singular) <= O(n^(2-d)) + n^(-1/8+o(1)).`

For the frozen cubic metric,

`P(A_{n,3} singular) <= n^(-1/8+o(1))`,

**`a_3 >= 1/8`.**
