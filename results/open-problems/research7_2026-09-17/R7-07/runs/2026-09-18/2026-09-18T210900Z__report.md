# 2. B4 — prove the union-of-three-perfect-matchings model exactly enough to expose its real variable

Let `n=2N`. For a perfect matching `M` on `[n]`, let `P_M` be its symmetric permutation matrix. Take three independent uniform perfect matchings and set

`A_col = P_{M1}+P_{M2}+P_{M3}`.

This is the symmetric edge-colored cubic configuration model. Nguyen--Wood supply the nearest fixed-prime cokernel theorem for this model; the present purpose is to see what survives uniformly when the prime grows.

## 2.1 Exact alternating-cycle moment

Fix a reference matching `M0` and let `C(M0,M)` be the number of alternating components in `M0 union M`, with a doubled common edge counted as one component. If

`F_N(x) = sum_M x^{C(M0,M)}`,

then deleting one reference edge gives the exact recurrence

`F_N(x)=(x+2N-2)F_{N-1}(x)`, `F_1(x)=x`.

Indeed, if the reference edge is also in `M`, deleting it removes one component and contributes the factor `x`. Otherwise delete the two reference vertices and splice their two `M`-partners; every matching on the remaining `2N-2` vertices has exactly `2(N-1)` such preimages and the component count is unchanged. Hence

`F_N(x)=x(x+2)...(x+2N-2)`.

On an alternating component of length `2 ell`, the permutation `P_{M0}P_M` has two `ell`-cycles. Since

`(P_{M0}-P_M)y=0  <=>  P_{M0}P_M y=y`,

each component contributes exactly two field dimensions. Thus

`dim ker(P_{M0}-P_M)=2 C(M0,M)`

over every field. For every prime `p`, therefore,

`E |ker(P_M-P_M' mod p)| = product_{j=0}^{N-1} (p^2+2j)/(2j+1)`

`= Gamma(N+p^2/2) Gamma(1/2) / [Gamma(p^2/2) Gamma(N+1/2)]`.

This also yields the exact joint Fourier identity

`sum_{t,y} | E_M e_p(t^T P_M y) |^2 = p^n product_{j=0}^{N-1} (p^2+2j)/(2j+1)`.

If `mu_y` is the law of `P_M y`, Young's inequality gives

`P(A_col y=0) <= ||mu_y||_2^2`,

and therefore

`E |ker(A_col mod p)| <= product_{j=0}^{N-1}(p^2+2j)/(2j+1)`.

For `p^2=o(n)`, Stirling gives logarithm

`(p^2/2) log(2eN/p^2) + O(p^4/n + log n)`.

At `p=n^{1/3-o(1)}` this is `O(n^{2/3+o(1)} log n)` in the exponent, far above polynomial scale. This is a complete no-go theorem for the simplest collision/Young route. It can be maximally slack: for a nonzero constant row and `p>3`, the collision norm is one while the actual null probability is zero because `A_col y=3y`.

## 2.2 Exact matching-to-target count

The stronger replacement is exact and keeps the third matching.

For `y,z in F_p^n`, define

`N_ab(y,z) = #{i : y_i=a, z_i=b}`.

Let `Nmatch(y,z)` be the number of perfect matchings `M` satisfying `P_M y=z`. Such a matching pairs each cell `(a,b)` with cell `(b,a)`. Therefore `Nmatch(y,z)=0` unless

`N_ab=N_ba` for every `a!=b`

and every diagonal `N_aa` is even. If these conditions hold, then exactly

`Nmatch(y,z) = product_{a<b} N_ab! * product_a (N_aa-1)!!`.      (2.1)

Proof: each off-diagonal cell pair is matched by an arbitrary bijection, giving `N_ab!`, while each diagonal cell is internally perfectly matched, giving `(N_aa-1)!!`; these choices are disjoint and exhaustive.

Condition now on `M1,M2` and define

`z = -(P_{M1}+P_{M2})y`.

Then exactly

`P(A_col y=0 | M1,M2) = Nmatch(y,z)/(n-1)!!`.                 (2.2)

No local CLT and no independence approximation is present in (2.2).

## 2.3 Joint entropy and the mutual-information barrier

Suppose `y` uses `k` residues and write `beta_ab=N_ab/n`. If (2.1) is compatible, Stirling applied cell-by-cell gives

`log Nmatch(y,z) = (n/2) log n - n/2 - (n/2) H(beta) + O(k^2 log(n+1))`.      (2.3)

The immutable artifact's first rendering of this display lost two `frac` tokens in transmission; the separate erratum at `dba033...` records and re-derives the correct formula (2.3). Since

`log (n-1)!! = (n/2) log n - n/2 + O(log n)`,

we have uniformly

`P(P_M y=z) = exp[-(n/2)H(beta) + O(k^2 log(n+1))]`.          (2.4)

When `z` has the same empirical profile `alpha` as `y`, both marginals of `beta` equal `alpha`. Define

`I(beta)=2H(alpha)-H(beta)`.

Then (2.4) is

`P(P_M y=z) = exp[-n H(alpha) + (n/2) I(beta) + O(k^2 log n)]`.   (2.5)

Meanwhile the number of rows with profile `alpha` is

`n!/prod_a n_a! = exp[nH(alpha)+O(k log n)]`.

Thus the full row entropy cancels the generic part of the conditional third-matching probability exactly. What survives is the positive mutual-information defect `I(beta)`. For a balanced approximately independent table, `H(beta) about 2H(alpha)` and the third matching costs the full inverse row count; for a table concentrated near a permutation graph, `H(beta) about H(alpha)` and one loses half the entropy.

This is the principal mathematical advance of the run:

**the growing-support obstruction in the colored model is now a precise high-mutual-information exceptional-set problem.**

The next theorem one would need is a large-deviation statement saying that the first two matchings themselves pay enough probability whenever the target contingency table has large `I(beta)`.

## 2.4 Two exact algebraic filters

The threefold equation preserves additional constraints that the collision norm erased. If `x_j=P_{Mj}y` and `x_1+x_2+x_3=0`, then for `p!=3`,

`sum_i y_i=0`.

For odd `p`, all three `x_j` have the same quadratic norm `q=sum_i y_i^2`, and

`<x_i,x_j> = -q/2` for every `i!=j`.

This is the finite-field analogue of three equal-norm vectors meeting at 120 degrees. It provides a second handle, alongside `I(beta)`, for the next exposure argument.

**B4 outcome:** positive restricted theorem and decisive no-go. The easy colored model is not solved, but its high-alphabet first-moment obstruction has been converted into an exact contingency/mutual-information problem.

# 3. B6 — exact change of measure back toward the cubic configuration model

Let `P` be the uniform pairing law on the `3n` labelled half-edges of the cubic configuration model. For a pairing `M`, let `C(M)` be the number of ordered proper 3-edge-colorings of its half-edges: one half-edge of each color at every vertex, and paired half-edges have equal color.

Generate a colored configuration instead by first assigning the three colors bijectively to the three half-edges at each vertex (`6^n` choices), then independently pairing the `n` half-edges of each color (`(n-1)!!` choices per color), and finally forgetting the colors. A fixed uncolored pairing has exactly `C(M)` preimages. Thus, if `Q` is this three-matching law,

`dQ/dP(M) = C(M)/E_P C(M)`,                                      (3.1)

where exactly

`E_P C = 6^n ((n-1)!!)^3/(3n-1)!!`.                             (3.2)

For `n=2N`,

`E_P C = 36^N (2N)!^3 (3N)! / [N!^3 (6N)!]`

and Stirling gives

`E_P C ~ 2 (4/3)^N = 2 (2/sqrt(3))^n`.                          (3.3)

So the union-of-three-perfect-matchings ensemble is **exactly** the ordinary cubic configuration model size-biased by its number of ordered 1-factorizations.

For every event `E` and threshold `c_n>0`, (3.1) gives the exact transfer inequality

`P(E) <= P(C<c_n) + (E C / c_n) Q(E)`.                           (3.4)

This quantifies the model mismatch. Qualitative contiguity alone is insufficient for a polynomial singularity exponent because (3.4) needs a polynomially controlled lower tail of `C/EC`.

## 3.1 Hamilton-cycle calibration

Let `H(M)` count edge-labelled Hamilton cycles of the cubic configuration. For each labelled Hamilton cycle on the vertices, there are `6^n` choices of the incident half-edges realizing its two cycle edges, and the remaining one half-edge per vertex can be perfectly matched in `(n-1)!!` ways. Therefore

`E_P H = ((n-1)!/2) * 6^n (n-1)!!/(3n-1)!!`.                  (3.5)

Every Hamilton cycle yields six ordered 3-edge-colorings: choose the complementary perfect-matching color in three ways and alternate the two other colors in two ways. A single ordered coloring has only three pairs of colors, hence witnesses at most three Hamilton cycles. Incidence double counting gives

`6H <= 3C`, hence `C>=2H`.                                      (3.6)

The mean ratio is exact:

`E C/E H = 2 ((n-1)!!)^2/(n-1)!`.

For `n=2N`,

`E C/E H = 4N * binom(2N,N)/4^N ~ 4 sqrt(N/pi) = 2 sqrt(2n/pi)`.  (3.7)

Thus a sufficiently quantitative lower-tail theorem for `H/EH` would lose only about `n^{1/2}` in the change of measure. Such a lower-tail theorem at the required rare-event precision is **not** established here.

A fresh source check found exactly the relevant classical qualitative result: Molloy--Robalewska--Robinson--Wormald, *1-Factorizations of random regular graphs*, Random Structures & Algorithms 10 (1997), 305--321, state contiguity for every fixed `r>=3` between random `r`-regular graphs and the construction from `r` perfect matchings. That supports the model choice but does not supply a polynomial likelihood-ratio bound. Janson's related small-subgraph-conditioning/contiguity work likewise supplies qualitative asymptotic equivalence, not the source-matched rate required by (3.4).

**B6 outcome:** positive. The deformation is no longer informal; its Radon--Nikodym derivative, mean normalization, and exact transfer loss are explicit. The missing transfer ingredient is a quantitative lower tail for the number of 1-factorizations (or a strong surrogate such as Hamilton-cycle count).

# 4. B26 — the quadratic/Salié charge is not a sporadic coherent obstruction

The preceding run decomposed the hyperbolic Fourier kernel

`U((t,y),(t',y')) = p^{-1} e_p(t y' + t' y)`

under the projective scaling `(t,y) -> (lambda^{-1}t, lambda y)` into multiplicative-character sectors. This run isolates the potentially exceptional characters.

Fix a nontrivial multiplicative character `eta`. Its sector has normalized orbit-character vectors on the nonzero `t`-axis, the nonzero `y`-axis, and each hyperbola `ty=r!=0`; the origin exists only in the trivial sector.

For same-axis coefficients the phase is constant, so character orthogonality gives exactly zero:

`<T_eta,U T_eta>=<Y_eta,U Y_eta>=0`.                              (4.1)

Axis--hyperbola and cross-axis coefficients reduce to normalized one-dimensional Gauss sums. Hence every such coefficient has magnitude exactly `p^{-1/2}` for nontrivial `eta`.

Hyperbola--hyperbola coefficients have the exact form

`p^{-1} sum_{x!=0} conjugate(eta(x)) e_p(r x + s/x)`,            (4.2)

and Weil's bound gives magnitude at most `2 p^{-1/2}`.

Therefore every nontrivial character block satisfies the coherence theorem

`max_{u,v} |(U_eta)_{uv}| <= 2/sqrt(p)`.                         (4.3)

The block remains unitary, so (4.3) is delocalization, not operator-norm decay.

The quadratic character is nontrivial. Its hyperbola coefficients are Salié-type sums, but they obey the same square-root bound (4.3). Thus the quadratic charge is **not** a locally coherent sporadic sector. By contrast, in the trivial character sector the same-axis coefficient is `(p-1)/p`, which is order one. Consequently any local saturation is confined to trivial charge; any obstruction from nontrivial charges would have to be a genuinely global interference phenomenon among many individually incoherent coefficients.

**B26 outcome:** positive elimination of a candidate exceptional family. The next Fourier-side attack should separate trivial-charge structure from collective nontrivial-charge flows, rather than treating the quadratic character as exceptional.
