### B27 — SWAP THE QUANTIFIERS: count support witnesses before graphs

The old `n^(1/20)` cutoff came from an intentionally crude assignment count. The kernel obstruction itself gives a better combinatorial object.

Let `S` be a fixed `k`-set in the fixed-`d` configuration model and let

`h=dk`

be its incident labelled half-edges. If `S` is unique-neighbour-bad, partition these `h` half-edges canonically as follows:

- every configuration edge internal to `S` contributes its two `S` half-edges as one block;
- for every outside vertex `v` touched by `S`, all `S` half-edges whose partners lie at `v` form one block.

Every block has size at least two. Therefore if the partition has `g` blocks,

`g <= floor(h/2)`.

Now fix one such set partition `pi` with `g` blocks. Designate `e` size-two blocks as internal matching pairs; at most `2^g` designations are possible, deliberately allowing impossible choices. The remaining `g-e` blocks are external. Their outside vertices can be chosen in at most `n^(g-e)` ways. If there are `h-2e` crossing half-edges, target half-edge choices cost at most `d^(h-2e)`.

The total number of prescribed matching pairs is

`q=e+(h-2e)=h-e`.

For `k/n` sufficiently small, `q<=dn/4`, and a prescribed family of `q` disjoint pairs occurs in a uniformly random perfect matching with probability at most

`(2/(dn))^q`.

Hence a fixed partition contributes at most

`2^g n^(g-e) d^(h-2e) (2/(dn))^(h-e)`

`= 2^(g+h-e) d^(-e) n^(g-h)`

`<= 2^(3h/2) n^(g-h)`.

The key factorial saving comes from counting set partitions by roots rather than by arbitrary functions. Give each block its least label as a canonical root. A partition into `g` blocks can be encoded by choosing the non-root set and assigning to each non-root its root. Thus the number of such partitions is at most

`2^h h^(h-g)`.

Therefore all `g`-block witnesses contribute at most

`2^(5h/2) (h/n)^(h-g)`

and, because `h-g>=h/2`, at most

`2^(5h/2) (h/n)^(h/2)`.

Summing over `g` gives, for an absolute constant `C_0`,

`P_config(S is unique-neighbour-bad) <= h C_0^h (h/n)^(h/2)`.

Union over `k`-sets and use `binom(n,k)<=(en/k)^k`. For a fixed `d`, there is a constant

`K_d = e C_0^d d^(d/2)`

such that

`P_config(U_k) <= dk [K_d (k/n)^(d/2-1)]^k`,

where `U_k` is the event that some `k`-set is unique-neighbour-bad.

Choose `delta_d>0` with

`delta_d <= min{1/(2d),1/4}`

and

`K_d delta_d^(d/2-1) <= 1/4`.

Put `a=(d-2)/2`. Split `3<=k<=delta_d n` at `L=C log n`, with `C` large enough that `4^(-L)=o(n^{-(d-2)})`.

For `k>=L`, the bound has geometric base at most `1/4`, so the tail is `o(n^{-(d-2)})`. For `3<=k<L`, replace `k` in the base by `L`:

`P_config(U_k) <= dk [K_d (L/n)^a]^k`.

The polynomially largest term starts at `k=3`, so

`sum_{k=3}^{L-1} P_config(U_k)`
`<= n^{-3a+o(1)}`
`= n^{-3(d-2)/2+o(1)}`
`= o(n^{-(d-2)}).`

Since fixed-`d` configuration graphs are simple with probability bounded away from zero, conditioning on simplicity costs only a constant factor.

**New theorem.** For every fixed `d>=3`, there exists `delta_d>0` such that

`P(exists 0 != x in ker A_{n,d} with 3 <= |supp x| <= delta_d n) = o(n^(2-d)).`

This is a strict strengthening of the preceding `n^(1/20)` support reduction. Modulo twins, every singularity mechanism capable of contributing at the source scale must now carry a **linear-size kernel support**.

If `T_d` is the twin event and

`G_d^lin(delta_d) = {exists 0 != x in ker A_{n,d}: |supp x| > delta_d n}`, then

`P(A_{n,d} singular)`
`<= P(T_d) + o(n^(2-d)) + P(G_d^lin(delta_d)).`

For `d=3`, the remaining source-relevant probabilistic estimate is

`P(G_3^lin(delta_3)) <= n^{-1+o(1)}`.

### B14 — FIND THE GROUP ACTING: quotient by coordinate levels

The switch identity suggests separating diffuse vectors from kernel vectors with very few coordinate levels. The first nontrivial global atomic class can be classified exactly in cubic graphs.

Suppose a cubic graph has `0!=x in ker A` and `x` takes exactly two values `{a,b}` on all vertices. Neither value can be zero: if the values were `{0,a}`, every row equation would force each vertex to have zero `a`-valued neighbours, impossible in a 3-regular graph containing an `a`-valued vertex.

Let `k(v)` be the number of `a`-valued neighbours of `v`. Every row equation is

`k(v)a + (3-k(v))b = 0`.

Because `a!=b`, the left side is affine in the integer `k(v)` with nonzero slope, so exactly one value of `k(v)` is possible throughout the graph. It is neither 0 nor 3; hence, up to swapping the two value classes, it is `k=1`.

Writing `S` for the `a`-class and `T` for the `b`-class, every vertex has one neighbour in `S` and two in `T`. Counting cross edges yields

`2|S|=|T|`,

so

`|S|=n/3`, `|T|=2n/3`, and `a+2b=0`.

Conversely any such equitable partition produces a two-valued kernel vector.

This structure is exponentially rare. Put `n=3m`. For a fixed partition with `|S|=m`, `|T|=2m`, the number of cubic configuration matchings realizing it is exactly

`3^(3m) (m-1)!! (2m)! (4m-1)!!`.

The factors are: choose each `S` vertex's one internal half-edge (`3^m`), choose each `T` vertex's one cross half-edge (`3^(2m)`), pair the selected `S` stubs internally, biject the remaining `2m` `S` stubs with the selected `T` stubs, and pair the remaining `4m` `T` stubs. There are `(9m-1)!!` total matchings. Hence the expected number `Z` of such partitions is

`E Z = binom(3m,m) 3^(3m) (m-1)!! (2m)! (4m-1)!! / (9m-1)!!`.

Stirling gives

`(1/n) log E Z = -log 3 + (4/3)log 2 + o(1)`

`= log(2^(4/3)/3)+o(1)`, with `2^(4/3)/3<1`.

Therefore

`P(cubic A has a globally two-valued kernel vector)`
`<= exp(-(log 3-(4/3)log 2+o(1)) n)`.

So one entire highly atomic linear-support class is exponentially negligible relative to the conjectural `n^{-1}` singularity scale.

### B10 — DERANDOMIZE: exact collision count for certificate-destroying switches

For a vector `x` on a simple `d`-regular graph, sample a uniformly random oriented edge `(u,v)` and set

`q_x(r,s)=P(x_u=r,x_v=s)`.

Because each undirected edge contributes both orientations,

`q_x(r,s)=q_x(s,r)`.

Define

`C_edge(x)=sum_{r,s} q_x(r,s)^2`.

Choose two oriented edges `(a,b)` and `(c,d)` independently. The previous exact two-switch identity says that the cross-switch preserves the same kernel vector iff

`x_b=x_c` and `x_a=x_d`.

Thus over all oriented-edge pairs its exact survival probability is

`sum_{r,s} q_x(r,s)q_x(s,r)=C_edge(x)`.

Only `O_d(n)` of the `d^2 n^2` ordered oriented-edge pairs are illegal for a two-switch: they share endpoints or create a proposed edge already present. Therefore among **legal** two-switches the fraction preserving `x` is

`C_edge(x)+O_d(1/n)`.

Consequently, if

`C_edge(x)<=1-eta`,

then there are `Omega_d(eta n^2)` legal switches which destroy that particular kernel certificate.

For the two-valued cubic equitable vector, the oriented edge-type masses are

`q(a,a)=1/9`,
`q(a,b)=q(b,a)=2/9`,
`q(b,b)=4/9`,

so

`C_edge=25/81`.

Hence asymptotically `56/81` of legal switches destroy that fixed vector, consistent with the independent exponential rarity result.

The gap is important and remains open: **destroying one selected kernel vector is not the same as raising matrix rank**. The switched graph may remain singular because another kernel vector survives or appears. Therefore this is a deterministic certificate-destruction count, not yet a source-level switching injection.

1. a canonical certificate whose destruction provably raises rank, or
