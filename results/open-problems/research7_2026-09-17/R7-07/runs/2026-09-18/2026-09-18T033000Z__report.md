## 5. B3 — exact endpoint-capture circumference theorem

### Idea

Do not try to rotate a longest rainbow path abstractly. Quantify exactly how much of the endpoint degree has already been consumed by path colors. If the uncaptured degree is large, it should itself force a long rainbow closing chord.

Let `G` be properly edge-colored and

\[
P=v_0v_1\cdots v_\ell
\]

be a rainbow path. Let `C(P)` be its set of path colors. Say `P` is terminally maximal at `x=v_ell` when there is no edge from `x` to a vertex outside `P` whose color is not in `C(P)`. Define

\[
h(P,x):=\#\{e\ni x:\chi(e)\in C(P)\}.
\]

Put `D=deg_G(x)`.

### Theorem 5.1

If `D-h(P,x)>=2`, then `G` contains a rainbow cycle of length at least

\[
\boxed{D-h(P,x)+1.}
\]

### Proof

Write `h=h(P,x)` and

\[
L=D-h+1.
\]

Every edge at `x` whose color is not in `C(P)` must end inside `P`, by terminal maximality. There are `D-h` such fresh-color edges. The predecessor `v_{ell-1}` cannot be the endpoint of a distinct fresh-color simple edge because `xv_{ell-1}` is already the path edge. Thus `D-h<=ell-1`, so `L<=ell`.

Assume no rainbow cycle has length at least `L`. Consider a fresh-color chord `xv_i`. If

\[
i\le \ell-L+1,
\]

the suffix `v_i v_{i+1} ... v_ell`, together with `xv_i`, is a rainbow cycle: the suffix uses distinct path colors while the chord color is absent from `C(P)`. Its length is `ell-i+1>=L`, contradiction.

Therefore every fresh-color edge at `x` must hit one of at most `L-2` terminal path vertices. Hence

\[
D\le h+(L-2)=h+(D-h+1)-2=D-1,
\]

impossible. The claimed rainbow cycle exists. ∎

### Consequence

Inside the cross-core projection it suffices to find one terminally maximal endpoint with

\[
\deg(x)=\Omega(d),\qquad h(P,x)=o(d).
\]

This reduces the rainbow-cycle closure problem to one scalar capture quantity.

## 7. B14 — exchangeability and deferred endpoint capture

### 7.1 Exact matching symmetry

For an open witness neighborhood of size `k`, a uniformly random maximum matching pairs any prescribed pair of open vertices with probability

\[
\rho(k)=
\begin{cases}
1/(k-1),&k\text{ even},\\
1/k,&k\text{ odd}.
\end{cases}
\]

Witness matchings are independent. Hence any fixed candidate rainbow cycle supported by distinct witnesses has conditional matching probability equal to the product of these local `rho(k)` factors.

The more useful application is a deferred endpoint estimate.

### 7.2 Deferred endpoint lemma

Let

\[
P=v_0\cdots v_\ell
\]

be a projected rainbow path with distinct used witnesses `b_1,...,b_ell`, ending at `x=v_ell`. For an old color `b_i` to appear on any projected edge incident with `x`, the physical percolation edge `xb_i` must be open. Hence

\[
1_{\{x\text{ incident to projected color }b_i\}}
\le
1_{\{xb_i\text{ open}\}}.
\]

Suppose a sigma-field `F` determines the path skeleton / used colors and certifies terminal maximality with respect to fresh colors at `x`, while the Bernoulli variables

\[
1_{\{xb_i\text{ open}\}},\qquad i<\ell,
\]

remain unexposed and independent of `F`. The entering path color contributes at most one captured edge. Therefore, conditionally on `F`,

\[
\boxed{h(P,x)\preceq 1+\operatorname{Bin}(\ell-1,p).}
\]

This is exact stochastic domination.

If `ell<=Ad` and `p=c/d`, the binomial mean is at most `Ac`. Taking

\[
H_d=\lceil d^{1/3}\rceil
\]

gives the standard tail estimate

\[
\Pr(h(P,x)\ge 1+H_d\mid F)
\le
\left(\frac{eAc}{H_d}\right)^{H_d}
=
\exp[-\Omega(d^{1/3}\log d)].
\]

Combining with Theorem 5.1, any such deferred terminal endpoint with

\[
\deg(x)\ge \kappa d/5
\]

would produce a rainbow projected cycle of length at least

\[
\boxed{\kappa d/5-d^{1/3}},
\]

and therefore an `Omega(d)` physical simple cycle.
