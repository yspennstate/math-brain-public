## 4. Exact blocker after the first recovery cycle

The cumulative reductions leave a bipartite cross core

```text

```

with fixed positive constants `c_A,c_B,c_E` depending only on the source epsilon such that

```text
delta_A(J) >= c_A d^2,
delta_B(J) >= c_B d,
E >= c_E n d.                                           (4.1)
```

For the uniform-edge law `nu`, write

```text
U(a,b)=d_a d_b/E.                                       (4.2)
```

For dyadic endpoint-degree scale variables `I,J`, write

```text
P_ij=P(I=i,J=j),
P_i=sum_j P_ij,
Q_j=sum_i P_ij,
alpha_ij=P_ij/P_i,
beta_ij=P_ij/Q_j,
Phi(2)=sum_ij P_ij alpha_ij beta_ij.                    (4.3)
```

Let

```text
N=D_A^(-1/2) A_J D_B^(-1/2),
Xi(J)=||N||_F^2=sum_{ab in E(J)}1/(d_a d_b).            (4.4)
```

The preceding runs prove that every still-unresolved cross-core sequence must satisfy simultaneously

```text

H(J|I)+H(I|J) -> infinity,
U=d_a d_b/E -> 0 in uniform-edge probability,
Xi(J)=stable-rank(N) -> infinity,                       (4.5)
```

while retaining (4.1). The normalized-incidence operator always has `||N||_op=1`; therefore the last condition is genuine rank dispersion, not spectral-radius growth.

## 7. Simplest still-unproved model: one regular connector side, infinitely many A-scales

The previous report's four degenerations can already occur with **only one side multiscale**. This is therefore a cleaner final laboratory than a fully two-sided diffuse transport matrix.

Fix constants `s,r>0` and let `S=s d` (integer-rounded). Consider bipartite graphs `J=(A,B)` with

```text
deg(b)=S for every b in B,
deg(a)>=r d^2 for every a in A.                          (7.1)
```

Partition A into `k=k(d)->infinity` degree classes `A_1,...,A_k`. An exact canonical block model can be made by choosing degrees `R_i>=r d^2`, a B-population `M=|B|` with `max_i R_i/M->0`, and for every i placing an `(R_i,S/k)`-biregular simple graph between `A_i` and the common B-side, with

```text
|A_i| R_i = M S/k.                                      (7.2)
```

Under the divisibility conditions and `R_i<=M`, standard biregular realizations exist; the k cell graphs are edge-disjoint because their A-sides are disjoint. Every B-vertex then has total degree exactly S and each A_i-edge class has exactly `1/k` of total incidence mass.

For the degree-scale transport matrix this model has one B column and

```text
P_i=1/k,
alpha_i=1,
beta_i=1/k,
Phi(2)=1/k -> 0,
H(J|I)+H(I|J)=log k -> infinity.                        (7.3)
```

Also

```text
U on A_i x B = R_i/M,
```

so `max_i R_i/M->0` gives the required low-product escape, and then

```text
Xi(J)=(1/k) sum_i M/R_i -> infinity.                    (7.4)
```

Thus this **one-sided diffuse block core** realizes every current obstruction while removing all within-cell irregularity and all B-degree irregularity.

There is one further useful filter. Since

```text
m=|A| <= E/(r d^2)=MS/(r d^2)=O(M/d),
```

the average degree of J is

```text
D_J=2MS/(M+m)=2S(1-o(1))=2s d(1-o(1)).                 (7.5)
```

The already-proved global `K>2` theorem therefore closes this laboratory whenever

```text
s(1+epsilon)>1
```

by a fixed margin. The genuinely unresolved one-sided laboratory can be restricted to

```text
0<s<=1/(1+epsilon),                                    (7.6)
```

where a typical B-vertex has open degree mean `pS=s(1+epsilon)<=1` and all useful surplus must be assembled through alternating two-step mass across the A-scales.

This is the simplest model I know that simultaneously preserves the source difficulty and realizes the exact low-product/high-rank/diffuse-transport boundary. It is **not claimed solved** here.
