## 4. B14 — exact periodic-center no-go theorem

For the cumulative `U_{d,p}` row walk, a support vector `X=(X_0,...,X_{p-1})` records a residue occupancy vector of a `d`-tuple satisfying

\[
\sum_j jX_j\equiv0\pmod p.
\]

For `k in F_p`, put

\[
c_k=(2\pi kj/p)_{j=0}^{p-1}.
\]

Then every support vector has `exp(i<c_k,X>)=1`, so its characteristic function obeys the exact period

\[
\phi(s+c_k)=\phi(s).
\tag{4.1}
\]

If `m` is a feasible sum of `N` row steps, then also `sum_j j m_j=0 mod p`, so the complete Fourier coefficient integrand

\[
I_m(s)=\phi(s)^Ne^{-i\langle s,m\rangle}
\]

satisfies

\[
I_m(s+c_k)=I_m(s).
\tag{4.2}
\]

Thus the `p` structured one-row saddle neighborhoods are exact phase-coherent translates, not approximately duplicated configurations.

For a fixed symmetric undirected type `M=(m_ij)`, this applies independently to every feasible row target. The constraint `m_ij=m_ji` couples the targets but does not constrain the row period labels. Consequently the `p^p` center tuples in the product row representation are genuine exact periods.

**Conclusion:** the proposed B14 route “use simultaneous row symmetry to quotient most structured saddles away” cannot improve the exponent by itself. A successful collective Fourier argument would need information absent from the product of separate row coefficient formulas. This is a useful no-go theorem and prevents an expensive but false orbit-counting route.

## 5. B21 — integer-cokernel endpoint reduction

For an integer matrix `A`, define

\[
C_A=\mathbb Z^n/A\mathbb Z^n,
\qquad
H_q(A)=|\operatorname{Hom}(C_A,\mathbb Z/q\mathbb Z)|.
\]

A homomorphism is represented by a row vector `y mod q` annihilating `A`, so

\[
H_q(A)=|\ker(A^T\bmod q)|.
\tag{5.1}
\]

If `det A=0`, Smith normal form gives a free `Z` summand in `C_A`, hence `H_q(A)>=q`. Therefore the following deterministic inequality is exact:

\[
\boxed{
\mathbf 1_{\{\det A=0\}}
\le \frac{H_q(A)-1}{q-1}.
}
\tag{5.2}
\]

Moreover, because `Z/qZ` has one subgroup of each order `r|q`, every homomorphism has a unique image order and

\[
\boxed{
H_q(A)=\sum_{r\mid q}|\operatorname{Sur}(C_A,\mathbb Z/r\mathbb Z)|.
}
\tag{5.3}
\]

Now choose four distinct primes

\[
p_i\asymp n^{1/4}/L(n),\qquad L(n)=n^{o(1)},
\]

and let `q=p_1p_2p_3p_4=n^{1-o(1)}`. Since squarefree `q` has only sixteen divisors, the uniform estimate

\[
\max_{r\mid q}
\mathbb E|\operatorname{Sur}(C_{A_{n,3}},\mathbb Z/r\mathbb Z)|
\le n^{o(1)}
\tag{5.4}
\]

would imply `EH_q<=n^{o(1)}` and then by (5.2)

\[
\Pr(A_{n,3}\text{ singular})\le n^{-1+o(1)}.
\]

So (5.4) is an exact sufficient condition for the cubic source endpoint `a_3=1` using only primes individually inside the already reached quarter-power scale.

The gap is explicit and noncircular: existing fixed-finite-group cokernel results do not automatically give (5.4) for groups whose order grows with `n`. A proof needs quantitative uniformity in the group size and, for the exact simple-graph source model, a transfer that remains valid for this unbounded observable rather than bare contiguity.

## 6. B27 — swap the prime quantifier and weaken to one mixed moment

For a prime `p`, write

\[
L_p(A)=\frac{H_p(A)-1}{p-1}.
\]

If `nu_p=dim ker(A mod p)`, then

\[
L_p=0\quad(\nu_p=0),
\qquad
L_p=1+p+\cdots+p^{\nu_p-1}\quad(\nu_p\ge1).
\]

If `det A=0` over `Q`, a primitive integer null vector remains nonzero modulo every prime. Hence `L_p(A)>=1` for every prime, and for any distinct primes

\[
\boxed{
\mathbf1_{\{\det A=0\}}
\le\prod_iL_{p_i}(A).
}
\tag{6.1}
\]

Therefore, with four quarter-scale primes, it is enough to prove the single joint estimate

\[
\boxed{
\mathbb E\prod_{i=1}^4L_{p_i}(A_{n,3})
\le n^{-1+o(1)}.
}
\tag{6.2}
\]

This is weaker than controlling all divisor surjection moments. Indeed CRT gives

\[
H_q=\prod_i[1+(p_i-1)L_{p_i}],

so the top mixed term is bounded by `EH_q` divided by `prod_i(p_i-1)`.

The scale is sharp rather than overstrong: the conjecturally dominant real twin event forces modular nullity at every prime and contributes at the same `n^{-1+o(1)}` scale to the left side of (6.2). The new obstruction is therefore precisely the probability/mass of **simultaneous modular singularity without real singularity**, including large-nullity tails.
