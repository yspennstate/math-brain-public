# 2. B3 — exact two-matching large-deviation theorem

The previous run converted the colored cubic model into an exact contingency/mutual-information problem. This run completes the first-two-matching exposure calculation rather than guessing a large-deviation rate.

Let

\[
A_{\rm col}=P_{M_1}+P_{M_2}+P_{M_3},
\]

where the `M_j` are independent uniform perfect matchings on `[n]`. Fix `y in F_p^n` with empirical profile `alpha`. At a uniformly chosen coordinate put

\[
A=y_i,\qquad B=y_{M_1(i)},\qquad C=y_{M_2(i)}.
\]

For one matching, if `gamma_ab` is the oriented empirical table of `(A,B)`, then `gamma` is symmetric with both marginals `alpha`. The number of perfect matchings inducing a feasible table is exactly

\[
\boxed{
N(\gamma)=
\frac{\prod_a(n\alpha_a)!}
{\prod_{a<b}(n\gamma_{ab})!\prod_a2^{n\gamma_{aa}/2}(n\gamma_{aa}/2)!}.
}
\tag{2.1}
\]

Therefore

\[
\log\Pr(\gamma)=-\frac n2 I(A;B)+O(k^2\log(n+1)),
\tag{2.2}
\]

uniformly when the row support has size `k`.

For two independent matchings let `tau_abc` be the empirical triple law of `(A,B,C)`. Conditioned on the two pair tables, the exact hypergeometric probability of `tau` is

\[
\boxed{
\Pr(\tau\mid\gamma^{(1)},\gamma^{(2)})
=
\prod_a
\frac{\left[\prod_b(n\gamma^{(1)}_{ab})!\right]
      \left[\prod_c(n\gamma^{(2)}_{ac})!\right]}
     {(n\alpha_a)!\prod_{b,c}(n\tau_{abc})!}.
}
\tag{2.3}
\]

Combining (2.2) for the two matchings with (2.3) gives

\[
\boxed{
\log\Pr(\tau)
=-nJ(\tau)+O(k^3\log(n+1)),
}
\tag{2.4}
\]

where

\[
J(\tau)=\frac12I(A;B)+\frac12I(A;C)+I(B;C\mid A).
\tag{2.5}
\]

Now set

\[
Z:=-(B+C).
\]

Third-matching closure requires `P_{M_3}y=Z`, so the empirical marginal of `Z` must again equal `alpha`. The exact matching-to-target formula from the preceding run yields

\[
\log\Pr(P_{M_3}y=Z\mid\tau)
=-nH(\alpha)+\frac n2I(A;Z)+O(k^2\log n).
\tag{2.6}
\]

There are `exp(nH(alpha)+O(k log n))` rows with profile `alpha`, so the row entropy cancels (2.6). The residual rate is exactly determined by the following identity.

### Theorem 2.1 — three-defect decomposition

For every joint law of `(A,B,C)` and every deterministic `Z=f(B,C)`,

\[
\boxed{
J-\frac12I(A;Z)
=\frac12\left[I(B;C)+I(B;C\mid A)+I(A;B,C\mid Z)\right].
}
\tag{2.7}
\]

Proof: the co-information identity

\[
I(A;C\mid B)=I(A;C)+I(B;C\mid A)-I(B;C)
\]

gives

\[
2J-I(A;B,C)=I(B;C\mid A)+I(B;C).
\]

Since `Z` is a deterministic function of `(B,C)`,

\[
I(A;B,C)=I(A;Z)+I(A;B,C\mid Z).
\]

Substitution proves (2.7). ∎

Define the nonnegative information defect

\[
\boxed{
\Delta(\tau):=I(B;C)+I(B;C\mid A)+I(A;B,C\mid Z).
}
\tag{2.8}
\]

Every feasible profile/type contribution to the normalized first-moment calculation therefore has exponential factor

\[
\boxed{
\exp\left[-\frac n2\Delta(\tau)+O(k^3\log(n+1))\right].
}
\tag{2.9}
\]

At a prime

\[
p\asymp n^{1/3}/(\log n)^2,
\]

we have `p^3 log n=O(n/log^5 n)`. The logarithm of the total number of empirical triple tables is of the same order. Hence every class with `Delta>=epsilon>0` is exponentially negligible even after summing all types. Only

\[
\boxed{
\Delta=O(p^3\log n/n)=O((\log n)^{-5})
}
\tag{2.10}
\]

can survive this entropy calculation.

# 3. B17 — classify the exact zero-defect profile and import the right analogue

Pinsker immediately gives

\[
I(B;C)\ge2\,TV(P_{BC},P_BP_C)^2
\]

and analogous conditional forms for the other two summands in `Delta`. Thus near-zero `Delta` means simultaneous approximate unconditional independence, conditional independence given `A`, and conditional independence of `A` from `(B,C)` given `Z`.

The exact zero set can be classified completely under the matching marginal constraint.

### Theorem 3.1 — zero-defect source-compatible profiles

Assume `p>3`, `Z=-(B+C)`, the four marginals of `A,B,C,Z` are all `alpha`, and `Delta=0`. Then either

1. `alpha` is uniform on `F_p`, or
2. `alpha=delta_0`.

Proof: `Delta=0` gives `I(B;C)=0`, so `B,C` are independent copies of `alpha`. Since `Z` also has law `alpha`,

\[
\alpha=R(\alpha*\alpha),
\tag{3.1}
\]

where `R mu(x)=mu(-x)`. Let `S=B+C`. Equation (3.1) gives `H(S)=H(alpha)=H(B)`, while independence gives `H(S|C)=H(B)`. Hence `I(S;C)=0`. The conditional law of `S` given `C=c` is `alpha` translated by `c`; all these translates are therefore equal. If the support of `alpha` contains distinct `c,c'`, then `alpha` is invariant under translation by nonzero `c-c'`, which generates the additive group of `F_p`; therefore `alpha` is uniform. If the support is a singleton `{a}`, (3.1) gives `a=-2a`, so `3a=0`; for `p>3`, `a=0`. ∎

Quantitatively, contraction of total variation under addition and Pinsker give

\[
\boxed{
TV(\alpha,R(\alpha*\alpha))\le\sqrt{\Delta/2}.
}
\tag{3.2}
\]

For additive Fourier coefficients this implies

\[
\left|\widehat\alpha(r)-\overline{\widehat\alpha(r)}^{\,2}\right|
\le2\,TV(\alpha,R(\alpha*\alpha)),
\]

hence

\[
|\widehat\alpha(r)|(1-|\widehat\alpha(r)|)
\le2\,TV(\alpha,R(\alpha*\alpha)).
\tag{3.3}
\]

So every Fourier mode of a near-zero-defect empirical law is forced toward either modulus zero or modulus one.

# 4. B9 — randomize multiplicative charge flows

The earlier Fourier-Hafnian decomposition attaches a multiplicative character of `F_p^*` to every oriented edge. In additive notation the character group is an abelian group `Q` of size `q=p-1`, and the cubic tensor enforces ordinary flow conservation.

For a connected graph `G=(V,E)`, the group of `Q`-valued flows has exactly

\[
q^{|E|-|V|+1}
\]

elements: prescribe arbitrary charges on non-tree edges and solve uniquely on a spanning tree.

Three structural facts follow.

1. The nonzero support of any flow has no support-degree-one vertex, by conservation. Every nonempty support component contains a cycle.
2. For an edge subgraph `H`, the number of flows whose support lies in `H` is at most `q^{|E(H)|-|V(H)|+c(H)}`.
3. If `e` is not a bridge, evaluation of a uniform flow at `e` is uniform on `Q`; hence `Pr(eta_e=0)=1/q`. In a connected cubic graph the expected number of zero-charged non-bridge edges is `O(n/p)`.

Thus typical charge flows are dense at growing `p`, while sparse exceptional flows are confined to cycle-rich subgraphs. This is exactly the structural separation B9 sought.

But it does not close the tensor estimate: every nontrivial character block is unitary of dimension `p+1`. Individual orbit-coordinate entries are `O(p^{-1/2})` twisted Kloosterman sums, yet summing over the orbit coordinates can restore unit operator norm. Treating the entrywise square-root gain as multiplicative would repeat the B26 failure.

**B9 outcome:** useful typical/exceptional flow theorem; no valid global multilinear contraction and therefore no source-metric movement.
