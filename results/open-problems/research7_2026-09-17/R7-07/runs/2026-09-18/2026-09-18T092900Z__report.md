## Idea before code

The preceding run showed that Huang's sparse non-equidistributed class was the source of the old cubic `1/9` restriction; after a field-independent support sieve, the first published obstacle became Huang's equidistributed estimate at `p << n^(1/8)`. This run separated the three `p^4` losses in that estimate rather than treating them as one barrier.

The core observation is that Nguyen--Pan's directed method uses exactly the same finite-field random walk `X` on `U_{d,p}` as Huang's undirected row decomposition. Thus the explicit cubic characteristic-function term is available **before** the symmetric edge-count coupling enters. The directed/undirected distinction first bites only when the row Fourier integrals must be recombined over the symmetric matrix `M=[m_ij]`.

At the same time, Huang's congruence-correction matrix can be chosen far more sparsely than an entrywise `O(p)` bound suggests. Finally, the raw symmetric count lattice has covering radius `O(p)`, making its pure Riemann-cell distortion compatible with a `1/6` scale.

The exact blocker is now: retain the cubic phase through the **global symmetric `M`-sum** without replacing it by a uniform absolute error.

# Method B21 — import the directed cubic invariant, with hypotheses checked

For each fixed row in Huang's undirected formula (4.3), conditional on its row size `n_i`, the probability factor is

\[
\Pr(X_1+\cdots+X_{n_i}=m_i),
\]

with independent copies of the uniform `U_{d,p}` random variable. Nguyen--Pan use the same `U_{d,p}` variable. Therefore their moment calculation transfers to each row without importing any directed independence beyond what Huang already has row-wise.

For `mu=(d/p)1`, `s perpendicular to 1`, and `Y_s=<s,X-mu>`, their explicit calculation gives

\[
EY_s=0,\qquad EY_s^2=\frac d p\|s\|_2^2,
\]

\[
EY_s^3=\frac{C_{d,p}}p\sum_j s_j^3,
\qquad C_{d,p}=d+O_d(p^{-1}),
\]

and

\[
EY_s^4\le C_d\left(p^{-2}\|s\|_2^4+p^{-1}\sum_j s_j^4\right).
\]

Thus the third moment is a controlled cubic invariant, not an unspecified `O(||s||^3/p)` remainder.

**Outcome.** The Nguyen--Pan improvement is locally reusable in the symmetric model. The first non-transferable step is later: directed types are described by one global type vector, whereas the undirected model must sum over a symmetric `p x p` edge-count matrix.

# Method B7 — retain the cubic phase and push the local Taylor limit to 1/6

Taylor expansion gives

\[
\phi(s):=Ee^{iY_s}
=1-\frac d{2p}\|s\|_2^2
-i\frac{C_{d,p}}{6p}\sum_j s_j^3
+O_d\left(p^{-2}\|s\|_2^4+p^{-1}\sum_j s_j^4\right).
\]

For sufficiently small fixed `||s||`, applying `log(1+z)=z+O(z^2)` yields

\[
\log\phi(s)
=-\frac d{2p}\|s\|_2^2
-i\frac{C_{d,p}}{6p}\sum_j s_j^3
+R(s),
\]

with

\[
|R(s)|\le C_d\left(p^{-2}\|s\|_2^4+p^{-1}\sum_j s_j^4\right)
\le C_d p^{-1}\|s\|_2^4.
\]

On Huang's full central Fourier ball

\[
\|s\|_2^2\le c p^4\log n/n
\]

and for `N asymp n/p`,

\[
N|R(s)|
\le C_d\frac n{p^2}\left(\frac{p^4\log n}{n}\right)^2
=C_d\frac{p^6(\log n)^2}{n}.
\]

Hence

\[
\phi(s)^N
=
\exp\left(-\frac{dN}{2p}\|s\|^2
-i\frac{C_{d,p}N}{6p}\sum_j s_j^3\right)
\left(1+O_d\left(\frac{p^6(\log n)^2}{n}\right)\right).
\]

So the **local characteristic-function remainder** is compatible with `p << n^(1/6)` once the cubic phase is retained. Huang's `1/8` loss at this stage comes from discarding that phase, not from the fourth-order remainder itself.

**Failure/gap.** This does not yet evaluate the cubic-corrected Fourier integral after summing over symmetric `M`. Dropping the cubic now would simply recreate the old barrier.

# Method B30 — localize the congruence and lattice losses

## B30.1 Exact sparse congruence correction

Huang's exact class `E` imposes row congruences. Given residues

\[
r_i\pmod d,\quad \sum_i r_i=0\pmod d,
\qquad s_i\pmod p,
\]

we constructed a symmetric integer correction `Delta` satisfying

\[
\sum_j\Delta_{ij}\equiv r_i\pmod d,
\qquad
\sum_j j\Delta_{ij}\equiv s_i\pmod p,
\]

with even diagonal and total sum zero, while also proving

\[
\boxed{\max_{ij}|\Delta_{ij}|=O_d(p),\qquad
\|\Delta\|_F=O_d(p^{3/2}).}
\]

The construction is explicit.

1. Choose exact row sums `R_i` in the required mod-`d` classes, with `sum R_i=0` and `sum iR_i=sum s_i (mod p)`. Only coordinates 0 and 1 require `O(p)` corrections, so `||R||_2=O_d(p)`.
2. Realize these row sums by a symmetric matrix `B` with even diagonal: pair the odd `R_i`, put a `1` on each paired off-diagonal edge, and set `B_ii=R_i-o_i`. Then `||B||_F=O_d(p)`.
3. Let the remaining weighted-moment error be `tau`, which has zero total modulo `p`. On the path `0-1-...-(p-1)`, put
   \[
   C=2\sum_{k=1}^{p-1}c_k(e_{k-1}-e_k)(e_{k-1}-e_k)^T,
   \]
   where
   \[
   2c_k\equiv-\sum_{i<k}\tau_i\pmod p,\qquad |c_k|\le p/2.
   \]
   Then `C` has zero row sums, even diagonal, and its weighted moment is exactly `tau` modulo `p`. It is tridiagonal with `O(p)` entries of size `O(p)`, so `||C||_F=O(p^(3/2))`.
4. Set `Delta=B+C`.

For Huang's quadratic exponent

\[
Q(A)=\frac{dnp^2}{4}\operatorname{Tr}A^2
-\frac{(d-1)np}{2}\|A1\|_2^2,
\]

his diagonalization gives operator norm `O_d(np^2)`. On `||A||_F<=sqrt(b log n/n)` and with `H=Delta/(dn)`,

\[
|Q(A+H)-Q(A)|
\le C_dnp^2(2||A||||H||+||H||^2)
\]

and therefore

\[
\boxed{
|Q(A+H)-Q(A)|
\le C_d\left(
\frac{p^{7/2}\sqrt{\log n}}{\sqrt n}
+\frac{p^5}{n}
\right).
}
\]

Thus **the congruence-translation distortion itself** is compatible with `p^7 log n=o(n)`, a `1/7` scale.

## B30.2 The raw lattice mesh is only O(p)

For the difference lattice

\[
\Lambda=\{H=H^T\in\mathbb Z^{p\times p}:H_{ii}\text{ even},\ \sum_{ij}H_{ij}=0\},
\]

we proved covering radius `rho(Lambda)=O(p)` in Frobenius norm. Coordinatewise rounding gives `O(p)` error; the resulting even total-sum defect is `O(p^2)` and can be repaired by changing `O(p^2)` distinct symmetric off-diagonal pairs by one unit, which adds only `O(p)` in Frobenius norm.

After normalizing by `dn`, a cell has radius `O_d(p/n)`, and the quadratic exponent varies across a central cell by at most

\[
O_d\left(
\frac{p^3\sqrt{\log n}}{\sqrt n}
+\frac{p^4}{n}
\right).
\]

Hence the intrinsic Riemann-cell distortion is compatible with the `1/6` scale; it is not fundamentally a `1/8` barrier.

**Boundary caveat.** The pointwise correction and covering lemmas are complete. Inserting them into the full truncated Gaussian sum still requires boundary-shell bookkeeping. No full Proposition 4.1 extension is claimed here.

# Exact blocker after all three methods

With the cubic term retained, each central row integral has the schematic form

\[
I_i(M)=\int_{1^\perp}
\exp\left(
-\frac{dn_i}{2p}\|s\|^2
-i\langle s,b_i(M)\rangle
-i\frac{C_{d,p}n_i}{6p}\sum_j s_j^3
\right)ds
\]

up to fourth-order relative error `O(p^6(log n)^2/n)` and exponentially small outer-frequency tails.

The remaining task is to show that

\[
\sum_{M\in E}W_{St}(M)\prod_i I_i(M)
\]

has the same leading value as Huang's quadratic Gaussian sum for at least `p << (n/log n)^(1/7)`. This is the **symmetric cubic-gluing lemma**. Symmetry `m_ij=m_ji` couples the row targets, so the directed one-vector calculation does not directly factor.

If that lemma is proved, the previous sparse-class sieve plus the new `O(p^(3/2))` congruence correction would immediately permit a prime `p=n^(1/7-o(1))` and hence the conditional improvement

\[
a_3\ge 1/7.
\]

That implication is recorded only as conditional. `a_3>=1/7` is **not** claimed in this run.

Simplest unresolved central case: `d=3`, exact uniform row sizes `n_i=n/p`, and the symmetric cubic-gluing sum with no row-size perturbation.
