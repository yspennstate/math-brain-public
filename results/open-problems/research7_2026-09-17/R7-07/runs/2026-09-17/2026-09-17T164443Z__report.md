## 4. B19 — constructive algorithm: exact DFS long-chord criterion

The main idea is to let DFS expose only edges that are necessary to decide whether a new vertex is discovered. Edges left unqueried are then not useless: by the defining DFS geometry, they all run along ancestor--descendant pairs. If sufficiently many such host edges remain, independent percolation turns one of the long ones into a cycle.

Let `G=(V,E)` be any finite simple graph with `|V|=n`, `|E|=m`, and let `G_p` be obtained by retaining every host edge independently with probability `p`.

Run deterministic depth-first search as follows. Fix deterministic orders of vertices and adjacency lists. From the current stack top `v`, query an as-yet-unqueried host edge `vw` only when `w` is still unvisited. If the query is positive, make `w` a child of `v` and descend. If the query is negative, continue. When the current vertex has no remaining unvisited neighbor, pop it. When a DFS tree finishes, start the next unvisited vertex as a new root. Let `F` be the resulting DFS forest, `Q` the number of queried host edges, and `U=m-Q` the number of unqueried host edges.

### Lemma 4.1 — queried outcomes are an adaptive iid Bernoulli sequence

Conditional on every previous query and every deterministic choice made by the algorithm, the next queried host edge has not previously been inspected. Its state is therefore an independent Bernoulli(`p`) variable. Thus the sequence of query outcomes, up to the random stopping time `Q`, is an iid Bernoulli(`p`) sequence.

Every positive query discovers a previously unvisited vertex. Hence the total number of positive queries is at most `n-1`.

### Lemma 4.2 — every unqueried edge is ancestor--descendant

For every host edge `uv` that is never queried, `u` and `v` are comparable in the ancestor order of the final DFS forest `F`.

**Proof.** Suppose without loss of generality that `u` is discovered first. If `v` were still unvisited when `u` was eventually popped, then DFS would have queried `uv` before popping `u`; contradiction. Hence `v` is discovered before `u` is popped. During that entire interval `u` stays on the DFS stack, so every newly discovered vertex is a descendant of `u`. Thus `v` is a descendant of `u`. `□`

### Lemma 4.3 — exact long-chord count

Fix an integer `L>=2`. Among all unqueried host edges, at most `n(L-1)` have endpoints at DFS-tree distance strictly less than `L`.

**Proof.** Orient every unqueried edge from its descendant endpoint toward its ancestor endpoint. A fixed descendant vertex has at most one ancestor at each distance `1,2,...,L-1`; hence at most `L-1` such short unqueried edges can be charged to it. Summing over the `n` descendants gives the claim. `□`

Consequently at least

`R_L := [m-Q-n(L-1)]_+`

unqueried host edges join an ancestor to a descendant at tree distance at least `L`.

### Lemma 4.4 — conditional cycle bound

Conditional on the complete DFS query history, the statuses of all unqueried host edges remain mutually independent Bernoulli(`p`) variables. If any of the `R_L` long unqueried edges is open, its endpoints are joined by the already-open DFS-tree path of length at least `L`, so the edge closes a simple cycle of length at least `L+1`.

Therefore

`P(no cycle of length >=L+1 | DFS history)`
`<= (1-p)^{R_L}`
`<= exp(-p R_L)`.                                          `(4.1)`

Equivalently,

`P(no cycle of length >=L+1 | history)`
`<= exp(-p [m-Q-n(L-1)]_+)`.                              `(4.2)`

This is an exact deterministic/probabilistic reduction. The single blocking variable is now `Q`, the amount of host edge mass consumed by DFS queries.

## 5. B19 — universal theorem for every multiplier `K>2`

The preceding criterion gives a clean source-level theorem.

### Theorem 5.1 — uniform `K>2` long-cycle theorem

Fix `K>2`. Put

`alpha := (K-2)/4`,

`beta := 1/2 - (1+alpha)/K = (K-2)/(4K)`,

and

`gamma_K := beta/2 = (K-2)/(8K)`.

Then there are `d_0=d_0(K)` and constants `c_1(K),c_2(K)>0` such that for every sufficiently large host order `n`, every finite simple graph `G` on `n` vertices of average degree `d>=d_0`, and every `p>=K/d`,

`P(G_p has no cycle of length >= gamma_K d)`
`<= exp(-c_1(K)n) + exp(-c_2(K)n)`.

In particular every fixed `K>2` is admissible in the definition of `K_long`, so

`K_long <= 2`.

### Proof

By monotonicity in `p`, it is enough to prove the assertion at

`p_0 := K/d`.

Choose `d_0>=K` so that `p_0<=1` and so the harmless integer inequalities below hold. Write `m=nd/2`.

Run the DFS from Section 4 at `p_0`. Let

`q_0 := ceil((1+alpha)n/p_0)`.

Because

`(1+alpha)/K = (K+2)/(4K) < 1/2`,                         `(5.1)`

we have `q_0<=m` for all sufficiently large `n`.

If `Q>=q_0`, then among the first `q_0` iid Bernoulli(`p_0`) queries there are at most `n-1` successes, by Lemma 4.1. Let

`X ~ Bin(q_0,p_0)`.

Its mean obeys

`mu=q_0 p_0 >= (1+alpha)n`.

Since `n-1<n<=mu/(1+alpha)`, the multiplicative Chernoff lower-tail bound gives

`P(Q>=q_0)`
`<= P(X<=n-1)`
`<= exp(- alpha^2 n / (2(1+alpha)))`.                     `(5.2)`

With the chosen `alpha`, one may take explicitly

`c_1(K)=(K-2)^2/[8(K+2)]`.                                `(5.3)`

Now work on the complementary event `Q<q_0`. Since `Q` is an integer and `q_0=ceil((1+alpha)n/p_0)`,

`Q < (1+alpha)n/p_0`.

Hence the number of unqueried host edges satisfies

`U=m-Q`
`> nd/2 - (1+alpha)n d/K`
`= beta nd`.                                               `(5.4)`

Take

`L := floor(beta d/2)`.

By Lemma 4.3, the number `R` of unqueried host edges whose DFS-tree endpoints are at distance at least `L` satisfies

`R >= U - n(L-1)`
`> beta nd - beta nd/2`
`= beta nd/2`.                                             `(5.5)`

Conditional on the DFS history, all these long unqueried edges remain independent Bernoulli(`p_0`). If one is open, it closes a simple cycle of length at least `L+1`. Therefore by Lemma 4.4,

`P(no cycle of length >=L+1 | history, Q<q_0)`
`<= exp(-p_0 R)`
`< exp(- (K/d)(beta nd/2))`
`= exp(-K beta n/2)`
`= exp(-(K-2)n/8)`.                                       `(5.6)`

Thus one may take

`c_2(K)=(K-2)/8`.                                         `(5.7)`

Finally,

`L+1 > beta d/2 = gamma_K d`.                             `(5.8)`

Combining (5.2) and (5.6) proves the theorem. `□`

## 6. Why the same global DFS count stops exactly at multiplier 2

The proof also diagnoses its own sharp obstruction.

At general source-scale

`p=(1+epsilon)/d`,

the total number of host edges is `m=nd/2`, so even if DFS queried **every** host edge, the expected number of positive queries would be only

`pm=(1+epsilon)n/2`.                                      `(6.1)`

When `0<epsilon<1`, this is strictly less than `n`. But DFS is allowed as many as `n-1` positive discovery queries. Therefore the crude global success budget does not make `Q=m` exponentially unlikely. In other words, the global query-deficit argument has an intrinsic factor-two wall:

`pm>n` precisely when the multiplier exceeds 2.              `(6.2)`

So merely sharpening Chernoff constants cannot push Theorem 5.1 from `K>2` to the conjectured `K>1`. The next proof must exploit **where** positive discoveries occur, not only how many occur globally.

This is a useful failure, not a source resolution.

## 7. B14 — symmetry/quotient stress test: a cyclic clique-chain

The previous report suggested that failure of a nonbacktracking-overlap argument might force a fixed fraction of Perron mass to localize in one `O(d)`-vertex set. The following exact symmetric family shows that this static picture is too narrow: nonbacktracking trajectories can be dynamically trapped for `Theta(d)` steps inside one of **many** small blocks even though no individual block carries appreciable global stationary mass.

### Construction 7.1

Fix integers `M>=3` and `d>=3`. Take disjoint blocks

`V_0,...,V_{M-1}`,

where every `V_i` spans a copy of `K_{d+1}`. In block `i` choose distinct vertices `a_i,b_i`, delete the internal edge `a_i b_i`, and add the cross edge

`b_i a_{i+1}`

with indices modulo `M`. Call the resulting graph `H_{M,d}`.

### Lemma 7.2 — exact degree and Hashimoto data

`H_{M,d}` is connected and `d`-regular on

`n=M(d+1)`

vertices. Therefore its average degree is exactly `d`.

Its Hashimoto matrix `B` satisfies

`B 1 = (d-1) 1`,

because every directed edge has exactly `d-1` legal nonbacktracking successors. Hence

`rho(B)=d-1`.                                               `(7.1)`

At the conjectured scale `p=(1+epsilon)/d`,

`p rho(B)=(1+epsilon)(1-1/d)`,                              `(7.2)`

which is at least `1+epsilon/2` for sufficiently large `d`.

Thus this family has exactly the same uniform nonbacktracking supercritical margin obtained abstractly in the preceding report.

### Lemma 7.3 — no static `O(d)` set has macroscopic stationary mass

For the nonbacktracking Markov chain

`Q=B/(d-1)`,

the uniform measure on directed edges is stationary. Since the graph is `d`-regular, the induced head-vertex stationary measure is uniform on vertices.

Therefore every vertex set `S` with `|S|<=C d` has stationary mass at most

`pi_V(S) <= C d/[M(d+1)] <= C/M`.                           `(7.3)`

Taking `M->infinity`, no `O(d)`-vertex set captures a fixed positive fraction of global stationary/Perron mass.

### Lemma 7.4 — nevertheless the chain is dynamically trapped for `Theta(d)` steps

There are exactly `M` undirected cross edges, hence `2M` directed cross-edge states, out of

`M(d+1)d`

directed edges total. Under stationarity,

`P(e_t is a directed cross edge)=2/[d(d+1)]`.               `(7.4)`

A nonbacktracking trajectory can move from the interior of one clique block to another only by traversing a cross edge. Thus, by the union bound, for every integer `k>=0`,

`P(a cross edge is traversed during times 0,...,k)`
`<= 2(k+1)/[d(d+1)]`.                                      `(7.5)`

For `k=floor(c d)` with fixed `c`, the right-hand side is `O_c(1/d)`. Therefore with probability `1-O_c(1/d)` a stationary nonbacktracking trajectory of length `Theta(d)` stays inside the same `O(d)`-vertex clique block, despite (7.3).

### Interpretation

This does **not** refute G0011 and does not refute the broad Hashimoto localization principle from the preceding report. It refutes only a tempting simplification of its localization branch: dynamic overlap cannot be characterized solely by “one globally heavy `O(d)` set.” A correct dichotomy must allow a **partition into many metastable `O(d)` blocks** or, more invariantly, low nonbacktracking conductance at scale `d`.

The family is actually friendly to the source conclusion:

- when `d->infinity`, each block `K_{d+1}-a_i b_i` has minimum degree `d-1`, so the Krivelevich--Samotij theorem applies at `p=(1+epsilon)/d` for sufficiently large `d` after reducing epsilon slightly;
- when `d` remains fixed and `M->infinity`, choose one fixed Hamilton cycle in each block. These cycles use disjoint internal edge sets, each survives with fixed positive probability `p^{d+1}`, and independence over the `M` blocks makes the probability that none survives tend to zero.

So the lesson is not “blocks obstruct cycles”; it is the opposite: **many blocks can amplify local cycle success even while they defeat global-mass localization heuristics.**

## 8. B6 — deform from the solved minimum-degree regime

The previous stress test suggests separating hosts according to whether average degree is already carried by a near-`d` minimum-degree core.

Fix `epsilon>0` and set

`eta := epsilon/[2(1+epsilon)]`.                            `(8.1)`

Suppose a host graph of average degree `d` contains a subgraph `H` of minimum degree

`k >= (1-eta)d`.                                            `(8.2)`

At `p>=(1+epsilon)/d`,

`pk >= (1+epsilon)(1-eta) = 1+epsilon/2`.                   `(8.3)`

Hence, along any regime in which `d->infinity` (so `k->infinity`), the Krivelevich--Samotij minimum-degree theorem with parameter `epsilon/2` gives with probability tending to one a cycle of length

`Omega_epsilon(k)=Omega_epsilon(d)`                         `(8.4)`

inside `H_p`.

Therefore any large-`d` obstruction to the source cannot simultaneously have a `(1-eta)d`-minimum-degree core. Combined with the previous report's fact that the 2-core still has average degree at least `d`, the genuinely hard residual family must exhibit substantial degree inhomogeneity: average degree stays high while degeneracy is bounded away from `d`.

This is a restricted structural reduction only. The quoted minimum-degree theorem is asymptotic in `k`, so (8.4) is **not** promoted to a literal all-source-quantifier proof for fixed large `d` as host order tends to infinity. The full uniform statement in this run is Theorem 5.1, not Section 8.

## 11. Exact remaining obstruction

The DFS proof transforms the conjectural improvement `2 -> 1` into a local-surplus problem.

Globally, below multiplier 2 there is no contradiction in querying almost all `m=nd/2` edges while using at most `n-1` positive discovery queries. To improve the multiplier, one needs a stopping region or collection of regions in which the available host-edge mass is high relative to the number of vertices that can absorb successful discoveries.

A useful schematic quantity is

`surplus(region) = available host edges - queried host edges - (long-chord allowance per vertex)`. `(11.1)`

Theorem 5.1 wins when this surplus is positive globally. At `K=1+epsilon`, global positivity need not hold. The next task is to prove one of two alternatives:

1. some adaptively found region has positive surplus at the correct `1+epsilon` scale, yielding a long open DFS chord by the same conditional-independence argument; or
2. every attempted region has nonpositive surplus, which should force an approximate decomposition into many dense/metastable `O(d)` blocks, where independent or weakly dependent local cycle chances can be amplified.

The cyclic clique-chain shows why alternative 2 must permit **many** blocks rather than a single localized Perron core.

This is the precise new gluing problem.
