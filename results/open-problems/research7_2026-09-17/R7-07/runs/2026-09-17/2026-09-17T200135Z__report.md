## 4. Exact blocking formula

The narrowest surviving branch isolated by the preceding reports is a percolated bipartite incidence core

`J_*=(A,B)`

with, for fixed `theta=theta(epsilon)>0`,

`e(J_*) > theta n d/8`,

`delta_A(J_*) > d^2/2`,

`delta_B(J_*) > theta d/16`,

percolated at

`p=(1+epsilon)/d`.

For distinct `a,a' in A`, define the *open witness set*

`W_p(a,a') := N_{J_{*,p}}(a) cap N_{J_{*,p}}(a') subseteq B`.

The previous report already proved that a simple `2 ell`-cycle in `J_{*,p}` is exactly an `ell`-vertex Berge cycle in the hypergraph of open connector neighborhoods. Equivalently, after choosing a projected cyclic sequence of distinct vertices

`C=(a_1,a_2,...,a_ell)`, `a_{ell+1}=a_1`,

one must be able to choose **distinct** witnesses

`b_i in W_p(a_i,a_{i+1})`.

The exact Hall obstruction is therefore:

```text
Find ell >= c d and distinct a_1,...,a_ell such that

    | union_{i in I} W_p(a_i,a_{i+1}) | >= |I|

for every I subseteq {1,...,ell}.
```

Equivalently, the blocker can be written as the failure margin

`H(C) := min_{empty != I subseteq [ell]} ( | union_{i in I} W_p(a_i,a_{i+1}) | - |I| )`.

A source-scale cycle in the cross core follows once one finds, with probability `1-o(1)`, a projected cycle of length `ell=Omega(d)` with

`H(C) >= 0`.

This is a diagnostic restatement of the already-established Berge-cycle equivalence, not a new source-level theorem. It pinpoints what the ordinary projection forgot: **projected breadth is insufficient unless the edge-witness family has an SDR along one long cycle.**

## 5. Route inventory: what has been tried and why each route stopped

### Route 1 — generic average-degree to minimum-degree pruning

Historical intake attempt `G0011-A001` already records the standard loss: an average-degree-`d` graph only guarantees a subgraph of minimum degree about `d/2`. Feeding that into the Krivelevich--Samotij near-critical minimum-degree theorem requires a multiplier near `2`, not `1+epsilon`.

**Failure:** deterministic pruning throws away exactly the factor needed to reach the source threshold. This route explains `K=2`; it cannot prove `K=1` without additional structure.

### Route 2 — B18/B25/B30: nonbacktracking translation, double counting, localization

The first admitted run moved the problem to the Hashimoto/nonbacktracking operator. The 2-core keeps average degree at least `d`, and the nonbacktracking spectral radius is large enough that at `p=(1+epsilon)/d` the cycle-bearing operator is already strictly supercritical.

**Failure:** supercritical nonbacktracking growth does not by itself produce a *simple cycle of length `Omega(d)`*. Walk mass can collide, recycle short connectors, or localize. The missing step was conversion from operator growth to long simple geometry under arbitrary degree inhomogeneity.

### Route 3 — B14/B19/B6: symmetry, DFS algorithm, deformation to a solvable multiplier

A deterministic DFS exposure was designed so every unqueried host edge is ancestor--descendant. Counting long unqueried chords and the total query budget yielded a uniform theorem for every fixed multiplier `K>2`, hence the genuine metric movement

`K_long <= 2`.

**Failure:** the global DFS budget has a hard factor-two sign change: the host has `nd/2` edges, while a discovery process may consume order `n/p` tests before enough independent long chords remain. The method needs a new source of conserved surplus or local amplification to cross from `2` to `1`; repeating the same query accounting cannot do it.

### Route 4 — localization to one heavy core

The cyclic clique-chain stress test showed that average degree and long-cycle probability can be distributed across many `Theta(d)`-scale blocks. A single globally heavy `O(d)` Perron core is therefore not the correct universal object.

**Failure:** localization to one spectral/dense block discards the multiplicity mechanism that can make an event a.a.s. even when each block succeeds only with bounded probability.

### Route 5 — B3: pass to one 2-connected block

A deterministic block-tree identity gives a 2-connected block retaining all but an additive one in average degree.

**Failure:** this removes articulation-point density loss but not the probabilistic quantifier. If the host consists of many bounded-size-in-`n` dense blocks, choosing one block loses the amplification over blocks; if one block is large, an irregular-block theorem is still needed.

### Route 6 — B3/B12/B24: high-girth branch plus short-cycle mass conservation

Using Nelson's circuit theorem, the high-girth near-full-density branch is solvable at the source multiplier for each fixed large `d`. Exact short-cycle peeling shows that the complementary branch carries a positive fraction of all host edge mass in edge-disjoint short cycles. Load counting then yields a hub-versus-many-blocks obstruction.

**Failure 1:** Nelson's threshold size `N(mu,eta)` is not uniform in the source regime `mu=Theta(d)`, `eta=Theta(1/d)` when `d=d(n)` can grow.

**Failure 2:** the short-cycle-rich branch still permits heavy vertex overlap and repeated witness reuse. Edge mass alone does not make one source-scale simple cycle.

### Route 7 — B1: maximal vertex-disjoint short-cycle packing

Changing from edge-disjoint to vertex-disjoint packing sharpened the structure to a trichotomy:

1. many vertex-disjoint short-cycle blocks;
2. a near-full-density high-girth remainder;
3. a tiny transversal `U` meeting every short cycle and carrying positive edge mass.

**Failure:** the trichotomy is structural, not yet a uniform probability theorem. The many-block and high-girth branches still need source-uniform amplification, while the tiny-transversal branch requires further geometry.

### Route 8 — B15: split the tiny-transversal branch

The dense-interior case `e(G[U])` large was closed using the already-proved `K>2` theorem on the much denser induced subgraph. The only small-transversal branch left is a cross-incidence graph with very asymmetric semidegrees.

**Failure:** the cross graph is not controlled by ordinary minimum degree at scale `d`; one side has degree `Theta(d^2)` and the other only `Theta(d)`, so one-step pruning/theorems do not match the source probability.

### Route 9 — B21: import two-type branching intuition

The residual cross core is far above its two-type nonbacktracking threshold, and the complete-bipartite benchmark produces source-scale cycles.

**Failure:** homogeneous two-type branching does not control arbitrary incidence overlap. It proves the threshold is not the issue, but it does not prevent global collisions or repeated connectors.

### Route 10 — B11/B19: two-step projection and concentrated local breadth

Dualizing two incidence steps into a projection on `A` gives the exact formula

`E deg_Q(a) = sum_{a'!=a} [1-(1-p^2)^{c_{a,a'}}]`.

Concavity and a two-stage exposure show every fixed `A`-vertex has `Omega(d)` distinct projected neighbors with failure `exp(-Omega(d))`, uniformly over all codegree profiles.

**Failure:** this breadth is local and unlabeled. A single connector can witness many projected edges. Pointwise `exp(-Omega(d))` failure also cannot be union-bounded over arbitrary host order `n`.

### Route 11 — B26: Berge-cycle / witness-label reformulation

The exact lifting equivalence identifies the remaining global requirement: a long cycle must use distinct `B`-witnesses.

**Failure:** forgetting labels creates fake projected cycles. Enforcing proper witness colours by pairing each connector's neighbors into a disjoint matching restores independence/properness but discards half the usable incidence mass. The resulting guaranteed effective projected degree is only

`((1+epsilon)^2/2)(1-o(1))`,

which is below the ordinary supercritical threshold for small `epsilon`. This reproduces the factor-two barrier in a different language.

### Route 12 — existing rainbow-cycle technology

Properly edge-coloured rainbow-cycle theorems are a strong analogue because a rainbow cycle is also a distinct-witness cycle.

**Failure:** the natural full two-section here is *not properly coloured*; one connector creates a clique of one colour. Making it proper by disjoint pairing causes the factor-two loss above. In addition, the sharp known proper-colour thresholds depend on the projected host order through logarithmic factors, while G0011 needs a cycle of length `Omega(d)` uniformly in arbitrary `n`.

## 6. What a successful proof must contain that none of the routes contains

The cumulative evidence rules out several false blockers:

- lack of local two-step branching is not the issue;
- maximal codegree / complete overlap is not itself a counterexample mechanism;
- low overlap is not itself a counterexample mechanism;
- articulation structure is not the decisive density loss;
- a single globally heavy spectral core is not necessary;
- ordinary projected cycles are not enough.

What is absent from every current route is a **witness-capacity theorem** that is simultaneously:

1. **source-scale:** it works at `p=(1+epsilon)/d`;
2. **lossless to first order:** it does not throw away a factor `2` by using each connector only once in advance;
3. **global:** it produces `Omega(d)` consecutive steps rather than `Omega(d)` one-step choices from one root;
4. **distinct-witness:** it verifies the Hall/SDR condition above along one long cyclic structure;
5. **uniform in host order:** its failure is `o(1)` without a forbidden union bound over arbitrary `n`;
6. **compatible with arbitrary incidence overlap:** it cannot assume pseudorandom codegrees unless that structure is derived by a valid decomposition.

A proof with these six properties would attack the actual blocker instead of another surrogate quantity.

## 8. Nearest solved analogue and what it has that G0011 lacks

The closest source-level solved analogue remains the Krivelevich--Samotij minimum-degree theorem. There one starts with a graph of minimum degree at least `k` and percolates at `(1+epsilon)/k`. The deterministic host gives every exploration location a one-scale supply of fresh candidate edges, so DFS/expansion can turn near-critical surplus into a long simple cycle without alternating through a low-degree witness class.

The cross core lacks exactly that one-scale reserve. Its two types satisfy, schematically,

`p * deg_A = Theta(d)`,

`p * deg_B = Theta(1)`.

So the relevant surplus exists only over **two steps**. Collapsing those steps forgets witnesses; preassigning witnesses loses half the mass. The missing tool is therefore a two-step analogue of the minimum-degree exploration theorem that keeps connector identities live until they are actually consumed.

The 2025 rainbow-cycle theorem is the closest solved analogue for the *distinct-label* aspect. It has a proper edge-colouring from the outset and can exploit robust expansion after colour splitting. G0011's natural connector colouring is highly improper because one connector induces a monochromatic clique in the projection; forcing properness prematurely is exactly the factor-two loss already diagnosed.
