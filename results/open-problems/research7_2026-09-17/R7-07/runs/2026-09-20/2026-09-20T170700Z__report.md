## 3. New structural lemma: the stationary harmonic environment is exponentially strongly mixing

The previous full-state theorem was stated with a constant depending on `f`. Its proof actually tracks the norm uniformly: for any fixed `eta>0` there are `C_eta,c_eta>0` such that every centered `f in L^{2+eta}(mu)` satisfies

`boxed{ ||K^n f||_2 <= C_eta exp(-c_eta n) ||f||_{2+eta}. }`  (3.1)

Indeed, in the two-spine proof the no-split term is bounded by Holder using the exponential common-prefix tail, and every split term is the product reverse-density contraction paired against `bar f tensor bar f`, where `bar f=E[f|type,B]`. Conditional expectation is an `L^{2+eta}` contraction, while all split-density and cutoff constants are independent of `f`. Thus the preceding proof gives the operator-norm form (3.1), not merely pointwise decay for one chosen observable.

Take the standard two-sided stationary extension `(Y_k)_{k in Z}` under `mu`. Let

`alpha(n)=sup |P(A cap B)-P(A)P(B)|`,

where `A in sigma(Y_j:j<=0)` and `B in sigma(Y_j:j>=n)`. For such `A,B`, by the Markov property there are measurable `a,b:[state]->[0,1]` with

`P(A cap B)-P(A)P(B)`
` = <a-Ea, K^n(b-Eb)>_mu`.                                   (3.2)

Cauchy--Schwarz and (3.1), say with `eta=1`, give

`|...| <= ||a-Ea||_2 C exp(-cn)||b-Eb||_3 <= C exp(-cn)`.

Hence

`boxed{ alpha(n) <= C exp(-cn). }`                           (3.3)

This is stronger structural information than the previous additive-functional statements: the entire stationary full-tree harmonic environment is exponentially strongly mixing.

## 4. A general semiexponential concentration corollary

Suppose `f` is centered and, for some `r>=1`,

`||f||_p <= C p^r` for all large `p`.                        (4.1)

Moment optimization gives

`P_mu(|f|>t) <= C exp(-c t^(1/r))`.                          (4.2)

Applied to the stationary sequence `f(Y_k)`, (3.3) gives the Merlevede--Peligrad--Rio hypotheses with

`gamma1=1`, `gamma2=1/r`,

and therefore effective exponent

`gamma=1/(r+1)`.                                              (4.3)

In particular, their Theorem 1 implies the linear-deviation consequence

`boxed{
 P_mu( max_{j<=n}|sum_{k<j} f(Y_k)| > delta n )
 <= C_delta exp(-c_delta n^(1/(r+1))).
}`                                                               (4.4)

Only this consequence is needed below.

## 5. Quantitative fixed-tree harmonic dimension concentration

For `h=phi-d_H`, the inherited exponential moment of `phi` gives

`||h||_p<=Cp`,                                                 (5.1)

so Section 4 applies with `r=1`. Therefore for every `delta>0`,

`P_mu( |sum_{k<n}h(Y_k)|>delta n ) <= C_delta exp(-c_delta sqrt(n)).`  (5.2)

The electrical endpoint in (2.1) is smaller: since `E_mu B^{-a}<infinity` for every fixed `a>0`,

`P_mu(|log B(Y_0)-log B(Y_n)|>delta n) <= C exp(-c n)`.       (5.3)

Combining (5.2)--(5.3),

`boxed{
 P_mu( |I_n/n-d_H|>delta ) <= C_delta exp(-c_delta sqrt(n)).
}`                                                               (5.4)

Now disintegrate over the starting tree. Let

`q_n(T)=H_T(|I_n/n-d_H|>delta)`.

Then `E_mu q_n` is bounded by (5.4). Markov at threshold `exp(-c_delta sqrt(n)/2)` gives a summable exceptional-tree probability. Hence, for `mu`-a.e. starting tree, eventually

`boxed{
 H_T(|I_n/n-d_H|>delta) <= exp(-c'_delta sqrt(n)).
}`                                                               (5.5)

Equivalence of `mu` with the original source law conditioned on survival transfers (5.5) to source-a.e. surviving trees.

Since `sum_n exp(-c sqrt(n))<infinity`, a second Borel--Cantelli argument, now inside harmonic measure on each such fixed tree, gives

`I_n/n -> d_H` for `H_T`-a.e. boundary ray.                  (5.6)

Thus the inherited exact-dimensional/dimension-drop theorem has a new quantitative fixed-tree form: in the source generation metric, harmonic cylinders concentrate around dimension `d_H` at stretched-exponential rate `exp(-c sqrt(n))`; for every nonregular source the inherited PF--KL rigidity has `d_H` strictly below the failed-boundary dimension. This is still only the harmonic-measure clause, not the full multifractal spectrum requested by Kumar.

## 7. Main fluctuation upgrade: quenched Gaussian MDP on `a_n=o(n^(1/10))`

Let `a_n->infinity` be deterministic and assume

`boxed{ a_n=o(n^(1/10)). }`                                  (7.1)

### 7.1 Predictable quadratic variation

Equation (6.6) gives

`a_n^{-2} log P_T(|n^{-1}<M>_n-sigma_H^2|>delta) -> -infinity`,  (7.2)

because `a_n^2=o(n^(1/5))`.

### 7.2 Martingale large jumps

The previous report proved the stationary tail

`P_mu(|D_1|>x)<=C exp(-c sqrt(x))`.                           (7.3)

Therefore

`P_mu(max_{k<n}|D_{k+1}|>epsilon sqrt(n)/a_n)`
` <= C n exp(-c n^(1/4) a_n^(-1/2)).`                        (7.4)

Let `s_n(T)` be the corresponding conditional probability. For fixed `L>0`,

`mu(s_n>exp(-L a_n^2))`
` <= C n exp(L a_n^2-c n^(1/4)a_n^(-1/2)).`                  (7.5)

Write `b_n=n^(1/10)/a_n -> infinity`. Then the negative term in (7.5) is of order

`n^(1/5) b_n^(1/2)`,

whereas `a_n^2=n^(1/5)b_n^(-2)`. The right side is summable. Borel--Cantelli therefore gives, for source-a.e. fixed surviving tree,

`boxed{
 limsup_n a_n^(-2) log P_T(
  max_{k<n}|D_{k+1}|>epsilon sqrt(n)/a_n)=-infinity.
}`                                                               (7.6)

This is the Chen--Ledoux large-jump condition at the desired speed.

### 7.3 Poisson/electrical endpoint

The previous report also proved

`P_mu(|W|>x)<=C exp(-c sqrt(x))`.                             (7.7)

Thus

`P_mu(max_{k<=n}|W(Y_k)|>epsilon a_n sqrt(n))`
` <= C n exp(-c a_n^(1/2)n^(1/4)).`                          (7.8)

Since (7.1) is much stronger than the endpoint requirement `a_n=o(n^(1/6))`, the same disintegration/Borel--Cantelli argument gives exponential equivalence of the endpoint to zero at speed `a_n^2`.

### Theorem 7.1 — widened quenched MDP

Assume the nonregular finite-type source regime, so `sigma_H^2>0`. For every deterministic sequence

`a_n->infinity`, `a_n=o(n^(1/10))`,                           (7.9)

there is a source-full set of surviving trees such that for every fixed tree `T` in that set,

`X_n=(I_n-n d_H)/(a_n sqrt(n))`

satisfies under `H_T` a moderate-deviation principle with speed `a_n^2` and rate

`boxed{ J(x)=x^2/(2 sigma_H^2). }`                            (7.10)

Proof: (7.2) and (7.6) are exactly the predictable-quadratic-variation and Chen--Ledoux hypotheses used in the previous run's Djellout martingale-MDP step; (7.8) transfers the result from the martingale core to `I_n` by exponential equivalence.

It is now forced by the known martingale-jump tail `exp(-c sqrt(x))`: at the threshold `sqrt(n)/a_n`, the tail exponent is `n^(1/4)a_n^(-1/2)`, and matching it against MDP speed `a_n^2` gives precisely `a_n=o(n^(1/10))`.
