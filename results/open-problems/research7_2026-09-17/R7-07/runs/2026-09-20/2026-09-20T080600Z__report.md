## 2. Inherited finite-type setup

Let the type set be `D={1,...,d}`. A type-`i` parent has a source potential-child count `nu` with

\[
G(z)=E[z^\nu],\qquad m_*=E\nu<\infty,
\]

and each potential child independently has type `j` with probability `q_j>0` and transmits with probability `p_{ij}>0`. The finite-type mean matrix is

\[
M_{ij}=m_*q_jp_{ij},\qquad \rho(M)>1.
\tag{2.1}
\]

The matrix is strictly positive under the standing source assumptions. Hence the multitype survival probabilities

\[
s_j=P_j(B>0)
\]

are strictly positive for every type.

For a surviving tree let `B(T)` denote the escape conductance/probability through the root with an added parent edge. If `B_u` are the conductances of the surviving transmitted child subtrees, then

\[
S(T)=\sum_uB_u,
\qquad
B(T)=F(S(T)),
\qquad
F(x)=\frac{x}{1+x}.
\tag{2.2}
\]

The harmonic child flow is

\[
H_T(u)=\frac{B_u}{S(T)}
\tag{2.3}
\]

on surviving children.

Previous C06 runs constructed a source-equivalent stationary and ergodic harmonic-descendant law `mu` and proved the exact electrical information observable

\[
\phi(B):=-\log(1-B),
\qquad
 d_H=E_\mu\phi(B),
\tag{2.4}
\]

with cylinder information

\[
I_n=-\log\theta_T(X_n)
=
\sum_{r=0}^{n-1}\phi(B_r)
+\log B_0-\log B_n.
\tag{2.5}
\]

Here `(B_r)` denotes the conductance along the stationary harmonic ray.

The immediately preceding report identified an exact Markov time reversal after projection to `(type,B)`. Its kernel is denoted `widehat Q`, and for the centered observable

\[
\bar\phi=\phi-d_H
\]

it proved

\[
\sum_{n\ge0}\|\widehat Q^n\bar\phi\|_{L^2(\bar\mu)}<\infty.
\tag{2.6}
\]

Thus

\[
u:=\sum_{n=0}^{\infty}\widehat Q^n\bar\phi\in L^2(\bar\mu),
\qquad
\bar\phi=u-\widehat Q u.
\tag{2.7}
\]

For the stationary reverse chain `(Y_n)` define

\[
D_{n+1}=u(Y_{n+1})-\widehat Q u(Y_n).
\tag{2.8}
\]

Then `(D_n)` is a stationary ergodic square-integrable martingale-difference sequence and

\[
\sum_{r=0}^{n-1}\bar\phi(Y_r)
=
\sum_{r=1}^{n}D_r+u(Y_0)-u(Y_n).
\tag{2.9}
\]

The asymptotic variance is

\[
\boxed{
\sigma_H^2
=E[D_1^2]
=E_{\bar\mu}[u^2-(\widehat Q u)^2].
}
\tag{2.10}
\]

The preceding run left open whether a nonregular source can have `sigma_H^2=0`. This report closes that gap.

## 3. Zero variance gives an exact edge coboundary

### Lemma 3.1 — deterministic reverse transition of the Poisson solution

If

\[
\sigma_H^2=0,
\tag{3.1}
\]

then

\[
D_1=0
\]

almost surely. Therefore for a stationary reverse edge `child -> parent`,

\[
\boxed{
\bar\phi(\text{child})
=u(\text{child})-u(\text{parent})
}
\tag{3.2}
\]

almost surely.

#### Proof

Equation (2.10) gives `E[D_1^2]=0`; hence `D_1=0` almost surely. Since

\[
\bar\phi(Y_0)=u(Y_0)-\widehat Q u(Y_0)
\]

and `D_1=0` says `u(Y_1)=\widehat Q u(Y_0)`, substitution gives (3.2). No continuity of `u` is required. `u` is only used as its `L^2(bar mu)` equivalence class. `square`

Reversing the orientation of the stationary edge, a forward harmonic edge `parent -> child` therefore satisfies

\[
\boxed{
u_i(B_{\rm parent})
=u_j(B_{\rm child})-\phi(B_{\rm child})+d_H
}
\tag{3.3}
\]

for the corresponding parent and child types `i,j`.

Define the source-measurable child variable

\[
Z_j(T):=u_j(B(T))-\phi(B(T))
\tag{3.4}
\]

on surviving type-`j` trees. Source equivalence of the stationary density guarantees that this is well defined modulo source-null sets under `P_j(. | B>0)`.

## 4. The edge identity holds simultaneously for every surviving child

The edge law picks one child according to the positive harmonic weights `H_T(u)`. A priori (3.3) is an almost-sure statement for the selected edge. Positivity upgrades it to a simultaneous branching statement.

### Lemma 4.1 — all surviving siblings have the same `Z`

Assume `sigma_H^2=0`. For source-almost every surviving parent tree `T`, every surviving transmitted child `v` satisfies

\[
\boxed{
Z_{\mathrm{type}(v)}(T_v)
=u_{\mathrm{type}(T)}(B(T))-d_H.
}
\tag{4.1}
\]

In particular all surviving siblings of the same parent have exactly the same `Z` value.

#### Proof

Let `Bad(T,v)` denote failure of (3.3) on edge `(T,v)`. Under the stationary forward edge law,

\[
0
=E_\mu\left[\sum_{v:B_v>0}H_T(v)\,1_{Bad(T,v)}\right].
\tag{4.2}
\]

Every summand is nonnegative, and every surviving child has

\[
H_T(v)=\frac{B_v}{\sum_wB_w}>0.
\]

Hence for `mu`-almost every surviving tree, no surviving child is bad. The stationary tree law is equivalent to the source tree law conditioned on survival, so the same conclusion holds source-almost surely. Rearranging (3.3) gives (4.1). `square`

This is the crucial strengthening: zero asymptotic variance is not merely an average cancellation. It forces a deterministic equality across **all independent surviving child subtrees at a branch point**.

## 5. Branching independence collapses the coboundary to a constant

The supercriticality assumption implies

\[
m_*>1.
\tag{5.1}
\]

Indeed `rho(M)<=m_*`, since each row sum of `M` is at most `m_*`; thus `rho(M)>1` forces `m_*>1`. Consequently

\[
P(\nu\ge2)>0.
\tag{5.2}
\]

### Lemma 5.1 — independent-equality collapse

Let `X,Y` be independent real random variables. If `X=Y` almost surely, then both are deterministic and equal to one common constant.

#### Proof

For every Borel set `A`, independence and equality imply

\[
P(X\in A,\,Y\notin A)=P(X\in A)P(Y\notin A)=0.
\]

Since `X,Y` have the same pointwise value almost surely, their laws coincide. Thus `p(1-p)=0` for every measurable event of the common law. The law is a Dirac mass. `square`

### Theorem 5.2 — sibling collapse

If `sigma_H^2=0`, then there exists a deterministic constant `c` such that for every type `j`,

\[
\boxed{
Z_j(T)=c
\quad P_j(\cdot\mid B>0)\text{-almost surely}.
}
\tag{5.3}
\]

#### Proof

Fix any two types `j,k`, and fix any parent type `i`. By (5.2), with positive probability the parent has at least two potential child slots. On the event that the first two such slots exist, require:

1. slot 1 has type `j`, transmits, and its subtree survives;
2. slot 2 has type `k`, transmits, and its subtree survives.

This event has strictly positive probability because

\[
q_jp_{ij}s_j>0,
\qquad
q_kp_{ik}s_k>0.
\tag{5.4}
\]

No restriction on the remaining children is needed. Conditional on these requirements, the two child subtrees are independent with laws

\[
P_j(\cdot\mid B>0),
\qquad
P_k(\cdot\mid B>0).
\]

By Lemma 4.1 their `Z` values are almost surely equal. Lemma 5.1 therefore forces `Z_j` and `Z_k` to be deterministic constants, and those constants are equal. Because `j,k` were arbitrary, a single constant `c` works for all types. `square`

This argument is the main new rigidity mechanism of the run. It uses neither smoothness of the Poisson solution nor topological support of the conductance law. The only ingredients are zero martingale variance, positive harmonic weight for every surviving child, and genuine branching independence.

## 6. Zero variance forces deterministic escape conductance

### Theorem 6.1 — conductance rigidity

If `sigma_H^2=0`, then there exists `b_* in (0,1)` such that for every type `i`,

\[
\boxed{
B(T)=b_*
\quad P_i(\cdot\mid B>0)\text{-almost surely}.
}
\tag{6.1}

Moreover

\[
\boxed{
-\log(1-b_*)=d_H.
}
\tag{6.2}

#### Proof

Let `T` be a source-typical surviving parent of type `i`. It has at least one surviving child `v`. By Lemma 4.1 and Theorem 5.2,

\[
u_i(B(T))=Z_{\mathrm{type}(v)}(T_v)+d_H=c+d_H.
\tag{6.3}
\]

But Theorem 5.2 applied to the parent itself gives

\[
Z_i(T)=u_i(B(T))-\phi(B(T))=c.
\tag{6.4}
\]

Subtracting (6.4) from (6.3),

\[
\phi(B(T))=d_H.
\tag{6.5}
\]

Since `phi(b)=-log(1-b)` is strictly increasing on `(0,1)`, `B(T)` is the deterministic constant

\[
b_*=1-e^{-d_H}.
\]

Supercritical survival gives `b_*>0`; trivially `b_*<1`. `square`

Thus a vanishing fluctuation variance collapses the entire random electrical environment to one conductance value.

## 7. Deterministic conductance forces the regular no-thinning source

Let

\[
K_i
=
\#\{\text{transmitted children of a type-}i\text{ parent whose subtrees survive}\}
\tag{7.1}
\]

be the number of infinite transmitted children.

If every surviving child has conductance `b_*`, then on `{K_i>=1}` the electrical recursion gives

\[
b_*
=F(K_i b_*)
=\frac{K_i b_*}{1+K_i b_*}.
\tag{7.2}
\]

Since `b_*>0`,

\[
1+K_i b_*=K_i,
\qquad
K_i=\frac1{1-b_*}=:k.
\tag{7.3}
\]

Hence `k` is an integer and, because `b_*>0`,

\[
k\ge2.
\tag{7.4}
\]

Therefore for every parent type `i`,

\[
\boxed{K_i\in\{0,k\}\quad\text{almost surely}.}
\tag{7.5}
\]

Now define

\[
t_i:=\sum_j q_jp_{ij}s_j.
\tag{7.6}
\]

Conditional on `nu=n`, each potential child independently becomes an infinite transmitted child with probability `t_i`; therefore

\[
K_i\mid\{\nu=n\}
\sim\operatorname{Bin}(n,t_i).
\tag{7.7}
\]

### Theorem 7.1 — source rigidity

If `sigma_H^2=0`, then for one integer `k>=2`,

\[
\boxed{
\nu\equiv k,
\qquad
p_{ij}=1\quad\text{for every }i,j.
}
\tag{7.8}

In particular every type survives with probability one.

#### Proof

Each `t_i>0` because all `q_j,p_{ij},s_j` are positive. Suppose `t_i<1` for some type `i`. By (5.2), choose `n>=2` with `P(nu=n)>0`. Then (7.7) gives

\[
P(K_i=1\mid\nu=n)
=n t_i(1-t_i)^{n-1}>0,
\]

contradicting (7.5), since `k>=2`. Therefore

\[
t_i=1
\quad\text{for every }i.
\tag{7.9}
\]

But `t_i` is a `q`-weighted average of numbers `p_{ij}s_j` lying in `[0,1]`, and every `q_j>0`. Equality in (7.9) forces

\[
p_{ij}s_j=1
\quad\text{for every }i,j.
\]

Hence

\[
p_{ij}=1,
\qquad
s_j=1
\quad\text{for every }i,j.
\tag{7.10}
\]

All potential children therefore transmit and all child subtrees survive. Thus

\[
K_i=\nu
\quad\text{almost surely}.
\]

Because survival itself now has probability one, (7.5) reduces to `K_i=k` almost surely, so

\[
\nu\equiv k.
\]

This is precisely the deterministic regular no-thinning source. `square`

### Converse

If `nu == k>=2` deterministically and every `p_ij=1`, the underlying unlabeled tree is the deterministic `k`-ary tree. The conductance equation gives

\[
b_*=\frac{k b_*}{1+k b_*},
\qquad
b_* = \frac{k-1}{k},
\tag{7.11}
\]

and every harmonic child has weight `1/k`. Therefore

\[
I_n=n\log k
\]

exactly and

\[
\sigma_H^2=0.
\tag{7.12}
\]

Combining both directions proves the exact classification.

## 9. Functional invariance principle

The previous report proved only a scalar central limit theorem. The same martingale decomposition yields the full process-level fluctuation theorem.

For `0<=t<=1`, define the reverse additive process

\[
S_n(t)
:=\frac1{\sqrt n}
\sum_{r=0}^{\lfloor nt\rfloor-1}\bar\phi(Y_r).
\tag{9.1}
\]

From (2.9),

\[
S_n(t)
=
\frac1{\sqrt n}
\sum_{r=1}^{\lfloor nt\rfloor}D_r
+
\frac{u(Y_0)-u(Y_{\lfloor nt\rfloor})}{\sqrt n}.
\tag{9.2}
\]

### Lemma 9.1 — the Poisson endpoint is uniformly negligible

Because `u in L^2(bar mu)`,

\[
\boxed{
\max_{0\le m\le n}\frac{|u(Y_m)|}{\sqrt n}
\longrightarrow0
\quad\text{in probability}.
}
\tag{9.3}
\]

#### Proof

By stationarity and the union bound,

\[
P\left(\max_{m\le n}|u(Y_m)|>\varepsilon\sqrt n\right)
\le
(n+1)P(|u|>\varepsilon\sqrt n).
\]

For every square-integrable random variable `U`,

\[
x^2P(|U|>x)\to0.
\]

Taking `x=epsilon sqrt(n)` proves (9.3). `square`

### Lemma 9.2 — martingale functional CLT

The martingale array

\[
M_n(t)=\frac1{\sqrt n}\sum_{r=1}^{\lfloor nt\rfloor}D_r
\]

converges in `D([0,1])` to `sigma_H W`, where `W` is standard Brownian motion.

#### Proof

The predictable quadratic variation is

\[
\frac1n\sum_{r=1}^{\lfloor nt\rfloor}
E[D_r^2\mid\mathcal F_{r-1}].
\]

The summand is a stationary integrable function of `Y_{r-1}`. Ergodicity therefore gives convergence to `t sigma_H^2`. Square integrability of `D_1` yields the conditional Lindeberg condition: for every `epsilon>0`, the expectation of

\[
\frac1n\sum_{r=1}^{n}
E[D_r^2 1_{\{|D_r|>\varepsilon\sqrt n\}}\mid\mathcal F_{r-1}]
\]

is

\[
E[D_1^2 1_{\{|D_1|>\varepsilon\sqrt n\}}]\to0.
\]

The stationary martingale functional CLT now applies. `square`

Combining Lemmas 9.1 and 9.2,

\[
\boxed{
S_n(\cdot)\Longrightarrow\sigma_HW(\cdot)
\quad\text{in }D([0,1]).
}
\tag{9.4}
\]

## 10. Transfer from reverse time to the forward harmonic ray

For a fixed block of length `n`, stationarity says the forward observable block and the reversed-chain observable block agree after reversing order. Reversal of a partial-sum path is the map

\[
(\mathcal Rf)(t)=f(1)-f(1-t)
\tag{10.1}
\]

up to a discretization error of one increment. Brownian motion is invariant in law under this time-reversal transform, and the map is continuous at continuous paths. Therefore (9.4) transfers from the reverse chain to the forward stationary harmonic ray:

\[
\boxed{
\left\{
\frac1{\sqrt n}
\sum_{r=0}^{\lfloor nt\rfloor-1}
(\Phi(T_{X_r})-d_H)
\right\}_{0\le t\le1}
\Longrightarrow
\{\sigma_HW(t)\}_{0\le t\le1}.
}
\tag{10.2}
\]

The one-increment discretization error divided by `sqrt(n)` vanishes in probability because `Phi in L^2(mu)`.

## 12. Why the rigidity proof is stronger than the periodic-orbit route

At the start of this run a natural idea was to use the explicit reverse maps

\[
T_r(b)=F(b+r)
\]

and show that zero variance makes the Poisson solution constant around supported periodic orbits. That route runs into an unnecessary regularity issue: the Poisson solution is only known a priori in `L^2`, while the conductance law may be singular or purely atomic.

The branching argument above avoids that entirely. Zero variance first gives an **edge-a.e. equality**. Positive harmonic weights make it simultaneous across siblings. Independent surviving child subtrees then turn equality of two random variables into deterministic collapse. This is measure-theoretic and source-robust; no density, atom, interval support, or continuity of the Poisson solution is required.

This is the main failed-route lesson of the run: do not solve a topological-support problem when branching independence already gives a probabilistic zero-one mechanism.
