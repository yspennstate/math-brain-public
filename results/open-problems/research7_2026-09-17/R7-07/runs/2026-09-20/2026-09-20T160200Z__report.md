## 2. Inherited chain, Poisson corrector and electrical endpoint

Let `K=K_H` be the harmonic-descendant kernel on surviving rooted environments and `mu` the canonical stationary ergodic law. Let

`Y_k=T_{X_k}`

be the environment seen from a harmonic ray. Put

`B(T)=escape conductance`,

`phi(T)=-log(1-B(T))`,

`d_H=E_mu phi`,

`h=phi-d_H`.

The previous report proved the forward Poisson equation

`u = sum_{m>=0} K^m h`,

`h=u-Ku`,

and the fixed-start martingale decomposition

`D_{k+1}=u(Y_{k+1})-K u(Y_k)`,

`M_n=sum_{k=0}^{n-1}D_{k+1}`,

`W=u+log B`,

`I_n-n d_H = M_n + W(Y_0)-W(Y_n)`.                         (2.1)

It also proved full-state exponential `L^2` mixing: for every centered `f in L^{2+eta}(mu)`,

`||K^n f||_2 <= C(f,eta) e^{-c(eta)n}`.                    (2.2)

Earlier C06 work proved all inverse moments of `B` on survival, hence under `mu`, and the stationary density is bounded above relative to the source law.

The previous report only used that `u` and `W` have all finite moments. The purpose of Sections 3--5 is to extract quantitative growth of those moments.

## 3. Source finite mean already gives an exponential moment for the electrical observable

Write

`S(T)=sum_u B(T_u)`.

The electrical recursion is

`B=S/(1+S)`,

so

`phi=-log(1-B)=log(1+S)`.                                   (3.1)

Because every child conductance is at most one and the number of potential children is `nu`,

`0<=S<=nu`.

Fix `0<a<=1`. Then

`e^{a phi}=(1+S)^a <= (1+nu)^a <= 1+nu`.                   (3.2)

The source assumption is only `E nu=m_*<infinity`, and the stationary density is bounded above. Hence

`E_mu e^{a phi}<infinity` for every `0<a<=1`.               (3.3)

Therefore there is a constant `C_h` such that for every `p>=1`,

`||h||_p <= C_h p`.                                         (3.4)

No offspring moment beyond the source finite-mean assumption is used here.

## 4. New theorem: `p^2` growth and a square-root exponential moment for the forward corrector

### Lemma 4.1 — quantitative resolvent interpolation

There are constants `C,c>0` such that for every real `p>=3` and every `n>=0`,

`||K^n h||_p <= C p exp(-c n/(p-1))`.                       (4.1)

#### Proof

Apply (2.2) once to the fixed centered observable `h`, choosing for example `eta=1`:

`||K^n h||_2 <= C_0 e^{-c_0 n}`.                            (4.2)

Stationarity plus Jensen make `K` a contraction on every `L^q(mu)`, so by (3.4),

`||K^n h||_{2p} <= ||h||_{2p} <= C_1 p`.                    (4.3)

For the single function `K^n h`, log-convexity of `L^r` norms between `2` and `2p` gives

`||K^n h||_p <= ||K^n h||_2^theta ||K^n h||_{2p}^{1-theta}`,

where

`1/p = theta/2 + (1-theta)/(2p)`,

hence `theta=1/(p-1)`. Combining (4.2)--(4.3) proves (4.1), after harmlessly changing constants. `square`

### Theorem 4.2 — sub-Weibull `1/2` Poisson corrector

For every `p>=3`,

`boxed{ ||u||_p <= C p^2. }`                                (4.4)

Consequently there exists `eta_u>0` such that

`boxed{ E_mu exp(eta_u sqrt(|u|)) < infinity. }`             (4.5)

#### Proof

By Minkowski and Lemma 4.1,

`||u||_p`
` <= sum_{n>=0} ||K^n h||_p`
` <= C p sum_{n>=0} exp(-c n/(p-1))`
` <= C' p^2`.                                                (4.6)

For the Orlicz statement, expand the exponential. For integers `m` large enough, apply (4.4) with `p=m/2`:

`E |u|^{m/2}`
` <= [ C (m/2)^2 ]^{m/2}`
` <= (C_2 m)^m`.                                             (4.7)

Since `m! >= (m/e)^m`, the series

`sum_m eta^m E|u|^{m/2}/m!`

converges for sufficiently small `eta>0`. `square`

### Corollary 4.3 — the martingale and electrical endpoints have the same Orlicz scale

Earlier inverse-conductance estimates imply, for every fixed `a>0`,

`E_mu exp(a |log B|)=E_mu B^{-a}<infinity`.                  (4.8)

Hence, with `W=u+log B`,

`||W||_p <= C p^2`,

`E_mu exp(eta_W sqrt(|W|))<infinity`.                        (4.9)

Under the stationary edge law,

`D_1=u(Y_1)-Ku(Y_0)`.

By stationarity and the `L^p` contraction of `K`,

`||D_1||_p <= 2||u||_p <= C p^2`,                            (4.10)

and therefore

`boxed{ P_mu(|D_1|>x) <= C exp(-c sqrt(x)). }`               (4.11)

The same tail form holds for `W`.

This is the first quantitative Orlicz control on the *forward* full-tree Poisson corrector in the C06 chain. It is weaker than a genuine exponential moment, but it is already strong enough for a nontrivial MDP window.

## 5. Endpoint is quenched-superexponentially negligible on moderate scales

Let `a_n -> infinity` be deterministic and assume temporarily

`a_n=o(n^(1/6))`.                                            (5.1)

For `epsilon>0`, stationarity and (4.9) give

`P_mu( max_{0<=k<=n}|W(Y_k)| > epsilon a_n sqrt(n) )`
` <= C n exp[-c (a_n sqrt(n))^(1/2)]`
` = C n exp[-c a_n^(1/2)n^(1/4)]`.                           (5.2)

Let

`q_n(T)=P_T(max_{k<=n}|W(Y_k)|>epsilon a_n sqrt(n))`.

Then `E_mu q_n` equals the left side of (5.2). For every fixed `L>0`, Markov gives

`mu(q_n>e^{-L a_n^2})`
` <= exp[L a_n^2] E_mu q_n`
` <= C n exp[L a_n^2-c a_n^(1/2)n^(1/4)]`.                   (5.3)

Under (5.1),

`n^(1/4)/a_n^(3/2) -> infinity`,

so the right side of (5.3) is summable. Borel--Cantelli, first for integer `L` and rational `epsilon` and then by monotonicity, gives a `mu`-full set such that for every fixed start `T` in that set,

`boxed{
 limsup_n a_n^{-2} log P_T(
   max_{k<=n}|W(Y_k)|>epsilon a_n sqrt(n)) = -infinity.
}`                                                               (5.4)

Thus the electrical/Poisson endpoint is exponentially equivalent to zero at Gaussian MDP speed for every `a_n=o(n^(1/6))`.

The remaining issue is the martingale core `M_n`.

## 6. Quantitative control of the predictable quadratic variation

The predictable variance observable of the martingale is

`v(T)=K(u^2)(T)-(Ku(T))^2`,

and the previous run identified

`E_mu v=sigma_H^2`.                                          (6.1)

From (4.4),

`||v||_p <= ||K(u^2)||_p <= ||u||_{2p}^2 <= C p^4`.          (6.2)

Put

`g=v-sigma_H^2`.

The full-state mixing theorem (2.2) applies to this fixed centered observable. Interpolating exactly as in Section 4 between exponential `L^2` decay and the uniform `L^{2p}` bound from (6.2) gives

`||K^n g||_p <= C p^4 exp(-c n/(p-1))`.                      (6.3)

Therefore the second Poisson corrector

`z=sum_{n>=0}K^n g`                                          (6.4)

satisfies

`boxed{ ||z||_p <= C p^5. }`                                (6.5)

Define the associated martingale differences

`E_{k+1}=z(Y_{k+1})-Kz(Y_k)`

and martingale

`N_n=sum_{k<n}E_{k+1}`.

Then

`sum_{k=0}^{n-1}(v(Y_k)-sigma_H^2)`
` = N_n+z(Y_0)-z(Y_n)`.                                      (6.6)

Under the stationary path law,

`||E_1||_p <= C p^5`.                                        (6.7)

For `p>=2`, the Burkholder square-function inequality and stationarity give

`||N_n||_p`
` <= C p || (sum_{k<n}E_{k+1}^2)^(1/2) ||_p`
` <= C p sqrt(n) ||E_1||_p`
` <= C sqrt(n) p^6`.                                         (6.8)

The endpoint in (6.6) is only `O(p^5)`, so after increasing the constant,

`boxed{
 || sum_{k<n}(v(Y_k)-sigma_H^2) ||_p
 <= C sqrt(n) p^6.
}`                                                               (6.9)

### Corollary 6.1 — stretched-exponential annealed concentration of quadratic variation

For every `delta>0`,

`boxed{
 P_mu( |n^{-1}<M>_n-sigma_H^2|>delta )
 <= C_delta exp(-c_delta n^(1/12)).
}`                                                               (6.10)

Indeed choose `p=floor(alpha n^(1/12))` in Markov's inequality applied to (6.9), with `alpha>0` small enough that `C alpha^6/delta<1`.

Now let

`r_n(T)=P_T(|n^{-1}<M>_n-sigma_H^2|>delta)`.

Since `E_mu r_n` is the left side of (6.10), for every deterministic scale

`a_n -> infinity`, `a_n=o(n^(1/24))`,                        (6.11)

and every `L>0`,

`mu(r_n>e^{-L a_n^2})`
` <= exp[L a_n^2-c_delta n^(1/12)]`,                         (6.12)

which is summable. Hence, for `mu`-almost every fixed start `T`, every `delta>0`,

`boxed{
 limsup_n a_n^{-2} log P_T(
  |n^{-1}<M>_n-sigma_H^2|>delta)=-infinity.
}`                                                               (6.13)

This is the required quenched exponential convergence of predictable quadratic variation at speed `a_n^2` on the window (6.11).

## 7. Quenched Chen--Ledoux large-jump condition

By (4.11), under stationarity,

`P_mu( max_{k<n}|D_{k+1}| > epsilon sqrt(n)/a_n )`
` <= C n exp[-c (sqrt(n)/a_n)^(1/2)]`
` = C n exp[-c n^(1/4)a_n^(-1/2)]`.                          (7.1)

If (6.11) holds, then certainly `a_n=o(n^(1/10))`, and

`n^(1/4)/a_n^(5/2) -> infinity`.                             (7.2)

Repeating the Markov-disintegration/Borel--Cantelli argument of Section 5 yields, for `mu`-almost every fixed start `T`,

`boxed{
 limsup_n a_n^{-2} log P_T(
  max_{k<n}|D_{k+1}|>epsilon sqrt(n)/a_n)=-infinity.
}`                                                               (7.3)

This is stronger than the large-jump / Chen--Ledoux condition at the MDP scale. The corresponding Lindeberg term is therefore negligible as well.

## 8. Main theorem — a quenched Gaussian moderate-deviation principle

### Theorem 8.1

Assume the nonregular finite-type source regime of the preceding C06 reports, so `sigma_H^2>0`. Let `a_n` be any deterministic sequence satisfying

`a_n -> infinity`,

`a_n=o(n^(1/24))`.                                            (8.1)

Then there is a source-full set of surviving trees `A_MDP` such that for every fixed `T in A_MDP`, under the harmonic measure of that single tree,

`X_n=(I_n-n d_H)/(a_n sqrt(n))`                              (8.2)

satisfies a large-deviation principle with speed `a_n^2` and good rate function

`boxed{ J(x)=x^2/(2 sigma_H^2). }`                           (8.3)

Equivalently, for every Borel set `A`,

`-inf_{x in int A} J(x)`
` <= liminf a_n^{-2} log P_T(X_n in A)`
` <= limsup a_n^{-2} log P_T(X_n in A)`
` <= -inf_{x in closure A} J(x)`.                            (8.4)

#### Proof

For the martingale `M_n`, Section 7 verifies the quenched Chen--Ledoux / large-jump condition at speed `a_n^2`, and Section 6 verifies quenched exponential convergence of the predictable quadratic variation to the deterministic value `sigma_H^2`. These are the scalar hypotheses of the standard martingale MDP criterion of Djellout (2002), with the bounded-small-jump step supplied by the Dembo/Puhalskii theorem. Therefore

`M_n/(a_n sqrt(n))`

satisfies the MDP with speed `a_n^2` and rate (8.3) for every fixed `T` in a common `mu`-full set.

Because (8.1) is stronger than the endpoint range `a_n=o(n^(1/6))`, Section 5 says

`[W(Y_0)-W(Y_n)]/(a_n sqrt(n))`

is quenched-exponentially equivalent to zero at speed `a_n^2`. Equation (2.1) transfers the same MDP from `M_n` to `I_n-n d_H`. Finally `mu` is equivalent to the original source law conditioned on survival, so the full set is source-full. `square`

For the deterministic regular no-thinning source, `sigma_H=0` and `I_n=n log k` identically; Theorem 8.1 is intentionally stated only for the nonregular case.

### Corollary 8.2 — fixed-tree harmonic boundary tails beyond the CLT

For source-a.e. surviving nonregular tree `T`, every `x>0`, and every scale (8.1),

`boxed{
 lim_n a_n^{-2} log H_T(
   I_n-n d_H >= x a_n sqrt(n))
 = -x^2/(2 sigma_H^2),
}`                                                               (8.5)

and the analogous lower-tail statement holds with the same quadratic rate.

This is a genuine quenched boundary-fluctuation statement on scales diverging beyond the CLT, although the exponent `1/24` is a proof-range artifact, not claimed sharp.

## 10. Remaining gap and next attack

The `1/24` window comes from two quantified losses:

- `||u||_p=O(p^2)` from interpolating a fixed `L^2` spectral gap against the Markov `L^{2p}` contraction;
- `||z||_p=O(p^5)` and a Burkholder factor `p`, producing `||sum(v-sigma^2)||_p=O(sqrt(n)p^6)`.

The strongest next attack is therefore **not another fixed-order cumulant**. It is to improve one of these moment-growth mechanisms:

1. prove an `L^p` spectral gap for `K` with resolvent norm `O(p^alpha)` for `alpha<1`, ideally uniformly bounded, using the exact-pipe/genuine-branch decomposition; or
2. prove a direct exponential/stretched-exponential concentration inequality for the predictable variance observable `v` from the split-Palm representation, avoiding the second Poisson/Burkholder loss; or
3. construct a source-admissible example showing that true exponential integrability of the forward corrector `u` can fail, thereby identifying the correct Orlicz exponent.

Any improvement from `p^2` toward `p` for `u`, or from `p^5` toward `p^beta` for the variance corrector, enlarges the quenched MDP window immediately. A true exponential moment plus exponential quadratic-variation concentration would plausibly recover the full moderate regime `a_n=o(sqrt(n))` and would be a much stronger bridge toward local fixed-`q` quenched pressure.
