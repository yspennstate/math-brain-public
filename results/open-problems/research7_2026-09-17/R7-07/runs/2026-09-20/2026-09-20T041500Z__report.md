## 2. Inherited setup and exact remaining stress point

Let the finite type set be `D={1,...,d}`. A type-`i` parent has potential-child count `nu`, common pgf

\[
G(z)=E[z^\nu],\qquad m_*=G'(1)<\infty,

and a potential child is of type `j` with probability `q_j>0`, transmits with probability `p_{ij}>0`, then carries an independent type-`j` forward tree. Thus

\[
M_{ij}=m_*q_jp_{ij},\qquad \rho(M)>1.
\tag{2.1}
\]

For a rooted forward tree `T`, let

\[
B(T)=P_o^T(\text{never hit the artificial parent}),
\qquad
C(T)=\sum_u B(T_u),
\]

so

\[
B(T)=F(C(T)),\qquad F(x)=\frac{x}{1+x}.
\tag{2.2}
\]

Under the Palm law obtained by distinguishing one potential child of a type-`i` parent, let `R_i` be the total conductance of all nondistinguished siblings. R14 proved

\[
P(R_i=0)=\frac{G'(1-t_i)}{m_*},
\qquad
t_i=\sum_jq_jp_{ij}s_j,
\qquad s_j=P_j(B>0),
\tag{2.3}
\]

and the extinction Jacobian

\[
J_{ij}=G'(1-t_i)q_jp_{ij}
\tag{2.4}
\]

satisfies

\[
\rho(J)<1.
\tag{2.5}

The preceding C06 report proved the Palm lower-tail estimate

\[
P(0<R_i\le r)\le Ce^{-c/r}
\qquad(r\downarrow0),
\tag{2.6}

using a derivative-pgf increment, without a hidden second-moment assumption. Hence, uniformly over the finite type set,

\[
E[R_i^{-1};R_i>0]<\infty
\tag{2.7}

and, for some `c_1,C_1>0`,

E[R_i^{-1};0<R_i<x^{-1}]\le C_1e^{-c_1x}

Indeed if `Y=R_i^{-1}` on `R_i>0`, then (2.6) gives `P(Y>y)<=Ce^{-cy}`, and the standard tail integral for `E[Y;Y>x]` gives (2.8), after weakening the exponent.

## 4. Stieltjes cone and an exact measure-valued transfer

For a vector of finite positive measures

\[
\Lambda=(\Lambda_i)_{i\in D}
\quad\text{on }[0,\infty),
\]

define

\[
g_i^\Lambda(b)
=
\int_0^\infty\frac{1}{1+bu}\,\Lambda_i(du),
\qquad 0\le b\le1.
\tag{4.1}
\]

For `r>=0` put

\[
\Phi_r(u)
:=
\frac{1+u}{1+(1+u)r},
\qquad
w_r(u)
:=
\frac{1}{1+(1+u)r}.
\tag{4.2}
\]

The key algebra is

\[
\frac{1}{1+b+r}\,
\frac{1}{1+F(b+r)u}
=
\frac{w_r(u)}{1+b\Phi_r(u)}.
\tag{4.3}
\]

Therefore `T` preserves the Stieltjes cone exactly. Define a positive linear operator `A` on vector measures by

\[
\boxed{
(\mathcal A\Lambda)_j(E)
=
\sum_iM_{ij}
\int\Lambda_i(du)
E\left[
 w_{R_i}(u)
 \mathbf1_{\{\Phi_{R_i}(u)\in E\}}
\right].

\tag{4.4}
\]

Then

\[
\boxed{
\mathcal T g^\Lambda=g^{\mathcal A\Lambda}.
}
\tag{4.5}
\]

Thus a finite nonzero invariant measure `A Lambda=Lambda` immediately gives a positive transfer fixed point.

\[
\boxed{
\mathfrak m(\mathcal A\Lambda)=\mathfrak m(\Lambda).
}
\tag{6.4}

#### Proof

For any nonnegative `g`, use (3.3):

\[
\begin{aligned}
&\sum_jE_j\big[B_j(\mathcal Tg)_j(B_j)\big] \\
&=\sum_{i,j}M_{ij}

\frac{B_j}{1+B_j+R_i}

\tag{6.5}

The Palm identity turns the sum over distinguished children into an ordinary source parent expectation. For a realised parent with `C=sum_u B_u`,

\sum_u\frac{B_u}{1+C}=\frac C{1+C}=B_{\rm parent},

F(C)=B_{\rm parent}.

Thus (6.5) equals

\[
\sum_iE_i[B_i g_i(B_i)].

Apply this with `g=g^Lambda` and use (4.5). `square`

## 9. Direct construction of the harmonic stationary density

Set

\[

\tag{9.1}

\[
\mathcal Tg=g,
\qquad

\tag{9.2}

\[

=
\mathfrak m(\Lambda^*)=1.
\tag{9.3}
\]

Moreover every type receives positive mass. Indeed if any coordinate `Lambda_i^*` is nonzero, then for every target type `j`, `M_ij>0` and the kernel weight in (4.4) is strictly positive, so invariance forces

\[
\Lambda_j^*([0,\infty))>0
\qquad\forall j.
\tag{9.4}

Define

\[
L_j:=\Lambda_j^*([0,\infty))<\infty,
\qquad
A_j:=\int\frac{1}{1+u}\,\Lambda_j^*(du)>0.
\tag{9.5}
\]

For `0<=b<=1`,

\[
A_j\le g_j(b)\le L_j,

\[
\boxed{
A_jb\le h_j(b)\le L_jb.

\tag{9.6}
\]

\[
\boxed{
\mu(j,dT)=h_j(B(T))P_j(dT)

\tag{9.7}
