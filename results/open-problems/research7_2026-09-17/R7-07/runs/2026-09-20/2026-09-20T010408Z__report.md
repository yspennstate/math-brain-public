# Part I. The Palm sibling conductance has a reciprocal-exponential lower tail

## 3. Source child-conductance input

An earlier R7-07 theorem proved that for each type there are constants `C,c,x_0>0` such that

\[
P_i(0<B\le x)\le C e^{-c/x},
\qquad 0<x\le x_0.
\tag{3.1}
\]

In particular every negative moment of `B` on survival is finite. The proof used only finite `m_*=E\nu` together with `rho(J)<1`; it did not require `E\nu^2<infinity`.

For a type-`i` potential sibling slot define

\[
a_i(y)
:=\sum_jq_jp_{ij}P_j(0<B\le y).
\tag{3.2}
\]

Then for small `y`, uniformly over the finite type set,

\[
a_i(y)\le C_1e^{-c_1/y}.
\tag{3.3}
\]

The subtlety is that the Palm sibling count is `nu^*-1`, where `nu^*` is size biased. A crude expected-count estimate would invoke `E(\nu^*-1)` and therefore an unnecessary second moment of `nu`. The following derivative-pgf estimate avoids that mistake.

## 4. Lemma — small positive Palm sibling total with only finite mean

### Lemma 4.1

There exist constants `C_R,c_R,y_0>0` such that for every parent type `i`,

\[
\boxed{
P(0<R_i\le y)
\le C_R e^{-c_R/y},
\qquad 0<y\le y_0.
}
\tag{4.1}
\]

Only `m_*=E\nu<infinity` is needed in addition to (3.1); no second moment of `nu` is used.

### Proof

Conditional on `nu^*=n`, the `n-1` nondistinguished slots are independent source slots. A sibling slot has positive conductance with probability

\[
t_i=\sum_jq_jp_{ij}s_j,
\]

and has positive conductance at most `y` with probability `a_i(y)`.

If

\[
0<R_i\le y,
\]

then there is at least one small-positive sibling and there is no sibling whose conductance exceeds `y`. We may discard the additional requirement that the sum of several small conductances be at most `y`. Hence, conditional on `nu^*=n`,

\[
P(0<R_i\le y\mid\nu^*=n)
\le
(1-t_i+a_i(y))^{n-1}-(1-t_i)^{n-1}.
\tag{4.2}
\]

The size-biased law is

\[
P(\nu^*=n)=\frac{nP(\nu=n)}{m_*}.
\tag{4.3}
\]

Averaging (4.2) therefore gives the exact derivative-pgf upper bound

\[
\boxed{
P(0<R_i\le y)
\le
\frac{G'(1-t_i+a_i(y))-G'(1-t_i)}{m_*}.
}
\tag{4.4}
\]

Because `t_i>0` for every type and the type set is finite, for small enough `y` one has

\[
a_i(y)\le t_i/2.
\]

All arguments of `G'` in (4.4) then lie in a compact interval strictly inside `[0,1)`. Every pgf is analytic there, so `G''` is uniformly bounded on those intervals even if `G''(1)=infinity`. The mean value theorem gives

\[
G'(1-t_i+a_i(y))-G'(1-t_i)
\le C_2a_i(y).
\tag{4.5}
\]

Combining (4.5) with (3.3) proves (4.1). `square`

### Consequence

The old qualitative statement “near-pipe positive siblings are rare” is now source-valid at Palm level with the same reciprocal-exponential scale as a single surviving child. Importantly, the proof respects the actual moment hierarchy of the source reduction: size bias does not force us to assume a second forward-offspring moment merely to control `R_i downarrow 0`.

# Part II. Reciprocal-exponential tail of every invariant backward conductance

## 5. A weighted boundary contraction

Let `pi` be any invariant probability for the compact Feller kernel `P^kappa` from (2.10). We already know

\[
\pi(D\times\{0\})=0.
\tag{5.1}
\]

Since `rho(Q^0)<1`, choose a positive vector

\[
v=(I-Q^0)^{-1}\mathbf1.
\tag{5.2}
\]

Then

\[
Q^0v=v-\mathbf1
\]

and therefore

\[
q_0:=\max_i\frac{(Q^0v)_i}{v_i}
=
\max_i\left(1-\frac1{v_i}\right)<1.
\tag{5.3}
\]

For `0<a\le y`, define the `v`-weighted probability of landing at backward conductance at most `F(y)`:

\[
S_i(a,y)
:=
\frac1{v_i}
\sum_jv_j
P^\kappa\big((i,a),\{j\}\times(0,F(y)]\big).
\tag{5.4}
\]

Because `F` is increasing, the event in (5.4) forces

\[
a+R_i\le y.
\tag{5.5}
\]

In particular it is impossible when `a>y`.

Split (5.4) according to `R_i=0` and `R_i>0`.

### Exact-pipe contribution

For `R_i=0`, the `a/(a+R_i)` factor equals one, so

\[
S_i^{(0)}(a)
=
\frac1{v_i}
\sum_jv_jM_{ij}P(R_i=0)
\frac{\kappa_j(F(a))}{\kappa_i(a)}.
\tag{5.6}
\]

Using `F(a)/a->1` and `kappa_j(x)/x->s_j`,

\[
S_i^{(0)}(a)
\longrightarrow
\frac1{v_i}
\sum_jv_jM_{ij}P(R_i=0)\frac{s_j}{s_i}
=
\frac{(Q^0v)_i}{v_i}
\le q_0.
\tag{5.7}
\]

The type set is finite, hence the convergence is uniform in `i` as `a downarrow0`.

### Positive-sibling contribution

On `0<R_i\le y`, use the elementary bounds from (2.7):

\[
\kappa_j(F(a+R_i))\le F(a+R_i)\le a+R_i,
\qquad
\kappa_i(a)\ge ab_i.
\]

Therefore

\[
\frac{a}{a+R_i}
\frac{\kappa_j(F(a+R_i))}{\kappa_i(a)}
\le\frac1{b_i}.
\tag{5.8}
\]

Since `sum_jM_ij<infinity` and the type set is finite, Lemma 4.1 gives

\[
\sup_{0<a\le y}S_i^{(+)}(a,y)
\le C_3P(0<R_i\le y)
\le C_4e^{-c_4/y}.
\tag{5.9}
\]

Choose `q` with `q_0<q<1`. From (5.7)--(5.9), after shrinking `y_0`,

\[
\boxed{
\sup_i\sup_{0<a\le y\le y_0}S_i(a,y)\le q<1.
}
\tag{5.10}
\]

This is the exact endpoint contraction that was missing from the previous stationary-law construction.

## 6. Theorem — reciprocal-exponential invariant tail and finite un-Doob measure

Define the weighted stationary tail

\[
\Phi(x)=\sum_i v_i\pi_i((0,x]).
\tag{6.1}
\]

Stationarity, (5.5), and (5.10) imply for `0<y\le y_0`

\[
\begin{aligned}
\Phi(F(y))
&=\sum_i\int\pi_i(da)
\sum_jv_j
P^\kappa((i,a),\{j\}\times(0,F(y)])\\
&\le q\sum_i v_i\pi_i((0,y])
=q\Phi(y).
\end{aligned}
\tag{6.2}
\]

Let

\[
T(x)=F^{-1}(x)=\frac{x}{1-x}.
\]

Then

\[
\frac1{T(x)}=\frac1x-1,
\qquad
T^n(x)=\frac{x}{1-nx}
\tag{6.3}
\]

while `nx<1`. Rewriting (6.2) as

\[
\Phi(x)\le q\Phi(T(x))
\tag{6.4}
\]

and iterating until `T^n(x)` reaches the fixed scale `y_0` gives

\[
\boxed{
\Phi(x)\le C_5e^{-c_5/x}
}
\tag{6.5}
\]

for all sufficiently small `x`. Since the coordinates of `v` are positive and finite,

\[
\boxed{
\pi(A\le x)\le C_6e^{-c_6/x},
}
\tag{6.6}
\]

where `A` denotes the backward-conductance coordinate under `pi`.

Consequently, for some `eta>0`,

\[
\boxed{E_\pi e^{\eta/A}<\infty,}
\tag{6.7}
\]

and in particular every inverse moment `E_pi A^{-r}` is finite.

### Finite mass of lambda

Recall

\[
\lambda_j(da)=\frac{\pi_j(da)}{\kappa_j(a)}.
\]

Using `kappa_j(a)>=ab_j`,

\[
\lambda_j((0,1])
\le
\frac1{b_j}
\int\frac1a\,\pi_j(da)
<\infty.
\tag{6.8}
\]

Thus the measures that un-Doob-transform the invariant law are not merely sigma-finite:

\[
\boxed{\lambda_j((0,1])<\infty\quad\text{for every type }j.}
\tag{6.9}
\]

This removes a genuine endpoint bookkeeping weakness from the preceding candidate proof.

### Exact linear endpoint of the stationary tree density

Set

\[
L_j:=\lambda_j((0,1])\in(0,\infty).
\tag{6.10}
\]

From

\[
H_j(C)=\int\lambda_j(da)\frac{aC}{a+C},
\]

we obtain

\[
\frac{H_j(C)}C
=
\int\lambda_j(da)\frac{a}{a+C}.
\tag{6.11}
\]

The integrand is bounded by one and tends to one as `C downarrow0`. Dominated convergence against the now finite measure `lambda_j` yields

\[
\boxed{
H_j(C)=L_jC+o(C),
\qquad C\downarrow0.
}
\tag{6.12}
\]

Moreover

\[
0<H_j(C)\le L_jC
\tag{6.13}
\]

for every `C>0`.

Because (6.7) gives all inverse moments of `A`, the same representation actually supplies finite right derivatives of every order at zero. The linear term (6.12) is the part needed for the present proof architecture.

# Part III. The constructed density solves R14's old scalar-vector transfer equation exactly

## 7. Return to branch conductance coordinates

Write

\[
b=B(T)=\frac{C(T)}{1+C(T)},
\qquad
C=\frac{b}{1-b},
\]

and define

\[
h_j(b)=H_j\left(\frac{b}{1-b}\right),
\qquad 0<b<1.
\tag{7.1}
\]

Stationarity of `mu` under harmonic descent can be written directly as an incoming-density identity. A distinguished type-`j` child has branch conductance `b`; if its type-`i` parent has sibling total `R_i`, then the parent branch conductance is

\[
F(b+R_i)=\frac{b+R_i}{1+b+R_i},
\]

and the harmonic probability of choosing the distinguished child is

\[
\frac{b}{b+R_i}.
\]

Campbell's formula therefore gives

\[
\boxed{
 h_j(b)
 =m_*q_jb
 \sum_i p_{ij}
 E\left[
 \frac{h_i(F(b+R_i))}{b+R_i}
 \right].
}
\tag{7.2}
\]

This is **exactly** the scalar-vector transfer equation left in R14's canonical H0008 handoff.

Equation (6.12), together with `b/(1-b)~b`, also gives the endpoint normalization

\[
\boxed{
\frac{h_j(b)}b\longrightarrow L_j\in(0,\infty)
\qquad(b\downarrow0).
}
\tag{7.3}
\]

Hence the progress-first stationary construction does more than produce an abstract invariant law: it constructs a positive solution of the previously unresolved transfer equation with a controlled, finite, strictly positive linear endpoint.

This does **not** prove uniqueness of the solution of (7.2) in the natural endpoint class. Uniqueness is a high-value next problem because it would make the stationary law canonical rather than merely existent.

# Part IV. Exact local information geometry of the dimension drop

## 8. A pointwise Rényi interpolation between harmonic and PF splits

Let a surviving realised tree have positive-conductance children indexed by `u`. Let

\[
W_u=\mathcal W(T_u)>0,
\qquad
B_u=B(T_u)>0.
\]

The PF limit-uniform and harmonic child splits are

\[
U_u=\frac{W_u}{\sum_vW_v},
\qquad
H_u=\frac{B_u}{\sum_vB_v}.
\tag{8.1}
\]

Define the local conductance-to-growth ratio

\[
R_u=\frac{B_u}{W_u}>0.
\tag{8.2}
\]

Then, with

\[
Z_t=\sum_u U_uR_u^t,
\qquad
\phi(t)=\log Z_t,
\qquad 0\le t\le1,
\tag{8.3}
\]

we have `Z_0=1` and

\[
\boxed{
H_u=\frac{U_uR_u}{Z_1}.
}
\tag{8.4}
\]

For each `t`, define the tilted sibling law

\[
Q_t(u)=\frac{U_uR_u^t}{Z_t}.
\tag{8.5}
\]

Because each realised vertex has finitely many children, all quantities below are ordinary finite sums. Differentiation gives

\[
\phi'(t)=E_{Q_t}[\log R],
\qquad
\boxed{
\phi''(t)=\operatorname{Var}_{Q_t}(\log R)\ge0.
}
\tag{8.6}
\]

Thus harmonic measure is the `t=1` exponential tilt of PF-uniform measure by `log(B/W)`.

## 9. Theorem — the one-step KL penalty is an integrated sibling variance

From (8.4),

\[
\begin{aligned}
D_{KL}(H\Vert U)
&=\sum_uH_u\log\frac{H_u}{U_u}\\
&=\sum_uH_u\bigl(\log R_u-\log Z_1\bigr)\\
&=\phi'(1)-\phi(1).
\end{aligned}
\tag{9.1}
\]

Since `phi(0)=0`,

\[
\phi(1)=\int_0^1\phi'(t)dt.
\]

Therefore

\[
\begin{aligned}
\phi'(1)-\phi(1)
&=\int_0^1[\phi'(1)-\phi'(t)]dt\\
&=\int_0^1\int_t^1\phi''(s)\,ds\,dt\\
&=\int_0^1s\phi''(s)\,ds.
\end{aligned}
\]

Using (8.6),

\[
\boxed{
D_{KL}(H_T\Vert U_T)
=
\int_0^1
 t\,\operatorname{Var}_{Q_{T,t}}
 \left(
 \log\frac{B(T_u)}{\mathcal W(T_u)}
 \right)dt.
}
\tag{9.2}
\]

This identity is pointwise and requires no stationary-law theorem.

### Consequence for the candidate finite-type theorem

R14's already-proved PF--KL identity, combined with the stationary-law candidate proof from the preceding C06 report, says

\[
\log\rho(M)-\dim_H(\mathrm{HARM})
=
E_\mu D_{KL}(H_T\Vert U_T).
\tag{9.3}
\]

Because the integrand in (9.2) is nonnegative, Tonelli yields the sharper candidate representation

\[
\boxed{
\log\rho(M)-\dim_H(\mathrm{HARM})
=
E_\mu\int_0^1
 t\,\operatorname{Var}_{Q_{T,t}}
 \left(
 \log\frac{B(T_u)}{\mathcal W(T_u)}
 \right)dt.
}
\tag{9.4}
\]

This identifies the exact local source of dimension loss: **heterogeneity among siblings in the electrical-conductance-to-PF-growth ratio `B/W`**. The regular no-thinning equality class is precisely the class in which this sibling variance vanishes everywhere under the source law, consistent with R14's rigidity theorem.

Equation (9.4) is more useful for future quantitative work than the bare statement “the KL divergence is positive”: a quantitative dimension-deficit estimate can now be attacked by lower-bounding a local variance on a positive-probability branching cylinder.
