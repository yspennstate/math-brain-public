## 2. Recalled global scalar normal form

Write

```text
beta = alpha/2 in (0,1)
c_beta = Gamma(1-beta)
C_beta = Gamma(1-beta) Gamma(1+beta).
```

Let `S,S'` be iid positive beta-stable variables normalized by

```text
E exp(-t S) = exp[-c_beta t^beta],
```

and let `T=SS'`. Previous R7-06 work proved the exact Stieltjes coordinate

```text
q_beta(a) = E[ T/(a+T) ],
```

and the physical squared-radius map

```text
R_beta(a) = a [ q_beta(a)/C_beta ]^(1/beta).
```

`R_beta` is a smooth strictly increasing bijection `(0,infinity)->(0,infinity)`. If

```text
M_beta(r) = mu_alpha{ |z|^2 <= r },
```

then

```text
1 - M_beta(R_beta(a)) = q_beta(a),

g_alpha(sqrt(R_beta(a)))
  = - q_beta'(a) / [pi R_beta'(a)].
```

The ordinary Mellin transform is

```text
hat q_beta(s)
 = c_beta^(2s/beta)
   Gamma(s) Gamma(1-s/beta)^2 / Gamma(1-s),
       0 < Re(s) < beta.
```

Thus the current blocker is not the original PWIT recursion. It is the functional inverse `R_beta^{-1}` at a prescribed physical radius.

## 3. B6 — deform to the classical endpoint and identify the exact loss of algebraic inversion

The endpoint `beta=1` is singular under the BCC normalization because `Gamma(1-beta)` diverges. The right comparison first removes that deterministic scale. Define

```text
V_beta = S / c_beta^(1/beta).
```

Then

```text
E exp(-t V_beta) = exp(-t^beta).
```

Pointwise in `t>=0`, this tends to `exp(-t)` as `beta` increases to one, which is the Laplace transform of the constant one. Hence

```text
V_beta => 1,
U_beta := V_beta V_beta' => 1.
```

### 3.1 The scaled Stieltjes coordinate

Put

```text
a = c_beta^(2/beta) x
```

and define

```text
Q_beta(x)
 = q_beta(c_beta^(2/beta) x)
 = E[ U_beta/(x+U_beta) ].
```

For every fixed `x>0`, the integrand is bounded and continuous, so weak convergence gives

```text
Q_beta(x) -> 1/(1+x).
```

Now remove the remaining deterministic physical scale:

```text
calR_beta(x)
 = R_beta(c_beta^(2/beta)x) / c_beta^(1/beta).
```

Since `C_beta=c_beta Gamma(1+beta)`, direct substitution gives the exact identity

```text
calR_beta(x)
 = x [ Q_beta(x)/Gamma(1+beta) ]^(1/beta).
```

Therefore

```text
calR_beta(x) -> x/(1+x).
```

The radial CDF transforms simultaneously:

```text
M_beta( c_beta^(1/beta) calR_beta(x) )
 = 1 - Q_beta(x)
 -> x/(1+x).
```

Thus, after the natural BCC endpoint rescaling, the squared-radius CDF tends to the uniform-disc CDF. If the scaled squared radius is `s=x/(1+x)`, the endpoint inverse is the elementary Möbius formula

```text
x = s/(1-s).
```

This also identifies exactly what breaks for every `beta<1`. The product `U_beta` is then nondegenerate. If one nevertheless had `Q_beta(x)=1/(1+x)` for every positive `x`, uniqueness of Stieltjes transforms would force `U_beta=1` almost surely, contradicting nondegeneracy of the positive stable law. Hence the endpoint's algebraic inversion disappears immediately inside the heavy-tailed interval.

### 3.2 First derivative in beta at the endpoint

The scale-normalized Mellin transform is particularly clean:

```text
hat Q_beta(s)
 = Gamma(s) Gamma(1-s/beta)^2 / Gamma(1-s),
       0 < Re(s) < beta.
```

At `beta=1`, this is `Gamma(s)Gamma(1-s)`, the Mellin transform of `(1+x)^(-1)`. Differentiate with respect to beta:

```text
partial_beta hat Q_beta(s)|_{beta=1}
 = 2 s psi(1-s) Gamma(s) Gamma(1-s).
```

For `0<Re(s)<1`, a beta-integral differentiation gives

```text
Integral_0^infinity x^(s-1)
  [ 2x{1-gamma_E-log(1+x)}/(1+x)^2 ] dx
 = 2s psi(1-s) Gamma(s) Gamma(1-s).
```

Therefore Mellin uniqueness yields

```text
partial_beta Q_beta(x)|_{beta=1}
 = 2x{1-gamma_E-log(1+x)}/(1+x)^2.
```

On a fixed Mellin line `Re(s)=c`, `0<c<1`, the gamma factors and their first two beta derivatives have a common exponentially decaying Stirling majorant for beta sufficiently near one. Hence differentiation and Mellin inversion can be interchanged twice. With `epsilon=1-beta`, locally uniformly for `x` in compact subsets of `(0,infinity)`,

```text
Q_{1-epsilon}(x)
 = 1/(1+x)
   - 2 epsilon x{1-gamma_E-log(1+x)}/(1+x)^2
   + O(epsilon^2).
```

Next set

```text
D(x)
 = log(1+x)
   + [2x/(1+x)] {1-gamma_E-log(1+x)}
   - (1-gamma_E).
```

Expanding the logarithm of the exact formula for `calR_beta` gives

```text
calR_{1-epsilon}(x)
 = x/(1+x) [1 - epsilon D(x) + O(epsilon^2)].
```

Fix a compact subinterval of `0<s<1` and invert this expansion. At `epsilon=0`, `x0=s/(1-s)` and the derivative of `x/(1+x)` is `(1+x)^(-2)>0`, so the implicit-function theorem applies. Since

```text
D(x0) = (2s-1){1-gamma_E+log(1-s)},
```

we get the explicit inverse deformation

```text
x(s,epsilon)
 = s/(1-s)
   + epsilon * s(2s-1){1-gamma_E+log(1-s)}/(1-s)^2
   + O(epsilon^2).
```

Substituting into `M=1-Q` simplifies surprisingly strongly:

```text
M_{1-epsilon}( c_{1-epsilon}^{1/(1-epsilon)} s )
 = s
   + epsilon s{1-gamma_E+log(1-s)}
   + O(epsilon^2),
```

again locally uniformly away from the edge. Hence the rescaled squared-radius density has first variation

```text
dM/ds
 = 1 + epsilon[1-gamma_E+log(1-s)-s/(1-s)]
   + O(epsilon^2).
```

The pole as `s` approaches one shows where regular endpoint perturbation ceases to be uniform: the circular edge becomes a boundary layer immediately inside the heavy-tailed regime.

**B6 outcome:** successful restricted theorem. The mechanism making the endpoint inverse algebraic is the collapse of the normalized stable product to a point mass. The first inverse/CDF deformation away from that endpoint is explicit, but this is only a perturbative result near `alpha=2`; it does not close arbitrary `0<alpha<2`.

## 4. B17 — the alpha=1 blocker is the inverse of the standard Struve function K_0

For `alpha=1`, so `beta=1/2`, the preceding run had already reduced the physical inversion to

```text
rho = (pi/2)[ H_0(z) - Y_0(z) ],
z = pi/(2 sqrt(a)).
```

The current NIST DLMF notation makes this exact object standard: DLMF 11.2.5 denotes by bold `K_nu` the **Struve function of the second kind**

```text
bold K_nu(z) = bold H_nu(z) - Y_nu(z),
```

which is not the modified Bessel function `K_nu`. Therefore the inverse problem is

```text
rho = L(z) := (pi/2) bold K_0(z).
```

DLMF 11.5.2 and 11.5.3 give, for `z>0`,

```text
L(z)
 = Integral_0^infinity e^(-zu)/sqrt(1+u^2) du
 = Integral_0^infinity e^(-z sinh t) dt.
```

This representation immediately gives, for every integer `n>=0`,

```text
(-1)^n L^(n)(z)
 = Integral_0^infinity u^n e^(-zu)/sqrt(1+u^2) du > 0.
```

Hence `L` is completely monotone and strictly decreasing. It diverges at zero and tends to zero at infinity, so each positive `rho` has a unique positive inverse `z=L^{-1}(rho)`.

A bounded current literature check dated 2026-09-19 searched specifically for the functional inverse rather than ordinary evaluation: `inverse Struve K`, `inverse Struve function H0 Y0`, `inverse Lommel function`, `functional inverse H_0-Y_0`, and common special-function/CAS documentation. The current DLMF provides the direct function, ODE and integral transforms but the located material did not expose a named functional inverse. The located SciPy documentation exposes direct Struve functions, not an inverse-Struve primitive. A result titled *The inverse Laplace transform of the modified Lommel functions* concerns inverse **Laplace transforms**, not functional inversion. These misses are negative evidence only and are not used as a novelty or impossibility certificate.

**B17 outcome:** successful identification of the simplest obstruction. The `alpha=1` inversion is the inverse of a classical completely monotone Struve-`K_0` Laplace transform, not an unknown PWIT object. No standard named functional inverse was found in the bounded check, so a change of notation alone does not resolve the source target.

## 5. B20 — exact inverse ODE and a direct physical radial ODE at alpha=1

DLMF's Struve equation at order zero gives

```text
bold K_0''(z) + (1/z) bold K_0'(z) + bold K_0(z)
 = 2/(pi z).
```

Thus `L=(pi/2) bold K_0` satisfies

```text
L''(z) + (1/z)L'(z) + L(z) = 1/z.
```

Let

```text
Z(rho)=L^{-1}(rho).
```

Because `L'<0`, the inverse is smooth, and inverse differentiation gives

```text
L'(Z)=1/Z',
L''(Z)=-Z''/(Z')^3.
```

Substituting `z=Z(rho)` and `L(Z)=rho` into the Struve equation yields

```text
- Z''/(Z')^3 + 1/(Z Z') + rho = 1/Z.
```

Multiplying by `Z(Z')^3` produces the exact inverse equation

```text
Z Z'' = (Z')^2 + (rho Z - 1)(Z')^3.
```

Therefore the alpha=1 inverse is **differential-algebraic over C(rho), of differential order at most two**. This statement does not imply, and I do not claim, that the inverse is D-finite.

### 5.1 The inverse is not algebraic

The positive Laplace representation yields the large-`z` Watson expansion

```text
L(z)=1/z - 1/z^3 + 9/z^5 - 225/z^7 + O(z^-9).
```

The standard small-argument expansions of `H_0` and `Y_0` give

```text
L(z) = -log(z/2) - gamma_E + O(z)
```

as `z` decreases to zero. Hence the inverse satisfies

```text
Z(rho) ~ 1/rho                 as rho -> 0,
Z(rho) ~ 2 e^(-gamma_E)e^(-rho) as rho -> infinity.
```

The exponential decay rules out algebraicity over `C(rho)`. Suppose a nonzero polynomial

```text
P(rho,Z)=sum_{j=0}^m p_j(rho) Z^j
```

vanished identically. Let `j0` be the least index with `p_j0` nonzero and divide by `Z^j0`. All terms with `j>j0` are then a polynomial times an exponentially decaying factor as `rho->infinity`, while the surviving nonzero polynomial `p_j0(rho)` cannot itself be exponentially small. Contradiction. Thus

```text
Z is differential-algebraic but not algebraic.
```

This is a precise structural classification of the simplest physical inverse. It does not rule out D-finiteness or every broader special-function class.

### 5.2 Eliminate the inverse from the alpha=1 radial law

For `beta=1/2`, the exact formulas simplify further. From the Struve representation one has

```text
F(a)=rho/sqrt(a),
sqrt(a)=pi/(2 Z(rho)),
C_{1/2}=pi/2.
```

Therefore the physical radial tail is exactly

```text
Q(rho)
 := 1 - mu_1{ |w| <= rho }
 = rho Z(rho).
```

Set `Z=Q/rho`. Then

```text
Z'  = (rho Q' - Q)/rho^2,
Z'' = Q''/rho - 2Q'/rho^2 + 2Q/rho^3.
```

Substituting these identities into the inverse ODE and clearing denominators gives a completely nonparametric second-order ODE for the alpha=1 radial tail:

```text
rho^2 Q (rho^2 Q'' - 2 rho Q' + 2Q)
 = rho^2 (rho Q' - Q)^2
   + (Q-1)(rho Q' - Q)^3.
```

No PWIT variable, stable expectation, Mellin parameter, or inverse symbol remains. The planar density is recovered directly by

```text
g_1(rho) = -Q'(rho)/(2 pi rho),
```

with the physical branch selected by

```text
Q(0+)=1,
Q(infinity)=0,
0<Q(rho)<1.
```

As a cross-check, formal reversion of the large-`z` expansion gives

```text
Z(rho)=rho^(-1)-rho+7rho^3-178rho^5+O(rho^7),
Q(rho)=1-rho^2+7rho^4-178rho^6+O(rho^8),
```

hence

```text
g_1(rho)
 = 1/pi - (14/pi)rho^2 + (534/pi)rho^4 + O(rho^6).
```

The first two terms independently recover the origin value and the earlier R7-06 curvature coefficient. At the other endpoint,

```text
Q(rho) ~ 2 e^(-gamma_E) rho e^(-rho),
g_1(rho) ~ e^(-gamma_E)/pi * e^(-rho),
```

which independently recovers the previous alpha=1 tail calculation.

**B20 outcome:** successful restricted theorem. At `alpha=1` the inverse is differential-algebraic but nonalgebraic, and the physical radial law itself obeys an exact nonlinear second-order ODE with no auxiliary parameter. This is stronger than an implicit special-function inversion but remains one special alpha, not the all-alpha source closure.
