## 4. B1 — CHANGE THE CATEGORY: `S` is gauge and the exact object is a self-spectral set

The new artifact proves the following lossless reduction.

### 4.1 Unique form on a chosen image basis

Let `U=im_F2 N`, and let `X` be any full-column-rank `v x m` basis matrix for `U`. Symmetry gives

\[
\ker N=U^\perp=\ker X^T.
\]

Since `im N subset im X`, factor `N=XA`. Equality of kernels and ranks forces `A=S X^T` for a unique invertible `m x m` matrix `S`. Symmetry of `N`, followed by multiplication by a left inverse of `X`, forces `S=S^T`. Hence

\[
\boxed{N=XSX^T}
\tag{4}
\]

with unique nonsingular symmetric `S` for a fixed chosen basis `X`.

### 4.2 Odd-dimensional form classification removes `S`

Here `m` is odd. I gave a self-contained proof that every nonsingular symmetric bilinear form on `F_2^m` is congruent to the standard dot product. The key point is that the norm functional `ell(x)=B(x,x)` is nonzero; its representing vector `omega` has norm one, while `omega^perp` is a nondegenerate alternating even-dimensional space. Thus

\[
B\cong\langle1\rangle\perp H^{(m-1)/2}\cong I_m.
\]

Consequently there is `T in GL_m(F_2)` with

\[
S=TT^T.
\]

Replacing `X` by `XT` gives the Euclidean factorization

\[
\boxed{N=XX^T.}
\tag{5}
\]

This is a gauge choice, not a count reduction.

### 4.3 Principal Walsh / self-spectral normal form

Write the rows of the Euclidean factor as `p_1,...,p_v in F_2^m` and define

\[
Q=\{0,p_1,\ldots,p_v\}.
\]

Exact row weights and intersections imply that the `p_i` are nonzero and pairwise distinct, and full column rank gives `span Q=F_2^m`. Therefore

\[
|Q|=v+1=2m+2=n.
\]

Since `N_ij=p_i dot p_j (mod 2)`, the entire normalized symmetric Hadamard matrix is

\[
\boxed{
\widetilde H=W_Q:=\bigl((-1)^{x\cdot y}\bigr)_{x,y\in Q}.
}
\tag{6}
\]

The converse is exact as well: if `Q subset F_2^m` contains zero, spans, has size `2m+2`, and its principal Walsh matrix `W_Q` is Hadamard, then ordering `Q={0,p_1,...,p_v}` and setting `N_ij=p_i dot p_j` reconstructs (1) and has `rank_F2 N=m`. The proof recovers row weight `m+1` from orthogonality with the all-one row and pairwise intersection `(m+1)/2` from the Hamming distance between two Hadamard rows.

Thus the final-recovery core is exactly a **self-spectral set** in `F_2^m`: a set `Q` whose own characters form a Hadamard matrix when restricted to `Q`. Equivalently, `W_Q` is a principal Hadamard submatrix of the full Walsh matrix.

This is the main conceptual progress of the run. The STUCK2 coupled `(P,S)` object was not the minimal invariant: `S` can be gauged away. The exact remaining object is one self-principal Fourier subset `Q`.

## 7. B20 — FIND WHY THE ALGORITHM FAILS: quadratic information moves into the Gram form

The half-Hadamard seed does not close the count. The failure is exact and quantitative.

If the chosen basis is encoded by `R in GL_m(F_2)` and one changes coordinates by `x=Rz`, then the standard dot product becomes

\[
x\cdot y=z^T G w,
\qquad
G=R^TR.
\tag{10}
\]

Thus normalizing the seed to the standard basis changes the character matrix from standard Walsh characters to the pairing `(-1)^{z^T G w}`. The basis information has moved into a nonsingular symmetric Gram matrix `G`.

Because `m` is odd, every nonsingular symmetric `G` occurs as `R^TR`; two basis matrices give the same `G` exactly up to the orthogonal gauge. Therefore the number of possible Gram forms is

\[
\frac{|GL(m,2)|}{|O(m,2)|}
=2^{(m^2+m)/2+O(1)}.
\tag{11}
\]

So arbitrary basis normalization leaves roughly `m^2/2` bits. The correct failure statement is not merely “the seed is large”; it is:

> the good-seed algorithm conserves a quadratic Gram parameter unless one proves additional restrictions coupling the transformed set to its bilinear form.

This is why the next route must exploit **self-principality** (`Q` is simultaneously the row set and the spectrum), not just ordinary Hadamard completion from half the columns.
