## B25 — count the same thing twice: spectrum entropy is only O(n)

Let `S_n` be the set of possible unordered integral spectra. Every `lambda=(lambda_1,...,lambda_n) in S_n` satisfies

`sum_i lambda_i^2 = tr(M^2)=n^2`.

Forget the signs. The nonzero squares form a partition of `n^2`; therefore the absolute-value multiplicity pattern has at most `p(n^2)` possibilities. If the positive magnitude `a` occurs `m_a` times, then there are exactly `m_a+1` ways to split those copies between `+a` and `-a`, hence at most

`prod_a (m_a+1) <= 2^{sum_a m_a} <= 2^n`

sign refinements.

A short generating-function bound is enough to control the partition number without importing an asymptotic theorem. Put `x=e^{-1/sqrt(N)}`. Euler's product gives

`p(N)x^N <= prod_{k>=1}(1-x^k)^{-1}`,

and

`log prod_{k>=1}(1-x^k)^{-1}
 = sum_{m>=1} 1/[m(e^{m/sqrt(N)}-1)]
 <= sqrt(N) sum_{m>=1}1/m^2
 = (pi^2/6)sqrt(N)`.

Thus

`p(N) <= exp((1+pi^2/6)sqrt(N))`,

and therefore

`|S_n| <= 2^n p(n^2) = exp(O(n))`.

For `lambda in S_n`, let `F_n(lambda)` be the number of switching-normalized matrices with that exact spectrum. Since

`I_n = sum_lambda F_n(lambda)`, 

we have

`max_lambda F_n(lambda) <= I_n <= exp(O(n)) max_lambda F_n(lambda)`.

Hence the source conjecture is **equivalent** to the single-fiber statement

`max_lambda F_n(lambda) = 2^{o(n^2)}`.

This is the main conceptual movement of the run: the choice of integral spectrum itself carries only linear entropy. Any quadratic obstruction must live inside one cospectral switching class.

A secondary consequence is that an integral spectrum has `O(n^{2/3})` distinct eigenvalues, since the sum of squares of `r` distinct integers is `Omega(r^3)` but the full spectral square sum is only `n^2`. This does not by itself bound the fiber.

## B30 — localize at one prime: exact matrix splitting test and gluing obstruction

For any `n x n` matrix `A` over `F_p`, define `B=A^p-A`.

### Lemma (complete splitting iff `B` is nilpotent)

The characteristic polynomial of `A` splits completely over `F_p` if and only if

`(A^p-A)^n=0`.

Proof: over an algebraic closure, every eigenvalue `lambda` of `A` maps to eigenvalue `lambda^p-lambda` of `B`. If `B` is nilpotent then every `lambda` lies in `F_p`, so the characteristic polynomial splits. Conversely, if all eigenvalues lie in `F_p`, each Jordan block is `lambda I+N`; the polynomial `x^p-x` has zero constant term after substitution at `lambda`, so its value on the block is a polynomial in the nilpotent `N` with zero constant term and is nilpotent. An `n x n` nilpotent matrix has nth power zero. QED.

Therefore one failed prime gives an exact non-integrality certificate without factoring a polynomial.

The obstruction to naively multiplying primes is now explicit. A fixed `p` has only

`binom(n+p-1,p-1)`

split monic degree-`n` polynomials, which is polynomial in `n` for fixed `p`; against `p^n` monic polynomials this idealized filter costs only `Theta(n)` bits. More seriously, reductions modulo different primes are deterministic images of the **same sign matrix**, not independent random matrices. CRT alone gives no probability product.

The exact finite census makes this visible. Simultaneous splitting modulo `3,5,7` coincides exactly with integrality for every `n<=7`, but at `n=8` it leaves `190,250` normalized matrices while only `111,290` are integral. Thus the tempting three-prime pattern genuinely breaks at the next case.

At `n=8`, testing `{3,5,7,11,13}` gives the following exact stronger fact. No two-prime subset of this tested set characterizes integrality. However each of

`{3,5,13}`, `{3,7,13}`, `{5,7,13}`, `{5,11,13}`

leaves exactly `111,290` matrices. Since every integral-spectrum matrix must survive every prime-splitting test, equality of the exact cardinalities proves equality of the sets for these finite cases. The near miss `{7,11,13}` leaves `111,306`, exactly sixteen false positives.

This suggests that a growing-prime filter may be mathematically useful, but no cross-prime independence or asymptotic exponent is claimed.

**B30 outcome:** exact local criterion, exact finite prime certificates, and a precise CRT-gluing failure; no asymptotic source closure.
