Earlier R7-06 work proved `|S_n|=exp(O(n))` and

`K_n(lambda) <= F_n(lambda) <= n! K_n(lambda)`,

\[

Thus an entire arbitrary-Hadamard family can sit inside one F0011 spectral fiber. A successful proof cannot assume that fixing the spectrum leaves only weakly correlated row choices.

## 7. Nearest solved analogue

The nearest solved **methodological** analogue found in the current literature is Caden Young, *Sharp Exponential Asymptotics for Normal Sign Matrices*, arXiv:2607.15294, submitted 2026-07-01.

Young proves for an iid `n x n` sign matrix

\[
\Pr(MM^T=M^TM)=2^{-\binom n2+O(n)}.
\]

The matching upper bound has exactly the kind of global entropy accounting F0011 lacks:

1. condition on the symmetric/skew-symmetric type pattern of every off-diagonal pair;
2. reduce the commutator equations modulo 4 to an affine linear system over `F_2`;
3. use rank duality to turn the sum of `2^{-rank}` over type patterns into a count of commuting symmetric pairs over `F_2`;
4. group by rational canonical type and use finite-field centralizer dimensions / balanced symmetric bilinear forms; the number of canonical types is only `2^{O(n)}`.

The crucial feature **missing from F0011** is the first nontrivial linearization. In Young's problem, the symmetric/skew type pattern `t` remains a quadratic-size source of structure and the commutator equation becomes many linear equations after mod 4. In F0011 the matrix is already symmetric, so the normality type pattern collapses to the all-symmetric slice and normality is automatic. The fixed-spectrum condition is instead encoded by global polynomial identities whose useful 2-adic linearization has not been found.

A second, structurally closer but not source-closing analogue is Ferber-Jain-Zhao, *On the number of Hadamard matrices via anti-concentration*, CPC 31 (2022). Their published theorem gives a fixed positive quadratic-exponent saving, but their Conjecture 1.3 predicts `H(n)=2^{O(n log n)}` and they explicitly state that even `H(n)=2^{o(n^2)}` would be very interesting and likely require new ideas. Thus the Hadamard boundary is not already disposed of by known anti-concentration.
