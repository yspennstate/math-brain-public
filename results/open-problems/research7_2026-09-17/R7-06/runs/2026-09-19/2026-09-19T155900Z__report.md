## 2. B30 — the first nontrivial 2-adic lift is a bounded-rank square-root problem

Take the simplest source-valid core

\[
H=H^T\in\{\pm1\}^{n\times n},\qquad H^2=nI,
\]

and put

\[
A=(J-H)/2\in\operatorname{Sym}_n(\{0,1\}),\qquad r=A1.
\]

From `H=J-2A` and symmetry of `A`,

\[
\boxed{
2A^2=1r^T+r1^T+\frac n2(I-J).
}
\tag{2.1}
\]

Write `n=4q`. Modulo two, (2.1) first forces all integer row sums `r_i` to have one common parity `p`. Write

\[
r\equiv p1+2u\pmod4,
\qquad u\in\mathbb F_2^n.
\]

Reducing the already-divided identity modulo two gives

\[
A^2=1u^T+u1^T+(p+q)J+qI
\quad(\bmod 2).
\]

Therefore, with

\[
C=A+(q\bmod2)I,
\]

one has the exact finite-field relation

\[
\boxed{
C^2=R_{p,u}:=1u^T+u1^T+(p+q)J,
\qquad \operatorname{rank}R_{p,u}\le2.
}
\tag{2.2}
\]

The coarse type `(p,u)` has only `2^{O(n)}` possibilities. This is the first nontrivial 2-adic spectral constraint found after the universal `H=J (mod 2)` collapse.

There is an even stronger exact integer identity:

\[
\boxed{
A^2=\frac n4I+
\frac12(1r^T+r1^T)-\frac n4J.
}
\tag{2.3}
\]

Thus conditioning on the full row-sum vector `r`, which has only `(n+1)^n=2^{O(n\log n)}` possibilities, fixes `A^2` completely as a scalar matrix plus a rank-at-most-two perturbation.

**Outcome B30:** the Young-style first lift does produce genuine global structure, but not a high-rank affine `F_2` system. It produces a symmetric square-root equation with bounded-rank square.

## 3. B11 — dualize through the image: almost-isotropic subspaces

I proved the following counting theorem.

### Theorem

For every fixed `s`, uniformly over all `R\in\mathbb F_2^{n\times n}` with `rank R<=s`,

\[
\boxed{
\#\{C\in\operatorname{Sym}_n(\mathbb F_2):C^2=R\}
\le 2^{n^2/4+O_s(n)}.
}
\tag{3.1}
\]

### Proof

For a solution set `U=im C` and `r=dim U`. Choose a basis matrix `X` for `U` and preimages `V` with `CV=X`. Then

\[
X^TX=V^TC^2V=V^TRV,
\]

so the standard dot product restricted to `U` has rank at most `s`.

For fixed dimension `r`, count ordered bases `X=(x_1,\ldots,x_r)` with Gram matrix `K=X^TX` of rank at most `s`. There are only `2^{O_s(r)}` possible such `K`. For fixed `K`, when `x_1,\ldots,x_{i-1}` are independent, the `i-1` equations

\[
x_j^Tx_i=K_{ji},\qquad j<i,
\]

are independent linear equations in `x_i`. Ignoring the diagonal Gram equation only enlarges the count, so the number of ordered bases is at most

\[
2^{nr-r(r-1)/2+O_s(r)}.
\]

Dividing by

\[
|GL_r(\mathbb F_2)|=2^{r^2+O(1)}
\]

bounds the number of possible image spaces by

\[
2^{nr-r(r-1)/2-r^2+O_s(r)}.
\]

For fixed `U` with basis matrix `X`, any symmetric `C` with image in `U` annihilates `U^\perp`, hence factors as

\[
C=XSX^T
\]

with `S=S^T`. Thus there are at most `2^{r(r+1)/2}` such `C`. Multiplication gives

\[
2^{r(n-r)+O_s(n)}\le2^{n^2/4+O_s(n)}.
\]

Summing over `r` proves (3.1).

Applying this with `s=2` to (2.2), and summing over the `2^{O(n)}` types `(p,u)`, yields the restricted theorem

\[
\boxed{
\#\{\text{labeled symmetric real Hadamard matrices of order }n\}
\le2^{n^2/4+O(n)}.
}
\tag{3.2}
\]

The same bound holds for any fixed trace/eigenvalue-multiplicity subfamily; hence it applies to one fixed integral spectral fiber on square Hadamard orders.

This is genuine progress on the STUCK1 recovery route: the first 2-adic constraint cuts the naive symmetric-sign entropy from approximately `n^2/2` bits to at most `n^2/4+O(n)` bits on the hardest two-eigenvalue core.

It is still far from the source requirement `2^{o(n^2)}`.
