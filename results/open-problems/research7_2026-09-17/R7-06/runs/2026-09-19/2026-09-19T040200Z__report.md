## 3. B3 — a stronger direct equation in physical radius for every beta

Define

```text
f_beta(a) = -a q_beta'(a)
          = E[aT/(a+T)^2].
```

For `-1 < Re(s) < beta`, exact Beta integration gives

```text
hat f_beta(s)
 = c_beta^(2s/beta)
   Gamma(1+s) Gamma(1-s/beta)^2 / Gamma(1-s).
```

Indeed `E[S^s]=c_beta^(s/beta) Gamma(1-s/beta)/Gamma(1-s)` and

```text
Integral_0^infinity u^s/(1+u)^2 du
 = Gamma(1+s) Gamma(1-s).
```

On the overlap strip `-1<Re(s)<0`, both `s` and `s+beta` are admissible, and the Gamma recurrence gives the exact shift equation

```text
hat f_beta(s+beta) = Psi_beta(s) hat f_beta(s),
```

where

```text
Psi_beta(s)
 = (beta c_beta)^2
   Gamma(1+s+beta) Gamma(1-s)
   / [s^2 Gamma(1+s) Gamma(1-s-beta)].
```

Let `A=a d/da`.  Mellin transform sends `A` to multiplication by `-s`, while multiplication by `a^beta` shifts `s` to `s+beta`.  Hence

```text
Psi_beta(-A) f_beta = a^beta f_beta.                 (3.1)
```

This is an exact dilation-functional equation, with `Psi_beta(-A)` defined by the displayed Mellin multiplier on any line `-1<c<0`.

Now pass to physical squared radius.  Let

```text
D = r d/dr,
y = D log Q,
A_Q = [beta/(beta-y)] D.
```

Differentiating

```text
log R = log a + beta^(-1)(log q - log C_beta)
```

shows that `A` pulls back exactly to `A_Q`.  Therefore

```text
f_beta(a(r)) = -A_Q Q(r) =: F_Q(r) > 0.
```

The radius identity gives

```text
a(r)^beta = C_beta r^beta/Q(r).
```

Conjugating (3.1) therefore yields the direct all-index physical equation

```text
Psi_beta(-A_Q) F_Q
  = [C_beta r^beta/Q] F_Q,
F_Q = -A_Q Q.                                         (3.2)
```

with boundary data `Q(0)=1`, `Q(r)->0` at infinity.

**Outcome B3:** successful theorem.  Equation (3.2) contains no PWIT variable, no stable expectation, no self-consistent `y_*`, and no explicit `R_beta^{-1}`.  It is, however, a nonlinear **nonlocal** Mellin/dilation equation for irrational beta.  Rational beta closes after finitely many commensurable Mellin shifts and recovers the finite nonlinear ODE structure of earlier runs.  I therefore record (3.2) as real source-level structural progress but not as a closed-form solution.

## 4. B18 — the inverse is exactly one log-stable-logistic quantile

Let `E_1,E_2` be iid Exp(1), independent of `S,S'`.  The ratio `V=E_1/E_2` has CDF

```text
P(V <= x) = x/(1+x).
```

Define

```text
W_beta = SS' E_1/E_2 = T V.
```

Conditioning on `T` gives the exact identity

```text
P(W_beta <= a)
 = E[a/(a+T)]
 = 1-q_beta(a).                                        (4.1)
```

Let `X_beta=log W_beta` and let `K_beta(u)` denote its quantile.  If `u` is the radial CDF value, then `a=exp(K_beta(u))`, and the exact squared-radius and ordinary-radius quantiles are

```text
r_beta(u)
 = C_beta^(-1/beta) (1-u)^(1/beta) exp(K_beta(u)),
```

and

```text
rho_alpha(u)
 = C_beta^(-1/alpha) (1-u)^(1/alpha) exp(K_beta(u)/2),
 alpha=2 beta.                                         (4.2)
```

The obstruction distribution itself has an explicit Gamma-quotient transform.  For `-1<Re(s)<beta`,

```text
E exp(s X_beta)
 = c_beta^(2s/beta)
   Gamma(1-s/beta)^2 Gamma(1+s)/Gamma(1-s).           (4.3)
```

Therefore

```text
phi_beta(t)
 = c_beta^(2it/beta)
   Gamma(1-it/beta)^2 Gamma(1+it)/Gamma(1-it).
```

Every cumulant is explicit.  In particular

```text
E X_beta
 = (2/beta)(log c_beta + gamma_E) - 2 gamma_E,
Var X_beta = pi^2/(3 beta^2),
```

and, for every integer `n>=2`,

```text
cum_n(X_beta)
 = (n-1)! zeta(n) [2/beta^n + (-1)^n - 1].            (4.4)
```

So the remaining inverse has been recast as the ordinary quantile of a one-dimensional distribution whose characteristic function is explicit and whose complete cumulant sequence is closed-form.

## 5. B22 — a physical non-D-finiteness theorem

The STUCK1 literature failure search suggested a more meaningful question than “is there a named inverse?”: does the physical law lie in the holonomic/D-finite class at all?  Gerhold's 2012 implied-volatility paper uses precisely this kind of obstruction for another difficult functional inverse.  Here the proof can be made directly from the BCC tail and does not import Gerhold's theorem.

The first Mellin pole from the previous exact representation is a double pole at `s=beta`.  Residue inversion gives

```text
Q_beta(r)
 ~ D_beta r^beta exp(-r^beta),                         (5.1)
```

with explicit positive

```text
D_beta
 = Gamma(1+beta)/Gamma(1-beta)
   * exp[-2 gamma_E - beta(psi(beta)+psi(1-beta))].
```

The Mellin integrand has exponential Gamma decay, so any fixed number of Euler derivatives may be passed through the shifted contour.  Thus for every fixed integer `j>=0`,

```text
Q_beta^(j)(r)/Q_beta(r)
 = (-beta)^j r^(j(beta-1)) (1+o(1)).                  (5.2)
```

### Theorem — irrational beta implies physical non-holonomicity

If `beta` is irrational, `Q_beta(r)` is not D-finite over `C(r)`.

**Proof.**  Suppose

```text
sum_{j=0}^m P_j(r) Q_beta^(j)(r) = 0
```

with polynomials `P_j`, not all zero.  For each nonzero `P_j`, let `d_j` and `p_j` be its degree and leading coefficient.  Divide by `Q_beta`.  By (5.2), the `j`th term has leading scale

```text
p_j (-beta)^j r^[d_j+j(beta-1)].
```

Cancellation of the unique largest power is impossible unless two exponents agree.  If `i!=j`, equality would imply

```text
beta-1 = (d_j-d_i)/(i-j),
```

which is rational.  This contradicts irrational beta.  QED.

Since

```text
g_alpha(rho) = -Q_beta'(rho^2)/pi,
```

(5.1)-(5.2) give

```text
g_alpha(rho)
 ~ (beta D_beta/pi)
    rho^(2alpha-2) exp(-rho^alpha).                   (5.3)
```

The same dominant-balance argument now uses exponents `d_j+j(alpha-1)`, so

```text
alpha irrational
  ==> g_alpha(rho) is not D-finite.                   (5.4)
```

This is a theorem about the actual source density in physical radius, not merely the auxiliary `q_beta` coordinate.

For rational `beta=p/q`, earlier work proved `q_beta` is D-finite.  D-finite functions are D-algebraic, rational powers preserve D-algebraicity, and the univariate D-algebraic class is closed under composition, differentiation, and functional inverse.  Therefore

```text
beta rational
  ==> Q_beta and g_(2 beta) are D-algebraic.          (5.5)
```

The closure-under-inverse step is documented constructively in Bertrand Teguia Tabuguia, *Operations for D-Algebraic Functions* (2023).  At beta=1/2 the previous run already displayed the resulting finite nonlinear physical ODE explicitly.

**Outcome B22:** successful theorem and sharper obstruction.  Irrational alpha is outside the entire D-finite/holonomic class.  Rational beta stays inside the larger D-algebraic class.  The theorem does not rule out D-algebraicity for irrational beta, and it does not claim that no broader “closed form” can exist.
