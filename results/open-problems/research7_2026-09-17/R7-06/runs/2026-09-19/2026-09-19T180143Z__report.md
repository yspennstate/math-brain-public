# Method B5 — introduce 2-adic lift depth explicitly

## Even `t`: exact depth of the first nonzero divided square

For even `t`, define the actual binary matrix `N=J-G`. Then

\[
N\mathbf1=2t^2\mathbf1
\]

and direct substitution in (1) gives the integer identity

\[
\boxed{N^2=t^2(I+J).}
\tag{2}
\]

Indeed, `J^2=vJ`, `JG=GJ=(2t^2-1)J`, and the coefficient of `J` simplifies to `t^2`.

Let `a=nu_2(t)>=1`, so `t=2^a u` with `u` odd. Equation (2) now gives an exact lift-depth statement:

\[
2^{-j}N^2\equiv0\pmod2\quad(0\le j<2a),
\]

while

\[
\boxed{2^{-2a}N^2\equiv I+J\pmod2.}
\tag{3}
\]

Thus the first nonzero divided square occurs at depth exactly `2 nu_2(t)`. In particular

\[
N^2/2\equiv0\pmod2,
\]

and the next visible level is

\[
\boxed{N^2/4\equiv(t/2\bmod2)(I+J)\pmod2.}
\tag{4}
\]

Entrywise, if `R_i` is a row support,

\[
\boxed{|R_i|=2t^2,\qquad |R_i\cap R_j|=t^2\quad(i\ne j).}
\tag{5}
\]

So row weights are divisible by eight and pair intersections by four; more sharply the off-diagonal intersection valuation is exactly `2 nu_2(t)`.

## Odd `t`: an explicit diagonal-colored Bockstein law

For odd `t`, let `N` be the binary representative of `G+I (mod 2)`, put `d_i=N_{ii}`, `D=diag(d_i)`, and `E=I-2D`. Then `G=N+E` exactly. Substitution in (1) gives

\[
\boxed{N^2+NE+EN=(t^2-1)(I+J).}
\tag{6}
\]

Since `E=I-2D`, division by two gives

\[
\boxed{
\frac{N^2}{2}+N-(ND+DN)
=\frac{t^2-1}{2}(I+J).
}
\tag{7}
\]

Every odd square is `1 mod 8`, so the right side is even and the first divided-square law is

\[
\boxed{
Q_1(N):=N^2/2\equiv N+ND+DN\pmod2.
}
\tag{8}
\]

If `b=nu_2(t^2-1)>=3`, then the residual on the left of (7) vanishes through depth `b-2` and satisfies

\[
\boxed{
2^{-(b-1)}\left[N^2/2+N-(ND+DN)\right]
\equiv I+J\pmod2.
}
\tag{9}
\]

The exact row/intersection laws are

\[
\boxed{|R_i|=2(t^2-1+d_i),}
\tag{10}
\]

and, for `i\ne j`,

\[
\boxed{|R_i\cap R_j|
=t^2-1-2N_{ij}(1-d_i-d_j).}
\tag{11}
\]

In particular

\[
\boxed{
|R_i|/2\equiv d_i,
\qquad
|R_i\cap R_j|/2\equiv N_{ij}(1+d_i+d_j)
\pmod2.
}
\tag{12}
\]

**B5 outcome.** The first parity shadow now has a fully explicit higher 2-adic signature in both parity branches. This is genuine structural movement but not movement of the frozen source metric.

# Method B17 — identify the exact code-theoretic image filter

Return to even `t` and put

\[
m=(v-1)/2=2t^2-1,
\qquad
W=\mathbf1^\perp\le\mathbb F_2^v.
\]

Suppose the exact `N` has maximal possible binary rank `m` and set `U=im_{F_2}N`. Since `N^2=0` and `N1=0` over `F_2`, `U` is a Lagrangian subspace of the `2m`-dimensional symplectic space `W`.

On `W` define

\[
q(x)=\operatorname{wt}(x)/2\pmod2.
\]

For even-weight vectors,

\[
q(x+y)=q(x)+q(y)+x\cdot y,
\]

so this is a quadratic refinement of the symplectic form. Equation (5) gives `q(r_i)=t^2=0 mod2` for every generating row and zero binary pair products. Hence

\[
\boxed{q|_U=0.}
\tag{13}
\]

Thus every word of `U` has weight divisible by four.

Now extend by one coordinate:

\[
\boxed{
C_U=\{(u,0):u\in U\}+\langle(\mathbf1,1)\rangle.
}
\tag{14}
\]

This code has dimension `m+1=n/2`, is self-orthogonal, and therefore is self-dual. Because `n=4t^2` is divisible by sixteen for even `t`, (13) also makes every word in the nontrivial coset have weight divisible by four. Therefore

\[
\boxed{C_U\text{ is a Type-II binary self-dual code}.}
\tag{15}
\]

There is a further exact projectivity condition: every column of `N` is nonzero, and no two columns are equal. Otherwise two equal columns would have integer inner product equal to their common weight `2t^2`, contradicting the off-diagonal inner product `t^2` from (2). Thus the row code `U` is projective.

This places the entropy-maximizing exact Hadamard shadow inside a classical code family. The relationship is used as a necessary condition only; no novelty is claimed for the general Hadamard/Type-II correspondence.

## A cubic obstruction beyond Type II

A binary self-dual code cannot be triply even (all weights divisible by eight). A short proof useful for this route is as follows. In a triply-even self-dual code, pair intersections are divisible by four and triple intersections are even. Hence coordinatewise products of codewords are orthogonal to the whole code and therefore stay inside it. Because the code is even and self-dual it also contains the all-one word, making it a unital subalgebra of `F_2^n`. Any such subalgebra is the algebra of functions constant on the blocks of a coordinate partition. If it has dimension `r`, there are `r` block indicators; triply-evenness forces each block size at least eight, so `n>=8r`. Self-duality gives `r=n/2`, an impossibility for nonzero length.

Apply this to (14). If all triple intersections among a generating row basis of `U` were even, then inclusion-exclusion modulo eight, together with (5), would force every word of `U` to have weight divisible by eight. Since `n` is divisible by sixteen, `C_U` would be triply even and self-dual, impossible. Therefore the cubic tensor

\[
\tau_{ijk}=|R_i\cap R_j\cap R_k|\pmod2
\]

is necessarily nonzero for every maximal-rank exact lift:

\[
\boxed{\tau\ne0.}
\tag{16}
\]

So the next layer cannot be obtained by simply imposing triorthogonality; exact lifts require a genuinely nonzero cubic-overlap structure.

**B17 outcome.** Higher-liftability forces a Type-II image-space condition and a nontrivial cubic overlap. The first is classical code geometry with an exact mass formula; the second tells us which tempting divisible-code simplification is impossible.

# Method B28 — count how many entropy-maximizing first shadows survive the code filter

The Lagrangian image choices in `W` are

\[
\boxed{L_m=\prod_{i=1}^{m}(2^i+1).}
\tag{17}
\]

The map `U -> C_U` in (14) is a bijection between these Lagrangians and binary self-dual codes of length `n=2(m+1)`: every binary self-dual code is even, hence contains the all-one vector, and shortening in the last coordinate recovers `U`.

Dougherty's exact Type-II count gives

\[
\boxed{T_m=2\prod_{i=1}^{m-1}(2^i+1).}
\tag{18}
\]

Therefore a uniformly random Lagrangian image passes the necessary Type-II lift filter with exact probability

\[
\boxed{
\frac{T_m}{L_m}=rac{2}{2^m+1}=2^{-m+1+o(1)}.
}
\tag{19}
\]

Equivalently the filter removes

\[
\boxed{
\log_2\frac{L_m}{T_m}
=\log_2\frac{2^m+1}{2}
=m-1+o(1)
}
\tag{20}
\]

bits of entropy.

For each Lagrangian `U`, the maximal-rank symmetric square-zero matrices with that image are parametrized by the same number `h_m` of invertible symmetric `m x m` matrices `S` through `N=XSX^T`. Thus (19) is also the exact survival fraction of the Type-II **image condition** in the whole entropy-maximizing `(U,S)` stratum.

This proves a precise version of the proposed typical-lift statement:

\[
\boxed{
\Pr(\text{a uniformly random maximal first shadow can satisfy the Type-II necessary condition})
=2^{-\Theta(n)}.
}
\tag{21}
\]

But the loss is only linear. The ambient maximal-rank shadow family has quadratic entropy, and multiplying it by `2^{-Theta(n)}` leaves the same leading quadratic exponent. Therefore this layer does **not** yield the `2^{-Omega(n^2)}` rejection needed to force a `2^{o(n^2)}` fixed-spectrum fiber.

**B28 outcome.** A typical entropy-maximizing first shadow indeed does not lift past this necessary condition, but the exact rejection exponent is only linear. This cleanly refutes the hope that the Type-II image restriction alone supplies the missing quadratic entropy loss.
