## 4. Method B10 — DERANDOMIZE: deterministic canonical Stieltjes/Lévy data

### Idea before calculation

Equation (3.1) still mentions stable random variables even though the previous contour inversion removed the self-consistent unknown.  The complete-Bernstein theorem says that `H_beta(z)/z` is a Stieltjes function with a unique positive representing measure.  The useful derandomization is therefore not another stable-density integral: recover that **canonical representing measure directly from the Gamma Mellin transform**.

### 4.1 No affine term in the complete-Bernstein representation

A complete Bernstein function has

\[
H_\beta(z)=a_0+b_0z+z\int_0^\infty\frac{\sigma_\beta(dt)}{z+t}.
\tag{4.1}
\]

Because `H_beta(0+)=0`, `a_0=0`.  Moreover `0<q_beta(a)<=1`, hence

\[
0\le \frac{H_\beta(a)}a
=\frac{a^{\beta-1}q_\beta(a)}{C_\beta}
\le \frac{a^{\beta-1}}{C_\beta}\to0,
\qquad a\to\infty,
\]

so `b_0=0`.  Therefore

\[
\boxed{
\frac{H_\beta(z)}z
=\int_0^\infty\frac{\sigma_\beta(dt)}{z+t}.
}
\tag{4.2}
\]

### 4.2 Mellin transform of the canonical density

Set

\[
g_\beta(a)=\frac{H_\beta(a)}a
=\frac{a^{\beta-1}q_\beta(a)}{C_\beta}.
\tag{4.3}
\]

For `1-beta<Re s<1`, shifting (3.4) gives

\[
\widehat g_\beta(s)
=\frac{c_\beta^{2(s+\beta-1)/\beta}}{C_\beta}
\frac{\Gamma(s+\beta-1)\Gamma((1-s)/\beta)^2}
{\Gamma(2-\beta-s)}.
\tag{4.4}
\]

The Stieltjes kernel has Mellin transform

\[
\int_0^\infty\frac{a^{s-1}}{a+t}\,da
=\frac\pi{\sin\pi s}t^{s-1},
\qquad 0<\Re s<1.
\tag{4.5}
\]

Thus the Mellin transform of the unique representing density is

\[
\boxed{
\widehat\sigma_\beta(s)
=\frac{\sin\pi s}{\pi C_\beta}
 c_\beta^{2(s+\beta-1)/\beta}
\frac{\Gamma(s+\beta-1)\Gamma((1-s)/\beta)^2}
{\Gamma(2-\beta-s)},
}
\tag{4.6}
\]

or, by reflection,

\[
\boxed{
\widehat\sigma_\beta(s)
=\frac{c_\beta^{2(s+\beta-1)/\beta}}{C_\beta}
\frac{\Gamma(s+\beta-1)\Gamma((1-s)/\beta)^2}
{\Gamma(2-\beta-s)\Gamma(s)\Gamma(1-s)},
}
\tag{4.7}
\]

for `1-beta<Re s<1`.

For any `kappa` in that strip,

\[
\boxed{
\sigma_\beta(t)
=\frac1{2\pi i}
\int_{\kappa-i\infty}^{\kappa+i\infty}
\widehat\sigma_\beta(s)t^{-s}\,ds.
}
\tag{4.8}
\]

Stirling on (4.7) yields

\[
|\widehat\sigma_\beta(\kappa+i\tau)|
\le K(1+|\tau|)^m
\exp\{-\pi|\tau|(1/\beta-1)\},
\tag{4.9}
\]

so the inversion is absolutely and locally uniformly convergent.  Inserting it into (4.2), taking Mellin transforms, and using (4.4)–(4.5) reproduces `g_beta`.  Uniqueness of the Stieltjes representing measure identifies this continuous inverse-Mellin density with the positive CBF measure; hence `sigma_beta(t)>=0`.

The final deterministic formula is therefore

\[
\boxed{
H_\beta(z)=z\int_0^\infty\frac{\sigma_\beta(t)}{z+t}\,dt,
}
\tag{4.10}
\]

where `sigma_beta` is defined solely by Gamma functions in (4.7)–(4.8).  The derivatives used later are

\[
H_\beta'(z)
=\int_0^\infty\frac{t\sigma_\beta(t)}{(z+t)^2}\,dt,
\qquad
-H_\beta''(z)
=2\int_0^\infty\frac{t\sigma_\beta(t)}{(z+t)^3}\,dt.
\tag{4.11}
\]

There is also a canonical deterministic Lévy density:

\[
\boxed{
H_\beta(z)=\int_0^\infty(1-e^{-zu})\ell_\beta(u)\,du,
\qquad
\ell_\beta(u)=\int_0^\infty t e^{-tu}\sigma_\beta(t)\,dt,
}
\tag{4.12}
\]

and

\[
\int_0^\infty u^{v-1}\ell_\beta(u)\,du
=\Gamma(v)\widehat\sigma_\beta(2-v),
\qquad1<\Re v<1+\beta.
\tag{4.13}
\]

The Gamma-product Mellin-Barnes form is of Fox-H type for arbitrary beta.  When `beta=p/q` is rational, Gauss multiplication converts the rational slopes to finitely many unit-slope Gamma factors, hence to a finite Meijer-G representation.  Penson–Górska is prior art for the analogous rational-index stable-law phenomenon; the BCC radius-map CBF density itself is the object derived here.

## 5. Method B24 — FIND THE EXTREMAL OBJECT: finite contour and quantitative denominator bounds

### Idea before calculation

The preceding B25 formula took disk contours `|w|=r` to `r->1`.  The root theorem already says there is only one slit-plane preimage.  The extremal object to control is therefore not the unknown root itself but the **smallest symmetric disk contour whose positive-axis endpoints bracket the target**.  Once such a contour exists, the residue theorem gives the inverse exactly; no boundary limit is needed.

### 5.1 Exact finite contour

Use

\[
\chi(w)=\left(\frac{1+w}{1-w}\right)^2,
\qquad
\phi(a)=\frac{\sqrt a-1}{\sqrt a+1}.
\tag{5.1}
\]

For `0<r<1` define

\[
A_-(r)=\left(\frac{1-r}{1+r}\right)^2,
\qquad
A_+(r)=A_-(r)^{-1}.
\tag{5.2}
\]

Fix `x>0`.  If

\[
\boxed{H_\beta(A_-(r))<x<H_\beta(A_+(r)),}
\tag{5.3}
\]

then the unique positive root `a_*=H_beta^{-1}(x)` lies between the endpoints and `w_*=phi(a_*)` lies strictly inside `|w|=r`.  There are no other slit-plane roots.  Hence

\[
\boxed{
w_*=\frac1{2\pi i}\oint_{|w|=r}
 w\frac{H_\beta'(\chi(w))\chi'(w)}
{H_\beta(\chi(w))-x}\,dw.
}
\tag{5.4}
\]

This is an **exact finite contour**.  The former radial-contour truncation error is zero.

No hidden root is needed to choose the contour.  For example take `r_n=1-2^{-n}` and select the first `n` satisfying (5.3).  It exists because `A_-(r_n)->0`, `A_+(r_n)->infinity`, while `H_beta` increases from zero to infinity.

### 5.2 Rigorous nonvanishing certificate

Let

\[
F(w)=H_\beta(\chi(w))-x,
\qquad
c_r=\frac{1-r^2}{1+r^2}.
\tag{5.5}
\]

For `|w|=r`, if `z=chi(w)`, then

\[
|\arg z|\le4\arctan r<\pi,
\qquad |z|\ge A_-(r).
\tag{5.6}
\]

For every `t>=0`,

\[
|z+t|
\ge\cos\left(\frac{|\arg z|}{2}\right)(|z|+t)
\ge c_r(|z|+t).
\tag{5.7}
\]

The deterministic Stieltjes derivative formula therefore yields

\[
|H_\beta'(z)|
\le c_r^{-2}H_\beta'(A_-(r)).
\tag{5.8}
\]

Also

\[
\chi'(w)=\frac{4(1+w)}{(1-w)^3},
\quad
\chi''(w)=\frac{8(2+w)}{(1-w)^4},
\tag{5.9}
\]

so

\[
C_{1,r}=\frac{4(1+r)}{(1-r)^3},
\qquad
C_{2,r}=\frac{8(2+r)}{(1-r)^4}
\tag{5.10}
\]

are valid contour bounds.  Hence

\[
\boxed{
L_r:=\sup_{|w|=r}|F'(w)|
\le C_{1,r}c_r^{-2}H_\beta'(A_-(r)).
}
\tag{5.11}
\]

For the grid `w_k=r exp(2 pi i k/N)` put

\[
d_{r,N}=\min_k|F(w_k)|.
\]

Every circle point is within arc distance at most `pi r/N` of a grid point, so

\[
\boxed{
\delta_{r,N}
:=d_{r,N}-\frac{\pi rL_r}{N}
\le\min_{|w|=r}|F(w)|.
}
\tag{5.12}
\]

Thus `delta_{r,N}>0` is a finite rigorous certificate that the contour denominator never vanishes.

### 5.3 Certified finite quadrature

From (4.11) and (5.7),

\[
|H_\beta''(z)|
\le c_r^{-3}[-H_\beta''(A_-(r))].
\]

Consequently

\[
\boxed{
M_r:=\sup_{|w|=r}|F''(w)|
\le c_r^{-3}[-H_\beta''(A_-)]C_{1,r}^2
+c_r^{-2}H_\beta'(A_-)C_{2,r}.
}
\tag{5.13}
\]

Parameterizing the circle,

\[
w_*=\frac1{2\pi}\int_0^{2\pi}
\frac{w(\theta)^2F'(w(\theta))}{F(w(\theta))}\,d\theta.
\tag{5.14}
\]

The `N`-point discrete average is

\[
Q_N=\frac1N\sum_{k=0}^{N-1}
\frac{w_k^2F'(w_k)}{F(w_k)}.
\tag{5.15}
\]

When `delta=delta_{r,N}>0`, differentiating the integrand gives

\[
\left|\frac d{d\theta}\frac{w^2F'}F\right|
\le
\frac{2r^2L_r}{\delta}
+\frac{r^3M_r}{\delta}
+\frac{r^3L_r^2}{\delta^2}
=:K_{r,N}.
\tag{5.16}
\]

The elementary uniform Riemann-sum bound therefore gives

\[
\boxed{|Q_N-w_*|\le\frac{\pi K_{r,N}}N.}
\tag{5.17}
\]

Every ingredient is now deterministic and certifiable through the exponentially convergent Gamma/Mellin/Stieltjes representation from B10.  This is not merely “run a root solver until it seems stable”: (5.3), (5.12), and (5.17) are explicit mathematical certificates.

\[

\tag{6.2}

\boxed{
w_*(\rho)=\frac{\pi-2Z(\rho)}{\pi+2Z(\rho)}.

\tag{6.3}

\[
\boxed{
H_{1/2}^{-1}(\rho)
=\chi(w_*(\rho))
=\left(\frac\pi{2Z(\rho)}\right)^2.

\tag{6.4}

### 6.2 No algebraic sporadic inverse for any beta in (0,1)

Earlier Mellin-pole work gives

\[
H_\beta(a)=\beta\log a+\eta_\beta+o(1),
\qquad a\to\infty,
\tag{6.5}

with explicit `eta_beta`.  Hence

\[
\boxed{

=\exp\left(\frac{x-\eta_\beta}{\beta}\right)(1+o(1)),

\tag{6.6}

An algebraic function over `C(x)` has a Puiseux expansion at infinity on each branch and therefore only power-law type growth.  The exponential growth in (6.6) is incompatible with algebraicity.  Thus

\[
\boxed{
H_\beta^{-1}\text{ is nonalgebraic for every }0<\beta<1.

\tag{6.7}
\]

This rules out a hidden rational/algebraic exceptional index.  It does **not** prove non-elementarity or non-D-algebraicity.
