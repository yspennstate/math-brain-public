## 7. New diagnostic normal form: exact liftability is a middle-weight shell / pair-sum condition

The first recovery's 2-adic coordinates can now be compressed to one exact combinatorial condition. This is a diagnostic reformulation, not an executed Section-B method and not a novelty claim about the classical Hadamard/code correspondence.

For `a in F_2^m`, define

\[
w_P(a):=\operatorname{wt}(Xa),
\qquad
L_P:=\{a\in\mathbb F_2^m:w_P(a)=m+1\}.
\]

For a pair `(U,S)`, the `i`th row of the binary matrix `X S X^T` is exactly the codeword

\[
X S p_i.
\]

The XOR of rows `i` and `j` is

\[
X S(p_i+p_j).
\]

Because (H) says every row has weight `m+1` and every two distinct rows intersect in `(m+1)/2`, equivalently every two distinct rows have Hamming distance `m+1`, we obtain the exact equivalence

\[
\boxed{
(H)
\iff
w_P(S p_i)=m+1\ \forall i,
\quad
w_P(S(p_i+p_j))=m+1\ \forall i<j.
}
\tag{M}
\]

Define

\[
D(P):=P\cup\{p_i+p_j:i<j\}.
\]

Then (M) is simply

\[
\boxed{S D(P)\subseteq L_P.}
\tag{L}
\]

Since `P` spans `F_2^m`, it contains a basis. The pairwise sums of those basis elements are all distinct, so

\[
\boxed{|D(P)|\ge m+\binom m2=\Theta(m^2).}
\tag{D}
\]

Thus the exact lift really does impose a quadratic number of middle-shell incidences; the difficulty is their very strong dependence, not an absence of constraints.

There is an equivalent Fourier statement. With

\[
\widehat{1_P}(a)=\sum_{j=1}^v(-1)^{a\cdot p_j},
\]

we have

\[
\widehat{1_P}(a)=v-2w_P(a),
\]

and since `v=2m+1`,

\[
\boxed{a\in L_P\iff \widehat{1_P}(a)=-1.}
\tag{F}
\]

Hence exact liftability requires an invertible symmetric linear map `S` to send the quadratic-size set `D(P)` into one particular Fourier level set of the same projective Type-II code.

Finally, if `q_1,...,q_m` is any basis chosen from `P` and `a_i=S q_i`, then (L) forces

\[
a_i\in L_P,
\qquad
a_i+a_j\in L_P\quad(i\ne j).
\tag{C}
\]

The codewords `Xa_i` are therefore `m` linearly independent words of weight `m+1` with every pair at distance `m+1`. After adjoining the standard all-one extension from the preceding Type-II construction, these are a partial Hadamard simplex inside the self-dual code. This is the global structure that the next recovery should count.
