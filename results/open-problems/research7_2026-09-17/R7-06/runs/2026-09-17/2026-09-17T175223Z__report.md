## 3. Exact blocker: the problem is a spectral leakage-versus-coherence inequality

The previous reports treated the two parameter endpoints in different representations. The cleanest diagnosis is to write the exact Fourier comparison that both endpoint arguments are trying to control.

Let

`Lambda = A2`,  `Lambda'=(1/3)Lambda`,  `G=Lambda'/Lambda`,  `|G|=9`,

and let

`omega*=G`

be the standard 9-point subgroup configuration modulo `Lambda`.

For a 9-point configuration `omega={x_1,...,x_9}` on the torus `R^2/Lambda`, define its structure factor

`S_omega(xi) := sum_{j=1}^9 exp(2 pi i <xi,x_j>)`,  `xi in Lambda*`.

For the periodized Gaussian

`F_{a,Lambda}(x)=sum_{v in Lambda} exp(-a |x+v|^2)`, `a>0`,

Poisson summation gives

`F_{a,Lambda}(x)
 = c_a sum_{xi in Lambda*} q_a(xi) exp(2 pi i <xi,x>)`,

where

`c_a = pi/(a area(Lambda)) > 0`,

`q_a(xi)=exp(-pi^2 |xi|^2/a)`.

For the ordered-pair energy with the diagonal omitted,

`E_a(omega)=sum_{i!=j} F_{a,Lambda}(x_i-x_j)`,

the diagonal and zero-frequency pieces cancel in an energy difference, so exactly

`E_a(omega)-E_a(omega*)
 = c_a sum_{xi!=0} q_a(xi)
   ( |S_omega(xi)|^2 - |S_omega*(xi)|^2 ).`                 (3.1)

Because `omega*=G` is a finite subgroup, character orthogonality gives the exact annihilator pattern

`S_omega*(xi)=9` if `xi in 3 Lambda*`,

`S_omega*(xi)=0` if `xi notin 3 Lambda*`.

Hence (3.1) becomes

`[E_a(omega)-E_a(omega*)]/c_a
 = L_a(omega) - C_a(omega)`,                                  (3.2)

where

`L_a(omega)
 := sum_{xi in Lambda* \ 3Lambda*} q_a(xi) |S_omega(xi)|^2`

is the positive **off-annihilator spectral leakage**, and

`C_a(omega)
 := sum_{0!=xi in 3Lambda*} q_a(xi)
       (81-|S_omega(xi)|^2)`

is the potentially negative **loss of subgroup coherence** on annihilator modes.

Therefore 9-point Gaussian optimality is exactly the assertion

`L_a(omega) >= C_a(omega)`                                      (3.3)

for every `a>0` and every 9-point configuration `omega` modulo `A2`.

Equation (3.3) is the exact blocking formula. The current repository does not have a parameter-uniform mechanism proving it.

### Why this formula explains the two endpoint proofs

For `a -> 0`, the weights `q_a(xi)` have a strong reciprocal-space shell hierarchy. Moving away from the subgroup forces leakage into low non-annihilator modes before the first annihilator shell can recover comparable weight. The repaired `P_{3,3}` witness and its strict residual encode precisely this regime.

For `a -> infinity`, the number of Fourier modes carrying nonnegligible weight diverges; (3.2) is no longer a uniformly finite-shell comparison. Termwise passage to the endpoint is therefore the wrong compactification. The previous run had to switch to direct space, where circle packing, contact rigidity and first-shell Hessian dominance control the energy.

The stuck point is not that either endpoint argument is weak. It is that they measure different manifestations of the same defect and there is currently no quantitative theorem transferring one defect measure into the other across a fixed compact interval of `a`.

## 6. Simplest unresolved case: move one point and keep the other eight fixed

The simplest nontrivial test of the missing stability principle is much smaller than the full 18-dimensional torus configuration space.

Let

`omega_x := (G \ {0}) union {x}`,

where one subgroup point is moved from `0` to an arbitrary `x in R^2/Lambda` and the other eight subgroup points remain fixed.

Only the ordered interactions involving the moved point change. Using the coset identity

`sum_{g in G} F_{a,Lambda}(x-g) = F_{a,Lambda'}(x)`,

one obtains exactly

`[E_a(omega_x)-E_a(omega*)]/2
 = [F_{a,Lambda'}(x)-F_{a,Lambda}(x)]
   -[F_{a,Lambda'}(0)-F_{a,Lambda}(0)]`.                        (6.1)

Define the theta/heat-kernel deficit

`D_{Gamma,a}(x):=F_{a,Gamma}(0)-F_{a,Gamma}(x)`.

Then (6.1) is

`[E_a(omega_x)-E_a(omega*)]/2
 = D_{Lambda,a}(x)-D_{Lambda',a}(x)`.                           (6.2)

Thus even this one-point family asks for the parameter-uniform inequality

`D_{A2,a}(x) >= D_{(1/3)A2,a}(x)`                              (6.3)

for all `a>0` and all `x` modulo `A2`.

In Fourier form, after separating the nine cosets of `3Lambda*` in `Lambda*`, (6.3) is exactly

`sum_{xi in Lambda* \ 3Lambda*}
   q_a(xi) [1-cos(2 pi <xi,x>)]
 >= 8 sum_{0!=xi in 3Lambda*}
   q_a(xi) [1-cos(2 pi <xi,x>)]`.                              (6.4)

This is the simplest unresolved case selected by the diagnosis. It is fully explicit, has no optimization over nine independent points, and still contains the characteristic factor `8` that already appeared in the repaired leading-shell coefficient. A violation of (6.3) would give an explicit one-point Gaussian competitor to `omega*_9`; a proof would produce the first parameter-uniform nonlocal defect inequality available to this track.
