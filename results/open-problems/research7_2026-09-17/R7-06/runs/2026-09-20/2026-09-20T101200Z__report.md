## 1. Exact source and inherited bottleneck

Van H. Vu, *Recent progress in combinatorial random matrix theory*, Probability Surveys 18 (2021), Conjecture 9.4, arXiv `2005.02797`, DOI `10.1214/20-PS346`.

For the symmetric Rademacher matrix `M_n^sym`, with independent fair signs on and above the diagonal and lower triangle filled by symmetry,

\[
\boxed{
\Pr\bigl(\operatorname{Spec}(M_n^{\rm sym})\subset\mathbb Z\bigr)
=2^{-(1/2+o(1))n^2}.
}
\tag{1.1}
\]

Equivalently, the total number of labelled symmetric sign matrices with integral spectrum is `2^{o(n^2)}`. The source quantifier is over the total integral-spectrum event; it does not fix the spectrum. The current C05 line is only a restricted fixed two-eigenvalue bridge.

The active family is

\[
H=H^T\in\{\pm1\}^{N\times N},\qquad H^2=NI,
\qquad N=2r,
\]

with balanced cut

\[
H=\begin{pmatrix}P&C\\C^T&D\end{pmatrix}.
\]

The preceding run proved that the semidefinite arithmetic shells `|delta|<=4`, where

\[
CC^T=\lambda I+R,\qquad \delta=r-\lambda,
\]

have only `2^{o(r^2)}` possible **Gram skeletons**. At `|delta|=4`, every shell point of rank `q>4` is, after switching/permutation, in the one-parity branch

\[
\boxed{
CC^T=(r-4\varepsilon)I+4\varepsilon BB^T,
\qquad \varepsilon\in\{+1,-1\},
}
\tag{1.2}
\]

where `B` is the membership matrix of a partition of `[r]` into `q` nonempty blocks. The missing theorem was a root-fiber reduction: fixing this row Gram still left potentially quadratically many sign roots `C`.

This run attacks that exact gap. Assume `r>12`, `q>4`, and the inherited entropy-dangerous regime `q=o(r)`. No invertibility of `C` is assumed.

## 2. New theorem I — the row block Gram forces a matching column block Gram

Let

\[
K_L=CC^T,\qquad K_R=C^TC,
\qquad \lambda=r-4\varepsilon.
\]

The square Gram matrices have identical eigenvalues. Since

\[
K_L-\lambda I=4\varepsilon BB^T
\]

is semidefinite of sign `epsilon`, rank `q`, and constant diagonal `4 epsilon`, the same is true spectrally for `K_R-lambda I`; its diagonal is also `4 epsilon` because every sign column has norm squared `r`.

Applying the already proved `|delta|=4` shell classification to the column Gram shows that the rank-`q>4` case cannot be its two-parity rank-four branch. Therefore, after independent column switching/permutation,

\[
\boxed{
C^TC=(r-4\varepsilon)I+4\varepsilon B'B'^T
}
\tag{2.1}
\]

for a column partition with exactly `q` blocks.

A row block of size `a` contributes the exceptional Gram eigenvalue

\[
\mu_a=r+4\varepsilon(a-1).
\tag{2.2}
\]

The map `a -> mu_a` is injective, and `K_L,K_R` have the same spectrum. Hence the row and column block-size multisets agree exactly:

\[
\boxed{
\{|G_i|\}_{\rm multi}=\{|H_j|\}_{\rm multi}.
}
\tag{2.3}
\]

This includes the negative-shell singular endpoint `mu_a=0`; no inverse is used.

## 3. New theorem II — exact equitable quotient and a block-size parity rigidity

Let `U,V` have as columns the normalized row/column block indicators. The intertwining identity

\[
(CC^T)C=C(C^TC)
\tag{3.1}
\]

forces `C` to map each column exceptional eigenspace to the equal-eigenvalue row eigenspace. Thus the quotient

\[
M=U^TCV
\]

is block diagonal by block size:

\[
\boxed{M=\bigoplus_aM_a,\qquad M_a^TM_a=M_aM_a^T=\mu_aI.}
\tag{3.2}
\]

For row/column groups `G,H` of the same size `a`, every row and every column of the sign submatrix `C[G,H]` has the same sum, namely the corresponding quotient entry. Consequently

\[
\boxed{
M_a\in\mathbb Z^{m_a\times m_a},\qquad
|M_{G,H}|\le a,\qquad M_{G,H}\equiv a\pmod2.
}
\tag{3.3}
\]

If instead `|G| ne |H|`, spectral support is disjoint and the whole rectangular block is exactly balanced in both directions:

\[
\boxed{
C[G,H]\mathbf1=0,
\qquad
\mathbf1^TC[G,H]=0.
}
\tag{3.4}
\]

A sign row or column of odd length cannot sum to zero. Therefore

\[
\boxed{
\text{if two distinct block sizes occur, every occurring block size is even.}
}
\tag{3.5}
\]

Equivalently, the presence of any odd block size forces the whole partition to be uniform. This is a root-level rigidity not visible from the row Gram skeleton alone.

## 4. New theorem III — all outer root data already have subquadratic entropy

The two signed labelled partitions contribute at most

\[
q^{2r}2^{2r}=2^{O(r\log q+r)}=2^{o(r^2)}
\]

possibilities when `q=o(r)`.

For fixed size profile, crude entrywise counting of (3.3) gives

\[
\log_2\#\{M\}
\le\sum_a m_a^2\log_2(2a+1).
\]

Since `m_a<=q` and `sum_a m_a a=r`, concavity gives

\[
\boxed{
\log_2\#\{M\}
\le q^2\log_2\left(\frac{2r}{q}+1\right)
=o(r^2).
}
\tag{4.1}
\]

Therefore all partition, switching, and quotient choices together are already at the entropy scale required by Vu. Any remaining quadratic root entropy has to reside in the residual operator.

## 5. New theorem IV — exact residual scaled isometry

Put

\[
Z=C-UMV^T.
\]

Then

\[
\boxed{ZV=0,\qquad U^TZ=0,}
\tag{5.1}
\]

and the scalar covariance on the complementary spectral subspaces gives

\[
\boxed{
ZZ^T=\lambda(I-UU^T),
\qquad
Z^TZ=\lambda(I-VV^T).
}
\tag{5.2}
\]

Thus after removing only the `q` block-constant modes, the remaining `(r-q)`-dimensional operator is an exact scaled isometry. In the negative shell, possible zero singular directions occur only in the quotient; `lambda=r+4>0` on the residual. Hence the singular/corank endpoint is not excluded.

## 6. New theorem V — injective ternary-core compression

Choose, in each row partition block, an anchor and the integer contrast basis

\[
e_g-e_{g_0}.
\]

Let `F in Z^{r x d}`, `d=r-q`, collect these row contrasts, and let `E` be the analogous column contrast basis. Their metric matrices are

\[
G_{\mathcal G}=F^TF
=\bigoplus_{G\in\mathcal G}(I_{|G|-1}+J_{|G|-1}),
\tag{6.1}
\]

\[
G_{\mathcal H}=E^TE
=\bigoplus_{H\in\mathcal H}(I_{|H|-1}+J_{|H|-1}).
\tag{6.2}
\]

Because `C` maps the column zero-sum lattice into the row zero-sum lattice, there is a unique integer coordinate matrix `A` with

\[
CE=FA.
\tag{6.3}
\]

Each column of `CE` is the difference of two sign columns, so every coordinate in the anchor-difference basis belongs to `{-2,0,2}`. Thus

\[
A=2T,
\qquad
\boxed{T\in\{-1,0,1\}^{d\times d}.}
\tag{6.4}
\]

Since `E` lies in the `lambda` eigenspace of `C^TC`,

\[
(CE)^T(CE)=\lambda E^TE.
\]

Substituting (6.3)-(6.4) yields the exact generalized-orthogonality equation

\[
\boxed{
T^TG_{\mathcal G}T
=\left(\frac r4-\varepsilon\right)G_{\mathcal H}.
}
\tag{6.5}
\]

Because the row and column block-size multisets agree, the two metric determinants agree. Therefore

\[
\boxed{
|\det T|
=\left(\frac r4-\varepsilon\right)^{(r-q)/2}.
}
\tag{6.6}
\]

In particular, if `r-q` is odd, then `r/4-epsilon` must be a perfect square. Since `r` is even, this gives the arithmetic obstruction

\[
\boxed{
q\text{ odd}\Longrightarrow \frac r4-\varepsilon\text{ is a square}.
}
\tag{6.7}
\]

Finally, for fixed signed partitions and quotient `M`, `C` is uniquely reconstructed from

\[
CV=UM,
\qquad
CE=2FT,
\]

because `span(V) direct-sum span(E)=R^r`. Hence the map from sign roots into the ternary cores (6.5) is injective once the already-subquadratic outer data are fixed.

This is the principal advance of the run: the old fixed-Gram root-fiber problem has been reduced, with only `2^{o(r^2)}` overhead, to a **fixed-alphabet ternary metric-isometry count** in dimension `r-q=(1-o(1))r`.

For every size class,

Therefore

\boxed{m_a\text{ odd}\Longrightarrow \mu_a=r+4\varepsilon(a-1)\text{ is a perfect square}.}

## 8. What the theorem resolves and what remains open

The previous intermediate idea that a low-shell root might be controlled just by a one-sided Gram partition is false as a complete description. A root automatically carries a matched column partition, an integer equitable quotient, and a large residual metric isometry. The right object is therefore intrinsically two-sided.

The new result does **not** prove `2^{o(r^2)}` roots. The dimension of the ternary core remains `(1-o(1))r`. The exact next theorem needed is a subquadratic count, or a contracting recursive decomposition, for

\[
\boxed{
T\in\{-1,0,1\}^{d\times d},
\qquad
T^TG_{\mathcal G}T=sG_{\mathcal H},
\qquad
s=r/4-\varepsilon,
}
\tag{8.1}
\]

subject to the sign-reconstruction constraint.

The bounded-rank `q<=4` branch still contains classical Hadamard, D-optimal/Ehlich--Wojtas, and rank-four two-cloud fibers and is not being silently discarded. Higher shells, indefinite low-rank defects, and general integral spectra remain outside this theorem.
