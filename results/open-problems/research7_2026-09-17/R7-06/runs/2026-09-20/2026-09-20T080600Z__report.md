## 2. New theorem A — an exact mod-4 skeleton for every even sign Gram matrix

Let `C in {+-1}^{r x r}` with `r` even and let `K=CC^T`. Encode row `i` by `b_i in {0,1}^r`, where `b_{ij}=1` exactly when `C_{ij}=-1`, and put

\[
w_i=|b_i|\pmod2.
\]

Then

\[
K_{ij}
=r-2|b_i|-2|b_j|+4\langle b_i,b_j\rangle.
\tag{2.1}
\]

Since `r` is even, `K/2` is integral. Reducing (2.1) modulo two yields

\[
\boxed{
\frac K2
\equiv
\left(\frac r2\bmod2\right)J
+w\mathbf1^T+\mathbf1w^T
\pmod2.
}
\tag{2.2}
\]

The right side has column space contained in `span{1,w}`, hence

\[
\boxed{
\operatorname{rank}_{\mathbb F_2}(K/2)\le2.
}
\tag{2.3}
\]

Now suppose `R=K-lambda I`, with `lambda` even and `q=rank_R R`. If `lambda=2 mod 4`, then over `F_2`

\[
R/2=I+L,
\qquad \operatorname{rank}L\le2,
\]

so

\[
\operatorname{rank}_{\mathbb F_2}(R/2)\ge r-2.
\]

For an integer matrix, rank modulo two cannot exceed rational rank because every nonzero mod-two minor is an odd, hence nonzero, integer minor. Therefore

\[
\boxed{
\lambda\equiv2\pmod4
\Longrightarrow
q\ge r-2.
}
\tag{2.4}
\]

Equivalently,

\[
\boxed{
q<r-2
\Longrightarrow
\lambda\equiv0\pmod4.
}
\tag{2.5}
\]

Since the inherited dangerous branch has `q=o(r)`, it follows eventually that

\[
\boxed{\lambda\in4\mathbb Z.}
\tag{2.6}
\]

This is strictly stronger than the preceding evenness theorem and uses neither invertibility nor a spectral-gap assumption.

## 3. New theorem B — defect one cannot occur

Assume `q=1`. By (2.5), `lambda` is a multiple of four. The inherited localization gives

\[
|r-\lambda|\le\frac r{r-1}<2.
\tag{3.1}
\]

If `r=2 mod 4`, the distance from `r` to `4Z` is two, contradicting (3.1). If `r=0 mod 4`, then (3.1) forces `lambda=r`; therefore `R=K-rI` is a symmetric rank-one matrix with zero diagonal. Every real symmetric rank-one matrix is `sigma vv^T`, whose diagonal is `sigma v_i^2`; zero diagonal forces `R=0`, contradicting rank one.

Hence

\[
\boxed{q=1\text{ is impossible}.}
\tag{3.2}
\]

The first genuinely non-Hadamard low-rank layer is therefore `q=2`.

## 4. New theorem C — exact classification of defect two

Assume `q=2` and `r>=6`. Again `lambda in 4Z`, while

\[
|r-\lambda|\le\frac{2r}{r-2}<4.
\tag{4.1}
\]

Let

\[
\delta:=r-\lambda=R_{ii}.
\tag{4.2}
\]

### 4.1. The `r=0 mod 4` branch

Then `delta=0`. Thus `R` is symmetric rank two with zero diagonal. Since `tr R=0`, its two nonzero eigenvalues have opposite signs. Therefore one may write

\[
R=xy^T+yx^T
\tag{4.3}
\]

for linearly independent vectors `x,y`. The diagonal condition gives `x_i y_i=0` for every coordinate. Partition coordinates into

- `A={i:x_i!=0,y_i=0}`,
- `B={i:x_i=0,y_i!=0}`,
- `Z={i:x_i=y_i=0}`.

After simultaneous permutation,

\[
\boxed{
R=
\begin{pmatrix}
0&X&0\\
X^T&0&0\\
0&0&0
\end{pmatrix},
\qquad \operatorname{rank}X=1.
}
\tag{4.4}
\]

Because `R=CC^T-rI` and `r` is even, every off-diagonal entry is even, so `X` is an even integer matrix. Thus the rows of `C` split into two internally orthogonal families, with all nonzero cross-correlations factoring through one rank-one matrix.

If `sigma` is the unique singular value of `X`, then the two nonzero eigenvalues of `R` are `+-sigma`, hence

\[
\det K=r^{r-2}(r^2-\sigma^2)=\det(C)^2.
\tag{4.5}
\]

Since `r-2` is even, `r^{r-2}` is an integer square. Therefore

\[
\boxed{r^2-\sigma^2=d^2}
\tag{4.6}
\]

for an integer `d>=0`. The defect lies on an integral Pythagorean shell.

### 4.2. The `r=2 mod 4` branch

Now `delta=2 mod 4`, so (4.1) forces

\[
\boxed{\delta\in\{-2,+2\}.}
\tag{4.7}
\]

Let `alpha,beta` be the two nonzero eigenvalues of `R`.

If `delta=+2`, then `lambda=r-2` and `alpha+beta=2r`. Since `0<=K<=2rI`, every defect eigenvalue belongs to `[-(r-2),r+2]`. One nonpositive eigenvalue would force the other to be at least `2r>r+2`, so `R` is positive semidefinite.

If `delta=-2`, then `lambda=r+2` and `alpha+beta=-2r`; the same interval argument shows both are negative, so `-R` is positive semidefinite.

In either case, put `S=+-R/2` with the sign chosen so `S` is PSD. Then `S` is integer, PSD, rank two and has diagonal one. Cauchy--Schwarz gives `|S_ij|<=1`, so all entries are in `{-1,0,1}`. Writing `S=XX^T` with unit rows in `R^2`, every two rows are equal, opposite or orthogonal. After individual row sign switches and a permutation, the rows are copies of two orthogonal unit vectors. Therefore, for a partition of `[r]` into two nonempty blocks of sizes `a,b`, `a+b=r`,

\[
\boxed{R=+2\,\operatorname{diag}(J_a,J_b)}
\tag{4.8}
\]

in the `delta=+2` case, and

\[
\boxed{R=-2\,\operatorname{diag}(J_a,J_b)}
\tag{4.9}
\]

in the `delta=-2` case, up to simultaneous signed permutation.

For `delta=+2`, positivity of the complementary block equation `P^2=2rI-K` gives `a,b<=r/2+1`. Write `a=r/2+s`, `b=r/2-s`, `s in {-1,0,1}`. Then

\[
\det K=(r-2)^{r-2}4\bigl((r-1)^2-s^2\bigr).
\tag{4.10}
\]

Because `det K=det(C)^2` and `(r-2)^{r-2}` is a square, `(r-1)^2-s^2` must be a square. If `|s|=1`, this is `r(r-2)=4u(u-1)` for `r=2u`; since consecutive coprime integers have square product only when both are squares, and consecutive integer squares differ by more than one except `0,1`, this is impossible for `r>=6`. Hence `s=0` and

\[
\boxed{a=b=r/2.}
\tag{4.11}
\]

For `delta=-2`, positivity of `K=(r+2)I-2diag(J_a,J_b)` gives `a,b<=r/2+1`, and with `a+b=r` this is precisely

\[
\boxed{|a-b|\le2.}
\tag{4.12}
\]

This branch explicitly retains the singular endpoint: when the larger block has size `r/2+1`, one exceptional Gram eigenvalue is zero.

## 6. Gram-skeleton entropy for `q<=2`

The family of possible defect-two Gram matrices has only subquadratic description complexity.

- If `r=0 mod 4`, choose the partition `A,B,Z` in at most `3^r` ways. The rank-one integer matrix `X`, with entries bounded by `r`, is determined by one nonzero row, one nonzero column and a pivot, hence by `O(r log r)` bits.
- If `r=2 mod 4`, the two-block form is specified by a bipartition and switching data, hence by `O(r)` bits.

Therefore

\[
\boxed{
\#\{K=CC^T:\operatorname{rank}(K-\lambda I)\le2\}
=2^{O(r\log r)}.
}
\tag{6.1}
\]

This is a Gram-skeleton count only. It does **not** yet bound the sign roots inside one Gram fiber. At `q=0` the fiber contains ordinary Hadamard matrices; at `q=2,+2` it contains saturated D-optimal designs. Those root-fiber entropies are the real remaining obstruction.
