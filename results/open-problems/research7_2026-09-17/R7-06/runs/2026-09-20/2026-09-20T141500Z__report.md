## 1. Exact source and inherited obstruction

Van H. Vu, *Recent progress in combinatorial random matrix theory*, Probability Surveys 18 (2021), Conjecture 9.4, Section 9 / PDF p. 15; arXiv `2005.02797`; DOI `10.1214/20-PS346`.

For the symmetric Rademacher matrix `M_n^sym`, with independent fair signs on and above the diagonal and symmetry below it,

\[
\boxed{
\Pr\bigl(\operatorname{Spec}(M_n^{\rm sym})\subset\mathbb Z\bigr)
=2^{-(1/2+o(1))n^2}.
}
\]

Equivalently, the total number of labelled symmetric sign matrices with integral spectrum should be `2^{o(n^2)}`. The source statement is a total-spectrum event; it does **not** fix a spectrum. The current C05 line remains a restricted centered two-eigenvalue bridge and is not source closure.

The inherited entropy-dangerous branch is the `|r-lambda|=4`, `q=o(r)`, `q>4` shell. After the two-sided quotient and contrast reduction, it has ternary inverse cores

\[
T,S\in\{-1,0,1\}^{d\times d},
\qquad TS=ST=sI,
\qquad d=r-q,
\qquad s=\frac r4-\varepsilon>0,
\]

with

\[
D:=T-S^T,
\qquad \operatorname{rank}_{\mathbb R}D=o(r).
\]

The preceding two C05 runs sharpened this to a single binary support system and proved that the common-support complement is an exact `s`-regular bipartite graph. One perfect-matching normalization permits `diag D=0` at only subquadratic entropy cost. The latest report then showed that a **pure mod-two** attack cannot finish the problem: a fixed rank-two, zero-diagonal, half-dense defect

\[
E=\begin{pmatrix}0&J_m\\J_m&0\end{pmatrix}
\]

has at least `2^{d^2/2-O(d)}` solutions to `X+X^{-T}=E` over `F_2`, generated by a symplectic group. That is an obstruction only to the proposed finite-field reduction, not to the integer sign-Gram shell and not to Vu's conjecture.

This run restores the exact integer equations on that rank-two support.

## 2. New theorem A — rank-two complete-bipartite defect forces a two-class equitable quotient

Assume `d=2m` and, after the inherited perfect-matching normalization,

\[
D=\begin{pmatrix}0&P\\Q&0\end{pmatrix},
\qquad P,Q\in\{\pm1\}^{m\times m},
\qquad \operatorname{rank}_{\mathbb R}D=2.
\]

The two off-diagonal blocks live on disjoint row and column halves, so

\[
\operatorname{rank}D=\operatorname{rank}P+\operatorname{rank}Q.
\]

Both are nonzero, hence each has rank one. After diagonal row/column sign equivalence preserving `TS=ST=sI`, the defect becomes

\[
\boxed{
D=\begin{pmatrix}0&J_m\\J_m&0\end{pmatrix}.
}
\]

Write

\[
T=\begin{pmatrix}A&B\\C&F\end{pmatrix}.
\]

Since `S=(T-D)^T`, the inverse equations give

\[
TT^T-TD=sI,
\qquad
T^TT-DT=sI.
\]

Symmetry of the two Gram matrices forces `TD` and `DT` to be symmetric. It follows that every block has constant row and column sums:

\[
A\mathbf1=F\mathbf1=\alpha\mathbf1,
\qquad
B\mathbf1=\beta\mathbf1,
\qquad
C\mathbf1=\gamma\mathbf1,
\]

and the same equations on columns. In the inherited binary-support normalization,

\[
B,C\in\{0,1\}^{m\times m},
\qquad 0\le\beta,\gamma\le m.
\]

Thus the huge finite-field symplectic orientation space collapses over the integers to an exact two-class equitable system before any counting estimate is applied.

## 3. New theorem B — Pythagorean quotient and subpolynomial quotient entropy

On the two-dimensional block-constant subspace, the quotient matrices are

\[
Q_T=
\begin{pmatrix}
\alpha&\beta\\
\gamma&\alpha
\end{pmatrix},
\qquad
Q_S=
\begin{pmatrix}
\alpha&\gamma-m\\
\beta-m&\alpha
\end{pmatrix}.
\]

Since `Q_TQ_S=sI_2`, the off-diagonal equations and the difference of the diagonal equations yield

\[
\boxed{\beta+\gamma=m.}
\]

The remaining diagonal equation is

\[
\boxed{\alpha^2=s+\beta\gamma.}
\]

Writing `delta=beta-gamma` gives the exact arithmetic shell

\[
\boxed{
\delta^2+(2\alpha)^2=m^2+4s,
\qquad
\delta\equiv m\pmod2.
}
\]

Hence the possible quotient triples are bounded by the sum-of-two-squares representation count:

\[
\boxed{
\#\{(\alpha,\beta,\gamma)\}
\le r_2(m^2+4s)
\le4\tau(m^2+4s)
=m^{o(1)}.
}
\]

Therefore the source-scale `2^{Theta(d^2)}` symplectic freedom of the mod-two shadow cannot survive in the quotient. Any remaining quadratic entropy has to live in a fixed interior group-divisible fiber.

## 4. New theorem C — exact group-divisible Gram system

The full Gram identities become

\[
\boxed{
TT^T=sI+
\begin{pmatrix}
\beta J&\alpha J\\
\alpha J&\gamma J
\end{pmatrix},
}
\]

\[
\boxed{
T^TT=sI+
\begin{pmatrix}
\gamma J&\alpha J\\
\alpha J&\beta J
\end{pmatrix}.
}
\]

Equivalently,

\[
AA^T+BB^T=sI+\beta J,
\qquad
CC^T+FF^T=sI+\gamma J,
\]

\[
AC^T+BF^T=\alpha J,
\]

and on the column side

\[
A^TA+C^TC=sI+\gamma J,
\qquad
B^TB+F^TF=sI+\beta J,
\]

\[
A^TB+C^TF=\alpha J.
\]

Thus all non-flat covariance information is compressed into a two-dimensional quotient. On

\[
\mathbf1^\perp\oplus\mathbf1^\perp,
\]

`T` is exactly a `sqrt(s)`-scaled isometry. The correct integer object is therefore a two-class group-divisible / weighing-type design, not an arbitrary element of the symplectic group seen modulo two.

## 5. Failed intermediate theorem, now sharpened — abstract integer equations still contain weighing recursion

The endpoint `beta=0` forces

\[
\gamma=m,
\qquad B=0,
\qquad C=J,
\qquad \alpha^2=s.
\]

Then

\[
AA^T=A^TA=sI,
\qquad
FF^T=F^TF=sI.
\]

So `A` and `F` are regular weighing matrices `W(m,s)` with row and column sum `alpha=+-sqrt(s)`. Conversely, any two such regular weighing matrices construct a valid abstract ternary inverse pair with the same dense rank-two defect. The transposed endpoint `beta=m,gamma=0` is analogous.

Therefore the statement

> low real rank + exact integer biorthogonality should itself imply a subquadratic root fiber

is false as an intermediate reduction unless one separately controls the weighing-matrix recursion. This is the integer analogue of the lesson from the previous finite-field counterfamily.

The actual C05 sign-root geometry, however, has additional anchor coherence. That extra structure excludes the endpoint asymptotically.

## 6. New theorem D — the actual C05 anchor geometry excludes the weighing endpoint for `q=o(r)`

The original contrast core inherits `q` row-partition and `q` column-partition labels and anchor masks

\[
U_{g,h}=C_{g_i,h},
\qquad
V_{g,h}=C_{g,h_j},
\qquad
D=(U-V)/2.
\]

Refining every inherited row and column block by the two defect halves gives at most `2q` refined classes in each half. On an `E=0` product of one refined row class and one refined column class, `U=V` throughout the whole Cartesian product. Because `U` is generated from a row anchor and `V` from a column anchor, this forces the common sign pattern on that product to be separable after the same row/column switching used to normalize the rank-one off-diagonal defects.

At the endpoint, the top-left block `A` is a weighing matrix `W(m,s)`. Two distinct rows in one refined row class therefore have inner product equal, up to one common sign, to the size of their support intersection. Orthogonality forces their supports to be disjoint. Since every row support has size exactly `s` among `m` columns, each refined class has at most

\[
\left\lfloor\frac ms\right\rfloor
\]

rows. At most `2q` refined classes cover the `m` rows of a half, so

\[
\boxed{
m\le2q\left\lfloor\frac ms\right\rfloor.}
\]

In the inherited shell,

\[
m=\frac{r-q}{2},
\qquad
s=\frac r4-\varepsilon.
\]

For `r+2q>12`, one has `m<3s`, hence `floor(m/s)<=2` whenever the endpoint exists. Therefore

\[
\boxed{m\le4q}
\qquad\Longrightarrow\qquad
\boxed{q\ge r/9.}
\]

The entropy-dangerous branch has `q=o(r)`. Thus, for all sufficiently large inherited instances,

\[
\boxed{0<\beta,\gamma<m.}
\]

This is the main progress of the run: the obvious regular-weighing recursion exists in the abstract integer core but is incompatible with the actual source-specific anchor geometry in the near-extremal branch. The previous symplectic obstruction is therefore narrowed to **interior** two-class group-divisible fibers with only `m^{o(1)}` possible quotient triples.

The singular/corank endpoint of the original sign cross-block remains included. None of the argument in this report inverts that original block; it operates inside the already singular-safe contrast-core reduction.
