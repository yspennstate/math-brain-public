## 1. Exact outside source and inherited claim

Van H. Vu, *Recent progress in combinatorial random matrix theory*, Probability Surveys 18 (2021), Conjecture 9.4, Section 9 / PDF p. 15; arXiv `2005.02797`; DOI `10.1214/20-PS346`.

For the symmetric Rademacher matrix `M_n^sym`, with independent fair signs on and above the diagonal,

\[
\boxed{
\Pr\bigl(\operatorname{Spec}(M_n^{\rm sym})\subset\mathbb Z\bigr)
=2^{-(1/2+o(1))n^2}.
}
\]

Equivalently, the total number of labelled symmetric sign matrices with integral spectrum should be `2^{o(n^2)}`. The source quantifier is the total integral-spectrum event, not a fixed spectrum. C05 remains a restricted centered two-eigenvalue bridge and does not close the source conjecture.

The immediately inherited theorem identified refined anchor classes as punctured partial Hadamards, proved square-dimension contraction when `q -> infinity`, and reduced the unique zero-minority rank-two branch to

\[
\varepsilon=+1,\qquad q=6,
\]

with a two-row/two-column completion to a Hadamard matrix of order `r-4`. The unresolved question was whether that completion actually decreases entropy or merely changes normalization.

## 2. New theorem — the q=6 zero-minority *normalized contrast core* is Hadamard enumeration in disguise

Put

\[
2m=r-6,
\qquad
N=2m+2=r-4,
\qquad
s=(m+1)/2.
\]

In this branch, after the inherited signed/permutation normalization, the contrast core is binary:

\[
T=X=\begin{pmatrix}A&B\\C&F\end{pmatrix}.
\]

Its quotient parameters are

\[
\beta=s,\qquad \gamma=s-1,\qquad \alpha=s.
\]

The exact row/column Gram equations and block regularity are

\[
XX^T
=sI+
\begin{pmatrix}
sJ&sJ\\sJ&(s-1)J
\end{pmatrix},
\]

\[
X^TX
=sI+
\begin{pmatrix}
(s-1)J&sJ\\sJ&sJ
\end{pmatrix},
\]

with row sums `s,s,s-1,s` on `(A,B,C,F)` and the transposed block-degree statement. Let `C_m` be this normalized core family.

Define

\[
K_0=J_{2m}-2X.
\]

Adjoin two columns `(c,d)` with tails `(1,1)` on the top `m` rows and `(1,-1)` on the bottom `m` rows. Adjoin an all-ones row `a` and a second row `b` with signs

\[
(+1,-1,-\mathbf1_m,+\mathbf1_m)
\]

on `(c,d,C_-,C_+)`.

A direct inner-product calculation gives

\[
\boxed{K(X)K(X)^T=NI_N.}
\]

Thus every `X in C_m` completes canonically and injectively to a Hadamard matrix of order `N`.

The reverse direction is also exact. Given any Hadamard matrix of order `N`, switch rows/columns so that a chosen row `a` and column `c` are all `+1`; choose a second row `b` and a column `d` with the canonical corner

\[
\begin{pmatrix}1&1\\1&-1\end{pmatrix}.
\]

Delete `a,b,c,d`. Split the remaining rows by their sign in column `d` and the remaining columns by their sign in row `b`. Each class has size exactly `m`. If `K_0` is the resulting punctured matrix, then

\[
X=(J-K_0)/2
\]

has exactly the q=6 core block degrees and Gram equations above. Therefore every Hadamard equivalence orbit contains a normalized core.

Since the signed row/column permutation group has size at most

\[
2^{2N}(N!)^2=2^{O(N\log N)},
\]

we obtain the two-sided count

\[
\boxed{
\frac{H(N)}{2^{2N}(N!)^2}
\le |C_m|
\le H(N).
}
\]

Hence

\[
\boxed{
\log_2|C_m|=\log_2 H(N)+O(N\log N)
}
\]

at the quadratic entropy scale.

## 3. Why this is mathematically important

The preceding run only showed a one-way upper reduction to Hadamard enumeration. This run proves the reverse puncturing theorem as well. Therefore the relaxed normalized core problem is **Hadamard-hard at the exact entropy scale of interest**.

In particular, a `2^{o(r^2)}` theorem based only on the normalized core equations `TS=ST=sI` would already imply, up to subquadratic normalization factors, the open square-Hadamard enumeration bound

\[
H(N)=2^{o(N^2)}.
\]

So the bounded-q strategy cannot keep trying to count the relaxed contrast core in isolation. The source-specific lift/anchor equations must be used, or one must genuinely solve the corresponding Hadamard-counting problem.

This is an explicit counterexample to the proposed intermediate principle that finite-codimension completion by itself yields a useful entropy contraction. Adding/removing two rows and two columns can preserve the full leading quadratic entropy.

That lift compatibility is exactly the information discarded by the relaxed core reduction.
