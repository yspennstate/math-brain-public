## 1. Exact source and inherited claim

Van H. Vu, *Recent progress in combinatorial random matrix theory*, Probability Surveys 18 (2021), Conjecture 9.4, Section 9 / PDF p. 15; arXiv `2005.02797`; DOI `10.1214/20-PS346`.

For the symmetric Rademacher matrix `M_n^sym`, with independent fair signs on and above the diagonal,

\[
\boxed{
\Pr\bigl(\operatorname{Spec}(M_n^{\rm sym})\subset\mathbb Z\bigr)
=2^{-(1/2+o(1))n^2}.
}
\]

Equivalently, the total number of labelled symmetric sign matrices with integral spectrum should be `2^{o(n^2)}`. The source quantifier is the total integral-spectrum event, not a fixed spectrum. The current line remains a restricted centered two-eigenvalue bridge and is not source closure.

The previous run had reduced the rank-two symplectic support in the inherited semidefinite `|r-lambda|=4`, `q=o(r)`, `q>4` shell to

\[
T=\begin{pmatrix}A&B\\C&F\end{pmatrix},
\qquad
D=T-S^T=\begin{pmatrix}0&J_m\\J_m&0\end{pmatrix},
\qquad
2m=r-q,
\]

with

\[
TS=ST=sI,
\qquad
s=\frac r4-\varepsilon,
\qquad
\varepsilon\in\{+1,-1\}.
\]

The exact quotient identities are

\[
\beta+\gamma=m,
\qquad
\alpha^2=s+\beta\gamma.
\]

Writing `a=|alpha|`, every row and column of the ternary diagonal blocks has exactly `s` nonzeros and, after majority normalization, exact minority degree

\[
\nu=(s-a)/2.
\]

The previous theorem gave `nu<=5q`, forced `beta,gamma=m/2+O(sqrt(mq))`, and showed that refined anchor classes are exact constant-intersection support families. Quadratic sign entropy was removed; the unresolved object was the binary-support gluing.

## 2. New theorem A — the quotient lies on explicit Diophantine square shells

Because `T,S` are integral and `TS=sI`, `s` is integral; hence

\[
\boxed{4\mid r.}
\]

Set

\[
\delta=\beta-\gamma,
\qquad
h=s-m/2=q/4-\varepsilon,
\qquad
L=4h=q-4\varepsilon>0.
\]

The exact quotient circle is

\[
\boxed{\delta^2+(2\alpha)^2=m^2+4s.}
\]

For sufficiently large `q=o(m)`, `m^2+4s<(m+2)^2`, which discretizes `|alpha|`.

If `m` is even, let

\[
M=m/2,
\qquad H=q/4-\varepsilon.
\]

Then for an integer `k>=0`,

\[
\boxed{|\alpha|=M-k,\qquad 2\nu=H+k,\qquad k=O(q),}
\]

and, with `x=delta/2`,

\[
\boxed{x^2=(2k+1)M+H-k^2.}
\]

If `m` is odd, put

\[
M=(m+1)/2,
\qquad H=(q-2)/4-\varepsilon.
\]

Then again

\[
\boxed{|\alpha|=M-k,\qquad 2\nu=H+k,\qquad k=O(q),}
\]

while

\[
\boxed{\delta^2=1+4\bigl(H+k(m+1-k)\bigr).}
\]

Thus the previous continuous-looking balance window is actually a union of only `O(q)` explicit square shells.

A useful corollary is

\[
\boxed{\nu\ge H/2.}
\]

Combined with the inherited upper bound `nu<=5q`, this puts the minority degree on a two-sided `Theta(q)` scale throughout the growing-defect regime. The only zero-minority rank-two branch with `q>4` is

\[
\boxed{\varepsilon=+1,\qquad q=6.}
\]

## 3. New theorem B — each refined anchor class is an exact punctured partial Hadamard

Inside a refined top anchor class, the inherited binary support rows `W_i in {0,1}^{2m}` have

\[
|W_i|=s+\beta,
\qquad
|W_i\cap W_j|=\beta.
\]

Center them:

\[
y_i=2W_i-\mathbf1_{2m}.
\]

Then for `i!=j`,

\[
\boxed{y_i\cdot y_j=2m-4s=-L,}
\qquad
\|y_i\|^2=2m.
\]

Appending the same `L=q-4 epsilon` entries `+1` to every row gives

\[
\widetilde y_i=(y_i,\mathbf1_L)
\]

and therefore

\[
\boxed{
\widetilde Y\in\{\pm1\}^{t\times4s},
\qquad
\widetilde Y\widetilde Y^T=4sI_t.
}
\]

So **every refined top and bottom row class is exactly a common-tail puncturing of a partial Hadamard matrix of width `4s=r-4 epsilon`**. The transposed anchor theorem gives the identical statement for all refined column classes.

This is stronger than the previous near-Hadamard correlation statement: the classwise correlations are removed exactly by restoring the common tail.

## 4. New theorem C — the natural anchor-class recursion already has square-dimension contraction

The unbordered class Gram matrix is

\[
G_t=(2m+L)I_t-LJ_t.
\]

Its all-ones eigenvalue is `2m-L(t-1)`, so positivity gives

\[
\boxed{
t\le1+\frac{2m}{q-4\varepsilon}.
}
\]

If the nonempty refined top-row class sizes are `t_1,...,t_ell`, then

\[
\boxed{
\ell\ge
\frac{m(q-4\varepsilon)}{2m+q-4\varepsilon}
=(1/2-o(1))(q-4\varepsilon),
}
\]

and

\[
\boxed{
\sum_i t_i^2
\le
m+\frac{2m^2}{q-4\varepsilon}.
}
\]

Thus whenever

\[
q\to\infty,
\qquad q=o(m),
\]

we have

\[
\boxed{\sum_i t_i^2=o(m^2).}
\]

The same square-sum contraction holds for bottom-row and both column-class families. This supplies the contraction profile needed by a recursive entropy proof; the remaining issue is now specifically the **cross-class gluing entropy**.

There is also a current-literature bridge. A class of size `t_i` gives a `t_i x 4s` partial Hadamard. Since `t_i<= (2+o(1))m/q` and `s=(1/2+o(1))m`,

\[
\frac{s}{t_i^3}\ge\Omega(q^3/m^2).
\]

Hence if `q/m^(2/3)->infinity`, every growing class is in the cubic-or-better regime covered by Damek Davis's 31 March 2026 partial-Hadamard counting theorem. This is only a classwise bridge; it does not count the simultaneous row/column gluing and therefore does not close this shell.

## 5. New theorem D — the unique zero-minority branch is exactly a two-row deletion of a full Hadamard problem

In the sole `nu=0` branch,

\[
\varepsilon=+1,
\qquad q=6,
\qquad s=(m+1)/2,
\]

and the quotient gives, after swapping halves if necessary,

\[
\beta=s,
\qquad
\gamma=s-1,
\qquad
|\alpha|=s.
\]

All ternary signs are then majority signs, so the binary support `X=|T|` contains the remaining core data. Define

\[
H=2X-J_{2m}.
\]

Its distinct-row inner products are exactly `-2` within either half and `0` across halves. Append two columns, using tail `(1,1)` on the top half and `(1,-1)` on the bottom half. With

\[
N=2m+2=4s=r-4,
\]

this produces

\[
\boxed{
Y\in\{\pm1\}^{(N-2)\times N},
\qquad YY^T=NI_{N-2}.
}
\]

A new codimension-two completion lemma proves that every such `Y` extends by two sign rows to a full Hadamard matrix of order `N`.

The proof is basis-free. `P=I-Y^TY/N` is the rank-two projector onto the orthogonal complement of the rows, with diagonal `2/N`. Hence

\[
R=(N/2)P
\]

is PSD rank two, diagonal one, and has integral off-diagonal entries `-(Y^TY)_{ij}/2`, so all entries lie in `{-1,0,1}`. Its unit-vector Gram representation therefore lies on two orthogonal signed lines. The two nonzero eigenvalues are both `N/2`, forcing `N/2` vectors on each line; their signed line coordinates give the two missing sign rows.

Consequently,

\[
\boxed{
N_{q=6,\nu=0}(r)
\le 2^{O(r\log r)} H(r-4),
}
\]

where `H(N)` counts labelled Hadamard matrices of order `N`. This is an actual recursive identification of the branch, not merely an analogy. The current Ferber--Jain--Zhao Hadamard count yields a strict quadratic entropy saving here, though not the `2^{o(r^2)}` source-scale bound.

## 6. Current literature boundary

A bounded current search on 20 September 2026 did not surface a paper claiming Vu's exact Conjecture 9.4. This is negative-search evidence only, not an openness or novelty certificate.

Ferber--Jain--Zhao, *On the number of Hadamard matrices via anti-concentration*, Combinatorics, Probability and Computing 31 (2022), gives the first nontrivial upper bound for square Hadamard enumeration, rather than a subquadratic count.

Damek Davis, *Counting partial Hadamard matrices in the cubic regime*, arXiv `2603.30013`, submitted 31 March 2026, gives precise asymptotics for `n x 4t` partial Hadamards when `t/n^3 -> infinity` and in a sufficiently large fixed cubic regime. This is the new relevant bridge for large `q`, but it remains classwise only.

## 8. Remaining gap and next attack

For growing `q`, the child dimensions already have the right contraction. The next missing theorem is therefore a **cross-class gluing theorem**: after `2^{o(r^2)}` quotient data, show that the inverse equations determine the off-diagonal interactions between punctured partial-Hadamard children with only subquadratic entropy. Davis's theorem can then potentially handle the individual children in the `q>>m^(2/3)` range.

For bounded `q`, the Diophantine parameterization is more useful. The `nu=0` case has now been reduced to a smaller full Hadamard instance. Every remaining bounded-defect branch has `nu>=1`; its minority support is a fixed-degree regular bipartite graph, hence a union of `O(1)` perfect matchings. The next bounded-defect attack is to determine whether those matching perturbations are finite-rank Hadamard trades, or instead produce a genuinely new group-divisible design atom. Either theorem would move the recursion forward.

The bounded-rank `q<=4` Hadamard/D-optimal branch, higher shells, indefinite defects, the full centered two-eigenvalue count, and finally Vu's total integral-spectrum conjecture remain open.
