## 1. Exact source and inherited claim

Van H. Vu, *Recent progress in combinatorial random matrix theory*, Probability Surveys 18 (2021), Conjecture 9.4, Section 9 / PDF p. 15; arXiv `2005.02797`; DOI `10.1214/20-PS346`.

For the symmetric Rademacher matrix `M_n^sym`, with independent fair signs on and above the diagonal,

\[
\boxed{
\Pr\bigl(\operatorname{Spec}(M_n^{\rm sym})\subset\mathbb Z\bigr)
=2^{-(1/2+o(1))n^2}.
}
\]

Equivalently, the total number of labelled symmetric sign matrices with integral spectrum should be `2^{o(n^2)}`. The source quantifier is the total integral-spectrum event, not a fixed spectrum. The current line remains a restricted centered two-eigenvalue bridge and is not source closure.

The previous run restored the integer equations on the rank-two symplectic support in the inherited `|r-lambda|=4`, `q=o(r)`, `q>4` shell. After normalization,

\[
T=\begin{pmatrix}A&B\\C&F\end{pmatrix},
\qquad
D=T-S^T=\begin{pmatrix}0&J_m\\J_m&0\end{pmatrix},
\qquad
2m=r-q,
\]

with `B,C` binary and

\[
\beta+\gamma=m,
\qquad
\alpha^2=s+\beta\gamma,
\qquad
s=\frac r4-\varepsilon.
\]

It proved that quotient endpoints are regular-weighing recursions abstractly but are excluded by the actual source-specific anchor geometry when `q=o(r)`. The remaining obstruction was the interior two-class family.

## 2. New theorem A — exact support regularity

The block Gram equations imply

\[
AA^T+BB^T=sI+\beta J,
\qquad
CC^T+FF^T=sI+\gamma J,
\]

and the transposed analogues. Taking diagonals and using binary row/column degrees gives

\[
\boxed{|A|\mathbf1=|A|^T\mathbf1=s\mathbf1,}
\]

\[
\boxed{|F|\mathbf1=|F|^T\mathbf1=s\mathbf1.}
\]

Thus every row and column of `A,F` has exactly `s` nonzero signs. With `a=|alpha|`, after one majority-sign normalization the number of minority signs in **every row and every column** is exactly

\[
\boxed{\nu=(s-a)/2.}
\]

## 3. New theorem B — constant-intersection packing forces the interior quotient to balance

For binary vectors of length `v`, constant weight `k`, and constant pairwise intersection `lambda`, Cauchy--Schwarz gives the quantitative Fisher bound

\[
\boxed{
 t\le \frac{v(k-\lambda)}{k^2-v\lambda}
}
\]

whenever the denominator is positive.

The inherited anchor refinement turns each top-half refined class into an exact constant-intersection family with

\[
(v,k,\lambda)=(2m,s+\beta,\beta),
\]

and each bottom-half class into one with

\[
(v,k,\lambda)=(2m,s+\gamma,\gamma).
\]

Because at most `2q` refined classes cover either half, we obtain

\[
\Phi_\beta:=(s+\beta)^2-2m\beta\le4qs,
\]

\[
\Phi_\gamma:=(s+\gamma)^2-2m\gamma\le4qs.
\]

Put

\[
h=s-m/2=q/4-\varepsilon>0,
\qquad
x=\beta-m/2.
\]

Then

\[
\Phi_\beta=(x+h)^2+2mh,
\qquad
\Phi_\gamma=(x-h)^2+2mh.
\]

Hence

\[
\boxed{(|x|+h)^2+2mh\le4qs,}
\]

and therefore

\[
\boxed{
\left|\beta-\frac m2\right|
\le \sqrt{4qs-2mh}-h.
}
\]

Since `q=o(m)`, this gives

\[
\boxed{
\beta=\frac m2+O(\sqrt{mq}),
\qquad
\gamma=\frac m2+O(\sqrt{mq}).
}
\]

Thus the anchor geometry excludes **all linearly unbalanced interior quotient branches**, not merely the exact endpoints.

## 4. New theorem C — only `O(q)` minority signs survive

Using

\[
a^2=s+\beta\gamma=s+\frac{m^2}{4}-x^2
\]

and the balance bound above, one obtains, for all sufficiently large `q=o(m)` instances,

\[
\boxed{s-a\le\frac{19}{2}q,}
\qquad
\boxed{\nu\le5q.}
\]

Therefore the negative/minority support of each majority-normalized ternary block has row and column degree only `O(q)=o(m)`.

For fixed supports `|A|,|F|`, the number of possible signings is bounded by

\[
2\binom{s}{\nu}^{2m},
\]

so

\[
\boxed{
\log_2 N_{\rm sign}
=O\!\left(mq\log\left(\frac mq+2\right)\right)
=o(m^2).
}
\]

This is the entropy-scale progress of the run: **quadratic entropy in the rank-two interior branch cannot come from the ternary signs**. It is forced entirely into the binary support matrix, up to subquadratic overhead.

## 5. New theorem D — the remaining support is two-sided near-Hadamard

Write, after majority normalization,

\[
A=P-2N_A,
\qquad
F=Q-2N_F,
\]

where `P=|A|`, `Q=|F|` and every row/column of `N_A,N_F` has degree `nu<=5q`. Let

\[
X=|T|=\begin{pmatrix}P&B\\C&Q\end{pmatrix}.
\]

The exact Gram equations imply

\[
\left|(PP^T+BB^T)_{ij}-\beta\right|\le8\nu
\quad(i\ne j),
\]

and the bottom analogue, while the mixed intersections satisfy

\[
0\le(PC^T+BQ^T)_{ij}-a\le4\nu.
\]

For the centered sign support matrix

\[
H=2X-J_{2m},
\]

this gives, uniformly for distinct rows,

\[
\boxed{|\langle H_i,H_j\rangle|\le170q,}
\]

and the column equations give the same bound for distinct columns. Since `q=o(m)`, all row and column correlations are `o(m)`.

Thus the surviving hard object is a two-sided **near-Hadamard binary support** carrying the exact inverse and anchor structure.

## 6. Failed reduction identified immediately — near-Hadamard correlations alone are not enough

The correlation conclusion by itself cannot be the next theorem. If `q/\sqrt{m\log m}\to\infty`, a uniformly random `2m x 2m` sign matrix has all pairwise row and column correlations `O(\sqrt{m\log m})=o(q)` with probability tending to one, by a Hoeffding bound followed by a union bound over `O(m^2)` row/column pairs.

Therefore there are still

\[
2^{(4-o(1))m^2}
\]

sign matrices obeying an `O(q)` two-sided correlation constraint in that parameter range. The new near-Hadamard support theorem is useful only together with the **exact inverse equations and low-complexity anchor partition**. This rules out wasting the next run on a correlation-only count.
