## 2. New theorem — exact Riccati identity and exact plateau

Put

\[
A=T^TT,\qquad B=D^TD.
\]

Since `S=sT^{-1}`,

\[
D=T-sT^{-T}=T(I-sA^{-1}).
\]

Therefore

\[
\boxed{B=A-2sI+s^2A^{-1}},
\]

and hence

\[
\boxed{AB=(A-sI)^2}.
\]

The multiplier relating `D` to `A-sI` is invertible, so

\[
\boxed{\operatorname{rank}(A-sI)=\operatorname{rank}D=k},
\qquad
\boxed{\ker(A-sI)=\ker D}.
\]

Thus the singular value `sqrt(s)` of `T` has **exact multiplicity `d-k`**, sharpening the previous `>=d-2q` plateau. The left version gives

\[
\ker(TT^T-sI)=\ker D^T,
\]

so

\[
\boxed{T:\ker D\to\ker D^T}
\]

is exactly a `sqrt(s)`-scaled isometry.

This theorem is basis-free and does not use ternarity.

## 3. Complete real normal form inside one fixed defect

Let `D=U Sigma V^T` be an SVD and set

\[

In SVD coordinates `Y=U^TXV`, distinct singular-value blocks decouple. On every positive singular-value block `sigma`, `Y` is symmetric and

\[

Therefore

\[
Y_\sigma=\sqrt{s+\sigma^2/4}\,J_\sigma,
\qquad J_\sigma=J_\sigma^T,

\[
Y_0=\sqrt{s}\,O_0,
\qquad O_0\in O(d-k).

So the fixed-defect real solution set is completely described. Every non-flat mode lies in the `k`-dimensional defect sector; the only quadratic real freedom is the orthogonal orientation on the exact plateau.

\sqrt{s+\sigma^2/4}-\sigma/2,

and their product is exactly `s`. Thus all non-flat singular values occur in `s`-reciprocal pairs.

## 4. New integral spectral-factorization obstruction

The Riccati identity gives the polynomial matrix factorization

\[
\boxed{
(xI-A)(xI-s^2A^{-1})
=(x-s)^2I-xD^TD.
}
\]

Taking determinants,

\[
\boxed{
\det((x-s)^2I-xD^TD)
=\chi_{T^TT}(x)\chi_{SS^T}(x).
}
\]

Both factors on the right are monic in `Z[x]`. Since `rank D=k`, define the degree-`2k` residual polynomial

\[
R_D(x)=
\frac{\det((x-s)^2I-xD^TD)}{(x-s)^{2(d-k)}}\in\mathbb Z[x].
\]

Then

\[
\chi_{T^TT}(x)=(x-s)^{d-k}f_T(x),
\]

\[
\chi_{SS^T}(x)=(x-s)^{d-k}g_T(x),
\]

where `f_T,g_T` are monic integral degree-`k` polynomials satisfying

\[
\boxed{R_D=f_Tg_T}.
\]

Thus a candidate defect is impossible unless `R_D` admits a monic degree-`k` factor over `Z`. In particular, irreducibility of `R_D` over `Q` with `k>0` is an exact no-root certificate.

If

\[
R_D=\prod_i h_i^{e_i}
\]

is its integral irreducible factorization, the number of possible `f_T` is at most

\[
\prod_i(e_i+1)\le2^{2k}.
\]

Therefore

\[
\boxed{
\#\{\chi_{T^TT}:D\text{ fixed}\}\le4^k.
}
\]

Since `k=o(r)`, a fixed defect has only `2^{o(r)}` possible core singular spectra. This removes Gram **eigenvalues** as a possible quadratic-entropy reservoir.

## 5. Arithmetic singular-square consequence

If `tau>0` is an integer eigenvalue of `D^TD`, then on that eigenspace every Gram eigenvalue `theta` satisfies

\[
\theta^2-(2s+\tau)\theta+s^2=0.
\]

Its discriminant is

\[
\Delta_\tau=\tau(\tau+4s).
\]

If `Delta_tau` is not a square, the quadratic is irreducible over `Q`. Because the `tau` eigenspace is rational and invariant, the two conjugate roots must occur with equal multiplicity. Hence an integer `tau` of odd multiplicity forces

\[
\boxed{\tau(\tau+4s)=z^2}.
\]

Equivalently,

\[
(\tau+2s-z)(\tau+2s+z)=4s^2.
\]

So all odd-multiplicity integer singular squares lie in a divisor-controlled thin list rather than an interval of possibilities.
