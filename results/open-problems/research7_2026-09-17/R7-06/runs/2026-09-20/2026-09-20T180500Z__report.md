## 1. Exact outside source and inherited theorem

Van H. Vu, *Recent progress in combinatorial random matrix theory*, Probability Surveys 18 (2021), Conjecture 9.4, Section 9 / PDF p. 15; arXiv `2005.02797`; DOI `10.1214/20-PS346`.

For the symmetric Rademacher matrix `M_n^sym`, with independent fair signs on and above the diagonal,

\[
\boxed{
\Pr\bigl(\operatorname{Spec}(M_n^{\rm sym})\subset\mathbb Z\bigr)
=2^{-(1/2+o(1))n^2}.
}
\]

Equivalently, the total number of labelled symmetric sign matrices with integral spectrum should be `2^{o(n^2)}`. The source statement is a total event, not a fixed-spectrum conjecture. The inherited F0011 line notes that only `2^{O(n)}` integral spectra are possible, so a uniform `2^{o(n^2)}` fixed-spectrum theorem would suffice after summation; that remains an intermediate route, not the source quantifier.

The immediately preceding C05 theorem proved that the unique zero-minority q=6 contrast-core relaxation is Hadamard-entropy equivalent at quadratic scale: after normalization it is in two-way correspondence, up to `2^{O(r log r)}` switching/permutation overhead, with Hadamard matrices of order `r-4`. That showed a core-only count cannot bypass the open square-Hadamard enumeration problem. The missing information was the six original row anchors and six original column anchors discarded by the relaxation.

This run pulls those source-specific anchors back in.

## 2. New theorem — exact 1/0 anchor discrepancy counts

In the q=6 zero-minority branch write

\[
s=\frac r4-1,
\qquad r=4s+4,
\qquad d=r-6=2m,
\qquad m=2s-1.
\]

The binary support reduction uses

\[
X_{g,h}=1_{\{C_{g,h}\ne C_{g,h_j}\}},
\qquad
Y_{g,h}=1_{\{C_{g,h}\ne C_{g_i,h}\}},
\]

and

\[
Y=X\oplus E,
\]

where the rank-two defect support is the complete two-half mask

\[
E=\begin{pmatrix}0&J_m\\J_m&0\end{pmatrix}.
\]

The q=6 zero-minority support degrees imply:

* `X` row weights are `2s` on the top half and `2s-1` on the bottom half;
* `X` column weights are `2s-1` on the left half and `2s` on the right half;
* after toggling across `E`, `Y` row weights are `2s-1` on top and `2s` on bottom.

Two rows in the same original Gram block have inner product four, so their Hamming distance is exactly

\[
(r-4)/2=2s.
\]

Hence a top non-anchor row differs from its row anchor on exactly **one** of the six column-anchor coordinates, whereas a bottom non-anchor row differs on **none**. By the column Gram identity, a left non-anchor column differs from its column anchor on exactly **one** of the six row-anchor coordinates, whereas a right non-anchor column differs on **none**.

This is source information absent from the relaxed Hadamard core.

## 3. New theorem — complete-bipartite defect forces unique giant original blocks

Let `a_ij=C_{g_i,h_j}` be the `6 x 6` anchor-anchor sign table. For a non-anchor row `g in G_i`, let `rho_g(j)` record whether `C_{g,h_j}` differs from `a_ij`; for a non-anchor column `h in H_j`, let `sigma_h(i)` record whether `C_{g_i,h}` differs from `a_ij`.

Then exactly

\[
\boxed{E_{g,h}=\rho_g(j)\oplus\sigma_h(i).}
\]

Top rows have one `rho`-flip; bottom rows have zero. Left columns have one `sigma`-flip; right columns have zero.

On the top-right `E=1` rectangle, the zero `sigma` budget forces **all right-half non-anchor columns into one original column block** `H_{j_*}`, and every top row uses that same `j_*` as its unique anchor flip.

On the bottom-left `E=1` rectangle, the zero `rho` budget forces **all bottom-half non-anchor rows into one original row block** `G_{i_*}`, and every left column uses that same `i_*` as its unique anchor flip.

On the top-left `E=0` rectangle, equality of the two flip indicators leaves only two possibilities: either the other two halves also lie in these distinguished blocks, or both avoid them. The first possibility would give block sizes

\[
\{2m+1,1,1,1,1,1\},
\]

which contradicts the inherited two-sided quotient theorem that distinct sizes in this q>4 shell must all be even.

Therefore

\[
\boxed{|G_{i_*}|=|H_{j_*}|=m+1=2s.}
\]

The other five blocks on either side have total size `2s+4`. Distinct sizes necessarily occur, so every block size is even. The distinguished size `2s` is unique: a second such block would leave only four total coordinates for four positive even blocks.

## 4. Main arithmetic consequence — the Hadamard-hard leaf exists only on `12u^2`

For a block size `a`, the inherited integer quotient theorem gives

\[
M_a^TM_a=\mu_a I,
\qquad
\mu_a=r+4(a-1).
\]

The distinguished size `a=2s` occurs with multiplicity exactly one. Therefore its quotient is a `1 x 1` integer matrix `[t]`, and

\[
t^2=\mu_{2s}=12s.
\]

Thus `6|t`; writing `t=6u` gives

\[
\boxed{s=3u^2}.
\]

Consequently every actually liftable q=6 zero-minority source root satisfies

\[
\boxed{r=12u^2+4,}
\]

while the Hadamard completion of the normalized core has order

\[
\boxed{N=r-4=12u^2.}
\]

The unique giant row block and unique giant column block each have size

\[
\boxed{6u^2=N/2.}
\]

So the preceding Hadamard-entropy equivalence was genuinely too relaxed: source compatibility removes every Hadamard order except the sparse square-order subsequence `12u^2` and imposes a marked half-size block.

This is not yet a `2^{o(r^2)}` count at those surviving orders.

## 5. Residual five-block arithmetic and exact exclusion of the first candidate

Write the five remaining even block sizes as

\[
2c_1,\ldots,2c_5.
\]

Then

\[
\boxed{c_1+\cdots+c_5=3u^2+2.}
\]

If a value `c` occurs with odd multiplicity `ell`, the quotient determinant identity forces

\[
\boxed{3u^2+2c=v^2}
\]

for some integer `v`. At least one residual size class has odd multiplicity because there are five residual blocks.

Also, writing the corresponding even quotient block as `M_{2c}=2Q_c` gives

\[
Q_c^TQ_c=(3u^2+2c)I_\ell,
\qquad |Q_c(i,j)|\le c,
\]

and therefore

\[
3u^2+2c\le \ell c^2.
\]

The first arithmetic candidate `u=1` is impossible. Then `s=3`, `r=16`, and the block profile is forced to

\[
\{6,2,2,2,2,2\}.
\]

The size-two quotient would be a `5 x 5` matrix `M_2` with

\[
M_2^TM_2=20I,
\qquad M_2(i,j)\in\{-2,0,2\}.
\]

After dividing by two this is a `5 x 5` ternary matrix `Q` with `Q^TQ=5I`. Every column must then have five nonzero `+/-1` entries, but two sign vectors of odd length five cannot be orthogonal. Contradiction.

Hence the first possible liftable order, if any exists, is

\[
\boxed{u\ge2,\quad r\ge52,\quad N=r-4\ge48.}
\]

This is an exact symbolic exclusion, not a census.
