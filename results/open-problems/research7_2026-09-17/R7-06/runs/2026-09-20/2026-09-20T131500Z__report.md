## 1. Exact source and inherited claim

Van H. Vu, *Recent progress in combinatorial random matrix theory*, Probability Surveys 18 (2021), Conjecture 9.4, arXiv `2005.02797`, DOI `10.1214/20-PS346`.

For the symmetric Rademacher matrix `M_n^sym`, with independent fair signs on and above the diagonal,

\[
\Pr\bigl(\operatorname{Spec}(M_n^{\rm sym})\subset\mathbb Z\bigr)
=2^{-(1/2+o(1))n^2}.
\]

Equivalently, the total integral-spectrum count should be `2^{o(n^2)}`. The source does **not** fix a spectrum. C05 remains a restricted bridge through the centered two-eigenvalue/symmetric-Hadamard family.

The immediately inherited shell is the one-parity `|r-lambda|=4`, `q=o(r)`, `q>4` branch. Its contrast cores satisfy

\[
T,S\in\{-1,0,1\}^{d\times d},
\qquad TS=ST=sI,
\qquad d=r-q,
\qquad s=r/4-\varepsilon,
\]

and

\[
D:=T-S^T,
\qquad \operatorname{rank}_{\mathbb R}D=k\le2q=o(r).
\]

The previous report proved that `D` is dense, gave the exact Riccati identity

\[
(T^TT)D^TD=(T^TT-sI)^2,
\]

and reduced the remaining quadratic freedom to a scaled isometry `ker D -> ker D^T`. The missing theorem was a count/structure theorem for that kernel-orientation fiber.

## 2. New proof — cellwise signs collapse to one binary support matrix

For non-anchor row `g in G_i` and non-anchor column `h in H_j`, define the two anchor-sign masks

\[
U_{g,h}=C_{g_i,h},
\qquad
V_{g,h}=C_{g,h_j}.
\]

The contrast formulas give

\[
T_{g,h}=\frac{C_{g,h}-V_{g,h}}2,
\qquad
S_{h,g}=\frac{C_{g,h}-U_{g,h}}2,
\]

and hence

\[
D=(U-V)/2.
\]

Let

\[
E=\mathbf1_{\{U\ne V\}}=D\pmod2.
\]

Since a nonzero minor modulo `2` is a nonzero integer minor,

\[
\operatorname{rank}_{\mathbb F_2}E\le\operatorname{rank}_{\mathbb Q}D=k\le2q.
\]

Now put

\[
X_{g,h}=\mathbf1_{\{C_{g,h}\ne V_{g,h}\}}.
\]

Then exactly

\[
\boxed{T=-V\odot X,}
\]

while

\[
\boxed{S^T=-U\odot(X\oplus E).}
\]

Therefore, once the anchor masks are recorded, **one binary matrix `X` determines both ternary inverse cores and reconstructs the non-anchor interior of `C`**.

The inverse equations become the exact signed binary system

\[
\boxed{
(V\odot X)(U\odot(X\oplus E))^T=sI,
}
\]

\[
\boxed{
(U\odot(X\oplus E))^T(V\odot X)=sI.
}
\]

This removes all residual ternary sign entropy from the kernel-orientation problem.

## 3. New structural theorem — a linear-size regular common core

Define

\[
A=X\odot(1-E).
\]

On `E=1` cells exactly one of `X` and `X\oplus E` is nonzero, so those cells contribute zero to the diagonal of the product. On `E=0`, the two anchor signs agree and the diagonal contribution is exactly `X`.

Thus every row and every column of `A` has sum `s`:

\[
\boxed{A\mathbf1=s\mathbf1,\qquad A^T\mathbf1=s\mathbf1.}
\]

Hence `A` is an `s`-regular bipartite graph. It decomposes into `s` edge-disjoint perfect matchings. Since

\[
s=r/4+O(1),
\qquad d=r-q=(1-o(1))r,
\]

the zero set of the dense low-rank defect contains a **linear number of disjoint permutation supports** on which `T` and `S^T` coincide and are nonzero.

Choosing one such matching and permuting columns along it puts the defect into the normal form

\[
\boxed{D_{ii}=0\text{ for all }i}
\]

at only `2^{O(d log d)}=2^{o(r^2)}` entropy cost. This normalization does not use invertibility of the original sign cross-block `C`, so the singular/corank endpoint remains included.

## 4. New entropy bridge — the shell is binary up to subquadratic overhead

The row/column partitions, anchor choices, and the `q` anchor rows plus `q` anchor columns together use at most

\[
2^{O(qr+r\log q+q\log r)}=2^{o(r^2)}
\]

possibilities.

For fixed anchor data,

\[
C_{g,h}=V_{g,h}(1-2X_{g,h})
\]

recovers the non-anchor interior. Therefore, if `N_bin(r,q)` is the largest number of binary supports solving the signed system above for admissible anchor data,

\[
\boxed{
N_{\rm shell}(r,q)
\le
2^{O(qr+r\log r)}N_{\rm bin}(r,q).
}
\]

Consequently a `2^{o(r^2)}` bound for the binary support systems would immediately give the same source-scale bound for this entire `|r-lambda|=4`, `q=o(r)`, `q>4` root shell.

This is a material narrowing of the missing theorem: the problem is no longer a ternary Gram/root fiber. It is one binary incidence matrix with a low-rank defect mask and a forced `s`-factor in the defect complement.

## 5. New finite-field shadow and a failed-attack diagnosis

Modulo `2` all sign masks vanish:

\[
\boxed{X(X+E)^T=(s\bmod2)I,}
\]

\[
\boxed{(X+E)^TX=(s\bmod2)I.}
\]

If `s` is odd, then

\[
\boxed{X+E=X^{-T},\qquad E=X+X^{-T}}
\]

over `F_2`, with `rank(E)<=2q`. Moreover

\[
X:\ker E\to\ker E^T
\]

is an exact isometry for the standard bilinear form.

If `s` is even, the row spaces of `X` and `X+E` are orthogonal. When `v_2(s)=1`, the inherited Smith-invariant identity sharpens this to

\[
\boxed{
\operatorname{rank}_{\mathbb F_2}X
=\operatorname{rank}_{\mathbb F_2}(X+E)
=d/2,
}
\]

so the two row spaces are exact dual complements.

This diagnoses an unproductive pivot before spending another run on it: **pure mod-2 rank counting cannot be expected to close the entropy problem**, because it retains a macroscopic orthogonal/dual-code orientation sector. The integer signed equations and the `s`-regular common-support factor are essential extra information.
