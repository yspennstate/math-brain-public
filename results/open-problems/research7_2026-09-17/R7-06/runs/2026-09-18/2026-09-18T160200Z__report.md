## 3. B4 — a complete weaker theorem: horizon-independent Bellman concentration in d=5

For deterministic scenery `z`, write the finite-horizon Bellman value as

\[
u_n^z(x)
=
\sup_{\tau\le n}
\mathbb E_x\sum_{j=0}^{\tau-1}z(X_j),
\tag{3.1}
\]

with immediate stopping allowed. This is the same Bellman value denoted `u_n^z` in the earlier R7-06 artifacts; the Greek `nu` notation below is only local notation, not a new process. For random scenery put

\[
a_n=\mathbb E\nu_n^\zeta(0).
\tag{3.2}
\]

Let

\[
g_n(x,y)=\sum_{j=0}^{n-1}p_j(x,y).
\]

### Proposition 3.1 (uniform square-summability)

In dimension five,

\[
\boxed{
\sum_y g_n(0,y)^2
\le
G_{2,5}:=\sum_{k=0}^{\infty}(k+1)p_k(0,0)<\infty
}
\tag{3.3}
\]

uniformly in `n`.

**Proof.** Symmetry and Chapman–Kolmogorov give

\[
\sum_y p_i(0,y)p_j(0,y)=p_{i+j}(0,0).
\]

Therefore

\[
\sum_y g_n(0,y)^2
=
\sum_{i,j<n}p_{i+j}(0,0)
\le
\sum_{k\ge0}(k+1)p_k(0,0).
\]

The local central-limit bound `p_k(0,0)<=C(k+1)^(-5/2)` makes the final series finite. ∎

### Proposition 3.2 (uniform Euclidean Lipschitz constant)

For every pair of deterministic sceneries `z,z'`,

\[
\boxed{
|\nu_n^z(0)-\nu_n^{z'}(0)|
\le
G_{2,5}^{1/2}\,\|z-z'\|_{\ell^2}.
}
\tag{3.4}
\]

**Proof.** For a fixed stopping rule `tau<=n`, let

\[
\mu_\tau(y)=
\mathbb E_0\sum_{j<\tau}\mathbf1_{\{X_j=y\}}.
\]

Then `0<=mu_tau(y)<=g_n(0,y)`. Its payoff is the linear functional `sum_y mu_tau(y)z(y)`, whose Euclidean Lipschitz constant is at most `||g_n(0,.)||_2`. The set of stopping rules is independent of the numeric scenery values, so taking the supremum preserves this common Lipschitz constant. Use (3.3). ∎

### Proposition 3.3 (one-site log-Sobolev inequality)

The law `Z^{-1}exp(-|x|^(5/2))dx` has a finite one-dimensional log-Sobolev constant.

**Proof.** For `V(x)=|x|^(5/2)`, `V''(x)=(15/4)|x|^(1/2)` outside zero, hence it is uniformly convex outside `[-1,1]`. On `[-1,1]`, the quadratic `W_0(x)=5x^2/4-1/4` matches both `V` and `V'` at `+/-1` and has second derivative `5/2`. Smoothing only near the two junctions gives a `C^2` potential `W` with `W''>=c_0>0` and bounded compactly-supported difference `V-W`. Bakry–Émery gives a log-Sobolev inequality for `e^{-W}` and the Holley–Stroock bounded-perturbation lemma transfers it to `e^{-V}`. ∎

Tensorization plus the Herbst argument now gives the useful theorem.

### Theorem 3.4 (uniform Bellman concentration)

There exists `c_*>0`, independent of horizon and starting point, such that

\[
\boxed{
\mathbb P\left(
\nu_n^\zeta(x)-\mathbb E\nu_n^\zeta(x)\ge r
\right)
\le e^{-c_*r^2},
\qquad r\ge0.
}
\tag{3.5}
\]

Consequently, for `r>0`,

\[
\boxed{
\mathbb E\left(
\nu_n^\zeta(x)-\mathbb E\nu_n^\zeta(x)-r
\right)_+
\le
\Psi(r):=
\frac{e^{-c_*r^2}}{2c_*r}.
}
\tag{3.6}
\]

Because `a_k<=a_n` for `k<=n`, this also yields

\[
\boxed{
\mathbb E(\nu_k^\zeta(x)-a_n-r)_+
\le\Psi(r),
\qquad k\le n.
}
\tag{3.7}
\]

The significant point is that all constants are independent of `n`; this uses the `d>4` square-summability of the Green kernel.

## 4. B20 — the exact failure of the intended lower-increment route

The previous plan was to show that a critical negative core remains opaque even against the actual unbounded continuation and then use that core to force the source asymptotic. The first half can now be carried out, but the second half has the wrong monotonicity sign.

Let

\[
\mathcal O=
\{\zeta(y)\le h_y\text{ for every }y\in B_R\}
\tag{4.1}
\]

with negative thresholds. This event is coordinatewise decreasing. The Bellman value `nu_n^z(x)` is coordinatewise increasing in the scenery because it is a supremum of linear functionals with nonnegative occupation coefficients.

For every nonnegative increasing functional `F`, product-measure association therefore gives

\[
\boxed{
\mathbb E[F\mid\mathcal O]
\le
\mathbb EF.
}
\tag{4.2}
\]

Indeed `1_{O^c}` is increasing, so Harris/FKG for product measures gives

\[
\mathbb E[F1_{\mathcal O^c}]
\ge
\mathbb EF\,\mathbb P(\mathcal O^c),
\]

which rearranges to (4.2).

Thus an inverse-square negative core is an **unfavorable** Bellman event. Opacity can show that the event remains strongly unfavorable despite exterior continuation; it cannot by itself be a favorable rare event proving a lower bound on `a_n`. A new comparison identity is needed to turn local suppression into information about the unconditioned growth.

This is the principal conceptual correction of the run.

## 5. B27 — replace the pathwise cap by an annealed excess estimate

At first exit time `t=T_R`, use the actual Bellman continuation

\[
H_t(x)=\nu_{n-t}^\zeta(x).
\tag{5.1}
\]

Suppose the core event `O` implies

\[
\zeta(y)\le-A(1+|y|^2)^{-1}
\quad(|y|<R)
\]

and

\[
A\log(1+R^2)\ge2C_5B.
\tag{5.2}
\]

The preceding opacity theorem then gives, pathwise in the scenery,

\[
V_n(0)
\le
\mathbb E_0[(H_{T_R}(X_{T_R})-B)_+;T_R\le n].
\tag{5.3}
\]

Choose

\[
B=a_n+r,
\qquad r>0.
\tag{5.4}
\]

### Theorem 5.1 (conditional annealed uncapped opacity)

For every decreasing core event `O` satisfying (5.2),

\[
\boxed{
\mathbb E[V_n(0)\mid\mathcal O]
\le
\Psi(r)
=
\frac{e^{-c_*r^2}}{2c_*r}.
}
\tag{5.5}
\]

Equivalently,

\[
\boxed{
\mathbb E[1_{\mathcal O}V_n(0)]
\le
\mathbb P(\mathcal O)\Psi(r).
}
\tag{5.6}
\]

**Proof.** For every `t<=n` and `x`, the functional

\[
F_{t,x}(\zeta)
=(\nu_{n-t}^\zeta(x)-a_n-r)_+
\]

is nonnegative and increasing. Therefore (4.2) and (3.7) imply

\[
\mathbb E[F_{t,x}\mid\mathcal O]
\le\mathbb EF_{t,x}
\le\Psi(r).
\]

The random-walk exit pair `(T_R,X_{T_R})` is independent of the scenery. Average the last inequality over its law in (5.3); the exit probability is at most one. ∎

Now use the critical core scale from the preceding report. For large `b`, let

\[
R_b=\left\lfloor\rho\sqrt{b/\log(e+b)}\right\rfloor,
\qquad
A_b=K\frac b{\log(e+b)},
\tag{5.7}
\]

and

\[
\mathcal O_b=
\left\{
\zeta(y)\le-\frac{A_b}{1+|y|^2}
\text{ for }|y|<R_b
\right\}.
\tag{5.8}
\]

For fixed `rho` and sufficiently large fixed `K`, the previous exact calculation gives both opacity for cap `b` and

\[
\mathbb P(\mathcal O_b)
\ge
\exp\{-C\Phi_5(b)\}.
\tag{5.9}
\]

Taking `b=a_n+r` in Theorem 5.1 yields

\[
\boxed{
\mathbb E[V_n(0)\mid\mathcal O_{a_n+r}]
\le
\frac{e^{-c_*r^2}}{2c_*r}.
}
\tag{5.10}
\]

In particular, for any fixed `eta>0`, set `r=eta a_n`. Since the admitted source lower bound implies `a_n->infinity`,

\[
\mathbb E[V_n(0)\mid\mathcal O_{(1+\eta)a_n}]
\le
\exp\{-c_\eta a_n^2\}
\tag{5.11}
\]

up to the explicit `1/a_n` prefactor.

Thus the actual unbounded continuation is asymptotically invisible in conditional expectation on a sufficiently strong critical inverse-square core. The pathwise cap from the previous run has been removed for this smooth Weibull recovery case.

The sought bridge has the form

\boxed{

\mathbb E\,\mathcal L_{n,R}(s)\,ds,
