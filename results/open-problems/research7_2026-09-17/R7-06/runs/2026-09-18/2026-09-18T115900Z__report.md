## 5. B1 — change category: reflection is an optimal-stopping obstacle

For deterministic scenery `z`, let

\[
u_0^z=0,
\qquad
u_{n+1}^z=(z+Pu_n^z)_+,
\qquad
F_n^z=z+Pu_n^z.
\]

If `(X_j)` is simple random walk, dynamic programming gives the exact Bellman representation

\[
\boxed{
 u_n^z(x)
 =
 \sup_{\tau\le n}
 \mathbb E_x\left[\sum_{j=0}^{\tau-1}z(X_j)\right],
}
\tag{5.1}
\]

where stopping immediately is allowed. Indeed, with `V_0=0`, the value recursion is

\[
V_{n+1}(x)=\max\{0,z(x)+PV_n(x)\},
\]

which is precisely the reflected odometer recursion.

Thus the remaining logarithmic question can be read as a parabolic obstacle/optimal-stopping sensitivity problem rather than merely as a random-scenery sum.

### Exact first-order kernel

For a bounded nonnegative perturbation `eta`, set `z_epsilon=z-epsilon eta`. The downward derivative

\[
d_n^{z,\eta}(x)
=
\lim_{\varepsilon\downarrow0}
\frac{u_n^z(x)-u_n^{z-\varepsilon\eta}(x)}{\varepsilon}
\]

exists. With

\[
A_j^z(x)=\mathbf1_{\{F_j^z(x)>0\}},
\]

it satisfies

\[
\boxed{
 d_{n+1}^{z,\eta}(x)
 =A_n^z(x)\bigl(\eta(x)+Pd_n^{z,\eta}(x)\bigr).
}
\tag{5.2}
\]

The equality case `F_n^z(x)=0` causes no ambiguity for this downward derivative: lowering the scenery keeps the perturbed pre-field nonpositive, so the derivative of the positive part is zero.

Iterating (5.2) yields

\[
K_{n,z}(x,y)
=
\mathbb E_x\left[
\sum_{j=0}^{n-1}\mathbf1_{\{X_j=y\}}
\prod_{i=0}^{j}A_{n-1-i}^z(X_i)
\right],
\tag{5.3}
\]

with

\[
d_n^{z,\eta}(x)=\sum_yK_{n,z}(x,y)\eta(y).
\]

This is a Green occupation kernel killed whenever the backward Bellman path meets the dynamic contact set. In particular,

\[
0\le K_{n,z}(x,y)\le g_n(x,y).
\tag{5.4}
\]

For the pre-reflection field, define

\[
\widetilde K_{n,z}(x,y)
=\mathbf1_{\{x=y\}}+\sum_wP(x,w)K_{n,z}(w,y).
\tag{5.5}
\]

Then

\[
0\le\widetilde K_{n,z}(x,y)\le g_{n+1}(x,y).
\tag{5.6}
\]

**B1 outcome:** successful category change. The raw finite Green function is only an upper envelope; the exact reflected sensitivity is a killed Green function determined by the obstacle/contact geometry.

## 6. B12 — conserved response: raw Green = reflected response + contact loss

Now take a finite nonnegative downward perturbation `eta` and put `z^-=z-eta`. Define

\[
\Delta_n=u_n^z-u_n^{z^-}\ge0,
\qquad
b_n=F_n^z-F_n^{z^-}=\eta+P\Delta_n\ge0.
\]

Using

\[
a_+-(a-b)_+=\min\{b,a_+\},\qquad b\ge0,
\]

we obtain

\[
\Delta_{n+1}=\min\{b_n,u_{n+1}^z\}.
\]

Let

\[
c_{n+1}=b_n-\Delta_{n+1}=(b_n-u_{n+1}^z)_+.
\]

Then

\[
\Delta_{n+1}=\eta+P\Delta_n-c_{n+1}.
\]

With `G_n=sum_{j=0}^{n-1}P^j`, iteration gives the exact identity

\[
\boxed{
\Delta_n
=G_n\eta-
\sum_{j=1}^{n}P^{n-j}c_j,
}
\tag{6.1}
\]

and, one step before reflection,

\[
\boxed{
F_n^z-F_n^{z^-}
=G_{n+1}\eta-
\sum_{j=1}^{n}P^{n+1-j}c_j.
}
\tag{6.2}
\]

This is the sought conservation law:

> **raw Green response = actual reflected response + future-propagated contact losses.**

Nothing heuristic enters (6.2).

For `z_s=z-s eta`, finite-horizon piecewise linearity also integrates the derivative exactly:

\[
\boxed{
F_n^z(x)-F_n^{z-\eta}(x)
=
\int_0^1\sum_y
\widetilde K_{n,z-s\eta}(x,y)\eta(y)\,ds.
}
\tag{6.3}
\]

So the killed kernel remains the correct object even for a finite-amplitude deformation; it simply changes along the path in scenery space.

### Critical energy compression

Set

\[
\gamma=d/2,
\qquad
q=d/(d-2).
\]

For any nonnegative `k` with `k(y)<=G(0,y)` and mass `L=sum_y k(y)`, I proved

\[
\boxed{
\sum_yk(y)^q
\le C_d\bigl(1+\log(1+L)\bigr).
}
\tag{6.4}
\]

Proof: take `R=max(2,sqrt(1+L))`. Inside `|y|<=R`, the critical identity `q(d-2)=d` gives

\[
\sum_{|y|\le R}G(0,y)^q\le C(1+\log R).
\]

Outside, `(d-2)(q-1)=2`, so

\[
k(y)^q
\le k(y)G(0,y)^{q-1}
\le CR^{-2}k(y),
\]

and the outer sum is `O(R^{-2}L)=O(1)`.

Applying (6.4) to `widetilde K` gives, with

\[
L_{n,z}(x)=\sum_y\widetilde K_{n,z}(x,y),
\]

\[
\boxed{
Q_{n,z}(x):=
\sum_y\widetilde K_{n,z}(x,y)^q
\le C_d\bigl(1+\log(1+L_{n,z}(x))\bigr).
}
\tag{6.5}
\]

The trivial bound `L<=n+1` recovers the old `O(log n)` energy. But the obstacle can make `L` much smaller: full contact gives `L=1`, while an everywhere-positive scenery gives `L=n+1` and the raw Green scale.

### Finite-amplitude Weibull cost

If a deformation lowers the pre-field by at least `h`, define

\[
Q_*
=\sup_{s\in[0,1]}
\sum_y\widetilde K_{n,z-s\eta}(x,y)^q,
\quad
L_*
=\sup_{s\in[0,1]}L_{n,z-s\eta}(x).
\]

From (6.3) and Holder,

\[
h
\le Q_*^{1/q}
\left(\sum_y\eta(y)^\gamma\right)^{1/\gamma},
\]

and therefore

\[
\boxed{
\sum_y\eta(y)^\gamma
\ge
\frac{h^\gamma}{Q_*^{\gamma-1}}
\ge
c_d
\frac{h^\gamma}
{(1+\log(1+L_*))^{\gamma-1}}.
}
\tag{6.6}
\]

This is an exact deterministic improvement of the **form** of the obstruction: the denominator is governed by effective obstacle lifetime, not automatically by the complete horizon.

It does not yet imply a new stochastic odometer asymptotic, because a useful source-probability bound on `L_*` remains to be proved.

**B12 outcome:** successful. The reflection loss and the right critical susceptibility are now explicit in exact formulas.

## 7. B15 — break radial symmetry on purpose

The preceding run's raw Green variational optimizer was

\[
\eta(y)\propto g_n(0,y)^{q-1}.
\]

I tested the natural asymmetric escape route: support the negative fluctuation only on an angular sector or another subset `A`.

Let

\[
Q_A=\sum_{y\in A}g_n(0,y)^q,
\qquad
Q=\sum_yg_n(0,y)^q.
\]

The exact Holder variational problem gives cost

\[
\frac{h^\gamma}{Q_A^{\gamma-1}}.
\]

If `Q_A=rho Q`, this is

\[
\boxed{
\rho^{-(\gamma-1)}
}
\]

times the unrestricted raw-Green optimum. Since `rho<=1`, arbitrary sector restriction never improves the exponent-level cost and is strictly worse unless it discards no `q`-energy.

Thus the naive symmetry-breaking route fails. The only useful asymmetry is **contact-adapted** asymmetry: after reflection the correct optimizer follows

\[
\eta(y)\propto\widetilde K_{n,z}(x,y)^{q-1},
\]

not a predetermined spatial sector.

**B15 outcome:** negative but decisive. Angular symmetry breaking by itself cannot remove the logarithm; the route must exploit the dynamic obstacle geometry.

\[

The exact reflected obstruction is now

\[

Q_{n,z}(x)=\sum_y\widetilde K_{n,z}(x,y)^q,

or more coarsely its effective lifetime

\[
\boxed{
L_{n,z}(x)=\sum_y\widetilde K_{n,z}(x,y).

The deterministic implications are:
