# B15 — break symmetry on purpose, but track the aperiodicity budget

Continue with the precise perturbation already introduced. Add the two diagonal steps `+(e_1+e_2)` and `-(e_1+e_2)` to the square lattice and give each diagonal step activity `z >= 0`. Let

`C_n(z) = sum_{k=0}^n a_{n,k} z^k`,

where `a_{n,k}` counts `n`-step self-avoiding walks using exactly `k` diagonal edges. Thus `a_{n,0}=sigma_n`.

At fixed positive perturbation the graph is non-bipartite. The checked 2002 source records existence of the one-step ratio on the triangular lattice, with Madras--Slade as its reference. The missing point for D0067 is **uniformity as the odd-cycle mechanism vanishes**.

The local pattern pair that exhibits this degeneration is completely explicit:

- long square-turn pattern `Q=((0,0),(1,0),(1,1))`, length `2`, diagonal count `0`;
- short diagonal pattern `P=((0,0),(1,1))`, length `1`, diagonal count `1`.

They have the same attachment vertices. Replacing `Q` by `P` changes length by exactly one. This is the parity-breaking analogue of the length-two pattern replacements behind Kesten's square-lattice argument.

## Exact finite packet calculation

Take any square-lattice SAW `omega` of length `N` containing a collection `M` of `m` pairwise vertex-disjoint occurrences of `Q`. For every subset `S subseteq M`, shortcut exactly the occurrences in `S` to diagonal edges. Because each shortcut deletes only the middle vertex of its two-edge turn and keeps the attachment vertices, simultaneous shortcuts on vertex-disjoint occurrences remain self-avoiding: the output vertex set is a subset of the original vertex set, and each new diagonal joins the two existing attachment vertices.

Introduce a length fugacity `u>0` only as a bookkeeping variable. The exact bivariate packet of all `2^m` descendants is

`F_{omega,M}(u,z) = sum_{S subseteq M} u^(N-|S|) z^|S| = u^N (1+z/u)^m`.

Separate descendants by whether their final length has the same parity as `N` (`|S|` even) or opposite parity (`|S|` odd):

`F_even = (u^N/2) [ (1+z/u)^m + (1-z/u)^m ]`,

`F_odd  = (u^N/2) [ (1+z/u)^m - (1-z/u)^m ]`.

Hence, for `0 <= z < u`, the normalized signed parity imbalance is **exactly**

`Theta_m(u,z) := (F_even-F_odd)/(F_even+F_odd) = ((1-z/u)/(1+z/u))^m`.       (B15.1)

This is the aperiodicity budget of the local odd-cycle replacement.

For fixed `z/u>0` and `m >= alpha N`,

`Theta_m(u,z) <= exp(-2 alpha N z/u)`,

because `log((1+t)/(1-t)) >= 2t` for `0<=t<1`. Thus a fixed positive odd-cycle activity exponentially destroys parity inside a packet with linearly many switchable turns.

The degeneration is equally explicit. Normalize the packet weights. A given switch is selected with probability

`p = (z/u)/(1+z/u) = z/(u+z)`.

Therefore

`P(packet uses at least one parity-breaking shortcut) <= m z/(u+z) <= (m/u) z`.       (B15.2)

If `m<=N` and `N z_N -> 0`, then the right-hand side tends to zero for every fixed `u>0`; in particular `Theta_m(u,z_N)->1`. At the vanishing-defect scale the very local mechanism that makes the perturbed lattice aperiodic becomes asymptotically invisible.

This is a self-contained calculation. It does not rely on an unverified quantitative reading of the historical non-bipartite proof.

## Proposition (defect invisibility forces `n z_n -> 0`)

The internally stress-tested B28 theorem supplies constants `alpha>0`, `lambda<mu` such that, for every fixed `k`,

`a_{n,k} >= 2^(-k) (sigma_{n+k}-lambda^(n+k)) binom(floor(alpha(n+k)),k)`.

Take `k=1`. Then

`a_{n,1} >= (1/2)(sigma_{n+1}-lambda^(n+1)) floor(alpha(n+1))`.       (B22.1)

Since `sigma_m^(1/m)->mu>lambda`,

`lambda^m/sigma_m -> 0`.

Hence for all sufficiently large `n`,

`sigma_{n+1}-lambda^(n+1) >= sigma_{n+1}/2`,

and

`floor(alpha(n+1)) >= alpha(n+1)/2`.

Therefore

`a_{n,1} >= alpha(n+1) sigma_{n+1}/8`.       (B22.2)

Now Kesten gives `r_n r_{n+1}=sigma_{n+2}/sigma_n -> mu^2`, while every nontrivial square-lattice SAW has at most three legal extensions, so `r_{n+1}<=3`. For all sufficiently large `n`, `r_n r_{n+1}>=mu^2/2`, and consequently

`r_n >= mu^2/6`.       (B22.3)

Combining (B22.2) and (B22.3),

`a_{n,1}/sigma_n >= c_* n`,

with the explicit safe constant

`c_* := alpha mu^2 / 48 > 0`.       (B22.4)

Since all coefficients of `C_n(z)` are nonnegative,

`C_n(z_n)/sigma_n >= 1 + z_n a_{n,1}/sigma_n >= 1 + c_* n z_n`.       (B22.5)

Thus

`C_n(z_n)/sigma_n -> 1  ==>  n z_n -> 0`.       (B22.6)

So the `n z_n ->0` clause in `(VANISHING-DEFECT)` is not merely a cautious choice: **it is forced by defect invisibility** for this perturbation, using the already-preserved clean-shortcut lower bound.

## Quantitative incompatibility with the local non-bipartite port

Equations (B15.1)--(B15.2) and (B22.6) meet at exactly the bad scale:

- to make the perturbed counts asymptotically indistinguishable from square-lattice counts, one must have `n z_n -> 0`;

This is the explicit deterioration that the qualitative fixed-perturbation theorem hides. It explains why continuity of the weighted connective constant, or even a fixed-`z>0` adjacent-ratio theorem, is insufficient for the square-lattice limit.
