# 4. B22 — read the failure: why an interior Kesten surgery cannot change length by one

The source itself identifies the key parity obstruction: `Z^2` is bipartite and Kesten's surgery preserves length parity.

There is a simple exact reason. If two lattice paths have the same ordered pair of endpoints, then their lengths have the same parity, because every step flips the bipartition colour. Consequently:

\[
\boxed{\text{any surgery that keeps both endpoints fixed changes length by an even integer.}}
\tag{4.1}
\]

Therefore an odd length-changing surgery between rooted SAWs must move the terminal endpoint to the opposite bipartition class (the initial endpoint is fixed at the origin). An interior pattern replacement that keeps both endpoints of the replaced segment fixed can never by itself compare `sigma_n` with `sigma_{n+1}`.

This isolates the minimum geometric obligation of any Kesten-style one-step surgery:

- it must move the final endpoint (or equivalently translate/modify a terminal tail), and
- it must control global self-intersections and inverse multiplicity created by that endpoint/tail motion.

I tried the obvious endpoint detours and terminal plaquette insertions. They either change length by an even number, or require a vacant local configuration whose inverse multiplicity / frequency is not uniformly controlled on all SAWs. No bounded-to-one odd surgery valid on a positive-density family was proved.

**B22 outcome:** exact obstruction identified; no source theorem. The useful conclusion is that the missing one-step information must enter through endpoint geometry rather than an endpoint-preserving interior pattern surgery.

# 5. B25 — count the same thing twice: exact two-end extension identity

This method gives the metric movement.

Let `Sigma_n` be the `n`-step SAWs from the origin and let `P_n` be uniform on `Sigma_n`. For

\[
\omega=(\omega_0=0,\omega_1,\ldots,\omega_n),
\]

define

\[
D_0(\omega)
:=\#\{a:a\sim0,\ a\notin V(\omega)\},
\]

and

\[
D_+(\omega)
:=\#\{b:b\sim\omega_n,\ b\notin V(\omega)\}.
\]

Thus `D_+` is the number of legal forward extensions. Reversal plus translation is a bijection of `Sigma_n`, so

\[
\mathbb E_n D_0=\mathbb E_n D_+=r_n.
\tag{5.1}
\]

For `n>=1`, both variables lie in `{0,1,2,3}`.

Define the collision count

\[
C_n(\omega)
:=\#\Bigl((N(0)\setminus V(\omega))
\cap (N(\omega_n)\setminus V(\omega))\Bigr).
\tag{5.2}
\]

A pair `(a,b)` counted by `D_0 D_+` may be attached to the two ends, giving the path

\[
(a,0,\omega_1,\ldots,\omega_n,b).
\]

After translation by `-a`, this is an `(n+2)`-step rooted SAW exactly when `a!=b`. Conversely, given any rooted `(n+2)`-step SAW, delete its first and last vertices and translate the remaining path so its first vertex is the origin. This recovers a unique `n`-step SAW and a unique valid pair `(a,b)` with `a!=b`.

Hence there is an exact bijection and therefore

\[
\boxed{
\sigma_{n+2}
=
\sum_{\omega\in\Sigma_n}
\bigl(D_0(\omega)D_+(\omega)-C_n(\omega)\bigr).
}
\tag{5.3}
\]

Dividing by `sigma_n` gives

\[
\boxed{
\mathbb E_n[D_0D_+]
=r_n r_{n+1}+\mathbb E_n C_n.
}
\tag{5.4}
\]

This identity is exact and SAW-specific.

## 5.1 The collision correction vanishes

If `C_n>0`, the endpoint `omega_n` shares a nearest neighbour with `0`, hence has graph distance exactly `2` from `0` (for `n>0`). There are only eight such square-lattice sites, and `C_n<=2`. Therefore by the endpoint-delocalization theorem (2.1),

\[
0\le\mathbb E_n C_n
\le
16\sup_x\mathbb P_n(\omega_n=x)
\longrightarrow0.
\tag{5.5}
\]

Combining with Kesten,

\[
\boxed{
\mathbb E_n[D_0D_+]\longrightarrow\mu^2.
}
\tag{5.6}
\]

## 5.2 A pointwise degree inequality

Because `0<=D_0,D_+<=3`,

\[
(3-D_0)(3-D_+)\ge0,
\]

so pointwise

\[
D_0D_+\ge3D_0+3D_+-9.
\tag{5.7}
\]

Taking expectations and using (5.1),

\[
\mathbb E_n[D_0D_+]\ge6r_n-9.
\tag{5.8}
\]

Now (5.6) yields

\[
\boxed{
\limsup_{n\to\infty}r_n
\le
U:=\frac{\mu^2+9}{6}.
}
\tag{5.9}
\]

Since `r_n r_{n+1}->mu^2` and all subsequential upper limits of `r_{n+1}` are at most `U`,

\[
\boxed{
\liminf_{n\to\infty}r_n
\ge
L:=\frac{\mu^2}{U}
=
\frac{6\mu^2}{\mu^2+9}.
}
\tag{5.10}
\]

The two bounds are reciprocal around `mu`:

\[
\frac{U}{\mu}=\frac{\mu}{L}
=\frac{\mu^2+9}{6\mu}.
\tag{5.11}
\]

Therefore the frozen metric improves to

\[
\boxed{
0\le A_{\rm SAW}
\le
\log\!\left(\frac{\mu^2+9}{6\mu}\right)
=
\log\!\left(1+\frac{(3-\mu)^2}{6\mu}\right).
}
\tag{5.12}
\]

This is a strict improvement over (3.1), because the square lattice has `mu<3` and

\[
\frac{\mu^2+9}{6}<3.
\]

Using only the source's displayed rigorous lower bound `mu>=2.6256`, (5.12) is numerically below about `0.0089`, whereas the preceding bound `log(3/mu)` is below about `0.134`. The symbolic inequality (5.12), not the decimal, is the frozen mathematical movement.

**B25 outcome: metric movement.** It does not prove `A_SAW=0`, but it reduces the rigorous worst-case parity oscillation by more than an order of magnitude using actual square-lattice SAW geometry plus published endpoint delocalization.

# 6. B15 — break the symmetry: marked boundary state and endpoint correlation

The same counting suggests what a proof must now kill.

## 6.1 One-neighbour marked-state switching

Fix `e=e_1=(1,0)` and let

\[
A_n=\{\omega\in\Sigma_n:e\notin V(\omega)\}.
\]

The map

\[
(0,\omega_1,\ldots,\omega_n)
\mapsto
(0,e,e-\omega_1,\ldots,e-\omega_n)
\tag{6.1}
\]

is a bijection from `A_n` onto the `(n+1)`-step SAWs whose first step is `e`. It is the marked version of the reversal/occupancy identity from the preceding run.

Let

\[
q_{n+1}:=\mathbb P_{n+1}(\omega_{n+1}=e).
\]

When a legal endpoint extension is transported under (6.1), it remains legal except precisely when the old extension lands at `e`, because that mapped child would collide with the newly inserted initial vertex `0`. Exact child counting therefore gives

\[
\boxed{
\mathbb E_n[D_+\mid A_n]=r_{n+1}+4q_{n+1}.
}
\tag{6.2}
\]

Duminil-Copin--Glazman--Hammond--Manolescu imply `q_{n+1}->0`, so

\[
\mathbb E_n[D_+\mid e\notin V]
=r_{n+1}+o(1).
\tag{6.3}
\]

Thus conditioning on one microscopic origin-neighbour event changes the mean endpoint degree by essentially the full difference between the two consecutive ratios. A naive finite-state claim that the one-site mark contracts automatically is false as a proof route: the exact switching (6.1) transports the marked class to the next length rather than destroying its memory.

## 6.2 Exact covariance obstruction

Let

\[
X_n:=\mathbf 1_{\{e\in V(\omega)\}}.
\]

The preceding run proved

\[
p_n:=\mathbb E_n X_n=1-r_n/4.
\tag{6.4}
\]

Counting children with the mark gives

\[
p_{n+1}
=
\frac{\mathbb E_n[X_nD_+]}{r_n}+q_{n+1}.
\tag{6.5}
\]

Subtracting `p_n` and writing the numerator as a covariance,

\[
\boxed{
p_{n+1}-p_n
=
\frac{\operatorname{Cov}_n(X_n,D_+)}{r_n}
+q_{n+1}.
}
\tag{6.6}
\]

Equivalently,

\[
\boxed{
r_{n+1}-r_n
=-\frac{4}{r_n}\operatorname{Cov}_n(X_n,D_+)-4q_{n+1}.
}
\tag{6.7}
\]

Hence Question 1.3 would follow from the genuinely geometric decorrelation statement

\[
\operatorname{Cov}_n(X_n,D_+)\to0.
\tag{6.8}
\]

The two-end identity gives an even more symmetric version. From (5.1), (5.4), (5.5),

\[
\boxed{
\operatorname{Cov}_n(D_0,D_+)
=r_n(r_{n+1}-r_n)+o(1)
=\mu^2-r_n^2+o(1).
}
\tag{6.9}
\]

Thus any nontrivial two-cycle of the normalizers forces a nonvanishing, sign-alternating correlation between the local free-degree fields at the two ends of a long SAW. A proof of asymptotic decorrelation of these bounded endpoint observables would close the source question immediately.

I did **not** prove such decorrelation. The pattern theorem controls frequencies of local patterns but does not by itself give mixing between the two distant endpoint neighbourhoods under the uniform fixed-length SAW measure. That is the precise remaining gap exposed by B15.
