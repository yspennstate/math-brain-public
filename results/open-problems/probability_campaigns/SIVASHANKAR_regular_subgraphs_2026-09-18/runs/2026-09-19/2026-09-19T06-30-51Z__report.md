## 5. B5 — orientation-reuse parameter for the corrected all-signed problem

The previous self-audit showed exactly why positive piercing is not enough: an exact positive row and its reverse force an **equality**, not merely a hit.

This run therefore introduces the exact-gap reuse parameter

\[
z_{\rm ex}:=\#\{\text{distinct cycle atoms occurring as the unique gap of an exact zero-slack single-gap row}\}.
\]

The main result is that, on an **even** clean cycle in FIRST-SCALE, graph realizability forces

\[
\boxed{z_{\rm ex}\le2.}
\tag{5.1}
\]

This is not a scalar mass argument; it uses the common edge/component incidence of the exact Tutte barriers.

### 5.1 Setup

Let the even cactus cycle have nonempty atoms `A_0,...,A_{2m-1}`. For the positive exact rows, the previous orientation-compression theorem proves that all positive sides lie in one global parity class. Call the union of those parity atoms `Q`, and call the opposite parity union `N`.

For a canonical single-gap alternating row with gap atom `A_g`, define the signs to be `+` on `Q`, `-` on `N`, and `0` on the gap. Thus

- if `g in Q`, then `T=Q\A_g`, `S=N`;
- if `g in N`, then `T=Q`, `S=N\A_g`.

Let

\[
H:=|Q|-|N|
\]

in **original vertex cardinality**, not atom count. The row height is

\[
h_g=|T|-|S|=
\begin{cases}
H-|A_g|,&g\in Q,\\
H+|A_g|,&g\in N.
\end{cases}
\tag{5.2}
\]

For an exact zero-slack row, `d-q=0`, so `def_k=k h_g`.

### 5.2 All exact rows canonicalize to heights 0 or 1 and one gap parity

In FIRST-SCALE every positive barrier has height exactly 1. Therefore an exact row cannot have `|h_g|>=2`: if `h_g>=2` it is itself a positive barrier of forbidden height, while if `h_g<=-2` its reverse is.

If `h_g=-1`, its reverse is a positive exact row with positive side in the opposite parity class. The previous even-cycle majority theorem forbids positive rows in both parity classes. Hence after fixing the common positive parity `Q`, every exact single-gap row may be canonically oriented so that

\[
\boxed{h_g\in\{0,1\}.}
\tag{5.3}
\]

Moreover all exact gap atoms lie in the same parity class.

Indeed, if one positive row has gap `g in Q`, then by (5.2)

\[
H=1+|A_g|\ge2.
\]

Any row with a gap in `N` would have `h=H+|A|>=3`, impossible. Thus every exact gap is in `Q`.

Conversely, if a positive row has gap `g in N`, then

\[
H=1-|A_g|\le0.
\]

A row with gap in `Q` has `h=H-|A|<=-1`; equality `-1` would reverse to a positive row whose positive side lies in `N`, contradicting the common-parity theorem, while smaller values are already impossible. Thus every exact gap is in `N`.

So the exact family has one canonical sign pattern and one gap parity.

### 5.3 Gap-reuse lemma

**Lemma 5.1 (at most two exact gaps on the clean even cycle).** Under the setup above, three distinct exact gap atoms cannot occur.

**Proof.** Suppose for contradiction that exact rows `R_g,R_h,R_l` have three distinct gap atoms in the common gap parity. By symmetry use the case where the gap parity is `Q`; the `N` case is identical with signs reversed.

Thus for row `R_g`,

\[
T_g=Q\setminus A_g,
\qquad S_g=N,
\qquad U_g=U_*\cup A_g,
\]

where `U_*` denotes vertices outside the cycle atoms, which are zero-state in every row of the clean model.

Use the already proved exact-zero-slack structure: `S_g,T_g` are independent, and **every connected component of `B[U_g]` has exactly one boundary edge to `T_g` and exactly one boundary edge to `S_g`**.

Choose a component `C` of `B[U_g]` meeting the nonempty atom `A_g`. Let `e=ut` be its unique `T_g`-boundary edge, with `u in C` and `t in T_g`.

Consider row `R_h`. Here `A_g subset T_h`, while `A_h subset U_h` and all other `Q` atoms belong to `T_h`.

We claim `t in A_h`. If `u in A_g` and `t notin A_h`, then both endpoints of `e` lie in the independent set `T_h`, impossible. If `u in U_*`, take a path inside `C` from a vertex of `A_g` to `u`. Choose the **last** edge of this path that leaves `A_g` for `U_*`; after that edge the path remains in `U_*` until `u`, because `C subset U_* union A_g`. That last edge is one `T_h-U_h` boundary edge of the `U_h`-component containing `u`. If `t notin A_h`, then `t in T_h`, so `e` is a second `T_h` boundary edge of that same `U_h` component, contradicting exact zero-slack for row `R_h`. Therefore `t in A_h`.

Apply the identical argument with row `R_l`. It forces the same unique edge `e` to have `t in A_l`. Since the cycle atoms are disjoint and `h!=l`, this is impossible. Therefore there are at most two distinct exact gaps. ∎

This proof explicitly allows common outside zero-state vertices `U_*`; it does not assume the gap atom itself is an entire `U` component.

## 6. B10 — deterministic all-signed rounding for the exact even-cycle subsystem

The previous report's even-cycle two-vertex construction only pierced positive rows and could violate reverse rows. Lemma 5.1 is enough to repair that defect **for the entire exact zero-slack single-gap subsystem**.

For each exact row, the reverse row is also exact. Thus feasibility for both orientations is the equality

\[
|X\cap T|-|X\cap S|=h_g,
\qquad h_g\in\{0,1\}.
\tag{6.1}
\]

### Theorem 6.1 (exact all-signed even-cycle repair)

In the clean single-gap **even-cycle exact-zero-slack** cactus subsystem in FIRST-SCALE, there exists a vertex set `X` with

\[
\boxed{|X|\le2}
\tag{6.2}
\]

that satisfies **every exact row and its reverse**.

### Proof

There are at most two distinct canonical exact gap atoms by Lemma 5.1.

#### Case A: `H>=2`, so every exact gap lies in `Q`

A gap `g` has

\[
h_g=H-|A_g|\in\{0,1\}.
\]

If a zero-height exact gap `z` occurs and there is a positive gap `p`, choose one vertex from `A_z`. It is `U` in row `z`, hence contributes 0 there; in row `p` the atom `A_z` lies in `T_p`, hence contributes +1. Thus (6.1) holds for both rows. If only zero-height rows exist, `X=emptyset` works.

If all exact gaps are positive-height gaps, then either there is a `Q` atom which is not an exact gap, in which case one vertex from that atom contributes +1 to every row, or the only two `Q` atoms are the two exact gaps. In the latter case choose one vertex from each gap atom: each row ignores its own gap and sees the other selected vertex in `T`, so its signed value is exactly 1. A single positive gap cannot be the only `Q` atom, since then its `T` side would be empty and could not have height 1.

Hence `|X|<=2`.

#### Case B: `H<=0`, so every exact gap lies in `N`

A gap `g` has

\[
h_g=H+|A_g|\in\{0,1\}.
\]

If all exact gaps have height 1, choose one vertex from any `Q` atom. Such an atom exists because a height-one row has `T=Q` with one more vertex than its `S` side. The chosen vertex lies in `T` for every exact row, giving value 1.

If a zero-height gap `z` and a positive gap `p` both occur, choose one vertex `q` from `Q` and one vertex `v` from `A_p`. In row `p`, `v` is the gap and contributes 0 while `q` contributes +1. In row `z`, `q` contributes +1 and `v`, lying in `N\A_z=S_z`, contributes -1, for total 0. If only zero-height rows occur, again `X=emptyset` works.

Therefore `|X|<=2` in all cases. Since each canonical exact row attains exactly its height `h_g`, its reverse row is automatically satisfied as well. ∎

### Scope

This theorem repairs the precise self-audit defect from the preceding run **for exact zero-slack rows on an even single-gap cycle**. It is genuinely all-signed within that exact subsystem.

It does **not** yet prove `g_k(B)<=2` even in the full clean one-cycle graph, because nonexact rows with `rho=0,-1,...` are not covered by the exact-gap family. In particular a near-tight height-zero row can have `d-q in {2,4,...,k-2}` and `rho=0`; selecting a vertex in its `S` side can violate that row even though every exact equality is satisfied.
