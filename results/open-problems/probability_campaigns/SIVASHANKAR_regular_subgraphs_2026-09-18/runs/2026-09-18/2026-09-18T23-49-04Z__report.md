# B4 — prove something weaker, completely

## Theorem A: exact-scale fractional LOCAL-REPAIR

Define the continuous signed-barrier relaxation

\[
\operatorname{LP}_k(B):=
\min\Bigl\{
\sum_{v}x_v:
0\le x_v\le1,\quad
k(x(T)-x(S))\ge\operatorname{def}_k(S,T)
\ \forall S\cap T=\varnothing
\Bigr\}.
\tag{3}
\]

Then, for every connected bridgeless loopless `B` with `Delta(B)<=r` and every `r>2k`, one has

\[
\boxed{
\operatorname{LP}_k(B)\le \frac{D_r(B)}{r}.
}
\tag{4}
\]

More precisely, the explicit vector

\[
\boxed{x_v=\frac{s(v)}{r}}
\tag{5}
\]

satisfies **every** signed Tutte barrier inequality in (3), including the zero- and negative-deficiency inequalities.

### Proof

Fix disjoint `S,T`. Put `U=V(B)\setminus(S\cup T)`. Let

- `b=e_B(T,U)`,
- `c=e_B(S,U)`,
- `m_T=e(B[T])`,
- `m_S=e(B[S])`,
- `q=q(S,T)`.

Because `k` is even, each component counted by `q` has an odd, hence at least one, number of edges to `T`. Since `B` is bridgeless, the edge cut of every proper nonempty component of `B-(S\cup T)` has size at least two. Therefore each `q`-component contributes at least two edges in total to `S\cup T`, and summing gives

\[
 b+c\ge 2q.
\tag{6}
\]

Also each `q`-component contributes at least one `T`-edge, so

\[
q\le b\le d.
\tag{7}
\]

Now

\[
d=b+2m_T,
\]

whereas

\[
\Delta_d:=d_B(T)-d_B(S)
=b-c+2(m_T-m_S).
\]

Hence

\[
\begin{aligned}
2(d-q)-\Delta_d
&=2(b+2m_T-q)-\bigl(b-c+2m_T-2m_S\bigr)\\
&=b+c+2m_T+2m_S-2q\\
&\ge0
\end{aligned}
\tag{8}
\]

by (6). Thus

\[
d-q\ge \frac{\Delta_d}{2}.
\tag{9}
\]

If `Delta_d >= 0`, then `k/r<1/2` because `r>2k`, so

\[
d-q\ge \frac{\Delta_d}{2}
\ge \frac{k}{r}\Delta_d.
\tag{10}
\]

If `Delta_d<0`, (7) gives `d-q>=0`, hence again

\[
d-q\ge0>\frac{k}{r}\Delta_d.
\tag{11}
\]

So in all cases

\[
 d-q\ge \frac{k}{r}\Delta_d.
\tag{12}
\]

On the other hand,

\[
\begin{aligned}
s(T)-s(S)
&=\bigl(r|T|-d_B(T)\bigr)-\bigl(r|S|-d_B(S)\bigr)\\
&=rh-\Delta_d.
\end{aligned}
\tag{13}
\]

Combining (12) and (13),

\[
\begin{aligned}
\frac{k}{r}\bigl(s(T)-s(S)\bigr)
&=kh-\frac{k}{r}\Delta_d\\
&\ge kh-(d-q)\\
&=kh-d+q\\
&=\operatorname{def}_k(S,T).
\end{aligned}
\tag{14}
\]

But the left side of (14) is exactly `k(x(T)-x(S))` for `x_v=s(v)/r`. This proves feasibility of (5). Finally

\[
\sum_v x_v=\frac1r\sum_v s(v)=\frac{D}{r},
\]

which proves (4). `square`

# B24 — find the extremal object

Theorem A has a useful equality theory. Define the fractional slack

\[
\Sigma(S,T)
:=
\frac{k}{r}\bigl(s(T)-s(S)\bigr)-\operatorname{def}_k(S,T).
\tag{16}
\]

Using (12),

\[
\Sigma(S,T)
=d-q-\frac{k}{r}\Delta_d\ge0.
\tag{17}
\]

## Theorem B: zero-slack barriers are balanced two-edge-cut structures

For a nontrivial disjoint pair `(S,T)`, equality `Sigma(S,T)=0` can occur only when

\[
\Delta_d=d_B(T)-d_B(S)=0,
\qquad
 d_{B-S}(T)=q(S,T).
\tag{18}
\]

In that case, writing `U=V\setminus(S\cup T)`, all of the following hold:

1. `B[S]` and `B[T]` have no edges;
2. every component of `B[U]` is a `q`-component;
3. every component of `B[U]` has exactly one edge to `T` and exactly one edge to `S`;
4. there are no other `S-U` or `T-U` edges;
5. edges between `S` and `T` are unrestricted;
6. consequently every `U`-component is attached to `S\cup T` through an exact two-edge cut, one edge on each side.

### Proof

If `Delta_d<0`, then `d-q>=0` while `-(k/r)Delta_d>0`, so (17) is strictly positive. If `Delta_d>0`, then (9) and `k/r<1/2` give

\[
\Sigma(S,T)
\ge\left(\frac12-\frac{k}{r}\right)\Delta_d>0.
\]

Hence zero slack forces `Delta_d=0`. Equation (17) then forces `d=q`.

But `d=b+2m_T`, while `q<=b`. Hence `d=q` implies

\[
b=q,\qquad m_T=0.
\tag{19}
\]

The degree equality `Delta_d=0` says

\[
0=b-c+2(m_T-m_S)=q-c-2m_S,
\]

so

\[
c+2m_S=q.
\tag{20}
\]

On the other hand, the bridgeless cut count (6) and `b=q` imply `c>=q`. Combining with (20) gives

\[
c=q,\qquad m_S=0.
\tag{21}
\]

Since `b=q`, the `q` counted components, each of which has at least one edge to `T`, exhaust all `T-U` edges and each receives exactly one. Since `c=q` and each such component already has one `T` cut edge, bridgelessness forces at least one `S` cut edge to it; the total `S-U` edge count is exactly `q`, so each receives exactly one and no other component receives any `S` or `T` edge. Connectedness excludes an uncounted `U`-component disconnected from `S\cup T`. This proves the structure. `square`

For every zero-slack pair, `Delta_d=0`, so (13) gives

\[
s(T)-s(S)=rh,
\]

and (1),(18) give

\[
\operatorname{def}_k(S,T)=kh.
\tag{22}
\]

Thus the hard equality constraints are not arbitrary set-cover constraints: they arise from a rigid balanced two-sided attachment geometry. The complete bipartite calibrations are the degenerate `U=empty` members of this equality class.

### Extremal interpretation

This changes the extremal picture. The complete bipartite examples are not merely lower-bound witnesses; they lie exactly on the fractional face singled out by Theorem B. Therefore any counterexample to a constant-factor `LOCAL-REPAIR` rounding theorem must create a genuine integrality gap among a family of balanced two-edge-cut / bipartite-like tight constraints, or among near-tight perturbations of them. Scalar deficiency alone cannot be the missing obstruction.

This also explains why the first-supercritical temptation `g_k(B)<=1` is not yet proved. When `R<D<=2R`, every **positive** original barrier has height `h=1`, but after choosing an omitted vertex a previously zero or negative barrier can become positive. The exact system (2) never permits us to discard those constraints. The old positive-barrier-only reasoning was therefore insufficient.
