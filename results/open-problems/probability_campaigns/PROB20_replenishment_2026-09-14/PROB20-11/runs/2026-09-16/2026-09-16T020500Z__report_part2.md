## 2. Exact quotient geometry and monotone cost

Work in

\[
G=\mathbb F_2^{12}/\langle\mathbf 1\rangle,
\qquad |G|=2048,
\]

represented by 11-bit words with folded distance

\[
\delta(x,y)=\min\{\operatorname{wt}(x+y),12-\operatorname{wt}(x+y)\}.
\]

A folded radius-3 ball has 299 quotient points. Because length 12 is even, parity is well defined on the quotient; the two parity halves each contain 1024 points.

For a concrete partial center set, define on each parity half `H`:

- `d_H`: the sum, over chosen triples, of the deficit between the exact orbitwise maximum triple intersection and the actual triple intersection;
- `E_H`: the higher-multiplicity third-Bonferroni excess

\[
E_H=\sum_{x\in H:\,m(x)>0}\binom{m(x)-1}{3}.
\]

For a full cover in a coarse state with half-bound `U_H`, the exact identity is

\[
\boxed{d_H+E_H=U_H-1024.}
\]

Both terms are monotone as centers are added. Therefore for a state oriented as `U=(1024,1025)`, every partial configuration belonging to a genuine cover must satisfy

\[
d_E+E_E=0,
\qquad
 d_O+E_O\le1.
\]

In particular, one positive unit on the zero-slack half is fatal and cannot be repaired by later isolates.

The new certificate recomputes all 2048 balls and all realizable parity/distance triple-intersection maxima from scratch using exact `std::bitset<2048>` arithmetic. It separately recomputes the coarse `U` value for each of the six states and asserts `U=(1024,1025)` before searching embeddings.

## 4. Exact normalization and exhaustive embedding search

For each state the certificate chooses a labeled close-edge vertex of maximum graph degree as the root. Any embedding is translated so that this root is the quotient origin. If the root has odd parity, translation globally flips all center parities; the code correspondingly replaces `neven` by `12-neven` and swaps the two half-budgets. Distances are unchanged.

A chosen close neighbor of the root is then fixed to the canonical coordinate subset

\[
\{1,\ldots,d\}
\]

for its folded distance `d<=4`. This loses no embeddings: the coordinate-permutation stabilizer of the origin is transitive on antipodal quotient classes at each folded distance `d<6`.

The remaining active vertices are exhaustively assigned quotient points satisfying their exact distances to every previously chosen vertex. At each branch the code updates:

1. every new exact triple-intersection deficit;
2. the exact increment in `E_H`, using the identity
   \[
   \binom{m}{3}-\binom{m-1}{3}=\binom{m-1}{2}
   \]
   when a ball raises an existing point multiplicity from `m` to `m+1`;
3. the zero/one parity-half budgets.

A branch is pruned only when the monotone exact cost exceeds the final state's permitted budget.
