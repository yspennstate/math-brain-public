## 2. Retained endpoint notation and identities

Write
\[
S_n=\xi_1+\cdots+\xi_n,\qquad
a_n=\Pr(S_n=n-1),\qquad \lambda_n=-\log a_n,
\]
and let
\[
Q_n:=\mathcal L((\xi_1,\ldots,\xi_n)\mid S_n=n-1).
\]
The cyclic lemma gives, for the root degree \(D_n=\ell_1(T_n)\),
\[
\Pr(D_n=d)=\frac n{n-1}d\pi_d
\frac{\Pr(S_{n-1}=n-1-d)}{a_n},
\tag{2.1}
\]
and hence
\[
\boxed{
\mathbb E[D_n^r;D_n>K]
=\frac n{n-1}
\mathbb E_{Q_n}[\xi_1^q;\xi_1>K].
}
\tag{2.2}
\]
Earlier verified work gives the arbitrary-law denominator estimate
\[
\lambda_n=o\!\left(n^{(1-r)/(1+r)}\right),
\tag{2.3}
\]
root UI through the entropy scale \((n/(\lambda_n+1))^{1/q}\), a distribution-dependent large-width escape theorem for every fixed level, canonical \(W_q\)-recentering for every sublinear residual shift, finite-core smoothing, renewal/Palm switching, and exact finite-depth random-prefix reductions.

Define the negative offspring transform and its one-sided Legendre transform
\[
\Lambda(\theta):=\log\mathbb E e^{-\theta(\xi-1)},\qquad
H(y):=\sup_{\theta\ge0}\{\theta y-\Lambda(\theta)\}.
\tag{2.4}
\]
Finite \(q\)-moment and infinite variance imply, in the verified dependency chain,
\[
\Lambda(\theta)=o(\theta^q),\qquad
\frac{H(y)}{y^{q/(q-1)}}\to\infty
\quad(y\downarrow0).
\tag{2.5}
\]

The preceding report proved the following factorial inequality for an arbitrary soft mark \(g:\mathbb Z_{\ge0}\to[0,1]\). With
\[
p_g=\mathbb Eg(\xi),\qquad q_{n,g}=\mathbb E_{Q_n}g(\xi_1),
\]
\[
M_g(\theta)=\mathbb E[g(\xi)e^{-\theta(\xi-1)}],
\]
if \(nq_{n,g}\ge2m\), then
\[
\log\frac{q_{n,g}}{2p_g}
\le
\frac{\lambda_n-\theta}{m}
+\frac{n-m}{m}\Lambda(\theta)
+\log\frac{M_g(\theta)}{p_g}.
\tag{2.6}
\]
The new result below is the complementary **one-mark** estimate. Unlike (2.6), it has no multiplicity hypothesis, so it remains effective exactly at the natural one-big-jump scale where the expected number of marks is only order one.

# 3. NEW: exact single-mark Chernoff inequality

For any soft mark \(g:\mathbb Z_{\ge0}\to[0,1]\) with \(p_g>0\), define
\[
\Psi_g(\theta):=-\log\frac{M_g(\theta)}{p_g}
\tag{3.1}
\]
and
\[
\mathcal J_{n,g}
:=
\sup_{\theta\ge0}
\left\{
\theta-(n-1)\Lambda(\theta)+\Psi_g(\theta)
\right\}.
\tag{3.2}
\]

### Theorem 3.1 — single-mark exact-conditioning bound

For every admissible \(n\),
\[
\boxed{
q_{n,g}\le p_g\exp\{\lambda_n-\mathcal J_{n,g}\}.
}
\tag{3.3}
\]
No condition of the form \(nq_{n,g}\to\infty\) is required.

### Proof

By definition of \(Q_n\),
\[
q_{n,g}
=
\frac{1}{a_n}
\mathbb E[g(\xi_1);S_n=n-1].
\tag{3.4}
\]
On \(S_n=n-1\),
\[
\sum_{i=1}^n(\xi_i-1)=-1,
\]
so for every \(\theta\ge0\), identically on the conditioning event,
\[
1=e^{-\theta}
\exp\!\left[-\theta\sum_{i=1}^n(\xi_i-1)\right].
\]
Hence
\[
\begin{aligned}
\mathbb E[g(\xi_1);S_n=n-1]
&\le
 e^{-\theta}
 \mathbb E[g(\xi)e^{-\theta(\xi-1)}]
 \left(\mathbb E e^{-\theta(\xi-1)}\right)^{n-1}\\
&=e^{-\theta}M_g(\theta)e^{(n-1)\Lambda(\theta)}.
\end{aligned}
\tag{3.5}
\]
Since \(a_n=e^{-\lambda_n}\), divide by \(a_n p_g\), take logarithms, and optimize over \(\theta\). This proves (3.3). \(\square\)

### Hard-support consequence

If the mark is supported on \(\{d,d+1,\ldots\}\), then \(\xi-1\ge d-1\) whenever \(g(\xi)>0\), so
\[
\Psi_g(\theta)\ge\theta(d-1).
\]
Therefore
\[
\mathcal J_{n,g}
\ge
(n-1)H\!\left(\frac d{n-1}\right),
\]
and
\[
\boxed{
q_{n,g}
\le
p_g
\exp\!\left\{
\lambda_n-(n-1)H\!\left(\frac d{n-1}\right)
\right\}.
}
\tag{3.6}
\]
The extra \(+1\) in the eventual tail cutoff below is exact: a mark supported on \(\{\xi>K\}\) is supported on integers \(d\ge K+1\).

# 4. NEW: aggregate root q-tail bound with no multiplicity assumption

Define the ordinary \(q\)-tail
\[
R_q(K):=\mathbb E[\xi^q;\xi>K].
\tag{4.1}
\]
For \(K<n\), use the soft mark
\[
g_{K,n}(x)
:=
\mathbf1_{\{x>K\}}
\min\left\{1,\left(\frac{x}{n}\right)^q\right\}.
\tag{4.2}
\]
Under \(Q_n\), every coordinate is at most \(n-1\), so
\[
n^q q_{n,g_{K,n}}
=
\mathbb E_{Q_n}[\xi_1^q;\xi_1>K].
\tag{4.3}
\]
On the ordinary law,
\[
n^q p_{g_{K,n}}
=
\mathbb E[\min(\xi^q,n^q);\xi>K]
\le R_q(K).
\tag{4.4}
\]
The mark is supported on \(\{K+1,K+2,\ldots\}\). Applying (3.6) yields:

### Theorem 4.1 — whole-tail Cramér certificate

For every admissible \(n\) and every integer \(0\le K<n\),
\[
\boxed{
\mathbb E_{Q_n}[\xi_1^q;\xi_1>K]
\le
R_q(K)
\exp\!\left\{
\lambda_n-(n-1)
H\!\left(\frac{K+1}{n-1}\right)
\right\}.
}
\tag{4.5}
\]
Consequently, by the cyclic identity,
\[
\boxed{
\mathbb E[D_n^r;D_n>K]
\le
\frac n{n-1}R_q(K)
\exp\!\left\{
\lambda_n-(n-1)
H\!\left(\frac{K+1}{n-1}\right)
\right\}.
}
\tag{4.6}
\]

This is an aggregate bound on the **entire root fractional tail**, not a sum of separate shell estimates. It also has no expected-mark-count requirement. Thus it directly covers the order-one-multiplicity regime left open by the factorial argument.

A sharper version retains the actual \(q\)-weighted tail transform. Put
\[
W_P(K,n)=\mathbb E[\min(\xi^q,n^q);\xi>K],
\]
\[
\Psi_{K,n}(\theta)
:=-\log
\frac{
\mathbb E[\min(\xi^q,n^q)\mathbf1_{\{\xi>K\}}
 e^{-\theta(\xi-1)}]
}{W_P(K,n)}.
\tag{4.7}
\]
Then the proof actually gives
\[
\boxed{
\mathbb E_{Q_n}[\xi_1^q;\xi_1>K]
\le
W_P(K,n)
\exp\{\lambda_n-\mathcal J_{n;K}\},
}
\tag{4.8}
\]
where
\[
\mathcal J_{n;K}
=
\sup_{\theta\ge0}
\{\theta-(n-1)\Lambda(\theta)+\Psi_{K,n}(\theta)\}.
\tag{4.9}
\]
Equation (4.5) is the support-only lower bound
\[
\mathcal J_{n;K}\ge(n-1)H((K+1)/(n-1)).
\]
For a lacunary law, (4.8) can be strictly stronger because \(\Psi_{K,n}\) remembers where the \(q\)-tail mass actually sits.

# 5. NEW: necessary central-valley plus ordinary-tail certificate for any root counterexample

Theorem 4.1 gives a clean adversarial consequence.

### Proposition 5.1 — necessary certificate for root UI failure

If \(\{D_n^r\}\) is not uniformly integrable along admissible \(n\), then there exist \(\varepsilon>0\), admissible \(n_j\to\infty\), and integers \(K_j\to\infty\) with \(K_j<n_j\) such that
\[
\mathbb E_{Q_{n_j}}[\xi_1^q;\xi_1>K_j]\ge\varepsilon
\tag{5.1}
\]
and
\[
\boxed{
\lambda_{n_j}
\ge
(n_j-1)H\!\left(\frac{K_j+1}{n_j-1}\right)
+
\log\frac{\varepsilon}{R_q(K_j)}.
}
\tag{5.2}
\]
In particular, since \(R_q(K_j)\to0\), the conditioning denominator must pay not only the lower-deviation/Cramér cost but also the diverging reciprocal ordinary \(q\)-tail cost.

### Proof

Non-UI and (2.2) provide \(\varepsilon>0\) and sequences \(K_j,n_j\) with (5.1), after decreasing \(\varepsilon\) by an inessential fixed factor. Apply (4.5) and rearrange. \(\square\)

This sharpens the earlier qualitative “nearby central local valley” certificate. A surviving root counterexample must synchronize three effects in one fixed law:

1. a small exact central atom \(a_{n_j}=e^{-\lambda_{n_j}}\);
2. enough Cramér budget to support degrees above \(K_j\);
3. amplification by at least the reciprocal of the vanishing ordinary \(q\)-tail \(R_q(K_j)\).

A merely lacunary tail or a merely small central atom is not sufficient by itself.

# 6. NEW: exact two-regime dichotomy with the factorial theorem

The single-mark theorem fills the logical gap of the preceding factorial theorem: it still works when there are only order-one expected marks. Combining the two gives an explicit necessary dichotomy for any anomalous tail.

For \(K<D\), retain the winsorized quantities
\[
W_Q(n;K,D)
=
\mathbb E_{Q_n}[\min(\xi_1^q,D^q);\xi_1>K],
\]
\[
W_P(K,D)
=
\mathbb E[\min(\xi^q,D^q);\xi>K].
\tag{6.1}
\]
Suppose
\[
w:=W_Q(n;K,D)>0,
\qquad
\frac{nw}{D^q}\ge8,
\tag{6.2}
\]
and put
\[
m:=\left\lfloor\frac{nw}{4D^q}\right\rfloor.
\tag{6.3}
\]
Because the mark is supported on \(\{\xi>K\}\), the exact factorial inequality (2.6), multiplied by \(m\) and optimized in \(\theta\), yields the **exact certificate**
\[
\boxed{
\lambda_n
\ge
m\log\frac{w}{2W_P(K,D)}
+
(n-m)
H\!\left(\frac{mK+1}{n-m}\right).
}
\tag{6.4}
\]
Indeed, before optimization one has
\[
m\log\frac{w}{2W_P(K,D)}
\le
\lambda_n+(n-m)\Lambda(\theta)-\theta(mK+1)
\]
for every \(\theta\ge0\).

Now suppose a root non-UI sequence has conditioned \(q\)-tail at least \(\varepsilon\). For each such \((n,K)\), choose the least integer \(D\le n\) for which
\[
W_Q(n;K,D)\ge\varepsilon/2.
\tag{6.5}
\]
Such a \(D\) exists because \(W_Q(n;K,n)\) is the full conditioned \(q\)-tail.

Then exactly one of the following occurs:

**Regime A: order-one multiplicity / natural scale.**
\[
\frac{nW_Q(n;K,D)}{D^q}<8.
\]
Since \(W_Q\ge\varepsilon/2\),
\[
\boxed{
D^q>\frac{\varepsilon n}{16}.
}
\tag{6.6}
\]
Thus any anomaly escaping factorial replication has already reached the natural scale \(D\gtrsim n^{1/q}\). It is nevertheless still subject to the single-mark whole-tail certificate (5.2)/(4.8).

**Regime B: replicable tail.** If \(nW_Q/D^q\ge8\), then (6.4) applies. Once \(K\) is large enough that \(W_P(K,D)<w/2\), its first term alone gives
\[
\lambda_n
\ge
m\log\frac{w}{2W_P(K,D)}.
\tag{6.7}
\]
Since (6.2) implies
\[
m\ge\frac{nw}{8D^q},
\]
we obtain
\[
\boxed{
D^q
\ge
\frac{nw}{8\lambda_n}
\log\frac{w}{2W_P(K,D)}.
}
\tag{6.8}
\]
For a fixed positive anomalous tail mass, \(W_P(K,D)\le R_q(K)\to0\), so the lower scale forced by replication contains an additional diverging factor \(\log(1/R_q(K))\) beyond the basic entropy scale \((n/\lambda_n)^{1/q}\).

Equations (6.6) and (6.8) are a useful quantitative obstruction to lacunary counterexamples. Below the natural scale, the anomaly must replicate often enough that the conditioning denominator pays a multiple of the reciprocal ordinary-tail logarithm; at or above the natural scale, replication is no longer available, but the one-mark theorem still charges the whole tail once.

This is a necessary-certificate theorem, not a proof of UI. The remaining possibility is that \(\lambda_n\) and the exact local valley are themselves large enough to finance these costs along a carefully synchronized subsequence.

# 7. Relation to the all-level problem

No root-only result is promoted to the requested every-fixed-level theorem.

For fixed \(k\), previous verified work gives the exact random-prefix representation. If
\[
A=N_k=\sum_{j<k}Z_j,\qquad B=Z_k,
\]
\[
X=|T|,\qquad U=(X-1)/h,\qquad u_M=\Pr(U=M),
\]
and
\[
C=(A+B-1)/h,\qquad n=1+hM,
\]
then the exact prefix likelihood is
\[
R_M(A,B)=\frac{u^{*B}_{M-C}}{u_M}.
\tag{7.1}
\]
For every fixed feasible prefix, \(R_M(A,B)\to B\), and Scheffé gives finite-depth total-variation convergence to the Kesten prefix. The endpoint is the \(B^r\)-weighted upgrade, with
\[
\mathbb E_{\widehat{\mathsf P}_k}B^r=\mathbb E Z_k^q<\infty.
\]

Earlier work already supplies the analogous high-boundary Cramér estimate with the actual generation-tail budget
\[
\tau_k(j)=\mathbb E[Z_k^q;Z_k\ge j].
\]
The new single-mark theorem is an iid-coordinate statement for the allocation representation and therefore does not, by itself, prove the weighted Scheffé upgrade for random \(B=Z_k\). The all-level missing step remains a weighted random-prefix/local-forest theorem below the moving Cramér-safe cutoff.

The new root dichotomy is still useful for the all-level attack because it identifies what any successful prefix theorem must reproduce: a one-payment tail bound when the dangerous boundary count has order-one multiplicity, plus factorial/replication control when it occurs many times.

# 11. Failed / insufficient routes retained

1. Bounded expectations do not imply UI.
2. Fixed-shift strong ratios do not control a diverging mesoscopic shift.
3. Generic Kesten bounds are exponential in the convolution count and exceed the endpoint first-moment budget.
4. Total variation or KL convergence controls bounded observables, not the endpoint \(q\)-moment by itself.
5. A canonical triangular local CLT cannot be assumed: \(W_q\)-convergence of the tilted one-site laws does not automatically verify a uniform Lindeberg/local-limit hypothesis.
6. Hard-shell factorial replication alone misses order-one multiplicity at \(d\asymp n^{1/q}\); Theorem 3.1/4.1 now supplies a complementary first-factorial-moment bound there, but its exponent may still be financed by an unusually small central atom.
7. A small central atom alone is not a counterexample; it must be synchronized with a vanishing ordinary \(q\)-tail and the exact Cramér cost as in (5.2).

# 12. Next attack

The next proof attempt should use the two-regime certificate quantitatively rather than return to pointwise local ratios.

**Root route.** Assume a tail anomaly \(\varepsilon\). Let \(D\) be the least winsorization scale carrying half that conditioned \(q\)-mass. If \(D^q\ll n\), (6.4) forces repeated copies and makes \(\lambda_n\) pay both a Cramér term and a multiple of \(\log(1/R_q(K))\). If \(D^q\gtrsim n\), use the exact single-mark transform (4.8), not only the support bound (4.5), to exploit the true location of the ordinary \(q\)-tail. The goal is to show that no fixed finite-\(q\) law can finance both regimes along infinitely many admissible \(n\).

A particularly concrete target is to prove a uniform implication of the form
\[
\mathbb E_{Q_n}[\xi_1^q;\xi_1>K]\ge\varepsilon
\quad\Longrightarrow\quad
\lambda_n\ge \mathcal L_{\varepsilon}(n,K),
\]
where the lower bound \(\mathcal L_{\varepsilon}\) obtained by optimizing between (4.8) and (6.4) eventually contradicts the existing central-atom upper bound for every \(K\to\infty\). The current run identifies the exact two ingredients of that optimization.

**Counterexample route.** A lacunary construction must now arrange that the exact central atom is small enough to dominate both
\[
(n-1)H((K+1)/(n-1))
\]
and
\[
\log(1/R_q(K)),
\]
while, below natural scale, also paying the replicated version (6.4). This is substantially more restrictive than the earlier missing-mean or single-shell designs.

**Every-level route.** Once the root optimization is understood, transplant the same first-mark versus replicated-mark split to the random boundary count in the exact prefix/forest representation, retaining the actual generation tail \(\tau_k(j)=\mathbb E[Z_k^q;Z_k\ge j]\) before taking any supremum.

No numerical experiment is promoted as proof in this report.
