## 3. The colored pair-partition polytope

For an integer `m>=1`, let the ground set have `2m` vertices and the label/color set be `[m]`. A deterministic state is a map

`sigma : [2m] -> [m]`

such that every label occurs exactly twice. Equivalently, for each color `c`, the two-point fibre

`E_c^sigma = sigma^{-1}(c)`

is one colored edge, and the `m` colored edges partition the ground set.

Let `x_sigma` be the `0/1` incidence vector on colored edges `(c,e)`. Define

`P_m = conv{x_sigma}`.

The K6 polytope used throughout the `(2,2,2)` analysis is exactly `P_3`: it has 90 vertices in 45 coordinates and affine dimension 37.

## 4. New exact theorem: general adjacency criterion

Given two deterministic states `sigma,tau`, construct a graph `G(sigma,tau)` on the **color labels** `[m]` as follows. For every ground vertex `v`, add one undirected edge between the labels

`sigma(v)` and `tau(v)`.

Loops and parallel edges are allowed. Call a connected component **nontrivial** if it contains at least two color labels. Let

`r(sigma,tau)`

be the number of nontrivial connected components.

### Theorem 4.1

For distinct vertices `x_sigma,x_tau` of `P_m`, the segment

`conv{x_sigma,x_tau}`

is an edge of `P_m` **if and only if**

`r(sigma,tau)=1`.

More precisely, the linear functional

`w = x_sigma+x_tau`

exposes a face containing exactly

`2^{r(sigma,tau)}`

distinct deterministic states. Those states are obtained by independently choosing, on each nontrivial connected component of `G(sigma,tau)`, whether to use all the `sigma` colored pairs or all the `tau` colored pairs.

### Proof

A state supported on the coordinate union

`supp(x_sigma) union supp(x_tau)`

must, for each color `c`, choose either the colored edge `E_c^sigma` or the colored edge `E_c^tau` (if they coincide, the two choices are identical).

Let `S subset [m]` be the set of colors for which the `tau` edge is chosen instead of the `sigma` edge.

Fix a ground vertex `v`. It is covered by the chosen `sigma` edge exactly when

`sigma(v) notin S`,

and it is covered by the chosen `tau` edge exactly when

`tau(v) in S`.

For the chosen colored edges to form a partition, `v` must be covered exactly once. Therefore

`1_{sigma(v) notin S} + 1_{tau(v) in S} = 1`,

which is equivalent to

`1_{sigma(v) in S} = 1_{tau(v) in S}`.                         (4.1)

Equation (4.1) must hold for every ground vertex. By construction of `G(sigma,tau)`, this says exactly that the indicator of `S` is constant on every connected component of `G(sigma,tau)`. Hence `S` is a union of connected components.

A singleton component `{c}` means every ground vertex having color `c` in one state also has color `c` in the other; because each color occurs twice, `E_c^sigma=E_c^tau`. Switching such a singleton component changes no colored edge. Each nontrivial component, by contrast, gives one genuine binary choice. Thus the number of distinct supported deterministic states is exactly

`2^r`, where `r=r(sigma,tau)`.                                 (4.2)

It remains to identify the exposed face of `w=x_sigma+x_tau`.

Let `s` be the number of colored edges common to `sigma` and `tau`. The coordinates of `w` are:

- `2` on common colored edges;
- `1` on noncommon colored edges belonging to one of the two states;
- `0` elsewhere.

Every deterministic state contains exactly `m` colored edges. Therefore, for any state `rho`,

`<w,x_rho> <= m+s`,

with equality only if `rho` contains all `s` common colored edges and every other selected edge lies in the above coordinate union. Both `sigma` and `tau` attain `m+s`. Hence the maximizers of `w` are exactly the supported hybrid states counted in (4.2).

If `r=1`, that exposed face has exactly two vertices, `x_sigma` and `x_tau`, so their segment is an edge.

If `r>=2`, choose a nonempty proper union `S` of nontrivial components. Let `rho_S` choose `tau` on `S` and `sigma` off `S`, and let `rho_{S^c}` make the complementary choices. Then, coordinatewise,

`x_sigma+x_tau = x_{rho_S}+x_{rho_{S^c}}`,                    (4.3)

with both `rho_S,rho_{S^c}` distinct from `sigma,tau`. Thus the midpoint of the alleged edge has a second convex representation, so `conv{x_sigma,x_tau}` is not an edge.

This proves the criterion. QED.

## 5. K6 consequence: the 90-vertex polytope is 2-neighborly

### Corollary 5.1

Every pair of distinct vertices of `P_3` is adjacent. Thus the 1-skeleton of the K6 colored-perfect-matching polytope is the complete graph `K_90`, with exactly

`C(90,2)=4005`

edges.

### Proof

For `m=3`, any two distinct states have at least one nontrivial component in `G(sigma,tau)`. Two disjoint nontrivial components would each contain at least two color labels, requiring at least four labels. There are only three. Hence `r(sigma,tau)=1`, and Theorem 4.1 applies. QED.

This is stronger than the earlier numerical observation that all 89 state-difference rays at one reference vertex appeared extreme: it is an exact combinatorial proof for all 4,005 pairs.
