# PROB20-12 — no positive linear slack retraction for the K6 core

**SOLUTION STATUS: PARTIAL.** The unrestricted Lyons union-coupling question remains open. This run returns to the first genuinely hard finite core, the rank profile `(2,2,2)` on six sites, and proves a new exact obstruction to a tempting Farkas/facet-completeness strategy.

Let `Omega` be the 90 deterministic balanced three-colorings of six sites (two sites of each color), and let `P_3` be their 90-vertex colored-perfect-matching marginal polytope in `R^45`. Let `L` be the 38-dimensional space of evaluation vectors on `Omega` of affine functions on `P_3`. The cone of valid inequality slacks is exactly `L intersect R_+^90`.

The new theorem is:

> **There is no positive linear retraction `T:R^90 -> L`.**
>
> Equivalently, there is no entrywise-nonnegative linear operator whose image lies in `L` and which fixes every vector in `L` pointwise.

The proof is exact and uses only the `S_6 x S_3` symmetry and four colored-edge coordinate functions. It is not a numerical nonexistence claim.

This does **not** prove or disprove completeness of the currently archived 4,450 K6 facet inequalities, and it does not prove or disprove the Lyons coupling. What it does rule out is a broad linear proof template: one cannot build a globally positive linear “slack repair” / positive projection onto the affine slack space. In particular, any universal decomposition of valid slacks into facet rays must use genuinely piecewise/nonlinear dependence on the slack vector, or at least a coefficient rule that is not positive on the whole ambient orthant.

## 3. The K6 affine slack space

Let

`Omega = { sigma:{0,...,5}->{0,1,2} : |sigma^{-1}(c)|=2 for c=0,1,2 }`.

Thus `|Omega|=90`.

For `sigma in Omega`, let `x_sigma in {0,1}^45` be the colored-edge incidence vector: for each color `c`, the unique coordinate `(c,e)` with `e=sigma^{-1}(c)` equals one.

Let

`P_3 = conv{x_sigma : sigma in Omega}`.

The affine dimension is 37. Define the affine-evaluation space

`L = { (beta + <a,x_sigma>)_{sigma in Omega} : beta in R, a in R^45 }`.

Hence

`dim L = 38`.

A linear inequality `<a,x> <= beta` has slack vector

`s_sigma = beta-<a,x_sigma>`.

Therefore the cone of all valid inequality slacks is exactly

`K = L intersect R_+^90`.

The existing 4,450 exact K6 facets provide 4,450 rays in this cone. Facet completeness is the assertion that those rays generate all of `K`.

## 4. Why a positive retraction would be an attractive proof device

Suppose one could construct a positive linear map

`T:R^90 -> L`

with

`T|_L = identity_L`.

Then every valid slack `s in K` would satisfy `s=T s`, while positivity would ensure that nonnegative ambient data remain nonnegative after applying `T`. More strongly, any proposed decomposition of every slack by a fixed coordinatewise-nonnegative linear coefficient rule through nonnegative slack rays would factor through such a positive retraction.

The theorem below shows that this entire ambient-positive linear strategy is impossible already for the K6 core.

## 5. NEW theorem — no positive linear retraction

### Theorem 5.1

There is no linear map

`T:R^Omega -> L`

such that

1. `T f=f` for every `f in L`; and
2. `T` is positive for the coordinatewise cone, i.e. `f>=0` implies `Tf>=0`.

Equivalently, `L` is not the range of a positive linear projection on `R^90`.

### Proof

Let

`G=S_6 x S_3`

act on `Omega` by permuting the six sites and the three color labels. This action preserves `P_3` and therefore preserves `L`.

Assume for contradiction that a positive retraction `T` exists. Average it over the finite group:

`Tbar = (1/|G|) sum_{g in G} rho(g) T rho(g)^{-1}`.          (5.1)

Every summand is positive, so `Tbar` is positive. Because `L` is `G`-invariant and every summand maps into `L`, `ran(Tbar) subset L`. If `f in L`, then `rho(g)^{-1}f in L`, so `T rho(g)^{-1}f=rho(g)^{-1}f`; consequently `Tbar f=f`. Finally `Tbar` commutes with the full `G` action.

Thus it is enough to rule out a **G-equivariant positive retraction**.

Fix the base state

`sigma_0 = 001122`,

i.e. sites `0,1` have color 0, sites `2,3` color 1, and sites `4,5` color 2.

The stabilizer `G_0` of `sigma_0` has order 48. Its orbits on `Omega` are exactly eight sets `O_0,...,O_7`, with the following sizes and canonical representatives:

| orbit | size | representative |
|---:|---:|---|
| `O_0` | 1 | `001122` |
| `O_1` | 2 | `112200` |
| `O_2` | 3 | `002211` |
| `O_3` | 8 | `120201` |
| `O_4` | 12 | `001212` |
| `O_5` | 16 | `011202` |
| `O_6` | 24 | `010212` |
| `O_7` | 24 | `012201` |

Because `Tbar` is `G`-equivariant, the row of its matrix at `sigma_0` is constant on these eight stabilizer orbits. Write that constant value as

`t_r >= 0` on `O_r`.                                          (5.2)

The inequalities follow from positivity of `Tbar`: a positive linear map on the coordinatewise ordered space has an entrywise nonnegative matrix.

Now use only four coordinate functions in `L`. For a colored edge `(c,e)`, let

`f_{c,e}(sigma)=1_{sigma^{-1}(c)=e}`.

Each `f_{c,e}` is one of the 45 affine coordinate functions, hence `Tbar f_{c,e}=f_{c,e}`.

For the four color-0 edges `01,02,23,24`, the exact counts of states in each orbit having that colored edge are:

| orbit | `#(0:01)` | `#(0:02)` | `#(0:23)` | `#(0:24)` |
|---:|---:|---:|---:|---:|
| `O_0` | 1 | 0 | 0 | 0 |
| `O_1` | 0 | 0 | 1 | 0 |
| `O_2` | 1 | 0 | 1 | 0 |
| `O_3` | 0 | 0 | 0 | 2 |
| `O_4` | 4 | 1 | 0 | 0 |
| `O_5` | 0 | 2 | 0 | 0 |
| `O_6` | 0 | 2 | 0 | 2 |
| `O_7` | 0 | 1 | 4 | 2 |

Evaluate `Tbar f=f` at the base state `sigma_0`.

Because `sigma_0` **does** have color-0 edge `01`,

`t_0 + t_2 + 4 t_4 = 1`.                                      (5.3)

Because it does **not** have color-0 edge `02`,

`t_4 + 2 t_5 + 2 t_6 + t_7 = 0`.                              (5.4)

Because it does **not** have color-0 edge `23`,

`t_1 + t_2 + 4 t_7 = 0`.                                      (5.5)

Because it does **not** have color-0 edge `24`,

`2 t_3 + 2 t_6 + 2 t_7 = 0`.                                  (5.6)

All `t_r` are nonnegative. Equation (5.5) gives

`t_1=t_2=t_7=0`.

Then (5.6) gives

`t_3=t_6=0`.

Then (5.4) gives

`t_4=t_5=0`.

Finally (5.3) gives

`t_0=1`.

Therefore the base row of `Tbar` is exactly the base row of the identity matrix. By transitivity and equivariance, every row is the corresponding identity row. Hence

`Tbar=I_{R^90}`.                                               (5.7)

But `ran(Tbar) subset L`, whereas `dim L=38<90`. This is impossible.

Therefore no positive linear retraction exists. QED.

## 6. Consequence for facet/Farkas strategies

Let `S` be **any** matrix whose columns are nonnegative slack vectors lying in `L` (for example, the 4,450 currently known facet slacks, or even the complete unknown set of facet rays).

If there were an entrywise-nonnegative coefficient matrix `C` such that

`S C f = f` for every `f in L`,                                (6.1)

then `T=SC` would be a positive linear retraction onto `L`, contradicting Theorem 5.1.

Thus there is no globally coordinatewise-positive **linear** coefficient selector that reconstructs every affine slack vector from nonnegative slack rays.

This is a proof-strategy obstruction, not a facet incompleteness result. A conic decomposition can still exist pointwise for every valid slack while depending piecewise-linearly or nonlinearly on the slack. Indeed, exact facet completeness, if true, would imply precisely such pointwise conic decompositions without implying a positive ambient retraction.

The practical lesson is that the seven local wall-cone problems should be attacked with local simplicial/triangulation, exact redundancy, or piecewise Farkas certificates rather than searching for one global positive linear projector.
