## 3. Countable weighted block setup

Let `I` be finite or countable. Let

`E = disjoint-union_{b in I} B_b`

where every `B_b` is a nonempty finite or countable set and `E` is countable.

For every `b in I`, choose an arbitrary unit vector

`w_b in l2(B_b)`.

Because the physical blocks are disjoint, the family `{w_b : b in I}` is orthonormal in `l2(E)`. Define

`V_b = l2(B_b) intersect w_b^perp`

and

`W = closed-span{w_b : b in I}`.

Let

`J : l2(I) -> l2(E)`

be the isometry `J e_b = w_b`. Thus `ran J=W`.

Let `S subset I` and let `S` also denote the diagonal projection on `l2(I)` onto coordinates in that set. Let

`D_S = direct-sum_{b in S} I_{l2(B_b)}`

be the physical block-fill projection. The orthogonal projection onto

`direct-sum_{b in S} V_b`

is

`D_S - J S J*`.                                             (3.1)

Now let `Q` be **any positive contraction** on `l2(I)`, not necessarily a projection. Define the physical kernel

`K = D_S + J (Q-S) J*`.                                      (3.2)

Relative to the orthogonal decomposition

`l2(E) = W direct-sum (direct-sum_b V_b)`,

`K` acts as `Q` on `W`, as identity on `V_b` for `b in S`, and as zero on `V_b` for `b notin S`. Therefore

`0 <= K <= I`.

Moreover, `K` is an orthogonal projection iff `Q` is an orthogonal projection.

Equation (3.2) is the countable positive-contraction version of the preceding weighted block normal form.

## 4. NEW theorem — exact one-color countable weighted lift

Let

`Y ~ P^Q`

be the quotient DPP on `I`.

Independently for all `b in I`, sample a physical site

`Z_b in B_b`

with

`Pr[Z_b=z] = |w_b(z)|^2`.                                    (4.1)

The countable product of these probability spaces exists because the family is countable.

Define `X subset E` blockwise by

- if `b in S intersect Y`, put `X intersect B_b = B_b`;
- if `b in S\Y`, put `X intersect B_b = B_b\{Z_b}`;
- if `b in Y\S`, put `X intersect B_b = {Z_b}`;
- if `b notin S union Y`, put `X intersect B_b = emptyset`.

This definition makes sense even when `B_b` is infinite: `B_b\{Z_b}` is simply a co-singleton configuration.

### Theorem 4.1

The random set `X` has exactly the DPP law

`X ~ P^K`

for the positive contraction `K` in (3.2).

Thus a quotient DPP can be inflated through arbitrarily large or infinite weighted blocks by a single shared weighted site per block.

### Proof by finite-support generating functional

Let `f:E->C` have finite support. It is enough to prove equality of

`E product_{x in X} (1+f_x)`                                    (4.2)

with the standard DPP determinant

`det(I+K F)`,                                                  (4.3)

where `F` is multiplication by `f`; all determinants below reduce to finite-dimensional determinants because `F` has finite support.

First suppose temporarily that all denominators written below are nonzero. The final identity is polynomial/rational on a Zariski-open set and hence extends to all finitely supported `f` by continuity/polynomial identity.

For each block put

`A_b = product_{x in B_b}(1+f_x)`,                              (4.4)

where only finitely many factors differ from one.

Define

`m_b = sum_{x in B_b} |w_b(x)|^2 f_x/(1+1_S(b) f_x)`.          (4.5)

Thus

- for `b notin S`, `m_b=sum_x |w_b(x)|^2 f_x`;
- for `b in S`, `m_b=sum_x |w_b(x)|^2 f_x/(1+f_x)`.

Only finitely many `m_b` are nonzero.

#### 4.1 Generating functional of the explicit block construction

If `b notin S`, then conditional on `1_{b in Y}` the block contributes

`1` if `b notin Y`,

and

`E(1+f_{Z_b}) = 1+m_b`

if `b in Y`.

If `b in S`, then the full block contributes `A_b` when `b in Y`. When `b notin Y`, the co-singleton block contributes

`C_b := E product_{x != Z_b}(1+f_x)`

`= A_b sum_z |w_b(z)|^2/(1+f_z)`

`= A_b (1-m_b)`.                                               (4.6)

Therefore the total conditional generating factor can be written as a base factor times a multiplicative weight for each quotient particle:

`E product_{x in X}(1+f_x)`

`= [product_{b in S} A_b(1-m_b)]`

`  * E_Y product_{b in Y} (1+d_b)`,                            (4.7)

where

`d_b = m_b` for `b notin S`,

and

`d_b = m_b/(1-m_b)` for `b in S`.                              (4.8)

Equivalently, with

`M=diag(m_b)`,

`T=I-SM`,

we have

`D:=diag(d_b)=M T^{-1}`.                                       (4.9)

Since `D` has finite support, the DPP generating identity for `Y~P^Q` gives

`E_Y product_{b in Y}(1+d_b)=det(I+Q D)`.                      (4.10)

Hence the explicit construction has generating functional

`[product_{b in S} A_b(1-m_b)] det(I+Q M T^{-1})`.             (4.11)

#### 4.2 Determinant of the inflated kernel

From (3.2),

`I+K F = I + D_S F + J(Q-S)J*F`.

Set

`R=I+D_S F`.

This is block diagonal. The matrix determinant lemma / Sylvester determinant identity gives

`det(I+K F)`

`= det(R) det(I+(Q-S) J* F R^{-1} J)`.                         (4.12)

Because the `w_b` have disjoint supports,

`J* F R^{-1} J = M`.                                          (4.13)

Also

`det(R)=product_{b in S} A_b`.                                 (4.14)

Now observe the exact factorization

`I+(Q-S)M = T+QM`

`= (I+Q M T^{-1}) T`.                                         (4.15)

Therefore

`det(I+(Q-S)M)`

`= det(I+Q M T^{-1}) det(T)`

`= det(I+Q M T^{-1}) product_{b in S}(1-m_b)`.                 (4.16)

Substituting (4.13)--(4.16) into (4.12) yields exactly (4.11).

Thus the finite-support generating functional of the explicit construction equals the DPP generating functional for `K`.

Cylinder laws on a countable discrete ground set are determined by these finitely supported generating functions, so

`X~P^K`.

QED.

## 5. Deterministic quotient map and support structure

The explicit representation immediately gives a canonical quotient bit from every block configuration in the support of `P^K`.

For `b in S`:

- quotient bit `1` corresponds to `X intersect B_b=B_b`;
- quotient bit `0` corresponds to `X intersect B_b=B_b\{z}` for one site `z`.

For `b notin S`:

- quotient bit `1` corresponds to a singleton `{z}`;
- quotient bit `0` corresponds to the empty block.

Hence define

`Phi_S(X) = { b in S : X intersect B_b=B_b }`

`          union { b notin S : |X intersect B_b|=1 }`.         (5.1)

Under `P^K`,

`Phi_S(X) ~ P^Q`.                                               (5.2)

This remains valid for infinite blocks. The support statement is literal, not only an almost-sure cardinality heuristic.

## 6. NEW theorem — countable partition-coupling equivalence for positive contractions

Let the colors be `i=0,...,k-1`.

Assume:

1. `Q_i` are positive contractions on `l2(I)`;
2. `sum_i Q_i=I_{l2(I)}`;
3. the owner sets `S_i` form a partition of `I`.

Define physical positive contractions

`K_i = D_{S_i}+J(Q_i-S_i)J*`.                                  (6.1)

Because the owner sets partition `I`,

`sum_i K_i=I_{l2(E)}`.                                        (6.2)

### Theorem 6.1

The following are equivalent.

**Quotient feasibility.** There exists a random ordered partition

`I=Y_0 disjoint-union ... disjoint-union Y_{k-1}`

with

`Y_i~P^{Q_i}`.

**Physical feasibility.** There exists a random ordered partition

`E=X_0 disjoint-union ... disjoint-union X_{k-1}`

with

`X_i~P^{K_i}`.

This equivalence holds for finite or countable `I,E`, finite or countably infinite blocks, and finite- or infinite-rank kernels.

### Proof: quotient coupling lifts

Assume the quotient partition exists. Independently sample one shared

`Z_b~|w_b|^2`

for every block.

Let `o(b)` be the unique owner color with `b in S_{o(b)}` and let `q(b)` be the unique quotient color with `b in Y_{q(b)}`.

Allocate physical block `B_b` by

- if `q(b)=o(b)`, give all of `B_b` to that color;
- if `q(b)!=o(b)`, give `B_b\{Z_b}` to the owner and `{Z_b}` to the quotient color;
- all remaining colors get nothing from `B_b`.

Every block is partitioned, hence all of `E` is partitioned.

Fix color `i`. Relative to the quotient bit `1_{b in Y_i}`, its physical block rule is exactly Theorem 4.1 with owner set `S_i`. Therefore

`X_i~P^{K_i}`.

### Proof: physical coupling deflates

Conversely, suppose a physical partition coupling exists.

For each fixed color `i`, Theorem 4.1 and Section 5 show that under its marginal law every owned block is either full or co-singleton, and every nonowned block is either empty or singleton. Since there are only countably many colors/blocks involved in the stated setting, all these marginal support restrictions hold simultaneously almost surely.

Fix a physical block `B_b` and let `o=o(b)`.

Because the colors partition `B_b`, exactly one of two possibilities can occur:

1. the owner occupies the full block and every nonowner is empty;
2. the owner occupies `B_b\{z}` for one site `z`, exactly one nonowner occupies `{z}`, and every other nonowner is empty.

In the first case declare quotient color `q(b)=o`. In the second case declare `q(b)` to be the unique singleton nonowner.

Then

`Y_i={b:q(b)=i}`

form a partition of `I`. Moreover, for each color individually this is precisely the deterministic map `Phi_{S_i}(X_i)`, so by (5.2)

`Y_i~P^{Q_i}`.

QED.

## 7. Projection specialization and direct Lyons consequences

Suppose now every `Q_i` is an orthogonal projection, say `Q_i=P_{U_i}`, with

`l2(I)=U_0 direct-sum ... direct-sum U_{k-1}`.

Then every `K_i` is also an orthogonal projection, onto

`H_i = J U_i direct-sum (direct-sum_{b in S_i} V_b)`.          (7.1)

Hence Theorem 6.1 is an exact countable projection-DPP partition-coupling equivalence.

For the original two-subspace Lyons problem, adjoin

`H_0=(H_1 direct-sum H_2)^perp`.

If the resulting three-color decomposition has form (7.1), then the physical Lyons question is equivalent to the quotient Lyons question on `I`.

### Corollary 7.1 — countably infinite weighted inflations of every solved finite core

If the quotient index set has

`|I|<=5`,

then the quotient problem is affirmative by Lyons's finite theorem. Therefore every countable weighted inflation (7.1) is affirmative, even when:

- `E` is countably infinite;
- one or more blocks `B_b` are infinite;
- the physical subspaces have infinite dimension and/or infinite codimension;
- the weights `w_b` are completely nonuniform;
- there is no within-block permutation symmetry.

This is a direct explicit coupling, not merely a limiting existence argument.

### Corollary 7.2 — positive-contraction cores also inflate exactly

Theorem 6.1 does not require the quotient kernels to be projections. Thus any solved partition-coupling instance for positive contractions `Q_i` summing to identity inflates to a solved countable physical instance `K_i` via (6.1).

This is compatible with the earlier Naimark/compression reduction but is logically independent of it.

### Corollary 7.3 — finite hierarchical peeling

Because Theorem 6.1 is an iff statement, weighted corank-one inflation/deflation can be iterated. If a physical instance reduces by finitely many such block collapses to a quotient core for which the partition coupling is known, then the original instance is solved by lifting the core coupling level by level.

In particular, every finite hierarchy whose terminal core has at most five coordinates is affirmative.

Conversely, a future quotient counterexample would inflate through every such hierarchy to further counterexamples.

## 8. Why the countable extension is not merely formal

The previous finite proof used a unit top exterior vector for each owned codimension-one block. That object does not exist when an owned block is infinite-dimensional. The current generating-functional proof removes that restriction completely.

For an infinite block `B_b`, the projection DPP on `w_b^perp` is explicitly a co-singleton process: it contains all of `B_b` except one site `Z_b`, with

`Pr(Z_b=z)=|w_b(z)|^2`.

When the quotient bit turns on, that missing weighted site is restored; when a nonowner quotient bit turns on, the same weighted site becomes its singleton. The shared-site rule is therefore still exact in infinite dimension.

The operator identity (4.15) is the algebraic mechanism behind this fermionic particle/hole transfer.

## 9. A useful kernel formula

For later work it is useful to record physical matrix entries. If `x in B_b`, `y in B_c`, write

`q_{bc}=<Q e_c,e_b>`.

Then

- for `b!=c`,
  `K(x,y)=w_b(x) conjugate(w_c(y)) q_{bc}`;
- for `b=c`,
  `K(x,y)=1_S(b) 1_{x=y} + (q_{bb}-1_S(b)) w_b(x) conjugate(w_b(y))`.

Thus the entire cross-block interaction is rank one through each interface vector `w_b`, while the owned complement is deterministically filled.

This formula may be useful for recognizing peelable blocks directly from a kernel without first writing a subspace basis.

## 11. Failed/closed routes and next attack

The new theorem also clarifies the boundary of this block method. A one-dimensional interface is special because each block has only one quotient bit, so the local physical support records that bit without interference. For a genuinely higher-dimensional interface, different equal-cardinality quotient subsets can contribute amplitudes to the same physical coordinate set, so a naive classical mixture over quotient subsets need not reproduce the DPP. Any higher-dimensional generalization must control those interference cross terms rather than merely repeat the finite block argument.

The two highest-value next attacks are therefore:

1. return to the direct K6/Farkas route and prove conic generation for the seven exact local normal-wall types; or
2. characterize higher-dimensional local interfaces for which the Pluecker supports of distinct quotient subsets are disjoint (or admit an exact local stochastic coupling), which would extend the present inflation theorem beyond defect one.

The first route remains the most direct path to the first genuinely unresolved finite case.
