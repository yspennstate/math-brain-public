## 3. Weighted block normal form

Let the finite ground set be partitioned into nonempty blocks

`E = B_1 disjoint-union ... disjoint-union B_m`.

For each block choose an **arbitrary** unit vector

`w_b in l2(B_b)`

and define

`V_b = l2(B_b) intersect w_b^perp`.

Thus `dim V_b=|B_b|-1`. Because different physical blocks have disjoint coordinate supports, the vectors `w_b` are orthonormal. Put

`W = span{w_1,...,w_m}`

and identify `W` with `l2([m])` by `w_b <-> e_b`.

Consider a full orthogonal decomposition

`l2(E)=H_0 direct-sum ... direct-sum H_{k-1}`.

Assume there are an ownership map

`o:[m]->{0,...,k-1}`

and mutually orthogonal quotient spaces

`W=U_0 direct-sum ... direct-sum U_{k-1}`

such that

`H_i = U_i direct-sum (direct-sum_{b:o(b)=i} V_b)`.       (3.1)

Call (3.1) the **weighted corank-one block normal form**.

The preceding block-exchangeability theorem is the special case

`w_b=|B_b|^{-1/2} 1_{B_b}`.

The point of the present theorem is that (3.1) itself is sufficient; no permutation group, exchangeability, or uniform weights are needed.

For `|B_b|=1`, `V_b=0`; the owner is arbitrary bookkeeping, exactly as in the preceding singleton clarification.

## 4. Exact one-color weighted lifting lemma

Fix one color and abbreviate

`H = U direct-sum (direct-sum_{b in S} V_b)`,

where `S` is its set of owned blocks. Let

`Y ~ P^U`

on the quotient set `[m]`.

For every `b in S symmetric-difference Y`, independently sample

`Z_b in B_b`

with the generally nonuniform law

`Pr[Z_b=z]=|w_b(z)|^2`.                                  (4.1)

Define `X subset E` blockwise by

- `X intersect B_b=B_b` if `b in S intersect Y`;
- `X intersect B_b=B_b\{Z_b}` if `b in S\Y`;
- `X intersect B_b={Z_b}` if `b in Y\S`;
- `X intersect B_b=emptyset` if `b notin S union Y`.

### Lemma 4.1

The resulting set has exactly the projection-DPP law

`X ~ P^H`.                                                (4.2)

More precisely, for every quotient basis `Y` and every compatible collection of distinguished sites,

`P^H[X=X(Y,Z)] = P^U[Y] * product_{b in S triangle Y} |w_b(Z_b)|^2`.   (4.3)

### Proof

For each block let `alpha_b` be a unit top exterior vector spanning `wedge^{|B_b|-1} V_b`. Since `V_b=w_b^perp`, Hodge duality inside the coordinate block gives, up to one irrelevant unit phase,

`alpha_b = sum_{z in B_b} epsilon_{b,z} conjugate(w_b(z)) e_{B_b\{z}}`,

where `|epsilon_{b,z}|=1`, and

`alpha_b wedge w_b`

is a unit multiple of the full coordinate wedge `e_{B_b}`. Thus the squared coefficient for omitting `z` from the owned codimension-one block is exactly `|w_b(z)|^2`.

Let `beta` be a unit top exterior vector for `U`. In the orthonormal quotient basis `{w_b}` write

`beta = sum_Y beta_Y w_Y`,

where

`|beta_Y|^2=P^U[Y]`.

A unit top exterior vector for `H` is, up to phase,

`xi_H = (wedge_{b in S} alpha_b) wedge beta`.

Fix `Y`. For `b in S intersect Y`, the factor `alpha_b wedge w_b` fills the whole physical block with unit modulus. For `b in S\Y`, the coefficient of the missing site `z` has squared modulus `|w_b(z)|^2`. For `b in Y\S`, expanding

`w_b=sum_z w_b(z)e_z`

gives singleton `z` with the same squared modulus `|w_b(z)|^2`. Blocks outside `S union Y` are empty.

The final occupancy pattern determines `Y` uniquely, and inside each partial block the distinguished site is also unique. Hence there is no interference between two different quotient terms for the same physical coordinate set. Squaring the single coefficient gives (4.3), proving (4.2). QED.

### Deterministic quotient map

Conversely, from any set in the support of `P^H`, recover its quotient set by

- for owned `b in S`, include `b` iff `X intersect B_b=B_b`;
- for nonowned `b notin S`, include `b` iff `|X intersect B_b|=1`.

Lemma 4.1 implies that this recovered set has law `P^U`.

## 5. Main theorem: weighted inflation/deflation preserves coupling feasibility

### Theorem 5.1

Under the normal form (3.1), the following are equivalent:

1. there exists a random ordered partition

   `E=X_0 disjoint-union ... disjoint-union X_{k-1}`

   with `X_i~P^{H_i}` for all colors;

2. there exists a random ordered partition

   `[m]=Y_0 disjoint-union ... disjoint-union Y_{k-1}`

   with `Y_i~P^{U_i}` for all colors.

### Proof: quotient coupling lifts upstairs

Assume the quotient partition exists. Independently for every physical block sample one shared

`Z_b` with `Pr[Z_b=z]=|w_b(z)|^2`.

Let `q(b)` be the unique quotient color with `b in Y_{q(b)}` and let `o(b)` be the owner from (3.1).

Allocate the physical block as follows:

- if `q(b)=o(b)`, give all of `B_b` to that color;
- if `q(b)!=o(b)`, give `B_b\{Z_b}` to the owner and the singleton `{Z_b}` to the quotient color;
- give no point of this block to any other color.

This is a partition of every block and hence of `E`.

Fix color `i`. Conditional on `Y_i`, its blockwise distribution is exactly Lemma 4.1: every owned but unselected block misses the same independently sampled weighted site, every selected nonowned block receives that site, and an owned selected block is full. Therefore `X_i~P^{H_i}`.

### Proof: any upstairs coupling deflates

Conversely suppose the physical partition coupling exists. Lemma 4.1 shows that, in every marginal support, an owner occupies either all of its block or all but one point, while a nonowner occupies either zero or one point.

Because all colors together partition `B_b`, exactly one of the following occurs:

- the owner occupies the full block and all nonowners are empty;
- the owner misses one site and exactly one nonowner occupies that singleton.

Define `q(b)` to be the owner in the first case and the unique singleton color in the second. Then

`Y_i={b:q(b)=i}`

partition `[m]`. For each fixed color, this is precisely the deterministic quotient map following Lemma 4.1, hence `Y_i~P^{U_i}`. QED.

## 6. Lyons corollaries

For the original two-subspace question, adjoin

`H_0=(H_1 direct-sum H_2)^perp`.

If the full three-color decomposition has weighted corank-one block normal form, Theorem 5.1 reduces the desired coupling exactly to the quotient spaces `U_1,U_2` on `m` coordinates.

### Corollary 6.1 — weighted finite reduction

If `m<=5`, then the original Lyons coupling exists, because Lyons's finite `|E|<=5` theorem solves the quotient problem.

This gives affirmative instances on arbitrarily large finite physical ground sets and with arbitrarily large ranks, even when the projections have **no** within-block permutation symmetry.

### Corollary 6.2 — one-block peeling

Suppose `E=B disjoint-union F`, choose a unit `w in l2(B)`, and suppose one color owns

`V=w^perp intersect l2(B)`

while every remaining degree of freedom lies in

`span{w} direct-sum l2(F)`.

Then the full coupling problem on `E` is equivalent to the coupling problem on the smaller ground set obtained by replacing all of `B` by a single virtual coordinate `b_*` representing `w`.

Thus any instance admitting such a defect-one block can be peeled exactly. Repeating this operation isolates a smaller **corank-one irreducible core**. If that core has at most five quotient coordinates, the instance is solved by Lyons's finite theorem.

### Corollary 6.3 — inflation preserves both positive and negative instances

Theorem 5.1 is an iff statement. Hence any quotient solution lifts to every choice of block sizes and weights. Conversely, if a quotient counterexample is ever found, every weighted corank-one inflation of it is automatically another counterexample. The reduction therefore preserves feasibility rather than merely giving a sufficient construction.
