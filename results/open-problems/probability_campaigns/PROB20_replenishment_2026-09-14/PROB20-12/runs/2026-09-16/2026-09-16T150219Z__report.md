## 3. Fixed exact LP and metric retained unchanged

For a finite ground set `E={1,...,n}`, let `P1,P2` be orthogonal projections of ranks `r1,r2` with `P1 P2=0`, and put `PH=P1+P2`. A projection DPP is supported on subsets of fixed cardinality and has

`p_P(A)=det(P_A)`.

Use variables `q_{A,B}>=0` indexed by disjoint `r1`-subsets `A` and `r2`-subsets `B`. The exact coupling equations are

`sum_B q_{A,B}=p1(A)`,

`sum_A q_{A,B}=p2(B)`,

`sum_{A union B=U} q_{A,B}=pH(U)`.

Write them as

`M q=b, q>=0`.

The fixed normalized Farkas metric from the preceding run is

`delta(b)=max{-b^T y : M^T y>=0, ||y||_infty<=1}`.       (3.1)

For a source-valid finite pair, `delta>0` if and only if the exact coupling LP is infeasible. If an exact primal coupling exists, then for every dual-feasible `y`,

## 4. New stability lemma for exactification of numerical dual candidates

The fixed normalization gives a useful certification bridge that was not written explicitly in the preceding checkpoint.

**Lemma.** For a fixed profile and incidence matrix `M`, define

`D={y : M^T y>=0, ||y||_infty<=1}`

and

`delta(b)=max_{y in D} -b^T y`.

Then for all marginal vectors `b,b'`,

`|delta(b)-delta(b')| <= ||b-b'||_1`.                    (4.1)

**Proof.** For every `y in D`, `||y||_infty<=1`, so Holder's inequality gives

`|(b-b')^T y| <= ||b-b'||_1 ||y||_infty <= ||b-b'||_1`.

Therefore

`-b^T y <= -b'^T y + ||b-b'||_1`.

Taking the maximum over `y in D` yields

`delta(b) <= delta(b')+||b-b'||_1`.

Interchanging `b` and `b'` gives the reverse inequality, proving (4.1). QED.

A stronger operational corollary is immediate. Suppose an algebraic or transcendental projection pair has exact marginal vector `b`, an interval computation supplies a center `b_tilde` with

`||b-b_tilde||_1 <= epsilon`,

and an **exact rational** vector `y` satisfies

`M^T y>=0`, `||y||_infty<=1`, and `-b_tilde^T y=eta>epsilon`.

Then

`-b^T y >= eta-epsilon>0`,

so the original projection pair is rigorously infeasible and is a finite counterexample. Thus a future candidate need not first be rationalized at the level of the projection matrix: it is enough to exactify the dual vector and rigorously interval-enclose the determinant marginal vector with total l1 error smaller than the dual margin.

This is useful because the dual cone is rational and profile-dependent, whereas the most promising projection candidates may naturally be algebraic or obtained from a numerical optimization on a unitary/orthogonal flag manifold.
