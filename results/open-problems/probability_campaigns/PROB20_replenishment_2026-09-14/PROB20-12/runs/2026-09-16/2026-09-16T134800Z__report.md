## 2. Fresh source and literature check — 16 September 2026

### Original source

Russell Lyons, *Determinantal Probability Measures*, Publ. Math. IHES 98 (2003), Question 10.1, asks whether for `H = H1 direct-sum H2` there is a disjoint coupling of `P^{H1}` and `P^{H2}` whose union has law `P^H`. Proposition 10.2 immediately following shows that for positive contractions with `Q1+Q2 <= I`, any coupling with the required union marginal is automatically disjoint. The full-space case `H=l2(E)` is handled there and is not rediscovered here.

Russell Lyons, *Determinantal Probability: Basic Properties and Conjectures*, arXiv:1406.2707, Question 2.8, restates exactly the same orthogonal-subspace union-marginal problem, notes numerical support, and again records the full-space case as easy.

## 3. Exact finite coupling LP

Let `E={1,...,n}` and let `P1,P2` be orthogonal projections of ranks `r1,r2` with `P1 P2=0`; put `PH=P1+P2`. A rank-r projection DPP is supported on r-subsets and

`p_P(A)=det(P_A)` for `|A|=r`.

Because the desired union law has cardinality `r1+r2`, and because disjointness is automatic by Lyons Proposition 10.2, it is enough to use variables

`q_{A,B} >= 0`

indexed by disjoint `A in C(E,r1)`, `B in C(E,r2)`. The exact primal constraints are

`sum_B q_{A,B} = p1(A)`,

`sum_A q_{A,B} = p2(B)`,

`sum_{A union B = U} q_{A,B} = pH(U)`.

Write this as

`M q = b, q >= 0`,                                              (3.1)

where `M` is a 0/1 incidence matrix depending only on `(n,r1,r2)` and `b` is the concatenation of the three exact DPP marginal vectors.

### Fixed normalized Farkas metric

This run fixes the normalization

`delta(P1,P2) = max { -b^T y : M^T y >= 0,  -1 <= y_j <= 1 for every row j }`.    (3.2)

This normalization is candidate-independent once `(n,r1,r2)` and the row convention are fixed.

It is exact and decisive:

1. If (3.1) is feasible, then for every dual-feasible `y`,
   `b^T y = q^T M^T y >= 0`, so `-b^T y <= 0`; since `y=0` is feasible, `delta=0`.
2. If (3.1) is infeasible, Farkas gives some `y` with `M^T y >=0` and `b^T y<0`. Scaling by `||y||_infty` preserves the inequalities and puts the witness inside the fixed box, hence `delta>0`.

Therefore

`delta(P1,P2) > 0  <=>  exact finite counterexample for that projection pair`.      (3.3)

A floating-point infeasibility status or a tiny positive solver objective is not a certificate under this definition.

For an integer skew-symmetric matrix `K` and positive integer `d`,

`Q=(dI-K)(dI+K)^{-1} in O(n,Q)`.
