# PROB20-12 — exact block-symmetry quotient reduction

**SOLUTION STATUS: PARTIAL.** The full Lyons union-coupling problem remains open. This run proves a new exact reduction theorem for a broad structured class: if the orthogonal projections commute with independent coordinate permutations inside a common finite block partition, then the full determinantal partition-coupling problem on the large ground set is **equivalent** to the same problem on the much smaller set of block labels. In particular, if there are at most five exchangeability blocks, Lyons's 2003 finite `|E|<=5` result gives the desired coupling for arbitrarily large original ground sets and arbitrarily large ranks.

This strictly extends the previously archived two-block exchangeable special case: that argument used one cut-count coupling and does not directly extend to three or more blocks because DPP block counts are generally correlated. The theorem below uses the representation structure forced by commutation with the full within-block permutation group and gives an exact quotient/lifting equivalence.

No universal proof, counterexample, or novelty claim is made. The proof below is self-review plus an exact rational six-site certificate described in Section 7.

## 3. Setup: a common exchangeability partition

Let

`E = B_1 disjoint-union ... disjoint-union B_m`,                 (3.1)

where every block is nonempty and finite, with `n_b=|B_b|`. Let

`G = S_{B_1} x ... x S_{B_m}`                                   (3.2)

act on `l2(E)` by coordinate permutations.

Suppose

`l2(E)=H_0 direct-sum ... direct-sum H_{k-1}`                    (3.3)

is a full orthogonal decomposition, with orthogonal projections `P_i`, and assume

`P_i g = g P_i` for every `g in G` and every `i`.                (3.4)

For each block define the normalized constant vector

`u_b = n_b^{-1/2} 1_{B_b}`,                                     (3.5)

its constant line `W_b=span{u_b}`, and the zero-sum space

`V_b = {f: supp(f) subset B_b, sum_{x in B_b} f(x)=0}`.          (3.6)

Then

`l2(E) = W direct-sum (direct-sum_b V_b)`,                       (3.7)

where

`W=span{u_1,...,u_m}` is naturally identified with `l2([m])`.

## 4. Lemma: invariant projection structure

### Lemma 4.1

Under (3.4), for every `i` there is a subspace `U_i subset W` and a set of owned blocks `S_i subset [m]` such that

`H_i = U_i direct-sum (direct-sum_{b in S_i} V_b)`.              (4.1)

Moreover,

`W = U_0 direct-sum ... direct-sum U_{k-1}`,                    (4.2)

and the sets `S_i` partition `[m]`. Thus every zero-sum block space `V_b` is assigned wholly to exactly one color.

### Proof

Fix a block `b`. The subspace `V_b` is invariant under `S_{B_b}` and carries its standard nontrivial representation (for `n_b=2`, the one-dimensional sign representation; for `n_b=1`, `V_b=0`). Every other factor `S_{B_c}`, `c!=b`, acts trivially on `V_b`.

An operator commuting with the full product group preserves `W` and each `V_b`. On `V_b`, the commutant of the permutation representation is scalar; equivalently, on the full coordinate block `l2(B_b)` the commutant of `S_{B_b}` is spanned by `I` and the all-ones matrix, and the latter vanishes on `V_b`. Therefore

`P_i|_{V_b} = lambda_{i,b} I_{V_b}`.                             (4.3)

Because `P_i` is an orthogonal projection, `lambda_{i,b}` is `0` or `1`. Since the full projections sum to identity,

`sum_i P_i = I`,                                                 (4.4)

exactly one color has `lambda_{i,b}=1`. Call it the owner `o(b)` and put `b in S_{o(b)}`.

The constant space `W` is also invariant. Put

`U_i = H_i intersect W = ran(P_i|_W)`.                           (4.5)

Orthogonality and (4.4) give (4.2), while the preceding block analysis gives (4.1). QED.

This is the structural ingredient missing from a mere collection of separate cut-count couplings: all large within-block standard representations are deterministic at the color level, and every genuinely overlapping degree of freedom lives in the `m`-dimensional constant quotient `W`.

## 5. Lemma: exact sampling law for one color

Identify `W` with `l2([m])` via `u_b <-> e_b`. Fix a color `i`, abbreviate

`S=S_i`, `U=U_i`, `r=dim U`,                                    (5.1)

and let `Y~P^U` be the quotient projection DPP on `[m]`.

For each `b in S symmetric-difference Y`, choose independently a uniform point

`Z_b in B_b`.                                                    (5.2)

Define a subset `X(Y,Z) subset E` blockwise by

- if `b in S intersect Y`, set `X intersect B_b = B_b`;
- if `b in S \ Y`, set `X intersect B_b = B_b \ {Z_b}`;
- if `b in Y \ S`, set `X intersect B_b = {Z_b}`;
- if `b notin S union Y`, set `X intersect B_b = emptyset`.

### Lemma 5.1 — block lift of one projection DPP

The resulting random set has exactly the projection-DPP law

`X(Y,Z) ~ P^{U direct-sum (direct-sum_{b in S} V_b)}`.           (5.3)

Equivalently, for every `Y subset [m]` of size `r` and every compatible choice of the partial-block sites,

`P^H[X=X(Y,Z)] = P^U[Y] * product_{b in S triangle Y} (1/n_b)`,  (5.4)

where `H=U direct-sum_b-in-S V_b` and `triangle` denotes symmetric difference.

### Proof by exterior coordinates

For each block choose a unit top exterior vector `alpha_b` spanning `wedge^{n_b-1} V_b`. In the standard coordinate wedge basis it has the form

`alpha_b = n_b^{-1/2} sum_{z in B_b} epsilon_z e_{B_b\{z}}`,     (5.5)

with signs/phases `|epsilon_z|=1`, and

`alpha_b wedge u_b = eta_b e_{B_b}`, `|eta_b|=1`.                (5.6)

Let `beta` be a unit top exterior vector for `U`. Under the quotient identification,

`beta = sum_{Y:|Y|=r} beta_Y u_Y`,                               (5.7)

with

`|beta_Y|^2 = P^U[Y]`.                                           (5.8)

A unit top exterior vector for `H` is, up to an irrelevant phase,

`xi_H = (wedge_{b in S} alpha_b) wedge beta`.                    (5.9)

Fix `Y`. If `b in S intersect Y`, the factor `alpha_b wedge u_b` gives the entire block with unit modulus by (5.6). If `b in S\Y`, (5.5) gives a uniformly weighted missing-site choice with squared modulus `1/n_b`. If `b in Y\S`, the expansion

`u_b=n_b^{-1/2} sum_{z in B_b} e_z`                              (5.10)

gives a uniformly weighted singleton choice, again with squared modulus `1/n_b`. Blocks outside `S union Y` contribute nothing.

For a final set of the stated occupancy type, `Y` is uniquely determined by the block occupancies, and every partial block has a unique distinguished `Z_b`. Therefore there is no cross-term ambiguity for that coordinate wedge. Its squared coefficient in (5.9) is exactly (5.4). Projection-DPP basis probabilities are the squared top-wedge coefficients, proving the lemma. QED.

### Deterministic quotient map

Conversely, from any set in the support of this DPP one recovers `Y` deterministically:

- on an owned block `b in S`, put `b in Y` iff `|X intersect B_b|=n_b`;
- on a non-owned block `b notin S`, put `b in Y` iff `|X intersect B_b|=1`.

Lemma 5.1 shows that under `P^H` this recovered set has law `P^U`.

## 6. Main theorem: exact equivalence of upstairs and quotient coupling

### Theorem 6.1 — block-symmetry quotient reduction

Under (3.1)--(3.4), the following are equivalent:

1. there is a random ordered partition

   `E = X_0 disjoint-union ... disjoint-union X_{k-1}`           (6.1)

   with `X_i~P^{H_i}` for every `i`;

2. there is a random ordered partition

   `[m] = Y_0 disjoint-union ... disjoint-union Y_{k-1}`         (6.2)

   with `Y_i~P^{U_i}` for every `i`, where the `U_i` are the quotient spaces from Lemma 4.1.

Thus the full partition-coupling feasibility problem is unchanged when each exchangeability block is collapsed to one quotient coordinate.

### Proof: quotient coupling implies full coupling

Assume (6.2). Independently for each physical block choose

`Z_b uniform on B_b`.                                            (6.3)

Let `o(b)` be the owner of `V_b`, and let `q(b)` be the unique color with `b in Y_{q(b)}`. Allocate block `B_b` as follows:

- if `q(b)=o(b)`, give **all** of `B_b` to that color;
- if `q(b)!=o(b)`, give `B_b\{Z_b}` to the owner `o(b)` and the singleton `{Z_b}` to the quotient color `q(b)`;
- give no point of that block to any other color.

This is visibly a partition of every block, hence of `E`.

Fix a color `i`. Conditional on its quotient set `Y_i`, its blockwise law is exactly the construction of Lemma 5.1 with owned set `S_i`: owned quotient blocks are full; owned non-quotient blocks miss one independent uniform site; selected non-owned quotient blocks contribute one independent uniform site; other blocks are empty. Therefore

`X_i~P^{H_i}`.                                                   (6.4)

### Proof: full coupling implies quotient coupling

Conversely, suppose (6.1) holds. Every marginal `X_i` lies almost surely in the support described by Lemma 5.1.

Fix a block `b` and let `o=o(b)`. In color `o`, the block occupancy is almost surely either `n_b` or `n_b-1`. For every non-owner color it is almost surely either `0` or `1`.

Because the `X_i` partition `B_b`, exactly one of two cases occurs:

- the owner has all `n_b` sites and every other color has zero; or
- the owner has `n_b-1` sites and exactly one non-owner color has the remaining singleton.

Define `q(b)` to be the owner in the first case and the unique singleton color in the second. Let

`Y_i={b:q(b)=i}`.                                                 (6.5)

Then the `Y_i` partition `[m]`. Moreover, for each fixed `i`, `Y_i` is exactly the deterministic quotient map of `X_i` described after Lemma 5.1. Since `X_i~P^{H_i}`, that lemma gives

`Y_i~P^{U_i}`.                                                   (6.6)

Thus (6.2) holds. QED.

## 7. Corollaries for Lyons Question 2.8

Let `H_1,H_2 subset l2(E)` be orthogonal and put

`H_0=(H_1 direct-sum H_2)^perp`.                                 (7.1)

If `P_{H_1}` and `P_{H_2}` commute with the common block-permutation group `G`, then so does `P_{H_0}=I-P_{H_1}-P_{H_2}`. Apply Theorem 6.1 to the three-color full decomposition.

A three-color partition coupling of `(H_0,H_1,H_2)` is equivalent to Lyons's desired coupling of `(H_1,H_2)`: if `X_0,X_1,X_2` partition `E`, then

`X_1 union X_2 = E\X_0`,                                        (7.2)

and DPP duality identifies the complement law of `P^{H_0}` with `P^{H_1 direct-sum H_2}`. Conversely any disjoint union coupling gives `X_0=E\(X_1 union X_2)`.

Hence:

### Corollary 7.1 — exact quotient equivalence for the two-subspace question

For common block-permutation-invariant projections, the Lyons instance on `E` has a solution **iff** the quotient instance `(U_1,U_2)` on the `m` block labels has a solution.

### Corollary 7.2 — at most five exchangeability blocks

If the common block partition has

`m<=5`,                                                          (7.3)

then the desired coupling exists, because Lyons 2003 proves the finite question for every ground set of size at most five.

This gives affirmative instances on arbitrarily large `E` and with arbitrarily large ranks: block sizes affect only deterministic zero-sum owner sectors and independent uniform choices of a transferred site; all genuine coupling difficulty lives on at most five quotient coordinates.

### Corollary 7.3 — other quotient-solvable profiles

More generally, any known positive quotient case lifts. For example, if one quotient subspace has rank one (or an equivalent codimension-one/dual case covered by the historical rank-one mechanism), the block-symmetric original instance is affirmative regardless of the physical block sizes.

### Relation to the old two-block theorem

For `m=2`, the quotient problem has only two coordinates and is automatically in Lyons's `|E|<=5` range. Thus Theorem 6.1 recovers the earlier common bipartition result under the stronger matrix-level symmetry hypothesis (commutation of the projections), but it also shows why the extension to many blocks is not obtained by independently coupling each cut count: the correct object is the quotient projection DPP `P^{U_i}`, whose counts across several blocks retain their correlations.
