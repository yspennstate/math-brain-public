## 3. Exact target and the counterexample-first family

For a covariance `C` and `X~N(0,C)`, write

\[
F_d(C)=\mathbb E\,\operatorname{Top}_d(X_1^2,\ldots,X_p^2),
\]

where `Top_d` is the sum of the `d` largest coordinate squares. On the fixed-spectrum orthogonal orbit `C=U\Sigma U^T`, the conjecture says that a diagonal/eigenbasis covariance maximizes `F_d`.

This run searched a rational, algebraically checkable `p=4,d=3` family. Set

\[
\Sigma_a=\operatorname{diag}(a,a,1,1),
\qquad a\in\{4,9,16\},
\]

and simultaneously rotate the `(1,3)` and `(2,4)` planes by

\[
U(c,s)=
\begin{pmatrix}
 c&0&s&0\\
 0&c&0&s\\
 -s&0&c&0\\
 0&-s&0&c
\end{pmatrix},
\qquad c^2+s^2=1,
\]

using the six exact Pythagorean choices

\[
(c,s)\in
\left\{
\left(\frac35,\frac45\right),
\left(\frac5{13},\frac{12}{13}\right),
\left(\frac8{17},\frac{15}{17}\right),
\left(\frac7{25},\frac{24}{25}\right),
\left(\frac{20}{29},\frac{21}{29}\right),
\left(\frac{12}{37},\frac{35}{37}\right)
\right\}.
\]

Thus there are `3*6=18` nontrivial exact rational covariance examples. Fraction arithmetic checks `UU^T=I` and constructs every covariance exactly.

This is deliberately a **counterexample search**. No implication from failure in this class to the unrestricted conjecture is asserted.

## 4. Exact reduction for `p=4,d=3`

For four coordinates and `d=3`, exactly one squared coordinate is discarded, so

\[
F_3(C)=\operatorname{tr}(C)-J(C),
\qquad
J(C):=\mathbb E\min_{1\le i\le4}X_i^2.
\tag{4.1}
\]

Because the trace is fixed on the orbit,

\[
F_{\rm rot}-F_{\rm KL}=J_{\rm KL}-J_{\rm rot}.
\tag{4.2}
\]

For the simultaneous two-block rotation above, the covariance is a direct sum of two identical `2x2` blocks. Generate one block from two independent standard normals in polar coordinates:

\[
(Z_1,Z_2)=R(\cos\phi,\sin\phi),
\qquad
\phi\sim\operatorname{Unif}[0,\pi],
\qquad
R^2\sim\chi^2_2,
\]

with angle and radius independent. The period is `pi` because only squared coordinates matter.

For one block define

\[
q_1(\phi)=\left(c\sqrt a\cos\phi+s\sin\phi\right)^2,
\]
\[
q_2(\phi)=\left(-s\sqrt a\cos\phi+c\sin\phi\right)^2,
\]
\[
m(\phi)=\min\{q_1(\phi),q_2(\phi)\}.
\tag{4.3}
\]

The minimum squared coordinate within that block is `R^2 m(phi)`. For two independent blocks, conditional on angular minima `m_1,m_2`, use the exponential survival law of `chi^2_2`:

\[
\begin{aligned}
\mathbb E\big[\min(R_1^2m_1,R_2^2m_2)\mid m_1,m_2\big]
&=\int_0^\infty
\Pr(R_1^2m_1>t)\Pr(R_2^2m_2>t)\,dt\\
&=\int_0^\infty
\exp\!\left(-\frac{t}{2m_1}\right)
\exp\!\left(-\frac{t}{2m_2}\right)dt\\
&=\boxed{\frac{2m_1m_2}{m_1+m_2}},
\end{aligned}
\tag{4.4}
\]

with the continuous value `0` when either `m_i=0`.

Therefore **all unbounded Gaussian radial integration is exact** and the remaining expectation is the compact two-angle integral

\[
\boxed{
J_{a,c,s}
=\frac1{\pi^2}\int_0^\pi\!\int_0^\pi
H(m(\phi),m(\psi))\,d\phi\,d\psi,
\qquad
H(x,y)=\frac{2xy}{x+y}.
}
\tag{4.5}
\]

No Gaussian tail truncation is needed anywhere in this certificate.

Since

\[
\operatorname{tr}\Sigma_a=2(a+1),
\]

the normalized excess is

\[
\boxed{
E(a,c,s)=
\frac{J_{a,1,0}-J_{a,c,s}}{2(a+1)}.
}
\tag{4.6}
\]

This reduction is exact.

## 5. Rigorous angular enclosure

Partition `[0,pi]` into `N=2048` equal cells. On each cell `I_k`, the executed checker evaluates `sin` and `cos` using `mpmath.iv` with 80 decimal digits and obtains outward interval enclosures for `q_1`, `q_2`, hence

\[
L_k\le m(\phi)\le U_k
\qquad(\phi\in I_k).
\tag{5.1}
\]

The harmonic mean `H` is coordinatewise increasing on the nonnegative quadrant because

\[
\frac{\partial H}{\partial x}
=\frac{2y^2}{(x+y)^2}\ge0,
\qquad
\frac{\partial H}{\partial y}
=\frac{2x^2}{(x+y)^2}\ge0.
\tag{5.2}
\]

Therefore on every product cell `I_k x I_l`,

\[
H(L_k,L_l)
\le H(m(\phi),m(\psi))
\le H(U_k,U_l).
\tag{5.3}
\]

Because all cells have equal area, averaging these lower and upper cell bounds yields a rigorous enclosure of (4.5). This is range enclosure rather than an asymptotic quadrature rule, so there is no unaccounted discretization remainder: the cell oscillation itself is retained in the lower/upper gap.

The checker converts the outward interval endpoints to IEEE doubles with an additional outward `nextafter`. Harmonic-mean evaluations and reductions are then widened once more by a final absolute `ROUND_PAD=10^{-6}` on each `J` endpoint. There are `2048^2=4,194,304` nonnegative terms, each bounded by `16`; the standard IEEE-754 summation worst-case mean error at this size is below `10^{-7}`, so the `10^{-6}` widening dominates the floating reduction error by more than an order of magnitude. The radial identity (4.4) is exact and contributes no numerical tail error.

The artifact is a self-check/certificate under the stated `mpmath.iv` + IEEE-754 semantics; it is not a proof-assistant formalization or an independent audit.
