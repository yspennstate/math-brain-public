# 3. Exact `p=4,d=2` reduction

Let `X~N(0,C)` and write

\[
F_2(C)=\mathbb E\operatorname{Top}_2(X_1^2,X_2^2,X_3^2,X_4^2).
\]

Because the sum of all four squared coordinates has expectation `tr(C)`, define the discarded bottom-two energy

\[
B_2(C):=\mathbb E\operatorname{Bottom}_2(X_1^2,X_2^2,X_3^2,X_4^2).
\]

Then

\[
F_2(C)=\operatorname{tr}(C)-B_2(C),
\tag{3.1}
\]

so on a fixed-spectrum orthogonal orbit

\[
F_{\rm rot}-F_{\rm KL}=B_{2,\rm KL}-B_{2,\rm rot}.
\tag{3.2}
\]

This run searches covariances that split into two independent rotated two-dimensional Gaussian blocks. The important point is that the radial variables can again be integrated **exactly**, now for `d=2` rather than the previous endpoint case `d=3`.

## 3.1 Conditional angular coefficients

For block 1, write its two squared coordinates as

\[
R_1^2 q_1(\phi),\qquad R_1^2 q_2(\phi),
\]

where `R_1^2~chi^2_2` and `phi` is uniform modulo `pi`. Define

\[
l=\min(q_1,q_2),\qquad u=\max(q_1,q_2).
\]

Similarly block 2 has coefficients

\[
m=\min(r_1,r_2),\qquad v=\max(r_1,r_2)
\]

and independent `R_2^2~chi^2_2`. Thus conditional on the two angles the four squared coordinates are

\[
lX,\quad uX,\quad mY,\quad vY,
\qquad X,Y\stackrel{\rm iid}{\sim}\chi^2_2,
\tag{3.3}
\]

with `0<=l<=u`, `0<=m<=v`.

## 3.2 Deterministic identity for the two smallest

Among the four nonnegative numbers in (3.3), the sum of the two smallest is exactly

\[
\boxed{
\min\{(l+u)X,\ (m+v)Y,\ lX+mY\}.
}
\tag{3.4}
\]

**Proof.** Any two-element subset is either both entries from block 1, both from block 2, or one entry from each block. If both come from block 1, the sum is `(l+u)X`; if both come from block 2, it is `(m+v)Y`. If one comes from each block, the smallest possible cross-block pair is `lX+mY`, and every other cross-block pair is at least this large because `l<=u` and `m<=v`. Taking the minimum of these three candidates yields the two-smallest sum. `square`

## 3.3 Exact integration of both Gaussian radii

The density of `X~chi^2_2` is `(1/2)e^{-x/2}`. Put

\[
A=l+u,\qquad C=m+v.
\]

Using `y=tx`, `dy=x dt`, homogeneity of (3.4) gives

\[
\begin{aligned}
K(l,u,m,v)
&:=\mathbb E\min\{AX,CY,lX+mY\}\\
&=\int_0^\infty\int_0^\infty
\min\{Ax,Cy,lx+my\}
\frac14e^{-(x+y)/2}\,dx\,dy\\
&=4\int_0^\infty
\frac{\min\{A,Ct,l+mt\}}{(1+t)^3}\,dt.
\tag{3.5}
\end{aligned}
\]

The lower envelope is explicit. The line `Ct` meets `l+mt` at

\[
t_L=\frac{l}{v},
\]

while `l+mt` meets `A` at

\[
t_R=\frac{u}{m}.
\]

Because `lm<=uv`, we have `t_L<=t_R`. Moreover:

- for `0<=t<=t_L`, `Ct` is below both other branches;
- for `t_L<=t<=t_R`, `l+mt` is below both other branches;
- for `t>=t_R`, `A` is below both other branches.

Hence

\[
\begin{aligned}
K
=4\Bigg[
&\int_0^{l/v}\frac{Ct}{(1+t)^3}\,dt
+\int_{l/v}^{u/m}\frac{l+mt}{(1+t)^3}\,dt\\
&+\int_{u/m}^{\infty}\frac{A}{(1+t)^3}\,dt
\Bigg].
\end{aligned}
\tag{3.6}
\]

Direct elementary integration simplifies to

\[
\boxed{
K(l,u,m,v)
=2\,
\frac{lmu+lmv+luv+muv}
     {lm+lu+mv+uv}.
}
\tag{3.7}
\]

The formula extends continuously to zero coefficients. The archived checker performs this integration symbolically and obtains residual exactly `0`.

Thus the **entire unbounded four-dimensional Gaussian radial part has disappeared**. Only two compact angular variables remain.

## 3.4 Monotonicity used for interval enclosure

The function `K` is coordinatewise nondecreasing on the nonnegative cone. This does not require differentiating (3.7): by (3.3)-(3.4), increasing any one of `l,u,m,v` increases one of the four squared coordinates pointwise, and the sum of the two smallest coordinates is itself coordinatewise nondecreasing. Taking expectation preserves the order.

This observation is what makes a cellwise interval certificate straightforward.
