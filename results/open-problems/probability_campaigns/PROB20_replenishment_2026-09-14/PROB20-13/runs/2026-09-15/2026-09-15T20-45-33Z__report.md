# 2. Balanced partition theorem

Put
\[
S_k:=1+2+\cdots+k=\frac{k(k+1)}2.
\]

The previous report isolated the following requirement: for every integer `r` at least `k`, construct a probability distribution on compositions of `r` using parts in `{1,...,k}` such that every part size has the same expected count `r/S_k`.

The next theorem proves a stronger integral statement.

## Theorem 2.1 — exact balanced packing

For every pair of integers
\[
k\ge1,\qquad r\ge k,
\]
there exist exactly `S_k` finite compositions
\[
C_1,\ldots,C_{S_k}
\]
of `r`, with all parts in `{1,...,k}`, such that across the whole family each part size `s in {1,...,k}` occurs **exactly `r` times**.

Equivalently, if `N_s(C_j)` is the number of parts equal to `s`, then
\[
\sum_{j=1}^{S_k}N_s(C_j)=r
\qquad(1\le s\le k).
\tag{2.1}
\]
Thus choosing one of the `S_k` compositions uniformly gives
\[
\mathbb E N_s=\frac r{S_k}
\qquad(1\le s\le k).
\tag{2.2}
\]

### Proof

It is useful to regard the construction as packing `r` copies of each item size `1,2,...,k` into `S_k` bins, each bin having total size exactly `r`. Ordering the items inside each bin afterwards turns the bins into compositions.

We use strong induction on `k`; for each fixed `k`, we also use strong induction on `r`.

### Base `k=1`

Here `S_1=1`. The single bin consisting of `r` copies of `1` has sum `r` and uses the unique part size exactly `r` times.

Assume henceforth that the theorem is known for every smaller maximum part size `k'<k`, for every admissible length.

### Case A: `k <= r < 2k`

Write
\[
r=k+t,\qquad 0\le t<k.
\tag{2.3}
\]

#### Subcase A1: `t=0`, so `r=k`

For the sizes `1,...,k-1`, use the involution
\[
s\longleftrightarrow k-s.
\]
For every two-element orbit `{s,k-s}`, create `k` bins of the form
\[
(s,k-s).
\]
This uses all `k` copies of both sizes.

If `k` is even, the fixed point `s=k/2` is handled by `k/2` bins
\[
(k/2,k/2),
\]
again using all `k` copies.

Finally create `k` singleton bins `(k)`, one for each copy of size `k`.

Every bin sums to `k`, and every size `1,...,k` is used exactly `k` times. Since the total item mass is `k S_k`, the number of bins is exactly `S_k`.

#### Subcase A2: `1 <= t < k`

On the set of “large” sizes
\[
\{t,t+1,\ldots,k\}
\]
use the involution
\[
s\longleftrightarrow r-s=k+t-s.
\tag{2.4}
\]
It maps this interval to itself.

For every two-element orbit `{s,r-s}`, create `r` bins
\[
(s,r-s).
\]
This uses all `r` copies of both involved sizes.

If there is a fixed point `s=r/2`, then `r` is even; create `r/2` bins
\[
(r/2,r/2),
\]
which use all `r` copies of that size.

Thus every size `t,t+1,...,k` has been used exactly `r` times, and every bin constructed so far sums to `r`.

If `t=1`, there are no residual sizes and we are done.

If `t>=2`, the only unused items are `r` copies of each size
\[
1,2,\ldots,t-1.
\]
Since `t-1<k`, the outer induction hypothesis applies to the pair `(t-1,r)` and produces exactly
\[
S_{t-1}
\]
additional bins of sum `r`, using each residual size exactly `r` times.

Combining the large-size complementary bins with these residual bins uses every size `1,...,k` exactly `r` times. The total item mass is `r S_k`, and every bin has mass `r`, so the final number of bins is exactly `S_k`.

This proves the entire base interval `k <= r < 2k`.

### Case B: `r >= 2k`

Then
\[
r-k\ge k.
\]
By the inner induction hypothesis at the smaller length `r-k`, there are `S_k` bins of sum `r-k` using each size `s` exactly `r-k` times.

By Subcase A1 there are `S_k` bins of sum `k` using each size `s` exactly `k` times.

Pair the two families row by row and concatenate the contents of each paired pair of bins. This gives `S_k` bins, each of sum
\[
(r-k)+k=r,
\]
and each size `s` occurs altogether
\[
(r-k)+k=r
\]
times.

This completes both inductions. `□`

## 2.2 Integer-partition-polytope corollary

Let
\[
\mathcal P_{k,r}:=
\left\{x\in\mathbb Z_{\ge0}^k:\ \sum_{s=1}^k s x_s=r\right\}.
\]
The theorem gives the exact convex-hull inclusion
\[
\boxed{
\frac r{S_k}(1,\ldots,1)\in\operatorname{conv}(\mathcal P_{k,r})
\qquad(r\ge k).
}
\tag{2.5}
\]
Moreover, the point has a rational representation with denominator exactly `S_k` coming from the explicit construction above.

General integer partition polytopes are studied, for example, by Onn and Shlyk, *Some efficiently solvable problems over integer partition polytopes*, Discrete Applied Mathematics 180 (2015), 135–140. I did not find this exact barycentric inclusion stated in the bounded literature search performed for this run, and no novelty claim is made.

# 3. Exact optimum for every power of every cycle

Let
\[
C_n^k
\]
be the `k`-th power of the cycle on `Z_n`: two vertices are adjacent when their ordinary cycle distance is at most `k`. Assume
\[
n\ge2k+1.
\]
Then the graph is `2k`-regular (with `n=2k+1` giving the complete graph),
\[
\pi\equiv\frac1n,
\qquad
m=nk,
\qquad
c_e=\pi_xP_{xy}=\frac1{2nk}
\tag{3.1}
\]
on every physical edge.

Write `d_C` for ordinary distance on the underlying cycle and
\[
\bar d_C:=\mathbb E[d_C(U,V)]
=\begin{cases}
\dfrac n4,&n\text{ even},\\[2mm]
\dfrac{n^2-1}{4n},&n\text{ odd},
\end{cases}
\tag{3.2}
\]
for independent uniform vertices `U,V`.

## Theorem 3.1

For every
\[
k\ge1,\qquad n\ge2k+1,
\]
one has the exact stationary product-flow optimum
\[
\boxed{
F(C_n^k)=\frac4{k+1}\,\bar d_C.
}
\tag{3.3}
\]
Equivalently,
\[
\boxed{
F(C_n^k)=
\begin{cases}
\dfrac{n}{k+1},&n\text{ even},\\[2mm]
\dfrac{n^2-1}{n(k+1)},&n\text{ odd}.
\end{cases}
}
\tag{3.4}
\]

### 3.1 Exact dual lower bound

Give every edge of jump type `s in {1,...,k}` the dual length
\[
\ell_s:=\frac{4s}{k+1}.
\tag{3.5}
\]
There are `n` physical edges of every jump type. Therefore
\[
\sum_ec_e\ell_e
=\sum_{s=1}^k n\frac1{2nk}\frac{4s}{k+1}
=\frac{2S_k}{k(k+1)}=1.
\tag{3.6}
\]
So the assignment is dual feasible.

For any path in `C_n^k`, replace a jump of cyclic size `s` by `s` unit steps around the underlying cycle in the same signed direction. Its dual cost is unchanged. Hence every path from `u` to `v` has dual cost at least
\[
\frac4{k+1}d_C(u,v).
\]
Conversely a shortest ordinary-cycle arc can be partitioned into jumps of sizes at most `k`, attaining that cost. Thus the induced shortest-path metric is exactly
\[
d_\ell(u,v)=\frac4{k+1}d_C(u,v).
\tag{3.7}
\]
The metric LP dual gives
\[
F(C_n^k)\ge\frac4{k+1}\bar d_C.
\tag{3.8}
\]

### 3.2 Matching primal routing

For an unordered pair at ordinary cycle distance `r<=k`, route its demand directly on the jump-`r` edge.

For a pair at ordinary cycle distance `r>=k+1`, apply Theorem 2.1. Choose uniformly among its `S_k` balanced compositions of `r`, choose a shortest orientation around the underlying cycle, and traverse the selected part sizes successively in that orientation.

If `n` is even and the pair is antipodal, first choose either shortest orientation with probability `1/2`.

Every selected route has total ordinary-cycle length `r`, so it is shortest for the dual metric (3.7), although it need not be shortest in the unweighted graph `C_n^k`.

For every `r>=k+1`, Theorem 2.1 gives
\[
\mathbb E N_s=\frac r{S_k}
\qquad(1\le s\le k),
\tag{3.9}
\]
so that distance class contributes equally to every jump orbit. For the direct classes `r=1,...,k`, the pair multiplicities are equal and each class contributes one direct jump of its own type; hence their aggregate contribution is also equal across jump types.

Therefore the total stationary product load summed over all physical edges of jump type `s` is one common value `T`, independent of `s`.

Every routed path for a pair at cycle distance `r` satisfies
\[
\sum_{s=1}^k sN_s=r.
\]
Averaging over the unordered stationary product demand gives
\[
S_kT=\bar d_C,
\qquad
T=\frac{\bar d_C}{S_k}.
\tag{3.10}
\]
Translation invariance spreads each orbit load uniformly over its `n` physical edges. Thus every edge has load
\[
\frac Tn.
\]
Dividing by the physical capacity `1/(2nk)` yields
\[
\psi
=2kT
=\frac{2k}{S_k}\bar d_C
=\frac4{k+1}\bar d_C.
\tag{3.11}
\]
Together with (3.8), this proves (3.3). `□`

# 4. Consequence for the Aldous–Fill diameter target

At the complete boundary `n=2k+1`,
\[
C_{2k+1}^k=K_{2k+1}.
\]
Formula (3.3) becomes
\[
F(K_{2k+1})=\frac{4k}{2k+1}.
\]
For the simple random walk on `K_{2k+1}`,
\[
\tau_{\rm rel}=\frac{2k}{2k+1},\qquad D=1,
\]
so
\[
F=2\tau_{\rm rel}D.
\]

Now assume `n>2k+1`, so the graph is connected and noncomplete. The previously archived interlacing lemma gives
\[
\lambda_2(P)\ge0,
\qquad
\tau_{\rm rel}\ge1.
\tag{4.1}
\]
Put
\[
R:=\left\lfloor\frac n2\right\rfloor.
\]
Then
\[
D(C_n^k)=\left\lceil\frac Rk\right\rceil.
\tag{4.2}
\]

If `n=2R` is even, (3.3) gives
\[
F=\frac{2R}{k+1}
\le2\frac Rk
\le2\left\lceil\frac Rk\right\rceil
=2D.
\tag{4.3}
\]

If `n=2R+1` is odd, then `R>=k+1` and
\[
F=\frac{4R(R+1)}{(k+1)(2R+1)}
<\frac{2(R+1)}{k+1}
\le\frac{2R}{k}
\le2D.
\tag{4.4}
\]

Hence every noncomplete cycle power satisfies the stronger estimate
\[
F(C_n^k)\le2D(C_n^k)\le2\tau_{\rm rel}D(C_n^k).
\tag{4.5}
\]

Combining the complete and noncomplete cases:
\[
\boxed{
F(C_n^k)\le2\tau_{\rm rel}D(C_n^k)
\quad\text{for every }k\ge1,\ n\ge2k+1.
}
\tag{4.6}
\]
