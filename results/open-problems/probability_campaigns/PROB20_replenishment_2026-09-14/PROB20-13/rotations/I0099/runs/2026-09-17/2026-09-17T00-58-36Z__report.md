## 3. B11 — DUALIZE: from a Paley triangle to full rational 4-torsion

Let \(p\equiv1\pmod4\) be prime and let \(a,b,c\in\mathbb F_p\) form a triangle in \(G_p\). Thus
\[
a-b,\quad a-c,\quad b-c
\]
are all nonzero quadratic residues. Consider
\[
E_{a,b,c}: y^2=(x-a)(x-b)(x-c).
\]
Its nonzero rational 2-torsion is
\[
P_a=(a,0),\qquad P_b=(b,0),\qquad P_c=(c,0).
\]

### Theorem 3.1 — every Paley triangle has full rational 4-torsion

For every such triangle,
\[
\boxed{E_{a,b,c}[4]\subset E_{a,b,c}(\mathbb F_p).}
\]
In particular,
\[
\boxed{16\mid \#E_{a,b,c}(\mathbb F_p).}
\]

### Proof

Because \(a-b\) and \(a-c\) are squares, choose \(r,s\in\mathbb F_p^\times\) with
\[
r^2=a-b,\qquad s^2=a-c.
\]
Set
\[
Q_a=(a+rs,\ rs(r+s)).
\]
First verify that \(Q_a\in E(\mathbb F_p)\). At \(x=a+rs\),
\[
x-a=rs,
\]
\[
x-b=(a-b)+rs=r^2+rs=r(r+s),
\]
\[
x-c=(a-c)+rs=s^2+rs=s(r+s).
\]
Hence
\[
(x-a)(x-b)(x-c)=r^2s^2(r+s)^2=[rs(r+s)]^2.
\]

Now compute the tangent slope. If \(f(x)=(x-a)(x-b)(x-c)\), then at \(x_0=a+rs\),
\[
f'(x_0)=2rs(r+s)^2,
\]
so the tangent slope is
\[
m=\frac{f'(x_0)}{2y_0}=r+s.
\]
Write
\[
f(x)=x^3-(a+b+c)x^2+\cdots.
\]
For a Weierstrass equation \(y^2=x^3+A x^2+\cdots\), the duplication formula gives
\[
x(2Q)=m^2-A-2x(Q).
\]
Here \(A=-(a+b+c)\), hence
\[
\begin{aligned}
x(2Q_a)
&=(r+s)^2+(a+b+c)-2(a+rs)\\
&=r^2+s^2+a+b+c-2a\\
&=(a-b)+(a-c)+a+b+c-2a\\
&=a.
\end{aligned}
\]
The only point of \(E\) with x-coordinate \(a\) is \((a,0)\), so
\[
2Q_a=P_a.
\]
Thus \(P_a\) is divisible by 2 in \(E(\mathbb F_p)\).

Repeating the same construction for \(P_b\) gives a rational point \(Q_b\) with \(2Q_b=P_b\). The points \(P_a,P_b\) are independent in \(E[2]\). Therefore \(Q_a,Q_b\) are independent order-4 points: if
\[
u Q_a+v Q_b=0,\qquad u,v\in\mathbb Z/4\mathbb Z,
\]
doubling gives
\[
(u\bmod2)P_a+(v\bmod2)P_b=0,
\]
so \(u,v\) are even; dividing them by two and using independence of \(P_a,P_b\) again forces \(u,v\equiv0\pmod4\). Hence \(\langle Q_a,Q_b\rangle\cong(\mathbb Z/4\mathbb Z)^2\) has 16 rational points. Since an elliptic curve in odd characteristic has exactly 16 geometric 4-torsion points, all of \(E[4]\) is rational. \(\square\)

This argument uses the **prime-field Paley triangle hypothesis**. It is not being asserted for arbitrary triples or imported from square prime powers.

## 4. B15 — BREAK THE SYMMETRY: every Paley triangle has an even number of common neighbors

Let
\[
t(a,b,c)=|N(a)\cap N(b)\cap N(c)|
\]
for a Paley triangle.

Brouwer–Martin write
\[
S=\sum_{x\in\mathbb F_p}\chi((x-a)(x-b)(x-c))
\]
and show
\[
p-3+S=8t(a,b,c)+4R.
\]
For a triangle, \(R=3\), so
\[
8t(a,b,c)=p-15+S.
\]
The associated elliptic curve has
\[
\#E(\mathbb F_p)=p+1+S.
\]
Therefore
\[
\boxed{t(a,b,c)=\frac{\#E(\mathbb F_p)-16}{8}.}
\]
By Theorem 3.1, \(16\mid\#E(\mathbb F_p)\). Hence
\[
\boxed{t(a,b,c)\equiv0\pmod2.}
\]

This is a strict refinement of the generic Hasse-scale statement for the special case of **triangles in prime-field Paley graphs**. The elliptic-curve representation is prior art; the parity extraction is recorded here as a derived consequence whose separate publication status is **UNVERIFIED**.

## 5. B15 continued — exact triple-overlap parity in the external binary code

Let \(C=\{c_1,\dots,c_k\}\) be a Paley clique. For each clique vertex define the set of external nonneighbors
\[
A_i=\{x\in\mathbb F_p\setminus C:\chi(x-c_i)=-1\}.
\]
The previous report's exact first/pairwise calculation gives
\[
|A_i|=\frac{p-1}{2},
\qquad
|A_i\cap A_j|=\frac{p-1}{4}\quad(i\ne j).
\]
Put
\[
q=\frac{p-1}{4}.
\]

### Theorem 5.1 — constant parity for every triple overlap

For every three distinct clique vertices,
\[
\boxed{|A_i\cap A_j\cap A_\ell|\equiv q\pmod2.}
\]

### Proof

Write
\[
m=|A_i\cap A_j\cap A_\ell|.
\]
The symmetric-difference size is
\[
|A_i\triangle A_j\triangle A_\ell|
=3(2q)-2(3q)+4m=4m.
\]
Therefore the external cubic sign sum is
\[
B_{ij\ell}
=\sum_{x\notin C}\chi((x-c_i)(x-c_j)(x-c_\ell))
=(p-k)-8m.
\tag{5.1}
\]

Let
\[
S_{ij\ell}=\sum_{x\in\mathbb F_p}\chi((x-c_i)(x-c_j)(x-c_\ell)).
\]
At the three selected clique vertices the summand is zero. At every other \(x\in C\), all three differences are squares, so the summand is +1. Thus
\[
B_{ij\ell}=S_{ij\ell}-(k-3).
\tag{5.2}
\]
The associated triangle elliptic curve satisfies
\[
\#E=p+1+S_{ij\ell}\equiv0\pmod{16},
\]
so
\[
S_{ij\ell}\equiv-(p+1)\pmod{16}.
\]
Equation (5.2) gives
\[
B_{ij\ell}\equiv2-p-k\pmod{16}.
\]
Comparing with (5.1),
\[
p-k-8m\equiv2-p-k\pmod{16},
\]
so
\[
8m\equiv2(p-1)\pmod{16}.
\]
Since \(p-1=4q\), this is equivalent to
\[
m\equiv q\pmod2.
\]
\(\square\)

Consequences:

- if \(p\equiv1\pmod8\), every pair and every triple column intersection has even size;
- if \(p\equiv5\pmod8\), every pair and every triple column intersection has odd size, while each single-column weight remains even.

Thus the external binary code is not an arbitrary equidistant code. Its third-order overlap parity is rigidly forced by finite-field arithmetic.

## 6. B11 continued — a radial weight law modulo 8

For \(J\subseteq\{1,\ldots,k\}\), let
\[
v_J=\bigtriangleup_{j\in J}A_j
\]
be the binary XOR of those columns and let \(m=|J|\). Inclusion–exclusion for symmetric difference gives
\[
\operatorname{wt}(v_J)
=\sum_{r\ge1}(-2)^{r-1}
\sum_{I\subseteq J,\ |I|=r}
\left|\bigcap_{i\in I}A_i\right|.
\]
Modulo 8, all terms with \(r\ge4\) vanish. Using
\[
|A_i|=2q,
\qquad
|A_i\cap A_j|=q,
\qquad
|A_i\cap A_j\cap A_\ell|\equiv q\pmod2,
\]
we obtain the exact congruence
\[
\boxed{
\operatorname{wt}(v_J)
\equiv
2q\left(m-\binom m2\right)
+4(q\bmod2)\binom m3
\pmod8.
}
\tag{6.1}
\]
The right-hand side depends only on \(m\) and \(p\bmod16\), not on which clique columns were chosen.

### Corollary 6.1 — triply-even span when \(p\equiv1\pmod{16}\)

If \(p\equiv1\pmod{16}\), then \(q\equiv0\pmod4\), and (6.1) gives
\[
\boxed{\operatorname{wt}(v_J)\equiv0\pmod8\quad\text{for every }J.}
\]
Thus the binary span generated by the external nonneighbor columns is triply even.

### Corollary 6.2 — allowed sizes of a column dependence

If a subset \(J\) is a binary dependence, then \(v_J=0\), so the right side of (6.1) must vanish modulo 8. It is periodic in \(m\) modulo 8. Therefore:

- \(p\equiv5\pmod{16}\): \(m\equiv0,7\pmod8\);
- \(p\equiv9\pmod{16}\): \(m\equiv0,3,4,7\pmod8\);
- \(p\equiv13\pmod{16}\): \(m\equiv0,7\pmod8\).

For \(p\equiv1\pmod{16}\), the mod-8 weight law is identically zero and gives no dependence-size restriction by itself.

This is a **dual/code invariant** unavailable to the real Gram-matrix/Plotkin argument of the previous report.

## 7. B24 — FIND THE EXTREMAL OBJECT: what the new invariant does and does not buy

The previous run built abstract exchangeable sign distributions that simultaneously:

1. match the exact Paley first moments;
2. match the exact Paley pair correlations;
3. assign zero mass to the all-plus extension cell.

Those models establish that second-order moment data cannot force an extension and hence cannot prove the source polylogarithmic bound.

The new theorems expose a concrete way in which an actual Paley clique is more rigid than those abstract models: its binary column system must satisfy, **for every triple**, the fixed overlap parity of Theorem 5.1, and therefore every span word obeys the radial mod-8 law (6.1).

So the source-scale extremal feasibility problem can now be sharpened to:

\[
\boxed{
\begin{array}{c}
\text{classify or exclude large equidistant binary sign systems that}\\
\text{simultaneously satisfy the Paley first/pair moments, the all-plus}\\
\text{defect, the constant triple-overlap parity, the radial mod-8 law,}\\
\text{and the fact that the columns arise from quadratic translates.}
\end{array}
}
\]

This is a real narrowing of the missing mechanism. It is **not yet** a source proof. Divisible-code constraints alone generally permit dimensions far larger than polylogarithmic in the ambient length, so the mod-8 law must be coupled to the actual quadratic-residue/translate structure, not treated as sufficient on its own.

The strongest conceptual conclusion of this run is therefore:

> the prior second-order no-go can be escaped, but the first available escape is a genuinely arithmetic third-order invariant; the next proof attempt should combine this 2-adic code rigidity with finite-field translation structure rather than add another generic moment inequality.
