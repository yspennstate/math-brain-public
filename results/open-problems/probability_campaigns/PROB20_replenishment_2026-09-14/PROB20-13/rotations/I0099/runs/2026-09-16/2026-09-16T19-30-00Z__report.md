## 3. B22 — read the failures: why the strongest character/direction arguments stop at square root

The first new-method question was not “how do we optimize the existing branch-and-bound?”, but “what exact mathematical information is missing from the best analytic proofs?”

For the Paley graph, take the connection set `Q` of nonzero quadratic residues, so

`|Q|=(p-1)/2` and `Q/Q=Q`.

Yip's prime-field Cayley bound specializes to

`omega(G_p) < sqrt(|Q/Q|)+1 = sqrt((p-1)/2)+1`,

which is the Hanson--Petridis square-root scale. In the Stepanov formulation underlying the prime case, the central inequality has the shape

`(N-1)n <= (p-1)/2`

for an auxiliary integer `n <= N`, where `N` is the putative clique size. The strongest direct choice `n=N` yields

`N(N-1) <= (p-1)/2`,

hence only `N=O(sqrt p)`.

This identifies a concrete obstruction: these arguments encode pair/direction or one-polynomial multiplicity information. They do not accumulate cancellation from the exponentially many **simultaneous translate constraints** created by a growing clique.

That same barrier is visible from the elementary common-neighbor character expansion. Let `S={s_1,...,s_k}` be a clique and, away from the anchor points, define

`L(S)={x in F_p : chi(x-s)=1 for every s in S}`.

Ignoring only the explicitly correctable anchor zeros, the indicator expands as

`1_{x in L(S)} = 2^{-k} prod_{s in S}(1+chi(x-s))`.

Therefore `|L(S)|` is a main term `p/2^k` plus an average of nontrivial character sums

`sum_x chi(prod_{s in T}(x-s))`, `empty != T subseteq S`.

Applying the Weil square-root estimate to each subset separately and then using the triangle inequality leaves an aggregate error of order `k sqrt(p)`: the factor `2^k` of subsets is canceled by the prefactor `2^{-k}`, while the average polynomial degree is of order `k`. Thus even after `k` anchors this straightforward route gives only

`|L(S)| <= p/2^k + O(k sqrt(p))`.

At the natural localization depth `k ~ (1/2) log_2 p`, the square-root error dominates exactly when one would need a much smaller extension set. This is the same square-root barrier in a different language.

**Conclusion of B22.** A polylogarithmic proof needs cancellation **across** the family of subset character sums, or an equivalent high-order structural statement. Improving the constant in an individual Weil/Stepanov bound cannot by itself reach the source target. This is consistent with Kunisky's localization program: higher localizations demand genuinely higher-order character information.

No theorem of the source conjecture is claimed from this analysis. Its value is to rule out spending subsequent runs merely polishing the known square-root machinery.

## 4. B5 — add the extension-count parameter and differentiate it discretely

For any clique anchor `S`, write

`M(S)=|L(S)|`,

where `L(S)` is the induced common-neighbor graph of the anchors. If `v in L(S)`, then exactly

`L(S union {v}) = N_{L(S)}(v)`

and therefore

`M(S union {v}) = deg_{L(S)}(v)`.

This is a literal discrete derivative of the extension-count parameter. Summing over all possible next anchors gives the exact double-count identity

`sum_{v in L(S)} M(S union {v}) = 2 e(L(S)).`   (4.1)

The identity is elementary but useful because it isolates what a uniform proof must control: not just the average next extension size, but the large-degree tail along a chain of mutually adjacent anchors.

### Lemma 4.1 — exact core peeling preserves every clique extension

Let `H` be any finite graph and let `r>=1`. Iteratively delete vertices whose current degree is `< r-1`. If `H` contains an `r`-clique, every vertex of that clique survives the entire deletion process.

### Proof

Let `C` be an `r`-clique. At any stage before a vertex of `C` is deleted, every vertex of `C` is adjacent to the other `r-1` vertices of `C`, all of which are still present if this is the first deletion from `C`. Hence no vertex of `C` can be the first vertex of `C` deleted by the rule `degree < r-1`. By induction no vertex of `C` is ever deleted. QED.

Applied after the `S_3 -> V_4` anchor reductions, this gives a sound exact preprocessing rule for every final `r`-clique decision problem.

I implemented the rule and compared it on a fixed archived obligation range at the blocker `p=3209`, `omega=15`, `S_3` anchors `24..30`. The same deterministic color-bound search without core peeling used

`4,578,739` recursive nodes in `3.255118` seconds.

The core-peeling variant used

`4,534,584` recursive nodes in `5.097476` seconds.

Thus it reduced the node count by only `44,155`, about `0.96435%`, while increasing measured wall time by a factor about `1.566` because repeated degree counts cost more than the tiny pruning gain. This is an actually executed negative experiment, not a route promoted on aesthetic grounds.

The reason is structural: these localized Paley candidate graphs remain quite dense, while the relevant `r-1` thresholds are small. The ordinary core is therefore almost the whole graph.

## 5. B3 — strengthen the invariant: an extension-profile / higher-face peeling hierarchy

The failure of vertex-core peeling suggests strengthening the preserved object rather than adding another low-level coding heuristic.

For a graph `H` and an integer `t>=1`, define the extension count of a `t`-clique `T` by

`ext_H(T)=| intersection_{v in T} N_H(v) |`.

### Lemma 5.1 — all faces of an `r`-clique have forced extension counts

If `C` is an `r`-clique in `H` and `T subseteq C` has `|T|=t`, then

`ext_H(T) >= r-t`.

Consequently, any iterative procedure that deletes a `t`-clique only when its current extension count is `< r-t` can never delete a `t`-face of an existing `r`-clique.

### Proof

Every vertex of `C\T` is adjacent to every vertex of `T`, so `C\T` is contained in the common-neighbor set of `T`. Hence `ext_H(T)>=|C\T|=r-t`. If a peeling process were to delete the first `t`-face belonging to an existing `r`-clique, all other vertices of that clique needed as extensions would still be present at that moment, contradicting the deletion threshold. QED.

For `t=1` this is Lemma 4.1. For `t=2` it is the familiar exact truss condition: every edge of an `r`-clique has at least `r-2` common neighbors. Larger `t` produces a genuine hierarchy of necessary extension-profile constraints.

This is a stronger invariant that survives localization and is a mathematically clean bridge to the character expansion in Section 3: for an anchored clique `S`, each `ext(T)` is itself a simultaneous quadratic-character constraint count.

However, the same density issue blocks the naive finite use. At the current prime scale, low-order face supports are still far above the small thresholds `r-t`; root-level core/truss peeling therefore leaves essentially all obligations. More importantly, a source-level argument would need to prove that **some** face along every large clique has unusually small extension count. The separate Weil bounds from Section 3 do not give that.

So B3 produces a sharper target rather than a source theorem:

> obtain uniform high-order cancellation for the extension-profile counts along a Paley clique, strong enough that the hierarchy must terminate after polylogarithmically many anchors.

That statement is not claimed proved. It tells the next attack exactly what new information must enter: cancellation among correlated character sums, not further projective symmetry or pairwise spectral information.
