## 3. B12 — the localized graph itself has an exact anharmonic S3 action

Let `chi` be the quadratic character of `F_p`, with `p = 1 (mod 4)`. Normalize a clique edge to `{0,1}` and define

`H_p = G_p[N(0) intersect N(1)]`.

Thus

`V(H_p) = {x in F_p \ {0,1}: chi(x)=chi(x-1)=1}`.

The previous run observed the six cross-ratio transforms when one normalizes a triangle. The stronger invariant needed here is that the transforms act as **automorphisms of the entire graph `H_p`**, so they may be used for exact search symmetry breaking without conditioning on a chosen triangle.

### Lemma 3.1 — S3 automorphism action on `H_p`

The maps

`s(x)=1-x`,  `t(x)=x^{-1}`

preserve `H_p` and its adjacency. They generate the anharmonic group of order six, with orbit contained in

`{x, 1-x, x^{-1}, 1-x^{-1}, (1-x)^{-1}, x/(x-1)}`.

#### Proof

Because `p = 1 (mod 4)`, `chi(-1)=1`.

If `x in H_p`, then `chi(x)=chi(x-1)=1`. For `s(x)=1-x`,

`chi(1-x)=chi(-(x-1))=1`

and

`chi((1-x)-1)=chi(-x)=1`,

so `s(x) in H_p`.

For `t(x)=x^{-1}`,

`chi(x^{-1})=1`,

and

`chi(x^{-1}-1)=chi((1-x)/x)=chi(1-x) chi(x)^{-1}=1`,

so `t(x) in H_p`.

For adjacency, if `x,y in H_p`, then

`s(x)-s(y)=-(x-y)`,

whose quadratic character equals `chi(x-y)` because `-1` is a square. Also

`t(x)-t(y)=x^{-1}-y^{-1}=-(x-y)/(xy)`.

Here `-1`, `x`, and `y` are all squares, so again

`chi(t(x)-t(y))=chi(x-y)`.

Hence both generators preserve adjacency and generate graph automorphisms. The usual relations `s^2=t^2=(st)^3=1` give the anharmonic `S_3` action. QED.

The new exact checker exhaustively verifies both generators on every vertex and every vertex pair for every newly certified prime; it does not merely assume the symbolic proof.

## 4. B18 — exact difference-set language and what it clarifies

The normalized clique problem can be restated without graph terminology. A clique in `H_p` is a set `S subset F_p` such that

1. `chi(x)=chi(x-1)=1` for every `x in S`, and
2. `chi(x-y)=1` for every distinct `x,y in S`.

So the finite problem is a constrained difference-set problem inside

`Q intersect (1+Q)`,

where `Q` is the nonzero quadratic-residue subgroup.

This language makes two points sharp.

First, the rank-3 association-scheme/Delsarte data used in the preceding run remembers only whether each individual difference lies in `Q`; by itself it reaches the familiar square-root barrier. Any source-level polylogarithmic proof must exploit **higher-order compatibility among many differences simultaneously**, not simply another two-class spectral inequality.

Second, the anharmonic `S_3` action above is natural in this language: it is the projective symmetry of a configuration with the two marked points `0,1`. It gives a finite exact quotient for the search, while leaving the asymptotic additive-structure problem untouched.

Outcome B18: the reformulation did not prove a new asymptotic bound, but it identified the precise higher-order object a uniform argument has to control and kept the route separate from Conjectures 26--29.

## 5. B20 — why the old exact algorithm failed at 2741, and the exact repair

The previous exact solver already used the affine Paley automorphism group to normalize an arbitrary clique edge to `{0,1}`. Therefore

`omega(G_p) = 2 + omega(H_p)`.

It used an exact branch-and-bound search on `H_p`, with a greedy coloring of the current candidate graph as an upper bound. At `p=2741`, the global search exceeded the bounded execution call even though prior finite tables say the true clique number is only 13.

The failure is a proof-search failure, not evidence of a large clique: on this pseudorandom-looking localized graph, the first-bit greedy coloring can use far more colors than the true clique number, so a monolithic decision tree becomes large.

The S3 invariant supplies a safe way to cut that tree into complete independent obligations.

### Lemma 5.1 — orbit-representative exclusion is complete

Suppose a clique `C` of size `r` exists in `H_p`. Choose any `v in C`, and let `u` be the fixed representative of the `S_3` orbit of `v`. By Lemma 3.1 there is an automorphism `g` in the anharmonic group with `g(v)=u`. Then `g(C)` is an `r`-clique containing `u`, so `N_{H_p}(u)` contains an `(r-1)`-clique.

Consequently, to prove that `H_p` has no `r`-clique, it is enough to choose one representative `u` from **every** `S_3` orbit and prove that `H_p[N(u)]` has no `(r-1)`-clique. QED.

For a proposed exact value `omega(G_p)=w`, the archived certificate now has two parts:

- a directly checked `w`-clique witness in `G_p`; and
- for every S3 orbit representative in `H_p`, an exhaustive proof that its neighborhood has no clique of size `w-2`.

If `G_p` had a clique of size `w+1`, then `H_p` would have one of size `w-1`; Lemma 5.1 would put an `(w-2)`-clique in the neighborhood of one searched representative, contradiction.

### Exactness of each branch-and-bound subsearch

The decision solver is integer/bitset-only. At a node with candidate set `P` and remaining requirement `r`, it greedily partitions `P` into independent color classes. If `c` classes are produced then every clique in `P` has size at most `c`. The recursion branches over the candidate vertices and prunes only when the candidate count or this coloring upper bound is below `r`. Thus a completed negative search is an exhaustive nonexistence proof. The `proof64` and aggregate hashes are only deterministic trace digests for reproducibility; they are not presented as standalone proof objects.

The key practical benefit of the S3 split is that each orbit obligation is separately bounded and archiveable. The former blocker `p=2741` has 684 localized vertices and 114 S3 orbits. The complete exclusion of a 12-clique in `H_2741` was split into four exact orbit ranges. Across all 114 representatives the searches visited 41,430,564 decision nodes and all returned negative. The same run also found and directly verified a 13-clique in `G_2741`.
