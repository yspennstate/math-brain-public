## 3. B18 — say it in another language: an exact external binary code

Let \(C=\{c_1,\dots,c_k\}\subset\mathbb F_p\) be a Paley clique. Put
\[
N=p-k
\]
and define the external sign matrix
\[
M=M(C)\in\{\pm1\}^{N\times k},
\qquad
M_{x,i}=\chi(x-c_i),
\quad x\in\mathbb F_p\setminus C.
\]

### Theorem 3.1 — exact Gram matrix

For every Paley clique \(C\),
\[
\boxed{
M^\top M=(p-1)I_k-(k-1)J_k.
}
\tag{3.1}
\]

#### Proof

For \(i=j\), all external entries are \(\pm1\), so
\[
(M^\top M)_{ii}=N=p-k=(p-1)-(k-1).
\]

Now fix \(i\ne j\). The standard quadratic-character correlation is
\[
\sum_{x\in\mathbb F_p}
\chi((x-c_i)(x-c_j))=-1.
\tag{3.2}
\]
At \(x=c_i,c_j\) the summand is zero. At each of the other \(k-2\) clique vertices \(x\in C\setminus\{c_i,c_j\}\), both differences are Paley edges and hence squares. Because \(p\equiv1\pmod4\), \(-1\) is also a square, so orientation causes no sign change. Thus each of those \(k-2\) removed terms equals \(+1\). Therefore
\[
(M^\top M)_{ij}
=-1-(k-2)=-(k-1).
\]
This is exactly (3.1). \(\square\)

### Corollary 3.2 — an equidistant binary-code model

Map a sign column to a binary word by \(+1\mapsto0\), \(-1\mapsto1\). Every column has Hamming weight
\[
\frac{N-(-(k-1))}{2}=\frac{p-1}{2},
\]
and every pair of distinct columns has Hamming distance
\[
\boxed{d=\frac{p-1}{2}.}
\tag{3.3}
\]

After XOR-normalizing by one codeword, the other \(k-1\) words all have weight \(d\) and any two supports intersect in exactly
\[
\frac d2=\frac{p-1}{4}.
\tag{3.4}
\]

This is a clean coding-theoretic reformulation of the clique constraint at second order.

### Corollary 3.3 — why the ordinary two-class code bound stops at \(\sqrt p\)

The eigenvalues of the Gram matrix (3.1) are
\[
p-1\quad\text{with multiplicity }k-1,
\]
and
\[
p-1-k(k-1)
\quad\text{on the all-ones direction}.
\]
Positive semidefiniteness gives
\[
\boxed{k(k-1)\le p-1.}
\tag{3.5}
\]
Thus the exact equidistant-code / Gram information alone reproduces only the classical square-root barrier.

More generally, for every \(a\in\mathbb R^k\),
\[
\boxed{
\sum_{x\notin C}
\left(\sum_{i=1}^k a_i\chi(x-c_i)\right)^2
=
(p-1)\sum_i a_i^2-(k-1)\left(\sum_i a_i\right)^2.
}
\tag{3.6}
\]
In particular, on the codimension-one subspace \(\sum_i a_i=0\), the quadratic form is **exactly** \((p-1)\|a\|_2^2\). This is the full conserved second-order information of the external sign system.

This route does not prove a polylogarithmic bound. It identifies exactly where a coding-theoretic proof must go beyond ordinary distance distributions: it must use higher-order/algebraic restrictions on the rows.

## 4. B18 literature cross-check — self-dual GRS codes are a known, broader Paley correspondence

There is another coding translation, but the fresh literature check shows it is already embedded in a broader result of Li–Zhou (arXiv:2512.19312).

### Proposition 4.1 — every even subclique yields a self-dual MDS GRS code

Let
\[
S=\{a_1,\dots,a_{2m}\}\subset C
\]
be any even subset of a Paley clique. Put
\[
L_i=\prod_{j\ne i}(a_i-a_j).
\]
Every factor \(a_i-a_j\) is a nonzero square, so every \(L_i\) is a square. Hence \(L_i^{-1}\) is a square; choose \(v_i\in\mathbb F_p^\times\) with
\[
v_i^2=L_i^{-1}.
\]
Then
\[
\mathrm{GRS}_m(S,v)
=
\left\{
(v_i f(a_i))_{i=1}^{2m}:\deg f<m
\right\}
\]
is a Euclidean self-dual \([2m,m,m+1]\) MDS code.

#### Direct proof

For every polynomial \(h\) of degree at most \(2m-2\),
\[
\boxed{
\sum_{i=1}^{2m}\frac{h(a_i)}{L_i}=0.
}
\tag{4.1}
\]
Indeed, use Lagrange interpolation
\[
h(X)=\sum_i h(a_i)
\frac{\prod_{j\ne i}(X-a_j)}{L_i}
\]
and compare the coefficient of \(X^{2m-1}\): it is zero on the left and equals the sum in (4.1) on the right.

If \(\deg f,\deg g<m\), then \(\deg(fg)\le2m-2\), so
\[
\sum_i v_i^2f(a_i)g(a_i)
=
\sum_i\frac{f(a_i)g(a_i)}{L_i}=0.
\]
The GRS code has dimension \(m\), so self-orthogonality in length \(2m\) implies self-duality. Its MDS property follows directly because a nonzero polynomial of degree \(<m\) has at most \(m-1\) roots among the evaluation points, so every nonzero codeword has weight at least
\[
2m-(m-1)=m+1,
\]
meeting the Singleton bound. \(\square\)

### Prior-art status of Proposition 4.1

This proposition is **not claimed novel**. Li–Zhou Theorem 2.4 gives the general derivative-character criterion for self-dual GRS codes and explicitly relates it to degree-parity induced subgraphs of Paley graphs/tournaments. A clique is simply an especially rigid odd-degree induced subgraph when its order is even.

Li–Zhou also prove asymptotic abundance of the broader parity class for \(r=o(q^{1/4})\). Consequently, **self-dual-GRS existence by itself is too weak to force a small clique**: many evaluation sets pass that parity/code test without being cliques. The useful residue of B18 is therefore the stronger exact sign-Gram condition (3.1), not generic GRS self-duality.

## 5. B12 — find what is conserved: the complete Krawtchouk generating transform

The previous report used the individual Boolean-Fourier coefficients
\[
B_T
=
\sum_{x\notin C}
\prod_{c\in T}\chi(x-c),
\qquad T\subseteq C.
\]
This run packages **all** of them into one exact positive-coefficient polynomial.

For each external vertex \(x\notin C\), define
\[
q_C(x)
=
|\{c\in C:\chi(x-c)=-1\}|,
\]
the number of clique vertices to which \(x\) is **not** adjacent. Let
\[
N_r
=
|\{x\notin C:q_C(x)=r\}|,
\qquad 0\le r\le k.
\]
Thus \(N_0\) is exactly the number of common neighbors of the entire clique; \(C\) is maximal iff \(N_0=0\).

Define
\[
F_C(z)
=
\sum_{T\subseteq C}B_T z^{|T|}.
\tag{5.1}
\]

### Theorem 5.1 — exact transform

For every clique \(C\),
\[
\boxed{
F_C(z)
=
\sum_{r=0}^k
N_r(1+z)^{k-r}(1-z)^r.
}
\tag{5.2}
\]
Equivalently, after the Möbius change of variables
\[
u=\frac{1-z}{1+z},
\qquad
z=\frac{1-u}{1+u},
\]
the non-neighbor generating polynomial
\[
Q_C(u)=\sum_{r=0}^kN_r u^r
\]
satisfies
\[
\boxed{
Q_C(u)
=
\left(\frac{1+u}{2}\right)^k
F_C\!\left(\frac{1-u}{1+u}\right).
}
\tag{5.3}
\]

#### Proof

For fixed \(x\notin C\),
\[
\sum_{T\subseteq C}
z^{|T|}
\prod_{c\in T}\chi(x-c)
=
\prod_{c\in C}(1+z\chi(x-c)).
\]
If \(q_C(x)=r\), exactly \(k-r\) factors use \(+1\) and \(r\) factors use \(-1\), so the product is
\[
(1+z)^{k-r}(1-z)^r.
\]
Summing over all external \(x\) proves (5.2). Substituting the displayed Möbius change gives
\[
1+z=\frac{2}{1+u},
\qquad
1-z=\frac{2u}{1+u},
\]
which is exactly (5.3). \(\square\)

### Corollary 5.2 — Krawtchouk form

Let
\[
S_j=\sum_{|T|=j}B_T.
\]
Then
\[
\boxed{
S_j
=
\sum_{r=0}^k N_r K_j(r;k),
}
\tag{5.4}
\]
where
\[
K_j(r;k)
=
\sum_{a=0}^j(-1)^a
\binom ra\binom{k-r}{j-a}
\]
is the binary Krawtchouk polynomial.

Thus the aggregate character correlations and the exact extension-defect distribution are two coordinate systems for the same object.

### Corollary 5.3 — maximality is a boundary zero

A clique is maximal iff
\[
N_0=0.
\]
By (5.3), this is equivalent to
\[
\boxed{F_C(1)=0.}
\tag{5.5}
\]
If \(C\) is maximal, then also
\[
\boxed{
N_1
=
-2^{1-k}F_C'(1)
=
-2^{1-k}\sum_{T\subseteq C}|T|B_T.
}
\tag{5.6}
\]
So the number of one-vertex-away extensions is an exact weighted aggregate of the entire character-correlation family.

This does not solve the source. It does sharpen the target: the source conjecture asks, in this language, for an algebraic reason that the positive polynomial \(Q_C\) cannot lose its constant coefficient once \(k\) is above a fixed power of \(\log p\).

## 6. B12 — exact first two defect moments

The sign Gram matrix or direct Paley strong-regularity counting gives
\[
\boxed{
\sum_{x\notin C}q_C(x)=\frac{k(p-1)}2,
}
\tag{6.1}
\]
and
\[
\boxed{
\sum_{x\notin C}(q_C(x))_2
=
\frac{k(k-1)(p-1)}4.
}
\tag{6.2}
\]
Hence for a uniformly random external row,
\[
\mu:=\mathbb E q
=
\frac{k(p-1)}{2(p-k)},
\tag{6.3}
\]
\[
\mathbb E(q)_2
=
\frac{k(k-1)(p-1)}{4(p-k)},
\tag{6.4}
\]
and
\[
\boxed{
\operatorname{Var}(q)
=
\frac{k(p-1)(p-k^2)}{4(p-k)^2}.
}
\tag{6.5}
\]
Again, the variance is nonnegative exactly up to the same square-root condition.

## 7. B23 — assume the opposite: a source-scale no-go theorem for every second-order argument

The parity half-cube example in the previous report showed abstractly that low-degree moments can miss an empty all-plus atom. The next theorem is stronger: it matches the **actual Paley first and pairwise sign moments exactly** while still assigning zero probability to the all-plus pattern.

### Theorem 7.1 — exact abstract no-extension model with Paley first/pair moments

Let \(k\ge4\) and let \(p\) be an integer satisfying
\[
\boxed{p\ge2k^2.}
\tag{7.1}
\]
Put \(N=p-k\). There exists an exchangeable probability distribution \(\mathcal D_{p,k}\) on
\[
\{\pm1\}^k\setminus\{(+1,\dots,+1)\}
\]
such that for every coordinate \(i\) and every pair \(i\ne j\),
\[
\boxed{
\mathbb E_{\mathcal D}\sigma_i
=
\mathbb E_{\mathcal D}\sigma_i\sigma_j
=
-\frac{k-1}{p-k}.
}
\tag{7.2}
\]
These are exactly the normalized first and pairwise moments of the external sign rows of a Paley \(k\)-clique.

All probabilities can be chosen rational, so after clearing denominators this is also a finite multiset model.

#### Proof

It is enough to construct an integer-valued random variable
\[
Q\in\{1,2,\dots,k\}
\]
giving the number of negative coordinates, and then conditionally on \(Q=q\) choose uniformly among the \(\binom{k}{q}\) sign vectors with exactly \(q\) negatives.

We require
\[
\mu:=\mathbb E Q
=
\frac{k(p-1)}{2N}
\tag{7.3}
\]
and
\[
\nu:=\mathbb E(Q)_2
=
\frac{k(k-1)(p-1)}{4N}.
\tag{7.4}
\]
The corresponding target variance is
\[
\sigma^2
=
\nu+\mu-\mu^2
=
\frac{k(p-1)(p-k^2)}{4N^2}.
\tag{7.5}
\]

We now show that a distribution on \(\{1,\dots,k\}\) with this mean and variance exists.

Let
\[
a=\lfloor\mu\rfloor,
\qquad
\theta=\mu-a.
\]
The distribution supported on \(a,a+1\) with probabilities \(1-\theta,\theta\) has mean \(\mu\) and the **minimum** possible variance among integer-valued distributions with this mean:
\[
v_{\min}=\theta(1-\theta)\le\frac14.
\tag{7.6}
\]
Because \(p\ge2k^2\),
\[
\sigma^2
=
\frac{k(p-1)(p-k^2)}{4N^2}
\ge
\frac{k}{16}
\ge\frac14,
\tag{7.7}
\]
using \(p-1\ge p/2\), \(p-k^2\ge p/2\), and \(N\le p\). Hence \(\sigma^2\ge v_{\min}\).

At the other extreme, the distribution on \(\{1,k\}\) with mean \(\mu\) has variance
\[
v_{\max}=(\mu-1)(k-\mu).
\tag{7.8}
\]
The target factorial moment obeys
\[
\nu=\frac{k-1}{2}\mu.
\tag{7.9}
\]
Since \(k\ge4\) and \(\mu\ge k/2\),
\[
\mu\ge\frac{2k}{k+1},
\]
which is equivalent to
\[
\nu\le k(\mu-1).
\]
Adding \(\mu-\mu^2\) to both sides gives
\[
\sigma^2\le(\mu-1)(k-\mu)=v_{\max}.
\tag{7.10}
\]

Therefore \(\sigma^2\in[v_{\min},v_{\max}]\). Mix the minimum-variance and endpoint distributions in the unique proportion that gives variance \(\sigma^2\). Both component distributions have the same mean \(\mu\), so the mixture has (7.3)–(7.5). All quantities are rational, and its support lies in \(\{1,\dots,k\}\), so \(Q=0\) never occurs.

Finally, under the exchangeable shell model,
\[
\mathbb E\sigma_i
=
1-\frac{2\mathbb EQ}{k}
=
1-\frac{p-1}{N}
=
-\frac{k-1}{N}.
\tag{7.11}
\]
Also
\[
\mathbb E[Q(k-Q)]
=
(k-1)\mu-\nu
=
\frac{k-1}{2}\mu.
\tag{7.12}
\]
Conditional on \(Q=q\), exactly one of two fixed coordinates is negative with probability
\[
\frac{2q(k-q)}{k(k-1)}.
\]
Hence
\[
\begin{aligned}
\mathbb E\sigma_i\sigma_j
&=
1-\frac{4\mathbb E[Q(k-Q)]}{k(k-1)}\\
&=
1-\frac{2\mu}{k}\\
&=
-\frac{k-1}{N}.
\end{aligned}
\tag{7.13}
\]
This proves (7.2), while \(Q\ge1\) proves that the all-plus atom has probability zero. \(\square\)

### Consequence for Conjecture 25

For every fixed \(A\),
\[
k=(\log p)^A
\]
satisfies \(p\ge2k^2\) for all sufficiently large \(p\). Thus **throughout the conjectural source scale**, the exact first and pairwise Paley sign moments are compatible with a distribution having no common-neighbor atom.

Therefore:

> Any proof of the polylogarithmic clique bound that uses only nonnegativity/exchangeability together with the exact first and pairwise sign moments is impossible in principle.

A successful proof must use genuinely higher-order algebraic constraints that distinguish the quadratic-character row set from the abstract distribution \(\mathcal D_{p,k}\).

This is a no-go theorem about a proof class, **not** a Paley counterexample and not a source refutation. The constructed sign distribution is abstract and need not arise from \(p-k\) actual finite-field rows.
