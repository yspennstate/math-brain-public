## 5. New mathematical idea before code

No code was written in this run. The first successor attack is a structural filter derived in Fourier/coding language.

Let `Q` be uniform on `F_2^N`, and let `P` be uniform on an affine binary linear code `a+C`. Write `L=dP/dQ`. With the Walsh characters `chi_u(x)=(-1)^{<u,x>}`, direct summation gives

\[
  \widehat L(u)=(-1)^{\langle u,a\rangle}\,\mathbf 1_{\{u\in C^\perp\}}.
\]

Indeed,

\[
\widehat L(u)
=2^{-N}\sum_x L(x)(-1)^{\langle u,x\rangle}
=|C|^{-1}\sum_{x\in a+C}(-1)^{\langle u,x\rangle},
\]

and the final character average is zero unless `u` annihilates `C`, in which case it is the phase `(-1)^{<u,a>}`.

Therefore if the dual distance satisfies

\[
  d(C^\perp)>D,
\]

then **every nonconstant likelihood-ratio Fourier coefficient of degree at most `D` vanishes exactly**. Equivalently, `P` and the uniform null have identical marginals on every coordinate set of size at most `D`.

Under independent bit noise with correlation parameter `rho`, the Bonami--Beckner/noise operator acts diagonally:

\[
  \widehat{T_\rho L}(u)=\rho^{|u|}\widehat L(u).
\]

Thus noise attenuates the hidden dual-code spectrum but does not create any low-degree Fourier signal that was absent before. A global algebraic certificate can nevertheless remain efficiently decodable from the noisy sample. Mao's 2026 graph construction is a source-relevant realization of precisely this separation: exact polylogarithmic-wise marginal uniformity and permutation invariance coexist with a polynomial-time rank distinguisher.

This yields a rigorous **route filter** (not a novelty claim and not a solution of the source question):

> No proposed sufficient condition that is determined only by the degree-`<=D` marginal/Fourier data together with the metadata `product uniform null + permutation invariance + independent resampling` can imply polynomial indistinguishability in the general graph setting.

The missing positive ingredient has to constrain global organization invisible to all `D`-local marginals. Chen--Li's treewidth theorem suggests one promising language: a quantitative *separator/decomposability* condition on the high-degree Fourier support, so that every large support can be broken into low-degree pieces meeting along a small interface and noise can absorb the recombination cost. The next run should try to formulate this as a clean abstract hypothesis and prove the corresponding reassembly inequality, rather than inventing another variant of the already-refuted broad conjecture.
