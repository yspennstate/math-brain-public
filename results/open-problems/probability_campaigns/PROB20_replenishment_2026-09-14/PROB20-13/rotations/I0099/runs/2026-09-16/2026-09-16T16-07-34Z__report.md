## 4. Exact symmetry reduction

Let `G_p` be the prime-field Paley graph, with `x~y` exactly when `x-y` is a nonzero quadratic residue modulo `p`. Since `p=1 mod 4`, `-1` is a square, so adjacency is undirected.

### Lemma 4.1 — fixed-edge normalization

For every clique `C` with at least two vertices, there is a Paley automorphism sending two chosen vertices of `C` to `0` and `1`. Consequently, if

`H_p = G_p[N(0) cap N(1)]`,

then

`omega(G_p) = 2 + omega(H_p)`.

**Proof.** Pick distinct `a,b` in `C`. Since they are adjacent, `d=b-a` is a nonzero quadratic residue. Translation by `-a` preserves all differences, and multiplication by `d^{-1}` preserves quadratic-residue status because `d^{-1}` is itself a square. Thus

`x -> (x-a)d^{-1}`

is a graph automorphism carrying `a,b` to `0,1`. Every remaining clique vertex lands in the common neighborhood of `0,1`, proving `omega(G_p) <= 2+omega(H_p)`. Conversely, every clique of `H_p`, together with `0,1`, is a clique of `G_p`, proving equality. QED.

For reference, the common-neighborhood size is exactly

`|V(H_p)|=(p-5)/4`.

Indeed, with `chi` the quadratic character and excluding `x=0,1`, its indicator is `(1+chi(x))(1+chi(x-1))/4`. The two linear character sums each contribute `-1`, while `sum_x chi(x(x-1))=-1`; hence the total is `(p-2-1-1-1)/4=(p-5)/4`.

This reduces `p` vertices to roughly `p/4` without changing the exact clique obligation.

## 5. Exhaustive exact upper certificate

The archived checker uses only integer modular arithmetic and exact bitsets; there is no floating-point or SDP step.

For each admissible prime `p` it:

1. constructs the quadratic-residue table exactly from the squares `x^2 mod p`;
2. constructs `H_p` on those `x` for which both `x` and `x-1` are nonzero squares;
3. finds a clique in `H_p` by deterministic branch-and-bound;
4. verifies pair-by-pair that the lifted set `{0,1} union C_H` is a clique of `G_p`;
5. runs a separate decision recursion asking whether `H_p` contains a clique of size `omega(G_p)-1`; a YES would lift to a clique of size `omega(G_p)+1`, while exhaustive NO certifies the upper bound.

The pruning bound in both searches is rigorous. At each node the remaining candidate graph is greedily partitioned into independent color classes. If `c` colors are produced, every clique in that candidate graph has size at most `c`. Thus a branch is discarded only when the number of still-needed clique vertices exceeds this certified coloring bound (or the candidate count). The recursion otherwise branches over every possible next vertex, deleting a vertex only after its inclusion branch has been exhausted. Therefore a returned NO after the root recursion exhausts is a complete finite proof that no target clique exists.

The transcript records, for each prime, the witness, target excluded size, number of search nodes/prunes, and a deterministic 64-bit hash of the exact decision traversal. The hash is only a reproducibility fingerprint; the proof is the inspectable exhaustive recursion and its rerunnable exact execution, not collision resistance of the hash.

The post-1601 external table gives a useful cross-check: for `1609,1613,1621,1637,1657,1669` both computations return respectively

`13,14,13,13,13,13`.

The witness sets need not coincide.

- The finite metric is now initialized, but extending it indefinitely is not a credible route to the source asymptotic. The next mathematical attack should use the exact clique archive to test a structural claim, not merely add primes.
- The elementary expansion of common-neighbor counts into `2^t` quadratic-character sums has individual Weil errors of square-root size; triangle inequality is far too weak at `t ~ log p`. A useful new theorem would need correlated cancellation across those high-order character sums or a different additive-structure mechanism. The known Graham–Ringrose lower phenomenon also warns that a uniform exponent-one logarithmic bound is false, so any successful source proof must genuinely allow a higher fixed polylogarithmic power.

A concrete next route is to extract exact multiplicative/additive invariants of the maximum cliques in the post-1601 archive (difference-set multiplicities, character correlations, and low-degree Fourier mass) and formulate a source-relevant statement that would force clique growth to be polylogarithmic if proved. Any such statement must be checked against the known Graham–Ringrose exceptional primes before it is promoted to a theorem target.
