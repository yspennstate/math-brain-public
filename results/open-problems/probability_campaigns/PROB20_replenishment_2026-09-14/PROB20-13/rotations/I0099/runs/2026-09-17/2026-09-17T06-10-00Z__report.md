## 5. B5 — add the dyadic extension-degree parameter

The first new move is to stop looking only at `F_p` and add the parameter

\[
n=2^j,\qquad j\ge1.
\]

Put

\[
Q=p^{2^{j-1}},
\]

so `F_Q` is the unique maximal proper subfield of `F_{p^n}`.

Define `R_j(C)` to be the number of Frobenius-`p` orbits of base points

\[
x\in\mathbf F_{p^n}\setminus\mathbf F_Q
\]

such that every `x-c_i` is a square in `F_{p^n}`.

Because `n=2^j`, every element outside `F_Q` has exact degree `n` over `F_p`; therefore every orbit counted by `R_j(C)` has exactly `n` elements.

### Theorem 5.1 — exact dyadic orbit formula

For every `j>=1`,

\[
\boxed{
\#X_C(\mathbf F_{p^{2^j}})
=
32p^{2^{j-1}}-64+2^{j+5}R_j(C).
}
\tag{5.1}
\]

#### Proof

Work over the quadratic extension `F_{Q^2}=F_{p^{2^j}}` of `F_Q`.

Every nonzero element of `F_Q` is a square in `F_{Q^2}`. Indeed, for `a in F_Q^*`,

\[
a^{(Q^2-1)/2}=(a^{Q-1})^{(Q+1)/2}=1.
\]

Hence for every base point `x in F_Q` not equal to one of the five branch values `c_i`, all five quantities `x-c_i` are nonzero squares in `F_{Q^2}` and the fibre of (4.1) has all `2^5=32` rational points. These `Q-5` base points contribute

\[
32(Q-5).
\]

At a finite branch value `x=c_i`, one square root is forced to be zero and the other four each have two choices; hence each branch fibre has 16 rational points. The five finite branch fibres contribute 80.

The fibre over infinity has 16 rational points; this is the same rational infinity fibre already counted in the pinned genus-17 cover calculation.

Thus all base points lying over the maximal proper subfield, together with infinity, contribute

\[
32(Q-5)+80+16=32Q-64.
\tag{5.2}
\]

Now take `x notin F_Q`. Such an `x` has exact Frobenius orbit size `n=2^j`. If all five differences `x-c_i` are squares, the fibre has 32 rational points; otherwise it has none. A good Frobenius orbit therefore contributes

\[
32n=2^{j+5}
\]

points to `X_C(F_{p^n})`. Summing over the `R_j(C)` good orbits and adding (5.2) proves (5.1). QED.

An immediate congruence is

\[
\#X_C(\mathbf F_{p^{2^j}})
\equiv32p^{2^{j-1}}-64\pmod{2^{j+5}}.
\tag{5.3}
\]

The more useful fact is that the orbit count itself is always even.

### Theorem 5.2 — every dyadic good-orbit count is even

For every Paley five-clique and every `j>=1`,

\[
\boxed{R_j(C)\equiv0\pmod2.}
\tag{5.4}
\]

Equivalently,

\[
\boxed{
\#X_C(\mathbf F_{p^{2^j}})
\equiv32p^{2^{j-1}}-64\pmod{2^{j+6}}.
}
\tag{5.5}
\]

#### Proof

Let `n=2^j`. Since `Phi=I+4M`, the binomial theorem gives

\[
\operatorname{Tr}(\Phi^n)
=
\sum_{r=0}^{n}\binom nr4^r\operatorname{Tr}(M^r).
\tag{5.6}
\]

For `3<=r<n`, the standard identity

\[
v_2\binom{2^j}{r}=j-v_2(r)
\]

implies

\[
v_2\left(4^r\binom{2^j}{r}\right)
=2r+j-v_2(r)\ge j+6.
\]

For `r=n`, the valuation is `2n>=j+6` whenever this term exists with `r>=3`; for `j=1` there is no such term. Therefore modulo `2^(j+6)` only `r=0,1,2` survive:

\[
\operatorname{Tr}(\Phi^n)
\equiv
34+2^{j+2}s+2^{j+3}(n-1)\operatorname{Tr}(M^2)
\pmod{2^{j+6}}.
\tag{5.7}
\]

Newton's identity gives

\[
\operatorname{Tr}(M^2)=s^2-2e.
\tag{5.8}
\]

Likewise, because `p=1+4q`, the scalar binomial expansion gives

\[
p^n
\equiv
1+2^{j+2}q+2^{j+3}(n-1)q^2
\pmod{2^{j+6}}.
\tag{5.9}
\]

Also

\[
p^{n/2}\equiv1\pmod{2^{j+1}}.
\tag{5.10}
\]

For `j=1`, this is just `p congruent 1 mod 4`; for `j>=2` it follows from the 2-adic lifting-the-exponent formula. Multiplying (5.10) by 32 yields

\[
32p^{n/2}\equiv32\pmod{2^{j+6}}.
\tag{5.11}
\]

Now put

\[
D_j:=\#X_C(\mathbf F_{p^n})-(32p^{n/2}-64).
\]

Using `#X(F_{p^n})=p^n+1-Tr(Phi^n)` together with (5.7)--(5.11),

\[
D_j
\equiv
2^{j+2}(q-s)
+2^{j+3}(n-1)(q^2-s^2+2e)
\pmod{2^{j+6}}.
\tag{5.12}
\]

By (4.5),

\[
q-s=32+8t,
\]

so the first term in (5.12) is congruent to

\[
2^{j+5}t\pmod{2^{j+6}}.
\tag{5.13}
\]

Moreover `q^2-s^2=(q-s)(q+s)` is divisible by 8, while the pinned congruence (4.6) gives

\[
2e\equiv4t\pmod8.
\]

Since `n-1` is odd, the second term in (5.12) is also congruent to

\[
2^{j+5}t\pmod{2^{j+6}}.
\tag{5.14}
\]

The two contributions (5.13) and (5.14) cancel modulo `2^(j+6)`, proving

\[
D_j\equiv0\pmod{2^{j+6}}.
\]

By the exact orbit formula (5.1), `D_j=2^(j+5)R_j(C)`, hence `R_j(C)` is even. QED.

This theorem is a new translation of the pinned level-five Frobenius constraint, not a new source-level clique bound.

## 6. B25 — count the same degree-two object two ways

The case `j=1` admits a much more elementary formulation. Put

\[
R(C):=R_1(C).
\]

Every degree-two Frobenius orbit `{x,x^p}` in `F_{p^2}\setminus F_p` corresponds to the monic irreducible quadratic

\[
f_x(T)=(T-x)(T-x^p)=T^2-sT+n\in\mathbf F_p[T].
\tag{6.1}
\]

For `c in F_p`,

\[
N_{F_{p^2}/F_p}(x-c)=f_x(c).
\]

The quadratic characters satisfy

\[
\chi_{p^2}(x-c)
=
\chi_p(N(x-c)),
\tag{6.2}
\]

because

\[
N(x-c)^{(p-1)/2}=(x-c)^{(p^2-1)/2}.
\]

Therefore `x-c` is a square in `F_{p^2}` exactly when `f_x(c)` is a square in `F_p`.

Consequently

\[
\boxed{
R(C)=\#\left\{
T^2-sT+n\text{ monic irreducible over }F_p:
\chi(c^2-sc+n)=1\ \forall c\in C
\right\}.
}
\tag{6.3}
\]

Equivalently, writing the discriminant condition explicitly,

\[
\boxed{
R(C)=\#\left\{(s,n)\in F_p^2:
\chi(s^2-4n)=-1,
\ \chi(c^2-sc+n)=1\ \forall c\in C
\right\}.
}
\tag{6.4}
\]

Thus the level-five problem has been moved from a genus-17 Frobenius representation to a two-dimensional finite-field coefficient count.

The new point is that the congruence can be sharpened from evenness to an exact mod-4 identity.

### Theorem 6.1 — degree-two orbit count modulo four

For every prime-field Paley five-clique,

\[
\boxed{R(C)\equiv2t_5(C)\pmod4.}
\tag{6.5}
\]

In particular,

\[
\boxed{
t_5(C)\text{ is even}
\iff
4\mid R(C).
}
\tag{6.6}
\]

This turns the empirical five-clique parity question into the concrete statement: **the number of irreducible monic quadratics taking square values at all five clique points is divisible by four.**

#### Proof, Step 1: upgrade `e_2(M)` from modulo four to modulo eight

The Frobenius eigenvalues on the 17-dimensional abelian variety occur in reciprocal Weil pairs

\[
\alpha_i,\quad p/\alpha_i,\qquad i=1,\dots,17.
\]

Since `Phi=I+4M`, write in an algebraic closure of `Q_2`

\[
\alpha_i=1+4a_i,
\qquad
p/\alpha_i=1+4b_i,
\]

with `a_i,b_i` 2-adic algebraic integers. Put

\[
u_i=a_i+b_i,\qquad v_i=a_ib_i.
\]

The pair-product identity

\[
(1+4a_i)(1+4b_i)=p=1+4q
\]

gives

\[
\boxed{u_i+4v_i=q.}
\tag{6.7}
\]

Let

\[
A=\sum_{i=1}^{17}v_i.
\]

Taking the trace of `M` and summing (6.7),

\[
s=17q-4A,
\]

so by (4.5),

\[
A=\frac{17q-s}{4}
=
4q+8+2t.
\tag{6.8}
\]

Now the 34 eigenvalues of `M` are `a_1,b_1,...,a_17,b_17`. Hence

\[
e
=
\sum_i a_ib_i+
\sum_{i<j}(a_i+b_i)(a_j+b_j)
=
A+\sum_{i<j}u_iu_j.
\tag{6.9}
\]

Using `u_i=q-4v_i`,

\[
\sum_{i<j}u_iu_j
=
\binom{17}{2}q^2
-4q(16)A
+16\sum_{i<j}v_iv_j.
\tag{6.10}
\]

Here `binom(17,2)=136` is divisible by 8, the middle coefficient is 64, and the final coefficient is 16. Therefore (6.9)--(6.10) imply

\[
\boxed{e\equiv A\equiv4q+2t\pmod8.}
\tag{6.11}
\]

This is strictly sharper than the previous `e congruent 2t mod 4` theorem.

#### Proof, Step 2: express the same information through `F_{p^2}` orbit counting

The dyadic fibre formula (5.1) at `j=1` is

\[
\#X_C(F_{p^2})=32p-64+64R(C).
\tag{6.12}
\]

On the other hand,

\[
\#X_C(F_{p^2})=p^2+1-\operatorname{Tr}(\Phi^2).
\]

Since `Phi=I+4M`,

\[
\operatorname{Tr}(\Phi^2)
=34+8s+16\operatorname{Tr}(M^2)
=34+8s+16(s^2-2e).
\tag{6.13}
\]

Equating (6.12) and (6.13) gives

\[
64R
=
p^2-32p+31-8s-16s^2+32e.
\tag{6.14}
\]

Substitute `p=1+4q` and `s=q-32-8t`. Direct expansion and division by 32 gives the exact integer identity

\[
\boxed{
2R
=
e+8qt+28q-32t^2-254t-504.
}
\tag{6.15}
\]

Reduce (6.15) modulo 8. The terms `8qt`, `32t^2`, and `504` vanish; `28q congruent 4q mod 8`, and `-254t congruent 2t mod 8`. By (6.11),

\[
2R
\equiv
(4q+2t)+4q+2t
\equiv4t
\pmod8.
\]

Dividing the congruence by 2 yields

\[
R\equiv2t\pmod4,
\]

which is (6.5). QED.

### What this does and does not solve

Theorem 6.1 gives an elementary-looking finite-field target for the empirical parity law. It does **not** prove `t_5(C)` even. The remaining obligation is now exactly

\[
\boxed{
4\mid
\#\{(s,n)\in F_p^2:
\chi(s^2-4n)=-1,
\chi(c^2-sc+n)=1\ \forall c\in C\}.
}
\tag{6.16}
\]

for every Paley five-clique `C`.

I looked for a fixed-point-free order-four action on the coefficient pairs `(s,n)` in (6.16). Conjugation supplies only the already-quotiented two-element root orbit; generic five-point branch sets have no affine/projective symmetry that preserves `C`, so the obvious coefficient involutions do not close the divisibility-by-four claim. This route therefore produces a sharply stated smaller blocker rather than a false solution.

## 7. B21 — transfer from Humbert-Edge/Prym literature, and the precise limitation

The closest solved object is now clearer than in the preceding reports.

The cover `X_C` is a Humbert-Edge/generalized Fermat curve of type `(2,5)`: it has the natural `(Z/2Z)^5` deck action and six branch orbits. Auffarth--Lucchini Arteche--Rojas prove the corresponding Jacobian decomposition in general. Specializing their type-5 dimension formula gives exactly

- `binom(6,4)=15` one-dimensional factors;
- `binom(6,6)=1` two-dimensional factor;

which is precisely the fifteen elliptic factors plus one genus-two factor already used in the I0099 arithmetic calculation.

Their polarization theorem is also exactly at the relevant 2-primary scale: for type 5, each factor is Prym-Tyurin of exponent 4 and the decomposition isogeny has kernel order

\[
4^{17}=2^{34}.
\]

This changes the prior-art boundary: the **decomposition and its 2-primary kernel are known geometry**, not an I0099 novelty claim.

It also identifies the right place to look next. The missing bit is not likely to come from treating the sixteen factors as independent abelian varieties. The preceding generic-GSp no-go models already showed that independent rational-4-torsion factors allow both values of the relevant mod-4 `e_2` class. The published Humbert-Edge theorem says that the factors are glued by a highly structured exponent-4 Prym-Tyurin isogeny.

However, the order/exponent statement by itself still does not close Theorem 6.1's divisibility target. In the Paley specialization Frobenius already acts trivially on the full factorwise 4-torsion. Merely knowing that the decomposition is 2-primary at exponent 4 therefore supplies no new distinction at the first mod-4 level. To extract the remaining bit one needs one of the following genuinely finer inputs:

1. an explicit description of the **level-8 lift** of the Humbert-Edge gluing kernel under Frobenius;
2. a direct order-four action or double count on the quadratic-polynomial set (6.16);
3. a growing-order version of these congruences that couples many five-subsets of a large clique.

Thus B21 did not solve the source conjecture, but it sharply relocates the arithmetic obstruction: from the rational isogeny decomposition, which is known, to its integral level-8 coupling.

## 8. Why this is still far from Conjecture 25

There are two separate gaps.

First, even proving the universal five-clique parity statement would still be a **fixed-order** local theorem. The preceding B27 no-go result proved that bounded-order parity moments, by themselves, cannot force the all-plus extension atom for arbitrary `k`: the top Boolean atom can be flipped while every proper fixed-order parity moment stays unchanged. Therefore a proof of (6.16) would be useful structural progress, not a source closure.

Second, the source asks for a uniform polylogarithmic upper bound on the largest clique. The present finite frontier `P=3637`, the dyadic orbit congruences, and the level-five divisibility reformulation give no function `C(log p)^A` valid for all primes. No such claim is made.

The source-level opportunity is that (6.16) is now a two-variable character/divisibility problem rather than an opaque genus-17 trace bit. If a method proves analogous `2^r` divisibility constraints uniformly for extension counts attached to `r`-subsets with `r` growing like `log p`, then the fixed-order obstruction would be bypassed. Nothing in this run establishes such growth.
