## 3. B14 — exact finite-field symmetry: triangle normalization is valid but not computationally better here

The previous exact search already used the affine Paley automorphism group to normalize one clique edge to `{0,1}`. This run pushed the symmetry one level further.

### Lemma 3.1 (exact triangle cross-ratio orbit)

Let p be prime, p congruent to 1 mod 4, and let {a,b,c} be a triangle in the Paley graph. After choosing an ordered edge (a,b), the affine map

z -> (z-a)/(b-a)

is a Paley automorphism and sends (a,b,c) to (0,1,x), where both x and x-1 are nonzero quadratic residues. Changing the ordering of the same triangle changes x within the six-element anharmonic orbit

x, 1-x, 1/x, 1-1/x, 1/(1-x), x/(x-1),

with the usual collapses when special values identify transforms.

#### Proof

Every edge difference in a Paley clique is a nonzero quadratic residue. Thus b-a is a square, so multiplication by (b-a)^(-1) preserves quadratic-residue status of every difference; translation also preserves differences. Hence the displayed affine map is a graph automorphism. Since c-a and c-b are both residues, x=(c-a)/(b-a) and x-1=(c-b)/(b-a) are residues. Permuting the ordered triple and renormalizing the first two entries to 0 and 1 produces exactly the standard six cross-ratio transforms. Each renormalization multiplier is the inverse of a clique-edge difference and is therefore a square, so every such normalization remains a Paley automorphism. QED.

This gives an exact reduction: for a clique of size at least three, the third normalized vertex may be chosen from one representative per S_3 cross-ratio orbit, and the remaining search is in the common-neighbor graph of `{0,1,x}`.

I implemented a prototype at p=2341. It was mathematically correct but slower than the best whole-H branch-and-bound at this frontier: splitting by triangle representatives destroys part of the global greedy-color ordering that was doing most of the pruning. The attempt was abandoned rather than polished. Outcome B14: **valid structural reduction, no frontier gain**.

## 4. B17 — a coding/association-scheme transfer hits the exact square-root barrier

The Paley graph on p vertices is a rank-3 strongly regular graph with

k=(p-1)/2,

restricted adjacency eigenvalues

r=(sqrt(p)-1)/2,  s=(-sqrt(p)-1)/2.

Any coding-theoretic/Delsarte argument that remembers only the two nontrivial relations of this rank-3 association scheme yields the same first spectral bound. Indeed the Hoffman bound for an independent set is

alpha(G_p) <= p(-s)/(k-s) = sqrt(p).

Because the Paley graph is self-complementary for p congruent to 1 mod 4, the same two-class information gives

omega(G_p) <= sqrt(p).

Thus the most naive translation to a two-distance code or rank-3 Delsarte LP cannot possibly reach a polylogarithmic clique bound. A successful coding-theory transfer must preserve higher-order/localized data that are invisible to the two-class distance distribution. This explains why the Elias–Bassalygo/Kalai–Linial analogy in the localization literature is potentially relevant, while also marking the boundary with I0100/I0101: importing their local-theta conjectures as if already proved would be circular and is not allowed.

Outcome B17: **negative structural result for a route** — pairwise association-scheme data alone provably stalls at sqrt(p); a useful uniform argument must add higher-order additive/local information.

## 5. B30 — solve one prime exactly, then extend the contiguous frontier

### 5.1 Exact fixed-edge localization

For any clique of size at least two, choose an ordered edge and send it by a Paley affine automorphism to `{0,1}`. Therefore, with

H_p = G_p[N(0) intersect N(1)],

we have

omega(G_p)=2+omega(H_p).

For an adjacent pair in the Paley strongly regular graph,

|V(H_p)|=(p-5)/4.

Thus to certify omega(G_p)=w it is enough to exhibit a clique of size w and exhaustively prove that H_p has no clique of size w-1; such an H_p clique would extend `{0,1}` to a clique of size w+1 in G_p.

### 5.2 Exact branch-and-bound logic

The archived solver uses only integer graph construction and bit operations. At every recursion node it greedily partitions the current candidate set P into independent color classes; if c colors are used, every clique contained in P has size at most c. The maximization pass branches on each candidate in reverse coloring order and prunes only when `current_size + color_bound <= incumbent`. The decision pass separately asks whether a clique of the one-larger target size exists, with the same exact coloring upper bound. Therefore a completed `false` decision is an exhaustive nonexistence proof for that target in H_p. No floating point arithmetic enters graph adjacency, witness verification, or branch decisions.

The new implementation preserves the previous algorithm but replaces repeatedly allocated `boost::dynamic_bitset` temporaries with fixed arrays of 64-bit words and inlined intersection/popcount operations. This is an implementation-level speedup, not a changed mathematical criterion.

The `proof64` field is only a deterministic search-trace digest for reproducibility; it is not treated as a standalone proof certificate. The proof object is the executable exact solver together with its completed output; the separate Python audit checks coverage and clique witnesses but does not independently reconstruct the full no-clique search tree.
