# 3. Main theorem — the equal-singular full-rank pointwise case is safe

## Theorem 1 — orthogonal-complex-structure input admits a symmetric orthogonal competitor

Let `A in R^{6 x 6}` be arbitrary and let `J` be any orthogonal complex structure:

\[
J^T=-J,\qquad J^2=-I_6.
\]

Then there exists a real symmetric orthogonal matrix `R` satisfying

\[
R^T=R,\qquad R^2=I_6,\qquad RJ=-JR,
\]

such that for every real `sigma`, with

\[
U=\sigma J,\qquad V=\sigma R,
\]

one has

\[
\boxed{\|V\|_F=\|U\|_F}
\]

and

\[
\boxed{
\|\mathcal L_A(V)\|_F\ge \|\mathcal L_A(U)\|_F.
}
\]

Therefore **no order-six counterexample can have an equal-singular full-rank skew maximizer**.

The proof is constructive modulo ordinary complex Schur triangularization and three scalar phase choices.

## 3.1 Energy cancellation

For any symmetric `V`, direct expansion gives

\[
\|\mathcal L_A(V)\|_F^2
=2\operatorname{tr}(A^TA V^2)+2\operatorname{tr}(AVAV).
\]

For any skew `U`,

\[
\|\mathcal L_A(U)\|_F^2
=2\operatorname{tr}(A^TA(-U^2))-2\operatorname{tr}(AUAU).
\]

If `U=sigma J` and `V=sigma R` with `R^2=I=-J^2`, then `V^2=-U^2=sigma^2 I`, hence

\[
\boxed{
\|\mathcal L_A(V)\|_F^2-
\|\mathcal L_A(U)\|_F^2
=2\sigma^2\left[
\operatorname{tr}(ARAR)+\operatorname{tr}(AJAJ)
\right].
}
\]

Also `||R||_F=||J||_F=sqrt(6)`, so the input norms match. It remains to choose `R` so that the trace bracket is nonnegative.

# 4. B1 — CHANGE THE CATEGORY: real six-space becomes complex three-space

Identify `R^6` with `C^3` so that `J` is multiplication by `i`. Every real-linear map `A:C^3 -> C^3` has a unique decomposition

\[
A z=Bz+C\bar z,
\qquad B,C\in\mathbb C^{3\times3}.
\]

A symmetric orthogonal `R` anticommuting with `J` is exactly a unitary real structure

\[
Rz=W\bar z,
\qquad W^T=W,\quad W^*W=I_3.
\]

For a real-linear map `Tz=Pz+Q\bar z`, its real trace is `2 Re tr(P)`. Therefore direct composition gives

\[
\frac12\operatorname{tr}_{\mathbb R}(AJAJ)
=\operatorname{Re}\operatorname{tr}(-B^2+C\bar C),
\]

while for `Rz=W\bar z`,

\[
\frac12\operatorname{tr}_{\mathbb R}(ARAR)
=\operatorname{Re}\operatorname{tr}
\left(C\bar W C\bar W+B W\bar B\bar W\right).

Thus the six-dimensional real obstruction becomes a three-dimensional complex phase-selection problem.

# 5. B14 — FIND THE GROUP ACTING: Schur gauge plus the U(3) stabilizer

\[

\[

\[
D=\operatorname{diag}(e^{i\theta_1},e^{i\theta_2},e^{i\theta_3}).

\[

upper triangular and sends

\[
C_0\mapsto C_1=D^*C_0\bar D,
\qquad
(C_1)_{ij}=e^{-i(\theta_i+\theta_j)}(C_0)_{ij}.

The corresponding real structure in the original coordinates is

\[
W=(QD)(QD)^T,
\qquad Rz=W\bar z.
\]

Since `B_1` is triangular,

\[
\operatorname{tr}(B_1\bar B_1)=\sum_{r=1}^3|\lambda_r|^2,
\qquad
\operatorname{tr}(B_1^2)=\sum_{r=1}^3\lambda_r^2,
\]

where `lambda_r` are the eigenvalues of `B`. Hence

\[
\boxed{
\operatorname{Re}\operatorname{tr}(B_1\bar B_1-B_1^2)
=2\sum_{r=1}^3(\operatorname{Im}\lambda_r)^2\ge0.
}
\]

The entire remaining issue is the `C` term. Dimension three makes its phase graph a triangle, and that triangle has exactly enough vertex phases to align all three edge products.

## Lemma 2 — three-node congruence phase alignment

For every `C in C^{3 x 3}` there exists a diagonal unitary `D` such that for `C_1=D^*C\bar D`,

\[
\boxed{
\operatorname{Re}\operatorname{tr}(C_1^2)
+\operatorname{tr}(C\bar C)\ge0.
}
\]

Here `tr(C\bar C)` is real.

### Proof

Write

\[
T_C:=\operatorname{tr}(C\bar C)
=\sum_i|c_{ii}|^2+2\sum_{i<j}\operatorname{Re}(c_{ij}\bar c_{ji}).
\]

If `T_C>=0`, first choose arbitrary diagonal phases and then add one common phase to all `theta_i`; this rotates `tr(C_1^2)` by an arbitrary unit complex scalar. Choose that common phase so that `Re tr(C_1^2)>=0`, and the result follows.

Now assume `T_C<0`. Put

\[
D_0:=\sum_i|c_{ii}|^2,
\qquad
E:=2\sum_{i<j}|c_{ij}c_{ji}|.
\]

The three off-diagonal contributions to `tr(C_1^2)` are

\[
2c_{12}c_{21}e^{-2i(\theta_1+\theta_2)},\quad
2c_{13}c_{31}e^{-2i(\theta_1+\theta_3)},\quad
2c_{23}c_{32}e^{-2i(\theta_2+\theta_3)}.
\]

There are three vertex phases and three edge phases. Whenever an edge coefficient is nonzero, solve the linear phase equations so that all nonzero edge terms have the same argument. With all three edges nonzero this is the nonsingular system

\[
\phi_1+\phi_2=-\arg(2c_{12}c_{21}),\quad
\phi_1+\phi_3=-\arg(2c_{13}c_{31}),\quad
\phi_2+\phi_3=-\arg(2c_{23}c_{32}),
\]

where `phi_i=-2 theta_i`; missing edges only remove constraints. The aligned edge sum therefore has magnitude `E`. The three diagonal terms have total magnitude at most `D_0`, so

\[
|\operatorname{tr}(C_1^2)|\ge E-D_0.
\]

Also

\[
-T_C
=-D_0-2\sum_{i<j}\operatorname{Re}(c_{ij}\bar c_{ji})
\le -D_0+2\sum_{i<j}|c_{ij}c_{ji}|
=E-D_0.
\]

Hence

\[
|\operatorname{tr}(C_1^2)|\ge -T_C.
\]

Finally, adding the same scalar phase to all three `theta_i` multiplies every term of `tr(C_1^2)` by the same unimodular factor while leaving `B_1=D^*TD` unchanged. Choose that common phase so that

\[
\operatorname{Re}\operatorname{tr}(C_1^2)
=|\operatorname{tr}(C_1^2)|.
\]

Then `Re tr(C_1^2)+T_C>=0`. QED.
