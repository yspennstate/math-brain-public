## 4. New restricted theorem: every subcritical linear delay collapses to immediate query

The preceding Section-I diagnosis selected the one-rejection-delay subclass as the simplest missing bridge. The recovery actually gives a stronger result.

Let `alpha_imm` denote the optimal constant competitive ratio among SBOffAO1 algorithms that, if they use their query, use it immediately after the sample (`QR_s`). The source's Algorithm 2 shows `alpha_imm >= 1/e`, since it is already `1/e`-competitive against the stronger sample-based online adversary.

Let `h: N -> N` be a deterministic delay envelope. Define `SBOffAO1[h]` to consist of source-valid ordinal algorithms which, on an input of total size `n`, either never query or use their unique query after rejecting at most `h(n)` post-sample arrivals. Let `alpha_h` be its optimal constant competitive ratio.

### Theorem (guard-padding collapse)

If

\[
\rho:=\limsup_{n\to\infty}\frac{h(n)}{n}<\alpha_{\rm imm},
\]

then

\[
\boxed{\alpha_h=\alpha_{\rm imm}.}
\]

In particular:

1. for every fixed `d`, allowing the query after at most `d` rejected post-sample arrivals gives exactly the same model-level competitive ratio as immediate query;
2. the requested **one-rejection-delay** subclass has exactly the immediate-query value;
3. more generally every `h(n)=o(n)` delay envelope has exactly the immediate-query value;
4. because `alpha_imm >= 1/e`, every deterministic envelope with `limsup h(n)/n < 1/e` is powerless to improve over immediate query.

Thus, if the unrestricted SBOffAO1 value is strictly larger than the immediate-query value, the extra power cannot come from any uniformly sub-`1/e`-linear query delay. Some linearly late query behavior is essential.

This theorem is source-valid in its stated restricted class but **does not determine `alpha_imm`** and therefore does not settle the source conjecture.

## 5. Complete proof of the guard-padding theorem

The inequality `alpha_h >= alpha_imm` is immediate because an immediate-query policy is a valid `h`-delay policy. The work is the reverse inequality.

Assume for contradiction that

\[
\alpha_h>\alpha_{\rm imm}.
\]

Choose constants

\[
\alpha_{\rm imm}<c<a<\alpha_h
\]

with also `rho<c`; this is possible because `rho<alpha_imm`. By the definition of `alpha_h`, choose an `h`-delay algorithm family `A=(A_n)` whose competitive ratio is at least `a`: for every input size and every source-valid SBOffAO instance of that size,

\[
\Pr(A\text{ wins})\ge a.
\tag{5.1}
\]

We construct from `A` an immediate-query algorithm family `B=(B_N)` with competitive ratio at least `a`, contradicting `a>alpha_imm`.

### 5.1 Fix an arbitrary core instance

Fix an arbitrary core size `N` and an arbitrary source-valid SBOffAO instance on a core set

\[
C=\{x_1,\ldots,x_N\},
\]

with arbitrary injective positive core weights and arbitrary fixed preliminary core order. The construction below must work for this completely arbitrary core instance.

Because `limsup h(n)/n=rho<c`, choose a total size `M>N`, as large as necessary, so that with `L:=M-N`,

\[
h(M)\le cM-N.
\tag{5.2}
\]

Add `L` new guard elements

\[
g_1,g_2,\ldots,g_L
\]

whose weights are all strictly below every core weight and satisfy

\[
w(g_1)>w(g_2)>\cdots>w(g_L)>0.
\]

The padded preliminary order is

\[
g_1,g_2,\ldots,g_L,\quad\text{then the arbitrary core preliminary order}.
\tag{5.3}
\]

This is a legal SBOffAO instance: its weights and preliminary order are fixed before the experiment and before the realized sample size and sample.

Run `A_M` on this padded size-`M` instance. Let its declared random sample size be `s`.

### 5.2 High sample sizes are universally harmless

Split according to

\[
\mathsf{Low}:=\{s\le (1-c)M\},
\qquad
\mathsf{High}:=\{s>(1-c)M\}.
\]

Conditional on any fixed sample size `s`, no algorithm can win if the global maximum was sampled, because every sample element must be rejected. Therefore

\[
\Pr(A_M\text{ wins}\mid s)\le 1-\frac{s}{M}.
\tag{5.4}
\]

On `High`, this is strictly below `c`.

Let `gamma=P(Low)`. If `gamma=0`, then (5.4) would imply total success `<c<a`, contradicting (5.1). Hence `gamma>0`. If `x` is the success probability conditional on `Low`, then

\[
a\le \gamma x+(1-\gamma)c,
\]

so

\[
x\ge c+\frac{a-c}{\gamma}\ge a.
\tag{5.5}
\]

Thus **on every padded core instance, the low-sample-size conditional experiment already has success at least `a`.**

### 5.3 On Low there are deterministically enough unsampled guards

On `Low`, the total number of unsampled elements is at least `cM`. There are only `N` core elements altogether. Hence, writing `U` for the number of unsampled guards,

\[
U\ge (M-s)-N\ge cM-N\ge h(M).
\tag{5.6}
\]

This is deterministic; no concentration estimate or asymptotic sampling approximation is needed.

Because every guard precedes every core element in the padded preliminary order, (5.6) implies that the first `h(M)` post-sample arrivals are guards. Since guard weights decrease along their preliminary order, those unsampled guards arrive in strictly decreasing guard-weight order.

### 5.4 Exact query-response shielding through the guard block

Let

\[
r_0:=\mathrm{QR}_{s}
\]

be the query response immediately after the padded sample, whether or not `A_M` actually queries then. Let `y` be the first unsampled guard.

There are exactly two cases.

**Case 1: `y` is not a record relative to the sample.** Then the current record remains the sample maximum throughout all subsequent guard arrivals, because every later guard is lighter than `y`. Moreover no rejected guard lies above that unchanged record. Consequently for every `j` before the core begins,

\[
\mathrm{QR}_{s+j}=r_0.
\tag{5.7}
\]

**Case 2: `y` is a record.** Then necessarily `y=g_1` and no core element was sampled. Indeed, if `y=g_k` with `k>1`, all earlier guards `g_1,\ldots,g_{k-1}` were sampled and one is heavier than `y`; and if any core element was sampled it is heavier than every guard. Thus after rejecting `y`, the current record is `g_1`, all `N` core elements are unseen and heavier than it, and every remaining guard is lighter. Therefore throughout the rest of the guard block,

\[
\mathrm{QR}_{s+j}=N
\qquad(j\ge1\text{ while only guards have arrived}).
\tag{5.8}
\]

Equations (5.7)-(5.8) show that throughout the first `h(M)` rejected arrivals, the delayed reliable-query response is an **exact deterministic postprocessing** of the immediate response `r_0` together with the ordinary record bit of the first guard:

\[
\boxed{
\mathrm{QR}_{s+j}
=
\begin{cases}
r_0,&y\text{ is not a record},\\
N,&y\text{ is a record},
\end{cases}
\quad 1\le j\le h(M).
}
\tag{5.9}
\]

There is zero Blackwell deficiency on this shielded history. This is the B11 mechanism of the run.

### 5.5 Turn the padded experiment into a legal immediate-query core algorithm

We now construct an immediate-query algorithm `B_N` for the arbitrary core instance.

Before receiving its core sample, `B_N` internally performs the following randomization.

1. Draw a virtual padded sample size `s` from the distribution used by `A_M`, conditioned on `Low`.
2. Draw a virtual sampled guard set `H subseteq {g_1,...,g_L}` with exactly the marginal law it has when a uniform `s`-subset is drawn from the padded `M` elements. Equivalently, for each feasible specific guard subset `H` of size `ell`, assign probability proportional to

\[
\binom{N}{s-\ell};
\]

normalization is `binom(M,s)` after summing over all guard subsets.
3. Set

\[
k:=s-|H|.
\]

Declare `k` as the **actual** core sample size.

Conditional on this internal choice, the source supplies `B_N` a uniform `k`-subset of the core. By construction, the union of that core sample and `H` has exactly the law of a uniform `s`-subset of the padded `M`-element instance. Hence `B_N` can reproduce the complete ordinal padded-sample pattern seen by `A_M`: every sampled core element is above every sampled guard, core comparisons come from the real observed core sample, and guard comparisons are synthetically known.

Immediately after receiving its core sample, `B_N` spends its unique oracle query. Let the core response be `r_C`.

From `r_C` and the synthetic guard sample, `B_N` reconstructs the padded immediate response `r_0` exactly:

- if `k>0`, the padded sample maximum is a core element, so no guard exceeds it and

\[
r_0=r_C;
\tag{5.10}
\]

- if `k=0` and `H` is empty, the padded sample is empty, so

\[
r_0=M;
\tag{5.11}
\]

- if `k=0` and `H` is nonempty, let `m=min\{i:g_i\in H\}`. The sample maximum is `g_m`; every core element exceeds it and precisely the guards `g_1,\ldots,g_{m-1}` are unsampled and exceed it. Hence

\[
r_0=N+(m-1).
\tag{5.12}
\]

The algorithm now runs an internal copy of `A_M`. It hides `r_0` from that copy unless and until the simulated policy queries. Before consuming any real core selection arrival, `B_N` can internally simulate the known unsampled guard prefix in its preliminary order. These are virtual low-weight arrivals; internal simulation between real arrivals is just computation and private randomness, not an extra source query or a selection from the real core.

If the simulated `A_M` selects a guard, it loses on the padded instance because the global maximum lies in the core; `B_N` may therefore enter a permanent losing state. If `A_M` rejects guards and requests its query after `j<=h(M)` such rejections, `B_N` supplies the exact response from (5.9), computed from its already-used immediate response and the observed synthetic record relation. If the simulated policy never queries, no response is needed.

After the virtual guard prefix is exhausted, `B_N` feeds the actual arriving core elements to the simulated `A_M` in their real induced core order. All ordinal comparisons in the combined padded history are reconstructible: every core element is above every guard, and comparisons within the core are the actual observed comparisons. Whenever the simulated `A_M` selects a core element, `B_N` selects that real element.

Because the padded global maximum is exactly the core global maximum, this coupling preserves the win event pathwise. By (5.6), every query permitted by the delay envelope occurs before the core begins. Therefore

\[
\Pr(B_N\text{ wins on the core instance})
=
\Pr(A_M\text{ wins on the padded instance}\mid \mathsf{Low})
\ge a.
\tag{5.13}
\]

The construction uses only ordinal core observations, a legal randomized exact core sample size, private randomness, and one immediate core query. It does not use core labels as proxies for hidden weight.

The core instance was arbitrary. Hence `B_N` is `a`-competitive at size `N`. The choice of the sufficiently large padded size `M` may depend on `N`, which is allowed in the definition of the algorithm family. Doing this for every `N` gives an immediate-query family with constant competitive ratio at least `a>alpha_imm`, a contradiction.

Thus `alpha_h<=alpha_imm`, and together with the trivial reverse inequality,

\[
\boxed{\alpha_h=\alpha_{\rm imm}.}
\]

This completes the proof.
