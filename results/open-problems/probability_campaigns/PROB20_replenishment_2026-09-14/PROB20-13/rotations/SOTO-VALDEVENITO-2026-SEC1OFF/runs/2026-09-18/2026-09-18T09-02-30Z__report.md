## 2. Mathematical idea before code

The top-six law already showed that finite-prefix hard distributions are not merely a proof device: increasing the distinguished prefix from five to six reduced the complete delayed-query Bellman value. The next question was whether this phenomenon persists at seven ranks and whether the hard-law search can be put in a category where the adversary's optimization is explicit instead of hand-tuned.

For fixed sampling density `p` and a fixed deterministic algorithm policy `pi`, the success probability against a mixture `mu` over preliminary top orders is **linear in `mu`**. Thus the finite-prefix adversary problem is naturally a finite zero-sum sequence-form game. If `c_{p,pi}(o)` denotes the success probability of policy `pi` against top order `o`, then a finite master problem is

`minimize z`

subject to

`sum_o mu_o c_{p,pi}(o) <= z`

for every currently exposed `(p,pi)` cut, together with `mu_o >= 0` and `sum_o mu_o = 1`.

A Bellman best-response oracle supplies violated policy cuts for any candidate `mu`. I used all `2^(7-1)=64` nested-end top-seven orders as the discovery universe, iterated this finite LP/best-response formulation over a sampling-density grid, then rationalized a sparse candidate. The exploratory optimization itself is floating-point discovery and is **not** part of the theorem. The theorem below depends only on the final exact rational hard law and an exact arithmetic checker.

The exploratory sequence-form search placed the top-seven family substantially below the previous `0.3745` endpoint; near the final candidate its numerical best-response envelope was about `0.37321`. ### Proof

#### Step 1. Exact iid-top-seven information game

Temporarily sample each of the seven distinguished ranks independently with probability `p`. A hidden state is a pair `(o,M)`, where `o` is one of the 38 preliminary top orders and `M subseteq {1,...,7}` is the sampled distinguished-rank mask. Give it prior mass

`mu(o) p^{|M|}(1-p)^{7-|M|}`.

There are `38*2^7 = 4864` positive hidden states before observational quotienting.

For any information cell `C`, distinguished-arrival index `t`, and query-used bit `u`, define an unnormalized Bellman value `W(C,t,u)` equal to the maximum success mass achievable from that cell. Waiting one distinguished arrival partitions `C` by the exact ordinal observation `a`. In a branch `C_a`, selecting the current item wins exactly on those hidden states in which that arriving rank is `1`; rejecting moves to `(C_a,t+1,u)`. Thus

`WAIT(C,t,u) = sum_a max( SELECT_MASS(C_a), W(C_a,t+1,u) )`.

If the query is unused, querying now partitions `C` by the exact source query response `q`, and because the response branches are disjoint,

`QUERY(C,t,0) = sum_q W(C_q,t,1)`.

Therefore

`W(C,t,0)=max(WAIT(C,t,0), QUERY(C,t,0))`

and

`W(C,t,1)=WAIT(C,t,1)`.

Terminal cells have value zero. This recursion allows the query before any distinguished arrival and after every rejection, so **delayed query timing is unrestricted**. It also allows every history-dependent accept/reject decision. The compiled exact graph for the hard law has `2574` Bellman nodes.

Common-tail observations do not hide an omitted source advantage. Every unsampled distinguished rank precedes the common tail. Once the common tail begins, rank 1 was either sampled or has already passed, so no later decision can win. Before that point, if a distinguished rank has been observed or sampled, the query count above the current record is determined entirely by the distinguished hidden state. If no distinguished rank has yet been seen, the additional tail component of a query response is independent of the hidden top-order choice conditional on that top mask; conditioning on such an independent signal can only randomize among continuations whose maximum is already taken by the Bellman recursion. Candidate identities are independently randomized as noted above.

Let `V(p)=W(ROOT,0,0)`. The exact checker computes this recursion using integer arithmetic after clearing the common denominator.

`|V_pi(p)-V_pi(q)| <= 7|p-q|`.

Taking the pointwise maximum over deterministic policies preserves the same Lipschitz constant:

`|V(p)-V(q)| <= 7|p-q|`.

This is the useful invariant produced by the B12 search: observation/query partitions conserve total hidden prior mass, and a change of sampling density can affect policy payoff only through the coupled top-seven sample mask.
