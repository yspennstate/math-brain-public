### Proof

We separate the finite iid-top-five certificate from the fixed-size-sample lift.

#### Step 1. Exact finite information game

Temporarily sample each of ranks `1,...,5` independently with probability `p`. For a hidden top order `pi` and top-five sample mask `M`, the hidden prior mass is

`F_5(pi) p^{|M|}(1-p)^{5-|M|}`.

All unsampled distinguished ranks arrive before the common tail. Therefore, while a win remains possible, the hidden state is fully determined by

1. the selected preliminary top-five order `pi`;
2. the hidden top-five sample mask `M`;
3. how many unsampled top-five arrivals have already been processed;
4. whether the single query has been used.

There are `13*2^5=416` positive-mass `(pi,M)` hidden states before observational quotienting.

At an arriving distinguished rank `r`, the algorithm observes only its ordinal position among already observed elements. If the best observed distinguished rank is `b`, a query returns exactly `b-1`, because every globally better distinguished rank `1,...,b-1` is then necessarily unseen. If no distinguished rank has yet been observed, the detailed query answer depends only on the common tail/sample and not on which `pi` was drawn. Conditioning on such independent tail detail can only randomize among continuations for the same top-five belief, so for an upper bound it is dominated by the best pure continuation already represented by Bellman maximization. Thus it may be collapsed to a single `5+` response symbol.

Once the top-five block ends, rank 1 was either sampled or already arrived and was rejected, so future winning probability is zero. Hence the winning-relevant game is finite.

#### Step 2. Complete delayed-query Bellman recursion

For an information-state set `H`, step `t`, and query-use bit `u`, let `V(H,t,u)` be the maximum future winning mass. Use unnormalized hidden masses.

If the query is unused, the algorithm may query immediately. The response partitions `H`; after seeing the response the algorithm optimizes independently in each response class. Or the algorithm may wait for the next arrival, observe its ordinal class, and then choose select versus reject. Therefore

`V(H,t,0) = max( sum_a V(H_a^query,t,1),
                  sum_o max(S(H_o,t), V(H_o,t+1,0)) )`,

while after the query is spent,

`V(H,t,1) = sum_o max(S(H_o,t), V(H_o,t+1,1))`.

Here `S(H_o,t)` is the mass of hidden states in observation class `o` for which the current arrival is rank 1. This recursion enumerates the complete one-query delayed-query policy tree. No immediate-query restriction is imposed.

Every operation is a sum or maximum of nonnegative hidden-state masses, so `V` is coordinatewise monotone in those masses.

#### Step 4. Uniform lift to the source's exact sample size

Return to the source experiment: the algorithm chooses an exact sample size `s`, then receives a uniformly random `s`-subset of the `n` elements. For a specified mask `M subset {1,...,5}` with `|M|=k`,

`P_{n,s}(M) = C(n-5,s-k)/C(n,s)

`|(s-a)/(n-j)-s/n|
