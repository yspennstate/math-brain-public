### Proof

We give the argument in four steps.

#### Step 1. Finite winning-relevant information game

Fix a deterministic ordinal algorithm and first fix its sample size. Under `F_4^*`, all unsampled elements among `x^1,...,x^4` arrive before any common-tail element. Therefore, while winning remains possible, the hidden state is determined by

1. the chosen top-four permutation `pi`;
2. the hidden sample mask `M subset {1,2,3,4}`;
3. the number of already processed unsampled top-four arrivals;
4. whether the single query has been used.

The algorithm is not shown `pi` or `M`. It sees only the ordinal sample/history and, if queried, the source query response.

At a top-four arrival `x^r`, every tail item is worse than `x^r`, so the observed ordinal position among all revealed items is

`1 + #{already observed top-four ranks strictly better than r}`.

If at least one top-four rank has been observed, and `b` is the best observed top-four rank, then the reliable query returns exactly `b-1`, because every globally better rank is still unseen. If no top-four rank has been observed, the exact query response is at least four and depends only on the common tail/sample, not on which `pi` was drawn. Conditioning on that additional independent tail signal can only randomize among continuations for the same top-four belief; it cannot beat the best pure continuation already represented by Bellman maximization. Thus all such responses may be collapsed to one `4+` symbol for an upper-bound computation.

Once the top-four block ends, either `x^1` was sampled or it already arrived and was rejected, so future winning probability is zero. Hence the exact winning-relevant game is finite.

#### Step 2. Exact Bellman recursion for iid top-four sampling

Temporarily sample each of the four distinguished ranks independently with probability `p`. For hidden state `(pi,M)`, let

`w_{pi,M}(p) = F_4^*(pi) p^{|M|}(1-p)^{4-|M|}`.

Use unnormalized masses. For an information-state set `H`, step `t`, and query-use flag `u`, let `V(H,t,u)` be the maximum future winning mass.

If the query has not been used, querying now partitions `H` by the exact response; after seeing the response the algorithm optimizes separately in each class. If it waits, nature partitions by the next ordinal observation, after which the algorithm chooses select versus reject. Thus

`V(H,t,0) = max( sum_a V(H_a^query,t,1),
                  sum_o max(S(H_o,t), V(H_o,t+1,0)) )`,

and

`V(H,t,1) = sum_o max(S(H_o,t), V(H_o,t+1,1))`.

Here `S(H_o,t)` is the total hidden-state mass in observation class `o` for which the current item is `x^1`. A tail class has value zero. This recursion enumerates the complete delayed-query policy tree; it does not assume an immediate query.

Every operation is a sum or maximum of nonnegative quantities. Therefore the recursion is coordinatewise monotone in the hidden weights.

#### Step 3. Exact uniform certificate over every p in [0,1]

For `k=0,1,2,3,4`, define the Bernstein monomial

`b_k(p)=p^k(1-p)^{4-k}`.

On any rational interval `[a,b]`, its exact maximum occurs at an endpoint or, when contained in the interval, at the unique interior critical point `p=k/4`. Replace each hidden weight

`F_4^*(pi)b_{|M|}(p)`

by its exact interval maximum. Monotonicity of the Bellman recursion then gives a rigorous upper bound simultaneously for every `p` in that interval, even though the coordinatewise maxima may occur at different `p` values.

#### Step 4. Lift back to the source's fixed-size sample

Now return to the actual source experiment: a uniform sample of exactly `s` elements from `n`. For a specified top-four mask `M` of size `k`,

`P_{n,s}(M) = C(n-4,s-k)/C(n,s)
             = (s)_k (n-s)_{4-k}/(n)_4`.

Set `p=s/n`. For four distinguished ranks only,

`P_{n,s}(M) = p^k(1-p)^{4-k} + O(1/n)`

uniformly in `s` and in all 16 masks. One direct sequential exposure bound is enough: after fewer than four distinguished-rank exposures, the without-replacement inclusion probability differs from `p` by at most `6/(n-3)`; telescoping four factors bounds the probability error for any specified mask by at most `24/(n-3)`, and hence the total-variation error over the 16 masks by at most `192/(n-3)`. The constant is deliberately crude; uniform convergence is what matters.

Conditional on a top-four mask, the same finite ordinal/query game applies. Tail-only query detail when no top-four rank has been observed is independent of the choice of `pi` and cannot improve beyond the best continuation for that belief. Since success payoffs lie in `[0,1]`, replacing the fixed-size mask law by the iid mask law changes the optimal success probability by at most the total-variation error. Hence every deterministic fixed-`s` algorithm has success against `F_4^*` at most

`244/625 + 192/(n-3)`

for large `n`, uniformly over `s`.

The bound is uniform in the algorithm's declared sample size, so averaging over an arbitrary randomized sample-size choice preserves it. Applying Yao's principle, for every randomized source algorithm there exists a deterministic input/preliminary order in the support of the adversarial distribution on which its success is at most `244/625+o(1)`. Taking arbitrarily large `n` yields

`alpha_SBOffAO1 <= 244/625`.

This completes the proof. QED.
