## 4. B15 — BREAK THE SYMMETRY: one missing root has an exact escape tube

The first question was whether the full-A4 theorem survives deleting only one oriented root. It does not survive in its original form, and the failure can be quantified exactly.

Let

`r_ij=(e_i-e_j)/sqrt(2)`, `w=(1,1,1,1,1)/sqrt(5)`,

and suppose the code contains every `A_4` root except `r_12`. For another code point write

`x=h w+y`, `y in H`, and `a=<y,r_12>=(y_1-y_2)/sqrt(2)`.

If `a<=1/2`, the missing inequality is automatically satisfied, so the previous full-A4 theorem still gives

`|h|>=sqrt(2/5)`.

The genuinely new regime is `1/2<=a<=1`. I proved the sharp inequalities

`||y||^2 <= a^2 + (7/5)(1-a)^2 = (12a^2-14a+7)/5`,

`h^2 >= 2(1-a)(6a-1)/5`,

and, with `y=a r_12+z`, `z perpendicular r_12`,

`||z||^2 <= (7/5)(1-a)^2`.

### Complete derivation

Scale `Y=sqrt(2)y`. All retained root inequalities are

`Y_i-Y_j<=1`

for every ordered pair except `(1,2)`. Put

`d=Y_1-Y_2=2a`, `m=(Y_1+Y_2)/2`, `q=1-d/2`.

For `k=3,4,5`, the two retained inequalities through coordinates 1 and 2 give

`m-q <= Y_k <= m+q`.

Write `Y_k=m+u_k`, with `u_k in [-q,q]`, and put `S=u_3+u_4+u_5`. Since `sum_i Y_i=0`, `m=-S/5`. Direct expansion yields

`||Y||^2 = d^2/2 + sum_{k=3}^5 u_k^2 - S^2/5`.

The quadratic form `sum u_k^2-(sum u_k)^2/5` is convex; its Hessian has eigenvalues `2,2,4/5`. Therefore its maximum on `[-q,q]^3` occurs at a cube vertex. At a vertex, `sum u_k^2=3q^2`, while `S^2` is `q^2` or `9q^2`; the maximum is the two-versus-one sign split and equals `14q^2/5`. Hence

`||Y||^2 <= d^2/2 + (14/5)(1-d/2)^2`.

Divide by two and substitute `d=2a`. This proves the three displayed inequalities.

The bound is sharp at the escape endpoint `a=1`: then `x=r_12`, `h=0`. Thus deleting just one oriented root destroys every positive uniform height gap. The full-A4 Petersen projection cannot simply be reused after one-root deletion.

## 5. B6 — DEFORM TO A SOLVABLE POINT: a robust A4-neighborhood barrier

Although literal root deletion is brittle, small geometric deformation of the *entire* 20-point section is not. The previous theorem has a positive stability neighborhood.

Define the intrinsic 11-point `S^3` threshold

`sigma_11 := min_{u_1,...,u_11 in S^3} max_{i<j}<u_i,u_j>`.

Compactness gives attainment. Since Bachoc--Vallentin prove `A(4,1/6)=10`, necessarily

`sigma_11>1/6`.

Set

`epsilon_* = min{ (sqrt(5)-2)/4, (1/2)( sqrt(5/(6(1-sigma_11)))-1 ) } > 0`.

### Robust-A4 theorem

Suppose a five-dimensional kissing code contains 20 labeled points `q_ij` such that, after one orthogonal transformation,

`||q_ij-r_ij|| <= epsilon < epsilon_*`

for every ordered pair `i != j`. Then the entire code has at most 40 points.

### Proof

For any extra point `x=h w+y`, the kissing inequality against `q_ij` gives

`<x,r_ij> <= <x,q_ij> + ||q_ij-r_ij|| <= 1/2+epsilon`.

Using both orientations gives

`|y_i-y_j| <= (1+2epsilon)/sqrt(2)`.

The exact five-coordinate range-variance inequality therefore yields

`||y||^2 <= M_epsilon := (3/5)(1+2epsilon)^2`.

Hence every extra point has `|h|>=h_0=sqrt(1-M_epsilon)`. The first term in `epsilon_*` ensures `M_epsilon<3/4`, hence `h_0>1/2`.

For two extra points in the same hemisphere, write

`x=a w+sqrt(1-a^2)u`, `x'=b w+sqrt(1-b^2)v`,

with `a,b>=h_0`, `u,v in S^3`. Their kissing inequality implies

`<u,v> <= F(a,b)=(1/2-ab)/(sqrt(1-a^2)sqrt(1-b^2))`.

When `a,b>1/2`, `F` decreases in either variable because

`sign(partial F/partial a)=sign(a/2-b)<0`

and symmetrically. Consequently

`<u,v> <= F(h_0,h_0)=1-1/(2M_epsilon)=:t_epsilon`.

The second term in `epsilon_*` is exactly the strict inequality `t_epsilon<sigma_11`. Therefore a hemisphere cannot contain 11 projected points. Each hemisphere contains at most ten extras, there are no equatorial extras, and the total is at most `20+10+10=40`.

This proves a genuine robustness statement: every hypothetical 41--44 point code must stay a positive distance away, modulo isometry and labeling, from every full `A_4` 20-point section. The radius is expressed exactly in the positive gap `sigma_11-1/6`; this run does not claim a new exact value of `sigma_11`.

**B6 outcome:** exact PARTIAL theorem, no unrestricted endpoint movement. It strengthens the first run by showing that `A_4` exclusion is not merely a measure-zero exact-symmetry phenomenon.
