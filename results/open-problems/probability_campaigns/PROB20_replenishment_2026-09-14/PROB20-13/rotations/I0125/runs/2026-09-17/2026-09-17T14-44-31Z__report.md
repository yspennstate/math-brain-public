## 4. Exact blocking statement

\[
\boxed{\nexists\,x_1,\ldots,x_{44}\in S^4\quad\text{such that}\quad
\langle x_i,x_j\rangle\le \tfrac12\ \text{for every }i\ne j.}
\]

Proving this alone would move the frozen interval from `[40,44]` to `[40,43]`.

The previous run put the same obligation into a bounded rank-five max-volume gauge. Choose five code points of maximal five-dimensional volume, write `H=B^T B`, and express the other 39 points as `B z_a`. Then a hypothetical 44-code supplies a solution of

\[
H\succ0,\qquad H_{ii}=1,\qquad H_{ij}\le \tfrac12,
\]

\[
z_a^T H z_a=1,\qquad (Hz_a)_i\le\tfrac12,
\qquad z_a^T H z_b\le\tfrac12\quad(a\ne b),
\]

with every square minor of the coefficient matrix `Z=(z_1,...,z_39)` bounded in absolute value by one. The previous run also supplied an explicit positive determinant/eigenvalue floor for `H`, so this normal form is compact and uniformly separated from the singular rank boundary.

The exact blocker is therefore:

\[
\boxed{\text{exclude the compact semialgebraic }(H,Z)\text{ feasibility system above for }N=44.}
\]

Compactness and bounded coordinates are not themselves a contradiction.

## 6. What a successful proof must contain that none of the existing routes contains

A metric-moving proof must provide at least one of the following genuinely new ingredients:

1. **A global exact separating certificate.** A polynomial/SDP/sum-of-squares inequality valid for every spherical code in `S^4` with separation `60 degrees`, whose exact objective is strictly below 44.

2. **A finite structural reduction.** A theorem showing that every 44-point code has one of finitely many local patterns/contact types, each of which can be ruled out exactly. The previous `A_4` theorem supplies one forbidden type but not the reduction to it.

3. **A local-correction inequality coupled to global positivity.** An auxiliary Gegenbauer-positive kernel may be permitted to have the "wrong" sign on a carefully chosen interval, provided one can prove an exact upper bound on the total positive contribution around every code point. This is the essential feature of Musin's four-dimensional method that is absent from the current I0125 routes.

4. **A certified exact 41-point construction.** This would instead move the lower endpoint and refute the expected value 40. No such construction is currently known in this track or in the bounded current-source search.

The central missing object is therefore not another local lemma about one known 40-code. It is a source-global certificate or source-global finite reduction.

## 8. Nearest solved problem and what its proof has that this target lacks

The nearest solved analogue is the four-dimensional kissing number `tau_4=24`, proved by Oleg Musin in *The kissing number in four dimensions*, Annals of Mathematics 168 (2008), 1--32.

Musin's key architecture is not merely "higher-degree LP". His modified Delsarte polynomial `f_4` has nonnegative Gegenbauer coefficients but is allowed to be positive on part of the forbidden-sign interval near inner product `-1`; he then bounds how many such positive contributions can occur and how large their total can be using local spherical geometry. In his notation the row-wise quantities `h_m` are bounded for the small possible local multiplicities, and the global positive-definite sum then yields the cardinality bound.

What five dimensions presently lack is an analogue with enough numerical margin:

- an explicit auxiliary kernel suitable for `S^4`;
- a rigorous description of the local cap configuration responsible for every positive off-diagonal contribution;
- an exact bound `h_max/f_0 < 44` to exclude 44 (and eventually `<41` to prove the conjectured exact value 40).

The three-point SDP encodes more average triple information than classical two-point LP, but it does not supply this kind of bespoke local nonconvex correction. Conversely, the I0125 `A_4` arguments supply strong local geometry only around very special sections, not around every point of an arbitrary 44-code.

This is the clearest technique gap recovered in the stuck audit.

## 10. B18 — SAY IT IN ANOTHER LANGUAGE

Translate the desired next proof into a **row-sum certificate problem**.

For an auxiliary zonal polynomial/kernel

`f(t)=sum_{k>=0} f_k G_k^{(5)}(t)`

with `f_0>0` and `f_k>=0`, positive definiteness gives the global lower bound

`sum_{i,j} f(<x_i,x_j>) >= f_0 N^2`.

A Musin-style recovery would not insist that `f(t)<=0` throughout the entire kissing interval `[-1,1/2]`. Instead it would allow a controlled positive region and prove, by exact local geometry, a row bound

`f(1)+sum_{j!=i} f(<x_i,x_j>) <= H`

for every code point. Summing rows would give `N <= H/f_0`.

For the immediate endpoint goal, the design target is therefore

`H/f_0 < 44`.

This is a research specification, not a theorem and not evidence that a suitable `f` exists.

**B18 outcome:** the unrestricted `N=44` problem is recast as finding one exact kernel plus one exact local cap bound. This is materially different from both the previous `A_4` section route and from rerunning the same globally sign-constrained SDP.
