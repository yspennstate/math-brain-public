## 4. B1 — CHANGE THE CATEGORY: an exact max-volume Gram normal form

Let `C={x_1,...,x_N} subset S^4` be a spanning kissing code. Choose five points `b_1,...,b_5` maximizing

`|det B|`, where `B=[b_1 ... b_5]` is the 5-by-5 matrix of those columns.

Set

`H = B^T B`.

Then `H` is positive definite, `H_ii=1`, and `H_ij<=1/2` for `i != j`.

For every remaining point `x`, write uniquely

`x = B z(x)`.

### Lemma 4.1 — 1-barycentric coefficient bound

For every extra point `x` and every coordinate `i`,

`|z_i(x)| <= 1`.

**Proof.** Replace column `b_i` of `B` by `x=Bz`. Multilinearity of determinant gives

`det[b_1,...,b_{i-1},x,b_{i+1},...,b_5] = z_i det B`.

The left-hand five-tuple consists of code points, so maximality of `|det B|` gives `|z_i| |det B| <= |det B|`. Since `det B != 0`, `|z_i|<=1`. QED.

### Lemma 4.2 — every square minor of the coefficient matrix is bounded by one

Let `Z` be the 5-by-(N-5) matrix whose columns are the coefficient vectors of the remaining code points. For every row set `I subset {1,...,5}` and every equally sized set `J` of extra columns,

`|det Z[I,J]| <= 1`.

**Proof.** Let `|I|=|J|=k`. Replace the basis columns indexed by `I` with the code points indexed by `J`. If the resulting 5-by-5 matrix is `B'`, then `B'=BM`, where, after permuting the untouched coordinates first, `M` is block upper triangular with diagonal blocks `I_(5-k)` and `Z[I,J]`. Hence

`|det B'| = |det B| |det Z[I,J]|`.

Again maximality of `B` gives `|det B'|<=|det B|`. QED.

The first lemma is a standard barycentric-spanner fact. The second is the full replacement-minor version that is natural for this finite code.

### Exact semialgebraic form

For `N=44`, write the 39 extra columns as `z_1,...,z_39`. A 44-code exists if and only if one can realize, after choosing a maximum-volume basis, variables `H,Z` satisfying

1. `H=H^T`, `H` positive definite, `H_ii=1`, `H_ij<=1/2` for `i != j`;
2. `z_a in [-1,1]^5` for all `a`;
3. `z_a^T H z_a = 1` for all `a`;
4. `(H z_a)_i <= 1/2` for every basis index `i` and extra point `a`;
5. `z_a^T H z_b <= 1/2` for all `a != b`;
6. every square minor of `Z` has absolute value at most 1.

The forward direction is exactly the construction above. Conversely, conditions 1--5 alone already reconstruct a valid code by taking any `B` with `B^T B=H` and columns `B e_i`, `B z_a`; condition 6 is a valid maximum-volume normalization available for every actual code.

This formulation fixes the ambient orthogonal gauge and, unlike a generic 44-by-44 Gram feasibility problem, represents rank five *exactly* rather than through an external rank relaxation.

## 5. B30 — ONE N AT A TIME: every hypothetical 44-code has a quantitative width in every lower-dimensional subspace

The max-volume gauge is useful only if its basis cannot degenerate toward a singular matrix. For `N=44` one can prove an explicit positive determinant floor using only elementary spherical-cap packing.

For `0<=epsilon<1`, define

`t(epsilon) = (1/2 + epsilon^2)/(1-epsilon^2)`.

### Projection lemma

Let `W` be an `r`-dimensional subspace of `R^5`, and suppose every `x in C` satisfies `dist(x,W)<epsilon`. Write

`x=p_x+q_x`, `p_x in W`, `q_x perpendicular W`,

and normalize `u_x=p_x/||p_x|| in S^(r-1)`. Then for distinct `x,y`,

`u_x . u_y < t(epsilon)`.

Indeed,

`p_x.p_y = x.y - q_x.q_y <= 1/2 + ||q_x|| ||q_y|| < 1/2+epsilon^2`,

while `||p_x||||p_y|| > 1-epsilon^2`.

Thus if all 44 original points lie in an `epsilon`-tube around `W`, their normalized projections form a 44-point spherical code in dimension `r` at the weaker threshold `t(epsilon)`.

### Explicit critical widths

Define

`epsilon_1 = 1/2`.

For `r=2`, put

`t_2 = cos(pi/22)`,

`epsilon_2 = sqrt((t_2-1/2)/(1+t_2)) = 0.4961486831...`.

For `r=3`, spherical-cap area on `S^2` gives the exact threshold

`t_3 = 199/242`,

`epsilon_3 = sqrt(26/147) = 0.4205600413...`.

For `r=4`, let `s_4 in (0,pi/6)` be the unique solution of

`(s_4 - (1/2) sin(2 s_4))/pi = 1/44`.

(The left side is the normalized area of a geodesic cap of radius `s_4` on `S^3`.) Put

`t_4 = cos(2 s_4)`,

`epsilon_4 = sqrt((t_4-1/2)/(1+t_4))`.

Numerically,

`s_4 = 0.4823241125...`, `t_4 = 0.5697060173...`, `epsilon_4 = 0.2107298089...`.

### Theorem 5.1 — subspace-width barrier for a 44-code

If `C subset S^4` is a 44-point kissing code, then for every `r`-dimensional subspace `W`, `r=1,2,3,4`,

`max_{x in C} dist(x,W) >= epsilon_r`.

**Proof.**

- `r=1`: if every point were at distance `<1/2` from a fixed line, then every point would lie at angular distance `<pi/6` from one of the two unit directions on that line. Two points in the same one of these two cones would have angular separation `<pi/3`, impossible. Hence there could be at most two points.

- `r=2`: under `dist<epsilon_2`, the projection lemma gives pairwise angular separation `> pi/22` on `S^1`. Forty-four such circular gaps would sum to more than `2pi`, impossible.

- `r=3`: let `s_3=arccos(21/22)`. Then `cos(2s_3)=199/242=t_3`, and a cap of radius `s_3` on `S^2` has normalized area `(1-cos s_3)/2=1/44`. Under `dist<epsilon_3`, projected separation is strictly greater than `2s_3`; slightly enlarging the 44 disjoint caps past `s_3` would give total area greater than the whole sphere, impossible.

- `r=4`: the normalized `S^3` cap area at radius `s` is

  `F_4(s)=(s-(1/2)sin(2s))/pi`.

  It is strictly increasing for `s>0`. By definition `F_4(s_4)=1/44`. Under `dist<epsilon_4`, projected angular separation is strictly greater than `2s_4`; again one can enlarge 44 disjoint caps slightly past radius `s_4`, forcing total normalized area greater than one. Contradiction.

QED.

### Corollary 5.2 — an explicit positive five-volume and determinant floor

Choose `b_1` arbitrarily. Apply Theorem 5.1 successively to the spans of the already chosen vectors. Gram--Schmidt then gives a five-tuple with volume at least

`V_* = epsilon_1 epsilon_2 epsilon_3 epsilon_4`

`    = (1/2) epsilon_2 epsilon_3 epsilon_4`

`    = 0.02198547369...`.

Therefore a maximum-volume basis satisfies

`|det B| >= V_*`,

and hence

`det H = det(B^T B) >= D_* := V_*^2 = 0.0004833610537...`.

This lower bound is exact through the definitions of `epsilon_2,epsilon_3,epsilon_4`; the decimals are only orientation values.

Since `trace(H)=5`, if `lambda_min(H)` is the smallest eigenvalue, the other four eigenvalues have product at most `(5/4)^4`. Consequently

`lambda_min(H) >= D_* (4/5)^4 = 0.0001979846876...`.

Thus the max-volume normal form for `N=44` is not merely bounded in `Z`: its basis Gram matrix stays a uniform positive distance from singularity.
