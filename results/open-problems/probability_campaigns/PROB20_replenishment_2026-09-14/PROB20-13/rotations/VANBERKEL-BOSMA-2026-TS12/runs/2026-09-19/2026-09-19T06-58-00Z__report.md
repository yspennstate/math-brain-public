## 4. New theorem: the <=2q complement-component profile

The q-short lemma can be doubled exactly. This is the main B6 mechanism of the run.

### Lemma (first old-prefix complement component of width at most 2q)

Let `P` be a certified prefix of a greedy strict 3-sumfree sequence whose two smallest elements are `f<g`, and set `q=f+g`. Let `L` be the last accepted value in `P`, and let

`F(P)={a+b+c : a,b,c in P are pairwise distinct}`.

Suppose `[u,v]` is the first connected component of integers greater than `L` which is disjoint from `F(P)`, and all integers from `L+1` through `u-1` lie in `F(P)`. Put `w=v-u+1`. If

`w <= 2q`,

then the greedy sequence contains **exactly**

`[u, u+min(w,q)-1]`

inside `[u,v]`.

Equivalently:

- if `w<=q`, the entire component is accepted;
- if `q<w<=2q`, the first `q` points are accepted and the remaining `w-q` points are excluded.

### Proof

For each `0<=j<min(w,q)`, the value `u+j` has no representation by three distinct elements of the old prefix `P` because `[u,v]` is disjoint from `F(P)`. Any representation created using at least one newly accepted value `y>=u` has value at least

`y+f+g >= u+q > u+j`.

Thus the first `min(w,q)` points are greedily accepted.

If `q<=j<w<=2q`, then `0<=j-q<q`; hence `u+j-q` lies in the first accepted q-block just proved. It is larger than every old prefix element used as one of the two globally smallest values and in particular is distinct from `f` and `g`. Therefore

`u+j=(u+j-q)+f+g`

is a sum of three distinct earlier sequence elements, so `u+j` is excluded. This proves the exact membership profile. ∎

This lemma is source-valid for the strict rule: the displayed representation uses three distinct entries.
