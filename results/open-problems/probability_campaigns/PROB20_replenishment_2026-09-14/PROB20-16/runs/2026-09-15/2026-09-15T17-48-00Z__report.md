# 2. Abstract convex-core satellite set-up

Let \(U\) be a measured core of size \(r\), and let
\[
\mathcal C\subset\{M=M^*:0\le M\le I\}
\]
be a **convex** set such that
\[
M\longmapsto H(P_M)
\]
is concave on \(\mathcal C\).

Let \(O_1,\ldots,O_m\) be disjoint satellite blocks. For each \(j\), fix

- a strict Hermitian positive contraction \(0<C_j<I\) on \(O_j\),
- a core vector \(b_j\in\mathbb C^r\),
- a satellite vector \(v_j\in\mathbb C^{O_j}\).

For a Hermitian core matrix \(A\) and complex amplitudes \(z_j\), define
\[
K(A,z)=
\begin{pmatrix}
A&z_1b_1v_1^*&\cdots&z_mb_mv_m^*\\
\bar z_1v_1b_1^*&C_1&&0\\
\vdots&&\ddots&\\
\bar z_mv_mb_m^*&0&&C_m
\end{pmatrix}.
\tag{2.1}
\]
Put
\[
s_j=|z_j|^2.
\tag{2.2}
\]

The satellites have no cross blocks among themselves, but may be arbitrarily large and internally coherent. Their core attachment directions \(b_j\) are completely arbitrary and need not be parallel.

For later use set
\[
\alpha_j=v_j^*C_j^{-1}v_j\ge0,
\qquad
\beta_j=v_j^*(I-C_j)^{-1}v_j\ge0.
\tag{2.3}
\]

# 3. Exact physical squared-strength domain

Schur complementation of the fixed block-diagonal satellite principal kernel gives
\[
K(A,z)\ge0
\iff
A-\sum_j\alpha_js_jb_jb_j^*\ge0.
\tag{3.1}
\]
Likewise
\[
I-K(A,z)\ge0
\iff
I-A-\sum_j\beta_js_jb_jb_j^*\ge0.
\tag{3.2}
\]
Hence the exact physical domain in \((A,s)\) is the spectrahedron
\[
\boxed{
\mathcal P=
\left\{
(A,s):
s_j\ge0,
\ A-\sum_j\alpha_js_jb_jb_j^*\ge0,
\ I-A-\sum_j\beta_js_jb_jb_j^*\ge0
\right\}.
}
\tag{3.3}
\]
It is convex. For fixed \(A\), it is coordinatewise downward closed in \(s\).

Independent scalar phase gauges on each whole satellite block remove the phases of \(z_j\) while commuting with \(C_j\). Therefore the entire DPP law and its Shannon entropy depend on \(z\) only through \(s_j=|z_j|^2\).

# 4. Exact conditional core kernels

For an exact satellite atom \(y_j\subseteq O_j\), define
\[
Q_{j,y_j}=C_j-P_{O_j\setminus y_j},
\qquad
q_j(y_j)=(-1)^{|O_j\setminus y_j|}\det Q_{j,y_j}>0,
\tag{4.1}
\]
and
\[
d_{j,y_j}=v_j^*Q_{j,y_j}^{-1}v_j\in\mathbb R.
\tag{4.2}
\]
The scalar \(d_{j,y_j}\) can have either sign.

The satellite principal marginal is the product DPP
\[
P_{C_1}\otimes\cdots\otimes P_{C_m},
\]
so the exact satellite atoms are independent with fixed weights
\[
q(y)=\prod_jq_j(y_j).
\tag{4.3}
\]

Conditioning on the complete satellite configuration \(y=(y_1,\ldots,y_m)\), Schur complementation of the exact-atom determinant gives the core DPP kernel
\[
\boxed{
M_y(A,s)=
A-\sum_js_jd_{j,y_j}b_jb_j^*.
}
\tag{4.4}
\]
Whenever the full kernel is a positive contraction, this conditional matrix is automatically a positive contraction.

# 5. The robust convex-core domain

A difficulty absent from the exchangeable-core theorem is that the signed conditional shifts in (4.4) can leave a restricted concavity region when strengths are reduced coordinatewise. The correct finite closure condition is to control every vertex of every strength box.

For a subset \(J\subseteq[m]\), define
\[
M_{y,J}(A,s)
=
A-\sum_{j\in J}s_jd_{j,y_j}b_jb_j^*.
\tag{5.1}
\]
Define
\[
\boxed{
\mathcal D_{\mathcal C}
=
\left\{
(A,s)\in\mathcal P:
M_{y,J}(A,s)\in\mathcal C
\text{ for every satellite atom }y
\text{ and every }J\subseteq[m]
\right\}.
}
\tag{5.2}
\]
This domain is finite-checkable: there are finitely many satellite atoms and finitely many subsets \(J\).

### Lemma 5.1 — convexity

\(\mathcal D_{\mathcal C}\) is convex.

**Proof.** The physical domain \(\mathcal P\) is convex. For each fixed \((y,J)\), the map
\[
(A,s)\mapsto M_{y,J}(A,s)
\]
is affine, so the preimage of the convex set \(\mathcal C\) is convex. Intersect all of these finitely many convex sets. \(\square\)

### Lemma 5.2 — downward closure

If \((A,s)\in\mathcal D_{\mathcal C}\) and \(0\le s'_j\le s_j\) coordinatewise, then
\[
(A,s')\in\mathcal D_{\mathcal C}.
\tag{5.3}
\]

**Proof.** Physical feasibility is downward closed by (3.1)–(3.2). For the core condition, write \(s'_j=\theta_js_j\), \(0\le\theta_j\le1\). For any fixed atom \(y\) and subset \(J\), let \(R\subseteq J\) be a random subset obtained by including \(j\in J\) independently with probability \(\theta_j\). Then
\[
M_{y,J}(A,s')
=
\mathbb E_R M_{y,R}(A,s).
\tag{5.4}
\]
Every vertex matrix on the right belongs to \(\mathcal C\) by definition, and \(\mathcal C\) is convex. \(\square\)

The subset conditions in (5.2) are precisely what makes mixed-sign complex amplitude interpolation compatible with a restricted core theorem.

# 6. Abstract lifting theorem

Let
\[
F(A,s)=H(P_{K(A,z)}),
\qquad s_j=|z_j|^2.
\tag{6.1}
\]
On \(\mathcal D_{\mathcal C}\), Shannon chain rule and (4.4) give
\[
\boxed{
F(A,s)
=
\sum_{j=1}^mH(P_{C_j})
+
\sum_yq(y)H(P_{M_y(A,s)}).
}
\tag{6.2}
\]
Since \(M_y(A,s)\) is affine in \((A,s)\), belongs to \(\mathcal C\), and core entropy is concave on \(\mathcal C\), every term in (6.2) is concave. Therefore:

### Theorem 6.1 — convex-core lifting

\[
\boxed{
F(A,s)\text{ is jointly concave in }(A,s)
\text{ on }\mathcal D_{\mathcal C}.
}
\tag{6.3}
\]

For each satellite strength, \(F\) is also coordinatewise nonincreasing on \(\mathcal D_{\mathcal C}\). Indeed, setting \(s_j=0\) completely decouples block \(O_j\), while its marginal and the complementary principal marginal remain fixed. Thus
\[
F(A,s^{\setminus j})-F(A,s)
=I(Y_j;X,Y_{-j})\ge0.
\tag{6.4}
\]
The entire one-dimensional segment from \(0\) to \(s_j\) lies in \(\mathcal D_{\mathcal C}\) by Lemma 5.2, and the slice is concave by (6.3); hence it is nonincreasing throughout.

# 7. Complex-amplitude affine segments

Take two points
\[
(A_0,z^0),\qquad(A_1,z^1)
\]
whose squared-strength representatives
\[
(A_0,s^0),\qquad(A_1,s^1)
\]
belong to \(\mathcal D_{\mathcal C}\). Define the actual affine kernel segment
\[
A_t=(1-t)A_0+tA_1,
\qquad
z_t=(1-t)z^0+tz^1.
\tag{7.1}
\]
Put
\[
s_j^t=|z_j^t|^2,
\qquad
\bar s_j=(1-t)s_j^0+ts_j^1.
\]
Then
\[
\boxed{
\bar s_j-s_j^t
=t(1-t)|z_j^1-z_j^0|^2\ge0.
}
\tag{7.2}
\]
Convexity of \(\mathcal D_{\mathcal C}\) gives
\[
(A_t,\bar s)\in\mathcal D_{\mathcal C},
\]
and downward closure gives
\[
(A_t,s^t)\in\mathcal D_{\mathcal C}.
\]
Strength monotonicity and joint concavity then yield
\[
\begin{aligned}
H(P_{K(A_t,z_t)})
&=F(A_t,s^t)\\
&\ge F(A_t,\bar s)\\
&\ge(1-t)F(A_0,s^0)+tF(A_1,s^1).
\end{aligned}
\tag{7.3}
\]
Thus:

### Theorem 7.1 — complex satellite lifting

\[
\boxed{
H(P_{K(A_t,z_t)})
\ge
(1-t)H(P_{K(A_0,z^0)})
+tH(P_{K(A_1,z^1)})
}
\tag{7.4}
\]
for every endpoint pair in \(\mathcal D_{\mathcal C}\).

This theorem is purely finite-dimensional and makes no stationary entropy-rate converse claim.

# 8. New global nonexchangeable three-site theorem

Take the core dimension \(r=3\) and let \(\mathcal C=\mathcal W\) be the closed weak-edge cone
\[
\boxed{
\mathcal W=
\left\{
M=M^*:
|M_{ij}|\le\frac27M_{kk},\quad
|M_{ij}|\le\frac27(1-M_{kk})
\text{ for every }i<j\text{ and every }k
\right\}.
}
\tag{8.1}
\]
The repository theorem `ROOT_GENERAL_DIAGONAL_CONE.md` proves:

1. \(\mathcal W\) is convex;
2. its interior consists of positive contractions;
3. DPP Shannon entropy is concave on its closure, including complex Hermitian kernels and unequal diagonals.

Apply Theorem 7.1.

### Theorem 8.1 — moving nonexchangeable three-site core with coherent satellites

Let the measured core have three coordinates. Fix arbitrary strict coherent satellite blocks \(C_j\), arbitrary core attachment vectors \(b_j\in\mathbb C^3\), arbitrary satellite vectors \(v_j\), and allow all complex amplitudes \(z_j\) to vary independently.

If both endpoints satisfy the finite robust-domain conditions
\[
(A_r,s^r)\in\mathcal D_{\mathcal W},
\qquad r=0,1,
\tag{8.2}
\]
then the entire actual affine matrix segment satisfies Lyons concavity.

The three-site core \(A_t\) is allowed to be fully nonexchangeable: all three diagonal entries, all three complex edges, and their phases may change affinely, subject only to the explicit finite constraints defining \(\mathcal D_{\mathcal W}\).

The full kernel may have arbitrarily many additional measured coordinates in coherent satellites, and the satellite attachment directions \(b_j\) need not be parallel. This is a global theorem on its domain, not a local Hessian neighborhood.

# 9. A simple explicit sufficient strength budget

The exact domain (5.2) is the strongest finite certificate. A simpler conservative condition shows it has a substantial interior.

For a three-site core \(A\), put
\[
\mu(A)=\min_k\{A_{kk},1-A_{kk}\},
\qquad
e(A)=\max_{i<j}|A_{ij}|,
\]
and suppose
\[
\Delta(A):=\frac27\mu(A)-e(A)>0.
\tag{9.1}
\]
For each satellite let
\[
\delta_j=\max_{y_j}|d_{j,y_j}|.
\tag{9.2}
\]
Every vertex conditional shift has entrywise bound
\[
\max_{p,q}|(M_{y,J}-A)_{pq}|
\le
\sum_{j\in J}s_j\delta_j\|b_j\|_\infty^2.
\tag{9.3}
\]
If a Hermitian perturbation \(E\) satisfies \(\max_{p,q}|E_{pq}|\le\rho\), then
\[
\mu(A+E)\ge\mu(A)-\rho,
\qquad
e(A+E)\le e(A)+\rho.
\]
Therefore \(A+E\in\mathcal W\) whenever
\[
e(A)+\rho
\le\frac27(\mu(A)-\rho),
\]
i.e.
\[
\rho\le\frac79\Delta(A).
\tag{9.4}
\]
Hence the explicit sufficient cone budget is
\[
\boxed{
\sum_js_j\delta_j\|b_j\|_\infty^2
\le\frac79\Delta(A).
}
\tag{9.5}
\]
This automatically places every conditional box vertex in \(\mathcal W\).

Physical feasibility may be certified independently by
\[
\boxed{
\sum_j\alpha_js_j\|b_j\|_2^2
\le\lambda_{\min}(A),
\qquad
\sum_j\beta_js_j\|b_j\|_2^2
\le\lambda_{\min}(I-A).
}
\tag{9.6}
\]
Thus every strict interior point of the three-site weak-edge cone admits a nonzero explicit satellite-strength neighborhood for arbitrary coherent satellite blocks and arbitrary attachment directions.

For a moving core segment one can enforce (9.5)–(9.6) at the endpoints and use the exact convex domain \(\mathcal D_{\mathcal W}\) for the rigorous segment certificate.

# 10. Boundary limits

The theorem above was written with strict satellite blocks only to make \(Q_{j,y_j}^{-1}\), \(C_j^{-1}\), and \((I-C_j)^{-1}\) literal. Closed positive contractions follow by common regularization
\[
K^\varepsilon=(1-2\varepsilon)K+\varepsilon I.
\tag{10.1}
\]
This preserves the affine endpoint interpolation and the disjoint-satellite block pattern. The conditional/core inequalities can be imposed on the regularized kernels and passed to the limit. Exact DPP atom probabilities are polynomial in the kernel entries, and \(-p\log p\) is continuous at \(p=0\). Therefore the entropy inequality survives the limit.

No inverse formula is asserted literally on zero-probability boundary atoms; they are handled only through the regularized limit.

# 12. Failed routes / cautions

1. **Checking only the actual conditional core \(M_y(A,s)\in\mathcal C\) is insufficient for the complex-amplitude Jensen proof.** The actual midpoint squared strengths are smaller than the affine average strengths, and signed conditional shifts need not remain inside an arbitrary restricted core region under coordinatewise strength reduction. This is why the subset-vertex closure in (5.2) is needed.

2. **Physical downward closure alone is insufficient.** It preserves positive-contraction feasibility but does not guarantee that a restricted core concavity theorem remains applicable after reducing strengths.

3. **No arbitrary unitary change of the measured basis is allowed.** DPP occupation entropy is basis-dependent. Only the explicit block phase gauges used above preserve every principal determinant.

4. **The weak-edge cone is a sufficient region, not the full three-site answer.** The lifting theorem cannot turn a partial core theorem into a universal one.
