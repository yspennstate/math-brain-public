## 1. Exact conditional-block localization

Let the measured ground set be a finite set
\[
E=U\sqcup R,
\]
and write a strict Hermitian contraction as
\[
K=
\begin{pmatrix}
A&B\\
B^*&C
\end{pmatrix},
\qquad 0<K<I.
\tag{1.1}
\]
Here \(A=K_U\), \(C=K_R\). Consider an affine chord on which **only the active principal block moves**:
\[
K_t=
\begin{pmatrix}
A_t&B\\
B^*&C
\end{pmatrix},
\qquad
A_t=(1-t)A_0+tA_1.
\tag{1.2}
\]
The cross block \(B\) and outside block \(C\) are fixed.

For an exact outside configuration \(y\subseteq R\), put
\[
Q_y=C-I_{R\setminus y}.
\tag{1.3}
\]
Strictness of the full DPP implies every outside atom has positive probability, hence \(Q_y\) is invertible. Define
\[
\mu_y=(-1)^{|R\setminus y|}\det Q_y
      =P_C(Y=y)>0
\tag{1.4}
\]
and
\[
\boxed{
F_y(A)=A-BQ_y^{-1}B^*.
}
\tag{1.5}
\]

### Lemma 1.1 — exact localization of the conditional law

Conditioned on \(X_R=y\), the active occupation vector \(X_U\) is a DPP with kernel \(F_y(A)\). In particular
\[
0<F_y(A)<I_U
\]
for every strict physical \(K\).

**Proof.**
For an active atom \(x\subseteq U\), the joint exact atom is
\[
p_{x,y}(K)
=
(-1)^{|U\setminus x|+|R\setminus y|}
\det
\begin{pmatrix}
A-I_{U\setminus x}&B\\
B^*&Q_y
\end{pmatrix}.
\tag{1.6}
\]
The block determinant formula gives
\[
p_{x,y}(K)
=
\mu_y\,
(-1)^{|U\setminus x|}
\det\!\left(F_y(A)-I_{U\setminus x}\right).
\tag{1.7}
\]
The second factor is exactly the finite-DPP atom formula on \(U\). Dividing by \(\mu_y\) proves the conditional-law assertion. Positivity of all conditional atoms yields the strict contraction property. \(\square\)

Because \(B,C,Q_y\) are fixed along (1.2),
\[
\boxed{
F_y(A_t)=(1-t)F_y(A_0)+tF_y(A_1).
}
\tag{1.8}
\]
Thus conditioning has produced **no acceleration at all**.

The entropy chain rule therefore gives the exact identity
\[
\boxed{
H(P_{K_t})
=
H(P_C)+\sum_{y\subseteq R}\mu_y H(P_{F_y(A_t)}).
}
\tag{1.9}
\]

This is the main structural result of the run.

## 2. Exact localization of Hessians and Jensen gaps

Let
\[
D=A_1-A_0.
\]
Differentiating (1.9) inside the strict domain gives
\[
\boxed{
D^2H(P_{K_t})[\widehat D,\widehat D]
=
\sum_y\mu_y\,
D^2H(P_{F_y(A_t)})[D,D],
}
\tag{2.1}
\]
where \(\widehat D=D\oplus0_R\).

Likewise the full finite Jensen gap localizes exactly:
\[
\boxed{
\Gamma_K(t)
=
\sum_y\mu_y\,\Gamma_{F_y}(t),
}
\tag{2.2}
\]
where
\[
\Gamma_K(t)
=
H(P_{K_t})-(1-t)H(P_{K_0})-tH(P_{K_1})
\]
and \(\Gamma_{F_y}\) is the lower-dimensional DPP entropy Jensen gap on the affine conditional chord (1.8).

### Corollary 2.1 — support-size reduction

If Lyons concavity is known on all kernels of size \(|U|\), then it holds on every higher-dimensional chord whose endpoint difference is supported inside the principal block \(U\times U\).

Thus the genuinely new difficulty of an affine direction cannot come merely from an arbitrarily large frozen coherent exterior: after conditioning, a direction supported on \(m\) measured coordinates is exactly an \(m\)-site problem averaged with fixed positive weights.

This statement is a reduction principle. It does **not** prove the conjecture at support size \(m\).

## 3. Complete two-coordinate consequence

Take \(|U|=2\). C055 proves full complex two-site concavity, so every term on the right of (2.2) is nonnegative.

### Theorem 3.1 — any fixed two-coordinate principal support

Let \(K_0,K_1\) be finite Hermitian positive contractions and suppose
\[
(K_1-K_0)_{ij}=0
\quad\text{whenever either }i\notin U\text{ or }j\notin U
\tag{3.1}
\]
for some \(|U|\le2\). Then
\[
\boxed{
H(P_{(1-t)K_0+tK_1})
\ge
(1-t)H(P_{K_0})+tH(P_{K_1})
}
\tag{3.2}
\]
for all \(0\le t\le1\), including complex kernels and spectral-boundary endpoints.

As noted in Section 0, this finite theorem overlaps prior campaign scope (in particular C062 with one fixed satellite block); it is retained here because (1.9)–(2.2) give a shorter exact localization proof and a reusable support-reduction mechanism.

For a strict base and a Hermitian \(2\times2\) active velocity
\[
D=
\begin{pmatrix}
d_1&z\\
\bar z&d_2
\end{pmatrix},
\]
C055 inserted into (2.1) gives the exact decomposition
\[
\boxed{
-D^2H(P_K)[\widehat D,\widehat D]
=
\sum_y\mu_y
\left[
I_{F_y}(D)-2\det(D)\lambda_y
\right],
}
\tag{3.3}
\]
where
\[
\lambda_y=
\log\frac{p^{(y)}_{10}p^{(y)}_{01}}
{p^{(y)}_{00}p^{(y)}_{11}}
\ge0.
\tag{3.4}
\]
The complete conditional Fisher informations \(I_{F_y}(D)\) are retained; no covariance proxy or frozen-log shortcut is used.

A quantitative consequence is
\[
\boxed{
-D^2H(P_K)[\widehat D,\widehat D]
\ge
4\|D\|_F^2
\sum_y\mu_y |(F_y)_{12}|^2.
}
\tag{3.5}
\]
The right side may vanish, so (3.5) is a lower bound, not a universal strict modulus.

## 4. A closed formula for an arbitrary moving complex edge

Specialize (3.3) to a pure complex edge velocity
\[
D=
\begin{pmatrix}
0&\delta\\
\bar\delta&0
\end{pmatrix}.
\tag{4.1}
\]
For a conditional pair
\[
F_y=
\begin{pmatrix}
\alpha_y&\xi_y\\
\bar\xi_y&\beta_y
\end{pmatrix},
\]
put \(q_y=|\xi_y|^2\). Its four exact atom probabilities are
\[
\begin{aligned}
p_{00}&=(1-\alpha_y)(1-\beta_y)-q_y,\\
p_{10}&=\alpha_y(1-\beta_y)+q_y,\\
p_{01}&=(1-\alpha_y)\beta_y+q_y,\\
p_{11}&=\alpha_y\beta_y-q_y.
\end{aligned}
\tag{4.2}
\]
They satisfy
\[
p_{10}p_{01}-p_{00}p_{11}=q_y,
\tag{4.3}
\]
so
\[
\lambda_y=\log\frac{p_{10}p_{01}}{p_{00}p_{11}}\ge0.
\tag{4.4}
\]

Along \(\xi_y(t)=\xi_y+t\delta\),
\[
\frac{d}{dt}|\xi_y(t)|^2
=
2\operatorname{Re}(\bar\xi_y(t)\delta),
\qquad
\frac{d^2}{dt^2}|\xi_y(t)|^2=2|\delta|^2.
\tag{4.5}
\]
Since the two-site entropy as a function of \(q=|\xi|^2\) satisfies
\[
\phi'(q)=-\lambda,\qquad
\phi''(q)=-
\left(
\frac1{p_{00}}+\frac1{p_{10}}+\frac1{p_{01}}+\frac1{p_{11}}
\right),
\tag{4.6}
\]
we get the exact arbitrary-dimensional edge-curvature formula
\[
\boxed{
\begin{aligned}
-\frac{d^2}{dt^2}H(P_{K_t})
={}&
\sum_y\mu_y\Bigg[
2|\delta|^2\lambda_y(t)\\
&\quad+
4\operatorname{Re}(\overline{\xi_y(t)}\delta)^2
\sum_{a,b\in\{0,1\}}\frac1{p^{(y)}_{ab}(t)}
\Bigg]\ge0.
\end{aligned}}
\tag{4.7}
\]
Every term is manifestly nonnegative.

Equation (4.7) strictly generalizes the *formula* from the preceding three-site cycle-quadrature checkpoint: no three-site gauge, no orthogonality condition, and no bound on the frozen exterior are needed. Its **finite concavity scope**, however, remains within the prior all-dimensional incident-row theorem and is not claimed as a new campaign class.

## 5. Boundary passage

For closed positive-contraction endpoints satisfying (3.1), use the common regularization
\[
K_j^{(\varepsilon)}
=
(1-2\varepsilon)K_j+\varepsilon I,
\qquad 0<\varepsilon<1/2.
\tag{5.1}
\]
Then
\[
K_1^{(\varepsilon)}-K_0^{(\varepsilon)}
=
(1-2\varepsilon)(K_1-K_0),
\]
so the active principal support is unchanged, and every regularized kernel is strict. Apply the strict conditional theorem and send \(\varepsilon\downarrow0\). Every finite DPP atom is polynomial in the entries of \(K\), and \(-p\log p\) is continuous at \(p=0\). Hence (3.2) holds on the closed contraction set.

No stationary entropy-rate converse is inferred.
