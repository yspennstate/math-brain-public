## 2. New exact structural reduction: only four sign-adapted original features are needed

The previous run used five features \((X_1,X_2,X_3,1_\varnothing,1_{123})\) so that one formula worked for both signs of \(\tau\). For a fixed base the sign is known, and one extreme event is enough.

### Theorem 2.1 — four-feature spacelike kernel

If \(\tau>0\), use
\[
Z_+=(X_1,X_2,X_3,\mathbf1_{\{X=123\}}).
\]
If \(\tau<0\), use
\[
Z_-=(X_1,X_2,X_3,\mathbf1_{\{X=\varnothing\}}).
\]
If all four expectation derivatives vanish and \(A\ne0\), then
\[
\boxed{F_K(A)>0.}
\tag{2.1}
\]

**Proof.** Vanishing of the three occupation derivatives gives \(A_{ii}=0\). For \(\tau>0\), vanishing of the full-event derivative is exactly \(D\det K[A]=0\), so Theorem 2.1 of the preceding checkpoint gives
\[
F_K(A)=2\sum_i c_i|A_{jk}|^2
+\tau p_{123}\|K^{-1/2}AK^{-1/2}\|_F^2>0.
\]
For \(\tau<0\), the empty-event derivative gives \(D\det(I-K)[A]=0\), and the complementary formula gives
\[
F_K(A)=2\sum_i(c_i+\tau)|A_{jk}|^2
+(-\tau)p_\varnothing\|(I-K)^{-1/2}A(I-K)^{-1/2}\|_F^2>0.
\]
\(\square\)

Thus the kernel of the sign-adapted four-feature derivative map is a five-real-dimensional strictly spacelike subspace of the Lorentz form. This improves the five-feature reduction from the preceding run.

### Corollary 2.2 — exact four-by-four scalar sufficient certificate

Let \(\Sigma_4\) be the covariance matrix of the appropriate four original statistics above. Let \(H_1,H_2,H_3=E_{11},E_{22},E_{33}\), and let \(H_4=\operatorname{adj}K\) for \(\tau>0\), while \(H_4=-\operatorname{adj}(I-K)\) for \(\tau<0\). Put \(\delta=\det M\), and
\[
(C_4)_{\alpha\beta}
=\operatorname{tr}(MH_\alpha MH_\beta)
-\frac12\operatorname{tr}(MH_\alpha)\operatorname{tr}(MH_\beta).
\tag{2.2}
\]
Theorem 2.1 implies that \(C_4\) has inertia \((3+,1-)\). The Fisher projection onto these four original statistics is
\[
\operatorname{FI}_4(A)=z^T\Sigma_4^{-1}z\le\operatorname{FI}(A).
\]
The same constrained Lorentz minimization as in the five-feature checkpoint gives
\[
\min_{D\mathbb EZ[A]=z}F_K(A)=\delta z^TC_4^{-1}z.
\]
Consequently
\[
\boxed{
\operatorname{FI}_4(A)+F_K(A)\ge0\ \forall A
\iff
\Sigma_4^{-1}+\delta C_4^{-1}\succeq0
\iff
\det(C_4+\delta\Sigma_4)\le0.
}
\tag{2.3}
\]
This is a four-by-four sign-adapted sufficient scalar for the full nine-direction Hessian. It is stronger than the five-feature certificate because it deliberately retains less Fisher information. Universal sign of (2.3) is **not proved here**; failure would refute only this proof route, not Lyons.

## 3. New analytic full-Hessian theorem from a split of two original Fisher projections

The four-feature scalar is still nonlinear. A simpler sufficient condition can be proved directly and yields an explicit new full-dimensional region.

### Theorem 3.1 — sign-adapted occupation/extreme-event certificate

Assume first \(\tau>0\), and put
\[
p=p_{123}=\det K,
\qquad
\theta=\tau(1-p).
\]
If
\[
\boxed{
\eta_+(K):=	au(1-p)+
\lambda_{\max}\!\left(S^{1/2}R(c)S^{1/2}\right)\le1,
}
\tag{3.1}
\]
then for every Hermitian \(A\),
\[
\boxed{
-D^2H(K)[A,A]\ge
p\tau\|K^{-1/2}AK^{-1/2}\|_F^2
+2\sum_i c_i|A_{jk}|^2
+d^T\Big[(1-\theta)S^{-1}-R(c)\Big]d
\ge0.
}
\tag{3.2}
\]
If \(\tau>0\), the first term makes (3.2) strict for every \(A\ne0\).

If \(\tau<0\), set
\[
\bar c_i=c_i+\tau,\qquad p_0=p_\varnothing=\det(I-K),
\qquad \bar\theta=(-\tau)(1-p_0).
\]
If
\[
\boxed{
\eta_-(K):=(-\tau)(1-p_0)+
\lambda_{\max}\!\left(S^{1/2}R(\bar c)S^{1/2}\right)\le1,
}
\tag{3.3}
\]
then for every Hermitian \(A\),
\[
\boxed{
-D^2H(K)[A,A]\ge
p_0(-\tau)\|(I-K)^{-1/2}A(I-K)^{-1/2}\|_F^2
+2\sum_i \bar c_i|A_{jk}|^2
+d^T\Big[(1-\bar\theta)S^{-1}-R(\bar c)\Big]d
\ge0.
}
\tag{3.4}
\]
Again it is strict for every nonzero \(A\).

At \(\tau=0\), the same argument with no extreme-event payment gives the sufficient condition
\[
\lambda_{\max}(S^{1/2}R(c)S^{1/2})\le1.
\tag{3.5}
\]

### Proof

Two lower bounds on the *same original measured Fisher information* are available:
\[
\operatorname{FI}(A)\ge
\frac{(D\det K[A])^2}{p(1-p)}
\tag{3.6}
\]
from the original full-atom indicator, and
\[
\operatorname{FI}(A)\ge d^TS^{-1}d
\tag{3.7}
\]
from the three original occupation indicators. Hence for every \(0\le\theta\le1\),
\[
\operatorname{FI}(A)\ge
\theta\frac{(D\det K[A])^2}{p(1-p)}
+(1-\theta)d^TS^{-1}d,
\tag{3.8}
\]
because the full Fisher information dominates each projection separately and therefore dominates every convex combination of them.

Write
\[
B=K^{-1/2}AK^{-1/2}.
\]
Then
\[
D\det K[A]=p\operatorname{tr}B,
\]
\[
D^2\det K[A,A]
=p\left((\operatorname{tr}B)^2-\operatorname{tr}(B^2)\right).
\tag{3.9}
\]
With the special choice \(\theta=\tau(1-p)\), the extreme-event part of (3.8) and the last term of (1.4) combine **exactly**:
\[
\theta\frac{(D\det K[A])^2}{p(1-p)}
-\tau D^2\det K[A,A]
=p\tau\operatorname{tr}(B^2)
=p\tau\|B\|_F^2.
\tag{3.10}
\]
Condition (3.1) implies \(0\le\theta\le1\), and by congruence it is exactly
\[
(1-\theta)S^{-1}-R(c)\succeq0.
\tag{3.11}
\]
Substitute (3.8)–(3.11) into (1.4). This proves (3.2).

For \(\tau<0\), apply the just-proved statement to the complementary DPP \(I-K\) in direction \(-A\). Its three interaction coefficients are \(\bar c_i=c_i+\tau\), its three-indicator covariance is again \(S\), its extreme mass is \(p_0\), and its three-body coefficient is \(-\tau>0\). This gives (3.3)–(3.4). \(\square\)

### Easy scalar corollary

Since \(S\succeq0\) and
\[
\operatorname{tr}S=\sum_iK_{ii}(1-K_{ii})\le\frac34,
\]
we have \(\|S\|_{\rm op}\le3/4\). Also \(R(a)\) has row sums at most \(2a_{\max}\), hence
\[
\lambda_{\max}(S^{1/2}R(a)S^{1/2})\le\frac32a_{\max}.
\]
Therefore the simpler conditions
\[
\boxed{
\tau(1-p_{123})+\frac32\max_i c_i\le1\qquad(\tau>0)
}
\tag{3.12}
\]
and
\[
\boxed{
(-\tau)(1-p_\varnothing)+\frac32\max_i(c_i+\tau)\le1\qquad(\tau<0)
}
\tag{3.13}
\]
are sufficient for strict negative definiteness of the complete Shannon-entropy Hessian in all nine real Hermitian directions.

This theorem is pointwise. Any affine kernel chord lying wholly inside one of these strict regions inherits entropy concavity by integrating the Hessian. No convexity of the whole region is asserted.
