# 4. Two-site setup

Fix a strict physical two-site kernel, after diagonal phase gauge,

\[
C(x)=
\begin{pmatrix}
x&r\\
r&y
\end{pmatrix},
\qquad s=r^2\ge0.
\]

The four atoms are

\[
p_{00}=(1-x)(1-y)-s,\quad
p_{10}=x(1-y)+s,
\]
\[
p_{01}=(1-x)y+s,\quad
p_{11}=xy-s,
\tag{4.1}
\]

all strictly positive on the interval considered. Put

\[
L(x)=\log\frac{p_{10}p_{01}}{p_{00}p_{11}}\ge0.
\tag{4.2}
\]

For `s>0`, the determinantal identity

\[
p_{10}p_{01}-p_{00}p_{11}=s
\]

makes `L(x)>0`.

Define three log-odds

\[
A(x)=\log\frac{p_{00}}{p_{01}},\qquad
B(x)=\log\frac{p_{10}}{p_{11}},\qquad
E(x)=\log\frac{p_{10}}{p_{01}}.
\tag{4.3}
\]

Direct differentiation gives

\[
\boxed{
A'(x)=-\frac{s}{p_{00}p_{01}}\le0,\qquad
B'(x)=-\frac{s}{p_{10}p_{11}}\le0,
}
\tag{4.4}
\]

while

\[
\boxed{
E'(x)=\frac{1-y}{p_{10}}+\frac{y}{p_{01}}>0.
}
\tag{4.5}
\]

This is B13: `A` and `B` can only decrease, while `E` can only increase.

The exact two-site entropy gradient can be written

\[
H_y=(1-x)A+xB,\qquad
H_x=(1-y)A+yB-E,
\tag{4.6}
\]

and the off-diagonal gradient is `-Lr`. Also

\[
L=B-A.
\tag{4.7}
\]

# 6. Main new lemma: endpoint matrix domination

Let

\[
G=\nabla H_2(C(x_0))-\nabla H_2(C(x_1)).
\tag{6.1}

After the real gauge,

\[

=-(1-y)u-yv-(E_0-E_1)

Equations (5.2)-(5.3) give the lower-right entries of the endpoint comparison matrices.

## Lemma 6.1 — two endpoint matrix inequalities

For every strict physical interval `x_1<x_0`,

\[
\boxed{
G\preceq \rho L_0\,e_2e_2^\ast,
\qquad
G\preceq \rho L_1\,e_2e_2^\ast.
}
\tag{6.4}
\]

Hence

\[
\boxed{
G\preceq \rho\min\{L_0,L_1\}\,e_2e_2^\ast.
}
\tag{6.5}
\]

### Proof

Consider

\[
M_0=\rho L_0e_2e_2^\ast-G.
\]

Its lower-right entry is, by (5.2),

\[
(M_0)_{22}=(1-x_1)u+x_1v\ge0,
\tag{6.6}
\]

its upper-left entry satisfies

\[
(M_0)_{11}=-G_{11}\ge(1-y)u+yv,
\tag{6.7}
\]

and

\[
|(M_0)_{12}|^2=s(u-v)^2.
\]

Therefore

\[
\det M_0
\ge
[(1-y)u+yv][(1-x_1)u+x_1v]-s(u-v)^2.
\tag{6.8}
\]

The right side has the exact atom decomposition

\[
\boxed{
p_{00}(x_1)u^2+
[p_{10}(x_1)+p_{01}(x_1)]uv+
p_{11}(x_1)v^2.
}
\tag{6.9}
\]

Every coefficient is positive. Thus `M_0` is positive semidefinite (indeed positive definite for `s>0`, `x_0>x_1`).

For

\[
M_1=\rho L_1e_2e_2^\ast-G,
\]

the same argument uses (5.3) and produces

\[
\det M_1
\ge
p_{00}(x_0)u^2+
[p_{10}(x_0)+p_{01}(x_0)]uv+
p_{11}(x_0)v^2\ge0.
\]

Hence both endpoint matrix inequalities hold. If `s=0`, then `A,B,L` are constant in `x`, while `E` increases, so directly `G=diag(G_{11},0)\preceq0`; (6.4)-(6.5) persist. `\square`

The statement is phase-covariant: for complex `r`, a diagonal site phase makes `r` real, leaves the ordered `e_1e_1^*` displacement unchanged, and conjugates the matrix inequality back.
