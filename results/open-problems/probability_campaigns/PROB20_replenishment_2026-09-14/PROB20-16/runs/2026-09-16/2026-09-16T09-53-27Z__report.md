## 2. New exact theorem: extreme-event derivative kills the adverse frozen mode on the zero-diagonal subspace

The first result is analytic and universal on three sites.

### Theorem 2.1

Let \(A=A^*\) have zero diagonal.

1. If \(\tau>0\) and
   \[
   D\det K[A]=0,
   \tag{2.1}
   \]
   then
   \[
   \boxed{
   F_K(A)
   =2\sum_{i=1}^3 c_i|A_{jk}|^2
    +\tau\,p_{123}\,
      \|K^{-1/2}AK^{-1/2}\|_F^2\ge0.
   }
   \tag{2.2}
   \]
   It is strict for \(A\ne0\).

2. If \(\tau<0\) and
   \[
   D\det(I-K)[A]=0
   \tag{2.3}
   \]
   (equivalently, the empty-atom first derivative vanishes), then
   \[
   \boxed{
   F_K(A)
   =2\sum_{i=1}^3 (c_i+\tau)|A_{jk}|^2
    +(-\tau)\,p_\varnothing\,
      \|(I-K)^{-1/2}A(I-K)^{-1/2}\|_F^2\ge0.
   }
   \tag{2.4}
   \]
   Again it is strict for \(A\ne0\).

3. If \(\tau=0\), connectedness implies \(c_i>0\) for all three complementary pairs, and
   \[
   F_K(A)=2\sum_i c_i|A_{jk}|^2>0
   \tag{2.5}
   \]
   for every nonzero zero-diagonal \(A\).

**Proof.** For zero-diagonal \(A\), \((\operatorname{adj}A)_{ii}=-|A_{jk}|^2\). If \(\tau>0\), substitute \(M=\operatorname{diag}(c)+\tau K\) into the definition of \(F_K\):
\[
 F_K(A)=2\sum_i c_i|A_{jk}|^2-\tau D^2\det K[A,A].
\tag{2.6}
\]
Write \(B=K^{-1/2}AK^{-1/2}\). The determinant derivative formulas are
\[
 D\det K[A]=p_{123}\operatorname{tr}B,
\]
\[
 D^2\det K[A,A]
 =p_{123}\left((\operatorname{tr}B)^2-\operatorname{tr}(B^2)\right).
\tag{2.7}
\]
Under (2.1), \(\operatorname{tr}B=0\), hence
\[
 D^2\det K[A,A]
 =-p_{123}\|B\|_F^2.
\]
Equations (2.6), (1.2), and \(\tau>0\) prove (2.2).

For \(\tau<0\), use the equivalent positive representation
\[
 M=\operatorname{diag}(c_i+\tau)+(-\tau)(I-K)
\]
and apply exactly the same determinant calculation to \(I-K\). The two signs from the affine direction \(-A\) disappear in the second derivative. This proves (2.4). The \(\tau=0\) claim is the connected case of the strictness statement already used in C077. \(\square\)

This theorem is stronger than merely saying the full entropy Hessian is favorable on these subspaces: the **frozen Lorentz term itself** becomes positive there before any Fisher payment is used.

## 4. Exact generic five-by-five Lorentz reduction

Assume first that the five covectors in (3.3) are linearly independent. (Degenerate feature-rank strata can be treated by deleting redundant covectors or by a continuous/pseudoinverse limit.) Define
\[
 G_\alpha=M^{1/2}H_\alpha M^{1/2}.
\]
On Hermitian matrices define
\[
 \mathcal J(B)=B-(\operatorname{tr}B)I,
\qquad
 \mathcal J^{-1}(Y)=Y-\frac12(\operatorname{tr}Y)I.
\tag{4.1}
\]
The five-by-five Lorentz Gram matrix is
\[
 \boxed{
 (C_5)_{\alpha\beta}
 =\langle G_\alpha,\mathcal J^{-1}G_\beta\rangle_F
 =\operatorname{tr}(MH_\alpha MH_\beta)
 -\frac12\operatorname{tr}(MH_\alpha)\operatorname{tr}(MH_\beta).
 }
\tag{4.2}
\]
By (3.6) and inertia splitting, \(C_5\) is nonsingular with inertia
\[
 (4+,1-).
\tag{4.3}
\]

For a prescribed feature derivative vector \(z\), minimize the frozen form over all Hermitian \(A\) satisfying (3.4). Lagrange multipliers in the \(B\)-coordinates of (1.4) give the exact constrained minimum
\[
 \boxed{
 \min_{D\mathbb E Z[A]=z}F_K(A)
 =\delta\,z^TC_5^{-1}z.
 }
\tag{4.4}
\]
Indeed the stationary point is
\[
 B_*=\mathcal J^{-1}\left(\sum_\alpha
 (C_5^{-1}z)_\alpha G_\alpha\right),
\]
and the positive definiteness on the feature kernel makes this stationary point the global constrained minimum.

Consequently the five-feature lower certificate
\[
 Q_5(A):=\mathrm{FI}_5(A)+F_K(A)
\tag{4.5}
\]
is nonnegative for all Hermitian directions if and only if
\[
 \boxed{
 \Sigma_5^{-1}+\delta C_5^{-1}\succeq0.
 }
\tag{4.6}
\]
Because \(C_5^{-1}\) has exactly one negative eigenvalue, (4.6) is itself only a **single scalar obstruction**. Equivalently,
\[
 \boxed{
 \det(C_5+\delta\Sigma_5)\le0.
 }
\tag{4.7}
\]
To see this, congrue (4.6) by \(\Sigma_5^{1/2}\). The matrix
\(\Sigma_5^{1/2}C_5^{-1}\Sigma_5^{1/2}\) has four positive and one negative eigenvalue, so adding the identity can only fail in that one negative eigendirection. Also
\[
 \det(I+\delta C_5^{-1}\Sigma_5)
 =\frac{\det(C_5+\delta\Sigma_5)}{\det C_5},
\]
and \(\det C_5<0\).

### Scope of (4.7)

If (4.7) holds, then from (3.5)
\[
 -D^2H(K)[A,A]
 =\mathrm{FI}(A)+F_K(A)
 \ge Q_5(A)\ge0
\]
for every Hermitian \(A\). Therefore universal proof of (4.7) on strict connected three-site kernels would settle the entire three-site Hessian problem.

**This run does not prove the universal sign (4.7).** It is a new stronger sufficient scalar, not a replacement for X095's exact full-score scalar. Failure of (4.7), if found, would refute only this five-feature proof route, not Lyons's conjecture.

## 5. Exact information-theoretic form of \(\mathrm{FI}_5\)

The five-feature projection has a simple middle-six-state interpretation that removes a generic covariance inversion.

Write
\[
 u_i=p_{\{i\}},\qquad
 v_i=p_{[3]\setminus\{i\}},\qquad
 r=\sum_i(u_i+v_i)=1-p_\varnothing-p_{123}.
\tag{5.1}
\]
On the middle event \(M=\{X\ne\varnothing,123\}\), define three mutually exclusive signed indicators
\[
 T_i=
 \begin{cases}
 +1,&X=\{i\},\\
 -1,&X=[3]\setminus\{i\},\\
 0,&\text{otherwise.}
 \end{cases}
\tag{5.2}
\]
The three vectors \(2X-\mathbf1\) on the middle states are \(\pm(2e_i-\mathbf1)\), and the \(3\times3\) matrix with columns \(2e_i-\mathbf1\) is invertible. Hence, after conditioning on the category \(\varnothing/M/123\), projecting onto the occupations \(X_i\) is exactly equivalent to projecting onto the \(T_i\).

Put
\[
 h_i=\frac{u_i+v_i}{r},\qquad
 k_i=\frac{u_i-v_i}{r}.
\tag{5.3}
\]
Then
\[
 \mathbb E[T_i\mid M]=k_i,
\qquad
 \operatorname{Cov}(T\mid M)
 =\operatorname{diag}(h)-kk^T.
\tag{5.4}
\]
For atom derivatives \(q_S=Dp_S[A]\), let
\[
 q_0=q_\varnothing,\qquad q_7=q_{123},\qquad
 q_M=-(q_0+q_7),
\]
\[
 \Delta_i=q_{\{i\}}-q_{[3]\setminus\{i\}}.
\]
Differentiating (5.3) gives
\[
 \dot k_i=\frac{\Delta_i-k_iq_M}{r}.
\tag{5.5}
\]
The Fisher chain rule for the three categories and the conditional middle projection now gives the exact formula
\[
 \boxed{
 \begin{aligned}
 \mathrm{FI}_5(A)
 ={}&\frac{q_0^2}{p_\varnothing}
 +\frac{q_7^2}{p_{123}}
 +\frac{q_M^2}{r}\\
 &+r\,\dot k^T
 \bigl(\operatorname{diag}(h)-kk^T\bigr)^{-1}\dot k.
 \end{aligned}
 }
\tag{5.6}
\]
All quantities are from the original eight measured atoms.

There is an exact description of what this projection discards. If all five feature derivatives vanish, then \(q_0=q_7=0\) and the three occupation equations imply
\[
 \boxed{
 q_{\{i\}}=q_{[3]\setminus\{i\}}=:y_i,
 \qquad
 y_1+y_2+y_3=0.
 }
\tag{5.7}
\]
Thus the only **atom-score** information discarded by the five features is a two-dimensional redistribution of the three complementary singleton/doubleton pairs. The remaining two real dimensions in the four-dimensional kernel of the feature derivative map are the atom-null/gauge directions already paid exactly by C077.

This turns the unresolved generic three-site payment into a very concrete question: can the category-plus-signed-middle Fisher information in (5.6) always pay the unique Lorentz time component after the pair-index redistribution (5.7) has been minimized out?
