## 3. Model: balanced rank-one graphon / dense two-spin SBM

Let `Q_n=U_M` be the uniform law on edge signs `X_ij in {-1,+1}`, `M=binom(n,2)`. Let `sigma_1,...,sigma_n` be iid Rademachers. Conditional on `sigma`, let the edges be independent with

`E[X_ij | sigma] = theta_n sigma_i sigma_j`,   `|theta_n|<=1`.

Call the resulting mixture `P_{n,theta}`. It is invariant under all vertex permutations and has uniform one-edge marginals. It is the balanced rank-one graphon / equal-two-spin dense SBM around edge density `1/2`.

Let `T_rho`, `0<rho<1`, retain each edge sign with Fourier eigenvalue `rho` (equivalently, resample it uniformly with probability `1-rho`). Conditional on `sigma`, `T_rho P_{n,theta}` is the same model with parameter `a_n=rho theta_n`.

For an edge set `F`, write `chi_F(X)=prod_{e in F} X_e`.

## 4. Exact moment structure: Eulerian subgraphs are the hierarchy

For every simple edge set `F`,

`E_P chi_F = theta_n^{|F|} E_sigma prod_v sigma_v^{deg_F(v)}`.

Hence

**Lemma 4.1 (Eulerian moment identity).**

`E_P chi_F = theta_n^{|F|}` if every vertex of `F` has even degree, and it is `0` otherwise.

So pair correlations of distinct edges are all zero, but triangles, cycles, and more general Eulerian subgraphs carry the signal. In particular, if `C_l` is a simple cycle of length `l`,

`E_P chi_{E(C_l)} = theta_n^l`.

Under the uniform null, Walsh characters are orthonormal. Therefore, with

`A_{n,D}=Adv_{Q_n}^{<=D}(P_{n,theta},Q_n)`, 

we have exactly

`A_{n,D}^2 = sum_{1<=|F|<=D} (E_P chi_F)^2`, 

and hence for every `3<=l<=D`,

`A_{n,D}^2 >= N_l theta_n^{2l}`,

where the number of unoriented simple `l`-cycles in `K_n` is

`N_l = (n)_l/(2l)`.

## 5. Cycle pressure forces the rank-one signal to the critical scale

Define

`c_n := n theta_n^2`.

Then the cycle lower bound gives

`A_{n,D}^2 >= [c_n^l/(2l)] * [(n)_l/n^l]`.

Assume there exists an integer sequence `l_n<=D_n` such that

1. `l_n -> infinity`,
2. `l_n^2/n -> 0`, and
3. `sup_n A_{n,D_n} <= K < infinity`.

The source scale `D_n=(log n)^{1+Omega(1)}` satisfies the first two conditions by taking `l_n=D_n` (or any growing integer below it).

Since

`(n)_{l_n}/n^{l_n} = prod_{j=0}^{l_n-1}(1-j/n) = exp(-o(1))`,

we obtain

`c_n^{l_n} <= 2 l_n K^2 exp(o(1))`.

Taking `l_n`-th roots,

**Proposition 5.1 (cycle-pressure bound).**

`limsup_{n->infinity} n theta_n^2 <= 1`.

More quantitatively,

`n theta_n^2 <= exp((log(2 l_n K^2)+o(1))/l_n) = 1+o(1)`.

This is the key higher-order implication that degree-2 observability misses entirely.

## 6. Exact noisy second moment

Set `a_n=rho theta_n` and `lambda_n=a_n^2`. The likelihood ratio of one conditional component relative to `U_M` is

`L_sigma(x)=prod_{i<j} (1+a_n sigma_i sigma_j x_ij)`.

After averaging over `sigma`, `L(x)=E_sigma L_sigma(x)`. Therefore

`E_U L^2 = E_{sigma,tau} prod_{i<j} [1+lambda_n sigma_i sigma_j tau_i tau_j]`.

With `u_i=sigma_i tau_i`, the `u_i` are iid Rademachers, so

`E_U L^2 = E_u prod_{i<j}(1+lambda_n u_i u_j)`.

Let `S=sum_i u_i` and `N=binom(n,2)`. The numbers of equal-sign and opposite-sign pairs satisfy

`N_same-N_opp=(S^2-n)/2`,   `N_same+N_opp=N`.

Thus, exactly,

`prod_{i<j}(1+lambda u_i u_j)`

`= (1-lambda^2)^{N/2} * ((1+lambda)/(1-lambda))^{(S^2-n)/4}`.

Put

`beta = (1/4) log((1+lambda)/(1-lambda)) = (1/2) artanh(lambda)`.

Then

`E_U L^2 = (1-lambda^2)^{N/2} e^{-beta n} E exp(beta S^2)`.

For `G~N(0,1)`, the Gaussian linearization identity gives

`exp(beta S^2)=E_G exp(sqrt(2 beta) G S)`.

Averaging the Rademachers first,

`E exp(beta S^2)=E_G cosh(sqrt(2 beta)G)^n`.

Using `cosh x <= exp(x^2/2)`,

`E exp(beta S^2) <= E_G exp(n beta G^2) = (1-2n beta)^(-1/2)`

whenever `2n beta<1`. Since the prefactor `(1-lambda^2)^{N/2}e^{-beta n}` is at most one,

**Lemma 6.1 (subcritical overlap bound).** If

`n artanh(lambda_n)<1`,

then

`1+chi^2(T_rho P_{n,theta} || U_M) = E_U L^2`

`<= [1-n artanh(lambda_n)]^(-1/2)`.

## 7. Main theorem: bounded LDA -> no strong distinguisher after fixed noise

Because `lambda_n=rho^2 theta_n^2`, Proposition 5.1 gives

`n lambda_n = rho^2 n theta_n^2 <= rho^2(1+o(1))`.

Also `lambda_n=O(1/n)`, so

`n artanh(lambda_n)=rho^2 n theta_n^2+o(1) <= rho^2+o(1)<1`.

Therefore Lemma 6.1 yields a uniform `L^2(U_M)` bound on the entire noisy likelihood ratio.

### Theorem 7.1 (rank-one graphon cycle transfer; PROVED PARTIAL)

Fix `0<rho<1`. In the balanced rank-one graphon model above, suppose for some `D_n` there exists `l_n<=D_n` with `l_n->infinity` and `l_n^2/n->0`, and suppose

`sup_n Adv_{U_M}^{<=D_n}(P_{n,theta},U_M)<infinity`.

Then

`sup_n chi^2(T_rho P_{n,theta} || U_M)<infinity`

(after discarding finitely many initial `n`). Consequently, for every sequence of tests `0<=phi_n<=1`,

`E_{T_rho P_n} phi_n <= C_rho * sqrt(E_{U_M} phi_n)`

for a finite constant `C_rho` depending only on the eventual low-degree bound and `rho`. In particular, **no test whatsoever**—not merely no polynomial or polynomial-time test—can strongly distinguish `T_rho P_n` from `U_M`.

### Proof of the testing consequence

Let `L_n=d(T_rho P_n)/dU_M`. Uniform boundedness of `E_U L_n^2` gives, by Cauchy–Schwarz,

`E_{T_rho P_n} phi_n = E_U[L_n phi_n]`

`<= ||L_n||_2 ||phi_n||_2`

`<= C_rho sqrt(E_U phi_n)`

for `0<=phi_n<=1`. Thus any event/test with null acceptance probability tending to zero also has planted noisy acceptance tending to zero. Reversing labels uses the complement test.

## 10. Reusable overlap identities for Gaussian/tensor roles

The proof exposes two general mixture identities worth sharing.

### Boolean latent-product overlap identity

If conditional on `Z` the Rademacher coordinates are independent with means `b_i(Z)`, then after retention noise `rho`,

`1+chi^2(T_rho P || U) = E_{Z,Z'} prod_i [1+rho^2 b_i(Z)b_i(Z')]`.

The rank-one graph theorem is the special case where coordinates are graph edges and the overlap product collapses to a one-dimensional Curie–Weiss partition function.

### Gaussian mean-mixture overlap identity

If `X|Z ~ N(b(Z),I_m)` and the null is `gamma_m=N(0,I_m)`, then after OU correlation `rho`,

`1+chi^2(T_rho P || gamma_m) = E_{Z,Z'} exp(rho^2 <b(Z),b(Z')>)`.

Thus any P08/P09 estimate controlling the exponential moment of latent overlaps immediately gives an all-test consequence. This is stronger than bounding only `E||b||^2` when mixture cancellation is important.
