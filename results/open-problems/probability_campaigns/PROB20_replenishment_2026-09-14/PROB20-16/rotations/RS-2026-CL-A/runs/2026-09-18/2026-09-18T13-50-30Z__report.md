## 3. B7 TAKE THE LIMIT — a D-scale pressure function and its critical reference radius

The preceding run proved that one less-noisy reference radius controls every stronger fixed noise level. This run asks what the limiting object is.

Let

\[
L_n-1=\sum_{j\ge1}L_{n,j},\qquad
b_{n,j}=\|L_{n,j}\|_{L^2(Q_n)}^2\ge0,
\]

and suppose scalar degree noise multiplies degree `j` by `q^{j/2}`. Define

\[
\chi_n^2(q)=\sum_{j\ge1}b_{n,j}q^j,
\qquad
\Psi_n(q)=\frac1{D_n}\log\bigl(1+\chi_n^2(q)\bigr).
\tag{3.1}
\]

The natural upper D-scale pressure is

\[
\boxed{
\Psi(q):=\limsup_{n\to\infty}\Psi_n(q),\qquad 0<q<1.
}
\tag{3.2}
\]

Because every `b_{n,j}` is nonnegative, `Psi_n(q)` and `Psi(q)` are nondecreasing in `q`. In logarithmic noise coordinate `x=-log q`,

\[
p_n(x)=\frac1{D_n}\log\left(1+\sum_j b_{n,j}e^{-xj}\right)
\tag{3.3}
\]

is a decreasing convex log-sum-exp function. The pointwise `limsup` can be written as a decreasing limit of the convex functions `sup_{n>=N}p_n(x)`, so the extended-valued envelope

\[
p(x)=\limsup_n p_n(x)=\Psi(e^{-x})
\tag{3.4}
\]

is decreasing and convex wherever it is finite (and is naturally treated as an extended convex function otherwise). This gives a genuine abscissa picture rather than a collection of unrelated noise levels.

Define the **critical reference radius**

\[
\boxed{
q_c:=\sup\{q\in(0,1):\Psi(q)=0\}.
}
\tag{3.5}
\]

The zero-pressure set is downward closed. The previous single-reference theorem immediately implies:

### Proposition 3.1 (pressure-zero interval implies rigorous noised indistinguishability)

Assume `sup_n Adv_n^{<=D_n}<=A<infinity`. If `Psi(q_*)=0` for some `q_*`, then for every fixed `0<q<q_*`,

\[
\chi_n^2(q)
\le
qA^2+
\left(\frac q{q_*}\right)^{D_n+1}\chi_n^2(q_*)
=
qA^2+o(1).
\tag{3.6}
\]

Thus every fixed `q<q_c` lying below some zero-pressure reference radius has uniformly bounded full noised chi-square and hence a fixed total-variation gap from strong distinguishability. If the LDA tends to zero, total variation tends to zero.

This formulation matters because it separates the source cutoff scale `D_n` from the much larger ambient Fourier degrees. The critical boundary `q_c` is not itself claimed to be easy to compute; Sections 4–5 identify a broad class for which it collapses to zero.

### A direct root/abscissa sufficient criterion

There is also an exact coefficient-root criterion that avoids evaluating a full reference partition function. Put

\[
\Gamma_n
:=
\sup_{j>D_n:\,b_{n,j}>0} b_{n,j}^{1/j},
\qquad
\Gamma:=\limsup_n\Gamma_n.
\tag{3.7}
\]

If `q Gamma<1`, choose `eta>0` with `q(Gamma+eta)<1`. Eventually every `j>D_n` obeys

\[
b_{n,j}q^j\le [q(\Gamma+\eta)]^j,
\]

and therefore

\[
\boxed{
\sum_{j>D_n}b_{n,j}q^j
\le
\frac{[q(\Gamma+\eta)]^{D_n+1}}
{1-q(\Gamma+\eta)}
\longrightarrow0.
}
\tag{3.8}
\]

Consequently bounded LDA plus `q Gamma<1` is another completely general scalar-degree sufficient condition for no strong distinction at retention `q`. This root test is mathematically elementary and is not claimed novel; its value here is that it makes the “point at infinity” obstruction explicit. It is still spectral rather than model-local, so it does not by itself close the source question.

**Outcome B7:** success. The previous one-reference theorem organizes into a genuine D-scale pressure/abscissa, and the coefficient root gives a sharp-looking one-sided radius condition. ## 4. B21 ASK WHO ELSE HAS THIS SHAPE — MacWilliams plus orbit collisions gives a universal code obstruction

The previous run expressed Mao-like symmetrized linear-code families through orbit-collision coefficients. Here the coding-theory language yields a much stronger quantitative theorem than the previous generic lower bound.

Let `C <= F_2^E` be a binary linear code of dimension `k`, and let `U_E` denote the uniform law on `F_2^E`. The uniform law `P_C` on `C` has likelihood ratio

\[
L_C(x)=\frac{dP_C}{dU_E}(x)
=\sum_{y\in C^\perp}\chi_y(x).
\tag{4.1}
\]

Let `G` be any finite group acting by coordinate permutations. Let `\Pi_G` denote averaging over this action, and let `P_{C,G}` be the corresponding mixture of the permuted code laws. For every `G`-orbit `O` in `F_2^E`, define

\[
N_O:=|C^\perp\cap O|.
\tag{4.2}
\]

Coordinate permutations preserve Hamming weight. Group averaging makes the Fourier coefficient constant on each orbit, equal to `N_O/|O|`. Hence after degree-diagonal product noise with retention `q`, the exact second moment is

\[
\boxed{
S_G(q)
:=1+\chi^2(T_{\sqrt q}P_{C,G}\|U_E)
=\sum_O q^{\mathrm{wt}(O)}\frac{N_O^2}{|O|}.
}
\tag{4.3}
\]

This is the orbit-collision formula preserved from the previous run.

Now define the ordinary dual weight enumerator

\[
W_{C^\perp}(q)=\sum_{y\in C^\perp}q^{\mathrm{wt}(y)}
=\sum_O N_O q^{\mathrm{wt}(O)}.
\tag{4.4}
\]

Weighted Cauchy–Schwarz gives

\[
\begin{aligned}
W_{C^\perp}(q)^2
&=
\left(
\sum_O
\frac{N_O}{\sqrt{|O|}}q^{\mathrm{wt}(O)/2}
\;\sqrt{|O|}q^{\mathrm{wt}(O)/2}
\right)^2\\
&\le
\left(
\sum_O q^{\mathrm{wt}(O)}\frac{N_O^2}{|O|}
\right)
\left(
\sum_O |O|q^{\mathrm{wt}(O)}
\right).
\end{aligned}
\tag{4.5}
\]

The `G`-orbits partition the whole Boolean cube, so

\[
\sum_O |O|q^{\mathrm{wt}(O)}=(1+q)^E.
\tag{4.6}
\]

Combining `(4.3)`–`(4.6)` yields the first bound:

\[
\boxed{
S_G(q)
\ge
\frac{W_{C^\perp}(q)^2}{(1+q)^E}.
}
\tag{4.7}
\]

Now invoke the classical univariate MacWilliams identity,

\[
W_{C^\perp}(q)
=
2^{-k}(1+q)^E
W_C\!\left(\frac{1-q}{1+q}\right).
\tag{4.8}
\]

For `0<=q<=1`, the argument `(1-q)/(1+q)` lies in `[0,1]`; the zero codeword alone gives

\[
W_C\!\left(\frac{1-q}{1+q}\right)\ge1.
\tag{4.9}
\]

Therefore:

### Theorem 4.1 (MacWilliams–orbit-collision lower bound)

For every binary linear code `C<=F_2^E` of dimension `k`, every finite coordinate-permutation group `G`, and every `0<=q<=1`,

\[
\boxed{
1+\chi^2(T_{\sqrt q}P_{C,G}\|U_E)
\ge
4^{-k}(1+q)^E.
}
\tag{4.10}
\]

No transitivity assumption is required. In particular, the same lower bound holds after full symmetry or after any subgroup symmetry breaking.

#### Interpretation

The inequality says that a low-dimensional linear support cannot be hidden from the second moment by coordinate symmetrization once the ambient number of Boolean coordinates is much larger than the code dimension. Symmetrization can distribute each dual Fourier coefficient over a large orbit, but the total collision loss is bounded below by the MacWilliams transform of the code itself.

This is stronger than trying to estimate the detailed Reed–Muller weight distribution. Kaufman–Lovett–Porat and the large classical coding literature remain relevant prior art for detailed enumerators, but the lower bound `(4.10)` only needs the MacWilliams identity, positivity, and Cauchy–Schwarz. Those ingredients are classical; the exact low-degree/noisy-inference synthesis is novelty **UNVERIFIED**.

### Corollary 4.2 (code-rate obstruction and a critical-radius upper bound)

Consider code families with ambient coordinate counts `E_n`, code dimensions `k_n`, source cutoffs `D_n`, and `E_n/D_n -> infinity`. If

\[
\frac{k_n}{E_n}\to R,
\tag{4.11}
\]

then for every fixed `q` satisfying

\[
\log(1+q)>2R\log2,
\tag{4.12}
\]

we have

\[
\frac1{D_n}\log\left(1+\chi_n^2(q)\right)
\ge
\frac{E_n}{D_n}
\left[
\log(1+q)-2\frac{k_n}{E_n}\log2
\right]
\longrightarrow+\infty.
\tag{4.13}
\]

Thus the D-scale critical radius obeys the one-sided bound

\[
q_c\le \min\{1,4^R-1\}
\tag{4.14}
\]

whenever the right side is informative. In the especially important low-rate regime `R=0`,

\[
\boxed{q_c=0.}
\tag{4.15}
\]

**Outcome B21:** success plus prior-art narrowing. Classical MacWilliams theory gives a surprisingly strong group-independent obstruction; detailed Reed–Muller weight-enumerator estimates are not needed for the coarse D-scale pressure conclusion.

## 5. B29 ADD THE POINTS AT INFINITY — Mao's pressure is carried at degree scale far beyond D

The previous run showed only that Mao must have a positive D-scale pressure exponent at every less-noisy reference radius. Theorem 4.1 upgrades this dramatically.

### 5.1 Mao before relabeling is exactly a low-dimensional linear-support law

Mao fixes evaluation vectors `v_1,...,v_n in F_2^K` and samples a uniform alternating bilinear form `B` on `F_2^K`. Before the final random vertex relabeling, the edge vector is

\[
X^{(0)}(B)
=
\bigl(B(v_i,v_j)\bigr)_{1\le i<j\le n}
\in F_2^{E_n},
\qquad
E_n=\binom n2.
\tag{5.1}
\]

The map

\[
T_n:\operatorname{Alt}(K)\to F_2^{E_n},
\qquad B\mapsto X^{(0)}(B)
\tag{5.2}
\]

is linear. Uniform input under a linear map pushes forward to the uniform law on its image

\[
C_n:=\operatorname{im}T_n.
\tag{5.3}
\]

Therefore the unsymmetrized planted law is exactly `P_{C_n}`. Its dimension satisfies

\[
k_n:=\dim C_n
\le
\dim\operatorname{Alt}(K)
=\binom K2.
\tag{5.4}
\]

Mao has

\[
K=\Theta((\log n)^r),
\qquad
D_n=\Theta((\log n)^{r-1}),
\tag{5.5}
\]

so

\[
k_n=O((\log n)^{2r}),
\qquad
E_n=\Theta(n^2),
\qquad
\frac{k_n}{E_n}\to0,
\qquad
\frac{E_n}{D_n}\to\infty.
\tag{5.6}
\]

The final random vertex relabeling is exactly averaging over the vertex-permutation group acting on edge coordinates. Thus Theorem 4.1 applies directly to Mao's actual permutation-invariant law.

### 5.2 Mao's D-scale pressure diverges at every positive reference radius

For every fixed `q>0`, `(4.10)` and `(5.6)` give

\[
\begin{aligned}
\log\bigl(1+\chi_n^2(q)\bigr)
&\ge
E_n\log(1+q)-2k_n\log2\\
&=
(1+o(1))E_n\log(1+q).
\end{aligned}
\tag{5.7}
\]

Consequently

\[
\boxed{
\frac1{D_n}\log\bigl(1+\chi_n^2(q)\bigr)
\longrightarrow+\infty
\qquad\text{for every fixed }q>0.
}
\tag{5.8}
\]

Equivalently, in the pressure notation of Section 3,

\[
\boxed{
\Psi(q)=+\infty\quad(q>0),
\qquad
q_c=0.
}
\tag{5.9}
\]

This is far stronger than the preceding generic consequence

\[
\liminf D_n^{-1}\log(1+\chi_n^2(q_*))
\ge\log(q_*/q)>0.
\]

Mao's family does not merely cross the reference-pressure boundary: it lies infinitely far beyond it on the source `D_n` scale.

### 5.3 Why “add the point at infinity” is the correct interpretation

If one studies a large-deviation profile only at degrees

\[
j\sim sD_n
\]

for finite `s`, then Mao's actual obstruction can be missed. Here the ambient degree scale is

\[
E_n/D_n\to\infty.
\]

The MacWilliams lower bound forces an exponentially enormous noised second moment from Fourier mass living at degrees comparable to the ambient edge count, not from a delicate band just above `D_n`. On the normalized variable `s=j/D_n`, the relevant contribution is naturally a **point at `s=+infinity`**.

This separates two failure modes that had been conflated earlier on this track:

1. **Degree reassembly under nonproduct noise:** high source degree can leak down through generator commutators/path transitions.
2. **Mao's product-noise failure:** there is no degree reassembly at all; product noise is degree diagonal. Instead, a low-dimensional hidden linear support creates overwhelming high-degree dual-code collision pressure, concentrated on a degree scale vastly larger than the source cutoff.

The second mechanism is the one quantified by `(5.8)`.

### 5.4 Important caution: huge chi-square is not itself a strong-testing theorem

Equation `(5.8)` does **not** imply by itself that total variation tends to one. Large or even divergent chi-square can be driven by rare likelihood-ratio spikes. Mao independently proves a deterministic polynomial-time rank test that strongly distinguishes after fixed resampling. The role of `(5.8)` is structural: it identifies exactly why every subexponential reference-pressure condition necessarily excludes Mao.

**Outcome B29:** success. The critical boundary is `q_c=0` for Mao, and the “point at infinity” in normalized degree is essential. This is a sharper obstruction than any finite-degree-band reassembly analysis.
