# 3. B26 — HUNT THE SPORADIC CASE

The previous code analysis showed that low-rate hidden linear support forces `q_c=0`. The open question was whether **positive-rate** code families can simultaneously have source-superlog dual distance and a **positive** critical radius. They can, and for the natural random-code ensemble the threshold is explicit and matches the earlier universal MacWilliams lower bound.

## 3.1 Exact second moment for a symmetrized random linear code

Let `E` be the coordinate count. Let `C_E <= F_2^E` be uniformly random among `k_E`-dimensional binary linear codes, and write

\[
R_E=\frac{k_E}{E}\to R\in(0,1).
\]

Then `U_E=C_E^\perp` is a uniformly random `(E-k_E)`-dimensional subspace. Let

\[
A_j=|\{y\in U_E:\operatorname{wt}(y)=j\}|,
\qquad
N_j={E\choose j}.
\]

Average the uniform planted law on `C_E` over the **full coordinate-permutation group** `S_E`. All vectors of weight `j` form one orbit, so the exact Fourier energy after symmetrization is

\[
b_j=\frac{A_j^2}{N_j},
\tag{3.1}
\]

and therefore

\[
S_E(q):=1+\chi^2(T_{\sqrt q}P_{C_E,S_E}\|U_{\{0,1\}^E})
=1+\sum_{j=1}^E q^j\frac{A_j^2}{N_j}.
\tag{3.2}
\]

For any fixed nonzero vector `y`, the exact inclusion probability in a uniformly random `(E-k_E)`-subspace is

\[
p_1(E)=\Pr(y\in U_E)
=\frac{2^{E-k_E}-1}{2^E-1}.
\tag{3.3}
\]

For two distinct nonzero binary vectors `y,z`, the pair is automatically linearly independent, hence

\[
p_2(E)=\Pr(y,z\in U_E)
=\frac{(2^{E-k_E}-1)(2^{E-k_E}-2)}{(2^E-1)(2^E-2)}.
\tag{3.4}
\]

Consequently, for every `j>=1`,

\[
\mathbb E A_j^2
=N_jp_1(E)+N_j(N_j-1)p_2(E).
\tag{3.5}
\]

Dividing by `N_j` and summing gives an **exact finite-E formula**:

\[
\boxed{
\mathbb E\,[S_E(q)-1]
=(p_1-p_2)\,\frac{q(1-q^E)}{1-q}
+p_2\bigl((1+q)^E-1\bigr).
}
\tag{3.6}
\]

No asymptotic weight-enumerator theorem is needed for (3.6).

### Proof of (3.5)-(3.6)

Write

\[
A_j=\sum_{y:\,\operatorname{wt}(y)=j}\mathbf 1_{\{y\in U_E\}}.
\]

Squaring and taking expectation separates the diagonal pairs `y=z`, each with probability `p_1`, from the `N_j(N_j-1)` ordered distinct pairs, each with probability `p_2`. This proves (3.5). Then

\[
\sum_{j=1}^E q^j\frac{\mathbb E A_j^2}{N_j}
=p_1\sum_{j=1}^E q^j
+p_2\sum_{j=1}^E(N_j-1)q^j,
\]

and

\[
\sum_{j=1}^E N_jq^j=(1+q)^E-1,
\]

which yields (3.6). `QED`

## 3.2 The positive-rate critical threshold

As `E->infinity`,

\[
p_1(E)=2^{-k_E+o(E)},
\qquad
p_2(E)=4^{-k_E+o(E)}.
\tag{3.7}
\]

Thus the first term in (3.6) always decays exponentially when `R>0`, while the second has exponential rate

\[
\log(1+q)-2R\log 2.
\tag{3.8}
\]

Define

\[
q_R:=4^R-1.
\tag{3.9}
\]

For every fixed `q<min(1,q_R)`, (3.6) gives

\[
\mathbb E\,[S_E(q)-1]\le e^{-c(q,R)E}
\tag{3.10}
\]

for some `c(q,R)>0` and all large `E`.

The opposite direction was already available from the universal MacWilliams/Cauchy lower bound valid for **every** code:

\[
S_E(q)\ge 4^{-k_E}(1+q)^E.
\tag{3.11}
\]

Therefore if `q>q_R`,

\[
\log S_E(q)
\ge E\,[\log(1+q)-2R\log2]+o(E).
\tag{3.12}
\]

When the source cutoff satisfies `D_E=o(E)`, this implies infinite `D_E`-scale pressure above the threshold.

## 3.3 Source-superlog dual distance occurs simultaneously

For any prescribed source cutoff `D_E=o(E)`, in particular

\[
D_E=(\log E)^{1+\delta}\qquad(\delta>0),
\]

a union bound and (3.3) give

\[
\Pr\bigl(d(C_E^\perp)\le D_E\bigr)
\le
p_1(E)\sum_{j=1}^{D_E}{E\choose j}
=
\exp\{-R E\log2+o(E)\}.
\tag{3.13}
\]

Hence with exponentially high probability the nonconstant Fourier support starts strictly above `D_E`, so the source low-degree advantage through `D_E` is exactly zero.

## 3.4 A deterministic sequence exists with the exact critical radius

Take independent random codes across `E`. For any rational `q<min(1,q_R)`, (3.10) and Markov give an exponentially summable bound for the event `S_E(q)-1` exceeds, say, `e^{-cE/2}`. The Borel–Cantelli lemma therefore gives almost surely

\[
S_E(q)-1\to0
\]

simultaneously for all rational `q<min(1,q_R)`. Monotonicity of `S_E(q)` in `q` extends this to every real `q` below the threshold. The dual-distance failures in (3.13) are also exponentially summable, so almost surely they occur only finitely often.

Thus at least one deterministic sequence of symmetrized binary linear-code alternatives satisfies both

\[

for all large `E`, and

\[
\boxed{
q_c=\min\{1,4^R-1\}.
}
\tag{3.14}
\]

Indeed, below the right side the noised chi-square tends to zero, while above it (3.12) and `E/D_E->infinity` force `Psi(q)=+infinity`.

# 4. B12 — FIND WHAT IS CONSERVED

The code calculation suggests a more general quantity: signal survives noise when **component-overlap energy** beats **latent collision entropy**. This section isolates an exact order-2 Rényi/collision budget that is monotone under stronger reversible noise and gives a model-level upper certificate for reference pressure.

## 4.1 Latent mixture Gram representation

Let `Q` be a reference distribution, let `Z` be a finite latent index set with weights `pi_z`, and let

\[
P=\sum_{z\in Z}\pi_zP_z,
\qquad
L_z=\frac{dP_z}{dQ}.
\]

Let `T_t=e^{-tA}` be a positivity-preserving, `Q`-stationary, self-adjoint Markov semigroup on `L^2(Q)`, with `A>=0`. Put

\[
g_{z,t}=T_tL_z
\]

and define the nonnegative Gram matrix

\[
K_t(z,z')=\langle g_{z,t},g_{z',t}\rangle_Q.
\tag{4.1}
\]

Then exactly

\[
\boxed{
1+\chi^2(T_tP\|Q)=\pi^TK_t\pi.
}
\tag{4.2}
\]

Define the order-2 Rényi entropy of the latent prior

\[
H_2(\pi)=-\log\sum_z\pi_z^2.
\tag{4.3}
\]

Since `K_t` is positive semidefinite,

\[
\pi^TK_t\pi
\le
\lambda_{\max}(K_t)\|\pi\|_2^2
=
\exp\{\log\lambda_{\max}(K_t)-H_2(\pi)\}.
\tag{4.4}
\]

This motivates the **latent collision budget**

\[
\boxed{
\mathcal B_t:=\log\lambda_{\max}(K_t)-H_2(\pi).
}
\tag{4.5}
\]

Equation (4.4) gives

\[
\log\bigl(1+\chi^2(T_tP\|Q)\bigr)\le\mathcal B_t.
\tag{4.6}
\]

## 4.2 Why this budget is the right monotone

Let `F` map a latent coefficient vector `a` to `sum_z a_zL_z`. Then

\[
K_t=F^*e^{-2tA}F.
\tag{4.7}
\]

Because `A>=0`, functional calculus gives

\[
t_2\ge t_1
\quad\Longrightarrow\quad
0\preceq e^{-2t_2A}\preceq e^{-2t_1A},
\]

hence

\[
K_{t_2}\preceq K_{t_1},
\qquad
\lambda_{\max}(K_{t_2})\le\lambda_{\max}(K_{t_1}).
\tag{4.8}
\]

So for a fixed latent prior, `mathcal B_t` is nonincreasing under stronger reversible noise.

There is also a symmetry/entropy direction. If a finite group permutes the latent indices equivariantly and the component Gram matrix is correspondingly permutation invariant, replacing `pi` by any group-average of `pi` is a doubly-stochastic averaging operation. Its `l_2` norm cannot increase, so `H_2(pi)` cannot decrease, while the spectral radius of the equivariant Gram matrix is unchanged. Therefore the **upper budget** (4.5) cannot increase under this latent symmetrization. This is an upper-bound statement; it does not assert that every arbitrary observation-space symmetrization is exactly represented by latent-weight averaging.

## 4.3 Schur/Collatz model-level certificate

Because `K_t` is entrywise nonnegative, for every strictly positive weight vector `w`, the weighted Schur/Collatz bound gives

\[
\lambda_{\max}(K_t)
\le
\max_z
\frac{\sum_{z'}K_t(z,z')w_{z'}}{w_z}.
\tag{4.9}
\]

For irreducible `K_t`, optimizing over `w` recovers the Perron root by the classical Collatz–Wielandt formula.

Thus a checkable sufficient condition at one reference noise time `t_*` is

\[
\boxed{
\log\left[
\max_z\frac{\sum_{z'}K_{t_*}(z,z')w_{z'}}{w_z}
\right]
-H_2(\pi)
=o(D_n).
}
\tag{4.10}
\]

Then

\[
\Psi(q_*)=0
\]

for the retention corresponding to `t_*`. Combined with bounded source LDA and the already-proved one-reference theorem, every stronger fixed noise level has bounded full noisy chi-square; with vanishing LDA, TV tends to zero.

For a uniform latent prior on `M` states and the unweighted choice `w=1`, (4.10) reduces to

\[
1+\chi^2(T_{t_*}P\|Q)
\le
\frac1M\max_z\sum_{z'}K_{t_*}(z,z').
\tag{4.11}
\]

If the latent action is transitive so every row sum is equal, (4.11) is exact: the all-ones vector is the Perron eigenvector. This recovers a clean “**latent entropy beats overlap energy**” principle.

### Interpretation

- In uniformly planted embedding models, `log M` is embedding entropy and the row sum is an overlap partition function. Chen–Li-type interface decompositions are naturally read as proving that the overlap energy does not overcome the latent entropy after fixed noise.
- In Mao-like low-rate code mixtures, the overlap spectral radius overwhelms the symmetrization entropy at every fixed positive retention, giving `q_c=0`.
- A one-component representation makes the certificate vacuous, so this is **not** a necessary-and-sufficient general characterization. It is a broad structural sufficient class and remains **PARTIAL** relative to the source.

# 5. B11 — DUALIZE

The collision-budget theorem is finite-latent and spectral. To connect it to **nonproduct reversible models** without diagonalizing the likelihood ratio, dualize the noisy Gram operator through the Dirichlet form.

## 5.1 Centered synthesis operator

Keep the latent mixture above and define centered component likelihoods

\[
u_z=L_z-1.
\]

Let

\[
F:\ell_2(Z)\to L_0^2(Q),
\qquad
Fa=\sum_z a_z u_z.
\tag{5.1}
\]

For the reversible semigroup `T_t=e^{-tA}`,

\[
\chi^2(T_tP\|Q)
=\left\|e^{-tA}F\pi\right\|_2^2
=\pi^TF^*e^{-2tA}F\pi.
\tag{5.2}
\]

The scalar inequality

\[
e^{-2tx}\le\frac{1}{1+2tx}
\qquad(x\ge0)
\tag{5.3}
\]

lifts by functional calculus to

\[
e^{-2tA}\preceq(I+2tA)^{-1}.
\tag{5.4}
\]

## 5.2 Dirichlet-frame constant

Write the Dirichlet form

\[
\mathcal E(h,h)=\langle h,Ah\rangle_Q.
\]

Define

\[
\boxed{
\mathfrak B_t(F)
:=
\sup_{h\ne0}
\frac{\sum_z\langle u_z,h\rangle_Q^2}
{\|h\|_2^2+2t\mathcal E(h,h)}.
}
\tag{5.5}
\]

This has the exact operator identities

\[
\mathfrak B_t(F)
=
\|(I+2tA)^{-1/2}F\|_{2\to2}^2
=
\lambda_{\max}\bigl(F^*(I+2tA)^{-1}F\bigr).
\tag{5.6}
\]

Combining (5.2), (5.4), and `||pi||_2^2=e^{-H_2(pi)}` gives

\[
\boxed{
\chi^2(T_tP\|Q)
\le
\exp\{-H_2(\pi)\}\,\mathfrak B_t(F).
}
\tag{5.7}
\]

Therefore the following **pure Dirichlet-frame inequality** is a model-level reference-pressure certificate:

\[
\sum_z\langle u_z,h\rangle_Q^2
\le
B_n\,[\|h\|_2^2+2t_*\mathcal E(h,h)]
\quad\text{for all }h.
\tag{5.8}
\]

If

\[
\log^+\bigl(1+B_ne^{-H_2(\pi_n)}\bigr)=o(D_n),
\tag{5.9}
\]

then `Psi(q_*)=0` at the reference noise time `t_*`. Bounded source LDA plus the one-reference theorem again gives the source-valid noisy indistinguishability conclusion at every stronger fixed noise level.

## 5.3 Exact variational dual form

Let `M_t=I+2tA`. For every `a` with `||a||_2=1`,

\[
\langle Fa,M_t^{-1}Fa\rangle
=
\sup_h\{2\langle Fa,h\rangle-\langle h,M_th\rangle\}.
\]

Hence

\[
\boxed{
\mathfrak B_t(F)
=
\sup_{\|a\|_2=1}\sup_h
\left\{
2\langle Fa,h\rangle_Q
-\|h\|_2^2
-2t\mathcal E(h,h)
\right\}.
}
\tag{5.10}
\]

This is the desired dual certificate: instead of enumerating the likelihood-ratio spectrum, one may upper-bound a frame of planted-component correlations against a **local Dirichlet energy**.

### Why this is useful for the source target
