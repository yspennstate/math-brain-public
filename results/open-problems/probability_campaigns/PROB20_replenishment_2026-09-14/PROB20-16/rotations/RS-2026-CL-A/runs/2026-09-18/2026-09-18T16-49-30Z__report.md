# 3. B10 — DERANDOMIZE

## 3.1 Deterministic dual-distance lower bound on the critical radius

Let `C <= F_2^E` be a binary linear code of dimension `k`. Put `U=C^perp`,

`A_j = |{u in U : wt(u)=j}|`, `N_j=binom(E,j)`,

and average the uniform law on `C` over the full coordinate-permutation group. The exact degree-`j` symmetrized Fourier energy is

`b_j=A_j^2/N_j`.

Let `d^perp=d(U)` be the minimum nonzero dual weight. Then for every `q in (0,1)`,

\[
\chi^2(T_{\sqrt q}P_{C,S_E}\|U_E)
 = \sum_{j\ge d^\perp} q^j\frac{A_j^2}{N_j}
 \le 2^{E-k}q^{d^\perp}.
\tag{3.1}
\]

**Proof.** Since `A_j<=N_j`, `A_j^2/N_j<=A_j`. For `j>=d^perp`, `q^j<=q^{d^perp}`. Therefore

`sum_{j>=dperp} q^j A_j^2/N_j <= q^{dperp} sum_j A_j <= q^{dperp} 2^{E-k}`. `QED`

## 3.2 Explicit asymptotically good codes give explicit positive-radius examples

`dim(U_E)/E -> r>0`, `d(U_E)/E -> delta>0`.

Let `C_E=U_E^perp`, so `R=dim(C_E)/E -> 1-r`. Then `C_E^perp=U_E` has linear minimum distance. For every source cutoff `D_E=o(E)`, including `D_E=(log E)^{1+eta}`, eventually `D_E<d(U_E)`, so the source LDA through `D_E` is exactly zero.

By (3.1),

\chi_E^2(q)
\le \exp\{E[(1-R)\log 2+\delta\log q+o(1)]\}.
\tag{3.2}
\]

## 4.1 Uniform transitive latent action collapses the Perron problem to double cosets

Let a finite group `G` act on the observation space preserving `Q` and commuting with a reversible noise semigroup `T_t`. Let the latent space be the transitive homogeneous space `Z=G/H`, with uniform prior. Choose an `H`-invariant base likelihood `L_0`, and set `L_{gH}=U_gL_0`.

Define

`K_t(z,z')=<T_tL_z,T_tL_{z'}>_Q`.

Equivariance gives

\[
K_t(gH,g'H)=\langle T_tL_0,U_{g^{-1}g'}T_tL_0\rangle_Q,
\tag{4.1}
\]

which depends only on the double coset `Hg^{-1}g'H`. Every row therefore has the same sum. Because `K_t` is symmetric and entrywise nonnegative, the all-ones vector is a Perron eigenvector and its common row sum is `lambda_max(K_t)`.

Let `D` run over `H\G/H`, choose a representative `g_D`, let `m_D=|D|/|H|` be the number of right cosets in `D`, set `M=|G/H|`, and define

`kappa_D(t)=<T_tL_0,U_{g_D}T_tL_0>_Q`.

Then exactly

\[
\boxed{
1+\chi^2(T_tP\|Q)
=\frac1M\sum_{D\in H\backslash G/H}m_D\,\kappa_D(t).
}
\tag{4.2}
\]

**Proof.** Uniform mixing gives `1+chi2=M^{-2} 1^T K_t 1`. Equal row sums reduce this to `row_sum/M`; decomposing the base row by double cosets gives (4.2). `QED`

## 5.1 Exact Perron-alignment correction

For any PSD Gram matrix `K` and prior vector `pi`, define

\[
\alpha(K,\pi)
:=\frac{\pi^TK\pi}{\lambda_{\max}(K)\|\pi\|_2^2}\in[0,1].
\tag{5.1}
\]

Then exactly

\[
\boxed{
\log(1+\chi^2)
=\log\lambda_{\max}(K)-H_2(\pi)+\log\alpha(K,\pi).
}
\tag{5.2}
\]

If `u=pi/||pi||_2` and `(lambda_i,v_i)` are the spectral data of `K`, then

`alpha=sum_i (lambda_i/lambda_1)|<u,v_i>|^2 >= |<u,v_1>|^2`.

For a uniform transitive model, the all-ones vector is Perron, so `alpha=1` and the spectral collision budget is exact.

## 5.2 Realizable high-entropy family with localized Perron mode

Let there be `M` latent states with uniform prior. Let `Q_M` be a Bernoulli law on a two-point space with rare event `A` of probability `epsilon_M=M^{-2}`. Define

`P_1=Q_M(.|A)`, and `P_2=...=P_M=Q_M`.

Then `L_1=1_A/epsilon_M` and `L_z=1` for `z>=2`. Under the one-coordinate heat-bath semigroup with retention `rho=e^{-t}`,

`T_tL_1=1+rho(L_1-1)`, while `T_tL_z=1` for `z>=2`.

The Gram matrix obeys

`K_t(1,1)=1+rho^2(M^2-1)`, and `K_t(i,j)=1` for all other pairs.

The actual noised mixture likelihood is

`L_mix,t=1+(rho/M)(L_1-1)`, so exactly

\[
\boxed{
1+\chi^2(T_tP\|Q_M)
=1+\frac{\rho^2}{M^2}(M^2-1)
\longrightarrow 1+\rho^2.
}
\tag{5.3}
\]

However `lambda_max(K_t)>=K_t(1,1)~rho^2M^2` and `H_2(pi)=log M`, so the previous spectral/entropy surrogate gives a factor of order at least `rho^2 M`, which diverges. Equivalently,

\[
\alpha(K_t,\pi)=\Theta(M^{-1}).
\tag{5.4}
\]

Thus large latent Rényi entropy is not enough, and even entropy versus Perron spectral radius can be logarithmically/exponentially loose unless the prior is aligned with a delocalized top mode.

## 5.3 What regularity is actually missing

There are three useful regimes.

1. **Transitive / association-scheme:** `alpha=1` exactly; B19 computes the pressure through double cosets.
2. **Delocalized Perron:** if `alpha>=exp(-o(D_n))`, then the spectral-entropy budget is faithful at the `D_n` scale. This is a statement about fidelity of that surrogate, not a necessary source condition.
3. **Typical overlap:** exactly
   `1+chi2=E_{Z~pi}[sum_{z'}pi_{z'}K_t(Z,z')]`.
   Rare high-overlap latent states can be harmless when their prior mass is small. A prior-typical row-load condition can therefore be strictly sharper than `lambda_max`.

The stress family isolates the precise obstruction requested by B2: the missing quantity for the Perron surrogate is **prior-to-Perron alignment / delocalization**, and the more robust route is likely a typical-overlap pressure rather than worst-row or spectral-radius control.
