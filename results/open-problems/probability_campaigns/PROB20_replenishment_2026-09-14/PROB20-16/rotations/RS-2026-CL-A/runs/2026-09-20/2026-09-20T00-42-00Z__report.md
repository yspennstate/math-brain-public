## 1. Exact outside source and later boundary

Outside source: Anastasia Kireeva, Randomstrasse 101, **“Low-degree hardness of finding the largest clique in Erdős–Rényi graph (problems 36-38)”**, posted 5 June 2026, URL `https://randomstrasse101.math.ethz.ch/posts/clique-low-degree/`.

The post title says **problems 36–38**, while the first broad displayed box is labeled **Open Problem 35**. I preserve that displayed numbering rather than silently renumbering it. The box asks:

> What are the conditions on the distributions `P_n` and `Q_n` such that if the low-degree advantage remains bounded for `D=(log n)^{1+Omega(1)}` as `n -> infinity`, it rigorously implies that no polynomials of a certain degree can distinguish between `P_n` and `Q_n`?

The source defines

`Adv_n^{<=D} = max_{deg(f)<=D} (E_{P_n} f - E_{Q_n} f)/sqrt(Var_{Q_n} f)`.

The surrounding Hopkins formulation is more specific and must not be confused with the broad first box. It takes `k in N`, `Omega` finite (or `R` in the continuous analogue), `Q_n` uniform on `Omega^{binom(n,k)}`, `P_n` invariant under the natural `S_n` relabeling, bounded LDLR through `D=(log n)^{1+Omega(1)}`, and predicts that for every fixed positive independent-noise rate there is no `n^{D/polylog n}`-time distinguisher between the noised planted law and the null.

Later boundary: Songtao Mao, **“The Polynomial-Time Low-Degree Conjecture is False,”** arXiv:2607.20318, submitted 22 July 2026. For each fixed `r>=3`, Mao constructs an `S_n`-invariant graph law `P_n` with `Q_n=G(n,1/2)` whose marginals on every edge set of size at most `D_n=Theta((log n)^(r-1))` are exactly uniform, hence source LDA is exactly zero through `D_n`, while a deterministic polynomial-time rank test strongly distinguishes after a fixed positive independent edge-resampling rate. Therefore uniform product null + permutation invariance + exact polylog moment matching + independent noise are not sufficient.

## 2. Inherited theorem and the exact missing implication

The predecessor proved a basis-free reference-chaos bridge. Let `R_n` admit an orthogonal chaos decomposition

`L^2(R_n)=oplus_{k>=0} H_{n,k}`

and a reversible Markov semigroup `T_{n,t}` with

`T_{n,t}|_{H_{n,k}} = exp(-t k) I`.

For `P_n,Q_n << R_n`, write

`p_n=dP_n/dR_n`, `q_n=dQ_n/dR_n`, `Delta_n=p_n-q_n`,

and define the one-sided low-degree norm inflation

`Lambda_n(d)=sup_{0!=f in P_{<=d}} ||f||_{L^2(Q_n)}^2 / ||f||_{L^2(R_n)}^2`.

If `Pi_{n,k}` is the reference-chaos projection and

`a_{n,k}=||Pi_{n,k} Delta_n||_{L^2(R_n)}^2`,

then the predecessor proved

`sum_{k=1}^d a_{n,k} <= Lambda_n(d) Adv_{Q_n}^{<=d}(P_n,Q_n)^2`.

Its noisy-TV theorem then controlled the spectral tail above `D_n` by

`exp(-2t D_n) ||Delta_n||_2^2`.

This imposed the global hypothesis

`log_+ ||Delta_n||_2^2 = o(D_n)`

for the every-fixed-positive-noise conclusion (or the corresponding strict exponent inequality at one noise time).

That condition is materially too strong. A likelihood ratio can have enormous unnoised `L2` mass concentrated on extremely rare configurations while every positive amount of reference noise destroys that rare spike. The missing implication is therefore:

> Can the tail above `D_n` be bounded using **interior smoothing** rather than unnoised global `L2` complexity?

The answer is yes.

## 3. New theorem: smoothed-tail reference-chaos criterion

Fix a target noise time `t>0`. Let `D_n -> infinity` and set

`A_n = Adv_{Q_n}^{<=D_n}(P_n,Q_n)`

and

`eta_n = sup_{1<=d<=D_n} log_+ Lambda_n(d)/d`.

For `s>0`, define the **interior smoothing complexity**

`Gamma_n(s)=||T_{n,s} Delta_n||_{L^2(R_n)}^2 = sum_{k>=1} exp(-2 s k) a_{n,k}`

whenever finite, and

`gamma_n(s)=log_+ Gamma_n(s)/D_n`.

### Theorem 3.1 — partial smoothing replaces global L2 complexity

Assume:

1. `sup_n A_n < infinity`;
2. for every fixed integer `K`, `Adv_{Q_n}^{<=K}(P_n,Q_n) -> 0`;
3. `limsup_n eta_n < 2t`;
4. there exists one fixed `s in (0,t)` such that `Gamma_n(s)<infinity` and

   `limsup_n gamma_n(s) < 2(t-s)`.

Then

`||T_{n,t}P_n - T_{n,t}Q_n||_TV -> 0`.

Thus no statistic of any computational complexity can strongly distinguish the two laws after the specified reference noise.

If instead `eta_n ->0` and, for every fixed `t>0`, one can choose some `s in (0,t)` with `gamma_n(s)->0`, then noisy TV tends to zero for **every fixed positive** noise time.

### Proof

Fix an integer `K`. Since the reference semigroup is chaos-diagonal,

`||T_{n,t} Delta_n||_2^2 = sum_{k>=1} exp(-2tk) a_{n,k}`.

Split the sum into `k<=K`, `K<k<=D_n`, and `k>D_n`.

**Fixed degrees.** By the inherited bridge,

`sum_{k<=K} a_{n,k} <= Lambda_n(K) Adv_{Q_n}^{<=K}(P_n,Q_n)^2`.

Condition 3 implies `Lambda_n(K)` is uniformly bounded for each fixed `K`, while condition 2 sends the fixed-degree source advantage to zero. Hence the fixed-degree contribution tends to zero.

**Intermediate degrees.** Let `A_* = sup_n A_n`. For each `k<=D_n`,

`a_{n,k} <= sum_{j<=k} a_{n,j} <= Lambda_n(k) A_*^2 <= A_*^2 exp(eta_n k)`.

Choose `delta>0` so that eventually `eta_n <= 2t-2delta`. Then

`sum_{K<k<=D_n} exp(-2tk) a_{n,k} <= A_*^2 sum_{k>K} exp(-2delta k)`.

The right side tends to zero as `K->infinity`, uniformly in all sufficiently large `n`.

**Tail above the source cutoff.** This is the new step. For any `s in (0,t)`,

`sum_{k>D_n} exp(-2tk) a_{n,k}`

`= sum_{k>D_n} exp(-2(t-s)k) exp(-2sk) a_{n,k}`

`<= exp(-2(t-s)D_n) Gamma_n(s)`.

By condition 4 this tends to zero exponentially in `D_n`.

Therefore `||T_{n,t}Delta_n||_2 ->0`. Since `R_n` is a probability law,

`TV(T_{n,t}P_n,T_{n,t}Q_n) = (1/2)||T_{n,t}Delta_n||_{L^1(R_n)} <= (1/2)||T_{n,t}Delta_n||_{L^2(R_n)} ->0`.

This proves the theorem. `square`

### Scope

This is a **PROVED PARTIAL** source-valid sufficient theorem. It does not characterize arbitrary `(P_n,Q_n)`, does not prove unnoised computational hardness, and does not rescue the unrestricted Hopkins conjecture. It materially weakens the predecessor's tail condition because it can apply when the unnoised `L2` exponent is arbitrarily larger than `D_n`.

## 4. Hypercontractive / Renyi corollary

The smoothed-tail hypothesis has a standard structural sufficient condition.

Suppose the reference semigroup is hypercontractive at time `s`:

`||T_{n,s} f||_2 <= ||f||_r`

for some fixed `r=r(s) in (1,2)`, uniformly in `n`. Then

`Gamma_n(s) <= ||Delta_n||_r^2 <= (||p_n||_r + ||q_n||_r)^2`.

For Renyi divergence of order `r`,

`D_r(P_n||R_n) = (1/(r-1)) log int p_n^r dR_n`,

so exactly

`log ||p_n||_r^2 = [2(r-1)/r] D_r(P_n||R_n)`

and likewise for `Q_n`.

### Corollary 4.1 — sublinear Renyi complexity is enough

Under assumptions 1–3 of Theorem 3.1, if for some `s in (0,t)` at which `T_s` is `L^r -> L^2` hypercontractive,

`D_r(P_n||R_n) + D_r(Q_n||R_n) = o(D_n)`,

then condition 4 of Theorem 3.1 holds with `gamma_n(s)->0`; hence

`TV(T_{n,t}P_n,T_{n,t}Q_n)->0`.

For the standard Boolean noise operator and the standard Gaussian Ornstein--Uhlenbeck semigroup,

`||T_s f||_2 <= ||f||_{1+exp(-2s)}`.

Therefore, if `eta_n->0` and

`D_r(P_n||R_n)+D_r(Q_n||R_n)=o(D_n)`

for every fixed `r in (1,2)`, then the noisy laws are asymptotically TV-indistinguishable for **every fixed `t>0`**.

For one fixed target time `t`, it suffices to take `s=t/2`, hence only the single Renyi order

`r_t = 1 + exp(-t)`

is needed.

This is a genuine assumption removal: the old theorem asked for subexponential `L2` pair complexity, while this corollary only asks for sublinear Renyi complexity at an order strictly below 2.

## 5. Decisive strictness example: rare spike defeats the old L2 hypothesis but satisfies the new theorem

Take the Boolean reference/null

`R_N=Q_N=U_N=Unif({-1,+1}^N)`.

Fix one point `x_*` and let

`epsilon_N = 2^{-N/2} exp(sqrt(N))`,

`P_N = (1-epsilon_N) U_N + epsilon_N delta_{x_*}`.

For all sufficiently large `N`, `epsilon_N in (0,1)`.

Let

`D_N=(log N)^{1+zeta}`

for any fixed `zeta>0`.

The likelihood difference is

`Delta_N = epsilon_N (2^N 1_{x_*} - 1)`.

For every nonempty Walsh character `chi_S`,

`<Delta_N,chi_S>_{U_N}=epsilon_N chi_S(x_*)`.

Hence exactly

`Adv_{U_N}^{<=D_N}(P_N,U_N)^2 = epsilon_N^2 sum_{k=1}^{D_N} binom(N,k)`.

Using `sum_{k<=D} binom(N,k) <= (eN/D)^D` for `D<=N/2`,

`log Adv^2 <= -N log 2 + 2sqrt(N) + D_N log(eN/D_N) -> -infinity`.

So the source LDA does not merely stay bounded; it tends to zero through the required polylogarithmic window. Also `Lambda_N(d)=1` identically because `Q_N=R_N`.

However the **old global L2 hypothesis fails maximally on the source scale**:

`||Delta_N||_2^2 = epsilon_N^2(2^N-1) = (1-o(1)) exp(2sqrt(N))`,

and therefore

`log ||Delta_N||_2^2 / D_N -> infinity`.

So the predecessor theorem cannot certify this family at any fixed positive noise time.

By contrast, for every fixed `r<2`,

`||Delta_N||_r^r`

`= epsilon_N^r [2^{-N}(2^N-1)^r + 1-2^{-N}]`.

The rare-point contribution has logarithm

`(r/2-1)N log 2 + r sqrt(N) + o(N)`,

which tends to `-infinity` because `r<2`; the ordinary-point term also vanishes. Hence

`||Delta_N||_r ->0`

for every fixed `r<2`. The Renyi/hypercontractive corollary therefore certifies TV-indistinguishability after every fixed positive noise time.

There is also an exact Fourier self-check. Under Boolean noise time `t`,

`||T_t Delta_N||_2^2 = epsilon_N^2[(1+exp(-2t))^N-1]`.

Its logarithm is

`-N log 2 + 2sqrt(N) + N log(1+exp(-2t)) + o(1)`

`= -N log(2/(1+exp(-2t))) + 2sqrt(N) + o(N) -> -infinity`.

So the new theorem gives the correct conclusion on a family where the old global `L2` exponent is arbitrarily bad relative to `D_N`.

No finite checker is needed: all identities in this example are exact one-line Walsh calculations.

## 6. Stronger quantitative Mao boundary from partial smoothing

The new theorem sharpens the structural diagnosis of Mao's counterexample.

In Mao's Boolean setting, `Q_n=R_n=G(n,1/2)`, so `Lambda_n(d)=1`, and exact `D_n`-wise independence gives

`Adv^{<=D_n}(P_n,Q_n)=0`.

Let `t_r>0` denote a noise time corresponding to Mao's fixed resampling rate at which strong distinction survives. Since the conclusion of Theorem 3.1 fails at `t_r`, its contrapositive gives the following necessary obstruction:

### Corollary 6.1 — Mao has positive interior smoothing complexity at every earlier time

For every fixed `s in (0,t_r)`,

`limsup_n [log_+ ||T_s(dP_n/dQ_n -1)||_2^2]/D_n >= 2(t_r-s)`.

Thus Mao's escaping signal cannot be described merely as enormous unnoised chi-square. A positive exponential amount of likelihood energy per source degree survives **every smaller positive amount of the same product noise**.

Using Boolean hypercontractivity with

`r_s = 1+exp(-2s)`,

we further obtain, along a subsequence realizing the positive exponent,

`limsup_n D_{r_s}(P_n||Q_n)/D_n >= [r_s/(r_s-1)](t_r-s)`.

Indeed hypercontractivity gives

`||T_s h_n||_2 <= ||h_n||_{r_s}`,

where `h_n=dP_n/dQ_n-1`. Exponential growth of the left side forces the same exponential scale for `||h_n||_{r_s}`; since `||dP_n/dQ_n||_{r_s} >= ||h_n||_{r_s}-1`, the displayed Renyi lower bound follows from

`log ||dP_n/dQ_n||_{r_s}^2 = [2(r_s-1)/r_s] D_{r_s}(P_n||Q_n)`.

This excludes Mao from the sufficient framework by a quantitative regularity condition rather than by naming the rank construction.

## 7. What this says about the full source question

The broad Kireeva question asks for conditions, not for a single model-specific theorem. The combined framework now has three conceptually separate conditions:

1. **source-to-reference geometry:** `Lambda_n(d)` grows slowly enough through the source degree window;
2. **fixed-degree escape:** truly bounded-degree signals vanish, which is necessary for TV convergence under fixed positive noise because fixed chaos levels are only multiplied by constants;
3. **tail regularity after arbitrarily small interior smoothing:** equivalently, in hypercontractive references, sublinear Renyi complexity at an order below 2.

The new contribution is that condition 3 no longer needs unnoised global `L2` control. This is structurally important because rare high-likelihood spikes are precisely where unnoised chi-square is brittle.

This still does **not** settle the unrestricted source problem. The largest gap is now condition 1 for natural nonproduct nulls: prove a useful `Lambda_n(d)` bound, or replace it by a source-to-noise comparison directly adapted to the null's natural Gibbs/Markov geometry. The earlier raw-monomial Gram lower bound is false and must not be revived.

## 8. Gaussian / tensor handoff

`||T_s f||_2 <= ||f||_{1+exp(-2s)}`.
