# 3. B14 — FIND THE GROUP ACTING: finite local groups and representation-support distance

## 3.1 Product finite-group setup

Let `Gamma` be a finite group and

\[
\Omega=\Gamma^N
\]

with uniform Haar probability `Q`. Let `H<=Omega` be a subgroup. Let `P` be the uniform law on `H`. Its likelihood ratio is

\[
L(x)=\frac{dP}{dQ}(x)=\frac{|\Omega|}{|H|}\mathbf 1_H(x).
\tag{3.1}
\]

The same spectral energies below hold for a coset of `H`; a coset only unitary-translates the Fourier coefficient matrices.

Every irreducible representation of `Omega` has tensor-product form

\[
\pi=\pi_1\otimes\cdots\otimes\pi_N,
\]

where each `pi_i` is an irreducible representation of `Gamma`. Define its **representation support**

\[
\operatorname{supp}(\pi)=\{i:\pi_i\not\cong\mathbf 1\},
\qquad
\operatorname{wt}(\pi)=|\operatorname{supp}(\pi)|,
\tag{3.2}
\]

and `d_pi=dim pi`.

For functions on `Omega`, use normalized Fourier transform

\[
\widehat f(\pi)=\mathbb E_Q[f(X)\pi(X)^*].
\]

## 3.2 Exact subgroup Fourier coefficient

From (3.1),

\[
\begin{aligned}
\widehat L(\pi)
&=\frac1{|\Omega|}\sum_{x\in\Omega}
\frac{|\Omega|}{|H|}\mathbf1_H(x)\pi(x)^*\\
&=\frac1{|H|}\sum_{h\in H}\pi(h)^*.
\end{aligned}
\tag{3.3}
\]

The group average in (3.3) is exactly the orthogonal projector onto the `H`-fixed subspace

\[
V_\pi^H=\{v:\pi(h)v=v\ \forall h\in H\}.
\]

Write it as `P_H^pi`. Therefore

\[
\boxed{
\widehat L(\pi)=P_H^\pi,
\qquad
\|\widehat L(\pi)\|_F^2=\dim V_\pi^H.
}
\tag{3.4}
\]

For a coset `gH`, the coefficient is a unitary factor times `P_H^pi`, so its Frobenius norm is unchanged.

Plancherel yields

\[
\mathbb E_Q L^2
=\sum_{\pi\in\widehat\Omega}d_\pi\|\widehat L(\pi)\|_F^2
=\sum_\pi d_\pi\dim V_\pi^H
=\frac{|\Omega|}{|H|}.
\tag{3.5}
\]

The final equality is also immediate from `L^2=(|Omega|/|H|)L`.

## 3.3 Representation-support enumerator

Define

\[
\boxed{
W_H^{\rm rep}(z)
:=
\sum_{\pi\in\widehat\Omega}
 d_\pi\,\dim V_\pi^H\,z^{\operatorname{wt}(\pi)}.
}
\tag{3.6}
\]

Let `h=L-1` and let `Pi_k^{rep}` project onto irreducible tensor factors of support size exactly `k`. Then (3.4) and Plancherel give the exact identity

\[
\boxed{
1+\mathcal G_h^{\rm rep}(z)
:=1+\sum_{k\ge1}\|\Pi_k^{\rm rep}h\|_2^2z^k
=W_H^{\rm rep}(z).
}
\tag{3.7}
\]

At the boundary,

\[
W_H^{\rm rep}(1)=\frac{|\Omega|}{|H|}=1+\chi^2(P\|Q).
\tag{3.8}
\]

Define the **representation-support distance**

\[
d_{\rm rep}(H)
:=
\min\{\operatorname{wt}(\pi):\pi\not\cong\mathbf1,
\ \dim V_\pi^H>0\}.
\tag{3.9}
\]

Then exactly

\[
\boxed{
\operatorname{Adv}^{\le D}_{\rm rep}(P,Q)^2
=
\sum_{\substack{\pi\ne\mathbf1\\\operatorname{wt}(\pi)\le D}}
 d_\pi\dim V_\pi^H,
}
\tag{3.10}
\]

and in particular

\[
\boxed{
\operatorname{Adv}^{\le D}_{\rm rep}(P,Q)=0
\iff d_{\rm rep}(H)>D.
}
\tag{3.11}
\]

For one-hot encoding of each finite-group coordinate, every local matrix coefficient is a degree-one coordinate function and a tensor product on `k` sites is a polynomial of site-degree `k`. Thus (3.10) is a literal low-degree polynomial statement for that standard finite-alphabet encoding; for an arbitrary numerical encoding it should be called a representation-support analogue rather than silently identified with ordinary polynomial degree.

# 5. B24 — FIND THE EXTREMAL OBJECT: sharp private-coordinate pressure and a repeated-overlap extremal direction

## 5.1 Exact extremal theorem under a private-coordinate budget

Let binary generator rows `R_1,...,R_M` be linearly independent and assume every row has at least `u` coordinates that occur in no other row. For a selected subset `A subseteq[M]`, the private coordinates of all selected rows survive the symmetric difference, so

\[
d(A):=\left|\triangle_{j\in A}R_j\right|
\ge u|A|.
\tag{5.1}
\]

For `0<=z<=1`,

\[
\begin{aligned}
W_C(z)
&=\sum_{A\subseteq[M]}z^{d(A)}\\
&\le\sum_{A\subseteq[M]}z^{u|A|}\\
&=\boxed{(1+z^u)^M}.
\end{aligned}
\tag{5.2}
\]

The bound is attained by `M` disjoint rows of size exactly `u`. Conversely, if `0<z<1` and equality holds in (5.2), then every singleton must satisfy `|R_j|=u`; since each row already has at least `u` private coordinates, every row consists entirely of private coordinates and the rows are disjoint. Thus:

### Theorem 5.1 — exact private-coordinate extremizer

Among all linearly independent binary generator families with at least `u` private coordinates per row, the maximum interior weight enumerator at any fixed `0<z<1` is exactly

\[
\boxed{(1+z^u)^M,}
\tag{5.3}
\]

uniquely up to coordinate relabeling by disjoint size-`u` rows.

This removes the preceding bounded-intersection-degree assumption and improves the earlier conservative KP estimate in the private-coordinate subclass. KP remains relevant only when one tries to replace private coordinates by a weaker cancellation profile.

An immediate source-scale corollary is also sharper. If `M_n<=n`, `u_n>=cD_n` for any fixed `c>0`, and `z=e^{-2r}<1`, then

\[
0\le\log W_C(z)
\le M_n\log(1+z^{u_n})
\le n e^{-2rcD_n}\to0.
\tag{5.4}
\]

No generator-intersection-degree condition is required.

## 5.2 Fixed row-size refinement

If each generator row has fixed size `m>=u`, singleton codewords have weight exactly `m`, while (5.1) remains valid for all selected sets of size at least two. Hence

\[
\boxed{

\le
(1+z^u)^M+M(z^m-z^u).
}
\tag{5.5}
\]

This is a simple strict refinement of (5.2) when `m>u`. It is not claimed to be the exact extremum under all simultaneous row-size/intersection constraints.

## 5.3 Repeated common overlap: exact block partition function

To test the `stars/chains/repeated-overlap` question, consider a block of `q` rows

\[
R_j=P_j\sqcup S,
\tag{5.6}
\]

where the `P_j` are pairwise disjoint private sets of size `u`, and the common shared set `S` has size `s`. Every row has size `m=u+s`. For a selected subfamily of cardinality `k`, the common set survives iff `k` is odd, so its codeword weight is

\[
uk+s\mathbf1_{k\text{ odd}}.
\tag{5.7}
\]

The exact block enumerator is therefore

\[
\begin{aligned}
B_q(z)
&=\sum_{k\text{ even}}\binom qk z^{uk}
+z^s\sum_{k\text{ odd}}\binom qk z^{uk}\\
&=\boxed{
\frac12\left[(1+z^s)(1+z^u)^q
+(1-z^s)(1-z^u)^q\right].
}
\end{aligned}
\tag{5.8}
\]

Let a positive random variable `X` take values `1+z^u` and `1-z^u` with probabilities `(1+z^s)/2` and `(1-z^s)/2`. Then

\[
B_q(z)=\mathbb E X^q.
\tag{5.9}
\]

By monotonicity of `L^p` norms,

\[
\boxed{
B_q(z)^{1/q}
\text{ is nondecreasing in }q.
}
\tag{5.10}
\]

Thus **within this repeated-common-overlap block family**, larger overlap cliques are worse per generator for the interior pressure. If generator-intersection degree is bounded by `Delta`, this family is maximized per row by the largest admissible clique size `q=Delta+1`.
