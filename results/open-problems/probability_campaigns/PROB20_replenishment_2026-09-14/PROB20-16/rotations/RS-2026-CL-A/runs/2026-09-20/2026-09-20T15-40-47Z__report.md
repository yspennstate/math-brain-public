<https://randomstrasse101.math.ethz.ch/posts/clique-low-degree/>

The post title says problems 36–38, but the broad low-degree-conditions box on the page is literally labeled **Open Problem 35**. I preserve the source's displayed numbering rather than silently renumbering it.

Immediately before that box, the page reproduces Hopkins's informal conjectural setup with the following hypotheses and quantifiers:

- fixed `k in N`;
- `Omega` is a finite set or `R`;
- `Q_n` is the uniform distribution on `Omega^{binom(n,k)}`;
- `P_n` is a distribution on `Omega^{binom(n,k)}` invariant under the natural `S_n` relabeling;
- the low-degree likelihood ratio / low-degree advantage remains bounded for `D=(log n)^{1+Omega(1)}`;
- then, conjecturally, for every fixed `epsilon>0` there should be no `n^{D/polylog n}`-time algorithm distinguishing `T_epsilon P_n` from `Q_n`, where `T_epsilon P_n` denotes the noisy planted law.

The displayed broad question is:

> **Open Problem 35.** What are the conditions on the distributions `P_n` and `Q_n` such that if the low-degree advantage remains bounded for `D=(log n)^{1+Omega(1)}` as `n -> infinity`, it rigorously implies that no polynomials of a certain degree can distinguish between `P_n` and `Q_n`?

The same page later contains a separate `Conjecture 35` and another `Open Problem 35` in the unplanted-clique section; those are not this claim.

Mandatory later boundary: Songtao Mao, **“The Polynomial-Time Low-Degree Conjecture is False,”** arXiv:2607.20318, submitted 22 July 2026:

<https://arxiv.org/abs/2607.20318>

For each fixed `r>=3`, Mao constructs an `S_n`-invariant graph law against `G(n,1/2)` whose marginals on every set of at most `D_n=Theta((log n)^{r-1})` edges are exactly uniform, so the LDA is exactly zero through `D_n`, yet after every fixed positive edge-resampling rate a deterministic polynomial-time rank test strongly distinguishes. Therefore symmetry + product null + low-degree matching + fixed independent noise do not suffice in general. Any positive theorem below is explicitly a restricted sufficient-condition theorem, not a proof of the unrestricted low-degree conjecture.

## 2. Inherited result and the exact next bottleneck

The 14:48 report proved, for **fixed finite-state** iid-vertex graphons with conditionally independent edges, that bounded source LDA through a growing polylogarithmic degree and fixed positive resampling noise imply bounded noisy LDA through every degree `L_n` satisfying

`L_n^10 / n -> 0`.

Its two ingredients were:

1. long even cycle moments force the local spectral parameter `n theta_n^2 Lambda^2 <= 1+o(1)`;
2. suppressing degree-two paths in a connected positive-excess motif leaves at most `2r` branch vertices and `3r` branch edges, but the report used a deliberately crude `(128 e^10)^r` shape count.

The two most important remaining restrictions were therefore:

- the proof exponent `1/10` was plainly enumeration-driven rather than structural;
- the latent state space was required to be finite because the path-kernel bound paid `mu_*^{-3r}`.

This run removes **both** restrictions. The exponent improves from `1/10` to `1/3`, and the theorem extends from finite-state kernels to arbitrary fixed **bounded symmetric row-centered graphons on a probability space**, with no finite-rank or finite-alphabet assumption.

## 3. Model: arbitrary bounded row-centered graphon

Let `(S,mu)` be any probability space. Let

`W : S x S -> R`

be a symmetric measurable bounded kernel satisfying the row-centering condition

`int W(x,y) dmu(y) = 0`

for `mu`-a.e. `x`. Let `T_W:L2(mu)->L2(mu)` be the self-adjoint Hilbert-Schmidt integral operator

`(T_W f)(x)=int W(x,y)f(y)dmu(y)`

and put

`Lambda = ||T_W||_op > 0`,    `M = ||W||_infty`.

For each `n`, sample latent variables `sigma_1,...,sigma_n iid mu`. Conditional on them, sample independent edge signs `X_ij in {-1,+1}` with

`E[X_ij | sigma] = theta_n W(sigma_i,sigma_j)`.

Assume `|theta_n| M <= 1` so this defines a probability law. Let `P_n` be the resulting planted law and let `Q_n` be uniform on all edge signs. This family is `S_n`-invariant.

For an edge set `F`, write

`chi_F(X)=prod_{e in F} X_e`

and

`t(F,W)=E_sigma prod_{uv in F} W(sigma_u,sigma_v)`.

Conditional edge independence gives the exact moment identity

`E_{P_n} chi_F = theta_n^{|F|} t(F,W)`.

After retention noise `T_rho`, `0<rho<1`, every Walsh coefficient of degree `e` is multiplied by `rho^e`, so

`Adv_{<=L}(T_rho P_n,Q_n)^2`

`= sum_{1<=|F|<=L} rho^{2|F|} theta_n^{2|F|} t(F,W)^2`.      (3.1)

## 4. Cycle pressure survives at arbitrary rank

Because `W` is bounded on a probability space, `T_W` is Hilbert-Schmidt and therefore compact self-adjoint. For every cycle `C_l`, `l>=2`,

`t(C_l,W)=Tr(T_W^l)`.

For even `l`,

`Tr(T_W^l)=sum_j lambda_j^l >= Lambda^l`.

Hence if the source LDA is bounded through degrees `D_n` containing even `l_n` with

`l_n -> infinity`,    `l_n^2/n -> 0`,

then the `(n)_{l_n}/(2l_n)` simple cycles give

`limsup_n n theta_n^2 Lambda^2 <= 1`.                       (4.1)

At Kireeva's source scale `D_n=(log n)^{1+Omega(1)}`, such a sequence `l_n` exists automatically.

Fix `rho in (0,1)` and define

`beta_n = n rho^2 theta_n^2 Lambda^2`.

From (4.1), for any fixed `beta_*` with

`rho^2 < beta_* < 1`,

we have `beta_n<=beta_*` for all sufficiently large `n`.

For cycle upper bounds at arbitrary rank, let

`H_W = ||W||_2 / Lambda`.

Since `sum_j lambda_j^2=||W||_2^2`, for every `l>=2`,

`|Tr(T_W^l)| <= ||W||_2^2 Lambda^{l-2} = H_W^2 Lambda^l`.   (4.2)

Thus arbitrary rank causes only a fixed cycle constant, not degree growth.

## 5. New path-suppression lemma without finite-state atoms

Define

`B_W = max{1, M/Lambda, (M/Lambda)^2}`.

For `ell>=1`, let `W^{(ell)}(x,y)` be the integral kernel of `T_W^ell`.

### Lemma 5.1 (uniform chain bound)

For every `ell>=1` and a.e. `(x,y)`,

`|W^{(ell)}(x,y)| <= B_W Lambda^ell`.                       (5.1)

#### Proof

For `ell=1`, this is `|W(x,y)|<=M<=B_W Lambda`.

For `ell>=2`, write `W_x(z)=W(x,z)` and `W_y(z)=W(z,y)`. Then

`W^{(ell)}(x,y)=<W_x, T_W^{ell-2} W_y>_{L2(mu)}`.

Because `mu` is a probability measure and `|W|<=M`,

`||W_x||_2, ||W_y||_2 <= M`.

Therefore

`|W^{(ell)}(x,y)|`

`<= ||W_x||_2 ||T_W||_op^{ell-2} ||W_y||_2`

`<= M^2 Lambda^{ell-2}`

`<= B_W Lambda^ell`.

QED.

### Lemma 5.2 (bounded-graphon excess contraction)

Let `F` be a connected simple graph with `e` edges, minimum degree at least two, not a cycle, and excess

`r=e-v>=1`,

where `v` is its number of nonisolated vertices. Then

`boxed{|t(F,W)| <= B_W^{3r} Lambda^e}.`                    (5.2)

#### Proof

Suppress every maximal path whose internal vertices have degree two. The resulting connected multigraph `H` may have loops and parallel edges, but every branch vertex has degree at least three. If `v_0,m_0` are its vertex and edge counts, suppression preserves excess:

`m_0-v_0=r`.

The minimum-degree bound gives

`2m_0 >= 3v_0`,

hence

`v_0<=2r`,    `m_0<=3r`.                                  (5.3)

If a kernel edge `a` corresponds to a suppressed path of length `ell_a`, then integrating the degree-two internal latent variables replaces that path by `W^{(ell_a)}`. The path lengths sum to `e`. Applying Lemma 5.1 to every path and then integrating the remaining branch labels against the probability measure `mu` gives

`|t(F,W)| <= prod_a (B_W Lambda^{ell_a})`

`<= B_W^{m_0} Lambda^e`

`<= B_W^{3r} Lambda^e`.

QED.

This is the first material structural improvement: `mu_*` disappears completely. The proof now works for continuous, infinite, and infinite-rank latent spaces as long as the fixed kernel is bounded.

## 6. Sharper excess enumeration: `e^{3r-1}`, not `e^{10r}`

Let `N_{e,r}` be the number of unlabeled connected simple graphs with `e` edges, minimum degree at least two, not a cycle, and excess `r=e-v>=1`.

### Lemma 6.1 (kernel/subdivision count)

There is an absolute constant `C_0` such that

`boxed{N_{e,r} <= C_0^r e^{3r-1}}`.                        (6.1)

#### Proof

After degree-two suppression, choose the number `v_0` of branch vertices. By (5.3),

`1<=v_0<=2r`,    `m_0=v_0+r<=3r`.

Temporarily label the branch vertices by `[v_0]`; this only overcounts unlabeled kernels. Allow loops and parallel edges, again an overcount. The number of unordered edge types is

`K=v_0(v_0+1)/2 <= 3r^2`.

The number of multigraphs with exactly `m_0` edge occurrences is at most

`binom(K+m_0-1,m_0)`.

Since `K+m_0-1<=6r^2` and `m_0>=r+1>r`, the standard binomial estimate gives

`binom(K+m_0-1,m_0) <= (6 e_E r)^{m_0}`,                  (6.2)

where `e_E=exp(1)` is Euler's constant.

For a fixed kernel, assigning positive subdivision lengths to its `m_0` edge occurrences with total length `e` gives at most

`binom(e-1,m_0-1)`

possibilities. Since `m_0-1>=r`,

`binom(e-1,m_0-1) <= (e_E e/r)^{m_0-1}`.                 (6.3)

Multiplying (6.2) and (6.3) cancels all but one power of `r`:

`<= (6 e_E^2)^{m_0} r e^{m_0-1}`.

Because `m_0<=3r`, and summing over at most `2r` choices of `v_0`,

`N_{e,r}`

`<= 2r^2 (6 e_E^2)^{3r} e^{3r-1}`.

Finally `2r^2<=4^r` for every `r>=1`, so (6.1) holds with, for example,

`C_0 = 4(6 e_E^2)^3`.

QED.

The exponent `3r` has a clear origin: a minimum-degree-three suppression kernel has at most `3r` branch edges. This is substantially tighter than the previous ordered-endpoint encoding.

## 7. Main theorem: arbitrary bounded graphons and degree `n^{1/3-o(1)}`

### Theorem 7.1 (bounded-graphon polynomial-degree amplification; PROVED PARTIAL)

Assume the model of Section 3 with a fixed bounded symmetric row-centered kernel `W`, `Lambda>0`. Suppose source-scale LDA is uniformly bounded through degrees `D_n` containing even `l_n->infinity` with `l_n^2/n->0`.

Fix any retention parameter `0<rho<1`. Let `L_n` satisfy

`boxed{L_n^3/n -> 0}.`                                    (7.1)

Then

`boxed{sup_n Adv_{<=L_n}(T_rho P_n,Q_n) < infinity}`      (7.2)

(after discarding finitely many initial `n`). Equivalently, there is a constant `C_W,rho` such that every polynomial `f_n` of degree at most `L_n` satisfies

`|E_{T_rho P_n} f_n - E_{Q_n} f_n|`

`<= C_W,rho sqrt(Var_{Q_n} f_n)`.                         (7.3)

#### Proof

Choose `beta_* in (rho^2,1)`. By Section 4, eventually `beta_n<=beta_*`.

**Cycle components.** There are at most `n^e/(2e)` labeled simple cycles of length `e`. By (4.2), their total connected squared-moment weight is at most

`(H_W^4/2) sum_{e>=3} beta_*^e/e`,                       (7.4)

which is finite.

**Positive-excess connected components.** For fixed `(e,r)`, every shape has `v=e-r` vertices and therefore at most `n^v` injective embeddings into `[n]`. Lemma 5.2 gives

`t(F,W)^2 <= B_W^{6r} Lambda^{2e}`.

Using Lemma 6.1 and

`n^{e-r}(rho^2 theta_n^2 Lambda^2)^e=beta_n^e n^{-r}`,

the total fixed-`(e,r)` contribution is at most

`beta_*^e e^{-1} [C_0 B_W^6 e^3/n]^r`.                  (7.5)

Put `C_W=C_0 B_W^6`. Condition (7.1) implies

`C_W L_n^3/n=o(1)`,

so for all large `n` the geometric sum over `r>=1` is at most twice its first term. Hence the total positive-excess connected contribution satisfies

`S_excess`

`<= (2C_W/n) sum_{e>=1} beta_*^e e^2`

`= O_{W,rho}(1/n)=o(1)`.                                  (7.6)

**Disconnected graphs.** Every nonzero graph is a vertex-disjoint collection of connected components of minimum degree at least two. Its squared moment weight factors over components. Dropping the vertex-disjointness and total-degree constraints gives the standard exponential polymer upper bound

`1+Adv_{<=L_n}(T_rho P_n,Q_n)^2`

`<= exp(S_cycle+S_excess)`.

By (7.4) and (7.6) the exponent is uniformly bounded. This proves (7.2), and the variational characterization of low-degree advantage gives (7.3). QED.

### Corollary 7.2 (source-scale consequence)

At Kireeva's source degree

`D_n=(log n)^{1+Omega(1)}`,

Theorem 7.1 protects every polynomial degree

`L_n=n^delta`

for each fixed

`boxed{delta<1/3}`.

Thus, within this broad iid-vertex conditional-edge-independent **bounded graphon** class, bounded source-scale LDA plus any fixed positive resampling noise propagates from polylogarithmic degree all the way to degree `n^{1/3-o(1)}`.

This strictly strengthens the 14:48 theorem in two independent directions:

- degree exponent: `1/10` -> `1/3`;
- latent model: fixed finite-state -> arbitrary fixed bounded graphon, including continuous and infinite-rank kernels.

## 8. Why this does not contradict Mao

Mao's distribution is not an iid-vertex graphon with conditionally independent edges. In the present class every nonzero self-adjoint kernel has

`t(C_4,W)=Tr(T_W^4)>0`,

so exact matching of all edge moments even through degree four forces `W=0` (or zero effective signal). Mao, by contrast, has exact uniform marginals through a growing polylogarithmic degree while retaining a polynomial-time rank obstruction. His Reed–Muller/bilinear construction therefore evades the graphon diagram factorization at the first structural step.

Accordingly, Theorem 7.1 is a genuine source-valid **sufficient-condition theorem** but not a solution of the unrestricted Open Problem 35. It identifies a broad natural class in which cycle pressure plus fixed noise controls substantially higher polynomial degrees, and it cleanly states the extra structure absent from Mao.

## 9. Sharpness information and the next bottleneck

The exponent `1/3` is no longer an arbitrary endpoint-encoding artifact. It comes from the fact that a positive-excess suppression kernel can have `3r` branch edges; the number of cubic kernels of excess `r` itself grows roughly like `r^{3r}` before automorphism cancellation. Thus any further improvement by the same absolute-value diagram method must exploit more than crude counting: cancellation, stronger Schatten contraction at branch vertices, or model-specific sign structure.

The exact remaining full-source gap is still large: general `S_n`-invariant distributions need not possess iid latent vertices or conditional edge independence, and Mao shows that code/rank dependencies can survive fixed noise while all low moments vanish.

The strongest next attack is therefore one of two genuinely different directions:

1. **Schatten/branch cancellation:** replace the pointwise branch bound by a global Hilbert-Schmidt/Schatten contraction that gains a factor per branch and may push the protected degree beyond `n^{1/3}` for kernels with spectral decay;
2. **non-graphon efficient structure:** formulate an analogous excess/width invariant for low-rank matrix computations or bounded-width branching programs, then prove that fixed noise plus bounded source LDA suppresses that invariant while Mao's rank test necessarily violates it.

A third useful extension is to allow `W=W_n` with quantitative uniform bounds on `||W_n||_infty/||T_{W_n}||_op` and on cycle Schatten ratios; the proof above already isolates exactly the constants that must stay controlled.

## 10. P08/P09 reusable lemma

The useful transferable mechanism is basis-independent:

> If a contraction diagram contains long degree-two propagation chains, suppress them first. If the propagator `T` has operator norm `Lambda` and endpoint vectors have uniformly bounded `L2` norm `M`, then a chain of length `ell>=2` costs at most `M^2 Lambda^{ell-2}`. Only the residual branch kernel, whose size is `O(excess)`, should pay dimension or endpoint losses.

For Gaussian/Wick or tensor diagrams this suggests charging losses to branch excess rather than total chaos degree. The exact bounded-graphon statement above is proved. Any Gaussian/tensor specialization still needs the relevant endpoint-norm or Schatten estimate and is not claimed automatically.
