# 3. B6 — DEFORM TO A POINT YOU CAN SOLVE

The previous report's weak-Ising orbit-tilt theorem controlled source collision pressure by shrinking the planting amplitude so that `lambda_n^2 ||a_n||_2^2=o(D_n)`. The answer is yes for a broad algebraic class. The key is to sum the latent bulk **before** estimating second moments.

## 3.1 Aggregate latent free-energy identity

Let `Q` be any probability measure on a finite observation space `Omega`. Let `Z` be a finite latent set, let `c_z>0`, and let `w_z(x)>0` be unnormalized component weights. Put

\[
Z_z:=\mathbb E_Q w_z(X),
\qquad
\pi_z:=\frac{c_z Z_z}{\sum_u c_u Z_u},
\qquad
L_z(x):=\frac{w_z(x)}{Z_z}.
\tag{3.1}
\]

Then the mixture likelihood ratio is **exactly**

\[
\boxed{
L(x):=\sum_z\pi_zL_z(x)
=\frac{W(x)}{\mathbb E_Q W(X)},
\qquad
W(x):=\sum_z c_z w_z(x).
}
\tag{3.2}
\]

This is elementary but important: the component normalizers disappear after the prior is weighted by those same normalizers.

Define the aggregate latent free-energy oscillation

\[
\Lambda:=\operatorname{osc}_x\log W(x)
=\sup_x\log W(x)-\inf_x\log W(x).
\tag{3.3}
\]

Since `inf W <= E_Q W <= sup W`, (3.2) implies

\[
0<L(x)\le e^{\Lambda}.
\]

Using `E_Q L=1`,

\[
\boxed{
1+\chi^2(P\|Q)=\mathbb E_Q L^2
\le e^{\Lambda}.
}
\tag{3.4}
\]

Thus **aggregate free-energy oscillation**, not any worst individual component norm, is a valid reference pressure.

## 3.2 Exact bulk-neutrality theorem

Suppose now

\[
w_z(x)=w_z^{(0)}(x)e^{U_z(x)}
\]

and the extensive baseline satisfies the pointwise partition identity

\[
\boxed{
W_0(x):=\sum_z c_z w_z^{(0)}(x)\equiv C_0,
}
\tag{3.5}
\]

with `C_0>0` independent of `x`. If

\[
|U_z(x)|\le R
\quad\text{for all }(z,x),
\tag{3.6}
\]

then

\[
e^{-R}C_0\le W(x)\le e^R C_0,
\]

so

\[
\Lambda\le2R.
\]

By (3.4),

\[
\boxed{
\log(1+\chi^2(P\|Q))\le2R.
}
\tag{3.7}
\]

This is the desired **bulk-cancellation mechanism**: `w_z^(0)` may contain an order-one field on all `n` coordinates, yet the full volume free energy cancels exactly after summing over the latent bulk. Only the defect/interface perturbation `U_z` is charged.

The assumption (3.5) is stronger than generic high temperature, but it is non-tautological, directly checkable, and survives arbitrary null dependence because it is pointwise in the observation.

## 3.3 Constant-amplitude extensive sign bulk over an interacting null

Take `Omega={-1,1}^n`, let `Q_n` be **any** null for which the transport half is available (in particular the weak bounded-degree zero-field Ising null of the previous runs), and let the latent bulk be all sign vectors `z in {-1,1}^n`. For a fixed constant `lambda`, set

\[
w_z^{(0)}(x)=\exp\!\left(\lambda\sum_{i=1}^n z_i x_i\right),
\qquad c_z=1.
\tag{3.8}
\]

Then, for every observation `x`,

\[
\boxed{
\sum_{z\in\{-1,1\}^n}w_z^{(0)}(x)
=\prod_i\sum_{z_i=\pm1}e^{\lambda z_i x_i}
=(2\cosh\lambda)^n,
}
\tag{3.9}
\]

so the constant-amplitude **entire volume** satisfies the bulk-neutrality identity exactly.

Now perturb each latent component by a local/interface factor `U_{n,z}` with

\[
\sup_{z,x}|U_{n,z}(x)|\le R_n=o(D_n).
\tag{3.10}
\]

Choose the prior by (3.1). Then, independent of the volume `n` and independent of the size of `lambda`,

\[
\boxed{
\log(1+\chi^2(P_n\|Q_n))\le2R_n=o(D_n).

\tag{3.11}
\]

This genuinely extends the preceding weak-amplitude class. The extensive field may be fixed at constant amplitude; only the **failure of bulk partition-of-unity** must be `o(D_n)`.

The class is nontrivial when `U_{n,z}` couples latent and observation coordinates in a way that destroys the exact product sum. For example a local term such as `beta z_i x_j` with `i != j` makes the aggregate `W_n(x)` depend on local spin products. If `R_n -> infinity` but `R_n=o(D_n)`, full chi-square may grow subexponentially on the source scale, so bounded source LDA is not rendered vacuous by a uniformly bounded full chi-square norm.

# 4. B27 — SWAP THE QUANTIFIERS: the sharp pressure-to-degree-loss profile

Assume the reversible noise semigroup `S_{n,t}` satisfies, for every `s` in some nonempty admissible set `S`,

\[
\|\Pi_{\le d}S_{n,t}\Pi_{\ge k}\|_{2\to2}
\le
\exp\{-s(k-d)-\delta_n(s)t\}
\tag{4.1}
\]

with `delta_n(s)>=0` (uniform positive lower bounds are available in the weak-Ising transport class for fixed admissible `s`). Define the transport rate function

\[
\boxed{
\Psi_{n,t}(g)
:=\sup_{s\in\mathcal S}
\{sg+\delta_n(s)t\}.
}
\tag{4.2}
\]

Let

\[
f_n=\frac{dP_n}{dQ_n}-1,
\qquad
A_n(D)=\|\Pi_{\le D}f_n\|_2,
\]

and suppose a model-level pressure certificate gives

\[
\|f_n\|_2^2\le e^{\Pi_n}.
\tag{4.3}
\]

For `d_n=D_n-g_n`, split at source degree `D_n`:

\[
\begin{aligned}
\|\Pi_{\le d_n}S_{n,t}f_n\|_2
&\le
\|\Pi_{\le d_n}S_{n,t}\Pi_{\le D_n}f_n\|_2\\
&\quad+
\|\Pi_{\le d_n}S_{n,t}\Pi_{\ge D_n+1}f_n\|_2.
\end{aligned}
\]

The first term is at most `A_n(D_n)` by contraction. Applying (4.1) for every admissible `s` and then optimizing gives

\[
\boxed{
\operatorname{Adv}^{\le D_n-g_n}(P_nS_{n,t},Q_n)
\le
A_n(D_n)
+
\exp\!\left\{
\frac{\Pi_n}{2}
-
\Psi_{n,t}(g_n+1)
\right\}.
}
\tag{4.4}
\]

This is the clean pressure-to-degree-loss theorem.

Define the inverse loss profile

\[
\boxed{
G_{n,t}(u)
:=\inf\{g\ge0:\Psi_{n,t}(g+1)\ge u\}.
}
\tag{4.5}
\]

Then for any `omega_n -> infinity`, choosing

\[
g_n\ge G_{n,t}(\Pi_n/2+\omega_n)
\tag{4.6}
\]

makes the high-source-degree contribution `o(1)`.

### Consequence: almost the full source degree survives

If there exists one fixed admissible `s_0>0` with `inf_n delta_n(s_0)>0` and

\[
\Pi_n=o(D_n),
\]

then one may take

\[
g_n=\frac{\Pi_n}{2s_0}+\omega_n=o(D_n)
\]

with `omega_n=o(D_n)` chosen to diverge. Therefore

\[
\boxed{
D_n-g_n=D_n-o(D_n),
}
\tag{4.7}
\]

not merely `(1-theta)D_n` for a fixed `theta>0`.

Thus the sharp quantifier order is:

> for each fixed admissible noise level/time and each model-level pressure bound `Pi_n`, there is an explicit inverse pressure-to-degree-loss function; if `Pi_n=o(D_n)`, bounded source LDA through `D_n` rigorously implies bounded noised LDA through **almost all of `D_n`**.

\[
g_n>R_n/s_0+\omega_n.
\tag{4.8}

This is strictly stronger than the previous fixed-fraction statement.

# 5. B20 — FIND WHY THE ALGORITHM FAILS: small geometric boundary is not enough

## 5.1 Exact translated-interval calculation

Let `Q_n` be the uniform product measure on `{-1,1}^n`, indexed cyclically. Fix a constant `lambda != 0`, put `t=tanh(lambda)`, and for each cyclic translation `r` let `I_r` be an interval of length `m_n<=n/2`. Define

\[
L_r(x)
=\frac{\exp(\lambda\sum_{i\in I_r}x_i)}{(\cosh\lambda)^{m_n}}
=\prod_{i\in I_r}(1+t x_i),
\tag{5.1}
\]

and let `P_n` be the **uniform** mixture over the `n` translations.

For two translations `r,r'`, independence gives the exact overlap

\[
\boxed{
K(r,r')
=\langle L_r,L_{r'}\rangle_{Q_n}
=(1+t^2)^{|I_r\cap I_{r'}|}.
}
\tag{5.2}
\]

Hence

\[
1+\chi^2(P_n\|Q_n)
=\frac1n\sum_{u=0}^{n-1}(1+t^2)^{\ell_n(u)},
\tag{5.3}
\]

where `ell_n(u)=|I_0 cap I_u|`. The diagonal shell alone yields

\[
\boxed{
\log(1+\chi^2(P_n\|Q_n))
\ge
m_n\log(1+t^2)-\log n.
}
\tag{5.4}
\]

Yet every planted interval has only **two boundary edges** on the cycle. Thus geometric boundary `O(1)` can coexist with overlap pressure `Theta(m_n)`.

Choosing, for example,

\[
m_n=D_n^2=(\log n)^{2+2\eta}
\]

still has `m_n=o(n)` and boundary `2=o(D_n)`, while (5.4) is `Theta(D_n^2)` and therefore far larger than the source scale `D_n`.

So “small support boundary” is not the missing condition. The interface must be measured **after subtracting the normalized two-copy bulk free energy**.

## 5.2 Universal diagonal entropy obstruction

The same point has an abstract exact form. For any latent mixture with prior `pi` and nonnegative Gram overlap `K`,

\[
1+\chi^2(P\|Q)
=\sum_{z,z'}\pi_z\pi_{z'}K(z,z')
\ge
\boxed{\sum_z\pi_z^2K(z,z)}.
\tag{5.5}
\]

Call the right-hand side the **diagonal collision mass** `D_diag`.

If `K(z,z)>=e^{b_n}` throughout the latent support, then

\[
D_{\rm diag}
\ge e^{b_n}\sum_z\pi_z^2
=
\exp\{b_n-H_2(\pi)\},
\tag{5.6}
\]

where

\[
H_2(\pi)=-\log\sum_z\pi_z^2
\]

is the collision entropy of the latent prior. Therefore a necessary condition for **any** reference-pressure route with

\[
\log(1+\chi^2)=o(D_n)
\]

is, at minimum,

\[
\boxed{
b_n-H_2(\pi)=o(D_n)
}
\tag{5.7}
\]

whenever the self-overlap is uniformly at least `e^{b_n}`.

For the translated interval family, `H_2(\pi)=\log n` while `b_n=m_n\log(1+t^2)`, recovering (5.4). This explains exactly why the tiny geometric boundary is irrelevant: the latent orbit does not have enough collision entropy to pay for the extensive self-overlap.

By contrast, the full-sign bulk-neutral construction in Section 3 has exponentially many latent states and, more importantly, satisfies the stronger pointwise partition identity (3.5); it cancels the bulk before the second moment is estimated.
