# 3. B9 — RANDOMIZE: sparse random constant-amplitude defects have quadratic collision pressure

The previous run allowed random interfaces abstractly through an exponential moment. Here the latent randomness is made explicit and the interface pressure is computed sharply enough to expose the correct **collision scale `n p_n^2`**, rather than the much larger mean support scale `n p_n`.

## 3.1 High-temperature null and random-field components

Let `G_n=(V_n,E_n)`, `|V_n|=n`, be a finite graph. Let

\[
Q_n(x)
\propto
\exp\left\{\sum_{\{i,j\}\in E_n}K_{ij}x_ix_j\right\},
\qquad x_i\in\{-1,+1\}.
\tag{3.1}
\]

No external field is present in the null. Define the Dobrushin influence matrix

\[
C_{ij}:=
\begin{cases}
\tanh |K_{ij}|,&\{i,j\}\in E_n,\\
0,&\text{otherwise},
\end{cases}
\tag{3.2}
\]

and suppose

\[
q:=\sup_n\max_i\sum_j C_{ij}<1.
\tag{3.3}
\]

This condition is invariant under adding arbitrary external fields, because the single-site Ising influence bound depends only on the pair coupling. Put

\[
D=(I-C)^{-1}=I+C+C^2+\cdots.
\tag{3.4}
\]

The classical Dobrushin covariance inequality gives, uniformly over every external field `h`,

\[
|\operatorname{Cov}_{Q_{n,h}}(X_i,X_j)|\le D_{ij}.
\tag{3.5}
\]

Because `C` is symmetric here,

\[
\max_i\sum_jD_{ij}
\le
\frac1{1-q}
=:W.
\tag{3.6}
\]

Fix a **constant amplitude** `beta in R`. Draw a random defect set `S subseteq V_n` by including vertices independently with probability `p_n`. Given `S`, plant the field

\[
L_S(x)
:=
\frac{\exp\{\beta\sum_{i\in S}x_i\}}
{\mathbb E_{Q_n}\exp\{\beta\sum_{i\in S}X_i\}}.
\tag{3.7}
\]

Let `P_n` be the Bernoulli-support mixture `dP_n/dQ_n=E_S L_S`.

This family is translation invariant whenever the null graph/couplings are transitive. It is nonproduct whenever the Ising couplings are nonzero. The component field amplitude `beta` does **not** go to zero.

## 3.2 Exact mixed-free-energy identity

Let

\[
F(h):=\log\mathbb E_{Q_n}e^{\langle h,X\rangle}.
\tag{3.8}
\]

For two defect sets `S,T`, their likelihood overlap is

\[
K(S,T)
:=\mathbb E_{Q_n}[L_S L_T].
\tag{3.9}
\]

Exactly,

\[
\log K(S,T)
=
F(\beta(1_S+1_T))-F(\beta1_S)-F(\beta1_T)+F(0).
\tag{3.10}
\]

Define `phi(u,v)=F(u1_S+v1_T)`. Twice applying the fundamental theorem of calculus gives

\[
\log K(S,T)
=
\int_0^\beta\int_0^\beta
\frac{\partial^2}{\partial u\,\partial v}\phi(u,v)\,du\,dv.
\tag{3.11}
\]

Since

\[
\frac{\partial^2}{\partial u\,\partial v}\phi(u,v)
=
\sum_{i\in S}\sum_{j\in T}
\operatorname{Cov}_{Q_{n,u1_S+v1_T}}(X_i,X_j),
\tag{3.12}
\]

(3.5) implies

\[
\boxed{
\log K(S,T)
\le
\beta^2
\sum_{i\in S}\sum_{j\in T}D_{ij}.
}
\tag{3.13}
\]

The right side is a **soft replica-collision interface**: two planted supports are charged only through the summable high-temperature interaction kernel `D`, not through their individual volumes.

## 3.3 Exact Bernoulli MGF bound

Write `S_i=1_{i in S}`, `T_j=1_{j in T}` and

\[
J(S,T):=\sum_{i,j}S_iD_{ij}T_j.
\tag{3.14}
\]

Since `S,T` are independent Bernoulli(`p`) fields,

\[
1+\chi^2(P_n\|Q_n)
=
\mathbb E_{S,T}K(S,T)
\le
\mathbb E_{S,T}e^{\beta^2J(S,T)}.
\tag{3.15}
\]

Condition on `S` and put

\[
a_j(S):=\sum_iS_iD_{ij}.
\tag{3.16}
\]

Then `0<=a_j<=W` and

\[
\begin{aligned}
\mathbb E_T e^{\beta^2J(S,T)}
&=\prod_j\left(1-p+p e^{\beta^2a_j}\right)\\
&\le
\exp\left\{p\sum_j(e^{\beta^2a_j}-1)\right\}.
\end{aligned}
\tag{3.17}
\]

For `0<=x<=W`, convexity of `e^{beta^2 x}` gives

\[
e^{\beta^2x}-1
\le
\frac{x}{W}(e^{\beta^2W}-1).
\tag{3.18}
\]

Also

\[
\sum_j a_j
=
\sum_iS_i\sum_jD_{ij}
\le W|S|.
\tag{3.19}
\]

Therefore

\[
\mathbb E_T e^{\beta^2J(S,T)}
\le
\exp\{pA|S|\},
\qquad
A:=e^{\beta^2W}-1.
\tag{3.20}
\]

Averaging over `S` gives the explicit bound

\[
\boxed{
1+\chi^2(P_n\|Q_n)
\le
(1-p+p e^{pA})^n
\le
\exp\{np(e^{pA}-1)\}.
}
\tag{3.21}
\]

Thus

\[
\boxed{
\Pi_{2,n}:=\log(1+\chi^2(P_n\|Q_n))
\le
np_n\left(e^{p_n(e^{\beta^2W}-1)}-1\right).
}
\tag{3.22}
\]

Using `e^y-1<=y e^y`,

\[
\Pi_{2,n}
\le
n p_n^2 A e^{p_nA}.
\tag{3.23}
\]

For fixed `beta` and fixed Dobrushin margin `q<1`, `A` is an `n`-independent constant. Consequently,

\[
\boxed{
np_n^2=o(D_n)
\quad\Longrightarrow\quad
\Pi_{2,n}=o(D_n).
}
\tag{3.24}
\]

This is the first result in this track where a component may carry a constant-amplitude field on **far more than `D_n` sites** while the reference pressure remains source-scale small. For example,

\[
p_n=n^{-1/2}D_n^{1/4}
\tag{3.25}
\]

gives

\[
\mathbb E|S|=\sqrt n\,D_n^{1/4}\gg D_n,
\qquad
np_n^2=D_n^{1/2}=o(D_n).
\tag{3.26}
\]

The mechanism is replica collision, not small component support.

## 3.4 Exact product-null calibration: the quadratic scale is sharp

At the product point `Q_n=Unif({+-1}^n)`, put `t=tanh beta`. Then

\[
L_S(x)=\prod_{i\in S}(1+t x_i).
\tag{3.27}
\]

Averaging an iid Bernoulli(`p`) support is pointwise exact:

\[
\frac{dP_n}{dQ_n}(x)
=
\prod_{i=1}^n(1+p t x_i).
\tag{3.28}
\]

Hence

\[
\boxed{
1+\chi^2(P_n\|Q_n)
=(1+p_n^2t^2)^n,
\qquad
\Pi_{2,n}=n\log(1+p_n^2t^2).
}
\tag{3.29}
\]

Equivalently, for independent support replicas `S,T`,

\[
K(S,T)=(1+t^2)^{|S\cap T|},
\quad
|S\cap T|\sim\operatorname{Bin}(n,p_n^2).
\tag{3.30}
\]

Thus the `np_n^2` scale in (3.24) is not an artifact of the Dobrushin proof: it is the exact collision scale already at the product point.

Retain the previously proved local-table/Kato–Toda transport certificate for sufficiently weak zero-field pairwise Ising nulls: there exists a fixed admissible `s_0>0` and positive coercivity so that the pressure-to-degree theorem applies.

\widehat\Pi_n

np_n\left(e^{p_n(e^{\beta^2W}-1)}-1\right)

Choose

# 4. B19 — MAKE IT AN ALGORITHM: a finite local certificate for the sparse-defect class

## 4.1 Dobrushin collision certificate

Input:

- finite graph `G=(V,E)` and pair couplings `K_ij`;
- field amplitude `beta`;
- Bernoulli defect density `p`;
- source cutoff `D`;
- a previously certified transport tilt `s_0` for the same null.

Compute

\[
q_D:=\max_i\sum_j\tanh|K_{ij}|.
\tag{4.1}
\]

If `q_D>=1`, this certificate returns **NO CERTIFICATE**; it does not claim the theorem is false. If `q_D<1`, set

\[
W_D=(1-q_D)^{-1},
\qquad
A_D=e^{\beta^2W_D}-1,
\tag{4.2}
\]

and

\[
\Pi_D^{cert}
:=
np\left(e^{pA_D}-1\right).
\tag{4.3}
\]

The degree-loss certificate is

\[
\boxed{
g_D^{cert}=\left\lceil\Pi_D^{cert}/(2s_0)+\omega\right\rceil.}
\tag{4.4}
\]

All graph-dependent work in (4.1) is local row summation. For bounded degree it is linear in the explicit interaction description.

For the transitive cycle with constant coupling `K`,

\[
q_D=2\tanh|K|,
\qquad
W_D\le\frac1{1-2\tanh|K|},
\tag{4.5}
\]

whenever `2 tanh|K|<1`.

## 4.2 Factor-table certificate inherited from B30

There is an independent finite local certificate from the preceding factor-table polymer theorem. Use uniform single-spin product reference and write

\[
1+u_e(x_i,x_j)=1+t_e x_ix_j,
\qquad t_e=\tanh K_{ij},
\tag{4.6}
\]

and for a field mark at one site

\[
1+v_i^{(1)}(x_i)=1+a x_i,
\qquad a=\tanh\beta.
\tag{4.7}
\]

When both replicas mark the same site, merge the two local factors:

\[
(1+a x_i)^2
=
1+v_i^{(2)}(x_i),
\qquad
v_i^{(2)}(x_i)=2a x_i+a^2.
\tag{4.8}
\]

If the physical graph has maximum degree `Delta`, the factor-intersection graph consisting of edge factors plus one merged site factor per vertex has

\[
\Delta_F\le2\Delta.
\tag{4.9}
\]

The table norms are

\[
\eta_0=\max_e|t_e|,
\quad
\eta_1=|a|,
\quad
\eta_2=2|a|+a^2,
\quad
\eta=\max(\eta_0,\eta_1,\eta_2).
\tag{4.10}
\]

The inherited conservative KP test is

\[
\boxed{
\eta
\le
\frac1{e(\Delta_F+1)+e^2\Delta_F}.
}
\tag{4.11}
\]

When it holds, the previous deterministic-interface certificate returns the explicit per-mark pressure constant

\[
c_{KP}
=
\frac{e(\eta_2+2\eta_1)}{1-e^2\Delta_F\eta}.
\tag{4.12}
\]

For the Bernoulli random-support model, the coarse union-interface MGF gives a valid alternative bound

\[
\Pi_{KP}^{cert}
=
n\log\left(1+(2p-p^2)(e^{c_{KP}}-1)\right).
\tag{4.13}
\]

This is generally weaker than the Dobrushin collision certificate because it pays for one-replica-only marks. The algorithm should therefore return

\[
\boxed{
\Pi^{cert}=\min(\Pi_D^{cert},\Pi_{KP}^{cert})
}
\tag{4.14}
\]

whenever both routes are valid.

## 4.3 First local replica-mismatch coefficients

The finite factor tables also explain *why* the sharper pressure begins quadratically in defect density.

Under the uniform product reference, with one edge `e={i,j}`,

\[
u_e=t_e x_ix_j,
\qquad
v_i^{(1)}=a x_i,
\qquad
v_i^{(2)}=2a x_i+a^2.
\tag{4.15}
\]

The first local same-site replica mismatch is

\[
\boxed{
\Delta_1(i)
:=E[v_i^{(2)}]-2E[v_i^{(1)}]
=a^2.
}
\tag{4.16}
\]

The one-edge/one-site second mismatch vanishes:

\[
\boxed{
\Delta_2(e,i)
:=\operatorname{Cov}(u_e,v_i^{(2)})
-2\operatorname{Cov}(u_e,v_i^{(1)})
=0.
}
\tag{4.17}
\]

The first nonzero spatial bridge between a replica-1 mark at `i` and replica-2 mark at adjacent `j` is the three-factor cluster

\[
\boxed{
B_3(e;i,j)
=E[(a x_i)(t_e x_ix_j)(a x_j)]
=a^2t_e.
}
\tag{4.18}
\]

Thus cross-replica spatial interaction requires **one mark from each replica**. Along a simple path, the leading bridge weight is `a^2` times the product of edge `t_e` values. This is the local-table counterpart of the Dobrushin soft-collision kernel and explains the `p^2` sparsity scale.

# 5. B2 — ATTACK THE NEGATION FIRST: expected interface size is not enough

The previous posterior-random-interface theorem used an exponential moment. Could one weaken that to `E|I|=o(D_n)`? No, even in the simplest bounded-arity high-temperature model.

## 5.1 Exact heavy-tail counterexample under the product null

Take

\[
Q_n=\operatorname{Unif}(\{-1,+1\}^n)
\tag{5.1}
\]

and fixed `beta !=0`, `t=tanh beta`. Let the latent support `S` equal the entire vertex set `V_n` with probability `epsilon_n`, and be empty otherwise. The two component likelihoods are

\[
L_\varnothing=1,
\qquad
L_V(x)=\prod_{i=1}^n(1+t x_i).
\tag{5.2}
\]

The mixture likelihood is

\[
L=(1-\epsilon_n)+\epsilon_n L_V.
\tag{5.3}
\]

Since `E_Q L_V=1` and `E_Q L_V^2=(1+t^2)^n`, exactly

\[
\boxed{
1+\chi^2(P_n\|Q_n)
=
1+\epsilon_n^2\big((1+t^2)^n-1\big).
}
\tag{5.4}
\]

For two independent latent supports `S,T`, the collision interface `I=S cap T` equals `V_n` only if both supports are full, which has probability `epsilon_n^2`. Hence

\[
\boxed{
\mathbb E|I|=n\epsilon_n^2
}
\tag{5.5}
\]

while, writing

\[
c_\beta:=\log(1+t^2)>0,
\tag{5.6}
\]

we also have the exact MGF identity

\[
\boxed{
1+\chi^2
=
\mathbb E e^{c_\beta |I|}.
}
\tag{5.7}
\]

Choose, for example, `epsilon_n=n^{-1/2}`. Then

\[
\mathbb E|I|=1=o(D_n),
\tag{5.8}
\]

but

\[
\Pi_{2,n}
=
\log\left(1+n^{-1}(e^{c_\beta n}-1)\right)
=
c_\beta n-\log n+o(1)
=\Theta(n).
\tag{5.9}
\]

So **a bounded expected interface can coexist with volume-order collision pressure**.

## 5.2 Tail-exponent calibration

More generally set

\[
\epsilon_n^2=e^{-\gamma n},
\qquad \gamma>0.
\tag{5.10}
\]

Then

\[
\mathbb E|I|=n e^{-\gamma n}\to0,
\tag{5.11}
\]

but

\[
\Pi_{2,n}
=
\log\left(1+e^{-\gamma n}(e^{c_\beta n}-1)\right).
\tag{5.12}
\]

Therefore

\[
\frac{\Pi_{2,n}}n
\to
(c_\beta-\gamma)_+.
\tag{5.13}
\]

At the critical value `gamma=c_beta`, the pressure stays `O(1)`; for `gamma<c_beta` it is linear in `n`. Thus the previous convenient sufficient hypothesis `gamma>c` is stronger than necessary at exact criticality, but **some exponential-tail comparison to the replica/interface cost is genuinely indispensable** under only scalar pressure control. First moments cannot replace it.

This is an exact counterexample to the attempted weakening, not a counterexample to Kireeva's source question.
