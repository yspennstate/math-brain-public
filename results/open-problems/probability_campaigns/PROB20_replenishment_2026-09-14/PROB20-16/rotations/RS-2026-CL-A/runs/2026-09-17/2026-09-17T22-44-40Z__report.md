## 4. B17 — standard correlation number gives an approximate-cylinder source theorem

The exact NUOD theorem corresponds to `gamma=1`. The natural quantitative relaxation is precisely the standard upper `gamma`-negative-dependence condition.

### Theorem 4.1 — upper `gamma`-negative dependence implies full Rényi-2 control

Assume the support indicators satisfy

\[
\boxed{
a_S\le\gamma\prod_{e\in S}q_e
\quad\text{for every nonempty }S
}
\tag{4.1}
\]

for some `gamma>=1`. Then for every heterogeneous product Bernoulli null and every coordinatewise resampling operator,

\[
\boxed{
\chi^2(TP\|Q)
\le
\gamma^2\left[
\prod_e(1+\nu_e)-1
\right]
\le
\gamma^2(e^U-1).
}
\tag{4.2}
\]

Consequently

\[
\boxed{
D_2(TP\|Q)
\le
\log\!\left(1+\gamma^2(e^U-1)\right),
}
\tag{4.3}
\]

and by (3.3),

\[
\boxed{
\chi^2(TP\|Q)
\le
\gamma^2
\left[
\exp\!\left(
\rho_*^2(\operatorname{Adv}^{\le D}(P,Q))^2
\right)-1
\right].
}
\tag{4.4}
\]

#### Proof

For every nonempty `S`, (4.1) gives

\[
a_S^2\le\gamma^2\prod_{e\in S}q_e^2.
\]

Insert this coefficientwise into (3.1), keeping the empty-set term separately:

\[
\begin{aligned}
1+\chi^2(TP\|Q)
&=1+\sum_{S\ne\varnothing}t_Sa_S^2\\
&\le1+\gamma^2
\sum_{S\ne\varnothing}
\prod_{e\in S}(t_eq_e^2)\\
&=1+\gamma^2\left[\prod_e(1+\nu_e)-1\right]\\
&\le1+\gamma^2(e^U-1).
\end{aligned}
\]

Subtract one for (4.2), take logarithms for (4.3), and use (3.3) for (4.4). `□`

## 5. B17 continued — an order-by-order cylinder profile is the less wasteful quantity

A single worst-cylinder `gamma` can still be dominated by a rare high-order event. The exact expansion suggests retaining the order.

For `k>=1`, define the upper-cylinder profile

\[
\Gamma_k

\frac{a_S}{\prod_{e\in S}q_e},
\tag{5.1}
\]

with the ratio interpreted only where the denominator is positive; cylinders with zero denominator necessarily have `a_S=0`. Note `Gamma_1=1`.

### Theorem 5.1 — correlation-profile chi-square bound

For every forced-support model,

\[
\boxed{
\chi^2(TP\|Q)
\le
\sum_{k\ge1}\Gamma_k^2 e_k(\nu_1,\ldots,\nu_N)
\le
\sum_{k\ge1}\Gamma_k^2\frac{U^k}{k!}.
}
\tag{5.2}
\]

#### Proof

Group the nonempty terms in (3.1) by cardinality. For every `|S|=k`,

\[
t_Sa_S^2
\le
\Gamma_k^2\prod_{e\in S}(t_eq_e^2)
=
\Gamma_k^2\prod_{e\in S}\nu_e.
\]

Summing over all `k`-sets gives the first inequality with the elementary symmetric polynomial `e_k`. The standard inequality

\[
e_k(\nu_1,\ldots,\nu_N)
\le \frac{(\sum_e\nu_e)^k}{k!}
=\frac{U^k}{k!}
\]

gives the second. `□`

A useful explicit specialization is: if

\[

\tag{5.3}

then

\[
\boxed{

\le C^2(e^{R^2U}-1).
}
\tag{5.4}
\]

More generally, for a source LDA bound `A`, any uniform bound on the exponential profile series

\[

## 6. B8 — the first hidden upper-cylinder violation occurs on three bits

The previous report established that all cylinders, not just pairs, matter. The smallest exact obstruction can be classified completely.

Let `A` be a random subset of `{1,2,3}` and assume the support indicators are unbiased and pairwise independent:

\[
\Pr(i\in A)=\frac12,
\qquad
\Pr(i,j\in A)=\frac14
\quad(i\ne j).
\tag{6.1}
\]

Pairwise data therefore look exactly independent. There is nevertheless one free third-order parameter.

### Proposition 6.1 — exact three-bit classification

Every unbiased pairwise-independent law on three Bernoulli bits has, in `{+1,-1}` Walsh coordinates, the form

\[
\boxed{
\Pr(Y=y)=\frac18\left(1+\theta y_1y_2y_3\right),
\qquad -1\le\theta\le1.
}
\tag{6.2}
\]

Hence

\[
0\le\Pr(1,1,1)\le\frac14.
\tag{6.3}
\]

The upper-cylinder ratio at order three satisfies

\[
\boxed{
\frac{\Pr(1,1,1)}{(1/2)^3}\le2,
}
\tag{6.4}
\]

and the value `2` is attained by the odd-parity law uniform on

\[
001,\ 010,\ 100,\ 111.
\tag{6.5}
\]

#### Proof

Write the probability mass function on `{+1,-1}^3` in the Walsh basis. Unbiased marginals force all degree-one Fourier coefficients to zero. Pairwise independence forces all degree-two coefficients to zero. Normalization fixes the constant coefficient. Only the degree-three character remains, so the density with respect to the uniform law is `1+theta y_1y_2y_3`. Pointwise nonnegativity is equivalent to `|theta|<=1`. At `y=(1,1,1)`, the mass is `(1+theta)/8`, yielding (6.3)–(6.4). Taking `theta=1` gives (6.5). `□`

This proves a sharp conceptual point: **checking every pair cannot establish the upper-cylinder condition needed for the Rényi-2 comparison. Dimension three is the first place a completely hidden higher-order cylinder can appear.** For at most two coordinates, there is no higher nontrivial cylinder beyond singletons and the pair itself.

## 10. Relation to planted clique and why this direction is structurally relevant

The source post is motivated by clique problems, and the upper-cylinder profile has a transparent graph interpretation for a uniformly random planted vertex set `K` of size `k`. If `A` is the set of all edges induced by `K` and an edge set `S` uses `v(S)` distinct vertices, then

\[
\boxed{
a_S
=\Pr(S\subseteq A)
=\frac{(k)_{v(S)}}{(n)_{v(S)}}.}
\tag{10.1}
\]

Every edge has the same marginal

\[
q=\frac{(k)_2}{(n)_2}.
\tag{10.2}
\]

Thus the cylinder inflation of `S` is

\[
\frac{a_S}{q^{|S|}}
=
\frac{(k)_{v(S)}}{(n)_{v(S)}}
\left(\frac{(n)_2}{(k)_2}\right)^{|S|},
\tag{10.3}
\]

which, away from endpoint effects, scales like

\[
\left(\frac nk\right)^{2|S|-v(S)}.
\tag{10.4}
\]

So the failure of NUOD / bounded correlation number in planted clique is not accidental: overlapping edges reuse planted vertices, producing large positive high-order cylinder inflation. Matchings have `2|S|-v(S)=0`, while stars, trees, and dense motifs have positive inflation exponent. This recovers in a particularly simple statistic the same qualitative issue that Chen–Li address more delicately by decomposing graph Fourier supports along small interfaces.

Equation (10.4) is **not** a new planted-clique threshold calculation and is not used as a closure claim. Its role is to show that the correlation-profile language is actually aligned with the source's motivating models rather than being an unrelated probability abstraction.
