## 5. B15 BREAK THE SYMMETRY ON PURPOSE — subgroup refinement only increases collision energy

The preceding report identified Mao's obstruction as high-degree dual-code orbit-collision pressure after vertex relabeling. This run asks whether that obstruction is an artifact of using the **full** relabeling group. It is not.

### 5.1 General group-projection monotonicity

Let a finite group `G` act unitarily on a degree-`j` source space by coordinate permutations, and for a subgroup `H<=G` define the averaging operators

\[
\Pi_G=\frac1{|G|}\sum_{g\in G}U_g,
\qquad
\Pi_H=\frac1{|H|}\sum_{h\in H}U_h.
\tag{5.1}
\]

These are orthogonal projections onto the `G`- and `H`-invariant subspaces. Because `H<=G`,

\[
\operatorname{Fix}(G)\subseteq\operatorname{Fix}(H),
\qquad
\Pi_G\Pi_H=\Pi_G.
\tag{5.2}
\]

Therefore for every degree-`j` vector `f_j`,

\[
\boxed{
\|\Pi_Hf_j\|_2^2
=
\|\Pi_Gf_j\|_2^2
+
\|(\Pi_H-\Pi_G)f_j\|_2^2
\ge
\|\Pi_Gf_j\|_2^2.
}
\tag{5.3}
\]

So **breaking symmetry from `G` to a subgroup `H` can only increase degreewise energy after averaging**. Full-group symmetrization is the most smoothing operation among its subgroup averages.

### 5.2 Exact orbit refinement formula for a linear code

Let `C<=F_2^E` be a binary linear code and

\[
f_j
=
\sum_{\substack{y\in C^\perp\\ |y|=j}}\chi_y.
\]

For a group `G` acting on coordinates, write `O` for its orbits on weight-`j` words and

\[
N_O=|C^\perp\cap O|.
\]

As proved in the preceding report,

\[
b_j(G)=\|\Pi_Gf_j\|_2^2
=
\sum_{\operatorname{wt}(O)=j}\frac{N_O^2}{|O|}.
\tag{5.4}
\]

Now let `H<=G`. Each `G`-orbit `O` splits into `H`-orbits `C_1,\dots,C_m`; set `N_i=|C^\perp\cap C_i|`. Then

\[
b_j(H)-b_j(G)
=
\sum_{O}
\left[
\sum_{C_i\subset O}\frac{N_i^2}{|C_i|}
-
\frac{(\sum_iN_i)^2}{\sum_i|C_i|}
\right]
\ge0
\tag{5.5}
\]

by Cauchy–Schwarz. Equality on a `G`-orbit holds exactly when the dual-code density `N_i/|C_i|` is constant across its `H`-orbit pieces.

Consequently, for every scalar noise parameter `q`,

\[
\boxed{
\chi^2_H(q)
=
\sum_jq^jb_j(H)
\ge
\sum_jq^jb_j(G)
=
\chi^2_G(q).
}
\tag{5.6}
\]

If the dual minimum distance is greater than `D`, then `b_j(H)=b_j(G)=0` for every `j<=D`: coordinate permutations preserve degree, so subgroup averaging cannot manufacture low-degree mass that was absent before averaging.
