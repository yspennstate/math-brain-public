## 2. Inherited result and the precise missing implication

The 09:45 theorem handled positive local-union statistics by writing a test as `f=1{sum_j h_j >=1}` and using read-k Finner bounds plus a source-high-degree residual estimate. That removed the earlier rarity hypothesis, but two material restrictions remained:

1. positivity/union structure was essential to compare `f` to `sum_j h_j`;
2. read-k overlap was used to prevent variance blow-up and to control the total null witness intensity.

For Kireeva's actual target, however, the distinguisher is a polynomial and can be **signed**. The natural missing implication is therefore:

> If a higher-degree polynomial is assembled from signed local pieces, can an explicit correlation/frame condition plus source-degree spectral control force its noisy distinguishing advantage to remain bounded by the source LDA, without any read-k, positivity, rarity, or union assumption?

The answer is yes. The correct quantity is the Rayleigh quotient of the local correlation Gram matrix in the actual coefficient direction, together with the aggregate normalized source-high-degree tail of the local pieces.

## 3. Setup

Let

`U_N = Unif({-1,+1}^N)`

and let `T_rho`, `rho in (0,1)`, be standard independent product noise, so Walsh character `chi_S` has eigenvalue `rho^|S|`.

Assume source low-degree advantage

`Adv_U^{<=D}(P,U) <= A`.                                      (3.1)

Let an arbitrary real-valued score admit a signed local decomposition

`F = c + sum_{j=1}^m a_j h_j`,                                (3.2)

where `h_j` depends only on a coordinate block `B_j`, of width `w_j=|B_j|`. There is **no restriction on how many blocks contain a coordinate** and no sign restriction on `a_j` or `h_j`.

Write

`v_j = Var_U(h_j)`, `sigma_F^2=Var_U(F)`,                     (3.3)

and ignore zero-variance pieces. Put

`b_j=a_j sqrt(v_j)`, `V_a=sum_j b_j^2`.                       (3.4)

Define the normalized local source-high-degree tail

`t_j=tau_{D,rho}(h_j)/sqrt(v_j)`,                              (3.5)

where

`tau_{D,rho}(h_j)
 = sum_{S subseteq B_j, |S|>D} rho^|S| |hhat_j(S)|`.          (3.6)

Finally define the coefficient-specific frame ratio and effective local spectral tail

`kappa_F = sigma_F^2/V_a`,                                    (3.7)

`s_F = (sum_j |b_j| t_j)^2 / V_a`.                            (3.8)

Both are invariant under rescaling an individual representation piece `h_j -> c_j h_j`, `a_j -> a_j/c_j`.

## 4. New signed local-frame transfer theorem

### Theorem 4.1

Under (3.1)–(3.8), whenever `sigma_F>0`,

`boxed{
 |E_{T_rho P}F-E_U F|/sigma_F
 <= A + sqrt(s_F/kappa_F).
}`                                                               (4.1)

Equivalently, without normalized notation,

`boxed{
 |E_{T_rho P}F-E_U F|
 <= A sigma_F + sum_j |a_j| sqrt(v_j) t_j.
}`                                                               (4.2)

This theorem has no read-k, positivity, rarity, monotonicity, disjointness, likelihood-ratio, Renyi, chi-square, or smoothed-L2 hypothesis.

### Proof

Center `F` under `U`; constants are stationary and cancel from the expectation difference. Split the noisy score at the source degree:

`T_rho(F-E_UF)=g+R`,

`g=Pi_{<=D}T_rho(F-E_UF)`,
`R=Pi_{>D}T_rho(F-E_UF)`.                                    (4.3)

By (3.1), applied to `g` and `-g`,

`|E_P g| <= A sqrt(Var_U g)`.                                 (4.4)

Orthogonal projection and product-noise contraction give

`Var_U g <= Var_U(F)=sigma_F^2`,                              (4.5)

hence

`|E_P g| <= A sigma_F`.                                       (4.6)

For the residual, linearity gives

`R=sum_j a_j Pi_{>D}T_rho(h_j-E_U h_j)`.                      (4.7)

Walsh characters have modulus one, so for every `x`,

`|Pi_{>D}T_rho(h_j-E_Uh_j)(x)|
 <= sum_{S subseteq B_j, |S|>D} rho^|S| |hhat_j(S)|
 = sqrt(v_j) t_j`.                                             (4.8)

Therefore

`||R||_infinity <= sum_j |a_j| sqrt(v_j) t_j
                 = sum_j |b_j| t_j`.                          (4.9)

Since `E_{T_rho P}F=E_P T_rho F` and `U` is stationary,

`|E_{T_rho P}F-E_UF|
 <= |E_P g|+|E_P R|
 <= A sigma_F + sum_j |b_j|t_j`.                              (4.10)

Dividing by `sigma_F=sqrt(kappa_F V_a)` and using definition (3.8) proves (4.1). QED.

## 5. The frame/correlation condition is explicit

Normalize each nonconstant local piece:

`u_j=(h_j-E_Uh_j)/sqrt(v_j)`,                                 (5.1)

and let

`Gamma_{j ell}=E_U[u_j u_ell]`.                               (5.2)

Then `Gamma` is a positive-semidefinite correlation Gram matrix and

`sigma_F^2=b^T Gamma b`,                                      (5.3)

so

`boxed{kappa_F=(b^T Gamma b)/(b^T b).}`                        (5.4)

Thus the exact frame quantity needed by Theorem 4.1 is not an inverse adapted frame or a signed Gram inversion. It is simply the **forward Rayleigh quotient in the actual score direction**.

A uniform class version follows immediately.

### Corollary 5.1 (uniform correlation-frame transfer)

If the relevant local family obeys

`lambda_min(Gamma) >= kappa_0 >0`,                             (5.5)

then every signed coefficient vector satisfies

`|E_{T_rho P}F-E_UF|/sqrt(Var_UF)
 <= A + sqrt(s_F/kappa_0)`.                                   (5.6)

A directly checkable sufficient condition is the Gershgorin bound

`sup_j sum_{ell != j} |Corr_U(h_j,h_ell)| <= delta <1`,        (5.7)

which gives

`lambda_min(Gamma)>=1-delta`.                                 (5.8)

This is the sought implication from a concrete correlation condition to a noisy higher-degree low-degree conclusion.

Importantly, (5.4) is weaker than requiring a uniform frame bound when one studies one specific polynomial: even if `Gamma` is singular somewhere, only the Rayleigh quotient in the actual coefficient direction must stay nondegenerate.

## 6. Width-only local tail and a broad no-read restriction corollary

For every local piece, Cauchy–Schwarz and Parseval give

`t_j^2
 <= B_rho(w_j,D)
 := sum_{s=D+1}^{w_j} binom(w_j,s) rho^(2s).                  (6.1)

Consequently

`s_F
 <= [sum_j |b_j| sqrt(B_rho(w_j,D))]^2/V_a
 <= sum_j B_rho(w_j,D).                                      (6.2)

The 09:45 report proved the following width estimate. Let

`phi_rho(x)=H(x)+2x log rho`,                                  (6.3)

and let `theta_rho` be its unique root in

`(rho^2/(1+rho^2),1)`.                                        (6.4)

For fixed `eta>0`, if

`D<w <= (D+1)/(theta_rho+eta)`,                               (6.5)

then

`B_rho(w,D) <= O_{rho,eta}(D) exp[-c_{rho,eta}D]`.            (6.6)

Combining (4.1), (5.5) and (6.6) gives:

### Corollary 6.1 (signed near-source-width local polynomials)

Suppose along a sequence:

1. `Adv_U^{<=D_n}(P_n,U_n)<=A_n` with `A_n=O(1)`;
2. `F_n=c_n+sum_{j<=m_n} a_{n,j}h_{n,j}` is any signed local score;
3. the local normalized correlation Gram matrix on the active coefficient span has lower frame bound `kappa_0>0`;
4. `log(m_n+2)=o(D_n)`;
5. every block satisfies
   `w_{n,j} <= (D_n+1)/(theta_rho+eta)`.

Then

`boxed{
 |E_{T_rho P_n}F_n-E_{U_n}F_n|/sqrt(Var_{U_n}F_n)
 <= A_n+o(1).
}`                                                               (6.7)

No read-number bound appears. No local term has to be positive or rare. The score can have arbitrary signs and arbitrary block-overlap multiplicities.

At Kireeva's scale `D_n=(log n)^(1+Omega(1))`, the size condition includes every polynomial-size local decomposition.

This is a true extension of the 09:45 theorem in a different direction: that theorem controlled strong rejection events for read-k unions; Corollary 6.1 controls **signed polynomial distinguishing advantage** and permits unlimited coordinate read, provided correlations do not collapse the aggregate variance.

## 7. Strictness: huge read number can coexist with a perfect frame

The frame formulation is not a disguised read-k condition.

Choose any collection of distinct subsets `B_1,...,B_m` of `[N]`, all of size `w>D`, and take

`h_j=chi_{B_j}`.                                               (7.1)

Under the uniform product null, distinct Walsh characters are orthonormal, so

`Gamma=I`, `kappa_F=1`                                       (7.2)

for every coefficient vector, **regardless of how strongly the blocks overlap**. A single coordinate may lie in an arbitrarily large fraction of the `m` blocks.

For each parity piece the exact normalized tail is not the crude square root of (6.1) but simply

`t_j=rho^w`.                                                   (7.3)

For equal-magnitude coefficients,

`s_F=m rho^(2w).`                                              (7.4)

Hence if `log m=o(w)` and `w>D` grows with `D`, Theorem 4.1 gives

`|E_{T_rho P}F-E_UF|/sqrt(Var_UF)
 <= A + sqrt(m) rho^w
 = A+o(1)`.                                                    (7.5)

This family can have enormous read number and still be exactly orthogonal. The older read-k route would reject it solely because of overlap multiplicity; the new frame theorem certifies it immediately.

## 8. Converse obstruction / what an escaping polynomial must violate

Theorem 4.1 also gives a quantitative source-valid obstruction. If a signed local score has noisy normalized distinguishing advantage

`Delta_F := |E_{T_rho P}F-E_UF|/sqrt(Var_UF)`,                 (8.1)

then

`boxed{s_F >= kappa_F (Delta_F-A)_+^2.}`                       (8.2)

Therefore a polynomial whose noisy advantage beats the source LDA by a fixed amount must exhibit at least one of two mechanisms:

1. **correlation/frame collapse:** `kappa_F` is small, meaning large signed cancellation in the local correlation Gram geometry; or
2. **persistent source-high-degree local spectral mass:** `s_F` stays non-negligible.

This is a sharper answer to the old signed/adapted-frame difficulty. One does not need to invert a signed Gram matrix to prove the forward implication; frame collapse itself is simply one explicit obstruction class.

For Mao, source LDA is exactly zero through `D_n`. Consequently, any representation of a successful Mao score in this signed-local form must satisfy

`s_{F_n}/kappa_{F_n} >= Delta_{F_n}^2`.                        (8.3)

In particular, no Mao distinguisher can simultaneously have a uniformly nondegenerate local correlation frame and vanishing effective local spectral tail. This does not claim that Mao's rank indicator actually has such a local decomposition; it says exactly what any such attempted structural representation would have to violate.
