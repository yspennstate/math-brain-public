## 3.1 Exact Hilbert-transform formula for the Kato generator

Work first in the fixed Hilbert realization obtained by multiplying by the square root of the density. For the pairwise Ising exponential family, write

\[
H=\sum_{e=\{i,j\}}J_e\chi_e,
\qquad
B_\alpha:=U_\alpha'U_\alpha^{-1}
=\frac12M_{H-\mathbb E_{Q_\alpha}H}.
\]

The scalar centering term is block diagonal for every source decomposition and plays no role in the Kato off-diagonal generator.

For the moving source-number operator the previous exact identity was

\[
\Pi_jN_\alpha'\Pi_k
=-|j-k|\,\Pi_jB_\alpha\Pi_k,
\qquad j\ne k.
\tag{3.1}
\]

On the other hand `N'=[K,N]` for the Kato generator. Hence, for `j != k`,

\[
(j-k)\Pi_jK_\alpha\Pi_k
=-|j-k|\Pi_jB_\alpha\Pi_k,
\]

so

\[
\boxed{
\Pi_jK_\alpha\Pi_k
=-\operatorname{sgn}(j-k)\Pi_jB_\alpha\Pi_k.
}
\tag{3.2}
\]

Define the block triangular Hilbert transform relative to a fixed source-number operator `N` by

\[
\mathcal H_N(X)
:=\sum_{j>k}\Pi_jX\Pi_k-
\sum_{j<k}\Pi_jX\Pi_k.
\tag{3.3}
\]

Then (up to the harmless sign convention chosen for `V'=-VK`)

\[
\boxed{K_\alpha=-\mathcal H_{N_\alpha}(B_\alpha).}
\tag{3.4}
\]

This is an exact formula, not an estimate.

## 3.2 Frozen-gauge interaction solves a block symmetric-Toda equation

Remove the scalar centering and define

\[
\widehat H_\alpha
:=V_\alpha\frac{M_H}{2}V_\alpha^*.
\tag{3.5}
\]

Because `V_alpha` freezes `N_alpha` to `N_0`, the transformed Kato generator is

\[
\widehat K_\alpha
=-\mathcal H_{N_0}(\widehat H_\alpha).
\tag{3.6}
\]

Differentiating (3.5) gives the exact Lax equation

\[
\boxed{
\frac d{d\alpha}\widehat H_\alpha
=-[\mathcal H_{N_0}(\widehat H_\alpha),\widehat H_\alpha].
}
\tag{3.7}
\]

This is the block symmetric-Toda flow associated with the ordinary-degree ordering. Equivalently, the source flag

\[
e^{\alpha M_H/2}V_{\le k}
\]

is obtained by the block QR/Iwasawa factorization of the positive multiplication operator `e^{alpha M_H/2}` relative to the ordinary-degree nested flag. The Kato unitary is the corresponding `Q` factor, up to block-diagonal gauge. Symmetric Toda/QR is classical; the point here is that the source-flag gauge has an explicit deterministic recursion rather than an abstract existence theorem.

Write

\[
\widehat H_\alpha
=\sum_{m\ge0}\alpha^mH_m.
\tag{3.8}
\]

Then (3.7) gives the exact coefficient recursion

\[
\boxed{
(m+1)H_{m+1}
=-\sum_{p+q=m}
[\mathcal H_{N_0}(H_p),H_q].
}
\tag{3.9}
\]

Every coefficient can therefore be generated deterministically from the local edge tables of `H_0=M_H/2`.

## 3.3 Exact degree-bandwidth conservation: higher Kato orders cannot create large degree jumps

At the product point, multiplication by one pair character `chi_e` changes ordinary degree only by `-2,0,+2`. Thus `H_0` is block-banded with degree bandwidth `w=2`.

The Toda flow preserves this bandwidth exactly. More generally, suppose a self-adjoint block matrix `H` satisfies

\[
H_{jk}=0\quad\text{for }|j-k|>w.
\]

For `j>k+w`, the `(j,k)` block of

\[
-[\mathcal H_N(H),H]
\]

is a sum over intermediate `ell` with coefficient

\[
-\{\operatorname{sgn}(j-\ell)-
\operatorname{sgn}(\ell-k)\}H_{j\ell}H_{\ell k}.
\]

If both factors are nonzero, `ell` must lie strictly between `k` and `j`; the two signs are then equal and the coefficient is zero. The same argument applies below the diagonal. Therefore

\[
\boxed{
\text{block bandwidth }w\text{ is invariant under the symmetric-Toda/Kato flow.}
}
\tag{3.10}
\]

For pairwise Ising,

\[
\boxed{
\Pi_j(0)\widehat H_\alpha\Pi_k(0)=0
\quad\text{whenever }|j-k|>2,
\quad\text{for every alpha in the flow interval.}
}
\tag{3.11}
\]

This rules out one possible B20 obstruction completely: higher Kato-gauge orders do **not** generate progressively larger source-degree gaps in the pairwise class. Any all-scale difficulty is spatial support growth and coefficient summability, not degree-gap proliferation.

## 3.4 A connected rooted Catalan majorant

Introduce independent edge parameters before restricting to a common scalar `alpha`. Use the multivariate Taylor/Möbius expansion to assign every coefficient canonically to the union of the edge supports appearing in that coefficient. Because commutators of disjointly supported operators vanish, every nonzero coefficient of order `m` is supported on a connected edge cluster with at most `m+1` edges and hence at most `m+2` vertices.

For `mu>=0`, define the rooted exponential interaction norm of the order-`m` coefficient by

\[
h_m(\mu)
:=\sup_i\sum_{X\ni i}e^{\mu|X|}\|H_{m,X}\|.
\tag{3.12}
\]

The initial pair interaction satisfies

\[
h_0(\mu)
\le\frac12e^{2\mu}J_{\rm row},
\qquad
J_{\rm row}:=\max_i\sum_{e\ni i}|J_e|.
\tag{3.13}
\]

Two elementary estimates suffice.

First, because the source-degree bandwidth is `2`, if `L` is the strictly raising part of a self-adjoint coefficient then its degree blocks have orthogonal domains/ranges, so

\[
\|\mathcal H_{N_0}(H_m)\|_{\rm root,\mu}
\le2h_m(\mu).
\tag{3.14}
\]

Second, if rooted interactions `Phi,Psi` have connected supports of sizes at most `a,b`, then

\[
\|[\Phi,\Psi]\|_{\rm root,\mu}
\le2(a+b)\|\Phi\|_{\rm root,\mu}
\|\Psi\|_{\rm root,\mu}.
\tag{3.15}
\]

This follows by summing only intersecting support pairs, using `||[X,Y]||<=2||X||||Y||`, and charging an intersecting union to a root in either support.

At order `m+1`, the support bounds are `p+2` and `q+2` with `p+q=m`. Therefore (3.9), (3.14), (3.15) yield

\[
(m+1)h_{m+1}
\le4(m+4)\sum_{p+q=m}h_ph_q.
\tag{3.16}
\]

Since `(m+4)/(m+1)<=4`,

\[
\boxed{
h_{m+1}
\le16\sum_{p+q=m}h_ph_q.
}
\tag{3.17}
\]

Let `C_m` be the Catalan numbers. Induction gives

\[
\boxed{
h_m(\mu)
\le C_m16^m h_0(\mu)^{m+1}
\le h_0(\mu)\,[64h_0(\mu)]^m.
}
\tag{3.18}
\]

Consequently the generating function is explicitly dominated by

\[
\boxed{
\sum_{m\ge0}h_mz^m
\le
\frac{1-\sqrt{1-64h_0z}}{32z},
\qquad
64h_0z<1.
}
\tag{3.19}
\]

In particular the Kato/Toda source-flag connection has a system-size-independent rooted quasi-local expansion whenever

\[
\boxed{
|\alpha|<\frac1{64h_0(\mu)}
\le\frac1{32e^{2\mu}J_{\rm row}}.
}
\tag{3.20}
\]

The constants are deliberately crude. The point is the existence of an explicit positive interval obtained from local row coupling alone.

# 5. B24 — FIND THE EXTREMAL OBJECT: the rigorous extremal surrogate is a binary commutator tree
