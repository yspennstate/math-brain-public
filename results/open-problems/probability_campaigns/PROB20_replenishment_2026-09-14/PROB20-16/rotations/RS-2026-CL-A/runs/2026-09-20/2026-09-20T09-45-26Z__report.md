## 2. Inherited theorem and exact missing implication

The 05:49 report proved the Boolean robust Fourier transfer inequality. For `U_N=Unif({-1,+1}^N)`, product-noise retention `rho in (0,1)`, and

`Adv_U^{<=D}(P,U) <= A`,                                      (2.1)

any Boolean test `h` satisfies

`|E_{T_rho P}h-E_U h| <= A sqrt(Var_U h) + Tau_{D,rho}(h)`,    (2.2)

where

`Tau_{D,rho}(h)=sum_{|S|>D} rho^|S| |hhat(S)|`.                (2.3)

The 08:40 report used (2.2) witness by witness. For a wide local witness on `w` coordinates, it controlled (2.3) by assuming the witness null mass decays as `exp(-alpha w)` with `alpha>log(1+rho^2)`.

The exact missing implication was whether one can remove that **exponential-rarity assumption** while retaining arbitrary local Boolean predicates and read-k overlap.

The new idea is to stop paying the LDA penalty separately for every local witness. Sum all witnesses first, project the entire noisy sum to degree `<=D`, and pay source LDA **once**. The only remaining local cost is a deterministic high-degree spectral-dimension tail. That tail can be exponentially small from width alone whenever each block is only a noise-dependent constant factor larger than the source degree `D`.

## 3. Read-k aggregate facts

Let independent base bits have law `U_N`. Let

`h_j:{-1,+1}^{B_j}->{0,1}`, `j=1,...,m`,

and assume the block family is read-k:

`max_i #{j:i in B_j} <= k`.                                   (3.1)

Set

`G=sum_j h_j`, `p_j=E_U h_j`, `lambda=sum_j p_j`,              (3.2)

`f=1{G>=1}`, `q=E_U f`, `L_q=-log(1-q)`.                      (3.3)

Two standard read-k consequences are

`lambda <= k L_q`,                                             (3.4)

`Var_U(G) <= k sum_j Var_U(h_j) <= k lambda`.                  (3.5)

For completeness, (3.4) follows from Finner's inequality applied to the complements:

`1-q = E prod_j (1-h_j)
    <= prod_j (E(1-h_j)^k)^(1/k)
    = prod_j (1-p_j)^(1/k)
    <= exp(-lambda/k)`.

For (3.5), Finner applied to exponentials gives

`E exp(t sum_j (h_j-p_j))
 <= prod_j [E exp(k t(h_j-p_j))]^(1/k)`.

The linear terms on both sides vanish. Comparing second-order terms as `t->0` yields

`Var(sum_j h_j) <= k sum_j Var(h_j)`.

This is within the established read-k framework of Gavinsky--Lovett--Saks--Srinivasan; no novelty claim is made for (3.4)–(3.5).

## 4. New aggregate transfer theorem

For a local block width `w`, define the Boolean noise-weighted high-degree dimension

`B_rho(w,D) = sum_{s=D+1}^w binom(w,s) rho^(2s)`,              (4.1)

with `B_rho(w,D)=0` when `w<=D`.

Define the aggregate spectral dimension

`mathcal B = sum_{j=1}^m B_rho(w_j,D)`, `w_j=|B_j|`.           (4.2)

### Theorem 4.1 (aggregate local spectral-dimension transfer)

Under (2.1) and the read-k condition (3.1),

`boxed{
E_{T_rho P} f
 <= lambda + A sqrt(k lambda) + sqrt(lambda mathcal B)
 <= k L_q + A k sqrt(L_q) + sqrt(k L_q mathcal B).
}`                                                               (4.3)

No rarity assumption on the local witnesses appears.

### Proof

Because `f<=G` pointwise and `T_rho` is positivity preserving,

`E_{T_rho P}f = E_P T_rho f <= E_P T_rho G`.                  (4.4)

Split the noisy witness sum into source-low and source-high degrees:

`T_rho G = g + R`,

`g = Pi_{<=D} T_rho G`, `R=Pi_{>D}T_rho G`.                   (4.5)

The low-degree part has mean

`E_U g = E_U G = lambda`,                                      (4.6)

and orthogonal projection plus noise contraction gives

`Var_U(g) <= Var_U(T_rho G) <= Var_U(G) <= k lambda`.          (4.7)

Apply the source LDA bound once to `g`:

`E_P g <= lambda + A sqrt(k lambda)`.                          (4.8)

It remains to control `R` uniformly. For each `j`, write

`R_j = Pi_{>D} T_rho h_j
     = sum_{S subseteq B_j, |S|>D} rho^|S| hhat_j(S) chi_S`.   (4.9)

Since every Walsh character has modulus one,

`||R_j||_infinity <= Tau_{D,rho}(h_j)`.                        (4.10)

Cauchy--Schwarz and Parseval give

`Tau_{D,rho}(h_j)
 <= sqrt(Var_U(h_j)) sqrt(B_rho(w_j,D))`.                      (4.11)

Therefore

`||R||_infinity
 <= sum_j ||R_j||_infinity
 <= sum_j sqrt(Var(h_j) B_rho(w_j,D))`

`<= sqrt[(sum_j Var(h_j))(sum_j B_rho(w_j,D))]`

`<= sqrt(lambda mathcal B)`.                                  (4.12)

Hence

`E_P R <= ||R||_infinity <= sqrt(lambda mathcal B)`.           (4.13)

Combining (4.4), (4.8) and (4.13) proves the first inequality in (4.3). Applying `lambda<=kL_q` gives the second. QED.

### Why this is materially stronger than 08:40

The 08:40 proof handled wide witnesses one by one, so each wide witness incurred its own `p_j + A sqrt(p_j)` term. The aggregate projection above removes those terms completely. Source LDA is paid once on the whole low-degree component, while all local high-degree pieces are handled by one deterministic residual envelope. This is what permits the next theorem with **no exponential-rarity hypothesis at all**.

## 5. Width-only exponential decay and the exact Boolean threshold

Let

`H(x)=-x log x-(1-x)log(1-x)`                                 (5.1)

be binary entropy in natural logarithms and define

`phi_rho(x)=H(x)+2x log rho`, `0<x<=1`.                        (5.2)

Its unique maximizer is

`x_* = rho^2/(1+rho^2)`,                                      (5.3)

and

`phi_rho(x_*)=log(1+rho^2)>0`, `phi_rho(1)=2log rho<0`.        (5.4)

Hence there is a unique root

`theta_rho in (x_*,1)`                                        (5.5)

with

`phi_rho(theta_rho)=0`.                                       (5.6)

For example, `theta_{1/2}=1/2`; numerically `theta_{0.7}≈0.76475`, `theta_{0.8}≈0.86920`, and `theta_{0.9}≈0.94947`.

### Lemma 5.1 (near-source-width local tail)

Fix `eta in (0,1-theta_rho)` and put

`c_{rho,eta} = -phi_rho(theta_rho+eta)>0`.                    (5.7)

If

`D < w <= (D+1)/(theta_rho+eta)`,                              (5.8)

then

`boxed{
B_rho(w,D) <= (w+1) exp(-c_{rho,eta} w)
           <= (C_{rho,eta}D+2) exp(-c_{rho,eta}(D+1)),
}`                                                               (5.9)

where `C_{rho,eta}=1/(theta_rho+eta)`.

#### Proof

For `s=xw`, the standard entropy bound gives

`binom(w,s) rho^(2s)
 <= exp{w[H(x)+2x log rho]}
 = exp(w phi_rho(x)).`                                         (5.10)

On `[theta_rho+eta,1]`, `phi_rho` is decreasing because that interval lies strictly to the right of its maximizer `x_*`. Condition (5.8) gives

`s/w >= (D+1)/w >= theta_rho+eta`

for every `s>=D+1`. Thus each term in (4.1) is at most

`exp[-c_{rho,eta} w]`.

There are at most `w+1` terms. This gives the first inequality in (5.9). Since `w>D` implies `w>=D+1`, while (5.8) also gives `w<=C_{rho,eta}(D+1)`, the second follows. QED.

The threshold is nontrivial for every fixed `rho<1` because `theta_rho<1`. Thus arbitrary local functions may depend on **strictly more than D coordinates** and still have exponentially small noisy source-high-degree residual. The allowable factor is `1/theta_rho>1`; it equals `2` at `rho=1/2`, about `1.3076` at `rho=0.7`, about `1.1505` at `rho=0.8`, and about `1.0532` at `rho=0.9`.

## 6. Main no-rarity corollary

### Corollary 6.1 (bounded LDA fools near-source-width read-k local unions)

Fix `rho in (0,1)` and `eta in (0,1-theta_rho)`. Suppose along a sequence:

1. `Adv_U^{<=D_n}(P_n,U_n) <= A_n` with `A_n=O(1)`;
2. the local witness family is read-`k_n` with `k_n=O(1)`;
3. `q_n=E_{U_n}f_n ->0`;
4. `log(m_n+2)=o(D_n)`;
5. every local witness has width

   `w_{n,j} <= (D_n+1)/(theta_rho+eta)`.                       (6.1)

Then

`boxed{E_{T_rho P_n} f_n ->0.}`                               (6.2)

Thus no such local-union statistic strongly distinguishes after fixed product noise.

#### Proof

Witnesses of width `<=D_n` contribute zero to `mathcal B_n`. Lemma 5.1 gives, uniformly over the remaining witnesses,

`B_rho(w_{n,j},D_n)
 <= O(D_n) exp(-c_{rho,eta}D_n)`.                              (6.3)

Therefore

`mathcal B_n
 <= m_n O(D_n) exp(-c_{rho,eta}D_n)
 = exp[-Omega(D_n)]`,                                          (6.4)

using `log m_n=o(D_n)`. In Theorem 4.1 the first two terms tend to zero because bounded `A_n,k_n` and `q_n->0` imply `L_{q_n}->0`; the third term tends to zero by (6.4). QED.

At Kireeva's source scale

`D_n=(log n)^(1+Omega(1))`,

condition `log m_n=o(D_n)` includes every polynomial-size local family. Hence the theorem rules out polynomial-size constant-read unions of **arbitrary** local Boolean predicates whose blocks are up to a fixed noise-dependent factor larger than `D_n`. Unlike the 08:40 theorem, their individual null probabilities may decay only polynomially, subexponentially in width, or in any other way compatible with the union null probability tending to zero.

This is a strict assumption trade: exponential rarity is removed completely, replaced by a near-source-width locality condition.

## 7. A more general quantitative criterion

Theorem 4.1 is useful even without the width threshold. It says the exact quantity to bound is not witness rarity but

`mathcal B_n = sum_j sum_{s>D_n}^{w_{n,j}} binom(w_{n,j},s) rho^(2s)`.   (7.1)

A sufficient condition for strong-distinction failure is simply

`k_n L_{q_n}
 + A_n k_n sqrt(L_{q_n})
 + sqrt(k_n L_{q_n} mathcal B_n) ->0`.                         (7.2)

Unlike defining the desired distinguishing error itself, `mathcal B_n` is a deterministic combinatorial function only of the local block widths, the source degree and the imposed noise. It is therefore a checkable structural condition, not a restatement of the conclusion.

The width-only theorem is one transparent regime in which (7.2) follows automatically.

`boxed{

For constant read and `q_n->0`, Mao's successful statistic therefore requires aggregate local spectral dimension diverging at least on the order `1/q_n`.

## 12. Gaussian/tensor/correlation handoff

There is a reusable coefficient-space analogue for P08/P09. For a `w`-dimensional standard Gaussian block with orthonormal Hermites and OU retention `rho`, any `h in L^2(gamma_w)` obeys

`sum_{|alpha|>D} rho^|alpha| |hhat(alpha)|
 <= sqrt(Var_gamma h)
    [sum_{t>D} binom(w+t-1,t) rho^(2t)]^(1/2).`                (12.1)

The bracket is a negative-binomial spectral dimension. Writing `x=t/w`, its method-of-types exponent is

`psi_rho(x)

It has a unique large positive root beyond `rho^2/(1-rho^2)`, so the coefficient tail decays exponentially when `D/w` stays above that root.

## 13. Failed route that taught something

A direct attempt to remove rarity while still applying (2.2) witness by witness fails because the sum of `A sqrt(p_j)` terms can be as large as `A sqrt(m lambda)` even when the union's null probability is tiny. The successful pivot was to sum first and project once. This is not a cosmetic rewrite: it changes the scaling from one LDA penalty per witness to one LDA penalty for the aggregate.

The pure width-only argument also exposes a real finite-alphabet limitation: when `(s-1)rho^2>=1`, raw character multiplicity at full support already defeats the elementary counting exponent. In that regime one needs witness structure (rarity, spectral entropy, product structure, etc.) beyond width alone.
