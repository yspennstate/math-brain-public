## 3. Exact finite-dimensional identity for source LDA

Fix `n,D`. Choose any `R_n`-orthonormal basis `{phi_alpha}` for the nonconstant reference-chaos space

`V_{n,D}=direct-sum_{1<=k<=D} H_{n,k}`,

and write `deg(alpha)=k` when `phi_alpha in H_{n,k}`.

Define the source covariance Gram matrix

`G_{n,D}(alpha,beta)=Cov_{Q_n}(phi_alpha,phi_beta)`

and the signal vector

`b_{n,D}(alpha)=E_{P_n}phi_alpha-E_{Q_n}phi_alpha = <Delta_n,phi_alpha>_{R_n}`.

Because constants drop out of both the numerator and the variance in the source definition, every degree-`<=D` polynomial is represented modulo constants by a coefficient vector `c`, and

`E_P f-E_Q f = c^T b`,

`Var_Q(f)=c^T G c`.

Therefore, with Moore--Penrose inverse if needed,

`Adv_n^{<=D}^2 = b_{n,D}^T G_{n,D}^{dagger} b_{n,D}`,

provided `b_{n,D}` lies in the range of `G_{n,D}`; otherwise the source advantage is infinite. In all bounded-LDA applications the range condition is automatic.

This identity is source-native: it uses the exact `Q_n` variance from Kireeva's definition and no auxiliary frame bound.

## 4. New theorem: noise-weighted covariance transfer

For an index set `I subset {alpha:deg(alpha)<=D}`, let `G[I]` denote the principal covariance block. For target noise time `t>0`, let

`W_t[I]=diag(exp(-2t deg(alpha)): alpha in I)`.

Define the **noise-weighted covariance pressure**

`Theta_n(I;t)=|| W_t[I]^(1/2) G_{n,D}[I] W_t[I]^(1/2) ||_op`.

For the degree band `K<deg<=D`, write `Theta_n(K,D;t)`.

### Theorem 4.1 — exact covariance transfer on any degree band

For every `0<=K<D`,

`sum_{K<k<=D} exp(-2tk) ||Pi_{n,k} Delta_n||_{L2(R_n)}^2`

`<= Adv_n^{<=D}(P_n,Q_n)^2 * Theta_n(K,D;t)`.

No `Lambda_n(d)` or adapted-frame condition appears.

### Proof

Let `G=G_{n,D}`, `b=b_{n,D}` and

`x=G^{dagger/2} b`.

Bounded source advantage gives `b in Range(G)`, hence

`b=G^(1/2)x`,

`||x||_2^2=b^T G^dagger b=Adv_n^{<=D}^2`.

Let `P_I` be coordinate projection onto the band `I={K<deg<=D}`. The corresponding reference-noise energy is exactly

`b_I^T W_t[I] b_I`

because the coordinates of `b` are the reference-chaos coefficients of `Delta_n`. But

`b_I=P_I G^(1/2)x`,

so

`b_I^T W_t[I] b_I`

`=||W_t[I]^(1/2) P_I G^(1/2)x||_2^2`

`<=||W_t[I]^(1/2) P_I G^(1/2)||_op^2 ||x||_2^2`.

The squared operator norm equals

`||W_t[I]^(1/2) P_I G P_I^T W_t[I]^(1/2)||_op`

`=Theta_n(K,D;t)`.

This proves the claim. `square`

## 6. Source-bounded tier: bounded LDA can already rule out strong distinction

Kireeva/Hopkins use **bounded**, not necessarily vanishing, low-degree advantage. The vanishing-TV theorem above deliberately asks fixed-degree advantage to vanish. There is nevertheless an exact bounded tier in the important stationary-null case.

Assume now `R_n=Q_n`, the polynomial filtration equals the reference chaos filtration through `D_n`, and `T_t` is `Q_n`-reversible with `T_t|H_k=e^{-tk}`. Then `G=I` and

`Adv_n^{<=D_n}^2=sum_{k<=D_n}||Pi_k(dP_n/dQ_n-1)||_2^2`.

If `sup_n Adv_n^{<=D_n}<infinity` and for some `s<t`

`sup_n exp(-2(t-s)D_n) Gamma_n(s)<infinity`,

then

`sup_n chi2(T_tP_n || Q_n)<infinity`.

Indeed the degrees through `D_n` contribute at most `Adv_n^{<=D_n}^2`, while the tail is bounded by the displayed smoothed-tail term.

Bounded chi-square rules out **strong** distinguishing. If `A_n` were an event with `Q_n(A_n)->0`, then Cauchy--Schwarz gives

`T_tP_n(A_n) <= Q_n(A_n) + sqrt( chi2(T_tP_n||Q_n) Q_n(A_n) ) ->0`.

Hence there cannot be events with null probability tending to zero and planted probability tending to one. This matches the source's bounded-LDA quantifier without artificially upgrading it to fixed-degree vanishing.

## 7. Transparent correlation-pressure corollary

The operator criterion can be certified without diagonalizing `G`.

By the symmetric Schur test,

`Theta_n(K,D;t)`

`<= sup_{alpha:K<deg(alpha)<=D} sum_{beta:K<deg(beta)<=D}`

`exp(-t(deg(alpha)+deg(beta))) |Cov_Q(phi_alpha,phi_beta)|`.

Therefore a sufficient **correlation pressure** condition is: for some `c>0,C<infinity`, uniformly in `n,D` and every basis element `alpha` of degree `k`,

`sum_{beta:1<=deg(beta)<=D} exp(-t deg(beta)) |Cov_Q(phi_alpha,phi_beta)|`

`<= C exp((t-c)k)`.

Then

`Theta_n(K,D;t) <= C exp(-c(K+1))`.
