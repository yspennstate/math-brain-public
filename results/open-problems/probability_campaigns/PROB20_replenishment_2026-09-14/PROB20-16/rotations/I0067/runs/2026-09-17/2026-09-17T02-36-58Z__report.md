# 4. B18 — say the transport in the language of Lie transport plus Hodge correction

This is a route diagnosis, not promoted as a new theorem.

For the especially clean restricted case in which both `b` and `u` are divergence free, write the Lie derivative / commutator

\[
[b,u]=(b\cdot\nabla)u-(u\cdot\nabla)b.
\tag{4.1}
\]

Because the bracket of divergence-free vector fields is divergence free,

\[
\boxed{
\mathbb P[(b\cdot\nabla)u]
=[b,u]+\mathbb P[(u\cdot\nabla)b].
}
\tag{4.2}
\]

This identity explains the constant-coefficient success and the variable-coefficient obstruction in one line. A divergence-preserving stochastic flow naturally transports vector fields through the Lie derivative `[b,u]`; the source noise is **not** pure Lie transport unless `nabla b=0`. The difference is a zero-order Hodge term.

For the single periodic shear

\[
b(x)=\sigma a(x_2)e_1,\qquad a\in C^\infty(\mathbb T),
\tag{4.3}
\]

one gets the particularly explicit mechanism

\[
\boxed{
\mathbb P[(b\cdot\nabla)u]
=[b,u]+\sigma\,\mathbb P[a'(x_2)u_2e_1].
}
\tag{4.4}
\]

Thus there are two non-equivalent flow languages:

* componentwise pullback can cancel the raw `(b·nabla)u` term, but then the fixed Euclidean divergence constraint and Leray projector become a time-dependent Hodge geometry;
* vector-field pushforward preserves incompressibility for a volume-preserving flow and cancels Lie transport, but then the zero-order Hodge remainder in (4.2) remains.

For constant `b`, `nabla b=0` and the flow is a translation, so the two languages collapse to the same solved situation. For genuinely variable `b`, any endpoint proof must control one of these two equivalent manifestations of the geometry rather than pretending the constant translation argument still applies.

**Outcome of B18:** useful reformulation; no metric movement. It localizes the missing endpoint mechanism to a random Hodge/Stokes problem plus lower-order flow terms.
