## 4. Mathematical idea before proof

### B20 — find exactly why the previous coalescence algorithm fails

The previous exact coalescence identity takes q large boxes of total mass c and merges them into one box of size c. That is powerful only if the target weight \(w_c\) is not catastrophically smaller than the fragment weights.

A full-dust counterexample can therefore try to make many individual c's extremely unfavorable even while keeping nearby values moderately heavy. The exact failure is not fragmentation itself; it is the insistence that the merged target land **at c**.

### B10 — derandomize the landing site

If every large c has a moderately heavy site within a fixed distance L below it, do not merge the q boxes to `(c,0,...,0)`. Deterministically choose a heavy predecessor \(g(c)\in[c-L,c]\) and put the bounded residue

\[
d(c):=c-g(c)\in\{0,1,\ldots,L\}
\]

into a second box. The exact total c is preserved:

\[
(a_1,\ldots,a_q)
\longmapsto
(g(c),d(c),0,\ldots,0).
\tag{4.1}
\]

Because the residue takes values in a fixed finite set, full support gives it a fixed positive weight. Thus arbitrarily deep suppressions at the original site c become irrelevant.

### B25 — count the same conditioning fiber twice

Summing (4.1) over all q-fragment compositions of c gives a new exact factorial-moment inequality. The only extra price is that the target now occupies two selected coordinates instead of one. Since the first target coordinate still has size at least `q(K+1)-L`, the target multiplicity retains the decisive `1/K` factor from the preceding refined coalescence theorem.

The resulting q-th moment has **exactly the same exponent threshold** as the global-envelope theorem, but the polynomial lower bound is now required only on a bounded-gap backbone.

## 5. New exact lemma: nearby-target q-box coalescence

For an integer cutoff \(K\) and q>=2, define as before

\[
A_{q,K}(c)
:=
\sum_{\substack{a_1+\cdots+a_q=c\\a_i>K}}
\prod_{i=1}^q w_{a_i},
\tag{5.1}
\]

and

\[
R_K:=\#\{i:Y_i>K\}.
\tag{5.2}
\]

Assume that for every c in the range of interest we have selected an integer

\[
g(c)\in[c-L,c],
\qquad d(c):=c-g(c)\in[0,L].
\tag{5.3}
\]

Define the nearby-target defect

\[
\widetilde Q_{q,K}(m)
:=
\sup_{q(K+1)\le c\le m}
\frac{A_{q,K}(c)}
{w_{g(c)}w_{d(c)}w_0^{q-2}}.
\tag{5.4}
\]

### Lemma 5.1 — exact nearby-target fiber count

If \(q(K+1)>L\), then

\[
\boxed{
E(R_K)_q
\le
\frac{m\,n^{q-1}}{q(K+1)-L}
\widetilde Q_{q,K}(m).
}
\tag{5.5}
\]

#### Proof

Expand the falling factorial:

\[
E(R_K)_q
=
\sum_{(i_1,\ldots,i_q)\ {m distinct}}
P(Y_{i_1}>K,\ldots,Y_{i_q}>K).
\tag{5.6}
\]

Fix an ordered q-tuple and fixed values \(a_1,\ldots,a_q>K\), and put

\[
c=a_1+\cdots+a_q.
\]

For every choice of all remaining coordinates having total \(m-c\), compare the original selected coordinates

\[
(a_1,\ldots,a_q)
\]

with the target selected coordinates

\[
(g(c),d(c),0,\ldots,0).
\]

Both selected blocks have total c, so the other coordinates are unchanged. Because the allocation probability is proportional to the product of the fixed weights, the ratio of the two configuration weights is exactly

\[
\frac{\prod_{j=1}^q w_{a_j}}
{w_{g(c)}w_{d(c)}w_0^{q-2}}.
\tag{5.7}
\]

Summing (5.7) over every composition of c with all \(a_j>K\) gives exactly

\[
\frac{A_{q,K}(c)}
{w_{g(c)}w_{d(c)}w_0^{q-2}}
\le
\widetilde Q_{q,K}(m).
\tag{5.8}
\]

It remains only to count how many selected tuples can map to one target allocation. In every target,

\[
Y_{i_1}=g(c)\ge c-L\ge q(K+1)-L.
\]

Since the total allocation mass is m, the number of possible first target indices is at most

\[
\frac{m}{q(K+1)-L}.
\tag{5.9}
\]

There are at most n choices for \(i_2\), and at most \(n^{q-2}\) ordered choices for the remaining zero target indices. Once the first two target values are fixed,

\[
c=Y_{i_1}+Y_{i_2}
\]

is fixed, so there is no additional multiplicity in c. Therefore one target allocation is counted at most

\[
\frac{m n^{q-1}}{q(K+1)-L}
\tag{5.10}
\]

times. Combining (5.6)--(5.10) proves (5.5). \(\square\)

This is an exact finite combinatorial identity/inequality, not an asymptotic local-limit claim.

## 6. Main theorem: bounded-gap polynomial backbones force persistence

### Definition 6.1 — polynomial backbone with bounded gaps

A fixed full-support weight sequence has a `(beta_-, beta_+, L)` polynomial backbone if there are constants

\[
2<\beta_-\le\beta_+<\infty,
\qquad c_+,c_->0,
\qquad L\in\mathbb N_0,
\]

and a set \(G\subseteq\mathbb N\) such that, for every sufficiently large k,

\[
w_k\le c_+k^{-\beta_-},
\tag{6.1}
\]

while for every sufficiently large integer c there is a selected

\[
g(c)\in G\cap[c-L,c]
\tag{6.2}
\]

with

\[
w_{g(c)}\ge c_-g(c)^{-\beta_+}.
\tag{6.3}
\]

No lower bound at all is required for \(w_k\) when \(k\notin G\). Those off-backbone weights may be super-polynomially or much more strongly suppressed.

### Theorem 6.2 — bounded-gap backbone persistence

Let one fixed full-support weight sequence \(w\), with \(w_0>0\), satisfy Definition 6.1. Let \(m_n/n\to\lambda>\nu\), where \(\nu\) is the boundary mean of this same law. Put

\[
\delta=\lambda-\nu
\]

and

\[
q_*
:=
\left\lfloor
\frac{\beta_+-2}{\beta_--2}
\right\rfloor+1.
\tag{6.4}
\]

Then, along the **full admissible sequence**, for every \(\varepsilon>0\),

\[
\boxed{
P\left(
\frac{Y_{(1)}}n
\ge
\frac{\delta-\varepsilon}{q_*-1}
\right)\to1.
}
\tag{6.5}
\]

Consequently,

\[
\boxed{
\liminf_{n\to\infty}E\frac{Y_{(1)}}n
\ge
\frac{\lambda-\nu}{q_*-1}.
}
\tag{6.6}
\]

In particular the frozen limsup metric has the same lower bound.

If

\[
\beta_+<2\beta_--2,
\tag{6.7}
\]

then q_*=2 and

\[
\boxed{
Y_{(1)}/n\to_p\delta,
\qquad
Y_{(2)}/n\to_p0,
\qquad
E[Y_{(1)}/n]\to\delta.
}
\tag{6.8}
\]

### Proof

#### Step 1: boundary normalization

The global upper bound (6.1) gives

\[
\limsup_{k\to\infty}w_k^{1/k}\le1.
\]

The backbone contains arbitrarily large g and (6.3) gives

\[
\limsup_{g\in G,\ g\to\infty}w_g^{1/g}\ge1.
\]

Hence the radius of \(\Phi\) is exactly \(\rho=1\). Since \(\beta_->2\),

\[
\Phi(1)=\sum_kw_k<\infty,
\qquad
\sum_k k w_k<\infty.
\]

Thus the boundary normalization \(\pi_k=w_k/\Phi(1)\) is a full-support probability law of finite positive mean \(\nu\). Multiplying all weights by the common normalization factor changes none of the allocation probabilities or envelope exponents, so we work with \(\pi\) below without changing notation in ratio calculations.

#### Step 2: a polynomial lower bound on the exact conditioning event without using \(w_{c_n}\)

By the ordinary law of large numbers for \(S_{n-2}\), choose a deterministic \(\eta_n\downarrow0\) such that

\[
P\left(
|S_{n-2}-(n-2)\nu|\le\eta_n n
\right)\to1.
\tag{6.9}
\]

For all large n this probability is at least 1/2. The interval contains at most \(2n+3\) integers after \(\eta_n\le1\), so some integer \(r_n\) in it satisfies

\[
P(S_{n-2}=r_n)\ge\frac1{2(2n+3)}.
\tag{6.10}
\]

Set

\[
c_n:=m_n-r_n.
\]

Then

\[
c_n=\delta n+o(n).
\tag{6.11}
\]

Choose the backbone predecessor \(g_n=g(c_n)\in[c_n-L,c_n]\) and residue

\[
d_n=c_n-g_n\in\{0,\ldots,L\}.
\]

Full support gives the strictly positive finite-reservoir constant

\[
a_L:=\min_{0\le d\le L}\pi_d>0.
\tag{6.12}
\]

The explicit event

\[
\{X_1=g_n,\ X_2=d_n,\ S_{n-2}=r_n\}
\subseteq\{S_n=m_n\}
\]

therefore yields

\[
\begin{aligned}
P(S_n=m_n)
&\ge
\pi_{g_n}\pi_{d_n}P(S_{n-2}=r_n)\\
&\ge
C n^{-\beta_+}n^{-1}.
\end{aligned}
\]

Hence

\[
\boxed{
P(S_n=m_n)\ge Cn^{-(\beta_++1)}.
}
\tag{6.13}
\]

The important point is that (6.13) never divides by or lower-bounds the possibly microscopic weight \(w_{c_n}\).

#### Step 3: every sublinear power cutoff captures all missing mass

Fix \(0<\gamma<1\) and let

\[
K_n=\lfloor n^\gamma\rfloor.
\tag{6.14}
\]

For

\[
Z_i=X_i\mathbf1_{\{X_i\le K_n\}},
\]

we have

\[
0\le Z_i\le K_n,
\qquad EZ_i\le\nu,
\qquad
\operatorname{Var}(Z_i)\le EZ_i^2\le\nu K_n.
\tag{6.15}
\]

Bernstein's inequality gives, for each fixed \(\varepsilon>0\),

\[
P\left(
\sum_{i=1}^nZ_i>(\nu+\varepsilon)n
\right)
\le
\exp\{-c_\varepsilon n/K_n\}.
\tag{6.16}
\]

Conditioning on \(S_n=m_n\) and dividing by (6.13),

\[
P\left(
\sum_iY_i\mathbf1_{\{Y_i\le K_n\}}>(\nu+\varepsilon)n
\right)
\le
C^{-1}n^{\beta_++1}e^{-c_\varepsilon n/K_n}
\to0.
\tag{6.17}
\]

The retained lower half of Janson Lemma 18.31 gives

\[
\sum_iY_i\mathbf1_{\{Y_i\le K_n\}}
\ge\nu n+o_p(n).
\tag{6.18}
\]

Combining (6.17)--(6.18),

\[
\sum_iY_i\mathbf1_{\{Y_i\le K_n\}}
=\nu n+o_p(n),
\]

so the mass above the cutoff is

\[
\boxed{
T_n:=\sum_iY_i\mathbf1_{\{Y_i>K_n\}}
=\delta n+o_p(n).
}
\tag{6.19}
\]

This conclusion holds for every fixed \(\gamma\in(0,1)\).

#### Step 4: bound the nearby-target q-fold defect

Fix q>=2. For c>=q(K+1), every composition

\[
a_1+\cdots+a_q=c,
\qquad a_i>K,
\]

has at least one coordinate at least c/q. Using the global upper envelope for that coordinate and then dropping the sum constraint on the remaining q-1 coordinates,

\[
\begin{aligned}
A_{q,K}(c)
&\le
C_q c^{-\beta_-}
\left(\sum_{a>K}a^{-\beta_-}\right)^{q-1}\\
&\le
C_q c^{-\beta_-}
K^{-(q-1)(\beta_--1)}.
\end{aligned}
\tag{6.20}
\]

For the deterministic nearby target, (6.3) gives

\[
w_{g(c)}\ge c_-g(c)^{-\beta_+}\ge c_-c^{-\beta_+},
\tag{6.21}
\]

and full support on the finite residue set gives

\[
w_{d(c)}\ge\min_{0\le d\le L}w_d=:a'_L>0.
\tag{6.22}
\]

Therefore

\[
\frac{A_{q,K}(c)}{w_{g(c)}w_{d(c)}w_0^{q-2}}
\le
C_q c^{\beta_+-\beta_-}
K^{-(q-1)(\beta_--1)}.
\]

Since c<=m_n=O(n),

\[
\boxed{
\widetilde Q_{q,K}(m_n)
\le
C_q n^{\beta_+-\beta_-}
K^{-(q-1)(\beta_--1)}.
}
\tag{6.23}
\]

#### Step 5: factorial-moment decay and the same finite-q threshold

Apply Lemma 5.1 with \(K=K_n\). Because L is fixed and \(K_n\to\infty\),

\[
q(K_n+1)-L\asymp K_n.
\]

Since \(m_n=O(n)\), (5.5) and (6.23) yield

\[
E(R_{K_n})_q
\le
C_q n^{q+\beta_+-\beta_-}K_n^{-D_q},
\tag{6.24}
\]

where

\[
D_q
:=1+(q-1)(\beta_--1)
=(q-1)\beta_- -q+2.
\tag{6.25}
\]

With \(K_n=n^{\gamma+o(1)}\),

\[
E(R_{K_n})_q
\le
n^{q+\beta_+-\beta_- -\gamma D_q+o(1)}.
\tag{6.26}
\]

A \(\gamma<1\) making this exponent negative exists iff

\[
q+\beta_+-\beta_-<D_q,
\]

which simplifies exactly to

\[
\boxed{
q(\beta_--2)>\beta_+-2.
}
\tag{6.27}
\]

The smallest integer q satisfying (6.27) is precisely q_* in (6.4). Choose

\[
\frac{q_*+\beta_+-\beta_-}{D_{q_*}}
<\gamma<1.
\tag{6.28}
\]

Then

\[
E(R_{K_n})_{q_*}\to0.
\tag{6.29}
\]

#### Step 6: convert finite fragmentation complexity into a macroscopic box

Markov's inequality applied to the falling factorial gives

\[
P(R_{K_n}\ge q_*)
\le
\frac{E(R_{K_n})_{q_*}}{q_*!}
\to0.
\tag{6.30}
\]

On the event \(R_{K_n}\le q_*-1\), all of the high-cutoff mass (6.19) lies in at most q_*-1 boxes. Therefore, for every fixed epsilon>0,

\[
P\left(
Y_{(1)}\ge\frac{(\delta-\varepsilon)n}{q_*-1}
\right)\to1.
\]

This proves (6.5), and boundedness by \(m_n/n\) gives (6.6).

If (6.7) holds, q=2 satisfies (6.27). Then \(R_{K_n}\le1\) w.h.p. Together with (6.19), exactly one box carries \(\delta n+o_p(n)\), while every other box is at most \(K_n=o(n)\). Hence (6.8). \(\square\)

## 7. What changed relative to the previous theorem

The old asymmetric-envelope theorem required

\[
w_k\ge c_-k^{-\beta_+}
\]

for **every** sufficiently large k. Theorem 6.2 requires this only on a set G whose gaps are uniformly bounded.

Outside G, no lower bound is imposed at all. In particular the bad-site weights may satisfy, along an infinite subsequence,

\[
w_k\ll k^{-M}
\qquad\text{for every fixed }M,
\]

or may exhibit arbitrarily violent local ratios. The proof survives because the deterministic nearby-target map never needs to use those bad sites as the merged target.

The exact obstruction exposed by B20 is therefore more precise than “deep local suppressions”: **deep suppressions are harmless if a polynomially heavy landing site is always within a bounded distance and the bounded residue can be stored at positive fixed cost.**

## 8. Explicit new stress law: polynomial even sites, super-polynomially suppressed odd sites

Define one fixed full-support law by

\[
w_0=1,
\]

and for k>=1,

\[
\boxed{
w_k=
\begin{cases}
k^{-3},&k\text{ even},\\
e^{-\sqrt{k}},&k\text{ odd}.
\end{cases}}
\tag{8.1}
\]

This is a single fixed weight sequence.

For all sufficiently large odd k,

\[
e^{-\sqrt{k}}\le k^{-3},
\]

so the global upper envelope holds with

\[
\beta_-=3.
\]

Take G to be the positive even integers. Every large c has an even predecessor

\[
g(c)\in\{c,c-1\},
\]

so L=1, and on G

\[
w_g=g^{-3}.
\]

Thus

\[
\beta_+=3,
\qquad
q_*=\left\lfloor\frac{3-2}{3-2}\right\rfloor+1=2.
\]

Theorem 6.2 therefore gives, for every \(\lambda>\nu\) and every full admissible sequence \(m_n/n\to\lambda\),

\[
\boxed{
Y_{(1)}/n\to_p\lambda-\nu,
\qquad
Y_{(2)}/n\to_p0,
\qquad
E[Y_{(1)}/n]\to\lambda-\nu.
}
\tag{8.2}
\]

Hence for this fixed law the frozen metric reaches its source-side ceiling:

\[
\boxed{b(w,\lambda)=\lambda-\nu.}
\tag{8.3}
\]

This law is outside the preceding global polynomial-lower-envelope theorem: on odd k,

\[
e^{-\sqrt{k}}k^M\to0
\]

for every fixed M, so no finite polynomial lower envelope holds at every site. Its adjacent local ratios also oscillate violently between very small and very large values. Repository search at the captured snapshot found no earlier PROB20-20 report treating this law or a “bounded-gap backbone” theorem.

I do **not** claim publication novelty over all heavy-tail literature. The statement here is only that it is a new certified branch relative to recovered track history and that the proof is self-contained under the displayed hypotheses.

## 9. Counterexample checks before promotion

### 9.1 Unbounded backbone gaps are not covered

If the distance

\[
L_c:=c-g(c)
\]

grows with c, then the reservoir weight \(w_{L_c}\) may itself become arbitrarily small. The proof's fixed constant (6.22) disappears. The theorem therefore does **not** silently extend to a sparse backbone with unbounded gaps.

### 9.2 Full support is used, not cosmetic

The nearby-target map stores the residue d(c) in a second box. Full support guarantees

\[
\min_{0\le d\le L}w_d>0.
\]

For a law with arithmetic holes, a different finite reservoir set or a span-aware version would be needed. No such extension is claimed here.

### 9.3 The upper exponent beta_->2 is used

It gives \(\Phi(1)<\infty\), finite boundary mean, a summable fragment tail, and the positive denominator in the finite-q threshold. The theorem is not a statement for arbitrary heavy tails or arbitrary radius-one laws.

### 9.4 The conclusion is full sequence

The cutoff \(K_n=n^\gamma\), denominator route, factorial-moment bound, and persistence conclusion are proved for every sufficiently large admissible n. No chosen subsequence is used to obtain (6.5) or (8.2).

### 9.5 The law is fixed

The weights in Definition 6.1 and the explicit law (8.1) do not depend on n. Only the conditioning total and deterministic cutoff vary.

### 9.6 No invalid 18.40 transfer appears

The inputs are only the exact iid-conditioning representation, a direct denominator lower bound, Bernstein for truncated iid sums, the retained source Lemma 18.31 control, and the new exact coalescence double count. No false pointwise rate necessity or probability-one factorial statement is used.

## 10. What a remaining full-dust counterexample must now defeat

Recovered work had already eliminated many smooth and structured possibilities. The present theorem adds a new obstruction.

A candidate fixed law with a polynomially heavy set of sites cannot create full-sequence dust merely by making all neighboring “bad” sites astronomically unlikely, **provided the heavy set has bounded gaps**. The deterministic residue repair routes around every such bad site.

Therefore a counterexample built from local suppressions must do at least one of the following:

1. make the gaps between all usable moderately heavy landing sites unbounded;
2. combine those gaps with residue weights that are themselves too costly;
3. destroy every finite-q coalescence comparison through a genuinely growing fragmentation defect;
4. leave the polynomial-tail regime altogether in a way not already covered by the smooth-hazard / sparse-window branches.

The most concrete next route is a span-aware, **growing-gap** version of Lemma 5.1: allow \(L=L_n\to\infty\), retain the exact target count, and measure the extra cost by

\[
-\log w_{d(c)}
\]

relative to the q-fragment coalescence gain. The failure threshold for that extension would identify exactly how fast usable backbone gaps must grow before the present argument can break.
