# 4. Dyadic setup and exact fixed-tail mass

The theorem below is deliberately restricted. Take a fixed dyadic boundary law in the normalization already used by the preceding exact-fiber reports:

\[
w_0=1,\qquad
w_{2^r}=2^{-r}u_r,\qquad u_r>0,
\]

with zero weights off `{0,1,2,4,8,...}`, radius one and finite positive boundary mean `nu`. Let `pi` be Janson's associated boundary probability law; equivalently `pi_k` is the normalized equivalent probability weight sequence at the boundary. We have

\[
\sum_r u_r<\infty,
\]

and the allocation conditioned on total mass is unchanged by the boundary normalization.

Fix once and for all an integer tail index `R`. Define

\[
\nu_{<R}:=\sum_{r<R}2^r\pi_{2^r},
\qquad
\delta_R:=\lambda-\nu_{<R}.
\tag{4.1}
\]

Since `nu_<R <= nu < lambda`,

\[
\delta_R>0,
\qquad
\delta_R\downarrow\delta:=\lambda-\nu
\quad (R\to\infty).
\tag{4.2}
\]

Let

\[
C_n^{(R)}:=\sum_{r\ge R}2^rN_{2^r}
=m_n-\sum_{r<R}2^rN_{2^r}.
\tag{4.3}
\]

For a **fixed** `R`, Janson Theorem 10.4 as used in the proof of Lemma 18.31 gives, for each fixed finite collection of occupancies,

\[
\frac1n\sum_{r<R}2^rN_{2^r}
\xrightarrow{p}
\nu_{<R}.
\tag{4.4}
\]

Hence

\[
\boxed{
\frac{C_n^{(R)}}n\xrightarrow{p}\delta_R.
}
\tag{4.5}
\]

This is the only source mass input needed below. There is no `Omega_n`, no moving `K_n`, and no hidden rate assumption.

# 6. Main new theorem — fixed-cutoff positive-metric transfer

## Theorem 6.1

Fix the dyadic law above, `lambda>nu`, and one already-fixed admissible sequence `m_n/n -> lambda`.

Fix a tail start `R`. Let `h` satisfy

\[
0<h<\frac{\delta_R^2}{64}.
\tag{6.1}
\]

Suppose there are infinitely many supported root indices `j -> infinity` such that

\[
H_{R,j}\le h.
\tag{6.2}
\]

Then, for every constant `c` satisfying

\[
\boxed{
\frac{\delta_R}{2}<c<\delta_R-4\sqrt h,
}
\tag{6.3}
\]

there is a deterministic subsequence `n_l` along which

\[
\liminf_{l\to\infty}
P\bigl(Y_{(1)}\ge c n_l-o(n_l)\bigr)
\ge
\frac1{1+ch}.
\tag{6.4}
\]

Consequently

\[
\boxed{
b(w,\lambda)\ge\frac{c}{1+ch}>0.}
\tag{6.5}
\]

This is a restricted dyadic theorem. It proves a positive limsup-expectation lower bound; it does **not** prove w.h.p. one-box condensation and does not settle arbitrary support.

### Proof

Take an infinite sequence of roots `j_l` satisfying (6.2), and write

\[
P_l:=2^{j_l},\qquad H_l:=H_{R,j_l}.
\]

Choose

\[
n_l:=\left\lceil\frac{P_l}{c}\right\rceil,
\tag{6.6}
\]

so

\[
\frac{P_l}{n_l}\to c.
\tag{6.7}
\]

Because `R` is fixed, (4.5) applies along this subsequence with no rate issue:

\[
\frac{C_{n_l}^{(R)}}{n_l}\xrightarrow{p}\delta_R.
\tag{6.8}
\]

#### Step 1. Root-tuned deterministic baseline

Set

\[
\varepsilon_l:=\sqrt{H_l}.
\tag{6.9}
\]

For `R<=r<j_l`, define thresholds backward from the root by

\[
t_{j_l-1}:=\varepsilon_l\sqrt{u_{j_l}},
\qquad
 t_{r-1}^2=t_r/2.
\tag{6.10}
\]

Equivalently, for depth `d=j_l-r>=1`,

\[
t_{j_l-d}
=2^{-1+2^{1-d}}
(\varepsilon_l\sqrt{u_{j_l}})^{2^{1-d}}.
\tag{6.11}
\]

Hence

\[
\frac1{t_{j_l-d}}
\le
2\varepsilon_l^{-1}
 u_{j_l}^{-1/2^d}.
\tag{6.12}
\]

Define the deterministic baseline

\[
 b_{n_l,r}:=
 \left\lfloor\frac{2\lambda_{n_l,r}}{t_r}\right\rfloor
\qquad (R\le r<j_l),
\tag{6.13}
\]

and put baseline zero at all `r>=j_l`.

Then

\[
q_{n_l,r}
=
\frac{\lambda_{n_l,r}}{b_{n_l,r}+1}
<\frac{t_r}{2}.
\tag{6.14}
\]

#### Step 2. Baseline mass is bounded by `4 sqrt(H_l) n_l`

Let

\[
B_l:=\sum_{r=R}^{j_l-1}2^rb_{n_l,r}.
\]

Using (5.2), (6.12), and (6.13),

\[
\begin{aligned}
\frac{B_l}{n_l}
&\le
2\sum_{r=R}^{j_l-1}\frac{u_r}{t_r}\\
&\le
4\varepsilon_l^{-1}
\sum_{r=R}^{j_l-1}
\frac{u_r}{u_{j_l}^{1/2^{j_l-r}}}\\
&=4\frac{H_l}{\varepsilon_l}
=4\sqrt{H_l}
\le4\sqrt h.
\end{aligned}
\tag{6.15}
\]

For each tail scale let

\[
e_{l,r}:=(N_{2^r}-b_{n_l,r})_+
\]

for `R<=r<j_l`, and let `e_(l,r)=N_(2^r)` for `r>=j_l`. Define the tail excess mass

\[
E_l:=\sum_{r\ge R}2^r e_{l,r}.
\tag{6.16}
\]

Then deterministically

\[
0\le C_{n_l}^{(R)}-E_l\le B_l.
\tag{6.17}
\]

#### Step 3. A fixed positive phase margin replaces the moving `Omega_n` clock

By (6.3), both numbers

\[
\delta_R-4\sqrt h-c>0,
\qquad
2c-\delta_R>0
\tag{6.18}
\]

are strictly positive.

Choose one fixed `eta>0` smaller than half the minimum of these two margins. On the event

\[
\left|C_{n_l}^{(R)}/n_l-\delta_R\right|<\eta,
\tag{6.19}
\]

which has probability tending to one by (6.8), equations (6.15)--(6.18) give, for large `l`,

\[
E_l
\ge
C_{n_l}^{(R)}-B_l
>
(c+\eta)n_l
>P_l,
\tag{6.20}
\]

while

\[
E_l\le C_{n_l}^{(R)}
<(2c-\eta)n_l
<2P_l.
\tag{6.21}
\]

Therefore

\[
\boxed{P(P_l\le E_l<2P_l)\to1.}
\tag{6.22}
\]

No source-produced moving cutoff appears.

#### Step 4. Complete inverse fiber has bounded relative weight

By (6.14), the recursion (5.4) obeys, inductively,

\[
T_{n_l,r}\le t_r.
\tag{6.23}
\]

Indeed the base case is immediate, and if `T_(r-1)<=t_(r-1)`, then

\[
T_{n_l,r}
\le t_r/2+t_{r-1}^2=t_r.
\]

Hence

\[
F_{n_l,j_l}
\le T_{n_l,j_l-1}^2
\le t_{j_l-1}^2
=H_lu_{j_l}.
\tag{6.24}
\]

The root placement activity is

\[
\lambda_{n_l,j_l}
=\frac{n_l}{P_l}u_{j_l}.
\tag{6.25}
\]

Therefore

\[
\boxed{
\frac{F_{n_l,j_l}}{\lambda_{n_l,j_l}}
\le
\frac{P_l}{n_l}H_l
\le ch+o(1).
}
\tag{6.26}
\]

#### Step 5. B25 exact source/target count gives a positive root probability

On the phase event (6.22), suppose a histogram has no `P_l` box. Because the baseline is zero at and above the root, no box larger than `P_l` can occur: the next dyadic size is at least `2P_l>E_l`.

The excess multiset therefore consists of dyadic boxes below `P_l`, has total mass in `[P_l,2P_l)`, and its top binary bit is exactly `P_l`. Dyadic carrying supplies a submultiset of excess boxes whose mass is exactly `P_l`.

Use the pinned exact coalescence map: replace those selected boxes by one `P_l` box and zeros. The map preserves total mass, number of coordinates, and `E_l`. Its aggregate inverse fiber over any fixed target is bounded by (6.26) times the target histogram weight.

Let `A_l={P_l<=E_l<2P_l}`, let `G_l` be configurations in `A_l` that contain a `P_l` box, and let `B_l^bad=A_l\setminus G_l`. If `W` denotes aggregate histogram weight, then summing the exact fiber estimate over all targets gives

\[
W(B_l^{bad})
\le
(ch+o(1))W(G_l).
\tag{6.27}
\]

After normalization by the conditioned partition function,

\[
P(B_l^{bad})
\le
(ch+o(1))P(G_l).
\tag{6.28}
\]

Since `P(A_l)->1`,

\[
P(G_l)+P(B_l^{bad})=1-o(1).
\]

Thus

\[
\boxed{
\liminf_lP(G_l)
\ge
\frac1{1+ch}.
}
\tag{6.29}
\]

On `G_l`, `Y_(1)>=P_l`; using (6.7),

\[
\liminf_l E[Y_{(1)}/n_l]
\ge
\frac{c}{1+ch}.
\tag{6.30}
\]

This proves (6.5). `square`

\tag{7.1}

\frac{(\lambda-\nu)^2}{64}.

\tag{7.2}

This is the strongest useful output of the run.

# 8. Counterexample checks before transfer

The exact histogram comparison is summed inside the actual conditioned partition function. No conditional estimate is silently promoted without its normalization.
