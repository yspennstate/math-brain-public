## 1. The fixed-law strict-record envelope

Put

\[
q_k:=k\pi_k=\nu\bar q_k.
\]

Choose once and for all `c_0>0` so small that

\[
0<c_0q_k<1
\]

for every positive support point. Define

\[
r(x):=
\min_{1\le k\le x,\ q_k>0}
\frac{-\log(c_0q_k)}{k}.
\tag{1.1}
\]

Let

\[
R_1<R_2<\cdots
\]

be the strict record points where `r` decreases, and put

\[
h_j:=r(R_j),\qquad
A_j:=R_jh_j=-\log(c_0q_{R_j}).
\tag{1.2}
\]

Because the normalized generating radius is one,

\[
h_j\downarrow0.
\tag{1.3}
\]

Because `sum_k q_k=nu<infinity`,

\[
q_{R_j}\to0,
\]

and hence

\[
\boxed{A_j\to\infty.}
\tag{1.4}
\]

The previous record theorem proved that for every `U_j->infinity` with `U_j/R_j->0`,

\[
\limsup_j R_j(r(U_j)-r(R_j))=+\infty.
\]

The next theorem strengthens the scale from the macroscopic record `R_j` down to the sublinear cap itself.

# 2. New deterministic theorem: cap-scaled record advantage diverges

## Theorem 2.1

Let `U_j` be any deterministic sequence with

\[
U_j\to\infty,
\qquad
\frac{U_j}{R_j}\to0.
\tag{2.1}
\]

Then

\[
\boxed{
\limsup_{j\to\infty}
U_j\bigl(r(U_j)-r(R_j)\bigr)=+\infty.
}
\tag{2.2}
\]

Thus the record advantage is not merely unbounded in *total* after multiplication by `R_j`; along a subsequence it is unbounded even after multiplication by the much smaller cap `U_j`.

### Proof

Let `i(j)` be the last strict-record index with

\[
R_{i(j)}\le U_j.
\]

Then

\[
r(U_j)=h_{i(j)},
\qquad
i(j)\to\infty.
\tag{2.3}
\]

Since `U_j/R_j->0`, eventually

\[
R_{i(j)}\le U_j\le R_j/2.
\tag{2.4}
\]

Assume contrariwise that (2.2) fails. Then for some finite `C` and all sufficiently large `j`,

\[
U_j(h_{i(j)}-h_j)\le C.
\tag{2.5}
\]

Because `R_{i(j)}<=U_j`, this implies

\[
h_{i(j)}-h_j
\le
\frac{C}{R_{i(j)}}.
\tag{2.6}
\]

Fix a large starting record index `j_0=j` and recursively define

\[
j_{s+1}=i(j_s).
\tag{2.7}
\]

For all indices in the asymptotic range, (2.4) gives

\[
R_{j_{s+1}}\le\frac12R_{j_s}.
\tag{2.8}
\]

Set

\[
X_j=h_j^{-1/2}.
\tag{2.9}
\]

Then `X_j->infinity`, and

\[
\frac{R_j}{X_j}
=R_j\sqrt{h_j}
=\frac{A_j}{\sqrt{h_j}}
\to\infty,
\tag{2.10}
\]

using (1.3)–(1.4). Hence `R_j>X_j` eventually.

Stop the recursion at the first index `L` with

\[
R_{j_L}\le X_j.
\tag{2.11}
\]

For `s<L`, summing (2.6) and using the geometric decrease (2.8),

\[
\begin{aligned}
h_{j_L}-h_j
&\le
C\sum_{s=0}^{L-1}\frac1{R_{j_{s+1}}}\\
&\le
\frac{2C}{R_{j_L}}.
\end{aligned}
\tag{2.12}
\]

Therefore

\[
A_{j_L}
=R_{j_L}h_{j_L}
\le
R_{j_L}h_j+2C
\le
X_jh_j+2C
=\sqrt{h_j}+2C.
\tag{2.13}
\]

The right side is bounded.

It remains only to check that `j_L->infinity`. The previous index satisfies

\[
R_{j_{L-1}}>X_j\to\infty,
\]

so `j_{L-1}->infinity`; then `U_{j_{L-1}}->infinity`, and therefore the last record below that cap, namely `j_L=i(j_{L-1})`, also tends to infinity. This contradicts `A_i->infinity` in (1.4). QED.

### Interpretation

If

\[
G_j:=R_j(r(U_j)-r(R_j)),
\]

then Theorem 2.1 says that along a subsequence

\[
\boxed{
\frac{G_j}{R_j/U_j}
=U_j(r(U_j)-r(R_j))
\to\infty.
}
\tag{2.14}
\]

So the total record advantage dominates **any fixed constant times the minimum number `R_j/U_j` of cap-sized fragments needed to carry record mass**.

# 3. New uniform-band record theorem

The actual no-condensation cloud does not live at one deterministic fragment scale. It occupies the entire band `(L_n,U_n]`. The cap-scaled theorem can be upgraded uniformly over every scale in such a band.

## Theorem 3.1

Let `L_j,U_j` satisfy

\[
L_j\to\infty,
\qquad
L_j\le U_j,
\qquad
\frac{U_j}{R_j}\to0.
\tag{3.1}
\]

Define

\[
\Gamma_j
:=
\inf_{L_j\le x\le U_j}
 x\bigl(r(x)-r(R_j)\bigr).
\tag{3.2}
\]

Then

\[
\boxed{
\limsup_{j\to\infty}\Gamma_j=+\infty.
}
\tag{3.3}
\]

### Proof

If (3.3) failed, choose for each sufficiently large `j` an integer `V_j in [L_j,U_j]` within `1/j` of the infimum. Then

\[
V_j\to\infty,
\qquad
V_j/R_j\to0,
\]

while

\[
V_j(r(V_j)-r(R_j))
\]

would remain bounded. This contradicts Theorem 2.1. QED.

Hence there is a subsequence, retained below without relabelling, on which

\[
\boxed{\Gamma_j\to\infty.}
\tag{3.4}
\]

This is stronger than applying Theorem 2.1 only at the upper cap: on the selected record subsequence, **every single intermediate fragment scale** from `L_j` through `U_j` has an unbounded per-fragment record disadvantage.

# 4. New raw fragmentation-energy inequality

Fix the subsequence on which `Gamma_j->infinity`. Let `k` be any positive support point satisfying

\[
L_j\le k\le U_j.
\]

By definition of `r(k)`,

\[
\frac{-\log(c_0q_k)}k\ge r(k).
\]

By (3.2),

\[
k(r(k)-h_j)\ge\Gamma_j.
\]

Therefore

\[
\boxed{
-\log(c_0q_k)
\ge
k h_j+\Gamma_j
\qquad
(L_j\le k\le U_j).
}
\tag{4.1}
\]

At the record itself,

\[
-\log(c_0q_{R_j})=R_jh_j.
\tag{4.2}
\]

Now take any supported fragment sizes

\[
k_1,\dots,k_t\in[L_j,U_j]
\]

with total mass at least the record mass,

\[
\sum_{a=1}^t k_a\ge R_j.
\tag{4.3}
\]

Summing (4.1) and comparing with (4.2) gives

\[
\log\frac{q_{R_j}}{\prod_{a=1}^tq_{k_a}}
\ge
 t\Gamma_j+(t-1)\log c_0.
\tag{4.4}
\]

Since `log c_0` is a fixed negative constant and `Gamma_j->infinity`, eventually

\[
\boxed{
\frac{q_{R_j}}{\prod_{a=1}^tq_{k_a}}
\ge
\exp\{\tfrac12 t\Gamma_j\}.
}
\tag{4.5}
\]

Thus, **at the raw size-biased fixed-law weight level, one macroscopic strict record eventually beats every particular fragmentation of at least the same mass into actual cloud-band pieces by an exponential factor whose exponent is a diverging amount per fragment**.

This statement has no probability/local-limit input and no assumption on how many fragment sizes are available. It identifies the remaining difficulty precisely: a hypothetical counterexample can survive only through the aggregate entropy/number of possible fragmentation paths and through exact-sum residual alignment, not because individual cloud fragments remain energetically competitive with the macroscopic record.

# 5. New integrated band inequality

Equation (4.1) can also be summed over all possible fragment sizes without counting the support explicitly.

Since

\[
\bar q_k=q_k/\nu,
\]

(4.1) yields

\[
\bar q_k
\le
\frac1{c_0\nu}
 e^{-\Gamma_j}e^{-h_jk}
\qquad
(L_j\le k\le U_j).
\tag{5.1}
\]

Therefore

\[
\begin{aligned}
Q(L_j,U_j)
&=\sum_{L_j<k\le U_j}\bar q_k\\
&\le
\frac1{c_0\nu}e^{-\Gamma_j}
\sum_{k>L_j}e^{-h_jk}\\
&\le
C_0 e^{-\Gamma_j}
\frac{e^{-h_jL_j}}{1-e^{-h_j}}.
\end{aligned}
\tag{5.2}
\]

Writing

\[
\beta_j:=-\log Q(L_j,U_j),
\]

we obtain

\[
\boxed{
\Gamma_j+h_jL_j
\le
\beta_j
-\log(1-e^{-h_j})
+C_1.
}
\tag{5.3}
\]

Because `h_j->0`,

\[
-\log(1-e^{-h_j})
=\log\frac1{h_j}+O(1).
\tag{5.4}
\]

Hence

\[
\boxed{
\Gamma_j+h_jL_j
\le
\beta_j+\log\frac1{h_j}+O(1).
}
\tag{5.5}
\]

This is an integrated version of the strict-record obstruction. Internal support multiplicity in the whole band has already been summed out; its maximal possible contribution appears only through the geometric factor `(1-e^{-h_j})^{-1}`.

# 6. Apply the uniform theorem to a hypothetical full counterexample

Assume for contradiction analysis that

\[
Y_{(1)}/n\to_p0.
\tag{6.1}
\]

Choose a deterministic high-probability cap `U_n=o(n)` and enlarge it, if necessary, so that

\[
U_n\ge2L_n
\]

while still `U_n=o(n)`.

At every strict record `R_j`, use the checked first-crossing construction from the Gaussian-Harnack report to choose an admissible `n_j` such that

\[
R_j/n_j\to\delta:=\lambda-\nu>0.
\tag{6.2}
\]

Then

\[
\frac{U_{n_j}}{R_j}\to0,
\qquad
L_{n_j}\to\infty.
\tag{6.3}
\]

Apply Theorem 3.1 with

\[
L_j:=L_{n_j},
\qquad
U_j:=U_{n_j}.
\]

There is a strict-record subsequence on which

\[
\boxed{
\Gamma_j:=
\inf_{L_{n_j}\le x\le U_{n_j}}
 x(r(x)-r(R_j))
\to\infty.
}
\tag{6.4}
\]

On the other hand, the ordinary-Palm actual amplified-band theorem from the previous checkpoint gives

\[
\boxed{
\beta_j:=-\log Q(L_{n_j},U_{n_j})=o(b_{n_j}).
}
\tag{6.5}
\]

Combining (5.5) and (6.5) yields the new necessary condition

\[
\boxed{
\Gamma_j+h_jL_{n_j}
\le
 o(b_{n_j})+\log\frac1{h_j}+O(1).
}
\tag{6.6}
\]

Since

\[
h_j=A_j/R_j,
\]

this can be rewritten in the especially transparent form

\[
\boxed{
\Gamma_j
+\frac{L_{n_j}}{R_j}A_j
+\log A_j
\le
 o(b_{n_j})+\log R_j+O(1).
}
\tag{6.7}
\]

Equation (6.7) is a new synchronization constraint on every hypothetical full counterexample. Along a subsequence it must simultaneously pay:

1. an **unbounded uniform record gap** `Gamma_j` across *every* actual cloud scale;
2. the amplified-baseline term `(L/R)A_j`;
3. the macroscopic record coding term `log A_j`;

while the only available compensation is the subexponential actual-band cost `o(b_n)` plus the universal geometric entropy `log R_j`.

# 7. New macroscopic record-cost bound under full no-condensation

Equation (6.7) also gives a quantitative upper bound on the cost of every synchronized macroscopic strict record.

All terms on the left are eventually nonnegative. Hence

\[
\frac{L_{n_j}}{R_j}A_j
\le
 o(b_{n_j})+\log R_j+O(1).
\tag{7.1}
\]

The amplified scale satisfies

\[
L_n=\mathcal R_n\frac{n}{b_n}(1+o(1)),
\]

while `R_j/n_j->delta`. Thus

\[
\frac{L_{n_j}}{R_j}
=\frac{\mathcal R_{n_j}}{\delta b_{n_j}}(1+o(1)).
\tag{7.2}
\]

The retained anti-concentration bound

\[
b_n\ge\tfrac12\log n-O(1)
\]

implies

\[
\log R_j=O(b_{n_j}).
\tag{7.3}
\]

Therefore every hypothetical full counterexample must satisfy, at all sufficiently large synchronized strict records,

\[
\boxed{
A_j
=O\!\left(
\frac{b_{n_j}^2}{\mathcal R_{n_j}}
\right).
}
\tag{7.4}
\]

Because `\mathcal R_n->infinity`, this is strictly stronger than the crude `A_j=O(b_n^2)` scale:

\[
\boxed{A_j=o(b_{n_j}^2).}
\tag{7.5}
\]

The bound is not yet enough to force `A_j=O(b_n)`, because the amplified-cloud theorem only guarantees `\mathcal R_n=o(b_n)` and may grow arbitrarily slowly.

Still, (7.4) is a new quantitative restriction linking three previously separate objects: the cost of a macroscopic record, the exact conditioning cost, and the strongest rigorously available amplified-cloud cutoff.

# 8. What this does and does not resolve

The new deterministic theorem materially strengthens the previous record result:

\[
R_j(r(U_j)-r(R_j))\to\infty\ \text{along a subsequence}
\]

is replaced by

\[
U_j(r(U_j)-r(R_j))\to\infty
\]

along a subsequence, and then by the uniform-band statement

\[
\inf_{L_j\le x\le U_j}x(r(x)-r(R_j))\to\infty
\]

along a further subsequence.

Consequently, no individual fragment scale in the actual amplified cloud can stay energetically competitive with the macroscopic record. Equation (4.5) quantifies this by a diverging exponential advantage **per fragment**.

However, this still does not close Problem 18.39. Two genuinely uncontrolled mechanisms remain:

1. **Aggregate path entropy.** Although each fixed fragmentation path is crushed by (4.5), there may be extremely many supported fragmentation paths. Summing (4.1) only gives the geometric compensation `(1-e^{-h_j})^{-1}`, which appears as `log(1/h_j)` in (6.6). The present argument does not show that `Gamma_j` dominates that term.
2. **Exact residual alignment.** The one-giant Harnack lower bound still contains the sublinear crossing/alignment cost. The uniform band theorem does not by itself prove that its record advantage dominates every possible admissible `m_n/n->lambda` centering irregularity.

Thus the correct status remains **PARTIAL**. No universal proof and no fixed-law full-sequence counterexample is obtained.

A useful new sufficient closure criterion is now explicit: if along the uniform-gap record subsequence either

\[
\Gamma_j-\log(1/h_j)\to+\infty
\]

fast enough to dominate the residual Harnack/alignment loss, or if an independent estimate improves the amplified diagonal so that (7.4) forces `A_j<=b_{n_j}-` the residual local cost, then the exact one-giant lower bound from the `22-30-00Z` checkpoint yields persistent macroscopic condensation.

# 10. Next attack

The sharp next target is now an **entropy-sensitive record theorem**.

The fixed-law inequality (4.1) says that throughout the actual cloud band

\[
\bar q_k\lesssim e^{-\Gamma_j}e^{-h_jk}.
\]

The remaining geometric entropy is exactly

\[
(1-e^{-h_j})^{-1}\asymp h_j^{-1}.
\]

Thus a decisive deterministic strengthening would be to prove, on some synchronized record subsequence,

\[
\Gamma_j-\log(1/h_j)\to+\infty,
\]

or a weaker integrated statement sufficient after multiplication by the number of cloud fragments. This is not implied by the present record axioms alone in any obvious way, and constructing extremal record sequences where the two terms nearly balance is also a useful counterexample-search direction.

A second attack is to exploit the actual fixed probability law rather than the worst-case geometric sum: if most values in `[L_n,U_n]` lie substantially above the record envelope, the true truncated exponential sum is much smaller than `1/h_j`, and (6.6) strengthens automatically. The only hard case is therefore a law carrying many near-envelope support points across the entire sublinear cloud band.

That near-envelope-rich case should be attacked separately by a multi-atom forced-sum/local-smoothing argument, because dense cheap support is precisely the regime where residual exact-sum alignment ought to become easier.
