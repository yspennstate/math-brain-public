# 1. The excess-size probability law

Put

\[
q_k:=k\pi_k.
\]

Define the tilted amplified-band mass

\[
D_n:=\sum_{L_n<k\le U_n} q_ke^{s_nk}.
\tag{1.1}
\]

By the retained canonical band saturation,

\[
\boxed{D_n=\delta+o(1).}
\tag{1.2}
\]

In particular, `D_n` is bounded above and below by positive constants for all sufficiently large `n`.

Define a probability law on the actual amplified band by

\[
\boxed{
\mu_n(k):=\frac{q_ke^{s_nk}}{D_n},
\qquad L_n<k\le U_n.
}
\tag{1.3}
\]

This has a useful direct interpretation: `mu_n` is the distribution of a box size when the capped canonical law is size-biased by its contribution to the **excess first moment** in the amplified band.

Let

\[
M_n:=E_{\mu_n}K
=\frac{\sum_{L_n<k\le U_n} kq_ke^{s_nk}}{D_n}.
\tag{1.4}
\]

Since `q_k=k pi_k`, the numerator is

\[
\sum_{L_n<k\le U_n}k^2\pi_ke^{s_nk}.
\]

Also

\[
\sum_{k\le U_n}k^2\pi_ke^{s_nk}
=F_n(s_n)E_n^{\rm can}X^2
=(1+o(1))(\sigma_n^2+\lambda_n^2).
\]

Using (1.2),

\[
\boxed{
L_n<M_n\le C(1+\sigma_n^2).
}
\tag{1.5}
\]

Since the retained variance lower bound has `sigma_n^2 >= c L_n -> infinity`, this may be simplified to

\[
\boxed{M_n\le C\sigma_n^2.}
\tag{1.6}
\]

Thus the variance controls the **mean physical scale of the canonical excess fragments**.

# 2. An endogenous variance-scale cutoff carrying half the excess

Define

\[
\boxed{
V_n:=\lceil 2M_n\rceil.
}
\tag{2.1}
\]

By (1.5)–(1.6),

\[
\boxed{
2L_n<V_n\le C\sigma_n^2=o(n).
}
\tag{2.2}
\]

The strict inequality `2L_n<V_n` is eventually valid because every `mu_n`-support point is strictly larger than `L_n`, hence `M_n>L_n`.

Markov's inequality under `mu_n` gives

\[
\mu_n(K>2M_n)\le\frac12.
\]

Therefore at least half of the entire canonical excess first moment already lies below `V_n`:

\[
\boxed{
\sum_{L_n<k\le V_n}q_ke^{s_nk}
\ge \frac12D_n
\ge \frac{\delta}{3}
}
\tag{2.3}
\]

for all sufficiently large `n`.

This is the first new structural point of the run. The arbitrary cap `U_n` can be discarded in the saturation argument: a fixed fraction of the supercritical excess is necessarily realized in the **endogenous interval**

\[
(L_n,V_n],\qquad V_n=O(\sigma_n^2)=o(n).
\]

There is also a count consequence. Let

\[
p_n^{\rm eff}
:=\Pr_n^{\rm can}(L_n<X\le V_n).
\]

Since `k<=V_n` on the interval,

\[
\begin{aligned}
p_n^{\rm eff}
&=\frac1{F_n(s_n)}
  \sum_{L_n<k\le V_n}\pi_ke^{s_nk}\\
&=\frac1{F_n(s_n)}
  \sum_{L_n<k\le V_n}\frac{q_k}{k}e^{s_nk}\\
&\ge \frac{1}{F_n(s_n)V_n}
  \sum_{L_n<k\le V_n}q_ke^{s_nk}.
\end{aligned}
\]

Using (2.3), `F_n(s_n)->1`, and `V_n<=C sigma_n^2`,

\[
\boxed{
p_n^{\rm eff}\ge \frac{c}{\sigma_n^2}.}
\tag{2.4}
\]

Consequently

\[
\boxed{
np_n^{\rm eff}\ge c\frac n{\sigma_n^2}\longrightarrow\infty,
}
\tag{2.5}
\]

because `sigma_n^2=o(n)`.

Thus every hypothetical full counterexample contains a diverging expected number of canonical excess-carrying boxes already below `O(sigma_n^2)`. The near-envelope-rich regime is not allowed to hide solely near the arbitrary cap `U_n`.

# 3. Synchronization to macroscopic strict records at the variance scale

Retain the strict lower-rate envelope

\[
r(x)
:=\min_{\substack{1\le k\le x\\q_k>0}}
\frac{-\log(c_0q_k)}{k},
\tag{3.1}
\]

where fixed `c_0>0` is chosen so `c_0 q_k<1` on the positive support.

Let

\[
R_1<R_2<\cdots
\]

be strict record locations and

\[
h_j:=r(R_j).
\tag{3.2}
\]

Use the already checked Gaussian-Harnack first-crossing synchronization to choose admissible indices `n_j` satisfying

\[
\frac{R_j}{n_j}\to\delta.
\tag{3.3}
\]

Write

\[
L_j:=L_{n_j},\qquad
V_j:=V_{n_j},\qquad
s_j:=s_{n_j},\qquad
\sigma_j^2:=\sigma_{n_j}^2.
\]

By (2.2),

\[
L_j\to\infty,\qquad
L_j\le V_j,\qquad
\frac{V_j}{R_j}\to0.
\tag{3.4}
\]

Therefore the previously proved **uniform cap-scaled record-gap theorem** applies to the interval `[L_j,V_j]`. After passage to a strict-record subsequence,

\[
\boxed{
\Gamma_j^{\rm var}
:=\inf_{L_j\le x\le V_j}
 x\bigl(r(x)-h_j\bigr)
\longrightarrow\infty.
}
\tag{3.5}
\]

This is stronger for the current purpose than the earlier gap over `[L_j,U_j]`: the upper endpoint is now `O(sigma_j^2)` and is generated by the canonical law itself.

For every supported integer `k` with `L_j<k<=V_j`, (3.5) gives

\[
k(r(k)-h_j)\ge \Gamma_j^{\rm var}.
\]

Since the point rate at `k` is at least `r(k)`,

\[
\boxed{
q_k\le c_0^{-1}
\exp\{-h_jk-\Gamma_j^{\rm var}\}.
}
\tag{3.6}
\]

# 4. Entropy compression of the near-envelope-rich branch

Define the truncated effective tilted mass

\[
D_j^{\rm var}
:=\sum_{L_j<k\le V_j}q_ke^{s_jk}.
\tag{4.1}
\]

By (2.3),

\[
\boxed{D_j^{\rm var}\ge\delta/3}
\tag{4.2}
\]

for all large `j`. It is also bounded above by `D_{n_j}=delta+o(1)`.

Normalize this effective interval:

\[
\boxed{
\mu_j^{\rm var}(k)
:=\frac{q_ke^{s_jk}}{D_j^{\rm var}},
\qquad L_j<k\le V_j.
}
\tag{4.3}
\]

Let

\[
M_j^{\rm var}:=E_{\mu_j^{\rm var}}K.
\]

Then trivially

\[
\boxed{M_j^{\rm var}\le V_j\le C\sigma_j^2.}
\tag{4.4}
\]

From the record barrier (3.6),

\[
\mu_j^{\rm var}(k)
\le
\frac{c_0^{-1}}{D_j^{\rm var}}
\exp\{-\Gamma_j^{\rm var}+(s_j-h_j)k\}.
\]

Equivalently,

\[
-\log \mu_j^{\rm var}(k)
\ge
\Gamma_j^{\rm var}
+(h_j-s_j)k
+\log(c_0D_j^{\rm var}).
\tag{4.5}
\]

Average (4.5) under `mu_j^var`. Writing `H(mu)` for Shannon entropy,

\[
H(\mu_j^{\rm var})
\ge
\Gamma_j^{\rm var}
+(h_j-s_j)M_j^{\rm var}
+\log(c_0D_j^{\rm var}).
\]

Since `D_j^var` is bounded above and below by fixed positive constants,

\[
\boxed{
\Gamma_j^{\rm var}
\le
H(\mu_j^{\rm var})
+(s_j-h_j)_+M_j^{\rm var}
+C.
}
\tag{4.6}
\]

Now use the elementary maximum-entropy bound for a nonnegative integer-valued random variable of mean `M`:

\[
H(Z)
\le
(M+1)\log(M+1)-M\log M
\le
\log(e(M+1)).
\tag{4.7}
\]

For completeness, (4.7) follows immediately from nonnegativity of KL divergence relative to the geometric law having the same mean; no asymptotic theorem is required.

Using (4.4),

\[
H(\mu_j^{\rm var})
\le
\log\bigl(C(1+\sigma_j^2)\bigr).
\tag{4.8}
\]

Combining (4.6)–(4.8) gives the main theorem of this run.

## Theorem 4.1 — variance-scale record/entropy obstruction

Under hypothetical full no-condensation, along the synchronized strict-record subsequence on which (3.5) holds,

\[
\boxed{
\Gamma_j^{\rm var}
\le
\log\bigl(C(1+\sigma_j^2)\bigr)
+C\sigma_j^2(s_j-h_j)_+
+C.
}
\tag{4.9}
\]

The older support-count inequality had the form

\[
\Gamma_j
\lesssim
(s_j-h_j)_+U_j+\log N_j^{\rm supp}.
\]

Equation (4.9) is substantially sharper in the difficult rich-support branch:

- the arbitrary cap `U_j` is replaced by the endogenous variance scale `sigma_j^2`;
- raw support cardinality is replaced by at most logarithmic **Shannon entropy**, `O(log sigma_j^2)`;
- at least a fixed fraction of the actual canonical excess is known to live inside the interval on which the estimate is applied.

# 5. A cap-free necessary variance lower bound

The parent report proved

\[
ns_n=O(b_n).
\tag{5.1}
\]

Since `h_j>=0`,

\[
(s_j-h_j)_+\le s_j\le C\frac{b_{n_j}}{n_j}.
\tag{5.2}
\]

Insert (5.2) into (4.9):

\[
\boxed{
\Gamma_j^{\rm var}
\le
C+\log\bigl(C(1+\sigma_j^2)\bigr)
+C\frac{b_{n_j}\sigma_j^2}{n_j}.
}
\tag{5.3}
\]

Equivalently,

\[
\boxed{
\sigma_j^2
\ge
\frac{n_j}{Cb_{n_j}}
\Bigl[
\Gamma_j^{\rm var}
-C\log(1+\sigma_j^2)-C
\Bigr]_+.
}
\tag{5.4}
\]

Thus a record gap that outruns the intrinsic entropy `log sigma_j^2` forces the canonical variance itself upward on the natural scale `n/b_n`.

Since

\[
L_{n_j}
=(1+o(1))\mathcal R_{n_j}\frac{n_j}{b_{n_j}},
\]

(5.4) may also be written schematically as

\[
\frac{\sigma_j^2}{L_{n_j}}
\gtrsim
\frac{
[\Gamma_j^{\rm var}-C\log(1+\sigma_j^2)-C]_+
}{\mathcal R_{n_j}}.
\tag{5.5}
\]

This is a genuine new feedback relation between the strict-record gap and the canonical variance. If the record gap becomes large faster than the entropy allowance, the fragmented canonical mechanism is forced to migrate to larger and larger variance scales.

# 6. Record-to-giant leverage from excess gap beyond entropy

Equation (4.9) also yields a direct lower bound on the positive saddle-record separation. If

\[
\Gamma_j^{\rm var}
>\log\bigl(C(1+\sigma_j^2)\bigr)+C,
\]

then

\[
\boxed{
(s_j-h_j)_+
\ge
\frac{
\Gamma_j^{\rm var}
-\log(C(1+\sigma_j^2))-C
}{C\sigma_j^2}.
}
\tag{6.1}
\]

Multiplying by `n_j`,

\[
\boxed{
 n_j(s_j-h_j)_+
\ge
c\frac{n_j}{\sigma_j^2}
\Bigl[
\Gamma_j^{\rm var}
-C\log(1+\sigma_j^2)-C
\Bigr]_+.
}
\tag{6.2}
\]

Because `sigma_j^2=o(n_j)`, the amplification factor

\[
\frac{n_j}{\sigma_j^2}\to\infty.
\]

Thus any strict-record advantage that cannot be paid purely by variance-scale entropy is magnified into a much larger **macroscopic saddle advantage**. This is exactly the quantity entering the archived one-giant comparison through

\[
\delta n_js_j-R_jh_j
\]

up to the already recorded first-crossing alignment term.

Combining (6.2) with the parent report's synchronized one-giant necessary inequality gives the following explicit closure criterion: if along a synchronized strict-record subsequence

\[
\frac{n_j}{\sigma_j^2}
\Bigl[
\Gamma_j^{\rm var}
-C\log(1+\sigma_j^2)-C
\Bigr]_+
\]

dominates the previously archived Gaussian-Harnack/alignment loss and the unavoidable logarithmic lattice penalty, then full no-condensation is impossible on that subsequence.

This is still a conditional closure criterion, not a universal proof, because the bracket in (6.2) may remain nonpositive if the near-envelope-rich band supplies entropy of order `Gamma_j^var`.

# 7. Why this narrows the surviving hard case

The previous checkpoint left a qualitative variance-versus-record dichotomy. The present report makes the rich branch substantially more rigid.

A hypothetical full-sequence counterexample must now satisfy **all** of the following simultaneously along synchronized macroscopic records:

1. `Gamma_j^var -> infinity` on the endogenous interval
   \[
   (L_j,V_j],\qquad V_j=O(\sigma_j^2)=o(n_j);
   \]
2. a fixed fraction of the supercritical canonical excess lies in that interval:
   \[
   \sum_{L_j<k\le V_j}q_ke^{s_jk}\ge\delta/3;
   \]
3. the canonical expected number of boxes using that interval diverges:
   \[
   n_j\Pr^{can}(L_j<X\le V_j)
   \ge c n_j/\sigma_j^2\to\infty;
   \]
4. nevertheless the record barrier can only be paid by
   \[
   O(\log\sigma_j^2)
   \]
   of entropy plus
   \[
   O(\sigma_j^2(s_j-h_j)_+)
   \]
   of saddle lift.

So the formerly vague "many near-envelope support points" escape is now compressed to a variance-scale probability law with controlled mean and controlled entropy.

The most promising next attack is to exploit (2.5) together with the fixed Bernoulli smoothing component. There are now `n/sigma_n^2 -> infinity` expected canonical excess fragments in an interval of width `O(sigma_n^2)`. A local exact-sum estimate that uses these fragments in addition to the fixed Bernoulli part should improve the current variance-loss bound

\[
\ell_n\le \tfrac12\log n+C\sigma_n^2+O(1).
\]

If that improvement reduces the local defect below the macroscopic amplification in (6.2), the one-giant record comparison closes. The key point is that any such argument can now work entirely at the **endogenous variance scale**, without reference to the arbitrary cap `U_n`.
