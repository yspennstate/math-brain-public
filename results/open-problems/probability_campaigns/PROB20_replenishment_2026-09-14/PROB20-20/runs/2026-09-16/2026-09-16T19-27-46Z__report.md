## 2. Exact source statement and fixed-law target

Primary source rechecked on 2026-09-16 from Janson's PDF, page 122 (PDF index 121). The source asks:

> **Problem 18.39.** Is `Y_(1)/n ->_p 0` possible when `0<nu<lambda`?

Janson immediately says that Example 18.36 makes this possible on a subsequence, conjectures that it is not possible for the full sequence, and conjectures more strongly that there are some fixed `epsilon>0` and some subsequence along which `Y_(1)>epsilon n` w.h.p. Problem 18.40 is stated separately for `lambda>nu=0`.

The fixed weighted-allocation law is

\[
\mathbb P(Y_1=y_1,\dots,Y_n=y_n\mid \sum_iY_i=m)
\propto \prod_{i=1}^n w_{y_i},
\qquad \sum_i y_i=m,
\]

for one fixed weight sequence `w`. With

\[
\Phi(t)=\sum_{k\ge0}w_kt^k,\qquad
\nu=\lim_{t\uparrow\rho}\frac{t\Phi'(t)}{\Phi(t)},
\]

the present target is the supercritical fixed-law regime

\[
0<\nu<\Lambda,\qquad m_n/n\to\Lambda.
\tag{2.1}
\]

Only when the finite-mean boundary normalization is valid I write

\[
\pi_k=\frac{w_k\rho^k}{\Phi(\rho)},\qquad E_\pi X=\nu.
\tag{2.2}
\]

Conditioning iid copies of `pi` on their sum being `m` gives exactly the same allocation law because the common factor cancels on the sum hyperplane.

Janson's Example 18.36 is an essential counterexample check on any proposed transfer: one and the same fixed irregular law has a subsequence with `Y_(1)/n -> 0` and another with two boxes of size `n/3`. Therefore neither a dust subsequential limit nor a one-giant subsequential limit can by itself control the full sequence.

## 3. Counterexample-first checks on the new route

Before stating a theorem I tested what a new method must survive.

### 3.1 Exact-atom local big-jump comparison is too strong

The preceding run already identified the obstruction for stretched-exponential tails with exponent above the simplest local-big-jump threshold: the condensate can be shifted from the nominal excess by a mesoscopic `o(n)` amount while still having macroscopic size `(Lambda-nu)n+o(n)`. Thus I do not try to prove

\[
P(S_n=m_n)\sim n\pi_{\lfloor(\Lambda-\nu)n\rfloor}
\]

as a universal intermediate goal.

### 3.2 Concavity cannot be dropped

Janson's Example 18.36 has sparse, highly irregular weights and demonstrates exactly why a chord comparison for `-log pi_k` cannot hold in the arbitrary source class. The theorem below explicitly retains concavity as an extra hypothesis and is therefore only PARTIAL.

### 3.3 Near-linear concave hazards expose the limit of the present argument

The eventually concave sublinear function

\[
h(x)=\frac{x}{\log x}
\]

has logarithmic elasticity

\[
\frac{x h'(x)}{h(x)}=1-\frac1{\log x}\to1.
\]

For every fixed `0<t<delta`,

\[
\frac{\delta h(tn)}{t h(\delta n)}\to1.
\]

Thus the strict scale gap used below vanishes. This is a real remaining obstruction, not a proof artefact hidden by notation. The next universal attack should focus on this near-linear concave-hazard boundary or on still more irregular laws.

## 4. B18 — rewrite the source event as a cap-versus-partition-function inequality

Let `X_1,...,X_n` be iid with boundary law `pi`, `S_n=sum X_i`, and

\[
M_n=\max_iX_i,\qquad \delta=\Lambda-\nu>0,
\qquad B_n=-\log P(S_n=m_n).
\]

For an integer cap `K` define the defective truncated exponential transform

\[
F_K(s)=\sum_{k\le K}\pi_ke^{sk},\qquad s\ge0,
\]

and the associated capped dual rate

\[
I_K(x)=\sup_{s\ge0}\{xs-\log F_K(s)\}.
\tag{4.1}
\]

Coefficient positivity gives, for every `s>=0`,

\[
P(S_n=m_n,\,M_n\le K)
\le e^{-sm_n}F_K(s)^n,
\]

and hence

\[
P(M_n\le K\mid S_n=m_n)
\le \exp\{B_n-nI_K(m_n/n)\}.
\tag{4.2}
\]

This elementary inequality is the dual language used below. It asks only whether an entire cap `M_n<=tn` is too expensive; it never asks which exact giant atom dominates the coefficient.

## 5. B5 — add the macroscopic cap parameter and differentiate the logarithmic hazard

Consider the following fixed-law class.

### Definition 5.1 (concave-hazard fixed law)

Let

\[
w_k=e^{-h(k)},\qquad k\in\mathbb Z_{\ge0},
\tag{5.1}
\]

where `h:[0,infinity)->[0,infinity)` satisfies

1. `h(0)=0`;
2. `h` is nondecreasing and concave;
3. `h(x)/x -> 0`;
4. `h(x)/log(2+x) -> infinity`.

Then the radius is `rho=1`, `Phi(1)<infinity`, every polynomial moment of the boundary law is finite, and

\[
0<\nu=\frac{\sum_kk e^{-h(k)}}{\sum_ke^{-h(k)}}<\infty.
\]

For `0<t<delta` define the cap-separation ratio

\[
R_h(t):=\liminf_{n\to\infty}
\frac{\delta\,h(tn)}{t\,h(\delta n)}.
\tag{5.2}
\]

and

\[
b_h(w,\Lambda):=\sup\{t\in(0,\delta):R_h(t)>1\},
\tag{5.3}
\]

with the supremum of the empty set defined as zero.

### Theorem 5.2 (concave-hazard cap theorem)

For a fixed law (5.1) satisfying Definition 5.1 and every full admissible sequence `m_n/n -> Lambda>nu`,

\[
\boxed{
\liminf_{n\to\infty}E\frac{Y_{(1)}}n
\ge b_h(w,\Lambda).
}
\tag{5.4}
\]

More strongly, for every fixed `t` with `R_h(t)>1`,

\[
P(Y_{(1)}>tn)\to1.
\tag{5.5}
\]

Also, for every `epsilon>0`,

\[
P\bigl(Y_{(1)}>(\delta+\epsilon)n\bigr)\to0.
\tag{5.6}
\]

Thus if `b_h=delta`, then

\[
\boxed{
\frac{Y_{(1)}}n\xrightarrow p\delta,
\qquad
E\frac{Y_{(1)}}n\to\delta.
}
\tag{5.7}
\]

#### Proof

Write

\[
Z=\Phi(1)=\sum_{k\ge0}e^{-h(k)},
\qquad \pi_k=Z^{-1}e^{-h(k)}.
\]

The assumptions `h/log -> infinity` and `h=o(x)` imply respectively that `Z` and every polynomial moment are finite and that `rho=1`. Full support gives span one and positive variance.

Fix `t in (0,delta)` with `R_h(t)>1` and set

\[
K_n=\lfloor tn\rfloor.
\]

Choose a constant `eta in (0,1)` so small that, eventually,

\[
(1-\eta)\frac{\delta h(K_n)}{t h(\delta n)}>1+c
\tag{5.8}
\]

for some `c>0`. Define the test tilt

\[
s_n=(1-\eta)\frac{h(K_n)}{K_n}.
\tag{5.9}
\]

Because `h(x)/x->0`, we have `s_n->0`. Concavity and `h(0)=0` imply that `h(x)/x` is nonincreasing, so for every integer `k<=K_n`,

\[
h(k)\ge \frac{k}{K_n}h(K_n),
\]

and hence

\[
-h(k)+s_nk\le-\eta h(k).
\tag{5.10}
\]

We next compute the truncated transform to first order. Since

\[
\frac{F_{K_n}(s_n)-1}{s_n}
=
\sum_{k\le K_n}\pi_k\frac{e^{s_nk}-1}{s_n}
-\frac{P(X>K_n)}{s_n},
\tag{5.11}
\]

the first term converges to `nu` by dominated convergence: indeed

\[
0\le
\pi_k\frac{e^{s_nk}-1}{s_n}
\le Ck e^{-\eta h(k)},
\]

and the majorant is summable by `h(k)/log k->infinity`. For the omitted tail, Markov's inequality gives

\[
0\le\frac{P(X>K_n)}{s_n}
\le\frac{\nu}{K_ns_n}
=\frac{\nu}{(1-\eta)h(K_n)}\to0.
\]

Therefore

\[
F_{K_n}(s_n)=1+\nu s_n+o(s_n),
\qquad
\log F_{K_n}(s_n)=\nu s_n+o(s_n).
\tag{5.12}
\]

Putting `lambda_n=m_n/n`, (4.1) gives

\[
I_{K_n}(\lambda_n)
\ge (\lambda_n-\nu+o(1))s_n,
\]

so

\[
nI_{K_n}(\lambda_n)
\ge
(1-\eta)\frac{\delta}{t}h(tn)(1+o(1)).
\tag{5.13}
\]

We now lower-bound the exact conditioning probability without any local large-deviation theorem. Let `r_n` be an integer with

\[
|r_n-(n-1)\nu|\le1
\]

and set `k_n=m_n-r_n`. The ordinary lattice local central limit theorem applies because the fixed boundary law has span one and finite positive variance, so

\[
P(S_{n-1}=r_n)\ge c_0n^{-1/2}
\tag{5.14}
\]

for all large `n`. Moreover

\[
k_n=\delta n+o(n).
\]

The one-coordinate event gives

\[
P(S_n=m_n)
\ge \pi_{k_n}P(S_{n-1}=r_n),
\]

hence

\[
B_n\le h(k_n)+\tfrac12\log n+O(1).
\tag{5.15}
\]

For any nondecreasing concave `h` with `h(0)=0`, `h(y)/h(x)->1` whenever `y/x->1`: monotonicity gives one side, while monotonicity of `h(x)/x` gives the other. Thus

\[
h(k_n)=h(\delta n)(1+o(1)).
\]

Since `h(\delta n)/log n->infinity`, (5.15) becomes

\[
B_n\le h(\delta n)(1+o(1)).
\tag{5.16}
\]

Combining (5.8), (5.13), (5.16) with the cap inequality (4.2),

\[
B_n-nI_{K_n}(\lambda_n)
\le -c' h(\delta n)\to-\infty
\]

for some `c'>0`. Hence

\[
P(M_n\le tn\mid S_n=m_n)\to0,
\]

which proves (5.5). Taking expectations and then the supremum over all such `t` proves (5.4).

It remains to prove the upper macroscopic bound (5.6). Fix `epsilon>0`. If `M_n>(\delta+\epsilon)n` and `S_n=m_n`, then after removing a maximal coordinate the remaining `n-1` variables have total at most

\[
(\nu-c_\epsilon)(n-1)
\]

for some fixed `c_epsilon>0` and all large `n` (terms with a negative remainder are simply impossible). Since `X>=0`, an ordinary Chernoff bound with a negative exponential tilt gives

\[
P\bigl(S_{n-1}\le(\nu-c_\epsilon)(n-1)\bigr)\le e^{-c n}
\tag{5.17}
\]

for some `c>0`. A union bound over the possible maximal coordinate therefore yields

\[
P\bigl(S_n=m_n,\,M_n>(\delta+\epsilon)n\bigr)
\le n e^{-cn}.
\tag{5.18}
\]

On the other hand (5.14) and the one-coordinate event give

\[
P(S_n=m_n)\ge\exp\{-h(\delta n+o(n))-O(\log n)\}=e^{-o(n)},
\]

because `h=o(x)`. Dividing (5.18) by this denominator proves (5.6).

If `b_h=delta`, (5.5) for every `t<delta` and (5.6) for every `epsilon>0` imply (5.7) in probability. Finally `0<=Y_(1)/n<=m_n/n=O(1)`, so the expectation converges as well. ∎

## 6. B5 continued — an elasticity condition that forces the exact metric

The scale ratio (5.2) has a clean differential sufficient condition.

### Corollary 6.1 (strict logarithmic elasticity below one)

Assume Definition 5.1 and suppose additionally that `h` is eventually differentiable and

\[
\limsup_{x\to\infty}\frac{x h'(x)}{h(x)}\le\alpha<1.
\tag{6.1}
\]

Then for every `Lambda>nu`, every full admissible sequence satisfies

\[
\boxed{
\frac{Y_{(1)}}n\xrightarrow p\Lambda-\nu,
\qquad
E\frac{Y_{(1)}}n\to\Lambda-\nu.
}
\tag{6.2}
\]

Consequently the frozen lower-bound metric on this class is exactly

\[
\boxed{b(w,\Lambda)=\Lambda-\nu.}
\tag{6.3}
\]

#### Proof

Fix `0<t<delta` and choose `alpha'` with `alpha<alpha'<1`. For large `x`,

\[
\frac{x h'(x)}{h(x)}\le\alpha'.
\]

Integrating `d log h / d log x` from `tn` to `delta n`,

\[
\log\frac{h(\delta n)}{h(tn)}
\le \alpha'\log\frac\delta t.
\]

Therefore

\[
R_h(t)
=\liminf_n\frac{\delta h(tn)}{t h(\delta n)}
\ge\left(\frac\delta t\right)^{1-\alpha'}>1.
\]

This holds for every `t<delta`, so `b_h=delta`, and Theorem 5.2 gives (6.2). ∎

This includes every regularly varying concave hazard of index strictly below one, but regular variation is not required; the only differential requirement is the uniform asymptotic elasticity gap in (6.1).

## 7. A fixed law newly certified by this route

Take

\[
\boxed{w_k=\exp\{-k^{3/4}-k^{2/3}\},\qquad k\ge0.}
\tag{7.1}
\]

Here

\[
h(x)=x^{3/4}+x^{2/3}
\]

is increasing, concave, sublinear, and satisfies `h/log -> infinity`. Moreover

\[
\frac{x h'(x)}{h(x)}
=
\frac{(3/4)x^{3/4}+(2/3)x^{2/3}}
{x^{3/4}+x^{2/3}}
\le\frac34<1.
\]

Thus for this **single fixed weight law**, for every `Lambda>nu` and every full admissible sequence,

\[
\boxed{Y_{(1)}/n\to_p\Lambda-\nu,
\qquad E[Y_{(1)}/n]\to\Lambda-\nu.}
\tag{7.2}
\]

This example is outside the exact classes previously certified in this track:

- it is not locally regularly varying;
- it is not asymptotic to `A exp(-c k^(3/4))`, since the ratio to `exp(-k^(3/4))` is `exp(-k^(2/3))->0`;
- the simplest DDS local shift-insensitivity test at the square-root scale fails: `h'(x)sqrt(x)` is of order `x^(1/4)`, not `o(1)`.

This does **not** establish novelty relative to the whole heavy-tail literature; it establishes that the track's certified fixed-law metric has genuinely expanded beyond its preceding hypotheses.

## 8. B27 — swap the universal quantifier for a pointwise cap criterion, then recover a metric

The source asks for all fixed laws. The present theorem instead proves, for each macroscopic fraction `t`, an explicit sufficient condition `R_h(t)>1` forcing `Y_(1)>tn` w.h.p. Taking the supremum over `t` produces the quantitative lower-bound function (5.3).

This quantifier swap is useful even when it does not give full condensation. It turns a qualitative source question into a computable profile:

\[
\boxed{
 b(w,\Lambda)\ge
 \sup\left\{0<t<\Lambda-\nu:
 \liminf_n
 \frac{(\Lambda-\nu)h(tn)}{t h((\Lambda-\nu)n)}>1
 \right\}
}
\tag{8.1}
\]

for the concave-hazard class. The previous arbitrary-law bound (1.1) remains available as well, so on overlap the strongest certified lower bound is the maximum of the two valid bounds.

The criterion also identifies the precise boundary where this route stops. For example `h(x)=x/log x` has elasticity tending to one and makes the ratio in (8.1) tend to one at every fixed `t<delta`. The theorem then gives no positive lower bound even though the law remains smooth, full-support, finite-mean, and far less irregular than Janson's sparse examples. That is the cleanest special case for the next run.
