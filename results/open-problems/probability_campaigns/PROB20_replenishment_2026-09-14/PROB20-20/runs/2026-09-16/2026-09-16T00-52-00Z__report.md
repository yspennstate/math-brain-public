## 2. Normalized iid model and retained inputs

When finite-mean boundary normalization is valid, put

\[
\pi_k=\frac{w_k\rho^k}{\Phi(\rho)},
\qquad
\sum_k\pi_k=1,
\qquad
\sum_k k\pi_k=\nu>0.
\]

Then

\[
(Y_1,\ldots,Y_n)
\overset d=
(\xi_1,\ldots,\xi_n)\mid\{S_n=m_n\},
\]

where `xi_i` are iid with law `pi` and `S_n=sum_i xi_i`.

Write

\[
p_n:=\Pr(S_n=m_n),
\qquad
b_n:=-\log p_n,
\qquad
\delta:=\lambda-\nu>0.
\]

The weak law gives `b_n -> infinity`, while Janson's Theorem 17.1, after the boundary normalization above, gives

\[
\boxed{b_n=o(n).}
\tag{2.1}
\]

Normalize the fixed size-biased boundary law

\[
\bar q_k:=\frac{k\pi_k}{\nu},
\qquad k\ge1.
\tag{2.2}
\]

The retained amplified-cloud theorem supplies deterministic sequences

\[
L_n
=
R_n\frac{n}{b_n}(1+o(1)),
\qquad
R_n\to\infty,
\qquad
R_n=o(b_n),
\tag{2.3}
\]

such that

\[
T_n^{\rm cloud}
:=
\sum_iY_i\mathbf1_{\{Y_i>L_n\}}
=
\delta n+o_p(n).
\tag{2.4}
\]

The immediately preceding corrected Palm report used a deliberately loose choice `r_n ~ b_n/sqrt(R_n)` to ensure that size-biased peeling captures a fixed fraction of this cloud. The main new point here is that the same conclusion can be proved in only

\[
\boxed{r_n=O(b_n/R_n)}

# 3. Exact sequential Palm identity retained

For an admissible state with `N` boxes and total `M>0`, choose one ball uniformly and remove the entire box containing it. If that box has size `k`, the exact transition kernel is

\[
K_{N,M}(k)
=
\frac{Nk\pi_k\,p_{N-1}(M-k)}{Mp_N(M)},
\qquad
p_N(M):=\Pr(S_N=M).
\tag{3.1}
\]

With `b(N,M)=-log p_N(M)` and `B~K_{N,M}`, the retained exact one-step identity is

\[
\boxed{
b(N,M)-E\,b(N-1,M-B)
=
D(K_{N,M}\Vert\bar q)
+
\log\frac{M/N}{\nu}.
}
\tag{3.2}
\]

If the process is stopped before a cumulative removed mass `c n` with fixed `0<c<delta`, then every pre-stop residual density stays strictly above `nu`, and the KL chain rule yields the stopped budget

\[
\boxed{
D(P^{\rm stop}_{n,r}\Vert Q^{*,\rm stop}_{n,r})
\le b_n,
}
\tag{3.3}
\]

where the reference process uses iid increments with law `bar q` and the same stopping rule. No local limit theorem, moment beyond the finite boundary mean, or collision correction is used.

# 4. New theorem: fixed-fraction cloud capture in O(b_n/R_n) peels

Fix any constant

\[
0<c<\delta.
\tag{4.1}
\]

For definiteness in the proof below one may take `c=delta/4`; the same argument works for every fixed `c<delta` with constants depending on `c`.

Choose another constant `eta>0` such that

\[
c+2\eta<\delta.
\]

By (2.4), with probability tending to one,

\[
T_n^{\rm cloud}\ge(c+2\eta)n.
\tag{4.2}
\]

Consider the ordinary size-biased peeling permutation of the conditioned boxes. Before the selected cloud mass reaches `c n`, on the event (4.2) the remaining cloud mass is at least `2 eta n`. Also `m_n <= 2 lambda n` eventually. Therefore, conditional on the current realized allocation and all previous selections, the probability that the next selected box belongs to the cloud is at least

\[
p_0:=\eta/\lambda>0
\tag{4.3}
\]

for all sufficiently large `n` (using a smaller harmless constant if desired).

Every cloud success removes more than `L_n` balls. Hence

\[
h_n:=\left\lceil\frac{cn}{L_n}\right\rceil
=
(c+o(1))\frac{b_n}{R_n}
\tag{4.4}
\]

cloud successes are sufficient to remove cloud mass at least `c n`. Since `R_n=o(b_n)`,

\[
h_n\to\infty.
\tag{4.5}
\]

Choose a fixed constant `A>2/p_0` and set

\[
r_n:=\lceil Ah_n\rceil.
\tag{4.6}
\]

Until the target is reached, the cloud-hit indicators stochastically dominate iid Bernoulli(`p_0`) trials. Consequently

\[
\Pr(\text{fewer than }h_n\text{ cloud hits in the first }r_n\text{ peels};\ (4.2))
\le
\Pr(\operatorname{Bin}(r_n,p_0)<h_n)
\le e^{-c_1h_n}
\tag{4.7}
\]

for some `c_1>0`. Combining (4.2), (4.5), and (4.7) yields

\[
\boxed{
\Pr\left(\sum_{j=1}^{r_n}B_j\ge cn\right)\to1,
\qquad
r_n=O\left(\frac{b_n}{R_n}\right)=o(b_n).
}
\tag{4.8}
\]

This strictly improves the previous `b_n/sqrt(R_n)` capture length.

### Why the domination is legitimate

The comparison in (4.7) is made conditional on the full realized remaining allocation, not merely on the pair `(N_j,M_j)`. Before the cloud target is hit, the remaining cloud mass has the deterministic lower bound above on the high-probability event (4.2); size-biased box selection therefore hits the cloud with conditional probability at least `p_0` at every pre-hit draw. Standard uniform-coupling of Bernoulli variables then yields stochastic domination. No independence of the actual hit indicators is asserted.

# 5. Stronger unconditional iid size-biased reference theorem

Stop the Palm process when cumulative **total** removed mass reaches `c n`, or after `r_n` selections. Cloud capture (4.8) implies that the total-mass hit event `H_n` satisfies

\[
P^{\rm stop}_{n,r_n}(H_n)\to1.
\tag{5.1}
\]

Because `c<delta`, the stopped KL budget (3.3) applies. Under the iid reference stopped process, nonnegativity of the increments gives

\[
Q^{*,\rm stop}_{n,r_n}(H_n)
=
\Pr_{\bar q}(X_1+\cdots+X_{r_n}\ge cn),
\tag{5.2}
\]

with iid `X_j~bar q`.

Binary data processing therefore yields the sharpened unconditional theorem

\[
\boxed{
-
\log
\Pr_{\bar q}(X_1+\cdots+X_{r_n}\ge cn)
\le
(1+o(1))b_n,
\qquad
r_n=O(b_n/R_n)=o(b_n).
}
\tag{5.3}
\]

The prior checkpoint had the same large-deviation price but only at `r_n ~ b_n/sqrt(R_n)`. Thus the fixed size-biased law must now create a linear sum using a number of iid draws smaller by a diverging factor.

# 6. Near-full excess capture in o(b_n) peels

The fixed-fraction statement can be pushed to a target approaching the entire missing mass.

Because (2.4) holds in probability, choose a deterministic sequence `epsilon_n downarrow 0` sufficiently slowly that all three conditions hold:

\[
\Pr\left(\left|T_n^{\rm cloud}/n-\delta\right|>\epsilon_n\right)\to0,
\tag{6.1}
\]

\[
|m_n/n-\lambda|\le\epsilon_n/4
\quad\text{eventually},
\tag{6.2}
\]

and

\[
\epsilon_nR_n\to\infty.
\tag{6.3}
\]

Such a choice is always possible: first choose any deterministic convergence-rate envelope for (2.4) and `m_n/n -> lambda`, then enlarge it by `R_n^{-1/2}`.

Set

\[
x_n:=(\delta-2\epsilon_n)n.
\tag{6.4}
\]

On the good event in (6.1), before selected cloud mass reaches `x_n`, at least `epsilon_n n` cloud mass remains. Since the remaining total is at most `2 lambda n`, the next peel hits the cloud with conditional probability at least

\[
p_n^{\rm hit}\ge\frac{\epsilon_n}{2\lambda}.
\tag{6.5}
\]

The number of cloud successes sufficient to reach `x_n` is

\[
h_n^{\rm full}
:=
\left\lceil\frac{x_n}{L_n}\right\rceil
=
(\delta+o(1))\frac{b_n}{R_n}.
\tag{6.6}
\]

Take

\[
r_n^{\rm full}
:=
\left\lceil
\frac{4h_n^{\rm full}}{p_n^{\rm hit}}
\right\rceil.
\tag{6.7}
\]

Then a binomial Chernoff bound gives

\[
\Pr\left(\sum_{j=1}^{r_n^{\rm full}}B_j\ge x_n\right)\to1,
\tag{6.8}
\]

while

\[
\boxed{
\frac{r_n^{\rm full}}{b_n}
=
O\left(\frac1{\epsilon_nR_n}\right)
\to0.
}
\tag{6.9}
\]

Moreover, by (6.2), before the total-mass target `x_n` is hit,

\[
\frac{M_j}{N_j}
\ge
\frac{m_n-x_n}{n}
\ge
\nu+\epsilon_n
>
\nu
\tag{6.10}
\]

for all sufficiently large `n`. Thus the stopped Palm KL budget remains valid even though the density margin tends to zero.

Consequently there exist `epsilon_n -> 0` and `r_n=o(b_n)` such that

\[
\boxed{
-
\log
\Pr_{\bar q}
\left(
X_1+\cdots+X_{r_n}
\ge
(\delta-2\epsilon_n)n
\right)
\le
(1+o(1))b_n.
}
\tag{6.11}
\]

This is a more precise structural statement than (5.3): essentially the **entire** supercritical excess must be reproducible by `o(b_n)` iid draws from the one fixed size-biased boundary law at total exponential price at most `b_n`.

# 8. New universal rate-envelope/composition bound

Define the truncated fixed-law per-unit coding rate

\[
a(U)
:=
\min_{\substack{1\le k\le U\\ \bar q_k>0}}
\frac{-\log\bar q_k}{k}.
\tag{8.1}
\]

Then for every positive support point `k<=U`,

\[
\bar q_k\le e^{-a(U)k}.
\tag{8.2}
\]

Put

\[
a_n:=a(U_n),
\qquad
r:=r_n,
\qquad
x:=x_n.
\]

Since `r=o(b_n)=o(n)` and `x~delta n`,

\[
d_n:=r/x\to0.
\tag{8.3}
\]

If `a_n<=d_n`, then immediately

\[
x a_n\le r=o(b_n).
\tag{8.4}
\]

Otherwise choose

\[
t=a_n-d_n>0.
\]

Using (8.2),

\[
M_{U_n}(t)
\le
\sum_{k\ge1}e^{-d_nk}
=
\frac1{e^{d_n}-1}
\le
\frac1{d_n}
=
\frac xr.
\tag{8.5}
\]

The right side tends to infinity, so the positive-part issue in (7.7) disappears for this chosen upper bound. Combining (7.6)--(7.7) with (8.5) yields

\[
-\log\Pr(E_n)
\ge
x a_n-r-r\log(x/r)-\log r.
\tag{8.6}
\]

Therefore every hypothetical full counterexample must satisfy

\[
\boxed{
xa(U_n)
\le
(1+o(1))b_n
+
r_n\log\frac{e x_n}{r_n}
+
\log r_n.
}
\tag{8.7}
\]

This is a support-free replacement for the previous crude `r log N(U)` correction. It uses only that `bar q` is a probability law and the minimal per-unit rate below the cap.

Since

\[
\frac{r_n}{b_n}
=O\left(\frac1{\epsilon_nR_n}\right),
\qquad
x_n\sim\delta n,
\]

(8.7) can be summarized as

\[
\boxed{
\frac{\delta n\,a(U_n)}{b_n}
\le
1
+
O\left(
\epsilon_n
+
\frac{\log(n\epsilon_nR_n/b_n+e)}{\epsilon_nR_n}
\right)
+
o(1).
}
\tag{8.8}
\]

The exact displayed error can be changed harmlessly by constants coming from the choice in (6.7); the structural point is that the leading coefficient in front of `b_n` is now **one**, because the peeling target approaches the full excess `delta n`.

# 10. Why the new rate-envelope estimate is noncircular

The only fixed-law bound used in Section 8 is

\[
\bar q_k\le e^{-a(U)k},\qquad k\le U,
\]

which is simply the definition of `a(U)`. The geometric-series estimate

\[
\sum_{k\ge1}e^{-dk}\le1/d
\]

then bounds the truncated mgf. There is no imported one-big-jump theorem, no hidden local limit theorem, and no assumption that `bar q` is long-tailed, subexponential, regularly varying, or eventually monotone.

The exact stopped KL comparison was already proved algebraically in the preceding corrected checkpoint. The only new probabilistic ingredient in Sections 4 and 6 is adaptive Bernoulli domination of cloud hits, justified by a lower bound on the **realized remaining cloud mass fraction** before the target is reached.

\gg

\[
E_j/b_{n_j}

\gg
