## Correct definition

Replace equation (2.1) of the parent report by

\[
\boxed{
V_n:=\min\{U_n,\lceil 2M_n\rceil\}.
}
\tag{C.1}
\]

This is required because `mu_n` is supported only on `(L_n,U_n]`. With (C.1):

- if `2M_n <= U_n`, Markov gives `mu_n(K<=V_n)>=1/2`;
- if `2M_n > U_n`, then `V_n=U_n` and the captured mass is exactly one.

Thus in every case

\[
\boxed{
\mu_n(K\le V_n)\ge\frac12
}
\]

and hence

\[
\boxed{
\sum_{L_n<k\le V_n}q_ke^{s_nk}
\ge \frac12D_n\ge\frac\delta3
}
\]

for all sufficiently large `n`.

Moreover the scale bound used later remains valid. If `V_n=ceil(2M_n)` then `V_n<=C sigma_n^2` by the parent report's bound `M_n<=C sigma_n^2`. If instead `V_n=U_n`, then `U_n<2M_n+1<=C sigma_n^2`. Therefore

\[
\boxed{
L_n<V_n\le C\sigma_n^2=o(n).
}
\tag{C.2}
\]

(The parent report's stronger displayed `2L_n<V_n` is unnecessary; all later arguments need only `L_n<V_n`. Since `U_n>=2L_n` and `M_n>L_n`, a comparable separation is available anyway.)

All subsequent statements remain unchanged after using (C.1):
