## 2. Exact source statement and fixed-law model

The original source was checked again on 2026-09-16 UTC from arXiv:1112.0510v1, PDF page 122. The exact quantifiers are:

- one fixed weight sequence `w=(w_k)`;
- `m=m(n)` with `m/n -> lambda`;
- the supercritical regime `0 < nu < lambda`;
- the question is whether `Y_(1)/n ->_p 0` can hold along the **full** sequence;
- Example 18.36 gives such vanishing only on a subsequence;
- Janson conjectures that full-sequence vanishing is impossible and, more strongly, that there are some fixed `epsilon>0` and a subsequence along which `Y_(1) >= epsilon n` w.h.p.

Problem 18.40, which follows immediately in the source, is a distinct `nu=0` question.

Section 10 fixes a single weight sequence and defines the allocation by

\[
P(B_{m,n}=y)=\frac{\prod_{i=1}^n w_{y_i}}{Z(m,n)},
\qquad \sum_i y_i=m.
\tag{2.1}
\]

Let

\[
\Phi(t)=\sum_{k\ge0}w_kt^k,
\qquad
\Psi(t)=\frac{t\Phi'(t)}{\Phi(t)},
\qquad
\nu=\lim_{t\uparrow\rho}\Psi(t).
\tag{2.2}
\]

When the finite-mean boundary normalization is valid, an equivalent rescaling lets us work with

\[
\pi_k=\frac{w_k\rho^k}{\Phi(\rho)},
\qquad E_\pi X=\nu,
\tag{2.3}
\]

and the allocation is exactly

\[
(Y_1,\ldots,Y_n)
\overset d=
(X_1,\ldots,X_n)\mid\{S_n=m\}.
\tag{2.4}
\]

Janson's Lemma 18.31 gives, for any `K_n->infinity`,

\[
\sum_{k>K_n} kN_k\le (\lambda-\nu)n+o_p(n).
\tag{2.5}
\]

Choosing `K_n=o(n)` implies

\[
\frac{Y_{(1)}}n\le \lambda-\nu+o_p(1).
\tag{2.6}
\]

Since `Y_(1)/n <= m_n/n = O(1)`, (2.6) also yields

\[
\limsup_n E\frac{Y_{(1)}}n\le\lambda-\nu.
\tag{2.7}
\]

Put throughout

\[
\delta:=\lambda-\nu>0.
\tag{2.8}
\]

## 5. B8: discretize the irregular law into windows and one measurable defect

Fix `eta>0`. Let

\[
1<K_1<K_2<\cdots,
\qquad
h_1>h_2>\cdots>0,
\qquad
h_j\downarrow0,
\tag{5.1}
\]

and let

\[
I_j=[K_j,\lfloor(1+\eta)K_j\rfloor]\cap\mathbb Z.
\tag{5.2}
\]

Assume the windows are eventually disjoint and

\[
\frac{K_{j+1}}{K_j}\longrightarrow\infty.
\tag{5.3}
\]

Define one fixed weight sequence

\[
w_0=w_1=1,
\qquad
w_k=e^{-h_jk}\quad(k\in I_j),
\qquad
w_k=0\quad(k\ge2\text{ outside the windows}).
\tag{5.4}
\]

Assume that its boundary normalization at `rho=1` is a span-one probability law `pi` with

\[
0<\nu=E_\pi X<\infty,
\qquad
0<\sigma^2=\operatorname{Var}_\pi X<\infty.
\tag{5.5}
\]

The explicit corollary in Section 9 verifies these conditions from elementary summability assumptions; they are not silently assumed there.

Define the absolute rate drop

\[
\Delta_j:=h_{j-1}-h_j>0,
\qquad j\ge2.
\tag{5.6}
\]

For a fixed interpolation parameter `theta in (0,1)`, define the old-window test tilt

\[
s_{j,\theta}:=h_j+\theta\Delta_j
=(1-\theta)h_j+\theta h_{j-1}.
\tag{5.7}
\]

Thus

\[
s_{j,\theta}-h_j=\theta\Delta_j,
\qquad
h_{j-1}-s_{j,\theta}=(1-\theta)\Delta_j.
\tag{5.8}
\]

Let

\[
F_j(s):=E_\pi[e^{sX};X<K_j].
\tag{5.9}
\]

The only moving-truncation error that enters the theorem is the **positive transform defect**

\[
d_j(\theta)
:=
\frac{[\log F_j(s_{j,\theta})-\nu s_{j,\theta}]_+}{\Delta_j}.
\tag{5.10}
\]

This is exact. No asymptotic free-energy identity has been inserted.

Assume the scale advantage beats placement entropy:

\[
\frac{\Delta_jK_j}{\log K_j}\longrightarrow\infty.
\tag{5.11}
\]

Define

\[
d_*(\theta):=\liminf_{j\to\infty}d_j(\theta)
\in[0,\infty].
\tag{5.12}
\]

Finally define the window-defect lower-bound functional

\[
\boxed{
 b_{\rm win}(w,\lambda)
 :=
 \sup_{0<\theta<1}
 \left[\delta-\frac{d_*(\theta)}{\theta}\right]_+.
}
\tag{5.13}
\]

The representation (5.4) and hypotheses (5.3), (5.5), (5.11) are part of the theorem's additional assumptions. Thus (5.13) is not being advertised as a bound for arbitrary weight sequences.

## 6. Main quantitative theorem

### Theorem 6.1 — sparse-window defect lower bound

Let one fixed weight law satisfy (5.1)–(5.5) and (5.11). Let `m_n` be any full admissible sequence indexed by all sufficiently large integers, with

\[
\frac{m_n}{n}\to\lambda>\nu.
\tag{6.1}
\]

Then

\[
\boxed{
 \limsup_{n\to\infty}E\frac{Y_{(1)}}n
 \ge b_{\rm win}(w,\lambda).
}
\tag{6.2}
\]

More precisely, fix `theta in (0,1)` with

\[
d_*(\theta)<\theta\delta.
\tag{6.3}
\]

Then for every

\[
0<t<\delta-\frac{d_*(\theta)}\theta
\tag{6.4}
\]

there is a deterministic subsequence along which

\[
P(Y_{(1)}>tn)\to1.
\tag{6.5}
\]

If `d_*(theta)=0` for some `theta`, then along a deterministic subsequence

\[
\frac{Y_{(1)}}n\xrightarrow p\delta,
\tag{6.6}
\]

and hence, using Janson's upper bound (2.7),

\[
\boxed{
\limsup_nE\frac{Y_{(1)}}n=\delta=\lambda-\nu.
}
\tag{6.7}
\]

### Proof

Fix `theta` satisfying (6.3) and a target `t` satisfying (6.4). Choose a number `q` with

\[
d_*(\theta)<q<\theta(\delta-t).
\tag{6.8}
\]

By the definition of liminf there is an infinite sequence of window indices, still denoted `j`, such that

\[
\log F_j(s_{j,\theta})-\nu s_{j,\theta}
\le q\Delta_j.
\tag{6.9}
\]

Choose once and for all

\[
0<c<\min\{\eta,1\}.
\tag{6.10}
\]

B19 below explains this choice as a constructive subsequence algorithm. For the proof set

\[
n_j:=\left\lfloor\frac{(1+c)K_j}{\delta}\right\rfloor.
\tag{6.11}
\]

Then `n_j->infinity`. Let `r_j` be an integer nearest to `nu(n_j-1)` and put

\[
k_j:=m_{n_j}-r_j.
\tag{6.12}
\]

Since `m_n/n->lambda`,

\[
\frac{k_j}{n_j}\to\delta,
\qquad
\frac{k_j}{K_j}\to1+c.
\tag{6.13}
\]

Because `0<c<eta`, `k_j` lies strictly inside `I_j` for all sufficiently large `j`. Hence `pi_{k_j}>0` and, on the current window,

\[
\pi_k=C_0e^{-h_jk}
\tag{6.14}
\]

with the same fixed normalization constant `C_0=1/Phi(1)`.

By span one and finite variance, the ordinary lattice local CLT gives

\[
P(S_{n_j-1}=r_j)
=\frac{1+o(1)}{\sigma\sqrt{2\pi n_j}}.
\tag{6.15}
\]

Therefore the exact conditioning event has the explicit lower bound

\[
P(S_{n_j}=m_{n_j})
\ge
\pi_{k_j}P(S_{n_j-1}=r_j)
\ge
c_0n_j^{-1/2}e^{-h_jk_j}.
\tag{6.16}
\]

Since `h_j->0` and `k_j=Theta(n_j)`, the right side is `e^{-o(n_j)}` up to the polynomial factor.

By (5.3),

\[
K_{j+1}>m_{n_j}
\tag{6.17}
\]

for all sufficiently large `j`. Thus on the event `S_{n_j}=m_{n_j}` every coordinate at least `K_j` lies in the current window `I_j`; no future cheaper window is arithmetically accessible.

Define

\[
R_j:=|\{i:X_i\ge K_j\}|.
\tag{6.18}
\]

The proof splits the exact sum event into the discrete cases `R_j=0`, `R_j=1`, and `R_j>=2`.

#### Case 1: no current-window coordinate

On `R_j=0`, all variables are below `K_j`. The positive exponential transform gives the exact Chernoff bound

\[
P(S_{n_j}=m_{n_j},R_j=0)
\le
 e^{-s_{j,\theta}m_{n_j}}
 F_j(s_{j,\theta})^{n_j}.
\tag{6.19}
\]

Divide by (6.16). Using `m_{n_j}=k_j+r_j`, `r_j=nu(n_j-1)+O(1)`, (6.9), and (6.14),

\[
\begin{aligned}
\log\frac{P(S_{n_j}=m_{n_j},R_j=0)}{P(S_{n_j}=m_{n_j})}
&\le
-(s_{j,\theta}-h_j)k_j
+n_jq\Delta_j
+O(\log n_j)+O(s_{j,\theta})\\
&=
-\Delta_jn_j\{\theta\delta-q+o(1)\}
+O(\log n_j).
\end{aligned}
\tag{6.20}
\]

Because `q<theta(delta-t)<theta delta`, the coefficient in braces is positive. Further, `n_j=Theta(K_j)` and (5.11) gives

\[
\Delta_jn_j\gg\log n_j.
\tag{6.21}
\]

Hence the right side of (6.20) tends to `-infinity`, and

\[
P(R_j=0\mid S_{n_j}=m_{n_j})\to0.
\tag{6.22}
\]

#### Case 2: two or more current-window coordinates

If `R_j>=2`, two coordinates contribute at least `2K_j`. From (6.11),

\[
\frac{2K_j}{n_j}\to\frac{2\delta}{1+c}.
\tag{6.23}
\]

Since `c<1`,

\[
\lambda-\frac{2\delta}{1+c}
=
\nu-\delta\frac{1-c}{1+c}
<\nu.
\tag{6.24}
\]

Thus there exists a fixed `a>0` such that, after removing any two coordinates of size at least `K_j`, the remaining `n_j-2` nonnegative iid variables must have sum at most `(nu-a)(n_j-2)` for all large `j`.

A negative exponential Chernoff bound is always available for nonnegative variables, so

\[
P(S_{n_j-2}\le(\nu-a)(n_j-2))\le e^{-c_an_j}
\tag{6.25}
\]

for some `c_a>0`. A union bound over the selected pair gives

\[
P(S_{n_j}=m_{n_j},R_j\ge2)
\le n_j^2e^{-c_an_j}.
\tag{6.26}
\]

The denominator (6.16) is only `e^{-o(n_j)}`. Therefore

\[
P(R_j\ge2\mid S_{n_j}=m_{n_j})\to0.
\tag{6.27}
\]

#### Case 3: exactly one current-window coordinate, but it is too small

Let

\[
A_j(t):=\{S_{n_j}=m_{n_j},\ R_j=1,\ Y_{(1)}\le tn_j\}.
\tag{6.28}
\]

If the unique current-window coordinate equals `u`, then `u in I_j`, `u<=tn_j`, and all other coordinates are below `K_j`. Thus

\[
P(A_j(t))
\le
n_j
\sum_{\substack{u\in I_j\\u\le tn_j}}
\pi_u
 e^{-s_{j,\theta}(m_{n_j}-u)}
 F_j(s_{j,\theta})^{n_j-1}.
\tag{6.29}
\]

For every `u,k_j in I_j`, exact window linearity gives

\[
\log\frac{\pi_u}{\pi_{k_j}}
=-h_j(u-k_j).
\tag{6.30}
\]

Dividing each term of (6.29) by the denominator lower bound (6.16) and using (6.9) yields

\[
\log(\text{term ratio})
\le
-(s_{j,\theta}-h_j)(k_j-u)
+n_jq\Delta_j
+O(\log n_j).
\tag{6.31}
\]

There are only `O(K_j)=O(n_j)` terms in the sum, so their total placement/support entropy changes the last term by only `O(log n_j)`.

Uniformly over `u<=tn_j`, (6.13) gives

\[
k_j-u\ge (\delta-t)n_j+o(n_j).
\tag{6.32}
\]

Using `s_{j,theta}-h_j=theta Delta_j`,

\[
\log\frac{P(A_j(t))}{P(S_{n_j}=m_{n_j})}
\le
-\Delta_jn_j\{\theta(\delta-t)-q+o(1)\}
+O(\log n_j).
\tag{6.33}
\]

The coefficient is positive by (6.8), and (6.21) again applies. Hence

\[
P(A_j(t)\mid S_{n_j}=m_{n_j})\to0.
\tag{6.34}
\]

Combining (6.22), (6.27), and (6.34),

\[
P(Y_{(1)}>tn_j\mid S_{n_j}=m_{n_j})\to1.
\tag{6.35}
\]

By the iid-conditioning identity (2.4), this is precisely the allocation statement (6.5).

Because `0<=Y_(1)/n<=m_n/n=O(1)`, (6.5) implies

\[
\limsup_nE\frac{Y_{(1)}}n\ge t.
\tag{6.36}
\]

Letting `t` increase to `delta-d_*(theta)/theta` proves the fixed-`theta` lower bound. Taking the supremum over `theta` proves (6.2).

If `d_*(theta)=0`, the same argument applies to every fixed `t<delta`; a diagonal choice of favorable window indices gives a deterministic subsequence on which `Y_(1)/n ->_p delta`. Together with (2.7), this proves (6.6)–(6.7). `square`

## 7. What is genuinely new in the metric

The preceding sparse-window theorem was binary: a fixed fractional rate drop plus summability implied the exact value `delta`.

Theorem 6.1 yields a quantitative branch even when the moving truncated transform has a nonzero first-order defect. Under its explicit sparse-window hypotheses,

\[
\boxed{
 b(w,\lambda)
 \ge
 \max\{b_{\rm int}(w,\lambda),\ b_{\rm win}(w,\lambda)\}.
}
\tag{7.1}
\]

The new term is

\[
 b_{\rm win}(w,\lambda)
 =
 \sup_{0<\theta<1}
 \left[\lambda-\nu-\frac{d_*(\theta)}\theta\right]_+.
\tag{7.2}
\]

Every extra assumption needed for (7.2) is retained in Section 5. It is not an unconditional replacement for (3.1).

The interpretation is exact: `theta Delta_j` is the per-particle energetic advantage of the current window against the chosen capped tilt, while `d_j(theta) Delta_j` is the actual positive free-energy defect per background box. A macroscopic coordinate of relative size `t` wins whenever

\[
\theta(\delta-t)>d_*(\theta).
\tag{7.3}
\]

This is the precise scale-gluing obstruction supplied by the run.

## 8. A structural criterion forcing zero defect

The defect in (5.10) is exact but implicit. This section gives explicit sufficient conditions under which `d_*(1/2)=0`, while allowing the **relative** rate drops to vanish.

Take

\[
s_j:=\frac{h_{j-1}+h_j}{2},
\qquad
\Delta_j=h_{j-1}-h_j.
\tag{8.1}
\]

Define tail quantities

\[
T_j:=\sum_{i\ge j}K_i e^{-h_iK_i},
\qquad
U_j:=\sum_{i\ge j}K_i^2 e^{-h_iK_i}.
\tag{8.2}
\]

Assume

\[
h_{j-1}^2=o(\Delta_j),
\tag{8.3}
\]

\[
\sum_{i\ge1}K_i^3
\exp\{-\tfrac12\Delta_{i+1}K_i\}<\infty,
\tag{8.4}
\]

\[
T_j=o(\Delta_j),
\qquad
h_{j-1}U_j=o(\Delta_j).
\tag{8.5}
\]

These assumptions also imply the summability needed for `Phi(1)<infinity` and finite variance, because `Delta_{i+1}<h_i` and hence (8.4) is stronger than the corresponding moment-weight summability.

### Lemma 8.1 — midpoint defect is `o(Delta_j)`

Under (8.3)–(8.5),

\[
\boxed{
\log F_j(s_j)-\nu s_j=o(\Delta_j).
}
\tag{8.6}
\]

In particular,

\[
d_*(1/2)=0.
\tag{8.7}
\]

### Proof

Write

\[
F_j(s_j)-1-\nu s_j
=
\sum_{k<K_j}\pi_k(e^{s_jk}-1-s_jk)
-P(X\ge K_j)-s_jE[X;X\ge K_j].
\tag{8.8}
\]

For `u>=0`,

\[
e^u-1-u\le \frac{u^2}{2}e^u.
\tag{8.9}
\]

The contribution of `k=1` to the first term of (8.8) is `O(s_j^2)`. For an old window `I_i`, `i<j`, the contribution is at most

\[
C s_j^2K_i^3e^{-(h_i-s_j)K_i}.
\tag{8.10}
\]

If `i<=j-2`, monotonicity gives

\[
h_i-s_j
\ge h_i-h_{i+1}
=\Delta_{i+1}.
\tag{8.11}
\]

For `i=j-1`,

\[
h_{j-1}-s_j=\frac12\Delta_j.
\tag{8.12}
\]

Consequently (8.4) gives the uniform bound

\[
\sup_j
\sum_{i<j}K_i^3e^{-(h_i-s_j)K_i}<\infty.
\tag{8.13}
\]

Therefore the first term of (8.8) is `O(s_j^2)=o(Delta_j)` by (8.3).

The number of supported points in `I_i` is `O(K_i)`, and each has weight at most a fixed normalization constant times `e^{-h_iK_i}`. Hence

\[
P(X\ge K_j)\le CT_j=o(\Delta_j)
\tag{8.14}
\]

and

\[
s_jE[X;X\ge K_j]
\le Cs_jU_j
\le Ch_{j-1}U_j
=o(\Delta_j).
\tag{8.15}
\]

Thus

\[
F_j(s_j)=1+\nu s_j+o(\Delta_j).
\tag{8.16}
\]

Since `s_j->0`,

\[
\log F_j(s_j)
=F_j(s_j)-1+O((F_j(s_j)-1)^2).
\tag{8.17}
\]

The square is `O(s_j^2)+o(Delta_j^2)=o(Delta_j)` by (8.3) and `Delta_j->0`. Combining (8.16)–(8.17) proves (8.6). `square`

This proof is precisely what the old F0059 route lacked: the moving-truncation error is bounded directly and compared on the same `Delta_j` scale as the energetic advantage.

## 9. New explicit fixed law with vanishing fractional rate improvements

Set, for `j>=2`,

\[
\eta=\frac12,
\qquad
h_j=\frac1{j^2},
\qquad
K_j=\left\lceil e^{j^4}\right\rceil,
\tag{9.1}
\]

and use the fixed law (5.4).

Then

\[
\Delta_j
=
\frac1{(j-1)^2}-\frac1{j^2}
=\frac{2j-1}{j^2(j-1)^2}
\sim\frac2{j^3}.
\tag{9.2}
\]

The **fractional** record improvement is

\[
\frac{\Delta_j}{h_{j-1}}
=1-\frac{h_j}{h_{j-1}}
\sim\frac2j
\longrightarrow0.
\tag{9.3}
\]

Thus no fixed `kappa>0` can satisfy the preceding report's geometric-gap hypothesis for this law.

Nevertheless:

1. `K_{j+1}/K_j -> infinity` because `(j+1)^4-j^4 -> infinity`.
2. `h_jK_j=e^{j^4}/j^2+o(1)`, so `Phi(1)<infinity` and all polynomial moments of the boundary law are finite.
3. `w_0,w_1>0`, hence the span is one and `0<nu<infinity`.

## 11. Counterexample checks against the new transfer

Before promoting Theorem 6.1, the following failure modes were checked and retained as explicit hypotheses rather than waved away.

### 11.1 Defect of the same order as the rate gap

\[

### 11.2 Placement entropy at the threshold scale

If `Delta_j K_j=O(log K_j)`, the polynomial number of possible placements/support points can compete with the energetic gap. The theorem therefore retains (5.11). It does not infer persistence from a positive record gap alone.

### 11.3 Missing interior support

If a sparse construction has only isolated support points rather than a window, the deterministic quantity `k_j=m_{n_j}-r_j` can miss the support. The full interval `I_j` is retained so the local-CLT denominator uses an actual supported coordinate.

### 11.4 Future cheaper scales

### 11.5 Two cheap macroscopic coordinates

If the chosen interior factor had `c>=1`, two current-window coordinates need not force the remaining background below its mean. The construction explicitly chooses `c<1`; this is the same stress exposed by the neighboring 18.41/18.42 phenomena.
