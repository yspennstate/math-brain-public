# 2. New exact identity: normalize the Palm reference only on feasible occupancies

At an exact-sum state `(N,M)`, the ordinary size-biased Palm kernel is

\[
K_{N,M}(k)
=
\frac{Nk\pi_k\,p_{N-1}(M-k)}{Mp_N(M)}.
\tag{2.1}
\]

Fix a cutoff `K<M` and put

\[
\alpha_{N,M}^{(K)}
:=
\sum_{k>K}K_{N,M}(k).
\tag{2.2}
\]

Because `p_{N-1}(M-k)=0` for `k>M`, the Palm kernel has no mass above `M`. Condition it on `k>K`:

\[
K_{N,M}^{(K)}(k)
=
\frac{K_{N,M}(k)}{\alpha_{N,M}^{(K)}}
\mathbf1_{\{K<k\le M\}}.
\tag{2.3}
\]

Previous reports compared this law with `qbar` conditioned on the full tail `k>K`. That is correct, but it allows fixed-law reference mass at occupancies that are physically impossible at the current exact-sum state. We can eliminate that slack exactly.

Define the feasible fixed-law tail mass

\[
Q_{K,M}
:=Q(K,M)
=\sum_{K<k\le M}\bar q_k
\tag{2.4}
\]

and the feasible reference law

\[
\bar q^{(K,M)}_k
=
\frac{\bar q_k}{Q_{K,M}}
\mathbf1_{\{K<k\le M\}}.
\tag{2.5}
\]

Whenever `alpha_{N,M}^{(K)}>0`, also `Q_{K,M}>0`.

## Lemma 2.1 — feasible-tail cloud-Palm identity

For every such state,

\[
\boxed{
 b(N,M)-E b(N-1,M-B)
=
D\!\left(K_{N,M}^{(K)}\middle\|\bar q^{(K,M)}\right)
+
\log\frac{M/N}{\nu}
+
\log\frac{\alpha_{N,M}^{(K)}}{Q_{K,M}}.
}
\tag{2.6}
\]

### Proof
The previously checked full-tail identity is

\[
 b(N,M)-E b(N-1,M-B)
=
D\!\left(K_{N,M}^{(K)}\middle\|\bar q^{(K)}\right)
+
\log\frac{M/N}{\nu}
+
\log\frac{\alpha_{N,M}^{(K)}}{Q(K)}.
\tag{2.7}
\]

On the support `K<k<=M`,

\[
\frac{\bar q^{(K,M)}_k}{\bar q^{(K)}_k}
=\frac{Q(K)}{Q_{K,M}}.
\]

Therefore

\[
D(K^{(K)}_{N,M}\|\bar q^{(K)})
=
D(K^{(K)}_{N,M}\|\bar q^{(K,M)})
+
\log\frac{Q_{K,M}}{Q(K)}.
\]

Substitution into (2.7) cancels `Q(K)` and proves (2.6). `square`

### Interpretation
The exact entropy budget never needs to pay for fixed-law tail mass beyond the residual total `M`. In particular a would-be counterexample cannot satisfy the previous tail-thickness requirement merely by placing substantial `qbar` mass at astronomically large occupancies that are inaccessible to the current exact-sum state.

# 3. First consequence: feasible-tail thickness is necessary

Run the auxiliary cloud-conditioned Palm chain from `(n,m_n)` with threshold `K_n` satisfying (1.3), until cumulative selected cloud mass first reaches `cn`. Let `tau_c` be that stopping time. As in the corrected earlier proof, every pre-stop residual state satisfies, eventually,

\[
N_j\ge n/2,
\qquad
\nu+\eta\le M_j/N_j\le\Lambda,
\tag{3.1}
\]

and hence

\[
\alpha_j:=\alpha_{N_j,M_j}^{(K_n)}\ge a_0.
\tag{3.2}
\]

Also

\[
M_j\le m_n,
\]

so

\[
Q(K_n,M_j)\le Q(K_n,m_n).
\tag{3.3}
\]

The density premium is uniformly positive:

\[
\log\frac{M_j/N_j}{\nu}
\ge
\log\left(1+\frac\eta\nu\right)
=:d_0>0.
\tag{3.4}
\]

Telescope (2.6) to `tau_c`. The KL terms and terminal exact-sum cost are nonnegative. Thus

\[
\boxed{
E_{\rm cl}\tau_c\,
H_n^{\rm feas}
\le b_n,
}
\tag{3.5}
\]

where

\[
H_n^{\rm feas}
:=
d_0+\log\frac{a_0}{Q(K_n,m_n)}.
\tag{3.6}
\]

Repeating the corrected bounded-length change-of-measure argument from `03-29-00Z`, if `H_n^{feas}` were a fixed positive fraction of `b_n` on a subsequence, the cloud chain would reach `cn` in a uniformly bounded number of steps with positive cloud-chain probability, and the bounded likelihood-ratio transfer would give a fixed positive microcanonical probability of a box of linear size. Therefore hypothetical full no-condensation forces

\[
\boxed{
-\log Q(K_n,m_n)=o(b_n)
}
\tag{3.7}
\]

for every iterable cutoff (1.3).

This already strengthens the retained full-tail statement

\[
-\log Q(K_n)=o(b_n),
\]

because all fixed-law mass above the physically feasible total `m_n` has disappeared from the obstruction.

The main result below localizes much further, from the macroscopic feasible range `k<=m_n` to the actual **sublinear maximum range** required by a full counterexample.

# 4. New fixed-horizon path transfer

The corrected report proved a transfer inequality for the event `tau_c<=r`. We need a slightly more flexible but immediate extension.

For an integer `r`, stop the auxiliary cloud-conditioned Palm chain at

\[
\sigma_r:=\tau_c\wedge r.
\tag{4.1}
\]

Let `P_cl^{(r)}` denote the resulting joint law of the reconstructed initial allocation and the marked path up to `sigma_r`. Let `Q_n^mic` denote the original microcanonical allocation law.

## Lemma 4.1 — fixed-horizon cloud-path transfer

For every event `E` depending only on the initial allocation,

\[
\boxed{
P_{\rm cl}^{(r)}(E)
\le a_0^{-r}Q_n^{\rm mic}(E).
}
\tag{4.2}
\]

### Proof
Compare with ordinary sequential marked-Palm sampling from the original microcanonical allocation. At cloud step `j`, conditioning the selected box to exceed `K_n` multiplies the joint path density by

\[
\frac{\mathbf1_{\{B_j>K_n\}}}{\alpha_j},
\qquad \alpha_j\ge a_0.
\]

A path stopped at `sigma_r` has length `s<=r`, so its likelihood ratio relative to the ordinary marked-Palm path is at most

\[
a_0^{-s}\le a_0^{-r}.
\]

After integrating out the ordinary marked choices, the initial-allocation marginal is exactly `Q_n^mic`. Summing over all stopped paths proves (4.2). `square`

No claim of equality of path measures is made; this is precisely the change-of-measure price that was missing in the superseded `02-55-00Z` transfer.

# 5. Main new theorem: a full counterexample needs exponentially thick mass inside its actual sublinear band

Assume only for contradiction analysis that

\[
Y_{(1)}/n\to_p0
\tag{5.1}
\]

under the target microcanonical laws.

Choose a deterministic high-probability cap `U_n` such that

\[
U_n\to\infty,
\qquad
U_n=o(n),
\qquad
\zeta_n
:=Q_n^{\rm mic}(Y_{(1)}>U_n)	o0.
\tag{5.2}
\]

Enlarge it if necessary so that

\[
U_n\ge2K_n,
\tag{5.3}
\]

which preserves `U_n=o(n)` and the high-probability cap property.

Because both

\[
\frac n{U_n}\to\infty
\]

and

\[
\log\frac1{\zeta_n}\to\infty
\]

(with the second condition interpreted as `+infinity` if `zeta_n=0`), we may choose a deterministic integer sequence

\[
r_n\to\infty
\tag{5.4}
\]

so slowly that simultaneously

\[
\boxed{
\frac{r_nU_n}{n}\to0,
\qquad
a_0^{-r_n}\zeta_n\to0.
}
\tag{5.5}
\]

For example, a diagonal choice below both one half of `sqrt(n/U_n)` and one half of `log(1/zeta_n)/|log a_0|` works after harmless flooring and further slowing.

Define the fixed size-biased mass in the actual sublinear band

\[
q_n^{\rm band}
:=Q(K_n,U_n)
=
\sum_{K_n<k\le U_n}\bar q_k.
\tag{5.6}
\]

We now prove the key new necessary condition.

## Theorem 5.1 — actual sublinear-band thickness

Under hypothetical full no-condensation, for every iterable lower cutoff `K_n` satisfying (1.3) and every high-probability cap `U_n` satisfying (5.2)–(5.3),

\[
\boxed{
-\log q_n^{\rm band}=o(b_n).
}
\tag{5.7}
\]

Equivalently,

\[
\boxed{
\sum_{K_n<k\le U_n}\frac{k\pi_k}{\nu}
=
\exp\{-o(b_n)\}.
}
\tag{5.8}
\]

Thus a putative counterexample cannot hide the required size-biased fixed-law mass above its own high-probability maximum cap.

### Step 1: the cloud chain also satisfies the cap with high probability for `r_n` steps

Apply Lemma 4.1 to the initial-allocation event

\[
E_n=\{Y_{(1)}>U_n\}.
\]

Using (5.5),

\[
P_{\rm cl}^{(r_n)}(Y_{(1)}>U_n)
\le
 a_0^{-r_n}\zeta_n
\to0.
\tag{5.9}
\]

Hence under the cloud path,

\[
P_{\rm cl}^{(r_n)}(Y_{(1)}\le U_n)\to1.
\tag{5.10}
\]

On the event `Y_(1)<=U_n`, the first `r_n` cloud-selected boxes remove at most

\[
r_nU_n=o(n)
\]

total mass. Since `c>0` is fixed, for large `n` this is less than `cn`; therefore

\[
\sigma_{r_n}=r_n
\]

and every one of the first `r_n` cloud-selected occupancies lies in `(K_n,U_n]`.

### Step 2: binary coarse-graining of each exact feasible-tail KL term

At a pre-stop state `(N_j,M_j)`, eventually

\[
M_j\ge m_n-cn=(\lambda-c+o(1))n,
\]

while `U_n=o(n)`. Hence

\[
U_n<M_j
\tag{5.11}
\]

uniformly at all pre-stop states.

Let

\[
P_j:=K_{N_j,M_j}^{(K_n)},
\qquad
R_j:=\bar q^{(K_n,M_j)}.
\]

Define

\[
p_j:=P_j(B\le U_n).
\tag{5.12}
\]

Under the feasible reference law,

\[
R_j(B\le U_n)
=
\frac{q_n^{\rm band}}{Q(K_n,M_j)}.
\tag{5.13}
\]

Binary data processing for KL gives

\[
D(P_j\|R_j)
\ge
p_j\log\frac{p_jQ(K_n,M_j)}{q_n^{\rm band}}
+(1-p_j)
\log\frac{(1-p_j)Q(K_n,M_j)}{Q(K_n,M_j)-q_n^{\rm band}}.
\]

Dropping the nonnegative reference-complement correction in the standard binary bound yields the convenient inequality

\[
\boxed{
D(P_j\|R_j)
\ge
p_j\log\frac{Q(K_n,M_j)}{q_n^{\rm band}}
-h(p_j),
}
\tag{5.14}
\]

where

\[
h(p)=-p\log p-(1-p)\log(1-p)\le\log2.
\]

Insert (5.14) into the exact feasible-tail identity (2.6). Write

\[
Q_j:=Q(K_n,M_j).
\]

Then one-step entropy decrement is at least

\[
 p_j\log\frac{Q_j}{q_n^{\rm band}}
-h(p_j)
+
\log\frac{M_j/N_j}{\nu}
+
\log\frac{\alpha_j}{Q_j}.
\tag{5.15}
\]

Rearrange the logarithms:

\[
 p_j\log\frac{Q_j}{q_n^{\rm band}}
+
\log\frac{\alpha_j}{Q_j}
=
 p_j\log\frac1{q_n^{\rm band}}
+(p_j-1)\log Q_j
+
\log\alpha_j.
\tag{5.16}
\]

Since `Q_j<=1` and `p_j<=1`,

\[
(p_j-1)\log Q_j\ge0.
\]

Also `alpha_j>=a_0` and the density premium is at least `d_0`. Therefore, with the fixed finite constant

\[
C_*:=\log2+|\log a_0|+d_0,
\]

or any larger fixed constant,

\[
\boxed{
\text{one-step decrement}
\ge
p_j\log\frac1{q_n^{\rm band}}-C_*.
}
\tag{5.17}
\]

(The exact constant is immaterial; only that it is independent of `n,j`.)

### Step 3: telescope for the growing but controlled horizon

Telescope (2.6) up to

\[
\sigma_n:=r_n\wedge\tau_c.
\]

The terminal exact-sum cost is nonnegative. Hence (5.17) gives

\[
b_n
\ge
\log\frac1{q_n^{\rm band}}
E_{\rm cl}\sum_{j<\sigma_n}p_j
-C_*r_n.
\tag{5.18}
\]

By the tower property,

\[
E_{\rm cl}\bigl[\mathbf1_{\{j<\sigma_n\}}p_j\bigr]
=
P_{\rm cl}(j<\sigma_n,\ B_{j+1}\le U_n).
\tag{5.19}
\]

But on the initial-allocation event `Y_(1)<=U_n`, equation (5.5) implies that all `r_n` steps occur before `tau_c` and all selected boxes are at most `U_n`. Therefore for every `0<=j<r_n`,

\[
P_{\rm cl}(j<\sigma_n,\ B_{j+1}\le U_n)
\ge
P_{\rm cl}(Y_{(1)}\le U_n)
=1-o(1),
\]

uniformly in `j`. Consequently

\[
\boxed{
E_{\rm cl}\sum_{j<\sigma_n}p_j
\ge
r_n(1-o(1)).
}
\tag{5.20}
\]

Combining (5.18) and (5.20),

\[
\log\frac1{q_n^{\rm band}}
\le
\frac{b_n+C_*r_n}{r_n(1-o(1))}
=
(1+o(1))\frac{b_n}{r_n}+O(1).
\tag{5.21}
\]

Because `r_n->infinity` and `b_n->infinity`, the right side is `o(b_n)`. This proves (5.7). `square`

# 6. Why Theorem 5.1 is materially stronger than the previous tail criterion

The retained `03-29-00Z` theorem forced

\[
-\log Q(K_n)=o(b_n).
\tag{6.1}
\]

That leaves a possible loophole: perhaps almost all of the required fixed size-biased tail mass sits at occupancies much larger than the actual maximum scale of a purported counterexample, so it never participates in the conditioned configurations.

Lemma 2.1 first removes mass above the exact residual total `M`. Theorem 5.1 removes much more: after assuming full no-condensation and selecting any high-probability sublinear maximum cap `U_n`, the law must already have

\[
\boxed{
Q(K_n,U_n)=e^{-o(b_n)}.
}
\tag{6.2}
\]

Thus the required fixed-law mass is forced into the same sublinear band that the purported counterexample actually uses.

This is not merely a restatement of finite mean. A fixed finite-mean law can have extremely sparse support and arbitrarily tiny band masses. The theorem says that such sparsity cannot occur on the exact-conditioning exponential scale simultaneously with full no-condensation, once the lower cutoff is uniformly iterable through compact-supercritical residual states.

# 7. Explicit corollary using the mesoscopic rate envelope

Take the explicit iterable cutoff `K_n=widehat K_n` from (1.7). Then hypothetical full no-condensation forces, for every deterministic high-probability maximum cap `U_n=o(n)` enlarged so that `U_n>=2 widehat K_n`,

\[
\boxed{
-\log
\sum_{\widehat K_n<k\le U_n}\bar q_k
=o(b_n).
}
\tag{7.1}
\]

Substituting the definition of `qbar`,

\[
\boxed{
-\log
\left(
\frac1\nu
\sum_{\widehat K_n<k\le U_n}k\pi_k
\right)
=o(b_n).
}
\tag{7.2}
\]

Every scale in this statement is determined by the one fixed boundary law, the target exact-conditioning cost, and the hypothetical high-probability maximum cap. No moving local CLT, regular variation, or subexponential-tail theorem is used.

# 8. New sublinear-band quantile obstruction

Fix `theta>0`. Define the upper band quantile above the explicit lower cutoff by

\[
V_n^{(\theta)}
:=
\inf\left\{
U>\widehat K_n:
\sum_{\widehat K_n<k\le U}\bar q_k
\ge e^{-\theta b_n}
\right\},
\tag{8.1}
\]

with `V_n^(theta)=+infinity` if the set is empty.

## Corollary 8.1 — every fixed exponential tail level must be reached sublinearly

Under hypothetical full no-condensation,

\[
\boxed{
V_n^{(\theta)}=o(n)
}
\tag{8.2}
\]

for every fixed `theta>0`.

### Proof
Choose a high-probability cap `U_n=o(n)` as in Theorem 5.1. By (7.1),

\[
-\log Q(\widehat K_n,U_n)=o(b_n).
\]

Hence for every fixed `theta>0`, eventually

\[
Q(\widehat K_n,U_n)\ge e^{-\theta b_n}.
\]

Thus the infimum in (8.1) is at most `U_n=o(n)`. `square`

This closes another concrete loophole in the previous argument: the `e^{-theta b_n}` fixed-law mass above the iterable cutoff cannot first appear at a macroscopic or supermacroscopic scale if full no-condensation is to hold.

Equivalently, the following is now a rigorous **closure criterion**:

> If for some fixed `theta>0` and some subsequence every `U_n=o(n)` has
> \[
> Q(\widehat K_n,U_n)<e^{-\theta b_n},
> \]
> then `Y_(1)/n ->p 0` along the full sequence is impossible.

This criterion covers fixed laws whose size-biased tail above the explicit iterable cutoff remains exponentially thin until a macroscopic support scale.

# 9. Relation to the strict record theorem

\tag{9.1}

The new band theorem says that if a full counterexample exists, then its actual sublinear cap cannot be supported by just one isolated cheap atom or by tail mass hidden beyond the cap. Instead, above the explicit iterable scale `widehat K_n`, the fixed size-biased law must accumulate

mass before that same sublinear cap.

This materially sharpens the remaining deterministic synchronization problem. Any eventual counterexample construction must satisfy simultaneously:

1. the mesoscopic cheap-atom bound controlling the compact-supercritical exact-sum rate;
2. the explicit iterable lower cutoff `widehat K_n`;

# 10. Self-review and boundary cases

### 10.1 The cloud path remains a tilted measure

Theorem 5.1 does not revert to the retracted direct transfer from the auxiliary cloud chain. The high-probability cap is transferred only for a deliberately slow growing horizon `r_n`, and its likelihood-ratio loss is explicitly controlled through

\[
a_0^{-r_n}\zeta_n\to0.
\]

This is why `r_n` is chosen diagonally rather than as a fixed formula of `b_n` alone.

### 10.2 Why a growing horizon is available

Full no-condensation gives a deterministic cap with `U_n/n->0` and failure probability `zeta_n->0`. Both `n/U_n` and `log(1/zeta_n)` diverge. Therefore there is always some deterministic `r_n->infinity` satisfying (5.5), however slowly either divergence occurs. No quantitative rate of no-condensation is assumed.

### 10.3 No issue from early stopping

On the good cap event, `r_nU_n=o(n)<cn`, so `tau_c>r_n`; the path genuinely contains all `r_n` cloud selections. On bad paths, stopping at `sigma_n=tau_c wedge r_n` keeps every exact Palm identity inside the compact-supercritical residual region.

### 10.4 Feasible reference mass is nonzero

At any state with `alpha_j>0`, the Palm kernel puts mass on at least one support point `K_n<k<=M_j`. Since `qbar_k>0` wherever `pi_k>0` for `k>=1`, the feasible normalization `Q(K_n,M_j)` is positive.

### 10.5 Lattice arithmetic

All exact-sum arguments are after dividing by the lattice span. The fixed-law support bands are understood on the resulting admissible lattice. No assertion is made at impossible residue classes.

### 10.6 What this does not prove

Theorem 5.1 is a necessary condition under the hypothetical counterexample, not an unconditional macroscopic-condensation theorem. It does not by itself imply a fixed positive `epsilon` with `P(Y_(1)>epsilon n)` bounded away from zero, much less the stronger w.h.p. subsequence form conjectured by Janson.
