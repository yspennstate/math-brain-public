# 3. Recovered matching upper bound

Write
\[
a_i:=\|A_i\|.
\]
If some `a_i=0`, every distinct word vanishes, so assume all `a_i>0`. Define
\[
\gamma_{ij}
:=
\frac{\|A_iA_j\|}{a_i a_j}
\in[0,1].
\tag{3.1}
\]
Let `m=floor(n/2)` and let `\mathfrak M_n` be the maximum-cardinality matchings of `K_n`. Put
\[
\mathcal M_n(\gamma)
:=
\frac1{|\mathfrak M_n|}
\sum_{M\in\mathfrak M_n}
\prod_{\{i,j\}\in M}\gamma_{ij}.
\tag{3.2}
\]
The preceding verified checkpoint proves
\[
\boxed{
L_n:=\frac1{n!}\sum_{\sigma}\|A_{\sigma(1)}\cdots A_{\sigma(n)}\|
\le
\left(\prod_i a_i\right)\mathcal M_n(\gamma).
}
\tag{3.3}
\]
It did so by grouping consecutive factors into disjoint pairs and averaging the induced perfect/near-perfect matching over permutations.

Previously only the pure words `A_i^n` were retained on the with-replacement side. The next sections add a disjoint, explicitly certified family of two-label collision words.

# 4. New block-orbit lemma for every two-label multiplicity

Fix PSD `A,B`, set
\[
a=\|A\|,\qquad b=\|B\|,\qquad
p=\|AB\|,\qquad
\gamma=\frac{p}{ab}.
\]
Let integers `r,s>=1`, `r+s=n>=3`.

## Lemma 4.1
\[
\boxed{
\rho(A^rB^s)
\ge
a^r b^s\gamma^{\max(r,s)}.
}
\tag{4.1}
\]

### Proof
Assume first `r>=s`. Then `r>=2`, and the previously verified unbalanced bridge (1.1) gives
\[
\rho(A^rB^s)
\ge
\frac{p^{2r-2}}
{\rho(AB)^{r-2}b^{r-s}}.
\]
Since `rho(AB)<=||AB||=p`,
\[
\rho(A^rB^s)
\ge
\frac{p^r}{b^{r-s}}
=a^r b^s\gamma^r.
\]
This is (4.1). If `s>=r`, interchange `A,B`; `rho(BA)=rho(AB)` and `||BA||=||AB||`, yielding exponent `s`. QED.

Now consider the block word
\[
A^rB^s.
\]
Because both symbols occur, its cyclic word has exactly two transitions. It cannot have a nontrivial period: repeating a shorter nonconstant period would create at least four cyclic transitions. Therefore its cyclic orbit contains exactly `n` distinct words.

Every cyclic rotation has the same characteristic polynomial, by repeated use of the standard `XY/YX` identity for square matrices, and hence the same spectral radius. Since operator norm dominates spectral radius, each of the `n` rotations has norm at least the right side of (4.1).

## Corollary 4.2 — one block orbit
For every `1<=r<=n-1`, the sum of the norms of the `n` cyclic rotations of
\[
A^rB^{n-r}
\]
is at least
\[
\boxed{
n\,a^r b^{n-r}
\gamma^{\max(r,n-r)}.
}
\tag{4.2}
\]

These orbit families are disjoint for different `r`, because they have different multiplicities of `A`.

# 5. New all-`n` augmented matching certificate for arbitrary PSD matrices

Return to arbitrary PSD `A_1,...,A_n`. For each unordered pair `{i,j}`, and for every `r=1,...,n-1`, retain the `n` cyclic rotations of
\[
A_i^rA_j^{n-r}.
\]
Different `r` give disjoint words, different unordered pairs have different support, and these words are disjoint from the pure words. Hence all selected contributions may be added without double counting.

Define
\[
\boxed{
\mathcal C_n(a,\gamma)
:=
\frac1{n^n}
\left[
\sum_{i=1}^n a_i^n
+
n\sum_{i<j}\sum_{r=1}^{n-1}
 a_i^r a_j^{n-r}
 \gamma_{ij}^{\max(r,n-r)}
\right].
}
\tag{5.1}
\]
Corollary 4.2 proves directly that the full with-replacement average `R_n` satisfies
\[
\boxed{R_n\ge \mathcal C_n(a,\gamma).}
\tag{5.2}
\]
Combining with (3.3) gives the main arbitrary-PSD theorem of this run.

## Theorem 5.1 — augmented collision certificate
The full owner inequality holds whenever
\[
\boxed{
\left(\prod_i a_i\right)\mathcal M_n(\gamma)
\le
\mathcal C_n(a,\gamma).
}
\tag{5.3}
\]

This strictly strengthens the previous pure-power matching certificate, because the old right side retained only `sum_i a_i^n/n^n`, while every added term in (5.1) is nonnegative.

### A concrete strict-extension example at `n=4`
Take commuting diagonal matrices
\[
A_i=\operatorname{diag}(t,\ldots,t,1,t,\ldots,t),
\]
with the `1` in coordinate `i`, and choose `t=0.13`. Then `a_i=1` and every pair has
\[
\gamma_{ij}=0.13.
\]
The old pure-word lower bound is
\[
4/4^4=0.015625,
\]
whereas the matching upper bound is
\[
\mathcal M_4=0.13^2=0.0169,
\]
so the previous pure-word certificate fails.

The new selected collision lower bound is
\[
\frac1{64}
\left(1+6\gamma^2+12\gamma^3\right)
=0.0176213125,
\]
which exceeds `0.0169`; hence Theorem 5.1 certifies the full inequality for this family.

For equal norms and a common normalized pair interaction `gamma`, the new `n=4` certificate is valid whenever
\[
64\gamma^2
\le
1+6\gamma^2+12\gamma^3.
\tag{5.4}
\]
The small positive root of equality is
\[
\boxed{\gamma_*=0.1331533609938359\ldots,}
\tag{5.5}
\]
strictly improving the earlier pure-word threshold `1/8=0.125` for this homogeneous-interaction certificate.

This is a certificate improvement, not a claim that `0.13315...` is an intrinsic boundary of the owner inequality.

# 6. Rank-one transfer identity recalled

Let
\[
A_i=a_i u_i u_i^*,\qquad \|u_i\|=1,
\]
and define the absolute Gram kernel
\[
g_{ij}:=|\langle u_i,u_j\rangle|,
\qquad g_{ii}=1.
\tag{6.1}
\]
For every word,
\[
\|A_{i_1}\cdots A_{i_n}\|
=
\left(\prod_{r=1}^n a_{i_r}\right)
\prod_{r=1}^{n-1}g_{i_ri_{r+1}}.
\tag{6.2}
\]
Set
\[
q_i=\sqrt{a_i},
\qquad
M=\operatorname{diag}(q)G\operatorname{diag}(q).
\]
The preceding checkpoint established exactly
\[
\sum_{i_1,\ldots,i_n}
\|A_{i_1}\cdots A_{i_n}\|
=q^TM^{n-1}q.
\tag{6.3}
\]
The distinct average is
\[
L_n=\left(\prod_i a_i\right)H_n(G),
\quad
H_n(G)=\frac1{n!}\sum_{\sigma}
\prod_{r=1}^{n-1}g_{\sigma(r),\sigma(r+1)}.
\tag{6.4}
\]

# 7. New overlap-band theorem for arbitrary scaled rank-one families

Define the smallest and largest distinct absolute overlaps
\[
g_-:=\min_{i\ne j}g_{ij},
\qquad
g_+:=\max_{i\ne j}g_{ij}.
\tag{7.1}
\]
Let
\[
S:=\sum_i a_i,
\qquad
\kappa(a):=
\frac{(S/n)^n}{\prod_i a_i}\ge1.
\tag{7.2}
\]
Also set
\[
d_-:=\frac{1+(n-1)g_-}{n}.
\tag{7.3}
\]

## Theorem 7.1 — scale-sensitive overlap band
For every `n`, every ambient dimension, and arbitrary positive scales `a_i`, the full owner inequality holds for rank-one PSD matrices whenever
\[
\boxed{
 g_+
\le
 d_-\,\kappa(a)^{1/(n-1)}.
}
\tag{7.4}
\]
No positivity assumption on the **absolute** Gram matrix `G=(g_ij)` is required.

### Proof
First, every Hamiltonian path uses exactly `n-1` distinct-overlap factors, each at most `g_+`. Therefore
\[
L_n
\le
\left(\prod_i a_i\right)g_+^{n-1}.
\tag{7.5}
\]

For the repeated-word side, put `c=g_-` and introduce the equiangular comparison kernel
\[
G_c=(1-c)I+c\mathbf1\mathbf1^T.
\tag{7.6}
\]
Entrywise,
\[
G\ge G_c\ge0.
\]
Thus, if
\[
M_c=\operatorname{diag}(q)G_c\operatorname{diag}(q),
\]
then `M>=M_c` entrywise. Products of nonnegative matrices preserve entrywise order, so
\[
M^{n-1}\ge M_c^{n-1}
\quad\text{entrywise}.
\]
Since `q>=0`,
\[
q^TM^{n-1}q
\ge
q^TM_c^{n-1}q.
\tag{7.7}
\]

The matrix `G_c` is PSD for `0<=c<=1`, hence so is `M_c`. Also
\[
q^TM_cq
=(1-c)\sum_i a_i^2+cS^2
\ge
S^2\left(\frac{1-c}{n}+c\right)
=S^2d_-.
\tag{7.8}
\]
The inequality used only `sum_i a_i^2>=S^2/n`.

Apply spectral Jensen to the PSD matrix `M_c` and the convex function `x\mapsto x^{n-1}` on `[0,infinity)`:
\[
q^TM_c^{n-1}q
\ge
S\left(\frac{q^TM_cq}{S}\right)^{n-1}
\ge
S^n d_-^{n-1}.
\tag{7.9}
\]
Therefore the full with-replacement average obeys
\[
R_n
\ge
\left(\frac Sn\right)^n d_-^{n-1}
=
\left(\prod_i a_i\right)
\kappa(a)d_-^{n-1}.
\tag{7.10}
\]
Under (7.4),
\[
\left(\prod_i a_i\right)g_+^{n-1}
\le
\left(\prod_i a_i\right)\kappa(a)d_-^{n-1}
\le R_n.
\]
Together with (7.5), this proves `L_n<=R_n`. QED.

### Scale-free corollary
Since `kappa(a)>=1`, it is enough that
\[
\boxed{
 g_+
\le
\frac{1+(n-1)g_-}{n}.
}
\tag{7.11}
\]
This gives a continuous interpolation between two earlier special cases:

* if `g_-=0`, (7.11) is exactly the earlier universal rank-one coherence condition `g_+<=1/n`;
* if the family is equiangular, `g_+=g_-=c`, and (7.11) becomes `c<=(1+(n-1)c)/n`, which is automatic for `0<=c<=1`.

Thus the previous weak-coherence and equiangular theorems are endpoints of a larger rigorously solved overlap band.

For `n=4`, equal scales are covered whenever
\[
\boxed{g_+\le\frac{1+3g_-}{4}.}
\tag{7.12}
\]
For example, all absolute overlaps in `[0.9,0.925]` are covered, as are all overlaps in `[0.6,0.7]`. The overlaps need not be equal, and the absolute Gram matrix need not itself be PSD.

### Stronger exact comparison certificate
The proof actually gives the stronger computable sufficient condition
\[
\boxed{
\left(\prod_i a_i\right)H_n(G)
\le
\frac1{n^n}q^TM_{g_-}^{\,n-1}q,
}
\tag{7.13}
\]
where `M_{g_-}=diag(q)G_{g_-}diag(q)`. Equation (7.4) is a closed-form consequence obtained by bounding `H_n(G)<=g_+^{n-1}` and applying Jensen.

# 9. Failed / incomplete routes this run

Several stronger ideas were investigated but are **not** promoted to theorem status.

1. **Full arbitrary-`n` rank-one conjecture via walk-versus-Hamiltonian comparison.** The transfer identity suggests the stronger statement that, for every absolute Gram kernel, the normalized weight of all walks dominates the normalized Hamiltonian-path weight. Broad random tests continue to support it, and exhaustive `0/1` kernel tests at very small `n` found no violation, but no proof was obtained. The difficulty is controlling heterogeneous off-diagonal weights without assuming the absolute Gram matrix is PSD.

2. **Profile-by-profile domination is false.** Even for equal scales and symmetric `0/1` kernels with diagonal one, some repeated multiplicity profiles can have lower average path weight than the all-distinct profile. Therefore a proof of the full rank-one case cannot simply show every collision profile individually dominates the distinct profile.

3. **The unrestricted pair product**
\[
\|A^2B^2\|\,\|ABAB\|\stackrel?\ge\|AB\|^4
\]
remains numerically robust but unproved. This run did not find a new noncircular operator interpolation closing it.

4. The new block-orbit certificate selects only words with two cyclic runs for each binary multiplicity. It does not yet exploit the many additional two-label necklaces with four or more runs, nor any three-label collision class.
