# 1. Source scope corrected before new research

The exact source target is, for PSD `A_1,...,A_n`, every `m<=n`, and in particular the operator norm,
\[
\frac1{n^m}\sum_{j_1,\ldots,j_m=1}^n\|A_{j_1}\cdots A_{j_m}\|
\ge
\frac{(n-m)!}{n!}\sum_{\substack{j_1,\ldots,j_m=1\\\text{all distinct}}}^n
\|A_{j_1}\cdots A_{j_m}\|.
\tag{1}
\]
Thus the right side is the **without-replacement** average and the left side is the **with-replacement** average. Israel--Krahmer--Ward prove `m<=3` and explicitly leave `m>=4` open.

Primary/current source checked 16 September 2026:

- https://arxiv.org/abs/1411.0333 (current indexed form is v4)
- DOI `10.1016/j.laa.2015.09.013`

The repository's historical **Bandeira Open Problem 0.2(b)** label was separately recovered from intake `E0044`, rather than assumed to be the same statement. It is **not mathematically the same target**: the Bandeira intake states the spectral norm **outside** each matrix average and asks the reverse direction (permutation average at least with-replacement average), attributed there to Duchi. The adjacent `0.2(a)` is the Recht--Re norm-outside direction. Therefore `Open Problem 0.2(b)` is retained here only as a **legacy campaign provenance alias**, not as an equivalence of statements.

This distinction matters: Lai--Lim 2020 refute the Recht--Re norm-outside statement, not (1). The old E0044 intake also contains an explicitly unverified rank-one/tiny-vector candidate for its different norm-outside reverse statement; it is not evidence against (1).

# 4. Counterexample-first exact rational search

This run followed the revised instruction to try to refute before proving new lemmas. Two independent exact/certified searches were executed.

## 4.1 Exact rational rank-one Gram search in R^2

For rational unit vectors `u_i` and rational positive scales `a_i`, set
\[
A_i=a_i u_i u_i^T.
\]
Then every word norm is exactly
\[
\boxed{
\|A_{i_1}\cdots A_{i_m}\|
=\left(\prod_{r=1}^m a_{i_r}\right)
\prod_{r=1}^{m-1}|\langle u_{i_r},u_{i_{r+1}}\rangle|,
}
\tag{2}
\]
so all tested averages and ratios are rational numbers. No floating-point comparison is needed.

The checker exhausts every `n`-subset, `4<=n<=8`, of a fixed ten-line rational Pythagorean pool and every source length `4<=m<=n`. This is **837 subsets and 2,049 exact source instances**. No ratio exceeded one.

The largest nontrivial ratio in this exact pool is the first unresolved diagonal case `(n,m)=(4,4)`:
\[
\boxed{
\mathcal R=
\frac{839708200000}{928418197493}
=0.904450389132243\ldots <1.
}
\tag{3}
\]
For the genuinely source-wider case `(n,m)=(5,4)`, the exact maximum in this pool is
\[
\boxed{
\mathcal R=
\frac{6660477147970000000}{7512470336326168587}
=0.886589477200808\ldots <1.
}
\tag{4}
\]
The script also checks the equality baseline exactly for `n=4,...,8`, all `m=4,...,n`.

On the hardest equal-scale geometries found for `n=4,5,6`, it then exhausts all scale vectors in `{1/2,1,2}^n`, for **2,754 additional exact source instances**. In every tested `(n,m)` the largest ratio occurs at a common scale; none exceeds the equal-scale value.

## 4.3 General 2 x 2 integer PSD matrices with certified algebraic singular values

To leave the rank-one locus, a fixed library of 16 distinct integer `2 x 2` PSD matrices was searched. For every distinct 4-subset and 5-subset, the source case `m=4` was evaluated. This gives

- `C(16,4)=1,820` source instances at `(n,m)=(4,4)`,
- `C(16,5)=4,368` source instances at `(n,m)=(5,4)`,
- **6,188 certified full-rank/rank-mixed instances total**.

For an integer product
\[
P=\begin{pmatrix}a&b\\c&d\end{pmatrix},
\]
write
\[
s=a^2+b^2+c^2+d^2,\qquad \delta=ad-bc.
\]
The operator norm is the exact algebraic number
\[
\boxed{
\|P\|_2=
\sqrt{\frac{s+\sqrt{s^2-4\delta^2}}2}.
}
\tag{6}
\]
The checker encloses each nested square root between adjacent dyadic rationals using integer `isqrt` at 60 fractional bits. It then forms a rigorous lower/upper interval for every WR and WOR average. A configuration is declared safe only when
\[
\frac{\mathrm{WOR}_{\rm upper}}{\mathrm{WR}_{\rm lower}}<1.
\]
Thus the finite no-counterexample claim is certified algebraically, not inferred from decimal SVD output.

The largest rigorous upper endpoints were
\[
\boxed{
\mathcal R_{4,4}<
\frac{5578442930663008110048}{6167854078388506852873}
=0.904438214614913\ldots,
}
\tag{7}
\]
and
\[
\boxed{
\mathcal R_{5,4}<
\frac{30976227745103649874625}{34111847527388582941602}
=0.908078277502638\ldots.
}
\tag{8}
\]
All 6,188 certified upper bounds are strictly below one.

Across the two executed artifacts this run therefore checks **12,815 exact/certified source configurations** beyond the equality baseline. This is a finite counterexample search, not a proof of the conjecture.
