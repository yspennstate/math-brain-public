# 3. Joint two-exponent log-convexity

For PSD `A,B`, define
\[
G(x,y):=\|A^xB^y\|,\qquad x,y\ge0.
\]

## Theorem 3.1
For any `(x_0,y_0),(x_1,y_1)` in `[0,infinity)^2` and `0<=theta<=1`,
\[
\boxed{
G((1-\theta)x_0+\theta x_1,(1-\theta)y_0+\theta y_1)
\le
G(x_0,y_0)^{1-\theta}G(x_1,y_1)^\theta.
}
\tag{3.1}
\]
Thus `(x,y) -> log ||A^xB^y||` is jointly convex wherever the norm is nonzero.

### Proof
First suppose `A,B>0`. Put
\[
\Delta x=x_1-x_0,\qquad \Delta y=y_1-y_0,
\]
and consider the analytic matrix-valued function on the strip `0<=Re z<=1`,
\[
F(z)=A^{x_0+z\Delta x}B^{y_0+z\Delta y}.
\]
On the line `z=it`, functional calculus and commutation of powers of the same matrix give
\[
F(it)=A^{it\Delta x}A^{x_0}B^{y_0}B^{it\Delta y}.
\]
The two imaginary powers are unitary, hence
\[
\|F(it)\|=G(x_0,y_0).
\]
Similarly,
\[
\|F(1+it)\|=G(x_1,y_1).
\]
For arbitrary unit vectors `u,v`, apply Hadamard three-lines to the scalar analytic function `u^*F(z)v`, then take the supremum over `u,v`. At real `z=theta` this gives (3.1).

For merely PSD `A,B`, apply the positive-definite result to `A+epsilon I,B+epsilon I` and let `epsilon` decrease to zero. Nonnegative real matrix powers and the operator norm are continuous in this limit. QED.

The preceding equal-power theorem is the restriction of (3.1) to the diagonal `x=y`.

# 4. New unbalanced spectral-radius bridge

The joint theorem supplies information that the diagonal interpolation cannot see.

Let integers
\[
r\ge s\ge1,\qquad r\ge2,
\]
and abbreviate
\[
p:=\|AB\|,\qquad \varrho:=\rho(AB),\qquad b:=\|B\|.
\]

## Theorem 4.1
For arbitrary PSD `A,B`,
\[
\boxed{
\rho(A^rB^s)
\ge
\frac{p^{2r-2}}{\varrho^{r-2}b^{r-s}}.
}
\tag{4.1}
\]
By symmetry, if `s>=r>=1` and `s>=2`,
\[
\boxed{
\rho(A^rB^s)
\ge
\frac{p^{2s-2}}{\varrho^{s-2}\|A\|^{s-r}}.
}
\tag{4.2}
\]

### Proof of (4.1)
If `p=0`, the claim is trivial, so assume `p>0`. Apply Theorem 3.1 between
\[
D=(1/2,1/2),\qquad T=(r/2,s/2)
\]
with
\[
\theta=\frac1{r-1}.
\]
The interpolated first coordinate is exactly `1`, while the second is
\[
\beta
=\frac{r+s-2}{2(r-1)}\le1.
\]
Hence
\[
G(1,\beta)
\le
G(1/2,1/2)^{1-\theta}G(r/2,s/2)^\theta.
\tag{4.3}
\]
Now
\[
G(1/2,1/2)^2
=\|B^{1/2}AB^{1/2}\|
=\rho(AB)=\varrho.
\tag{4.4}
\]
On the other hand, because `0<=beta<=1`,
\[
p=\|AB\|
=\|AB^\beta B^{1-\beta}\|
\le
G(1,\beta)b^{1-\beta},
\]
so
\[
G(1,\beta)\ge p\,b^{-(1-\beta)}.
\tag{4.5}
\]
Combining (4.3)–(4.5) and raising to the power `r-1=1/theta` gives
\[
G(r/2,s/2)
\ge
\frac{p^{r-1}}
{\varrho^{(r-2)/2}b^{(r-s)/2}}.
\tag{4.6}
\]
Finally,
\[
G(r/2,s/2)^2
=\|B^{s/2}A^rB^{s/2}\|
=\rho(A^rB^s),
\tag{4.7}
\]
because `B^{s/2}A^rB^{s/2}` is PSD and has the same characteristic polynomial, up to the standard `XY/YX` identity, as `A^rB^s`. Squaring (4.6) proves (4.1). QED.

At `r=s=m`, (4.1) reduces exactly to the previous equal-power hierarchy. At `r=3,s=1`, it yields the concrete new estimate
\[
\rho(A^3B)\ge\frac{\|AB\|^4}{\rho(AB)\|B\|^2}.
\tag{4.8}
\]

# 5. Cyclic-orbit lower bound for every two-label occupancy

Let `C_{r,s}^{\{A,B\}}` denote the sum of norms of **all** binary words with exactly `r` copies of `A` and `s` copies of `B`.

The block word
\[
A^rB^s
\]
has exactly `r+s` distinct cyclic rotations when `r,s>0`. Successive cyclic rotations are `XY`/`YX` partners, so all have the same characteristic polynomial and therefore the same spectral radius `rho(A^rB^s)`. Every operator norm is at least its spectral radius.

Combining this with (4.1) proves:

## Theorem 5.1
For integers `r>=s>=1`, `r>=2`,
\[
\boxed{
C_{r,s}^{\{A,B\}}
\ge
(r+s)\frac{\|AB\|^{2r-2}}
{\rho(AB)^{r-2}\|B\|^{r-s}}.
}
\tag{5.1}
\]
The symmetric formula obtained by interchanging `A,B` holds when `s>=r`.

This is a lower bound for the **complete** occupancy class, obtained by retaining only one certified cyclic orbit; omitted words are nonnegative and need no control.

For the four-letter `3+1` class, (5.1) gives, for the four `A`-heavy words,
\[
C_{3,1}^{A\text{-heavy}}
\ge
4\frac{p^4}{\varrho\,b^2},
\]
and by swapping the letters the complete pair contribution obeys
\[
Q_{31}^{\{A,B\}}
\ge
4\frac{p^4}{\varrho}
\left(\frac1{\|A\|^2}+\frac1{\|B\|^2}\right).
\tag{5.2}
\]
This is a useful scale/spectral-sensitive supplement to the already stronger uniform theorem `Q_31^{\{A,B\}}>=8p^2`; it does not improve the present unrestricted `n=4` scalar minimum by itself.

# 6. Stronger balanced collision theorem

Now set `r=s=m>=2` and write
\[
t:=\frac{\rho(AB)}{\|AB\|}\in(0,1]
\]
when `p=||AB||>0`.

The cyclic block orbit in Theorem 5.1 contains `2m` words and contributes at least
\[
2m\frac{p^{2m-2}}{\varrho^{m-2}}
=2m p^m t^{-(m-2)}.
\tag{6.1}
\]
For `m>=2`, the two alternating words `(AB)^m` and `(BA)^m` are not in that block orbit. Each has norm at least its spectral radius `varrho^m=p^m t^m`. Therefore
\[
\boxed{
C_{m,m}^{\{A,B\}}
\ge
2p^m\left(m t^{-(m-2)}+t^m\right).
}
\tag{6.2}
\]

For `m>=3`, the scalar bracket is minimized at `t=1`. Indeed, put `x=1/t>=1` and
\[
f_m(x)=m x^{m-2}+x^{-m}.
\]
Then
\[
f_m'(x)
=m x^{-m-1}\big((m-2)x^{2m-2}-1\big)\ge0,
\]
with equality at the endpoint only in the borderline `m=3,x=1` case. Hence
\[
f_m(x)\ge f_m(1)=m+1.
\]
We obtain the new theorem
\[
\boxed{
C_{m,m}^{\{A,B\}}
\ge2(m+1)\|AB\|^m,
\qquad m\ge3.
}
\tag{6.3}
\]

This improves the preceding checkpoint's coefficient `8` whenever `m>=4`; for `m=3` both give `8`.

Examples:
\[
C_{3,3}\ge8\|AB\|^3,
\qquad
C_{4,4}\ge10\|AB\|^4,
\qquad
C_{5,5}\ge12\|AB\|^5.
\]

The case `m=2` remains exceptional. Formula (6.2) gives only
\[
C_{2,2}\ge 4p^2+2\rho(AB)^2,
\]
whereas the archived `n=4` interpolation/Jensen analysis gives the stronger dimension-free aggregate control responsible for the current `0.758991...` factor.

# 7. Aggregate even-length consequence

For `2m` PSD matrices define
\[
P_m:=\sum_{i<j}\|A_iA_j\|^m,
\]
and let `Q_{m,m}` be the complete length-`2m` occupancy layer supported on two labels with multiplicities `(m,m)`.

Summing (6.3) over all unordered pairs gives
\[
\boxed{
Q_{m,m}\ge2(m+1)P_m,
\qquad m\ge3.
}
\tag{7.1}
\]

The preceding verified checkpoint proved by perfect-matching enumeration and scalar AM–GM that the all-distinct sum satisfies
\[
\boxed{
S_{2m}\le2(2m-2)!P_m.
}
\tag{7.2}
\]
Combining the independent bounds (7.1) and (7.2),
\[
\boxed{
Q_{m,m}
\ge
\frac{m+1}{(2m-2)!}
S_{2m},
\qquad m\ge3.
}
\tag{7.3}
\]

Concrete instances are
\[
Q_{3,3}\ge\frac16S_6,
\]
\[
\boxed{Q_{4,4}\ge\frac1{144}S_8},
\]
\[
\boxed{Q_{5,5}\ge\frac1{6720}S_{10}}.
\]
The old coefficient was `4/(2m-2)!`; the new one is `(m+1)/(2m-2)!`, so the gain factor is `(m+1)/4`, strictly larger than one for every `m>=4`.

This is still only one occupancy layer and is not a proof of the full `n=2m` conjecture. Its value is that it supplies a growing exact payment from a difficult repeated-word layer using only pair norms and no dimension/rank assumptions.
