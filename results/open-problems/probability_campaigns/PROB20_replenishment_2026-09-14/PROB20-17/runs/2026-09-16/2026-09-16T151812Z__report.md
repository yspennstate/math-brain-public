# 3. New theorem: quadratic local stability at the rank-one equality manifold

The immediately preceding checkpoint recommended concentrating the next refutation attempt near the equality manifold. This run does so analytically.

Fix integers `2<=m<=n`, a unit vector `e in C^d`, and tangent vectors
\[
v_1,\ldots,v_n\in e^\perp.
\]
For real `t` define unit vectors
\[
u_i(t)=\frac{e+t v_i}{\sqrt{1+t^2\|v_i\|^2}},
\qquad
A_i(t)=u_i(t)u_i(t)^*.
\tag{3.1}
\]
Each `A_i(t)` is a rank-one PSD projector. Put
\[
\bar v=\frac1n\sum_{i=1}^n v_i,
\qquad
V=\frac1n\sum_{i=1}^n\|v_i-\bar v\|^2.
\tag{3.2}
\]
Let `WR_m(t)` and `WOR_m(t)` denote the two source averages in (2.1), with the operator norm.

**Theorem.** As `t->0`,
\[
\boxed{
\operatorname{WR}_m(t)
=1-(m-1)Vt^2+O(t^4),
}
\tag{3.3}
\]
\[
\boxed{
\operatorname{WOR}_m(t)
=1-(m-1)\frac{n}{n-1}Vt^2+O(t^4),
}
\tag{3.4}
\]
and consequently
\[
\boxed{
\frac{\operatorname{WOR}_m(t)}{\operatorname{WR}_m(t)}
=1-\frac{m-1}{n-1}Vt^2+O(t^4).
}
\tag{3.5}
\]
In particular, if the projective tangent directions are not all equal (`V>0`), then there exists `delta>0` such that
\[
0<|t|<\delta
\quad\Longrightarrow\quad
\operatorname{WOR}_m(t)<\operatorname{WR}_m(t).
\tag{3.6}
\]
If all `v_i` are equal, then in the explicit family (3.1) all `u_i(t)` are equal and equality holds identically.

This theorem is source-valid for **every** `m<=n`, including the genuinely wider cases `m<n`; it is not restricted to the diagonal specialization `m=n` studied in many older checkpoints.

## 3.1 Exact rank-one word formula

For unit vectors `u_i`, rank-one projectors satisfy
\[
A_{i_1}\cdots A_{i_m}
=
\left(\prod_{r=1}^{m-1}\langle u_{i_r},u_{i_{r+1}}\rangle\right)
 u_{i_1}u_{i_m}^*.
\]
Since the rank-one endpoint operator has norm one,
\[
\boxed{
\|A_{i_1}\cdots A_{i_m}\|
=
\prod_{r=1}^{m-1}
|\langle u_{i_r},u_{i_{r+1}}\rangle|.
}
\tag{3.7}
\]

## 3.2 Pairwise overlap expansion

From (3.1),
\[
\langle u_i(t),u_j(t)\rangle
=
\frac{1+t^2\langle v_i,v_j\rangle}
{\sqrt{(1+t^2\|v_i\|^2)(1+t^2\|v_j\|^2)}}.
\tag{3.8}
\]
For any fixed complex `z`,
\[
|1+t^2z|=1+t^2\operatorname{Re}z+O(t^4).
\]
Also
\[
(1+t^2a)^{-1/2}=1-\frac12at^2+O(t^4).
\]
Therefore
\[
\begin{aligned}
|\langle u_i(t),u_j(t)\rangle|
&=1+t^2\operatorname{Re}\langle v_i,v_j\rangle
-\frac{t^2}{2}(\|v_i\|^2+\|v_j\|^2)+O(t^4)\\
&=\boxed{1-\frac{t^2}{2}\|v_i-v_j\|^2+O(t^4)}.
\end{aligned}
\tag{3.9}
\]
There are only finitely many pairs, so the remainder is uniform over `i,j`.

Substituting (3.9) into (3.7), for each fixed length-`m` word,
\[
\|A_{i_1}(t)\cdots A_{i_m}(t)\|
=
1-\frac{t^2}{2}
\sum_{r=1}^{m-1}\|v_{i_r}-v_{i_{r+1}}\|^2
+O(t^4),
\tag{3.10}
\]
again uniformly over the finite word set.

## 3.3 With-replacement average

Under ordered sampling with replacement, each consecutive pair is an independent uniform ordered pair `(I,J)` from `[n]^2`. The elementary variance identity is
\[
\frac1{n^2}\sum_{i,j=1}^n\|v_i-v_j\|^2
=2V.
\tag{3.11}
\]
Averaging (3.10) over all `n^m` words gives
\[
\operatorname{WR}_m(t)
=1-\frac{t^2}{2}(m-1)(2V)+O(t^4),
\]
which is (3.3).

## 3.4 Without-replacement average

Under an ordered sample of `m` distinct indices, each consecutive pair is uniform over the `n(n-1)` ordered distinct pairs. Since diagonal pair distances vanish,
\[
\frac1{n(n-1)}
\sum_{i\ne j}\|v_i-v_j\|^2
=
\frac{n}{n-1}\,2V.
\tag{3.12}
\]
Averaging (3.10) over ordered distinct words gives
\[
\operatorname{WOR}_m(t)
=1-\frac{t^2}{2}(m-1)
\frac{2n}{n-1}V+O(t^4),
\]
which is (3.4).

Finally, both averages equal one at `t=0`, so dividing their expansions gives (3.5). If `V>0`, the quadratic coefficient in (3.5) is strictly negative, proving (3.6).

# 4. Interpretation for counterexample search

The exact equality family is not merely a fragile point for rank-one matrices. In every nontrivial projective tangent direction of the normalized family (3.1), the source ratio bends **below** one at quadratic order. Thus a rank-one counterexample cannot emerge infinitesimally from the common-projector equality manifold along such a direction.

For the first genuinely wider frontier `(n,m)=(5,4)`, (3.5) becomes
\[
\frac{\operatorname{WOR}_4(t)}{\operatorname{WR}_4(t)}
=1-\frac34 Vt^2+O(t^4).
\tag{4.1}
\]
For the two-dimensional rational half-angle parametrization used in the checker below, the tangent velocity is twice the scalar parameter, so the coefficient becomes
\[
-\frac{4(m-1)}{n-1}\operatorname{Var}(x).
\tag{4.2}
\]
This gives an exact diagnostic for near-equality searches rather than merely observing numerically that the ratio is below one.

The result does **not** prove a full neighborhood theorem for arbitrary full-rank PSD perturbations of an equality configuration, and it does not decide whether a counterexample can exist away from the common rank-one manifold.
