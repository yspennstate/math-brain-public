# PROB20-17 — norm-inside-average noncommutative AM–GM

**SOLUTION STATUS: PARTIAL**

Target (diagonal case requested by the owner): for arbitrary \(n\) and arbitrary PSD \(d\times d\) matrices \(A_1,\dots,A_n\),
\[
\frac1{n!}\sum_{\sigma\in S_n}\|A_{\sigma(1)}\cdots A_{\sigma(n)}\|
\le
\frac1{n^n}\sum_{k_1,\dots,k_n\in[n]}\|A_{k_1}\cdots A_{k_n}\|
\]
in operator norm.  The norm is **inside** both sums.

This run attacks the first unresolved diagonal instance \(n=4\).  It proves a new universal approximation factor
\[
\boxed{
\frac{(R/256)}{(S/24)}\ge 0.5744713549163718\ldots
}
\]
for arbitrary PSD \(A_1,A_2,A_3,A_4\), where
\[
S:=\sum_{\sigma\in S_4}\|A_{\sigma(1)}A_{\sigma(2)}A_{\sigma(3)}A_{\sigma(4)}\|,
\qquad
R:=\sum_{i,j,k,\ell=1}^4\|A_iA_jA_kA_\ell\|.
\]
Equivalently,
\[
\boxed{R\ge 6.127694452441299\ldots\,S.}
\]
The conjectured \(n=4\) value is \(R\ge \frac{32}{3}S\), so this is partial.

# 1. Occupancy decomposition for \(n=4\)

Partition the 256 words by multiplicity pattern:
\[
R=S+Q_{211}+Q_{22}+Q_{31}+Q_4.
\]

Here:

* \(S\): all four indices distinct, 24 words;
* \(Q_{211}\): one index repeated twice and two other distinct indices, 144 words;
* \(Q_{22}\): two indices each repeated twice, 36 words;
* \(Q_{31}\): one index repeated three times and one other index once, 48 words;
* \(Q_4\): four equal indices, 4 words.

Let
\[
a_i:=\|A_i\|,\qquad
p_{ij}:=\|A_iA_j\|,\qquad
P_2:=\sum_{1\le i<j\le4}p_{ij}^2,
\qquad
Q_4=\sum_{i=1}^4 a_i^4.
\]

If \(S=0\), every claimed lower bound is trivial, so assume \(S>0\).

# 2. Two endpoint \(2+1+1\) classes pay \(2S\)

Kosaki's two-sided matrix AM–GM inequality, in the form used by Israel–Krahmer–Ward, gives for PSD \(A,D\) and arbitrary \(X\)
\[
2\|AXD\|\le \|A^2X\|+\|XD^2\|.
\]
Set \(X=BC\).  For every distinct ordered quadruple \((A,B,C,D)\),
\[
2\|ABCD\|
\le
\|A^2BC\|+\|BCD^2\|.
\tag{2.1}
\]

Summing (2.1) over all 24 permutations shows that the two endpoint-repeat positional classes together satisfy
\[
C_{12}+C_{34}\ge 2S.
\tag{2.2}
\]

By adjoint invariance, \(C_{12}=C_{34}\), but only (2.2) is needed.

# 3. New cross-position inequality: \(C_{13}\ge S^2/(6Q_4)\)

This is the new lemma of the run.

Let \(A,B,C,D\succeq0\) be distinct members of the four-matrix set and put
\[
N:=\|ABCD\|,
\qquad
q:=\|BCBA\|.
\]

Israel–Krahmer–Ward's Cauchy/AM–GM inequality
\[
\|X_1 X_2 X_3\|^2
\le
\|X_1X_2X_1^*\|\,
\|X_3^*X_2X_3\|
\tag{3.1}
\]
holds when \(X_2\succeq0\).  Apply it with
\[
X_1=AB,\quad X_2=C,\quad X_3=D.
\]
Then
\[
N^2
\le
\|ABCBA\|\,\|DCD\|.
\]
By submultiplicativity,
\[
\|ABCBA\|
\le
\|A\|\,\|BCBA\|
=a\,q,
\]
where \(a=\|A\|\).  Also
\[
\|DCD\|\le d^2c
\]
with \(c=\|C\|\), \(d=\|D\|\).  Hence
\[
N^2\le q\,a c d^2.
\tag{3.2}
\]

For every \(t>0\), scalar AM–GM gives
\[
2N
\le
tq+\frac{acd^2}{t}
\le
tq+\frac{a^4+c^4+2d^4}{4t}.
\tag{3.3}
\]

Now sum (3.3) over all 24 distinct ordered quadruples.

The first term \(q=\|BCBA\|\) runs bijectively through the 24 words in the positional \(C_{13}\) class (repeated index in positions 1 and 3).  The pure fourth-power term counts each \(a_i^4\) with total coefficient \(6/t\).  Therefore
\[
2S\le t\,C_{13}+\frac6t\,Q_4
\qquad(t>0).
\tag{3.4}
\]

Rearranging,
\[
C_{13}\ge \frac{2S}{t}-\frac{6Q_4}{t^2}.
\]
Optimizing the right-hand side at
\[
t=\frac{6Q_4}{S}
\]
gives
\[
\boxed{
C_{13}\ge \frac{S^2}{6Q_4}.
}
\tag{3.5}
\]

Reversal/adjoint invariance gives \(C_{24}=C_{13}\).  Since the remaining \(C_{23}\) and \(C_{14}\) classes are nonnegative,
\[
\boxed{
Q_{211}\ge 2S+\frac{S^2}{3Q_4}.
}
\tag{3.6}
\]

This strictly strengthens the endpoint-only estimate \(Q_{211}\ge2S\) whenever \(S>0\).

# 4. The \(2+2\) layer satisfies \(Q_{22}\ge4P_2\)

Fix a pair \(A,B\succeq0\), and let \(p=\|AB\|=\|BA\|\).

Two palindromic words satisfy
\[
\|AB^2A\|=\|BA\|^2=p^2,
\qquad
\|BA^2B\|=\|AB\|^2=p^2.
\]

Also
\[
\rho(A^2B^2)=\rho(AB^2A)=p^2,
\]
because \(A^2B^2\) and \(AB^2A\) have the same nonzero spectrum by the \(XY/YX\) principle.  Therefore
\[
\|A^2B^2\|\ge p^2.
\]
Similarly
\[
\|B^2A^2\|\ge p^2.
\]

Thus the six \(2+2\) words from this unordered pair contribute at least \(4p^2\).  Summing over the six unordered pairs,
\[
\boxed{
Q_{22}\ge4P_2.
}
\tag{4.1}
\]

# 5. Re-check of the \(3+1\) lemma and aggregate bound

The earlier task-context \(3+1\) lemma was re-checked because it depends on the direction of the Araki–Lieb–Thirring inequality.

## Lemma 5.1

For \(A,B\succeq0\), put
\[
b:=\|B\|,
\qquad
p:=\|AB\|.
\]
If \(b>0\), then each of
\[
A^3B,\quad A^2BA,\quad ABA^2,\quad BA^3
\]
has operator norm at least
\[
\frac{p^3}{b^2}.
\tag{5.1}
\]

### Proof

Set \(C=B/b\), so \(0\preceq C\preceq I\), and let
\[
q:=\|AC\|=p/b.
\]
Then
\[
q^2=\|CA^2C\|.
\]

The \(r=3/2\) Araki–Lieb–Thirring inequality in operator norm gives
\[
\|C^{3/2}A^3C^{3/2}\|
\ge
\|CA^2C\|^{3/2}
=q^3.
\tag{5.2}
\]

The PSD matrices
\[
C^{3/2}A^3C^{3/2}
\quad\text{and}\quad
A^{3/2}C^3A^{3/2}
\]
have the same nonzero eigenvalues, hence the same norm.  Since \(0\preceq C^3\preceq C\),
\[
\|A^{3/2}CA^{3/2}\|\ge q^3.
\tag{5.3}
\]

The matrix \(A^3C\) has the same nonzero spectrum as the PSD matrix \(A^{3/2}CA^{3/2}\), so
\[
\|A^3C\|
\ge
\rho(A^3C)
=
\|A^{3/2}CA^{3/2}\|
\ge q^3.
\]
Likewise \(A^2CA\) is similar (after regularization if \(A\) is singular) to \(A^{3/2}CA^{3/2}\), so
\[
\|A^2CA\|\ge q^3.
\]
Taking adjoints gives the corresponding bounds for \(ACA^2\) and \(CA^3\).

Multiplying back by \(b\) proves (5.1).

If \(b=0\), then \(B=0\) and the statement is trivial.

## Aggregate consequence

For each unordered pair \(\{i,j\}\), its eight \(3+1\) words therefore contribute at least
\[
4p_{ij}^3\left(a_i^{-2}+a_j^{-2}\right),
\]
with zero-norm cases interpreted by continuity/triviality.

Hence
\[
Q_{31}
\ge
4\sum_{i\ne j}\frac{p_{ij}^3}{a_i^2}.
\tag{5.4}
\]

Use Hölder:
\[
2P_2
=
\sum_{i\ne j}p_{ij}^2
=
\sum_{i\ne j}
\left(\frac{p_{ij}^3}{a_i^2}\right)^{2/3}
a_i^{4/3}
\]
so
\[
2P_2
\le
\left(\sum_{i\ne j}\frac{p_{ij}^3}{a_i^2}\right)^{2/3}
\left(\sum_{i\ne j}a_i^4\right)^{1/3}.
\]
Each \(a_i^4\) occurs three times in the oriented sum, so
\[
\sum_{i\ne j}a_i^4=3Q_4.
\]
Therefore
\[
\sum_{i\ne j}\frac{p_{ij}^3}{a_i^2}
\ge
\frac{(2P_2)^{3/2}}{(3Q_4)^{1/2}}.
\]
Combining with (5.4),
\[
\boxed{
Q_{31}
\ge
8\sqrt{\frac23}\,
\frac{P_2^{3/2}}{\sqrt{Q_4}}.
}
\tag{5.5}
\]

# 6. Two elementary constraints on \(S\)

First, split a distinct word into adjacent pairs:
\[
\|A_iA_jA_kA_\ell\|
\le
p_{ij}p_{k\ell}.
\]
Summing over all 24 permutations yields
\[
S\le
8\bigl(
p_{12}p_{34}+p_{13}p_{24}+p_{14}p_{23}
\bigr).
\]
By \(2xy\le x^2+y^2\) on each complementary pair,
\[
\boxed{
S\le4P_2.
}
\tag{6.1}
\]

Second, submultiplicativity and scalar AM–GM give, for every distinct word,
\[
\|A_iA_jA_kA_\ell\|
\le
a_ia_ja_ka_\ell
\le
\frac{a_1^4+a_2^4+a_3^4+a_4^4}{4}
=
\frac{Q_4}{4}.
\]
There are 24 distinct words, hence
\[
\boxed{
S\le6Q_4.
}
\tag{6.2}
\]

# 7. New universal \(n=4\) constant

Combine
\[
R=S+Q_{211}+Q_{22}+Q_{31}+Q_4
\]
with (3.6), (4.1), and (5.5):
\[
R
\ge
3S+\frac{S^2}{3Q_4}
+4P_2
+8\sqrt{\frac23}\frac{P_2^{3/2}}{\sqrt{Q_4}}
+Q_4.
\tag{7.1}
\]

Normalize by
\[
s:=\frac{S}{P_2},
\qquad
q:=\frac{Q_4}{P_2}.
\]
By (6.1) and (6.2),
\[
0<s\le4,
\qquad
s\le6q.
\tag{7.2}
\]

Dividing (7.1) by \(S\),
\[
\frac RS
\ge
3+\frac{s}{3q}
+\frac{4+8\sqrt{2/3}\,q^{-1/2}+q}{s}.
\tag{7.3}
\]

For fixed \(q\), the right-hand side is decreasing throughout the feasible \(s\)-interval, so the minimum occurs at
\[
s=\min(4,6q).
\]

### Region 1: \(0<q\le2/3\)

Set \(s=6q\).  The lower bound is decreasing in \(q\) on this interval, so its minimum is at \(q=2/3\), where it equals
\[
\frac{49}{6}=8.1666\ldots.
\]

### Region 2: \(q\ge2/3\)

Set \(s=4\).  Then
\[
\frac RS
\ge
F(q)
:=
4+\frac q4+\frac{4}{3q}
+2\sqrt{\frac{2}{3q}}.
\tag{7.4}
\]

Write \(q=x^2\).  The unique minimizer \(x_*\ge\sqrt{2/3}\) is the unique root in that interval of
\[
\boxed{
3x^4-4\sqrt6\,x-16=0.
}
\tag{7.5}
\]
Numerically,
\[
x_*=1.8344502390076465,
\qquad
q_*=3.3652076793952115.
\]
At this point
\[
\boxed{
\frac RS
\ge
F(q_*)
=
6.127694452441299\ldots.
}
\tag{7.6}
\]

Therefore
\[
\boxed{
\frac{R/256}{S/24}
=
\frac{3R}{32S}
\ge
0.5744713549163718\ldots.
}
\tag{7.7}
\]

This improves the endpoint-only approximation factor
\[
0.5297778397\ldots
\]
for arbitrary PSD matrices.

# 9. Failed / blocked routes recorded this run

1. **Termwise collision domination is too strong.**  Individual \(2+1+1\) words can be smaller than all-distinct words; only aggregate inequalities are credible.

2. **The projection cross-compression lemma does not extend verbatim to positive contractions.**  Random PSD-contraction tests produce violations of
   \[
   \|ABCD\|^2\le\|BABC\|\,\|CDCB\|.
   \]
   Therefore the projection proof route cannot be lifted by simply replacing projections with contractions.

3. **Pure linear word-norm relaxations are weak.**  An LP using reversal symmetry, endpoint Kosaki inequalities, pair-split Cauchy inequalities, and fourth-power Hölder constraints has a much weaker optimum than the nonlinear \(P_2,Q_4\) argument.  This indicates that nonlinear scale information is essential.
