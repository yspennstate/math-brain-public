# PROB20-17 — norm-inside-average noncommutative AM–GM

**SOLUTION STATUS: PARTIAL.**

The full Bandeira/Duchi norm-inside-average conjecture remains open.  The exact target is, for arbitrary `n` and arbitrary PSD `d x d` matrices `A_1,...,A_n`,
\[
\frac1{n!}\sum_{\sigma\in S_n}\|A_{\sigma(1)}\cdots A_{\sigma(n)}\|
\le
\frac1{n^n}\sum_{k_1,\dots,k_n\in[n]}\|A_{k_1}\cdots A_{k_n}\|,
\]
with spectral norm **inside** both averages.  The norm-outside Recht–Ré counterexample is a different statement.

This run continues the first unresolved diagonal instance `n=m=4`.  For PSD `A_1,...,A_4`, write
\[
S:=\sum_{\sigma\in S_4}\|A_{\sigma(1)}A_{\sigma(2)}A_{\sigma(3)}A_{\sigma(4)}\|,
\qquad
R:=\sum_{i,j,k,\ell=1}^4\|A_iA_jA_kA_\ell\|.
\]
The sharp target is `3R>=32S`.

The strongest durable arbitrary-dimensional quantitative theorem remains
\[
\boxed{\frac{R/256}{S/24}\ge0.7303902120286716\ldots}.
\]
This run does **not** increase that constant.  It contributes two exact pieces of new structure:

1. a Heinz-similarity bridge that reduces the sharp unresolved two-matrix `2+2` problem to one concrete upper/geometric-mean inequality; and
2. an exact rational rank-one certificate showing that the tempting stronger positional claim `C_23>=S` is false, even though the weaker aggregate conjecture `C_23>=S^2/(4P)` survives the same example.

It also records an exact Bhatia–Davis upper coupling for `C_23` and a failed complex-interpolation path, so these routes are not repeatedly rediscovered.

# 3. The unresolved sharp pairwise `2+2` problem

For PSD `A,B`, set
\[
p:=\|AB\|,
\qquad
x:=\|A^2B^2\|,
\qquad
y:=\|ABAB\|.
\]
The most valuable pairwise target remains
\[
\boxed{x+y\stackrel{?}{\ge}2p^2.}
\tag{3.1}
\]
A stronger sufficient statement is
\[
\boxed{xy\stackrel{?}{\ge}p^4.}
\tag{3.2}
\]
Indeed, (3.2) implies (3.1) by scalar AM–GM.

If (3.1) held for all PSD pairs, then each unordered pair's six `2+2` words would contribute at least `6p^2`, giving globally
\[
Q_{22}\ge6P\ge\frac32S,
\]
which is the equal-matrix coefficient for the complete `2+2` layer.

# 4. New exact Heinz-similarity bridge

## Theorem 4.1
For arbitrary PSD `A,B`, define
\[
U:=A^{3/2}B^2A^{1/2}.
\]
Then
\[
\boxed{
\|U+U^*\|\ge2\|AB\|^2.
}
\tag{4.1}
\]

### Proof
First suppose `A>0`.  Put
\[
S_0:=A^{1/2},
\qquad
T:=AB^2A.
\]
Then `S_0` is self-adjoint and invertible, while `T` is PSD.  Apply (2.1):
\[
\|S_0TS_0^{-1}+S_0^{-1}TS_0\|\ge2\|T\|.
\]
The two similarity terms are
\[
S_0TS_0^{-1}=A^{3/2}B^2A^{1/2}=U,
\]
\[
S_0^{-1}TS_0=A^{1/2}B^2A^{3/2}=U^*.
\]
Moreover
\[
T=AB^2A=(BA)^*(BA),
\]
so
\[
\|T\|=\|BA\|^2=\|AB\|^2=p^2.
\]
This proves (4.1) for positive definite `A`.

For merely PSD `A`, replace it by `A+\varepsilon I`, apply the proved inequality, and let `\varepsilon\downarrow0`.  All terms are continuous in operator norm.  QED.

### Consequence: one sharply isolated missing inequality
If one could prove either
\[
\boxed{\|U\|^2\le xy}
\tag{4.2}
\]
or, more directly,
\[
\boxed{\|U+U^*\|\le x+y},
\tag{4.3}
\]
then the pair conjecture (3.1) would follow immediately.  For example, (4.2) would give
\[
2p^2
\le\|U+U^*\|
\le2\|U\|
\le2\sqrt{xy}
\le x+y.
\]

Equations (4.2) and (4.3) are **not proved** here.  Fresh real/complex PSD tests support them, but they remain conjectural leads.

A standard one-parameter similarity interpolation only proves the weaker estimate
\[
\|U\|^2\le x\,p^2,
\]
so the new bridge does not by itself settle (3.1).

# 5. Exact rational rank-one obstruction to `C_23>=S`

Let `C_23` denote the `2+1+1` positional class whose repeated index occupies positions 2 and 3.  A natural but overly strong candidate would be `C_23>=S`.  The following exact rational rank-one example refutes it.

Take unit vectors in `R^3`
\[
u_0=(1,0,0),
\qquad
u_1=(0,1,0),
\]
\[
u_2=(0,20/29,21/29),
\qquad
u_3=(16/21,13/21,4/21),
\]
and positive scales
\[
(s_0,s_1,s_2,s_3)=(312,52,110,5).
\]
Define rank-one PSD matrices
\[
A_i=s_i u_i u_i^T.
\]
The absolute Gram entries are exactly
\[
g_{01}=g_{02}=0,
\qquad g_{03}=\frac{16}{21},
\qquad g_{12}=\frac{20}{29},
\]
\[
g_{13}=\frac{13}{21},
\qquad g_{23}=\frac{344}{609}.
\]
For a rank-one word,
\[
\|A_{i_1}\cdots A_{i_m}\|
=
\left(\prod_{r=1}^m s_{i_r}\right)
\prod_{r=1}^{m-1}|g_{i_ri_{r+1}}|.
\tag{5.1}
\]
Direct exact rational summation gives
\[
S=\frac{196072448000}{17661}.
\tag{5.2}
\]
The six positional `2+1+1` class sums are
\[
C_{12}=C_{34}=\frac{2009002729760}{41209},
\]
\[
C_{13}=C_{24}=\frac{718641054372800}{225866529},
\]
\[
C_{14}=\frac{854366656000}{370881},
\]
and
\[
\boxed{
C_{23}=\frac{1832928073600}{370881}.
}
\tag{5.3}
\]
Thus
\[
\boxed{
\frac{C_{23}}S=0.44515325896\ldots<1.
}
\tag{5.4}
\]
So `C_23>=S` is rigorously false, already for rational rank-one PSD matrices.

This example does **not** refute the weaker aggregate candidate
\[
C_{23}\stackrel{?}{\ge}\frac{S^2}{4P}.
\tag{5.5}
\]
Indeed, for the same exact example,
\[
P=\frac{905839238000}{52983},
\]
and
\[
\frac{C_{23}}{S^2/(4P)}=2.74209724008\ldots>1.
\]
Thus (5.5) remains open.

# 6. Exact Bhatia–Davis upper coupling for the middle-repeat class

Although it is in the wrong direction for proving the conjecture, there is a clean exact structural relation worth recording.

For distinct `A,B,C`, the Bhatia–Davis matrix AGM inequality with `X=B^2` gives
\[
2\|AB^2C\|
\le
\|A^2B^2+B^2C^2\|
\le
\|A^2B^2\|+\|B^2C^2\|.
\tag{6.1}
\]
Sum (6.1) over all 24 distinct ordered triples `(A,B,C)` drawn from the four matrices.  Define the ordered-square sublayer
\[
O:=\sum_{i\ne j}\|A_i^2A_j^2\|.
\]
Every ordered square word appears twice as a first term and twice as a second term on the right.  Therefore
\[
2C_{23}\le4O,
\]
so
\[
\boxed{C_{23}\le2O.}
\tag{6.2}
\]
This is an exact coupling, but it is an **upper** bound and hence does not supply the missing lower payment for `Q_211`.

# 7. Failed interpolation route recorded explicitly

A useful exact analytic path was found:
\[
F(z)
:=
A^{2-2z}B^{2-z}A^{-1+2z}B^zA,
\tag{7.1}
\]
for positive definite `A,B`.  It has the exact real interpolation values
\[
F(0)=A^2B^2,
\qquad
F(1)=BABA=(ABAB)^*,
\]
\[
F(1/2)=AB^2A,
\qquad
\|F(1/2)\|=p^2.
\tag{7.2}
\]
This would prove (3.2) immediately if a Hadamard three-lines argument supplied boundary controls by `x` and `y`.

However fresh numerical boundary checks show the obstruction: on `Re z=0`, `||F(it)||/x` can be much larger than `1` (well over two orders of magnitude in moderate ill-conditioned tests).  Thus (7.1) is **not** a valid direct three-lines proof of (3.2).  The path is archived so this exact dead end is not repeatedly retried.

# 8. Additional diagnostic leads — not theorems

Fresh numerical work supports, but does not prove, several equivalent/sufficient routes to (3.2):

* the geometric bridge (4.2), `||U||^2<=xy`;
* the matrix-sum bridge (4.3), `||U+U^*||<=x+y`;
* the oriented sum inequality `||A^2B^2+ABAB||>=2p^2`;
* a top-singular-vector inequality for `T=AB`, `Tv=pu`, `T^*u=pv`:
  \[
  \|A^2B^2v\|\,\|T^2v\|\stackrel{?}{\ge}p^4;
  \]
* the spectral-radius sufficient condition
  \[
  \rho\!\left((A^2B^2)(ABAB)^*\right)\stackrel{?}{\ge}p^4.
  \]

Complex tests show the last product can have non-real eigenvalues, so there is no immediate "similar to PSD" shortcut.  None of these diagnostics is used in any proved constant.
