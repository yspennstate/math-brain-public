## 0. Exact target and this run's advance

For arbitrary `n` and arbitrary PSD `d x d` matrices `A_1,...,A_n`, the target is
\[
\frac1{n!}\sum_{\sigma\in S_n}\|A_{\sigma(1)}\cdots A_{\sigma(n)}\|
\le
\frac1{n^n}\sum_{k_1,\dots,k_n\in[n]}\|A_{k_1}\cdots A_{k_n}\|
\]
in spectral norm, with the norm **inside** both averages.  The norm-outside Recht–Ré counterexample is not this statement.

No full resolution is claimed in this run.  The main new exact result is a dimension-free **path-sandwich inequality for arbitrary products of PSD matrices**:
\[
\boxed{
\|A_1A_2\cdots A_m\|^2
\le
\|A_1\|\,\|A_m\|
\prod_{j=1}^{m-1}\|A_jA_{j+1}\|.
}
\tag{0.1}
\]
It is valid for every `m>=2`, every dimension, and arbitrary PSD factors.  For the first unresolved `n=4` case this gives a new Hamiltonian-path reduction
\[
\boxed{
S^2\le24H,
}
\tag{0.2}
\]
where
\[
S=\sum_{\sigma\in S_4}
\|A_{\sigma(1)}A_{\sigma(2)}A_{\sigma(3)}A_{\sigma(4)}\|
\]
and
\[
H=
\sum_{\sigma\in S_4}
 a_{\sigma(1)}a_{\sigma(4)}
 p_{\sigma(1)\sigma(2)}
 p_{\sigma(2)\sigma(3)}
 p_{\sigma(3)\sigma(4)},
\]
with `a_i=||A_i||` and `p_ij=||A_iA_j||`.

This does not by itself improve the best universal scalar factor already archived, but it gives a new exact pair-data constraint that is not contained in the old two-edge split `S<=4P`; it is especially useful for eliminating proposed counterexamples whose Hamiltonian path statistics are small.

A second useful outcome is negative: a tempting route toward the remaining middle-repeat class is false.  The inequality
\[
\|ABC\|^2\stackrel{?}{\le}
\|A\|\,\|C\|\,\|AB^2C\|
\tag{0.3}
\]
fails already for `3 x 3` positive definite matrices.  A deterministic seed reproducing a ratio `1.22158...>1` is archived in the checker.

Finally, numerical stress tests continue to support the aggregate conjecture
\[
C_{23}\stackrel{?}{\ge}\frac{S^2}{4P},
\qquad
P:=\sum_{i<j}\|A_iA_j\|^2,
\tag{0.4}
\]
but (0.4) is **not proved** and is recorded only as a concrete next target.

# 3. A two-factor sandwich lemma

The path theorem follows from one elementary but strong Loewner-order fact.

## Lemma 3.1
For PSD matrices `X,Y`,
\[
\boxed{
YXY\preceq \|XY\|\,Y.
}
\tag{3.1}
\]

### Proof
Set
\[
C:=Y^{1/2}XY^{1/2}\succeq0.
\]
The nonzero spectrum of `C` equals the nonzero spectrum of `XY`, hence
\[
\|C\|=\rho(XY)\le\|XY\|.
\]
Therefore
\[
C\preceq\|XY\|I.
\]
Congruence by `Y^{1/2}` gives
\[
YXY
=Y^{1/2}CY^{1/2}
\preceq
\|XY\|Y.
\]
QED.

### Remarks

1. The coefficient `||XY||` can be replaced by the smaller `rho(XY)=||Y^{1/2}XY^{1/2}||`; the operator-norm form is chosen because the campaign's scalar bookkeeping already uses `p_ij=||A_iA_j||`.
2. Equality occurs in commuting scalar cases, so the lemma has the correct homogeneity and can be sharp.

# 4. New path-sandwich theorem for arbitrary product length

## Theorem 4.1
For every integer `m>=2` and arbitrary PSD matrices `A_1,...,A_m`,
\[
\boxed{
\|A_1A_2\cdots A_m\|^2
\le
\|A_1\|\,\|A_m\|
\prod_{j=1}^{m-1}\|A_jA_{j+1}\|.
}
\tag{4.1}
\]

### Proof
Let
\[
W:=A_1A_2\cdots A_m.
\]
Then
\[
\|W\|^2
=
\|W^*W\|
=
\|A_m\cdots A_2 A_1^2 A_2\cdots A_m\|.
\]
Because
\[
A_1^2\preceq \|A_1\|A_1,
\]
congruence by `A_2\cdots A_m` yields
\[
\|W\|^2
\le
\|A_1\|
\|A_m\cdots A_3(A_2A_1A_2)A_3\cdots A_m\|.
\tag{4.2}
\]
Lemma 3.1 with `X=A_1`, `Y=A_2` gives
\[
A_2A_1A_2\preceq\|A_1A_2\|A_2.
\]
Substituting into (4.2),
\[
\|W\|^2
\le
\|A_1\|\,\|A_1A_2\|
\|A_m\cdots A_3 A_2 A_3\cdots A_m\|.
\]
Apply Lemma 3.1 again to the central sandwich
\[
A_3A_2A_3\preceq\|A_2A_3\|A_3.
\]
Iterating gives
\[
\|W\|^2
\le
\|A_1\|
\left(\prod_{j=1}^{m-1}\|A_jA_{j+1}\|\right)
\|A_m\|,
\]
which is (4.1).  QED.

### Normalized contraction form
If every `A_j` is a positive contraction, then
\[
\boxed{
\|A_1\cdots A_m\|
\le
\left(
\prod_{j=1}^{m-1}\|A_jA_{j+1}\|
\right)^{1/2}.
}
\tag{4.3}
\]

This is an exact dimension-free reduction of a long PSD word to its adjacent two-matrix norms.

# 5. Four-matrix Hamiltonian-path corollary

For the `n=4` problem define
\[
a_i:=\|A_i\|,
\qquad
p_{ij}:=\|A_iA_j\|=p_{ji}.
\]
For every permutation `(i,j,k,l)` of `(1,2,3,4)`, Theorem 4.1 gives
\[
\|A_iA_jA_kA_l\|^2
\le
a_i a_l p_{ij}p_{jk}p_{kl}.
\tag{5.1}
\]
Summing square roots and applying scalar Cauchy–Schwarz over the 24 permutations,
\[
S^2
\le
24
\sum_{(i,j,k,l)\in S_4}
 a_i a_l p_{ij}p_{jk}p_{kl}.
\]
Thus, with
\[
H:=
\sum_{(i,j,k,l)\in S_4}
 a_i a_l p_{ij}p_{jk}p_{kl},
\]
we have the exact new constraint
\[
\boxed{S^2\le24H.}
\tag{5.2}
\]

This is complementary to the old perfect-matching split
\[
S\le
8(p_{12}p_{34}+p_{13}p_{24}+p_{14}p_{23})
\le4P,
\qquad
P:=\sum_{i<j}p_{ij}^2.
\tag{5.3}
\]
Neither scalar bound uniformly dominates the other at the raw pair-data level.  The advantage of (5.2) is that it detects **three-edge path compatibility** rather than only disjoint two-edge matchings.

### Data-dependent use in the existing collision relaxation
The current arbitrary-dimensional collision lower bounds can be written using
\[
s:=S/P,
\qquad e:=E/P,
\qquad q:=Q/P,
\]
with
\[
E:=\sum_{i<j}a_i^2a_j^2,
\qquad
Q:=\sum_i a_i^4.
\]
Previously only `s<=4` was inserted.  Equation (5.2) supplies the additional exact candidate-specific constraint
\[
s\le \frac{\sqrt{24H}}{P}.
\tag{5.4}
\]
Because the existing lower-bound objective decreases in `s` across its feasible interval, every proposed numerical counterexample with `sqrt(24H)/P<4` automatically receives a stronger rigorous lower certificate than the universal `0.6293369...` bound.

This does not produce a better **universal** constant, because commuting/equal configurations can saturate the path inequality, but it is directly useful in certified counterexample screening.

\[

It is false.

\[
\frac{\|ABC\|^2}
{\|A\|\,\|C\|\,\|AB^2C\|}
=1.22158026036533\ldots>1.
\]
Thus no proof may use (6.1) or any argument that implicitly assumes this monotonicity under middle squaring.

This is a genuine failed-route certificate, not a counterexample to the original conjecture.
