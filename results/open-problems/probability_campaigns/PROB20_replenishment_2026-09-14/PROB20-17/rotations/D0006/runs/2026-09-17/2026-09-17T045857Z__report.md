## 3. Mathematical idea before any code

The finite-support counterexample route is dead for a structural reason: a generic scalar projection separates every finite support point and every `n`-fold support sum, so scalar and vector complete-mix feasibility coincide.

The next question is therefore not “which finite LP should be searched?” but:

> What extra compatibility must the **continuum of scalar complete mixes** possess in order to come from one vector coupling?

This run attacks that question in three different languages.

- **B11** turns non-vector-mixability into a positive multi-marginal transport dual witness and isolates a precise missing “ridge-cone generation” principle.

## 4. B11 — dualize: the missing statement is a ridge-dual cone-generation theorem

For this section let `F` be compactly supported on `K subset R^d`, let

`mu = int x dF(x)`,

and let `Pi_n(F)` denote the compact set of couplings of `n` copies of `F`.

For `x=(x_1,...,x_n)` define the vector defect

`D(x) = x_1+...+x_n-n mu`

and continuous cost

`c(x_1,...,x_n)=||D(x)||_2^2`.

Define

`V(F) = min_{pi in Pi_n(F)} int c d pi`.

Since the coupling set is compact and the cost is continuous/nonnegative,

`V(F)=0`

if and only if `F` is vector `n`-CM with center `mu`.

### Proposition 4.1 — symmetric multi-marginal dual

Standard compact multi-marginal Kantorovich duality, followed by symmetrization of the potentials, gives

`V(F) = sup { n int_K phi dF : phi in C(K), sum_{i=1}^n phi(x_i) <= ||sum_i x_i - n mu||^2 for every (x_1,...,x_n) in K^n }`.

#### Why one common potential is enough

The ordinary dual allows `n` potentials `phi_1,...,phi_n` with

`sum_i phi_i(x_i) <= c(x_1,...,x_n)`.

Because the cost is permutation-invariant and every marginal is the same `F`, average this inequality over all permutations of `(x_1,...,x_n)`. With

`phi_bar = (1/n) sum_i phi_i`,

the averaged inequality is

`sum_i phi_bar(x_i) <= c(x_1,...,x_n)`,

while the dual objective is unchanged:

`n int phi_bar dF = sum_i int phi_i dF`.

Thus a compactly supported `F` that is **not** vector `n`-CM has a continuous common-potential witness `phi` with

`sum_i phi(x_i) <= ||D(x)||^2`

for all tuples and

`int phi dF > 0`.

This is the exact dual object a projection-only proof must exclude.

### Scalar projected duals

For a unit vector `u`, let `G_u=(u dot)_# F`. The scalar quadratic defect cost is

`c_u(x_1,...,x_n) = (u dot D(x))^2`.

If `G_u` is scalar `n`-CM, then its minimum defect cost is zero. Equivalently, every continuous scalar dual potential `psi` satisfying

`sum_i psi(u dot x_i) <= (u dot D(x))^2`

obeys

`int psi(u dot x) dF(x) <= 0`.

Thus the projection hypothesis annihilates an entire family of **ridge** dual witnesses.

### Proposition 4.2 — every ridge-generated vector witness is harmless

Take finitely many unit directions `u_j`, coefficients `alpha_j >= 0`, and scalar dual-feasible functions `psi_j` such that

`Q := sum_j alpha_j u_j u_j^T <= I_d`

in PSD order. Put

`phi(x) = sum_j alpha_j psi_j(u_j dot x)`.

Then

`sum_i phi(x_i)`
` <= sum_j alpha_j (u_j dot D(x))^2`
` = D(x)^T Q D(x)`
` <= ||D(x)||^2`.

So `phi` is vector-dual feasible. If every line projection of `F` is `n`-CM, then

`int phi dF = sum_j alpha_j int psi_j dG_{u_j} <= 0`.

Therefore:

**Any source-level counterexample must possess a positive vector dual witness that is genuinely non-ridge-decomposable.**

More precisely, if every vector-dual feasible continuous `phi` belongs to the uniform closure of the ridge-generated cone above, then projection-wise `n`-CM forces `V(F)=0` and hence vector `n`-CM.

This gives a concrete positive route:

`boxed: prove a ridge-cone generation/density theorem for the vector defect dual.`

The abstract PSD example from the previous report explains why this is not a formal consequence of convexity. The new point here is that the exact missing statement is now located at the **dual-potential level**, where the geometry of the common marginal `F` can potentially matter.

**B11 outcome:** no metric movement, but the unrestricted positive direction is reduced to a precise cone-generation question rather than an unspecified minimax gap.

## 5. B6 — deform to the atomic regime: an exact compatible-approximation criterion

The 2012 Puccetti–Wang–Wang paper already proves, in one dimension, closure of `n`-CM laws under weak limits (with the center controlled) and a discrete approximation/decomposition theorem. The vector analogue needed here is elementary and can be proved directly.

### Proposition 5.1 — vector `n`-CM is closed under compatible limits

Suppose `F_k` are probability laws on `R^d`, each vector `n`-CM with constant vector sum `c_k`, and

`F_k => F`, `c_k -> c`.

Then `F` is vector `n`-CM with constant vector sum `c`.

#### Proof

For every `k`, choose a coupling `pi_k` of `n` copies of `F_k` supported on

`{(x_1,...,x_n): x_1+...+x_n=c_k}`.

Since `F_k => F`, the family of marginals is tight, hence the family `{pi_k}` is tight on `(R^d)^n`. Pass to a weakly convergent subsequence `pi_k => pi`. Each marginal of `pi` is `F`.

Let `S(x_1,...,x_n)=x_1+...+x_n`. By continuity of `S`,

`S_# pi_k => S_# pi`.

But `S_# pi_k = delta_{c_k} => delta_c`. Therefore `S_# pi=delta_c`, so `pi` is a vector complete mix of `F`. QED.

For finite-first-moment laws, `W_1(F_k,F)->0` automatically gives convergence of means and therefore convergence of the canonical centers `c_k=n mu_k`.

### Proposition 5.2 — every compactly supported vector complete mix has finite vector-CM approximants

Let `F` be compactly supported and vector `n`-CM with sum `c`. Then there exists a sequence of finitely supported vector `n`-CM laws `F_k => F`, all with sum center `c`.

#### Proof

Take a complete-mix coupling `pi` of `F` supported on the closed affine set

`H_c={x_1+...+x_n=c}`.

Symmetrize `pi` under coordinate permutations; this preserves its common marginal `F` and its support in `H_c`.

Approximate this symmetric probability measure weakly by finitely supported probability measures whose atoms are chosen from `supp(pi)`, then symmetrize each finite approximation over coordinate permutations. Call the resulting exchangeable finite measure `pi_k`.

Every atom of `pi_k` still lies in `H_c`; all coordinate marginals of `pi_k` are equal by exchangeability; call their common finite marginal `F_k`. Then `F_k` is vector `n`-CM with center `c`, and marginal convergence gives `F_k => F`. QED.

### Corollary 5.3 — finite compatible projection criterion

For compactly supported `F`, vector `n`-CM is equivalent to the existence of finite laws `F_k => F` with supports `A_k` and directions `u_k` such that

1. `u_k dot` is injective on `A_k` and on `nA_k`;
2. the scalar projection `(u_k dot)_# F_k` is `n`-CM;
3. the lifted vector sum centers converge to the desired center of `F` (automatic in the compact common-center construction above).

#### Proof

If `F` is vector `n`-CM, use Proposition 5.2. Each finite `A_k` admits a generic direction avoiding the finitely many hyperplanes orthogonal to nonzero elements of

`(A_k-A_k) union (nA_k-nA_k)`.

Every projection of the vector complete mix is scalar `n`-CM.

Conversely, the previous D0006 sum-separating lift theorem turns each scalar complete mix of `(u_k dot)_#F_k` into a vector complete mix of `F_k`. Proposition 5.1 then passes to the limit. QED.

### What this says about Open Problem 6

For each **fixed direction** `u`, the source hypothesis and the one-dimensional 2012 decomposition theorem allow discrete scalar `n`-CM approximations of `G_u`.

That is not enough.

To invoke Corollary 5.3, the discrete scalar laws must arise as generic projections of **one common vector approximation `F_k`**. Different directions cannot be discretized independently and then glued after the fact.

Thus the deformation route exposes a second exact formulation of the missing ingredient:

`boxed: construct projectively compatible atomic approximants, not separate atomic approximants direction by direction.`

This explains why the previous countable-support theorem is useful but does not by itself settle the continuous problem.

**B6 outcome:** a complete approximation criterion, but no source-level metric movement. The weak-closure mechanism has clear prior art in one dimension; no novelty is claimed for closure itself.

## 6. B21 — neighboring shape: reduce axisymmetric sphere laws to a 1D triangle-constrained mix

A natural place to search for a genuinely continuous counterexample is a law supported on the unit sphere: scalar projections are explicit, while fixed-sum vector configurations have rigid geometry.

Let `rho` be a probability law on `[-1,1]`, let

`m = int z d rho(z)`,

and define the axisymmetric sphere law `A(rho)` by

`Z ~ rho`, `Theta ~ Unif[0,2pi)` independently,

`X=(sqrt(1-Z^2) cos Theta, sqrt(1-Z^2) sin Theta, Z)`.

### Theorem 6.1 — exact axisymmetric `3`-CM reduction

`A(rho)` is vector `3`-CM if and only if there exists a coupling `(Z_1,Z_2,Z_3)` with every `Z_i ~ rho` such that, almost surely,

`Z_1+Z_2+Z_3=3m`

and the three radii

`r_i=sqrt(1-Z_i^2)`

satisfy the triangle inequalities

`max(r_1,r_2,r_3) <= (r_1+r_2+r_3)-max(r_1,r_2,r_3)`.

#### Necessity

If `(X_1,X_2,X_3)` is a vector complete mix, its constant sum must be

`3 E[X] = (0,0,3m)`.

Writing `X_i=(H_i,Z_i)` with `H_i in R^2`, the vertical coordinates give

`Z_1+Z_2+Z_3=3m`.

The horizontal coordinates satisfy

`H_1+H_2+H_3=0`

with `||H_i||=r_i`. Three planar vectors of lengths `r_i` can sum to zero only if their lengths form the sides of a (possibly degenerate) triangle. Hence the triangle inequalities are necessary.

#### Sufficiency

Conversely suppose such a coupling `(Z_1,Z_2,Z_3)` exists. For every realized radius triple satisfying the triangle inequalities, choose measurably planar vectors `h_i` with

`||h_i||=r_i`, `h_1+h_2+h_3=0`.

For example, away from degenerate cases set `h_1=(r_1,0)` and choose the angle of `h_2` by the cosine rule so that `||h_1+h_2||=r_3`; define `h_3=-(h_1+h_2)`. The degenerate boundary cases are obtained continuously.

Now draw one independent uniform angle `Theta` and rotate **all three** horizontal vectors by the same planar rotation `R_Theta`. Put

`X_i=(R_Theta h_i,Z_i)`.

For each `i`, conditional on `Z_i`, the horizontal direction is uniform, so `X_i` has law `A(rho)`. Their horizontal sum is zero and their vertical sum is `3m`; hence

`X_1+X_2+X_3=(0,0,3m)`

almost surely. Thus `A(rho)` is vector `3`-CM. QED.

This turns a three-dimensional vector problem into a one-dimensional complete-mix problem with one additional geometric constraint. It is a concrete counterexample-search frontier rather than a sampled-direction heuristic.

## 7. First spherical candidate: all line projections are `3`-CM, but the vector law also is

Let `sigma` be normalized surface area on `S^2` and consider the extreme linear tilt

`dF_+(x) = (1+x_3) d sigma(x)`.

The density is nonnegative and integrates to one.

### Every one-dimensional projection is `3`-CM

Fix a unit direction `u` and set `Y=u dot X`. Under `sigma`, `Y` is uniform on `[-1,1]`; conditional on `Y=y`, rotational symmetry gives

`E_sigma[X | u dot X=y]=y u`.

Therefore under `F_+`, the projected density is

`g_u(y)=1/2 (1+(e_3 dot u)y)`, `-1<=y<=1`.

This density is monotone. Its mean is

`mu_u=(e_3 dot u)/3`,

which lies in `[-1/3,1/3]`. Wang–Wang's monotone-density criterion therefore gives `3`-complete mixability for **every** direction `u`.

So `F_+` satisfies exactly the tempting linewise hypothesis.

### Nevertheless `F_+` has an explicit vector complete mix

Its axial marginal is

`rho_+(dz)=((1+z)/2) dz` on `[-1,1]`.

Let `(W_1,W_2,W_3)` be uniform on the simplex

`W_i>=0`, `W_1+W_2+W_3=1`

(that is, Dirichlet `(1,1,1)`) and put

`Z_i=1-2W_i`.

Each `W_i` has density `2(1-w)` on `[0,1]`, so each `Z_i` has density `(1+z)/2`. Also

`Z_1+Z_2+Z_3=1`.

Set `r_i=sqrt(1-Z_i^2)`. The standard triangle discriminant is

`Delta = 2(r_1^2 r_2^2+r_2^2 r_3^2+r_3^2 r_1^2) - (r_1^4+r_2^4+r_3^4)`.

Using `Z_1+Z_2+Z_3=1`, direct expansion gives the exact factorization

`Delta = 8(1-Z_1)(1-Z_2)(1-Z_3) = 64 W_1 W_2 W_3 >= 0`.

Hence the radii always form a triangle. Theorem 6.1 therefore constructs a vector `3`-complete mix of `F_+` with constant sum `e_3`.

This candidate is valuable precisely because it almost realizes the desired quantifier mismatch: **every scalar projection is `3`-CM by a different monotone-density argument, yet a hidden common vector coupling still exists.**

## 8. Second spherical candidate: the scalar hypothesis breaks before the vector obstruction appears

The next natural attempt is an even quadrupole tilt, because it keeps mean zero while making the covariance anisotropic.

Let

`P_2(t)=(3t^2-1)/2`

and for `0<=epsilon<=2` define

`dF_epsilon(x)=(1+epsilon P_2(x_3)) d sigma(x)`.

This is a probability law on `S^2` with mean zero.

### Vector obstruction

If three unit vectors sum to zero, then they are an equilateral triple in a plane: for example

`||x_1+x_2||^2=||-x_3||^2=1`

forces `x_1 dot x_2=-1/2`, and similarly for the other pairs. Therefore their empirical second-moment matrix

`(1/3) sum_i x_i x_i^T`

has eigenvalues `(1/2,1/2,0)` and is bounded above by `(1/2)I`.

Consequently any zero-center sphere law that is vector `3`-CM must satisfy

`E[XX^T] <= (1/2)I`.

For `F_epsilon`,

`E[X_3^2]=1/3 + (2/15)epsilon`.

Thus vector `3`-CM is impossible once

`epsilon > 5/4`.

### But the axial scalar projection has already ceased to be `3`-CM

The axial density is

`g_epsilon(y)=1/2(1+epsilon P_2(y))`, `-1<=y<=1`.

For any scalar zero-center `3`-complete mix `(Y_1,Y_2,Y_3)`, the pointwise identity

`Y_1^4+Y_2^4+Y_3^4 = 1/2 (Y_1^2+Y_2^2+Y_3^2)^2`

holds whenever `Y_1+Y_2+Y_3=0`. Taking expectations and applying Jensen gives the necessary marginal moment inequality

`m_4 >= (3/2)m_2^2`.

For `g_epsilon`, direct integration yields

`m_2=1/3+(2/15)epsilon`,

`m_4=1/5+(4/35)epsilon`.

Hence

`m_4-(3/2)m_2^2 = -(28 epsilon^2+20 epsilon-35)/1050`.

The positive zero is

`epsilon_* = (-5+3 sqrt(30))/14 = 0.816548...`.

Therefore the **single axial projection** is already not `3`-CM for every

`epsilon > epsilon_*`,

well before the vector covariance obstruction at `epsilon>5/4` can be used.

So this entire spherical-harmonic route fails as a source counterexample for an exact, source-relevant reason; it should not be searched numerically at larger anisotropy.
