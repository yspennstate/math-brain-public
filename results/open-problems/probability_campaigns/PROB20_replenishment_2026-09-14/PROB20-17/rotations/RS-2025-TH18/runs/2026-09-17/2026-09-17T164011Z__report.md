## 4.1 From an LP to an asymmetric quotient-width problem

Define the one-sided gauge

`rho_+(z) = max_j z_j`.

Then `(BLOCK)` asks for the typical distance, in this asymmetric gauge, from one distinguished random Fourier datum `x_D` to the complementary Fourier subspace `Range(P_C)`. This is not a symmetric Kashin/RIP norm problem. Negative coordinates are free, and only the positive peak matters.

The minimax dual recovered in the previous report makes the same point from the opposite side: `kappa_D` is the maximum excess mass at coordinate zero among nonnegative probability vectors whose forbidden Fourier component on `C` vanishes. Thus the problem can equally be read as a random-spectrum positive trigonometric-polynomial concentration problem. ## 4.2 A discrepancy/partial-coloring form that exposes a possible port

Let `v_a = Q_a e_0` be the real conjugate-pair Fourier atoms, and write

`x_D = sum_{a in D} v_a`,  `x_C = sum_{a in C} v_a`.

Set the centered random-sign baseline

`w_D = x_D - x_C`.

For a coefficient vector `y=(y_a)_{a in C}` define the complementary completion

`q_y = x_C - sum_{a in C} y_a v_a`.

Then purely by substitution,

`x_D - q_y = w_D + sum_{a in C} y_a v_a`.

This identity does **not** resolve `(BLOCK)`; it only identifies a useful stronger test class. If one restricts `y` to the cube `[-1,1]^C`, the complementary coefficients of `q_y` lie in `[0,2]`. Define the restricted target parameter

\[
\kappa_D^{\mathrm{box}}
:=
\inf_{y\in[-1,1]^C}
\max_j\left(w_D(j)+\sum_{a\in C}y_a v_a(j)\right).
\tag{4.1 target-definition}
\]

Because this restricts the allowed completions, proving

`E kappa_D^box = O(1/sqrt(n))`

would be a sufficient **stronger** result for `alpha_LL=0`. I am not claiming that estimate.

The significance of centering at `x_C` is that the zero coordinate is no longer burdened by the order-one value `x_D(0)`: the baseline `w_D(0)` is proportional to the random pair-count imbalance `|D|-|C|`, hence is on the source fluctuation scale rather than the deterministic half-mass scale. The same centered representation turns the problem into an extension/correction problem: half of the Fourier pair choices have already produced the random baseline, and the complementary half supply bounded adaptive coefficients with which one tries to erase the extreme positive peak.

That is much closer to **discrepancy minimization in a translated, non-symmetric convex body** than to the original worst-case RIP formulation.

# 6. B27 — SWAP THE QUANTIFIERS

The published RIP route pays for a theorem that is much more uniform than the source metric now requires. The B3 reduction permits the quantifiers to be weakened in three ways simultaneously.

### Published-style worst-case shape

Schematically, a uniform nullspace/RIP approach asks for a high-probability statement about **all** vectors/supports in a class for the sampled Fourier operator. This is strong enough to ignore the LP optimizer but correspondingly expensive and vulnerable to sparse sign-changing obstructions.

### Current exact source requirement

The metric needs only

`E_D [ inf_q rho_+(x_D-q) ]`.

Thus:

1. `D` is random under one fixed source law;
2. for each realized `D`, the completion `q=q(D)` may depend arbitrarily on that same realization;
3. only the single distinguished datum `x_D=P_De_0` must be completed;
4. only the positive maximum is penalized;
5. for metric movement, expectation control is enough — not a theorem for every mask and every vector.

The restricted body `(4.2)` weakens the uniformity in the same spirit: it asks whether **there exists** one bounded correction `y(D)` for the actual source baseline, not whether every vector in `Range(P_D)` has a Kashin-type norm bound.

There is one important caveat. A merely constant-probability good event is not automatically sufficient for the expectation target because a crude bad-event theta value can be as large as order `n`. A high-probability port therefore needs a failure probability small enough to make its bad-event contribution negligible (or, better, a direct expectation estimate). Exponentially small failure from a hereditary partial-coloring/small-ball argument would be more than sufficient; constant-probability existence would not finish the expectation bound by itself.

This quantifier structure is why the fresh Matrix Spencer / convex-body partial-coloring machinery is more relevant than another uniform Fourier RIP theorem. Partial coloring constructs one adaptive solution to one instance and controls the instance-specific path; it does not need to certify every vector in the ambient subspace.

### B27 outcome

The correct quantifier swap is:

`uniform over all Fourier-sparse vectors`

**to**

`for source-random D, construct one D-dependent completion of the one prescribed datum, with source-sufficient tail/expectation control`.

No theorem is claimed; this is the exact reason the selected port below is not ruled out by the previous sparse-kernel obstruction.
