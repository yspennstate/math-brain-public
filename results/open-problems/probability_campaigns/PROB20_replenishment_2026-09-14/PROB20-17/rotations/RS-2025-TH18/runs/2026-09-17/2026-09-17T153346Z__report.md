## 2. Recovered exact clipping setup

With the nonunitary DFT convention `F* F = n I`, define the pair projections

`Q_a = (1/n) F diag(1_{a,n-a}) F*`,

and the zero-mode projection

`P_0 = (1/n) F diag(1_{0}) F*`.

Put

`P_D = sum_{a in D} Q_a`,  `P_C = sum_{a in C} Q_a`.

Then

`P_0 + P_D + P_C = I`,

and the three projections are pairwise orthogonal.

Write

`u = P_0 e_0 = (1/n) 1`.

For the complement-side dual construction recovered in the preceding reports, the affine Fourier constraint space is

`H_D = { h : P_D h = - P_D e_0 }`.

The sign-vector start is

Its generated residual and clipping update are

`r_k(D) = (-h_k(D))_+`,

`h_{k+1}(D) = h_k(D) + (P_0 + P_C) r_k(D)`.

The previous reports already proved that this is alternating projection between the affine Fourier constraint and the nonnegative orthant and that its dual objective obeys

# 3. B13 — FIND WHAT ONLY INCREASES: the zero-mode complement defect is exactly accumulated repair cost

Run the clipping procedure simultaneously for `D` and for the complementary nonzero mask `C=D^c_*`. For the complementary run,

`H_C = { h^c : P_C h^c = - P_C e_0 }`,

`h_0(C) = u + P_D e_0 - P_C e_0 = 2u - h_0(D)`.

Let

`r_k = (-h_k)_+`,  `r_k^c = (-h_k^c)_+`,

and define the complement defect

`delta_k = h_k + h_k^c - 2u`.

Initially

`delta_0 = 0`.

The two updates are

`h_{k+1} = h_k + (P_0+P_C) r_k`,

`h_{k+1}^c = h_k^c + (P_0+P_D) r_k^c`.

Therefore, exactly,

`delta_{k+1} = delta_k + P_0(r_k+r_k^c) + P_C r_k + P_D r_k^c`.   (3.1)

Projecting (3.1) onto the zero mode and using nonnegativity of the residuals gives

`P_0 delta_{k+1} = P_0 delta_k + ((||r_k||_1 + ||r_k^c||_1)/n) 1`.   (3.2)

Since `delta_0=0`, induction yields the exact closed form

`P_0 delta_k = (1/n) [sum_{j<k} (||r_j||_1 + ||r_j^c||_1)] 1`.   (3.3)

This is a genuine monovariant: its scalar coefficient is nondecreasing and increases by exactly the paired repair mass.

There is an equivalent objective identity. Because `J_k=2+sum_{j<k}||r_j||_1` and similarly for the complementary run,

`P_0 delta_k = ((J_k + J_k^c - 4)/n) 1`.   (3.4)

Thus the zero-mode part of the complement defect is not an error that a successful proof should keep small. It is **exactly the cost that the dual construction is paying**.

The transverse component obeys

`(I-P_0) delta_{k+1} = (I-P_0) delta_k + P_C r_k + P_D r_k^c`.   (3.5)

Equation (3.5) is equally informative about the failed route: the transverse defect receives the **free-frequency** parts of the residuals. By contrast, the first-step theorem controlled the constrained component `P_D r_0` in mean square. Therefore the first-step contraction does not directly control the object injected into the transverse complement defect.

### B13 outcome

The complement defect has an exact monotone coordinate, but it is the wrong sign for the hoped-for invariant: successful repair necessarily makes the zero-mode defect grow. A useful iteration theorem must separate the intentional scalar drift (3.3) from transverse geometry. Treating `||delta_k||` itself as a small stability parameter is structurally impossible.

# 4. B6 — DEFORM TO A SOLVABLE POINT: exact centered reflection is rigid and kills the useful free-frequency motion

The previous report suggested recentering the clipping map so that the `D` and `C` trajectories might remain exact reflections. This section shows why that exact version cannot work.

Suppose `h in H_D` and `h^c in H_C` satisfy exact centered reflection, meaning

`(I-P_0)(h+h^c)=0`.   (4.1)

Project (4.1) onto `Range(P_D)`. Since `P_D h = -P_D e_0`, we obtain

`P_D h^c = P_D e_0`.   (4.2)

Project onto `Range(P_C)`. Since `P_C h^c = -P_C e_0`, we obtain

`P_C h = P_C e_0`.   (4.3)

Combining (4.2)--(4.3) with the defining affine constraints gives

`h = h_0(D) + a 1`,

`h^c = h_0(C) + b 1`   (4.4)

for some real scalars `a,b`.

So exact centered reflection leaves **no nonzero free-frequency degrees of freedom at all**. The only allowed motion from the sign-vector starts is a constant/zero-mode shift.

This has a concrete positivity cost. If `h>=0` and `h^c>=0`, then

`a >= - min_j h_0(D)_j`,

`b >= - min_j h_0(C)_j`.

But `h_0(C)=2u-h_0(D)`, coordinatewise. Hence

`a+b >= max_j h_0(D)_j - min_j h_0(D)_j - 2/n`.   (4.5)

Since the dual objective for `h=h_0+a1` is `J(h)=2+n a`, the paired exactly-reflecting feasible objectives satisfy

`J(h)+J(h^c) >= 2 + n [max_j h_0(D)_j - min_j h_0(D)_j]`.   (4.6)

I do **not** attach an asymptotic estimate to the random range in (4.6) here; none is needed for the structural conclusion.

### B6 outcome

The proposed deformation to restore exact reflection is too rigid. Exact centered reflection forces the pair to remain on the initial sign-vector line plus zero-mode shifts and therefore forbids precisely the free Fourier corrections that make the dual construction interesting. Any viable symmetry argument must allow a controlled transverse defect; exact reflection is a dead route.

# 5. B3 — PROVE SOMETHING STRONGER: exact one-sided Fourier-extension / Chebyshev form of theta

The clipping trajectory is useful for constructing a feasible dual point, but it may not be the right object to analyze globally. Instead, eliminate the trajectory and optimize over the entire affine space at once.

Let

`x_D = P_D e_0`.

Every `h in H_D` has a unique decomposition

`h = M u - x_D + q`,   with `q in Range(P_C)`,   (5.1)

where

`M = sum_j h_j`.

Indeed, `P_D h=-x_D`, the nonzero free component is `P_C h=q`, and `P_0 h=M u`.

Define

`z = x_D - q`.   (5.2)

Then `P_0 z=0`, `P_D z=x_D`, and

`h = M u - z`.   (5.3)

Entrywise positivity of `h` is exactly

`z_j <= M/n` for every `j`.   (5.4)

For a fixed `q`, the smallest admissible `M` is therefore

`M = n max_j (x_D-q)_j`.

Define the one-sided extension constant

`kappa_D = inf_{q in Range(P_C)} max_j (x_D-q)_j`.   (5.5)

Because every candidate `z=x_D-q` has mean zero, `kappa_D>=0`. Equations (5.1)--(5.5) prove the exact identity

`theta(bar G_D) = 1 + n kappa_D`.   (5.6)

This is not an approximation or a relaxation. It is the frequency-dual LP written as a one-sided Chebyshev extension problem.

### 5.1 Equivalent Fourier statement

Since `F* x_D` is the indicator of the selected nonzero frequency set `D` under the current DFT normalization, (5.5) says:

> Prescribe the Fourier coefficients on the random half-set `D` to be the coefficients of `e_0`, force the zero Fourier coefficient to be zero, choose the complementary Fourier coefficients arbitrarily, and minimize only the **largest positive time-domain coordinate**.

Negative coordinates are unrestricted. This one-sided feature is exactly where positivity can be substantially easier than a uniform two-sided `l1/l2` nullspace inequality.

### 5.2 Exact minimax dual and consistency with the frequency primal

For completeness, write `Delta_n={p>=0: sum p=1}`. Since

`max_j v_j = max_{p in Delta_n} <p,v>`,

finite-dimensional convex duality gives

`kappa_D = max { <p,x_D> : p in Delta_n, P_C p=0 }`.   (5.7)

Reason: if `P_C p` is nonzero, the infimum over the unrestricted `q in Range(P_C)` is `-infinity`; if `P_C p=0`, the `q` term vanishes.

For feasible `p`,

`p = P_0 p + P_D p = u + P_D p`,

so

`<p,x_D> = <P_D p,e_0> = p_0 - 1/n`.   (5.8)

Thus

`1 + n kappa_D = n max { p_0 : p>=0, sum p=1, P_C p=0 }`.   (5.9)

The right-hand side is exactly the frequency-primal form of `theta(bar G_D)`. Hence (5.6) is internally dual-consistent with the source LP.

### 5.3 Direct metric consequence

The source ensemble at density `1/2` is invariant under graph complementation, so

`E theta(G_n) = E theta(bar G_n) = 1 + n E kappa_D`.   (5.10)

Therefore the entire frozen upper-exponent problem is equivalent to a one-sided extension estimate:

- `E kappa_D = O((log log n)^beta / sqrt(n))` implies `alpha_LL <= beta`;
- any `beta<1/2` would move the frozen metric;
- `E kappa_D = O(1/sqrt(n))` would prove `alpha_LL=0`;
- the full source asymptotic would require the sharper `E kappa_D = (1+o(1))/sqrt(n)` after accounting for the additive `1` in (5.10).

A stronger sufficient theorem, and now the cleanest B3 target, is the high-probability statement

`kappa_D <= C/sqrt(n)`   (5.11)

for the exact random half-frequency source mask. Proving (5.11) would immediately remove the logarithmic loss, but **(5.11) is a target, not a result of this run**.

### 5.4 Why standard Kashin/RIP results do not immediately settle (5.11)

A two-sided Kashin-type theorem would control absolute coordinate size for every relevant vector or would give a uniform `l2/l1` inequality on a large random subspace. That is stronger than necessary here.
