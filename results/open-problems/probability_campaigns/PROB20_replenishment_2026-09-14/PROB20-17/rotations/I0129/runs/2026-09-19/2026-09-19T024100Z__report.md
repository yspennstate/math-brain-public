# 4. B18 — change language: explicit weighted fundamental circuits after cofactor-light pruning

The previous report suggested a weighted four-partite hypergraph / incidence-matroid formulation. A useful point of care is that selecting an entire four-edge star for each rough component is not automatically the ordinary hypergraphic matroid independence system. I therefore stay inside the **ordinary graphic cycle space of the bipartite incidence graph**, where every statement below is exact.

## 4.1 Almost all rough mass can be forced onto cofactor-light slots

Set
\[
\eta_m=(\log m)^{-1/2}.
\]
Call a residue slot `s` **bad** if
\[
\log H_s>\eta_m m.
\tag{4.1}
\]
For each represented row, (3.4) implies
\[
\#\{\hbox{bad slots in that row}\}
\le
\frac{O(L/\log m)}{\eta_m m}
=O\left(\frac{m}{\sqrt{\log m}}\right).
\tag{4.2}
\]
Uniformly in a legal slot,
\[
\log P_s\le\log A_s=d_0m+O(\log m).
\tag{4.3}
\]
Let `D_m` be the set of clean components incident to at least one bad slot. Then, even after overcounting a component at several bad slots,
\[
\sum_{Z\in D_m}\log Z
\le
\sum_{s\text{ bad}}\log P_s
=O\left(\frac{m^2}{\sqrt{\log m}}\right)
=o(L).
\tag{4.4}
\]
Delete `D_m`, and call the remaining incidence graph `G^{light}`. Every occupied slot of `G^{light}` has the original full-slot cofactor bound
\[
\boxed{\log H_s\le \frac{m}{\sqrt{\log m}}=o(m).}
\tag{4.5}
\]
Moreover the weighted feedback number loses only `o(L)`: if `R` makes `G^{light}-R` acyclic, then `R union D_m` makes `G^circ` acyclic, so by (3.1) and (4.4),
\[
\boxed{
\tau_w(G^{light})
\ge
\delta_{\rm cyc}L-o(L).
}
\tag{4.6}
\]
Thus the constant-fraction cycle-essential mass survives after **all** occupied slots are made cofactor-light. This removes the possibility that the weighted obstruction is carried only by the `O(L/log m)` non-clean cofactor entropy.

## 4.2 A monotone explicit fundamental-circuit family carries the feedback mass

Order the component vertices of `G^{light}` by nonincreasing weight `w(Z)=log Z` (break ties deterministically). Starting with all slot vertices and no component vertices, process components in that order. Accept `Z` if adjoining its component vertex and its four incidence edges keeps the accepted graph acyclic; otherwise reject `Z`.

Let `F` be the final accepted component set and `R` the rejected set. By construction the incidence graph on `F` is a forest, so `R` itself is a component feedback set. Therefore (4.6) gives
\[
\boxed{
\sum_{Z\in R}\log Z
\ge
\delta_{\rm cyc}L-o(L).
}
\tag{4.7}
\]

Now fix a rejected component `Z`. At the moment it is rejected, at least two of its four neighboring residue slots already lie in the same tree of the accepted forest. Choose one such pair by a fixed lexicographic rule. The unique forest path between those two slots, together with the two incidence edges through `Z`, is a simple incidence cycle `C_Z`.

Every component vertex on `C_Z\setminus\{Z\}` was accepted earlier, hence
\[
\boxed{
w(Y)\ge w(Z)\qquad(Y\in C_Z\setminus\{Z\}).
}
\tag{4.8}
\]
No cycle `C_{Z'}` for another rejected component contains `Z`, because all forest paths use only accepted component vertices. Consequently the cycles `{C_Z:Z in R}` are linearly independent in the ordinary `F_2` cycle space: in any nonempty linear combination, an incidence edge at a distinguished rejected component occurring in only its own cycle cannot cancel.

### Theorem 4.1 — cofactor-light monotone fundamental circuits
There is an explicit independent family of simple Berge/incidence cycles `{C_Z}` with distinguished components `Z` such that

1. every slot on every `C_Z` obeys `log H_s=o(m)`;
2. the distinguished logarithmic weights satisfy
   \[
   \sum_Z\log Z\ge\delta_{\rm cyc}L-o(L);
   \]
3. the distinguished component is minimum-weight on its own cycle.

This is stronger than the abstract feedback-set statement: the cycle-essential mass has now been represented by explicit, independent, cofactor-light circuits.

There are only six unordered pairs of row colors among `{0,1,2,4}`. The deterministic endpoint pair chosen for each `C_Z` therefore gives, by pigeonhole, one fixed row-color pair carrying distinguished weight at least
\[
\boxed{
\left(\frac{\delta_{\rm cyc}}6-o(1)\right)L
=(0.00685912575077188\ldots-o(1))L.
}
\tag{4.9}
\]
The connecting forest paths may still use all four colors; (4.9) is not a two-row cycle theorem.

**B18 outcome: positive.** The weighted obstruction can be pushed onto an explicit circuit family after eliminating cofactor-heavy slots at `o(L)` cost. No unproved matroid-exchange assertion is needed.

# 5. B13 — monotone weighted cyclomatic excess

The same descending-weight process supplies the requested monovariant.

Immediately before a rejected component `Z` is considered, let `c(Z)` be the number of connected components of the accepted forest represented among its four neighboring slots. If one were to insert the four-edge star for `Z`, its graph cycle rank would jump by exactly
\[
\mu(Z)=4-c(Z)\in\{1,2,3\}.
\tag{5.1}
\]
Define the running weighted cyclomatic potential
\[
\Psi_q=\sum_{\substack{Z\text{ rejected}\text{ among first }q}}\mu(Z)w(Z).
\tag{5.2}
\]
It is nondecreasing, and because `mu(Z)>=1`, (4.7) yields at the end
\[
\boxed{
\Psi_{\rm final}
\ge
\sum_{Z\in R}w(Z)
\ge
\delta_{\rm cyc}L-o(L).
}
\tag{5.3}
\]
Each positive increment is witnessed by `mu(Z)` independent fundamental cycles in the temporary forest plus `Z`; for the arithmetic use it is enough to retain the one canonical cycle `C_Z` from Section 4.

The crucial point is not merely monotonicity. The descending order makes every positive increment **weight-monotone along its witness cycle**: the closing component is no heavier than any already-present component on the connecting path. The only remaining dust scenario is genuinely many small distinguished components whose total weight is `Theta(L)`; eliminating that scenario requires arithmetic, not graph bookkeeping.

A useful limitation is also now explicit. # 6. B27 — fixed four-color 8-cycle: generalized CRT shows bare square lifts have no global cycle surplus

The first genuinely four-color simple incidence cycle has four component vertices and four shared slot vertices, i.e. length eight. Fix such a simple cycle and enumerate its distinct rough components cyclically as
\[
z_1,z_2,z_3,z_4,
\]
with shared slots `s_i` between `z_i` and `z_{i+1}` (indices modulo four). Assume the four shared slots have the four distinct row colors `0,1,2,4` in some cyclic order. Let
\[
A_i=n_{j_i}-r_i,
\qquad
\kappa_i=\kappa_{k_{j_i},r_i}.
\]
Because both adjacent clean components occupy `s_i`, coprimality of distinct rough prime bases and the individual square lifts give
\[
(z_i z_{i+1})^2\mid A_i-t\kappa_i.
\tag{6.1}
\]
Every prime divisor of `z_i z_{i+1}` exceeds `Y>k_{j_i}`, whereas every prime divisor of `kappa_i` is at most `k_{j_i}`. Thus `kappa_i` is invertible modulo `(z_i z_{i+1})^2`, and (6.1) is equivalent to the one-variable congruence
\[
t\equiv u_i:=A_i\kappa_i^{-1}
\pmod{(z_i z_{i+1})^2}.
\tag{6.2}
\]

For a simple cycle the component prime bases are distinct, so
\[
\gcd((z_i z_{i+1})^2,(z_{i+1}z_{i+2})^2)=z_{i+1}^2,
\]
while opposite moduli are coprime. The generalized Chinese remainder theorem therefore says that the four congruences (6.2) are simultaneously soluble **if and only if** the four adjacent compatibility conditions hold:
\[
u_i\equiv u_{i+1}\pmod{z_{i+1}^2}.
\tag{6.3}
\]
Clearing the invertible kappas, (6.3) is exactly
\[
\boxed{
z_{i+1}^2
\mid
A_i\kappa_{i+1}-A_{i+1}\kappa_i.
}
\tag{6.4}
\]
But (6.4) is precisely the already-known two-slot square-lift determinant for the single shared component `z_{i+1}`.

### Theorem 6.1 — CRT factorization of the bare cycle square lifts
For a simple clean incidence cycle, the shared-slot square-lift congruences in the single unknown `t` impose no additional global around-cycle congruence beyond the pairwise gcd compatibilities (6.4). In particular a four-color 8-cycle does **not** acquire an extra modulus power merely by multiplying its four shared-slot square lifts.

The statement extends verbatim to any finite family of full-slot congruences
\[
t\equiv A_s\kappa_s^{-1}\pmod{P_s^2}:
\]
generalized CRT reduces simultaneous solvability to pairwise congruences modulo `gcd(P_s^2,P_{s'}^2)`. Additional overlaps can strengthen pairwise conditions, but there is no intrinsically cyclic one-variable CRT remainder.

This is a route-refutation result, not a source theorem. It explains why previous attempts to “go around the cycle and gain another p-adic power” kept returning scale-saturated determinants: the algebra of the square lifts alone has no unused global compatibility condition.

For intuition, in the pure pair-dominant, cofactor-light 8-cycle where
\[
A_i=z_i z_{i+1}e^{o(m)},
\]
the magnitude equations reduce to
\[
\log z_i+\log z_{i+1}=d_0m+o(m).
\]
Hence
\[
\log z_1=\log z_3=um+o(m),
\qquad
\log z_2=\log z_4=(d_0-u)m+o(m)
\]
for a free `0<u<d_0`. Even the Archimedean scale has a one-parameter alternating family rather than the half-scale pinning of a 6-cycle. This model calculation is diagnostic only; Theorem 6.1 is the rigorous obstruction.

**B27 outcome: negative but decisive.** A strict 8-cycle deficit cannot come from the shared-slot square lifts alone. The next arithmetic input must use information not contained in the single-unknown CRT system: the component-level signed-Pascal defect congruences, exact quotient collapse/residue relation, the exact nonlinear common-binomial branch, or a new large-prime theorem.
