# 4. B1 — change category: the multi-row factor graph has a linear cycle space

## 4.1 Definition of the factor-incidence graph

For a set `J` of represented row offsets, define a bipartite graph `I_J` as follows.

- One side consists of a vertex `z_ell` for every rough prime-power component `Z_ell` in the collapsed core.
- The other side consists of row-slot vertices `(j,r)` with `j in J` and `0<=r<m+j` (where `j=4` means row lower index `m+4`).
- Join `z_ell` to the unique slot `(j,r_{j,ell})` determined by
\[
n_j\equiv r_{j,\ell}\pmod{Z_\ell}.
\]

Because `Z_ell` is rough, its prime base exceeds every lower index under consideration, and the earlier localization gives a unique admissible residue for each represented row. Thus every component vertex has degree exactly `|J|`. There are no repeated component-slot edges.

This is a factor graph: instead of treating each rough component as one edge between two row slots, it retains the component as a vertex and attaches all row incidences simultaneously.

# 5. B13 — a cyclomatic monovariant: linearly many cycle-closing component insertions

The previous theorem can be made constructive and order-robust.

Work with the four-row factor graph `I_{J_4}`. Start with all `4m+7` slot vertices and no component vertices. Insert the `K` rough components one at a time in **any order**. When a new component `z` is about to be inserted, let
\[

\]
be the number of distinct connected components of the current graph containing its four neighboring slot vertices.

Adding `z` adds one vertex and four edges. It merges the `c(z)` old connected components together through `z`, so the number of connected components changes by `1-c(z)`. Therefore the cyclomatic number changes by
\[
\Delta\beta_1
=4-1+(1-c(z))
=4-c(z).
\tag{5.1}
\]
In particular
\[
\boxed{\Delta\beta_1\in\{0,1,2,3\},\qquad \Delta\beta_1\ge0.}
\tag{5.2}

# 6. B19 — make it an algorithm: explicit cycle extraction and arithmetic certificates

## 6.1 Deterministic cycle-basis extraction

Given an exact candidate `t`, its represented top indices `n_0,n_1,n_2,n_4`, and the rough prime-power components of the collapsed core, the graph construction has no residue branching once a component `Z` is known:
\[
r_j=n_j\bmod Z
\]
with the earlier localization ensuring the residue lies in the correct row-slot range.

A deterministic union-find algorithm therefore does the following.

1. Initialize one disjoint-set node for every slot `(j,r)` in rows `j=0,1,2,4`.
2. Process the rough components `Z` in any fixed order.
3. Compute their four exact residues and the four current union-find roots of those slot vertices.
4. Insert the component vertex and its four incidences.
5. If the four slot roots were distinct, the insertion adds no cycle. Otherwise, union-find paths give explicit fundamental cycle certificate(s). Record `4-c(Z)` independent cycles and then union the components.

Equation (5.1) proves correctness of the cycle count. Theorem 5.1 proves that a linear number of distinct rough components trigger the cycle-output branch.

This is not a finite checker result; it is a constructive proof mechanism. The unresolved issue is not finding the cycles but extracting enough arithmetic loss from their labels.

## 6.2 Exact divisibility carried by every simple cycle

Let a simple cycle be written cyclically as
\[
\mathcal C=(Z_1,v_1,Z_2,v_2,\ldots,Z_\ell,v_\ell,Z_1),
\tag{6.1}
\]

At the slot `v_i`, both pairwise-coprime prime powers divide the same exact integer:
\[

\qquad
Z_{i+1}\mid n_{j_i}-r_i.
\]
Hence
\[
Z_iZ_{i+1}\mid n_{j_i}-r_i.
\tag{6.2}
\]
Multiplying (6.2) around the cycle gives the first cycle certificate:
\[
\boxed{
\left(\prod_{i=1}^{\ell}Z_i\right)^2
\mid
\prod_{i=1}^{\ell}(n_{j_i}-r_i).
}
\tag{6.3}
\]

There is a second certificate using the two cycle slots adjacent to each component. A simple cycle uses two distinct slot neighbors of a component; because one component has only one slot in each row, these two slots come from distinct represented rows. Since `Z_i` divides both associated slot integers,
\[
Z_i\mid
(n_{j_{i-1}}-r_{i-1})-(n_{j_i}-r_i).
\tag{6.4}
\]
The `Z_i` are pairwise coprime, so multiplying gives
\[
\boxed{
\prod_{i=1}^{\ell}Z_i
\mid
\prod_{i=1}^{\ell}
\Big((n_{j_{i-1}}-n_{j_i})-(r_{i-1}-r_i)\Big).
}
\tag{6.5}
\]

Equations (6.3) and (6.5) are exact, cycle-level elimination statements. They are the natural arithmetic objects that were unavailable in the projected two-row forest picture.
