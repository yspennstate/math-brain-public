# 4. B14 — FIND THE GROUP ACTING: Hu's Möbius theorem applies rowwise, but not directly to the moving-prime quartet

Fix a row parameter `k` and put
\[
a_r:=\kappa_{k,r}
=(-1)^{k-1-r}k\binom{k-1}{r}.

For `0<=r<k-1`,
\[
q_r:=\frac{a_{r+1}}{a_r}
=-\frac{k-1-r}{r+1}
=\frac{r+1-k}{r+1}.
\tag{4.1}
\]
Solving `r` from `q_r` and incrementing once gives the exact Möbius evolution
\[
\boxed{

=
\frac{(k-1)q_r+1}{-q_r+k+1}.
}
\tag{4.2}

\[
M_k=
\begin{pmatrix}
k-1&1\\
-1&k+1

\det M_k=k^2.
\tag{4.3}

# 6. B11 — DUALIZE: an integer-valued interpolation polynomial globalizes every clean moving-prime congruence

This is the main result of the run.

## 6.1 The interpolation polynomial

For `k>=2`, let `I_k(X)` be the unique polynomial of degree at most `k-1` satisfying
\[
I_k(r)=\kappa_{k,r}
=(-1)^{k-1-r}k\binom{k-1}{r}
\qquad(0\le r<k).
\tag{6.1}
\]

### Lemma 6.1 — integer-valuedness and congruence preservation

`I_k(n)` is an integer for every integer `n>=0`. Moreover, if `p>k`, `f>=1`, and
\[
x\equiv y\pmod{p^f},
\]
then
\[
\boxed{I_k(x)\equiv I_k(y)\pmod{p^f}.}
\tag{6.2}
\]

**Proof.** Let `b_r=kappa_{k,r}`. Newton interpolation on the consecutive nodes `0,1,...,k-1` gives
\[
I_k(X)=\sum_{j=0}^{k-1}(\Delta^jb)_0\binom Xj.
\tag{6.3}
\]
Every finite difference `(Delta^j b)_0` is an integer, and `binom(n,j)` is an integer for every integer `n>=0`; hence `I_k(n)` is integer-valued.

For the congruence, write
\[
\binom Xj=\frac{X(X-1)\cdots(X-j+1)}{j!}.
\]
The numerator is an integer polynomial, so its difference at `x` and `y` is divisible by `x-y`, hence by `p^f`. Because `j<k<p`, `j!` is a unit modulo `p^f`. Therefore
\[
\binom xj\equiv\binom yj\pmod{p^f}
\]
for every `j<k`; (6.2) follows from (6.3). QED.

## 6.2 Exact positive Lagrange / harmonic formula

The Lagrange denominator at node `r` is
\[
\prod_{\substack{0\le s<k\\s\ne r}}(r-s)
=(-1)^{k-1-r}r!(k-1-r)!.
\]
The sign cancels the sign in `kappa_{k,r}`, giving the exact positive formula
\[
\boxed{
I_k(X)
=
\frac{k}{(k-1)!}
\sum_{r=0}^{k-1}
\binom{k-1}{r}^{\!2}
\prod_{\substack{0\le s<k\\s\ne r}}(X-s).
}
\tag{6.4}
\]
For `n>=k`, factor `(n)_k=k! binom(n,k)` from each product. Then
\[
\boxed{
I_k(n)
=
k^2\binom nk
\sum_{r=0}^{k-1}
\frac{\binom{k-1}{r}^{2}}{n-r}.
}
\tag{6.5}
\]
This identity is exact. In particular `I_k(n)>0` for `n>=k`.

Using
\[
\sum_{r=0}^{k-1}\binom{k-1}{r}^2
=
\binom{2k-2}{k-1},
\]
and `r<=k`, (6.5) gives uniformly when `n>>k^2`
\[
\boxed{
I_k(n)
=
\binom nk\,
\frac{A_k}{n}
\left(1+O\!\left(\frac{k}{n}\right)\right),
\qquad
A_k:=k^2\binom{2k-2}{k-1}.
}
\tag{6.6}
\]

## 6.3 One integer containing the entire clean rough core

Define
\[
\boxed{
Q_m
:=
I_m(n_0)
-I_{m+1}(n_1)
-I_{m+2}(n_2)
+I_{m+4}(n_4).
}
\tag{6.7}
\]
This is an integer by Lemma 6.1.

### Theorem 6.2 — global clean-core divisor

For every sufficiently large exact plastic-branch quartet,
\[
\boxed{W^\circ\mid Q_m.}
\tag{6.8}
\]

**Proof.** Fix a clean component
\[
Z=p^{v_p(t)}\in\mathcal C^\circ.
\]
By definition `p>4m+8`, hence `p>k_h` for every `h in {0,1,2,4}`. The slot decomposition gives
\[
n_h\equiv r_h\pmod Z.
\]
Lemma 6.1 therefore gives
\[
I_{k_h}(n_h)
\equiv I_{k_h}(r_h)
=\kappa_{k_h,r_h}
\pmod Z.
\]
Taking the signed four-row combination,
\[
Q_m\equiv
\kappa_{m,r_0}
-\kappa_{m+1,r_1}
-\kappa_{m+2,r_2}
+\kappa_{m+4,r_4}
=D_Z
\equiv0\pmod Z
\]
by the preserved signed-Pascal theorem (3.11). Thus every clean component divides `Q_m`. Distinct clean components are powers of distinct primes, hence pairwise coprime, so their product `W^circ` divides `Q_m`. QED.

This is the key dualization: the moving-prime congruence family is no longer spread over unrelated fields. It is a divisor of one global integer.
