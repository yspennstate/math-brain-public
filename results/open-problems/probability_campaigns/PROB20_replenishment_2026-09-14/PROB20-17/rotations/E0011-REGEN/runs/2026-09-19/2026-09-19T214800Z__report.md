## 4. B2 — ATTACK THE NEGATION FIRST: the most natural charge-neutral annulus fails at size 3

### 4.1 Square annular entrance states

At the anchor `p=1/2`, consider the following stable finite pattern `A_n`, `n>=3`:

- in an `n x n` square, every perimeter site is vacant;
- every strict interior site is O;
- outside the vacancy perimeter is CO.

The vacancy perimeter separates the O core from the CO exterior, so there is no adjacent CO--O pair initially. Translation of this pattern gives a location-flexible candidate rather than a fixed absolute site.

Let `V_n` be the vacancy perimeter. It is a simple square-lattice cycle, hence

`|V_n| = |E_00(V_n)| = 4(n-1)`.

This is exactly the charge-neutral topology identified below in B12.

### 4.2 A source-valid fatal subevent

Define `C_n` to be the event that, starting from `A_n` under the legal all-CO exterior, **every effective event until the configuration becomes all CO is a CO adsorption**; if an O2 adsorption occurs, `C_n` fails.

On `C_n`:

- a CO arriving at a vacancy with no neighboring O survives and fills that vacancy;
- a CO arriving at a vacancy adjacent to O reacts immediately with one adjacent O (uniformly if there is more than one), so the landing site stays vacant and the removed O site becomes vacant;
- no new O is created, because no O2 event occurs.

Thus the number of O sites can only decrease and, once it reaches zero, the remaining vacancies are filled by CO. The event therefore ends in the absorbing all-CO configuration.

Any source-valid two-child SUCCESS event for a coexistence seed must retain/create oxygen in its children. It is consequently disjoint from `C_n`. Hence, for any regenerative trial built on this entrance and this legal exterior,

`f >= P(C_n)`

and, since SUCCESS and FATAL are disjoint,

`a <= 1-f`.

Therefore

`a-63 f <= 1-64 f <= 1-64 P(C_n)`.

So `P(C_n)>=1/64` is a complete **rejection certificate** for this candidate seed.

### 4.3 Exact recursion

For a transient state with oxygen set `O` and vacancy set `V`, let `e(V)` be the number of vacant-vacant nearest-neighbor edges. Multiplying all `p=1/2` rates by four gives weight `2` for each CO clock and weight `1` for each O2 edge. Let `d_O(v)` be the number of O neighbors of vacancy `v`.

The exact CO-only poison probability `P(O,V)` obeys

`P(empty,empty)=1`,

and

`P(O,V) = 1/(2|V|+e(V)) * [`

`  2 sum_{v in V: d_O(v)=0} P(O,V\{v})`

`+ 2 sum_{v in V: d_O(v)>0} (1/d_O(v)) sum_{u~v,u in O} P(O\{u}, V union {u}) ]`.

Every O2 clock contributes zero to this subevent. This is a finite exact recursion: each CO-only transition either removes an O or fills a vacancy that is not adjacent to O.

Suppose the vacancy perimeter is directly adjacent to a CO collar and a trial declares removal of any collar CO to be FATAL. Initially the ring has

## 5. B12 — FIND WHAT IS CONSERVED: connected charge-neutral vacancy geometry is exactly unicyclic

`Q = N_CO - N_O`.

At `p=1/2`, `q=1`, its generator is

`LQ = (V-E_00)/2`,

where `V` is the number of vacancies and `E_00` the number of vacant-vacant nearest-neighbor edges.

For one connected finite vacancy component `G`, let `beta_1(G)` be its cycle rank. The graph identity

`beta_1 = E_00 - V + 1`

gives

`V-E_00 = 1-beta_1`.

Therefore the contribution of a connected vacancy component to charge drift is

`(1-beta_1)/2`.

So, among connected vacancy interfaces:

- trees (`beta_1=0`) have positive CO-directed charge drift `+1/2`;
- **unicyclic** components (`beta_1=1`) have exactly zero charge drift;

## 6. B19 — MAKE IT AN ALGORITHM: soft-collar annular SUCCESS/FATAL/RETRY trial

The exact screen determines how the regenerative algorithm must be designed.

### 6.1 Seed class

Fix a finite protected box `B` with a central restart window and two forward child windows. Define a **soft annular seed class** `S_d` existentially, not by an absolute microscopic word. A state is in `S_d` if inside the restart window there is:

1. a nonempty connected O core;
2. a simple nearest-neighbor vacancy circuit surrounding that core;
3. CO on the outside of the circuit;
4. at least one **sacrificial** CO protection layer whose defects are allowed during an excursion;
5. a further intact outer quarantine layer/frontier so that arbitrary exterior information cannot influence the core before the trial is stopped.

Translation, reflection and small circuit deformations are part of the same seed class. In particular, the class is not tied to one exact location and does not continue the retired R08 fuel-strip/Hamming-defect ladder.

The charge calculation motivates the vacancy circuit; the B2 rigid-collar rejection motivates the soft protection.

### 6.2 Trial stopping rule

Start from `S_d`, require at least one actual Harris event before a return is declared, and expose the exact source graphical dynamics in the finite influence region. At each step recompute the topological seed certificates.

- **SUCCESS:** before outer protection is breached, each of two prescribed forward child windows contains a translated admissible `S_d` seed with disjoint future protection regions. This is the deterministic two-child event needed by the eventual block comparison.
- **RETRY:** no SUCCESS has occurred, the current excursion has returned to one admissible `S_d` seed in the restart window, the same outer protected-exterior quantifiers are restored, and the future Harris slab is fresh.
- **FATAL:** SUCCESS and RETRY have not occurred and either (i) the required O or CO phase is lost, (ii) the exploration/influence frontier breaches the outer quarantine, or (iii) the fixed finite time horizon expires outside `S_d`.

This partitions a finite trial. Because a RETRY restores the same source-valid seed class and protection quantifiers, the strong Markov restart lemma applies exactly. FATAL deliberately absorbs all unresolved end-of-horizon states; no probability is hidden outside SUCCESS/FATAL/RETRY.

### 6.3 Exact finite computation once the state description is proved viable

At `p=1/2` every effective CO clock has rational rate `1/2`, every vacant-pair O2 clock rational rate `1/4`, and every finite `r=infinity` reaction-choice branch has a rational `1/k` factor. Therefore, after a finite state/descriptor representation is fixed, the SUCCESS and FATAL probabilities are exact rational absorbing probabilities.

The algorithm is:

1. canonicalize a seed state modulo permitted translations/dihedral symmetries;
2. enumerate every effective CO clock, vacant-pair O2 clock and reaction-choice branch;
3. stop immediately on SUCCESS, RETRY or FATAL;
4. otherwise append the reached state/descriptor and continue breadth-first;
