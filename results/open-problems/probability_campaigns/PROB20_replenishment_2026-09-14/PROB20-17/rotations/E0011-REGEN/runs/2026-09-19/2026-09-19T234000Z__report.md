## 2. New idea: protect against *causal influence*, not against every collar change

The one-layer obstruction is a stopping-rule obstruction, not a dynamical impossibility. Removing one CO in an outer shell is not itself harmful to the central annular trial unless information from the arbitrary exterior can propagate far enough, fast enough, to alter the finite outcome before its horizon.

For a finite-horizon trial, the source process has a Harris graphical representation with finite-range event supports. This gives an explicit, source-uniform superexponential tail for exterior influence. Consequently an ideal finite-core calculation with a convenient boundary can be converted into a genuinely protected-exterior trial by paying an arbitrarily small additive error in `a-63f`, provided the buffer is wide enough.

This is the complete lemma proved below.

## 3. B6 — DEFORM: replace hard quarantine by a causal buffer

Fix `p in (0,1)` and put `q=2(1-p)`. Fold the instantaneous reaction into the local update attached to each adsorption mark.

### Lemma 3.1 — event-support radii

A CO adsorption mark centered at `x` occurs at rate `p` and its result is determined by, and can change, only sites in the closed nearest-neighbor ball

`B_1(x)`.

An O2 adsorption mark on a nearest-neighbor edge `{x,y}` occurs at rate

`q/4 = (1-p)/2`

and its result is determined by, and can change, only sites in

`B_1(x) union B_1(y)`.

Therefore every event support has at most `8` sites and L1 diameter at most `3`.

**Proof.** A CO arrival only needs to know whether `x` is vacant and which nearest-neighbor O atoms can react with the arriving CO; any instantaneous annihilation removes the arriving particle and one adjacent opposite particle and cannot create a new occupied particle. Hence no site outside `B_1(x)` is inspected or changed. For O2, the two deposited O atoms can only react with CO atoms adjacent to one of the two endpoints, so the full support is `B_1(x) union B_1(y)`. For adjacent `x,y`, this union has `5+5-2=8` sites and L1 diameter `3`. QED.

This statement is independent of any annulus geometry. It is a property of the exact source process.

## 4. B13 — FIND WHAT ONLY INCREASES: causal distance requires event depth

Let `A` be the finite set of sites on which a trial's terminal decision is read, and let `B=A^{+d}` be its L1 `d`-neighborhood. Couple two source processes with the same Harris marks and reaction-choice auxiliaries but allow their initial conditions to differ arbitrarily on `B^c`.

Trace the state of a target site backwards through event supports. A single predecessor step can move from one dependency site to another site in the same event support. By Lemma 3.1, such a step changes L1 location by at most `3`. Hence a dependency path from `A` to `B^c` must contain at least

`N := ceil(d/3)`

event marks.

The required causal depth is thus a deterministic monotone barrier: increasing the buffer by three lattice units forces at least one additional time-ordered local event into every possible exterior-to-core influence chain.

## 5. B25 — COUNT THE SAME THING TWICE: explicit factorial causal-cone tail

We now count the possible backward dependency chains.

Fix a dependency site `z`.

### CO predecessors

A CO event support contains `z` iff its center belongs to `B_1(z)`, so there are `5` possible centers. Each clock has rate `p`. Once such an event is chosen, at most `4` *other* sites in its support can be the next site on an oriented dependency chain. Thus the total rate-weighted continuation count contributed by CO events is at most

`5 * p * 4 = 20 p`.

### O2 predecessors

An O2 support contains `z` iff its edge has at least one endpoint in `B_1(z)`. There are exactly `16` such undirected nearest-neighbor edges: the five vertices of `B_1(z)` have degree sum `20`, and the four internal center-neighbor edges were counted twice, so the union contains `20-4=16` edges. Each edge clock has rate `(1-p)/2`. Its support contains at most `8` sites, hence at most `7` alternatives for the next dependency site. The O2 contribution is therefore at most

`16 * ((1-p)/2) * 7 = 56(1-p)`.

Define

`K(p) := 20p + 56(1-p) = 56-36p`.

In particular,

`K(p) <= 56` for every `p in (0,1)`,

and at the metric anchor `p_0=1/2`,

`K(1/2)=38`.

### Theorem 5.1 — finite-speed causal insulation

For any finite target set `A`, buffer width `d`, and time horizon `tau`, the probability that the state/history on `A` up to time `tau` depends on the initial condition outside `A^{+d}` is at most

`epsilon(A,d,tau,p) := |A| * sum_{n>=ceil(d/3)} (K(p) tau)^n / n!`.

Consequently `epsilon -> 0` superexponentially in `d` for fixed `A,tau,p`, and source-uniformly one may replace `K(p)` by `56`.

If `N=ceil(d/3) >= 2 K(p) tau`, then the explicit bound

`epsilon(A,d,tau,p) <= 2 |A| (e K(p) tau / N)^N`

holds.

**Proof.** Start a backward chain from any `z_0 in A`. For a specified chain length `n`, iterating the two predecessor counts above bounds the sum, over all oriented spatial/support choices for the chain, of the product of their clock rates by `K(p)^n`. The `n` marks must occur in backward time order inside an interval of length `tau`; the volume of the ordered time simplex is `tau^n/n!`. Therefore the expected number of length-`n` backward causal chains from one target site is at most `(K(p)tau)^n/n!`. A chain reaching outside `A^{+d}` needs `n>=N` by Section 4. Markov/union bound over chains and over `|A|` targets proves the first inequality.

For the second, write `x=K(p)tau`. If `N>=2x`, the ratio of consecutive terms after the first is at most `x/(N+1)<1/2`, so the tail is at most `2x^N/N!`. Stirling's elementary inequality `N! >= (N/e)^N` gives the displayed formula. QED.

No independence between different candidate chains is assumed; this is an expectation/union bound in the Harris construction.

## 6. Main transfer theorem for the regeneration metric

The theorem above turns any finite-core trial calculation into a protected-exterior certificate with an explicit margin penalty.

Consider an **ideal finite-core trial** `T_tilde` with:

- a finite decision set `A`;
- finite horizon `tau`;
- source-model adsorption/reaction rules on a finite protected region containing `A^{+d}`;
- arbitrary convenient deterministic boundary data at the outside of that region;
- terminal categories SUCCESS / FATAL / RETRY, with RETRY returning to the same location-flexible core seed class;
- exact/certified ideal probabilities `a_tilde, f_tilde`.

The boundary is only a computational device. In the actual source trial, initialize the same finite protected pattern through `A^{+d}` but allow the exterior beyond the buffer to be arbitrary. Couple the actual and ideal trials with the same local Harris marks. Declare the existence of a causal chain from outside the buffer to the decision set before `tau` as FATAL. On its complement, the two trials have identical histories on `A` and therefore identical terminal decisions.

### Theorem 6.1 — margin compiler

The resulting source-valid protected-exterior trial satisfies

`a >= a_tilde - epsilon`,

`f <= f_tilde + epsilon`,

and hence

`a - 63 f >= (a_tilde - 63 f_tilde) - 64 epsilon(A,d,tau,p)`.

**Proof.** Let `Bad` be the causal-contamination event. Theorem 5.1 gives `P(Bad)<=epsilon`, uniformly over the arbitrary exterior configuration. On `Bad^c`, graphical locality makes the actual and ideal histories on the decision set identical through `tau`. Thus actual SUCCESS contains ideal SUCCESS minus `Bad`, giving the first inequality. Actual FATAL is contained in ideal FATAL union `Bad`, giving the second. Substitution yields the margin inequality. QED.

This removes the inherited rigid-quarantine rule. A sacrificial/quarantine site may change many times without being fatal; only a Harris dependency chain that actually crosses the buffer before the terminal decision must be charged to FATAL.
