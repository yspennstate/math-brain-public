## 2. A stable two-vacancy SOS phase interface

For an integer-valued height function

`h : Z -> Z`

satisfying

`|h(y+1)-h(y)| <= 2`                                                   (2.1)

for every `y`, define a configuration `eta_h` on `Z^2` row by row by

`eta_h(x,y)=2`  if `x <= h(y)-1`,

`eta_h(x,y)=0`  if `x in {h(y),h(y)+1}`,

`eta_h(x,y)=1`  if `x >= h(y)+2`.                                     (2.2)

Thus each horizontal row is

`... O O | 0 0 | CO CO ...`,

but the location of the two-vacancy gap may vary with `y` by at most two lattice units from one row to the next.

### Lemma 2.1 — the SOS configuration is source-stable

Every configuration `eta_h` satisfying (2.1) is stable: it contains no nearest-neighbor `O-CO` pair.

### Proof

Within one row, the two vacant sites separate the O half-line from the CO half-line, so there is no horizontal unlike occupied pair.

For a vertical unlike pair at a fixed horizontal coordinate `x`, one row would have to be O there and the adjacent row CO there. If the two adjacent heights are `a` and `b`, this requires simultaneously

`x <= a-1`

and

`x >= b+2`

in one orientation, which is possible only if `a-b >= 3`. The opposite orientation requires `b-a >= 3`. Both are excluded by (2.1). QED.

This family is a genuine two-dimensional source state, not a one-dimensional surrogate: vertical nearest-neighbor stability is part of the statement.

## 3. Exact one-mark forward move at a local minimum

Fix a row `y` and write `a=h(y)`. Suppose

`a <= h(y-1)` and `a <= h(y+1)`.                                      (3.1)

Thus row `y` is a local minimum of the height profile. Its two vacant sites are

`v_0=(a,y)`, `v_1=(a+1,y)`.

At general source parameter `p`, the O2 source clock on the vacant edge `{v_0,v_1}` has rate

`q/4 = (1-p)/2`.

### Theorem 3.1 — one O2 source mark raises one local minimum exactly

If the O2 source clock on `{v_0,v_1}` rings while the system is in `eta_h`, then after the instantaneous reactions the resulting configuration is exactly

`eta_{h+e_y}`,                                                        (3.2)

where `e_y` adds one to the height at row `y` and leaves every other height unchanged.

In particular, at the anchor `p=1/2`, the exact clean forward clock has rate `1/4`.

### Proof

At `v_0=(a,y)`, the horizontal neighbor `(a-1,y)` is O. Under (3.1), the vertical neighbors `(a,y+-1)` are either vacant or O: an adjacent row of height `a` has a vacancy at `x=a`, while an adjacent row of height `a+1` or `a+2` has O there. They cannot be CO. Therefore the O deposited at `v_0` has no adjacent CO and survives.

At `v_1=(a+1,y)`, the horizontal neighbor `(a+2,y)` is CO. Again by (3.1), each vertical neighbor at horizontal coordinate `a+1` is either vacant or O, never CO. Hence the deposited O at `v_1` has exactly one adjacent opposite particle, namely the horizontal CO at `(a+2,y)`. The instantaneous reaction removes that deposited O and that CO, so both `v_1` and `(a+2,y)` are vacant afterward.

The row has therefore changed from

`... O | 0 0 | CO ...`

to

`... O O | 0 0 | CO ...`,

with the new gap at `a+1,a+2`. This is exactly height `a+1`. Every other row is untouched. Since the two neighboring heights were between `a` and `a+2`, after the increase they differ from `a+1` by at most one, so the resulting height profile still satisfies (2.1). QED.

### Interpretation

This is stronger than the earlier local zipper statement in one important respect: the **phase collar is part of the state and is regenerated automatically by the same source mark**. The old left vacancy becomes O and the old first CO becomes the new right vacancy. There is no naked-packet-to-phase-collar reverse construction after a clean move.

## 4. Exact two-mark backward move at a local maximum

Now suppose row `y` is a local maximum:

`a >= h(y-1)` and `a >= h(y+1)`.                                      (4.1)

Again the vacant sites are `v_0=(a,y)` and `v_1=(a+1,y)`.

### Theorem 4.1 — two CO source marks lower one local maximum exactly

Starting from `eta_h`, suppose a CO source arrival occurs once at each of `v_0` and `v_1`, in either order, with no other source occurrence changing this local neighborhood between the two arrivals. After the two instantaneous-reaction updates, the resulting configuration is exactly

`eta_{h-e_y}`.                                                        (4.2)

At `p=1/2` the two required site clocks each have rate `1/2`.

### Proof

First consider a CO arrival at the right vacancy `v_1=(a+1,y)`. Horizontally it sees the left vacancy `v_0` and the CO at `(a+2,y)`. Under (4.1), each vertical neighbor at horizontal coordinate `a+1` is either vacant or CO, never O. Thus the arriving CO has no adjacent O and survives at `v_1`.

Now consider a CO arrival at the left vacancy `v_0=(a,y)`. The horizontal site `(a-1,y)` is O. Under (4.1), the vertical neighbors at coordinate `a` are vacant or CO, never O. Hence `(a-1,y)` is the unique adjacent O. The incoming CO reacts with it; both particles are removed, so `(a-1,y)` and `v_0` are vacant afterward.

The same conclusions hold if the left arrival occurs first: it removes `(a-1,y)` and returns `v_0` to vacancy; the later arrival at `v_1` still has no adjacent O and survives. The final row is therefore

`... O | 0 0 | CO CO ...`

with the two vacancies now at `a-1,a`, which is exactly height `a-1`. Neighboring heights were between `a-2` and `a`, so the new height again differs from each by at most one. QED.

Thus the clean SOS interface has an exact chemical asymmetry:

- forward local-minimum motion: **one O2 source mark**;
- backward local-maximum motion: **two CO source marks**.

No approximation or mean-field step is used.

## 5. The asymmetry is source-count optimal by the exact charge

Let

`Q = N_CO - N_O`.

For every finite source history in the infinite-reaction model, reactions remove one CO and one O and therefore preserve `Q`; a CO source arrival changes `Q` by `+1`, while an O2 source arrival changes `Q` by `-2`. Hence for any finite history

`Delta Q = A_CO - 2 A_O2`,                                             (5.1)

where `A_CO` and `A_O2` are the numbers of source arrivals of the two kinds.

For two clean SOS configurations that differ on only finitely many rows, define

`Delta H = sum_y (h'(y)-h(y))`.

Increasing one row height by one changes exactly two sites: the old left vacancy becomes O and the old first CO becomes vacant. Consequently `Q` drops by two. By telescoping,

`Delta Q = -2 Delta H`.                                                (5.2)

Combining (5.1) and (5.2) gives the exact clean-interface selection rule

`A_CO - 2 A_O2 + 2 Delta H = 0`.                                      (5.3)

### Corollary 5.1 — optimal mark lower bounds

If a clean-to-clean source history has `Delta H=k>0`, then

`A_O2 >= k`,

so it uses at least `k` source arrivals. If `Delta H=-k<0`, then

`A_CO >= 2k`,

so it uses at least `2k` source arrivals.

For `k=1`, Theorems 3.1 and 4.1 attain these lower bounds exactly. Therefore the one-mark/two-mark asymmetry is **not** an artifact of the chosen scripts; it is forced by the exact source charge.

### Proof

For `Delta H=k>0`, (5.3) gives

`2 A_O2 - A_CO = 2k`,

hence `A_O2 >= k`. For `Delta H=-k`, it gives

`A_CO - 2 A_O2 = 2k`,

hence `A_CO >= 2k`. QED.

This is the main structural theorem of the run.

## 6. A clean small-time separation valid for every fixed coefficient

The exact mark-count gap has an immediate finite-window consequence.

Fix a finite guarded neighborhood of one clean SOS cell and let `Lambda<infinity` bound the total primitive source-clock rate in that guard. At a local minimum, let `R_t` be the cylinder event that the designated horizontal O2 clock rings exactly once during `[0,t]` and no other source clock in the guard rings. At `p=1/2`, Theorem 3.1 gives

`P(R_t) >= (t/4) exp(-Lambda t)`.                                     (6.1)

Any clean-to-clean transition with net height `-1` needs at least two source arrivals by Corollary 5.1. Therefore, regardless of how such a backward transition is implemented inside the same finite guard,

`P(clean backward translation by t)`
` <= P(Pois(Lambda t)>=2)`
` <= ((Lambda t)^2/2) exp(Lambda t)`.                                (6.2)

Combining (6.1)--(6.2),

`P(R_t) / P(clean backward translation by t) -> infinity`             (6.3)

as `t downarrow 0`. Hence for every fixed finite comparison coefficient `kappa`, including `kappa=63` and the coordinator's stronger coefficient `2`, there exists `t_kappa>0` such that the **clean forward / clean backward** ratio exceeds `kappa` for every `0<t<t_kappa`.

This is a rigorous order separation, but it is **not yet** a positive value of `M_reg`: one-mark histories can leave the clean SOS manifold without being a completed backward translation. Those defect exits must be repaired or included in a finite multitype regenerative class before (6.3) can be used as a source-closing SUCCESS/FATAL ratio.

## 7. Exact defect bookkeeping: the missing states have a charge label

Equation (5.3) also organizes the dirty states.

A clean right move has

`Delta Q=-2`, `Delta H=+1`,

so `Delta Q+2 Delta H=0`.

A completed clean left move has

`Delta Q=+2`, `Delta H=-1`,

again giving zero.

By contrast, after the **first** CO mark of a would-be left move, before the second CO completes the translated clean front, the source history has accumulated

`Delta Q=+1`

but no completed clean height decrement. Thus the natural defect ledger

`D := (source charge accumulated since the last clean SOS state) + 2*(completed clean height change)`

has value `D=1` on this one-CO transient and returns to `D=0` when the complementary CO mark completes the clean left move.

This does not by itself prove closure of all possible local defects, but it gives a non-arbitrary coordinate for the next finite state space: clean states have `D=0`, the primary one-CO transients have `D=1`, and any proposed repair must pay the exact charge balance before it can return to a clean height state. The state search therefore need not be organized by raw occupation strings alone.
