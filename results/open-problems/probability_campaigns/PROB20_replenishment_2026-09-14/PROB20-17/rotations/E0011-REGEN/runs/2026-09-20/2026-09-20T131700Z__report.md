## 3. Main local theorem: two rings of one O2 clock translate the phase cell exactly

Let `Z` denote a source O2 adsorption on the boundary edge

`e={v_0,v_1}`.

### Theorem 3.1 — same-edge double-hit translation

Starting from (2.1), the legal two-mark word

`Z Z`                                                       (3.1)

maps the clean phase cell exactly to the translated phase cell (2.2). Both reactions on the first `Z` are forced, and the two O atoms deposited by the second `Z` both survive. No reaction-choice favorable branch is used.

### Proof

On the first `Z`, O is deposited at `v_0` and `v_1`. At `v_i`, the unique adjacent CO is `w_i`: the inward neighbor `u_i` is O, the other endpoint of `e` receives O, and the tangential guard site is vacant. Therefore the O deposited at `v_i` reacts with `w_i`. After the first mark,

`u_i=O, v_i=0, w_i=0, x_i=CO` for `i=0,1`.              (3.2)

In particular the same boundary edge `e={v_0,v_1}` is still vacant, so a second O2 adsorption on **the same edge** is legal.

On the second `Z`, O is again deposited at `v_0,v_1`. Now neither endpoint has any adjacent CO: `w_i` was cleared by the first mark, `u_i` is O, the tangential guard sites are vacant, and the other endpoint carries the co-deposited O. Hence both newly deposited O atoms survive. The sites `w_i` remain vacant and `x_i` remain untouched CO. This is exactly (2.2). QED.

### Why this is different from the preceding zipper theorem

One `Z` produces an outward vacancy EAR / `2 x 2` vacant plaquette at `v_0,v_1,w_0,w_1`. The second ring is not an intrinsically harmful duplicate. It converts that EAR into an **exact translated phase cell** by filling the old boundary row with O while leaving the newly cleared row vacant.

So, on this clean straight cell, the first and second rings of the same designated edge have the deterministic interpretation

`clean phase cell -> EAR -> translated phase cell`.        (3.3)

This removes one local compiler stage that had previously been left implicit.

## 4. Source-count optimality of the double hit

Let

`Q=N_CO-N_O`.

Every successful CO source arrival changes `Q` by `+1`, every successful O2 source arrival changes `Q` by `-2`, and instantaneous reactions preserve `Q`.

Relative to the clean cell (2.1), the translated target (2.2) removes the two CO particles at `w_0,w_1` and adds two O particles at `v_0,v_1`. Hence

`Delta Q = -2 - 2 = -4`.                                (4.1)

Consider any exact finite source trajectory which makes this local transformation while restoring / preserving the stated guarded exterior. If it uses `A_CO` CO arrivals and `A_O2` O2 arrivals, then

`A_CO - 2 A_O2 = -4`.                                   (4.2)

Thus

`A_O2 = 2 + A_CO/2`,

and the total number of source arrivals satisfies

`L=A_CO+A_O2 = 2 + (3/2) A_CO >= 2`.                    (4.3)

The word `ZZ` uses exactly two O2 arrivals and no CO arrival. Therefore:

**Corollary 4.1.** The exact one-layer translation (2.1) -> (2.2) has minimum possible source depth **two**, and the same-edge double hit attains that minimum.

This is useful for regeneration estimates because the exact same-class local compiler does not hide a long prescribed repair word.

## 8. Parallel straight-strip lift
