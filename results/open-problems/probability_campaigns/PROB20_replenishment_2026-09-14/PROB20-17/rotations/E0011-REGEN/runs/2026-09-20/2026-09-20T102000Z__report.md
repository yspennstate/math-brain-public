## 2. The original SOS row gaps form a disjoint anchor matching

Fix `n` consecutive rows of a clean SOS seed `eta_h`. For each row `y`, write

`e_y := {(h(y),y),(h(y)+1,y)}`.

Each `e_y` is a nearest-neighbor vacant edge. The `n` edges `e_y` are pairwise vertex-disjoint because they lie in distinct rows. Therefore the original vacancy set contains a matching of size exactly `n`.

The following elementary source fact is the key.

### Lemma 2.1 — one source occurrence can occupy at most two original vacant sites

Let `A_0` be any specified set of sites which are vacant before a source occurrence. After one successful source occurrence and all instantaneous reactions triggered by it, at most two sites of `A_0` can have changed from vacant to occupied.

### Proof

A CO source occurrence adsorbs at one vacant site. It can therefore make at most one previously vacant site occupied. If the incoming CO reacts, its adsorption site returns to vacancy and the reaction partner changes from occupied to vacant, so reactions do not increase the number of old vacancies made occupied.

An O2 source occurrence adsorbs on two adjacent vacant sites and can therefore make at most those two old vacant sites occupied. Any instantaneous O--CO reaction removes particles and creates vacancies; it cannot create an additional occupied site. Hence the number of sites of `A_0` newly occupied by one source occurrence is at most two. QED.

This statement is independent of which reaction partner is selected when several unlike neighbors are available.

## 3. Main theorem: linear-depth survival of an exact vacancy-edge anchor

### Theorem 3.1 — SOS anchor-survival theorem

Start from any clean `n`-row SOS seed `eta_h`, flat or nonflat, with `|h(y+1)-h(y)|<=2`. Run any source-valid history of `k` successful source occurrences, with arbitrary legal reaction outcomes. If

`2k < n`,

then at least one of the original horizontal row-gap edges `e_y` is still entirely vacant after the `k` occurrences.

Equivalently, the source-event distance from the clean SOS seed to destruction of **all** original row-gap anchors is at least

`ceil(n/2)`.

### Proof

Suppose every original row-gap edge `e_y` has ceased to be an all-vacant edge. Since the `e_y` are pairwise vertex-disjoint, for each of the `n` edges at least one of its two original endpoints must now be occupied. These witnesses are all distinct, so at least `n` sites from the original vacancy set are occupied.

By Lemma 2.1, after `k` source occurrences at most `2k` sites from the original vacancy set can be occupied. Thus destruction of all `n` original edges implies `2k>=n`. Contrapositively, if `2k<n`, one original `e_y` remains an adjacent vacant pair. QED.

### Corollary 3.2 — second-order closure without enumeration

For a five-row SOS window (`n=5`), every state reachable in at most two source occurrences retains an exact original adjacent vacancy pair. This includes:

- every one-mark dirty state from P02-B;
- every state formed by one competing interruption during any one- or two-mark first-order repair word;
- flat and nonflat corner geometries with neighboring height differences `0,1,2`;
- arbitrary legal reaction-partner outcomes.

Thus there is no need to enumerate second-order occupation strings merely to prove the existence of a surviving vacancy nucleus.

## 4. Sharpness of the event-depth bound on a flat ribbon

The lower bound `ceil(n/2)` is not an artifact of the proof.

Take the flat ribbon `h(y)=0`, so the original vacancies are the two columns `x=0,1`. For every disjoint pair of adjacent rows `(2j-1,2j)`, fire one O2 adsorption on the vertical vacant edge joining `(0,2j-1)` and `(0,2j)`. In the flat phase geometry the deposited O atoms in the left vacancy column have no neighboring CO and therefore survive. One such source occurrence occupies the left endpoint of two distinct original horizontal row-gap edges.

If `n` is even, `n/2` such disjoint vertical O2 marks occupy the left endpoint of every original horizontal anchor. If `n` is odd, `(n-1)/2` vertical marks cover the first `n-1` rows and one final horizontal O2 mark on the last row occupies its left endpoint. Therefore all original row-gap anchors can be destroyed in exactly

`ceil(n/2)`

source occurrences.

Hence the source-event distance to loss of this entire original anchor matching is exactly `ceil(n/2)` on the flat SOS ribbon.

This is a structural event-depth statement, not a claim that the whole phase separator has necessarily been destroyed at that time.

## 5. Universal reset from any surviving edge

The preceding theorem is useful because P02-A already proved a universal vacancy-edge carving nucleus.

Inherited exact lemma (`2026-09-20T035500Z__report.md`): if `x,y` are adjacent vacancies and `z` is any neighbor of `y` distinct from `x`, then, uniformly over arbitrary stable exterior chemistry, there is a legal adaptive source word of length at most two which makes `z` vacant while preserving the existing carved vacancy path. Consequently one vacant edge can carve any prescribed self-avoiding vacancy path with at most two source arrivals per new site.

The earlier vacancy bulldozer theorem additionally clears an arbitrary finite rectangle once a two-column vacancy workspace has been prepared.

These facts give a state-independent reset compiler.

### Theorem 5.1 — universal finite SOS reset

Fix a finite protected repair guard `G` large enough to contain:

1. the chosen `n`-row SOS window;
2. every site that may be changed by the finite dirty history under consideration;
3. a staging corridor and a rectangular rebuild box `R`;
4. one nearest-neighbor causal halo around all source words used below.

Suppose the current stable state in `G` contains at least one adjacent vacancy pair. Then there exists a finite source-valid adaptive word, uniformly over arbitrary stable chemistry elsewhere in `G`, which ends in an exact clean flat SOS packet inside `R`. By appending one horizontal O2 mark on a chosen local-minimum row, there is also a finite source-valid word ending in an exact clean **forward** SOS packet.

### Proof

**Step 1: move/grow the vacancy nucleus.** Starting from the available vacancy edge, use the inherited two-arrivals-per-added-site carving lemma to make a self-avoiding vacant path to the staging side of `R`. Extend the path in a snake through a two-column staging strip adjacent to `R`. All previously carved vacancies are preserved by the lemma.

**Step 2: erase the dirty chemistry.** The two-column staging strip is now a vacancy workspace. Apply the inherited vacancy bulldozer, row by row, to clear `R` completely to vacancies. The bulldozer is uniform over the arbitrary stable chemistry currently present in `R`; this is precisely why no second-order occupation-state classification is needed.

**Step 3: rebuild a clean phase packet.** Choose `R` with an even-width left phase slab, a two-column central gap, and a right phase slab. Starting from the all-vacant `R`, fill the left slab by O2 adsorptions on a fixed horizontal domino tiling. No CO has yet been installed, so all these O atoms survive. Next fill the right slab site-by-site by CO arrivals. The two vacant central columns separate the species, so these CO particles have no adjacent O and survive. The result is an exact flat member of the SOS family.

**Step 4: optional forward completion.** On any interior row of the rebuilt flat packet, the two central vacancies form a local-minimum row. The one-mark theorem from the preceding P02-A report applies: one horizontal O2 adsorption shifts that row forward by one and leaves an exact clean SOS state.

All steps use only legal source events in the original unstirred model. QED.

### Uniform finite word length and positive cylinder probability

Because `G` is finite, the construction above has a finite deterministic worst-case word length `L_G`. A crude bound can be read off directly: path/staging carving is linear in `|G|`, the bulldozer costs at most `4|R|`, and rebuilding costs at most `|R|`; after enlarging the guard once, one may take for example

`L_G <= 12 |G| + 1`.

The precise constant is unimportant; finiteness and uniformity are what matter.

At `p=1/2`, every desired CO clock has rate `1/2` and every desired O2 edge clock has rate `1/4`. In a guard with `A=|G|` sites, the total state-changing source-clock rate is at most `A`: CO contributes at most `A/2`, and the square lattice has fewer than `2A` undirected internal edges, so O2 contributes at most `A/2`.

When a desired deposited particle has several unlike neighbors, a favorable reaction partner has conditional probability at least `1/4`; an O2 occurrence needs at most two such choices. Hence an intentionally crude uniform lower bound for realizing one prescribed source/reaction step before any competing guarded source event is at least

`1/(64 A)`.

Therefore every state covered by Theorem 5.1 has a clean reset cylinder of probability at least

`rho_G := (64 A)^(-L_G) > 0`,

and a clean forward cylinder of at least `(64 A)^(-(L_G+1))`.

These bounds are deliberately crude but fully source-valid. The point is that the probability is uniform over **all** dirty states in the event-depth class, not that it is numerically large.

## 6. Linear-depth dirty-state closure theorem

Combine Theorems 3.1 and 5.1.

### Theorem 6.1 — finite-order SOS closure to depth `floor((n-1)/2)`

Fix a finite protected guard `G` for an `n`-row clean SOS seed. Let `D_{n,k}(G)` be the set of stable states reachable from the clean seed by at most `k` source occurrences whose reaction supports stay inside `G`.

For every

`k <= floor((n-1)/2)`,

every state in `D_{n,k}(G)` admits:

1. a finite exact source-valid clean SOS RETRY/reset word of length at most `L_G`;
2. a finite exact source-valid clean forward word of length at most `L_G+1`;
3. a uniform positive cylinder probability at least `rho_G` (respectively `rho_G/(64A)`) for those words.

No occupation-string enumeration is needed, and the statement includes all nonflat `|Delta h|=1,2` corner states and all reaction-choice branches.

P02-B's requested “second-order quotient” is now analytically obsolete as a **reachability** task. On `n=5` rows, second-order interruptions are covered automatically. More generally the certified dirty-order closure depth grows linearly:

## 7. A superexponential anchor-loss bound in short time

The event-depth theorem also gives a useful probability separation.

Take a flat `n`-row SOS ribbon in a fixed-width protected guard `G_n` with

`|G_n| <= C n`

for a fixed geometric constant `C`. At `p=1/2`, the total state-changing source-clock rate in the guard is at most `Cn`. Therefore the number `N_t` of guarded source occurrences by time `t` is stochastically dominated by `Pois(Cnt)`.

Complete loss of all original horizontal row anchors requires at least

`r_n := ceil(n/2)`

source occurrences. Hence, for

`t_n = theta/n`,

one has

`P(anchor matching lost by t_n)`

`<= P(Pois(C theta) >= r_n)`

`<= (e C theta / r_n)^(r_n)`                                      (7.1)

whenever `r_n > C theta`, by the standard Poisson Chernoff bound. Thus

`log P(anchor loss by theta/n)`

`<= -(1/2+o(1)) n log n`.                                         (7.2)

So anchor loss is superexponentially small in `n` on the `1/n` time scale.

By contrast, from the **initial flat clean ribbon**, the `n` horizontal O2 gap clocks are all exact one-mark clean forward clocks, with total rate `n/4`. If `Lambda_0<=Cn` is the full initial guarded source rate, then the probability that the first guarded source occurrence by time `theta/n` is one of these clean forward marks is at least

`int_0^(theta/n) (n/4) exp(-Cn s) ds`

`>= (theta/4) exp(-C theta)`.                                      (7.3)

The right-hand side is a positive constant independent of `n`.

Therefore the raw geometric ratio

`P(clean one-mark forward before any other guarded mark)`
`/ P(all original anchors lost by theta/n)`

diverges faster than exponentially with `n`.

This is a much stronger separation than the earlier fixed-width first-order bookkeeping. It is **not** yet `M_reg>0`, because histories with one or more nonforward marks but fewer than `r_n` marks are only proved *recoverable* by a positive-probability reset word; they have not yet been promoted to exact RETRY outcomes with a uniform pointwise `a>2f` or `a>63f` margin.

### Failed promotion attempt

It is tempting to call every state with a surviving vacancy edge a RETRY. That is **not valid** for the frozen metric: the retry seed class must carry the same protected-exterior quantifiers and a uniform attempt law. A state with only one fragile surviving edge need not have the same one-step success/fatal ratio as the clean `n`-row SOS seed.

Likewise, the tiny lower bound `rho_G` only proves a reset cylinder exists. Counting every failed reset-cylinder attempt as FATAL would generally destroy the coefficient-2, and certainly the coefficient-63, margin. Thus this run deliberately does not relabel positive reachability as positive regeneration.

This identifies the true remaining quantitative obstruction: **reset throughput under repeated competing marks**, not missing finite defect cases.

inside an `n`-row protected SOS packet. Theorem 3.1 supplies a hard floor on the rate at which `D_t` can be driven to zero in event count, while Theorem 5.1 supplies a uniform clean-reset cylinder from every state before that floor is exhausted.

The next nonduplicate target is to avoid treating failed reset cylinders pessimistically. Two promising precise routes are:

1. **Anchor-depth superharmonic potential.** Assign value `u(d)` to a dirty state according to a certified lower bound `d` on surviving anchor depth, use the fact that one source occurrence can consume at most two original anchors, and credit every successful local reset with return to the top depth. A finite number of source occurrences damages only finitely many cells, while untouched cells retain exact vacancy edges. Use the universal reset compiler cellwise and derive an M/M/1-type domination for the number of dirty cells. A negative drift for that defect count would promote the present reachability theorem to genuine same-class RETRY.
