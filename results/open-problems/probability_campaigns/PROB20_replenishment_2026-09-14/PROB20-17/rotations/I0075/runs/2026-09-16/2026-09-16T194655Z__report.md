## 3. B2 — attack the negation first: a periodic counterexample

### 3.1 Construction

Let the cities be all lattice points `Z^2`.

Start with the ordinary square-lattice network containing every horizontal and vertical unit segment.

For every pair `a,b in Z`, define the selected unit square

\[
Q_{a,b}=[3a,3a+1]\times[3b,3b+1].
\]

Modify the square lattice independently on each selected square:

1. delete all four boundary unit segments of `Q_{a,b}`;
2. insert the Steiner point
   \[
   c_{a,b}=(3a+\tfrac12,3b+\tfrac12);
   \]
3. join `c_{a,b}` by a straight segment to each of the four corners of `Q_{a,b}`.

Call the resulting infinite periodic Steiner network `N_*`.

The selected squares are edge-disjoint and separated with period `3` in both coordinate directions. Every deleted boundary pair remains connected through its square center, so the network remains connected. Every road is a straight segment. Hence `N_*` is a source-valid Steiner network on the square-grid city configuration.

### 3.2 Exact normalized length

The ordinary square lattice has length density `2`.

There is one selected unit square per `3 x 3` period cell, hence one selected square per area `9`.

For each selected square:

* removed length = `4`;
* each center-to-corner spoke has length `1/sqrt(2)=sqrt(2)/2`;
* four spokes add total length `2 sqrt(2)`.

Therefore

\[
\begin{aligned}
L(N_*)
&=2-\frac{4}{9}+\frac{2\sqrt2}{9}\\
&=\boxed{\frac{14+2\sqrt2}{9}}.
\end{aligned}
\]

Since `sqrt(2)<2`,

\[
\boxed{L(N_*)<2}.
\]

Numerically this is about `1.869825236...`, but the proof uses the exact algebraic expression.

The remaining and decisive obligation is the **full all-pairs stretch bound**, not a local cell test.

## 4. Full all-pairs stretch proof

I prove

\[
\boxed{
 r_{N_*}(p,q)\le \sqrt2\,\|p-q\|_2
 \quad\text{for every }p,q\in\mathbb Z^2.
}
\]

The proof has an analytic large-distance part and a finite exact core for the bounded residual range.

### 4.1 Local star metric

For any selected square, every pair of distinct corners can travel through its center in length

\[
\frac{\sqrt2}{2}+\frac{\sqrt2}{2}=\sqrt2.
\]

Thus, for city-to-city routing only, a selected square may be represented by a complete graph on its four corners whose six shortcut edges all have route-cost `sqrt(2)`. Each such shortcut is an actual two-spoke route in `N_*`; this is only a metric shorthand, not an added geometric road.

### 4.2 Three-step axial macro route

For every city `z`,

\[
r_{N_*}(z,z+(3,0))\le 2+\sqrt2.
\]

Indeed, along any three consecutive horizontal unit-grid steps there is at most one deleted edge: deleted horizontal edges have their left endpoint's `x`-coordinate divisible by `3`. If one of the three edges is deleted, replace that one unit step by the two-spoke route through the unique selected-square center, of length `sqrt(2)`. The other two unit edges remain.

By the same argument vertically,

\[
r_{N_*}(z,z+(0,3))\le2+\sqrt2.
\]

Reversing a route gives the same bounds for negative directions.

### 4.3 Three-by-three diagonal macro route

For every city `z`,

\[
r_{N_*}(z,z+(3,3))\le4+\sqrt2.
\]

Write `z=(x,y)`. Let `A` be the smallest multiple of `3` not smaller than `x`, and let `B` be the smallest multiple of `3` not smaller than `y`. Then

\[
0\le A-x\le2,\qquad0\le B-y\le2,
\]

and the selected square `[A,A+1] x [B,B+1]` lies inside the `3 x 3` rectangle from `(x,y)` to `(x+3,y+3)`.

Use this route:

1. move horizontally from `(x,y)` to `(A,y)`;
2. move vertically to `(A,B)`;
3. cross the selected square diagonally via its Steiner center, from `(A,B)` to `(A+1,B+1)`, at cost `sqrt(2)`;
4. move horizontally to `(x+3,B+1)`;
5. move vertically to `(x+3,y+3)`.

The first two portions use surviving unit edges because, before the first encountered multiple of `3`, no relevant edge-coordinate can be a deleted boundary coordinate. The last two portions similarly run from `A+1`/`B+1` toward the end of the same period interval and do not traverse the selected square's deleted boundary. The total number of surviving unit segments is

\[
(A-x)+(B-y)+(x+3-A-1)+(y+3-B-1)=4.
\]

Hence total route length is `4+sqrt(2)`.

The network is invariant under coordinate interchange and under the reflections `x -> 1-x`, `y -> 1-y` (together with its period-3 translations), so the same bound holds for all sign choices:

\[
r_{N_*}(z,z+(\pm3,\pm3))\le4+\sqrt2.
\]

### 4.4 Arbitrary displacement in `(3Z)^2`

Let

\[
u=(3X,3Y).
\]

Assume without loss of generality `|X| >= |Y|`. Concatenate `|Y|` diagonal macro moves in the required signs and then `|X|-|Y|` horizontal macro moves. Every macro move preserves the source residue class modulo `3`, so the preceding bounds can be reused at every step.

The route length is at most

\[
\begin{aligned}
&(4+\sqrt2)|Y|+(2+\sqrt2)(|X|-|Y|)\\
&=(2+\sqrt2)|X|+2|Y|.
\end{aligned}
\]

By Cauchy–Schwarz,

\[
(2+\sqrt2)|X|+2|Y|
\le
\sqrt{(2+\sqrt2)^2+4}\,\sqrt{X^2+Y^2}.
\]

Now

\[
(2+\sqrt2)^2+4=10+4\sqrt2<16,
\]

because `sqrt(2)<3/2`. Therefore

\[
r_{N_*}(z,z+u)
<4\sqrt{X^2+Y^2}
=\frac43\|u\|_2.
\]

So we have the uniform macro estimate

\[
\boxed{
r_{N_*}(z,z+u)\le\frac43\|u\|_2
\quad(u\in(3\mathbb Z)^2).
}
\]

### 4.5 Residual displacement of one cell

For an arbitrary integer displacement `d`, choose the componentwise nearest multiple-of-3 vector `u` so that

\[
d=u+e,
\qquad
u\in(3\mathbb Z)^2,
\qquad
e\in\{-1,0,1\}^2.
\]

Then

\[
\|e\|_2\le\sqrt2.
\]

I claim every such residual `e` can be routed with length at most `2`.

* If only one coordinate of `e` is nonzero, the desired adjacent city pair is joined either by its surviving unit edge (cost `1`) or, if that edge is one side of a selected square, through the corresponding star center (cost `sqrt(2)`).
* If both coordinates are nonzero, the two cities are opposite corners of one unit square. If that unit square is selected, the star gives cost `sqrt(2)`. If it is not selected, that nonselected unit square can share at most one boundary edge with the 3-periodic selected squares. Of the two L-shaped two-edge boundary routes between opposite corners, at least one therefore uses no deleted edge, and has cost exactly `2`.

Hence

\[
\boxed{r_{N_*}(z,z+e)\le2.}
\]

### 4.6 All displacements of Euclidean norm at least 49

Let `d=q-p`, `R=||d||_2`, and choose `u,e` as above. Concatenating the macro route and the residual route gives

\[
\begin{aligned}
r_{N_*}(p,q)
&\le \frac43\|u\|_2+2\\
&\le \frac43(R+\sqrt2)+2.
\end{aligned}
\]

For `R>=49`, this is at most `sqrt(2) R`. It is enough to check the endpoint `R=49`, because `sqrt(2)-4/3>0`. At `R=49`, the difference between the desired right side and this upper bound is

\[
49\sqrt2-\frac43(49+\sqrt2)-2
=\frac{143\sqrt2-202}{3}>0.
\]

The last inequality is exact because

\[
2\cdot143^2=40898>40804=202^2.
\]

Therefore

\[
\boxed{
r_{N_*}(p,q)\le\sqrt2\,\|p-q\|_2
\quad\text{whenever }\|p-q\|_2\ge49.
}
\]

### 4.7 Exact finite core for `0 < ||p-q||_2 < 49`

Only finitely many cases remain. Translation by `(3Z)^2` is a symmetry, so it is enough to check the nine source residues

\[
p\bmod3\in\{0,1,2\}^2.
\]

For each source residue, the exact certificate checks every nonzero integer displacement `d=(dx,dy)` with

Thus every produced route has exact cost

All algebraic comparisons are exact integer calculations in `Q(sqrt(2))`; no floating-point arithmetic is used. For example, to verify
