## 3. B16/B3 — a denser periodic star geometry

### 3.1 Construction of `N_8`

Cities are all lattice points `Z^2`.

Start with every horizontal and vertical unit segment of the square lattice. Select precisely the unit squares whose lower-left corners `(a,b)` satisfy

\[
\boxed{a+3b\equiv0\pmod 8.}
\]

For each selected square `[a,a+1] x [b,b+1]`:

1. delete its four boundary unit segments;
2. add the center `(a+1/2,b+1/2)`;
3. add the four straight center-to-corner spokes.

Call the resulting infinite network `N_8`.

Two selected squares cannot share a side. Indeed a horizontal side-neighbour changes `a+3b` by `±1` modulo `8`, and a vertical side-neighbour changes it by `±3`; none is `0`. Thus the deleted boundary edges are pairwise distinct.

The homomorphism

\[
(a,b)\longmapsto a+3b\pmod8
\]

from `Z^2` onto `Z/8Z` has an index-eight kernel, so selected squares have density exactly `1/8` per unit area.

Every deleted adjacent-city edge is replaced by a two-spoke path of length `sqrt(2)`, so the infinite network remains connected. It is a source-valid connected straight-segment Steiner network.

### 3.2 Exact normalized length

\[
