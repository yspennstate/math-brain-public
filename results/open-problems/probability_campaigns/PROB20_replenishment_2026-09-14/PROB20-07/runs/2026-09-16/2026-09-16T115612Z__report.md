\[

\[
P_{ij,\bullet}=a_0(1,1,1)+b_0Q_{ij,\bullet}.

In the unordered parent-pair order
\[

\[
Q^{(+)}
=
(e_1,e_1,e_2,e_2,e_3,e_3).
\tag{2.1}

After the simultaneous relabelling \(2\leftrightarrow3\), the archived \(-1\) tensor becomes
\[
\widetilde Q^{(-)}
=
(e_3,e_3,e_2,e_2,e_1,e_1).
\tag{2.2}

This relabelling is a conjugacy of the simplex dynamics and does not change regularity or the coefficient floor.

Now use the common centered chart
\[
u=x_1-x_3,\qquad
v=x_2-\frac13.
\tag{2.3}

Equivalently,
\[
x_1=\frac13-\frac v2+\frac u2,\qquad
x_2=\frac13+v,\qquad
x_3=\frac13-\frac v2-\frac u2.
\tag{2.4}

W^{(+)}_1=x_1^2+2x_1x_2,

W^{(+)}_2=2x_1x_3+x_2^2,

W^{(+)}_3=2x_2x_3+x_3^2.

\widetilde W^{(-)}_1=2x_2x_3+x_3^2,

\[
\widetilde W^{(-)}_2=2x_1x_3+x_2^2,

\widetilde W^{(-)}_3=x_1^2+2x_1x_2.

After restoring the endpoint baseline \(a_0\), exact substitution gives

F_+(u,v)=\bigl(\alpha(u,v),\beta(u,v)\bigr),

\tag{2.5}

## 3. The entire weak-endpoint edge is angular damping

For
\[
0\le\theta\le1,
\]
form the endpoint convex combination
\[
P_\theta
=
\theta P^{(+)}
+(1-\theta)\widetilde P^{(-)}.
\]
Put
\[
\kappa=2\theta-1\in[-1,1].
\]

Because the second centered component in (2.5) is common while the first has opposite sign, the exact centered map is
\[
\boxed{
H_\kappa(u,v)
=
\bigl(\kappa\alpha(u,v),\beta(u,v)\bigr).
}
\tag{3.1}
\]

No approximation is involved. The convex parameter \(\theta\) becomes a pure **angular damping factor** \(\kappa\) on the formerly neutral coordinate.

The common polynomial Lyapunov function from the archived endpoint proof is
\[
\boxed{
L(u,v)
=
\left(1+\frac32v\right)u^2+v^2.
}
\tag{3.2}
\]

For either endpoint map,
\[
L(F_\pm(u,v))<L(u,v)
\tag{3.3}
\]
at every nonzero state in the weak-endpoint image simplex.

Let
\[
A=\alpha(u,v),\qquad B=\beta(u,v).
\]
The endpoint image again lies in the strip
\[
-\frac14\le B\le\frac12,
\]
so
\[
1+\frac32B\ge\frac58>0.

Consequently
\[
L(H_\kappa(u,v))
=
\kappa^2\left(1+\frac32B\right)A^2+B^2
\le
\left(1+\frac32B\right)A^2+B^2

\tag{3.4}

## 4. A new exact bound for the nonlinear second component

From one iterate onward every operator in the triangle has coordinates at least \(1/12\). In the common chart this weak-endpoint image simplex is
\[
-\frac14\le v\le\frac12,
\qquad
|u|\le\frac12-v.
\tag{4.1}
\]

We prove the sharp-enough universal estimate
\[
\boxed{
\beta(u,v)^2
\le
\frac{81}{256}L(u,v)
}
\tag{4.2}
\]
throughout (4.1).

Set
\[
r=u^2,\qquad
0\le r\le R(v):=\left(\frac12-v\right)^2.
\]
Since
\[
\beta^2=\frac9{64}(r-3v^2)^2,
\]
inequality (4.2) is equivalent to
\[
F(r,v):=
9\left[\left(1+\frac32v\right)r+v^2\right]
-
4(r-3v^2)^2
\ge0.
\tag{4.3}
\]

For fixed \(v\),
\[
\frac{\partial^2F}{\partial r^2}=-8<0.
\]
Thus \(F\) is concave in \(r\), so its minimum on the interval
\[
0\le r\le R(v)
\]
occurs at an endpoint.

At \(r=0\),
\[
F(0,v)
=
-9v^2(2v-1)(2v+1)
=
9v^2(1-4v^2)
\ge0
\tag{4.4}
\]
because \(-1/4\le v\le1/2\).

At \(r=R(v)\),
\[
F(R(v),v)
=
\frac{(1-2v)
\left(
64v^3+42v^2+3v+16
\right)}8.
\tag{4.5}
\]
The factor \(1-2v\) is nonnegative. On the same interval,
\[
64v^3\ge-1,\qquad
42v^2\ge0,\qquad
3v\ge-\frac34,
\]
so
\[
64v^3+42v^2+3v+16
\ge
-1-\frac34+16
=
\frac{57}{4}>0.
\tag{4.6}
\]
Therefore (4.5) is nonnegative, proving (4.2).

The constant \(81/256\) is attained at the top vertex of the weak-endpoint image triangle:
\[
u=0,\qquad v=\frac12.
\]
Indeed there
\[
\beta=\frac9{32},\qquad
L=\frac14,
\]
so
\[
\frac{\beta^2}{L}
=
\frac{81}{256}.
\]
Thus the auxiliary estimate itself is sharp on the truncated state domain.

## 5. Explicit geometric contraction on the weak-floor edge

Define
\[
C=
\left(1+\frac32B\right)A^2\ge0.
\]
Then
\[
L(F_+)=C+B^2,
\]
and
\[
L(H_\kappa)
=
\kappa^2C+B^2
=
\kappa^2L(F_+)+(1-\kappa^2)B^2.
\tag{5.1}
\]

Using the archived endpoint Lyapunov inequality
\[
L(F_+)\le L(u,v)
\]
and the new bound (4.2),
\[
\begin{aligned}
L(H_\kappa(u,v))
&\le
\kappa^2L(u,v)
+
(1-\kappa^2)\frac{81}{256}L(u,v)\\
&=
q_{\rm edge}(\kappa)L(u,v),
\end{aligned}
\]
where
\[
\boxed{
q_{\rm edge}(\kappa)
=
\frac{81+175\kappa^2}{256}.
}
\tag{5.2}
\]

Moreover
\[
1-q_{\rm edge}(\kappa)
=
\frac{175}{256}(1-\kappa^2).
\tag{5.3}
\]
Hence
\[
\boxed{
|\kappa|<1
\Longrightarrow
q_{\rm edge}(\kappa)<1.
}
\tag{5.4}
\]

Therefore every interior point of the edge joining the two aligned neutral tensors is **globally geometrically regular**, even though its coefficient floor is still exactly \(1/12\).

At the two edge endpoints \(\kappa=\pm1\), \(q_{\rm edge}=1\), and the preceding checkpoint's strict quartic decrement supplies global asymptotic convergence.

This is a new phenomenon relative to the preceding ray theorem: geometric damping can arise at the weak coefficient floor itself from convex interpolation of the two opposite neutral directions.

## 6. Adding barycentric noise: the full convex triangle

Let \(U\) be the constant barycentric QSO. For
\[
0\le\lambda\le1
\]
define
\[
P_{\lambda,\theta}
=
(1-\lambda)U+\lambda P_\theta.

In centered coordinates \(U\) is exactly the zero map. Therefore
\[
\boxed{
G_{\lambda,\kappa}(u,v)
=
\lambda H_\kappa(u,v)
=
\lambda\bigl(\kappa\alpha(u,v),\beta(u,v)\bigr).
}
\tag{6.1}
\]

The radial estimate from the immediately preceding checkpoint applies to every point in the endpoint output strip:
\[
L(\lambda y)
\le
q_{\rm rad}(\lambda)L(y),
\tag{6.2}
\]
where
\[
\boxed{
q_{\rm rad}(\lambda)
=
\frac{\lambda^2(8-3\lambda)}5.
}
\tag{6.3}
\]
For
\[
0\le\lambda<1,
\]
\[
q_{\rm rad}(\lambda)<1,
\]
while
\[
q_{\rm rad}(1)=1.
\]

Combining (5.2) and (6.2), for every iterate from time \(1\) onward,
\[
\boxed{
L(z_{n+1})
\le
Q(\lambda,\kappa)L(z_n),
}
\tag{6.4}
\]
with
\[
\boxed{
Q(\lambda,\kappa)
=
\frac{\lambda^2(8-3\lambda)}5

\frac{81+175\kappa^2}{256}.

\tag{6.5}

If
\[
(\lambda,|\kappa|)\ne(1,1),

then at least one factor is strictly below one, hence
\[
\boxed{Q(\lambda,\kappa)<1.}
\tag{6.6}

Therefore
\[
L(z_n)
\le
Q(\lambda,\kappa)^{n-1}L(z_1),

\tag{6.7}

and because \(L\) is positive definite on the forward strip,
\[

Thus the original simplex trajectory converges to

At the two exceptional neutral vertices
\[
(\lambda,\kappa)=(1,\pm1),

the archived endpoint theorem gives strict monotone Lyapunov decay and therefore global asymptotic convergence as well.

Hence every point of the closed convex triangle
\[
\operatorname{conv}
\left\{

is globally regular.

## 8. Interpretation for the sharp-threshold problem

The preceding run controlled only the two line segments
\[
[U,P^{(+)}],
\qquad
[U,\widetilde P^{(-)}].
\]
This run fills in the entire convex region between them.

The new angular parameter has a clear dynamical meaning:
\[
\kappa=2\theta-1.
\]
The two neutral endpoint tensors push the same nonlinear \(v\)-coordinate but opposite \(u\)-directions. Convex interpolation therefore cancels part of the dangerous neutral direction without changing the second component. The exact bound
\[
\beta^2\le\frac{81}{256}L
\]
then converts that cancellation into a uniform geometric rate.

This also sharpens the endpoint bifurcation picture. The \(-1\) tensor is the endpoint of the explicit sub-\(1/12\) two-cycle family. At the vertex itself the cycle has collapsed and convergence is quartically damped. Moving along the weak-floor edge toward the \(+1\) tensor immediately creates a quadratic/geometric damping factor
\[
q_{\rm edge}(\kappa)<1.
\]
Moving inward toward the barycentric operator creates the independent radial damping factor
\[
q_{\rm rad}(\lambda)<1.
\]

Thus a substantial two-dimensional region through the two only real-neutral endpoint equality mechanisms is globally regular. The dangerous strict-floor obstruction, if it exists, must leave this triangle and exploit genuinely different non-radial tensor directions.

This still does **not** prove
\[
\alpha_3=\frac1{12}.
\]
The full coefficient polytope has many more dimensions, and a general admissible perturbation does not preserve the common normal form (6.1). Higher-period and aperiodic recurrent sets remain unexcluded in the unrestricted family.

The global rigorous bracket therefore remains
\[
\boxed{\frac1{12}\le\alpha_3\le\frac19}.
\]

## 10. Failed/limited routes retained

\[
F_+=(\alpha,\beta),
\qquad
F_-=(-\alpha,\beta).

A generic perturbation changes both components and also shifts the fixed point. Therefore the same angular factorization does not survive in an arbitrary tensor-space neighborhood.

The older raw one-step/two-step Fisher contraction route remains insufficient, as archived earlier; the present theorem should not be interpreted as a universal metric contraction for all strict-floor QSOs.

\[

\]
for a hypothetical non-singleton endpoint omega-limit set remains a localization theorem, not a convergence theorem by itself.

## 11. Next proof obligation

The natural next step is now more precise than the previous "open neighborhood" target.

Write a general endpoint/strict-floor tensor near the neutral triangle as
\[
P=P_{\lambda,\theta}+E,
\]
translate coordinates to the actual unique fixed point, and decompose the centered map as
\[
G_{\lambda,\kappa}
+
\mathcal E_E.
\]

The triangle theorem supplies two independent coercive mechanisms:

1. **radial damping**
   \[
   1-q_{\rm rad}(\lambda),
   \]
   generated by moving above the \(1/12\) coefficient floor;
2. **angular damping**
   \[
   1-q_{\rm edge}(\kappa)
   =
   \frac{175}{256}(1-\kappa^2),
   \]
   generated by cancellation between the \(+1\) and \(-1\) neutral directions.

A useful neighborhood theorem would bound the perturbation error in the same Lyapunov function:
\[
|\Delta_E L|
\le
C\|E\|\,L
+
\text{higher-order terms},
\]
and then compare it against the explicit combined margin
\[
1-Q(\lambda,\kappa).
\]

Away from the two neutral vertices this should give a genuine open region by compactness and explicit quantitative margin. The genuinely delicate remaining pieces are shrinking neighborhoods of the two vertices where the margin degenerates and the archived quartic endpoint decrement must be combined with the one-sided coefficient-floor constraints.

That is the next high-value route. In parallel, the existing TV \(<1/2\) recurrence localization can be used to restrict any possible nonlocal obstruction before applying such a neighborhood argument.
