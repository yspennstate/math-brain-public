## 3. Uniform perturbation bounds in coefficient sup norm

Let \(P_0=P_{\lambda,\kappa}\) be a base tensor in \(\mathcal T_\eta\), and let \(P\) be another symmetric stochastic tensor satisfying
\[
P_{ij,k}\ge\frac1{12}
\]
and
\[
\|P-P_0\|_\infty\le\varepsilon.
\]
Write
\[
E=P-P_0.
\]

For any simplex state \(x\),
\[
(V_P(x)-V_{P_0}(x))_k
=
\sum_{i,j}E_{ij,k}x_ix_j.
\]
Since \(\sum_{i,j}x_ix_j=1\),
\[
\boxed{
|(V_P-V_{P_0})_k(x)|\le\varepsilon.
}
\tag{3.1}
\]

In the centered chart, if
\[
\Delta u=(V_P)_1-(V_P)_3-[(V_{P_0})_1-(V_{P_0})_3],
\]
\[
\Delta v=(V_P)_2-(V_{P_0})_2,
\]
then
\[
\boxed{|\Delta u|\le2\varepsilon,\qquad |\Delta v|\le\varepsilon.}
\tag{3.2}
\]

Because both \(P\) and \(P_0\) have coefficient floor at least \(1/12\), both outputs lie in the truncated simplex
\[
\frac1{12}\le x_k\le\frac56.
\]
Hence along the segment joining the two outputs,
\[
|u|\le\frac34,
\qquad
-\frac14\le v\le\frac12.
\tag{3.3}
\]

On this region,
\[
\left|\frac{\partial L}{\partial u}\right|
=2|u|\left|1+\frac32v\right|
\le
2\cdot\frac34\cdot\frac74
=
\frac{21}{8},
\tag{3.4}
\]
and
\[
\left|\frac{\partial L}{\partial v}\right|
=\left|\frac32u^2+2v\right|
\le
\frac{59}{32}.
\tag{3.5}
\]
Therefore the mean-value theorem and (3.2) give the explicit global perturbation estimate
\[
\boxed{
|L(V_P(x))-L(V_{P_0}(x))|
\le
\frac{227}{32}\varepsilon.
}
\tag{3.6}
\]
The constant is simply
\[
2\cdot\frac{21}{8}+\frac{59}{32}=rac{227}{32}.
\]

We also need a derivative bound. Since \(E\) is symmetric in the parent indices,
\[
\frac{\partial}{\partial x_\ell}
\sum_{i,j}E_{ij,k}x_ix_j
=
2\sum_jE_{\ell j,k}x_j,
\]
so
\[
\left|
\frac{\partial (V_P-V_{P_0})_k}{\partial x_\ell}
\right|
\le2\varepsilon.
\tag{3.7}
\]
Using
\[
\frac{\partial x}{\partial u}
=\left(\frac12,0,-\frac12\right),
\qquad
\frac{\partial x}{\partial v}
=\left(-\frac12,1,-\frac12\right),
\]
we obtain, for each output coordinate,
\[
|\partial_u\Delta V_k|\le2\varepsilon,
\qquad
|\partial_v\Delta V_k|\le4\varepsilon.
\]
Thus the centered perturbation \(h=G_P-G_{P_0}\) satisfies
\[
|\partial_u h_u|\le4\varepsilon,
\qquad
|\partial_v h_u|\le8\varepsilon,
\]
\[
|\partial_u h_v|\le2\varepsilon,
\qquad
|\partial_v h_v|\le4\varepsilon.
\]
Hence, in the induced \(\ell^\infty\) operator norm,
\[
\boxed{
\|Dh\|_\infty\le12\varepsilon.
}
\tag{3.8}
\]
At the barycentre itself,
\[
\boxed{
\|G_P(0,0)\|_\infty\le2\varepsilon.
}
\tag{3.9}
\]

## 4. A uniform local contraction box

The Jacobian of the base map (2.1) is
\[
DG_{\lambda,\kappa}(u,v)
=
\begin{pmatrix}
\lambda\kappa(1+3v/4) & 3\lambda\kappa u/4\\
-3\lambda u/4 & 9\lambda v/4
\end{pmatrix}.
\tag{4.1}
\]

On the box
\[
\mathcal B_R:=\{(u,v):|u|\le R,\ |v|\le R\},
\]
the first row sum is bounded by
\[
|\lambda\kappa|\left(1+\frac32R\right),
\tag{4.2}
\]
and the second row sum by
\[
3R.
\tag{4.3}
\]

For a base point in \(\mathcal T_\eta\), (2.7) gives \(|\lambda\kappa|\le1-\eta\). Set
\[
R_\eta
:=
\min\left\{\frac18,\frac\eta3\right\}.
\tag{4.4}
\]
Then
\[
(1-\eta)\left(1+\frac32R_\eta\right)
\le
(1-\eta)\left(1+\frac\eta2\right)
=
1-\frac\eta2-\frac{\eta^2}{2}
\le
1-\frac\eta2,
\tag{4.5}
\]
while
\[
3R_\eta\le\frac38\le1-\frac\eta2.
\tag{4.6}
\]
Thus
\[
\boxed{
\|DG_{P_0}\|_\infty
\le
1-\frac\eta2
\quad\text{on }\mathcal B_{R_\eta}.
}
\tag{4.7}
\]

If
\[
\varepsilon\le\frac\eta{48},
\tag{4.8}
\]
then by (3.8)
\[
\|DG_P\|_\infty
\le
1-\frac\eta2+12\varepsilon
\le
1-\frac\eta4
<1
\tag{4.9}
\]
throughout the same box.

If in addition
\[
\varepsilon\le\frac{\eta R_\eta}{8},
\tag{4.10}
\]
then for every \(z\in\mathcal B_{R_\eta}\), using (3.9),
\[
\begin{aligned}
\|G_P(z)\|_\infty
&\le
\|G_P(z)-G_P(0)\|_\infty+\|G_P(0)\|_\infty\\
&\le
\left(1-\frac\eta4\right)R_\eta+2\varepsilon\\
&\le R_\eta.
\end{aligned}
\tag{4.11}
\]
So \(G_P\) maps \(\mathcal B_{R_\eta}\) into itself and is a strict contraction there.

By the Banach fixed-point theorem, \(P\) has a unique fixed point inside this box, and every orbit that enters the box converges geometrically to that fixed point. This local conclusion is obtained directly; no separate continuity-of-fixed-points or spectral-perturbation theorem is needed.

## 5. Global Lyapunov entry into the contraction box

Set
\[
r_\eta:=\frac58R_\eta^2.
\tag{5.1}
\]
By (2.3),
\[
L(u,v)<r_\eta
\]
implies
\[
|u|<R_\eta,
\qquad
|v|<R_\eta,
\]
so the strict sublevel set \(\{L<r_\eta\}\) is contained in the local contraction box.

Now take any state in the weak-endpoint image simplex with
\[
L(u,v)\ge r_\eta.
\]
For the base map,
\[
L(V_{P_0}(x))
\le
q_\eta L(x).
\]
Using the perturbation estimate (3.6),
\[
L(V_P(x))
\le
q_\eta L(x)+\frac{227}{32}\varepsilon.
\tag{5.2}
\]
Therefore
\[
L(V_P(x))-L(x)
\le
-(1-q_\eta)r_\eta+rac{227}{32}\varepsilon.
\tag{5.3}
\]

If
\[
\varepsilon
\le
\frac{(1-q_\eta)r_\eta}{2(227/32)}
=
\boxed{
\frac{10(1-q_\eta)R_\eta^2}{227}
},
\tag{5.4}
\]
then every iterate outside the local sublevel set loses at least the fixed amount
\[
\frac12(1-q_\eta)r_\eta>0
\tag{5.5}
\]
of Lyapunov value.

Because \(P\) has coefficient floor at least \(1/12\), the first iterate of **every** simplex point, including every boundary point, lies in the weak-endpoint image simplex. From then on, either the orbit enters \(\{L<r_\eta\}\), or (5.5) forces \(L\) to decrease by the same positive amount forever, which is impossible because \(L\ge0\).

Hence every trajectory enters \(\{L<r_\eta\}\subset\mathcal B_{R_\eta}\) after finitely many steps. By Section 4 it then converges to the unique Banach fixed point in the box.

This proves global regularity.

Combining (4.8), (4.10), and (5.4) gives exactly
\[
\boxed{
\varepsilon_\eta
=
\min\left\{
\frac\eta{48},
\frac{\eta R_\eta}{8},
\frac{10(1-q_\eta)R_\eta^2}{227}
\right\}.
}
\tag{5.6}
\]

## 6. Consequences for the parameter geometry

### 6.1 Genuine full-dimensional neighborhoods away from the neutral vertices

The preceding triangle theorem controlled only a two-dimensional affine slice of the heredity-tensor polytope. The new theorem is different: the perturbation \(E\) is arbitrary subject only to symmetry, stochasticity, the coefficient floor, and a coefficient-sup-norm bound. Therefore every compact trimmed region \(\mathcal T_\eta\) has a positive-radius **full-dimensional relative neighborhood** inside the endpoint admissible polytope consisting entirely of globally regular QSOs.

This rules out endpoint counterexamples in an actual tube around the previously classified real-neutral mechanisms, except possibly in neighborhoods shrinking onto the two neutral vertices themselves.

### 6.2 Ordinary open neighborhoods for strict-floor base points

If \(\lambda\le1-\eta\), then the exact triangle floor is
\[
a(\lambda)=\frac13-\frac\lambda4
\ge
\frac1{12}+\frac\eta4.
\tag{6.1}
\]
Since
\[
\varepsilon_\eta\le\frac\eta{48}<\frac\eta4,
\]
any stochastic tensor within this coefficient radius automatically still has coefficients strictly above \(1/12\). Thus, for the strictly interior radial part of the triangle, the theorem gives an ordinary open neighborhood in the full QSO parameter space, not merely a one-sided endpoint-relative neighborhood.

### 6.3 Endpoint edge interior

For \(\lambda=1\) and \(|\kappa|\le1-\eta\), the base tensor lies exactly on the weak coefficient floor \(1/12\), so arbitrary two-sided perturbation would leave the admissible endpoint polytope. The theorem nevertheless gives a full-dimensional **one-sided** relative neighborhood within \(P_{ij,k}\ge1/12\).

This is precisely the kind of one-sided robustness that the previous checkpoint identified as the next important target.

## 8. What this does and does not solve

This is a strict expansion over the preceding result. The previous theorem established exact global regularity *on* the neutral triangle. The new theorem establishes global regularity on a genuine positive-thickness tensor-space tube around every trimmed portion of that triangle.

The endpoint difficulty is now concentrated still more sharply. A hypothetical weak-endpoint counterexample approaching either classified real-neutral mechanism must approach one of the two exact neutral vertices themselves; it cannot approach an interior point of the neutral edge or any compact subset of the triangle away from those vertices.

The unrestricted problem nevertheless remains open. The explicit radius \(\varepsilon_\eta\) shrinks to zero as \(\eta\downarrow0\), exactly where the neutral multipliers approach \(\pm1\) and the base Lyapunov damping becomes quartic rather than geometric. The remaining hard local/global interface is therefore a one-sided perturbation theorem **at the two neutral vertices themselves**.

The natural next calculation is now very specific. Write
\[
P=P^{(\pm)}+E,
\qquad
E_{ij,k}\ge0\ \text{on every endpoint coefficient equal to }1/12,
\]
with compensating negative perturbations only on the corresponding large coefficients forced by row stochasticity. Translate to the actual perturbed fixed point and expand the archived endpoint Lyapunov decrement. One must determine whether the one-sided sign constraints force the first nonzero quadratic/cubic perturbative correction in the neutral direction to be contracting. If yes, the explicit tube theorem proved here can be glued to those two vertex neighborhoods and would remove the entire real-neutral endpoint obstruction from the full parameter polytope.

Even that would not automatically close \(\alpha_3=1/12\): a genuinely nonlocal recurrent set far from the classified neutral mechanisms could remain. But the cumulative endpoint facts now include fixed-point uniqueness, no nontrivial period two, full fixed-point spectral stability except the globally controlled real-neutral equalities, TV diameter \(<1/2\) for every non-singleton omega-limit set, exact global regularity on the neutral triangle, and now full-dimensional robust regularity around every trimmed portion of that triangle.

The rigorous unrestricted bracket remains
\[
\boxed{\frac1{12}\le\alpha_3\le\frac19}.
\]
