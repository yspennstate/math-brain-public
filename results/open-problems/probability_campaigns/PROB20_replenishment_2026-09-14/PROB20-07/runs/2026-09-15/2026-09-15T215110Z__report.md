# 3. Endpoint channel formulation

\[
a:=\frac1{12},
\qquad
b:=1-3a=\frac34,
\]

because any heredity tensor with `P_{ij,k}>=1/12` decomposes as

\[
P_{ij,\bullet}=a(1,1,1)+bQ_{ij,\bullet}
\]

with stochastic residual rows `Q_{ij,bullet}`.

For a state `z`, write the unordered iid-parent law

\[
U(z)=
(z_1^2,2z_1z_2,2z_1z_3,z_2^2,2z_2z_3,z_3^2).
\]

If `x,y` form a 2-cycle, one common residual stochastic channel satisfies

\[
U(x)Q=A_*:=\frac{y-a\mathbf1}{b},

U(y)Q=B_*:=\frac{x-a\mathbf1}{b}.

Therefore for every `lambda>=0`,

\[
\boxed{
\sum_k(B_{*,k}-\lambda A_{*,k})_+
\le
\sum_r(U_r(y)-\lambda U_r(x))_+.
}
\tag{3.1}
\]

This is the exact binary relative-majorization stop-loss condition proved in the `135950Z` checkpoint.
