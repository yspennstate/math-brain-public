# 3. Endpoint channel formulation

It suffices to work at the weak endpoint floor

\[
a:=\frac1{12},\qquad b:=1-3a=\frac34,
\]

because any QSO with all coefficients `>=1/12` admits the decomposition

\[
P_{ij,\bullet}=a(1,1,1)+bQ_{ij,\bullet}
\]

with stochastic residual rows `Q_{ij,bullet}`.

For a state `z`, define the unordered iid-parent law

\[
U(z)=(z_1^2,2z_1z_2,2z_1z_3,z_2^2,2z_2z_3,z_3^2).
\]

If `x,y` form a two-cycle, one common stochastic residual channel satisfies

\[
U(x)Q=A_*:=\frac{y-a\mathbf1}{b},
\qquad
U(y)Q=B_*:=\frac{x-a\mathbf1}{b}.
\]

Hence for every `lambda>=0`,

\[
\boxed{
\sum_k(B_{*,k}-\lambda A_{*,k})_+
\le
\sum_r(U_r(y)-\lambda U_r(x))_+.
}
\tag{3.1}
\]

This is the exact stop-loss / binary relative-majorization necessity archived in the `135950Z` checkpoint.

# 4. Chamber A and a useful exact parameterization

By the previous checkpoint, every remaining nontrivial two-cycle changes all three coordinates. Orient the phase and relabel so

\[
X:=x_1>Y:=y_1,
\]

and both other coordinates increase, with

\[
r_1:=\frac YX<1<r_2:=\frac{y_2}{x_2}\le r_3:=\frac{y_3}{x_3}.
\]

Put

\[
u:=X-Y>0,
\qquad
S:=X+Y,
\qquad
P:=XY,
\qquad
C:=1-S.
\]

The preceding report already proves

\[
S\le\frac23.
\tag{4.1}
\]

We now assume chamber A,

\[
r_1r_3\le1.
\tag{4.2}
\]

Because `r_1r_2<=r_1r_3`, both mixed products are nonincreasing.

Let

\[
t:=\frac{y_2-x_2}{u}\in(0,1).
\]

Define

\[
m:=x_2-Yt,
\qquad
n:=x_3-Y(1-t).
\]

The mixed-product inequalities are exactly

\[
m\ge0,\qquad n\ge0,
\]

and because the coordinates sum to one,

\[
m+n=C.
\]

Since `r_2<=r_3`, exact cross multiplication gives

\[
tC\le m.
\]

Now set

\[
A:=\frac mt,
\qquad
B:=\frac n{1-t}.
\]

Then

\[
\boxed{A\ge C\ge B\ge0}
\tag{4.3}
\]

and

\[
\boxed{tA+(1-t)B=C.}
\tag{4.4}
\]

The two cycle points become

\[
\boxed{
\begin{aligned}
x_2&=t(A+Y),& y_2&=t(A+X),\\
x_3&=(1-t)(B+Y),& y_3&=(1-t)(B+X),
\end{aligned}
}
\tag{4.5}
\]

so

\[
\boxed{
r_2=\frac{A+X}{A+Y},\qquad
r_3=\frac{B+X}{B+Y}.}
\tag{4.6}
\]

This parameterization is exact for chamber A and is the key simplification in this run.

# 6. The `lambda=r_2^2` inequality forces an enormous lower bound on `A`

Take

\[
\lambda=r_2^2>1.
\]

In chamber A, all likelihood ratios involving parent type 1 are at most one, and the `22` atom is exactly at the breakpoint. Therefore the only strictly positive source contributions are `23` and `33`.

Using (4.4) to eliminate `B,t`, exact algebra gives

\[
\sum_r(U_r(y)-r_2^2U_r(x))_+
=
\frac{u(A-C)}{(A+Y)^2}
\left[A(2-S)+2P+SC\right].
\tag{6.1}
\]

The decreasing target coordinate contributes

\[
(X-a)-r_2^2(Y-a)
=
\frac{u}{(A+Y)^2}
\left(A^2+2aA-P+aS\right).
\tag{6.2}
\]

The bracket in (6.2) is strictly positive on the chamber-A domain. Indeed `A>=C`, `P<=S^2/4`, and

\[
C^2+\frac C6-\frac{S^2}{4}+\frac S{12}
=
\frac{(S-2)(9S-7)}{12}>0
\]

for `S<=2/3`. Hence this target atom is active.

Applying (3.1) and multiplying away the positive common factor gives the exact necessary inequality

\[
\frac34(A-C)
\left[A(2-S)+2P+SC\right]
\ge
A^2+\frac A6-P+\frac S{12}.
\tag{6.3}
\]

Now relax only by `P<=S^2/4`. This increases the left side and decreases the right side, so a necessary weaker inequality is

\[
\frac34(A-C)
\left[A(2-S)+\frac{S^2}{2}+SC\right]
\ge
A^2+\frac A6-\frac{S^2}{4}+\frac S{12}.
\tag{6.4}
\]

The left-minus-right side factors exactly:

\[
-\frac{(2A+S)
\left(9AS-6A+9S^2-33S+20\right)}{24}.
\tag{6.5}
\]

At `S=2/3`, the second factor equals `2>0`, so (6.4) is impossible. Therefore any candidate has

\[
S<\frac23.
\tag{6.6}
\]

Since `2A+S>0` and `6-9S>0`, equations (6.4)–(6.5) force

\[
\boxed{
A\ge L(S):=
\frac{9S^2-33S+20}{6-9S}.
}
\tag{6.7}
\]

This lower bound is already very strong: `L(1/3)=10/3` and it diverges as `S\uparrow2/3`.

# 7. The `lambda=r_2r_3` inequality gives the opposite bound

Now take

\[
\lambda=r_2r_3>1.
\]

At this breakpoint the only source likelihood ratio strictly above `lambda` is `r_3^2`, so only the `33` source atom contributes. Using (4.4), exact algebra gives

\[
\sum_r(U_r(y)-r_2r_3U_r(x))_+
=
\frac{u(A-C)^2(B+X)}{(A-B)(A+Y)}.
\tag{7.1}
\]

The decreasing target coordinate has numerator

\[
(X-a)-r_2r_3(Y-a)
=
\frac{uN}{(A+Y)(B+Y)},
\tag{7.2}
\]

where

\[
N:=AB+a(A+B+S)-P.
\tag{7.3}
\]

We first check that this target atom is indeed active. Since `B>=0`,

\[
N\ge aA+aS-P.
\]

Using (6.7) and `P<=S^2/4`,

\[
N\ge aL(S)+aS-\frac{S^2}{4}.
\]

The last quantity equals

\[
-\frac{27S^3-18S^2-27S+20}{36(3S-2)}.
\tag{7.4}
\]

On `1/3<=S<2/3`, the denominator is negative while the cubic numerator is positive (it decreases on this interval and equals `10` at `1/3` and `2` at `2/3`). Thus (7.4) is positive, so

\[
N>0.
\tag{7.5}
\]

Applying (3.1) at `lambda=r_2r_3`, multiplying away positive denominators, and writing

\[
K:=(B+X)(B+Y)=B^2+BS+P,
\]

gives

\[
\frac34(A-C)^2K\ge(A-B)N.
\tag{7.6}
\]

Since `B<=C<=A`,

\[
\frac{(A-C)^2}{A-B}\le A-C.
\]

Therefore (7.6) implies the weaker necessary inequality

\[
\frac34K(A-C)
\ge
A(B+a)+a(B+S)-P.
\]

Equivalently,

\[
\boxed{AH\ge J,}
\tag{7.7}
\]

where

\[
H:=\frac34K-B-a,
\qquad
J:=\frac34KC+a(B+S)-P.
\tag{7.8}
\]

---

# 8. `H<0` throughout the chamber-A domain

Because `P<=S^2/4`,

\[
H
\le
h(B,S):=
\frac34\left(B^2+BS+\frac{S^2}{4}\right)-B-\frac1{12}.
\tag{8.1}
\]

For fixed `S`, `h` is convex in `B`, so its maximum on `0<=B<=C=1-S` is attained at an endpoint. Exact evaluation gives

\[
h(0,S)=\frac{9S^2-4}{48}<0
\quad(S<2/3),
\tag{8.2}
\]

and

\[
h(1-S,S)=\frac{9S^2+12S-16}{48}<0
\quad(1/3<=S<=2/3).
\tag{8.3}
\]

Therefore

\[
\boxed{H<0.}
\tag{8.4}
\]

# 9. Exact contradiction with the lower bound `A>=L(S)`

From (6.7),

\[
A\ge L(S).
\]

Since `H<0`, this implies

\[
AH\le L(S)H.
\tag{9.1}
\]

But (7.7) requires

\[
J\le AH.
\tag{9.2}
\]

Thus feasibility would force

\[
J\le L(S)H.
\tag{9.3}
\]

We now prove the strict opposite inequality.

A direct exact simplification yields

\[
J-L(S)H
=
\frac{\mathcal N(B,S,P)}{36(2-3S)},
\tag{9.4}
\]

where

\[
\begin{aligned}
\mathcal N
={}&(162S-126)B^2
+(270S^2-531S+246)B\\
&+(270S-198)P
+20-27S.
\end{aligned}
\tag{9.5}
\]

On `1/3<=S<2/3`, the coefficient `270S-198` is negative. Hence `mathcal N` is minimized, for fixed `B,S`, by the maximal possible

\[
P=\frac{S^2}{4}.
\]

After this substitution, `mathcal N` is a concave quadratic in `B` because

\[
162S-126<0.
\]

Therefore its minimum on `0<=B<=1-S` is attained at one of the two endpoints. Exact endpoint factorizations are

\[
\mathcal N\left(0,S,\frac{S^2}{4}\right)
=
\frac{(3S-2)(45S^2-3S-20)}{2}>0,
\tag{9.6}
\]

because both factors are negative on `1/3<=S<2/3`, and

\[
\mathcal N\left(1-S,S,\frac{S^2}{4}\right)
=
-\frac{(9S-7)(9S^2-60S+40)}{2}>0.
\tag{9.7}
\]

Here `9S-7<0`, while the quadratic `9S^2-60S+40` is decreasing on the interval and still equals `4>0` at `S=2/3`.

Hence

\[
\mathcal N(B,S,P)>0
\]

throughout the chamber-A domain. Since `2-3S>0`, (9.4) gives

\[
\boxed{J-L(S)H>0.}
\tag{9.8}
\]

This contradicts (9.3).

Therefore chamber A is impossible.

\[
\boxed{
P_{ij,k}\ge\frac1{12},\ x\leftrightarrow y\text{ nontrivial fully three-coordinate 2-cycle}
\Longrightarrow
r_1r_3>1.
}
\tag{9.9}
\]

Combining with the previous run's exclusion of `r_1r_2>1`, the only surviving likelihood-ratio chamber is

\[
\boxed{r_1r_2\le1<r_1r_3.}
\tag{9.10}
\]

Together with the previous `lambda=1` / `lambda=r_1` argument,

\[
\boxed{X+Y\le\frac23.}
\tag{9.11}
\]
