# 3. Exact reduction of a prescribed two-cycle to relative majorization

Fix a floor

\[
0\le a<\frac13,
\qquad b:=1-3a>0.
\]

Let `x,y` be two probability vectors with every coordinate at least `a`.

For a probability vector `z=(z_1,z_2,z_3)`, define its **unordered iid-pair distribution** on the six parent categories

\[
\mathcal P:=\{11,12,13,22,23,33\}
\]

by

\[
U(z)=\bigl(z_1^2,\ 2z_1z_2,\ 2z_1z_3,\ z_2^2,\ 2z_2z_3,\ z_3^2\bigr).
\]

Also define the floor-stripped child distributions

\[
C_a(y):=\frac{y-a\mathbf1}{b},
\qquad
D_a(x):=\frac{x-a\mathbf1}{b}.
\]

These are probability vectors whenever `x_i,y_i>=a`.

## Theorem 3.1 — exact prescribed-cycle criterion

There exists a three-type QSO with symmetric heredity coefficients satisfying

\[
P_{ij,k}\ge a\qquad\forall i,j,k
\]

and

\[
V(x)=y,
\qquad
V(y)=x
\]

**if and only if** there exists one `6 x 3` row-stochastic matrix `Q` such that

\[
\boxed{
U(x)Q=C_a(y),
\qquad
U(y)Q=D_a(x).
}
\tag{3.1}
\]

Equivalently, the binary experiment `(U(x),U(y))` relatively majorizes `(C_a(y),D_a(x))`.

### Proof

Assume first such a QSO exists. Write each unordered-parent heredity row as

\[
P_{ij,\bullet}=a(1,1,1)+bQ_{ij,\bullet}.
\]

Because each `P_{ij,\bullet}` is stochastic and has all coordinates at least `a`, each residual row `Q_{ij,\bullet}` is a probability vector. Thus the six residual rows form a row-stochastic `6 x 3` matrix `Q`.

For every `z` in the simplex,

\[
V(z)=a\mathbf1+b\,U(z)Q.
\]

Applying this at `x` and `y`, the two-cycle equations are exactly (3.1).

Conversely, if a row-stochastic `Q` satisfies (3.1), define

\[
P_{ij,\bullet}:=a(1,1,1)+bQ_{ij,\bullet}
\]

for the six unordered parent pairs, and set `P_{ji}=P_{ij}`. These are valid symmetric stochastic heredity rows with all coordinates at least `a`; the identity `V(z)=a\mathbf1+bU(z)Q` then gives `V(x)=y` and `V(y)=x`.

So (3.1) is necessary and sufficient. `□`

### Why this matters

For fixed `a,x,y`, two-cycle feasibility was previously an 18-coefficient linear problem plus row-stochasticity. The theorem removes the floor and exposes the exact mathematical object: a binary statistical experiment on only six source atoms garbling to a three-atom reversed/shifted experiment.

It also cleanly separates the **cycle geometry** (`x,y`) from the **heredity realization** (`Q`).

# 4. Finite stop-loss certificate

For probability pairs `(A,B)` and `(C,D)` with strictly positive reference coordinates, the classical binary Blackwell criterion says that a common stochastic channel exists exactly when the target experiment is no more informative than the source. One convenient finite form is

\[
\boxed{
\sum_k(D_k-\lambda C_k)_+
\le
\sum_r(B_r-\lambda A_r)_+
\quad\text{for every }\lambda\ge0.
}
\tag{4.1}
\]

For completeness, necessity is elementary: if `C=AQ` and `D=BQ`, then

\[
D_k-\lambda C_k
=
\sum_r(B_r-\lambda A_r)Q_{rk},
\]

so positive-part subadditivity and summation over `k` give (4.1). Sufficiency is the finite binary Blackwell/Sherman–Stein theorem, equivalently the relative-majorization theorem.

Both sides of (4.1) are continuous piecewise-linear functions of `lambda`. Hence it is enough to check the finite breakpoint set

\[
\boxed{
\Lambda(x,y;a)
=
\left\{
\frac{U_r(y)}{U_r(x)}:r\in\mathcal P
\right\}
\cup
\left\{
\frac{x_k-a}{y_k-a}:k=1,2,3
\right\}
\cup\{0\},
}
\tag{4.2}
\]

with zero-denominator cases handled by the usual limiting convention.

Thus **arbitrary prescribed two-cycle existence is decided by at most ten scalar stop-loss checks** after sorting duplicate breakpoints.

The six source likelihood ratios have the special product form

\[
\frac{U_{ij}(y)}{U_{ij}(x)}
=
\frac{y_i}{x_i}\frac{y_j}{x_j}.
\]

This product structure is the key extra information absent from generic relative majorization and is the main target for a full no-two-cycle proof at `a=1/12`.

# 6. Exact reduction of an arbitrary fixed-point flip to convex order

The next local obstruction in the previous checkpoint was: can a fixed point away from the barycentre have tangent multiplier `-1` when the floor is above `1/12`? The following theorem reduces that question exactly to one-dimensional convex order.

Fix `a<1/3`, `b=1-3a`, a probability vector `x` with `x_i>a`, and a nonzero tangent vector

\[
h_i=x_i f_i,
\qquad
\sum_i x_i f_i=0.
\]

Let `I,J` be iid with law `x`, and put

\[
S:=f(I)+f(J).
\]

Define

\[
q_i:=\frac{x_i-a}{b},
\qquad
R_i:=-\frac{x_i}{x_i-a}f_i.
\tag{6.1}
\]

Let `R` denote the three-point random variable taking value `R_i` with probability `q_i`.

## Theorem 6.1 — fixed-point flip iff convex order

There exists a three-type QSO with `P_{ij,k}\ge a`, fixed point `x`, and tangent eigenvector `h` satisfying

\[
DV(x)h=-h
\]

**if and only if**

\[
\boxed{R\preceq_{cx} S,}
\tag{6.2}
\]

i.e. `R` is dominated by `S` in convex order.

### Proof: necessity

Write

\[
P=a\mathbf1+bQ
\]

rowwise. Under iid parents `I,J~x`, let `K` be the residual child generated by `Q`.

Because `x` is fixed,

\[
x=a\mathbf1+bq,
\]

so the residual child marginal is exactly `q` from (6.1).

For the residual QSO `W`,

\[
(DW(x)h)_k
=
\sum_{i,j}x_ix_jQ_{ij,k}(f_i+f_j)
=
q_k\,\mathbb E[S\mid K=k].
\]

Since on tangent vectors `DV=bDW`, the flip equation `DV(x)h=-h` gives

\[
bq_k\,\mathbb E[S\mid K=k]
=-x_kf_k.
\]

Using `bq_k=x_k-a`,

\[
\boxed{
\mathbb E[S\mid K=k]=R_k.
}
\tag{6.3}
\]

Therefore `R=E[S|K]`; Jensen's inequality gives `R\preceq_{cx}S`.

### Proof: sufficiency

Assume `R\preceq_{cx}S`. By Strassen's martingale-coupling theorem, there exists a coupling of a random variable with the law of `S` and a random variable with the law of `R` such that

\[
\mathbb E[S\mid R]=R.
\]

The source variable `S=f(I)+f(J)` is a deterministic symmetric function of the unordered parent pair. Lift the martingale coupling to those unordered parent-pair atoms by distributing each `S`-atom according to its original iid-parent mass; if several child labels have the same `R_i`, split the target mass among those labels according to the prescribed probabilities `q_i`.

This constructs a symmetric row-stochastic residual channel `Q_{ij,k}` whose residual child has marginal `q` and satisfies (6.3). Define `P=a\mathbf1+bQ`. Then

\[
V(x)=a\mathbf1+bq=x,
\]

and the calculation above reverses to give `DV(x)h=-h`.

Thus (6.2) is also sufficient. `□`

# 7. Finite local criterion and endpoint interpretation

For real random variables with equal mean, convex order is equivalent to the stop-loss inequalities

\[
\mathbb E[(R-t)_+]
\le
\mathbb E[(S-t)_+]
\quad\forall t\in\mathbb R.
\]

Here `R` has only three atoms and `S` has at most six unordered-pair values

\[
2f_1,\ f_1+f_2,\ f_1+f_3,\ 2f_2,\ f_2+f_3,\ 2f_3.
\]

Hence the arbitrary-fixed-point flip question at a chosen `a,x,f` is again a **finite exact stop-loss problem**.

At the endpoint tensor already identified in the prior checkpoint,

\[
a=\frac1{12},
\qquad
x=(1/3,1/3,1/3),
\qquad
f=(1,0,-1),
\]

we have `b=3/4`, `q=x`, and

\[
R=(-4/3,0,4/3)
\]

with equal weights. The parent-sum distribution is supported on

\[
\{-2,-1,0,1,2\}
\]

with probabilities `1/9,2/9,3/9,2/9,1/9`. In particular the stop-loss inequality at `t=0` is tight:

\[
\mathbb E[R_+]=\frac49
=
\mathbb E[S_+].
\]

This supplies a convex-order explanation of the barycentric flip endpoint and places the previous Dobrushin equality theorem inside a sharper exact framework.

The remaining local problem is now explicit:

> prove that for `a>1/12` there are no `x_i>a` and nonzero mean-zero three-point `f` such that the three-point `R` in (6.1) is convex-order dominated by the iid parent sum `S`.

If true, this would establish sharp local stability at **every** fixed point, not only the barycentre.
