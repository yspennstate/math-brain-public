## 4. Bradley [3] (1987): exact source-condition reduction

This is the substantive progress of the run.

### 4.1 What Matsui already verifies

Matsui’s Remark 2.5(ii) considers the borderline relation

```
gamma + beta = 1,
```

with

```
tau(n) = alpha (log^{vee 2} n)^(-beta),
q_1(x) = x^2 exp((log^+ x)^gamma).
```

Following Bradley [2]/[3] Theorem 1 notation, Matsui evaluates Bradley’s condition (1.5), whose critical argument is

```
y_n = n^(1/2) exp( -(d/2) sum_{k=1}^n k^(-1) tau(k) ).
```

For the unit exponential coefficient, Matsui’s displayed calculation reduces the relevant exponent to

```
-alpha d/gamma * L^gamma
+ 2^(-gamma) L^gamma * (1 - alpha d/gamma * L^(gamma-1))^gamma,
```

where `L=log n` in the source convention. Matsui concludes that Bradley’s condition (1.5) holds when

```
alpha d > gamma 2^(-gamma),
```

and also at equality when `gamma>1/2`. The source further says the other conditions on `tau` and the *unit-coefficient* `q_1` follow for `beta,gamma in (0,1)`.

Crucially, Matsui also says the Bradley constant `d>0` appears to depend on the construction quantities `A_j` and `B_tau`, and that these constants need further analysis. This is why one cannot simply call the Bradley route a source-valid I0014 counterexample.

### 4.2 Insert the **exact I0014 moment gauge**

For I0014 put

```
gamma = 1-beta in (1/2,1).
```

The exact Corollary-2.3(b) moment factor is

```
exp[ 2 alpha (2 log^+ x)^gamma / gamma ]
= exp[ C (log^+ x)^gamma ],
```

with

```
C = (2 alpha/gamma) 2^gamma.
```

Thus the exact Bradley test must use

```
q_C(x) = x^2 exp[C (log^+ x)^gamma].
```

Repeating Matsui’s displayed algebra with the positive exponential coefficient multiplied by `C` gives the source-normalized exponent

```
E_d(L)
= -alpha d/gamma * L^gamma
  + C 2^(-gamma) L^gamma
    (1 - alpha d/gamma * L^(gamma-1))^gamma.
```

Since

```
C 2^(-gamma) = 2 alpha/gamma,
```

this is

```
E_d(L)
= (alpha/gamma) L^gamma
  [ -d + 2(1 - alpha d/gamma * L^(gamma-1))^gamma ].      (4.1)
```

This calculation is deliberately kept in **Matsui’s own normalization**; I do not insert a separate natural-log/base-2 conversion into his displayed condition.

### 4.3 Rigorous sufficient threshold `d>2`

If `d>2`, then because `gamma<1`,

```
(alpha d/gamma) L^(gamma-1) -> 0,
```

and the bracket in (4.1) tends to

```
2-d < 0.
```

Therefore

```
E_d(L) -> -infinity,
```

so Matsui’s upper bound for Bradley’s condition (1.5) is `o(n)`.

Hence:

> **PROVED SOURCE-CONDITION REDUCTION A.** For the exact I0014 exponential gauge and any `beta in (0,1/2)`, Bradley condition (1.5) is satisfied by Matsui’s displayed test whenever the Bradley construction constant has `d>2`.

This is a statement about the cited Bradley condition, **not yet a certified counterexample**, because Bradley’s full theorem and construction-dependent value of `d` have not been recovered.

### 4.4 The critical equality `d=2` also works below one-half

At `d=2`, (4.1) becomes

```
E_2(L)
= (2 alpha/gamma) L^gamma
  [ (1-z_L)^gamma - 1 ],
```

where

```
z_L = (2 alpha/gamma) L^(gamma-1).
```

For sufficiently large `L`, `0<z_L<1`. Since `0<gamma<1`, concavity of `s -> s^gamma` gives, for `0<=z<=1`,

```
(1-z)^gamma <= 1-gamma z.
```

Thus

```
E_2(L)
<= -(2 alpha/gamma) L^gamma * gamma z_L
=  -(4 alpha^2/gamma) L^(2gamma-1).                    (4.2)
```

Now I0014 has `beta<1/2`, hence

```
gamma=1-beta>1/2
```

and therefore

```
2gamma-1 = 1-2beta > 0.
```

The right-hand side of (4.2) tends to `-infinity`. Consequently Bradley condition (1.5) is also satisfied at the exact critical value `d=2`.

> **PROVED SOURCE-CONDITION REDUCTION B.** Throughout `beta in (0,1/2)`, Matsui’s Bradley-(1.5) test for the exact I0014 moment gauge succeeds already at `d=2`.

The equality phenomenon is not accidental: Matsui’s own unit-coefficient analysis says equality in its corresponding coefficient threshold is included exactly when the moment exponent `gamma>1/2`. Here `gamma=1-beta`, so the whole I0014 region has that property.
