# B5 — ADD A PARAMETER AND DIFFERENTIATE

## Outcome: Mo's full-line Airy integrals satisfy a closed third-order scalar ODE

For `T` off the real integration line (or as a fixed upper/lower boundary value where the integrals are defined), set
\[
I_j(T):=\int_{-\infty}^{\infty}H_j(u,T)\,du
=\int_{-\infty}^{\infty}\frac{Ai^{(j)}(u)}{(T-u)^{1/2}}\,du,
\]
and abbreviate
\[
I(T):=I_0(T).
\]
The branch of `(T-u)^{1/2}` is the same one used in Mo.

The first useful identity is pointwise:
\[
\partial_T H_j=H_{j+1}-\partial_uH_j. \tag{1}
\]
Indeed,
\[
\partial_TH_j=-\frac12Ai^{(j)}(u)(T-u)^{-3/2},
\]
while
\[
\partial_uH_j=H_{j+1}+\frac12Ai^{(j)}(u)(T-u)^{-3/2}.
\]
For `j=0,1`, the boundary terms at `u=\pm\infty` vanish under the standard Airy asymptotics. Integrating (1) therefore gives
\[
\boxed{I'=I_1,\qquad I''=I_2.} \tag{2}
\]

A third differentiation can be done directly without requiring a pointwise boundary value for `H_2`:
\[
I'''(T)=-\frac{15}{8}
\int_{-\infty}^{\infty}Ai(u)(T-u)^{-7/2}\,du. \tag{3}
\]
On the other hand,
\[
TI'+\frac12I
=-\frac12\int_{-\infty}^{\infty}
\frac{uAi(u)}{(T-u)^{3/2}}\,du. \tag{4}
\]
Using the Airy equation `Ai''(u)=uAi(u)` and integrating by parts twice,
\[
\int Ai''(u)(T-u)^{-3/2}\,du
=\frac{15}{4}\int Ai(u)(T-u)^{-7/2}\,du, \tag{5}
\]
with the usual oscillatory/decaying boundary interpretation. Substitution into (4) agrees exactly with (3), hence
\[
\boxed{I'''=TI'+\frac12I.} \tag{6}
\]

This is precisely the scaled symmetric-square Airy equation. It is not a numerical observation: (6) is an exact scalar ODE satisfied by the full-line quantity that enters Mo's `B1,B2` coefficients.

# B12 — FIND WHAT IS CONSERVED

## Outcome 1: an exact first integral collapses Mo's two coefficients

Equation (6) has the quadratic first integral
\[
\boxed{
K(T):=I'(T)^2-2I(T)I''(T)+TI(T)^2.
} \tag{7}
\]
Indeed,
\[
K'
=2I'I''-2(I'I''+II''')+I^2+2TII'
=-2II'''+I^2+2TII'=0 
\]
by (6).

To determine its value, take `T` to positive infinity in either admissible half-plane/boundary sector. The standard Airy integral normalization `\int_{-\infty}^{\infty}Ai(u)du=1` and the large-`T` expansion of the Abel kernel give
\[
I(T)\sim T^{-1/2},\qquad I'=O(T^{-3/2}),\qquad I''=O(T^{-5/2}),
\]
so `K(T)->1`. Therefore
\[
\boxed{
I'^2-2II''+TI^2=1.
} \tag{8}
\]

Now insert (2) into Mo's displayed coefficient formulas. Write
\[
b(T):=B_1(T)=\frac{1-I'(T)}{2I(T)}. \tag{9}
\]
Mo's second coefficient is
\[
B_2=-\frac{B_1}{2}-\frac{T}{4}I
+\frac{B_1}{2}I'+\frac12I''. \tag{10}
\]
Then
\[
4I(B_2+B_1)
=(1-I')(1+I')-TI^2+2II''
=1-I'^2-TI^2+2II''=0
\]
by (8). Hence
\[
\boxed{B_2(T)=-B_1(T).} \tag{11}
\]

Differentiating (9) and again using (8) gives
\[
4I^2\left(b'-b^2+\frac{T}{4}\right)
=I'^2-2II''+TI^2-1=0,
\]
so
\[
\boxed{b'=b^2-\frac{T}{4}.} \tag{12}
\]

Let
\[
c:=2^{-2/3}=4^{-1/3},\qquad f(T):=Ai(cT).
\]
Since `c^3=1/4`, `f''=(T/4)f`, and therefore `-f'/f` solves (12). The large-positive-`T` branch selected by Mo has
\[
b(T)\sim\frac{\sqrt T}{2},
\]
which selects the decaying Airy solution rather than the growing `Bi` solution. Thus
\[
\boxed{
B_1(T)=-c\frac{Ai'(cT)}{Ai(cT)},
\qquad
B_2(T)=+c\frac{Ai'(cT)}{Ai(cT)}=-B_1(T).
} \tag{13}
\]

This is a substantial simplification of Mo's Section 6/7 input: the two coefficients defined there through full-line singular Airy integrals reduce to one explicit Airy logarithmic derivative.

### Equivalent exact representation of the full-line integral

Equation (9) with (13) is
\[
I'-2\frac{f'}{f}I=1,
\]
so
\[
\left(\frac{I}{f^2}\right)'=\frac1{f^2}. \tag{14}
\]
Using the standard Airy Wronskian antiderivative gives, on each analytic branch,
\[
\boxed{
I(T)=\frac{\pi}{c}Ai(cT)Bi(cT)+C_{\rm branch}Ai(cT)^2,
} \tag{15}
\]
where the branch-dependent additive constant multiplies the homogeneous solution `Ai(cT)^2`. Since `\pi/c=2^{2/3}\pi`, this representation makes the branch structure explicit while leaving the branch constant free.

The important point for D0041 is that the branch-dependent homogeneous term cancels from `B_1` and `B_2`: (13) is branch-independent away from the poles at zeros of `Ai(cT)`.

## Outcome 2: a second invariant in Mo's finite 4 x 4 ODE system

Mo's Proposition 7.1 gives homogeneous dynamics `Y_\zeta=U(\zeta,T)Y` with
\[
\operatorname{tr}U=\partial_\zeta\log\frac{\phi_0}{\psi},
\qquad \psi=(T-\zeta)^{1/2}.
\]
Liouville's formula therefore yields
\[
\boxed{
\frac{\psi}{\phi_0}\det Y
\quad\text{is independent of }\zeta.
} \tag{16}
\]
If
\[
V:=Y_TY^{-1},
\]
then the compatibility identity `V_\zeta=U_T+[U,V]` gives on traces
\[
\partial_\zeta\operatorname{tr}V=\partial_T\operatorname{tr}U
=-\frac{1}{2\psi^4}.
\]
Since
\[
\partial_\zeta\left(\frac1{2\psi^2}\right)=\frac1{2\psi^4},
\]
one obtains the exact scalar conservation law
\[
\boxed{
\partial_\zeta\left(
\operatorname{tr}V+\frac1{2\psi^2}
\right)=0.
} \tag{17}
\]
Equivalently, after the scalar gauge
\[
\widehat Y=\left(\frac{\psi}{\phi_0}\right)^{1/4}Y,
\]
the zeta-connection is traceless, and a further `T`-only scalar normalization may be used to make the corresponding `T`-connection traceless as well. This identifies a natural `SL_4` gauge for the direct compatibility calculation.

I do **not** claim that (16)-(17) alone prove the Mo/BV PDE. Their value is structural: they isolate scalar normalization from the non-scalar finite ODE dynamics and give a conserved quantity that the normalization-free criterion from the previous report can potentially exploit.

## Outcome: exact real-axis jump for I(T), and no jump at all for B1,B2

The 08:00 direct-route report correctly retained the real-axis meeting/jump term in the contour integration by parts. This run resolves the full-line Airy part of that jump exactly.

For real `t`, use principal-root boundary values. If `u>t`, then
\[
(t-u+i0)^{-1/2}=-i(u-t)^{-1/2},
\qquad
(t-u-i0)^{-1/2}=+i(u-t)^{-1/2}.
\]
Therefore
\[
I_+(t)-I_-(t)
=-2iJ(t), \tag{18}
\]
where
\[
J(t):=\int_t^\infty\frac{Ai(u)}{\sqrt{u-t}}\,du
=\int_0^\infty Ai(t+s)s^{-1/2}\,ds. \tag{19}
\]

The same differentiation / Airy-equation calculation as above shows that `J` satisfies
\[
J'''=tJ'+\frac12J. \tag{20}
\]
The exponentially decaying solution with the correct large-positive-`t` scale is `Ai(ct)^2`. A direct Laplace asymptotic fixes the coefficient:
\[
J(t)\sim\frac12t^{-1/2}e^{-2t^{3/2}/3},
\]
while
\[
Ai(ct)^2\sim\frac{1}{4\pi}c^{-1/2}t^{-1/2}
 e^{-2t^{3/2}/3}.
\]
Since `c^{1/2}=2^{-1/3}`, the exact solution is
\[
\boxed{
J(t)=2^{2/3}\pi\,Ai(ct)^2.
} \tag{21}
\]
Consequently
\[
\boxed{
I_+(t)-I_-(t)
=-2^{5/3}\pi i\,Ai(ct)^2.
} \tag{22}
\]
This agrees with the branch form (15): the entire upper/lower discontinuity is a homogeneous `Ai(cT)^2` term.

Because (13) depends only on the Airy logarithmic derivative, this immediately gives
\[
\boxed{
B_{1,+}(t)=B_{1,-}(t),\qquad
B_{2,+}(t)=B_{2,-}(t)
} \tag{23}
\]
where defined (i.e. away from the Airy zeros/poles). Thus the `B_1,B_2` coefficients themselves do **not** contribute to the upper/lower real-axis jump in the direct Mo contour problem.

This does not yet prove the full contour-jump cancellation: Mo's `Q`, incomplete Airy integrals, square-root endpoint factors and `S` terms still have to be matched. But one nontrivial source of branch dependence has now been removed exactly.
