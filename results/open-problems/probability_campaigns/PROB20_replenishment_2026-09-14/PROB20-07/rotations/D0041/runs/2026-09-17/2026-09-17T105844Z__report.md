# B11 — DUALIZE / reverse the parameter map

## Outcome: the corrected map is orientation-safe, and it extends to an explicit near-diagonal window

The previous report checked the map from Mo variables to Bloemendal–Virág variables on the admissible sequence `M=N+2`. This run derives the inverse map as an independent convention check and records the largest simple class of near-diagonal sequences for which the same centering works automatically.

Let
\[
M_N=N+d_N>N,\qquad N\text{ even},\qquad
q_N:=\sqrt{M_N/N},
\]
\[
b_N:=(N/4)^{1/3},\qquad
 a_N:=(M_N^{-1/2}+N^{-1/2})^{-2/3}.
\]
Take the same data matrix in both models, with
\[
p=N,\qquad n=M_N,\qquad \ell_N=1+\tau_N,
\qquad S_N=XX^T=M_NY_N.
\]
The exact Bloemendal–Virág boundary coordinate is
\[
u_N=a_N(1-q_N\tau_N).
\tag{1}
\]
Solving (1) for `tau_N` and then forming Mo's coordinate gives the **exact reverse map**
\[
\tau_N=\frac{1-u_N/a_N}{q_N},
\]
\[
\boxed{
 w_N^{\rm Mo}:=b_N(1-\tau_N)
 =b_N(1-q_N^{-1})+\frac{b_N}{a_Nq_N}u_N.
}
\tag{2}
\]
Thus there is no possible hidden sign reversal: a positive finite BV boundary coordinate maps to a positive finite Mo coordinate with asymptotic coefficient `+1`.

For the eigenvalue coordinate, write
\[
Z_N=\frac{a_N^2}{\sqrt{M_NN}}
\left(\lambda_{\max}(S_N)-(\sqrt{M_N}+\sqrt N)^2\right).
\]
The previous forward calculation is the exact affine relation
\[
Z_N=x_N(\zeta_N^{\rm Mo}),
\]
where
\[
x_N(\zeta)=
\frac{a_N^2}{q_N}\bigl[4q_N^2-(q_N+1)^2\bigr]
+\frac{a_N^2q_N}{b_N^2}\zeta.
\tag{3}
\]
Solving (3) gives the exact inverse
\[
\boxed{
\zeta_N^{\rm Mo}
=\frac{b_N^2}{a_N^2q_N}Z_N
-\frac{b_N^2}{q_N^2}
\bigl[4q_N^2-(q_N+1)^2\bigr].
}
\tag{4}
\]
Again the coefficient of `Z_N` is positive.

Now use
\[
q_N-1=\frac{d_N}{N(q_N+1)},
\qquad
4q_N^2-(q_N+1)^2=(q_N-1)(3q_N+1).
\tag{5}
\]
If
\[
\boxed{d_N=o(N^{1/3}),}
\tag{6}
\]
then `q_N->1`, `a_N/b_N->1`, and
\[
b_N(1-q_N^{-1})=O(d_NN^{-2/3})\to0,
\]
while the additive edge offset in (4) is
\[
\frac{b_N^2}{q_N^2}(q_N-1)(3q_N+1)
=O(d_NN^{-1/3})\to0.
\]
Therefore, uniformly for each fixed finite coordinate,
\[
 u_N\to w\quad\Longleftrightarrow\quad w_N^{\rm Mo}\to w,
\]
\[
 Z_N\to\zeta\quad\Longleftrightarrow\quad
 \zeta_N^{\rm Mo}\to\zeta.
\tag{7}
\]
So the `M=N+2` repair is not a knife-edge trick; it belongs to the whole admissible class `M-N=o(N^{1/3})`.

### Boundary scale discovered

Equation (5) also identifies the first scale at which Mo's fixed center `4` can visibly differ from the exact finite-aspect-ratio soft edge. If `d_N` is of order `N^{1/3}`, then the additive standardized edge shift in (3)/(4) is generally order one. Thus `d_N=o(N^{1/3})` is the natural simple window in which the center `4` and the BV finite-aspect-ratio center can be interchanged without an order-one translation.

This is not needed for the existing `d_N=2` proof, but it is useful audit information: it exposes exactly which approximation is harmless and which one is not.

# B3 — PROVE SOMETHING STRONGER

## Outcome: eliminate the unknown Mo normalization before doing the direct PDE calculation

The 08:00 report reduced a direct check, assuming a numerical normalization constant, to a scalar contour residual plus a real-axis jump term. Its remaining normalization issue was that Mo writes the limiting formula with “some constant C,” and a `w`-dependent prefactor changes the PDE.

This run removes the need to decide `C(w)` in advance.

Let `U(\zeta,w)` denote **the complete raw Mo right-hand side with the scalar prefactor C omitted**, including the `sqrt(TW_2)` factor and the imaginary part of the contour integral. Allow the true normalization to be any nonzero scalar function of `w`:
\[
F(\zeta,w)=C(w)U(\zeta,w).
\tag{8}
\]
Define the beta=1 BV operator
\[
\mathcal L:=\partial_\zeta+2\partial_w^2+(\zeta-w^2)\partial_w,
\tag{9}
\]
and, wherever `U` is nonzero,
\[
A(\zeta,w):=\frac{\mathcal L U}{U},
\qquad
B(\zeta,w):=\frac{U_w}{U},
\qquad
c(w):=\frac{C'(w)}{C(w)}.
\tag{10}
\]
A direct product-rule calculation gives
\[
\frac{\mathcal L(CU)}{CU}
=A+4cB+2(c'+c^2)+(\zeta-w^2)c.
\tag{11}
\]
Therefore `F=CU` solves the PDE if and only if
\[
\boxed{
A+4cB+2c'+2c^2+(\zeta-w^2)c=0.
}
\tag{12}
\]
Crucially, differentiating (12) in `zeta` eliminates both `c'` and `c^2` because `c` depends only on `w`:
\[
\boxed{
A_\zeta+4cB_\zeta+c=0.
}
\tag{13}
\]
Hence, on every region where
\[
D:=1+4B_\zeta\ne0,
\]
the logarithmic derivative of the unknown normalization is forced by the **raw formula alone**:
\[
\boxed{
 c(w)=-\frac{A_\zeta}{1+4B_\zeta}.
}
\tag{14}
\]
For such a `c` to exist, the right side must be independent of `zeta`. Thus a normalization-free necessary condition is
\[
\boxed{
\partial_\zeta
\left(
\frac{A_\zeta}{1+4B_\zeta}
\right)=0.
}
\tag{15}
\]
Equivalently,
\[
A_{\zeta\zeta}(1+4B_\zeta)-4A_\zeta B_{\zeta\zeta}=0.
\tag{16}
\]
This criterion involves only Mo's **unnormalized** displayed formula; no guess about `C` appears.

### Sufficiency with one scalar normalization check

Assume on a connected region that (15) holds and `D` never vanishes. Define `c(w)` by (14). Then the derivative with respect to `zeta` of the left side of (12) is zero by (13). Consequently it is enough to verify (12) at **one** reference value `zeta=zeta_0` for each `w`. Once that one scalar identity holds, integrate
\[
C(w)=C(w_0)\exp\left(\int_{w_0}^w c(s)\,ds\right)
\tag{17}
\]
and fix the single multiplicative constant `C(w_0)` from probability normalization/boundary data. Then `CU` satisfies the PDE throughout the region.

If `D=0` at isolated points, (13) requires `A_\zeta=0` there and continuation can be handled separately; no claim is made here that this degeneracy is absent.
