# 4. B18 — say it in another language: horizontal levels become a zero-count problem

Fix any level

```text
0 < c < h_*.
```

Set

```text
phi_c(delta)=k(delta)-c j(delta)
            =j(delta)(h(delta)-c).
```

Because `j>0` and `h` rises strictly from `0` to `h_*` and then falls strictly to `0`, there are unique numbers

```text
0 < alpha(c) < delta_* < beta(c) < infinity
```

with

```text
phi_c(alpha)=phi_c(beta)=0,
phi_c(delta)<0 on (0,alpha),
phi_c(delta)>0 on (alpha,beta),
phi_c(delta)<0 on (beta,infinity).    (2)
```

Thus `phi_c` has exactly two sign changes, of type `-,+,-`.

Define its Laplace transform

```text
F_c(r)=L[phi_c](r)
      =L[j](r)(G(r)-c).                (3)
```

Since `L[j](r)>0`, zeros of `F_c` are exactly the positive solutions of `G(r)=c`.

The problem is therefore reduced to the following two-sign-change Laplace lemma.

## Lemma 2 (elementary two-sign-change Descartes rule)

Let `phi:(0,infinity)->R` be continuous, with strict sign pattern

```text
-,+,-
```

separated by exactly two points `alpha<beta`, and suppose `L[phi](r)` converges absolutely for every `r>0`. Then `L[phi]` has at most **two distinct** positive zeros.

### Proof

Assume for contradiction that there are three distinct positive zeros

```text
0 < r1 < r2 < r3
```

of `L[phi]`.

Choose a nonzero coefficient vector `(a1,a2,a3)` solving the two homogeneous equations

```text
a1 e^{-r1 alpha}+a2 e^{-r2 alpha}+a3 e^{-r3 alpha}=0,
a1 e^{-r1 beta} +a2 e^{-r2 beta} +a3 e^{-r3 beta} =0.
```

Such a nonzero vector exists because there are two equations and three unknowns. Put

```text
q(delta)=a1 e^{-r1 delta}+a2 e^{-r2 delta}+a3 e^{-r3 delta}.
```

Then `q(alpha)=q(beta)=0`.

A nontrivial linear combination of these three exponentials has at most two zeros **counting multiplicity**. Here is a direct proof. Factor out the positive `e^{-r1 delta}` and set

```text
y=e^{-(r2-r1)delta},
p=(r3-r1)/(r2-r1)>1.
```

The remaining factor is

```text
f(y)=a1+a2 y+a3 y^p,
```

for `0<y<1`. Its derivative is

```text
f'(y)=a2+p a3 y^{p-1},
```

which has at most one positive zero. By Rolle's theorem, `f` has at most two zeros counting multiplicity. In particular, because `alpha` and `beta` are already two distinct zeros of `q`, they are both simple and are the only zeros of `q` on `(0,infinity)`.

Therefore `q` changes sign exactly at `alpha` and `beta`. Multiplying all `a_i` by `-1` if necessary, we may arrange that `q` has the same sign pattern `-,+,-` as `phi`. Hence

```text
q(delta) phi(delta)>0
```

for every `delta` except the two zero points. Absolute convergence follows because `q` is a finite sum of positive-rate exponentials and `phi` has the assumed Laplace convergence. Consequently

```text
int_0^infinity q(delta) phi(delta) ddelta > 0.          (4)
```

On the other hand, by the definition of `q` and the assumed transform zeros,

```text
int q phi
 =a1 L[phi](r1)+a2 L[phi](r2)+a3 L[phi](r3)
 =0,                                                     (5)
```

contradicting (4). This proves the lemma. `square`

Applied to `phi_c`, Lemma 2 gives:

```text
For every c in (0,h_*), the equation G(r)=c
has at most two distinct positive solutions.            (6)
```

No external shape-preservation theorem is needed for (6).

# 5. B25 — count the same thing twice: zero-counting forces one connected hill

The endpoint limits and positivity imply that `G` attains a positive global maximum. Indeed, choose any `r0>0`. For sufficiently small `r` and sufficiently large `r`, `G(r)<G(r0)/2`; hence the global maximum is attained on a compact middle interval. Let

```text
M=max_{r>0} G(r).
```

By (1), `0<M<h_*`.

For any `c in (0,M)`, the strict superlevel set

```text
S_c={r>0:G(r)>c}
```

is nonempty and bounded away from both `0` and `infinity`. If `S_c` had two or more connected components, two bounded components would contribute at least four distinct boundary points satisfying `G(r)=c`. That contradicts the two-zero bound (6). Thus:

```text
Every nonempty strict superlevel set S_c is one interval. (7)
```

This one-dimensional quasiconcavity already forces a one-hill order structure.

Choose a maximizer `r_*`. If

```text
0<r1<r2<=r_*
```

and `G(r1)>G(r2)`, choose `c` strictly between those two values. Then `r1` and `r_*` both lie in `S_c` while the intervening point `r2` does not, contradicting the interval property (7). Hence `G` is nondecreasing on `(0,r_*]`. The symmetric argument shows it is nonincreasing on `[r_*,infinity)`.

There cannot be two distinct maximizers. If there were a dip between them, a level between the dip and `M` would disconnect a superlevel set; if there were no dip, `G` would be constant on the interval between them. But `G` is real analytic on `(0,infinity)`, so a nontrivial plateau would force `G` to be constant everywhere, contrary to the endpoint limits and positivity. Hence the maximizer `r_*` is unique.

The branch monotonicity is in fact strict in the order sense. If two distinct points on the left branch had the same value, nondecreasing monotonicity would make `G` constant on the interval between them, and analyticity would again force global constancy. The same argument applies on the right branch. Therefore

```text
G(r1)<G(r2) for 0<r1<r2<=r_*,
G(r1)>G(r2) for r_*<=r1<r2<infinity.                  (8)
```

This recovers the order-unimodality previously obtained from Karp–Vishnyakova–Zhang, now directly from the two-sign-change Laplace lemma.

# 6. Strict derivative signs remain elementary

For completeness, I checked that the previous B25 derivative upgrade meshes exactly with the new order proof.

Suppose `r0 != r_*` and, contrary to the source claim,

```text
G'(r0)=0.
```

Set `c=G(r0)`. By (1), `0<c<h_*`, so `phi_c` has the two strict sign changes (2). By (8), `G` is strictly monotone through `r0`. Since `G` is real analytic and `G'(r0)=0`, the first nonzero Taylor term of `G-G(r0)` has odd degree at least three. Therefore

```text
F_c(r)=L[j](r)(G(r)-c)=L[phi_c](r)
```

has a zero of multiplicity at least three at `r0`. Thus

```text
int delta^m e^{-r0 delta} phi_c(delta) ddelta=0,
m=0,1,2.                                                (9)
```

Let `alpha<beta` be the sign-change locations of `phi_c` and set

```text
P(delta)=-(delta-alpha)(delta-beta).
```

`P` has exactly the same `-,+,-` sign pattern as `phi_c`, so

```text
int_0^infinity P(delta)e^{-r0 delta}phi_c(delta) ddelta>0. (10)
```

But `P` has degree two, so (9) forces the same integral to be zero. Contradiction. Hence

```text
G'(r)!=0 for every r!=r_*.
```

Differentiability plus (8) therefore gives

```text
G'(r)>0  for 0<r<r_*,
G'(r)<0  for r>r_*.
```

At the unique interior maximizer, Fermat's theorem gives `G'(r_*)=0`. Together with the already-rigorous endpoint value limits, this is exactly the installed core source assertion.
