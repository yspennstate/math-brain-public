### Exact source setup

All graph edges have graph length one. A vertex set `N subset R^2` is a `10`-net if every point of the plane lies within Euclidean distance 10 of some point of `N`.

For a fixed finite source set `S`, the paper's setup asks for a bounded-degree planar graph `G`, drawn in the same Euclidean plane, whose vertex set `N` is a 10-net containing `S`, such that

`d_G(p_i,x) = |p_i-x| + O(1)`

for every graph vertex `x` and every source `p_i`. The introductory definition says the additive constant is independent of **scale**.

Theorem 1 proves the statement for every pair of sources, with universal constants.

The formal open box is:

> **Question 1 (Three fixed sources).** Let `p_1,p_2,p_3` be three non-collinear points in `R^2`. Does there exist a bounded-degree planar graph `G`, drawn in the plane, whose vertex set is a 10-net containing `p_1,p_2,p_3`, such that `d_G(p_i,x)=|p_i-x|+O(1)` for every vertex `x` and `i=1,2,3`?

The source then separately asks the broader classification question for arbitrary finite source sets. This admission candidate freezes **Question 1 only**; it does not silently replace it by the broader classification problem.

### Quantifier / constant freeze

The variables `p_1,p_2,p_3` in Question 1 are arbitrary non-collinear points, so the positive direction is a construction valid for every such triple. A negative answer can be supplied by one explicit non-collinear triple together with a proof that no source-valid graph exists for it.

The formal Question 1 writes `O(1)` and the setup requires the additive error to be independent of scale. The question does **not** explicitly repeat Theorem 1's stronger phrase `the constants are universal`. Therefore an admitted worker must not silently strengthen the source by demanding a constant uniform over all triple shapes unless a later author statement establishes that reading. The safe source semantics are: for each fixed triple, a finite additive bound independent of `x` and scale.
