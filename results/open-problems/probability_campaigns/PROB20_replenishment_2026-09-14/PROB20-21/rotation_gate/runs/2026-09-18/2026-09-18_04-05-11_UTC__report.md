## 7. B18 — rewrite the source as a weighted Bernoulli subset-sum collision problem

The current MathOverflow answer records an especially useful source-equivalent language. Let

`d_i = a_{i+1}-a_i > 0`.

At each recursion step the right embedding shifts the coordinate by `d_i`. With iid Bernoulli indicators for the right choices, the index of the nonzero atom is, up to an irrelevant additive constant,

`S_n = B_0 + d_1 B_1 + ... + d_{n-1} B_{n-1}`,

where all Bernoulli variables have the same parameter (up to replacing `p` by `1-p`). Thus the source problem is an entropy-concavity problem for positive-integer weighted iid Bernoulli sums, with first weight `1`.

For each support value `s`, its mass is obtained by collecting Boolean subsets having the same weighted sum. Equivalently, the combinatorial datum is the collision partition of the Boolean cube induced by one positive integer linear form.

This language exposes why arbitrary stochastic coarse-graining is too broad: only collision partitions realizable by positive integer subset sums occur. It also gives a finite state space of collision patterns at every fixed depth.
