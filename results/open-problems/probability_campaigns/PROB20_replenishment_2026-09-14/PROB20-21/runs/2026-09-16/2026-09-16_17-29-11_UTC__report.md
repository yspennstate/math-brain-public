# 3. B14 — complete Hamming-cube symmetry action and an exact `S_7` quotient

## 3.1 Full source-objective symmetry

Let `Q_n={0,1}^n` with Hamming distance. Every Hamming-cube automorphism has the form

\[
\tau(x)=a\oplus \pi(x),
\]

where `a in {0,1}^n` and `pi in S_n` permutes coordinates. This is the complete automorphism group of the Hamming cube:

\[
\operatorname{Aut}(Q_n)\cong (\mathbb Z_2)^n\rtimes S_n,
\qquad |\operatorname{Aut}(Q_n)|=2^n n!.
\]

A short proof of completeness is standard and included here. Translate any automorphism so it fixes `0`. It must permute the `n` neighbors `e_i` of `0`. A vertex `x` is uniquely determined by which `e_i` satisfy `d(x,e_i)=|x|-1`; hence after the neighbor permutation is fixed, every vertex is fixed. Undoing the initial translation gives exactly bit flips followed by a coordinate permutation.

The BSC kernel is

\[
K_\alpha(x,y)=\alpha^{d(x,y)}(1-\alpha)^{n-d(x,y)},
\]

so it is invariant under every `tau`. Since `X` is uniform,

\[
I(b(X);Y)=I((c\oplus b\circ\tau)(X);Y),\qquad c\in\{0,1\}.
\]

Thus the proved symmetry action available on truth tables is

\[
\operatorname{Aut}(Q_n)\times\mathbb Z_2,
\]

of size `2^{n+1} n!`; at `n=7` its size is `1,290,240`. This is complete among Hamming-cube input automorphisms, with the additional exact output-complement symmetry.

## 3.2 A symmetry that preserves the source compressed family

The whole group need not preserve the source's **fixed lex-compression orientation**. However the involution

\[
D(A)=\{x:\bar x\notin A\}
\tag{3.1}
\]

is both an objective symmetry and an internal symmetry of `S_n`. It is "flip all input bits, then complement the output." On each singleton or pair section, antipodal input reversal reverses the source lex chain and set complementation reverses membership, sending an initial segment to an initial segment. Hence `D(S_n)=S_n` and `D^2=id`.

The executed exact checker reconstructs `S_7` from the source singleton/pair implications and verifies every implication. It obtains

- `|S_7| = 44,315` exactly, matching the source table;
- sorted-mask SHA-256 `9caace4fb804076a20a55c2e0b9fb3e1f860a7a7629f788a9e42fe1c1e77a50d`;
- `1007` balanced compressed functions;
- `135` fixed points of `D`, all balanced;
- **22,225 exact `D`-orbits**.

Therefore every future source-valid `n=7` search may rigorously replace 44,315 compressed candidates by 22,225 `D`-orbit representatives, with no loss. This is a real search-space reduction, but not metric movement.

# 5. B11 — exact entropy defect as a Fourier/moment dual inequality

This run also rewrites the **full vector-output** defect, without replacing it by coordinate-wise information.

Use `{-1,+1}` coding and natural logarithms. Define

\[
\psi(t)=\log2-h\!\left(\frac{1+t}{2}\right).
\]

If `mu=E f` and `g_\rho=T_\rho f`, then exactly

\[
I(f(X);Y)=\mathbb E\psi(g_\rho(Y))-\psi(\mu),
\]

so the Courtade–Kumar defect is

\[
\mathcal D_f(\rho)
=\psi(\rho)+\psi(\mu)-\mathbb E\psi(g_\rho).
\tag{5.1}
\]

Since `psi'(t)=atanh(t)` and `psi(0)=0`, for `|t|<=1`,

\[
\psi(t)=\sum_{m\ge1}\frac{t^{2m}}{2m(2m-1)}.
\tag{5.2}
\]

Therefore the original conjecture is exactly the single dual/moment inequality

\[
\boxed{
\mathcal D_f(\rho)
=\sum_{m\ge1}\frac{\rho^{2m}+\mu^{2m}-M_{2m}(\rho)}{2m(2m-1)}\ge0,
}
\tag{5.3}
\]

where

\[
M_{2m}(\rho)=\mathbb E\bigl(T_\rho f(Y)\bigr)^{2m}.
\]

Writing

\[
T_\rho f(y)=\sum_S\rho^{|S|}\widehat f(S)\chi_S(y),
\]

Walsh orthogonality gives the exact Fourier convolution

\[
\boxed{
M_{2m}(\rho)=
\sum_{S_1\triangle\cdots\triangle S_{2m}=\varnothing}
\rho^{|S_1|+\cdots+|S_{2m}|}
\prod_{j=1}^{2m}\widehat f(S_j).
}
\tag{5.4}
\]

The symmetric-difference constraint forces even total degree, so every `M_{2m}` is a polynomial in `u=rho^2` with rational coefficients for a finite truth table.

This produces a finite hierarchy with a rigorous tail. Let

\[
a_m=\frac1{2m(2m-1)},\qquad
R_K=\log2-\sum_{m=1}^{K}a_m.
\]

Because `|T_rho f|<=1`, for every `m>=K+1`,

\[
|T_\rho f|^{2m}\le |T_\rho f|^{2K+2}.
\]

Dropping the nonnegative `rho^{2m}+mu^{2m}` part of the tail in (5.3) gives the rigorous sufficient lower bound

\[
\boxed{
\mathcal D_f(\rho)
\ge
\sum_{m=1}^{K}a_m\bigl[\rho^{2m}+\mu^{2m}-M_{2m}(\rho)\bigr]
-R_K M_{2K+2}(\rho).
}
\tag{5.5}
\]

This is the main B11 methodological output. For fixed `K`, every function-dependent term is an **exact rational polynomial in `u=rho^2`**; the only transcendental constant is `R_K`, for which one global rational enclosure of `log 2` suffices. Thus a large part of an `n=7` continuous-interval search can potentially be converted from repeated posterior logarithms into rational polynomial sign tests/Bernstein certificates. `K=1` recovers the familiar second-moment/high-noise flavor; increasing `K` supplies systematically sharper corrections rather than inventing a new local inequality each run.

No claim is made here that any fixed `K` proves the full conjecture. The next run should measure how many of the 22,225 `D`-orbits are discharged by small `K` over the middle interval.
