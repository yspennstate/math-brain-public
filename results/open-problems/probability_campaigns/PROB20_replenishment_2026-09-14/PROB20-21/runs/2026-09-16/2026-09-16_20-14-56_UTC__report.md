# 2. B18 — rewrite the low-noise defect through the local sensitive-degree profile

The previous endpoint proof treated biased and balanced functions separately. A better low-noise language uses the complete local sensitive-degree profile and handles both in one inequality.

Work in natural logarithms. Let

\[
p=\Pr(f(X)=1),
\qquad
D_f(\alpha)=\log2-h(\alpha)-I(f(X);Y).
\]

For each cube vertex `y`, let `d_y` be the number of sensitive incident edges,

\[
d_y=\#\{i:f(y)\ne f(y\oplus e_i)\},
\]

and define

\[
A=\mathbb E_y d_y,
\qquad
E=\mathbb E_y[d_y\log d_y],
\]

with `0 log 0=0`.

Condition on `Y=y` and put

\[
e_y=\Pr(f(X)\ne f(y)\mid Y=y).
\]

Because the uniform prior and BSC are reversible, conditioned on `Y=y` the input is obtained from `y` by iid bit flips of probability `alpha`. Therefore

\[
e_y\le 1-(1-\alpha)^7.
\tag{2.1}
\]

The disjoint event that **exactly one** coordinate flips and that coordinate is sensitive gives

\[
\boxed{e_y\ge d_y\alpha(1-\alpha)^6.}
\tag{2.2}
\]

Set

\[
c=(1-\alpha)^6,
\qquad L=\log(1/\alpha).
\]

On any interval where (2.1) is at most `1/2`, binary entropy is increasing at every relevant `e_y`. Since

\[
h(z)\ge z\log(1/z),
\]

(2.2) yields

\[
\begin{aligned}
H(f(X)\mid Y)
&=\mathbb E_y h(e_y)\\
&\ge \alpha c\,\mathbb E_y\bigl[d_y(L-\log d_y-\log c)\bigr]\\
&\ge \alpha c(AL-E).
\end{aligned}
\tag{2.3}
\]

Also

\[
h(\alpha)
=\alpha L-(1-\alpha)\log(1-\alpha)
\le \alpha(L+1).
\tag{2.4}
\]

Since

\[
D_f(\alpha)=\log2-h(p)-h(\alpha)+H(f(X)\mid Y),
\]
we obtain the full-vector lower bound

\[
\boxed{
D_f(\alpha)
\ge
B_f(\alpha)
:=
\log2-h(p)
+
\alpha\left[(cA-1)L-cE-1\right].
}
\tag{2.5}
\]

This is a theorem for the original mutual-information defect; it is not a coordinate-wise substitute.
