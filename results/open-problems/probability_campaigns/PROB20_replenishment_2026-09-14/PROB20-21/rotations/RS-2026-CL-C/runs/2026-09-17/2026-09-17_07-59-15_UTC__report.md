# 3. B5 — add a softness parameter: multiplicative clique softening has the wrong Fourier scale

A natural response to the exact-clique monomial degree `m=binom(k,2)` is to soften the hard clique predicate before truncating it. The simplest such deformation already exhibits a sharp obstruction.

Fix a candidate `k`-set `S`, let

`m = binom(k,2)`,

and encode each internal edge by a Rademacher variable `X_e in {-1,+1}`, with `+1` meaning present. Let

`D_S = # { missing internal edges of S } = (m - sum_e X_e)/2`.

For a softness parameter `lambda>1`, consider the multiplicative Gibbs weight

`W_lambda(X) = lambda^{-D_S}`.

A present edge contributes factor `1`; a missing edge contributes `lambda^{-1}`. Therefore

`W_lambda(X) = prod_{e in binom(S,2)} (a_lambda + b_lambda X_e)`,

where

`a_lambda = (1+lambda^{-1})/2`,

`b_lambda = (1-lambda^{-1})/2`.

The Walsh coefficient of an edge subset `A` of size `j` is exactly

`hat W_lambda(A) = a_lambda^{m-j} b_lambda^j`.

Consequently the **normalized squared Fourier-level distribution** is exactly binomial:

`sum_{|A|=j} hat W_lambda(A)^2 / ||W_lambda||_2^2
 = P(Bin(m,p_lambda)=j)`,

with

`p_lambda = b_lambda^2/(a_lambda^2+b_lambda^2)
          = (lambda-1)^2/[2(lambda^2+1)].`

This identity is exact.

### 3.1 The deformation needed to favor near-cliques forces Fourier mass to degree Theta(k^2)

Under the probability measure obtained by reweighting the uniform internal-edge measure by `W_lambda`, the missing-edge indicators remain independent and

`P_lambda(edge missing)=1/(lambda+1)`.

Hence

`E_lambda D_S = m/(lambda+1)`.

To bias a `k`-set down to only `O(k)` missing internal edges — already a much weaker demand than being a clique — one needs

`lambda = Omega(k)`.

For such `lambda`,

`p_lambda -> 1/2`.

More crudely, for every `lambda>=2`,

`p_lambda >= 1/10`.

Now let the low-degree cutoff be

`d <= C k`

for a fixed constant `C`. Since `m=Theta(k^2)`, a Chernoff lower-tail bound gives, uniformly for `lambda>=2`,

`||Pi_{<=d} W_lambda||_2^2 / ||W_lambda||_2^2
 = P(Bin(m,p_lambda)<=d)
 <= exp(-c_C m)
 = exp(-Theta(k^2))`

for all sufficiently large `k`.

At the source scale `k=Theta(log n)`, the fraction of the `L_2` energy captured by degree `O(log n)` is therefore

`exp(-Theta((log n)^2))`.

### B5 outcome

The basic multiplicative soft-clique route fails for a structural reason: once the softness is strong enough to move a candidate from its typical `Theta(k^2)` missing edges to even `O(k)` missing edges, its Fourier spectrum is still concentrated around degree `Theta(k^2)`. Thus “replace the clique monomial by `lambda^{-#missing}` and truncate” cannot be the target-scale answer.

This is **not** an impossibility result for the Randomstrasse problem. It rules out one particularly natural one-parameter deformation and motivates a different use of typical-instance slack: algebraize the *sequential construction* rather than soften the final clique predicate.

# 4. B9 — randomize the construction: a singleton-block greedy algorithm reaches (1-o(1)) log_2 n

The next idea removes the tie-breaking/argmax operation from each greedy step.

Let

`L = log_2 n`

and target

`k = floor(L - 4 log_2 L)`.

Thus

`k = (1-o(1)) log_2 n`.

Suppose a clique `C` of size `s` has already been built. Take a fresh block `B`, disjoint from all previously exposed blocks and from `C`. A vertex `v in B` is **eligible** if it is adjacent to every vertex of `C`. Conditional on the history, the eligibility indicators in `B` are independent Bernoulli variables with

`p_s = 2^{-s}`.

Instead of asking for an arbitrary eligible vertex, demand that the block contain **exactly one** eligible vertex. When that happens, the extension is canonical inside the block and the unique eligible vertex can be added to the clique.

We use different block sizes in an initial and a bulk regime.

Set

`s_0 = ceil(2 log_2 L)`.

## 4.1 Initial regime: singleton blocks

For `1 <= s < s_0`, use trial blocks of size one. A trial succeeds with probability exactly

`q_s = 2^{-s}`.

Allocate

`R_s = ceil(A 2^s L)`

independent trials at level `s`, where `A>0` is a sufficiently large fixed constant. Then

`P(no successful trial at level s | history)
 <= exp(-R_s 2^{-s})
 <= exp(-A L).`

The total number of vertices consumed in this regime is

`sum_{s<s_0} R_s = O(A L 2^{s_0}) = O(A L^3)`.

## 4.2 Bulk regime: sparse singleton blocks

For `s_0 <= s < k`, let

`M_s = ceil(2^s/L^2)`

and use fresh trial blocks of size `M_s`. The number `N_s` of eligible vertices in one trial is

`N_s ~ Bin(M_s,2^{-s}).`

Its mean `lambda_s=M_s2^{-s}` satisfies, for large `n`,

`1/L^2 <= lambda_s <= 2/L^2`.

The singleton probability is

`q_s = P(N_s=1)
     = M_s 2^{-s}(1-2^{-s})^{M_s-1}.`

Using `(1-p)^r >= 1-rp` for `rp<=1`, and `lambda_s<=2/L^2`, we obtain

`q_s >= lambda_s(1-lambda_s) >= 1/(2L^2)`

for all large `n`.

Allocate

`R = ceil(2 A L^3)`

fresh blocks at every bulk level. Then

`P(no singleton block at level s | history)
 <= exp(-q_s R)
 <= exp(-A L).`

There are at most `L` levels, so by a union bound the probability that **any** level fails is at most

`L exp(-A L) = o(1)`.

Conditional independence is legitimate by deferred decisions: at a given level, the events use disjoint edge sets from the fixed current clique to fresh blocks; future-block edges need not be exposed earlier.

## 4.3 There are enough disjoint vertices

The initial regime uses `O(L^3)` vertices. In the bulk regime,

`sum_{s=s_0}^{k-1} R M_s
 <= O(L^3) sum_s (2^s/L^2 + 1)
 = O(L 2^k + L^4).`

Since

`2^k <= n/L^4`,

this is

`O(n/L^3 + L^4)=o(n)`.

Thus all trial blocks can be chosen disjointly in advance for sufficiently large `n`.

### Theorem 4.1 — singleton-block greedy reaches the source scale

There is a randomized block-greedy procedure which, on `G(n,1/2)`, constructs an **exact clique** of size

`log_2 n - O(log log n) = (1-o(1)) log_2 n`

with probability `1-o(1)`, and in which every accepted stage is certified by the event “this particular trial block contains exactly one common neighbor of the current clique.”

This theorem is an algorithmic reorganization of the classical greedy phenomenon, not a claim of a new computational threshold. Its value for the present problem is algebraic: singleton events admit unusually simple signed polynomial certificates.

# 5. B28 — replace “for all inputs” by typical existence, then flatten every candidate path to degree O(log n)

Fix a clique prefix `C` of size `s` and one trial block `B`. For each `v in B`, define the exact eligibility monomial

`E_v^C(Y) = prod_{u in C} Y_{uv}`.

It has degree `s`. Let

`N_B^C(Y) = sum_{v in B} E_v^C(Y)`

be the number of eligible candidates in the block, and define

`U_B^C(Y) = 1 - (N_B^C(Y)-1)^2`.

Finally define the candidate extension score

`H_{B,v}^C(Y) = E_v^C(Y) U_B^C(Y).`

Because `deg N_B^C <= s`, we have

`deg H_{B,v}^C <= 3s`.

The key point is its exact sign table on **every graph**, not merely typically:

- If `N_B^C=1` and `v` is the unique eligible vertex, then `H_{B,v}^C=1`.
- If `v` is not eligible, then `H_{B,v}^C=0`.
- If `N_B^C=0` or `2`, then every candidate has score `0`.
- If `N_B^C>=3`, then `U_B^C=1-(N_B^C-1)^2<0`, so every eligible candidate has negative score.

Therefore

`H_{B,v}^C <= 1`

universally, and

`H_{B,v}^C = 1`

**if and only if** `(B,v)` is a valid singleton extension of `C`.

This avoids the need to polynomially encode an equality test `N=1`: the equality is represented as the positive side of a degree-`3s` polynomial with a unit gap.

## 5.1 Signed path certificate

A candidate path `P` of length `t` specifies vertices

`v_1,...,v_t`

and, for each extension stage, one of the preassigned trial blocks containing the next vertex. Let

`C_s(P)={v_1,...,v_s}`.

For every stage define the corresponding singleton-extension score

`H_s(P;Y)=H_{B_s,v_{s+1}}^{C_s(P)}(Y)`.

Set

`Q_P(Y) = sum_s H_s(P;Y)`.

If there are `t-1` extension stages, then each summand has degree at most `3t`, so

`deg Q_P <= 3t = O(t)`.

Moreover:

- If every proposed extension in `P` is a valid singleton extension, every summand equals `1`, so `Q_P=t-1`.
- If at least one extension is invalid, that summand is at most `0` while every other summand is at most `1`, hence `Q_P<=t-2`.

Thus the shifted score

`Phi_P(Y)=Q_P(Y)-(t-2)`

obeys the exact dichotomy

`Phi_P(Y)=1` for every valid singleton path,

`Phi_P(Y)<=0` for every invalid path,

with

`deg Phi_P <= 3t`.

A valid path is automatically a clique, because every extension vertex is adjacent to the entire preceding prefix.

### Theorem 5.1 — source-scale positive certificates exist at degree O(log n)

For

`t = floor(log_2 n - 4 log_2 log_2 n)`,

the singleton-block construction implies that, with probability `1-o(1)` over `G(n,1/2)`, **at least one** candidate path `P` satisfies

`Phi_P(Y)=1`,

and every path that is not a valid `t`-clique construction satisfies

`Phi_P(Y)<=0`.

Every `Phi_P` has degree at most

`3t = O(log n)`.

This is the strongest constructive reduction obtained in this track so far. The quadratic degree blow-up from multiplying the successive adjacency tests has disappeared: path validity is encoded by **addition plus a final threshold margin**, not by the product of all stage predicates.

## 5.2 Why this still does not move alpha_LD

The Randomstrasse source does not ask for a family of exponentially many scalar PTF certificates. It asks for one vector-valued polynomial `f(Y)` whose coordinate thresholds actually return the clique.

The remaining compiler problem is now:

> Given an explicit family `{Phi_P}` of degree-`O(log n)` polynomials with the unit-gap property `Phi_P=1` for valid paths and `Phi_P<=0` otherwise, and with a valid path existing with high probability, construct a degree-`O(log n)` vector polynomial whose thresholded coordinates select the vertices of one positive path.

Naively multiplying stage gates returns to degree `Theta(log^2 n)`. Naively forming an exact OR/positive-part over all path scores likewise reintroduces a high-degree aggregation problem. The previous run's fixed-candidate uniform-approximation barrier warns against solving this by demanding tiny uniform errors over an exponentially large candidate family.

The path-certificate theorem therefore moves the hard step from “polynomialize greedy recursion” to a much more isolated Boolean-complexity question:

`LOW-DEGREE SIGNED CERTIFICATES  ->  LOW-DEGREE SEARCH SELECTOR.`

This is not cosmetic. Before this run, even a source-scale degree-`O(log n)` certificate for a full greedy trajectory was missing. Now the entire adaptive trajectory has such a certificate; only winner selection remains.

# 6. A second B5 diagnostic: softmax aggregation would need source-scale amplification

The most obvious way to select a positive certificate is to amplify the unit score gap, for example with a softmax-like weight `exp(beta Phi_P)` and normalize over paths. But the candidate path family has superpolynomial size. To make all nonpositive certificates negligible compared with a single `Phi_P=1` certificate using a purely uniform gap argument, `beta` must be at least of order the logarithm of the candidate count, which is itself much larger than a constant at the target scale. Polynomially truncating such an exponential then multiplies the certificate degree by the approximation order and destroys the `O(log n)` budget.

This is only a route diagnosis, not a lower bound: a successful selector could exploit correlations, randomized hashing, typical graph geometry, or the Definition-1.1 error tolerance rather than uniform softmax domination.

# 7. Relation to decision-list / PTF literature

The remaining object resembles a decision-list or winner-selection problem whose tests are themselves degree-`O(log n)` signed polynomials. Existing polynomial-threshold-function results for ordinary decision lists show that substantial compression of long sequential logic into low-degree sign polynomials is possible in some settings. But those theorems take Boolean literals/queries in a different model; straightforwardly substituting degree-`O(log n)` path predicates multiplies degrees and does not yield the source construction. No transfer theorem located in this run closes the compiler step.

That makes the nearest useful next question precise: is there a **search-specific**, distributional compiler for a sparse positive-certificate family that avoids degree multiplication because only one coherent root-to-leaf path needs to be output on a typical random graph?
