## 1. Exact source and dated current-status check

Outside source: Anastasia Kireeva, Randomstrasse 101, *Low-degree hardness of finding the largest clique in Erdos-Renyi graph (problems 36-38)*, posted 5 June 2026, final displayed open box (the page labels it `Open Problem 35`). Live URL checked 17 September 2026:

`https://randomstrasse101.math.ethz.ch/posts/clique-low-degree/`

The source asks for a multivariate polynomial

`f : {0,1}^{binom(n,2)} -> R^n`

of degree `O(log n)` which, for `G ~ G(n,1/2)`, finds a clique of size `log_2 n` and has a structure similar to Definition 1.1 of Wein (2022). The source explicitly says that values `>=1` should represent selected clique vertices, values `<=1/2` unselected vertices, with a small number of mistakes allowed. It also explicitly says that it is unclear whether the classical greedy `log_2 n` clique algorithm can be written as a degree-`O(log n)` polynomial or replaced by an equivalent polynomial.

Primary reference recovered exactly:

Alexander S. Wein, *Optimal Low-Degree Hardness of Maximum Independent Set*, Math. Stat. Learn. 4 (2022), arXiv:2010.06563.

Wein Definition 1.1 is a rounding rule, not the normalization condition of Definition 1.2. For an independent-set polynomial it defines

- `A={i:f_i>=1}`;
- `A_tilde={i in A: i has no neighbors in A}`;
- `B={i:f_i in (1/2,1)}`;
- output `A_tilde` if `|A\A_tilde|+|B| <= eta n`, and the empty set otherwise.

For the clique problem, apply the rule to the complement graph. Equivalently, for the present source define

`A_f(G)={i:f_i(G)>=1}`,

`A_tilde_f(G)={i in A_f(G): i is adjacent in G to every other vertex in A_f(G)}`,

`B_f(G)={i:f_i(G) in (1/2,1)}`,

and return `A_tilde_f(G)` when `|A_f\A_tilde_f|+|B_f| <= eta n`, otherwise return the empty set.

This is the exact clique-complement adaptation of Definition 1.1 and an affine complement of edge variables preserves polynomial degree.

**Scope caution.** Randomstrasse says `similar structure to Definition 1.1` and `small number of mistakes`; it does not numerically freeze `eta`, and it does not cite Definition 1.2's additional `E||f||^2 <= gamma k` normalization. I do not silently import that stronger norm constraint. The construction proved below has **zero rounding errors for every graph**, so it satisfies the Definition-1.1 mistake rule for every `eta>=0` and is immune to the tolerance ambiguity. Its coefficients are very large, so it should not be represented as satisfying a Definition-1.2 norm bound unless that is separately proved.

Wein's dense-graph Section 1.3 gives an impossibility theorem above `(1+epsilon) log_2 n` and then states that the matching achievability remains open: it is not clear how to write greedy as a low-degree polynomial or otherwise find `(1-epsilon) log_2 n`; it suggests degree `O(log n)` as a possible scale. That is the direct primary-literature ancestor of the Randomstrasse box.

## 3. B2 — attack the literal greedy polynomialization first

Fix the deterministic vertex order `1,2,...,n` and consider the literal sequential greedy algorithm which accepts a vertex exactly when it is adjacent to every previously accepted vertex. Let `g_n(Y) in {0,1}` be the exact indicator that vertex `n` is accepted.

Restrict all edge variables among vertices `1,...,n-1` to one. Under this restriction, greedy accepts all of the first `n-1` vertices. Consequently

`g_n(Y) = product_{j=1}^{n-1} Y_{j,n}`

on the restricted Boolean cube.

The multilinear representation of a Boolean-cube function is unique. The restricted function is the AND monomial of `n-1` variables and therefore has exact polynomial degree `n-1`. Restriction cannot increase degree. Thus any polynomial which is **equal as a real-valued function** to the literal 0/1 greedy-selection indicator must have degree at least `n-1`.

This is an obstruction to the most literal algebraization, not to the source problem. It does **not** say that a real polynomial whose **threshold** at `1` realizes or approximates the same decision has degree `n-1`; indeed AND itself has linear threshold degree. The source's threshold semantics are therefore precisely the loophole a successful construction must exploit.

Outcome B2: **literal exact-value greedy polynomialization is exhausted; threshold/approximate representations remain viable.**

## 4. B14 — the group action is useful, but deterministic averaging is invalid

Let `S_n` act on graph inputs by relabeling vertices and on `R^n` by permuting coordinates. For `pi in S_n`, define the conjugate polynomial

`f^pi(Y) = pi f(pi^{-1} Y)`.

Conjugation only permutes variables and coordinates, so

`deg(f^pi)=deg(f)`.

Because `G(n,1/2)` is invariant under vertex relabeling and the clique rounding rule above is equivariant, `f^pi` has exactly the same distribution of clique size and mistake count as `f`. Therefore a uniformly random `pi` gives an `S_n`-invariant **distribution over degree-D polynomials** with unchanged success probability.

What fails is deterministic Reynolds averaging. Let `n=2` and take the constant polynomial `f=(1,0)`. Its threshold set is the singleton `{1}`, always a clique, with zero mistakes. Averaging with its coordinate-swapped conjugate gives

`f_bar=(1/2,1/2)`.

Since the selection threshold is `>=1`, `f_bar` selects no vertex. Thus deterministic averaging can destroy the objective even though it preserves degree.

The exact self-check archived this finite witness with rational arithmetic.

Outcome B14: **random orbit symmetrization is justified; deterministic coefficient averaging is not.** A future symmetry reduction must operate on distributions/orbits or prove a stronger preservation lemma.

## 5. B19 — explicit low-degree selector for the first k-clique

This is the substantive new construction.

### Theorem 5.1 — exact zero-error selector

For every integers `n>=k>=1`, there is an explicit deterministic polynomial

`f_{n,k}:{0,1}^{binom(n,2)} -> R^n`

of degree at most

`2 binom(k,2) = k(k-1)`

such that on **every** graph `G`:

1. if `G` contains a `k`-clique, the Definition-1.1-style threshold rounding of `f_{n,k}` returns exactly one `k`-clique;
2. if `G` contains no `k`-clique, the rounded output is empty;
3. every coordinate is either `>1` on the selected clique or `<=0` off it, so `B_f=emptyset` and there are zero mistakes for every `eta>=0`.

The selected clique is the first `k`-clique in any fixed explicit ordering of the `k`-subsets.

### Proof

Order all `k`-subsets of `[n]` as

`S_1,...,S_M`, where `M=binom(n,k)`.

For each `j`, let

`I_j(Y)= product_{e in binom(S_j,2)} Y_e`.

On the Boolean cube `I_j` is exactly the indicator that `S_j` is a clique and has degree

`m=binom(k,2)`.

Set

`R=8 M^2`,

`w_j=2 R^(M-j)`.

Define

`g_j(Y)=w_j I_j(Y) (1 - 2 sum_{ell<j} I_ell(Y))`

and, for each vertex `i`,

`f_i(Y)= sum_{j: i in S_j} g_j(Y)`.

Each `g_j` has degree at most `2m`, hence the vector polynomial has degree at most `2m`.

If there is no `k`-clique, every `I_j=0`, so `f=0` and the rounded output is empty.

Now suppose `j_*` is the least index with `I_{j_*}=1`. For `j<j_*`, `g_j=0`, while

`g_{j_*}=w_{j_*}`.

For any later clique `j>j_*`, put

`r_j=sum_{ell<j} I_ell`.

Then `1<=r_j<=M`, so

`-(2M-1) w_j <= g_j <= -w_j`.

Noncliques still have `g_j=0`.

If `i` is not in `S_{j_*}`, its only possible nonzero contributions come from later cliques and are nonpositive; therefore

`f_i<=0`.

If `i` is in `S_{j_*}`, then

`f_i >= w_{j_*} - (2M-1) sum_{j>j_*} w_j`.

The geometric tail obeys

`sum_{j>j_*} w_j < w_{j_*}/(R-1)`.

Since `R=8M^2`,

`(2M-1)/(R-1) < 1/2`.

Thus

`f_i > w_{j_*}/2 >= 1`.

Therefore the threshold set `A_f={i:f_i>=1}` is exactly `S_{j_*}`. It is already a clique, so `A_tilde_f=A_f`, every unselected coordinate is `<=0`, and `B_f` is empty. This proves all clauses. QED.

### Corollary 5.2 — degree O(log n) finds Theta(sqrt(log n)) clique whp

Let

`L=log_2 n`,

`k=floor(sqrt(2L))`.

Then

`deg(f_{n,k}) <= k(k-1) <= 2 log_2 n`,

so the degree is `O(log n)` with an explicit fixed constant.

It remains to show that `G(n,1/2)` has a `k`-clique with high probability. This can be proved without importing the sharp clique-number theorem. Partition at least `floor(n/k)` disjoint vertex blocks of size `k`. Their internal-clique events are independent and each has probability

`p=2^{-binom(k,2)}`.

Since `k^2<=2L`,

`binom(k,2) <= L-k/2`,

and therefore

`p >= n^{-1} 2^{k/2}`.

For all large `n`, the number `q` of disjoint blocks is at least `n/(2k)`, so

`q p >= 2^{k/2}/(2k) -> infinity`.

Hence

`P(no one of the disjoint blocks is a clique) <= exp(-q p) -> 0`.

With probability `1-o(1)`, at least one `k`-clique exists, and Theorem 5.1 returns one with zero rounding errors. Thus an explicit degree-`O(log n)` polynomial achieves

`k=(sqrt(2)+o(1)) sqrt(log_2 n)`

clique vertices with high probability.

This is **PARTIAL**. Because

`k/log_2 n -> 0`,

it proves no positive value of the frozen constant `alpha_LD`.

### Model-scope caveat

The formula has an enormous number of terms and huge coefficients. The source asks for an explicit low-degree multivariate polynomial and cites Definition 1.1, which constrains degree and rounding but not evaluation time or coefficient norm. Under that literal source scope the theorem is valid. It must **not** be upgraded to a Definition-1.2-normalized low-degree algorithm without a separate `E||f||^2` proof.

The mechanism is elementary enough that it may be folklore; the bounded literature check above did not identify this exact selector, but no novelty claim is made.

## 7. What this changes and what remains

New proved facts:

- literal exact-value sequential greedy has degree at least `n-1` on a simple restriction, so it is not the desired polynomialization;
- random `S_n` conjugation preserves degree and success distribution, while deterministic orbit averaging can fail the source threshold semantics;
- there is a completely explicit degree `k(k-1)` zero-error polynomial selector for the first `k`-clique on every graph;
- choosing `k=floor(sqrt(2 log_2 n))` yields a source-valid degree-`O(log n)` polynomial finding a `Theta(sqrt(log n))` clique whp.

Still open:

`alpha_LD>0`, in particular the source goal `alpha_LD=1` corresponding to a `(1-o(1)) log_2 n` or source-scale `log_2 n` clique under the intended rounding semantics.

The exact obstruction exposed by this run is that exact clique indicators cost `binom(k,2)` degree. At `k=Theta(log n)` that is `Theta(log^2 n)`. A successful source-scale construction must exploit the fact that Definition 1.1 thresholds a real polynomial; it cannot simply enumerate cliques with exact indicator monomials.

The most promising next category is therefore **polynomial-threshold / distributional approximation**, not a larger exact clique-indicator enumeration.
