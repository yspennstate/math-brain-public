## 2. B11 — Fourier dualization: an exact sufficient criterion

The source asks for a polynomial whose thresholded output is a clique. A natural way to attack that is to begin with an exact but possibly complicated clique selector and ask whether its low Fourier levels already determine it with overwhelming probability.

Encode `G(n,1/2)` by independent Rademacher edge variables `X_e in {-1,+1}` (an affine change from `{0,1}` preserves degree). Let

`Z(X,omega) in {0,1}^n`

be any random exact selector, with coefficient seed `omega` independent of the graph, such that whenever it succeeds its support is a `k`-clique. Write the Walsh-Fourier expansion coordinatewise and let `Pi_{<=D}` denote projection onto edge monomials of degree at most `D`.

Define the total high-degree energy

`Tail_D(Z) = E_{X,omega} || Z - Pi_{<=D} Z ||_2^2
            = sum_i E_omega sum_{|S|>D} hat Z_i(S;omega)^2.`

### Lemma 2.1 — Fourier-tail-to-source-polynomial bridge

If, for `D=O(log n)`,

`Tail_D(Z)=o(1)`

and `Z` returns a `k`-clique with probability `1-o(1)`, then there exists a deterministic degree-`D` polynomial `f:{0,1}^{binom(n,2)}->R^n` whose Definition-1.1-style threshold rounding returns the same `k`-clique with probability `1-o(1)` and makes zero rounding mistakes on that event.

### Proof

For a fixed seed `omega`, let

`P(X,omega)=Pi_{<=D} Z(X,omega)`

and set

`f(X,omega)=2 P(X,omega)`.

If simultaneously for all coordinates

`|P_i-Z_i|<1/4`,

then when `Z_i=1` we have `f_i>3/2>=1`, and when `Z_i=0` we have `|f_i|<1/2`. Hence thresholding at `1` recovers the support of `Z` exactly and produces no value in `(1/2,1)`.

By the union bound written as an `l_2` Markov estimate,

`P_{X,omega}(exists i: |P_i-Z_i|>=1/4)
 <= 16 E_{X,omega} ||P-Z||_2^2
 = 16 Tail_D(Z)
 = o(1).`

Thus the random degree-`D` polynomial succeeds with probability `1-o(1)`. Averaging over the independent seed `omega`, there is at least one deterministic seed `omega_n` whose graph-failure probability is `o(1)`. Fix that seed. Degree is unchanged. QED.

This is a genuine source-valid reduction: it retains the source's final thresholding semantics rather than silently replacing the problem by detection.

### Noise-stability form

For `rho`-correlated edge configurations, define the vector noise energy

`N_rho(Z)=sum_i E_omega sum_S (1-rho^{|S|}) hat Z_i(S;omega)^2.`

Then

`Tail_D(Z) <= N_rho(Z)/(1-rho^{D+1}).`

So, for example, if `D=C log n` and `rho=1-c/D`, then the denominator is bounded below by a positive constant depending only on `c`, and it would suffice to construct an exact selector with

`N_{1-c/D}(Z)=o(1).`

This criterion is deliberately marked **sufficient, not necessary**. In fact, a hard 0/1 clique selector is plausibly too noise-sensitive at the target `k=Theta(log n)` scale: a `1/Theta(log n)` edge-resampling rate changes `Theta(log n)` of the `Theta(log^2 n)` internal clique edges in expectation. The bridge therefore says what a Fourier-projection route would have to achieve, but it also warns that projecting a discontinuous greedy/lexicographic selector may be the wrong object. A successful construction may need a genuinely margin-valued polynomial rather than the low-degree projection of a hard selector.

Outcome B11: **a rigorous Fourier/noise sufficient condition is now available, but no target-scale selector satisfying it is proved.**

## 3. B15 — break symmetry on purpose, then recover it distributionally

The previous report constructed a zero-error selector of degree `2m`, where `m=binom(k,2)`, by multiplying each clique indicator by a prefix term. That multiplication is unnecessary.

Fix any ordering of the `k`-subsets

`S_1,...,S_M`, `M=binom(n,k)`,

and put

`I_j(Y)=prod_{e in binom(S_j,2)} Y_e`.

Thus `I_j` is exactly the clique indicator and has degree

`m=binom(k,2)`.

Let

`R=8 M^2`,

`w_j=2 R^(M-j)`,

and define the signed candidate score

`h_j(Y)=w_j ( I_j(Y) - 2 sum_{ell<j} I_ell(Y) ).`

Finally set, for every vertex `i`,

`f_i(Y)=sum_{j:i in S_j} h_j(Y).`

### Theorem 3.1 — exact first-clique selector at degree `binom(k,2)`

For every graph `G`, thresholding the above vector at `1` returns exactly the first `k`-clique in the fixed candidate ordering, and returns the empty set if no `k`-clique exists. Every selected coordinate is at least `1`; every unselected coordinate is at most `0`. In particular the Definition-1.1-style rounding has zero mistakes for every tolerance `eta>=0`. The polynomial degree is at most

`binom(k,2)`.

### Proof

Every `h_j` is a linear combination of the degree-`m` clique indicators, so `deg h_j<=m` and `deg f_i<=m`.

If there is no clique, all `I_j=0`, hence all `h_j=f_i=0`.

Otherwise let `j_*` be the first index with `I_{j_*}=1`. For `j<j_*`, `h_j=0`. At `j_*`, the prefix sum vanishes and

`h_{j_*}=w_{j_*}.`

For every `j>j_*`, the prefix contains at least one clique, so

`h_j <= w_j(1-2)=-w_j <=0.`

Also, since the prefix sum is at most `M`,

`h_j >= -2M w_j.`

If `i notin S_{j_*}`, it receives no `j_*` contribution, all earlier contributions vanish, and all later contributions are nonpositive. Hence

`f_i<=0.`

If `i in S_{j_*}`, then

`f_i >= w_{j_*} - 2M sum_{j>j_*} w_j.`

The weights form a geometric tail of ratio `1/R`, hence

`sum_{j>j_*} w_j < w_{j_*}/(R-1).`

Therefore

`f_i > w_{j_*}(1 - 2M/(R-1)).`

With `R=8M^2`, the factor in parentheses is greater than `1/2`, while `w_{j_*}>=2`, so `f_i>1`. Thus the threshold set is exactly `S_{j_*}`. QED.

This halves the algebraic degree of the exact selector from the previous report's `2 binom(k,2)` to `binom(k,2)`. It is still only a `sqrt(log n)`-scale mechanism under the `O(log n)` degree budget: for every fixed constant `c>0`, choosing `k=floor(c sqrt(log_2 n))` gives degree `O(log n)`, and the random graph contains such a clique with high probability because it already contains a greedy clique of order `log_2 n`. But `k/log_2 n ->0`, so `alpha_LD` remains zero.

### Exact `S_n`-invariant randomized version

Now choose the ordering `(S_1,...,S_M)` uniformly at random, independently of the graph. Conditional on any graph containing `r>=1` different `k`-cliques, the first clique in a uniformly random ordering is uniform among those `r` cliques. Therefore Theorem 3.1 gives a random degree-`m` polynomial whose selected clique is exactly uniform among the graph's `k`-cliques.

The joint law is `S_n`-equivariant: relabeling vertices simply relabels a uniformly random ordering of the `k`-subsets. This recovers symmetry **distributionally**, rather than by the invalid deterministic coefficient averaging ruled out in the previous report.

This randomized version does not rely on randomness for success — every ordering succeeds whenever a `k`-clique exists — but it creates a clean symmetric selector that may be a useful test object for Fourier/noise calculations.

## 4. B21 — who else has this shape? Approximate-degree theory kills the uniform-enumeration route

The natural attempt after Theorem 3.1 is to replace each exact degree-`m` clique indicator by a much lower-degree approximation and hope to keep the dominance construction. Vanishing-error approximate-degree theory shows why the most literal version of that idea cannot reach `k=Theta(log n)`.

Consider the following broad architecture.

1. Before seeing the graph, choose a family `F` of `M` candidate `k`-sets, possibly at random but independently of `G`.
2. For each candidate `S`, replace the exact clique indicator

   `I_S = AND_m`, `m=binom(k,2)`,

   by a degree-`d` polynomial `q_S` which **uniformly** approximates `I_S` on all Boolean edge assignments to error at most `epsilon`.
3. Prove correctness by a global dominance/union-bound argument requiring the aggregate candidate approximation error to vanish, e.g. `M epsilon=o(1)`.

### Proposition 4.1 — fixed-candidate uniform-approximation barrier

Any architecture satisfying the three bullets above and having success probability bounded below by a fixed positive constant must use

`d=Omega(k^2)`.

In particular, at `k=alpha log_2 n` for fixed `alpha>0`, it requires degree `Omega(log^2 n)`, not `O(log n)`.

### Proof

A fixed `k`-set is a clique in `G(n,1/2)` with probability

`2^{-m}`.

For any fixed candidate family of size `M`, the union bound gives

`P(exists S in F that is a clique) <= M 2^{-m}.`

The same inequality holds after averaging over a random candidate family chosen independently of the graph. Therefore success probability bounded below by a positive constant forces

`M >= c 2^m`

for some constant `c>0`, hence

`log(1/epsilon) >= log M - o(1) = Omega(m)`

whenever `M epsilon=o(1)`.

Now restrict all graph variables outside one candidate `S`. A uniform approximant `q_S` becomes a degree-`d` polynomial in the `m` internal edge bits uniformly approximating `AND_m` to error `epsilon`. The vanishing-error approximate-degree lower bound for AND gives

`d = Omega(sqrt(m log(1/epsilon)))`

through the relevant error range. Since `log(1/epsilon)=Omega(m)`,

`d=Omega(m)=Omega(k^2).`

QED.

The approximate-degree input is standard polynomial-method literature; one explicit dual lower-bound construction for AND at vanishing error is discussed by Thaler/Bogdanov-Mande-Thaler-Williamson and related work, and the broader dual-polynomial framework appears in Bun-Thaler. The only fact used here is the `Omega(sqrt(m log(1/epsilon)))` lower bound.

### Scope of the barrier

This is **not** a lower bound for the Randomstrasse source problem. It rules out a specific but very natural architecture: a graph-independent candidate list large enough to contain a target clique, plus uniform per-candidate soft indicators whose errors are suppressed by a global union/dominance argument.

It does not rule out:

- distributional rather than uniform approximation;
- adaptive/recursive candidate generation like greedy;
- a margin-valued polynomial that never approximates individual clique indicators;
- correlated error cancellation;
- AMP/message-passing style constructions;
- use of the allowed Definition-1.1 mistake budget in a structured way.

This distinction matters because AND itself has threshold degree one; the obstruction comes from demanding **uniform numerical approximation small enough across exponentially many candidates**, not from the final source threshold.

Outcome B21: **the uniform candidate-enumeration route is exhausted at target scale; the next attack must exploit typical-instance structure or adaptive margins rather than approximate every candidate clique predicate everywhere.**

## 5. Combined diagnosis

The three methods point in the same direction.

- B11 says low-degree Fourier projection would solve the problem if one could build an exact clique selector whose total high-degree energy is `o(1)`, but hard selectors may be too discontinuous/noise-sensitive.
- B15 shows exact candidate enumeration is algebraically cleaner than previously thought — degree `binom(k,2)`, not twice that — yet still intrinsically quadratic in clique size.
- B21 shows that simply softening each of exponentially many candidate indicators uniformly does not repair that quadratic barrier: the error level required for global control forces approximate degree back to `Omega(k^2)`.

So the next route should not be “better enumeration.” It should exploit the **typical** random-graph distribution and the fact that below the greedy threshold the common-neighborhood process has enormous slack.

A promising target is a block-greedy / margin-valued construction for `k=(1-epsilon)log_2 n`: divide the process into stages while the common-neighborhood size remains polynomially large, replace exact first-success decisions by low-degree distributional surrogates, and spend the allowed error budget only on atypical candidate-set fluctuations. Such a construction would not need uniformly accurate clique predicates over `2^{Theta(log^2 n)}` candidate sets and would evade Proposition 4.1 by design.

The next distinct Section-B methods are therefore:

- **B5** — add an explicit edge-noise/softness parameter to a block-greedy surrogate and differentiate its success/margin as the parameter is removed;
- **B9** — randomize the block priorities/partitions first, prove average success with degree tracked, then derandomize the coefficient seed;
- **B28** — replace uniform candidate correctness by a sharply quantified `G(n,1/2)`-typical guarantee and determine exactly how small the exceptional set must be for Definition 1.1 rounding.

No positive-alpha claim is made until the complete degree and rounding analysis reaches `(alpha-o(1))log_2 n` for some fixed `alpha>0`.
