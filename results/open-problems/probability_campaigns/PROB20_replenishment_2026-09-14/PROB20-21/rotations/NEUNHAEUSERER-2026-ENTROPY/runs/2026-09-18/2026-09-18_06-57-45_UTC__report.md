## 3. Exact weighted-sum formulation and curvature identity

At depth four write

`S = w_1 B_1 + w_2 B_2 + w_3 B_3 + w_4 B_4`,

where `w_i>0` and the `B_i` are iid `Bernoulli(p)`. The source is the subfamily in which, after a harmless additive shift and replacing `p` by `1-p`,

`(w_1,w_2,w_3,w_4)=(1,d_1,d_2,d_3)`

with positive integers `d_i=a_{i+1}-a_i`.

For each output value, let `C` be the collision class of subsets of `[4]` producing that value. If

`c_{C,k} = #{A in C : |A|=k}`,

then

`Q_C(p) = sum_{k=0}^4 c_{C,k} p^k (1-p)^(4-k)`

is the probability of that output atom. The Shannon entropy is

`H(p) = - sum_C Q_C(p) log Q_C(p)`.

Since `sum_C Q_C''(p)=0`, direct differentiation gives

`H''(p) = - S_C [ Q_C''(p) log Q_C(p) + (Q_C'(p))^2/Q_C(p) ].`   (3.1)

Define

`F(p) := sum_C [ Q_C'' log Q_C + (Q_C')^2/Q_C ]`.

Then proving concavity is exactly proving `F(p)>=0`; strict positivity gives `H''(p)<0` in the interior.

Complementing every subset sends `S` to `W-S`, where `W=sum_i w_i`, while replacing `p` by `1-p`. Hence the output distribution is reflected and

`H(p)=H(1-p)`.   (3.2)

It therefore suffices to prove strict concavity for `0<p<=1/2`.

# 7. Analytic endpoint tail: `0<p<=1/100000`

The interval certificate deliberately stops away from zero. The endpoint is handled uniformly, with no collision-pattern split.

Let the 16 labeled Bernoulli microstates have probabilities

`f_A(p)=p^{|A|} q^{4-|A|}`,  `q=1-p`.

Write

`T(p)=sum_C Q_C''(p) log Q_C(p)`,

`J(p)=sum_C (Q_C'(p))^2/Q_C(p)`.

Then

`H''(p)=-T(p)-J(p)`.   (7.1)

## 7.1 Uniform upper bound on `|T|`

For a collision class `C`, `Q_C=sum_{A in C} f_A`, so

`|Q_C''| <= sum_{A in C} |f_A''|`.

Also `Q_C>=f_A`, hence `-log Q_C <= -log f_A`. Consequently

`|T| <= sum_A |f_A''| (-log f_A)`.   (7.2)

For `0<p<=1/2`, direct differentiation of the five level-polynomials gives the valid bounds

- level 0: `|(q^4)''| <= 12`;
- level 1: `|(p q^3)''| <= 6`;
- level 2: `|(p^2 q^2)''| <= 2`;
- level 3: `|(p^3 q)''| <= 1`;
- level 4: `|(p^4)''| <= 3`.

With multiplicities `1,4,6,4,1`,

`sum_A |f_A''| <= 12 + 4*6 + 6*2 + 4*1 + 3 = 55`.   (7.3)

Moreover, for every microstate and `p<=1/2`,

`-log f_A <= 4(log(1/p)+1)`,

because `-log(1-p) <= p/(1-p) <=1`. Combining with (7.2)-(7.3),

`|T(p)| <= 220 (log(1/p)+1)`.   (7.4)

## 7.2 Uniform lower bound on `J`

Positivity of the weights makes the zero-output atom unique, with

`Q_0=q^4`,  `Q_0'=-4q^3`.

Keep this class separate and apply Cauchy-Schwarz to all remaining classes:

`J >= (Q_0')^2/Q_0 + ((1-Q_0)')^2/(1-Q_0)`

`   = 16 q^2/(1-q^4)`.   (7.5)

For `p<=1/2`, `q^2>=1/4` and

`1-q^4 = 1-(1-p)^4 <= 4p`,

so (7.5) yields the very simple bound

`J(p) >= 1/p`.   (7.6)

## 7.3 The tail sign

From (7.1), (7.4), and (7.6),

`H''(p) <= 220(log(1/p)+1) - 1/p`.   (7.7)

Set `x=1/p`. For `x>=100000`, the elementary inequality `log x <= sqrt(x)` gives

`H''(p) <= 220(sqrt(x)+1)-x`.

Let `y=sqrt(x)`. Then `y>316`, while `y^2-220y-220` is increasing for `y>110`; at `y=316`,

`316^2 - 220*316 - 220 = 30116 > 0`.

Thus the right side of (7.7) is strictly negative whenever `0<p<=10^-5`.

Together with the exact interval certificate and symmetry (3.2), this proves
