# B11 — DUALIZE: exact positive-kernel geometry for rank three

Let `L` be a rank-three relation space and let `R` be any `3 x 6` matrix whose rows form a basis of `L`. Write its six column vectors as `c_1,...,c_6 in R^3`.

**Exact proposition.**
There exists a strictly positive vector `w=(w_1,...,w_6)>0` with `Rw=0` if and only if
`0` lies in the (three-dimensional) interior of `conv{c_1,...,c_6}`.

**Proof.**
If `Rw=0` with every `w_i>0`, normalize so that `sum_i w_i=1`. Then
`0=sum_i w_i c_i`
is a convex representation using every column with strictly positive coefficient. Since `R` has row rank three, the columns span `R^3`. If zero lay on a supporting hyperplane of their convex hull, equality in the supporting functional together with all `w_i>0` would force every `c_i` into that hyperplane, contradicting the three-dimensional span. Hence zero is an interior point.

Conversely suppose zero is interior. Fix `i`. For sufficiently small `epsilon_i>0`, the point `-epsilon_i c_i` still belongs to the convex hull. Choose a convex representation
`-epsilon_i c_i = sum_j lambda_{ij} c_j`.
Then, with `delta_i=epsilon_i/(1+epsilon_i)>0`,
`0 = delta_i c_i + (1-delta_i) sum_j lambda_{ij} c_j`.
Thus for each coordinate `i` there is a convex representation of zero whose coefficient of `c_i` is positive. Averaging these six representations gives
`0=sum_i w_i c_i`
with every `w_i>0` and `sum_i w_i=1`; equivalently `Rw=0`. QED.

This is the clean Gordan/Farkas geometry behind the positivity filter. It is standard convex/oriented-matroid structure and is **not claimed novel**. It replaces an existential positive-kernel LP by an origin-in-convex-hull condition, but it still does not determine the entropy collision fibers.
