# 2. B3 — prove a stronger block-profile statement, then identify exactly where it stops

The previous report identified a local pseudometric `Gamma`-limit as the desired object. The strongest deterministic statement one can reasonably demand before probability enters is that **boundary-to-boundary block profiles are exact sufficient statistics for global passage**. That statement is true, even with zero weights.

## Theorem 2.1 — exact skeleton composition of block metrics

Let `G=(V,E)` be a finite graph with nonnegative edge weights. Partition the edge set into disjoint deterministic blocks

\[
E=E_1\sqcup\cdots\sqcup E_M.
\]

For block `i`, let `V_i` be the set of endpoints of edges in `E_i`, and let `B_i` consist of all vertices of `V_i` incident to an edge from some other block, together with `s` or `t` when they belong to `V_i`.

For `u,v in B_i`, define the restricted block distance

\[
D_i(u,v)=\inf\{\tau(\gamma):\gamma:u\to v,\ \gamma\text{ uses only edges of }E_i\},
\]

with value `+infinity` when there is no such block path.

Construct the **skeleton graph** `K` whose vertex set is

\[
B=\{s,t\}\cup\bigcup_i B_i,
\]

and, for every block `i` and `u,v in B_i`, has an abstract edge `(u,v;i)` of weight `D_i(u,v)` whenever `D_i(u,v)<infinity`.

Then

\[
\boxed{T_G(s,t)=T_K(s,t).}\tag{2.1}
\]

### Proof

Take any `s-t` path `gamma` in `G`. Split its edge sequence into maximal consecutive runs contained in one `E_i`. The endpoints of every run are in the corresponding `B_i` (except global endpoints, which were explicitly included). Replacing each run by its block distance gives a skeleton walk of no larger cost. Therefore

\[
T_K(s,t)\le T_G(s,t).
\]

Conversely, every finite skeleton edge `(u,v;i)` is realized by a minimizing path inside the finite block `E_i` because edge weights are nonnegative and cycles may be erased. Concatenating the realizing block paths along a skeleton path gives a walk in `G` with exactly the skeleton cost, so

\[
T_G(s,t)\le T_K(s,t).
\]

Thus equality holds. QED.

### Consequence

A correct block-level large-deviation theory does **not** need the microscopic environment after it knows the complete terminal metric profile of every block. This is the exact deterministic gluing object sought in BGS/Verges-type arguments, and it remains valid for pseudometrics with zero distances.

## Why two tempting stronger local principles fail

The theorem also exposes two opposite mistakes.

**Too strong.** If one asks for a lower metric bound on *every lattice pair* inside a block,

\[
D_i(u,v)\ge c\|u-v\|_1\quad\text{for every }u,v,
\]

then for adjacent endpoints of an edge `e={u,v}` the direct edge gives `D_i(u,v)<=tau_e`, hence `tau_e>=c`. The alleged metric condition has collapsed to forcing every edge high; that pays much more entropy than an optimal slow metric need pay.

**Too weak.** If one records only block pairs separated by at least a fixed macroscopic fraction of the block diameter, the skeleton can still contain arbitrarily long chains of cheap **short portal hops**. A global path can alternate blocks/interfaces before any individual hop reaches the tested separation scale. Therefore a macroscopic-pair condition by itself does not imply a global lower passage bound unless the coarse construction also controls transition complexity or supplies a monotone coordinate forcing macroscopic progress.

This is not a counterexample to Question 18. It is a counterexample to the naive claim that a sparse list of macroscopic block distances automatically glues.

**B3 outcome:** the exact full block-profile composition theorem is proved; the missing probabilistic theorem is now specifically an `n^d`-cost LDP/entropy localization for those complete profiles, or a structured profile class that prevents portal hopping without forcing every edge high. No source-clause movement.

# 3. B19 — make the recovery direction into an explicit algorithm

The portal problem disappears if blocks are **nested shells**, because every path from `0` to `ne_1` must make monotone radial progress in the last-exit/first-hit sense. This gives a completely atom-safe multi-shell recovery principle.

Throughout this section let `F` be any bounded non-point-mass law with essential supremum

\[
b:=\operatorname*{ess\,sup}F<\infty.
\]

Let `F_theta` be the exponential tilt already proved atom-safe in the handoff:

\[
\frac{dF_\theta}{dF}(x)=e^{\theta x-\Lambda(\theta)}.
\]

## 3.1 A one-shell path-counting certificate

Fix a desired local slope `0<c<b`. Choose `t` with

\[
c<t<b.
\]

Under `G=F_theta` put

\[
q=q_{\theta,t}:=G([0,t)).
\]

For `lambda>0` define

\[
A=2d\,[q+(1-q)e^{-\lambda}].
\tag{3.1}
\]

Call `(theta,t,lambda)` a **certificate for c** if

\[
A<1,
\qquad
\lambda\frac ct+\log A<0.
\tag{3.2}
\]

Such a finite certificate exists for every `c<b`. Indeed, for fixed `t<b`, exponential tilting sends `q_{theta,t}->0` as `theta->infinity`. Pick

\[
\lambda>\frac{\log(2d)}{1-c/t}.
\]

At `q=0`,

\[
\lambda c/t+\log(2d)-\lambda
=
\log(2d)-\lambda(1-c/t)<0,
\]

so (3.2) holds for all sufficiently large finite `theta`.

### Lemma 3.1 — exponential exclusion of a fast long path

Suppose all edges in a region are iid `G` and `(theta,t,lambda)` certifies `c`. From any fixed starting vertex, for every integer `m>=1`,

\[
\Pr_G\{\exists\text{ a path ending at }\ell_1\text{-distance at least }m
\text{ with passage time }\le cm\}
\le C e^{-\kappa m}
\tag{3.3}
\]

for constants `C,kappa>0` depending only on the certificate and `d`.

### Proof

A fast path may be loop-erased without increasing passage time, so consider a self-avoiding path `gamma` of length `ell>=m`. Let `H_gamma` be the number of its edges whose weight is at least `t`. If `tau(gamma)<=cm`, then

\[
tH_\gamma\le cm,
\qquad
H_\gamma\le(c/t)m.
\]

Since

\[
H_\gamma\sim\operatorname{Bin}(\ell,1-q),
\]

exponential Markov gives

\[
\Pr(H_\gamma\le(c/t)m)
\le
\exp(\lambda(c/t)m)
[q+(1-q)e^{-\lambda}]^\ell.
\]

There are at most `(2d)^ell` self-avoiding paths of length `ell` from a fixed vertex. Summing over `ell>=m`,

\[
\Pr(\exists\text{ fast path})
\le
\frac{\exp\{m[\lambda c/t+\log A]\}}{1-A}
\le Ce^{-\kappa m}
\]

by (3.2). QED.

## 3.2 Disjoint radial shells

Let

\[
0=r_0<r_1<\cdots<r_K\le1
\]

and choose slopes `c_j in (0,b)`. Put

\[
m_j=\lfloor r_j n\rfloor.
\]

Partition edges by radial level: shell `j` contains every nearest-neighbour edge `e={x,y}` for which

\[
m_{j-1}\le\min(\|x\|_1,\|y\|_1)\le m_j-1.
\tag{3.4}
\]

These edge sets are disjoint. Give shell `j` iid law `F_{theta_j}`, where `(theta_j,t_j,lambda_j)` certifies `c_j`; leave all other edges at the original law `F`. Call the resulting product measure `Q_n`.

For any path from `0` to `ne_1`, let `tau_j` be its first hit of the sphere `||x||_1=m_j`, and let `sigma_j` be its **last** visit to the sphere `||x||_1=m_{j-1}` before `tau_j`. The segment from `sigma_j` to `tau_j` uses only shell-`j` edges. Its endpoints have `ell_1` separation at least

\[
m_j-m_{j-1}.
\]

Moreover these extracted shell segments are ordered and edge-disjoint as path segments.

By Lemma 3.1, union-bounding over the `O(n^{d-1})` possible entry vertices of a shell,

\[
Q_n\{\text{shell }j\text{ admits such a crossing of cost}\le c_j(m_j-m_{j-1})\}
\le C_j n^{d-1}e^{-\kappa_j(m_j-m_{j-1})}.
\tag{3.5}
\]

Hence, if every shell width `r_j-r_{j-1}` is positive, with `Q_n`-probability `1-e^{-Omega(n)}` every path from `0` to `ne_1` pays more than

\[
\sum_{j=1}^Kc_j(m_j-m_{j-1}).
\tag{3.6}
\]

## Theorem 3.2 — radial multi-tilt recovery bound

Fix a source threshold `a<b`. Suppose the finite radial control satisfies

\[
\sum_{j=1}^Kc_j(r_j-r_{j-1})>a.
\tag{3.7}
\]

Then for all sufficiently large `n`, under `Q_n`,

\[
Q_n\{T(0,ne_1)>an\}=1-e^{-\Omega(n)}.
\tag{3.8}
\]

Let

\[
v_d=\operatorname{Vol}\{x\in\mathbb R^d:\|x\|_1\le1\}=\frac{2^d}{d!}.
\]

The number of lattice edges inside the `ell_1` ball of radius `rn` satisfies

\[
|E(B_1(rn))|=d v_d r^d n^d+O(n^{d-1}),
\tag{3.9}
\]

and therefore

\[
\frac1{n^d}D(Q_n\|P)
\longrightarrow
 d v_d\sum_{j=1}^K
(r_j^d-r_{j-1}^d)
D(F_{\theta_j}\|F).
\tag{3.10}
\]

By data processing through the event in (3.8),

\[
\boxed{
\limsup_{n\to\infty}
-\frac1{n^d}\log P\{T(0,ne_1)>an\}
\le
 d v_d\sum_{j=1}^K
(r_j^d-r_{j-1}^d)
D(F_{\theta_j}\|F).
}
\tag{3.11}
\]

### Proof of the entropy step

Write `A_n={T(0,ne_1)>an}` and `q_n=Q_n(A_n)`. By (3.8), `q_n->1`. Product relative entropy gives (3.10). Binary data processing gives

\[
D(Q_n\|P)
\ge
D(\operatorname{Bern}(q_n)\|\operatorname{Bern}(P(A_n)))
\ge
q_n\log\frac1{P(A_n)}-h(q_n).
\]

Divide by `n^d`, use `q_n->1` and `h(q_n)=o(n^d)`, and obtain (3.11). QED.

## 3.3 Explicit finite-dimensional variational program

Define the one-slope certificate cost

\[
\mathcal H_F(c)=
\inf D(F_\theta\|F),
\tag{3.12}
\]

where the infimum is over all finite triples `(theta,t,lambda)` satisfying `c<t<b` and (3.2). The existence argument above shows

\[
\mathcal H_F(c)<\infty\qquad(0<c<b).
\]

Theorem 3.2 yields the computable radial recovery envelope

\[
\boxed{
\overline R_F(a)
:=\limsup_n-n^{-d}\log P(T(0,ne_1)>an)
\le
 d v_d
\inf
\left\{
\sum_{j=1}^K(r_j^d-r_{j-1}^d)\mathcal H_F(c_j):
\sum_jc_j(r_j-r_{j-1})>a
\right\}.
}
\tag{3.13}
\]

The infimum is over arbitrary finite radial step controls. This is a genuine constructive algorithm: choose a target slowdown, optimize finitely many shell radii/slopes, recover each slope by an atom-safe exponential tilt, and obtain an explicit `n^d` entropy upper bound.

The previous one-ball tilt is the special case `K=1`. The multi-shell form reveals why an inhomogeneous recovery profile can be cheaper: strong slowdown can be placed nearer the origin, where the changed volume is smaller.

### A simple near-zero consequence

In the residual regime (1.1), `mu(e_1)=0`. Fix any `c_0 in (0,b)` and one finite certificate for `c_0`. For every sufficiently small `a<c_0`, choose a single shell of radius `r>a/c_0`. Then

\[
\overline R_F(a)
\le C(F,c_0,d)a^d.
\tag{3.14}
\]

Thus the upper rate envelope in the zero-time-constant regime vanishes at most at order `a^d` as the threshold tends to zero. This is still an envelope bound, not rate existence.

**B19 outcome:** SUCCESS as an explicit, atom-safe `Gamma`-limsup/recovery family for radial quotient-metric slowdowns. It proves an optimized upper bound on the rate envelope but not the matching `Gamma`-liminf, hence no source-clause movement.

# 4. B30 — one direction/scale at a time: stress tests and the new residual decomposition

## 4.1 Bernoulli `0/1` stress class: an explicit all-noise-style radial bound

Take

\[
F=p\delta_0+(1-p)\delta_1,
\qquad p\ge p_c(\mathbb Z^d),
\]

so `mu=0`. Put `q=1-p`. Fix `0<a<1`. For any `r>a`, force **every** edge inside `B_1(rn)` to have weight `1`. Every path from `0` to `ne_1` must first leave that ball and therefore pays at least `rn+O(1)>an` for large `n`.

The forcing event has probability

\[
q^{|E(B_1(rn))|}.
\]

Using (3.9) and then `r downarrow a`,

\[
\boxed{
\limsup_{n\to\infty}
-\frac1{n^d}\log P\{T(0,ne_1)>an\}
\le
 d v_d a^d\log\frac1{1-p}.
}
\tag{4.1}
\]

This is deliberately a crude stress certificate, not a proposed exact rate. It shows concretely the endpoint-local `a^d` geometry and supplies a finite upper envelope even when infinitesimal tilting is completely flat at the level of the time constant.

## 4.2 Supercritical zero atom: exact reduction to endpoint access cost

Assume now strictly

\[
F(\{0\})>p_c.
\]

Let `C_infinity` be the unique infinite cluster of zero-weight edges, and define the access cost

\[
A(x)=\inf_{z\in C_\infty}T(x,z).
\tag{4.2}
\]

Because any two vertices of `C_infinity` are connected at zero passage cost,

\[
\boxed{T(x,y)\le A(x)+A(y).}\tag{4.3}
\]

### Proof

For any `eta>0`, choose `z,w in C_infinity` with

\[
T(x,z)\le A(x)+\eta,
\qquad
T(y,w)\le A(y)+\eta.
\]

Since `T(z,w)=0`, the triangle inequality gives

\[
T(x,y)\le A(x)+A(y)+2\eta.
\]

Let `eta downarrow0`. QED.

Consequently, for every `lambda in (0,1)`,

\[
\boxed{
\{T(0,ne_1)>an\}
\subseteq
\{A(0)>\lambda an\}
\cup
\{A(ne_1)>(1-\lambda)an\}.
}
\tag{4.4}
\]

By stationarity,

\[
P\{T(0,ne_1)>an\}
\le
P\{A(0)>\lambda an\}
+
P\{A(0)>(1-\lambda)an\}.
\tag{4.5}
\]

There is also the exact one-sided implication

\[
\boxed{
\{A(0)>an\}\cap\{ne_1\in C_\infty\}
\subseteq
\{T(0,ne_1)>an\},
}
\tag{4.6}
\]

because, when `ne_1 in C_infinity`, the target itself is one competitor in the infimum defining `A(0)`, so `A(0)<=T(0,ne_1)`.

Equations (4.4)–(4.6) isolate a new, simpler subproblem for the **strictly supercritical** portion of (1.1): determine the `n^d` large-deviation rate for the one-point access variable `A(0)>an`, and prove an exponential-scale localization/decorrelation statement showing that conditioning on a large access barrier near one endpoint does not create an additional `Theta(n^d)` penalty for the distant endpoint to belong to `C_infinity`.

This is closely aligned with the endpoint-localization picture in the chemical-distance literature, but it is not supplied by that literature for the present weighted `n^d` problem.

The critical boundary

\[
F(\{0\})=p_c
\]

has no infinite zero cluster and is **not** covered by this access reduction. It remains a genuinely distinct residual regime.

## 4.3 Why the `ell_1` radial choice is not arbitrary within homothetic barriers

The shell recovery above used `ell_1` balls. Consider instead a centrally symmetric convex body `K` with Minkowski norm `||.||_K`, normalized so the target direction lies at unit gauge. Suppose

\[
\|x\|_K\le L\|x\|_1.
\tag{4.7}
\]

Then

\[
L^{-1}B_1\subseteq K,
\qquad
\operatorname{Vol}(K)L^d\ge v_d.
\tag{4.8}
\]

A gauge increase `Delta r` only guarantees `ell_1` displacement at least `Delta r/L`, while the number of modified edges in a homothetic shell is asymptotic to `d Vol(K)` times the shell volume factor. Thus, after rescaling the required local slope to compensate for the factor `L`, the basic volume-efficiency factor is bounded below by

\[
\operatorname{Vol}(K)L^d\ge v_d,
\]

with equality for the `ell_1` ball. So among this natural class of symmetric homothetic shell foliations, the `ell_1` radial construction is already volume-optimal at the purely geometric level.

This does **not** imply that the true rare environment is radial or homothetic; anisotropic/nonhomothetic pseudometric profiles may be cheaper. It only rules out a gratuitous geometric improvement within this restricted recovery family.

**B30 outcome:** SUCCESS in splitting the residual class into a strictly-supercritical endpoint-access problem plus a separate critical boundary, and in producing a sharp geometric rationale for the radial recovery family. No source-clause movement.
