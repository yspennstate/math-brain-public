# 2. B8 — binary potential duality removes the finite-volume dependence obstruction

The cycle-1 blocker asked for an approximate tensorization statement of the form

\[
\text{global slow profile cost}
\ge
\sum \text{local block costs}-o(n^2).
\]

For binary passage times in a **finite graph**, this can be proved exactly up to a boundary-state count. The correct variable is not a family of cutsets but an integer shortest-path potential.

## Theorem 2.1 — exact potential representation and block tensorization

Let `G=(V,E)` be a finite connected graph. Give every edge an independent capacity/passage cost

\[
c_e\in\{0,1\},\qquad \Pr(c_e=1)=q\in(0,1).
\]

Let `s,t in V`, let `d_c(s,t)` be the minimum `c`-cost of an `s`–`t` path, and let `k` be a nonnegative integer.

Then

\[
\boxed{
d_c(s,t)\ge k
\iff
\exists\,\varphi:V\to\{0,1,\ldots,k\}
\text{ with }
\varphi(s)=0,\ \varphi(t)=k,
\ |\varphi(u)-\varphi(v)|\le c_{\{u,v\}}
\text{ for every edge.}}
\tag{2.1}
\]

Now partition the edge set into pairwise disjoint blocks

\[
E=E_1\sqcup\cdots\sqcup E_M.
\]

Let `V_i` be the vertices incident to `E_i`, and let `S` contain `s,t` plus every vertex belonging to at least two of the `V_i`. For a boundary trace

\[
\beta:S\to\{0,\ldots,k\},\qquad \beta(s)=0,\quad\beta(t)=k,
\]

let `A_i(beta)` be the event that there exists a local potential on `V_i`, extending `beta` on `S cap V_i`, and satisfying the edge inequalities on `E_i`.

Then

\[
\boxed{
\{d_c(s,t)\ge k\}
=
\bigcup_{\beta}
\bigcap_{i=1}^M A_i(\beta).
}
\tag{2.2}
\]

Since the `A_i(beta)` depend on disjoint edge sets, for fixed `beta` they are independent. Therefore

\[
\boxed{
\max_{\beta}\prod_i\Pr(A_i(\beta))
\le
\Pr(d_c(s,t)\ge k)
\le
(k+1)^{|S|}
\max_{\beta}\prod_i\Pr(A_i(\beta)).
}
\tag{2.3}
\]

Equivalently, with

\[
I_i(\beta):=-\log\Pr(A_i(\beta)),
\]

we have the exact deterministic sandwich

\[
\boxed{
\min_{\beta}\sum_i I_i(\beta)-|S|\log(k+1)
\le
-\log\Pr(d_c(s,t)\ge k)
\le
\min_{\beta}\sum_i I_i(\beta).
}
\tag{2.4}
\]

### Proof

If a feasible `varphi` exists, every `s`–`t` path `gamma=(v_0=s,...,v_m=t)` satisfies

\[
k
=|\varphi(t)-\varphi(s)|
\le
\sum_{j=1}^m|\varphi(v_j)-\varphi(v_{j-1})|
\le
\sum_{e\in\gamma}c_e,
\]

so `d_c(s,t)>=k`.

Conversely, if `d_c(s,t)>=k`, define

\[
\varphi(v)=\min\{k,d_c(s,v)\}.
\]

The triangle inequality for the shortest-path metric gives

\[
|\varphi(u)-\varphi(v)|\le c_{\{u,v\}}
\]

on every edge, while `varphi(s)=0` and `varphi(t)=k`. This proves (2.1).

For (2.2), a global feasible potential has a trace `beta` on `S` and restricts to a local feasible potential on every block. Conversely, if every block has an extension with the **same** trace `beta`, the local potentials paste into a well-defined global potential because the blocks share values only on `S`, and every edge belongs to exactly one block. This proves (2.2).

For a fixed trace `beta`, the block events are independent because the edge sets are disjoint. Taking one term gives the lower bound in (2.3); taking the union bound over at most `(k+1)^{|S|}` traces gives the upper bound. Taking negative logarithms gives (2.4). QED.

## Mesoscopic consequence

Tile a square of diameter `Theta(n)` by squares of side `L=L_n`, assigning every edge to one block. The interface vertex count satisfies

\[
|S|\le C\frac{n^2}{L}+O(n).
\]

For the point-to-point Bernoulli problem `k<=n`. Hence the entire boundary-state penalty in (2.4) is bounded by

\[
|S|\log(n+1)
\le
C\frac{n^2\log n}{L}+O(n\log n).
\]

Choosing

\[
\log n\ll L_n\ll n
\]

gives

\[
\boxed{|S|\log(n+1)=o(n^2).}
\tag{2.5}
\]

Thus, in a finite box, the global Bernoulli slow-passage event is, at the correct volume scale, **exactly a minimum of sums of independent local extension costs plus `o(n^2)`**.

This directly resolves one part of the stuck report's Item (c)(3): in the binary finite-volume stress case, long-range dependence generated by conditioning can be encoded by an interface trace whose combinatorial entropy is sub-volume. It does **not** yet identify the limiting local cost or prove the infinite-volume point-to-point rate.

The mechanism is the shortest-path analogue of Théret's discrete stream boundary conditions. For Bernoulli capacities no capacity discretization is needed: the potential itself is integer-valued.

# 3. B13 — the outer-radius circuit count is a quantitative monovariant

The remaining point-to-point event lives on the infinite lattice. In two dimensions there is a second exact structure.

Assume

\[
F=p\delta_0+(1-p)\delta_1,
\qquad p>1/2,
\qquad q:=1-p<1/2.
\]

Call a dual edge `q-open` when its crossed primal edge has passage time `1`. These dual edges form subcritical bond percolation.

For Bernoulli `0/1` FPP in the plane, the deterministic planar cutset/circuit representation says that the passage time between two sets equals the maximum number of pairwise edge-disjoint positive dual circuits separating them. This is the same combinatorial mechanism used in the critical-FPP literature; its validity is deterministic and does not depend on the parameter being critical.

Let

\[
T_n:=T(0,ne_1).
\]

For `R>2`, let `N_{n,R}` be the maximum number of pairwise edge-disjoint `q`-open dual circuits that separate `0` from `ne_1` and are contained in the square

\[
\Lambda_{Rn}:=[-Rn,Rn]^2.
\]

Then `N_{n,R}` is nondecreasing in `R`, and configuration by configuration

\[
N_{n,R}\uparrow T_n.
\]

The useful point is a volume-speed quantitative version.

## Theorem 3.1 — superexponential localization after linear slack

For every `delta>0`, there exist constants `c_q,C_q>0`, depending only on `q<1/2`, such that for all `R>2` and all sufficiently large `n`,

\[
\boxed{
\Pr\{T_n-N_{n,R}\ge \delta n\}
\le
2^n\left(C_qe^{-c_q(R-1)n}\right)^{\lceil\delta n\rceil}.
}
\tag{3.1}
\]

In particular,

\[
\boxed{
\limsup_{n\to\infty}\frac1{n^2}
\log\Pr\{T_n-N_{n,R}\ge\delta n\}
\le
-c_q\delta(R-1),
}
\tag{3.2}
\]

and the right-hand side tends to `-infinity` as `R->infinity`.

### Proof

Take the fixed straight primal path `L_n` from `0` to `ne_1`. Every dual circuit separating its endpoints must cross `L_n`. Hence each separating circuit contains at least one dual edge crossing one of the `n` primal edges of `L_n`.

Suppose `T_n-N_{n,R}>=m`. Choose a maximum edge-disjoint family of `T_n` separating positive dual circuits. At most `N_{n,R}` members of this family are contained in `Lambda_{Rn}`, so at least `m` are not contained in that box.

For each such non-contained circuit, choose one of its dual edges crossing `L_n`. Because the circuits are edge-disjoint, the chosen crossing edges are distinct. Following the circuit from that crossing edge until it exits `Lambda_{Rn}` produces a `q`-open dual path of Euclidean/graph length at least `(R-1)n-O(1)`. The resulting `m` long paths are edge-disjoint.

Subcritical bond percolation on the square lattice has exponential one-arm decay: for a fixed dual root edge `e`,

\[
\Pr_q\{e\leftrightarrow \partial B(e,L)\}
\le C_qe^{-c_qL}.
\]

For any fixed choice of `m` distinct crossing roots on `L_n`, the event that the corresponding `m` long connections occur edge-disjointly is a disjoint occurrence of increasing events. The BK inequality bounds it by the product of the one-arm probabilities. Summing over root subsets, crudely by `2^n`, yields (3.1). Setting `m=ceil(delta n)` and dividing logarithms by `n^2` gives (3.2). QED.

## Tail sandwich

For every `a in (0,1)` and `delta in (0,a)`,

\[
\boxed{
\Pr\{N_{n,R}\ge an\}
\le
\Pr\{T_n\ge an\}
\le
\Pr\{N_{n,R}\ge(a-\delta)n\}
+
\Pr\{T_n-N_{n,R}\ge\delta n\}.
}
\tag{3.3}
\]

By Theorem 3.1, the second term can be made smaller than `exp(-Mn^2)` for any prescribed `M`, by taking `R` large enough after fixing `delta`.

Therefore the infinite-lattice escape problem is **not** an irreducible volume-order obstruction in the strict supercritical Bernoulli stress case. Up to arbitrarily small threshold slack and a superexponentially small error, the source tail is a finite-box nested-circuit packing problem.

This is a genuine strengthening of the previous recovery map. It does not cover the critical boundary `p=1/2`, where the dual positive edges are critical and the exponential one-arm input fails.

# 4. B20 — why the imported max-flow theorem still does not close the special case

The two facts above remove two previously suspected blockers:

1. finite-volume block dependence can be encoded with `o(n^2)` interface entropy by Theorem 2.1;
2. infinite-volume escape can be suppressed at superexponential `n^2` cost after a linear threshold slack by Theorem 3.1.

And the literature check removes a third suspected blocker: Théret and Dembin–Théret show that max-flow upper-LDP technology itself remains valid for compactly supported capacities even when the typical flow is zero.

The first unresolved step is now genuinely **topological/geometric**.

In a finite planar box, `N_{n,R}` is the maximum number of edge-disjoint positive dual circuits separating two *interior point defects*. To turn those winding circuits into an ordinary source-to-sink flow, one cuts the domain along a branch joining the two defects; the circuits then become paths between the two copies of the cut. On the lattice this produces a perfectly finite discrete `slit-domain` network.

However, the slit has lattice width `O(1)`, hence width `O(1/n)` after macroscopic rescaling. It is not directly one of the fixed Lipschitz source/sink domains to which Dembin–Théret Theorem 1.4 applies. A macroscopic thickening of the slit changes `Theta(eta n^2)` edges. That suggests an `O(eta)` normalized-rate comparison, but the required two-sided comparison has **not** been proved here.

This is the precise point where the black-box port stops:

\[
\boxed{
\text{prove a surface-tension/rate limit for the Bernoulli winding flow in a vanishing-width slit domain,}
}
\tag{4.1}
\]

with stability strong enough to pass first `n->infinity`, then slit width `eta->0`, and finally `R->infinity` / `delta->0` using (3.3).

The finite-potential tensorization theorem gives a second route to the same object: define local block-extension costs for the integer potential and establish a deterministic continuum variational limit for their minimum. Equation (2.4) already proves that the probabilistic interaction correction is `o(n^2)`; the missing part is now the **limit of the minimizing boundary-profile energy**, not control of conditioned dependence.

This is an important negative/diagnostic outcome of B20: another entropy lemma is not the next step. The next actual proof would need either

- a vanishing-slit stability theorem that lets one contract Dembin–Théret's fixed-domain flow LDP to `N_{n,R}`, or
- a complete `Gamma`-limit for the mesoscopic integer-potential energy from (2.4).

Neither is established in this run.
