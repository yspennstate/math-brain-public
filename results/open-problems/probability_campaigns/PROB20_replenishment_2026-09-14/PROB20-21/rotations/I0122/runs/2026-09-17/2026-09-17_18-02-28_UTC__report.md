## 3. Recalled counterexample framework from the previous reports

Assume for contradiction that `P` is a source counterexample. Then every incomparable pair has one orientation with probability strictly greater than `2/3` and the reverse orientation with probability strictly less than `1/3`.

Orient every comparable pair by the poset order and every incomparable pair toward its `>2/3` orientation. The previous run proved that this tournament has no directed triangle: for a directed triangle `x->y->z->x`, the three corresponding comparison events have probabilities each greater than `2/3`, whereas every total order satisfies at most two of the three cyclic comparisons, so their probabilities sum to at most `2`, a contradiction. Hence the tournament is transitive.

Write its unique total order as

\[
v_1\prec_*v_2\prec_*\cdots\prec_*v_n.
\]

Because every actual comparability is oriented by `P`, this total order is itself a linear extension of `P`.

Cut this order at every adjacent incomparable pair. The resulting maximal contiguous blocks

\[
B_1,B_2,\ldots,B_k
\]

are chains in `P`: inside a block every adjacent pair is comparable in the forward direction, and transitivity makes the whole block a chain. By maximality, if

\[
x_i:=\max B_i,\qquad y_i:=\min B_{i+1},
\]

then

\[
x_i\parallel y_i
\]

for every boundary `i=1,...,k-1`. Since `x_i \prec_* y_i`, the counterexample assumption gives

\[
\Pr(x_i<_L y_i)>\frac23.
\tag{3.1}
\]

The previous report only obtained `k>=3`. The goal of this run was to solve the first unresolved block-count case completely.

# 4. B4 — prove the selected special case completely

## The boundary-inversion cover lemma

Let `e=e(P)` be the number of linear extensions. For each block boundary define

\[
E_i:=\{L:x_i<_L y_i\},\qquad
R_i:=\{L:y_i<_L x_i\}=E_i^c.
\]

The key exact observation is

\[
\boxed{\bigcap_{i=1}^{k-1}E_i=\{L_*\}},
\tag{4.1}
\]

where `L_*` is the block-concatenation order

\[
B_1B_2\cdots B_k.
\]

### Proof of (4.1)

Within each `B_i`, the internal order is forced because `B_i` is a chain. If `E_i` occurs then the last element of `B_i` appears before the first element of `B_{i+1}`. Therefore **every** element of `B_i` appears before **every** element of `B_{i+1}`. If all `E_i` occur simultaneously, all of `B_1` precedes all of `B_2`, all of `B_2` precedes all of `B_3`, and so on. Thus the only possible extension is the concatenation `L_*`.

Conversely, `L_*` is exactly the strong-majority total order `v_1,...,v_n`, which is a linear extension of `P`, so it belongs to the intersection. This proves (4.1).

Taking complements gives the exact cover identity

\[
\boxed{
\bigcup_{i=1}^{k-1}R_i=\mathcal L(P)\setminus\{L_*\},
\qquad
\left|\bigcup_{i=1}^{k-1}R_i\right|=e-1.
}
\tag{4.2}
\]

Under the counterexample assumption (3.1), every reverse set satisfies

\[
\boxed{|R_i|<\frac e3.}
\tag{4.3}
\]

Equations (4.2)–(4.3) turn the balance conjecture, on this structural slice, into a finite set-cover obstruction.

## Corollary 4.1 — two blocks are impossible

If `k=2`, (4.2) says `|R_1|=e-1`, while (4.3) says `|R_1|<e/3`. Since the boundary pair is incomparable, swapping it in `L_*` yields a second linear extension, so `e>=2`; then `e-1>=e/2>e/3`, contradiction.

Thus a counterexample cannot have two blocks. (`k=1` would make `P` a chain and is excluded by the source hypothesis.)

## Corollary 4.2 — three blocks are impossible

If `k=3`, (4.2) and the union bound give

\[
e-1\le |R_1|+|R_2|<\frac{2e}{3}.
\]

Hence `e<3`.

But the two block boundaries are incomparable. Starting from `L_*`, swapping the adjacent incomparable pair at the first boundary gives one new linear extension, and swapping the adjacent incomparable pair at the second boundary gives a different new linear extension. Together with `L_*`, this gives `e>=3`, contradiction.

Therefore the exact three-chain-block special case selected in the mandatory stuck report is **completely excluded** from a source counterexample.

This is stronger than simply saying that width two is known: the three blocks give a chain cover of size at most three, but the proof uses the special **contiguous-block structure in the strong-majority order**, not a theorem for arbitrary width-three posets. The general width-three case remains outside what is proved here.

## Corollary 4.3 — four blocks are also impossible

This is the useful B30 extension beyond the originally selected special case.

If `k=4`, there are three reverse sets `R_1,R_2,R_3`. By (4.2),

\[
e-1
=|R_1\cup R_2\cup R_3|
\le |R_1|+|R_2|+|R_3|
<e.
\]

The middle quantity is an integer, so necessarily

\[
|R_1|+|R_2|+|R_3|=e-1
=|R_1\cup R_2\cup R_3|.
\tag{4.4}
\]

Equality of the sum of cardinalities with the union cardinality forces the three sets to be pairwise disjoint.

But the first and third boundary swaps are disjoint. In the canonical extension `L_*`, swap the adjacent incomparable pair `(x_1,y_1)` at boundary 1. The result is a valid linear extension. Boundary 3 is untouched and remains an adjacent incomparable pair, so swap `(x_3,y_3)` as well. The resulting extension is valid and lies in

\[
R_1\cap R_3,
\]

contradicting pairwise disjointness from (4.4).

Therefore `k=4` is impossible as well.

## Theorem 4.4 — block-count obstruction for every source counterexample

Combining the preceding cases:

\[
\boxed{
\text{If a counterexample to the 1/3–2/3 conjecture exists, its transitive}\
\text{strong-majority order has at least five maximal contiguous chain blocks.}
}
\tag{4.5}
\]

Equivalently, the complete structural subclasses `k<=4` are certified source-valid: no counterexample can lie there.

This is a theorem-sized analytic claim, so the proof is written in full above. No finite-only claim is being promoted and no checker was manufactured merely for receipt generation.

# 6. B30 — one block scale at a time: the exact cover formulation beyond four blocks

The same notation gives an exact representation for arbitrary block count `k`. Put `m=k-1` boundaries. Then

\[
\bigcup_{i=1}^{m}R_i=\mathcal L(P)\setminus\{L_*\},
\qquad |R_i|<e/3.
\tag{6.1}
\]

There is also guaranteed overlap coming purely from adjacent-swap geometry. If two boundaries `i,j` are nonadjacent (`|i-j|>=2`), their boundary pairs use disjoint elements. Starting at `L_*`, the two adjacent incomparable swaps commute and produce a valid extension belonging to

\[
R_i\cap R_j.
\tag{6.2}
\]

More generally, every independent set `S` of boundary indices in the path on `{1,...,m}` gives a distinct valid linear extension obtained by simultaneously swapping those disjoint boundary pairs; that extension violates exactly the boundary events indexed by `S` among these canonical single-swap coordinates.

For `m=3` (four blocks), the forced overlap `R_1 cap R_3 != empty` is already incompatible with the zero-overlap forced by (6.1), which is exactly Corollary 4.3.

For `m=4` (five blocks), this first-moment cover argument no longer closes. The independent boundary pairs force at least the three concrete double-swap extensions indexed by

\[
\{1,3\},\quad\{1,4\},\quad\{2,4\},
\]

so the reverse-set cover has nontrivial overlap, but four sets of size `<e/3` have enough total capacity that this alone is not contradictory for arbitrary `e`. This identifies the next exact blocker without inventing another lemma:

\[
\boxed{
\text{For the five-block residual, control the *weighted overlap structure* of the}\
R_i\text{ strongly enough that four }(<e/3)\text{-sets cannot cover }e-1\text{ extensions.}
}
\tag{6.3}
\]

That is now the smallest unresolved block-count case of this route.
