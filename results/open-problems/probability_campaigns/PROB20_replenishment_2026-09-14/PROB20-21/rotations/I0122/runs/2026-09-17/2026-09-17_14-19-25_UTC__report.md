## 2. Mathematical idea before code

The previous run made expected-rank separation a useful statistic, but arbitrary convex-body geometry stalls in the interval

\[
399/1000<d\le 1.
\]

The new idea is to exploit **critical pairs**, where the poset itself gives a canonical injection between the two orientation classes of linear extensions. Instead of asking a general convex body to control a cut, compare linear extensions at every **rank-distance layer** and take two moments of the same layer excess.

This produces a simple exact identity in which the orientation bias is the zeroth moment of a nonnegative sequence and the expected-rank difference is its first moment. The resulting inequality is substantially stronger than the generic shifted-Grünbaum estimate on this structural class and has a direct ideal-lattice certificate.

# B3 — PROVE SOMETHING STRONGER

## 3. Critical pairs and a distance-preserving swap injection

For an element `x`, write

\[
D(x)=\{z:z<_P x\},\qquad U(x)=\{z:x<_P z\}.
\]

An ordered incomparable pair `(x,y)` is **critical** when

\[
D(x)\subseteq D(y),\qquad U(y)\subseteq U(x).
\]

Let `E=e(P)` be the number of linear extensions. For every integer `k>=1`, define

\[
A_k=\#\{L:x<_L y,\ \operatorname{rank}_L(y)-\operatorname{rank}_L(x)=k\},
\]

and

\[
B_k=\#\{L:y<_L x,\ \operatorname{rank}_L(x)-\operatorname{rank}_L(y)=k\}.
\]

### Lemma 3.1 — layerwise critical-swap injection

For every critical pair `(x,y)` and every `k>=1`,

\[
\boxed{A_k\ge B_k.}
\]

Moreover,

\[
\boxed{A_1=B_1.}
\]

### Proof

Take a linear extension counted by `B_k`, so `y` occurs before `x` at distance `k`. Swap only the positions of `x` and `y`.

The moved element `x` goes earlier. Every predecessor of `x` is also a predecessor of `y`, by `D(x)\subseteq D(y)`, and hence was already before the old position of `y`. So moving `x` to that position violates no predecessor constraint.

The moved element `y` goes later. Every successor of `y` is also a successor of `x`, by `U(y)\subseteq U(x)`, and hence was already after the old position of `x`. So moving `y` to that position violates no successor constraint.

No other pair changes relative order. Therefore the swap gives a valid linear extension counted by `A_k`. Swapping the same two positions recovers the starting extension, so the map is injective. Hence `A_k>=B_k`.

When `k=1`, the two elements are adjacent. Because `x` and `y` are incomparable, adjacent swapping is valid in either direction in **every** linear extension. Thus the map is a bijection at layer one and `A_1=B_1`. QED.

## 4. Two moments of one nonnegative excess sequence

Let

\[
p=\Pr(x<_L y)=\frac{\sum_k A_k}{E},\qquad q=1-p,
\]

and let

\[
\mu_x=\mathbb E\operatorname{rank}_L(x),\qquad
\mu_y=\mathbb E\operatorname{rank}_L(y),\qquad
d=\mu_y-\mu_x.
\]

Define

\[
r_k=\frac{A_k-B_k}{E}\ge0.
\]

The layer-one bijection gives `r_1=0`. Therefore

\[
\boxed{p-q=\sum_{k=2}^{n-1} r_k=2p-1}
\]

and, by taking the signed expected rank distance,

\[
\boxed{d=\sum_{k=2}^{n-1}k r_k.}
\]

Because every contributing `k` is between `2` and `n-1`,

\[
2\sum_{k\ge2}r_k
\le
\sum_{k\ge2}k r_k
\le
(n-1)\sum_{k\ge2}r_k.
\]

Hence:

### Theorem 4.1 — critical-pair bias versus expected-rank gap

For every critical pair `(x,y)` in an `n`-element poset,

\[
\boxed{2(2p-1)\le d\le(n-1)(2p-1).}
\]

Equivalently,

\[
\boxed{
\frac12+\frac{d}{2(n-1)}\le p\le\frac12+\frac d4.
}
\]

In particular, the critical orientation automatically has `p>=1/2`.

The upper bound is the useful side for the source problem:

### Corollary 4.2 — a `2/3` expected-rank certificate

If a critical pair satisfies

\[
d=\mu_y-\mu_x\le\frac23,
\]

then

\[
\frac12\le p\le\frac23.
\]

Thus the pair is itself 1/3-balanced.

Consequently any source counterexample must satisfy

\[
\boxed{\mu_y-\mu_x>2/3}
\]

for **every critical pair in its critical orientation**.

This is stronger than the previous generic order-15 shifted-Grünbaum filter `d>399/1000`, but only on the critical-pair subclass. It does not certify all order-15 posets by itself and therefore does not move `n_bal`.

## 5. Exact ideal-lattice certificate: no pair probabilities needed

The theorem above has a direct exact certificate compatible with Gupta's ideal-lattice dynamic program.

Let `F(I)` be the number of ways to build the initial ideal `I`, and let `B(J)` be the number of ways to complete a linear extension after the initial ideal `J`. For a fixed element `x`, define the integer

\[
H_x=
\sum_{\substack{I\in J(P):\ x\notin I,\\I\cup\{x\}\in J(P)}}
(|I|+1)F(I)B(I\cup\{x\}).
\]

Every linear extension has a unique initial ideal consisting of the elements before `x`; if that ideal is `I`, then the rank of `x` is exactly `|I|+1`, and the number of extensions passing through the transition `I -> I union {x}` is `F(I)B(I union {x})`. Hence

\[
\boxed{H_x=E\mu_x.}
\]

For a critical pair `(x,y)`, therefore,

\[
H_y-H_x=E(\mu_y-\mu_x)=Ed.
\]

Corollary 4.2 becomes the exact integer condition

\[
\boxed{3(H_y-H_x)\le2E.}
\]

If this inequality holds for any critical pair, that pair is certified 1/3-balanced.

This is algorithmically different from computing every mutual rank probability: it requires the ordinary extension-count ideal DP, exact rank-sum accumulators, and the critical-pair relation. It could serve as a cheap pre-screen in a targeted order-15 computation before the more expensive all-pairs/triple certificate stages. I do **not** claim that it makes a complete order-15 census feasible under the current compute restrictions.

# B25 — COUNT THE SAME THING TWICE

## 7. The second distance layer forces a slave witness

The moment identities contain more local information than just Theorem 4.1.

Write

\[
s=p-q=2p-1=\sum_{k\ge2}r_k.
\]

Then

\[
d
=2r_2+\sum_{k\ge3}kr_k
\ge2r_2+3\sum_{k\ge3}r_k
=3s-r_2.
\]

Therefore

\[
\boxed{r_2\ge3s-d=3(2p-1)-d.}
\]

### Corollary 7.1 — strict layer-two excess

If a critical pair satisfies

\[
p>2/3,\qquad d\le1,
\]

then

\[
r_2>0,
\]

so

\[
\boxed{A_2>B_2.}
\]

Now use the same critical swap injection specifically at distance two. Since it injects the `B_2` extensions into the `A_2` extensions and the latter set is strictly larger, there is an `A_2` extension outside the image.

Such an extension has the local order

\[
x<_L z<_L y
\]

with exactly one element `z` between the pair. If swapping `x,y` back were valid, this extension would lie in the image of the injection. Therefore the reverse swap is invalid. Since only `z` is crossed, the obstruction must be one of

\[
x<_P z\quad\text{or}\quad z<_P y.
\]

Because `x||y`, transitivity prevents `x<z<y`; hence these cases refine respectively to

\[
x<_P z\ \text{ and }\ z||y,
\]

or

\[
z<_P y\ \text{ and }\ z||x.
\]

This is exactly Peczarski's definition of a **slave** of the ordered incomparable pair `(x,y)`.

Thus:

### Theorem 7.2 — local slave wedge forced by a near critical imbalance

For a critical pair `(x,y)`, if

\[
\Pr(x<y)>2/3
\quad\text{and}\quad
\mu_y-\mu_x\le1,
\]

then there exists a slave `z` appearing between `x` and `y` in a distance-two majority extension.

This is a local three-element witness, not a source closure.

## 8. Combination with the Gold-Partition certificate

Gupta's 2026 paper quotes Peczarski's sufficient condition in the following source-compatible form: if an ordered incomparable pair `(x,y)` has at most one slave and

\[
2e(P+xy)\ge e(P),
\]

then `P` has the Gold Partition property, which implies the 1/3–2/3 conclusion.

For a critical orientation, the swap injection above gives

\[
p=\frac{e(P+xy)}{e(P)}\ge\frac12,
\]

so the numerical half condition is automatic.

Therefore any counterexample to the 1/3–2/3 conjecture must satisfy the stronger combined critical-pair filter

\[
\boxed{
\text{for every critical pair }(x,y):
\quad
\mu_y-\mu_x>2/3
\quad\text{and}\quad
\#\operatorname{slaves}(x,y)\ge2.
}
\]

The second clause follows because a source counterexample cannot have the Gold Partition property, and the first Peczarski certificate would otherwise apply.

The two clauses arise from independent mechanisms: the first is the new layer-moment inequality, the second is an existing Gold-Partition certificate. Their conjunction is the main structural sieve delivered by this run.
