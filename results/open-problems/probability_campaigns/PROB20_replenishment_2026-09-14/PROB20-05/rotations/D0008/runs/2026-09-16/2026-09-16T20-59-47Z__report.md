## 2. Exact source scope recovered

Wang's definition says that `F` is `n`-completely mixable when there exist `X_1,...,X_n` all with law `F` whose sum is almost surely a constant. For finite mean this constant is `n\mu`.

The source's sufficient condition **(b)** in Section 2.2 is exact and will be the frozen class for `n_explicit` in this track:

> If `F` admits a monotone density on its essential support `[a,b]`, with mean `\mu`, then `F` is `n`-CM iff
> \[
> a+\frac{b-a}{n}\le \mu\le b-\frac{b-a}{n}.
> \]

Open Problem 8 then asks, for a distribution satisfying a sufficient condition (explicitly citing (b) as the example), for a possible copula of an `n`-complete mix with margins `F`.

The survey itself emphasizes that the proofs of the monotone-density results are combinatorial/discretization arguments and that the dependence structure hidden in them is unclear. This is precisely the explicitness gap addressed here.

## 3. Counterexample / obstruction first

The recovered rotation mistake gives the first exact obstruction: **the obvious cyclic rearrangement does not even solve the uniform law for `n>=3`**. Therefore any B18/B19 construction must encode the constant-sum constraint, not merely marginal preservation and finite cyclic symmetry.

The obstruction is not that uniform laws lack explicit complete mixes. For example, for `n=3`, with `U~Unif[0,1]`, define

\[
T_1(u)=u,
\qquad
T_2(u)=u+\tfrac12\pmod 1,
\]

and

\[
T_3(u)=
\begin{cases}
1-2u,&0\le u<1/2,\\
2-2u,&1/2\le u\le1.
\end{cases}
\]

`T_1(U),T_2(U),T_3(U)` are each uniform on `[0,1]` and

\[
T_1(U)+T_2(U)+T_3(U)=\frac32
\quad\text{a.s.}
\]

The verification is branchwise: on `[0,1/2)`, the sum is `u+(u+1/2)+(1-2u)=3/2`; on `[1/2,1]`, it is `u+(u-1/2)+(2-2u)=3/2`. The third map is measure-preserving because each of its two affine branches maps an interval of mass `1/2` onto `[0,1]` with slope magnitude 2. Thus the correct search space is broader than a single invertible `n`-cycle.

This uniform construction extends to every `n>=2` by independent concatenation of two-coordinate countermonotone blocks, with one three-coordinate block when `n` is odd. This is only a narrow-family construction and **does not move `n_explicit` for `n>=3`**, because the metric requires a construction uniform over every distribution in source class (b).

## 4. B18 — say the problem in another language

Let `Q=F^{-1}` be the quantile function. An explicit complete mix can be written as a measurable pushforward from one atomless base variable:

\[
U\sim \mathrm{Unif}[0,1],\qquad
X_i=Q(T_i(U)),\quad i=1,\ldots,n,
\]

where every `T_i` is Lebesgue-measure preserving and

\[
\sum_{i=1}^n Q(T_i(u))=n\mu\quad\text{for a.e. }u.
\tag{R}
\]

Thus the copula problem is an **explicit rearrangement problem**. It is not enough to find an `n`-cycle; one needs the weighted orbit/rearrangement identity (R).

A second equivalent language comes from the complete-mix decomposition theorem used in the survey: one seeks an explicit probability measure `h` on the constant-sum hyperplane

\[
H_{n,\mu}=\{(x_1,\ldots,x_n):x_1+\cdots+x_n=n\mu\}
\]

such that the average empirical measure of `(x_1,...,x_n)` under `h` is exactly `F`. Once such an `h` is explicit, randomly permuting the coordinates gives an exchangeable complete mix with all margins `F`. The existence theorem by itself is not an answer to Open Problem 8 because it does not provide `h` for the monotone-density class.

**Outcome B18:** the useful object is either an explicit family of rearrangements satisfying (R), or an explicit mixing measure `h`; the old finite-cycle ansatz is too narrow.

## 5. B19 — make the existence proof an algorithm

For a decreasing density on `[0,1]`, a natural exact decomposition is the layer-cake mixture of uniforms on initial intervals. In Stieltjes form one may write

\[
f(x)=\int_{[x,1]}\frac{1}{r}\,dH(r),
\]

where for smooth `f` the continuous part has density `-r f'(r)` and there is the appropriate endpoint mass. If `R~H`, then `X|R=r ~ Unif[0,r]` and `E[R]=2E[X]=2\mu`.

This looks algorithmic: draw radii, then use an explicit uniform complete mix conditionally. But the constant-sum requirement exposes the missing step. If radii `R_1,...,R_n` are coupled and conditional uniforms are mixed within their intervals, the final sum can be constant only if the radii themselves satisfy a compatible exact allocation constraint. The layer law `H` is not automatically `n`-CM and generally is not covered by the same source theorem. Therefore this decomposition merely **moves the unknown coupling one level upward**; it is not an explicit solution.

A second algorithmic attempt splits one upper-tail draw against `n-1` lower draws, reflecting the combinatorial proof's one-versus-`n-1` geometry. The split point must depend on the realized high value in order to leave exactly the required residual sum. Enforcing all `n-1` remaining marginals simultaneously turns this into a measurable free-boundary / conditional allocation problem. This reproduces the genuine wall from `D0008-A001` rather than hiding it behind a discretization.

**Outcome B19:** no source-general algorithm for `n>=3` was obtained. The precise missing object is an explicit measurable rule solving the residual-sum allocation while preserving each marginal exactly.

## 6. B6 — deform from a source-valid solvable endpoint

The endpoint `n=2` is not just solvable; source condition (b) collapses completely. This gives the first rigorous value of the frozen metric.

### Theorem (complete source-class construction for `n=2`)

Let `F` admit a monotone density `f` on its essential support `[a,b]` and satisfy Wang's condition (b) for `n=2`. Then `F` is the uniform distribution on `[a,b]`. Consequently

\[
(X_1,X_2)
=\bigl(a+(b-a)U,\ a+(b-a)(1-U)\bigr),
\qquad U\sim\mathrm{Unif}[0,1],
\]

is an explicit complete mix: both coordinates have law `F` and `X_1+X_2=a+b=2\mu` a.s. In copula coordinates the copula is exactly the countermonotone copula `W(u,v)=\max(u+v-1,0)`.

### Proof

Condition (b) at `n=2` reads

\[
a+\frac{b-a}{2}\le\mu\le b-\frac{b-a}{2},
\]

so necessarily `\mu=(a+b)/2`.

Affinely normalize `[a,b]` to `[0,1]`; write the normalized density again as `f`, with `\int_0^1 f=1` and mean `\mu=1/2`. The identity

\[
2\left(\mu-\frac12\right)
=
\int_0^1\!\int_0^1
(x-y)(f(x)-f(y))\,dx\,dy
\tag{1}
\]

follows by expanding the double integral. If `f` is nondecreasing, the integrand in (1) is nonnegative everywhere; if `f` is nonincreasing, it is nonpositive everywhere. Since the left side is zero, equality forces `(x-y)(f(x)-f(y))=0` for almost every `(x,y)`. A monotone function with this property is constant a.e. Hence `f=1` a.e. on `[0,1]`, so before normalization `F=Unif[a,b]`.

The displayed pair therefore has both margins `F`; its sum is identically `a+b`. The probability-coordinate vector `(U,1-U)` has copula `W`. QED.

This proves a construction uniformly for **every** member of the exact source condition-(b) class at `n=2`. Therefore the frozen metric is now

\[
\boxed{n_{\mathrm{explicit}}=2.}
\]

This value records the largest source-class-uniform `n` certified in recovered history plus this run. It does **not** assert that `n=3` is impossible; `n=3` is simply not yet certified for the full class.

**Outcome B6:** metric movement from `UNMEASURED/HISTORY_GAP` to `2`. Deforming away from this endpoint immediately introduces nonconstant monotone densities when `n>=3`, and the simple countermonotone pairing no longer closes the sum coordinate-by-coordinate.
