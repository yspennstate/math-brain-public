## 6. B3 — prove a stronger structural statement: a closed one-pole governing family

For beta=2, Rumanov's classical cases are naturally associated with one-pole governing functions. Guided by that mechanism, take the finite-pole ansatz

\[
\boxed{
 b_+(t,x)=-\frac{1+x^2}{x-Q(t)}.
}
\tag{6.1}
\]

This is an ansatz inside the source-specialized governing system; it is not imported as a formula for the gap probability.

Define Rumanov's conserved density

\[
\rho=\frac{b_++v}{\sigma}.
\]

Using (5.3) and (6.1),

\[
\boxed{
\rho
=-\frac1{x-Q}
+\frac{2x}{1+x^2}
-r.
}
\tag{6.2}
\]

Rumanov's first governing equation is the conservation law

\[
\partial_t\rho+\partial_xJ=0,
\qquad
J=\partial_xb_+-b_+\rho-2b_1.
\tag{6.3}
\]

Since `r_t=-r`, integrating (6.3) in `x` gives

\[
\boxed{
J=-\frac{\dot Q}{x-Q}-rx+J_0(t),
}
\tag{6.4}
\]

where dot means `d/dt`. Solving (6.3) for `b_1` yields

\[
\boxed{
 b_1
 =-\frac{J_0+rQ}{2}
 +\frac{\dot Q-r(1+Q^2)}{2(x-Q)}.
}
\tag{6.5}
\]

Now substitute (6.1),(6.5) into Rumanov's second governing equation (2.25). After clearing the only pole `(x-Q)^2`, the residual is a quadratic polynomial in `x`. Matching its three coefficients gives

\[
\boxed{
\dot J_0=rQ-r^2(1+Q^2),
}
\tag{6.6}
\]

\[
\boxed{
J_0
=\frac12\left[
 r^2(1+Q^2)-2rQ-rac{\dot Q^2}{1+Q^2}
\right],
}
\tag{6.7}
\]

and

\[
\boxed{
\ddot Q
=\frac{Q\dot Q^2}{1+Q^2}
+r(1+Q^2)(rQ-1).
}
\tag{6.8}
\]

The system is overdetermined only apparently: differentiating (6.7) and using (6.8) gives (6.6) identically. Hence the governing system has collapsed to one scalar second-order ODE plus the algebraic first integral (6.7).

Now put

\[
Q=\sinh y.
\tag{6.9}
\]

Equation (6.8) simplifies exactly to

\[
\boxed{
\ddot y
=r\cosh y\,(r\sinh y-1).
}
\tag{6.10}
\]

Because `d/dt=-r d/dr`, this is

\[
\boxed{
y_{rr}+\frac1r y_r
=\sinh y\cosh y-\frac1r\cosh y.
}
\tag{6.11}
\]

**B3 outcome:** a stronger object than a single gap ODE is obtained: an explicit beta=2 source-specialized one-pole Lax-compatible family, reduced completely to the scalar auxiliary equation (6.11). The still-unproved issue is physical BVP selection, not algebraic closure of the governing system.

## 7. B30 — solve one coefficient/pole sector at a time, then eliminate the auxiliary variable

The point of the B30 run was to avoid guessing the final Painlevé equation. The three polynomial coefficients generated by Rumanov's governing equation were solved separately, producing (6.6)–(6.8), and only then was the gap logarithmic derivative considered.

Assume, **for this paragraph and the next one only**, that the physical carousel solution `U` is the common solution of the Fokker–Planck equation (5.2) and Rumanov's first-order equation

\[
U_t-b_+U_x+b_1U=0
\tag{7.1}
\]

for the branch above. At `x -> +infinity`, the source boundary gives `U -> G(2r)` and `U_x -> 0`, while (6.5) gives

\[
b_1(\infty)=-\frac{J_0+rQ}{2}.
\]

Therefore

\[
\boxed{
\frac{d}{dt}\log G(2r)=\frac{J_0+rQ}{2}.
}
\tag{7.2}
\]

Define the source-normalized logarithmic derivative

\[
\boxed{
\Sigma(r)=r\frac{d}{dr}\log G(2r).
}
\tag{7.3}
\]

Since `d/dt=-r d/dr`, equations (6.7),(6.9),(7.2) imply

\[
\boxed{
\Sigma(r)
=\frac{r^2}{4}\left(y_r^2-\cosh^2y\right).
}
\tag{7.4}
\]

Now differentiate (7.4) using only the source-specialized auxiliary ODE (6.11). The cancellations are exact:

\[
\boxed{
\Sigma'
=-\frac r2\cosh y\,(\cosh y+y_r),
}
\tag{7.5}
\]

\[
\boxed{
\Sigma''
=-\frac r2\sinh y\,(\cosh y+y_r)^2,
}
\tag{7.6}
\]

and

\[
\boxed{
r\Sigma'-\Sigma
=-\frac{r^2}{4}(\cosh y+y_r)^2.
}
\tag{7.7}
\]

Using `cosh^2 y-sinh^2 y=1`, eliminate `y` from (7.5)–(7.7). One obtains

\[
\boxed{
(r\Sigma'')^2
+4(r\Sigma'-\Sigma)
\left(r\Sigma'-\Sigma+(\Sigma')^2\right)=0.
}
\tag{7.8}
\]

Equation (7.8) is exactly the classical sine-kernel sigma-Painlevé-V equation in the normalization where the small-gap branch begins `Sigma(r) ~ -r/pi`.

**B30 outcome:** the nonlinear elimination is complete. The remaining obstruction has been reduced to a single selection/uniqueness statement, rather than an unknown nonlinear reduction.

## 8. Source normalization: the one free regular branch parameter is exactly the Sine-beta intensity

\tag{8.2}

Substituting (8.2) into the exact Hamiltonian expression for `Sigma` gives

\[
\boxed{
\Sigma(r)=-a r+O(r^2).
}
\tag{8.3}
\]

Now return to the Brownian-carousel source. Valkó–Virág's Proposition 4 identifies the Sine-beta count in `[0,lambda]` with the limiting carousel winding divided by `2 pi`; Proposition 9(vii) gives expected carousel count `(2 pi)^{-1}` times the integral of the drift profile. \[
\frac1{2\pi}.
\tag{8.4}
\]

Consequently, for the simple locally finite Sine-beta process,

\[
G(s)=1-\frac{s}{2\pi}+o(s),

\[
\boxed{
\Sigma(r)
=r\frac{d}{dr}\log G(2r)

\tag{8.5}

Comparing (8.3) and (8.5) fixes the formerly free regular-branch parameter:
