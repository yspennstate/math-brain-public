## 1. Exact target

Let `lambda` be uniform on `[0,1]` and `mu=lambda⊗lambda`. The target is

`W_2^2(mu,pi) <= 1/10`

for every copula `pi` with both marginals `lambda`.

## 2. Exact universal two-sample endpoint certificate

For iid

`P=(A,B), Q=(A',B') ~ pi`,

the crossed point

`Z=(A,B')`

has law `mu=lambda⊗lambda`. Choose as the target endpoint either `P` or `Q`, whichever gives the smaller squared coordinate displacement from `Z`. This preserves target marginal `pi` by exchangeability and gives

`W_2^2(mu,pi) <= 1/6 - J(pi)/2`,

where

`J(pi)=E |(A-A')^2-(B-B')^2|`.                                      (2.1)

Hence

`J(pi)>=2/15`                                                        (2.2)

is sufficient for the conjectured `1/10` bound.

For an `n`-bin positive shuffle with global permutation `p`, write

`d=i-j`, `e=p(i)-p(j)`.

If the within-bin residual difference is `delta=S-T`, then

`(A-A')^2-(B-B')^2`

`= (d-e)(d+e+2delta)/n^2`.

Since `delta` is triangular on `[-1,1]`, define

`psi12(k)=12 E|k+2delta|`.

Direct integration gives

`psi12(0)=8`,
`psi12(±1)=13`,
`psi12(k)=12|k|` for `|k|>=2`.                                      (2.3)

Thus, with

`S12(p)=sum_{i,j}|d-e| psi12(d+e)`,                                 (2.4)

we have the exact rational identity

`J=S12/(12 n^4)`.                                                     (2.5)

Therefore the endpoint certificate is exactly

`5 S12(p) >= 8 n^4`.                                                  (2.6)

No floating-point computation is needed for (2.6).

## 3. Exact cellwise diagonal-residual fallback

For a global `n`-bin permutation `p`, let

`a_i=2i+1-n`.

A balanced assignment sends each source grid cell `(r,s)` to a target branch label `L(r,s)`, with every label used exactly `n` times. The archived cellwise construction couples each source cell residual optimally to the target diagonal residual and yields total transport cost

`C=1/3 - W/(2n^4) - 7/(30n^2)`,                                    (3.1)

where

`W=sum_{r,s}[a_r a_{L(r,s)} + a_s a_{p(L(r,s))}]`.                   (3.2)

Hence an explicit balanced assignment certifies `C<=1/10` whenever

`15W >= 7n^2(n^2-1)`.                                                 (3.3)

The assignment finder used below is SciPy's Hungarian algorithm after replicating every branch label `n` times. Crucially, a successful certificate does not rely on its floating-point optimality: after an assignment is returned, the branch capacities and `W` are recomputed from the integer matrix, and only the exact integer margin

`M_cell=15W-7n^2(n^2-1)`                                             (3.4)

is used.

The four valid positive-shuffle square symmetries used for canonicalization are identity, coordinate swap (`p -> p^{-1}`), 180-degree conjugation, and their composition. All preserve `mu`, Euclidean cost, and the cell certificate by relabeling coordinates/cells/branches.

4. invoke the integer cell certificate only on the final small set;

This should be substantially cheaper than cell-checking every endpoint failure and is the most direct route to a complete ten-bin theorem.
