`J(pi)=E |(A-A')^2-(B-B')^2|`.

Therefore

`J(pi)>=2/15`

is sufficient for the desired `1/10` bound.

For a positive `n`-bin graph shuffle with global permutation `p`, put, for each pair of cell indices,

`d=i-j`, `e=p(i)-p(j)`.

## 4. The two cell residuals are analytically closed

### 4.1 Identity

### 4.2 Positive cell reversal

The permutation

`p_rev(j)=10-j`

is **not** the exact antidiagonal coupling: inside each macro-cell its graph segment still has positive slope. It therefore requires a separate certificate.

For the archived equal-slab block construction, put

`d_j=j-p_rev(j)=2j-10`.

Its displacement statistic is

`D = (1/11) sum_{i<j}|d_i-d_j|`.

Since

`|d_i-d_j|=2|i-j|`

and

`sum_{0<=i<j<=10}(j-i)=11(11^2-1)/6=220`,

we obtain

`D=440/11=40`.

For the full triangular rank law,

`H_B=2/3`, `G_B=7/15`,

so

`G_B/H_B=7/10`.

The exact equal-slab identity at block size `m=11` is

`Delta/h^2 = 55 G_B - D H_B`.

For reversal,

`Delta/h^2 = 55*(7/15) - 40*(2/3)`

`            = 77/3 - 80/3`

`            = -1 < 0`.                                  (4.1)

Thus the explicit equal-slab transport for the positive cell reversal is strictly cheaper than the diagonal benchmark. In particular

`W_2^2(lambda⊗lambda,gamma_{p_rev}) < 1/10`.

This is a useful distinction from the true antidiagonal coupling, which is itself a conjectured/evident equality extremizer.
