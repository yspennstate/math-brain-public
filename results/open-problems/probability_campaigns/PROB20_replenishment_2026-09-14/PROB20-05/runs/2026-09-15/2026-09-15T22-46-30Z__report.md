## 1. Exact target and inherited local transport

For a consecutive block of `m` bins, with global mesh `h=1/n` and diagonal-rank interval

`B=[a,a+mh]`,

write

`U=X+Y-1`, `V=X-Y`.

Conditional on the source band, define

`t=(F_U(U)-a)/(mh)`,
`Q(t)=F_U^{-1}(a+mh t)`,
`A(t)=1-|Q(t)|`,
`z=V/A(t)`.

Then

`t~Unif[0,1]`, `z~Unif[-1,1]`

independently.

The archived displacement-group transport gives an exact cost change

`Delta = -m h^2 [ H_B B_sigma + int_0^1 Q(t) F_sigma(t) dt ]`,

with

`H_B=int_0^1 A(t)dt`,
`G_B=E|Q(T)-Q(T')|`.

If

`A_sigma(s)=int_0^s F_sigma(t)dt`

and

`C_sigma=sup_{0<s<1} A_sigma(s)/(2s(1-s))`,

the archived Stieltjes argument yields

`int Q F_sigma >= -C_sigma G_B`.

Thus

`B_sigma/C_sigma >= G_B/H_B`                                      (1.1)

is sufficient.

## 4. A general two-row domino transport for nonendpoint bands

The endpoint construction has a useful extension that does not require a corner triangle.

For a block starting at global rank `a=k/n`, target branch `j` has rotated coordinates

`U' = 2a-1 + h(j+sigma(j)+2r)`,
`V' = h(j-sigma(j))`.

The diagonal target has

`U_0' = 2a-1 + 2mh t`,
`V_0'=0`.

Because the shuffle block and the diagonal block have the same target second moment, it is enough to compare source-target cross terms. The common constant `(2a-1)E Q` cancels. For a source region assigned to branch `j`, with

`s_j=j+sigma(j)`, `d_j=j-sigma(j)`,

the normalized cross score is

`E[ Q(t)(s_j+2r) + A(t) z d_j ]`.                                  (4.1)

If the same two-row/ten-slab domino partition is used, `t` and `z` remain independent on every source rectangle. Hence each branch-domino score is determined by only six scalar moments:

`E[Q|low]`, `E[A|low]`, `E[Qr|low]`,
`E[Q|high]`, `E[A|high]`, `E[Qr|high]`,

or the corresponding full-band moments for a vertical domino.

After averaging the ten branch scores, the sufficient comparison is

`(1/10) sum_j score_j >= 20 E[Q(t)t]`.                              (4.2)

Equation (4.2) is an exact admissible transport criterion for an arbitrary rank interval, including intervals crossing rank `1/2`.
