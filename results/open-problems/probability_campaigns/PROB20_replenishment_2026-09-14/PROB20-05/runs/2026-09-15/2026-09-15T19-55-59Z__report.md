## 1. Recalled displacement-group transport

Fix global mesh `h=1/n` and a local `m`-bin block with diagonal rank interval

`B=[a,a+mh]`.

In rotated coordinates

`U=X+Y-1`, `V=X-Y`,

original Euclidean squared cost is one half of squared cost in `(U,V)`. Under the independent source, conditional on the block, write

`t=(F_U(U)-a)/(mh)`,
`Q(t)=F_U^{-1}(a+mh t)`,
`A(t)=1-|Q(t)|`,
`z=V/A(t)`.

Then `t~Unif[0,1]`, `z~Unif[-1,1]`, independently.

For a local permutation `sigma in S_m`, branch `j` has displacement

`d_j=j-sigma(j)`.

Group branches having equal displacement `d`. Order the displacement groups increasingly, partition the source `z` interval into consecutive pieces with the same group masses, and within each group monotonically transport the independent horizontal rank `t` onto the union of the target horizontal branch intervals belonging to that displacement.

The preceding checkpoint proves the exact cost identity

`Delta = -m h^2 [ H_B B_sigma + int_0^1 Q(t)F_sigma(t) dt ]`,        (1.1)

where

`H_B=int_0^1(1-|Q(t)|)dt`,

`B_sigma` is the vertical displacement correlation of the ordered groups, and `F_sigma` is a rational piecewise-affine horizontal quantile error with zero integral.

Let

`A_sigma(s)=int_0^s F_sigma(t)dt`,

`C_sigma=sup_{0<s<1} A_sigma(s)/(2s(1-s))`.                          (1.2)

Using Stieltjes integration against increasing `Q`, the same checkpoint proves

`int QF_sigma >= -C_sigma G_B`,                                      (1.3)

where

`G_B=E|Q(T)-Q(T')|`.

Thus the sufficient condition is

`B_sigma/C_sigma >= G_B/H_B`.                                       (1.4)

For a finite permutation, a rational lower bound on `B_sigma/C_sigma` is certified exactly by checking finitely many rational quadratics on the affine pieces of `F_sigma`; no floating-point extremization is required.

## 4. New endpoint domino transport for the 122 hard permutations

The remaining asymptotic obstruction is an eight-bin block touching rank 0 or rank 1. For `n>=16`, its rank mass is

`L=8/n <=1/2`.

Consider the left endpoint. Under the exact diagonal-optimal map, the source preimage of ranks `[0,L]` is the corner triangle

`x>=0`, `y>=0`, `x+y<=R`, `R=sqrt(2L)`.

Scale

`x=R xi`, `y=R eta`.

Conditional on the block, `(xi,eta)` is uniform with density 2 on the standard triangle. Put

`s=xi+eta`,
`z=(xi-eta)/s`,
`t=s^2`.

Then

`t~Unif[0,1]`, `z~Unif[-1,1]`, independently.                        (4.1)

A target branch `j` of the local permutation has normalized coordinates

`(j+r, sigma(j)+r)`, `r~Unif[0,1]`.

For any admissible conditional coupling define the normalized source-target cross score

`Phi = E[ xi(j+r)+eta(sigma(j)+r) ]`.                                (4.2)

The diagonal block has score exactly

`Phi_diag = 2m/5 =16/5`.                                             (4.3)

The diagonal and shuffle target blocks have the same target second moment, so any block coupling with `Phi>=16/5` has no larger quadratic cost than the diagonal-optimal block transport.

### 4.1 The 2 x 8 rectangle partition

Split the horizontal variable `t` into two equal bands

`L_t=[0,1/2]`, `H_t=[1/2,1]`,

and split `z` into eight equal slabs. This creates 16 rectangles, each of conditional mass `1/16`.

A branch receives one of two allowed domino types:

* **horizontal domino:** any two distinct `z` slabs in the same `t` band; map target rank by `r=2t` in the low band or `r=2t-1` in the high band;
* **vertical domino:** the same `z` slab in both `t` bands; map target rank by `r=t`.

Either type gives the branch exactly mass `1/8` and exactly uniform target rank `r`. A partition of all 16 rectangles into eight branch-labelled allowed dominoes is therefore an exact admissible transport.

The exact moments are

`E[s|L_t]=sqrt(2)/3`,
`E[s r|L_t]=sqrt(2)/5`,

`E[s|H_t]=(4-sqrt(2))/3`,
`E[s r|H_t]=4/15+2sqrt(2)/15`,

`E[s|full]=2/3`,
`E[s r|full]=2/5`.                                                    (4.4)

The mean of `z` slab `q=0,...,7` is

`z_q=(2q-7)/8`.                                                       (4.5)

Hence every branch-domino score is an exact element of `Q(sqrt(2))`:

`Phi_{j,D} = (1/2)[(j+sigma(j))E s + 2E(sr) + (j-sigma(j))E s E(z|D)]`. (4.6)

The block score is the average over the eight branches.

### 4.2 Exact finite endpoint certificate

For each of the 122 permutations failing the `2/5` displacement-group threshold, a finite 0-1 assignment problem over the 16 source rectangles finds a branch-labelled domino partition. The numerical MILP is used only to FIND a partition. The returned object is then checked exactly:

* every pair is one of the allowed horizontal/vertical dominoes;

All 122 certificates succeed.

Thus every one of the 122 endpoint-hard indecomposable permutations has strictly smaller cost than the diagonal for every `n>=16`. The remaining indecomposable permutations already satisfy the displacement-group threshold at `2/5`; an endpoint triangular quantile has exactly `G_B/H_B=2/5`, so they are also proved.
