## 2. Recalled displacement-group transport

Fix global mesh `h=1/n` and a consecutive local block of `m` bins with diagonal rank interval

`B=[a,a+mh]`.

Use

`U=X+Y-1`, `V=X-Y`.

Conditional on the source diagonal-rank band, set

`t=(F_U(U)-a)/(mh)`,
`Q(t)=F_U^{-1}(a+mh t)`,
`A(t)=1-|Q(t)|`,
`z=V/A(t)`.

Then

`t~Unif[0,1]`, `z~Unif[-1,1]`

independently.

For a local permutation `sigma`, branches with the same displacement

`d_j=j-sigma(j)`

are grouped. Ordering displacement groups in `z` and transporting the independent horizontal rank `t` monotonically to the union of horizontal target intervals gives the exact cost identity

`Delta = -m h^2 [ H_B B_sigma + int_0^1 Q(t)F_sigma(t) dt ]`,        (2.1)

where

`H_B=int_0^1 A(t)dt`,
`G_B=E|Q(T)-Q(T')|`.

Let

`A_sigma(s)=int_0^s F_sigma(t)dt`

and

`C_sigma=sup_{0<s<1} A_sigma(s)/(2s(1-s))`.

The archived Stieltjes/convex-order argument gives

`int Q F_sigma >= -C_sigma G_B`.

Therefore the local shuffle is certified whenever

`B_sigma/C_sigma >= G_B/H_B`.                                      (2.2)

For a fixed finite permutation and rational threshold, (2.2) is checked exactly by finitely many rational quadratic inequalities on the affine pieces of `F_sigma`.

## 4. New 2 x 9 endpoint-domino transport

Assume the nine-bin block touches the left endpoint and

`L=9/n <= 1/2`,

so `n>=18`.

Under the exact diagonal-optimal map, the source preimage of ranks `[0,L]` is a corner triangle. After scaling,

`x=R xi`, `y=R eta`, `R=sqrt(2L)`,

the conditional source is uniform with density 2 on

`xi>=0`, `eta>=0`, `xi+eta<=1`.

Set

`s=xi+eta`,
`z=(xi-eta)/s`,
`t=s^2`.

Then

`t~Unif[0,1]`, `z~Unif[-1,1]`

independently.

A target branch `j` has normalized target coordinates

`(j+r, sigma(j)+r)`, `r~Unif[0,1]`.

Define the normalized source-target cross score

`Phi=E[ xi(j+r)+eta(sigma(j)+r) ]`.

Because the diagonal and shuffle blocks have the same target second moment, a conditional coupling with

`Phi >= Phi_diag`

cannot cost more than the diagonal-optimal transport on the block. Direct integration gives

`Phi_diag=2m/5=18/5`.                                                (4.1)

### 4.1 Domino partition

Split `t` into two halves and `z` into nine equal slabs, giving 18 equal-mass rectangles.

Each of the nine target branches receives exactly one allowed domino:

1. a horizontal domino consisting of any two distinct `z` slabs in the low `t` half, with target rank `r=2t`;
2. a horizontal domino in the high `t` half, with target rank `r=2t-1`; or
3. a vertical domino using the same `z` slab in both halves, with target rank `r=t`.

Every allowed domino has conditional mass `1/9`, and under the displayed rank map its target parameter `r` is exactly uniform on `[0,1]`. Thus any exact partition of the 18 rectangles into nine branch-labelled allowed dominoes is an admissible block transport.

The moments are

`E[s|low]=sqrt(2)/3`,
`E[s r|low]=sqrt(2)/5`,

`E[s|high]=(4-sqrt(2))/3`,
`E[s r|high]=4/15+2sqrt(2)/15`,

`E[s|full]=2/3`,
`E[s r|full]=2/5`.

The mean of `z` slab `q=0,...,8` is

`z_q=(2q-8)/9`.

Therefore every branch-domino score lies exactly in `Q(sqrt(2))`.

A finite binary assignment is used only to FIND a domino partition. Each returned partition is then checked independently with exact arithmetic:

- all 18 source rectangles occur exactly once;

All `1730` endpoint-hard permutations passed this exact certificate check in the split verification run.

Hence every endpoint-hard indecomposable nine-bin permutation has strictly smaller transport cost than the diagonal for every `n>=18`. The remaining indecomposable endpoint permutations already pass the displacement-group threshold `2/5`.
