## w393

**L1 — KEEP, deterministic reduction.** Write `B_n=[-n,n]^2`, `S_n=∂B_n`, and let `E_n` mean a shortest path in the *induced finite graph* `B_n` between two distinct `S_n` vertices visits 0. My reproduction: a witness in `B_(n+1)` has two simple arms from 0; the prefix of each arm up to its first `S_n` visit lies in `B_n`. Their concatenation is still shortest in `B_n`, since any cheaper replacement there would be a cheaper path in `B_(n+1)`. Thus `E_(n+1)⊆E_n`. Choose a centered witness at each surviving scale. Finite degree gives a diagonal sequence constant on each finite centered prefix. For any finite competitor `Q` to a stabilized segment, choose a selected box containing `Q`: box minimality proves the segment no heavier than `Q`. This last comparison is the load-bearing step that upgrades box geodesics to full-lattice geodesics. The resulting two-sided simple path is a bigeodesic through 0. Reverse implication uses first exits of a bigeodesic. `E_n` is finite-edge measurable. No FPP hazard estimate follows from the equivalence.

**L2 — KEEP, conditional survival lemma.** With `A_n=Σ_{j<n}q_j` and `M_n=1_{E_n}exp(A_n)`, conditional expectation gives `E[M_(n+1)|F_n]≤M_n exp(q_n)(1-q_n)≤M_n`. Since a nonnegative supermartingale converges to a finite limit almost surely, `E_∞∩{Σq_n=∞}` is null. This does not multiply unconditional row probabilities or assume independence. Missing for P0117: an `F_n`-measurable divergent lower hazard.

**L3 — KEEP, limited positive hazard.** For `r=n+1`, the square boundary has `8r` perimeter edges, all outside `F_n`. If each is below `m/(8r)`, where `m` is the minimum origin-incident weight, the shorter arc between any two `S_r` points costs below `m/2`; any simple path through 0 pays at least `2m`. Hence the event kills `E_r`, and conditional probability is exactly `b_n=G([0,m/(8r)))^(8r)` for the specified ring event. Under the stated support-at-zero and nonatomic assumptions, `b_n>0` but eventually `b_n≤2^(-8r)`, so `Σb_n<∞`. It cannot feed L2. This is a rigorous negative route, with no conclusion about the actual hazard.

**C1 — KEEP, abstract counterexample.** `∏_{n=1}^N(1-1/(n+1)^2)=(N+2)/(2(N+1))→1/2`; positive summable conditional killing can leave survival. It is not an iid FPP example.

**C04 — KEEP, logical obstruction.** Partition `[0,1)` into `M_R` equal half-open pieces. Every individual event has probability `1/M_R→0`; their union is certain at each R. It shows why individual midpoint decay does not imply decay of the adaptive endpoint union.

**C05 — KEEP, explicit filtration boundary.** Both full-lattice completions agree on every edge induced by `B_1`, all assigned weight 1. In the cheap completion, from each `S_1` endpoint move one edge to `S_2`, follow at most eight perimeter edges, and return one edge to the other endpoint. The ten or fewer modified edges cost at most `10/20=1/2`. Any simple path through 0 pays at least two origin-incident `B_1` edges, hence cost at least 2; no global origin-hit geodesic remains. In the constant completion, opposite axial `S_1` points have a global geodesic through 0. Thus the global event differs although the finite-box event and its inside-edge data coincide. The recorded 28-pair exact check (16 global hits versus 0; box hits 16 in both) is consistent with this analytic proof. This is a deterministic measurability counterexample, not an iid FPP counterexample.

**C06 — KEEP as a conditional partition lemma and a local source-passage check.** For fixed gain `M`, the preprint's section 7.4 explicitly fixes a finite deterministic separation `S(M)` for every partition and sends partition index `j→∞` before taking `M` large. For a marked site, only finitely many marked neighbors lie within `S(M)`; if all their labels differ from the center's, each pair is eventually split by partitions whose mesh tends to zero. Their maximum splitting index is finite, so the retained indicator tends pointwise to the original mark; bounded convergence gives the probability limit. If the neighborhood grew as `N(j)=j²`, independent uniform labels and `j` equal bins would instead give retention `(1-1/j)^(2j²)→0`. This confirms only the final limit order, assuming the preprint's distinct-label theorem, uniform comparison and positive mark density. Those upstream results are not certified by this verdict.

**OpenAI preprint Proposition 7.6 — KEEP the final contradiction conditionally; full theorem unverified.** The source's Section 6 result is actually headed *Corollary 6.2* although later prose calls it Theorem 6.2. Assuming that corollary gives the same upper/lower Busemann pair for two equal-label marked bigeodesics in the union metric, the bigeodesic inequality based at each path yields `B_+(k,u)+B_-(k,u)=0` for every `u` on the second path. For a strictly raised edge `e=(u,v)` there, calibration gives `B_+(u,v)=t_e`. With far endpoints `x_N^- , x_N^+` on the first path, the detour cost `L_N=T(x_N^-,u)+t_e+T(v,x_N^+)` and first-path cost `D_N=T(x_N^-,x_N^+)` satisfy `L_N-D_N→-B_-(k,u)-B_+(k,v)+t_e=0`. Lemma 7.5 says the first path retains cost `D_N` in its individual metric and the named edge is lower there by at least `g>0`; all other union-to-individual changes only lower costs. Thus the explicit detour walk costs at most `L_N-g<D_N` for large `N`, contradiction. The algebra and walk comparison survive possible path intersections. This verifies the last deduction **only if** Corollary 6.2, Lemma 7.5, and the strict near-edge increase from Proposition 7.4 all hold. Their proofs were not fully checked here.

## Cross-triad request from w392: zero-edge boundary

**`P0117-w392-own-zero-edge-boundary` — KEEP as a counterexample only to the weakened noninjective definition.** Let `p=P(t_e=0)>0`. Horizontal row-zero edges are iid, so the chance the first `N` are all nonzero is `(1-p)^N→0`; a zero edge `u—v` exists almost surely. Set `v_(2k)=u`, `v_(2k+1)=v` for all integers `k`. Every finite segment has cost zero, and nonnegative weights make zero the minimum passage cost between its endpoints, including when the endpoints coincide. This path remains in a width-zero strip and repeats vertices. The usual bigeodesic definition requires pairwise distinct vertices, and a nonatomic law has `p=0`; hence the example has no bearing on the target theorem. It must be labeled a boundary counterexample, not a bigeodesic or a refutation of w390's injective tube result.
