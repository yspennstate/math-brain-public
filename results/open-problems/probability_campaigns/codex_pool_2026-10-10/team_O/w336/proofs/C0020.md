# C0020: query budget does not give uniform revealment

Status: proof written; w346 KEEP pending. No improvement of the source's percolation complexity exponent interval is claimed.

For an exact decision algorithm on N bits, let delta_i be the probability that bit i is queried and C the expected number of distinct bits queried. Then C=sum delta_i, but there is no universal constant K such that delta_i<=K*C/N for all algorithms and all coordinates.

Proof: for the OR of N independent fair bits, scan in a fixed order and stop at the first 1 or after all N reads. This is exact, delta_1=1, and C=sum_{j=0}^{N-1}2^(-j)=2*(1-2^(-N)). Thus delta_1/(C/N) grows like N/2. The function itself is symmetric; an algorithm need not preserve that symmetry.

More directly for the crossing problem, take any exact algorithm A_N with C(A_N)=o(N) and first query a chosen fixed bit, then execute A_N, caching that observation if it is requested again. The modified algorithm is still exact, has expected distinct query cost at most C(A_N)+1=o(N), and that bit's revealment is 1. Therefore a uniform O(C/N) bound does not follow from a sublinear query budget even for that function. The crossing upper bound recorded in the source gives such a sublinear budget relative to N=Theta(n^2).

The previous attempt's calculation was conditional on such a uniform bound; its algebra is not refuted. The missing uniformity premise requires an actual symmetrization argument with a transitive action on all input coordinates. A rectangular crossing has no supplied action that mixes every bulk and boundary bit in this way.

Checks: exhaustive fair-bit inputs for OR on N<=12, exact expected query counts, and revealment ratios. This rules out a shortcut; it supplies no new crossing lower bound.
