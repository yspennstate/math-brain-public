**Status: PROVED PARTIAL.** This report does **not** solve Randomstrasse101 Conjecture 16 for arbitrary deterministic tensors. The source-level arbitrary-tensor exponent recovered from the present primary literature remains

```text
gamma = 1/2 - 1/(2r)
```

in the unresolved range `2 <= p < 2r`, versus the conjectured

```text
alpha = 1/2 - 1/p.
```

This run materially changes method. The previous report reduced the problem to an `O(k polylog)` operator-norm entropy bound for the whole tangent field `x -> A_x`. I prove here that this proposed intermediate theorem is **false even for one scalar symmetric tensor**, including every fixed order `r >= 3` in the unresolved `p=2` regime. The obstruction is geometric: the tangent operator can rotate along a level set on which the original tensor process is constant. Thus a cover of the full tangent operator counts right/input-space rotation that the Gaussian process does not see.

The replacement is an **output-covariance reduction**. Writing `C_x=A_x A_x^*`, the source process satisfies

```text
|<g,F(x)>|^2 <= d^(1-2/p) <g,C_x g>.
```

Hence the conjectured exponent follows if the Gaussian quadratic process generated by the output covariances has only polylogarithmic complexity. I prove a finite low-trace Loewner-envelope theorem giving the source exponent for a genuinely broader covariance class with arbitrary input-frame rotation. I then return to the weighted one-slot decomposition from the predecessor and prove two additional structural facts: an exact amplitude-weighted covariance reduction and an empirical rank-`m` covariance Maurey theorem with Frobenius error `O(m^{-1/2})`. Finally I prove a weight/mass reciprocity identity and dyadic decomposition showing that large column reweightings necessarily carry exponentially small process mass. This directly attacks the previous BSS-weight obstruction.

## 2. Tangent notation in source normalization

Put

```text
S^2 := sum_i ||T_i||_{I_p}^2,
alpha := 1/2 - 1/p.
```

For `x in B_p^d`, define

```text
F(x) := ( T_i[x^r] )_(i=1)^n in R^n,
(A_x v)_i := T_i[x^(r-1),v].                               (2.1)
```

Thus

```text
F(x)=A_x x.                                                (2.2)
```

Real polarization for symmetric forms gives a constant `P_r` depending only on `r` such that every mixed evaluation is at most `P_r ||T_i||_{I_p}` on `B_p` slots. Since `p>=2` and the dual exponent `q=p/(p-1)<=2`, each row of `A_x`, viewed as a Euclidean linear functional, has Euclidean norm at most `P_r ||T_i||_{I_p}`. Consequently

```text
||A_x||_HS <= R,                                           (2.3)
R := P_r S.                                                 (2.4)
```

Also

```text
||x||_2 <= d^alpha ||x||_p <= d^alpha.                     (2.5)
```

The Gaussian process in Conjecture 16 is

```text
X_x=<g,F(x)>.
```

The predecessor proved the valid transfer theorem

```text
log N(F(B_p), 2 d^alpha R/sqrt(k))
 <= log N({A_x}, R/sqrt(k)) + C k log(2k).                 (2.6)
```

It then proposed proving

```text
log N({A_x}, ||.||_op, R/sqrt(k))
 <= C k polylog(d,n).                                      (2.7)
```

Theorem 2.6 from the predecessor remains valid. The next section proves that the hoped-for universal hypothesis (2.7) is false.

## 3. Counterexample: the full tangent-field entropy can be exponentially too large

### Theorem 3.1 (level-set rotation refutes the universal tangent entropy target)

Fix any integer `r>=3`. There are symmetric order-`r` tensors with `n=1`, `p=2`, and `||T||_{I_2}=1` for which the process is constant on an `(m-1)`-sphere while the tangent operators along that same sphere contain an `exp(c_r m)` constant-separated packing.

Consequently, for a fixed integer `k_0=k_0(r)` and arbitrarily large `d`, one has

```text
log N({A_x:x in B_2^d}, ||.||_op, R/sqrt(k_0))
 >= c_r d,                                                  (3.1)
```

whereas `k_0 polylog(d,n)=polylog(d)` for fixed `k_0`. Therefore the proposed universal estimate (2.7) is false even inside the unresolved regime `p=2<2r`.

#### Proof

Work in `R^(m+1)` with coordinates `(t,y)`, `y in R^m`. Consider the homogeneous polynomial

```text
P(t,y)=c_r t^(r-2) ||y||_2^2.                              (3.2)
```

For `r>=3`,

```text
max_{t^2+||y||_2^2<=1} |t|^(r-2)||y||_2^2
 = ((r-2)/r)^((r-2)/2) * (2/r),                           (3.3)
```

so choose `c_r>0` to make the associated symmetric tensor satisfy

```text
||T||_{I_2}=1.                                             (3.4)
```

For a homogeneous diagonal polynomial,

```text
D P(x)[v] = r T[x^(r-1),v],                                (3.5)
```

so the scalar tangent row `A_x` is represented by `(1/r) grad P(x)`.

Choose any fixed `a,b>0` with `a^2+b^2=1`; for definiteness one may take `a=b=2^(-1/2)`. For `theta in S^(m-1)`, put

```text
x_theta=(a,b theta).                                       (3.6)
```

Then

```text
F(x_theta)=P(x_theta)=c_r a^(r-2)b^2,                      (3.7)
```

which is independent of `theta`.

On the other hand,

```text
grad_y P(x_theta)=2 c_r a^(r-2)b theta,                    (3.8)
```

and the `t`-derivative depends only on `a,b`, not on `theta`. Therefore

```text
||A_(x_theta)-A_(x_phi)||_op
 = delta_r ||theta-phi||_2,                                (3.9)

delta_r := (2 c_r/r) a^(r-2)b >0.                         (3.10)
```

A standard sphere-packing argument gives a subset `Theta subset S^(m-1)` of cardinality at least `exp(c m)` with pairwise Euclidean distance at least a fixed numerical constant. Hence the corresponding tangent rows have pairwise operator distance at least a constant depending only on `r`.

By (2.3), `R=P_r S=P_r` is also a constant depending only on `r`. Choose once and for all

```text
k_0 >= (8R/delta_r)^2.                                    (3.11)
```

Then `R/sqrt(k_0) <= delta_r/8`, and the packed tangents remain separated at the radius in (3.1). Since `d=m+1`, (3.1) follows. QED.

### Meaning of the obstruction

This is stronger than a bad logarithm. The full tangent operator remembers the **input/right singular direction** `theta` even though the original process value is exactly constant on the whole rotating family. Any universal theorem that pays for all operator-norm tangent rotations therefore overcounts geometry that the Gaussian process does not see.

This does **not** refute Theorem (2.6), nor does it refute Conjecture 16. It refutes only the proposed universal sufficient hypothesis (2.7).

The correct next object must quotient out these invisible input rotations.

## 4. New reduction: only the output covariance matters to the Gaussian direction

Define the output covariance of the tangent map

```text
C_x := A_x A_x^* in R^(n x n),                             (4.1)
```

which is positive semidefinite and satisfies

```text
Tr C_x = ||A_x||_HS^2 <= R^2.                              (4.2)
```

### Theorem 4.1 (output-covariance reduction)

For every deterministic symmetric tensor family in the source normalization,

```text
E sup_{x in B_p^d} |<g,F(x)>|
 <= d^alpha
    ( E sup_{x in B_p^d} <g,C_x g> )^(1/2).                (4.3)
```

Consequently, the source target exponent follows if one proves the dimension-free quadratic-process estimate

```text
E sup_{x in B_p^d} <g,C_x g>
 <= R^2 polylog(d,n)^2.                                   (4.4)
```

#### Proof

For every fixed `x` and Gaussian vector `g in R^n`,

```text
|<g,F(x)>|
 = |<g,A_x x>|
 = |<A_x^* g,x>|
 <= ||A_x^*g||_2 ||x||_2
 <= d^alpha ||A_x^*g||_2.                                 (4.5)
```

Squaring gives

```text
|<g,F(x)>|^2
 <= d^(2alpha) <g,A_xA_x^*g>
 = d^(2alpha) <g,C_xg>.                                   (4.6)
```

Take the supremum over `x`, then expectation, and apply Jensen to the square root. QED.

### Mixed-norm interpretation

The quadratic process in (4.4) is exactly the square of the mixed Gaussian tensor norm

```text
sup_{||x||_p<=1, ||v||_2<=1}
 | sum_i g_i T_i[x^(r-1),v] |.                            (4.7)
```

Thus Theorem 4.1 reduces Conjecture 16 to controlling one **Euclidean final slot** without any polynomial dimension loss. For `p=2` this is comparable, by polarization, to the original Euclidean tensor problem; for `p>2` it is a stronger mixed-norm target. This is a reduction, not a solution.

### Why this fixes Theorem 3.1's pathology

For the scalar counterexample of Section 3, `n=1`, so every `C_x` is simply a nonnegative scalar. The exponentially rotating input/right tangent directions disappear completely. This is the quotient that (2.7) failed to perform.

## 5. A genuinely broader proved class: finite low-trace Loewner envelopes

The output-covariance reduction immediately yields a covariance-structure theorem that allows arbitrary input-frame rotation and does not require common singular vectors, commutation, block support, or low tangent-operator entropy.

### Theorem 5.1 (finite low-trace covariance-envelope theorem)

Assume there are positive semidefinite matrices

```text
H_1,...,H_M in R^(n x n)                                  (5.1)
```

such that

```text
Tr H_a <= Lambda R^2 for every a,                          (5.2)
```

and for every `x in B_p^d` there is a convex combination

```text
H(x) in conv{H_1,...,H_M}                                 (5.3)
```

with

```text
C_x <= H(x)                                                (5.4)
```

in Loewner order. Then

```text
E ||sum_i g_i T_i||_{I_p}
 <= C d^alpha R sqrt( Lambda log(2M) ).                    (5.5)
```

In particular, if `Lambda` and `log M` are polylogarithmic in `(d,n)`, the Randomstrasse101 target polynomial exponent holds for this class.

#### Proof

For every `g`,

```text
sup_x <g,C_xg>
 <= sup_x <g,H(x)g>
 <= max_{1<=a<=M} <g,H_ag>.                               (5.6)
```

For a fixed PSD `H`, the standard Gaussian quadratic-form tail bound gives, for all `t>=0`,

```text
P{ g^T H g
    >= Tr H + 2 sqrt(Tr(H^2)t) + 2 ||H||_op t }
 <= e^(-t).                                                (5.7)
```

Because `H>=0`,

```text
sqrt(Tr(H^2)) <= Tr H,
||H||_op <= Tr H.                                         (5.8)
```

Using (5.2), applying a union bound over `M`, and integrating the resulting tail yields

```text
E max_a g^T H_a g
 <= C Lambda R^2 log(2M).                                 (5.9)
```

Insert this into Theorem 4.1. QED.

### Why this is broader than the failed tangent-entropy route

A single low-trace envelope may dominate a continuum of covariance matrices whose input/right singular vectors rotate through an exponentially large family. The theorem charges only the directions in **Gaussian output space** that can actually amplify `<g,F(x)>`.

The scalar tensor in Theorem 3.1 is the extreme illustration: its tangent field has exponential constant-scale operator entropy, but its output covariance lives in one dimension, so a single envelope suffices.

No external novelty claim is made for this sufficient class. Its role is to identify a covariance geometry that genuinely survives the level-set-rotation counterexample and is strictly better aligned with the original Gaussian process.

## 6. Process-weighted covariance: a sharper object than normalized tangent directions

The predecessor's balanced one-slot decomposition remains useful, but the correct quadratic object must retain its amplitude.

For fixed `x`, write

```text
c_j(x):=A_x e_j,
a_j(x):=||c_j(x)||_2,
v_j(x):=x_j c_j(x),                                        (6.1)
L(x):=sum_j ||v_j(x)||_2=sum_j |x_j|a_j(x).                (6.2)
```

By Cauchy--Schwarz and (2.3),

```text
L(x)
 <= ||x||_2 (sum_j a_j(x)^2)^(1/2)
 = ||x||_2 ||A_x||_HS
 <= d^alpha R.                                             (6.3)
```

When `L(x)>0`, define

```text
q_x(j):=||v_j(x)||_2/L(x)=|x_j|a_j(x)/L(x),                (6.4)
u_(x,j):=v_j(x)/||v_j(x)||_2.                              (6.5)
```

Then

```text
F(x)=L(x) sum_j q_x(j) u_(x,j).                            (6.6)
```

Define the **balanced process covariance**

```text
K_x
 := L(x)^2 sum_j q_x(j) u_(x,j)u_(x,j)^*                  (6.7)
```

and put `K_x=0` if `L(x)=0`.

Equivalently, omitting zero columns,

```text
K_x
 = L(x) sum_j (|x_j|/a_j(x)) c_j(x)c_j(x)^*.              (6.8)
```

### Theorem 6.1 (amplitude-weighted covariance reduction)

For every `g` and `x`,

```text
|<g,F(x)>|^2 <= <g,K_x g>.                                (6.9)
```

Moreover

```text
Tr K_x=L(x)^2 <= d^(2alpha)R^2.                            (6.10)
```

Hence

```text
E ||sum_i g_iT_i||_{I_p}
 <= ( E sup_x <g,K_xg> )^(1/2).                            (6.11)
```

#### Proof

By (6.6) and Jensen/Cauchy--Schwarz under the probability law `q_x`,

```text
|<g,F(x)>|^2
 = L(x)^2 |sum_j q_x(j)<g,u_(x,j)>|^2
 <= L(x)^2 sum_j q_x(j)<g,u_(x,j)>^2
 = <g,K_xg>.                                               (6.12)
```

The trace identity follows because every `u_(x,j)` has Euclidean norm one. QED.

### Relation to Theorem 4.1

`C_x` is simpler and gives the exact desired `d^alpha` factor outside the quadratic process. `K_x` is more process-adaptive: it deletes zero-mass columns and downweights columns according to their actual contribution to the barycenter. It is therefore the better object for the predecessor's weighted-column route.

## 7. Countertest: normalized covariance alone is still too large

It would be tempting to normalize (6.7) by `L(x)^2` and attempt to prove a polylogarithmic bound for

```text
M_x:=K_x/L(x)^2=sum_j q_x(j)u_(x,j)u_(x,j)^*.              (7.1)
```

That is false. The amplitude `L(x)` is essential.

### Proposition 7.1 (a cancellation nodal set with spherical normalized covariance)

Fix `r>=3`. For every `m` there is a symmetric order-`r` tensor family with `p=2`, `n=m`, and `S=Theta_r(1)` having a sphere of points `x_theta` such that

```text
F(x_theta)=0,                                              (7.2)
M_(x_theta)=theta theta^*                                  (7.3)
```

for every `theta in S^(m-1)`. Thus

```text
E sup_theta <g,M_(x_theta)g>
 = E ||g||_2^2
 = m.                                                      (7.4)
```

At the same time

```text
L(x_theta)^2=Theta_r(1/m),                                 (7.5)
```

so

```text
E sup_theta <g,K_(x_theta)g>=Theta_r(1).                   (7.6)
```

#### Construction and proof

Use coordinates `(z_0,z_1,z_2,y_1,...,y_m)`. For `ell=1,...,m`, let the diagonal polynomial of `T_ell` be

```text
P_ell(z)
 = c_r m^(-1/2)
   z_0^(r-3)(z_1^2-z_2^2)y_ell,                            (7.7)
```

with the factor `z_0^(r-3)` omitted when `r=3`. Choose fixed positive `a,b,t` with

```text
a^2+2b^2+t^2=1,                                           (7.8)
```

and put

```text
x_theta=(a,b,b,t theta).                                   (7.9)
```

Since `z_1^2-z_2^2=0` on this set,

```text
F(x_theta)=0.                                              (7.10)
```

The only nonzero tangent columns relevant to the cancellation are the `z_1` and `z_2` columns. Using `D P_ell(x)[v]=rT_ell[x^(r-1),v]`, they are

```text
c_1(x_theta)= beta_r m^(-1/2) theta,
c_2(x_theta)=-beta_r m^(-1/2) theta                        (7.11)
```

for a nonzero constant `beta_r` depending only on the fixed choices. All `y`-columns vanish on the nodal set because they carry the factor `z_1^2-z_2^2`; the `z_0` column also vanishes there.

Therefore

```text
v_1= b beta_r m^(-1/2) theta,
v_2=-b beta_r m^(-1/2) theta,                              (7.12)
L=2b|beta_r|m^(-1/2),                                     (7.13)
q(1)=q(2)=1/2,                                            (7.14)
u_1=theta,
u_2=-theta.                                                    (7.15)
```

Equations (7.2)--(7.6) follow.

Each polynomial has injective norm `Theta_r(m^(-1/2))`, so summing the squared norms over `m` outputs gives `S=Theta_r(1)`. QED.

### Lesson

Even the process-weighted **normalized** direction covariance may rotate through every rank-one projector. But when that rotation is supported by very little process mass, `L(x)^2` automatically shrinks by the reciprocal dimension. The amplitude-weighted covariance `K_x`, not `M_x`, is the stable object.

This counterexample was checked before using a normalized-covariance hypothesis in any proof.

## 8. New theorem: empirical covariance Maurey at the correct process weights

The balanced covariance has an exact empirical approximation that does not require BSS weights and never samples zero-mass columns.

### Theorem 8.1 (process-weighted covariance Maurey)

Fix `x` with `L(x)>0`, and draw `J_1,...,J_m` independently from `q_x`. Define

```text
Khat_(x,m)
 := (L(x)^2/m)
    sum_(a=1)^m u_(x,J_a)u_(x,J_a)^*.                     (8.1)
```

Then

```text
E_J Khat_(x,m)=K_x,                                       (8.2)
Tr Khat_(x,m)=Tr K_x=L(x)^2                               (8.3)
```

and

```text
E_J ||Khat_(x,m)-K_x||_F^2
 = (L(x)^4/m) [1-Tr(M_x^2)]
 <= L(x)^4/m
 <= d^(4alpha)R^4/m.                                      (8.4)
```

Consequently, for every `x` there exists a rank-`<=m` PSD empirical covariance with the same trace and

```text
||Khat_(x,m)-K_x||_F
 <= d^(2alpha)R^2/sqrt(m).                                (8.5)
```

Moreover, because the traces agree, for an independent standard Gaussian `g`,

```text
E_(J,g)
 | g^T(Khat_(x,m)-K_x)g |^2
 = 2 E_J ||Khat_(x,m)-K_x||_F^2
 <= 2 d^(4alpha)R^4/m.                                    (8.6)
```

#### Proof

Let

```text
P_J:=u_(x,J)u_(x,J)^*.
```

Then `E P_J=M_x`, `Tr P_J=1`, and `P_J^2=P_J`. Therefore

```text
E ||P_J-M_x||_F^2
 = E Tr(P_J^2)-Tr(M_x^2)
 = 1-Tr(M_x^2).                                           (8.7)
```

Independence of the `m` samples gives (8.4) after multiplying by `L(x)^4`. The trace identity is exact term by term.

For a symmetric matrix `Delta` with `Tr Delta=0`,

```text
E_g (g^T Delta g)^2=2||Delta||_F^2.                        (8.8)
```

Apply this to `Delta=Khat-K` and average over the samples. QED.

### Why this improves the predecessor's BSS bottleneck

BSS sparsification certified an active range with `O(k)` coordinates but introduced potentially huge external spectral weights unrelated to the process mass. Theorem 8.1 uses **exactly the barycentric distribution that generates the process point**. Its empirical covariance is automatically rank `m`, has no extraneous weights, has exactly the correct trace, and ignores every zero-mass rotating direction.

The unsolved part is now narrower: the selected normalized directions still depend on the shared witness `x^(r-1)`. The next task is to control the entropy of these **q-weighted empirical covariance configurations**, not of all tangent directions.

## 9. New weight/mass reciprocity and dyadic decomposition

There is a simple exact identity that explains why very large column reweightings cannot simultaneously carry large process mass.

For a nonzero column with `q_x(j)>0`, define its coefficient relative to the unweighted tangent covariance by

```text
w_x(j):=L(x)|x_j|/a_j(x).                                 (9.1)
```

Then from (6.4),

```text
w_x(j)=x_j^2/q_x(j),                                      (9.2)
```

and

```text
K_x=sum_j w_x(j)c_j(x)c_j(x)^*.                           (9.3)
```

### Proposition 9.1 (weight/mass reciprocity)

Let

```text
h(x):=||x||_2^2.                                           (9.4)
```

Then

```text
E_(J~q_x) w_x(J)
 = sum_{j:q_x(j)>0} x_j^2
 <= h(x)
 <= d^(2alpha).                                            (9.5)
```

Hence for every `lambda>=1`,

```text
q_x{ j : w_x(j)>lambda h(x) }
 <= 1/lambda.                                              (9.6)
```

In particular, if all coordinates with `w_x(j)>lambda h(x)` are discarded from the barycentric representation (6.6), the discarded process vector has Euclidean norm at most

```text
L(x)/lambda.                                               (9.7)
```

#### Proof

Equation (9.2) gives

```text
sum_j q_x(j)w_x(j)=sum_{q_x(j)>0}x_j^2<=||x||_2^2.         (9.8)
```

Markov gives (9.6). The discarded barycenter is

```text
L(x) sum_{j in bad} q_x(j)u_(x,j),                         (9.9)
```

whose Euclidean norm is at most `L(x)q_x(bad)`. QED.

### Corollary 9.2 (dyadic covariance layers)

Define

```text
B_0(x):={j:w_x(j)<=2h(x)},
B_s(x):={j:2^s h(x)<w_x(j)<=2^(s+1)h(x)},  s>=1.           (9.10)
```

Let `F_s(x)` and `K_s(x)` denote the corresponding pieces of the barycenter and covariance. Then

```text
F(x)=sum_{s>=0}F_s(x),
K_x=sum_{s>=0}K_s(x),                                      (9.11)
```

and for `s>=1`,

```text
q_x(B_s)<=2^(-s),                                         (9.12)
||F_s(x)||_2<=L(x)2^(-s),                                 (9.13)
Tr K_s(x)<=L(x)^2 2^(-s),                                 (9.14)
K_s(x)<=2^(s+1)h(x) C_x.                                  (9.15)
```

For `B_0`, (9.15) holds with factor `2h(x)` and the mass is at most one.

#### Proof
