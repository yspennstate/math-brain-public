\omega(A_m)=\min_{S:\operatorname{rank}(A_{S^c})<m}\sigma_m(A_S),

\tag{1.1}

For iid Gaussian `A_m`, full spark holds almost surely. Hence `rank(A_{S^c})<m` iff `|S^c|\le m-1`, and monotonicity of the least singular value under addition of rows gives

\[
\boxed{\omega(A_m)=\min_{|B|=m}s_{\min}(A_B)}
\quad\text{a.s.}
\tag{1.2}
\]

Set

\[
L_m=\binom{2m-1}{m},\qquad

s_m(\lambda)=\frac{\lambda}{L_ma_m},
\tag{1.3}
\]

and define the all-apex hard-edge count

\[
W_m(\lambda)=\sum_{|B|=m}
\mathbf 1_{\{s_{\min}(A_B)\le s_m(\lambda)\}}.
\tag{1.4}
\]

Then

\[
\{L_ma_m\omega(A_m)\le\lambda\}=\{W_m(\lambda)\ge1\}.
\tag{1.5}
\]

The useful inherited theorem from the preceding run is the dependence-aware polynomial-window second moment. For every fixed `K<infinity`, uniformly on

\[

## 2. New theorem: a two-sided constant-scale distribution bracket

Define

\[
Y_m:=L_ma_m\,\omega(A_m).
\tag{2.1}
\]

### Theorem P08-EXACT-SCALE-TIGHTNESS

For every fixed `lambda>0`,

\[
\boxed{
\frac{\lambda}{1+\lambda}
\le
\liminf_{m\to\infty}\Pr\{Y_m\le\lambda\}
\le
\limsup_{m\to\infty}\Pr\{Y_m\le\lambda\}
\le
\min\{1,\lambda\}.
}
\tag{2.2}
\]

More quantitatively, for any fixed `K` and uniformly on the polynomial window (1.6),

\[
\Pr\{Y_m\le\lambda\}
\le
\lambda\bigl(1+O_K(e^{-c_Km})\bigr),
\tag{2.3}
\]

while

\[
\boxed{
\Pr\{Y_m>\lambda\}
\le
\frac{1}{1+\lambda}
+\frac{C_K}{m^2}
+O_K(e^{-c_Km}).
}
\tag{2.4}
\]

Equivalently,

\[
\Pr\{Y_m\le\lambda\}
\ge
\frac{\lambda}{1+\lambda}
-O_K(m^{-2})-O_K(e^{-c_Km}).
\tag{2.5}
\]

### Proof

The upper CDF bound is the first-moment inequality. By (1.5),

\[
\Pr\{Y_m\le\lambda\}
=\Pr\{W_m(\lambda)\ge1\}
\le\mathbb E W_m(\lambda)
=\mu_m(\lambda),
\]

and (1.7) gives (2.3).

For the lower CDF bound use Paley--Zygmund at level zero. Since `W_m>=0`,

\[
\Pr\{W_m>0\}
\ge \frac{(\mathbb EW_m)^2}{\mathbb EW_m^2}.
\tag{2.6}
\]

Now

\[
\mathbb EW_m^2
=\mu_m+\mathbb E(W_m)_2
\le
\mu_m+\mu_m^2(1+\delta_m),
\qquad
\delta_m:=C_Km^{-2}.
\tag{2.7}
\]

Therefore

\[
\Pr\{Y_m\le\lambda\}
=\Pr\{W_m>0\}
\ge
\frac{\mu_m}{1+\mu_m(1+\delta_m)}.
\tag{2.8}
\]

Correspondingly,

\[
\Pr\{Y_m>\lambda\}
\le
\frac{1+\mu_m\delta_m}{1+\mu_m(1+\delta_m)}.
\tag{2.9}
\]

The elementary identity

\[
\frac{1+\mu\delta}{1+\mu(1+\delta)}
-\frac1{1+\mu}
=
\frac{\mu^2\delta}
{(1+\mu)(1+\mu+\mu\delta)}
\le\delta
\tag{2.10}
\]

gives

\[
\Pr\{Y_m>\lambda\}
\le\frac1{1+\mu_m}+\delta_m.
\]

Using (1.7) gives (2.4), and (2.5) follows by complementing. Taking `m->infinity` yields (2.2). QED.

### Interpretation

This is substantially sharper than merely

\[
\omega(A_m)=4^{-m+o_{\mathbb P}(m)}.
\]

It says that after the **correct deterministic hard-edge normalization** `L_m a_m`, the minimum is neither escaping to zero nor infinity. In fact its CDF is trapped between two explicit nondegenerate laws:

\[
\frac{\lambda}{1+\lambda}
\lesssim F_m(\lambda)
\lesssim \min(1,\lambda).
\tag{2.11}
\]

No fixed-`k` Poisson assembly is required for this theorem.

## 3. Quantiles are now pinned to constants

Let

\[
q_m(u):=\inf\{x>0:\Pr(Y_m\le x)\ge u\},
\qquad 0<u<1.
\]

### Corollary P08-QUANTILE-BRACKET

For every fixed `u in (0,1)`,

\[
\boxed{
u
\le \liminf_{m\to\infty}q_m(u)
\le \limsup_{m\to\infty}q_m(u)
\le \frac{u}{1-u}.
}
\tag{3.1}
\]

Indeed, if `x<u`, then (2.3) gives `Pr(Y_m<=x)<u` for large `m`; hence the lower bound. If `x>u/(1-u)`, then (2.4) gives

\[
\limsup_m\Pr(Y_m>x)
\le\frac1{1+x}<1-u,
\]

so eventually the CDF exceeds `u`.

In particular, any median `med(Y_m)` satisfies

\[
\boxed{
\frac12-o(1)\le \operatorname{med}(Y_m)\le1+o(1).
}
\tag{3.2}
\]

The candidate Poisson law would sharpen the median to `log 2`; (3.2) is the unconditional dependence-aware bracket obtainable from the proved one- and two-point theory.

## 4. Exact source normalization: the row norm is asymptotically `sqrt(m)`

The source/conjecture normalizes by the maximum row norm. Write

\[
R_m:=\max_{1\le i\le2m-1}\|a_i\|_2.
\tag{4.1}
\]

The previous report only needed `m^{-1}\log R_m->0`. Here the stronger scale is needed.

### Lemma P08-MAX-ROW-NORM

Under the canonical infinite-array coupling,

\[
\boxed{\frac{R_m}{\sqrt m}\longrightarrow1\quad\text{almost surely}.}
\tag{4.2}
\]

### Proof

For fixed `epsilon in (0,1)`, standard chi-square concentration gives

\[
\Pr\left\{\left|\frac{\|a_i\|_2^2}{m}-1\right|>\epsilon\right\}
\le2e^{-c_\epsilon m}.
\tag{4.3}
\]

A union bound over `i<=2m-1` yields

\[
\Pr\left\{
\max_{i\le2m-1}
\left|\frac{\|a_i\|_2^2}{m}-1\right|>\epsilon
\right\}
\le4m e^{-c_\epsilon m},
\tag{4.4}
\]

which is summable in `m`. Borel--Cantelli gives (4.2) along rational `epsilon downarrow0`. No independence across dimensions is required. QED.

Stirling also gives

\[
\boxed{
L_ma_m
=\frac{4^m}{2\sqrt\pi}\left(1+O(m^{-1})\right).
}
\tag{4.5}
\]

Therefore the source-normalized exact-scale variable

\[
Z_m:=rac{4^m\sqrt m}{2\sqrt\pi}
\frac{\omega(A_m)}{R_m}
\tag{4.6}
\]

satisfies

\[
\frac{Z_m}{Y_m}
=
\frac{4^m}{2\sqrt\pi L_ma_m}\,
\frac{\sqrt m}{R_m}
\longrightarrow1
\quad\text{almost surely}.
\tag{4.7}
\]

Thus the exact-scale tightness is not an artifact of the auxiliary hard-edge normalization: it holds in the normalization appearing naturally in the phase-retrieval stability question.

For every fixed `lambda>0`, (2.2) and (4.7) imply

\[
\boxed{
\frac{\lambda}{1+\lambda}
\le
\liminf_m\Pr\{Z_m\le\lambda\}
\le
\limsup_m\Pr\{Z_m\le\lambda\}
\le
\min\{1,\lambda\}.
}
\tag{4.8}
\]

Hence

\[
\boxed{
\frac{\omega(A_m)}{R_m}
=\Theta_{\mathbb P}\!\left(\frac{4^{-m}}{\sqrt m}\right).
}
\tag{4.9}
\]

This is a new unconditional source-facing statement: the Gaussian stability parameter has exponential base `1/4` and its remaining scale is polynomially pinned all the way down to `m^{-1/2}` times a tight nondegenerate random factor.

## 5. New second-order localization of the logarithmic instability

Define exactly the source-normalized logarithmic exponent

\[
X_m:=-\frac1m\log\frac{\omega(A_m)}{R_m}.
\tag{5.1}
\]

The earlier unconditional result was only `X_m->log 4` (indeed almost surely under the canonical coupling). The exact-scale theorem identifies the next deterministic term.

Set

\[
T_m
:=m(X_m-\log4)-\frac12\log m+\log(2\sqrt\pi).
\tag{5.2}
\]

By the definition (4.6), this identity is exact:

\[
\boxed{T_m=-\log Z_m.}
\tag{5.3}
\]

### Theorem P08-SECOND-ORDER-EXPONENT

The family `(T_m)` is tight. More precisely, for every fixed `t>=0`,

\[
\boxed{
\limsup_{m\to\infty}\Pr\{T_m\ge t\}\le e^{-t},
}
\tag{5.4}
\]

and

\[
\boxed{
\limsup_{m\to\infty}\Pr\{T_m\le-t\}
\le\frac1{1+e^t}
\le e^{-t}.
}
\tag{5.5}
\]

Consequently,

\[
\boxed{
X_m
=\log4
+\frac{\log m}{2m}
-\frac{\log(2\sqrt\pi)}{m}
+O_{\mathbb P}(m^{-1}).
}
\tag{5.6}
\]

### Proof

From (5.3),

\[
\Pr\{T_m\ge t\}=\Pr\{Z_m\le e^{-t}\},
\qquad
\Pr\{T_m\le-t\}=\Pr\{Z_m\ge e^t\}.
\]

Apply (4.8) at `lambda=e^{-t}` to the first event and the survival form of (4.8) at `lambda=e^t` to the second. This gives (5.4)--(5.5). Tightness follows, and dividing (5.2) by `m` gives (5.6). QED.

This is exactly the deterministic first correction that the candidate Poisson theorem suggested, but it is now proved **without** using the fixed-`k` Poisson assembly. The still-candidate Poisson theorem would identify the limiting `O_P(1)` term as Gumbel; the present theorem proves the centering and the `1/m` fluctuation scale unconditionally from the dependence-aware second moment.
