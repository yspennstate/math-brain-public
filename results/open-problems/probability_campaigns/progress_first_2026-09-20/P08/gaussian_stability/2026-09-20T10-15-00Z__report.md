## 1. Source, ownership, and inherited input

The external source remains Bandeira--Dmitriev--Lucca--Nizic-Nikolac--Rodder, *Randomstrasse101: Open Problems of 2025*, arXiv:2603.29571, Definition 10.1, Conjecture 20 and Open Problem 21. For iid standard real Gaussian

\[
A_m\in\mathbb R^{(2m-1)\times m},
\]

I use the dimensionally consistent form

\[
\omega(A_m)=\min_{S:\operatorname{rank}(A_{S^c})<m}\sigma_m(A_S).
\]

At full spark this equals

\[
\omega(A_m)=\min_{|B|=m}s_{\min}(A_B)\qquad\text{a.s.}
\tag{1.1}
\]

Canonical ownership is preserved: Shmalo, *Extreme least singular values of Gaussian row submatrices and a phase retrieval stability problem*, arXiv:2607.06249, already proves the Gaussian exponential scale

\[
\omega(A_m)=4^{-m+o_{\mathbb P}(m)}.
\tag{1.2}
\]

The present P08 track is complementary: it studies the exact hard-edge scale and dependence corrections rather than re-claiming (1.2).

Write

\[
L_m=\binom{2m-1}{m},\qquad
 a_m=\sqrt2\,\frac{\Gamma((m+1)/2)}{\Gamma(m/2)},
\qquad
Y_m=L_ma_m\omega(A_m),
\tag{1.3}
\]

and

\[
W_m(\lambda)=\sum_{|B|=m}
\mathbf 1_{\{s_{\min}(A_B)\le \lambda/(L_ma_m)\}}.
\]

Then

\[
\{Y_m\le\lambda\}=\{W_m(\lambda)>0\}.
\tag{1.4}
\]

The previous P08 run proved, using the correlated-minor second moment and no independence assumption, that for every fixed `K<infinity`, uniformly for

\[
m^{-K}\le\lambda\le m^K,
\tag{1.5}
\]

\[
\Pr\{Y_m\le\lambda\}
\ge D(\lambda)-\varepsilon_{m,K},
\qquad
\varepsilon_{m,K}\le C_Km^{-2}+C_Ke^{-c_Km},
\tag{1.6}
\]

where, with `r=ceil(lambda)`,

\[
D(\lambda)=\frac{\lambda(2r-\lambda)}{r(r+1)}.
\tag{1.7}
\]

The one-minor hard-edge union bound is global:

\[
\Pr\{Y_m\le\lambda\}\le\min\{1,\lambda\}.
\tag{1.8}
\]

The goal of this run is to extract the strongest exact-scale concentration that follows from (1.6)--(1.8) alone.

## 2. A simple identity hidden in the Dawson--Sankoff envelope

For `lambda>=1`, put

\[
r=\lceil\lambda\rceil,\qquad \delta=r-\lambda\in[0,1].
\]

Then

\[
D(\lambda)
=\frac{(r-\delta)(r+\delta)}{r(r+1)}
=\frac{r^2-\delta^2}{r(r+1)},
\]

so

\[
\boxed{
1-D(\lambda)
=\frac{r+\delta^2}{r(r+1)}
\le \frac1r
\le \frac1\lambda.
}
\tag{2.1}
\]

For `0<=lambda<=1`, the same envelope is exactly

\[
D(\lambda)=\lambda-\frac{\lambda^2}{2}.
\tag{2.2}
\]

These two elementary formulas turn the two-factorial-moment information into exponential tails for the logarithm of the exact-scale minimum.

## 3. New theorem: unconditional moderate deviations of the exact hard-edge factor

Define

\[
A_m=(-\log Y_m)_+,
\qquad
B_m=(\log Y_m)_+.
\]

### Theorem P08-LOG-MODERATE-TAIL

For every fixed `K<infinity`, uniformly for

\[
0\le t\le K\log m,
\]

one has

\[
\boxed{
\Pr\{A_m>t\}\le e^{-t},
}
\tag{3.1}
\]

and

\[
\boxed{
\Pr\{B_m>t\}
\le e^{-t}+C_Km^{-2}+C_Ke^{-c_Km}.
}
\tag{3.2}
\]

Consequently

\[
\boxed{
\Pr\{|\log Y_m|>t\}
\le 2e^{-t}+C_Km^{-2}+C_Ke^{-c_Km}
}
\tag{3.3}
\]

through the full logarithmic window.

### Proof

For (3.1), apply the global union bound (1.8) at `lambda=e^{-t}`:

\[
\Pr(A_m>t)=\Pr(Y_m<e^{-t})\le e^{-t}.
\]

For (3.2), `lambda=e^t` lies in `[1,m^K]`. Therefore (1.6) and (2.1) give

\[
\Pr(B_m>t)
=1-\Pr(Y_m\le e^t)
\le1-D(e^t)+\varepsilon_{m,K}
\le e^{-t}+\varepsilon_{m,K}.
\]

Adding the two one-sided estimates gives (3.3). QED.

This is an unconditional exact-scale statement. The `m^{-2}` floor is not a proof artifact inserted here: it is exactly the algebraic size of the already proved aggregate pair-correlation correction. Removing that floor requires genuinely higher connected-moment information.

## 4. New theorem: logarithmic moments below order two

### Theorem P08-LOG-LP

For every fixed `p>0`,

\[
\boxed{
\Gamma(p+1)\bigl(1-2^{-(p+1)}\bigr)
\le
\liminf_{m\to\infty}\mathbb E A_m^p
\le
\limsup_{m\to\infty}\mathbb E A_m^p
\le
\Gamma(p+1).
}
\tag{4.1}
\]

For `0<p<2`, define the finite constant

\[
C_p^+
:=p\int_0^\infty
 t^{p-1}\bigl[1-D(e^t)\bigr]dt.
\tag{4.2}
\]

Then

\[
\boxed{
\limsup_{m\to\infty}\mathbb E B_m^p\le C_p^+\le\Gamma(p+1),
}
\tag{4.3}
\]

and hence

\[
\boxed{
\limsup_{m\to\infty}\mathbb E|\log Y_m|^p
\le \Gamma(p+1)+C_p^+
\le2\Gamma(p+1),
\qquad 0<p<2.
}
\tag{4.4}
\]

For `p=1`, (4.2) agrees with the exact constant computed in the preceding run,

\[
C_1^+=\frac54-\gamma_E.
\tag{4.5}
\]

### Proof of (4.1)

The layer-cake identity gives

\[
\mathbb EA_m^p
=p\int_0^\infty t^{p-1}\Pr(A_m>t)dt.
\]

The upper bound follows immediately from (3.1):

\[
\mathbb EA_m^p
\le p\int_0^\infty t^{p-1}e^{-t}dt
=\Gamma(p+1).
\]

For the lower bound, use (1.6) at `lambda=e^{-t}`. On the first Dawson interval, (2.2) gives

\[
\Pr(A_m>t)
\ge e^{-t}-\frac12e^{-2t}-\varepsilon_{m,K}
\]

for `0<=t<=K log m`. The integrated error is

\[
O\bigl(\varepsilon_{m,K}(\log m)^p\bigr)=o(1),
\]

and the truncated limiting tail beyond `K log m` vanishes. Therefore

\[
\liminf_m\mathbb EA_m^p
\ge p\int_0^\infty t^{p-1}
\left(e^{-t}-\frac12e^{-2t}\right)dt
=\Gamma(p+1)\left(1-2^{-(p+1)}\right).
\]

### Proof of (4.3)

Again by layer cake,

\[
\mathbb EB_m^p
=p\int_0^\infty t^{p-1}\Pr(B_m>t)dt.
\]

Fix `K>p+2`. On `[0,K log m]`, (1.6) gives the sharper bound

\[
\Pr(B_m>t)
\le 1-D(e^t)+\varepsilon_{m,K}.
\]

The integrated error is `o(1)`, and because of (2.1),

\[
1-D(e^t)\le e^{-t},
\]

so the limiting integral is finite and bounded by `Gamma(p+1)`.

At `t=K log m`, (3.2) gives

\[
\Pr(B_m>K\log m)
\le m^{-K}+C_Km^{-2}+e^{-c_Km}.
\tag{4.6}
\]

By monotonicity, the contribution from `[K log m,2m]` is at most

\[
(2m)^p\left(m^{-K}+C_Km^{-2}+e^{-c_Km}\right)=o(1)
\]

exactly when `p<2`.

For `t>=2m`, fix one square minor `G_m`. Since

\[
Y_m\le L_ma_m s_{\min}(G_m)
\le \frac{L_ma_m}{\sqrt m}\|G_m\|_F
\]

and `log(L_ma_m/sqrt(m))<1.5m` for all sufficiently large `m`, the event `B_m>t` implies

\[
\|G_m\|_F>e^{t-1.5m}.
\]

But `||G_m||_F` is chi with `m^2` degrees of freedom. At `t>=2m` its threshold is at least `e^{m/2}`, so the chi tail is super-exponentially small, and its contribution to every fixed polynomial moment is `o(1)`. This proves (4.3), and (4.4) follows because `A_mB_m=0`. QED.

The threshold `p=2` is informative: with only one- and two-point information, the aggregate `m^{-2}` correlation floor is just large enough to survive a second-moment integration over a linear logarithmic range.

## 5. Endpoint `p=2`: uniform L2 control still holds

The preceding proof does not give the sharp limiting constant at `p=2`, but it does give boundedness.

### Corollary P08-LOG-L2-BOUND

There exists an absolute finite constant `C` such that for all sufficiently large `m`,

\[
\boxed{
\mathbb E|\log Y_m|^2\le C.
}
\tag{5.1}
\]

### Proof

The negative side satisfies `E A_m^2<=Gamma(3)=2`. For the positive side, take any fixed `K>2`. The interval `[0,K log m]` is uniformly bounded by the exponential envelope (3.2). On `[K log m,2m]`, (4.6) gives

\[
2\int_{K\log m}^{2m}t\Pr(B_m>t)dt
\le 4m^2\left(m^{-K}+C_Km^{-2}+e^{-c_Km}\right)=O(1).
\]

The tail above `2m` is super-exponentially small by the fixed-minor Frobenius argument. QED.

This upgrades the previous exact-scale `L^1` control to unconditional `L^2` boundedness of the logarithmic hard-edge factor.

## 6. Transfer to the source normalization

Let

\[
R_m=\max_{1\le i\le2m-1}\|a_i\|_2,
\qquad
X_m=-\frac1m\log\frac{\omega(A_m)}{R_m},
\]

and define the exact second-order centering

\[
c_m=\log4+\frac{\log m}{2m}-\frac{\log(2\sqrt\pi)}m.
\tag{6.1}
\]

Also put

\[
T_m=m(X_m-c_m).
\tag{6.2}
\]

From (1.3),

\[
T_m
=-\log Y_m+\log\frac{R_m}{\sqrt m}+\delta_m,
\tag{6.3}
\]

where

\[
\delta_m
=\log\left(\frac{L_ma_m}{4^m/(2\sqrt\pi)}\right)
=O(m^{-1})
\tag{6.4}
\]

by Stirling. In fact the first coefficient is `-3/(8m)`, but only `o(1)` is needed here.

### Row-norm error

For a single Gaussian row, the Euclidean norm is 1-Lipschitz. Standard Gaussian norm concentration and a union bound over `2m-1` rows give

\[
\mathbb E\left(\log\frac{R_m}{\sqrt m}\right)_+^2
=O\left(\frac{\log m}{m}\right).
\tag{6.5}
\]

For the negative part, `R_m>=||a_1||_2`; the chi-density lower-tail moments give

\[
\mathbb E\left(\log\frac{R_m}{\sqrt m}\right)_-^2
=O(m^{-1}).
\tag{6.6}
\]

Therefore

\[
\boxed{
\log(R_m/\sqrt m)\longrightarrow0
\quad\text{in }L^2.
}
\tag{6.7}
\]

### Corollary P08-SOURCE-L2

Combining (5.1), (6.3) and (6.7),

\[
\boxed{
\sup_{m\gg1}\mathbb E|T_m|^2<\infty.
}
\tag{6.8}
\]

Equivalently,

\[
\boxed{
\mathbb E|X_m-c_m|^2=O(m^{-2}),
\qquad
\operatorname{Var}(X_m)=O(m^{-2}).
}
\tag{6.9}
\]

For every `1<=p<2`, the sharper limiting bound transfers from (4.4):

\[
\boxed{
\limsup_{m\to\infty}\mathbb E|T_m|^p
\le\Gamma(p+1)+C_p^+
\le2\Gamma(p+1).
}
\tag{6.10}
\]

Thus the second-order localization of the source exponent is now unconditional in every `L^p`, `1<=p<=2` (with an explicit limiting constant for `p<2` and boundedness at `p=2`).

## 7. Source-facing moderate-deviation form

The row norm can also be removed with high probability rather than only in moments. Gaussian norm concentration gives an absolute `C_0` such that

\[
\Pr\left\{\left|\log\frac{R_m}{\sqrt m}\right|>
C_0\sqrt{\frac{\log m}{m}}\right\}=O(m^{-3}).
\tag{7.1}
\]

Hence, for every fixed `K`, uniformly for `0<=t<=K log m`,

\[
\boxed{
\Pr\left\{
|X_m-c_m|>
\frac{t+C_0\sqrt{(\log m)/m}+O(m^{-1})}{m}
\right\}
\le
2e^{-t}+C_Km^{-2}+C_Ke^{-c_Km}.
}
\tag{7.2}
\]

This is a dependence-aware, exact-second-order high-probability refinement of the published exponential-scale theorem (1.2). It uses only the proved one- and two-minor machinery; the exponentially many minors are never treated as independent.
