# 2. New deterministic theorem: projected-hinge descent needs only the actual excess direction

Fix a threshold `tau>=0`. For a feasible accumulated correction
\[
q\in\operatorname{Ran}(P_C),
\]
put
\[
r=x-q,
\qquad
e=(r-\tau\mathbf 1)_+,
\qquad
H=\|e\|_2^2.
\tag{2.1}
\]
Here the positive part is coordinatewise.

Define the next feasible correction by
\[
\boxed{
q^+=q+\eta P_Ce,
}
\tag{2.2}
\]
where `0<eta<2`. Since `P_Ce` lies in `Ran(P_C)`, every iterate is an exact feasible Fourier-dual correction for (1.1).

## Theorem P07-B.6 — inversion-free directional contraction

For (2.1)-(2.2),
\[
\boxed{
\|(x-q^+-\tau\mathbf1)_+\|_2^2
\le
H-(2\eta-\eta^2)\|P_Ce\|_2^2.
}
\tag{2.3}
\]
In particular, at the canonical unit step `eta=1`,
\[
\boxed{
H^+\le H-\|P_Ce\|_2^2.
}
\tag{2.4}
\]
Therefore if
\[
R(e):=\frac{\|P_Ce\|_2^2}{\|e\|_2^2}
\tag{2.5}
\]
is at least `gamma`, then
\[
\boxed{H^+\le(1-\gamma)H.}
\tag{2.6}
\]

### Proof

Let
\[
\Phi(u)=\frac12\|u_+\|_2^2.
\]
The scalar map `t -> (t_+)^2/2` has derivative `t_+`, which is 1-Lipschitz. Hence `Phi` has 1-Lipschitz gradient and for arbitrary `h`,
\[
\Phi(u+h)\le\Phi(u)+\langle u_+,h\rangle+\frac12\|h\|_2^2.
\tag{2.7}
\]
Take
\[
u=r-\tau\mathbf1,
\qquad u_+=e,
\qquad h=-\eta P_Ce.
\]
Because `P_C` is an orthogonal projector,
\[
\langle e,P_Ce\rangle=\|P_Ce\|_2^2.
\]
Substitution into (2.7) gives
\[
\frac12H^+
\le
\frac12H
-\eta\|P_Ce\|_2^2
+\frac{\eta^2}{2}\|P_Ce\|_2^2,
\]
which is exactly (2.3). Setting `eta=1` gives (2.4), and dividing by `H` gives (2.6). ∎

This theorem requires neither inversion of an endogenous Fourier minor nor a uniform lower eigenvalue bound.

# 3. The new directional condition strictly weakens the previous Schur condition

Let
\[
S=\operatorname{supp}(e),
\qquad e=E_Sw,
\qquad M_S=P_C[S,S].
\]
Then
\[
\|P_Ce\|_2^2
=\langle e,P_Ce\rangle
=w^TM_Sw,
\]
so the directional ratio is simply
\[
\boxed{
R(e)=\frac{w^TM_Sw}{w^Tw}.
}
\tag{3.1}
\]
The preceding report instead used the exact Schur interpolant and, when `M_S` was invertible, the effective inverse-direction margin
\[
\gamma_{\rm Schur}(w)
:=
\frac{w^Tw}{w^TM_S^{-1}w}.
\tag{3.2}
\]
Cauchy-Schwarz in the eigenbasis of `M_S` gives
\[
(w^TM_Sw)(w^TM_S^{-1}w)\ge(w^Tw)^2,
\]
hence
\[
\boxed{
R(e)\ge\gamma_{\rm Schur}(w).
}
\tag{3.3}
\]
Thus the unit projected-hinge step contracts at least as strongly as the optimally damped Schur estimate available from the same direction, while also remaining well-defined if `M_S` is singular.

In particular, the old target
\[
\lambda_{\min}(M_S)\ge\gamma
\]
is sufficient but substantially stronger than necessary. The true object exposed by the algorithm is only the endogenous Rayleigh quotient (3.1).

This is the first major simplification of the P07-B bottleneck in this run.

# 4. Exact cumulative lemma sufficient to remove the iterated logarithm

Run the unit iteration
\[
q_0=0,

r_k=x-q_k,
\quad
e_k=(r_k-\tau\mathbf1)_+,

\[

\tag{4.2}

Theorem P07-B.6 gives
\[
H_{k+1}\le(1-R_k)H_k
\le e^{-R_k}H_k.

Since initially
\[
H_0\le\|x\|_2^2=d/n\le1,

\boxed{

\tag{4.3}

\[

\tag{4.4}

H_K\le\eta^2/n,

\max_j r_K(j)
\le\tau+\|e_K\|_\infty
\le\tau+\eta/\sqrt n.

Thus
\[
\boxed{

\tag{4.5}

This yields the following exact probabilistic target, strictly weaker than `APBM`.

Moreover
\[
P_C\delta_0

\boxed{

## 5.1 Dependence-aware empirical hinge moments

For `j != 0`, write `epsilon_a=2xi_a-1`. The exact source representation from the preceding report is
\[
x(j)
=-\frac1{2n}
+\frac1n\sum_{a=1}^{m}
\varepsilon_a\cos(2\pi aj/n).
\tag{5.5}
\]
Define
\[
Y_j=\sqrt n\left(x(j)+\frac1{2n}\right).
\tag{5.6}
\]
The previous report established the exact second-order dependence:
\[
\operatorname{Var}(Y_j)=\frac{n-2}{4n},
\]
and, for `k` not congruent to `+/-j`,
\[
\operatorname{Cov}(Y_j,Y_k)=-\frac1{2n},
\tag{5.7}
\]
while `Y_{-j}=Y_j` exactly.

The Rademacher summands in (5.6) are uniformly `O(n^{-1/2})`. Hence the one-dimensional triangular arrays converge uniformly to `N(0,1/4)`. For each non-antipodal pair `(j,k)`, the two-dimensional covariance matrix converges uniformly to `(1/4)I_2`, and the sum of third absolute moments is `O(n^{-1/2})`; the same two-dimensional Berry-Esseen argument used in the preceding threshold-count theorem therefore gives uniform asymptotic independence for bounded Lipschitz test functions.

For the hinge functions below, truncate first at a fixed level. Uniform subgaussian moment bounds for the Rademacher sums make the truncation error uniformly small in every fixed `L^p`; then let the truncation level tend to infinity. The `O(n)` antipodal pairs contribute negligibly to the variance of the empirical averages, while the `O(n^2)` non-antipodal pairs have covariance tending uniformly to zero. Consequently, for
\[
g_A(z)=(z/2-A)_+,
\]
we obtain the `L^2`, hence in-probability, empirical laws
\[
\boxed{
\frac{s}{\sqrt n}
\longrightarrow
\mu_A:=\mathbb E g_A(Z),
}
\tag{5.8}
\]
and
\[
\boxed{
H
\longrightarrow
\frac14+\nu_A,
\qquad
\nu_A:=\mathbb E g_A(Z)^2,
}
\tag{5.9}
\]
where `Z~N(0,1)`. The `1/4` in (5.9) is the origin contribution: `x(0)=d/n -> 1/2` in probability, while `tau ->0`.

Writing `phi` and `Phi` for the standard normal density and CDF and `Q=1-Phi`, elementary Gaussian integration gives
\[
\boxed{
\mu_A
=\frac12\phi(2A)-A Q(2A),
}
\tag{5.10}
\]
and
\[
\boxed{
\nu_A
=\frac14\left[(1+4A^2)Q(2A)-2A\phi(2A)\right].
}
\tag{5.11}
\]

## 5.2 Exact Gaussian cancellation

From (5.4), (5.8), (5.9), `e(0)->1/2`, and `s/n->0`,

\langle e,P_C\delta_0\rangle
\longrightarrow

\[

Therefore

\longrightarrow

in probability.

Now `u=P_Cdelta_0` belongs to `Ran(P_C)`, so

Cauchy-Schwarz and (5.2) yield

\|P_Ce\|_2^2
\ge

Since `c/n -> 1/2` in probability and `H -> 1/4+nu_A`, we have proved:

\[
\boxed{
\liminf_{n\to\infty}^{\mathbb P}
\frac{\|P_C(x-A\mathbf1/\sqrt n)_+\|_2^2}

# 6. Exact stall-to-primal bridge for P07-A

The projected-hinge descent has a useful exact dichotomy connecting the P07-B dual route to P07-A's positive-Fourier primal route.

Suppose for some iterate `q` the excess
\[
e=(x-q-\tau\mathbf1)_+
\]
is nonzero but
\[
P_Ce=0.
\tag{6.1}
\]
Then
\[
e\in\operatorname{Ran}(P_0+P_D),
\qquad e\ge0.
\]
Let
\[
s=\|e\|_1,
\qquad p=e/s.
\]
Then `p` is an **exact primal-feasible probability vector** in the source Fourier LP: `p>=0`, `sum p=1`, and it has no `C` Fourier component.

Furthermore, because `q` lies in `Ran(P_C)`,
\[
\langle e,q\rangle=0.
\]
On the active set,
\[
x-q=\tau\mathbf1+e,
\]
so
\[
\langle e,x-q\rangle
=\tau s+H.
\tag{6.2}
\]
On the other hand, since `x=P_Ddelta_0` and `e in Ran(P_0+P_D)`,
\[
\langle e,x\rangle
=e(0)-s/n.
\tag{6.3}
\]
Combining (6.2)-(6.3) gives
\[
\boxed{
p(0)-\frac1n
=\tau+\frac{H}{s}.
}
\tag{6.4}
\]
Hence the primal LP immediately certifies
\[
\boxed{
\vartheta(G)\ge n p(0)
=1+n\tau+nH/s
>1+n\tau.
}
\tag{6.5}
\]

So an exact nonzero stall is not an algorithmic mystery: it *is itself a primal witness showing that the chosen threshold is too low*.

There is also a quantitative near-stall statement. For arbitrary nonzero `e`,
\[
\operatorname{dist}
\left(
\frac e{\|e\|_1},
\operatorname{Ran}(P_0+P_D)
\right)
=
\frac{\|P_Ce\|_2}{\|e\|_1}
\le
\sqrt{R(e)}.
\tag{6.6}
\]
Thus a small directional ratio produces a nonnegative probability vector that is quantitatively close in `l^2` to the primal allowed Fourier subspace.

This is the clean handoff to P07-A's current support/entropy program: a theorem ruling out **near-positive, near-bandlimited source witnesses** above the relevant spike scale would directly prevent long low-`R_k` stretches in P07-B. Conversely, P07-B should not duplicate P07-A's support enumeration; the dual role can focus on converting any such robust primal exclusion into cumulative leakage via (6.6).
