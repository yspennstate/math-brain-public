## 2. Inherited renewal block and the limitation of one-sided capping

Let

\[
G_1,G_2,\ldots,H_1,H_2,\ldots\stackrel{iid}{\sim}\operatorname{Geom}(1/2),
\qquad \Pr(G=k)=2^{-k},\quad k\ge1,
\]

and phase-randomize the two alternating-run strings. For the first `r` complete runs on each side write

\[
\bar\rho_r=\frac{\mathbf E\,LCS(X^{(r)},Y^{(r)})}{2r}.
\]

The inherited P05 theorem gives `bar rho_(2m) -> gamma_2`.

The preceding report capped only one source at `M` and proved

\[
0\le \gamma_2-a_M\le2^{-M}.
\]

That construction is monotone and therefore useful for lower bounds, but its error is one-sided: every tail approximation deletes symbols. The present theorem uses the *other* median of the geometric tail, preserving mean run length and balancing insertions against deletions. The resulting approximation is not monotone, but its two-sided error is smaller by an exact factor two.

## 3. New balanced M-state quantizer

For `M>=1`, define

\[
\boxed{
Q_M(g)=
\begin{cases}
g,&g<M,\\
M+1,&g\ge M.
\end{cases}}
\tag{3.1}
\]

Its range is

\[
\{1,2,\ldots,M-1,M+1\},
\]

so it has exactly `M` run-length states (for `M=1`, the sole state is `2`). The value `M` is deliberately skipped.

Put

\[
\delta_M:=G-Q_M(G).
\]

On the tail event `G>=M`, whose probability is `2^{-(M-1)}`, write `G=M+E`; then

\[
\Pr(E=e)=2^{-(e+1)},\qquad e=0,1,2,\ldots,
\]

and `delta_M=E-1`. Since `E E=1` and `Var(E)=2`, the following identities are exact:

\[
\boxed{\mathbf E\delta_M=0,}
\tag{3.2}
\]

\[
\boxed{
\mathbf E(\delta_M)_+
=\mathbf E(-\delta_M)_+
=2^{-M},
}
\tag{3.3}
\]

\[
\boxed{\mathbf E|\delta_M|=2^{1-M},\qquad
\mathbf E\delta_M^2=2^{2-M}.}
\tag{3.4}
\]

Also

\[
\boxed{\mathbf E Q_M(G)=2,}
\tag{3.5}
\]

because

\[
\sum_{k=1}^{M-1}\frac{k}{2^k}
+\frac{M+1}{2^{M-1}}
=2.
\]

Thus the finite-state surrogate has exactly the same mean run length as the true source. This is the key distinction from truncation.

## 4. Deterministic common-core inequality

Take any positive run vectors `g=(g_1,...,g_r)` and `q=(q_1,...,q_r)` with the same alternating phase. Let `x(g),x(q)` be the corresponding binary run strings and let

\[
c_i=\min(g_i,q_i).
\]

The run string `x(c)` is a common subsequence of both `x(g)` and `x(q)`. Define the two directed discrepancies

\[
A=\sum_i(g_i-q_i)_+,
\qquad
B=\sum_i(q_i-g_i)_+.
\]

For every deterministic comparison string `y`, deleting `A` symbols from `x(g)` reaches the common core, while deleting `B` symbols from `x(q)` reaches the same core. Therefore

\[
LCS(x(g),y)\le LCS(x(c),y)+A\le LCS(x(q),y)+A,
\]

and symmetrically

\[
LCS(x(q),y)\le LCS(x(g),y)+B.
\]

Hence

\[
\boxed{
|LCS(x(g),y)-LCS(x(q),y)|\le\max(A,B).
}
\tag{4.1}
\]

The point is that the penalty is the larger *directed* edit mass, not the total absolute edit mass `A+B`. Centering the run error makes the two directed masses cancel to first order over many renewal epochs.

For simultaneous approximations on both inputs, with directed discrepancies `(A_X,B_X)` and `(A_Y,B_Y)`, the same core argument gives

\[
\boxed{
|LCS(X,Y)-LCS(\widetilde X,\widetilde Y)|
\le
\max(A_X+A_Y,\;B_X+B_Y).
}
\tag{4.2}
\]

No probabilistic independence is used in (4.1)-(4.2).

## 5. One-sided centered bridge: factor-two asymptotic improvement

Quantize only the left run lengths by `Q_M`, leave the right source exact, and define

\[
\widehat\rho^{(1)}_{r,M}
=\frac{\mathbf E\,LCS(\widetilde X^{(r,M)},Y^{(r)})}{2r}.
\]

Let

\[
A_r=\sum_{i=1}^r(\delta_{M,i})_+,
\qquad
B_r=\sum_{i=1}^r(-\delta_{M,i})_+,
\qquad
S_r=A_r-B_r=\sum_{i=1}^r\delta_{M,i}.
\]

By (4.1),

\[
|\bar\rho_r-\widehat\rho^{(1)}_{r,M}|
\le\frac{\mathbf E\max(A_r,B_r)}{2r}.
\]

Using `max(a,b)=(a+b+|a-b|)/2` and (3.3)-(3.4), this is the exact comparison budget

\[
\boxed{
|\bar\rho_r-\widehat\rho^{(1)}_{r,M}|
\le
2^{-(M+1)}+
\frac{\mathbf E|S_r|}{4r}.
}
\tag{5.1}
\]

Because `E S_r=0` and `Var(S_r)=r 2^{2-M}`, Cauchy--Schwarz yields the explicit finite-r form

\[
\boxed{
|\bar\rho_r-\widehat\rho^{(1)}_{r,M}|
\le
2^{-(M+1)}+
\frac{2^{-1-M/2}}{\sqrt r}.
}
\tag{5.2}
\]

For fixed `M`, the same fixed-phase even-run superadditivity used in the preceding one-sided-cap report gives a limit

\[
\widehat a_M^{(1)}
:=\lim_{m\to\infty}\widehat\rho^{(1)}_{2m,M}.
\]

(The two relative-phase limits differ only by an `O(1)` boundary deletion, exactly as before.) Since `bar rho_(2m)->gamma_2`, (5.2) gives the new asymptotic bridge

\[
\boxed{
|\gamma_2-\widehat a_M^{(1)}|\le2^{-(M+1)}.
}
\tag{5.3}
\]

The previous one-sided cap had error `2^{-M}`. Thus at the **same M run-length states** the centered construction halves the asymptotic transfer error.

The finite-r bound (5.2) is already strictly better than the old cap error once `r>2^M`; at `r=2^M` the two explicit budgets are equal.

Important honesty point: `widehat a_M^(1)` is not asserted to lie below `gamma_2`. The gain is a smaller two-sided approximation error, not monotonicity.

## 6. Fully finite two-sided surrogate

Apply `Q_M` independently to both run sources and define

\[
\widehat\rho^{(2)}_{r,M}
=\frac{\mathbf E\,LCS(\widetilde X^{(r,M)},\widetilde Y^{(r,M)})}{2r}.

Now both sources have the finite run alphabet

\[
\{1,\ldots,M-1,M+1\}

with probabilities

\[
2^{-1},2^{-2},\ldots,2^{-(M-1)},2^{-(M-1)}
\]

where the last displayed probability belongs to `M+1` and the value `M` is absent. This is a genuinely finite exact source, with mean run length exactly two.

Applying (4.2) to the `2r` independent centered errors gives

\[
\boxed{
|\bar\rho_r-\widehat\rho^{(2)}_{r,M}|
\le
2^{-M}+
\frac{2^{-(M+1)/2}}{\sqrt r}.
}
\tag{6.1}
\]

The even-run limit

\[
\widehat a_M^{(2)}:=\lim_{m\to\infty}\widehat\rho^{(2)}_{2m,M}

therefore obeys

\[
\boxed{
|\gamma_2-\widehat a_M^{(2)}|\le2^{-M}.
}
\tag{6.2}
\]

The old symmetric two-sided cap paid `2^{-(M-1)}`. Hence the balanced finite-alphabet surrogate halves that error too. Equivalently, for the same transfer budget it saves one complete run-alphabet level.

The explicit finite-r bound (6.1) beats the old symmetric cap budget once `r>2^{M-1}`.

## 7. New optimality theorem inside scalar run quantization

The factor-two gain above is not obtainable by merely finding a scalar quantizer with smaller mean absolute run error: the old cap is already optimal for that objective. The improvement comes from *balancing the two directional errors*.

Let

\[
D_K:=\inf_{Q:\,|\operatorname{range}(Q)|\le K}
\mathbf E|G-Q(G)|,
\]

where `Q` ranges over deterministic positive-integer run quantizers.

### Theorem 7.1 — exact K-point L1 quantization of the fair geometric law

For every `K>=1`,

\[
\boxed{D_K=2^{1-K}.}
\tag{7.1}
\]

#### Proof

For an ordered one-dimensional L1 quantizer, crossing assignments can be uncrossed by the Monge inequality

\[
|x-a|+|y-b|\le |x-b|+|y-a|
\quad(x\le y,\ a\le b),
\]

so an optimum may be taken to have contiguous clusters. On any finite cluster `[a,b]` of the geometric weights, the mass at `a` exceeds the total mass strictly to its right, hence the unique weighted median is `a`. On the infinite tail `[a,\infty)`, both `a` and `a+1` are weighted medians.

Set `D_1=1`; indeed either representative `1` or `2` has expected absolute error one. For `K>=2`, let `b>=2` be the first point assigned to the second cluster. The first cluster `[1,b-1]` contributes

\[
\sum_{g=1}^{b-1}(g-1)2^{-g}
=1-\frac{b}{2^{b-1}}.
\]

By geometric memorylessness, the tail beginning at `b` has total mass `2^{-(b-1)}` and, after translation, is another copy of the original law. Thus

\[
D_K=\min_{b\ge2}
\left(
1-\frac{b}{2^{b-1}}
+\frac{D_{K-1}}{2^{b-1}}
\right)
=1-\max_{b\ge2}\frac{b-D_{K-1}}{2^{b-1}}.
\tag{7.2}
\]

Inductively `D_{K-1}=2^{2-K}=:d<=1`. For `K=2`, `d=1` and the maximum is attained at `b=2,3`, giving `D_2=1/2`. For `K>=3`, `d<1`, and

\[
\frac{(b+1-d)/2^b}{(b-d)/2^{b-1}}
=\frac{b+1-d}{2(b-d)}<1
\qquad(b\ge2),
\]

so the maximum is uniquely at `b=2`. Therefore

\[
D_K=\frac{D_{K-1}}2=2^{1-K}.
\]

QED.

Now write for any scalar quantizer

\[
\alpha=\mathbf E(G-Q(G))_+,
\qquad
\beta=\mathbf E(Q(G)-G)_+.
\]

Then

\[
\max(\alpha,\beta)
\ge\frac{\alpha+\beta}{2}
=\frac{\mathbf E|G-Q(G)|}{2}
\ge2^{-K}.
\]

The asymptotic one-sided common-core budget is `max(alpha,beta)/2`, hence every `K`-state scalar quantizer used through this proof architecture must pay at least

\[
\boxed{2^{-(K+1)}.}
\tag{7.3}
\]

The balanced quantizer `Q_K` attains equality because (3.3) gives `alpha=beta=2^{-K}`. Thus:

\[
\boxed{
\text{the factor-two centered bridge is optimal among deterministic K-state scalar run quantizers under the common-core/Lipschitz transfer.}
}
\tag{7.4}
\]

This is an architecture-level optimality statement, not a claim that no block/vector or LCS-specific comparison can do better.

A useful interpretation is that both tail representatives `M` and `M+1` are L1-optimal medians of the infinite geometric tail. The old cap chooses `M`, putting all error in the deletion direction. The new quantizer chooses `M+1`, and geometric memorylessness makes the directional errors exactly equal, cutting the relevant `max` cost in half without increasing the state count or the scalar L1 distortion.
