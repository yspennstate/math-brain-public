## 2. Inherited exact uncapped crossing quotient

Binary run lengths are iid
\[
\Pr(G=k)=2^{-k},\qquad k=1,2,\ldots .
\]

Fix a threshold \(M\ge2\). A fresh run is represented by category \(j<M\) if
\(G=j\), and by tail category \(M\) if \(G\ge M\). Conditional on the tail,
\[
G=M+E,\qquad \Pr(E=e)=2^{-(e+1)},\quad e\ge0.
\tag{2.1}
\]

The preceding report proved that the residual after matching same-symbol runs closes exactly on the finite crossing alphabet
\[
\mathcal C_M=
\{E(d):-(M-1)\le d\le M-1\}
\cup
\{T^+(r),T^-(r):1\le r\le M\},
\tag{2.2}
\]
with \(4M-1\) crossing types. The key identity is
\[
\Pr(E-F=0)=\frac13,\qquad
\Pr(E-F=\pm k)=\frac{2^{-k}}3,\quad k\ge1,
\tag{2.3}
\]
for iid zero-based geometric \(E,F\). Hence no run overflow is discarded and there is no tail truncation error.

The same report also proved the arbitrary-length bridge: a uniform Bellman subsolution with average matched reward \(g\) per crossing epoch yields
\[
\gamma_2\ge g/2.
\tag{2.4}
\]
The factor \(1/2\) is an exact run-cost normalization, not a simulation convention: the quotient epoch completes two original runs total; source-exchange symmetry gives asymptotically one completed run per source per epoch; and an original run has mean length two.

The previous exact uncapped certificate retained three future quota categories per source and, at \(M=8\), proved
\[

=0.776224526037597\ldots .
\tag{2.5}

## 3. New idea: one more legally retained future category

The obstacle after (2.5) is not the geometric tail itself; it is the information available when choosing which side of a run crossing to delete.

For an integer \(K\ge2\), define a quotient state
\[
s=(c;a_1,\ldots,a_K;b_1,\ldots,b_K),
\qquad c\in\mathcal C_M,
\tag{3.1}
\]
where \(a_i,b_i\in\{1,\ldots,M\}\) are exact-or-tail categories of future alternating runs.

This run takes \(K=4\), so after the active residual there are four retained future categories per source. Counting the active residual as the current quota, this is the five-quota version of the renewal policy.

Suppose \(c\) is a positive residual from source A. There are still only two primitive source-valid crossing actions.

**L (delete the active residual).** Delete A's active residual, then align `a1` with `b1`. Before choosing L/R, reveal
\[
Q=b_{K+1}.
\]
After the `a1,b1` comparison, the next state's future lists are
\[
(a_2,\ldots,a_K,A_{K+1};
 \ b_2,\ldots,b_K,Q).
\tag{3.2}
\]
The branch-unique \(A_{K+1}\) is averaged before the action comparison.

**R (delete the intervening opposite-symbol run).** Delete B's `b1`, then align the active residual against `b2`. The next state's future lists are
\[
(a_1,\ldots,a_K;
 \ b_3,\ldots,b_K,Q,B_{K+2}).
\tag{3.3}
\]
The branch-unique \(B_{K+2}\) is averaged before the action comparison.

The important point is that \(Q=b_{K+1}\) occurs in **both** candidate next states (3.2) and (3.3). It may therefore be revealed before taking the maximum without conditioning on branch-specific information that is subsequently forgotten. Negative crossings are obtained by exact source exchange.

This is the same legality principle as the preceding three-future-category certificate, but with one more retained coordinate.

### Lemma P05-R7.1 — exact K-future Bellman bridge

Let \(F_{M,K}\) be the finite Bellman operator on the states (3.1), using the exact geometric-tail transitions (2.1)--(2.3), the two legal actions (3.2)--(3.3), and source-exchange symmetry. If a bounded potential \(\phi\) and \(g\in\mathbb R\) satisfy
\[
(F_{M,K}\phi)(s)-\phi(s)\ge g
\qquad\text{for every state }s,
\tag{3.4}
\]
then
\[
\boxed{\gamma_2\ge g/2}.
\tag{3.5}
\]

**Proof.**
At each state choose an action attaining the Bellman maximum. Because the only newly revealed pre-decision category is the common \(Q\), this defines a valid nonanticipating alignment on the original iid run sequences.

Let \(R_t\) be cumulative matched symbols and \(S_t\) the quotient state. Equation (3.4) gives
\[
\mathbf E\!\left[
(R_{t+1}-R_t)+\phi(S_{t+1})-\phi(S_t)
\mid S_t
\right]\ge g.
\]
Summing for \(t<T\), the potential telescopes. Since the finite-state potential is bounded,
\[
\mathbf E R_T\ge Tg-O(1).
\tag{3.6}
\]

The added future coordinate changes information only; it does not change the primitive L/R run accounting. Thus the two-original-runs-per-epoch argument from the uncapped crossing quotient remains exact. With source-exchange-symmetric tie breaking, the recurrent law is exchange invariant, so each source completes one run per epoch asymptotically. Original run lengths are iid `Geom(1/2)` with mean two. Hence each source consumes two original symbols per epoch asymptotically, and (3.6) gives (3.5). QED.

### Lemma P05-R7.2 — lookahead monotonicity

For fixed \(M\), the best exact certificate obtainable from this hierarchy cannot decrease when \(K\) is increased by one.

**Proof.**
A \(K+1\)-future policy can ignore its last retained coordinates and emulate any \(K\)-future policy. More explicitly, in the \(K+1\) state the category \(b_{K+1}\) that served as the shared pre-decision variable \(Q\) for the \(K\)-policy is already retained. Under L, the first \(K\) future B coordinates after the transition are
\[
b_2,\ldots,b_K,b_{K+1},
\]
exactly the K-policy's B continuation. Under R, they are
\[
b_3,\ldots,b_K,b_{K+1},b_{K+2},
\]
again exactly the K-policy continuation after averaging the branch-unique final coordinate. The A side is identical. Lifting a K-state policy/potential by ignoring the extra coordinate therefore preserves its Bellman inequality, while the \(K+1\) operator has at least the same actions. QED.

This lemma is useful because the extra lookahead is not merely a larger Monte Carlo state: it is a nested family of rigorous lower certificates for the original infinite strings.

## 7. Remaining mathematical gap and next attack

The next attack should therefore target **the action alphabet, not another raw coordinate**:

1. Canonically quotient source exchange so negative crossing orientations are never materialized.
2. Stream Bellman slabs instead of storing the whole tensor, freeing enough memory for a controlled extra action state.
3. Add a rigorously run-costed two-crossing option that can postpone the L/R decision through one additional phase, represented as a semi-Markov Bellman inequality
   \[
   \mathbf E[\text{matches}-\lambda\,\text{source symbols}+\Delta\phi]\ge0.
   \]
4. Require the macro to retain every revealed run category until it is consumed or explicitly averaged, so there is no reveal-and-forget conditioning.
5. First test the macro on the extremal state family (7.1). Only if it improves the exact residual there should it be promoted to a full-state certificate.
