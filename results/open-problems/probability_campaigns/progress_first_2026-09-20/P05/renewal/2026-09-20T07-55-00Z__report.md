## 2. Old obstruction and the new idea

The preceding report compared a phase-randomized `r`-run renewal block to a deterministic length-`2r` iid block by the triangle inequality

\[
|LCS(X_1^{T_r},Y_1^{S_r})-LCS(X_1^{2r},Y_1^{2r})|
\le |T_r-2r|+|S_r-2r|.
\]

That gave the exact boundary penalty

\[
\frac{\binom{2r}{r}}{2^{2r-1}}
\sim \frac{2}{\sqrt{\pi r}}.
\]

The new observation is that LCS prefix values are not merely separately 1-Lipschitz. They are **jointly 1-Lipschitz in the `L_infinity` distance of the two prefix endpoints**. This replaces the sum of the two endpoint fluctuations by their maximum.

That is a genuine theorem about deterministic LCS tables and yields a strictly sharper arbitrary-length bridge.

## 3. Deterministic theorem: prefix-endpoint `L_infinity` stability

For fixed strings `X,Y`, write

\[
F(m,n):=LCS(X_1^m,Y_1^n).
\]

### Lemma P05-R10.1 — suffix-extension bound

For arbitrary finite strings `x,y,u,v`,

\[
\boxed{
0\le LCS(xu,yv)-LCS(x,y)\le \max\{|u|,|v|\}.
}
\tag{3.1}
\]

#### Proof

Monotonicity gives the lower bound. Let `M` be an optimal matching for `xu,yv`. Delete from `M` every matched pair having at least one endpoint in one of the appended suffixes `u` or `v`. The surviving pairs form a common subsequence of `x,y`, so it remains to bound how many pairs were deleted.

There are three types of deleted pairs:

1. appended-`u` matched to old-`y`;
2. old-`x` matched to appended-`v`;
3. appended-`u` matched to appended-`v`.

Types 1 and 2 cannot both occur in a single increasing matching. Indeed, a type-1 pair has first coordinate beyond the end of `x` and second coordinate inside `y`, whereas a type-2 pair has first coordinate inside `x` and second coordinate beyond the end of `y`; the two pairs cross in the product order.

If type 1 occurs, every deleted pair uses a distinct position of `u`, hence at most `|u|` pairs are deleted. If type 2 occurs, every deleted pair uses a distinct position of `v`, hence at most `|v|` pairs are deleted. If neither occurs, all deleted pairs are type 3, hence at most `min(|u|,|v|)`. In all cases at most `max(|u|,|v|)` pairs disappear. QED.

### Theorem P05-R10.2 — prefix endpoint stability

For all prefix endpoints `(m,n)` and `(m',n')`,

\[
\boxed{
|F(m,n)-F(m',n')|
\le
\max\{|m-m'|,|n-n'|\}.
}
\tag{3.2}
\]

#### Proof

If the two endpoint pairs are comparable coordinatewise, (3.2) is exactly Lemma P05-R10.1 applied to the shorter rectangle and its two appended suffixes.

Suppose instead, without loss of generality, that `m>=m'` and `n<=n'`. Put `B=F(m',n)`. By appending only to the first string,

\[
0\le F(m,n)-B\le m-m'.
\]

By appending only to the second string,

\[
0\le F(m',n')-B\le n'-n.
\]

Both values therefore lie in the interval

\[
[B,\,B+\max(m-m',n'-n)],
\]

which proves (3.2). QED.

This statement was exhaustively self-checked on every binary pair of lengths at most four and every pair of prefix endpoints, covering `172485` comparisons. That finite self-check is not the proof; it is only an implementation sanity check.

## 4. Sharper stopped-renewal comparison

Use the phase-randomized renewal construction from P05-R9. Let

\[
T_r=\sum_{i=1}^rG_i,\qquad
S_r=\sum_{i=1}^rH_i,
\]

where all run lengths are iid `Geom(1/2)` on `{1,2,...}`. Let

\[
\bar\rho_r
=\frac{\mathbf E\,LCS(X_1^{T_r},Y_1^{S_r})}{2r}.
\]

Theorem P05-R10.2 gives pathwise

\[
\left|
LCS(X_1^{T_r},Y_1^{S_r})
-LCS(X_1^{2r},Y_1^{2r})
\right|
\le
\max\{|T_r-2r|,|S_r-2r|\}.
\tag{4.1}
\]

Set

\[
D_r:=T_r-2r,
\qquad
\mu_r:=\mathbf E|D_r|.
\]

The preceding report proved exactly

\[
\boxed{
\mu_r=
\frac{r\binom{2r}{r}}{2^{2r-1}}.
}
\tag{4.2}
\]

Also `E D_r^2=Var(T_r)=2r`. If `A=|D_r|` and `B=|S_r-2r|`, then `A,B` are iid and

\[
\mathbf E\max(A,B)
=
\mu_r+\frac12\mathbf E|A-B|.
\]

By Cauchy--Schwarz,

\[
\mathbf E|A-B|
\le
\sqrt{\mathbf E(A-B)^2}
=
\sqrt{2\operatorname{Var}(A)}
=
\sqrt{4r-2\mu_r^2}.
\]

Therefore

\[
\boxed{
\left|
\bar\rho_r-
\frac{\mathbf E LCS(X_1^{2r},Y_1^{2r})}{2r}
\right|
\le
\beta_r,
}
\tag{4.3}
\]

where

\[
\boxed{
\beta_r
:=
\frac{\mu_r+\sqrt{r-\mu_r^2/2}}{2r}.
}
\tag{4.4}
\]

This strictly improves the previous use of `mu_r/r` for the renewal endpoint comparison over the large-`r` regime relevant to the bridge.

The Wallis bound

\[
\binom{2r}{r}\le \frac{4^r}{\sqrt{\pi r}}

\mu_r\le 2\sqrt{\frac r\pi}.

For

one has `f_r'(x)>=0` for `x<=2 sqrt(r/3)`. Since `2/sqrt(pi)<2/sqrt(3)`, the above upper bound for `mu_r` lies in the monotone region. Hence

\[
\boxed{
\beta_r
\le
\frac{\kappa}{\sqrt r},
\qquad
\kappa=
\frac1{\sqrt\pi}
+
\frac12\sqrt{1-\frac2\pi}
=0.865594721042299774\ldots .

\tag{4.5}
\]

The previous asymptotic endpoint coefficient was

## 6. Exact structural theorem: the two run actions are complete

The earlier renewal certificates used two primitive crossing actions, `L` and `R`. It was not yet proved in this line that this action alphabet itself is complete for exact LCS, rather than merely defining a family of lower-bound policies. That gap can be closed.

### Lemma P05-R10.3 — run-boundary normal form for binary LCS

Let `x,y` be nonempty binary strings.

1. If the first symbols agree, then repeatedly matching equal first symbols until one first run is exhausted is exact.
2. If the first symbols disagree, write
   \[
   x=c^a x',\qquad y=(1-c)^b y',
   \]
   where `c^a` and `(1-c)^b` are the complete first runs. Then
   \[
   \boxed{
   LCS(x,y)=\max\{LCS(x',y),LCS(x,y')\}.
   }
   \tag{6.1}
   \]

#### Proof

For item 1, the standard LCS recurrence says that if the first symbols agree, an LCS exists using that common first symbol; remove it from both strings and iterate.

For item 2, consider any nonempty common subsequence. Its first matched symbol is either `c` or `1-c`. If it is `c`, the subsequence in `y` must skip the complete first `(1-c)`-run, so its length is at most `LCS(x,y')`. If its first symbol is `1-c`, the subsequence in `x` must skip the complete first `c`-run, so its length is at most `LCS(x',y)`. The empty subsequence is covered by either branch. Conversely each branch is a legal common subsequence of the original pair. Therefore (6.1) is exact. QED.

This proves that **no third primitive crossing action is needed** for exact binary LCS. Greedily match a common active run portion; at a phase mismatch, delete one whole current run or the other. The difficulty is future information and state compression, not the primitive action alphabet.

## 7. Finite-lookahead completeness theorem

The withdrawn P05-R5.2 claim tried to embed one particular Bellman potential pointwise when increasing lookahead. That proof was invalid because the extra retained coordinate is conditioned rather than automatically averaged. The following statement is different and valid: it concerns the **optimal policy classes themselves**, which are genuinely nested.

For `K>=1`, let `Gamma_K` be the supremum asymptotic common-subsequence rate among legal run policies that may inspect at most `K` complete future runs of each source, may retain a finite internal state/counter, and use only the exact run-normal-form actions of Lemma P05-R10.3.

### Theorem P05-R10.4 — finite lookahead is asymptotically complete

\[
\boxed{
\Gamma_K\le\Gamma_{K+1}\le\gamma_2,
\qquad
\lim_{K\to\infty}\Gamma_K=\gamma_2.
}
\tag{7.1}
\]

#### Proof

The policy classes are nested, so `Gamma_K<=Gamma_{K+1}`. Every legal policy outputs an actual common subsequence of the two source strings, so `Gamma_K<=gamma_2`.

For even `K`, consider the block policy that partitions both run sequences into consecutive `K`-run blocks and, on each paired block, uses Lemma P05-R10.3 to compute the **exact** finite-block LCS. It needs no more than `K`-run lookahead and a finite block counter. Concatenating the blockwise LCSs is a legal common subsequence. Its expected renewal rate is exactly the phase-randomized quantity `bar rho_K` from P05-R9. Therefore

\[
\Gamma_K\ge\bar\rho_K.
\]

P05-R9 proved

\[
\bar\rho_{2m}\to\gamma_2.
\]

Hence

\[
\liminf_{K\to\infty}\Gamma_K\ge\gamma_2.
\]

Combined with `Gamma_K<=gamma_2`, this proves (7.1). QED.

This theorem changes the interpretation of the current `0.779108...` certificate. Its gap is **not** evidence that the renewal/run-action framework misses the true optimum. The exact action architecture is complete, and finite-lookahead policy classes converge to `gamma_2`; the remaining bottleneck is how to compress enough future information into a certifiable finite state.

## 9. What failed / what this redirects

A tempting next move from P05-R7 was to enlarge the primitive action alphabet with two-crossing macro-actions. Lemma P05-R10.3 shows that such macros are **not required for exactness**: every exact LCS can already be represented by the two whole-run deletion actions plus forced same-symbol matching. Macros may still be useful computationally because they package future information, but they should not be treated as mathematically new actions.

Likewise, simply increasing the geometric threshold `M` is now clearly secondary. The uncapped-tail work already showed truncation is not the main loss, and Theorem P05-R10.4 shows finite lookahead is the actual approximation axis.
