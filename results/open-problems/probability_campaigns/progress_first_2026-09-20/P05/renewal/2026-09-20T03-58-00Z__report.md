## 3. Exact finite closure of uncapped geometric tails

Original binary run lengths have
\[
\Pr(G=k)=2^{-k},\qquad k=1,2,\ldots .
\]
Fix an integer threshold `M>=2`. A fresh run is represented by one of `M` categories:

- exact category `j`, `1<=j<M`, when `G=j`;
- tail category `M`, when `G>=M`.

Conditional on the tail category,
\[
G=M+E,
\qquad
\Pr(E=e)=2^{-(e+1)},\quad e=0,1,2,\ldots .
\tag{3.1}
\]
Thus `E` is a zero-based geometric variable.

After matching the common part of two active same-symbol runs, represent the residual by the finite crossing alphabet
\[
\mathcal C_M=
\{E(d):-(M-1)\le d\le M-1\}
\cup
\{T^+(r),T^-(r):1\le r\le M\}.
\tag{3.2}
\]
Here `E(d)` is an exact signed residual `d`; `T^+(r)` means a positive residual `r+E`; and `T^-(r)` is its source-exchange image. Hence there are only
\[
(2M-1)+2M=4M-1
\]
crossing types despite the original unbounded run lengths.

As in the preceding four-quota policy, retain three future run categories per source. A complete quotient state is therefore
\[
(c;a_1,a_2,a_3;b_1,b_2,b_3),
\quad c\in\mathcal C_M,
\tag{3.3}
\]
with `(4M-1)M^6` states.

### Lemma P05-R6.1 — geometric difference closes the tail exactly

Let `E,F` be iid with (3.1). Then
\[
\Pr(E-F=0)=\frac13,
\qquad
\Pr(E-F=k)=\Pr(E-F=-k)=\frac{2^{-k}}3\quad(k\ge1).
\tag{3.4}
\]

**Proof.** For `k>=0`,
\[
\Pr(E-F=k)
=\sum_{f\ge0}2^{-(f+k+1)}2^{-(f+1)}
=2^{-k-2}\sum_{f\ge0}4^{-f}
=\frac{2^{-k}}3.
\]
For `k>0`, exchangeability gives the negative side. QED.

This identity is the exact closure mechanism: differences of two tail runs either tie, enter a finite exact residual, or return to another tail residual of the same geometric form.

### Tail versus exact run

Suppose the positive active residual is `r+E` and the newly exposed same-symbol run has exact length `b<M`.

If `r>b`, the new residual is `T^+(r-b)` and the immediate match is `b`.

If `r=b`, the immediate match is `b`, and the continuation is `E(0)` with probability `1/2` and `T^+(1)` with probability `1/2`.

If `r<b`, put `q=b-r`. Then for `e<q` one obtains the exact negative residual `-(q-e)`; at `e=q` one ties; and on `e>q` memorylessness gives `T^+(1)`. The exact expected immediate reward is
\[
r+\mathbf E\min(E,q)=r+1-2^{-q}.
\tag{3.5}
\]

### Tail versus tail run

Now compare `r+E` against `M+F` and put `q=M-r`. By (3.4), the continuation distribution is finite:

- `T^+(1)` with probability `2^{-q}/3`;
- `E(0)` with probability `2^{-q}/3`;
- finitely many exact negative residuals corresponding to `E-F=0,1,...,q-1`;
- `T^-(q+1)` with probability `1/3`.

The exact expected immediate reward is
\[
\mathbf E\min(r+E,M+F)
=r+1-\frac{2^{1-q}}3.
\tag{3.6}
\]
Indeed
\[
\mathbf E\min(E,q+F)
=\sum_{k=1}^{q}2^{-k}
 +\sum_{k=q+1}^{\infty}2^{-k}2^{-(k-q)}
=1-\frac{2^{1-q}}3.
\]
For `q=0`, (3.6) is `M+1/3`, and the continuation is exactly the equiprobable mixture of `E(0),T^+(1),T^-(1)`.

Thus no truncation error remains: all overflow probabilities and rewards are summed exactly inside the finite state space (3.3).

## 4. Legal Bellman operator and arbitrary-length bridge

At every crossing there are the same two source-valid actions as in the preceding report:

1. **L:** delete the active residual, then align the first retained future run of A against the first retained future run of B;
2. **R:** delete the shorter source's intervening opposite-symbol run, then align the active residual against B's second retained run.

The action may inspect one fresh run category `Q` which appears in **both** candidate next states. Branch-unique fresh categories are averaged before the `max`. Consequently the Bellman policy never reveals a branch-specific random variable and then forgets it after using it to choose the branch.

Let `F_M` be the resulting finite Bellman operator on potentials `phi` over (3.3), with the uncapped reward/transition formulas of Section 3. If
\[
(F_M\phi)(s)-\phi(s)\ge g
\qquad\text{for every }s,
\tag{4.1}
\]
then the maximizing stationary policy produces at least `g` matched symbols per alignment epoch in long-run average.

The only remaining issue is converting epochs to original source symbols.

### Lemma P05-R6.2 — the uncapped policy still costs exactly two original runs per epoch

Every epoch completes exactly two original runs total, regardless of whether an active residual is exact or tail-valued.

**Proof.** Matching the common same-symbol prefix completes at least the shorter active run. On a tie, both active runs complete. On a mismatch, exactly one active run completes; action L deletes the remaining active residual and therefore completes the other active run, whereas action R deletes exactly the intervening opposite-symbol run exposed by the shorter source. Either way the epoch total is exactly two completed original runs. QED.

### Lemma P05-R6.3 — one run per source per epoch asymptotically

Choose source-exchange-symmetric tie breaking. The finite controlled chain on (3.3) has a unique recurrent class, and its stationary law is invariant under exchange of the two sources. Hence each source completes asymptotically one original run per epoch.

**Proof.** The transition kernel and maximizing potential are source-exchange symmetric. It remains to exclude two disjoint asymmetric recurrent classes.

Give every finitely represented future run category the value `1`, an event of positive probability. From any exact residual `E(d)`, whichever action the stationary policy chooses, repeated such fresh categories either reset by L or reduce the residual under R until the exact zero-residual state is reached. From any tail residual `T^\pm(r)`, the same argument reduces the finite base `r` under repeated R choices, while the hidden geometric excess has probability `1/2` to be zero whenever the base reaches the boundary needed for a tie; an L choice resets immediately. Continuing to draw category `1` flushes the retained future window to all ones. Therefore every state has a positive-probability path to one canonical exact-zero/all-one state. Any closed recurrent class must contain that canonical state, so the finite chain has a unique recurrent class.

Uniqueness plus source-exchange symmetry forces the stationary law to be exchange invariant. Let `K_A(t),K_B(t)` be original runs completed by the first `t` epochs. Lemma P05-R6.2 gives pathwise
\[
K_A(t)+K_B(t)=2t.
\]
The stationary mean increments are equal by exchange invariance, hence each is one. The finite-chain ergodic theorem gives
\[
K_A(t)/t\to1,
\qquad K_B(t)/t\to1.
\tag{4.2}
\]
QED.

Original binary run lengths are iid `Geom(1/2)` with mean two. Combining (4.2) with the ordinary SLLN along the random completed-run subsequences shows that each source consumes asymptotically two original symbols per epoch. Therefore (4.1) implies
\[
\boxed{\gamma_2\ge g/2}.
\tag{4.3}
\]
This is an arbitrary-length theorem for the original uncapped iid binary strings; the finite state space is only the proof certificate.
