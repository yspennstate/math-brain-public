## 2. New idea: linearize every LCS max by a fair branch plus a pivotal bonus

For deterministic finite strings `x,y`, let

\[
V(i,j)=LCS(x_i x_{i+1}\cdots,\;y_j y_{j+1}\cdots)
\]

with zero boundary values when either suffix is empty.

At a mismatch `x_i != y_j`, put

\[
A=V(i+1,j),\qquad B=V(i,j+1),\qquad
\Delta(i,j)=|A-B|.
\]

The standard LCS recursion says

\[
V(i,j)=\max\{A,B\}.
\]

The key observation is that `Delta` is always binary.

### Lemma P05-R11.1 — mismatch children differ by at most one

At every mismatch,

\[
\boxed{\Delta(i,j)\in\{0,1\}.}
\tag{2.1}
\]

#### Proof

Let `C=V(i+1,j+1)`. Appending one symbol to either argument can increase an LCS by at most one, hence

\[
C\le A\le C+1,\qquad C\le B\le C+1.
\]

Since `A,B` are integers, `|A-B|` is either zero or one. QED.

Therefore

\[
\boxed{
\max\{A,B\}=\frac{A+B}{2}+\frac{\Delta(i,j)}2.
}
\tag{2.2}
\]

This suggests a randomized exact evaluator whose trajectory does **not** use `Delta` to choose a branch.

## 3. Exact randomized evaluator for every deterministic pair

Start at `(0,0)` and stop when either string is exhausted.

- If `x_i=y_j`, collect reward `1` and move diagonally to `(i+1,j+1)`.
- If `x_i!=y_j`, collect reward `Delta(i,j)/2`, toss an independent fair coin, and move to `(i+1,j)` or `(i,j+1)` with probability `1/2` each.

The pivotal bonus can be evaluated offline from the DP table; critically, it does not affect the branch coin.

### Theorem P05-R11.2 — exact evaluator identity

For every deterministic finite pair `x,y`, the evaluator's expected total reward, where expectation is only over its fair mismatch coins, is exactly `LCS(x,y)`.

#### Proof

Let `R(i,j)` be the evaluator's expected future reward from suffix state `(i,j)`. The boundary values of `R` and `V` are both zero. Work backwards.

If `x_i=y_j`, then by induction

\[
R(i,j)=1+R(i+1,j+1)=1+V(i+1,j+1)=V(i,j).
\]

If `x_i!=y_j`, then by induction and (2.2),

\[
\begin{aligned}
R(i,j)
&=\frac{\Delta(i,j)}2
 +\frac{R(i+1,j)+R(i,j+1)}2\\
&=\frac{|A-B|}{2}+\frac{A+B}{2}\\
&=\max\{A,B\}=V(i,j).
\end{aligned}
\]

Thus `R(0,0)=V(0,0)=LCS(x,y)`. QED.

This is an exact representation, not a Monte Carlo approximation.

## 4. Source-averaged path law

The deterministic theorem becomes useful because the evaluator's **trajectory** is source-blind beyond the equality test. The pivotal field influences reward but not motion.

For iid uniform strings over an alphabet of size `k>=2`, run the evaluator on two length-`n` strings. Let

- `T_n` be the number of evaluator steps before the first boundary is hit;
- `M_n` be the number of match/diagonal steps;
- `Q_n` be the number of mismatch/single-coordinate steps;
- `P_n` be the number of pivotal mismatch visits, i.e. the sum of `Delta(i,j)` over mismatch states visited;
- `H_n` be the terminal coordinate deficit, so if the evaluator stops at consumed coordinates `(I,J)`, then `H_n=|I-J|`.

Take the filtration generated by the path's revealed source symbols/equality tests and independent fair branch coins, but not by unused pivotal bonuses. At every interior step, conditional on this filtration, the current symbols match with probability exactly `1/k`. If one symbol is carried over from the preceding mismatch, the other is a fresh independent uniform symbol; if both coordinates advanced, both are fresh. Hence

\[
\mathbf E M_n=\frac1k\mathbf E T_n,
\qquad
\mathbf E Q_n=\frac{k-1}{k}\mathbf E T_n.
\tag{4.1}
\]

Pathwise total symbol consumption is

\[
2M_n+Q_n=2n-H_n.
\tag{4.2}
\]

Combining (4.1) and (4.2) gives, with `m_{k,n}:=E M_n`,

\[
\boxed{
m_{k,n}=\frac{2n-\mathbf E H_n}{k+1},
\qquad
\mathbf E Q_n=(k-1)m_{k,n}.
}
\tag{4.3}
\]

Theorem P05-R11.2, averaged over sources and coins, gives the exact finite-`n` relation

\[
\boxed{
a_{k,n}:=\mathbf E LCS(X_1^n,Y_1^n)
=m_{k,n}+\frac12\mathbf E P_n.
}
\tag{4.4}
\]

Define the occupation-weighted pivotal density among mismatch visits by

\[
p_{k,n}:=\frac{\mathbf E P_n}{\mathbf E Q_n}.
\tag{4.5}
\]

Then (4.3)--(4.4) yield the exact identity

\[
\boxed{
a_{k,n}
=m_{k,n}\left(1+\frac{k-1}{2}p_{k,n}\right).
}
\tag{4.6}
\]

## 5. The boundary deficit is only order square-root n

Let `S_t` be the difference between the numbers of source coordinates consumed from the two strings after `t` evaluator steps. A match changes `S` by zero. At a mismatch, the fair branch coin changes `S` by `+1` or `-1` with equal conditional probabilities. Therefore

\[
S_t^2-\frac{k-1}{k}t
\]

is a martingale up to the bounded stopping time `T_n`. At termination `|S_{T_n}|=H_n`, so optional stopping gives

\[
\boxed{
\mathbf E H_n^2=\frac{k-1}{k}\mathbf E T_n.
}
\tag{5.1}
\]

Since (4.2)--(4.3) imply

\[
\mathbf E T_n\le \frac{2kn}{k+1},
\]

we obtain

\[
\boxed{
\mathbf E H_n
\le
\sqrt{\frac{2(k-1)}{k+1}n}
=o(n).
}
\tag{5.2}
\]

Consequently

\[
\boxed{
\frac{m_{k,n}}n\longrightarrow \frac{2}{k+1}.
}
\tag{5.3}
\]

## 6. Main structural theorem: gamma is exactly a pivotal density

The Chvatal--Sankoff limit `gamma_k=lim a_{k,n}/n` exists. Combining that limit with (4.6) and (5.3) proves that `p_{k,n}` itself has a limit.

### Theorem P05-R11.3 — pivotal occupation formula

Let

\[
p_k^*:=\lim_{n\to\infty}p_{k,n}.
\]

Then the limit exists and

\[
\boxed{
\gamma_k=\frac{2+(k-1)p_k^*}{k+1},
\qquad
p_k^*=\frac{(k+1)\gamma_k-2}{k-1}.
}
\tag{6.1}
\]

In particular for the assigned binary problem,

\[
\boxed{
\gamma_2=\frac23+\frac13p_* ,

p_*:=\lim_{n\to\infty}p_{2,n}=3\gamma_2-2.

\tag{6.2}
\]

Thus exact determination of the binary Chvatal--Sankoff constant is equivalent to determining one occupation-weighted probability: along the simple source-blind randomized deletion trajectory, what asymptotic fraction of visited **mismatches** are pivotal, meaning the two deletion continuations have LCS values differing by one?

## 7. Why this is not already a purely local finite-state statistic

The pivotal indicator is binary, but it is not determined by a bounded immediate neighborhood without additional state. For example, at the initial mismatch the pairs

- `x=000`, `y=100` have deletion-child values `(2,2)` and hence `Delta=0`;
- `x=001`, `y=100` have deletion-child values `(1,2)` and hence `Delta=1`.

The first two symbols of each source are identical between the two examples (`x` begins `00`, `y` begins `10`), yet deeper suffix information changes pivotality. Therefore a successful finite-state certificate needs a controlled boundary/residual profile, not only current run lengths or a one-step equality pattern.

This is exactly where the complementary R17 reward-flux theorem may become useful: R17 now proves pathwise that one gradient defect changes cumulative strip reward by at most one, independently of its lifetime. P05's new target is to turn such finite-strip discrepancy control into an upper/lower envelope for the occupation frequency of `Delta=1`, without taking over R17's strip claim.
