### 1.1 Resolution of the Lember--Sova source-reconciliation gap

The preceding report opened a `SOURCE_RECONCILIATION_GAP` because Jüri Lember and
Joonas Sova, *Extremal Alignments in LCS-Inference*, Scandinavian Journal of
Statistics 53(3) (2026), 1327--1342, first published 18 July 2026,
DOI `10.1111/sjos.70086`, states in its abstract that it derives a bound on the
unknown Chvatal--Sankoff constant, while the publisher view did not expose the
formula.

A 2026 University of Tartu thesis now resolves the relevant binary theorem. William
Undrits, *Bounds for the Chvatal-Sankoff Constant of Pairwise Markov Models*
(Tartu, 2026; supervisor Joonas Sova; handle `10062/122453`) states explicitly on
printed p.4 that its Theorem 2 generalizes `[10, Theorem 2]`, where `[10]` is the
Lember--Sova paper. Its Theorem 2 (printed p.14) is

\[
H\le
2h(\gamma)+\gamma h(\alpha^*)
+\bigl(2-\gamma-((\alpha\gamma)\vee0)\bigr)\log_2(K-1).
\tag{1.1}
\]

For independent fair binary strings, \(K=2\), \(q_x=q_y=1/2\), the pair process
has entropy rate \(H=2\), the two admissible alpha endpoints straddle \(1/2\), so
\(\alpha^*=1/2\), and \(\log_2(K-1)=0\). Therefore the Lember--Sova entropy bound
specializes exactly to

\[
\boxed{2\le 2h(\gamma_2)+\gamma_2.}
\tag{1.2}
\]

The upper root is

\[
\gamma_2\le 0.866595230051538\ldots ,
\]

which is much weaker than Lueker's \(0.826280\). Thus the particular 2026 bound
advertised through Lember--Sova Theorem 2 does **not** improve the best recovered
iid fair-binary endpoint. This closes the prior reconciliation gap for that theorem.
It is not a claim that no other theorem anywhere in the paper has consequences
outside this specialization.

## 2. New route: randomize the initial run phase

The first renewal report fixed both run blocks to start with symbol \(0\). That was
convenient for exact even-run concatenation, but comparison with ordinary iid
length-\(2r\) strings then paid an unnecessary \(1/r\) term for forcing the first
bits.

Instead let \(Z_X,Z_Y\) be independent fair bits and let

\[
G_1,G_2,\ldots,\qquad H_1,H_2,\ldots
\]

be independent iid geometric run lengths with

\[
\Pr(G_i=k)=\Pr(H_i=k)=2^{-k},\qquad k\ge1.
\]

For even \(r\), form \(A_r^*\) from \(r\) alternating runs of lengths
\(G_1,\ldots,G_r\) starting in phase \(Z_X\), and form \(B_r^*\) analogously from
\(H_1,\ldots,H_r\) and \(Z_Y\). Define

\[
\bar b_r:=\mathbf E\,LCS(A_r^*,B_r^*),
\qquad
\bar\rho_r:=\frac{\bar b_r}{2r}.
\]

### Theorem P05-R9.1 — phase-randomized renewal variational identity

For even \(r,s\),

\[
\bar b_{r+s}\ge \bar b_r+\bar b_s,
\]

and

\[
\boxed{
\gamma_2
=\lim_{m\to\infty}\bar\rho_{2m}
=\sup_{m\ge1}\bar\rho_{2m}.
}
\tag{2.1}
\]

#### Proof

Condition on the two phases \(Z_X,Z_Y\). Since \(r\) is even, after the first
\(r\) alternating runs the next run begins again in the original phase. The next
\(s\) run lengths are independent of the first \(r\) run lengths. For deterministic
strings,

\[
LCS(UU',VV')\ge LCS(U,V)+LCS(U',V').
\]

Apply this conditional on the phases and average. Independence of the two *blocks'
phases* is not required; only the fresh run lengths are required. This gives
superadditivity on even run counts, hence Fekete's lemma gives the existence of the
even-run supremum.

Now define

\[
T_r=\sum_{i=1}^rG_i,\qquad S_r=\sum_{i=1}^rH_i.
\]

Because the initial phases are fair, \(A_r^*\) is exactly the prefix
\(X_1^{T_r}\) of an ordinary unconditioned infinite fair iid binary string stopped
at the end of its \(r\)-th run. Likewise \(B_r^*=Y_1^{S_r}\), independently.
Changing one prefix length by one changes LCS by at most one, so

\[
\left|
LCS(X_1^{T_r},Y_1^{S_r})
-
LCS(X_1^{2r},Y_1^{2r})
\right|
\le |T_r-2r|+|S_r-2r|.
\tag{2.2}
\]

Section 3 computes the expectation on the right exactly and shows it is
\(o(r)\). Hence \(\bar\rho_r-a_{2r}/(2r)\to0\), while
\(a_{2r}/(2r)\to\gamma_2\). Combining this limit with superadditivity gives
(2.1). QED.

## 3. Exact negative-binomial boundary identity

The random endpoint \(T_r\) has law

\[
\Pr(T_r=t)=\binom{t-1}{r-1}2^{-t},\qquad t\ge r,
\qquad
\mathbf ET_r=2r.
\]

The earlier report bounded \(\mathbf E|T_r-2r|\) by standard deviation. Here the
quantity can be evaluated exactly.

### Lemma P05-R9.2 — exact run-endpoint mean absolute deviation

For every \(r\ge1\),

\[
\boxed{
\mathbf E|T_r-2r|
=
\frac{r\binom{2r}{r}}{2^{\,2r-1}}.
}
\tag{3.1}
\]

#### Proof

Since \(T_r\) has mean \(2r\),

\[
\mathbf E|T_r-2r|
=
2\sum_{t=r}^{2r-1}(2r-t)
\binom{t-1}{r-1}2^{-t}.
\tag{3.2}
\]

Set

\[
A_t:=r\binom tr2^{-t}.
\]

Using
\(\binom tr=(t/r)\binom{t-1}{r-1}\) and
\(\binom{t-1}r=((t-r)/r)\binom{t-1}{r-1}\),

\[
A_t-A_{t-1}
=
(2r-t)\binom{t-1}{r-1}2^{-t}.
\tag{3.3}
\]

The sum in (3.2) therefore telescopes to \(A_{2r-1}\). Since

\[
\binom{2r-1}{r}=\frac12\binom{2r}{r},
\]

multiplication by the leading factor \(2\) gives (3.1). QED.

Combining (2.2) and (3.1) gives the **exact** phase-randomized renewal comparison

\[
\boxed{
\left|
\bar\rho_r-\frac{a_{2r}}{2r}
\right|
\le
\frac{\binom{2r}{r}}{2^{\,2r-1}}.
}
\tag{3.4}
\]

By the central-binomial asymptotic, the right side is

\[
\frac{2}{\sqrt{\pi r}}\,(1+o(1)),
\]

versus the preceding fixed-phase comparison
\(\sqrt{2/r}+1/r\). The start-conditioning term disappears entirely.

## 4. Capped phase-randomized finite certificate

Let \(G_i^{(M)}=\min(G_i,M)\) and similarly for \(H_i\), keeping the fair random
initial phases. Let \(\bar\rho_{r,M}\) be the expected LCS divided by \(2r\) for
the resulting two finite capped \(r\)-run blocks.

Exactly as in the first renewal report, capping only deletes symbols and

\[
\mathbf E(G-M)_+=2^{-(M-1)}.
\]

Therefore

\[
\boxed{
\bar\rho_{r,M}
\le \bar\rho_r
\le \bar\rho_{r,M}+2^{-(M-1)}.
}
\tag{4.1}
\]

The phase average adds only a denominator \(4\), so \(\bar\rho_{r,M}\) remains an
exact rational finite computation. From Theorem P05-R9.1,

\[
\boxed{\gamma_2\ge\bar\rho_{r,M}.}
\tag{4.2}
\]

## 5. Sharpen Alexander's finite-size parameters

The preceding report used the convenient uniform choice
\(\lambda=\theta=8/5\) in Alexander's Proposition 2.4. That made the bridge easy
to state but left a large avoidable constant.

Write

\[
L=\log(2r),
\]

and, for \(r\ge8\), define

\[
q_r:=\frac{2}{\sqrt{2rL}}+\frac1L,
\]

\[
p_r:=
1+\frac{1}{2rL}
+\frac{\log 5.1-1}{L}
+\frac{\log L}{2L},
\]

\[
\boxed{
\Lambda_r:=
\frac{q_r+\sqrt{q_r^2+4p_r}}2,
\qquad
\Theta_r:=
\sqrt{2+\frac{\log4}{L}}.
}
\tag{5.1}
\]

### Lemma P05-R9.3 — explicit admissible Alexander parameters

For every \(r\ge8\), \(\lambda=\Lambda_r\) and \(\theta=\Theta_r\) satisfy
Alexander Proposition 2.4.

#### Proof

The first Alexander condition is

\[
\lambda^2>
1+\frac1{2rL}
+\frac{2\lambda}{\sqrt{2rL}}
+\frac{\log(5.1\lambda)}{L}
+\frac{\log L}{2L}.
\tag{5.2}
\]

For \(r\ge8\), \(p_r>1\), so \(\Lambda_r>1\). Hence

\[
\log\Lambda_r<\Lambda_r-1.
\]

Substituting this strict upper bound for \(\log\lambda\) into the right side of
(5.2) yields exactly

\[
p_r+q_r\Lambda_r.
\]

By the quadratic definition (5.1),

\[
\Lambda_r^2=p_r+q_r\Lambda_r,
\]

so the actual right side of (5.2) is strictly smaller than
\(\Lambda_r^2\). The second Alexander condition is

\[
\theta^2\ge 2+\frac{\log4}{L},
\]

which holds with equality for \(\Theta_r\). QED.

Alexander therefore gives

\[
\boxed{
\gamma_2
\le
\frac{a_{2r}}{2r}
+
(2\Lambda_r+\Theta_r)
\sqrt{\frac{\log(2r)}{2r}}
+
\sqrt{\frac{2\log2}{r}}.
}
\tag{5.3}
\]

As \(r\to\infty\),

\[
\Lambda_r\to1,\qquad \Theta_r\to\sqrt2,
\]

so the leading Alexander coefficient tends to \(2+\sqrt2\), rather than the
previous fixed coefficient \(24/5=4.8\).

## 6. Main new theorem: sharpened exact two-sided finite certificate

### Theorem P05-R9.4 — phase-randomized renewal/Alexander sandwich

For every even \(r\ge8\) and integer \(M\ge1\),

\[
\boxed{
\bar\rho_{r,M}
\le \gamma_2
\le \bar\rho_{r,M}+\Delta_{r,M},
}
\tag{6.1}
\]

where

\[
\boxed{
\Delta_{r,M}
=
(2\Lambda_r+\Theta_r)
\sqrt{\frac{\log(2r)}{2r}}
+
\sqrt{\frac{2\log2}{r}}
+
\frac{\binom{2r}{r}}{2^{\,2r-1}}
+
2^{-(M-1)}.
}
\tag{6.2}
\]

#### Proof

The lower inequality is (4.2). For the upper inequality, apply (5.3), then use
(3.4) in the upper direction,

\[
\frac{a_{2r}}{2r}
\le
\bar\rho_r+
\frac{\binom{2r}{r}}{2^{2r-1}},
\]

and finally apply (4.1),

\[
\bar\rho_r\le\bar\rho_{r,M}+2^{-(M-1)}.
\]

Substitution gives (6.1)--(6.2). QED.

### Corollary P05-R9.5 — exact finite primal/dual control

If an exact finite primal certificate proves

\[
L_{r,M}\le\bar\rho_{r,M},
\]

then

\[
\gamma_2\ge L_{r,M}.
\]

If an exact finite DP/transfer/Bellman dual proves

\[
\bar\rho_{r,M}\le U_{r,M},
\]

then

\[
\boxed{\gamma_2\le U_{r,M}+\Delta_{r,M}.}
\tag{6.3}

Thus the finite-state target is now cleaner than in the previous report: the
