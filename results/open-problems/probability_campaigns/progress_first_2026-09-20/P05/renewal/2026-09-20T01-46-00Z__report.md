## 2. What failed in the previous state and the new idea

The previous run reduced the iid binary problem to capped geometric-run regeneration and proved an exact `M`-state one-residual policy. At `M=32` it certified

## 3. Capped run process

After discarding at most one initial run to synchronize the starting symbol (an `O(1)` loss), the two binary strings have independent alternating run lengths
\[
G_1,G_2,\ldots,\qquad H_1,H_2,\ldots
\]
with
\[
\Pr(G_i=k)=\Pr(H_i=k)=2^{-k},\qquad k\ge1.
\]

Fix a cap `M>=2` and define the usable quota
\[
Q_M(g)=\min(g,M).
\]
Its exact law on `{1,\ldots,M}` is
\[
p_M(k)=
\begin{cases}
2^{-k},&k<M,\\
2^{-(M-1)},&k=M.
\end{cases}
\]

When the policy leaves a run whose original length exceeds `M`, all overflow is simply consumed/deleted unmatched. Hence every produced match is a genuine common-subsequence match in the original uncapped strings, and run-completion accounting always refers to the original runs, not merely their capped quotas.

A state is
\[
s=(a_0,a_1,a_2\,;\,b_0,b_1,b_2)\in\{1,\ldots,M\}^6,
\]
where `a_0,b_0` are the active same-symbol usable quotas and `a_1,a_2` (respectively `b_1,b_2`) are the next two alternating capped run quotas already visible in that source.

The immediate reward is
\[
r(s)=\min(a_0,b_0).
\]

## 4. Exact crossing actions

### Tie

If `a_0=b_0`, both active runs finish. With fresh independent quotas `A_3,B_3~p_M`,
\[
(a_0,a_1,a_2\,;\,b_0,b_1,b_2)
\longmapsto
(a_1,a_2,A_3\,;\,b_1,b_2,B_3).
\]
Exactly one original run from each source is completed.

### Mismatch `a_0>b_0`

Let
\[
d=a_0-b_0\ge1.
\]
After matching `b_0` symbols, source `B` has completed its active run while source `A` retains usable residual `d`. Source `B` is now in its opposite-symbol run of quota `b_1`.

There are two valid ways to restore same phase.

**L: delete the longer active residual.** Consume/delete all of residual `d` in `A`. Then the next active runs are `a_1,b_1`, and with a fresh `A_3`,
\[
s_L=(a_1,a_2,A_3\,;\,b_1,b_2,Q).
\]

**R: delete the intervening opposite run.** Consume/delete all of `B`'s run `b_1`. Then `B` enters `b_2`, which has the same symbol as residual `d`, and with a fresh `B_4`,
\[
s_R=(d,a_1,a_2\,;\,b_2,Q,B_4).
\]

Here
\[
Q\sim p_M
\]
is source `B`'s next fresh quota after `b_2`. Crucially, `Q` appears in **both** candidate next states. The policy may therefore reveal `Q` before deciding between L and R without conditioning on any future quantity that later disappears from its state. The branch-unique variables `A_3` and `B_4` are averaged only after the choice.

The case `a_0<b_0` is the exact source-exchange image.

Pathwise, every epoch completes exactly two original runs total:
- tie or L completes one run from each source;
- R completes two runs from the shorter source and zero from the longer source in that epoch.

## 5. Bellman operator and exact finite certificate

For any bounded potential
\[
h:\{1,\ldots,M\}^6\to\mathbb R,
\]
define `T h` as follows.

On a tie,
\[
(Th)(s)
=r(s)+
\mathbf E_{A_3,B_3}
h(a_1,a_2,A_3\,;\,b_1,b_2,B_3).
\tag{5.1}
\]

If `a_0>b_0`, with `d=a_0-b_0`,
\[
\begin{aligned}
(Th)(s)
=r(s)+\mathbf E_Q\max\Big\{&
\mathbf E_{A_3}h(a_1,a_2,A_3\,;\,b_1,b_2,Q),\\
&
\mathbf E_{B_4}h(d,a_1,a_2\,;\,b_2,Q,B_4)
\Big\}.
\end{aligned}
\tag{5.2}
\]
The other orientation is obtained by exchanging the sources.

The maximizer in (5.2) is a legitimate finite-lookahead alignment policy because its only pre-decision new information is `Q`, which belongs to both possible next states.

### Lemma P05-R4.1 — Bellman subsolution certificate

If a bounded `h` and a real number `g` satisfy
\[
(Th)(s)-h(s)\ge g
\qquad\text{for every state }s,
\tag{5.3}
\]
then this finite policy produces at least `g` matched symbols per epoch asymptotically.

**Proof.**
At each mismatch choose an action attaining the maximum in (5.2), with a source-exchange-symmetric fair tie break if the two continuation values are equal. Conditional on the present state,
\[
\mathbf E\!\left[
R_{t+1}-R_t+h(S_{t+1})-h(S_t)\mid S_t
\right]\ge g.
\]
Summing for `t=0,\ldots,T-1`,
\[
\mathbf E R_T
\ge Tg+h(S_0)-\mathbf E h(S_T).
\]
Because the state space is finite, `h` is bounded, so the last two terms are `O(1)`. Dividing by `T` gives the asserted long-run expected reward lower bound. The same finite-state additive-functional argument gives the almost-sure rate on recurrent classes. QED.

### Lemma P05-R4.2 — conversion from epochs to original symbols

For the source-exchange-symmetric maximizing policy,
\[
\gamma_2\ge \frac g2.
\tag{5.4}
\]

**Proof.**
Let `K_A(T),K_B(T)` be completed original run counts after `T` epochs. Pathwise,
\[
K_A(T)+K_B(T)=2T.
\]
The controlled finite-state kernel is source-exchange symmetric. Moreover, because all capped quotas are at most `M`, a sufficiently long finite block of newly exposed quota-1 runs forces any residual down to a tie and flushes the finite lookahead window. This event has a state-uniform positive probability. Hence the finite controlled chain has one recurrent communicating class reached from every state; its stationary law is unique. Source exchange leaves that law invariant, so the stationary mean run-completion increments from the two sources are equal. Their sum is two, hence each equals one. By the finite-state ergodic theorem,
\[
\frac{K_A(T)}T\to1,\qquad
\frac{K_B(T)}T\to1
\quad\text{a.s.}
\]

The **original uncapped** run lengths have mean two. Therefore, by the iid strong law along the random run-count subsequences,
\[
\frac{\text{original symbols consumed from A by epoch }T}{T}\to2,
\qquad
\frac{\text{original symbols consumed from B by epoch }T}{T}\to2.
\]
If `N_T` is the larger consumed prefix length, then `N_T/T->2`. Every reward match is a valid common subsequence of the two prefixes padded to length `N_T`, so
\[
L(X_1^{N_T},Y_1^{N_T})\ge R_T.
\]
Using the Chvátal--Sankoff limit along the subsequence `N_T`,
\[
\gamma_2
\ge \liminf_T\frac{R_T}{N_T}
\ge \frac g2.
\]
QED.

Thus a finite inequality (5.3) is a rigorous certificate for arbitrary string lengths.

## 7. A new quotient identity

The six-coordinate state space is still larger than necessary.

### Lemma P05-R4.3 — common-active-shift equivariance

Suppose `t>=0` and `a_0+t,b_0+t<=M`. Let
\[
C_t(a_0,a_1,a_2;b_0,b_1,b_2)
=(a_0+t,a_1,a_2;b_0+t,b_1,b_2).
\]
Then for **every** potential `h`,
\[
(Th)(C_t s)=t+(Th)(s).
\tag{7.1}
\]

**Proof.**
Adding the same `t` to both active quotas increases the immediate reward `min(a_0,b_0)` by exactly `t`. It does not change whether the active quotas tie, their oriented difference when they do not tie, any suffix quota, or either candidate next-state law. Hence the continuation term is identical and (7.1) follows. QED.

Consequently a Bellman bias may be normalized to satisfy
\[
h(C_t s)=h(s)+t.
\tag{7.2}
\]
The exact `M=10` integer potential generated here satisfies the scaled version of (7.2) identically.

This quotient removes the absolute common active level. Instead of `M^2` active pairs, only the tie state plus the two oriented nonzero differences matter:
\[
1+2(M-1)=2M-1.
\]
For the present three-quota window this reduces the natural state count from
\[
M^6
\quad\text{to}\quad
(2M-1)M^4,
\]
before also quotienting source exchange. At `M=10`, that is `1,000,000 -> 190,000` pre-exchange states.

This is the most useful structural result of the run for the next attack: it gives an exact dimension reduction for richer lookahead certificates.
