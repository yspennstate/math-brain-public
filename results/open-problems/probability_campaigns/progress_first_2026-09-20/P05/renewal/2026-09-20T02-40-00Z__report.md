## 2. New idea: quotient the common active run level

The previous run used three capped run quotas from each source and an exact Bellman subsolution on `M^6` states. It proved
\[
\gamma_2\ge0.770918990441703\ldots
\]
at `M=10`, and identified a common-active-shift equivariance.

This run turns that identity into an actual state-space reduction and spends the saved state budget on a fourth run quota of lookahead.

Write a four-quota state before matching as
\[
(a_0,a_1,a_2,a_3\,;\,b_0,b_1,b_2,b_3),
\]
with `a_0,b_0` same-symbol active quotas. Put
\[
m=\min(a_0,b_0),\qquad d=a_0-b_0.
\]
For a quotient potential `phi`, lift it to
\[
h(a_0,a_1,a_2,a_3;b_0,b_1,b_2,b_3)
=m+\phi(d;a_1,a_2,a_3;b_1,b_2,b_3).
\tag{2.1}
\]

### Lemma P05-R5.1 — exact quotient of the Bellman residual

For potentials of the form (2.1), the Bellman residual `Th-h` is independent of the common active level `m`. Therefore the complete subsolution check can be performed on
\[
(d;a_1,a_2,a_3;b_1,b_2,b_3),
\qquad d\in\{-(M-1),\ldots,M-1\},
\]
with only
\[
(2M-1)M^6
\]
states instead of `M^8` unquotiented four-quota states.

**Proof.** Every epoch first matches exactly `m` common active symbols. If `d=0`, both active runs finish; if `d>0`, source A retains residual `d`; if `d<0`, source B retains residual `-d`. All candidate next states depend on `d` and future quotas but not on `m`. In `Th-h`, the immediate reward `m` cancels the `m` term in (2.1), leaving a function only of the quotient coordinates. QED.

At `M=9`, this reduces
\[
9^8=43,046,721
\]
full states to
\[
17\cdot9^6=9,034,497
\]
quotient states, making a genuine extra lookahead run computationally accessible.

## 3. Legal four-quota lookahead operator

The capped quota law is
\[
p_M(k)=2^{-k}\ (1\le k<M),\qquad p_M(M)=2^{-(M-1)}.
\]
As before, overflow beyond the cap is deleted unmatched, so every produced match is a valid match in the original uncapped strings.

For `d=0`, both active runs finish and, with fresh `A_4,B_4`, the quotient state moves to
\[
(a_1-b_1\,;\,a_2,a_3,A_4\,;\,b_2,b_3,B_4).
\]
The future lifted potential contributes the new common active level `min(a_1,b_1)`.

For `d>0`, after the common active prefix has been matched, there are again two source-valid ways to restore equal symbol phase:

1. **L:** delete A's active residual `d`, then align `a_1` with `b_1`. With fresh `A_4` and common fresh quota `Q=B_4`, the next quotient state is
   \[
   (a_1-b_1\,;\,a_2,a_3,A_4\,;\,b_2,b_3,Q).
   \]
2. **R:** delete B's intervening opposite-symbol run `b_1`, then align residual `d` with `b_2`. With the same common fresh quota `Q=B_4` and branch-unique `B_5`, the next quotient state is
   \[
   (d-b_2\,;\,a_1,a_2,a_3\,;\,b_3,Q,B_5).
   \]

The decision may inspect `Q` because `Q` appears in both candidate next states. The branch-unique `A_4` or `B_5` is averaged only after the choice. Hence this is genuine legal finite lookahead; no branch-unique future is revealed and then forgotten.

The `d<0` case is the exact source-exchange image.

Define the quotient Bellman operator `F` by these transitions, including the next common active level in the continuation value. If a bounded quotient potential satisfies
\[
(F\phi)(s)-\phi(s)\ge g\qquad\text{for every quotient state }s,
\tag{3.1}
\]
then the lifted `h` satisfies the original run-level Bellman subsolution with the same `g`.

Exactly as in the previous report, each L/R/tie epoch completes exactly two original runs total. With source-exchange-symmetric tie breaking, the finite controlled chain is exchange symmetric, so the two sources each complete asymptotically one original run per epoch. Original binary run lengths are iid `Geom(1/2)` with mean two. Consequently a certificate (3.1) yields
\[
\boxed{\gamma_2\ge g/2}.
\tag{3.2}
\]
Thus the finite quotient certificate controls arbitrary original string lengths, not only a finite simulation horizon.

## 5. Structural hierarchy, not just one decimal

Let `beta_{M,L}` denote the best asymptotic lower rate attainable by this legal capped-run policy class with cap `M` and `L` retained run quotas per source, allowing any exact finite-state Bellman policy on the corresponding state.

For every `M,L>=2`,
\[
\beta_{M,L}\le\beta_{M,L+1}\le\gamma_2,
\tag{5.1}
\]
and
\[
\beta_{M,L}\le\beta_{M+1,L}\le\gamma_2.
\tag{5.2}
\]

**Proof.** The upper inequalities hold because each policy emits an actual common subsequence of the original strings. For (5.1), an `(L+1)`-quota policy can ignore the last retained quota and emulate any `L`-quota policy exactly. Taking suprema proves both monotonicities. QED.

## 6. Exact geometric residual identity for the next attack

The next useful compression should exploit the special memorylessness of binary run lengths rather than merely increase `M`.

### Lemma P05-R5.3 — fresh residual after two geometric runs disagree

Let `G,H` be independent `Geom(1/2)` variables on `{1,2,...}`, so `P(G=k)=2^{-k}`. Conditional on `G>H`, the residual
\[
D=G-H
\]
is again `Geom(1/2)` and is independent of `H`.

**Proof.** For `d,h>=1`,
\[
\Pr(D=d,H=h,G>H)=2^{-(h+d)}2^{-h}=2^{-d}4^{-h}.
\]
Also
\[
\Pr(G>H)=\sum_{d,h\ge1}2^{-d}4^{-h}=\frac13.
\]
Thus
\[
\Pr(D=d,H=h\mid G>H)=3\,2^{-d}4^{-h}
=\underbrace{2^{-d}}_{\Pr(D=d\mid G>H)}
\underbrace{3\,4^{-h}}_{\Pr(H=h\mid G>H)},
\]
which factors. QED.

The same statement holds with G and H exchanged. This is the structural opening for eliminating the artificial hard cap: beyond a finite threshold, geometric tails can potentially be represented by an affine or phase-type continuation rather than separate quota values.
