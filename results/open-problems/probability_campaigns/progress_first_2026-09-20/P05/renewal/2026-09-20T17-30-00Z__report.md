## 3. The capped left character source is finite-state Markov

After a character of the capped left source has been read, record its current run age

\[
A\in\{1,\ldots,M\}.
\]

The current bit may be quotiented by global bit-complement symmetry. Conditional on age `a<M`, the next character continues the same run with probability `1/2`, moving to age `a+1`, or starts the opposite-bit run at age `1` with probability `1/2`. At age `M`, the cap forces the next character to switch bit and return to age `1`.

Thus the left infinite character process has only `M` relevant quotient states. The uncapped right source is still iid fair binary.

The mean capped run length is

\[
\boxed{\mu_M=\mathbf E\min(G,M)=2-2^{1-M}.}
\tag{3.1}
\]

## 4. New theorem: age-typed Pareto-renewal macro operator

Fix macro word length two and parameters `0<z_x,z_y<1`. At a macro node, greedily embed each of the four words

\[
00,\quad01,\quad10,\quad11
\]

into the fresh left and right suffixes. For a word `w`, write

\[
(T_X(w),T_Y(w))
\]

for its two greedy endpoint increments and `A_X(w)` for the left terminal run age. Keep one deterministic representative of every Pareto-minimal endpoint pair, breaking identical-point ties lexicographically. Denote this frontier by `F_2`.

For starting left age `a` and terminal age `b`, define

\[
\boxed{
K^{(M)}_{a,b}(z_x,z_y)
=
\mathbf E_a\!\sum_{w\in\mathcal F_2}
 z_x^{T_X(w)}z_y^{T_Y(w)}
 \mathbf 1\{A_X(w)=b\}.
}
\tag{4.1}
\]

This is an `M x M` nonnegative matrix.

### Theorem 4.1 — finite Collatz certificate controls arbitrary run blocks

Suppose a positive vector `h in R^M_{>0}` and a number `0<lambda<1` satisfy

\[
\boxed{K^{(M)}(z_x,z_y)h\le\lambda h}
\tag{4.2}
\]

coordinatewise. Then

\[
\boxed{a_M\le
\frac{\mu_M\log(1/z_x)+2\log(1/z_y)}{-\log\lambda}.}
\tag{4.3}
\]

### Proof

**Lossless pruning.** For deterministic source strings, greedy embedding of any fixed suffix word from an earlier coordinate pair finishes no later, coordinatewise, than embedding the same suffix from a later pair. Therefore if a two-bit candidate endpoint is dominated, replacing it by a frontier candidate and retaining the same later word blocks cannot worsen the final endpoint. Repeating macro by macro loses no possible common subsequence of even length.

This remains true even when the dominating and dominated candidates end at different left Markov states: the statement is pathwise on the already realized underlying source strings, not a stochastic-state comparison.

**Stopping-line regeneration.** For a retained word `w`, whether it belongs to the Pareto frontier is determined by the source prefixes through `(T_X(w),T_Y(w))`: every competitor's statement `T_X(v)<=T_X(w)` and `T_Y(v)<=T_Y(w)` is decidable inside those stopped prefixes. The left capped process is a finite-state Markov chain, so by the strong Markov property its future after `T_X(w)` depends only on terminal age `A_X(w)` (the terminal bit is removed by complement symmetry). The right iid source has a fresh independent fair tail after `T_Y(w)`. Sibling independence is not required because the weighted population is summed and expectation is linear.

Iterating the macro construction and applying (4.2), if `Z_q(a)` is the total weight of retained words after `q` two-bit macros, with terminal witness factor `h`, then

\[
\mathbf E_a Z_q\le\lambda^q h_a.
\tag{4.4}
\]

If some common subsequence of length `2q` fits in a deterministic character box `(n_x,n_y)`, lossless pruning supplies a retained word with both endpoints in that box. Because `z_x,z_y<1` and `h>=h_min>0`,

\[
\Pr\{LCS(X_1^{n_x},Y_1^{n_y})\ge2q\}
\le C_h z_x^{-n_x}z_y^{-n_y}\lambda^q,
\tag{4.5}
\]

where `C_h=h_max/h_min` is a finite root/type constant. A special initial pre-character state changes only this multiplicative constant and therefore not the exponential rate.

Now let `N^X_r` and `N^Y_r` be the character lengths of `r` complete left capped runs and `r` complete right geometric runs. By the law of large numbers,

\[
\frac{N^X_r}{r}\to\mu_M,
\qquad
\frac{N^Y_r}{r}\to2.
\]

The left sums are bounded-run sums and the right geometric sums have exponential tails, so the corresponding normalized lengths are uniformly integrable. For any `epsilon>0`, on the overwhelmingly likely event

\[
N^X_r\le(\mu_M+\epsilon)r,
\qquad
N^Y_r\le(2+\epsilon)r,
\]

monotonicity embeds the random run blocks in that deterministic character box. Set `q=ceil(c r)`. Equation (4.5) decays exponentially whenever

\[
c>
\frac{(\mu_M+\epsilon)\log(1/z_x)+(2+\epsilon)\log(1/z_y)}{-\log\lambda}.
\]

Let `r->infinity`, use uniform integrability to pass from the tail probability to normalized expectation, then let `epsilon downarrow0`. Since a length `2q` common subsequence corresponds to normalized run-block value `q/r`, this gives (4.3). QED.

This is the required finite-to-arbitrary-length bridge: a finite `M x M` matrix inequality, plus explicit tail control in its entries, certifies an asymptotic statement about uncapped arbitrarily long strings.
