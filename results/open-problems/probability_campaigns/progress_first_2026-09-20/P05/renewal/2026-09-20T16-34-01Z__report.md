\[
\bar\rho_r=\frac{\mathbf E\,LCS(X^{(r)},Y^{(r)})}{2r}.

\bar\rho_{2m}\longrightarrow\gamma_2.

The earlier two-sided cap replaces **both** `G_i` and `H_i` by `min(.,M)`.  Its exact pathwise deletion argument gives the tail penalty

\bar\rho_{r,M}^{(2)}\le\bar\rho_r

## 3. New theorem: one-sided cap halves the renewal tail error

Define

\[
G_i^{[M]}:=\min(G_i,M)
\]

and let `X^(r,M)` be obtained from `X^(r)` by replacing only the left-source run lengths `G_i` with `G_i^[M]`.  Leave the right source `Y^(r)` completely uncapped.  Define

\[
\boxed{
\rho^{(1)}_{r,M}:=
\frac{\mathbf E\,LCS(X^{(r,M)},Y^{(r)})}{2r}.
}
\tag{3.1}
\]

### Theorem 3.1 — exact finite-r one-sided comparison

For every `r,M>=1`,

\[
\boxed{
0\le \bar\rho_r-\rho^{(1)}_{r,M}\le2^{-M}.
}
\tag{3.2}
\]

### Proof

For any deterministic strings `x,y`, if `x'` is obtained by deleting `d` symbols from `x`, then

\[
0\le LCS(x,y)-LCS(x',y)\le d.
\tag{3.3}
\]

The left inequality is monotonicity.  For the right inequality, take an optimal common subsequence of `x,y`; deleting `d` positions of `x` destroys at most `d` matched positions.

In the present coupling, `X^(r,M)` is obtained from `X^(r)` by deleting exactly

\[
D_{r,M}:=\sum_{i=1}^r(G_i-M)_+
\tag{3.4}
\]

symbols.  Therefore pathwise

\[
0\le
LCS(X^{(r)},Y^{(r)})-LCS(X^{(r,M)},Y^{(r)})
\le D_{r,M}.
\tag{3.5}
\]

For the fair-binary geometric run law,

\[
\begin{aligned}
\mathbf E(G-M)_+
&=\sum_{j\ge1}\Pr(G\ge M+j)\\
&=\sum_{j\ge1}2^{-(M+j-1)}\\
&=2^{1-M}.
\end{aligned}
\tag{3.6}
\]

Hence `E D_{r,M}=r 2^(1-M)`.  Divide (3.5) by `2r` and take expectations to obtain (3.2).  QED.

Compared with (2.2), the cap error has been reduced by the exact factor two

\[
2^{-(M-1)}\quad\longrightarrow\quad2^{-M}.
\tag{3.7}
\]

No simulation, asymptotic approximation or independence substitution is used.

## 4. New theorem: a monotone tail-resolution ladder

Increasing the cap from `M` to `M+1` adds exactly one symbol to every left-source run satisfying `G_i>=M+1`.  Let

\[
C_{r,M}:=\sum_{i=1}^r\mathbf 1_{\{G_i\ge M+1\}}.
\]

Then `X^(r,M)` is a subsequence of `X^(r,M+1)` with exactly `C_{r,M}` deleted symbols.  Applying (3.3) again gives

\[
0\le
LCS(X^{(r,M+1)},Y^{(r)})
-LCS(X^{(r,M)},Y^{(r)})
\le C_{r,M}.
\]

Since

\[
\mathbf E C_{r,M}=r\Pr(G\ge M+1)=r2^{-M},
\]

we obtain the uniform finite-r increment bound

\[
\boxed{
0\le
\rho^{(1)}_{r,M+1}-\rho^{(1)}_{r,M}
\le2^{-(M+1)}.
}
\tag{4.1}
\]

This is stronger information than the aggregate truncation error: it resolves the approximation into exact one-bit-per-long-run marginal layers.

## 5. Existence of the mixed renewal constants and exponential approximation to gamma_2

For relative initial phase `sigma in {same,opposite}`, write

\[
F^{\sigma}_{r,M}
=\mathbf E\,LCS(X^{(r,M)},Y^{(r)}\mid\sigma).
\]

For even `r,s`, concatenating independent run blocks with the same fixed phase relation gives pathwise superadditivity, hence

\[
F^\sigma_{r+s,M}\ge F^\sigma_{r,M}+F^\sigma_{s,M}.
\tag{5.1}
\]

Therefore Fekete's lemma gives a limit of `F^sigma_(2m,M)/(2m)` for each phase relation.

The two phase limits are equal.  Indeed, from an opposite-phase `r`-run pair (`r` even), retain the first `r-2` capped runs on the left and runs `2,...,r-1` on the right.  These retained blocks have the same phase and the correct iid run laws, so

\[
F^{\rm opposite}_{r,M}\ge F^{\rm same}_{r-2,M}.
\tag{5.2}
\]

Conversely, deleting the left block's last two capped runs and the right block's first and last geometric runs converts the opposite-phase pair to that same `(r-2)`-run pair.  By (3.3), the expected LCS loss is at most the expected number of deleted symbols, bounded by

\[
2\mathbf E\min(G,M)+2\mathbf E H\le8.
\]

Thus

\[
F^{\rm opposite}_{r,M}
\le F^{\rm same}_{r-2,M}+8.
\tag{5.3}
\]

Equations (5.2)-(5.3) force the same per-run limit for the two phase classes.  Consequently the phase-averaged limit

\[
\boxed{
a_M:=\lim_{m\to\infty}\rho^{(1)}_{2m,M}
}
\tag{5.4}
\]

exists.

Passing to the limit in (3.2), using (2.1), gives

\[
\boxed{
0\le\gamma_2-a_M\le2^{-M}.
}
\tag{5.5}
\]

Passing to the limit in (4.1) gives

\[
\boxed{
0\le a_{M+1}-a_M\le2^{-(M+1)}.
}
\tag{5.6}
\]

Hence

\[
\boxed{
a_M\uparrow\gamma_2}
\]

with a completely explicit exponential error envelope.

This is the main structural result of the run: **the ordinary binary Chvatal--Sankoff constant is the monotone limit of one-sided finite-run-alphabet renewal constants, with certified remainder at most `2^-M`.**

## 6. Exact base point and the marginal-utilization series

At `M=1`, the capped left string has exactly one symbol per run, hence is the deterministic alternating word of length `r` once its phase is fixed.  If the right block has the same initial phase, that alternating word is a subsequence of the `r` geometric runs by taking one symbol from each run, so the LCS is exactly `r`.  If the initial phases are opposite, the first desired left symbol does not occur before right run 2, and each later alternating symbol requires advancing one further run; exactly `r-1` symbols are attainable.  Therefore

\[
\rho^{(1)}_{r,1}=\frac{(r+(r-1))/2}{2r}
=\frac14\left(2-\frac1r\right),
\]

and

\[
\boxed{a_1=\frac12.}
\tag{6.1}
\]

Define the marginal layer

\[
\Delta_M:=a_{M+1}-a_M
\]

and its normalized utilization

\[
\boxed{u_M:=2^{M+1}\Delta_M.}
\tag{6.2}
\]

By (5.6),

\[
0\le u_M\le1.
\tag{6.3}
\]

Since `a_M -> gamma_2`, telescoping from (6.1) gives the exact convergent representation

\[
\boxed{
\gamma_2
=\frac12+
\sum_{M=1}^{\infty}2^{-(M+1)}u_M,
\qquad 0\le u_M\le1.
}
\tag{6.4}
\]

Equivalently,

\[
\boxed{
2\gamma_2-1
=\sum_{M=1}^{\infty}2^{-M}u_M.
}
\tag{6.5}
\]

Thus the Chvatal--Sankoff problem can be reframed as determining the geometrically weighted **run-tail utilization profile**: `u_M` is the asymptotic fraction, in normalized marginal value, of the potential `(M+1)`st symbol in long left runs that an optimal mixed-source LCS can actually exploit.

The published interval translates to

\[
0.585331984
\le
\sum_{M\ge1}2^{-M}u_M
\le
0.652560.
\tag{6.6}
\]

This is an identity/reparameterization, not endpoint movement.

A useful corollary is that any theorem of the form

\[
u_j\le u_*<1\qquad(j\ge M)
\]

would sharpen the geometric remainder immediately to

\[
\boxed{
\gamma_2-a_M\le u_*2^{-M},
}
\tag{6.7}
\]

so future work can attack a local marginal-influence quantity rather than the entire infinite tail at once.

## 7. Geometric memorylessness gives a finite residual family for nonanticipating mixed-source policies

The uncapped side remains geometric, but its residual law is exactly stable.  If `H~Geom(1/2)`, then for any integer `x>=1`,

\[
\Pr(H>x)=2^{-x},
\]

and for `k>=1`,

\[
\Pr(H-x=k\mid H>x)
=\frac{2^{-(x+k)}}{2^{-x}}
=2^{-k}.
\]

Hence

\[
\boxed{(H-x\mid H>x)\stackrel d=H.}
\tag{7.1}
\]

When a capped run of length at most `M` is matched against the uncapped side and the uncapped run survives, its residual is therefore a **fresh geometric run**, independent of the consumed amount.  When the capped side survives, its residual is an exact integer in `{1,...,M-1}`.

Thus a nonanticipating renewal policy that does not reveal the exact geometric excess before its crossing decision closes on a finite residual family consisting of the exact capped residuals plus one fresh-geometric state.  This is a genuine finite-state reduction for a lower-policy architecture.

Important limitation: the offline LCS optimum sees the realized future run lengths.  Equation (7.1) by itself does **not** turn `a_M` into a finite Markov decision process for an upper bound.  An upper certificate still has to control the value of that extra future information.  No such upper certificate is claimed here.
