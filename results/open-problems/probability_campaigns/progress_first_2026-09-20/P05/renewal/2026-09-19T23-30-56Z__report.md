## 2. New route before code: expose iid binary strings as geometric-run renewals

Let

\[
G_1,G_2,\ldots,\quad H_1,H_2,\ldots
\]

be two independent iid sequences with

\[
\Pr(G_i=k)=\Pr(H_i=k)=2^{-k},\qquad k=1,2,\ldots .
\]

Thus `G_i,H_i` are geometric with success probability `1/2`, mean `2`, variance `2`.

For an even integer `r>=2`, define the two random run blocks

\[
A_r=0^{G_1}1^{G_2}0^{G_3}\cdots 1^{G_r},\qquad
B_r=0^{H_1}1^{H_2}0^{H_3}\cdots 1^{H_r},
\]

and

\[
b_r:=\mathbf E\,L(A_r,B_r),\qquad
\rho_r:=\frac{b_r}{2r}.
\]

The normalization `2r` is the expected symbol length of either `r`-run block. The choice `r` even is deliberate: after an even number of runs the last symbol is `1`, so the next independent block can start with `0` without merging runs. This gives an exact renewal concatenation.

## 3. Main new theorem: exact renewal variational representation

### Theorem P05-R1 — even-run renewal identity

For the exact binary two-string Chvatal-Sankoff constant,

\[
\boxed{
\gamma_2
=\lim_{m\to\infty}\rho_{2m}
=\sup_{m\ge1}\rho_{2m}.
}
\]

Moreover, if `r,s` are even,

\[
\boxed{b_{r+s}\ge b_r+b_s.}
\]

Hence every finite even-run value is a rigorous lower bound:

\[
\boxed{\rho_r\le\gamma_2\qquad(r\text{ even}).}
\]

#### Proof, step 1: exact run-block superadditivity

Take even `r,s`. Because geometric run lengths are independent and because the symbol after the `r`th run flips from `1` back to `0`, an `(r+s)`-run block has the exact distributional decomposition

\[
A_{r+s}\stackrel d= A_rA'_s,
\qquad
B_{r+s}\stackrel d= B_rB'_s,
\]

where `(A'_s,B'_s)` is an independent copy of `(A_s,B_s)` and is independent of `(A_r,B_r)`.

For deterministic strings `U,V,U',V'`, concatenating a common subsequence of `(U,V)` with a common subsequence of `(U',V')` gives a common subsequence of `(UU',VV')`. Therefore

\[
L(UU',VV')\ge L(U,V)+L(U',V').
\]

Taking expectations gives

\[
b_{r+s}\ge b_r+b_s.
\]

Set `c_m=b_{2m}`. Then `c_{m+n}>=c_m+c_n`, so Fekete's lemma gives

\[
\lim_{m\to\infty}\frac{c_m}{m}
=\sup_{m\ge1}\frac{c_m}{m}.
\]

Equivalently, the limit and supremum of `rho_{2m}=c_m/(4m)` exist and are equal.

#### Proof, step 2: identify the renewal limit with gamma_2

Let

\[
T_r=G_1+\cdots+G_r,\qquad S_r=H_1+\cdots+H_r.
\]

Couple `A_r,B_r` to two independent infinite fair binary strings conditioned to start at `0`; then `A_r=X_1^{T_r}` and `B_r=Y_1^{S_r}` at their `r`th run endpoints.

For any two infinite strings and any nonnegative prefix lengths `p,q,n`, changing one prefix length by one changes LCS length by at most one. Hence deterministically

\[
\left|
L(X_1^p,Y_1^q)-L(X_1^n,Y_1^n)
\right|
\le |p-n|+|q-n|.
\]

Since `E T_r=E S_r=2r` and `Var(T_r)=Var(S_r)=2r`, Cauchy--Schwarz gives

\[
\mathbf E|T_r-2r|\le\sqrt{2r},\qquad
\mathbf E|S_r-2r|\le\sqrt{2r}.
\]

Write `a_n^{00}` for expected LCS of two length-`n` fair strings conditioned to have first bit `0`. Then

\[
|b_r-a_{2r}^{00}|\le2\sqrt{2r}.
\]

Forcing the first bit of an unconditioned string to `0` is one single-symbol substitution; changing one symbol of either input changes LCS by at most one. Coupling both strings this way gives

\[
|a_{2r}^{00}-a_{2r}|\le2.
\]

Therefore the completely explicit comparison is

\[
\boxed{
\left|
\rho_r-\frac{a_{2r}}{2r}
\right|
\le \sqrt{\frac2r}+\frac1r.
}
\tag{3.1}
\]

By the Chvatal--Sankoff limit, `a_{2r}/(2r) -> gamma_2`. Thus `rho_r -> gamma_2` along even `r`. Combining with Fekete proves

\[
\gamma_2=\sup_{r\in2\mathbb N}\rho_r.
\]

QED.

### Why this is useful

This is not another decimal estimate. It is an exact structural representation of the original iid binary constant as the optimum of a renewal hierarchy. It says that one may attack `gamma_2` through finite **numbers of runs** rather than fixed numbers of characters, and every even-run certificate controls arbitrary string lengths through superadditivity plus the renewal comparison.

It also isolates where the hard part lives: `r=2` only pairs corresponding runs and gives the elementary rate `2/3`; improvement comes entirely from LCS alignments that exploit interactions across several alternating runs.

Indeed, for `r=2`,

\[
L(0^{G_1}1^{G_2},0^{H_1}1^{H_2})
=\min(G_1,H_1)+\min(G_2,H_2),
\]

and

\[
\mathbf E\min(G,H)
=\sum_{k\ge1}\Pr(G\ge k,H\ge k)
=\sum_{j\ge0}4^{-j}=\frac43.
\]

Hence `b_2=8/3` and `rho_2=2/3` exactly. The gap from `2/3` to the true constant is therefore a clean measure of cross-run alignment gain.

## 4. Finite exact certificate controlling arbitrary lengths

The renewal representation is still infinite because geometric runs are unbounded. The tail can be removed with an explicit deterministic error.

For `M>=1`, set

\[
G_i^{(M)}=\min(G_i,M),\qquad H_i^{(M)}=\min(H_i,M),
\]

form `A_{r,M},B_{r,M}` from these capped run lengths, and write

\[
b_{r,M}=\mathbf E L(A_{r,M},B_{r,M}),\qquad
\rho_{r,M}=\frac{b_{r,M}}{2r}.
\]

### Theorem P05-R2 — capped finite-certificate sandwich

For every even `r` and every `M`,

\[
\boxed{
\rho_{r,M}\le\rho_r\le\rho_{r,M}+2^{-(M-1)}
}
\tag{4.1}
\]

and therefore

\[
\boxed{\gamma_2\ge\rho_{r,M}.}
\tag{4.2}
\]

Furthermore, `rho_{r,M}` is an **exact rational finite computation**. Specifically,

\[
\Pr(G^{(M)}=k)=
\begin{cases}
2^{-k},&1\le k<M,\\
2^{-(M-1)},&k=M,
\end{cases}
\]

so all `2r` run lengths have a common product denominator dividing

\[
2^{2r(M-1)}.
\]

#### Proof

Capping only deletes symbols from each run, so `A_{r,M}` is a subsequence of `A_r` and similarly for `B`. Hence

\[
L(A_{r,M},B_{r,M})\le L(A_r,B_r).
\]

Conversely, deleting the excess symbols needed to turn `(A_r,B_r)` into `(A_{r,M},B_{r,M})` can reduce LCS by at most the total number deleted. Thus

\[
0\le L(A_r,B_r)-L(A_{r,M},B_{r,M})
\le \sum_{i=1}^r(G_i-M)_+ +\sum_{i=1}^r(H_i-M)_+.
\]

For `G~Geom(1/2)`,

\[
\mathbf E(G-M)_+
=\sum_{t\ge1}\Pr(G\ge M+t)
=\sum_{t\ge1}2^{-(M+t-1)}
=2^{-(M-1)}.
\]

Taking expectations and dividing by `2r` yields (4.1). Equation (4.2) follows from Theorem P05-R1. The finite-support probability formula above proves exact rationality. QED.

This gives the requested finite-certificate-to-arbitrary-length bridge: a finite exact weighted sum over capped run blocks is not merely a finite-size statistic; it is automatically a rigorous lower bound on the infinite-string constant.
