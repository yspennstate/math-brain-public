# 2. New theorem I: the exact dual-response-reserve reduction

The finite-law line has naturally used the reserve

\[
\mathcal R_F:=Q_{MS}+2\mu-R_{MS}.
\tag{2.1}
\]

The Pareto calculation in the preceding P01-B report proved that `R_F` can be negative for arbitrary source-admissible heavy-tailed laws. That does **not** mean the factor-two conjecture fails. It means the finite-law reserve is only one of two canonical reserves supplied by the source lower bounds.

Define the second, tail/logarithmic reserve

\[
\boxed{
\mathcal R_T
:=Q_{MS}+2\mathcal L-R_{MS}-2\underline Q_G.
}
\tag{2.2}
\]

### Theorem 2.1 — dual reserve identities

For every source-admissible law for which the displayed quantities are finite,

\[
\boxed{
\mathcal R_F-2\delta
=2(\underline Q_G+\mu)-T_{MS},
}
\tag{2.3}
\]

and

\[
\boxed{
\mathcal R_T-2\delta
=2\mathcal L-T_{MS}.
}
\tag{2.4}
\]

Consequently

\[
\boxed{
\max\{\mathcal R_F,\mathcal R_T\}\ge2\delta
\quad\Longrightarrow\quad
T_{MS}\le2T_G.
}
\tag{DR}
\]

### Proof

Using `delta=Q_MS-underline Q_G`,

\[
\begin{aligned}
\mathcal R_F-2\delta
&=Q_{MS}+2\mu-R_{MS}-2Q_{MS}+2\underline Q_G\\
&=2(\underline Q_G+\mu)-(Q_{MS}+R_{MS})\\
&=2(\underline Q_G+\mu)-T_{MS},
\end{aligned}
\]

which is `(2.3)`. Likewise

\[
\begin{aligned}
\mathcal R_T-2\delta
&=Q_{MS}+2\mathcal L-R_{MS}-2\underline Q_G
 -2Q_{MS}+2\underline Q_G\\
&=2\mathcal L-(Q_{MS}+R_{MS})\\
&=2\mathcal L-T_{MS},
\end{aligned}
\]

which is `(2.4)`. If the maximum reserve is at least `2 delta`, then either `(2.3)` or `(2.4)` is nonnegative. The corresponding lower bound in `(1.2)` gives `T_MS<=2T_G`. QED.

The same theorem can be written directly in terms of the exact residence slack. From `(1.3)`,

\[
\boxed{
\mathcal R_F=\mathcal S+2\mu-\mathcal L,
\qquad
\mathcal R_T=\mathcal S+\mathcal L-2\underline Q_G.
}
\tag{2.5}
\]

Thus the two source lower bounds switch dominance exactly at

\[
\boxed{
\underline Q_G=\mathcal L-\mu.
}
\tag{2.6}
\]

Indeed

\[
\mathcal R_T-\mathcal R_F
=2(\mathcal L-\mu-\underline Q_G).
\tag{2.7}
\]

Equivalently, a single sufficient source-level target is

\[
\boxed{
\mathcal S-2\delta
\ge
\min\{\mathcal L-2\mu,\ 2\underline Q_G-\mathcal L\}.
}
\tag{DUAL}
\]

This is the correct two-lower-bound replacement for the earlier over-strong one-reserve targets. It is not claimed proved universally here.

# 3. New theorem II: Abel-weighted prefix transport

The previous P01-B transport estimate bounded all Gittins-valley rectangles by

\[
\sum_VD_V
\le\frac{\sup_x\tau(x)\theta(x)}{c}.
\tag{3.1}
\]

For very heavy tails the supremum can diverge even when the large-age region contains no further Gittins/M-SERPT mismatch. The problem is the order of operations: `(3.1)` takes the worst endpoint weight *before* exploiting where the Gittins valleys actually occur.

The following Abel argument keeps the rank-prefix geometry first.

Order the Gittins valleys by age,

\[
V_i=(u_i,v_i],\qquad i=1,2,\ldots.
\]

At the endpoints put

\[
a_i:=[\theta(u_i)-\theta(v_i)]
     [p(u_i)-p(v_i)]\ge0,
\tag{3.2}
\]

and

\[
w_i:=\frac{\tau(v_i)\theta(v_i)}{\lambda c}\ge0.
\tag{3.3}
\]

Then `(1.9)` is simply

\[
D_i=w_i a_i.
\tag{3.4}
\]

Define the running endpoint-weight record

\[
\widehat w_i:=\max_{1\le j\le i}w_j,
\qquad \widehat w_0:=0.
\tag{3.5}
\]

### Lemma 3.1 — suffix rectangle budget

For every `i`,

\[
\boxed{
\sum_{j\ge i}a_j
\le \theta(u_i)p(u_i)
=\frac{\lambda S(u_i)}{A(u_i)}.
}
\tag{3.6}
\]

### Proof

Associate to each Gittins valley the rectangle

\[
\mathfrak R_j=
[\theta(v_j),\theta(u_j)]
\times[p(v_j),p(u_j)].
\]

Its area is `a_j`. Since `theta` and `bar p` are nonincreasing and every Gittins-valley endpoint is an M-SERPT hill age, for `j>i` we have

\[
\theta(u_j)\le\theta(v_i),
\qquad
p(u_j)=\bar p(u_j)\le\bar p(v_i)=p(v_i).
\]

Thus the interiors of the rank rectangles are pairwise disjoint and every suffix rectangle `R_j`, `j>=i`, lies inside

\[
[0,\theta(u_i)]\times[0,p(u_i)].
\]

The sum of their areas is therefore at most the area of that box. Identity `(1.8)` gives the last equality in `(3.6)`. QED.

### Theorem 3.2 — Abel prefix bound

The total pre-credit waiting mismatch satisfies

\[
\boxed{
\sum_iD_i
\le
\mathfrak A_G
:=
\sum_i
\frac{\lambda S(u_i)}{A(u_i)}
(\widehat w_i-\widehat w_{i-1}).
}
\tag{ABEL}
\]

For countably many valleys the formula means the monotone limit of finite truncations.

### Proof

For a finite first `n` valleys,

\[
\sum_{i=1}^nD_i
=\sum_{i=1}^nw_i a_i
\le\sum_{i=1}^n\widehat w_i a_i.
\]

Abel summation gives the exact identity

\[
\sum_{i=1}^n\widehat w_i a_i
=
\sum_{i=1}^n
(\widehat w_i-\widehat w_{i-1})
\sum_{j=i}^na_j.
\tag{3.7}
\]

Apply `(3.6)` to every suffix in `(3.7)` and then let `n` increase. Every term is nonnegative, so monotone convergence gives `(ABEL)`. QED.

Combining `(1.11)` and `(ABEL)` yields the new support-independent waiting theorem

\[
\boxed{
Q_{MS}-\underline Q_G
\le \mathfrak A_G.
}
\tag{3.8}
\]

The old global-supremum estimate is recovered only after discarding the prefix discount. Indeed, at any M-SERPT hill age `h`,

\[
r(h)=N(h)/S(h)\ge r(0)=\mu.
\]

Hence

\[
A(h)=c+\lambda N(h)
\ge c+\rho S(h)\ge S(h),
\]

so

\[
\frac{\lambda S(h)}{A(h)}\le\lambda.
\tag{3.9}
\]

Therefore

\[
\mathfrak A_G
\le \lambda\sup_i\widehat w_i
=\frac{\sup_i\tau(v_i)\theta(v_i)}c
\le\frac{\sup_x\tau(x)\theta(x)}c.
\tag{3.10}
\]

The important point is that `(ABEL)` can remain finite when the last quantity in `(3.10)` is infinite. If `tau(x)theta(x)` diverges only in a terminal age range containing no more Gittins valleys, there are no new `w_i` records there and the divergent tail contributes **zero** to `mathfrak A_G`. In particular, an eventually all-hill/FB tail is no longer falsely penalized merely because `tau*theta` becomes large.

This directly repairs the main defect of the preceding `sup tau*theta` transport bound.
