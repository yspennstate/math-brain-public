and

\[
\mathcal L:=\int_0^\infty \frac{S(x)}{A(x)}\,dx

## 2. Exact rank-drop measure on one Gittins valley

Fix a Gittins valley

\[
V=(u,v].
\]

By source Lemma 5.3, its endpoints are M-SERPT hill ages. Decompose `V` into the M-SERPT hill pieces and M-SERPT valleys used in the earlier waiting proof.

Define a nonnegative measure `nu_V` that records the decrease of `H=S/A` along that M-SERPT decomposition:

- on an M-SERPT hill piece, `d nu_V=-dH`;
- for an M-SERPT valley `(y,z]`, put an atom of mass `H(y)-H(z)` at the right endpoint `z`.

The source Lemma-5.4/Corollary-5.5 monotonicity used in the preceding report guarantees that all these masses are nonnegative. The chunks telescope, so

\[
\boxed{
\nu_V(V)=H(u)-H(v).
}
\tag{2.1}
\]

The exact chunk identities from the previous waiting proof were

\[
d\Xi-dQ_{MS}=T\,dH
\quad\text{on M-SERPT hills},
\tag{2.2}
\]

and

\[
\Xi(y,z)-Q_{MS}(y,z)
=T(z)[H(z)-H(y)]
\quad\text{on an M-SERPT valley }(y,z].
\tag{2.3}
\]

Hence they combine **exactly** into

\[
\boxed{
\Xi_V-Q_{MS,V}=-\int_V T(x)\,d\nu_V(x).
}
\tag{2.4}
\]

This is the useful reformulation: the difference between the half-residence credit and M-SERPT waiting on a Gittins valley is a Stieltjes pairing between an increasing coordinate `T` and the positive rank-drop measure `nu_V`.

## 3. New exact credit: the terminal-weight bound had discarded an entire positive area

The preceding report replaced every weight `T(x)` in `(2.4)` by the terminal value `T(v)`. Do not make that replacement. Write instead

\[
-\int_VT\,d\nu_V
=-T(v)[H(u)-H(v)]
+\int_V[T(v)-T(x)]\,d\nu_V(x).
\tag{3.1}
\]

Define the **variation credit**

\[
\boxed{
\mathcal C_V
:=
\int_V[T(v)-T(x)]\,d\nu_V(x)\ge0.
}
\tag{3.2}
\]

The Gittins waiting surrogate contribution on `V` is

\[
\underline Q_{G,V}
=[S(u)-S(v)]\frac{\tau(v)}{A(u)A(v)}.
\tag{3.3}
\]

Exactly as in the previous endpoint calculation,

\[
T(v)[H(v)-H(u)]+\underline Q_{G,V}
=
S(v)T(v)\left(\frac1{A(v)}-\frac1{A(u)}\right).
\tag{3.4}
\]

Thus, with

\[
\boxed{
\mathcal B_V
:=
S(v)T(v)\left(\frac1{A(v)}-\frac1{A(u)}\right)\ge0,
}
\tag{3.5}
\]

we get the new **exact valley identity**

\[
\boxed{
\Xi_V-igl(Q_{MS,V}-\underline Q_{G,V}\bigr)
=
\mathcal B_V+\mathcal C_V.
}
\tag{VAR-EXACT}
\]

There is no AM-GM step, no support-cardinality parameter, and no finite-chain assumption in `(VAR-EXACT)` under the source's continuous-density/piecewise-monotone presentation.

On a Gittins hill region the M-SERPT and Gittins-surrogate waiting integrands coincide, so the entire `Xi` hill contribution is untouched. Define

\[
\mathcal B_G
:=
\Xi_{\mathcal H_G}+\sum_{V\in\mathcal V_G}\mathcal B_V,
\qquad
\mathcal C_G:=\sum_{V\in\mathcal V_G}\mathcal C_V.
\tag{3.6}
\]

Summing `(VAR-EXACT)` gives

\[
\boxed{
\Xi-(Q_{MS}-\underline Q_G)
=
\mathcal B_G+\mathcal C_G.
}
\tag{3.7}
\]

The prior bound `(1.5)` is obtained merely by throwing away `C_G`.

Substitute `(3.7)` into `(1.2)`. Since

\[
T_{MS}=2Q_{MS}+\mathcal L-2\Xi-\Lambda,
\]
we obtain the strengthened master identity

\[
\boxed{
T_{MS}
=
2\underline Q_G+\mathcal L
-2\mathcal B_G-2\mathcal C_G-\Lambda.
}
\tag{MASTER-V}
\]

Therefore the precise universal inequality that now suffices for Conjecture 8.1 is

\[
\boxed{
\mathcal L-2\mathcal R_G^{HS}
\le
2\mathcal B_G+2\mathcal C_G+\Lambda.
}
\tag{VHS}
\]

`(VHS)` is strictly weaker than `(OLD-HS)`. The full conjecture is **not** claimed here because `(VHS)` is not yet proved universally.

## 4. Why `C_G` is exactly the multi-record prefix interaction R7-04 needs

Consider the finite-chain/block version of one Gittins valley. Let its M-SERPT decomposition have endpoints

\[
a_0=u<a_1<\cdots<a_k=v,
\]

and write

\[
H_i=H(a_i),\qquad T_i=T(a_i),
\]
\[
\Delta H_i:=H_i-H_{i+1}\ge0,\qquad
\Delta T_i:=T_{i+1}-T_i\ge0.
\]

Then `(3.2)` becomes

\[
\boxed{
\mathcal C_V
=
\sum_{i=0}^{k-1}(T_k-T_{i+1})\Delta H_i.
}
\tag{4.1}
\]

Abel/Fubini summation gives the equivalent prefix form

\[
\boxed{
\mathcal C_V
=
\sum_{q=1}^{k-1}(H_0-H_q)\Delta T_q.
}
\tag{4.2}
\]

This is the support-independent interaction that was invisible in the terminal-weight bound.

For the same chain, the `D1` part of `Lambda` is

\[
\sum_{i=0}^{k-1}\Delta H_i\Delta T_i.
\]

Hence

\[
\boxed{
2\mathcal C_V+\sum_iD_{1,i}
=
\sum_i\Delta H_i\Delta T_i
+2\sum_{i<q}\Delta H_i\Delta T_q.
}
\tag{4.3}
\]

The right side contains **every ordered early-rank-drop / later-`T`-increase cross term**.

Consequences:

1. If the Gittins valley is one M-SERPT chunk, `C_V=0`; this is the aligned case already treated by the preceding prefix-compensation theorem.
2. If Gittins skips exactly one strict M-SERPT record, then
   \[
   \mathcal C_V=\Delta H_0\Delta T_1,
   \]
   so `(4.3)` adds the missing cross term `2 Delta H_0 Delta T_1` to the two diagonal `D1` terms.
3. For arbitrarily many skipped records, `(4.3)` automatically contains all the earlier-to-later interactions; no atom-by-atom case enumeration is required.

This matches R7-04's newest handoff: its finite theorem says the first possible obstruction is a longer prefix mismatch chain. The exact quantity `C_V` is the natural general-law prefix interaction generated by such a chain.

## 5. New load-only lower bound for every `T` increment

The second new lemma turns the abstract variation area into an explicit residual-capacity bound.

Put

\[
m(x):=E[X\wedge x]=\frac{1-A(x)}\lambda,
\qquad
q(x):=E[(X\wedge x)^2].
\]

Recall the exact primitive used in the preceding report,

\[
P(x):=A(x)x+\tau(x),
\qquad
\frac{dT}{dY}=P(x).
\tag{5.1}
\]

Two elementary inequalities hold for every `x`:

\[
x\ge m(x)
\tag{5.2}
\]

because `X wedge x <= x`, and

\[
q(x)\ge m(x)^2
\tag{5.3}
\]

by Jensen. Therefore

\[
P(x)
=A(x)x+\frac\lambda2q(x)
\ge
\frac{A(x)(1-A(x))}{\lambda}
+
\frac{(1-A(x))^2}{2\lambda}
=
\boxed{
\frac{1-A(x)^2}{2\lambda}.
}
\tag{5.4}
\]

Since `Y=1/A`, integration of `(5.1),(5.4)` gives, for every `a<b`,

\[
\boxed{
T(b)-T(a)
\ge
\frac1{2\lambda}
\left[
\Phi(A(b))-\Phi(A(a))
\right],
\qquad
\Phi(t):=t+\frac1t.
}
\tag{LOAD-T}
\]

For `0<t<=1`, `Phi` increases as residual capacity `t` decreases. Thus `(LOAD-T)` is positive and requires no tail-shape or support-size assumption.

## 6. Prefix-cut variation theorem

Fix again a Gittins valley `V=(u,v]`. Let `a in (u,v)` be any cut compatible with the M-SERPT Stieltjes decomposition, and define the rank drop accumulated before the cut by

\[
\Delta_H(u,a):=\nu_V((u,a])\ge0.
\tag{6.1}
\]

Every unit of `nu_V` occurring before `a` receives weight at least `T(v)-T(a)` in `(3.2)`. Hence

\[
\mathcal C_V
\ge
[T(v)-T(a)]\Delta_H(u,a).
\tag{6.2}
\]

Applying `(LOAD-T)` gives the explicit support-independent bound

\[
\boxed{
2\mathcal C_V
\ge
\frac{\Delta_H(u,a)}{\lambda}
\left[
\Phi(A(v))-\Phi(A(a))
\right].
}
\tag{CUT}
\]

Now recall the exact hill-survival deficit of a Gittins valley from the preceding report:

\[
D_V
:=
\mathcal L_V-2\mathcal R^{HS}_V
=
\frac1\lambda\int_{A(v)}^{A(u)}\left(\frac1t-2\right)dt
-2(v-u)S(v)\left(\frac1{A(v)}-1\right).
\tag{6.3}
\]

Discarding the favorable endpoint-survival term and the nonpositive portion above residual capacity `1/2` gives

\[
D_V
\le
\frac1\lambda\Psi(A(v)),
\tag{6.4}
\]

where

\[
\Psi(z):=
\begin{cases}
0,&z\ge1/2,\\[1mm]
\log\dfrac1{2z}-1+2z,&0<z<1/2.
\end{cases}
\tag{6.5}
\]

Combining `(CUT)` and `(6.4)` proves the new closure criterion:

> **PREFIX-CUT VARIATION CLOSURE.** If a Gittins valley `V=(u,v]` admits a cut `a` such that
> \[
> \boxed{
> \Delta_H(u,a)
> \left[
> \Phi(A(v))-\Phi(A(a))
> \right]
> \ge
> \Psi(A(v)),
> }
> \tag{VC}
> \]
> then
> \[
> \boxed{D_V\le2\mathcal C_V.}
> \]
> Thus the entire positive hill-survival deficit of that valley is paid by the newly retained variation credit alone, without using `B_V`, `D1`, or `D3`.

This theorem is independent of the number of internal M-SERPT records. A valley containing a long skipped-prefix chain is therefore easier, not harder, whenever that chain produces appreciable `H=S/A` variation before the terminal residual-capacity drop.

## 7. Quantitative description of the only hard high-load branch

If `(VC)` fails, then for **every** admissible cut `a`,

\[
\boxed{
\Delta_H(u,a)
<
\frac{\Psi(A(v))}
{\Phi(A(v))-\Phi(A(a))}.
}
\tag{7.1}
\]

This sharply constrains any remaining high-load obstruction.

Fix a residual-capacity level `alpha in (0,1)` independent of `A(v)` and take a cut with `A(a)=alpha` when such a cut lies in the valley. As `z:=A(v) downarrow0`,

\[
\Psi(z)=\log(1/z)+O(1),
\qquad
\Phi(z)-\Phi(\alpha)=\frac1z+O(1).
\]

Therefore failure of `(VC)` forces

\[
\boxed{
\Delta_H(u,a)
=O\!\left(z\log\frac1z\right).
}
\tag{7.2}
\]

So a genuinely deep post-half-load Gittins valley can evade the variation charge only if its M-SERPT envelope accumulates **vanishingly small `H=S/A` drop throughout every fixed-capacity prefix** and postpones essentially all variation into the final `A=O(z)` layer.

This is a much narrower geometry than “three or more records”. It is also consistent with the earlier aligned-prefix theorem: when there is no internal variation at all, the problem collapses to an aligned valley chain, where the preceding report exhibited an explicit positive prefix-compensation certificate.

There is a useful exact rigidity observation behind `(7.2)`. If `H=S/A` is exactly constant on an age interval, say `H=h`, then

\[
A'(x)=-\lambda S(x)=-\lambda hA(x),
\]
so `A` is exponential there, while

\[
r_S(x)=\frac{N(x)}{S(x)}
=\frac{1-c/A(x)}{\lambda h}
\]
strictly **decreases** as age increases. Hence an exactly `H`-flat interval cannot itself generate new strict M-SERPT records. Any remaining multi-record counterexample geometry must therefore combine near-flatness in the sense of `(7.2)` with record variation compressed into the final residual-capacity layer.
