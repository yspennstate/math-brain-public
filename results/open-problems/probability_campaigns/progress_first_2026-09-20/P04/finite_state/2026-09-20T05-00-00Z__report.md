## 3. New reduction: every sitewise finite statistic of Bradley's diagonal layer vector preserves the difficult independence property

Let

`W^(h) = (W_j^(h))_{j in Z^d}`, `h in Z^d`,

be independent copies of Bradley's 1994 binary **nonstationary** field. Every one-site marginal `W_j^(h)` is fair `{-1,+1}`.

For each physical output site `k`, define the diagonal layer vector

`V_k = (W_j^(k-j))_{j in Z^d}`.

At a fixed `k`, distinct coordinates `j` use distinct layer labels `k-j`. Therefore

`V_k ~ nu := (fair Rademacher)^{tensor Z^d}`.

Now let `A` be any finite alphabet and let

`f : {-1,+1}^{Z^d} -> A`

be an arbitrary measurable map. Define the finite-state field

`Y_k = f(V_k)`.

No locality, continuity, finite-coordinate dependence, algebraic structure, or invertibility is assumed for `f`.

### Theorem 3.1 — exact source properties inherited except tail reconstruction

For every measurable finite-valued `f`, the field `Y` is strictly stationary and satisfies Bradley's exact lattice-halfspace one-dependence. It is nondegenerate exactly when `f(V_0)` is nonconstant under `nu`.

#### Proof: strict stationarity

Fix `t in Z^d`. For every `k,j`,

`V_(k+t)(j) = W_j^(k+t-j)`.

Relabel the iid layer family by

`W_tilde^(h) := W^(h+t)`.

The whole family `(W_tilde^(h))_h` has exactly the same law as `(W^(h))_h`. Under this relabeling,

`V_(k+t)(j) = W_tilde_j^(k-j)`.

Thus the joint law of `(V_(k+t))_k` equals that of `(V_k)_k`, and applying the same measurable `f` sitewise proves strict stationarity of `Y`.

#### Proof: Bradley halfspace one-dependence

Fix a coordinate `i` and `m in Z`. Consider all source variables used by output sites with `k_i < m`. Group them by layer `h=k-j`. Within a fixed layer `h`, such variables have

`j_i = k_i-h_i < m-h_i`.

Thus the entire left output halfspace is measurable with respect to the join, over `h`, of

`L_h := sigma(W_j^(h) : j_i < m-h_i)`.

Similarly, if `k_i > m+2`, then within layer `h=k-j` one has

`j_i = k_i-h_i > m+2-h_i`,

so the right output halfspace is measurable with respect to the join of

`R_h := sigma(W_j^(h) : j_i > m+2-h_i)`.

Bradley's binary source field gives `L_h independent of R_h` for every `h`. Different layers are independent of one another. Therefore the join of all `L_h` is independent of the join of all `R_h`. Passing to the smaller sigma-fields generated by the finite-valued outputs preserves independence. QED.

### Why this reduction matters

Bradley's original real-valued stationarization uses an injective coordinate map so that every layer bit can be recovered sitewise. The theorem shows that injectivity is **not needed** for stationarity or for the exact source halfspace independence. The finite-state problem can therefore be attacked inside a very concrete class:

> Find a nonconstant finite-valued statistic `f` of an iid countable Rademacher vector such that the induced diagonal-factor field `Y_k=f(V_k)` becomes measurable from its own spatial tail.

This is a genuine finite-alphabet construction route rather than an attempted finite recoding of all layer information.

## 4. Tail-rigidity lemma for finite disagreements

The next lemma is measure-theoretic and applies to any own-tail-deterministic field, not only Bradley's architecture.

### Lemma 4.1 — a self-coupling cannot differ at finitely many sites

Let `mu` be a probability law on a countable-lattice field such that every coordinate is measurable with respect to the full spatial tail. Let `(Y,Y')` be **any coupling** with both marginals equal to `mu`. Put

`D = {k : Y_k != Y'_k}`.

Then, outside a coupling-null set,

`|D| < infinity  =>  D = emptyset`.

Equivalently,

`P(0 < |D| < infinity)=0`.

#### Proof

Choose increasing finite boxes `B_n` whose union is the lattice. Fix an output coordinate `r`. Since `Y_r` is tail measurable, for every `n` there is a measurable decoder `g_(r,n)` on configurations outside `B_n` such that

`Y_r = g_(r,n)(Y|B_n^c)`

`mu`-almost surely. Because `Y'` has the same marginal law, the same identity holds for `Y'` with the same decoder outside a coupling-null set. Intersect the resulting full-measure events over the countable set of pairs `(r,n)`.

On that full-measure event, if `D` is finite, choose `n` with `D subset B_n`. Then the two exterior configurations agree outside `B_n`, and therefore

`Y_r = g_(r,n)(Y|B_n^c) = g_(r,n)(Y'|B_n^c) = Y'_r`.

This holds for every `r`, hence `D` is empty. QED.

This lemma is exactly the rigidity needed to test finite-state compressions of Bradley's countable independent layers: a perturbation that changes only finitely many output symbols is forbidden unless it changes none.

## 5. New obstruction: own-tail determinism forces infinite total influence

For `j in Z^d`, define the coordinate-resampling influence of `f` under the iid product law `nu` by

`I_j(f) = P(f(omega) != f(omega^(j)))`,

where `omega~nu` and `omega^(j)` is obtained by replacing only coordinate `j` by an independent fair Rademacher bit.

Fix a layer label `h`. Replace the entire Bradley layer `W^(h)` by an independent copy `W'^(h)`, leaving all other layers unchanged, and construct the corresponding output field `Y'` from the **same** function `f`.

Both `Y` and `Y'` have the same stationary marginal law.

At physical site `k=h+j`, the diagonal vector uses the resampled layer `h` in exactly one coordinate, namely coordinate `j`, because

`k-j = h`.

All other coordinates of `V_(h+j)` use distinct layers and are independent of both the old and new `j`-bits. Hence the old/new pair of diagonal vectors is exactly the product-law single-coordinate resampling coupling. Therefore

`P(Y_(h+j) != Y'_(h+j)) = I_j(f)`.

If

`D_h := {k : Y_k != Y'_k}`, 

then Tonelli gives the exact identity

`E |D_h| = sum_(j in Z^d) I_j(f)`,

with both sides allowed to be `+infinity`.

### Theorem 5.1 — infinite-influence necessity

Assume the finite-state diagonal-factor field `Y_k=f(V_k)` is nondegenerate and measurable with respect to its own spatial tail. Then

`sum_j I_j(f) = infinity`.

More sharply, under a one-layer resampling,

`P(0 < |D_h| < infinity)=0`,

and

`P(|D_h|=infinity)>0`.

#### Proof

The first displayed zero-probability statement follows immediately from Lemma 4.1 because `(Y,Y')` is a self-coupling of the tail-deterministic marginal law.

Suppose for contradiction that `sum_j I_j(f)<infinity`. Then `E|D_h|<infinity`, so `|D_h|<infinity` almost surely. Lemma 4.1 forces `D_h=emptyset` almost surely. Therefore, for every `j`,

`I_j(f)=P(Y_(h+j) != Y'_(h+j))=0`.

If every coordinate-resampling influence is zero, then `f` is independent of each individual input bit conditional on all the others. Iterating over an arbitrary finite set `F`, `f` is measurable with respect to the coordinates outside `F`. Hence `f` is measurable with respect to the iid product tail sigma-field. Kolmogorov's zero-one law then makes the finite-valued `f` almost surely constant under `nu`, contradicting nondegeneracy.

Thus total influence is infinite.

Finally, nonconstancy of `f` implies at least one `I_j(f)>0` (otherwise the preceding zero-one argument again makes `f` constant). Hence `P(D_h nonempty)>0`; finite nonempty disagreement is impossible by Lemma 4.1, so `P(|D_h|=infinity)>0`. QED.

### Corollary 5.2 — broad compression classes ruled out

No nonconstant diagonal factor `f` with summable coordinate-resampling influences can produce a Bradley finite-state solution. In particular this excludes:

1. every finite-coordinate / cylinder `f`;
2. every bounded-radius or finite-window nonlinear compression of the diagonal layer vector;
3. every arbitrary measurable finite-valued `f` for which `sum_j I_j(f)<infinity`.

The conclusion does **not** require `f` to be invertible, algebraic, continuous, monotone, symmetric, or a group/quasigroup homomorphism.

This strictly changes the construction picture from the historical handoff. Finite-state compression of Bradley's stationarization is not ruled out merely because a finite alphabet cannot injectively store countably many bits. What is ruled out is any compression whose response to one layer has finite expected spatial footprint. A surviving finite-state factor must exhibit a genuinely nonlocal **infinite avalanche** when one independent Bradley layer is resampled.

## 6. Failed extension from the preceding SFT theorem

The previous report left open whether Bradley halfspace independence itself forces an arbitrary invariant measure supported on an SFT to have shell-local conditional laws. I tried to derive this by exposing opposite coordinate halfspaces one at a time.

The obstacle is real: the source assumption only gives unconditional independence for a pair of sufficiently separated halfspaces. Conditioning on the other coordinate directions can create multi-side secret-sharing dependence. An SFT's support constraints are local, but a highly nonuniform invariant measure on that support can assign global weights that are not determined by a finite shell. Thus the box-uniform argument cannot simply be upgraded by replacing uniform extension counts with Bradley independence. I found no valid route from the pairwise halfspace sigma-field independence to a full DLR/Markov property.

This is recorded as a failed implication, not as evidence that such an SFT measure exists.

## 7. Next constructive attack: infinite-influence finite statistics

Theorem 5.1 gives a precise design criterion rather than only a no-go statement. The remaining diagonal-factor class is nonempty as a class of Boolean functions: measurable functions of countably many iid bits can have infinite total influence.

A concrete family to analyze next is a threshold of an almost-surely convergent Rademacher series,

`f(omega) = 1{ sum_j a_j omega_j >= 0 }`,

with `a in l^2(Z^d)` but deliberately not in `l^1(Z^d)`. The series converges almost surely. For suitable coefficient blocks with anti-concentration near zero, the resampling influences are expected to be of first order in `|a_j|`, so nonsummable `a` is a plausible way to meet the necessary infinite-influence condition.

This is **CONJECTURAL DESIGN WORK**, not a result: the decisive obligation is to prove or disprove

`Y_0 measurable from intersection_(B finite) sigma(Y_k : k notin B)`

for such a factor. Infinite total influence is necessary, not sufficient. A useful next step is to choose a block-structured `l^2\l^1` coefficient sequence for which the influence lower bounds can be proved exactly, then test whether Bradley's shell parity identities induce a measurable exterior decoder for the threshold output.

A second option, if threshold factors fail, is an infinite-depth decision tree whose expected number of queried diagonal coordinates is infinite but whose output remains binary; the layer-resampling avalanche theorem gives an exact criterion any such tree must satisfy.
