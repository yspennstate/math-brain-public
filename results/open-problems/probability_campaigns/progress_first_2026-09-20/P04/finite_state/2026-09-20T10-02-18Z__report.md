## 2. Main new theorem

All logarithms in this section are base two.

### Theorem 2.1 — arbitrarily low-rate stationary finite-state helper correcting every finite erasure

Fix `d>=1` and `K>=3`. There exist jointly stationary finite-state fields

`B=(B_v)_(v in Z^d)`, `C=(C_v)_(v in Z^d)`

such that:

1. `B` is iid Bernoulli(1/2), so `H(B_0)=1`;
2. for every finite `S subset Z^d`,

   `H(B_S | B_(S^c), C)=0`;

3. the helper entropy density satisfies

   `h_Zd(C) <= 1/(K-1)`.

Consequently, for every `epsilon>0` there is such a pair with

`h(C)/H(B_0) < epsilon`.

In particular, there is **no** dimension-dependent constant `c_d>0` for the abstract helper statement above.

The helper alphabet below has at most eight symbols, independent of `K`.

## 3. One-dimensional K-adic hierarchy

It is enough to build the construction line-by-line along the first coordinate. Start in one dimension.

Let

`B=(B_n)_(n in Z)`

be iid fair bits. Independently choose a Haar-uniform `K`-adic integer

`U in Z_K`.

For each `m>=1`, write `u_m` for the residue of `U` in `{0,...,K^m-1}`. Define the nested scale-`m` partition of `Z` into blocks

`I_(m,a) = {a K^m-u_m, ..., (a+1)K^m-u_m-1}`,  `a in Z`.

The boundary congruences are compatible because `u_(m+1)=u_m mod K^m`, so the partitions coarsen with `m`.

Put

`s_m = K^(m-1)`.

In every scale-`m` block `I=[ell,ell+K^m-1]`, designate the site

`d(I)=ell+s_m`.

Equivalently, the scale-`m` designated sites are exactly

`D_m(U) = {n in Z : n+U = K^(m-1) (mod K^m)}`.

These sets are pairwise disjoint. Indeed membership in `D_m(U)` says that the `K`-adic valuation of `n+U` is exactly `m-1`, since the first nonzero base-`K` digit is `1`. Hence one physical site stores at most one scale check.

Their densities are

`dens D_m = K^(-m)`,

so the union

`D(U)=union_(m>=1) D_m(U)`

has density

`delta_K = sum_(m>=1) K^(-m) = 1/(K-1)`.

### A finite-state zero-entropy phase name

The `K`-adic odometer `U -> U+1` is an aperiodic ergodic zero-entropy `Z`-system. Fix once and for all a finite generating partition for this odometer; for example, by the finite-generator theorem one may take a two-set measurable generator because the entropy is zero. Let

`M_n=M(U+n)`

be the corresponding binary generating name. Thus the full bi-infinite marker name `(M_n)_(n in Z)` determines `U` modulo null sets, and `h(M)=0`.

We also expose the one-bit designation indicator

`J_n = 1_(n in D(U))`.

Since `J` is a factor of `U`, `(M,J)` still has entropy rate zero.

## 4. Quadratic parity check at each scale block

Fix a scale-`m` block

`I={ell,...,ell+K^m-1}`.

Define the cyclic translation by `s_m` inside `I`:

`T_(m,I)(x) = ell + ((x-ell+s_m) mod K^m)`.

Because `K>=3`, `T` and `T^(-1)` move a point in two distinct directions around a cycle of length `K` in the coarse `s_m`-coordinate.

Define one binary check for the entire block:

`Q_(m,I)(B) = XOR_(x in I) [ B_x B_(T_(m,I)x) ]`.

Store this single bit at the designated site `d(I)`. At all nondesignated sites store no check.

The one-dimensional helper symbol is therefore

`C_n = ( M_n, J_n, Z_n )`,

where

`Z_n = Q_(m,I)(B)` if `n=d(I)` for the unique scale `m`, and `Z_n=0` if `J_n=0`.

Thus `C_n` takes values in a fixed alphabet of size at most `2^3=8`.

The map is highly nonlocal: a scale-`m` check reads a block of length `K^m`, while a typical site is selected for scale `m` with probability `K^(-m)`. In particular its natural coding-radius first moment is divergent:

`sum_m K^m K^(-m) = infinity`.

That is exactly how it evades the finite-range and finite-expected-coding-volume obstructions proved in earlier P04 runs.

## 5. Exact finite-erasure recovery in one dimension

Fix a finite nonempty erasure set `E subset Z`. From the full helper name `C`, recover `U` from `M`, hence recover every hierarchical block and every designated check location.

We prove that, almost surely, `B_E` is uniquely determined by `B_(E^c)` and all stored checks.

### 5.1 Eventually all erased sites lie in one ancestor block

The scale partitions are nested. Therefore either `E` is eventually contained in one scale block, or it is split by a scale boundary at every sufficiently large scale.

The second event has probability zero. To see this, for large `m` the spacing `K^m` exceeds `diam(E)`, so there is at most one scale-`m` boundary in the finite interval spanning `E`. If such a boundary persists through all larger nested scales, some fixed integer `b` in that finite interval satisfies

`b+U = 0 (mod K^m)` for all `m`,

hence `U=-b` as a `K`-adic integer. Haar measure gives zero mass to each single `K`-adic integer, and there are only finitely many possible `b` here.

Hence, almost surely, there is `m_0(E,U)` such that for every `m>=m_0`, all of `E` lies in a single scale-`m` block `I_m`.

Increase `m_0` further so that

`s_m=K^(m-1) > diam(E)`

for every `m>=m_0`.

### 5.2 Every wrong finite filling is detected at infinitely many independent scales

Fix the actual word `b_E` and another candidate word `b'_E != b_E`, keeping the outside configuration fixed. Let

`Delta={x in E : b'_x != b_x}`

be the nonempty flip set. Write `delta_x=1_Delta(x)`.

For `m>=m_0`, let `T_m` be the cyclic shift on the unique ancestor block `I_m`. Since `s_m>diam(E)`, the three sets

`Delta`, `T_m Delta`, `T_m^(-1) Delta`

are pairwise disjoint, and the latter two lie outside `E`.

Expand the quadratic check over `F_2`:

`Q_m(b+delta)+Q_m(b)`

`= XOR_x [ delta_x b_(T_m x) + b_x delta_(T_m x) + delta_x delta_(T_m x) ]`.

The last term vanishes because `Delta` and `T_m^(-1)Delta` are disjoint. Renaming the second sum gives the exact identity

`Q_m(b') XOR Q_m(b)`

`= XOR_(x in Delta) [ B_(T_m x) XOR B_(T_m^(-1) x) ].`                 (5.1)

The `2|Delta|` source bits on the right are distinct iid fair bits outside `E`. Hence, conditional on `(U,B_E)`, the check difference in (5.1) is itself a fair bit.

Moreover, the seed sets

`A_m = T_m Delta union T_m^(-1) Delta`

are disjoint for all sufficiently large successive `m`. Every point of `A_m` lies at ordinary distance between roughly `s_m` and `(K-1)s_m` from `E`, while

`s_(m+1)=K s_m`.

More explicitly, if `D=diam(E)`, then for large `m`

`dist(A_m,E) >= s_m-D`,

whereas every point of `A_m` lies within `(K-1)s_m+D` of `E`; and

`K s_m-D > (K-1)s_m+D`

once `s_m>2D`. Thus the annuli are disjoint.

Therefore the check differences for all sufficiently large `m` are independent fair bits. The probability that the wrong candidate `b'_E` passes **every** ancestor check is zero.

There are only `2^|E|-1` wrong candidates. A finite union of null events is null. Hence, almost surely, there is exactly one filling of `E` compatible with the known outside bits and all hierarchical checks, namely the true one:

`H(B_E | B_(E^c), C)=0`.                                              (5.2)

This is exact recovery, not asymptotic small error.

## 6. Extension to every dimension

Now let `d>=1`, write sites as `(n,y)` with

`n in Z`, `y in Z^(d-1)`,

and let `B_(n,y)` be iid fair bits.

For every transverse line `y`, independently choose a Haar `K`-adic phase `U_y` and perform the one-dimensional construction on the line

`{(n,y):n in Z}`.

The field is strictly stationary under all of `Z^d`: a shift by `(t_1,t_perp)` sends the phase family to

`U'_y = U_(y+t_perp)+t_1`,

which has the same iid Haar law, and the iid bulk is shift invariant.

If `S subset Z^d` is finite, it intersects only finitely many lines. On each such line, Section 5 recovers the erased bulk bits from the unerased bits on that line and that line's helper. Taking the finite product of these almost-sure recovery statements gives

`H(B_S | B_(S^c), C)=0`                                                (6.1)

for every finite `S`.

### Entropy density

The phase-marker part `(M,J)` has zero `Z^d` entropy density. In a side-`N` box there are order `N^(d-1)` transverse lines, and the length-`N` marker word on each line has entropy `o(N)` because the odometer coding has one-dimensional entropy zero. Hence the total marker entropy is `o(N^d)`.

Conditional on the phases, only designated sites can carry a nonzero check bit. A fixed site belongs to `D_m` with probability `K^(-m)`, and the `D_m` are disjoint, so

`P(J_0=1)=delta_K=1/(K-1)`.

For every finite box `F`,

`H((Z_v)_(v in F) | phase markers) <= E |F intersect D| = delta_K |F|`.

Dividing by `|F|` along Følner boxes gives

`h_Zd(C) <= delta_K = 1/(K-1)`.                                      (6.2)

Since `H(B_0)=1`, choosing `K` arbitrarily large makes the helper/bulk entropy ratio arbitrarily small.

This completes Theorem 2.1.

## 7. Consequence for the preceding Bradley reduction

The previous P04 report's `iid bulk + thin helper` reduction remains correct and useful, but its proposed entropy-only closing lemma is now ruled out.

Even with all of the following properties simultaneously,

- iid finite-state bulk;
- stationary finite-state helper;
- exact recovery of **every** finite bulk erasure;
- helper alphabet bounded independently of the target rate;

there need not be any positive universal lower bound on helper entropy density relative to bulk entropy.

The obstruction to a Bradley field therefore cannot be only a Shannon-rate or stationary coding theorem. An infinite hierarchy can reuse one sparse stream of checks across every finite erasure while spending arbitrarily small entropy density.

This also explains why the previous finite-range Garden-of-Eden argument was genuinely using locality. The present hierarchy is pre-injective in the finite-erasure sense but its check radius has an infinite first moment, so remote checks can distinguish a local change at infinitely many scales.

## 8. Why this is not a Bradley construction

The theorem above is a counterexample to an **intermediate helper conjecture**, not a solution of Question 10.

The helper deliberately exposes a nontrivial `K`-adic odometer marker `M`. That marker is a factor of `C`, has zero entropy, and is not mixing under translation in the first coordinate (the odometer has nontrivial discrete spectrum).

By contrast, Bradley's exact separated-halfspace independence implies strong mixing along every nonzero lattice direction: for two cylinder events, a sufficiently large translate separates their supports across a Bradley-valid coordinate gap, making them exactly independent; cylinder approximation yields mixing for arbitrary events. Every factor of a mixing action is mixing.

Therefore a field containing this explicit odometer marker cannot satisfy Bradley's halfspace condition. The same phase defect is exactly the one isolated in the earlier P04 finite/profinite-phase obstruction.

So the new construction does **not** weaken the full-source target. It identifies the missing ingredient much more sharply:

> low-rate hierarchical finite-erasure coding is possible at finite alphabet and under strict stationarity; what Bradley forbids is a hierarchy whose phase/organization becomes a common nonmixing latent visible to the field.

Any positive construction now needs a **cut-blind mixing hierarchy**: enough unbounded-scale checks to imitate Section 5, but no recoverable compact/global phase in either separated halfspace and no violation of exact halfspace sigma-field independence.
