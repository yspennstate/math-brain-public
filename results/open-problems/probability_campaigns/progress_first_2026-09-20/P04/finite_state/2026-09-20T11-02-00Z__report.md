## 2. New one-dimensional theorem: a 3-state stationary factor of iid determined by its own tail

The key point is that the global odometer from the preceding run can be eliminated entirely if the hierarchy is generated by rare *self-marked* long checks.

All arithmetic in check bits is over `F_2`.

### Theorem 2.1

There exists a nondegenerate strictly stationary 3-state process

`X=(X_n)_(n in Z)`

such that, for every finite `E subset Z`,

`H(X_E | X_(E^c)) = 0`.

In particular every coordinate of `X` is measurable with respect to the full double-tail sigma-field. Moreover `X` is a measurable shift-equivariant factor of an iid Bernoulli process, and hence is mixing in the ergodic-theoretic sense.

This theorem does **not** assert one-dependence in one dimension. Bradley explicitly notes that his Theorem 1 fails for `d=1`. The point here is different: finite alphabet + strict stationarity + exact own-tail reconstruction can be achieved by a phase-free mixing factor; the remaining difficulty is the exact separated-halfspace independence.

### 2.1 Definition of the process

Let

`W=(W_n)_(n in Z)`

be iid Bernoulli(1/2) bits.

Whenever `W_n=0`, define the distance to the next zero on the right by

`G_n := min{ g>=1 : W_(n+g)=0 }`.

Almost surely `G_n<infinity`. Fix the expansion base

`A:=16`

and put

`S_n := A^(G_n)`.

For a zero site `n`, define the length-`3S_n` interval

`I_n := {n,n+1,...,n+3S_n-1}`

and the cyclic shift by one third of that interval,

`T_n(x) := n + ((x-n+S_n) mod (3S_n)),   x in I_n`.

Define the quadratic check

`Q_n(W) := XOR_(x in I_n) [ W_x W_(T_n x) ]`.

Finally set

`X_n := (W_n,Z_n)`,

where

`Z_n := Q_n(W)` if `W_n=0`,

and

`Z_n := 0` if `W_n=1`.

Since `(W_n,Z_n)` can only be `(1,0)`, `(0,0)`, or `(0,1)`, the alphabet has exactly three possible symbols (some check value occurs with positive probability, while nondegeneracy already follows from the visible fair bit `W_n`).

The rule is measurable and commutes with every integer shift. Therefore the law of `X` is strictly stationary. Since `X` is a measurable factor of the iid Bernoulli shift, ordinary ergodic-theoretic mixing passes to `X`.

The rest of the proof is the own-tail statement.

## 3. Infinitely many safe remote checks for any fixed finite erasure

Fix a finite nonempty set `E subset Z`. Let

`a=min E`, `b=max E`, `D=b-a`.

We need infinitely many check sites far to the left whose complete *marker geometry* is visible outside `E`, but whose check intervals reach through `E`.

For large integers `j`, define

`n_j := - floor(j^(3/2))`

and

`g_j := ceil((1/2) log_2 j)`.

Let `A_j` be the finite-pattern event

`W_(n_j)=0`,

`W_(n_j+1)=...=W_(n_j+g_j-1)=1`,

`W_(n_j+g_j)=0`.

Then on `A_j`,

`G_(n_j)=g_j`

and

`S_(n_j)=16^(g_j)`.

For all sufficiently large `j`, the pattern intervals

`[n_j,n_j+g_j]`

are pairwise disjoint, because successive values of `floor(j^(3/2))` separate by order `sqrt(j)` while `g_j=O(log j)`. Hence the events `A_j` are independent from some index onward.

Also

`P(A_j)=2^(-(g_j+1))`.

Because `g_j=ceil((1/2)log_2 j)`, there are positive constants `c,C` such that for all large `j`,

`c j^(-1/2) <= P(A_j) <= C j^(-1/2)`.

Thus

`sum_j P(A_j)=infinity`.

By the second Borel--Cantelli lemma, almost surely infinitely many `A_j` occur.

On `A_j`, write

`S_j := 16^(g_j)`.

Since `S_j` grows on the order of `j^2` whereas `|n_j|` grows on the order of `j^(3/2)`, for every fixed finite `E`, all sufficiently large successful `j` satisfy

`n_j+g_j < a`

and

`E subset [n_j,n_j+S_j-1]`.

Thus the two zeros certifying `G_(n_j)=g_j` and all intervening marker bits are strictly outside `E`, while `E` lies in the first third of the check interval `I_(n_j)`.

Because `g_j -> infinity`, from the infinitely many successful `j` one may choose a subsequence for which `g_j` is strictly increasing. Along that subsequence the corresponding scales grow by at least the factor `16` at every step.

This is the self-marked substitute for the preceding report's global `K`-adic phase: arbitrarily large useful scales are visible from local finite marker words situated far from the erasure, and no compact global origin variable is present.

## 4. Every wrong finite filling is killed by independent remote check differences

Suppose the true word on `E` is `w_E` and consider any other candidate `w'_E != w_E`, keeping all bits on `E^c` fixed. Let

`Delta := {x in E : w'_x != w_x}`.

Then `Delta` is nonempty and finite.

Take a successful remote check `n=n_j` from Section 3 with scale `S=S_j` so large that

`E subset [n,n+S-1]`

and

`S>D`.

On `E`, write the candidate perturbation as `delta_x=1_Delta(x)`. Since `E` lies in the first third of `I_n`, for every `x in Delta`,

`T_n x = x+S`,

`T_n^(-1)x = x+2S`.

The three sets

`Delta`, `Delta+S`, `Delta+2S`

are pairwise disjoint, and the latter two lie in `E^c`.

Expand the quadratic check after the perturbation:

`Q_n(w+delta) XOR Q_n(w)`

`= XOR_(x in I_n) [ delta_x W_(T_n x) XOR W_x delta_(T_n x) XOR delta_x delta_(T_n x) ]`.

The last term is zero because no `x` and `T_n x` both lie in `Delta`. Reindexing the second linear term gives

`Q_n(w') XOR Q_n(w)`

`= XOR_(x in Delta) [ W_(T_n x) XOR W_(T_n^(-1)x) ]`

`= XOR_(x in Delta) [ W_(x+S) XOR W_(x+2S) ].`                 (4.1)

The `2|Delta|` bits on the right are distinct iid fair bits outside `E`. Therefore, conditional on the true erased word and on the remote marker event `A_j`, the check difference in (4.1) is itself a fair bit.

Now use the strictly increasing-`g_j` successful subsequence. Consecutive selected scales differ by at least a factor `16`. For all sufficiently large selected scales, the seed sets

`(Delta+S) union (Delta+2S)`

are pairwise disjoint from one scale to the next. They are also disjoint from all of the finite marker blocks `[n_j,n_j+g_j]`, which lie far to the left of `E`, whereas the seed sets lie far to its right.

Consequently the check-difference bits in (4.1) are independent fair bits along an infinite subsequence of safe remote checks. A fixed wrong candidate filling therefore passes every one of those checks with probability zero.

There are only `2^|E|-1` wrong binary fillings. Taking the finite union over them yields, almost surely,

`W_E is uniquely determined by ( W_(E^c), (Z_n)_(n in E^c) ).`          (4.2)

But the right-hand side is exactly measurable from `X_(E^c)`, because the first component of every exterior symbol reveals `W_n` and each exterior zero site reveals its stored check bit.

Once `W_E` is recovered, the entire Bernoulli configuration `W` is known. Therefore for every erased site `x in E` one can recompute `G_x`, `S_x`, and (when `W_x=0`) `Q_x(W)`, hence `Z_x`. Thus

`H(X_E | X_(E^c))=0`.                                                   (4.3)

The candidate set is finite and the consistency tests are countable, so the unique compatible filling defines a measurable decoder. Since the family of finite subsets of `Z` is countable, the probability-one sets in (4.3) may be intersected over all finite `E`. This proves Theorem 2.1.

## 5. Multidimensional corollary: exact Bradley independence in all but one direction

The one-dimensional construction can be placed independently on parallel coordinate lines.

Fix `d>=2`. Write a site as

`k=(n,y)`,

where `n in Z` is the first coordinate and `y in Z^(d-1)` collects the remaining coordinates. For each transverse line `y`, take an independent copy

`X^(y)=(X_n^(y))_(n in Z)`

of the 3-state process from Theorem 2.1, and define

`Y_(n,y):=X_n^(y)`.

### Corollary 5.1

The field `Y` has the following properties.

1. `Y` is nondegenerate, 3-state and strictly stationary under the full `Z^d` action.
2. `Y` is determined by its own full spatial tail; indeed for every finite `F subset Z^d`,

   `H(Y_F | Y_(F^c))=0`.
3. For each transverse coordinate `i in {2,...,d}` and every integer `m`, the source-exact halfspace sigma-fields

   `sigma(Y_k : k_i <= m)`

   and

   `sigma(Y_k : k_i >= m+2)`

   are independent.

Thus `Y` satisfies Bradley's exact halfspace condition in `d-1` of the `d` coordinate directions and fails to settle the problem only in the direction parallel to the remote-check lines.

### Proof

Strict stationarity in the first coordinate follows from stationarity of each line process. A transverse translation simply permutes an iid family of identically distributed lines, so the full field is strictly stationary.

If `F` is finite, it intersects only finitely many lines. On each affected line, Theorem 2.1 reconstructs the erased symbols on that line from the symbols outside the finite line-section of `F`. Those linewise exterior symbols are contained in the global exterior `F^c`. Taking the finite product of the linewise decoders gives the own-tail identity.

For `i>=2`, each entire first-coordinate line has a fixed `i`-th transverse coordinate. The halfspace `k_i<=m` is generated by one family of lines and the halfspace `k_i>=m+2` by a disjoint family of lines. Those line processes are independent by construction. Hence the two full sigma-fields are independent. In fact this transverse independence is stronger than required.

No corresponding claim is made for the first coordinate. The long checks are oriented along that coordinate, and Bradley's 1994 paper explicitly notes that the full one-dimensional conjunction cannot hold. Therefore Corollary 5.1 is a sharp partial construction, not a disguised full solution.

## 6. What this changes relative to the previous P04 picture

The previous report's low-rate helper construction used a `K`-adic odometer name to tell the decoder where checks of each scale lived. That gave exact finite-erasure correction but immediately introduced a nonmixing global phase. It was therefore natural to suspect that finite-state exact tail recovery itself might force such a globally visible hierarchy.

Theorem 2.1 disproves that suspicion.

The hierarchy here has no global origin, no finite-index phase, no odometer, and no external marker process. Useful scales are generated by ordinary finite rare words in an iid Bernoulli source. The resulting finite-state process is itself a Bernoulli factor and hence mixing as a `Z`-action, yet every finite erasure is exactly reconstructible from the process's own exterior.

So the obstruction in Bradley Question 10 is now more specific:

> **the hard constraint is not stationarity, finite alphabet, mixing, or own-tail reconstruction separately; it is arranging the remote redundancy so that it is simultaneously invisible across every one-layer-separated coordinate cut.**

The line-product corollary shows that one can satisfy all of the target properties except one directional family of halfspace-independence constraints using only three symbols.

This also supplies a useful sanity check on several earlier obstruction attempts. Any argument purporting to deduce impossibility merely from finite alphabet + stationarity + mixing + own-tail determinism is false: Theorem 2.1 already has all four properties in one dimension (without the Bradley cut condition).

## 7. Why the bad direction is nontrivial and what a full positive construction would need

For a fixed source cut in coordinate `i`, the omitted layer `k_i=m+1` can act as a one-time-pad reservoir. If a check stored on the left reaches into the right halfspace, exact independence can still survive if the check contains enough fresh randomness from that omitted layer to mask every cross-cut degree of freedom. In `d=1` the omitted layer is one site, which is far too small for an unbounded hierarchy. In `d>=2` it is an infinite `(d-1)`-dimensional hyperplane, so this masking mechanism becomes genuinely plausible.

The new construction suggests a dimension-specific route rather than another odometer hierarchy.

Let active checks have random radius `R` with heavy tail

`P(R>=r) approx r^(-alpha)`

for some

`1 < alpha <= d`.

Then two competing quantities separate in `d>=2`:

- the expected number of cut crossings contributed per unit `(d-1)`-area is controlled by `E R`, which is finite when `alpha>1`;
- the expected number of remote radius-`R` checks whose region can cover a fixed target behaves like

  `sum_r r^(d-1) P(R>=r)`,

  which diverges when `alpha<=d`.

Thus, unlike the one-dimensional line construction, one can plausibly have **infinitely many remote reconstruction opportunities per target while maintaining finite demand density on every gap hyperplane**.

That quantitative window `(1,d]` is the new design regime.

### 7.1 Concrete next construction target: subcritical gap-layer pad matching

A possible next architecture is:

1. choose a sparse stationary iid family of active check anchors, each with an independent/self-marked heavy-tailed radius in the window above;
2. orient every check into the positive orthant, so for a given coordinate cut only left-side checks can reach across it;
3. for every check/cut crossing, assign a distinct payload bit in the single omitted hyperplane as a private one-time pad;
4. choose the anchor intensity so that the crossing-demand intensity on each gap hyperplane is strictly below one;
5. assign demands to pad sites by a stationary subcritical queue/matching along one transverse coordinate;
6. use nonlinear quadratic or randomized permutation-support checks so that every nonempty finite difference is detected by infinitely many independent remote checks.

The matching/queue step is attractive because a finite perturbation of the demand process in a strictly subcritical stationary queue should affect only a finite busy region almost surely, potentially preserving own-tail decodability without introducing a global phase. Exact implementation and proof are still missing. In particular one must prove simultaneously that the matching is recoverable from the field's exterior, that private pads stay private for every coordinate cut, and that finite candidate changes cannot cause an infinite rematching avalanche.

This is **CONJECTURAL design work**, not a theorem of this report.

A related finite combinatorial test is to use check supports that are permutation graphs inside large boxes: one support point per coordinate line gives a natural candidate one-time pad on each crossed gap layer. The central finite obstruction to test is whether many such checks can be packed with uniformly bounded cross-cut pad congestion while still giving enough independent parity tests to separate every nonempty finite error pattern.

Do not return to a global dyadic/`K`-adic phase. The next useful attack is the `d=2` binary/finite-alphabet **subcritical pad-matching gadget**:
