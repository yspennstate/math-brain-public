# P04 / D0038 — vector-algebraic no-go and finite-cylinder tail evaporation

Date: 2026-09-20 UTC.

## 1. Exact source target and continuity

Source: Richard C. Bradley, *Basic Properties of Strong Mixing Conditions. A Survey and Some Open Questions*, Probability Surveys 2 (2005), Section 8, Question 10, printed pp. 135–136, arXiv:math/0511078.

For a given `d>=2`, Bradley asks whether there exists a nondegenerate strictly stationary finite-state, even two-state if possible, random field `X=(X_k)_{k in Z^d}` with both:

1. **lattice-halfspace one-dependence**: for every coordinate `i` and every integer `m`,

   `sigma(X_k : k_i <= m)` is independent of `sigma(X_k : k_i >= m+2)`;

2. **own-tail measurability**: every coordinate is measurable modulo null sets with respect to

   `T_X = intersection_{S finite} sigma(X_k : k notin S)`.

Bradley's 1994 real-valued stationary example has both properties. Its preliminary construction is binary but nonstationary; stationarity is obtained by packing countably many translated independent binary layers into one nonatomic real coordinate. That is background, not a finite-state solution.

I re-read the owner directive and registry for the 20 September progress-first campaign, the canonical D0038 claim, and the latest D0038 terminal handoff from 17 September. The new work below deliberately does not repeat the exhausted routes. In particular, the old D0038 campaign already proved:

- the historical implication `tail deterministic => zero entropy rate` is false;
- Bradley independence gives a sparse iid sublattice and hence positive entropy density for any nondegenerate finite-state candidate;
- scalar `F_p` Haar algebraic shifts cannot solve the problem;
- finite-copy-footprint versions of Bradley's independent-layer stationarization cannot solve it;
- fixed-radius / efficient FFIID mechanisms do not provide tail determinism;
- one-scale entropy inequalities alone do not kill multidirectional secret-sharing synergy.

The specific gap left by the scalar algebraic theorem was important: a finite alphabet may be a **vector** alphabet, and proper vector-valued linear shifts can in fact be one-dependent. For example, from iid `U_k in F_p`, the vector process `X_k=(U_k,U_{k+e_1},...,U_{k+e_d})` is a proper shift-invariant linear process and satisfies the required separated-halfspace independence. Thus the scalar theorem did not automatically cover finite-dimensional linear/cocycle codings.

The main result of this run closes that gap for **all finite-dimensional `F_p`-linear Haar algebraic fields**, without assuming a principal ideal, a scalar alphabet, a finite-type presentation, or a finite coding radius.

## 3. Main theorem: no finite-dimensional `F_p`-linear Haar solution

### Theorem 3.1 — vector algebraic no-go

Let `p` be prime, `q>=1`, and

`V <= (F_p^q)^(Z^d)`

be a closed, shift-invariant `F_p`-linear subgroup. Let `mu_V` be Haar probability measure on `V`, and let `X` be the coordinate field under `mu_V`.

If `X` is lattice-halfspace one-dependent in Bradley's exact sense and is measurable modulo null sets with respect to its own spatial tail, then `V={0}`. In particular, **no nondegenerate finite-dimensional `F_p`-linear algebraic/Haar random field solves Bradley Question 10**.

This strictly extends the earlier D0038 scalar theorem (`q=1`): vector alphabets and arbitrary submodule presentations are now included.

The proof separates into two structural lemmas with opposite module-theoretic conclusions:

- tail determinism forces the dual module to be **torsion**;
- Bradley halfspace one-dependence forces the dual module to be **torsion-free**.

Hence the dual module is zero.

### 3.2 Algebraic setup

Put

`R = F_p[u_1^{+-1},...,u_d^{+-1}]`,

the Laurent polynomial ring, and let `K=Frac(R)`.

The continuous character group of the full shift `(F_p^q)^(Z^d)` is `R^q`: a Laurent vector

`g=(g_1,...,g_q)`,

with `g_j=sum_a c_{j,a} u^a`, defines the character

`chi_g(x)=exp(2 pi i / p * sum_{j,a} c_{j,a} x_{a,j})`.

Let

`N = {g in R^q : chi_g is identically 1 on V}`.

Then `N` is an `R`-submodule and

`M := dual(V) ~= R^q / N`

as an `R`-module. Since `R` is Noetherian, `N` is finitely generated.

We use `rank_R M := dim_K(M tensor_R K)`.

## 4. Tail determinism forces `M` to be torsion

### Lemma 4.1 — no finite-support group element

If the Haar field on `V` is tail deterministic, then `V` contains no nonzero configuration of finite support.

#### Proof

Assume `0 != h in V` has finite support `S`. Choose a coordinate `(a,j)` with `h_{a,j} != 0`.

Let `X~mu_V`. Translation on the compact group by `h`, namely `tau_h(x)=x+h`, preserves Haar measure. Since `X_{a,j}` is measurable modulo null sets with respect to the tail, in particular it is measurable modulo null sets with respect to `sigma(X_k:k notin S)`. Hence there is a measurable function `Phi` of the exterior coordinates such that

`X_{a,j}=Phi(X_{S^c})` almost surely.

By Haar invariance the same identity holds almost surely after replacing `X` by `X+h`. But `(X+h)_{S^c}=X_{S^c}`, so

`X_{a,j}+h_{a,j} = Phi((X+h)_{S^c}) = Phi(X_{S^c}) = X_{a,j}`

almost surely, contradicting `h_{a,j} != 0` in `F_p`.

Therefore no nonzero finite-support element belongs to `V`. QED.

### Lemma 4.2 — positive module rank creates a finite-support configuration

If `rank_R M>0`, then `V` contains a nonzero finite-support configuration.

#### Proof

Choose finite `R`-module generators `n^(1),...,n^(s)` of `N`, and place them as the rows of an `s x q` Laurent-polynomial matrix `A(u)`.

The quotient exact sequence

`N -> R^q -> M -> 0`

shows

`rank_K A = rank_R N = q-rank_R M < q`.

After applying the usual Laurent involution `u_i -> u_i^{-1}` if required by the character/convolution convention, the same rank inequality holds. Therefore the homogeneous system over `K`

`A^dagger(u) H(u)=0`

has a nonzero vector solution `H in K^q`. Clearing denominators gives a nonzero `H in R^q` satisfying the same equations.

Interpret the finitely many coefficients of `H` as a finite-support configuration `h in (F_p^q)^(Z^d)`. The equations `A^dagger H=0` say that every generator of the annihilator module vanishes on every translate of `h`; hence every element of `N` does. By Pontryagin duality, `h in N^perp=V`.

Thus `V` contains a nonzero finite-support element. QED.

### Corollary 4.3 — tail determinism implies torsion

By Lemma 4.1, tail determinism forbids the conclusion of Lemma 4.2. Hence

`rank_R M=0`.

For a finitely generated module over the domain `R`, rank zero is equivalent to being torsion: for every `m in M` there exists `0 != f in R` with `f m=0`.

Therefore

`tail determinism => M is a torsion R-module.`

This is the finite-dimensional linear-algebraic form of the intuitive fact that exact recovery from the complement of every finite hole requires global algebraic constraints; a positive free module component would create a finitely supported degree of freedom.

## 5. Bradley halfspace one-dependence forces `M` torsion-free

### Lemma 5.1 — a torsion character violates a separated halfspace cut

Suppose the Haar coordinate field on `V` is lattice-halfspace one-dependent. Then `M` has no nonzero torsion element.

#### Proof

Assume for contradiction that `0 != m in M` is torsion. Choose a nonzero Laurent polynomial `f in R` with

`f m=0`

having the **minimum possible number of monomials** among all nonzero annihilators of this fixed `m`.

Because every Laurent monomial is a unit in `R`, `f` cannot consist of a single monomial: a monomial annihilator would imply `m=0`. Thus `supp(f)` contains at least two exponent vectors. Choose a coordinate direction `i` on which two exponents differ.

Choose an integer threshold `t` strictly between two consecutive occupied `i`-coordinate levels of `supp(f)`, and split

`f = L + Rr`

where `L` contains the monomials with exponent coordinate `a_i <= t` and `Rr` the remaining monomials. Both pieces are nonzero and contain strictly fewer monomials than `f`.

For every `n>=1`, characteristic `p` gives

`f^(p^n) = L^(p^n) + Rr^(p^n)`

with exponent vectors dilated by `p^n`, and

`f^(p^n) m=0`.

Minimality of the monomial support of `f` implies

`L^(p^n) m != 0` and `Rr^(p^n) m != 0`.

Indeed, if `L^(p^n) m=0`, then `L^(p^n)` would be a nonzero annihilator of `m` with fewer monomials than `f`; similarly for `Rr^(p^n)`.

Now choose a finite Laurent-vector representative `g in R^q` of the class `m in M`. Let `w_i` be the width of the `i`th coordinates appearing in `supp(g)`.

The representative `L^(p^n) g` of `L^(p^n)m` is supported in translates whose largest `i`-coordinate is at most

`p^n t_L + max_i supp(g)`,

where `t_L` is the largest `i`-coordinate occurring in `supp(L)`. Likewise `Rr^(p^n)g` is supported at `i`-coordinates at least

`p^n t_R + min_i supp(g)`,

where `t_R>t_L` is the smallest occupied `i`-coordinate of `supp(Rr)`.

Hence the gap between those two supports is at least

`p^n (t_R-t_L) - w_i`.

Choose `n` so large that this is at least `2`. After an overall lattice translation, one representative is supported in a Bradley left halfspace `{k_i<=m_0}` and the other in the corresponding right halfspace `{k_i>=m_0+2}`.

But in `M`,

`L^(p^n)m = - Rr^(p^n)m != 0`.

Thus the same **nontrivial character of `V`** is measurable with respect to each of the two separated halfspace sigma-fields. Two independent sigma-fields have only trivial common measurable random variables modulo null sets. A nontrivial compact-group character is not almost surely constant under Haar measure. Contradiction.

Therefore `M` has no nonzero torsion element. QED.

### Corollary 5.2

`Bradley halfspace one-dependence => M is torsion-free.`

The key new point relative to the previous scalar proof is that the Frobenius dilation is applied to a **scalar annihilator of an arbitrary module element `m`**, not to a vector relation. This avoids the obstruction that componentwise Frobenius need not preserve a general submodule presentation.

## 6. Proof of Theorem 3.1

If both source properties hold, Corollary 4.3 says `M` is torsion and Corollary 5.2 says `M` is torsion-free. Hence `M=0`.

By Pontryagin duality, `M=dual(V)=0` implies `V` is the trivial compact group. The Haar field is therefore degenerate.

This contradicts the required nondegeneracy and proves Theorem 3.1. QED.

## 7. Scope of the theorem

Theorem 3.1 rules out all of the following in one stroke:

- scalar and vector alphabets `F_p^q` for arbitrary finite `q`;
- principal and non-principal algebraic subshifts;
- finite-type and non-finite-type closed shift-invariant linear subgroups;
- any Haar law on such a subgroup, regardless of whether it is presented as a cellular automaton, convolutional code, cocycle kernel, vector-valued parity system, or linear multidirectional secret-sharing code.

It does **not** rule out:

- nonlinear finite-state subshifts/measures;
- random or hierarchical constraint systems whose constraint geometry is itself random and not recoverable as a fixed linear submodule;
- non-Haar measures on finite-state symbolic systems;
- nonlinear cocycles over a stationary hidden hierarchy.

Accordingly the full Bradley metric stays zero.

## 8. Secondary theorem: fixed-width cylinder tails carry asymptotically zero information

The handoff proposed a stationary dyadic / inverse-limit hierarchy. Before attempting that construction, there is a clean geometric obstruction worth recording.

### Theorem 8.1 — finite-cylinder tail evaporation

Let `X` be any strictly stationary random field satisfying Bradley lattice-halfspace one-dependence; no tail determinism or linearity is assumed. Fix a coordinate direction, say the first, and a finite transverse set `F subset Z^(d-1)`. Define the strip process

`Y_n = (X_(n,u) : u in F)`.

Then `Y=(Y_n)_(n in Z)` is a strictly stationary 1-dependent sequence. Consequently its double tail

`T_F = intersection_{N>=1} sigma(Y_n : |n|>=N)`

is trivial.

If `Z` is any finite-valued random variable measurable with respect to the field, then

`I(Z ; sigma(Y_n:|n|>=N)) -> 0`.

In particular, if `Z=X_0` is nondegenerate finite-state, no decoder that is restricted to the far tail of one fixed-width cylinder can recover `X_0` with vanishing error.

#### Proof

Strict stationarity of `X` gives strict stationarity of `Y` under translation in the first coordinate.

For every integer `m`,

`sigma(Y_n:n<=m) subset sigma(X_k:k_1<=m)`

and

`sigma(Y_n:n>=m+2) subset sigma(X_k:k_1>=m+2)`.

Bradley's defining independence therefore gives

`sigma(Y_n:n<=m) independent of sigma(Y_n:n>=m+2)`.

So `Y` is exactly 1-dependent. In particular its absolute-regularity coefficient satisfies `beta_Y(n)=0` for every `n>=2`. A standard theorem for stationary sequences (also stated in Bradley's 2005 survey, Section 2.5) says absolute regularity implies a trivial double tail. Hence `T_F` is trivial.

Put

`D_N = sigma(Y_n:|n|>=N)`.

Then `D_N` decreases to `T_F`. For each value `a` of the finite-valued `Z`, reverse martingale convergence gives

`P(Z=a | D_N) -> P(Z=a | T_F)=P(Z=a)`

almost surely and in `L^1`.

Since the alphabet of `Z` is finite, conditional entropy is continuous and bounded on the probability simplex, so

`H(Z|D_N) -> H(Z)`

and therefore

`I(Z;D_N)=H(Z)-H(Z|D_N) -> 0`.

For the decoder statement, the optimal `D_N`-measurable prediction success is

`E max_a P(Z=a|D_N)`,

which converges to `max_a P(Z=a)<1` when `Z` is nondegenerate. Thus asymptotically exact reconstruction from a fixed-width cylinder is impossible. QED.

### Consequence for the positive program

Any source-valid tail decoder must use **transverse width escaping every fixed finite cross-section**. The old handoff's proposed random dyadic hierarchy therefore cannot route the information for a site along a bounded-width ancestral corridor. Its reconstruction shells must genuinely widen with scale.

This is not a finite-state impossibility theorem, because Bradley's real-valued example also obeys this geometric requirement. It is a concrete design constraint for any future finite-alphabet inverse-limit/cocycle construction.

## 11. Next attack

The strongest remaining positive route is no longer a deterministic algebraic subshift. The next attempt should build a **nonlinear stationary random hierarchy** with these explicit tests:

1. a finite output alphabet;
2. a stationary random multiscale geometry (for example a 2-adic/dyadic hierarchy) whose phase is not detectable from either member of a Bradley-separated halfspace pair;
3. conditional or direct exact independence of the two halfspace sigma-fields after the hierarchy is averaged out;
4. recursive secret-sharing constraints whose reconstruction support has transverse width `w(r)->infinity`, as forced by Theorem 8.1;
5. for every finite erased set, a larger-scale relation that recovers each erased symbol from the exterior;
6. positive entropy density, consistent with the earlier sparse-iid lemma.

A useful concrete construction target is a **cut-blind widening annular code**: at scale `2^n`, encode a lower-scale secret into several directional shares with fresh pads placed in the intervening slabs, but assign sites to scales through a stationary hierarchy so that each physical site stores only finitely many bits. The exact technical question is whether the hierarchy can be made invisible in the marginal law of every individual coordinate halfspace while remaining jointly recoverable from the full exterior.

If that fails, the next negative route should be nonlinear rather than another linear module: prove that any finite-alphabet stationary field with the source halfspace factorization and zero finite-erasure entropy would force a uniformly bounded-width reconstruction channel on some positive-density set, contradicting Theorem 8.1. At present there is no proof of that implication.
