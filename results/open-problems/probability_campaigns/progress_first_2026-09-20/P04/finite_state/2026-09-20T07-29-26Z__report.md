## 2. The reusable rigidity principle

I first isolate the coupling fact used repeatedly below.

### Lemma 2.1 — same-law finite disagreement is impossible

Let `Y` be a stationary finite-state field that is measurable with respect to its own full tail. Let `(Y,Y')` be **any** coupling with

`Law(Y')=Law(Y)`.

Then

`P(0 < |{k:Y_k!=Y'_k}| < infinity)=0`.                               (2.1)

#### Proof

For each deterministic finite box `B` and each `k`, tail determinism gives a measurable decoder

`psi_(k,B)` such that `Y_k=psi_(k,B)(Y_(B^c))` almost surely.

Because `Y'` has the same marginal law, the same decoder identity holds for `Y'` almost surely. If the disagreement set is nonempty and finite, it is contained in some deterministic box `B_n`. On that event the two exteriors `Y_(B_n^c)` and `Y'_(B_n^c)` agree. Applying the common decoders to the two marginals forces every coordinate to agree, a contradiction. Taking the countable union over `n` proves (2.1). ∎

This lemma is architecture-free. The rest of the run manufactures a finite-disagreement same-law coupling from a **local refresh** of an auxiliary randomizer.

## 3. Finitary coding and a finite-change localization lemma

The next statement is useful beyond bounded-radius block codes.

Let `S=(S_k,k in Z^d)` be any stationary source field, and let `Y` be a translation-equivariant factor. A nonnegative integer-valued random variable `R_k=R_0(T_k S)` is called a **certifying coding radius** when, almost surely, agreement of another source configuration with `S` on the physical box

`B(k,R_k)={j:||j-k||_infinity<=R_k}`

forces the same output at `k`. This is the standard pointwise form of a finitary code. Write

`V_d(r)=|B(0,r)|=(2r+1)^d`.

### Lemma 3.1 — finite source refresh produces finite output disagreement under integrable coding volume

Assume

`E V_d(R_0) < infinity`.                                                (3.1)

Let `(S,S')` be a coupling with the same source marginal law, such that the two source configurations differ only on a deterministic finite set `C subset Z^d`.

Then the output disagreement set

`D={k:Y_k(S)!=Y_k(S')}`

is finite almost surely. More quantitatively,

`E |D| <= |C| E V_d(R_0)`.                                             (3.2)

#### Proof

If `B(k,R_k(S))` misses `C`, then `S` and `S'` agree on the entire certifying coding box for output `k`; therefore `Y_k(S)=Y_k(S')`. Hence

`D subset {k:B(k,R_k(S)) intersection C != empty}`.                    (3.3)

Using the union bound over `c in C`, stationarity, and Tonelli,

`E |D|
 <= sum_(c in C) sum_(k in Z^d) P(c in B(k,R_k))
 = |C| sum_(z in Z^d) P(||z||_infinity <= R_0)
 = |C| E V_d(R_0)`.                                                     (3.4)

The right side is finite, so `|D|<infinity` almost surely. ∎

### Corollary 3.2 — local same-law source moves cannot be visible to a self-tail code

Under the hypotheses of Lemma 3.1, if `Y` is own-tail deterministic then every same-law source coupling supported on a deterministic finite source set must satisfy

`Y(S)=Y(S')` almost surely.                                             (3.5)

Indeed, otherwise `D` is finite almost surely and nonempty with positive probability, contradicting Lemma 2.1.

This is the first genuinely new enlargement beyond the preceding finite-window report: the output coding radius may be unbounded, provided its expected physical coding volume is finite.

## 4. Local-refresh auxiliary fields

I now formalize the class of randomized marker constructions excluded by the new lemma.

Let `V` denote Bradley's full stationary parent field in vector form, built from the countably many independent binary layers. Let `U=(U_k,k in Z^d)` be an independent stationary auxiliary field taking values in a standard Borel state space.

For a finite set `C` containing the origin, let `K_0` be a Markov kernel on auxiliary configurations satisfying:

1. **locality:** a `K_0` update changes only the coordinates in `C`;
2. **law preservation:** if `U~nu`, then `U'~K_0(U,.)` also has law `nu`.

Let `K_t` be the translated update acting on `C+t`.

Call `nu` **locally refresh-ergodic** for this update family if every bounded measurable function `g(U)` satisfying

`g(U')=g(U)` almost surely under every translated update coupling `U'~K_t(U,.)`   (4.1)

is constant `nu`-almost surely.

The iid case is the main example: take `C={0}` and let `K_t` replace `U_t` by an independent fresh sample. Invariance under all such single-site resamplings makes `g` measurable with respect to the iid tail, hence constant by Kolmogorov's zero-one law.

## 5. Main theorem — locally refreshable randomness cannot help

### Theorem 5.1 — auxiliary-refresh obstruction for integrable-volume finitary factors

Let `V` be Bradley's stationary parent, let `U` be independent of `V`, and assume the law of `U` is locally refresh-ergodic as in Section 4.

Let `Y` be a finite-state translation-equivariant finitary factor of `(V,U)` with a certifying coding radius satisfying

`E V_d(R_0)<infinity`.                                                  (5.1)

If `Y` is measurable with respect to its own full spatial tail, then **every translated local refresh of `U` leaves the whole output field unchanged almost surely**.

Consequently each output coordinate is, modulo null sets, measurable with respect to the Bradley parent `V` alone. In particular, no such self-tail field can genuinely use the locally refreshable auxiliary randomness.

#### Proof

Fix `t`. Couple `(V,U)` with `(V,U')` by leaving `V` fixed and applying one `K_t` update to `U`.

The source marginal is unchanged: `V` is untouched, `U'` again has law `nu`, and independence of `V` and `U'` is preserved because the kernel uses only `U`. The two source configurations differ only in the deterministic finite physical set `C+t`.

By Lemma 3.1, the two output fields `Y,Y'` differ at only finitely many sites almost surely. They also have the same marginal law. If the local refresh changed the output with positive probability, then with positive probability this finite disagreement set would be nonempty, contradicting Lemma 2.1. Therefore

`Y(V,U')=Y(V,U)` almost surely                                           (5.2)

for every translated local refresh.

There are only countably many translates. Disintegrate (5.2) over `V`. For almost every parent realization `v`, the map

`u -> Y_0(v,u)`

is invariant, in the sense of (4.1), under every translated auxiliary update. Local refresh ergodicity therefore makes this map constant `nu`-almost surely. Hence there exists a measurable `G_0` such that

`Y_0=G_0(V)` almost surely.                                              (5.3)

Translation equivariance gives the same conclusion for every `Y_k`. Thus `Y` is an observed factor of `V` alone; the auxiliary marker/randomizer contributes no information to the output law. ∎

### Important scope point

The theorem does **not** yet exclude every integrable-volume finitary factor of Bradley's parent itself. It proves a reduction: if an attempted construction augments Bradley with an iid/local-refreshable hierarchy, then under (5.1) any successful self-tail output must in fact ignore that hierarchy.

The pure-`V` unbounded-radius case is still open inside this architecture.

## 6. Randomized finite-range channels are completely excluded

The preceding theorem becomes a full no-go for the most natural randomized local modification of Bradley's construction.

### Corollary 6.1 — no finite-range stochastic channel from Bradley's stationary field

Let `U_k` be iid auxiliary randomizers, independent of Bradley's parent `V`. Fix a deterministic finite physical window `F`, a finite output alphabet `A`, and an arbitrary measurable local rule

`f : (state(V) x state(U))^F -> A`.

Define

`Y_k=f((V_(k+s),U_(k+s))_(s in F))`.                                   (6.1)

If `Y` is nondegenerate, then it is **not** own-tail deterministic.

#### Proof

The deterministic radius `r=max_(s in F)||s||_infinity` satisfies (5.1). If `Y` were tail deterministic, Theorem 5.1 would imply that it ignores `U` modulo null sets. Since the rule uses only the fixed physical window `F`, this means there is a measurable finite-window rule `g` with

`Y_k=g((V_(k+s))_(s in F))` almost surely.                              (6.2)

But the 07:23 theorem proves that every nonconstant finite-valued deterministic finite-window factor of Bradley's full parent fails own-tail determinism. Contradiction. ∎

Equivalently: replacing Bradley's nonatomic site encoding by an arbitrary **finite-state randomized local channel**, even with continuous iid random seeds, does not solve Question 10.

This closes a loophole not covered by the deterministic finite-window theorem. Randomized local dithering, random local permutations, finite-radius random marker choices, and finite-radius stochastic quantizers all fall under Corollary 6.1.

## 7. A broader marker corollary

### Corollary 7.1 — finite-range iid-generated marker hierarchies do not rescue finite-radius coding

Suppose a stationary marker field `M` is itself a deterministic finite-window factor of an iid field `U`, and the proposed finite-state output is a deterministic finite-window factor of `(V,M)`. Then the composition is a deterministic finite-window factor of `(V,U)`, so Corollary 6.1 applies.

Thus the positive route left by the earlier global-phase obstruction cannot be repaired merely by replacing a global dyadic/2-adic phase by a **finite-range mixing marker process**. If a marker hierarchy is to help, it must use genuinely unbounded spatial coding or some auxiliary source that cannot be locally refreshed without crossing infinitely many observed dependencies.

This is precisely the direction suggested by the old handoff: the hierarchy must be both cut-blind and globally nonlocal. The present theorem makes the latter requirement exact for the randomized-local architecture.

## 8. Why the integrable-volume threshold appears

It is important not to overclaim the finitary extension.

A finitary code only says that each individual output reads finitely many source sites almost surely. It does **not** say that one source site is read by only finitely many outputs. For a stationary certifying radius,

`N_0=#{k:0 in B(k,R_k)}`

has expectation

`E N_0 = E V_d(R_0)`.                                                   (8.1)

Thus (5.1) makes the reverse coding cone finite almost surely. Without (5.1), a single local source refresh can be visible to infinitely many outputs, and Lemma 2.1 no longer gives a contradiction.

This is not a technical fiction. For an iid auxiliary radius field with a sufficiently heavy tail, every radius is finite almost surely while a fixed source site can lie in infinitely many random coding balls. Therefore `R_0<infinity` almost surely is strictly weaker than finite expected coding volume.

The theorem should therefore be read as:

> **self-tail determinism forces any genuinely useful local randomizer to communicate through an infinite-mean reverse coding architecture.**

That is a new quantitative restriction on the surviving positive constructions.

## 9. Failed attempt to remove the moment condition

I tried to extend Lemma 3.1 to arbitrary almost-surely finite coding radius. The exact obstruction is now clear.

If `E V_d(R_0)=infinity`, then the reverse cone

`{k:0 in B(k,R_k)}`

may be infinite. A source modification supported at one physical site can then affect infinitely many potential output decoders even though each output itself uses a finite window. Hence the same-law coupling generated by a single local refresh need not have finite output disagreement, so own-tail rigidity does not apply directly.

The adaptive parity-ray method from the 07:23 report does not automatically repair this. Its finite-window proof can route a Bradley parity tail through locally nonpivotal vertices because each selected source coordinate has a deterministic finite output neighborhood. For an arbitrary finitary code with infinite reverse cone, one selected source coordinate may be visible at arbitrarily remote output sites. A new argument would have to control **reverse** coding geometry, not merely the forward coding radius at each output.

This is useful failure information rather than a no-change rerun: the missing theorem is now a reverse-cone statement.

## 11. Next mathematical attack

The strongest next target is the pure-parent finitary gap:

> Let `Y` be a finite-state finitary factor of Bradley's full stationary parent `V`, with an almost surely finite unbounded coding radius. Can the adaptive piecewise-Haar rerouting be upgraded so that a thin legal layer perturbation produces only finitely many output disagreements?

The new report identifies the correct quantity to attack: the **reverse coding cone** of a selected parent site. Two concrete routes are now available.

1. **Finite-mean reverse-cone route.** Under `E(2R_0+1)^d<infinity`, each parent site has finite reverse coding cone almost surely. Try to route Bradley's parity branches adaptively outside the union of those finite reverse cones while keeping the routing map Haar-preserving. The main technical issue is making the reverse-cone selection cells invariant under the branch-switch translations.

2. **Moment-free route.** If the reverse cone is infinite, use Bradley halfspace independence to ask whether an infinite reverse cone itself forces a common observable across two separated halfspaces. A theorem of the form “infinite identifiable reverse influence across both sides violates (1.1)” would combine with the present local-refresh dichotomy and could remove the coding-volume hypothesis.

The first route is the closer continuation. It is not yet a proof: the coding radius/reverse cone can change when the Bradley layer is rerouted, and that invariance issue must be resolved rather than assumed.
