## 2. New abstract lemma: measurable homomorphisms from profinite sources to a finite group are automatically finite-coordinate

The key point is that an apparently infinite algebraic code into a discrete finite output cannot actually use infinitely many independent finite-group coordinates if the code is a Borel group homomorphism.

### Lemma 2.1 — automatic finite-coordinate support

Let `I` be countable, let `(G_s)_(s in I)` be finite groups, and let

\[
K:=\prod_{s\in I}G_s
\]

with its product topology. Let `H` be a finite discrete group. If

\[
\phi:K\longrightarrow H
\]

is a Borel measurable group homomorphism, then `phi` is continuous and there exists a finite set `F subset I` such that `phi(x)` depends only on `(x_s)_(s in F)`.

Equivalently, every Borel homomorphism from a countably based profinite product to a finite group factors through a finite coordinate quotient.

### Proof

Let

\[
N:=\ker\phi.
\]

Because `phi` is Borel, `N` is a Borel subgroup of the compact metrizable group `K`. The image `phi(K)` is finite, so `N` has finite index. Hence `K` is a finite union of cosets of `N`.

If `N` were meager, every coset of `N` would be meager, and their finite union would make `K` meager in itself. This contradicts the Baire theorem for the compact Hausdorff metrizable group `K`. Therefore `N` is nonmeager.

A Borel set has the Baire property. Pettis' elementary category theorem says that if a Baire-property subset `A` of a topological group is nonmeager, then `AA^{-1}` contains a neighborhood of the identity. Apply this with `A=N`. Since `N` is a subgroup,

\[
NN^{-1}=N,
\]

so `N` itself contains a neighborhood of the identity. Therefore `N` is open. A homomorphism to a discrete group is continuous exactly when its kernel is open, hence `phi` is continuous.

Now use the product topology. Since `N` is an open neighborhood of the identity, there is a finite set `F subset I` such that the identity cylinder

\[
C_F:=\{x\in K:x_s=e_{G_s}\ \text{for every }s\in F\}
\]

is contained in `N`. If `x,y in K` agree on `F`, then `xy^{-1} in C_F subset N`, and therefore

\[
\phi(x)\phi(y)^{-1}=\phi(xy^{-1})=e_H.
\]

Thus `phi(x)=phi(y)`. Hence `phi` depends only on the finite coordinate set `F`. QED.

### Remarks

1. No commutativity is needed.
2. The same conclusion holds for an affine translate of a homomorphism.
3. The conclusion is stronger than mere approximation by cylinder maps: the dependence is **exactly finite-coordinate**.
4. In inverse-limit language, every Borel homomorphism from a countably based profinite group to a finite discrete group factors through a finite quotient. Thus passing to infinitely many finite algebraic stages does not create a genuinely infinite finite-valued homomorphic observable.

## 3. Equivariant version: every measurable finite-group linear code of a profinite Bernoulli field is finite range

Let `J` be finite or countable and let `(G_j)_(j in J)` be finite groups. Consider the profinite Bernoulli source

\[
\Omega:=\prod_{(u,j)\in\mathbb Z^d\times J}G_j
\]

with product Haar law. Spatial translations act by

\[
(\tau_v\omega)_{u,j}=\omega_{u+v,j}.
\]

Let `H` be a finite group, and suppose

\[
\Phi:\Omega\to H^{\mathbb Z^d}
\]

is Borel measurable, shift-equivariant, and a group homomorphism.

### Theorem 3.1 — automatic locality of equivariant profinite homomorphic codes

There is a finite set

\[
F\subset\mathbb Z^d\times J
\]

and a finite-coordinate homomorphism `f` such that, for every `v in Z^d`,

\[
(\Phi\omega)_v
=f\bigl((\omega_{v+u,j})_{(u,j)\in F}\bigr),
\tag{3.1}
\]

up to the harmless sign convention in the definition of the shift. In particular `Phi` is a finite-range block homomorphism and uses only finitely many source layers at each site.

### Proof

Define the origin coordinate map

\[
\phi(\omega):=(\Phi\omega)_0.
\]

It is a Borel homomorphism from the countable product of finite groups `Omega` to the finite group `H`. Lemma 2.1 gives a finite coordinate set `F` on which `phi` depends. Shift-equivariance then gives the translated formula (3.1) at every site. QED.

This theorem rules out an important attempted escape from the earlier finite-layer obstruction. One might hope to use an *infinite* algebraic convolution or a profinite inverse limit so that one output symbol receives infinitely many tiny algebraic contributions. For a discrete finite output, there is no such Borel homomorphic observable: measurability plus the group law forces the putative infinite series to collapse to finite support.

## 4. Corollary: the homomorphic/affine profinite bundle class cannot be own-tail deterministic

The previous theorem becomes an immediate tail obstruction under the product Haar source.

### Theorem 4.1 — no nondegenerate own-tail finite-state homomorphic factor of profinite Bernoulli

In the setting of Theorem 3.1, let

\[
X:=\Phi(U),
\]

where `U` has product Haar law on `Omega`. If `X` is measurable with respect to its own full spatial tail, then every coordinate of `X` is almost surely constant. Hence no nondegenerate field in this class can solve Bradley Question 10.

The same conclusion holds for affine translates of such homomorphic codes.

### Proof

Let `D subset Z^d` be the finite spatial projection of the finite coordinate set `F` in (3.1), and choose `R<infinity` such that

\[
D\subset[-R,R]^d.
\]

Write `B_n=[-n,n]^d intersect Z^d`. Every output `X_v` is measurable from source columns at spatial sites in `v+D`. If `v notin B_n`, then no site in `v+D` can lie in `B_{n-R}`. Therefore

\[
\sigma(X_v:v\notin B_n)
\subset
\sigma(U_{u,j}:u\notin B_{n-R},\ j\in J).
\tag{4.1}
\]

Intersecting over `n`,

\[
\mathcal T_X
\subset
\bigcap_n\sigma(U_{u,j}:u\notin B_n,\ j\in J)
=:\mathcal T_U.
\tag{4.2}
\]

Regard each spatial column

\[
U_u=(U_{u,j})_{j\in J}
\]

as one random variable. The columns `(U_u)_(u in Z^d)` are independent. Their spatial tail `T_U` is therefore trivial by the Kolmogorov zero-one law. Hence `T_X` is trivial.

If `X` is own-tail deterministic, `X_0` is measurable with respect to the trivial sigma-field `T_X`, so `X_0` is almost surely constant. The same holds at every site (and strict stationarity, if imposed, makes the common degeneracy immediate). Thus no nondegenerate own-tail field occurs. QED.

### Consequence for the surviving infinite-fanout bundle idea

The preceding run's bundle formula was additive at a fixed cut:

\[
C_{a,t}=P_a+\rho_a(R)+\ell_{a,t}(L).
\]

That cut-level identity is valid and useful. But if one tries to realize the **entire stationary field** as a measurable shift-equivariant finite-group homomorphism (or affine homomorphism) of independent finite-group pads/layers, Theorems 3.1--4.1 force the global code back into finite range. It then has trivial own tail and cannot work.

So the following class is now closed:

> **No Borel shift-equivariant finite-group linear/affine convolution, no countably staged profinite homomorphic inverse limit, and no measurable finite-group character with genuinely infinite coordinate support can implement the required Bradley finite-state field when driven by a profinite Bernoulli source.**

This is not the same as the earlier Haar group-shift/SFT obstruction. There the *output support and canonical Haar measure* were algebraic. Here the theorem attacks the **coding map itself**, even when the source has countably many finite layers and the intended code was supposed to be genuinely infinite-range.

It is still only a construction-class obstruction. A nonlinear measurable factor need not be a homomorphism and can have genuinely infinite coding range.

## 5. New no-go theorem for the one-bad-direction construction: independent lines cannot be repaired while remaining independent

The report at `2026-09-20T11-02-00Z__report.md` built a phase-free finite-state one-dimensional process with strong finite-erasure reconstruction, then placed independent copies on lines parallel to one coordinate axis. That gave Bradley's exact halfspace independence in the `d-1` transverse directions and left one bad direction.

A natural hope is to modify the one-dimensional line process until it also satisfies Bradley's condition in the longitudinal direction, while leaving the lines independent. The next theorem shows that this is impossible in principle.

### Lemma 5.1 — a one-dependent sequence has trivial double tail

Let `Y=(Y_n)_(n in Z)` be any random sequence such that for every integer `m`,

\[
\sigma(Y_n:n\le m)
\perp\!\!\!\perp
\sigma(Y_n:n\ge m+2).
\tag{5.1}
\]

Then its double tail

\[
\mathcal D_Y:=\bigcap_{N\ge1}\sigma(Y_n:|n|\ge N)
\tag{5.2}
\]

is trivial.

### Proof

Take `A in D_Y`. Fix `r>=1` and choose `N>=r+2`. Define

\[
\mathcal L:=\sigma(Y_n:n\le -N),\qquad
\mathcal C:=\sigma(Y_n:-r\le n\le r),\qquad
\mathcal R:=\sigma(Y_n:n\ge N).
\]

By (5.1) with `m=-N`, the sigma-field `L` is independent of the entire sigma-field generated by coordinates `n>=-N+2`. Since `N>=r+2`, this latter sigma-field contains `C vee R`. Thus

\[
\mathcal L\perp\!\!\!\perp(\mathcal C\vee\mathcal R).
\tag{5.3}
\]

By (5.1) with `m=r`, `C` is independent of `R`. Together with (5.3), the three sigma-fields `L,C,R` are mutually independent. Hence

\[
\mathcal L\vee\mathcal R
\perp\!\!\!\perp
\mathcal C.
\tag{5.4}
\]

Because `A` belongs to the double tail, `A in L vee R`. Therefore `A` is independent of `C`. This is true for every `r`. As `r` increases, `C` increases to the full sigma-field `sigma(Y_n:n in Z)`. Hence `A` is independent of the entire process sigma-field, and in particular independent of itself. Therefore

\[
P(A)=P(A)^2,
\]

so `P(A)` is `0` or `1`. QED.

This proof is elementary and uses the **full sigma-field independence** in Bradley's definition, not pairwise independence.

### Theorem 5.2 — independent-line Bradley fields cannot be own-tail deterministic

Write

\[
\mathbb Z^d=\mathbb Z e_1\times\mathbb Z^{d-1}.
\]

Suppose a field has the form

\[
X_{(n,z)}=Y^z_n,
\]

where the line processes `(Y^z)_(z in Z^{d-1})` are independent. Assume the field satisfies Bradley's halfspace condition (1.1) in the `e_1` direction. If `X` is own-tail deterministic, then every `X_{(n,z)}` is almost surely constant. In particular no nondegenerate Bradley solution can be obtained by independent parallel-line gluing.

### Proof

Fix one line, say `z=0`, and write `Y=Y^0`. Restricting the two independent global halfspace sigma-fields to this line gives exactly (5.1). Lemma 5.1 therefore makes the row double tail `D_Y` trivial.

Let

\[
\mathcal Z:=\sigma(Y^z_n:z\ne0,\ n\in\mathbb Z)
\]

be the sigma-field of all other lines. By hypothesis `Z` is independent of the entire row-0 process.

For `N>=1`, let

\[
\mathcal A_N:=\sigma(Y_n:|n|>N).
\]

The exterior of the `d`-dimensional box `[-N,N]^d` is contained in

\[
\mathcal A_N\vee\mathcal Z,
\tag{5.5}
\]

because the only exterior variables on row `z=0` are row coordinates with `|n|>N`, while every exterior variable on another row is already in `Z`.

If `X_(0,0)=Y_0` is measurable with respect to the full spatial tail of `X`, then it is measurable with respect to `A_N vee Z` for every `N`. Let `g(Y_0)` be any bounded measurable function. Since `Z` is independent of the whole row process,

\[
E[g(Y_0)\mid\mathcal A_N\vee\mathcal Z]
=E[g(Y_0)\mid\mathcal A_N].
\tag{5.6}
\]

But the left-hand side equals `g(Y_0)` because `Y_0` is `A_N vee Z`-measurable. Therefore `g(Y_0)` is `A_N`-measurable for every `N`. Taking indicator functions of the values of `Y_0` (or a countable determining class for a standard Borel state space) shows that

\[
Y_0\text{ is measurable with respect to }\bigcap_N\mathcal A_N=\mathcal D_Y.
\]

The double tail is trivial by Lemma 5.1, so `Y_0` is almost surely constant. Translation gives the same conclusion for every site. QED.

### Extension

The identical argument applies to independent **finite-cross-section tubes** parallel to `e_1`: regard each longitudinal slice of one tube as a vector-valued symbol. Bradley independence in the longitudinal direction makes that vector sequence one-dependent; Lemma 5.1 still gives a trivial double tail. Thus bounded-width independent slab/tube gluing also cannot repair the missing direction.

### What this changes

The phase-free three-state process from the `11-02` report remains useful as a demonstration that finite alphabet + stationarity + own-tail reconstruction is possible without a global odometer phase. But any full Bradley construction based on that mechanism must couple different lines/tubes in a genuinely multidimensional way. The missing directional condition cannot be imposed row by row while retaining row independence.

## 6. A nonlinear escape hatch: permutation-action bundle masking

The profinite homomorphism theorem closes the globally linear implementation of the infinite-fanout bundle, but it does **not** close nonlinear shared masking. There is a simple exact finite-group-action version of the bundle lemma that survives.

### Lemma 6.1 — finite permutation-action bundle masking

Let `G` be a finite group acting on a finite set `A`. Let `L` and `R` be independent source blocks. Let `P` be uniform on `G`, independent of `(L,R)`. Let

\[
\rho(R)\in G
\]

be arbitrary, and for a finite or countable index set `T` let

\[
a_t(L)\in A,\qquad t\in T,
\]

be arbitrary same-side functions. Define

\[
C_t=(P\rho(R))\cdot a_t(L),\qquad t\in T.
\tag{6.1}
\]

Then

\[
\sigma(L,(C_t)_{t\in T})
\perp\!\!\!\perp
\sigma(R).
\tag{6.2}
\]

The conclusion remains true for countably infinite `T`.

### Proof

Set

\[
U:=P\rho(R).
\]

Conditional on any value of `R`, right multiplication by `rho(R)` is a permutation of the finite group `G`, so `U` is uniform on `G`. More strongly, `U` is independent of `R`: for every `u,r`, the event `U=u` corresponds to the single pad value `P=u\rho(r)^{-1}`, which has probability `1/|G|` independently of `r`. Since `P` is also independent of `L`, `U` is independent of `(L,R)`.

The entire bundle `(C_t)_t` is a measurable function of `(L,U)`. Hence `(L,(C_t)_t)` is independent of `R`, proving (6.2). Countably many coordinates cause no issue because independence of the generated sigma-fields follows from the finite-dimensional statement and a monotone-class argument. QED.

If the action of `P` changes infinitely many `a_t(L)` values with positive probability, resampling `P` creates infinite reverse influence and therefore avoids the finite-disagreement obstruction from the previous report. Unlike a global group homomorphism `Omega -> H^{Z^d}`, the map `(L,P,R) -> (C_t)_t` can be genuinely nonlinear through the orbit data `a_t(L)`.

Thus the automatic-locality theorem does not kill the bundle concept itself; it tells us exactly where the remaining positive search has to live.

## 8. Failed route and remaining gap

### Failed route A: infinite linear/profinite convolution

The intended idea was to exploit countably many tiny algebraic stages while keeping only one finite symbol at each output site. Lemma 2.1 shows that a Borel finite-valued homomorphism cannot genuinely see infinitely many such stages. The inverse limit collapses to a finite quotient before any Bradley geometry is used.

### Failed route B: repair the phase-free construction line by line

If the missing coordinate-direction independence is imposed on each independent row, each row becomes one-dependent and therefore double-tail trivial. Independent transverse rows cannot contribute information about the erased row symbol. The full own-tail condition therefore forces degeneracy.

### Remaining gap

A positive solution may still use a **nonlinear, genuinely multidimensional, infinite-influence** factor. The permutation-action bundle lemma shows that exact one-cut masking survives in such a class. What remains completely unresolved is simultaneous consistency over all horizontal and vertical cuts: the same finite-state output symbol participates in many bundles, and the cross-cut group actions must not leave a common invariant visible to two separated halfspaces.

A negative solution would need a theorem saying, roughly, that finite alphabet + stationarity + Bradley independence forces any such nonlinear infinite-fanout bundle system to collapse to a local/profinite factor or to expose a nontrivial common invariant. No such theorem is proved here.

## 9. Next concrete attack

The next run should **not** return to private-pad matching, finite-load queues, globally linear/profinite convolution, or independent-line repair. Those routes are now closed in their stated classes.

The most concrete surviving construction problem is `d=2` with a finite transitive permutation group `G action A`:

1. build a stationary sparse random family of horizontal and vertical infinite bundles;
2. each bundle has one uniform pad acting diagonally on infinitely many finite-state checks as in (6.1);
3. opposite-side dependence enters only through multiplication of that common group element, so one-cut independence is exact;
4. horizontal and vertical bundle systems are **coupled**, not independent line products;
5. for every finite nonempty flip set `Delta`, infinitely many remote bundles give conditionally independent tests that distinguish the wrong filling;
6. verify that no orbit invariant, bundle label, phase, or pad quotient is measurable from both members of any Bradley-separated halfspace pair.

The first mathematical subproblem is a two-cut compatibility lemma: characterize when two crossing permutation bundles sharing finitely many output sites can both admit the representation (6.1) without forcing a nonconstant common invariant. Proving impossibility for all finite transitive actions would be a broad new obstruction; producing one nontrivial compatible action would be the first credible route past the current boundary.

That is the next genuinely different method. The full Bradley question remains open.
