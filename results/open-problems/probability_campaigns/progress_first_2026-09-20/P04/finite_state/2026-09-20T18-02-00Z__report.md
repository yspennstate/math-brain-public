## 2. First result: physical overlap of already cut-safe packets is harmless

The previous run's first requested test has a clean positive answer. Summing many packet shares at the same physical output site does **not** by itself create cross-cut dependence.

### Theorem 2.1 — side-local aggregation preserves exact cut independence

Fix any Bradley cut `(L,R)`, for example

\[
L=G_{i,m},\qquad R=H_{i,m+2}.
\]

For each packet label `a` let `U_a^L` and `U_a^R` be arbitrary finite or countable random elements. Assume

1. the packet pairs `(U_a^L,U_a^R)` are independent across `a`;
2. within every packet,
   \[
   U_a^L\perp\!\!\!\perp U_a^R.
   \tag{2.1}
   \]

Let the final left output field `X_L` be any measurable function of the full left raw family `(U_a^L)_a`, and let `X_R` be any measurable function of `(U_a^R)_a`. Then

\[
\boxed{X_L\perp\!\!\!\perp X_R.}
\tag{2.2}
\]

This remains true when a physical output symbol is the finite sum/XOR of arbitrarily many different packet shares, provided the realized sum at that site is well-defined and uses only raw variables assigned to that same side.

#### Proof

By (2.1) and independence across packet labels, the two joined sigma-fields

\[
\mathcal A_L=\bigvee_a\sigma(U_a^L),\qquad
\mathcal A_R=\bigvee_a\sigma(U_a^R)
\]

are independent. Since `sigma(X_L) subset A_L` and `sigma(X_R) subset A_R`, the smaller output sigma-fields are independent. QED.

### Application to the perfect directional gadget

For one additive `2d`-share gadget, every **proper** collection of shares is product-uniform. Therefore if, for a given cut, the raw variables assigned to `L union R` omit at least one share of every packet, then `U_a^L` and `U_a^R` are independent for that packet. Theorem 2.1 shows that arbitrary side-local aggregation and physical overlap among many such packets preserves exact cut independence.

So the first suspected failure mode from the preceding report is **not** an obstruction:

> Overlap of independent packets at output sites is harmless once each packet is already cut-safe at the raw-share level.

The difficulty moves one level down: how can an unbounded-range packet or bundle be made cut-safe for *every translated coordinate cut* while remaining useful for tail reconstruction?

## 3. Exact linear masking criterion: far-side response must lie in the pad span

The next theorem isolates the algebraic condition for a reused family of pads to hide an arbitrary collection of far-side summaries. It turns the informal “common-mask bundle” idea from earlier runs into an exact rank law.

### Theorem 3.1 — finite pad-span criterion

Let `F=F_q` be a finite field. Let

\[
P\sim\operatorname{Unif}(F^r),\qquad
R\sim\operatorname{Unif}(F^s)
\]

be independent. For a finite collection of observed outputs let

\[
C=A P+B R\in F^t,
\tag{3.1}
\]

where `A` is a `t x r` matrix and `B` is a `t x s` matrix over `F`. Then the following are equivalent:

1. `C` is independent of `R`;
2. every conditional law `L(C | R=r)` is the same;
3. `im(B) subset im(A)`;
4. for every row coefficient `lambda in F^t`,
   \[
   \lambda^T A=0\quad\Longrightarrow\quad \lambda^T B=0.
   \tag{3.2}
   \]

In particular,

\[
\boxed{\operatorname{rank} B\le \operatorname{rank} A.}
\tag{3.3}
\]

#### Proof

Conditional on `R=r`, the random vector `C` is uniform on the affine coset

\[
Br+\operatorname{im}(A).
\]

These conditional laws are identical for all `r` exactly when every displacement `Br` belongs to `im(A)`, i.e. exactly when `im(B) subset im(A)`. This proves `(1)<->(2)<->(3)`.

For finite-dimensional vector spaces,

\[
\operatorname{im}(B)\subset\operatorname{im}(A)
\]

is equivalent, by annihilators, to

\[
\ker(A^T)\subset\ker(B^T),
\]

which is (3.2). Rank inequality (3.3) is immediate. QED.

### Interpretation: every pad-canceling cycle must also cancel the remote signal

Think of the rows of `A` as outputs and its columns as masking pads. A finitely supported linear combination `lambda` with

\[
\lambda^T A=0
\]

is a **masking cycle**: the pads cancel from that output combination. Equation (3.2) says exact cut blindness forces the same cycle to cancel every far-side summary as well. Otherwise

\[
\lambda^T C=\lambda^T B R
\]

is a nonconstant far-side statistic directly visible from the observed side.

Thus overlap is safe only when all linear leakage created by pad cancellation vanishes.

### Corollary 3.2 — the one-pad infinite bundle is necessarily rank one

Suppose a finite family of outputs all use the same single uniform pad `P` with coefficient `1`:

\[
C_j=P+\rho_j(R),\qquad j=1,\ldots,t,
\tag{3.4}
\]

where the `rho_j` are linear functionals of a uniform finite-field far-side source. Then the bundle is independent of `R` iff all `rho_j` are the same linear functional.

Indeed `im(A)` is the diagonal line spanned by `(1,...,1)`. Therefore the far-side response vector must also lie in that diagonal line. Equivalently, every difference

\[
C_j-C_k=\rho_j(R)-\rho_k(R)
\]

must be constant; in the homogeneous linear setting it must vanish.

This proves that the “shared pad + common far-side summary” bundle found in the earlier progress-first run was not merely a sufficient trick. **Within the linear/additive architecture it is the exact one-pad possibility.**

### Countable bundle form

For countably many outputs with each observed finite subset depending on finitely many pads and far-side coordinates, exact independence of the whole output sigma-field from the far-side source is equivalent to Theorem 3.1 on every finite restriction. Equivalently:

> every finitely supported output combination that cancels all pads must cancel the far-side response.

This is the useful form for an infinite-fanout stationary construction.

## 4. Masking-rank budget for overlapping packets

The previous criterion yields a finite-set budget that is independent of how complicated the routing geometry is.

### Corollary 4.1 — remote response rank cannot exceed masking rank

For any finite observed set `T` on one side of a Bradley cut, write its additive decomposition as

\[
C_T=A_T P+B_T R.
\]

If `C_T` is exactly independent of the far-side source `R`, then

\[
\operatorname{rank}(B_T)
\le
\operatorname{rank}(A_T)
\le
\#\{\text{independent pad dimensions incident to }T\}.
\tag{4.1}
\]

Therefore `r` linearly independent remote summary dimensions require at least `r` independent masking dimensions on that observed side. Reusing one pad across infinitely many outputs can hide infinitely many *copies of one common summary*, but cannot hide an arbitrarily high-rank family of distinct summaries.

This is exactly the tradeoff needed for the surviving infinite-fanout program. Infinite reverse fanout is compatible with tail rigidity, but pad reuse has a strict algebraic price: **fanout does not create masking rank**.

## 5. Spatial obstruction for a fixed finite parity packet

The local `2d`-share secret-sharing gadget is perfect algebraically, but a second issue appears once its variables are placed at lattice sites. A fixed finite minimal parity circuit cannot stretch arbitrarily far and remain Bradley-safe packet by packet.

### Lemma 5.1 — a minimal parity circuit crossing an empty separator violates Bradley independence

Let `E subset Z^d` be finite, and over `F_q` let `(Z_v)_{v in E}` be uniform subject to one minimal relation

\[
\sum_{v\in E} a_v Z_v=0,
\qquad a_v\ne0\text{ for all }v.
\tag{5.1}
\]

Then every proper coordinate subcollection is product-uniform. If a Bradley cut `(G_{i,m},H_{i,m+2})` has

\[
E\cap G_{i,m}\ne\varnothing,\qquad
E\cap H_{i,m+2}\ne\varnothing,
\]

but

\[
E\cap\{v:v_i=m+1\}=\varnothing,
\tag{5.2}
\]

then the two packet sigma-fields on the separated halfspaces are not independent. In fact their mutual information is exactly `log q`.

#### Proof

Under (5.2), `E` is partitioned into the two nonempty sets

\[
E_L=E\cap G_{i,m},\qquad E_R=E\cap H_{i,m+2}.
\]

Because both are proper subsets of `E`, each marginal is product-uniform, so

\[
H(Z_{E_L})=|E_L|\log q,
\qquad
H(Z_{E_R})=|E_R|\log q.
\]

The one full-rank relation (5.1) gives

\[
H(Z_E)=(|E|-1)\log q.
\]

Hence

\[
I(Z_{E_L};Z_{E_R})
=H(Z_{E_L})+H(Z_{E_R})-H(Z_E)
=\log q>0.
\]

QED.

### Corollary 5.2 — packetwise cut safety forces contiguous coordinate projections

If such a minimal parity packet is to satisfy Bradley independence by itself for **every** translated cut, then for every coordinate `i`, its projection

\[
\{v_i:v\in E\}
\]

must be a full integer interval. Therefore

\[
|E|\ge 1+\big(\max_{v\in E}v_i-\min_{v\in E}v_i\big)
\tag{5.3}
\]

for every coordinate `i`.

In particular, a fixed `M`-variable minimal parity packet that is independently cut-safe has coordinate diameter at most `M-1`. A fixed `2d+1`-variable “secret plus `2d` shares” parity packet cannot itself route a secret to arbitrarily remote locations while preserving every Bradley cut.

This does **not** rule out superposition. Other packets/pads can mask a packet's apparent cross-cut relation; Theorem 3.1 describes exactly what must happen in the additive case. The conclusion is narrower but useful: a positive construction cannot consist of independently Bradley-safe copies of one fixed finite packet simply thrown to larger and larger radii.

## 6. Infinite mean is not enough for fresh finite packets

The preceding report showed that finite **mean** source incidence is fatal, leaving heavy-tailed finite-realization packets with infinite mean as a possible route. There is a sharper no-go statement for *fresh independent packets*: infinite mean packet size does not help if each individual packet still has finite physical footprint almost surely.

### Theorem 6.1 — fresh finite-footprint packet stripping

Let `(Z_a)_{a in N}` be independent packet randomizers, independent also of stationary auxiliary randomness `R`, and let a finite-state field `X` be a measurable function of `(R,(Z_a)_a)`. Assume the source law and coding are such that replacing one `Z_a` by an independent copy gives an output field `X^(a)` with the same law as `X`.

Suppose that for every packet `a`, changing only `Z_a` can affect only a finite random set of output coordinates almost surely. No integrability assumption is made on the size of that set.

If `X` is own-tail deterministic, then **every packet layer is irrelevant**: `X` is measurable from `R` alone. In particular, if `R` is absent, `X` is degenerate.

#### Proof

Fix `a` and independently refresh `Z_a`. By assumption, `X^(a)` has the same law as `X` and the disagreement set

\[
D_a=\{v:X_v\ne X_v^{(a)}\}
\]

is finite almost surely. Same-law finite-disagreement rigidity from the preceding report therefore gives

\[
X=X^{(a)}\quad\text{a.s.}
\tag{6.1}
\]

for every `a`.

Fix one output coordinate. Equation (6.1) says it is invariant under independent refresh of every individual packet coordinate. Conditional on `R`, it is therefore measurable with respect to the tail sigma-field of the independent sequence `(Z_a)`. Kolmogorov's zero-one law makes that tail trivial, so the coordinate is `R`-measurable. Apply this to the countable output lattice. QED.

### Consequence for the heavy-tailed packet plan

A law such as

\[
\Pr(M\ge n)=1/n,
\qquad M<\infty\text{ a.s.},\qquad E M=\infty,
\]

can evade the finite-**mean** incidence theorem, but it still cannot rescue a construction made of **fresh independent finite packets**. Each packet refresh has finite footprint and is stripped by Theorem 6.1.

Therefore every genuinely pivotal mask/gate in the surviving construction must have **infinite physical reverse fanout**, not merely infinite expected packet size. This cleanly separates two notions that had been conflated in the previous positive sketch:

- infinite mean finite packet size: insufficient;
- a single pivotal latent variable changing infinitely many outputs: still viable and, in this architecture, necessary.

## 7. Exact surviving additive architecture

Combining Sections 2--6 leaves a much narrower linear/additive target.

A viable construction may still use finite-state sums of many raw contributions at each site, and physical overlap is not a problem. But it must satisfy all of the following.

1. **Infinite-fanout pivotal pads/gates.** Fresh finite-footprint packet randomness is impossible by Theorem 6.1.
2. **Finite realized output state.** Every output must still be a well-defined finite-alphabet symbol, so any actual aggregation rule must avoid an undefined countable parity.
3. **Infinite-mean incidence or an equally nonsummable mechanism.** The finite-mean stripping theorem from the preceding report still applies.
4. **Cycle compatibility on every Bradley cut.** If `A_{i,m}` is the output-vs-mask incidence operator and `B_{i,m}` is the far-side response operator, then on every finite observed set
   \[
   \operatorname{im} B_{i,m}\subset\operatorname{im} A_{i,m}.
   \tag{7.1}
   \]
   Equivalently every finitely supported mask-canceling cycle must also cancel the far-side signal.
5. **No fixed finite packet can do the long-range work alone.** Any minimal parity circuit that is packetwise Bradley-safe must grow in arity at least linearly with its coordinate span.

For one reusable pad bundle, (7.1) collapses the remote response to rank one: every output in that bundle can see only the same far-side linear summary up to a constant. Multiple pads permit higher response rank, but Corollary 4.1 makes the required masking rank explicit.

This gives a concrete random-operator formulation of the next positive problem. Construct a stationary row-finite (finite realized aggregation) but infinite-mean incidence operator `A` whose pivotal columns have infinite support, together with a response/check operator `B`, such that for **every** coordinate cut and every finite row restriction,

\[
\operatorname{im}B_T\subset\operatorname{im}A_T,
\tag{7.2}
\]

while deleting any finite collection of output rows still leaves enough global checks to reconstruct those deleted output symbols. Deterministic finite-range/convolutional versions are already excluded by the earlier algebraic theorems; any survivor must be genuinely random/nonlocal.
