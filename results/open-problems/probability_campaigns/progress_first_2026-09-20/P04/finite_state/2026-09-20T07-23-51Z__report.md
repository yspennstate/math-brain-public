`σ(X_k:k in G_(i,m)) independent of σ(X_k:k in H_(i,m+2))`            (1.1)

## 2. Bradley's stationary parent in vector form

Let `(W^(h))_(h in Z^d)` be independent copies of Bradley's 1994 binary nonstationary field. As in the preceding reports, write the sigma-field-equivalent vector version of the stationary construction as

`V_k(j)=W_j^(k-j),   j in Z^d`.                                        (2.1)

Bradley's real scalar coordinate is a one-site measurable bijective encoding of this countable vector, so proving a theorem for finite windows of `V` also proves it for finite windows of the original real-valued stationary field.

Fix a nonempty finite physical coding window `F subset Z^d`, a finite alphabet `A`, and a measurable map

`f : ( {-1,+1}^{Z^d} )^F -> A`.                                       (2.2)

Define the translation-equivariant finite-window factor

`Y_k = f( (V_(k+s))_(s in F) )`.                                       (2.3)

`Y` is strictly stationary. We do **not** assume that an arbitrary such block code preserves Bradley's exact gap-two halfspace independence; the theorem below is stronger in a different direction: if `Y` is nonconstant, it already fails own-tail determinism, so it cannot solve Question 10 regardless of its cut-independence behavior.

Put

`D=F-F`.                                                               (2.4)

The finite set `D` controls every same-layer overlap created by the block code.

## 3. Main theorem

### Theorem 3.1 — finite physical coding radius over Bradley's stationary parent is impossible

Let `d>=2`, let `F subset Z^d` be finite and nonempty, and let `A` be finite. For every measurable `f` in (2.2), if the field `Y` in (2.3) is nondegenerate, then `Y` is **not** measurable with respect to its own full spatial tail.

Equivalently, no nonconstant finite-alphabet deterministic finite-spatial-window factor of Bradley's countable-layer stationary construction can answer Bradley Question 10.

For `F={0}` this recovers the preceding report. The new issue for `|F|>1` is substantial: one output now sees several coordinates of the **same** source layer, so whether a layer coordinate is pivotal depends on the layer being modified. The previous trick of choosing a ray from a pivotal mask independent of that layer is unavailable. The replacement is the piecewise-Haar rerouting argument proved below.

## 4. Exact local geometry of one source layer inside a finite output window

Fix a source-layer label `h in Z^d`.

A layer coordinate `W_u^(h)` is visible to `Y_k` iff there is some `s0 in F` such that

`u = k+s0-h`,

or equivalently

`k = h+u-s0`.

Therefore the finite set of output sites that can see layer coordinate `u` is

`B_u := h+u-F`.                                                        (4.1)

Now fix `k=h+u-s0 in B_u`. Across all input sites `V_(k+s)`, `s in F`, the coordinates of the same layer `h` that `Y_k` can see are

`k+s-h = u+(s-s0) in u+D`.                                             (4.2)

More generally, for any other source layer `g`, all layer-`g` coordinates used by the entire vector `(Y_k)_(k in B_u)` lie in

`(h-g)+u+D`.                                                           (4.3)

Thus although `f` may inspect infinitely many diagonal labels, **for each fixed source layer** the local decision around center `u` uses only a translate of one fixed finite set `D`.

This bounded-per-layer geometry is the lever missing from the sitewise proof.

## 5. Parity-tree perturbations with prescribed local footprint

Recall the compact sign group `K` supporting one Bradley layer. Bradley's shell identities can be written

`W_(phi(n)) = product_(v in S_n) W_v`,                                 (5.1)

where `S_n={v:||v||_infinity=n}` and `phi` is the norm-monotone enumeration used in the construction. In additive mod-two flip notation, every group element `e in K` satisfies

`e_v = XOR_(w in C(v)) e_w`,                                           (5.2)

where `C(v)=S_(phi^{-1}(v))` is the child sphere of `v`.

The layer law is Haar measure on `K`. Hence multiplication by any fixed element of `K` preserves the layer law.

### Lemma 5.1 — locally isolated thin flip

For every fixed finite set `D` and every sufficiently deep parity-tree vertex `u`, there exists `gamma_u in K` such that

`support(gamma_u) intersection (u+D) = {u}`.                            (5.3)

Moreover `gamma_u` can be chosen as a union of two infinite descendant rays: one through `u`, one through a sibling of `u` chosen outside the bounded neighborhood `u+D`; all later vertices can be taken still farther away.

#### Proof

For a nonroot `u`, its parent is unselected in the desired perturbation, so selecting only the branch through `u` would give one selected child at the parent and violate (5.2). Select a second sibling on the same child sphere. Since `d>=2`, the child sphere has cardinality tending to infinity and a sibling can be chosen outside any prescribed finite neighborhood. Continue each selected child by exactly one selected child at every later generation. Then every selected vertex has one selected child and the common unselected parent has two selected children, so (5.2) holds. Child radii increase without bound, allowing all later support to avoid `u+D`. The root case needs only one ray. ∎

### Lemma 5.2 — finite projection patterns admit finite-ray extensions

Let `C subset Z^d` be finite and let `delta in K`. There is `delta_thin in K` such that

`delta_thin|_C = delta|_C`,                                             (5.4)

and the support of `delta_thin` is a finite tree skeleton followed by finitely many infinite descendant rays.

#### Proof

Take the finite ancestor closure `T` of `C` in the parity tree and copy the values of `delta` on `T`. Process vertices of `T` downward. For each `v in T`, the already prescribed selected children have some parity. If that parity differs from the prescribed value at `v`, select one additional child outside `T`; otherwise select none. This makes (5.2) true at every vertex of `T`. There are only finitely many added boundary children. Continue each selected boundary child by one infinite ray. Unselected vertices outside this finite skeleton have no selected children, while every selected ray vertex has one selected child, so all parity equations hold. ∎

The rays can additionally be routed outside any finite list of forbidden bounded neighborhoods after extending the finite prefix, again because `d>=2` gives growing child spheres.

## 6. A local sensitivity field for the block code

For sufficiently deep `u`, choose `gamma_u` as in Lemma 5.1 and define

`Q_u = 1{ (Y_k)_(k in B_u) changes when W^(h) is multiplied by gamma_u }`.   (6.1)

All other source layers are held fixed.

Because `gamma_u` meets `u+D` only at `u`, equation (4.2) shows that `Q_u` is exactly the event that locally toggling the single layer coordinate `u` changes at least one output that can see it. The far continuation of `gamma_u` is invisible to those outputs.

Two properties replace the independent pivotal mask of the sitewise proof.

### Lemma 6.1 — local sensitivity vanishes at infinity

Let

`q_u=P(Q_u=1)`.

Then

`lim_(R->infinity) sup_(||u||_infinity>=R) q_u = 0`.                    (6.2)

#### Proof

Because `A` is finite and `f` is measurable on a countable product, for every `epsilon>0` there is a cylinder function `f_epsilon` depending on only finitely many diagonal coordinates in each of the finitely many input sites such that

`P( f((V_s)_(s in F)) != f_epsilon((V_s)_(s in F)) ) < epsilon`.       (6.3)

By stationarity the same error bound holds at every translated output site.

For `u` sufficiently far out, none of the finitely many diagonal labels inspected by `f_epsilon` at any site in `B_u` corresponds to layer `h` at a coordinate in the support of `gamma_u`: the only nearby support point is `u`, while the other support points lie still farther down the parity tree. Therefore all cylinder outputs on `B_u` are unchanged by `gamma_u`.

The fixed translation `W^(h) -> gamma_u W^(h)` preserves the joint source law. A union bound over the at most `|F|` sites in `B_u` gives

`q_u <= 2 |F| epsilon`                                                  (6.4)

for all sufficiently remote `u`. Since `epsilon` is arbitrary, (6.2) follows. ∎

### Lemma 6.2 — bounded-gap halfspace independence of the sensitivity field

There is a deterministic integer `L_F<infinity`, depending only on `F`, such that whenever two collections of centers are separated in one coordinate by at least `L_F`, the corresponding `Q` sigma-fields are independent.

A sufficient choice is any

`L_F > 3 + max_i ( max_(z in D) z_i - min_(z in D) z_i )`.             (6.5)

#### Proof

By (4.3), for every source layer `g`, the event `Q_u` uses layer-`g` coordinates only in `(h-g)+u+D`. If two sets of centers are separated by (6.5) in coordinate `i`, these finite coordinate blocks lie in Bradley-separated halfspaces of `W^(g)`. Hence the corresponding source sigma-fields are independent in every layer `g`. The layers themselves are mutually independent. Taking the joins over all `g` preserves independence. ∎

In particular, on a large child sphere we can choose a linearly large ordered menu of candidate children separated by `L_F` in a transverse coordinate; their `Q` variables are mutually independent.

## 7. Large fresh menus on the parity tree

Let `v` be a sufficiently deep parity-tree vertex and let

`n(v)=phi^{-1}(v)`, so `C(v)=S_(n(v))`.

Fix a transverse coordinate, say coordinate 2. On one face of the child sphere choose a deterministic menu

`M(v) subset S_(n(v))`

whose coordinate-2 spacings are at least `L_F` and which avoids a bounded neighborhood of a designated default child. Then

`|M(v)| >= c_F n(v)`                                                    (7.1)

for a constant `c_F>0` once `n(v)` is large. By Lemma 6.2, the variables `(Q_u)_(u in M(v))` are mutually independent.

The same norm-monotonicity used in the preceding report makes successive child radii explode: after choosing a child on `S_n`, its inverse index is at least of order `n^d`. Consequently, after discarding a finite prefix, the source blocks used by a new menu are Bradley-separated from all blocks inspected in earlier menus. Conditional on an earlier menu history, the next menu therefore has its original product law.

For finitely many simultaneous rays, route them sequentially and delete from each new sphere the finitely many `D`-neighborhoods that would collide with already chosen branches. A sphere in dimension `d>=2` still contains a linearly large separated menu. Thus all eventual selected ray vertices may be required to satisfy

`u-v notin D` for distinct selected deep vertices `u,v`.               (7.2)

This means no output block can see two selected deep layer coordinates at once.

## 8. The new ingredient: adaptive piecewise-Haar ray rerouting

In the sitewise report, the pivotal mask did not depend on the layer being changed, so a ray could be selected independently of that Haar layer. Here `Q_u` can depend on neighboring coordinates of `W^(h)`. We need to adapt to the actual layer **without changing its law**.

### Lemma 8.1 — one-step piecewise-Haar rerouting

Suppose a currently selected parity ray reaches a parent `v` and then follows a designated default child `c`. Let `u_1,...,u_M` be a menu of alternative children with pairwise separated local neighborhoods. For each `r`, let `rho_r in K` be the symmetric-difference perturbation that removes the default tail through `c` and replaces it by a tail through `u_r`; choose all deeper default continuations outside the local neighborhoods of the menu.

Define the selection rule

`J(x)= first r with Q_(u_r)(x)=0`,

and use `J=0` if all menu values equal one, with `rho_0=identity`.

Then the map

`R(x)=rho_(J(x)) x`                                                     (8.1)

preserves Haar measure on `K` (for every fixed realization of all other source layers).

#### Proof

For each `r>=1`, let

`C_r={Q_(u_1)=...=Q_(u_(r-1))=1, Q_(u_r)=0}`.                           (8.2)

The fallback cell is `C_0={all Q_(u_s)=1}`.

The geometry of the menu implies that `rho_r` has no local effect in the dependency neighborhood of `Q_(u_s)` for `s!=r`. In the neighborhood of `u_r`, it acts only by toggling `u_r`. But `Q_(u_r)` is a **difference event** between a configuration and the same configuration with that local toggle, so toggling `u_r` merely swaps the two members of the comparison. Hence

`Q_(u_s)(rho_r x)=Q_(u_s)(x)` for every `s`.                            (8.3)

Therefore `rho_r C_r=C_r`. On `C_r`, `R` is the fixed Haar translation `rho_r`; on `C_0`, it is the identity. For every measurable `A subset K`,

`mu(R^(-1) A)
 = sum_r mu(C_r intersection rho_r^(-1) A)
 = sum_r mu(rho_r C_r intersection A)
 = sum_r mu(C_r intersection A)
 = mu(A)`.                                                             (8.4)

So `R` preserves Haar exactly. ∎

This is the central new device of the run: the routing may inspect whether candidate sites are locally harmless because the decision cells are invariant under the very translations used to reroute the parity flow.

### Lemma 8.2 — infinite adaptive rerouting still preserves Haar

Starting beyond a deterministic finite prefix, repeat Lemma 8.1 successively down a ray, and on finitely many rays if needed. Then the coordinatewise limit transformation preserves Haar measure.

#### Proof

Every finite composition preserves Haar. Rerouting at generation `t` changes only parity-tree coordinates beyond a radius tending to infinity. Hence every fixed coordinate stabilizes after finitely many reroutings. For a bounded cylinder function `g` on `K`, `g(R_N x)` is therefore eventually equal to `g(R_infinity x)` pointwise. Dominated convergence gives

`E g(R_infinity W)=lim_N E g(R_N W)=E g(W)`.                            (8.5)

Cylinder functions determine probability measure on the compact product group, so `R_infinity W` is Haar. The argument is conditional on the other independent layers, hence the complete joint source law is preserved. ∎

## 9. The adaptive rays are harmless with arbitrarily high probability

At a deep parent `v`, on a menu `M(v)` the `Q` variables are mutually independent and each has probability at most

`epsilon(n)=sup_(||u||>=n) q_u`,

with `epsilon(n)->0` by Lemma 6.1. Thus, conditional on every earlier inspected menu,

`P(all candidates in M(v) have Q=1)
 <= epsilon(n(v))^(c_F n(v))`.                                         (9.1)

After going deep enough that `epsilon(n)<=1/2`, this is at most

`2^(-c_F n(v))`.                                                        (9.2)

The radii along a Bradley descendant ray grow superlinearly (indeed by repeated polynomial-scale inverse-index growth), so the sum of (9.2) over future generations can be made arbitrarily small by starting sufficiently deep.

Therefore for every `eta>0`, each required thin branch can be adaptively rerouted so that, with probability at least `1-eta`, **every selected vertex beyond a finite prefix has `Q_u=0`**. For finitely many branches, choose the individual failure budgets to sum below `eta` and use (7.2) to keep all deep selected vertices mutually `D`-separated.

No independence between this success event and the eventual target-change event will be needed.

## 10. A nonconstant output supplies a finite target trigger

Assume `Y_0` is nonconstant. The source layers `(W^(h))_(h in Z^d)` are independent Haar copies.

If replacing any single layer by an independent copy left `Y_0` unchanged almost surely for every `h`, then `Y_0` would be invariant under changing every finite set of layer coordinates. It would therefore be measurable with respect to the tail sigma-field of the independent layer family, which is trivial. Hence `Y_0` would be constant, a contradiction.

Thus there is some layer `h` such that independent resampling of `W^(h)` changes `Y_0` with positive probability. If `W'^(h)=delta W^(h)`, then for independent Haar `W^(h),W'^(h)`, the difference `delta` is Haar and independent of `W^(h)`. Averaging over `delta` shows that there is a **fixed** `delta_0 in K` for which

`p := P( Y_0(W) != Y_0(delta_0 W) ) > 0`,                              (10.1)

where only layer `h` is translated.

At output zero, layer `h` is visible only through the finite coordinate set

`C_h=F-h`.                                                             (10.2)

Therefore the event in (10.1) depends on `delta_0` only through its restriction to `C_h`. By Lemma 5.2, replace `delta_0` by a thin element with the same restriction on `C_h`: a finite tree skeleton followed by finitely many rays. Equation (10.1) is unchanged.

Choose deterministic prefixes on those rays long enough that all adaptive work begins outside the input coordinates of `Y_0` and outside the finite skeleton.

## 11. Proof of Theorem 3.1

Let `x` denote the chosen source layer `W^(h)` and set initially

`z_0=delta_0 x`.

Because `delta_0` is fixed, `z_0` is Haar. Starting after the finite skeleton, apply the adaptive piecewise-Haar rerouting from Sections 8–9 to every thin ray of `delta_0`, producing a limit layer `z_infinity`.

By Lemma 8.2, conditional on all other source layers,

`z_infinity` has the same Haar law as `x`.                              (11.1)

Hence the source configuration with layer `h` replaced by `z_infinity` has **exactly the same joint law** as the original full source configuration. Let `Y'` be its finite-state output. Then

`Law(Y')=Law(Y)`.                                                       (11.2)

The reroutings begin outside `C_h`, so they do not alter the action of `delta_0` on the input of `Y_0`. Consequently

`P(Y'_0 != Y_0)=p` before imposing the ray-success event.               (11.3)

Choose the starting depths so that the probability that **any** adaptive branch ever falls back to a menu with all `Q=1` is less than `p/2`. If `S` is the event that all branches succeed forever, then without any independence assumption,

`P( Y'_0 != Y_0 and S ) >= p-P(S^c) > p/2 >0`.                         (11.4)

On `S`, every selected deep parity-tree vertex `u` has `Q_u=0`. The construction also guarantees (7.2), so any output site whose finite input window meets the deep perturbation support sees **exactly one** selected deep layer coordinate. By the definition of `Q_u`, changing that single coordinate leaves every output in `B_u` unchanged. Thus all output disagreements caused by the infinitely long adaptive tails vanish.

The only output sites that can still change are those whose finite input windows meet the **finite initial tree skeleton and deterministic prefixes**. There are finitely many such sites. On the positive-probability event in (11.4), site zero is one of them and does change. Hence

`P( 0 < |{k:Y_k != Y'_k}| < infinity ) > 0`.                            (11.5)

Now use the general finite-disagreement rigidity of an own-tail deterministic field. If two same-law realizations `Y,Y'` agree outside a finite set, choose a finite box containing that set. Every coordinate of an own-tail deterministic field is measurable from the exterior of that box, and the same measurable decoder applies to both marginals. Since their exteriors coincide, all decoded coordinates coincide. Thus a same-law coupling can never have a finite nonempty disagreement set.

Equation (11.5) contradicts this. Therefore `Y` is not own-tail deterministic. ∎

## 12. What this theorem changes

The no-go hierarchy for the direct Bradley stationarization is now:

1. finite-layer truncation cannot be strictly stationarized by a finite random set of translate indices;
2. finite-source-footprint / finite-radius-iid constructions cannot be tail deterministic;
3. no nonconstant **sitewise** finite statistic of all Bradley layers can be tail deterministic (preceding report);
4. **new:** no nonconstant finite statistic of **any deterministic finite physical window** of the full infinite-layer Bradley stationary parent can be tail deterministic.

Item 4 is not a finite-copy theorem: every allowed parent site contains countably many source layers, and a finite window still has an infinite independent-copy footprint. The adaptive piecewise-Haar argument is what makes the extension possible.

A direct corollary for Bradley's original real-valued stationary example is:

> Every nondegenerate finite-valued factor with deterministic finite coding radius relative to Bradley's stationary real field fails own-tail determinism.

Thus a positive finite-state solution obtained as a factor of Bradley's stationary example would need a **genuinely infinite physical coding radius**. Together with the earlier reverse-influence result, it would also need global, non-summable information propagation.

This still leaves a large logical gap to the source problem: an arbitrary finite-state Bradley field need not be a factor of Bradley's particular stationary parent at all.

## 14. Failed route and remaining gap

I also reconsidered whether the finite-window theorem could be obtained by simply grouping the finitely many same-layer bits into a `super-coordinate` and invoking the preceding sitewise proof. That fails at exactly one important point: the block-pivotal event depends on the unchanged coordinates of the **same Haar layer**, so the ray choice is not independent of that layer. Treating it as independent would invalidate the same-law coupling. Lemma 8.1 is the repair; the selection is allowed to depend on the layer because it is implemented as a piecewise Haar translation on invariant cells.

The full D0038 obstruction still missing is an intrinsic analogue of this rerouting argument for an **arbitrary** finite-state candidate. The Bradley source parent provides a concrete compact-group parity tree on which same-law thin perturbations can be rerouted. A general candidate does not come with such a perturbation group.

## 15. Next mathematical attack

The most immediate extension is from deterministic finite coding windows to **finitary factors of Bradley's stationary parent with almost surely finite but unbounded physical coding radius**. The present proof suggests the exact route:

1. define a random local dependency neighborhood for each candidate parity vertex;
2. use the tail of the coding radius to find, on each huge child sphere, many candidate vertices whose dependency neighborhoods are simultaneously small and pairwise disjoint;
3. make the `small-radius + Q_u=0` selection cells invariant under the corresponding ray-rerouting translations;
4. apply the same piecewise-Haar lemma without assuming any moment bound on the coding radius if the sphere growth is strong enough.

If this succeeds, every finitary finite-state factor of Bradley's stationary example is excluded, leaving only genuinely everywhere-infinite spatial codings. If it fails, the failure mechanism will identify the exact heavy-tail coding-radius regime in which a positive Bradley-factor construction could still hide.

A separate full-source route remains to abstract the finite-disagreement coupling away from Bradley's parent: derive, from finite alphabet plus exact halfspace independence alone, an internal same-law perturbation that is invisible outside a finite random region. Such a perturbation would immediately contradict own-tail determinism and would settle Question 10 negatively.
