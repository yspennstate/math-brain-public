## 2. New block-grid theorem: arbitrary separated blocks are iid

The spacing-4 single-site observation has a stronger block form that appears to be the useful scale for the remaining problem.

Fix an integer `L>=1` and write

`Q_L = {0,1,...,L-1}^d`,                                               (2.1)

`M = L+3`.                                                              (2.2)

For `r in Z^d`, define the translated bulk block

`Q_r = Q_L + M r`,                                                      (2.3)

and the block random variable

`B_r = X_(Q_r)`.                                                        (2.4)

### Theorem 2.1 — `(B_r)` is iid

If `X` is strictly stationary and satisfies Bradley's exact halfspace condition (1.1), then

`(B_r : r in Z^d)`                                                      (2.5)

is an iid random field (with the common law of `X_(Q_L)`).

#### Proof

It suffices to prove mutual independence for every finite nonempty set of coarse indices `F subset Z^d`. Induct on `|F|`.

The assertion is trivial for one block. Suppose `|F|>=2`. Choose a coordinate `i` on which the points of `F` do not all agree. Order the occupied values of `r_i` and split between two consecutive occupied levels. Thus for some integer `a`, after relabelling the split if needed,

`F_- = {r in F : r_i <= a}`,

`F_+ = F \ F_-`,                                                        (2.6)

are both nonempty and every `r in F_+` has `r_i>=a+1`.

Every physical site in a low block has

`k_i <= M a + L - 1`.                                                   (2.7)

Set

`m = M a + L`.                                                          (2.8)

Then all low blocks lie in `G_(i,m)` because their coordinates satisfy `k_i<m`. Every physical site in a high block satisfies

`k_i >= M(a+1) = M a + L + 3 > m+2`,                                  (2.9)

so all high blocks lie in `H_(i,m+2)`. By (1.1), the sigma-fields generated by all low blocks and all high blocks are independent.

By the induction hypothesis, the blocks inside each side are already mutually independent. Independence of the two generated sigma-fields therefore gives mutual independence of the whole finite family. Strict stationarity makes all block laws identical. This completes the induction. ∎

For `L=1`, `M=4`, this recovers the correct sparse iid skeleton `(4 Z)^d`.

### Rectangular variant

Exactly the same proof works for a rectangle

`Q = product_i {0,...,L_i-1}`

placed on the coarse lattice with coordinate steps `L_i+3`. Hence the phenomenon is not tied to cubes.

## 3. Entropy sandwich: the iid bulk contains asymptotically all entropy

Let the finite output alphabet be `A`, `q=|A|`, and write

`h = h_Zd(X)`                                                           (3.1)

for the entropy per physical lattice site, in the same logarithmic base throughout.

From the correct spacing-4 iid skeleton,

`h >= 4^(-d) H(X_0) > 0`                                               (3.2)

for every nondegenerate finite-state candidate. Here is the block-scale sharpening.

### Theorem 3.1 — exact entropy sandwich

For every `L>=1`,

`L^d h <= H(B_0) <= (L+3)^d h`.                                        (3.3)

#### Lower bound

Stationarity and ordinary block subadditivity imply

`h <= H(X_(Q_L))/|Q_L| = H(B_0)/L^d`,                                 (3.4)

which is the left inequality.

#### Upper bound

For `n>=1`, take the `n^d` iid bulk blocks with coarse indices

`r in {0,...,n-1}^d`.

Their union is contained in the physical cube

`U_n = {0,...,Mn-1}^d`,                                                 (3.5)

where `M=L+3`. Since the blocks are iid,

`H(X_(U_n)) >= n^d H(B_0)`.                                            (3.6)

Divide by `(Mn)^d` and let `n->infinity`. The left side tends to `h`, giving

`h >= H(B_0)/M^d`,                                                      (3.7)

or the upper bound in (3.3). ∎

Thus

`H(B_0)/(L^d) -> h`                                                     (3.8)

and the separated iid bulk blocks capture an asymptotic fraction

`(L/(L+3))^d -> 1`                                                      (3.9)

of physical sites while already carrying essentially all entropy of the process.

This is much stronger structurally than merely knowing that a positive-density sparse set is iid.

## 4. Exact `iid bulk + thin helper` reduction

Partition the lattice into fundamental coarse cells

`P_r = {0,...,M-1}^d + Mr`,                                             (4.1)

with `M=L+3`. Inside each cell keep the iid bulk `Q_r` and define the three-layer corridor/helper set

`R_r = P_r \ Q_r`.                                                      (4.2)

Write

`C_r = X_(R_r)`.                                                        (4.3)

Then `(B_r,C_r)` is simply a regrouping of the original field under the subgroup `M Z^d`. The helper alphabet has size at most

`|D_L| = q^(s_L)`,

`s_L = M^d - L^d = (L+3)^d-L^d = O(L^(d-1))`.                          (4.4)

By finite-index entropy scaling, the coarse process `(B,C)` has entropy rate `M^d h`. Since `B` is iid, its coarse entropy rate is exactly `H(B_0)`. Therefore

`h(C | B) = M^d h - H(B_0)`                                            (4.5)

and (3.3) gives

`0 <= h(C|B) <= (M^d-L^d)h = s_L h`.                                  (4.6)

In particular,

`h(C|B)/H(B_0) <= ((L+3)^d-L^d)/L^d = O(1/L)`.                         (4.7)

So every hypothetical finite-state Bradley solution, viewed at a large block scale, has an exact representation of the following kind:

- an iid coarse bulk process `B` carrying `Theta(L^d)` entropy per coarse site;
- a corridor/helper process `C` living on only `Theta(L^(d-1))` physical symbols per coarse site;
- helper entropy *beyond the iid bulk* which is only surface order.

The tail condition makes this reduction considerably sharper.

### Theorem 4.1 — every finite iid-bulk erasure is recoverable using the helper

If `X` is own-tail deterministic, then for every finite coarse set `S subset Z^d`,

`H(B_S | B_(S^c), C_(Z^d)) = 0`.                                      (4.8)

#### Proof

Erase the finite physical set

`E = union_(r in S) Q_r`.                                               (4.9)

Every coordinate in `B_S` is tail measurable and therefore measurable from `X_(E^c)`. But the complement `E^c` consists exactly of all bulk blocks `B_r` with `r notin S` together with **all** corridor variables `C_r`, including the corridors in cells whose bulks were erased. This is (4.8). ∎

Because `B` is iid, (4.8) can equivalently be written as the exact conditional-information identity

`I(B_S ; C_(Z^d) | B_(S^c)) = H(B_S) = |S| H(B_0)`                    (4.10)

for every finite `S`.

Equation (4.10) is the cleanest current formulation of the remaining difficulty: a surface-size helper alphabet, observed over the whole infinite lattice, must reveal **all** information in every finite erased set of an iid bulk, but only jointly with the unerased iid bulk.

It also explains why one-scale Shannon inequalities have repeatedly failed: an infinite helper can reuse highly nonlocal parity/secret-sharing information across many different erasures.

## 5. New obstruction: no finite-range pre-injective syndrome can realize the helper

The reduction above suggests trying a finite-alphabet parity-check/cocycle construction: make the corridor `C` a local syndrome of the iid bulk `B`, then decode any finite bulk erasure from the unerased bulk plus all syndromes. The next theorem rules out that entire route for large `L`.

### Lemma 5.1 — elementary pre-injective local counting bound

Let `S` and `D` be finite alphabets. Let

`Phi : S^(Z^d) -> D^(Z^d)`                                             (5.1)

be a translation-equivariant finite-neighborhood map. Suppose `Phi` is **pre-injective**:

if `b,b'` differ on only finitely many sites and `Phi(b)=Phi(b')`, then `b=b'`.  (5.2)

Then

`|D| >= |S|`.                                                          (5.3)

#### Proof

Let `N subset Z^d` be a finite coding neighborhood for the coordinate map of `Phi`. Fix a background configuration `b*` and a large Følner box `F_n`. For each word `w in S^(F_n)`, form the configuration `b^w` equal to `w` on `F_n` and to `b*` off `F_n`.

Any two such inputs differ only on `F_n`. By pre-injectivity their output configurations are different. Locality implies that all outputs agree with `Phi(b*)` outside the finite enlargement `F_n+N`. Therefore the restrictions

`Phi(b^w)_(F_n+N)`                                                      (5.4)

must be pairwise distinct. Hence

`|S|^(|F_n|) <= |D|^(|F_n+N|)`.                                       (5.5)

Take logarithms, divide by `|F_n|`, and let `n->infinity`. Følner amenability gives `|F_n+N|/|F_n| -> 1`, proving (5.3). ∎

This is the elementary entropy-counting core behind the Garden-of-Eden/pre-injectivity principle; no external theorem is needed for the stated bound.

### Corollary 5.2 — no bounded-range corridor syndrome for Bradley

Consider the coarse decomposition at scale `L`. Let

`S_L = supp(B_0)`.                                                      (5.6)

Because entropy never exceeds log support size,

`log |S_L| >= H(B_0) >= L^d h`.                                       (5.7)

The corridor variable has alphabet contained in

`D_L = A^(R_0)`,

so

`log |D_L| <= s_L log q`.                                              (5.8)

Since `h>0` and `s_L=O(L^(d-1))`, for all sufficiently large `L`,

`L^d h > s_L log q`,                                                   (5.9)

hence

`|S_L| > |D_L|`.                                                       (5.10)

Suppose a proposed finite-state construction at this scale has the following architecture:

1. the coarse bulk is the full iid field `B in S_L^(Z^d)`;
2. the corridor/helper is a finite-range shift-equivariant deterministic syndrome `C=Phi(B)` (the coding range may depend on `L`, but is finite for fixed `L`);
3. from `B_(S^c)` and `C` one can exactly reconstruct `B_S` for every finite `S` and every allowed bulk configuration.

Then item 3 makes `Phi` pre-injective: if two bulk configurations differ only finitely and have the same syndrome, the exact finite-erasure decoder must identify the differing bulk and therefore forces the two configurations to coincide. Lemma 5.1 then requires `|D_L|>=|S_L|`, contradicting (5.10).

Therefore:

> **No nondegenerate finite-state Bradley solution can be implemented, at all sufficiently large block scales, by a finite-range deterministic corridor syndrome / parity-check / cocycle map whose syndromes, together with the unerased bulk, exactly correct arbitrary finite bulk erasures.**

This is stronger than the earlier `surface-determined box` obstruction. Here the helper does **not** have to determine a block by itself. The decoder may use every other iid bulk block, exactly as in a parity-check or secret-sharing code. What fails is finite-range production of only surface-alphabet syndromes while retaining pre-injectivity against arbitrary finite changes.

The same counting proof works with a fixed auxiliary environment `u` if, after conditioning on `u`, the map from bulk to syndrome is still finite-range and pre-injective in the bulk. I do not claim the theorem for an arbitrary random environment whose conditioning changes the admissible bulk support; that would require an additional relative-entropy argument.

## 6. What this says about the requested cocycle / inverse-limit route

The new result cuts the positive search into two sharply different cases.

### Local algebraic/cocycle route

A finite-range local cocycle or parity-check construction is now excluded much more broadly than the earlier linear-Haar theorem. The obstruction uses only:

- the exact Bradley halfspace geometry;
- finite alphabet;
- local syndrome production;
- exact finite-erasure correction.

No linearity, group law, quasigroup law, Markov property, or uniform measure is assumed in Lemma 5.1.

### Inverse-limit/hierarchical route

The previous run ruled out inverse limits whose finite stages all have zero entropy. The present run shows that a surviving positive-entropy hierarchy also cannot simply hide a local syndrome in the `O(L^(d-1))` corridor around `Theta(L^d)` iid bulk symbols. Its helper must be **genuinely nonlocal at every sufficiently large coarse scale**: changing finitely many bulk blocks has to be detectable arbitrarily far away in the helper field.

This is the same infinite-avalanche feature that appeared earlier in the Bradley-layer influence analysis, but it is now derived for an **arbitrary hypothetical source-valid candidate**, after coarse graining, rather than only for a factor of Bradley's particular real-valued architecture.

## 7. Failed upgrade: why the report stops short of a full impossibility proof

The tempting next inequality would be

`h(C) >= H(B_0)`                                                        (7.1)

or even a fixed positive fraction of `H(B_0)`, under the sole hypotheses that `B` is iid and every finite `B`-erasure is recoverable from `(B outside, C)`.

If (7.1) were true, the full Bradley problem would be impossible for large `L`, because

`h(C) <= H(C_0) <= s_L log q = O(L^(d-1))`,                            (7.2)

whereas

`H(B_0) >= L^d h = Omega(L^d)`.                                       (7.3)

I do **not** have a valid proof of (7.1) in the unrestricted measurable/nonlocal setting.

The obstacle is real rather than bookkeeping. For a finite vector of independent bits, a single parity bit determines each missing coordinate if all the other coordinates are revealed, so conditional information can be reused many times. In the infinite stationary setting, finite-range pre-injectivity forbids compressing that syndrome below the bulk alphabet size, but an unbounded-range helper could in principle send every finite perturbation into an infinite, extremely sparse pattern. Exactly this kind of nonlocal coding is what the full problem still allows.

Thus I am **not** promoting the local syndrome theorem to a full impossibility result.

## 8. New precise bottleneck: relative homoclinic syndrome inequality

The coarse reduction isolates a clean theorem whose resolution would materially move D0038.

> **Relative homoclinic syndrome problem.** Let `B=(B_r)_(r in Z^d)` be a nondegenerate iid finite-alphabet field and let `C` be a jointly stationary finite-alphabet field. Assume that for every finite `S`,
>
> `H(B_S | B_(S^c), C_(Z^d))=0`.                                      (8.1)
>
> Must the entropy rate of `C` be at least `H(B_0)`? More generally, is there a universal `c_d>0` such that
>
> `h(C) >= c_d H(B_0)`?                                                (8.2)

A positive answer with **any** constant `c_d>0` would close Bradley Question 10 negatively: at block scale `L`, (8.2), (5.7), and the surface alphabet bound (7.2) would contradict each other for large `L`.

A counterexample would be equally valuable: it would exhibit exactly the kind of low-rate, infinite-range, finite-erasure syndrome that a positive finite-state Bradley construction needs, and could be tested against the halfspace-independence constraints on the full `(B,C)` field.

This is a materially narrower target than the original open question and is the next attack.
