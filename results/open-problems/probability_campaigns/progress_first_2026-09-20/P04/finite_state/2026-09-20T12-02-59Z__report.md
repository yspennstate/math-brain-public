## 2. Tail-rigidity coupling lemma

I use the following elementary lemma repeatedly. It appeared in weaker architecture-specific forms in earlier D0038 work, but here it is used to obtain a new incidence theorem with no coding-radius hypothesis.

### Lemma 2.1 — finite same-law disagreement is forbidden

Let `X` and `X'` be two random fields on the same countable lattice, with the same marginal law. Suppose the common law is determined by its own full tail, in the strong finite-erasure sense

`H(X_F | X_(F^c)) = 0`

for every finite `F`.

If the disagreement set

`D={v : X_v != X'_v}`

is finite almost surely, then `D` is empty almost surely.

### Proof

For every deterministic finite box `B`, tail determinism supplies a measurable decoder of `X_B` from `X_(B^c)`, on a probability-one event. Since there are countably many finite boxes, intersect these events for the two marginals.

On the event that `D` is finite, choose a deterministic box `B` containing `D`. Then

`X_(B^c)=X'_(B^c)`.

Applying the common tail decoder to this identical exterior gives

`X_B=X'_B`.

Together with exterior agreement, `X=X'`. Therefore a same-law coupling cannot have a finite nonempty disagreement set with positive probability. QED.

The important point is that no moment bound and no deterministic coding radius is needed: **almost-sure finiteness of the reverse disagreement is already fatal.**

## 3. New theorem: finite expected auxiliary-pad incidence is impossible

The previous route introduced independent separator pads. The next theorem isolates what tail determinism forces on any such source layer.

Let `(P_v)_(v in Z^d)` be iid uniform symbols in a nontrivial finite group `G`, independent of any other source randomness. Suppose a stationary finite-alphabet output field `X` is a measurable equivariant function of all sources. Think of some output coordinates as check symbols. For each check anchored at a site `a`, let

`A(a) subset Z^d`

be the finite set of pad sites whose values the check actually reads. There may be several check coordinates per physical site, but their number is uniformly bounded because the output alphabet is finite; absorb that finite multiplicity into the anchor notation.

Define the pad-incidence intensity

`lambda := E[ number of pairs (check c anchored at 0, pad v in A(c)) ]`.

The check may have arbitrarily large random range and highly nonlocal dependence. No coding-radius moment is assumed.

### Theorem 3.1 — finite-incidence pad obstruction

Assume `lambda<infinity`. Then the following two properties cannot both hold:

1. the output law is determined by its own full tail; and
2. the iid pad layer is genuinely used, meaning resampling `P_0` changes the output with positive probability.

Equivalently, in an own-tail-deterministic output, every genuinely pivotal iid auxiliary pad layer must have **infinite expected reverse incidence**.

### Proof

Send one unit of mass from every check anchor `a` to every pad site `v in A(a)` read by that check. By stationarity / the mass-transport identity,

`E N_0 = lambda`,

where

`N_0 := #{checks c : 0 in A(c)}`

is the reverse number of check outputs that read the pad at the origin.

Since `lambda<infinity`, the integer-valued variable `N_0` is finite almost surely.

Now form a second source configuration by replacing only `P_0` by an independent fresh uniform `G`-symbol, leaving every other source variable unchanged. The source law is unchanged, hence the two output fields `X,X'` have the same marginal law.

Only outputs that read `P_0` can change. Therefore the disagreement set is contained in the finite set of at most `N_0` check anchors (plus any bounded local output coordinates that directly display/use `P_0`, if present). It is thus finite almost surely.

If the pad is genuinely pivotal, that disagreement set is nonempty with positive probability. This contradicts Lemma 2.1. Hence `P_0` must be output-irrelevant, contrary to property 2. QED.

### What is new relative to the earlier coding-volume result

An earlier report ruled out randomized finitary channels under a finite expected coding-volume condition such as `E(2R_0+1)^d<infinity`. The present theorem has a different and substantially weaker hypothesis: it does **not** require a coding radius, geometric balls, finitary determination of every output, or any moment of a forward radius. It uses only finite expected *reverse pad incidence*. A check may read pads from arbitrarily remote locations with a wildly heavy-tailed geometry.

Thus the theorem applies directly to separator-matching architectures that were not covered by a finite coding-volume estimate.

## 4. Private separator-pad matching is impossible in every load regime

Consider the specific repair proposed after the one-bad-direction construction.

A long check of span/radius `R` crosses order `R` Bradley cuts in its bad direction. To make the check invisible across each cut, the proposal assigns a private pad on the corresponding omitted separator hyperplane. Assume a finite pad capacity per physical site (one pad bit, or any fixed number `C`). The assignment is stationary and no pad occurrence is reused beyond that finite private capacity.

Let `L(c)` be the number of separator-pad incidences demanded by check `c`. For the intended geometry,

`L(c) >= c R(c)`

for a fixed positive constant `c` once `R` is large.

There are only two cases.

### Case A: finite mean demand

If

`E L(c) < infinity`,

then the incidence intensity `lambda` of Theorem 3.1 is finite. A private pad is pivotal by design: changing it flips (or nontrivially permutes) the associated masked check. Therefore own-tail determinism is impossible.

This kills exactly the preceding run's proposed power-law window

`P(R>=r) ~ r^(-alpha), alpha>1`,

because then `E R<infinity`, so the expected separator-pad demand per active check is finite.

### Case B: infinite mean demand

If

`E L(c)=infinity`,

then a stationary injection of all pad incidences into a finite-capacity pad field cannot exist. Indeed, send one unit of mass from each demanded incidence to its assigned pad site. Expected outgoing mass per lattice site is infinite, while expected incoming mass is at most the finite capacity `C`. This contradicts stationarity / mass transport.

Therefore an injective/private finite-capacity separator matching cannot serve all incidences.

### Corollary 4.1

**No stationary finite-capacity private separator-pad matching can simultaneously mask all cross-cut long checks and yield an own-tail-deterministic finite-state output, regardless of the tail law of the check radius.**

For power-law tails there is no remaining exponent window:

- `alpha>1`: finite-load regime, ruled out by Theorem 3.1;
- `alpha<=1`: infinite-load regime, ruled out by the finite-capacity mass-transport count.

This is a genuine course correction to the preceding report. The proposed `1<alpha<=d` subcritical matching route is now closed and should not be repeated.

The result is still only a construction-class obstruction. It does not rule out Bradley's finite-state field because a successful construction need not use independent private pads.

## 5. Why the obstruction points to infinite-fanout shared masks

Theorem 3.1 says more than “use heavier tails.” If an iid source symbol is genuinely used by an own-tail-deterministic code, resampling it must have positive probability of changing infinitely many output sites. In a separator-pad architecture this means a pad cannot be private. It must have **infinite reverse fanout**.

At first that sounds incompatible with exact halfspace independence: if two left-side checks use the same separator pad, their difference cancels the pad and may reveal right-side information. But there is one exact algebraic way reuse can be harmless: all checks sharing a pad must have the *same far-side dependence* modulo left-side information.

That observation gives a new positive design lemma.

## 6. Bundle-masking lemma: infinite fanout can preserve exact cut independence

Fix one Bradley cut. Abstract its source randomness as three independent blocks:

- `L`: source randomness on the left;
- `R`: source randomness on the right;
- `(P_a)_(a in A)`: iid uniform separator pads in a finite abelian group `G`.

For each separator label `a`, allow a finite or countably infinite family of left-side check outputs indexed by `t in T_a` of the form

`C_(a,t) = P_a + rho_a(R) + ell_(a,t)(L)`,

with addition in `G`. Here the right-side contribution `rho_a(R)` is **common to the entire bundle** `T_a`; only the left term `ell_(a,t)(L)` varies with `t`.

Let the rest of the left output be any function of `L` alone. Let the right output be any function of `R` alone. (A symmetric collection of right-side crossing bundles may be added using a disjoint separator-pad family.)

### Lemma 6.1 — rank-one bundle masking

Under this architecture, the full left output sigma-field is independent of the full right output sigma-field, even when some `T_a` are infinite.

### Proof

Fix `a` and choose an arbitrary reference `t_0 in T_a` when the bundle is nonempty. The whole bundle can be written as

`C_(a,t_0) = U_a + ell_(a,t_0)(L)`,

`C_(a,t)-C_(a,t_0) = ell_(a,t)(L)-ell_(a,t_0)(L)`,

where

`U_a := P_a + rho_a(R)`.

Because `P_a` is uniform on `G` and independent of `(L,R)`, `U_a` is itself uniform and independent of `(L,R)`, regardless of the value of `rho_a(R)`.

Therefore, conditional on `L`, the entire bundle law depends only on an independent uniform `U_a` plus deterministic left-side differences; it is independent of `R`. Different `a` use independent pads, so the same holds jointly for every finite set of bundle coordinates. Passing to the generated countable sigma-field by the monotone-class theorem gives independence of the complete left bundle sigma-field from `R`, and hence from any right output measurable from `R`. QED.

### Interpretation

Private one-time pads correspond to `|T_a|=1`. Tail rigidity kills that case because resampling `P_a` changes only finitely many outputs.

The bundle lemma allows `|T_a|=infinity`. Then resampling one separator pad changes infinitely many check outputs, so the finite-disagreement obstruction disappears. Reusing the pad does **not** leak the far-side secret because pairwise or higher differences inside the bundle cancel both `P_a` and the common term `rho_a(R)`, leaving only left-side information.

Thus exact Bradley independence and the infinite reverse influence demanded by own-tail determinism are not logically incompatible. They force a much more rigid structure:

> **cross-cut dependence must be organized into infinite-fanout, low-rank bundles rather than privately masked checks.**

This is the materially different pivot for the next construction attempt.

## 7. New construction obligation: an infinite-fanout bundle cocycle

A full finite-state Bradley candidate would now need to realize the bundle lemma *simultaneously for every coordinate cut* while retaining remote finite-erasure reconstruction.

For each direction `i`, cut level `m`, and separator site `s` with `s_i=m+1`, the checks on (say) the left assigned to `s` should have a decomposition

`check = P_s + rho_s^(i,m)(right halfspace) + left_local_term`,

where the right-dependent term is common to every check in that bundle. The bundle must contain infinitely many output sites with positive probability so that resampling `P_s` has infinite reverse influence.

Three constraints are immediate.

1. **Finite alphabet:** each physical site stores only finitely many symbols, so infinite fanout must occur through one source symbol influencing infinitely many *other* sites, not by storing infinitely many checks locally.

2. **All cuts simultaneously:** a long check crossing many coordinate layers cannot demand a fresh private pad at each layer. Its cross-cut decomposition has to telescope/cocycle so that, at cut `m`, all dependence on the opposite side collapses to the single bundle summary `rho_s^(i,m)`.

3. **Tail recovery:** despite this rank collapse at each individual cut, the collection of many directions/cuts jointly must distinguish every wrong finite filling. This is exactly the high-order secret-sharing synergy Bradley's real-valued construction achieves through independent layers, but here it must be realized with finite symbols and infinite fanout.

The natural algebraic object is therefore no longer a matching. It is an **infinite-fanout cocycle of bundle summaries**.

A useful toy identity to target is a family of checks `C_a(x)` such that for every cut their restriction factors as

`C_a = L_a + S_cut + R_cut`,

with the same `S_cut+R_cut` for all checks in one separator bundle, while differences between bundles remain rich enough across transverse directions to recover a deleted site. Ordinary additive row/column rank-one models fail because the shared summaries become directly measurable from both halfspaces. Here the separator pad must keep each shared summary hidden from the individual sides while its infinite fanout prevents finite-refresh couplings.

This is not yet a construction; it is the new sharply defined algebraic target after closing the private-pad route.

## 9. Remaining gap and next concrete attack

The next attack should not return to private matching. It should work directly on a `d=2` **bundle cocycle** with two coordinate directions.

Concrete subproblem:

> Construct a strictly stationary finite-group-valued source/check system in which every separator bit has infinite fanout, every vertical and horizontal Bradley cut admits the rank-one bundle decomposition of Lemma 6.1, and the combined vertical/horizontal bundles give infinitely many independent tests against each wrong finite filling.

The first algebraic step is to search for a two-direction telescoping identity that makes the opposite-side contribution common within each separator bundle. If such an identity exists, the heavy-tail scale law should deliberately have infinite mean incidence; finite mean is now known to be impossible. If no such two-direction identity can exist in a broad cocycle class, that obstruction itself would be a useful next theorem.

A successful proof still has to recover *all* erased output symbols from the output exterior, not merely an underlying payload layer, and must verify the full halfspace sigma-field independence rather than pairwise independence.
