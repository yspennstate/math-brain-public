## 0. Exact target and protocol convention

For every finite total Boolean communication matrix `M in {0,1}^{X x Y}` of real rank `r`, the full target is to prove universal constants `C,c>0` such that

`D(M) <= C [log_2(r+1)]^c`,

or to produce an asymptotic family violating every fixed power of `log r`.

Alice receives a row index, Bob a column index, and a deterministic protocol is a binary transcript tree whose leaf is labelled by the output bit. `D(M)` is the minimum worst-case transcript length. The target is real rank of total Boolean matrices; approximate rank, sign rank, randomized communication, and the false log-approximate-rank analogue are different questions.

## 3. Strengthened minimum-relation normal form

The previous Corollary 7.1 can be sharpened in a way useful for exact enumeration.

### Lemma 3.1 — minimum-relation basis normal form

Assume `|V|-r=3` and `(P_k)` fails. Then there exists a maximal dissociated real basis

`S={s_1,...,s_r}`

and exactly three omitted columns `{t,u,v}` with coordinate vectors

`t=sum_i c_i s_i`, `u=sum_i a_i s_i`, `v=sum_i b_i s_i`,

where `a,b,c in {-1,0,1}^r`, such that:

1. `nu_S(t)=#{i:c_i=-1}<=floor(r/2)<=k`;
2. `#{i:a_i=-1}>=k+1` and `#{i:b_i=-1}>=k+1`;
3. `a,b` are linearly independent;
4. each of `a,b` has at least one `+1` coordinate;
5. the signed relation

   `-t + sum_{c_i=1}s_i - sum_{c_i=-1}s_i = 0`

   has globally minimum support among all nonzero signed relations of `V`;
6. if `p(c)=#{i:c_i=1}` and `n(c)=#{i:c_i=-1}`, then

   `p(c)>=n(c)+1`.

#### Proof

Take a globally minimum-support signed relation

`sum_{x in P} x = sum_{y in N} y`

and choose `t` on a smaller side; after possibly interchanging the two sides, take `t in N`, so `|N|<=|P|`. Remove `t` from the relation support. Minimum support implies the remaining support is dissociated. Extend it, while still omitting `t`, to a maximal dissociated set `S`.

The preceding nullity-three reduction shows that a violating configuration forces this `S` to be a real basis omitting exactly `{t,u,v}`, with `t` light and `u,v` independent heavy omissions. Since `S` is a real basis, each omitted column has a unique coordinate vector, and maximal dissociation forces those coordinates to be ternary.

The original minimum relation is still a representation of `t` over `S`, and uniqueness means that its coefficients are exactly the nonzero entries of `c`. Hence

`n(c)=|N|-1`, `p(c)=|P|`,

so `p(c)>=n(c)+1`, and the fundamental relation of `t` retains globally minimum support `1+||c||_0`.

The previous smaller-side estimate gives `n(c)<=floor(r/2)`. Since a violation with `rho=2` has `2(k+1)>r`, one has `k>=floor(r/2)`, hence `t` is light.

For `u`, if `a` had no `+1` coordinate, then `u` would be a nonpositive linear combination of nonnegative Boolean basis columns. Thus `u<=0` componentwise. But `u` itself is a nonzero Boolean column, so `u>=0`, impossible. Therefore `a` has a `+1`; likewise `b` has a `+1`. Heavy width in a real basis is just the number of `-1` coefficients, proving the remaining assertions. QED.

### Why item 4 matters

If the Boolean/nonnegative origin is dropped, the corresponding purely ternary statement is false already at `r=5,k=2`. One exact abstract counterexample is

`a=(-1,-1,-1,0,0)`,

`b=(-1,-1,0,-1,0)`,

`c=(1,1,0,0,-1)`.

Here the `c` relation is minimum-support and has the correct smaller-side orientation, but direct exact enumeration gives `rho(2)=2`, so `3*2=6>5`. Both heavy vectors have no positive coefficient, which is exactly what cannot occur for nonzero Boolean columns over a nonnegative Boolean basis. The verifier for this run certifies this failed stronger route explicitly.

Thus a proof of the remaining core cannot treat the coordinate problem as an arbitrary ternary matroid problem: the nonnegative Boolean origin is genuinely used.

## 4. Exact signed-relation calculus in basis coordinates

Identify `S` with the standard basis `e_1,...,e_r`. Then the configuration is

`{e_1,...,e_r,a,b,c}`.

Every signed relation is parameterized by the three coefficients on the omitted vectors:

`lambda,mu,nu in {-1,0,1}`.

Indeed, a relation has the form

`sum_i d_i e_i + lambda a + mu b + nu c = 0`,

so necessarily

`d_i=-(lambda a_i+mu b_i+nu c_i)`.

Therefore it is a signed relation exactly when

`lambda a + mu b + nu c in {-1,0,1}^r`.                 `(4.1)`

There are only `3^3-1=26` nonzero parameter triples to inspect.

This gives an exact finite test for the entire dissociation profile of one normal-form triple:

- a subset is dissociated iff it contains no support of a relation from `(4.1)`;
- a dissociated subset is maximal iff adjoining any omitted vector introduces such a support;
- for an omitted vector `w`, `nu_S(w)` is the minimum number of negative coefficients among relations supported in `S union {w}` after normalizing the coefficient of `w` to `-1`.

A maximal dissociated subset must span real rank `r`; otherwise one could adjoin a vector outside its span and remain linearly independent from it, hence remain dissociated. Since the full configuration has only `r+3` elements, only subsets of sizes `r,r+1,r+2,r+3` need be checked.

No numerical linear algebra is required.

## 5. Coordinate-orbit reduction

The remaining finite normal forms can be quotiented exactly by permutation of the basis coordinates.

For the two heavy vectors define the nine counts

`N_xy = #{i : (a_i,b_i)=(x,y)}`, `x,y in {-1,0,1}`.

These nine nonnegative integers sum to `r`. They determine the pair `(a,b)` up to coordinate permutation. Swapping the names of the two heavy omissions transposes this `3 x 3` table, so one representative from each transpose pair suffices.

For a fixed pair table, its stabilizer permutes coordinates independently inside each `(a_i,b_i)` cell. Hence a `c`-orbit is determined exactly by, for each of the nine cells, how many coordinates receive `c_i=-1,0,+1`.

The enumeration imposes only necessary conditions from Lemma 3.1 before evaluating the full profile:

- `n(a),n(b)>=k+1`;
- `p(a),p(b)>=1`;
- `a,b` noncollinear;
- `n(c)<=floor(r/2)` and `p(c)>=n(c)+1`;
- `t` distinct from every basis element and from `u,v`;
- the fundamental `c` relation has globally minimum signed-relation support.

Every remaining orbit is then checked against **all** maximal dissociated subsets using `(4.1)`.

This search is broader than Boolean realizability: it does not ask whether arbitrary ternary triples passing the necessary conditions can actually be realized by a Boolean basis. Therefore finding no violating triple is a valid certificate for the Boolean problem at those ranks.

## 7. Exact failed route: pure ternary exchange is insufficient

The abstract `r=5,k=2` triple in Section 3 satisfies all of the minimum-relation and heavy/light combinatorics except the necessary positive coefficient condition on the heavy omissions. Exact enumeration gives 32 maximal dissociated subsets; each has heavy rank exactly two. In particular the original basis has widths

`nu(a)=3`, `nu(b)=3`, `nu(c)=1`.

Thus the inequality `(P_k)` is genuinely false for arbitrary ternary vector configurations of real nullity three. Any universal continuation of this route must continue to exploit that the original columns and the basis columns are nonnegative Boolean vectors.

This also explains why a purely oriented-matroid or sign-pattern pivot proof was stalling: it was trying to prove a stronger statement that is false.
