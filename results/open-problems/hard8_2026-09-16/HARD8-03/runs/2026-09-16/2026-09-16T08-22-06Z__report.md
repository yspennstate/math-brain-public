## 3. New exact obstruction: coordinate-partition matrices

For integers `g>=2`, `h>=2`, define a Boolean matrix `M_{g,h}` as follows.

- Row set: `X=[h]^g`.
- Column set: `Y={(j,k): j in [g], k in [h]}`.
- Entry:

`M_{g,h}(x,(j,k)) = 1[x_j=k]`.

Write `v_{j,k}` for column `(j,k)`. For each fixed group `j`,

`sum_{k=1}^h v_{j,k} = 1_X`.

Thus all `g` group sums are equal.

### Proposition 3.1 (rank and complete relation space)

For `M_{g,h}`,

`rank_R(M_{g,h}) = 1 + g(h-1)`.

Moreover, every real relation

`sum_{j=1}^g sum_{k=1}^h a_{j,k} v_{j,k}=0`

has the form

`a_{j,k}=lambda_j` for all `k`, with `sum_j lambda_j=0`.

#### Proof

Evaluating the relation at row `x=(x_1,...,x_g)` gives

`sum_j a_{j,x_j}=0`

for every choice of coordinates. Fix all coordinates except `x_j` and compare two choices of `x_j`; this gives

`a_{j,k}=a_{j,k'}`

for all `k,k'`. Hence each group has a common coefficient `lambda_j`, and evaluation at any row gives `sum_j lambda_j=0`.

The relation space therefore has dimension exactly `g-1` among `gh` columns, so the rank is

`gh-(g-1)=1+g(h-1)`. QED.

### Proposition 3.2 (all maximal HLS-dissociated sets)

A subset `S` of the columns is HLS-independent, meaning all of its subset sums are distinct, **if and only if `S` contains at most one complete group** `{v_{j,1},...,v_{j,h}}`.

Consequently every maximal HLS-independent set has exactly:

- one complete group; and
- `h-1` columns from every other group.

In particular every maximal HLS-independent set has size

`h+(g-1)(h-1)=1+g(h-1)=rank(M_{g,h})`,

and the number of maximal sets is exactly

`g h^(g-1)`.

#### Proof

If `S` contains two complete groups, their equal group sums give two distinct subsets of `S` with the same sum, so `S` is not independent.

Conversely, suppose two subsets of `S` have the same sum. Subtracting them gives a relation with coefficients in `{-1,0,1}` supported on `S`. By Proposition 3.1 the coefficient is constant inside each group. If a group is incomplete in `S`, an absent column has coefficient zero, forcing the common coefficient for that entire group to be zero. If at most one group is complete, all incomplete-group coefficients vanish, and the equation `sum_j lambda_j=0` forces the remaining complete-group coefficient to vanish too. Thus the relation is trivial.

For maximality, there must be one complete group: if none were complete, one could add a missing column to some group without creating two complete groups. Once one group is complete, every other group must miss exactly one column, since if it missed at least two, one of them could be added while preserving independence. QED.

### Proposition 3.3 (forced linear local negative width)

Fix any maximal HLS-independent set `S`. Let `c=v_{j,k_0}` be one of the `g-1` omitted columns. In **every** `{-1,0,1}` representation

`c = sum_{s in S} alpha_s s`,

all `h-1` selected columns from the same incomplete group `j` have coefficient `-1`. Therefore every representation has at least `h-1` negative coefficients.

In fact the representation is unique and has exactly `h-1` negatives:

`v_{j,k_0} = sum_{k=1}^h v_{j_*,k} - sum_{k != k_0} v_{j,k}`,

where `j_*` is the unique complete group of `S`.

Hence for **every** maximal HLS set,

`max_c nu_S(c)=h-1`,

where `nu_S(c)` is the minimum number of negative coefficients in a `{-1,0,1}` representation of `c` over `S`.

#### Proof

Move a representation to one side:

`c - sum_{s in S} alpha_s s=0`.

By Proposition 3.1 the coefficients within group `j` are all equal. The omitted column `c` has coefficient `1`, so each selected column in that same group must also have relation coefficient `1`; therefore its representation coefficient is `-1`. Thus at least `h-1` negatives are forced.

Every other incomplete group has an absent column of relation coefficient zero, so its whole group coefficient is zero. The only remaining nonzero group is the unique complete group `j_*`; the condition that the group coefficients sum to zero forces its coefficient to be `-1`, which translates to representation coefficient `+1` on all its `h` members. This gives the displayed representation and proves uniqueness. QED.

### Corollary 3.4 (uniform local-width HLS route is false)

Take `g=2`. Then

`r=rank(M_{2,h})=2h-1`,

while **every** maximal HLS-independent set has local negative width

`h-1=(r-1)/2`.

Thus there is no theorem of the form

> every rank-`r` Boolean matrix has an HLS maximal dissociated set whose every column needs only `polylog(r)` negative coefficients.

The obstruction is linear in `r`.

This is stronger than the rank-4 finite obstruction in the prior checkpoint: it is an explicit infinite family, and the bad local width cannot be removed by choosing a different maximal HLS basis.

## 4. The obstruction matrices themselves are easy: exact partition number for `g=2`

The obstruction is a failure of that **proof strategy**, not evidence against log-rank.

### Proposition 4.1

For `h>=2`,

`p(M_{2,h})=2h=r+1`.

Thus the one-sided rectangle partition number is linear in rank even though every HLS maximal set has local negative width `(r-1)/2`.

#### Proof

Rows can be written `(i,j)` and columns as `L_1,...,L_h,R_1,...,R_h`, with

`M((i,j),L_k)=1[i=k]`,

`M((i,j),R_l)=1[j=l]`.

A nonempty all-1 rectangle cannot contain two distinct `L` columns, because no row has 1 in both; similarly it cannot contain two distinct `R` columns. If a rectangle contains both `L_i` and `R_j`, its row set is contained in the singleton `{(i,j)}`.

Therefore every rectangle in a partition is of one of two types:

1. a subset of the star of one single column; or
2. the two 1-cells in one row `(i,j)`, using columns `{L_i,R_j}`.

Let `F` be the set of rows whose two incidences are covered together by type-2 rectangles, and let `H=K_{h,h}\F` be the remaining bipartite edge set. The remaining incidences need at least one singleton-column rectangle for every vertex incident with `H`, and one such rectangle per active vertex is sufficient. Hence any partition has size at least

`|F|+|V(H)| = h^2-|E(H)|+|V(H)|`.

If `H` has `a` active left vertices and `b` active right vertices, then `|E(H)|<=ab`, so

`|E(H)|-|V(H)| <= ab-a-b <= h^2-2h`,

because `(a-1)(b-1)` is maximized at `a=b=h`. Thus every partition uses at least `2h` rectangles. Taking the `2h` full column-stars gives exactly `2h`, proving the claim. QED.

For general `g,h`, the trivial column-star partition gives

`p(M_{g,h}) <= gh <= 2 rank(M_{g,h})`

for `h>=2`. So the entire obstruction family is easy from the monotone viewpoint.

## 5. New theorem: a heavy-tail version of local-width positivization

The previous theorem should not require **every** column to have small negative width. Columns with large width can simply be peeled off if there are few distinct such columns.

Let

`M = sum_{i=1}^a P_i - sum_{j=1}^b N_j`

be any signed primitive-rectangle decomposition of a Boolean matrix. For a column `y`, let

`q(y) := |{j : y lies in the right side of N_j}|`.

Fix an integer threshold `k>=0`. Let

`H_k := {y : q(y)>k}`

and let `tau_k` be the number of **distinct nonzero Boolean column vectors** `M[:,y]` occurring among `y in H_k`.

### Theorem 5.1 (heavy-tail positivization)

`p(M) <= tau_k + sum_{q=0}^k binom(b,q) sum_{ell=0}^q binom(a,ell+1)`.

In particular, for `t=a+b>=2`,

`p(M) <= tau_k + (k+1)^2 t^(2k+1)`.

#### Proof

Partition the heavy columns `H_k` by equality of their full Boolean column vector. For one nonzero type `v`, all 1-cells in columns of that type form the rectangle

`{x : v_x=1} x {y in H_k : M[:,y]=v}`.

Different types use disjoint column sets, so these `tau_k` rectangles disjointly partition every 1-cell in the heavy columns.

Now restrict `M` and every signed rectangle to the complementary light column set `Y\H_k`. The same signed equality remains valid, and by construction at most `k` negative rectangles are active on any light column. Apply the previous checkpoint's local-width theorem to this restricted matrix. Because the heavy and light blocks have disjoint column sets, their rectangle partitions combine disjointly. QED.

### Corollary 5.2 (heavy HLS columns may be exceptional)

Let `S` be an HLS maximal dissociated set and, for each distinct matrix column `c`, choose a `{-1,0,1}` representation over `S` minimizing its number `nu_S(c)` of negative coefficients. If for some

`k=(log(r+1))^{O(1)}`

the number of distinct columns satisfying `nu_S(c)>k` is at most

`exp((log(r+1))^{O(1)})`,

then `log p(M)=(log(r+1))^{O(1)}`.

Indeed HLS gives `|S|=O(r log r)`, so the signed decomposition has `a,b<=|S|`, and Theorem 5.1 applies.

The coordinate-partition obstruction is harmless under this criterion: for `g=2` there is only one omitted/heavy column for every maximal set.

## 6. New recursive criterion: heavy columns may instead have low rank

Counting heavy column types is still unnecessarily strong. A potentially huge bad block can be treated recursively if it loses rank.

### Theorem 6.1 (rank-tail criterion sufficient for log-rank)

Suppose there is a nondecreasing function

`k(r)=(log(r+1))^{O(1)}`

with the following property for every Boolean matrix `M` of rank `r>=2`:

> There exists an HLS maximal dissociated column set `S` and chosen `{-1,0,1}` representations of all columns over `S` such that, if `B` is the set of columns whose representation uses more than `k(r)` negative coefficients, then
>
> `rank(M[:,B]) <= r/2`.

Then the deterministic log-rank conjecture follows.

#### Proof

Let `G=Y\B`. Restrict the HLS signed rectangle decomposition to columns `G`. Since every column in `G` uses at most `k(r)` negative basis coefficients, the previous local-width theorem gives

`p(M[:,G]) <= Q(r)`,

where, using `|S|=O(r log(r+1))`,

`log Q(r)=O(k(r) log(r+1))=(log(r+1))^{O(1)}`.

The 1-cells in the good and bad column blocks are disjoint, so

`p(M) <= p(M[:,G]) + p(M[:,B]) <= Q(r)+p(M[:,B])`.

Define `P(r)` as the supremum of `p(A)` over Boolean matrices of rank at most `r`, after identifying duplicate columns if desired. The hypothesis gives

`P(r) <= Q(r)+P(floor(r/2))`.

Iterating for at most `ceil(log_2 r)` levels and using monotonicity of `Q` yields

`P(r) <= O(log r) Q(r)`,

so

`log p(M)=(log(r+1))^{O(1)}`

for every Boolean `M`.

Apply the same bound to `J-M`, whose rank is at most `r+1`. A 1-rectangle partition of `M` together with a 1-rectangle partition of `J-M` is a monochromatic partition of all entries. The Aho–Ullman–Yannakakis deterministic simulation then gives deterministic communication complexity polynomial in the logarithm of that monochromatic partition number. Therefore

`D(M)=(log(r+1))^{O(1)}`.

QED.

### Why this criterion survives the new obstruction

For `M_{g,h}`, every maximal HLS set omits exactly one column from each of `g-1` incomplete groups, and those omitted columns are linearly independent. Thus for every threshold `k<h-1`, the heavy block has exact rank

`g-1`,

whereas

`rank(M_{g,h})=1+g(h-1)`.

For `h>=3`,

`g-1 < (1/2)[1+g(h-1)]`.

So the family that destroys uniform local width automatically satisfies the desired constant-factor heavy-rank drop. This suggests that **rank of the high-cancellation tail**, rather than its maximum width, is the more robust quantity to study.

## 7. Stronger scale-sensitive conjecture suggested by the obstruction — OPEN

The coordinate-partition family actually has approximately

`rank(heavy columns) ~ r/(h-1)`

when the local negative width is `h-1`.

This motivates the following deliberately marked conjectural strengthening:

> **Directed cancellation rank-tail conjecture.** There is an absolute constant `C` such that every finite Boolean column configuration of rank `r` admits some maximal HLS-dissociated set `S` for which, for every integer `k>=1`, the columns whose minimum negative width exceeds `k` span rank at most `C r/(k+1)` (or even this for one polylogarithmic threshold `k`).

A bound of this kind would imply Theorem 6.1 and hence solve log-rank. It is **not proved here**.

### Exact bounded evidence completed in this run

An exact exhaustive search was carried out over every subset of the 15 nonzero Boolean vectors in `{0,1}^4` (32,767 nonempty column configurations). For each configuration the search:

1. computed exact real rank;
2. enumerated every maximal dissociated subset;
3. computed exact minimum negative width of every omitted column by exhaustive `{-1,0,1}` representation search; and
4. for thresholds `k=1,2,3`, minimized the rank of the heavy columns over all maximal dissociated subsets.

No configuration violated

`rank(heavy) <= floor(r/(k+1))`.

This is finite evidence only and is not used as a theorem. A pure-Python exact reproducer is archived separately after this mathematical report.

## 8. Failed route and what changed

**Failed route:** prove that every rank-`r` Boolean matrix has an HLS maximal dissociated set with polylogarithmic maximum negative width.

**Reason it fails:** Proposition 3.3 gives an explicit infinite family with unavoidable width `(r-1)/2`, even though `p(M)=r+1`.

**Replacement route:** allow a high-cancellation tail, but require either

- few distinct heavy column types (Theorem 5.1), or
- a substantial rank drop on the heavy submatrix (Theorem 6.1).

This is a genuine narrowing of the open problem: a future proof attempt can focus on a rank-sensitive basis-selection/exchange lemma rather than trying to control every column uniformly.

## 10. Next attack

The highest-value next step is a **basis-exchange theorem for high-negative-width columns**.

A concrete target is:

> Given a rank-`r` Boolean column family and a maximal dissociated set `S` chosen to minimize a suitable lexicographic heavy-rank profile, show that the columns requiring more than `k` negatives cannot span more than, say, `r/2` dimensions for `k=polylog(r)`.

Two immediate directions:

1. derive exchange inequalities from a minimal representation
   `c=sum A-sum B`, using Boolean nonnegativity to constrain supports of `B` and determine when replacing basis elements by `c` lowers the heavy-rank profile;
2. search exact dimension `5` and structured families for a counterexample to the proposed rank-tail inequality before investing in a general proof.

A counterexample to the rank-tail criterion would only kill this route; it would not refute log-rank. Conversely, a proof of the criterion would give a complete solution through Theorem 6.1 and the existing HLS signed-rank theorem.
