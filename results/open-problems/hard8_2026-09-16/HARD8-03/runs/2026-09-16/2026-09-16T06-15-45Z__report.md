## 2. Definitions fixed for this checkpoint

A **primitive matrix** is the indicator `1_{A x B}` of a combinatorial rectangle `A x B`.

The **partition number** `p(M)` of a Boolean matrix is the minimum number of pairwise disjoint primitive matrices whose sum equals `M`; equivalently, the minimum number of disjoint rectangles partitioning the 1-entries.

A **signed rectangle decomposition** is

`M = sum_{i=1}^a P_i - sum_{j=1}^b N_j`,

where every `P_i,N_j` is primitive and the resulting entries are exactly in `{0,1}`. Here `a` is the number of positive rectangles and `b` the number of negative rectangles. Repeated rectangles are allowed in the statement; the proof below still works.

Hambardzumyan–Lovett–Shirley define `srr(M)` as the minimum `a+b` over such decompositions and prove `srr(M)=O(r log r)`.

## 3. New exact lemma: few subtractions can be positivized efficiently

### Theorem 3.1 (few-negative signed-to-positive conversion)

Suppose a nonzero Boolean matrix has a signed rectangle decomposition

`M = sum_{i=1}^a P_i - sum_{j=1}^b N_j`.

Then its 1-entries admit an explicit disjoint rectangle partition of size at most

`Q(a,b) = sum_{q=0}^b binom(b,q) 2^{b-q} binom(a,q+1)`.

In particular,

`p(M) <= Q(a,b) <= a (a+2)^b`.

This is a theorem proved below, not a numerical conjecture. I did not find this exact parameterized inequality in the bounded literature search performed for this run; **novelty is not certified**.

### Proof

Write each negative rectangle as `N_j = C_j x D_j`.

For every cell `(x,y)` and every negative rectangle `j`, give the cell one of three states:

- state `0` if `x notin C_j`;
- state `1` if `x in C_j` but `y notin D_j`;
- state `2` if `x in C_j` and `y in D_j`.

For a signature `sigma in {0,1,2}^b`, define

`X_sigma = (intersection_{sigma_j=0} (X\C_j)) intersection (intersection_{sigma_j in {1,2}} C_j)`

and

`Y_sigma = (intersection_{sigma_j=1} (Y\D_j)) intersection (intersection_{sigma_j=2} D_j)`.

There is no condition on `y` when `sigma_j=0`.

Then the nonempty sets `B_sigma = X_sigma x Y_sigma` are pairwise disjoint rectangles and partition the entire matrix: each cell has exactly one ternary signature by the three-way rule above.

Fix one such block and let

`q = |{j : sigma_j=2}|`.

Exactly `q` negative rectangles are active at every cell of this block. Let `d_+(x,y)` be the number of active positive rectangles at `(x,y)`. Since `M(x,y)` is Boolean,

`M(x,y) = d_+(x,y) - q in {0,1}`,

so throughout this block

`d_+(x,y) in {q,q+1}`.

Now take any `(q+1)`-element subset `S` of the `a` positive rectangles and intersect all rectangles in `S` with `B_sigma`. This is again a rectangle. Every cell in such an intersection has at least `q+1` active positive rectangles; the preceding bound says it has exactly `q+1`, hence `M=1` there.

Conversely, every 1-cell in `B_sigma` has exactly `q+1` active positive rectangles, so it belongs to the intersection indexed by its full active-positive set.

Finally, intersections belonging to two different `(q+1)`-subsets are disjoint. If a cell belonged to both, it would activate at least `q+2` distinct positive rectangles, impossible because `d_+ <= q+1` on the block.

Thus the 1-cells inside `B_sigma` are partitioned by at most `binom(a,q+1)` rectangles.

How many ternary signatures have exactly `q` state-2 coordinates? Choose those `q` coordinates in `binom(b,q)` ways; each of the remaining `b-q` coordinates can be state 0 or 1, giving `2^{b-q}` possibilities. Summing over `q` proves

`p(M) <= sum_q binom(b,q) 2^{b-q} binom(a,q+1)`.

For the coarse bound, use `binom(a,q+1) <= a^{q+1}`:

`Q(a,b) <= a sum_q binom(b,q) 2^{b-q} a^q = a(a+2)^b`.

QED.

## 4. Immediate consequences

### Corollary 4.1 — a concrete sufficient route to full log-rank

Suppose one can strengthen the Hambardzumyan–Lovett–Shirley signed decomposition theorem as follows: for every rank-`r` Boolean matrix `M`, there is a signed rectangle decomposition with

`a+b <= r^{O(1)}`

and

`b <= (log(r+1))^{O(1)}`.

Then the full log-rank conjecture follows.

Indeed Theorem 3.1 gives

`log p(M) <= log a + b log(a+2) = (log(r+1))^{O(1)}`,

which is exactly the signed-rectangle/partition formulation proved equivalent to log-rank in Hambardzumyan–Lovett–Shirley.

Since their actual theorem already gives `a+b=O(r log r)`, the remaining subproblem can be isolated as:

> **Few-subtractions problem.** Can every rank-`r` Boolean matrix be represented by `O(r log r)` signed primitive matrices while using only `(log r)^{O(1)}` negative primitive matrices?

This is strictly narrower than arbitrary signed-to-positive conversion and is the main proposed attack produced in this run.

### Corollary 4.2 — logarithmically many subtractions are sometimes necessary

The 2026 revision of Hambardzumyan–Lovett–Shirley records known Boolean matrices with

`log p(M) >= Omega((log r(M))^2)`.

For any such family, Theorem 3.1 implies that **every** signed decomposition with `a+b <= O(r log r)` must have

`b = Omega(log r)`.

Reason: with `a <= O(r log r)`, Theorem 3.1 gives

`log p(M) <= log a + b log(a+2) = O((b+1) log r)`.

Comparing this with `Omega((log r)^2)` forces `b=Omega(log r)`.

So the few-subtractions route cannot plausibly be improved to `O(1)` negative rectangles. The natural target scale begins at `Theta(log r)` and the full conjecture would follow from any polylogarithmic upper bound.

### Corollary 4.3 — symmetric zero-partition bound

Apply Theorem 3.1 to

`1-M = J + sum_{j=1}^b N_j - sum_{i=1}^a P_i`.

The 0-entries of `M` therefore have partition number

`p(1-M) <= (b+1)(b+3)^a`.

This makes the sign imbalance explicit: few negative terms control the positive partition, while few positive terms control the zero partition after complementing.

## 5. Secondary exact lemma: entropy of rectangle incidence gives a large monochromatic rectangle

Let

`M = sum_{i=1}^t epsilon_i 1_{A_i x B_i}`

be any signed rectangle decomposition. Put `alpha_i=|A_i|/|X|` and let `h_2` be binary entropy.

Choose a uniformly random row `x` and let `Z=(1_{x in A_1},...,1_{x in A_t})`. Then

`H(Z) <= sum_i h_2(alpha_i)`.

Hence some row-incidence pattern occurs on at least a fraction

`2^{-sum_i h_2(alpha_i)}`

of all rows (because max atom probability is at least `2^{-H(Z)}`). All rows having that pattern are identical rows of `M`, since for fixed `y`

`M(x,y)=sum_i epsilon_i Z_i 1_{y in B_i}`.

At least half the columns on that repeated row carry the same bit. Therefore `M` contains a monochromatic rectangle of density at least

`2^{-1-sum_i h_2(alpha_i)}`.

The column-symmetric statement also holds with `beta_i=|B_i|/|Y|`. Consequently a decomposition satisfying

`min(sum_i h_2(alpha_i), sum_i h_2(beta_i)) <= (log r)^{O(1)}`

would already yield the Nisan–Wigderson large-monochromatic-rectangle condition. This is another possible structural target, although the generic HLS decomposition does not presently supply such an entropy bound.

## 7. Failed / rejected routes this run

1. **Bound partition number merely from total signed rectangle rank.** This is exactly the open cancellation-to-monotonicity problem, so treating total `t=O(r log r)` alone as enough would be circular.
2. **Use only the number of row-incidence patterns.** A rank-`r` Boolean matrix already has at most `2^r` distinct rows, yielding only the trivial `O(r)` communication scale. The entropy lemma becomes interesting only if a particular short signed decomposition has much smaller incidence entropy.
3. **Assume all-negative count can be constant.** Corollary 4.2 rules this out for known partition-vs-rank hard families: logarithmically many negative rectangles are forced in every `O(r log r)`-term decomposition.
4. **Conflate the August 2026 Zhao Song lower bound with a refutation.** Song's preprint improves the known explicit lower bound but remains polynomial in `log r`; it is compatible with the log-rank conjecture.

## 9. Next attack

The next iteration should focus on the HLS construction itself. Let `S` be a maximal dissociated set of columns, so every column is a `{−1,0,1}` combination of `S`. Their proof creates one negative primitive matrix for each basis column that is used negatively somewhere. The precise next question is therefore:

> Can `S` and the witnessing subset-sum collisions be chosen so that only `(log r)^{O(1)}` members of `S` are ever used with coefficient `−1` across all columns?

Two concrete tasks:

1. Search small exact Boolean column configurations for minimum possible **global negative support** among maximal dissociated generating sets, rather than minimizing total signed rank only.
2. Try to prove a structural exchange lemma: if many basis elements are globally negative, replace a subset of them by suitable Boolean columns so as to reduce global negative support without increasing the dissociated generating set beyond `O(r log r)`.

A counterexample to this strengthened HLS route would also be useful: it would identify where the cancellation complexity is genuinely distributed and force a different conversion method.
