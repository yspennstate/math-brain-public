# HARD8-03 — Deterministic log-rank conjecture

**Run checkpoint:** 2026-09-16T11:18:00Z

## 0. Exact target and protocol convention

For every finite total Boolean communication matrix `M in {0,1}^{X x Y}` of real rank `r`, prove universal constants `C,c>0` such that

`D(M) <= C [log_2(r+1)]^c`,

or exhibit an asymptotic family of total Boolean matrices violating every fixed power of `log r`.

Alice receives a row `x`, Bob a column `y`; a deterministic protocol is a binary transcript tree whose reached leaf is labelled with the common output bit `M[x,y]`. `D(M)` is the minimum worst-case transcript length. The `+1` handles rank zero/small rank. This is the total-Boolean, real-rank conjecture, not approximate rank, sign rank, randomized communication, or the false log-approximate-rank analogue.

The current exploratory route uses the set `V` of **distinct nonzero Boolean columns** in a cancellation configuration. A subset `S subset V` is dissociated if no nonzero coefficient vector in `{-1,0,1}^S` sums to zero. For maximal dissociated `S`, every `v in V` has a signed representation

`v = sum_{a in A} a - sum_{b in B} b`, `A cap B = empty`,

and

`nu_S(v) = min |B|`,

`H_k(S) = {v : nu_S(v)>k}`,

`rho_V(k) = min_{S maximal dissociated} rank_R H_k(S)`.

The candidate constant-1 profile inequality is

`(k+1) rho_V(k) <= r := rank_R(V)`.                         `(P_k)`

It is **not** known universally. The prior checkpoint proved it for real nullity one and several larger relation geometries, and proved that a minimum-rank counterexample must have nullity at least two. The main result of this run upgrades that to **nullity at least three** by proving `(P_k)` for every Boolean configuration of real nullity at most two.

## 3. Two elementary rank-nullity lemmas

Write

`N = |V|`, `r = rank(V)`, `d = N-r`.

### Lemma 3.1 (maximal dissociated sets omit at most the real nullity)

For every maximal dissociated `S subset V`,

`span_R(S)=span_R(V)`

and consequently

`|V\S| <= d`.

#### Proof

If some `v in V` were outside `span(S)`, then `S union {v}` would still be dissociated: a signed relation with nonzero coefficient on `v` would put `v` in `span(S)`, while a relation with zero coefficient on `v` would contradict dissociation of `S`. This contradicts maximality. Thus `rank(S)=r`, hence `|S|>=r`, and

`|V\S|=N-|S| <= N-r=d`. QED.

In particular,

`rho_V(k) <= d`                                                     `(3.1)`

for every `k`, because every heavy column lies outside `S`.

### Lemma 3.2 (universal high-threshold vanishing)

If `V` is not itself dissociated, then for every maximal dissociated `S` and every `v notin S`,

`nu_S(v) <= |S|-1 <= r+d-2`.

Hence

`rho_V(k)=0` for every `k >= r+d-2`.                               `(3.2)`

#### Proof

Maximality gives at least one signed representation

`v = sum A - sum B`

with disjoint `A,B subset S`. Because all columns are nonzero and coordinatewise nonnegative, `A` cannot be empty: otherwise the nonnegative vector `v` would equal the nonpositive vector `-sum B`, impossible. Therefore `B` cannot be all of `S`, so `|B|<=|S|-1`.

As `V` is not dissociated, a maximal dissociated `S` is proper, hence `|S|<=N-1=r+d-1`. Combining gives the stated width bound. If `V` itself is dissociated, `rho_V(k)=0` trivially for all `k`. QED.

These two facts are useful beyond nullity two: any obstruction to `(P_k)` must beat the automatic heavy-rank bound `d` and must occur below the threshold `r+d-2`.

## 4. A support-minimal signed relation always creates one controlled light omission

A **signed relation** is an equality

`sum_{p in P} p = sum_{n in N_-} n`

with disjoint subsets `P,N_- subset V`, not both empty. Since columns are nonzero and nonnegative, both sides are nonempty. Call the relation support-minimal if no nonzero signed relation has strictly smaller support.

### Lemma 4.1 (one-light omission lemma)

Assume `V` is not dissociated and let

`sum_{p in P}p = sum_{n in N_-}n`

be support-minimal, with `a=|P|`, `b=|N_-|`. There exists a maximal dissociated set `S` omitting a column `t` such that

`nu_S(t) <= min(a,b)-1 <= floor((r+d-2)/2)`.

Moreover `|V\S|<=d`, so for every

`k >= min(a,b)-1`

one has

`rho_V(k) <= d-1`.                                                  `(4.1)`

#### Proof

Choose `t` from the smaller side of the relation. If `t in P`, then

`t = sum_{n in N_-}n - sum_{p in P\{t}}p`,

so the displayed representation has negative width `a-1`. If `t in N_-`, reverse the relation and obtain negative width `b-1`. Thus in either case the width is at most `min(a,b)-1`.

Support-minimality implies that the set consisting of all other columns in the relation support is dissociated: any signed relation inside it would have strictly smaller support. Extend that dissociated set greedily to a maximal dissociated set `S` in `V`. The column `t` can never be added, because the original signed relation would then be contained in the enlarged set. Hence `t notin S`, and the same displayed relation remains a legal representation over `S`; adding extra columns can only decrease the minimum width.

By Lemma 3.1, at most `d` columns are omitted. Once `t` is light, at most `d-1` omitted columns can remain heavy, proving `(4.1)`.

Finally, the relation support has size `a+b<=|V|=r+d`, so

`min(a,b)-1 <= floor((a+b-2)/2) <= floor((r+d-2)/2)`. QED.

This lemma is a general finite-nullity tool. It does not prove `(P_k)` for arbitrary `d`, but it is exactly strong enough when `d=2`.

## 5. Main theorem: the constant-1 profile inequality holds for nullity two

### Theorem 5.1

Let `V` be any finite set of distinct nonzero Boolean columns with

`rank_R(V)=r`, `|V|-r <= 2`.

Then for every integer `k>=0`,

`(k+1) rho_V(k) <= r`.                                               `(5.1)`

In particular, every finite counterexample to the candidate constant-1 profile inequality must have real nullity at least three.

#### Proof

Nullity zero is immediate because `V` is linearly independent and hence dissociated. Nullity one was classified exactly in the preceding checkpoint. It remains to treat

`|V|=r+2`.

If `V` is dissociated then `rho_V(k)=0` and there is nothing to prove. Assume it is not dissociated and put

`h=floor(r/2)`.

From Lemma 3.1,

`rho_V(k)<=2`                                                        `(5.2)`

for all `k`.

From Lemma 4.1 with `d=2`, there is a maximal dissociated set with one omitted column of width at most

`floor((r+2-2)/2)=floor(r/2)=h`.

Thus

`rho_V(k)<=1` for every `k>=h`.                                     `(5.3)`

Finally Lemma 3.2 with `d=2` gives

`rho_V(k)=0` for every `k>=r`.                                      `(5.4)`

Now split into three ranges.

1. If `0<=k<h`, then by `(5.2)`

   `(k+1)rho_V(k) <= 2(k+1) <= 2h <= r`.

2. If `h<=k<r`, then by `(5.3)`

   `(k+1)rho_V(k) <= k+1 <= r`.

3. If `k>=r`, then `(5.4)` gives zero.

This proves `(5.1)` for nullity two, and hence for nullity at most two. QED.

### Corollary 5.2 (strengthened minimal-obstruction statement)

Any finite Boolean configuration violating `(P_k)` must satisfy

`|V|-rank(V) >= 3`.

Combining with the preceding checkpoint, a minimum-rank/minimum-size obstruction must therefore be:

- coloop-free;
- linearly indecomposable;
- of real nullity at least three;
- outside the abstract equal-sum-block class;
- deletion-critical in the precise heavy-direction sense proved in the preceding checkpoint.

This materially narrows the next finite and structural search.

## 6. Why the proof is specific and why it does not solve log-rank

The proof uses three facts that line up only at nullity two:

- rank-nullity alone gives heavy rank at most `2`;
- a single support-minimal signed relation can force one of those at most two omitted columns to be light once `k>=floor(r/2)`;
- nonnegative Boolean columns force all negative widths below or equal to `r` at the last threshold.

For nullity three the analogous bounds are only `rho<=3`, then `rho<=2` after one controlled omission; this does **not** bridge the middle range required by `(P_k)`. A second simultaneously controlled omission is the missing mechanism. Therefore this checkpoint is a genuine extension of the profile theorem but not a hidden proof of the full conjecture.

The HLS recursion would need a uniform statement for arbitrary auxiliary cancellation configurations, whose nullity can be large. No new unrestricted communication upper bound is claimed here.

## 7. Failed/blocked proof route identified this run

A tempting induction on nullity is insufficient in its naive form. Deleting a column from a nullity-three configuration gives a nullity-two configuration whenever rank is preserved, and Theorem 5.1 supplies a good maximal dissociated set in the deletion. But when the deleted column is restored, the preceding checkpoint's deletion-critical theorem allows it to become a new independent heavy direction. Thus `rho` can rise by one, exactly too much in the middle threshold range. Any nullity-three proof needs either:

1. two light omissions controlled simultaneously; or
2. a theorem forcing the restored column into the old heavy span; or
3. a plateau/multi-exchange argument that reorganizes the deletion certificate without increasing heavy rank.

This explains why the new nullity-two theorem does not automatically induct.
