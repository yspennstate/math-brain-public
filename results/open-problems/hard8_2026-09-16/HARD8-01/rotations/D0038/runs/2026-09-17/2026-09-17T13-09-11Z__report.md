## 5. B6 — deform Bradley's stationarization to finitely many layers

**Goal.** Determine whether the 1994 stationary construction can be continuously deformed to a finite-state object simply by keeping finitely many translated copies.

Let `X^(j)`, `j in Z^d`, be independent copies of Bradley's binary nonstationary Proposition-1 field. Bradley's full stationary object at site `k` retains the entire countable vector

\[
\bigl(X^{(j)}_{k-j}\bigr)_{j\in\mathbb Z^d}
\]

through an injective real encoding.

Take instead a finite nonempty layer set `J subset Z^d` and retain only

\[
Y^J_k:=\bigl(X^{(j)}_{k-j}\bigr)_{j\in J}\in\{-1,+1\}^{J}.
\]

This deformation keeps two useful features **layer by layer**:

- each retained layer is lattice-halfspace one-dependent, so the finite independent product has the same separated-halfspace independence;
- each retained layer is tail deterministic, so the finite vector is tail deterministic.

The failure is strict stationarity. A spatial shift acts on the translate index as well as on the site index. Bradley obtains invariance precisely because the complete family of translates `j in Z^d` is present. A fixed finite nonempty `J` is not closed under all translations.

Randomizing a finite layer set does not supply the missing invariant “uniform shift.” There is no translation-invariant probability law on **finite nonempty subsets of `Z^d`**. Indeed, if `J` were stationary and finite almost surely, then for Følner boxes `B_n`,

\[
\frac{|J\cap B_n|}{|B_n|}\to0\quad\text{a.s.}
\]

and the ratio is bounded by one. By dominated convergence and stationarity,

\[
\mathbb P(0\in J)
=\mathbb E\frac{|J\cap B_n|}{|B_n|}\longrightarrow0.
\]

Hence `P(k in J)=0` for every `k`, and countability forces `J=emptyset` almost surely.

This is recorded only as a **route diagnosis**, not promoted as a source theorem: it kills the naive “take finitely many Bradley layers and randomize their locations” deformation. It does not rule out a fundamentally different finite-state field.

**B6 outcome:** the stationary Bradley proof cannot be reached by a finite-layer truncation. The passage from finitely many layers to all translates is discontinuous exactly at the strict-stationarity requirement.

## 6. B14 — find the group acting: why lossless spatial repacking cannot replace the nonatomic coordinate

Bradley's layer data can be indexed by pairs `(k,j) in Z^d x Z^d`, where `k` is the output site and `j` the translated-copy label. Under a spatial translation `t`, the natural action is the diagonal action

\[
(k,j)\mapsto(k+t,j+t).
\]

The difference

\[
r=k-j
\]

is invariant. Therefore the pair-index set decomposes into **countably many translation orbits**, one orbit for each `r in Z^d`.

By contrast, the physical output lattice `Z^d` under translations has one orbit. Consequently there is no deterministic translation-equivariant bijection that simply relabels all pair-indexed Bradley bits into one finite-capacity copy of `Z^d`: an equivariant bijection must preserve orbit decomposition.

The same obstruction can be viewed information-theoretically. Bradley's sitewise vector contains countably many independent binary layer coordinates before the real encoding; any lossless sitewise encoding therefore has infinite single-site Shannon information. A finite alphabet cannot be isomorphic to that site state.

Again this does **not** prove D0038 impossible. A successful finite-state construction need not be a lossless recoding of Bradley's all-layer action; it may discard most of those bits and generate tail determinism by a different global mechanism. What this analysis does prove operationally is that future work should not spend runs looking for an equivariant “clever packing” of the same complete layer array into finitely many symbols. The architecture itself has to change.

**B14 outcome:** no source movement; the direct Bradley/Olshen stationarization should be treated as a structural template for dependence geometry, not as an object that can be finitely recoded without losing information.

## 7. B26 — hunt the sporadic case: binary `d=2` hierarchical phase instead of all translates

The finite-layer obstruction leaves one qualitatively different positive mechanism: replace “all translates simultaneously” by a **stationary random hierarchy** that supplies remote coding shells at successively larger scales.

The simplest candidate is a `2`-adic/dyadic hierarchy in `d=2`: choose a translation-invariant random nested dyadic grid, use finite parity/secret-sharing constraints inside selected annuli, and arrange that every site is re-encoded at arbitrarily remote scales. This has three advantages over the failed finite-layer truncation:

1. it has a genuine translation-invariant probability law without choosing a finite global origin;
2. it uses only finitely many output symbols per site;
3. it can have unbounded, non-summable reverse influence, as the fifth run showed any FFIID-style positive construction must.

But it exposes the exact next obstruction. Let `H` denote the hierarchy. If, conditional on `H`, the left and right separated halfspaces are independent, averaging over `H` need **not** preserve independence: both halfspaces can learn the same latent hierarchy. A sufficient design condition would be much stronger:

\[
\mathcal L(X_L\mid H)=\mathcal L(X_L),\qquad
\mathcal L(X_R\mid H)=\mathcal L(X_R),\qquad
X_L\perp X_R\mid H,
\]

for every Bradley-separated pair `(L,R)` of coordinate halfspaces. Then integrating out `H` would preserve unconditional independence. At the same time, tail reconstruction must either recover the relevant hierarchy from the full exterior without making it visible to either individual side, or use a phase-oblivious decoder.

This is the most concrete positive design test produced by the six-run campaign:

> **cut-blind hierarchy test:** build a stationary finite-alphabet hierarchical code whose hierarchy may control multi-directional joint relations but leaves the marginal law of every individual separated halfspace exactly hierarchy-independent.

I did **not** find such a code in this run, and I do not promote the test as a theorem. It is a handoff target for a future fresh reassignment because it directly attacks the one feature Bradley's countable-layer construction gets for free: each independent layer has the correct cut law before the layers are packed.

**B26 outcome:** no metric movement. The `d=2` binary hierarchical construction remains the simplest positive laboratory, but the common-latent problem is now stated as an exact conditional-law requirement rather than as a vague warning about random phases.
