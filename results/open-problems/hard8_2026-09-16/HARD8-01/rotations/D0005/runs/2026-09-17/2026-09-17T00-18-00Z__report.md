## 3. Mathematical idea before computation

The preceding run reduced planar D0005 to a two-copy aggregation problem and supplied an exact refutation hierarchy, but it did not explain how to build positive couplings beyond triangles and parallelograms.

The new idea is to slice a planar convex body by parallel lines. A uniform point in the body first chooses a slice coordinate with density proportional to the slice width and then, conditional on that coordinate, is uniform on the slice interval. For a trapezoid two special things happen simultaneously:

- the slice-width function is affine, hence the slice-coordinate density is concave and therefore `n`-CM for every `n >= 3`;
- both the slice midpoint and slice width are affine functions of the slice coordinate.

The first affine identity forces the conditional interval centers to add to the correct global constant. The second affine identity makes the **total conditional interval length deterministic**, and an exact two-line inequality shows it always dominates twice the longest conditional interval. The uniform-interval joint-mixability theorem can then be applied on every realized slice tuple.

No numerical search or checker is needed for this theorem; the complete argument is on the page. B8's attempted counterexample direction produced no exact negative certificate and is not promoted as evidence.

## 4. B8 — discretize by one-dimensional convex slices

Let `C` be a nondegenerate planar trapezoid. Complete mixability and uniformity are preserved by invertible affine transformations, so choose coordinates in which the two parallel bases lie on `y=0` and `y=1`. Then

`C = {(x,y): 0 <= y <= 1, l(y) <= x <= r(y)}`,

where `l` and `r` are affine. Put

`w(y) = r(y)-l(y) = a + (b-a)y`,

where `a,b >= 0` are the two base lengths and `a+b>0`, and put

`c(y) = (l(y)+r(y))/2`.

The midpoint function `c` is also affine. The area of `C` is

`A = integral_0^1 w(y) dy = (a+b)/2`.

If `(X,Y)` is uniform on `C`, then the slice coordinate has density

`f_Y(y) = w(y)/A`, `0 <= y <= 1`,

and conditionally on `Y=y`, `X` is uniform on the interval

`I(y)=[l(y),r(y)]`.

Since `w` is affine and nonnegative, `f_Y` is a continuous concave density on its interval. Thus Puccetti-Wang-Wang Theorem 4.2 supplies, for **every `n >= 3`**, a coupling

`Y_1,...,Y_n ~ f_Y`

such that

`Y_1+...+Y_n = n mu_Y` almost surely,

where a direct integral gives

`mu_Y = E[Y] = (a+2b)/(3(a+b))`.

The rest of the proof is to lift this scalar complete mix to the horizontal interval fibers.

## 5. B25 — count the slice centers and widths twice

### Theorem 5.1 — planar trapezoid complete mixability

**Claim.** Let `C subset R^2` be any nondegenerate convex trapezoid. Then `Unif(C)` is `n`-completely mixable for every integer `n >= 3`. In particular it is `3`-CM, so it satisfies the full source range for the planar trapezoid subclass.

**Status:** `PROVED / PARTIAL SOURCE RESULT / SELF-CHECK ONLY`.

### Proof

Use the affine normalization and notation of Section 4. Fix any `n >= 3`, and choose an `n`-complete mix `(Y_1,...,Y_n)` of the slice-coordinate law, so

`sum_i Y_i = n mu_Y` almost surely.

For a realized tuple `y=(y_1,...,y_n)`, let

`I_i = I(y_i) = [l(y_i),r(y_i)]`,

with length

`w_i=w(y_i)`

and midpoint

`c_i=c(y_i)`.

Because `c` is affine,

`sum_i c_i = n c(mu_Y)`.

But `E[X|Y]=c(Y)`, so

`mu_X=E[X]=E[c(Y)]=c(E[Y])=c(mu_Y)`.

Therefore every realized interval tuple has the **same required center sum**

`sum_i c_i = n mu_X`.                                             (5.1)

Now use the affine width function. Again because `w` is affine,

`sum_i w_i = n w(mu_Y)`.                                          (5.2)

A direct substitution gives

`3 w(mu_Y) = 2(a^2+ab+b^2)/(a+b)`.                                (5.3)

Let `M=max(a,b)`. Since `w` linearly interpolates between `a` and `b`, every slice length satisfies `w_i <= M`. If `b>=a`, then

`3 w(mu_Y)-2b = 2a^2/(a+b) >= 0`.

If `a>=b`, then

`3 w(mu_Y)-2a = 2b^2/(a+b) >= 0`.

Hence in all cases

`3 w(mu_Y) >= 2M`.                                                 (5.4)

Since `n>=3`, equations (5.2)-(5.4) imply

`sum_i w_i = n w(mu_Y) >= 3w(mu_Y) >= 2M >= 2 max_i w_i`.          (5.5)

By the exact Wang-Wang criterion for uniform intervals, for each realized slice tuple `y` there exists a joint mix of

`U(I_1),...,U(I_n)`

whose constant sum equals the sum of their means. By (5.1), that constant is `n mu_X`.

It remains only to make these fiberwise choices into one probability coupling without hiding a selection gap. Put all slice intervals inside one common compact interval `K`. For each admissible `y` in the compact hyperplane section

`H={y in [0,1]^n : sum_i y_i=n mu_Y}`,

let `Gamma(y)` be the set of probability measures `gamma` on `K^n` whose `i`th marginal is `U(I(y_i))` and whose support lies on

`x_1+...+x_n=n mu_X`.

By (5.5) and Wang-Wang, every `Gamma(y)` is nonempty. It is compact in the weak topology. The graph

`{(y,gamma): gamma in Gamma(y)}`

is closed: the interval endpoints depend continuously on `y`, hence `U(I(y_i))` varies weakly continuously, while the constant-sum support condition is closed and is preserved under weak limits. Therefore this compact-valued correspondence has a Borel measurable selector by the standard Arsenin-Kunugui/Kuratowski-Ryll-Nardzewski measurable-selection theorem. Denote one such selected kernel by `y -> gamma_y`.

First sample `(Y_1,...,Y_n)` from the scalar complete mix. Conditional on the realized `Y` tuple, sample `(X_1,...,X_n)` according to `gamma_Y`. For each coordinate `i`, the conditional law of `X_i` given `Y_i=y` is `U(I(y))`. Since `Y_i` has density `w(y)/A`, the pair `(X_i,Y_i)` has constant area density `1/A` on `C`, hence is exactly `Unif(C)`. The vertical coordinates satisfy

`sum_i Y_i=n mu_Y`

and the selected horizontal coupling satisfies

`sum_i X_i=n mu_X`

almost surely. Consequently

`sum_i (X_i,Y_i) = n(mu_X,mu_Y)`

almost surely, while every coordinate pair is uniform on `C`. This is an `n`-complete mix of `Unif(C)`.

Since `n>=3` was arbitrary, the theorem holds for every `n>=3`. QED.

## 7. Exact obstruction to extending the slicing proof to every planar body

The same slice language isolates exactly what breaks beyond trapezoids.

For a general planar convex body in a fixed slicing direction, write

`C={(x,y): alpha<=y<=beta, l(y)<=x<=r(y)}`,

and define

`w(y)=r(y)-l(y)`, `c(y)=(l(y)+r(y))/2`.

Convexity makes the projection density proportional to `w`, and the source itself notes that every one-dimensional projection of a planar uniform convex-body law has a concave density. Thus the scalar projection is `n`-CM for every `n>=3` by Puccetti-Wang-Wang.

But a scalar complete mix `Y_1+...+Y_n=n mu_Y` lifts through the interval fibers only if one can simultaneously arrange

`sum_i c(Y_i)=n mu_X`,                                             (7.1)

and

`sum_i w(Y_i) >= 2 max_i w(Y_i)`                                  (7.2)

almost surely.

For a trapezoid, `c` and `w` are affine, so (7.1) is automatic and the left side of (7.2) is deterministic; Section 5 proves the required bound. For a generic quadrilateral, at least one of `c,w` is only piecewise affine in every obvious slicing normalization. For a general body they are nonlinear. Then the ordinary scalar condition `sum Y_i=constant` does not force (7.1), and even if the center condition is arranged, (7.2) is not automatic.

This is now the precise obstruction to this entire route. The simplest source-relevant case not covered by the new theorem is a **generic convex quadrilateral with no parallel sides**.
