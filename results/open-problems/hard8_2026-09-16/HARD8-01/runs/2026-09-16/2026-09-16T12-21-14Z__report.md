# 3. A universally safe first-gap shortening theorem for SI automata

Let an SI automaton have permutation letters \(P\) and simple idempotent letters \(E\). Earlier checkpoints proved that a shortest reset word can be chosen in **rank-drop-only canonical form**, with exactly \(n-1\) singular letters:
\[
w=e_1v_1e_2v_2\cdots e_{n-2}v_{n-2}e_{n-1},
\tag{1}
\]
where every \(e_i\in E\), every \(v_i\in P^*\), and each singular occurrence lowers the current rank by exactly one.

Write
\[
e_i=e_{s_i\to t_i}.
\]
Let \(g_1\in G=\langle P\rangle\) be the permutation induced by \(v_1\), and put
\[
r=s_1g_1.
\]
Immediately after \(e_1\), the image is
\[
Qe_1=Q\setminus\{s_1\}.
\]
After \(v_1\), the image is
\[
Q\setminus\{r\}.
\]
Since the next \(e_2=e_{s_2\to t_2}\) lowers rank, necessarily
\[
r\notin\{s_2,t_2\}.
\]
Therefore
\[
(Q\setminus\{r\})e_2=Q\setminus\{r,s_2\}.
\tag{2}
\]
The key point is that (2) depends on \(g_1\) only through the single state \(r=s_1g_1\).

## Theorem 1 (safe first-gap shortening)

For every synchronizing SI automaton, there is a canonical reset word of the form (1) such that
\[
\boxed{|v_1|\le |s_1G|-1\le n-1.}
\tag{3}
\]
Moreover, the shortening may be performed while leaving **the entire subset after the second singular letter unchanged**, hence preserving the original suffix of the canonical reset word.

### Proof

Start from any canonical reset word (1). Let \(r=s_1g_1\) as above. In the directed Schreier graph of the positive generators \(P\) on the orbit
\[
\mathcal O=s_1G,
\]
choose a shortest directed path from \(s_1\) to \(r\). Because \(G\) is finite and generated by \(P\), positive words already generate the whole group, so this directed Schreier graph is strongly connected. A shortest directed path is simple, hence has at most
\[
|\mathcal O|-1
\]
edges.

Let \(v_1'\) be the corresponding positive-generator word. Then
\[
s_1\overline{v_1'}=r=s_1g_1.
\]
Thus after \(e_1v_1'e_2\), formula (2) gives exactly the same image subset as after \(e_1v_1e_2\). The original suffix \(v_2e_3\cdots v_{n-2}e_{n-1}\) therefore remains valid and resets the automaton. This proves (3). \(\square\)

### Target-set strengthening

If \(R\subseteq s_1G\) is any nonempty set of first-hole positions such that every \(r\in R\) leads, after the second singular letter, to a suffix-completable canonical state, then the same argument gives
\[
\boxed{|v_1|\le |s_1G|-|R|.}
\tag{4}
\]
Indeed, a shortest path from \(s_1\) to the target set \(R\) has all preterminal vertices in the complement of \(R\), and no repeated vertex.

For the one-idempotent transitive class, if \(R_2\) is the set of states \(r\) for which the two-hole state \(\{s,r\}\) is Bellman-viable, then
\[
|v_1|\le n-|R_2|.
\tag{5}
\]
Relative to the naive \(n-1\) allowance, this produces an initial credit of at least \(|R_2|-1\).

This is the first genuinely state-dependent credit term obtained from the Bellman formulation.

# 4. Exact orbit dichotomy for synchronizing one-idempotent SI automata

Return to
\[
\mathcal A=(Q,P\cup\{e_{s\to t}\}),
\qquad G=\langle P\rangle.
\]
Let \(O_s=sG\) and \(O_t=tG\).

## Theorem 2 (orbit dichotomy)

If \(\mathcal A\) is synchronizing, exactly one of the following holds:

1. \(G\) is transitive on \(Q\); or
2. \(G\) has exactly two orbits,
   \[
   \boxed{Q\setminus\{t\}\quad\text{and}\quad\{t\},}
   \tag{6}
   \]
   with \(s\in Q\setminus\{t\}\). In particular \(t\) is fixed by every letter.

Conversely, every one-idempotent SI automaton with orbit structure (6) is synchronizing.

### Proof

If \(O_s=O_t\) and there is another \(G\)-orbit \(C\), then every permutation letter preserves \(C\), and \(e\) acts trivially on \(C\). Also \(e\) maps \(O_s\) into itself. Hence no word can merge a state of \(C\) with a state of \(O_s\), so synchronization is impossible. Therefore \(O_s=O_t\) forces transitivity.

Now suppose \(O_s\ne O_t\). Any third \(G\)-orbit is fixed setwise by every permutation and pointwise by \(e\), so again synchronization is impossible. Thus there are exactly the two orbits \(O_s,O_t\).

Because \(s\notin O_t\), the singular letter \(e\) fixes every point of \(O_t\), while each permutation letter restricts to a permutation of \(O_t\). Consequently every word restricts to a permutation of \(O_t\), and the image of \(O_t\) always has cardinality \(|O_t|\). A reset word therefore forces \(|O_t|=1\), so \(O_t=\{t\}\) and \(O_s=Q\setminus\{t\}\).

Conversely, assume (6). The state \(t\) is fixed by every letter. While a non-\(t\) state remains live, transitivity of \(G\) on \(Q\setminus\{t\}\) lets us move one live non-\(t\) state to \(s\); applying \(e\) then merges it into \(t\). Repeating synchronizes. \(\square\)

## Corollary 3 (the nontransitive branch satisfies a stronger quadratic bound)

In case (6),
\[
\boxed{\operatorname{rt}(\mathcal A)\le \frac{n(n-1)}2.}
\tag{7}
\]
Hence for \(n\ge2\), this branch satisfies the Černý square.

### Direct proof

Put \(R=Q\setminus\{t\}\), \(|R|=r=n-1\). Consider the directed Schreier graph of \(P\) on \(R\), and define
\[
B_d=\{q\in R:\text{some positive word of length at most }d\text{ maps }q\text{ to }s\}.
\]
Reverse breadth-first search in a strongly connected digraph gives
\[
|B_d|\ge \min(r,d+1).
\tag{8}
\]
If exactly \(k\) states of \(R\) are currently live, the dead set in \(R\) has size \(r-k\). By (8), \(B_{r-k}\) has at least \(r-k+1\) states, so it cannot be contained in the dead set. Hence some live state reaches \(s\) in at most \(r-k\) permutation letters; applying \(e\) removes one live non-\(t\) state.

Starting with \(k=r\) and continuing to \(k=1\), the total permutation cost is at most
\[
0+1+\cdots+(r-1)=\frac{r(r-1)}2.
\]
There are exactly \(r\) singular letters. Thus
\[
\operatorname{rt}(\mathcal A)
\le r+\frac{r(r-1)}2
=\frac{r(r+1)}2
=\frac{n(n-1)}2.
\]
\(\square\)

Therefore **any one-idempotent SI counterexample to Černý must lie in the transitive branch.**

# 5. Positive-Cayley-diameter criterion for arbitrary SI automata

Let an arbitrary synchronizing SI automaton have permutation alphabet \(P\), group \(G=\langle P\rangle\), and any number of simple idempotent letters. Define the directed positive-generator diameter
\[
\Delta_P(G)=\max_{g\in G} d_P(1,g).
\]

## Theorem 4 (diameter bound)

Every synchronizing SI automaton satisfies
\[
\boxed{
\operatorname{rt}(\mathcal A)
\le (n-1)+(n-2)\Delta_P(G).
}
\tag{9}
\]
Consequently,
\[
\boxed{\Delta_P(G)\le n-1\quad\Longrightarrow\quad
\operatorname{rt}(\mathcal A)\le(n-1)^2.}
\tag{10}
\]

### Proof

Use a canonical rank-drop-only reset word with exactly \(n-1\) singular letters and hence exactly \(n-2\) inter-singular permutation blocks. Replace each permutation block by a shortest positive-generator word inducing the same element of \(G\). Every subset image at every singular step remains unchanged. Each block then has length at most \(\Delta_P(G)\), yielding (9). Equation (10) is immediate. \(\square\)

Combining Theorem 1 with the same replacement gives the slightly sharper general estimate, for \(n\ge3\),
\[
\boxed{
\operatorname{rt}(\mathcal A)
\le 2(n-1)+(n-3)\Delta_P(G).
}
\tag{11}
\]
The threshold \(\Delta_P(G)\le n-1\) is unchanged, but (11) shows that the first inter-singular block never needs to pay a large Cayley-diameter cost.

Since a strongly connected directed Cayley graph on \(|G|\) vertices has diameter at most \(|G|-1\), another immediate corollary is
\[
\boxed{|G|\le n\quad\Longrightarrow\quad\text{Černý square for the SI automaton}.}
\tag{12}
\]
In the transitive case \(|G|=n\) means the action is regular. This recovers the regular-group square condition in the one-idempotent setting and shows that the same diameter mechanism works with multiple simple idempotent letters as well.

Thus any SI counterexample must satisfy
\[
\boxed{\Delta_P(G)\ge n.}
\tag{13}
\]

# 6. A further necessary condition in the one-idempotent transitive case

For transitive \(G\), let
\[
d=|tG_s|
\]
be the subdegree of the defect orbital containing \((s,t)\).

## Proposition 5

A synchronizing one-idempotent SI automaton with transitive \(G\) and \(d=1\) has a regular permutation group. Hence it satisfies the square.

### Proof

The defect orbital digraph has outdegree and indegree one, so it is a disjoint union of directed cycles. Earlier HARD8-01 checkpoints proved that a synchronizing SI automaton admits a spanning defect forest built from conjugates of the singular arc. Therefore the defect orbital must connect all vertices; with degree one it is a single directed \(n\)-cycle.

Every element of the point stabilizer \(G_s\) fixes the unique out-neighbor \(t\) of \(s\). It then fixes the unique out-neighbor of \(t\), and inductively every vertex on the directed cycle. Hence \(G_s\) is trivial. Transitivity then gives \(|G|=n\), so the action is regular. \(\square\)

Combining all current reductions, a one-idempotent SI counterexample would have to satisfy simultaneously
\[
\boxed{
G\text{ transitive and nonregular},\qquad
\Delta_P(G)\ge n,\qquad
|tG_s|\ge2.
}
\tag{14}
\]
These are only necessary conditions, not a contradiction.

# 7. Exact Bellman credit identity

The previous checkpoint suggested a Bellman supersolution. A useful exact reformulation is obtained by measuring **remaining square-budget credit**.

For a canonical hole state \(H\), set
\[
r(H)=n-1-|H|,
\]
which is the number of inter-singular permutation blocks still required after that state. Define
\[
\boxed{
C(H)=r(H)(n-1)-F(H).
}
\tag{15}
\]
At the terminal state \(H_*=Q\setminus\{t\}\), \(r(H_*)=0\) and \(C(H_*)=0\).

The Bellman recurrence gives the exact identity
\[
\boxed{
C(H)=
\max_{\substack{u\in G\\s,t\notin Hu\\F(Hu\cup\{s\})<\infty}}
\left[
C(Hu\cup\{s\})+(n-1)-d_P(1,u)
\right].
}
\tag{16}
\]

### Proof

For every admissible successor \(H'=Hu\cup\{s\}\), one has \(r(H')=r(H)-1\). Hence
\[
\begin{aligned}
C(H)
&=r(H)(n-1)-\min_u\bigl(d_P(1,u)+F(H')\bigr)\\
&=\max_u\bigl(r(H)(n-1)-d_P(1,u)-F(H')\bigr)\\
&=\max_u\bigl((n-1)-d_P(1,u)+C(H')\bigr).
\end{aligned}
\]
\(\square\)

For the initial one-idempotent state,
\[
F(\{s\})\le(n-1)(n-2)
\quad\Longleftrightarrow\quad
C(\{s\})\ge0.
\tag{17}
\]
Thus the square is exactly a nonnegative-credit statement in this restricted class. A transition longer than \(n-1\) spends previously accumulated credit; a shorter transition creates credit.

This formally captures the phenomenon seen in checkpoint 6, where an optimal five-state example has an unavoidable final gap of length \(5>4\) but earlier gaps save enough to keep the total within the square.

# 8. Prefix-credit formulation

For a canonical reset path let
\[
L_k=|v_1|+\cdots+|v_k|,
\qquad 1\le k\le n-2.
\]
Call the path **prefix-credit feasible** if
\[
\boxed{L_k\le k(n-1)\quad\text{for every }k.}
\tag{18}
\]
Any such path proves the square, while still allowing an individual later gap to exceed \(n-1\).

Theorem 1 proves the \(k=1\) case of (18) universally for SI automata. Checkpoint 6 proves that the stronger requirement \(|v_k|\le n-1\) for every single gap is false already at \(n=5\). Thus (18) is a strictly more flexible target and is the natural next amortized strengthening to test.

It is important that (18) is stronger than merely having total Bellman cost at most the square: a path could in principle go temporarily into debt and recover later. The finite census below tests whether such temporary debt is actually necessary in the first nontrivial one-idempotent cases.

# 9. Exact exhaustive five-state census: prefix credit never costs anything for one or two permutation letters

Fix \(Q=\{0,1,2,3,4\}\) and \(e=e_{0\to1}\). Every five-state simple idempotent is conjugate to this one. Exhaustively enumerate every unordered permutation alphabet of size one or two consisting of distinct elements of \(S_5\):
\[
120+\binom{120}{2}=7260
\]
configurations.

For each configuration the verifier performs, with exact finite arithmetic only:

1. positive-generator BFS of \(G\);
2. exact canonical hole-state Bellman recursion;
3. synchronizability test \(F(\{0\})<\infty\);
4. exact dynamic programming for the least travel among paths satisfying all prefix budgets \(L_k\le4k\);
5. exact generated-group order and positive Cayley diameter;
6. exact count \(|R_2|\) of viable two-hole states.

### Census result

Exactly
\[
\boxed{5760}
\]
of the 7260 configurations are synchronizing. For **every one** of these 5760 automata,
\[
\boxed{
\text{prefix-constrained optimum}=F(\{0\}).
}
\tag{19}
\]
In particular, every optimal canonical reset path can be chosen with cumulative permutation travel
\[
L_1\le4,\qquad L_2\le8,\qquad L_3\le12.
\]
There were **zero prefix-feasibility failures and zero optimum penalties**.

The exact Bellman-travel distribution is
\[
\begin{array}{c|rrrrrrrrr}
F(\{0\})&3&4&5&6&7&8&9&10&12\\ \hline
\#&1770&954&1272&990&492&204&60&6&12.
\end{array}
\tag{20}
\]
Thus all 5760 instances satisfy the Černý square, with exactly 12 configurations attaining the full permutation budget 12 and hence reset threshold 16.

The exact generated-group order distribution is
\[
\begin{array}{c|rrrrrrrrr}
|G|&4&5&8&10&12&20&24&60&120\\ \hline
\#&24&84&36&180&48&720&108&1140&3420.
\end{array}
\tag{21}
\]
The largest observed positive Cayley diameter is
\[
\boxed{14},
\]
so the prefix-credit phenomenon is not merely a consequence of the easy diameter criterion \(\Delta\le4\).

For viable two-hole states,
\[
\boxed{|R_2|=1\text{ in }264\text{ cases},\qquad |R_2|=3\text{ in }5496\text{ cases}.}
\tag{22}
\]

An experimentally suggested start-credit inequality is
\[
\boxed{
12-F(\{0\})\ge |R_2|-1.
}
\tag{23}
\]
It holds in all 5760 cases. The minimum margin is exactly zero. Equality occurs in precisely 18 cases:

- 12 cases with \((F,|R_2|,|G|,\Delta)=(12,1,5,4)\);
- 6 cases with \((F,|R_2|,|G|,\Delta)=(10,3,120,10)\).

Equation (23) is **only a finite experimental conjecture**, not a theorem. In particular the \(|R_2|=1\) extremal cases show that a universal proof of (23) would already have to contain the hard zero-extra-credit regime rather than bypass it.

# 10. Exact failure of the naive “cheapest next compression” rule

The classical five-state Černý automaton gives a small exact warning against greedy compression even inside the one-idempotent Bellman system.

Take the cycle
\[
a=(1,2,3,4,0)
\]
and \(e=e_{0\to1}\). Starting from the post-first-singular hole state \(H=\{0\}\), the three possible rank-dropping first transitions have exact shortest costs
\[
2,3,4
\]
and yield respectively
\[
\{0,2\},\quad\{0,3\},\quad\{0,4\}.
\]
Exact Bellman recursion gives
\[
F(\{0,2\})=F(\{0,3\})=\infty,
\qquad
F(\{0,4\})=8.
\]
So the cheapest immediate compression, cost 2, destroys the possibility of a rank-drop-only canonical completion. The cheapest **viable** first transition costs 4.

This is why Theorem 1 is phrased as shortening toward a known viable target, and why future potentials must measure viability/branch structure rather than only immediate compression length.

# 11. What was proved, what remains conjectural

## Newly proved in this checkpoint

1. **Safe first-gap theorem for arbitrary SI automata:** a canonical reset word may be chosen with first permutation gap at most \(|s_1G|-1\le n-1\), while preserving the complete subset after the second singular letter.
2. **Target-set refinement:** if \(R\) viable first targets are available in an orbit of size \(N\), a safe first gap of length at most \(N-|R|\) exists.
3. **Exact orbit dichotomy for synchronizing one-idempotent SI automata:** either \(G\) is transitive, or the only two orbits are \(Q\setminus\{t\}\) and the fixed singleton \(\{t\}\).
4. **Direct zero-branch bound:** the nontransitive branch has reset threshold at most \(n(n-1)/2\).
5. **Positive-Cayley-diameter bound for arbitrary SI automata:** \(\operatorname{rt}\le(n-1)+(n-2)\Delta_P(G)\), hence the square whenever \(\Delta_P(G)\le n-1\).
6. **Refined diameter bound:** \(\operatorname{rt}\le2(n-1)+(n-3)\Delta_P(G)\) for \(n\ge3\).
7. **One-idempotent necessary conditions:** any counterexample must have transitive nonregular \(G\), \(\Delta_P(G)\ge n\), and defect subdegree at least 2.
8. **Exact Bellman credit identity** (16), making amortization algebraically explicit.
9. **Exact finite census:** all 5760 synchronizing five-state one-idempotent automata with at most two distinct permutation letters admit an optimal prefix-credit-feasible canonical reset path.
10. **Exact greedy obstruction in \(C_5\):** the two cheapest immediate rank drops enter Bellman-dead hole states.

## Conjectural / open within this project

- The prefix-credit property (18) has **not** been proved for all SI automata.
- The finite start-credit inequality (23) has **not** been proved universally.
- None of the SI reductions covers arbitrary non-SI deterministic automata.
- No counterexample to the Černý square has been found.

The unrestricted Černý conjecture therefore remains open.

# 12. Failed routes and lessons retained

1. **Per-gap \(n-1\) cap:** already disproved by checkpoint 6; some optimal canonical schedules necessarily contain a gap longer than \(n-1\).
2. **Chain/sibling-only singular-arc moves:** checkpoint 6 gives an exact five-state example whose best such schedule has length 19 although the true reset threshold is 14.
3. **Greedy cheapest compression:** Section 10 gives an exact \(C_5\) failure; local cheapness can enter a dead canonical state.
4. **Plain group diameter:** useful when \(\Delta\le n-1\), but the five-state census has valid prefix-credit schedules even at directed positive Cayley diameter 14. The missing mechanism is state-dependent viable-branch credit.

# 13. Next attack

The strongest next target is now a **viability-aware Bellman supersolution** rather than a rank-only or metric-only cap.

For each viable hole state \(H\), define the viable successor set
\[
\mathcal V(H)=
\{Hu\cup\{s\}:s,t\notin Hu,\ F(Hu\cup\{s\})<\infty\}.
\]
The exact credit identity (16) suggests trying to prove that large metric costs can occur only when future viable branching is correspondingly rich, so that the loss
\[
d_P(1,u)-(n-1)
\]
is paid by a quantitative increase in a branch/Schreier potential.

A concrete next lemma to seek is a statewise version of the first-step target-set bound: relate the shortest transition from \(H\) into a viable successor family to the size or expansion of the set of group elements carrying \(H\) to that family. Unlike the first step, this lives in a subset-Schreier graph, so its orbit may be exponentially large; any useful theorem must exploit the simple-idempotent structure rather than the raw subset-orbit diameter.

The exact five-state census provides a finite testbed: any proposed potential should reproduce all 5760 optimum Bellman values, explain why the prefix constraint is free there, and distinguish the 18 equality cases in (23).
