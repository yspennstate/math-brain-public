## 4. Refutation-first exact block

The previous HARD8-01 checkpoint completely covered the SI class with **at most one permutation transformation** through `n=10`, for syntactic alphabet sizes 3 and 4. The next disjoint finite block is the following.

### Definition: `C_cyc2(n,q)`

After collapsing duplicate induced transformations, the support consists of:

- exactly two **distinct permutation transformations** `p_1,p_2` that lie in one common cyclic subgroup of `S_n`; and
- `k` distinct simple idempotents `e_{s->t}`, with `0<=k<=q-2`.

If the distinct support has fewer than `q` transformations, duplicate alphabet symbols restore an exactly-`q` syntactic alphabet. Duplicate letters do not alter the transition monoid or shortest reset length, so this preserves the frozen metric convention.

The search was counterexample-first: every synchronizing support in the exact finite cover below was assigned its exact reset threshold by subset BFS and tested against `(n-1)^2`.

## 5. Exact coverage theorem for this finite enumeration

This is a coverage proof for the stated finite class, not a theorem about all DFAs.

Let the two permutations lie in `<g>`, where `g` is a permutation of `n` states. State conjugation sends `g` to a canonical permutation having the same cycle type, i.e. the same integer partition `lambda` of `n`. Write

\[
o(lambda)=\operatorname{lcm}\{\text{parts of }lambda\}.
\]

The two distinct permutation transformations are then powers `g^a,g^b` with

\[
0\le a<b<o(lambda).
\]

Conversely every unordered pair of distinct powers is enumerated. Conjugating states also sends a simple idempotent `e_{s->t}` to another simple idempotent, so after fixing the canonical representative of `lambda`, enumerating every subset of the `E=n(n-1)` simple idempotents of size `k` covers every possible singular-letter choice. Different generators or residual centralizer symmetries can create duplicate tests, but cannot create an omission.

Therefore the exact number of supports visited for syntactic alphabet size `q` is

\[
N(n,q)=
\left(\sum_{lambda\vdash n}\binom{o(lambda)}2\right)
\left(\sum_{k=0}^{q-2}\binom{n(n-1)}k\right).
\]

The program independently increments its loop counters and refuses to print `ALL_EXACT_TWO_CYCLIC_PERM_CHECKS_PASSED` unless the observed total equals this formula.

For `n=8` there are 22 cycle types, `E=56`, and

\[
\sum_{lambda\vdash8}\binom{o(lambda)}2=384.
\]

Hence

\[
N(8,3)=384(1+56)=21,888,
\]

and

\[
N(8,4)=384\left(1+56+\binom{56}{2}\right)=613,248.
\]

For `n=9` there are 30 cycle types, `E=72`, and the corresponding exponent-pair count is 845. Thus

\[
N(9,3)=845(1+72)=61,685,
\]

and

\[
N(9,4)=845\left(1+72+\binom{72}{2}\right)=2,221,505.
\]

These are exhaustive cover counts for `C_cyc2(n,q)`, not isomorphism-class counts.

## 6. Exact reset-threshold certificate method

Each support is tested by exact BFS in the power automaton. The start vertex is the full subset `Q`; one BFS step applies one support transformation to the current subset. The first singleton reached therefore occurs at exactly the shortest reset-word length. If no singleton is reachable, the support is nonsynchronizing.

The implementation uses integer arrays and bit masks only. There is no floating point, random sampling, SAT/SMT timeout, heuristic cutoff, or probabilistic acceptance condition in the accepted `n=8,9` runs.

The checker also separates results by `k`, so the genuinely four-distinct-transformation case (`q=4,k=2`) is distinguishable from an exactly-four-symbol automaton obtained by duplicating a letter from a three-transformation support.
