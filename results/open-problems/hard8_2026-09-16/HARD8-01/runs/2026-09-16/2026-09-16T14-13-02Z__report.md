## 4. Refutation-first finite block

The finite search in this run was designed to find a certified counterexample inside a substantial SI subspace before attempting another structural proof.

A **simple idempotent** is a transformation `e_{s->t}`, `s!=t`, that sends `s` to `t` and fixes every other state. Define `C(n,q,<=1P)` to be the class of exactly-`q`-symbol DFAs whose set of distinct induced letter transformations consists only of simple idempotents and at most one permutation transformation.

Duplicate syntactic symbols do not affect synchronizability or reset threshold: collapsing equal transformations preserves the set of induced word transformations and word lengths after choosing one representative symbol for each support transformation. Thus an exactly-`q` automaton in this class has a distinct support of size at most `q`; conversely any nonempty support of size at most `q` can be realized with exactly `q` syntactic symbols by duplicating a support letter.

The run exhaustively searched this entire structured class for `n=8,9,10` and `q=3,4`, using exact subset BFS to compute the shortest reset distance. No violation was found.

## 5. New theorem: automata generated only by simple idempotents

### Theorem H8-01-SIMPLE-IDEMPOTENT-DIGRAPH-1 — project proof, priority not claimed

Let `A` be an `n`-state DFA, `n>=2`, whose distinct letter transformations are all simple idempotents. Build a directed graph `D` on `Q` with an arc `s->t` for every support letter `e_{s->t}`. Then:

1. `A` is synchronizing if and only if there is a vertex `r` of `D` reachable by a directed path from every vertex of `Q`.
2. Whenever `A` is synchronizing,

`rt(A)=n-1`.

### Proof

Suppose first that a word `w` resets `A` to `r`. A simple idempotent either fixes the current state or moves it along one directed arc of `D`. Therefore, following the successive states of any `q in Q` under the letters of `w` gives a directed walk from `q` to `r` after deleting stationary steps. Hence every vertex reaches `r` in `D`.

Conversely, suppose every vertex reaches some `r`. Choose for every `v!=r` one first edge on a shortest directed path from `v` to `r`. These `n-1` chosen arcs form an in-arborescence directed toward `r`: distance to `r` strictly decreases along each chosen edge, so there is no directed cycle, and every nonroot vertex has one chosen parent.

Apply the corresponding simple-idempotent letters in decreasing order of distance from `r` (children before parents). When the letter `e_{v->parent(v)}` is applied, every state that has already been merged into `v` moves with `v` to its parent, while all other current states are fixed. Inductively, after all `n-1` tree edges have been applied, every original state is at `r`. Hence `rt(A)<=n-1`.

For the reverse inequality, a simple idempotent can lower the cardinality of any current image set by at most one: it changes only the point `s`, so at most the image `s` can collide with the already-present image `t`. Starting from an image of size `n` and ending at size 1 therefore requires at least `n-1` letters. Thus `rt(A)>=n-1`, proving equality. QED.

### Immediate consequence for the present census

A synchronizing all-simple-idempotent support must contain the `n-1` distinct arcs of some spanning in-arborescence. Therefore an exactly-`q` syntactic alphabet with duplicate letters allowed cannot synchronize in the all-simple-idempotent class when `q<n-1`. In particular the zero synchronizing counts for the no-permutation `q=3,4`, `n=8,9,10` blocks below are theorem-forced, not merely empirical.

## 6. Exact coverage argument for the one-permutation block

Let `E=n(n-1)` be the number of simple idempotents and let `p(n)` be the number of integer partitions of `n`, equivalently the number of conjugacy classes of permutations in `S_n`.

For the no-permutation part, the checker enumerates every subset of the `E` simple idempotents of sizes `1,...,q`.

For the exactly-one-permutation-support part, choose one canonical permutation for every cycle type/partition of `n`. For that fixed canonical permutation enumerate every subset of the `E` simple idempotents of sizes `0,...,q-1`.

This is complete: if a structured support has a unique permutation `p`, a state relabeling conjugates `p` to the canonical representative of its cycle type. The same conjugation sends every simple idempotent `e_{s->t}` to another simple idempotent `e_{pi(s)->pi(t)}`, and every such idempotent subset is enumerated. Centralizer-equivalent subsets may therefore be tested more than once, but no state-isomorphism class in the stated structured block is omitted. The checker is an exhaustive cover, not a claim that the displayed coverage count is the number of isomorphism classes.

The formula counts are

`N_no_perm(n,q) = sum_{k=1}^q binom(E,k)`

and

`N_one_perm(n,q) = p(n) * sum_{k=0}^{q-1} binom(E,k)`.

The program independently increments loop counters and requires equality with these formulas before printing `ALL_CHECKS_PASSED`.
