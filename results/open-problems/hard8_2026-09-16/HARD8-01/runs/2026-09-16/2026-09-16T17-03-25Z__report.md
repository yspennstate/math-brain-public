## B13 — find what only increases: subset/kernel monovariants

### Idea written before any code

For a word `w`, its kernel partition on Q can only coarsen when another letter is appended: if `xw=yw`, then `xwa=ywa`. This is the most obvious monotone object attached to synchronization.

### Why this does not close the blocker

The kernel is too coarse. If appending a letter preserves rank, then the number of kernel classes does not change, hence the kernel partition itself does not change. Long portions of a shortest reset word can therefore move among same-rank images while this monovariant is frozen. That is exactly where a greedy "always reduce rank now" argument can lose information. Thus kernel coarsening alone cannot plausibly account for a sharp total of 49 steps.

The useful reformulation is not a new theorem but a search coordinate. For a fixed automaton A and rank r, form the **rank-r plateau graph** whose vertices are reachable r-subsets and whose directed edges are

\[
S\xrightarrow{a} Sa\qquad\text{only when }|Sa|=r.
\]

A compression occurs only by exiting this plateau to smaller rank. The natural quantity to inspect is the shortest plateau distance from S to a vertex possessing a rank-decreasing outgoing letter. A genuinely slow candidate must create long plateau travel at one or more ranks, not merely have a slowly coarsening kernel.

Outcome B13: **useful change of coordinates, but kernel monotonicity alone is insufficient**. Do not pursue another kernel-only lemma next run.

## B20 — find why greedy rank reduction fails

The exact local obstruction to greedy one-letter rank reduction is now isolated conceptually:

\[
|Sa|=|S|\quad\text{for every available letter }a
\]

at the current image S, even though a longer word eventually compresses S. Equivalently, the search must traverse a same-rank plateau before reaching a compression exit.

For the irreducible four-letter blocker there is a second, stronger finite structure. Write the four letters as `a_1,...,a_4`. Because deleting any one letter leaves a nonsynchronizing automaton, the standard pair-synchronization criterion gives, for each i, at least one unordered state pair `p_i` that cannot be merged by the ternary alphabet `Σ\{a_i}`. In the pair automaton this can be represented by a nonempty set `U_i` of non-diagonal pair states containing `p_i` and closed under each of the other three letters. The full four-letter automaton is synchronizing, so the missing letter is required somewhere in any escape mechanism from the corresponding ternary obstruction.

This yields a counterexample-oriented finite certificate shape rather than another restricted transformation family:

- four deleted-letter indices;
- four witness pairs `p_i` (not required to be distinct);
- four closed non-diagonal ternary pair regions `U_i`;
- four actual 8-state transformations that realize those closures;
- full four-letter subset BFS used only at the end to measure the exact reset threshold.

Outcome B20: **promising finite obstruction architecture**. It attacks the negation first and is source-valid: every irreducibly synchronizing four-letter counterexample must exhibit deleted-letter nonsynchronization witnesses of this kind. The difficulty is not existence of witnesses; it is enumerating all lifts to genuine state transformations without losing completeness.

## B14 — exploit the group acting

The symmetry group relevant to the missing cell is simultaneous state relabeling together with alphabet relabeling. For a four-letter support it acts as

\[
(\pi,\sigma):\{a_1,a_2,a_3,a_4\}\mapsto
\{\pi^{-1}a_{\sigma(1)}\pi,\ldots,\pi^{-1}a_{\sigma(4)}\pi\},
\qquad (\pi,\sigma)\in S_8\times S_4.
\]

A complete reduction must quotient this action rigorously; a heuristic hash or selected representative family is not enough.

The witness-pair formulation suggests a smaller first quotient. The four witness pairs form a four-edge colored multigraph on eight state vertices, where color i records the deleted letter whose ternary subalphabet fails on that pair. First canonicalize this finite witness pattern under `S_8 x S_4`; then, within each witness-pattern orbit, enumerate/lift transformations only modulo the stabilizer of that pattern. Overlap between different witness choices is harmless for **coverage**; the required proof obligation is that every irreducible support admits at least one witness quartet and hence lands in at least one enumerated witness orbit.

For the transformation lift, use one-hot variables `x[i,q,t]` meaning letter i maps state q to state t. Closure variables for `U_i` can enforce that each ternary letter maps every selected non-diagonal pair back into the same non-diagonal region. Any surviving full support is then checked by exact subset BFS. The plateau-escape quantity from B13/B20 is a search-order heuristic only; it must never replace exhaustive coverage.

Outcome B14: **the right symmetry target is the witness-certified irreducible cell, not another raw restricted letter family**. The remaining correctness obligation is to implement a canonical/overcovering enumeration whose completeness can be proved independently of solver behavior.
