# 2. One-idempotent SI normalization

For Sections 2–8 fix the **restricted** but important class
\[
\mathcal A=(Q,P\cup\{e\}),
\]
where every \(p\in P\) is a permutation, \(G=\langle P\rangle\le\operatorname{Sym}(Q)\), and
\[
e=e_{s\to t},\qquad s\ne t.
\]
Thus
\[
e(s)=t,\qquad e(x)=x\quad(x\ne s).
\]
Write
\[
d_P(1,u)=\min\{|w|:w\in P^*,\ \bar w=u\}
\]
for the positive-generator distance from the identity to \(u\in G\).

Checkpoint 4 proved that a shortest rank-\(k\) word in any SI automaton may be chosen with exactly \(n-k\) singular letters, every one of which lowers rank. In the present one-idempotent case, every shortest reset word therefore has a canonical representative with exactly \(n-1\) occurrences of \(e\).

There is also no need for any permutation prefix before the first \(e\): if
\[
w=v_0 e v_1 e\cdots e v_{n-2}e,
\qquad v_i\in P^*,
\]
then
\[
Qv_0=Q
\]
because \(v_0\) is a permutation, so deleting \(v_0\) leaves the image after the first \(e\) unchanged and only shortens the word. Hence a shortest canonical reset word may be written
\[
\boxed{
w=e v_1 e v_2 e\cdots v_{n-2}e.
}
\tag{1}
\]

This simple normalization is important below: the entire permutation budget is carried by the \(n-2\) **inter-singular** blocks.

# 3. Exact hole dynamics

For a subset \(S\subseteq Q\), call
\[
H=Q\setminus S
\]
its hole set. Immediately after a rank-dropping use of \(e\), the source \(s\) is a hole while the target \(t\) remains live. Thus every canonical post-singular hole set satisfies
\[
\boxed{s\in H,\qquad t\notin H.}
\tag{2}
\]

Suppose the current hole set is \(H\), then a permutation block induces \(u\in G\). Before the next singular letter, the holes are
\[
Hu:=\{hu:h\in H\}.
\]
The next \(e\) lowers rank iff both \(s\) and \(t\) are live, i.e.
\[
\boxed{s,t\notin Hu.}
\tag{3}
\]
When this holds, \(e\) deletes exactly \(s\), so the new hole set is
\[
\boxed{H'=Hu\cup\{s\}.}
\tag{4}
\]
In particular \(|H'|=|H|+1\), and (2) is restored.

This is the exact finite-state dynamics behind the one-idempotent problem.

# 4. Exact Bellman potential for the one-idempotent class

Let
\[
\mathcal H=
\{H\subseteq Q:s\in H,\ t\notin H\}.
\]
The unique terminal hole set of size \(n-1\) is
\[
H_*:=Q\setminus\{t\}.
\]
Define \(F:\mathcal H\to\mathbb N\cup\{\infty\}\) recursively by
\[
F(H_*)=0,
\tag{5}
\]
and, for \(H\ne H_*\),
\[
\boxed{
F(H)=
\min_{\substack{u\in G\\s,t\notin Hu}}
\left[d_P(1,u)+F(Hu\cup\{s\})\right].
}
\tag{6}
\]
If no admissible transition eventually reaches \(H_*\), the value is \(\infty\).

Because every transition increases \(|H|\) by one, (6) is an acyclic Bellman recursion over at most \(2^{n-2}\) hole states.

## Theorem 1 (exact hole-Bellman formula)

For every synchronizing one-idempotent SI automaton,
\[
\boxed{
\operatorname{rt}(\mathcal A)
=(n-1)+F(\{s\}).
}
\tag{7}
\]

### Proof

Take a shortest reset word in canonical form (1). Let \(u_i\in G\) be the permutation induced by \(v_i\). Since every \(e\) lowers rank, the successive hole sets obey (3)–(4), beginning with
\[
H_1=\{s\}
\]
and ending with \(H_{n-1}=H_*\). Replacing each \(v_i\) by a shortest positive-generator word inducing the same \(u_i\) preserves every subset image and cannot increase length. Hence the total number of permutation letters in an optimal canonical reset word is at least the Bellman minimum \(F(\{s\})\), and equality can be achieved by concatenating shortest words for the minimizing transitions in (6).

There are exactly \(n-1\) copies of \(e\). Therefore the reset threshold is (7). \(\square\)

### Why this is useful

The Černý square for this class is exactly the assertion
\[
\boxed{
F(\{s\})\le(n-1)(n-2).
}
\tag{8}
\]
So a non-greedy proof can be sought as an explicit **supersolution/potential** dominating the Bellman recursion, rather than as a uniform bound on each individual rank-reduction gap.

This is the main conceptual shift of this checkpoint.

# 5. Sibling transporter law

Checkpoint 5 proved the chain law. Here is its exact sibling analogue.

Let
\[
e=e_{s\to t},\qquad f=e_{s'\to t'}.
\]
Suppose the current cumulative permutation prefix is \(g\), so the current conjugated defect arc has target
\[
p=tg^{-1}.
\]
Append a permutation word inducing \(u\in G\), then use \(f\). The next target is
\[
t'u^{-1}g^{-1}.
\]

## Lemma 2 (sibling / common-target transporter law)

The next defect arc has the **same target** \(p\) iff
\[
\boxed{tu=t'.}
\tag{9}
\]

### Proof

The targets agree iff
\[
t'u^{-1}g^{-1}=tg^{-1}.
\]
Cancel \(g^{-1}\), then right-multiply by \(u\):
\[
t'=tu.
\]
\(\square\)

Thus both basic local tree moves reduce a two-coordinate condition to one state:

- **chain:** current target = next source iff \(tu=s'\);
- **sibling:** current target = next target iff \(tu=t'\).

The remaining endpoint is then determined by the chosen transporter.

# 6. Exact endpoint suborbits

Assume now that \(G\) is transitive and, for clarity, return to the single idempotent \(e=e_{s\to t}\).

Define the unbounded local endpoint sets
\[
C_\infty=
\{tu^{-1}:u\in G,\ tu=s\}
\tag{10}
\]
for chain steps, and
\[
S_\infty=
\{su^{-1}:u\in G,\ tu=t\}
\tag{11}
\]
for sibling steps.

Let
\[
d=|tG_s|.
\tag{12}
\]
This is the subdegree of the orbital containing \((s,t)\). Since an orbital digraph of a transitive group has equal indegree and outdegree,
\[
|sG_t|=|tG_s|=d.
\tag{13}
\]

## Theorem 3 (local endpoint sets are suborbits of size \(d\))

One has
\[
\boxed{|C_\infty|=|S_\infty|=d.}
\tag{14}
\]
Moreover neither set contains \(t\).

### Proof

For siblings, the condition \(tu=t\) means \(u\in G_t\), hence
\[
S_\infty=sG_t,
\]
which has size \(d\) by (13). Since \(s\ne t\), this orbit does not contain \(t\).

For chains choose one \(u_0\in G\) with \(tu_0=s\), possible by transitivity. Every solution of \(tu=s\) is of the form
\[
u=h u_0,\qquad h\in G_t.
\]
Therefore
\[
C_\infty
=
\{tu_0^{-1}h^{-1}:h\in G_t\}
=xG_t,
\qquad x:=tu_0^{-1}.
\]
The ordered pair \((t,x)\) is in the same orbital as \((s,t)\), because
\[
(t,x)u_0=(s,t).
\]
Hence the fiber over first coordinate \(t\) in that orbital has size \(d\), proving \(|C_\infty|=d\). If \(xG_t\) contained \(t\), then the orbital would contain a diagonal pair, impossible because it contains the off-diagonal pair \((s,t)\). \(\square\)

## Corollary 4 (2-transitive collision obstruction disappears algebraically)

If \(G\) is 2-transitive, then \(d=n-1\), and
\[
\boxed{C_\infty=S_\infty=Q\setminus\{t\}.}
\tag{15}
\]
Thus, ignoring generator length, from any canonical stage with \(h\le n-2\) holes one can always choose a chain-compatible or sibling-compatible next endpoint outside the hole set.

In particular, a 2-transitive one-idempotent SI automaton always admits, **at the level of group elements**, a collision-free Hamiltonian defect chain and also a collision-free star schedule. The hard obstruction is therefore not orbit geometry but **positive-generator metric cost**.

This resolves the collision question left open in checkpoint 5 for the 2-transitive case.

# 7. Bounded endpoint-growth profile

For \(L\ge0\) define the bounded sets
\[
C_L=
\{tu^{-1}: tu=s,\ d_P(1,u)\le L\},
\tag{16}
\]
\[
S_L=
\{su^{-1}: tu=t,\ d_P(1,u)\le L\},
\tag{17}
\]
and the mixed local profile
\[
M_L=C_L\cup S_L,
\qquad
\mu(L)=|M_L|.
\tag{18}
\]
Note that \(s\in S_0\), so \(\mu(L)\ge1\).

The hole dynamics gives an immediate counting theorem.

## Theorem 5 (mixed local-profile certificate)

Suppose that for every
\[
h=1,2,\ldots,n-2
\]
there exists an integer \(L_h\ge0\) such that
\[
\boxed{\mu(L_h)>h.}
\tag{19}
\]
Then
\[
\boxed{
\operatorname{rt}(\mathcal A)
\le
(n-1)+\sum_{h=1}^{n-2}L_h.
}
\tag{20}
\]

### Proof

After the first \(e\), the hole set is \(H=\{s\}\). Assume inductively that \(|H|=h\), \(s\in H\), and \(t\notin H\).

Because \(|M_{L_h}|>h=|H|\), choose
\[
x\in M_{L_h}\setminus H.
\]

If \(x\in S_{L_h}\), choose \(u\) with
\[
tu=t,\qquad su^{-1}=x,
\qquad d_P(1,u)\le L_h.
\]
Since \(u\) fixes \(t\), the condition \(t\notin H\) implies \(t\notin Hu\). Also
\[
s\in Hu\iff su^{-1}\in H\iff x\in H,
\]
which is false. Hence the next \(e\) lowers rank.

If instead \(x\in C_{L_h}\), choose \(u\) with
\[
tu=s,\qquad tu^{-1}=x,
\qquad d_P(1,u)\le L_h.
\]
Now
\[
s\in Hu\iff su^{-1}=t\in H,
\]
which is false, while
\[
t\in Hu\iff tu^{-1}=x\in H,
\]
which is also false. Again \(e\) lowers rank.

In either case (4) produces a new hole set of size \(h+1\), still containing \(s\) and excluding \(t\). Iterating through \(h=n-2\) reaches \(H_*\). There are \(n-1\) singular letters and the permutation blocks have total length at most \(\sum L_h\). \(\square\)

For a 2-transitive group, \(\mu(L)\to n-1\), so define the exact hitting levels
\[
\lambda_h=
\min\{L:\mu(L)>h\},
\qquad 1\le h\le n-2.
\tag{21}
\]
Then
\[
\operatorname{rt}(\mathcal A)
\le(n-1)+\sum_{h=1}^{n-2}\lambda_h.
\tag{22}
\]
Because \(\mu(L)\) is nondecreasing and eventually equals \(n-1\), double counting gives the exact area identity
\[
\boxed{
\sum_{h=1}^{n-2}\lambda_h
=
\sum_{L\ge0}\bigl((n-1)-\mu(L)\bigr).
}
\tag{23}
\]
Hence a static sufficient condition for the Černý square in the 2-transitive one-idempotent case is
\[
\boxed{
\sum_{L\ge0}\bigl((n-1)-\mu(L)\bigr)
\le(n-1)(n-2).
}
\tag{24}
\]

This profile certificate is generator-sensitive and permits some local transport lengths to exceed \(n-1\), provided faster growth at other radii compensates.

# 8. Exact five-state obstruction: no uniform \(n-1\) inter-singular cap

Return to the checkpoint-5 automaton
\[
Q=\{0,1,2,3,4\},
\]
\[
p=(0,1,2,4,3),
\qquad
q=(1,2,3,0,4),
\qquad
e=e_{0\to2}.
\tag{25}
\]
The two permutation letters generate \(S_5\), so this is a particularly strong test of the high-transitivity route.

Exact subset BFS gives
\[
\boxed{\operatorname{rt}=14<16.}
\tag{26}
\]

The new exact hole-Bellman values are as follows. We list only hole sets satisfying \(0\in H\), \(2\notin H\):

```text
H               F(H)   one optimal next permutation cost
{0}               10          3
{0,1}             10          4
{0,3}              7          2
{0,4}              6          1
{0,1,3}            5          5
{0,1,4}            5          5
{0,3,4}            6          6
{0,1,3,4}          0          terminal
```

Thus Theorem 1 gives
\[
4+F(\{0\})=4+10=14,
\]
matching the exact reset threshold.

A particularly important consequence is that **every canonical rank-drop-only reset word has a final permutation block of length at least five**. Indeed, immediately before the last singular letter there are exactly three holes, and the only possibilities are
\[
\{0,1,3\},\quad
\{0,1,4\},\quad
\{0,3,4\}.
\]
To make the final \(e\) rank-dropping, the permutation block must send the three-hole set to
\[
Q\setminus\{0,2\}=\{1,3,4\}.
\]
The exact shortest positive-generator lengths are respectively
\[
\boxed{5,\ 5,\ 6.}
\tag{27}
\]
Explicit shortest generator-index words \([p,q]=[0,1]\) are:

```text
{0,1,3} -> {1,3,4}: [1,1,1,0,1]       length 5
{0,1,4} -> {1,3,4}: [1,0,1,0,1]       length 5
{0,3,4} -> {1,3,4}: [1,1,0,1,0,1]     length 6
```

Therefore:

## Corollary 6

For the automaton (25), there is **no** canonical reset word in which every inter-singular permutation block has length at most
\[
n-1=4.
\tag{28}
\]
Nevertheless the automaton resets in length \(14<16\).

So the tempting lemma

> after every rank drop, another rank drop can always be arranged within \(n-1\) permutation letters along one globally successful canonical schedule

is false, even for a five-state automaton whose permutation group is the full \(S_5\).

This makes the need for amortization mathematically unavoidable rather than merely suggestive.

# 9. No universal rank-only stage-cap proof can reach the square

The preceding obstruction can be paired with the classical \(5\)-state Černý automaton.

Call a **rank-only stage-cap scheme** at \(n=5\) a triple of nonnegative bounds
\[
b_1,b_2,b_3
\]
with the property that every synchronizing five-state one-idempotent SI automaton admits a canonical reset word
\[
e v_1 e v_2 e v_3 e
\]
with
\[
|v_h|\le b_h
\quad(h=1,2,3).
\]
To prove the Černý square by such a scheme one would need
\[
b_1+b_2+b_3\le12.
\tag{29}
\]

## Theorem 7 (rank-only stage caps are impossible)

No such universal triple satisfying (29) exists.

### Proof

First consider the classical \(5\)-state Černý automaton, presented as one cyclic permutation generator together with \(e_{0\to1}\). Its reset threshold is exactly
\[
(5-1)^2=16.
\]
Every group element is a power of the 5-cycle and has positive-generator distance at most \(4\). Therefore any canonical reset word promised by a stage-cap scheme with total cap at most \(12\) would have total permutation length at most \(12\), hence total word length at most \(16\). Since the true threshold is exactly \(16\), equality must hold throughout. In particular its three inter-singular permutation blocks must each have length exactly \(4\), and therefore
\[
 b_1\ge4,\qquad b_2\ge4,\qquad b_3\ge4.
\tag{30}
\]

Now apply the same universal scheme to the \(S_5\) automaton (25). By (27), its final inter-singular block necessarily has length at least \(5\), so
\[
b_3\ge5.
\tag{31}
\]
Combining (30) and (31) gives
\[
b_1+b_2+b_3\ge4+4+5=13,
\]
contradicting (29). \(\square\)

### Interpretation

This rules out an entire proof architecture, not merely one guessed inequality. Any successful SI proof at the square must use information beyond the current rank/hole count. It must maintain a **state-dependent credit/potential** or another globally correlated invariant that allows a stage costing more than \(n-1\) to be repaid by cheaper stages elsewhere.

The exact Bellman potential (6) gives the natural state space on which to search for such an invariant.

# 10. One-coordinate local schedules are also insufficient

One might hope to repair the failed per-gap cap by allowing arbitrary lengths but insisting that every transition between consecutive singular arcs is one of the two one-coordinate moves:

1. chain: previous target = next source;
2. sibling: previous target = next target.

For the same \(S_5\) automaton (25), exact dynamic programming over all such child-before-parent rank-dropping schedules gives
\[
\boxed{
\text{minimum one-coordinate-local reset length}=19>16.
}
\tag{32}
\]
One optimal local schedule has conjugated arcs
\[
(0\to2),\quad
(4\to2),\quad
(2\to3),\quad
(1\to3),
\tag{33}
\]
with permutation gaps
\[
5,5,5.
\tag{34}
\]
The transitions are sibling, chain, sibling respectively.

By contrast the unrestricted exact reset threshold is \(14\). Hence **even the union of the chain and sibling one-coordinate mechanisms is not a universal square proof strategy**. The actual short word must sometimes make a genuinely two-coordinate jump, then compensate by an exceptionally cheap later jump.

This sharpens the end-of-checkpoint-5 conclusion: the missing theorem is not merely “add sibling moves.” It is a true **branch-aware, two-coordinate amortization theorem**.

# 12. Exact bounded-length pair interpretation

The bounded chain set also has a precise ordered-pair interpretation. For a current cumulative prefix \(g\) and a desired new endpoint \(q\), a chain-compatible word \(u\) satisfies
\[
tu=s,
\qquad
qg u=t.
\]
Hence
\[
(t,qg)u=(s,t).
\tag{36}
\]
Therefore \(q\) is available within \(L\) chain letters iff the ordered pair \((t,qg)\) is at directed Schreier distance at most \(L\) from \((s,t)\).

Similarly, for a sibling-compatible new source \(q\),
\[
tu=t,
\qquad
qg u=s,
\]
so
\[
(t,qg)u=(t,s).
\tag{37}
\]
Thus bounded local endpoint growth is literally a cross-section of a ball in the ordered-pair Schreier graph.

Equations (36)–(37) connect the Bellman hole dynamics to the pair-orbit metric from checkpoints 4–5 without paying the full independent orbit-size bound at every step.

# 15. Next attack

The next bounded iteration should search for an explicit **Bellman supersolution** \(\Phi(H)\) satisfying a telescoping inequality of the form
\[
\min_{\substack{u\in G\\s,t\notin Hu}}
\left[d_P(1,u)+\Phi(Hu\cup\{s\})\right]
\le \Phi(H)
\tag{38}
\]
with
\[
\Phi(\{s\})\le(n-1)(n-2),
\qquad
\Phi(H_*)=0.
\tag{39}
