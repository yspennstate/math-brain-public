## 4. Exact structured class certified here

A **simple idempotent** is a transformation \(e_{s\to t}\), \(s\ne t\), that sends \(s\) to \(t\) and fixes every other state.

Define \(\mathcal C_{\le2\mathrm{cyc}}(n,q)\) to consist of exactly-\(q\)-symbol DFAs whose set of distinct induced transformations has:

- zero, one, or two permutation transformations;
- every nonpermutation transformation a simple idempotent;
- if two permutation transformations occur, they lie in one common cyclic subgroup of \(S_n\).

Duplicate syntactic letters are allowed in the frozen alphabet convention. Collapsing duplicate transformations leaves synchronizability and shortest reset length unchanged, while any support of size at most \(q\) can be realized with exactly \(q\) symbols by duplicating support letters. Therefore support enumeration is exact for this restricted syntactic class.

The prior HARD8-01 report certified the two-common-cyclic-permutation branch for \(n=8,9\) and the earlier report certified the at-most-one-permutation branch through \(n=10\). This run:

## 5. Coverage proof: exactly two common-cyclic permutation transformations

Suppose the two distinct permutation transformations lie in \(\langle g\rangle\), where \(g\in S_n\). Conjugating states sends \(g\) to a canonical permutation having the same cycle type \(\lambda\vdash n\). If

\[
o(\lambda)=\operatorname{lcm}(\text{parts of }\lambda),
\]

then the two transformations become \(g^a,g^b\) for some

\[
0\le a<b<o(\lambda).
\]

Conversely every unordered pair of distinct powers is enumerated. The same conjugation maps each simple idempotent to another simple idempotent, and every relevant idempotent subset is enumerated. Hence the checker is an exhaustive cover; residual centralizer symmetries may create duplicate tests but cannot create omissions.

Writing \(E=n(n-1)\) for the number of simple idempotents, the exact support count is

\[
N_{\mathrm{cyc2}}(n,q)=
\left(\sum_{\lambda\vdash n}\binom{o(\lambda)}2\right)
\left(\sum_{k=0}^{q-2}\binom{E}{k}\right).
\]

The program computes the loop count independently and exits without the PASS marker if it differs from this formula.

## 7. Exact reset-threshold method and checks

All reported reset thresholds come from BFS in the subset automaton starting at the full state set. Applying a letter to a subset produces its exact image subset. BFS layers therefore give word length, and the first singleton reached has exactly the shortest reset length.

The accepted code uses only integer arrays and bit masks. There is:

- no floating point;
- no random sampling;
- no SAT timeout interpreted as a certificate;
- no heuristic cutoff;
- no inferred nonexistence from runtime.

The optimized C++ checker precomputes every relevant subset image but does not alter the mathematical state graph. A separate Python implementation replays the new \(k=2\) extremals without using the C++ BFS code. That replay is a **self-check**, not an independent research audit.
