# 2. One-gap setup recalled

Let `T` be a tree with `m` edges and let

`f:V(T)->{0,...,m}`

be graceful. Fix a threshold `L`. For the unique edge of old difference `d`, let `c_d(L)=1` exactly when that edge crosses the label cut

`{f<L} | {f>=L}`.

A **one-gap certificate** `(f,L,k,r)` means

`c_d=0` for `d<=k`,

`c_d=1` for `d>k`,

and the root `r` satisfies one of the two boundary conditions

* low branch: `f(r)=L-k-1`, or
* high branch: `f(r)=L+k`.

If `s` consecutive labels are inserted at `L`, all old high-side labels are shifted by `s`. The previous checkpoint proved that the old edge differences then become exactly

`1,...,k`

and

`k+s+1,...,m+s`.

Hence every edge involving the `s` new vertices must realize the missing interval

`B_{k,s}={k+1,...,k+s}`.

# 3. Exact rooted-forest absorber formulation

Let `F` be a forest on `s` vertices with connected components

`F_1,...,F_c`,

and choose one root `rho_i` in each component. We intend to graft `F` onto the old root `r` by adding precisely the `c` edges

`r rho_i`, `1<=i<=c`.

Because `F` has `s-c` internal edges, the graft adds exactly

`(s-c)+c=s`

edges, as it must.

## Definition 3.1 — cutoff-`k` rooted-forest absorber

A bijection

`lambda:V(F)->{0,...,s-1}`

is a **cutoff-`k` absorber labeling** if

`{ |lambda(u)-lambda(v)| : uv in E(F) }`

union

`{ k+1+lambda(rho_i) : 1<=i<=c }`

is exactly

`{k+1,...,k+s}`

with no repetitions.

This definition is not merely sufficient; it is the exact one-block condition.

## Theorem 3.2 — branch-independent absorber equivalence

Let `(f,L,k,r)` be a one-gap certificate on `T`, and let rooted forest `F` have `s` vertices. Then the graft of `F` at `r` can be gracefully labeled by inserting one consecutive block of `s` labels at `L` **if and only if** `F` has a cutoff-`k` absorber labeling.

### Proof: low branch

Assume first

`f(r)=L-k-1`.

Insert the new block

`L,L+1,...,L+s-1`,

shift each old label at least `L` upward by `s`, and label each new vertex `v` by

`L+lambda(v)`.

Old edges already occupy

`1,...,k`

and

`k+s+1,...,m+s`.

An internal edge `uv` of `F` has difference

`|lambda(u)-lambda(v)|`.

An attachment edge `r rho_i` has difference

`(L+lambda(rho_i))-(L-k-1)`

`=k+1+lambda(rho_i)`.

Therefore the new edges fill the missing interval `B_{k,s}` exactly if and only if `lambda` is a cutoff-`k` absorber labeling.

### Proof: high branch

Now suppose

`f(r)=L+k`.

After inserting the block, the old root shifts to

`L+k+s`.

Given an absorber labeling `lambda`, label the new vertices by the **reflected offsets**

`lambda*(v)=s-1-lambda(v)`.

Internal differences are unchanged by reflection. For an attachment root,

`(L+k+s)-(L+lambda*(rho_i))`

`=k+s-(s-1-lambda(rho_i))`

`=k+1+lambda(rho_i)`.

Thus exactly the same absorber equation is obtained. The converse follows by reversing the calculation.

QED.

This removes a nuisance from the composition problem: low and high one-gap branches do not require two absorber theories. Reflection makes them identical.

# 4. Pinned graceful augmentation: an exact equivalence

The absorber equation itself is an ordinary graceful-labeling problem after adding one controlled apex.

Given rooted forest `F` with roots `rho_1,...,rho_c`, define `A_k(F)` as follows:

1. add a new apex `a`;
2. join `a` to every root `rho_i`;
3. add `k` additional pendant leaves `p_1,...,p_k`, all adjacent to `a`.

Since the apex joins the `c` components of `F`, `A_k(F)` is a tree. It has

`s+k+1`

vertices and

`s+k`

edges.

## Theorem 4.1 — pinned-augmentation equivalence

The rooted forest `F` has a cutoff-`k` absorber labeling if and only if `A_k(F)` has a graceful labeling `psi` satisfying

`psi(a)=0`,

`{psi(p_1),...,psi(p_k)}={1,...,k}`,

and

`psi(V(F))={k+1,...,k+s}`.

### Proof

Suppose `lambda` is an absorber labeling. Define

`psi(a)=0`,

assign the pendant apex leaves the labels `1,...,k`, and put

`psi(v)=k+1+lambda(v)`

for every `v in V(F)`.

This is a bijection onto

`{0,...,k+s}`.

The `k` special apex leaves give edge differences `1,...,k`.

Every internal edge of `F` keeps the difference

`|lambda(u)-lambda(v)|`.

Every apex-root edge has difference

`psi(rho_i)=k+1+lambda(rho_i)`.

By the absorber equation, all edges involving `F` therefore have differences exactly

`k+1,...,k+s`.

So `psi` is graceful.

Conversely, from any pinned graceful labeling with the stated vertex-label sets, define

`lambda(v)=psi(v)-(k+1)`

on `F`. Removing the special differences `1,...,k` from the graceful edge spectrum leaves exactly `k+1,...,k+s`, and these are precisely the internal-forest and apex-root differences in the absorber equation.

QED.

## Interpretation

The one-gap exactness problem has now been reduced to a pinned ordinary graceful-labeling problem on a very structured augmentation. This is useful for two reasons.

* Existing pinned graceful-labeling methods can be imported directly if their hypotheses match `A_k(F)`.
* Conversely, obstructions to this pinned labeling immediately obstruct the corresponding exact gap absorber.

The reduction is exact and does not assume the forest components are isomorphic.

# 5. Suffix-root absorbers and root transfer

To iterate the method, gracefulness alone is not enough. We also want the new labeling to carry another one-gap certificate at a new root.

A particularly clean condition is that the component roots occupy a terminal block of the inserted offsets.

## Definition 5.1 — suffix-root absorber

A cutoff-`k` absorber labeling of a rooted `s`-vertex forest with `c` components is **suffix-root** if

`{lambda(rho_i):1<=i<=c}={s-c,...,s-1}`.

Then the attachment differences are exactly

`k+s-c+1,...,k+s`.

Since the full new spectrum is `k+1,...,k+s`, the internal forest differences are forced to be

`k+1,...,k+s-c`.

Because an internal difference is at most `s-1`, suffix-root absorption automatically requires

`k+s-c <= s-1`,

or equivalently

`c>=k+1`.

This recovers the previous component lower bound inside the stronger transfer framework.

## Theorem 5.2 — suffix-root transfer theorem

Let `(f,L,k,r)` be a one-gap certificate. Let `F` be an `s`-vertex rooted forest with `c` components and a suffix-root cutoff-`k` absorber labeling `lambda`. Define

`K = k+s-c`.

Then grafting every component root of `F` to `r` gives a graceful tree carrying a new one-gap certificate of cutoff `K` at the unique component root `u` satisfying

`lambda(u)=K`.

Such a root exists because

`s-c <= K=s-c+k <= s-1`

when `c>=k+1`.

### Low-branch proof

Use the low-branch block labeling from Theorem 3.2 and keep threshold `L`.

The crossing status by edge-difference is now explicit:

* old differences `1,...,k` are noncrossing;
* internal forest differences `k+1,...,K` are entirely within the inserted block and are noncrossing;
* attachment differences `K+1,...,k+s` cross from the old low root into the inserted block;
* shifted old crossing differences `k+s+1,...,m+s` remain crossing.

Therefore the new crossing vector is exactly

`0^K 1^(m+s-K)`.

The distinguished component root has new label

`L+lambda(u)=L+K`,

which is the high-branch boundary label for cutoff `K` at threshold `L`.

Hence it is a new one-gap certificate.

### High-branch proof

Use the reflected absorber offsets

`lambda*(v)=s-1-lambda(v)`

and threshold

`L'=L+s`.

All inserted vertices lie below `L'`; all shifted old high-side vertices lie at least `L'`. Internal forest edges are noncrossing, attachment edges are crossing, and the same difference split as above gives cutoff `K`.

The root `u` with original offset `lambda(u)=K` has reflected offset

`s-1-K`.

Hence its new label is

`L+s-1-K`

`=(L+s)-K-1`

`=L'-K-1`,

which is the low-branch boundary label for cutoff `K`.

QED.

## Relation to the previous balanced-broom theorem

The balanced-broom construction from the previous checkpoint has exactly

`c=k+1`

new-vertex components. In that minimal case

`K=k+s-(k+1)=s-1`,

so the new distinguished root is the component root at the maximum inserted offset `s-1`.

Thus Theorem 5.2 strictly contains the prior root-transfer calculation: the earlier construction was one special suffix-root absorber.

# 6. The first repeated-component packing problem: identical centred stars

We now solve exactly a repeated-rooted-component case motivated by LPW's `F x q` structure.

Fix integers

`k>=0`, `h>=2`.

Let `S_h` denote the `h`-vertex star rooted at its centre. Write

`t=h-1`

for its number of leaves.

Let `F` consist of `c` disjoint copies of this rooted star. Thus

`s=ch`,

there are `c` roots, and there are

`N=ct=s-c`

nonroot leaves.

We ask:

> For which multiplicities `c` does `F` admit a suffix-root cutoff-`k` absorber?

The answer is exact.

## Theorem 6.1 — sharp repeated-centred-star absorber theorem

For `h>=2`, a forest of `c` identical `h`-vertex stars rooted at their centres admits a suffix-root cutoff-`k` absorber **if and only if**

`c=2k+1`.

The proof has two independent parts: an exact sum obstruction and a constructive permutation.

---

## 6.2 Necessity from the total internal-difference sum

Assume a suffix-root absorber exists.

Because the roots occupy the top `c` offsets, their labels are

`N,N+1,...,N+c-1`.

Every other vertex is a leaf, so the leaf labels are exactly

`0,1,...,N-1`.

Since each root is the centre of a star, every internal forest edge joins a root to a leaf. Therefore every root label is larger than every leaf label, and the total sum of internal edge differences is independent of how leaves are assigned among the roots.

Let

`R=sum_{j=0}^{c-1}(N+j)`

be the sum of root labels and

`L=sum_{ell=0}^{N-1} ell`

the sum of leaf labels.

Each root is incident with exactly `t=h-1` internal edges, while every leaf appears exactly once. Hence the actual total internal-difference sum is

`S_actual = t R - L`.

Now

`N=ct`,

`R=cN+c(c-1)/2`,

`L=N(N-1)/2`.

A suffix-root absorber must have internal edge differences exactly

`k+1,k+2,...,k+N`,

because there are `N=s-c` internal edges. Thus the required sum is

`S_required = N(2k+N+1)/2`.

Direct simplification gives

`S_actual-S_required`

`= c(h-1)(c-2k-1)/2`.

Because `c>0` and `h-1>0`, equality is possible only when

`c=2k+1`.

This proves necessity.

### Immediate consequence

The **minimal** component count `c=k+1` from the previous component bound is impossible for repeated nontrivial centred stars whenever `k>0`, because

`k+1 != 2k+1`.

The simplest example is `k=1`: two identical rooted edges cannot form a suffix-root absorber, but three can. The obstruction is not a search failure; it is the exact sum identity above.

# 7. Sufficiency: a closed-form absorber for `c=2k+1`

Now put

`c=2k+1`,

`t=h-1`,

`N=ct`,

`s=ch=N+c`.

Index the `c` star roots by

`j=0,...,c-1`

and give root `j` the offset

`lambda(R_j)=N+j`.

Thus the roots occupy exactly the top `c` offsets, as required for a suffix-root absorber.

Index all `N` leaves by pairs

`(b,r)`,

where

`0<=b<=t-1`,

`0<=r<=c-1`,

and assign the leaf offset

`lambda(ell_{b,r})=bc+r`.

These are exactly the bottom offsets `0,...,N-1`.

The only remaining task is to decide which root receives each leaf.

Define the cyclic permutation

`sigma(r) = r+k (mod c)`,

represented in `{0,...,c-1}`.

Define

`j(r)=r+sigma(r)-k`.

This is an ordinary integer, not a congruence class. It always lies in `{0,...,c-1}`. Indeed, because `c=2k+1`,

* for `0<=r<=k`, `sigma(r)=r+k`, hence
  
  `j(r)=2r`,
  
  producing all even indices `0,2,...,2k`;
* for `k+1<=r<=2k`, `sigma(r)=r-k-1`, hence
  
  `j(r)=2r-2k-1`,
  
  producing all odd indices `1,3,...,2k-1`.

Thus `j(r)` is a permutation of all `c` root indices.

For every block index `b`, attach leaf `ell_{b,r}` to root `R_{j(r)}`.

Because `j(r)` is a permutation, each root receives exactly one leaf from each block `b`, hence exactly `t=h-1` leaves. Therefore every component is indeed a copy of the rooted star `S_h`.

## Exact internal differences

For leaf `(b,r)`, the internal edge difference is

`lambda(R_{j(r)})-lambda(ell_{b,r})`

`=N+j(r)-bc-r`

`=ct + (r+sigma(r)-k) - bc-r`

`=(t-b)c + sigma(r)-k`.

Since `c=2k+1`,

`c-k=k+1`.

Writing

`q=t-1-b`,

we obtain

`(t-b)c + sigma(r)-k`

`= q c + (c-k) + sigma(r)`

`= q c + k+1 + sigma(r)`.

As `b` varies, `q` runs through `0,...,t-1`. As `r` varies, `sigma(r)` runs through `0,...,c-1`. Therefore the internal edge differences are exactly

`k+1,k+2,...,k+ct`

`=k+1,...,k+N`,

with no repetition.

## Exact attachment differences

The attachment edge from the old one-gap root to star root `R_j` has the absorber difference

`k+1+lambda(R_j)`

`=k+1+N+j`.

As `j=0,...,c-1`, these are exactly

`k+N+1,...,k+N+c`

`=k+N+1,...,k+s`.

Combining internal and attachment differences gives

`k+1,...,k+s`.

Hence `lambda` is a suffix-root cutoff-`k` absorber.

This proves sufficiency and completes Theorem 6.1.

QED.

# 8. Explicit repeated-star root-transfer theorem

Combining Theorems 5.2 and 6.1 gives a direct composition rule.

## Theorem 8.1

Let `(f,L,k,r)` be any one-gap certificate. Let `h>=2`, and set

`c=2k+1`.

Graft onto `r` exactly `c` disjoint copies of the `h`-vertex star, joining `r` to the centre of each new star.

Then the enlarged tree is graceful. Moreover, one of the new star centres becomes a one-gap root with cutoff

`K=k+s-c`

where `s=ch`. Equivalently,

`K = k + c(h-1)`

`= k + (2k+1)(h-1)`.

The distinguished new root is the star centre whose absorber offset is

`N+k`,

where `N=c(h-1)`.

### Multiplicative form

The cutoff recurrence simplifies to

`2K+1=(2h-1)(2k+1)`.

Proof:

`2K+1`

`=2[k+(2k+1)(h-1)]+1`

`=(2k+1)+2(2k+1)(h-1)`

`=(2k+1)(2h-1)`.

This multiplicative identity is useful for iteration.

# 9. Iterated exact family

Starting from any one-gap certificate with cutoff `k_0`, choose arbitrary integers

`h_1,h_2,...,h_q >=2`.

At stage `i`, attach exactly

`c_i=2k_i+1`

copies of the rooted `h_i`-vertex star to the current distinguished root, and transfer the root by Theorem 8.1.

Then every intermediate tree is graceful and

`2k_{i+1}+1=(2h_i-1)(2k_i+1)`.

Therefore

`2k_q+1=(2k_0+1) product_{i=1}^q (2h_i-1)`.

This gives an explicit recursively branching graceful family generated by exact block absorptions. The construction is deterministic and involves no search once the initial certificate is fixed.

Again, this is recorded as a composition consequence, not as a claim that the resulting tree family is absent from the classical graceful-labeling literature.

# 10. Why the sharp multiplicity matters for the LPW splitting route

Letzter–Pokrovskiy–Williams prove a splitting lemma in which, after deleting a controlled set, one obtains many copies of the same rooted forest. An exact proof cannot simply discard the unmatched copies as their almost-graceful argument does.

The repeated-star theorem shows both promise and danger for using that structure exactly.

### Positive lesson

Repeated isomorphic rooted pieces really can be packed into one consecutive difference block in closed form. For centred stars, the packing is fully explicit and automatically propagates a one-gap certificate.

### Negative lesson

Multiplicity is arithmetic. For nontrivial centred stars, a suffix-root cutoff-`k` absorber is possible only at the precise multiplicity

`2k+1`.

In particular, the component-count lower bound `c>=k+1` is far from sufficient. Even the apparently natural minimal multiplicity `c=k+1` is impossible when `k>0`.

Thus an exact LPW-style composition must control not only component shape and number but also how the multiplicities interact with the current cutoff state.

### Useful new state variable

For the star absorber, the odd quantity

`omega=2k+1`

behaves multiplicatively:

`omega -> (2h-1) omega`.

This suggests that a future exact decomposition theorem might profit from tracking an odd multiplicative state rather than only the additive cutoff `k`.

# 11. Relation to pinned graceful trees

The repeated-star absorber has a clean pinned-augmentation interpretation.

For `c=2k+1`, augment the `c` rooted stars by

* a new apex `a` joined to all `c` star centres;
* `k` additional leaves at `a`.

The resulting tree has a graceful labeling in which

* `a` has label `0`;
* the `k` special apex leaves have labels `1,...,k`;
* the star forest occupies labels `k+1,...,k+s`;
* the star centres occupy the top `c` labels within that forest interval.

For the smallest nontrivial example `k=1`, `c=3`, `h=2`, this is a spider with one length-1 leg and three length-2 legs. The formula gives an exact apex-zero graceful labeling. This specific example lies inside recently studied spider territory; it is included only as the smallest witness of the general absorber formula.

# 12. Failed route resolved exactly

The prior checkpoint proposed an interval-packing theorem for repeated rooted components. A tempting first guess was that the component lower bound

`c>=k+1`

might be close to sufficient when the components are highly symmetric.

The repeated-centred-star theorem disproves that guess sharply.

For every `k>0` and every nontrivial rooted star size `h>=2`, the multiplicity

`c=k+1`

fails by a fixed, nonzero sum deficit. More precisely, if roots occupy the top `c` offsets then

`S_actual-S_required`

`=c(h-1)(c-2k-1)/2`.

At `c=k+1`, this equals

`-k(k+1)(h-1)/2`,

so no relabeling or matching of leaves can repair the deficit.

The correct multiplicity is `2k+1`, for which the deficit vanishes and the explicit cyclic construction succeeds.

This is a completed obstruction-and-repair calculation rather than a timeout or finite search observation.

# 15. Next attack

The next useful target is the same sharp classification for repeated rooted **paths**.

For a fixed rooted path `H`, let `c` copies be the new forest and impose the suffix-root condition. The root labels are then fixed to the top `c` offsets, while the internal differences must form one consecutive interval. Unlike stars, the total internal-difference sum is no longer independent of how the remaining labels are placed, so a more refined invariant is needed.

Two concrete approaches are now natural.

1. **Cut-sum / transport formulation.** Express
   
   `sum_{uv in E(F)} |lambda(u)-lambda(v)|`
   
   as the sum, over label cuts, of the number of forest edges crossing each cut. The required consecutive difference interval determines the total exactly. For repeated paths, the cut-crossing profile may give a sharp multiplicity obstruction analogous to `c=2k+1`.
2. **Pinned augmentation search with exact certificates.** By Theorem 4.1, the absorber question is equivalent to a pinned graceful labeling of `A_k(F)`. Small rooted paths can therefore be searched exactly without inventing a new solver encoding. Any discovered pattern should then be converted to a symbolic construction or an exact impossibility invariant.

A second direction is to ask whether LPW's repeated rooted forest can be grouped into batches whose component multiplicities match an evolving cutoff state. The star case suggests tracking the odd state `2k+1`, because exact absorption multiplies that state by an odd factor.

No claim in this report closes the full conjecture.
