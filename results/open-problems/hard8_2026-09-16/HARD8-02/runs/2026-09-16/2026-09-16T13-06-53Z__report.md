## 2. Absorber setup and the inherited defect identity

Take `c` disjoint endpoint-rooted paths

`r_i -- m_i -- l_i`.

A suffix-root cutoff-`k` absorber is a bijection

`lambda:V(F_c)->{0,...,3c-1}`

such that

* the roots receive exactly `{2c,...,3c-1}`;
* the `2c` internal edge differences are exactly `{k+1,...,k+2c}`.

The checkpoint

`hard8_2026-09-16/HARD8-02/runs/2026-09-16/2026-09-16T11-25-23Z__report.md`

proved the universal necessary identity

`c(c-2k-1)=3E+R`,                                      (2.1)

where

`E = sum_i min(lambda(m_i),lambda(l_i)) - c(c-1)/2 >= 0`

and `R` is the total leaf-edge difference over those paths on which the middle gets the larger nonroot label.

Set

`q:=c-(2k+1)`.

The previous run handled `q=1`. Here `q=2`, so write

`h:=k+1`,

`c=2k+3=2h+1`.                                         (2.2)

The required edge spectrum is

`{h,h+1,...,5h+1}`.                                    (2.3)

The defect identity becomes

`2c=3E+R`.                                              (2.4)

The construction below has `E=0` and exactly two reversed leaf pairs whose differences sum to `2c`.

## 3. A quick obstruction: strict lower-leaf/upper-root splitting is impossible for q=2

The preceding checkpoint proved that if the leaf edges were exactly the lower consecutive half

`{k+1,...,k+c}`

and the root-middle edges were exactly the upper consecutive half

`{k+c+1,...,k+2c}`,

then the total reversed leaf weight `N` would satisfy

`N = c(c-2k-1)/4 = cq/4`.                              (3.1)

For `q=2` this gives

`N=c/2`.

But `c=2k+3` is odd, so the right-hand side is a half-integer while `N` is an integer. Therefore:

> **No q=2 absorber can use the strict lower-leaf/upper-root split.**

The explicit construction below uses the minimum possible amount of spectrum interleaving: its leaf spectrum differs from the lowest `c` target colors by one exchange.

# 4. Universal q=2 construction for h>=2

Fix `h>=2`, put

`c=2h+1`,

and index the paths by

`i in {0,1,...,2h}`.

The nonroot labels are `0,...,4h+1`; the root labels are `4h+2,...,6h+2`.

## 4.1 Pair the nonroot labels by the doubling permutation

Define

`pi(i)=2i mod c`,                                      (4.1)

with residues represented in `{0,...,2h}`.

Pair the low label `i` with the high label

`H_i=c+pi(i)`.                                         (4.2)

Because `c` is odd, multiplication by `2` is a permutation modulo `c`; hence the pairs use every nonroot label exactly once.

The magnitude of the leaf edge on path `i` is

`d_i=H_i-i=c+pi(i)-i`.                                 (4.3)

There are two cases.

For `0<=i<=h`, no wrap occurs in (4.1), so

`pi(i)=2i`,

and

`d_i=c+i`,

which yields

`{2h+1,2h+2,...,3h+1}`.                               (4.4)

For `h+1<=i<=2h`, one wrap occurs, so

`pi(i)=2i-c`,

and therefore

`d_i=i`,

which yields

`{h+1,h+2,...,2h}`.                                   (4.5)

Thus the complete leaf spectrum is exactly

`L={h+1,h+2,...,3h+1}`.                               (4.6)

Relative to the lowest `c` target colors

`{h,h+1,...,3h}`,

this performs precisely the single exchange

`h -> 3h+1`,

increasing the leaf-color sum by exactly

`(3h+1)-h=2h+1=c`.                                    (4.7)

This is the q=2 counterpart of the one-swap q=1 geometry from the previous checkpoint.

## 4.2 Orient exactly two leaf pairs backwards

Reverse the orientation only on paths

`i=h` and `i=h+1`.

That is, for these two paths the high endpoint becomes the middle; on every other path the low endpoint is the middle.

At `i=h`,

`pi(h)=2h`,

so

`H_h=4h+1`,

`d_h=3h+1`.                                            (4.8)

At `i=h+1`,

`pi(h+1)=1`,

so

`H_{h+1}=2h+2`,

`d_{h+1}=h+1`.                                         (4.9)

Hence the total reversed leaf weight is

`R=(3h+1)+(h+1)=4h+2=2c`.                             (4.10)

Every pair still has one endpoint in `{0,...,c-1}`, so the pair minima are exactly `0,...,c-1`; consequently `E=0`. Equation (2.4) is therefore met exactly.

The middle-label set is

`M=({0,...,2h}\{h,h+1}) union {2h+2,4h+1}`.          (4.11)

## 4.3 The required root spectrum

The full target (2.3) minus the leaf spectrum (4.6) is

`R_target={h} union {3h+2,3h+3,...,5h+1}`.            (4.12)

We now assign every root exactly once and realize exactly this set.

### Special path i=h

Its middle is `4h+1`. Give it root

`5h+1`.

The resulting root-edge difference is

`(5h+1)-(4h+1)=h`.                                    (4.13)

Since roots have the form

`2c+a=4h+2+a`,

this special root has root index

`a=h-1`.                                               (4.14)

### Extra reversed path i=h+1

Its middle is `2h+2`. Give it root index

`a=h+2`,

hence root

`r=2c+(h+2)=5h+4`.                                    (4.15)

Because `h>=2`, this lies inside `{4h+2,...,6h+2}`. Its root-edge difference is

`(5h+4)-(2h+2)=3h+2`.                                 (4.16)

Thus (4.13) and (4.16) realize the exceptional value `h` and the bottom value of the long root interval.

It remains to realize

`{3h+3,...,5h+1}`                                     (4.17)

on the other `2h-1` paths while using every remaining root index exactly once.

---

## 4.4 Base doubling assignment for the ordinary middle labels

The remaining middle labels are

`M_0={0,...,h-1} union {h+2,...,2h}`.                 (4.18)

Introduce the shift index set

`D_0={-(h-1),..., -1,0,1,...,h-1}`.                  (4.19)

Associate to each `s in D_0` the middle

`mu(s)=s` if `s>=0`,

`mu(s)=c+s` if `s<0`.                                 (4.20)

This is a bijection from `D_0` onto `M_0`.

The base assignment would use root index

`a_0(s)=mu(s)+s`.                                      (4.21)

For `s=0,...,h-1`, these are the even indices

`0,2,...,2h-2`.

For `s=-1,...,-(h-1)`, these are the odd indices

`2h-1,2h-3,...,3`.

Therefore the base assignment uses exactly

`{0,...,2h}\{1,2h}`.                                 (4.22)

It also gives root-edge difference

`(2c+a_0(s))-mu(s)=2c+s`,

so its shift spectrum is exactly `D_0`.

The only issue is that the full construction has already reserved root indices

`h-1` for the special path and `h+2` for the extra path. For `h>=3`, both occur in the base set (4.22), while the two unused indices `1` and `2h` are precisely what we need in their place.

A four-entry trade fixes this without changing the shift spectrum `D_0`.

---

## 4.5 Even h trade

First let

`h=2r`.

For `h=2`, no trade is needed: the base omissions `{1,2h}={1,4}` are already exactly `{h-1,h+2}`. This case is therefore complete directly from (4.21), together with the two reserved roots.

Now assume `h>=4`, so `r>=2`.

Define a permutation `psi` of `D_0` by leaving every shift fixed except

`psi(-(r+1)) = r`,

`psi( r+1 ) = -r`,

`psi(-r)     = -(r+1)`,

`psi( r)     = r+1`.                                  (4.23)

For each `s in D_0`, assign the root index

`a(s)=mu(s)+psi(s)`.                                   (4.24)

Because (4.23) merely permutes four members of `D_0`, the shift spectrum remains exactly `D_0`.

The four changed root indices are computed explicitly:

* `s=-(r+1)`: `mu=3r`, so `a=3r+r=4r=2h`;
* `s=r+1`: `mu=r+1`, so `a=(r+1)-r=1`;
* `s=-r`: `mu=3r+1`, so `a=(3r+1)-(r+1)=2r=h`;
* `s=r`: `mu=r`, so `a=r+(r+1)=2r+1=h+1`.

Under the base assignment these four roots had been

`h-1, h+2, h+1, h`,

respectively. Thus the trade replaces exactly the two forbidden base roots

`h-1,h+2`

by exactly the two previously missing roots

`1,2h`,

while retaining `h,h+1`.

Hence the ordinary paths use precisely

`{0,...,2h}\{h-1,h+2}`.                               (4.25)

---

## 4.6 Odd h trade

Now let

`h=2r+1>=3`,

so `r>=1`.

Again leave all shifts fixed except

`psi(-r)       = -(r+1)`,

`psi( r)       = r+1`,

`psi(-(r+1))   = r`,

`psi( r+1)     = -r`.                                 (4.26)

The four new root indices are:

* `s=-r`: `mu=3r+3`, hence `a=3r+3-(r+1)=2r+2=h+1`;
* `s=r`: `mu=r`, hence `a=r+(r+1)=2r+1=h`;
* `s=-(r+1)`: `mu=3r+2`, hence `a=3r+2+r=4r+2=2h`;
* `s=r+1`: `mu=r+1`, hence `a=(r+1)-r=1`.

Their base roots were

`h+2,h-1,h,h+1`,

respectively. Thus, exactly as in the even case, the trade replaces `h-1,h+2` by `1,2h` and leaves all other root indices unchanged. Therefore (4.25) again holds.

Since (4.26) is a permutation of four shifts in `D_0`, the ordinary shift spectrum is still exactly `D_0`.

---

## 4.7 Root spectrum and completion of the proof

For every ordinary middle, the root-edge difference is

`2c+psi(s)=4h+2+psi(s)`.

Because `psi(D_0)=D_0`, these differences are exactly

`{4h+2-(h-1),...,4h+2+(h-1)}`

`={3h+3,...,5h+1}`.                                  (4.27)

The extra path `i=h+1` contributes `3h+2` by (4.16), and the special path `i=h` contributes `h` by (4.13). Thus the full root spectrum is exactly

`{h} union {3h+2,...,5h+1}`,                          (4.28)

which is the complement (4.12) of the leaf spectrum.

The ordinary paths use every root index except `h-1,h+2` by (4.25); the special and extra paths use exactly those two missing indices. Hence every root label `{2c,...,3c-1}` appears exactly once.

The nonroot pairing already used every label `{0,...,2c-1}` exactly once. Therefore all `3c` vertex labels are distinct and exhaust `{0,...,3c-1}`.

Finally, (4.6) and (4.28) are disjoint and have union

`{h,h+1,...,5h+1}`

`={k+1,...,k+2c}`.

This proves the q=2 absorber theorem for every `h>=2`, equivalently every `k>=1`.

# 5. The remaining small case h=1 (k=0,c=3)

The uniform root assignment above deliberately assumes `h>=2` because the extra root `5h+4` would otherwise fall outside the suffix root block. The sole missing parameter pair has a direct certificate.

Take the three rooted paths `(root,middle,leaf)` to be

`(8,2,0)`,

`(6,1,5)`,

`(7,4,3)`.

The vertex labels are exactly `{0,1,...,8}`; the roots are exactly `{6,7,8}`. The leaf-edge differences are

`2,4,1`,

and the root-edge differences are

`6,5,3`.

Thus the complete edge spectrum is exactly

`{1,2,3,4,5,6}`.

Therefore `(c,k)=(3,0)` is also a suffix-root cutoff-0 absorber.

Combining this certificate with Section 4 proves:

> **Theorem 5.1. For every integer `k>=0`, `c=2k+3` endpoint-rooted copies of `P_3` admit a suffix-root cutoff-`k` absorber.**

# 6. What this adds to the cumulative absorber program

The project now has exact constructions at

`q=0,1,2`.

Equivalently, for every `k>=1`, all three multiplicities

`c=2k+1, 2k+2, 2k+3`

are feasible. At `k=0`, `c=1` and `c=3` are feasible while `c=2` is the previously proved exceptional impossibility.

The q=2 construction also achieves a particularly simple spectrum geometry:

* lowest `c` target colors: `{h,...,3h}`;
* actual leaf colors: `{h+1,...,3h+1}`.

Thus only one color crosses the leaf/root boundary. Since the strict split is impossible by Section 3, this is the minimum possible number of crossing colors.

The construction uses a complete-mapping/orthomorphism motif on the odd cyclic group: `pi(i)=2i mod (2h+1)` simultaneously gives a permutation and a complete signed displacement pattern. The root assignment is another doubling-type displacement system plus a four-entry trade repairing the two suffix-root holes. This algebraic viewpoint looks more promising for `q=3` than ad hoc search.

This remains a theorem about a very specific rooted forest absorber. A route from these absorber layers to all trees still needs a decomposition/repair theorem that produces the relevant repeated endpoint-rooted `P_3` pieces while controlling the unused labels and colors. No such universal bridge is claimed here.

# 9. Failed / closed routes in this iteration

1. **Strict spectrum split.** Closed universally for q=2 by the half-integral reversal-sum obstruction.
2. **Unrepaired doubling root assignment.** The natural map `a_0(s)=mu(s)+s` misses root indices `1,2h` but uses the two reserved indices `h-1,h+2`. It therefore collides with the two reversed special paths for every `h>=3`.

# 10. Next attack

The next exact target is the third excess layer

`q=3`,

that is

`c=2k+4`.

The q=1 and q=2 formulas now suggest a more systematic approach than unconstrained search:

1. force `E=0` and solve the defect budget `R=cq=3c` by a small controlled reversal set;
2. design the low-high pairing using an affine/complete-mapping permutation so that the leaf spectrum differs from the lowest `c` target colors by the smallest possible number of exchanges;
3. express the root assignment as a signed displacement system on an interval/cyclic group;
4. repair the finite set of suffix-root collisions by a bounded trade whose form depends only on a small congruence class of `c`.

A stronger prize would be an extension theorem `(c,k)->(c+1,k)` beyond the exceptional `(2,0)` obstruction. Such an extension would bootstrap the now-known q=0,1,2 seeds into all larger multiplicities and would be much more useful for eventual tree decomposition/absorption.
