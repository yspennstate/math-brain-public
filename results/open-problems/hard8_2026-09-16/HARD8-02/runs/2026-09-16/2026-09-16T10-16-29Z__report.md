# 2. Recalled absorber language

Let `F` be a rooted forest on `s` vertices with component roots `rho_1,...,rho_c`. At cutoff `k`, an absorber labeling is a bijection

`lambda:V(F)->{0,...,s-1}`

such that the multiset union

`{ |lambda(u)-lambda(v)| : uv in E(F) }`

and

`{ k+1+lambda(rho_i) : 1<=i<=c }`

is exactly

`{k+1,...,k+s}`.

A **suffix-root absorber** additionally satisfies

`{lambda(rho_i)}={s-c,...,s-1}`.

The previous checkpoint proved that inserting such an absorber into any cutoff-`k` one-gap certificate yields another graceful tree and transfers the certificate to a new root with new cutoff

`K=k+s-c`.

Thus the present task is to construct exact suffix-root absorbers for useful repeated rooted components.

---

# 3. Root-extremal graceful motifs

Let `H` be a tree on `h>=2` vertices with a distinguished root `rho`.

Call `(H,rho)` **root-extremal graceful** if there is a graceful labeling

`g:V(H)->{0,...,h-1}`

with

`g(rho)=h-1`.

Equivalently, by complementing every label, one may require `g(rho)=0`.

Fix such a labeling `g` and fix a bipartition

`chi:V(H)->{0,1}`.

Because `H` is a tree, every edge joins opposite `chi`-classes.

---

# 4. The universal odd tensor absorber

## Theorem 4.1 — repeated root-extremal tree absorber

Fix `k>=0` and put

`c=2k+1`.

Let `F` be the disjoint union of `c` copies of `(H,rho)`, each copy rooted at its copy of `rho`. Then `F` has a suffix-root cutoff-`k` absorber labeling.

In particular, this holds for every rooted path whose root is an endpoint, every centered star, and every other rooted tree known to admit an extremal-root graceful labeling.

### Construction

Index the copies by

`r in {0,...,c-1}`.

Define the permutation

`tau(r)=2r mod c`,

where the result is represented in `{0,...,c-1}`.

For each vertex `v in V(H)`, define a residue permutation

`pi_v(r)=r` if `chi(v)=0`,

`pi_v(r)=tau(r)` if `chi(v)=1`.

Now define the global label on the copy of `v` in copy `r` by

`lambda(v,r)=c g(v)+pi_v(r)`.

We prove that this is the desired absorber.

---

## 4.2 Bijection and suffix-root property

For each fixed vertex `v`, `pi_v` is a permutation of `{0,...,c-1}`. Because `g` is a bijection onto `{0,...,h-1}`, the labels of the `c` copies of the unique vertex with local label `j` are exactly

`{cj,cj+1,...,cj+c-1}`.

As `j` runs from `0` to `h-1`, these blocks partition

`{0,...,ch-1}`.

Hence `lambda` is a bijection on all

`s=ch`

vertices of `F`.

Since `g(rho)=h-1`, the component roots receive exactly

`{c(h-1),...,ch-1}`

`={s-c,...,s-1}`.

Therefore the labeling is suffix-root once we verify the edge differences.

---

# 5. The centered-residue lemma

The crucial fact is elementary but exact.

## Lemma 5.1

For odd

`c=2k+1`

and

`tau(r)=2r mod c`,

the integer differences

`tau(r)-r`, `0<=r<c`,

are exactly

`{-k,-k+1,...,-1,0,1,...,k}`.

### Proof

If `0<=r<=k`, then `2r<c`, so

`tau(r)-r=2r-r=r`,

which gives `0,1,...,k`.

If `k+1<=r<=2k`, then `2r>=c` and

`tau(r)=2r-c`,

so

`tau(r)-r=r-c`,

which gives `-k,...,-1`.

Together these are exactly all integers from `-k` through `k`. QED.

Because the interval is symmetric, the same is true of `r-tau(r)`.

---

# 6. Exact internal difference blocks

Take an edge `uv` of `H`. Orient it so that

`g(v)>g(u)`

and let

`d=g(v)-g(u)`.

Because `g` is graceful, as `uv` ranges over `E(H)`, the local differences `d` are exactly

`1,2,...,h-1`,

one apiece.

In copy `r`, the corresponding global difference before applying absolute value is

`lambda(v,r)-lambda(u,r)`

`=cd + pi_v(r)-pi_u(r)`.

The endpoints have opposite bipartition colors, so by Lemma 5.1 the residue differences across all `r` are exactly

`{-k,...,k}`.

Moreover

`cd-k >= c-k = k+1 >0`,

so all these oriented differences are positive and the absolute values are the same numbers.

Thus the `c` copies of the unique local edge of difference `d` realize exactly

`{cd-k,...,cd+k}`.

Since `c=2k+1`, this interval can be written as

`{ k+(d-1)c+1, ..., k+dc }`.

For consecutive `d`, these blocks are adjacent with no overlap:

* `d=1` gives `k+1,...,k+c`;
* `d=2` gives `k+c+1,...,k+2c`;
* ...
* `d=h-1` ends at `k+c(h-1)`.

Therefore all internal forest edges realize exactly

`{k+1,...,k+c(h-1)}`.

Put

`N=c(h-1)=s-c`.

Then the internal spectrum is precisely

`{k+1,...,k+N}`.

---

# 7. Attachment differences and completion of the proof

The roots have labels

`N,N+1,...,N+c-1`.

In the cutoff-`k` absorber equation, their attachment edges therefore contribute

`k+1+N, k+2+N, ..., k+c+N`,

i.e.

`{k+N+1,...,k+N+c}`

`={k+s-c+1,...,k+s}`.

Together with the internal spectrum from Section 6, the new edges realize exactly

`{k+1,...,k+s}`

without repetition.

Hence `lambda` is a suffix-root cutoff-`k` absorber. QED.

# 8. Exact endpoint-rooted path formula

The previous checkpoint identified repeated rooted paths as the next target. Theorem 4.1 settles the constructive side for every path length.

Let

`P_h=v_0v_1...v_{h-1}`

with root `v_0`.

Use the classical alternating-extremes labeling

`g(v_0)=h-1`,

`g(v_1)=0`,

`g(v_2)=h-2`,

`g(v_3)=1`,

`g(v_4)=h-3`,

and so on.

Equivalently,

`g(v_i)=i/2` for odd `i`,

`g(v_i)=h-1-i/2` for even `i`.

The successive edge differences are

`h-1,h-2,...,1`,

so this is a graceful labeling with the endpoint root at `h-1`.

Therefore:

## Corollary 8.1

For every `k>=0` and every `h>=2`, `2k+1` copies of the endpoint-rooted path `P_h` have an explicit suffix-root cutoff-`k` absorber.

No search, parity case split, or unproved path-packing lemma is required.

This is stronger than the immediate target proposed at the end of the preceding checkpoint, which asked merely for a classification/construction for repeated rooted paths.

I do **not** claim that `2k+1` is necessary for arbitrary path absorbers; the necessity theorem below is for the natural block-separable tensor architecture, not for all possible labelings.

# 10. Why the multiplicity `2k+1` is forced in the block-separable tensor ansatz

The appearance of `2k+1` is not an artifact of choosing the doubling permutation.

Consider any construction of the following natural form. Let `g` be a graceful labeling of an `h`-vertex motif `H`. For `c` copies, assign

`lambda(v,r)=c g(v)+pi_v(r)`,

where every `pi_v` is a permutation of `{0,...,c-1}`.

Suppose further that for the unique local edge whose graceful difference is `d`, the `c` lifted copies are intended to occupy the canonical consecutive block

`I_d={k+(d-1)c+1,...,k+dc}`.

Then necessarily

`c=2k+1`.

## Theorem 10.1 — block-separable multiplicity obstruction

Under the assumptions above,

`c=2k+1`.

### Proof

Orient the local edge from the smaller `g`-label to the larger one. Every lifted oriented difference is

`cd+pi_v(r)-pi_u(r)`.

Because both `pi_v` and `pi_u` are permutations of the same residue set,

`sum_r pi_v(r)=sum_r pi_u(r)=c(c-1)/2`.

Therefore the sum of the `c` lifted oriented differences is exactly

`c^2 d`.

On the other hand, the sum of the desired block `I_d` is

`c [ cd + k - (c-1)/2 ]`.

Equating the two expressions gives

`c^2 d = c^2 d + c[k-(c-1)/2]`,

hence

`k=(c-1)/2`.

Therefore

`c=2k+1`.

QED.

So any attempt to preserve the local graceful levels as `c`-wide label blocks and assign one consecutive `c`-block of global differences to each local edge difference is arithmetically locked to exactly the odd multiplicity used above.

Escaping `2k+1` requires a genuinely different architecture in which global difference colors from different local edge types interleave or exchange between blocks.

# 11. Composition with an arbitrary existing one-gap certificate

Combine Theorem 4.1 with the suffix-root transfer theorem from the preceding checkpoint.

Let `(f,L,k,r)` be any one-gap certificate. Let `(H,rho)` be any root-extremal graceful tree on `h` vertices. Attach

`c=2k+1`

disjoint copies of `H` to the old root `r` by adding one edge from `r` to the distinguished root of each copy.

There are

`s=ch`

new vertices. Theorem 4.1 supplies a suffix-root cutoff-`k` absorber, so the enlarged tree is graceful and carries another one-gap certificate with cutoff

`K=k+s-c`

`=k+(2k+1)(h-1)`.

Equivalently,

`2K+1=(2h-1)(2k+1)`.

This multiplicative state law therefore does **not** belong specifically to repeated stars. It is the universal law of the odd tensor lift for every root-extremal graceful motif.

The distinguished new root is the copy-root whose global residue is `k`, because

`K=c(h-1)+k`.

# 12. Iterated motif theorem

Starting from any one-gap certificate with cutoff `k_0`, choose a sequence of root-extremal graceful motifs

`(H_1,rho_1),...,(H_t,rho_t)`

with orders `h_1,...,h_t`.

At stage `i`, attach `2k_{i-1}+1` copies of `H_i` using the tensor absorber. Then every stage is graceful and

`2k_i+1=(2h_i-1)(2k_{i-1}+1)`.

Hence

`2k_t+1=(2k_0+1) product_{i=1}^t (2h_i-1)`.

This produces a recursively branching infinite graceful family in which the repeated motifs may change arbitrarily from stage to stage and may have nontrivial internal structure.

The preceding star-only iteration is the special case where every `H_i` is a centered star.

# 13. Relation to the LPW repeated-forest decomposition

Letzter–Pokrovskiy–Williams Lemma 4.1 yields, after deleting a small exceptional set, many repeated copies of a bounded forest `F` whose components are rooted trees. The tensor theorem aligns with one exact feature of that decomposition: **repeated rooted tree types can be packed into a consecutive difference block without any loss, provided the rooted type has an extremal graceful labeling and the repetition count matches the current odd cutoff state.**

This is not yet an exact repair theorem for LPW, for three reasons.

1. LPW's repeated multiplicity is determined by the structural decomposition and need not equal `2k+1`.
2. Their bounded forest can contain several rooted-tree isomorphism types simultaneously.
3. An arbitrary rooted tree component need not currently be known to admit a graceful labeling with its specified root at `0` or `h-1`; proving that for every rooted tree would itself be a strong form of the graceful conjecture (0-rotatability).

The tensor theorem therefore supplies an exact absorber module, not a universal completion of the LPW argument.

The block-separable obstruction in Theorem 10.1 says something useful about the gap: merely reindexing residues inside fixed local-label blocks cannot adjust an arbitrary LPW multiplicity. A successful exact LPW repair must either alter the decomposition multiplicities or permit global difference colors to mix between local motif-edge types.

# 16. Failed / closed route from this iteration

The initial plan was to classify repeated endpoint-rooted paths by direct exact-cover search. That search rapidly becomes combinatorially expensive and, more importantly, is unnecessary for the constructive side. The tensor viewpoint exposes a closed form immediately.

The key lesson is that the earlier star labels already had a hidden two-scale structure: local graceful edge colors choose coarse blocks of width `c`, while the map `r -> 2r mod c` supplies the centered residue offsets `-k,...,k`. Once separated, the same mechanism applies to every bipartite graceful motif, hence every root-extremal graceful tree.

Direct search remains useful only for the genuinely different question of whether repeated paths admit suffix-root absorbers at multiplicities `c != 2k+1`, i.e. outside the block-separable architecture.
