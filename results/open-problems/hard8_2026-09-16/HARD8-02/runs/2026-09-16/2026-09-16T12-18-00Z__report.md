# 2. Setup and notation

Take `c` disjoint endpoint-rooted paths

`r_i -- m_i -- l_i`.

A suffix-root cutoff-`k` absorber is a bijection

`lambda:V(F_c)->{0,...,3c-1}`

such that

* the roots receive exactly `{2c,...,3c-1}`;
* the `2c` internal edge differences are exactly `{k+1,...,k+2c}`.

The preceding checkpoint proved that every such absorber satisfies

`c(c-2k-1)=3E+R`,                                     (2.1)

where

`E = sum_i min(lambda(m_i),lambda(l_i)) - c(c-1)/2 >=0`

and

`R = sum_{i: lambda(m_i)>lambda(l_i)} |lambda(m_i)-lambda(l_i)|`.

For the first excess layer

`c=2k+2`,

write

`h=k+1`,

so that

`c=2h`,

`k=h-1`,

and the required internal spectrum is

`{h,h+1,...,5h-1}`.                                  (2.2)

We assume `h>=2`, exactly equivalent to `k>=1`.

# 3. A general split-spectrum identity

Before constructing the q=1 absorber, it is useful to close the most obvious failed route.

Suppose, more generally, that a `P_3` absorber with parameters `(c,k)` has the stronger property that

* the `c` leaf-edge differences are exactly

  `{k+1,...,k+c}`;

* the `c` root-middle differences are exactly

  `{k+c+1,...,k+2c}`.

Let `N` be the sum of the leaf-edge differences on those paths where the middle has the larger nonroot label.

## Theorem 3.1 — exact reversal sum in the split architecture

Every split-spectrum absorber satisfies

`N = c(c-2k-1)/4`.                                    (3.1)

### Proof

The roots are `{2c,...,3c-1}`, hence their sum is

`S_R = c(5c-1)/2`.

The assumed root-edge spectrum has sum

`S_root = c(2k+3c+1)/2`.

Because every root is above every nonroot label,

`sum_i lambda(m_i)=S_R-S_root`

`= c(c-k-1)`.                                         (3.2)

All nonroot labels are `0,...,2c-1`, with total

`c(2c-1)`,

so

`sum_i lambda(l_i)=c(2c-1)-c(c-k-1)=c(c+k)`.          (3.3)

Therefore

`sum_i (lambda(l_i)-lambda(m_i))=c(2k+1)`.            (3.4)

The unsigned leaf differences are `{k+1,...,k+c}`, whose sum is

`S_leaf=c(2k+c+1)/2`.

If a leaf edge is reversed, its contribution to the signed sum in (3.4) changes from `+d` to `-d`. Thus

`S_leaf-2N=c(2k+1)`.

Solving gives

`2N = c(2k+c+1)/2-c(2k+1)`

`= c(c-2k-1)/2`,

and hence (3.1). QED.

## Corollary 3.2 — the naive split is impossible for q=1

Set `c=2k+2`, so `q=c-(2k+1)=1`. Then (3.1) gives

`N=c/4`.

Since `q>0`, `N>0`, so at least one leaf edge must be reversed. But every leaf-edge difference is at least

`k+1=c/2`.

Hence any nonempty reversal set has

`N>=c/2>c/4`,

a contradiction.

Therefore:

> **For every `k>=0`, no q=1 absorber can put the leaf edges on the lower consecutive half and the root edges on the upper consecutive half.**

This is stronger than the classical Langford congruence obstruction: even in parity classes where the lower-half nonroot pairing alone can exist, the required root assignment makes the full split architecture impossible.

# 5. Explicit universal q=1 construction

## Theorem 5.1

For every integer `h>=2`, equivalently every `k=h-1>=1`, there exists a suffix-root cutoff-`k` absorber on

`c=2h=2k+2`

endpoint-rooted copies of `P_3`.

### Construction

All arithmetic in the next two permutations is ordinary integer arithmetic except where a modulus is explicitly shown.

Let

`n=2h-1`.

### Step A: pair all nonroot labels

Define a permutation `pi` of `{0,...,2h-1}` by

`pi(0)=2h-1`,                                         (5.1)

and for `1<=i<=2h-1`, writing `t=i-1`,

`pi(i) = (2t+1) mod n`.                               (5.2)

Because multiplication by `2` is invertible modulo the odd integer `n`, the values in (5.2) are a permutation of `{0,...,2h-2}`; together with (5.1), `pi` is a permutation of `{0,...,2h-1}`.

For each low label `i`, pair it with the high label

`H_i=2h+pi(i)`.

Orient every pair low-to-high except the pair with `i=1`:

* for `i!=1`, set `m_i=i` and `l_i=H_i`;
* for `i=1`, set `m_1=H_1` and `l_1=1`.

Since `pi(1)=1`, the unique reversed pair is

`m_1=2h+1`, `l_1=1`,

of difference `2h`.

### Step B: compute the leaf spectrum exactly

For `i>=1`, again put `t=i-1`. The map

`tau(t)=(2t+1) mod n`

has integer displacement set

`{tau(t)-t:0<=t<n}={-(h-1),...,h-1}`.                (5.3)

Indeed:

* for `0<=t<=h-1`, no wrap occurs and `tau(t)-t=t+1`, except at the last endpoint where the same residue calculation gives the top positive displacement;
* after wrap, the displacements continue consecutively through the negatives;

or, equivalently, this is the standard odd multiplication-by-two displacement calculation translated by one.

Since `i=t+1`,

`pi(i)-i = (tau(t)-t)-1`,

so the displacements contributed by `i>=1` are

`{-h,-h+1,...,h-2}`.

The exceptional index `i=0` has displacement

`pi(0)-0=2h-1`.

Therefore

`{pi(i)-i} = {-h,...,h-2} union {2h-1}`.             (5.4)

Every paired high label exceeds its low label, so every leaf-edge magnitude is

`2h+pi(i)-i`.

Using (5.4), the leaf-edge spectrum is exactly

`{h,...,3h-2} union {4h-1}`,                         (5.5)

which is (4.1).

### Step C: assign the roots

The set of middle labels is

`M={0,2,3,...,2h-1} union {2h+1}`.                   (5.6)

First assign the exceptional middle

`m=2h+1`

to the root

`r=5h`.

Its root-edge difference is

`5h-(2h+1)=3h-1`.                                    (5.7)

This uses root index `h` inside the suffix block `{4h,...,6h-1}`.

For every remaining middle `m in {0,2,...,2h-1}`, define its compressed index

`v=0` if `m=0`,

`v=m-1` if `m>=2`.

Thus `v` runs bijectively over `{0,...,n-1}`.

Define

`u = h v mod n`,                                     (5.8)

and then expand across the omitted root index `h` by

`a=u` if `u<h`,

`a=u+1` if `u>=h`.                                   (5.9)

Finally assign root

`r=4h+a`.                                             (5.10)

Because `gcd(h,2h-1)=1`, (5.8) is a permutation of `{0,...,n-1}`. Equation (5.9) therefore uses each root index in

`{0,...,2h-1}\{h}`

exactly once; together with the exceptional root index `h`, every root in `{4h,...,6h-1}` is used exactly once.

### Step D: compute the ordinary root differences

The congruence

`2h congruent 1 (mod 2h-1)`

makes (5.8) explicit by parity.

If `v=2r` is even, with `0<=r<=h-1`, then

`u = h(2r) mod n = r`.

For `r=0`, we have `m=0`, `a=0`, hence

`a-m=0`.

For `r>=1`, `m=v+1=2r+1` and `a=r`, hence

`a-m=-r-1`,

which gives exactly

`{-2,-3,...,-h}`.                                    (5.11)

If `v=2r+1` is odd, with `0<=r<=h-2`, then

`u = h(2r+1) mod n = h+r`,

so by (5.9)

`a=h+r+1`.

Also

`m=v+1=2r+2`,

therefore

`a-m=h-r-1`,

which gives exactly

`{h-1,h-2,...,1}`.                                   (5.12)

Combining the even and odd cases,

`{a-m}={-h,...,-2} union {0,...,h-1}`.               (5.13)

Thus the ordinary root-edge differences `r-m=4h+(a-m)` are exactly

`{3h,...,4h-2} union {4h,...,5h-1}`.                 (5.14)

Adding the exceptional root difference (5.7), the complete root spectrum is

`{3h-1,...,4h-2} union {4h,...,5h-1}`,               (5.15)

which is exactly (4.2).

### Step E: finish the absorber verification

The leaf spectrum (5.5) and root spectrum (5.15) are disjoint, and their union is

`{h,h+1,...,5h-1}`.

Since `h=k+1` and `c=2h`, this is precisely

`{k+1,...,k+2c}`.

The roots are exactly

`{4h,...,6h-1}={2c,...,3c-1}`,

and the nonroot pairing uses every label

`{0,...,4h-1}={0,...,2c-1}`

exactly once.

Hence the construction is a suffix-root cutoff-`k` absorber. QED.

# 8. A useful exact spectrum-sum formula beyond the split case

Let `A` be the set of the `c` leaf-edge differences of an arbitrary absorber, let

`S_A=sum_{d in A} d`,

and let `R` again be the total reversed leaf-edge weight. A direct sum calculation gives

`3 S_A = c(4k+c+2)+2R`.                              (8.1)

If `S_0` denotes the sum of the lower `c` target values `{k+1,...,k+c}`, then

`6(S_A-S_0)=4R-cq`,                                  (8.2)

where `q=c-(2k+1)`.

Using the archived defect identity `cq=3E+R`, this becomes

`S_A-S_0=(R-E)/2`.                                   (8.3)

For q=1,

`R=c-3E`,

hence

`S_A-S_0=c/2-2E`.                                    (8.4)

In particular, every q=1 absorber has

`0<=E<=c/4`.

If `t` leaf differences lie in the upper half of the target interval, then replacing `t` values of the lower half by `t` upper-half values costs at least `t^2` in total sum. Therefore

`t^2 <= S_A-S_0 = c/2-2E <= c/2`.                   (8.5)

So any q=1 absorber has at most

`floor(sqrt(c/2))`

leaf differences in the upper half. Corollary 3.2 says at least one such interleaving is necessary; Theorem 5.1 achieves the extremal simple pattern `t=1`, `E=0`.

This identifies the closed-form family as a minimal-interleaving realization of the q=1 budget.
