# New result 1: exact cut-suffix criterion for one-gap extension

Let `T` have `m` edges and let

`f:V(T)->{0,...,m}`

be a graceful labeling. Fix a root `r`. For a prospective new label

`L in {0,...,m+1}`,

define the **gap-inserted old-vertex labeling**

`g_L(v) = f(v) + 1[f(v) >= L]`.

Thus `g_L` uses every label in `{0,...,m+1}` except `L`.

For each old difference `d in {1,...,m}`, let `e_d` denote the unique edge with old difference `d`. Define

`c_d(L)=1`

iff the endpoints of `e_d` lie on opposite sides of the threshold `L`, i.e. one has old label `<L` and the other has old label `>=L`; otherwise put `c_d(L)=0`.

## Proposition (one-gap cut-suffix criterion)

After inserting the gap at `L`, the old edges have pairwise distinct differences **if and only if**

`c_1(L) <= c_2(L) <= ... <= c_m(L)`.

Equivalently, there is a unique `k in {0,...,m}` such that

`c_d(L)=0` for `d<=k`, and `c_d(L)=1` for `d>k`.

In that case the new differences on the old edges are exactly

`{1,...,k} union {k+2,...,m+1}`,

so the unique missing difference is `k+1`.

Attaching a new leaf `z` at the root and assigning `g(z)=L` produces a graceful labeling of the enlarged tree **if and only if**

`|L-g_L(r)| = k+1`.

Equivalently, the old root label must satisfy one of the two exact arithmetic conditions

- `f(r)=L-k-1` with `f(r)<L`, or
- `f(r)=L+k` with `f(r)>=L`.

### Proof

For the edge `e_d`, inserting the gap changes its difference by exactly one precisely when its endpoints straddle `L`; hence its new difference is

`d+c_d(L)`.

Because every `c_d` is binary, if the sequence has a descent then for some `d` we have `c_d=1` and `c_{d+1}=0`; then both `e_d` and `e_{d+1}` acquire difference `d+1`, so distinctness fails.

Conversely, if the binary sequence is nondecreasing, it has the form `0^k 1^(m-k)`. The transformed values are then

`1,2,...,k,k+2,k+3,...,m+1`,

which are distinct and omit exactly `k+1`. The new leaf is incident only with `r`, so the enlarged tree is graceful exactly when its new edge supplies that missing value, namely `|L-g_L(r)|=k+1`. Expanding the definition of `g_L(r)` yields the two displayed root-label formulas. QED.

## Why this reformulation is useful

The gap condition is no longer an opaque search over relabelings. It says that a graceful labeling must admit an **ordered vertex cut** `{f<L} | {f>=L}` for which the edge colours split at a single number `k`:

- every small colour `1,...,k` stays inside one side of the cut;
- every large colour `k+1,...,m` crosses the cut;
- the root sits at one of two exact offsets from the threshold.

In the rainbow language of Letzter–Pokrovskiy–Williams, this is a rainbow embedding with a *suffix-of-colours cut*. This looks substantially more structured than arbitrary almost-rainbow embeddings and therefore gives a concrete object for an absorption/composition argument.

### Two limiting cases recover familiar mechanisms

1. **Endpoint/0-rotatable extension.** Take `L=m+1`. Then no old edge crosses, so `k=m`, and the criterion reduces to `f(r)=0`. The complementary case `L=0` reduces to `f(r)=m`. Thus ordinary endpoint leaf extension is the `k=m` case.
2. **Alpha-boundary extension.** If `f` is an alpha-labeling with global threshold `alpha` and take `L=alpha+1`, every edge crosses. Thus `k=0`, the missing new difference is 1, and extension works whenever the root has old label `alpha` or `alpha+1`. This is the `k=0` extreme.

The one-gap route continuously interpolates between these two classical extremes.

# New result 2: an explicit rooted tree where an interior gap is essential

Consider the six-vertex tree with edges

`(0,1), (0,4), (1,2), (1,3), (4,5)`

and root `r=0`.

An exact graceful labeling is

- `f(0)=3`,
- `f(1)=0`,
- `f(2)=5`,
- `f(3)=4`,
- `f(4)=1`,
- `f(5)=2`.

The old edge differences are respectively

- `(0,1):3`,
- `(0,4):2`,
- `(1,2):5`,
- `(1,3):4`,
- `(4,5):1`,

so they are exactly `{1,2,3,4,5}`.

Take `L=1`. The crossing vector by increasing old difference is

`(c_1,...,c_5)=(0,0,1,1,1)`,

so `k=2`. Shift every old label `>=1` upward by one. The old vertices then receive

- `g(0)=4`, `g(1)=0`, `g(2)=6`, `g(3)=5`, `g(4)=2`, `g(5)=3`.

The old edge differences become `{1,2,4,5,6}`, missing 3. Attach a new leaf at root 0 and give it label `L=1`; its edge has difference `|4-1|=3`. The enlarged seven-vertex tree is therefore graceful.

The exact exhaustive search in the artifact enumerates all 12 graceful labelings of this six-vertex tree and finds that this specified root is never labeled `0` or `5`. Thus endpoint extension fails for this rooted instance while the interior gap succeeds. This shows concretely that the Aug-2026 gap idea is not merely a disguised 0-rotatability argument.

# Structural consequences and a sharper proof target

For a certificate `(f,L,k)`, delete the `m-k` crossing edges (equivalently, the edges whose graceful differences exceed `k`). Every remaining connected component lies wholly in one label interval `[0,L-1]` or `[L,m]`. Thus a universal proof of the one-gap mechanism could be attacked as a **component gluing theorem**:

1. partition the tree into components whose internal edges are assigned the small differences `1,...,k`;
2. place entire components on the low or high side of `L`;
3. use the contracted component-tree edges for the large suffix `k+1,...,m`;
4. force the distinguished root to one of the two arithmetic positions `L-k-1` or `L+k`.

This is a more precise target than merely asking for a gap. It also aligns naturally with the tree-splitting machinery in Letzter–Pokrovskiy–Williams: their proof already decomposes trees into controlled pieces before a rainbow embedding. The missing upgrade is exactness plus the suffix-cut alignment.

## Candidate strengthened route (OPEN)

> **Rooted suffix-cut extension conjecture.** Every rooted graceful tree `(T,r)` has some graceful labeling `f` and integers `L,k` satisfying the cut-suffix condition and the root arithmetic condition above.

If true, this implies the full graceful tree conjecture by leaf deletion and induction: remove a leaf `z` from an arbitrary tree and root the smaller tree at the former neighbour of `z`; inductively label the smaller tree gracefully, apply the rooted extension statement, and restore `z`.

This route is stronger than the original conjecture and remains unproved. The MathWorld computation through order 22 is evidence specifically for this style of one-gap extension, not a proof.

# Next concrete attack

The highest-value next step is to prove a **suffix-cut composition lemma**. Start with a tree split at a small separator into rooted components. Seek sufficient hypotheses under which graceful (or alpha/near-alpha) labelings of the components can be placed into disjoint integer intervals so that:

- all internal component edge differences occupy exactly an initial segment `1,...,k`;
- all separator edges receive exactly the suffix `k+1,...,m` and cross one common label threshold;
- one designated root lands at `L-k-1` or `L+k`.

A successful composition lemma for a decomposition class broad enough to cover the LPW tree split would turn the asymptotic rainbow technology into an exact inductive route. A useful intermediate theorem would be to prove the rooted suffix-cut property for all spiders or for all caterpillars, comparing it against known 0-rotatability failures to see whether the interior-gap relaxation removes the obstruction.
