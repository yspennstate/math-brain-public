## 3. Hard-core reduction

If either coordinate is rational, the conjecture is immediate: if \(\alpha=a/b\), every positive multiple of \(b\) has \(\|q\alpha\|=0\). The same holds symmetrically for \(\beta\).

If \(\alpha\) is irrational but not badly approximable, then there is a sequence \(q_j\to\infty\) with
\[
q_j\|q_j\alpha\|\to0,
\]
and since \(\|q_j\beta\|\le1/2\), Littlewood follows. Likewise for \(\beta\).

Thus a genuine counterexample must have both coordinates badly approximable, equivalently both simple continued fractions have bounded partial quotients.

Write
\[
\alpha=[b_0;b_1,b_2,\ldots],\qquad
\beta=[d_0;d_1,d_2,\ldots]
\]
with convergents
\[
\frac{A_m}{B_m},\qquad \frac{C_n}{D_n}.
\]
Define complete quotients
\[
\xi_m=[b_{m+2};b_{m+3},\ldots],\qquad
\eta_n=[d_{n+2};d_{n+3},\ldots]
\]
and exact scale factors
\[
\Theta_m=B_{m+1}\xi_m+B_m,
\qquad
\Delta_n=D_{n+1}\eta_n+D_n.
\]

The reconstruction formulas are
\[
\alpha=\frac{A_{m+1}\xi_m+A_m}{B_{m+1}\xi_m+B_m},
\qquad
\beta=\frac{C_{n+1}\eta_n+C_n}{D_{n+1}\eta_n+D_n}.
\]

## 4. Exact two-sided portal identities

For integers \(x,y\), put
\[
q=xB_m+yB_{m+1},
\qquad
p=xA_m+yA_{m+1},
\qquad
\delta^{\alpha}_m=y-x\xi_m.
\]
The standard determinant identity
\[
A_{m+1}B_m-A_mB_{m+1}=(-1)^m
\]
gives
\[
\boxed{
q\alpha-p=(-1)^{m+1}\frac{\delta^{\alpha}_m}{\Theta_m}.
}
\tag{4.1}
\]
Likewise, for integers \(z,v\),
\[
q=zD_n+vD_{n+1},
\qquad
r=zC_n+vC_{n+1},
\qquad
\delta^{\beta}_n=v-z\eta_n,
\]
we have
\[
\boxed{
q\beta-r=(-1)^{n+1}\frac{\delta^{\beta}_n}{\Delta_n}.
}
\tag{4.2}
\]

The coefficient maps are not merely surjective. The matrices
\[
M_m^\alpha=
\begin{pmatrix}
B_m&B_{m+1}\\
A_m&A_{m+1}
\end{pmatrix},
\qquad
M_n^\beta=
\begin{pmatrix}
D_n&D_{n+1}\\
C_n&C_{n+1}
\end{pmatrix}
\]
have determinant \(\pm1\). Hence every integer pair \((q,p)\) has a unique coefficient pair \((x,y)\), and every integer pair \((q,r)\) has a unique coefficient pair \((z,v)\).

This removes a subtle ambiguity that is easy to miss in the one-sided portal notation: changing \((z,v)\) by the integer kernel of the denominator map changes the associated numerator by one, so the full denominator/numerator pair is the correct unimodular coordinate object.

## 5. Exact double-portal lattice normal form

Define the standard three-dimensional lattice
\[
\Lambda(\alpha,\beta)
=
\left\{
\bigl(q,q\alpha-p,q\beta-r\bigr):
q,p,r\in\mathbb Z
\right\}.
\]
Its basis matrix can be written
\[
U_{\alpha,\beta}=
\begin{pmatrix}
1&0&0\\
\alpha&-1&0\\
\beta&0&-1
\end{pmatrix},
\]
so \(|\det U_{\alpha,\beta}|=1\).

For every pair of convergent indices \((m,n)\), set
\[
G_{m,n}
=
\operatorname{diag}
\left(
\frac1{\Theta_m\Delta_n},
\Theta_m,
\Delta_n
\right)
\]
and
\[
\Lambda_{m,n}=G_{m,n}\Lambda(\alpha,\beta).
\]
Again \(\det G_{m,n}=1\), so every \(\Lambda_{m,n}\) is unimodular.

### Theorem 5.1 — exact double-portal coordinates

Take arbitrary integers \(q,p,r\). Let \((x,y)\) and \((z,v)\) be their unique continued-fraction coefficient pairs:
\[
\binom{q}{p}=M_m^\alpha\binom{x}{y},
\qquad
\binom{q}{r}=M_n^\beta\binom{z}{v}.
\]
Then the corresponding vector of \(\Lambda_{m,n}\) is exactly
\[
\boxed{
\left(
\frac{q}{\Theta_m\Delta_n},
(-1)^{m+1}(y-x\xi_m),
(-1)^{n+1}(v-z\eta_n)
\right).
}
\tag{5.1}
\]
In particular,
\[
\boxed{
|XYZ|
=
|q|\,|q\alpha-p|\,|q\beta-r|.
}
\tag{5.2}
\]

#### Proof

The first coordinate is the definition of \(G_{m,n}\). The second is (4.1) multiplied by \(\Theta_m\), and the third is (4.2) multiplied by \(\Delta_n\). Multiplying the three absolute values cancels the normalizing scales. QED.

If \(p,r\) are nearest integers to \(q\alpha,q\beta\), then
\[
\boxed{
|XYZ|=|q|\,\|q\alpha\|\,\|q\beta\|.
}
\tag{5.3}
\]

Equivalently, if a common denominator relation
\[
xB_m+yB_{m+1}=zD_n+vD_{n+1}=q
\tag{5.4}
\]
has
\[
|y-x\xi_m|<\Theta_m/2,
\qquad
|v-z\eta_n|<\Delta_n/2,
\]
then the associated numerator combinations are nearest integers and
\[
\boxed{
q\|q\alpha\|\|q\beta\|
=
\frac{|q|}{\Theta_m\Delta_n}
\,|y-x\xi_m|\,|v-z\eta_n|.
}
\tag{5.5}
\]

This is the symmetric exact form of the previous one-sided portal identity.

## 6. Exact continued-fraction renormalization

The complete quotients satisfy
\[
\xi_m=b_{m+2}+\frac1{\xi_{m+1}},
\qquad
\eta_n=d_{n+2}+\frac1{\eta_{n+1}}.
\]
Using the denominator recurrences,
\[
B_{m+2}=b_{m+2}B_{m+1}+B_m,
\qquad
D_{n+2}=d_{n+2}D_{n+1}+D_n,
\]
we obtain exact scale recurrences
\[
\boxed{
\Theta_{m+1}=\xi_{m+1}\Theta_m,
\qquad
\Delta_{n+1}=\eta_{n+1}\Delta_n.
}
\tag{6.1}
\]
Therefore
\[
\boxed{
\Lambda_{m+1,n}
=
\operatorname{diag}
(\xi_{m+1}^{-1},\xi_{m+1},1)\,\Lambda_{m,n},
}
\tag{6.2}
\]
and
\[
\boxed{
\Lambda_{m,n+1}
=
\operatorname{diag}
(\eta_{n+1}^{-1},1,\eta_{n+1})\,\Lambda_{m,n}.
}
\tag{6.3}
\]
The two moves commute.

Thus the entire two-dimensional array of continued-fraction frames is not an assortment of unrelated approximations. It is an exact discrete sampling of the positive diagonal action preserving the coordinate product.

At the coefficient level, shifting the \(\beta\)-frame by one sends
\[
(z,v)\mapsto(v-d_{n+2}z,z),
\]
up to the convention for ordering the new coefficients. In the normalized portal coordinates this becomes the much simpler diagonal rule
\[
(a,\delta)\mapsto
\left(\frac a{\eta_{n+1}},-\eta_{n+1}\delta\right),
\]
so \(|a\delta|\) is invariant. The same statement holds on the \(\alpha\) side.

This explains algebraically why repeated changes of continued-fraction frame did not create an independent packing constraint in the prior runs: they are pieces of the same diagonal renormalization orbit.

## 7. A discrete continued-fraction-grid criterion for the hard core

Let \(\lambda_1(\Lambda)\) denote the Euclidean length of the shortest nonzero vector of a lattice \(\Lambda\).

### Theorem 7.1 — discrete cusp criterion

Assume \(\alpha,\beta\) are irrational and badly approximable. Then
\[
\boxed{
\liminf_{q\to\infty}q\|q\alpha\|\|q\beta\|=0
}
\]
if and only if
\[
\boxed{
\inf_{m,n\to\infty}\lambda_1(\Lambda_{m,n})=0,
}
\tag{7.1}
\]
where it is enough to allow any sequence of index pairs escaping every finite rectangle.

Equivalently, a classical counterexample in the badly-approximable hard core is exactly a pair for which the double continued-fraction grid stays uniformly away from the cusp.

#### Proof: grid cusp implies Littlewood

Suppose \(\lambda_1(\Lambda_{m_j,n_j})\to0\) along escaping index pairs. Choose nonzero lattice vectors
\[
(X_j,Y_j,Z_j)
=G_{m_j,n_j}(q_j,q_j\alpha-p_j,q_j\beta-r_j)
\]
with Euclidean norm tending to zero.

Eventually \(q_j\neq0\). Indeed, if \(q_j=0\), then
\[
(X_j,Y_j,Z_j)=(0,-\Theta_{m_j}p_j,-\Delta_{n_j}r_j).
\]
As the index pair escapes, a nonzero integer pair \((p_j,r_j)\) cannot make this vector tend to zero.

Also \(|q_j|\to\infty\). If \(q_j\) stayed in a finite nonzero set, then for each such fixed \(q\), irrationality gives positive distances \(\|q\alpha\|,\|q\beta\|\); along any escaping index direction one of the scaled error coordinates would fail to tend to zero.

By (5.2),
\[
|q_j|\,|q_j\alpha-p_j|\,|q_j\beta-r_j|
=|X_jY_jZ_j|.
\]
The nearest-integer errors are no larger than the chosen errors, so
\[
|q_j|\,\|q_j\alpha\|\,\|q_j\beta\|
\le |X_jY_jZ_j|.
\]
Finally
\[
|X_jY_jZ_j|
\le
\left(\frac{X_j^2+Y_j^2+Z_j^2}{3}\right)^{3/2}
\to0.
\]
Hence Littlewood holds.

#### Proof: Littlewood implies grid cusp in the badly-approximable hard core

Suppose there are \(q_j\to\infty\) with
\[
\ell_j=q_j\|q_j\alpha\|\|q_j\beta\|\to0.
\]
Put
\[
e_{\alpha,j}=\|q_j\alpha\|,
\qquad
e_{\beta,j}=\|q_j\beta\|,
\qquad
t_j=\ell_j^{1/3}.
\]
Bad approximability supplies constants \(c_\alpha,c_\beta>0\) such that
\[
q\|q\alpha\|\ge c_\alpha,
\qquad
q\|q\beta\|\ge c_\beta
\quad(q\ge1).
\]
Therefore
\[
e_{\alpha,j}\le \ell_j/c_\beta\to0,
\qquad
e_{\beta,j}\le \ell_j/c_\alpha\to0.
\]

Define the ideal continuous diagonal scales
\[
\Theta_j^*=\frac{t_j}{e_{\alpha,j}},
\qquad
\Delta_j^*=\frac{t_j}{e_{\beta,j}}.
\]
They satisfy
\[
\frac{q_j}{\Theta_j^*\Delta_j^*}
=\Theta_j^*e_{\alpha,j}
=\Delta_j^*e_{\beta,j}
=t_j.
\tag{7.2}
\]
Moreover both scales tend to infinity, because
\[
(\Theta_j^*)^3
=\frac{q_je_{\beta,j}}{e_{\alpha,j}^2}
\ge \frac{c_\beta}{e_{\alpha,j}^2}\to\infty,
\]
and symmetrically \(\Delta_j^*\to\infty\).

Since badly approximable numbers have bounded partial quotients, say
\[
b_i\le A_\alpha,
\qquad d_i\le A_\beta,
\]
we have
\[
1<\xi_m<A_\alpha+1,
\qquad
1<\eta_n<A_\beta+1.
\]
By (6.1), consecutive scales have uniformly bounded multiplicative gaps. Hence we may choose indices \(m_j,n_j\) with
\[
\frac{\Theta_j^*}{A_\alpha+1}<\Theta_{m_j}\le\Theta_j^*,
\qquad
\frac{\Delta_j^*}{A_\beta+1}<\Delta_{n_j}\le\Delta_j^*.
\]
Take nearest integers \(p_j,r_j\). The corresponding normalized vector has coordinates bounded by
\[
|X_j|\le(A_\alpha+1)(A_\beta+1)t_j,
\qquad
|Y_j|\le t_j,
\qquad
|Z_j|\le t_j.
\]
Thus its norm tends to zero, proving (7.1). QED.

### Significance

The usual diagonal-flow equivalence is classical. The project-level contribution here is the exact **continued-fraction discretization**: both continued fractions produce a canonical two-index grid whose step ratios are the complete quotients themselves. In the only unresolved hard core, those step ratios are uniformly bounded, so no information is lost by replacing the continuous positive diagonal orbit with this discrete continued-fraction grid.

This also supplies a clean target for combinatorial work: prove that the explicitly generated grid \(\Lambda_{m,n}\) must enter the cusp for every bounded-type pair.

## 8. Exact common-denominator criterion and the cubic barrier

The recent Matala-aho approach searches for small integer solutions of
\[
xB_m+yB_{m+1}=zD_n+vD_{n+1}=q.
\tag{8.1}
\]
The double-portal identity makes the quantitative threshold exact.

Assume partial quotients are bounded by \(A_\alpha,A_\beta\). Suppose
\[
|x|,|y|\le R_\alpha,
\qquad
|z|,|v|\le R_\beta.
\]
Then
\[
|\delta_m^\alpha|
=|y-x\xi_m|
\le(A_\alpha+2)R_\alpha,
\]
\[
|\delta_n^\beta|
\le(A_\beta+2)R_\beta.
\tag{8.2}
\]
Also
\[
|q|
\le R_\alpha(B_m+B_{m+1})<2R_\alpha\Theta_m,
\]
and symmetrically
\[
|q|<2R_\beta\Delta_n.
\]
Hence
\[
\frac{|q|}{\Theta_m\Delta_n}
<
2\min\left(
\frac{R_\alpha}{\Delta_n},
\frac{R_\beta}{\Theta_m}
\right).
\tag{8.3}
\]

If the coefficient sizes are sublinear in the corresponding scales, the nearest-integer conditions eventually hold, and (5.5), (8.2), (8.3) give
\[
\boxed{
q\|q\alpha\|\|q\beta\|
\le
2(A_\alpha+2)(A_\beta+2)
R_\alpha R_\beta
\min\left(
\frac{R_\alpha}{\Delta_n},
\frac{R_\beta}{\Theta_m}
\right).
}
\tag{8.4}
\]

Let
\[
N_{m,n}=\min(\Theta_m,\Delta_n).
\]
Then a simpler sufficient condition is
\[
\boxed{
\frac{R_\alpha R_\beta\min(R_\alpha,R_\beta)}{N_{m,n}}\to0.
}
\tag{8.5}
\]
If additionally the resulting common denominators satisfy \(q\to\infty\), Littlewood follows.

In the isotropic case \(R_\alpha=R_\beta=R\), this becomes
\[
\boxed{
R=o(N_{m,n}^{1/3}).
}
\tag{8.6}
\]

### Why the current Thue–Siegel scale is exactly critical

Matala-aho's August 2026 paper obtains nonzero solutions with coefficient size on the order of the one-third power of the four relevant convergent denominators. At comparable scales this means
\[
R\asymp N^{1/3}.
\]
Equation (8.4) then gives only
\[
q\|q\alpha\|\|q\beta\|=O(1),
\]
not a quantity tending to zero.

Therefore the bare one-third-power small-solution theorem, by itself, is **scale-critical** for the classical Littlewood target. A universal proof through this route requires at least one of the following genuinely stronger inputs:

- an \(o(N^{1/3})\) coefficient improvement infinitely often;
- an asymmetric solution satisfying (8.5);
- extra cancellation making one or both tail defects much smaller than their raw coefficient bounds;
- a structural recurrence forcing the same relation family to improve on infinitely many scales.

This is a concrete obstruction, not a search failure.

## 9. A renormalization interpretation of the prior frame degeneracies

The prior project work found two negative facts:

1. adjacent \(\beta\)-frames are exactly unimodularly conjugate;
2. later \(\alpha\)-convergent phase frames are perturbatively frozen around the same actual phase configuration in the regime where the approximation error is controlled.

Equations (6.2)–(6.3) now place those observations in one exact structure. The natural state is the unimodular lattice \(\Lambda_{m,n}\), not a particular coefficient rectangle or residue phase frame. Moving in \(m\) or \(n\) is just a diagonal renormalization preserving the triple coordinate product.

Accordingly, trying to manufacture a contradiction solely by comparing adjacent frames is unlikely to add information. A successful next step has to use something not invariant under this bookkeeping change: recurrence of the **lattice shape**, an additive restriction imposed by the unipotent form of the base lattice, entropy/return complexity, or an improvement in the common-denominator relation itself.

## 10. Relation to the uniform-variant counterexamples

The 2026 uniform counterexamples do not refute the present task. The uniform statement asks whether
\[
Q\min_{1\le q\le Q}\|q\alpha\|\|q\beta\|\to0.
\]
Failure permits infinitely many scales \(Q\) at which all denominators up to \(Q\) are collectively too weak. The classical conjecture asks only for some unbounded sequence \(q_j\) with
\[
q_j\|q_j\alpha\|\|q_j\beta\|\to0.
\]
Shulga's August 2026 theorem explicitly notes that the uniform counterexample set has large Hausdorff dimension, in contrast with the dimension-zero possible exceptional set for the classical problem.

Nothing in the double-grid theorem imports a uniform-variant counterexample into the classical setting.

### Conditional / conjectural

### Still open

The full Littlewood conjecture remains open. There is no exact pair with a proved positive classical liminf, and there is no universal proof that every pair has liminf zero.

## 12. Failed route closed in this iteration

A tempting idea is that the 2026 Thue–Siegel common-denominator theorem might already imply Littlewood after inserting convergent error estimates. Equation (8.4) shows why that inference is invalid: the generic coefficient exponent \(1/3\) is exactly the exponent at which the three normalized factors balance to constant order.

Thus a proof that merely reproduces \(R=O(N^{1/3})\) at comparable scales, with no additional tail-defect cancellation, cannot close the conjecture through this estimate.

## 14. Next attack

The next useful attack should work on the lattice state itself rather than on another adjacent coordinate frame.

Two concrete routes are now sharply posed.

**Route A — beat the cubic common-denominator threshold.** Search for a structural reason that the kernel relation
\[
xB_m+yB_{m+1}=zD_n+vD_{n+1}
\]
contains infinitely many solutions for which
\[
R_\alpha R_\beta\min(R_\alpha,R_\beta)=o(N_{m,n}),
\]
or for which the actual tail defects are much smaller than their coefficient envelopes. Either conclusion, together with (8.4), gives Littlewood directly.

**Route B — exploit the special unipotent origin of the grid.** The two-dimensional array \(\Lambda_{m,n}\) is an exact discrete positive-diagonal orbit of the special lattice \(\Lambda(\alpha,\beta)\). Under a hypothetical counterexample and bounded partial quotients this grid is uniformly compact. The next target is a recurrence/entropy statement showing that a uniformly compact grid of this special unipotent form must either become periodic/algebraic in a way already known to satisfy Littlewood, or develop a cusp excursion. This would connect the project’s explicit continued-fraction coordinates to the E-K-L rigidity mechanism without pretending to reprove it.
