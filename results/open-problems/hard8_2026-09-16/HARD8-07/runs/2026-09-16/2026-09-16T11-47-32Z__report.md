## 3. Hard-core notation

Rational coordinates are already solved: if \(\alpha=a/b\), every positive multiple of \(b\) has \(\|q\alpha\|=0\). Likewise, if either irrational coordinate is not badly approximable, a sequence with \(q\|q\alpha\|\to0\) (or the symmetric statement for \(\beta\)) settles Littlewood immediately because the other nearest-integer factor is at most \(1/2\).

Thus any genuine counterexample has both coordinates badly approximable. Write the continued fraction of \(\beta\) as
\[
\beta=[d_0;d_1,d_2,\ldots]
\]
with convergents
\[
\frac{C_n}{D_n}.
\]
For a fixed \(n\), define the complete quotient
\[
\eta_n=[d_{n+2};d_{n+3},\ldots]
\]
and
\[
\Delta_n=D_{n+1}\eta_n+D_n,
\qquad
\kappa_n=\frac{D_{n+1}}{\Delta_n}.
\]
Thus \(0<\kappa_n<1\).

For an integer coefficient pair \((z,v)\), define the signed represented denominator
\[
Q_n(z,v)=zD_n+vD_{n+1},
\]
the corresponding integer numerator combination
\[
R_n(z,v)=zC_n+vC_{n+1},
\]
and the signed tail defect
\[
\delta_n(z,v)=v-z\eta_n.
\]
When \(Q_n(z,v)\ne0\), put
\[
q_n(z,v)=|Q_n(z,v)|.
\]

## 4. New exact identity: the hyperbolic portal weight

The preceding run used only the inequality
\[
\|q\beta\|\le \frac{|\delta_n|}{\Delta_n}.
\]
The missing observation is that, throughout every sublinear coefficient regime relevant to the project, this can be upgraded to an exact factorization for \(q\|q\beta\|\).

### Theorem 4.1 — exact signed-tail and denominator identities

For every integer pair \((z,v)\),
\[
\boxed{
Q_n(z,v)\beta-R_n(z,v)
=
(-1)^{n+1}\frac{\delta_n(z,v)}{\Delta_n}.
}
\tag{4.1}
\]
Moreover,
\[
\boxed{
\frac{Q_n(z,v)}{\Delta_n}
=z+\kappa_n\delta_n(z,v).
}
\tag{4.2}
\]

#### Proof

The continued-fraction reconstruction is
\[
\beta=\frac{C_{n+1}\eta_n+C_n}{D_{n+1}\eta_n+D_n}
=\frac{C_{n+1}\eta_n+C_n}{\Delta_n}.
\]
Hence
\[
\begin{aligned}
Q_n\beta-R_n
&=\frac{(zD_n+vD_{n+1})(C_{n+1}\eta_n+C_n)
-(zC_n+vC_{n+1})(D_{n+1}\eta_n+D_n)}{\Delta_n}.
\end{aligned}
\]
The \(z\)-coefficient in the numerator is
\[
\eta_n(D_nC_{n+1}-C_nD_{n+1}),
\]
and the \(v\)-coefficient is
\[
D_{n+1}C_n-C_{n+1}D_n.
\]
Using
\[
C_{n+1}D_n-C_nD_{n+1}=(-1)^n,
\]
the numerator becomes
\[
(-1)^{n+1}(v-z\eta_n)=(-1)^{n+1}\delta_n,
\]
which proves (4.1).

For (4.2), simply subtract \(z\Delta_n\) from \(Q_n\):
\[
Q_n-z\Delta_n
=(v-z\eta_n)D_{n+1}=\delta_nD_{n+1}.
\]
Divide by \(\Delta_n\). QED.

### Corollary 4.2 — exact hyperbolic portal weight

Assume
\[
|\delta_n(z,v)|<\frac{\Delta_n}{2}.
\tag{4.3}
\]
Then the integer in (4.1) is the unique nearest integer to the represented \(\beta\)-multiple, and therefore
\[
\boxed{
q_n\|q_n\beta\|
=
\left|z+\kappa_n\delta_n\right|\,|\delta_n|.
}
\tag{4.4}
\]
Define the **hyperbolic portal weight**
\[
\boxed{
W_n(z,v)
:=
\left|z+\kappa_n\delta_n(z,v)\right|\,|\delta_n(z,v)|.
}
\tag{4.5}
\]
Then, whenever (4.3) holds,
\[
\boxed{W_n(z,v)=q_n\|q_n\beta\|.}
\tag{4.6}
\]

This is exact, not asymptotic.

### Consequence for the Littlewood product

For every such portal,
\[
\boxed{
q_n\|q_n\alpha\|\|q_n\beta\|
=W_n(z,v)\,\|q_n\alpha\|.
}
\tag{4.7}
\]
Thus the \(\beta\)-side geometry is completely summarized by the pointwise weight \(W_n\). The old estimate \(W_n\ll R S\) for a box/strip \(|z|,|v|\le R\), \(|\delta_n|\le S\), is only a coarse envelope.

If \(R,S=o(D_n)\), then (4.3) is automatic for all sufficiently large \(n\), since \(\Delta_n\ge D_n\) and \(|\delta_n|\le S\).

## 5. Sharpened pointwise alpha-convergent inequality

Let \(A_j/B_j\) be **any** convergent of \(\alpha\), and let \(A_{j+1}/B_{j+1}\) be its successor. Define
\[
\rho_j(q)=\left\|\frac{qA_j}{B_j}\right\|.
\]
The elementary triangle inequality gives the stronger bound
\[
\boxed{
\|q\alpha\|
\le
\rho_j(q)+\frac{q}{B_jB_{j+1}}.
}
\tag{5.1}
\]
Indeed,
\[
\|q\alpha\|
\le
\left\|\frac{qA_j}{B_j}\right\|
+q\left|\alpha-\frac{A_j}{B_j}\right|,
\]
and the convergent estimate is
\[
\left|\alpha-\frac{A_j}{B_j}\right|<\frac1{B_jB_{j+1}}
\]
for an irrational \(\alpha\).

Combining (4.7) and (5.1) gives an exact pointwise replacement for the previous box-scale anisotropic estimate.

### Theorem 5.1 — pointwise hyperbolic portal inequality

Whenever (4.3) holds,
\[
\boxed{
q_n\|q_n\alpha\|\|q_n\beta\|
\le
W_n(z,v)\,\rho_j(q_n)
+
W_n(z,v)\frac{q_n}{B_jB_{j+1}}.
}
\tag{5.2}
\]
Writing
\[
a_n(z,v)=\left|z+\kappa_n\delta_n(z,v)\right|,
\]
we have from (4.2)
\[
q_n=\Delta_n a_n,
\qquad
W_n=a_n|\delta_n|,
\]
so the second term is exactly
\[
\boxed{
\frac{\Delta_n a_n^2|\delta_n|}{B_jB_{j+1}}.
}
\tag{5.3}
\]

This is strictly more informative than replacing \(a_n\) by a global coefficient cap \(R\) and \(|\delta_n|\) by a strip width \(S\).

## 6. Matched-scale pointwise criterion

Assume the partial quotients of \(\alpha\) and \(\beta\) are bounded by \(A_\alpha\) and \(A_\beta\), respectively. Put
\[
K_\beta=(A_\beta+1)^2+1.
\]
Since
\[
D_{n+1}\le(A_\beta+1)D_n,
\qquad
\eta_n<A_\beta+1,
\]
we have
\[
\boxed{\Delta_n\le K_\beta D_n.}
\tag{6.1}
\]

Choose the matched \(\alpha\)-convergent index \(j=j(n)\) by
\[
B_j\le D_n<B_{j+1}.
\tag{6.2}
\]
Because
\[
B_{j+1}\le(A_\alpha+1)B_j,
\]
condition (6.2) implies
\[
B_j>\frac{D_n}{A_\alpha+1}.
\]
Consequently
\[
B_jB_{j+1}>\frac{D_n^2}{A_\alpha+1}.
\tag{6.3}
\]
Combining (5.3), (6.1), and (6.3),
\[
\boxed{
W_n\frac{q_n}{B_jB_{j+1}}
\le
K_\beta(A_\alpha+1)
\frac{a_n^2|\delta_n|}{D_n}.
}
\tag{6.4}
\]

### Corollary 6.1 — pointwise sufficient criterion

Suppose that for infinitely many \(n\) there is an integer portal \((z_n,v_n)\) with \(q_n\to\infty\) and (4.3), such that, for the matched index \(j(n)\),
\[
\boxed{
W_n(z_n,v_n)\,\rho_{j(n)}(q_n)\to0
}
\tag{6.5}
\]
and
\[
\boxed{
\frac{a_n(z_n,v_n)^2|\delta_n(z_n,v_n)|}{D_n}\to0.
}
\tag{6.6}
\]
Then the Littlewood conjecture holds for \((\alpha,\beta)\).

#### Proof

Apply (5.2), use (6.4), and let \(n\to\infty\) along the chosen subsequence. QED.

The prior criterion
\[
R^2S/D_n\to0,
\qquad
RS\rho\to0
\]
is recovered from (6.5)–(6.6) by the coarse bounds \(a_n\le R+S\) and \(|\delta_n|\le S\). The new version is pointwise and can succeed even when the enclosing coefficient box is much larger than the specific useful portal.

## 7. Frame-free weighted packing obstruction to a counterexample

Assume hypothetically that
\[
\Lambda
:=
\liminf_{q\to\infty}q\|q\alpha\|\|q\beta\|>0.
\tag{7.1}
\]
Fix any \(0<\lambda<\Lambda\). Then there is \(q_0\) such that
\[
q\|q\alpha\|\|q\beta\|\ge\lambda
\qquad(q\ge q_0).
\tag{7.2}
\]
For every portal satisfying (4.3) and \(q_n\ge q_0\), equation (4.7) gives
\[
\boxed{
\|q_n\alpha\|\ge\frac{\lambda}{W_n(z,v)}.
}
\tag{7.3}
\]
This is a frame-free exclusion inequality: no \(\alpha\)-convergent approximation has entered.

Now let
\[
\mathcal C_n(R,S)
=
\{(z,v)\in\mathbb Z^2:
|z|,|v|\le R,
|v-z\eta_n|\le S\}.
\]
For a signed portal define its **actual alpha phase**
\[
\Theta_n(z,v)
=Q_n(z,v)\alpha\pmod1.
\tag{7.4}
\]
For two portals \(u,u'\), their phase difference is generated by the difference portal:
\[
\|\Theta_n(u)-\Theta_n(u')\|
=
\|Q_n(u-u')\alpha\|.
\tag{7.5}
\]

The preceding checkpoint proved a bounded-type lower bound showing that when \(R_n=o(D_n)\), every nonzero difference represented by coefficients bounded by \(2R_n\) has absolute denominator tending to infinity uniformly. Therefore (7.2) applies to every pair for all sufficiently large \(n\). If also \(S_n=o(D_n)\), then (4.3) applies to every difference portal because its tail defect is at most \(2S_n\).

### Theorem 7.1 — frame-free weighted separation

Under the counterexample hypothesis (7.1), if
\[
R_n=o(D_n),
\qquad
S_n=o(D_n),
\]
then for all sufficiently large \(n\), every pair of distinct portals \(u,u'\in\mathcal C_n(R_n,S_n)\) satisfies
\[
\boxed{
\|\Theta_n(u)-\Theta_n(u')\|
\ge
\frac{\lambda}{W_n(u-u')}.
}
\tag{7.6}
\]
This holds throughout the full sublinear coefficient/strip range and requires **no** matched \(\alpha\)-frame and **no** condition \(R_n^2S_n=o(D_n)\).

Since \(0<\kappa_n<1\), a difference portal obeys
\[
W_n(u-u')
\le
(|\Delta z|+|\Delta\delta|)|\Delta\delta|
\le
4S_n(R_n+S_n).
\]
Thus, if \(S_n\le R_n\),
\[
\boxed{
\|\Theta_n(u)-\Theta_n(u')\|
\ge
\frac{\lambda}{8R_nS_n}.
}
\tag{7.7}
\]
The important improvement over the preceding modular-phase theorem is not merely a constant: (7.7) remains valid far beyond the perturbative regime \(R_n^2S_n=o(D_n)\), all the way to arbitrary sublinear \(R_n,S_n\).

Combined with the already archived strip-population lemma, a putative counterexample therefore forces \(\asymp R_nS_n\) actual \(\alpha\)-phases to form a critical-scale packing at **every** admissible sublinear strip scale.

This still does not contradict circle capacity: \(N\asymp RS\) points can in principle be separated at scale \(\asymp1/(RS)\). It is therefore a necessary rigidity statement, not a resolution.

## 8. Exact alpha-frame transition law

The previous run proposed comparing the same denominator set under successive \(\alpha\)-convergent phases. That transition can be written exactly.

Let \(A_j/B_j\) and \(A_{j+1}/B_{j+1}\) be consecutive convergents of \(\alpha\), and define
\[
\Phi_j(Q)=\frac{QA_j}{B_j}\pmod1.
\]
The determinant identity
\[
A_{j+1}B_j-A_jB_{j+1}=(-1)^j
\]
gives
\[
\boxed{
\frac{QA_{j+1}}{B_{j+1}}
-
\frac{QA_j}{B_j}
=
(-1)^j\frac{Q}{B_jB_{j+1}}.
}
\tag{8.1}
\]
Thus the adjacent-frame displacement is not an independent random rephasing. It is an explicit small linear shear in \(Q\).

Moreover, every later convergent phase lies close to the actual phase:
\[
\boxed{
\operatorname{dist}_{\mathbb R/\mathbb Z}
\bigl(\Phi_j(Q),Q\alpha\bmod1\bigr)
\le
\frac{|Q|}{B_jB_{j+1}}.
}
\tag{8.2}
\]
For any later \(k\ge j\), monotonicity of the convergent denominators gives
\[
\boxed{
\operatorname{dist}_{\mathbb R/\mathbb Z}
\bigl(\Phi_k(Q),Q\alpha\bmod1\bigr)
\le
\frac{|Q|}{B_kB_{k+1}}
\le
\frac{|Q|}{B_jB_{j+1}}.
}
\tag{8.3}
\]
So **all future alpha frames are trapped in a shrinking neighborhood of one frame-free phase configuration**.

## 9. New route obstruction: successive alpha frames are asymptotically frozen in the old perturbative regime

The weighted counterexample exclusion (7.3) and the approximation error (8.2) interact through exactly the second term in the pointwise portal inequality.

Indeed, for a portal with weight \(W\),
\[
\left|\|Q\alpha\|-\left\|\frac{QA_j}{B_j}\right\|\right|
\le
\frac{|Q|}{B_jB_{j+1}}.
\]
Multiplying by \(W\), the total distortion at the natural weighted scale is
\[
\boxed{
W\frac{|Q|}{B_jB_{j+1}},
}
\tag{9.1}
\]
which is precisely the error term in (5.2).

Therefore, if
\[
W\frac{|Q|}{B_jB_{j+1}}=o(1),
\tag{9.2}
\]
then a lower bound of order \(1/W\) for the actual phase automatically transfers to the \(j\)-th convergent phase and to **every later** convergent phase with only \(o(1/W)\) loss.

For a matched frame and a box/strip difference with \(S\le R\), the old estimates give
\[
W\ll RS,
\qquad
|Q|\ll RD_n,
\qquad
B_jB_{j+1}\gg D_n^2,
\]
so
\[
W\frac{|Q|}{B_jB_{j+1}}
\ll
\frac{R^2S}{D_n}.
\tag{9.3}
\]
Hence throughout the exact scale range used in the preceding anisotropic theorem,
\[
\boxed{
R_n^2S_n/D_n\to0,
}
\]
the phase drift between the actual \(\alpha\)-rotation and every successive matched/future \(\alpha\)-convergent model is asymptotically **smaller than the counterexample-forced packing scale**.

### Corollary 9.1 — the proposed cross-alpha-frame attack is perturbatively non-independent

In the regime \(R_n^2S_n=o(D_n)\), comparing the same \(\beta\)-resonant \(Q\)-set under successive or later \(\alpha\)-convergent phases cannot, by itself, create a new packing incompatibility: all of those phase sets are \(o(1/(R_nS_n))\)-perturbations of the same actual phase set.

This is the \(\alpha\)-side analogue of the previous checkpoint's exact \(\beta\)-frame conjugacy obstruction. Together they eliminate both obvious “compare adjacent frames” strategies:

- changing the \(\beta\)-frame is an exact integer coordinate conjugacy;
- changing to later \(\alpha\)-convergent phases is a vanishing perturbation of the actual phase configuration in precisely the regime where the modular portal error is controlled.

The next proof attempt must therefore either:

1. work directly with the frame-free actual phases \(Q\alpha\bmod1\), where Theorem 7.1 remains valid on much larger sublinear scales; or
2. deliberately enter a nonperturbative regime where \(W|Q|/(B_jB_{j+1})\) is order one and derive new information rather than treating it as an error term; or
3. return to the fixed \(SL_3\)-lattice/diagonal-flow formulation and exploit entropy or recurrence not visible in single-frame packing.

## 10. Why the new frame-free theorem is a real enlargement, but not a proof

The earlier modular packing theorem required
\[
R_n^2S_n=o(D_n)
\]
to make the \(\alpha\)-convergent approximation error negligible. Theorem 7.1 removes that restriction entirely: it uses the actual \(\alpha\)-phase, so it only needs the sublinear conditions ensuring that difference denominators escape to infinity and the \(\beta\)-tail formula is the nearest-integer error.

For example, with
\[
R_n=D_n^{0.9},
\qquad
S_n=1,
\]
the old modular error scale is
\[
R_n^2S_n/D_n=D_n^{0.8},
\]
which is useless, while the new frame-free weighted separation remains valid under a hypothetical counterexample.

But the number of strip portals is still only of the same order as the reciprocal separation scale. Thus ordinary one-scale pigeonhole/circle packing remains exactly critical. This identifies the next missing ingredient more precisely: one needs a **multiscale, additive-energy, return-map, or entropy statement** saying that the nested cut-and-project portal sets cannot remain critically packed by the single rotation \(Q\mapsto Q\alpha\) at all sublinear scales.

That is compatible with the Einsiedler–Katok–Lindenstrauss perspective: a genuine counterexample would have extremely low dynamical complexity. The present work does not reprove their theorem and does not claim that the weighted packing condition alone implies entropy zero; it only produces an explicit continued-fraction coordinate manifestation that may be suitable for a combinatorial attack.

## 13. Failed route and next attack

**Failed route:** the previous plan to seek incompatibility between successive matched \(\alpha\)-convergent packings. Equations (8.1)–(9.3) show that, exactly where the modular method has controlled error, those phase configurations are only negligible perturbations of one actual \(\alpha\)-rotation. Repeating that strategy would repackage the same constraint.

**Next attack:** work directly with the weighted actual phases from Theorem 7.1 at scales outside the old perturbative window. In particular, study the cut-and-project set
\[
\mathcal C_n(R,S)
\]
under the homomorphism
\[
(z,v)\mapsto (zD_n+vD_{n+1})\alpha\pmod1
\]
and exploit **nested scales and additive structure**, rather than a single packing number. Concrete targets for the next bounded run are:

1. derive exact return-time decompositions of the thin strip \(|v-z\eta_n|\le S\) from the continued fraction of \(\eta_n\);
2. quantify the additive energy of the represented denominator set and compare it with the weighted separation constraints (7.6);
3. test whether repeated near-critical packing forces a bounded-complexity Sturmian/three-gap phase pattern, which could then be transferred to a rigidity statement in the fixed unimodular Littlewood lattice;
4. if this fails, document an explicit synthetic critically packed model showing the obstruction and switch to the diagonal-flow entropy route.

The classical Littlewood conjecture remains **OPEN**.
