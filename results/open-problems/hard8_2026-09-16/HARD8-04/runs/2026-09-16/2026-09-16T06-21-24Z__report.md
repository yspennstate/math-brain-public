## 3. Binary Legendre-pair route, written as an exact certificate theorem

Let `v` be odd. For `a=(a_0,...,a_{v-1}) in {±1}^v`, define periodic autocorrelation

\[
\operatorname{PAF}_a(t)=\sum_{i=0}^{v-1}a_i a_{i+t},
\]

with indices modulo `v`. A normalized binary Legendre pair is a pair `(a,b)` with

\[
\sum_i a_i=\sum_i b_i=1,
\qquad
\operatorname{PAF}_a(t)+\operatorname{PAF}_b(t)=-2
\quad (t\ne0).
\]

Global negation preserves every PAF, so any binary Legendre pair with row sums `±1` can be normalized this way.

### Proposition 3.1 — explicit two-circulant-core construction

Let `A,B` be the `v x v` circulant matrices generated by `a,b`. Then

\[
AA^{\mathsf T}+BB^{\mathsf T}
=2(v+1)I_v-2J_v.
\]

Indeed the diagonal entries are `2v`, and every nonzero cyclic displacement gives the Legendre sum `-2`.

Because circulant matrices commute and are normal, the following `2(v+1) x 2(v+1)` sign matrix is Hadamard:

\[
H=\begin{pmatrix}
1&1&-\mathbf1^{\mathsf T}&-\mathbf1^{\mathsf T}\\
1&-1&\mathbf1^{\mathsf T}&-\mathbf1^{\mathsf T}\\
\mathbf1&\mathbf1&A&B\\
\mathbf1&-\mathbf1&-B^{\mathsf T}&A^{\mathsf T}
\end{pmatrix}.
\]

The lower `2v` rows have core Gram matrix

\[
\begin{pmatrix}
AA^{\mathsf T}+BB^{\mathsf T}&0\\
0&B^{\mathsf T}B+A^{\mathsf T}A
\end{pmatrix}
=
2(v+1)I_{2v}-2\operatorname{diag}(J_v,J_v),
\]

while the first two border columns contribute exactly `2 diag(J_v,J_v)`. The row-sum normalization makes the first two rows orthogonal to all lower rows, and they are mutually orthogonal. Hence

\[
HH^{\mathsf T}=2(v+1)I.
\]

Taking `v=2m-1` gives order `4m`. Thus the conjecture “binary Legendre pairs exist for every odd `v`” is a sufficient, more structured route to the full Hadamard conjecture.

## 4. New exact defect formulation for this campaign

This section is an exact reformulation and search obstruction developed in this run. I am **not claiming literature novelty**; the bounded source search above did not locate this particular energy-gap/local-barrier formulation.

For a balanced pair `(a,b)` with both sums `1`, define for `1 <= t <= (v-1)/2`

\[
d_t=\operatorname{PAF}_a(t)+\operatorname{PAF}_b(t)+2,
\qquad
E(a,b)=\sum_{t=1}^{(v-1)/2}d_t^2.
\]

Then `E=0` exactly for Legendre pairs.

### Lemma 4.1 — divisibility of every defect

For any binary sequence `a`, the Hamming distance between `a` and a cyclic shift is even: every `+ -> -` transition is matched by a `- -> +` transition. Therefore

\[
\operatorname{PAF}_a(t)=v-2D_t\equiv v\pmod4.
\]

Since `v` is odd,

\[
d_t\equiv 2v+2\equiv0\pmod4.
\]

So every defect is an integer multiple of four.

### Lemma 4.2 — zero-sum defect constraint

The basic identity

\[
\sum_{t=0}^{v-1}\operatorname{PAF}_a(t)=\left(\sum_i a_i\right)^2
\]

gives total `1` for each normalized sequence. Hence

\[
\sum_{t=1}^{v-1}
\left(\operatorname{PAF}_a(t)+\operatorname{PAF}_b(t)+2\right)=0.
\]

By the symmetry `PAF(t)=PAF(v-t)`, this implies

\[
\sum_{t=1}^{(v-1)/2}d_t=0.
\]

### Theorem 4.3 — universal positive defect-energy gap

If `(a,b)` is not a Legendre pair, then

\[
E(a,b)\ge 32.
\]

Proof: a nonzero defect vector consists of multiples of four and has sum zero. Therefore at least two coordinates are nonzero, one positive and one negative; each has magnitude at least four. Thus `E >= 4^2+4^2=32`.

Moreover `E=32` iff the half-defect vector has exactly one `+4`, exactly one `-4`, and all other coordinates zero.

This gives an exact objective with a nontrivial forbidden interval `(0,32)`; there are no “almost solutions” of smaller positive squared-correlation error in this normalization.

### Theorem 4.4 — equivalent spectral-flatness energy

Let

\[
\widehat a(k)=\sum_{j=0}^{v-1}a_j\zeta_v^{-jk},
\quad
P_k=|\widehat a(k)|^2+|\widehat b(k)|^2.
\]

The target correlation vector has value `2v` at shift zero and `-2` elsewhere. Its DFT is `2` at frequency zero and `2(v+1)` at every nonzero frequency. Since the normalized row sums give `P_0=2`, Parseval yields the exact identity

\[
2E(a,b)=\frac1v\sum_{k=1}^{v-1}
\left(P_k-2(v+1)\right)^2.
\]

Thus correlation-defect descent and PSD-flattening are literally the same quadratic optimization.

At the minimum positive level `E=32`, if the nonzero half-defects occur at distinct shifts `r,s` with signs `+4,-4`, then for nonzero `k`

\[
P_k-2(v+1)
=8\left(\cos\frac{2\pi kr}{v}-\cos\frac{2\pi ks}{v}\right).
\]

So the entire spectral defect is controlled by two shift locations. This is a small algebraic state space worth exploiting rather than treating near-solutions as arbitrary.

## 5. Broader Goethals–Seidel analogue

The same argument is not limited to the stronger binary-Legendre route. Suppose four binary sequences `x^(1),...,x^(4)` of odd length `v` have row sums `sigma_j` satisfying

\[
\sum_{j=1}^4\sigma_j^2=4v.
\]

Write

\[
S_t=\sum_{j=1}^4\operatorname{PAF}_{x^{(j)}}(t),
\qquad
G=\sum_{t=1}^{(v-1)/2}S_t^2.
\]

A circulant Goethals–Seidel quadruple requires `S_t=0` for every nonzero shift. Each `S_t` is divisible by four because it is a sum of four binary PAFs, each congruent to `v (mod 4)`. Also

\[
\sum_t S_t=\sum_j \sigma_j^2=4v=S_0,
\]

so the half-shift defects sum to zero. Consequently either `G=0` or

\[
G\ge32.
\]

The same Parseval calculation gives

\[
2G=\frac1v\sum_{k=1}^{v-1}
\left(\sum_{j=1}^4|\widehat{x^{(j)}}(k)|^2-4v\right)^2.
\]

This generalizes the exact “energy gap plus spectral flatness” certificate to a broader construction family that directly gives Hadamard matrices of order `4v` when the four circulant correlation equations are solved. It is therefore a more flexible continuation path than relying only on the stronger all-odd binary Legendre-pair conjecture.

## 6. Exact local-search obstruction at length 15

A tempting proof strategy would be: from any balanced pair, repeatedly exchange one `+1` and one `-1` position (preserving row sum) in either or both sequences, and prove that `E` strictly decreases until it reaches zero. This run finds an exact obstruction to that strategy.

Let `v=15`, and encode a sequence by the positions occupied by `+1`. Take

```
A0 = {0,2,4,5,6,7,11,14}
B0 = {3,5,7,8,10,11,13,14}.
```

Both sequences have sum `1`. Their half-defect vector is exactly

\[
(-4,0,+4,0,0,0,0),
\]

so `E=32`, the smallest positive value allowed by Theorem 4.3.

I exhaustively evaluated the entire neighborhood in which **each** sequence may perform at most one balanced exchange (`+1` position swapped with a `-1` position), including changing both sequences simultaneously. The minimum energy in this whole neighborhood is still `32`. Therefore there is no strictly decreasing move from this state under that natural neighborhood.

However it is not a trapped component if plateau moves are permitted. The exact path

```
A1 = A0
B1 = {0,5,7,8,10,11,13,14}
```

has defect

\[
(0,0,+4,-4,0,0,0),\qquad E=32,
\]

and then

```
A2 = {0,4,5,6,7,9,11,14}
B2 = {0,2,7,8,10,11,13,14}
```

is an exact Legendre pair with defect vector zero. Thus the energies along this two-step path are

\[
32\longrightarrow32\longrightarrow0.
\]

Using Proposition 3.1, `(A2,B2)` gives a `32 x 32` Hadamard matrix, and the companion verifier checks `HH^T=32I` in exact integer arithmetic.

### Consequence

Any universal local-descent proof using only **strict decrease of this quadratic defect energy** under one balanced exchange per sequence is false. A viable descent theorem needs at least one of:

1. plateau motion with a secondary potential;
2. a larger local move class;
3. a nonlocal algebraic/compression step;
4. a different Lyapunov function.

The minimum-energy layer is especially structured: exactly two shift defects of opposite sign. This suggests attacking the `E=32` manifold symbolically before trying to control arbitrary energies.
