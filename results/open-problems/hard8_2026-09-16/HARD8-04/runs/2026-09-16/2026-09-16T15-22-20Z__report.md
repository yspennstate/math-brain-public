## 4. New partial theorem for the admitted H(2092) target

A periodic T-matrix quadruple of order 523 would immediately yield H(2092) through the classical Cooper-Wallis / Goethals-Seidel route with the order-1 Williamson quadruple. I therefore examined the multiplicative-subgroup-invariant T(523) search class before launching an expensive search.

### Proposition: exact multiplier-order gate at 523

Let `T_0,T_1,T_2,T_3 : Z_523 -> {0,+1,-1}` have pairwise disjoint supports partitioning `Z_523` and satisfy

\[
\sum_{i=0}^3 \operatorname{PAF}_{T_i}(s)=523\,\delta_{s,0}.
\]

Suppose all four sequences are invariant under multiplication by a nontrivial subgroup `K <= Z_523^*` of order `d`. Then

\[
\boxed{d\in\{3,9\}.}
\]

Moreover, in the `d=9` case, after permuting components and negating components as allowed so that `T_0(0)=+1`, the row sums are forced to be

\[
\boxed{(19,9,9,0)}.
\]

There are 58 nonzero K-orbits, and the ordered support-orbit counts have exactly 4060 possibilities.

### Proof

Because 523 is prime, every nonzero K-orbit has size `d`, while `0` is fixed. Exactly one component is nonzero at 0. Permute the four components and negate the component containing 0 if necessary so that

\[
T_0(0)=+1.
\]

For `i=0,1,2,3`, let `a_i` be the number of nonzero K-orbits in the support of `T_i`. Within those `a_i` orbits, let `z_i` be the number of `+` orbits minus the number of `-` orbits. Then

\[
\sum_i a_i=\frac{522}{d},\qquad |z_i|\le a_i,\qquad z_i\equiv a_i\pmod2,
\]

and the four row sums are

\[
r_0=1+d z_0,\qquad r_i=d z_i\quad(i=1,2,3).
\]

Now sum the periodic-correlation identity over all shifts `s`. For any sequence `x`,

\[
\sum_s \operatorname{PAF}_x(s)
=\left(\sum_q x(q)\right)^2.
\]

Hence

\[
(1+d z_0)^2+d^2(z_1^2+z_2^2+z_3^2)=523. \tag{1}
\]

Also `d | 522`, so

\[
d\in\{1,2,3,6,9,18,29,58,87,174,261,522\}.
\]

If `d>1` is even, `1+d z_0` is odd and the other three row sums are even. Therefore the left side of (1) is `1 mod 4`, while

\[
523\equiv3\pmod4,
\]

a contradiction. Thus `d` is odd.

For odd `d>=29`, every row sum has absolute value at most `sqrt(523)<23`. Divisibility forces

\[
dz_1=dz_2=dz_3=0.
\]

Also `|1+d z_0|<23` and `d>=29` force `z_0=0`, giving left side `1`, not `523`. Thus every odd divisor `d>=29` is impossible.

The only nontrivial divisors left are `d=3` and `d=9`. This proves the first statement.

For `d=9`, equation (1) becomes

\[
(1+9z_0)^2+81(z_1^2+z_2^2+z_3^2)=523.
\]

The bound `|1+9z_0|<=sqrt(523)<23` gives `z_0 in {-2,-1,0,1,2}`. Checking these five exact possibilities, the residual `523-(1+9z_0)^2` is a nonnegative multiple of 81 only for `z_0=2`, where

\[
523-19^2=162=2\cdot81.
\]

Thus

\[
z_1^2+z_2^2+z_3^2=2,
\]

so, up to permuting `T_1,T_2,T_3` and negating those components,

\[
(z_0,z_1,z_2,z_3)=(2,1,1,0),
\]

which gives row sums `(19,9,9,0)`.

Finally, the parity/bound conditions on the support-orbit counts give

\[
a_0=2+2x_0,\quad a_1=1+2x_1,\quad a_2=1+2x_2,\quad a_3=2x_3,
\]

with `x_i>=0`. Since the number of nonzero K-orbits is `522/9=58`,

\[
x_0+x_1+x_2+x_3=27.
\]

The number of ordered nonnegative solutions is therefore

\[
\binom{27+4-1}{4-1}=\boxed{\binom{30}{3}=4060}.
\]

This completes the proof.
