## 3. B3 — prove something stronger: a continuum of source-endpoint counterexamples

The earlier report used the concrete exponent `3/2`. The same argument works for every `α∈(1,2]`.

Fix `α∈(1,2]` and define a root degree law supported on `{3,4,5,...}` by

```text
P(D=k)=k^{-(α+2)},       k>=4,
P(D=3)=1-sum_{k>=4} k^{-(α+2)}.
```

(The displayed tail mass is strictly below one, so this is a probability law.) Since `D>=3`, both `g'(1)` and `g''(1)` are positive. Moreover

```text
g''(1) = E[D(D-1)] < infinity
```

because the tail summand is asymptotic to `k^{-α}` and `α>1`, whereas

```text
g'''(1) = E[D(D-1)(D-2)] = infinity
```

because the tail summand is asymptotic to `k^{1-α}` and `α<=2`.

For a non-root UGW vertex let

```text
ν = D* - 1.
```

Then exactly

```text
P(ν=j) = (j+1) P(D=j+1) / g'(1)
        ~ (1/g'(1)) j^{-(α+1)},
```

so

```text
P(ν>x) ~ [1/(α g'(1))] x^{-α}.                 (3.1)
```

Choose the constant transmission probability

```text
r = 1/Eν = g'(1)/g''(1).
```

Because `D>=3`, `D(D-1)>=2D`, hence `g''(1)>=2g'(1)` and therefore `0<r<=1/2`. Let

```text
ξ | ν ~ Bin(ν,r).
```

Then `Eξ=rEν=1`: the descendant process is exactly critical. It is aperiodic because `P(ξ=0)>0` and `P(ξ=1)>0`.

Bernoulli thinning preserves regular variation. One elementary proof is to fix `δ∈(0,r)`, split on `ν<(1-δ)x/r`, `ν>(1+δ)x/r`, and use Chernoff bounds for the binomial deviations in the two intermediate directions; the exponentially small conditional errors are negligible relative to the polynomial tail (3.1). Hence

```text
P(ξ>x) ~ [r^α/(α g'(1))] x^{-α}.               (3.2)
```

For `1<α<2`, `ξ-1` is therefore in the domain of attraction of a spectrally positive `α`-stable law with a norming sequence

```text
B_n = n^{1/α} L(n)
```

for a slowly varying `L`. Duquesne's theorem under exact total-progeny conditioning gives conditioned-tree height scale

```text
n/B_n = n^{1-1/α}/L(n).
```

Because `α<2`,

```text
(n/B_n)/sqrt(n) = n^{1/2-1/α}/L(n) -> 0.       (3.3)
```

The exceptional original UGW root is handled by exactly the delayed-root argument of the previous report: if `η|D~Bin(D,r)` and `N=1+T_1+...+T_η`, the generalized Dwass identity plus the stable lattice local limit theorem gives

```text
P(η=k | N=n) -> k P(η=k)/Eη,
```

so the conditioned number of root components is tight. Applying (3.3) to each of those finitely many conditioned descendant trees gives

```text
diam(S)/sqrt(n) -> 0 in probability given |S|=n.
```

Thus the source `n^{-1/2}` scaling fails for a whole continuum of admissible finite-root-second-moment laws, not only the earlier `α=3/2` witness.

**B3 outcome:** success. The counterexample mechanism is robust on the entire interval `α∈(1,2)` and reaches a qualitatively sharper boundary at `α=2`, treated next.

## 4. B7 — take the limit: the Gaussian boundary `α=2`

The strongest diagnostic is the endpoint of the preceding family. Define

```text
P(D=k)=k^{-4},              k>=4,
P(D=3)=1-sum_{k>=4} k^{-4}.
```

Direct evaluation gives

```text
sum_{k>=4} k^{-4} = 0.0074775546987925125036580175...,
P(D=3)              = 0.9925224453012074874963419825...,
g'(1)               = 3.0175872020261797108517270719...,
g''(1)              = 6.1989377614218030019766548259...,
m_*                  = 2.0542696354423439846326904846...,
r=g'(1)/g''(1)       = 0.4867910145518316649507175157...,
g'''(1)              = infinity.
```

For `ν=D*-1`, the tail is now exact up to the finite initial modification:

```text
P(ν=j) = 1/[g'(1)(j+1)^3],       j>=3,
P(ν>x) ~ [1/(2g'(1))] x^{-2}.                    (4.1)
```

Consequently

```text
E[ν^2 1_{ν<=x}] ~ [1/g'(1)] log x.              (4.2)
```

After critical Bernoulli thinning,

```text
ξ|ν ~ Bin(ν,r),
P(ξ>x) ~ [r^2/(2g'(1))] x^{-2},                 (4.3)
```

and the truncated variance of `ξ-1` is slowly varying and diverges logarithmically:

```text
V(x)=E[(ξ-1)^2 1_{|ξ-1|<=x}]
    ~ [r^2/g'(1)] log x.                         (4.4)
```

Therefore `ξ-1` belongs to the **normal domain of attraction (`α=2`) but has infinite variance**. Let `B_n` be the canonical normal norming, characterized for example by

```text
n V(B_n) / B_n^2 -> 1.
```

From (4.4),

```text
B_n asymp sqrt(n log n),
B_n/sqrt(n) -> infinity.                         (4.5)
```

Duquesne's `α=2` exact-total-progeny theorem now has a particularly revealing conclusion: the limiting continuum tree is still **Brownian CRT**, but the discrete metric must be scaled on the height scale

```text
n/B_n asymp sqrt(n/log n),
```

not on `sqrt(n)`.

The literal UGW root again cannot repair this. The generalized Dwass identity for `k` root subtrees is

```text
P(T_1+...+T_k=m)
 = (k/m) P((ξ_1-1)+...+(ξ_m-1)=-k).
```

The span-one normal-domain lattice local limit theorem yields, for fixed `k`,

```text
B_m P(sum_{i=1}^m (ξ_i-1)=-k) -> φ(0)>0,
```

and a uniform concentration bound `sup_j B_m P(sum=j)<=C`. Since `Eη<∞`, dominated convergence gives

```text
P(N=n) ~ Eη φ(0)/(n B_n),
P(η=k|N=n) -> kP(η=k)/Eη.                       (4.6)
```

Thus the number of conditioned root components is tight. Conditional height convergence/tightness at scale `m/B_m`, together with `B_m/sqrt(m)->∞`, implies uniformly over component sizes at most `n` that each root component has height `o_P(sqrt(n))`. Hence

```text
boxed: diam(S)/sqrt(n) -> 0 in probability, given |S|=n.   (4.7)
```

Equation (4.7) implies that under **any finite fixed source-style coefficient** `Σ/√n`, the rooted metric-measure tree converges in GHP probability to a one-point space, not to the nondegenerate standard Brownian CRT. If one instead uses the correct nonstandard factor `B_n/n`, the Brownian CRT reappears.

This is a cleaner counterexample than the `3/2`-stable witness: the shape universality class at the correct scale is Brownian, so the failure is exactly that `g''(1)<∞` does not control the effective variance or the `sqrt(n)` normalization after UGW size biasing.

**B7 outcome:** success. The source endpoint fails already at the Gaussian boundary of the stable domain of attraction.

## 5. B24 — find the extremal threshold: the exact scalar moment condition

The source's moment-indexing issue can be stated exactly in the one-type saturated reduction.

For the size-biased non-root forward count `ν=D*-1`,

```text
Eν                    = g''(1)/g'(1),
E[ν(ν-1)]             = g'''(1)/g'(1),
Var(ν)                 = g'''(1)/g'(1)
                         + g''(1)/g'(1)
                         - (g''(1)/g'(1))^2.     (5.1)
```

Given `ν`, let `ξ~Bin(ν,r)` with fixed `r∈(0,1)`. The law of total variance gives

```text
Var(ξ)
 = r(1-r) Eν + r^2 Var(ν).                       (5.2)
```

Assuming `g''(1)<∞`, the first term in (5.2) is finite. Since `r>0`, equations (5.1)–(5.2) imply the exact equivalence

```text
boxed: Var(ξ)<∞  iff  g'''(1)<∞.                 (5.3)
```

At scalar criticality `r=g'(1)/g''(1)`, nothing changes in this equivalence. Therefore the natural classical finite-variance threshold for the **effective critical offspring law** is a finite third factorial moment of the original UGW root degree, not the finite second factorial moment proposed in Remark 6.5/Open problem (3).

This also reconciles the source's sentence that “the single-type finite-variance case is classical” with Aldous: it is correct if “finite variance” refers to the actual critical offspring count `ξ`. Under UGW size biasing, `g''(1)<∞` does not give that condition; `g'''(1)<∞` does in the one-type model.

I do **not** promote (5.3) into a complete multitype sharp theorem. In the full finite-type case the correct condition is finiteness of the Perron-weighted offspring covariance tensor, and source-specific type weights/transmission probabilities can matter. The claim here is exact only for the scalar reduction, which is already enough to refute the universal `g''(1)<∞` endpoint.

**B24 outcome:** success. The scalar threshold is identified exactly and explains the one-moment shift responsible for H0005.
