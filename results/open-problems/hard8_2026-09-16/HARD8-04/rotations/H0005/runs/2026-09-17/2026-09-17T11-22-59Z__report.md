## 4. B25 — count the same thing twice: exact delayed-root conditioning

### 4.1 Literal root offspring

Under the exact source UGW model, the root has `D` potential children rather than `ν`. With the same one-type transmission probability `r`, let

```text
η | D ~ Bin(D,r).
```

The root failed cluster is therefore a **delayed Galton–Watson tree**:

- the root has `η` failed children;
- each failed child starts an independent ordinary critical GW tree with descendant offspring law `ξ`.

Write `T` for the total progeny of one ordinary `ξ`-GW tree, and let `T_1,T_2,...` be iid copies. The literal source cluster size is

```text
N = 1 + T_1 + ... + T_η.
```

Because `D` has finite second moment, `η` has finite second moment in particular `0<Eη<∞`.

### 4.2 Generalized Dwass identity at the root

For fixed `k>=1`, a forest of `k` independent `ξ`-GW trees has exact total-size law

```text
P(T_1+...+T_k = m)
  = (k/m) P(ξ_1+...+ξ_m = m-k).
```

Equivalently, with `Y_i=ξ_i-1`,

```text
P(T_1+...+T_k = m)
  = (k/m) P(Y_1+...+Y_m = -k).                 (4.1)
```

This is the forest form of the Dwass/Kemperman cyclic lemma. Since `Y` is aperiodic and in the `3/2`-stable domain of attraction, the lattice stable local limit theorem gives

```text
B_m P(Y_1+...+Y_m = -k) -> f_α(0) > 0          (4.2)
```

for every fixed `k`, together with the uniform concentration bound

```text
sup_j B_m P(Y_1+...+Y_m = j) <= C.             (4.3)
```

Here `B_m ~ c_B m^(2/3)`.

Taking `m=n-1`, equations (4.1)–(4.3) give

```text
P(N=n, η=k)
 = P(η=k) (k/(n-1)) P(sum_{i=1}^{n-1} Y_i = -k)
 ~ P(η=k) k f_α(0) / ((n-1) B_{n-1})           (4.4)
```

for every fixed `k`.

The uniform bound (4.3) dominates the `k`th summand in `(n B_n) P(N=n)` by `C k P(η=k)`. This is summable because `Eη<∞`. Dominated convergence therefore yields the exact delayed-root local asymptotic

```text
P(N=n)
 ~ Eη * f_α(0) / (n B_n)
 ~ C_root n^(-5/3).                            (4.5)
```

More importantly, division of (4.4) by (4.5) gives, for every fixed `k`,

```text
P(η=k | N=n) -> k P(η=k)/Eη.                   (4.6)
```

The limiting right-hand side sums to one. Hence the whole conditional root-degree distribution converges in total variation to the size-biased law of `η`. In particular,

```text
η | {N=n} is tight.                            (4.7)
```

This removes the possible loophole that exact total-size conditioning might force the exceptional root to have a diverging number of children and thereby restore Brownian geometry. It does not.

### 4.3 Uniform height collapse for every fixed number of root subtrees

Let `\mathcal T_m` be an ordinary `ξ`-GW tree conditioned to have exactly `m` vertices, and `H_m` its height. Duquesne's exact-progeny stable-tree theorem gives

```text
H_m / (m/B_m)  tight,
```

and in our pure power-law witness `m/B_m asymp m^(1/3)`. Thus the family

```text
H_m / m^(1/3)
```

is tight over admissible large `m`.

Fix `eps>0`. Define

```text
u_n(eps) = sup_{1<=m<=n, P(T=m)>0} P(H_m > eps sqrt(n)).
```

Then `u_n(eps)->0`. Indeed:

- if `m <= eps sqrt(n)`, deterministically `H_m <= m-1 < eps sqrt(n)`;
- if `m > eps sqrt(n)`, then

```text
eps sqrt(n) / m^(1/3) >= eps n^(1/6),
```

because `m<=n`, and the right side tends to infinity. Tightness of `H_m/m^(1/3)` therefore makes the supremum tend to zero.

Now condition a `k`-tree forest on total progeny `n-1`. Given its component sizes `(m_1,...,m_k)`, the component trees are independent GW trees conditioned on those sizes. Therefore, for every fixed `K`, uniformly over `1<=k<=K`,

```text
P(max_{1<=i<=k} H_{m_i} > eps sqrt(n)
  | T_1+...+T_k=n-1)
 <= K u_n(eps) -> 0.                           (4.8)
```

By conditional root-degree tightness (4.7), first choose `K` so that

```text
sup_{large n} P(η>K | N=n)
```

is arbitrarily small, and then use (4.8). Hence under the **literal delayed-root source law**,

```text
max root-subtree height / sqrt(n) -> 0
```

in probability given `N=n`.

The full delayed tree is obtained by joining those root subtrees at one new root, so

```text
diam(S) <= 2 + 2 max_i H_i.
```

Consequently

```text
boxed:  diam(S)/sqrt(n) -> 0 in probability, conditioned on |S|=n.  (4.9)
```

For any fixed finite positive constant `Σ`, (4.9) implies

```text
(S, (Σ/sqrt(n)) d_gr, unif_S)
   -> one-point metric-measure space
```

in rooted GHP probability. It therefore cannot converge to the nondegenerate Brownian CRT.

This is the exact root-level repair missing from the previous report. It preserves the source's UGW root law rather than replacing the root by a typical size-biased vertex.


for positive boundary distances after fixing admissible `alpha,mu`.

Set

```text
F(h)=integral_0^h exp(-alpha y^2/mu) dy.
```

Then `F` is continuous and strictly increasing, `F(0)=0`, and

```text
L := lim_{h->infinity} F(h) in (0,infinity).
```

Given any desired `r in (0,1)`, put

```text
q=(1-r)/r > 0.
```

Choose `a>0` so small that `q F(a)<L`. By continuity and strict monotonicity there is a unique `b>0` with

```text
F(b)=qF(a).
```

Then choosing the two source boundary distances as

```text
h_theta=a,  h_safe=b
```

gives exactly

```text
p = F(a)/(F(a)+F(b)) = 1/(1+q) = r.            (5.1)
```
