# R03 run13 C239 refinement — 2026-09-16

This note sharpens the residual event named in C239 of the immutable run report. It does not change the validity of the displayed C239 upper bound; the report's support-only residual is a superset of the sharper JSS residual below.

Let `Cons(delta,rho)` be the Jain–Sah–Sawhney almost-constant class from their Theorem 1.5, let

`A_row = {there exists x in Cons(delta,rho) with B_n^T x = 0}`,

and let `U_row` be the union of signed equal/opposite row-pair events. For Rademacher entries, Theorem 1.5 at `t=0` and second Bonferroni give, for all sufficiently large `n`,

`P(A_row \ U_row) <= C(n(n-1),2) 4^{-n} + 2^{-n} exp(-eta n)`

for the theorem's existential `delta,rho,eta>0`.

Define the sharper residual

`R_JSS = {B_n singular; no signed row or column pair; no unit left-null vector belongs to Cons(delta,rho)}`.

Then

`P(det B_n=0) <= 2n(n-1)2^{-n} + C(n(n-1),2)4^{-n} + 2^{-n}exp(-eta n) + P(R_JSS)`

and hence

`b(n) <= C(n(n-1),2)2^{-n} + exp(-eta n) + 2^n P(R_JSS)`.

This is stronger than the support-only residual written in the immutable report. Every unit vector supported on at most `delta n` coordinates lies in `Cons(delta,rho)` (take the common center `lambda=0` on the at least `(1-delta)n` zero coordinates), so `R_JSS` in particular forces every nonzero left-null vector to have support greater than `delta n`. The converse need not hold: a dense vector can still be almost constant. Therefore the phrase "genuinely unstructured" should be attached to `R_JSS`, not merely to the support-`>delta n` superset.
