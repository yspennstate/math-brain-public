## Method #17: the residual already has a classical integer-sequence incarnation

4. OEIS A116527: “Number of singular n X n rational {0,1}-matrices with no zero rows or columns and with all rows distinct and all columns distinct, up to permutation of rows.” Current table ends at n=8. URL: https://oeis.org/A116527

This is exactly the binary collision-free singular residual `R_m/m!` used by R03, where `R_m=# {A in G_m: det A=0}`. Thus

`r(m+1) = 2^(m+1-m^2) * m! * A116527(m)`

for every tabulated order, and definitionally for the sequence itself.

5. OEIS A000409 gives the exact all-n count, up to row permutation, of singular binary matrices with distinct nonzero rows but a zero/equal column. Its page provides the signed-Stirling formula

`A000409(m) = - Sum_{k=0}^{m-1} s(m+1,k+1) binom(2^k-1,m)`.

URL: https://oeis.org/A000409

6. OEIS A000410 counts singular binary matrices with distinct nonzero rows, up to row permutation. Its n=9 term was added on 15 Jul 2026 explicitly “using A046747”. URL: https://oeis.org/A000410

By the definitions, the exact same-index identity is

`A116527(m) = A000410(m) - A000409(m)`.

The current A116527 page instead contains a conjectural cross-reference with `A000409(n-1)`. That displayed shifted-index statement is false already at n=4: `425-6=419`, whereas A116527(4)=75. This is an auxiliary database correction, not source closure.

7. OEIS A046747 currently lists the total real-singular binary counts through order 9, with

`S_9 = 902616230040448613437952`,

credited to Dominik Beck on 2 Jul 2026. URL: https://oeis.org/A046747

## Method #29: finite profinite/CRT compactification

9. Kenneth Maples, *Singularity of Random Matrices over Finite Fields*, arXiv:1012.2372, gives finite-field singularity universality with exponentially small error under nondegeneracy. URL: https://arxiv.org/abs/1012.2372

The new elementary CRT observation is exact: for any integer/binary m x m matrix, if distinct primes P have product `Q > m^(m/2)`, then Hadamard implies

`det A = 0 over Z  <=>  det A = 0 mod p for every p in P`.

For m=9, primes `{2,3,5,7,11,13}` have product 30030 and `30030^2 > 9^9`, so simultaneous singularity modulo these six primes is exactly real singularity. Existing single-prime R03 incidence bounds do not automatically combine: `sum min_p Z_p <= min_p sum Z_p` gives no better than the best single-prime bound, while product/geometric-mean witnesses overcount higher modular corank. A useful next theorem would have to count CRT-coherent projective null witnesses after collision removal, rather than multiply marginal finite-field probabilities.
