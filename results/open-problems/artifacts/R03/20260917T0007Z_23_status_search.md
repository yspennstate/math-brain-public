## New adjacent literature found this run

W. H. Haemers and M. J. P. Peeters, `The maximum order of reduced square (0,1)-matrices with a given rank`, Electronic Journal of Linear Algebra 24 (2012), pp. 3–6, DOI 10.13001/1081-3810.1575.

The paper defines a binary matrix as *reduced* when no two rows or columns are dependent. In Section 3 it constructs nonsymmetric reduced square binary matrices of real rank `r`, with sample orders for `r=1,...,10` equal to `1,2,4,7,9,17,23,34,55,67`, and Theorem 3.1 gives

`n(r) >= 2^((r-3)/2) * sqrt(r)`.

This literature is directly relevant to R03's collision-free binary class: for nonzero binary vectors over the reals, pairwise dependence is exactly equality, so a reduced square binary matrix is in the no-zero/no-repeat row-and-column class used by R03. The construction therefore supplies a structural obstruction to trying to force a large *universal* modular-rank floor solely from collision exclusion.

Repository search for the exact paper title did not locate a previous R03 use of this source. That negative repository search is only a provenance check, not a novelty claim.
