## Core theorem already audited by R20

For a finite irreducible reversible chain, orient non-loop edges, set

`C=diag(pi_x P(x,y))`, `B=incidence`, `L=BCB^T=Pi(I-P)`, and `H0={b:1^T b=0}`.

For linear flow routings `R:H0->R^E` with `BR=I_H0`, define

`cost(R)=sup_{0!=b in H0} (Rb)^T C^{-1}(Rb)/(b^T Pi^{-1}b)`.

R01 proves

`tau_2 = inf_{BR=I_H0} cost(R)`,

attained by `R_*=CB^T L^+`.  The all-pairs-flow formulation in the prior reports is exactly equivalent.

## New source-fit formulation in run 3

A centered state-to-stationarity flow family is a family `psi^x` satisfying

`B psi^x=e_x-pi`,

`sum_x pi_x psi^x=0`.

Let

`G_xy=(psi^x)^T C^{-1} psi^y`.

Then the new scalar flow-only formulation is

`tau_2 = inf_Psi lambda_max(Pi^{1/2} G_Psi Pi^{1/2})`.

The matrix automatically kills `sqrt(pi)`.  Electrical state-to-stationarity flows

`psi_*^x=CB^T L^+(e_x-pi)`

attain equality.  This is equivalent to the right-inverse theorem but removes the explicit outer supremum from the displayed source-facing characterization.

## New derivation of the exact Aldous–Fill motivation

Run 3 proves that this exact characterization directly yields both inequalities of Aldous–Fill Theorem 4.32, and the randomized-path Corollary 4.33.

Given arbitrary ordered paths, first symmetrize by replacing `gamma_xy` with the 50/50 mixture of `gamma_xy` and the reversal of `gamma_yx`; this does not increase the maximum directed congestion.  The induced state-to-stationarity flows are centered.

For an edge test field, let `D_xy` be its line integral along the symmetric random path and `g_x=sum_y pi_y D_xy`.  Since `D_xy=-D_yx`,

`Var_pi(g) <= (1/2) sum_xy pi_x pi_y D_xy^2`.

The factor `1/2` is the orthogonal-projection factor for antisymmetric kernels.  Applying pathwise Cauchy–Schwarz and then collecting edge loads gives exactly

`||R_gamma||^2 <= w max_e sum_xy pi_x pi_y r(gamma_xy) 1_{e in gamma_xy}`

and

`||R_gamma||^2 <= w max_e (1/w_e) sum_xy pi_x pi_y |gamma_xy| 1_{e in gamma_xy}`.

Since `tau_2 <= ||R_gamma||^2`, these are precisely Theorem 4.32.  The same proof with expected path loads gives Corollary 4.33.  This addresses Aldous–Fill's stated motivation that the path inequalities should follow from an exact flow characterization.
