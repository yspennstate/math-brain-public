## Candidate theorem U070

Let L=log 4 and, for a positive integer b_N, define

S_N(y)=L {b_N y/L},  0 <= y < L,

and S_N(y)=y outside [0,L). Put sigma(y)=e^y/(1+e^y), ell(x)=log(x/(1-x)), and tau_N(x)=sigma(S_N(ell(x))). Use the same harmonic clocks as C087,

lambda_{N,s}=N/[2s(N-s)],  s=1,...,N-1,

and at mark s color every leaf independently red with probability tau_N(s/N), splitting if both colors occur. Descendants use fresh clocks/colors.

**Proposed U070:** every positive-integer sequence b_N satisfying

b_N=o(N^3)

compiles the complete CTCS(infinity) limit. More precisely, for every fixed k,T, the k-label partition-valued path converges in total variation on [0,T].

### Exact continuum generator is unchanged

For every b_N, multiplication mod L preserves Lebesgue measure on [0,L), and S_N is the identity outside. Hence for every specified split i,j>=1,

int_0^1 F_{N;i,j}(x) dx = B(i,j),

where

F_{N;i,j}(x)=[tau_N(x)^i(1-tau_N(x))^j+tau_N(x)^j(1-tau_N(x))^i]/[2x(1-x)].

Only discrete-grid aliasing remains.

### Third derivative of the logit phase

Let

g(x)=log(x/(1-x)).

Then

g'(x)=1/[x(1-x)],

g''(x)=(2x-1)/[x^2(1-x)^2],

and

g'''(x)=-2(3x^2-3x+1)/[x^3(x-1)^3]
         =2(3x^2-3x+1)/[x^3(1-x)^3].

Since

3x^2-3x+1=3(x-1/2)^2+1/4>0,

g''' is positive and bounded above and below by positive constants on the full active interval [1/2,4/5]. This removes the second-derivative degeneracy at x=1/2.

For a two-variable Weyl mode (m,k) with k != 0, use

phi_N(s)=m s/N + (k b_N/L) g(s/N).

Then

phi_N'''(s)=(k b_N/(L N^3)) g'''(s/N),

so on the active range

|phi_N'''(s)| asymp_{k} lambda_N := b_N/N^3.

### One A-process plus the second-derivative test

Let S=sum_{n in I} e(phi(n)) over an interval I of length M=O(N), and suppose lambda <= |phi'''| <= C lambda with constant sign. For 1<=h<=H, the differenced phase

Delta_h phi(n)=phi(n+h)-phi(n)

has

(Delta_h phi)''(n)=int_0^h phi'''(n+t) dt,

hence |(Delta_h phi)''| asymp h lambda. The ordinary second-derivative estimate gives

|S_h| := |sum e(Delta_h phi(n))|
 <= C[ N sqrt(h lambda) + (h lambda)^(-1/2) ].

Van der Corput differencing yields

|S|^2 <= C[ N^2/H + (N/H) sum_{h<=H}|S_h| ].

Summing h^{1/2} and h^{-1/2},

(|S|/N)^2
 <= C[ H^{-1} + lambda^{1/2} H^{1/2} + N^{-1} lambda^{-1/2} H^{-1/2} ].

Choose H comparable to lambda^{-1/3} when lambda is small (and truncate H to the interval length if needed). Then

|S|/N <= C[ lambda^{1/6} + N^{-1/2} lambda^{-1/6} ].

With lambda=b_N/N^3 this becomes

|S|/N <= C[ (b_N/N^3)^{1/6} + b_N^{-1/6} ].

Thus every fixed nonzero k Fourier mode vanishes whenever b_N -> infinity and b_N=o(N^3). If b_N stays bounded along a subsequence, the older bounded-variation Riemann estimate gives convergence there. Therefore all sequences b_N=o(N^3) are covered after splitting into bounded and divergent subsequences.

The k=0,m!=0 Weyl modes are ordinary grid Fourier sums and vanish directly. Hence the pairs

(s/N, {b_N g(s/N)/L})

are jointly equidistributed on the active region in the sense needed for every fixed split integrand. The piecewise-smooth periodic split amplitude is Riemann integrable, so q_N(i,j)->B(i,j) for every fixed i,j.

Fresh proposal colors imply exact hidden-label lumpability. Consequently each fixed visible restriction is a finite-state CTMC; entrywise generator convergence plus common uniformization gives whole-path TV convergence on every finite time interval, hence finite-state J1 and the projective CTCS(infinity) limit.

The proof intentionally does **not** claim the cubic boundary b_N asymp c N^3. At that scale lambda stays O(1), the displayed bound is no longer o(1), and a genuine aliasing/stationary-phase correction may survive. This is the exact next obstruction.
