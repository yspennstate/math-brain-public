## New route

At each harmonic-grid split proposal with bias `x=s/N`, mark each ambient label independently with probability `theta_N`.  All marked labels share one common Bernoulli(`x`) color `Z`; every unmarked label receives an independent Bernoulli(`x`) color.  Use a fresh marking, common color and singleton colors at every proposal and for every active clade.  Thus one random dependence block may contain order `N theta_N` labels, while all remaining dependence blocks are singletons.

The proposal clock at mark `x=s/N` has rate

`lambda_{N,s}=N/(2 s (N-s)) = 1/(2N x(1-x))`,  `1<=s<=N-1`.

For a fixed specified split `A|B`, `|A|=i`, `|B|=j`, the probability of the oriented event `A red, B blue` equals

`P_theta^{i,j}(x) = x [theta+(1-theta)x]^i [(1-theta)(1-x)]^j + (1-x)[(1-theta)x]^i [theta+(1-theta)(1-x)]^j`.

By symmetry of the grid under `x -> 1-x`, the finite-grid unordered specified split rate is

`q_{N,theta}(i,j)=(1/N) sum_{s=1}^{N-1} g_{i,j,theta}(s/N)`,

where

`g_{i,j,theta}(x)=P_theta^{i,j}(x)/(x(1-x))`

`= [theta+(1-theta)x]^i (1-theta)^j (1-x)^{j-1} + (1-theta)^i x^{i-1}[1-(1-theta)x]^j`.

For fixed `i,j`, this is a polynomial in `x`, continuous jointly in `(x,theta)` on `[0,1]x[0,1/2]`, so the Riemann sums converge uniformly in `theta` in that range.

## Exact continuum deformation

Define

`q_theta(i,j)=int_0^1 g_{i,j,theta}(x) dx`.

Two changes of variables give

`q_theta(i,j)=B_{1-theta}(j,i+1)+B_{1-theta}(i,j+1)`.

Since the beta recursion gives

`B(i,j)=B(j,i+1)+B(i,j+1)`, 

we obtain the exact deficit identity

`B(i,j)-q_theta(i,j)=Delta_theta(i,j)`

with

`Delta_theta(i,j)=int_0^theta [(1-v)^{i-1} v^j + (1-v)^{j-1} v^i] dv >=0.`

Thus the one-cluster deformation reduces every specified CTCS split rate coordinatewise.  It also reveals a hierarchy: if `s=min(i,j)`, then `Delta_theta(i,j)=O(theta^{s+1})`; singleton splits are the first affected, at order `theta^2`, balanced splits are much more stable.

Summing over all unordered nontrivial splits of an `m`-set yields another exact identity:

`D_m(theta) := sum_{A|A^c} Delta_theta(|A|,m-|A|)`

`= int_0^theta [1-v^m-(1-v)^m]/(1-v) dv.`

Hence

`0 <= D_m(theta) <= min{-log(1-theta), m theta^2/[2(1-theta)]}`.

For `m=2`, `D_2(theta)=theta^2`, equivalently the pair-separation rate is exactly `1-theta^2`.

This exact deformation identity is the main new claim to prove in U062.
