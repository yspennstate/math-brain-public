# U074 candidate: deterministic aliasing can be forced

For the active grid `S_N={s:1/2<=s/N<4/5}`, put

\[
\alpha_{N,s}=g(s/N)/L\in\mathbb R.
\]

For a complexity budget `B`, define the simultaneous aliasing radius

\[
\rho_N(B)=\min_{1\le b\le B}\max_{s\in S_N}
\|b\alpha_{N,s}\|_{\mathbb T}.
\]

This is nonincreasing in `B`.  Simultaneous Dirichlet approximation with `M_N=|S_N|` and `Q=N` gives some integer

\[
1\le b_N\le N^{M_N}
\]

with

\[
\max_{s\in S_N}\|b_N\alpha_{N,s}\|_{\mathbb T}\le 1/N,
\]

hence

\[
\rho_N(N^{M_N})\le1/N.
\]

Thus every active phase lies within `1/N` of the seam.  Write it as either `0+epsilon_{N,s}` or `1-epsilon_{N,s}` and define the `A`-weighted proportion `w_N` of the first side.  Along a subsequence, `w_N -> w`.

If the deterministic hierarchy converged to CTCS for every fixed split, then for every `H_{i,j}` one would need

\[
wH_{i,j}(0)+(1-w)H_{i,j}(1-)=\int_0^1H_{i,j}(t)dt.
\]

For `H_{1,1}`,

\[
H_{1,1}(0)=1/2,\quad H_{1,1}(1-)=8/25,
\quad \int_0^1H_{1,1}(t)dt=\frac{3}{10\log2},
\]

so the required seam weight is

\[
w_{11}=\frac{15/\log2-16}{9}.
\]

For `H_{1,3}`,

\[
H_{1,3}(0)=1/8,\quad H_{1,3}(1-)=68/625,
\quad \int_0^1H_{1,3}(t)dt=\frac{21}{250\log2},
\]

so

\[
w_{13}=\frac{420/\log2-544}{81}.
\]

Equality `w_{11}=w_{13}` would force

\[
\log2=57/80.
\]

But convexity of `1/x` gives the two-panel trapezoid upper bound

\[
\log2=\int_1^2\frac{dx}{x}
<\frac14\left(1+\frac23\right)
 +\frac14\left(\frac23+\frac12\right)
=\frac{17}{24}<\frac{57}{80}.
\]

Contradiction.  Therefore there exists a deterministic integer branch schedule `b_N <= N^{|S_N|}=exp(O(N log N))` for which the undithered compact-logit hierarchy does **not** converge to CTCS.  This is an obstruction theorem, not a new model class for the metric.

A fixed integer `b` cannot satisfy the `1/N` simultaneous approximation for all large `N` (e.g. use grid points tending to `x=3/5`, for which `g(x)/L=log_4(3/2)` is irrational), so any such chosen `b_N` necessarily tends to infinity.

# U073 candidate: finite cyclic dither removes aliasing with no restriction on b_N

Let `d_N -> infinity` be any integer sequence and let `b_N>=1` be **arbitrary**, with no growth condition.  At every active harmonic proposal `s`, sample a fresh

\[
J\sim \mathrm{Unif}\{0,1,\dots,d_N-1\}
\]

and use fractional logit coordinate

\[
T_{N,s,J}=\left\{b_N\alpha_{N,s}+\frac{J}{d_N}\right\}.
\]

Set the Bernoulli paintbox bias to `sigma(L T_{N,s,J})`; outside the active interval retain the identity bias `s/N`.  The dither is redrawn independently at every proposal and in every descendant clade.

For any bounded-variation circle function `H`, the equally spaced shifted grid satisfies the deterministic discrepancy estimate

\[
\sup_\theta\left|
\frac1d\sum_{j=0}^{d-1}H(\{\theta+j/d\})-
\int_0^1H(t)dt\right|
\le \frac{\operatorname{Var}_{\mathbb T}(H)}{d}.
\]

Apply this to every fixed `H_{i,j}`.  Averaging over the fresh dither makes the active split-rate error uniformly in the arbitrary branch count `b_N`

\[
O_{i,j}(d_N^{-1})+O_{i,j}(N^{-1}).
\]

The outside part is an ordinary Riemann sum.  Therefore every specified split rate satisfies

\[
q_N(i,j)=B(i,j)+O_{i,j}(d_N^{-1}+N^{-1}),
\]

**uniformly over every possible integer sequence `b_N`**.

Because all dither, color and descendant-clock randomness is fresh, hidden labels lump out exactly on each fixed visible restriction.  Entrywise generator convergence plus common uniformization should therefore yield, for fixed visible `k` and `T<infinity`,

\[
\left\|\mathcal L(\Pi_N^{[k]}|_{[0,T]})-
\mathcal L(\Pi_{\rm CTCS}^{[k]}|_{[0,T]})\right\|_{TV}
\le C_{k,T}(d_N^{-1}+N^{-1})\to0.
\]

This is the full finite-restriction partition-path limit, hence finite-state `J_1` and the frozen projective CTCS(infinity) limit.

The shifted-lattice/discrepancy step is classical numerical-integration machinery; no novelty is claimed for random/cyclic shifts or Koksma-type estimates.  The potentially new content is the CTCS compiler and the aliasing obstruction/repair pair.
