The preceding run proposed a very broad representation theorem for quenched directing measures. Rather than chase that general theorem, prove a smaller exact algebraic compiler.

Let `q_N` be the least prime at least `N`, and let

`K_N = min(N, max(2, floor(sqrt(N))+1))`.

For the `N` label positions `alpha_l=l-1` in `F_{q_N}`, take every polynomial `f` over `F_q` of degree `<K_N`. The evaluation words

`(f(alpha_1),...,f(alpha_N))`

form a Reed–Solomon/MDS orthogonal array of strength `K_N`: on every `b<=K_N` columns, every `q^b` value pattern occurs exactly `q^(K_N-b)` times. This is immediate from Vandermonde interpolation.

For each threshold `u=1,...,q-1`, write `x_u=u/q`. Give each pair `(u,f)` an independent Poisson proposal clock of rate

`1 / [ 2 (q-1) q^K x_u (1-x_u) ]`.

When a clock rings on a current clade, cut it by the deterministic mask

`label l is red iff representative(f(alpha_l)) < u`.

For any fixed visible block of size `b<=K_N`, OA strength makes the values exactly iid uniform in `F_q`, so threshold colors are exactly iid Bernoulli(`x_u`) after averaging over the equally weighted polynomial clocks. Therefore a specified unordered split of sizes `i,j` has exact rate

`G_q(i,j) = (1/(q-1)) sum_{u=1}^{q-1} (u/q)^(i-1) (1-u/q)^(j-1)`.

As `q_N -> infinity`, `G_q(i,j) -> B(i,j)`. Since `K_N -> infinity`, every fixed finite restriction is eventually covered exactly. Hidden labels do not alter visible rates because each descendant clade restarts the same ambient polynomial-clock family.
