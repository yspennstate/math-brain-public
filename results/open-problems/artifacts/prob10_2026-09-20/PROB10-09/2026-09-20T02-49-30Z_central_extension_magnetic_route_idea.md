# PROB10-09 idea before code — non-split central surface extension

Date: 2026-09-20 UTC

Frozen parent remains the Benjamini–Schramm iid **bond**-percolation target for every locally finite Cayley graph of every finitely generated nonamenable group: `p_c(G)<p_u(G)`. This note records the mathematical idea before any checker is written.

## Candidate fixed graph

Take a non-trivial infinite cyclic central extension of the genus-two closed surface group

\[
1\to\langle z\rangle\cong\mathbb Z\to \widetilde\Gamma_{2,e}\xrightarrow{\pi}\Gamma_2\to1,
\qquad e\ne0,
\]

with standard lifts `a1,b1,a2,b2` and presentation convention

\[
[a_1,b_1][a_2,b_2]=z^e,\qquad z\text{ central}.
\]

Freeze the standard symmetric Cayley graph

\[
G_e=\operatorname{Cay}(\widetilde\Gamma_{2,e},
\{a_1^{\pm1},b_1^{\pm1},a_2^{\pm1},b_2^{\pm1},z^{\pm1}\}),
\]

which is 10-regular.

The point of using `e != 0` is to avoid merely repackaging a Cartesian product. The quotient is a nonamenable surface group, while the kernel is infinite central.

## Three materially different routes compared

### Route A — crude free-core/complement nonbacktracking bound: expected to fail

Magnus Freiheitssatz in the surface quotient implies that the lifts `a1,b1,a2` freely generate `F_3`; together with the central generator they give an embedded `F_3 x Z` subgraph. If one ignores the central-extension structure in the operator norm and simply treats `{b2^±1,z^±1}` as four arbitrary complementary generators, then

\[
\|A_{G_e}\|\le 2\sqrt5+4,
\]

which is exactly the coarse `q=5,r=4` free-core/complement point. The corresponding nonbacktracking threshold is only about `0.13837`. The exact product-fiber critical witness for `T_6 x Z` crosses at about `0.15431`, so this route cannot certify a gap. This also lies directly in the neighboring NM13-11 free-core/complement lane, so it is not the route to pursue here.

### Route B — fixed-endpoint / bridge refinement from the June archive: not enough data this run

Rounds 053--055 reduce `p_c<p_{2->2}` to fixed-endpoint nonbacktracking detour/bridge decay. For `G_e`, however, no new bridge large-deviation estimate is currently available. Merely naming that endpoint estimate as the missing lemma would violate the PROB10-09 contract. I therefore do not spend the run manufacturing a conditional restatement.

### Route C — central Fourier decomposition + magnetic domination: pursue

Because `z` is central, Fourier transform in the central coordinate decomposes the surface-generator part of adjacency into projective/magnetic adjacency operators `A_theta` on the ordinary genus-two surface Cayley graph. Each magnetic edge has unit modulus, hence pointwise

\[
|A_\theta f|\le A_{\Sigma_2}|f|.
\]

Therefore

\[
\|A_\theta\|_{2\to2}\le\|A_{\Sigma_2}\|_{2\to2}
\]

for every central character. The two central edges contribute the scalar `2 cos(theta)`, so

\[
\|A_{G_e}\|\le \|A_{\Sigma_2}\|+2.
\]

Using Nagnibeda's rigorous genus-two Markov bound `||M_2|| <= 0.662816`, conservatively rounded upward to `663/1000`, would give

\[
\|A_{G_e}\|<8(663/1000)+2=913/125=7.304,
\]

far below the crude `2 sqrt(5)+4` bound.

Independently, the subgroup generated by `a1,b1,a2,z` is `F_3 x Z`, hence the Cayley graph contains `T_6 square Z`. The June exact cluster-branching formula

\[
\varphi_{\mathbb Z}(p)=1-\frac{(1-p)^3}{(1-p+p^2)^2}
\]

implies `p_c(T_6 square Z)<p_0` whenever `5 varphi_Z(p_0)>1`.

At the simple rational `p_0=31/200`, the intended exact check is

\[
5\varphi_{\mathbb Z}(31/200)-1>0.
\]

For a 10-regular graph, `Q=9`; with `R=913/125`, the nonbacktracking growth root is

\[
\beta=\frac{R+\sqrt{R^2-36}}2
=\frac{913+\sqrt{271069}}{250},
\]

so

\[
\beta^{-1}=\frac{913-\sqrt{271069}}{2250}\approx0.17438.
\]

If the exact checks pass, this gives the strict chain

\[
p_c(G_e)<\frac{31}{200}<\beta^{-1}\le p_{2\to2}(G_e)\le p_u(G_e)
\]

and the certified quantitative gap

\[
p_u(G_e)-p_c(G_e)\ge
\frac{2257-4\sqrt{271069}}{9000}\approx0.01938.
\]

## Negation test to run

The critical negation is that a central twist might enlarge the surface-generator operator norm and destroy the Nagnibeda import. The magnetic pointwise domination above is intended to rule this out uniformly in the central character. The finite checker will verify only the exact algebraic inequalities (`5 phi_Z(p0)>1`, discriminant/root identities, positivity of the final gap); the direct-integral and diamagnetic argument must be proved on the page.

## Prior-art guardrail

The current neighboring NM13-11 route owns the arbitrary free-core/complement cardinality method; this route is deliberately different and exploits the central extension to obtain a uniform magnetic norm bound unavailable from cardinality alone. A bounded current literature check must still be recorded before any novelty language: Hutchcroft 2019 covers hyperbolic graphs; Hutchcroft--Pan 2024 covers several subgroup-relativized obstacle classes; Choi--Seo 2025 covers acylindrically hyperbolic groups; Peres 2000 covers direct products. No novelty claim is made in this idea note.
