## New structural direction before code

The preceding PROB10-07 work proves every complete bipartite `K_{a,b}` with `min(a,b)<=30`, using a terminal-partition transfer. Continuing only to width 31 would be a same-route range extension. This run instead asks whether a fixed nontrivial core can be placed in front of the star transfer, producing a genuinely new non-series-parallel family.

Take the complete tripartite graph

`K_{1,2,n}`

with fixed parts `A={a}`, `B={b,c}`, and variable part `C={r_1,...,r_n}`. The fixed core on `a,b,c` has the two edges `ab,ac`; every `r_i` is joined to all three terminals. For `n>=2`, this graph has a `K_4` minor: use branch sets `{a}`, `{b}`, `{r_1}`, and `{c,r_2}`. Hence it is not series-parallel.

The key observation is that after the fixed core and any distinguished `C` vertices are processed, an unmarked `C` vertex acts only on the connectivity partition of the three terminals. There are exactly five labelled partition states. If a new star hits at most one vertex from each current terminal block, it is legal; if it hits two vertices already in one block, it closes a cycle and is illegal. In the state order

`a|b|c`, `a|bc`, `ab|c`, `abc`, `ac|b`,

the exact unmarked-star transfer is

```
M = [[4,1,1,1,1],
     [0,4,0,2,0],
     [0,0,4,2,0],
     [0,0,0,4,0],
     [0,0,0,2,4]].
```

Thus `M=4I+N` with `N^3=0`. Consequently, for any initial row vector `v` and every integer `x>=0`,

`v M^x 1 / 4^x`

is an exact quadratic polynomial in `x`, obtained from

`I + (x/4)N + (x(x-1)/32)N^2`.

This should let every edge-pair Rayleigh numerator be reduced to a degree-at-most-four polynomial.

## Pair-orbit plan

Under `S_2 x S_n`, there are three edge types:

- `X`: a fixed-core edge, represented by `ab`;
- `Y`: an `A-C` edge, represented by `a r_1`;
- `Z`: a `B-C` edge, represented by `b r_1`.

Distinct edge pairs have ten orbits:

1. `XX`: `ab, ac`;
2. `YY`: `a r_1, a r_2`;
3. `ZZ-B`: `b r_1, b r_2`;
4. `ZZ-C`: `b r_1, c r_1`;
5. `ZZ-D`: `b r_1, c r_2`;
6. `XY`: `ab, a r_1`;
7. `XZ-B`: `ab, b r_1`;
8. `XZ-D`: `ab, c r_1`;
9. `YZ-C`: `a r_1, b r_1`;
10. `YZ-D`: `a r_1, b r_2`.

For each orbit, process the minimum number `k=0,1,2` of distinguished `C` vertices first. Enumerate exactly the legal core-edge subsets and distinguished star subsets, with the requested edge(s) forced, to obtain four initial vectors `v_0,v_e,v_f,v_{ef}`. Put `x=n-k`. Then

`Z = v_0 M^x 1`, `I_e = v_e M^x 1`, `I_f = v_f M^x 1`, `I_ef = v_ef M^x 1`,

and the source Rayleigh numerator is

`Delta = I_e I_f - Z I_ef`.

The intended certificate is that `Delta/16^x` has nonnegative coefficients in `x`, and is positive on the physical range for every orbit.

## Three materially different approaches compared

1. **General false-twin closure.** `K_{m,n}` and `K_{1,2,n}` can be generated by vertex cloning. A theorem that forest Rayleigh is preserved by arbitrary false-twin extension would be much stronger, but the forest decomposition after cloning depends on multi-terminal connectivity inside the old neighborhood. I do not currently have a closed scalar Rayleigh identity for that operation. This is not promoted.
2. **Component-species / Tutte expansion.** Bipartite tree components admit explicit labelled counts, so all forests of `K_{m,n}` can be written by an exponential formula. Edge-pair forcing then splits according to whether the marked edges lie in the same component. The resulting coefficient inequality is exact but does not expose a manifest sign without a new total-positivity input. This route is held as a possible all-width attack, not used as a theorem here.
3. **Fixed-core partition transfer.** For `K_{1,2,n}`, the entire non-series-parallel core is finite and the variable part consists of identical legal stars. The five-state transfer above closes exactly and gives a direct all-`n` Rayleigh certificate. This is the production route for this run.
