## Three materially different routes compared

### A. Deletion–contraction quadratic

For a third edge `g`, write the forest polynomial as `I=A+y_g B`, where `A=I_{G\setminus g}` and `B=I_{G/g}` in matroid notation. Then for a tested pair `e,f != g`,

`Delta_G^{e,f}(y_g)=Delta_A^{e,f}+C_{A,B}^{e,f} y_g+Delta_B^{e,f} y_g^2`,

where

`C_{A,B}^{e,f}=A_e B_f+B_e A_f-A B_{ef}-B A_{ef}`.

This is exact, but P14/HARD10-01 already isolated the same mixed-term obstruction: `C` has no fixed sign. A new run should not rename that blocker as progress. I therefore use this identity only as a falsification lens: any proposed closure must control the mixed term, not merely the endpoint Rayleigh gaps.

### B. False-twin extension

The families `K_{1,2,n}` and `K_{a,b,n}` are generated by repeatedly adding a vertex with the same neighborhood. A scalar statement such as “Rayleigh is preserved by adding a false twin” would be much stronger, but after one clone the effect on future acyclicity depends on the entire connectivity partition induced on the common neighborhood. Thus the correct invariant is a finite terminal-partition response vector, not one Rayleigh number. I do not assume a false-twin closure theorem.

### C. Fixed-core terminal-partition transfer — chosen route

Freeze two parts of a complete tripartite graph `K_{a,b,n}` and process the third part one vertex at a time. Let `m=a+b` fixed terminals. A processed forest induces a partition `pi` of the `m` terminals. For a new vertex `r`, choose a spoke set `S` into the terminals. The extension is acyclic iff `S` meets each block of `pi` at most once; when legal, all blocks met by `S` merge. Hence the transfer is exact on the Bell-partition state space.

Crucially, for every state the empty spoke set and the `m` singleton spoke sets preserve the partition. Therefore

`M_m=(m+1)I+N_m`,

and every nonzero transition of `N_m` strictly decreases the number of terminal blocks. Consequently `N_m^m=0` and

`M_m^x=(m+1)^x sum_{j=0}^{m-1} binom(x,j) (N_m/(m+1))^j`.

Thus every marked forest count is `(m+1)^x` times a polynomial of degree at most `m-1`, and every normalized Rayleigh difference is an exact polynomial in the number `x` of unmarked repeated vertices.

The previous theorem handled `m=3` (`K_{1,2,n}`). This run will test, and if successful prove completely, the two partitions of `m=4`, namely `K_{1,3,n}` and `K_{2,2,n}`, and the two partitions of `m=5`, namely `K_{1,4,n}` and `K_{2,3,n}`. The target certificate is stronger than a finite list of `n`: for each edge-pair orbit, derive the exact normalized Rayleigh polynomial and prove it nonnegative for every physical integer `x>=0` (with the correct `x>=1` restriction when a pair uses no repeated vertex and `n>=1`).

If every orbit polynomial has manifestly nonnegative coefficients, this gives an all-`n` theorem. If not, the first negative coefficient/polynomial value becomes an exact obstruction to this certificate and the run changes method rather than hiding it.
