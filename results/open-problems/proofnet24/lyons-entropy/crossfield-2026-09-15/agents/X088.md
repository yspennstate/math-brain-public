## 2. Exact measured law for every four-site Hermitian circulant

For arbitrary eigenvalues lambda_i in (0,1), partition the spectral labels into U={0,2}, V={1,3}. Let u_j and v_j be the count probabilities of the two independent Bernoulli variables in each group, and let f_j be the count probabilities of all four variables. Write

    A=u_1 v_1, B=u_2 v_0+u_0 v_2, f=f_2=A+B.

The complete measured atom table is

| Measured sets | Multiplicity | Probability of each set |
|---|---:|---:|
| Empty | 1 | f_0 |
| Singletons | 4 | f_1/4 |
| Adjacent pairs | 4 | (A+2B)/8 |
| Opposite pairs | 2 | A/4 |
| Triples | 4 | f_3/4 |
| Full | 1 | f_4 |

Here “adjacent” and “opposite” refer to the original four-cycle coordinates. To prove the table, expand the determinant generating function multilinearly in the four spectral Bernoulli choices. A selected mode set T contributes the projection law with probabilities |det F_ST|². Single and triple minors all have squared modulus 1/4. For two-element sets with separations d_S,d_T,

    |det F_ST|²=(1/8)[1-cos(pi d_S d_T/2)].                 (2)

This is 1/8 if both separations are odd, 1/4 if exactly one is even, and zero if both are even. This proves every entry of the table without substituting count entropy for configuration entropy.

There is also an exact classical realization. Start with independent Bernoulli occupations in a 2-by-2 array, with row pairs (0,2),(1,3). Independently shuffle each row uniformly, then independently shuffle each column uniformly. Identify the two column pairs with the two opposite measured pairs. The resulting four-bit law is exactly the table above: a same-row input pair yields four adjacent outputs with probability 1/4 each; a cross-row input pair yields each opposite output with probability 1/4 and each adjacent output with probability 1/8. All other cardinalities are uniform. This two-round random-swap representation does not, by itself, prove entropy concavity for arbitrary input Bernoulli parameters.

## 3. The entire departure from count uniformity is one quadratic

Use the affine coordinates

    lambda_0=a+x, lambda_2=a-x,
    lambda_1=b+y, lambda_3=b-y.

Then

    u=((1-a)²-x², 2a(1-a)+2x², a²-x²),
    v=((1-b)²-y², 2b(1-b)+2y², b²-y²).

A direct expansion gives the quadratic identity

    Delta:=A-2B=2[x²+y²-(a-b)²].                         (3)

The pair atoms therefore equal f/6-Delta/24 on adjacent pairs and f/6+Delta/12 on opposite pairs. Count-uniformity is exactly Delta=0. Since A,B>0, the physical normalized imbalance

    z=Delta/(2f)

satisfies -1<z<1/2. Define

    j(z)=(1+z)log(1+z)/3
                      +2(1-z/2)log(1-z/2)/3,
    J(f,Delta)=f j(Delta/(2f)),
    E_4(lambda)=-sum_(k=0)^4 f_k log(f_k/binom(4,k)).

The exact configuration-entropy identity is

    H(P_K)=E_4(lambda)-J(f_2,Delta).                      (4)

The function J is the relative-entropy deficit within the pair layer. Its sign J>=0 is insufficient to transfer a Hessian sign. Along any affine kernel direction, its complete second derivative is

    J''=j''(z)/(4f) (Delta'-2z f')²
                           +J_f f''+J_Delta Delta'',      (5)
    j''(z)=1/[2(1+z)(1-z/2)],
    J_f=[log(1+z)+2log(1-z/2)]/3<=0,
    J_Delta=log[(1+z)/(1-z/2)]/6,
    Delta''=4[(x')²+(y')²-(a'-b')²].

Thus (5) retains the additional positive rank-one Fisher term and both signed acceleration corrections. None is omitted below.

## 6. Proof of the theorem

First let 0<t<=t_*, and fix a=b=t. Put r=x²,s=y² and beta=6t(1-t)-1. Directly from the atom table,

    Delta=2(r+s)>=0,
    f_2=6t²(1-t)²+beta(r+s)+6rs,                         (7)
    D²_(x,y) f_2=[[2beta+12y²,24xy],
                  [24xy,2beta+12x²]].

The physical square is |x|,|y|<=t. For any real direction (u,v), bounding |xy|<=t² and 2|uv|<=u²+v² gives

    D²f_2[(u,v)] <= (2beta+36t²)(u²+v²)
                   =(-2+12t+24t²)(u²+v²)
                   <=8(u²+v²).                          (8)

The last equality at t=t_* is exactly the defining quadratic for t_*; the coefficient is increasing for t>=0. Also D²Delta=4I_2. Since 0<=z<=1/2, (5), (6), and (8) yield

At x=y=0 all formulas have their continuous values, with z=kappa=J_Delta=0. Thus J is convex on the entire strict square. Equation (4) subtracts this convex function from the concave E_4 restricted to the affine eigenvalue map. It proves the entropy Hessian is nonpositive in both independent edge coordinates.
