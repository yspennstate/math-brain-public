`q_r(S)=e(S)/(n-r)^2`.

`rho_{r+1}(n)/rho_r(n) = E_{S uniform in Delta_r} q_r(S)`.

The pointwise inequality `q_{r+1}(T)<=q_r(S)` along every valid edge `S subset T` is false. The next object to test is therefore the edge-size-biased child average. For a parent with `e(S)>0`, put

`a_r(S)= E[q_{r+1}(T) | T is a uniformly chosen valid child of S]`.

Because every rank-`r+1` face has exactly `r+1` parents, a uniformly chosen rank-`r+1` face can equivalently be generated by size-biasing a uniform rank-`r` face by `e(S)` and then choosing a uniformly random valid child. Hence

`E_{Delta_{r+1}} q_{r+1} = E_{Delta_r}[e(S)a_r(S)] / E_{Delta_r}[e(S)]`.

This makes the desired density-ratio monotonicity an exact weighted-average inequality. Before searching for an injection, test two tempting sufficient strengthenings exactly:

1. negative covariance / regression of `e(S)` against `a_r(S)`;
