## 1. Change language: Chen is a Hilbert-function log-concavity problem

A fresh literature read found Brendon Rhoades, *Increasing subsequences, matrix loci and Viennot shadows*, Forum of Mathematics, Sigma 12 (2024), e97, DOI 10.1017/fms.2024.75. Rhoades defines an Artinian graded quotient

`R_n = F[x_{n x n}] / I_n`,

where `I_n` is generated by the row sums, column sums, and products of two variables drawn from the same row or the same column. Its Hilbert series is

`Hilb(R_n;q) = ell_{n,n} + ell_{n,n-1} q + ... + ell_{n,1} q^(n-1)`.

Thus Chen's source conjecture is exactly log-concavity of the Hilbert function of `R_n` (with the indexing reversed). Rhoades also realizes the Novak–Rhoades characters in the graded pieces and formulates a stronger equivariant injection conjecture. This is prior art, not an NM13-07 novelty.

The useful consequence for this track is conceptual: the source is not only a probability/RSK inequality. It is also a concrete Artinian Hilbert-function problem with a squarefree standard monomial basis indexed by Viennot shadow sets. Generic Macaulay admissibility does not imply log-concavity, so merely recognizing a Hilbert function is insufficient. A future algebraic attack would need an extra property of this particular quotient (for example an injection, Lefschetz-type operator, Hodge/Lorentzian structure, or another source-specific positivity mechanism). The fresh paper itself does not establish such a property.

## 2. Swap the quantifiers in the insertion-flux obstruction

The predecessor proved the exact curvature-reserve identity. With

`p_k = ell_{n,k}/n!`, `q_k = ell_{n+1,k}/(n+1)!`,

`q_i = a_i p_i + (1-a_{i-1}) p_{i-1}`,

set `x=p_{k-1}`, `y=p_k`, `r=y/x` and

`P_k(r) = (a_k r+1-a_{k-1})^2 - (a_{k-1}r+1-a_{k-2})(a_{k+1}r+1-a_k)`.

Also set

`Delta_+ = y^2 - x p_{k+1}`,

`V = a_{k+1} Delta_+ / x`,

and let `q_{k-1}` be the actual previous output coordinate. The predecessor's identity (C3) gives

`q_k^2-q_{k-1}q_{k+1} = x^2 P_k(r) + V q_{k-1} + U G_+`,

where `U G_+ >= 0` whenever the incoming row is log-concave.

Therefore the following one-sided condition is sufficient at every cell:

`a_{k+1} Delta_+ q_{k-1} / x >= max(0, -x^2 P_k(r))`.       (R)

Equivalently, if `P_k(r)<0`,

`V q_{k-1} >= -x^2 P_k(r)`.

This is a substantially sharper target than asking both left and right curvature reserves jointly to dominate the negative envelope defect. It asks whether one fixed side — the right incoming Chen curvature — already pays the entire debt.

This implication is a theorem, immediate from the exact C3 identity. What is *not* yet a theorem is that (R) holds for every Plancherel/LIS row.

## 3. Why this is a useful source-specific target

The universal log-concavity-preserver route failed because the geometric envelope discards the incoming strict Chen curvature. Condition (R) keeps exactly one source-specific curvature. If (R) were proved for every `n,k`, then induction from the trivial initial rows would prove Chen's source conjecture.

The target is also naturally asymmetric. That is useful rather than suspicious: RSK insertion already has a directional time interpretation, and the exact largest-letter insertion flux singles out a direction. A proof might compare `Delta_+` with a conditional tableau statistic governing `a_{k+1}`.

The immediate falsification plan is exact: rebuild Plancherel rows by hook lengths, recover `a_k` from the cumulative insertion identity, inspect every cell where `P_k(r)<0`, and test (R) by integer/rational arithmetic. If it fails, the first failure says a second curvature term or a higher tableau moment is indispensable. If it survives, inspect the minimum rescue/debt ratio row by row and look for a monotone lower envelope.

## 4. Monovariant candidate to test, not assume

For cells with `P_k(r)<0`, define

`rho_{n,k} = (V q_{k-1}) / (-x^2 P_k(r))`.

Condition (R) is `rho_{n,k} >= 1`. Define the row minimum

`m_n = min_{k : P_k(r)<0} rho_{n,k}`.

The useful stronger finite pattern to test is whether, after any small sporadic rows, `m_n` is increasing. Such a pattern would not itself prove all-`n` positivity, but it would point toward a scalable comparison rather than a fragile cancellation.
