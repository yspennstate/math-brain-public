# E0095 / C16 matching idea before checker

After admission, attack the next finite cycle case `n=16` directly.

1. **B2 (negation first).** Search all perfect matchings made only of non-cycle edges for a graph with adjacency `lambda_2 < sqrt(3)`. A Hamiltonian presentation of the Möbius–Kantor graph gives a natural benchmark with `lambda_2=sqrt(3)`, so a strict improvement would refute its extremality.
2. **B15 (break symmetry).** Do not restrict the search to circulant/vertex-transitive matchings. Enumerate every labeled matching; in particular test all valid two-switch perturbations of the symmetric benchmark.
3. **B29 (projectivize / add boundary points).** The Poincare eigenvalue is the maximum Rayleigh quotient on the projective zero-sum space. Therefore every non-extremal matching can be certified *exactly* by a single integer zero-sum vector `w` with `(w^T A w)^2 > 3 (w^T w)^2` and `w^T A w>0`. Floating point may be used only to select a candidate witness; the checker must verify the displayed integer inequality exactly. Equality candidates are handled by an exact characteristic polynomial.

This certificate architecture avoids treating floating-point diagonalization as proof and keeps the finite core independently reproducible.
