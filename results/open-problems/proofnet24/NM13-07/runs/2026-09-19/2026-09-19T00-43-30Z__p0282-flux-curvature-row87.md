### Theorem 1 — exact local universal-preserver criterion

Fix an interior index `k`, numbers `0<=a_i<=1`, and put `c_i=1-a_i`. Suppose a positive input sequence is log-concave on the four needed sites:

`p_{k-1}^2 >= p_{k-2}p_k`,

`p_k^2 >= p_{k-1}p_{k+1}`.

Define

`q_i = a_i p_i + c_{i-1}p_{i-1}`.

Set `x=p_{k-1}>0`, `y=p_k>0`, and `r=y/x`. Then the step preserves the target inequality

`q_k^2 >= q_{k-1}q_{k+1}`

for **every** positive locally log-concave input with those central values if and only if

`P_k(r) >= 0 for every r>0`,

where

`P_k(r) = (a_k r+c_{k-1})^2 - (a_{k-1}r+c_{k-2})(a_{k+1}r+c_k)`.       (P)

#### Proof

The two input log-concavity inequalities are exactly

`p_{k-2} <= x/r`,

`p_{k+1} <= yr`.

For fixed `x,y`, `q_{k-1}` is nondecreasing in `p_{k-2}` and `q_{k+1}` is nondecreasing in `p_{k+1}`. Therefore

`q_k^2-q_{k-1}q_{k+1}`

is minimized by taking both outer variables at their maximum allowed values, namely

`p_{k-2}=x/r`, `p_{k+1}=yr`.

At that geometric-envelope input,

`q_k=x(a_k r+c_{k-1})`,

`q_{k-1}=x(a_{k-1}+c_{k-2}/r)`,

`q_{k+1}=xr(a_{k+1}r+c_k)`.

Hence

`q_k^2-q_{k-1}q_{k+1}=x^2 P_k(r)`.

Thus `P_k(r)>=0` for all positive `r` is sufficient for every positive locally log-concave input. It is also necessary, because for any fixed `r>0` the local geometric progression itself is a valid log-concave input and attains equality in the two outer bounds. This proves the criterion. QED.

Expanding `(P)` gives one exact quadratic

`P_k(r)=A_k r^2+B_k r+C_k`,

with

`A_k=a_k^2-a_{k-1}a_{k+1}`,

`B_k=2a_k(1-a_{k-1})-a_{k-1}(1-a_k)-a_{k+1}(1-a_{k-2})`,

`C_k=(1-a_{k-1})^2-(1-a_{k-2})(1-a_k)`.

So the stronger kernel question is not vague: it is exactly positivity of a quadratic on the positive half-line.

### Theorem 2 — curvature-reserve decomposition

Keep the notation of Theorem 1. Define the two incoming Chen curvatures

`Delta_- = x^2-p_{k-2}y >= 0`,

`Delta_+ = y^2-xp_{k+1} >= 0`.

`G_- = x(a_{k-1}+c_{k-2}/r)`,

`G_+ = xr(a_{k+1}r+c_k)`,

and the curvature deductions

`U = c_{k-2} Delta_- / y`,

`V = a_{k+1} Delta_+ / x`.

Then exactly

`q_k^2-q_{k-1}q_{k+1}`

`= x^2P_k(r)+UG_+ + VG_- - UV`                                      (C1)

`= x^2P_k(r)+Uq_{k+1}+VG_-`                                           (C2)

`= x^2P_k(r)+Vq_{k-1}+UG_+`.                                          (C3)

#### Proof

From the definitions of `Delta_-` and `Delta_+`,

`p_{k-2}=x/r-Delta_-/y`,

`p_{k+1}=yr-Delta_+/x`.

Substitute into the bidiagonal flux rule. This gives

`q_{k-1}=G_- - U`,

`q_{k+1}=G_+ - V`,

while `q_k=x(a_kr+c_{k-1})` is unchanged. By Theorem 1, replacing both outer variables by their geometric-envelope values gives `q_k^2-G_-G_+=x^2P_k(r)`. Therefore

`q_k^2-q_{k-1}q_{k+1}`

`=x^2P_k(r)+UG_+ + VG_- - UV`,

which is (C1). Since `q_{k+1}=G_+-V`, the pair `UG_+-UV` equals `Uq_{k+1}`, giving (C2). Similarly `q_{k-1}=G_--U` turns `VG_--UV` into `Vq_{k-1}`, giving (C3). QED.
