## 5. Method #9 — RANDOMIZE: completion error is an exact Plancherel tail expectation

Write the defect counts as

`E_q(n)=ell_{n,n-q}`.

The fixed-defect residual-partition formula already established on this track is, with `N=n-q`,

`E_q(n)
 = 1/(q!)^2 * sum_{mu|-q, mu_1<=N} (f^mu)^2 R_mu(N)^2`,       (5.1)

where

`R_mu(N)=prod_{i=1}^q (N+i-mu_i)`                            (5.2)

and `mu` is padded by zeroes. The polynomial completion removes the source truncation:

`Etilde_q(n)
 = 1/(q!)^2 * sum_{mu|-q} (f^mu)^2 R_mu(N)^2
 = P_q(n)/q!`.                                                (5.3)

Under Plancherel measure on partitions of `q`,

`P_q^Pl(mu)=(f^mu)^2/q!`,

so (5.1)--(5.3) become exact expectation identities:

`E_q(n)      = (1/q!) E_q^Pl[R_mu(N)^2 1_{mu_1<=N}]`,
`Etilde_q(n) = (1/q!) E_q^Pl[R_mu(N)^2]`.                    (5.4)

Thus the completion error is a positive tail expectation over the event `mu_1>N`, not an uncontrolled polynomial artifact.

### Fixed-depth tail-support theorem

Fix integers `j>=1`, depth `s>=1`, and neighbor offset `t in {-1,0,1}`. Set

`n=2j-s`, `q=j+t`, `N=n-q=j-s-t`.

Every partition `mu|-q` can be written uniquely as

`mu=(q-r, lambda)`,                                           (5.5)

where `lambda|-r` and `q-r>=lambda_1` (with the empty tail at `r=0`). The source truncation fails exactly when

`mu_1=q-r>N`,

which is equivalent to

`r < s+2t`.                                                   (5.6)

For such a partition, the first factor in (5.2) is

`N+1-mu_1
 = (j-s-t)+1-(j+t-r)
 = r-s-2t+1`.                                                 (5.7)

At the largest invalid value `r=s+2t-1`, this factor is zero. Therefore every **nonzero** completion-error term lies in the finite range

`0 <= r <= s+2t-2`.                                          (5.8)

Consequently, if

`C_{j,t,s}
 = 1/(q!)^2
   sum_{r=0}^{s+2t-2}
   sum_{lambda|-r, q-r>=lambda_1}
     (f^(q-r,lambda))^2 R_(q-r,lambda)(N)^2`,                 (5.9)

with an empty sum when the upper bound is negative, then

`E_{j+t}(2j-s) = Etilde_{j+t}(2j-s) - C_{j,t,s}`.             (5.10)

**Proof.** Equation (5.6) classifies all partitions excluded by the source truncation. Equation (5.7) shows the endpoint invalid layer has zero weight, so only (5.8) contributes. Conversely every partition represented in (5.9) is invalid; terms with another zero residual factor simply contribute zero. Subtracting precisely those completed weights from (5.3) gives (5.10). QED.

The key point is that for every fixed depth `s`, the correction depends only on tail partitions of bounded sizes `r<=s` (up to `s+2` for the `j+1` neighbor), even when `j` grows.
