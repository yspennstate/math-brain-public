## 5. New lemma: a spectral-ratio bound for the mixed Bellman Hessian

The old loss in (4.6) treats the worst state-Hessian direction and the worst input-Hessian direction as if they could align simultaneously. They cannot: the input-Hessian coefficient is largest when the input lives on a much faster spectral scale than the state, whereas the mixed term then loses alignment. The following calculation captures that tradeoff exactly enough to improve the constant.

### Lemma `NM10-AVP3-CROSS-HESSIAN-01A`

Let `A` be a positive self-adjoint finite-spectrum operator on a real Hilbert space, `p>=2`, and

`Psi_p(z)=integral_0^infinity ||e^{-sA}z||^p ds`.

Then

`|D^2 Psi_p(z)[A^(1/2)z,A^(1/2)y]| <= kappa_p ||z||^(p-1)||y||`,       (5.1)

where

`kappa_p = p(1+sqrt(2p-3))/4`.                           (5.2)

At `p=2`, `kappa_2=1`. For the frozen range `2<p<3`, this is strictly smaller than the inherited Cauchy coefficient `(p-1)sqrt(p/2)`.

### Proof

The case `z=0` is immediate. Diagonalize `A` in an orthonormal basis:

`A e_j=lambda_j e_j`, `lambda_j>0`.

Write

`z=sum_j z_j e_j`, `y=sum_j y_j e_j`,

and set

`r(s)=||e^{-sA}z||^2`,

`m_(1/2)(s)=<e^{-sA}z,A^(1/2)e^{-sA}z>/r(s)`,

`m_1(s)=<e^{-sA}z,Ae^{-sA}z>/r(s)`.                     (5.3)

By Cauchy–Schwarz in the spectral probability measure determined by the squared coordinates of `e^{-sA}z`,

`m_(1/2)(s)^2 <= m_1(s)`.                                (5.4)

Let `a=(p-2)/2`. Expanding the Hilbert Hessian of `||.||^p` shows that the mixed Hessian is linear in `y`:

`D^2 Psi_p(z)[A^(1/2)z,A^(1/2)y] = sum_j K_j y_j`,        (5.5)

with

`K_j = p z_j integral_0^infinity r(s)^a e^(-2 lambda_j s)`

`      * [lambda_j + (p-2)sqrt(lambda_j)m_(1/2)(s)] ds`. (5.6)

Now define

`g_j(s)=r(s)^a e^(-2 lambda_j s)`.                        (5.7)

Since

`r'(s)=-2r(s)m_1(s)`,

we have the exact derivative identity

`-g_j'(s) = [2lambda_j+(p-2)m_1(s)]g_j(s)`.              (5.8)

Because `A>0`, `g_j(s)->0`, and therefore

`integral_0^infinity [2lambda_j+(p-2)m_1(s)]g_j(s) ds`

` = g_j(0)=||z||^(p-2)`.                                 (5.9)

Thus (5.6) is an average, against a positive measure of total mass `||z||^(p-2)`, of the scalar ratio

`q = [lambda+(p-2)sqrt(lambda)m_(1/2)]/[2lambda+(p-2)m_1]`.          (5.10)

Put `c=p-2`. By (5.4), if `m=m_(1/2)>0` and `x=sqrt(lambda)/m`, then

`q <= [x^2+c x]/[2x^2+c] =: f_c(x)`.                    (5.11)

(The case `m=0` is vacuous here because `A>0` and `z!=0`.) A direct derivative gives

`f_c'(x) = c[-2x^2+2x+c]/[2x^2+c]^2`.                   (5.12)

For `c>0` its positive maximizer is

`x_*=[1+sqrt(1+2c)]/2=[1+sqrt(2p-3)]/2`.                (5.13)

At the critical point `c=2x_*(x_*-1)`, so

`max_(x>0) f_c(x)=f_c(x_*)=x_*/2=[1+sqrt(2p-3)]/4`.     (5.14)

For `p=2`, the same value is `1/2` by direct inspection.

Combining (5.6), (5.9), and (5.14),

`|K_j| <= kappa_p |z_j| ||z||^(p-2)`.                   (5.15)

Therefore

`(sum_j K_j^2)^(1/2) <= kappa_p ||z||^(p-1)`.           (5.16)

Finally (5.5) and Hilbert-space Cauchy–Schwarz give (5.1). QED.

This is the new mechanism. It does not alter either pure Hessian estimate (4.3) or (4.4); it replaces only the mixed-term geometric-mean loss by a spectral-ratio calculation that uses the exact semigroup derivative.

## 6. Improved source-constant theorem for the exact P24 pair

### Theorem `NM10-AVP3-CROSS-HESSIAN-01B`

Let `beta>=0` and

`2<=p<1+2/beta^2`,

with the convention that the upper endpoint is infinity when `beta=0`. Put

`delta=1-beta^2(p-1)/2 >0`,

`kappa_p=p(1+sqrt(2p-3))/4`,

and

`C_hat_(p,beta) = [beta kappa_p + sqrt(beta^2 kappa_p^2 + delta p(p-1))]/(2delta)`.   (6.1)

For the P24 torus pair `A=Lambda`, `B=beta Lambda^(1/2)`, every finite horizon `T`, and arbitrary progressive stochastic input `g` with `f=0`,

`||u||_{L^p(Omega x (0,T);H^1)} <= C_hat_(p,beta) ||g||_{L^p(Omega x (0,T);L^2)}`.   (6.2)

For `beta>0` and `p>2` in the subcritical range, this improves the inherited P24 upper constant obtained from (4.6). In particular, for the frozen `beta=1`,

`C_p^g(T) <= C_hat_p`

with

`C_hat_p=[kappa_p+sqrt(kappa_p^2+p(p-1)(3-p)/2)]/(3-p)`. (6.3)

### Proof

Work first on a finite Fourier projection, where Ito's formula for `Psi_p` is classical. In (3.1), expand the Hessian contribution as

`H_z[A^(1/2)(beta z+y),A^(1/2)(beta z+y)]`

` = beta^2 H_z[A^(1/2)z,A^(1/2)z]`

`   + 2beta H_z[A^(1/2)z,A^(1/2)y]`

`   + H_z[A^(1/2)y,A^(1/2)y]`.                           (6.4)

Use the inherited sharp state-direction bound (4.3), the new mixed bound (5.1), and the inherited input-direction bound (4.4). After stopping, taking expectations, integrating in time, and dropping the nonnegative terminal Bellman value, one obtains

`delta I <= beta kappa_p I^((p-1)/p) J^(1/p)`

`           + p(p-1)/4 I^((p-2)/p) J^(2/p)`,             (6.5)

where `I,J` are as in Section 4. If `J=0`, uniqueness gives `I=0`. Otherwise put `R=(I/J)^(1/p)`. Then

`delta R^2 <= beta kappa_p R + p(p-1)/4`.                (6.6)

The positive root of the equality in (6.6) is exactly (6.1), proving the finite-projection estimate.

The old P24 Bellman theorem already provides existence and a uniform subcritical bound on the full torus problem, so no existence argument is being smuggled into the improved estimate. Approximate an arbitrary progressive `g` by finite Fourier projections, use the commuting projected equations, apply the uniform estimate above, and pass to the known full solution by the same projection/Fatou argument used in the corrected P24 source-scale proof. This gives (6.2). QED.
