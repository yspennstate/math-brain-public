## 4. New finite block: seven-column carry-lane policy

Fix block length `L=7`. Use the three rows `{-1,0,1}` and columns `0,...,7`. In departure columns `0,...,6`, the policy permits both orientations of each physical vertical edge and permits each physical horizontal edge only eastward. Vertical edges in the terminal column `x=7` are omitted.

For a start lane `s`, let `tau_s` be the minimum passage time in this restricted graph from `(0,s)` to the first vertex of the terminal column, and let `J_s` be the terminal lane. By reflection, the two outer start lanes have the same law; write state `O` for either outer lane and `C` for the center lane.

The exact exponential-infection recursion in the archived artifact gives

`g_O := E tau_O = 4.296421748498267...`,

`g_C := E tau_C = 4.129295270479138...`,

`p_OC := P(J_O=C) = 0.3682954578435359...`,

`p_CC := P(J_C=C) = 0.36893534232210445...`.

The exact rational values are printed in the archived output. The recursion visits `123985` states from an outer start and `176254` states from a center start.

### Lemma 4.1 — the finite recursion is exact

Let `S` be the infected vertex set before the terminal column has been hit. Every admissible physical edge from `S` to its complement has an independent residual rate-one exponential clock. If `m_j(S)` is the number of admissible boundary physical edges whose uninfected endpoint is `j` and `m(S)=sum_j m_j(S)`, then the next infection occurs after mean time `1/m(S)` and is at `j` with probability `m_j(S)/m(S)`. Hence

`E_S tau = 1/m(S) + sum_j [m_j(S)/m(S)] E_{S union {j}} tau`,

with terminal sets absorbing, and the same recursion propagates the exact terminal-lane probabilities.

This uses one clock per physical edge. The two stored orientations of a vertical edge never double-count a boundary edge: at any infected/uninfected cut only the orientation from the infected endpoint contributes. Horizontal westward traversal is simply excluded by the policy. Since all coefficients are rational integers, the recurrence returns exact rational values. QED.

## 5. Dependence-controlled block concatenation

Translated consecutive blocks use disjoint physical edges: block `j` owns the horizontal edges from columns `7j,...,7j+6` and the vertical edges in those departure columns; the terminal-column vertical edges are deliberately omitted and become departure-column edges of the next block. Therefore each fresh block environment is independent of the past conditional on its incoming lane.

Let `Z_j in {C,O}` be the lane state at the start of block `j`. Its transition probabilities are

`P(C|O)=p_OC`, `P(C|C)=p_CC`.

Set

`lambda = p_CC-p_OC = 0.0006398844785685518... > 0`,

`pi_C = p_OC/(p_OC+1-p_CC) = 0.3685312752864588...`,

`pi_O = 1-pi_C = 0.6314687247135412...`.

Starting at the center, the two-state recursion gives exactly

`P(Z_j=C) = pi_C + pi_O lambda^j`.

Since `g_C<g_O`, the expected cost of block `j` is

`E cost_j = pi_C g_C + pi_O g_O + pi_O lambda^j (g_C-g_O)`

and therefore is at most the stationary mean `pi_C g_C + pi_O g_O`.

`E T(0,7N e1) <= N(pi_C g_C + pi_O g_O) + pi_O`
