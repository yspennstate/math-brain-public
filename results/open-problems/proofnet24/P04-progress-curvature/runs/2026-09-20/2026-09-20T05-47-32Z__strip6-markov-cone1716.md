## 3. The six-column carry-lane block

Use three lanes `{-1,0,1}`. A block has columns `0,1,...,6`.

Inside one block allow:

- every horizontal physical edge from column `j` to `j+1`, but only traversed eastward, for `j=0,...,5`;
- both traversal directions of each physical vertical edge in columns `0,...,5`;
- **no** vertical edge in the terminal column `6`.

Thus consecutive translated blocks have disjoint physical edge sets. The terminal column of one block becomes the departure column of the next, whose vertical edges are still fresh.

### Exactness of the finite recursion

For an infected set `S` not yet meeting the terminal column, let `b(S)` be the number of currently usable boundary physical edges from infected to uninfected vertices, respecting the eastward restriction on horizontals. Let `r_S(v)` be the number of such boundary edges entering one outside vertex `v`.

Because all physical edge weights are iid rate-one exponentials, exponential memorylessness gives the exact Richardson/FPP recursion

\[
E(S)
=
\frac1{b(S)}+
\sum_{v\notin S}

with `E(S)=0` once a terminal vertex is infected. The same transition probabilities propagate the absorbing terminal-lane distribution. Each recursion step adds one vertex, so backward induction is finite and exact. No simulation or floating-point decision is used for (3.1)--(3.3).

## 4. Exact two-state dependence transfer

Aggregate the terminal lane into states

- `C`: center lane;
- `O`: either outer lane.

Reflection symmetry makes this aggregation Markov. Its transition matrix is

\[
P=
\begin{pmatrix}
p_{CC}&1-p_{CC}\\ p_{OC}&1-p_{OC}\end{pmatrix}
\tag{4.1}
\]

when rows are `(C,O)` and the first column is `C`.

The nontrivial eigenvalue is

\[
\lambda=p_{CC}-p_{OC}
=
\frac{10935965793766396838008814960989}
{5693872942219238740957593600000000}

\tag{4.2}

The stationary masses are

\[

\tag{4.3}

\[
\boxed{
\pi_O=1-\pi_C
=0.6312536381524816\ldots .
}
\tag{4.4}
\]

Start the first block at the center lane. If `c_j` denotes the probability that block `j` starts in state `C`, then

\[
c_{j+1}=p_{OC}+(p_{CC}-p_{OC})c_j,
\qquad c_0=1,
\]

so

\[
\boxed{c_j=\pi_C+\pi_O\lambda^j\ge\pi_C.}
\tag{4.5}
\]

Since the exact checker verifies `g_C<g_O`, the expected cost of block `j` satisfies

\[
\mathbb E G_j
=c_jg_C+(1-c_j)g_O
\le \pi_Cg_C+\pi_Og_O.
\tag{4.6}
\]

Define

\[
a_6:=\frac{\pi_Cg_C+\pi_Og_O}{6}.
\tag{4.7}
\]

After `N` blocks the constructed path reaches column `6N` in a random lane. If it is outer, append the single vertical edge in the terminal column to the center. That edge was deliberately excluded from all preceding blocks and is fresh `Exp(1)`. By (4.5), the terminal outer probability is at most `pi_O`. Therefore, **for every integer `N>=1`**, not only asymptotically,

\[
\boxed{

\tag{4.8}

This is the dependence-controlled block transfer. There is no independence assumption about optimal unrestricted geodesics and no local-surgery multiplication. The only dependence retained by the constructed policy is its one-bit lane class, which is solved exactly.

## 9. Why this route succeeds where the preceding fixed-end block stalls

The length-8 ladder computes a very good shortest path between **fixed center endpoints**, but concatenation discards terminal-lane information at every interface. Increasing the fixed block length improves the axis bound only by solving ever larger infected-set recursions.

The new construction changes the category of the block state: the right endpoint is allowed to be any of three lanes, and that lane is carried into the next block. The exact state needed for transfer is only `C/O`, not a full boundary configuration. This removes repeated reset cost while keeping the block environments disjoint.

That is why a six-column block, despite being shorter than the previous length-8 fixed-end block, improves the axis rate from `0.63038...` to `0.60829...`.

The approach still does **not** address the central axis/diagonal pair. Its oblique lower bound is entropy-limited by the current local-SAW compiler. The next quantitative target is therefore either:

1. improve the carry-lane policy (longer block or wider finite state while retaining an exact Markov transfer), or
2. combine the new axis bound with a stronger finite-memory self-avoiding path-count automaton to push the cone boundary below `1.716`.
