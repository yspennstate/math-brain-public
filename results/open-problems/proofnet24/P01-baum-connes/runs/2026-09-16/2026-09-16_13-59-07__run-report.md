# 0. Executive result

The universal scalar assembly maps

\[
\mu_i^G:K_i^{\mathrm{top}}(G)\longrightarrow K_i(C_r^*(G)),\qquad i=0,1,
\]

remain **OPEN** for arbitrary second-countable locally compact `G`. This run gives neither a universal proof nor a scalar counterexample.

The concrete bottleneck attacked here is the finite higher-Kazhdan/cohomological candidate screen inherited from P63. A fresh 2026 preprint of Pooya–Ren–Wang makes finitely generated infinite one-relator groups a natural explicit first-Laplacian test family. The main result of this run is that this whole family is **trace-obstruction saturated**: its first `L^2`-Betti number is always already in the exact Lück/Li–Nowak–Pooya scalar trace ring, with the torsion denominator exactly explained by the canonical cyclic subgroup. Therefore **even a perfect reduced spectral-gap certificate for the finite first Laplacian cannot produce a scalar Baum–Connes counterexample by the canonical trace-range argument in this family**.

The same calculation extends to orientable surface-plus-one-relation groups. A second theorem extracted from the new P25 block-gap work shows that Feshbach separation can transport a low-band `K_0` class but cannot manufacture a new canonical trace: the low-band projection has exactly the same `K_0` class and trace as the finite-support reference projection. This sharply limits what that controlled route can accomplish in P01.

## `P01-P64A-ONE-RELATOR-TRACE-SATURATION` — **PROVED**

Let

\[
G=\langle X\mid r\rangle
\]

be a finitely generated **infinite** one-relator group, let `F=F(X)`, put

\[
d=|X|<\infty,
\qquad
m=\exp_F(r)\in \mathbb N\cup\{\infty\}.
\]

Then

\[
\boxed{
\beta_1^{(2)}(G)=
\begin{cases}
 d-1-\dfrac1m,&m<\infty,\\[2mm]
 d-1,&m=\infty,
\end{cases}}
\]

and the scalar assembly trace ring is

\[
\boxed{
\Lambda_G=
\begin{cases}
\mathbb Z[1/m],&m<\infty,\\
\mathbb Z,&m=\infty.
\end{cases}}
\]

Consequently

\[
\boxed{\beta_1^{(2)}(G)\in\Lambda_G.}
\]

If `m>1`, the rational number `beta_1^(2)(G)` has denominator **exactly `m` in lowest terms**, because

\[
\beta_1^{(2)}(G)=\frac{(d-1)m-1}{m},
\qquad
\gcd((d-1)m-1,m)=1.
\]

Thus the fractional denominator is not merely allowed abstractly: it is saturated by the actual cyclic torsion subgroup of order `m`.

Since a finitely generated one-relator group is finitely presented, it is of type `F_2`. Its degree-one cohomological Laplacian is therefore a **finite group-ring matrix**. With the standard presentation 2-complex and Fox derivatives, one may take, up to the usual left/right convention,

\[
\partial_1=(x_1-1,\ldots,x_d-1),
\qquad
\partial_2=
\begin{pmatrix}
\partial r/\partial x_1\\
\vdots\\
\partial r/\partial x_d
\end{pmatrix},
\]

and

\[
\boxed{
\Delta_1=\partial_1^*\partial_1+\partial_2\partial_2^*
\in M_d(\mathbb C G).
}
\]

Attaching cells of dimension at least three produces a `K(G,1)` without changing this finite two-skeleton, so this is the finite degree-one matrix relevant to the `F_2` gate.

If zero is isolated in the reduced spectrum of this `Delta_1`, the higher Kazhdan projection

\[
p_1=\mathbf1_{\{0\}}(\Delta_1)\in M_d(C_r^*(G))
\]

has canonical trace

\[
\tau(p_1)=\beta_1^{(2)}(G)\in\Lambda_G.
\]

Therefore Li–Nowak–Pooya Proposition 1 can never contradict scalar assembly surjectivity from this trace, no matter how strong the gap certificate is.

This directly screens the fresh Pooya–Ren–Wang one-relator higher-Kazhdan family from the **forbidden canonical trace** route. It does **not** assert scalar Baum–Connes for every one-relator group, and it does **not** assert that the first Laplacian is always gapped.

## `P01-P64B-SURFACE-PLUS-ONE-RELATION-TRACE-SATURATION` — **PROVED**

Let `Sigma_g` be a closed orientable surface of genus `g>=1`, let

\[
S=\pi_1(\Sigma_g),
\qquad
1\ne\alpha\in S,
\qquad
G=S/\langle\!\langle\alpha\rangle\!\rangle,
\]

and put `m=exp_S(alpha)`. Dicks–Linnell give

\[
\beta_1^{(2)}(G)=
\begin{cases}
0,&g=1,\\[1mm]
2g-2-\dfrac1m,&g\ge2,
\end{cases}
\]

and exhibit a cyclic subgroup `C<=G` of order `m` into which every torsion subgroup embeds. Hence every finite subgroup has order dividing `m`, while `C` itself has order `m`, so

\[
\boxed{\Lambda_G=\mathbb Z[1/m]}
\]

and therefore

\[
\boxed{\beta_1^{(2)}(G)\in\Lambda_G.}
\]

For `g>=2` and `m>1`, the denominator of `beta_1^(2)(G)` is again exactly `m`, since

\[
\beta_1^{(2)}(G)=\frac{(2g-2)m-1}{m}.
\]

These groups have a finite presentation with `2g` generators and two relators (the surface relator and `alpha`), so their degree-one cohomological Laplacian is a concrete finite `2g x 2g` group-ring matrix built from the two Fox-derivative columns. Thus the same conclusion holds: **a reduced gap for the first Laplacian would produce a reduced projection, but its canonical trace is automatically in the scalar assembly trace ring.**

## `P01-P64C-FESHBACH-TRACE-NO-CREATION` — **PROVED**

Let `A=A*` lie in a unital C*-algebra with a trace `tau`, and let `p` be a projection, `q=1-p`. Write

\[
a=pAp,\qquad b=pAq,\qquad d=qAq.
\]

Assume

\[
\boxed{a\le\beta p,\qquad d\ge\delta q,\qquad \beta<\delta.}
\]

Then the P25 block argument, independently rederived here, gives

\[
\sigma(A)\cap(\beta,\delta)=\varnothing.
\]

Let

\[
P=\mathbf1_{(-\infty,\beta]}(A).
\]

The off-diagonal homotopy

\[
A_t=a+d+t(b+b^*),\qquad 0\le t\le1,
\]

has the same open gap `(beta,delta)` for every `t`. Its low spectral projections give a norm-continuous path from `p` to `P`. Therefore

\[
\boxed{[P]=[p]\in K_0,\qquad \tau(P)=\tau(p).}
\]

This is the exact P01 limitation:

> Feshbach/block-gap separation can turn a controlled finite-support projection into the correct low-band `K_0` class, but it cannot create a new canonical trace value.

In particular, if `p in M_n(C G)` is a finite-support projection whose trace is already in `Lambda_G`, then the low-band projection `P` has the same allowed trace. Conversely, if a finite-support `p` already had trace outside `Lambda_G`, it would itself already be a reduced `K_0` trace obstruction; no Feshbach construction would be needed to manufacture one.

This does **not** diminish P25's value for controlled transport. It identifies exactly what it transports: an existing class, not a new scalar-trace obstruction.

## `P01-P64D-IRRATIONAL-FINITE-TYPE-UPSTREAM-BLOCKER` — **PROVED logical reduction / OPEN existence**

Li–Nowak–Pooya Proposition 1 requires type `F_{n+1}`. Such a group is in particular of type `FP_{n+1}(Q)`. Fournier-Facio–Sauer's current 2026 paper explicitly states that the existence of a group of type `FP_{n+1}(Q)` with irrational `n`-th `L^2`-Betti number is an open problem.

Therefore any **irrational** higher-Kazhdan counterexample candidate satisfying the Li–Nowak–Pooya finite-type gate would already solve this upstream open problem before the reduced-gap question is even addressed.

This changes the candidate-search priority:

1. irrational `L^2`-Betti candidates of the required finite type are presently not available from the known constructions;
2. the Fournier-Facio–Sauer arbitrary-real family does not meet `FP_2(Q)`, hence a fortiori does not meet `F_3` for the degree-two Li–Nowak–Pooya route;
3. the next realistic finite-type screen should therefore include **rational values outside `Lambda_G`** as well as any future breakthrough irrational examples, rather than spending gap/SOS effort on trace values already certified to lie in `Lambda_G`.

Primary source:

`https://ems.press/content/serial-article-files/42627`

\[
\mu_i:K_i^G(EG)\to K_i(C_r^*(G)),\qquad i=0,1.
\]

Theorem 9, quoting Lück Theorem 0.3, says that if the Baum–Connes assembly map is surjective, then

\[
\tau_*\circ\mu_0
\]

takes values in the subring

\[
\Lambda_G\subset\mathbb Q
\]

generated by `Z` and inverses of orders of finite subgroups.

\[

# 3. Mandatory spectral-stability seed rederived

Let `A=A*>=0` in a unital C*-algebra and assume

\[
\sigma(A)\subset\{0\}\cup[\delta,M],
\qquad
0<\delta\le M.
\]

Because `{0}` is clopen in `sigma(A)`, its characteristic function is continuous **on the spectrum**, so continuous functional calculus gives

\[
\boxed{P_A=\mathbf1_{\{0\}}(A)\in C^*(A,1).}
\]

For `t>=0`, the functions `e^{-t lambda}` and `1_{0}(lambda)` agree at `lambda=0`, while on `[delta,M]`

\[
|e^{-t\lambda}-0|\le e^{-t\delta}.
\]

Hence

\[
\boxed{\|e^{-tA}-P_A\|\le e^{-t\delta}.}
\]

For `eta>0`, the function

\[
r_\eta(\lambda)=\frac{\eta}{\lambda+\eta}
\]

equals `1` at `0` and is decreasing on `[0,infty)`. Therefore

\[
\boxed{
\|\eta(A+\eta I)^{-1}-P_A\|
\le\frac{\eta}{\delta+\eta}.
}
\]

Now let `A,B>=0` satisfy

\[
\sigma(A),\sigma(B)\subset\{0\}\cup[\delta,\infty)
\]

with the **same** `delta>0`. Define the bounded Moore–Penrose inverses by functional calculus,

\[
A^\dagger=f(A),\qquad
f(0)=0,\quad f(\lambda)=1/\lambda\ (\lambda\ge\delta),
\]

and similarly for `B`. Then

\[
\|A^\dagger\|,\|B^\dagger\|\le1/\delta.
\]

Since `BP_B=0`,

\[
(1-P_A)P_B
=A^\dagger A P_B
=A^\dagger(A-B)P_B,
\]

so

\[
\|(1-P_A)P_B\|\le\frac{\|A-B\|}{\delta}.
\]

Symmetrically,

\[
\|P_A(1-P_B)\|\le\frac{\|A-B\|}{\delta}.
\]

Using

\[
P_A-P_B=P_A(1-P_B)-(1-P_A)P_B,
\]

we get the required sufficient estimate

\[
\boxed{
\|P_A-P_B\|\le\frac{2\|A-B\|}{\delta}.
}
\]

This is **not** a theorem producing a uniform gap for group approximants. It only says what follows once a common gap is already proved.

### Shrinking-gap failure

Take a positive `A` with nonzero kernel and positive spectrum bounded below by some `delta_0>0`, and let

\[
B=A+\varepsilon I.
\]

Then

\[
\|A-B\|=\varepsilon\to0,
\]

but the old kernel eigenvalue moves to `varepsilon`; hence `P_B=0` on the old kernel while `P_A=1` there, so

\[
\|P_A-P_B\|=1.
\]

The positive gap for `B` near that component is only `varepsilon`, so no fixed common `delta` survives. This is the exact reason marked/strong/norm-small perturbation by itself does not stabilize kernels.

# 4. Proof of `P01-P64A-ONE-RELATOR-TRACE-SATURATION`

Let

\[
G=\langle X\mid r\rangle,
\quad
F=F(X),
\quad
d=|X|<\infty,
\quad
m=\exp_F(r).
\]

Assume `G` is infinite.

## 4.1 `L^2`-Betti number

Dicks–Linnell define

\[
\chi(G)=1-d+\frac1m,
\]

with the convention `1/infty=0`, and prove

\[
\beta_1^{(2)}(G)=\max\{-\chi(G),0\}.
\]

For an infinite one-relator group, `beta_0^(2)(G)=0`, and their summary/proof gives

\[
\boxed{\beta_1^{(2)}(G)=d-1-\frac1m.}
\]

If `m=infty`, then `r=1` and `G=F_d`, so this reads `beta_1=d-1`.

## 4.2 Exact finite-subgroup trace ring

Assume first `m<infty`. Write

\[
r=q^m
\]

with `q` not a proper power of larger exponent, and let `c` be the image of `q` in `G`. Dicks–Linnell prove that

\[
C=\langle c\rangle
\]

has order exactly `m`. Hence the order `m` itself occurs among finite subgroups, so

\[
\mathbb Z[1/m]\subseteq\Lambda_G.
\]

Their proof then takes the normal closure `H` of `c`, shows

\[
H=F_0\rtimes C
\]

with `F_0` free and `G/H` locally indicable, and invokes Theorem 3.1. Theorem 3.1(i) says every torsion subgroup embeds in `C`. Therefore every finite subgroup of `G` has order dividing `m`. If `D<=G` is finite, then

\[
|D|\mid m,
\qquad
\frac1{|D|}=\frac{m/|D|}{m}\in\mathbb Z[1/m].
\]

Thus every generator of `Lambda_G` lies in `Z[1/m]`, proving

\[
\boxed{\Lambda_G=\mathbb Z[1/m].}
\]

If `m=infty`, then `G` is free and torsion-free, so `Lambda_G=Z`.

## 4.3 Exact denominator saturation

For finite `m`,

\[
\beta_1^{(2)}(G)
=d-1-\frac1m
=\frac{(d-1)m-1}{m}.
\]

Since

\[
(d-1)m-1\equiv-1\pmod m,
\]

the numerator is coprime to `m`. Thus, for `m>1`, the reduced denominator is exactly `m`.

This is useful diagnostically: the fraction is not an unexplained rational anomaly. It uses precisely the maximal torsion denominator already present in the group.

## 4.4 Concrete finite Laplacian and the Li–Nowak–Pooya gate

A finite presentation gives a finite two-skeleton of a `K(G,1)` after attaching cells only in dimensions at least three. Therefore `G` is type `F_2`, exactly what Li–Nowak–Pooya require for `n=1`.

With the one-relator presentation 2-complex, the cellular differentials in degrees `2 -> 1 -> 0` are represented, up to the conventional choice of left/right modules, by

\[
\partial_1=(x_1-1,\ldots,x_d-1)
\]

and the Fox column

\[
\partial_2=
\begin{pmatrix}
\partial r/\partial x_1\\
\vdots\\
\partial r/\partial x_d
\end{pmatrix}.
\]

Hence the positive degree-one Laplacian

\[
\Delta_1=\partial_1^*\partial_1+\partial_2\partial_2^*
\]

is a **finite** `d x d` matrix over `C G`.

Suppose one succeeds in proving a genuine reduced gap

\[
\sigma_{M_d(C_r^*(G))}(\Delta_1)
\subset\{0\}\cup[\delta,M]
\]

for some `delta>0`. Then

\[
p_1=\mathbf1_{\{0\}}(\Delta_1)
\in M_d(C_r^*(G))
\]

and, by Li–Nowak–Pooya Proposition 7,

\[
\tau(p_1)=\beta_1^{(2)}(G).
\]

But Sections 4.1–4.2 show

\[
\tau(p_1)=\beta_1^{(2)}(G)\in\Lambda_G.
\]

Therefore the implication in Li–Nowak–Pooya Proposition 1 is numerically satisfied, not contradicted.

### Exact conclusion

The finite-type condition is satisfied. The finite matrix is explicit. A gap may or may not exist. But **even if the gap is proved**, the canonical trace does not obstruct scalar assembly.

This is a rigorous candidate-screen certificate, not a claim that the projection class is necessarily in the assembly image for every one-relator group.

1\ne\alpha\in S.
\]

Let

\[
m=\exp_S(\alpha).
\]

Dicks–Linnell Theorem 5.1 gives

\[
\chi(G)=\min\left\{2-2g+\frac1m,0\right\},
\]

and

\[
\beta_n^{(2)}(G)=-\delta_{n,1}\chi(G).
\]

Hence

\[
\beta_1^{(2)}(G)=0\quad(g=1),
\]

while for `g>=2`,

\[
\boxed{\beta_1^{(2)}(G)=2g-2-\frac1m.}
\]

Their construction chooses a root `beta` with `beta^m=alpha`, lets `c` be its image in `G`, and proves that

\[
C=\langle c\rangle
\]

has order `m`. Lemma 5.6(iii) proves that every torsion subgroup of `G` embeds in `C`. Thus exactly as above,

\[
\boxed{\Lambda_G=\mathbb Z[1/m].}
\]

For `g>=2`,

\[
\beta_1^{(2)}(G)
=\frac{(2g-2)m-1}{m}
\in\mathbb Z[1/m],
\]

and if `m>1` the denominator is exactly `m` because the numerator is `-1 mod m`.

A standard finite presentation is

\[
G=\langle x_1,y_1,\ldots,x_g,y_g
\mid
R_\Sigma,\alpha\rangle,
\]

where

\[
R_\Sigma=\prod_{j=1}^g[x_j,y_j].
\]

Hence the degree-one Laplacian is a finite `2g x 2g` group-ring matrix obtained from the `2 x 2g` Fox Jacobian of the two relators together with the degree-zero boundary. If that Laplacian has isolated zero in the reduced algebra, its kernel projection trace is `beta_1^(2)(G)`, which is already in `Lambda_G`.

So this second explicit finite-presentation family is also closed for the canonical trace-range counterexample route.

# 6. Proof of `P01-P64C-FESHBACH-TRACE-NO-CREATION`

Let

\[
A=
\begin{pmatrix}
a&b\\ b^*&d\end{pmatrix}
\]

relative to `pH direct-sum qH`, where

\[
a\le\beta p,
\qquad
d\ge\delta q,
\qquad\beta<\delta.
\]

Fix `lambda in (beta,delta)`. Then

\[
d_\lambda=d-\lambda q\ge(\delta-\lambda)q>0,
\]

so `d_lambda` is invertible. The Schur complement of `d_lambda` in `A-lambda` is

\[
S_\lambda
=a-\lambda p-bd_\lambda^{-1}b^*.
\]

Since `d_lambda^{-1}>=0`,

\[
S_\lambda
\le(\beta-\lambda)p<0.
\]

Thus `S_lambda` is invertible. The standard block factorization then shows that `A-lambda` is invertible. Since `lambda` was arbitrary,

\[
\boxed{\sigma(A)\cap(\beta,\delta)=\varnothing.}
\]

Now define

\[
A_t=
\begin{pmatrix}
a&t b\\ t b^*&d\end{pmatrix},
\qquad 0\le t\le1.
\]

The same Schur-complement proof uses only the signs of `a-beta` and `d-delta`, so it gives the same gap `(beta,delta)` for every `t`.

Choose a continuous scalar function `f` with

\[
f=1\text{ on }(-\infty,\beta],
\qquad
f=0\text{ on }[\delta,\infty).
\]

Because every `A_t` avoids `(beta,delta)`,

\[
P_t=f(A_t)
\]

is exactly the low spectral projection. Since `t -> A_t` is norm-continuous, so is `t -> P_t`.

At `t=0`,

\[
A_0=a\oplus d.
\]

All of `sigma(a)` lies at or below `beta` and all of `sigma(d)` lies at or above `delta`, hence

\[
P_0=p.
\]

At `t=1`, `P_1=P`. Therefore `p` and `P` are connected by a norm-continuous projection path and

\[
[P]=[p]\in K_0.
\]

Any trace on a C*-algebra induces a homomorphism on `K_0`, so

\[
\boxed{\tau(P)=\tau(p).}
\]

No smallness condition on `b` appears anywhere in this stable trace conclusion.
