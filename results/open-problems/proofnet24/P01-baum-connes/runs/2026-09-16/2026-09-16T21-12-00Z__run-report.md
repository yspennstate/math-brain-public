# 5. `P01-P74A-GAUGE-DERIVATIVE-MATRIX-K1-COORDINATES` — PROVED

## Theorem

Let
\[
U=\sum_{g\in S}A_g\lambda_g
\in U_N(M_N(\mathbb CG))
\]
be a finite-support matrix unitary. With the unnormalized matrix trace `Tr_N`, define
\[
\kappa_j(U)
=(\operatorname{Tr}_N\otimes\tau)(U^*\partial_jU).
\tag{5.1}
\]
Then:

1. `kappa_j(U)` depends only on the stabilized homotopy class `[U] in K_1(A)`;
2. it is additive under block sum;
3. the finite coefficient formula is
   \[
   \boxed{
   \kappa_j(U)=
   \sum_{g\in S}\ell_j(g)\operatorname{Tr}(A_g^*A_g);
   }
   \tag{5.2}
   \]
4. for the fixed wreath-product group,
   \[
   \boxed{
   [U]=\kappa_1(U)[u_{s_1}]+\kappa_2(U)[u_{s_2}],
   }
   \tag{5.3}
   \]
   and in particular `kappa_j(U) in Z`;
5. with Pooya's explicit topological generators,
   \[
   \boxed{
   \mu_1^G(\kappa_1(U)v_1+\kappa_2(U)v_2)=[U].
   }
   \tag{5.4}
   \]

## Proof

For fixed `j`, form the based gauge loop
\[
L_{U,j}(t)=U^*\alpha_{j,t}^{(N)}(U),
\qquad 0\le t\le2\pi.
\tag{5.5}
\]
Because `alpha_{j,0}=alpha_{j,2pi}=id`, this is a loop based at `1`.

Define its trace winding by
\[
W_\tau(L)=
\frac1{2\pi i}\int_0^{2\pi}
(\operatorname{Tr}_N\otimes\tau)(L(t)^*L'(t))\,dt.
\tag{5.6}
\]
For a smooth endpoint-fixed homotopy `L(s,t)` of based loops, cyclicity of the trace gives
\[
\partial_s\,\tau(L^{-1}\partial_tL)
=\partial_t\,\tau(L^{-1}\partial_sL),
\]
because the Maurer–Cartan commutator term has trace zero. Integration in `t` has zero endpoint contribution since the endpoints remain `1`. Thus `W_tau` is based-homotopy invariant. It is plainly stable under adjoining identity blocks and additive under block sum. Therefore `W_tau(L_{U,j})` depends only on `[U] in K_1(A)`.

Using (4.4),
\[
\begin{aligned}
L_{U,j}^*L_{U,j}'
&=\alpha_{j,t}(U^*)U\,U^*i\alpha_{j,t}(\partial_jU)\\
&=i\alpha_{j,t}(U^*\partial_jU).
\end{aligned}
\]
By trace invariance (4.2),
\[
W_\tau(L_{U,j})
=(\operatorname{Tr}_N\otimes\tau)(U^*\partial_jU)
=\kappa_j(U).
\tag{5.7}
\]
So (1) and (2) follow. This is the standard trace-winding mechanism behind the de la Harpe–Skandalis determinant; the argument above is included so no determinant theorem is used as a black box.

Now expand
\[
U^*\partial_jU
=\sum_{g,h\in S}
\ell_j(h)A_g^*A_h\lambda_{g^{-1}h}.
\]
The canonical trace kills every term except `g=h`, hence
\[
\kappa_j(U)
=\sum_{g\in S}\ell_j(g)\operatorname{Tr}(A_g^*A_g),
\]
which proves (5.2).

Pooya's published computation gives
\[
K_1(A)=\mathbb Z[u_{s_1}]\oplus\mathbb Z[u_{s_2}].
\tag{5.8}
\]
On its basis,
\[
\kappa_j(u_{s_k})=\ell_j(s_k)=\delta_{jk}.
\tag{5.9}
\]
Since `kappa_j` is a homomorphism on `K_1(A)`, equations (5.8)–(5.9) show that `kappa_1,kappa_2` are exactly the two integral coordinate maps. This proves (5.3) and, retroactively, integrality of the apparently real sums in (5.2).

Finally the inherited, source-checked Pooya assembly computation gives
\[
\mu_1^G(v_j)=[u_{s_j}].
\]
Linearity and (5.3) give (5.4). QED.
