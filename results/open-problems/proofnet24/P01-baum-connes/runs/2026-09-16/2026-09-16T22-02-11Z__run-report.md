## 3. Ninety-percent new-method work

### Move #8 — GO THE OTHER WAY AND DISCRETIZE

P74's obstruction was that `partial_j` is unbounded in the C*-norm, so plain norm truncation cannot certify the gauge coordinate. The right discretization is not an arbitrary norm approximation. It is the **torus Fourier decomposition inside the smooth domain**, together with a derivative-energy tail bound.

For a smooth unitary `U`, this run derives

\[
\kappa_j(U)=\sum_{k\in\mathbb Z^2} k_j a_k,
\qquad
E_j(U)=\sum_{k\in\mathbb Z^2} k_j^2a_k,
\]

with `a_k >= 0`, and proves the finite truncation certificate

\[
\left|\kappa_j(U)-\sum_{|k_j|\le M}k_j a_k\right|
\le \frac{E_j(U)}{M}.
\]

Since the exact answer is an integer, once `E_j(U)/M<1/2`, finite Fourier data determine the exact coordinate by nearest-integer rounding. This repairs the specific P74 failure: derivative control is now part of the norm used to truncate.

Outcome: **successful**.

### Move #16 — COMPUTE SMALL CASES AND STARE AT WHAT FAILS

I tested the obvious finite Taylor truncations of the analytic factor before deciding how to discretize it. In the commutative subgroup algebra with `z=u_{s_1}` and `H=z+z^{-1}`,

\[

\qquad

Exact Laurent-polynomial arithmetic gives

\[

So finite Taylor truncation does not preserve exact unitarity even at the first two nontrivial orders. Polar correction would restore unitarity, but generically introduces a nonpolynomial inverse square root and therefore gives back infinite Fourier support. This is why the useful finite object is the **pairing truncation plus a rigorous tail bound**, not an exact finite-support truncation of the unitary itself.

Outcome: the naive finite-unitary discretization **fails**, but the failure identifies the correct finite certification scheme.

## 4. P75 theorem: smooth gauge coordinates compute the K1 class

### Claim `P01-P75A-SMOOTH-GAUGE-K1-PAIRING`

**PROVED for the frozen group.** Let

\[
A=C_r^*(G),
\]

and let

\[
\ell=(\ell_1,\ell_2):G\longrightarrow\mathbb Z^2
\]

be obtained by forgetting the lamp subgroup and abelianizing `F_2`, so `ell_j(s_k)=delta_jk` and every lamp has zero `ell`-coordinate.

Define the torus action

\[
\alpha_t(\lambda_g)
=e^{i(t_1\ell_1(g)+t_2\ell_2(g))}\lambda_g,
\qquad t\in\mathbb T^2.
\]

Let `A^infty` be the smooth-vector Fréchet *-algebra for this action. Define

\[
\partial_j(\lambda_g)=\ell_j(g)\lambda_g;
\]

thus `i partial_j` is the infinitesimal generator of the `j`th circle action. Let `tau` be the canonical trace on `A`, and write

\[
T_N=\operatorname{Tr}_N\otimes\tau
\]

with the unnormalized matrix trace. For every smooth matrix unitary

\[
U\in U_N(M_N(A^\infty)),
\]

define

\[
\kappa_j(U)=T_N(U^*\partial_jU).
\]

Then:

1. `kappa_j(U)` depends only on the class `[U] in K_1(A)`;
2. `kappa_j(U)` is an integer;
3. the exact K-theory class is

\[
\boxed{
[U]=\kappa_1(U)[u_{s_1}]+\kappa_2(U)[u_{s_2}]
}
\]

and therefore

\[
\boxed{
\mu_1^G\bigl(\kappa_1(U)v_1+\kappa_2(U)v_2\bigr)=[U].
}
\]

Moreover, if

\[
U=\sum_{k\in\mathbb Z^2}U_k
\]

is its torus Fourier decomposition and

\[
a_k=T_N(U_k^*U_k),
\]

then

\[
\boxed{
\kappa_j(U)=\sum_{k\in\mathbb Z^2}k_j a_k,
\qquad
E_j(U):=T_N((\partial_jU)^*\partial_jU)
=\sum_{k\in\mathbb Z^2}k_j^2a_k.
}
\]

For every positive integer `M`,

\[
\boxed{
\left|\kappa_j(U)-\sum_{|k_j|\le M}k_j a_k\right|
\le\frac{E_j(U)}{M}.
}
\]

Consequently, if `E_j(U)/M<1/2`, the exact integer `kappa_j(U)` is the unique nearest integer to the finite truncated sum.

This theorem is a fixed-group corollary of Pooya's `K_1` computation plus standard smooth C*-dynamical-system machinery. It is not asserted as new literature.

## 5. Proof of P75A

### 5.1 The torus action and its smooth algebra

Each `ell_j` is a group homomorphism, so multiplying the left-regular group unitary `lambda_g` by the character `exp(i t dot ell(g))` defines a *-automorphism of the algebraic group ring. It is isometric in the reduced norm and hence extends to `A=C_r^*(G)`. Strong continuity follows first on the dense algebraic group ring and then on all of `A` by uniform boundedness of the automorphisms.

The canonical trace is invariant:

\[
\tau(\alpha_t(a))=\tau(a).
\]

Therefore, for every smooth `a`, differentiating the trace identity gives

\[
\tau(\partial_ja)=0.
\tag{5.1}
\]

The smooth-vector algebra `A^infty` is dense. It is also inverse closed, and this particular point can be checked directly: if `a in A^infty` is invertible in `A`, then

\[
\alpha_t(a^{-1})=\alpha_t(a)^{-1}.
\]

The inversion map on the Banach-Lie group of invertibles is smooth, while `t mapsto alpha_t(a)` is smooth. Hence `t mapsto alpha_t(a^{-1})` is smooth, so `a^{-1} in A^infty`. The same argument works at every matrix level. Thus the smooth algebra is spectrally invariant; the standard holomorphic-functional-calculus/Karoubi density theorem identifies its topological `K_1` with `K_1(A)`.

This is exactly the extra domain control that P74 lacked.

### 5.2 Homotopy invariance of the pairing

Let `U(s)` be a `C^1` path of smooth unitaries and put

\[
X=U^*\dot U,
\qquad
Y=U^*\partial_jU.
\]

Then `X^*=-X`, `dot U=UX`, and

\[
\partial_j\dot U=(\partial_jU)X+U\partial_jX.
\]

Differentiate the pairing:

\[
\frac d{ds}T_N(U^*\partial_jU)
=T_N(\dot U^*\partial_jU)+T_N(U^*\partial_j\dot U).
\]

Using `dot U^*=X^*U^*=-XU^*`, this becomes

\[
-T_N(XY)+T_N(YX)+T_N(\partial_jX).
\]

The first two terms cancel by traciality, and the last is zero by (5.1). Hence

\[
\frac d{ds}\kappa_j(U(s))=0.
\tag{5.2}
\]

The same Leibniz/tracial calculation gives

\[
\kappa_j(UV)=\kappa_j(U)+\kappa_j(V),
\]

and block sum is additive as well. By spectral invariance, smooth representatives and smooth homotopies compute the same `K_1(A)` as the C*-completion. Thus `kappa_j` is a homomorphism on `K_1(A)`.

### 5.3 Identification with Pooya's two integral coordinates

For the two Pooya basis unitaries,

\[
\partial_j(u_{s_k})=\delta_{jk}u_{s_k},
\]

so

\[
\kappa_j(u_{s_k})=\delta_{jk}.
\tag{5.3}
\]

Pooya's computation gives

\[
K_1(A)=\mathbb Z[u_{s_1}]\oplus\mathbb Z[u_{s_2}].
\]

Therefore the two homomorphisms `(kappa_1,kappa_2)` are exactly the integer coordinate maps in that basis. This proves both integrality and

\[
[U]=\kappa_1(U)[u_{s_1}]+\kappa_2(U)[u_{s_2}].
\]

The inherited assembly identities `mu_1^G(v_j)=[u_{s_j}]` then give the displayed assembly preimage by additivity.

### 5.4 Fourier formula and finite tail certificate

For `k in Z^2`, let

\[
U_k=(2\pi)^{-2}\int_{\mathbb T^2}e^{-ik\cdot t}\alpha_t(U)\,dt.
\]

Smoothness implies rapid Fourier decay in the Fréchet topology, so termwise application of `partial_j` is legitimate:

\[
U=\sum_kU_k,
\qquad
\partial_jU=\sum_k k_jU_k.
\]

Since `T_N` is `alpha`-invariant,

\[
T_N(U_k^*U_l)=0\qquad(k\ne l).
\tag{5.4}
\]

Indeed, applying `alpha_t` multiplies this trace by `exp(i(l-k) dot t)` without changing its value.

Put

\[
a_k=T_N(U_k^*U_k)\ge0.
\]

Equations (5.4) and the Fourier expansions give

\[
\kappa_j(U)
=T_N(U^*\partial_jU)
=\sum_k k_j a_k,
\tag{5.5}
\]

and

\[
E_j(U)
=T_N((\partial_jU)^*\partial_jU)
=\sum_k k_j^2a_k.
\tag{5.6}
\]

For the tail outside `|k_j|<=M`, positivity gives

\[
\begin{aligned}
\left|\sum_{|k_j|>M}k_ja_k\right|
&\le\sum_{|k_j|>M}|k_j|a_k\\
&\le\frac1M\sum_{|k_j|>M}k_j^2a_k\\
&\le\frac{E_j(U)}M.
\end{aligned}
\tag{5.7}
\]

This proves the truncation certificate. Since Section 5.3 already proves `kappa_j(U) in Z`, an error strictly below `1/2` determines the exact coordinate by nearest-integer rounding.

This is the successful repair of P74's unbounded-derivation obstruction: approximation takes place in a derivative-controlled smooth/Sobolev scale rather than in C*-norm alone.

## 6. One further explicit class: an analytic infinite-support representative

### Claim `P01-P75B-ANALYTIC-INFINITE-SUPPORT-ASSEMBLY-CLASS`

**PROVED.** Put

\[

\qquad

\qquad

\qquad

Then `H=H^*`, so `E` is unitary and the path

\[
[0,1]\ni t\longmapsto e^{itH}
\]

joins `1` to `E`. Hence

\[
[E]=0\in K_1(A).
\tag{6.1}
\]

The element `E` belongs to the smooth, indeed analytic, torus subalgebra. It is not finitely supported. To see the latter, restrict to the cyclic subgroup algebra

\[
C_r^*(\langle s_1\rangle)\cong C(\mathbb T),
\]

where `u_{s_1}` is the coordinate `z`. The function is

\[
z\longmapsto e^{i(z+z^{-1})}.
\]

If this were a Laurent polynomial, its extension on `C^*` would have only a finite-order pole at zero and infinity. Instead `exp(i(z+z^{-1}))` has an essential singularity at zero. Hence it is not a Laurent polynomial. Linear independence of the group Fourier coefficients then rules out a finite group-ring support for `E` inside `C_r^*(G)`.

Now `V` is a unitary and, by (6.1),

\[
[V]=[u_w]
=4[u_{s_1}]-3[u_{s_2}].
\tag{6.2}
\]

The P75 pairing gives the same result directly. Since `H` and `partial_1 H=u_{s_1}-u_{s_1}^{-1}` commute inside the cyclic subgroup algebra,

\[
\partial_1E=iE(u_{s_1}-u_{s_1}^{-1}).
\]

Therefore

\[
\tau(E^*\partial_1E)
=i\tau(u_{s_1}-u_{s_1}^{-1})=0,
\]

and `partial_2 E=0`. Additivity with the word unitary gives

\[
\boxed{(\kappa_1(V),\kappa_2(V))=(4,-3).}
\tag{6.3}
\]

Consequently the requested assembly membership is explicit:

\[
\boxed{
\mu_1^G(4v_1-3v_2)=[V].
}
\tag{6.4}
\]

This is one further explicit class for the **same fixed group and degree**, and unlike P73/P74 it has a genuinely infinite-support analytic representative. It does not increase the rank because the rank-two target is already saturated.
