# 4. Ninety-percent new-method screen

## Move #7 — TAKE THE LIMIT

### Idea

P75 works on the smooth-vector algebra for the torus action. Instead of asking for more explicit smooth functions, complete the smooth unitary locus in the graph norm of the tracial `L^2` gauge generator.

Let `A=C_r^*(G)` and let `alpha_t` be the `T^2` gauge action induced by the exponent-sum map

\[
\ell=(\ell_1,\ell_2):G\to\mathbb Z^2.
\]

On `L^2(A,tau)` the `j`th circle acts unitarily. Write `nabla_j` for its skew-adjoint infinitesimal generator, so on group elements

\[
\nabla_j(\lambda_g)=i\ell_j(g)\lambda_g.
\tag{4.1}
\]

The P75 pairing can then be written

\[
\kappa_j(U)
=\frac1i(\operatorname{Tr}_N\otimes\tau)(U^*\nabla_jU).
\tag{4.2}
\]

### Candidate limit mechanism

For a bounded unitary `U` in the `L^2` graph domain of both generators, smooth it by torus convolution:

\[
a_\varepsilon
=\int_{\mathbb T^2}\rho_\varepsilon(t)\alpha_t(U)\,dt.
\tag{4.3}
\]

The expected convergence is simultaneously

\[
\|a_\varepsilon-U\|\to0,
\qquad
\|\nabla_j a_\varepsilon-\nabla_jU\|_2\to0.
\tag{4.4}
\]

The smoothed element need not be unitary. For small `epsilon`, however, it is invertible. Its polar unitary is

\[
b_\varepsilon
=a_\varepsilon(a_\varepsilon^*a_\varepsilon)^{-1/2}.
\tag{4.5}
\]

The key estimate to prove is

\[
\|b_\varepsilon-U\|\to0,
\qquad
\|\nabla_j b_\varepsilon-\nabla_jU\|_2\to0.
\tag{4.6}
\]

The second convergence is the nontrivial part. If

\[
h_\varepsilon=a_\varepsilon^*a_\varepsilon,
\]

then the `*`-derivation property of `nabla_j` gives

\[
\nabla_jh_\varepsilon
=(\nabla_ja_\varepsilon)^*a_\varepsilon
+a_\varepsilon^*\nabla_ja_\varepsilon.
\tag{4.7}
\]

Because the limit `U` is unitary, the corresponding limit expression is `nabla_j(U^*U)=0`. Thus (4.4) should imply

\[
\|\nabla_jh_\varepsilon\|_2\to0.
\tag{4.8}
\]

For `h_epsilon` uniformly bounded away from zero, the integral functional-calculus representation of `h^{-1/2}` gives a uniform estimate of the shape

\[
\|\nabla_j(h_\varepsilon^{-1/2})\|_2
\le C\|\nabla_jh_\varepsilon\|_2,
\tag{4.9}
\]

which is precisely what is needed for (4.6).

If (4.6) is proved carefully, then the P75 integer pairings of `b_epsilon` are eventually the fixed `K_1` coordinates of `U` (because sufficiently norm-close unitaries are homotopic), while the pairing in (4.2) converges by the `L^2` graph convergence. That would extend P75 to the first Sobolev graph closure.

**Route survives the screen and is the selected simplest special case for the next run, but is not promoted to a theorem here because this is the mandatory stuck/thinking run.**

No hidden gap is papered over: the next run must write the product-domain argument for the `L^2` generator, the uniform functional-calculus derivative estimate, and the pairing-continuity estimate in full.
