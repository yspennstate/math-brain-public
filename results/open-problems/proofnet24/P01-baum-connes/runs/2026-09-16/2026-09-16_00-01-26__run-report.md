# 0. Executive result

The original target remains **OPEN**:

\[
\mu_i^G:K_i^{\mathrm{top}}(G)\longrightarrow K_i(C_r^*(G)),\qquad i=0,1,
\]

for **every second-countable locally compact group** `G`.

This run gives neither a universal proof nor a scalar counterexample. It does not replace the target by Baum–Connes with arbitrary coefficients and does not silently narrow the universal problem to discrete groups.

The new work attacks the precise source-compression bottleneck isolated by P01-P49 and the newest P25 report. P25 proved that, in the triangular cyclic-filling family, the finite-scale height Mayer–Vietoris boundary of the scalar Bott source class dies at root scale, but its explicit quotient-word construction carried a very large depth-dependent constant

\[
2\,20^{m-1}m!.
\]

This run replaces that recursive word construction by a direct **combinatorial-number-system (combinadic) orbit-block construction**. The result is an explicit root-scale representative with coefficient only linear in `m` times `(m!)^{1/m}`.

Fix `m>=2`,

\[
H_{m,L}=C_L*F_{m-1}
=\langle x_1,\ldots,x_m\mid x_1^L=1\rangle,
\]

\[
\alpha_m(x_1)=x_1,\qquad
\alpha_m(x_j)=x_{j-1}x_j\quad(2\le j\le m),
\]

and

\[
\Gamma_{m,L}=H_{m,L}\rtimes_{\alpha_m}\mathbb Z,
\qquad
tht^{-1}=\alpha_m(h).
\]

Let

\[
\pi:H_{m,L}\to C_L=\langle x_1\rangle
\]

be the free-product retraction killing `x_2,...,x_m`.

The main new theorem is:

## `P01-P50A-COMBINADIC-ORBIT-WORD-COMPRESSION` — **PROVED**

For every integer `s>=0` there is an explicit height-zero word

\[
W_{m,s}\in H_{m,L}\subset\Gamma_{m,L}
\]

such that

\[
\boxed{\pi(W_{m,s})=x_1^s}
\tag{0.1}
\]

and, for `s>=1`,

\[
\boxed{
|W_{m,s}|_{\Gamma_{m,L}}
\le
(3m-2)\Bigl((m!s)^{1/m}+m-1\Bigr).
}
\tag{0.2}
\]

The bound is independent of `L` except for the interpretation of the exponent modulo `L` in `C_L`.

More precisely, write the combinadic expansion

\[
\boxed{
s=\binom{q_m}{m}+\binom{q_{m-1}}{m-1}+\cdots+\binom{q_1}{1},
\qquad
q_m>q_{m-1}>\cdots>q_1\ge0.
}
\tag{0.3}
\]

For `j>=1`, `q>=1`, define

\[
U_{j,q}
:=
\prod_{r=0}^{q-1}\alpha_m^r(x_j)
=
(x_jt)^q t^{-q}
\in H_{m,L}.
\tag{0.4}
\]

Then

\[
\boxed{\pi(U_{j,q})=x_1^{\binom qj}}
\tag{0.5}
\]

and one may take

\[
W_{m,s}=\prod_{j=1}^{m}U_{j,q_j},
\tag{0.6}
\]

omitting the zero binomial terms. The key input is the exact identity

\[
\pi(\alpha_m^r(x_j))=x_1^{\binom r{j-1}},
\tag{0.7}
\]

followed by the hockey-stick identity.

The corresponding boundary theorem is:

## `P01-P50B-EXPLICIT-ROOT-MV-HALFSPACE-ENTRY` — **PROVED, conditional only on already-validated P25 categorical change-of-groups/MV step**

Let `kappa_L` be the first death scale of the exact cyclic source class and let `Theta^partial_{m,L}` be the first vanishing scale of the height Mayer–Vietoris boundary from current P25. Then

\[
\boxed{
\Theta^\partial_{m,L}
\le
2(3m-2)\Bigl((m!\kappa_L)^{1/m}+m-1\Bigr).
}
\tag{0.8}
\]

Since `kappa_L<=L/2`,

\[
\boxed{
\Theta^\partial_{m,L}
\le
2(3m-2)\Bigl((m!L/2)^{1/m}+m-1\Bigr).
}
\tag{0.9}
\]

Combining with the independently rechecked lower half of P25-P38,

\[
\boxed{
\frac12\left(\frac{\kappa_L}{B_m}\right)^{1/m}
\le
\Theta^\partial_{m,L}
\le
2(3m-2)\Bigl((m!\kappa_L)^{1/m}+m-1\Bigr),
\qquad
B_m=\frac{m^{m-1}}{(m-1)!}.
}
\tag{0.10}
\]

Thus the boundary is root-scale with a much smaller explicit general-depth upper constant. For `m=2`, P25 already has the sharper special estimate

\[
\Theta^\partial_{2,L}\le10\lceil\sqrt{\kappa_L}\rceil,
\]

so `(0.8)` is intended as the improved **general-depth** certificate, not as a replacement for that special `m=2` constant.

Most importantly, `(0.8)` does **not** prove that the full class

\[
z_{m,L}\in K_0^{\Gamma_{m,L}}(P_2\Gamma_{m,L})
\]

dies at root scale. The height cover is `H_{m,L}`-invariant, not `Gamma_{m,L}`-invariant, and the compression uses equality only after quotienting by `N=ker(pi)`. The word `W_{m,s}` is generally **not equal to** `x_1^s` in `H_{m,L}`; it merely belongs to the same `N`-coset. Therefore the remaining source obstruction has now been localized further: it is the controlled lifting/cancellation problem in the halfspace/gluing kernel, or equivalently a genuinely `Gamma`-equivariant mapping-torus/PV compression problem.

This yields the route certificate:

## `P01-P50C-RECURSIVE-CONSTANT-NONSTRUCTURAL` — **PROVED / route certificate**

The exponential-in-depth constant `20^{m-1}m!` in the P25 quotient-word construction is **not structural**. At the quotient/MV-boundary level it can be replaced by a coefficient of order

\[
(3m-2)(m!)^{1/m}.
\]

Hence future effort should not be spent optimizing the old recursive quotient-word constant. The serious obstruction is lifting the already-root-scale quotient boundary cancellation to the full `Gamma`-equivariant source class, and then matching that scale with target controlled K-relations and reduced-norm control.

# 3. Mandatory spectral-stability seed, rederived

Let `A>=0` in a unital C*-algebra and assume

\[
\sigma(A)\subset\{0\}\cup[\delta,M],
\qquad 0<\delta\le M.
\]

Because `{0}` is clopen in the relative spectrum, the function equal to `1` at `0` and `0` on `[delta,M]` is continuous on `sigma(A)`. Hence continuous functional calculus gives

\[
\boxed{P_A=\mathbf1_{\{0\}}(A)\in C^*(A,1).}
\tag{3.1}
\]

For `t>0`, on the kernel `e^{-tA}-P_A=0`, while on positive spectrum its absolute value is at most `e^{-t delta}`. Therefore

\[
\boxed{
\|e^{-tA}-P_A\|\le e^{-t\delta}.
}
\tag{3.2}
\]

Likewise, for `eta>0`, the function

\[
f_\eta(x)=\frac{\eta}{x+\eta}
\]

has value `1` at zero and on `[delta,M]` is at most `eta/(delta+eta)`. Thus

\[
\boxed{
\|\eta(A+\eta I)^{-1}-P_A\|
\le
\frac{\eta}{\delta+\eta}.
}
\tag{3.3}
\]

Now suppose `A,B>=0` and both satisfy the same positive gap `delta`. Define the bounded pseudoinverses

\[
A^\dagger=f(A),\qquad B^\dagger=f(B),
\quad
f(0)=0,\quad f(x)=1/x\ (x\ge\delta).
\]

Then

\[
\|A^\dagger\|,\|B^\dagger\|\le1/\delta.
\]

Since `BP_B=0`,

\[
(1-P_A)P_B
=A^\dagger AP_B
=A^\dagger(A-B)P_B,
\]

so

\[
\|(1-P_A)P_B\|\le\frac{\|A-B\|}{\delta}.
\]

Interchanging `A,B` gives the same bound for `(1-P_B)P_A`. Since

\[
P_A-P_B=P_A(1-P_B)-(1-P_A)P_B,
\]

we obtain the requested safe estimate

\[
\boxed{
\|P_A-P_B\|
\le
\frac{2\|A-B\|}{\delta}.
}
\tag{3.4}
\]

(The standard two-projection identity sharpens the constant to `1`, as retained in prior P01 reports, but the factor `2` is sufficient here.)

Finally, if `A` has nonzero kernel and

\[
B=A+\varepsilon I,
\]

then `||A-B||=epsilon ->0` while `P_B=0` and `||P_A-P_B||=1`. The positive spectrum of `B` contains `epsilon`, so no common gap bounded below independently of `epsilon` exists. This is the exact shrinking-gap obstruction. Norm closeness alone is not a proof of spectral-projection stability for group approximants.

# 4. New theorem P50A — combinadic orbit-word compression

We now prove the theorem in full.

## 4.1 Exact exponent created by one triangular orbit

For `j>=1`, `r>=0`, define `E_j(r)` by

\[
\pi(\alpha_m^r(x_j))=x_1^{E_j(r)}.
\]

For `j=1`, `alpha_m^r(x_1)=x_1`, so

\[
E_1(r)=1=\binom r0.
\]

For `j>=2`,

\[
E_j(0)=0,
\]

and

\[
\alpha_m^{r+1}(x_j)
=
\alpha_m^r(x_{j-1})\alpha_m^r(x_j).
\]

Applying `pi` gives

\[
E_j(r+1)=E_{j-1}(r)+E_j(r).
\]

Pascal's identity and the initial condition imply by induction

\[
\boxed{
E_j(r)=\binom r{j-1}.
}
\tag{4.1}
\]

This is an equality in the cyclic quotient only; it does not claim that the nonabelian word `alpha^r(x_j)` equals `x_1^{binom(r,j-1)}` in `H`.

## 4.2 Orbit blocks realize binomial coefficients

For `q>=1`, define

\[
U_{j,q}=\prod_{r=0}^{q-1}\alpha_m^r(x_j).
\]

Since `t h t^{-1}=alpha_m(h)`, telescoping gives

\[
\boxed{
U_{j,q}=(x_jt)^q t^{-q}.
}
\tag{4.2}
\]

This element has height zero and hence belongs to `H`. After cancelling the final positive `t` against `t^{-q}`, `(4.2)` yields the explicit word-length bound

\[
|U_{j,q}|_\Gamma\le3q-2.
\tag{4.3}
\]

For `j=1` we can do better and simply use

\[
U_{1,q}=x_1^q,
\qquad |U_{1,q}|_\Gamma\le q.
\tag{4.4}
\]

Applying `pi`, using `(4.1)`, and then the hockey-stick identity gives

\[
\pi(U_{j,q})
=
x_1^{\sum_{r=0}^{q-1}\binom r{j-1}}
=
\boxed{x_1^{\binom qj}}.
\tag{4.5}
\]

Thus one orbit block of length `O(q)` produces cyclic exponent of order `q^j`.

## 4.3 Combinatorial number system

We use the standard greedy combinadic fact, and include the proof so no external number-theory black box is needed.

### Lemma 4.1

For every `s>=0` and `m>=1`, there exist integers

\[
q_m>q_{m-1}>\cdots>q_1\ge0
\]

such that

\[
\boxed{
s=\sum_{j=1}^m\binom{q_j}{j}.
}
\tag{4.6}
\]

### Proof

For `s=0`, take all terms zero. Assume `s>=1`. Choose `q_m` maximal with

\[
\binom{q_m}{m}\le s.
\]

Then maximality and Pascal give

\[
s-\binom{q_m}{m}
<
\binom{q_m+1}{m}-\binom{q_m}{m}
=
\binom{q_m}{m-1}.
\]

Apply the same greedy choice to the remainder at level `m-1`; the strict inequality forces

\[
q_{m-1}<q_m.
\]

Iterating gives strictly decreasing indices. At level `1`, every nonnegative remainder is `binom(q_1,1)=q_1`, so the algorithm terminates exactly. ∎

Let

\[
Q=q_m.
\]

Because `s>=1`, `Q>=m`, and

\[
s\ge\binom Qm
=
\frac{Q(Q-1)\cdots(Q-m+1)}{m!}
\ge
\frac{(Q-m+1)^m}{m!}.
\]

Hence

\[
\boxed{
Q\le(m!s)^{1/m}+m-1.
}
\tag{4.7}
\]

The strict ordering also implies `q_j<=Q-m+j`.

## 4.4 Constructing `W_{m,s}`

Take the combinadic indices from Lemma 4.1 and define

\[
W_{m,s}=\prod_{j=1}^{m}U_{j,q_j},
\]

omitting any term for which the relevant binomial coefficient is zero.

Using `(4.5)` and `(4.6)`,

\[
\pi(W_{m,s})
=
x_1^{\sum_j\binom{q_j}{j}}
=
\boxed{x_1^s}.
\]

For the length, use the sharp coefficient `1` on the `j=1` block and `3` on the others:

\[
|W_{m,s}|_\Gamma
\le
q_1+3\sum_{j=2}^m q_j.
\]

Since every `q_j<=Q`,

\[
|W_{m,s}|_\Gamma
\le
(3m-2)Q.
\]

Combining with `(4.7)` proves

\[
\boxed{
|W_{m,s}|_\Gamma
\le
(3m-2)\Bigl((m!s)^{1/m}+m-1\Bigr).
}
\tag{4.8}
\]

This proves `P01-P50A-COMBINADIC-ORBIT-WORD-COMPRESSION`.

## 4.5 Exact distinction from a forbidden shortcut

The construction proves only

\[
\pi(W_{m,s})=x_1^s.
\]

Equivalently,

\[
W_{m,s}x_1^{-s}\in N=\ker\pi.
\]

It does **not** prove

\[
W_{m,s}=x_1^s\quad\text{in }H_{m,L}.
\]

For example, already at `m=2`, the orbit block is a product of the noncommuting words `alpha^r(x_2)`. Killing `x_2` produces the large triangular exponent, but those `x_2` factors do not cancel in `H`. This is why the theorem compresses the `N`-quotient/MV boundary but does not by itself compress the full `Gamma` source class.

# 5. New theorem P50B — explicit root-scale MV boundary / halfspace entry

Define the quotient-compression radius

\[
\mathcal C_m(S)
=
\max_{0\le s\le S}
\min\{\,|w|_\Gamma:w\in H,\ \pi(w)=x_1^s\,\}.
\]

P50A gives, for `S>=1`,

\[
\boxed{
\mathcal C_m(S)
\le
(3m-2)\Bigl((m!S)^{1/m}+m-1\Bigr).
}
\tag{5.1}
\]

The categorical/topological step of current P25-P38 is as follows. Let `N=ker(pi)`. Because `N` is torsion-free, it acts freely on the proper Rips complexes, and change of groups identifies the relevant `H`-equivariant overlap K-homology with the `C_L`-equivariant K-homology of the quotient. If every cyclic displacement of size at most the cyclic death scale `kappa_L` has an `N`-coset representative of `Gamma`-length at most `C`, then the cyclic null relation at scale `kappa_L` maps to the quotient overlap at scale at most `2C`. Therefore

\[
\Theta^\partial_{m,L}\le2\mathcal C_m(\kappa_L).
\tag{5.2}
\]

Substituting `(5.1)` gives

\[
\boxed{
\Theta^\partial_{m,L}
\le
2(3m-2)\Bigl((m!\kappa_L)^{1/m}+m-1\Bigr).
}
\tag{5.3}
\]

The exact cyclic source theorem gives `kappa_L<=floor(L/2)`, hence

\[
\boxed{
\Theta^\partial_{m,L}
\le
2(3m-2)\Bigl((m!L/2)^{1/m}+m-1\Bigr).
}
\tag{5.4}
\]

For the lower direction, P18/P25's finite-height projection gives, if the boundary vanishes by scale `D`,

\[
\kappa_L
\le
Q_D\binom{Q_D+m-1}{m-1},
\qquad Q_D\le2D.
\]

With

\[
B_m=\frac{m^{m-1}}{(m-1)!},
\]

one has

\[
Q\binom{Q+m-1}{m-1}\le B_mQ^m,
\]

so

\[
\kappa_L\le B_m(2D)^m.
\]

Therefore

\[
\boxed{
D\ge\frac12\left(\frac{\kappa_L}{B_m}\right)^{1/m}.
}
\tag{5.5}
\]

# 6. What P50 changes for the Baum–Connes program

P49 established a **lower** root scale for the full source relation. P25-P38 then showed that the height-MV boundary already has an **upper** root-scale certificate. P50 now shows that the enormous recursive constant in that upper certificate was an artifact: the cyclic quotient boundary can be compressed directly by orbit blocks plus combinadics.

The source-side obstruction can therefore be stated more sharply.

The following tasks are no longer plausible explanations for a super-root obstruction:

1. finding a root-scale representative of the cyclic quotient exponent;
2. overcoming the old `20^{m-1}m!` recursive constant;
3. proving that the finite-scale height-MV boundary itself vanishes at root scale.

They now have explicit certificates.

## 6.2 What remains genuinely open

The missing source implication is still

\[
\operatorname{Res}_{H}^{\Gamma}(z_{m,L;D})
\in\operatorname{im}(K_0^H(X_D^+)\oplus K_0^H(X_D^-))
\quad\Longrightarrow?\quad
z_{m,L;D'}=0
\]

with `D'=O_m(D)` or another root-scale bound.

There are two exact categorical difficulties:

- the height halfspaces are `H`-invariant but not `Gamma`-invariant;
- restriction from `Gamma` to `H` is not known to be injective at the relevant finite source scale.

A proof must therefore supply either:

1. controlled `H`-halfspace/flasque cancellation plus a valid induction back to the semidirect product; or
2. a genuinely `Gamma`-equivariant finite-scale mapping-torus/Pimsner–Voiculescu sequence that realizes the same cancellation.

Even if the full source relation is compressed to `D=O(L^{1/m})`, the current verified matrix-stable norm window is only

\[
R\log L=o(L^{1/m}).
\]

Thus P50 does not erase the target-side boundary-scale problem isolated by P47/P49. It makes the comparison cleaner: the natural source scale is genuinely root-scale, while the present cb near-isometry window is smaller by a logarithmic factor.

A successful permanence proof on this family now needs at least one of:

- a fixed positive fraction root-scale cb upper/reverse norm window;
- a class-sensitive target relation theorem that works at root scale without full near-isometry;
- a new source compression that lands strictly below `L^{1/m}/log L` (P49 strongly obstructs this for the present class).

# 7. Counterexample route: finite matrices remain distinct from von Neumann dimensions

Nothing in P50 weakens the counterexample route's exact requirements.

Let

\[
C\in M_{u,v}(\mathbb CG),
\qquad D=C^*C.
\]

An exotic von Neumann kernel dimension

\[
\dim_{L(G)}\ker C
\]

is **not** by itself a reduced-`C^*` K-class. To obtain the kernel projection in the reduced algebra one needs

\[
\sigma_{C_r^*(G)}(D)\subset\{0\}\cup[\delta,M]
\]

for some `delta>0`; only then

\[
P=\mathbf1_{\{0\}}(D)\in M_v(C_r^*(G)).
\]

If scalar assembly were surjective, the canonical trace of `[P]` would have to lie in the allowed scalar assembly trace range. Thus a finite, reduced-gapped matrix with forbidden trace/class remains a valid coefficient-free counterexample certificate.

The following shortcuts remain invalid:

- an irrational `l^2`-Betti number without a finite reduced-gapped matrix;
- an infinite sum of nonzero finite-subgroup projections whose traces converge but whose projections do not converge in norm;
- a group quotient without the weak-containment/amenable-kernel condition needed for a reduced group-C* map;
- marked-group or strong convergence used as if it supplied upper reduced-norm control;
- an embedding used as if it isolated zero in reduced spectrum.
