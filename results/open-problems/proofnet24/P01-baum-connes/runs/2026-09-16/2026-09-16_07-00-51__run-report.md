# 3. Mandatory spectral-stability seed

Let `A>=0` in a unital C*-algebra and assume
\[
\sigma(A)\subset\{0\}\cup[\delta,M],\qquad \delta>0.
\]
Because `{0}` is clopen in `sigma(A)`, continuous functional calculus gives
\[
P_A=1_{\{0\}}(A)\in C^*(A,1).
\]
On the kernel, `e^{-tA}=1`; on `[delta,M]` its norm is at most `e^{-t delta}`. Hence
\[
\boxed{\|e^{-tA}-P_A\|\le e^{-t\delta}.}
\tag{3.1}
\]
Likewise the scalar function `eta/(x+eta)` equals `1` at zero and is at most `eta/(delta+eta)` on the positive spectral part, so
\[
\boxed{
\|\eta(A+\eta I)^{-1}-P_A\|
\le\frac{\eta}{\delta+\eta}.
}
\tag{3.2}
\]

Now let positive `A,B` have the same positive gap `delta`. Their Moore–Penrose inverses satisfy
\[
\|A^\dagger\|,\|B^\dagger\|\le\delta^{-1}.
\]
Since `BP_B=0`,
\[
(1-P_A)P_B=A^\dagger AP_B=A^\dagger(A-B)P_B,
\]
and similarly
\[
(1-P_B)P_A=B^\dagger(B-A)P_A.
\]
Thus both cross terms have norm at most `||A-B||/delta`. Using the standard two-projection decomposition (or simply the sum of the two off-kernel components) gives the requested sufficient bound
\[
\boxed{
\|P_A-P_B\|
\le\frac{2\|A-B\|}{\delta}.
}
\tag{3.3}
\]
A sharper factor `1` is available from the standard two-projection angle identity, but `(3.3)` is the required estimate.

This is a **sufficient norm-plus-uniform-gap hypothesis**, not a proof that approximating group operators possess such a gap. If `A` has nonzero kernel and
\[
B=A+\varepsilon I,
\]
then `||A-B||=epsilon ->0` while `ker B=0`; the positive gap of `B` shrinks to `epsilon`, so there is no common uniform `delta`. This exposes exactly why norm closeness alone cannot control kernels.

# 4. Independent proof of `P01-P57A-MIXED-C2-ORBIT-CLASSIFICATION`

Write
\[
\sigma_g=K\cup Kg
\]
as a vertex set, using that `g` commutes with `c` and therefore with `K`.

Assume
\[
h\sigma_g=\sigma_{g'}.
\]
Because `1` is a vertex of `sigma_g`, the element `h=h*1` is a vertex of the target, hence
\[
h\in K\cup Kg'.
\]

If `h in K`, then
\[
hK=K,
\qquad
hKg=Kg,
\]
so equality with `K union Kg'` forces
\[
Kg=Kg',
\]
i.e. `g' in Kg`.

If `h in Kg'`, write `h=kg'` with `k in K`. Then
\[
hK=Kg'
\]
and, because `g,g'` centralize `K`,
\[
hKg=K g'g.
\]
For the union to equal `K union Kg'`, the second coset must be `K`, so
\[
g'g\in K,
\]
i.e.
\[
g'\in Kg^{-1}.
\]

Conversely, if `g' in Kg`, the sets are already the same up to the `K` action, while if `g' in Kg^{-1}`, left multiplication by `g'` exchanges the two `K`-cosets. Therefore `(0.1)` is an equivalence.

Now take canonical representatives
\[
g=a^rt^n,\qquad g'=a^{r'}t^{n'}
\]
with
\[
1\le n,n'\le\lfloor d/2\rfloor,
\qquad
n\le r\le d-n,
\qquad
n'\le r'\le d-n'.
\]
If `g' in Kg`, height gives `n'=n`. The only possible `a`-exponents modulo `L=2d` are `r` and `r+d`; but both `r,r'` lie in `[1,d-1]`, so only `r'=r` is possible. If `g' in Kg^{-1}`, height gives `n'=-n`, impossible for positive canonical heights. Hence `(0.2)` follows.

Finally
\[
\#\{r:n\le r\le d-n\}=d-2n+1,
\]
so summing over `n` gives `(0.3)`.

# 6. Proof of `P01-P57C-MIXED-C2-PRIMITIVE-H1-NOGO`

## 6.1 The first K-homology filtration of `BC_L`

Use the homological Atiyah–Hirzebruch spectral sequence for complex K-homology:
\[
E^2_{p,q}=H_p(BC_L;K_q(pt))\Longrightarrow K_{p+q}(BC_L).
\]
Complex K-homology coefficients are `Z` in even degree and zero in odd degree. For a finite cyclic group,
\[
H_{2j}(BC_L;\mathbb Z)=0\quad(j>0),
\qquad
H_{2j+1}(BC_L;\mathbb Z)=\mathbb Z/L.
\]
Thus
\[
E^2_{1,0}=\mathbb Z/L.
\]

No differential leaves `(1,0)` because the homological `d_r` lowers `p` by `r>=2`. An incoming differential has source
\[
(p,q)=(1+r,1-r).
\]
If `r` is even, `1-r` is odd and the K coefficient vanishes. If `r` is odd, `1+r` is positive even and the cyclic group homology vanishes. Hence
\[
E^\infty_{1,0}=\mathbb Z/L.
\]
Since
\[
F_0K_1(BC_L)=K_1(pt)=0,
\]
the first filtration subgroup is canonically
\[
F_1K_1(BC_L)\cong\mathbb Z/L.
\]
The quotient-circle class `xi_L` classifies the generator `a in C_L`; its H1 edge is therefore `1 mod L`, proving `(0.6)` and in particular that this first-filtration component has exact order `L`.

## 6.2 Naturality for `C_2 -> C_L`

The inclusion sends the generator of `C_2` to
\[
c=a^d.
\]
On first homology it sends
\[
1\pmod2\longmapsto d\pmod L.
\]
AHSS naturality gives the same map on the first K-homology filtration. Thus
\[
(BK\to BC_L)_*(\xi_2)
\]
has first-filtration component `d mod L`, of exact order two.

Let
\[
q:H_L=C_L*\langle b\rangle\to C_L
\]
be the free-product retraction. Applying `(Bq)_*` to the P57B signature gives
\[
[(Bq)_*\mathfrak e_{r,n}(u)]_{F_1}
=\pm\dim(u)d\pmod L.
\tag{6.1}
\]
Therefore all direct mixed-`C_2` equatorial signatures generate at most the subgroup
\[
\langle d\rangle=\{0,d\}\subset\mathbb Z/L.
\]
On the other hand, the retained free-source detector has Wang boundary
\[
\partial_W(\bar z_{2,L})=\pm i_*(\xi_L)\ne0
\]
inside `K_1(BH_L)`, and retraction to `BC_L` has first-filtration component `1 mod L`. For `L>=4`, `1` does not lie in `<d>`. This proves `(0.8)`.

Again, the conclusion is exactly about the **direct local equatorial signature** of the explicit mixed `C_2` block. It does not commute the full unresolved critical cellular differential with the Wang map without proof.
