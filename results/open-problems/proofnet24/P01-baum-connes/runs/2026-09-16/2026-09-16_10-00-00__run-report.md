## `P01-P60B-GLSZ-FUNCTIONAL-CALCULUS-HALF-BARRIER` — **PROVED**

\[

\boxed{

# 3. Mandatory spectral-stability seed rederived

Let `A=A*>=0` in a unital matrix `C*`-algebra and suppose

\[
\sigma(A)\subset\{0\}\cup[\delta,M],
\qquad \delta>0.
\]

Then `{0}` is clopen in `sigma(A)`, so continuous functional calculus gives

\[
\boxed{P_A=\mathbf1_{\{0\}}(A)}
\]

inside the algebra.

For `t>0`, the function `e^{-tx}` equals `1` at zero and is at most `e^{-t delta}` on `[delta,M]`, hence

\[
\boxed{
\|e^{-tA}-P_A\|\le e^{-t\delta}.
}
\]

For `eta>0`, the function `eta/(x+eta)` equals `1` at zero and is at most `eta/(delta+eta)` on the positive spectrum, hence

\[
\boxed{
\|\eta(A+\eta I)^{-1}-P_A\|
\le\frac{\eta}{\delta+\eta}.
}
\]

Now suppose positive `A,B` share the same positive gap:

\[
\sigma(A),\sigma(B)\subset\{0\}\cup[\delta,\infty).
\]

Define the bounded pseudoinverse

\[
A^\dagger(0)=0,
\qquad
A^\dagger(x)=x^{-1}\quad(x\ge\delta).
\]

Since `BP_B=0`,

\[
(1-P_A)P_B
=A^\dagger A P_B
=A^\dagger(A-B)P_B,
\]

so

\[
\|(1-P_A)P_B\|
\le\frac{\|A-B\|}{\delta}.
\]

Interchanging `A,B` gives the symmetric estimate. Thus, using the elementary two-projection bound,

\[
\boxed{
\|P_A-P_B\|
\le\frac{2\|A-B\|}{\delta}.
}
\]

As retained earlier, a sharper factor `1` follows from the standard exact two-projection norm identity, but the requested factor `2` is already sufficient.

### Shrinking-gap failure

Let `A>=0` have nonzero kernel and let

\[
B=A+\varepsilon I.
\]

Then

\[
\|A-B\|=\varepsilon\to0,
\]

but `ker B=0`. The positive gap of `B` near the old kernel is only `epsilon`; there is no common positive `delta` independent of `epsilon`.

Therefore norm closeness by itself does not control kernel projections. The common-gap hypothesis is a **sufficient stability assumption**, not a theorem about marked-group approximants.

P60C below exhibits a concrete matrix where the heat and resolvent approximants fail in norm with error exactly `1` for every finite parameter.

# 5. Proof of `P01-P60A-GLSZ-APPROX-SOS-RESIDUAL-FLOOR`

Fix `delta>0` and let `Q>=0` be any positive operator in `L(G)`. Define

\[
R=D^2-\delta D-Q.
\]

A finite sum of squares

\[
Q=\sum_jB_j^*B_j
\]

in `C_r^*(G)` is a special case, so proving the theorem for arbitrary `Q>=0` is stronger than proving it only for SOS witnesses.

## 5.1 A controlled atom in the negative window when `0<delta<8`

Because

\[
\lambda_1
=16\sin^2\frac\pi6
=4,
\]

if `0<delta<8`, then `lambda_1>delta/2`. Since `lambda_n->0`, there is a minimal integer `m>=2` such that

\[
\lambda_m\le\frac\delta2.
\]

By minimality,

\[
\lambda_{m-1}>\frac\delta2.
\tag{5.1}
\]

Put

\[
x_n=\frac\pi{4n+2}.
\]

On `(0,pi/2]`, the function `sin x/x` is decreasing. Since `x_m<x_{m-1}`,

\[
\frac{\sin x_m}{\sin x_{m-1}}
\ge\frac{x_m}{x_{m-1}}
=\frac{2m-1}{2m+1}.
\]

For `m>=2`,

\[
\frac{2m-1}{2m+1}\ge\frac35.
\]

Squaring gives

\[
\frac{\lambda_m}{\lambda_{m-1}}
\ge\frac9{25}.
\]

Using (5.1),

\[
\boxed{
\lambda_m>\frac9{50}\delta.
}
\tag{5.2}
\]

Together with `lambda_m<=delta/2`,

\[
\delta-\lambda_m\ge\frac\delta2.
\]

Therefore

\[
\boxed{
\lambda_m(\delta-\lambda_m)
>\frac9{100}\delta^2.
}
\tag{5.3}
\]

## 5.2 Compression to the atom

Let

\[
E_m=\mathbf1_{\{\lambda_m\}}(D).
\]

This is a nonzero projection in `L(G)`. On its range,

\[
D E_m=\lambda_m E_m.
\]

Hence

\[
E_m R E_m
=
\lambda_m(\lambda_m-\delta)E_m-E_mQE_m.
\]

Because `Q>=0`,

\[
E_mQE_m\ge0,
\]

so

\[
E_mRE_m
\le
-\lambda_m(\delta-\lambda_m)E_m.
\]

By (5.3),

\[
E_mRE_m
<
-\frac9{100}\delta^2 E_m.
\]

Choose any unit vector in `ran(E_m)`. Its quadratic form under `R` is at most `-9 delta^2/100`. Since `R` is self-adjoint,

\[
\boxed{
\|R\|>\frac9{100}\delta^2,
\qquad 0<\delta<8.
}
\tag{5.4}
\]

Replacing strict inequality by the safe weak lower bound proves the first branch of `c_op(delta)`.

## 5.3 The branch `delta>=8`

Use the first positive atom

\[
\lambda_1=4.
\]

Let `E_1` be its spectral projection. Then

\[
E_1RE_1
=4(4-\delta)E_1-E_1QE_1
\le-4(\delta-4)E_1.
\]

Thus

\[
\boxed{
\|R\|\ge4(\delta-4),
\qquad\delta\ge8.
}
\tag{5.5}
\]

This proves the operator-norm residual floor for every positive correction `Q` and hence for every finite SOS correction.

## 5.4 Tracial negative-part floor

Write the Jordan decomposition

\[
R=R_+-R_-,
\qquad R_+,R_-\ge0.
\]

Since `R>=-R_-`, compression gives

\[
E_mRE_m\ge-E_mR_-E_m.
\]

Combining with

\[
E_mRE_m\le-a_mE_m,
\qquad
 a_m:=\lambda_m(\delta-\lambda_m),
\]

we get

\[
E_mR_-E_m\ge a_mE_m.
\]

Taking the canonical finite trace,

\[
\tau(R_-)
\ge\tau(E_mR_-E_m)
\ge a_m\tau(E_m).
\tag{5.6}
\]

For `0<delta<8`, (4.2) and (5.3) yield

\[
\tau(R_-)
>
\frac9{100}\delta^2\frac1{2^{2m+1}-1}.
\tag{5.7}
\]

It remains to bound `m` explicitly in terms of `delta`.

By minimality,

\[
\frac\delta2<\lambda_{m-1}.
\]

Using the elementary upper bound (4.3) at `m-1`,

\[
\frac\delta2
<\frac{4\pi^2}{(2m-1)^2}.
\]

Thus

\[
2m-1<\frac{2\sqrt2\pi}{\sqrt\delta},
\]

hence

\[
2m+1<\frac{2\sqrt2\pi}{\sqrt\delta}+2.
\]

Since

\[
\frac1{2^{2m+1}-1}>2^{-(2m+1)},
\]

we obtain

\[
\boxed{
\tau(R_-)
>
\frac9{100}\delta^2
2^{-\,2\sqrt2\pi/\sqrt\delta-2},
\qquad 0<\delta<8.
}
\tag{5.8}
\]

For `delta>=8`, the first atom has mass at least `1/(2^3-1)=1/7`, so

\[
\boxed{
\tau(R_-)
\ge\frac{4(\delta-4)}7.
}
\tag{5.9}
\]

This completes P60A.

# 6. Proof of `P01-P60B-GLSZ-FUNCTIONAL-CALCULUS-HALF-BARRIER`

Let

\[
P=\mathbf1_{\{0\}}(D)
\]

in `L(G)`. Because `tau(P)=1/3`, `P` is nonzero.

Take any

\[
f\in C(\sigma(D))
\]

and set

\[
c=f(0).
\]

On the kernel of `D`, the operator `f(D)-P` acts as the scalar

\[
c-1.
\]

Therefore

\[
\|f(D)-P\|\ge|c-1|.
\tag{6.1}
\]

On the positive eigenspace corresponding to `lambda_n`, `P` vanishes and `f(D)` acts as `f(lambda_n)`. Hence

\[
\|f(D)-P\|
\ge|f(\lambda_n)|
\]

for every `n`. Since

\[
\lambda_n\to0
\]

and `f` is continuous,

\[
|f(\lambda_n)|\to|f(0)|=|c|.
\]

Thus

\[
\|f(D)-P\|\ge|c|.
\tag{6.2}
\]

Combining (6.1) and (6.2),

\[
\boxed{
\|f(D)-P\|
\ge\max\{|c|,|1-c|\}.
}
\tag{6.3}
\]

For any complex number `c`,

\[
\max\{|c|,|1-c|\}\ge\frac12
\]

by the triangle inequality `1<=|c|+|1-c|`. Therefore

\[
\|f(D)-P\|\ge\frac12.
\]

The constant function `f=1/2` gives

\[
\left\|\frac12I-P\right\|=\frac12,
\]

because `P` is a nontrivial projection. Hence

\[
\boxed{
\operatorname{dist}(P,C^*(D,1))=\frac12.
}
\tag{6.4}
\]

If in addition `f(0)=1`, then `c=1` and (6.3) gives

\[
\boxed{
\|f(D)-P\|\ge1.
}
\tag{6.5}
\]

The constant function `f=1` attains equality.

## 6.1 Spectral-correction corollary

Suppose `q` is a real polynomial intended as an almost-projection cutoff with kernel value

\[
q(0)>\frac12.
\]

Continuity and `lambda_n->0` imply

\[

\]

# 7. Proof of `P01-P60C-GLSZ-HEAT-RESOLVENT-MAXIMAL-NORM-FAILURE`

Fix `t>0`.

On `ker D`,

\[
e^{-tD}-P=0.
\]

On the positive eigenspace at `lambda_n`, it acts by

\[
e^{-t\lambda_n}.
\]

Since `lambda_n->0`,

\[
e^{-t\lambda_n}\to1.
\]

Therefore

\[
\|e^{-tD}-P\|
\ge\sup_n e^{-t\lambda_n}=1.
\]

On the other hand, the scalar multiplier is between `0` and `1` on the positive spectrum and zero on the kernel difference, so the norm is at most `1`. Hence

\[
\boxed{
\|e^{-tD}-P\|=1
\quad\text{for every finite }t>0.
}
\tag{7.1}
\]

Now fix `eta>0`. On the kernel,

\[
\eta(D+\eta I)^{-1}-P=0.
\]

On the positive eigenspace at `lambda_n`, the scalar value is

\[
\frac{\eta}{\lambda_n+\eta}.
\]

As `n->infinity`, this tends to `1`. Again all such values lie in `(0,1)`, so

\[
\boxed{
\|\eta(D+\eta I)^{-1}-P\|=1
\quad\text{for every }\eta>0.
}
\tag{7.2}
\]

Thus neither family converges to `P` in operator norm at all. The failure is not a poor rate; the error is identically maximal.

This exactly complements the spectral-stability seed:

No marked-group approximation theorem can bridge these cases without adding a genuine gap or an equally strong class-sensitive substitute.

## 9.2 Independence occurs only after conditioning

The copied-column matrices are
