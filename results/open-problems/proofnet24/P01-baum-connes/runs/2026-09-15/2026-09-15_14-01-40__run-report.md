# 0. Executive status

The original target remains **OPEN**:

\[
\mu_i^G:K_i^{\mathrm{top}}(G)\longrightarrow K_i(C_r^*(G)),\qquad i=0,1,
\]

for every second-countable locally compact group `G`.

Nothing in this run proves a reduction from that full scope to discrete groups. The new theorem below is deliberately restricted to one finitely generated discrete marked family.

## Strongest new result

This run proves a genuine **matrix-stable upper reduced-norm comparison** on the nonamenable family

\[
G_L=C_L*\mathbb Z=\langle a,b\mid a^L=1\rangle
\longrightarrow
F_2=\langle a,b\rangle.
\]

This was the exact next test family isolated by current P25.

For an `M_n`-valued group-ring element `X` supported in the word ball of radius `R` in `F_2`, let `X_L` be the coefficientwise quotient evaluation in `C_r^*(G_L)`. If `L>=8R+1`, then

\[
\boxed{
\|X_L\|
\le
\Gamma(R,L)\,\|X\|,
}
\tag{0.1}
\]

uniformly in the matrix size `n`, where

\[
\boxed{
\Gamma(R,L)
=
\exp\!\left[
\frac{4R}{L-1}
\left(
\log 13+3\log\frac{L-1}{2}
\right)
\right].
}
\tag{0.2}
\]

Consequently

\[
\boxed{
R_L\log L/L\to0
\quad\Longrightarrow\quad
\Gamma(R_L,L)\to1.
}
\tag{0.3}
\]

This is `P01-P40B-POWER-AMPLIFIED-UPPER-NORM` below. It is obtained from a completely bounded fixed-radius reduced-free-product comparison (`P01-P40A`) plus the C*-power trick.

Thus route (b) has crossed an important gate in a concrete genuinely nonamenable approximation: **marked convergence alone does not give upper norm control, but reduced-free-product Khintchine theory does give it here, with an explicit cb modulus.**

This does **not** prove scalar Baum–Connes. The remaining obstruction is now more precise: the source relation scale and target K-equivalence/nullhomotopy propagation for the classes used in an assembly argument must stay in the regime

\[
R_L=o(L/\log L)
\]

(or another regime for which a stronger norm estimate is proved). Current cyclic P25 examples show that arbitrary relations can cost `Theta(L)`, so class-sensitive control remains indispensable.

## 2.1 Li–Nowak–Pooya — exact scalar trace-range theorem

Primary source:

Kang Li, Piotr W. Nowak, Sanaz Pooya, *Higher Kazhdan projections, `ell_2`-Betti numbers and Baum–Connes conjectures*, J. Noncommut. Geom. 18 (2024), 313–336, DOI `10.4171/JNCG/529`.

Current EMS article:

`https://ems.press/journals/jncg/articles/12879482`

Current EMS PDF:

`https://ems.press/content/serial-article-files/42627`

The exact chain in the published paper is:

- type `F_{n+1}` provides a finite degree-`n` cochain matrix;
- a spectral gap means **zero isolated in the reduced spectrum** of the cohomological Laplacian in `M_k(C_r^*(G))`;
- Proposition 7 identifies the trace of the reduced higher Kazhdan projection with `beta_n^(2)(G)`;
- Theorem 9 quotes Lück's trace theorem: the trace of a scalar assembly class belongs to `Lambda_G`, the subring of `Q` generated by inverses of orders of finite subgroups;
- Proposition 1: if `G` is type `F_{n+1}`, the reduced degree-`n` Laplacian is gapped, and the **coefficient-free** degree-zero assembly map is surjective, then

\[
\beta_n^{(2)}(G)\in\Lambda_G,
\]

and in particular is integral for torsion-free `G`.

No arbitrary-coefficient Baum–Connes statement is substituted here.

The distinction preserved throughout P01 is therefore:

- finite type is needed to obtain the finite cohomological matrix from a finite skeleton;
- an independently supplied finite group-ring matrix does **not** need type `F_{n+1}`;
- a von Neumann kernel projection is not automatically a reduced-C* projection;
- an irrational/transcendental von Neumann dimension by itself is not a scalar Baum–Connes counterexample.

# 3. Spectral-stability seed rederived

Let `A>=0` in a unital matrix C*-algebra and assume

\[
\sigma(A)\subset\{0\}\cup[\delta,M],\qquad \delta>0.
\]

Then the characteristic function of `{0}` is continuous on `sigma(A)`, so

\[
P_A=\mathbf 1_{\{0\}}(A)
\]

belongs to the C*-algebra.

For `t>0`, functional calculus gives

\[
\boxed{
\|e^{-tA}-P_A\|\le e^{-t\delta}.
}
\tag{3.1}
\]

For `eta>0`,

\[
\boxed{
\|\eta(A+\eta I)^{-1}-P_A\|
\le
\frac{\eta}{\delta+\eta}.
}
\tag{3.2}
\]

Now let positive `A,B` both have the same gap `delta` and kernel projections `P_A,P_B`. Define the bounded pseudoinverse

\[
A^\dagger(0)=0,\qquad A^\dagger(t)=t^{-1}\quad(t\ge\delta).
\]

Since `BP_B=0`,

\[
(1-P_A)P_B
=A^\dagger AP_B
=A^\dagger(A-B)P_B,
\]

hence

\[
\|(1-P_A)P_B\|
\le
\frac{\|A-B\|}{\delta}.
\]

Interchanging `A,B` gives

\[
\|(1-P_B)P_A\|
\le
\frac{\|A-B\|}{\delta}.
\]

The two-projection identity

\[
\|P_A-P_B\|
=
\max\{\|(1-P_A)P_B\|,\|(1-P_B)P_A\|\}
\]

gives the sharper estimate

\[
\boxed{
\|P_A-P_B\|
\le
\frac{\|A-B\|}{\delta}.
}
\tag{3.3}
\]

Therefore the requested bound `2||A-B||/delta` is valid but nonsharp.

The common positive gap is essential. If `B=A+epsilon I`, a kernel of `A` disappears although `||A-B||=epsilon`; allowing the positive gap to collapse destroys projection stability.

# 4. `P01-P40A-RX-FREE-PRODUCT-CB-BASE` — PROVED

## Statement

Let

\[
G_\infty=F_2=\langle a,b\rangle,
\qquad
G_L=C_L*\mathbb Z=\langle a,b\mid a^L=1\rangle.
\]

Let

\[
X=\sum_{|g|\le R}A_g\otimes\lambda_{G_\infty}(g)
\in M_n(C_r^*(G_\infty))
\]

be any matrix-valued group-ring element supported in the standard word ball of radius `R`. Assume

\[
2R<L.
\]

Let

\[
X_L=\sum_{|g|\le R}A_g\otimes\lambda_{G_L}(\bar g)
\in M_n(C_r^*(G_L))
\]

be its coefficientwise quotient evaluation.

Then, uniformly in `n`,

\[
\boxed{
\|X_L\|
\le
A_R\|X\|,
}
\tag{4.1}
\]

where

\[
\boxed{
A_R
=1+\sum_{d=1}^{R}4d(2d+1)
=1+\frac{R(R+1)(8R+10)}3.
}
\tag{4.2}
\]

In particular `A_R<=13R^3` for every integer `R>=1`.

This is a **completely bounded** local estimate: the same constant works at every matrix size.

## Proof

### Step 1: reduced-free-product descriptions

With canonical traces,

\[
C_r^*(F_2)
\cong
(C_r^*(\mathbb Z),\tau)*_{\rm red}(C_r^*(\mathbb Z),\tau),
\]

and

\[
C_r^*(C_L*\mathbb Z)
\cong
(C_r^*(C_L),\tau_L)*_{\rm red}(C_r^*(\mathbb Z),\tau).
\]

Write the first factors as

\[
A_\infty=C(\mathbb T),
\qquad
A_L=C(\Omega_L),
\]

where `Omega_L` is the set of `L`-th roots of unity.

The first-factor quotient is restriction

\[
q_L:C(\mathbb T)\to C(\Omega_L),
\qquad
q_L(z^k)=a^k.
\]

Globally this map does **not** preserve the canonical traces, so we do not invoke free-product functoriality from a state-preserving map.

### Step 2: local first-factor geometry

Let

\[
V_R^\infty
=\operatorname{span}\{z^k:0<|k|\le R\}
\subset\ker\tau,
\]

and

\[
V_R^L
=\operatorname{span}\{a^k:0<|k|\le R\}
\subset\ker\tau_L.
\]

Because `q_L` is a *-homomorphism, its restriction is a complete contraction in C*-norm.

Because `2R<L`, for `|k|,|ell|<=R`,

\[
\tau_L((a^k)^*a^\ell)
=\delta_{k\ell}
=\tau((z^k)^*z^\ell).
\]

Thus

\[
q_L:V_R^\infty\to V_R^L
\]

is an isometry on the GNS Hilbert spaces. Since the traces are tracial, the same is true for the opposite GNS Hilbert spaces.

The second free-product factor is unchanged and is treated by the identity map.

### Step 3: transfer on Ricard–Xu `E_d`

Decompose `X` by free-product syllable length:

\[
X=\sum_{d=0}^{R}X_d.
\]

Every first-factor letter occurring in every `X_d` belongs to `V_R^\infty`, because the original group word length is at most `R`.

Ricard–Xu's operator space `E_d` is an `ell_infty` sum of Haagerup tensor products involving:

- column GNS Hilbert spaces;
- row/opposite GNS Hilbert spaces;
- in the diagonal terms, at most one factor carrying the original C*-operator-space norm.

On the local letters, `q_L` is an isometry on the row/column Hilbert factors and a complete contraction on the C*-factor. Functoriality of the Haagerup tensor product therefore gives a complete contraction

\[
E_{d,\infty}^{\rm local}\to E_{d,L}^{\rm local}.
\]

Hence

\[
\|X_{d,L}\|_{E_{d,L}}
\le
\|X_d\|_{E_{d,\infty}}.
\tag{4.3}
\]

### Step 4: homogeneous reduced norms

By Ricard–Xu Theorem 2.5,

\[
\|X_{d,L}\|
\le
(2d+1)\|X_{d,L}\|_{E_{d,L}}
\le
(2d+1)\|X_d\|_{E_{d,\infty}}
\le
(2d+1)\|X_d\|.
\tag{4.4}
\]

For `d>=1`, Ricard–Xu Corollary 3.3 gives

\[
\|X_d\|
=\|P_dX\|
\le
4d\|X\|.
\tag{4.5}
\]

For `d=0`, the scalar expectation satisfies

\[
\|X_0\|\le\|X\|.
\]

Summing (4.4) over `d` yields

\[
\|X_L\|
\le
\left(1+\sum_{d=1}^{R}4d(2d+1)\right)\|X\|,
\]

which is (4.1)–(4.2).

Every ingredient is completely bounded with the displayed constant, so the proof is uniform in matrix size. QED.

## Categorical check

No map

\[
C_r^*(F_2)\to C_r^*(C_L*\mathbb Z)
\]

is asserted. The group quotient has nonamenable kernel, and global reduced functoriality is not available. The theorem is only a finite-propagation coefficient comparison, proved directly from reduced-free-product operator-space estimates.

# 5. `P01-P40B-POWER-AMPLIFIED-UPPER-NORM` — PROVED

The polynomial constant in P40A can be amplified to a near-contractive estimate by the C*-power trick.

## Statement

In the setting of P40A, assume

\[
L\ge8R+1.
\]

Then for every matrix size `n` and every `X` supported in the radius-`R` word ball,

\[
\boxed{
\|X_L\|
\le
\Gamma(R,L)\|X\|,
}
\tag{5.1}
\]

where

\[
\boxed{
\Gamma(R,L)
=
\exp\!\left[
\frac{4R}{L-1}
\left(
\log 13+3\log\frac{L-1}{2}
\right)
\right].
}
\tag{5.2}
\]

Consequently, for any integer sequence `R=R_L` satisfying

\[
\boxed{
R_L\log L/L\to0,
}
\tag{5.3}
\]

we have the matrix-stable asymptotic upper norm bound

\[
\boxed{
\sup_{n\ge1}
\sup_{0\ne X\in M_n(\mathbb CF_2),\ \operatorname{prop}(X)\le R_L}
\frac{\|X_L\|}{\|X\|}
\le1+o(1).
}
\tag{5.4}
\]

## Proof

Choose

\[
m=\left\lfloor\frac{L-1}{4R}\right\rfloor.
\]

Since `L>=8R+1`,

\[
m\ge\frac{L-1}{8R}.
\tag{5.5}
\]

Set

\[
Y=(X^*X)^m.
\]

Then `Y` has word support radius at most

\[
S=2mR,
\]

and

\[
2S=4mR\le L-1<L.
\]

Therefore P40A applies to `Y` with radius `S`.

The algebraic group quotient respects multiplication, so exactly

\[
Y_L=(X_L^*X_L)^m.
\]

Hence

\[
\|X_L\|^{2m}
=\|Y_L\|
\le
A_S\|Y\|
=A_S\|X\|^{2m}.
\]

Thus

\[
\|X_L\|
\le
A_S^{1/(2m)}\|X\|.
\tag{5.6}
\]

For `S>=1`, the exact formula (4.2) gives

\[
A_S\le13S^3.
\tag{5.7}
\]

Also

\[
S=2mR\le\frac{L-1}{2}.
\]

Using (5.5),

\[
\frac1{2m}\le\frac{4R}{L-1}.
\]

Substituting these estimates into (5.6) gives exactly (5.1)–(5.2).

Finally,

\[
\log\Gamma(R_L,L)
\le
C\frac{R_L\log L}{L}
\]

for an absolute `C`, so (5.3) implies (5.4). QED.

## Why this matters

This is the first P01 theorem in the canonical sequence that supplies a **genuinely quantitative upper reduced operator-norm theorem across a nonamenable marked approximation**, rather than treating local/strong convergence as though it implied one.

The theorem is matrix-stable and therefore has the right formal strength for quantitative K-theory defects.

## Why it is not enough

The modulus only becomes asymptotically contractive in the sublinear regime

\[
R=o(L/\log L).
\]

Current P25 cyclic results show that some K-relations genuinely require propagation `Theta(L)`. Therefore P40B does not by itself transport arbitrary ordinary K-theory relations or prove Baum–Connes permanence.

# 6. `P01-P40C-CONTROLLED-K-DEFECT-TRANSFER` — PROVED

P40B can be inserted directly into the controlled-K framework developed in P01-P33/P25.

Let `U_t` be a stabilized path of `epsilon`-unitaries in `M_n(C_r^*(F_2))` with propagation at most `R` for all `t`. Then each unitary defect

\[
U_t^*U_t-I,
\qquad
U_tU_t^*-I
\]

has propagation at most `2R`.

If

\[
L\ge16R+1,
\]

P40B with defect radius `2R` yields

\[
\boxed{
\|U_{t,L}^*U_{t,L}-I\|
\le
\Gamma(2R,L)\,\epsilon,
}
\tag{6.1}
\]

and likewise for the other defect, uniformly in `t` and in the stabilization size.

Therefore, if

\[
\boxed{
\Gamma(2R,L)\epsilon<1,
}
\tag{6.2}
\]

polar correction turns the transferred path into a genuine stable unitary homotopy in `C_r^*(G_L)`.

Similarly, if `p_t=p_t^*` is an `epsilon`-projection path of propagation at most `R`, then its defect has radius at most `2R`, and

\[
\boxed{
\Gamma(2R,L)\epsilon<\frac14
}
\tag{6.3}
\]

allows spectral rounding at `1/2` after transfer.

Thus P40B supplies exactly the upper-norm factor `alpha` required abstractly by `P01-P33B`, now on one genuinely nonamenable family with an explicit asymptotic modulus.

# 7. `P01-P40D-GAPPED-POLYNOMIAL-PROJECTION-TRANSFER` — PROVED

This connects P40 to the finite-matrix/spectral route.

Let a fixed formal positive matrix `D` over `CF_2` have support radius `rho` and suppose its reduced evaluation `D_infty` satisfies

\[
\sigma(D_\infty)\subset\{0\}\cup[\delta,M].
\]

Let `p_N` be the P38 minimax Chebyshev cutoff, so

\[
p_N(0)=1,
\qquad
E_N:=\sup_{x\in[\delta,M]}|p_N(x)|
=
\operatorname{sech}\!\left(
2N\operatorname{artanh}\sqrt{\delta/M}
\right).
\]

Then

\[
\|p_N(D_\infty)-P_\infty\|\le E_N,
\]

where `P_infty=1_{0}(D_infty)`, and

\[
\|p_N(D_\infty)^2-p_N(D_\infty)\|
\le E_N(1+E_N).
\tag{7.1}
\]

The formal defect polynomial has support radius at most

\[
R_{\rm def}=2N\rho.
\]

Whenever

\[
L\ge8R_{\rm def}+1,
\]

P40B gives

\[
\boxed{
\|p_N(D_L)^2-p_N(D_L)\|
\le
\Gamma(R_{\rm def},L)E_N(1+E_N).
}
\tag{7.2}
\]

If the right side is `<1/4`, then spectral cutoff at `1/2` produces an actual projection

\[
Q_{N,L}
=\mathbf1_{[1/2,\infty)}(p_N(D_L))
\in M_k(C_r^*(G_L)).
\]

No spectral gap for `D_L` is assumed.

This is a real reduced-C* statement, not a von Neumann-only construction. It shows that on the free-product test family the combination

\[
\text{limit gap}
+\text{P38 optimal finite-propagation cutoff}
+\text{P40 upper norm}
\]

produces honest stage reduced-C* projection classes whenever the quantitative budget closes.

What it does **not** prove is that `Q_{N,L}` equals the kernel projection of `D_L`; the stage may remain gapless at zero. It is a rounded polynomial projection representing the transferred controlled K-class.
