# 0. Executive result

The original problem remains **OPEN**:

\[
\mu_i^G:K_i^{\mathrm{top}}(G)\longrightarrow K_i(C_r^*(G)),\qquad i=0,1,
\]

for every second-countable locally compact group `G`.

This run neither proves the conjecture nor gives a scalar counterexample. It proves a new **two-degree non-uniformity theorem** for the coefficient-free source side of assembly. The point is not to narrow the original scope to discrete groups: finitely generated discrete groups are a subclass of second-countable locally compact groups, so any universal controlled proof has to survive the obstruction below.

For a finitely generated discrete group `Gamma`, let

\[
\mu_{i}^{\Gamma,d}:K_i^\Gamma(P_d\Gamma)\to K_i(C_r^*(\Gamma))
\]

be the ordinary **scalar** assembly map at Rips scale `d`, and let

\[
q_{d,D,*}:K_i^\Gamma(P_d\Gamma)\to K_i^\Gamma(P_D\Gamma)
\]

be the source structure map. For integer scales define the scalar finite-Rips injectivity modulus

\[
\boxed{
\mathfrak I_i(\Gamma;d)
:=
\inf\Bigl\{D\in\mathbb N:\ D\ge d,\
\ker\mu_i^{\Gamma,d}\subseteq\ker q_{d,D,*}\Bigr\}
\in\mathbb N\cup\{\infty\}.
}
\tag{0.1}
\]

The new package is:

## `P01-P48A-CYCLIC-K1-INJECTIVITY-ESCAPE` — **PROVED**

For every `L>=4`, let `C_L=<a | a^L=e>` and let `x_{L,1}` be the scale-one quotient-circle class from P18. Since

\[
K_1(C_r^*(C_L))=0,
\]

we have

\[
\mu_1^{C_L,1}(x_{L,1})=0.
\]

P18's exact source barcode gives the first death scale `kappa_L` of this class. Therefore

\[
\boxed{
\mathfrak I_1(C_L;1)\ge \kappa_L.
}
\tag{0.2}
\]

Explicitly,

\[
\boxed{
\kappa_L=L/2\quad(L\text{ even}),
}
\tag{0.3}
\]

and, if `L` is odd with

\[
L=\prod_j p_j^{a_j},\qquad P(L)=\max_j p_j^{a_j},
\]

then

\[
\boxed{
\kappa_L=\frac{P(L)-1}{2P(L)}L.
}
\tag{0.4}
\]

In particular, along even `L`,

\[
\mathfrak I_1(C_L;1)\ge L/2\to\infty.
\tag{0.5}
\]

Every `C_L` is finite, hence its coefficient-free Baum–Connes assembly map is an isomorphism. Thus finite-Rips injectivity control in degree one is already non-uniform on **finite Baum–Connes-positive groups**.

## `P01-P48B-TRIANGULAR-K0-INJECTIVITY-ESCAPE` — **PROVED**

Fix `m>=2` and the triangular cyclic-filling groups `Gamma_{m,L}` from P25/P47. Let

\[
B_m=\frac{m^{m-1}}{(m-1)!},
\qquad
K_{\rm PV}=183600000000,
\]

and, at tolerance `epsilon_0=1/64`, let

\[
\kappa_{\rm asm}:=k_{J,\epsilon_0/\alpha_J}
\]

be the universal quantitative-assembly propagation coefficient of Oyono-Oyono–Yu. No useful numerical value of `kappa_asm` is claimed; only its finiteness is used. Define

\[
\boxed{
C_m
=
\frac{1}{\kappa_{\rm asm}K_{\rm PV}(400B_m)^{1/m}}.
}
\tag{0.6}
\]

The current P25 source Bott class

\[
z_{m,L}\in K_0^{\Gamma_{m,L}}(P_2\Gamma_{m,L})
\]

satisfies

\[
\mu_0^{\Gamma_{m,L},2}(z_{m,L})=0
\]

but has first source death scale `Delta_{m,L}` obeying, for all sufficiently large `L`,

\[
\Delta_{m,L}
\ge
C_m\left(\frac{L-1}{\log L}\right)^{1/m}.
\tag{0.7}
\]

Hence

\[
\boxed{
\mathfrak I_0(\Gamma_{m,L};2)
\ge
C_m\left(\frac{L-1}{\log L}\right)^{1/m}.
}
\tag{0.8}
\]

Every `Gamma_{m,L}` is Haagerup and satisfies Baum–Connes with coefficients, hence in particular scalar Baum–Connes. The obstruction is therefore again quantitative non-uniformity **inside a Baum–Connes-positive family**, not failure of assembly.

## `P01-P48C-NO-GROUP-INDEPENDENT-FINITE-RIPS-INJECTIVITY` — **DISPROVES A UNIVERSAL CONTROL SHORTCUT**

There is no group-independent finite source-control function which witnesses scalar assembly injectivity at finite Rips scale in either degree.

More precisely:

1. there is no finite integer `D_1` such that for every finite group `G`
   \[
   \ker\mu_1^{G,1}\subseteq\ker q_{1,D_1,*};
   \]

2. there is no finite integer `D_0` such that for every finitely generated discrete Haagerup group `G`
   \[
   \ker\mu_0^{G,2}\subseteq\ker q_{2,D_0,*}.
   \]

For degree one, given `D_1`, choose an even `L>2D_1`; then `x_{L,1}` has zero scalar assembly but survives to scale `D_1`. For degree zero, given `D_0` and fixed `m>=2`, choose `L` so large that

\[
C_m\left(\frac{L-1}{\log L}\right)^{1/m}>D_0;
\]

then `z_{m,L}` gives the contradiction.

This is a precise failed-route certificate: a universal proof of scalar Baum–Connes cannot be based on a **group-independent bounded Rips enlargement** which turns every finite-scale scalar assembly kernel into zero. Group-dependent geometry/control is unavoidable.

This does **not** contradict Baum–Connes injectivity. Every displayed kernel class dies later in the direct system; the theorem says only that the required death scale is unbounded across groups.

\[
C_r^*(C_L)=C^*(C_L)

\mu_1^{C_L,1}(x_{L,1})=0.

# 6. Mandatory spectral-stability seed rederived

Let `A=A^*>=0` in a unital `C^*`-algebra and assume

\[
\sigma(A)\subset\{0\}\cup[\delta,M],
\qquad 0<\delta\le M.
\tag{6.1}
\]

## 6.1 Kernel projection belongs to the algebra

The subset `{0}` is clopen in `sigma(A)`. Hence the function

\[
f(0)=1,\qquad f(x)=0\quad(x\in[\delta,M])
\]

is continuous on `sigma(A)`. Continuous functional calculus gives

\[
\boxed{P_A=\mathbf1_{\{0\}}(A)=f(A)\in C^*(A).}
\tag{6.2}
\]

This is a **reduced-`C^*` projection** when `A` belongs to a reduced group `C^*`-algebra. It must not be confused with a von-Neumann spectral projection that exists without a reduced gap.

## 6.2 Heat cutoff

At `x=0`,

\[
e^{-tx}-\mathbf1_{\{0\}}(x)=0.
\]

For `x>=delta`,

\[
|e^{-tx}|\le e^{-t\delta}.
\]

Therefore

\[
\boxed{
\|e^{-tA}-P_A\|\le e^{-t\delta}.
}
\tag{6.3}
\]

## 6.3 Resolvent cutoff

For `eta>0`, define

\[
g_\eta(x)=\frac{\eta}{x+\eta}.
\]

Then `g_eta(0)=1`, while on `[delta,M]`

\[
0\le g_\eta(x)\le\frac{\eta}{\delta+\eta}.
\]

Hence

\[
\boxed{
\|\eta(A+\eta I)^{-1}-P_A\|
\le
\frac{\eta}{\delta+\eta}.
}
\tag{6.4}
\]

## 6.4 Two operators with a common positive gap

Let `A,B>=0` and assume

\[
\sigma(A),\sigma(B)\subset\{0\}\cup[\delta,\infty).
\]

Let `P_A,P_B` be their kernel projections. Define the bounded pseudoinverse

\[
A^\dagger=h(A),\qquad
h(0)=0,\quad h(x)=x^{-1}\ (x\ge\delta).
\]

Then

\[
\|A^\dagger\|\le\delta^{-1}
\]

and, because `BP_B=0`,

\[
(1-P_A)P_B
=A^\dagger A P_B
=A^\dagger(A-B)P_B.
\]

Therefore

\[
\|(1-P_A)P_B\|
\le\frac{\|A-B\|}{\delta}.
\tag{6.5}
\]

Interchanging `A,B` gives

\[
\|P_A(1-P_B)\|
\le\frac{\|A-B\|}{\delta}.
\tag{6.6}
\]

For orthogonal projections,

\[
\|P_A-P_B\|
=
\max\{\|(1-P_A)P_B\|,\|P_A(1-P_B)\|\}.
\]

Thus in fact

\[
\boxed{
\|P_A-P_B\|
\le
\frac{\|A-B\|}{\delta}.
}
\tag{6.7}
\]

The requested estimate

\[
\|P_A-P_B\|\le2\|A-B\|/\delta
\]

is therefore valid but nonsharp.

## 6.5 Shrinking-gap failure

Take

\[
A=\begin{pmatrix}0&0\\0&1\end{pmatrix},
\qquad
B_\varepsilon=A+\varepsilon I.
\]

Then

\[
\|A-B_\varepsilon\|=\varepsilon\to0,
\]

but

\[
P_A=\begin{pmatrix}1&0\\0&0\end{pmatrix},
\qquad
P_{B_\varepsilon}=0.
\]

The positive spectral gap of `B_epsilon` is only `epsilon`, so there is no common uniform `delta`. This is exactly why norm convergence alone cannot be substituted for a verified uniform-gap theorem in group approximations.

# 9. Independent kernel operator-norm / decoupling audit

## `AUDIT_FOR=P04` — current Target-2 dependency subchain

The latest P04 report records `P22-T2-RECHECK-34: PASS`. I checked the delicate dependency order against the primary paper instead of accepting that status.

Primary source:

**A general technique for approximating high-dimensional empirical kernel matrices**,

### 9.1 Decoupling really comes first

The proof writes the off-diagonal kernel matrix `Delta` as a matrix-valued U-statistic and introduces the decoupled copy `tilde Delta`. The stated decoupling inequality is

\[
\boxed{
\mathbb E\|\Delta\|
\le
8\,\mathbb E\|\widetilde\Delta\|.
}
\tag{9.1}
\]

Only **after** this step does the proof condition on the original sample `(x_1,...,x_n)`.

### 9.2 Independence is conditional, not unconditional

After conditioning, the decoupled matrix is written

\[
\widetilde\Delta=\sum_{j=1}^n Z_j,
\]

and the paper explicitly observes that the matrices `Z_j` are independent **conditioned on the original sample**. Noncommutative Khintchine is applied only at that point.

Thus the dependency order used by P22/P04 is correct:

\[
\boxed{
\text{U-statistic decoupling}
\to
\text{condition on original sample}
\to
\text{conditional independence}
\to
\text{NCK}.
}
\tag{9.2}
\]

Using NCK before conditioning would be unjustified; the primary proof does not do so.

### 9.3 Exact variance proxy retains both terms

For the centered correlation kernel matrix `bar G`, the primary proof obtains

\[
\boxed{
V
=
\frac14\left\|
\sum_{j=1}^n
\left(
\bar G_{\setminus j}
+
\sum_{i\ne j}\bar G_{ii}e_je_j^T
\right)
\right\|.
}
\tag{9.3}
\]

So before coarse relaxation the variance term genuinely contains both

- the leave-one-out correlation matrices `bar G_{\setminus j}`;
- the diagonal row-sum contribution.

The factor `1/4` is also present. The current P04/P22 dependency bookkeeping is consistent with the source.

### 9.4 Growing-degree arithmetic rechecked

The current P22 scaling is

\[
R=2^\ell,\qquad d=2^R,\qquad n=d^R,\qquad k=R+\ell-1.
\]

For the two conservative error terms,

\[
E_1=dR\frac{3^k}{\sqrt n},
\qquad
E_2=Rd^2\frac{(2R)^k}{n},
\]

compute in base `d`:

\[
\log_d E_1
=
1+\log_dR+k\log_d3-\frac R2.
\]

Since

\[
\log_d3=\frac{\log_2 3}{R},
\]

we get

\[
\boxed{\log_d E_1=-R/2+O(1),}
\]

hence `E_1->0`.

Likewise,

\[
\log_d E_2
=
\log_dR+2+k\log_d(2R)-R,
\]

and

\[
\log_d(2R)=\frac{\ell+1}{R},
\]

so

\[
\boxed{\log_d E_2=-R+\ell+O(1),}
\]

hence `E_2->0`.

**Audit verdict:** **PASS for the operator-norm/decoupling/growing-degree subchain.** This is intentionally not a new blanket end-to-end certification of every P04 Target-2 dependency.

# 10. What P48 changes in the P01 proof program

P47 and P25 have progressively localized the proof-side obstruction:

1. fixed finite matrices can have good local reduced-norm and even fixed-matrix spectral behavior;
2. the triangular families have two-sided cb local norm control on a subcritical window;
3. target null relations can be forced to the boundary of that window;
4. P25 now shows that the **scalar topological source class itself** can require a much larger Rips scale before its zero assembly image is visible as a source relation.

P48 converts item 4 into a universal no-go theorem for group-independent finite-Rips injectivity control.

This is stronger than saying “a particular controlled theorem has bad constants.” In degree one, the obstruction is already linear and occurs for finite cyclic groups:

\[
\mathfrak I_1(C_L;1)\ge L/2
\]

along even `L`.

In degree zero, it occurs in a nonamenable Haagerup family:

\[
\mathfrak I_0(\Gamma_{m,L};2)
\gtrsim_m
\left(\frac{L}{\log L}\right)^{1/m}.
\]

Therefore a universal scalar proof by controlled K-theory must be formulated with **group-dependent** control data. A single scale-enlargement function of `(d,i)` cannot encode scalar injectivity for all groups.

This does not weaken the original target. It removes one overstrong proof schema and tells the next attack what extra variable must enter: presentation/filling geometry, a quantitative contractibility function, or another group-sensitive source-control invariant.

# 11. Finite matrix / reduced projection / von-Neumann dimension firewall

The following distinctions remain part of the canonical P01 state.

Let

\[
C\in M_{u,v}(\mathbb CG),
\qquad
D=C^*C.
\]

There are three different objects:

1. **finite matrix:** `C` is an algebraic matrix over `CG`;
2. **von-Neumann kernel projection:**
   \[
   P_{\rm vN}=\mathbf1_{\{0\}}(D)\in M_v(LG),
   \]
   always defined by measurable functional calculus;
3. **reduced-`C^*` kernel projection:** the same spectral projection belongs to
   \[
   M_v(C_r^*(G))
   \]
   only when zero is isolated in the reduced spectrum (or by some other direct reduced-`C^*` construction).

The von-Neumann dimension

\[
\dim_{LG}\ker C
=(\operatorname{Tr}\otimes\tau_G)(P_{\rm vN})
\]

is a number. It is not by itself a reduced-`C^*` `K_0` class.

Consequently:

- irrational or transcendental `L^2` dimensions alone do not yield scalar Baum–Connes counterexamples;
- Li–Nowak–Pooya becomes relevant only after a genuine reduced spectral gap creates a reduced-`C^*` projection;
- the previously screened Austin/GLSZ/Grabowski examples on Baum–Connes-positive hosts are necessarily gapless at zero for the offending matrix.

This firewall is unchanged by P48.

# 12. Failed routes — cumulative record

The following shortcuts remain **DISPROVED / CLOSED** and must not be reused.

1. **Infinite trace-convergent sums of finite-subgroup projections.** Trace convergence does not imply norm convergence of a sum of nonzero projections, so it does not manufacture an element of `C_r^*(G)\otimes K`.

2. **Irrational `L^2`-Betti number alone.** A von-Neumann dimension is not a reduced-`C^*` projection or `K_0` class.

3. **Reduced quotient functoriality from an algebraic quotient.** A quotient `G->G/N` gives a reduced `C^*` map only under the required weak containment; for the canonical quotient representation this is tied to amenability of the kernel. P47 supplies a concrete nonamenable-kernel family where no reduced quotient map exists.

4. **Marked/strong convergence implies upper reduced norm control.** It does not. The local cb estimates in P40/P25 require actual proof.

5. **Embedding implies spectral gap.** It does not isolate zero.

6. **Short controlled representative implies short relation.** P47 gives an assembled Bott class with a fixed short representative but boundary-scale null relations.

7. **Baum–Connes on both quotient endpoints restores a reduced quotient map.** P47C disproves this.

8. **Group-independent finite-Rips injectivity control.** **Newly closed by P48:** even among finite groups in degree one, and among Haagerup groups in degree zero, the finite source death scale is unbounded.

9. **Trace mesh alone forces a kernel identification.** A mesh requires a quantitative norm/trace transport channel; this was isolated in P45.

10. **Hausdorff spectral convergence alone preserves a positive gap above a nonzero kernel.** Vanishing-mass spectral points may approach zero; P42/P43 require rank/trace locking to identify the true kernel.

# 14. Remaining obligations and next concrete attack

The universal conjecture is not closed, so the schedule must continue.

## 14.1 Proof-side next attack: `P01-GROUP-DEPENDENT-SOURCE-CONTROL-49`

P48 proves that a universal finite scale `D(d)` is impossible. The next useful theorem should introduce a **group-sensitive** source injectivity modulus and connect it to a concrete geometric invariant.

A focused target is:

> For a finitely generated discrete `G`, bound
> \[
> \mathfrak I_i(G;d)
> \]
> in terms of an explicit filling/contractibility function of the Rips complexes or a presentation-scale invariant, then compare that bound with the matrix-stable upper reduced-norm window available for the same family.

The triangular family is the calibration test. Any proposed invariant must reproduce at least

\[
\mathfrak I_0(\Gamma_{m,L};2)
\gtrsim
(L/\log L)^{1/m},
\]

while the cyclic degree-one family forces linear behavior at scale one.

If such a group-dependent modulus can be transported under a verified permanence theorem, it could replace the invalid uniform-QI shortcut. If not, the failure should be turned into another exact certificate.

## 14.2 Counterexample-side next attack

Continue to exclude Baum–Connes-positive exotic-dimension hosts before attempting a gap proof. The live route remains:

1. choose a genuinely coupled finite differential / mapping-cone matrix over a group whose scalar assembly surjectivity is not already known;
2. prove a **reduced** positive gap by an independent analytic/cohomological certificate;
3. compute the true reduced kernel projection trace/class and compare with the allowed scalar assembly trace range.

Finite matrices, reduced-`C^*` projections, and von-Neumann dimensions must remain distinct at every step.

## 14.3 Locally compact scope

Nothing proved here promotes the discrete approximation theorems to arbitrary second-countable locally compact groups. A full solution still needs either a genuinely locally compact theorem or a valid reduction/permanence theorem. No such bridge is claimed.

# 16. Bottom line

The coefficient-free Baum–Connes problem remains open in the full requested scope. The substantive advance of this run is a rigorous falsification of a natural controlled-K proof schema **in both degrees**:

\[
\boxed{
\text{scalar assembly can be an isomorphism for every group in a family,}
\quad
\text{while finite-Rips injectivity witnesses escape to unbounded scales.}
}
\]

Degree one already has linear escape on finite cyclic groups. Degree zero has certified polynomial/logarithmic escape on the triangular Haagerup family. Consequently, future controlled proofs must carry genuinely group-dependent source-control information; a single group-independent Rips enlargement cannot prove universal scalar injectivity.

The counterexample route remains exactly the legacy finite-matrix route: an actual reduced spectral gap plus a forbidden reduced-`C^*` kernel class/trace, not merely an exotic von-Neumann dimension.
