# 0. Status and strongest new result

The original coefficient-free Baum–Connes problem remains **OPEN**:

\[
\mu_i^G:K_i^{\mathrm{top}}(G)\longrightarrow K_i(C_r^*(G)),\qquad i=0,1,
\]

for every second-countable locally compact group \(G\).

No universal proof and no scalar counterexample is obtained in this run. Every new theorem below is explicitly for countable discrete groups; no reduction of the original locally compact scope is asserted.

The strongest new result is `P01-P39A-SURJECTIVE-BC-FORBIDDEN-KERNEL-GAPLESS`:

> If scalar degree-zero Baum–Connes assembly is surjective for a countable discrete group \(G\), and a finite group-ring matrix \(C\) has von Neumann kernel dimension outside Lück's trace ring \(\Lambda_G\), then its von Neumann kernel projection is **not** a reduced-\(C^*\) projection, zero is **not isolated** in the reduced spectrum of \(C^*C\), and every interval \((0,\eta)\) carries positive canonical spectral mass.

This gives an exact certificate separating a finite matrix / von Neumann kernel dimension from a reduced-\(C^*\) kernel projection.

The theorem has a concrete application to Tim Austin's irrational/transcendental Atiyah examples. Austin constructs a finitely generated group

\[
G_V=(\mathbb Z_2^{\oplus F_2}/V)\rtimes F_2
\]

and a rational group-ring element with transcendental kernel dimension. But \(G_V\) satisfies Baum–Connes **with coefficients**: the normal subgroup \(\mathbb Z_2^{\oplus F_2}/V\) is abelian/amenable, the quotient \(F_2\) satisfies Baum–Connes with coefficients, and Chabert–Echterhoff's amenable-normal-subgroup permanence theorem applies. Therefore Austin's finite matrix is a rigorous **almost-counterexample certificate**:

- finite (indeed scalar) rational/integral group-ring matrix: **YES**;
- kernel trace outside \(\Lambda_G\): **YES**;
- isolated reduced zero: **NO, proved impossible**;
- von Neumann kernel projection in \(C_r^*(G)\): **NO, proved impossible**.

Thus a major historical source of exotic finite-matrix von Neumann dimensions is rigorously screened out from route (a), not merely because no gap has been found, but because a gap would contradict a known Baum–Connes theorem.

# 3. Spectral-stability seed — rederived

Let \(A\ge0\) in a unital matrix C*-algebra and assume

\[
\sigma(A)\subset\{0\}\cup[\delta,M],\qquad\delta>0.
\]

Since \(\{0\}\) is clopen in \(\sigma(A)\), continuous functional calculus gives

\[
P_A=\mathbf1_{\{0\}}(A)
\]

inside the same matrix C*-algebra.

For \(t>0\),

\[
\|e^{-tA}-P_A\|
=
\sup_{\lambda\in\sigma(A)\setminus\{0\}}e^{-t\lambda}
\le e^{-t\delta}.
\]

For \(\eta>0\),

\[
\left\|\eta(A+\eta I)^{-1}-P_A\right\|
=
\sup_{\lambda\in\sigma(A)\setminus\{0\}}
\frac{\eta}{\lambda+\eta}
\le\frac{\eta}{\delta+\eta}.
\]

Now let positive \(A,B\) share the same gap

\[
\sigma(A),\sigma(B)\subset\{0\}\cup[\delta,\infty).
\]

Define the bounded pseudoinverse

\[
A^\dagger(0)=0,
\qquad
A^\dagger(\lambda)=\lambda^{-1}\quad(\lambda\ge\delta).
\]

Since \(BP_B=0\),

\[
AP_B=(A-B)P_B,
\]

so

\[
(1-P_A)P_B=A^\dagger(A-B)P_B
\]

and

\[
\|(1-P_A)P_B\|
\le\frac{\|A-B\|}{\delta}.
\]

Reverse \(A,B\). For orthogonal projections,

\[
\|P_A-P_B\|
=
\max\{\|(1-P_A)P_B\|,\|(1-P_B)P_A\|\},
\]

hence the sharper estimate

\[
\boxed{
\|P_A-P_B\|
\le
\frac{\|A-B\|}{\delta}.
}
\]

The user-requested factor-2 inequality follows, but is nonsharp.

The common gap cannot be dropped. If \(A\) has nonzero kernel and

\[
B=A+\varepsilon I,
\]

then \(\|A-B\|=\varepsilon\) while \(P_B=0\), so the kernel projection can jump by norm one as the positive gap shrinks to zero.

# 4. `P01-P39A-SURJECTIVE-BC-FORBIDDEN-KERNEL-GAPLESS` — PROVED

## Statement

Let \(G\) be a countable discrete group such that the scalar degree-zero assembly map

\[
\mu_0^G:K_0^G(\underline EG)\longrightarrow K_0(C_r^*(G))
\]

is surjective.

Let

\[
C\in M_{a,b}(\mathbb CG)
\]

be any finite group-ring matrix and put

\[
D=C^*C\in M_b(C_r^*(G)).
\]

Let

\[
P_{\rm vN}=\mathbf1_{\{0\}}(D)
\in M_b(LG)
\]

be the von Neumann spectral projection, and set

\[
\alpha
=(\operatorname{Tr}_b\otimes\tau_G)(P_{\rm vN})
=
\dim_{LG}\ker C.
\]

Assume

\[
\boxed{\alpha\notin\Lambda_G.}
\]

Then:

1. \(P_{\rm vN}\notin M_b(C_r^*(G))\);
2. zero is **not isolated** in the reduced spectrum of \(D\);
3. if \(\mu_D\) denotes the spectral measure of \(D\) for the faithful unnormalized matrix trace \(\operatorname{Tr}_b\otimes\tau_G\), then for every \(\eta>0\),
   \[
   \boxed{\mu_D((0,\eta))>0.}
   \]

Thus a forbidden von Neumann kernel dimension on a scalar-BC-surjective group necessarily comes with positive reduced spectrum accumulating at zero.

## Proof

### Step 1 — a reduced kernel projection would violate Lück's trace range

Suppose

\[
P_{\rm vN}\in M_b(C_r^*(G)).
\]

It then defines

\[
[P_{\rm vN}]\in K_0(C_r^*(G)).
\]

By surjectivity of \(\mu_0^G\), this class lies in the scalar assembly image. Lück's modified trace theorem, as quoted as Theorem 9 by Li–Nowak–Pooya, gives

\[
(\operatorname{Tr}_b\otimes\tau_G)_*([P_{\rm vN}])
\in\Lambda_G.
\]

But the left-hand side is exactly \(\alpha\), contradicting the hypothesis.

Therefore

\[
\boxed{P_{\rm vN}\notin M_b(C_r^*(G)).}
\tag{4.1}
\]

This conclusion does not use finite type and does not assume a spectral gap.

### Step 2 — isolated zero would force the projection into the reduced algebra

Because \(\alpha\notin\Lambda_G\) and \(0\in\Lambda_G\), we have \(\alpha>0\), hence \(D\) has nonzero kernel in the left regular representation and

\[
0\in\sigma_{C_r^*(G)}(D).
\]

If zero were isolated in that spectrum, then \(\mathbf1_{\{0\}}\) would be continuous on \(\sigma(D)\). Continuous functional calculus inside \(M_b(C_r^*(G))\) would give

\[
\mathbf1_{\{0\}}(D)=P_{\rm vN}
\in M_b(C_r^*(G)),
\]

contradicting (4.1).

Hence

\[
\boxed{0\text{ is non-isolated in }\sigma_{C_r^*(G)}(D).}
\tag{4.2}
\]

### Step 3 — every positive neighborhood has positive canonical spectral mass

Let

\[
E_D((0,\eta))
\]

be the von Neumann spectral projection. Suppose for some \(\eta>0\) that

\[
\mu_D((0,\eta))
=(\operatorname{Tr}_b\otimes\tau_G)(E_D((0,\eta)))=0.
\]

The canonical trace on \(M_b(LG)\) is faithful, so

\[
E_D((0,\eta))=0.
\]

For a bounded self-adjoint operator, a nonempty open subset of the spectrum has nonzero spectral projection. Therefore

\[
\sigma(D)\cap(0,\eta)=\varnothing.
\]

Since zero is in the spectrum, this would isolate zero, contradicting (4.2).

Thus for every \(\eta>0\),

\[
\boxed{
\mu_D((0,\eta))>0.
}
\tag{4.3}
\]

This completes the proof.

## Categorical significance

The theorem distinguishes all three objects that must not be conflated:

- the **finite matrix** \(C\in M_{a,b}(\mathbb CG)\);
- the **von Neumann kernel projection** \(P_{\rm vN}\in M_b(LG)\);
- an **ordinary reduced-\(C^*\) projection**, which P39A proves cannot equal \(P_{\rm vN}\) when the kernel trace is forbidden and scalar assembly is surjective.

An exotic finite-matrix von Neumann dimension therefore does not by itself threaten scalar Baum–Connes; it must be accompanied by the analytically much stronger isolated-zero property.

# 5. `P01-P39B-AUSTIN-IRRATIONAL-KERNEL-GAPLESS` — PROVED

## Statement

There exists a finitely generated countable discrete group \(G\) and a scalar finite integral group-ring element

\[
C\in\mathbb ZG
\]

such that

\[
\alpha=\dim_{LG}\ker C
\]

is transcendental, while nevertheless:

1. \(G\) satisfies Baum–Connes with coefficients, hence scalar Baum–Connes;
2. the von Neumann kernel projection is not in \(C_r^*(G)\);
3. zero is non-isolated in the reduced spectrum of \(C^*C\);
4. every interval \((0,\eta)\) has positive canonical spectral mass for \(C^*C\).

## Proof

Austin's Corollary 1.2 gives a left-translation-invariant

\[
V\le\mathbb Z_2^{\oplus F_2}
\]

such that

\[
G=(\mathbb Z_2^{\oplus F_2}/V)\rtimes F_2
\]

is finitely generated and admits

\[
Q\in\mathbb QG
\]

with transcendental

\[
\dim_{LG}\ker Q.
\]

Choose a nonzero integer \(m\) clearing denominators and set

\[
C=mQ\in\mathbb ZG.
\]

Then

\[
\ker C=\ker Q,
\]

so the kernel dimension \(\alpha\) remains transcendental.

Now let

\[
U=\mathbb Z_2^{\oplus F_2}/V.
\]

It is an abelian group, hence amenable, and

\[
1\to U\to G\to F_2\to1.
\]

The free group \(F_2\) is hyperbolic and satisfies Baum–Connes with coefficients by Lafforgue. Chabert–Echterhoff's permanence theorem for an amenable normal subgroup therefore gives Baum–Connes with coefficients for \(G\). In particular scalar \(\mu_0^G\) is surjective.

Moreover every finite subgroup \(H<G\) maps to a finite subgroup of the torsion-free quotient \(F_2\), hence maps trivially and lies in \(U\). Since \(U\) has exponent two, every finite subgroup has order a power of two. Consequently

\[
\Lambda_G\subseteq\mathbb Z[1/2]\subset\mathbb Q.
\]

The transcendental number \(\alpha\) is therefore outside \(\Lambda_G\).

Apply P39A to the finite integral group-ring element \(C\). All four conclusions follow.

\[
\boxed{
\text{Austin gives finite matrix + forbidden trace, but BC forces gaplessness.}
}
\]

## Exact almost-counterexample ledger

For this Austin pair \((G,C)\):

| Required route-(a) ingredient | Status |
|---|---|
| finite group-ring matrix | **YES**, even \(1\times1\) and integral after clearing denominators |
| kernel trace outside scalar trace range | **YES**, transcendental |
| isolated zero in reduced spectrum | **NO — rigorously impossible** |
| actual reduced-\(C^*\) kernel projection | **NO — rigorously impossible** |

This is stronger than saying that nobody has found a gap: a gap would contradict a known Baum–Connes theorem.

A viable forbidden-trace matrix must now live in a group where scalar \(K_0\)-assembly surjectivity is genuinely unresolved or false. The matrix must be coupled strongly enough to have a provable closed range in the **left regular representation**. Known BC-positive exotic-kernel examples are useful instead as negative calibrations for spectral-gap mechanisms.

## Re-derivation

Let coefficient space be \(\mathbb R^m\) with basis \(e_1,\dots,e_m\), and let the isotropic row law be

\[
x=\sqrt m\,\varepsilon e_J,
\]

where \(J\) is uniform on \(\{1,\dots,m\}\) and \(\varepsilon\) is an independent random sign. Then

\[
\mathbb E(xx^\top)=I_m.
\]

Take \(r=m-s\) independent rows and weight by row volume

\[
\det(XX^\top).
\]

The determinant is nonzero exactly when the sampled coordinate indices are distinct. On that event the rows are orthogonal of norm \(\sqrt m\), so

\[
\det(XX^\top)=m^r,
\]

a constant. Thus the volume-biased row span is a uniformly chosen \(r\)-coordinate subspace, and the residual projection \(P_s\) projects onto the uniformly chosen set of \(s\) omitted coordinate axes.

For a basis wedge

\[
e_I=e_{i_1}\wedge\cdots\wedge e_{i_j},
\]

we have

\[
(\wedge^jP_s)e_I
=
\begin{cases}
 e_I,&I\subseteq\text{omitted set},\\
 0,&\text{otherwise}.
\end{cases}
\]

The probability that a fixed ordered-free \(j\)-set is contained in the uniformly chosen omitted \(s\)-set is

\[
\frac{(s)_j}{(m)_j}.
\]

Off-diagonal matrix coefficients vanish identically in this coordinate basis. Hence

\[
\boxed{
\mathbb E[\wedge^jP_s]
=
\frac{(s)_j}{(m)_j}I
}
\]

for every \(j\le s\): the complete exterior-design hierarchy is exactly Haar.

At the endpoint \(s=1\), choose \(a=e_1\). Then

\[
p_1=a^\top P_1a
\]

is Bernoulli with parameter \(1/m\). For the normalized likelihood variable

\[
L_1=mp_1,
\]

\[
\mathbb E L_1=1,
\qquad
\mathbb E L_1^2=m.
\]

Therefore the endpoint chi-square is

\[
\boxed{
\Xi=m-1,
}
\]

not \(O(1)\).

So exact exterior/Hodge moments at every order do **not** determine the endpoint second likelihood moment. P04 correctly concludes that the actual harmonic Target-4 proof needs extra symmetric/Jordan information supplied by the physical \(O(d)\) orbit structure.
