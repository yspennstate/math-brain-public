# 3. Spectral-stability seed rederived

Let `A` be positive in a unital matrix C*-algebra and assume

\[
\sigma(A)\subset\{0\}\cup[\delta,M],
\qquad
0<\delta\le M.
\]

Then the indicator of `{0}` is continuous on `sigma(A)`, hence

\[
P_A=\mathbf1_{\{0\}}(A)
\]

belongs to the same C*-algebra.

On the zero eigenspace `e^{-tA}=1`, while on the positive spectrum it has norm at most `e^{-t\delta}`. Therefore

\[
\boxed{
\|e^{-tA}-P_A\|\le e^{-t\delta}.
}
\]

Likewise, the scalar function

\[
f_\eta(x)=\frac{\eta}{x+\eta}
\]

has `f_eta(0)=1` and is at most `eta/(delta+eta)` on `[delta,M]`, so

\[
\boxed{
\|\eta(A+\eta I)^{-1}-P_A\|
\le
\frac{\eta}{\delta+\eta}.
}
\]

Now let positive `A,B` have the **same** positive gap:

\[
\sigma(A),\sigma(B)
\subset
\{0\}\cup[\delta,\infty).
\]

Define the bounded pseudoinverse by functional calculus,

\[
A^\dagger(0)=0,
\qquad
A^\dagger(x)=x^{-1}\quad(x\ge\delta).
\]

Since `BP_B=0`,

\[
A P_B=(A-B)P_B.
\]

Multiplying by `A^dagger` gives

\[
(1-P_A)P_B=A^\dagger(A-B)P_B,
\]

hence

\[
\|(1-P_A)P_B\|
\le
\frac{\|A-B\|}{\delta}.
\]

Interchanging `A,B` gives the reverse cross term. For orthogonal projections,

\[
\|P_A-P_B\|
=
\max\{\|(1-P_A)P_B\|,\|(1-P_B)P_A\|\},
\]

so in fact

\[
\boxed{
\|P_A-P_B\|
\le
\frac{\|A-B\|}{\delta}.
}
\]

Thus the user-requested estimate

\[
\|P_A-P_B\|
\le
2\|A-B\|/\delta
\]

is valid but nonsharp.

The common-gap hypothesis is essential. If `A` has nonzero kernel and

\[
B=A+\varepsilon I,
\]

then `||A-B||=epsilon` but `P_B=0`; if the positive gap of `B` is allowed to shrink with `epsilon`, kernel projections can jump discontinuously.

This seed is only a **sufficient norm-plus-uniform-gap theorem**. It does not prove that any approximation family has the required common gap.

# 4. New theorem: trace mesh versus a gapped finite matrix

Throughout this section `G` and the stages `G_j` are countable discrete groups. No claim here is made for arbitrary locally compact groups.

Let

\[
C\in M_{u,v}(\mathbb CG),
\qquad
D=C^*C\in M_v(\mathbb CG),
\]

and suppose the parent reduced spectrum is genuinely gapped:

\[
\boxed{
\sigma_{M_v(C_r^*(G))}(D)
\subset
\{0\}\cup[\delta,M],
\qquad
0<\delta<M.
}
\tag{4.1}
\]

Let

\[
P=\mathbf1_{\{0\}}(D)\in M_v(C_r^*(G)),
\qquad
\alpha=(\operatorname{Tr}_v\otimes\tau_G)(P).
\tag{4.2}
\]

Assume there are algebraic coefficient-evaluation maps on group rings

\[
\phi_j:\mathbb CG\to\mathbb CG_j
\]

on the fixed finite supports under discussion. These may come from group quotients, but **no** global homomorphism

\[
C_r^*(G)\to C_r^*(G_j)
\]

is assumed.

Let `rho` be a word-support radius for `D`.

## 4.1 Exact minimax cutoff

Put

\[
\theta
=
\operatorname{arcosh}\frac{M+\delta}{M-\delta}
=
2\operatorname{artanh}\sqrt{\delta/M}.
\tag{4.3}
\]

For `N>=1`, the P38 Chebyshev minimizer is

\[
p_N(x)
=
\frac{
T_N\!\left(\frac{M+\delta-2x}{M-\delta}\right)
}{
T_N\!\left(\frac{M+\delta}{M-\delta}\right)
},
\tag{4.4}
\]

and satisfies

\[
p_N(0)=1,
\qquad
\sup_{x\in[\delta,M]}|p_N(x)|
=
\varepsilon_N
:=
\operatorname{sech}(N\theta).
\tag{4.5}
\]

Hence, with

\[
A_N=p_N(D),
\]

we have

\[
\boxed{
\|A_N-P\|\le\varepsilon_N
}
\tag{4.6}
\]

and

\[
\boxed{
\|A_N^2-A_N\|
\le
\varepsilon_N(1+\varepsilon_N).
}
\tag{4.7}
\]

The support radius of `A_N` is at most `N rho`, while that of the idempotent defect

\[
F_N=A_N^2-A_N
\tag{4.8}
\]

is at most `2N rho`.

## 4.2 Stage hypotheses

For a chosen degree `N=N_j`, assume:

### (T) Exact local trace transport

Writing

\[
A_{j,N}=p_N(D_j),
\qquad D_j=\phi_j(D),
\]

assume

\[
\boxed{
(\operatorname{Tr}_v\otimes\tau_{G_j})(A_{j,N})
=
(\operatorname{Tr}_v\otimes\tau_G)(A_N).
}
\tag{4.9}
\]

A sufficient condition for quotient families is that no nonidentity group element in the support of `A_N` is collapsed to the identity. This is a finite-support identity-coefficient statement, not reduced-C* functoriality.

### (U) Upper reduced-norm transfer for the single defect

Assume there is a finite `Lambda_j>=1` such that

\[
\boxed{
\|\phi_j(F_N)\|_{M_v(C_r^*(G_j))}
\le
\Lambda_j
\|F_N\|_{M_v(C_r^*(G))}.
}
\tag{4.10}
\]

Set

\[
\eta_j
=
\Lambda_j\varepsilon_N(1+\varepsilon_N)
\tag{4.11}
\]

and assume

\[
\boxed{\eta_j<1/4.}
\tag{4.12}
\]

### (M) Reduced-C* trace mesh

Assume the rounded stage projection below has trace in a lattice `h_j Z`. It is enough, and often easier to verify, that every reduced-C* projection over `G_j` satisfies

\[
(\operatorname{Tr}\otimes\tau_{G_j})(q)
\in h_j\mathbb Z.
\tag{4.13}
\]

This hypothesis concerns **reduced-C*** projections. It says nothing a priori about arbitrary von-Neumann spectral projections.

## 4.3 Rounding constant

For `0<=eta<1/4`, define

\[
r(\eta)
=
\frac{1-\sqrt{1-4\eta}}2.
\tag{4.14}
\]

If a self-adjoint element `a` satisfies

\[
\|a^2-a\|\le\eta<1/4,
\]

its spectrum lies in two clusters separated by `1/2`, and

\[
q=\mathbf1_{[1/2,\infty)}(a)
\]

is a projection with

\[
\boxed{
\|q-a\|\le r(\eta).
}
\tag{4.15}
\]

The identity

\[
\eta=r(\eta)(1-r(\eta))
\tag{4.16}
\]

will be useful below.

# 5. `P01-P45A-TRACE-MESH-DIOPHANTINE-CUTOFF` — PROVED

Under (4.1) and the stage hypotheses (T), (U), (M), define

\[
Q_j
=
\mathbf1_{[1/2,\infty)}(A_{j,N_j})
\in M_v(C_r^*(G_j)).
\tag{5.1}
\]

Then

\[
\boxed{
\operatorname{dist}(\alpha,h_j\mathbb Z)
\le
v\Bigl[
\varepsilon_{N_j}
+r(\eta_j)
\Bigr].
}
\tag{5.2}
\]

Equivalently, there exists an integer `m_j` such that

\[
\boxed{
|\alpha-m_jh_j|
\le
v\Bigl[
\operatorname{sech}(N_j\theta)
+r\!\bigl(
\Lambda_j\operatorname{sech}(N_j\theta)
(1+\operatorname{sech}(N_j\theta))
\bigr)
\Bigr].
}
\tag{5.3}
\]

## Proof

From (4.7), coefficient evaluation, and (U),

\[
\|A_{j,N}^2-A_{j,N}\|
\le
\Lambda_j\varepsilon_N(1+\varepsilon_N)
=
\eta_j<1/4.
\]

Therefore `Q_j` is a genuine projection in the **reduced** group C*-algebra and

\[
\|Q_j-A_{j,N}\|
\le r(\eta_j).
\tag{5.4}
\]

By (M),

\[
(\operatorname{Tr}_v\otimes\tau_{G_j})(Q_j)
=m_jh_j
\]

for some integer `m_j`.

Now

\[
\begin{aligned}
|m_jh_j-\alpha|
&\le
\left|
(\operatorname{Tr}_v\otimes\tau_{G_j})(Q_j-A_{j,N})
\right|\\
&\quad+
\left|
(\operatorname{Tr}_v\otimes\tau_{G_j})(A_{j,N})
-(\operatorname{Tr}_v\otimes\tau_G)(A_N)
\right|\\
&\quad+
\left|
(\operatorname{Tr}_v\otimes\tau_G)(A_N-P)
\right|.
\end{aligned}
\]

The middle term is exactly zero by (T). Since the unnormalized matrix trace has norm `v`, (5.4) gives the first term at most

\[
v r(\eta_j),
\]

and (4.6) gives the final term at most

\[
v\varepsilon_N.
\]

This proves (5.2)–(5.3). QED.

## Interpretation

This is a theorem about a **parent reduced spectral gap**. It does not assume a stage gap. The stage object `Q_j` is obtained by rounding a controlled polynomial and is known to be reduced-C*. No identification with the true stage von-Neumann kernel is needed.

Thus a gapped parent finite matrix imposes an arithmetic approximation condition on its kernel trace whenever the approximation family supplies:

1. local trace transport for the polynomial cutoff;
2. upper reduced-norm control for its idempotent defect;
3. a discrete reduced-C* trace mesh.

This is the first P01 formula that directly couples the historical finite-matrix route to the historical upper-norm route.

# 6. `P01-P45B-TRACE-MESH-FORCES-NORM-DISTORTION` — PROVED

Keep the hypotheses above but regard the upper reduced-norm factor `Lambda_j` as the unknown quantity to be forced large.

Let

\[
d_j
=
\operatorname{dist}(\alpha,h_j\mathbb Z),
\qquad
\varepsilon=\varepsilon_{N_j},
\]

and define

\[
y_j
=
\frac{d_j}{v}-\varepsilon.
\tag{6.1}
\]

If

\[
0<y_j<1/2
\]

and the rounded-projection regime `eta_j<1/4` holds, then

\[
\boxed{
\Lambda_j
\ge
\frac{y_j(1-y_j)}{
\varepsilon(1+\varepsilon)
}.
}
\tag{6.2}
\]

If `y_j>=1/2`, then no `eta_j<1/4` can satisfy the hypotheses at all.

## Proof

P45A gives

\[
d_j
\le
v(\varepsilon+r(\eta_j)).
\]

Hence

\[
r(\eta_j)\ge y_j.
\tag{6.3}
\]

On `[0,1/4)`, `r(eta)` lies in `[0,1/2)` and satisfies

\[
\eta=r(\eta)(1-r(\eta)).
\]

The function `x(1-x)` is increasing on `[0,1/2]`. Thus (6.3) implies

\[
\eta_j
\ge
 y_j(1-y_j).
\]

Using

\[
\eta_j
=
\Lambda_j\varepsilon(1+\varepsilon)
\]

gives (6.2). If `y_j>=1/2`, (6.3) contradicts `r(eta_j)<1/2`. QED.

## Consequence

Suppose the parent trace stays a definite arithmetic distance from the stage trace mesh while the Chebyshev error is much smaller. Then the defect's reduced norm **must** inflate under stage evaluation.

For example, if

\[
d_j\ge c h_j^\kappa,
\qquad
\varepsilon_{N_j}=o(h_j^\kappa),
\]

then (6.2) forces, at the corresponding scale,

\[
\Lambda_j
\gtrsim
\frac{h_j^\kappa}{\varepsilon_{N_j}}.
\]

Because `epsilon_N` decays exponentially in `N`, an arithmetic trace mismatch can force exponentially large norm distortion.

This is an exact obstruction to overly optimistic approximation arguments: if a prospective counterexample has an exotic gapped kernel trace, then a sufficiently fine discrete stage trace mesh cannot coexist with a uniformly bounded upper reduced-norm transfer at arbitrarily deep polynomial cutoffs.

# 7. `P01-P45C-ROTH-GAP-OBSTRUCTION` — PROVED

Assume now that

\[
h_j=\frac1{q_j},
\qquad
q_j\in\mathbb N,
\qquad
q_j\to\infty,
\tag{7.1}
\]

and that the parent kernel trace `alpha` is an **algebraic irrational**.

Assume there are degrees `N_j` for which:

1. local trace transport (T) holds;
2. the defect upper norm factors are uniformly bounded,
   \[
   \Lambda_j\le\Lambda_0<\infty;
   \tag{7.2}
   \]
3. `eta_j<1/4` eventually;
4. the available cutoff degrees satisfy
   \[
   \boxed{
   \liminf_{j\to\infty}
   \frac{N_j\theta}{\log q_j}>2.
   }
   \tag{7.3}
   \]

Then the parent gap hypothesis (4.1) is impossible.

Equivalently:

## `P01-P45C-ROTH-GAP-OBSTRUCTION`

For an algebraic irrational finite-matrix kernel trace, any approximation family with reciprocal-integer stage trace mesh and uniformly bounded defect norm distortion must fail at least one of:

- the parent reduced spectral gap;
- exact local trace transport at the required growing degree;
- the upper reduced-norm bound;
- the degree budget (7.3).

## Proof

For `0<=eta<1/4`,

\[
r(\eta)
\le2\eta,
\tag{7.4}
\]

because `eta=r(1-r)>=r/2` when `0<=r<=1/2`.

For large `j`, `epsilon_j=epsilon_{N_j}<=1`, so

\[
\eta_j
\le
2\Lambda_0\varepsilon_j.
\]

Therefore

\[
r(\eta_j)
\le
4\Lambda_0\varepsilon_j.
\]

P45A gives integers `m_j` such that

\[
\left|
\alpha-\frac{m_j}{q_j}
\right|
\le
v(1+4\Lambda_0)\varepsilon_j.
\tag{7.5}
\]

The exact Chebyshev error obeys

\[
\varepsilon_j
=
\operatorname{sech}(N_j\theta)
\le
2e^{-N_j\theta}.
\tag{7.6}
\]

Let

\[
c
=
\liminf_j\frac{N_j\theta}{\log q_j}>2.
\]

Choose exponents

\[
2<\nu<\nu'<c.
\]

For all sufficiently large `j`,

\[
\varepsilon_j
\le
2q_j^{-\nu'}.
\]

The fixed multiplicative constant in (7.5) is absorbed by the exponent gap `nu'-nu`, so eventually

\[
\left|
\alpha-\frac{m_j}{q_j}
\right|
<
q_j^{-\nu}.
\tag{7.7}
\]

Reduce `m_j/q_j` to `p_j/s_j`. Since `s_j<=q_j`,

\[
q_j^{-\nu}\le s_j^{-\nu}.
\]

The approximants are eventually distinct because their error tends to zero and `alpha` is irrational. Thus (7.7) gives infinitely many reduced rationals satisfying

\[
\left|
\alpha-\frac{p_j}{s_j}
\right|
<
s_j^{-\nu}
\qquad(\nu>2),
\]

contradicting Roth's theorem for algebraic irrational numbers. QED.

## Sharp meaning of the constant `2`

The number `2` in (7.3) is not a spectral artifact. It is the Diophantine exponent supplied by Roth.

More generally, if a trace `alpha` has finite irrationality exponent `mu(alpha)`, the same argument replaces `2` by `mu(alpha)`. For a quadratic irrational, the stronger classical badly-approximable estimate gives a direct `c/q^2` lower bound and P45B yields an explicit finite-scale norm-distortion lower bound.

No claim is made for Liouville traces, whose irrationality exponent is infinite.
