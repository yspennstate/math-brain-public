## 2. New idea before code: use the lamp algebra to build an exact finite-support matrix unitary

The recent fixed-target route had become increasingly analytic: Sobolev closure, polar correction, Toeplitz walls, and Halmos dilation. This run asks a different question: can the finite lamp subgroup itself provide an **exact finite-support matrix splice** whose class is nontrivial only because a free-word channel is inserted?

Choose a nontrivial order-two lamp configuration
\[
h=a_ea_{s_1}\in B.
\]
Then \(h^2=e\), so \(u_h=u_h^*=u_h^{-1}\). Define the complementary lamp projections
\[
p_h=\frac{1+u_h}{2},
\qquad
q_h=\frac{1-u_h}{2}.
\]
They satisfy exactly
\[
p_h^2=p_h,
\quad q_h^2=q_h,
\quad p_hq_h=q_hp_h=0,
\quad p_h+q_h=1.
\]
Now form
\[
S_h=
\begin{pmatrix}
p_h&q_h\\
q_h&p_h
\end{pmatrix}
\in M_2(\mathbb CG).
\]
Because the two projections are complementary,
\[
S_h^*=S_h,
\qquad
S_h^2=I_2.
\]
Thus \(S_h\) is an exact finite-support matrix unitary.

This lamp splice is \(K_1\)-null. Let
\[
H=\frac1{\sqrt2}
\begin{pmatrix}1&1\\1&-1\end{pmatrix}.
\]
Then
\[
S_h=H^*\operatorname{diag}(1,u_h)H.
\]
Since \(q_h\) is a projection,
\[
u_h=1-2q_h=e^{i\pi q_h}.
\]
Hence
\[
S_h(t)=H^*\operatorname{diag}(1,e^{i\pi t q_h})H,
\qquad 0\le t\le1,
\]
is a norm-continuous unitary path from \(I_2\) to \(S_h\). Therefore
\[
\boxed{[S_h]=0\in K_1(C_r^*(G)).}
