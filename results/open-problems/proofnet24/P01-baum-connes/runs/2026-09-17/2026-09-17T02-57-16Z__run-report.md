# 3. `P01-P80A-COMPLEX-POLAR-WALL = PROVED`

## Theorem

For nontrivial `w\in F_2` and arbitrary `c\in\mathbb C`:

1. `F_c=u_w+c u_a` is invertible in `C_r^*(G)` iff `|c|\ne1`.
2. For `|c|\ne1`, let
   \[
   U_c=F_c(F_c^*F_c)^{-1/2}.
   \]
   Then
   \[
   \boxed{
   [U_c]=
   \begin{cases}
   [u_w],&|c|<1,\\
   0,&|c|>1.
   \end{cases}}
   \]
3. If the abelianization of `w` is `(m,n)`, then
   \[
   \boxed{
   \mu_1^G(mv_1+nv_2)=[U_c]\quad(|c|<1),
   \qquad
   \mu_1^G(0)=[U_c]\quad(|c|>1).}
   \]
4. On the critical wall `|c|=1`, the von Neumann polar phase exists but is not in `C_r^*(G)`.

## Proof: exact invertibility locus

Because `u_w` is unitary,
\[
F_c\text{ invertible}\iff 1+c u_g\text{ invertible}.
\]
The spectrum of `u_g` is the whole unit circle. Hence
\[
0\in\sigma(1+c u_g)
\iff \exists z\in\mathbb T:\ 1+cz=0
\iff |c|=1.
\]
Therefore
\[
\boxed{F_c\text{ is invertible exactly off the unit circle in parameter space}.}
\]

## Proof: subcritical class

If `|c|<1`, then for every `0\le t\le1`,
\[
F_{tc}=u_w+t c u_a
\]
is invertible because `|tc|<1`. Polar decomposition varies norm-continuously on the invertible group, so its polar unitaries join `u_w` to `U_c`. Thus
\[
\boxed{[U_c]=[u_w]\quad(|c|<1).}
\]

## Proof: supercritical class

If `|c|>1`, use
\[
F_t=t u_w+c u_a,\qquad0\le t\le1.
\]
Factoring `c u_a` shows invertibility for the whole path because `t/|c|<1`. At `t=0`, the polar unitary is `(c/|c|)u_a`. The scalar phase is null-homotopic, and `u_a` is null-homotopic because with
\[
p=\frac{1-u_a}{2}
\]
one has `e^{i\pi p}=u_a`. Hence
\[
\boxed{[U_c]=0\quad(|c|>1).}
\]

## Proof: assembly coordinates

Pooya's basis gives
\[
[u_w]=m[u_{s_1}]+n[u_{s_2}]
=\mu_1^G(mv_1+nv_2).
\]
Combining with the two polar homotopies proves the stated assembly formula.

## Proof: the critical phase is von Neumann but not reduced

Assume `|c|=1`. In `L(\langle g\rangle)\cong L^\infty(\mathbb T)`, the polar phase of `1+c u_g` is represented almost everywhere by
\[
\phi_c(z)=\frac{1+cz}{|1+cz|}.
\]
The only zero of `1+cz` on `\mathbb T` is `z=-1/c`, a Haar-null point, so the polar part is a von Neumann unitary. But `\phi_c` has opposite one-sided limits at that simple zero and is not continuous. Thus
\[
\phi_c(u_g)\notin C_r^*(\langle g\rangle).
\]
The canonical conditional expectation
\[
E_{\langle g\rangle}:C_r^*(G)\to C_r^*(\langle g\rangle)
\]
fixes elements of `L(\langle g\rangle)` under its normal extension. If `\phi_c(u_g)` belonged to `C_r^*(G)`, the expectation would force it into `C_r^*(\langle g\rangle)`, contradiction. Multiplying by `u_w` shows that the von Neumann polar of `F_c` is also not reduced.

This extends P79's single critical radius to the full critical circle `|c|=1`.

# 4. `P01-P80B-CYCLIC-TOEPLITZ-BOUNDARY = PROVED / CLASSICAL MECHANISM`

For `|c|\ne1`, define the cyclic phase
\[
\psi_c(z)=\frac{1+cz}{|1+cz|}\in C(\mathbb T,\mathbb T).
\]
Its winding number is
\[
\boxed{
\operatorname{wind}(\psi_c)=
\begin{cases}
0,&|c|<1,\\
1,&|c|>1.
\end{cases}}
\]
because the circle `1+c\mathbb T` excludes the origin inside the parameter unit disk and surrounds it once outside.

In the classical Toeplitz extension
\[
0\longrightarrow\mathcal K\longrightarrow\mathcal T
\longrightarrow C(\mathbb T)\longrightarrow0,
\]
the standard index convention gives
\[
\partial[\psi_c]=\operatorname{ind}(T_{\psi_c})
=-\operatorname{wind}(\psi_c).
\]
Hence the boundary charge is exactly
\[
\boxed{0\text{ for }|c|<1,\qquad -1\text{ for }|c|>1.}
\]
This is a classical Toeplitz-index mechanism, not a novelty claim.

The reduced polar decomposes as
\[
U_c=u_w\,\psi_c(u_g).
\]
In ambient `K_1`,
\[
[u_g]=[u_{w^{-1}a}]=-[u_w]+[u_a]=-[u_w].
\]
Therefore the Toeplitz winding jump explains the P79/P80 class jump exactly:

- inside: `wind=0`, so `[U_c]=[u_w]`;
- outside: `wind=1`, so `[U_c]=[u_w]+[u_g]=0`;
- on the wall: the symbol phase is discontinuous, so the Toeplitz/Fredholm representative and the reduced polar both fail at the same parameter locus.

This is a boundary-map explanation internal to the same frozen group: the cyclic algebra is generated by an element of `G`, and the resulting computation is used only to decide the class of the same `C_r^*(G)` polar unitary. It is not counted as movement on an unrelated group or coefficient version.
