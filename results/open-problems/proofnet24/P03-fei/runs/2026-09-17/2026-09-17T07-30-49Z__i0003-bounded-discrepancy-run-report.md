# 3. B6 — deform the balanced periodic point by line defects

The completed periodic theorem suggests starting from a balanced periodic background and changing entire lines. One changed horizontal line changes infinitely many directed edges, so finite-vertex perturbation folklore is irrelevant. The right variable is not the number of modified edges but the cumulative line flux.

Write the deterministic horizontal and vertical signs as

`a_y in {+1,-1}`, `b_x in {+1,-1}`,

so that the exact source transition kernel is

\[
(Pf)(x,y)=\frac12 f(x+a_y,y)+\frac12 f(x,y+b_x).
\tag{3.1}
\]

Define the two-sided discrepancies

\[
D_a=\sup_{m<n}\left|\sum_{k=m+1}^{n}a_k\right|,
\qquad
D_b=\sup_{m<n}\left|\sum_{k=m+1}^{n}b_k\right|.
\tag{3.2}
\]

Equivalently, `D_a,D_b<infinity` iff there exist bounded bi-infinite primitives `alpha_y,beta_x` satisfying

\[
\alpha_y-\alpha_{y-1}=a_y,
\qquad
\beta_x-\beta_{x-1}=b_x.
\tag{3.3}
\]

This condition contains every balanced periodic environment, every finite collection of line flips of one, and every environment with balanced periodic tails outside a finite set. It is strictly larger than the periodic class: for any aperiodic sign sequence `(c_k)`, the pair-block rule

\[
(a_{2k},a_{2k+1})=(c_k,-c_k)
\tag{3.4}
\]

has uniformly bounded discrepancy while remaining aperiodic; the same construction may be used independently for `(b_x)`.

Thus B6 produced a source-valid deformation class which treats whole-line defects rather than pretending they are finite graph perturbations.

# 4. B12 — the conserved object is a bounded face stream function

The source drift is divergence free. Under (3.3) that divergence-free current has a **bounded stream function**, and this is exactly what turns the source walk into a strongly sectorial perturbation of recurrent planar simple random walk.

Let `m` be counting measure on `Z^2`. Every vertex `(x,y)` has exactly two incoming predecessors, `(x-a_y,y)` and `(x,y-b_x)`, each carrying transition probability `1/2`. Therefore `mP=m`: counting measure is invariant, in agreement with the source.

The adjoint on `ell^2(m)` is

\[
(P^*f)(x,y)=\frac12 f(x-a_y,y)+\frac12 f(x,y-b_x).
\tag{4.1}
\]

Put

\[
S=\frac{P+P^*}{2},\qquad A=\frac{P-P^*}{2}.
\tag{4.2}
\]

Then

\[
(Sf)(x,y)=\frac14\{f(x+1,y)+f(x-1,y)+f(x,y+1)+f(x,y-1)\},
\tag{4.3}
\]

so the symmetric part is exactly discrete-time simple random walk. This equality is source background.

For a positively oriented horizontal edge from `(x,y)` to `(x+1,y)` and vertical edge from `(x,y)` to `(x,y+1)`, the antisymmetric edge currents are

\[
j^{\rm h}_{x,y}=\frac{a_y}{4},\qquad
j^{\rm v}_{x,y}=\frac{b_x}{4}.
\tag{4.4}
\]

Using the bounded primitives from (3.3), define a face function on the unit square with lower-left corner `(x,y)` by

\[
\psi_{x,y}=\frac{\alpha_y-\beta_x}{4}.
\tag{4.5}
\]

Then the current is the discrete curl of `psi`:

\[
j^{\rm h}_{x,y}=\psi_{x,y}-\psi_{x,y-1},
\qquad
j^{\rm v}_{x,y}=\psi_{x-1,y}-\psi_{x,y}.
\tag{4.6}
\]

Moreover

\[
\|\psi\|_\infty\le \frac{\|\alpha\|_\infty+\|\beta\|_\infty}{4}<\infty.
\tag{4.7}
\]

This bounded stream function is the useful conserved/coboundary object found by B12.

# 5. Exact sector estimate

For finitely supported real functions `f,g`, write

\[
\mathcal B(f,g)=\langle f,Ag\rangle_m.
\]

By pairing opposite orientations of each undirected edge,

\[
\begin{aligned}
\mathcal B(f,g)=\frac14\sum_{x,y}\{&a_y[f_{00}g_{10}-f_{10}g_{00}]\\
&+b_x[f_{00}g_{01}-f_{01}g_{00}]\},
\end{aligned}
\tag{5.1}
\]

where, on the face based at `(x,y)`, `00=(x,y)`, `10=(x+1,y)`, `01=(x,y+1)`, and `11=(x+1,y+1)`.

Substitute the curl representation (4.6) and collect the coefficient of one face variable `psi_{x,y}`. It is

\[
\begin{aligned}
C_{x,y}(f,g)
={}&(f_{00}g_{10}-f_{10}g_{00})
-(f_{01}g_{11}-f_{11}g_{01})\\
&-(f_{00}g_{01}-f_{01}g_{00})
+(f_{10}g_{11}-f_{11}g_{10})\\
={}&(f_{00}-f_{11})(g_{10}-g_{01})
 +(f_{10}-f_{01})(g_{11}-g_{00}).
\end{aligned}
\tag{5.2}
\]

Hence

\[
\mathcal B(f,g)=\sum_{x,y}\psi_{x,y}C_{x,y}(f,g).
\tag{5.3}
\]

Define the ordinary nearest-neighbor gradient energy

\[
G(f)=\sum_{x,y}\{[f(x+1,y)-f(x,y)]^2+[f(x,y+1)-f(x,y)]^2\}.
\tag{5.4}
\]

Each diagonal difference across a unit square is a sum of two nearest-neighbor differences. Therefore

\[
\sum_{x,y}(f_{00}-f_{11})^2\le 2G(f),
\qquad
\sum_{x,y}(f_{10}-f_{01})^2\le 2G(f),
\tag{5.5}
\]

and the analogous bounds hold for `g`. Cauchy--Schwarz in (5.3) gives

\[
\boxed{
|\mathcal B(f,g)|
\le 4\|\psi\|_\infty\sqrt{G(f)G(g)}.
}
\tag{5.6}
\]

For the symmetric kernel `S`,

\[
\mathcal E_s(f,f)
:=\langle f,(I-S)f\rangle_m
=\frac14G(f).
\tag{5.7}
\]

Thus

\[
|\mathcal B(f,g)|
\le 16\|\psi\|_\infty
\sqrt{\mathcal E_s(f,f)\mathcal E_s(g,g)}.
\tag{5.8}
\]

For the full non-symmetric form

\[
\mathcal E(f,g)=\langle f,(I-P)g\rangle_m
=\mathcal E_s(f,g)-\mathcal B(f,g),
\tag{5.9}
\]

the skewness of `A` gives

\[
\mathcal E(f,f)=\mathcal E_s(f,f).
\tag{5.10}
\]

Consequently

\[
\boxed{
|\mathcal E(f,g)|
\le [1+16\|\psi\|_\infty]
\sqrt{\mathcal E(f,f)\mathcal E(g,g)}.
}
\tag{5.11}
\]

In terms of the one-dimensional primitives, one admissible explicit constant is

\[
1+4(\|\alpha\|_\infty+\|\beta\|_\infty).
\tag{5.12}
\]

Since the kernel is bounded on `ell^2(m)`, finitely supported functions are a form core and the estimate extends by density. This is the strong sector condition.

# 6. `P03-I0003-BOUNDED-DISCREPANCY-SECTOR-232 = KNOWN / VERIFIED TRANSFER`

## Statement

For the exact fully oriented Manhattan walk (3.1), assume both line-sign sequences have uniformly bounded two-sided discrepancy, equivalently (3.3) admits bounded primitives. Then the walk is recurrent from every starting vertex.

This is a **restricted source-class theorem**, so the broad Problem 3 status remains PARTIAL. Its repository label is **KNOWN**, because the final recurrence step is an application of a published general theorem rather than a claim of a newly discovered recurrence principle.

## Proof

Sections 4--5 prove that the continuous-time Markov form associated with `P-I` is strongly sectorial and that its symmetric part is exactly the standard nearest-neighbor simple-random-walk form on `Z^2`. The latter is recurrent. Beznea--Cimpean--Rockner (2018), Theorem 5.1, says that under the strong sector condition recurrence of the non-symmetric form follows from recurrence of its symmetric part. Therefore the Poissonized Manhattan walk is recurrent with respect to counting measure.

To connect this form statement to the discrete chain, let `Q_t=exp[t(P-I)]`. Then

\[
Q_t(x,x)=e^{-t}\sum_{n\ge0}\frac{t^n}{n!}P^n(x,x),
\]

so Tonelli gives

\[
\int_0^\infty Q_t(x,x)\,dt
=\sum_{n\ge0}P^n(x,x).
\tag{6.1}
\]

(The source uses total jump rate two rather than one; this only multiplies the integral by a fixed factor and it explicitly performs the same Poissonization identity.) Hence continuous-time recurrence is exactly discrete-time recurrence at a state.

It remains to verify irreducibility so the conclusion holds at every state. Bounded discrepancy forces both signs to occur arbitrarily far in both directions in each of `(a_y)` and `(b_x)`: an eventually one-signed tail would make its primitive unbounded.

Fix a start `(x,y)` and target `(X,Y)`. Put `s=a_y` and `t=b_X`. Choose a row `r` with `a_r=-s`, taking `r<min(y,Y)` if `t=+1` and `r>max(y,Y)` if `t=-1`. Then choose a column `c` beyond both `x` and `X` in the direction `s` (right if `s=+1`, left if `s=-1`) such that `b_c=sign(r-y)=-t`. Such choices exist by the two-sided occurrence just noted. The four directed segments

\[
(x,y)\to(c,y)\to(c,r)\to(X,r)\to(X,Y)
\tag{6.2}
\]

all follow legal oriented lines. Thus the directed graph is strongly connected. Combining irreducibility with (6.1) proves recurrence from every vertex. QED.

## Concrete scope gained

The theorem immediately handles finite whole-line defects of any balanced doubly periodic environment and, more generally, environments with balanced periodic tails and only a finite exceptional core. It also handles genuinely aperiodic pair-block fields such as (3.4). This is a strict enlargement of P03's preceding periodic scope even though the underlying recurrence mechanism is prior art.

# 7. Refutation first: mean zero and merely sublinear prefix discrepancy are not enough

A tempting generalization is to replace bounded discrepancy by zero asymptotic mean, or even by prefix sums `o(n)`. The source itself kills that route.

For iid fair line signs, the strong law gives almost surely

\[
\frac1n\sum_{k=1}^{n}a_k\to0,
\qquad
\frac1n\sum_{k=1}^{n}b_k\to0,
\tag{7.1}
\]

and the analogous limits in the negative direction. Yet Bou-Rabee--Peres Theorem 1.1 proves that the corresponding exact Manhattan walk is transient for almost every such environment. Thus no criterion based only on zero line means or `o(n)` prefix discrepancy can characterize recurrence.

This is useful information for the next attack: the relevant quantity is not just cancellation in density, but the *scale* of the stream primitive.

# 8. B30 — one scale at a time: the genuinely new adjacent route

Because the bounded-stream result is literature-implied, I did not stop after proving it. The next class is allowed to have unbounded primitives. Define, after fixing any primitives of (3.3),

\[
M(R)=\sup_{|x|,|y|\le R}|\alpha_y-\beta_x|.
\tag{8.1}
\]

The face calculation is local: for functions supported in a box of radius `R`, the same proof gives a sector bound with constant of order `1+M(R)`. On the reversible side, the simple-random-walk capacity from the origin to distance `R` is of order `1/log R`. This suggests testing whether a finite-volume non-reversible capacity comparison can prove recurrence under a genuinely larger condition such as

\[
M(R)=o(\sqrt{\log R}).
\tag{8.2}
\]

**No theorem is claimed here.** The precise obstruction is boundary/collapse bookkeeping. Gaudilliere--Landim's global sector comparison immediately gives `cap <= C cap_s` when a global sector constant exists. Replacing that constant by the local value `M(R)` inside a collapsed finite box requires controlling the antisymmetric current created at the collapsed boundary. I did not find a source allowing that replacement for free, and I do not silently promote the heuristic estimate

`cap(0,B_R^c) ?<= const*(1+M(R))^2/log R`

without proving those boundary terms.

This is the substantive new attack produced by B30. It is strictly outside the completed periodic/bounded-stream transfer and has a falsifiable next obligation: either derive the exact finite-volume capacity inequality, including collapse-boundary current, or construct a deterministic counterexample with very slowly growing `M(R)`.

The iid source counterexamples do not immediately kill (8.2): their one-dimensional primitives typically fluctuate on a much larger square-root scale. Thus the proposed scale is not contradicted by the known almost-sure transience theorem.

For fixed positive diagonal `t-1`, every positive-semidefinite completion has each free entry bounded in absolute value by `t-1` from its `2x2` principal minor. \[
(K_t)_{ij}=0\qquad(i\ne j,\ ij\notin E(H)).
\tag{10.3}
\]

Hence `X_t=K_t/Tr K_t` is PSD, has trace one, and vanishes on the required nonedges: it is primal-feasible.

\[
\operatorname{Tr}(K_tB_t)=\langle J,K_t\rangle.
\tag{10.4}
\]

Taking the trace of `K_tS_t=I` gives

\[
n=t\operatorname{Tr}K_t-\langle J,K_t\rangle,
