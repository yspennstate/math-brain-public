# 2. Quadratic multiplication is a flat four-point Fourier transform

This run attacks the previous exact next target — one actual low-degree first-separator cell — without taking a nonsummable absolute value.

Work in `F_2^n` coordinates. For a pair `i<j`, define the quadratic monomial phase
\[
q_{ij}(x)=(-1)^{x_i x_j}.
\tag{2.1}
\]
On its two coordinates,
\[
q_{ij}(00)=q_{ij}(01)=q_{ij}(10)=1,
\qquad
q_{ij}(11)=-1.
\]
Its normalized two-bit Fourier vector is
\[
\widehat q(\varnothing)=\widehat q(\{i\})
=\widehat q(\{j\})=\frac12,
\qquad
\widehat q(\{i,j\})=-\frac12.
\tag{2.2}
\]
Hence multiplication by `q_{ij}` acts, for every fixed outside Fourier label
\[
T\subset[n]\setminus\{i,j\},
\]
on the four-vector
\[
v_T=(\widehat h(T\cup U))_{U\subseteq\{i,j\}}
\tag{2.3}
\]
by a real orthogonal `4 x 4` matrix whose every entry has magnitude `1/2`.

This flatness is special to the quadratic monomial. A degree-`q>2` monomial phase has one large Fourier coefficient and many coefficients of magnitude `2^{1-q}`; the argument below is therefore not silently generalized to all compiler degrees.

Let
\[
m_T=\|v_T\|_2^2.
\]
If `m_T>0`, set
\[
p_T(U)=\frac{\widehat h(T\cup U)^2}{m_T},
\]
and let `p'_T` be the analogous conditional distribution after multiplication by `q_{ij}`. Orthogonality preserves every `m_T`.

The spectral entropy decomposes exactly as
\[
H_{\rm nat}(h)
=\sum_T m_T\log\frac1{m_T}
+\sum_Tm_T H(p_T),
\tag{2.4}
\]
where the first term is invariant under `h -> h q_{ij}`.

# 3. A self-contained four-point entropic uncertainty lemma

Let `U` be a real orthogonal `4 x 4` matrix with `|U_{ab}|=1/2`. For a real unit vector `x`, set
\[
p_a=x_a^2,
\qquad
q_b=(Ux)_b^2.
\]
Then
\[
\boxed{H(p)+H(q)\ge\log4=2\log2.}
\tag{3.1}
\]
All logarithms in this report section are natural.

A self-contained proof uses only finite-dimensional interpolation. Since
\[
\|U\|_{1\to\infty}=\frac12,
\qquad
\|U\|_{2\to2}=1,
\]
Riesz–Thorin gives, for `1<=r<=2` and `r'=r/(r-1)`,
\[
\|Ux\|_{r'}
\le4^{1/2-1/r}\|x\|_r.
\tag{3.2}
\]
At `r=2` both sides equal one. Differentiate the logarithm of (3.2) from the left at `r=2`. For any unit vector `z`,
\[
\left.\frac d{dr}\log\|z\|_r\right|_{r=2}
=-\frac14 H((z_a^2)_a).
\]
Because `(r')'|_{r=2}=-1`, the derivative of the left-hand logarithmic ratio in (3.2) is
\[
\frac14[H(p)+H(q)],
\]
while the derivative of `(1/2-1/r)\log4` is `(1/4)\log4`. Equality holds at the endpoint and the inequality holds to its left, so the left derivative is at least the right derivative. This proves (3.1).

No asymptotics, positivity conjecture, or imported infinite-dimensional theorem is used.

\[
\boxed{

\tag{4.4}

### Proof

\[

\left[
\log2+\frac12(H(p_T)-H(p'_T))

H(p'_T)\ge2\log2-H(p_T),

\[
\log2+\frac12(H(p_T)-H(p'_T))
\le H(p_T).

Average with the nonnegative masses `m_T`. `QED`.

\tag{7.1}
\]
The same earlier nonlinear mask is physically constant along the `i_r`- and `j_r`-edges, so
\[

\qquad
I_{j_r}(fm)=I_{j_r}(f).

\]
The exact recurrence (4.7) and (5.6) hence give

R_{r-1}(f)-R_r(f)

\]
Summing the disjoint gates,
\[
\boxed{

\le
\sum_{r=1}^m

\tag{7.3}
\]
For a perfect or near-perfect matching this is the familiar logarithmic influence-entropy quantity and can be as large as

J\log(n/J).
\]
Thus `P03-FIRST-QUADRATIC-GATE-PAYMENT-116` is a genuine constant-`J` gate theorem, but a naive repetition on disjoint gates recovers only a Han-type logarithmic envelope and does **not** prove FEI.

This identifies the new missing structure sharply: further quadratic gates must exploit the nonzero comparator credit `-mathcal U_{ij}(m)` created when gates **share coordinates / rank structure**, or use the equivalent signed R16/R32 first-separator cancellations.
