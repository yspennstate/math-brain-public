## 2. Exact arithmetic reduction for every Boolean function

Let `N=2^n`. Identify cube points with `F_2^n`, and let

\[
W_S=\sum_x f(x)\chi_S(x)
\]

be the unnormalized Walsh coefficient. For `n>=1`, every `W_S` is even, so define

\[
a_S:=|W_S|/2\in\mathbb Z_{\ge0}.
\]

Parseval in unnormalized form gives

\[
\sum_S W_S^2=N^2,
\qquad
\sum_S a_S^2=\frac{N^2}{4}.
\tag{2.1}
\]

Set

\[
P:=\prod_{a_S>0}a_S^{a_S^2},
\qquad
Q:=\sum_S |S|a_S^2.
\tag{2.2}
\]

Since

\[
\widehat f(S)^2=\frac{4a_S^2}{N^2},
\]

a direct substitution yields, in **bits**,

\[
H_2(f)
=2(n-1)-\frac{8}{N^2}\log_2 P,
\tag{2.3}
\]

while the standard Fourier identity for total influence gives

\[
I(f)=\sum_S|S|\widehat f(S)^2
=\frac{4Q}{N^2}.
\tag{2.4}
\]

Therefore every nonconstant Boolean function has

\[
\boxed{
\frac{H_2(f)}{I(f)}
=\frac{K_n-2\log_2P}{Q},
\qquad
K_n:=\frac{N^2(n-1)}2.
}
\tag{2.5}
\]

This representation makes comparisons of logarithmic expressions exact. For two profiles `(P_1,Q_1)` and `(P_2,Q_2)`, the inequality

\[
\frac{K_n-2\log_2P_1}{Q_1}
\ge
\frac{K_n-2\log_2P_2}{Q_2}
\]

is equivalent to the integer comparison

\[
\boxed{
2^{K_n(Q_2-Q_1)}P_2^{2Q_1}
\ge P_1^{2Q_2},
}
\tag{2.6}
\]

with the power of two moved to the opposite side if its exponent is negative. The checker performs exactly (2.6); no floating ranking decides an optimum.

## 3. Proved symmetry reduction

Write

\[
f=1-2\mathbf 1_A
\]

for the set `A` of `-1` values.

Two exact symmetries suffice:

1. **Output negation.** Replacing `f` by `-f` preserves all squared Fourier coefficients and every influence. Therefore assume
   \[
   1\le k:=|A|\le N/2.
   \]

2. **Cube translation.** Replacing `f(x)` by `f(x+y)` multiplies `\widehat f(S)` by the sign `\chi_S(y)` and permutes no edge directions, so both `H_2` and `I` are unchanged. Choosing `y in A`, assume
   \[
   0\in A.
   \]

Thus a complete search at fixed minority size `k` needs only the

\[
\binom{N-1}{k-1}
\]

subsets containing zero. No unproved symmetry quotient is used.

For `n<=4`, enumerating every such set for every `1<=k<=N/2` is already tiny. The exact checked representative counts are

\[
1,\ 4,\ 64,\ 16384
\]

for `n=1,2,3,4` respectively.

In each dimension the only equality state against the one-point candidate is `k=1`.

Q\equiv0\pmod{16}.
