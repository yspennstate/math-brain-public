# 5. `P03-PARTIAL-STAR-SCALAR-DECOMPOSITION-133` — PROVED

Define the aligned correlation functional

`A_d(h) = Σ_T d(p_T,q_T)`

and the within-`U` randomized correlation functional

`D_U(h) = (1/|U|) Σ_{a in U} Σ_T d(p_T,q_{T+a})`.

Equivalently, if `C` runs over cosets of `U` in `W`, then

`D_U(h) = Σ_C (1/|U|) Σ_{T,V in C} d(p_T,q_V)`.

The complete star-block functional is

`L_U(h) = H_nat(h) - E_{a in U} H_nat(h q_a) + E_{a in U} H_nat(q_a)`.

Every nonzero star phase has quadratic rank two, while `q_0=1`. Hence

`E_a H_nat(q_a) = 2 ln2 (1 - 1/|U|)`.

Now use

`e(p,q) = (h0(p)+h0(q))/2 + d(p,q)`.

In the difference between aligned pairing and `U`-randomized pairing, the marginal entropy terms cancel exactly inside every `U`-coset. Therefore

`L_U(h) = A_d(h) - D_U(h) + 2 ln2 (1 - 1/|U|)`.

This is an exact signed identity. It holds for every Boolean `h`, every actual coordinate `b`, and every nonzero star-direction subspace `U`. No absolute values, independence assumptions, or asymptotic limits are used.

For `U=W`, this reduces to the complete-star formula used in claim 126. The new point is that the identity remains exact for the shrinking or conditional stars needed by an actual rank-building ordering of the full quadratic layer.

# 6. `P03-PARTIAL-STAR-COMPARATOR-RANK-GEOMETRY-134` — PROVED

Let the current comparator mask be a pure quadratic phase `q_A`. Relative to the coordinate split `b | W`, write its alternating matrix as

`A = [[0, r^T], [r, B]]`,

where `B` is alternating on `W` and `r in W`.

Let

`delta = 1_{ r notin im(B) }`,

`theta_U(r,B) = | U intersect (r + im(B)) | / |U|`.

Then the exact partial-star comparator cost is

`L_U(q_A) = 2 ln2 [ delta + theta_U(r,B) - 1/|U| ]`.

In particular it is always nonnegative.

## 6.1 Rank classification

Let `k=dim ker(B)`. Since `B` is alternating,

`im(B) = ker(B)^perp`.

If `r in im(B)`, write `r=Bz`. A congruence change of variables adding `z` to the distinguished coordinate decouples that coordinate from `B`, so

`rank(A)=rank(B)`.

If `r notin im(B)`, then the functional `x -> r dot x` is nonzero on `ker(B)`. The kernel equations for `A` show that the new distinguished coordinate cannot occur in a kernel vector with coefficient one, while `ker(B)` loses exactly one dimension by imposing `r dot x=0`. Hence

`rank(A)=rank(B)+2`.

Therefore

`rank(A)=rank(B)+2 delta`.

Adding a star mask `q_a` replaces `r` by `r+a`. Averaging over `a in U`, the fraction for which the rank does **not** gain two is exactly `theta_U(r,B)`. Hence

`E_a rank(A+a) = rank(B) + 2(1-theta_U)`.

Also

`E_a rank(q_a) = 2(1-1/|U|)`.

Since quadratic-phase Fourier entropy equals `rank * ln2`, subtraction gives exactly

`L_U(q_A) = 2 ln2 [delta + theta_U - 1/|U|]`.

## 6.2 Positivity

If `delta=0`, then `r in im(B)`, so `a=0` already lies in the intersection defining `theta_U`; hence `theta_U >= 1/|U|`.

If `delta=1`, then

`delta + theta_U - 1/|U| >= 1-1/|U| >= 0`.

Thus the comparator block cost is pointwise nonnegative, with no averaging over the current mask ensemble required.

## 6.3 Exact support interpretation

A quadratic phase with alternating matrix `B` has squared Fourier spectrum uniform on an affine coset of `im(B)`. The two restrictions of `q_A` have supports differing by the shift `r`.

Therefore the aligned term is exactly

`A_d(q_A) = 2 ln2 * delta`.

The within-`U` randomized term is exactly

`D_U(q_A) = 2 ln2 * (1-theta_U)`.

Thus the two pieces of the comparator credit have a direct code/rank meaning:

- `delta=1` is the rank-growth / disjoint-support aligned event;
- `1-theta_U` is the failure of a random allowed star shift to re-enter the comparator support coset.

Substituting these two identities into Section 5 reproduces the rank formula exactly.

This is the desired low-degree signed geometry: the comparator is not a featureless baseline but an explicit support-intersection/rank process.

# 7. `P03-CONDITIONAL-STAR-CORRELATION-LEDGER-135` — PROVED IDENTITY / OPEN PAYMENT

For any current pure quadratic comparator mask `q_A`, the exact paired block response is

`Delta_U(f;A) = L_U(f q_A) - L_U(q_A)`.

By Section 5, the universal star baseline `2 ln2(1-1/|U|)` cancels **before any estimate**, giving

`Delta_U(f;A)`

`= [ A_d(f q_A) - A_d(q_A) ]`

`  - [ D_U(f q_A) - D_U(q_A) ]`.

Using the exact rank geometry from Section 6,

`Delta_U(f;A)`

`= [ A_d(f q_A) - 2 ln2 delta ]`

`  - [ D_U(f q_A) - 2 ln2(1-theta_U) ]`.

This is the new conditional signed star formula. The comparator rank-growth and support-reentry credits are retained explicitly rather than bounded separately.

## 7.1 Exact star ordering of the full quadratic layer

Order actual coordinates `1,...,n`. At stage `k`, let

`U_k = span{ e_{k+1},...,e_n }`.

Let `M_{k-1}` be the quadratic mask space generated by all edges whose smaller endpoint is `< k`. Appending the complete star at coordinate `k` enlarges it to `M_k`.

Then exact paired telescoping gives

`H_nat(f) - R_2(f)`

`= Σ_{k=1}^{n-1} E_{A in M_{k-1}} Delta_{U_k}(f;A)`,

where

`R_2(f) = E_Q [ H_nat(f q_Q) - H_nat(q_Q) ]`

is the residual after the complete quadratic mask layer. Affine masks are harmless because multiplying by a character only permutes Fourier coefficients.

Combining with the previous formula, the complete quadratic-layer expenditure is exactly

`Σ_k E_A { [A_d(fq_A)-A_d(q_A)] - [D_{U_k}(fq_A)-D_{U_k}(q_A)] }`.

This is an **identity**, not yet a universal `O(J)` bound.

## 7.2 Exact remaining quadratic-layer payment

A sufficient and exact low-degree target is now

`Σ_{k=1}^{n-1} E_{A in M_{k-1}}`

`{ [A_d(fq_A)-A_d(q_A)] - [D_{U_k}(fq_A)-D_{U_k}(q_A)] } <= C J(f)`.

Call this `P03-CONDITIONAL-STAR-CORRELATION-PAYMENT-135-OPEN`.

This is sharper than the previous abstract conditional budget because every term is now explicit:

# 8. `P03-QUADRATIC-ENDPOINT-TWOSIDED-136` — PROVED / NON-CLOSING

The preceding report proved a one-sided collision-rigidity statement for the completed quadratic ensemble. This run sharpens it to a two-sided constant endpoint bound.

Let `Q` be uniform over homogeneous quadratic forms on `F_2^n`, let `q_Q` be its Boolean phase, and put `N=2^n`. Then

`R_2(f) = E_Q[ H_nat(f q_Q) - rank(A_Q) ln2 ]`.

For every Boolean `f`,

`|R_2(f)| <= ln(3-2/N) < ln 3`.

## 8.1 Exact averaged fourth collision

For any Boolean `h`, let

`C(h)=Σ_S hhat(S)^4`.

Fourier expansion gives

`C(h)=N^{-3} Σ_{x,a,b} h(x) h(x+a) h(x+b) h(x+a+b)`.

For `h=f q_Q`, averaging over all quadratic `Q` kills the parallelogram unless `a` and `b` are linearly dependent over `F_2`. Over `F_2`, this means exactly

`a=0`, or `b=0`, or `a=b`.

There are `3N-2` ordered pairs `(a,b)` of this type. In each surviving case the physical points pair, so the Boolean `f` product is `+1`. Therefore

`E_Q C(f q_Q) = (3N-2)/N^2 = 3/N - 2/N^2`.

For the comparator quadratic phase, its spectrum is uniform on `2^rank(A_Q)` points, so

`C(q_Q)=2^{-rank(A_Q)}`.

Writing `nu=n-rank(A_Q)`, the same identity gives

`E 2^nu = 3-2/N`.

## 8.2 Lower endpoint

Shannon entropy dominates collision entropy:

`H_nat(fq_Q) >= -ln C(fq_Q)`.

Because `-ln` is convex,

`E H_nat(fq_Q) >= -ln E C(fq_Q)`

`= ln N - ln(3-2/N)`.

Also `rank(A_Q) <= n`, hence

`E rank(A_Q) ln2 <= ln N`.

Therefore

`R_2(f) >= -ln(3-2/N)`.

## 8.3 Upper endpoint

Pointwise `H_nat(fq_Q) <= ln N`.

From Jensen applied to `2^nu`,

`2^{E nu} <= E 2^nu = 3-2/N`,

so

`E nu ln2 <= ln(3-2/N)`.

Thus

`E rank(A_Q) ln2 >= ln N - ln(3-2/N)`

and hence

`R_2(f) <= ln(3-2/N)`.

This proves the two-sided endpoint bound.

### Why it does not close anything by itself

This is deliberately marked **NON-CLOSING**. When `J(f)` is as small as `2/N`, an `O(1)` endpoint is enormously larger than `O(J)`. More importantly, a bounded endpoint does not bound cumulative positive expenditure. The result is used only as a normalization and collision-rigidity statement; it is not substituted for the correlation payment in Section 7 or for the global compiler debt.
