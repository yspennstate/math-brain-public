# 5. Exact reduction to an integer linear form in prime logarithms

Fix a nonconstant Boolean `f` on `n<=5` variables and write the unnormalized Walsh transform

\[
W_S=\sum_{x\in\{0,1\}^n}f(x)(-1)^{S\cdot x}.
\]

All `W_S` are even. Put

\[
a_S=|W_S|/2\in\{0,1,\dots,A\}.
\]

Unnormalized Parseval gives

\[
\sum_SW_S^2=N^2,\qquad \sum_Sa_S^2=A^2.
\tag{5.1}
\]

Thus

\[
\widehat f(S)^2=\frac{a_S^2}{A^2}
\]

and, with zero terms interpreted as zero,

\[
\boxed{H_2(f)=2(n-1)-\frac2{A^2}\sum_Sa_S^2\log_2a_S.}
\tag{5.2}
\]

Let `B(f)` be the number of undirected cube edges across which `f` changes. Since each coordinate has `A` undirected edges,

\[
\boxed{I(f)=B(f)/A.}
\tag{5.3}
\]

Define

\[
T(f)=\sum_Sa_S^2\log_2a_S,\qquad R_n=(A-1)^2\log_2(A-1).
\]

Then the desired candidate domination `C_n^* >= H_2(f)/I(f)` is exactly equivalent to

\[
\boxed{
L_n(f):=A^2(n-1)(B(f)-n)+nT(f)-B(f)R_n\ge0.
}
\tag{5.4}
\]

For `n<=5`, every positive `a_S<=16` and `A-1<=15` factors over

\[
\mathcal P=\{2,3,5,7,11,13\},
\]

so

\[
L_n(f)=\sum_{p\in\mathcal P}e_p(f)\log_2p
\tag{5.5}
\]

with integer coefficients `e_p(f)`; the rational first term in (5.4) is included as the `log_2 2=1` coefficient. Exact equality is decidable by unique factorization: `L_n(f)=0` iff all `e_p=0`.

For strict signs the checker uses only integer arithmetic. Put `Q=2^20`. For each odd prime `p`, compute the exact integer `p^Q` and set

\[
k_p=\operatorname{msb}(p^Q)=\lfloor Q\log_2p\rfloor.
\]

Hence exactly

\[
\frac{k_p}{Q}\le\log_2p<\frac{k_p+1}{Q}.
\tag{5.6}
\]

Positive coefficients in (5.5) use the lower endpoint, negative coefficients the upper endpoint, while `log_2 2=1` is exact. Therefore a positive integer lower numerator proves `L_n(f)>0` with no floating-point decision. Every non-tie in the certified scan has such a positive lower numerator and there are zero interval-overlap cases.
