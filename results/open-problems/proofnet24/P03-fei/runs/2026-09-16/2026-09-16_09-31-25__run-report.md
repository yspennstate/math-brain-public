# 5. `P03-BOREL-HADAMARD-FEATURE-154` — PROVED

This theorem identifies the previous Hadamard RKHS kernel directly with Borel time.

Recall the exact two-output Hadamard entropy contribution `e(p,q)`,

`h0(x)=-x ln x`,

`d(p,q)=e(p,q)-(h0(p)+h0(q))/2`,

and the complementary kernel

`K(p,q)=(p+q)ln2-d(p,q)`.

The preceding run proved

`d^2 K/(dp dq)`
` = [1/(4 sqrt(pq))] log((sqrt(p)+sqrt(q))/|sqrt(p)-sqrt(q)|)`

for `p,q>0`, off the diagonal, and `K(p,0)=K(0,q)=0`.

For `s>0` define the nonnegative Borel cosine-deficit feature

`phi_s(p)=1-cos( (s/2) sqrt(p) )`, `p>=0`.

Then

`boxed:`

`K(p,q)=8 integral_0^infinity phi_s(p) phi_s(q) ds/s^3`.       (5.1)

Consequently an explicit real Hilbert feature map is

`Phi(p)(s)=sqrt(8) phi_s(p) s^(-3/2)`

in `L^2((0,infinity),ds)`.

Moreover

`boxed:`

`d(p,q)=4 integral_0^infinity [phi_s(p)-phi_s(q)]^2 ds/s^3`.  (5.2)

## Proof

The integral in (5.1) is absolutely convergent. Near zero,

`phi_s(p)=s^2 p/8+O(s^4 p^2)`,

so the product divided by `s^3` is `O(s)`. At infinity each factor is bounded by two, giving an `O(s^-3)` tail.

Let the right side of (5.1) be `K_B(p,q)`. It vanishes on either coordinate axis. For `p,q>0`, first work with a finite upper cutoff and then pass by Abel regularization. Since

`partial_p phi_s(p)= [s/(4 sqrt p)] sin((s/2)sqrt p)`,

one obtains

`partial_p partial_q K_B`

`= [1/(2 sqrt(pq))] integral_0^infinity`

`    sin((s/2)sqrt p) sin((s/2)sqrt q) ds/s`.

The convergent cosine-difference identity gives

`integral_0^infinity sin(as)sin(bs) ds/s`
` = (1/2) log((a+b)/|a-b|)`

for positive unequal `a,b`. Therefore

`partial_p partial_q K_B`
` = [1/(4 sqrt(pq))]`
`    log((sqrt p+sqrt q)/|sqrt p-sqrt q|)`.

This is exactly the mixed derivative of `K`. Both kernels vanish on the coordinate axes, so integrating the mixed derivative from the axes proves (5.1); continuity gives the diagonal and zero endpoints.

Finally,

`K(p,p)+K(q,q)-2K(p,q)=2d(p,q)`

because `K(p,p)=2p ln2`. Apply (5.1) to this polarization identity to obtain (5.2).

The Borel one is adapted to the historical R16/R32 expenditure because it keeps the actual resolvent time `s` visible.
