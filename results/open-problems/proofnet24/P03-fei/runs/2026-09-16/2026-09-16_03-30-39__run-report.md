`H_2(f) <= C I(f)`

`I(f)=sum_i Pr[f(x) != f(x^i)]`.

Zero Fourier terms contribute zero.

`H_2(F)=H_2(f)` and `I(F)=J(f):=sum_i min(I_i(f),1-I_i(f))`.

# 2. Quadratic multiplication is a flat four-point Fourier transform

Work in `F_2^n` coordinates. For `i<j`, put

`q_ij(x)=(-1)^(x_i x_j)`.

On the two gate bits it has values `(1,1,1,-1)` and Fourier vector

`(1/2, 1/2, 1/2, -1/2)`.

Therefore multiplication by `q_ij` acts, for every fixed outside Fourier label `T subset [n]\{i,j}`, on the four-vector

`v_T=(hat h(T union U))_{U subset {i,j}}`

by a real orthogonal `4 x 4` matrix all of whose entries have absolute value `1/2`.

Let `m_T=||v_T||_2^2`. If `m_T>0`, let

`p_T(U)=hat h(T union U)^2/m_T`

and let `p'_T` be the corresponding four-point distribution after multiplying by `q_ij`. Orthogonality preserves every `m_T`, and

`H_nat(h)=sum_T m_T log(1/m_T)+sum_T m_T H(p_T)`.                 (2.1)

The first term is unchanged by the quadratic gate.

This exact flatness is special to a degree-two monomial. A degree `q>2` monomial phase has one large Fourier coefficient and the rest of size `2^(1-q)`; no uniform flat-transform conclusion is claimed there.

# 3. Four-point entropic uncertainty — self-contained proof

Let `U` be real orthogonal `4 x 4` with `|U_ab|=1/2`. For a real unit vector `x`, set `p_a=x_a^2` and `q_b=(Ux)_b^2`. Then

`H(p)+H(q) >= log 4 = 2 log 2`.                                  (3.1)

Proof. `||U||_{1->infinity}=1/2` and `||U||_{2->2}=1`. Riesz–Thorin gives, for `1<=r<=2` and `r'=r/(r-1)`,

`||Ux||_{r'} <= 4^(1/2-1/r) ||x||_r`.                           (3.2)

At `r=2` both sides are one. For a unit vector `z`,

`d/dr log ||z||_r |_{r=2} = -H((z_a^2)_a)/4`.

Also `(r')'|_{r=2}=-1`. Differentiate the logarithm of (3.2) from the left at the equality endpoint. The derivative of the left logarithmic ratio is `[H(p)+H(q)]/4`; the derivative of the right exponent is `(log4)/4`. Because the inequality holds to the left and is equality at `2`, the left derivative is at least the right derivative. This proves (3.1).

No asymptotic theorem or positivity assumption is used.

# 4. `P03-QUADRATIC-UNCERTAINTY-DEFICIT-115 — PROVED`

Define

`U_ij(h) := log 2 + (1/2)[H_nat(h)-H_nat(h q_ij)]`.              (4.1)

Define also

`C_ij(h):=sum_T m_T H(p_T)`.

If `S` is a spectral random subset with `Pr[S=A]=hat h(A)^2`, then

`C_ij(h)=H(1_{i in S},1_{j in S} | S\{i,j})`.                    (4.2)

**Theorem.** For every real unit-`L^2` phase `h`, hence for every Boolean phase,

`0 <= U_ij(h) <= C_ij(h)`.                                       (4.3)

Proof. By (2.1),

`U_ij(h)=sum_T m_T [log2 + (H(p_T)-H(p'_T))/2]`.

For the lower bound, `H(p'_T)<=log4=2log2`. For the upper bound, (3.1) gives `H(p'_T)>=2log2-H(p_T)`. Thus every bracket lies between `0` and `H(p_T)`; average with the nonnegative masses `m_T`.

Now let `M` be **any** current mask code not containing `q_ij` and define the exact paired spectral-entropy response

`R_M(f)=E_{m in M} H_nat(fm)-E_{m in M} H_nat(m)`.

For `M'=M direct-sum <q_ij>`, uniform averaging over the new generator bit gives the exact signed recurrence

`R_M(f)-R_M'(f)=E_{m in M}[ U_ij(fm)-U_ij(m) ]`.                 (4.4)

The comparator term `-U_ij(m)` is always nonpositive and is a real signed **credit**. It is not discarded. This is the new entropy-domain counterpart of the R16/R32 signed gate ledger.

# 5. `P03-FIRST-QUADRATIC-GATE-PAYMENT-116 — PROVED`

Immediately before the first quadratic monomial, `M=RM(1,n)`, so every mask is a character up to a global sign. For a character `chi`,

`H_nat(chi)=0`, while `H_nat(chi q_ij)=2log2`.

Thus `U_ij(chi)=0`. Multiplication by a character permutes Fourier coefficients and commutes with multiplication by `q_ij`, so `U_ij(f chi)=U_ij(f)`. Therefore the exact first quadratic gate expenditure is

`R_RM(1)(f)-R_{RM(1)+<q_ij>}(f)=U_ij(f)`.                       (5.1)

Consequently every possible first quadratic gate is nonnegative in Shannon entropy and

`0 <= U_ij(f) <= C_ij(f)`.                                      (5.2)

This does not contradict `P03-ACTUAL-CENTRAL-MONOTONICITY-NOGO-67`, which concerns the central resolvent limit, not the integrated Shannon gate response.

For a Boolean phase, the spectral marginal identity is

`Pr[i in S]=I_i(f)`.

Hence

`C_ij(f) <= h(I_i(f))+h(I_j(f))`,                               (5.3)

where `h(x)=-x log x-(1-x)log(1-x)` is binary entropy in nats.

Gauge first, so all `I_i<=1/2` and `J=sum_i I_i`. Averaging uniformly over unordered pairs,

`E_{pairs} U_ij(f) <= (2/n) sum_i h(I_i) <= 2 h(J/n)`.           (5.4)

If `J=0`, the gauged phase is constant. Otherwise a nonconstant Boolean phase has at least one disagreeing undirected cube edge, so `J>=2/N=2^(1-n)`. Using `h(x)<=x log(e/x)` and `1+log n<=n`,

`2h(J/n) <= (2+2log2) J < 3.387 J`.                             (5.5)

Therefore

`E_{pairs}[first quadratic gate expenditure] <= (2+2log2)J`,

and in particular **there exists a quadratic monomial that can be placed first with signed Shannon expenditure at most `(2+2log2)J` nats**.

The degree-two monomials form a basis of `RM(2,n)/RM(1,n)`, so choosing which generator is first is a legitimate within-degree reorder. Completed degree-two and later degree-block endpoints are unchanged. First-separator labels change, but exact telescoping remains valid.

Scope: this pays one entire first quadratic gate, including every relation weight and every alternating collision order inside that gate's R16/R32 Borel function. It is not a payment of the complete quadratic layer and is not automatically combined with already-reserved shell credits.

# 7. `P03-DISJOINT-QUADRATIC-MATCHING-118 — PROVED / NON-CLOSING`

Let `{i_r,j_r}`, `r=1,...,m`, be pairwise disjoint coordinate pairs and append those quadratic monomials after `RM(1,n)`.

`U_{i_r j_r}(m)=0`.                                               (7.1)

The same earlier nonlinear mask is constant on physical `i_r`- and `j_r`-edges, so the source influences in those two coordinates equal the original influences. The exact recurrence (4.4) gives

`R_{r-1}(f)-R_r(f) <= h(I_{i_r}(f))+h(I_{j_r}(f))`.

`R_0(f)-R_m(f) <= sum_r [h(I_{i_r})+h(I_{j_r})]`.                 (7.2)

The missing mechanism is precisely the nonzero comparator credit `-U_ij(m)` created by **overlapping / rank-building quadratic masks**, or its equivalent signed R16/R32 first-separator cancellation.
