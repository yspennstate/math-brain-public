# 5. `P03-HADAMARD-SCALAR-SANDWICH-129` — PROVED

Set

\[
h(x)=-x\ln x,\qquad h(0)=0,
\]

and

\[
d(p,q)=e(p,q)-\frac12[h(p)+h(q)].
\tag{5.1}
\]

Then for every `p,q>=0`,

\[
\boxed{
(\ln2)(\sqrt p-\sqrt q)^2
\le d(p,q)
\le(\ln2)|p-q|.
}
\tag{5.2}
\]

Also, defining

\[
k(p,q)=(p+q)\ln2-d(p,q),
\tag{5.3}
\]

one has

\[
\boxed{0\le k(p,q)\le2(\ln2)\sqrt{pq}.}
\tag{5.4}
\]

## 5.1 Upper bound

By homogeneity, assume `p>=q`, `p>0`, and put `t=sqrt(q/p)` in `[0,1]`. The desired upper bound is equivalent to `F(t)>=0`, where

\[
F(t)=(1+t)^2\ln(1+t)+(1-t)^2\ln(1-t)-2t^2\ln t-4t^2\ln2.
\tag{5.5}
\]

Using `0 ln0=0`, `F(0)=F(1)=0`. On `(0,1)`,

\[
F''(t)=2\ln\frac{1-t^2}{16t^2},
\tag{5.6}
\]

\[
F'''(t)=\frac4{t^3-t}<0.
\tag{5.7}
\]

Thus `F''` decreases strictly from `+infinity` to `-infinity` and has one zero. Moreover `F'(0+)=0` and `F'(1-)=-4 ln2<0`. Hence `F'` first rises and then falls, crossing zero once; `F` rises from zero and falls back to zero. Therefore `F>=0`.

## 5.2 Exact complement identity

Put

\[
P=\frac{(\sqrt p+\sqrt q)^2}{2},
\qquad
Q=\frac{(\sqrt p-\sqrt q)^2}{2}.
\tag{5.8}
\]

A direct second-Hadamard substitution gives

\[
\boxed{d(p,q)+d(P,Q)=(p+q)\ln2.}
\tag{5.9}
\]

Also

\[
|P-Q|=2\sqrt{pq}.
\tag{5.10}
\]

Applying the upper bound to `(P,Q)` yields

\[
d(P,Q)\le2(\ln2)\sqrt{pq}.
\]

Using (5.9) proves both the lower bound in (5.2) and (5.4). This is an exact signed complement identity; the complement is not discarded before the estimate.
