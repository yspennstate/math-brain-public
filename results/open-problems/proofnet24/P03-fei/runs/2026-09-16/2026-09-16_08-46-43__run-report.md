# 5. `P03-COSINE-MACWILLIAMS-BRIDGE-148` — PROVED

This is the main new identity.

Identify the physical truth-table positions with `V=F_2^n`, `N=2^n`. Use the normalized Walsh transform

`fhat(xi)=N^(-1) sum_{x in V} f(x) (-1)^(xi dot x)`.

Let

`C_0={A subset V : |A| even, xor A=0}`.

For `theta=s/N`, set

`rho_w(s)=sin(theta)^w cos(theta)^(N-w)`.

## 5.1 Exact shell projector and Krawtchouk form

For an even integer `w`, define

`S_w(f)=sum_{A subset V, |A|=w, xor A=0} f_A`,

where `f_A=product_{x in A} f(x)`.

Character projection of the XOR constraint gives

`S_w(f) = (1/N) sum_xi K_w(t_xi;N)`,

where

`t_xi=(N-N fhat(xi))/2`

is the number of negative entries of `f chi_xi`, and

`K_w(t;N)=[z^w](1+z)^(N-t)(1-z)^t`

is the binary Krawtchouk polynomial.

In particular the exact number of XOR-zero even supports in shell `w` is

`M_w=(1/N)[ C(N,w) + (N-1)(-1)^(w/2) C(N/2,w/2) ]`.

Thus the signed number of frustrated relations in shell `w` is explicitly

`((-1)^(w/2)/2)[M_w-S_w(f)]`.

This preserves dual-code multiplicity rather than replacing it by a shell cardinality upper bound.

## 5.2 Exact cosine collapse of the full R32 parity sum

For each `xi`, expand directly

`product_x [ cos(theta) + i f(x)(-1)^(xi dot x) sin(theta) ]`.

Its real part selects the even subsets and supplies the sign `(-1)^(|A|/2)`. But every factor is an exponential of a sign, so the product is

`exp( i theta sum_x f(x)(-1)^(xi dot x) ) = exp(i s fhat(xi))`.

Averaging over `xi` projects onto `xor A=0`. Therefore

`sum_{A in C_0} f_A (-1)^(|A|/2) rho_|A|(s)
 = (1/N) sum_xi cos(s fhat(xi))`.

For the constant truth table, the same expression is

`(1/N)[cos s + N-1]`.

Since `1_{f_A=-1}=(1-f_A)/2`, the fully aggregated parity-frustration response is exactly

`G_0(f;s)
 :=2N sum_{A in C_0, f_A=-1} (-1)^(|A|/2) rho_|A|(s)`

`= cos s + N - 1 - sum_xi cos(s fhat(xi))`.

Equivalently,

`G_0(f;s)=cos s-1 + sum_xi [1-cos(s fhat(xi))]`.

No absolute value has been taken. All `0 mod 4` and `2 mod 4` shells have already canceled with their true common Boolean signs at the same Borel time.

## 5.3 Exact terminal-code MacWilliams transform

Now let `D <= C_0` be any binary linear residual code whose supports are therefore even and XOR-zero, and put

`P=D^perp`.

Orthogonality of binary characters gives the exact code projector

`1_D(a)=|P|^(-1) sum_{u in P} (-1)^(u dot a)`.

Let `sigma_u(x)=(-1)^(u_x)`. Repeating the preceding product calculation yields

`G_D(f;s)
 :=2N sum_{A in D, f_A=-1} (-1)^(|A|/2) rho_|A|(s)`

`= (N/|P|) sum_{u in P} [ cos(s m(sigma_u)) - cos(s m(f sigma_u)) ]`,

where `m(h)=N^(-1)sum_x h(x)`.

Because `D <= C_0 = RM(1,n)^perp`, the dual code `P` contains all affine masks `RM(1,n)`. Quotient by this affine subcode. For one representative `sigma` of a coset in `P/RM(1,n)`, summing over all affine characters merely runs through all Fourier labels. Hence

`G_D(f;s)
 = E_{sigma in P/RM(1,n)} [
     sum_xi cos(s sigmahat(xi))
     - sum_xi cos(s (f sigma)hat(xi)) ]`.

Equivalently,

`G_D(f;s)=E_sigma[ G_0(f sigma;s)-G_0(sigma;s) ]`.

This is the exact terminal-mask paired response **pointwise in Borel time**, with full dual-code multiplicity.

Therefore the live outside-code parity-frustration integrand is

`G_live(f;s)=G_0(f;s)-G_D(f;s)`.

For `D=D_{d_h}`, `P=D^perp` is exactly the actual half-band prefix mask code.

## 5.4 Exact R16 moment coefficients from the same formula

Expanding the cosines and using Parseval `sum_xi fhat(xi)^2=1` cancels the quadratic term. For the full response,

`G_0(f;s)=sum_{r>=2} (-1)^r [1-sum_xi fhat(xi)^(2r)] s^(2r)/(2r)!`.

For the code term,

`G_D(f;s)=sum_{r>=2} (-1)^r E_sigma[
    sum_xi sigmahat(xi)^(2r)
    -sum_xi (f sigma)hat(xi)^(2r)
] s^(2r)/(2r)!`.

Thus the already-defined live R16/R32 coefficient is exactly

`D_{D,r}
 = 1-sum_xi fhat(xi)^(2r)

   +E_sigma sum_xi (f sigma)hat(xi)^(2r)`.

This is a direct algebraic identification of the collision-order bank with the same terminal mask ensemble. It does **not** say that the alternating series may be made positive term-by-term; the odd orders remain refunds.

# 6. Exact Borel entropy identity

The cosine bridge recovers Shannon entropy with the correct natural-log units without any interchange ambiguity.

For `0<=a<=1`, define

`F_a(s)=1-cos(as)-a^2(1-cos s)`.

The numerator is `O(s^4)` at zero and bounded at infinity, so `F_a(s)/s^3` is absolutely integrable. Two integrations by parts give

`integral_0^infinity F_a(s) s^(-3) ds
 = (a^2/2) integral_0^infinity [cos(as)-cos s] s^(-1) ds`.

The convergent cosine-difference Frullani integral is `ln(1/a)`. Hence

`4 integral_0^infinity F_a(s) s^(-3) ds = -a^2 ln(a^2)`.

The `a=0` endpoint follows by continuity.

Since `sum_xi fhat(xi)^2=1`, one has

`G_0(f;s)=sum_xi F_|fhat(xi)|(s)`.

Therefore

`H_nat(f)=4 integral_0^infinity G_0(f;s) s^(-3) ds`.

Likewise, integrating the code identity yields exactly the paired terminal response

`R_D(f)=4 integral_0^infinity G_D(f;s) s^(-3) ds`,

and hence

`H_nat(f)-R_D(f)=4 integral_0^infinity G_live(f;s) s^(-3) ds`.

This makes the old warning completely transparent: a small value of the **integral** of `G_D` does not bound the positive or negative variation of `G_D(s)`.

# 8. `P03-FULL-BOREL-NEGVAR-150` — PROVED

This theorem addresses the user's positive-part warning precisely.

Define the negative Borel variation after full same-time shell aggregation by

`V_-(f)=4 integral_0^infinity max(-G_0(f;s),0) s^(-3) ds`.

Then

`V_-(f) <= 8 D_2(f) <= 16 J(f)`.

## Proof

From Section 7, every scalar `F_a` is nonnegative on `[0,pi]`, so negative variation starts only after `pi`.

For all `s`,

`F_a(s) >= -a^2(1-cos s) >= -2a^2`.

### Case 1: `a^2<=1/2`

Then

`4 integral_pi^infinity (F_a)_- s^(-3) ds
 <= 4 a^2/pi^2`

`<= (8/pi^2) a^2(1-a^2)
 < 8 a^2(1-a^2)`.

### Case 2: `a^2>1/2`

Put `delta=1-a`. Since `F_1=0`, the mean-value theorem and

`|partial_a F_a(s)|
 = |s sin(as)-2a(1-cos s)|
 <= s+4 <= 3s`

for `s>=pi` give

`(F_a(s))_- <= min(2,3 delta s)`.

If `delta<=2/(3pi)`, split at `S=2/(3delta)`:

`4 integral_pi^infinity (F_a)_- s^(-3) ds
 <= 12 delta/pi - 9 delta^2
 < 4 delta`.

Since `a^2>1/2`,

`a^2(1-a^2)=a^2 delta(1+a) >= delta/2`,

so this is at most `8a^2(1-a^2)`.

If `delta>2/(3pi)`, the crude bound gives at most `4/pi^2`, while

`a^2(1-a^2)>=delta/2>1/(3pi)`;

again the factor `8` is more than sufficient.

Thus for every `a in [0,1]`,

`4 integral (F_a)_- s^(-3) ds <= 8a^2(1-a^2)`.

Finally,

`(sum_xi F_a)_- <= sum_xi (F_a)_-`,

so

`V_-(f)<=8 sum_xi fhat(xi)^2[1-fhat(xi)^2]=8D_2(f)<=16J(f)`.

## What this theorem does and does not permit

`4 integral (G_0)_+ s^(-3) ds = H_nat(f)+V_-(f) <= H_nat(f)+16J(f)`.

# 9. `P03-RKHS-COSET-PYTHAGORAS-151` — PROVED

The previous run proved that the Hadamard kernel

`K(p,q)=(p+q)ln2-d(p,q)`

is positive definite, with the exact positive Mellin representation

`K(p,q)=integral p^(1/2+i xi) q^(1/2-i xi) mu(dxi)`.

Therefore there is a real Hilbert space `H_K` and feature map `Phi` with

`<Phi(p),Phi(q)>=K(p,q)`.

The new observation is that the entire Mellin-frequency selector sum can be collapsed before any cutoff.

Fix one ordered quadratic star. Let `W` be the current frequency group and `O<=W` the old-coordinate subgroup. Let `Q=W/O` be its set of cosets. For each coset `C`, define Hilbert vectors

`P_C=sum_{T in C} Phi(p_T)`,

`Q_C=sum_{T in C} Phi(q_T)`.

For the quadratic comparator spectrum `r_T`, define

`C_C=sum_{T in C} Phi(r_T)`.

Let a bar denote the average over cosets, and write

`Var_Q(X)=sum_{C in Q} ||X_C-Xbar||^2`,

`Cov_Q(X,Y)=sum_C <X_C-Xbar,Y_C-Ybar>`.

The subgroup correlations satisfy exactly

`C_O^K=(1/|O|) sum_C <P_C,Q_C>`,

`C_W^K=(1/|W|) <sum_C P_C, sum_C Q_C>`.

Hence

`C_W^K-C_O^K = -(1/|O|) Cov_Q(P,Q)`.

For the comparator the same formula gives

`G_comp=-(1/|O|) Var_Q(C)`.

Therefore the paired block response is

`Delta = (1/|O|)[Var_Q(C)-Cov_Q(P,Q)]`.

Now put

`M_C=(P_C+Q_C)/2`,

`D_C=(P_C-Q_C)/2`.

The real-Hilbert polarization identity gives

`Cov_Q(P,Q)=Var_Q(M)-Var_Q(D)`.

Thus the exact all-frequency Pythagoras form is

`Delta = (1/|O|)[ Var_Q(C)-Var_Q(M)+Var_Q(D) ]`.

This keeps the signed selector/re-entry term as the variance difference

`Var_Q(C)-Var_Q(M)`

and the nonnegative source-difference term as `Var_Q(D)`.

The comparator variance is already known exactly from `P03-ORDERED-COMPARATOR-CORRELATION-144`:

`Var_Q(C)/|O| = 2 ln2 * 2^(-eta) (1-2^(-kappa0))`,

where `kappa0=dim ker C_matrix` and `eta` is the residual alternating nullity from the previous report.

There is also an exact scalar geometry identity

`||Phi(p)-Phi(q)||^2=2d(p,q)`

because `K(p,p)=2p ln2`. Consequently Cauchy within each coset yields

`Var_Q(D)/|O| <= A_d/2`.

This recovers the absolutely payable part without any Mellin cutoff, while displaying exactly what must remain signed: one has to compare the source midpoint coset variance `Var_Q(M)` with the comparator rank variance `Var_Q(C)` across the ordered stars.

The complete quadratic-layer sub-obligation can therefore be written equivalently as

`sum_k E_B [Var(C_k)-Var(M_k)+Var(D_k)]/|O_k| <= C J(f)`.

This is an exact reformulation, not a weaker target. It does not pay the higher-degree compiler layers.
