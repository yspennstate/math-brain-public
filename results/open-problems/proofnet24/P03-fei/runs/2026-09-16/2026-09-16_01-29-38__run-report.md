# 3. `P03-CYCLE-PLANE-SIGN-SUPPLY-103` — PROVED

\tag{3.4}

## 3.2 Cycle construction

Fix any ordering `a_1,\dots,a_w`. Choose
\[
c\in V\setminus A
\]
and a starting point `z_1=z`. Define recursively
\[
z_{i+1}=a_i+z_i+c
\qquad(1\le i\le w),
\tag{3.5}
\]
where addition is in `\mathbb F_2^n`.

Because `A\in C_0`,
\[
\bigoplus_{i=1}^w a_i=0,
\]
and because `w` is even, iterating (3.5) gives
\[
z_{w+1}=z_1+\bigoplus_i a_i+(w\bmod2)c=z_1.
\tag{3.6}
\]
Thus the recurrence closes into a cycle.

Call `(c,z_1)` **admissible** if
\[
z_i\notin A
\qquad(1\le i\le w).
\tag{3.7}
\]
For every admissible pair define
\[
P_i=\{a_i,c,z_i,z_{i+1}\}.
\tag{3.8}
\]
Equation (3.5) gives XOR zero on `P_i`.

All four points are distinct. We have `a_i\ne c` because `c\notin A`, and `z_i,z_{i+1}\ne a_i` by admissibility. If `z_i=c`, then (3.5) gives `z_{i+1}=a_i\in A`, impossible. If `z_{i+1}=c`, then `z_i=a_i`, impossible. Finally `z_i=z_{i+1}` would imply `a_i=c`. Hence each `P_i` is a genuine four-point affine two-flat and
\[
P_i\cap A=\{a_i\}.
\tag{3.9}
\]

## 3.3 Exact mod-two assembly and Boolean sign

Take symmetric difference over all `P_i`. Each `a_i` occurs once; `c` occurs `w` times and vanishes because `w` is even; every `z_i` occurs twice, once as the incoming and once as the outgoing cycle point. Therefore
\[
\boxed{
P_1\triangle P_2\triangle\cdots\triangle P_w=A.
}
\tag{3.10}
\]
Multiplying the actual Boolean signs gives
\[
\prod_{i=1}^w f_{P_i}=f_A=-1.
\tag{3.11}
\]
Thus an odd number of the `P_i` are frustrated. Since `w` is even, an odd number are also **unfrustrated**. In particular every admissible parameter cycle contains at least one index with
\[
f_{P_i}=+1.
\tag{3.12}
\]
This is a signed identity on the same original Boolean phase; no independent signs are introduced.

## 3.4 Counting admissible cycles

Define prefix XORs
\[
p_{i-1}=a_1+\cdots+a_{i-1},
\qquad p_0=0.
\]
The recurrence gives explicitly
\[
z_i=z_1+p_{i-1}+((i-1)\bmod2)c.
\tag{3.13}
\]
For a fixed `c\notin A`, each condition
\[
z_i=b,
\qquad b\in A,
\]
excludes exactly one value of `z_1`. There are `w^2` pairs `(i,b)`, so a union bound leaves at least
\[
N-w^2
\tag{3.14}
\]
admissible starting values. There are `N-w` choices of `c`. Hence the number of admissible parameter cycles is at least
\[
(N-w)(N-w^2).
\tag{3.15}
\]

## 3.5 Multiplicity of one external plane

Fix one affine plane `P` meeting `A` in exactly one point. If it occurs as `P_i` in a parameter cycle, the index `i` is uniquely determined by the unique point `P\cap A=\{a_i\}`.

The common anchor `c` can be any one of the three points of `P\setminus A`. Once `c` is chosen, `z_i` can be either of the remaining two outside points; `z_{i+1}` is then forced. Given `i,c,z_i`, equation (3.13) determines `z_1` uniquely.

Therefore a fixed external plane appears in at most
\[
3\cdot2=6
\tag{3.16}
\]
parameter cycles.

Every admissible cycle has at least one unfrustrated plane occurrence by (3.12). Dividing (3.15) by the multiplicity bound (3.16) proves (3.4).
