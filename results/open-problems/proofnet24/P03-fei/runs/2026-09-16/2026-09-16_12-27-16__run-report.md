# 4. `P03-FUTURE-OCCUPATION-MONOTONICITY-171` — PROVED

## 4.1 A second exact potential

Define

```text
s_{a,b}
 := E_{M~S(a,b)} 2^{-(nu(M)-kappa(M))}.
```

For fixed `M`, the quantity `2^{-(nu-kappa)}` is the fraction of old-supported covectors lying in `im M`.

Indeed, the restriction map

```text
O -> (ker M)^*,
z |-> [v |-> z dot v]
```

has kernel `O cap (ker M)^perp = O cap im M`. Its image dimension is

```text
nu-kappa,
```

because the annihilator inside `ker M` of every old-supported covector is exactly `ker M cap U`. Hence

```text
|O cap im M|/|O|=2^{-(nu-kappa)}.
```

Averaging yields the interpretation of `s_{a,b}`.

## 4.2 Exact formula in terms of `t`

For `a>=1`, choose a uniform old-supported vector `z`. With probability `2^{-a}` it is zero and is automatically in `im M`. Conditional on `z!=0`, the old-coordinate orbit formula in claim 165 gives

```text
P_M(z in im M)=1-t_{a-1,b}.
```

Therefore

```text
boxed(
s_{a,b}
 = 2^{-a}+(1-2^{-a})(1-t_{a-1,b})
 = 1-(1-2^{-a})t_{a-1,b}.
)
```

For `a=0`, trivially

```text
s_{0,b}=1.
```

## 4.3 `beta` is exactly the same potential one step earlier

Take `M~S(a,b)` and append one new future coordinate. Its connection covector `d` is uniform among covectors supported on `O`. The resulting extension has law `S(a,b+1)`.

The new basis vector `e_new` lies in the image of the extension iff there exists `x in ker M` with `d dot x=1`, equivalently iff `d` does **not** annihilate `ker M`, equivalently iff

```text
d notin im M.
```

Thus `e_new` fails to lie in the image iff `d in im M`. Conditional on `M`, that probability is exactly

```text
2^{-(nu-kappa)}.
```

But the leakage coefficient of a nonzero future Fourier label under `S(a,b+1)` is precisely the probability that the label is not in the comparator image. Hence

```text
boxed(beta_{a,b+1}=s_{a,b}).
```

This also agrees algebraically with the formula from claim 165.

## 4.4 Monotonicity under moving one future coordinate to old

For `b>=1`,

```text
Theta_{a,b}
 = beta_{a,b+1}-beta_{a+1,b}
 = s_{a,b}-s_{a+1,b-1}.
```

We prove this is nonnegative.

If `a=0`,

```text
s_{0,b}=1,
s_{1,b-1}=1-(1/2)t_{0,b-1}.
```

Since `S(0,b-1)` is the zero form, `t_{0,b-1}=2^{-(b-1)}`, so

```text
Theta_{0,b}=2^{-b}>0.
```

Now let `a>=1` and set

```text
c_a=1-2^{-a}.
```

Then

```text
Theta_{a,b}
 = c_{a+1} t_{a,b-1} - c_a t_{a-1,b}.
```

By claim 166 applied to the base ensemble `S(a-1,b-1)`,

```text
t_{a,b-1}-t_{a-1,b}
 = (3/2)
   E_{S(a-1,b-1)}[2^{-2nu}(2^kappa-1)]
 >=0.
```

Also

```text
c_{a+1}-c_a=2^{-(a+1)}>0.
```

Therefore

```text
boxed(
Theta_{a,b}
 = c_{a+1}(t_{a,b-1}-t_{a-1,b})
   +2^{-(a+1)}t_{a-1,b}
 >=0.
)
```

Equivalently, for `a>=1,b>=1`,

```text
boxed(
Theta_{a,b}
 = (3/2)(1-2^{-(a+1)})
   E_{S(a-1,b-1)}[2^{-2nu}(2^kappa-1)]
   +2^{-(a+1)}t_{a-1,b}.
)
```

This is an exact decomposition of the future-occupation coefficient into a re-entry term plus a boundary-isotropic term. No absolute value and no endpoint inference is used.

# 5. `P03-LEAKAGE-TOTAL-VARIATION-172` — PROVED

The new sign theorem upgrades the previous signed leakage telescope to a genuine dimension-free variation theorem for the averaged leakage potential.

For `k=1,...,n`, write


```text

```

We already know

```text
A_{a,b}<=0,
Gamma_{a,b}>=0,
```

and claim 171 now gives

```text
Theta_{a,b}>=0.
```

Hence

```text
(d_k)_+
 <= Gamma_{a,b}P_K+Theta_{a,b}P_U.
```

The key point is that the right side is exactly summable **per original Fourier label**.

Let `z!=0` be a Fourier label, let

```text
m=max supp(z),
p(z)=fhat(z)^2.
```

For every `k<m`, this label belongs to the future class `P_U`; at `k=m` it belongs to the moved-coordinate class `P_K`; for `k>m` it is already old and sees only the nonpositive coefficient `A`.

By claim 171,

```text
Theta_{k-1,n-k}
 = s_{k-1,n-k}-s_{k,n-k-1}.
```

Therefore the full positive occupation coefficient before the label's last coordinate is exposed telescopes:

```text
sum_{k<m} Theta_{k-1,n-k}
 = s_{0,n-1}-s_{m-1,n-m}
 = 1-s_{m-1,n-m}.
```

At the last coordinate,

```text
Gamma_{m-1,n-m}
 = beta_{m-1,n-m+1}-t_{m-1,n-m}
 = s_{m-1,n-m}-t_{m-1,n-m}.
```

Thus the entire nonnegative debit coefficient attached to the spectral atom `z` is exactly

```text
boxed(
1-t_{m-1,n-m}
)
```

and in particular is at most one.

Summing over all nonzero Fourier labels gives the exact component bound

```text
sum_k [Gamma_k P_K(k)+Theta_k P_U(k)]
 = sum_{z!=0} p(z)[1-t_{m(z)-1,n-m(z)}]
 <= sum_{z!=0}p(z)
 = Var(f).
```

Therefore

```text
boxed(
sum_{k=1}^n (L_{k-1}(f)-L_k(f))_+
 <= Var(f).
)
```

After the exact character gauge,

```text
Var(f)
 = sum_{S!=empty} fhat(S)^2
 <= sum_S |S| fhat(S)^2
 = I(f)=J(f),
```

so

```text
boxed(
sum_k (L_{k-1}-L_k)_+ <= J(f).
)
```

This is the desired positive-variation conclusion for the **first-moment leakage sequence**, now proved rather than inferred from the endpoint.
