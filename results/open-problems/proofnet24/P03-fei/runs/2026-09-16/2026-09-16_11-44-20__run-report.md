# 4. `P03-ORDERED-ISOTROPIC-KERNEL-LAW-165` — PROVED

## Statement

For `M~S(a,b)`, sample `V_M` uniformly from `ker M`, conditionally on `M`. Then the unconditional law of `V_M=(x,y) in O direct_sum U` has exactly three orbit values.

Write `d=a+b`. Then

```text
P(V_M=0)=t_{a,b}.
```

For every nonzero pure-future vector `(0,y)`,

```text
boxed(
P(V_M=(0,y))
 = 2^{-a-1} t_{a,b-1}
)
```

when `b>=1`.

For every vector `(x,y)` with `x!=0`,

```text
boxed(
P(V_M=(x,y))
 = 2^{-d} t_{a-1,b}
)
```

when `a>=1`.

Consequently the Fourier transform of this kernel-vector law is

```text
E_M E_{v in ker M} (-1)^{z dot v}
 = P_M(z in im M).
```

Writing `z=(s,t)` with respect to `O direct_sum U`,

```text
P_M(z in im M)=1,                         z=0,
P_M(z in im M)=1-t_{a-1,b},              t=0, s!=0,
P_M(z in im M)=t_{a,b}-2^{-a-1}t_{a,b-1}, t!=0.
```

## Proof: pure-future vectors

Fix `v=(0,y)`, `y!=0`. The condition `Mv=0` is exactly

```text
C y=0.
```

This imposes `a` independent binary equations on the uniform matrix `C`, hence

```text
P(Mv=0)=2^{-a}.
```

Condition on this event and quotient by the radical vector `v`. After a change of basis in `U`, the quotient form is exactly `S(a,b-1)`. Since `v` contributes one radical dimension,

```text
nu(M)=1+nu(M/v).
```

Therefore

```text
P(V_M=v)
 = E[1_{Mv=0} 2^{-nu(M)}]
 = 2^{-a} * (1/2) * t_{a,b-1}.
```

This is the first formula.

## Proof: vectors with nonzero old component

Now let `v=(x,y)` with `x!=0`. The stabilizer of the totally isotropic subspace `U` acts transitively on `V\U`, so it is enough to take `v=(e_1,0)`.

Then `Mv=0` requires

- the `a-1` off-diagonal entries in the first column of `A` to vanish;
- the `b` entries in the first row of `C` to vanish.

These are `d-1` independent bits, so

```text
P(Mv=0)=2^{-(d-1)}.
```

Conditioned on `Mv=0`, quotienting by `v` leaves exactly an `S(a-1,b)` form. Again `nu(M)=1+nu(M/v)`, and hence

```text
P(V_M=v)
 = 2^{-(d-1)} * (1/2) * t_{a-1,b}
 = 2^{-d} t_{a-1,b}.
```

## Proof of the Fourier transform

For fixed `M`, uniform averaging over `ker M` gives

```text
E_{v in ker M} (-1)^{z dot v}
 = 1_{z in (ker M)^perp}
 = 1_{z in im M},
```

because an alternating matrix has `(ker M)^perp=im M` under the standard pairing.

Use the three orbit masses above.

For `t!=0`, the sum over all vectors with `x!=0` cancels in the `y` variable, while the sum over nonzero pure-future vectors is `-1`. Therefore

```text
P(z in im M)
 = t_{a,b}-2^{-a-1}t_{a,b-1}.
```

For `t=0`, `s!=0`, the pure-future contribution is `(2^b-1)2^{-a-1}t_{a,b-1}`, and the sum over `x!=0,y` is `-2^b`. Using normalization of the kernel-vector law gives

```text
P(z in im M)=1-t_{a-1,b}.
```

All multiplicities are exact.

# 6. `P03-RANK-REENTRY-POTENTIAL-BRIDGE-166` — PROVED

This theorem identifies the rank potential increment from moving one coordinate from the totally-isotropic future block to the old block.

## Statement

Let `M~S(a,b)` and write

```text
nu=dim ker M,
kappa=dim(ker M cap U).
```

Then

```text
boxed(
t_{a+1,b}-t_{a,b+1}
 = (3/2) E_{S(a,b)}[2^{-2nu}(2^kappa-1)]
 >=0.
)
```

Thus `t_{a,b}` is monotone under the actual future-to-old coordinate move.

Moreover the previous ordered-star comparator Shannon credit for this same base matrix is

```text
C_comp(M)
 = 2 ln2 * 2^{-nu}(2^kappa-1).
```

Hence

```text
boxed(
t_{a+1,b}-t_{a,b+1}
 = (3/(4 ln2)) E[2^{-nu} C_comp(M)].
)
```

This is a **same-credit bridge**. It does not create an independent reserve.

## Proof: append an old coordinate

Start from `M` on a `d=a+b` dimensional space. To obtain `S(a+1,b)`, append one old coordinate with a connection vector `d` uniform in all of `F_2^d`:

```text
M_old = [ M d ]
        [ d^T 0 ].
```

For an alternating matrix, `im M=(ker M)^perp`, so

```text
P(d in im M | M)=2^{-nu}.
```

If `d in im M`, a congruence transformation reduces the extension to `M direct_sum 0`, hence the new nullity is `nu+1`.

If `d notin im M`, the rank rises by two and the new nullity is `nu-1`.

Therefore

```text
E[2^{-nu_old} | M]
 = 2^{-nu}[2-(3/2)2^{-nu}].
```

## Proof: append a future coordinate

To obtain `S(a,b+1)`, the new future coordinate may connect only to `O`; its connection covector is uniform in the `a`-dimensional subspace of covectors vanishing on `U`.

Restrict these covectors to `ker M`. The image dimension is

```text
nu-kappa,
```

because the annihilator of this restriction map is exactly `ker M cap U`.

Thus

```text
P(d in im M | M)=2^{-(nu-kappa)}.
```

The same rank-two extension dichotomy gives

```text
E[2^{-nu_future} | M]
 = 2^{-nu}[2-(3/2)2^{-(nu-kappa)}].
```

Subtracting and averaging yields

```text
t_{a+1,b}-t_{a,b+1}
 = (3/2)E[2^{-2nu}(2^kappa-1)].
```

Finally, the prior comparator formula is

```text
2 ln2 * 2^{-eta}(1-2^{-kappa}),
eta=nu-kappa,
```

which is exactly

```text
2 ln2 * 2^{-nu}(2^kappa-1).
```

This proves the bridge.

# 7. `P03-SIGNED-LEAKAGE-TELESCOPE-167` — PROVED

The entire ordered quadratic layer has a dimension-free signed first-moment leakage budget.

## Statement

```text
boxed(
```

The sum is signed. No assertion is made about

## Proof

```text
L_0(f)=1-fhat(empty)^2.
```

At `k=n`, `S(n,0)` is the full uniform alternating ensemble. Claim 165 says every nonzero Fourier label has the same leakage coefficient

```text

```

```text

```

so

```text
t_{n-1,0}
 = [2^n/(2^n-1)](1-t_{n,0}),
```

matching the full-ensemble formula from claim 160.


