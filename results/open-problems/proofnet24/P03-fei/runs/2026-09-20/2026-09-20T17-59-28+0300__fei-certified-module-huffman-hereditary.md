## 3. New theorem — certified-module coefficient propagation

Let `D` be a finite full binary tree whose leaves are disjoint nonempty physical coordinate blocks `L` partitioning the active coordinates. Let `d_L` be the depth of leaf `L`.

Assume that for every leaf `L` and every physical outside section `g` reaching `L` there are constants `C_L,K_L` such that

\[
H(g)\le C_L I(g)
\tag{3.1}
\]

and a full physical restriction tree on `L` with

\[
R(g)\le K_L I(g).
\tag{3.2}
\]

Define

\[
c_L(d):=C_L+\rho d,
\tag{3.3}
\]

\[
k_L(d):=
C_L+\rho(d-1)+(K_L-C_L+\rho)2^{-d}.
\tag{3.4}
\]

At `d=0`, formula (3.4) gives `k_L(0)=K_L` exactly.

### Theorem 3.1
For every Boolean root function `f`,

\[
\boxed{
H(f)\le \sum_L c_L(d_L) I_L(f)
}
\tag{3.5}
\]

and there exists a full adaptive physical restriction tree `T` satisfying

\[
\boxed{
R_T(f)\le \sum_L k_L(d_L) I_L(f).
}
\tag{3.6}
\]

No fresh variables, branch independence, symmetry, degree bound, or common controller is assumed. The orientation at an internal module cut is allowed to depend on the actual Boolean section at that node.

### Proof

Prove a stronger statement inductively for every node block `U` of `D` and every physical outside section on `U`. At a leaf, (3.5)-(3.6) are exactly the assumed certificates.

Let an internal node split as `U=A sqcup Y`, with the left and right child decomposition trees already certified. Write `c_L,k_L` for the child-level coefficients before the additional parent depth is added.

For the direct bound, apply (2.1) and the child direct theorem to all `Y`-sections:

\[
H(S_A)
\le
\mathbb E_yH(f_y)+\rho I_Y(f)
\le
\sum_{L\subset A} c_L I_L(f)
+
\rho\sum_{L\subset Y}I_L(f).
\tag{3.7}
\]

Similarly,

\[
H(S_Y)
\le
\sum_{L\subset Y} c_L I_L(f)
+
\rho\sum_{L\subset A}I_L(f).
\tag{3.8}
\]

Shannon subadditivity `H(S_A,S_Y)<=H(S_A)+H(S_Y)` therefore gives

\[
H(f)
\le
\sum_{L\subset U}(c_L+\rho)I_L(f).
\tag{3.9}
\]

Thus every leaf direct coefficient obeys the recurrence

\[
c' = c+\rho.
\tag{3.10}
\]

For hereditary allocation, first query every coordinate of `A`. By complete-block compression and (3.7), the prefix costs at most

\[
\sum_{L\subset A}c_L I_L(f)
+
\rho\sum_{L\subset Y}I_L(f).
\]

At every resulting `A`-section, graft the child hereditary tree on `Y`. Averaging (2.3) gives the actual `A`-first full-tree estimate

\[
R_{A\text{-first}}
\le
\sum_{L\subset A}c_L I_L(f)
+
\sum_{L\subset Y}(k_L+\rho)I_L(f).
\tag{3.11}
\]

The symmetric `Y`-first tree obeys

\[
R_{Y\text{-first}}
\le
\sum_{L\subset A}(k_L+\rho)I_L(f)
+
\sum_{L\subset Y}c_L I_L(f).
\tag{3.12}
\]

Choose the cheaper of these two **actual physical trees**. Since `min{x,y}<=(x+y)/2`,

\[
R_T(f)
\le
\sum_{L\subset U}\frac{c_L+k_L+\rho}{2}I_L(f).
\tag{3.13}
\]

Hence every leaf hereditary coefficient obeys

\[
k'=\frac{c+k+\rho}{2}.
\tag{3.14}
\]

Starting from `c(0)=C_L`, `k(0)=K_L`, recurrence (3.10) gives `c(d)=C_L+rho d`. Substituting this into (3.14) and solving the halving recurrence gives exactly (3.4):

\[
k(d)=C_L+\rho(d-1)+(K_L-C_L+\rho)2^{-d}.
\]

This proves (3.5)-(3.6). QED.

## 4. Universal singleton/pair modules

The theorem becomes unconditional by taking only one- and two-coordinate leaves.

### Lemma 4.1 — exact bases

For a Boolean function on one coordinate, the spectrum is a single atom, so

\[
C_1=K_1=0.
\]

For every Boolean function on two coordinates,

\[
H(f)\le2I(f)
\tag{4.1}
\]

and there is a full tree with

\[
R_T(f)\le I(f).
\tag{4.2}
\]

Proof: up to global sign, the negative truth-set has size `0,1,2`. Size zero is constant. Size one is the one-point defect: its squared Fourier law is uniform on four atoms, hence `H=2`; both physical influences are `1/2`, so `I=1`; querying either coordinate has `B_i=1` and leaves one-coordinate functions, hence `R=1`. If the negative set has size two, the points are adjacent or opposite; the function is respectively a character or a parity character, so `H=R=0`. This exhausts the two-variable Boolean functions. QED.

Thus a singleton leaf has `(C,K)=(0,0)` and a pair leaf has `(C,K)=(2,1)`.

For a singleton module at depth `d`, Theorem 3.1 gives

\[
k_{\rm sing}(d)=\rho\left(d-1+2^{-d}\right).
\tag{4.3}
\]

For a pair module at depth `d`,

\[
\boxed{
k_{\rm pair}(d)
=2+\rho(d-1)+(\rho-1)2^{-d}.}
\tag{4.4}
\]

The direct pair coefficient is

\[
c_{\rm pair}(d)=2+\rho d.
\tag{4.5}
\]

Partitioning an arbitrary finite active coordinate set into pairs and at most one singleton therefore gives an explicit all-dimensional, fresh-variable-free hereditary certificate. The coefficient now depends on the **influence-weighted module depths**, not on the maximum depth.

## 6. Huffman pair-profile corollary

Assume for clarity that the active coordinate count is even and pair the coordinates into modules `P_1,...,P_s`. Put

\[
q_r:=\frac{I_{P_r}(f)}{I(f)},
\qquad \sum_rq_r=1.
\tag{6.1}
\]

For a module tree with pair depths `d_r`, (4.4) gives the exact certified ratio

\[
\frac{R_T(f)}{I(f)}
\le
2-\rho
+\rho\sum_rq_rd_r
+(\rho-1)\sum_rq_r2^{-d_r}.
\tag{6.2}
\]

### Corollary 6.1 — Huffman form

If `s>=2`, choose a binary Huffman tree for `q`. Its weighted average length obeys

\[
\sum_rq_rd_r\le H_2(q)+1,
\]

and every codeword has depth at least one, so

\[
\sum_rq_r2^{-d_r}\le\frac12.
\]

Therefore

\[
\boxed{
R_T(f)
\le
\left[
\rho H_2(q)+\frac{3+\rho}{2}
\right]I(f),
}
\tag{6.3}
\]

where

\[
\frac{3+\rho}{2}
=2.942695040888963\ldots .
\]

This is dimension-free whenever the **pair-influence profile entropy** is bounded, regardless of the number of physical coordinates.

A second explicit code bound is sometimes sharper. Set provisional Shannon lengths

\[
\ell_r=\left\lceil\log_2\frac1{q_r}\right\rceil.
\]

Since `sum 2^{-ell_r}<=1`, a prefix tree exists; pruning unused unary branches only decreases every depth. The pair coefficient (4.4) is increasing in `d`, and `2^{-ell_r}<=q_r`, so

\[
k_{\rm pair}(\ell_r)
\le
2+\rho\log_2\frac1{q_r}+(\rho-1)q_r.
\]

Hence

\[
\boxed{
R_T(f)
\le
\left[
\rho H_2(q)+2+(\rho-1)\sum_rq_r^2
\right]I(f).
}
\tag{6.4}
\]

One may take the better of (6.3) and (6.4), and one may optimize the initial physical pairing as well. For odd active dimension, Theorem 3.1 applies verbatim with one singleton module; no dummy/fresh coordinate is appended.

## 7. Decisive limitation of pure code optimization

The module code tree alone still cannot close FEI.

Take an even number `n=2s` of coordinates with uniform physical influences and pair them arbitrarily. Then every pair module has weight `q_r=1/s`. For every binary module tree, Kraft/Huffman gives

\[
\frac1s\sum_rd_r\ge\log_2s.
\]

Since the last term in (4.4) is nonnegative,

\[
\frac1s\sum_rk_{\rm pair}(d_r)
\ge
\rho\log_2s+2-\rho,
\tag{7.1}
\]

which diverges with `s`.

This is only a lower bound on the **analytic certificate produced by this code compiler**, not on the true optimal hereditary allocation. Indeed a nondegenerate bent quadratic has uniform physical influences but the inherited exact quadratic-rank theorem gives hereditary ratio `R/I=1`. Therefore no choice of pair grouping or Huffman tree can remove the logarithm from this compiler by coding optimization alone. A full FEI proof still needs a structure-sensitive early stop (quadratic/symmetric/etc.) or a new cross-scale rebate that recognizes such functions before paying all code depths.

This is a decisive obstruction to the narrow proposal “remove the logarithm merely by rebalancing the coordinate tree.” It is not a counterexample to FEI.
