## 3. #5 ADD A PARAMETER AND DIFFERENTIATE IN IT — exact internal-rank profile

The fixed-size component proof in Claims 318--319 deliberately uses the worst-case external prefix

`p0 = k-(s-1)`

for a deterministic candidate component `S` of fixed size `s`. The question for this run is whether that is merely conservative bookkeeping or whether it can hide a source-model defect.

Fix a deterministic set `S subset V`, `|S|=s`, and a vertex `v in S`. Write the external edge weights from `v` to `V\S` in increasing order as

`X_{v,1}<X_{v,2}<...<X_{v,n-s}`,

with associated outside labels `U_{v,j}`. Let the `s-1` internal incident weights be

`Y_{v,w}=W({v,w}),   w in S\{v}`.

Because the weights are continuous, ties occur with probability zero. Define the **internal rank profile**

`H_v(x) := #{w in S\{v}: Y_{v,w}<x}`.                       (3.1)

This is a nondecreasing integer-valued step function taking values in `{0,...,s-1}`.

### 3.1 Exact rank identity

For the external edge with external rank `j`, its rank among **all** `n-1` edges incident to `v` is exactly

`rank_v({v,U_{v,j}}) = j + H_v(X_{v,j}).`                    (3.2)

Indeed, exactly `j-1` external edges are strictly lighter than it, and exactly `H_v(X_{v,j})` internal edges are strictly lighter. Including the edge itself gives rank `j+H_v(X_{v,j})`.

Therefore

`{v,U_{v,j}} is in v's actual top k`
`  iff j + H_v(X_{v,j}) <= k`.                               (3.3)

This is the exact deterministic relation requested by method #5.

If a particular external deadline has `h` internal edges below it, then the condition is simply

`j <= k-h`.                                                   (3.4)

Thus the local forced-external-prefix length as a function of this parameter is

`p(h)=k-h`,                                                    (3.5)

and its discrete derivative is exactly

`p(h+1)-p(h)=-1`.                                             (3.6)

Each additional internal competitor below a deadline removes exactly one possible external top-`k` slot at that deadline—no more and no less.

### 3.2 The actual selected external edges form a prefix

Define

`R_v(j)=j+H_v(X_{v,j})`.

Since `X_{v,j+1}>X_{v,j}` and `H_v` is nondecreasing,

`R_v(j+1)-R_v(j)`
` = 1 + H_v(X_{v,j+1})-H_v(X_{v,j}) >=1`.                    (3.7)

Hence the selected external ranks form an initial prefix. Put

`p_v := max{j: j+H_v(X_{v,j})<=k}`,                           (3.8)

with `p_v=0` if the set is empty. Then the actual external proposals from `v` are exactly

`{X_{v,1},...,X_{v,p_v}}`.                                   (3.9)

If `r_v` denotes the number of **internal** `S--S` edges in the actual top `k` at `v`, then simply by counting the `k` selected incident edges,

`p_v = k-r_v`,                                                (3.10)

with `0<=r_v<=s-1`.

There is a useful warning here. In general one must **not** identify `r_v` with `H_v(X_{v,p_v})`: the final kth incident edge can itself be internal, so there can be internal selected edges heavier than the last selected external edge. Equation (3.10) is exact; the tempting equality `r_v=H_v(X_{v,p_v})` is not generally exact. This is precisely the kind of hidden profile simplification an auditor should not use.

### 3.3 Why `p0=k-(s-1)` is the exact worst-case fixed witness

Because `H_v(x)<=s-1` for every `x`, (3.3) gives

`j<=k-(s-1)  =>  j+H_v(X_{v,j})<=k`.                         (3.11)

Thus every one of the first

`p0=k-(s-1)`                                                   (3.12)

external edges is an actual top-`k` proposal at `v`, for every internal profile and every realization of the internal weights.

Conversely, there are realizations with all `s-1` internal edges lighter than the relevant external deadline, so no larger deterministic prefix can be certified using only the cardinality bound `s-1`. Therefore `p0` is the exact worst-case profile-free fixed witness.

The loss relative to the clean `k`-proposal array is bounded:

`0 <= k-p_v=r_v <= s-1`,                                     (3.13)

and over all `s` component vertices

`sum_{v in S}(k-p_v)=sum_v r_v <= s(s-1)`.                   (3.14)

For fixed `s`, this is `O_s(1)`. Claims 303, 315 and 318 were built to be uniform under arbitrary bounded proposal-rank omissions and bounded quota shifts. Therefore the worst-case `p0` reduction changes only the bounded-omission polynomial bookkeeping; it does not alter the `exp[-sk+o(k)]` rejection scale.

This answers the #5 question: the `p0` reduction loses **only bounded terminal-deadline bookkeeping** at fixed component size. It does not discard an exponential factor or a new interaction class.

## 4. #12 FIND WHAT IS CONSERVED — four invariants under the profile deformation

Now vary the internal profile from the degenerate state `H_v=0` to an arbitrary step profile with at most `s-1` jumps. Four objects needed by the literal LK component proof remain invariant in the required sense.

### 4.1 Raw-edge family separation is invariant

Let

`F_int(S)=sigma(W(e): e subset S)`                            (4.1)

be the sigma-field generated by all internal `S--S` raw-edge weights.

Every raw edge used by the external proposal/rejection mechanism has at least one endpoint in `V\S`:

- root-to-outside proposal edges `{v,u}`, `v in S`, `u notin S`;
- selected--selected support edges between outside proposal labels;
- selected--nonowner-component-vertex tail edges `{u,w}`, `u notin S`, `w in S`;
- residual external rejection edges from selected outside labels to the external pool.

None belongs to `binom(S,2)`. Since the original raw weights are iid, the entire noninternal raw-edge family is independent of `F_int(S)`.

Therefore conditioning on the complete internal weight profile changes **none** of the raw laws used in the repaired external rejection mechanism.

This is stronger and cleaner than conditioning only on the number of internal edges below one deadline: the whole internal sigma-field may be exposed for free as far as the external raw-edge law is concerned.

### 4.2 The forced rejection count changes only by a bounded amount

For an actual component, every actual external proposal from `v` must be rejected at its outside endpoint. The exact number of such proposals is `p_v=k-r_v`, so the total exact external rejection count is

`sum_{v in S} p_v = sk - sum_{v in S} r_v`.                  (4.2)

Since `0<=r_v<=s-1`,

`sk-s(s-1) <= sum_v p_v <= sk`.                              (4.3)

Thus deforming the internal profile cannot remove more than `s(s-1)` external rejection deadlines. At fixed `s`, Claim 303's bounded-omission saddle absorbs the entire deformation uniformly.

The fixed witness uses exactly `s p0=sk-s(s-1)` deadlines, the minimum guaranteed by (4.3). Hence it is not guessing an average internal occupancy; it is taking the literal profile minimum.

### 4.3 The canonical external defect taxonomy is invariant

After internal edges are deleted for proposal ranking, the external arrays at the vertices in `S` are built from disjoint noninternal raw-edge families. The repaired external interaction taxonomy remains the same:

1. collision of outside proposal labels;
2. a named nonexternal support edge from a selected outside label to another selected label or a nonowner component vertex;
3. bounded proposal-deadline omissions caused by the charged support edge.

Internal `S--S` edges do not become a new support defect in this external analysis: they have already been moved into the profile `H_v`. A cross edge `{u,w}` with `u notin S` and `w in S` is **not** internal and remains a normal root-tail/support edge, with exactly the same charge-first/delete-second treatment as in Claims 315--319.

Therefore no fourth codimension class appears when `H_v` varies.

### 4.4 The exact tail law survives internal conditioning

Claim 319's boundary law is also conserved. Suppose outside label `u` is absent from component vertex `b`'s exposed external prefix and `T_b` is that prefix's terminal threshold. Conditional on the ordered external prefix,

`W({b,u}) ~ Uniform[T_b,1]`.                                 (4.4)

Adding `F_int(S)` to the conditioning sigma-field does not affect (4.4), because `F_int(S)` is generated by disjoint raw variables. Thus, for a deadline `D` measurable before this tail coordinate is exposed,

`P(W({b,u})<=D | external prefix, F_int(S))`
` = (D-T_b)_+/(1-T_b)`.                                     (4.5)

On the same prefix guard this is `O(k/n)`.

What remains forbidden is the old self-conditioning mistake: do not additionally condition on an event that already inspects this named tail coordinate. If its activity creates an omission, pay the `O(k/n)` charge first under (4.5), reveal it once, then delete every contaminated deadline. The internal-profile conditioning does not change that order.

## 5. #23 DO WHAT THE PROPOSER DID NOT EXPECT — condition on the internal profile first

The source and the earlier P03 component argument both organize the proof by first choosing a candidate component and then imposing a coarse external witness. A natural alternative is to condition on the internal rank profile first and run the repaired external mechanism profile-by-profile.

This alternative is valid if one conditions on the **internal raw-edge sigma-field** `F_int(S)`. It is *not* valid if one conditions naively on the final internal occupancy vector `(r_v)`, because `r_v` is determined by comparison with external order statistics and therefore is not measurable from internal edges alone.

That distinction is the main audit value of this organization.

### 5.1 Safe profile-first conditioning

Condition on `F_int(S)`. Then every step function `H_v` is deterministic, but the external raw edges remain iid with their original law. For the realized external order statistics, (3.8) determines the exact proposal prefix length `p_v`.

If `S` is a component, every rank `j<=p_v` must be rejected at its outside endpoint. In particular, because `p_v>=p0`, the component event implies the **profile-independent fixed event**

`A_S^0 := {for every v in S, every one of its first p0 external proposals is rejected}`.        (5.1)

The event `A_S^0` is measurable using only noninternal raw edges. Therefore

`P(A_S^0 | F_int(S)) = P(A_S^0)`                             (5.2)

for every realized internal profile.

This gives a profile-by-profile proof of the key uniformity: no internal arrangement can make the fixed external witness more likely through hidden conditioning.

### 5.2 Internal tree witness and exact conditional factorization

Let `G` be Claim 316's single global kth-threshold envelope, with inherited upper constant `b=32/5`. On `G`, if `S` is a connected component, its retained internal graph contains some labelled spanning tree `T` all of whose edge weights are at most

`b k/(n-1)`.                                                  (5.3)

For a fixed labelled tree `T`, let `L_T` be this light-tree event. It is `F_int(S)`-measurable. From (5.1),

`{S is a component} cap G`
` subset union_T (L_T cap A_S^0)`.                            (5.4)

Now use the profile-first conditional expectation rather than an informal independence sentence:

`P(L_T cap A_S^0)`
` = E[ 1_{L_T} P(A_S^0 | F_int(S)) ]`
` = E[1_{L_T}] P(A_S^0)`
` = P(L_T) P(A_S^0).`                                        (5.5)

This is exact. It does not condition the product on `G`; `G` is used only to deduce the necessary light-tree witness and is dropped before multiplication.

Since `T` has `s-1` distinct internal edges,

`P(L_T) <= (b k/(n-1))^(s-1).`                              (5.6)

Claim 318 gives, uniformly for fixed `2<=s<=6`, and Claim 319 confirms at `s=7`,

`P(A_S^0) <= exp[-s k+o_C(k)] + n^{-3+o(1)}`.               (5.7)

Combining (5.4)--(5.7) and Cayley's `s^(s-2)` labelled trees reproduces the existing fixed-size component bound with all conditioning explicit.

### 5.3 Why conditioning on the final occupancy vector is a trap

It is tempting to condition first on

`r=(r_v)_{v in S}`                                           (5.8)

and then say that vertex `v` has exactly `k-r_v` external proposals. The equality itself is true. But the event `{r_v=h}` is not internal-only: it depends on how the internal weights interlace with the random external order statistics. Conditioning on `r` therefore biases the external proposal values.

That bias is harmless if one immediately discards the conditioning and uses the fixed `p0` witness, but it blocks a naive assertion that the external marked-saddle law is unchanged conditional on `r`.

The safe alternatives are:

1. condition only on `F_int(S)`, where external laws stay exact, then use the profile-independent `p0` witness; or
2. expose external proposal values in their native order and use the full repaired sigma-field calculus of Claims 303/315, without pretending the occupancy vector is independent.

Thus the profile-first organization is useful as an **audit** but does not shorten the published proof enough to replace Claim 318's fixed witness. The fixed `p0` route remains the cleaner final proof surface.

This was the main failed stronger idea of method #23: exact final occupancy is a stopping statistic involving external order values, so conditioning on it before applying the external saddle would introduce selection bias. The run records the obstruction rather than manufacturing a false conditional-independence theorem.
