## 3. #2 ATTACK THE NEGATION FIRST — try to break Claim 311 at `K=1,2`

The target is the quantitative step in Claim 311: after conditioning on the proposal-label partition, can the number of low-complexity witnesses grow faster than `(C_r k^2)^K`, or can a prescribed support edge fail to cost `O(k/n)`?

### 3.1 Deleted-root proposal sigma-field

Fix deterministic distinct roots

`R={v_1,...,v_r}`

with fixed `r`. Delete all root--root edges. Put `N=n-r`. For each root `a`, let

`A_a={W({v_a,x}): x notin R}`.

The raw-edge families `A_a` are pairwise disjoint, hence independent. Let

`X_{a,1}<...<X_{a,k}=T_a`

be the first `k` outside order statistics, with their ordered outside labels. Let `F_P` be the sigma-field generated by all of these values and labels, for all roots. Let `G_L` be the fixed threshold guard

`T_a <= L k/n` for every a,

where fixed `L` is any guard constant used by the repaired fixed-C proof.

A basic exact conditional law is now important.

### Lemma 3.1 — exact root-tail factorization

Conditional on `F_P`, for a fixed root `a`, the coordinates

`W({v_a,u})`

whose outside labels `u` do **not** appear among root `a`'s first `k` proposal labels are mutually independent and each has the exact law

`Uniform[T_a,1]`.

The tail families for different roots are conditionally independent as well.

#### Proof

Inside one root array the raw coordinates are iid Uniform[0,1]. Conditioning on the identities and ordered values of exactly the first `k` coordinates says that each remaining named coordinate lies above the terminal order statistic `T_a`, without imposing any further relative-order information on the named tail coordinates. By the product density, their regular conditional joint density is the product of uniform densities on `[T_a,1]`. Different root arrays use disjoint raw edges after root--root deletion, so the product statement persists across roots. `□`

### 3.2 Which root-to-selected-label edges can actually be `q`-edges?

Apply Claim 309's safe root suffix omissions. Then partition all proposal occurrences by equal outside label, and in each collision block retain the **global minimum proposal deadline of the entire block** if it survives the root suffix; otherwise omit the whole block. Let `D_u` denote the retained deadline for a surviving selected label `u`.

If label `u` occurred among root `b`'s first `k` deleted-array proposals, then `W({v_b,u})` is itself one of the proposal deadlines in `u`'s collision block. Global-minimum retention gives

`W({v_b,u}) >= D_u`.

Therefore a root-to-selected-label raw edge can satisfy the support-incidence inequality

`W({v_b,u}) < D_u`

**only if `u` was absent from root `b`'s first `k` proposal labels**. In that case Lemma 3.1 applies literally. This observation removes the only potentially dangerous conditional-law branch.

### 3.3 The three one-edge geometries

After the preprocessing above, every right vertex of Claim 311's incidence graph `Gamma_0` is one of the following geometries.

#### Type SS: selected--selected support edge

Let `e={u,z}` with distinct `u,z in S`, where `S` is the set of all outside proposal labels. The edge `e` is not in any root proposal array and is therefore independent Uniform[0,1] conditional on `F_P`. Since at most one deadline survives per selected label, `e` has positive degree in `Gamma_0` iff

`W(e)<D_u` or `W(e)<D_z`.

On `G_L`,

`P(e is a support vertex | F_P,G_L) = max(D_u,D_z) <= L k/n`.

The same raw edge can contaminate both endpoint deadlines, but it is charged exactly once.

#### Type SR-tail: selected--nonowner-root tail edge

Let `e={u,v_b}`, where `u` is a surviving selected label and `u` is absent from root `b`'s first `k` deleted-array proposals. By Lemma 3.1,

`W(e) | F_P ~ Uniform[T_b,1]`.

Hence

`P(W(e)<D_u | F_P,G_L)`
`= (D_u-T_b)_+/(1-T_b)`
`<= (Lk/n)/(1-Lk/n)`
`<= 2L k/n`

for all sufficiently large `n` in the fixed `C` window.

#### Type SR-prefix: root-edge support geometry with the label already exposed at that root

This branch is **impossible after global-minimum collision retention**. If `u` occurs in root `b`'s first `k` exposed proposals, then that raw edge is a proposal deadline in the same collision block, and it cannot be strictly lighter than the retained global minimum `D_u`. If the global minimum is lost to a root suffix omission, the whole block is omitted and there is no retained `D_u` to contaminate.

Thus “selected--root support” reduces exactly to the tail branch above; there is no unaccounted prefix law.

Root--root edges themselves are not `q`-edges. They are Claim 309's `p`-edges. Conditional on `F_P`, a prescribed unique root--root edge `e={v_a,v_b}` is independent Uniform[0,1] and is endpoint-active somewhere iff

`W(e) <= max(T_a,T_b)`.

Therefore on `G_L`

`P(e active somewhere | F_P,G_L) <= Lk/n`.

### 3.4 Product codimension for a prescribed support set

Let `F` be any fixed set of `q` distinct candidate support raw edges after the label partition and collision preprocessing. Conditional on `F_P` and the root--root endpoint-activity data, the raw variables belonging to distinct members of `F` are distinct. Type-SS variables are independent Uniform[0,1]; Type-SR tail variables are named tail coordinates governed by Lemma 3.1; mixed Type-SS/SR families are disjoint. Consequently

`P(F subset H | F_P, root data, G_L) <= (2L k/n)^q`,

where `H` is the set of positive-degree right vertices of `Gamma_0`.

Likewise, for any prescribed set of `p` unique endpoint-active root--root raw edges,

`P(those p edges are active | F_P,G_L) <= (L k/n)^p`.

These inequalities are literal conditional product bounds. They do not use a dependency graph, a union-bound surrogate for a single edge, or a mean-degree approximation.

### 3.5 Witness multiplicity at `K=1,2`

After global-minimum collision retention there is at most one retained deadline per distinct selected label. Therefore:

- there are at most `binom(rk,2)=O_r(k^2)` Type-SS support raw edges;
- there are at most `r(rk)=O_r(k)` selected--root pairs, hence certainly `O_r(k^2)` Type-SR candidates;
