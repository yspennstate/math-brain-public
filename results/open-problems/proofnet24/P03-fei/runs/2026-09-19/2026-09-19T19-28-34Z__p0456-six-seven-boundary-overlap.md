## 2. #2 ATTACK THE NEGATION FIRST — is there a literal size-6 / size-7 coverage gap?

The target was deliberately narrow. Claim 318 treats component sizes `2<=s<=6` by deleting internal candidate-component edges before ordering external proposals. None occurs. In fact, size 7 has an **overlap**: both routes work.

### 2.1 The fixed-size external witness extends literally to `s=7`

Fix a deterministic set `S subset V`, `|S|=7`. Delete all internal `S--S` edges only for the purpose of ordering external weights. For each `v in S`, write

`X_{v,1}<X_{v,2}<...`

for the weights of the `n-7` edges from `v` to `V\S`, and put

`p0 = k-(7-1)=k-6`.                                          (2.1)

There are at most six internal edges incident to `v`. Hence every one of

`X_{v,1},...,X_{v,p0}`                                      (2.2)

belongs to the **actual** top `k` at `v`, no matter what the six internal weights are: below `X_{v,p0}` there are at most `p0-1` external edges and six internal edges, totaling at most `k-1` competitors.

Therefore, if `S` is a component of literal `LK(n,k)`, every proposal in (2.2) must be rejected at its outside endpoint. Let `A_S^{(7)}` be precisely this external-rejection event.

Claim 318's proof uses only that `s` is fixed and that the shift `k-p0=s-1` is fixed. Claim 303 is uniform over arbitrary bounded proposal-rank omissions and bounded quota shifts. Re-running the **same** repaired canonical skeleton split at fixed `s=7` therefore gives, uniformly over deterministic seven-sets,

`P(A_S^{(7)}) <= exp[-7k+o_C(k)] + n^{-3+o(1)}.              (2.3)

No new analytic estimate is needed here: the fixed shift is now six instead of at most five. The high-complexity cutoff `D=3` still gives the second term, and every low-complexity omission count stays bounded by a constant depending only on `s=7`.

### 2.2 Combine the size-7 external witness with the internal tree witness

Let `G` be the single global two-sided kth-threshold envelope already used in Claim 316, with inherited constants

`a=5/32`, `b=32/5`.                                         (2.4)

On its upper half, every actual kth incident threshold is at most `b k/(n-1)`. If `S` is a connected component, its retained internal edges contain a spanning tree. Hence on `G`, for some labelled spanning tree `T` on `S`, all six tree-edge weights satisfy

`W(e) <= b k/(n-1)`.                                        (2.5)

For a fixed labelled tree this event depends only on internal `S--S` raw edges and has probability at most

`(b k/(n-1))^6`.                                            (2.6)

The event `A_S^{(7)}` uses only raw edges with at least one endpoint outside `S`: proposal arrays from `S` to `V\S` and rejection/support edges incident to selected outside labels. Thus (2.6) and `A_S^{(7)}` are exactly independent. Crucially, we do **not** condition this product on `G`; `G` is used only to deduce the necessary tree-light witness and is then dropped.

By Cayley's formula there are `7^5` labelled spanning trees. Therefore

`P(S is a component, G)`
` <= 7^5 (b k/(n-1))^6 [exp(-7k+o(k)) + n^{-3+o(1)}]`.       (2.7)

Summing over the `binom(n,7)` deterministic seven-sets and using `k=log n+O_C(1)` gives

`P(exists a 7-component, G)`
` <= k^6 n^{-6+o(1)} + k^6 n^{-2+o(1)}`
` = o(1).`                                                   (2.8)

Thus the fixed-size external-rejection route itself already covers size 7.

## 3. #14 FIND THE GROUP ACTING — the symmetries that are actually legal

The goal here is not to make the proof prettier by quotienting away information. It is to state exactly why every fixed deterministic root tuple and every fixed deterministic component set has the same bound.

### 3.1 Fixed-root factorial moments: full vertex exchangeability

The iid edge-weight law is invariant under the full vertex permutation group `S_n`. Therefore for every deterministic ordered tuple of distinct roots `(v_1,...,v_r)`,

`P(I_{v_1}=...=I_{v_r}=1)`                                  (3.1)

has the same value. If `Z_n=sum_v I_v`, this gives the exact identity

`E[(Z_n)_r] = (n)_r P(I_1=...=I_r=1)`                       (3.2)

for any fixed reference ordered tuple. Claim 317's uniform fixed-root estimate therefore immediately supplies every fixed factorial moment. No averaging over favorable roots occurs.

### 3.2 After roots are fixed: only outside-label permutations are quotiented

For a fixed root set `R`, after deleting root-root edges the root outside arrays are independent ordered samples without replacement from `N=n-r` outside labels. The group `S_N` permuting those outside labels acts transitively on arrays with a given **equality partition of the ordered proposal positions**. If that partition has `m` blocks, its exact probability is

`(N)_m / (N)_k^r`.                                          (3.3)

This is the legitimate symmetry behind the collision factor in Claims 311/317.

Proposal **ranks are not quotiented**. Deadlines, root suffix omissions, the global-minimum representative in a collision block, and the exact `Uniform[T,1]` tail conditioning all depend on ordered positions. A rank permutation is not a symmetry of the repaired event.

### 3.3 Fixed component set `S`: outside-label symmetry gives uniformity in `S`

Fix `|S|=s`. After deleting internal `S--S` edges, the external proposal arrays at vertices in `S` consist of disjoint iid raw-edge families. The subgroup that fixes `S` setwise and permutes `V\S` relabels all outside proposal labels without changing their law. Hence the external-rejection estimate for `A_S` is identical for every deterministic labelled `s`-set.

The full vertex group also sends any deterministic `s`-set to any other, so the set-uniformity used in the `binom(n,s)` union bound is exact.

For internal spanning trees, every **fixed labelled tree** has the same light-edge probability because it consists of exactly `s-1` distinct iid internal raw edges. We nevertheless retain the full Cayley factor `s^{s-2}`. We do **not** claim that vertex permutations act transitively on nonisomorphic tree shapes and do not quotient tree shapes away.

These are all the symmetries used. In particular, no symmetry argument is used to suppress endpoint-conditioned tail laws or to turn ordered ranks into unordered slots.

## 4. #30 ONE DIRECTION AT A TIME — exact `Uniform[T,1]` law at the small-component boundary

The most delicate boundary condition is this: an outside label `u` may be selected by one component vertex and absent from another component vertex's first `p0=k-(s-1)` external labels. The support edge from the latter vertex to `u` can then contaminate the rejection deadline at `u`. The proof must cost that raw edge under the **correct** conditional law and must remain valid after canonical deadline deletion.

### 4.1 Exact tail law for an absent label

Fix `b in S`, put `N=n-s`, and let

`Y_x = W({b,x}),   x in V\S`

be iid `Uniform[0,1]`. Write their ordered values and labels as

`X_1<...<X_N`, `U_1,...,U_N`,

and put `p=p0` and `T=X_p`. Let

`F_b^p = sigma(X_1,...,X_p, U_1,...,U_p)`.                   (4.1)

Take a deterministic outside label `u` such that `u notin {U_1,...,U_p}`. The standard order-statistic disintegration gives, as a regular conditional distribution,

`W({b,u}) | F_b^p  ~ Uniform[T,1]`.                          (4.2)

More strongly, conditional on `F_b^p`, all raw coordinates whose labels are absent from the prefix are independent `Uniform[T,1]` variables. One direct proof is to condition on `T=t`, the ordered lower values and their labels: the joint density of every remaining coordinate on `[t,1]` factorizes with constant density `(1-t)^{-1}` per coordinate.

Consequently, for any proposal deadline `D` measurable before this coordinate is exposed,

`P(W({b,u}) <= D | F_b^p)`
` = (D-T)_+/(1-T).                                           (4.3)

On a prefix threshold guard `T,D <= Lk/n`, with fixed `L` and large `n`,

`(D-T)_+/(1-T) <= 2L k/n`.                                  (4.4)

The fact that `p=k-(s-1)` rather than `k` changes nothing in (4.2): only absence from the actually exposed prefix matters.

### 4.2 Why the global component guard must not be inserted into (4.2)

The global envelope `G` concerns actual kth thresholds and can depend on raw coordinates outside the first `p` external prefix. Therefore the proof does **not** assert that (4.2) remains true after conditioning on the full `G`.

Instead, for fixed `S` use the prefix-measurable guard

`H_{S,L} = { X_{v,p0} <= Lk/(n-s) for every v in S }`.      (4.5)

Given the prefix sigma-fields, `H_{S,L}` carries no extra information about a named tail coordinate. Moreover, on the inherited global upper envelope, `H_{S,L}` automatically holds for any fixed `L>b+o(1)`, because the `p0`th external edge is necessarily in the true top `k` and hence has weight no larger than the true kth threshold.

Thus the component proof uses `G` only for the deterministic implication “component => light internal tree (and, in the global route, empty low cut)”; it then drops `G` before multiplying disjoint raw-edge events. This is exactly the guard separation already implicit in Claim 305 and makes the size-6/7 boundary explicit.

### 4.3 Repaired deletion patterns: when does the tail law survive?

There are two cases, and conflating them would be a conditioning error.

**Case A: the deletion pattern is already measurable without the named coordinate.**  
If a set of omitted deadlines has been determined from proposal prefixes and previously exposed **other** support variables, then conditioning on that deletion pattern does not change (4.2). The named coordinate is still an independent `Uniform[T,1]` tail coordinate.

**Case B: the named coordinate itself creates the omission.**  
If `{b,u}` is the next candidate support edge and its activity `W({b,u})<D` would cause a deadline to be deleted, one must not condition first on the **final** deletion pattern. The correct order is:

1. condition on the sigma-field generated by all proposal prefixes and all previously charged raw variables, **excluding** `W({b,u})`;
2. use (4.3)--(4.4) to pay the `O(k/n)` activity cost;
3. reveal/charge this raw edge exactly once;
4. delete every retained deadline it contaminates;
5. continue with the residual disjoint blocks.

This is precisely Claim 315/316's charge-first/delete-second rule. If the same raw edge contaminates two deadlines, it is charged once and both deadlines are deleted. If it was already charged earlier, it is never conditioned and charged again.

So the exact `Uniform[T,1]` law survives **every repaired deletion pattern in the only sense needed by the proof**: either the pattern is measurable before this coordinate and leaves the law unchanged, or the coordinate is costed under the tail law before it is allowed to create that pattern. There is no circular conditioning on its own activity.
