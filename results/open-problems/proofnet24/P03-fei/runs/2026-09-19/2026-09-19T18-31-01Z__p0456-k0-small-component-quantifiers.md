### 2.1 Deterministic proof; no `r=2` or `r=3` counterexample exists

Fix any deterministic distinct root set

`R={v_1,...,v_r}`

and delete all root-root edges before exposing the first `k` outside proposals at each root. Let `S` denote the set of proposal labels and, on the collision-free branch, let

`E=V\(R union S)`.

Assume `K=c+p+q=0`.

**Step 1: `p=0` fixes the actual root proposal lists.**  
For each root `v_a`, let `T_a` be the deleted-array `k`th outside threshold. By definition of the repaired root-edge charge, `p=0` means that no root-root edge incident to `v_a` has weight at most `T_a`. Claim 310's sequential insertion lemma then says that an edge heavier than the initial `T_a` can never enter the final top `k`: inserting root-root edges can only lower the running `k`th threshold. Therefore the actual top-`k` list at every root is exactly its deleted-array first `k` outside proposals.

This step is exactly where the false pre-Claim-309 `r>=3` shortcut must **not** be used. We use only the correct endpoint-active definition and the sequential prefix lemma.

**Step 2: `c=0` removes all selected-label collisions.**  
Every one of the `rk` proposal occurrences has a distinct outside label. Thus there is one retained deadline `D_u` for every selected label `u in S`, and there is no collision promotion issue.

**Step 3: isolation creates at least `k` strict lighter competitors at the selected endpoint.**  
Let `u` be the label selected by root `v_a`, with proposal-edge weight

`D_u=W({v_a,u})`.

By Step 1, `{v_a,u}` is in the top `k` at `v_a`. If `v_a` is isolated in the bilateral-preference graph, this proposal edge cannot also be in the top `k` at `u`. With continuous raw weights, ties have probability zero. Hence there are at least `k` **distinct** edges incident to `u` whose raw weights are strictly smaller than `D_u`.

**Step 4: `q=0` forces all those competitors into `E`.**  
The canonical support family contains every nonexternal raw edge

`{u,y}`, with `y in (R union S)\{u}`,

that is lighter than the retained deadline `D_u`. The condition `q=0` therefore says that no such nonexternal lighter edge exists. The proposal edge `{v_a,u}` itself has weight exactly `D_u`, not less, so it is not a lighter competitor. Consequently every one of the at least `k` strict lighter competitors from Step 3 has its other endpoint in

`E=V\(R union S)`.

Thus

`#{x in E: W({u,x})<D_u} >= k`.

This proves the Claim-317 implication for **every** fixed `r`, not only `r=2,3`.

### 3.1 Deleting more internal candidate-component edges

Let `D` be a set of internal edges removed from consideration and let `P_v(D)` denote the external edges that lie in the top `k` among all nondeleted incident edges at `v`.

If `D subset D'`, then

`P_v(D) subseteq P_v(D')`.

Reason: deleting internal edges cannot increase the number of edges lighter than any fixed external edge `x_{v,j}`. Hence an external edge that was in the top `k` cannot be pushed out by removing internal competitors.

Therefore:

- the **selected external set only increases** as more internal edges are deleted;
- the stronger event “every currently selected external edge is rejected” only **decreases** under further internal deletion;
- the proof witness using only the first `p0` external edges is actually **invariant**, because its raw-edge definition does not use internal edges at all.

The last point is what the component proof needs. No stochastic monotonicity involving a changing charge set is required.

`R(J)= intersection_{alpha notin J} {proposal alpha is rejected at its outside endpoint}`.
