# 6. `P03-TERMINAL-CHEBYSHEV-FUNCTIONAL-49` — **PROVED**

The following statement converts the Reed–Muller moment saturation into a uniform approximation theorem without any dimension factor.

For a scalar function `phi:[0,1]->R`, define the exact paired prefix response
\[
\Delta_d[\phi]
=
\mathbb E_\lambda
\left[
\sum_S\phi(p^f_{d,\lambda}(S))
-
\sum_S\phi(p^1_{d,\lambda}(S))
\right].
\tag{6.1}
\]

## Theorem

Suppose `d` is a completed monomial-degree prefix and `R=2^d`. Let `g` be any bounded function on `[0,1]`, and let `q` be a polynomial of degree at most `R-2`. Then
\[
\boxed{
|\Delta_d[xg(x)]|
\le2\|g-q\|_{L^\infty[0,1]}.
}
\tag{6.2}
\]

## Proof

The polynomial `xq(x)` has degree at most `R-1` and has no constant term. By (5.1), together with the trivial equality of the first moments,
\[
\Delta_d[xq(x)]=0.
\tag{6.3}
\]
For either probability vector `p`,
\[
\left|
\sum_Sp_S[g(p_S)-q(p_S)]
\right|
\le
\|g-q\|_\infty\sum_Sp_S
=
\|g-q\|_\infty.
\]
Apply this to the two paired spectra and average over `lambda`:
\[
|\Delta_d[xg(x)]|
=|\Delta_d[x(g-q)(x)]|
\le2\|g-q\|_\infty.
\]
QED.

### Why no factor `N` appears

The approximation error is multiplied by the spectral probability `p_S` before summation, so the total error is controlled by `sum p_S=1`. Approximating `x/(x+t)` directly as an unweighted function and then summing a uniform error over all `N` labels would lose a fatal factor `N`; (6.2) avoids exactly that error.

This is an approximation-theoretic explanation of R16's warning that exhausting any fixed collection—and even a very large initial segment—of collision moments does not by itself remove Shannon's logarithmic singularity.

This statement is a limitation of the present approximation mechanism, not a proof that no stronger Boolean theorem can beat the scale.
