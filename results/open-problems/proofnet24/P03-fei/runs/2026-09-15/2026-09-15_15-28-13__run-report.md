# 6. `P03-DEGREE-RESOLVENT-LIGHTCONE-55` — **PROVED**

\[
|\mathscr R(t)|
\le
\frac{2\vartheta(t)^{R-3/2}}
{t\sqrt{1+t}}.
\tag{6.2}
\]

Apply (6.2) to the two endpoints of (6.1), using `R_q` at degree `q-1` and `2R_q` at degree `q`. Then

\[

This is a legitimate absolute-value bound because its right side is explicit and summable; it does not replace the unresolved microscopic signed quantity by its positive part.

## 6.2 Summed high-degree block turnover

\[
R_0=2^{q_0-1},
\qquad
\tau_0=3z^2/R_0^2\le2.

The bound is independent of `n`, the number of later degree blocks, and the number of monomials in those blocks.

# 8. `P03-RADIAL-SCALE-MONOTONICITY-57` — **PROVED**

The carried pointwise radial recurrence gave an upper bound for

\[
K_w(a)/K_{w+2}(a).
\]

This run proves that this ratio is **monotone nondecreasing in the resolvent scale `a`**.

Assume `w` and `N-w` are even and `0<=w<=N-2`. Because

\[
F_w(s)=\sin^ws\cos^{N-w}s
\]

is nonnegative, `pi`-periodic, and symmetric around `pi/2`, folding the Laplace integral gives

\[
\boxed{
K_w(a)
=
\frac1{\sinh(a\pi/2)}
\int_0^{\pi/2}
\sin^wu\cos^{N-w}u\,
\cosh(a(\pi/2-u))du.
}
\tag{8.1}
\]

The common prefactor cancels in the adjacent ratio. Put

\[
z=\pi/2-u.
\]

Then

\[
\frac{K_w(a)}{K_{w+2}(a)}
=
E_{\nu_a}[\cot^2u],
\tag{8.2}
\]

where `nu_a` has density proportional to

\[
\sin^{w+2}u\cos^{N-w-2}u\cosh(az).
\]

If `a_2>a_1>0`, the likelihood ratio is

\[
L(z)=\frac{\cosh(a_2z)}{\cosh(a_1z)}.
\]

Its logarithmic derivative is

\[
\frac{d}{dz}\ln L(z)
=a_2\tanh(a_2z)-a_1\tanh(a_1z)\ge0,
\]

because `a -> a tanh(az)` is increasing for fixed `z>=0`.  Since

\[
\cot^2u=\tan^2z
\]

is also increasing in `z`, the monotone-likelihood-ratio covariance inequality gives

\[
\boxed{
\frac{K_w(a_1)}{K_{w+2}(a_1)}
\le
\frac{K_w(a_2)}{K_{w+2}(a_2)}.
}
\tag{8.3}
\]

As `a downarrow 0`, both kernels diverge like the same `1/a` period factor, and their ratio tends to the beta-integral ratio

\[
\boxed{
\lim_{a\downarrow0}
\frac{K_w(a)}{K_{w+2}(a)}
=
\frac{N-w-1}{w+1}.
}
\tag{8.4}
\]

Therefore the exact universal lower bound is

\[
\boxed{
\frac{K_w(a)}{K_{w+2}(a)}
\ge
\frac{N-w-1}{w+1}
\qquad(a>0).
}
\tag{8.5}
\]

For fixed `N,w` and `a->infinity`, Laplace's method at the origin gives

\[
K_w(a)\sim\frac{\Gamma(w+1)}{a^{w+1}},
\qquad
K_{w+2}(a)\sim\frac{\Gamma(w+3)}{a^{w+3}},
\]

hence

\[
\boxed{
\frac{K_w(a)}{K_{w+2}(a)}
\sim\frac{a^2}{(w+1)(w+2)}.
}
\tag{8.6}
\]

This rigorously kills the shortcut of extrapolating a low-`a` adjacent-shell capacity bound to all resolvent scales. The radial mismatch only worsens as the resolvent moves inward toward large `a`.

# 9. `P03-LIGHTCONE-RADIAL-COMPATIBILITY-58` — **PROVED**

The light cone and the radial recurrence fit together at a concrete threshold.

A degree-`q` relation surviving before the degree-`q` block has

\[
w\ge2^q.
\tag{9.1}
\]

On the active light-cone window `t<=tau_q(z)` from (6.5),

\[

\le
12z^2N^2 2^{-2q}.
\]

Therefore, for every surviving shell,

\[
\boxed{
\frac{a^2}{wN}
\le
12z^2 2^{n-3q}.
}
\tag{9.2}
\]

Fix `eta>0`. If

\[
\boxed{
q\ge
\frac{n+\log_2(12z^2/\eta)}3,
}
\tag{9.3}
\]

then throughout the entire light-cone window

\[
a^2\le\eta wN.
\tag{9.4}
\]

Now use the carried exact radial root bound. With

\[
A=w(w-1),
\quad
C=a^2+2w(N-w)+N,
\]

one has

\[
\frac{K_w}{K_{w+2}}
\le
\frac{C+\sqrt{C^2-4AB}}{2A}
\le\frac CA.
\]

For `w>=2`, (9.4) gives

\[
C\le(\eta+5/2)wN,
\qquad
A\ge w^2/2,
\]

and therefore

\[
\boxed{
\frac{K_w(a)}{K_{w+2}(a)}
\le
(2\eta+5)\frac Nw.
}
\tag{9.5}
\]

Thus for degree blocks above approximately `n/3` (up to the explicit logarithmic correction in `z`), **every resolvent scale at which the block has not already been Chebyshev-suppressed lies in the favorable adjacent-shell radial regime**.

This is not yet a shell-payment theorem: source/target incidence, frustrated affine blocks, Boolean signs, and terminal/source selection still have to be handled.  It removes radial-scale mismatch as an additional obstruction in this high-degree active corridor.

# 10. `P03-QFLAT-PLUCKER-FIRSTSEP-59` — **PROVED**

A separate affine/Reed–Muller structural calculation generalizes the earlier quadratic-pivot theorem.

Let

\[

\[

For a squarefree monomial

\[

\]

consider its parity on the flat:

\[
\sum_{x\in P}m_S(x)\pmod2.
\]

For any multilinear polynomial in `y`, summing over all `y in F_2^q` extracts modulo two exactly the coefficient of

\[
y_1\cdots y_q,
\]

because every monomial missing at least one `y_l` is attained an even number of times.

If `|S|<q`, the substituted polynomial `m_S(x(y))` has degree `<q`, so this coefficient vanishes. Hence

\[
\boxed{
\sum_{x\in P}m_S(x)=0\pmod2
\qquad(|S|<q).
}
\tag{10.1}
\]

If `|S|=q`, the top coefficient comes only from taking one linear term from every factor. It is the permanent of the `q x q` coordinate minor

\[
U_S=(u_{\ell,j})_{\ell\in[q],\,j\in S}.
\]

Over `F_2`, permanent and determinant agree, so

\[
\boxed{
\sum_{x\in P}m_S(x)
=\det U_S\pmod2
\qquad(|S|=q).
}
\tag{10.2}
\]

Since `W` has rank `q`, some `q x q` minor is nonzero. Therefore:

\[
\boxed{
\text{every affine }q\text{-flat survives every compiler monomial of degree }<q
\text{ and is first separated at degree }q.
}
\tag{10.3}
\]

Under a fixed order of degree-`q` monomials, its first separator is exactly the first nonzero `q`-dimensional Pluecker coordinate of `W` in that order.  Translation `a` does not affect the degree-`q` parity.
