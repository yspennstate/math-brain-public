# 4. `P03-MASK-COSET-CENTRAL-RESOLVENT-60` — **PROVED**

This is the main new structural theorem.

Let the physical input set be

\[
V=\mathbb F_2^n,
\qquad |V|=N.
\]

Represent the Boolean phase by its binary truth-table vector

\[
f(x)=(-1)^{b(x)},
\qquad b\in\mathbb F_2^V.
\]

Let `M` be any binary linear mask code in `F_2^V` containing all affine-linear truth tables `RM(1,n)`. This includes every actual monomial compiler prefix after the affine layer.

For a truth table `z`, define its normalized bias

\[
\beta(z)=\frac1N\sum_{x\in V}(-1)^{z(x)}
=1-\frac{2|z|}{N}.
\tag{4.1}
\]

For `t>0` put

\[
\Phi_t(u)=\frac{u}{u+t},\qquad 0\le u\le1.
\tag{4.2}
\]

Then the exact paired resolvent after uniform masking by `M` is

\[
\boxed{
\mathcal R_M(t)
=N\left[
\mathbb E_{m\in M}\Phi_t(\beta(b+m)^2)
-
\mathbb E_{m\in M}\Phi_t(\beta(m)^2)
\right].
}
\tag{4.3}
\]

Equivalently, if

\[
A_j(C)=|\{z\in C:|z|=j\}|,
\]

then

\[
\boxed{
\mathcal R_M(t)
=\frac{N}{|M|}
\sum_{j=0}^N
[A_j(b+M)-A_j(M)]
\frac{(1-2j/N)^2}{(1-2j/N)^2+t}.
}
\tag{4.4}
\]

Thus the small-resolvent compiler is exactly a comparison of the radial weight enumerator of an actual mask code with the radial weight enumerator of its Boolean coset.

## 4.1 Proof

For a truth table `z`, write

\[
\psi_z(x)=(-1)^{z(x)}.
\]

For a physical Fourier character `S`, let

\[
\ell_S(x)=S\cdot x\pmod2.
\]

Then

\[
\widehat{\psi_z}(S)
=\frac1N\sum_x(-1)^{z(x)+\ell_S(x)}
=\beta(z+\ell_S).
\tag{4.5}
\]

For the spectral score

\[
G_t(\psi_z)
=\sum_S\Phi_t(\widehat{\psi_z}(S)^2),
\]

we therefore have

\[
G_t(\psi_{b+m})
=\sum_S\Phi_t(\beta(b+m+\ell_S)^2).
\tag{4.6}
\]

Because `M` contains every linear truth table, `ell_S in M`. For fixed `S`, translation

\[
m\mapsto m+\ell_S
\]

is a bijection of `M`. Hence

\[
\mathbb E_{m\in M}G_t(\psi_{b+m})
=N\mathbb E_{m\in M}\Phi_t(\beta(b+m)^2).
\tag{4.7}
\]

The same identity with `b=0` gives the comparator. Subtracting proves (4.3); grouping by Hamming weight proves (4.4). No approximation, limit, or unsigned replacement occurs.

For `M=RM(1,n)`, (4.3) reduces to the familiar source formula

\[
\mathcal R_0(t)
=\sum_S\frac{p_S}{p_S+t}-\frac1{1+t},
\qquad p_S=\widehat f(S)^2.
\tag{4.8}
\]

Indeed the affine masks simply run through the physical characters and a harmless global sign.

## 4.2 Central-layer limit

As `t downarrow 0`,

\[
\Phi_t(u)\to 1_{\{u>0\}}.
\]

Since `beta(z)=0` iff `|z|=N/2`, define

\[
B(C)=|\{z\in C:|z|=N/2\}|.
\]

Then

\[
\boxed{
\mathcal R_M(0+)
=\frac{N}{|M|}
[B(M)-B(b+M)].
}
\tag{4.9}
\]

The singular end of the compiler therefore measures a literal **central-balance occupation deficit** between a Reed–Muller mask code and the actual Boolean coset.

This is closure-relevant: the R16 moment hierarchy controls polynomial statistics of the bias, whereas the `t downarrow 0` limit is sensitive to the exact central atom. The long-standing logarithmic/moment-exhaustion obstruction is thus visible directly in the code geometry.

## 4.3 Exact integrated code kernel

For `T>0`, define

\[
F_T(u)=
\begin{cases}
u\log(1+T/u),&u>0,\\
0,&u=0.
\end{cases}
\tag{4.10}
\]

Since

\[
\int_0^T\frac{u}{u+t}\,dt=F_T(u),
\]

(4.3) integrates exactly to

\[
\boxed{
\int_0^T\mathcal R_M(t)\,dt
=N\left[
\mathbb E_{b+M}F_T(\beta^2)
-
\mathbb E_MF_T(\beta^2)
\right].
}
\tag{4.11}
\]

The endpoint singularity is therefore not an artifact of a power-series expansion; it is a logarithmic radial weight-enumerator comparison.

# 5. Exact generator-resolved primal gate formula — **PROVED as part of claim 60**

Let `g notin M` be the next actual compiler gate and

\[
M'=M\oplus\langle g\rangle.
\]

Then each element of `M'` is uniquely `m` or `m+g` with `m in M`, so (4.3) gives

\[
\boxed{
\begin{aligned}
\mathcal R_M(t)-\mathcal R_{M'}(t)
=\frac N2\mathbb E_{m\in M}\Big[&
\Phi_t(\beta(b+m)^2)-\Phi_t(\beta(b+m+g)^2)\\
&-\Phi_t(\beta(m)^2)+\Phi_t(\beta(m+g)^2)
\Big].
\end{aligned}
}
\tag{5.1}
\]

This is the exact primal counterpart of the carried first-separator parity formula. It retains the actual monomial generator and comparator subtraction.

Put

\[
\alpha_f(m)=\beta(b+m),
\qquad
\gamma_f(m)=\beta(b+m+g),
\]

and similarly `alpha_1, gamma_1` with `b=0`. Since

\[
\Phi_t(x)-\Phi_t(y)
=\frac{t(x-y)}{(x+t)(y+t)},
\]

we also obtain

\[
\boxed{
\mathcal R_M(t)-\mathcal R_{M'}(t)
=\frac{Nt}{2}\mathbb E_m
\left[
\frac{\alpha_f^2-\gamma_f^2}
{(\alpha_f^2+t)(\gamma_f^2+t)}
-
\frac{\alpha_1^2-\gamma_1^2}
{(\alpha_1^2+t)(\gamma_1^2+t)}
\right].
}
\tag{5.2}
\]

If `g` is a degree-`q` monomial, its phase changes only on the corresponding codimension-`q` coordinate face. Writing the correlation as the sum of its inside-face and outside-face contributions factors

\[
\alpha^2-\gamma^2
=4uv,
\tag{5.3}
\]

where `u` and `v` are the signed correlations on the two gate regions. Thus the low-resolvent gate cost is a genuine **signed selector/correlation product**, not a positive block count.

Both (5.1) and the prior dual formula

\[
\mathcal R_{k-1}(t)-\mathcal R_k(t)
=2Na
\sum_{\substack{A\in D_{k-1}\\g_k(A)=1\\f_A=-1}}
(-1)^{|A|/2}K_{|A|,N}(a),
\qquad a=N\sqrt t,
\tag{5.4}
\]

compute the same exact gate response. Hence the primal central-occupation representation has not discarded the `2 mod 4` credits, code multiplicity, or first-separator condition; they are the Fourier/MacWilliams dual data of the same quantity.

This gives a new exact interface for the next attack: prove a signed inequality for the correlation product in (5.2), or equivalently for (5.4), while retaining the R16 refunds.

# 6. `P03-J-ADAPTIVE-MICROCORE-61` — **PROVED**

# 7. `P03-ADAPTIVE-PREFIX-REDUCTION-62` — **PROVED**

This combines the new microcore payment with the preceding degree-resolvent light cone **and preserves the signed high-resolvent bank**.

For a completed degree-`q-1` prefix let

\[
R_q=2^{q-1}.
\]

The prior light-cone theorem proves that for `q>=3`, `z>0`, and

\[
\tau_q(z)=\frac{3z^2}{R_q^2}\le2,
\]

all completed degree blocks from `q` through any later completed degree `d` satisfy

\[
\sum_{s=q}^{d}
\int_{\tau_q(z)}^2
|B_s(t)|\,dt
\le\frac{12e^{-z}}z,
\tag{7.1}
\]

where

\[
B_s(t)=\mathcal R^{[s-1]}(t)-\mathcal R^{[s]}(t).
\]

Now define

\[
z_J=\log\left(12\left(1+\frac1J\right)\right).
\tag{7.2}
\]

Then

\[
\frac{12e^{-z_J}}{z_J}
=\frac{J}{(1+J)z_J}
\le J.
\tag{7.3}
\]

Choose `q>=3` so that

\[
\boxed{
\frac{3z_J^2}{4^{q-1}}
\le\frac{J}{2N}.
}
\tag{7.4}
\]

Equivalently it suffices that

\[
q\ge
1+\frac12\log_2\frac{6Nz_J^2}{J}.
\tag{7.5}
\]

Assume `q<=d`. Split the completed suffix endpoint response at `t_core=J/(2N)`. By (6.4),

\[
\left|
\int_0^{t_{\rm core}}
[\mathcal R^{[q-1]}-\mathcal R^{[d]}]dt
\right|\le J.
\tag{7.6}
\]

Because `tau_q(z_J)<=t_core`, (7.1) and the triangle inequality give

\[
\left|
\int_{t_{\rm core}}^2
[\mathcal R^{[q-1]}-\mathcal R^{[d]}]dt
\right|
\le J.
\tag{7.7}
\]

Therefore

\[
\boxed{
|\mathcal Q_{d,<2}-\mathcal Q_{q-1,<2}|
\le2J.
}
\tag{7.8}
\]

This already pays the entire small-resolvent endpoint of the high-degree suffix, including the singular origin.

## 7.1 The bank moves by an exponentially tiny amount

The completed degree-`q-1` dual has minimum distance `2^q`. The carried terminal-moment theorem therefore gives

\[
C_{q-1,r}=0
\qquad(2\le r<R_q).
\tag{7.9}
\]

Since further appends only remove common relations,

\[
0\le C_{q-1,r}-C_{d,r}\le C_{0,r}\le rJ.
\tag{7.10}
\]

Using the exact R16 signed bank,

\[
\begin{aligned}
|\mathcal B_d-\mathcal B_{q-1}|
&=|\Delta_{d,>2}-\Delta_{q-1,>2}|\\
&\le
J\sum_{r\ge R_q}
\frac{r}{(r-1)2^{r-1}}\\
&\le
\boxed{2^{3-R_q}J}.
\end{aligned}
\tag{7.11}
\]

No individual odd-order refund is reclassified as a cost; absolute values are taken only after the difference is supported in the exponentially remote tail `r>=R_q`, where the total is universally summable.

Combining (7.8) and (7.11) yields the bank-preserving reduction

\[
\boxed{
\left|
(\mathcal Q_{d,<2}-\mathcal B_d)
-(\mathcal Q_{q-1,<2}-\mathcal B_{q-1})
\right|
\le
(2+2^{3-R_q})J.
}
\tag{7.12}
\]

This is a direct reduction of the exact FEI compiler obligation, not merely of an unsigned surrogate.

## 7.2 Scope

A convenient choice is

\[
q_0(J,n)
=
\max\left\{

\frac12\log_2\frac{6Nz_J^2}{J}

\right\}.
\tag{7.13}

Whenever `q_0<=d`, every completed degree layer from `q_0` through `d` changes the exact banked small-resolvent obligation by only `O(J)` in total.

\[
