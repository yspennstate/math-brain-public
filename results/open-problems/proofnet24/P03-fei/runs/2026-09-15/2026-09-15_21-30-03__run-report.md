# 5. `P03-TERMINAL-BOREL-POSITIVITY-81` — PROVED

## 5.1 Residual Borel transform

At a complete degree prefix `d`, define the undeclared / terminal residual Borel function

\tag{5.1}
\]
By subtracting the deposited support formula `(4.3)` from the initial formula, equivalently by the residual collision moments `C_{d,r}`, one has
\[

\sum_{\substack{A\in D_d\setminus\{0\}\\f_A=-1}}
(-1)^{|A|/2}
\sin^{|A|}(s/N)\cos^{N-|A|}(s/N).
}
\tag{5.2}
\]
No sign has been removed.

## 5.2 The half-band dual is doubly even

Let
\[
d_h=\left\lceil\frac n2\right\rceil,
\qquad
r_h=n-d_h-1,
\qquad
D_{d_h}=RM(r_h,n).
\]
For `n<=1` FEI is trivial, so assume `n>=2`.

The code `RM(r_h,n)` is generated by truth-table supports of monomials `x_U`, `|U|<=r_h`. Every such generator has weight
\[
2^{n-|U|},
\]
which is divisible by four because `r_h<=n-2`.

For two monomial generators `x_U,x_V`, the intersection of their supports has size
\[
2^{n-|U\cup V|}.
\]
Moreover
\[
|U\cup V|\le2r_h\le n-1,
\]
so this intersection has even cardinality. Hence all generator pairs are orthogonal over `F_2`.

Now build an arbitrary codeword by adding generators one at a time. If `x` has weight divisible by four and `y` is a generator, then
\[
\operatorname{wt}(x+y)
=\operatorname{wt}(x)+\operatorname{wt}(y)
-2|\operatorname{supp}x\cap\operatorname{supp}y|.
\]
The first two terms are divisible by four. Pairwise generator orthogonality and linearity imply the intersection parity is even, so the last term is also divisible by four. By induction,
\[
\boxed{\operatorname{wt}(A)\equiv0\pmod4\quad(A\in D_{d_h}).}
\tag{5.3}
\]

## 5.3 Pointwise positivity

For every nonzero `A in D_{d_h}`, let `w=|A|`. By `(5.3)`,
\[
(-1)^{w/2}=1.
\]
Also `N=2^n` is divisible by four and therefore `N-w` is even. Thus, for every real `s`,
\[
\sin^w(s/N)\ge0,
\qquad
\cos^{N-w}(s/N)\ge0.
\]
Every summand in `(5.2)` is nonnegative. Therefore
\[
\boxed{
\Psi_{d_h}(s)\ge0
\qquad(s\in\mathbb R).
}
\tag{5.4}
\]
Equivalently,
\[
\boxed{
\mathfrak G_{d_h}(s)\le\Phi_f(s)
\qquad(s\in\mathbb R).
}
\tag{5.5}
\]
This is a **one-sided signed comparison**. It does not assert `mathfrak G_{d_h}>=0`, and it does not take the absolute value of the deposited compiler response.

### Scope

The doubly-even hypothesis is essential. Earlier Reed–Muller duals can contain `2 mod 4` words; for example the previously recorded `RM(2,4)` example has a weight-six word. Thus `(5.4)` cannot simply be moved earlier in the compiler.
