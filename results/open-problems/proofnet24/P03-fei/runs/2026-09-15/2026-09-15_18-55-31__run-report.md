# 4. `P03-INDIVIDUAL-GATE-LIGHTCONE-64` — **PROVED**

The degree-resolvent light cone from the previous run can be strengthened from completed degree blocks to **every individual monomial gate**.

## 4.1 General moment-gap resolvent lemma

For a mask code `M`, write the exact mask-coset resolvent in the previous run's notation

\[
\mathscr R_M(t)
=
N E_{m\in M}
\left[
\Phi_t(\beta_f(m)^2)-\Phi_t(\beta_1(m)^2)
\right],
\qquad
\Phi_t(x)=\frac{x}{x+t}.
\tag{4.1}
\]

Because `M` contains all affine masks,

\[
E_M\beta_f(m)^2
=E_M\beta_1(m)^2
=\frac1N.
\tag{4.2}
\]

Also

\[
E_M\beta_f(m)^{2r}
-E_M\beta_1(m)^{2r}
=-C_{M,r}.
\tag{4.3}
\]

Hence if

\[
C_{M,r}=0
\qquad(1\le r<R),
\tag{4.4}
\]

then the paired functional annihilates every polynomial `xq(x)` with `deg q<=R-2`.

Set

\[
g_t(x)=\frac1{x+t},
\qquad
\Phi_t(x)=xg_t(x).
\]

Map `[0,1]` to `[-1,1]`. The exact Chebyshev expansion of `g_t` has geometric ratio

\[
\vartheta(t)
=(\sqrt{1+t}-\sqrt t)^2
=e^{-2\operatorname{arsinh}\sqrt t}.
\tag{4.5}
\]

Truncating after degree `R-2` gives a polynomial `q` satisfying

\[
\|g_t-q\|_\infty
\le
\frac{\vartheta(t)^{R-3/2}}
{t\sqrt{1+t}}.
\tag{4.6}
\]

The potentially fatal factor `N` cancels because the error is multiplied by `x` and `(4.2)` gives total mass `1/N` on each side:

\[
\boxed{
|\mathscr R_M(t)|
\le
\frac{2\vartheta(t)^{R-3/2}}
{t\sqrt{1+t}}.
}
\tag{4.7}
\]

No dimension-dependent prefactor is hidden here.

## 4.2 Apply to one degree-`q` monomial append

Consider any actual degree-`q` monomial gate during the compiler, `q>=3`. Immediately before that gate, the mask code `M` already contains

\[
RM(q-1,n).
\]

Therefore

\[
D=M^\perp
\subseteq
RM(q-1,n)^\perp
=
RM(n-q,n),
\]

whose minimum distance is

\[
2^q.
\tag{4.8}
\]

The same is true after adjoining the gate. Put

\[
R_q=2^{q-1}.
\]

If `2<=r<R_q`, any frustrated `2r`-tuple would have a nonzero parity support in the relevant dual code of size at most `2r<2^q`, contradicting `(4.8)`. A zero parity support has Boolean product `+1` and is not frustrated. Hence, both before and after the individual gate,

\[
\boxed{
C_{M,r}=C_{M+\langle g\rangle,r}=0
\qquad(2\le r<R_q).
}
\tag{4.9}
\]

Apply `(4.7)` to the two endpoints and subtract. For every `t>0`,

\[
\boxed{
|\Delta_g\mathscr R(t)|
\le
\frac{4\vartheta(t)^{R_q-3/2}}
{t\sqrt{1+t}}.
}
\tag{4.10}
\]

This is an **individual-gate** light cone.

## 4.3 Integrated gate light cone

For `0<t<=2`,

\[
\operatorname{arsinh}\sqrt t\ge\sqrt{t/3}.
\]

For `R_q>=4`, `(4.10)` therefore gives

|\Delta_g\mathscr R(t)|
\le

\tag{4.11}

\boxed{

This estimate keeps the gate fixed until after the signed exact response is formed. The absolute value is taken only after the moment gap produces a uniformly summable tail.

# 5. `P03-INDIVIDUAL-MESOSCOPIC-TURNOVER-65` — **PROVED**

The previous completed-degree-block theorem paid mesoscopic endpoint variation after `O(log n)` degrees. Claim 64 upgrades this to the total variation of the **individual monomial gates**.

Fix a resolvent scale

\[
0<t_0\le2
\]

and an integer `q_0>=3`. Let `G` be any collection of actual compiler gates of degrees at least `q_0`. For any `z>0` satisfying

\[
\frac{3z^2}{4^{q_0-1}}\le t_0,
\tag{5.1}
\]

every gate in `G` has its own light-cone threshold below `t_0`. Therefore `(4.12)` gives

\[
\boxed{
\sum_{g\in G}
\int_{t_0}^2
|\Delta_g\mathscr R(t)|\,dt
\le
8|G|\frac{e^{-z}}z.
}
\tag{5.2}
\]

For the actual compiler, `|G|<=2^n=N`. Set

\[
z_{N,J}
=
\ln\left(8N\left(1+\frac1J\right)\right).
\tag{5.3}
\]

Then

\[
8Ne^{-z_{N,J}}
=
\frac{J}{1+J},
\]

so whenever

\[
q_0
\ge
1+
\left\lceil
\log_2\frac{\sqrt3\,z_{N,J}}{\sqrt{t_0}}
\right\rceil,
\tag{5.4}
\]

we obtain the universal summable bound

\[
\boxed{
\sum_{\substack{g\text{ actual compiler gate}\\\deg g\ge q_0}}
\int_{t_0}^{2}
|\Delta_g\mathscr R(t)|\,dt
\le
\frac{J}{(1+J)z_{N,J}}
\le J.
}
\tag{5.5}
\]

This is a genuine total **individual-gate absolute-variation** theorem on the mesoscopic interval. Consequently the cumulative positive turnover on the same interval is also at most `J`.

The absolute values in `(5.5)` are legitimate: the resulting bound is universally summable. Nothing here infers positive turnover from a bounded alternating endpoint.

Every noncharacter has

\[
J(f)\ge\frac2N.
\tag{5.6}
\]

Indeed every nontrivial folded coordinate influence is an integer multiple of `2/N`, and `J=0` characterizes a cube character after the gauge.

Thus

\[
z_{N,J}\le\ln(8N(1+N/2))=O(n).

For example at

\[

it is enough to take

\[
q_0
=
\max\left\{3,
1+\left\lceil\log_2(8z_{N,J})\right\rceil
\right\}
=
O(\log n).
\tag{5.7}
\]

Hence:

\[
\boxed{
\text{outside the first }O(\log n)\text{ degree layers, all individual-gate}
\atop
\text{turnover on }[1/16,2]\text{ is already paid by }J.
}
\tag{5.8}
\]

This substantially sharpens the preceding `P03-LOGDEG-MESOSCOPIC-REDUCTION-56`, which controlled only completed-degree-block variation.

The theorem does **not** bound the same gates on `0<t<t_0`. In the rare regime `J` can be of order `N^{-1}`, so choosing `t_0=J/(2N)` pushes `(5.4)` too far to close the half-band by itself. The surviving problem remains an ultramicroscopic signed source/selector correlation problem.

# 6. `P03-PARENT-WALSH-GATE-66` — **PROVED**

The latest P03 report identified the exact primal gate correlation product as the best next object. For a monomial gate, its full parent geometry produces an exact higher-order signed finite difference.

Identify the physical truth-table points with `x in F_2^n`. Let

\[
g(x)=\prod_{i\in S}x_i,
\qquad |S|=q\ge2,
\tag{6.1}
\]

be an actual degree-`q` monomial gate. Immediately before `g`, the compiler code `M` contains every parent

\[
p_i(x)=\prod_{j\in S\setminus\{i\}}x_j,
\qquad i\in S.
\tag{6.2}
\]

For `m in M`, put

\[
h_m(x)=f(x)(-1)^{m(x)}.
\]

Partition the gate-coordinate patterns into

\[
F_*:=\{x:x_i=1\ \forall i\in S\},
\]

\[
F_i:=\{x:x_i=0,\ x_j=1\ \forall j\in S\setminus\{i\}\},
\]

and let `F_rest` be the remaining patterns. Define normalized signed cell correlations

\[
c_*(m)=\frac1N\sum_{x\in F_*}h_m(x),
\qquad
c_i(m)=\frac1N\sum_{x\in F_i}h_m(x),
\]

\[
r(m)=\frac1N\sum_{x\in F_{\rm rest}}h_m(x).
\tag{6.3}
\]

Then

\[
\beta_f(m)=r+c_*+\sum_{i\in S}c_i,
\qquad
\beta_f(m+g)=r-c_*+\sum_{i\in S}c_i.
\tag{6.4}
\]

Let

\[
H_t(y)=\frac{y^2}{y^2+t}.
\]

Define the source half of the exact gate response by

\[
A_f(t)
=
E_{m\in M}
[H_t(\beta_f(m))-H_t(\beta_f(m+g))].
\tag{6.5}
\]

The paired gate response is

\[
\Delta_g\mathscr R(t)
=
\frac N2[A_f(t)-A_1(t)].
\tag{6.6}
\]

## 6.1 Parent subgroup action

Adding `p_i` flips the signs on exactly `F_*` and `F_i`. Therefore the parent subgroup acts by

\[
c_i\mapsto s_i c_i,
\qquad
c_*\mapsto\left(\prod_i s_i\right)c_*,
\qquad
r\mapsto r,
\]

with `s_i in {+1,-1}`. Since `M` is invariant under all parent translations,

\[
A_f(t)
=
E_m\Psi_{q,t}(r,c_*,c_1,\ldots,c_q),
\tag{6.7}
\]

where

\[
\boxed{
\Psi_{q,t}
=
2^{-q}\sum_{s\in\{\pm1\}^q}
\left(\prod_i s_i\right)
\left[
H_t\!\left(r+\sum_i s_ic_i+c_*\right)
-
H_t\!\left(r+\sum_i s_ic_i-c_*\right)
\right].
}
\tag{6.8}
\]

This already retains the sign of every parent-cell correlation.

## 6.2 Exact derivative representation

Repeated application of the fundamental theorem of calculus gives

\[
\boxed{
\Psi_{q,t}
=
\frac{c_*\prod_{i=1}^q c_i}{2^q}
\int_{[-1,1]^{q+1}}
H_t^{(q+1)}
\left(
 r+c_*u_0+\sum_{i=1}^q c_i u_i
\right)\,du.
}
\tag{6.9}
\]

No absolute value has been taken. Equation `(6.9)` is an exact first-separator recurrence for the actual monomial face geometry.

## 6.3 Exact even-degree cancellation

Because `H_t` is even, the finite difference obeys

\[
\boxed{
\Psi_{q,t}(-r,c_*,c_1,\ldots,c_q)
=
(-1)^{q+1}\Psi_{q,t}(r,c_*,c_1,\ldots,c_q).
}
\tag{6.10}
\]

Hence for **even** `q`, the gate functional is odd in the rest-cell correlation and vanishes identically when `r=0`. More precisely,

\[
\boxed{
\Psi_{q,t}
=
\frac{r c_*\prod_{i=1}^q c_i}{2^{q+1}}
\int_{[-1,1]^{q+2}}
H_t^{(q+2)}
\left(
ru_{q+1}+c_*u_0+\sum_i c_i u_i
\right)\,du,
\qquad q\text{ even}.
}
\tag{6.11}
\]

For the quadratic layer, `(6.11)` says that after the exact parent-character averaging the source gate response contains the product of the four quadrant correlations. This is a signed fourth-order cancellation, not a positive bad-block count.

## 6.4 A rigorous absolute corollary — useful but not universally closing

For `m>=1`, partial fractions give

\[
\|H_t^{(m)}\|_\infty\le m!\,t^{-m/2}.
\tag{6.12}
\]

If `q>=4`, the dual distance `2^q` implies that the masked signs under uniform `m in M` have the same moments as independent Rademachers through order `2(q+1)`. Every `F_i` and `F_*` has size `N/2^q`, so the Rademacher moment bound gives

\[
\|c_i\|_{2(q+1)},\ \|c_*\|_{2(q+1)}
\le
\frac{\sqrt{2q+1}}{\sqrt{N2^q}}.
\tag{6.13}
\]

Hölder and `(6.9)` yield the individual-gate bound

\[
\boxed{
|\Delta_g\mathscr R(t)|
\le
2(q+1)!(2q+1)^{(q+1)/2}
N^{-(q-1)/2}
2^{-q(q+1)/2}
 t^{-(q+1)/2}.
}
\tag{6.14}
\]

For even `q>=4`, `(6.11)` supplies one additional correlation factor and one obtains

\[
\boxed{
|\Delta_g\mathscr R(t)|
\le
2(q+2)!(2q+3)^{(q+2)/2}
N^{-q/2}
2^{-q(q+1)/2}
 t^{-(q+2)/2}.
}
\tag{6.15}
\]

These are valid absolute estimates because the relevant finite moments lie below the exact dual-distance threshold. They are **not** promoted to a universal FEI payment: near `t=0` their singular powers can overwhelm `J` in the rare regime. Their role is diagnostic and complementary to the exponentially decaying Chebyshev light cone.
