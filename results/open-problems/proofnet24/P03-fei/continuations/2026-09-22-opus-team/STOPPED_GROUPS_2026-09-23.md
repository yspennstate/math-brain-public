# Groups stopped before their reports (23 September 2026)

Ten groups were stopped mid-run to save compute budget: W2-A and W3-01, 02, 03, 05, 06, 07, 08, 09, 10. None of them wrote a report. This page records what their own logs and code show. Each item gives its log file, so every number can be traced. A claim is marked "certified" only when the group's interval computation says so and the certificate is in its folder. Everything else here is numerical, has no written proof, and has not been refereed.

## Results worth keeping

1. A 10-variable function beating Hod's bound (W3-10, `logs/certify_restriction_k10.log`, `logs/best_restriction_k10.txt`). Fixing 8 of the 18 variables of Numaro's g gives a balanced, prime function on 10 variables with I = 257/128 and H = 6.50983612758815148, so H/(I−1) = 6.45937228163785573. By the O'Donnell–Tan amplification this gives C_FEI ≥ 6.4593, which beats Hod's 6.4547837 using 10 variables instead of 18. Numaro's 6.5218 is still the record. The group certified H and J with 70-digit interval arithmetic. The coordinator recomputed both from the truth table with an exact integer Walsh transform and got the same digits (mean 0, I = 257/128, H/(I−1) = 6.4593722816378557316). The best 12-variable restriction reaches 6.47544 (`logs/numaro_restrictions.log`). The best prime restriction at each arity is 6.000 (4), 6.347 (6), 6.459 (10) and 6.475 (12). Arities 5, 7 and 11 have no balanced prime restriction.

2. H ≤ 4I for every AND/OR chain (W3-09, `code/cert_chains.py`, `logs/cert_chains.log`, `logs/chains_*.log`). An AND/OR chain x1 ∧ (x2 ∨ (x3 ∧ …)) is a linear threshold function. The group reduced "H ≤ 4I for every chain" to the positivity of an explicit function Φ_8 on [1/2, 1). Φ_8 is built from ε(p) = 4p² + (2/ln 2)[g(p) + g(1−p)] − g(|1−2p|)/ln 2 with g(x) = x² ln x, summed along the doubling map. They certified Φ_8 ≥ 0.02079 on every dyadic cell with mpmath interval arithmetic. The analytic steps (the reduction, the monotonicity of the two series parts, the tail bound) are described in the script's docstring as "checked in REPORT", and that report was never written. The coordinator has since rebuilt the argument from the certificate's definitions and written it out in [W3-09-ltf-sharp/REPORT.md](W3-09-ltf-sharp/REPORT.md); the unrolled formula matches exact Walsh sums on 300 random chains, and a re-run of the certificate reproduced its output. The constant 4 is sharp: chains reach H/I = 3.99515 as t → 0 (`chains_defect3.log`), and AND_n has H/I → 4. In the referee's searches (W2-A, n ≤ 22) no linear threshold function exceeded H/I = 3.981. So the evidence points to 4 as the sharp FEI constant for linear threshold functions. F5 proved 14.2142.

3. An explicit min-entropy constant for unate functions (W3-03, `code/w303_unate_constant.py`, `logs/unate_constant.log`). For monotone f and i ∈ S, f̂(S) = E[D_i f · χ_{S∖i}], so |f̂(S)| ≤ Inf_i(f). Hence H_∞(f) = min(log2 1/(1−Var f), 2 log2 1/max_i Inf_i) exactly. Combining this with an explicit KKL lemma, ln(1/δ) ≤ coth(a/2)(ln u + (u−1)a) for every a > 0 where u = I/Var, gives H_∞ ≤ C_u·I with C_u = sup_u R(u). An interval computation bounds C_u ≤ 7.18126, and numerically the supremum is 7.0404, at u = 8.76. The qualitative statement (FMEI for monotone functions through KKL) is standard; the explicit constant is the new part. The lemma's proof is not written out in the folder. Exhaustive search over monotone functions with n ≤ 6 gives max H_∞/I = 2.169. AND_n has H_∞/I → 2/ln 2 = 2.8854 (`or_of_rare.log`). So the sharp unate constant lies between 2.885 and 7.181.

4. The referee's numerical checks of F5's LTF proof (W2-A, `logs/SUMMARY_numbers.txt`). The checks were written independently of F5's code. Every lemma of F5's proof was evaluated on structured families of linear threshold functions (326 to 451 functions at n = 12, 16, 20, plus targeted cases at n = 22) and on annealed integer-weight instances at n = 9 and 11, with exact ties. The self-test against the definitions has 0 mismatches. Every worst ratio is below 1: Lemma 2 0.7675, Lemma 3 0.2572 (tail 0.4824), Lemma 4 0.1479, Lemma 5 0.8392, Lemma 6 0.4074, Theorem 1 at most 0.2801. The pointwise Littlewood–Offord step reaches exactly 1.000000 and never exceeds it, so that step is tight. The identity E[|S ∩ U_i| : i ∈ S] = (N_i − 1)/2 holds exactly on 2,228 pairs. The constants were recomputed to 40 digits: C = 14.214188086005913764, L1 = 4.1511069801549289, a* = 1.2006422748676162407. For majority, the Lemma 3 and Lemma 4 ratios tend to 2 ln 2/L1 = 0.33396 and (2 ln 2 − 1/2)/L1 = 0.21351. The referee did not finish its written reading of the proof. The status of F5 therefore stays "claimed, audited by the coordinator, numerically checked by an independent referee".

## Partial runs with no conclusion yet

- W3-02, transitive functions (`logs/exhaust_B33.json`, `certify_kt33.log`, `anneal_*_bal_s1.json`). Exhaustive search over the 2^25 functions invariant under the symmetry group of K3,3 on 9 variables gives the balanced maximum H/(I−1) = 6.28317519 (certified; I = 261/128, the same as Numaro's g, and H = 6.52861). Towers of this function stay at 6.28316. Annealing over balanced functions invariant under cyclic, PSL(2,q), AGL(1,q) and wreath-product groups up to n = 20 found nothing above 6.0. No transitive function beat 6.4548.
- W3-06, new hosts (`logs/families*.out`, `groups_m*.log`, `certify_base.log`). The record function is two parallel classes of AG(2,3) with coins, which is the same object as PM(K3,3) with coins. Adding more parallel classes lowers the value (5.43, 4.90), and so do PM(K4,4), PM(K4), PM(K6), majority with free middle sites, and wreath-product symmetric hosts (every one ≤ 5.71). A tie coin on 4 variables has H/(I−1) = 6 exactly. No new record.
- W3-07, value iteration over all gates (`logs/thresh_G7.json`, `policy_*.out`, `test_core.out`). The core reproduces F3's G7 witness to 12 digits (D = −6.784395770749e−3). At C = 6.4548 the iteration over the tested gate families (NPN classes of arity 4, restricted gates of arity 6, G7) converged in three rounds, with worst residual −9.9e−8 on G7. The threshold search was cut short by a script error (`thresh_G7.out`). No certified statement.
- W3-08, multiscale restriction (`logs/tower_validate.log`, `check_flow_tensor.log`, `check_mixing_bound.log`, `exist_delta_n4.log`). The group's restricted-entropy functional D_δ satisfies an exact composition law for biased compositions and exact tensorization D(f·g) = D(f) + D(g) on disjoint variables. The flow identity ∫E A(f_t) dt = D_δ(f) was checked to 1e−14. The mixing bound M_J ≤ (2/ln 2)·Inf(J^c) holds on every function tested, with worst ratio 2.3987. On n = 4, every function has some δ ≥ 0.9 with κ_δ ≤ 4.78. No induction was closed.
- W3-05, semigroup interpolation (`code/exhaust_n4.py`, `logs/exhaust_n4.log`, `families.log`). The group found and checked on all functions with n ≤ 4 the identity H = H_∞ + 2∫_0^∞ Cov_{q_t}(|S ⊕ U|, log 1/w) dt along a tilted semigroup. It also checked the small-δ expansion H(S_δ)/(δI) → log(1/δ) + 1 + Σ_i (Inf_i/I) log(1/Inf_i) of the thinned spectral law. `gauged_numaro.py` was still running on Numaro's g when the group stopped.
- W3-01, monotone functions (`logs/testbed.log`, `exhaust_n*.log`, `shift_*.log`). Shifting never increases total influence (Hart; checked exhaustively for n ≤ 5), but it can lower the entropy by up to 0.897·I (`shift_loss_search.log`). So a reduction of FEI to shifted monotone functions by compression loses a constant and needs a separate argument. Exhaustive checks of the F5-type bound on "regular" monotone functions for n ≤ 6 gave max H/I ≤ 3.40, far below the bound C(K).

All of these folders keep their code, so any run can be resumed from its last log.
