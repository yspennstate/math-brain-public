## 4. New theorem: exact hybrid block-tree compiler

### Theorem 4.1 — exact physical block influence budget

For every physical block `A`,

\[
\boxed{
I(f)=I_A(f)+2^{-|A|}\sum_a I(f_{A=a}),
}
\tag{4.1}
\]

where the child influence is over the surviving coordinates.

**Proof.** For `i in A`, its root edge boundary is included exactly once in `I_A`. For every `j notin A`, averaging `Inf_j(f_{A=a})` over the cylinder assignments `a` counts exactly the same `j`-edges as `Inf_j(f)`, partitioned by their `A`-coordinate labels. Summing over all coordinates gives (4.1). QED.

Consequently, on any adaptive physical block tree `T`,

\[
\sum_{v\in T^\circ}w_v I_{A_v}(f_v)
=I(f)-\sum_{\ell}w_\ell I(f_\ell)\le I(f).
\tag{4.2}
\]

This is a true resource budget; no independence or fresh coordinate is introduced.

### Theorem 4.2 — hybrid selector compiler

Fix `theta>0`. Suppose there is a finite `K_theta` such that every Boolean state of dimension at least two and nonzero Fourier entropy has some nonempty proper physical block `A` satisfying

\[
B_A(f)+\theta E_A(f)\le K_\theta I_A(f).
\tag{4.3}
\]

Then full FEI holds, with

\[
\boxed{
H(f)\le \frac{2K_\theta}{1+\theta\ln2}\,I(f)
}
\tag{4.4}
\]

for every Boolean function in every dimension.

**Proof.** Recursively choose a block satisfying (4.3) and stop at dimension zero or one. Every Boolean function on one bit is a signed character or constant, hence has Fourier entropy and `Phi_1` equal to zero. Let

\[
R_T=\sum_v w_v B_{A_v}(f_v).
\]

The current arbitrary-block Walsh theorem applies to each physical coordinate-projection block and gives

\[
H(f)\le2R_T.
\tag{4.5}
\]

The endpoint charges telescope exactly on the same dependent tree:

\[
\sum_vw_vE_{A_v}(f_v)=\Phi_n(f).
\tag{4.6}
\]

Summing (4.3), using (4.2), gives

\[
R_T+\theta\Phi_n(f)\le K_\theta I(f).
\tag{4.7}
\]

The previously proved dyadic endpoint theorem gives

\[
\Phi_n(f)\ge\frac{\ln2}{2}H(f).
\tag{4.8}
\]

Therefore

\[
H(f)\le2R_T
\le2K_\theta I(f)-2\theta\Phi_n(f)
\le2K_\theta I(f)-\theta\ln2\,H(f),
\]

which is (4.4). QED.

For the checker below `theta=1`, so a proof of (3.3) would yield coefficient `2K/(1+ln2)`.

This is not a proof of (3.3). It is a new exact compiler joining two previously separate full-scope routes: true hereditary allocation and dimension-adaptive endpoint rebate.
