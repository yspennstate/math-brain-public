# Approach 1 — B18/B25: root pivotal and square-pivotal representation of an adaptive stopping tree

The node formulas hide the actual correlation structure.  Translate them back to the root cube.

For uniform `X`, define the root edge-pivotal indicators
\[
P_i(X)=\mathbf 1\{f(X)\ne f(X^{(i)})\}
\]
and square-pivotal indicators
\[
P_{ik}^{(2)}(X)
=\mathbf 1\{
f(X)f(X^{(i)})f(X^{(k)})f(X^{(i,k)})=-1
\},
\qquad i<k.
\]
Let `Q(X)` be the set of coordinates queried along the stopping-tree path followed by `X`.

## Theorem 1 — exact correlated root representation

For every finite adaptive physical stopping tree with no repeated query on one root-to-leaf path,
\[
\boxed{
Q_T=\sum_i\mathbb E[P_i(X)\mathbf 1_{\{i\in Q(X)\}}],
}
\tag{1.1}
\]
\[
\boxed{
I_L=\sum_i\mathbb E[P_i(X)\mathbf 1_{\{i\notin Q(X)\}}],
}
\tag{1.2}
\]
and, with
\[
\mathcal C_T
=\sum_{v\ {\rm int}}w_v I(D_{i(v)}f_v),
\]
\[
\boxed{
\mathcal C_T
=\sum_{i<k}\mathbb E[
P_{ik}^{(2)}(X)\mathbf 1_{\{i\in Q(X)\ {\rm or}\ k\in Q(X)\}}
].
}
\tag{1.3}
\]

If
\[
\mathcal C_2(f)=\sum_{i<k}\Pr(P_{ik}^{(2)}=1),
\qquad
\mathcal C_{2,L}=\sum_\ell w_\ell\mathcal C_2(f_\ell),
\]
then
\[
\boxed{\mathcal C_2(f)=\mathcal C_T+\mathcal C_{2,L}.}
\tag{1.4}
\]

### Proof

A node cylinder that queries `i` has not fixed `i`.  On that cylinder the conditional probability of the root event `P_i=1` is exactly `Inf_i(f_v)`.  For a fixed `i`, cylinders at which `i` is queried are disjoint root events, and their union is `{i in Q(X)}`.  Summing gives (1.1).

At a stopping leaf, coordinate `i` contributes to `I(f_l)` exactly when it was not queried; its leaf influence is the conditional probability of the same root event `P_i=1`.  Summing leaf cylinders gives (1.2).  In particular (1.1)+(1.2) reproves (R1) without discarding branch dependence.

For (1.3), at a node querying `i`,
\[
I(D_i f_v)
=\sum_{k\ {\rm free},\,k\ne i}
\Pr(P_{ik}^{(2)}=1\mid X\hbox{ reaches }v).
\]
For a fixed pair `{i,k}`, the square is charged at exactly one node if the stopping path queries at least one endpoint: the node where the first endpoint of that pair is queried.  If neither endpoint is queried before stopping, it is not charged.  Summing the disjoint first-hit cylinders gives (1.3).  The complementary event is exactly that both endpoints survive to the leaf, which proves (1.4).  QED.

Equation (1.3) is the ordinary P03 curvature telescope in a root-level **correlated random-cover** form.  The reformulation matters: the query set `Q(X)` is allowed to depend on the same `X` on which the edge and square events are evaluated.  No independence is inserted.

# Approach 3 — B6: fold square curvature before accumulating it

Ordinary `I(D_i f)` is badly sensitive to a quadratic gauge: multiplying `f` by a quadratic phase multiplies `D_i f` by a character.  Total influence of the derivative can therefore change, although the dangerous part is only whether a derivative coordinate is genuinely non-character-like.

For `i<k`, put
\[
c_{ik}(f)=\Pr(P_{ik}^{(2)}=1),
\qquad
\bar c_{ik}(f)=\min\{c_{ik}(f),1-c_{ik}(f)\},
\]
and define
\[
\boxed{
\mathfrak F_2(f)=\sum_{i<k}\bar c_{ik}(f).
}
\tag{3.1}
\]

Because `Inf_k(D_i f)=c_{ik}(f)`,
\[
\boxed{
J(D_i f)=\sum_{k\ne i}\bar c_{ik}(f).
}
\tag{3.2}
\]

## Lemma 3 — folded local curvature

Let
\[
\kappa_3=4h_2(1/4)=3.245112497836531\ldots.
\]
For every Boolean `f` and physical coordinate `i`,
\[
\boxed{
B_i(f)\le\frac12J(D_i f)+\kappa_3 j_i(f).
}
\tag{3.3}
\]

### Proof

Write `j=j_i(f)` and, if necessary, replace `D_i f` by its negative so its minority sign has density `j`.  This does not change any derivative influence or `J(D_i f)`.

If `j<=1/4`, then for every residual coordinate `k`,
\[
\operatorname{Inf}_k(D_i f)
\le
\Pr(D_i f\hbox{ is minority})
+\Pr(D_i f(\cdot^{(k)})\hbox{ is minority})
\le2j\le\frac12.
\]
Hence every derivative influence is already folded and
\[
J(D_i f)=I(D_i f).
\]
The proved P03 curvature bound (R4) gives
\[
B_i(f)\le\frac12J(D_i f)+\frac1{\ln2}j
\le\frac12J(D_i f)+\kappa_3j.
\]

If `j>=1/4`, conditioning only lowers entropy, so
\[
B_i(f)\le H(Z_i)=h_2(j).
\]
The function `h_2(t)/t` is decreasing on `(0,1/2]`, because
\[
\frac{d}{dt}\frac{h_2(t)}t
=\frac{\log_2(1-t)}{t^2}<0.
\]
Therefore
\[
h_2(j)\le\frac{h_2(1/4)}{1/4}\,j
=\kappa_3j.
\]
This proves (3.3).  QED.

## Lemma 4 — folded square curvature is a restriction supermartingale

For every query coordinate `i`,
\[
\boxed{
\mathfrak F_2(f)
\ge
J(D_i f)
+\frac{\mathfrak F_2(f^+)+\mathfrak F_2(f^-)}2.
}
\tag{3.4}
\]

### Proof

The terms of `\mathfrak F_2(f)` incident to `i` sum exactly to `J(D_i f)` by (3.2).  For a pair `{k,l}` disjoint from `i`, its square probability is the average of the corresponding child probabilities:
\[
c_{kl}(f)=\frac{c_{kl}(f^+)+c_{kl}(f^-)}2.
\]
The folding map `phi(t)=min(t,1-t)` is concave on `[0,1]`, hence
\[
\bar c_{kl}(f)
\ge\frac{\bar c_{kl}(f^+)+\bar c_{kl}(f^-)}2.
\]
Sum over nonincident pairs and add the incident terms.  QED.

Likewise, because the same concavity applies to ordinary influences of unqueried coordinates,
\[
J(f)\ge j_i(f)+\frac{J(f^+)+J(f^-)}2. \tag{3.5}
\]
Thus for every full physical tree,
\[
\sum_{v\ {\rm int}}w_vJ(D_{i(v)}f_v)\le\mathfrak F_2(f),
\qquad
J_T\le J(f). \tag{3.6}
\]

For every Boolean function in every dimension,
\[
\boxed{
H(f)\le
\frac12\mathfrak F_2(f)
+\left(\kappa_3+\frac2{\ln2}\right)J(f).
}
\tag{3.7}
\]

Numerically,

=6.130502579614458\ldots.

## Structural properties of `\mathfrak F_2`

### Quadratic-gauge invariance

If `Q` is any `F_2` quadratic polynomial, then the multiplicative `i,k` square of `(-1)^Q` is a constant sign.  Hence quadratic twisting sends each `c_{ik}` either to itself or to `1-c_{ik}`.  Therefore
\[
\boxed{
\mathfrak F_2((-1)^Qf)=\mathfrak F_2(f).
}
\tag{3.8}
\]
This is exact for arbitrary quadratic coupling, not only character-valued rows.

### Tensor additivity

For disjoint products,
\[
\boxed{
\mathfrak F_2(f\otimes g)=\mathfrak F_2(f)+\mathfrak F_2(g).
}
\tag{3.9}
\]
Pairs inside one factor retain their square law; cross-factor squares are identically `+1`.  Also `J(f\otimes g)=J(f)+J(g)`.  Thus the scalar ratio `\mathfrak F_2/J`, when finite, is not amplified by tensor powers.

### Exact cubic 2-shadow formula

For a phase `f=(-1)^P` with `deg P<=3`, the second `F_2` derivative in a pair `{i,k}` is affine.  Its linear part is nonzero exactly when `{i,k}` lies in at least one cubic monomial of the ANF of `P`.  Therefore the square law is balanced in exactly those pairs and deterministic in every other pair.  If `Sh_2(P_3)` denotes the 2-shadow of the cubic monomial support,
\[
\boxed{
\mathfrak F_2((-1)^P)=\frac12|Sh_2(P_3)|.
}
\tag{3.10}
\]
Quadratic and lower terms do not enter (3.10).  This is the promised extension beyond character-valued quadratic derivatives: arbitrary quadratic coupling is automatically quotiented out at this second-order folded level.

## 4.1 One-point defects refute `F2<=KJ`

Let `w_n` be `-1` at one input and `+1` elsewhere.  Every coordinate has
\[
j_i(w_n)=2^{1-n},
\qquad
J(w_n)=n2^{1-n}.
\]
For every pair, the square is odd exactly on the unique two-face containing the defect, so
\[
c_{ik}=2^{2-n}
\]
and this is already folded for `n>=3`.  Hence
\[
\mathfrak F_2(w_n)
={n\choose2}2^{2-n},
\qquad
\boxed{\frac{\mathfrak F_2(w_n)}{J(w_n)}=n-1.}
\tag{4.1}
\]
Thus no finite universal `K` can satisfy `\mathfrak F_2<=KJ`.

This does not harm FEI: the existing one-point allocation is bounded and the newest finite-defect theorem can stop this family without paying the full folded curvature.

## 4.2 Addressing independently refutes the same scalar closure

For the standard addressing function
\[
\operatorname{Addr}_s(a,y)=y_a,
\qquad a\in\{0,1\}^s,\quad |y|=2^s,
\]
each address bit has influence `1/2`, while the data influences sum to `1`.  Thus
\[
J(\operatorname{Addr}_s)=\frac s2+1.
\]
For two distinct address bits, the square parity is balanced, giving folded mass `1/2`.  For an address bit and a data bit, the square is odd with probability `2/2^s`.  Data--data squares are trivial.  Therefore
\[
\mathfrak F_2(\operatorname{Addr}_s)
=\frac{s(s-1)}4+2s,
\]
and
\[
\boxed{
\frac{\mathfrak F_2}{J}
=\frac{s(s+7)}{2(s+2)}
\sim\frac s2.
}
\tag{4.2}
\]
Again the scalar closure fails, while addressing itself has other known FEI/partition certificates.

## 4.3 A pointwise square-to-edge payment is impossible

For the two-bit quadratic phase `f(x_1,x_2)=(-1)^{x_1x_2}`, at `x=(0,0)` both root edge-pivotal indicators vanish but the square-pivotal indicator equals one:
\[
P_1(0)=P_2(0)=0,\qquad P_{12}^{(2)}(0)=1.
\]
Hence no pointwise finite-constant rule can pay a hit square solely from the edge-pivotal indicators at the same root point.  The expectation and shift correlation in Theorem 1 are essential.

## 4.4 The natural addressing tree also defeats fixed two-account constants

Querying all address bits and stopping at the data-character leaves gives
\[
Q_T=\frac s2,\qquad I_L=1,
\]
while the exact first-hit curvature is
\[
\mathcal C_T
=\frac{s(s-1)}4+2s.
\]
Thus no fixed pair `(K_Q,K_L)` pays
\[
\mathcal C_T\le K_QQ_T+K_LI_L
\]
for this **particular natural tree** as `s` grows.  This is not a refutation of Theorem 2 or of the existence of some other certified tree; it says the universal proof cannot simply choose the obvious address-selector tree and reuse fixed curvature coefficients.

## 4.5 Descendant lifetime still overcharges independent structure

The exact lifetime identity (1.5) shows the issue cleanly.  In a fixed full coordinate order for `w_n`, the lifetime-to-`J` ratio is `(n-1)/2`.  For the natural addressing tree it is
\[
\frac{s(s+3)}{2(s+2)}\sim\frac s2.
\]
And if disjoint tensor factors are queried sequentially, the untouched factors' influences are charged during earlier queries even though their cross square curvature is zero.  This is why the square-pivotal resource is a better interaction detector than raw descendant influence, while the finite-defect and addressing examples show why even the folded square resource still needs a hereditary stopping/certificate mechanism.

# remaining_full_scope_gap

The run does **not** prove a universal finite FEI constant.  It narrows the remaining allocation problem in a different direction.

The useful new global resource is
\[
\mathfrak F_2
=\sum_{i<k}\min(c_{ik},1-c_{ik}),
\]
because it is:

- all-dimensional;
- exactly quadratic-twist invariant;
- exactly tensor additive;
- restriction-supermartingale;
- directly linked to local spectral-bit allocation by Lemma 3.

But `\mathfrak F_2/J` is globally unbounded, already on one-point defects and addressing.  Therefore the next legitimate target is **hereditary folded-curvature stopping**, not another scalar constant:

> Construct, for every Boolean `f`, an adaptive stopping tree whose high `\mathfrak F_2` pieces are stopped inside already-certified classes (finite-defect, symmetric/addressing-like, quadratic/controlled, etc.), while the consumed folded curvature is paid by queried influence and/or residual certified leaf influence with dimension-free constants.

Equivalently, use the root representation to find a correlated random cover `Q(X)` for the square-pivotal process that satisfies an **expected** two-account bound, not a false pointwise one.  The addressing calculation shows that the obvious selector tree is insufficient; the tensor calculation shows that any replacement should ignore cross-component noninteraction.  This is a concrete dependency/interaction problem, not a restatement of FEI.

A second live option is to build a Bellman functional from the folded derivative costs `J(D_i)` but with explicit certified stopping before one-point/addressing regimes.  A raw scalar `F2<=KJ` or raw full-depth pivotal-lifetime bound is now retired by the exact counterexamples above.
