## 4. New theorem: exact folded-influence pruning

Let `f` be Boolean. For a physical coordinate `i`, write

\[
\alpha_i=\operatorname{Inf}_i(f),\qquad
j_i=\min\{\alpha_i,1-\alpha_i\}.
\]

Fix `0<tau<=1/2` and set

\[
\kappa(\tau)=\frac{\Psi(\tau)}{\tau}.
\]

### Theorem 4.1 — threshold pruning compiler

There is a finite adaptive physical restriction tree with the following properties.

At every internal node `v` carrying a Boolean section `f_v`, the queried coordinate `i(v)` satisfies

\[
j_{i(v)}(f_v)\ge\tau.
\tag{4.1}
\]

Every terminal leaf `ell` satisfies

\[
j_i(f_\ell)<\tau
\quad\text{for every remaining coordinate }i.
\tag{4.2}
\]

Writing `w_v` and `w_ell` for the physical cylinder weights,

\[
\boxed{
I(f)=
\sum_{v\in T^\circ}w_v\alpha_{i(v)}(f_v)
+\sum_{\ell}w_\ell I(f_\ell).
}
\tag{4.3}
\]

Moreover

\[
\boxed{
H(f)\le
\kappa(\tau)
\sum_{v\in T^\circ}w_v\alpha_{i(v)}(f_v)
+\sum_{\ell}w_\ell H(f_\ell).
}
\tag{4.4}
\]

No fresh variable, branch independence, controller, symmetry, degree, surjectivity, or derivative-mixture substitution is used.

### Proof

At a nonterminal state choose any coordinate with `j_i>=tau`, reveal its physical bit, and recurse. Dimension drops by one, so the process terminates.

For a single query,

\[
I(f_v)
=
\alpha_i(f_v)
+\frac12 I((f_v)_{i=0})
+\frac12 I((f_v)_{i=1}).
\tag{4.5}
\]

Indeed every edge in the queried direction is paid by `alpha_i`, while for each other physical coordinate its edges partition exactly between the two physical cylinders. Multiplying (4.5) by node weights and telescoping over the tree proves (4.3).

For entropy the restriction identity is exact:

\[
H(f_v)
=
\Delta_iH(f_v)
+\frac12H((f_v)_{i=0})
+\frac12H((f_v)_{i=1}).
\tag{4.6}
\]

The inherited all-dimensional concave restriction theorem gives

\[
\Delta_iH(f_v)\le\Psi(j_i(f_v)).
\tag{4.7}
\]

By (1.4), `Psi(t)/t` decreases. Since `j_i>=tau`,

\[
\Psi(j_i)\le\kappa(\tau)j_i.
\tag{4.8}
\]

Finally `j_i<=alpha_i`, so

\[
\Delta_iH(f_v)
\le\kappa(\tau)\alpha_i(f_v).
\tag{4.9}
\]

Multiply by node weights and telescope (4.6). This proves (4.4). QED.

### Corollary 4.2 — a strict counterexample survives to a low-folded-influence leaf

If `C>=kappa(tau)` and

\[
H(f)>CI(f),
\tag{4.10}
\]

then at least one terminal leaf `h` of the tree satisfies

\[
H(h)>CI(h)
\tag{4.11}
\]

and all of its folded influences are `<tau`.

**Proof.** If every leaf obeyed `H(h)<=CI(h)`, then (4.4), `kappa(tau)<=C`, and (4.3) would imply `H(f)<=CI(f)`, contradicting (4.10). QED.

This is a hereditary localization result: the violating coefficient is preserved, not degraded by tree depth.

## 5. Character folding and the dependency/profile stop

For a Boolean function `h`, define

\[
A(h)=\{i:\operatorname{Inf}_i(h)>1/2\},\qquad
g=\chi_{A(h)}h.
\tag{5.1}
\]

Character multiplication translates the Fourier spectrum, hence

\[
H(g)=H(h).
\tag{5.2}
\]

Across coordinate `i`, multiplication by a character either preserves or reverses the edge sign. Therefore

\[
\operatorname{Inf}_i(g)
=
\min\{\operatorname{Inf}_i(h),1-\operatorname{Inf}_i(h)\}
=j_i(h),
\tag{5.3}
\]

so

\[
I(g)=J(h)\le I(h).
\tag{5.4}
\]

This uses no affine input change and adds no variable.

Drop zero-influence coordinates. For a nonconstant `g`, define

\[
w_i(g)=\frac{\operatorname{Inf}_i(g)}{I(g)}.
\tag{5.5}
\]

The preceding global dependency-bank theorem gives

\[
H(g)\le c_*I(g)(H_2(w(g))+1),
\qquad c_*=\frac2{\ln2}.
\tag{5.6}
\]

### Theorem 5.1 — hard-core localization

Fix `0<tau<=1/2`, `R>=0`, and

\[
C\ge C_0(\tau,R)
=\max\{\kappa(\tau),c_*(R+1)\}.
\tag{5.7}
\]

If a Boolean `f` satisfies `H(f)>CI(f)`, then there is a Boolean `g`, obtained from a physical restriction descendant of `f` and then multiplying only by a character, such that

\[
\boxed{H(g)>CI(g),}
\tag{5.8}
\]

\[
\boxed{0<\operatorname{Inf}_i(g)<\tau
\quad\text{for every active }i,}
\tag{5.9}
\]

and

\[
\boxed{H_2(w(g))>R.}
\tag{5.10}
\]

### Proof

Apply Corollary 4.2 and choose a violating terminal leaf `h`. Character-fold it by (5.1).

Equations (5.2)--(5.4) give

\[
H(g)=H(h)>CI(h)\ge CI(g),

so the same strict coefficient violation survives. Since each folded influence of `h` is `<tau`, (5.3) gives (5.9).

If instead `H_2(w(g))<=R`, then (5.6) would give

\[
H(g)
\le c_*I(g)(R+1)
\le CI(g),

contradicting (5.8). Hence (5.10). QED.

## 6. New compiler equivalence and failure normal form

Define the hard-core class

\[

\left\{

\[

\tag{6.2}
\]

for one finite constant `K_core`. Then every Boolean function satisfies

\[
\boxed{

\le
\max\left\{
\kappa(\tau),
\frac2{\ln2}(R+1),
K_{\rm core}
\right\}

}
\tag{6.3}
\]

Thus a finite universal FEI constant on `H_{tau,R}` is sufficient for full FEI. The converse is immediate, so for every fixed `tau,R` the existence of some finite universal FEI constant is equivalent to its existence on this hard core.

### Proof

Use the threshold-pruning tree of Theorem 4.1. For a terminal leaf `h`, character-fold to `g`.

If `H_2(w(g))<=R`, (5.6) gives

\[
H(h)=H(g)
\le c_*(R+1)I(g)
\le c_*(R+1)I(h).
\tag{6.4}
\]

If `H_2(w(g))>R`, then `g in H_{tau,R}` and

\[
H(h)=H(g)
\le K_{\rm core}I(g)
\le K_{\rm core}I(h).
\tag{6.5}
\]

Therefore every leaf has FEI coefficient at most

\[
C_L=\max\{c_*(R+1),K_{\rm core}\}.
\]

Insert this into (4.4) and use (4.3). The root coefficient is at most `max{kappa(tau),C_L}`, which is (6.3). QED.

If full FEI were false, then for every fixed `tau>0` there would exist a sequence of Boolean functions `g_m` such that

\[
\max_i\operatorname{Inf}_i(g_m)<\tau,

\[

and

\[
\frac{H(g_m)}{I(g_m)}\to\infty.

More strongly, choosing any sequence `tau_m>0`, `R_m>=0`, and a candidate coefficient exceeding the finite number `C_0(tau_m,R_m)`, Theorem 5.1 produces a corresponding violating hard-core descendant.
