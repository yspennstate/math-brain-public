## 2. New applied theorem: one fixed prime gate gives a finite recursive FEI obstruction

Let

\[
a:=I(G)=\frac{257}{128},\qquad b:=H(G),\qquad
R:=\frac{b}{a-1}.
\]

By (1.2),

\[
R>R_0:=6.4593722816378554.
\tag{2.1}
\]

Define recursively `F_1=G`, and for `d>=1` let

\[
F_{d+1}=G(F_d^{(1)},\ldots,F_d^{(10)}),
\tag{2.2}
\]

where the ten copies use disjoint variable blocks.

### Theorem 2.1

Every `F_d` is balanced and

\[
\boxed{I(F_d)=a^d},
\qquad
\boxed{H(F_d)=b\,{a^d-1\over a-1}},
\tag{2.3}
\]

hence

\[
\boxed{
{H(F_d)\over I(F_d)}
=R\,(1-a^{-d})
=R\left(1-\left({128\over257}\right)^d\right).
}
\tag{2.4}
\]

Moreover the balanced gate/support-deficit ratio is invariant under this recursion:

\[
\boxed{
{H(F_d)\over I(F_d)-1}=R
}
\qquad(d\ge1).
\tag{2.5}
\]

### Proof

Balance is preserved because the ten child outputs are independent unbiased signs and the outer gate `G` is balanced.

For a balanced inner function the empty Fourier coefficient is zero. A spectral sample from the composition is therefore generated by first drawing an outer spectral set `S` according to `\widehat G(S)^2`, and for each active `j in S` independently drawing one inner spectral set from `F_d`. Because every inner draw is nonempty and the blocks are labelled and disjoint, the outer active set `S` is recoverable from the final spectral union. Shannon's chain rule therefore gives, exactly,

\[
H(F_{d+1})=H(G)+I(G)H(F_d)=b+aH(F_d).
\tag{2.6}
\]

The same block factorization gives

\[
I(F_{d+1})=I(G)I(F_d)=aI(F_d).
\tag{2.7}
\]

Starting from `H(F_1)=b`, `I(F_1)=a`, equations (2.3) follow by induction. Equations (2.4) and (2.5) are algebraic consequences. QED.
