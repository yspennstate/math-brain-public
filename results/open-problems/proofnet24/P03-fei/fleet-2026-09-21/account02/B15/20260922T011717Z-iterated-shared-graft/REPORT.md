#### Proof

Because the nine host cells are pairwise disjoint, exactly one gadget is
active at any physical input, so \(T(h)\in\{\pm1\}\). Off the hosts the
function is the fixed monotone core. On a host, the same free-edge conditions
proved in the source report reduce monotonicity to monotonicity of \(h\);
fresh gadget directions inherit monotonicity from \(h\). The host pivot is
uniform on its two endpoints, the other gadget inputs are uniform, and
\(h\) is balanced, so each host contribution has mean zero. The fixed core
also has mean zero. Hence \(T(h)\) is balanced.

Average \(h\) over all fresh gadget inputs. Since \(h\) is balanced, only the
distinguished singleton survives:

\[
\mathbb E_{\rm fresh}h
=b\,\chi_d.
\]

Therefore the Fourier coefficient with no fresh gadget coordinate is

\[
\widehat{T(h)}(S,\varnothing)
=
\widehat a(S)+b\sum_j\widehat Q_j(S).
\tag{3.5}
\]

For a nonempty fresh subset \(U\) in host \(j\),

\[
\widehat{T(h)}(S,U)
=
\widehat P_j(S)\widehat h(U)
+
\widehat Q_j(S)\widehat h(U\cup\{d\}).
\tag{3.6}
\]

The two core supports in (3.6) are disjoint. Each non-core gadget coefficient
is therefore replicated 256 times at scale \(w=1/256\). For squared mass
\(u\),

\[
256\,\phi(w^2u)
=
w\phi(u)+16wu.
\tag{3.7}
\]

Summing (3.7) over the gadget spectrum except the constant
(\(0\), by balance) and the distinguished singleton (\(b^2\)) gives, for one

\[

\tag{3.8}
\]

\(H_0=H_{\rm core}(0)+9\cdot16w\), yields (3.1).

For influence, the source Fourier-degree calculation is insensitive to the

\tag{3.9}

Since
\(I_0-1=133/128=266/256\), (3.9) is exactly (3.2).
\(\square\)
