## 2. Imported source inequality and gauge-invariant block notation

Work on the uniform cube and multiply by a character so every folded influence is represented by

\[
q_i=\operatorname{Inf}_i(f)\le\frac12,
\qquad
\mathcal J(f)=\sum_iq_i.
\]

For a physical block `A`, let `f_z=f|_{x_A=z}` and put

\[
D_A:=\mathcal J(f)-\mathbb E_z\mathcal J(f_z).
\]

The account01/B18 curvature-refunded theorem, consumed through the account04/B14 report above, gives

\[
D_A=I_A+C_A,
\qquad I_A=\sum_{i\in A}q_i,
\qquad C_A=\sum_{j\notin A}c_j(A),
\tag{2.1}
\]

and

\[
\boxed{
\Delta_A\mathcal F
\le B_A-W_A,
\qquad
B_A=H(X_A\mid X_{A^c}),
\qquad
W_A:=\sum_{j\notin A}\mathfrak j'(q_j)c_j(A).
}
\tag{2.2}
\]

For gauge bookkeeping it is useful to write the crossing increment equivalently as

\[
c_j(A)
=
\mathbb E_z\left|p_j(z)-\frac12\right|
-\left|p_j-\frac12\right|,
\tag{2.3}
\]

where `p_j(z)` is the physical influence of coordinate `j` in the child before re-centering. In the centered gauge this equals the source positive-part formula. Expression (2.3) is visibly invariant if a character complements the derivative indicator for coordinate `j`.

Finally, spectral subadditivity gives

\[
B_A\le H(X_A)\le\sum_{i\in A}h_2(q_i).
\tag{2.4}
\]

Define the all-block charge

\[
\boxed{
U_A:=\sum_{i\in A}h_2(q_i)-W_A.
}
\tag{2.5}
\]

Then (2.2)-(2.4) imply the universal physical-block estimate

\[
\boxed{\Delta_A\mathcal F\le U_A.}
\tag{2.6}
\]

## 3. New theorem: an all-block physical stopping compiler

Fix `K>2`. At any centered noncharacter node, query **any nonempty physical block** `A` satisfying

\[
\boxed{U_A<KD_A.}
\tag{3.1}
\]

If no such block exists, stop. Child nodes are character-centered again; this changes no `H`, `J` or `F` and does not change the physical nature of later restrictions.

### Theorem 3.1 — all-block nonreused payment

For every tree generated by the rule (3.1),

\[
\boxed{
\mathcal F(f)-\mathbb E\mathcal F(f_L)
<
K\bigl(\mathcal J(f)-\mathbb E\mathcal J(f_L)\bigr)
\le K\mathcal J(f).
}
\tag{3.2}
\]

Every branch terminates after at most the original dimension many coordinate eliminations, and every terminal leaf satisfies simultaneously

\[
\boxed{
U_A\ge K D_A
\quad\text{for every nonempty physical block }A
\text{ of the leaf}.}
\tag{3.3}
\]

**Proof.** At a queried node, (2.6) and (3.1) give `Delta_A F<KD_A`. Multiply by the node reach probability and sum. Both `F` and `J` telescope along the same physical restriction tree; `D_A` is exactly the `J` lost at that node, so no refund is reused. A nonempty queried block removes at least one physical coordinate, giving finite termination. The stopping condition is precisely (3.3). QED.

### Corollary 3.2 — all-block terminal-class sufficiency

If every centered Boolean function satisfying (3.3) obeys

\[
\mathcal F(f)\le K\mathcal J(f),
\tag{3.4}
\]

then every Boolean function obeys

\[
\boxed{
H(f)\le\left(K+\frac2{\ln2}\right)\mathcal J(f)
\le\left(K+\frac2{\ln2}\right)I(f).
}
\tag{3.5}
\]

Indeed (3.2) plus (3.4) cancels the leaf `KJ` exactly, and the source scalar phase cap `P<=(2/ln2)J` pays the remaining `P`. Thus allowing arbitrary physical blocks does **not** add another copy of `K`.

This is the direct transfer back to the original FEI target.

## 4. Exact minimum-dimensional ratio core, with all quantifiers simultaneous

Assume `F<=KJ` fails. Choose one violating Boolean function on at most `N` essential variables. Among **all** noncharacter Boolean functions on at most `N` variables choose one maximizing

\[
\rho:=\frac{\mathcal F}{\mathcal J}>K,
\tag{4.1}
\]

and among maximizers choose one, `g`, of minimum essential dimension. This is legitimate because there are only finitely many Boolean truth tables in dimensions at most `N`.

Then the following properties hold simultaneously.

### (i) Essentiality and character centering

No coordinate is dummy, or deleting it gives the same ratio in smaller dimension. Multiplication by a character preserves `H`, folded `J`, `P` and therefore `F/J`, so choose the centered gauge `q_i<=1/2` without changing the extremal property.

### (ii) Every proper physical restriction has smaller ratio

For every nonempty proper block `A` and every child `g_z` with `J(g_z)>0`,

\[
\frac{F(g_z)}{J(g_z)}<\rho.
\tag{4.2}
\]

Otherwise a lower-dimensional function would attain the same maximum. Characters/constants have `F=J=0`. Averaging (4.2) gives

\[
\boxed{
\Delta_A F(g)\ge \rho D_A(g)
}
\tag{4.3}
\]

for every nonempty block `A` (including the full block, where both sides equal `F(g)=rho J(g)`).

Combining (4.3) with the universal upper bound (2.6) proves the **all-block critical-core condition**

\[
\boxed{
U_A(g)\ge\rho D_A(g)
\quad\text{for every nonempty physical block }A.}
\tag{4.4}
\]

Thus the one extremal core required by the proof is automatically terminal for the all-block stopping rule at `K=rho`.

### (iii) Tensor primitivity, with zero loss

If `g=g_1 g_2` on two nonempty disjoint coordinate sets, then the spectral law is a product and

\[
H(g)=H(g_1)+H(g_2),\quad
P(g)=P(g_1)+P(g_2),\quad
J(g)=J(g_1)+J(g_2),
\]
so `F` is also additive. Hence `rho(g)` is a `J`-weighted average of the two factor ratios, and at least one lower-dimensional factor has ratio at least `rho`, contradicting the extremal/minimum-dimension choice. Therefore `g` is tensor-primitive.

This is a zero-tax reduction; no tensor amplification or asymptotic passage is used.

## 5. Tensor and gauge tests for the *terminal condition itself*

The previous paragraph only makes the core primitive. The all-block condition also behaves exactly under the two transformations requested in the assignment.

### Tensor heredity

For a disjoint product `f=f_1 f_2` and a block `A=A_1 disjoint-union A_2`, physical restrictions factor. Consequently

\[
D_A=D_{A_1}+D_{A_2},\qquad
C_A=C_{A_1}+C_{A_2},\qquad
W_A=W_{A_1}+W_{A_2},
\]

and therefore

\[
\boxed{U_A=U_{A_1}+U_{A_2}.}
\tag{5.1}
\]

Thus a product is all-block terminal at `K` **iff each factor is all-block terminal at K**. There is no tensor tax hidden in the terminal class.

### Character gauge invariance

Multiplication by a character sends the Fourier random set to `X xor T`, which preserves all entropies `B_A`; it replaces derivative indicators by their complements on toggled coordinates, but (2.3) preserves each `c_j(A)`. Folded `q_j`, `j(q_j)`, `j'(q_j)`, `D_A`, `C_A`, `W_A` and `U_A` are therefore unchanged. Moreover

\[
(\chi_T f)_{A=z}
=\pm\chi_{T\setminus A}f_{A=z},
\]

so all descendant `F,J` values are unchanged. Hence the entire all-block stopping/criticality statement is character-gauge invariant. No arbitrary linear/affine re-basing is claimed or used.

## 6. New co-singleton phase-support tax

The all-block quantifier becomes especially rigid for

\[
A=[n]\setminus\{j\}.
\]

After fixing `A`, every child is a one-bit constant or character. Its folded influence is zero, hence

\[
D_A=J(g).
\tag{6.1}
\]

For the one surviving coordinate, the child influence is exactly `0` or `1`. Its expectation is the parent influence `q_j`, so

\[
\boxed{c_j(A)=q_j,\qquad W_A=q_j\mathfrak j'(q_j).}
\tag{6.2}
\]

For the spectral random set,

\[
B_A=H(X_{-j}\mid X_j)=H(g)-h_2(q_j).
\tag{6.3}
\]

Now use the sharper source inequality (2.2), not the subadditive replacement. Since every co-singleton child has `F=0`,

\[
\Delta_A F=F(g)=\rho J(g).
\]
Therefore

\[
\rho J
\le H-h_2(q_j)-q_j\mathfrak j'(q_j).
\]
Since `H=F+P=rho J+P`, the `rho J` term cancels exactly and gives

\[
\boxed{
\mathcal P(g)
\ge
h_2(q_j)+q_j\mathfrak j'(q_j)
\quad\text{for every physical coordinate }j.}
\tag{6.4}
\]

Equivalently, with

\[
\Phi(q):=h_2(q)+q\mathfrak j'(q)-\mathfrak j(q),
\tag{6.5}
\]

the other coordinates must carry

\[
\boxed{
\sum_{i\ne j}\mathfrak j(q_i)\ge\Phi(q_j).
}
\tag{6.6}
\]

This is an exact **phase-support tax** on every coordinate of the same minimum-dimensional critical core. It is not assumed for arbitrary Boolean functions and is not promoted into a sign-free sufficient condition.

Using the scalar source bound

\[
\mathfrak j(q)\le\frac{2}{\ln2}q,
\qquad \mathfrak j'(q)\ge0,
\]

(6.6) implies the simpler dimension-free spread constraint

\[
\boxed{
J(g)-q_j\ge\frac{\ln2}{2}\Phi(q_j),
}
\tag{6.7}
\]

and in particular

\[
\boxed{
J(g)\ge\frac{\ln2}{2}h_2(q_j).
}
\tag{6.8}
\]

Because singleton terminality at `K=rho` also gives `h_2(q_j)>=rho q_j`,

\[
\boxed{
q_j\le\frac{2}{\rho\ln2}\,J(g)
\quad\text{for every }j.}
\tag{6.9}
\]

Thus an extremal critical core cannot concentrate essentially all of its folded influence in one physical coordinate. The stronger exact constraint is (6.6); (6.9) is only a clean corollary.

For small `q`, `Phi(q)=q log_2(1/q)+O(q)`, so (6.7) forces a logarithmic amount of phase budget into the complementary coordinates. This is precisely the sparse-coordinate regime in which the singleton terminal inequalities alone are weakest.
