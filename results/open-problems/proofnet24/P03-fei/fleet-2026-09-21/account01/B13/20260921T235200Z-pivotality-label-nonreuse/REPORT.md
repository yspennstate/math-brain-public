## 2. New universal theorem: exact simultaneous pivotality labels cost at most twice physical influence

Let

`f:{0,1}^{B disjoint_union S}->{-1,+1}`

be Boolean. For `r in S`, let

`eta_r(z,y_{S\{r}})=1{ f(z,y) != f(z,y xor e_r) }`

be the `r`-pivotality indicator. Assume that for every `r` in a chosen family `R subset S`, this pivotality indicator is **exactly `B`-measurable**:

`eta_r(z,y_{S\{r}})=q_r(z)`

for some `q_r:{0,1}^B->{0,1}`. No sign assumption on `D_r f` is needed. Put

`T(z)=(q_r(z))_{r in R}`.

### Theorem 2.1 — pivotality-label nonreuse

For every `k in B`,

`Inf_k(T) <= 2 Inf_k(f)`.

Consequently

`H(T) <= I(T) <= 2 I_B(f)`.

Here `Inf_k(T)=Pr[T(Z)!=T(Z xor e_k)]`, `I(T)=sum_{k in B}Inf_k(T)`, and entropy is in bits.

### Proof

Fix `k in B` and an assignment `z` of `B\{k}` for which the two label values differ. Choose any `r in R` for which `q_r` differs between the two `k`-branches. Fix arbitrarily all survivor bits except `r`. In the resulting Boolean square with coordinate directions `(k,r)`, exactly one of the two `r`-edges is bichromatic, because `eta_r=q_r(z)` is independent of every survivor bit and its value changes across `k`.

Every Boolean labeling of a four-cycle has an even number of bichromatic edges. Hence exactly one of the two `k`-edges in that square is bichromatic. Averaging over the two values of the `r` bit gives conditional `k`-influence exactly `1/2`, for every assignment of the remaining survivor bits. Therefore every `B\{k}` edge on which `T` changes contributes at least `1/2` to the conditional `k`-influence of `f`, proving

`Inf_k(f) >= Inf_k(T)/2`.

For the entropy inequality, partition the uniform `B`-cube into the fibers `A_t={z:T(z)=t}`. Cube edge-isoperimetry gives

`Inf(1_{A_t}) >= 2 mu(A_t) log_2(1/mu(A_t))`.

Summing over `t`, every edge on which `T` changes is counted twice, so

`2 I(T) >= 2 H(T)`.

This proves the theorem. QED.

### Sharpness: addressing

For the standard address function, `B` consists of `m` address bits and `S` of the `2^m` data bits. Exactly one data bit is pivotal at each address. Thus `T(z)` is the selected address label, so

`H(T)=I(T)=m`,

while every address bit has influence `1/2`, hence `I_B(f)=m/2`. Therefore both inequalities in Theorem 2.1 are equalities. This applies the known addressing obstruction rather than assuming it away.

## 3. Robust theorem: the only extra label charge is a selected proxy-edge parity failure

Now let `q_r(z)` be arbitrary `B`-measurable proxy bits, not necessarily exact pivotality. Define the pointwise support error

`epsilon_r(z,y)=eta_r(z,y) xor q_r(z)`.

For a `k`-edge of the `B` cube on which `T=(q_r)_r` changes, choose deterministically one changed coordinate `r=r(k,z)` (for example the least in a fixed ordering). With `z_0,z_1` the two endpoints, define

`beta(k,z) = Pr_y[ epsilon_r(z_0,y) != epsilon_r(z_1,y) ]`,

where `y` ranges over the surviving coordinates other than the selected `r`. Put

`R_sel = sum_{k in B} E_{z in {0,1}^{B\{k}}} [ 1{T(z_0)!=T(z_1)} beta(k,z) ]`.

### Theorem 3.1 — selected failure bound

For every Boolean `f` and every family of `B`-measurable proxy bits,

`H(T) <= I(T) <= 2 I_B(f) + R_sel`.

### Proof

Fix one label-changing `k`-edge and its selected `r`. Since `q_r` changes, the true pivotality statuses `eta_r` change exactly on those residual assignments for which the two error bits `epsilon_r` are equal. This has probability `1-beta`. On every such residual assignment, the same Boolean-square parity argument as in Theorem 2.1 forces exactly one of the two `k`-edges to be bichromatic. Hence the conditional `k`-influence is at least `(1-beta)/2`, or

`1 <= 2 p_k(z) + beta`.

Average over label-changing physical edges, then sum over `k`. The fiber edge-isoperimetric argument still gives `H(T)<=I(T)`. QED.

The crucial point is nonreuse: `R_sel` selects **one** proxy row per changing physical label edge. It is not the old sum of every row-control incidence. In particular `R_sel=0` whenever the source proxy supports are exact, regardless of how many exact source labels share a physical revealed coordinate.
