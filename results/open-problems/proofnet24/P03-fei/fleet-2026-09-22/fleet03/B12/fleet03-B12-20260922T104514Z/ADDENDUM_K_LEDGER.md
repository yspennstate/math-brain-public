# Addendum — exact K-shifted terminal-surplus conservation

This addendum strengthens `PATHWISE-REFUND-RETENTION-v1` from the same run by writing the ledger in the exact currency used by the all-block terminal/critical-core argument.

## 1. Definitions

At a centered Boolean node `g`, for a physical block `A`, retain the notation of `REPORT.md`:

\[
D_A=I_A+C_A,
\qquad
\Delta_A\mathcal F=B_A-W_A-S_A-R_A,
\]
where

\[
S_A=\sum_{i\in A}\mathfrak j(q_i)-\operatorname{JS}_A\ge0,
\qquad
R_A\ge0.
\]

Define the block subadditivity slack

\[
\boxed{
E_A:=\sum_{i\in A}h_2(q_i)-B_A\ge0.
}
\tag{1.1}
\]

For any fixed real `K`, put

\[
\mathcal G_K:=\mathcal F-K\mathcal J,
\qquad
\sigma_i(K):=h_2(q_i)-Kq_i,
\]

and define the exact terminal-surplus functional

\[
\boxed{
T_A(K)
:=
\sum_{i\in A}\sigma_i(K)
-
\sum_{j\notin A}\bigl(K+\mathfrak j'(q_j)\bigr)c_j(A).
}
\tag{1.2}
\]

Since `W_A=sum j'(q_j)c_j(A)` and `C_A=sum c_j(A)`, this is exactly

\[
T_A(K)
=
\sum_{i\in A}h_2(q_i)-W_A-K(I_A+C_A)
=U_A-KD_A.
\tag{1.3}
\]

Thus `T_A(K)>=0` is precisely the all-block terminal inequality at level `K`; no new surrogate has been introduced.

## 2. Exact one-step identity

### Theorem A.1 — K-shifted refund identity

For every centered Boolean function, every physical block `A`, and every real `K`,

\[
\boxed{
\Delta_A\mathcal G_K
=
T_A(K)-E_A-S_A-R_A.
}
\tag{2.1}
\]

### Proof

Use the exact identity from the main report and the exact folded-influence drift:

\[
\begin{aligned}
\Delta_A\mathcal G_K
&=\Delta_A\mathcal F-KD_A\\
&=B_A-W_A-S_A-R_A-K(I_A+C_A).
\end{aligned}
\]

Insert

\[
B_A=\sum_{i\in A}h_2(q_i)-E_A
\]

and collect terms. The bracket is exactly (1.2). `QED`.

This identity isolates four logically different quantities that were previously mixed together:

1. `T_A(K)`: the terminal surplus available at the node;
2. `E_A`: spectral-coordinate dependence inside the queried block;
3. `S_A`: unused selector/recombination phase slack;
4. `R_A`: reflected-concavity curvature refund from surviving posterior motion.

The latter three are all nonnegative and are not allowed to vanish from the bookkeeping when a child is recentered.

## 3. Exact adaptive-tree conservation

Let `T` be any finite adaptive physical restriction tree with reach probabilities `pi_v`, queried blocks `A_v`, and leaf `L`. Then telescoping (2.1) gives:

### Theorem A.2 — pathwise terminal-surplus conservation

\[
\boxed{
\mathcal G_K(g_\varnothing)-\mathbb E\mathcal G_K(g_L)
=
\sum_{v\in T^\circ}\pi_v
\bigl[T_v(K)-E_v-S_v-R_v\bigr].
}
\tag{3.1}
\]

Equivalently,

\[
\boxed{
\sum_v\pi_v T_v(K)
=
\mathcal G_K(g_\varnothing)-\mathbb E\mathcal G_K(g_L)
+
\sum_v\pi_v(E_v+S_v+R_v).
}
\tag{3.2}
\]

Thus a terminal-surplus dollar used at an ancestor cannot be silently reused after descendant recentering: every generation contributes only its own current `T_v(K)`, and the exact telescoping term records the change in `G_K`.

## 4. Critical-core strengthening of all-block terminality

Let `g` be a minimum-essential-dimension maximizer of

\[
\rho=\mathcal F(g)/\mathcal J(g)
\]

as in the all-block terminal-core theorem. Then

\[
\mathcal G_\rho(g)=0,
\]

and every proper physical restriction child satisfies

\[
\mathcal G_\rho(g_z)\le0,
\]
with strict inequality whenever a noncharacter child of positive folded influence has ratio strictly below `rho`.

Applying Theorem A.1 gives the sharpened block inequality

\[
\boxed{
T_A(\rho)
=
\Delta_A\mathcal G_\rho+E_A+S_A+R_A
\ge
E_A+S_A+R_A.
}
\tag{4.1}
\]

This strictly refines the previously used statement `T_A(rho)>=0`. It says the terminal surplus is not free reusable credit: before anything can remain for another argument it must pay three explicit nonnegative deficits generated by the very same physical restriction.

For an arbitrary adaptive tree descending from the same ratio-critical root, every terminal leaf is a physical restriction descendant and hence `G_rho(leaf)<=0`. Equation (3.2) becomes

\[
\boxed{
\sum_v\pi_v T_v(\rho)
=
-\mathbb E\mathcal G_\rho(g_L)
+
\sum_v\pi_v(E_v+S_v+R_v)
\ge
\sum_v\pi_v(E_v+S_v+R_v).
}
\tag{4.2}
\]

Equation (4.2) is the requested descendant-refund retention statement in the *same terminal-surplus currency* used by Path C.

## 5. Strengthening the robust trigger-block theorem

Suppose row `i` is relative-`eta` robust with trigger set `F_i`. Apply (4.1) to the actual trigger block `A=F_i`. The prior partner theorem used only the nonnegative part of

\[
T_{F_i}(\rho)
=
\sum_{k\in F_i}\sigma_k(\rho)
-
\sum_{j\notin F_i}
(\rho+\mathfrak j'(q_j))c_j(F_i).
\]

The sharpened conclusion is

\[
\boxed{
\sum_{k\in F_i}\sigma_k(\rho)
-
\sum_{j\notin F_i}
(\rho+\mathfrak j'(q_j))c_j(F_i)
\ge
E_{F_i}+S_{F_i}+R_{F_i}.
}
\tag{5.1}
\]

Keeping only the `j=i` crossing and dropping the right side recovers the earlier trigger-surplus theorem. Hence (5.1) is a genuine strengthening: after paying **all** physical posterior crossings caused by the trigger block, the remaining trigger surplus must still pay block dependence, unused selector slack, and reflected curvature.

This is useful for the next nonrobust-row attack. A candidate proof may no longer count the same trigger-coordinate terminal surplus once in a robust-row demand and again as a descendant phase/curvature refund; (5.1) and (4.2) put those uses in one exact ledger.
