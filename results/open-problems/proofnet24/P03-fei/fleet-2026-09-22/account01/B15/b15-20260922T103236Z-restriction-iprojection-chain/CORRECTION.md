# Typographical correction

In `REPORT.md`, Section 2, the first child Fourier coefficient is displayed as `\nu_T=\widehat{G_0}(T)`. The intended symbol is

\[
u_T=\widehat{G_0}(T),\qquad v_T=\widehat{G_1}(T).
\]

In the displayed correction above, the first character is the Latin letter `u` with no LaTeX command prefix: equivalently, in plain text, `u_T = Fourier coefficient of G_0 at T`. The report's later equations already use the Latin `u_T` and `v_T`; no formula, theorem, constant, checker result, or classification changes.
