## New result A: robust complementarity gap below alpha=1

`eps = ||ReLU(Wx) - q x||`,

`L = ||W||_op`,

`Lambda_+(W) = sup{x^T ((W+W^T)/2) x : x>=0, ||x||=1}`.

Then

`q - Lambda_+(W) <= eps (1 + L/q)`.

Therefore, if `Lambda_+(W)<1`,

`inf_{x>=0, ||x||=1, q>=1} ||ReLU(Wx)-q x||`

`(1-Lambda_+(W))/(1+||W||_op)`.

# 4. Deterministic robust complementarity inequality

## `P16-COMPLEMENTARITY-RESIDUAL-42` — PROVED

Let W be any real N by N matrix and define

`F(x)=ReLU(Wx)`.

Fix

`x>=0`, `||x||=1`, `q>0`,

and set

`r=F(x)-q x`, `eps=||r||`, `y=Wx`, `L=||W||_op`.

Let

`B={i : y_i<0}`.

On B, `F_i(x)=0`, so

`r_i=-q x_i`.

Therefore

`||x_B|| <= eps/q`.                                               (4.1)

Also

`x^T F(x) = q + x^T r >= q-eps`.                                 (4.2)

The only difference between `x^T W x` and `x^T F(x)` is the negative-preactivation leakage:

`x^T W x = x^T F(x) - D`,

where

`D = sum_(i in B) x_i (-y_i) >= 0`.

By Cauchy-Schwarz and (4.1),

`D <= ||x_B|| ||y_B|| <= (eps/q) ||Wx|| <= L eps/q`.             (4.3)

Since the skew part of W vanishes in a quadratic form,

`x^T W x = x^T [(W+W^T)/2] x <= Lambda_+(W)`.

Combining (4.2)-(4.3),

`Lambda_+(W) >= q - eps - L eps/q`.

Equivalently,

`q - Lambda_+(W) <= eps (1+L/q)`.                                 (4.4)

Whenever `q>Lambda_+(W)`, this gives the explicit residual lower bound

`eps >= q(q-Lambda_+) / (q+L)`.                                  (4.5)

If `Lambda_+<1`, the right side of (4.5) is increasing for `q>=1`: its derivative has numerator

`q^2 + 2Lq - L Lambda_+ > 0`.

Therefore

`inf_(x>=0, ||x||=1, q>=1) ||F(x)-q x||`

`    >= (1-Lambda_+(W))/(1+||W||_op)`.                            (4.6)

This statement is deterministic after W is fixed and is therefore uniform over W-dependent input choices.

### Dead-state check

If `F(x)=0`, then for q>=1 the residual is exactly q and cannot violate (4.6). Dead neurons/orbits therefore create no exception.

# 5. Gaussian uniform robust pseudoray gap below alpha=1

## `P16-UNIFORM-PSEUDORAY-GAP-BELOW1-42` — PROVED

Fix `alpha<1`.

From the primary theorem,

`Lambda_+(W) -> sqrt(alpha)` almost surely.

As a function of the iid standard Gaussian matrix G in

`W=sqrt(alpha/N) G`,

`Lambda_+` is `sqrt(alpha/N)`-Lipschitz in Frobenius norm, because

`|sup_x x^T W x - sup_x x^T W' x|`

is at most

`sqrt(alpha/N) ||G-G'||_op`

and hence at most

`sqrt(alpha/N) ||G-G'||_F`.

Almost-sure convergence implies convergence of medians to `sqrt(alpha)`. Gaussian concentration therefore upgrades every fixed gap to an exponential tail.

For all sufficiently large N, the median lies below

`sqrt(alpha) + (1-sqrt(alpha))/4`.

Hence

`P{Lambda_+ > (1+sqrt(alpha))/2}`

is at most

`2 exp[- N (1-sqrt(alpha))^2/(32 alpha)]`.                        (5.1)

Independently, scaling the source's finite-N norm lemma gives

`P{||W||_op > 8 sqrt(alpha)}`

` <= 2 exp[-(8-log81)N]`.                                        (5.2)

On the intersection of the complementary events,

`1-Lambda_+ >= (1-sqrt(alpha))/2`

and

`1+||W||_op <= 1+8 sqrt(alpha)`.

Thus (4.6) gives

`inf_(x>=0, ||x||=1, q>=1) ||ReLU(Wx)-q x||`

` >= (1-sqrt(alpha)) / [2(1+8 sqrt(alpha))]`.                     (5.3)

This is a high-probability, uniform-in-input theorem for the original tied matrix. It is not merely annealed expectation and does not require the input to be independent of W.

# 6. Gaussian symmetric/skew decomposition

Write

`S=(W+W^T)/2`,

`A=(W-W^T)/2`.

For iid Gaussian W these two matrices are independent Gaussian objects.

For `i<j`,

`S_ij=(W_ij+W_ji)/2`,

`A_ij=(W_ij-W_ji)/2`,

so both have variance `alpha/(2N)`, and Gaussian orthogonality makes them independent. Also `A_ji=-A_ij`, `A_ii=0`. The diagonal of S has variance `alpha/N`, giving exactly

`S =_d sqrt(alpha/2) Z_N`

for standard GOE Z_N.

This independent skew noise is invisible to every symmetric Rayleigh quotient, because `x^T A x=0`, but it is visible to the recurrent update `Wx` coordinate by coordinate. That distinction is the core of the alpha>1 result below.

# 7. The skew defect of an S-measurable copositive optimizer

Choose any Borel/measurable maximizer determined from S alone,

`x=x_+(S) in argmax{x^T Sx : x>=0, ||x||=1}`,

and set

`q=x^T Sx=Lambda_+(S)`,

`I=supp(x)`, `k=|I|`.

On the event q>=0, the following holds.

## 7.1 KKT identity on the active support

For every i in I, x_i>0, so the positivity constraint is locally inactive. Stationarity on the sphere gives

`(Sx)_i = q x_i`, `i in I`.                                      (7.1)

The off-support inequality `(Sx)_i<=0` also holds but is not needed for the lower bound.

## 7.2 Conditional law of Ax

Let

`sigma^2 = alpha/(2N)`.

Conditional on S and x, A remains independent. Direct covariance calculation gives

`Cov(Ax) = sigma^2 (I_N - x x^T)`.                               (7.2)

In particular,

`Var((Ax)_i) = sigma^2 (1-x_i^2)`.                               (7.3)

## 7.3 Scalar ReLU-noise lemma

Let `Z~N(0,1)` and `t>=0`. Define

`h(t)=E[((t+Z)_+ - t)^2]`.

Splitting at `Z=-t` gives

`h(t)=Phi(t)-t phi(t)+t^2 Phi(-t)`.

Differentiation yields

`h'(t)=2t Phi(-t)>=0`,

so

`h(t)>=h(0)=1/2`.                                                 (7.4)

Therefore, for every c>=0 and Gaussian `Y~N(0,tau^2)`,

`E[((c+Y)_+ - c)^2] >= tau^2/2`.                                 (7.5)

## 7.4 Conditional mean-square residual

For i in I, by (7.1),

`(Wx)_i = q x_i + (Ax)_i`.

Apply (7.5) with `c=q x_i` and `tau_i^2=sigma^2(1-x_i^2)`. Summing active coordinates and discarding the nonnegative off-support contribution gives

`E_A ||ReLU(Wx)-q x||^2`

` >= (1/2) sum_(i in I) sigma^2(1-x_i^2)`

` = (sigma^2/2) (k-1)`

` = alpha (k-1)/(4N)`.                                           (7.6)

This proves

### `P16-SKEW-DEFECT-MEAN-42` — PROVED

The result is exact at finite N. No asymptotic approximation is used in (7.6).

### Edge check

If k=1, a skew matrix annihilates the only occupied coordinate in its self-coordinate direction and the lower bound becomes zero. Thus the `k-1` term is structurally necessary, not an artifact.

# 8. A finite-N sparse-support bound for the symmetric positive-cone optimizer

To turn (7.6) into an order-one statement we must show that a global positive-cone maximizer cannot be microscopically supported.

The argument below is deliberately elementary and finite-N.

For any fixed unit vector u,

`u^T S u = u^T W u`

is exactly centered Gaussian with variance `alpha/N`.

Fix

`delta0=0.04`,

`eta_net=0.05`,

`r0=0.9 sqrt(alpha)`.

For any coordinate support J of size s, let M_J be an eta_net-net of its unit sphere. We may take

`|M_J| <= (1+2/eta_net)^s = 41^s`.

For a symmetric matrix, if its restriction to J has operator norm at least r0, the standard quadratic-form net inequality gives some u in M_J with

`|u^T S u| >= (1-2 eta_net) r0`

`                 = 0.81 sqrt(alpha)`.

Thus for a fixed support J,

`P{ sup_(supp u subset J, ||u||=1) u^T S u >= r0 }`

` <= 2 * 41^s * exp[-0.32805 N]`.                                (8.1)

For `s<=delta0 N`, summing supports and using

`sum_(s<=delta0 N) C(N,s) <= (N+1) exp[N H(delta0)]`

gives

`P{ exists ||u||=1, |supp u|<=0.04N, u^T S u >=0.9 sqrt(alpha) }`

` <= 2(N+1) exp[-c_sparse N]`,                                   (8.2)

where

`c_sparse = 0.32805 - H(0.04) - 0.04 log 41`

`         = 0.011562969597654765... >0`.                          (8.3)

No positivity restriction was used in (8.2), so it is stronger than needed.

On the other hand `Lambda_+ -> sqrt(alpha)`. The same Gaussian concentration argument as before shows that, for sufficiently large N,

`P{Lambda_+ <0.9 sqrt(alpha)} <= 2 exp(-N/800)`.                  (8.4)

Indeed the median is eventually at least `0.95 sqrt(alpha)`, and `Lambda_+` is `sqrt(alpha/N)`-Lipschitz.

Combining (8.2)-(8.4):

### `P16-SPARSE-COPOSITIVE-SUPPORT-42` — PROVED

With exponentially high probability, every global maximizer of the nonnegative symmetric quadratic problem has

`|supp(x)| > 0.04 N`.                                             (8.5)

The constant 0.04 is deliberately nonoptimized.

# 9. High-probability order-one skew defect

Let

`R(A)=||ReLU((S+A)x)-q x||`

for S and its selected maximizer x fixed.

Parameterize the independent upper-triangular entries of A by standard Gaussians z. Since

`A_ij = sqrt(alpha/(2N)) z_ij`, `i<j`,

we have

`||Delta A||_F = sqrt(alpha/N) ||Delta z||_2`.

ReLU is 1-Lipschitz, so R is `sqrt(alpha/N)`-Lipschitz as a function of z. Gaussian Poincare therefore gives

`Var_A(R|S) <= alpha/N`.                                          (9.1)

From (7.6), if `k>=delta N`,

`E_A R^2 >= alpha(k-1)/(4N)`.

For `delta N>=10`,

`(E_A R)^2 = E_A R^2 - Var_A(R)`

`            >= alpha delta/8`.                                  (9.2)

Gaussian lower-tail concentration now gives

`P_A{R <= sqrt(alpha delta/32) | S}`

` <= exp(-N delta/64)`.                                           (9.3)

Set `delta=0.04`. On the support event (8.5),

`sqrt(alpha delta/32) = sqrt(alpha/800)`

and the conditional failure probability is at most

`exp(-N/1600)`.                                                    (9.4)

For fixed `alpha>1`, one more concentration event gives `q>1` exponentially surely. Since the median of Lambda_+ tends to sqrt(alpha), for sufficiently large N,

`P{Lambda_+ <= (1+sqrt(alpha))/2}`

` <= 2 exp[-N (sqrt(alpha)-1)^2/(32 alpha)]`.                     (9.5)

Combining (8.2), (8.4), (9.4), (9.5) proves:

### `P16-COPOSITIVE-OPTIMIZER-SKEW-DEFECT-42` — PROVED

For each fixed `alpha>1`, for any S-measurable choice of global positive-cone symmetric maximizer x_+(S), all sufficiently large N satisfy

`P{ Lambda_+(S)>1, |supp x_+|>0.04N,`

`    ||ReLU(Wx_+) - Lambda_+(S)x_+|| >= sqrt(alpha/800) }`

` >= 1 - [2e^{-N/800}`

`          +2(N+1)e^{-0.0115629695 N}`

`          +e^{-N/1600}`

`          +2e^{-N(sqrt(alpha)-1)^2/(32alpha)}]`.                  (9.6)

Polynomial factors can of course be absorbed into a fixed-alpha exponential rate for sufficiently large N.

### Scope

This theorem is NOT uniform over arbitrary A-dependent selections from the sphere. It is intentionally about the natural optimizer determined from the symmetric part alone. That restriction is essential to the independence used in the skew calculation.

The theorem therefore does not close `1<alpha<2`; it identifies what any successful bad direction must do that the symmetric numerical-range optimizer does not: it must use information from the skew component A to satisfy ReLU complementarity.
