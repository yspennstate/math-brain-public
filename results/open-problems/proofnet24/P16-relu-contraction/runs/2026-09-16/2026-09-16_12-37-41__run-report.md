# 4. Stronger balancing identity: the actual transition has exact geometric-mean alignment

Consider any live normalized realized segment of the tied dynamics

\[
F_W(u_t)=g_tu_{t+1},
\qquad
u_t:=u_t\in\mathbb R_+^N,
\qquad
\|u_t\|=1,
\qquad g_t>0,
\]

for `t=0,...,k-1`. No return assumption is made.

Define

\[
\kappa=\left(\prod_{t=0}^{k-1}g_t\right)^{1/k},
\qquad
a_0=1,
\qquad
a_{t+1}=\frac{a_tg_t}{\kappa}.
\]

Then

\[
a_k=a_0=1.
\]

Put

\[
A=\sum_{t=0}^{k-1}a_t,
\qquad
\lambda_t=\frac{a_t}{A}.
\]

The `lambda_t` are probability weights. Since

\[
\lambda_tg_t
=\frac{a_tg_t}{A}
=\frac{\kappa a_{t+1}}{A},
\]

we obtain, **using the actual target `u_{t+1}` at every step including the last**, the exact identity

\[
\begin{aligned}
\sum_{t=0}^{k-1}
\lambda_tu_{t+1}^TF_W(u_t)
&=\sum_t\lambda_tg_t\\
&=\frac\kappa A\sum_{t=0}^{k-1}a_{t+1}\\
&=\frac\kappa A\sum_{t=1}^{k}a_t\\
&=\kappa,
\end{aligned}
\tag{4.1}
\]

because `a_k=a_0`.

Thus if `T` is sampled from `lambda` with independent auxiliary randomness and

\[
U=u_T,
\qquad V=u_{T+1},
\]

then

\[
\boxed{
E_T[V^TF_W(U)\mid W,\text{segment}]=\kappa.
}
\tag{4.2}
\]

## `P16-BALANCED-ACTUAL-TRANSITION-48 — PROVED`

Equation `(4.2)` is the claim.

### Relation to the previous run

The preceding theorem defined the last cyclic target as `u_0` rather than the actual `u_k`, obtaining

\[
\kappa\big[1-\lambda_0(1-\langle u_0,u_k\rangle)\big].
\]

That theorem remains correct. The new identity shows exactly what the return condition was buying: **recurrence-specific closing consistency**, not high cross-alignment itself.

This distinction matters. A high-geometric-mean forward block, recurrent or not, already yields a high-alignment actual transition after gain balancing. Therefore an information lower bound based only on an actual source/target pair may be charging information that is generic to a one-step ReLU output rather than information specific to long-time recurrent instability.

# 5. Deterministic finite-block characterization of the global target

Let

\[
K_N=\{x\in\mathbb R_+^N:\|x\|=1\}
\]

and define

\[
L_n^+(W)
:=\max_{x\in K_N}\|F_W^n(x)\|,
\qquad n\ge1.
\tag{5.1}
\]

The maximum exists because `K_N` is compact and finite ReLU iterates are continuous.

## 5.1 Submultiplicativity

For `m,n>=1`, `F_W^n(x)` is nonnegative. By positive homogeneity,

\[
\|F_W^m(y)\|
\le L_m^+(W)\|y\|
\qquad (y\ge0).
\]

Therefore

\[
\boxed{
L_{m+n}^+(W)
\le L_m^+(W)L_n^+(W).
}
\tag{5.2}
\]

## 5.2 One contracting block is equivalent to uniform exponential contraction

If for some integer `n_0`

\[
L_{n_0}^+(W)<1,
\]

set

\[
\rho=(L_{n_0}^+)^{1/n_0}<1.
\]

Writing `t=qn_0+r`, `0<=r<n_0`, submultiplicativity gives

\[
L_t^+
\le (L_{n_0}^+)^q\max_{0\le r<n_0}L_r^+
\le C_+(W)\rho^t
\]

for a finite deterministic `C_+(W)`. Hence every nonnegative input contracts exponentially.

Conversely, if there are `C<infinity`, `rho<1` with

\[
L_t^+\le C\rho^t
\]

for all `t`, then `L_n^+<1` for all sufficiently large `n`.

Finally, for arbitrary signed input `x`, `F_W(x)>=0` and

\[
\|F_W(x)\|\le\|W\|\|x\|.
\]

Thus positive-cone uniform contraction and the full all-input target differ only by this first-step prefactor.

Hence the full bad event for a fixed matrix is exactly

\[
\boxed{
\mathcal B_N
=
\bigcap_{n\ge1}\{L_n^+(W)\ge1\}.
}
\tag{5.3}
\]

## `P16-POSITIVECONE-BLOCK-EQUIVALENCE-48 — PROVED`

Equations `(5.2)--(5.3)` and the first-step reduction are the claim.

This formulation is useful because it replaces an infinite-time trajectory statement by a countable family of finite continuous optimization problems.

# 6. Explicit Borel witness selection; no abstract selector theorem needed

The previous run left measurable selection as an explicit technical obligation. We now close it.

## 6.1 Continuity of `L_n^+`

For fixed finite `n`, the map

\[
(W,x)\mapsto F_W^n(x)
\]

is jointly continuous. Maximization of its norm over the compact fixed set `K_N` therefore makes

\[
W\mapsto L_n^+(W)
\]

continuous. In particular, the bad event `(5.3)` is Borel.

## 6.2 A finite-net Borel high-product block

Fix a deterministic cutoff `L_0>1`, a block length `n`, and `tau>0`. On

\[
\mathcal B_N\cap\{\|W\|\le L_0\},
\]

we have `L_n^+(W)>=1`.

Choose once and for all a deterministic finite `epsilon`-net

\[
Q=\{q_1,\ldots,q_M\}\subset K_N
\]

with

\[
\epsilon\le (1-e^{-\tau})L_0^{-n}.
\tag{6.1}
\]

Since `F_W^n` is `L_0^n`-Lipschitz in its input on the norm event, a maximizer `x_*` with `||F_W^n(x_*)||>=1` has a net point `q_j` satisfying

\[
\|F_W^n(q_j)\|
\ge1-L_0^n\epsilon
\ge e^{-\tau}.
\tag{6.2}
\]

Define `q(W)` to be the **first** point in the fixed enumeration attaining the largest value of `||F_W^n(q_j)||`. Since this is a finite collection of continuous functions with deterministic tie-breaking, `q(W)` is Borel.

The trajectory from `q(W)` is live on `(6.2)`. Normalize it:

\[
F_W(u_t)=g_tu_{t+1},
\qquad
\prod_{t=0}^{n-1}g_t
=\|F_W^n(q(W))\|
\ge e^{-\tau}.
\tag{6.3}
\]

## `P16-MEASURABLE-BLOCK-WITNESS-48 — PROVED`

For every fixed `n,tau,L_0`, the construction above is an explicit Borel finite high-product witness on the global bad event intersected with the norm cutoff.

No Kuratowski--Ryll-Nardzewski or other imported measurable-selection theorem is needed.

## 6.3 Borel near-cycle by finite cell loop erasure

Fix `delta,eta>0`. Partition `K_N` into finitely many Borel cells of diameter at most `delta`, using a deterministic finite net and nearest-center tie-breaking. Let the number of cells be `M_cell`.

Choose a deterministic block length satisfying

\[
n>
M_{\rm cell}
+
\frac{M_{\rm cell}\log L_0+\tau}{\eta}.
\tag{6.4}
\]

Apply the Borel block construction above. The cell itinerary of `u_0,...,u_n` is a finite word. Chronological loop erasure decomposes its `n` edges into repeated-cell loops plus a residual simple path. The residual visits distinct cells, so it has at most `M_cell` edges.

Suppose every removed repeated-cell loop `[s,t]` had

\[
\frac1{t-s}\sum_{j=s}^{t-1}\log g_j< -\eta.
\]

The total log gain over all loop edges would then be less than `-eta` times the number of such edges. Each residual edge has `log g_j<=log L_0`. Hence, writing `r<=M_cell` for the residual length,

\[
\sum_{j=0}^{n-1}\log g_j
<
-\eta(n-r)+r\log L_0
\le
-\eta(n-M_{\rm cell})+M_{\rm cell}\log L_0
< -\tau,
\]

contradicting `(6.3)`.

Therefore at least one repeated-cell pair `s<t` satisfies

\[
\boxed{
\|u_t-u_s\|\le\delta,
\qquad
\left(\prod_{j=s}^{t-1}g_j\right)^{1/(t-s)}
\ge e^{-\eta}.
}
\tag{6.5}
\]

Choose the lexicographically first such `(s,t)`. There are only finitely many pairs, the states and gains are Borel functions of `W` on the live block, and cell membership uses deterministic tie-breaking. Thus the selected near-cycle is Borel.

## `P16-MEASURABLE-NEARCYCLE-48 — PROVED`

For every fixed `delta,eta,tau,L_0`, a canonical Borel near-neutral near-returning segment exists on

\[
\mathcal B_N\cap\{\|W\|\le L_0\}.
\]

### Quantitative limitation

This is a measurability/existence theorem, not a useful entropy bound. A `delta`-cover of the `(N-1)`-dimensional positive sphere can have exponentially many cells, and `(6.4)` may therefore force an exponentially large block length; the input net resolution `(6.1)` can then be extremely fine. The construction must **not** be mistaken for a low-rate code.

# 7. Generic Gaussian ReLU target directions already cost information

The preceding two-state KL theorem needs a representation of a matrix-adaptive source/target pair. Before trying to upper-bound its information, it is necessary to understand how much information is already present in a completely generic one-step target.

Fix a deterministic unit vector `u` independent of `W`. For `alpha>0`, write

\[
Wu=\sqrt{\alpha/N}\,Z,
\qquad
Z=(Z_1,\ldots,Z_N),
\qquad
Z_i\stackrel{\rm iid}{\sim}N(0,1).
\]

Let

\[
Y=Z_+,
\qquad
R=\|Y\|,
\qquad
V=Y/R
\]

when `R>0`; set `V=0` on the all-negative event. The scalar factor `sqrt(alpha/N)` cancels, so the target **direction law is independent of `alpha`**.

Let

\[
B_i=1_{\{Z_i>0\}}.
\]

Then `B_1,...,B_N` are iid fair bits and are deterministic functions of `W` once `u` is fixed.

## 7.1 A norm tail used below

For `t=1/4`,

\[
E\exp(tZ_+^2)
=\frac12+rac1{2\sqrt{1-2t}}
=\frac{1+\sqrt2}{2}.
\]

Therefore

\[
\boxed{
P\{R>\sqrt N\}
\le e^{-c_RN},
\qquad
c_R=rac14-\log\frac{1+\sqrt2}{2}
=0.06177359354040235\ldots.
}
\tag{7.1}
\]

## 7.2 Fano rate-distortion lower bound

Let `Vhat` be **any** possibly randomized representation coupled with `W`, and assume

\[
E\|V-Vhat\|_2\le\delta.
\tag{7.2}
\]

Fix `a>0`. Decode a support bit from the representation by

\[
\widehat B_i
=
1_{\{Vhat_i\ge a/(2\sqrt N)\}}.
\tag{7.3}
\]

On the event `R<=sqrt(N)`:

- if `B_i=1` and `Z_i>=a`, then `V_i>=a/sqrt(N)`, so a false negative in `(7.3)` forces coordinate error at least `a/(2sqrt(N))`;
- if `B_i=0`, then `V_i=0`, so a false positive forces the same coordinate error.

The only positive coordinates not controlled by this implication satisfy `0<Z_i<a`. Consequently the average bit-error probability obeys

\[
\overline p
\le
\Phi(a)-\frac12
+
\frac{2\delta}{a}
+
e^{-c_RN}.
\tag{7.4}
\]

Indeed, the number of controlled decoding errors is at most

\[
\frac{2\sqrt N}{a}\|V-Vhat\|_1
\le
\frac{2N}{a}\|V-Vhat\|_2.
\]

Since `B` is uniform on `{0,1}^N`, binary Fano coordinatewise plus concavity of binary entropy `h` gives, whenever the right side of `(7.4)` is below `1/2`,

\[
\begin{aligned}
I(W;Vhat)
&\ge I(B;Vhat)\\
&=N\log2-H(B\mid Vhat)\\
&\ge
N\big[\log2-h(\overline p)\big].
\end{aligned}
\tag{7.5}
\]

Thus, with

\[
p_N(a,\delta)
=
\Phi(a)-\frac12+rac{2\delta}{a}+e^{-c_RN},
\]

we have the explicit theorem

\[
\boxed{
I(W;Vhat)
\ge
N\left[\log2-h\big(p_N(a,\delta)\big)\right]
}
\tag{7.6}
\]

whenever `p_N(a,delta)<1/2`.

## `P16-GENERIC-RELU-TARGET-FANO-RD-48 — PROVED`

Equation `(7.6)` is the claim. It is an **unconditional fixed-source theorem**. It is not silently transferred to the conditional distribution of a target selected on a rare bad event.

## 7.3 Fixed-ball / finite-codebook bound

There is also a pointwise covering estimate. Fix a deterministic vector `vhat` and define

\[
S=\left\{i:vhat_i\ge\frac{a}{2\sqrt N}\right\}.
\]

On `R<=sqrt(N)` and `||V-vhat||_2<=delta`, every index of either type

\[
i\in S,\ Z_i\le0,
\qquad\text{or}\qquad
i\notin S,\ Z_i\ge a
\]

costs at least `a/(2sqrt(N))` of coordinatewise absolute error. Hence the number `C` of such indices satisfies

\[
C\le \frac{2N\delta}{a}.
\tag{7.7}
\]

For `i in S`, the corresponding indicator has probability `1/2`. For `i notin S`, it has probability

\[
q_a=1-\Phi(a)<1/2.
\]

The indicators are independent and each has success probability at least `q_a`. Thus their sum stochastically dominates `Bin(N,q_a)`. If

\[
r=\frac{2\delta}{a}<q_a,
\]

Chernoff's lower-tail bound and `(7.1)` give

\[
\boxed{
P\{\|V-vhat\|_2\le\delta\}
\le
\exp[-N D_{\rm Ber}(r\|q_a)]
+
\exp[-c_RN].
}
\tag{7.8}
\]

Define

\[
c_{\rm ball}(a,\delta)
=
\min\{D_{\rm Ber}(2\delta/a\|1-\Phi(a)),c_R\}.
\]

Then the right side of `(7.8)` is at most `2e^{-Nc_ball}`.

For any deterministic codebook `C_N`, a union bound gives

\[
P\{\operatorname{dist}(V,C_N)\le\delta\}
\le
2|C_N|e^{-Nc_{\rm ball}}.
\tag{7.9}
\]

Hence if the codebook covers at least half the fresh target law,

\[
\boxed{
\frac1N\log|C_N|
\ge
c_{\rm ball}(a,\delta)-\frac{\log4}{N}.
}
\tag{7.10}

# 10. Adversarial checks of the new P16 arguments

## 10.1 Same matrix across time

Sections 4--6 are deterministic statements about the actual tied matrix. No fresh layer is introduced. Sections 7--8 deliberately study a separate **fixed-source one-step law** only to quantify how much information an ordinary target direction already contains; that restriction is explicit.

## 10.2 Exceptional directions

The measurable block and near-cycle selectors are allowed to depend on the full observed matrix. No ordinary-start source theorem is applied to them.

## 10.3 Why actual-transition balancing does not solve recurrence

Equation `(4.2)` is stronger algebraically than the preceding cyclic-target inequality but weaker conceptually as a recurrence certificate: it no longer contains a return constraint. This is exactly why a generic next-state coding cost can consume the information budget.

## 10.4 Dead neurons

The target rate-distortion lower bound uses the random support signs themselves. In the adaptive alignment theorem, sparse represented targets improve the fixed-pair exponent. Therefore dead neurons are not ignored; they create both coding information and potentially stronger alignment cost. The missing theorem must couple those two effects under bad-event conditioning.

## 10.5 Correlations across layers / times

No independent random-matrix product theorem is used. The near-cycle construction is deterministic. The generic target theorem concerns one fixed source by design and is not substituted for a tied adaptive path.

## 10.6 Finite-width errors

The balancing identity, positive-cone block equivalence, Borel selector, Fano bound and fixed-ball bound are all finite-`N`. The numerical rate comparison in Section 8 uses the `N->infinity` limit only to drop the exponentially small `e^{-c_RN}` term in the Fano bit-error parameter.

## 10.7 Zero output

For the generic target law, `R=0` exactly when all Gaussian coordinates are nonpositive, an event of probability `2^{-N}`. Defining `V=0` there causes no problem in the displayed inequalities. The bit-decoding proof remains valid.

## 10.8 Conditional versus unconditional rate distortion

This is the most important scope check. Equations `(7.6)` and `(7.10)` are unconditional fixed-source theorems. They do **not** imply the same target entropy after conditioning on the global bad event. Section 8 therefore rejects only a generic-source coding substitution, not the bad-event-specific compression strategy itself.

## Lyapunov / submultiplicative dynamics

The positive-cone norms `L_n^+` give an exact deterministic finite-block characterization: one contracting block is equivalent to global uniform exponential contraction. The bad event is the countable intersection `L_n^+>=1`.

The fresh fixed-input second moment `(alpha/2)` remains an ordinary-start fact. It is not used on adaptive states.

The key lesson is now two-sided. KL decoupling can price an adaptive pair from below, but a representation may already need linear information just to describe a generic next state.
