# 4. Stronger balancing identity: actual-transition alignment is exactly the geometric mean

Consider any live normalized realized segment of the tied dynamics

`F_W(u_t)=g_t u_(t+1),  u_t>=0,  ||u_t||=1,  g_t>0`,

for `t=0,...,k-1`. No return assumption is made.

Define

`kappa = (product_(t=0)^(k-1) g_t)^(1/k)`,

`a_0=1`, and `a_(t+1)=a_t g_t/kappa`.

Then `a_k=a_0=1`. Put

`A=sum_(t=0)^(k-1) a_t`, and `lambda_t=a_t/A`.

The `lambda_t` are probability weights. Since

`lambda_t g_t = kappa a_(t+1)/A`,

we obtain, **using the actual target `u_(t+1)` at every step including the last**,

`sum_t lambda_t u_(t+1)^T F_W(u_t)`

`= sum_t lambda_t g_t`

`= (kappa/A) sum_(t=0)^(k-1) a_(t+1)`

`= (kappa/A) sum_(t=1)^k a_t`

`= kappa`,

because `a_k=a_0`.

Thus if `T` is sampled from `lambda` with independent auxiliary randomness and

`U=u_T,  V=u_(T+1)`, then

`E_T[V^T F_W(U) | W, segment] = kappa`.  `(4.1)`

## `P16-BALANCED-ACTUAL-TRANSITION-48 — PROVED`

Equation `(4.1)` is the claim.

### Relation to the previous cyclic-target theorem

The preceding run replaced the last actual target `u_k` by `u_0`, obtaining

`kappa [1-lambda_0(1-<u_0,u_k>)]`.

That theorem remains correct. The new identity shows exactly what the return condition was buying: **recurrence-specific closing consistency**, not high cross-alignment itself.

This is conceptually important. A high-geometric-mean forward block, recurrent or not, already yields a high-alignment actual transition after gain balancing. Therefore an information lower bound based only on an actual source/target pair may charge information generic to a one-step ReLU output rather than information specific to long-time recurrent instability.

# 5. Deterministic finite-block characterization of the global target

Let

`K_N={x in R_+^N : ||x||=1}`

and define

`L_n^+(W) := max_(x in K_N) ||F_W^n(x)||`,  `n>=1`.  `(5.1)`

The maximum exists because `K_N` is compact and finite ReLU iterates are continuous.

## 5.1 Submultiplicativity

For `m,n>=1`, `F_W^n(x)` is nonnegative. Positive homogeneity gives

`||F_W^m(y)|| <= L_m^+(W) ||y||` for every `y>=0`.

Therefore

`L_(m+n)^+(W) <= L_m^+(W) L_n^+(W)`.  `(5.2)`

## 5.2 One contracting block iff uniform exponential contraction

If for some integer `n_0`, `L_(n_0)^+(W)<1`, set

`rho=(L_(n_0)^+)^(1/n_0)<1`.

Writing `t=q n_0+r`, `0<=r<n_0`, submultiplicativity gives

`L_t^+ <= (L_(n_0)^+)^q max_(0<=r<n_0) L_r^+ <= C_+(W) rho^t`

for a finite `C_+(W)`. Hence every nonnegative input contracts exponentially.

Conversely, if `L_t^+<=C rho^t` for all `t` with `rho<1`, then `L_n^+<1` for all sufficiently large `n`.

For arbitrary signed input `x`, `F_W(x)>=0` and

`||F_W(x)||<=||W|| ||x||`.

Thus positive-cone uniform contraction and the full all-input target differ only by the first-step prefactor.

Hence the full bad event for a fixed matrix is exactly

`B_N = intersection_(n>=1) { L_n^+(W) >= 1 }`.  `(5.3)`

## `P16-POSITIVECONE-BLOCK-EQUIVALENCE-48 — PROVED`

Equations `(5.2)--(5.3)` and the first-step reduction are the claim.

This replaces the infinite-time uniform target by a countable family of finite continuous optimization problems.

# 6. Explicit Borel witness selection

The previous run left measurable selection as a technical obligation. We close it without importing an abstract measurable-selection theorem.

## 6.1 Continuity

For fixed finite `n`, `(W,x) -> F_W^n(x)` is jointly continuous. Maximization over compact fixed `K_N` therefore makes `W -> L_n^+(W)` continuous. In particular `(5.3)` is Borel.

## 6.2 Finite-net Borel high-product block

Fix deterministic `L_0>1`, block length `n`, and `tau>0`. On

`B_N intersection {||W||<=L_0}`,

we have `L_n^+(W)>=1`.

Choose once and for all a deterministic finite `epsilon`-net `Q={q_1,...,q_M}` of `K_N` with

`epsilon <= (1-exp(-tau)) L_0^(-n)`.  `(6.1)`

On the norm event, `F_W^n` is `L_0^n`-Lipschitz in its input. Therefore a maximizer `x_*` with `||F_W^n(x_*)||>=1` has a net point satisfying

`||F_W^n(q_j)|| >= 1-L_0^n epsilon >= exp(-tau)`.  `(6.2)`

Define `q(W)` to be the **first** point in the fixed enumeration attaining the maximum of the finite list `||F_W^n(q_j)||`. Finite deterministic tie-breaking among continuous functions is Borel.

The trajectory from `q(W)` is live on `(6.2)`. Normalize it as

`F_W(u_t)=g_t u_(t+1)`.

Then

`product_(t=0)^(n-1) g_t = ||F_W^n(q(W))|| >= exp(-tau)`.  `(6.3)`

## `P16-MEASURABLE-BLOCK-WITNESS-48 — PROVED`

For every fixed `n,tau,L_0`, this is an explicit Borel finite high-product witness on the global bad event intersected with the norm cutoff.

## 6.3 Borel near-cycle by finite cell loop erasure

Fix `delta,eta>0`. Partition `K_N` into finitely many Borel cells of diameter at most `delta`, using a deterministic finite net and nearest-center tie-breaking. Let there be `M_cell` cells.

Choose deterministic block length

`n > M_cell + (M_cell log L_0 + tau)/eta`.  `(6.4)`

Apply the Borel block construction. Chronological loop erasure of the cell itinerary of `u_0,...,u_n` decomposes the `n` edges into repeated-cell loops plus a residual simple path. The residual visits distinct cells and has at most `M_cell` edges.

Suppose every removed repeated-cell loop `[s,t]` had mean log gain strictly below `-eta`. Loop edges would contribute less than `-eta` times their number. Each residual edge has `log g_j<=log L_0`. Thus, with residual length `r<=M_cell`,

`sum_(j=0)^(n-1) log g_j`

`< -eta(n-r)+r log L_0`

`<= -eta(n-M_cell)+M_cell log L_0`

`< -tau`,

contradicting `(6.3)`.

Therefore some repeated-cell pair `s<t` satisfies

`||u_t-u_s||<=delta`

and

`(product_(j=s)^(t-1) g_j)^(1/(t-s)) >= exp(-eta)`.  `(6.5)`

Choose the lexicographically first such pair. There are finitely many predicates, all states/gains are Borel functions of `W` on the live block, and cells use deterministic tie-breaking. The selected near-cycle is Borel.

## `P16-MEASURABLE-NEARCYCLE-48 — PROVED`

For every fixed `delta,eta,tau,L_0`, a canonical Borel near-neutral near-returning segment exists on `B_N intersection {||W||<=L_0}`.

### Quantitative limitation

This is an existence/measurability theorem, **not** a low-entropy representation. A `delta`-cover of the positive sphere can have exponentially many cells; `(6.4)` can therefore force an exponentially large block length, and `(6.1)` can require an extremely fine input net. No information-rate conclusion is inferred from this construction.

# 7. Generic Gaussian ReLU target directions already cost information

The retained two-state KL theorem needs a representation of a matrix-adaptive source/target pair. Before trying to upper-bound its information, quantify how much information is already present in a generic one-step target.

Fix a deterministic unit `u` independent of `W`. For `alpha>0`, write

`Wu = sqrt(alpha/N) Z`, with `Z_i iid~N(0,1)`.

Let

`Y=Z_+`, `R=||Y||`, `V=Y/R` when `R>0`, and set `V=0` on the all-negative event.

The scalar factor `sqrt(alpha/N)` cancels, so the target **direction law is independent of alpha**.

Let `B_i=1_{Z_i>0}`. Then `B_1,...,B_N` are iid fair bits and are deterministic functions of `W` once `u` is fixed.

## 7.1 Norm tail

For `t=1/4`, direct Gaussian integration gives

`E exp(t Z_+^2) = 1/2 + 1/(2 sqrt(1-2t)) = (1+sqrt(2))/2.`

Therefore Chernoff gives

`P{R>sqrt(N)} <= exp(-c_R N)`,  `(7.1)`

where

`c_R = 1/4 - log((1+sqrt(2))/2) = 0.06177359354040235...`.

## 7.2 Fano rate-distortion lower bound

Let `Vhat` be **any** possibly randomized representation coupled with `W`, with

`E ||V-Vhat||_2 <= delta`.  `(7.2)`

Fix `a>0`. Decode

`Bhat_i = 1_{Vhat_i >= a/(2 sqrt(N))}`.  `(7.3)`

On `R<=sqrt(N)`:

- if `B_i=1` and `Z_i>=a`, then `V_i>=a/sqrt(N)`, so a false negative forces coordinate error at least `a/(2sqrt(N))`;
- if `B_i=0`, then `V_i=0`, so a false positive forces the same coordinate error.

The only uncontrolled positive coordinates have `0<Z_i<a`. The number of controlled decoding errors is at most

`(2 sqrt(N)/a) ||V-Vhat||_1 <= (2N/a) ||V-Vhat||_2`.

Hence average bit-error probability obeys

`pbar <= Phi(a)-1/2 + 2 delta/a + exp(-c_R N)`.  `(7.4)`

Since `B` is uniform on `{0,1}^N`, coordinatewise binary Fano and concavity of binary entropy `h` imply, whenever the right side of `(7.4)` is below `1/2`,

`I(W;Vhat) >= I(B;Vhat)`

`= N log 2 - H(B|Vhat)`

`>= N [log 2 - h(pbar)]`.  `(7.5)`

Thus, defining

`p_N(a,delta)=Phi(a)-1/2+2 delta/a+exp(-c_R N)`, we have

`I(W;Vhat) >= N [log 2-h(p_N(a,delta))]`,  `(7.6)`

when `p_N(a,delta)<1/2`.

## `P16-GENERIC-RELU-TARGET-FANO-RD-48 — PROVED`

Equation `(7.6)` is the claim. It is an **unconditional fixed-source theorem**. It is not transferred to the conditional law of a target selected on a rare bad event.

## 7.3 Fixed-ball / finite-codebook bound

Fix deterministic `vhat` and define

`S={i: vhat_i >= a/(2sqrt(N))}`.

On `R<=sqrt(N)` and `||V-vhat||_2<=delta`, every index of either type

- `i in S` and `Z_i<=0`, or
- `i notin S` and `Z_i>=a`

costs at least `a/(2sqrt(N))` of coordinatewise absolute error. Therefore their total count `C` satisfies

`C <= 2N delta/a`.  `(7.7)`

For `i in S`, the indicator has probability `1/2`; for `i notin S`, it has probability

`q_a=1-Phi(a)<1/2`.

The indicators are independent and each success probability is at least `q_a`, so their sum stochastically dominates `Bin(N,q_a)`. If

`r=2delta/a < q_a`,

Bernoulli Chernoff plus `(7.1)` gives

`P{||V-vhat||_2<=delta}`

`<= exp[-N D_Ber(r || q_a)] + exp[-c_R N]`.  `(7.8)`

Define

`c_ball(a,delta)=min{ D_Ber(2delta/a || 1-Phi(a)), c_R }`.

Then the right side is at most `2 exp(-N c_ball)`.

For any deterministic codebook `C_N`, union bound gives

`P{dist(V,C_N)<=delta} <= 2 |C_N| exp(-N c_ball)`.  `(7.9)`

If the codebook covers at least half the fresh target law,

`(1/N) log |C_N| >= c_ball(a,delta) - (log 4)/N`.  `(7.10)`

## `P16-GENERIC-RELU-TARGET-BALL-48 — PROVED`

Equations `(7.8)--(7.10)` are the claim.

Again, this is a fresh fixed-source target theorem. A codebook tailored only to a rare dynamical bad event may have much smaller conditional entropy; `(7.10)` does not exclude that possibility.

# 8. Numerical obstruction at the critical edge

The preceding run's universal `b0=1` lossy sampled-transition theorem uses norm cutoff `L_0=8sqrt(alpha)`.

At `alpha=2`, in the near-neutral limit, its zero-distortion exponent is

`c_edge=(1/4)(1-1/sqrt(pi))^2=0.047482679772069526...`.  `(8.1)`

It stays positive for total source-plus-target distortion below

`delta_*=(1-1/sqrt(pi))/(8sqrt(2))=0.03852056259813935...`.  `(8.2)`

Take the exact rational test value `a=58/125=0.464`. At target distortion `delta_*`, the Fano bound has limiting bit-error certificate

`p_* = Phi(0.464)-1/2 + 2delta_*/0.464`

`=0.3447130349349080...`.

Therefore

`log 2-h(p_*)=0.04903495769522859... > c_edge`.  `(8.3)`

The explicit gap is `0.00155227792315906...`.

The fixed-ball theorem is stronger for deterministic codebooks at the same radius:

`q_a=1-Phi(0.464)=0.3213238728156926...`,

`r=2delta_*/a=0.1660369077506007...`,

`D_Ber(r||q_a)=0.0622099052760671...`.

This exceeds `c_R`, so

`c_ball(0.464,delta_*)=c_R=0.06177359354040235...`.  `(8.4)`

Thus a deterministic codebook covering even half of an ordinary fresh ReLU target law at radius `delta_*` has asymptotic rate at least `0.06177...` nats per coordinate, above the universal alignment debt `0.04748...`.

## `P16-NOGO-GENERIC-RD-SUBSTITUTE-48 — DISPROVED route`

Rejected proof substitution:

> Use a generic one-step Gaussian ReLU target rate-distortion code as the low-information representation required by the universal `b0=1` one-transition alignment theorem.

The Fano and fixed-ball certificates show that this generic source is already too information-rich at the relevant distortion scale.

### What this does not reject

This is not a global impossibility theorem for two-state compression on the bad event. Three escapes remain:

1. **Bad-event conditioning.** A rare recurrent event can strongly bias support bits and amplitudes. The unconditional fresh-target rate-distortion theorem cannot simply be inserted conditionally.
2. **Target `l1` / support refinement.** The alignment theorem strengthens when `b(V)=||V||_1/sqrt(N)<1`; dead neurons can increase its exponent. The universal `b0=1` budget is deliberately crude.
3. **Recurrence-specific information.** A cyclic closing target, a multi-transition Gram functional, mask consistency, or another path constraint may isolate the cost of returning to previously visited geometry rather than merely describing a generic next state.

This is the run's sharpest obstruction certificate.

### Claim

P15 fixes arbitrary training pairs `(x_i,y_i)` with `||x_i||<=R`, feature map

`phi_t(x)=m^(-1/2) sigma(W_t x)`,

coordinatewise `|sigma'|<=L`, and output head `A_t` satisfying

`||A_t||_op <= A_0 sqrt(m)`.

Prediction is

`z_t(x)=m^(-1/2) A_t^T sigma(W_t x)`.

The first layer takes an ordinary minibatch gradient step on squared loss. If

`s_t^2=(1/b_t) sum_(i in B_t) ||z_t(x_i)-y_i||^2`,

P15 claims

`||grad_W L_t||_F <= L A_0 R s_t`,

`||W_T-W_0||_F <= L A_0 R sum_(t<T) eta_t s_t`,

and, for every `||x||<=R`,

`||phi_T(x)-phi_0(x)|| <= (L^2 A_0 R^2/sqrt(m)) sum_(t<T) eta_t s_t`.

### Independent derivation

For one observation, with residual `r_i=z_t(x_i)-y_i`, direct differentiation gives

`grad_W (1/2)||r_i||^2`

`= m^(-1/2) diag(sigma'(W_t x_i)) A_t r_i x_i^T`.

Its Frobenius norm is at most

`m^(-1/2) L ||A_t||_op ||r_i|| ||x_i|| <= L A_0 R ||r_i||`.

Averaging over the minibatch and applying Cauchy--Schwarz gives

`||grad_W L_t||_F`

`<= L A_0 R (1/b_t) sum_(i in B_t)||r_i||`

`<= L A_0 R s_t`.

Summing ordinary gradient-step norms gives the second claim. Coordinatewise `L`-Lipschitzness of `sigma` gives

`||phi_T(x)-phi_0(x)||`

`<= (L/sqrt(m)) ||(W_T-W_0)x||`

`<= (L R/sqrt(m)) ||W_T-W_0||_F`,

which gives exactly P15's constant.

No independence from the responses is used. The theorem genuinely requires bounded input norm, bounded derivative along the path, output-head operator-norm bound, and **ordinary gradient steps** for the explicit gradient-derived path budget. P15 separately labels its arbitrary-optimizer update-path variant rather than pretending AdamW obeys the same formula.

**Verdict: PASS.**

# 10. Adversarial checks

## 10.1 Same matrix across time

Sections 4--6 are deterministic statements about the actual tied matrix. No fresh layer is introduced. Sections 7--8 deliberately study a separate **fixed-source one-step law** only to quantify how much information an ordinary target direction already contains; that restriction is explicit.

## 10.2 Exceptional directions

The measurable block and near-cycle selectors are allowed to depend on the full observed matrix. No ordinary-start source theorem is applied to them.

## 10.3 Actual-transition balancing is not recurrence closure

Equation `(4.1)` is stronger algebraically than the preceding cyclic-target inequality but weaker conceptually as a recurrence certificate: it no longer contains a return constraint. This is exactly why generic next-state coding can consume the information budget.

## 10.4 Dead neurons

The target rate-distortion theorem uses random support bits. In the adaptive alignment theorem, sparse represented targets improve the fixed-pair exponent. Dead neurons therefore create both coding information and potentially stronger alignment cost. The missing theorem must couple these effects under bad-event conditioning.

## 10.5 Correlations across time

No independent random-matrix product theorem is used. The near-cycle construction is deterministic. The generic target theorem concerns one fixed source by design and is not substituted for a tied adaptive path.

## 10.6 Finite-width errors

Balancing, positive-cone block equivalence, Borel selection, Fano, and fixed-ball bounds are finite-`N`. The rate comparison in Section 8 uses `N->infinity` only to drop the exponentially small `exp(-c_R N)` term in the Fano error parameter.

## 10.7 Zero output

`R=0` occurs exactly when all Gaussian coordinates are nonpositive, probability `2^(-N)`. Defining `V=0` there causes no problem in the displayed inequalities.

## 10.8 Conditional versus unconditional rate distortion

Equations `(7.6)` and `(7.10)` are unconditional fixed-source theorems. They do **not** imply the same target entropy after conditioning on the global bad event. Section 8 rejects only a generic-source coding substitution, not a bad-event-specific compression strategy.

# 11. Comparison of proof mechanisms

## Lyapunov / submultiplicative dynamics

The positive-cone norms `L_n^+` give an exact deterministic finite-block characterization: one contracting block is equivalent to global uniform exponential contraction. The bad event is the countable intersection `L_n^+>=1`.

## Random-matrix products

No independent-product result is imported. Exact long cycles contain tied repeated entries and remain difficult. The current route avoids treating them as fresh products.

## Mean field

The fresh fixed-input second moment `(alpha/2)` remains an ordinary-start fact. It is not used on adaptive states.

## Concentration

The preceding fixed-pair alignment theorem gives an order-`N` Gaussian tail. This run adds support/magnitude decoding of a fresh target direction, with explicit Gaussian norm and Bernoulli lower-tail estimates.

## Coupling / information

KL decoupling can price an adaptive pair from below, but a representation may already need linear information simply to describe a generic next state. A successful proof needs an upper information bound for **excess recurrent structure**, not the whole next-state description.

## Deterministic Lipschitz / homogeneity

Positive homogeneity gives both submultiplicativity and exact gain balancing. ReLU 1-Lipschitzness gives finite-net witness stability. No stronger monotonicity claim is used.

## Fixed-query high probability

## Matrix-adaptive statements

The block/near-cycle selector is Borel after `W` is fixed. The retained adaptive alignment theorem remains a lower bound on

`log(1/P(E)) + I(W; representation | E)`,

not an unconditional bad-event probability theorem.

## Uniform in input

The full all-input/all-time contraction theorem remains proved only for `alpha<1/2`. Positive-cone block equivalence is deterministic for every matrix but does not itself show that a random Gaussian matrix has a contracting block in the open range.

## Almost sure

No new almost-sure-in-time contraction theorem is proved. Previously retained summable restricted cycle-class bounds can yield across-width Borel--Cantelli statements under a chosen coupling, which is a different quantifier.

## Bottom line

P16 is not solved. This run closes the measurable-witness gap and exposes a sharper obstruction in the information program. Gain balancing shows that high **actual-transition** alignment is generic to any high-product block, not inherently recurrent. A fresh ReLU target direction already carries linear information at the distortion scale where the universal one-transition theorem operates. Therefore a proof near `alpha=2` must isolate and price the **extra information of recurrent self-consistency**—through target `l1`/support geometry, closing-transition mass, or a multi-transition/path constraint—rather than trying to compress an ordinary next-state direction below its natural rate.
