\[
W_{ij}\stackrel{\rm iid}{\sim}N(0,\alpha/N),\qquad
F_W(x)=\operatorname{ReLU}(Wx),\qquad

with the **same matrix `W` reused forever**, throughout

The strongest target is unchanged: for every fixed `alpha<2`, with probability tending to one as `N -> infinity`, there should be random constants `C(W)<infinity` and `rho(W)<1` such that

\[
\|F_W^t(x)\|\le C(W)\rho(W)^t\|x\|
\]

for **every** input `x` and every `t>=0`. Equivalently, the maximal radial Lyapunov exponent is negative. Positive homogeneity gives, for `W=sqrt(alpha) A`,

\[
\lambda_{\max}(W)=\lambda_{\max}(A)+\frac12\log\alpha,

so the conjectural edge statement remains

\[
P\left\{\lambda_{\max}(A_N)<-\frac12\log 2+\varepsilon\right\}\to1

for every `eps>0`.

The strongest statement is still neither proved nor falsified on `1/2<=alpha<2`. This run makes a finite-width, every-input advance on exact recurrent obstructions without changing the tied model.

## Main new package

The preceding run showed that pairwise-disjoint-support projective cycles are exponentially unlikely and identified overlap cosine as the next obstruction. This run resolves two substantial pieces of that obstruction.

1. **Support-word compression.** Any exact projective cycle whose activation-support word repeats with a shorter period deterministically compresses to a shorter projective cycle with the **same geometric-mean gain**. In particular, every same-support cycle of any period collapses to a period-one ReLU eigenray. Thus a noncontracting same-support cycle is already covered by the inherited period-one exclusion theorem.

2. **A general overlapping period-two sign-gauge bound.** For arbitrary nonempty supports `S,T`, with no disjointness assumption, let `Z_{S,T}` be the number of phase-marked projective 2-cycles with those supports. Then

\[
\boxed{
E Z_{S,T}\le \min(|S|,|T|)\,2^{-(N-1)}.
}
\tag{0.1}
\]

This holds for **all gains**; it is not restricted to noncontracting cycles. The factor comes from an exact sign-gauge orbit on the internal tied block plus the worst-case `1/2` probability per row outside `S union T`. No fresh-layer substitution is made.

Summing `(0.1)` over support pairs whose union has size at most `m` gives the exact finite-width certificate

\[
\boxed{
P\{\exists\text{ projective 2-cycle with }|S\cup T|\le m\}
\le
N\,2^{-(N-1)}
\sum_{u=1}^{m}\binom Nu(3^u-2).
}
\tag{0.2}
\]

Consequently, if `m=floor(beta N)` and

\[
H(\beta)+\beta\log 3<\log2,
\]

then the probability decays exponentially. The unique root in `(0,1/2)` is

\[
\boxed{
\beta_2^*=0.1892896249152317626\ldots
}
\tag{0.3}
\]

and for every fixed `beta<beta_2^*`,

\[
P\{\exists\text{ projective 2-cycle with }|S\cup T|\le\beta N\}
\le \operatorname{poly}(N)e^{-N c_2(\beta)},
\]

with

\[
\boxed{c_2(\beta)=\log2-H(\beta)-\beta\log3>0.}
\tag{0.4}
\]

This is an **every-input high-probability theorem for the original tied matrix**. The candidate cycle may be selected after seeing `W`.

A cosine-sensitive refinement is also proved. For unit phases `u,v`, put

\[
\rho=\langle u,v\rangle,
\qquad
p(\rho)=\frac14+\frac{\arcsin\rho}{2\pi}.
\]

For every `rho0<1`, support pairs with `rho<=rho0` satisfy

\[
E Z_{S,T}(\rho\le\rho_0)
\le
\min(|S|,|T|)\,2^{-(|S\cup T|-1)}
 p(\rho_0)^{N-|S\cup T|}.
\tag{0.5}
\]

Hence union fractions below the first root of

\[
H(\beta)+\beta\log(3/2)+(1-\beta)\log p(\rho_0)=0
\tag{0.6}
\]

are exponentially excluded. Numerically:

- `rho0=1/2`: `p=1/3`, threshold `beta=0.3157831633506621...`;
- `rho0=0.9`: threshold `beta=0.2384169442121402...`;
- `rho0 -> 1`: the threshold decreases to the universal `beta_2^*` in `(0.3)`.

Finally, the high-overlap branch is reduced deterministically to an approximate-ray / near-margin obstruction. If a unit 2-cycle satisfies

\[
F(u)=g v,\qquad F(v)=h u,\qquad gh\ge1,
\]

and `L=||W||`, then

\[
\boxed{
(g-h)^2+2gh(1-\rho)\le 2L^2(1-\rho),
}
\tag{0.7}
\]

so high `rho` forces the two gains to synchronize. Also one of the two phases is an approximate expanding fixed ray:

\[
\boxed{
\min\left\{
\inf_{q\ge1}\|F(u)-qu\|,
\inf_{q\ge1}\|F(v)-qv\|
\right\}
\le L\sqrt{2(1-\rho)}.
}
\tag{0.8}
\]

If `S != T`, every changed mask coordinate is simultaneously a small-margin coordinate in the aggregate sense

\[
\boxed{
\sum_{i\in S\triangle T}
\left[(Wu)_i^2+(Wv)_i^2\right]
\le
2L^2(1-\rho).
}
\tag{0.9}
\]

Thus the exact surviving period-two obstruction is no longer merely “overlap.” Except on exponentially small events already controlled, it must be a **macroscopically supported, support-changing, partially overlapping cycle**, and if its phase cosine is very high it must also create a quantitative approximate expanding eigenray and a collection of tiny mask margins. This interfaces directly with the inherited information/margin and nonnormal-transient machinery.

# 3. Exact projective-cycle setup

A phase-marked projective `k`-cycle consists of nonzero states `x_0,...,x_{k-1}` and gains `g_j>0`, indices modulo `k`, satisfying

\[
F_W(x_j)=g_jx_{j+1}.
\tag{3.1}
\]

Every phase is an output of ReLU and is therefore coordinatewise nonnegative. Let

\[
S_j=\operatorname{supp}(x_j).
\]

The geometric-mean radial gain is

\[
\kappa=\left(\prod_{j=0}^{k-1}g_j\right)^{1/k}.
\tag{3.2}
\]

The cycle is noncontracting when `kappa>=1`.

A dead state cannot create a recurrent obstruction: if `F_W(x)=0`, all later states are zero. All cycle statements below therefore concern nonempty supports.

# 4. Deterministic support-word compression

## `P16-SUPPORT-WORD-COMPRESSION-40` — PROVED

This theorem uses no randomness.

First balance the gains. Set `a_0=1` and recursively

\[
a_{j+1}=a_jg_j/\kappa.
\]

Because the product of the `g_j` is `kappa^k`, the definition is cyclic. Put

\[
y_j=a_jx_j.
\]

By positive homogeneity,

\[
F_W(y_j)=\kappa y_{j+1}.
\tag{4.1}
\]

Suppose the cyclic support word has period `d|k`:

\[
S_{j+d}=S_j
\qquad\text{for all }j.
\tag{4.2}
\]

Define

\[
z_r=
\sum_{m=0}^{k/d-1}y_{r+md},
\qquad r=0,\ldots,d-1.
\tag{4.3}
\]

Each term in `z_r` has support `S_r`, so `z_r>0` exactly on `S_r`. For a single balanced phase, `(4.1)` says

- on `S_{r+1}`, `Wy_{r+md}=kappa y_{r+md+1}`;
- outside `S_{r+1}`, `Wy_{r+md}<=0` coordinatewise.

Because all terms in the same congruence class have the same next support, summing preserves both facts:

\[
(Wz_r)_{S_{r+1}}=\kappa(z_{r+1})_{S_{r+1}},
\]

while

\[
(Wz_r)_{S_{r+1}^c}\le0.
\]

Therefore

\[
\boxed{F_W(z_r)=\kappa z_{r+1}.}
\tag{4.4}
\]

So a `k`-cycle whose support word has period `d` produces a projective `d`-cycle with the **same** geometric-mean gain `kappa`.

### Corollaries

### `P16-SAME-SUPPORT-CYCLE-COLLAPSE-40` — PROVED

If all phase supports are the same (`d=1`), then

\[
\boxed{F_W(z)=\kappa z}
\]

for `z=sum_j y_j>0` on the common support. Thus every same-support projective cycle of any period produces a period-one ReLU eigenray with multiplier equal to the cycle’s geometric-mean gain.

Hence for `alpha<2`, the inherited every-input period-one theorem immediately excludes noncontracting same-support cycles with the same probability bound as expanding/noncontracting fixed rays. Near `alpha=2`, the retained certificate is of order

\[
\exp\left[-\left(\frac1{72}+o(1)\right)N(2-\alpha)^2\right].
\]

### `P16-ALTERNATING-SUPPORT-COMPRESSION-40` — PROVED

Any even-period cycle whose support word alternates `S,T,S,T,...` compresses to a genuine projective 2-cycle with gain `kappa` on each compressed step.

### Consequence

A minimal exact projective obstruction can be assumed to have a **primitive support word**: if the support word repeats with smaller period, the obstruction already exists at that smaller period. This is useful for future fixed-period counting and prevents long cycles from hiding behind a merely repeated short mask program.

# 5. Arbitrary-overlap period two: internal block representation

Now fix nonempty supports `S,T`, with no disjointness assumption. Put

\[
s=|S|,\qquad t=|T|,\qquad
U=S\cup T,\qquad u=|U|,
\]

and let `R=U^c`.

For a projective 2-cycle write, after separate phase normalization if desired,

\[
F_W(u_0)=g v_0,
\qquad
F_W(v_0)=h u_0,
\tag{5.1}
\]

where `u_0>0` on `S`, `v_0>0` on `T`, and both are zero off their supports.

The active equations are

\[
W_{T,S}u_0=g v_0,
\qquad
W_{S,T}v_0=h u_0.
\tag{5.2}
\]

Define the duplicated-support block operator

\[
\mathcal M_{S,T}(W)
=
\begin{pmatrix}
0 & W_{S,T}\\
W_{T,S} & 0
\end{pmatrix}
\quad\text{on }\mathbb R^S\oplus\mathbb R^T.
\tag{5.3}
\]

The two off-diagonal blocks **share the entries `W_{I,I}` when `I=S cap T`**. They are not independent layers.

Set

\[
\widehat u=\sqrt h\,u_0,
\qquad
\widehat v=\sqrt g\,v_0,
\qquad
\kappa=\sqrt{gh}.
\]

Then `(5.2)` is equivalent to

\[
\boxed{
\mathcal M_{S,T}(W)
\binom{\widehat u}{\widehat v}
=
\kappa
\binom{\widehat u}{\widehat v}.
}
\tag{5.4}
\]

Thus every projective 2-cycle supplies a positive real eigendirection of the **tied overlapping block operator**. Conversely, an internal eigendirection is only a candidate: the inactive ReLU inequalities still have to hold.

The nonzero eigenvalues of `(5.3)` occur in `+/-` pairs and there are at most `2 min(s,t)` of them. Hence the number of positive nonzero real eigenvalues is at most

\[
\boxed{\min(s,t).}
\tag{5.5}
\]

No product-spectrum asymptotics are needed.

# 6. The internal overlap sign-gauge theorem

## `P16-PERIOD2-INTERNAL-GAUGE-40` — PROVED

Let `I=S cap T`. For a positive real eigendirection of `(5.3)`, call it **overlap-compatible** if every duplicated overlap coordinate has the same sign in the two phase blocks. Only overlap-compatible eigendirections can be transformed into a pair of strictly positive phase vectors.

For a diagonal sign matrix `D` on `U`, conjugate the internal tied block by

\[
W_{U,U}\mapsto D W_{U,U}D.
\tag{6.1}
\]

Because the entries are centered iid Gaussian, the internal law is invariant. On the duplicated phase space,

\[
\mathcal M_{S,T}(DWD)
=
\begin{pmatrix}D_S&0\\0&D_T\end{pmatrix}
\mathcal M_{S,T}(W)
\begin{pmatrix}D_S&0\\0&D_T\end{pmatrix}.
\tag{6.2}
\]

The all-minus sign on `U` acts trivially on the internal matrix and only changes an eigenvector by global sign. Therefore the effective sign group has size

\[
2^{u-1}.
\tag{6.3}
\]

Fix any overlap-compatible nonzero eigendirection with no zero support coordinate. Among these `2^{u-1}` sign classes, **exactly one** makes both phase blocks strictly positive. If an eigendirection is not overlap-compatible, none does.

Hence, for any condition `C` invariant under the sign gauge (for example an eigenvalue threshold, component norms, or the phase cosine), averaging exactly over the sign group gives

\[
\boxed{
E C^+_{S,T}(C)
=
2^{-(u-1)}
E R^{+,\mathrm{comp}}_{S,T}(C),
}
\tag{6.4}
\]

where the left side counts internally positive candidate eigendirections and the right side counts positive real overlap-compatible eigendirections before enforcing positivity.

In particular, by `(5.5)`,

\[
\boxed{
E C^+_{S,T}(C)
\le
2^{-(u-1)}\min(s,t).
}
\tag{6.5}
\]

Gaussian absolute continuity removes degenerate eigenspaces/zero-coordinate cases almost surely; alternatively they can simply be omitted because they cannot represent the prescribed strict supports.

This is the key overlap replacement for the stronger disjoint sign factor from the preceding run. Overlap recycles exactly one available sign bit per reused coordinate: the same diagonal sign must act on both phase copies of an overlap coordinate.

# 7. External rows and the universal fixed-support period-two bound

For every row `i in R=U^c`, a genuine 2-cycle needs

\[
w_i^Tu_0\le0,
\qquad
w_i^Tv_0\le0.
\tag{7.1}
\]

Conditional on all internal data, the outside row is independent Gaussian. If the phases are unit vectors after zero extension to `R^N`, their correlation is

\[
\rho=\langle u_0,v_0\rangle\in[0,1].
\]

The pair `(w_i^Tu_0,w_i^Tv_0)` is centered bivariate Gaussian with correlation `rho`, so rotational geometry in the underlying two-dimensional standard Gaussian plane gives

\[
\boxed{
P\{w_i^Tu_0\le0,w_i^Tv_0\le0\}
=
 p(\rho)
:=
\frac14+\frac{\arcsin\rho}{2\pi}.
}
\tag{7.2}
\]

The outside rows are independent. In particular,

\[
p(\rho)\le\frac12.
\tag{7.3}
\]

The inactive inequalities on the internal symmetric-difference rows `S triangle T` may be highly correlated with the active equations because of the shared core. For an **upper bound** we simply discard those constraints. Therefore every genuine cycle is contained in the event “internally positive candidate + all outside rows inactive in both phases.”

Combining `(6.5)` and `(7.3)` gives the main fixed-support theorem.

## `P16-PERIOD2-FIXEDSUPPORT-40` — PROVED

Let `Z_{S,T}` be the number of phase-marked projective ReLU 2-cycles with ordered supports exactly `(S,T)`, with arbitrary positive gains. Then

\[
\begin{aligned}
E Z_{S,T}
&\le
2^{-(u-1)}\min(s,t)
\left(\frac12\right)^{N-u}\\
&=
\boxed{\min(s,t)\,2^{-(N-1)}.}
\end{aligned}
\tag{7.4}
\]

The striking point is that the worst-case exponent is independent of the overlap size.

This is weaker than the preceding disjoint-support identity, where all internal inactive inequalities are also independent and the fixed-support cost is of order `2^{-2N}`. But `(7.4)` applies to **arbitrary overlap**, including the shared `W_{I,I}` core.

### Weight-law dependence

For the main P16 theorem we keep the exact iid Gaussian law. The crude `1/2` outside-row bound and the diagonal sign-gauge argument actually need only independent rows/entries with a continuous coordinatewise sign-symmetric law. The sharper `arcsin` formula `(7.2)` is Gaussian-specific. No universality claim for the full Lyapunov conjecture is made.

# 8. Sparse-union exclusion for all overlapping 2-cycles

The number of ordered nonempty support pairs `(S,T)` with union of cardinality `u` is

\[
\binom Nu(3^u-2).
\tag{8.1}
\]

Indeed, after choosing the union, each coordinate is labeled `S only`, `T only`, or `both`; the two assignments making one support empty are removed.

Summing `(7.4)` and using `min(s,t)<=N` gives the exact finite-width result.

## `P16-PERIOD2-SPARSE-UNION-40` — PROVED

For every integer `1<=m<=N`,

\[
\boxed{
P\{\exists\text{ projective 2-cycle with }|S\cup T|\le m\}
\le
N\,2^{-(N-1)}
\sum_{u=1}^{m}\binom Nu(3^u-2).
}
\tag{8.2}
\]

This counts **all gains**, not merely noncontracting cycles.

Let `m=floor(beta N)`. For `beta<3/4`, the summands are exponentially increasing up to the endpoint, and the entropy bound `binom(N,beta N)<=exp(N H(beta))` gives

\[
P\{\exists\text{ such cycle}\}
\le
\operatorname{poly}(N)
\exp\{-N c_2(\beta)\},
\tag{8.3}
\]

where

\[
\boxed{
c_2(\beta)=\log2-H(\beta)-\beta\log3.}
\tag{8.4}
\]

The first positive root of `c_2(beta)=0` is

\[
\boxed{
\beta_2^*=0.1892896249152317626023946933\ldots
}
\tag{8.5}
\]

so every fixed `beta<beta_2^*` has an explicit positive exponential rate.

Examples:

\[
c_2(0.10)=0.2582029783\ldots,

\[
c_2(0.15)=0.1056462495\ldots,
\]

\[
c_2(0.18)=0.0240034818\ldots.
\]

Thus a typical tied Gaussian matrix has **no exact projective 2-cycle at all** whose two supports together occupy less than about `18.93%` of the coordinates.

This is a finite-width every-input statement: the two-cycle, its supports and its phases may all be selected after observing `W`.

# 9. Cosine-sensitive support-union refinement

If we restrict to candidate phases with

\[
\rho\le\rho_0<1,
\]

then `(7.2)` improves the outside factor from `1/2` to

\[
p_0=p(\rho_0)<1/2.
\]

Combining with `(6.5)` gives

\[
\boxed{
E Z_{S,T}(\rho\le\rho_0)
\le
\min(s,t)
2^{-(u-1)}p_0^{N-u}.
}
\tag{9.1}
\]

Summing over support unions yields

\[
P\{\exists\text{ 2-cycle}:|S\cup T|\le m,\rho\le\rho_0\}
\le
2N\sum_{u=1}^{m}
\binom Nu(3/2)^u p_0^{N-u}.
\tag{9.2}
\]

For fixed `beta=m/N` below the mode, the exponential exponent is

\[
\Phi(\beta,\rho_0)
=
H(\beta)+\beta\log(3/2)
+(1-\beta)\log p_0.
\tag{9.3}
\]

## `P16-PERIOD2-LOWCOS-UNION-40` — PROVED

Whenever

\[
\Phi(\beta,\rho_0)<0,

the corresponding class is exponentially unlikely. Let `beta_*(rho0)` be the first root `Phi=0`. Direct high-precision calculation gives

\[
\beta_*(1/2)=0.3157831633506621328\ldots

because `p(1/2)=1/3`, and

\beta_*(0.9)=0.2384169442121401911\ldots.

As `rho0` increases to one, `p0` increases to `1/2` and `beta_*(rho0)` decreases to the universal threshold `(8.5)`.

This makes the overlap-energy obstruction quantitative: **weakly aligned phases must use a substantially larger coordinate union before the first-moment entropy can overwhelm the tied sign cost.**

# 10. High-overlap deterministic rigidity

The low-cosine theorem leaves the difficult branch `rho close to 1`. Here an exact deterministic reduction is available.

Normalize the two phase directions to unit norm and write

\[
F(u)=gv,
\qquad
F(v)=hu,
\qquad
g,h>0.
\tag{10.1}
\]

Since ReLU is 1-Lipschitz coordinatewise,

\[
\|gv-hu\|
=
\|F(u)-F(v)\|
\le
\|W(u-v)\|
\le
L\|u-v\|,
\qquad L=\|W\|.
\tag{10.2}
\]

Because `u,v` are unit and nonnegative,

\[
\|u-v\|^2=2(1-\rho).
\tag{10.3}
\]

Expanding the left side of `(10.2)` gives

\[
\|gv-hu\|^2
=(g-h)^2+2gh(1-\rho).
\]

Therefore

\[
\boxed{
(g-h)^2+2gh(1-\rho)
\le
2L^2(1-\rho).
}
\tag{10.4}
\]

## `P16-HIGHRHO-GAIN-SYNC-40` — PROVED

If the two-cycle is noncontracting, `gh>=1`, then

\[
\boxed{
|g-h|
\le
\sqrt{2(L^2-gh)(1-\rho)}
\le
\sqrt{2(L^2-1)(1-\rho)}.
}
\tag{10.5}
\]

Thus high overlap cosine prevents the “one huge gain / one tiny gain” escape: the two gains must synchronize.

Since `gh>=1`, at least one of `g,h` is at least one. If `g>=1`, then

\[
\|F(u)-gu\|
=g\|v-u\|
\le
L\sqrt{2(1-\rho)},
\]

because `g<=L`. The other case is symmetric.

## `P16-HIGHRHO-APPROX-RAY-40` — PROVED

Every noncontracting projective 2-cycle satisfies

\[
\boxed{
\min\left\{
\inf_{q\ge1}\|F(u)-qu\|,
\inf_{q\ge1}\|F(v)-qv\|
\right\}
\le
L\sqrt{2(1-\rho)}.
}
\tag{10.6}
\]

So `rho -> 1` forces an approximate expanding period-one ray.

This does **not** turn the inherited exact fixed-ray theorem into a complete proof. Prior P16 already constructed stable nonnormal systems with arbitrarily accurate near-unit pseudoeigenvectors. Approximate-ray exclusion needs an additional quantitative normality/transient or self-consistent-mask argument.

# 11. High overlap also forces mask-change margins to zero

Assume the support sets differ. For `i in S\T`, the first step is inactive at row `i` while the second is active:

\[
(Wu)_i\le0,
\qquad
(Wv)_i=hu_i>0.
\]

For `i in T\S`,

\[
(Wu)_i=gv_i>0,
\qquad
(Wv)_i\le0.
\]

At every changed coordinate, the two preactivations have opposite weak signs. Therefore

\[
(W(u-v))_i^2
\ge
(Wu)_i^2+(Wv)_i^2.
\]

Summing over the symmetric difference and using `(10.3)` yields

\[
\boxed{
\sum_{i\in S\triangle T}
\left[(Wu)_i^2+(Wv)_i^2\right]
\le
\|W(u-v)\|^2
\le
2L^2(1-\rho).
}
\tag{11.1}
\]

## `P16-HIGHRHO-MASK-MARGIN-40` — PROVED

A high-cosine support-changing exact 2-cycle necessarily realizes its mask changes through collectively tiny preactivation margins. In particular,

\[
h^2\|u_{S\setminus T}\|^2
+
g^2\|v_{T\setminus S}\|^2
\le
2L^2(1-\rho).
\tag{11.2}
\]

This is precisely the interface missing in the preceding run’s overlap-cardinality discussion. It does not by itself make the event rare because the directions are chosen after seeing `W`; however, it connects the high-overlap cycle branch to the inherited adaptive margin-KL / lossy-witness machinery.

# 12. What is now ruled out, and the sharp remaining obstruction

Combine the inherited and new theorems.

For `alpha<2`, outside events already exponentially small:

1. a noncontracting period-one ReLU ray is absent with the inherited period-one bound;
2. every pairwise-disjoint-support exact cycle of every period is absent with the preceding run’s fixed exponential bound;
3. by `P16-SUPPORT-WORD-COMPRESSION-40`, every noncontracting same-support cycle of any period is already a forbidden period-one obstruction;
4. by `P16-PERIOD2-SPARSE-UNION-40`, every exact period-two cycle with support union below `(beta_2^*-o(1))N` is absent;
5. if the phase cosine is bounded away from one, the required support-union fraction is even larger according to `(9.3)`.

Therefore a surviving exact noncontracting period-two mechanism must be

\[
\boxed{
\text{macroscopically supported + support-changing + partially overlapping.}
}
\]

If its overlap cosine is close to one, it additionally has to satisfy the gain synchronization, approximate-ray and tiny-mask-margin certificates `(10.5)`--`(11.2)`.

This is a sharper obstruction than the preceding statement “large overlap cosine.” The hard branch is now:

\[
\boxed{
\text{dense partial-overlap switching with adaptive near-zero margins / nonnormal renewal.}
}
\]

The exact global conjecture is still open because excluding all finite exact cycles is not enough: a non-atomic recurrent invariant measure or indefinitely renewed nonnormal transient mechanism can in principle have nonnegative maximal Lyapunov exponent without any periodic orbit of the forbidden types.

# 13. Method comparison and stress tests

## 13.1 Mean-field recurrence

For a fixed direction independent of a fresh Gaussian layer,

\[
E\|\operatorname{ReLU}(Wx)\|^2
=\frac\alpha2\|x\|^2.
\]

This explains the critical value `alpha=2` and the source finite-horizon profile. It does **not** control a `W`-dependent exceptional direction in the tied model.

## 13.2 Lyapunov formulation

The exact target is the maximal radial Lyapunov exponent, not one-step expectation and not the spectral radius of `W`. The new cycle theorems are necessary-obstruction results inside the exact Lyapunov problem, not a replacement objective.

## 13.3 Random-matrix products

For a 2-cycle the exact tied internal object is `(5.3)`, equivalently the correlated product `W_{S,T}W_{T,S}`. On the overlap `I=S cap T`, the two blocks share `W_{I,I}`. The proof keeps that dependence. No independent Ginibre-product law is imported.

## 13.4 Concentration

The reviewed source gives exponentially good concentration for one deterministic or `W`-independent start at fixed horizon. The new sparse-union cycle theorem instead uses sign-gauge counting and external-row independence to obtain a finite-`N` **uniform-in-input** statement.

## 13.5 Coupling

The preceding disjoint-cycle failure bound is summable in width and therefore gives an almost-sure-across-widths statement under any coupling with correct marginals. The new sparse-union bound is also exponentially small for `beta<beta_2^*`, so the same Borel--Cantelli observation applies to that restricted event. This is not an almost-sure-in-time theorem for one fixed matrix.

## 13.6 Deterministic Lipschitz and monotonicity

ReLU is 1-Lipschitz, which gives the high-overlap rigidity `(10.4)`. The full map is not order-preserving because `W` has mixed signs, so nonlinear Perron--Frobenius monotonicity cannot simply be invoked. The same-support compression theorem works instead because the inactive inequalities have a common support and remain nonpositive under summation.

## 13.7 Dead neurons

If an iterate becomes zero, the trajectory remains zero. Dead neurons therefore help contraction and cannot generate the recurrent cycles considered here.

## 13.8 Exceptional directions

The new fixed-support and sparse-union results allow the supports and phase directions to depend arbitrarily on the realized matrix. They therefore address the exact exceptional-direction quantifier that the source fixed-horizon theorem leaves open.

## 13.9 Finite width

Equations `(7.4)` and `(8.2)` are finite-`N` statements. The entropy threshold `(8.5)` is only the asymptotic corollary. There is no hidden `N -> infinity` step in the sign-gauge proof.
