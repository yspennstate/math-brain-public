`W_ij iid ~ N(0, α/N)`,  `F_W(x)=ReLU(Wx)`,  `x_(t+1)=F_W(x_t)`,

> For each fixed `α<2`, with probability tending to one as `N→∞`, there exist random `C(W)<∞` and `ρ(W)<1` such that

# 4. A fixed cross-transition Gaussian functional

Let `u,v in R_+^N` be deterministic unit vectors and define

`H_(u,v)(W) = v^T ReLU(Wu)`.

Put

`μ_α = sqrt(α/(2π))`,

`b(v) = ||v||_1/sqrt(N)`, so `0 < b(v) <= 1`.

Because `Wu` has iid coordinates `N(0,α/N)`, exactly

`E H_(u,v) = sqrt(α/(2πN)) ||v||_1 = μ_α b(v)`.

This mean depends on the target phase `v`, but not on the source direction `u`.

Write `W=sqrt(α/N) G` with standard Gaussian `G`. ReLU is 1-Lipschitz, so for any `G,G'`,

`|H_(u,v)(G)-H_(u,v)(G')|`

` <= || ReLU(sqrt(α/N)Gu)-ReLU(sqrt(α/N)G'u) ||`

` <= sqrt(α/N) ||(G-G')u||`

` <= sqrt(α/N) ||G-G'||_F`.

Hence the standard Gaussian concentration MGF gives, for every real `θ`,

`log E exp[ θ(H_(u,v)-E H_(u,v)) ] <= α θ^2/(2N)`.

Therefore for `a>=μ_α b(v)`,

`P{H_(u,v)>=a} <= exp[ -N (a-μ_α b(v))^2/(2α) ]`.

This is finite-width and requires only that the queried pair be deterministic (or decoupled from `W`). It is a cross-state extension of the preceding one-ray alignment calculation.

## `P16-FIXEDPAIR-ALIGNMENT-MGF-47 — PROVED`

The exact mean, MGF proxy, and tail above are the claim.

### Dead-neuron refinement

If `|supp(v)| <= σN`, then by Cauchy--Schwarz

`b(v) <= sqrt(σ)`.

Thus

`P{H_(u,v)>=a} <= exp[ -N (a-μ_α sqrt(σ))_+^2/(2α) ]`.

This is the basic support-sensitive improvement used below.

# 5. Gain balancing and one random transition

Consider any live normalized realized segment

`F_W(u_t) = g_t u_(t+1)`, `||u_t||=1`, `u_t>=0`, `g_t>0`,

for `t=0,...,k-1`.

Define its geometric mean gain

`κ = (product_t g_t)^(1/k)`.

Set

`a_0=1`, `a_(t+1)=a_t g_t/κ`.

Then the product identity gives `a_k=a_0=1`. Let

`A = sum_(t=0)^(k-1) a_t`,

`λ_t = a_t/A`.

Thus `λ` is a probability vector and, cyclically,

`λ_t g_t = κ λ_(t+1)` for `t<k-1`,

`λ_(k-1) g_(k-1) = κ λ_0`.

Now define the cyclic target

`v_t = u_(t+1)` for `t<k-1`, and `v_(k-1)=u_0`.

Then

`sum_t λ_t v_t^T F_W(u_t)`

` = sum_(t<k-1) λ_t g_t + λ_(k-1) g_(k-1) <u_0,u_k>`

` = κ [1 - λ_0(1-<u_0,u_k>)]`.

For unit vectors,

`1-<u_0,u_k> = ||u_k-u_0||^2/2`.

Therefore, writing `r=||u_k-u_0||`,

`sum_t λ_t v_t^T F_W(u_t) >= κ (1-r^2/2)`.

Now, conditional on the realized path, sample an index `T` with probabilities `λ_t` using fresh auxiliary randomness and set

`U=u_T`, `V=v_T`.

Then exactly

`E_T[ V^T F_W(U) | W,path ]`

` = κ [1-λ_0 r^2/2]`

` >= κ(1-r^2/2)`.

## `P16-BALANCED-TRANSITION-SAMPLING-47 — PROVED`

This is the claim. Its important feature is that **arbitrarily severe gain imbalance disappears**: the weights are chosen from the gain ratios so that the weighted average is the geometric mean, up to the explicit return-cosine loss on the closing transition.

If a near-cycle has

`κ >= exp(-η)` and `r<=r_0`,

then the sampled transition satisfies the conditional expectation bound

`E_T[V^T F_W(U) | W,path] >= a_(η,r_0)`,

where

`a_(η,r_0) = exp(-η)(1-r_0^2/2)`.

As `η,r_0 -> 0`, this approaches `1`.

# 6. Adaptive one-transition information debt

Let `E` be a `W`-measurable event with probability `p>0`. Assume that on `E` a measurable finite recurrent witness has been selected with

- live normalized nonnegative states `u_0,...,u_k`;
- geometric mean gain `κ>=exp(-η)`;
- return distance `||u_k-u_0||<=r_0`.

The measurable finite-witness hypothesis is explicit. The previously proved compactness-closing lemma supplies the relevant finite near-cycles from any nonnegative upper-Lyapunov witness; converting an existential global bad event into one canonical measurable selector is a technical selection step and is not hidden here.

Form `λ` and sample `(U,V)` as in Section 5. Let `P_E` be the resulting joint law of `(W,U,V)` conditioned on `E`.

Define the decoupled law

`Q = P_W tensor P_(U,V | E)`.

Because `E` is `W`-measurable,

`D(P_E || Q) = log(1/p) + I(W ; U,V | E)`.

Suppose additionally that

`b(V)=||V||_1/sqrt(N) <= b_0`

almost surely under the selected transition law; the universal choice is `b_0=1`.

Under `P_E`, Section 5 gives

`E H_(U,V)(W) >= a_(η,r_0)`.

Under `Q`, conditional on `(U,V)=(u,v)`, Section 4 gives

`log E_W exp[θ H_(u,v)(W)]`

` <= θ μ_α b_0 + α θ^2/(2N)`

for `θ>=0`.

The entropy variational inequality therefore yields

`log(1/p)+I(W;U,V|E)`

` >= θ [a_(η,r_0)-μ_α b_0] - α θ^2/(2N)`.

Optimizing over `θ>=0` gives

**(6.1)**

`log(1/P(E)) + I(W;U,V | E)`

` >= N [ a_(η,r_0)-μ_α b_0 ]_+^2 / (2α)`.

## `P16-ADAPTIVE-TRANSITION-INFO-47 — PROVED`

Equation `(6.1)` is the claim.

This theorem already allows the near-cycle, the balancing weights, and the sampled transition to depend arbitrarily on the same tied matrix. The adaptivity is not treated as a fresh Gaussian query; it is paid exactly through mutual information.

### Near-neutral limiting rate

With `η,r_0 -> 0` and no support information (`b_0=1`), the coefficient is

`c_trans(α) = [1-sqrt(α/(2π))]^2/(2α)`.

At `α=2`,

`c_trans(2) = (1/4)(1-1/sqrt(pi))^2`

` = 0.047482679772069526...`.

The coefficient stays strictly positive all the way to the requested edge `α=2`.

# 7. Lossy two-state rate-distortion theorem

The exact sampled pair can have infinite mutual information because it may be a deterministic continuous function of `W`. The useful object is therefore a lossy representation.

Let `(\hat U,\hat V)` be any possibly randomized representation of `(U,V)` such that, on `E`,

- `\hat U,\hat V` are nonnegative unit vectors;
- `||W|| <= L_0`;
- `E[ ||U-\hat U|| + ||V-\hat V|| | E ] <= δ`;
- `||\hat V||_1/sqrt(N) <= b_0` almost surely.

For every realization on `E`,

`| V^T F_W(U) - \hat V^T F_W(\hat U) |`

` <= ||V-\hat V|| ||F_W(U)||`

`    + ||F_W(U)-F_W(\hat U)||`

` <= ||W|| [ ||V-\hat V|| + ||U-\hat U|| ]`.

Taking conditional expectations and using Section 5,

`E[ \hat V^T F_W(\hat U) | E ]`

` >= a_(η,r_0) - L_0 δ`.

Now decouple only the represented pair:

`\hat Q = P_W tensor P_(\hat U,\hat V | E)`.

Again,

`D(P_(W,\hat U,\hat V | E) || \hat Q)`

` = log(1/P(E)) + I(W;\hat U,\hat V | E)`.

Applying the fixed-pair MGF conditionally under `\hat Q` and optimizing exactly as above gives

**(7.1)**

`log(1/P(E)) + I(W;\hat U,\hat V | E)`

` >= N [ a_(η,r_0) - L_0 δ - μ_α b_0 ]_+^2 /(2α)`.

## `P16-LOSSY-TWOSTATE-INFO-47 — PROVED`

Equation `(7.1)` is the claim.

This is stronger structurally than the previous full-path lossy theorem: it requires low information and low distortion only for **one randomized transition pair**, not for the entire recurrent word.

### Edge distortion target

Use the source-certified crude event `||W||<=8 sqrt(α)`, so `L_0=8 sqrt(α)`. In the near-neutral limit and with `b_0=1`, the exponent remains positive whenever

`δ < [1-sqrt(α/(2π))]/[8 sqrt(α)]`.

At `α=2`,

`δ < (1-1/sqrt(pi))/(8 sqrt(2))`

`  = 0.03852056259813935...`.

Here `δ` is the **sum** of source and target Euclidean distortions. If each vector is approximated within the same radius `ε`, then `δ<=2ε`, reproducing the earlier per-vector scale `ε<0.01926028...`.

### Finite codebook corollary

If the represented pair lies in a `W`-independent codebook of size `M_N`, then

`I(W;\hat U,\hat V | E) <= log M_N`.

Hence `(7.1)` gives

`P(E) <= M_N exp[-N c]`,

with

`c = [a_(η,r_0)-L_0δ-μ_α b_0]_+^2/(2α)`.

At the edge and zero error, the codebook rate must be below about `0.04748` nats per coordinate in the worst support case. This is an explicit quantitative compression target.

# 8. Dead neurons improve, rather than obstruct, the sampled-transition rate

Suppose every possible sampled cyclic target has at most `σN` active coordinates. Then

`b_0 <= sqrt(σ)`.

The adaptive theorem becomes

`log(1/P(E))+I(W;U,V|E)`

` >= N [a_(η,r_0)-sqrt(α σ/(2π))]_+^2/(2α)`.

The lossy theorem has the same replacement when the represented target also obeys the support bound.

## `P16-DEADNEURON-SUPPORT-RATE-47 — PROVED`

This is the claim.

At `α=2`, near-neutral zero-error rate:

- no support information, `σ=1`: `0.047482679772069526...`;
- half support, `σ=1/2`: `0.0903175955722575...`.

Thus dead neurons are not a hidden escape in this certificate. Sparser target phases make a fresh fixed pair **less** aligned on average and therefore increase the information debt needed for a matrix-adaptive high-alignment transition.

This does not mean sparse adaptive recurrence is globally impossible; the selector may still encode enough information about `W` to pay the larger debt.

# 9. Full balanced weighted-path concentration

The one-transition theorem discards useful path geometry. For completeness, the balancing weights also give a sharper full-path fixed-query bound.

For deterministic nonnegative unit cyclic phases `u_0,...,u_(k-1)` with `u_k=u_0` and a deterministic probability vector `λ`, define

`A_λ(W) = sum_t λ_t u_(t+1)^T ReLU(Wu_t)`.

Let

`K_st = <u_s,u_t>`

and

`Γ_λ = sum_(s,t) λ_s λ_t K_st K_(s+1,t+1)`

with cyclic indices.

The exact mean is

`E A_λ = μ_α sum_t λ_t ||u_(t+1)||_1/sqrt(N) <= μ_α`.

For `W=sqrt(α/N)G`, the row-`i` gradient is, almost everywhere,

`sqrt(α/N) sum_t λ_t u_(t+1,i) 1_{g_i^T u_t>0} u_t`.

All coordinates, weights, and Gram entries are nonnegative. Summing squared row gradients therefore gives the deterministic bound

`Lip(A_λ)^2 <= (α/N) Γ_λ`.

Consequently

`P{ A_λ >= a }`

` <= exp[ -N (a-EA_λ)_+^2 / (2α Γ_λ) ]`.

Now define the weighted phase resultant

`m_λ = sum_t λ_t u_t`, `s_λ=||m_λ||`.

Since `0<=K_(s+1,t+1)<=1`,

`Γ_λ <= sum_(s,t) λ_sλ_t K_st = ||m_λ||^2 = s_λ^2`.

Similarly, because `K_st<=1`,

`Γ_λ <= || sum_t λ_t u_(t+1) ||^2`.

Therefore

`Γ_λ <= min{ ||sum_t λ_t u_t||^2, ||sum_t λ_t u_(t+1)||^2 }`.

## `P16-BALANCED-WEIGHT-GRAM-47 — PROVED`

The claim is the fixed-query concentration theorem and the resultant bound above.

For the balancing weights from Section 5, an exact projective cycle has `A_λ(W)=κ`. A dispersed balanced path with small resultant has a **larger**, not smaller, Gaussian rate. Severe gain imbalance no longer destroys the certificate at the functional level; it is absorbed into `λ`.

Sanity check: for two orthogonal equal-weight phases, `Γ_λ=1/2`. At `α=2`, `κ=1`, and worst target density, the fixed-query coefficient is twice the one-transition base rate:

`2 c_edge = 0.09496535954413905...`.

This is precisely the geometry that made cancellation magnitude typical in the preceding run. Joint gain alignment is nevertheless exponentially costly for a fixed path.

### Independent derivation

Let `C_1,...,C_m in R^N` be the independent columns, and fix unit `x`. Put `S=<C_1,x>`.

Centering and variance one give `E S^2=1`. Independence gives the exact fourth moment

`E S^4 = 3 + (E ξ^4-3) sum_i x_i^4 <= B_* := max(B,3)`.

Paley--Zygmund on `S^2` at half its mean gives

`P{|S|>=1/sqrt(2)} >= 1/(4B_*) =: q_B`.

Take the soft slab cutoff `φ` equal to one on `|t|<=1/(2sqrt(2))`, zero on `|t|>=1/sqrt(2)`, linear between. Then `0<=φ<=1`, `Lip(φ)=2sqrt(2)`, and uniformly in unit `x`,

`E φ(<C_1,x>) <= 1-q_B`.

For the compressible class `Comp_N(α_0,η_0)`, let

`F = sup_x [ m^(-1) sum_j φ(<C_j,x>) - Eφ(<C_1,x>) ]`.

Symmetrization and contraction reduce `EF` to a constant times

`E sup_(x in Comp) |<H,x>|`,

where `H=m^(-1) sum_j ε_j C_j`.

If `s=floor(α_0 N)`, then deterministically

`sup_(x in Comp) |<H,x>| <= max_(|J|<=s)||H_J||_2 + η_0||H||_2`.

For each coordinate,

`E H_i^4 = [m Eξ^4 + 3m(m-1)]/m^4 <= (B+3)/m^2`.

Also

`max_(|J|<=s)||H_J||_2 <= s^(1/4) (sum_i H_i^4)^(1/4)`.

Thus

`E max_(|J|<=s)||H_J||_2 <= (B+3)^(1/4) α_0^(1/4) sqrt(N/m)`,

and `E||H||_2<=sqrt(N/m)`.

With `N/m<=Γ_0`, write `R=sqrt(Γ_0)`. P13 chooses

`η_B = q_B/(128 sqrt(2) R)`,

`α_B^(1/4) = q_B/[128 sqrt(2) R (B+3)^(1/4)]`.

Using the safe symmetrization/contraction factor `4 Lip(φ)=8sqrt(2)`, the two width terms contribute together at most `q_B/8`; for large `m`, the residual `2/sqrt(m)` is at most `q_B/8`. Hence `EF<=q_B/4` exactly as claimed.

Changing one column changes `F` by at most `1/m`, so McDiarmid gives

`P{F-EF>q_B/4} <= exp[-q_B^2 m/8]`.

On the good event, every compressible vector has empirical soft-slab mass at most `1-q_B/2`. But if `A_(-j)^T x=0`, then `m-1` of the `m` inner products vanish, so the empirical soft-slab mass is at least `(m-1)/m`, which exceeds `1-q_B/2` for all `m>2/q_B`. Contradiction.

Every factor in the displayed safe constants and in the McDiarmid exponent checks. The claim genuinely needs centered iid variance-one entries, a **uniform** fourth-moment bound, independent columns, and a bounded macroscopic aspect ratio. It uses no density or operator-norm event.

# 11. Adversarial checks of the new P16 argument

## 11.1 Same matrix across time

No step replaces the tied matrix by fresh layers. The recurrence and balancing weights are formed from the actual trajectory of the same `W`. Fresh Gaussian concentration is used only under the deliberately decoupled law `Q`, and the cost of that decoupling is exactly

`log(1/P(E))+I(W;representation | E)`.

## 11.2 Exceptional directions

The selected near-cycle and sampled transition may depend arbitrarily on `W`. The theorem does not claim their query is fresh. Their adaptivity is the mutual-information term in `(6.1)` / `(7.1)`.

## 11.3 Gain imbalance

A route based on the unweighted arithmetic mean of gains can be distorted by one very large and many small gains. The balancing identity removes this exactly:

`λ_t g_t = κ λ_(t+1)`.

Hence the selected-transition expected alignment is governed by geometric mean gain, not arithmetic mean gain.

## 11.4 Dead neurons

Sparse target phases reduce the fixed-query mean from `μ_α` to at most `μ_α sqrt(σ)`. They strengthen the information lower bound. Dead neurons are therefore not an unpriced loophole in this theorem.

## 11.5 Finite-width errors

Sections 4--9 are finite-`N` Gaussian statements. There is no mean-field limit or hidden `o_N(1)` in the core inequalities. The only asymptotic language enters when discussing near-cycles with `η,r_0 ->0` or the high-probability norm event.

## 11.6 Measurable witness selection

The information identity is stated for a `W`-measurable event and a measurable selected finite witness. A full proof from the global maximal-Lyapunov bad event must either construct a canonical measurable finite witness from the existing compactness-closing argument or invoke an appropriate measurable-selection theorem with its hypotheses checked. This is a technical obligation, not silently assumed closure.

## 11.7 Exact continuous pair can have infinite information

`I(W;U,V|E)` can be infinite for an exact deterministic selector. Therefore `(6.1)` by itself does **not** upper-bound `P(E)`. The substantive remaining task is the lossy version `(7.1)`: construct `(\hat U,\hat V)` with sufficiently small distortion **and** conditional information rate.

## 11.8 Ambient Euclidean nets remain quantitatively hopeless

At the edge, total pair distortion must be below roughly `0.0385` under the crude norm certificate. A generic sphere net at that resolution has several nats per coordinate **per vector**, far above the available base debt `0.04748 N`. Thus the new reduction shortens the witness from a whole path to two vectors, but a naive ambient net still cannot close the theorem.

False. A full-path representation is sufficient but not necessary. The new theorem uses only one randomized source/target pair.

The true obstruction is now:

- sample a gain-balanced transition;
- construct a nonnegative unit pair representation with total distortion below the explicit threshold;
- prove that its conditional mutual information rate is below the corresponding fixed-pair Gaussian alignment rate.

The earlier cancellation theory remains potentially useful for constructing such a representation or forcing additional structure, but cancellation magnitude itself is not a rare event.
