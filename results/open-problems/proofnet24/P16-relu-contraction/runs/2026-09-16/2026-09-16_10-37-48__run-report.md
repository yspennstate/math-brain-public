# 6. `P16-CANCELLATION-L1-GAUSSIAN-46` — PROVED

Fix deterministic `Y=(y_t)`. It may depend on `N`, but for this fixed-query theorem it is independent of `W`.

Write `W = sqrt(alpha/N) G`, with iid standard Gaussian rows `g_i^T`.

Define the one-row standard-scale cancellation

`Ctilde_Y(g) = (1/2) [ sum_t |g^T y_t| - |g^T z| ]`.

Then

`C_W(Y)_i = sqrt(alpha/N) Ctilde_Y(g_i)`.

For standard Gaussian `g`,

`E |g^T y| = sqrt(2/pi) ||y||`.

Therefore

`E Ctilde_Y(g) = Delta(Y)/sqrt(2 pi)`.

Summing over rows gives the exact identity

**(6.1)**  `E ||C_W(Y)||_1 = sqrt(alpha N/(2 pi)) Delta(Y)`.

## 6.1 Lipschitz constant and lower tail

For two standard row vectors `g,g'`,

`|Ctilde_Y(g)-Ctilde_Y(g')|`

` <= (1/2) [ sum_t |(g-g')^T y_t| + |(g-g')^T z| ]`

` <= A(Y) ||g-g'||`,

because `||z|| <= A(Y)`.

Consequently `G -> ||C_W(Y)||_1` is `sqrt(alpha) A(Y)`-Lipschitz in Frobenius norm. Gaussian concentration gives, for every `s>=0`,

**(6.2)**  `P{ ||C||_1 <= E||C||_1 - s } <= exp[ -s^2/(2 alpha A^2) ]`.

Since `||C||_1 <= sqrt(N) ||C||_2`, put

`theta = Delta/A`,  `mu_alpha = sqrt(alpha/(2 pi))`.

For every `tau>=0`,

**(6.3)**

`P{ ||C_W(Y)||_2 / A <= tau }`

` <= exp{ - N [mu_alpha theta - tau]_+^2 / (2 alpha) }`.

This is a fixed-query high-probability theorem, not yet an adaptive-orbit theorem.

# 7. `P16-CANCELLATION-GRAM-RMS-46` — PROVED

The L1 identity only sees the triangle defect. The L2 cancellation relevant to the dynamic identity has an exact full-Gram law.

For correlated standard normals `(X,Y)` with correlation `rho`, define

`psi(rho) = E |X||Y|`.

The exact formula is

**(7.1)**  `psi(rho) = (2/pi) [ sqrt(1-rho^2) + rho arcsin(rho) ]`.

A short verification differentiates in `rho`: `psi'(rho)=(2/pi) arcsin(rho)` and uses `psi(0)=2/pi`.

Let

`a_t = ||y_t||`,

`rho_st = <y_s,y_t>/(a_s a_t)` when both norms are nonzero,

and, if `z!=0`,

`rho_tz = <y_t,z>/(a_t ||z||)`.

Terms with zero norm contribute zero.

Define

`Q(Y) = E_g [ Ctilde_Y(g)^2 ]`.

Expanding the square and applying (7.1) gives

**(7.2)**

`Q(Y) = (1/4) [`

`  sum_(s,t) a_s a_t psi(rho_st)`

`  + ||z||^2`

`  - 2 sum_t a_t ||z|| psi(rho_tz)`

`]`.

When `z=0`, the last sum is zero.

Because the fixed path sees iid rows,

**(7.3)**  `E ||C_W(Y)||_2^2 = alpha Q(Y)`.

## 7.1 Concentration and exact finite-width mean bracket

From the one-row Lipschitz estimate,

`||C_W(Y;G)-C_W(Y;G')||_2 <= sqrt(alpha/N) A ||G-G'||_F`.

Thus `||C_W(Y)||_2` is `sqrt(alpha/N) A`-Lipschitz, and

**(7.4)**

`P{ | ||C||_2 - E||C||_2 | >= s }`

` <= 2 exp[ - N s^2/(2 alpha A^2) ]`.

Gaussian Poincare gives

`Var(||C||_2) <= alpha A^2/N`.

Combining with (7.3),

**(7.5)**

`sqrt( alpha [ Q(Y)-A(Y)^2/N ]_+ )`

` <= E||C_W(Y)||_2 <= sqrt(alpha Q(Y))`.

The same-row temporal correlations are kept exactly in `Q(Y)`; there is no independent-time approximation.

# 8. `P16-CANCELLATION-Q-STABILITY-46` — PROVED

For two finite words `Y=(y_t)` and `V=(v_t)`, set

`D(Y,V) = sum_t ||y_t-v_t||`.

## 8.1 Observed cancellation

Coordinatewise triangle inequality gives

`|C_W(Y)_i-C_W(V)_i|`

` <= (1/2)[ sum_t |w_i^T(y_t-v_t)| + |w_i^T(z_Y-z_V)| ]`.

Using `z_Y-z_V=sum_t(y_t-v_t)` and taking the Euclidean norm over rows,

**(8.1)**  `||C_W(Y)-C_W(V)||_2 <= ||W||_op D(Y,V)`.

Also

**(8.2)**  `|A(Y)-A(V)| <= D(Y,V)`,

**(8.3)**  `||z_Y-z_V|| <= D(Y,V)`,

**(8.4)**  `|Delta(Y)-Delta(V)| <= 2 D(Y,V)`.

## 8.2 Reference Gaussian scale

`sqrt(Q(Y))` is the `L2(g)` norm of `Ctilde_Y(g)`. Reverse triangle in `L2` and the same one-row bound imply

**(8.5)**  `|sqrt(Q(Y))-sqrt(Q(V))| <= D(Y,V)`.

Thus a lossy representation controls both the observed cancellation and its path-dependent reference scale.

## 8.3 Universal path-geometry bracket

Jensen and the exact one-row mean give

**(8.6)**  `Q(Y) >= Delta(Y)^2/(2 pi)`.

For the upper bound, if `z!=0`, let `h=z/||z||` and define the aligned comparison word

`v_t = ||y_t|| h`.

It has zero cancellation for every matrix. Writing `y_t=a_t u_t`, weighted Cauchy-Schwarz gives

`D(Y,V)^2 <= A sum_t a_t ||u_t-h||^2 = 2 A Delta`.

If `z=0`, choose any unit `h`; the same bound with `Delta=A` remains valid. Apply (8.5):

**(8.7)**  `Delta^2/(2 pi) <= Q(Y) <= 2 A Delta`.

Apply (8.1) against the same aligned word:

**(8.8)**  `||C_W(Y)||_2 <= ||W||_op sqrt(2 A Delta)`.

This deterministic inequality will convert an observed cancellation requirement into phase dispersion.

# 9. `P16-LOSSY-CANCELLATION-KL-46` — PROVED

Let `E` be a `W`-measurable event with `p=P(E)>0`. On `E`, let `Y=Y(W)` be a fully adaptive finite word, globally normalized to

`A(Y)=1`.

Let `V` be a possibly randomized representation satisfying, on `E`,

`D(Y,V) <= delta`,  `||W||_op <= L0`.

Then `A(V)<=1+delta`.

Define the decoupled law

`Q0 = P_W tensor P_(V|E)`.

Since `E` is measurable from `W`, the KL chain rule is exact:

**(9.1)**  `D( P_(W,V|E) || Q0 ) = log(1/p) + I(W;V|E)`.

## 9.1 Anomalously small cancellation

Assume on `E`

`sqrt(Q(Y)) >= q0` and `||C_W(Y)||_2 <= r0`.

Put `qminus = max(q0-delta,0)`.

By (8.1) and (8.5), on `E`,

`sqrt(Q(V)) >= qminus`,

`||C_W(V)||_2 <= r0 + L0 delta`.

Under `Q0`, condition on fixed `V`. By the finite-width lower mean bound (7.5),

`E_W ||C_W(V)||_2 >= sqrt( alpha [ qminus^2 - (1+delta)^2/N ]_+ )`.

The fixed-query Gaussian lower tail then yields `Q0(B) <= exp(-N cminus_N)`, where

**(9.2)**

`cminus_N =`

` [ sqrt(alpha [qminus^2-(1+delta)^2/N]_+) - (r0+L0 delta) ]_+^2`

` / [ 2 alpha (1+delta)^2 ]`.

The event `B` has probability one under `P_(W,V|E)`, so data processing for KL gives

**(9.3)**  `log(1/P(E)) + I(W;V|E) >= N cminus_N`.

## 9.2 Anomalously large cancellation

Assume instead on `E`

`sqrt(Q(Y)) <= q1` and `||C_W(Y)||_2 >= r1`.

Then

`sqrt(Q(V)) <= q1+delta`,

`||C_W(V)||_2 >= r1-L0 delta`.

Under the decoupled fixed-query law,

`E_W ||C_W(V)||_2 <= sqrt(alpha) (q1+delta)`.

The upper Gaussian tail gives

**(9.4)**  `log(1/P(E)) + I(W;V|E) >= N cplus`,

where

**(9.5)**

`cplus = [ r1-L0 delta-sqrt(alpha)(q1+delta) ]_+^2`

`        / [ 2 alpha (1+delta)^2 ]`.

This resolves the former `P16-DYNAMIC-CANCELLATION-COST-46` obligation in its correct form: **cancellation anomalies relative to the path-specific Gaussian scale have an explicit information/probability cost**. Merely large cancellation need not be anomalous.

# 10. `P16-CANCELLATION-DISPERSION-46` and weighted rank — PROVED

Normalize an arbitrary nonzero word as

`y_t = A lambda_t u_t`,

where `lambda_t>=0`, `sum_t lambda_t=1`, `||u_t||=1`.

Let

`r = ||sum_t lambda_t u_t|| = ||z||/A`,

`theta = 1-r = Delta/A`.

Define the weighted projective variance

`V_lambda = sum_(s,t) lambda_s lambda_t ||u_s-u_t||^2`.

Then exactly

**(10.1)**  `V_lambda = 2(1-r^2)`.

Therefore

**(10.2)**  `theta = V_lambda/[2(1+r)] >= V_lambda/4`.

The deterministic bound (8.8) becomes

**(10.3)**  `||C_W(Y)||_2/A <= ||W||_op sqrt(2 theta)`.

For a balanced near-recurrent segment, the inherited cancellation normalization is

`chi_z = ||c||/||z||`.

If `chi_z >= gamma` and `||W||<=L`, then

`gamma(1-theta) <= L sqrt(2 theta)`.

Put `q=gamma/L`. Solving the quadratic gives the exact lower bound

**(10.4)**

`theta >= Theta(q) = q^2/[1+q^2+sqrt(1+2 q^2)]`

`                 = q^2/2 + O(q^4)`.

Below `alpha=1`, the inherited high-probability pseudoray gap is

`gamma_alpha = (1-sqrt(alpha)) / [2(1+8 sqrt(alpha))]`.

Using the standard event `||W||<=8 sqrt(alpha)` therefore forces a strictly positive weighted phase-dispersion floor on any sufficiently accurate near-neutral bad recurrence.

The constant is small. At `alpha=1/2`, the leading approximation to the forced `theta` is about `7.56e-6`, and it decreases rapidly as `alpha` approaches one. This is structure, not closure.

## 10.1 Weighted effective rank

Because all ReLU phases are nonnegative,

`0 <= K_st=<u_s,u_t> <= 1`.

Define

`r_eff,lambda = 1 / sum_(s,t) lambda_s lambda_t K_st^2`.

Since `K_st^2 <= K_st`,

`sum lambda_s lambda_t K_st^2 <= sum lambda_s lambda_t K_st = r^2`.

Hence

**(10.5)**  `r_eff,lambda >= 1/(1-theta)^2`.

This is a rigorous partial answer to the previous `P16-EFFECTIVE-RANK-FROM-SWITCHING-46` target, but the numeric improvement above one is far too small to trigger the strong path-alignment exponent needed near the edge.

# 11. `P16-NOGO-CANCELLATION-RAREEVENT-46` — DISPROVED route

Take two orthogonal nonnegative unit vectors `u,v` and the deterministic test word

`y_0=u/2`,  `y_1=v/2`.

Then

`A=1`,  `z=(u+v)/2`,  `||z||=1/sqrt(2)`.

In the exact Gram formula:

`psi(0)=2/pi`,

`psi(1/sqrt(2)) = (sqrt(2)/pi)(1+pi/4)`.

Substitution gives

**(11.1)**

`Q_2 = 1/8 - 1/(4 pi) = (pi-2)/(8 pi)`

`    = 0.04542252845405233...`.

Therefore, from (7.4)-(7.5),

**(11.2)**  `||C_W(Y)||_2 = sqrt(alpha Q_2) + o_P(1)`.

Numerically,

`sqrt(Q_2) = 0.2131256166068554...`,

`sqrt(Q_2/2) = 0.1507025687472717...`.

The inherited bad-orbit cancellation floor below one is only

`gamma_0.5 = 0.02199937146...`,

`gamma_0.7 = 0.01061575615...`,

`gamma_0.9 = 0.00298718801...`,

`gamma_0.99 = 0.00027972205...`.

Thus a perfectly ordinary dispersed fixed path has cancellation far above the level that a bad orbit is forced to maintain below one. The route

> bad orbit => nonzero cancellation => rare event

is invalid without further dynamic constraints.

This is a **proof-route falsification**, not a counterexample to the original contraction conjecture. The test word is not asserted to be a realized orbit.

The correct event to price is the joint event that a matrix-selected path simultaneously has:

1. near-neutral or positive radial/cyclic gain;
2. cancellation compatible with the same reused rows;
3. recurrent/return geometry;
4. a sufficiently low-information lossy representation.

`   * [ rho (kappa+2nu) theta^2 - omega(2kappa+2nu+rho) ]`.

It claims a beneficial finite mean ridge exists iff

`rho theta^2 > omega`,

with

`nu_star = omega(kappa+rho)/(rho theta^2-omega)`

and

`Gamma_star = kappa (rho theta^2-omega)^2`

`             / [ d (kappa+rho)^2 (kappa theta^2+omega) ]`.

## 12.2 Independent derivation

Set

`a = rho theta^2 - omega`,

`b = rho(kappa theta^2 + omega)`,

`x = kappa+nu >= kappa`.

The square bracket in the gain is exactly

`2 a x - b`.

Apart from the positive factor

`C = rho kappa/[d(kappa+rho)^2]`,

the objective is

`f(x) = (2 a x-b)/x^2 = 2a/x - b/x^2`.

If `a<=0`, then `2ax-b<0` for every finite `x`, so no finite mean ridge gives positive gain; as `nu->infinity`, the gain tends to zero.

If `a>0`,

`f'(x)=2(b-a x)/x^3`,

so the unique maximizer is `x_star=b/a`. It is feasible because

`x_star-kappa = [b-a kappa]/a = omega(kappa+rho)/a > 0`.

Thus

`nu_star = omega(kappa+rho)/a`,

which is P15's formula. At the maximizer,

`f(x_star)=a^2/b`.

Multiplying by `C` gives exactly

`Gamma_star = kappa a^2/[d(kappa+rho)^2(kappa theta^2+omega)]`.

# 18. Sharp obstruction after this run

The previous checkpoint left “substantial signed cancellation” as one possible bad-orbit escape. This run shows that description is too coarse.

For a fixed path, cancellation is governed by a deterministic path functional `Q(Y)`. If the path is dispersed, `Q(Y)` is positive and cancellation near `sqrt(alpha Q(Y))` is ordinary. The hard issue is that the trajectory geometry itself is selected by the same matrix.

The current obstruction is therefore:

> **self-selected typical cancellation:** a tied Gaussian matrix may in principle choose a recurrent high-growth path whose cancellation is not a tail event at all when conditioned only on the path geometry.

A successful proof must break that self-selection loop. Candidate mechanisms are:

- a joint large-deviation theorem for high cyclic alignment and the cancellation statistic for one fixed path;
- a low-rate/low-distortion representation theorem for an actual Lyapunov witness;
- a gain-balance theorem preventing the balancing weights from concentrating on too few phases, thereby forcing useful weighted effective rank.
