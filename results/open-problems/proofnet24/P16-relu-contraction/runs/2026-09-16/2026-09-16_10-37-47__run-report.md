# 0. Executive result

P16 remains **OPEN** for the original tied-weight Gaussian ReLU iteration

\[
W_{ij}\stackrel{\rm iid}{\sim}N(0,\alpha/N),\qquad
F_W(x)=\operatorname{ReLU}(Wx),\qquad
x_{t+1}=F_W(x_t),
\]

with the **same square matrix `W` reused forever**, zero bias, and coordinatewise ReLU, throughout

\[
\boxed{\tfrac12\le\alpha<2}.
\]

The strongest requested statement remains:

> for every fixed `alpha<2`, with probability tending to one as `N->infinity`, there exist random `C(W)<infinity` and `rho(W)<1` such that
> \[
> \|F_W^t(x)\|\le C(W)\rho(W)^t\|x\|
> \]
> for **every** input `x` and **every** `t>=0`.

Equivalently, the maximal radial Lyapunov exponent / uniform subadditive growth rate is negative. No counterexample to this strongest statement is found in this run.

The main advance is that the cancellation obstruction isolated in the preceding run can now be priced **exactly for a fixed path, and by KL for a lossy adaptive path**. The result also exposes a sharp failed route: **large ReLU cancellation is not generically rare**. For a sufficiently dispersed path it is the normal Gaussian scale. Thus the remaining proof cannot simply argue that the cancellation floor required by a bad orbit is exponentially expensive.

For deterministic vectors `Y=(y_0,...,y_{k-1})`, define

\[
A(Y)=\sum_t\|y_t\|,\qquad
z(Y)=\sum_t y_t,\qquad
\Delta(Y)=A(Y)-\|z(Y)\|\ge0.
\]

For row `w_i^T` of `W`, set `b_{it}=w_i^T y_t` and define the signed ReLU-cancellation vector

\[
C_W(Y)_i
:=\frac12\left(\sum_t|b_{it}|-\left|\sum_t b_{it}\right|\right)
=\min\left\{\sum_t(b_{it})_+,\sum_t(-b_{it})_+\right\}.
\tag{0.1}
\]

For a balanced realized segment from the previous run, `C_W(Y)` is exactly the inherited cancellation vector `c`.

This run proves:

1. **Exact L1 mean / lower tail.** For fixed `Y`,
   \[
   \boxed{
   E\|C_W(Y)\|_1
   =\sqrt{\frac{\alpha N}{2\pi}}\,\Delta(Y).

   \tag{0.2}
   \]
   Writing `theta=Delta/A` and `mu_alpha=sqrt(alpha/(2pi))`,
   \[
   \boxed{

   \le
   \exp\left[-\frac{N}{2\alpha}
   [\mu_\alpha\theta-\tau]_+^2\right].
   }
   \tag{0.3}
   \]

2. **Exact RMS geometry from the whole time-correlated Gram structure.** If `g~N(0,I_N)` and
   \[
   \widetilde C_Y(g)=\frac12\left(\sum_t|g^Ty_t|-|g^Tz|\right),
   \qquad Q(Y)=E\widetilde C_Y(g)^2,
   \]
   then
   \[
   \boxed{E\|C_W(Y)\|_2^2=\alpha Q(Y).}
   \tag{0.4}
   \]
   `Q(Y)` has an explicit closed Gram formula using
   \[
   \psi(\rho)=E|X||Y|
   =\frac2\pi\left(\sqrt{1-\rho^2}+\rho\arcsin\rho\right)
   \tag{0.5}
   \]
   for correlated standard normals. Moreover `||C_W(Y)||_2` is `sqrt(alpha/N) A(Y)`-Lipschitz in the underlying Gaussian matrix, so it concentrates exponentially around its mean, with

   \le E\|C_W(Y)\|_2

   \tag{0.6}
   \]

3. **Path geometry controls the Gaussian cancellation scale.** One has
   \[
   \boxed{
   \frac{\Delta(Y)^2}{2\pi}\le Q(Y)\le2A(Y)\Delta(Y).
   }
   \tag{0.7}
   \]
   If `y_t=lambda_t u_t`, `u_t` unit, `lambda_t>=0`, and `sum lambda_t=1`, then with
   \[
   \mathcal V_\lambda
   =\sum_{s,t}\lambda_s\lambda_t\|u_s-u_t\|^2

   the triangle defect obeys
   \[
   1-\|z\|=\frac{\mathcal V_\lambda}{2(1+\|z\|)}\ge\frac{\mathcal V_\lambda}{4}.

   \[
   D(Y,V)=\sum_t\|y_t-v_t\|,
   \]
   then deviations of the observed cancellation from the fixed-query scale `sqrt(alpha Q(V))` incur an exact information/probability debt. In particular, under the explicit hypotheses in Section 8,
   \[
   \boxed{
   \log\frac1{P(E)}+I(W;V\mid E)\ge N c_{\rm can},

# 5. `P16-CANCELLATION-L1-GAUSSIAN-46` — PROVED

Fix arbitrary deterministic vectors `Y=(y_t)_{t<k}`. They may depend on `N`; they are only required to be independent of the Gaussian matrix for this fixed-query statement.

Write

\[
W=\sqrt{\alpha/N}\,G,
\]

where the rows `g_i^T` of `G` are iid `N(0,I_N)`. Define

\[
\widetilde C_Y(g)
=\frac12\left(\sum_t|g^Ty_t|-|g^Tz|\right).
\]

Then

\[
C_W(Y)_i=\sqrt{\alpha/N}\,\widetilde C_Y(g_i).
\]

Since `E|g^Ty|=sqrt(2/pi)||y||`,

\[
E\widetilde C_Y(g)
=\frac1{\sqrt{2\pi}}\left(\sum_t\|y_t\|-\|z\|\right)
=\frac{\Delta(Y)}{\sqrt{2\pi}}.
\tag{5.1}
\]

Summing the `N` rows proves the exact identity

\[
\boxed{
E\|C_W(Y)\|_1
=\sqrt{\frac{\alpha N}{2\pi}}\,\Delta(Y).
}
\tag{5.2}
\]

## 5.1 Gaussian concentration

For two row vectors `g,g'`,

\[
|\widetilde C_Y(g)-\widetilde C_Y(g')|
\le\frac12\left(
\sum_t|(g-g')^Ty_t|+|(g-g')^Tz|
\right)
\le A(Y)\|g-g'\|.
\tag{5.3}
\]

Therefore, as a function of the whole standard Gaussian matrix `G`,

\[
G\longmapsto \|C_W(Y)\|_1
\]

is `sqrt(alpha) A(Y)`-Lipschitz in Frobenius norm: use `(5.3)` rowwise and Cauchy--Schwarz across the `N` rows.

Gaussian concentration yields, for every `s>=0`,

\[
P\left\{
\|C_W(Y)\|_1
\le E\|C_W(Y)\|_1-s
\right\}
\le
\exp\left[-\frac{s^2}{2\alpha A(Y)^2}\right].
\tag{5.4}
\]

Since `||C||_1<=sqrt(N)||C||_2`, if `A>0`, `theta=Delta/A`, and `tau>=0`, the event `||C||_2/A<=tau` implies `||C||_1<=sqrt(N)A tau`. Combining with `(5.2)` gives

\[
\boxed{
P\left\{
\frac{\|C_W(Y)\|_2}{A(Y)}\le\tau
\right\}
\le
\exp\left[
-\frac{N}{2\alpha}
\left(\sqrt{\frac\alpha{2\pi}}\,\theta-\tau\right)_+^2
\right].
}
\tag{5.5}
\]

In particular, zero or abnormally tiny cancellation is exponentially unlikely for a fixed path with a fixed positive triangle defect.

This theorem is **not** applied directly to a matrix-adaptive orbit. Section 8 performs the required decoupling/information payment.

# 6. `P16-CANCELLATION-GRAM-RMS-46` — PROVED

The L1 theorem sees only the triangle defect. The L2 norm used in the dynamic pseudoray identity has a sharper exact geometry.

For standard jointly Gaussian `(X,Y)` with unit variances and correlation `rho`, define

\[
\psi(\rho)=E|X||Y|.
\]

The standard bivariate Gaussian calculation gives

\[
\boxed{
\psi(\rho)
=\frac2\pi\left(
\sqrt{1-\rho^2}+\rho\arcsin\rho
\right).
}
\tag{6.1}
\]

One way to verify `(6.1)` is to differentiate the Gaussian expectation in `rho`: `psi'(rho)=(2/pi)arcsin(rho)`, use `psi(0)=2/pi`, and integrate.

Let

\[
a_t=\|y_t\|,
\qquad
\rho_{st}=\frac{\langle y_s,y_t\rangle}{a_sa_t}
\]

when both norms are nonzero. When `z!=0`, put

\[
\rho_{t,z}=\frac{\langle y_t,z\rangle}{a_t\|z\|}.
\]

Terms with a zero norm are interpreted as zero. Expanding

\[
\widetilde C_Y(g)^2
=\frac14\left[
\left(\sum_t|g^Ty_t|\right)^2
+(g^Tz)^2
-2\left(\sum_t|g^Ty_t|\right)|g^Tz|
\right]
\]

and applying `(6.1)` gives the exact Gram formula

\[
\boxed{
Q(Y):=E\widetilde C_Y(g)^2
=\frac14\left[
\sum_{s,t}a_sa_t\psi(\rho_{st})
+\|z\|^2
-2\sum_t a_t\|z\|\psi(\rho_{t,z})
\right].
}
\tag{6.2}
\]

If `z=0`, the last sum is zero.

Because rows are independent under a fixed path,

\[
\boxed{
E\|C_W(Y)\|_2^2
=N\frac\alpha N Q(Y)
=\alpha Q(Y).
}
\tag{6.3}
\]

## 6.1 Exponential concentration with the exact finite-width correction

From `(5.3)`, the vector-valued map satisfies

\[
\|C_W(Y;G)-C_W(Y;G')\|_2
\le\sqrt{\frac\alpha N}\,A(Y)\|G-G'\|_F.
\tag{6.4}
\]

Hence the scalar norm `||C_W(Y)||_2` is `sqrt(alpha/N) A(Y)`-Lipschitz. Gaussian concentration gives

\[
P\left\{
\left|\|C_W(Y)\|_2-E\|C_W(Y)\|_2\right|\ge s
\right\}
\le
2\exp\left[-\frac{Ns^2}{2\alpha A(Y)^2}\right].
\tag{6.5}
\]

Gaussian Poincare, or simply the variance consequence of the same Lipschitz constant, yields

\[
\operatorname{Var}(\|C_W(Y)\|_2)
\le\frac{\alpha A(Y)^2}{N}.
\]

Using `(6.3)`,

\[
\boxed{
\sqrt{\alpha\left(Q(Y)-\frac{A(Y)^2}{N}\right)_+}
\le E\|C_W(Y)\|_2
\le\sqrt{\alpha Q(Y)}.
}
\tag{6.6}
\]

Thus, for a deterministic path of fixed normalized geometry, the cancellation norm is exponentially concentrated at scale `sqrt(alpha Q(Y))`; time correlations are encoded exactly by `(6.2)` rather than discarded.

# 7. `P16-CANCELLATION-Q-STABILITY-46` and geometry bounds — PROVED

For two words `Y=(y_t)` and `V=(v_t)` define

\[
D(Y,V)=\sum_t\|y_t-v_t\|.
\tag{7.1}
\]

## 7.1 Deterministic observed-cancellation stability

Coordinatewise,

\[
|C_W(Y)_i-C_W(V)_i|
\le\frac12\left[
\sum_t|w_i^T(y_t-v_t)|
+|w_i^T(z_Y-z_V)|
\right].
\]

Taking the Euclidean norm over rows and using

\[
z_Y-z_V=\sum_t(y_t-v_t)
\]

gives

\[
\boxed{
\|C_W(Y)-C_W(V)\|_2
\le\|W\|_{\rm op}\,D(Y,V).
}
\tag{7.2}
\]

Also

\[
|A(Y)-A(V)|\le D(Y,V),
\qquad
\|z_Y-z_V\|\le D(Y,V),
\]

so

\[
\boxed{|\Delta(Y)-\Delta(V)|\le2D(Y,V).}
\tag{7.3}
\]

## 7.2 The path-dependent Gaussian scale is itself Lipschitz

Since `sqrt(Q(Y))` is the `L^2(g)` norm of `widetilde C_Y(g)`, reverse triangle plus `(5.3)` gives

\[
|\sqrt{Q(Y)}-\sqrt{Q(V)}|
\le
\|\widetilde C_Y-\widetilde C_V\|_{L^2(g)}
\le
\sum_t\|y_t-v_t\|.
\]

Therefore

\[
\boxed{
|\sqrt{Q(Y)}-\sqrt{Q(V)}|
\le D(Y,V).
}
\tag{7.4}
\]

This is the precise stability needed for lossy path representations: both the observed cancellation and its fixed-query reference scale transfer continuously.

## 7.3 Universal bracket in terms of triangle defect

Jensen applied to `(5.1)` gives

\[
Q(Y)
\ge(E\widetilde C_Y)^2
=\frac{\Delta(Y)^2}{2\pi}.
\tag{7.5}
\]

For the upper bound, if `z!=0` let `h=z/||z||` and define an aligned comparison word

\[
v_t=\|y_t\|h.
\]

Then `C_W(V)=0` for every `W`, hence `Q(V)=0`. Writing `y_t=a_tu_t`, weighted Cauchy--Schwarz gives

\[
D(Y,V)^2
\le A\sum_t a_t\|u_t-h\|^2
=2A(A-\|z\|)
=2A\Delta.
\]

If `z=0`, choose any unit `h`; the same bound holds with `Delta=A`. Apply `(7.4)` to get

\[
\boxed{
\frac{\Delta(Y)^2}{2\pi}
\le Q(Y)
\le2A(Y)\Delta(Y).
}
\tag{7.6}
\]

The same comparison plus `(7.2)` gives the deterministic bound

\[
\boxed{
\|C_W(Y)\|_2
\le\|W\|_{\rm op}\sqrt{2A(Y)\Delta(Y)}.
}
\tag{7.7}
\]

This bound is useful below because it turns an observed cancellation requirement into a phase-dispersion requirement without any probabilistic independence.

# 17. Strongest obstruction after this run

The preceding report identified “substantial signed ReLU cancellation or low-effective-rank/high-information recurrence.” This run resolves one ambiguity: substantial cancellation is **not automatically a rarity certificate**.

For a fixed path, the exact quantity controlling cancellation is `Q(Y)`, a nonlinear functional of the whole time Gram matrix. If the path is dispersed, `Q(Y)` is positive and cancellation of size `sqrt(alpha Q(Y))` is typical. The dynamic problem is hard because the path itself is chosen from `W`.

Thus the sharp current obstruction is:

\[
\boxed{
\begin{array}{c}
\text{a matrix-adaptive recurrent path can potentially arrange high radial gain while}\
\text{its signed cancellation remains entirely typical for the geometry that the same matrix selected.}
\end{array}
}
\]

The proof must break this self-selection loop. Three possible mechanisms remain:

- **joint large deviations:** show that high cyclic alignment and typical/required cancellation cannot coexist cheaply for one fixed path, then decouple a lossy representation;
- **rate-distortion:** show any high-growth recurrent witness admits a representation whose information rate is below the joint fixed-query exponent;
- **gain-balance geometry:** prove that long high-growth near-recurrences cannot concentrate their balancing weights on too few phases, forcing enough weighted effective rank to make the inherited path-alignment exponent dominate.

This is more precise than the earlier blanket “aperiodic switching” obstruction.
