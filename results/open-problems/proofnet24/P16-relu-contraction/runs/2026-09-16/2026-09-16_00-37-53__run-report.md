# 0. Executive result

P16 remains **OPEN** for the original tied-weight model on

`1/2 ≤ α < 2`.

The model is exactly

`W_ij iid~ N(0, α/N),     F_W(x) = ReLU(Wx),     x_(t+1) = F_W(x_t),`

with **the same matrix W reused forever**.

The strongest target is: for each fixed `α < 2`, with probability tending to one as width `N` tends to infinity, there are random constants `C(W) < ∞` and `ρ(W) < 1` such that

`||F_W^t(x)|| ≤ C(W) ρ(W)^t ||x||`

for **every** input `x` and every `t ≥ 0`. Equivalently, the maximal radial Lyapunov exponent is negative. Writing `W = sqrt(α) A`, positive homogeneity gives

`λ_max(W) = λ_max(A) + (1/2) log α`,

so the edge form is

`P{ λ_max(A_N) < -(1/2) log 2 + ε } -> 1` for every `ε > 0`.

The main advance is an exact **mask-plus-energy information theorem** for arbitrary directions selected after observing the same Gaussian matrix. It strictly strengthens the previous energy-only mutual-information theorem and identifies the gate bias that minimizes the information cost of a noncontracting adaptive direction.

For an arbitrary measurable unit selector `U = U(W, ξ)`, with auxiliary randomness `ξ` independent of `W`, define

- radial gain `g_W(U) = ||ReLU(WU)||`;
- activation mask `M = (1_{w_i^T U > 0})_(i=1)^N`;
- mean active fraction `a = E|M|/N`;
- normalized mean ReLU energy `s = E g_W(U)^2 / α`.

## P16-MASK-ENERGY-KL-36 — PROVED

If `0 < a < 1` and `s ≥ a`, then

`I(W;U) ≥ N log 2 - H(M) + (N/2) [ s - a - a log(s/a) ].`      (0.1)

This is finite-width and allows fully `W`-dependent selectors. It never claims `WU` is Gaussian under the adaptive law. Gaussianity is used only under the comparison law in which `W` and `U` are independent, and the exact cost of that replacement is the KL term on the left.

Since `H(M) ≤ N h(a)`, where `h` is binary entropy in nats,

`I(W;U) ≥ N R(s,a)`,                                             (0.2)

where

`R(s,a) = D_Ber(a || 1/2) + (1/2)[ s - a - a log(s/a) ].`        (0.3)

The previous scalar energy-only rate `J_+(s)` is recovered exactly by minimizing over `a`:

`J_+(s) = min_(0<a<1) R(s,a),     s ≥ 1/2.`                      (0.4)

The unique minimizing gate fraction `q_*(s)` solves

`q_*^3 = s (1-q_*)^2.`                                           (0.5)

Thus the information-cheapest way to obtain unusually large ReLU energy is **not gate-neutral**.

Near the conjectural edge, write `α = 2 - Δ`. At the noncontracting energy level `s = 1/α`,

`q_*(1/(2-Δ)) = 1/2 + Δ/20 + 13 Δ^2/1000 + 213 Δ^3/50000 + O(Δ^4).`   (0.6)

So the KL-efficient adversarial direction uses a specific upward gate drift of order `(2-α)/20`.

If instead the gate is neutral, `a = 1/2`, then the exact rate is

`R(1/α,1/2) = 1/(2α) - 1/4 - (1/4) log(2/α).`                    (0.7)

At `α = 2 - Δ`,

`R(1/(2-Δ),1/2) = Δ^2/32 + Δ^3/48 + 3 Δ^4/256 + O(Δ^5).`        (0.8)

The preceding energy-only rate was

`J_+(1/(2-Δ)) = Δ^2/40 + 53 Δ^3/3000 + O(Δ^4).`

Therefore **gate neutrality improves the leading information exponent from `1/40` to `1/32`**.

More generally, if

`a = 1/2 + γ Δ + o(Δ)`,

then

`R(1/(2-Δ),a) = [ 1/40 + (5/2)(γ - 1/20)^2 ] Δ^2 + o(Δ^2).`      (0.9)

This is `P16-GATE-BIAS-RIGIDITY-36`: the `1/40` optimum is attained only at the specific drift `γ = 1/20`; forcing the gate closer to `1/2` incurs an explicit quadratic information penalty.

The quenched bad-event form is also proved. Let `E` be any `W`-measurable event with probability `p > 0`. Under `E`, let `U` satisfy

`E[ log g_W(U) | E ] ≥ ℓ`,

and let `V` be a unit-vector lossy representation. Put

`ε_E = ( E[ ||W(U-V)||^2 | E ] )^(1/2)`,

let `M_V` be the activation mask of `V`, and define

`s_V = E[g_W(V)^2 | E] / α`,

`a_V = E[|M_V| | E] / N`.

## P16-QUENCHED-MASK-ENERGY-36 — PROVED

Whenever `s_V ≥ a_V`,

`log(1/p) + I(W;V | E)`

`  ≥ N log 2 - H(M_V | E) + (N/2)[ s_V - a_V - a_V log(s_V/a_V) ].`   (0.10)

ReLU 1-Lipschitzness and Jensen give the energy transfer

`s_V ≥ s_0 := ( exp(ℓ) - ε_E )^2 / α.`                            (0.11)

If only a gate upper bound `a_V ≤ a_0` is known and `a_0 ≤ q_*(s_0)`, monotonicity gives

`log(1/p) + I(W;V | E) ≥ N R(s_0,a_0).`                          (0.12)

If `V` lies in a deterministic, `W`-independent codebook of size at most `M_code`, then

`p ≤ M_code exp[ -N R(s_0,a_0) ].`                               (0.13)

Near `α = 2 - Δ`, if

`ε_E = c Δ + o(Δ),     a_0 = 1/2 + γ Δ + o(Δ),`

then

`R(s_0,a_0)`

` = [ (1-4c)^2/40 + (5/2)( γ - (1-4c)/20 )^2 ] Δ^2 + o(Δ^2).`   (0.14)

Thus a lossy bad witness with output distortion `o(Δ)` and gate bias `o(Δ)` pays

`(1/32 + o(1)) N Δ^2`

in the event-probability-plus-description budget.

A second new theorem localizes where the adaptive advantage can occur. Order the rows and set

`H_i = (w_1,...,w_(i-1)),     I_i = I(w_i;U | H_i),`

`s_i = (N/α) E[(w_i^T U)_+^2],     a_i = P(w_i^T U > 0).`

## P16-ROWLOCAL-MASK-ENERGY-36 — PROVED

`I(W;U) ≥ sum_i R(s_i,a_i) ≥ N R( average_i s_i, average_i a_i ).`   (0.15)

If at most `β N` rows have `s_i > 1/2` and the average energy satisfies `average_i s_i ≥ 1/α`, then

`I(W;U) ≥ β N J_+( 1/2 + (1/α - 1/2)/β ).`                       (0.16)

For fixed `β in (0,1]` and `α = 2 - Δ`,

`I(W;U) ≥ (1/(40β) + o(1)) N Δ^2.`                               (0.17)

Hence an adaptive direction operating near the minimal `1/40` information budget cannot concentrate its favorable energy deviation on a fixed strict fraction of rows; the advantage must be diffuse.

Finally, output-space compression does not automatically preserve the mask. For normalized preactivations

`z_i(U) = sqrt(N/α) w_i^T U`,

one has, for every `t > 0`,

`d_H(M_W(U),M_W(V))/N`

` ≤ N^(-1) # { i : |z_i(U)| ≤ t } + ||W(U-V)||^2 / (α t^2).`     (0.18)

This is `P16-MASK-DISTORTION-MARGIN-36`. It identifies the exact missing input for mask-stable compression: a **dynamic anti-margin theorem**. A `W`-dependent direction may be chosen near or on many row hyperplanes, so the fresh-Gaussian small-margin law cannot be inserted without proof.

The strongest requested theorem is therefore neither proved nor falsified. The sharp obstruction is now more specific: a bad every-input orbit must sustain a same-matrix information advantage of order `N(2-α)^2`; near the information optimum it must also realize the particular gate drift `(2-α)/20` and spread its energy advantage across many rows. If one proves dynamic gate balance at `o(2-α)`, the minimum information debt rises to coefficient `1/32`.

The appearance of `1/32` also in the inherited sharp unrestricted-span rank threshold is recorded as a numerical/structural coincidence only; **no equivalence is claimed**.

# 5. Exact scalar joint transform

Let `Z ~ N(0,1)`, `X = (Z_+)^2`, and `B = 1_{Z>0}`. For `θ < 1/2` and real `η`,

`M(θ,η) = E exp(θ X + η B)`

`       = 1/2 + exp(η) / (2 sqrt(1-2θ)).`                       (5.1)

Define

`R(s,a) = sup_(θ<1/2, η real) { θ s + η a - log M(θ,η) }.`       (5.2)

For `s > 0` and `0 < a < 1`, the stationary equations give

`r = sqrt(s/a),`

`θ = (1 - a/s)/2,`

`η = log(a/(1-a)) - (1/2) log(s/a).`

Substitution yields exactly

`R(s,a) = a log(2a) + (1-a) log(2(1-a))`

`         + (1/2)[ s - a - a log(s/a) ].`                       (5.3)

The first term is the binary gate KL cost and the second is the positive-magnitude variance-tilt cost.

Differentiating in `a` gives

`∂R/∂a = log(a/(1-a)) - (1/2) log(s/a).`                         (5.4)

The unique minimizer satisfies `(0.5)`. With `r = q_*/(1-q_*)`, that equation becomes `r^3 = s(1+r)`, exactly the optimizer equation from the previous energy-only theorem. This independently verifies `(0.4)`.

# 6. Proof of P16-MASK-ENERGY-KL-36

Let `P = P_(W,U)` be the actual joint law and let `Q = P_W tensor P_U`. Then

`D(P || Q) = I(W;U).`                                            (6.1)

Under `Q`, condition on `U=u`. The normalized row preactivations

`Z_i = sqrt(N/α) w_i^T u`

are iid standard Gaussian. Therefore their sign mask is exactly uniform on `{0,1}^N`; conditional on that mask, the active squared magnitudes are iid chi-square with one degree of freedom; signs and magnitudes are independent.

Map `(W,U)` to the pair consisting of the mask `M` and the vector of squared positive normalized preactivations. KL data processing gives

`I(W;U) ≥ D(P_(M,X) || Q_(M,X)).`                                (6.2)

The chain rule splits the right side into

`D(P_M || Uniform) + E_M D(P_(X|M) || Q_(X|M)).`                 (6.3)

The mask term is exactly

`N log 2 - H(M).`                                                (6.4)

If a fixed mask has `k` active coordinates, then under the reference law

`E exp( θ sum_i X_i ) = (1-2θ)^(-k/2).`

The elementary entropy variational inequality, averaged over the actual mask, gives

`E_M D(P_(X|M) || Q_(X|M))`

` ≥ N [ θ s + (a/2) log(1-2θ) ].`                               (6.5)

When `s ≥ a`, optimize at `θ = (1-a/s)/2`. The value is

`(N/2)[ s - a - a log(s/a) ].`                                  (6.6)

Adding `(6.4)` proves `(0.1)`.

At no stage is the adaptive law of `WU` treated as Gaussian.

Entropy subadditivity and concavity give

`H(M) ≤ sum_i H(M_i) ≤ N h(a)`,

which proves the mean-gate corollary `(0.2)`.

# 10. Mask distortion and the dynamic-margin debt

If the masks of `U` and `V` differ at row `i`, then for every `t>0` either

`|z_i(U)| ≤ t`

or

`|z_i(U)-z_i(V)| > t`.

Counting sign disagreements and applying the elementary squared-Markov bound to the second alternative gives `(0.18)` exactly.

Conditionally on a bad event,

`E[d_H(M_U,M_V)/N | E]`

` ≤ μ_(U,E)(t) + ε_E^2/(α t^2)`,                              (10.1)

where `μ_(U,E)(t)` is the conditional expected fraction of normalized preactivations within distance `t` of zero.

For a deterministic direction independent of `W`, `μ(t)` is of order `t`. For an adaptive direction this cannot be assumed: the selector can align with row hyperplanes. Thus **dynamic anti-margin control is an exact missing hypothesis** for transferring gate/mask structure through output-space compression.

If a future compressed representative is guaranteed to remain in the same activation cell, the Hamming term is zero. But a same-matrix cell representative may itself contain arbitrarily large information about `W`, so same-cell geometry alone does not solve the compression problem.

# 11. New failed routes and counter-certificates

All earlier failed routes remain rejected. New sharpenings are:

**P16-NOGO-OUTPUTDIST-IMPLIES-MASKDIST-36.** Small `||W(U-V)||` does not by itself imply small mask Hamming distance; near-zero preactivations can flip under arbitrarily small perturbations. Equation `(0.18)` shows the missing term.

**P16-NOGO-PER-MATRIX-VISITED-MASK-COUNT-36.** A pathwise statement that each individual matrix visits at most `K` masks does not imply `H(M|E) ≤ log K` across the bad-matrix ensemble. The `K` labels may depend on `W`, and their union across matrices may cover the full hypercube. The mask entropy in `(0.10)` is ensemble entropy, not one-path cardinality.

**P16-NOGO-EXACT-ROWINFO-FROM-L2-36.** Exact selector mutual information cannot be universally upper-bounded by finite row-replacement `L^2` sensitivity. Take `N ≥ 2` and `U = w_1/||w_1||`. The direction `U` is a nonatomic deterministic function of `W`, so the joint law is singular relative to `P_W tensor P_U` and `I(W;U)=∞`. Yet replacing rows `i>1` leaves `U` unchanged, and the row-1 replacement contribution is finite because `U` is unit and `E||w_1||^2=α`. Therefore the row-ghost debt can bridge to information only after explicit lossy/randomized compression.

**P16-NOGO-GATE-RATE-ALONE-36.** The stronger `1/32` rate is conditional on dynamic gate balance. Applying it directly to a worst-input selector would repeat the exact quantifier error highlighted by the original source.
