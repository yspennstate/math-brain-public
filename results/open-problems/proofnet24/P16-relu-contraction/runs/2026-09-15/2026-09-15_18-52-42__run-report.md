# 5. Exact ReLU dual representation

Let G be an `N x r` matrix with iid standard Gaussian entries and define

`M(G) = sup_(||a||=1) ||ReLU(Ga)||`.

Let

`S_+ = { y in R^N : y >= 0, ||y||=1 }`

and add one zero index:

`Yset = S_+ union {0}`.

For every v in R^N,

`||v_+|| = max( 0, sup_(y in S_+) y^T v )`.

Therefore:

## `P16-RELU-DUAL-GAUSSIAN-30` — NEW / PROVED

`M(G) = sup_(a in S^(r-1), y in Yset) y^T G a`.

### Proof

If `(Ga)_+` is nonzero, choose

`y = (Ga)_+ / ||(Ga)_+||`.

Then `y^T G a = ||(Ga)_+||`.

If `(Ga)_+=0`, the zero index gives value zero. Conversely, for every nonzero y in S_+,

`y^T G a <= y^T (Ga)_+ <= ||(Ga)_+||`.

Taking suprema proves the identity.

The zero index is essential. If Ga is strictly negative coordinatewise, the ReLU norm is zero but the supremum over the positive unit sphere alone would be negative.

# 6. Gaussian comparison: removing the net entropy

Define the centered Gaussian process

`X_(a,y) = y^T G a`

on `S^(r-1) x Yset`.

Let g in R^r and h in R^N be independent standard Gaussian vectors. Define

`Y_(a,y) = g^T a + h^T y` for nonzero y,

and `Y_(a,0)=0`.

For nonzero y,y', put

`A = <a,a'>`,  `C = <y,y'>`.

Then

`E (X_(a,y)-X_(a',y'))^2 = 2 - 2 A C`,

whereas

`E (Y_(a,y)-Y_(a',y'))^2 = 4 - 2 A - 2 C`.

Their difference is

`2 (1-A)(1-C) >= 0`.

If exactly one y-index is zero, the X-increment variance is 1 and the Y-increment variance is 2. If both are zero, both increments vanish.

The Sudakov-Fernique comparison principle therefore gives

`E M(G) <= E sup Y`.

For the comparison process,

`sup_a g^T a = ||g||`.

If h has at least one positive coordinate,

`sup_(y in S_+) h^T y = ||h_+||`.

If h is strictly negative coordinatewise, that supremum is negative, but the zero index truncates the total supremum at zero. In all cases,

`sup Y <= ||g|| + ||h_+||`.

By Jensen,

`E ||g|| <= sqrt(r)`

and

`E ||h_+|| <= sqrt(N/2)`.

Therefore:

## `P16-GAUSSIAN-WIDTH-MEAN-30` — NEW / PROVED

`E M(G) <= sqrt(r) + sqrt(N/2)`.

This is the source of the improvement. The entire r-dimensional coefficient sphere costs Gaussian width `sqrt(r)`, not a covering entropy `r log(1/margin)`.

### Claim

Let X be centered, variance one, and discrete. If the collision probability

`kappa = P{X'=X''}`

satisfies `kappa > 1/2`, then

`E X^4 >= 2/(1-kappa) - 3`,

with equality for an appropriate centered standardized two-point law.

### Independent proof

Let p be the largest atom mass. First,

`kappa = sum_i p_i^2 <= p sum_i p_i = p`.

Thus `kappa>1/2` implies `p>1/2`. This one-line bound is the clean justification that the largest atom is heavy.

Let the heavy atom equal a, put `q=1-p` and `x=a^2`.

Conditional on `X != a`, let the second moment be m_2. Variance one gives

`m_2 = (1-px)/q`.

Centering gives conditional mean `-pa/q`. By Cauchy-Schwarz,

`m_2 >= p^2 x / q^2`,

so the feasible interval is

`0 <= x <= q/p`.

By Jensen on the conditional law,

`E[X^4 | X != a] >= m_2^2`.

Therefore

`E X^4 >= F_p(x) := p x^2 + (1-px)^2/q`.

Differentiate:

`F_p'(x) = 2p(x-1)/q`.

Since p>1/2, we have `q/p<1`, so F_p is decreasing over the entire feasible interval. Its minimum is at `x=q/p`, giving

`E X^4 >= q^2/p + p^2/q = 1/(pq) - 3`.

Next, the sum of squares of the remaining atom masses is at most their total mass squared, so

`kappa <= p^2 + q^2 = 1 - 2pq`.

Hence

`pq <= (1-kappa)/2`.

Combining the last two displays gives

`E X^4 >= 2/(1-kappa) - 3`.

For the centered standardized two-point law with masses p,q, every inequality above is equality and `kappa=p^2+q^2`.

Thus the source claim is correct and sharp.

No density, tail, or random-matrix theorem is hidden in this scalar lemma.

# 16. Stress tests

1. **Dead neuron / dead state.** If x_t=0, all later states vanish. Every rank statement remains valid.

2. **Exact ray or finite low-rank cycle.** For an ordinary start, if the entire orbit stays below the new rank threshold, the theorem contracts it forever. Such low-rank recurrence is not a surviving obstruction.

3. **Exit step.** The state creating the `(r+1)`st direction may lie outside the old span, but the input to that step lies inside it, so the exit-producing multiplier is charged. No off-by-one gap occurs.

4. **Adaptive q-frame.** The basis may depend arbitrarily on previously revealed Gaussian answers. Orthogonality and past-measurability are exactly the source innovation hypotheses.

5. **No-exit completion.** If the orbit never leaves a revealed span, its future is already determined by the revealed restriction; deterministic measurable orthogonal completion preserves freshness of unused Gaussian directions.

6. **Adversarial W-dependent start.** The theorem does not apply. This is the original worst-input gap emphasized by the source.

7. **High-rank orbit.** No claim is made after rank exceeds the selected r.

8. **Finite width.** All probability bounds in the new theorem are finite-N inequalities.

9. **Near alpha=2.** The certified rank fraction vanishes quadratically. No fixed positive rank fraction uniformly up to 2 is claimed.

10. **Dual zero index.** Including y=0 is mathematically necessary when Ga is coordinatewise negative.

11. **Full-space sanity check.** Taking r=N gives a weaker sufficient constant than the inherited positive-cone alpha<1/2 theorem, so there is no contradiction.
