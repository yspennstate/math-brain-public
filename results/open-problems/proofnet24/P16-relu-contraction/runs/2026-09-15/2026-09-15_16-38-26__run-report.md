# 5. Causal adaptive Gaussian frame

Let G be an N by N matrix with iid N(0,1) entries.

A **causal adaptive orthonormal frame** is a sequence q_1,...,q_d such that:

1. q_1 is deterministic or independent of G;
2. after revealing q_1,Gq_1,...,q_j,Gq_j, the next q_(j+1) is measurable from that revealed history;
3. q_(j+1) has unit norm and is orthogonal to span(q_1,...,q_j).

The exact source innovation lemma gives

`z_j := G q_j`, j = 1,...,d,

as iid standard Gaussian vectors in R^N.

Equivalently, `Z = [z_1|...|z_d]` is an ordinary N by d iid Gaussian matrix.

Let `Q = [q_1|...|q_d]` and `S_d = range(Q)`. For every coefficient vector a,

`G Q a = Z a`

and

`||Q a|| = ||a||`.

These are pathwise identities. In particular, a may be selected after observing the entire revealed matrix Z.

# 6. Exact positive-part variational representation

For a vector y in R^N, let y_+ denote its coordinatewise positive part, and let

`B_+^N = { u in R_+^N : ||u|| <= 1 }`.

Then

`||y_+|| = sup_(u in B_+^N) <u,y>`.

If y_+ is nonzero, choose u = y_+ / ||y_+||; if y_+ is zero, choose u = 0.

Therefore, for iid Gaussian Z,

`M_(N,d)(Z) := sup_(||a||=1) ||(Za)_+||`

has the exact Gaussian-process representation

`M_(N,d)(Z) = sup_(a in S^(d-1), u in B_+^N) u^T Z a`.

# 7. Gaussian comparison: expected adaptive-span ReLU norm

For an index pair (a,u), define

`X_(a,u) = u^T Z a`.

Let g ~ N(0,I_d) and h ~ N(0,I_N) be independent, and define

`Y_(a,u) = g^T a + h^T u`.

For two index points (a,u) and (b,v), set

`A = <a,b>` and `U = <u,v>`.

Then

`E (X_(a,u)-X_(b,v))^2 = ||u||^2 + ||v||^2 - 2 A U`,

while

`E (Y_(a,u)-Y_(b,v))^2 = 2 - 2A + ||u||^2 + ||v||^2 - 2U`.

Subtracting gives the exact increment gap

`2 (1-A)(1-U) >= 0`.

By the Sudakov-Fernique / Gordon Gaussian comparison theorem,

`E M_(N,d) <= E sup_(a,u) Y_(a,u)`.

The product index set separates, so

`sup_(a,u) Y_(a,u) = ||g|| + ||h_+||`.

By Jensen,

`E||g|| <= sqrt(d)`

and

`E||h_+|| <= sqrt(E||h_+||^2) = sqrt(N/2)`.

Therefore:

## `P16-ADAPTIVE-SPAN-RELU-MEAN-28` — NEW / PROVED

`E M_(N,d) <= sqrt(N/2) + sqrt(d)`.

The coefficient 1/sqrt(2) is the fresh ReLU energy scale. The cost of allowing every vector in a d-dimensional adaptive span is only sqrt(d/N) after normalization.
