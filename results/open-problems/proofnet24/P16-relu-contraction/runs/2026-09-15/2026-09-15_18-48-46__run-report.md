# 5. Exact dual representation for a Gaussian ReLU restriction

Let

\[
G\in\mathbb R^{N\times r}
\]

have iid \(N(0,1)\) entries and define

\[
M(G)
=
\sup_{\|a\|=1}
\|\operatorname{ReLU}(Ga)\|.
\]

Let

\[
S_+^{N-1}
=
\{y\in\mathbb R^N:y\ge0,\ \|y\|=1\}.
\]

Introduce one extra zero index and write

\[
\mathcal Y
=
S_+^{N-1}\cup\{0\}.
\]

For every \(v\in\mathbb R^N\),

\[
\|v_+\|
=
\max\left\{
0,
\sup_{y\in S_+^{N-1}}y^Tv
\right\}.
\]

Therefore:

## `P16-RELU-DUAL-GAUSSIAN-30` — NEW / PROVED

\[
\boxed{
M(G)
=
\sup_{\substack{a\in S^{r-1}\\y\in\mathcal Y}}
y^TGa.
}
\tag{5.1}
\]

### Proof

If \((Ga)_+\ne0\), choosing

\[
y=(Ga)_+/\|(Ga)_+\|
\]

attains

\[
y^TGa=\|(Ga)_+\|.
\]

If \((Ga)_+=0\), the zero index gives value zero. Conversely, for every nonzero \(y\in S_+^{N-1}\),

\[
y^TGa
\le
y^T(Ga)_+
\le
\|(Ga)_+\|.
\]

Taking suprema proves `(5.1)`.

QED.

This is the exact object on which Gaussian comparison acts.

# 6. Gaussian comparison: the logarithmic net entropy disappears

Define the centered Gaussian process

\[
X_{a,y}=y^TGa,
\qquad
(a,y)\in S^{r-1}\times\mathcal Y.
\]

Let

\[
g\sim N(0,I_r),
\qquad
h\sim N(0,I_N)
\]

be independent and define a comparison process by

\[
Y_{a,y}
=
\begin{cases}
 g^Ta+h^Ty,&y\ne0,\\
 0,&y=0.
\end{cases}
\tag{6.1}
\]

For nonzero \(y,y'\in S_+^{N-1}\), put

\[
A=\langle a,a'\rangle,
\qquad
C=\langle y,y'\rangle.
\]

Then

\[
E(X_{a,y}-X_{a',y'})^2
=2-2AC,
\]

whereas

\[
E(Y_{a,y}-Y_{a',y'})^2
=4-2A-2C.
\]

The difference is

\[
\boxed{
2(1-A)(1-C)\ge0.
}
\tag{6.2}
\]

If one of \(y,y'\) is the zero index, the corresponding increment variances are respectively \(1\) and \(2\), so the same comparison direction holds. If both are zero, both increments vanish.

Sudakov--Fernique comparison therefore gives

\[
EM(G)
=E\sup X
\le
E\sup Y.
\tag{6.3}
\]

For the comparison process,

\[
\sup_{a\in S^{r-1}}g^Ta=\|g\|.
\]

Also

\[
\max\left\{
0,
\sup_{y\in S_+^{N-1}}h^Ty
\right\}
=
\|h_+\|.
\]

Hence

\[
\sup Y
\le
\|g\|+\|h_+\|.
\]

By Jensen,

\[
E\|g\|
\le
\sqrt{E\|g\|^2}
=
\sqrt r,
\]

and

\[
E\|h_+\|
\le
\sqrt{E\|h_+\|^2}
=
\sqrt{N/2}.
\]

Therefore:

## `P16-GAUSSIAN-WIDTH-MEAN-30` — NEW / PROVED

\[
\boxed{
EM(G)
\le
\sqrt r+\sqrt{N/2}.
}
\tag{6.4}
\]

This is the key improvement over the preceding sphere-net argument. The domain complexity enters as a Gaussian width \(\sqrt r\), not as \(r\log(1/\hbox{margin})\).
