# 5. Spherical wedge representation of activation disagreement

Let `G` be an `N×r` iid standard Gaussian matrix with row vectors `g_1,...,g_N`.

For a nonzero coefficient vector `a`, define the binary activation mask

`m_G(a)_i = 1{ <g_i,a> > 0 }`.

For unit `a,b ∈ S^(r-1)`, define the spherical disagreement wedge

`R_(a,b) = { u ∈ S^(r-1) : 1{<u,a>>0} != 1{<u,b>>0} }`.

If `θ(a,b) ∈ [0,π]` is the spherical angle and `μ` is uniform measure on the sphere, rotational invariance gives the exact identity

`μ(R_(a,b)) = θ(a,b)/π`.

The normalized row directions `g_i/||g_i||` are iid uniform on `S^(r-1)` and their signs on `a` are exactly the signs of `<g_i,a>`.

Thus two coefficient directions have the same ReLU mask precisely when none of the sampled row directions lies in their disagreement wedge, up to the binary convention at boundary points. The wedge measure is unchanged by measure-zero boundaries.

# 6. VC dimension of the wedge range class

Let `H_r(m)` be the maximal number of homogeneous-halfspace sign traces on `m` points in `R^r`.

Cover's bound is

`H_r(m) ≤ 2 Σ_(j=0)^(r-1) C(m-1,j)`.

A wedge trace is the symmetric difference of two homogeneous-halfspace traces. Therefore the wedge shatter coefficient is at most

`H_r(m)^2`.

For `m=16r`, the standard binomial estimate gives

`H_r(16r)^2 ≤ 4 (16e)^(2r) < 2^(16r)`.

Hence the wedge range class has

`VCdim(wedges) < 16r`.

The numerical constant is not optimized; only linearity in `r` matters.

# 7. `P16-GAUSSIAN-MASK-CELL-DIAMETER-32` — PROVED

There is a universal constant `C_HW` such that for every `0<ε,η<1/2`, if

`N ≥ (C_HW/ε) [ r log(1/ε) + log(1/η) ]`,

then with probability at least `1-η`, every two unit directions `a,b` with the same Gaussian activation mask satisfy

`θ(a,b) < π ε`.

## Proof

By Section 6 the wedge class has VC dimension at most `16r`. The Haussler–Welzl ε-net theorem implies that, under the displayed sample-size condition after absorbing the factor 16 into `C_HW`, the iid row directions form an ε-net for the wedge range space with probability at least `1-η`.

If `m_G(a)=m_G(b)`, no sampled row direction lies in `R_(a,b)`. By the ε-net property this forces

`μ(R_(a,b))<ε`.

Using `μ(R_(a,b))=θ(a,b)/π` gives

`θ(a,b)<π ε`.

QED.

### Convenient asymptotic form

Put `δ=r/N`. For a sufficiently large universal `C_0`, one may choose

`ε = C_0 [ δ log(e/δ) + N^(-1) log(1/η) ]`

whenever the right side is below a fixed small constant. Therefore the maximum angular diameter of every activation cell obeys

`D_cell = O( δ log(e/δ) + N^(-1)log(1/η) )`

with probability at least `1-η`.

If `δ=c Δ^2` with `Δ→0` and `log(1/η)=o(NΔ)`, then

`D_cell = O( Δ^2 log(1/Δ) ) = o(Δ)`.

This is the key separation of scales used below.

# 8. `P16-MASK-CELL-WIDTH-32` and `P16-VISITED-MASK-WIDTH-32` — PROVED

Let `C⊂S^(r-1)` have Euclidean diameter at most `D`. Its Gaussian width is

`w(C)=E_h sup_(a∈C) <h,a>`,  with `h~N(0,I_r)`.

Choose any `a_0∈C`. Then

`sup_(a∈C) <h,a> ≤ <h,a_0> + D ||h||`.

Taking expectation and using `E<h,a_0>=0`, `E||h||≤√r`,

`w(C) ≤ D √r`.

Since Euclidean chord distance is at most spherical angle, on the event of Section 7 every activation cell satisfies

`boxed:  w(C) ≤ π ε √r`.

Now let a set `A` be contained in a union of `M` activation cells `C_1,...,C_M`, all of diameter at most `D`. Choose a representative `a_j∈C_j`. Then

`sup_(a∈A)<h,a> ≤ D||h|| + max_(1≤j≤M)<h,a_j>`.

Each `<h,a_j>` is centered Gaussian with variance one, so

`E max_j <h,a_j> ≤ √(2 log M)`.

Therefore

`boxed:  w(A) ≤ D√r + √(2 log M)`.

### Critical caveat

The activation cells themselves are functions of the same Gaussian matrix `G` whose ReLU gain one ultimately wants to bound. The displayed width bound is a genuine geometric certificate, but it cannot be inserted naively into a Sudakov–Fernique comparison for that **same** `G` as though the reachable set were independent.

This circularity is the surviving probabilistic dependence debt. The new theorem reduces that debt to visited-mask/cycle complexity; it does not erase it.

# 9. `P16-MASK-GAIN-RIGIDITY-32` — PROVED

Let `B` be any real `N×r` matrix. For unit vectors `a,b`, ReLU is 1-Lipschitz coordinatewise, hence

`||ReLU(Ba)-ReLU(Bb)|| ≤ ||B(a-b)|| ≤ ||B||_op ||a-b||`.

Therefore

`| ||ReLU(Ba)|| - ||ReLU(Bb)|| | ≤ ||B||_op ||a-b||`.

If `a,b` lie in one activation cell of angular diameter at most `D`, then

`boxed:  |gain_B(a)-gain_B(b)| ≤ ||B||_op D`,

where `gain_B(a)=||ReLU(Ba)||` for unit `a`.

The same estimate controls the full output-vector difference.

For an ordinary-start causal revealed span, inherited frame control gives `||B||_op=O(1)` on the near-edge rank scale `r/N=O(Δ^2)`. Combined with Section 7,

`gain variation inside one cell = O(Δ^2 log(1/Δ)) = o(Δ)`.

Thus:

## `P16-MASK-WIDE-CONTRACTION-32` — PROVED

If one direction in a cell has gain at most `1-κΔ` for fixed `κ>0`, then for sufficiently small `Δ` every direction in that cell has gain at most `1-(κ/2)Δ` on the joint cell-diameter/operator-norm event.

The analogous statement holds for a cell containing a direction with gain at least `1+κΔ`.

This is a deterministic consequence once the cell diameter and operator norm are certified.

# 10. Deterministic activation-mask graph

Fix a deterministic matrix `W`. Let `K` be a projectively invariant set of live unit states contained in a finite-dimensional subspace `S`:

`g(u)=||F_W(u)||>0`,

`T(u)=F_W(u)/g(u) ∈ K`.

Partition `K` by the binary activation mask

`m(u)=1{Wu>0}`.

There are finitely many nonempty mask cells. Construct a directed graph:

- vertices are masks occurring in `K`;
- an edge `p→q` exists if some `u∈K` with mask `p` has `T(u)` in mask `q`;
- edge weight

`ω(p,q)=sup{ log g(u) : u∈K, m(u)=p, m(T(u))=q }`.

All edge weights are finite above because `g(u)≤||W||`.

---

# 11. `P16-NONNEG-LYAP-TO-MASK-CYCLE-32` — PROVED

Assume every activation cell intersecting `K` has spherical diameter at most `D`.

If an infinite orbit `u_(t+1)=T(u_t)` in `K` satisfies

`limsup_(T→∞) (1/T) Σ_(t<T) log g(u_t) ≥ 0`,

then for every `ζ>0` there exist a directed mask cycle

`p_0→p_1→...→p_l=p_0`

and edge witnesses `v_0,...,v_(l-1)∈K` such that

1. `m(v_j)=p_j` and `m(T(v_j))=p_(j+1)`;
2. `(1/l) Σ_j log g(v_j) ≥ -ζ`;
3. `angle(T(v_j),v_(j+1)) ≤ D` for every `j` modulo `l`.

Equivalently,

`Π_j g(v_j) ≥ exp(-ζ l)`,

while the edge witnesses form a `D`-stitched approximate projective cycle.

## Proof

Follow the finite directed mask-edge path generated by the orbit. Actual log gain on each step is at most the corresponding edge weight. Hence the limsup average of edge weights along this path is nonnegative.

For a finite weighted directed graph, the limsup average weight of any infinite path is at most the maximum directed-cycle mean. One proof: if every directed cycle had mean at most `-γ<0`, delete cycles from any finite prefix; at most `M-1` residual edges remain when the graph has `M` vertices, while all deleted cycles contribute at most `-γ` times their lengths. Since edge weights are bounded above, the prefix average is at most `-γ+O(1/T)`, contradicting a nonnegative limsup.

Therefore some directed cycle has mean edge weight at least zero.

For each edge choose a witness whose log gain is within `ζ` of the edge supremum. This gives item 2.

For item 3, `T(v_j)` and `v_(j+1)` lie in the same activation cell `p_(j+1)`, so their angle is at most `D`.

QED.

### Interpretation

This is a genuine deterministic closing reduction. It does **not** claim the witnesses form one exact orbit. It says any nonnegative Lyapunov orbit forces a finite activation-cycle scaffold whose local mismatches are no larger than the cell diameter.

The remaining task is to show such a high-gain stitched scaffold is probabilistically impossible or dynamically self-correcting at the relevant length scale.

# 12. `P16-MASK-CYCLE-LENGTH-32` — PROVED

For a Gaussian `N×r` map in general position, the number of strict sign regions is exactly

`2 Σ_(j=0)^(r-1) C(N-1,j)`.

To include directions on hyperplane faces under the binary mask convention, an upper bound is obtained by choosing the set of exactly-zero rows first. If `k≤r-1` rows vanish, the remaining signs form a central arrangement in dimension at most `r-k`. Thus the number of binary face masks is bounded by

`M_face(N,r) ≤ Σ_(k=0)^(r-1) C(N,k) [ 2 Σ_(j=0)^(r-k-1) C(N-k-1,j) ]`.

Consequently, for `1≤r≤N/2`,

`log M_face(N,r) = O( r log(eN/r) )`.

The directed cycle in Section 11 may be chosen simple in mask space and hence has length

`l ≤ M_face(N,r)`.

The exponent is not claimed optimal; its order is the important quantity.

# 13. `P16-NEAREDGE-MASK-CYCLE-32` — PROVED / ordinary-start conditionalization

Now return to the original tied Gaussian model with a deterministic or `W`-independent start.

Use the inherited causal orbit frame. If the orbit span has final rank `r`, let `Q_r` be the causally discovered orthonormal basis and

`B_r = W Q_r`.

The exact Gaussian innovation theorem gives `B_r` the iid `N(0,α/N)` column law. After rescaling by `√(N/α)`, its rows are iid standard Gaussian in coefficient space.

Assume the near-edge regime

`α=2-Δ`,

`r/N = O(Δ^2)`.

On the high-probability mask-cell event,

`D_cell = O(Δ^2 log(1/Δ))`.

Therefore, if the tied orbit has nonnegative upper radial Lyapunov exponent, Section 11 produces a directed activation cycle with

- mean log gain at least `-ζ` for arbitrary `ζ>0`;
- projective stitching error at most `O(Δ^2 log(1/Δ))` on each edge;
- cycle length at most

`exp( O( N Δ^2 log(1/Δ) ) )`.

This is the sharpest current ordinary-start structural obstruction in the critical rank band.

It is much stronger than the statement “the orbit may be dynamically reachable.” A bad orbit must organize a near-noncontracting approximate cycle whose projective mismatch is smaller by a factor `Δ/log` than the natural `O(Δ)` radial contraction margin.

But the possible cycle can be exponentially long, so inherited fixed-period/ray exclusions do not yet close it.

# 14. `P16-MASK-ENTROPY-UNION-NOGO-32` — PROVED proof-strategy obstruction

In Gaussian general position the strict region count is

`M_strict(N,r)=2 Σ_(j=0)^(r-1) C(N-1,j)`.

If `r/N=δ→0` with `r→∞`, Stirling/binomial asymptotics give

`log M_strict(N,r) = Θ( N δ log(1/δ) )`.

At the near-edge critical rank scale `δ=cΔ^2`,

`log M_strict = Θ( N Δ^2 log(1/Δ) )`.

By contrast, the inherited exact one-ray/fresh-pair Cramér exponent for noncontraction satisfies

`I(1/α) = Δ^2/40 + O(Δ^3)`.

Thus a per-direction or per-mask bad-event bound of only

`exp(-c N Δ^2)`

cannot be union-bounded over all ambient activation masks: the ambient mask entropy carries an additional divergent factor `log(1/Δ)` in the exponent.

This does **not** prove a bad cycle exists. It proves the following route is insufficient near the edge:

> obtain a one-ray/fresh-pair `exp(-cNΔ^2)` estimate and union-bound it over every activation mask of the revealed span.

A successful high-rank proof must instead obtain at least one of:

- a dynamically visited mask family with entropy `o(NΔ^2)`;
- a coupled multi-edge/cycle large-deviation cost stronger than the one-ray cost;
- a deterministic telescoping/reset mechanism that avoids paying ambient mask entropy;
- a quenched invariant-measure argument that prices only realized recurrent structure.

This is the precise next dependence/entropy debt.

### Audited statement

For a fixed positive-semidefinite Gram matrix `K` and ridge `λ>0`, define

`H=K(K+nλI)^(-1)`,

`A=I-H=nλ(K+nλI)^(-1)`.

With training responses `Y` fixed, residual KRR around a training-row mean `M` has fitted values

`F(M)=M+H(Y-M)`.

P15 claims that perturbing the mean by any matrix `D`, even if `D` is same-response/data dependent, gives

`F(M+D)-F(M)=AD`,

hence a Frobenius contraction, with mode multiplier

`nλ/(κ_j+nλ)`.

It further claims this does not imply a fresh-input contraction, because at a query `u`

`ΔF(u)=D(u)-k(u,X)(K+nλI)^(-1)D(X)`.

### Independent derivation

Expand exactly:

`F(M)=M+HY-HM = HY+(I-H)M = HY+AM`.

Therefore

`F(M+D)-F(M)=AD`.

If `κ_j≥0` is a Gram eigenvalue, then the corresponding eigenvalue of `A` is

`a_j=nλ/(κ_j+nλ) ∈ (0,1]`.

Hence `||AD||_F≤||D||_F`, with exact attenuation `a_j` in each Gram eigendirection.

No probabilistic independence is used.

At a fresh point,

`F_M(u)=M(u)+k(u,X)(K+nλI)^(-1)(Y-M(X))`,

so subtraction gives exactly

`ΔF(u)=D(u)-k(u,X)(K+nλI)^(-1)D(X)`.

If `D(X)=0` but `D(u)≠0`, training fitted values are unchanged while the fresh prediction changes by the full `D(u)`. Thus the off-design caveat is necessary.

# 17. Stress tests

## Dead neurons / zero state

If `F_W(x)=0`, the trajectory is identically zero afterward and contraction is trivial. The projective mask graph is defined only on live states; death is an absorbing contractive exit, not an obstruction.

## Boundary preactivations

The activation mask is defined by strict positivity. Same binary mask means no sampled row lies in the corresponding open disagreement wedge. Wedge boundaries have spherical measure zero, and the face-count bound in Section 12 explicitly overcounts possible boundary masks. No general-position shortcut is needed for the deterministic graph itself.

## Exceptional directions

The mask-cell theorem is uniform over **all coefficient directions inside an iid Gaussian revealed span**, so exceptional directions inside that span are included. However, for the original every-input theorem, a `W`-dependent first direction may destroy the iid causal initialization; that remains open.

## Correlations across layers / tied reuse

No fresh-layer substitution is used in Sections 10–14. The mask graph is built from the one fixed matrix and the actual tied projective map. Gaussian iid structure enters only through the exact inherited causal-frame law for an ordinary start.

## Finite width

`P16-GAUSSIAN-MASK-CELL-DIAMETER-32` is a finite-`N` high-probability theorem with an explicit sample-size form. The near-edge statements are asymptotic corollaries.

## Activation-cell data dependence

The cell-width theorem is geometric but the cells depend on the same Gaussian matrix. Treating this random width as though it described a set independent of `G` would be circular. This is explicitly not done.

## Long cycles

The mask-cycle reduction can produce a cycle of length exponential in `r log(N/r)`. Fixed-period exclusions do not cover this automatically. This is now a named obstruction rather than hidden in “nonperiodic recurrence.”

# 23. Bottom line

The tied Gaussian ReLU contraction conjecture is not solved or falsified.

The preceding full-span theorem showed that whole-span contraction becomes impossible at rank fraction

`δ_span(α)=(1/√α-1/√2)^2 ~ (2-α)^2/32`.

This run proves that, on precisely that critical rank scale, the activation cells themselves are extremely small:

`diameter = O((2-α)^2 log(1/(2-α)))`.

Therefore a nonnegative-Lyapunov ordinary-start orbit cannot hide in a large activation cell. It must organize a **near-projective activation-mask cycle** with almost noncontracting geometric mean radial gain. The cycle may nevertheless be exponentially long, and the ambient number of masks has entropy larger by `log(1/(2-α))` than the available one-ray large-deviation exponent.

So the sharp surviving obstruction is now:

`dynamically reachable long-cycle entropy + same-matrix dependence`,

plus the separate `W`-dependent first-input quantifier for the uniform theorem.

That is the next theorem-sized object to control.
