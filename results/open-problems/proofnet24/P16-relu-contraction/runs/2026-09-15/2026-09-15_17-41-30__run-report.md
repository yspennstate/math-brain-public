# 5. Rectangular Gaussian ReLU contraction theorem

Let

\[
B\in\mathbb R^{N\times r},
\qquad
B_{ij}\stackrel{\rm iid}{\sim}N(0,\alpha/N).
\]

Fix

\[
0<\alpha<2
\]

and numbers

\[
\sqrt{\alpha/2}<q_0<q<1.
\]

Define the one-ray ReLU-square rate function

\[
\boxed{
I(s)
=
\sup_{0\le\lambda<1/2}
\left\{
\lambda s
-
\log\left[
\frac12\left(1+(1-2\lambda)^{-1/2}\right)
\right]
\right\},
\qquad s>1/2.
}
\tag{5.1}
\]

This is the inherited exact Cramér rate for

\[
Y=(Z_+)^2,
\qquad Z\sim N(0,1).
\]

For later use put

\[
L_\alpha=\frac{8\sqrt\alpha}{3},
\]

\[
\eta
=
\min\left\{
\frac12,
\frac{q-q_0}{L_\alpha}
\right\},
\]

\[
A_{\alpha,q_0,q}
=
\log\left(1+\frac2\eta\right),
\]

and

\[
\boxed{
c_\chi=\frac{3-\log4}{2}.}
\tag{5.2}
\]

## `P16-GAUSSIAN-SPAN-LC-29` — NEW / PROVED

\[
\boxed{
\begin{aligned}
P\left\{
\sup_{a\ne0}
\frac{\|\operatorname{ReLU}(Ba)\|}{\|a\|}>q
\right\}
\le{}&
\exp\left[
 rA_{\alpha,q_0,q}

\tag{5.3}
\]

For every deterministic unit \(a\in S^{r-1}\), the coordinates of \(Ba\) are iid

\[
N(0,\alpha/N).
\]

Thus

\[
\frac{\|\operatorname{ReLU}(Ba)\|^2}{\alpha}
=
\frac1N
\sum_{i=1}^N(Z_i^+)^2.
\]

Because

\[
q_0^2/\alpha>1/2,
\]

Chernoff gives

\[
\boxed{
P\{\|\operatorname{ReLU}(Ba)\|>q_0\}
\le
\exp[-NI(q_0^2/\alpha)].
}
\tag{5.4}
\]

### Proof — operator-norm auxiliary event

Let \(\mathcal N_{1/4}\) be a Euclidean \(1/4\)-net of \(S^{r-1}\) with

\[
|\mathcal N_{1/4}|\le9^r.
\]

For fixed unit \(a\),

\[
\|Ba\|^2
\stackrel d=
\frac\alpha N\chi_N^2.
\]

Using the exact chi-square mgf and optimizing at \(\lambda=3/8\),

\[
P\{\chi_N^2\ge4N\}
\le
\exp\left[-\frac{3-\log4}{2}N\right]
=e^{-c_\chi N}.
\]

Therefore, except with probability

\[
9^r e^{-c_\chi N},
\]

every point of \(\mathcal N_{1/4}\) has norm at most \(2\sqrt\alpha\). The usual net transfer gives

\[
\boxed{
\|B\|_{2\to2}\le\frac{2\sqrt\alpha}{1-1/4}

\tag{5.5}

No external random-matrix theorem is used.

\[
|\mathcal N_\eta|
\le

=
\exp[rA_{\alpha,q_0,q}].

\[
\exp[rA_{\alpha,q_0,q}-NI(q_0^2/\alpha)]

for the event

\[
\|\operatorname{ReLU}(Ba_0)\|\le q_0
\qquad\forall a_0\in\mathcal N_\eta.

On the simultaneous operator event `(5.5)`, for any unit \(a\) choose \(a_0\in\mathcal N_\eta\) with \(\|a-a_0\|\le\eta\). ReLU is 1-Lipschitz, so

Homogeneity gives the claim for all \(a\ne0\).

\[

\[
