# 4. Shifted Gaussian ReLU notation

Let \(\sigma(z)=z_+\). Consider

\[
A=\mu+X,\qquad B=\nu+Y,
\]

where \((X,Y)\) is centered jointly Gaussian with

\[
p=EX^2,\qquad q=EY^2,\qquad r=E[XY].
\]

Put

\[
d=\mu-\nu,\qquad v=p+q-2r.
\]

For \(s>0\), define

\[
H(m,s)=E|m+sZ|
=2s\phi(m/s)+m[2\Phi(m/s)-1],
\tag{4.1}
\]

\[
S(m,s)=E\operatorname{sgn}(m+sZ)=2\Phi(m/s)-1.
\tag{4.2}
\]

Set \(H(m,0)=|m|\); degenerate \(S\)-terms below are understood by continuous approximation and have zero covariance prefactor.

Since

\[
\sigma(z)=\tfrac12(z+|z|),
\]

\[
\sigma(A)-\sigma(B)=\tfrac12[(A-B)+(|A|-|B|)].
\tag{4.3}
\]

Also

\[
(A-B)^2-(|A|-|B|)^2
=4|AB|\mathbf1_{\{AB<0\}}.
\tag{4.4}
\]

Define

\[
\Gamma:=E[|AB|\mathbf1_{\{AB<0\}}]\ge0.
\tag{4.5}
\]

Then

\[
E(\sigma(A)-\sigma(B))^2
=\tfrac12E(A-B)^2-\Gamma
+\tfrac12E[(A-B)(|A|-|B|)].
\tag{4.6}
\]

# 5. Exact orientation term by Gaussian integration by parts

Let \(Z_0=X-Y\). Gaussian integration by parts for the Lipschitz function \(|\cdot|\), justified by smooth approximation, gives

\[
E[Z_0|A|]=(p-r)S(\mu,\sqrt p),
\tag{5.1}
\]

\[
E[Z_0|B|]=(r-q)S(\nu,\sqrt q).
\tag{5.2}
\]

Therefore

\[
\begin{aligned}
E[(A-B)(|A|-|B|)]
={}&d[H(\mu,\sqrt p)-H(\nu,\sqrt q)]\\
&+(p-r)S(\mu,\sqrt p)
+(q-r)S(\nu,\sqrt q).
\end{aligned}
\tag{5.3}
\]

Define the exact orientation debt

\[
\boxed{
\beta(\mu,\nu;p,q,r)
:=
(\mu-\nu)[H(\mu,\sqrt p)-H(\nu,\sqrt q)]
+(p-r)S(\mu,\sqrt p)
+(q-r)S(\nu,\sqrt q).
}
\tag{5.4}
\]

# 8. `P16-ADAPTIVE-SECANT-DEBIAS-23` — PROVED as an exact identity

Summing `(6.1)` over rows gives

\[
\boxed{
\begin{aligned}
E[\|F_W(x)-F_W(y)\|^2\mid\mathcal F]
={}&\tfrac12E[\|W(x-y)\|^2\mid\mathcal F]\\
&+\tfrac12\mathfrak B_{\rm orient}
-\mathfrak G_{\rm cross},
\end{aligned}
}
\tag{8.1}
\]

where

\[
\mathfrak B_{\rm orient}
=
\sum_{i=1}^N\beta(\mu_i,\nu_i;p,q,r),
\tag{8.2}
\]

\[
\mathfrak G_{\rm cross}
=
\sum_iE[|(Wx)_i(Wy)_i|\mathbf1_{\{(Wx)_i(Wy)_i<0\}}\mid\mathcal F]
\ge0,
\tag{8.3}

\[
\boxed{
E[\|W(x-y)\|^2\mid\mathcal F]
=
\|\mu-\nu\|^2+N(p+q-2r).
}
\tag{8.4}
\]

Define

\[
\mathfrak R_{\mathcal F}
:=
\frac{E[\|W(x-y)\|^2\mid\mathcal F]}{\alpha\|x-y\|^2}-1.

Then

\[
\boxed{
\frac{E[\|F_W(x)-F_W(y)\|^2\mid\mathcal F]}{\|x-y\|^2}
=
\frac\alpha2
+
\frac\alpha2\mathfrak R_{\mathcal F}

\frac{\mathfrak B_{\rm orient}}{2\|x-y\|^2}
-
\frac{\mathfrak G_{\rm cross}}{\|x-y\|^2}.
}
\tag{8.5}
\]

For a fresh pair, \(S=\{0\}\), \(\mu=\nu=0\), and both positive debts vanish, recovering the inherited sharp fresh-pair theorem.

# 10. `P16-COMMON-SHIFT-OBSTRUCTION-23` — PROVED

Let centered jointly Gaussian \((X,Y)\) satisfy

\[
EX^2=EY^2=\sigma^2>0,
\qquad E[XY]=r<\sigma^2,
\]

and put

\[
A_M=M+X,
\qquad B_M=M+Y.
\]

Then

\[
v=E(A_M-B_M)^2=2(\sigma^2-r),
\]

while `(5.4)` gives

\[
\beta_M=v[2\Phi(M/\sigma)-1].
\]

Therefore

\[
\boxed{
E(A_{M,+}-B_{M,+})^2
=
v\Phi(M/\sigma)-\Gamma_M,
}
\tag{10.1}
\]

where

\[
\Gamma_M=E[|A_MB_M|\mathbf1_{\{A_MB_M<0\}}].
\]

As \(M\to+\infty\), \(\Gamma_M\to0\) and

\[
\boxed{
\frac{E(A_{M,+}-B_{M,+})^2}{E(A_M-B_M)^2}\to1.

\tag{10.2}

- the centered difference covariance is fixed;
