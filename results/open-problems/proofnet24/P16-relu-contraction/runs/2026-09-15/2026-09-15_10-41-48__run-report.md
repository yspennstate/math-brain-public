Let \(\sigma(z)=z_+\). For \(a\ne b\) define

\[
m(a,b)=\frac{\sigma(a)-\sigma(b)}{a-b}.

\[
\boxed{0\le m(a,b)\le1.}

\[
\boxed{m(-a,-b)=1-m(a,b).}
\tag{5.2}

Thus

\[
\sigma(a)-\sigma(b)=m(a,b)(a-b).
\tag{5.3}

# 6. `P16-PAIR-SIGN-SYMMETRY-22` — NEW / PROVED

Fix any real matrix \(W\) and any \(x,y\). For each row let \(a_i=(Wx)_i\), \(b_i=(Wy)_i\), \(d_i=a_i-b_i\), and let \(m_i=m(a_i,b_i)\). Then

\[
(F_W(x)-F_W(y))_i=m_id_i,
\]

whereas

\[
(F_{-W}(x)-F_{-W}(y))_i=-(1-m_i)d_i.
\]

Therefore

\[
\boxed{
\begin{aligned}
&\|F_W(x)-F_W(y)\|^2+\|F_{-W}(x)-F_{-W}(y)\|^2\\
&=\sum_i[m_i^2+(1-m_i)^2]d_i^2\\
&\le\|W(x-y)\|^2.
\end{aligned}}
\tag{6.1}
\]

More explicitly,

\[
\boxed{
\begin{aligned}
&\|F_W(x)-F_W(y)\|^2+\|F_{-W}(x)-F_{-W}(y)\|^2\\
&=\|W(x-y)\|^2-2\sum_i|a_ib_i|\mathbf1_{\{a_ib_i<0\}}.
\end{aligned}}
\tag{6.2}
\]

The second term is a strict gate-crossing deficit.

# 8. `P16-FRESH-PAIR-MGF-22` — NEW / PROVED

Fix a \(W\)-independent pair \(x\ne y\) and one standard Gaussian row \(g\). Put

\[
a=g\cdot x,\qquad b=g\cdot y,\qquad d=\frac{a-b}{\|x-y\|}\sim N(0,1),
\]

and \(m=m(a,b)\). Define

\[
Y=\frac{(\sigma(a)-\sigma(b))^2}{\|x-y\|^2}=m^2d^2.
\tag{8.1}
\]

The centered Gaussian pair \((a,b)\) is invariant under \((a,b)\mapsto(-a,-b)\), which sends \(m\mapsto1-m\), \(d\mapsto-d\). Hence for \(0\le\theta<1/2\),

\[
Ee^{\theta Y}=\frac12E[e^{\theta m^2d^2}+e^{\theta(1-m)^2d^2}].
\]

For fixed \(A=\theta d^2\ge0\), the function \(e^{Am^2}+e^{A(1-m)^2}\) is convex on \([0,1]\), so its maximum is \(1+e^A\). Therefore

\[
\boxed{
Ee^{\theta Y}
\le M(\theta):=\frac12[1+(1-2\theta)^{-1/2}],
\qquad0\le\theta<1/2.
}
\tag{8.2}
\]

This is exactly the MGF of \(Y_0=(Z_+)^2\), \(Z\sim N(0,1)\). The bound is uniformly sharp: for the pair \((x,0)\), \(Y\stackrel d=Y_0\).

# 12. `P16-FRESH-PROJECTIVE-SECANT-22` — NEW / PROVED

for a standard Gaussian pair of correlation \(c\). Hence

\[
\frac{E\|F_W(u)-F_W(v)\|^2}{\|u-v\|^2}

# 13. `P16-FRESH-LAYER-DYNAMIC-22` — NEW / PROVED / RESTRICTED MODEL

\[
x_{t+1}=F_{W_t}(x_t),\qquad y_{t+1}=F_{W_t}(y_t),

\[
E[\|x_{t+1}-y_{t+1}\|^2\mid\mathcal F_t]
\le\frac\alpha2\|x_t-y_t\|^2.

\[
\boxed{

\tag{13.1}

P\{\|x_t-y_t\|\ge\rho^t\|x_0-y_0\|\}

\boxed{

# 17. `P16-TIED-SECANT-OBSTRUCTION-22` — NEW / PROVED

Let \(x\ne y\), \(h=(x-y)/\|x-y\|\), and write \(W=\sqrt{\alpha/N}G\) with standard-scale rows \(g_i\). Put

\[
d_i=g_i\cdot h
\]

and let \(m_i\in[0,1]\) be the ReLU secant slope between \(g_i\cdot x\) and \(g_i\cdot y\). Then

\[
\frac{\|F_W(x)-F_W(y)\|^2}{\|x-y\|^2}
=\frac\alpha N\sum_i m_i^2d_i^2.
\]

Using

\[
m_i^2=\frac12-m_i(1-m_i)+(m_i-\tfrac12),
\]

we get the exact decomposition

\[
\boxed{
\begin{aligned}
\frac{\|F_W(x)-F_W(y)\|^2}{\|x-y\|^2}
={}&\frac12\|Wh\|^2\\
&-\frac\alpha N\sum_i m_i(1-m_i)d_i^2\\
&+\frac\alpha N\sum_i(m_i-\tfrac12)d_i^2.
\end{aligned}}
\tag{17.1}
\]

The middle term is favorable/nonpositive. The last is the **activation-orientation bias**. For a fresh fixed pair, row/global sign symmetry changes \(m_i-1/2\) to its negative while preserving \(d_i^2\), so its expectation is zero. For a pair selected after seeing \(W\), that cancellation is unavailable.

The first term exposes the **Rayleigh-selection debt**: an adaptive pair can choose a difference direction \(h\) with abnormally large \(\|Wh\|\).

Thus the tied problem has two exact adaptive debts:

\[
\boxed{\text{Rayleigh-selection debt}}
\]

and

\[
\boxed{\text{activation-orientation debt}.}
\]

This is sharper than the generic phrase “correlation across layers.”

# 18. Why the fresh theorem cannot be iterated in the tied model

For deterministic initial \((x_0,y_0)\), the fresh theorem applies at the first tied step. But

\[
(x_1,y_1)=(F_W(x_0),F_W(y_0))
\]

is then a function of the same \(W\). The conditional law of \(W\) given the current pair is no longer an iid centered Gaussian law.

Therefore

\[
E[\|x_{t+1}-y_{t+1}\|^2\mid x_t,y_t]
\le\frac\alpha2\|x_t-y_t\|^2
\]

is valid with fresh independent \(W_t\) but is **not justified** under tied reuse.

The prior adaptive Gaussian-innovation theorem partially repairs this by decomposing each new tied query into

\[
\boxed{\text{recycled Gaussian mean}+\text{fresh Gaussian innovation}.}
\]

The next module must control the pair secant gain after conditioning on that recycled history.

R_0=E\|m(Y)-\mu\|^2,
\qquad
R_1=E\|m(Y)+c(Y)-\mu\|^2,
\]

P15 claims

\[
\boxed{
R_1-R_0
=E[\|c\|^2-2\langle Y-m,c\rangle+2\sigma^2\operatorname{div}c].
}
\tag{20.1}
\]

### Audit

Expanding,

\[
R_1-R_0=E[2\langle m-\mu,c\rangle+\|c\|^2].
\]

Since \(m-\mu=\varepsilon-(Y-m)\),

\[
R_1-R_0
=E[\|c\|^2-2\langle Y-m,c\rangle+2\langle\varepsilon,c(Y)\rangle].
\]

Under the source-stated Stein regularity,

\[
E\langle\varepsilon,c(Y)\rangle
=\sigma^2E\operatorname{div}c(Y).
\]

This proves `(20.1)` exactly. No derivative of \(m\) and no independence between \(m\) and \(c\) is required.

### Primary source verification

Charles Stein, *Estimation of the Mean of a Multivariate Normal Distribution*, Annals of Statistics 9 (1981), 1135--1151, DOI `10.1214/aos/1176345632`, is the classical primary source for unbiased Gaussian risk estimation.

Bellec and Zhang, *Second order Stein: SURE for SURE and other applications in high-dimensional inference*, arXiv:`1811.04121`, explicitly states the Gaussian Stein formula for functions with integrable gradient and develops SURE from it.

The imported identity and P15's stated regularity scope match these sources.
