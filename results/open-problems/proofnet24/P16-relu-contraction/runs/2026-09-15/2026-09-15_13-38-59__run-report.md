# 5. Gaussian innovation sign geometry

Let

\[
\Gamma_1,\ldots,\Gamma_N\stackrel{\rm iid}{\sim}N(0,I_d).
\]

For \(a\ne0\), define

\[
\widehat p_N(a)=\frac1N\sum_{i=1}^N\mathbf1_{\{a\cdot\Gamma_i>0\}}.

Let

\[
S_{N,d}=\sum_{j=0}^{d-1}\binom{N-1}{j}.
\tag{5.1}

The number of strict homogeneous sign patterns realized by hyperplanes through the origin on a Gaussian sample in general position is

\[
2S_{N,d}.
\tag{5.2}

Write each Gaussian point as

\[
\Gamma_i=\epsilon_iV_i,
\qquad
\epsilon_i\stackrel{\rm iid}{\sim}\operatorname{Rad}(\pm1),

with the unoriented line \(V_i\) independent of the orientation \(\epsilon_i\). Conditional on the lines, every fixed realizable base sign pattern multiplied by the random orientation vector is an iid Rademacher sign vector.

\boxed{

D_{\rm KL}

# 6. `P16-GROWINGDIM-GATE-KL-25` — NEW / PROVED

# 9. `P16-GATE-PHASE-25` — NEW / PROVED

Fix \(\alpha\in[1,2)\) and let

\[
\beta_\alpha=\frac1\alpha-\frac12>0.
\tag{9.1}
\]

Define the binary entropy

\[
H(\delta)=-\delta\log\delta-(1-\delta)\log(1-\delta).
\]

For \(0<\delta<\beta_\alpha\), the sign-pattern entropy at dimension ratio \(d/N\approx\delta\) is \(H(\delta)\), while forcing gate bias at least \(\beta_\alpha-\delta\) costs \(J(\beta_\alpha-\delta)\).

The function

\[
\delta\mapsto H(\delta)
\]

is strictly increasing on \((0,1/2)\), while

\[
\delta\mapsto J(\beta_\alpha-\delta)
\]

is strictly decreasing. At \(\delta=0\),

\[
H(0)=0<J(\beta_\alpha),
\]

while at \(\delta=\beta_\alpha\),

\[
H(\beta_\alpha)>0=J(0).
\]

Therefore there is a unique

\[
\boxed{
\delta_{\rm gate}(\alpha)\in(0,\beta_\alpha)
}
\]

satisfying

\[
\boxed{
H(\delta_{\rm gate})
=
J(\beta_\alpha-\delta_{\rm gate}).
}
\tag{9.2}
\]

\[
T_N\le(\delta_{\rm gate}(\alpha)-\epsilon)N.

# 12. `P16-GATE-CAPACITY-BARRIER-25` — NEW / PROVED

The uniform sign-balance theorem has an exact high-dimensional barrier.

For iid centrally symmetric points in general position in \(\mathbb R^d\), Wendel's theorem gives

\[
\boxed{
P\{\exists a:\ a\cdot\Gamma_i>0\ \forall i\}
=
2^{-N+1}
\sum_{j=0}^{d-1}\binom{N-1}{j}.
}
\tag{12.1}
\]

Equivalently,

\[
\boxed{
P\{\exists a:\ a\cdot\Gamma_i>0\ \forall i\}
=
P\{\operatorname{Bin}(N-1,1/2)\le d-1\}.
}
\tag{12.2}
\]

Therefore if

\[
\frac dN\to\delta,
\]

then:

- for \(\delta<1/2\), the probability tends to zero exponentially;
- for \(\delta>1/2\), the probability tends to one exponentially;
- \(\delta=1/2\) is the sharp ambient capacity threshold.

Hence once the Gaussian innovation span has dimension exceeding \(N/2\), there typically exists a coefficient vector with gate fraction one.

This **does not** prove that a tied ReLU trajectory can realize that coefficient vector. The actual orbit coefficients are generated recursively by the same ReLU/Gram dynamics.

Thus `(12.1)` is a proof-method / ambient-capacity obstruction:

\[
\boxed{
\text{uniform gate neutrality over all coefficient vectors cannot close long time past }d/N=1/2.
}
\tag{12.3}
\]

The future theorem must control the much smaller dynamically reachable subset.

Primary source checked: J. G. Wendel, *A Problem in Geometric Probability*, Math. Scand. 11 (1962), 109--111/112, DOI `10.7146/math.scand.a-10655`. The original paper states exactly the probability `(12.1)` under central-reflection symmetry and general position.
