\[

F_W(x)=\operatorname{ReLU}(Wx),\qquad
x_{t+1}=F_W(x_t),

with the **same random matrix \(W\) reused forever**.

\[
\boxed{
\forall\alpha<2,\quad
P\{\exists C(W)<\infty,\rho(W)<1:\ \|F_W^t(x)\|\le C(W)\rho(W)^t\|x\|\ \forall x,t\}\to1.
}
\tag{MAIN}
\]

It remains **OPEN** for

\[
\boxed{\tfrac12\le\alpha<2},
\]

including \(\alpha=1\).

\[
\boxed{
\text{uniform all-start exponential contraction}\iff\lambda_{\max}(W)<0.

\[
\lambda_{\max}(W_\alpha)=\lambda_{\max}(A)+\tfrac12\log\alpha.
\]

Therefore `(MAIN)` is exactly

\[
\boxed{
P\{\lambda_{\max}(A_N)<-\tfrac12\log2+\varepsilon\}\to1
\quad\forall\varepsilon>0.
}
\tag{1.1}
\]

This run proves an exact conditional Gaussian secant identity for arbitrary finite tied query histories and finds a sharp new obstruction: **a common positive recycled preactivation mean can erase the ReLU half-energy factor completely**.

# 4. Shifted Gaussian ReLU secant calculation

Let \(\sigma(z)=z_+\), and let

\[
A=\mu+X,\qquad B=\nu+Y,
\]

where \((X,Y)\) is centered jointly Gaussian with

\[
p=EX^2,\qquad q=EY^2,\qquad r=E[XY].
\]

Set

\[
d=\mu-\nu,\qquad v=p+q-2r.
\]

For \(s>0\), define

\[
H(m,s)=E|m+sZ|=2s\phi(m/s)+m[2\Phi(m/s)-1],
\tag{4.1}
\]

\[
S(m,s)=E\operatorname{sgn}(m+sZ)=2\Phi(m/s)-1.
\tag{4.2}
\]

Take \(H(m,0)=|m|\), with degenerate sign terms understood by continuous approximation.

The elementary identity

\[
\sigma(z)=\tfrac12(z+|z|)
\]

gives

\[
\sigma(A)-\sigma(B)=\tfrac12[(A-B)+(|A|-|B|)].
\]

Also

\[
(A-B)^2-(|A|-|B|)^2=4|AB|\mathbf1_{\{AB<0\}}.
\]

Let

\[
\Gamma=E[|AB|\mathbf1_{\{AB<0\}}]\ge0.
\]

Then

\[
E(\sigma(A)-\sigma(B))^2
=\tfrac12E(A-B)^2-\Gamma
+\tfrac12E[(A-B)(|A|-|B|)].
\tag{4.3}
\]

For \(Z_0=X-Y\), Gaussian integration by parts, justified for \(|\cdot|\) by smooth approximation, gives

\[
E[Z_0|A|]=(p-r)S(\mu,\sqrt p),
\]

\[
E[Z_0|B|]=(r-q)S(\nu,\sqrt q).
\]

Hence

\[
\boxed{
\begin{aligned}
\beta(\mu,\nu;p,q,r)
:={}&(\mu-\nu)[H(\mu,\sqrt p)-H(\nu,\sqrt q)]\\
&+(p-r)S(\mu,\sqrt p)+(q-r)S(\nu,\sqrt q).
\end{aligned}
}
\tag{4.4}
\]

# 7. `P16-ADAPTIVE-SECANT-DEBIAS-23` — PROVED as an exact identity

Summing `(5.1)` over rows yields

\[
\boxed{
\begin{aligned}
E[\|F_W(x)-F_W(y)\|^2\mid\mathcal F]
={}&\tfrac12E[\|W(x-y)\|^2\mid\mathcal F]\\
&+\tfrac12\mathfrak B_{\rm orient}-\mathfrak G_{\rm cross},
\end{aligned}
}
\tag{7.1}
\]

where

\[
\mathfrak B_{\rm orient}=\sum_{i=1}^N\beta(\mu_i,\nu_i;p,q,r),
\tag{7.2}
\]

\[
\mathfrak G_{\rm cross}
=\sum_iE[|(Wx)_i(Wy)_i|\mathbf1_{\{(Wx)_i(Wy)_i<0\}}\mid\mathcal F]\ge0,
\tag{7.3}
\]

and

\[
\boxed{
E[\|W(x-y)\|^2\mid\mathcal F]=\|\mu-\nu\|^2+N(p+q-2r).
}
\tag{7.4}
\]

Define the Rayleigh-selection debt

\[
\mathfrak R_{\mathcal F}
=\frac{E[\|W(x-y)\|^2\mid\mathcal F]}{\alpha\|x-y\|^2}-1.
\]

Then

\[
\boxed{
\frac{E[\|F_W(x)-F_W(y)\|^2\mid\mathcal F]}{\|x-y\|^2}
=
\frac\alpha2
+\frac\alpha2\mathfrak R_{\mathcal F}
+\frac{\mathfrak B_{\rm orient}}{2\|x-y\|^2}
-\frac{\mathfrak G_{\rm cross}}{\|x-y\|^2}.
}
\tag{7.5}
\]

For a fresh pair, \(S=\{0\}\) and \(\mu=\nu=0\), so both positive debts vanish and the inherited sharp \(\alpha/2\) theorem is recovered.

**Status:** the identity-level target is CLOSED/PROVED. Uniform subcritical debt control remains OPEN.

# 9. `P16-COMMON-SHIFT-OBSTRUCTION-23` — PROVED

Let centered jointly Gaussian \((X,Y)\) satisfy

\[
EX^2=EY^2=\sigma^2>0,\qquad E[XY]=r<\sigma^2,
\]

and set

\[
A_M=M+X,\qquad B_M=M+Y.
\]

Then

\[
v:=E(A_M-B_M)^2=2(\sigma^2-r),
\]

and `(4.4)` gives

\[
\beta_M=v[2\Phi(M/\sigma)-1].
\]

Thus

\[
\boxed{
E(A_{M,+}-B_{M,+})^2=v\Phi(M/\sigma)-\Gamma_M,
}
\tag{9.1}
\]

where

\[
\Gamma_M=E[|A_MB_M|\mathbf1_{\{A_MB_M<0\}}].
\]

To justify the large-positive-shift limit rigorously, use

\[
\{A_MB_M<0\}\subset\{A_M<0\}\cup\{B_M<0\}.
\]

By Cauchy--Schwarz,

\[
E[|A_MB_M|\mathbf1_{\{A_M<0\}}]
\le
(E[A_M^2B_M^2])^{1/2}P(A_M<0)^{1/2}.
\]

For a Gaussian pair,

\[
(E[A_M^2B_M^2])^{1/2}=O(M^2+1),
\]

whereas

\[
P(A_M<0)=\Phi(-M/\sigma)
\le
C\exp[-M^2/(2\sigma^2)]
\]

up to the standard polynomial Gaussian-tail prefactor. The same estimate holds with \(A,B\) interchanged. Therefore

\[
\boxed{\Gamma_M\to0\qquad(M\to+\infty).}
\tag{9.2}
\]

Consequently

\[
\boxed{
\frac{E(A_{M,+}-B_{M,+})^2}{E(A_M-B_M)^2}\to1
\qquad(M\to+\infty).
}
\tag{9.3}
\]

For \(M\to-\infty\), `(9.1)` and nonnegativity imply the ratio tends to zero.

Therefore a common positive shift can erase the fresh \(1/2\) factor completely while leaving both the mean difference and centered difference covariance unchanged.

**Disproved theorem template:** no universal conditional \(1/2+o(1)\) factor can depend only on \(\mu-\nu\) and \(p+q-2r\). The common mode matters.

The natural dynamic parameter is

\[
\boxed{\nu_i/\sqrt q,}
\tag{9.4}
\]

the recycled preactivation signal relative to fresh innovation standard deviation.
