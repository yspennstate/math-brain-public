# 3. New theorem: low innovation alone does not imply low dimension

## `P16-LOWINNOV-DIMENSION-CE-18` — NEW / PROVED counterexample

For every

\[
0<\eta<1
\]

and every integer

\[
m\ge2,
\]

there exists a sequence of

\[
2m-1
\]

unit vectors

\[
v_1,\ldots,v_{2m-1}
\in
\mathbb R_+^m
\]

such that:

1. \(v_1=e_1\);
2. for every \(r\ge2\),
   \[
   \boxed{
   \iota_r
   =
   \operatorname{dist}
   (v_r,\operatorname{span}(v_1,\ldots,v_{r-1}))
   \le
   \eta;
   }
   \tag{CE1}
   \]
3. nevertheless
   \[
   \boxed{
   \operatorname{span}(v_1,\ldots,v_{2m-1})
   =
   \mathbb R^m.
   }
   \tag{CE2}
   \]

In fact the innovation-ratio pattern is exactly

\[
\boxed{
1,\eta,0,\eta,0,\ldots,\eta,0.
}
\tag{CE3}
\]

### Construction

Let

\[
a=\sqrt{1-\eta^2}.
\]

Set

\[
v_1=e_1.
\]

For \(j=2,\ldots,m\), define

\[
\boxed{
v_{2j-2}
=
a e_{j-1}
+
\eta e_j,
}
\tag{CE4}
\]

\[
\boxed{
v_{2j-1}
=
e_j.
}
\tag{CE5}
\]

All vectors are unit and lie in the positive orthant.

Inductively, before \(v_{2j-2}\) appears, the old span contains

\[
e_1,\ldots,e_{j-1}
\]

but not \(e_j\).

Hence the orthogonal residual of \(v_{2j-2}\) is exactly

\[
\eta e_j,
\]

so

\[
\iota_{2j-2}=\eta.
\]

But once \(v_{2j-2}\) and \(e_{j-1}\) have been seen, their span contains

\[
e_j
=
\eta^{-1}
\left(
v_{2j-2}

a e_{j-1}
\right).

Therefore

\[
\iota_{2j-1}=0.
\]

At the end the span contains every standard basis vector.

QED.

# 4. The exact mechanism: hidden-direction promotion

The counterexample isolates the missing quantity.

At a rank-increase time, a new orthogonal direction can enter with a tiny coefficient \(\eta\).

A later vector can then rotate almost entirely into that already-revealed direction while having **zero new innovation**.

In `(CE4)`--`(CE5)`, the direction \(e_j\) is first introduced with amplitude

\[
\eta,
\]

then immediately promoted to amplitude

\[
1.
\]

The amplification factor is exactly

\[
\boxed{
\eta^{-1}.
}
\]

This suggests the correct deterministic bookkeeping.

Let

\[
q_1,q_2,\ldots
\]

be the orthonormal fresh directions generated at rank-increase times.

For a normalized query \(\widehat v_r\), write

\[
\widehat v_r
=
\sum_j
c_{rj}q_j.
\]

If fresh direction \(q_j\) is introduced at time \(\tau_j\), its pivot coefficient is

\[
d_j
=
|c_{\tau_j,j}|
=
\iota_{\tau_j}.
\]

Define the finite-horizon promotion factor

\[
\boxed{
A_j(R)
=
\max_{\tau_j\le r\le R}
\frac{|c_{rj}|}{d_j}.
}
\tag{P1}
\]

Because \(|c_{rj}|\le1\),

\[
A_j(R)\le d_j^{-1}.
\]

The counterexample attains this upper scale.

Therefore a tiny Gram pivot does **not** imply that the corresponding new direction remains negligible later.

# 5. Conditional correction: promotion control does imply compression

\[
A_j(R)\le B
\qquad

\[
\boxed{
\left\|

\sum_{j\in J}

# 6. Exact ReLU recurrence-debt identity

The tied map provides additional structure beyond an arbitrary vector sequence.

Let

\[

\]

\[

\[

\[

\[
\boxed{

\sum_{j<t}a_jx_j.

\[

=

\[

D_tWr_t.

\sum_{j<t}a_jx_{j+1}

\sum_{j<t}a_jD_jy_j.

# 7. Mask mismatch has a deterministic metric bound

For two real scalars \(u,v\),

\[
\left|
(\mathbf1_{\{u>0\}}-\mathbf1_{\{v>0\}})v
\right|
\le
|u-v|.

Indeed, if the indicators agree the left side is zero.

If they differ, \(u\) and \(v\) have opposite signs or one is zero, hence

\[
|v|\le|u-v|.

Apply this coordinatewise with

\[
u=(y_t)_i,

v=(y_j)_i.

Then

\[
\boxed{
\|(D_t-D_j)y_j\|

\|y_t-y_j\|

\|W\|
\|x_t-x_j\|.
}
\tag{R4}

\[
\boxed{

\right].

\tag{R5}
\]

This is a completely deterministic tied-ReLU recurrence inequality.

# 8. What low innovation actually gives

Take \(a=a_t\) to be a least-squares coefficient vector for projecting \(x_t\) onto

\[
\operatorname{span}(x_0,\ldots,x_{t-1}).
\]

Then

\[
\|r_t\|
=
\operatorname{dist}
(x_t,\operatorname{span}(x_0,\ldots,x_{t-1}))
=
\delta_t.
\]

So low innovation gives

\[
\|r_t\|
\ll
\|x_t\|.
\]

But `(R3)` shows that approximate recurrence of the **next** state additionally requires control of

\[
\boxed{
\mathcal M_t(a)
=
\sum_{j<t}
|a_j|
\|(D_t-D_j)y_j\|.
}
\tag{R6}
\]

This is the exact activation-mask debt.

There is a second debt hidden in the coefficient vector itself.

If

\[
X_t=[x_0|\cdots|x_{t-1}]
\]

and its positive singular values are bounded below by \(\kappa\), then the minimum-norm projection coefficients satisfy

\[
\boxed{
\|a_t\|_2
\le
\frac{\|x_t\|}{\kappa}.
}
\tag{R7}
\]

If the past Gram matrix is nearly singular, the coefficients can be very large.

Thus the low-innovation branch splits into three structurally different situations:

1. **small residual + stable coefficients + small mask debt:**  
   genuine approximate linear recurrence propagates to the next state;

2. **small residual + unstable coefficients:**  
   the past query Gram matrix is ill-conditioned, creating a separate recurrent/compressible geometry;

3. **small residual + large mask debt:**  
   the ReLU activation pattern changes enough to destroy the linear recurrence.

This is the corrected low-innovation trichotomy.
