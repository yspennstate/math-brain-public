## 2.1 Tied finite-horizon theorem

One matrix with entries `N(0,1/N)` is reused at every time. For every fixed integer T≥0, fixed δ>0, and deterministic unit start,

`P_W{ max_(0≤t≤T) |2^t ||x_t||^2 - 1| > δ } ≤ C exp(-cN)`.

The same fixed-horizon estimate holds for a random start independent of W, and a Fubini/Markov argument gives exponentially small exceptional input mass for any prescribed input law independent of W.

The source does **not** assert a W-dependent/adversarial start theorem, arbitrary growing horizon, infinite-time contraction, or simultaneous one-matrix-all-inputs contraction. Its proof uses adaptive Gram–Schmidt Gaussian innovations.

## 2.2 Independent-layer global-Lipschitz theorem

A separate source theorem uses independent matrices `W_1,...,W_L`, each with entries `N(0,α/n)`. For fixed depth L, if `K_(n,L)(α)` is the genuine global Euclidean Lipschitz constant and

`α_L = sup{ α : P(K_(n,L)(α)≤1)→1 as n→∞ }`,

then

`lim_(L→∞) α_L = 2`

and

`α_L ≥ 2 exp[-(sqrt(10)+o(1)) sqrt(log L / L)]`.

The order of limits is part of the theorem: fix L, send width n→∞, then send L→∞. No arbitrary joint regime `L=L(n)` is claimed. This theorem cannot be transferred to the tied model by setting all layers equal.

## 2.3 Exact scaling in α

`F_(sqrt(α)A)^t(x) = α^(t/2) F_A^t(x)`.

Thus projective states and masks are independent of α>0 until death; only radial exponents shift by `(1/2) log α`.

# 5. Exact adaptive Gaussian frame representation

Let `G=sqrt(N/α) W` be the standard Gaussian matrix.

The inherited `P16-MULTISTART-INNOVATION-16` theorem gives, for a causal query history started from deterministic or W-independent data, orthonormal fresh domain directions `q_1,...,q_d` such that `z_j:=G q_j` are iid `N(0,I_N)`.

Let `Q=[q_1|...|q_d]` and `Z=[z_1|...|z_d]`. Then `Q^TQ=I_d`, Z has iid standard Gaussian entries, and for every vector in the revealed query span `v=Qa`, the pathwise exact identity is

`Gv=Za`,  `||v||=||a||`.

Therefore

`||Wv||^2 = (α/N) ||Za||^2`.

The coefficient a may depend arbitrarily on the entire revealed Gaussian sample. A spectral bound on Z is therefore automatically uniform over that adaptivity.

# 6. Gaussian frame theorem with explicit constants

First let `X~chi-square_N`. For `0<u<1`, Chernoff gives

`P{X≥N(1+u)} ≤ exp[-(N/2)(u-log(1+u))] ≤ exp[-Nu^2/8]`

because `u-log(1+u)≥u^2/4`. Similarly

`P{X≤N(1-u)} ≤ exp[-Nu^2/8]`.

Hence

`P{|X/N-1|>u} ≤ 2 exp[-Nu^2/8]`.

Let `N_1/4` be a 1/4-net of the unit sphere in `R^d`, with cardinality at most `9^d`. For a symmetric matrix B,

`||B||_op ≤ 2 max_(x in N_1/4) |x^T B x|`.

Apply this to `B=N^(-1) Z^T Z - I_d`. For fixed unit x, `||Zx||^2~chi-square_N`. If `||B||_op>ε`, some net point has quadratic deviation `>ε/2`.

## `P16-GROWINGDIM-FRAME-26` — NEW / PROVED

For every `1≤d≤N` and `0<ε<1`,

`P{ ||N^(-1) Z^T Z - I_d||_op > ε } ≤ 2 · 9^d · exp[-N ε^2/32]`.

Consequently, on the good event, simultaneously for **every adaptive vector v in the revealed query span**,

`α(1-ε)||v||^2 ≤ ||Wv||^2 ≤ α(1+ε)||v||^2`.

No union bound over query vectors is required. No independence between v and the revealed Gaussian matrix Z is required.

# 7. Sharpness scale of the frame theorem

The sufficient theorem gives frame distortion `O_P(sqrt(d/N))` for `d=o(N)`.

This scale is asymptotically sharp in the Gaussian model. The classical sample-covariance edge theorem gives, when `d/N→δ in (0,1)`,

`λ_max(N^(-1) Z^T Z) → (1+sqrt(δ))^2` a.s.,

`λ_min(N^(-1) Z^T Z) → (1-sqrt(δ))^2` a.s.

for Gaussian entries. Primary reference checked: Z. D. Bai and Y. Q. Yin, *Limit of the Smallest Eigenvalue of a Large Dimensional Sample Covariance Matrix*, Annals of Probability 21 (1993), 1275–1294, DOI `10.1214/aop/1176989118`; the paper proves the lower edge and records the known upper edge.

Consequently, to make the **uniform** frame distortion `o(Δ)` near `α=2-Δ`, the natural necessary scale is

`d/N=o(Δ^2)`.

The gate-entropy hypothesis from the preceding run is stronger by a logarithm, so the frame does not become the first bottleneck there.

# 9. Lag-pair geometry and exact reset budget

Fix a live current query `x_t` and an older queried state `x_j`, `j<t`. Let

`S_(t-1)=span(x_0,...,x_(t-1))`

and let

`δ_t=||P_(S_(t-1)^perp) x_t||`.

If `δ_t=0`, there is no fresh Gaussian innovation; this is the inherited recurrence branch and is excluded from the present theorem.

If `δ_t>0`, define the **relative old-span ratio**

`r_(j,t) = ||P_(S_(t-1))(x_t-x_j)|| / δ_t`.

Because `x_j in S_(t-1)`,

`||x_t-x_j||^2 = δ_t^2 (1+r_(j,t)^2)`.

The inherited `P16-LAG-GEOMETRIC-CERT-24` and `P16-TIED-LAG-TAIL-24` show that on the joint gate/frame event, the conditional mean-square gain of this pair is bounded by

`Q_(α,ε,η)(r) = α [ (1+ε)r^2 + 1/2+η + (1/sqrt(2π)) sqrt(1+ε) r ] / (1+r^2)`.

Moreover, conditionally on the past, for every `τ>0`,

`P{ ||x_(t+1)-x_(j+1)|| ≥ (sqrt(Q)+τ)||x_t-x_j|| | F_(t-1) } ≤ exp[-N τ^2(1+r^2)/(2α)]`.

This is now a **joint gate/frame/old-span budget**.

# 10. Exact finite-width simultaneous reset theorem

`ψ'(r) = [2(1+ε-1/2-η)r + a sqrt(1+ε)(1-r^2)]/(1+r^2)^2 > 0`.

`Q0:=Q_(α,ε,η)(r0)<1`.

# 11. Exact finite-N old-span threshold

For `α≥1`, define

`A=α(1+ε)-1`,

`B=[α/sqrt(2π)] sqrt(1+ε)`,

`C=α(1/2+η)-1`.

The condition `Q_(α,ε,η)(r)<1` is exactly

`A r^2 + B r + C < 0`.

If `η<1/α-1/2`, then C<0. If A>0, the positive root is

`r_*(α,ε,η) = [-B + sqrt(B^2-4AC)]/(2A)`.

Every `0≤r<min{1,r_*}` lies in the conditional contraction region.

At `α=1, ε=0`, where A=0, the threshold is the positive linear root `r_*=-C/B`.

This theorem can be used directly for fixed α, without any near-edge asymptotics.

# 14. Radial specialization and consistency check

Take the lag comparison state to be zero. Then

`r_t = ||P_(S_(t-1)) x_t|| / ||P_(S_(t-1)^perp) x_t||`.

If

`ι_t = ||P_(S_(t-1)^perp) x_t|| / ||x_t||`

is the innovation ratio, then

`ι_t = 1/sqrt(1+r_t^2)`.

Therefore a noncontracting radial step in the near-edge joint-good regime requires

`r_t ≥ (sqrt(π/8)-o(1))Δ_N`,

which implies

`1-ι_t ≥ (π/16)Δ_N^2 + o(Δ_N^2)`.

This matches the neutral-gate threshold derived in preceding P16 work and now holds simultaneously over the growing-horizon gate/frame regime.

It does not contradict the older worst-recycled-mean high-innovation coefficient π/64 because the present bound uses the proved gate-neutrality event rather than a worst positive recycled mean.

# 15. What is now ruled out

The previous obstruction list contained four local debts:

1. gate bias;
2. revealed-frame/Rayleigh distortion;
3. old-span contamination / low relative innovation;
4. conic cancellation / synchronization recurrence.

This run proves that under the growing-horizon entropy conditions:

- gate bias is `o(2-α)`;
- frame distortion is also `o(2-α)`;
- every lag pair whose old-span ratio lies below the sharp first-order threshold contracts with high probability.

Hence before ambient gate capacity becomes large, the only remaining local mechanisms for a noncontracting reset are

- **old-span contamination beyond the threshold**, or
- **zero-innovation / conic-cancellation / synchronization recurrence**.

The global theorem is still open because a noncontracting orbit may spend a large fraction of time in exactly those recurrent regimes.
