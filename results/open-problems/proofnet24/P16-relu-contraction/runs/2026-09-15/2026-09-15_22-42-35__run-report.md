### `P16-ROW-GHOST-RMS-34` — NEW / PROVED

A separate theorem directly quantifies the **adversarial first-probe dependence debt**.

Let U=U(W,ξ) be any measurable unit-vector selector; ξ is arbitrary auxiliary randomness independent of W. Let W^(i) replace row i of W by an independent copy, use the same ξ, and let `U^(i)=U(W^(i),ξ)`. Define

`D_row(U) = Σ_i E [ w_i^T (U-U^(i)) ]²`.

Then

`| √( E ||ReLU(WU)||² ) - √(α/2) | ≤ √D_row(U)`.

The proof is a one-line Hilbert-space ghost comparison after observing that U^(i) is independent of the original row w_i. In particular,

`E ||ReLU(WU)||² ≤ ( √(α/2) + √D_row(U) )²`.

Therefore an adaptive selector whose expected squared gain is at least one must pay

`D_row(U) ≥ (1-√(α/2))²`.

Near the edge `α=2-Δ`, the exact debt threshold is

`(1-√(1-Δ/2))² = Δ²/16 + Δ³/64 + O(Δ⁴)`.

If `D_row(U)=o(Δ²)`, then

`E ||ReLU(WU)||² ≤ 1 - Δ/2 + o(Δ)`

and

`√(E ||ReLU(WU)||²) ≤ 1 - Δ/4 + o(Δ)`.

This is an **expectation-level theorem for the original tied Gaussian first probe**, not a high-probability or all-time theorem. It gives an exact quantitative obligation for any route that selects an exceptional direction after seeing W.

The sharp current obstruction is now:

# 5. `P16-BLOCK-NUMERICAL-RANGE-34` — exact quadratic stitching identity

Because both `h_(j+1)` and `v_(j+1)` are unit vectors,

`<v_(j+1), h_(j+1)> = 1 - ε_j²/2`.

This is exact, from

`ε_j² = ||h_(j+1)-v_(j+1)||² = 2 - 2<v_(j+1),h_(j+1)>`.

Now compute the cyclic block Rayleigh quotient:

`<w,Bw> = Σ_j <w_(j+1), A_j w_j>`

`= G Σ_j s_(j+1)² <v_(j+1), h_(j+1)>`

`= G Σ_j s_(j+1)² (1-ε_j²/2)`.

Cyclicity gives

`Σ_j s_(j+1)² = Σ_j s_j² = ||w||²`.

Therefore

`<w,Bw>/||w||² = G [1 - (1/2) E_s(ε²)]`,

with

`E_s(ε²) = (Σ_j s_(j+1)² ε_j²)/(Σ_j s_j²)`.

For a real matrix B,

`w^T B w = w^T Sym(B) w`,

where `Sym(B)=(B+B^T)/2`. Hence

## Theorem

`λ_max(Sym B) ≥ G [1 - E_s(ε²)/2]`.

In particular, if every ε_j≤D,

`λ_max(Sym B) ≥ G(1-D²/2)`.

### Why this is a genuine strengthening

The least-singular certificate from run 33 loses linearly in the RMS stitch:

`σ_min(G^(-1)B-I) ≤ √E_s(ε²)`.

The Hermitian Rayleigh certificate loses **quadratically**:

`1 - <w,Bw>/(G||w||²) = E_s(ε²)/2`.

It also completely avoids eigenvector conditioning, pseudospectral inversion and any cycle-length amplification.

It remains only a necessary bad-orbit certificate; a stable nonnormal system can have a large numerical range.

# 8. `P16-AMBIENT-NUMRANGE-BARRIER-34` — why masks cannot be discarded

Let `S_ℓ` be the cyclic shift on the ℓ phase coordinates and define the unmasked cyclic lift

`A_ℓ = S_ℓ ⊗ W`.

Let `e=(1,...,1)/√ℓ`, so `S_ℓ e=e`. For any unit x, put `z=e⊗x`. Then

`z^T A_ℓ z = (e^T S_ℓ e)(x^T W x) = x^T W x`.

Hence

`λ_max(Sym A_ℓ) ≥ λ_max((W+W^T)/2)`.

Now let W have iid `N(0,α/N)` entries. Put

`H=(W+W^T)/2`.

For i<j,

`Var(H_ij)=α/(2N)`.

For i=j,

`Var(H_ii)=α/N`.

Thus H is exactly a GOE matrix with Wigner variance parameter `σ²=α/2`.

Bai and Yin, *Necessary and Sufficient Conditions for Almost Sure Convergence of the Largest Eigenvalue of a Wigner Matrix*, Annals of Probability 16(4), 1729–1741 (1988), prove the almost-sure Wigner edge `λ_max→2σ` under finite fourth moment; the Gaussian matrix here satisfies those hypotheses exactly. Therefore

`λ_max(H) → √(2α)` almost surely.

Consequently, for every fixed α>1/2,

`P{ λ_max(Sym A_ℓ)>1 } → 1`.

### Consequence

No argument can close the open interval by replacing the dynamic block masks with the identity and then proving that the resulting ambient Hermitian/numerical radius is below one. The ambient object is already expansive once α>1/2.

The dynamically selected masks and their support/alignment constraints are therefore mathematically essential, not bookkeeping.

This does **not** imply that an actual ReLU orbit has nonnegative Lyapunov exponent. It only falsifies an ambient numerical-range proof strategy.

# 9. `P16-ROW-GHOST-RMS-34` — exact dependence price for a W-dependent first probe

This section addresses the separate every-input/adversarial-start obstruction.

Let the rows of W be `w_1,...,w_N`, iid `N(0, α I_N/N)`.

Let ξ be auxiliary randomness independent of W, and let

`U=U(W,ξ)`

be any measurable unit-vector selector.

For each i, let `w_i'` be an independent copy of row i, let `W^(i)` be W with row i replaced by `w_i'`, and use the same ξ to define

`U^(i)=U(W^(i),ξ)`.

Define the row-ghost dependence debt

`D_row(U) = Σ_(i=1)^N E [ w_i^T(U-U^(i)) ]²`.

The expectation is over W, all replacement rows and ξ.

## Proof

Define scalars

`a_i = w_i^T U`,

`b_i = w_i^T U^(i)`.

Since U^(i) depends on W^(i), ξ but **not on the original row w_i**, U^(i) is independent of w_i. Conditionally on U^(i),

`b_i ~ N(0, α/N)`.

Therefore

`Σ_i E (b_i)_+² = α/2`.

Now work in the direct-sum Hilbert space of square-integrable scalar coordinates over i and the underlying probability space. The ReLU map is 1-Lipschitz, so

`|(a_i)_+ - (b_i)_+| ≤ |a_i-b_i| = |w_i^T(U-U^(i))|`.

Hence

`|| ((a_i)_+)_i - ((b_i)_+)_i ||_(L² direct sum) ≤ √D_row(U)`.

The two Hilbert norms are respectively

`√( E ||ReLU(WU)||² )`

and

`√(α/2)`.

The reverse triangle inequality yields the exact certificate

`| √( E ||ReLU(WU)||² ) - √(α/2) | ≤ √D_row(U)`.

This proves `P16-ROW-GHOST-RMS-34`.

## Corollary: adaptive expected expansion requires quadratic dependence debt

Let

`R(U)=E ||ReLU(WU)||²`.

Then

`R(U) ≤ ( √(α/2) + √D_row(U) )²`.

If `R(U)≥1`, necessarily

`D_row(U) ≥ (1-√(α/2))²`.

At `α=2-Δ`,

`(1-√(α/2))² = Δ²/16 + Δ³/64 + O(Δ⁴)`.

Thus the natural adaptation debt is exactly on the same quadratic edge scale `Δ²` that already appeared in the causal-rank and full-span analyses.

If instead

`D_row(U)=o(Δ²)`,

then

`√R(U) ≤ 1-Δ/4+o(Δ)`

and

`R(U) ≤ 1-Δ/2+o(Δ)`.

## Corollary: expected nonnegative log gain also forces the same debt

If `g(U)=||ReLU(WU)||` and `E log g(U)≥0`, then Jensen gives

`E g(U)² ≥ exp(2 E log g(U)) ≥ 1`.

Hence again

`D_row(U) ≥ (1-√(α/2))²`.

This is useful for a W-dependent stationary/invariant selector **only at the averaged level stated**. It is not a proof that `λ_max(W)<0` with high probability.

## Event version

If a selected direction satisfies `g(U)≥q` on an event of probability p, then `R(U)≥p q²`. Whenever `q√p ≥ √(α/2)`, the same theorem gives

`D_row(U) ≥ (q√p - √(α/2))²`.

Again this is an expectation/coupling statement. It does not by itself control the probability of a bad invariant orbit.

# 10. What the row-ghost theorem does and does not solve

### It does solve

It gives an exact, source-faithful quantitative price for choosing the first probe after seeing W. For a deterministic or W-independent unit vector, using the same ξ gives `U=U^(i)` for every i, so `D_row=0` and the theorem recovers the exact fresh benchmark

`E ||ReLU(WU)||² = α/2`.

Thus the source's warning about W-dependent exceptional directions is converted into a checkable row-replacement obligation.

### It does not solve

The main theorem asks for a quenched high-probability statement simultaneously over all inputs and all times. `P16-ROW-GHOST-RMS-34` is an annealed expectation theorem for one selected probe. It does not provide concentration of the selected gain, nor does it show that a maximal-Lyapunov invariant selector has small row debt.

A successful use must therefore prove one of:

1. a dynamically relevant bad selector has `D_row=o((2-α)²)`, contradicting nonnegative averaged log gain;
2. large `D_row` itself forces many row-sensitive mask changes, recycled-energy charges, synchronization/reset debt, or signed-cancellation cost;
3. a quenched finite-witness argument upgrades the annealed selector theorem to uniform input control.

This becomes a concrete replacement for the vague phrase “adversarial first direction.”
