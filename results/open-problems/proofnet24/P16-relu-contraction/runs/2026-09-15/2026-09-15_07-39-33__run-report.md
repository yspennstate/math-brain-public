# New object: conic innovation

For a nonzero trajectory define
\[
S_{t-1}=\operatorname{span}(x_0,\dots,x_{t-1}),\qquad
C_{t-1}=\operatorname{cone}(x_0,\dots,x_{t-1}),
\]
and
\[
\iota_t=\frac{\operatorname{dist}(x_t,S_{t-1})}{\|x_t\|},\qquad
\boxed{\kappa_t=\frac{\operatorname{dist}(x_t,C_{t-1})}{\|x_t\|}.}
\tag{1}
\]
Because \(C_{t-1}\subset S_{t-1}\) and \(0\in C_{t-1}\),
\[
0\le\iota_t\le\kappa_t\le1.
\]
The gap \(\kappa_t-\iota_t\) measures the amount of **signed cancellation** needed beyond plain span approximation.

# Main theorem: ReLU is radially sublinear on the positive cone

For scalar ReLU \(\sigma(s)=s_+\),
\[
\sigma(u+v)\le\sigma(u)+|v|,
\qquad
\sigma\!\left(\sum_j a_ju_j\right)\le\sum_j a_j\sigma(u_j)
\quad(a_j\ge0).
\]

## `P16-CONE-RADIAL-SUBLINEAR-19` — PROVED

If
\[
x=\sum_j a_jx_j+r,\qquad a_j\ge0,
\]
then coordinatewise
\[
\boxed{F_W(x)\le\sum_j a_jF_W(x_j)+|Wr|,}
\tag{2}
\]
and hence
\[
\boxed{\|F_W(x)\|\le\sum_j a_j\|F_W(x_j)\|+\|W\|\|r\|.}
\tag{3}
\]
So for **positive-cone recurrence**, activation-mask mismatch is not a separate radial debt. It remains relevant for vector identities, but not for this norm upper bound.

# Radial maximum principle

For a trajectory let
\[
g_j=\frac{\|x_{j+1}\|}{\|x_j\|}.
\]
Suppose
\[
\left\|x_t-\sum_{j<t}a_jx_j\right\|\le\delta\|x_t\|,
\qquad a_j\ge0.
\]
Define
\[
C_t(a)=\frac{\sum_{j<t}a_j\|x_j\|}{\|x_t\|},
\qquad
g_{<t}^{\max}=\max_{j<t:a_j>0}g_j.
\]

## `P16-CONE-RADIAL-MAXPRINCIPLE-19` — PROVED

\[
\boxed{g_t\le C_t(a)g_{<t}^{\max}+\|W\|\delta.}
\tag{4}
\]
In particular, if \(C_t(a)\le1+\varepsilon\),
\[
g_t-g_{<t}^{\max}
\le\varepsilon g_{<t}^{\max}+\|W\|\delta.
\]
Thus a near-unit-mass positive recurrence cannot create a substantially larger radial multiplier than the states generating it.

# Near-unit cone mass forces projective return

Put
\[
u_j=x_j/\|x_j\|,\qquad
c_j=a_j\|x_j\|/\|x_t\|,\qquad
w=\sum_jc_ju_j.
\]
Then \(\|w-u_t\|\le\delta\) and \(\sum c_j=C_t(a)\). If \(\delta<1\) and \(C_t(a)\le1+\varepsilon\), then \(C_t(a)\ge1-\delta\), and
\[
\sum_jc_j\|u_j-u_t\|^2
=2C_t(a)-2\langle w,u_t\rangle
\le2(\varepsilon+\delta).
\]

## `P16-CONE-PROJECTIVE-RETURN-19` — PROVED

There exists some support index \(j<t\) such that
\[
\boxed{\|u_j-u_t\|^2\le\frac{2(\varepsilon+\delta)}{1-\delta}.}
\tag{5}
\]
Thus near-unit-mass conic recurrence automatically yields a projective return, exactly the geometry needed by the existing approximate-cycle program.

# Signed cancellation debt

Allow a signed recurrence
\[
x_t=\sum_{j<t}a_jx_j+r,\qquad \|r\|\le\delta\|x_t\|.
\]
Write \(a_j=a_j^+-a_j^-\), \(a_j^\pm\ge0\), and define
\[
N_-(a)=\frac{\sum_j a_j^-\|x_j\|}{\|x_t\|}.
\]
Let \(p=\sum a_j^+x_j\in C_{t-1}\), \(n=\sum a_j^-x_j\in C_{t-1}\). Since \(x_t=p-n+r\),
\[
\operatorname{dist}(x_t,C_{t-1})
\le\|x_t-p\|
\le\|r\|+\|n\|.
\]

## `P16-CANCELLATION-DEBT-19` — PROVED

\[
\boxed{N_-(a)\ge(\kappa_t-\delta)_+.}
\tag{6}
\]
Hence \(\iota_t\ll1\) but \(\kappa_t\asymp1\) forces every accurate linear recurrence to use macroscopic negative weighted mass.

# Signed radial bound

The same ReLU sublinearity gives, with \(x_t=p-n+r\),
\[
F_W(x_t)\le \sum_j a_j^+F_W(x_j)+|Wn|+|Wr|.
\]

## `P16-SIGNED-CONE-RADIAL-19` — PROVED

\[
\boxed{
\|x_{t+1}\|
\le
\sum_{j<t}a_j^+\|x_{j+1}\|
+
\|W\|
\left[
\|r\|+\sum_{j<t}a_j^-\|x_j\|
\right].
}
\tag{7}
\]
For radial upper bounds, the old activation-mask debt can therefore be replaced by the sharper **signed-cancellation debt**.

# Hidden-promotion counterexample is detected by \(\kappa_t\)

\boxed{\iota_t=0,\qquad \kappa_t=\sqrt{1-\eta^2}.}
\tag{8}

As \(\eta\downarrow0\), the linear innovation tends to zero while conic innovation tends to one. The new conic statistic detects exactly the geometry that defeated the previous low-innovation theorem.
