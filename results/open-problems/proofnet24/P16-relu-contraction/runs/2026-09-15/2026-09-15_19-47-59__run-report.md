# 5. ReLU duality and the rectangular Gaussian problem

For any real \(N\times r\) matrix \(G\), define

\[
M(G)
=
\sup_{\|a\|=1}
\|\operatorname{ReLU}(Ga)\|.
\]

For any vector \(z\),

\[
\|z_+\|
=
\sup_{\substack{y\ge0\\\|y\|=1}}
y^Tz.
\]

Therefore

\[
\begin{aligned}
M(G)
&=
\sup_{\|a\|=1}
\sup_{\substack{y\ge0\\\|y\|=1}}
y^TGa
\\
&=
\sup_{\substack{y\ge0\\\|y\|=1}}
\|G^Ty\|.
\end{aligned}
\tag{5.1}
\]

This is exactly a rectangular nonnegative-PCA / maximum-conic-singular-value problem.

The previous P16 run used the first representation and Sudakov--Fernique to obtain the upper bound

\[
E M(G)
\le
\sqrt r+\sqrt{N/2}.
\tag{5.2}
\]

The question left open was whether the sum on the right was only an upper comparison artifact or the true leading asymptotic.

It is the true leading asymptotic.

# 6. Primary external theorem: Montanari--Richard rectangular nonnegative PCA

Primary source checked this run:

Andrea Montanari and Emile Richard,
*Non-Negative Principal Component Analysis: Message Passing Algorithms and Sharp Asymptotics*,
IEEE Transactions on Information Theory 62(3), 1458--1484 (2016),
DOI `10.1109/TIT.2015.2457942`.
Open primary preprint: arXiv:1406.4775.

The paper studies a rectangular matrix

\[
X=\sqrt\beta\,u_0v_0^T+Z,
\]

where

\[
Z\in\mathbb R^{n\times p},
\qquad
Z_{ij}\stackrel{\rm iid}{\sim}N(0,1/n),
\qquad
\frac pn\to\gamma\in(0,\infty),
\]

and the nonnegative-PCA value

\[
\sigma^+(X)
=
\sup_{\substack{v\ge0\\\|v\|=1}}
\|Xv\|.
\tag{6.1}
\]

Their Theorem 4 gives an almost-sure exact asymptotic and proves that their Sudakov--Fernique upper bound is matched by an AMP lower construction.

For the pure-noise case \(\beta=0\), the fixed-point parameter is \(0\). From their definitions,

\[
G_V(0)
=
\frac{E[G(G)_+]}{\sqrt{E(G_+)^2}}
=
\frac{1/2}{1/\sqrt2}
=
\frac1{\sqrt2},
\]

so their rectangular Rayleigh value is

\[
R_V^{\rm rec}(0,\gamma)
=
1+\sqrt\gamma\,G_V(0)
=
1+\sqrt{\gamma/2}.
\]

Thus the pure-noise specialization is

\[
\boxed{
\sup_{\substack{v\ge0\\\|v\|=1}}
\|Zv\|
\longrightarrow
1+\sqrt{\gamma/2}
\quad\text{almost surely}.
}
\tag{6.2}
\]

No spike-law hypothesis survives when \(\beta=0\), because the spike disappears from the matrix.

The paper's almost-sure statements are with respect to a product coupling of the matrix sequence. In particular they imply convergence in probability for each dimension sequence with the stated marginals.

# 12. Elementary independent sanity check: sign-pair lower bound

There is a simple deterministic lower bound that independently confirms that whole-span ReLU norms can be large.

For every vector \(z\),

\[
\|z_+\|^2+\|(-z)_+\|^2
=
\|z\|^2.
\]

Let \(a_*\) be a top right singular vector of a deterministic matrix \(B\).
Then one of \(a_*\) and \(-a_*\) satisfies

\[
\|\operatorname{ReLU}(B(\pm a_*))\|^2
\ge
\frac12\|Ba_*\|^2.
\]

Therefore:

## `P16-SIGNPAIR-OPNORM-31` — NEW / PROVED

\[
\boxed{
L_{\rm ReLU}(B)
\ge
\frac1{\sqrt2}\|B\|_{\rm op}
\qquad\text{for every real matrix }B.
}
\tag{12.1}
\]

For a Gaussian \(N\times r\) matrix with \(r/N\to\delta\), Bai--Yin gives

\[
\frac{\|G\|_{\rm op}}{\sqrt N}

&=
\mu_P-
\frac{k\mu_P-\mu_\ell}{k-1}

\frac{(k-1)\mu_P-k\mu_P+\mu_\ell}{k-1}

&=
\frac{\mu_\ell-\mu_P}{k-1}.
\end{aligned}
\]

\[
\sum_{\ell=1}^k a_\ell
=
\frac1{k-1}
