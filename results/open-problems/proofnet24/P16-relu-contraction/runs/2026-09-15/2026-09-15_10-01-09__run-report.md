# 5. New theorem: synchronization records force reset debt

Fix a block-memory length

\[

Assume that for every \(t\in E\) there is a witness pair

\[

\[

\tag{5.1}
\]

Put

\[
d_t=j_t-i_t
\in\{1,\ldots,L-1\}.

\[
\Delta_{i_t,d_t}\ge\gamma_t>0.
\tag{5.2}
\]

This is exactly the form delivered by `P16-DIFFUSE-CONE-SYNC-20`, with

\[
\gamma_t
=
\frac{R_t^2-1}{s_t}

for a chosen witness, whenever \(R_t>1\).

## `P16-SYNC-RESET-DEBT-21` — NEW / PROVED

Under `(5.1)`--`(5.2)`,

\[
\boxed{
\sum_{d=1}^{L-1}P_d
\ge
\frac1L
\sum_{t\in E}\gamma_t.
}
\tag{5.3}
\]

Consequently,

\[
\boxed{
\sum_{d=1}^{L-1}N_d
\ge
\frac1L
\sum_{t\in E}\gamma_t
-
(L-1).
}
\tag{5.4}
\]

Equivalently,

\[
\boxed{
\sum_{t\in E}\gamma_t
\le
L\left[
(L-1)
+
\sum_{d=1}^{L-1}N_d
\right].

\tag{5.5}

### Proof

Fix a witness increment \((i,d)\).

It can serve only event times \(t\) for which

\[
t-L\le i,
\qquad
i+d\le t-1.

Equivalently,

\[
i+d+1\le t\le i+L.

\[
L-d\le L

such event times.

If several event times use the same witness increment \((i,d)\), every corresponding \(\gamma_t\) is at most

\[
\Delta_{i,d}.

Therefore the sum of all \(\gamma_t\)'s charged to that one increment is at most

\[
L\Delta_{i,d}
\le
L(\Delta_{i,d})_+.

\[
\sum_{t\in E}\gamma_t
\le
L\sum_{d=1}^{L-1}P_d.

This proves `(5.3)`.

Now sum `(4.6)` over

\[
d=1,\ldots,L-1.
\]

Then

\[
\sum_dN_d
\ge
\sum_dP_d-(L-1),
\]

and `(5.3)` gives `(5.4)`.

# 7. New theorem: exact radial-angular tradeoff for one tied step

The reset debt is not purely angular.

Let

\[
u,v\in S^{N-1}
\]

be two live projective states, and write

\[
F_W(u)=g_u\,u',
\qquad
F_W(v)=g_v\,v',
\]

with

\[
g_u,g_v>0,
\qquad
\|u'\|=\|v'\|=1.
\]

Put

\[
c=\langle u,v\rangle,
\qquad
c'=\langle u',v'\rangle.
\]

Because ReLU is 1-Lipschitz,

\[
\|F_W(u)-F_W(v)\|
\le
\|W\|\|u-v\|.
\tag{7.1}
\]

But

\[
\|F_W(u)-F_W(v)\|^2
=
g_u^2+g_v^2-2g_ug_vc'
\]

and

\[
g_u^2+g_v^2
\ge
2g_ug_v.
\]

Therefore

\[
\|F_W(u)-F_W(v)\|^2
\ge
2g_ug_v(1-c').
\]

Also

\[
\|u-v\|^2
=
2(1-c).
\]

Hence:

## `P16-PAIR-RADIAL-ANGULAR-21` — NEW / PROVED

\[
\boxed{
g_ug_v(1-c')
\le
\|W\|^2(1-c).
}
\tag{7.2}
\]

Whenever

\[
c'<1,
\]

\[
\boxed{
g_ug_v
\le
\|W\|^2
\frac{1-c}{1-c'}.
}
\tag{7.3}
\]

### Reset interpretation

If the pair **desynchronizes**,

\[
c'<c,
\]

then

\[
\frac{1-c}{1-c'}<1.
\]

Thus a reset improves the crude product bound below \(\|W\|^2\).

More quantitatively, if

\[
1-c\le\varepsilon,
\qquad
1-c'\ge\zeta,
\]

then

\[
\boxed{
g_ug_v
\le
\|W\|^2
\frac{\varepsilon}{\zeta}.
}
\tag{7.4}
\]

Therefore, if

\[
\zeta>\|W\|^2\varepsilon,
\]

then

\[
\boxed{
g_ug_v<1,
}
\tag{7.5}
\]

so at least one of the two tied radial steps is strictly contracting.

This is the first deterministic theorem in the synchronization branch that converts a sufficiently strong angular reset into a radial contraction payment.
