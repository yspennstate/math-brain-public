## 2.1 Tied finite-horizon theorem

The reviewed source uses one matrix with entries

\[
W_{ij}\stackrel{\mathrm{iid}}\sim N(0,1/N)
\]

reused at every time.  Theorem 7.1 says: fix an integer \(T\ge0\) and \(\delta>0\).  There exist constants \(C,c>0\), depending only on \(T,\delta\), such that for every deterministic unit start,

\[
\boxed{
P_W\left\{
\max_{0\le t\le T}
\left|2^t\|x_t\|^2-1\right|>\delta
\right\}
\le Ce^{-cN}.
}
\tag{2.1}
\]

Corollary 7.2 gives the same theorem for a random unit start independent of \(W\).  Theorem 7.3 gives, for one typical matrix, an exponentially small bad-input mass under any deterministic or random input measure independent of \(W\).

The source explicitly says:

- the horizon is fixed in the stated theorem;
- one matrix is **not** asserted to work for every sphere point simultaneously;
- a start chosen after observing \(W\) can sit on an exceptional direction;
- the dependence problem is that \(x_1\) already depends on \(W\), and the proof resolves this with adaptive Gram--Schmidt Gaussian innovations.

By exact positive scaling, for general \(W=\sqrt\alpha A\), the same projective path has

\[
F_{\sqrt\alpha A}^t(x)
=
\alpha^{t/2}F_A^t(x),
\]

so the corresponding fixed-horizon reference squared norm is \((\alpha/2)^t\).

# 5. Ray geometry: remove radial mismatch exactly

Fix a live post-ReLU orbit segment, so

\[
x_j,x_t\in\mathbb R_+^N\setminus\{0\},
\qquad
1\le j<t.
\]

Write

\[
a=\|x_t\|,
\qquad
b=\|x_j\|,
\qquad
u_t=\frac{x_t}{a},
\qquad
u_j=\frac{x_j}{b},
\]

and define the projective correlation

\[
c_{j,t}=\langle\nu_j,\nu_t\rangle\in[0,1].
\tag{5.1}
\]

Let

\[
S=S_{t-1}=\operatorname{span}(x_0,\ldots,x_{t-1}),
\qquad
\delta_t=\|P_{S^\perp}x_t\|,
\]

and when \(a>0\) define the innovation ratio

\[
\iota_t=\frac{\delta_t}{a}.
\tag{5.2}
\]

Because \(x_j\in S\),

\[
c_{j,t}^2
\le
\|P_S\nu_t\|^2
=
1-\iota_t^2.
\tag{5.3}
\]

The unscaled reset theorem compares \(x_t\) directly to \(x_j\).  That comparison needlessly pays any difference in radial norm.  ReLU is positively homogeneous, so the natural comparison object is the entire old ray.

Define the least-squares nonnegative ray scale

\[
\boxed{
\lambda_{j,t}
=
\frac{\langle x_t,x_j\rangle}{\|x_j\|^2}
=
\frac{a}{b}c_{j,t}
\ge0.
}
\tag{5.4}
\]

Let

\[
z_{j,t}=\lambda_{j,t}x_j\in S.
\]

This is history-measurable before querying \(Wx_t\).

## `P16-RAY-GEOMETRY-27` — NEW / PROVED

If \(\delta_t>0\), define

\[
\boxed{
r^{\rm ray}_{j,t}
=
\frac{
\|P_S(x_t-z_{j,t})\|
}{\delta_t}.
}
\tag{5.5}
\]

Then

\[
\boxed{
\|x_t-z_{j,t}\|^2
=
a^2(1-c_{j,t}^2),
}
\tag{5.6}
\]

and

\[
\boxed{
(r^{\rm ray}_{j,t})^2
=
\frac{
1-\iota_t^2-c_{j,t}^2
}{
\iota_t^2
}.
}
\tag{5.7}
\]

In particular,

\[
\boxed{
0\le r^{\rm ray}_{j,t}
\le
\frac{\sqrt{1-\iota_t^2}}{\iota_t}.
}
\tag{5.8}
\]

Also

\[
\boxed{
r^{\rm ray}_{j,t}\le r_{j,t},}
\tag{5.9}
\]

where \(r_{j,t}\) is the preceding run's unscaled old/current ratio.

### Proof

Since \(z_{j,t}\) is the orthogonal projection of \(x_t\) onto the line \(\operatorname{span}(x_j)\),

\[
\begin{aligned}
\|x_t-z_{j,t}\|^2
&=
\|x_t\|^2
-
\frac{\langle x_t,x_j\rangle^2}{\|x_j\|^2}
\\
&=
a^2(1-c_{j,t}^2),
\end{aligned}
\]

proving `(5.6)`.

Since \(x_j\in S\),

\[
P_Sz_{j,t}=z_{j,t}.
\]

Moreover,

\[
\|P_Sx_t\|^2
=a^2-\delta_t^2
=a^2(1-\iota_t^2).
\]

Therefore

\[
\begin{aligned}
\|P_S(x_t-z_{j,t})\|^2
&=
\|P_Sx_t\|^2
-
\frac{\langle x_t,x_j\rangle^2}{\|x_j\|^2}
\\
&=
a^2(1-\iota_t^2-c_{j,t}^2).
\end{aligned}
\]

Divide by

\[
\delta_t^2=a^2\iota_t^2
\]

to obtain `(5.7)`.  Inequality `(5.8)` is immediate.

Finally, \(z_{j,t}\) minimizes

\[
\|P_S(x_t-\lambda x_j)\|
\]

over all \(\lambda\in\mathbb R\), and the minimizer is nonnegative because both states lie in the positive orthant.  Taking \(\lambda=1\) proves `(5.9)`.

QED.
