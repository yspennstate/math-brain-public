# 5. ReLU duality and the rectangular Gaussian problem

For a real N by r matrix G, define

`M(G) := sup_{||a||=1} ||ReLU(Ga)||.`

For every vector z,

`||z_+|| = sup_{y≥0, ||y||=1} y^T z.`

Therefore

`M(G) = sup_{y≥0, ||y||=1} ||G^T y||.`

This is exactly a rectangular nonnegative-PCA / maximum-conic-singular-value problem.

The preceding P16 report used the primal representation and Sudakov–Fernique to prove

`E M(G) ≤ √r + √(N/2).`

The open question was whether this sum was merely an upper-comparison artifact or the true leading asymptotic. The primary theorem below shows it is the true leading asymptotic.

# 6. Primary external theorem: Montanari–Richard rectangular nonnegative PCA

Primary source checked this run:

Andrea Montanari and Emile Richard, *Non-Negative Principal Component Analysis: Message Passing Algorithms and Sharp Asymptotics*, IEEE Transactions on Information Theory 62(3), 1458–1484 (2016), DOI `10.1109/TIT.2015.2457942`, open primary preprint arXiv:1406.4775.

The paper studies a rectangular spiked matrix

`X = √β u_0 v_0^T + Z,`

where Z is n by p with iid `N(0,1/n)` entries and `p/n → γ ∈ (0,∞)`, and the nonnegative-PCA value

`σ⁺(X) := sup_{v≥0, ||v||=1} ||Xv||.`

Their rectangular theorem gives an almost-sure exact asymptotic and matches the Sudakov–Fernique upper bound with an AMP lower construction.

In the pure-noise case β = 0, the fixed-point parameter is zero. Their scalar functions satisfy

`G_V(0) = E[G G_+] / sqrt(E[G_+^2]) = (1/2)/(1/√2) = 1/√2,`

so the rectangular Rayleigh value becomes

`1 + √(γ/2).`

Therefore, for iid `N(0,1/n)` noise Z,

`sup_{v≥0, ||v||=1} ||Zv|| → 1 + √(γ/2)`

almost surely.

No spike-law hypothesis survives at β = 0 because the spike disappears from the matrix.

## Deterministic positivity / monotonicity route

The exact full-span obstruction strengthens the need to exploit the forward-invariant nonnegative cone and conic hulls of actual states. Any further gain must come from positivity or reachability, not sharper unrestricted linear-span estimates.

# 23. Bottom line

The tied ReLU contraction conjecture is still not solved or disproved on `1/2 ≤ α < 2`.

This run closes a major ambiguity in the high-rank route.

The full iid Gaussian revealed-span ReLU norm has the exact almost-sure asymptotic

`√α ( √δ + 1/√2 ).`

Therefore the full-span contraction threshold is exactly

`δ_span(α) = (1/√α - 1/√2)^2.`

Near α = 2,
