# 5. Deterministic radial submultiplicativity

Fix an arbitrary real matrix \(W\).

After one ReLU step, every orbit lies in

\[
\mathbb R_+^N.
\]

Let

\[
K=S^{N-1}\cap\mathbb R_+^N.
\]

For \(t\ge0\), put

\[
\Gamma_t
=
\sup_{u\in K}
\|F_W^t(u)\|.
\]

Because \(K\) is compact and \(F_W^t\) is continuous, the supremum is attained.

If

\[
F_W^t(u)\ne0,
\]

then

\[
v
=
\frac{F_W^t(u)}
{\|F_W^t(u)\|}
\in K.
\]

By positive homogeneity,

\[
F_W^{t+s}(u)
=
\|F_W^t(u)\|F_W^s(v).
\]

Therefore

\[
\|F_W^{t+s}(u)\|
\le
\Gamma_t\Gamma_s.
\]

If

\[
F_W^t(u)=0,
\]

the same inequality is trivial.

Taking the supremum gives

\[
\boxed{
\Gamma_{t+s}
\le
\Gamma_t\Gamma_s.
}
\tag{5.1}
\]

Hence

\[
a_t=\log\Gamma_t
\]

is subadditive, with the convention

\[
\log0=-\infty.
\]

Fekete's lemma therefore gives

\[
\boxed{
\lambda_{\max}
=
\lim_{t\to\infty}
\frac{a_t}{t}
=
\inf_{t\ge1}
\frac{a_t}{t}.
}
\tag{5.2}
\]

This quantity is the deterministic worst-orbit radial Lyapunov exponent.

\[
\Gamma_t
\le
\Gamma_L^k\Gamma_r
\le
\rho^{kL}\Gamma_r.

Therefore

\[
\Gamma_t
\le
C_0\rho^t,

where

\[
C_0
=
\max_{0\le r<L}
\Gamma_r\rho^{-r}.

\[
\|F_W^t(u)\|
\le
C_0\rho^t.

F_W(x)\in\mathbb R_+^N

\[
\|F_W(x)\|

\|F_W^t(x)\|

# 10. The limit measure does not charge dead directions

\[
B=\max\{0,\log\|W\|\}.

Along the maximizing orbit,

\[
\frac1{t_k}
\sum_{j=0}^{t_k-1}

=
\frac1{t_k}
\log\Gamma_{t_k}
\to
\lambda_{\max}.

For \(R>0\), define

\[
E_R
=

Let

\[
p_{k,R}
=
\nu_k(E_R).

Each time the orbit lies in \(E_R\), its log gain is \(<-R\); at every other time its log gain is at most \(B\).

\frac1{t_k}\log\Gamma_{t_k}
\le
-Bp_{k,R}+B

p_{k,R}

\frac{

R+B

p_{k,R}
\le
\frac{
B-\lambda_{\max}+1

R+B

\[
\boxed{
\nu(D)=0.

\tag{10.1}

So a worst long-run orbit cannot spend positive asymptotic frequency arbitrarily close to immediate death when its long-run exponent is finite.

# 11. Invariance despite the dead-set singularity

The projective map

\[
T(u)=F_W(u)/g(u)
\]

is continuous on \(K\setminus D\), but is not defined on \(D\).

This is the only technical point in the compactness argument.

Fix a bounded continuous function

\[
f:K\to\mathbb R.
\]

Along every finite maximizing orbit,

\[
\frac1{t_k}
\sum_{j=0}^{t_k-1}
\left[
f(Tu_{k,j})-f(u_{k,j})
\right]
=
\frac{
f(u_{k,t_k})-f(u_{k,0})
}{
t_k
}
\to0.
\tag{11.1}
\]

To pass to the weak limit without assuming continuity on \(D\), choose a continuous cutoff

\[
\chi_R:[0,\infty)\to[0,1]
\]

equal to zero on

\[
[0,e^{-2R}]
\]

and one on

\[
[e^{-R},\infty).
\]

Define

\[
h_R(u)
=
\begin{cases}
\chi_R(g(u))f(Tu), & g(u)>0,\\
0,&g(u)=0.
\end{cases}
\]

Then \(h_R\) is continuous on all of \(K\).

The difference between \(h_R\) and \(f\circ T\) is supported in

\[
\{g<e^{-R}\}.
\]

Section 10 makes the empirical frequency of this set \(O(R^{-1})\), uniformly along the maximizing subsequence.

Therefore one may:

1. replace \(f\circ T\) by \(h_R\);
2. pass \(k\to\infty\) by weak convergence;
3. send \(R\to\infty\).

Equation (11.1) yields

\[
\boxed{
\int f(Tu)\,d\nu(u)
=
\int f(u)\,d\nu(u).
}
\tag{11.2}
\]

Thus

\[
\nu\in\mathcal I_W.

\lambda_{\max}.

\boxed{

\log\|F_W^t(u)\|

\lambda_{\max}\ge0.
}
\tag{13.1}
\]

Poincaré recurrence gives a sequence

\[

such that

\[

\]

Fix \(\varepsilon>0\).

For all sufficiently large recurrence times,

\[
\|T^{L_k}u-u\|<\varepsilon
\]

and, by (13.1),

\[
\|F_W^{L_k}(u)\|
\ge
\e^{-\varepsilon L_k}.

Set

\[

=
\|F_W^{L_k}(u)\|.

Positive homogeneity gives the exact polar decomposition

\[
F_W^{L_k}(u)
=
r_kT^{L_k}u.

\[
\begin{aligned}
\|F_W^{L_k}(u)-r_ku\|
&=
r_k
\|T^{L_k}u-u\|\\
&<
\varepsilon r_k.
\end{aligned}

\[
\boxed{
\|F_W^{L_k}(u)-r_ku\|
<
\varepsilon r_k,
\qquad
r_k^{1/L_k}\ge e^{-\varepsilon}.

\tag{13.2}

This proves `P16-RECURRENT-OBSTRUCTION-10`.
