## 1. Exact model and retained state

The primary July model is the tied-weight Gaussian ReLU iteration
\[
W_{ij}\stackrel{\mathrm{iid}}{\sim}N(0,\alpha/N),\qquad
F_W(x)=\operatorname{ReLU}(Wx),\qquad
x_{t+1}=F_W(x_t),
\]
with the same \(W\) reused at all times.  The July source is Gmail message
`19f2da59e9f2f6ff`, attachment
`Decay_of_iterated_ReLU_maps_with_a_fixed_Gaussian_matrix.pdf`; its original normalization is \(\alpha=1\).

The strongest desired statement remains:

> For every fixed \(\alpha<2\), with probability tending to one as \(N\to\infty\), every initial vector \(x_0\) converges to \(0\) exponentially under iteration of \(F_W\), ideally with radial exponent \(\frac12\log(\alpha/2)\), or at least with some deterministic contraction rate \(\rho(\alpha)<1\).

This remains OPEN for \(1/2\le\alpha<2\), including \(\alpha=1\).

## 2. New theorem P16-SPARSE-TRANSITION

Let
\[
H(t)=-t\log t-(1-t)\log(1-t)
\]
be binary entropy in nats.  For
\[
0<a,b\le1/2,\qquad \eta>0,
\]
define
\[
L_{\alpha,\eta}(a,b)
=
\sqrt\alpha\left[
\sqrt a+\sqrt b+
\sqrt{2(H(a)+H(b)+\eta)}
\right].
\]

Then
\[
\boxed{
\Pr\left\{
\sup_{\substack{|S|\le aN\\|T|\le bN}}
\|W_{T,S}\|_{\rm op}
>
L_{\alpha,\eta}(a,b)
\right\}
\le
(N+1)^2e^{-\eta N}.
}
\tag{2.1}
\]

Consequently, on this event, for **every** state \(x\), including \(x=x(W)\), if
\[
S=\operatorname{supp}(x),\qquad
T=\operatorname{supp}(F_W(x)),
\]
and
\[
|S|\le aN,\qquad |T|\le bN,
\]
then
\[
\boxed{
\|F_W(x)\|
\le
L_{\alpha,\eta}(a,b)\|x\|.
}
\tag{2.2}
\]

This is a genuinely uniform-over-inputs theorem; no independence between \(x\) and \(W\) is assumed.

### Proof

For fixed supports \(S,T\) with \(s=|S|\), \(t=|T|\),
\[
W_{T,S}\stackrel d=\sqrt{\alpha/N}\,G_{t\times s},
\]
where \(G\) has iid \(N(0,1)\) entries.

For a standard \(t\times s\) Gaussian matrix,
\[
\mathbb E\|G\|_{\rm op}\le\sqrt s+\sqrt t,
\]
and Gaussian concentration gives
\[
\Pr\{\|G\|_{\rm op}\ge\sqrt s+\sqrt t+u\}
\le e^{-u^2/2}.
\tag{2.3}
\]
The expectation bound follows directly from Sudakov--Fernique by comparing
\(p^\top Gq\) to \(g^\top p+h^\top q\); the tail follows because operator norm is \(1\)-Lipschitz in Frobenius norm.

For \(a,b\le1/2\),
\[
\sum_{s\le aN}\binom Ns\le(N+1)e^{NH(a)},
\qquad
\sum_{t\le bN}\binom Nt\le(N+1)e^{NH(b)}.
\]
Set
\[
u=\sqrt{2N(H(a)+H(b)+\eta)}.
\]
A union bound over all ordered support pairs gives (2.1).

For (2.2), if \(S=\operatorname{supp}(x)\) and
\(T=\operatorname{supp}(F_W(x))\), then
\[
(Wx)_T=W_{T,S}x_S,
\]
and hence
\[
\|F_W(x)\|
=\|(W_{T,S}x_S)_+\|
\le\|W_{T,S}\|\,\|x\|.
\]
The support pair may depend arbitrarily on \(W\), because the event in (2.1) is already uniform over all support pairs.

The Gaussian norm estimate was cross-checked against the primary reference:
Kenneth R. Davidson and Stanislaw J. Szarek,
*Local operator theory, random matrices and Banach spaces*,
Handbook of the Geometry of Banach Spaces 1 (2001),
DOI 10.1016/S1874-5849(01)80010-3.

## 3. New corollary P16-SPARSE-DYN

For \(a=b=\delta\),
\[
L_{\alpha,\eta}(\delta)
=
\sqrt\alpha\left[
2\sqrt\delta+
\sqrt{4H(\delta)+2\eta}
\right].
\]

For \(\alpha\ge1/2\), define the unique
\(\delta_{\rm sp}(\alpha)\in(0,1/2)\) by
\[
\boxed{
\sqrt\alpha\left[
2\sqrt{\delta_{\rm sp}}
+
2\sqrt{H(\delta_{\rm sp})}
\right]
=1.
}
\tag{3.1}
\]

For every fixed
\[
0<\delta<\delta_{\rm sp}(\alpha)
\]
one can choose \(\eta>0\) so that
\[
\rho(\alpha,\delta)
:=
L_{\alpha,\eta}(\delta)<1.
\]
Then, with failure probability at most \((N+1)^2e^{-\eta N}\),

\[
\boxed{
|\operatorname{supp}(x_t)|\le\delta N\ \forall t
\quad\Longrightarrow\quad
\|x_t\|\le\rho(\alpha,\delta)^t\|x_0\|\ \forall t.
}
\tag{3.2}
\]

Thus the tied Gaussian ReLU map is uniformly exponentially contractive on every trajectory that remains sufficiently sparse.

Numerically,
\[
\delta_{\rm sp}(0.5)=0.0571530717\ldots,
\]
\[
\delta_{\rm sp}(0.73525597457)=0.0359489512\ldots,
\]
\[
\boxed{
\delta_{\rm sp}(1)=0.02499644146\ldots,
}
\]
\[
\delta_{\rm sp}(1.5)=0.0155851960\ldots,
\qquad
\delta_{\rm sp}(2)=0.0111884479\ldots.
\]

Therefore, at the original \(\alpha=1\), a noncontracting invariant orbit cannot stay below any fixed support fraction
\[
\delta<0.02499644\ldots.
\]
Equivalently, any such obstruction must have
\[
\limsup_t\frac{|\operatorname{supp}(x_t)|}{N}
\ge0.02499644\ldots
\]
in the asymptotic sense captured by the theorem.

This removes permanently sparse/dead-neuron subsystems as a possible obstruction.  It does **not** solve the dense regime; fixed-input masks are typically macroscopic, and the known \(W\)-dependent one-step expanding direction is dense.

## 4. Periodic-orbit consequence

Suppose
\[
y=F_W(x),\qquad
F_W(y)=\lambda x,\qquad
\lambda>0,
\]
with supports
\[
S=\operatorname{supp}(x),\qquad
T=\operatorname{supp}(y).
\]
Then
\[
\|y\|\le\|W_{T,S}\|\,\|x\|,
\]
and
\[
\lambda\|x\|
\le\|W_{S,T}\|\,\|y\|.
\]
Hence
\[
\boxed{
\lambda
\le
\|W_{S,T}\|\,\|W_{T,S}\|.
}
\tag{4.1}
\]

On the event (2.1), if
\[
|S|\le aN,\qquad |T|\le bN,
\]
then
\[
\boxed{
\lambda
\le
L_{\alpha,\eta}(a,b)^2.
}
\tag{4.2}
\]

Thus no noncontracting projective two-cycle can lie entirely in a support-size region where \(L_{\alpha,\eta}(a,b)<1\).  The same per-step argument excludes any finite cycle whose supports all remain below a symmetric sparse threshold with \(L_{\alpha,\eta}(\delta)<1\).

The earlier deterministic period-two counterexample therefore remains a valid logical warning, but the random Gaussian model now rules out its sparse analogue.

## 5. Quantifiers

**Expectation.**
For deterministic \(x\) independent of \(W\),
\[
\mathbb E\|F_W(x)\|^2=\frac{\alpha}{2}\|x\|^2.
\]
This does not survive adaptive maximization over \(x=x(W)\).

**High probability, fixed input.**
The growing-horizon theorem gives
\[
\|x_t\|=(\sqrt{\alpha/2}+o(1))^t\|x_0\|
\]
through the innovation horizon.

**Almost surely across widths.**
Summable width-\(N\) failure probabilities can be combined with Borel--Cantelli along a chosen width sequence.  This is not an infinite-time theorem at one fixed width.

**Uniform over all inputs, infinite time.**
Proved on the whole state space for
\[
\alpha<1/2.
\]
For \(1/2\le\alpha<2\), this run adds a uniform infinite-time theorem on the subclass of trajectories remaining below the explicit sparse support threshold.

**Uniform one-step contraction.**
Disproved w.h.p. for
\[
\alpha>0.7352559745708619\ldots.
\]

## 7. Failed routes / sharp obstructions

1. **Full-cone one-step contraction at \(\alpha=1\): DISPROVED.**
   P16-CONE-LB gives a \(W\)-dependent expanding direction.

2. **Uniform fresh-Gaussian radial law over \(W\)-dependent starts: DISPROVED.**
   The same one-step obstruction already violates it.

3. **No expanding rays implies collapse: DISPROVED as a deterministic implication.**
   The explicit period-two counterexample shows otherwise.

4. **A hidden permanently sparse subsystem can sustain a bad orbit: DISPROVED below the explicit sparse threshold.**
   P16-SPARSE-DYN rules it out w.h.p.

5. **Independent-layer LC transfers to tied weights: REJECTED.**
   Layerwise independence and sign-gauge freedom are lost.

6. **Tiny norm after \(cN\) steps implies future safety: REJECTED.**
   Positive homogeneity makes only relative future gains relevant.

7. **Full joint spectral radius over arbitrary masks: TOO PESSIMISTIC.**
   It allows mask sequences that ReLU dynamics cannot realize.

The remaining obstruction is therefore genuinely **dense, dynamically reachable, and recurrent**.

## 9. Next attack

The new theorem eliminates the sparse corner of the period-two problem.  The next attack should therefore parameterize dense supports by
\[
a=|S|/N,\qquad
b=|T|/N,\qquad
q=|S\cap T|/N
\]
and study
\[
y=P_TWx,\qquad
\lambda x=P_SWy,
\]
with positivity on \(S,T\), off-support sign constraints
\[
P_{T^c}Wx\le0,\qquad
P_{S^c}Wy\le0,
\]
and \(\lambda>1\).

Eliminating \(y\) gives
\[
P_SW P_TW P_Sx=\lambda x
\]
plus the coupled sign constraints.  The natural object is a complexity exponent
\[
\Sigma_\alpha(a,b,q;\lambda).
\]

The sparse theorem shows that a noncontracting two-cycle must leave every symmetric region
\[
a,b<\delta_{\rm sp}(\alpha).
\]
Thus the Kac--Rice/first-moment problem can be restricted to the genuinely dense regime.

There are two decisive outcomes:

1. an exponentially negative complexity exponent for every \(\alpha<2\), which removes the first genuinely recurrent obstruction; or
2. a positive complexity exponent at some \(\alpha<2\), which would be strong evidence that the strongest all-input tied-weight conjecture is false.

In parallel, any reachable-class proof should condition on active fraction.  The full dense cone is too large by P16-CONE-LB, while the sparse class is now controlled.  What remains is precisely the entropy of **dense dynamically reachable** directions.
