### Model A: tied weights / iterated random ReLU map — the P16 primary target

For width `N`,

\[
W_{ij}\stackrel{\rm iid}{\sim}N(0,\alpha/N),\qquad
F(x)=\operatorname{ReLU}(Wx),\qquad x_{t+1}=F(x_t),
\]

where the **same matrix W is reused at every time**. The July main note specializes mostly to `alpha=1`; I keep `alpha` explicit because the sharp radial threshold is `alpha=2`.

The desired strongest theorem is:

> For every `alpha<2`, with high probability over W, **every** starting vector satisfies exponential decay to zero under the tied iteration, at an asymptotic rate governed by `sqrt(alpha/2)` (or at least by some `rho(alpha)<1`).

This all-start infinite-time theorem is **not proved** in the July state.

What was proved in July for Model A:

- For every deterministic start independent of W and every **fixed** horizon T,
  \[
  \|x_t\|^2/\|x_0\|^2\to (\alpha/2)^t
  \]
  simultaneously for `t<=T`, with exponentially small width-N failure probability.
- The proof uses an exact adaptive Gaussian-innovation representation: Gram-Schmidt produces orthogonal query directions `v_j`, and the images `Wv_j` are fresh independent Gaussian vectors even though the directions are adaptively selected from previous images.
- For each fixed t, two trajectories have the arccosine-kernel overlap recursion; in the alpha=1 normalization the limiting angle obeys `theta_t ~ 3 pi/t`.
- For alpha=1, no exact ReLU ray has multiplier at least any fixed `r>1/sqrt(2)` with exponentially high probability, conditional on the real-Ginibre exterior-tail input derived in that note. Thus every trajectory whose normalized direction converges must eventually contract at every fixed rate `r>1/sqrt(2)`.
- The exact infinite-time obstruction is an invariant probability measure of the normalized dynamics with nonnegative average log-gain. Exact rays are only point-mass invariant measures; long cycles or wandering invariant measures remain possible.
- A one-step adapted sign estimate is insufficient because the same row of W is tested at many times; the missing proposed input is a genuine **multi-time adapted sign-decoupling** / low-Gaussian-width theorem for reachable state classes.

### Model B: independent layers / global Lipschitz constant — a separate solved July project

Here

\[
W_1,\ldots,W_L\text{ are independent},\qquad
(W_\ell)_{ij}\sim N(0,\alpha/n),
\]

and the network is

\[
x_\ell=\operatorname{ReLU}(W_\ell x_{\ell-1}).
\]

The July global-stability manuscript proves an all-input Euclidean Lipschitz threshold in the iterated limit: for fixed depth L first let `n->infinity`, define the largest alpha for which the global Lipschitz constant is <=1 with high probability, then let `L->infinity`. It proves

\[
\lim_{L\to\infty}\alpha_L=2,
\]

with the quantitative lower bound

\[
\alpha_L\ge 2\exp\left[-(\sqrt{10}+o(1))\sqrt{\frac{\log L}{L}}\right].
\]

This is a genuinely global all-input theorem, but it **does not imply** the tied-weight result. Its sign-gauge symmetry can flip rows/columns separately at each independent layer; that symmetry is unavailable when the same W must be reused at every time.

Roman Sarapin's July `Letter.pdf` concerns this independent-layer/global-Lipschitz line: it compares an actual Jacobian mask product with an independent Bernoulli-mask product and asks for the limiting top singular value. That issue is not the same as the tied recurrent problem.

## 2. New result: growing-horizon state evolution for a fixed start

The July tied-weight theorem states only fixed T. The innovation representation actually permits a much longer horizon once one replaces the fixed-dimensional uniform law of large numbers by a growing-dimensional net argument.

### Theorem P16.1 — growing-horizon norm law

Let

\[
W_{ij}\stackrel{\rm iid}{\sim}N(0,\alpha/N),\qquad
x_{t+1}=\operatorname{ReLU}(Wx_t),
\]

and let `x_0` be any deterministic nonzero vector, or a random vector independent of W. There are universal constants `c,C>0` such that for every integer `T<N` and every `0<epsilon<1/4`, if

\[
(T+1)\log(C/\epsilon)\le c\epsilon^2N,
\tag{1}
\]

then with probability at least

\[
1-2\exp\{-c\epsilon^2N+C(T+1)\log(C/\epsilon)\}-2e^{-cN},
\tag{2}
\]

simultaneously for every `0<=t<T`,

\[
\alpha\Big(\frac12-\epsilon\Big)
\le
\frac{\|x_{t+1}\|^2}{\|x_t\|^2}
\le
\alpha\Big(\frac12+\epsilon\Big).
\tag{3}
\]

In particular the good event prevents death before T, and

\[
\big[\alpha(1/2-\epsilon)\big]^{t/2}\|x_0\|
\le \|x_t\|
\le
\big[\alpha(1/2+\epsilon)\big]^{t/2}\|x_0\|.
\tag{4}
\]

Consequences:

- If `alpha<2`, choose epsilon with `alpha(1/2+epsilon)<1`. Then there is `c_alpha>0` and `rho_alpha<1` such that every fixed start contracts as
  \[
  \|x_t\|\le \rho_\alpha^t\|x_0\|,
  \qquad 0\le t\le c_\alpha N,
  \]
  with exponentially high probability.
- For the original alpha=1 model, for every fixed `eta>0` there is `c_eta>0` such that through `c_eta N` steps the contraction rate can be chosen at most `2^{-1/2}+eta`.
- If `alpha>2`, choose epsilon with `alpha(1/2-epsilon)>1`. Then every fixed start **grows** geometrically through `c_alpha N` steps with exponentially high probability. Thus the sharp threshold 2 persists to a linear-in-width horizon for fixed starts.
- More sharply, if `T=T_N` and one chooses epsilon_N so that
  \[
  T_N\log(C/\epsilon_N)=o(\epsilon_N^2N),
  \]
  then the per-step squared gain is uniformly `alpha/2+o_P(1)` through the entire growing horizon. For example any `T_N` satisfying `T_N log N=o(N)` admits epsilon_N->0. So the exact fresh-Gaussian rate survives far beyond fixed time.

### Proof

Normalize `\|x_0\|=1` by positive homogeneity. Put `K=T+1`.

Use the July Gram-Schmidt construction along the trajectory. Every time the span of `x_0,...,x_t` gains a dimension, append the normalized new orthogonal direction to an adaptive orthonormal list `v_1,v_2,...`. If fewer than K directions are generated by the trajectory, complete the list adaptively by any measurable orthonormal-completion rule. Since `K<=N`, the exact Gaussian-innovation lemma applies to all K probes:

\[
g_j:=Wv_j,\qquad j=1,\ldots,K,
\]

are independent `N(0,alpha I_N/N)` vectors.

Define the N-by-K matrix G by rows

\[
G_i=\sqrt{N/\alpha}\,(g_{1i},\ldots,g_{Ki}).
\]

Then the rows `G_i` are iid `N(0,I_K)`.

For each time `t<T`, expand

\[
x_t=\sum_{j=1}^K c_{t,j}v_j.
\]

Parseval gives `\|c_t\|=\|x_t\|`, and coordinatewise

\[
(Wx_t)_i=\sqrt{\alpha/N}\,G_i\cdot c_t.
\]

Therefore, whenever `x_t!=0`, with `u_t=c_t/\|c_t\|`,

\[
\frac{\|x_{t+1}\|^2}{\|x_t\|^2}
=
\alpha Q_G(u_t),
\qquad
Q_G(u):=\frac1N\sum_{i=1}^N(G_i\cdot u)_+^2.
\tag{5}
\]

The crucial point is that `u_t` may depend arbitrarily on the entire Gaussian data already generated. We therefore control `Q_G(u)` **uniformly over every unit vector u in R^K**.

For one fixed unit u, `(G_i\cdot u)_+^2` are iid with mean 1/2 and a universal subexponential norm. Bernstein gives

\[
P\{|Q_G(u)-1/2|>\epsilon/4\}
\le 2e^{-c\epsilon^2N}.
\tag{6}
\]

Take a delta-net `N_delta` of the unit sphere in `R^K`, with

\[
|N_\delta|\le (C/\delta)^K.
\]

A union bound gives the desired estimate on all net points at cost

\[
\exp\{CK\log(C/\delta)-c\epsilon^2N\}.
\]

To pass from the net to the full sphere, note the exact Lipschitz estimate

\[
|\sqrt{Q_G(u)}-\sqrt{Q_G(v)}|
\le \frac{\|G\|_{op}}{\sqrt N}\|u-v\|.
\tag{7}
\]

This follows because coordinatewise ReLU is 1-Lipschitz. A standard Gaussian matrix net bound gives

\[
P\{\|G\|_{op}>C\sqrt N\}\le 2e^{-cN}
\]

uniformly for `K<=N`. Choose `delta=c_0 epsilon`. On this operator-norm event, (7) transfers the epsilon/4 bound from the net to an epsilon bound over the whole sphere. This proves

\[
\sup_{\|u\|=1}|Q_G(u)-1/2|\le\epsilon
\tag{8}
\]

with probability (2), under condition (1).

Finally substitute the adaptive direction `u_t` into (8) in the exact identity (5), simultaneously for every `t<T`. This proves (3) and (4).

**Why this is not circular:** the uniform event (8) is a statement about the entire K-dimensional coefficient sphere after the innovation matrix has been generated. It does not require the trajectory coefficients to be independent of G.

## 3. Almost-every-input and almost-sure corollaries

The failure bound in Theorem P16.1 is uniform over every deterministic start. Therefore, for any probability measure `mu_N` on the unit sphere independent of W, Fubini gives

\[
E_W\,\mu_N(\text{bad starts})\le p_N,
\]

where `p_N` is the failure probability in (2). Markov then gives

\[
P_W\{\mu_N(\text{bad starts})>\sqrt{p_N}\}\le\sqrt{p_N}.
\]

Thus the growing-horizon theorem also holds for all but an exponentially small `mu_N`-mass of inputs, with exponentially high probability over W.

If one considers any sequence of widths N and deterministic starts, and chooses parameters so that the failure probabilities are summable in N (for example fixed epsilon and `T<=cN` with a strict exponent margin), then the first Borel-Cantelli lemma implies that the growing-horizon bound holds eventually almost surely across the width sequence. This is an almost-sure **large-width statement**, not an infinite-time statement at one fixed width.

## 4. Prior uniform tied-weight result: rigorous alpha<1/2 cone contraction

The older June tied-weight manuscript records a complete global result for `alpha<1/2`. It can be re-derived directly.

After the first step every nonzero trajectory lies in the nonnegative cone. Define

\[
M_+(W)=\sup_{u\ge0,\|u\|=1}\|\operatorname{ReLU}(Wu)\|.
\]

Because the output is nonnegative,

\[
M_+(W)=\sup_{u,v\in S_+^{N-1}}v^TWu.
\]

This is the supremum of a centered Gaussian process. For `X_{u,v}=v^TWu`,

\[
E(X_{u,v}-X_{u',v'})^2
=\frac\alpha N\big(2-2\langle u,u'\rangle\langle v,v'\rangle\big).
\]

Compare with

\[
Y_{u,v}=\sqrt{\alpha/N}(g\cdot u+h\cdot v),
\]

for independent standard Gaussian g,h. Since

\[
2-2ab\le (2-2a)+(2-2b)
\]

for `a,b<=1`, Sudakov-Fernique gives

\[
E M_+(W)
\le
\sqrt{\alpha/N}\big(E\|g_+\|+E\|h_+\|\big)
\le \sqrt{2\alpha}+o(1).
\]

Gaussian concentration then gives

\[
M_+(W)\le \sqrt{2\alpha}+o(1)
\]

with exponentially high probability. Hence if `alpha<1/2`, there is `rho<1` such that with high probability

\[
\|F(x)\|\le\rho\|x\|\qquad\forall x\ge0.
\]

Since the first ReLU step enters the cone, every trajectory then decays geometrically. This is genuinely uniform over all inputs and infinite time, but its threshold `alpha<1/2` is far below the conjectured sharp value 2.

At alpha=1, this one-step cone norm is not contractive: the comparison scale is about `sqrt 2>1`. Thus the alpha=1 theorem must exploit **multi-step dynamical structure**, not a deterministic one-step Lipschitz estimate.

## 5. What remains open after the new theorem

The new linear/growing-horizon theorem does **not** prove the desired infinite-time tied-weight result. There are two sharp reasons.

### 5.1 The innovation budget is finite

Every genuinely new orthogonal query consumes one input-space dimension. After at most N independent orthogonal probes, the matrix has been fully exposed. The proof above can control a growing horizon while the coefficient sphere has dimension sufficiently smaller than the sample size N; it cannot supply fresh randomness forever.

### 5.2 Small norm does not imply permanent collapse

At time `cN`, Theorem P16.1 makes `\|x_t\|` exponentially small in N for alpha<2. But the map is positively homogeneous. A later normalized direction with gain >1 can amplify the norm by the same relative factor regardless of its absolute size. Therefore “the norm is already tiny” is not an infinite-time argument.

The exact remaining obstruction is the one isolated in the July note:

\[
\log\rho_+
=
\sup_{\mu:\,F_\#\mu=\mu}
\int\log g(u)\,d\mu(u),
\]

where `F(u)=ReLU(Wu)/\|ReLU(Wu)\|` is the normalized map and `g(u)=\|ReLU(Wu)\|`. To prove global collapse it suffices and is essentially necessary to rule out **every** invariant measure with nonnegative mean log-gain. The no-ray theorem only rules out fixed-point measures. Long periodic or nonperiodic invariant measures are the unresolved cases.

The multitime sign-decoupling conjecture in the July note is one sufficient route. A potentially cleaner next route suggested by the new theorem is:

> prove that the **reachable coefficient class**, rather than the full coefficient sphere, has Gaussian width `o(sqrt N)` after a moderate number of steps.

Theorem P16.1 uses a full K-dimensional sphere net and therefore pays entropy `exp(CK)`. Any dynamical compression of the reachable coefficient set would allow substantially larger horizons and could connect to the July synchronization-plus-ray-gap criterion.

## 6. Expectation / high probability / almost sure / uniform-over-input status

These notions are now separated explicitly.

- **Expectation:** for one deterministic input at the first step,
  \[
  E\|x_1\|^2=(\alpha/2)\|x_0\|^2.
  \]
  Because W is reused, an exact multiplicative expectation identity for all later times is not available by simple conditioning. The new result is high-probability, not an expectation theorem.
- **High probability, fixed input:** PROVED here through horizons satisfying (1), including `T=cN` for sufficiently small c and fixed contraction margin.
- **High probability, almost every input:** PROVED by Fubini/Markov from the same bound.
- **Almost surely across widths:** follows by Borel-Cantelli whenever the chosen sequence has summable failure probabilities.
- **Uniform over every input, infinite time:** PROVED only in the conservative tied range `alpha<1/2`; OPEN for `1/2<=alpha<2`, including the intended alpha=1 case.
- **Independent-layer global Lipschitz problem:** sharp threshold tends to 2 in the iterated `(n then L)` limit; this is a separate model and cannot be used as a proof of the tied result.

## 7. Failed / rejected shortcuts

1. **Treating tied layers as independent.** Invalid after time one; the same W creates maximal dependence.
2. **Using the independent-layer global-Lipschitz theorem for the tied model.** Invalid because the layerwise sign-gauge group is lost when all layers share W.
3. **A one-step global operator norm bound.** At alpha=1, `\|W\|` is about 2 and the positive-cone ReLU norm is on the `sqrt 2` scale; neither is contractive.
4. **Multiplying one-step sign probabilities over time.** Invalid because each row is reused and the rowwise Gaussian sign tests are correlated across times.
5. **No expanding rays implies global collapse.** False as a logical inference: cycles and wandering invariant measures remain.
6. **Exponentially small norm at a large finite time implies convergence to zero forever.** Invalid by positive homogeneity; only relative gains matter.
7. **Fixed-time arccosine synchronization implies uniform synchronization of all starts.** Not justified; the fixed-pair theorem does not control W-dependent exceptional starts.

## 10. Best next attack

The best next theorem-sized target is no longer the old fixed-T state evolution. It is:

> **Reachable-class entropy/width theorem.** Prove that after `t_0=t_0(alpha)` steps, the normalized reachable class
> \[
> K_t(W)=\{F^t(x)/\|F^t(x)\|:x\ne0,F^t(x)\ne0\}

> has Gaussian width small enough, uniformly for a fixed block of later times, to support a multitime row-exposure estimate whose entropy cost is below the half-support sign budget.

A concrete intermediate target is to prove, for a fixed small block length m and alpha=1, that every sign-feasible block with geometric mean gain at least one has either (a) consecutive normalized directions bounded away from parallel, which yields a genuine multivariate orthant cost, or (b) lies within a quantitative near-ray tube, which can be excluded by a strengthened version of the no-ray argument. This directly attacks the invariant-measure obstruction rather than repeating finite-horizon state evolution.
