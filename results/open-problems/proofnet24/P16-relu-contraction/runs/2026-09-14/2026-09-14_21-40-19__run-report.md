### `P16-CYCLE2-APPROXRAY-09` — NEW / PROVED

Every exact projective period-two orbit canonically produces a **ReLU approximate eigenray**.  If

\[
(Au)_+=g\,v,\qquad
(Av)_+=h\,u,
\qquad g,h>0,
\]

with unit \(u,v\ge0\), supports \(T=\operatorname{supp}u\), \(S=\operatorname{supp}v\), and

\[
r=\sqrt{gh},
\qquad
w=\sqrt h\,u+\sqrt g\,v,
\]

then

\[
0\le (Aw)_+\le r w
\]

coordinatewise,

\[
(Aw)_i^+=r w_i
\qquad(i\in S\cap T),
\]

and

\[
\boxed{
\frac{\|(Aw)_+-rw\|}{r\|w\|}
\le
\left[
\frac{
h\|u_{T\setminus S}\|^2
+
g\|v_{S\setminus T}\|^2
}{
g+h+2\sqrt{gh}\,\langle u,v\rangle
}
\right]^{1/2}.
}
\tag{AR1}
\]

In particular, if

\[
\vartheta=\langle u_{S\cap T},v_{S\cap T}\rangle=\langle u,v\rangle,
\]

then

\[
\boxed{
\frac{\|(Aw)_+-rw\|}{r\|w\|}
\le
\sqrt{1-\vartheta^2}.
}
\tag{AR2}
\]

For \(W=\sqrt\alpha A\), the same normalized ray defect holds with target multiplier

\[
r_W=\sqrt{\alpha gh}.
\]

Thus any noncontracting two-cycle, for which \(\alpha gh\ge1\), and whose overlap mass satisfies \(\vartheta\approx1\), produces an approximate ReLU eigenray with multiplier at least one and vanishing relative defect.

### `P16-CYCLE2-EQUALSUPPORT-09` — NEW / PROVED

If an exact two-cycle has

\[
S=T,
\]

then the approximate ray above is exact:

\[
\boxed{
(Aw)_+=\sqrt{gh}\,w.
}
\]

Therefore, for every fixed \(\alpha<2\), the inherited no-large-ray theorem implies that with high probability there is **no noncontracting exact period-two cycle with equal consecutive supports**.

So a surviving noncontracting period-two obstruction for \(\alpha<2\) must have a nonempty support symmetric difference.

\Gamma_\alpha(s,t)

\left[

# 5. Proof of `P16-CYCLE2-APPROXRAY-09`

Let

\[
u,v\ge0,
\qquad
\|u\|=\|v\|=1,
\]

and suppose

\[
(Au)_+=g v,
\qquad
(Av)_+=h u,
\qquad
g,h>0.
\]

Put

\[
T=\operatorname{supp}u,
\qquad
S=\operatorname{supp}v,
\qquad
I=S\cap T,
\]

\[
r=\sqrt{gh},
\qquad
w=\sqrt h\,u+\sqrt g\,v.
\]

We inspect coordinates.

## 5.1 On the overlap

If \(i\in I\), both \(u_i,v_i>0\), so both active equations are strictly active:

\[
(Au)_i=g v_i,
\qquad
(Av)_i=h u_i.
\]

Therefore

\[
\begin{aligned}
(Aw)_i
&=
\sqrt h\,(Au)_i
+
\sqrt g\,(Av)_i\\
&=
\sqrt h\,g v_i
+
\sqrt g\,h u_i\\
&=
\sqrt{gh}
\left(
\sqrt g\,v_i
+
\sqrt h\,u_i
\right)\\
&=
r w_i.
\end{aligned}
\]

In particular this coordinate is positive and

\[
(Aw)_i^+=r w_i.
\]

## 5.2 On \(S\setminus T\)

Here

\[
v_i>0,\qquad u_i=0.
\]

The first cycle equation gives

\[
(Au)_i=g v_i>0.
\]

The second gives

\[
(Av)_i\le0
\]

because the output support of \((Av)_+\) is \(T\), which does not contain \(i\).

Therefore

\[
(Aw)_i
=
\sqrt h\,g v_i
+
\sqrt g\,(Av)_i
\le
\sqrt h\,g v_i.
\]

But

\[
w_i=\sqrt g\,v_i
\]

and

\[
r w_i
=
\sqrt{gh}\sqrt g\,v_i
=
g\sqrt h\,v_i.
\]

Hence

\[
0
\le
(Aw)_i^+
\le
r w_i.
\]

## 5.3 On \(T\setminus S\)

The same argument with \(u,v\) interchanged gives

\[
0
\le
(Aw)_i^+
\le
r w_i.
\]

## 5.4 Outside the union

If

\[
i\notin S\cup T,
\]

then

\[
(Au)_i\le0,
\qquad
(Av)_i\le0.
\]

Thus

\[
(Aw)_i\le0
\]

and

\[
(Aw)_i^+=0=r w_i.
\]

Combining the four regions,

\[
\boxed{
0\le(Aw)_+\le r w
}
\]

coordinatewise, with equality on the overlap and outside the support union.

Therefore the defect is supported on the symmetric difference

\[
D=S\triangle T
\]

and

\[
\|(Aw)_+-rw\|
\le
r\|w_D\|.
\]

Now

\[
\|w_D\|^2
=
h\|u_{T\setminus S}\|^2
+
g\|v_{S\setminus T}\|^2.
\]

Also

\[
\|w\|^2
=
g+h+2\sqrt{gh}\langle u,v\rangle.
\]

This proves (AR1).

For the simpler overlap-mass bound, put

\[
\vartheta=\langle u_I,v_I\rangle.
\]

Since \(u,v\ge0\) and their supports overlap only on \(I\),

\[
\langle u,v\rangle=\vartheta.
\]

Cauchy--Schwarz gives

\[
\vartheta
\le
\|u_I\|\|v_I\|.
\]

Because both overlap norms are at most one,

\[
\|u_I\|\ge\vartheta,
\qquad
\|v_I\|\ge\vartheta.
\]

Hence

\[
\|u_{T\setminus S}\|^2
=
1-\|u_I\|^2
\le
1-\vartheta^2,
\]

and similarly

\[
\|v_{S\setminus T}\|^2
\le
1-\vartheta^2.
\]

Thus

\[
\|w_D\|^2
\le
(g+h)(1-\vartheta^2).
\]

Since

\[
\|w\|^2
=
g+h+2r\vartheta
\ge
g+h,
\]

we obtain

\[
\frac{\|(Aw)_+-rw\|}{r\|w\|}
\le
\sqrt{1-\vartheta^2}.
\]

This proves (AR2).

Finally, for

\[
W=\sqrt\alpha A,
\]

positive homogeneity gives

\[
F_W(w)=\sqrt\alpha\,F_A(w),
\]

so the target ray multiplier is

\[
\sqrt\alpha\,r
=
\sqrt{\alpha gh}
\]

and the relative defect is unchanged.

QED.

# 8. Proof of `P16-CYCLE2-TYPE-SPECTRAL-09`

Fix nonempty supports \(S,T\).

Put

\[
G=A_{S,T},
\qquad
H=A_{T,S}.
\]

Even when \(S\cap T\ne\varnothing\), each block marginally has iid \(N(0,1/N)\) entries.

The two blocks may share entries; no independence between \(G\) and \(H\) is used.

Every exact two-cycle satisfies

\[
HG\,u_T
=
(gh)u_T.
\]

Therefore

\[
gh
\le
\|H\|\,\|G\|.
\]

A noncontracting \(W=\sqrt\alpha A\) two-cycle requires

\[
gh\ge1/\alpha.
\]

Hence at least one block must satisfy

\[
\|G\|\ge\alpha^{-1/2}
\quad\text{or}\quad
\|H\|\ge\alpha^{-1/2}.
\]

Let

\[
s=|S|/N,
\qquad
t=|T|/N.
\]

For an \(|S|\times|T|\) Gaussian block with variance \(1/N\), the standard Gaussian rectangular norm bound gives

\[
P\left\{
\|G\|
\ge
\sqrt s+\sqrt t+u
\right\}
\le
\exp(-Nu^2/2),
\qquad
u\ge0.
\]

The same marginal bound holds for \(H\).

Therefore, without assuming independence,

\[
\boxed{
P\left\{
\|H\|\|G\|\ge1/\alpha
\right\}
\le
2\exp\left[
-\frac N2
\Gamma_\alpha(s,t)^2
\right].
}
\tag{8.1}
\]

Now incorporate the exact tied-weight sign symmetry from `P16-CYCLE2-ENTROPY-08`.

For fixed supports, the number of internal algebraic projective candidate lines is at most

\[
N.
\]

Simultaneous diagonal sign conjugation on the support union has effective orbit size

\[
2^{m-1},
\qquad
m=|S\cup T|.
\]

The radial spectral event

\[
gh\ge1/\alpha
\]

is invariant under this conjugation.

Hence the expected number of **internally positive** candidate lines satisfying the radial threshold is at most
