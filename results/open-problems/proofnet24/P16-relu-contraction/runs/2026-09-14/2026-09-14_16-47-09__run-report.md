# 5. Deterministic best-response monotonicity

This simple point had not yet been entered as a named theorem.

For any deterministic real matrix \(A\), define, whenever the positive parts are nonzero,
\[
v_k
=
\frac{(Au_k)_+}{\|(Au_k)_+\|},
\]
\[
u_{k+1}
=
\frac{(A^\top v_k)_+}{\|(A^\top v_k)_+\|}.
\]

Put
\[
s_k=\|(Au_k)_+\|,
\qquad
d_k=\|(A^\top v_k)_+\|.
\]

Then
\[
s_k=v_k^\top Au_k.
\]

Because \(u_{k+1}\) maximizes
\[
x\mapsto v_k^\top Ax
\]
over the nonnegative unit sphere,
\[
d_k
=
v_k^\top Au_{k+1}
\ge
v_k^\top Au_k
=
s_k.
\]

Likewise, because \(v_{k+1}\) maximizes
\[
y\mapsto y^\top Au_{k+1}
\]
over the nonnegative unit sphere,
\[
s_{k+1}
=
v_{k+1}^\top Au_{k+1}
\ge
v_k^\top Au_{k+1}
=
d_k.
\]

Therefore:

### P16-BESTRESP-MONO — PROVED

\[
\boxed{
s_0\le d_0\le s_1\le d_1\le s_2\le\cdots\le M_+(A).
}
\tag{P16-BESTRESP-MONO}
\]

At every finite \(N\), alternating positive best response is a monotone lower-bound algorithm for \(M_+(A)\).

This does **not** prove that its limit equals \(M_+(A)\); nonconvex alternating maximization can in principle stop at a suboptimal stationary point.

For the diagonal part, truncate

For unit \(q\),

\[

\le

Thus
\[

is uniformly integrable over all dimensions and unit coefficient vectors.

### Final ratio step

Let
\[
a_k=\sqrt{d_k},
\]
and
\[
G_k=\{S\le(1+a_k)k\}.

Markov gives

Uniform integrability gives
