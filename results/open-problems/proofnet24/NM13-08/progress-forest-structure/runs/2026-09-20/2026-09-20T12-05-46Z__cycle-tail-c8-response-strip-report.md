## 3. Retained five-state response algebra

Fix three independent terminals `0,1,2`. Their connectivity has five partitions

\[
0|1|2,\qquad 0|12,\qquad 01|2,\qquad 02|1,\qquad 012.
\]

For one fresh right vertex adjacent to all three terminals, the exact transfer is

\[
S=4I+N,\qquad N^3=0,\quad N^2\ne0.
\]

Every unmarked path/cycle atom used below has an exact transfer

\[
T=A I+B N+C N^2,
\]

with `A>0`. Normalize it as

\[
\widehat T=I+aN+cN^2,\qquad a=B/A,\quad c=C/A,
\]

and define

\[
\rho(T)=\frac{a^2/2-c}{a}.
\]

For arbitrary normalized unmarked atoms,

\[
\prod_j(I+a_jN+c_jN^2)=I+uN+vN^2,
\]

where

\[
u=\sum_j a_j,
\qquad
v=\sum_jc_j+\sum_{i<j}a_ia_j.
\]

Therefore

\[
\frac{u^2}{2}-v=\sum_j\left(\frac{a_j^2}{2}-c_j\right)
                =\sum_j\rho_j a_j.
\]

If `u>0`,

\[
\boxed{v=\frac{u^2}{2}-hu,\qquad
h=\frac{\sum_j\rho_j a_j}{\sum_j a_j}},
\]

so `h` is a positive weighted average of the individual atom responses. This retained identity is the bridge from finite local atom checks to arbitrary multiplicities.

## 4. New decomposition lemma: the 52-state cycle-tail annihilator

A right cycle differs from a path because the last right vertex must eventually be tested against the first. During construction keep the frontier

\[
(0,1,2,x_0,x),
\]

consisting of the three terminals, the first cycle vertex `x_0`, and the current endpoint `x`. Connectivity of these five frontier vertices has exactly the Bell number

\[
B_5=52
\]

states.

One unmarked extension step introduces a fresh vertex `y`, considers the four possible new edges

\[
xy,\ y0,\ y1,\ y2,
\]

rejects any chosen subset that joins vertices already connected in the incoming partition, and then forgets `x`. This defines an exact integer `52 x 52` transfer matrix `E`.

Set

\[
p(\lambda)=(\lambda-1)(\lambda^2-6\lambda+2)
           =\lambda^3-7\lambda^2+8\lambda-2.
\]

### Lemma `T07-CYCLE-TAIL-ANNIHILATOR-22`

The exact cycle-tail extension operator satisfies

\[
\boxed{p(E)^3=0}.
\]

Moreover

\[
\operatorname{rank}p(E)=20,\qquad
\operatorname{rank}p(E)^2=5,
\qquad
\operatorname{rank}p(E)^3=0.
\]

For `n>=3`, write the unmarked right-cycle transfer as

\[
T_{C_n}=A_nI+B_nN+C_nN^2.
\]

Then

\[
\boxed{A_n=7A_{n-1}-8A_{n-2}+2A_{n-3}}
\tag{4.1}
\]

for all `n>=6`,

\[
\boxed{B_n=14B_{n-1}-65B_{n-2}+116B_{n-3}-92B_{n-4}
+32B_{n-5}-4B_{n-6}}
\tag{4.2}
\]

for all `n>=9`, and

\[
\boxed{\begin{aligned}
C_n={}&21C_{n-1}-171C_{n-2}+685C_{n-3}-1452C_{n-4}
+1734C_{n-5}\\
&-1196C_{n-6}+468C_{n-7}-96C_{n-8}+8C_{n-9}
\end{aligned}}
\tag{4.3}
\]

for all `n>=12`.

### Proof

The checker constructs all 52 partitions and every extension entry by exact acyclicity enumeration. Direct exact matrix arithmetic gives the three displayed ranks and `p(E)^3=0`.

There are fixed start and close maps `R,C` such that

\[
T_{C_n}=R E^{n-2}C,
\]

because the start map creates the first two right vertices while retaining `x_0`, each subsequent right vertex uses exactly the same operator `E`, and the close map tests the final edge back to `x_0` and forgets both right frontier vertices. Consequently every matrix entry of `T_{C_n}`, and every linear functional of its entries, satisfies the order-nine recurrence with characteristic polynomial `p^3`.

The coefficients `A_n,B_n,C_n` are linear functionals of the transfer:

\[
A_n=(T_{C_n})_{00},\quad
B_n=(T_{C_n})_{01},\quad
C_n=\frac{(T_{C_n})_{04}-B_n}{6}.
\]

Thus all three satisfy the `p^3` recurrence. For `A_n`, the residual of the shorter `p` recurrence is itself a matrix-coefficient sequence for powers of `E`, hence also satisfies `p^3`; the checker verifies nine consecutive exact zero residuals (`n=6,...,14`), which forces all later residuals to vanish. The same argument with `p^2` for `B_n` uses nine consecutive zero residuals (`n=9,...,17`). Equation (4.3) is the direct `p^3` recurrence. This proves (4.1)–(4.3). QED.

This lemma is an all-cycle-length structural statement, not a finite `C_8` interpolation.

## 6. Local-to-global atom-admission lemma

The response-strip argument used in preceding runs can be stated as the following closure lemma.

### Lemma `T07-FINITE-ATOM-STRIP-ADMISSION-22`

Let `L` be a finite collection of three-terminal right atoms with fresh, pairwise disjoint interiors. Suppose each unmarked atom has normalized transfer `I+aN+cN^2` with `a>0` and response `rho` in a common interval `[alpha,beta]`. For every edge pair type supported on one or two exposed atoms, form the exact Rayleigh response polynomial `Q_tau(u,v)` obtained after replacing every other atom by the generic unmarked response `U(u,v)=I+uN+vN^2`.

If

\[
Q_\tau\!\left(u,\frac{u^2}{2}-hu\right)\ge0
\]

for every `u>=0`, every `h in [alpha,beta]`, and every local type `tau`, then the graph formed from three independent terminals joined to an arbitrary disjoint union of atoms from `L` is pairwise negatively correlated under the uniform-all-forests law. If all local inequalities are strict except a listed boundary case, the global theorem has exactly those inherited equality cases.

### Proof

Fix two present edges `e,f`. They meet at most two right components; expose those components completely, using the appropriate exact transfer matrices with `e`, `f`, or both required. Every other component is unmarked. Pulling out the positive product of their scalar factors `A_j`, their normalized product is `U(u,v)` and (by the weighted-average identity) lies in the strip `[alpha,beta]`.

For each of the four counts `I,I_e,I_f,I_ef`, the exposed marked part gives a fixed row vector `r_X`, so, up to the same positive scalar,

\[
I_X=r_XU(u,v)\mathbf1.
\]

Because `U` is affine in `(u,v)`, each count is affine in `(u,v)`, and therefore the Rayleigh numerator is a quadratic `Q_tau(u,v)`. Multiplying back the common scalar multiplies the Rayleigh numerator by its positive square, so its sign is unchanged. The assumed local strip inequality therefore proves the global inequality for arbitrary component multiplicities. QED.

The lemma is a genuine transfer: the local list is finite, while the multiplicities are unbounded.

\[
