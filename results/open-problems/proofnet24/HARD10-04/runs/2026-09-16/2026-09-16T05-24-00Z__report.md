## 0. Exact target and result of this iteration

For standard external site diffusion-limited aggregation on \(\mathbb Z^2\), start from \(A_1=\{0\}\), let
\[
K_n:=\overline A_n=A_n\cup\partial A_n,
\qquad
p_n(x):=\omega(x,K_n),
\qquad
R_n:=\max_{x\in A_n}|x|_2,
\]
and attach \(X_{n+1}\in\partial A_n\) with conditional law \(p_n\), using the same first-hit convention pinned in the preceding HARD10-04 checkpoints.

The full target remains **OPEN**. This report does not prove almost-sure convergence of
\[
\frac{\log R_n}{\log n},
\]
does not determine a deterministic exponent \(\beta\), and does not rigorously refute existence or determinism.

This iteration advances the spatial-renormalization route suggested by the preceding checkpoint. There are two main new results.

### Main conclusion A — pathwise spatial diversification of actual capacity

On every sufficiently large unit-capacity block beginning at radius \(R_j\), if the lattice is partitioned into square boxes of side \(L_j\), then **any collection of boxes carrying a fixed positive fraction of the actual capacity increment must contain at least order \(R_j/L_j^2\) distinct boxes**. Equivalently, the normalized actual-capacity distribution on \(L_j\)-boxes has min-entropy, Shannon entropy, and every fixed Rényi effective support bounded below by
\[
\log\frac{R_j}{L_j^2}-O(1).
\]
In particular, for every fixed \(\alpha<1/2\), at scale \(L_j=R_j^\alpha\), a unit of logarithmic capacity is forced to use at least
\[
R_j^{1-2\alpha+o(1)}
\]
spatial boxes. This is an actual-path statement, not merely a predictable-drift or expected-value statement.

### Main conclusion B — mesoscopic non-return for the actual particle sequence

Fix integers \(H_j,L_j\ge1\) known at the start of a unit-capacity block. For each particle attached during the block, ask whether any of the next \(H_j\) particles returns within Euclidean distance \(L_j\) of that particle. Let \(V_j(H_j,L_j)\) be the number of such quick-return starts and \(N_j\) the number of particles in the block. Then almost surely eventually
\[
\frac{V_j(H_j,L_j)}{N_j}
\le
C\,H_j(L_j+1)^2R_j^{-1/2}
+
C\,\frac{H_j\log R_j}{R_j^{3/2}}.
\]
Consequently, whenever
\[
H_j(L_j+1)^2=o(R_j^{1/2}),
\]
we have
\[
\boxed{
\frac{V_j(H_j,L_j)}{N_j}\longrightarrow0
\quad\text{a.s.}
}
\]
Thus almost every actual particle creates a mesoscopic neighborhood that is not revisited for a polynomial number of subsequent particle additions throughout a large range of space-time scales.

Two useful specializations are:

1. For every fixed \(\varepsilon>0\),
   \[
   \frac1{N_j}
   \#\left\{n\in B_j:
   |X_{n+2}-X_{n+1}|\le R_j^{1/4-\varepsilon}
   \right\}
   \longrightarrow0.
   \]
   So **almost every pair of consecutive attachments is separated by at least \(R_j^{1/4-\varepsilon}\)**, not only the direct-genealogy bursts considered in the preceding checkpoint.

2. For every fixed \(\varepsilon>0\), taking
   \[
   L_j=R_j^{1/8-\varepsilon},
   \qquad
   H_j=R_j^{1/4-\varepsilon}
   \]
   gives
   \[
   H_jL_j^2=R_j^{1/2-3\varepsilon},
   \]
   hence, for asymptotically almost every particle attached in the block, its \(R_j^{1/8-\varepsilon}\)-neighborhood is avoided by the next \(R_j^{1/4-\varepsilon}\) particles.

These theorems give genuine spatial diversification and a space-time refractory property for standard planar external site DLA. They still do **not** prove morphological independence: visits to many boxes may remain correlated through old arms/fjords, and the box-capacity entropy lower bound does not yet identify the cubic-moment exponent.

All new arguments are given below. They use only previously archived exact local-capacity response, the planar pointwise Beurling estimate, the local Kesten particle-count bound, and bounded exponential-supermartingale arguments. They are self-reviewed, not independently refereed or formally verified.

# 4. A pathwise cardinality-capacity inequality

The simplest new observation is that the capacity created in a spatial set is bounded by the number of lattice sites available in that set.

Let \(D\subset\mathbb Z^2\) be any finite set. It may be deterministic or \(\mathcal F_{\sigma_j}\)-measurable. Define the actual capacity created by particles attached in \(D\) during block \(j\):
\[
\Gamma_j(D)
:=
\sum_{n\in B_j}
\Delta_{n+1}\,
\mathbf1_{\{X_{n+1}\in D\}}.
\tag{4.1}
\]

Because DLA never attaches to the same lattice site twice,
\[
\#\{n\in B_j:X_{n+1}\in D\}\le |D|.
\tag{4.2}
\]
By (3.3) and (3.7), each such selected site contributes at most \(C/R_j\) capacity. Therefore, pathwise,
\[
\boxed{
\Gamma_j(D)
\le
C\frac{|D|}{R_j}.
}
\tag{4.3}
\]

No expectation, martingale argument, or independence enters (4.3).

### Consequence 4.1 — any positive capacity share requires linearly many sites

Suppose a set \(D\) carries at least an \(\eta\)-fraction of the block capacity:
\[
\Gamma_j(D)
\ge
\eta\bigl(C_{\sigma_{j+1}}-C_{\sigma_j}\bigr).
\]
Using (3.5), for fixed \(\eta>0\) and all large \(j\),
\[
\Gamma_j(D)\ge \eta/2.
\]
Then (4.3) forces
\[
\boxed{
|D|\ge c\eta R_j.
}
\tag{4.4}
\]

Thus actual logarithmic capacity cannot be generated by a spatial support containing \(o(R_j)\) lattice sites.

This strengthens, in an actual-path form, the earlier predictable turnover principle. It also immediately gives a pathwise deep-core bound: for a disk \(B(0,s)\),
\[
\boxed{
\Gamma_j(B(0,s))
\le
C\frac{s^2+1}{R_j}.
}
\tag{4.5}
\]
Hence for any \(s_j=o(R_j^{1/2})\),
\[
\Gamma_j(B(0,s_j))\to0
\qquad\text{a.s.}
\tag{4.6}
\]
This recovers the earlier deep-core exclusion for actual capacity without passing through capacity-Palm expectation.

# 5. Mesoscopic box diversification of actual capacity

Fix an integer box side length \(L\ge1\). Partition \(\mathbb Z^2\) into half-open lattice squares
\[
Q_{a,b}^{(L)}
=
([aL,(a+1)L)\times[bL,(b+1)L))\cap\mathbb Z^2,
\qquad(a,b)\in\mathbb Z^2.
\tag{5.1}
\]
Each box contains at most \(C(L+1)^2\) lattice sites.

For block \(j\), define
\[
\Gamma_{j,Q}
:=
\sum_{n\in B_j}
\Delta_{n+1}\mathbf1_{\{X_{n+1}\in Q\}}.
\tag{5.2}
\]
Equation (4.3) gives uniformly over every box
\[
\boxed{
\Gamma_{j,Q}
\le
C\frac{(L+1)^2}{R_j}.
}
\tag{5.3}
\]

The box masses sum to the actual block capacity:
\[
\sum_Q\Gamma_{j,Q}
=
C_{\sigma_{j+1}}-C_{\sigma_j}
=1+o(1).
\tag{5.4}
\]

## 5.1 Number of boxes needed to carry a fixed capacity fraction

Let \(\mathcal Q\) be any collection of \(L\)-boxes. By (5.3),
\[
\sum_{Q\in\mathcal Q}\Gamma_{j,Q}
\le
C\,|\mathcal Q|\frac{(L+1)^2}{R_j}.
\tag{5.5}
\]
Thus if \(\mathcal Q\) carries at least an \(\eta\)-fraction of the block capacity, then for all large \(j\),
\[
\boxed{
|\mathcal Q|
\ge
c\eta\frac{R_j}{(L+1)^2}.
}
\tag{5.6}
\]

In particular, the total number of boxes receiving any positive capacity satisfies
\[
\boxed{
N_{\rm box}(j,L)
\ge
c\frac{R_j}{(L+1)^2}.
}
\tag{5.7}
\]

For \(L_j=R_j^\alpha\) with \(0\le\alpha<1/2\),
\[
\boxed{
N_{\rm box}(j,L_j)
\ge
R_j^{1-2\alpha+o(1)}.
}
\tag{5.8}
\]

Examples:

- at fixed lattice scale \(L=O(1)\), at least \(\Omega(R_j)\) distinct boxes are needed;
- at the preceding run's switch scale \(L=R_j^{1/4-\varepsilon}\), at least
  \[
  \Omega(R_j^{1/2+2\varepsilon})
  \]
  distinct boxes are needed to carry the block capacity;
- even at the much larger scale \(L=R_j^{1/2-\varepsilon}\), at least
  \[
  \Omega(R_j^{2\varepsilon})
  \]
  boxes are necessary.

This proves the concrete mesoscopic-box diversification target left open in the preceding report, in the sense of actual capacity support rather than merely particle visits.

## 5.2 Capacity-box entropy

Normalize the box masses by total block capacity:
\[
\pi_{j,Q}
:=
\frac{\Gamma_{j,Q}}
{C_{\sigma_{j+1}}-C_{\sigma_j}}.
\tag{5.9}
\]
Then \(\sum_Q\pi_{j,Q}=1\), and (3.5), (5.3) imply
\[
\boxed{
\|\pi_j\|_\infty
\le
C\frac{(L+1)^2}{R_j}
}
\tag{5.10}
\]
for all sufficiently large \(j\).

The min-entropy therefore satisfies
\[
H_\infty(\pi_j)
:=-\log\|\pi_j\|_\infty
\ge
\boxed{
\log R_j-2\log(L+1)-O(1).
}
\tag{5.11}
\]
Since Shannon entropy dominates min-entropy,
\[
\boxed{
H(\pi_j)
\ge
\log\frac{R_j}{(L+1)^2}-O(1).
}
\tag{5.12}
\]

For every fixed Rényi order \(q>1\),
\[
\sum_Q\pi_{j,Q}^q
\le
\|\pi_j\|_\infty^{q-1}\sum_Q\pi_{j,Q}
=
\|\pi_j\|_\infty^{q-1}.
\]
Thus the corresponding effective number of capacity boxes
\[
N_{{\rm eff},q}^{\rm box}
:=
\left(\sum_Q\pi_{j,Q}^q\right)^{-1/(q-1)}
\]
satisfies
\[
\boxed{
N_{{\rm eff},q}^{\rm box}(j,L)
\ge
c_q\frac{R_j}{(L+1)^2}.
}
\tag{5.13}
\]
In fact the constant may be chosen independent of \(q\) after fixing the universal constants in (5.10).

So actual capacity has a genuine spatial entropy lower bound at every mesoscopic scale \(L=o(R^{1/2})\).

# 6. A shape-free local return hazard

The preceding checkpoint used a local-ball harmonic-measure estimate only after direct genealogical bursts. The same estimate applies after **every** actual attachment.

Fix a cluster state of radius at least \(R\), a revealed lattice point \(y\), and a radius \(L\ge1\). The Euclidean ball \(B(y,L)\) contains at most
\[
C_0(L+1)^2
\]
lattice sites. Every accessible boundary site has harmonic measure at most \(CR^{-1/2}\) by planar Beurling. Hence, regardless of the cluster shape,
\[
\boxed{
\mathbb P\{X_{m+1}\in B(y,L)\mid\mathcal F_m\}
\le
C(L+1)^2R^{-1/2}
}
\tag{6.1}
\]
whenever the current cluster radius is at least \(R\) and \(y\) is already revealed.

The center \(y\) need not be a current boundary point and the ball may contain old cluster sites, empty sites, and boundary sites; only currently attachable sites contribute to the probability, so counting every lattice point is a valid upper bound.

# 7. Mesoscopic refractory theorem for every attachment

Fix a unit-capacity block \(B_j\). Let \(H_j,L_j\ge1\) be integer-valued functions measurable with respect to \(\mathcal F_{\sigma_j}\). For brevity write
\[
H:=H_j,
\qquad
L:=L_j,
\qquad
R:=R_j.
\]

For every start \(n\in B_j\), define the quick-return event
\[
G_n(H,L)
:=
\left\{
\exists t\in\{1,\ldots,H\}:
|X_{n+1+t}-X_{n+1}|_2\le L
\right\}.
\tag{7.1}
\]
Let
\[
g_n:=\mathbb P(G_n(H,L)\mid\mathcal F_n).
\tag{7.2}
\]

## 7.1 Predictable hazard bound

Condition first on the realized next particle \(X_{n+1}=y\) and hence on \(\mathcal F_{n+1}\). Radius is nondecreasing, so at each of the next \(H\) particle times the cluster radius remains at least \(R\). By (6.1), at every one of those times the conditional probability of landing in \(B(y,L)\) is at most
\[
C(L+1)^2R^{-1/2}.
\]
A union bound, applied conditionally along the future filtration, gives
\[
\mathbb P(G_n(H,L)\mid\mathcal F_{n+1})
\le
C H(L+1)^2R^{-1/2}.
\]
Averaging over \(X_{n+1}\) yields
\[
\boxed{
 g_n
\le
\varepsilon_j
:=
C H_j(L_j+1)^2R_j^{-1/2}.
}
\tag{7.3}
\]
The bound may be replaced by \(\min(1,\varepsilon_j)\), but only the regime \(\varepsilon_j\to0\) is useful below.

This estimate is valid even when the return horizon extends beyond the end of the current capacity block, because radius can only increase and therefore the pointwise Beurling upper bound only improves.

## 7.2 Concentration despite overlapping return windows

Let
\[
J_n:=\mathbf1_{G_n(H,L)}.
\tag{7.4}
\]
The event \(G_n(H,L)\) uses particles through \(X_{n+H+1}\), hence is measurable by \(\mathcal F_{n+H+1}\).

Set
\[
M:=H+1.
\]
Partition start indices according to their residue class modulo \(M\), measured relative to \(\sigma_j\). Within one residue class, the event attached to one start is fully revealed before the next start in that residue class is conditioned upon.

For a Bernoulli variable \(J\) with conditional mean \(g\),
\[
\mathbb E[e^J\mid\mathcal G]
=1+(e-1)g
\le e^{(e-1)g}.
\tag{7.5}
\]
Therefore, on each residue class, the process
\[
\exp\left(
\sum J_n-(e-1)\sum g_n
\right)
\tag{7.6}
\]
is a nonnegative supermartingale, stopped when start times exit \(B_j\).

Take the barrier
\[
b_j:=6\log R_j.
\]
Ville's inequality gives failure probability at most \(R_j^{-6}\) on each residue class. If, say, \(H_j\le R_j\), then there are at most \(R_j+1\) residue classes, so the total failure probability for block \(j\) is at most
\[
2R_j^{-5}
\]
for all large \(j\). Because \(R_j\) grows exponentially in capacity index \(j\), these probabilities are summable. Borel-Cantelli therefore gives, almost surely eventually,
\[
\sum_{n\in B_j}J_n
\le
(e-1)\sum_{n\in B_j}g_n
+6(H_j+1)\log R_j.
\tag{7.7}
\]
Using (7.3),
\[
\sum_{n\in B_j}g_n
\le
\varepsilon_jN_j.
\tag{7.8}
\]
Hence, writing
\[
V_j(H_j,L_j):=\sum_{n\in B_j}J_n,
\]
we obtain
\[
\boxed{
V_j(H_j,L_j)
\le
C H_j(L_j+1)^2R_j^{-1/2}N_j
+
C H_j\log R_j
}
\tag{7.9}
\]
almost surely eventually.

Divide by \(N_j\), and use the local Kesten lower bound (3.6):
\[
\boxed{
\frac{V_j(H_j,L_j)}{N_j}
\le
C H_j(L_j+1)^2R_j^{-1/2}
+
C\frac{H_j\log R_j}{R_j^{3/2}}.
}
\tag{7.10}
\]

This is the mesoscopic refractory theorem.

## 7.3 Polynomial space-time tradeoff

Suppose
\[
L_j=\lfloor R_j^\alpha\rfloor,
\qquad
H_j=\lfloor R_j^\eta\rfloor,
\qquad
\alpha,\eta\ge0.
\tag{7.11}
\]
Then the main term in (7.10) is
\[
R_j^{\eta+2\alpha-1/2+o(1)}.
\]
Thus whenever
\[
\boxed{
\eta+2\alpha<\frac12,
}
\tag{7.12}
\]
we have
\[
\boxed{
\frac{V_j(R_j^\eta,R_j^\alpha)}{N_j}
\longrightarrow0
\quad\text{a.s.}
}
\tag{7.13}
\]
(the additive term also vanishes, since \(\eta<1/2<3/2\)).

Interpretation: for asymptotically almost every particle attached during the block, the ball of radius \(R_j^\alpha\) around that particle receives no new attachment during the next \(R_j^\eta\) particle additions, throughout the full region
\[
\eta+2\alpha<1/2.
\]

# 8. Consequences

## 8.1 Consecutive attachments are usually mesoscopically separated

Take \(H_j=1\). Then (7.10) gives
\[
\frac1{N_j}
\#\left\{n\in B_j:
|X_{n+2}-X_{n+1}|\le L_j
\right\}
\le
C(L_j+1)^2R_j^{-1/2}+o(1).
\tag{8.1}
\]
Therefore for every fixed \(\varepsilon>0\), with
\[
L_j=R_j^{1/4-\varepsilon},
\]
\[
\boxed{
\frac1{N_j}
\#\left\{n\in B_j:
|X_{n+2}-X_{n+1}|\le R_j^{1/4-\varepsilon}
\right\}
\longrightarrow0.
}
\tag{8.2}
\]

The preceding checkpoint proved such a far-switch statement only after direct parent-child bursts. Equation (8.2) shows that the same mesoscopic separation is typical for the **entire actual particle sequence**.

## 8.2 Fixed-radius neighborhoods have nearly \(R^{1/2}\) particle-time refractory periods

Take \(L_j=L\) fixed and
\[
H_j=R_j^{1/2-\varepsilon}.
\]
Then
\[
H_j(L+1)^2R_j^{-1/2}=O(R_j^{-\varepsilon}),
\]
so
\[
\boxed{
\frac1{N_j}
\#\left\{n\in B_j:
B(X_{n+1},L)
\text{ is revisited within the next }
R_j^{1/2-\varepsilon}
\text{ particles}
\right\}
\to0.
}
\tag{8.3}
\]

Thus a typical microscopic neighborhood is abandoned for almost \(\sqrt R\) subsequent particle additions.

## 8.3 A balanced mesoscopic space-time example

Fix \(\varepsilon>0\) and take
\[
\alpha=\frac18-\varepsilon,
\qquad
\eta=\frac14-\varepsilon.
\]
Then
\[
\eta+2\alpha
=
\frac12-3\varepsilon<\frac12.
\]
Hence
\[
\boxed{
\text{for }1-o(1)\text{ of particles in the block, }
B(X_{n+1},R_j^{1/8-\varepsilon})
\text{ is not revisited for the next }R_j^{1/4-\varepsilon}\text{ particles.}
}
\tag{8.4}
\]

This is a genuine space-time local non-recurrence statement for the standard DLA attachment process.

# 9. Relation between spatial capacity entropy and non-return

The two new theorems address complementary aspects of the remaining renormalization problem.

1. The **capacity-box theorem** says that one unit of logarithmic capacity cannot be carried by a bounded or slowly growing number of spatial regions. At scale \(L=o(\sqrt R)\), the number of boxes needed to carry a fixed capacity fraction diverges at least as \(R/L^2\).

2. The **refractory theorem** says that typical particle neighborhoods do not get revisited quickly. At scales satisfying \(H L^2=o(\sqrt R)\), a vanishing fraction of particles see any return to their \(L\)-ball within the next \(H\) additions.

Together, they rule out a stronger class of localization scenarios than the preceding direct-genealogy theorem: capacity is spatially spread across many mesoscopic boxes, and the particle sequence usually does not oscillate rapidly back into a recently used local neighborhood.

However, neither result proves independence of those boxes. A large old arm can intersect many boxes, and the harmonic measure in widely separated boxes can remain correlated through a common fjord/arm geometry. The capacity-box entropy is a support/anti-concentration statement, not an entropy-rate or mixing theorem for the rescaled morphology.

# 10. Why this still does not close the exponent

The radial exponent is governed by the relation between physical particle count and logarithmic capacity/radius. The present results still leave at least three serious gaps.

### 10.1 Spatial diversification is weaker than morphological regeneration

Using \(R/L^2\) boxes does not imply those boxes behave independently or that the process forgets the large-scale geometry that generated their harmonic masses.

### 10.2 The box theorem does not determine the cubic harmonic-moment exponent

The one-particle capacity drift remains
\[
a_n\asymp S_3(n)=\sum_xp_n(x)^3.
\]
The box-capacity distribution concerns realized capacity increments in space. It does not yet control the polynomially rare high-harmonic-measure events that can dominate \(S_3\).

### 10.3 The refractory theorem is a particle-time local statement

Even if a neighborhood is avoided for \(H\) particles, the process can return later, and different abandoned neighborhoods may belong to the same long-lived arm system. The condition \(HL^2=o(\sqrt R)\) is still far below the full unit-capacity particle count \(N_j\gtrsim R^{3/2}\).

Thus no exponent improvement is claimed.

# 11. Strongest next attack

The new box theorem suggests a sharper renormalization target than simple far-switching.

Partition a unit-capacity block into \(L\)-boxes and consider the normalized actual-capacity measure
\[
\pi_{j,Q}.
\]
We now know pathwise that
\[
\|\pi_j\|_\infty\lesssim L^2/R,
\qquad
H(\pi_j)\ge\log(R/L^2)-O(1).
\]
The missing theorem should control **dependence between the capacity-bearing boxes**, not merely their number.

A concrete target is a multi-arm/return inequality of the following form. For a box \(Q\) that has just received a capacity-relevant attachment, bound the conditional capacity that can return to an enlarged neighborhood \(Q^{(+)}\) during the next fixed amount of logarithmic-capacity time by
\[
\rho<1
\]
plus a summable error, uniformly over the old morphology. Iterating such a contraction across the \(\Omega(R/L^2)\) capacity-support boxes would create a genuine spatial regeneration mechanism.

An alternative is a coarse-grained covariance theorem: for two \(L\)-boxes separated by at least \(R^\theta\), control the covariance of their future capacity shares after one capacity unit. The earlier backwards-genealogy screening theorem suggests that logarithmic-capacity separation can destroy ancestry information; the new results show that actual capacity is simultaneously forced across many boxes. Coupling these two facts is now a plausible route toward a stationary/ergodic annular capacity field.

A successful theorem of this type could then be combined with the archived Rényi-3/Palm/free-energy reductions to force a deterministic block particle dimension and hence a deterministic radial exponent.

# 12. Checks actually performed

The following points were explicitly checked in this iteration.

1. **One-site counting:** a lattice site can be attached at most once, so cumulative actual capacity inside a finite set can be bounded by cardinality times the one-step maximum.

2. **Direction of the Beurling/capacity bound:** \(p_n(x)\le CR_j^{-1/2}\) on a block implies \(\Delta_{n+1}\le16p_n(x)^2\le C/R_j\), not the reverse.

3. **Box support versus box capacity:** the theorem is stated for actual accumulated capacity \(\Gamma_{j,Q}\); it does not silently identify all particle visits with equal capacity weight.

4. **Random block lengths:** the return-event concentration is organized by start indices modulo \(H_j+1\), so each event window is revealed before the next same-residue start. The stopping condition \(n<\sigma_{j+1}\) is \(\mathcal F_n\)-measurable.

5. **Return horizon crossing block end:** the local return hazard remains valid after \(\sigma_{j+1}\), since radius is nondecreasing and the pointwise harmonic-measure bound only gets smaller.

6. **Growing number of residue classes:** a \(6\log R_j\) barrier gives per-class failure \(R_j^{-6}\); multiplying by at most \(O(H_j)\) classes remains summable for the polynomial regimes used here. The displayed theorem assumes, harmlessly for all stated corollaries, \(H_j\le R_j\).

7. **Denominator in the refractory fraction:** the additive concentration error is divided by the archived local Kesten lower bound \(N_j\ge cR_j^{3/2}\), not by an unproved asymptotic for \(N_j\).

8. **Space-time exponent:** with \(L=R^\alpha\) and \(H=R^\eta\), the main quick-return exponent is exactly \(\eta+2\alpha-1/2\).

These are self-checks, not independent or formal verification.
