# 7. A capacity-Palm burst spacetime exclusion theorem

Fix a large capacity block \(j\). Let
\[
L_j=R_j^\alpha,
\qquad
H_j=R_j^\eta,
\tag{7.1}
\]
with \(0\le\alpha<1\), \(\eta\ge0\).

Call a pair of three-particle burst starts \((n,m)\) **bad** if

* \(n\in B_j\);
* \(E_n^{(3)}\) and \(E_m^{(3)}\) both occur;
* \(3\le m-n\le H_j\); and
* the two burst-start sites obey
  \[
  |X_{m+1}-X_{n+1}|\le L_j.
  \]

The lower cutoff \(m-n\ge3\) makes the two three-particle observation windows non-overlapping. The overlapping cases \(m=n+1,n+2\) imply a four-particle direct chain and are already almost surely finite by the 04:29 checkpoint; they may therefore be added back at the end without changing the eventual theorem.

Condition on the entire first burst through time \(n+3\), including its starting site
\[
y:=X_{n+1}.
\]
At every later possible start \(m\ge n+3\), radius is at least \(R_j\). By (6.4), regardless of all intervening history,
\[
\mathbb P\{E_m^{(3)},\ X_{m+1}\in B(y,L_j)\mid\mathcal F_m\}
\le
C\frac{\sqrt{L_j+1}}{R_j^{3/2}}.
\tag{7.2}
\]
A conditional union bound over at most \(H_j\) later starts gives
\[
\mathbb P\{\text{a bad partner occurs after this revealed burst}\mid\mathcal F_{n+3}\}
\le
C H_j\frac{\sqrt{L_j+1}}{R_j^{3/2}}.
\tag{7.3}
\]

To sum over possible first bursts in block \(j\), use their predictable hazards. The block total satisfies, by (4.6) and (3.7),
\[
\sum_{n\in B_j}q_3(n)\le C
\tag{7.4}
\]
eventually almost surely (the final two start positions cost only \(O(R_j^{-1})\)). Hence the conditional expected number of bad non-overlapping pairs whose first start lies in \(B_j\) is at most
\[
\boxed{
C H_j\frac{\sqrt{L_j+1}}{R_j^{3/2}}.
}
\tag{7.5}
\]

With the polynomial choices (7.1), this is
\[
R_j^{\eta+\alpha/2-3/2+o(1)}.
\tag{7.6}
\]
If
\[
\boxed{
\eta+\frac\alpha2<\frac32,
}
\tag{7.7}
\]
then (7.5) is a fixed negative power of \(R_j\), summable over capacity blocks because \(R_j\) grows exponentially in \(j\). Markov plus Borel–Cantelli therefore yields:

\[
\boxed{
\begin{minipage}{0.88\textwidth}
For every fixed \(\alpha,\eta\) satisfying \(\eta+\alpha/2<3/2\), almost surely for all sufficiently large capacity blocks, there is no pair of three-particle burst starts whose first start lies in the block, whose particle-time separation is at most \(R_j^\eta\), and whose spatial separation is at most \(R_j^\alpha\).
\end{minipage}
}
\tag{7.8}
\]

The statement remains true after restoring the overlapping starts because four-particle chains occur only finitely often almost surely.

# 10. Burst markers have positive density on logarithmic capacity windows

The earlier global theorem states that cumulative actual three-particle burst count is \(\Theta(C_N)\), but for renormalization it is useful to have a local-in-capacity window statement.

For a capacity interval consisting of \(k\) consecutive unit blocks,
\[
\mathcal I_{j,k}:=[\sigma_j,\sigma_{j+k}),
\]
(4.6) and (3.7) imply, almost surely for all sufficiently large \(j\),
\[
Q_{j,k}
:=
\sum_{n\in\mathcal I_{j,k}\text{ valid start}}q_3(n)
\ge
c k.
\tag{10.1}
\]
Partition the start indices modulo three. In each residue class the three-particle observation windows are disjoint. If \(I_n=\mathbf 1_{E_n^{(3)}}\), then for
\[
c_*:=1-e^{-1},
\]
\[
\exp\left(
-\sum I_n+c_*\sum q_3(n)
\right)
\]
is a nonnegative supermartingale on that residue class, because for a conditional Bernoulli variable with mean \(q\),
\[
\mathbb E[e^{-I}\mid\mathcal G]
=1-c_*q
\le e^{-c_*q}.
\tag{10.2}
\]
Applying Ville/Markov to each of the three residue classes and summing them gives, for any \(s>0\), except with probability at most \(3e^{-s}\),
\[
H_{j,k}
:=
\sum_{n\in\mathcal I_{j,k}}I_n
\ge
c_*Q_{j,k}-3s.
\tag{10.3}
\]
Choose
\[
s=\frac{c_*c}{6}k.
\]
Then
\[
\mathbb P\{H_{j,k}<c'k\mid\mathcal F_{\sigma_j}\}
\le
3e^{-c''k}.
\tag{10.4}
\]
Taking
\[
k_j:=\left\lceil A\log(j+2)\right\rceil
\tag{10.5}
\]
with \(A\) large enough makes the exceptional probabilities summable. Therefore
\[
\boxed{
H_{j,k_j}\ge c k_j=\Omega(\log j)
}
\tag{10.6}
\]
almost surely for every sufficiently large \(j\).

In particular, every sufficiently late forward capacity interval of length \(A\log(j+2)\) contains at least one—and in fact order \(\log j\)—operational capacity-Palm burst markers.

This is a local capacity-time density statement, stronger in form than merely knowing the global cumulative count is \(\Theta(C_N)\).

# 11. What this says about the Kesten barrier

The new burst-local hazard (6.4) is
\[
\Lambda_n(B(y,L))
\lesssim
\sqrt L\,R^{-3/2}.
\tag{11.1}
\]
At microscopic \(L=O(1)\), the natural particle-time scale at which one can no longer rule out a capacity-Palm return is therefore precisely
\[
R^{3/2}.
\tag{11.2}
\]
That is the same exponent as the Kesten particle-per-radial/capacity lower scale.

This is not an accident of the proof bookkeeping. Formula (11.1) comes from exactly three factors:

1. one factor \(R^{-1/2}\) from the total harmonic measure that a microscopic target can carry at radius \(R\);
2. two additional powers of \(p\), together bounded by \((p^*)^2\lesssim R^{-1}\), because a three-particle burst is a cubic/capacity-Palm marker.

Thus ordinary one-arm Beurling plus the exact cubic burst representation lands **exactly** at \(R^{-3/2}\).

This gives a sharper description of the missing theorem than the previous abstract no-go statement. To improve the radial exponent through this channel, one needs a post-burst or repeated-lineage estimate that beats (11.1) by a genuine power. A schematic target is:
\[
\boxed{
\Lambda_m(B(y,L)
\mid\text{a recent capacity-Palm burst near }y\text{ has terminated and the process has exited})
\le
C\frac{\sqrt{L+1}}{R^{3/2+\delta}}
}
\tag{11.3}
\]
