## 0. Exact target and result of this iteration

For standard external site diffusion-limited aggregation on \(\mathbb Z^2\), start from \(A_1=\{0\}\). Given a finite connected cluster \(A_n\), let \(\partial A_n\) be its outer vertex boundary and \(\overline A_n=A_n\cup\partial A_n\). The next site \(X_{n+1}\in\partial A_n\) is sampled from simple-random-walk harmonic measure from infinity,
\[
p_n(x)=\omega(x,\overline A_n),
\]
and attached. Put
\[
R_n:=\max_{x\in A_n}|x|_2.
\]
The full target is to prove
\[
\frac{\log R_n}{\log n}\to\beta
\qquad\text{almost surely}
\]
for a deterministic \(\beta\), and identify \(\beta\), or rigorously refute existence/determinism for this exact lattice model.

The full target remains **OPEN**. No full exponent value is claimed.

The new theorem of this iteration is an exact **capacity-block intermittency conservation law**. Earlier recovered work defines the capacity-biased boundary law \(r_n\) and the KL intermittency
\[
I_n=D_{\rm KL}(p_n\|r_n).
\]
Let \(\sigma_j\) be the first particle index at which logarithmic capacity reaches level \(j\), and let
\[
B_j:=\{\sigma_j,\ldots,\sigma_{j+1}-1\},
\qquad N_j:=|B_j|.
\]
Then this run proves
\[
\boxed{
\log\sum_{k\in B_j}e^{I_k}=\pi j+O(\log j)
}
\qquad\text{a.s.}
\]
and therefore, defining the particle-uniform block free energy
\[
\Lambda_j:=\log\left(\frac1{N_j}\sum_{k\in B_j}e^{I_k}\right),
\qquad
\Theta_j:=\frac{2\Lambda_j}{\pi j},
\]
one has
\[
\boxed{
\log N_j=\pi j\left(1-\frac{\Theta_j}{2}\right)+O(\log j).
}
\]
Thus the number of particles required for one unit of capacity growth is exactly the complement of the block log-moment-generating function of intermittency, on the exponential scale.

Even without convergence of \(\Theta_j\), define
\[
G_j:=\max_{1\le \ell<j}\frac{\ell}{j}\left(1-\frac{\Theta_\ell}{2}\right).
\]
Then
\[
\boxed{
\frac{1}{j}\log\sigma_j=\pi G_j+o(1)
}
\]
and hence along capacity levels
\[
\boxed{
\frac{\log R_{\sigma_j}}{\log\sigma_j}
=\frac{1+o(1)}{2G_j}.
}
\]
Consequently, the full DLA exponent exists if and only if this running block-intermittency envelope has a limit; if \(G_j\to G\), then
\[
\boxed{\beta=\frac1{2G}.}
\]
A sufficient but strictly stronger condition is \(\Theta_j\to\Theta\), in which case
\[
\boxed{\beta=\frac1{2-\Theta}.}
\]
This block criterion is weaker than the previously recovered pointwise condition \(I_n/\log R_n\to\theta\): it allows arbitrary within-block oscillation and retains only a logarithmic exponential mean of intermittency.

Finally, Kesten's rigorous \(\beta\le2/3\) bound implies a new structural recurrence statement: for every large capacity horizon \(j\), some capacity block \(\ell\) with \(\ell/j\ge3/4-o(1)\) must satisfy
\[
\Theta_\ell\le\frac12+o(1).
\]
So highly intermittent blocks cannot monopolize every recent capacity scale; low-intermittency blocks recur on every large multiplicative capacity window. This does not prove stabilization.

## 3. Recalled capacity and intermittency identities

Let
\[
C_n:=\operatorname{Cap}(\overline A_n).
\]
For an accessible \(x\in\partial A_n\), define the capacity increment if \(x\) is attached,
\[
d_n(x):=
\operatorname{Cap}(\overline{A_n\cup\{x\}})-\operatorname{Cap}(\overline A_n).
\]
With \(X_{n+1}\) selected according to \(p_n\), let
\[
\Delta_{n+1}:=C_{n+1}-C_n=d_n(X_{n+1})
\]
and the predictable drift
\[
a_n:=\mathbb E[\Delta_{n+1}\mid\mathcal F_n]
=\sum_xp_n(x)d_n(x).
\tag{3.1}
\]

Losev–Smirnov Lemma 5 gives deterministic \(0<c_0<C_0<\infty\) such that
\[
c_0p_n(x)^2\le d_n(x)\le C_0p_n(x)^2.
\tag{3.2}
\]
Define
\[
\kappa_n(x):=d_n(x)/p_n(x)^2,
\qquad c_0\le\kappa_n(x)\le C_0.
\]
Then
\[
a_n=\sum_x\kappa_n(x)p_n(x)^3.
\tag{3.3}
\]

Define the capacity-biased attachment law
\[
r_n(x):=\frac{p_n(x)d_n(x)}{a_n}
\]
and the KL intermittency
\[
I_n:=D_{\rm KL}(p_n\|r_n).
\tag{3.4}
\]
Let
\[
H_n:=-\sum_xp_n(x)\log p_n(x),
\qquad
\mu_n:=\sum_xp_n(x)\log\kappa_n(x).
\]
The recovered exact identity is
\[
\boxed{
\log a_n=-2H_n+\mu_n+I_n.
}
\tag{3.5}
\]

Losev–Smirnov's quoted discrete Makarov theorem gives, uniformly for large connected planar sets,
\[
H_n=\log R_n+O(\log\log R_n).
\tag{3.6}
\]
Also the capacity-radius comparison is
\[
C_n=\frac2\pi\log R_n+O(1).
\tag{3.7}
\]
Because \(\mu_n=O(1)\), (3.5)–(3.7) are the key inputs to the new block theorem.

The recovered martingale result gives
\[
\boxed{
C_n=C_1+\sum_{k<n}a_k+M_\infty+o(1)
}
\tag{3.8}
\]
for a finite random \(M_\infty\), and hence
\[
\boxed{
\log R_n=\frac\pi2\sum_{k<n}a_k+O(1)
}
\quad\text{a.s.}
\tag{3.9}
\]

# 4. Capacity blocks and vanishing overshoot

For integer \(j\ge1\), define the capacity hitting time
\[
\sigma_j:=\inf\{n:C_n\ge j\}.
\tag{4.1}
\]
Set
\[
B_j:=\{\sigma_j,\sigma_j+1,\ldots,\sigma_{j+1}-1\},
\qquad
N_j:=|B_j|=\sigma_{j+1}-\sigma_j.
\tag{4.2}
\]

### Lemma 4.1 — PROVED

Almost surely,
\[
C_{\sigma_j}=j+o(1)
\tag{4.3}
\]
and
\[
\boxed{
A_j:=\sum_{k\in B_j}a_k=1+o(1).
}
\tag{4.4}
\]

### Proof

By (3.2) and the discrete Beurling bound
\[
p_n^*\le CR_n^{-1/2},
\]
the realized increment obeys
\[
0\le\Delta_{n+1}\le C(p_n^*)^2\le C/R_n\to0
\quad\text{a.s.}
\tag{4.5}
\]
because \(R_n\to\infty\). Hence the overshoot when \(C_n\) first crosses an integer level tends to zero, proving (4.3).

From (3.8),
\[
\sum_{k\in B_j}a_k
=
C_{\sigma_{j+1}}-C_{\sigma_j}
-
\bigl(M_{\sigma_{j+1}}-M_{\sigma_j}\bigr).
\]
The first difference is \(1+o(1)\) by (4.3), while the martingale difference tends to zero because \(M_n\to M_\infty\). This proves (4.4). QED.

For every \(k\in B_j\),
\[
j+o(1)\le C_k<j+1,
\]
so by (3.7), uniformly over the block,
\[
\log R_k=\frac\pi2j+O(1)
\tag{4.6}
\]
and therefore
\[
\log\log R_k=\log j+O(1).
\tag{4.7}
\]

# 5. Main new theorem: capacity-block intermittency conservation

### Theorem 5.1 — PROVED

There is a deterministic constant \(K<\infty\) such that almost surely for all sufficiently large \(j\), uniformly for \(k\in B_j\),
\[
\boxed{
-\pi j+I_k-K\log j
\le
\log a_k
\le
-\pi j+I_k+K\log j.
}
\tag{5.1}
\]
Consequently,
\[
\boxed{
\log\sum_{k\in B_j}e^{I_k}
=
\pi j+O(\log j).
}
\tag{5.2}
\]

### Proof

Insert the uniform block estimates (4.6)–(4.7) into the exact intermittency identity (3.5) and the discrete Makarov estimate (3.6):
\[
\log a_k
=-2\log R_k+I_k+O(\log\log R_k)
=-\pi j+I_k+O(\log j),
\]
uniformly for \(k\in B_j\). This proves (5.1).

Exponentiating and summing gives
\[
j^{-K}e^{-\pi j}
\sum_{k\in B_j}e^{I_k}
\le
A_j
\le
j^Ke^{-\pi j}
\sum_{k\in B_j}e^{I_k}.
\tag{5.3}
\]
By Lemma 4.1, \(A_j=1+o(1)\), hence (5.2). QED.

### Interpretation

Equation (5.2) is a conservation law for intermittency. One unit of capacity growth at capacity level \(j\) contains, up to polynomial factors, exactly \(e^{\pi j}\) units of the exponential KL weight \(e^{I_k}\), regardless of how that weight is distributed among particles.

This is stronger for exponent purposes than a pointwise intermittency criterion because arbitrary high/low oscillations of \(I_k\) within a block are allowed.

# 6. Block free energy determines block particle count

Define the block log-mean-exponential intermittency
\[
\Lambda_j
:=
\log\left(
\frac1{N_j}\sum_{k\in B_j}e^{I_k}
\right)
\tag{6.1}
\]
and its normalized form
\[
\Theta_j:=\frac{2\Lambda_j}{\pi j}.
\tag{6.2}
\]

### Corollary 6.1 — PROVED

\[
\boxed{
\log N_j
=
\pi j-\Lambda_j+O(\log j)
=
\pi j\left(1-\frac{\Theta_j}{2}\right)+O(\log j).
}
\tag{6.3}
\]

This is immediate from (5.2) and the definition of \(\Lambda_j\).

Because \(I_k\ge0\),
\[
\Lambda_j\ge0,
\qquad
\Theta_j\ge0.
\tag{6.4}
\]
Also the standard Beurling/Makarov bounds give
\[
I_k\le\log R_k+O(\log\log R_k)
=\frac\pi2j+O(\log j),
\]
so
\[
\Theta_j\le1+o(1).
\tag{6.5}
\]
Thus block particle growth lies between the compact and maximally screened exponential scales:
\[
e^{(\pi/2-o(1))j}
\lesssim
N_j
\lesssim
e^{(\pi+o(1))j}.
\tag{6.6}
\]
These bounds alone reproduce only the elementary radius exponent window \([1/2,1]\); Kesten remains essential for the better upper radial exponent \(2/3\).

# 7. Exact running-envelope formula for the radial exponent

Since
\[
\sigma_j
=
\sigma_1+\sum_{\ell=1}^{j-1}N_\ell,
\]
we have the elementary log-sum-exp identity
\[
\log\sigma_j
=
\max_{1\le\ell<j}\log N_\ell+O(\log j).
\tag{7.1}
\]
Insert (6.3) and define
\[
G_j
:=
\max_{1\le\ell<j}
\frac{\ell}{j}
\left(1-\frac{\Theta_\ell}{2}\right).
\tag{7.2}
\]

### Theorem 7.1 — PROVED

\[
\boxed{
\frac1j\log\sigma_j
=
\pi G_j+o(1).
}
\tag{7.3}
\]
Moreover, since \(C_{\sigma_j}=j+o(1)\),
\[
\boxed{
\log R_{\sigma_j}
=
\frac\pi2j+O(1),
}
\tag{7.4}
\]
and hence
\[
\boxed{
\frac{\log R_{\sigma_j}}{\log\sigma_j}
=
\frac{1+o(1)}{2G_j}.
}
\tag{7.5}
\]

### Proof

Equation (7.1) follows because the sum has at most \(j\) positive terms. Equation (6.3) gives
\[
\frac1j\max_{\ell<j}\log N_\ell
=
\pi
\max_{\ell<j}
\frac\ell j\left(1-\frac{\Theta_\ell}{2}\right)
+o(1),
\]
where the \(O(\log\ell)\) errors are \(o(j)\) uniformly. This proves (7.3). Equation (7.4) is the capacity-radius comparison, and division yields (7.5). QED.

### Corollary 7.2 — exponent existence criterion

The full radial exponent exists if and only if the running envelope \(G_j\) has a limit \(G>0\). In that case
\[
\boxed{\beta=\frac1{2G}.}
\tag{7.6}
\]

**Justification of the full sequence, not only capacity times.** If \(\sigma_j\le n<\sigma_{j+1}\), then \(C_n\in[j+o(1),j+1)\), so \(\log R_n=(\pi/2)j+O(1)\). If \(G_j\to G\), then both \(\log\sigma_j/j\) and \(\log\sigma_{j+1}/j\) tend to \(\pi G\). Therefore every intermediate \(\log n/j\) has the same limit, giving \(\log R_n/\log n\to1/(2G)\). Conversely, existence of \(\beta\) implies the same limit along \(\sigma_j\), and (7.5) forces \(G_j\to1/(2\beta)\).

This is an exact reformulation of the full exponent problem in terms of a scalar block-intermittency envelope.

# 8. A weaker sufficient condition than pointwise intermittency convergence

### Corollary 8.1 — PROVED

If
\[
\Theta_j\to\Theta,
\tag{8.1}
\]
then the radial exponent exists and
\[
\boxed{
\beta=\frac1{2-\Theta}.
}
\tag{8.2}
\]

### Proof

If \(\Theta_j\to\Theta\), then
\[
\frac1j\log N_j
\to
\pi\left(1-\frac\Theta2\right)=:\alpha>0
\]
by (6.3). Hence \(\log\sigma_j/j\to\alpha\), because an exponentially increasing sequence of block sizes has the same exponential rate as its partial sums. Equation (7.4) gives
\[
\beta
=
\frac{\pi/2}{\alpha}
=
\frac1{2-\Theta}.
\]
QED.

This criterion is genuinely weaker than requiring the pointwise normalized KL divergence \(I_n/\log R_n\) to converge: only the block log-mean-exp of \(I_n\) must stabilize. Rare high-intermittency steps are incorporated automatically through the exponential average.

# 9. Kesten forces recurrent low-intermittency capacity blocks

Kesten's rigorous planar bound implies, at the capacity hitting times,
\[
R_{\sigma_j}\le C\sigma_j^{2/3}
\]
for all large \(j\). Using (7.4),
\[
\frac\pi2j+O(1)
\le
\frac23\log\sigma_j+O(1),
\]
so
\[
\frac1j\log\sigma_j
\ge
\frac{3\pi}{4}-o(1).
\tag{9.1}
\]
By Theorem 7.1,
\[
G_j\ge\frac34-o(1).
\tag{9.2}
\]

### Corollary 9.1 — PROVED

For every sufficiently large \(j\), there exists \(\ell<j\) such that
\[
\boxed{
\frac\ell j\ge\frac34-o(1)
}
\tag{9.3}
\]
and
\[
\boxed{
\Theta_\ell\le\frac12+o(1).
}
\tag{9.4}
\]

### Proof

Choose \(\ell\) realizing the maximum in \(G_j\). By (9.2),
\[
\frac\ell j\left(1-\frac{\Theta_\ell}{2}\right)
\ge\frac34-o(1).
\]
Since \(\Theta_\ell\ge0\), the second factor is at most \(1\), giving (9.3). Since \(\ell/j\le1\), the same inequality gives
\[
1-\Theta_\ell/2\ge3/4-o(1),
\]
which is (9.4). QED.

### Meaning

The rigorous \(2/3\) radial upper exponent can be read as a recurrence theorem for capacity-block intermittency: no matter how large the scale, within the most recent quarter of capacity history there is a block whose exponential-mean intermittency is at most \(1/2+o(1)\) in the normalization of (6.2).

This is not enough for exponent existence; it provides recurrence, not convergence. But it identifies precisely what Kesten controls in the new intermittency coordinates.

## 10. Relation to the recovered Rényi-3 theorem

The recovered backfill proved that if the instantaneous order-3 exponent
\[
\tau_{3,n}:=-\frac{\log S_3(n)}{\log R_n}
\]
converges to \(\tau_3\), then \(\beta=1/\tau_3\), and that
\[
\tau_{3,n}=2-\frac{I_n}{\log R_n}+o(1).
\]

The present block theorem is strictly more tolerant of microscopic oscillation. It replaces the pointwise quantity \(I_n\) by the capacity-block free energy
\[
\Lambda_j=\log\mathbb E_{U_j}e^{I_k},
\]
where \(U_j\) is the uniform law on particle times \(k\in B_j\). In statistical-mechanics language, \(\Lambda_j\) is the log partition function per particle for intermittency within one unit of capacity growth.

The exact identity
\[
\log N_j=\pi j-\Lambda_j+O(\log j)
\]
shows that the mass-radius exponent is controlled by a free-energy quantity, not necessarily by a typical or pointwise intermittency value. This distinction matters if a small fraction of exceptionally screened/high-growth tips dominates capacity.

## 13. Next concrete attack

The new theorem identifies a more robust observable than pointwise \(I_n\):
\[
\Theta_j
=
\frac{2}{\pi j}
\log\left(
\frac1{N_j}
\sum_{k\in B_j}e^{I_k}
\right).
\]
The full exponent exists iff the running envelope
\[
G_j
=
\max_{\ell<j}\frac\ell j\left(1-\Theta_\ell/2\right)
\]
stabilizes. A strong but not necessary route is to prove \(\Theta_j\) itself converges.

The best next attacks are therefore:

1. **Capacity-block quasi-subadditivity.** Try to compare the partition sums
   \[
   Z_j:=\sum_{k\in B_j}e^{I_k}
   \]
   across adjacent or dyadic capacity blocks after factoring out the deterministic \(e^{\pi j}\) growth. Theorem 5.1 already says \(\log Z_j-\pi j=O(\log j)\); the missing information is how this fixed partition mass is split among \(N_j\) particles.
2. **Control concentration of \(e^{I_k}\).** Define the effective participation ratio
   \[
   \mathcal P_j:=
   \frac{(\sum_{B_j}e^{I_k})^2}{\sum_{B_j}e^{2I_k}}.
   \]
   If one can show \(\log\mathcal P_j\) has a deterministic linear rate in \(j\), then \(N_j\) is squeezed between \(\mathcal P_j\) and the partition-mass constraint, potentially forcing \(\Theta_j\) stabilization. This converts the problem into a second-moment question for the capacity-intermittency weights.
3. **Cubic-tilt environment mixing.** Since \(r_n\) is uniformly comparable to the cubic harmonic-measure tilt \(p_n^3/S_3(n)\), study the environment seen from a capacity-effective site. Seek mixing across unit-capacity blocks, not unit-particle blocks.
4. **Exploit Kesten recurrence.** Corollary 9.1 guarantees low-intermittency blocks recur within every recent quarter of capacity history. To prove convergence, one needs an additional propagation mechanism showing a low-intermittency block constrains subsequent \(\Theta\)'s. A screening/locality inequality under cubic tilt would be a natural candidate.
5. **Weaker milestone.** Prove a deterministic bound on the oscillation of \(\Theta_j\), or show that \(\Theta_j\le1/2+o(1)\) on a positive lower density of capacity blocks. Either would sharpen the current structural understanding and may combine with the envelope formula.

The immediate technical subproblem for the next iteration is to bound \(\sum_{B_j}e^{2I_k}\) using harmonic-measure moments and one-step capacity response. Since \(e^{I_k}\) is the arithmetic/geometric gap of \(\Delta_{k+1}\), a tractable inequality connecting \(e^{2I_k}\) to ratios of \(S_5(k),S_3(k)\), or to the conditional coefficient of variation of \(\Delta_{k+1}\), could turn the new partition-sum conservation law into a concentration theorem.
