\[
\boxed{
\|\omega_K-\omega_O\|_{\rm TV}=\omega_K(I).
}

\[
\boxed{
\|\omega_{K_n}-\omega_{K_n\setminus B_s}\|_{\rm TV}

}

\[
Z_{n+1}\sim\omega(\cdot,K_n\setminus B_s),
\]
and
\[
Z_{n+1}=X_{n+1}
\]
unless the actual DLA walker first hits the erased core.

\[
s_R=Re^{-L_R},
\qquad
L_R\to\infty,
\qquad
L_R\le \log(R/4),
\]
then, almost surely along all sufficiently large dyadic epochs,
\[
\boxed{
\frac1{M_R}
\#\{n\in[\tau_R,\tau_{2R}):X_{n+1}\ne Z_{n+1}\}
\le
C e^{-L_R/2}+O(R^{-1/4}),
}
\]
where \(M_R=\tau_{2R}-\tau_R\).

Hence the actual attachment sequence can be changed at only an \(o(1)\) fraction of particle times so that every replacement attachment is sampled from an entrance law determined solely by the truncated geometry outside radius \(Re^{-L_R}\).

By logarithmic capacity-radius comparison, the retained geometry has capacity depth only
\[
\frac2\pi L_R+O(1).
\]
Since \(L_R\) may diverge arbitrarily slowly, this gives an **arbitrarily slowly diverging particle-time memory window in capacity coordinates**, in a sparse-edit / empirical sense.

A convenient concrete choice is \(L_R=\log\log R\), giving
\[
s_R=R/\log R
\]
and mismatch fraction
\[
O((\log R)^{-1/2})+O(R^{-1/4}).
\]
Thus, over a full radial doubling, almost all actual DLA attachment locations can be matched to a core-erased entrance mechanism depending only on the annular geometry between radii roughly \(R/\log R\) and \(2R\).

This is substantially closer to an annular renormalization statement than the preceding capacity-time genealogy mixing theorem. It still does **not** close the exponent, because the core-erased annular state itself has growing complexity and the shadow sequence is not yet an autonomous stationary Markov chain.

# 3. Exact core-erasure balayage

Let \(K\subset\mathbb Z^2\) be finite and nonempty, and split it into disjoint sets
\[
K=I\sqcup O,
\qquad O\ne\varnothing.
\]
Let \(\mu_K\) be harmonic measure from infinity on \(K\), and \(\mu_O\) harmonic measure from infinity on \(O\). Extend \(\mu_O\) by zero on \(I\).

For \(y\in I\) and \(z\in O\), set
\[
H_O(y,z)=\mathbb P^y\{S_{T_O}=z\}.
\]
Planar simple random walk is recurrent, so \(T_O<\infty\) almost surely.

### Theorem 3.1 — PROVED

For every \(z\in O\),
\[
\boxed{
\mu_O(z)
=
\mu_K(z)
+
\sum_{y\in I}\mu_K(y)H_O(y,z).
}
\tag{3.1}
\]
Consequently,
\[
\boxed{
\|\mu_K-\mu_O\|_{\rm TV}=\mu_K(I).
}
\tag{3.2}
\]

### Proof

Start a random walk from a pole tending to infinity and stop it at its first hit of \(K\). If that first hit lies in \(O\), it is already the first hit of \(O\). If it lies at \(y\in I\), apply the strong Markov property there and continue until the first subsequent hit of \(O\). Taking the pole to infinity gives (3.1).

Every correction term in (3.1) is nonnegative, so \(\mu_O(z)\ge\mu_K(z)\) on \(O\). Summing (3.1) over \(z\in O\) shows that the excess mass on \(O\) is exactly \(\mu_K(I)\). On \(I\), the extended \(\mu_O\) is zero, so the missing mass is also \(\mu_K(I)\). Thus the \(L^1\) distance is \(2\mu_K(I)\), proving (3.2). QED.

### Canonical coupling

The proof gives an explicit coupling. Draw
\[
X\sim\mu_K.
\]
If \(X\in O\), set \(Z=X\). If \(X\in I\), start a fresh continuation of the same walk from \(X\) and let \(Z\) be its first hit of \(O\). Then
\[
Z\sim\mu_O,
\]
and
\[
\boxed{
\mathbb P\{Z\ne X\}=\mu_K(I)
=\|\mu_K-\mu_O\|_{\rm TV}.
}
\tag{3.3}
\]
So this is a maximal coupling.

# 4. Shape-uniform core deletion for a large DLA cluster

For the DLA closure \(K_n\), write
\[
\mathcal R_n:=\max_{z\in K_n}|z|_2.
\]
The previous checkpoint proved the deterministic inner-penetration estimate
\[
\mu_n(K_n\cap B_s)
\le
C\left(\frac{s}{\mathcal R_n}\right)^{1/2}
\tag{4.1}
\]
whenever \(2\le s\le\mathcal R_n/4\).

Let
\[
O_{n,s}:=K_n\setminus B_s,
\qquad
\nu_{n,s}:=\omega(\cdot,O_{n,s}).
\tag{4.2}
\]
No connectedness of \(O_{n,s}\) is required.

### Corollary 4.1 — PROVED

If \(\mathcal R_n\ge R\) and \(2\le s\le R/4\), then
\[
\boxed{
\|\mu_n-\nu_{n,s}\|_{\rm TV}
\le
C\left(\frac{s}{R}\right)^{1/2}.
}
\tag{4.3}
\]

### Proof

Apply Theorem 3.1 with
\[
I=K_n\cap B_s,
\qquad
O=K_n\setminus B_s,
\]
and then apply (4.1). QED.

This is a one-step, shape-uniform finite-memory statement: to determine the next first-hit law up to total variation \(O((s/R)^{1/2})\), the entire geometry inside \(B_s\) may be deleted.

# 6. Sparse-edit coupling of the actual attachment sequence

Fix one dyadic epoch \([\tau_R,\tau_{2R})\) and a cutoff \(s\le R/4\). At each time \(n\) in the epoch, let
\[
X_{n+1}
\]
be the actual DLA attachment, so conditionally on \(\mathcal F_n\),
\[
X_{n+1}\sim\mu_n.
\]

Using the canonical core-erasure coupling of Theorem 3.1, enlarge the probability space with an auxiliary point \(Z_{n+1}^{(s)}\) such that, conditionally on \(\mathcal F_n\),
\[
\boxed{
Z_{n+1}^{(s)}\sim\nu_{n,s}
}
\tag{6.1}
\]
and
\[
\boxed{
Z_{n+1}^{(s)}=X_{n+1}
\quad\text{unless}\quad
X_{n+1}\in B_s.
}
\tag{6.2}
\]
In fact
\[
\mathbb P\{Z_{n+1}^{(s)}\ne X_{n+1}\mid\mathcal F_n\}
=\mu_n(B_s).
\tag{6.3}
\]

Define the mismatch indicator
\[
D_{n+1}^{(s)}
:=
\mathbf1\{Z_{n+1}^{(s)}\ne X_{n+1}\}
=
\mathbf1\{X_{n+1}\in B_s\}.
\tag{6.4}
\]
By (4.1), throughout the radial epoch,
\[
\mathbb E[D_{n+1}^{(s)}\mid\mathcal F_n]
\le
C(s/R)^{1/2}.
\tag{6.5}
\]

# 7. Stopped martingale concentration on an entire radial epoch

Set
\[
\xi_{n+1}
=
D_{n+1}^{(s)}
-
\mathbb E[D_{n+1}^{(s)}\mid\mathcal F_n].
\]
Then \((\xi_{n+1})\) is a martingale-difference sequence and \(|\xi_{n+1}|\le1\).

After the stopping time \(\tau_R\), use the deterministic horizon \(L_R=CR^2\) from (5.4). The maximal Azuma–Hoeffding inequality gives, conditionally on \(\mathcal F_{\tau_R}\),
\[
\mathbb P\left\{
\max_{m\le L_R}
\left|
\sum_{i=0}^{m-1}\xi_{\tau_R+i+1}
\right|
>R^{5/4}
\middle|
\mathcal F_{\tau_R}
\right\}
\le
2e^{-cR^{1/2}}.
\tag{7.1}
\]
The right side is summable over dyadic \(R\). Hence Borel–Cantelli and (5.3) imply, almost surely for all sufficiently large dyadic \(R\),
\[
\left|
\frac1{M_R}
\sum_{n=\tau_R}^{\tau_{2R}-1}\xi_{n+1}
\right|
\le
CR^{-1/4}.
\tag{7.2}
\]

Combining with (6.5) gives the key particle-time estimate.

### Theorem 7.1 — PROVED (sparse-edit annular locality)

Almost surely, for every sufficiently large dyadic \(R\) and every deterministic cutoff \(s=s_R\) with \(2\le s\le R/4\),
\[
\boxed{
\frac1{M_R}
\#\left\{
n\in[\tau_R,\tau_{2R}):
Z_{n+1}^{(s)}\ne X_{n+1}
\right\}
\le
C\left(\frac{s}{R}\right)^{1/2}
+CR^{-1/4}.
}
\tag{7.3}
\]

Equivalently, all but this fraction of the actual DLA attachment locations are **exactly equal** to points whose conditional law is the harmonic entrance law of the core-erased set \(K_n\setminus B_s\).

This is stronger than merely comparing one-step laws or block averages: it is an explicit sparse-edit coupling of the actual attachment sequence.

# 8. Arbitrarily slowly diverging capacity memory

Choose
\[
s_R=Re^{-L_R}
\tag{8.1}
\]
with
\[
L_R\to\infty,
\qquad
L_R\le\log(R/4).
\tag{8.2}
\]
Then Theorem 7.1 becomes
\[
\boxed{
\frac{\#\{\text{mismatched particle times in the }R\to2R\text{ epoch}\}}{M_R}
\le
Ce^{-L_R/2}+CR^{-1/4}
=o(1).
}
\tag{8.3}
\]

The core-erased state is the geometry in
\[
K_n\setminus B_{Re^{-L_R}}.
\]
For \(R_n\in[R,2R]\), logarithmic capacity-radius comparison gives
\[
\operatorname{Cap}(K_n)
-
\frac2\pi\log(Re^{-L_R})
=
\frac2\pi L_R+O(1).
\tag{8.4}
\]
Thus the amount of **capacity-scale history retained by the shadow entrance law is only \(O(L_R)\)**.

Since \(L_R\) may diverge arbitrarily slowly, this proves:

### Corollary 8.1 — PROVED

For every deterministic \(L_R\to\infty\) satisfying (8.2), the attachment sequence during a dyadic radial crossing can be changed at only an \(o(1)\) fraction of particle times so that the replacement point at each time is sampled from an entrance law determined only by the most recent \(O(L_R)\) units of logarithmic-capacity geometry.

Concrete examples:

- \(L_R=\log\log R\): retain geometry outside \(R/\log R\), mismatch fraction \(O((\log R)^{-1/2})\);
- \(L_R=\log\log\log R\): retain geometry outside \(R/\log\log R\), mismatch fraction \(O((\log\log R)^{-1/2})\);
- more generally any arbitrarily slowly diverging \(L_R\) gives vanishing edit density.

No exponent assumption enters this result.

# 9. Empirical observable formulation

Let \(\phi_n:\mathbb Z^2\to[-1,1]\) be any \(\mathcal F_n\)-measurable family of test functions. It may, in particular, be a function determined solely by the current truncated geometry \(K_n\setminus B_s\).

By the coupling,
\[
|\phi_n(X_{n+1})-\phi_n(Z_{n+1}^{(s)})|
\le
2D_{n+1}^{(s)}.
\]
Therefore Theorem 7.1 gives, almost surely eventually,
\[
\boxed{
\left|
\frac1{M_R}
\sum_{n=\tau_R}^{\tau_{2R}-1}
\phi_n(X_{n+1})
-
\frac1{M_R}
\sum_{n=\tau_R}^{\tau_{2R}-1}
\phi_n(Z_{n+1}^{(s)})
\right|
\le
C(s/R)^{1/2}+CR^{-1/4}.
}
\tag{9.1}
\]

Since, conditionally on \(\mathcal F_n\),
\[
Z_{n+1}^{(s)}\sim\nu_{n,s},
\]
a second bounded martingale concentration step yields, for any fixed predictable family \(\phi_n\),
\[
\boxed{
\frac1{M_R}
\sum_{n=\tau_R}^{\tau_{2R}-1}
\phi_n(X_{n+1})
=
\frac1{M_R}
\sum_{n=\tau_R}^{\tau_{2R}-1}
\sum_z\nu_{n,s}(z)\phi_n(z)
+
O((s/R)^{1/2})
+O(R^{-1/4})
}
\tag{9.2}
\]
almost surely along large dyadic epochs.

With \(s=Re^{-L_R}\), every bounded annular-local one-step observable therefore has the same particle-time empirical average, up to \(o(1)\), as its average under a core-erased entrance mechanism with only \(O(L_R)\) capacity memory.

# 10. Why this does not yet solve the exponent

This result removes a genuine obstruction but exposes the next one clearly.

The full radial exponent would follow from self-averaging of particle counts per unit capacity, or equivalently from stabilization of one of the archived Rényi-3 / Palm-information / block-free-energy observables.

The new theorem shows that **deep core geometry is not the reason self-averaging can fail**: over a full radial doubling, all but an asymptotically negligible fraction of actual particle attachments can be represented using entrance laws that depend only on an arbitrarily slowly diverging capacity-memory window.

However, three gaps remain.

1. **The annular state space still grows.** Even an \(O(L_R)\)-capacity shell can contain a geometrically complicated collection of branches and fjords whose complexity grows with \(R\).
2. **The shadow sequence is non-autonomous.** Its one-step law is \(\omega(\cdot,K_n\setminus B_s)\), where the truncated state is inherited from the actual DLA history. The sparse-edit theorem does not yet construct a stationary Markov chain on rescaled annular shapes.
3. **Sparse edits are enough for empirical bounded observables, not automatically for nonlinear block quantities.** Particle count itself is the length of the epoch and is not a bounded additive observable of individual attachment locations.

Thus this run supplies an approximate finite-memory principle, but a contraction/tightness theorem for the **annular morphology process itself** is still required.

# 11. Failed route / limitation: naive whole-path TV coupling

A natural first attempt is to use the one-step bound
\[
\|\mu_n-\nu_{n,s}\|_{\rm TV}\lesssim(s/R)^{1/2}
\]
and union-bound over all \(M_R\) particle steps. This is useless: \(M_R\) can be polynomially large, so the bound would require an unrealistically tiny one-step error.

The sparse-edit argument avoids this failure by using the **explicit balayage coupling**, where a mismatch occurs exactly when the actual attachment lies in the erased core, and then controlling the empirical mismatch count by its predictable harmonic mass plus martingale concentration.

The result is therefore substantially stronger than a black-box accumulation of total-variation errors.
