# 4. Distributional hypothesis

Let

\[
X_n

\tag{4.1}
\]

Assume:

### IID / centering / variance

\[
E\xi=0,
\qquad
E\xi^2=1,
\]
and all \(\xi_{ij}\) are iid.

### Symmetry

\[
\boxed{
\xi\stackrel d=-\xi.
}
\tag{4.2}
\]

This exact symmetry is used to center the cross-resolvent block and force scalar expectation of the self-resolvents.

### Dimension-free Euclidean concentration

There is a fixed \(K<\infty\) such that for every \(N\), for an iid vector

\[
\Xi_N=(\xi_1,\ldots,\xi_N),
\]

and every real \(L\)-Lipschitz function \(f:\mathbb R^N\to\mathbb R\),

\[
\boxed{
P\{|f(\Xi_N)-Ef(\Xi_N)|>t\}
\le
2\exp
\left(
-\frac{t^2}{K^2L^2}
\right).
}
\tag{GC}
\]

This is an explicit hypothesis.

It is **stronger** than merely assuming ordinary subgaussian one-dimensional tails; no claim is made that every subgaussian product law satisfies `(GC)` with a dimension-free constant.

For standard bounded/log-concave/Gaussian examples this is natural, but here it is stated explicitly rather than smuggled into `(GC)`.

# 6. Spectral-norm clipping

The off-spectrum resolvent is not globally Lipschitz in the raw entries because a rare matrix can move a singular value onto the contour.

The clean repair is deterministic clipping.

Let

\[
\mathcal C_S
=
\{Y\in\mathbb R^{n\times m}:\|Y\|_{\rm op}\le S\}.
\]

This is a closed convex subset of the Frobenius Hilbert space.

Let

\[
\Pi_S(X)
\]

be its metric projection in Frobenius norm.

Equivalently, if

\[
X=Q\,\operatorname{diag}(s_j)\,R^*
\]

is an SVD, then

\[
\Pi_S(X)
=
Q\,\operatorname{diag}(s_j\wedge S)\,R^*.
\]

Therefore:

\[
\boxed{
\|\Pi_S(X)-\Pi_S(Y)\|_F
\le
\|X-Y\|_F.
}
\tag{6.1}
\]

Also, for signed permutation matrices \(P,Q\),

\[
\boxed{
\Pi_S(PXQ)=P\Pi_S(X)Q.
}
\tag{6.2}
\]

Finally,

\[
\|X\|_{\rm op}\le S
\quad\Longrightarrow\quad
\Pi_S(X)=X.
\tag{6.3}
\]

This clipping step gives globally regular functions to which `(GC)` applies.

# 7. Clipped resolvent maps and Lipschitz constants

Write

\[
Y=\Pi_S(X).
\]

Define

\[
R_L^S(z;X)
=
z(z^2-YY^*)^{-1},
\tag{7.1}
\]

\[
R_R^S(z;X)
=
z(z^2-Y^*Y)^{-1},
\tag{7.2}
\]

\[
C^S(z;X)
=
Y(z^2-Y^*Y)^{-1}.
\tag{7.3}
\]

All inverses exist for every \(X\), because the singular values of \(Y\) lie in \([0,S]\) and (5.1) holds.

## 7.1 Self-resolvent Lipschitz bound

For \(Y,Z\in\mathcal C_S\),

\[
R_L(z;Y)-R_L(z;Z)
=
z(z^2-YY^*)^{-1}
(YY^*-ZZ^*)
(z^2-ZZ^*)^{-1}.
\]

Since

\[
\|YY^*-ZZ^*\|_{\rm op}
\le
(\|Y\|+\|Z\|)
\|Y-Z\|_{\rm op}
\le
2S\|Y-Z\|_F,
\]

we obtain

\[
\boxed{
\|R_L^S(z;X)-R_L^S(z;X')\|_{\rm op}
\le
L_{\Gamma}^{\rm self}
\|X-X'\|_F.
}
\tag{7.4}
\]

The right self-resolvent obeys the same bound.

## 7.2 Cross-resolvent Lipschitz bound

Let

\[
C(Y)=Y(z^2-Y^*Y)^{-1}.
\]

Then

\[
\begin{aligned}
C(Y)-C(Z)
={}&
(Y-Z)(z^2-Y^*Y)^{-1}\\
&+
Z(z^2-Y^*Y)^{-1}
(Y^*Y-Z^*Z)
(z^2-Z^*Z)^{-1}.
\end{aligned}
\]

Also

\[
\|Y^*Y-Z^*Z\|
\le
2S\|Y-Z\|_F.
\]

Hence

\[
\boxed{
\|C^S(z;X)-C^S(z;X')\|_{\rm op}
\le
L_{\Gamma}^{\rm cross}
\|X-X'\|_F.
}
\tag{7.5}
\]

Together with (6.1), the clipped maps are globally \(L_\Gamma\)-Lipschitz in the matrix Frobenius metric.

Because

\[
X=\Xi/\sqrt m,
\]

they are globally

\[
\boxed{
L_\Gamma/\sqrt m
}
\tag{7.6}
\]

Lipschitz as functions of the raw iid entry vector \(\Xi\).

# 8. Exact symmetry centers

This is where symmetry (4.2) is used.

The law of \(X\) is invariant under independent signed row and column permutations.

Because clipping is equivariant, the expectation of every clipped self-resolvent commutes with all signed permutations.

The commutant of the full signed-permutation group is the scalar matrices.

Therefore there are deterministic scalars \(a_L(z),a_R(z)\) such that

\[
\boxed{
E R_L^S(z;X)=a_L(z)I_n,
}
\tag{8.1}
\]

\[
\boxed{
E R_R^S(z;X)=a_R(z)I_m.
}
\tag{8.2}
\]

Moreover, changing the sign of one row of \(X\) changes the corresponding sign in \(C^S(z;X)\), while preserving the law. Hence

\[
\boxed{
E C^S(z;X)=0.
}
\tag{8.3}
\]

Taking traces,

\[
a_L(z)
=
E\frac1n\operatorname{Tr}R_L^S(z;X),
\tag{8.4}
\]

\[
a_R(z)
=
E\frac1m\operatorname{Tr}R_R^S(z;X).
\tag{8.5}
\]

This exact centering replaces the product-Haar conditional centering used in the previous run.
