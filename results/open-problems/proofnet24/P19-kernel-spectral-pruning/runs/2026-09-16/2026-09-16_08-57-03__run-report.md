# 4. Setup for a source-legal ghost proxy

Let

\[
S=(Z_1,\ldots,Z_N)
\]

be independent coordinates. They represent the part of the training/noise-driving randomness with respect to which the actual learned/pruned signal is stable. Let `Theta` be exogenous procedure randomness, independent of the current source noise object `X_n` and of independent ghost samples used below. The actual signal is

\[
P=A(S,\Theta)
\in\mathbb F^{p\times d}.
\tag{4.1}
\]

No linearity, differentiability, convexity, fixed support, or iid pruning mask is assumed.

For each `i`, let `S^{(i)}` replace `Z_i` by an independent copy while keeping the **same** `Theta`. Let `psi` be a fresh probe, independent of the learners in this theorem, and define

\[
G=E[\psi\psi^*].
\tag{4.2}
\]

Let `D` be a family of coordinate supports such that every row of each matrix difference used below has support in some `J in D`. Define

\[
 a
 =
 \inf_{J\in\mathfrak D}
 \lambda_{\min}(G_{JJ}).
\tag{4.3}
\]

For any such matrix `M`, rowwise expansion gives

\[
E\|M\psi\|^2
=
\operatorname{tr}(MGM^*)
=
\sum_{\ell}m_\ell^*Gm_\ell
\ge
 a\sum_\ell\|m_\ell\|^2
=a\|M\|_F^2.
\tag{4.4}
\]

Thus

\[
\boxed{
\|M\|_F^2
\le
\frac{E_\psi\|M\psi\|^2}{a}.
}
\tag{4.5}
\]

Equation (4.5) is deterministic conditional on `M`; it remains valid when `M` and its support are chosen by the trained procedure, because the lower bound is simultaneous over the support family.

For exact rowwise `k`-sparse outputs, the difference of two trained outputs is rowwise at most `2k`-sparse. Hence one may take

\[
a=a_{2k}(G)
:=
\inf_{|J|\le2k}\lambda_{\min}(G_{JJ}).
\tag{4.6}
\]

Under exact support lock the support union has size at most `k`, so `a_k(G)` suffices.

# 5. `P19-SYNC-GHOST-PROXY-41` — PROVED

Let `S'` be an independent copy of `S`, and define the synchronized ghost

\[
P_0^{\rm sync}=A(S',\Theta),
\tag{5.1}
\]

using the **same exogenous procedure seed** `Theta`.

Define

\[
 b_i^2
 =
 E\left\|
 [A(S,\Theta)-A(S^{(i)},\Theta)]\psi
 \right\|^2.
\tag{5.2}
\]

Then

\[
\boxed{
E\|P-P_0^{\rm sync}\|_F^2
\le
\frac1a\sum_{i=1}^N b_i^2.
}
\tag{5.3}
\]

Since operator norm is at most Frobenius norm, the same right side bounds

\[
E\|P-P_0^{\rm sync}\|_{\rm op}^2.
\tag{5.4}
\]

## Proof

Condition on `Theta=theta`. Given `theta`, the two matrices

\[
A(S,\theta),\qquad A(S',\theta)
\]

are iid Hilbert-space-valued random variables in the Frobenius Hilbert space. Therefore

\[
E_{S,S'}\|A(S,\theta)-A(S',\theta)\|_F^2
=
2E_S\|A(S,\theta)-E_SA(S,\theta)\|_F^2.
\tag{5.5}
\]

Hilbert-valued Efron--Stein gives

\[
E_S\|A(S,\theta)-E_SA(S,\theta)\|_F^2
\le
\frac12
\sum_{i=1}^N
E\|A(S,\theta)-A(S^{(i)},\theta)\|_F^2.
\tag{5.6}
\]

Multiplying by two and integrating over `Theta` yields

\[
E\|P-P_0^{\rm sync}\|_F^2
\le
\sum_i
E\|A(S,\Theta)-A(S^{(i)},\Theta)\|_F^2.
\tag{5.7}
\]

Apply the simultaneous restricted-Gram inequality (4.5) to each replacement difference and average:

\[
E\|A(S,\Theta)-A(S^{(i)},\Theta)\|_F^2
\le
\frac{b_i^2}{a}.
\tag{5.8}
\]

Summing proves (5.3). QED.

## Source legality

If

\[
(S',\Theta)\ \perp\ X_n,
\tag{5.9}
\]

then the ghost signal/frame `P_0^{sync}` is independent of the current source noise object `X_n`, even though the **actual** `P=A(S,Theta)` may be highly adapted to that current noise through `S`.

This is the key source-facing gain. Independence is manufactured only for the virtual proxy frame. The actual trained/pruned frame is not falsely declared independent.

The condition (5.9) is explicit. If `Theta` itself was selected from, or otherwise depends on, the current `X_n`, synchronized reseeding is not source-legal and the theorem does not silently repair that dependence.

# 6. `P19-HIERARCHICAL-GHOST-PROXY-41` — PROVED

Sometimes one wants a completely independent copy of the whole training procedure rather than a synchronized exogenous seed. Let `Theta'` be an independent copy of `Theta` and define

\[
P_0^{\rm ind}=A(S',\Theta').
\tag{6.1}
\]

Define the prediction-scale procedure variance

\[
 v_{\rm proc}^2
 =
 E\left\|
 [A(S,\Theta)-A(S,\Theta')]\psi
 \right\|^2.
\tag{6.2}
\]

Then

\[
\boxed{
E\|P-P_0^{\rm ind}\|_F^2
\le
\frac{v_{\rm proc}^2+\sum_i b_i^2}{a}.
}
\tag{6.3}
\]

Again the same right side upper-bounds the expected squared operator norm.

## Proof

Set

\[
\mu(S)=E_\Theta A(S,\Theta).
\tag{6.4}
\]

For an independent full copy `P_0^{ind}`,

\[
E\|P-P_0^{\rm ind}\|_F^2
=
2E\|P-EP\|_F^2.
\tag{6.5}
\]

The Hilbert-space law of total variance gives

\[
E\|P-EP\|_F^2
=
E\|P-\mu(S)\|_F^2
+
E\|\mu(S)-E\mu(S)\|_F^2.
\tag{6.6}
\]

The procedure part satisfies the exact iid-copy identity

\[
2E\|P-\mu(S)\|_F^2
=
E\|A(S,\Theta)-A(S,\Theta')\|_F^2.
\tag{6.7}
\]

For the data part, Hilbert Efron--Stein gives

\[
2E\|\mu(S)-E\mu(S)\|_F^2
\le
\sum_i E\|\mu(S)-\mu(S^{(i)})\|_F^2.
\tag{6.8}
\]

By Jensen, using the same `Theta` in the replacement pair,

\[
E\|\mu(S)-\mu(S^{(i)})\|_F^2
\le
E\|A(S,\Theta)-A(S^{(i)},\Theta)\|_F^2.
\tag{6.9}
\]

Combining (6.5)--(6.9), then applying (4.5) to the procedure difference and every replacement difference, gives (6.3). QED.

so

\[
\left(E\|P-P_0\|_{op}^2\right)^{1/2}
\le
\frac{L}{\sqrt{aN}}.
\tag{7.14}
\]

A constant-order restricted floor and retained singular floor therefore make the relative ghost debt `O(N^{-1/2})`. If either floor vanishes, the required local stability becomes correspondingly stronger.

# 8. Exact counterexamples and failed shortcuts

## 8.1 `P19-PERCOORD-STABILITY-NOT-ENOUGH-CE-41` — PROVED

Let `xi_1,...,xi_N` be iid Rademacher variables and

\[
T_N=N^{-1/2}\sum_{i=1}^N\xi_i.
\tag{8.1}
\]

Define a rank-one matrix

\[
P_N=u(T_N)e_1^T,
\qquad
u(t)=(\cos t,\sin t)^T.
\tag{8.2}
\]

Every `P_N` has its sole nonzero singular value exactly equal to one.

If coordinate `i` is independently replaced, then `T_N-T_N^{(i)}` equals zero with probability `1/2` and equals `\pm2/\sqrt N` with total probability `1/2`. Since

\[
\|u(s)-u(t)\|^2
=2-2\cos(s-t),
\tag{8.3}
\]

we have the exact one-coordinate influence

\[
\boxed{
E\|P_N-P_N^{(i)}\|_F^2
=1-\cos(2/\sqrt N)
\sim\frac2N.
}
\tag{8.4}
\]

Thus every individual replacement RMS tends to zero.

Now let `P_N'` be built from an independent ghost sample. Since

\[
E e^{iT_N}
=\cos(1/\sqrt N)^N,
\tag{8.5}
\]

independence gives

\[
E\cos(T_N-T_N')
=\cos(1/\sqrt N)^{2N}.
\tag{8.6}
\]

Therefore

\[
\boxed{
E\|P_N-P_N'\|_F^2
=2\left[1-\cos(1/\sqrt N)^{2N}\right]
\longrightarrow
2(1-e^{-1})>0.
}
\tag{8.7}
\]

The singular floor is identically one, but the independent ghost frame does not align. The reason is exact:

\[
\sum_i E\|P_N-P_N^{(i)}\|_F^2
\to2,
\tag{8.8}
\]

rather than zero.

Hence a statement of the form “every one-observation replacement RMS tends to zero” is too weak. The Efron--Stein sum of **squared** influences, normalized by `a g^2`, is the correct sufficient scale.

This independently reproduces, at the signal-frame level, the same accumulation warning seen in P15's current vanishing-per-row counterexample.

## 8.2 `P19-PROCEDURE-DEBT-CE-41` — PROVED

Let the data `S` be arbitrary and ignored by the learner. Let the exogenous procedure seed `Theta` be Bernoulli and define

\[
A(S,\Theta)
=
\begin{cases}
 e_1e_1^*,&\Theta=0,\\
 e_2e_2^*,&\Theta=1.
\end{cases}
\tag{8.9}
\]

Every signal has rank one and singular floor one. All synchronized data replacement influences are exactly zero:

\[
A(S,\Theta)=A(S^{(i)},\Theta).
\tag{8.10}
\]

However, for an independent procedure seed `Theta'`, the two singular lines are orthogonal with probability `1/2`, and

\[
E\|A(S,\Theta)-A(S,\Theta')\|_F^2=1.
\tag{8.11}
\]

Thus data stability alone cannot certify an **independent-seed** source proxy. Either synchronize an exogenous seed that is itself independent of the current noise, or pay `v_proc` as in Section 6.

## 8.3 iid-mask shortcut remains rejected

If the hard-pruned output is rowwise `k`-sparse but its support is chosen from the same trained matrix, the replacement difference has a random support union of size at most `2k`. A theorem proved for one fixed support cannot be conditioned through that selection as though the support were independent.

The present argument uses a simultaneous restricted floor over **all** relevant support unions, so the support may be chosen after seeing the trained matrix. This is exactly why the inherited Gaussian RIP theorem is valid here and an iid Bernoulli-mask surrogate is not.

## 10.3 Independent audit: `P19-AUDIT-P16-FIXEDQUERY-ALIGNMENT-41` — PASS

P16 fixes a deterministic unit vector `v` independent of

\[
W=\sqrt{\alpha/N}\,G,
\]

where `G` has iid standard Gaussian entries, and defines

\[
H_v(W)=v^T\operatorname{ReLU}(Wv).
\tag{10.1}
\]

Because `Gv~N(0,I_N)` with independent coordinates,

\[
E H_v
=
\sqrt{\frac\alpha N}
\frac1{\sqrt{2\pi}}
\sum_i v_i
\le
\sqrt{\frac\alpha{2\pi}},
\tag{10.2}
\]

using `sum_i v_i<=||v||_1<=sqrt N`. Negative entries of `v` do not invalidate this upper bound.

As a function of `G`, ReLU's 1-Lipschitz property gives

\[
|H_v(G)-H_v(G')|
\le
\sqrt{\frac\alpha N}
\|(G-G')v\|
\le
\sqrt{\frac\alpha N}
\|G-G'\|_F.
\tag{10.3}
\]

Standard Gaussian concentration therefore yields

\[
P\{H_v\ge a\}
\le
\exp\left[
-\frac N{2\alpha}
\left(a-\sqrt{\frac\alpha{2\pi}}\right)_+^2
\right].
\tag{10.4}
\]

If for some `q>=1`

\[
\|\operatorname{ReLU}(Wv)-qv\|\le\epsilon,
\]

then by Cauchy--Schwarz

\[
H_v
=v^T(qv+e)
\ge q-\|e\|
\ge1-\epsilon.
\tag{10.5}
\]

Substitution of `a=1-epsilon` reproduces P16's claimed exponential pseudoray bound exactly.

The proof is correct **only for a fixed query independent of `W`**, exactly as P16 states. It does not license applying the Gaussian law to a direction selected after observing the tied matrix. # 11. Method comparison and route discipline

## Resolvent / SLL

This remains the primary source route for BBP singular-projector overlap. The new ghost theorem is upstream: it manufactures a noise-independent proxy frame and proves that the actual adaptive frame is close enough to inherit the proxy SLL.

## Davis--Kahan / Wedin

Use only with a real gap. Here the relevant first gap is the proxy signal gap to zero, `sigma_r(P_0)`. After a deployed observation-matrix operator perturbation is available, a separate observed singular-cluster gap may justify Wedin/Hermitian dilation. Neither step produces the MP overlap constants.

## Leave-one-out / Efron--Stein

This is the central new mechanism. One-coordinate synchronized replacement movements accumulate quadratically through Efron--Stein to control the distance from the actual adaptive signal to an independent ghost signal. The exact counterexample in Section 8 shows why the sum of squared influences is the relevant quantity, not merely the maximum influence tending to zero.

## Deterministic equivalents / free probability

A deterministic equivalent is useful for the source-legal ghost frame if its hypotheses cover that frame. A global MP/free convolution statement does not, by itself, repair the same-noise adaptive-frame bias. The inherited adaptive rank-one counterexample remains decisive.

## Sparsification concentration

The valid interface is a simultaneous restricted Gram event over every admissible support union. This survives support selection from the same trained matrix. Fixed-support or iid-mask concentration does not.

## Counterexample discipline

The new per-coordinate accumulation and procedure-seed counterexamples are retained alongside all inherited route-kills. No failed shortcut is silently recycled.
