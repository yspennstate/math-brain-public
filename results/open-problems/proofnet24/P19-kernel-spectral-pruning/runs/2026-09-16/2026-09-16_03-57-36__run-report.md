# 4. Exact target: rare trained-score boundaries

The hard-pruning setup retained from `P19-HARD-BOUNDARY-SYMDIFF-31` is

```text
C=(c_1,...,c_r),
s_l(C)=||c_l||_2,
S_k(C)=deterministic exact-cardinality top-k support,
H_k(C)=C P_(S_k(C)).
```

Earlier P19 proved that if `||C-C'||_F<=rho`, every support flip lies in an explicit `2 rho` score boundary. It also proved a sharp counterexample: an `O(1/n)` pre-pruning perturbation can cause an order-one post-pruning jump when the trained score boundary is tied.

The unresolved question is therefore not whether hard top-`k` is globally Lipschitz — it is not. The useful question is:

> Given a common deletion-trained anchor, when is the score boundary so unlikely to be crossed by one-observation insertion/replacement retraining that the post-pruning replacement RMS is still `O(1/n)`?

The theorem below answers this conditionally and with explicit constants.

# 5. `P19-DELETION-GAP-LOCK-36` — PROVED

Let `D` denote any fixed common deletion context. Let

```text
C_0=C_0(D) in R^(q x r)
```

be a reference/deletion readout. Let

```text
S_0=S_k(C_0)
```

under the fixed tie rule. Assume `1<=k<r` and define the strict anchor gap

```text
gamma(D)
 = s_(k)(C_0)-s_(k+1)(C_0) > 0.
```

For a fresh insertion value `z`, let `C(z)` be the fully retrained readout; the representation/optimizer/refit may otherwise be arbitrary.

Then

```text
boxed:
S_k(C(z)) != S_0
   => ||C(z)-C_0||_F >= gamma(D)/2.                     (5.1)
```

## Proof

Let

```text
delta=||C(z)-C_0||_F.
```

Every channel score is 1-Lipschitz in its column and hence

```text
|s_l(C(z))-s_l(C_0)|
 <= ||c_l(z)-c_l(0)||
 <= delta.                                             (5.2)
```

If `delta<gamma/2`, then every anchor-selected channel has insertion score at least

```text
s_(k)(C_0)-delta,
```

whereas every anchor-unselected channel has insertion score at most

```text
s_(k+1)(C_0)+delta.
```

Their difference is strictly larger than

```text
gamma-2 delta > 0.
```

Thus every selected anchor channel remains above every unselected anchor channel, so the exact-cardinality support is unchanged. Contraposition proves `(5.1)`.

QED.

This theorem uses the actual trained top-`k` rule. No random mask is inserted.

# 6. `P19-PAIRWISE-MARGIN-FLIP-36` — PROVED

The global Frobenius bound can be sharpened to the actual pairwise score margins.

For `a in S_0`, `b notin S_0`, put

```text
m_ab=s_a(C_0)-s_b(C_0) > 0
```

and insertion score perturbations

```text
delta_l(z)=s_l(C(z))-s_l(C_0).
```

Suppose that, conditional on `D`, for every selected/unselected pair,

```text
P{ delta_b(Z)-delta_a(Z) >= t | D }
 <= exp[-t^2/(2 nu_ab^2)]
```

for all `t>=0` and a fresh insertion `Z`.

Then

```text
boxed:
P{S_k(C(Z)) != S_0 | D}
 <= sum_(a in S_0, b notin S_0)
      exp[-m_ab^2/(2 nu_ab^2)].                        (6.1)
```

For two conditionally iid fresh insertions `Z,Z'`,

```text
boxed:
P{S_k(C(Z)) != S_k(C(Z')) | D}
 <= 2 sum_(a in S_0, b notin S_0)
      exp[-m_ab^2/(2 nu_ab^2)].                        (6.2)
```

## Proof

If the insertion support differs from `S_0`, cardinality preservation gives some

```text
a in S_0 \ S_k(C(Z)),
b in S_k(C(Z)) \ S_0.
```

Because `b` is selected and `a` is not,

```text
s_b(C(Z)) >= s_a(C(Z)).
```

Rearranging around `C_0`,

```text
delta_b(Z)-delta_a(Z)
 >= s_a(C_0)-s_b(C_0)
 = m_ab.
```

Union over all selected/unselected pairs gives `(6.1)`. If two insertion supports differ, at least one of them differs from `S_0`, so `(6.2)` follows by another union bound.

QED.

This is often substantially sharper than replacing every pairwise margin by the single `k/(k+1)` gap.

# 7. `P19-SUBGAUSS-GAP-FLIP-36` — PROVED

A convenient distribution-free-in-channel corollary uses only the full retraining drift.

Assume, conditional on `D`,

```text
P{ ||C(Z)-C_0||_F >= t | D }
 <= 2 exp[-t^2/(2 sigma(D)^2)]                         (7.1)
```

for all `t>=0`.

Then by `(5.1)`,

```text
boxed:
P{S_k(C(Z)) != S_0 | D}
 <= 2 exp[-gamma(D)^2/(8 sigma(D)^2)].                 (7.2)
```

For two iid insertions,

```text
boxed:
p_bad(D)
:=P{S_k(C(Z)) != S_0 or S_k(C(Z')) != S_0 | D}
 <= 4 exp[-gamma(D)^2/(8 sigma(D)^2)].                 (7.3)
```

In particular, it is enough for the deletion gap to exceed the one-observation retraining noise scale by only `sqrt(log n)` to make support flips polynomially rarer than `n^-2`. Specifically, if

```text
gamma(D)^2/(8 sigma(D)^2) >= 2 log n + u,
```

then

```text
p_bad(D) <= 4 e^(-u) / n^2.                           (7.4)
```

No constant-sized gap is required.

# 8. `P19-RAREBOUNDARY-CLIPPED-RMS-36` — PROVED

This is the performance theorem that makes `(7.3)` useful.

Let `psi(X) in R^r` be a common honest fresh-query proxy, independent of the insertion values conditional on `D`, with Gram

```text
G(D)=E[psi(X) psi(X)* | D].
```

Let

```text
b_k(D)=sup_(|I|<=k) lambda_max(G_II).
```

For an insertion `Z`, define the proxy deployed predictor

```text
f_Z(X)=H_k(C(Z)) psi(X).
```

Let

```text
v(D)^2=E[ ||C(Z)-C_0||_F^2 | D ].                     (8.1)
```

For any target `Y`, define clipped squared loss

```text
ell_T(f;(X,Y))=min{ ||Y-f(X)||^2, T }.
```

For two iid insertions `Z,Z'`, define the conditional clipped-loss replacement RMS

```text
beta_T(D)^2
=E[ |ell_T(f_Z;Q)-ell_T(f_Z';Q)|^2 | D ],             (8.2)
```

where `Q=(X,Y)` is a fresh query independent of the insertions conditional on `D`.

Under `(7.1)`,

```text
boxed:
beta_T(D)^2
 <= 16 T b_k(D) v(D)^2
    + 4 T^2 exp[-gamma(D)^2/(8 sigma(D)^2)].            (8.3)
```

Hence

```text
boxed:
beta_T(D)
 <= 4 sqrt(T b_k(D)) v(D)
    + 2 T exp[-gamma(D)^2/(16 sigma(D)^2].              (8.4)
```

## Proof

Let `E_good` be the event that both insertion supports equal `S_0`. By `(7.3)`,

```text
P(E_good^c|D)
 <= 4 exp[-gamma^2/(8 sigma^2)].                       (8.5)
```

On `E_good`,

```text
f_Z-f_Z'
=(C(Z)-C(Z')) P_(S_0) psi.
```

Therefore

```text
E[ ||f_Z-f_Z'||^2 1_(E_good) | D ]
 <= b_k(D) E||C(Z)-C(Z')||_F^2
 <= 4 b_k(D) v(D)^2,                                  (8.6)
```

where the last inequality is

```text
||A-B||^2 <= 2||A-C_0||^2+2||B-C_0||^2.
```

The map

```text
r -> min{||r||^2,T}
```

is globally `2 sqrt(T)`-Lipschitz, so on `E_good`,

```text
|ell_T(f_Z)-ell_T(f_Z')|^2
 <= 4T ||f_Z-f_Z'||^2.                                (8.7)
```

The good-event contribution is therefore at most `16 T b_k v^2`.

On the bad event each clipped loss lies in `[0,T]`, so their difference has magnitude at most `T`. Thus the bad-event contribution is at most

```text
T^2 P(E_good^c|D),
```

which with `(8.5)` proves `(8.3)`. Taking square roots and using `sqrt(a+b)<=sqrt(a)+sqrt(b)` proves `(8.4)`.

QED.

## Representation-debt boundary

The theorem is intentionally written for a common proxy feature map. If insertion retraining changes the representation itself, write

```text
phi_Z = psi + (phi_Z-psi)
```

and add the corresponding coefficient-weighted `L^2` representation debts exactly as in the inherited P19 proxy-transfer theorems. They are **not** silently absorbed into `(8.3)`.

# 9. `P19-RAREBOUNDARY-PREDVAR-36` — PROVED

Return to the inherited clipped leave-one-out gap `H_T`. The preceding P19 chain established the exact coordinate-replacement decomposition

```text
Delta_j H_T
 = (1/n) [ A_j + sum_(i != j) xi_ij ],                 (9.1)
```

where `|A_j|<=T` is the direct clipped-evaluation term and `xi_ij` is a deletion/replacement clipped-loss influence.

Therefore conditional `L^2` Minkowski gives

```text
sqrt(q_j)
:= ||Delta_j H_T||_(L^2 | F_(j-1))
 <= (1/n)
    [ T + sum_(i != j)
      ||xi_ij||_(L^2 | F_(j-1)) ].                    (9.2)
```

Suppose the deletion-anchor theorem applies uniformly to every relevant `(i,j)` context with predictable or deterministic envelopes

```text
b_k <= B,
v <= L/n,
gamma^2/(8 sigma^2) >= 2 log n + u.                  (9.3)
```

Then `(8.4)` and `(7.4)` give

```text
||xi_ij||_2
 <= [4 L sqrt(TB) + 2 T e^(-u/2)]/n.                 (9.4)
```

Substitution into `(9.2)` yields

```text
boxed:
sqrt(q_j)
 <= [ T + 4 L sqrt(TB) + 2 T e^(-u/2) ] / n,         (9.5)
```

and hence

```text
boxed:
q_j
 <= [ T + 4 L sqrt(TB) + 2 T e^(-u/2) ]^2 / n^2.    (9.6)
```

This closes the **variance-scale** part of `P19-GHOST-RAREBOUNDARY-36`.

The practical point is important. A blind ghost estimator must discover a rare order-one support flip by sampling it. Formula `(9.6)` instead certifies the rare boundary analytically from two quantities with direct algorithmic meaning:

1. one-observation insertion/retraining drift scale `sigma,L/n`;
2. deletion-trained top-`k` score gap `gamma`.

If these are source-certified, the predictable variance does not require `Theta(n^2)` ghost draws merely to discover a boundary event whose probability is already exponentially/polynomially bounded by the margin theorem.

A safe hybrid certificate is simply

```text
U_j^hybrid=min{ U_j^ghost, U_j^margin },
```

where `U_j^ghost` is the preceding finite ghost UCB and `U_j^margin` is any simultaneously valid implementation of `(9.6)`. The minimum of two valid upper bounds is valid on their joint validity event. If `L,sigma,gamma,B` are themselves estimated, their estimation error must be included; they cannot be plugged in from the same data without a simultaneous argument.

# 10. The remaining exponential-confidence issue

A small predictable variance does not by itself make the martingale increments sub-Gaussian. Rare support flips can be large. This was already exposed by `P19-VARONLY-SELFNORM-CE-34`.

The right next object is an MGF that preserves the rare-jump probability explicitly.

## `P19-RAREJUMP-MGF-36` — PROVED

Let `X` be conditionally mean zero given a sigma-field `G`. Suppose

```text
|X| <= B almost surely,
```

and for a `G`-measurable good event indicator one has

```text
P{|X|>a | G} <= p,
0<=a<=B.
```

Then for every `lambda>=0`,

```text
boxed:
log E[e^(lambda X)|G]
 <= (lambda^2/2)
    [ a^2 e^(lambda a)
      + p B^2 e^(lambda B) ].                         (10.1)
```

### Proof

For every real `x`, Taylor's formula with integral remainder gives

```text
e^(lambda x)
 <= 1+lambda x
    +(lambda^2 x^2/2) e^(lambda |x|).
```

Take the conditional expectation. The linear term vanishes because `E[X|G]=0`. On the good event, `x^2 e^(lambda|x|)<=a^2 e^(lambda a)`; on its complement it is at most `B^2 e^(lambda B)`, whose conditional probability is at most `p`. Thus

```text
E[e^(lambda X)|G]
 <= 1 +(lambda^2/2)
    [a^2 e^(lambda a)+pB^2 e^(lambda B)].
```

Use `log(1+y)<=y`.

QED.

### Doob application

For the inherited replacement identity

```text
D_j=E[Delta_j H_T | F_j],
```

conditional Jensen gives

```text
E[e^(lambda D_j)|F_(j-1)]
 <= E[e^(lambda Delta_j H_T)|F_(j-1)].                (10.2)
```

Therefore any rare-boundary good/bad decomposition for the **actual full coordinate replacement** immediately transfers to the Doob increment.

Equation `(10.1)` explains exactly when the universal `O(T)` Bernstein scale can be beaten at the confidence level of interest. If the good-region increment is `a=O(1/n)` and the boundary probability is super-polynomial or exponential enough that

```text
p e^(lambda B)
```

remains tiny at the optimizing `lambda`, the large jump does not dominate the MGF. If `p` is only modestly small, the order-one range still matters. This is a quantitative statement, not a heuristic.

### What is still missing

The score-gap theorem supplies the rare **support-flip** probability. To turn it into a small good-region **pathwise** increment `a`, one additionally needs a feature/output envelope or a conditional feature-tail theorem. A covariance bound alone only gives RMS control. Section 12 gives an exact counterexample showing that this extra requirement is necessary.

# 11. `P19-MARGIN-SCALE-CE-36` — PROVED

A positive retraining-stability scale without a score margin cannot control hard pruning.

Take `r=2`, `q=1`, `k=1`, anchor

```text
C_0=(1,1),
```

with the fixed tie rule selecting coordinate 1. Let a fresh insertion produce

```text
C_Z=(1+Z/n, 1-Z/n),
```

where `Z` is Rademacher.

Then deterministically

```text
||C_Z-C_0||_F=sqrt(2)/n.                              (11.1)
```

Nevertheless

```text
S_1(C_Z)={1} if Z=+1,
S_1(C_Z)={2} if Z=-1.
```

For two iid insertions `Z,Z'`,

```text
P{S_1(C_Z) != S_1(C_Z')}=1/2.                        (11.2)
```

Under an honest proxy `psi~N(0,I_2)`, when the supports differ the two pruned coefficient vectors are

```text
(1+1/n,0),
(0,1+1/n),
```

so their prediction `L^2` distance squared is

```text
2(1+1/n)^2.
```

Averaging over the support-disagreement event gives order-one prediction RMS despite `O(1/n)` pre-pruning drift.

Thus

```text
boxed:
small one-observation coefficient drift
 does not imply small post-pruning RMS
 without a score-margin condition.
```

This is the stochastic counterpart of the earlier deterministic boundary-flip counterexample.

# 12. `P19-SMALLCOEFF-NOT-PATHWISELOSS-CE-36` — PROVED

The margin theorem closes the variance branch, but not by itself the pathwise Bernstein-scale branch for unbounded features.

Take fixed support `k=1`, target `Y=0`, coefficient readouts

```text
C=0,
C'=epsilon,
```

and a deterministic query feature

```text
psi(X)=sqrt(T)/epsilon.
```

Then

```text
||C-C'||=epsilon -> 0,
```

but

```text
f(X)=0,
f'(X)=sqrt(T),
```

so the clipped squared losses differ by exactly

```text
T.
```

Therefore an arbitrarily small coefficient perturbation can still produce the full clipped-loss range on a sufficiently large feature realization. Hence:

```text
boxed:
score margin + small coefficient drift
 does not imply a small pathwise clipped-loss increment
 without a feature/output envelope or tail condition.
```

This is why `(9.6)` is a true predictable-variance theorem while a full `O(1/n)` Bernstein scale remains **CONDITIONAL** on an additional feature-tail statement.

P16 considers a period-two ReLU candidate with positive phase vectors `u` on support `S` and `v` on support `T`. Put

```text
I=S cap T,
U=S union T,
R=U^c.
```

For an outside row `i in R`, after conditioning on the internal rows, P16 claims

```text
X_i=w_i^T u,
Y_i=w_i^T v
```

are centered Gaussian with correlation

```text
rho=<u_I,v_I>/(||u|| ||v||),
```

and

```text
P{X_i<=0,Y_i<=0}
 = 1/4 + arcsin(rho)/(2 pi).                           (13.1)
```

### Independent derivation

Because the tied Gaussian matrix has iid rows, conditioning on all rows indexed by `U` leaves every outside row independent with its original centered Gaussian law. Hence

```text
Var(X_i)=(alpha/N)||u||^2,
Var(Y_i)=(alpha/N)||v||^2,
Cov(X_i,Y_i)=(alpha/N)<u_I,v_I>.
```

This gives P16's `rho` exactly.

Standardize to a bivariate standard Gaussian `(X,Y)` of correlation `rho`. Write

```text
X=G_1,
Y=rho G_1 + sqrt(1-rho^2) G_2,
```

with `(G_1,G_2)` isotropic in the plane. The event `X>0,Y>0` is a planar wedge. Its opening angle is

```text
pi/2 + arcsin(rho).
```

Rotational invariance therefore gives

```text
P(X>0,Y>0)
 = [pi/2+arcsin(rho)]/(2 pi)
 = 1/4+arcsin(rho)/(2 pi).
```

Central symmetry gives the same value for `P(X<0,Y<0)`. Gaussian nondegeneracy makes the distinction between `<` and `<=` irrelevant. This proves `(13.1)`.

Different outside rows are independent after the same conditioning because they use disjoint iid Gaussian rows. Therefore the total outside factor is exactly

```text
[1/4+arcsin(rho)/(2 pi)]^(N-|U|),
```

which is P16's stated claim.

### Verdict

**PASS.** The conditioning, covariance, orthant constant, and row-product exponent are all correct. The result is restricted to the outside rows; it does not make the overlapping internal blocks independent, and P16 does not claim otherwise.

A numerical sanity check at `rho=0.6` with 500,000 Gaussian pairs gave empirical orthant probability `0.352042` versus exact `0.35241638`, consistent within Monte Carlo fluctuation. The simulation is not used as proof.


## 14.3 Singular-vector overlap

## 14.5 Coefficient/operator and singular-subspace stability

for two legally aligned `k`-sparse deployed readouts and their support union obeys

# 15. Same-trained-matrix pruning audit

The new theorem explicitly checks the dependence issue requested by the user.

1. `S_k(C(Z))` is the deterministic support chosen from the fully retrained matrix for insertion `Z`.
2. The support is rerun after replacement; it is not frozen.
3. No Bernoulli/iid mask is substituted.
4. The event of a support change is bounded through actual score crossings around a common deletion-trained anchor.
5. If an honest Gaussian/sparse-RIP proxy is used, its simultaneous support theorem must be uniform over all relevant supports. It is not legitimate to condition on a trained support and then pretend that support was fixed independently of the same matrix.
