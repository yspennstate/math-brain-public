# 4. Adaptive low-rank perturbations cannot change the global MP ESD

## `P19-ADAPTIVE-RANK-MP-IMMUNITY-46 — PROVED`

Let `A,B` be `n x m` matrices over `R` or `C`, and assume

`rank(A-B) <= r`.

Then

`rank(AA^* - BB^*) <= 2r`.

Consequently, if `F_{AA^*}` and `F_{BB^*}` denote the empirical spectral distribution functions normalized by `n`,

`sup_x |F_{AA^*}(x)-F_{BB^*}(x)| <= 2r/n`.

### Proof

Write `D=A-B`. Then

`AA^*-BB^* = D A^* + B D^*`.

Each summand has rank at most `rank(D)<=r`, so the rank of the sum is at most `2r`.

For two `n x n` Hermitian matrices `M,N`, the standard rank/interlacing inequality gives

`sup_x |F_M(x)-F_N(x)| <= rank(M-N)/n`.

Apply this with `M=AA^*`, `N=BB^*`.

### Corollary: adaptive MP bulk immunity

Let

`W_n = X_n + P_n`

where `P_n` may be an arbitrary measurable function of `X_n` and of the training data. If

`rank(P_n)=r_n=o(n)`,

then

`sup_x |F_{W_n W_n^*}(x)-F_{X_n X_n^*}(x)| <= 2r_n/n -> 0`

pathwise. Therefore any limiting global squared-singular-value ESD of `X_n`—in particular the MP law under source hypotheses—is inherited by `W_n`.

**No independence, no moment assumption on `P_n`, and no bound on `||P_n||_op` is used in this transfer.**

### Hard top-k structured-pruning corollary

If `H_k(C)` retains only `k` columns of a matrix `C`, then

`rank(H_k(C)) <= k`.

Therefore, if this retained matrix is the additive signal in `W=X+H_k(C)` and `k=o(n)`, the global MP ESD is immune to the fact that the support was selected from the trained matrix itself.

This statement is about **low-rank additive signal after column pruning**. It does not apply to arbitrary entrywise pruning of the noise matrix; an entrywise masked difference can have full rank.

### What this theorem does not say

Rank control alone does not control extremes or vectors. A rank-one perturbation can move the top singular value by order one or more, and a rank-one signal selected as the top singular direction of the same noise has planted overlap one by construction. Thus:

- global ESD/MP bulk: robust under `o(n)` adaptive rank;
- extreme singular values: require separate control;
- singular-vector/projector overlap: require resolvent/SLL/contour information.

This strengthens the earlier P19 MP-ESD transfer, which unnecessarily carried an operator-closeness/tightness debt for the global ESD layer.

# 5. Ridge-whitened learned-readout proxy theorem

Consider two ridge systems on the same output labels `y_i`.

The reference/source-legal feature rows are `x_i`; the actual learned feature rows are `x~_i`. Define empirical moments

`A0 = (1/N) sum_i x_i x_i^*`,

`B0 = (1/N) sum_i y_i x_i^*`,

`H0 = A0 + lambda0 I`,

`C0 = B0 H0^{-1}`,

and

`A = (1/N) sum_i x~_i x~_i^*`,

`B = (1/N) sum_i y_i x~_i^*`,

`H = A + lambda I`,

`C = B H^{-1}`.

The actual learned features may depend on the same sample/labels. This section is deterministic once the two systems are realized.

## `P19-RIDGEWHITENED-READOUT-PROXY-46 — PROVED`

Set

`S = H0^{-1/2}(H-H0)H0^{-1/2}`,

`delta = ||S||_op < 1`,

`z = ||(B-B0)H0^{-1/2}||_F`,

`a = ||B0 H0^{-1/2}||_F`,

`mu = lambda_min(H0)>0`.

Then

`boxed: ||C-C0||_F <= (z+a delta)/(sqrt(mu)(1-delta)).`

### Proof

Because

`H = H0^{1/2}(I+S)H0^{1/2}`,

we have

`H^{-1}=H0^{-1/2}(I+S)^{-1}H0^{-1/2}`.

Since `delta<1`,

`||(I+S)^{-1}||_op <= 1/(1-delta)`

and

`||(I+S)^{-1}-I||_op <= delta/(1-delta)`.

Now

`C-C0 = (B-B0)H^{-1} + B0(H^{-1}-H0^{-1})`.

Substituting the normalized inverse gives

`C-C0`

`= [(B-B0)H0^{-1/2}(I+S)^{-1}`

`   + B0 H0^{-1/2}((I+S)^{-1}-I)] H0^{-1/2}`.

Using the Frobenius/operator product inequality and

`||H0^{-1/2}||_op = 1/sqrt(mu)`

yields exactly

`||C-C0||_F`

`<= [ z/(1-delta) + a delta/(1-delta) ] / sqrt(mu)`.

No independence claim is used.

### Relation to the P15 ridge-whitened theorem

This proof uses the same relative resolvent geometry as the current P15 result, but it is a distinct matrix-readout statement: the perturbation includes both the feature covariance `A` and the feature-label cross moment `B`, which are exactly the quantities needed to control the coefficient/readout matrix that will subsequently be pruned.

# 7. Population proxy, trained support lock, and source legality

Let the reference feature map be a fixed or independently cross-fitted/source-legal map `phi0`, with `x_i=phi0(U_i)` and `||x_i||<=R`. Let `C0` denote its empirical ridge readout at ridge `lambda0` and let

`C_* = B_*(A_*+lambda0 I)^{-1}`

be the deterministic population ridge readout.

The preceding P19 run proved, for iid bounded `(x_i,y_i)`, the high-probability fixed-feature concentration

`||C0-C_*||_F <= r_pop(eta)`

with

`r_pop(eta)`

`= [YR/(lambda0 sqrt(N))][1+R^2/lambda0][1+sqrt(2 log(2/eta))]`

with probability at least `1-eta`.

Let

`r_feat = (z+a delta)/(sqrt(mu)(1-delta))`

or use the explicit upper bound from Section 6, and define

`R_N = r_pop(eta)+r_feat`.

Then, on the fixed-feature concentration event,

`||C-C_*||_F <= R_N`.

## `P19-NEURAL-POPULATION-PROXY-46 — PROVED under the stated benchmark hypotheses`

Let `H_k` denote deterministic hard top-k pruning by column Euclidean norm with fixed tie rule. Let

`gamma_* = score_(k)(C_*) - score_(k+1)(C_*)`.

If

`gamma_* > 2 R_N`,

then the actual learned readout `C` and deterministic population proxy `C_*` have exactly the same top-k column support. Consequently, with

`P = H_k(C)`, `P_* = H_k(C_*)`,

`boxed: ||P-P_*||_op <= ||P-P_*||_F <= R_N.`

### Proof

Every column norm is 1-Lipschitz with respect to the full Frobenius perturbation. Thus all column scores of `C` differ from those of `C_*` by at most `R_N`. A population gap larger than `2R_N` prevents any selected/unselected score crossing. On the common support, pruning is an orthogonal coordinate projection, so it does not increase the Frobenius difference.

### Same-matrix pruning audit

This is precisely why no iid mask appears. The support is allowed to be selected from the trained `C`; equality with a deterministic/source-legal support is a theorem consequence of the population margin. If the population gap condition fails, the argument stops and the earlier boundary-energy/rare-jump route remains necessary.

# 9. Separation of the five spectral/statistical layers

The present run strengthens the separation that P19 has enforced throughout:

1. **Global eigenvalue/squared-singular-value distribution.** Low-rank rank inequality is enough. Adaptive `o(n)` rank cannot change the limiting ESD, even if its norm is huge.
2. **Extreme singular values.** Rank alone is useless for their location. Weyl gives transfer only after an operator perturbation bound such as `R_N` is available.
3. **Eigenvector/singular-vector/projector overlap.** This is a resolvent/subspace-local-law object. The August theorem uses stable projectors/cross projectors; the adaptive actual matrix is reached through a legal proxy plus deterministic Riesz/Procrustes transfer.
4. **Prediction/operator-learning performance.** The readout coefficient bound is a separate object. Prediction movement follows from a feature covariance upper bound; conversely prediction movement gives coefficient control only with a genuine restricted lower Gram floor. The inherited unidentifiable-feature counterexample remains active.
5. **Finite-width/training effects.** These are the explicit debts `epsilon`, ridge drift `xi`, relative ridge perturbation `delta`, cross-moment debt `z`, population concentration `r_pop`, pruning margin `gamma_*`, retained singular floor `g`, and contour clearance `d_Gamma`.

### Method comparison

- **Resolvent/Riesz:** the preferred route for source projector laws and clustered spikes.
- **Davis–Kahan/Wedin:** legal only after a genuine gap; no BBP constants are manufactured from it.
- **Leave-one-out / predictable concentration:** still the correct fallback when no deterministic/cross-fit proxy margin exists; the earlier boundary-energy MGF problem remains open.
- **Free probability / global deterministic equivalents:** useful for global distributions or prediction equivalents, but they do not erase adaptive signal-frame bias or prove singular-vector overlap by themselves.
- **Sparsification concentration:** simultaneous restricted events can survive trained support selection; fixed-support/iid-mask laws cannot simply be conditioned through a support chosen from the same matrix.
- **Counterexamples:** remain essential because MP-looking bulk behavior is compatible with radically non-MP singular-vector behavior under adaptive rank-one spikes.

# 10. Preserved failures and counterexamples

The following routes remain rejected and are not revived by the new theorems.

## 10.1 Same-matrix iid-mask substitution — `DISPROVED`

A support selected from the trained matrix is not an iid mask. Conditioning a fixed-support concentration law on that selection generally changes its distribution. The correct repairs are a simultaneous structured event, an actual margin/support-lock theorem, or a predictable/cross-fitted argument.

## 10.2 MP bulk implies BBP vector law — `DISPROVED`, now even more sharply separated

The new rank theorem proves that an adaptive rank-one spike cannot change the limiting global ESD. Yet the inherited construction `P=theta u_1(X)v_1(X)^*` moves the leading singular value for every `theta>0`, has planted overlap one by construction, and violates the scalar independent-frame resolvent compression. Thus a perfect MP bulk is compatible with a completely non-independent singular-vector law.

## 10.3 Absolute signal closeness without a relative identification scale — `DISPROVED`

If the retained signal singular floor vanishes, `||P-P_*||_op=o(1)` alone need not align the signal frame. The ratio `R_N/g` is the relevant identification scale.

## 10.4 Prediction closeness without restricted identifiability — `DISPROVED`

A feature covariance can vanish in a direction along which two coefficient matrices differ. Prediction equality therefore does not imply coefficient or singular-vector equality without a lower Gram/restricted eigenvalue condition.

## 10.5 Local support lock implies independent-ghost closeness — `DISPROVED`

A sample can have every immediate one-coordinate neighbor on the same support while an independent sample lies on another support with probability tending to one. Local lock is a local perturbation theorem, not a ghost-distribution theorem.

## 10.6 July activation identity implies fresh-risk improvement — `DISPROVED route`

The exact identity `||Ea||^2=sum_j(...)` is a realized perturbation identity. Fresh prediction risk requires a feature/query law and relevant covariance/tail control.

`H~=H^{1/2}(I+S)H^{1/2}`

which gives `delta/(1-delta)`.

For the prediction difference, split it into a query-vector movement term and an inverse movement term; Cauchy–Schwarz in the `H^{-1/2}` geometry yields exactly P15's displayed coefficient. No independence is needed.
