\tag{0.7}

# 4. `P19-RIDGE-INSERTION-RADIUS-43` — PROVED

Let `z=(x,y)` with

\[
\|x\|_2\le R,
\qquad
\|y\|_2\le Y.
\tag{4.1}
\]

For an `(n-1)`-sample deletion set `D`, define

\[
F_D^{[n]}(C)
=
\frac1{2n}\sum_{z_j\in D}\|Cx_j-y_j\|_2^2
+
\frac\lambda2\|C\|_F^2,
\tag{4.2}
\]

and its minimizer `C_D`. For an admissible insertion `z`, define

\[
F_{D,z}(C)
=F_D^{[n]}(C)+\frac1{2n}\|Cx-y\|_2^2,
\tag{4.3}
\]

and let `C_{D,z}` be its minimizer.

## 4.1 Uniform norm bound

Because `C_D` minimizes `(4.2)`,

\[
F_D^{[n]}(C_D)\le F_D^{[n]}(0)\le\frac{Y^2}{2}.
\]

Therefore

\[
\boxed{
\|C_D\|_F\le\frac Y{\sqrt\lambda}.
}
\tag{4.4}
\]

The same bound holds for every full `n`-sample minimizer `C_{D,z}`.

## 4.2 Strong-convexity insertion estimate

`F_{D,z}` is `lambda`-strongly convex in Frobenius geometry. Since

\[
\nabla F_D^{[n]}(C_D)=0,
\]

we have

\[
\nabla F_{D,z}(C_D)
=
\frac1n(C_Dx-y)x^*.
\tag{4.5}
\]

By strong monotonicity of the gradient,

\[
\lambda\|C_{D,z}-C_D\|_F
\le
\|\nabla F_{D,z}(C_D)\|_F.
\tag{4.6}
\]

Using `(4.4)`,

\[
\|(C_Dx-y)x^*\|_F
=\|C_Dx-y\|_2\|x\|_2
\le
YR\left(1+\frac R{\sqrt\lambda}\right).
\tag{4.7}
\]

Hence

\[
\boxed{
\|C_{D,z}-C_D\|_F
\le
\rho_n
:=
\frac{YR}{n\lambda}
\left(1+\frac R{\sqrt\lambda}\right).
}
\tag{4.8}
\]

This holds for every admissible insertion, not just in expectation.

Consequently for two insertions `z,z'` over the same deletion anchor,

\[
\boxed{
\|C_{D,z}-C_{D,z'}\|_F\le2\rho_n.
}
\tag{4.9}
\]

This is the smooth pre-pruning replacement scale.

# 5. `P19-DELETION-BOUNDARY-ENERGY-43` — PROVED

The hard-pruning map is deterministic and trained-matrix adaptive.

For any matrix `C=[c_1 ... c_d]`, define column scores

\[
s_j(C)=\|c_j\|_2.
\tag{5.1}
\]

`H_k(C)` keeps the `k` largest-score columns and sets the others to zero, using a fixed deterministic tie-breaking rule.

## 5.1 General top-`k` boundary lemma

Let `C,C'` satisfy

\[
\|C-C'\|_F\le\delta.
\tag{5.2}
\]

Let `S=S_k(C)`, `S'=S_k(C')`, let

\[
\tau=s_{(k)}(C),
\qquad
\gamma=s_{(k)}(C)-s_{(k+1)}(C),
\tag{5.3}
\]

and define

\[
B_\delta(C)=\{j:|s_j(C)-\tau|\le2\delta\}.
\tag{5.4}
\]

For every `j`,

\[
|s_j(C)-s_j(C')|
\le\|c_j-c_j'\|_2
\le\delta.
\tag{5.5}
\]

If `j in S\S'` and `l in S'\S`, then by the two top-`k` orderings

\[
s_j(C)\ge s_l(C),
\qquad
s_l(C')\ge s_j(C').
\]

Therefore

\[
0\le s_j(C)-s_l(C)\le2\delta.
\tag{5.6}
\]

Since every dropped score is at least `tau` and every entering score is at most `tau`, `(5.6)` implies

\[
(S\triangle S')\subseteq B_\delta(C),
\qquad
S\ne S'\Longrightarrow\gamma\le2\delta.
\tag{5.7}
\]

In particular,

\[
\boxed{\gamma>2\delta\Longrightarrow S'=S.}
\tag{5.8}
\]

The exact column decomposition is

\[
\begin{aligned}
\|H_k(C)-H_k(C')\|_F^2
={}&
\sum_{j\in S\cap S'}\|c_j-c_j'\|_2^2\\
&+\sum_{j\in S\setminus S'}s_j(C)^2
+\sum_{j\in S'\setminus S}s_j(C')^2.
\end{aligned}
\tag{5.9}
\]

Thus, with

\[
\Phi_\delta(C)
:=
1_{\{\gamma\le2\delta\}}
\sum_{j\in B_\delta(C)}(s_j(C)+\delta)^2,
\tag{5.10}
\]

we obtain the asymmetric but exact useful bound

\[
\boxed{
\|H_k(C)-H_k(C')\|_F^2
\le
\delta^2+\Phi_\delta(C).
}
\tag{5.11}
\]

No support is randomized; this is a pathwise statement about the actual trained top-`k` rule.

## 5.2 Common deletion-anchor version

Return to Section 4. For deletion anchor `C_D`, write

\[
a_j=s_j(C_D),
\quad
\tau_D=a_{(k)},
\quad
\gamma_D=a_{(k)}-a_{(k+1)},
\tag{5.12}
\]

\[
B_D=\{j:|a_j-\tau_D|\le2\rho_n\},
\tag{5.13}
\]

and

\[
\boxed{
\Phi_D
=
1_{\{\gamma_D\le2\rho_n\}}
\sum_{j\in B_D}(a_j+\rho_n)^2.
}
\tag{5.14}
\]

Every insertion-trained matrix lies within `rho_n` of `C_D`. Therefore every support change relative to the anchor lies inside `B_D`. For two insertions `z,z'`, the shared-support contribution is at most

\[
\|C_{D,z}-C_{D,z'}\|_F^2\le4\rho_n^2,
\]

while every column appearing in the support symmetric difference has insertion score at most `a_j+rho_n`. Hence

\[
\boxed{
\|H_k(C_{D,z})-H_k(C_{D,z'})\|_F^2
\le
4\rho_n^2+\Phi_D.
}
\tag{5.15}
\]

If

\[
\gamma_D>2\rho_n,
\tag{5.16}
\]

then every admissible insertion has exactly the anchor support and `(5.15)` improves to

\[
\boxed{
\|H_k(C_{D,z})-H_k(C_{D,z'})\|_F
\le2\rho_n.
}
\tag{5.17}
\]

## 5.3 Boundary occupancy/amplitude reduction

Let

\[
b_D=|B_D|.
\]

For `j in B_D`, `a_j<=tau_D+2rho_n`; therefore

\[
\boxed{
\Phi_D
\le
1_{\{\gamma_D\le2\rho_n\}}
 b_D(\tau_D+3\rho_n)^2.
}
\tag{5.18}
\]

Also `(a+rho)^2<=2a^2+2rho^2` and `||C_D||_F^2<=Y^2/lambda`, so

\[
\boxed{
\Phi_D
\le
1_{\{\gamma_D\le2\rho_n\}}
\left(
\frac{2Y^2}{\lambda}+2d\rho_n^2
\right).
}
\tag{5.19}
\]

This distinguishes three genuinely different pruning diagnostics:

1. the score gap `gamma_D`;
2. the number of channels near the threshold `b_D`;
3. the amplitude/energy scale `tau_D` of those channels.

A vanishing score gap alone does not determine whether hard pruning is unstable.

# 6. `P19-RIDGE-PRUNED-GHOST-MSE-43` — PROVED

Let

\[
P(S)=H_k(C_S)
\tag{6.1}
\]

for iid data `S=(Z_1,...,Z_n)`, and let `S'` be an independent copy. Define

\[
P_0=P(S').
\tag{6.2}
\]

For coordinate `i`, let `S^{(i)}` replace `Z_i` by an independent copy. The two training sets `S` and `S^{(i)}` are exactly two insertions into the common deletion anchor `S_{-i}`. Therefore `(5.15)` gives

\[
\|P(S)-P(S^{(i)})\|_F^2
\le
4\rho_n^2+\Phi_i,
\tag{6.3}
\]

where `Phi_i` is computed from the deletion-trained anchor `C_{-i}` and does **not** depend on either inserted value.

Hilbert-space Efron–Stein gives

\[
E\|P(S)-P(S')\|_F^2
=
2E\|P-EP\|_F^2
\le
\sum_{i=1}^n
E\|P(S)-P(S^{(i)})\|_F^2.
\tag{6.4}
\]

Combining `(6.3)` and `(6.4)`,

\[
\boxed{
E\|P-P_0\|_F^2
\le
4n\rho_n^2
+
\mathfrak B_n,
\qquad
\mathfrak B_n:=\sum_{i=1}^nE\Phi_i.
}
\tag{6.5}
\]

Since

\[
\rho_n
=
\frac{K_{\lambda,R,Y}}n,
\qquad
K_{\lambda,R,Y}
=
\frac{YR}{\lambda}\left(1+\frac R{\sqrt\lambda}\right),
\tag{6.6}
\]

we have

\[
4n\rho_n^2
=
\frac{4K_{\lambda,R,Y}^2}{n}.
\tag{6.7}
\]

Thus fixed-feature ridge supplies the correct smooth `1/n` ghost mean-square scale automatically. Hard pruning adds exactly `mathfrak B_n`.

A prediction/operator-learning corollary is immediate. If a fresh feature vector `psi` is independent of `(S,S')` and

\[
G=E[\psi\psi^*]\preceq bI,
\tag{6.8}
\]

then

\[
\boxed{
E\|(P-P_0)\psi\|_2^2

# 9. Spectral hierarchy and method comparison

The program continues to keep five layers separate.

## 9.1 Global eigenvalue / singular-value distribution

A Marchenko–Pastur ESD statement controls the bulk distribution and, in rectangular regimes, its possible zero atom. It says nothing by itself about the orientation of a same-matrix trained/pruned signal frame. The retained adaptive rank-one BBP counterexample proves this sharply.

## 9.2 Restricted extreme singular values

For prediction-to-operator identification after structured pruning, a simultaneous sparse restricted Gram floor is the relevant object. A global MP hard edge may be zero while every support of size `s` has a positive lower edge when `s log(ed/s)<<n`. This is an inherited proved separation.

## 9.3 Singular-vector / subspace overlap

The August source derives overlap/projector weights through holomorphic resolvent compression. The correct growing-rank objects are projectors and the cross projector/mixed dyad. Individual-vector statements require isolation.

The new theorem reaches this layer only after the dimensionless relative signal condition `(7.4)` has been proved against a source-legal proxy.

## 9.4 Prediction / operator-learning performance

Ridge replacement sensitivity is a direct finite-sample operator-learning statement. Equation `(6.9)` converts it to fresh prediction movement under an upper feature covariance bound. The reverse direction still requires a restricted lower Gram floor.

## 9.5 Finite-width / finite-sample debts

The explicit debts are now:

- ridge insertion radius `rho_n`;
- deletion score gap `gamma_i`;
- boundary occupancy `|B_i|`;
- boundary amplitude `tau_i`;
- retained ghost singular floor `g_n`;
- source SLL error / compatibility / stable contour;
- for exponential confidence, a globally small jump or legal full-vector MGF / predictable rare-jump certificate.

### Resolvent methods

Still the correct route for the actual BBP/projector constants and for non-Haar source validation. The new pruning theorem only transfers a legal SLL from a proxy to the adaptive frame.

### Davis–Kahan / Wedin

Useful only after a real singular gap is known. The retained singular floor `g_n` is an identification scale for the signal frame; a deployed outlier cluster additionally needs a stable contour/gap. No gap is inferred merely from prediction stability.

### Leave-one-out / deletion anchors

This run shows a concrete advantage: the same deletion learner is the common anchor for the observed and ghost replacement values. Its score boundary is therefore the exact object controlling whether deterministic top-`k` can jump.

### Free probability / deterministic equivalents

No free-probability shortcut is used. Global deterministic equivalents can describe eigenvalue distributions or fixed-frame risks, but they do not erase dependence created by choosing a signal/support from the same matrix. Any asymptotic-freeness reduction would require its own proof under the adaptive selection rule.

### Sparsification concentration

If prediction discrepancies rather than direct ridge parameter differences are used, simultaneous sparse-RIP/restricted-Gram concentration remains valid after adaptive support selection because the event is quantified over all supports before selection. A fixed-support or iid-mask calculation conditioned through trained support selection is not valid.
