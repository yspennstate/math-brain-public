# 4. Setup and exact coordinate replacement decomposition

Let

`S = (Z_1,...,Z_n)`

with iid `Z_i=(X_i,Y_i)`. Auxiliary training randomness is independent of `S` and held common across replacement/deletion couplings.

For each `i`, let

`f_-i = A(S_-i)`

be the deletion retrain. For `j != i`, replace retained observation `Z_j` by an independent copy `Z_j'` and write

`f_-i^(j) = A(S_-i^(j))`.

Use squared loss and analytic clipping

```text
ell(f;z)   = ||y-f(x)||^2,
ell_T(f;z) = min{ell(f;z), T}.
```

Define

```text
R_(i,T)       = E_Z ell_T(f_-i;Z),
Rhat_loo,T    = n^(-1) sum_i ell_T(f_-i;Z_i),
Rbar_loo,T    = n^(-1) sum_i R_(i,T),
H_T           = Rbar_loo,T - Rhat_loo,T.
```

As in the preceding run, `E H_T = 0` because `Z_i` is independent of `f_-i`.

For an independent copy `Z_j'`, let `S^(j)` be the full sample with coordinate `j` replaced and write

`Delta_j H_T = H_T(S) - H_T(S^(j))`.

Define, for `i != j`,

```text
d_ij(z)
 = ell_T(f_-i;z) - ell_T(f_-i^(j);z),

xi_ij
 = E_Z d_ij(Z) - d_ij(Z_i).
```

For `i=j`, deletion removes the changed training coordinate, so `f_-j` is identical before and after replacement. Put

```text
A_j
 = ell_T(f_-j;Z_j') - ell_T(f_-j;Z_j).
```

Then the coordinate replacement has the exact decomposition

```text
Delta_j H_T
 = n^(-1) [ A_j + sum_(i != j) xi_ij ].               (4.1)
```

Also `|A_j| <= T` pathwise.

This is the quantity that must receive an exponential-moment bound. The individual `xi_ij` for fixed `j` need not be independent; the theorem below does not assume they are.

# 5. `P19-LOO-CONDITIONAL-BERNSTEIN-33` — PROVED

Let

`F_j = sigma(Z_1,...,Z_j)`

and define the Doob differences

```text
D_j
 = E[H_T | F_j] - E[H_T | F_(j-1)].
```

Assume deterministic numbers `v_j >= 0`, `c_j >= 0` such that almost surely, for every integer `m >= 2`,

```text
E[ |Delta_j H_T|^m | F_(j-1) ]
<= (m!/2) v_j c_j^(m-2).                               (5.1)
```

Set

```text
V = sum_j v_j,
c = max_j c_j.
```

Then for every `t>0`,

```text
P{ H_T >= sqrt(2 V t) + c t } <= exp(-t).              (5.2)
```

Equivalently, with probability at least `1-eta`,

```text
H_T
<= sqrt( 2 V log(1/eta) ) + c log(1/eta).              (5.3)
```

## Proof

### Step 1: replacement identity for the Doob increment

Conditional on `F_j`, replacing `Z_j` by an independent copy and averaging over that copy and all future coordinates erases the information in `Z_j`. Hence

```text
E[ H_T(S^(j)) | F_j ]
 = E[ H_T(S) | F_(j-1) ].
```

Therefore

```text
D_j
 = E[ Delta_j H_T | F_j ].                             (5.4)
```

Also, conditional on `F_(j-1)`, the pair `(Z_j,Z_j')` is exchangeable, so

`E[Delta_j H_T | F_(j-1)] = 0`.

### Step 2: conditional MGF of one replacement

For `0 <= lambda < 1/c_j`, the moment condition and conditional centering give

```text
E[ exp(lambda Delta_j H_T) | F_(j-1) ]
<= 1 + sum_(m>=2) lambda^m E|Delta_j H_T|^m / m!
<= 1 + [lambda^2 v_j] / [2(1-lambda c_j)]
<= exp( [lambda^2 v_j] / [2(1-lambda c_j)] ).           (5.5)
```

### Step 3: transfer the MGF to the Doob increment

By conditional Jensen and `(5.4)`,

```text
E[ exp(lambda D_j) | F_(j-1) ]
<= E[ exp(lambda Delta_j H_T) | F_(j-1) ]
<= exp( [lambda^2 v_j] / [2(1-lambda c_j)] ).           (5.6)
```

### Step 4: iterate the martingale MGF

Since `c_j <= c`, iterating `(5.6)` gives

```text
E exp(lambda H_T)
<= exp( lambda^2 V / [2(1-lambda c)] ),
0 <= lambda < 1/c.                                      (5.7)
```

This is the standard sub-gamma MGF form.

For a target level

`x = sqrt(2 V t) + c t`,

choose

```text
lambda
 = sqrt(2t/V) / [ 1 + c sqrt(2t/V) ]
```

when `V>0`; the zero-variance case is immediate. Direct substitution into the Chernoff exponent gives exactly

`lambda x - lambda^2 V/[2(1-lambda c)] = t`.

Thus `(5.2)` follows.

QED.

### Relation to Freedman/Bernstein

Freedman's 1975 Annals of Probability paper `On Tail Probabilities for Martingales`, DOI `10.1214/aop/1176996452`, is the primary classical benchmark for Bernstein-type martingale tails. The proof above is self-contained and uses a conditional Bernstein moment condition rather than importing a source constant without checking hypotheses.

# 6. `P19-LOO-PSI1-INFLUENCE-33` — concrete sufficient condition

Use the conditional Luxemburg convention

```text
||X||_(psi_1 | G)
 = inf{ K>0 : E[ exp(|X|/K) | G ] <= 2 }.
```

Suppose that for every `i != j`, almost surely in the deletion/replacement learner pair,

```text
|| ||f_-i(X)-f_-i^(j)(X)|| ||_(psi_1(P_X))
<= L_ij,                                                   (6.1)
```

where `L_ij` is a deterministic envelope. No independence between the two trained learners is assumed.

Then, with

```text
K_j^0
 = T/log(2) + 4 sqrt(T) sum_(i != j) L_ij,                (6.2)
```

one has

```text
|| Delta_j H_T ||_(psi_1 | F_(j-1))
<= K_j^0 / n.                                             (6.3)
```

Consequently, for `t=log(1/eta)`, with probability at least `1-eta`,

```text
H_T
<= [ sqrt(8 t sum_j (K_j^0)^2) + (max_j K_j^0) t ] / n.  (6.4)
```

## Proof

The scalar map `r -> min{r^2,T}` is `2 sqrt(T)`-Lipschitz on `r>=0`, and the norm is 1-Lipschitz. Therefore

```text
|d_ij(z)|
<= 2 sqrt(T) ||f_-i(x)-f_-i^(j)(x)||.                    (6.5)
```

Conditional on the learner pair, `Z_i` is an honest fresh draw because both deletion learners exclude coordinate `i`. Thus `(6.1)` implies

```text
||d_ij(Z_i)||_(psi_1) <= 2 sqrt(T) L_ij.
```

For a random variable `X` with `||X||_(psi_1)<=K`, Jensen gives `E|X| <= K log 2`, and the conditional Luxemburg triangle inequality gives

```text
||X-EX||_(psi_1) <= 2K.
```

Hence

```text
||xi_ij||_(psi_1) <= 4 sqrt(T) L_ij.                     (6.6)
```

Because `|A_j|<=T`,

```text
||A_j||_(psi_1) <= T/log 2.                              (6.7)
```

Apply the conditional Orlicz triangle inequality to `(4.1)` to obtain `(6.3)`.

Finally, if a conditionally centered variable has conditional `psi_1` norm at most `K`, then its conditional tail is at most `2 exp(-u/K)` and

```text
E|X|^m <= 2 m! K^m.
```

Thus `(5.1)` holds with

```text
v_j = 4 (K_j^0/n)^2,
c_j = K_j^0/n.
```

Substitution into `(5.3)` proves `(6.4)`.

QED.

## Uniform `O(1/n)` replacement corollary

If

`L_ij <= L/n`

for all `i != j`, then

```text
K_j^0 <= T/log 2 + 4 L sqrt(T),
```

and therefore

```text
H_T
<= [ T/log 2 + 4 L sqrt(T) ]
   [ sqrt(8 log(1/eta)/n) + log(1/eta)/n ].              (6.8)
```

This is the requested Bernstein/Freedman confidence improvement.

It is stronger in confidence than the preceding RMS/Chebyshev theorem, but it has a stronger hypothesis: `psi_1` replacement control rather than only `L^2` control.

# 7. `P19-GAUSSIAN-COVBOUNDARY-PSI1-33` — PROVED

The new `psi_1` hypothesis can be supplied by the existing hard-boundary geometry under an honest conditional Gaussian proxy.

Let `C,C'` be two trained readouts with

`||C-C'||_F <= rho`.

Let `S,S'` be their deterministic exact-cardinality top-`k` supports, and write

`H_k(C)=C P_S`, `H_k(C')=C' P_S'`.

The previous P19 hard-boundary theorem gives

`S triangle S' subset J_rho(C)`

for the explicit score boundary `J_rho(C)`.

Let the common fresh-query proxy satisfy, conditional on the trained pair,

`psi ~ N(0,G)`.

Define

```text
b_k(G)
 = sup_(|I|<=k) lambda_max(G_II),

Psi_(G,k)(rho;C)
 = sup_Q || C Q G^(1/2) ||_F,                            (7.1)
```

where `Q` ranges over the cardinality-preserving signed support swaps allowed by the previous boundary theorem and supported on `J_rho(C)`.

Then

```text
|| ||[H_k(C)-H_k(C')] psi|| ||_(psi_1)
<= 2 [ rho sqrt(b_k(G)) + Psi_(G,k)(rho;C) ].            (7.2)
```

## Gaussian norm lemma

For any deterministic matrix `A` and `g~N(0,I)`, put

`F = ||A||_F`.

If `F=0` the claim is trivial. Otherwise the map `g -> ||Ag||` is `||A||_op`-Lipschitz, `E||Ag|| <= F`, and Gaussian concentration gives

```text
E exp( t [ ||Ag|| - E||Ag|| ] )
<= exp( t^2 ||A||_op^2 / 2 ).
```

With `t=1/(2F)` and `||A||_op<=F`,

```text
E exp( ||Ag||/(2F) )
<= exp(1/2 + 1/8)
= exp(5/8)
< 2.
```

Therefore

```text
|| ||Ag|| ||_(psi_1) <= 2 ||A||_F.                      (7.3)
```

## Boundary proof

The exact algebraic decomposition is

```text
H_k(C)-H_k(C')
 = (C-C') P_S' + C(P_S-P_S').                           (7.4)
```

For the first term,

```text
||(C-C') P_S' G^(1/2)||_F
<= ||C-C'||_F ||P_S' G^(1/2)||_op
<= rho sqrt(b_k(G)).                                     (7.5)
```

The second term is one of the signed boundary swaps in `(7.1)`. Apply `(7.3)` to both terms and use the `psi_1` triangle inequality. This gives `(7.2)`.

QED.

## Different learned feature maps

If the two retrains use feature maps `phi,phi'` rather than the common proxy, define the explicit `psi_1` representation debts

```text
zeta^(1)
 = || ||H_k(C)(phi-psi)|| ||_(psi_1),

zeta'^(1)
 = || ||H_k(C')(phi'-psi)|| ||_(psi_1).
```

Then

```text
L_pair
<= 2[ rho sqrt(b_k(G)) + Psi_(G,k)(rho;C) ]
   + zeta^(1) + zeta'^(1).                               (7.6)
```

This is the quantity that may be inserted as `L_ij` in Section 6.

An `L^2` representation debt is **not** silently substituted for a `psi_1` debt.

# 8. `P19-BOUNDARY-LOO-BERNSTEIN-33` — raw-risk theorem

Assume the explicit conditional `psi_1` influence bounds of Section 6, supplied for hard pruning by Section 7 or by another legally justified source-specific envelope.

For deletion learner `i`, let raw population risk be

`R_i = E ell(f_-i;Z)`.

Assume, exactly as in the preceding report, a conditional raw-loss tail envelope

```text
P{ ell(f_-i;Z) > t | S_-i }
<= A_i exp(-t/K_i),    t>=T.                             (8.1)
```

Define

```text
tau_T
 = n^(-1) sum_i A_i K_i exp(-T/K_i).                    (8.2)
```

Let

```text
D_i
 = ||f_S - f_-i||_(L^2(P_X)),
Dbar = n^(-1) sum_i D_i.                                 (8.3)
```

Let `eps_Bern(T,eta)` denote the right side of `(6.4)`.

Then with probability at least `1-eta`,

```text
Rbar_loo_raw
<= Rhat_loo_raw + eps_Bern(T,eta) + tau_T,               (8.4)
```

and therefore

```text
sqrt(R(f_S))
<= sqrt( Rhat_loo_raw + eps_Bern(T,eta) + tau_T )
   + Dbar.                                                (8.5)
```

## Proof

Section 6 gives

`Rbar_loo,T <= Rhat_loo,T + eps_Bern`.

Since clipped empirical LOO loss is at most raw empirical LOO loss and tail integration under `(8.1)` gives

`R_i - R_(i,T) <= A_i K_i exp(-T/K_i)`,

averaging yields `(8.4)`.

For every `i`, reverse triangle inequality in the residual Hilbert space gives

`sqrt(R(f_S)) <= sqrt(R_i) + D_i`.

Average over `i` and apply concavity of square root to obtain `(8.5)`.

QED.

## Scaling

If `L_ij<=L/n`, `A_i<=A`, `K_i<=K`, and `T=K log n`, then at fixed confidence

```text
eps_Bern
 = O( log(n)/sqrt(n) ),

tau_T <= A K / n.
```

For confidence `eta=n^(-q)`,

```text
eps_Bern
 = O( log(n)^(3/2) / sqrt(n) )
```

under fixed `q,K,L`.

The previous Chebyshev theorem had the same fixed-confidence `n` order but polynomial confidence. The new theorem delivers the requested logarithmic confidence dependence.

# 10. `P19-L2-NOT-PSI1-CE-33` — RMS alone does not provide the needed exponential scale

The stronger influence hypothesis is not cosmetic.

Let `0<p<1/2` and define a scalar random variable

```text
X_p = a_p with probability p,
      0   with probability 1-p.
```

If `a_p=1/sqrt(p)`, then

`||X_p||_2 = 1`

for every `p`.

Under the same `psi_1` convention, `K=||X_p||_(psi_1)` must satisfy

```text
1-p + p exp(a_p/K) <= 2.
```

Therefore necessarily

```text
K
>= a_p / log((1+p)/p)
= 1 / [ sqrt(p) log((1+p)/p) ],                          (10.1)
```

which diverges as `p -> 0`.

Equivalently, taking fixed amplitude `T` gives

```text
||X_p||_2 = T sqrt(p) -> 0,
```

while

```text
||X_p||_(psi_1)
>= T / log((1+p)/p),                                     (10.2)
```

whose ratio to the RMS diverges.

Thus there is no universal constant `C` such that

`||X||_(psi_1) <= C ||X||_2`

for the replacement influence class.

The preceding `L^2` theorem therefore cannot simply be relabeled as a Bernstein theorem at the same stability scale. One needs either:

- a conditional `psi_1` / Bernstein moment envelope;
- a bounded pathwise influence envelope;
- or another explicit higher-moment structure.

The present theorem chooses the first route.

Note that analytic clipping alone makes every loss difference bounded by `T`, but using only that crude bound on all `n-1` affected deletion learners produces an order-one coordinate influence and loses the stability gain. The point of Section 6 is to retain the small **trained-pipeline replacement scale** while upgrading its tail behavior.

Still the correct tool for the July outlier locations, cluster residues, and singular-vector overlaps. The present learning proof neither verifies nor weakens the source compressed-resolvent hypothesis.

## Davis–Kahan / Wedin

Second-stage only. A positive restricted feature-Gram lower edge converts prediction discrepancy to an operator discrepancy; a genuine protected singular gap is then required before projector or mixed-dyad perturbation is claimed.

## Leave-one-out / ghost

Essential. The prior memorization counterexample already proved that full-sample fresh replacement RMS plus tiny reused training error does not control population risk. Deletion restores the independence of `Z_i` from `f_-i` needed by both the variance and Bernstein proofs.

## Bernstein / Freedman

This run upgrades the Doob martingale from second-moment control to a conditional sub-gamma MGF. The exact condition is stated in `(5.1)` and the concrete `psi_1` sufficient condition in Section 6. No unverified pathwise raw-feature bound is inserted.

A source-relevant deterministic equivalent would need to control local quantities appearing in `(7.6)`:

- replacement readout drift `rho_ij`;
- covariance-weighted score-boundary profile;
- `psi_1` representation debts;
- restricted feature-Gram edges.

An ambient ESD or average test-error equivalent is insufficient.

## Free probability

No free-probability reduction is used. A response-trained representation and deterministic support chosen from that representation are not automatically asymptotically free from the noise or feature Gram. Any future reduction must verify freeness hypotheses explicitly.

## Sparsification concentration

The valid random-matrix null is a simultaneous support-uniform concentration/RIP event. It remains valid for adaptive support selection precisely because it is uniform over all supports. This is not iid masking.

## Same trained matrix

The support can be an arbitrary deterministic function of the trained matrix. The discontinuity is paid through the actual score boundary and covariance profile. One observed boundary value is not silently promoted to a deterministic replacement envelope; Section 6 requires a valid coupling-wide `L_ij` bound or a separately audited high-probability event plus its failure probability.

### Audited statement

For Hilbert-valued square-integrable sample functionals `B(S),G(S)` with Hoeffding decompositions

`B=EB+sum_(A != empty) B_A`,

`G=EG+sum_(A != empty) G_A`,

P15 defines the reuse debt

```text
D_reuse
 = 2 sum_A E <B_A,G_A>,                                  (13.1)
```

signed one-coordinate replacement effects

```text
C_i
 = E <Delta_i B, Delta_i G>
 = 2 sum_(A contains i) E <B_A,G_A>,                     (13.2)
```

and Efron–Stein slack

```text
s(F)
 = (1/2) sum_i E||Delta_i F||^2 - E||F-EF||^2.          (13.3)
```

The claim is

```text
| D_reuse - sum_i C_i |
<= 2 sqrt( s(B) s(G) ).                                  (13.4)
```

### Independent derivation

Orthogonality of distinct Hoeffding components gives

```text
E||F-EF||^2
 = sum_A E||F_A||^2.                                     (13.5)
```

If `i notin A`, `Delta_i F_A=0`. If `i in A`, replacing coordinate `i` by an independent copy and using the zero conditional mean of the Hoeffding component in that coordinate gives

```text
E||Delta_i F_A||^2
 = 2 E||F_A||^2.                                         (13.6)
```

Cross terms between different `A` vanish by the same Hoeffding orthogonality after replacement. Therefore

```text
(1/2) sum_i E||Delta_i F||^2
 = sum_A |A| E||F_A||^2,                                 (13.7)
```

so

```text
s(F)
 = sum_A (|A|-1) E||F_A||^2.                             (13.8)
```

Similarly `(13.2)` follows by applying the replacement identity simultaneously to `B_A,G_A`. Summing over `i`,

```text
sum_i C_i
 = 2 sum_A |A| E<B_A,G_A>.                               (13.9)
```

Subtract `(13.1)` and use weighted Cauchy–Schwarz:

```text
|sum_i C_i - D_reuse|
= 2 | sum_A (|A|-1) E<B_A,G_A> |
<= 2
   [ sum_A (|A|-1) E||B_A||^2 ]^(1/2)
   [ sum_A (|A|-1) E||G_A||^2 ]^(1/2),
```

which is exactly `(13.4)`.

### Independent exact check of P15's extremal example

For independent Rademachers `Z_1,Z_2`, P15 takes

```text

G = Z_1 - (3/4) Z_1 Z_2.
```

```text

C_1 = 1/2,
C_2 = -3/2,
sum_i C_i = -1,
s(B)=1,
s(G)=9/16.
```

Hence

```text
|1/2 - (-1)| = 3/2 = 2 sqrt(1 * 9/16),
```

so the inequality is attained with equality.
