# 4. `P19-FULLSAMPLE-JACKKNIFE-BOUNDARY-44` — PROVED

\[

\quad
\tau_S=b_{(k)},
\quad

\tag{4.1}

Set

\[
B_S^{(4)}
=
\{j:|b_j-\tau_S|\le4\rho_n\},
\tag{4.2}

and

\[
\boxed{
\Psi_S
=
1_{\{\gamma_S\le4\rho_n\}}
\sum_{j\in B_S^{(4)}}(b_j+2\rho_n)^2.
}
\tag{4.3}
\]

The inherited deterministic top-`k` boundary lemma says that for arbitrary matrices `C,C'` with

\[
\|C-C'\|_F\le\delta,
\]

if `tau=s_(k)(C)`, `gamma=s_(k)(C)-s_(k+1)(C)`, and

\[
B_\delta(C)=\{j:|s_j(C)-\tau|\le2\delta\},

then

\[
\|H_k(C)-H_k(C')\|_F^2
\le
\delta^2
+
1_{\{\gamma\le2\delta\}}
\sum_{j\in B_\delta(C)}(s_j(C)+\delta)^2.
\tag{4.4}
\]

Apply `(4.4)` with `C=C_S`, `C'=C_{S^{(i,z')}}`, and, by `(3.4)`, `delta=2 rho_n`. This gives for every `i,z'`

\[
\boxed{
\|H_k(C_S)-H_k(C_{S^{(i,z')}})\|_F^2
\le4\rho_n^2+\Psi_S.
}
\tag{4.5}
\]

Crucially, `Psi_S` does not depend on `i` or the replacement value. Therefore `(4.5)` is simultaneous over the entire one-coordinate replacement neighborhood of the actual trained matrix.

If

\[
\gamma_S>4\rho_n,
\tag{4.6}
\]

then the boundary term vanishes and the same top-`k` support is retained by **every** one-coordinate retraining:

\[
S_k(C_{S^{(i,z')}})=S_k(C_S),
\qquad
\|H_k(C_S)-H_k(C_{S^{(i,z')}})\|_F\le2\rho_n.
\tag{4.7}
\]

This is a pathwise theorem about trained-matrix pruning. No support independence and no Bernoulli mask is introduced.

\varepsilon_S\le\frac12\Delta_C(P(S)),

# 9. `P19-LOCALLOCK-NOT-GHOST-CE-44` — PROVED

The local no-union theorem must not be overextended to independent ghosts.

Let `S=(Z_1,...,Z_n)` with iid Bernoulli(1/2) coordinates and let

\[
N_1(S)=\sum_i Z_i.
\]

Define a deterministic two-column trained coefficient map

\[
C(S)=
\begin{cases}
(2,1),&N_1(S)\le1,\\
(1,2),&N_1(S)\ge2,
\end{cases}
\]

and apply hard top-1 pruning.

At the particular sample `S=0^n`, every one-coordinate replacement has `N_1<=1`, so the top-1 support is **identical for every immediate neighbor** and the local pruned replacement jump is zero.

But for an independent ghost `S'`,

\[
P\{N_1(S')\ge2\}
=1-\frac{n+1}{2^n}
\longrightarrow1.
\]

Thus with probability tending to one the ghost selects the opposite support.

Therefore

\[
\boxed{
\text{one observed sample with perfect local support lock}
\not\Rightarrow
\text{global independent-ghost closeness}.
}
\tag{9.1}
\]

This exact counterexample explains why `(4.6)` may be used for simultaneous **local replacement** conclusions, while ghost/SLL transfer needs a distributional quantity such as `E Psi_S`, a predictable MGF, or a valid independent cross-fit theorem. It also blocks any attempt to plug the observed future-dependent local-gap event directly into a martingale Bernstein argument.

# 11. Spectral hierarchy and method comparison

The run continues to separate five logically different layers.

## 11.1 Eigenvalue / singular-value distributions

A global MP empirical spectral distribution controls average bulk singular values and, in rectangular regimes, a possible zero atom. It does not control the orientation of an adaptive trained/pruned signal frame. The retained adaptive top-noise-singular-vector counterexample remains decisive.

### Resolvent methods

Still the correct route for BBP/projector constants and source non-Haar verification. A pruning stability theorem can transfer or perturb a legal resolvent result; it cannot replace it.

### Davis–Kahan / Wedin

Legitimate only with a real singular gap such as `(6.4)`. It cannot infer overlap from MP ESD alone and cannot resolve a BBP critical window without separate RMT input.

### Leave-one-out / jackknife

The key improvement in this run is that every coordinate replacement is within `2rho_n` of the **same full-sample matrix**, so a single full-sample boundary band controls the entire immediate replacement neighborhood. This removes an unnecessary n-fold union for local support stability.

### Free probability / deterministic equivalents

No free-probability reduction is used. Global deterministic equivalents do not erase dependence created by selecting a support from the same trained matrix. Any asymptotic-freeness claim for the adaptive frame would require a separate proof.

### Sparsification concentration

Same-matrix top-`k` remains deterministic and adaptive. Fixed-support iid-mask concentration cannot be conditioned through that selection. Simultaneous restricted-Gram/RIP events remain legal because they are quantified over all admissible supports before selection.
