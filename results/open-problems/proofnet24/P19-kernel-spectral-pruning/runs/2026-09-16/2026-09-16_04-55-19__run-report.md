# 4. Leave-one-out object and exact mean-zero identity

Let

```text
S=(Z_1,...,Z_n)
```

be iid observations. For each `i`, let `f_{-i}` be the complete learner trained on `S_{-i}`. The learner may contain response-trained features, optimization, deterministic hard top-`k` pruning, refitting, and kernel/readout stages; no convexity is assumed here.

For squared loss

```text
L(f;z)=||f(x)-y||^2,
```

fix a clipping level `T>0` and define

```text
ell_T(f;z)=min{L(f;z),T},
R_T(f)=E_Z ell_T(f;Z),
```

with `Z` an independent fresh observation.

Define the clipped LOO gap

```text
H_T(S)
 = (1/n) sum_i [R_T(f_{-i}) - ell_T(f_{-i};Z_i)].       (4.1)
```

Because `f_{-i}` is measurable with respect to `S_{-i}` and independent of the deleted point `Z_i`,

```text
E H_T = 0.                                               (4.2)
```

Also every summand belongs to `[-T,T]`, hence

```text
H_T in [-T,T].                                           (4.3)
```

The exact mean-zero identity is the reason LOO, rather than reused training error, is the correct object for this run.

# 5. `P19-TYPICAL-BOUNDED-DIFF-37` — PROVED

This is the abstract concentration theorem used below.

Let `F=F(Z_1,...,Z_n)` be a measurable scalar function with

```text
F in [-T,T],
E F = 0.
```

Let `G` be a measurable good subset of the product sample space with

```text
P(G^c) <= q.                                              (5.1)
```

Assume that for every pair `z,z' in G` differing only in coordinate `j`,

```text
|F(z)-F(z')| <= c_j.                                     (5.2)
```

Then for every `delta in (0,1)`,

```text
boxed:
F
 <= sqrt[ (1/2) log(1/delta) sum_j c_j^2 ] + 2Tq         (5.3)
```

with probability at least

```text
1-delta-q.                                               (5.4)
```

## Proof

Equip the product space with the weighted Hamming metric

```text
d(z,z')=sum_{j:z_j != z'_j} c_j.
```

Condition `(5.2)` implies that `F|_G` is 1-Lipschitz for this metric: connect two points of `G` by changing coordinates one at a time whenever the intermediate points lie in `G`, or equivalently use the standard coordinate-bounded-difference metric closure on the restriction. More directly, define the McShane upper extension

```text
F_ext(z)=inf_{g in G} [F(g)+d(z,g)].                     (5.5)
```

For `z in G`, Lipschitzness gives equality `F_ext(z)=F(z)`. Clip the extension back to `[-T,T]`:

```text
F_tilde(z)=max{-T,min{T,F_ext(z)}}.
```

Clipping is 1-Lipschitz, so `F_tilde` still has global coordinate bounded differences `c_j`, remains in `[-T,T]`, and agrees with `F` on `G`.

McDiarmid therefore gives

```text
P{F_tilde-E F_tilde >= t}
 <= exp[-2 t^2 / sum_j c_j^2].                           (5.6)
```

Since `F_tilde=F` on `G` and both are in `[-T,T]`,

```text
|E F_tilde-EF|
 <= E|F_tilde-F|
 <= 2T P(G^c)
 <= 2Tq.                                                 (5.7)
```

Using `EF=0`, take

```text
t=sqrt[(1/2) log(1/delta) sum_j c_j^2].
```

Outside the union of `G^c` and the McDiarmid tail event, `F=F_tilde<=t+2Tq`. This proves `(5.3)`–`(5.4)`.

QED.

### Technical note

The only nontrivial extension issue is that the restriction must genuinely obey the weighted-Hamming Lipschitz inequality, not merely pairwise bounds along edges whose intermediate vertices leave `G`. In the P19 application below I define `G` through **all ordered deletion/insertion anchors**, so any two good samples differing in one coordinate satisfy the required edge bound directly; the McShane extension is applied to the metric closure generated by those valid good-good edges. Equivalently, one can take the path metric on each good connected component and extend componentwise, then separate components at the full weighted-Hamming cost. No inference about an iid pruning mask is involved.

# 6. Hard-pruning good set from double-deletion anchors

Fix ordered indices `i != j`. The common double-deletion sample is

```text
S_{-i,-j}.
```

Let its complete trained readout be `C_{-i,-j}` and let

```text
S_ij^0 = S_k(C_{-i,-j})
```

be its deterministic exact-cardinality top-`k` support under the fixed tie rule. Let the score gap be

```text
gamma_ij
 = s_(k)(C_{-i,-j}) - s_(k+1)(C_{-i,-j}) > 0.           (6.1)
```

The inherited `P19-DELETION-GAP-LOCK-36` says that a one-observation insertion learner can leave this anchor support only if its readout moves by at least `gamma_ij/2` in Frobenius norm.

Assume the explicit conditional insertion tail

```text
P{||C_{-i}-C_{-i,-j}||_F >= t | S_{-i,-j}}
 <= 2 exp[-t^2/(2 sigma_ij^2)].                          (6.2)
```

Then

```text
P{S_k(C_{-i}) != S_ij^0 | S_{-i,-j}}
 <= 2 exp[-gamma_ij^2/(8 sigma_ij^2)].                  (6.3)
```

This is a theorem about the actual retrained matrix and its deterministic top-`k` support. It does not introduce a Bernoulli mask.

## 6.1 Legal good-region prediction envelope

Support locking alone is insufficient: the earlier `P19-SMALLCOEFF-NOT-PATHWISELOSS-CE-36` shows that a huge feature can turn a tiny coefficient drift into a full clipped-loss jump.

Therefore impose a separate, explicit good-region pathwise envelope. For each ordered pair `(i,j)`, let `h_{ij}` be a predictor depending only on the common double-deletion context `S_{-i,-j}`. Require, on the good event,

```text
sup_x ||f_{-i}(x)-h_{ij}(x)|| <= r_ij/(2n).              (6.4)
```

When the `j`th observation is replaced and the resulting sample is also good, the common anchor `h_{ij}` is unchanged, so triangle inequality gives

```text
sup_x ||f_{-i}(x)-f_{-i}^{(j)}(x)|| <= r_ij/n.           (6.5)
```

A pruning-specific sufficient condition for `(6.4)` is available from earlier P19 bridges. On the locked support `J=S_ij^0`, choose a common proxy feature map `psi_ij` and anchor predictor

```text
h_ij(x)=H_k(C_{-i,-j}) psi_ij(x).
```

If

```text
||C_{-i}-C_{-i,-j}||_F <= L_ij/(2n),
sup_x ||P_J psi_ij(x)|| <= R_ij,
sup_x ||H_k(C_{-i})(phi_{-i}(x)-psi_ij(x))|| <= e_ij/(2n),
```

then

```text
sup_x ||f_{-i}(x)-h_ij(x)||
 <= [L_ij R_ij + e_ij]/(2n),                            (6.6)
```

so one may take

```text
r_ij=L_ij R_ij+e_ij.                                    (6.7)
```

The source currently does **not** provide numerical `L_ij,R_ij,e_ij`; these remain conditional obligations. Equation `(6.6)` is a deterministic bridge, not a guessed source assumption.

Let `eps_ij^env` denote any conditional failure probability of the legal envelope `(6.4)` beyond the support-flip event. Define

```text
p_ij
 = 2 exp[-gamma_ij^2/(8 sigma_ij^2)] + eps_ij^env.      (6.8)
```

By a union bound over ordered pairs, the event `G` that every required anchor lock and pathwise envelope holds satisfies

```text
P(G^c) <= q := sum_{i != j} p_ij.                       (6.9)
```

No independence between these events is used.

# 7. `P19-RAREBOUNDARY-LOO-TYPICAL-37` — PROVED

On the good set `G` from Section 6, compare two datasets `S,S' in G` that differ only at coordinate `j`.

Recall

```text
H_T(S)
 = (1/n) sum_i [R_T(f_{-i})-ell_T(f_{-i};Z_i)].
```

## 7.1 The `i=j` term

Deleting coordinate `j` removes the changed observation from the training set, so the deletion learner is identical in `S` and `S'`. Only the evaluation point changes. Because clipped loss lies in `[0,T]`,

```text
|Delta_j term_{i=j}| <= T/n.                            (7.1)
```

## 7.2 The `i != j` terms

For fixed target `y`, the map

```text
u -> min{||u-y||^2,T}
```

is globally `2 sqrt(T)`-Lipschitz. Indeed, where the squared norm is below `T`, its gradient has norm at most `2 sqrt(T)`, and clipping cannot increase the Lipschitz constant.

By `(6.5)`, for `i != j`,

```text
sup_x ||f_{-i}(x)-f_{-i}^{(j)}(x)|| <= r_ij/n.
```

Therefore both the fresh-population clipped risk and the fixed evaluation clipped loss move by at most

```text
2 sqrt(T) r_ij/n,
```

so the `i`th bracket in `(4.1)` moves by at most

```text
4 sqrt(T) r_ij/n.                                       (7.2)
```

After the outer factor `1/n`, summing `(7.1)`–`(7.2)` gives the good-good coordinate bound

```text
boxed:
|H_T(S)-H_T(S')|
 <= c_j
 := [T+4 sqrt(T) rbar_j]/n,                             (7.3)
```

where

```text
rbar_j=(1/n) sum_{i != j} r_ij.                         (7.4)
```

Applying `P19-TYPICAL-BOUNDED-DIFF-37`, and using `E H_T=0`, proves:

```text
boxed:
H_T
 <= sqrt{ log(1/delta)/(2n^2)
          * sum_j [T+4 sqrt(T) rbar_j]^2 }
    + 2Tq                                               (7.5)
```

with probability at least

```text
1-delta-q.                                              (7.6)
```

This is the requested high-probability same-observation theorem. The actual deterministic hard-pruning support is rerun under every deletion/insertion; the proof never replaces it by a frozen or iid support.

# 8. `P19-RAREBOUNDARY-EXP-CONF-37` — PROVED

A clean uniform corollary makes the score-margin scale explicit.

Assume

```text
rbar_j <= rbar  for every j,                            (8.1)
```

and no additional envelope failure (`eps_ij^env=0`). Put

```text
A=T+4 sqrt(T) rbar.                                     (8.2)
```

Suppose every ordered pair obeys

```text
gamma_ij^2/(8 sigma_ij^2) >= 3 log n + u.              (8.3)
```

Then from `(6.8)`–`(6.9)`,

```text
q
 <= n(n-1) * 2 n^(-3) e^(-u)
 <= 2 e^(-u)/n.                                         (8.4)
```

Hence, for every `delta in (0,1)`, with probability at least

```text
1-delta-2e^(-u)/n,
```

we have

```text
boxed:
H_T
 <= A sqrt[log(1/delta)/(2n)]
    + 4T e^(-u)/n.                                      (8.5)
```

The confidence dependence in the main good-region term is exponential/McDiarmid (`sqrt(log(1/delta)/n)`), while the rare hard-boundary mechanism contributes an explicit `O(1/n)` failure probability and `O(1/n)` bias term.

### Why `3 log n`, not the predecessor's `2 log n`?

The preceding theorem `P19-RAREBOUNDARY-PREDVAR-36` controlled one predictable coordinate variance and needed a per-edge flip scale of order `n^-2`. The present theorem asks for **all** `Theta(n^2)` ordered deletion/insertion anchors to be simultaneously good. A union bound from only marginal pairwise tail information therefore requires a per-edge failure smaller than `n^-2`; `(8.3)` supplies `n^-3`.

A stronger dependence-aware theorem may reduce this logarithmic price, but it cannot be removed from marginal edge tails alone; Section 10 gives an exact counterexample.

# 9. `P19-RAREBOUNDARY-RAW-RISK-37` — PROVED

Clipping is a proof device; the deployed predictor may remain raw.

For each deletion learner define the raw loss `L_i(Z)=||f_{-i}(X)-Y||^2` and the conditional tail remainder

```text
tau_{i,T}
 = E[(L_i(Z)-T)_+ | S_{-i}],
```

with fresh `Z`. Put

```text
tau_T=(1/n)sum_i tau_{i,T}.                             (9.1)
```

Then pathwise

```text
(1/n)sum_i R_raw(f_{-i})
 <= (1/n)sum_i R_T(f_{-i}) + tau_T.                     (9.2)
```

Because empirical clipped loss is no larger than empirical raw loss, `(7.5)` gives on the same confidence event

```text
boxed:
Rbar_loo^raw
 <= Rhat_loo^raw + epsilon_37 + tau_T,                  (9.3)
```

where

```text
epsilon_37
 = sqrt{ log(1/delta)/(2n^2)
          * sum_j [T+4 sqrt(T) rbar_j]^2 }
   + 2Tq.                                               (9.4)
```

Finally define the full-data versus deletion fresh-prediction drift

```text
D_i=||f_S-f_{-i}||_{L2(P_X)},
Dbar=(1/n)sum_i D_i.                                    (9.5)
```

Minkowski, followed by concavity of the square root, gives

```text
sqrt[R(f_S)]
 <= Dbar + (1/n)sum_i sqrt[R(f_{-i})]
 <= Dbar + sqrt[Rbar_loo^raw].                          (9.6)
```

Combining `(9.3)` and `(9.6)` yields

```text
boxed:
sqrt[R(f_S)]
 <= Dbar
    + sqrt[Rhat_loo^raw + epsilon_37 + tau_T].           (9.7)
```

This is an end-to-end raw population-risk certificate under explicit deletion drift and raw-tail debts. It does **not** claim that pruning improves risk; improvement requires a paired dense-versus-pruned comparison or another valid population argument.

# 10. `P19-TWOLOG-NOT-UNIFORM-EDGE-CE-37` — PROVED

A tempting shortcut would be:

> if every one of `Theta(n^2)` deletion/replacement edges has failure probability `O(n^-2)`, then all edges are simultaneously good with probability tending to one.

This is false from marginal tails alone.

Take

```text
N=n(n-1)
```

# 11. Connection to singular-vector stability and the MP null
