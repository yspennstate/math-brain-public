Let the training sample size be `N` to avoid conflating it with the spectral matrix dimension `n` in the source paper. Let

`S_N = {(x_i,y_i)}_{i=1}^N`

and the population ridge solution

`C_* = B(A+lambda I)^(-1)`.

# 5. Population ridge concentration

## `P19-POPULATION-RIDGE-PROXY-45 — PROVED`

Define empirical moments

`A_N = (1/N) sum_i x_i x_i^*`,

`B_N = (1/N) sum_i y_i x_i^*`.

The normal equations give

`C_N = B_N(A_N+lambda I)^(-1)`.

Fix `delta in (0,1)` and put

`s_delta = 1 + sqrt(2 log(2/delta))`.

Then with probability at least `1-delta`,

`||A_N-A||_F <= (R^2/sqrt(N)) s_delta`,

`||B_N-B||_F <= (Y R/sqrt(N)) s_delta`.

Consequently

`||C_N-C_*||_F <= r_N(delta)`

with

`r_N(delta) = [Y R/(lambda sqrt(N))] [1+R^2/lambda] s_delta`.

### Proof

For `Z_i^A=x_i x_i^*`,

`||Z_i^A||_F = ||x_i||^2 <= R^2`.

Independence and centering in the Frobenius Hilbert space give

`E ||A_N-A||_F^2 <= R^4/N`,

hence

`E ||A_N-A||_F <= R^2/sqrt(N)`.

Replacing one sample changes `A_N` in Frobenius norm by at most `2R^2/N`. Since matrix norm is 1-Lipschitz with respect to its argument,

`P{ ||A_N-A||_F >= E||A_N-A||_F + t }`

`<= exp[-N t^2/(2R^4)]`

by scalar bounded differences. Taking `t=R^2 sqrt(2 log(2/delta)/N)` gives the displayed `A_N` bound with failure at most `delta/2`.

The same argument for `Z_i^B=y_i x_i^*`, with `||Z_i^B||_F<=YR`, gives the `B_N` bound with failure at most `delta/2`.

Now

`C_N-C_*`

`= (B_N-B)(A_N+lambda I)^(-1)`

`  + B[(A_N+lambda I)^(-1)-(A+lambda I)^(-1)]`.

Both `A_N` and `A` are positive semidefinite, so

`||(A_N+lambda I)^(-1)||_op <= 1/lambda`,

`||(A+lambda I)^(-1)||_op <= 1/lambda`.

The resolvent identity gives

`||(A_N+lambda I)^(-1)-(A+lambda I)^(-1)||_op`

`<= ||A_N-A||_op/lambda^2`

`<= ||A_N-A||_F/lambda^2`.

Also

`||B||_F <= E||y x^*||_F <= YR`.

Substitution yields exactly

`||C_N-C_*||_F`

`<= (YR/(lambda sqrt(N))) s_delta`

` + (YR R^2/(lambda^2 sqrt(N))) s_delta`

`= r_N(delta)`.

No label/noise independence beyond iid training pairs is used in this concentration theorem.

# 6. Hard top-k support lock to the population proxy

## `P19-POPULATION-TOPK-LOCK-45 — PROVED`

Let

`a_j = ||(C_*)_:j||_2`

and let

`gamma_* = a_(k)-a_(k+1)`

be the deterministic population top-k score gap.

On the event `||C_N-C_*||_F<=r`, every column score moves by at most `r`. Therefore, if

`gamma_* > 2r`,

the top-k support of `C_N` is exactly the deterministic top-k support of `C_*`.

On that event, hard pruning is simply projection onto a common fixed column set, hence

`||P_N-P_*||_F <= ||C_N-C_*||_F <= r`,

and therefore

`||P_N-P_*||_op <= r`.

Taking `r=r_N(delta)` gives a finite-sample high-probability certificate.

### Why this is not an iid-mask argument

The support of `P_N` is still selected from the trained matrix. We do not condition a fixed-support law through that selection. Instead, a uniform coefficient-space event proves that the selected support equals a deterministic population support. Once equality is proved, the same-matrix support dependence has been eliminated by a theorem, not by substitution.

If `gamma_*` is zero or comparable to `r_N`, this route honestly fails. The inherited zero-margin hard-pruning counterexamples remain applicable.

# 7. Pathwise Riesz-projector transfer from the source-legal proxy

## `P19-ADAPTIVE-RIESZ-PROXY-TRANSFER-45 — PROVED`

Let `X` be any rectangular matrix on the same probability space. It may depend arbitrarily on the training sample used to form `P_N`.

Set

`W_* = X+P_*`,

`W = X+P_N`.

Let `H(A)` be the Hermitian dilation

`H(A) = [[0,A],[A^*,0]]`.

Then

`||H(W)-H(W_*)||_op = ||P_N-P_*||_op <= r`.

Let `Gamma` be a positively oriented rectifiable contour contained in the resolvent set of `H(W_*)`, and define

`d_Gamma = inf_{z in Gamma} dist(z,spec H(W_*))`,

`ell_Gamma = length(Gamma)`.

Assume `r<d_Gamma`.

Then `Gamma` also lies in the resolvent set of `H(W)`, the number of enclosed eigenvalues is unchanged, and the corresponding Riesz projectors satisfy

`||Pi_Gamma(W)-Pi_Gamma(W_*)||_op`

`<= q_Gamma(r)`

with

`q_Gamma(r) = [ell_Gamma/(2 pi)] r/[d_Gamma(d_Gamma-r)]`.

### Proof

For `z in Gamma`,

`||(zI-H(W_*))^(-1)||_op <= 1/d_Gamma`.

Since

`||(H(W)-H(W_*))(zI-H(W_*))^(-1)|| < 1`,

the Neumann argument gives invertibility for `H(W)` and

`||(zI-H(W))^(-1)||_op <= 1/(d_Gamma-r)`.

The second resolvent identity is

`R_W(z)-R_*(z) = R_W(z)[H(W)-H(W_*)]R_*(z)`.

Integrating around the contour,

`Pi_Gamma(W)-Pi_Gamma(W_*) = (1/(2 pi i)) integral_Gamma [R_W(z)-R_*(z)] dz`.

Taking operator norms gives the displayed `q_Gamma(r)` bound.

Along the homotopy `H_t=H(W_*)+t(H(W)-H(W_*))`, the same contour remains in the resolvent set for every `t in [0,1]`, so projector rank is constant.

This proof is deterministic and pathwise. It does not use independence between `P_N` and `X`.

# 10. Marchenko–Pastur ESD, extremes, prediction risk, finite width — kept separate

## 10.1 Global eigenvalue/singular-value distribution

## `P19-ADAPTIVE-MP-ESD-PROXY-45 — PROVED`

Suppose the deterministic proxy has `rank(P_*)=o(n)` and the source global law for `X_n` holds. Then Theorem 3.1/source rank inequality gives the same global squared-singular-value limit for

`W_* = X_n+P_*`.

If also

`||P_N-P_*||_op = r_N = o_P(1)`

and `||W_n||_op+||W_*||_op=O_P(1)`, Weyl gives

`max_j |sigma_j(W_n)-sigma_j(W_*)| <= r_N`.

Hence

`max_j |sigma_j(W_n)^2-sigma_j(W_*)^2|`

`<= r_N [||W_n||_op+||W_*||_op] = o_P(1)`.

Therefore the empirical squared-singular-value distributions have the same bounded-Lipschitz limit. In the source MP model, the actual adaptive observation has the same global MP law.

This conclusion can hold even when a singular-vector theorem fails because a protected outlier gap/contour clearance is missing. It therefore does not justify an iid-mask or independent-spike vector argument.

## 10.2 Extreme singular values

For every index,

`|sigma_j(W_n)-sigma_j(W_*)| <= r_N`.

Thus source outlier locations transfer at the operator perturbation scale. At or near a critical collision with the bulk, this does not imply vector-overlap stability.

## 10.3 Singular-vector / projector overlap

Needs either the Riesz contour clearance of Section 7 or the real gap of Section 9. Global ESD convergence alone is insufficient.

## 10.4 Prediction/operator-learning discrepancy

Let a fresh probe `psi` have covariance `G=E[psi psi^*]` with `||G||_op<=b`. On the support-lock event,

`E_psi ||(P_N-P_*) psi||^2`

`= tr[(P_N-P_*)^*(P_N-P_*) G]`

`<= b ||P_N-P_*||_F^2`

`<= b r_N(delta)^2`.

This is `P19-POPULATION-PROXY-PREDICTION-45 — PROVED`.

The converse direction still requires a restricted lower Gram floor on the actual support family; the inherited counterexample with an unidentifiable feature direction remains active.

## 10.5 Finite-width/sample debt

For bounded `R,Y` and `lambda` bounded below,

`r_N(delta) = O(sqrt(log(1/delta)/N))`.

The source projector transfer therefore has an explicit finite-sample debt. It vanishes only if the population top-k margin dominates this scale and the source contour clearance does not vanish faster.

No statement is made here for a critical BBP window whose separation is of the same or smaller scale; that remains an open coupling problem.

# 11. Method comparison and preserved failed routes

## Resolvent / Riesz methods

Best fit for the August theorem and for repeated/tight clusters. The new pathwise contour transfer works after the source theorem and therefore avoids proving a new adaptive-frame local law.

## Davis–Kahan / Wedin

Valid only after a genuine protected singular gap is supplied. Used as a corollary, never as a substitute for the BBP overlap calculation.

## Leave-one-out / predictable boundary process

Still the strongest route when no deterministic/source-legal population proxy with a usable margin exists. The entering `P19-PREDICTABLE-BOUNDARY-MGF-45` remains open. The new population-proxy theorem bypasses it only in the explicit fixed-feature ridge benchmark.

## Free probability / deterministic equivalents

Global deterministic equivalents can identify a bulk/ESD and sometimes outlier locations. They do not by themselves remove same-matrix dependence of trained signal directions. The new theorem avoids that problem by applying the source law to a deterministic proxy and transferring pathwise.

## Sparsification concentration

No iid pruning mask is introduced. Hard top-k support is trained/adaptive. The theorem proves that support equals a deterministic population support when the population margin dominates the coefficient estimation radius.

## Preserved rejected routes

1. MP ESD implies vector isotropy — **DISPROVED**.
2. Same-noise adaptive spike may be treated as independent — **DISPROVED** by adaptive top-noise-singular-vector construction.
