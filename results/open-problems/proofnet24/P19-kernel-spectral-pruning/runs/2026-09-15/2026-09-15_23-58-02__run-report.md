# 4. Leave-one-out setup

Let

\[
S=(Z_1,\ldots,Z_n),\qquad Z_i=(X_i,Y_i)
\]

be iid. Any auxiliary training randomness is independent of `S` and is held common across replacement/deletion couplings.

For each `i`, let

\[
f_{-i}=A(S_{-i})
\tag{4.1}
\]

be the deletion retrain. For `j\ne i`, replace retained observation `Z_j` by an iid copy and write

\[
f_{-i}^{(j)}=A(S_{-i}^{(j)}).
\tag{4.2}
\]

The squared loss and its analytic clipping are

\[
\ell(f;z)=\|y-f(x)\|^2,
\qquad
\ell_T(f;z)=\min\{\ell(f;z),T\}.
\tag{4.3}
\]

The deployed predictor is not clipped; clipping is only a proof device.

Define

\[
R_{i,T}=E_Z\ell_T(f_{-i};Z),
\tag{4.4}
\]

\[
\widehat R_{\rm loo,T}
=n^{-1}\sum_{i=1}^n\ell_T(f_{-i};Z_i),
\qquad
\overline R_{\rm loo,T}
=n^{-1}\sum_{i=1}^nR_{i,T}.
\tag{4.5}
\]

For `i\ne j`, define the fresh clipped-loss replacement RMS

\[
\boxed{
\beta_{ij,T}^2
=E\left[
\ell_T(f_{-i};Z)-\ell_T(f_{-i}^{(j)};Z)
\right]^2,
}
\tag{4.6}
\]

where `Z` is an additional fresh iid test draw.

# 5. `P19-LOO-RMS-CLIPPED-32` — PROVED

Put

\[
H_T(S)=\overline R_{\rm loo,T}-\widehat R_{\rm loo,T}.
\tag{5.1}
\]

Then

\[
\boxed{EH_T=0.}
\tag{5.2}
\]

and

\[
\boxed{
\operatorname{Var}(H_T)
\le
{1\over2n^2}
\sum_{j=1}^n
\left(T+\sum_{i\ne j}\beta_{ij,T}\right)^2.
}
\tag{5.3}
\]

Therefore, for every `eta in (0,1)`, with probability at least `1-eta`,

\[
\boxed{
\overline R_{\rm loo,T}
\le
\widehat R_{\rm loo,T}+arepsilon_{T,\eta},
}
\tag{5.4}
\]

where

\[
\boxed{
\varepsilon_{T,\eta}
={1\over n\sqrt{2\eta}}
\left[
\sum_{j=1}^n
\left(T+\sum_{i\ne j}\beta_{ij,T}\right)^2
\right]^{1/2}.
}
\tag{5.5}
\]

## Proof

Because `Z_i` is absent from `S_{-i}`, it is independent of its deletion learner `f_{-i}`. Hence

\[
E\ell_T(f_{-i};Z_i)=ER_{i,T}
\]

for each `i`, which proves `(5.2)`.

Now replace a single sample coordinate `Z_j` by an iid copy `Z_j'` and write `H_T^{(j)}` for the result.

### Case `i=j`

The learner `f_{-j}` is unchanged because the replaced coordinate is deleted. Only its evaluation point changes. Since `0<=ell_T<=T`, that contribution to the `L^2` norm of `H_T-H_T^{(j)}` is at most `T/n`.

### Case `i\ne j`

Define

\[
d_{ij}(z)=\ell_T(f_{-i};z)-\ell_T(f_{-i}^{(j)};z).
\tag{5.6}
\]

The change of the `i`th centered LOO summand is exactly

\[
E_Zd_{ij}(Z)-d_{ij}(Z_i).
\tag{5.7}
\]

Since `Z_i` is excluded from both learners, conditional on `f_{-i},f_{-i}^{(j)}` it is an honest iid test draw. Therefore

\[
E\left[(E_Zd_{ij}(Z)-d_{ij}(Z_i))^2
\mid f_{-i},f_{-i}^{(j)}\right]
\le E_Zd_{ij}(Z)^2.
\tag{5.8}
\]

After averaging,

\[
\left\|E_Zd_{ij}(Z)-d_{ij}(Z_i)\right\|_{L^2}
\le\beta_{ij,T}.
\tag{5.9}
\]

Minkowski gives

\[
\|H_T-H_T^{(j)}\|_{L^2}
\le
n^{-1}\left(T+\sum_{i\ne j}\beta_{ij,T}\right).
\tag{5.10}
\]

For completeness, the variance inequality used next is derivable by the same coordinate Doob-martingale argument appearing in the current P15 peer report: decompose `H_T-EH_T` into independent-coordinate martingale increments; each increment energy is no larger than one half of the squared `L^2` change under an iid replacement of that coordinate. Thus

\[
\operatorname{Var}(H_T)
\le {1\over2}\sum_jE(H_T-H_T^{(j)})^2.
\tag{5.11}
\]

Substituting `(5.10)` proves `(5.3)`. Chebyshev proves `(5.4)`–`(5.5)`.

QED.

### Scope

This theorem assumes only **fresh RMS** replacement control. It does not assume a uniform pathwise bound

`sup_z |ell(f_{-i};z)-ell(f_{-i}^{(j)};z)| << 1`.

The cost of working at second-moment level is polynomial confidence `1/sqrt(eta)` rather than a Bernstein `log(1/eta)` dependence.

# 6. `P19-LOO-PRED-RMS-32` — PROVED

The function `r -> min(r^2,T)` is `2 sqrt(T)`-Lipschitz on the nonnegative line and the norm is 1-Lipschitz. Hence

\[
\boxed{
|\ell_T(f;(x,y))-\ell_T(g;(x,y))|
\le2\sqrt T\,\|f(x)-g(x)\|.
}
\tag{6.1}
\]

Define the fresh predictor replacement RMS

\[
\boxed{
B_{ij}^2
=E\|f_{-i}(X)-f_{-i}^{(j)}(X)\|^2.
}
\tag{6.2}
\]

Then

\[
\boxed{\beta_{ij,T}\le2\sqrt T\,B_{ij}.}
\tag{6.3}
\]

Therefore

\[
\boxed{
\varepsilon_{T,\eta}
\le
{1\over n\sqrt{2\eta}}
\left[
\sum_{j=1}^n
\left(T+2\sqrt T\sum_{i\ne j}B_{ij}\right)^2
\right]^{1/2}.
}
\tag{6.4}
\]

If `B_ij<=B/n` for every `i\ne j`, then

\[
\boxed{
\varepsilon_{T,\eta}
\le
(T+2B\sqrt T)/\sqrt{2\eta n}.
}
\tag{6.5}
\]

Thus an `O(1/n)` fresh predictor replacement scale yields a vanishing one-run LOO generalization debt even without a pathwise loss-stability constant.

# 7. `P19-LOO-RMS-RAW-RISK-32` — PROVED

Let

\[
R_i=E_Z\ell(f_{-i};Z)
\tag{7.1}
\]

be raw population risk of deletion learner `i`. Assume an explicit conditional raw-loss tail envelope, almost surely in the deletion sample,

\[
P\{\ell(f_{-i};Z)>t\mid S_{-i}\}
\le A_i e^{-t/K_i},
\qquad t\ge T.
\tag{7.2}
\]

No source value of `A_i` or `K_i` is guessed.

Tail integration gives

\[
R_i-R_{i,T}
=E(\ell-T)_+
\le A_iK_i e^{-T/K_i}.
\tag{7.3}
\]

Define

\[
\tau_T=n^{-1}\sum_iA_iK_i e^{-T/K_i}.
\tag{7.4}
\]

Because clipped empirical LOO risk does not exceed raw empirical LOO risk

\[
\widehat R_{\rm loo}^{raw}
=n^{-1}\sum_i\ell(f_{-i};Z_i),
\tag{7.5}
\]

Section 5 yields, with probability at least `1-eta`,

\[
\boxed{
\overline R_{\rm loo}^{raw}
:=n^{-1}\sum_iR_i
\le
\widehat R_{\rm loo}^{raw}
+\varepsilon_{T,\eta}
+\tau_T.

\tag{7.6}
\]

If `A_i<=A`, `K_i<=K`, `B_ij<=B/n`, and `T=K log n`, then at fixed confidence

\[
\varepsilon_{T,\eta}
=O((\log n+\sqrt{\log n})/\sqrt n),
\qquad
\tau_T\le AK/n.
\tag{7.7}
\]

The deployed predictor remains un-clipped. Clipping is purely analytic.

# 9. `P19-FRESH-RMS-NOT-REUSE-CE-32` — PROVED counterexample

A direct full-sample shortcut is false even for bounded losses.

Let

\[
\mathcal X=\{1,\ldots,M\}
\]

with `X` uniform and deterministic target `Y=0`. Given training inputs `S=(X_1,...,X_n)`, define

\[
\boxed{
f_S(x)=1\{x\notin\{X_1,\ldots,X_n\}\}.}
\tag{9.1}
\]

Every training point is observed, so

\[
\widehat R_{train}(f_S)=0.
\tag{9.2}
\]

Conditional population risk is

\[
\boxed{
R(f_S)=1-|\{X_1,\ldots,X_n\}|/M
\ge1-n/M.
}
\tag{9.3}
\]

For `M>>n`, risk is arbitrarily close to one.

If a single training input is replaced, the observed-set indicator changes on at most two atoms. Therefore

\[
\boxed{
E_X|f_S(X)-f_{S^{(j)}}(X)|^2\le2/M,
}
\tag{9.4}
\]

so the fresh full-sample replacement RMS is at most `sqrt(2/M)`, which tends to zero.

Hence

\[
\boxed{
\text{small fresh full-sample RMS replacement}
+\text{zero reused training error}
\not\Rightarrow
\text{small population risk}.
}
\tag{9.5}
\]

The LOO construction correctly detects the memorizer. A held-out point is absent from its deletion learner unless another training point duplicates it, and

\[
\boxed{
E\widehat R_{\rm loo}=(1-1/M)^{n-1},
}
\tag{9.6}
\]

which is close to one for `M>>n`.

This is a rigorous falsification of the direct RMS-to-reused-risk route and the reason the ghost/LOO mechanism is structurally necessary.

# 10. `P19-BOUNDARY-LOO-RAW-32` — hard-pruning specialization

Write deletion and deletion-replacement predictors as

\[
f_{-i}(x)=H_k(C_{-i})\phi_{-i}(x),
\tag{10.1}
\]

\[
f_{-i}^{(j)}(x)=H_k(C_{-i}^{(j)})\phi_{-i}^{(j)}(x).
\tag{10.2}
\]

Let `psi_ij` be a legally defined common fresh-query proxy for this pair with Gram

\[
G_{ij}=E[\psi_{ij}\psi_{ij}^*],
\tag{10.3}
\]

and put

\[
\rho_{ij}=\|C_{-i}-C_{-i}^{(j)}\|_F.
\tag{10.4}
\]

Define representation debts

\[
\zeta_{ij}
=\|H_k(C_{-i})(\phi_{-i}-\psi_{ij})\|_{L^2},
\tag{10.5}
\]

\[
\zeta_{ij}'
=\|H_k(C_{-i}^{(j)})(\phi_{-i}^{(j)}-\psi_{ij})\|_{L^2}.
\tag{10.6}
\]

The inherited covariance-boundary theorem gives

\[
\boxed{
\|f_{-i}-f_{-i}^{(j)}\|_{L^2}
\le
\rho_{ij}\sqrt{b_k(G_{ij})}
+\Psi_{G_{ij},k}(\rho_{ij};C_{-i})
+\zeta_{ij}+\zeta_{ij}'.
}
\tag{10.7}
\]

Thus any deterministic `L^2` envelope for the right side supplies the `B_ij` in `(6.4)`. Equivalently, take the replacement-coupling `L^2` norm of the right side. A single observed boundary value is **not** silently promoted to a deterministic stability constant.

The same boundary theorem controls `D_i` in `(8.1)` when applied to the full-data and deletion pair.

This is the key same-trained-matrix point: the hard support may depend arbitrarily on the trained matrix; the support discontinuity is paid by the actual boundary covariance profile, not by replacing the support with an iid mask.

# 11. `P19-MP-LOO-BOUNDARY-CERT-32` — PROVED by composition under an honest null

Suppose the common proxy Gram obeys the simultaneous restricted event

\[
(1-\delta)I\preceq G_{II}\preceq(1+\delta)I
\qquad\text{for every }|I|\le2k,
\tag{11.1}
\]

with `0<=delta<1`. Then the inherited sparse-RIP boundary theorem gives

\[
\boxed{
\|[H_k(C)-H_k(C')]\psi\|_{L^2}
\le
\sqrt{1+\delta}\,[\rho+B_{2k,\rho}(C)],
}
\tag{11.2}
\]

and

\[
\boxed{
\|H_k(C)-H_k(C')\|_{op}
\le
\sqrt{(1+\delta)/(1-\delta)}\,
[\rho+B_{2k,\rho}(C)].
}
\tag{11.3}
\]

Representation debts remain explicit if feature maps differ.

For the already validated honest iid Gaussian feature null, simultaneous sparse-RIP follows from a chi-square/net argument whenever

\[
k\log(er/k)=o(n).
\tag{11.4}
\]

Thus `(0.1)` can remain informative even when `r/n>1` and the **global** empirical Gram is singular with an MP zero atom.

The distinct spectral objects are therefore:
