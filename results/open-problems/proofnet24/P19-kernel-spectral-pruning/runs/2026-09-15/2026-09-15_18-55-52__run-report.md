# 4. Restricted Gram transfer from feature-map stability

The key observation is that the global feature operator norm is stronger than necessary. Only sparse directions that can occur in a pruning support union need to be stable.

Let `H` be a real Hilbert space and let

\[
T_0,T:\mathbb R^r\to H
\]

be linear maps. Think of either:

- empirical feature operators
  \[
  T_0v=m^{-1/2}\Psi v,
  \qquad
  Tv=m^{-1/2}\Phi v,
  \]
  for two feature matrices `Psi,Phi in R^{m x r}`; or
- population feature operators
  \[
  T_0v=\langle v,\psi(X)\rangle\in L^2,
  \qquad
  Tv=\langle v,\phi(X)\rangle\in L^2.
  \]

Put

\[
G_0=T_0^*T_0,
\qquad
G=T^*T.
\]

For sparsity level `s`, define

\[
\mathcal S_s
=
\{v\in\mathbb R^r:\|v\|_2=1,\ \|v\|_0\le s\},
\]

\[
B_s
=
\sup_{v\in\mathcal S_s}\|T_0v\|_H^2,
\]

and the sparse directional feature debt

\[
\boxed{
\varepsilon_s
=
\sup_{v\in\mathcal S_s}
\|(T-T_0)v\|_H.
}
\tag{4.1}
\]

## `P19-RESTRICTED-GRAM-TRANSFER-27` — NEW / PROVED

For every `s`,

\[
\boxed{
\sup_{|J|\le s}
\|(G-G_0)_{JJ}\|_{\rm op}
\le
2\sqrt{B_s}\,\varepsilon_s
+\varepsilon_s^2.
}
\tag{4.2}
\]

### Proof

Put `E=T-T_0`. For every `v in S_s`,

\[
\begin{aligned}
v^*(G-G_0)v
&=
\|T_0v+Ev\|_H^2-\|T_0v\|_H^2\\
&=
2\langle T_0v,Ev\rangle_H+\|Ev\|_H^2.
\end{aligned}
\]

Hence

\[
|v^*(G-G_0)v|
\le
2\sqrt{B_s}\,\varepsilon_s+\varepsilon_s^2.
\tag{4.3}
\]

For a symmetric principal block,

\[
\|(G-G_0)_{JJ}\|_{\rm op}
=
\sup_{\substack{\|v\|=1\\\operatorname{supp}(v)\subseteq J}}
|v^*(G-G_0)v|.
\]

Take the supremum over `|J|<=s`.

QED.

### Important dependence point

No independence appears in the proof. `T`, `T_0`, the supports, and the training data may be mutually dependent. The theorem is a deterministic operator identity once the two feature maps are aligned in a common coordinate system.

# 5. Exact empirical and population corollaries

## 5.1 Empirical feature matrices

Let

\[
G_0=\frac1m\Psi^*\Psi,
\qquad
G=\frac1m\Phi^*\Phi,
\qquad
\Delta_\Phi=\Phi-\Psi.
\]

Then

\[
\boxed{
\varepsilon_s^{\rm emp}
=
\sup_{v\in\mathcal S_s}
\frac{\|\Delta_\Phi v\|_2}{\sqrt m}
}
\tag{5.1}
\]

and

\[
B_s^{\rm emp}
=
\sup_{v\in\mathcal S_s}
\frac{\|\Psi v\|_2^2}{m}.
\]

Equation `(4.2)` is then an **exact finite-sample trained-to-proxy Gram certificate**.

A crude but checkable columnwise bound is also immediate. If

\[
e_{\rm col}
=
\max_j\frac{\|\Delta_\Phi e_j\|_2}{\sqrt m},
\]

then for every `s`-sparse unit `v`,

\[
\frac{\|\Delta_\Phi v\|}{\sqrt m}
\le
\sum_j|v_j|e_{\rm col}
\le
\sqrt s\,e_{\rm col}.
\]

Thus

\[
\boxed{
\sup_{|J|\le s}
\|(G-G_0)_{JJ}\|_{\rm op}
\le
2\sqrt{B_s^{\rm emp}}\sqrt s\,e_{\rm col}
+s e_{\rm col}^2.
}
\tag{5.2}
\]

The sparse-direction debt `(5.1)` is the sharper object; `(5.2)` is only a fallback measurement.

## 5.2 Population covariance

For centered aligned features `phi(X),psi(X)`, define

\[
\Sigma_\phi=E[\phi\phi^*],
\qquad
\Sigma_\psi=E[\psi\psi^*].
\]

With

\[
\varepsilon_s^{\rm pop}
=
\sup_{v\in\mathcal S_s}
\left(E|v^*(\phi-\psi)|^2\right)^{1/2},
\]

\[
B_s^{\rm pop}
=
\sup_{v\in\mathcal S_s}E|v^*\psi|^2,
\]

we obtain

\[
\boxed{
\sup_{|J|\le s}
\|(\Sigma_\phi-\Sigma_\psi)_{JJ}\|_{\rm op}
\le
2\sqrt{B_s^{\rm pop}}\,\varepsilon_s^{\rm pop}
+(\varepsilon_s^{\rm pop})^2.
}
\tag{5.3}
\]

This is the local counterpart of the earlier global P19 feature-Gram perturbation theorem. It does not pay feature width outside the pruning-relevant support class.

# 7. Transfer to adaptive structured prune-and-refit

Partition the `r` channels into fixed blocks of width at most `b`. The inherited greedy theorem uses retained block sets `A` of size at most `k-1` and candidate block sets `L` of size at most `k`. Therefore every union `A union L` contains at most

\[
s=2bk
\]

coordinates, safely.

For the trained Gram `G`, define

\[
M_{L\mid A}
=
G_{LL}-G_{LA}G_{AA}^{-1}G_{AL},
\]

and let `D_{L|A}` be its block diagonal.

## `P19-TRAINED-WEAKSUBMOD-27` — NEW / PROVED

Assume `(6.1)` at `s=2bk` and `d_s<a_s`. Then for every admissible `A,L`,

\[
\boxed{
(a_s-d_s)I
\preceq
M_{L\mid A}
\preceq
(b_s+d_s)I.
}
\tag{7.1}
\]

Consequently

\[
\boxed{
\lambda_{\min}
\left(
D_{L\mid A}^{-1/2}
M_{L\mid A}
D_{L\mid A}^{-1/2}
\right)
\ge
\frac{a_s-d_s}{b_s+d_s}.
}
\tag{7.2}
\]

Hence the trained weak-submodularity ratio obeys

\[
\boxed{
\gamma_k(G)
\ge
\frac{a_s-d_s}{b_s+d_s}.
}
\tag{7.3}
\]

The inherited adaptive greedy prune-and-refit guarantee becomes

\[
\boxed{
F(S_g)
\ge
\left[
1-\left(1-\frac{\gamma_k(G)}k\right)^k
\right]F(S_*)
\ge
(1-e^{-\gamma_k(G)})F(S_*).
}
\tag{7.4}
\]

### Proof of `(7.1)`

For every `x` on the candidate coordinates,

\[
x^*M_{L\mid A}x
=
\min_y
\binom yx^*
G_{A\cup L,A\cup L}
\binom yx.
\]

The lower restricted bound `(6.3)` gives

\[
x^*M_{L\mid A}x
\ge
(a_s-d_s)\|x\|^2.
\]

For the upper bound choose `y=0`, giving

\[
x^*M_{L\mid A}x
\le
(b_s+d_s)\|x\|^2.
\]

Each diagonal Schur block obeys the same bounds, so

\[
(a_s-d_s)I\preceq D_{L\mid A}\preceq(b_s+d_s)I.
\]

The generalized Rayleigh quotient gives `(7.2)`.

QED.

# 10. Sparse neighboring-retrain singular-vector theorem

The preceding `P19-SPARSE-PREDICTION-DYAD-26` assumed two sparse readouts act on the same feature map. Fully retrained neural features need one additional debt.

Let two legally aligned pruned predictors be

\[
f_1(x)=C_1\phi_1(x),
\qquad
f_2(x)=C_2\phi_2(x),
\]

with column supports

\[
S_1=\operatorname{supp}_{\rm col}(C_1),
\qquad
S_2=\operatorname{supp}_{\rm col}(C_2),
\]

and

\[
|S_1|,|S_2|\le k.
\]

Let `psi(x)` be a common honest/aligned proxy feature map in the same channel coordinates and set

\[
J=S_1\cup S_2,
\qquad |J|\le2k.
\]

Assume its second-moment Gram on `J` obeys

\[
\boxed{
E[\psi_J\psi_J^*]\succeq aI,
\qquad a>0.
}
\tag{10.1}
\]

Define

\[
\delta_{\rm pred}
=
\left(E\|f_1-f_2\|^2\right)^{1/2},
\]

and the **coefficient-weighted feature debts**

\[
\zeta_1
=
\left(E\|C_1(\phi_1-\psi)\|^2\right)^{1/2},
\]

\[
\zeta_2
=
\left(E\|C_2(\phi_2-\psi)\|^2\right)^{1/2}.
\]

## `P19-SPARSE-LOO-DYAD-27` — NEW / PROVED

With

\[
\Delta=C_1-C_2,
\]

we have

\[
\boxed{
\|\Delta\|_{\rm op}
\le
\|\Delta\|_F
\le
\frac{
\delta_{\rm pred}+\zeta_1+\zeta_2
}{\sqrt a}.
}
\tag{10.2}
\]

### Proof

Because `Delta` is supported on `J`,

\[
E\|\Delta\psi\|^2
=
\operatorname{tr}
\left[
\Delta_J
E(\psi_J\psi_J^*)
\Delta_J^*
\right]
\ge
a\|\Delta\|_F^2.
\tag{10.3}
\]

But

\[
\begin{aligned}
\Delta\psi
&=C_1\psi-C_2\psi\\
&=(f_1-f_2)
-C_1(\phi_1-\psi)
+C_2(\phi_2-\psi).
\end{aligned}
\]

Minkowski in `L^2` gives

\[
\left(E\|\Delta\psi\|^2\right)^{1/2}
\le
\delta_{\rm pred}+\zeta_1+\zeta_2.
\]

Combine with `(10.3)`.

QED.

If only feature-map debts are available, then, since `C_i=C_iP_{S_i}`,

\[
\zeta_i
\le
\|C_i\|_{\rm op}
\left(
E\|P_{S_i}(\phi_i-\psi)\|^2
\right)^{1/2}.
\tag{10.4}
\]

Thus the theorem pays only feature mismatch on channels actually used by each sparse readout.
