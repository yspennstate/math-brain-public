# 5. Exact conditional Wishart reduction

For disjoint `A,L`, define the empirical conditional covariance

\[
M_{L\mid A}
=
G_{LL}
-
G_{LA}G_{AA}^{-1}G_{AL},
\tag{5.1}
\]

where the subscripts denote the coordinate unions `U(A),U(L)`.

Let

\[
P_A
=
X_A(X_A^*X_A)^{-1}X_A^*
\]

be the orthogonal projector onto the columns of `X_A`.

Direct algebra gives

\[
\boxed{
M_{L\mid A}
=
\frac1nX_L^*(I-P_A)X_L.
}
\tag{5.2}
\]

## `P19-CONDITIONAL-WISHART-26` — NEW / PROVED

Conditionally on `X_A`, let

\[
U_A\in\mathbb R^{n\times d_A}
\]

have orthonormal columns spanning `\operatorname{im}(I-P_A)`. Then

\[
Z_{A,L}=U_A^*X_L
\in\mathbb R^{d_A\times s_L}
\]

has iid `N(0,1)` entries and is independent of `X_A`. Moreover

\[
\boxed{
M_{L\mid A}
=
\frac1nZ_{A,L}^*Z_{A,L}.
}
\tag{5.3}
\]

Equivalently,

\[
\boxed{
\frac n{d_A}M_{L\mid A}
=
\frac1{d_A}Z_{A,L}^*Z_{A,L}
}
\tag{5.4}
\]

conditionally on `X_A`.

### Proof

The columns of `X_L` are independent of `X_A`. Conditional on `X_A`, the matrix `U_A` is deterministic orthonormal. Rotational invariance of each standard Gaussian column gives

\[
U_A^*X_j\sim N(0,I_{d_A})
\]

for every `j\in U(L)`, and independence across columns is preserved. Equation `(5.3)` follows from `(5.2)` and

\[
I-P_A=U_AU_A^*.
\]

QED.

### Why this matters

The adaptive Schur complement is not merely *approximately* Wishart after conditioning: under this honest Gaussian null it is exactly a lower-dimensional Wishart covariance. The conditioning removes `s_A` row-space degrees of freedom but does not bias the unrevealed feature columns.

This is the correct object; no iid pruning mask appears.

# 6. Elementary finite-width covariance concentration

The next lemma is proved from the chi-square MGF and a sphere net, so no external singular-value theorem is imported.

Let

\[
Z\in\mathbb R^{d\times m}
\]

have iid `N(0,1)` entries and

\[
S=\frac1dZ^*Z-I_m.
\]

For fixed unit `v`,

\[
v^*\frac1dZ^*Zv
\stackrel d=
\frac1d\chi_d^2.
\]

For `0<u\le1`, direct Chernoff optimization of the chi-square MGF gives

\[
P\left\{
\left|\frac1d\chi_d^2-1\right|>u
\right\}
\le
2e^{-du^2/8}.
\tag{6.1}
\]

For completeness, the upper-tail rate is

\[
\frac d2[u-\log(1+u)]
\ge
\frac{du^2}{8},
\]

because

\[
u-\log(1+u)-u^2/4
\]

has nonnegative derivative on `[0,1]`; the lower-tail rate is even larger.

Let `\mathcal N` be a `1/4`-net of `S^{m-1}` with

\[
|\mathcal N|\le9^m.
\]

For symmetric `S`, the standard net inequality gives

\[
\|S\|_{\rm op}
\le
2\max_{v\in\mathcal N}|v^*Sv|.
\]

Therefore, for `0<\delta\le1`,

\[
\boxed{
P\left\{
\left\|\frac1dZ^*Z-I\right\|_{\rm op}>\delta
\right\}
\le
2\,9^m
\exp\left[-\frac{d\delta^2}{32}\right].
}
\tag{6.2}
\]

This deliberately uses a crude explicit constant in exchange for a completely elementary proof.

# 7. Simultaneous adaptive conditional-correlation theorem

Define the exact combinatorial count

\[
\boxed{
\mathfrak N_{p,k}
=
\left(
\sum_{j=0}^k{p\choose j}
\right)^2.
}
\tag{7.1}
\]

This upper-bounds the number of ordered disjoint pairs `(A,L)` with

\[
|A|\le k-1,
\qquad
1\le|L|\le k.
\]

Put

\[
\boxed{
d_0=n-b(k-1).}
\tag{7.2}
\]

For failure level `0<\eta<1`, define

\[
\boxed{
\delta_{n,p,k,b}(\eta)
=
\sqrt{
\frac{32}{d_0}
\left[
\log\frac{2\mathfrak N_{p,k}}\eta
+bk\log9
\right]
}.
}
\tag{7.3}
\]

## `P19-ADAPTIVE-CONDITIONAL-GAUSS-26` — NEW / PROVED

Assume

\[
\delta_*:=\delta_{n,p,k,b}(\eta)<1.
\]

Then with probability at least `1-\eta`, **simultaneously for every** disjoint block pair `(A,L)` satisfying

\[
|A|\le k-1,
\qquad
1\le|L|\le k,
\]

one has

\[
\boxed{
\left\|
\frac n{d_A}M_{L\mid A}-I
\right\|_{\rm op}
\le
\delta_*.
}
\tag{7.4}
\]

Let

\[
D_{L\mid A}
=
\bigoplus_{b\in L}M_{bb\mid A},
\]

and

\[
\mathcal R_{L\mid A}
=
D_{L\mid A}^{-1/2}
M_{L\mid A}
D_{L\mid A}^{-1/2}.
\]

On the same event,

\[
\boxed{
\lambda_{\min}(\mathcal R_{L\mid A})
\ge
\frac{1-\delta_*}{1+\delta_*}
}
\tag{7.5}
\]

and

\[
\boxed{
\lambda_{\max}(\mathcal R_{L\mid A})
\le
\frac{1+\delta_*}{1-\delta_*}
}
\tag{7.6}
\]

simultaneously for all such pairs.

Consequently the P19 weak-submodularity ratio satisfies

\[
\boxed{
\gamma_k
\ge
\frac{1-\delta_*}{1+\delta_*}
}
\tag{7.7}
\]

on that event.

### Proof

For one fixed pair `(A,L)`, condition on `X_A`. By `P19-CONDITIONAL-WISHART-26`,

\[
\frac n{d_A}M_{L\mid A}
=
\frac1{d_A}Z^*Z
\]

with `Z` a `d_A\times s_L` standard Gaussian matrix. Since

\[
d_A\ge d_0,
\qquad
s_L\le bk,
\]

`(6.2)` gives

\[
P\left\{
\left\|
\frac n{d_A}M_{L\mid A}-I
\right\|>\delta_*
\right\}
\le
2\,9^{bk}e^{-d_0\delta_*^2/32}.
\]

The conditional bound does not depend on the realized `X_A`, so it also holds unconditionally.

Union bound over at most `\mathfrak N_{p,k}` pairs and the definition `(7.3)` give total failure probability at most `\eta`. This proves `(7.4)` simultaneously.

Write

\[
c_A=d_A/n.
\]

Then `(7.4)` gives

\[
c_A(1-\delta_*)I
\preceq
M_{L\mid A}
\preceq
c_A(1+\delta_*)I.
\tag{7.8}
\]

Every diagonal block of `M_{L\mid A}` is a principal block, so

\[
c_A(1-\delta_*)I
\preceq
D_{L\mid A}
\preceq
c_A(1+\delta_*)I.
\tag{7.9}
\]

Combining the lower bound on `M` with the upper bound on `D`,

\[
M_{L\mid A}
\succeq
\frac{1-\delta_*}{1+\delta_*}
D_{L\mid A}.
\]

Likewise,

\[
M_{L\mid A}
\preceq
\frac{1+\delta_*}{1-\delta_*}
D_{L\mid A}.
\]

Congruence by `D^{-1/2}` proves `(7.5)`–`(7.6)`, and the definition of `\gamma_k` gives `(7.7)`.

QED.

# 8. Asymptotic local regime and improvement over the global MP edge

For `1\le k\le p/2`, the standard entropy bound gives

\[
\log\mathfrak N_{p,k}
=O\bigl(k\log(ep/k)\bigr).
\]

For fixed block width `b`, if

\[
\boxed{
k\log(ep/k)+\log(1/\eta)=o(n),}
\tag{8.1}
\]

then

\[
\delta_*=o(1)
\]

and hence

\[
\boxed{
\gamma_k
\ge
1-O\left(
\sqrt{\frac{k\log(ep/k)+\log(1/\eta)}n}
\right).
}
\tag{8.2}
\]

This is qualitatively stronger than the inherited global MP condition-number bound.

In particular, `(8.2)` can remain near one even when

\[
p/n\to\alpha\ge1,
\]

where the full empirical Gram is singular and the global MP lower edge is zero.

The reason is exact: greedy pruning queries only small conditional coordinate blocks, and the theorem pays the entropy of all such small blocks rather than the condition number of the entire ambient feature space.

## Consequence for greedy prune-and-refit

On the event `(7.7)`, the inherited greedy theorem gives

\[
\boxed{
F(S_g)
\ge
\left[
1-\left(
1-
\frac{1-\delta_*}{k(1+\delta_*)}
\right)^k
\right]
F(S_*).
}
\tag{8.3}
\]

As `\delta_*\to0`, the generic weak-submodular factor approaches

\[
1-e^{-1}.
\]

This is still a worst-case generic greedy factor. Under the population identity-covariance null the refit objective is modular and greedy is exact. The point of `(8.3)` is finite-sample robustness under simultaneous adaptive conditional correlations.

# 9. Deterministic restricted-isometry-to-Schur transfer

The Gaussian theorem above can be factored into a deterministic geometric statement that is useful for subgaussian and trained-feature proxies.

Suppose a Gram matrix `G\succeq0` satisfies, for every coordinate union `J` containing at most `s` coordinates,

\[
\boxed{
(1-\delta)I
\preceq
G_{JJ}
\preceq
(1+\delta)I,
\qquad
0\le\delta<1.
}
\tag{9.1}
\]

## `P19-RIP-SCHUR-TRANSFER-26` — NEW / PROVED

For any disjoint coordinate sets `A,L` with

\[
|A|+|L|\le s,
\]

the Schur complement

\[
M_{L\mid A}
=
G_{LL}-G_{LA}G_{AA}^{-1}G_{AL}
\]

satisfies

\[
\boxed{
(1-\delta)I
\preceq
M_{L\mid A}
\preceq
(1+\delta)I.
}
\tag{9.2}
\]

Hence, for any block partition of `L` and corresponding block diagonal `D_{L|A}`,

\[
\boxed{
\frac{1-\delta}{1+\delta}
\le
\lambda_{\min}(D^{-1/2}MD^{-1/2})
\le
\lambda_{\max}(D^{-1/2}MD^{-1/2})
\le
\frac{1+\delta}{1-\delta}.
}
\tag{9.3}
\]

### Proof

For any vector `x` on `L`, the Schur variational identity is

\[
x^*M_{L\mid A}x
=
\min_y
\begin{pmatrix}y\\x\end{pmatrix}^*
G_{A\cup L,A\cup L}
\begin{pmatrix}y\\x\end{pmatrix}.
\]

The restricted lower bound gives

\[
x^*Mx
\ge
(1-\delta)
\min_y(\|y\|^2+\|x\|^2)
=
(1-\delta)\|x\|^2.
\]

For the upper bound choose `y=0`:

\[
x^*Mx
\le
x^*G_{LL}x
\le
(1+\delta)\|x\|^2.
\]

This proves `(9.2)`. Equation `(9.3)` follows exactly as in Section 7.

QED.

### Scope

This theorem shows what a trained-feature transfer actually needs: not an iid-mask story and not necessarily a global covariance theorem, but an honest restricted-eigenvalue/RIP certificate on the coordinate unions the pruning algorithm may visit.

For isotropic subgaussian honest features, standard sparse covariance concentration can be plugged into `(9.1)` once its hypotheses are verified. This run does **not** silently assert that an arbitrary response-trained representation has such an RIP law.

# 10. Exact conditional Marchenko–Pastur reduction

The finite-width concentration theorem has a clean fixed-pair asymptotic form.

Consider a sequence of disjoint scalar-coordinate sets `A_n,L_n`, with

\[
a_n=|A_n|,
\qquad
m_n=|L_n|,
\qquad
d_n=n-a_n.
\]

Assume

\[
a_n/n\to\tau<1,
\qquad
m_n/d_n\to\beta\in[0,\infty).
\]

By `(5.4)`, conditionally on `X_{A_n}`,

\[
\frac n{d_n}M_{L_n\mid A_n}
=
\frac1{d_n}Z_n^*Z_n
\]

with `Z_n` standard Gaussian.

## `P19-CONDITIONAL-MP-26` — NEW / PROVED REDUCTION

The empirical eigenvalue law of

\[
\frac n{d_n}M_{L_n\mid A_n}
\]

is exactly the classical Wishart law and therefore converges to the Marchenko–Pastur law of aspect `\beta`.

Its upper edge tends to

\[
\boxed{(1+\sqrt\beta)^2.}
\]

For `\beta<1`, its lower edge tends to

\[
\boxed{(1-\sqrt\beta)^2.}
\]

For `\beta>1`, the `m_n\times m_n` covariance has a zero atom from rank deficiency, while the nonzero lower edge is the usual positive MP edge.

For scalar blocks, the diagonal normalizer satisfies

\[
\max_{j\in L_n}
\left|
\frac{n}{d_n}M_{jj\mid A_n}-1
\right|
\xrightarrow{P}0
\]

whenever `\log m_n=o(d_n)`, by chi-square concentration and a union bound. Hence the normalized conditional correlation matrix

\[
\mathcal R_{L_n\mid A_n}
=
D^{-1/2}MD^{-1/2}
\]

has the same MP limit and the same nonzero extreme-edge limits.

### Interpretation

This is a **conditional MP law**, not the July source MP law and not the earlier pruning-boundary radial MP law. The matrices are different:

- July: noise matrix `X_n` in an additive spike model;
- earlier P19 boundary null: a score-selected readout boundary block;

# 13. Sparse prediction agreement gives singular-vector stability past the global hard edge

The local theorem has a stronger singular-vector consequence than the inherited global Gram-floor certificate.

Let

\[
C_1,C_2\in\mathbb R^{q\times r}

be two deployed readouts, each supported on at most `k` feature columns. Their support union `J` satisfies

\[

Put

\[

\]

For an empirical feature Gram `G`, define the empirical prediction discrepancy

\[
\boxed{

=
\operatorname{tr}(\Delta G\Delta^*).
}
\tag{13.1}
\]

## `P19-SPARSE-PREDICTION-DYAD-26` — NEW / PROVED

Assume the realized Gram obeys the restricted lower bound

\[
\boxed{

\qquad
a>0.
}
\tag{13.2}
\]

Then

\[
\boxed{
\|C_1-C_2\|_{\rm op}
\le
\|C_1-C_2\|_F
\le
\sqrt{\frac{\mathcal L_G(C_1,C_2)}a}.
}
\tag{13.3}
\]

Let `K` be a positive singular-value cluster of `C_1` with observed separation, including from zero,

\[
\Delta_K(C_1)>0.
\]

If

\[
\boxed{
\sqrt{\frac{\mathcal L_G(C_1,C_2)}a}
\le
\Delta_K(C_1)/2,
}
\tag{13.4}
\]

then the corresponding cluster of `C_2` is well defined and safe Hermitian-dilation/Wedin estimates give

\[
\boxed{
\|\Pi_K^L(C_2)-\Pi_K^L(C_1)\|_{\rm op}
\le
\frac4{\Delta_K(C_1)}
\sqrt{\frac{\mathcal L_G(C_1,C_2)}a},
}
\tag{13.5}
\]

\[
\boxed{
\|\Pi_K^R(C_2)-\Pi_K^R(C_1)\|_{\rm op}
\le
\frac4{\Delta_K(C_1)}
\sqrt{\frac{\mathcal L_G(C_1,C_2)}a},
}
\tag{13.6}
\]

and for the source-style sign-free mixed dyad,

\[
\boxed{
\|F_K(C_2)-F_K(C_1)\|_{\rm op}
\le
\frac4{\Delta_K(C_1)}
\sqrt{\frac{\mathcal L_G(C_1,C_2)}a}.
}
\tag{13.7}
\]

### Proof

Because `\Delta` is supported on `J`,

\[
\mathcal L_G
=
\operatorname{tr}(\Delta_JG_{JJ}\Delta_J^*)
\ge
 a\|\Delta_J\|_F^2.
\]

Therefore

\[
\|\Delta\|_{\rm op}
\le
\|\Delta\|_F
\le
\sqrt{\mathcal L_G/a},
\]

which proves `(13.3)`. Equations `(13.5)`–`(13.7)` are then the inherited safe Wedin/Hermitian-dilation bounds, invoked only after `(13.4)` supplies a genuine gap margin.

QED.
