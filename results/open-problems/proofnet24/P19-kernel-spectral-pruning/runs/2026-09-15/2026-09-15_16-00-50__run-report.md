# 5. Exact prune-and-refit Schur theorem

After discarding `T`, allow the readout on the kept coordinates to be refit arbitrarily. For

\[
A\in\mathbb R^{q\times |S|},
\]

define

\[
\mathcal L_S(A)
=E\|C\xi-A\xi_S\|_2^2.
\tag{5.1}
\]

Define the conditional covariance / Schur complement

\[
\boxed{
\Sigma_{T\mid S}
=
\Sigma_{TT}
-
\Sigma_{TS}\Sigma_{SS}^{-1}\Sigma_{ST}.
}
\tag{5.2}
\]

## `P19-PRUNE-REFIT-SCHUR-24` — NEW / PROVED

The unique minimum-risk refitted readout on the kept coordinates is

\[
\boxed{
A_S^*
=
C_S+C_T\Sigma_{TS}\Sigma_{SS}^{-1}.
}
\tag{5.3}
\]

The exact minimal population prediction perturbation is

\[
\boxed{
\mathcal R_{\rm refit}(S)
:=
\min_A\mathcal L_S(A)
=
\operatorname{tr}
\left[
C_T\Sigma_{T\mid S}C_T^*
\right].
}
\tag{5.4}
\]

The no-refit centered pruning risk from the preceding run is

\[
\mathcal R_{\rm no}(S)
=
\operatorname{tr}[C_T\Sigma_{TT}C_T^*],
\tag{5.5}
\]

so refitting gains exactly

\[
\boxed{
\mathcal R_{\rm no}(S)-\mathcal R_{\rm refit}(S)
=
\operatorname{tr}
\left[
C_T\Sigma_{TS}\Sigma_{SS}^{-1}\Sigma_{ST}C_T^*
\right]
\ge0.
}
\tag{5.6}
\]

### Proof

Write

\[
B=A-C_S.
\]

Then

\[
C\xi-A\xi_S
=C_T\xi_T-B\xi_S.
\tag{5.7}
\]

The normal equation is

\[
B\Sigma_{SS}=C_T\Sigma_{TS},
\]

hence

\[
B^*=C_T\Sigma_{TS}\Sigma_{SS}^{-1},
\]

which gives `(5.3)`. Equivalently,

\[
C\xi-A_S^*\xi_S
=
C_T
\left(
\xi_T-\Sigma_{TS}\Sigma_{SS}^{-1}\xi_S
\right).
\tag{5.8}
\]

The covariance of the bracket is exactly the Schur complement `(5.2)`, proving `(5.4)`. Subtract `(5.4)` from `(5.5)` to obtain `(5.6)`. The matrix in `(5.6)` is positive semidefinite because it is `BB^*` after inserting `Σ_SS^{-1/2}`. QED.

### Interpretation

The right structured-pruning quantity after readout refitting is not marginal feature variance. It is **conditional covariance after projecting the discarded block onto the kept feature span**.

This is the population analogue of quotienting a nuisance direction: predictable discarded-feature content costs zero after refitting.

# 6. Exact one-block deletion score

Let `B` be one feature block and let `S=B^c`. Then the exact optimal loss incurred by deleting block `B` and refitting every retained coefficient is

\[
\boxed{
q_B
=
\operatorname{tr}
\left[
C_B\Sigma_{B\mid B^c}C_B^*
\right].
}
\tag{6.1}
\]

This score is invariant under orthogonal changes of coordinates within the block. It can be tiny even when the marginal block energy

\[
\operatorname{tr}[C_B\Sigma_{BB}C_B^*]
\]

is large, whenever the block is nearly predictable from the retained coordinates.

Thus strong feature correlation is not automatically an obstacle to pruning; it can create redundancy that refitting exploits.

However, the next counterexample shows that these singleton/block deletion scores are not additive across multiple simultaneous deletions.

# 7. Conditional deletion scores are not additive

## `P19-REFIT-SINGLETON-NONADD-CE-24` — NEW / PROVED

Let independent standard Gaussians be

\[
Z,\varepsilon_1,\varepsilon_2,W\sim N(0,1),
\]

and set

\[
\phi_1=Z+\eta\varepsilon_1,
\qquad
\phi_2=Z+\eta\varepsilon_2,
\qquad
\phi_3=W,
\tag{7.1}
\]

with

\[
\eta=0.1.
\]

Take scalar output and full coefficient vector

\[
C=(1/2,1/2,a),
\qquad a=0.1.
\tag{7.2}
\]

Put

\[
v=1+\eta^2=1.01.
\]

Then

\[
\operatorname{Var}(\phi_1\mid\phi_2)
=
v-\frac1v
=
\frac{\eta^2(2+\eta^2)}{1+\eta^2}
\approx0.0199009901.
\tag{7.3}
\]

Therefore the exact one-feature deletion/refit costs are

\[
q_1=q_2
=
\frac14\operatorname{Var}(\phi_1\mid\phi_2)
\approx0.0049752475,
\tag{7.4}
\]

while

\[
q_3=a^2=0.01.
\tag{7.5}
\]

A **static** rule that ranks the original singleton conditional deletion scores and deletes the two cheapest coordinates would therefore delete features `1` and `2`.

But deleting both correlated features and keeping only feature `3` loses

\[
\boxed{
\operatorname{Var}\left(\frac{\phi_1+\phi_2}{2}\right)
=1+\frac{\eta^2}{2}
=1.005.
}
\tag{7.6}
\]

By contrast, deleting features `1` and `3`, keeping feature `2`, and optimally refitting gives

\[
\boxed{
q_{\{1,3\}}
=
\frac14\operatorname{Var}(\phi_1\mid\phi_2)+a^2
\approx0.0149752475.
}
\tag{7.7}
\]

The ratio is approximately

\[
\boxed{67.11.}
\tag{7.8}
\]

Thus one-block conditional costs cannot simply be sorted once and added to solve a multi-block exact-cardinality refit problem.

This counterexample does **not** disprove an adaptive greedy algorithm that recomputes conditional costs after every deletion; it disproves only static singleton-score additivity/top-k.

# 8. Block-covariance near-oracle theorem without refitting

The preceding counterexample says full-covariance refit selection can remain combinatorial. There is nevertheless a clean theorem when correlation is strong **within** known blocks but weak **across** blocks.

Let

\[
\mathcal B=\{B_1,\ldots,B_m\}
\]

be a fixed partition of the feature coordinates into equal-cost blocks. A structured support is a union of blocks, and the budget keeps exactly `k` blocks.

Define the block-diagonal covariance surrogate

\[
\boxed{
D_{\mathcal B}
=\operatorname{blockdiag}
(\Sigma_{B_1B_1},\ldots,\Sigma_{B_mB_m}).
}
\tag{8.1}
\]

For block `a`, define its retained-value score

\[
\boxed{
g_a
=
\operatorname{tr}
\left[
C_{B_a}\Sigma_{B_aB_a}C_{B_a}^*
\right]
=
\|C_{B_a}\Sigma_{B_aB_a}^{1/2}\|_F^2.
}
\tag{8.2}
\]

Let

\[
\varepsilon_{\mathcal B}
=
\|\Sigma-D_{\mathcal B}\|_{\rm op},
\tag{8.3}
\]

and suppose

\[
\mu_{\mathcal B}
=
\lambda_{\min}(D_{\mathcal B})>0.
\tag{8.4}
\]

Let `S_B` be the union of the `k` blocks with largest `g_a`, and let `S_*` be the exact cardinality-`k` block support minimizing the true no-refit centered risk `(2.1)`.

## `P19-BLOCK-COV-ORACLE-24` — NEW / PROVED

For every block support `S`,

\[
\boxed{
\left|
\mathcal R_\Sigma(S)-
\mathcal R_{D_{\mathcal B}}(S)
\right|
\le
\varepsilon_{\mathcal B}
\|CP_{S^c}\|_F^2.
}
\tag{8.5}
\]

Put

\[
\delta_{\mathcal B}
=
\varepsilon_{\mathcal B}/\mu_{\mathcal B}.
\tag{8.6}
\]

If

\[
\delta_{\mathcal B}<1,
\]

then

\[
\boxed{
\mathcal R_\Sigma(S_B)
\le
\frac{1+\delta_{\mathcal B}}
{1-\delta_{\mathcal B}}
\mathcal R_\Sigma(S_*).
}
\tag{8.7}
\]

Without the lower spectral floor, the additive form remains:

\[
\boxed{
\mathcal R_\Sigma(S_B)
\le
\mathcal R_\Sigma(S_*)
+2\varepsilon_{\mathcal B}\|C\|_F^2.
}
\tag{8.8}
\]

### Proof

For `P=P_{S^c}`,

\[
\mathcal R_\Sigma(S)-\mathcal R_{D_{\mathcal B}}(S)
=
\operatorname{tr}
[(\Sigma-D_{\mathcal B})PC^*CP].
\]

The second factor is positive semidefinite, so

\[
|\operatorname{tr}[(\Sigma-D_{\mathcal B})PC^*CP]|
\le
\varepsilon_{\mathcal B}\operatorname{tr}(PC^*CP),
\]

which is `(8.5)`. Also

\[
\mathcal R_{D_{\mathcal B}}(S)
\ge
\mu_{\mathcal B}\|CP\|_F^2.
\]

This yields the multiplicative sandwich

\[
(1-\delta_{\mathcal B})\mathcal R_{D_{\mathcal B}}(S)
\le
\mathcal R_\Sigma(S)
\le
(1+\delta_{\mathcal B})\mathcal R_{D_{\mathcal B}}(S).
\]

Since `D_B` is block diagonal, its risk is the sum of discarded scores `g_a`, so keeping the `k` largest scores exactly minimizes the surrogate. Compare `S_B` and `S_*` through the sandwich to obtain `(8.7)`. The additive proof is identical to the scalar diagonal case and gives `(8.8)`. QED.

### Scope

Equal block cost/cardinality is essential for the simple top-k statement. With unequal block costs, the exact surrogate problem is a knapsack-type selection problem, not ordinary top-k.

This theorem permits arbitrarily strong **within-block** correlation. Only the cross-block operator debt is required to be small.

# 9. Prediction risk controls coefficient operator motion only with a Gram floor

The refit theorem gives prediction error directly. Singular-vector stability requires an operator perturbation of the coefficient/readout matrix. The bridge is a lower feature-covariance edge.

Embed the optimal refit into the full coordinate space by defining

\[
\widetilde C_S P_S=A_S^*,
\qquad
\widetilde C_SP_T=0.
\tag{9.1}
\]

Put

\[
\Delta_S=C-\widetilde C_S.
\tag{9.2}
\]

Then by construction

\[
\mathcal R_{\rm refit}(S)
=
\operatorname{tr}[\Delta_S\Sigma\Delta_S^*].
\tag{9.3}
\]

Assume now the **global** centered feature covariance satisfies

\[
\boxed{\Sigma\succeq\mu I_r,\qquad \mu>0.}
\tag{9.4}
\]

## `P19-PRUNE-REFIT-OP-24` — NEW / PROVED

\[
\boxed{
\|C-\widetilde C_S\|_{\rm op}
\le
\|C-\widetilde C_S\|_F
\le
\sqrt{\frac{\mathcal R_{\rm refit}(S)}{\mu}}.
}
\tag{9.5}
\]

### Proof

From `(9.4)`,

\[
\mathcal R_{\rm refit}(S)
=
\operatorname{tr}[\Delta_S\Sigma\Delta_S^*]
\ge
\mu\operatorname{tr}[\Delta_S\Delta_S^*]
=
\mu\|\Delta_S\|_F^2.
\]

Then `||Δ||op≤||Δ||F`. QED.

This is a genuine prediction-risk-to-operator theorem, but the positive covariance floor is indispensable.
