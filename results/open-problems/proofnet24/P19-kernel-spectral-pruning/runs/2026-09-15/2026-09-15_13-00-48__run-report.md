# 4. Deterministic boundary transfer with only a columnwise proxy debt

Let

\[
C=(c_1,\ldots,c_r),
\qquad
D=(d_1,\ldots,d_r)
\in\mathbb R^{q\times r}.
\tag{4.1}
\]

Use the exact-cardinality score

\[
s_j(C)=\|c_j\|_2,
\qquad
s_j(D)=\|d_j\|_2.
\tag{4.2}
\]

Let `S_k(C)` be the deterministic top-`k` support with the inherited fixed tie rule. For a radius `rho >= 0`, define the boundary set

\[
\begin{aligned}
J_\rho(C)
={}&
\{j\in S_k(C):
s_j(C)\le s_{(k+1)}(C)+2\rho\}
\\
&\cup
\{j\notin S_k(C):
s_j(C)\ge s_{(k)}(C)-2\rho\}.
\end{aligned}
\tag{4.3}
\]

Define

\[
\Omega_C(\rho)=\|CP_{J_\rho(C)}\|_{\rm op}.
\tag{4.4}
\]

Put the **columnwise proxy debt**

\[
\boxed{
\varepsilon_\infty
=
\max_j\|c_j-d_j\|_2.
}
\tag{4.5}
\]

This can be much smaller or easier to certify than the global operator norm `||C-D||_op`.

## `P19-BOUNDARY-RESTRICTED-TRANSFER-21` — NEW / PROVED

For every `rho >= 0`,

\[
\boxed{
J_\rho(C)
\subseteq
J_{\rho+\varepsilon_\infty}(D).
}
\tag{4.6}
\]

Let

\[
t=\rho+\varepsilon_\infty,
\qquad
J=J_t(D).
\tag{4.7}
\]

Then

\[
\boxed{
\Omega_C(\rho)
\le
\Omega_D(t)
+
\|(C-D)P_J\|_{\rm op}.
}
\tag{4.8}
\]

Thus hard-pruning boundary transfer requires only:

- `epsilon_infty` for score localization;
- a boundary-restricted operator debt on `J`.

A global operator proxy theorem is not necessary.

## Proof of boundary localization

The reverse triangle inequality gives

\[
|s_j(C)-s_j(D)|
\le\varepsilon_\infty
\tag{4.9}
\]

for every `j`. Therefore every score order statistic is also `epsilon_infty`-Lipschitz:

\[
|s_{(\ell)}(C)-s_{(\ell)}(D)|
\le\varepsilon_\infty.
\tag{4.10}
\]

Take `j in J_rho(C)`.

If `j` is selected by both supports, `(4.9)`–`(4.10)` transfer the selected-side boundary inequality and give

\[
s_j(D)
\le
s_{(k+1)}(D)+2(\rho+\varepsilon_\infty).
\]

If `j` is selected by `C` but unselected by `D`, there exists a channel `h` that is unselected by `C` but selected by `D`. Since `s_j(C) >= s_h(C)`,

\[
s_j(D)
\ge
s_j(C)-\varepsilon_\infty
\ge
s_h(C)-\varepsilon_\infty
\ge
s_h(D)-2\varepsilon_\infty
\ge
s_{(k)}(D)-2\varepsilon_\infty.
\]

So `j` lies in the unselected-side boundary of `D` at width `rho+epsilon_infty`.

The two cases with `j` unselected by `C` are symmetric: if it remains unselected, use `(4.9)`–`(4.10)` directly; if it becomes selected, pair it with a dropped reference-selected channel. This proves `(4.6)`.

For `(4.8)`, because `J_rho(C) subset J`,

\[
\begin{aligned}
\Omega_C(\rho)
&=
\|CP_{J_\rho(C)}\|_{\rm op}
\\
&\le
\|DP_{J_\rho(C)}\|_{\rm op}
+
\|(C-D)P_{J_\rho(C)}\|_{\rm op}
\\
&\le
\|DP_J\|_{\rm op}
+
\|(C-D)P_J\|_{\rm op}.
\end{aligned}
\]

QED.

# 5. Prediction-space control of a restricted coefficient block

The new theorem above shifts the problem from a global parameter norm to a target-relevant boundary block. The next step is to extract that block from fresh-query prediction stability.

Let a fresh query/input `X` be independent of the fitted systems after conditioning on their training data. Let

\[
\psi(X)\in\mathbb R^r
\tag{5.1}
\]

be the honest proxy feature vector and

\[
\phi(X)\in\mathbb R^r
\tag{5.2}
\]

the aligned trained feature vector. In the ReLU quotient setting these are the post-permutation canonical feature coordinates.

Let

\[
g(X)=D\psi(X),
\qquad
f(X)=C\phi(X).
\tag{5.3}
\]

Define the proxy feature Gram matrix

\[
G
=
E[\psi(X)\psi(X)^*].
\tag{5.4}
\]

Assume for now that `G` is positive definite. Let `J subset [r]`, `K=J^c`, and define the feature Schur complement

\[
\boxed{
G_{J\mid K}
=
G_{JJ}-G_{JK}G_{KK}^{-1}G_{KJ}.
}
\tag{5.5}
\]

Put

\[
\boxed{
\mu_J
=
\lambda_{\min}(G_{J\mid K}).
}
\tag{5.6}
\]

When `K` is empty, take `G_{J|K}=G`.

Define the output-direction prediction covariance debt

\[
\boxed{
\delta_{\rm pred}
=
\left\|
E[(f(X)-g(X))(f(X)-g(X))^*]
\right\|_{\rm op}^{1/2}.
}
\tag{5.7}
\]

Define the feature-mismatch covariance debt

\[
\boxed{
\delta_\phi
=
\left\|
E[(\phi(X)-\psi(X))(\phi(X)-\psi(X))^*]
\right\|_{\rm op}^{1/2}.
}
\tag{5.8}
\]

## `P19-SCHUR-PREDICTION-OP-21` — NEW / PROVED

If

\[
\|C\|_{\rm op}\le M_C,
\tag{5.9}
\]

then for every nonempty `J`,

\[
\boxed{
\|(C-D)P_J\|_{\rm op}
\le
\frac{
\delta_{\rm pred}+M_C\delta_\phi
}{
\sqrt{\mu_J}
}.
}
\tag{5.10}
\]

This is dimension-free in the output dimension `q` and does not require a global coefficient Gram floor beyond the conditional identifiability of the requested feature block.

### Proof

Put

\[
\Delta=C-D,
\qquad
\zeta=\phi-\psi.
\]

Then

\[
\Delta\psi
=
(f-g)-C\zeta.
\tag{5.11}
\]

For any unit output direction `y`, let

\[
a=\Delta^*y=(a_J,a_K).
\]

The defining variational property of the Schur complement gives

\[
a^*Ga
\ge
a_J^*G_{J\mid K}a_J
\ge
\mu_J\|a_J\|^2.
\tag{5.12}
\]

Taking the supremum over unit `y`,

\[
\sqrt{\mu_J}\|\Delta P_J\|_{\rm op}
\le
\left\|
E[(\Delta\psi)(\Delta\psi)^*]
\right\|_{\rm op}^{1/2}.
\tag{5.13}
\]

For random vectors `A,B`, the quantity

\[
\|E[(A+B)(A+B)^*]\|_{\rm op}^{1/2}
=
\sup_{\|y\|=1}\|y^*(A+B)\|_{L^2}
\]

obeys the triangle inequality. Apply it to `(5.11)`:

\[
\left\|
E[(\Delta\psi)(\Delta\psi)^*]
\right\|_{\rm op}^{1/2}
\le
\delta_{\rm pred}
+
\left\|E[(C\zeta)(C\zeta)^*]\right\|_{\rm op}^{1/2}.
\]

The last term is at most

\[
\|C\|_{\rm op}\delta_\phi
\le M_C\delta_\phi.
\]

Combine with `(5.13)`.

QED.

# 9. Exact Gaussian-ReLU kernel Schur floor

The new Schur-complement theorem is useful only if its conditional feature variance can remain nondegenerate at finite/growing width. The orthogonal Gaussian-ReLU benchmark gives an exact answer.

Let

\[
X\sim N(0,I_d),
\tag{9.1}
\]

and let `u_1,...,u_r` be orthonormal unit directions, `r <= d`. Define

\[
\psi_j(X)=\operatorname{ReLU}(u_j^*X).
\tag{9.2}
\]

Then

\[
E\psi_j^2=\frac12,
\qquad
E\psi_i\psi_j=\frac1{2\pi}
\quad(i\ne j).
\tag{9.3}
\]

Hence

\[
\boxed{
G=aI_r+b\mathbf1\mathbf1^*,
\qquad
a=\frac{\pi-1}{2\pi},
\qquad
b=\frac1{2\pi}.
}
\tag{9.4}
\]

## `P19-GAUSS-RELU-SCHUR-FLOOR-21` — NEW / PROVED

For every nonempty subset `J subset [r]`,

\[
\boxed{
\lambda_{\min}(G_{J\mid J^c})
\ge
\frac{\pi-1}{2\pi}.
}
\tag{9.5}
\]

If `|J| >= 2`, equality holds exactly:

\[
\boxed{
\lambda_{\min}(G_{J\mid J^c})
=
\frac{\pi-1}{2\pi}.
}
\tag{9.6}
\]

For a singleton `J={j}`,

\[
\boxed{
\mu_j
=
\frac{(\pi-1)(\pi+r-1)}{2\pi(\pi+r-2)}
>
\frac{\pi-1}{2\pi}.
}
\tag{9.7}
\]

In particular the coordinate and boundary conditional-identifiability constants remain bounded away from zero uniformly in width.

### Proof

Let `m=|J|`, `s=r-m`. For `s>0`,

\[
G_{J^cJ^c}=aI_s+b\mathbf1_s\mathbf1_s^*.
\]

Sherman–Morrison gives

\[
\mathbf1_s^*G_{J^cJ^c}^{-1}\mathbf1_s
=
\frac{s}{a+bs}.
\tag{9.8}
\]

Therefore

\[
\begin{aligned}
G_{J\mid J^c}
&=
aI_m+b\mathbf1_m\mathbf1_m^*
-
b^2\frac{s}{a+bs}\mathbf1_m\mathbf1_m^*
\\
&=
\boxed{
aI_m+\frac{ab}{a+bs}\mathbf1_m\mathbf1_m^*.}
\tag{9.9}
\end{aligned}
\]

For `m>=2`, the vector subspace orthogonal to `1_m` has eigenvalue exactly `a`, proving `(9.6)`. For `m=1`, `(9.9)` gives

\[
\mu_j
=
a+\frac{ab}{a+b(r-1)}
=
\frac{a(a+br)}{a+b(r-1)},
\]

which simplifies to `(9.7)`.

If `s=0`, the Schur complement is just `G`; its minimum eigenvalue is `a` for `r>=2`, while for `r=1` the single eigenvalue is `1/2>a`.

QED.
