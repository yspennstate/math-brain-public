# 4. Leave-one-out setup

Let `S=(Z_1,…,Z_n)` with iid `Z_i=(X_i,Y_i)`. Any auxiliary training randomness is independent of `S` and is held common across replacement/deletion couplings.

For each `i`, let

```text
f_{−i} = A(S_{−i})
```

be the deletion retrain. For `j≠i`, replace retained observation `Z_j` by an iid copy and write

```text
f_{−i}^{(j)} = A(S_{−i}^{(j)}).
```

Squared loss and analytic clipping are

```text
ℓ(f;z) = ||y−f(x)||²,
ℓ_T(f;z) = min{ℓ(f;z),T}.
```

The deployed predictor is not clipped; clipping is only a proof device.

Define

```text
R_(i,T) = E_Z ℓ_T(f_{−i};Z),
Rhat_(loo,T) = n^−1 Σ_i ℓ_T(f_{−i};Z_i),
Rbar_(loo,T) = n^−1 Σ_i R_(i,T).
```

For `i≠j`, define the fresh clipped-loss replacement RMS

```text
β_(ij,T)²
= E [ ℓ_T(f_{−i};Z) − ℓ_T(f_{−i}^{(j)};Z) ]²,
```

where `Z` is an additional fresh iid test draw.

# 5. `P19-LOO-RMS-CLIPPED-32` — PROVED

Define

```text
H_T(S) = Rbar_(loo,T) − Rhat_(loo,T).
```

Then

```text
E H_T = 0,
```

and

```text
Var(H_T)
≤ [1/(2n²)] Σ_j [ T + Σ_{i≠j} β_(ij,T) ]².
```

Consequently, for every `η∈(0,1)`, with probability at least `1−η`,

```text
Rbar_(loo,T) ≤ Rhat_(loo,T) + ε(T,η),
```

where

```text
ε(T,η)
= [ Σ_j ( T + Σ_{i≠j} β_(ij,T) )² ]^(1/2)
  / [ n√(2η) ].
```

## Proof

Because `Z_i` is absent from `S_{−i}`, it is independent of deletion learner `f_{−i}`. Hence

```text
E ℓ_T(f_{−i};Z_i) = E R_(i,T)
```

for every `i`, proving `E H_T=0`.

Replace one sample coordinate `Z_j` by an iid copy `Z_j'` and call the resulting gap `H_T^(j)`.

### Contribution with `i=j`

The deletion learner `f_{−j}` is unchanged because the replaced coordinate is deleted. Only the evaluation point changes. Since `0≤ℓ_T≤T`, this contributes at most `T/n` in `L²`.

### Contributions with `i≠j`

Define

```text
d_ij(z) = ℓ_T(f_{−i};z) − ℓ_T(f_{−i}^{(j)};z).
```

The change of the `i`th centered LOO summand is exactly

```text
E_Z d_ij(Z) − d_ij(Z_i).
```

Crucially, `Z_i` is excluded from both learners. Conditional on `f_{−i},f_{−i}^{(j)}`, the point `Z_i` is therefore an honest iid test draw. Hence

```text
E[ (E_Z d_ij(Z) − d_ij(Z_i))² | f_{−i},f_{−i}^{(j)} ]
≤ E_Z d_ij(Z)².
```

After averaging,

```text
|| E_Z d_ij(Z) − d_ij(Z_i) ||_(L²) ≤ β_(ij,T).
```

Minkowski gives

```text
||H_T − H_T^(j)||_(L²)
≤ n^−1 [ T + Σ_{i≠j} β_(ij,T) ].
```

For completeness, the variance step is obtained by the same coordinate Doob-martingale argument used in the current P15 peer report: decompose `H_T−EH_T` into independent-coordinate martingale increments; each increment energy is at most one half of the squared `L²` change under an iid replacement of that coordinate. Thus

```text
Var(H_T) ≤ (1/2) Σ_j E(H_T−H_T^(j))².
```

Substitution proves the displayed variance bound. Chebyshev yields the probability statement.

QED.

### Scope

Only fresh **RMS** replacement control is assumed. There is no hypothesis of the form

```text
sup_z |ℓ(f_{−i};z) − ℓ(f_{−i}^{(j)};z)| ≪ 1.
```

The price of working at second-moment level is polynomial confidence `1/√η` rather than Bernstein-style `log(1/η)` dependence.

# 6. `P19-LOO-PRED-RMS-32` — PROVED

The scalar map `r ↦ min{r²,T}` is `2√T`-Lipschitz for `r≥0`, while the norm is 1-Lipschitz. Therefore

```text
|ℓ_T(f;(x,y)) − ℓ_T(g;(x,y))|
≤ 2√T ||f(x)−g(x)||.
```

Define fresh prediction replacement RMS

```text
B_ij² = E ||f_{−i}(X) − f_{−i}^{(j)}(X)||².
```

Then

```text
β_(ij,T) ≤ 2√T B_ij.
```

Hence

```text
ε(T,η)
≤ [ Σ_j ( T + 2√T Σ_{i≠j} B_ij )² ]^(1/2)
  / [ n√(2η) ].
```

If `B_ij≤B/n` for every `i≠j`, then

```text
ε(T,η) ≤ (T + 2B√T) / √(2ηn).
```

Thus an `O(1/n)` fresh predictor replacement scale yields vanishing one-run LOO generalization debt despite the absence of a pathwise loss-stability constant.

# 7. `P19-LOO-RMS-RAW-RISK-32` — PROVED

Let raw population risk of deletion learner `i` be

```text
R_i = E_Z ℓ(f_{−i};Z).
```

Assume an explicit conditional raw-loss tail envelope, almost surely in the deletion training sample:

```text
P{ ℓ(f_{−i};Z) > t | S_{−i} } ≤ A_i exp(−t/K_i),   t≥T.
```

No source value of `A_i` or `K_i` is guessed.

Tail integration gives

```text
R_i − R_(i,T)
= E(ℓ−T)_+
≤ A_i K_i exp(−T/K_i).
```

Define

```text
τ_T = n^−1 Σ_i A_i K_i exp(−T/K_i).
```

Because clipped empirical LOO loss is no larger than raw empirical LOO loss

```text
Rhat_loo_raw = n^−1 Σ_i ℓ(f_{−i};Z_i),
```

Section 5 gives, with probability at least `1−η`,

```text
Rbar_loo_raw := n^−1 Σ_i R_i
≤ Rhat_loo_raw + ε(T,η) + τ_T.
```

If `A_i≤A`, `K_i≤K`, `B_ij≤B/n`, and `T=K log n`, then at fixed confidence

```text
ε(T,η) = O( (log n + √log n)/√n ),
τ_T ≤ AK/n.
```

This is a raw-loss result. The deployed predictor remains un-clipped.

# 8. `P19-FULL-FROM-LOO-RMS-32` — PROVED

Define full-data versus deletion fresh prediction drift

```text
D_i = ||f_S − f_{−i}||_(L²(P_X)).
```

For every `i`, triangle inequality in the residual Hilbert space gives

```text
√R(f_S) ≤ √R_i + D_i.
```

Average over `i` and use concavity of square root:

```text
√R(f_S) ≤ √Rbar_loo_raw + Dbar,
Dbar = n^−1 Σ_i D_i.
```

Combining with Section 7 proves the main certificate

```text
√R(f_S)
≤ √( Rhat_loo_raw + ε(T,η) + τ_T ) + Dbar
```

with probability at least `1−η`.

The four debts are explicit and noninterchangeable:

1. observed raw LOO error;
2. RMS replacement concentration `ε(T,η)`;
3. raw-loss tail remainder `τ_T`;
4. full-vs-deletion drift `Dbar`.

# 9. `P19-FRESH-RMS-NOT-REUSE-CE-32` — PROVED counterexample

A direct full-sample shortcut is false even for bounded losses.

Let the input space be `X={1,…,M}`, with `X` uniform and deterministic target `Y=0`. Given training inputs `S=(X_1,…,X_n)`, define

```text
f_S(x) = 1{ x is not in {X_1,…,X_n} }.
```

Every training point is observed, so

```text
Rhat_train(f_S) = 0.
```

Conditional population risk is

```text
R(f_S) = 1 − |{X_1,…,X_n}|/M ≥ 1 − n/M.
```

For `M≫n`, population risk is arbitrarily close to one.

If one training input is replaced, the observed-set indicator changes on at most two atoms, so for a fresh uniform query

```text
E_X |f_S(X) − f_{S^(j)}(X)|² ≤ 2/M.
```

Thus the fresh full-sample replacement RMS is at most `√(2/M)`, tending to zero.

Therefore

```text
small fresh full-sample RMS replacement
+ zero reused training error
DOES NOT imply
small population risk.
```

The LOO construction correctly detects the memorizer. A held-out point is absent from its deletion learner unless another training point duplicates it, and

```text
E Rhat_loo = (1−1/M)^(n−1),
```

which is close to one for `M≫n`.

This exactly falsifies the direct fresh-RMS-to-reused-risk route and proves that the deletion/ghost mechanism is structurally necessary.

# 10. `P19-BOUNDARY-LOO-RAW-32` — hard-pruning specialization

Write deletion and deletion-replacement predictors as

```text
f_{−i}(x) = H_k(C_{−i}) φ_{−i}(x),
f_{−i}^{(j)}(x) = H_k(C_{−i}^{(j)}) φ_{−i}^{(j)}(x).
```

Let `ψ_ij` be a legally defined common fresh-query proxy for the pair, with Gram

```text
G_ij = E[ ψ_ij ψ_ij* ],
ρ_ij = ||C_{−i} − C_{−i}^{(j)}||_F.
```

Define representation debts

```text
ζ_ij  = || H_k(C_{−i})(φ_{−i}−ψ_ij) ||_(L²),
ζ'_ij = || H_k(C_{−i}^{(j)})(φ_{−i}^{(j)}−ψ_ij) ||_(L²).
```

The inherited covariance-boundary theorem gives, pathwise in the realized trained pair,

```text
||f_{−i} − f_{−i}^{(j)}||_(L²)
≤ ρ_ij √b_k(G_ij)
  + Ψ_(G_ij,k)(ρ_ij;C_{−i})
  + ζ_ij + ζ'_ij.
```

A deterministic RMS envelope for the right side supplies `B_ij` in Section 6. Equivalently, take the replacement-coupling `L²` norm of the right side. A single observed one-shot boundary value is **not** promoted to a deterministic stability constant.

The same boundary theorem controls `D_i` when applied to the full-data and deletion pair.

This is the key same-trained-matrix point: hard support may depend arbitrarily on the trained matrix; support discontinuity is paid by the actual score boundary/covariance profile, not by replacing the support with an iid mask.

# 11. `P19-MP-LOO-BOUNDARY-CERT-32` — PROVED by composition under the honest null

Suppose the common proxy Gram obeys the simultaneous restricted event

```text
(1−δ) I ≤ G_II ≤ (1+δ) I
for every support I with |I|≤2k,
```

with `0≤δ<1`. Then the inherited sparse-RIP boundary theorem gives

```text
||[H_k(C)−H_k(C')]ψ||_(L²)
≤ √(1+δ) [ ρ + B_(2k,ρ)(C) ],
```

and

```text
||H_k(C)−H_k(C')||_op
≤ √[(1+δ)/(1−δ)] [ ρ + B_(2k,ρ)(C) ].
```

Representation debts are added explicitly when feature maps differ.

For the already validated honest iid Gaussian feature null, simultaneous sparse-RIP follows from a chi-square/net argument whenever

```text
k log(er/k) = o(n).
```

Thus the raw-risk certificate can remain informative even when `r/n>1` and the **global** empirical feature Gram is singular with an MP zero atom.

The distinct spectral questions remain separated:

- **eigenvalue distribution:** global MP ESD/zero atom;
- **extreme/restricted eigenvalues:** local `2k` sparse-RIP edges needed for identifiability;
- **singular-vector overlap:** July `α_L, α_R`, still a compressed-resolvent residue theorem;
- **prediction risk:** the LOO/raw-loss theorem of this run;
- **finite width:** `ε(T,η)`, tail remainder, sparse-RIP failure probability, and deletion drift.

If a protected positive singular cluster has an observed gap `Δ_K`, Wedin/Hermitian dilation is used only when the operator debt plus representation/alignment debts is at most `Δ_K/2`. Only then do inherited projector/mixed-dyad stability bounds apply. No MP ESD or risk statement substitutes for the July overlap theorem.

# 12. Method comparison and dependence audit

## Resolvent methods

They remain the correct tool for the July spike outlier locations and singular-vector overlaps. The present risk theorem does not verify the source compressed-resolvent hypothesis or the missing non-Haar growing-frame local law.

## Davis–Kahan / Wedin

They remain second-stage gap theorems. This run first establishes a prediction/operator debt and requires restricted feature identifiability. Wedin is invoked only after a genuine gap, never to manufacture BBP overlap factors.

## Leave-one-out / ghost

Now provably essential. Section 9 shows that full-sample fresh RMS replacement does not control reused empirical risk. Deletion restores the independence needed for the variance calculation.

## Deterministic equivalents

A future trained-feature deterministic equivalent is useful only if it controls the **local** boundary covariance profile, replacement RMS, and restricted Gram edges, not merely ambient ESD or average test error.

## Free probability

No free-probability step is needed here. Response-trained features and deterministic trained-matrix pruning do not become asymptotically free automatically. Any future free-probability reduction must verify its hypotheses explicitly.

## Sparsification concentration

The valid Gaussian null is a simultaneous support-uniform sparse-RIP/concentration event. It is not an iid Bernoulli mask applied after training.

### Claim

P16 considers iid Gaussian rows with entries `W_ij ~ N(0,α/N)`, an arbitrary measurable random unit vector `U=U(W,ξ)` with auxiliary randomness independent of `W`, and

```text
g_W(U) = ||ReLU(WU)||.
```

For `X=(Z_+)²`, `Z~N(0,1)`, its scalar MGF is

```text
M_+(θ) = (1/2)[1 + (1−2θ)^(-1/2)],   0≤θ<1/2.
```

P16 claims

```text
I(W;U)
≥ N [ θ E g_W(U)² / α − log M_+(θ) ].
```

### Independent derivation

Let `P` be the actual joint law of `(W,U)` and `Q=P_W ⊗ P_U` the product of the same marginals. If `P` is not absolutely continuous with respect to `Q`, then `I(W;U)=∞` and the claim is trivial. Otherwise the entropy variational inequality gives

```text
D(P||Q) ≥ E_P F − log E_Q exp(F).
```

Choose

```text
F(W,U) = (Nθ/α) ||ReLU(WU)||².
```

Under `Q`, conditional on `U=u`, the vector `u` is independent of `W`. Therefore the row products are iid `N(0,α/N)` and

```text
||ReLU(Wu)||² = (α/N) Σ_i (Z_i^+)².
```

Direct half-Gaussian integration gives the stated `M_+(θ)`, hence

```text
E_Q exp(F) = M_+(θ)^N.
```

On the actual law,

```text
E_P F = (Nθ/α) E g_W(U)².
```

Since `D(P||Q)=I(W;U)`, substitution proves the claim exactly. Optimization over `θ` yields P16’s stated upper-tail rate bound.

The proof correctly charges adaptivity rather than assuming that `WU` is Gaussian under the actual selected law. P16 also correctly states that this alone does not solve its all-input/all-time theorem because an exact continuous selector may carry infinite mutual information.

**Audit verdict: PASS.** This is a component audit, not one of the two complete OTHER-worker end-to-end audits required for closure.

## 14.2 Stable scaling check

Under `B_ij≤B/n`, the theorem gives

```text
ε(T,η) ≤ (T+2B√T)/√(2ηn).
```

With an exponential loss tail and `T=K log n`, both the concentration debt and tail remainder vanish at fixed confidence. Thus the theorem has the expected finite-width scaling for an `O(1/n)` stable deletion pipeline.

## 14.3 Confidence limitation

Only second moments of replacement differences are assumed, so Chebyshev is the justified confidence step. A `log(1/η)` Bernstein/Freedman statement needs a stronger conditional influence-tail assumption and is not claimed here.
