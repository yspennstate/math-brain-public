# 6. Fresh-audit family covariance theorem

Let `T` denote the sigma-field generated by all training data, optimizer randomness, legal symmetry alignment, pruning scores/supports, and every model-selection choice made **before** the audit block is opened.

Conditional on `T`, let

\[
X_1,\ldots,X_m
\stackrel{\rm iid}{\sim}P_X
\]

be a fresh untouched query block.

Let

\[
\xi(X)\in\mathbb R^r
\]

be any `T`-measurable feature-valued map once its argument is supplied, and define the population and empirical second moments

\[
H
=
E[\xi(X)\xi(X)^*\mid T],
\]

\[
\widehat H
=
\frac1m\sum_{i=1}^m
\xi(X_i)\xi(X_i)^*.
\]

Let `Jcal` be a finite `T`-measurable family of coordinate sets with

\[
1\le |J|\le s
\qquad(J\in\mathcal J).
\]

Assume the explicit conditional sparse-subgaussian envelope

\[
\boxed{
\sup_{J\in\mathcal J}
\sup_{\substack{\operatorname{supp}(v)\subseteq J\\\|v\|_2=1}}
\|v^*\xi(X)\|_{\psi_2\mid T}
\le K.
}
\tag{6.1}
\]

No such envelope is asserted for the unavailable source; it is a theorem hypothesis that must be proved or bounded before application.

## `P19-FRESH-AUDIT-FAMILY-COV-28` — NEW / PROVED

There is a universal constant `C<infinity` such that for every `0<eta<1`, conditional on `T`, with probability at least `1-eta`,

\[
\boxed{
\sup_{J\in\mathcal J}
\|(\widehat H-H)_{JJ}\|_{\rm op}
\le
C K^2
\left[
\sqrt{\frac{u_{\mathcal J}}m}
+
\frac{u_{\mathcal J}}m
\right],
}
\tag{6.2}
\]

where

\[
\boxed{
u_{\mathcal J}
=
s\log9+\log\frac{2|\mathcal J|}{\eta}.
}
\tag{6.3}
\]

### Proof

Fix `J` and a unit vector `v` supported on `J`. Put

\[
Y_i=(v^*\xi(X_i))^2.
\]

By `(6.1)`, the standard Orlicz implication

\[
\|Z\|_{\psi_2}\le K
\quad\Longrightarrow\quad
\|Z^2-EZ^2\|_{\psi_1}\le C_1K^2
\]

holds with a universal constant. Conditional Bernstein therefore gives, for every `t>=1`,

\[
P\left\{
\left|
\frac1m\sum_iY_i-EY_i
\right|
>
C_2K^2
\left(
\sqrt{t/m}+t/m
\right)
\middle|T
\right\}
\le2e^{-t}.
\tag{6.4}
\]

For each `J`, take a `1/4`-net `N_J` of its unit sphere. It may be chosen with

\[
|N_J|\le9^{|J|}\le9^s.
\]

Union-bound `(6.4)` over every net point in every `J in Jcal` with

\[
t=s\log9+\log(2|\mathcal J|/\eta).
\]

The failure probability is at most `eta`.

For a symmetric matrix `A`, the standard `1/4`-net inequality is

\[
\|A\|_{\rm op}
\le2\max_{v\in N_J}|v^*Av|.
\]

Apply this to

\[
A=(\widehat H-H)_{JJ}
\]

and absorb the factor two into the universal constant. This proves `(6.2)`.

QED.

# 11. Marchenko–Pastur null versus sparse local identifiability

# 12. Same-matrix pruning dependence — exact conclusion

The current dependence picture is now sharper.

## Valid

A pruning support may be an arbitrary deterministic function of the trained matrix and training responses. If an untouched query block is revealed only **after** training/pruning is frozen, the conditional fresh-audit theorems apply.

It remains invalid to replace deterministic magnitude pruning of a trained matrix by an iid Bernoulli mask merely because the sparsity rate or coordinate marginals match.
