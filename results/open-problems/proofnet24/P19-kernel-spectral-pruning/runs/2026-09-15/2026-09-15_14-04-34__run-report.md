The following theorem is intentionally restricted to a concrete bias-free feedforward ReLU feature extractor. It is a deterministic reduction, not a claim that the July singular-vector manuscript used this neural architecture.

Let two already **legally aligned** depth-\(L\) ReLU feature maps be

\[
h_0(x)=\widetilde h_0(x)=x,
\tag{4.1}
\]

\[
h_\ell(x)
=
\sigma(W_\ell h_{\ell-1}(x)),
\qquad
\widetilde h_\ell(x)
=
\sigma(\widetilde W_\ell\widetilde h_{\ell-1}(x)),
\qquad
1\le\ell\le L,
\tag{4.2}
\]

where \(\sigma(t)=\max\{t,0\}\) acts coordinatewise.

"Legally aligned" means that any comparison has already fixed only genuine model symmetries, such as channel permutations and positive ReLU rescalings where appropriate. No arbitrary orthogonal hidden rotation is inserted.

Define

\[
a_\ell=\|W_\ell\|_{\rm op},
\qquad
\widetilde a_\ell=\|\widetilde W_\ell\|_{\rm op},
\qquad
e_\ell=\|W_\ell-\widetilde W_\ell\|_{\rm op}.
\tag{4.3}
\]

Define two pathwise perturbation budgets

\[
\mathfrak L_L^{\to}
=
\sum_{s=1}^L
e_s
\left(\prod_{j<s}a_j\right)
\left(\prod_{j>s}\widetilde a_j\right),
\tag{4.4}
\]

\[
\mathfrak L_L^{\leftarrow}
=
\sum_{s=1}^L
e_s
\left(\prod_{j<s}\widetilde a_j\right)
\left(\prod_{j>s}a_j\right),
\tag{4.5}
\]

and

\[
\boxed{
\mathfrak L_L
=
\min\{
\mathfrak L_L^{\to},
\mathfrak L_L^{\leftarrow}

\tag{4.6}
\]

Empty products are one.

## Proof

Coordinatewise ReLU is 1-Lipschitz in Euclidean norm. Therefore

\[
\begin{aligned}
\|h_\ell-\widetilde h_\ell\|
&\le
\|
W_\ell h_{\ell-1}
-
\widetilde W_\ell\widetilde h_{\ell-1}
\|
\\
&\le
e_\ell\|h_{\ell-1}\|
+
\widetilde a_\ell
\|h_{\ell-1}-\widetilde h_{\ell-1}\|.
\end{aligned}
\tag{5.5}
\]

Also

\[
\|h_{\ell-1}(x)\|
\le
\left(
\prod_{j<\ell}a_j
\right)\|x\|.
\tag{5.6}
\]

Starting from zero difference at layer zero and iterating `(5.5)` gives

\[
\|h_L-\widetilde h_L\|
\le
\mathfrak L_L^\to\|x\|.
\tag{5.7}
\]

Repeating the decomposition in the opposite direction,

\[
W_\ell h_{\ell-1}
-
\widetilde W_\ell\widetilde h_{\ell-1}
=
W_\ell(h_{\ell-1}-\widetilde h_{\ell-1})
+
(W_\ell-\widetilde W_\ell)\widetilde h_{\ell-1},
\]

gives

\[
\|h_L-\widetilde h_L\|
\le
\mathfrak L_L^\leftarrow\|x\|.
\tag{5.8}
\]

Take the minimum to obtain `(5.1)`. Square and average for `(5.3)`. Finally,

\[
\|E[ZZ^*]\|_{\rm op}
\le
\operatorname{tr}E[ZZ^*]
=
E\|Z\|^2

with \(Z=h_L-\widetilde h_L\), proving `(5.4)`.

# 7. Sharp one-layer Gaussian ReLU feature theorem

The generic Lipschitz theorem is distribution-free but can be loose. Under a Gaussian query, the one-layer ReLU map has a sharp \(1/2\) squared-L2 contraction relative to the incoming weight difference.

## `P19-GAUSS-RELU-FEATURE-SHARP-22` — NEW / PROVED

Let

\[
X\sim N(0,I_d)
\]

and let \(a,b\in\mathbb R^d\). Then

\[
\boxed{
E[
(\operatorname{ReLU}(a^*X)
-
\operatorname{ReLU}(b^*X))^2
]
\le
\frac12\|a-b\|_2^2.
}
\tag{7.1}
\]

The constant \(1/2\) is sharp: equality holds when \(a\) and \(b\) are positively collinear.

Consequently, for two aligned one-hidden-layer feature matrices \(U,\widetilde U\) with rows \(u_j^*,\widetilde u_j^*\),

\[
\phi_U(X)
=
(\operatorname{ReLU}(u_j^*X))_j,
\]

\[
\boxed{
E\|\phi_U(X)-\phi_{\widetilde U}(X)\|_2^2
\le
\frac12
\|U-\widetilde U\|_F^2,
}
\tag{7.2}
\]

and hence

\[
\boxed{
\delta_\phi
\le
\frac1{\sqrt2}
\|U-\widetilde U\|_F.
}
\tag{7.3}
\]

## Proof

If one vector is zero, `(7.1)` is immediate from \(E[\operatorname{ReLU}(Z)^2]=1/2\) for \(Z\sim N(0,1)\).

Otherwise put

\[
r=\|a\|,
\qquad
s=\|b\|,
\qquad
\theta=\arccos\frac{a^*b}{rs}\in[0,\pi].
\]

The exact Gaussian ReLU kernel is

\[
E[
\operatorname{ReLU}(a^*X)
\operatorname{ReLU}(b^*X)
]
=
\frac{rs}{2\pi}
[
\sin\theta
+
(\pi-\theta)\cos\theta
].
\tag{7.4}
\]

Therefore

\[
\begin{aligned}
&E[
(\operatorname{ReLU}(a^*X)
-
\operatorname{ReLU}(b^*X))^2
]
\\
&=
\frac{r^2+s^2}{2}
-
\frac{rs}{\pi}
[
\sin\theta
+
(\pi-\theta)\cos\theta
].
\end{aligned}
\tag{7.5}
\]

Meanwhile

\[
\frac12\|a-b\|^2
=
\frac{r^2+s^2}{2}
-rs\cos\theta.
\tag{7.6}
\]

Subtracting `(7.5)` from `(7.6)` gives

\[
\frac{rs}{\pi}
[
\sin\theta-\theta\cos\theta
].
\tag{7.7}
\]

The bracket is nonnegative because it vanishes at \(0\) and has derivative

\[
\theta\sin\theta\ge0
\]

on \([0,\pi]\). This proves `(7.1)`.

Summing `(7.1)` over rows proves `(7.2)`, and covariance operator norm is bounded by the trace, giving `(7.3)`.

QED.

# 8. Neural-feature Gram and kernel resolvent stability

Feature stability should not be conflated with prediction stability. It also has a separate kernel/operator consequence.

Let

\[
\phi=\phi(X)\in\mathbb R^r,
\qquad
\psi=\psi(X)\in\mathbb R^r,
\]

be aligned trained and proxy feature vectors on a fresh query. Define

\[
G_\phi=E[\phi\phi^*],
\qquad
G_\psi=E[\psi\psi^*],
\tag{8.1}
\]

\[
A_\phi
=
(E\|\phi-\psi\|^2)^{1/2},
\tag{8.2}
\]

\[
M_\phi=(E\|\phi\|^2)^{1/2},
\qquad
M_\psi=(E\|\psi\|^2)^{1/2}.
\tag{8.3}
\]

## `P19-FEATURE-GRAM-RESOLVENT-22` — NEW / PROVED

The feature Gram perturbation satisfies

\[
\boxed{
\varepsilon_G
:=
\|G_\phi-G_\psi\|_{\rm op}
\le
A_\phi(M_\phi+M_\psi).
}
\tag{8.4}
\]

For the depth-\(L\) ReLU system in Section 4,

\[
M_\phi
\le
M_X\prod_{\ell=1}^L a_\ell,
\qquad
M_\psi
\le
M_X\prod_{\ell=1}^L\widetilde a_\ell,
\tag{8.5}
\]

so

\[
\boxed{
\varepsilon_G
\le
\mathfrak L_LM_X^2
\left[
\prod_{\ell=1}^L a_\ell
+
\prod_{\ell=1}^L\widetilde a_\ell
\right].
}
\tag{8.6}
\]

Let

\[
m_\phi(z)
=
\frac1r
\operatorname{tr}(G_\phi-zI)^{-1},
\qquad
m_\psi(z)
=
\frac1r
\operatorname{tr}(G_\psi-zI)^{-1}.
\tag{8.7}
\]

For every \(z\in\mathbb C_+\),

\[
\boxed{
|m_\phi(z)-m_\psi(z)|
\le
\frac{\varepsilon_G}{(\operatorname{Im}z)^2}.
}
\tag{8.8}
\]

Every ordered eigenvalue satisfies

\[
\boxed{
|\lambda_j(G_\phi)-\lambda_j(G_\psi)|
\le
\varepsilon_G.
}
\tag{8.9}
\]

If a proxy eigenvalue cluster has gap \(g>0\) from its complement and

\[
\varepsilon_G<g/2,
\tag{8.10}
\]

then its corresponding trained eigenspace exists and the self-adjoint Davis--Kahan theorem gives the safe projector estimate

\[
\boxed{
\|\Pi_\phi-\Pi_\psi\|_{\rm op}
\le
\frac{\varepsilon_G}{g-\varepsilon_G}
\le
\frac{2\varepsilon_G}{g}.
}
\tag{8.11}
\]

Thus eigenvalue distribution, extreme feature-Gram eigenvalues, and feature-kernel eigenvectors have separate stability statements and separate gap requirements.

## Proof of `(8.4)`

Write \(\Delta=\phi-\psi\). Then

\[
G_\phi-G_\psi
=
E[\Delta\phi^*]
+
E[\psi\Delta^*].
\]

Since \(\|uv^*\|_{\rm op}=\|u\|\|v\|\),

\[
\begin{aligned}
\|G_\phi-G_\psi\|_{\rm op}
&\le
E[\|\Delta\|\|\phi\|]
+
E[\|\psi\|\|\Delta\|]
\\
&\le
A_\phi M_\phi
+
A_\phi M_\psi
\end{aligned}
\]

by Cauchy--Schwarz.

## Proof of the resolvent bound

The resolvent identity gives

\[
(G_\phi-zI)^{-1}
-
(G_\psi-zI)^{-1}
=
-(G_\phi-zI)^{-1}
(G_\phi-G_\psi)
(G_\psi-zI)^{-1}.
\]

For Hermitian \(G\),

\[
\|(G-zI)^{-1}\|_{\rm op}
\le
(\operatorname{Im}z)^{-1}.
\]

Also \(|r^{-1}\operatorname{tr}A|\le\|A\|_{\rm op}\). Therefore `(8.8)` follows.

Equation `(8.9)` is Weyl. Equation `(8.11)` is invoked only under the explicit spectral-gap condition `(8.10)`.

QED.
