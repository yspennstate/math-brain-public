## 7. Section-B method #2 — ATTACK THE NEGATION FIRST

I first tried to falsify P0037 on the smallest exact source-faithful finite systems rather than prove another sufficient condition.

The key reduction for an unweighted simple graph on `n<=4` vertices is that every spanning tree has rank `r=n-1<=3`. If `A square B` occurs on a spanning tree `T` and neither event is trivial, there are nonempty disjoint witnesses `W_A,W_B subseteq T`. Consequently

`|W_A| <= r-1` and `|W_B| <= r-1`,

because two nonempty disjoint subsets fit inside an `r`-edge tree.

## 8. Section-B method #16 — COMPUTE EVERY SMALL CASE AND STARE AT THE SEQUENCE

### 8.1 Exact reduction lemma

**Lemma.** Let `mu` be any probability law supported on `r`-element subsets of a finite ground set. Let `A,B` be increasing events. Define `A_<r` to be the increasing event generated by all minimal witnesses of `A` of size at most `r-1`, and similarly `B_<r`. Then on the support of `mu`,

`A square B = A_<r square B_<r`,

while

`mu(A_<r) <= mu(A)` and `mu(B_<r) <= mu(B)`.

**Proof.** Inclusion from right to left is immediate because `A_<r subseteq A` and `B_<r subseteq B`. Conversely, if an `r`-element support point `T` lies in `A square B`, there are disjoint witnesses `W_A,W_B subseteq T`. Delete redundant coordinates from each to obtain minimal witnesses. Both remain nonempty unless the corresponding event is the whole space. Since they are disjoint and their union lies in the `r`-set `T`, neither can have size `r`; hence each has size at most `r-1`, so `T in A_<r square B_<r`. Trivial whole-space events satisfy BK directly and may be separated. The marginal inequalities follow from event inclusion. QED.

For `n=4`, `r=3`, so every reduced nontrivial event is determined by an antichain of singleton and pair witnesses. After choosing its singleton witnesses, any pair containing one of those singleton edges is redundant; every remaining pair may independently be chosen as a minimal witness. This gives a finite exact event enumeration.

## 9. Section-B method #25 — COUNT THE SAME THING TWICE

I translated spanning trees of a connected unicyclic graph into the identity of the unique omitted cycle edge. This gives a short direct proof of the source inequality for that class.

Let the unique cycle have edges `e`. Every spanning tree is `T_e=E\{e}` for exactly one cycle edge, and under positive weights

`P(T=T_e) proportional to 1/w_e`.

For an increasing event `A`, define its set of bad omitted edges

`D_A := {e : T_e notin A}`.

If `W subseteq T_i` is a witness that forces `A` and `e in D_A`, then necessarily `e in W`: otherwise `W subseteq T_e`, which would force `T_e in A`, contradicting `e in D_A`.

Suppose `T_i in A square B`, with disjoint witnesses `W_A,W_B`. The preceding observation forces

`D_A subseteq W_A`, `D_B subseteq W_B`.

Therefore `D_A cap D_B` is empty. Also `i` is in neither bad set because `T_i` lies in both events. Hence, writing `p(D)` for the omitted-edge probability of a set `D`,

`P(A square B) <= 1 - p(D_A) - p(D_B)`.

If the bad sets overlap, no disjoint witnesses can exist and the square probability is zero. If they are disjoint, then

`1-p(D_A)-p(D_B) <= (1-p(D_A))(1-p(D_B)) = P(A)P(B)`.

Thus weighted unicyclic graphs obey the conjectured BK inequality.

This argument is useful route information but **not claimed as new mathematics**. Van den Berg–Jonasson's fixed-size BK theorem, including weighted/product extensions, already subsumes this co-singleton model; the Codex fixed-conjunction argument also covers part of the same mechanism. The genuinely new target must therefore exploit graphic-matroid basis constraints beyond fixed-size/product reductions.

Outcome of B25: **successful structural proof, but classified as KNOWN/rediscovered special case rather than metric movement or source closure.**
