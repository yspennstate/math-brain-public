## 3. Starting point: what the recovery asked this run to test

The preceding stuck report identified the exact missing mechanism: fixed-witness negative association is easy, but adaptive disjoint witnesses create overlapping unions. Mészáros avoids the analogous problem for matchings by partitioning **ordered pairs** into cells. Inside each matching cell, the union decomposes into independent alternating paths/cycles; path choices give a Boolean cube, and Reimer applies cellwise.

For USTs, the recovery asked this run to test whether ordered pairs of spanning trees admit a comparable cell decomposition, starting with the simplest unresolved source-faithful case: uniform UST on \(K_5\) with arbitrary increasing events.

The answer is now precise:

## 4. Method #1 — CHANGE THE CATEGORY: tree-pair fibres are base-cobase reconfiguration systems

Let \(G=(V,E)\) be a finite connected graph and let \(T_1,T_2\) be spanning trees. Define
\[
I:=T_1\cap T_2,\qquad U:=T_1\cup T_2.
\]
Fix \(I,U\), and consider the ordered-pair fibre
\[
\mathcal C_{I,U}
:=\{(S_1,S_2):S_1,S_2\text{ spanning trees},\
S_1\cap S_2=I,\ S_1\cup S_2=U\}.
\]

Contract every edge of the common forest \(I\), and restrict to the remaining edge set \(U\setminus I\). Call the resulting graphic matroid \(M_{I,U}\). If
\[
X=S_1\setminus I,\qquad Y=S_2\setminus I,
\]
then \(X\cap Y=\varnothing\), \(X\cup Y=U\setminus I\), and both \(X,Y\) are bases of \(M_{I,U}\). Conversely, every decomposition of \(U\setminus I\) into two bases lifts uniquely to an ordered pair in \(\mathcal C_{I,U}\).

Thus a natural UST pair cell is **not** fundamentally a matching cell. It is a **base-cobase system**:
\[
\mathcal C_{I,U}
\longleftrightarrow
\{X\subseteq U\setminus I:X\text{ and }(U\setminus I)\setminus X
\text{ are both bases}\}.
\]

This category change makes the 2026 basis-pair reconfiguration literature directly relevant. Symmetric basis exchanges preserve the multiset union and hence stay inside exactly these fibres. For graphic matroids those compatible basis pairs are connected by symmetric exchanges. But connected exchange geometry is much weaker than the product-of-independent-bits structure in the matching proof. Nothing in the reconfiguration theorem supplies the Boolean complement cell on which Reimer acts.

**Outcome of method #1:** useful structural reduction, but no BK proof. It identifies the correct finite object: base-cobase cells of graphic matroids.

## 5. Method #12 — FIND WHAT IS CONSERVED: pair weight is exactly constant on each fibre

The preceding category change has an exact weighted invariant. If edge \(e\) has positive weight \(w_e\), then for every \((S_1,S_2)\in\mathcal C_{I,U}\),
\[
w(S_1)w(S_2)
=
\prod_{e\in I}w_e^2
\prod_{e\in U\setminus I}w_e.
\]
Indeed, every common edge occurs twice in the ordered pair, every edge of the symmetric difference occurs once, and every other edge occurs zero times.

So these fibres are not an arbitrary combinatorial partition: they are the **finest obvious pair cells on which arbitrary UST pair weights are constant**.

For a cellwise Mészáros port, the desired finite inequality would be
\[
\bigl|((A\square B)\times\Omega)\cap\mathcal C_{I,U}\bigr|
\le
\bigl|(A\times B)\cap\mathcal C_{I,U}\bigr|, \tag{5.1}
\]
where \(\Omega\) is the spanning-tree support. If (5.1) held for every fibre, summing with the constant pair weight above would prove the weighted source inequality immediately.

That exact conservation law is why (5.1) is the right direct analogue to test before investing in any larger proof.

**Outcome of method #12:** the natural fibres perfectly respect arbitrary edge weights, but that alone is not enough. Method #19 shows (5.1) is false.
