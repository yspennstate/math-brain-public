## 4. Positive witnesses for increasing events

Let `mu` be a probability measure on subsets of a finite ground set `E`. For an increasing event `A`, call `F subset E` a positive witness if every configuration containing `F` lies in `A`; equivalently the principal cylinder

`C_F := {omega: F subset omega}`

is contained in `A`. Let `W(A)` be the family of inclusion-minimal positive witnesses.

For increasing events, positive witnesses suffice in the source definition of disjoint occurrence. Indeed, if a witness fixes some coordinates absent and some present in a configuration `omega`, delete the absent requirements: any configuration containing the present part can first be lowered on the deleted coordinates to one agreeing with the original witness and then raised back; monotonicity keeps the event true. Thus a disjoint-occurrence witness can always be shrunk to disjoint positive witnesses, and then further to inclusion-minimal positive witnesses.

For `F in W(A)`, define

`B_perp(F) := union_{G in W(B), G cap F = emptyset} C_G`.

This is increasing and depends only on coordinates in `E\F`.

## 5. Method #15 — BREAK THE SYMMETRY ON PURPOSE: witness congestion replaces orbit symmetry

The key move is to stop averaging events under graph automorphisms and instead ask how many distinct minimal witnesses can be carried by one sampled configuration. Define

`N_A(omega) := #{F in W(A): F subset omega}`

and the support-relative witness congestion

`kappa_mu(A) := max_{omega in supp(mu)} N_A(omega)`.

This quantity is deliberately asymmetric: it depends on the actual witness family and the measure's support, not on an `S_n` orbit type.

### Theorem NM13-02-P0037-WC (witness-congestion BK bound)

Let `mu` be any negatively associated probability measure on `2^E`. For increasing events `A,B`,

`mu(A square B) <= min(kappa_mu(A), kappa_mu(B)) mu(A) mu(B)`.

In particular, if either event has `kappa_mu=1`, then the full BK inequality holds for that pair.

### Proof

Every `omega in A square B` has disjoint positive witnesses for `A` and `B`; shrink the `A` witness to some `F in W(A)`. Therefore

`A square B = union_{F in W(A)} (C_F cap B_perp(F))`.

(The reverse inclusion is immediate: `F` itself witnesses `A`, while the definition of `B_perp(F)` supplies a disjoint positive witness for `B`.)

`C_F` is increasing and depends only on coordinates of `F`. `B_perp(F)` is increasing and depends only on the complementary coordinates. Negative association therefore gives

`mu(C_F cap B_perp(F)) <= mu(C_F) mu(B_perp(F)) <= mu(C_F) mu(B)`.

Taking a union bound over `F` yields

`mu(A square B) <= mu(B) sum_{F in W(A)} mu(C_F)`.

The sum is exactly the expected number of minimal `A` witnesses present:

`sum_F mu(C_F) = E_mu N_A`.

If `omega notin A`, then `N_A(omega)=0`; if `omega in A`, then `N_A(omega)<=kappa_mu(A)`. Hence

`E_mu N_A <= kappa_mu(A) mu(A)`,

which proves

`mu(A square B) <= kappa_mu(A) mu(A)mu(B)`.

Interchanging `A,B` gives the minimum of the two congestion parameters. QED.

### UST consequence: an exact source-faithful subclass in every graph order

Weighted UST measures are negatively associated. Therefore Conjecture 4.10 is **proved for every pair `(A,B)` for which either event has support-relative minimal-witness congestion one**.

For a spanning-tree law this has a simple graph interpretation. If the minimal positive witness forests of `A` are pairwise incompatible in the sense that no spanning tree contains two of them, then `kappa_mu(A)=1`, and BK holds against **every** increasing event `B`, for arbitrary positive edge weights and arbitrary finite connected graph. Principal events `A={F subset T}` are the one-witness special case, but the theorem also allows arbitrary families of mutually support-incompatible witness forests.

This is a complete restricted-class theorem in the exact source model, not a closure of Conjecture 4.10.

## 6. Method #24 — FIND THE EXTREMAL OBJECT: Sperner controls worst witness congestion

Now assume `mu` is homogeneous of fixed rank `r`: every configuration in its support has exactly `r` present coordinates. This includes every spanning-tree measure, with `r=|V|-1`.

Fix any support configuration `omega`. The family

`{F in W(A): F subset omega}`

is an antichain in the Boolean lattice `2^omega`: two distinct minimal witnesses cannot contain one another. Sperner's theorem therefore gives

`N_A(omega) <= binom(r, floor(r/2))`.

Thus the witness-congestion theorem immediately implies the finite-rank quantitative BK bound

`mu(A square B) <= binom(r, floor(r/2)) mu(A)mu(B)`

for **every** pair of increasing events under any negatively associated rank-`r` law.

For a weighted spanning tree on an `n`-vertex connected graph, `r=n-1`, so

`P(A square B) <= binom(n-1, floor((n-1)/2)) P(A)P(B)`.

In particular, on every positively weighted connected five-vertex graph,

`P(A square B) <= 6 P(A)P(B)`.

The number `6` here is not claimed to be the true five-vertex BK constant. It is only the sharp worst-case **witness-congestion** bound supplied by this method. The congestion extremum is genuinely attainable at the combinatorial level: on a fixed four-edge tree, the six two-edge subsets form a Sperner antichain, and the increasing event generated by those six principal cylinders has six minimal witnesses present on that tree. Therefore witness counting alone cannot improve the rank-four factor below `6`; any proof of full `K5` BK must exploit cancellation/geometry beyond mere minimal-witness multiplicity.

**Outcome of #24:** the extremal object is an antichain of minimal witnesses inside one sampled basis. This gives an explicit finite-order source bound and, more importantly, identifies exactly what a stronger proof must beat.
