## 2. General k-volume fractional compiler

Consider two disjoint ORIGINAL-coordinate banks `I,J`; all remaining original coordinates may be conditioned on. Let

`R = F(X_I) + 2 X_I^T M X_J + G(X_J)`,

where `M` is an arbitrary real `|I| x |J|` matrix and `F,G` are arbitrary real measurable functions finite almost surely. Thus arbitrary within-bank quadratic terms, arbitrary affine terms generated by outside conditioning, and arbitrary signs are retained.

Fix an integer `k>=1` with `rank(M)>=k`, and write

`Z_k = e_k(M^T M)
     = sum_{|S|=|T|=k} det(M[S,T])^2 > 0`.

Give pairs `(S,T)` of row and column `k`-sets probability

`w_ST = det(M[S,T])^2/Z_k`.

Let

`alpha_i = P_w(i in S)`, `beta_j = P_w(j in T)`.

Then

`0<=alpha_i,beta_j<=1`, `sum_i alpha_i=sum_j beta_j=k`.

### Theorem 2.1 (fractional volume compiler)

Let `q>=1` and suppose

`alpha_i <= q/2` for every row `i`.

Then the characteristic function of `R` obeys

`|phi_R(t)| <= min(1, B_{k,q} |t|^{-k/(2q)})`,                 (2.1)

where

`B_{k,q} = [e^k q^{-k/2} pi^k Z_k^{-1/2}]^{1/(2q)}`.          (2.2)

Consequently, for every

`0<gamma<min(1,k/(2q))`,

`H_gamma(R):=sup_s E|R-s|^{-gamma}`

satisfies

`H_gamma(R)
 <= C_{k,gamma,q} Z_k^{-gamma/(2k)}`,                          (2.3)

with

`C_{k,gamma,q}
 = [2k c_gamma e^gamma pi^gamma q^{-gamma/2}]
   /[gamma (k-2q gamma)]`,                                    (2.4)

and

`c_gamma = 2^(1-gamma) Gamma((1-gamma)/2)
           /[2 sqrt(pi) Gamma(gamma/2)]`.                      (2.5)

This theorem is a fractional-potential extension of the current three-volume density calculation. In particular, it remains useful when `k/(2q)<=1`, where absolute Fourier inversion no longer gives a density bound directly.

### Proof of Theorem 2.1

Let `X_J'` be an independent copy of `X_J` and put `D=X_J-X_J'`. Each coordinate `D_j` has probability density

`g_j=f_j*tilde f_j`,

with `||g_j||_1=1` and `||g_j||_infinity<=1`. The standard decoupling step from the cited volume theorem gives

`|phi_R(t)|^2
 <= E_D prod_{i in I} |psi_i(2t(MD)_i)|`.                    (2.6)

Write the product on the right as `F_t(D)`. For `q>=1`,

`E F_t <= (E F_t^q)^(1/q)`.                                   (2.7)

Use the Brascamp-Lieb datum consisting of the row maps `d -> (Md)_i` with exponents `alpha_i` and coordinate maps `d -> d_j` with exponents `1-beta_j`. Its scaling is exact because

`sum_i alpha_i + sum_j(1-beta_j) = |J|`.                       (2.8)

For positive Gaussian row parameters `d_i` and active coordinate parameters `e_j`, the diagonal-plus-PSD determinant expansion and Cauchy-Binet give

`det(D_J+M^T D_I M)
 >= sum_{|S|=|T|=k} det(M[S,T])^2
       prod_{i in S} d_i prod_{j notin T} e_j
 >= Z_k prod_i d_i^{alpha_i} prod_j e_j^{1-beta_j}`.           (2.9)

The final step is weighted AM-GM with weights `w_ST`. It remains valid at `beta_j=1` by the same endpoint argument as the cited three-volume proof. Lieb's Gaussian characterization therefore yields BL constant at most

`Z_k^{-1/2}
 prod_i alpha_i^{-alpha_i/2}
 prod_j (1-beta_j)^{-(1-beta_j)/2}`.                            (2.10)

For a row `i` with `alpha_i>0`, apply sharp Hausdorff-Young to

`|psi_i(2t u)|^q`

at output exponent `q/alpha_i>=2`. Exactly as in the current three-volume proof,

`|| |psi_i(2t .)|^q ||_{1/alpha_i}
 <= (pi/|t|)^{alpha_i}
    (alpha_i/q)^{alpha_i/2}
    (1-alpha_i/q)^{-(q-alpha_i)/2}`.                           (2.11)

Coordinates with `alpha_i=0` are dropped using `|psi_i|<=1`. The `alpha_i` factors in (2.11) cancel those in (2.10), while

`prod_i (1-alpha_i/q)^{-(q-alpha_i)/2} <= e^{k/2}`,            (2.12)

because `-(1-x)log(1-x)<=x`, and similarly

`prod_j (1-beta_j)^{-(1-beta_j)/2} <= e^{k/2}`.                (2.13)

Since `sum alpha_i=k`, (2.6)-(2.13) give

`E F_t^q
 <= e^k q^{-k/2} (pi/|t|)^k Z_k^{-1/2}`.                    (2.14)

Taking the `1/(2q)` power proves (2.1)-(2.2).

Now use the proved distributional fractional-Riesz inequality

`H_gamma(R)
 <= c_gamma int_R |t|^{gamma-1}|phi_R(t)| dt`.                 (2.15)

If `b=k/(2q)>gamma` and `B=B_{k,q}`, direct integration gives

`int |t|^{gamma-1} min(1,B|t|^{-b}) dt
 = [2b/(gamma(b-gamma))] B^{gamma/b}`.                         (2.16)

Furthermore

`B^{gamma/b}
 = e^gamma q^{-gamma/2} pi^gamma Z_k^{-gamma/(2k)}`.           (2.17)

Substitution of (2.16)-(2.17) into (2.15) is exactly (2.3)-(2.4). QED.
