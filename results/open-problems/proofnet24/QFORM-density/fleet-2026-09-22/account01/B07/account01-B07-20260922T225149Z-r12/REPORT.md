## 2. Determinant laws

For a real `m x n` matrix `B`, write

`E_k(B)=sum_{|I|=|J|=k} det(B[I,J])^2=e_k(BB^T)`

and

`D_B(z)=det(I+zBB^T)=sum_{k>=0} z^k E_k(B)`.

The bipartite determinantal minor law is

`mu_z(I,J)= z^k det(B[I,J])^2 / D_B(z)`,  `|I|=|J|=k`.

Let `N=|I|=|J|`. Its row and column one-point kernels are

`K_L=zBB^T(I+zBB^T)^(-1)`,
`K_R=zB^TB(I+zB^TB)^(-1)`,

so

`E_z N=tr K_L=tr K_R`.

Conditioned on `N=k`, the factor `z^k` cancels. Denote the resulting fixed-order law by

`nu_k(I,J)=det(B[I,J])^2/E_k(B)`.

By Cauchy--Binet, the row marginal is the size-`k` L-ensemble for `L=BB^T`:

`nu_k(I)=det((BB^T)[I,I])/E_k(B)`,

and similarly the column marginal is the size-`k` L-ensemble for `B^TB`.

## 3. Lemma: physical inclusion probabilities increase with the fixed order

### Lemma 3.1 — `QFORM-FIXED-K-DPP-INCLUSION-MONOTONICITY-v1`

Assume `rank B>=3`. For a fixed physical row `i`, let

`ell_i^(k)=P_{nu_k}(i in I)`.

Then `ell_i^(k)` is nondecreasing in `k` on every order for which `E_k(B)>0`. The analogous statement holds for every physical column.

### Proof

Diagonalize

`BB^T=U diag(x_1,...,x_r) U^T`,  `x_s>0`.

The size-`k` L-ensemble can be generated by first choosing a spectral subset `S`, `|S|=k`, with weight proportional to `prod_{s in S}x_s`, and then sampling from the projection DPP onto the columns `U_S`. Hence

`ell_i^(k)=sum_s U_{is}^2 pi_s^(k)`,

where the spectral inclusion probability is

`pi_s^(k)
 = x_s e_{k-1}(x_without_s) /
   [e_k(x_without_s)+x_s e_{k-1}(x_without_s)]`.

Thus `pi_s^(k)` increases with `k` exactly when

`e_k(x_without_s)/e_{k-1}(x_without_s)`

decreases with `k`. This is a direct consequence of Newton's inequalities: the normalized elementary symmetric sequence `e_k/C(r-1,k)` is log-concave, so its consecutive quotient decreases, and the additional combinatorial quotient `C(r-1,k)/C(r-1,k-1)=(r-k)/k` also decreases. Therefore every `pi_s^(k)`, and hence every nonnegative weighted sum `ell_i^(k)`, is nondecreasing. The column proof is identical using `B^TB`. QED.

## 4. Main theorem: ridge leverage localizes the order-three determinant bank

### Theorem 4.1 — `QFORM-RIDGE-TO-FIXED3-ANCHOR-LOCALIZATION-v1`

Assume `E_3(B)>0`. Choose `z>0` such that

`E_z N=2`.

Let physical row `i` and physical column `j` satisfy

`(K_L)_ii > h`,   `(K_R)_jj > h`

for some `h>3/4`. Define the jointly anchored third-order bank

`M_3(i,j)
 = sum_{|I|=|J|=3, i in I, j in J} det(B[I,J])^2`.

Then

`M_3(i,j)/E_3(B) > 4h-3`.

In particular, at the current threshold `h=23/24`,

`M_3(i,j) > (5/6) E_3(B)`.

### Proof

Let `w_k=P_z(N=k)` and put

`tau=P_z(N>=4)`.

Since `E_z N=2`, Markov gives `tau<=1/2`.

For the row anchor, write `p_i=(K_L)_ii=sum_k w_k ell_i^(k)`. By Lemma 3.1,

`ell_i^(k)<=ell_i^(3)` for `k<=3`,

while trivially `ell_i^(k)<=1` for `k>=4`. Hence

`p_i <= (1-tau) ell_i^(3)+tau`.

Therefore

`ell_i^(3) >= (p_i-tau)/(1-tau)`.

If `p_i=1`, the desired bound is immediate. Otherwise the right side decreases with `tau`, and `tau<=1/2`, so

`ell_i^(3) >= 2p_i-1 > 2h-1`.

The identical argument gives the fixed-order-three column inclusion

`r_j^(3)>2h-1`.

Under the *joint* fixed-order law `nu_3`, the union bound now gives

`P_{nu_3}(i in I, j in J)
 >= ell_i^(3)+r_j^(3)-1
 >4h-3`.

By definition the left side is exactly `M_3(i,j)/E_3(B)`. QED.

No coordinate rotation, density assumption, moment assumption, or selected reciprocal minor enters this argument. It is a finite-dimensional determinant identity plus a monotonicity property of fixed-size determinant laws.
