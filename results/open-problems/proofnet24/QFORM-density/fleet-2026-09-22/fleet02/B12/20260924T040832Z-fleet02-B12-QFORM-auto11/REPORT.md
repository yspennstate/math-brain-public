## Theorem: QFORM-FLOOR-ENHANCED-TRANSVERSE-REPAIR-v1

Let `F,W : R^m -> H` be represented in orthogonal output components, equivalently let the carrier map `M` satisfy

`||Mx||^2 = ||Fx||^2 + ||Wx||^2`.

Let `K` be the right-singular subspace of `F` generated by its `q` smallest singular directions, with `1<=q<m`. Define

`d = inf_{y in K, ||y||=1} ||Fy||`,

`a = inf_{z in K^perp, ||z||=1} ||Fz||`,

`b = inf_{y in K, ||y||=1} ||Wy||`,

`c = ||W P_{K^perp}||op`.

Because `K` contains the lowest singular directions, `a>=d`. Assume `a,b>0`. Put

`H2 = [[d^2+b^2, -bc],[-bc, a^2+c^2]]`,

and let

`rhohat^2 = lambda_min(H2)`.

Explicitly, with

`U = a^2+b^2+c^2+d^2`,

`V = a^2(d^2+b^2)+c^2 d^2`,

we have

`rhohat^2 = (U-sqrt(U^2-4V))/2`.

Then

`boxed: s_m(M) >= rhohat.`

If a later coefficient perturbation `E` obeys `||E||op<=delta`, then

`boxed: s_m(M+E) >= [rhohat-delta]_+.`

### Proof

Take `x=y+z` with `y in K`, `z in K^perp`, and write `Y=||y||`, `Z=||z||`. Since `K` is a right-singular subspace of `F`, `Fy` is orthogonal to `Fz`. Hence

`||F(y+z)||^2 >= d^2 Y^2 + a^2 Z^2`.

Also

`||W(y+z)|| >= max(bY-cZ,0)`.

If `bY>=cZ`, then

`||Mx||^2 >= d^2Y^2+a^2Z^2+(bY-cZ)^2 = [Y,Z] H2 [Y,Z]^T >= rhohat^2(Y^2+Z^2)`.

If `bY<cZ`, discard the `W` contribution. For `r=Y/Z`,

`R(r)=(d^2 r^2+a^2)/(r^2+1)`

decreases in `r` because `a>=d`. Thus for `r<c/b`,

`R(r) >= R(c/b) = (d^2 c^2+a^2 b^2)/(b^2+c^2)`.

The last quantity is exactly the Rayleigh quotient of `H2` at the boundary vector `(c/b,1)`, so it is at least `lambda_min(H2)=rhohat^2`. This proves the first claim. The dense-tail statement is singular-value Weyl.

Two consequences isolate the gain over r48. First,

`H2 = H2(d=0) + d^2 e1 e1^T`,

so `rhohat` is at least the partner r48 repair bound and reduces to it exactly at `d=0`. Second,

`H2-d^2 I = [[b^2,-bc],[-bc,a^2+c^2-d^2]]`.

Its determinant is `b^2(a^2-d^2)>=0` and both diagonal entries are nonnegative. Therefore

`boxed: rhohat >= d.`

Hence arbitrarily large transverse leakage `c` cannot push the repaired carrier below a positive low-singular floor. This is the feature lost when the floor is discarded.
