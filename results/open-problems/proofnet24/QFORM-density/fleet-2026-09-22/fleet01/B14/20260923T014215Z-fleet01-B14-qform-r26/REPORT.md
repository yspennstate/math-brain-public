## 2. A localization compiler for fractional concentration

For a real random variable `R`, write

`Q_R(rho)=sup_t P(|R-t|<rho)`.

### Theorem 2.1 — `QFORM-PAIRLOG-FRACTIONAL-CONCENTRATION-v1`

Fix `0<alpha<=1`. Suppose

`Q_R(rho) <= min(1,K rho^alpha)`                                  (2.1)

for every `rho>0`. Then for every `A>0` and every `t`,

`E log_+(A/|t-R|)
 <= alpha^(-1) Psi(K A^alpha).`                                  (2.2)

Consequently the physical-pair envelope (1.1) gives

`p_Q(t)
 <= 2sqrt(2)/r
    + [alpha sqrt(D)]^(-1)
      Psi( K (2r^2/kappa)^alpha )`                               (2.3)

for every `r>0`.

#### Proof

Layer cake gives

`E log_+(A/|t-R|)
 = integral_0^infinity P(|t-R|<A e^(-v)) dv`.

By (2.1), with `u=K A^alpha`, this is at most

`integral_0^infinity min(1,u e^(-alpha v)) dv`.

If `u<=1`, the value is `u/alpha`. If `u>=1`, split at `v=alpha^(-1)log u`; the value is `alpha^(-1)(1+log u)`. This is exactly (2.2). Substituting `A=2r^2/kappa` into (1.1) proves (2.3). QED.

## 3. The half-Hölder compiler and its optimized constant

### Corollary 3.1 — `QFORM-PAIRLOG-HALF-HOLDER-v1`

Assume

`Q_R(rho) <= min(1,K sqrt(rho)).`                                (3.1)

Put

`rho_0 = 2K sqrt(D/kappa).`                                     (3.2)

Then

`||p_Q||_infinity
 <= 4sqrt(2) K^(1/2) (D kappa)^(-1/4),      rho_0<=1,`           (3.3)

and

`||p_Q||_infinity
 <= 2D^(-1/2)[2+log rho_0],                 rho_0>=1.`           (3.4)

#### Proof

Theorem 2.1 with `alpha=1/2` gives

`p_Q(t) <= 2sqrt(2)/r
 +2D^(-1/2) Psi(K sqrt(2/kappa) r).`                             (3.5)

Set `q=K sqrt(2/kappa)`. In the branch `qr<=1`, minimize

`2sqrt(2)/r + 2D^(-1/2)q r`.

The stationary point is

`r_*=(D kappa)^(1/4)/sqrt(K)`,

and `q r_*<=1` is exactly `rho_0<=1`. The minimum is (3.3).

In the branch `qr>=1`, minimize

`2sqrt(2)/r +2D^(-1/2)[1+log(qr)].`

The stationary point is `r=sqrt(2D)`, for which `qr=rho_0`; evaluating gives (3.4). QED.

The importance of (3.3)-(3.4) is that a moving critical value need not have a bounded density. Square-root small-ball control already integrates the physical-pair logarithm.

## 4. Arbitrary higher-rank Schur remainder: a single nonzero physical square is enough

`Q_R(rho) <= min(1, 2sqrt(2) H sqrt(rho/|a|)).`                 (4.2)

`Phi(u)=2+log u`, `u>=1`.                                       (6.3)

#### Proof
