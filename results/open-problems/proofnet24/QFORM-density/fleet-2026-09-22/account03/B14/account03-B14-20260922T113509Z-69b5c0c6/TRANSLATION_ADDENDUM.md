# account03/B14 addendum — exact translation / range-linear-term equivalence

**Status:** `PROVED SUPPORTING EQUIVALENCE / FULL CONJECTURE OPEN`.

The main report reduces the full law class, with no loss in the optimal `L^infinity` constant, to a countable dyadic-rational skeleton while leaving cell locations and separations unrestricted. This addendum isolates which part of that location freedom is pure translation and which part is genuinely geometric.

## Proposition — whole-coordinate translations are exactly range-linear perturbations

Fix a real symmetric matrix `A`. Let `C_hom(A)` denote the optimal output-density/small-ball constant when

`Q_A(x)=x^T A x`

is evaluated on arbitrary independent input densities bounded by one.

Let `C_range-aff(A)` be the corresponding optimal constant over all polynomials

`Q_{A,b,c}(x)=x^T A x + 2 b^T x + c`

with `b in Range(A)` and `c in R`, again over arbitrary independent input densities bounded by one.

Then

`C_range-aff(A)=C_hom(A)`.

The same equality holds with either side interpreted as `+infinity`.

### Proof

The inequality `C_hom(A)<=C_range-aff(A)` is immediate by taking `b=0,c=0`.

Conversely, if `b in Range(A)`, choose `m` with `A m=b`. Then

`x^T A x + 2 b^T x + c = (x+m)^T A (x+m) + c - m^T A m`.

If `X_1,...,X_n` are independent with densities bounded by one, then the translated variables `Y_i=X_i+m_i` remain independent and their densities have exactly the same `L^infinity` bounds. Therefore the law of `Q_{A,b,c}(X)` is merely a scalar translate of the law of `Q_A(Y)`. Scalar translation does not change a density `L^infinity` norm or any interval small-ball ratio. Hence every range-affine instance is controlled by `C_hom(A)`, proving the reverse inequality. QED.

## Consequences for localization

1. **Absolute location can be normalized if the proof carries the corresponding range-linear term.** For a finite-fragment or dyadic input law, translating the entire support of coordinate `i` by any amount is analytically harmless in the precise sense above.

2. **Relative fragment separation is not removed.** A single translation per coordinate cannot collapse widely separated components of the same marginal. The main report therefore correctly leaves fragment separations unbounded.

3. **Singular matrices require the range condition.** If `A` is invertible, `Range(A)=R^n` and arbitrary linear terms are equivalent to input translations. If `A` is singular, only `b in Range(A)` is generated by translations; claiming the same equivalence for an arbitrary kernel-direction linear term would be an unjustified strengthening.

4. **Anchored dyadic skeleton.** In the countable skeleton of the main report, one may choose one dyadic cell in each marginal and translate it to cell index zero. The resulting polynomial acquires a rational range-linear term whenever `A` is rational and the shifts are dyadic. Thus absolute cell indices can be quotiented out at the price of retaining a finite rational linear vector; relative gaps remain the true translation-sensitive data.

This is an exact equivalence, not a moment or compactness argument, and it preserves the optimal constant.
