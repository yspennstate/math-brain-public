1. Exponent identities
----------------------
For 1<r<=2 define
  r'=r/(r-1), beta=(r-1)/2, q=2/(r-1).
Then
  q*r/2 = r',
  1/q = beta,
  1/(1+beta)=2/(r+1).
PASS.

2. Interpolation identity
-------------------------
The L1-Lr' interpolation parameter theta=r/2 satisfies
  1/2=(1-theta)/1+theta/r'.
Indeed RHS = 1-r/2 + (r/2)*(r-1)/r = 1-r/2 +(r-1)/2 =1/2.
PASS.

3. Mixed-frequency norm
-----------------------
From
  int ||a_t||_{r'}^{r'} dt <= 2*pi*K^{r'-1} M_r^{r'}
and ||a_t||_1<=1,
  ||a_t||_2^q <= ||a_t||_{r'}^{r'}.
Hence
  || ||a_t||_2 ||_{L^q(dt)}
  <= (2*pi)^{1/q} K^{(r'-1)/q} M_r^{r'/q}
  = (2*pi)^beta K^{1/2} M_r^{r/2}.
Exponent checks:
  (r'-1)/q = 1/2,
  r'/q = r/2.
PASS.

4. Frequency-tail constant
--------------------------
Let q*=q/(q-1). Then
  [int_{|t|>T} |t|^{-q*} dt]^{1/q*}
  = [2(q-1)]^{(q-1)/q} T^{-1/q}
  = A_r T^{-beta},
where
  A_r=[2(3-r)/(r-1)]^{(3-r)/2}.
PASS.

5. Optimization
---------------
For F(T)=2T+L T^{-beta}, derivative zero gives
  T*=(beta L/2)^{1/(1+beta)}.
At T*, L T*^{-beta}=2T*/beta.
Thus Fourier inversion yields
  ||p_Q||_inf <= (1+beta)/(pi beta)
                  [(beta L)/2]^{1/(1+beta)}
with L=pi A_r (2*pi)^beta K^{1/2} M_r^{r/2}.
This matches REPORT (3.25).
PASS.

6. Hyperbolic conditional Lr source
-----------------------------------
Fresh account04/B01 gives for each fixed affine coefficients
  ||p_{2cUV+bU+gV+d}||_r <= 2^alpha |c|^{-alpha},
  alpha=(r-1)/r.
For coefficients depending on y, completing the product at each fixed y only translates U,V and adds a constant. Translation preserves cap-one input bounds and independence, so the identical conditional estimate holds pointwise in y.
PASS.

7. Final exponents and scaling
------------------------------
Using K<=2D^{-1/2} and M_r<=2^alpha |c|^{-alpha}, REPORT (4.6) has
  D exponent = -1/[2(r+1)],
  |c| exponent = -(r-1)/(r+1).
Under coefficient scaling A->lambda A,
  D->lambda^4 D, c->lambda c,
so total scaling exponent is
  4/[2(r+1)] + (r-1)/(r+1)=1.
PASS.
