## 3. A macroscopic half-cut lemma for a diffuse three-frame

The central deterministic point is that the one child direction and two cross directions should be grouped **before** selecting a local pivot.

Let `W` be an `m x 3` matrix with orthonormal columns. Write its physical rows as `w_i` and assume

`nu:=max_i ||w_i||^2 <=1/48`.                                    (3.1)

Independently put each original coordinate into `S` or `T` with probability `1/2`, and set

`G_S=W_S^T W_S`, `G_T=W_T^T W_T=I_3-G_S`.                       (3.2)

### Lemma 3.1 — balanced physical half-cut

There is a deterministic original-coordinate cut `S|T` for which

`(1/4)I_3 <= G_S <=(3/4)I_3`,
`(1/4)I_3 <= G_T <=(3/4)I_3`.                                   (3.3)

#### Proof

Write independent Rademacher signs `eps_i=+1` on `S` and `-1` on `T`. Then

`G_S-(1/2)I_3=(1/2)sum_i eps_i w_i w_i^T`.                      (3.4)

Because the signs are independent and centered,

`E ||G_S-(1/2)I_3||_F^2
 =(1/4)sum_i ||w_iw_i^T||_F^2
 =(1/4)sum_i ||w_i||^4
 <=(nu/4)sum_i||w_i||^2
 =3nu/4
 <=1/64`.                                                        (3.5)

Therefore

`P(||G_S-I/2||_F>1/4)
 <=(1/64)/(1/16)=1/4`.                                           (3.6)

A good cut exists. On it the operator deviation is at most the Frobenius deviation, proving (3.3); the same follows for `G_T=I-G_S`. QED.

This is deliberately a macroscopic physical grouping. The cut may contain order `m` coordinates, so the argument never pays the `m^{-1/2}` coefficient of one diffuse physical pivot.
