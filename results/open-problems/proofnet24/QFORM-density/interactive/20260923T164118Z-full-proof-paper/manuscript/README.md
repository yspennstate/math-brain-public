# Density Bounds for Quadratic Forms under Product Measures

This archive contains the anonymous LaTeX source of the paper.

Upload the ZIP to Overleaf and set `main.tex` as the main document. The project uses PDFLaTeX and BibTeX with standard packages. To compile locally, run PDFLaTeX on `main.tex`, BibTeX on `main`, then PDFLaTeX twice more.

The theorem for arbitrary real matrices applies to the symmetric part `(B+B^T)/2`. The dimension-independent bound for general indefinite forms with arbitrary bounded product densities remains open.
