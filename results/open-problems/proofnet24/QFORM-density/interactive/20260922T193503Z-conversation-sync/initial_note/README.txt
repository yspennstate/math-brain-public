# Quadratic-form proof note

The PDF gives complete proofs of absolute continuity, the diagonal pi bound, and the diffuse-component theorem with arbitrary separable perturbations. It does NOT claim a full solution of the universal three-large-eigenvalue conjecture. The new extension awaits independent end-to-end review.

Compile Quadratic_Form_Proofs.tex with pdflatex (twice). No external figures or font files are required.

check_algebra.py requires Python 3 and SymPy. It checks the explicit example and scalar algebra only, not the general conjecture. Its executed output is algebra_checks.json.
