# Quadratic-form ridge-window proof package

REPORT.md contains complete arguments for a one-scale ridge criterion and a spectral-window supporting theorem. The full arbitrary-matrix conjecture is not proved. Independent review of these new arguments is pending.

Run `python checks.py` after installing numpy, scipy and sympy to reproduce the finite checks. These checks corroborate algebra and examples, not the universal analytic proof. Git commit and hash evidence, the new sign-in request, and precisely scoped fleet observations are in RUN_RECORD.json.
