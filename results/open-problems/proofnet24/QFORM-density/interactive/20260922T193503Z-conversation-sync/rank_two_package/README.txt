The complete supporting proofs include an orientation-free rank-two half-Riesz estimate with arbitrary original-coordinate affine terms, and a rank-three Schur consequence. This is not a proof of the full original conjecture. Independent mathematical review is pending.

To rerun the finite diagnostic checks, install numpy, scipy and sympy in your own Python environment, then run:
  python checks.py
  python affine_checks.py

The JSON result files record the executed checks. They are not universal proof certificates. MANIFEST.json records the committed source hashes.
