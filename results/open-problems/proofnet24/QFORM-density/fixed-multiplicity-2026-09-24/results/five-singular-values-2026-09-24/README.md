# Five-singular-value result

Current audited bounded-density theorem:

[
s_5(A)ge s>0
quadLongrightarrowquad
|p_{X^TAX+b^TX+c}|_infty<2400K^2/s
]

for arbitrary real symmetric (A), arbitrary affine terms, and independent real coordinates with densities bounded by (K).
