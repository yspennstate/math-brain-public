## 2. Consumed exact speed reduction

Fix `0<=lambda<1`, put `c=1-lambda`, and let `B` be the quenched branch escape probability. Conditional on current offspring `k`, with iid copies `B_0,...,B_k`, set

`S_k=sum_{i=0}^k B_i`,
`w_k=S_k/((k+1)(S_k-c))`,
`c_k=E w_k`,
`a_k=-c'_k/c_k`.

Aidekon's symmetrized speed formula is

`ell_lambda=(r-lambda)/(r+lambda)`,
`r=E[nu c_nu]/E[c_nu]`.

For the two-point law define

`theta=p c_D/((1-p)c_1+p c_D)`.

Then exactly

`r=1+(D-1)theta`,
`r'=(D-1)theta(1-theta)(a_1-a_D)`,
`ell'_lambda=2(lambda r'-r)/(r+lambda)^2`.                 (2.1)

The inherited minimum-one derivative estimate is

`0<=a_D`, `a_1<=1/(1-lambda)`.                              (2.2)

The other substantive dependency is the raw common-mean chord/Jensen degree-ratio estimate. If `mu=E B`, then for every `D>=2`,

`c_D/c_1 <= R_D(lambda,mu)`

with

`R_D(lambda,mu)`
` =[(D+1-mu)(lambda+2mu-1)]/[D mu(D+lambda)]`.              (2.3)

The predecessor bounded `mu` through a scalar unconditional Jensen quadratic. This run obtains a stronger `mu` cap by isolating the one-child conditional mean first.

## 3. New mechanism: one-child conditional Jensen cap

Write

`mu_1=E[B | nu=1]`,
`mu_D=E[B | nu=D]`,
`mu=(1-p)mu_1+p mu_D`.                                      (3.1)

Let

`f_lambda(t)=t/(lambda+t)`.                                  (3.2)

For a one-child branch root, the unique child has offspring type `1` or `D` with probabilities `1-p` and `p`. Conditional on that type and using concavity of `f_lambda`,

`mu_1`
` <=(1-p) f_lambda(mu_1)+p f_lambda(mu_D)`
` <=(1-p) mu_1/(lambda+mu_1)+p/(lambda+1)`.                 (3.3)

After multiplication by the positive denominator `(lambda+mu_1)(lambda+1)`, this is

`G_{p,lambda}(mu_1)<=0`,                                    (3.4)

`G_{p,lambda}(x)`
` =(lambda+1)x^2+(lambda^2-1+p lambda)x-p lambda`.          (3.5)

For `p,lambda>0`, `G(0)<0` and the leading coefficient is positive, so `G` has exactly one positive root. Hence any `x_0>0` with `G(x_0)>=0` is a rigorous upper bound on `mu_1`.
