## 4. New mechanism: couple the high-degree score to its own denominator

The preceding lower bound on `a_D` first lower-bounded `Z` and then replaced `(S_D-c)^2` by `(D+lambda)^2`, losing the fact that a small own branch escape simultaneously makes its contribution to the denominator small. This run keeps that dependence.

Define the nonnegative compatibility variable

`Z:=B(1-cR)=B+cB'`.

### Lemma 4.1 — pointwise branch-type compatibility

If the root of the branch has `N>=1` children, then

`Z >= ((N-1)/N) B^2`.                                           (4.1)

In particular, on `{N=D}`,

`Z >= ((D-1)/D) B^2`.                                           (4.2)

#### Proof

Let

`T=sum_{j=1}^N B_j`.

The exact escape recursion is

`B=T/(lambda+T)`.

The logarithmic derivative recursion is

`R=[1+lambda sum_j B_jR_j/T]/(lambda+T)`.

Since `R_j<=1/c`,

`1-cR`
` >= 1-[c+lambda]/(lambda+T)`
` = (T-c)/(lambda+T)`,

because `c+lambda=1`. Hence

`Z=B(1-cR)`
` >= T(T-c)/(lambda+T)^2`
` = B^2(1-c/T)`.

Every child branch has escape at least `c`, so `T>=Nc`. Therefore

`1-c/T >= 1-1/N=(N-1)/N`.

This proves (4.1). QED.

### Lemma 4.2 — denominator-coupled lower score

Set

`M_D(lambda)=lambda+D(1-lambda)=D-(D-1)lambda`,
`b_D(lambda)=D(1-lambda)/M_D(lambda)`,
`A_D(lambda)=D-1+lambda`.

Then

`a_D >= p J_D^*(lambda)`,                                       (4.3)

where

`J_D^*(lambda)`
` =(D-1) [ b_D/(A_D+b_D) ]^2`
` =(D-1)D^2(1-lambda)^2`
`   / [ A_D M_D + D(1-lambda) ]^2`.                             (4.4)

#### Proof

Differentiate

`w_D=S_D/((D+1)(S_D-c))`.

With `U=sum_i B_iR_i`,

`-c_D'`
` =E[(S_D-cU)/((D+1)(S_D-c)^2)]`
` =E[(sum_i Z_i)/((D+1)(S_D-c)^2)]`.

By exchangeability,

`-c_D'=E[ Z_0/(S_D-c)^2 ]`.                                    (4.5)

Restrict to the event that branch 0 itself has D children. On this event, Lemma 4.1 gives

`Z_0 >= ((D-1)/D) B_0^2`.                                      (4.6)

Also the other D branch escapes are at most one, hence

`S_D-c`
` <= B_0 + D-c`
` = B_0+A_D`.                                                    (4.7)

On the same event, the D children below branch 0 each have escape at least c, so its own escape obeys

`B_0>=b_D=Dc/(lambda+Dc)=Dc/M_D`.                              (4.8)

The map `x -> x^2/(A_D+x)^2` is increasing. Combining (4.5)--(4.8),

`-c_D'`
` >= p (D-1)/D * [b_D/(A_D+b_D)]^2`.                           (4.9)

The inherited static bound `c_D<=1/D` therefore yields

`a_D=(-c_D')/c_D`
` >= p(D-1)[b_D/(A_D+b_D)]^2`,

which is (4.3)--(4.4). QED.
