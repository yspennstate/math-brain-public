## 4. New lemma: high-degree score forced by the same branching law

### Lemma 4.1 — branch-level compatibility variable

For `0<=lambda<1`, define

`Z:=B(1-cR)=B+cB'`.                                             (4.1)

Then `Z>=0`. Moreover, on the event that the root of the branch has `D` children,

`Z >= D c (M-1)/M^2`,                                           (4.2)

where

`M=lambda+D c=D-(D-1)lambda`.                                  (4.3)

Consequently, under the offspring law (1.1),

`E Z >= p D c(M-1)/M^2`.                                       (4.4)

### Proof

If the branch root has `N` children, write

`T=sum_{j=1}^N B_j`.

The exact escape recursion is

`B=T/(lambda+T)`.                                                (4.5)

Differentiating logarithmically gives

`R = [1+lambda sum_j B_j R_j/T]/(lambda+T)`.                    (4.6)

By (3.1)--(3.2), if `N=D` then

`T>=D c`,

and

`sum_j B_jR_j/T <=1/c`.                                        (4.7)

Therefore

`B>=D c/M`,                                                      (4.8)

`R<= [1+lambda/c]/M =1/(cM)`.                                  (4.9)

Since `M>1` for `lambda<1` and `D>1`,

`Z=B(1-cR)>= (D c/M)(1-1/M)`
` =D c(M-1)/M^2`.                                               (4.10)

For `N=1`, (3.2) only gives `Z>=0`, which is enough. Averaging over `P(N=D)=p` proves (4.4). QED.

### Lemma 4.2 — positive lower bound on `a_D`

For the current-degree-D tilt coefficient,

`a_D >= p J_D(lambda)`,                                         (4.11)

where

`J_D(lambda)=`
` D^2(D-1)(1-lambda)^2`
` /[(D-(D-1)lambda)^2(D+lambda)^2]`.                           (4.12)

### Proof

Let `U=sum_{i=0}^D B_iR_i`. Differentiating (3.3) gives

`-c_D' = E[(S_D-cU)/((D+1)(S_D-c)^2)]`.                        (4.13)

But

`S_D-cU=sum_{i=0}^D B_i(1-cR_i)=sum_{i=0}^D Z_i`.              (4.14)

Also `S_D<=D+1`, hence

`S_D-c<=D+lambda`.                                               (4.15)

Using (4.4),

`-c_D' >= E Z/(D+lambda)^2`.                                   (4.16)

From `S_D>=(D+1)c` and the fact that `s/(s-c)` decreases in `s`,

`c_D<=1/D`.                                                      (4.17)

Therefore

`a_D=-c_D'/c_D`
` >= D E Z/(D+lambda)^2`
` >= p D^2 c(M-1)/[M^2(D+lambda)^2]`.                          (4.18)

Since

`M-1=(D-1)c`,                                                    (4.19)

this is exactly (4.11)--(4.12). QED.

### Mechanism gain

The predecessor allowed the high-degree score `a_D` to be zero while the static ratio `c_D/c_1` was near its worst value. Lemma 4.2 rules out that joint extremization whenever `p>0`: the same law that creates degree-D mass forces a positive amount of `B+cB'`, hence a positive high-degree score.

Combining (3.8) and (4.11),

`a_1-a_D <= 1/(1-lambda)-p J_D(lambda)`.                        (4.20)

This is the new static/derivative compatibility estimate.
