## 1. Source normalization and recovered prior attempts

Let `nu` be the offspring random variable. The original source assumption is a supercritical Galton–Watson tree without leaves (`P(nu=0)=0`). In the theorem proved below I impose the stronger bounded-support assumption

`d <= nu <= D` almost surely, with integers `2 <= d < D < infinity`.

This automatically gives no leaves and supercriticality.

I use the **parent-bias convention** of He–Wang–Xiang: at a non-root vertex with `k` children, the edge to the parent has weight `lambda` and every child edge has weight `1`, so

`P(parent | k)=lambda/(lambda+k)`,  `P(each fixed child | k)=1/(lambda+k)`.

Thus larger `lambda` is more rootward and the LPP conjecture asks that the speed `ell_lambda` be nonincreasing in `lambda`. In the older child-bias convention of Ben Arous–Fribergh–Sidoravicius, `beta` is the child/parent weight ratio, so

`beta = 1/lambda`.

Recovered source/literature points:

1. arXiv:1111.5865 v1 states that the speed `v(beta)` is increasing for child bias `beta >= 717`. Its Section 7.1 observes the minimal-degree rescaling `d beta`; the later published version has the larger numerical constant 1160. He–Wang–Xiang summarize that published result in parent-bias form as `lambda <= m1/1160`.
2. arXiv:1610.08151 (He–Wang–Xiang; published in Journal of Applied Probability in 2025) proves, for minimum offspring `m1>=2`, strict decrease on

   `0 <= lambda <= theta_d := d/(1+sqrt(1-1/d))`.

   `0 < -beta'(lambda) <= beta(lambda)/(d-lambda)`.

## 2. Literal regeneration-score attack and its obstruction

I first tested the route most literally matching P01's assignment. Bowditch–Tokushige write `ell'_lambda` as a covariance between the centered displacement and a Girsanov score accumulated over LPP regeneration blocks. At a vertex with `k` children, the one-step score is

- parent step: `k/[lambda(lambda+k)] > 0`;
- child step: `-1/(lambda+k) < 0`.

Thus even with `d<=k<=D`, the regeneration score is not monotone in displacement: it changes sign with step orientation. A range bound on the number of children alone gives only an absolute covariance estimate, not the sign needed for monotonicity. A successful literal regeneration proof would require a new cycle-level ordering/association inequality between displacement and the signed score. I did not find such an inequality in this run.

This is the mathematical obstruction, not merely a missing calculation.

To get an actual theorem rather than another stuck lemma, I then used the equivalent analytic escape-variable representation of the speed, retaining the derivative/covariance viewpoint but placing the measure-change term in a scalar variable that admits explicit bounds.

## 3. Exact derivative reduction

Let `beta_0,...,beta_nu` be iid copies of the escape probability from a vertex to infinity before hitting its parent, independent of `nu`. Put

`S = sum_{i=0}^nu beta_i`,

`A = lambda - 1 + S`,

`u = S / ((nu+1) A)`.

Aidekon's speed formula, as quoted in He–Wang–Xiang equation (2.1), is

`ell_lambda = E[(nu-lambda) beta_0/A] / E[(nu+lambda) beta_0/A]`.

Conditional on `nu`, the denominator `A` is symmetric in the `nu+1` iid escape variables, so exchangeability gives

`E[(nu +/- lambda) beta_0/A] = E[(nu +/- lambda) u]`.

Define the `u`-tilted effective offspring

`r(lambda) = E[nu u]/E[u]`.

Then

`ell_lambda = (r-lambda)/(r+lambda)`

and therefore

`ell'_lambda = 2(lambda r' - r)/(r+lambda)^2`.                         (3.1)

Now differentiate `u`. Since `A'=1+S'`,

`u'/u = S'/S - (1+S')/A`

`      = - [S+(1-lambda)S']/(S A)`.

Define

`q = [S+(1-lambda)S']/(S A)`.

Let `mu_lambda` be the probability measure with density `u/E[u]`. Differentiating the quotient for `r` gives the exact identity

`r' = - Cov_mu(nu,q)`.                                                   (3.2)

Thus the entire measure-change obstruction is now one covariance.

Because offspring is bounded and `lambda` is restricted to a compact subset of `(1,d)`, the He–Wang–Xiang lower bound on `beta`, their derivative bound, and `A>=d-lambda/d>0` uniformly dominate `u` and `u'`. Hence differentiation through expectation in (3.2) is justified by dominated convergence.

## 4. Uniform bounds for arbitrary bounded offspring support

Fix `1<lambda<d` and write `h=D-d`.

He–Wang–Xiang give

`1-lambda/d <= beta_i <= 1-lambda/D`,

`0 < -beta_i' <= beta_i/(d-lambda)`.

Summing and dividing by `S` yields

`0 <= -S'/S <= 1/(d-lambda)`.

Since `lambda>1`,

`[S+(1-lambda)S']/S = 1 + (lambda-1)(-S'/S)`

lies in

`[1, (d-1)/(d-lambda)]`.                                                (4.1)

Also

`A >= lambda-1 + (d+1)(1-lambda/d) = d-lambda/d`,

and, using `nu<=D`,

`A <= lambda-1 + (D+1)(1-lambda/D) = D-lambda/D`.                       (4.2)

Combining (4.1)-(4.2),

`q_min(lambda) := 1/(D-lambda/D) <= q <=`

`q_max(lambda) := (d-1)/((d-lambda)(d-lambda/d))`.                       (4.3)

Since under `mu_lambda` we still have `nu in [d,D]`, Cauchy–Schwarz plus Popoviciu's variance inequality (equivalently Gruss' covariance inequality) gives

`-Cov_mu(nu,q) <= |Cov_mu(nu,q)|`

`                   <= (D-d)(q_max-q_min)/4`

`                   = h(q_max-q_min)/4`.                                (4.4)

Moreover `r=E_mu[nu]>=d`. By (3.1)-(3.2),

`lambda r' - r <= lambda h(q_max-q_min)/4 - d`.

Define

`F_{d,D}(lambda)`

` := d/lambda - (h/4) [ (d-1)/((d-lambda)(d-lambda/d))`

`                        - 1/(D-lambda/D) ]`.                            (4.5)

Then whenever `F_{d,D}(lambda)>0`,

`lambda r'-r <= -lambda F_{d,D}(lambda)<0`.

Because `r<=D`, this yields the quantitative derivative estimate

`BOX:  ell'_lambda <= - 2 lambda F_{d,D}(lambda)/(D+lambda)^2 < 0.`      (4.6)

This is the main new derivative-sign estimate.

## 5. The proved parameter region has a unique explicit boundary

For `0<lambda<d`, both `q_max` and `q_min` are increasing. More precisely,

`q_min = D/(D^2-lambda)`, so `q_min' = D/(D^2-lambda)^2`.

From (4.5),

`F' = -d/lambda^2 -(h/4)q_max' +(h/4)q_min'`.

The positive last term cannot offset the first term. Indeed `h<D`, `lambda<d<=D`, hence

`(h/4) q_min' < D^2/[4(D^2-lambda)^2]`

`                 <= 1/[4(D-1)^2]`

`                 < 1/d`

`                 < d/lambda^2`.

Since `q_max'>0`, it follows that

`BOX: F'_{d,D}(lambda)<0 on (0,d).`                                     (5.1)

Also `F(lambda)->+infinity` as `lambda downarrow 0`, whereas `F(lambda)->-infinity` as `lambda upward d`. Therefore there is a unique

`rho_{d,D} in (0,d)`

such that `F_{d,D}(rho_{d,D})=0`, and P01 proves strict derivative negativity throughout

`1 <= lambda < rho_{d,D}`

whenever `rho_{d,D}>1` (the endpoint `lambda=1` follows directly/continuously from the same bounds).

Combining with He–Wang–Xiang on `[0,theta_d]`, any bounded-support pair `(d,D)` satisfying

`F_{d,D}(theta_d)>0`                                                     (5.2)

has a **genuinely new source-level interval**: the speed is strictly decreasing on `[0,rho_{d,D})`, with `rho_{d,D}>theta_d`.

This criterion is exact for the present coarse range-covariance method.

## 6. A clean general sufficient width condition

Set `lambda_0=d-h/4`. Exact simplification gives

`F_{d,D}(lambda_0)`

` = h N(d,h) / [(4d-h)(4d^2-4d+h)(4d^2+8dh-4d+4h^2+h)]`,               (6.1)

where

`N(d,h)=32d^4+44d^3h-32d^3+12d^2h^2-4d^2h+7dh^2-h^3`

and, crucially,

`N(d,h)=32d^3(d-1)+4d^2h(11d-1)+h^2(12d^2+7d-h)`.                      (6.2)

Thus `F(lambda_0)>0` for `0<h<4d`. If

`h < 4(d-theta_d)`,                                                     (6.3)

then `lambda_0>theta_d>1`, so `rho_{d,D}>lambda_0>theta_d`: this is an explicit bounded-width class where the theorem extends the published all-offspring interval.

Since `F` is decreasing and `lambda/(D+lambda)^2` is increasing for `lambda<D`, (4.6) also gives a uniform margin on `[1,lambda_0]`:

`BOX: ell'_lambda <= -delta_{d,h}`,

`delta_{d,h}:=2 F_{d,D}(lambda_0)/(D+1)^2 > 0.`                         (6.4)

## 7. Concrete first theorem: offspring in {2,3,4}

Take `d=2,D=4,h=2`. Then

`F_{2,4}(lambda)`

` = (33 lambda^2 - 208 lambda + 256)`

`   / [lambda(16-lambda)(4-lambda)(2-lambda)]`.

Its unique zero in `(0,2)` is

`rho_{2,4}=(104-8 sqrt(37))/33 = 1.676906...`.

The current all-offspring minimum-degree-two endpoint is

`theta_2=4-2 sqrt(2)=1.171572...`.

Therefore every Galton–Watson offspring law supported in `{2,3,4}` has strictly decreasing speed at least on

`BOX: 0 <= lambda < (104-8 sqrt(37))/33`,

which is a large genuinely uncovered middle-bias interval relative to the 2025 all-offspring theorem.

At `lambda_0=3/2`,

`F_{2,4}(3/2)=292/435`,

so the uniform quantitative margin is

`BOX: ell'_lambda <= -584/10875 < -0.0537 on 1 <= lambda <= 3/2.`        (7.1)
