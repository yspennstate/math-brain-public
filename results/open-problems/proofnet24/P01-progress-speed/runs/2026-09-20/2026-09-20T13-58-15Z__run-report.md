## 3. New mechanism: recursively sharpen only the one-child conditional mean

`U_1^(0)=u/(lambda0+u)`,
`U_D^(0)=D u/(lambda0+D u)`

The predecessor stopped there. The new observation is that the **one-child** root sees exactly one child whose root type is again `{1,D}`. If `mu_1<=x` and `mu_D<=y`, then conditioning on that child's type and applying Jensen separately gives

`BOX: U_1^(j+1)=(1-p0) f_{lambda0}(U_1^(j))+p0 f_{lambda0}(U_D^(0)).`
