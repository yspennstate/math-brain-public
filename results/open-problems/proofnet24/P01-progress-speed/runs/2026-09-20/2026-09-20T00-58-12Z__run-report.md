## 1. Frozen source assumptions and bias convention

Let `nu` be the offspring variable. The source problem assumes a supercritical Galton–Watson tree without leaves:

`P(nu=0)=0`, `m=E nu>1`.

For the theorem below impose the stronger bounded-support hypothesis

`d <= nu <= D` almost surely,

for integers `2<=d<D<infinity`. The concrete strongest breadth theorem uses only `2<=nu<=74`.

Use the parent-bias convention of He–Wang–Xiang: at a non-root vertex with `k` children,

`P(parent | k)=lambda/(lambda+k)`,
`P(each fixed child | k)=1/(lambda+k)`.

Thus increasing `lambda` biases toward the root and the conjectural sign is `ell'_lambda<=0`. The child-bias convention of Ben Arous–Fribergh–Sidoravicius is reciprocal:

`beta = 1/lambda`.

If `v(beta)=ell_{1/beta}`, then where differentiable

`v'(beta)=-ell'_{1/beta}/beta^2`.

## 3. Starting derivative identity from the previous P01 run

Let `B_0,...,B_nu` be iid escape variables and write

`S = sum_{i=0}^nu B_i`,
`A = lambda-1+S`,
`u = S/((nu+1)A)`.

By exchangeability in Aidekon's speed formula,

`ell_lambda = (r-lambda)/(r+lambda)`,

where

`r = E[nu u]/E[u]`.

Define the `u`-tilted law `mu_lambda` by `dmu = u dP / E[u]`.

Differentiating `u` gives

`u'/u = -q`,

with

`q = [S+(1-lambda)S']/(S A)`.

Therefore

`r' = -Cov_mu(nu,q)`,                                                (3.1)

and

`ell'_lambda = 2(lambda r'-r)/(r+lambda)^2`.                          (3.2)

On compact subintervals of `[1,d)`, bounded offspring plus the escape lower bound and derivative bound dominate `u,u'`, so differentiation through expectation is justified as in the preceding P01 report.

## 4. Uniform pointwise q envelopes

Fix `1<=lambda<d`.

Since `S'<=0` and `-S'/S<=1/(d-lambda)`, for `lambda>=1`,

`1 <= [S+(1-lambda)S']/S <= (d-1)/(d-lambda)`.                       (4.1)

Also, because `nu>=d` and every escape variable is at least `1-lambda/d`,

`A >= lambda-1+(d+1)(1-lambda/d)=d-lambda/d`.                        (4.2)

Because `nu<=D` and every escape variable is at most `1-lambda/D`,

`A <= lambda-1+(D+1)(1-lambda/D)=D-lambda/D`.                        (4.3)

Hence

`q_-(lambda):=1/(D-lambda/D) <= q <=`

`q_+(lambda):=(d-1)/((d-lambda)(d-lambda/d))`.                        (4.4)

Both envelope functions increase with `lambda` on `(0,d)`.

The previous P01 run inserted (4.4) into Gruss/Popoviciu and paid

`-Cov_mu(nu,q) <= (D-d)(q_+-q_-)/4`.

The new argument avoids that product-of-ranges loss.

## 5. New lemma: covariance is controlled by distance of the tilted mean from the support boundary

Let

`N=nu` under `mu_lambda`, `r=E_mu N`,

and set

`m_n = E_mu[q | N=n]`, `pi_n=mu(N=n)`.

Then (3.1) and the pairwise covariance identity give

`r' = sum_{n<m} pi_n pi_m (m-n)(m_n-m_m)`.                            (5.1)

If `q_-<=q<=q_+`, then every conditional mean `m_n` also lies in `[q_-,q_+]`, so with `Q=q_+-q_-`,

`r' <= Q sum_{n<m} pi_n pi_m (m-n)`

`   = (Q/2) E|N-N'|`,                                                 (5.2)

where `N'` is an independent copy under the same tilted law.

Now use the support bounds twice. Since `N,N'>=d`,

`|N-N'| <= (N-d)+(N'-d)`,

hence

`(1/2)E|N-N'| <= r-d`.                                                (5.3)

Likewise, since `N,N'<=D`,

`|N-N'| <= (D-N)+(D-N')`,

so

`(1/2)E|N-N'| <= D-r`.                                                (5.4)

Combining (5.2)–(5.4),

`BOX: r' <= Q min(r-d,D-r).`                                          (5.5)

This is the run's mechanism-level advance. The measure-change term is charged to the tilted mean's distance from the nearer endpoint instead of to the full width independently of where that mean lies.

## 6. Uniform rectangle theorem

Fix `1<=lambda<=L<d`. From monotonicity of the envelopes,

`q <= q_+(L)`,

while

`q >= q_-(lambda) >= q_-(1)=1/(D-1/D)`.

Define

`Q^*_{d,D}(L)`
` := (d-1)/((d-L)(d-L/d)) - 1/(D-1/D)`,                              (6.1)

and

`c_{d,D}(L):=L Q^*_{d,D}(L)`.                                       (6.2)

Then for every `lambda in [1,L]`, (5.5) yields

`lambda r'-r <= c min(r-d,D-r)-r`,                                   (6.3)

with `c=c_{d,D}(L)` and `r in [d,D]`.

The scalar function on the right is piecewise linear. If `c<=1`, its maximum occurs at `r=d` and equals `-d`. If `c>1`, it increases up to the midpoint and decreases afterward, so its maximum occurs at

`r=(d+D)/2`

and equals

`[c(D-d)-(D+d)]/2`.

Therefore define

`M_{d,D}(L)`
` := min{d, [D+d-c_{d,D}(L)(D-d)]/2}.                                (6.4)

If

`BOX: c_{d,D}(L)(D-d) < D+d`,                                       (6.5)

then `M_{d,D}(L)>0` and (3.2) gives the uniform quantitative theorem

`BOX: ell'_lambda <= - 2 M_{d,D}(L)/(D+L)^2 <0`

for every

`1<=lambda<=L`.                                                       (6.6)

Combining with He–Wang–Xiang on `[0,theta_d]` gives strict decrease on `[0,L]` whenever `L>theta_d` and (6.5) holds.

This theorem is distribution-free inside the support rectangle: it does not assume adjacent support, rarity, or a lower bound on the probability of any degree.
