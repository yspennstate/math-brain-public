## 2. Consumed exact speed reduction and inherited bounds

Fix `0<=lambda<1`, put

`c=1-lambda`,

and let `B` be the quenched branch escape probability. In the no-leaf regime,

`c<=B<=1` pathwise.

Conditional on current offspring `k`, with iid copies `B_0,...,B_k`, set

`S_k=sum_{i=0}^k B_i`,
`w_k=S_k/((k+1)(S_k-c))`,
`c_k=E w_k`,
`a_k=-c'_k/c_k`.

Aidekon's symmetrized speed formula gives

`ell_lambda=(r-lambda)/(r+lambda)`,
`r=E[nu c_nu]/E[c_nu]`.

For the two-point law define

`theta=p c_D/((1-p)c_1+p c_D)`.

Then exactly

`r=1+(D-1)theta`,
`r'=(D-1)theta(1-theta)(a_1-a_D)`,
`ell'_lambda=2(lambda r'-r)/(r+lambda)^2`.                  (2.1)

`BOX: c_D<=1/D`.                                            (2.3)
