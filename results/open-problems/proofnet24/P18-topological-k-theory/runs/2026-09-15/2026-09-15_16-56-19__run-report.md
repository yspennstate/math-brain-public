# 3. The exact non-direct family

Let

\[
\alpha(a)=a,
\qquad
\alpha(b)=b^{-1}.
\]

Then `alpha^2=id` and `alpha` preserves the standard free word length.

It also preserves the normal closure of `a^L`, so it descends to

\[
\alpha_L\in\operatorname{Aut}(C_L*\mathbb Z).
\]

Define `Gamma,Gamma_L` by `(0.1)`–`(0.2)`.

## 3.1 The semidirect product is genuinely non-direct

The automorphism `alpha` is outer: inner automorphisms act trivially on

\[
H_1(F_2;\mathbb Z)\cong\mathbb Z^2,
\]

whereas `alpha` acts by

\[
(a,b)\longmapsto(a,-b).
\]

If `f t^n` is central in `Gamma`, then conjugation on `F_2` gives

\[
\alpha^n=\operatorname{Ad}(f^{-1}).
\]

For odd `n` this would make `alpha` inner, impossible. For even `n`, `alpha^n=id`, so `f` centralizes `F_2`; hence `f=e`. Therefore

\[
\boxed{Z(\Gamma)=\langle t^2\rangle.}
\tag{3.1}
\]

The quotient `Gamma/Z(Gamma)` contains the nontrivial order-two class of `t`, while

\[
(F_2\times\mathbb Z)/Z(F_2\times\mathbb Z)\cong F_2
\]

is torsion free. Consequently

\[
\boxed{\Gamma\not\cong F_2\times\mathbb Z.}
\tag{3.2}
\]

So the theorem below is not merely a relabeling of P25's direct product.

## 3.2 The index-two direct-product cover

Because `alpha^2=id`,

\[
K
:=
\langle F_2,t^2\rangle
\cong
F_2\times\mathbb Z
\]

is normal of index two in `Gamma`.

Likewise

\[
K_L
:=
\langle H_L,t^2\rangle
\cong
H_L\times\mathbb Z
\]

is normal of index two in `Gamma_L`.

This finite cover is the structural input that allows P40 to survive the twist.

# 4. Finite-index regular embedding

Let a discrete group `G` contain a normal finite-index subgroup `K` of index `m`, with left-coset representatives

\[
r_0=e,r_1,\ldots,r_{m-1}.
\]

Using the decomposition

\[
\ell^2(G)
=
\bigoplus_{j=0}^{m-1}\ell^2(r_jK)
\cong
\ell^2(K)\otimes\mathbb C^m,
\]

left regular multiplication gives a faithful isometric embedding

\[
\iota_G:C_r^*(G)\hookrightarrow M_m(C_r^*(K)).
\tag{4.1}
\]

For `g in G`, the `(i,j)` entry is either zero or

\[
\lambda_K(r_i^{-1}gr_j),
\]

when `r_i^{-1}gr_j in K`.

This choice of **left** cosets is important: no extra automorphism operator is hidden in the matrix entries.

For the present semidirect product take `m=2` and

\[
r_0=e,
\qquad
r_1=t.
\]

If

\[
g=f t^n,
\qquad f\in F_2,
\]

then the unique nonzero entry in column `j` lies in row

\[
i\equiv n+j\pmod2
\]

and equals

\[
\boxed{
\alpha^{-i}(f)t^{n+j-i}
\in F_2\times\langle t^2\rangle.
}
\tag{4.2}
\]

Because `alpha` preserves free word length,

\[
|\alpha^{-i}(f)|=|f|.
\tag{4.3}
\]

Exactly the same matrix formula holds at the stage, and coefficient evaluation commutes with the two finite-index embeddings.

# 5. Proof of the non-direct P40 theorem

\[

be coefficientwise group-ring evaluation.

### Step 1 — direct-product local map

P01-P40 gives, on the `F_2` radius-`R` operator space,

\[
\|J_{L,R}^{F_2}\|_{cb}
\le
\Gamma_+(R,L)
\]

whenever `L>=8R+1`.

Since

\[
C_r^*(F_2\times\langle t^2\rangle)
=
C_r^*(F_2)\otimes_{\min}C(\mathbb T),
\]

the map tensored with the identity on `C(T)` has the same cb bound. Concretely, an element is a continuous `C_r^*(F_2)`-valued function on the circle and P40 is applied pointwise:

\[
\boxed{
\|J_{L,R}^{F_2}\otimes\mathrm{id}_{C(\mathbb T)}\|_{cb}
\le
\Gamma_+(R,L).
}
\tag{5.1}
\]

### Step 2 — finite-index matrix entries stay at the same radius

By `(4.2)`–`(4.3)`, every entry of

\[
\iota_\Gamma(X)
\in
M_2(C_r^*(F_2\times\mathbb Z))
\]

has free-group support radius at most `R` whenever `X in E_R(Gamma)`.

Moreover the square

\[
\begin{CD}
E_R(\Gamma) @>{J_{L,R}^{\Gamma}}>> C_r^*(\Gamma_L)\\
@V{\iota_\Gamma}VV @VV{\iota_{\Gamma_L}}V\\
M_2(E_R(F_2\times\mathbb Z)) @>{(J_{L,R}^{F_2}\otimes\mathrm{id})^{(2)}}>> M_2(C_r^*(H_L\times\mathbb Z))
\end{CD}
\]

commutes coefficientwise.

### Step 3 — matrix stability

For every matrix size `n`,

\[
\begin{aligned}
\|(J_{L,R}^{\Gamma})^{(n)}(X)\|
&=
\|\iota_{\Gamma_L}^{(n)}(J_{L,R}^{\Gamma}(X))\|\\
&\le
\Gamma_+(R,L)
\|\iota_\Gamma^{(n)}(X)\|\\
&=
\Gamma_+(R,L)\|X\|.
\end{aligned}
\]

Thus `(0.3)` is proved at every matrix size.

Because

\[
\log\Gamma_+(R,L)
=
O(R\log L/L),

`(0.5)` follows.

### General finite-order version

If `alpha` has finite order `m` but is not length preserving, define

\[
\ell_\alpha(f)
=
\max_{0\le j<m}|\alpha^j(f)|.
\tag{5.2}

This is an `alpha`-invariant subadditive length. Using radius measured by `ell_alpha`, exactly the same index-`m` proof gives the same P40 constant, because every finite-index matrix entry has ordinary free length at most the `ell_alpha` radius.

Thus the theorem is a periodic-monodromy principle, not an accident of order two.

# 7. Kernel-rank lower bound without assuming `C Gamma` is Sylvester

\[
z\longmapsto C(z)
\in

\[

\dim_{L(H_L)}\ker C_L(z)

\right|
\le

\boxed{

\tag{9.12}

## 9.4 Rank sandwich

Let

\[

\in M_v(L(\Gamma_L)).

Since `p_{N_L}(0)=1`,

\[
P_L\le Q_L.
\tag{9.13}

Therefore

\[
\beta_L
:=
(\operatorname{Tr}_v\otimes\tau_{\Gamma_L})(P_L)
\le

=\beta.
\tag{9.14}
\]

Section 7 gives the opposite inequality

\[
\beta_L\ge\beta.
\tag{9.15}
\]

Thus `beta_L=beta`. Since the finite von-Neumann trace is faithful and `P_L<=Q_L`,

\[
\boxed{P_L=Q_L.}

This proves `(0.11)`–`(0.14)`.

## 9.5 Explicit gap

Let

\[

=
\frac{M+\delta}{M-\delta}

Define `s_L,delta_{*,L}` by `(0.15)`.

\qquad

\tag{9.16}

A positive stage spectral point in `(0,delta_{*,L})` would give a nonzero spectral projection contained in `Q_L` and orthogonal to `P_L`, contradicting `Q_L=P_L`.

Using

and

\[
\sinh(\theta/2)

we obtain `(0.16)`.
