# 3. Inherited analytic and algebraic channels

The proof uses three independent legs from the preceding P18 report.

## 3.1 Local matrix-stable upper reduced norm

For a finite group-ring matrix `X` whose `F_2` coefficient support has radius at most `R`, with arbitrary finite `t`-support,

\[
\boxed{
\|X_L\|_{C_r^*(\Gamma_L)}
\le
\Gamma_+(R,L)
\|X\|_{C_r^*(\Gamma)},
}
\tag{3.1}
\]

whenever `L>=8R+1`, where

\[
\boxed{
\Gamma_+(R,L)
=
\exp\!\left[
\frac{4R}{L-1}
\left(
\log13+3\log\frac{L-1}{2}
\right)
\right].
}
\tag{3.2}
\]

The estimate is completely bounded and independent of matrix size.

The proof passes through the index-two subgroup

\[
F_2\times\langle t^2\rangle\triangleleft\Gamma.
\]

The finite-index matrix entries apply only `alpha^0` or `alpha^1` to free coefficients, and `alpha` preserves ordinary free word length.

For the fixed matrix `C`, if

\[
\beta_L
=

then

\[
\boxed{\beta_L\ge\beta.}
\tag{3.3}
\]

This comes from the same index-two embedding, Fourier decomposition in the central `t^2` coordinate, and fiberwise P01-P42A for matrices over `C F_2`.

## 3.3 Parent and stage trace meshes

\boxed{2\beta\in\mathbb Z.}

# 4. The majority plateau polynomial

Fix

\[
0<\delta_0<\delta<M.
\]

Put

\[
c=\frac{\delta+\delta_0}{2},
\qquad
\gamma=\frac{\delta-\delta_0}{2M}>0,
\qquad
z(x)=\frac{c-x}{M}.
\tag{4.1}
\]

For an odd integer

\[
n=2m+1,
\]
define

\[
q_n(x)
=
\sum_{k=m+1}^{n}
\binom nk
\left(\frac{1+z(x)}2\right)^k
\left(\frac{1-z(x)}2\right)^{n-k}.
\tag{4.2}
\]

Because `0<c<M`, for `x in [0,M]` one has

\[
-1<z(x)<1,
\]
so

\[
p(x)=\frac{1+z(x)}2
\in(0,1),
\]
and `q_n(x)` is the strict-majority probability

\[
\Pr\{\operatorname{Bin}(n,p(x))\ge m+1\}.
\]

Set

\[
\varepsilon_n=e^{-n\gamma^2/2}.
\tag{4.3}
\]

Then Hoeffding's inequality gives

\[
\boxed{
0\le q_n(x)\le1
\qquad(0\le x\le M),
}
\tag{4.4}
\]

\[
\boxed{
q_n(x)\ge1-\varepsilon_n
\qquad(0\le x\le\delta_0),
}
\tag{4.5}
\]

and

\[
\boxed{
q_n(x)\le\varepsilon_n
\qquad(\delta\le x\le M).
}
\tag{4.6}
\]

The transition remains fixed in the empty parent interval `(delta_0,delta)` while increasing `n` only flattens the two plateaux.

# 5. Choice of degree and propagation

For each `L`, choose `n_L` to be the least odd integer satisfying

\[
\boxed{
n_L
\ge
\frac{2}{\gamma^2}\log(24vL)
=
\frac{8M^2}{(\delta-\delta_0)^2}\log(24vL).
}
\tag{5.1}
\]

Then

\[
\boxed{
\varepsilon_L:=e^{-n_L\gamma^2/2}
\le\frac1{24vL}.
}
\tag{5.2}
\]

Because

\[
n_L=O(\log L),
\]
for all sufficiently large `L`, simultaneously

\[
\boxed{L\ge16n_L\rho+1}
\tag{5.3}
\]
and

\[
\boxed{\Gamma_+(2n_L\rho,L)\le2.}
\tag{5.4}
\]

The first bound is stronger than the marked-ball injectivity needed for trace preservation and exactly matches the P40 admissibility condition for the idempotent defect radius `2 n_L rho`.

Define

\[
A_{\infty,L}=q_{n_L}(D_\infty),
\qquad
A_L=q_{n_L}(D_L).
\tag{5.5}
\]

Let

\[
P_\infty=\mathbf1_{\{0\}}(D_\infty).
\]

On the parent spectrum, `(4.5)`–`(4.6)` imply

\[
\boxed{
\|A_{\infty,L}-P_\infty\|
\le\varepsilon_L.
}
\tag{5.6}
\]

Furthermore every parent spectral value of `A_{infty,L}` lies in

\[
[0,\varepsilon_L]
\cup
[1-\varepsilon_L,1],
\]
so

\[
\boxed{
\|A_{\infty,L}^2-A_{\infty,L}\|
\le\varepsilon_L.
}
\tag{5.7}
\]

The free-factor support radius of `A_{infty,L}` is at most `n_L rho`; the defect has radius at most `2 n_L rho`.

# 6. Transfer of the idempotent defect

Coefficient evaluation is algebraically multiplicative on the group ring, hence

\[
A_L^2-A_L
=
(A_{\infty,L}^2-A_{\infty,L})_L.
\]

By `(3.1)`, `(5.3)`, and `(5.4)`,

\[
\eta_L
:=
\|A_L^2-A_L\|
\le
2\varepsilon_L
\le
\frac1{12vL}
<\frac14
\tag{6.1}
\]
for large `L`.

Because `q_n` is real and `D_L` is self-adjoint, `A_L` is self-adjoint. The spectrum of a self-adjoint `eta`-idempotent with `eta<1/4` avoids `1/2`, so

\[
Q_L
=
\mathbf1_{[1/2,\infty)}(A_L)
\in
M_v(C_r^*(\Gamma_L))
\tag{6.2}
\]
is a genuine projection.

For a self-adjoint `A` with

\[
\|A^2-A\|\le\eta<1/4,
\]
scalar spectral calculus gives

\[
\left\|\mathbf1_{[1/2,\infty)}(A)-A\right\|
\le
r(\eta)
:=
\frac{1-\sqrt{1-4\eta}}2
\le2\eta.
\]

Therefore

\[
\boxed{
\|Q_L-A_L\|
\le4\varepsilon_L.
}
\tag{6.3}
\]

This estimate is matrix-size independent except for the later unnormalized trace factor `v`.

# 7. Exact trace locking at the finer `(2L)^{-1}` mesh

The trace extracts the coefficient of the identity group element.

The polynomial `A_{infty,L}` has free-factor support radius at most `n_L rho`. Under `(5.3)`, no nontrivial group element in that support can become the identity merely from the new relation `a^L=1`. The `t`-exponent is unchanged by the quotient.

Thus

\[
\boxed{
(\operatorname{Tr}_v\otimes\tau_{\Gamma_L})(A_L)
=
(\operatorname{Tr}_v\otimes\tau_{\Gamma})(A_{\infty,L}).
}
\tag{7.1}
\]

From `(5.6)`,

\[
\left|
(\operatorname{Tr}_v\otimes\tau_{\Gamma})(A_{\infty,L})
-\beta
\right|
\le v\varepsilon_L.
\tag{7.2}
\]

From `(6.3)`,

\[
\left|
(\operatorname{Tr}_v\otimes\tau_{\Gamma_L})(Q_L)
-
(\operatorname{Tr}_v\otimes\tau_{\Gamma_L})(A_L)
\right|
\le4v\varepsilon_L.
\tag{7.3}
\]

Combining `(7.1)`–`(7.3)`,

\[
\left|
(\operatorname{Tr}_v\otimes\tau_{\Gamma_L})(Q_L)-\beta
\right|
\le5v\varepsilon_L
\le\frac5{24L}
<\frac1{4L}.
\tag{7.4}
\]

By `(3.4)`–`(3.5)`, both numbers in `(7.4)` lie in the lattice

\[
\frac1{2L}\mathbb Z,
\]
whose spacing is `1/(2L)`. The error is strictly less than half the spacing. Hence

\[
\boxed{
(\operatorname{Tr}_v\otimes\tau_{\Gamma_L})(Q_L)=\beta.
}
\tag{7.5}
\]

This numerical locking step deliberately does **not** assert that trace determines the full `K_0` class.

# 8. Rank sandwich identifies the actual kernel

Let

\[
P_L=\mathbf1_{\{0\}}(D_L)
\in M_v(L(\Gamma_L)).
\]

At `x=0`, `(4.5)` gives

\[
q_{n_L}(0)
\ge1-\varepsilon_L
>1/2.
\]

Therefore every vector in the true kernel of `D_L` lies in the `Q_L` spectral subspace:

\[
\boxed{P_L\le Q_L.}
\tag{8.1}
\]

Taking finite von-Neumann traces gives

\[
\beta_L
:=
(\operatorname{Tr}_v\otimes\tau_{\Gamma_L})(P_L)
\le
(\operatorname{Tr}_v\otimes\tau_{\Gamma_L})(Q_L)
=
\beta.
\tag{8.2}
\]

But the independent rank theorem `(3.3)` gives

\[
\beta_L\ge\beta.
\tag{8.3}
\]

Thus

\[
\beta_L=\beta.
\]

Since `P_L<=Q_L` and the finite trace is faithful,

\[
\boxed{P_L=Q_L.}
\tag{8.4}
\]

Consequently the actual kernel projection is already in the reduced group C*-algebra, proving `(0.2)`–`(0.3)`.

No stable-rank or cancellation theorem is used. No finite matrix-size bound is hidden: stabilization is absorbed by the completely bounded norm estimate, while `u,v` are the fixed matrix dimensions of `C`.

# 9. Uniform stage gap

For every scalar

\[
0\le x\le\delta_0,
\]
`(4.5)` gives

\[
q_{n_L}(x)
\ge1-\varepsilon_L
>1/2.
\tag{9.1}
\]

Suppose `D_L` had a positive spectral point in `(0,delta_0]`. By continuity of `q_{n_L}`, a nonzero spectral subspace around that point would lie in `Q_L`. Because the spectral interval is bounded away from zero, that subspace is orthogonal to the true kernel projection `P_L`.

This contradicts `(8.4)`.

Therefore

\[
\boxed{
\sigma(D_L)\cap(0,\delta_0]=\varnothing.
}
\tag{9.2}
\]

If `beta>0`, this gives

\[
\sigma(D_L)
\subset
\{0\}\cup[\delta_0,\infty).
\]

If `beta=0`, `(8.4)` gives `Q_L=0`. Because `q_{n_L}(0)>1/2` and remains above `1/2` on a neighborhood of zero, the presence of zero in the spectrum would force a nonzero `Q_L` spectral subspace. Hence zero is not in the stage spectrum, and

\[
\sigma(D_L)
\subset
[\delta_0,\infty).
\]

This proves `(0.4)`.

### Quantifier audit

The theorem says:

> for **every fixed** `delta_0<delta`, eventually the stage gap is at least `delta_0`.

It does not claim one finite `L_0` works simultaneously for all `delta_0` approaching `delta`.

The degree is

\[
n_L
=
O_{\delta,\delta_0,M,v}(\log L),
\]
so the local P40 radius is still only `O(log L)`.

# 11. Positive spectral-edge convergence

Assume `C` is nonzero, so the positive parent spectrum is nonempty, and define

\[
g_\infty
=
\min(\sigma(D_\infty)\setminus\{0\})>0.
\tag{11.1}
\]

For large `L`, Section 9 gives either an isolated zero or an invertible stage. Define

\[
g_L
=
\inf(\sigma(D_L)\setminus\{0\}).
\tag{11.2}
\]

We prove `(0.5)`.

## 11.1 Lower limit

Fix arbitrary

\[
0<\delta_0<g_\infty.
\]

Choose any upper bound

\[
M'>\|D_\infty\|
\]
and apply the plateau theorem with

\[
\delta=g_\infty,
\qquad
M=M'.
\]

Eventually

\[
g_L\ge\delta_0.
\]

Because `delta_0<g_infty` was arbitrary,

\[
\boxed{
\liminf_{L\to\infty}g_L
\ge g_\infty.
}
\tag{11.3}
\]

## 11.2 Upper limit from one finitely supported approximate eigenvector

For a bounded self-adjoint operator, every spectral point lies in the approximate point spectrum. Therefore, for every `epsilon>0`, there exists a unit vector `xi` such that

\[
\|(D_\infty-g_\infty)\xi\|<\varepsilon/2.
\]

Finite-support vectors are dense in

\[
\ell^2(\Gamma)^v,
\]
so after a small perturbation and renormalization we may choose `xi` with finite support and

\[
\boxed{
\|(D_\infty-g_\infty)\xi\|<\varepsilon.
}
\tag{11.4}
\]

Only finitely many group elements occur in `xi` and in `D_infty xi`. For all sufficiently large `L`, the quotient

\[
\Gamma\to\Gamma_L
\]
is injective on every pairwise relation needed to identify those basis vectors. This is ordinary fixed-radius marked-ball agreement; no moving norm statement is invoked.

Transfer the coefficients of `xi` to a stage vector `xi_L`. Then

\[
\|\xi_L\|=1
\]
and the finite residual is coefficientwise identical:

\[
\boxed{
\|(D_L-g_\infty)\xi_L\|
=
\|(D_\infty-g_\infty)\xi\|
<\varepsilon.
}
\tag{11.5}
\]

For a self-adjoint operator,

\[
\operatorname{dist}(g_\infty,\sigma(D_L))
\le
\|(D_L-g_\infty)\xi_L\|,
\]
so the stage spectrum contains a point within `epsilon` of `g_infty`.

Taking `epsilon<g_infty/2` ensures that this nearby point is positive rather than zero. Therefore

\[
\boxed{
\limsup_{L\to\infty}g_L
\le g_\infty.
}
\tag{11.6}
\]

Combining `(11.3)` and `(11.6)` yields

\[
\boxed{g_L\to g_\infty.}
\]

### Scope warning

The proof gives convergence of the **bottom positive spectral edge of this fixed matrix**. It does not prove Hausdorff convergence of the entire spectrum, nor norm convergence for arbitrary moving group-ring elements.
