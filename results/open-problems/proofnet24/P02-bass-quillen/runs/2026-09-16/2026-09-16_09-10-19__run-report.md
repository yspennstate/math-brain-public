# 3. Mandatory imported elementary audits

## 3.1 Rank-one stable cancellation

Let `A` be commutative and let `P` be a finitely generated projective `A`-module of constant rank one. If

`P direct_sum A^m ~= A^(m+1)`,

then taking top exterior powers gives

`det(P direct_sum A^m) ~= P`

and

`det(A^(m+1)) ~= A`.

Hence

`P ~= A`.

This proves only the displayed **rank-one cancellation**. It neither proves that a higher-rank projective is free nor that every projective in the Quillen problem is stably free. No later use of `K_0` in this report is allowed to erase the finite-rank orbit obligation.

## 3.2 `R[1/r]` need not be local

Let

`R=k[x,y]_(x,y)`, `A=R[1/x]`.

Then

`A/(y) ~= k[x]_(x)[1/x] ~= k(x)`

and

`A/(y-x) ~= k[x]_(x)[1/x] ~= k(x)`.

Thus `(y)` and `(y-x)` are maximal ideals of `A`. They are distinct, since equality would put

`x = y-(y-x)`

in their common ideal, whereas `x` is a unit in `A`.

So localization at a parameter need not preserve locality. No local-ring projective-freeness theorem is applied to `R[1/r]` merely because `R` is local.

# 5. Source-verified Vaserstein conventions

For a commutative ring `B`, a unimodular row

`g=(a,b,c)`

and a column

`w=(a',b',c')^T`

with `g w=1`, use the standard Vaserstein alternating matrix

`V(g,w) =`

`[ [ 0,  a,  b,  c ],`
`  [ -a, 0,  c', -b' ],`
`  [ -b,-c', 0,   a' ],`
`  [ -c, b',-a',  0  ] ]`.

Its Pfaffian is `g w=1`. The elementary symplectic Witt group `W_E(B)` is the stable elementary-congruence group of Pfaffian-one invertible alternating matrices, and the Vaserstein symbol sends the elementary orbit of `g` to `[V(g,w)]`.

The explicit matrix convention and Pfaffian-one definition were checked against the van der Kallen / Rao Vaserstein-symbol literature and against Tariq Syed's generalized-Vaserstein-symbol treatment. The inherited dimension-two bijection

`Um_3(B)/E_3(B) -> W_E(B)`

is retained exactly where the archived source check established it; no dimension-three or `1/2` hypothesis is imported from an unrelated theorem.

No comparison with higher Grothendieck–Witt groups is needed for the new algebra below.

# 6. `P02-C155-COMPLETION-VASERSTEIN-SYMPLECTIC-KERNEL` — PROVED

## Statement

Let `B` be a commutative projective-free ring. Let

`g=(a,b,c) in Um_3(B)`.

Choose a completion

`M in SL_3(B)`

whose first row is `g`. Such a completion exists because `ker(g:B^3->B)` is a rank-two projective and is therefore free; orienting a basis adjusts the determinant to one.

Put

`e=(1,0,0)^T`,

`w=M^(-1)e`.

Then `g w=1`. Let

`Psi=V(e^T,e)=psi_2 direct_sum psi_2`.

Then

`boxed( diag(1,M)^T Psi diag(1,M) = V(g,w) ).`       (6.1)

Consequently the Vaserstein symbol of `g` equals the image of the stable special-linear class of `M` under the natural congruence map

`h_B: SK_1(B) -> W_E(B)`.

Moreover, because `B` is projective-free,

`boxed( K_1Sp(B) -> SK_1(B) -> W_E(B) -> 0 )`       (6.2)

is exact, by direct elementary matrix algebra. In particular

`ker h_B = image(K_1Sp(B)->SK_1(B))`.

This proof is characteristic-free.

## Proof of the matrix identity

For a column `x=(x_1,x_2,x_3)^T`, put

`K(x)=`

`[ [0, x_3, -x_2],`
`  [-x_3, 0, x_1],`
`  [x_2,-x_1,0] ]`.

Then

`Psi = [ [0, e^T], [-e, K(e)] ]`

in `1+3` block form. Hence

`diag(1,M)^T Psi diag(1,M)`

has top-right block

`e^T M = g`

and bottom-right block

`M^T K(e) M`.

The standard cross-product / adjugate identity, valid as a polynomial identity over `Z`, is

`M^T K(x) M = det(M) K(M^(-1)x)`

whenever `M` is invertible. Since `det M=1`, this is

`M^T K(e) M = K(M^(-1)e)=K(w)`.

This is exactly (6.1).

The polynomial identity was also independently symbolically expanded during this run: before imposing `det M=1`, the right side is `K(adj(M)e)`, hence after determinant one it is `K(M^(-1)e)`.

Therefore

`V_B([g]) = h_B([M]).`       (6.3)

## Exact kernel

First, the image of `K_1Sp(B)` lies in `ker h_B`: a stable symplectic matrix `S` satisfies

`S^T Psi S=Psi`,

so its congruence class is neutral in `W_E`.

Conversely, suppose `h_B([M])=0`. By the defining stable elementary congruence relation in `W_E`, after adding hyperbolic blocks there is an elementary matrix `E` such that, writing `D` for the corresponding stabilization of `M`,

`D^T Psi D = E^T Psi E`.

Then

`S := D E^(-1)`

satisfies

`S^T Psi S=Psi`,

so `S` is symplectic. Since `E` is elementary, `[S]=[D]=[M]` in stable `K_1`. Thus `[M]` lies in the image of `K_1Sp(B)`.

This proves the kernel equality.

## Surjectivity of `h_B`

Take any Pfaffian-one invertible alternating form on a free module `B^(2n)`. Choose a basis vector `e`. Nondegeneracy makes the corresponding row unimodular, so there is `f` with `omega(e,f)=1`. The hyperbolic plane spanned by `e,f` splits orthogonally. Its orthogonal complement is projective; projective-freeness of `B` makes it free. Iterating gives a symplectic basis.

Thus every Pfaffian-one alternating matrix `A` is

`A=G^T Psi G`

for some `G in GL_(2n)(B)`. The Pfaffian identity

`Pf(G^T Psi G)=det(G) Pf(Psi)`

and `Pf(A)=Pf(Psi)=1` give `det G=1`. Hence the class of `A` lies in the image of `h_B`.

Therefore (6.2) is exact.

## Scope

This is not a general theorem that `SK_1=W_E`. It identifies the exact symplectic kernel. It also does not use or claim an all-characteristic identification between elementary `W_E` and any chosen higher Grothendieck–Witt group.

# 8. `P02-C157-N1-CANONICAL-ZEROCYCLE-QUOTIENT` — PROVED

`SL_2(B)=Sp_2(B)`

for the standard rank-two symplectic form. Therefore the stable class `[H]` lies in the image of `K_1Sp(B)`. Since

`[M']-[M]=[H]`

in `SK_1(B)`, we obtain

`beta([M'])-beta([M]) in Sigma_alpha`.

Hence

`boxed( zeta_g := zeta_g(M) mod Sigma_alpha in CH_0(X)/Sigma_alpha )`       (8.1)

is independent of the chosen completion.

C154 already gives independence from the arbitrary denominator-clearing exponent used to compute `beta([M])` from a torsion cokernel.

`product_x [ cos(theta) + i f(x)(-1)^(xi dot x) sin(theta) ]`.

`i^|A| f_A (-1)^(xi dot xor(A)) sin(theta)^|A| cos(theta)^(N-|A|)`.

`exp(i theta sum_x f(x)(-1)^(xi dot x))`

`= exp(i s fhat(xi))`.

`(1/N) sum_xi cos(s fhat(xi))`.
