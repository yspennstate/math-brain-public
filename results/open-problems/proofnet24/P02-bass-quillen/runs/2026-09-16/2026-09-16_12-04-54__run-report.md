# 2. Mandatory elementary audits, rederived

## 2.1 Rank-one stable cancellation is only rank one

Let `A` be commutative and `P` finite projective of constant rank one. If

```text
P direct_sum A^m ~= A^(m+1),
```

then taking the top exterior power gives

```text
det(P direct_sum A^m)
 ~= P tensor det(A^m)
 ~= P,
```

while

```text
det(A^(m+1)) ~= A.
```

Hence `P~=A`.

This proves only the displayed rank-one cancellation. It neither proves stable freeness of an arbitrary projective nor cancels ranks two or three. Those ranks require the actual unstable unimodular-row/orbit obligation.

## 2.2 `R[1/r]` need not be local

Let

```text
R=k[x,y]_(x,y),
A=R[1/x].
```

Then

```text
A/(y) ~= k[x]_(x)[1/x] ~= k(x),
A/(y-x) ~= k[x]_(x)[1/x] ~= k(x).
```

Thus `(y)` and `(y-x)` are maximal ideals of `A`. They are distinct, because equality would put

```text
y-(y-x)=x
```

in their common ideal, but `x` is a unit in `A`.

Therefore localization at a parameter need not be local. No local-ring projective-freeness theorem is applied to `R[1/r]` merely because `R` was local.

# 4. `P02-C165-PROJECTIVEFREE-SURFACE-POINT-CI` — PROVED

## Statement

Let `C` be a Noetherian regular domain of dimension `2`. Assume every finitely generated projective `C`-module is free. Let `n` be a maximal ideal of height `2`. Then

```text
boxed( n is generated by two elements. )
```

Equivalently, every codimension-two closed point of `Spec C` is a **global** complete intersection, not merely a local one.

This is the exact global input needed to replace the previous conductor-parity route.

## Proof

Put

```text
k=C/n.
```

Apply `Hom_C(-,C)` to

```text
0 -> n -> C -> k -> 0.
```

Because `Ext^i_C(C,C)=0` for `i>0`, the long exact Ext sequence gives

```text
Ext^1_C(n,C) ~= Ext^2_C(k,C).            (4.1)
```

The module on the right is supported at `n`. Localize at `n`. Since

```text
C_n
```

is a regular local ring of dimension two, choose a regular system of parameters `x,y`. The Koszul resolution

```text
0 -> C_n -> C_n^2 -> C_n -> k -> 0
```

shows directly that

```text
Ext^2_{C_n}(k,C_n) ~= k.                 (4.2)
```

Finite free resolutions commute with localization in the degrees at issue, so

```text
Ext^2_C(k,C)_n ~= k.
```

Choose an extension class `xi in Ext^1_C(n,C)` whose localization at `n` is nonzero, and represent it by

```text
0 -> C -> P -> n -> 0.                  (4.3)
```

We show that `P` is locally free of rank two.

### Away from `n`

If `p != n`, then some element of `n` is outside `p`, hence

```text
n_p=C_p.
```

The localized extension is therefore

```text
0 -> C_p -> P_p -> C_p -> 0,
```

which splits because the quotient is free. Thus

```text
P_p ~= C_p^2.
```

### At `n`

Put `R=C_n` and `m=nR`. The parameter Koszul sequence

```text
0 -> R -> R^2 -> m -> 0                 (4.4)
```

represents a nonzero class of

```text
Ext^1_R(m,R) ~= Ext^2_R(k,R) ~= k.
```

The localized class `xi_n` is nonzero. Since this Ext group is one-dimensional over `k`, `xi_n` differs from the class of (4.4) by a nonzero scalar. Lift that scalar to a unit of `R`. Pushing out (4.4) by multiplication with this unit changes the extension class but not the isomorphism type of its middle free module. Hence

```text
P_n ~= R^2.
```

Therefore `P` is finitely presented and all of its prime localizations are free of rank two. By the finite-projective local criterion,

```text
P is finite projective of rank 2.
```

By the projective-freeness hypothesis,

```text
P ~= C^2.
```

The quotient map in (4.3) is then a surjection

```text
C^2 -> n,
```

so `n` is generated by two elements.

QED.

## Why this is genuinely stronger than local regularity

Regularity already says `n C_n` needs two generators. C165 proves that two generators can be chosen **globally in `C`**. The global step is exactly where projective-freeness is used.

# 5. `P02-C166-POINT-SYMPLECTIC-BOUNDARY` — PROVED

## Statement

Let `C` be a regular domain of dimension two. Let `q in C` be nonzero and let `n` be a height-two maximal ideal with `q in n`. Assume

```text
n=(a,b).
```

Put

```text
A0=C/(q),
B=C[1/q].
```

Then there is an explicit matrix

```text
M_n in SL_2(B)=Sp_2(B)
```

whose Quillen localization boundary is

```text
boxed( partial[M_n] = -[C/n] )
```

modulo the generic component class `[C/q]`. Thus the closed-point zero-cycle class of `n` lies in the stable symplectic image.

## Construction

Because `q in n=(a,b)`, choose `c,d in C` with

```text
q=ac+bd.
```

Define

```text
K = [ -b   c ]
    [  a   d ].
```

Then

```text
det K = -q.                              (5.1)
```

Since `C` is a domain and `q!=0`, `K:C^2->C^2` is injective.

The row `(a,b)` satisfies

```text
(a,b)K=(0,q).
```

Hence it induces a surjection

```text
coker K -> n/qC.
```

We now prove this is an isomorphism.

Let `(X,Y)` map to zero in `n/qC`; equivalently

```text
aX+bY=qh=(ac+bd)h
```

for some `h in C`. Therefore

```text
a(X-ch)+b(Y-dh)=0.
```

Because `(a,b)=n` has height two in the regular Cohen–Macaulay domain `C`, the two generators form a regular sequence. The first Koszul syzygy is therefore the whole syzygy module, so for some `t in C`,

```text
X-ch=-bt,
Y-dh= at.
```

Thus

```text
(X,Y)=t(-b,a)+h(c,d),
```

which is in the column image of `K`. Hence

```text
boxed( coker K ~= n/qC = n A0. )         (5.2)
```

Now set

```text
D=diag((-q)^(-1),1),
M_n=K D.
```

By (5.1),

```text
det M_n=1,
```

so

```text
M_n in SL_2(B)=Sp_2(B).
```

For localization `C -> B`, the boundary of `K` is its torsion cokernel:

```text
partial[K]=[n A0].
```

The scalar factor contributes

```text
partial[D]=-[A0],
```

because the boundary of `q^{-1}` is `-[C/q]`; the sign unit `-1` has zero boundary. Consequently

```text
partial[M_n]=[n A0]-[A0].                (5.3)
```

Finally the exact sequence

```text
0 -> n A0 -> A0 -> C/n -> 0
```

gives

```text
boxed( partial[M_n]=-[C/n]. )            (5.4)
```

Because `M_n` is already a `2x2` symplectic matrix, its stable `K_1` class belongs to

```text
im(K1Sp(B)->SK1(B)).
```

Thus every globally two-generated height-two closed point on the divisor is symplectically hit by an explicit finite matrix.

QED.

## Important feature

No smoothness of `C/(q)`, no normal-crossing condition, no algebraically closed residue field, and no `2^{-1}` assumption occurs. Singular intersection points are included.

# 9. `P02-C170-ALLN-SECOND-LOCALIZATION-IDENTITY` — PROVED

The useful two-stage localization is not special to `N=1`.

Let

```text
F=r^N+u alpha,
S_N=R/(F).
```

In `S_N`,

```text
r^N=-u alpha.                            (9.1)
```

Set

```text
C_N=S_N[1/u].
```

Then for every `N>=1`,

```text
boxed( S_N[1/r] = S_N[1/u,1/alpha] = C_N[1/alpha]. )   (9.2)
```

Indeed, if `r` is inverted then `r^N` is a unit, so by (9.1) the product `u alpha` is a unit. In a commutative ring, if a product is a unit then each factor is a unit. Conversely, if `u` and `alpha` are inverted then (9.1) makes `r^N` a unit, hence `r` is a unit.

Thus the `N>=2` rank-three problem can still be viewed as a second principal localization from

```text
C_N=S_N[1/u]
```

to

```text
B_N=C_N[1/alpha].
```

The missing feature is no longer the algebraic identity; it is the regular/projective-free structure of `C_N`.
