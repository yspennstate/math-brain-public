# 3. Required elementary audits, rederived

## 3.1 Rank-one stable cancellation

Let `A` be commutative and let `P` be rank-one projective. If

`P direct_sum A^m ~= A^(m+1)`,

then taking the top exterior power gives

`P ~= det(P direct_sum A^m) ~= det(A^(m+1)) ~= A`.

This proves only this rank-one stable-to-actual implication. It is not higher-rank cancellation, not arbitrary freeness over `R[1/r]`, and not Bass–Quillen.

## 3.2 Localization at a parameter is not automatically local

For a field `k`, let

`R=k[x,y]_(x,y)`, `A=R[1/x]`.

Then

`A/(y) ~= k[x]_(x)[1/x] ~= k(x)`

and substitution `y=x` gives

`A/(y-x) ~= k(x)`.

Hence `(y)` and `(y-x)` are maximal. They are distinct because equality would put their difference `x` in a proper ideal even though `x` is a unit in `A`.

Thus local-ring freeness cannot be invoked on `R[1/r]` without proving locality.

# 5. `P02-C103-r-ADIC-COLON-FAITHFULNESS` — PROVED

## Statement

Let `(R,m)` be Noetherian local, `r in m`, and let

`B = Rhat = lim_n R/r^n`

be the `r`-adic completion. Let `K subset R` be an ideal. Then for every `q>=0`,

`(K:r^q)B = KB : r^q`.  (5.1)

Consequently,

`(K:r^infty)B = KB:r^infty`.  (5.2)

Moreover the exact stabilization depth

`delta_r(K) = min{q : K:r^q = K:r^infty}`

is preserved:

`delta_r(K)=delta_r(KB)`.  (5.3)

Finally, for every `alpha in R` and every `q>=0`,

`r^q alpha in K+r^(q+1)R`

if and only if

`r^q alpha in KB+r^(q+1)B`,  (5.4)

and

`alpha in (K:r^q)+rR`

if and only if

`alpha in (KB:r^q)+rB`.  (5.5)

## Proof

Put `M=R/K`. Multiplication by `r^q` gives

`0 -> (K:r^q)/K -> M --r^q--> M`.

The map `R->B` is flat, so tensoring preserves the kernel. Since

`M tensor_R B ~= B/KB`,

we obtain

`((K:r^q)/K) tensor_R B ~= ker(r^q:B/KB -> B/KB)`

`= (KB:r^q)/KB`.

The left side is `(K:r^q)B/KB`, proving (5.1).

Because `R` is Noetherian, the ascending colon chain stabilizes. Choose `q0` with

`K:r^q0 = K:r^infty`.

Equation (5.1) then gives (5.2). Conversely, suppose the completed colon chain stabilizes at stage `q`. Then

`[(K:r^(q+1))/(K:r^q)] tensor_R B = 0`

by (5.1). Faithful flatness forces the quotient itself to vanish. Hence stabilization happens at exactly the same first stage, proving (5.3).

For (5.4), use the canonical quotient isomorphism

`R/r^(q+1)R ~= B/r^(q+1)B`.

Under it, the image of `K` is exactly the image of `KB`. Thus membership of the class of `r^q alpha` in that image is identical on the two sides.

For (5.5), combine (5.1) with faithful-flat contraction of ideals:

`[(K:r^q)+rR]B = (KB:r^q)+rB`

and `JB intersect R=J` for every ideal `J` under a faithfully flat map. This proves the claim.

## Consequence

Every finite C62/C69 colon-stage certificate and every exact first successful colon depth is unchanged by the C100 completion reduction. Completion is not a finite-stage repair mechanism.

# 6. `P02-C104-BOCKSTEIN-COMPLETION-RIGIDITY` — PROVED

Retain the C71 notation for a finitely generated tail

`K=(g_1,...,g_t)`.

For `q>=1`, put

`S_q=R/r^qR`,

`Z_q=Syz_{S_q}(gbar_1,...,gbar_t)`,

`Q=R/(K+rR)`.

The higher Bockstein is

`beta_{K,q}:Z_q -> Q`,

where a syzygy `cbar` is lifted to `c_i in R`, one writes

`sum c_i g_i = r^q t`,

and sets

`beta_{K,q}(cbar)=t mod (K+rR)`.

Let `B=Rhat` and `Khat=KB`. Because completion gives canonical isomorphisms

`R/r^qR ~= B/r^qB`

and

`R/(K+rR) ~= B/(Khat+rB)`,

the source syzygy module and target quotient for the completed Bockstein are canonically the same modules. A finite syzygy class over the completion has a representative over `R` because the finite quotient rings are identical. For such a representative the defining equality

`sum c_i g_i=r^q t`

is literally the same equality after extension to `B`.

Therefore

`boxed(beta_{K,q} = beta_{Khat,q})`  (6.1)

under the canonical finite-quotient identifications.

In particular,

`[alpha] in im beta_{K,q}`

if and only if

`[alpha] in im beta_{Khat,q}`.  (6.2)

Thus C65's first Bockstein, C66's Hilbert–Burch first-defect criterion, and the full C71 Bockstein ladder survive completion **exactly**, not merely up to a comparison map.

This is stronger than saying that the colon ideals base-change: the actual finite obstruction maps are unchanged.

# 8. `P02-D32-COMPLETION-NO-COLON-CUTOFF` — explicit mixed-characteristic H4 stress test

C72 previously showed arbitrary colon depth in an equicharacteristic complete example. The same phenomenon occurs directly in the mixed-characteristic H4 branch and survives completion.

Fix a prime `p` and let

`R=Z_p[[u,x,y]]`,

so `R` is a complete regular local ring of dimension four with maximal ideal `(p,u,x,y)`. Set

`r=p`, `A=R[1/p]`.

For any `m>=1`, put

`F=p+ux`, `f=F/p=1+ux/p`,

`g_1=p^m x-F`,

and consider

`v_m=(f, u g_1, uy, 0)`.

## 8.1 Unimodularity

Modulo `f`, one has `F=0`, hence

`ux=-p`.

Since `p` is a unit in `A`, the product `ux` is a unit, so both `u` and `x` are units in `A/fA`. Consequently

`g_1 = p^m x`

is a unit modulo `f`. Thus `v_m` is unimodular.

## 8.2 Allowed source twist and exact colon depth

The elementary operation adding `up` times the first coordinate to the second sends

`u(p^m x-F)`

to

`u p^m x`.

The resulting integral tail is

`K_m=(p^m x,y)`.

For `0<=q<=m`,

`K_m:p^q=(p^(m-q)x,y)`.  (8.1)

Indeed, modulo `y` the ring is the domain `Z_p[[u,x]]`; cancellation of `p^q` proves the formula. At `q=m`, the colon is `(x,y)`, and it is already `p`-saturated because `p` is a nonzerodivisor modulo `(x,y)`.

Take `alpha=x`. For `q<m`, reducing modulo `(p,y)` gives

`x notin (K_m:p^q)+pR`,

whereas at `q=m`,

`x in K_m:p^m`.

Thus the first successful C69/C71 colon-Bockstein stage is exactly `m`, arbitrarily large, even though `R` is already `p`-adically complete and mixed characteristic.

## 8.3 Yet the row is elementary-trivial

After the source twist the row is

`(1+ux/p, u p^m x, uy,0)`.

Adding `-p^{-(m+1)}` times the second coordinate to the first changes the first coordinate by

`-u p^m x p^{-(m+1)}=-ux/p`,

so the first coordinate becomes exactly `1`.

Therefore every `v_m` is elementary-trivial although its first saturation certificate can be pushed to arbitrary depth.

## Verdict

The method claim

> `r`-adic completion should bound the required colon depth, or should turn a failed finite Bockstein stage into a successful one

is **DISPROVED**.

This is a method failure, not a counterexample to Quillen.

# 9. `P02-D33-COMPLETION-DOES-NOT-MAKE-LOCAL` — mixed-characteristic dimension-four counterexample

The original nonlocality warning survives the C100 completion reduction.

Let

`B=Z_(p)[y,z]_(p,y,z)`

and

`R=B[[r]]`.

Then `R` is a regular local ring of dimension four, mixed characteristic, with regular parameter `r`, and it is `r`-adically complete. Put

`A=R[1/r]`.

Consider

`M_1=(p,y,z)A`,

`M_2=(p,z,y-r)A`.

For the first ideal,

`A/M_1 ~= F_p[[r]][1/r] ~= F_p((r))`,

so `M_1` is maximal.

For the second, reduce first modulo `(p,z)`. One obtains

`F_p[y]_(y)[[r]]/(y-r)`.

Substitution `y=r` identifies this quotient with `F_p[[r]]` (equivalently, quotienting by the monic linear relation `r-y` completes `F_p[y]_(y)` in the `y`-adic topology). After inverting `r`,

`A/M_2 ~= F_p((r))`,

so `M_2` is also maximal.

They are distinct: if `M_1=M_2`, their common ideal would contain

`y-(y-r)=r`,

but `r` is a unit in `A`.

Hence even an `r`-adically complete mixed-characteristic regular local H4 ring can have a nonlocal `R[1/r]`.

So C100 cannot be followed by “the completed localization is local, hence projectives are free.”

# 10. `P02-C106-FIXED-WORD-FORMAL-COMPACTNESS` — PROVED

C103-C105 show that completion gives no new finite Bockstein information. The positive use of completion is instead a coherent all-orders lifting principle.

## Statement

Assume now that `R` is `r`-adically complete and separated. Let

`A=R[1/r]`,

`v in Um_m(A)`.

Fix once and for all:

- a finite elementary-word pattern
  `E(X_1,...,X_L)=prod_{j=1}^L E_{a_j b_j}(X_j)`;
- denominator exponents `d_1,...,d_L>=0`.

Then the following are equivalent.

**(i)** There exist `a_1,...,a_L in R` such that

`v E(r^{-d_1}a_1,...,r^{-d_L}a_L)=e_1`.  (10.1)

**(ii)** There are compatible inverse systems

`a_{j,n} in R/r^nR`

for `j=1,...,L`, such that after choosing any compatible lifts and clearing one fixed common denominator `r^D` (depending only on `v`, the word, and the fixed `d_j`),

`r^D [v E(r^{-d_1}a_{1,n},...,r^{-d_L}a_{L,n})-e_1]`

vanishes modulo `r^n` for every `n`.  (10.2)

## Proof

(i) implies (ii) by reduction modulo `r^n`.

Conversely, compatibility gives unique limits

`a_j in R=lim_n R/r^nR`.

A fixed finite elementary word has matrix entries that are polynomials with integer coefficients in the parameters. Because the word length and denominator exponents are fixed, one finite exponent `D` clears every denominator occurring in

`v E(r^{-d_1}a_1,...,r^{-d_L}a_L)-e_1`.

Call the resulting integral vector `w in R^m`. Condition (10.2) says

`w in r^n R^m`

for every `n`. Since `R` is `r`-adically separated,

`intersection_n r^n R=0`,

so `w=0`. This proves (10.1).

## Why the hypotheses matter

- **Compatibility matters.** Existence of unrelated solutions modulo every `r^n` does not supply an inverse-limit point unless a compatible branch is produced.
- **Uniform denominator bounds matter.** An element of `R[1/r]` has a finite denominator exponent. A formal procedure whose required negative powers of `r` grow without bound does not automatically define an element of the localization.
- **Fixed finite word matters.** If the word length itself diverges, the limiting object need not be a finite elementary product.

Thus the completed rank-three problem has a precise new target: construct a compatible lifting theorem for a fixed rank-three factorization/orbit word with bounded denominators. This is a genuine formal/Henselian obligation, not another finite colon computation.

**Claim:** `P04-T4-VOLUME-ALIGNMENT-41`  
**Verdict:** **PASS** for the exact stated volume-biased mean-square alignment theorem; no verdict on ordinary-law inverse-volume transfer or full Target 4.

The claim assumes an `(m+1) x m` matrix `H` with iid centered rows, full column rank almost surely, and enough integrability for the Gram determinant. Let

`c_i=(-1)^(i+1) det(H_{-i})`.

The cofactor vector satisfies `H^T c=0`, and Cauchy–Binet gives

`sum_i c_i^2 = det(H^T H)`.

Hence for the unit null vector `v=c/||c||` and volume-biased law

`dQ/dP = det(H^TH)/E det(H^TH)`, one has

`E_Q (1^T v)^2 = E_P (sum_i c_i)^2 / E_P sum_i c_i^2`.

For `i != j`, condition on all rows except row `i`. Then `c_i` is independent of row `i`, while `c_j` is linear in row `i`, with coefficients fixed by the conditioning. Centering gives

`E[c_i c_j | other rows]=0`.

Therefore all cross terms vanish and

`E_P (sum_i c_i)^2 = sum_i E c_i^2 = E det(H^TH)`.

Thus

`E_Q(1^T v)^2=1`.

The proof is exact. It uses neither isotropy nor a Schur-complement inverse-Gram estimate. In particular it **does not** justify transfer back from the volume-biased law to the ordinary iid law, where the Radon–Nikodym derivative involves an inverse determinant. P04 correctly leaves that hard-edge obligation open.
