# 2. Required elementary audits

## 2.1 Rank one

Let `A` be commutative and `P` a rank-one finitely generated projective. If

`P direct_sum A^m ~= A^(m+1)`,

then taking top exterior powers gives

`det(P direct_sum A^m) ~= P`,

while

`det(A^(m+1)) ~= A`.

Hence `P ~= A`.

This proves only rank-one cancellation under the displayed stable-freeness premise. It does not prove higher-rank cancellation or Bass–Quillen.

## 2.2 `R[1/r]` need not be local

Let

`R=k[x,y]_(x,y)`, `A=R[1/x]`.

Then

`A/(y) ~= k[x]_(x)[1/x] ~= k(x)`

and likewise

`A/(y-x) ~= k(x)`.

Thus `(y)A` and `(y-x)A` are maximal. They are distinct: equality would imply their difference `x` belongs to the common ideal, but `x` is a unit in `A`.

Therefore localization of a regular local ring at a parameter need not be local. No projective-freeness theorem for local rings may be applied to `A` without separately proving locality.

Let `R` be regular local of dimension four and `r` a regular parameter. Then `R/(r)` is regular local of dimension three. The localization sequence gives

`K_0(R/(r)) -> K_0(R) -> K_0(A) -> K_{-1}(R/(r))`.

# 5. New theorem `P02-C68-FINITE-JET-SATURATION` — PROVED

Let

`K_h=(g_1,g_2,g_3)`

with

`g_i=k_i+h_iF`, `F=r^N+u alpha`, `N>=1`.

Fix `q>=1`. Let another twist satisfy

`h'_i=h_i+r^q z_i`, `z_i in R`.

Then

`g'_i=g_i+r^q z_i F`.

The claim is

`r^q alpha in K_h+r^(q+1)R`

if and only if

`r^q alpha in K_h'+r^(q+1)R`.

## Proof

Assume first

`r^q alpha = sum_i c_i g'_i + r^(q+1)s`.

Substitute `g'_i=g_i+r^q z_iF`:

`r^q alpha = sum_i c_i g_i + r^q F sum_i c_i z_i + r^(q+1)s`.

Because `N>=1`,

`F = u alpha + r^N congruent u alpha mod r`.

Therefore, modulo `K_h+r^(q+1)R`,

`r^q alpha congruent r^q u alpha C`,

where

`C=sum_i c_i z_i`.

Hence

`r^q alpha (1-uC) in K_h+r^(q+1)R`.

Since `u in m` and `R` is local, `1-uC` is a unit. Multiplying by its inverse gives

`r^q alpha in K_h+r^(q+1)R`.

The converse is identical after interchanging `h` and `h'`.

Thus

**stage-`q` capture depends only on `(h_1,h_2,h_3) mod r^q`.**

No completeness, approximation or characteristic hypothesis is used.

### Immediate consequences

1. At `q=1`, only the special-fiber residues `bar h_i in S=R/rR` matter.
2. At fixed `q`, tuning deeper `r`-adic coefficients is provably useless.
3. The colon search at stage `q` factors through `(R/r^q)^3`.
4. This theorem is compatible with C63: the successful C63 move changes `h` from `0` to `1`, which is visible modulo `r`. C68 does not forbid it.

# 6. New theorem `P02-C69-FINITE-CAPTURE-CERTIFICATE` — PROVED

Let

`J_h=K_h:r^infty`.

Then

`alpha in J_h+rR`

if and only if there is a finite integer `q>=0` such that

`r^q alpha in K_h+r^(q+1)R`.

This is the C62 saturation criterion, but C68 upgrades it to a finite-jet statement:

> If a source-changing twist succeeds at all, then some finite `q` certifies success, and **every** twist with the same `q`-jet succeeds at the same stage.

## Proof of the finite criterion

If

`alpha=j+r beta`, `j in J_h`,

then by definition of saturation there exists `q` with

`r^q j in K_h`.

Multiplying the first equality by `r^q` gives

`r^q alpha in K_h+r^(q+1)R`.

Conversely, if

`r^q alpha=k+r^(q+1)beta`, `k in K_h`,

then

`alpha-r beta in K_h:r^q subset J_h`,

so `alpha in J_h+rR`.

C68 now shows that the witness depends only on the `q`-jet of `h`.

## Meaning for approximation/descent

This is a genuine finite certificate. A successful saturation move never requires an infinite `r`-adic convergence argument: some finite colon stage already records it. This does **not** automatically descend the whole H4 problem to finite type, but it removes one possible completion obstruction. Any proposed approximation theorem now only has to preserve finitely many coefficients and one finite ideal-membership identity for the source-move certificate.

# 7. New theorem `P02-C70-FIRST-DEFECT-JET-LAW` — PROVED

Specialize C68 to `q=1` and retain the C65 Bockstein notation.

Let

`h'=h+r z`,

coordinatewise. Then the special-fiber generators are identical, so `K_h` and `K_h'` have the same `bar K` in `S=R/rR`, the same syzygy module, and the same quotient

`Q=S/bar K`.

Let

`a=bar alpha`.

For a syzygy `bar c=(bar c_1,bar c_2,bar c_3)`, choose lifts `c_i` and write

`sum_i c_i g_i = r t`.

Then

`sum_i c_i g'_i`

`= r t + r F sum_i c_i z_i`

`= r [t+F sum_i c_i z_i]`.

Reducing after division by `r`, and using `bar F=u a`, gives the exact transformation law

`beta_h'(bar c)`

`= beta_h(bar c) + u a sum_i bar c_i bar z_i`

in `Q`.

Therefore

`a in im beta_h'`

if and only if

`a in im beta_h`.

Indeed, if

`a=beta_h'(bar c)=beta_h(bar c)+u a q`,

then

`(1-uq)a=beta_h(bar c)`.

The image of `u` lies in the maximal ideal of the local quotient `Q`, so `1-uq` is a unit; `im beta_h` is an `S`-submodule, hence `a in im beta_h`. The reverse implication follows symmetrically.

## Hilbert–Burch form

In the perfect height-two setting of C66, keep the same lifted Hilbert–Burch matrix `Phi`. If

`(g_1,g_2,g_3)Phi = r(tau_1,tau_2)`,

then

`(g'_1,g'_2,g'_3)Phi`

`=r[(tau_1,tau_2)+F z Phi]`.

Thus modulo `r`,

`bar tau'_j = bar tau_j + u a sum_i bar z_i bar phi_ij`.

Consequently the capture condition

`a in (bar tau_1,bar tau_2) subset Q`

is invariant under all changes `h -> h+r z`.

So the perfect height-two `q=1` search is intrinsically a **special-fiber residue problem**. No choice of deeper lift can rescue a failed residue choice.

# 8. New eliminated route `P02-D23-HIGHER-JET-TUNING` — DISPROVED AS A METHOD

The following proposed strengthening is false as a proof strategy:

> “Fix the source-twist residue classes modulo `r`, then tune sufficiently deep `r`-adic digits of the coefficients until first-colon saturation captures `alpha`.”

C68/C70 prove the opposite: once the residue class modulo `r` is fixed, the `q=1` answer is fixed. More generally, once the `q`-jet is fixed, the stage-`q` answer is fixed.

This is a **method elimination**, not a counterexample to Quillen freeness.

### Positive stress test: C63 survives

C63 changes the relevant twist coefficient from residue `0` to residue `1` modulo `r`; hence C68 permits the first-colon answer to change. Once the residue is `1`, replacing the coefficient by `1+r z` cannot destroy first-stage capture, exactly as C70 predicts.

### Negative stress test: D22 survives

D22 shows that merely lowering the special-fiber height to two does not force capture. C70 strengthens that lesson: for a fixed failed residue-level height-two configuration, no higher `r`-adic adjustment of the same source twist can repair the first-colon defect.
