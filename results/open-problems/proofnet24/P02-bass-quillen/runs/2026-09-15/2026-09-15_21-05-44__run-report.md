# 3. Required elementary audits, rederived

## 3.1 Rank one

Let `A` be commutative and `P` a rank-one finitely generated projective. If

`P direct_sum A^m ~= A^(m+1)`,

then taking the top exterior power gives

`P ~= det(P direct_sum A^m) ~= det(A^(m+1)) ~= A`.

This proves only the stated rank-one cancellation. It does not cancel higher-rank stably free modules.

## 3.2 `R[1/r]` need not be local

Let

`R=k[x,y]_(x,y)`, `A=R[1/x]`.

Then

`A/(y) ~= k[x]_(x)[1/x] ~= k(x)`

and, by substituting `y=x`,

`A/(y-x) ~= k(x)`.

Thus `(y)` and `(y-x)` are maximal. They are distinct because equality would put their difference `x` in a proper ideal, although `x` is a unit in `A`.

Therefore no local-ring freeness theorem may be applied to `R[1/r]` without proving locality.

# 6. `P02-C107-COMMON-TAIL-DESATURATION` — PROVED

## Statement

Let `R` be a commutative ring. Let `F,a in R` satisfy:

1. multiplication by `F` on `R` is injective;
2. multiplication by the image of `a` on `R/(F)` is injective.

For `g=(g_1,...,g_m)` define

`M_a = ker( F, -a g_1, ..., -a g_m : R^(m+1) -> R )`

and

`M_1 = ker( -F, g_1, ..., g_m : R^(m+1) -> R )`.

Then

`boxed{ M_a ~= M_1 }`.  (6.1)

## Proof

Define

`Phi : M_1 -> M_a`,

`Phi(t,z_1,...,z_m)=(a t,z_1,...,z_m)`.

If `(t,z) in M_1`, then

`-F t + sum g_i z_i = 0`,

so

`F(a t)-a sum g_i z_i = 0`.

Thus `Phi` lands in `M_a`.

For surjectivity, let `(s,z) in M_a`. Then

`F s = a sum g_i z_i`.  (6.2)

Reducing modulo `F`, the regularity of `a mod F` gives

`sum g_i z_i = F t`

for some `t in R`. Substituting in (6.2) gives

`F(s-a t)=0`.

Since `F` is a nonzerodivisor, `s=a t`. Therefore `(s,z)=Phi(t,z)`.

For injectivity, if `Phi(t,z)=0`, then `z=0`. Since `(t,z) in M_1`, also `F t=0`, so `t=0`. Hence `Phi` is an isomorphism.

## Interpretation

The statement is stronger than a stable-class comparison. Under the regular-pair condition `(F,a)`, a common factor on all tail coordinates may be removed from the **actual first syzygy module**. Therefore a relative-tail obstruction that sees only this common factor cannot by itself be an invariant of rank-three freeness.

# 7. `P02-C108-UNIT-NUMERATOR-DESATURATION` — PROVED

## Statement

Under the C92 hypotheses in the four-dimensional H4 laboratory,

`v=(F/r^N,ub,uc,ud) in Um_4(A)`,

with `alpha` a unit and `r,u` tangent-independent. Put

`q=(-F,b,c,d) in R^4`.

Then

`boxed{ ker(v:A^4->A) ~= ker(q:A^4->A) }`.  (7.1)

## Proof

Multiplying the row `v` by the unit `r^N in A^x` does not change its kernel. We obtain

`w=(F,r^N u b,r^N u c,r^N u d)`.

For each tail coordinate apply the integral elementary source-to-tail operation

`w_j -> w_j - u g_j w_0`,

where `(g_1,g_2,g_3)=(b,c,d)`. Since

`r^N-F=-u alpha`,

the resulting row is

`w'=(F,-u^2 alpha b,-u^2 alpha c,-u^2 alpha d)`.  (7.2)

Set `a=u^2 alpha`.

By C92, `S=R/(F)` is a regular local domain and the image of `r` is a nonzero parameter. In `S`,

`r^N = -u alpha`.

Because `alpha` is a unit and `r` is nonzero in the domain `S`, the image of `u`, hence the image of `a`, is nonzero. Thus `a` is a nonzerodivisor on `S`. Also `F` is a nonzerodivisor in the regular local domain `R`.

C107 applies to (7.2), giving over `R`

`ker(w') ~= ker(-F,b,c,d)`.

Finally localize at `r`. Unit scaling and elementary column operations preserve kernels up to canonical free-source isomorphism, proving (7.1).

## Consequence

In the transverse unit-numerator branch, the common relative factor `u` can be removed from the projective-module problem. The live rank-three object may be taken to be the ordinary integral row

`q=(-F,b,c,d)`.

This is a new reason not to keep attacking the old relative tail merely through deeper `u`/`r`-saturation.

# 8. `P02-C109-DEPTH-TWO-FULL-IDEAL-CLOSURE` — PROVED

## Statement

Let `(R,m)` be a four-dimensional regular local ring, let `r` be a parameter, `A=R[1/r]`, and let

`q=(q_0,q_1,q_2,q_3) in R^4`

be such that `q_A` is unimodular. Put

`I=(q_0,q_1,q_2,q_3)`

and

`M=ker(q:R^4->I)`.

If

`depth_R(R/I) >= 2`,  (8.1)

then

`boxed{ M ~= R^3,  ker(q_A) ~= A^3 }`.  (8.2)

Moreover, suppose `q` is **r-primitive**, meaning `I` is not contained in `(r)`. Then `ht I>=2`, and for proper `I`, condition (8.1) is equivalent to

`ht I=2` and `R/I` Cohen–Macaulay.  (8.3)

## Proof

From

`0 -> I -> R -> R/I -> 0`

and `depth R=4`, the depth lemma gives

`depth I >= min(4, depth(R/I)+1) >= 3`.

From

`0 -> M -> R^4 -> I -> 0`

we get

`depth M >= min(4, depth I+1)=4`.

Every finite module over a regular local ring has finite projective dimension. Auslander–Buchsbaum gives

`pd_R M + depth_R M = 4`,

so `pd_R M=0`. Thus `M` is projective, hence free because `R` is local. Its generic rank is three, proving (8.2).

Now assume `r`-primitivity. Since `q_A` is unimodular, `IA=A`, so some power `r^L` lies in `I`. If `ht I=1`, choose a height-one prime `P` minimal over `I`. Then `r in P`. Because `r` is a regular parameter, `R/(r)` is regular local and `(r)` is prime of height one. Hence `P=(r)`, forcing `I subset (r)`, contrary to primitivity. Therefore `ht I>=2`.

In dimension four, `depth(R/I)>=2` implies `dim(R/I)>=2`, so together with `ht I>=2` it forces `ht I=2`; then depth equals dimension and the quotient is Cohen–Macaulay. The converse is immediate.

## Application to C108

In the C92 unit-numerator branch, `q=(-F,b,c,d)` is automatically `r`-primitive: modulo `r`, `F=u alpha`, and tangent independence gives `u notin (r)` while `alpha` is a unit.

Therefore any genuinely resistant full ideal in this branch must satisfy one of:

1. `ht I>=3`; or
2. `ht I=2` but `R/I` has a depth defect / embedded structure.

A height-two Cohen–Macaulay full ideal is already closed by ordinary homological algebra; no Mennicke or Hermitian machinery is needed there.

# 9. `P02-C110-HILBERT-BURCH-MAPPING-CONE-CORE` — PROVED

C109 pushes the regular branch toward height three. The most structured height-three case is exactly the one where the residual tail modulo `F` is height-two perfect.

## Hypotheses

Continue with a four-dimensional regular local ring `R`, a nonzerodivisor `F`, and

`q=(-F,g_1,g_2,g_3)`.

Put

`S=R/(F)`,

`Kbar=(gbar_1,gbar_2,gbar_3) subset S`.

Assume:

1. `S` is Cohen–Macaulay (in C92 it is regular local of dimension three);
2. `Kbar` has height two and is perfect;
3. `gbar_1,gbar_2,gbar_3` are a minimal generating set of `Kbar`.

Let

`Phibar in M_{3x2}(S)`

be a Hilbert–Burch matrix adapted to these generators, so its signed `2 x 2` minors are exactly `gbar_1,gbar_2,gbar_3` after the harmless common unit normalization allowed by Hilbert–Burch.

Lift `Phibar` to

`Phi in M_{3x2}(R)`

and let `Delta_1,Delta_2,Delta_3` be its signed maximal minors.

## Step 1: elementary replacement by lifted minors

Because `Delta_i mod F = g_i mod F`, write

`g_i = Delta_i + F h_i`.

Since the first coordinate of `q` is `-F`, the elementary tail operation

`g_i -> g_i + h_i(-F)`

replaces `g_i` by `Delta_i`. Thus `q` is elementarily equivalent over `R` to

`q'=(-F,Delta_1,Delta_2,Delta_3)`.  (9.1)

## Step 2: the lifted determinantal ideal is height two perfect

Let

`Delta=(Delta_1,Delta_2,Delta_3)=I_2(Phi)`.

Since `(F,Delta)/(F)=Kbar` has height two in `S`,

`ht_R(F,Delta)=3`.

The determinantal height bound for maximal minors of a `3 x 2` matrix gives

`ht Delta <=2`.

On the other hand, adding one element can raise height by at most one, so

`3=ht(F,Delta) <= ht(Delta)+1`.

Hence

`ht Delta=2`.

Hilbert–Burch over the Cohen–Macaulay regular local ring `R` now gives the exact resolution

`0 -> R^2 --Phi--> R^3 --(Delta_1,Delta_2,Delta_3)--> R -> R/Delta ->0`.  (9.2)

Thus `R/Delta` is Cohen–Macaulay of dimension two. Since `(F,Delta)` has height three, `F` avoids every associated prime of `R/Delta`; equivalently, `F` is a nonzerodivisor on `R/Delta`.

## Step 3: mapping cone

Take the mapping cone of multiplication by `F` on (9.2). Because `F` is regular on `R/Delta`, the cone resolves `R/(F,Delta)`. Up to harmless sign conventions, its leftmost differential is

`Theta = [ -F I_2 ; Phi ] : R^2 -> R^5`,  (9.3)

that is,

```
Theta =
[ -F      0      ]
[  0     -F      ]
[ phi11  phi12   ]
[ phi21  phi22   ]
[ phi31  phi32   ].
```

The resulting exact complex is

`0 -> R^2 --Theta--> R^5 -> R^4 --q'--> R -> R/(F,Delta) ->0`.  (9.4)

In particular, if

`M=ker(q':R^4->R)`,

then

`boxed{ M ~= coker(Theta) }`.  (9.5)

## Step 4: localize at `r`

Assume now that `q'_A` is unimodular, as in the P02 rank-three problem. Then

`P=ker(q'_A:A^4->A)`

is projective of rank three and (9.4) localizes to

`0 -> A^2 --Theta_A--> A^5 -> P ->0`.  (9.6)

The sequence splits because `P` is projective. Therefore `Theta_A` is a split rank-two monomorphism, and

`boxed{ P ~= coker(Theta_A) }`.  (9.7)

Moreover,

`boxed{ P is free iff the two columns of Theta_A extend to a basis of A^5 }`.  (9.8)

Indeed, if the cokernel is free, lift a basis of it to three more columns; conversely an invertible `5 x 5` completion gives free cokernel.

## Significance

The height-three/perfect-residual branch of the rank-three Quillen problem has been reduced to a **special rank-two matrix completion problem**:

`Theta_A = [ -F I_2 ; Phi ]`.

This is substantially sharper than saying merely that a class lies in stable `K_0`: the matrix already exhibits the one-step unstable obstruction which Vaserstein/Mennicke/Euler/Hermitian methods are designed to detect.

# 11. `P02-D34-DESATURATION-NEEDS-TRANSVERSALITY` — DISPROVED as an overstrong method claim

C107 must not be used after deleting its regular-pair hypothesis.

Let

`R=k[[x,y,z,t]]`,

and consider

`w=(x,xy,xz,0)=x(1,y,z,0)`.

Because `x` is a nonzerodivisor,

`ker(w)=ker(1,y,z,0)`.

The latter is visibly free rank three, with basis for example

`(-y,1,0,0)`, `(-z,0,1,0)`, `(0,0,0,1)`.

A naive deletion of the common tail factor `a=x` against the same source `F=x` would produce

`q=(-x,y,z,0)`.

Now

`ker(q) = N direct_sum R`,

where

`N=ker((-x,y,z):R^3 -> (x,y,z))`.

Since `x,y,z` is a regular sequence, the Koszul resolution gives a minimal exact sequence

`0 -> R -> R^3 -> N ->0`.

The map on the left has all entries in the maximal ideal, so this is a nontrivial minimal free resolution; `N` has projective dimension one and is not projective. Consequently `N direct_sum R` is not free (if it were, `N` would be a direct summand of a free module and hence projective).

Thus

`ker(w) ~= R^3`

but

`ker(q)` is nonfree.

Here `a=x` is zero in `R/(F)`, exactly violating C107. Hence:

`boxed{ common-tail desaturation is false without transversality / regularity modulo F }`.

This is a method counterexample, not a counterexample to Quillen.

`dQ/dP = D/E D`,

## Independent derivation

Let the columns of `H` be `g_1,...,g_m`, set

`eta=g_1 wedge ... wedge g_m`,

and define the unit Pluecker `r`-vector

`Omega=*eta/sqrt(D)`.

For an `r`-subset `R0`,

`Omega_{R0} = +/- det(H_{R0^c})/sqrt(D)`.

For `j`-subsets `I,J`, the standard contraction formula gives

`<e_I,(wedge^j K)e_J>
 = sum_L +/- Omega_{I union L} Omega_{J union L}`,

where `L` ranges over `(r-j)`-subsets disjoint from `I union J`. Multiplying by `D` converts each term into a product of two complementary `m x m` minors.

If `I != J`, choose `a in I\J`. In every nonzero term, the first minor omits row `a`, while the second contains row `a` and is linear in it. Conditioning on all other rows and using `E h_a=0` kills the term. Thus every off-diagonal expectation is zero.

For `I=J`, there are exactly `C(n-j,r-j)` squared minors. By iid row exchangeability all have one common expectation `delta_m`. Cauchy–Binet gives

`E D = C(n,r) delta_m`.

Therefore

`E_Q <e_I,(wedge^j K)e_I>
 = C(n-j,r-j)/C(n,r)
 = C(r,j)/C(n,j)`.

This proves (13.1). Integrability is sufficient because `D` is itself the sum of the nonnegative squared maximal minors, so finite `E D` controls every diagonal term used above.
