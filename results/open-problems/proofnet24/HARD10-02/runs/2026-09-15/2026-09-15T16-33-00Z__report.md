## 2. Cumulative first-order identity retained from the verified checkpoint

Let `A,B` be absorbing boundary sets of a finite graph, let `x` be the post-first-step starting vertex, and suppose the root edge `e_0={r,x}` has already been traversed and is therefore old. Let

\[
h(z)=P_z^{SRW}(\tau_B<\tau_A).
\]

The durable checkpoint proves the fixed-harmonic fresh-edge martingale and therefore

\[
\left.\frac{d}{dc}P_x^{ORRW(c)}(\tau_B<\tau_A)\right|_{c=1}=-D,
\tag{2.1}
\]

where

\[
D=
E_x^{SRW}\sum_{\substack{k<\tau:\\
\{X_k,X_{k+1}\}\text{ fresh}}}
\bigl(h(X_{k+1})-h(X_k)\bigr).
\tag{2.2}
\]

For an oriented fresh edge `e=(u,v)`, write

\[
q_e(x)=P_x(\text{first crossing of }e\text{ is }u\to v)
-P_x(\text{first crossing is }v\to u).
\]

Then

\[
D=\sum_{e\neq e_0}(h(v_e)-h(u_e))q_e(x).
\tag{2.3}
\]

The 14:35 checkpoint gives an exact killed-Green formula for every `q_e`. This is the tool used below.

# 3. New family: a planar bipartite triangle-free obstruction

For an integer `m>=1`, define `H_m` with vertices

\[
r,x,b,z_1,y_1,\ldots,z_m,y_m
\]

and edges

\[
\{r,x\},\quad \{x,b\},\quad
\{r,z_i\},\quad \{z_i,y_i\},\quad \{y_i,x\}
\qquad(1\le i\le m).
\tag{3.1}
\]

The failure vertex is `r`, the success vertex is `b`, and the walk starts at `x` immediately after the initial traversal `r->x`, so `{r,x}` is already old and every other edge is fresh.

`H_m` is:

- simple;
- planar;
- bipartite, with one bipartition containing `r,y_i,b` and the other containing `x,z_i`;
- triangle-free (indeed the basic cycles through the initial edge have length four).

Its only large degrees are

\[
\deg(r)=m+1,\qquad \deg(x)=m+2.
\tag{3.2}
\]

Thus this family deliberately tests whether the previous fan obstruction was merely an odd-cycle/triangle phenomenon.

# 4. Exact harmonic voltage on `H_m`

By symmetry, set

\[
H=h(x),\qquad Y=h(y_i),\qquad Z=h(z_i).

\[
2Z=Y,
\qquad

# 5. Exact first-crossing biases on `H_m`

All branches are symmetric. The needed first-crossing biases can be solved either from the general Green formula or directly from the deleted-edge Dirichlet system.

## 5.1 Target edge

For the boundary edge `x->b`,

\[
q_{xb}=G(x,x)=\frac{3}{m+6},
\tag{5.1}
\]

because `b` is the only success boundary neighbor.

## 5.2 Root spoke

Orient a root spoke as `r->z_i`. The orientation `r->z_i` cannot occur before absorption at `r`; hence

\[
q_{rz_i}=-G(x,z_i)=-\frac{1}{m+6}.
\tag{5.2}
\]

The Green values follow from the same branch equations with a unit source at `x`:

\[
G(x,x)=\frac{3}{m+6},\quad
G(x,y_i)=\frac{2}{m+6},\quad
G(x,z_i)=\frac{1}{m+6}.
\]

## 5.3 Middle edge `z_i-y_i`

Orient the edge `z_1->y_1` and delete only its off-diagonal continuation while retaining the original degree diagonals. By symmetry let the first-crossing-bias solution have values

`q_x,q_z,q_y,q_{z,*},q_{y,*}`

at `x,z_1,y_1` and at the other branch vertices. The deleted-edge equations give

\[
2q_z=1,
\qquad
2q_y-q_x=-1,
\]

and for an undistinguished branch

\[
2q_{z,*}-q_{y,*}=0,
\qquad
2q_{y,*}-q_{z,*}-q_x=0.
\]

Thus

\[
q_y=\frac{q_x-1}{2},
\qquad
q_{y,*}=\frac{2q_x}{3}.
\]

The equation at `x` is

\[
(m+2)q_x-q_y-(m-1)q_{y,*}=0,
\]

which yields

\[
\boxed{q_{z_i y_i}(x)=-\frac{3}{2m+13}.}
\tag{5.3}
\]

## 5.4 Edge `y_i-x`

Orient `y_1->x` and delete that edge in the same first-crossing Dirichlet system. On the distinguished branch one gets

\[
2q_z-q_y=0,
\qquad
2q_y-q_z=1,
\]

so `q_z=1/3`, `q_y=2/3`. On the other branches, again `q_{y,*}=2q_x/3`. The equation at `x` now has right side `-1`:

\[
(m+2)q_x-(m-1)q_{y,*}=-1.
\]

Hence

\[
\boxed{q_{y_i x}(x)=-\frac{3}{m+8}.}
\tag{5.4}
\]

Both interior branch edges therefore have a first-crossing orientation bias *against* the increasing harmonic direction.

# 6. Exact first-order correction and threshold

The harmonic increments in the orientations used above are

\[
h(b)-h(x)=\frac{m+3}{m+6},
\]

and

\[
h(z_i)-h(r)=h(y_i)-h(z_i)=h(x)-h(y_i)=\frac1{m+6}.
\]

Substituting (5.1)–(5.4) into (2.3) gives

\[
D_m
=
\frac{3(m+3)}{(m+6)^2}
-\frac{m}{(m+6)^2}
-\frac{3m}{(m+6)(2m+13)}
-\frac{3m}{(m+6)(m+8)}.
\]

After simplification,

\[
\boxed{
D_m
=-\frac{5m^3+41m^2-91m-936}
{(m+6)^2(m+8)(2m+13)}.
}
\tag{6.1}
\]

For integer `m>=1`, the cubic

\[
p(m)=5m^3+41m^2-91m-936
\]

satisfies

\[
p(4)=-324,
\qquad
p(5)=259,
\]

and

\[
p'(m)=15m^2+82m-91>0
\qquad(m\ge1).
\]

Therefore

\[
\boxed{
D_m>0\quad(1\le m\le4),
\qquad
D_m<0\quad(m\ge5).
}
\tag{6.2}
\]

In particular, for `m=5`,

\[
\boxed{D_5=-\frac{259}{36179}<0.}
\tag{6.3}

By (2.1),

\[
\boxed{
\left.\frac{d}{dc}P_x^{ORRW(c)}(\tau_b<\tau_r)\right|_{c=1}

\tag{6.4}
\]

This is a rigorous planar **bipartite, triangle-free** counterexample to universal first-order escape monotonicity.

# 7. Exact full-reinforcement counterexample on the same bipartite family

The derivative result already implies that for `m=5` there exists an interval `c>1` on which escape exceeds SRW. A direct exact recursion produces a concrete rational parameter.

For each branch `r-z_i-y_i-x`, before absorption there are only three relevant branch states:

- `0`: neither `x-y_i` nor `y_i-z_i` is old;
- `A`: `x-y_i` is old but `y_i-z_i` is fresh;
- `C`: both internal branch edges are old.

(The boundary edge `z_i-r` absorbs when crossed and never needs a persistent state.)

Let `X_{a,d}` be the success probability from `x` when exactly `a` branches are in state `A`, exactly `d` are in state `C`, and `n=m-a-d` remain in state `0`.

For a `C` branch, let `Y_C,Z_C` be the values at its `y,z` vertices. The two-state equations are

\[
Y_C=\frac{X_{a,d}+Z_C}{2},
\qquad
Z_C=\frac{c}{c+1}Y_C,
\]

hence

\[
\boxed{
Y_C=\frac{c+1}{c+2}X_{a,d},
\qquad
Z_C=\frac{c}{c+2}X_{a,d}.
}
\tag{7.1}
\]

For an `A` branch,

\[
\boxed{
Y_A(a,d)=
\frac{cX_{a,d}+\frac{c}{c+2}X_{a-1,d+1}}{c+1}.
}
\tag{7.2}
\]

If a state-`0` branch is entered freshly from `x`, the resulting value is `Y_A(a+1,d)`.

At `x`, the total transition weight is

\[
Z_{a,d}=c(1+a+d)+1+n,
\tag{7.3}
\]

where the `1` inside the first term is the initially old edge `x-r` and the second standalone `1` is the fresh success edge `x-b`. Therefore

\[
\boxed{
X_{a,d}
=
\frac{
1+nY_A(a+1,d)+acY_A(a,d)+dcY_C(a,d)
}{Z_{a,d}}.
}
\tag{7.4}
\]

Equations (7.1)–(7.4) form a triangular exact recursion: compute by decreasing `a+d`, and at fixed `a+d` by increasing `a`.

For `m=5` and

\[
\boxed{c=\frac98\quad(a=1/8),}
\]

the exact rational recursion gives

\[
P_x^{ORRW(9/8)}(\tau_b<\tau_r)-P_x^{SRW}(\tau_b<\tau_r)
=
\frac{
12273379805549756953660104222378580389717218286352429470319397
}{
120057133643886825040706122653589668492966446032818287314554256827
}
>0.
\tag{7.5}
\]

Here

\[
P_x^{SRW}(\tau_b<\tau_r)=h(x)=\frac3{11}.
\]

Thus graph-universal escape domination by SRW fails at a **concrete positive reinforcement** even under all three properties:

\[
\boxed{\text{planar + bipartite + triangle-free}.}
\]

This strengthens the previous 15:35 fan obstruction, which used triangles.
