# Terminology note for REPORT.md

In Theorem 3.4 item 3, the phrase **"outward Hasse-adjacent incomparable pair"** is imprecise and should be read as **"outward Hasse-witnessed incomparable pair"**.

The exported incomparable pair is `(r,q)` in a `U(p,q)` channel or `(p,r)` in a `D(p,q)` channel. The witness `r` is Hasse-adjacent to the corresponding old endpoint (`p lessdot r` or `r lessdot q`); the exported incomparable pair itself is not asserted to be a cover pair. Equations (3.7)-(3.8), the `>1/12` count, the coherent-gate application, and all subsequent conclusions are unchanged.

This note preserves the original immutable report while removing a terminology ambiguity; it makes no mathematical strengthening.
