# P13 I0051 proof note: signed means in `P13-I0051-L1-CLT-02`

Canonical run report: `proofnet24/P13-closure-clades/runs/2026-09-16/2026-09-16_16-03-16__run-report.md` at creation commit `7edf5ee6907526b7dae4dfd359b7c3d91d457cfd`.

The theorem there allows an arbitrary real `t in l^1`. Brandenberger--Chin--Mossel Proposition 1.3 is printed with a positive mean-slope parameter `mu`. If the slope `mu_t=sum_r t_r rho_r` in Section 7 is nonpositive, apply their proposition to

\[
\widetilde X_n(t):=X_n(t)+c n
\]

with any fixed `c> -mu_t` (for instance `c=1+|mu_t|`). Then

\[
\widetilde X_n
=\widetilde X_{I_n}+\widetilde X'_{n-I_n}+t_n,
\]

because `c I_n+c(n-I_n)=cn`; the centered variable and variance are unchanged:

\[
\widetilde X_n-E\widetilde X_n=X_n-EX_n,
\qquad
\operatorname{Var}(\widetilde X_n)=\operatorname{Var}(X_n).
\]

Its mean slope is `mu_t+c>0`, and all error and toll bounds from Section 7 are identical. Thus the stated CLT for arbitrary signed `t in l^1` follows under the literal hypotheses of Proposition 1.3. If `sigma_t^2=0`, the report's direct `L^2` argument applies and no contraction theorem is needed.

This note does not change any claim or formula; it makes explicit a one-line hypothesis normalization that was implicit in the run report. The canonical report remains immutable.
