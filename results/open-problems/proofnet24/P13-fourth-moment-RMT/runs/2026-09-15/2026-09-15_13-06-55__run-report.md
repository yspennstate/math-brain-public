# 4. Primary-source verification used this run

Primary source:

Galyna V. Livshyts, *The smallest singular value of heavy-tailed not necessarily i.i.d. random matrices via random rounding*, arXiv:1811.07038v4 / J. Anal. Math. 145 (2021), 257–306.

The primary source explicitly records:

1. classical net arguments need operator-norm control and therefore historically imported fourth moments or subgaussian tails;
2. the random-rounding construction is designed precisely to bypass that norm input;
3. Definition 1.1 requires only a concentration function separated from one;
4. the arbitrary-aspect-ratio theorem applies to mean-zero matrices with independent entries/identically distributed rows under bounded concentration plus a second-moment-type column condition;
5. Corollary 3 specializes this to mean-zero iid variance-one entries with bounded concentration;
6. Theorem 3, the random-rounding net theorem, assumes only independence of columns, and measures approximation error through averaged column moments rather than an operator norm.

For the real coordinate-\(L^2\) law below, the bounded-concentration hypothesis is explicit and elementary. If

\[
\|f_\xi\|_2\le K_2,
\]

then for

\[
\boxed{a_*=(32K_2^2)^{-1}}
\tag{P1}
\]

Cauchy–Schwarz gives, uniformly in the center \(z\),

\[
P\{|\xi-z|\le a_*\}
\le
K_2\sqrt{2a_*}
=
\frac14.
\tag{P2}
\]

Thus the Livshyts concentration parameters may be fixed at

\[
\boxed{a=a_*,\qquad b=1/4.}
\tag{P3}
\]

The downstream absolute constants in Livshyts's net theorem are not numerically specified in the paper. Accordingly the uniform constants \(\delta,\rho,c\) below are stated with their exact **dependency set** \((K_2,c_*)\), not invented numerical values.

# 5. Real rectangular compressible-kernel theorem under coordinate L2

Let

\[
\operatorname{Comp}(\delta,\rho)
=
\left\{x\in S^{m-1}:
\operatorname{dist}(x,\operatorname{Sparse}(\delta m))\le\rho
\right\}.
\]

## `P13-REAL-RECT-COMP-L2-24` — NEW / PROVED

Fix

\[
K_2<\infty,
\qquad
c_*>0.
\]

There exist constants

\[
\boxed{
\delta=\delta(K_2,c_*)>0,
\quad
\rho=\rho(K_2,c_*)>0,
\quad
c=c(K_2,c_*)>0,
}
\tag{R1}
\]

such that the following holds for all sufficiently large \(m\).

Let

\[
B\in\mathbb R^{N\times m},
\qquad
N\ge c_*m,
\]

have iid entries \(\xi\) satisfying

\[
E\xi=0,
\qquad
E\xi^2=1,
\qquad
\|f_\xi\|_2\le K_2.
\tag{R2}
\]

Then

\[
\boxed{
P\{\ker B\cap\operatorname{Comp}(\delta,\rho)\ne\varnothing\}
\le e^{-cm}.
}
\tag{R3}
\]

The same constants work uniformly for a triangular family satisfying `(R2)` with the same \(K_2\).

### Proof architecture

By `(P1)`–`(P3)`, every entry has a concentration function separated from one by constants depending only on \(K_2\).

For a fixed unit vector \(x\), standard concentration-function tensorization for independent rows gives

\[
P\{\|Bx\|_2\le c_0\sqrt N\}
\le e^{-c_1N},
\tag{R4}
\]

with \(c_0,c_1>0\) depending only on \(K_2\). This is the fixed-vector small-ball input in Livshyts's arbitrary-aspect-ratio argument.

The compressible set is a union over supports of size at most \(\delta m\). Its Euclidean covering entropy is

\[
\exp\{O(\delta m\log(C/(\delta\rho)))\}.
\tag{R5}
\]

A naive net would require \(\|B\|\), which is exactly the fourth-moment bottleneck we are avoiding. Instead apply Livshyts's Theorem 3 random-rounding net to the compressible set. Here the matrix has independent columns, and for the required \(p=1\) approximation scale

\[
\sum_{j=1}^mE\|Be_j\|_2^2
=Nm
\tag{R6}
\]

uses only variance one. The theorem supplies a deterministic nearby net and an exponentially high probability approximation event whose error is controlled by `(R6)`, not by \(\|B\|\).

Choose first the random-rounding parameters so that the approximation error is below \(c_0\sqrt N/2\); then choose \(\rho\) fixed sufficiently small; finally choose \(\delta\) so that the entropy exponent in `(R5)` is strictly smaller than the tensorized exponent \(c_1N\ge c_1c_*m\). Union over the net in `(R4)` and add the random-rounding failure probability.

This gives `(R3)` with constants depending only on \((K_2,c_*)\).

### Scope

No third or fourth moment, no operator norm, no Bai–Yin event and no subgaussian tail are used.

This theorem is an entire-nullspace statement, stronger than incompressibility of one selected normal.

# 6. Deterministic rank-two leverage pruning

Let

\[
E\subset\mathbb R^m,
\qquad
\dim E=2,
\]

and let

\[
A\in\mathbb R^{2\times m},
\qquad
AA^\top=I_2,
\]

have rows forming an orthonormal basis of \(E\). Write the columns as \(a_j\in\mathbb R^2\).

For \(R\subset[m]\), define

\[
G_{R^c}
=
\sum_{j\notin R}a_ja_j^\top.
\]

## `P13-REAL-RANK2-PRUNE-24` — NEW / PROVED

Fix \(0<\tau<1\) and put

\[
\boxed{
L_\tau=\left\lceil\log_2\tau^{-4}\right\rceil+1.
}
\tag{PR1}
\]

Assume

\[
\boxed{
G_{R^c}\succeq\tau^2I_2
\qquad
\text{for every }|R|\le L_\tau.
}
\tag{PR2}
\]

Then there is a coordinate subset \(J\subset[m]\) such that

\[
\boxed{G_J:=\sum_{j\in J}a_ja_j^\top\succeq\tau^2I_2}
\tag{PR3}
\]

and every internal leverage satisfies

\[
\boxed{a_j^\top G_J^{-1}a_j\le\frac12
\qquad(j\in J).}
\tag{PR4}
\]

### Proof

Start with \(J_0=[m]\), so \(G_{J_0}=I_2\). If some current column has leverage

\[
\ell_j=a_j^\top G_J^{-1}a_j>1/2,
\]

remove it. The matrix determinant lemma gives

\[
\det(G_J-a_ja_j^\top)
=
\det G_J(1-\ell_j)
<\frac12\det G_J.
\tag{PR5}
\]

As long as at most \(L_\tau\) columns have been removed, `(PR2)` gives

\[
\det G_J\ge\tau^4.
\tag{PR6}
\]

But after \(L_\tau\) removals, `(PR5)` would give

\[
\det G_J<2^{-L_\tau}<\tau^4,
\]

contradicting `(PR6)`. Hence the procedure stops earlier. At stopping time `(PR3)` holds and no leverage exceeds \(1/2\), giving `(PR4)`.

QED.

# 8. Real coordinate-L2 pair estimate under robust plane transversality

The following inherited analytic input is rederived here to make constants explicit.

Let

\[
X=(\xi_1,\ldots,\xi_m)
\]

have independent real coordinates with

\[
\|f_{\xi_j}\|_2\le K_2.
\]

For a full-row-rank real map \(L:\mathbb R^m\to\mathbb R^r\), whiten it and write its frame columns as \(\sqrt{p_j}b_j\). If all whitened leverages satisfy \(p_j\le1/2\), the real Fourier-power / geometric Brascamp–Lieb argument gives

\[
\boxed{
\|f_{LX}\|_\infty
\le
\frac{(2\sqrt e\,K_2^2)^r}
{\sqrt{\det(LL^\top)}}.
}
\tag{A1}
\]

Indeed, the one-dimensional Fourier-power bound is

\[
\int_{\mathbb R}|\phi_j(t)|^qdt
\le
\frac{4\pi\sqrt e\,K_2^2}{\sqrt q},
\qquad q\ge2,
\]

and the geometric Brascamp–Lieb decomposition cancels the leverage scaling; Fourier inversion contributes \((2\pi)^{-r}\).

If only a coordinate subframe \(J\) has internal leverages at most \(1/2\), convolution with the omitted independent coordinates cannot increase the density maximum, so `(A1)` applies with \(LL^\top\) replaced by \(L_JL_J^\top\).

Now let \(u,v\in S^{m-1}\), put

\[
\Delta=1-|\langle u,v\rangle|^2>0,
\]

and let \(E=\operatorname{span}\{u,v\}\). Let \(A\) be an orthonormal-row basis of \(E\), and write

\[
L=
\begin{pmatrix}u^\top\\v^\top\end{pmatrix}
=CA.
\]

Then

\[
\det(CC^\top)=\Delta.
\]

If a pruned coordinate subframe has

\[
G_J=A_JA_J^\top\succeq\tau^2I_2,
\]

then

\[
\sqrt{\det(L_JL_J^\top)}
=
\sqrt{\Delta\det G_J}
\ge
\tau^2\sqrt\Delta.
\]

Therefore `(A1)` with \(r=2\) gives

\[
\boxed{
\|f_{(\langle X,u\rangle,\langle X,v\rangle)}\|_\infty
\le
\frac{4eK_2^4}{\tau^2\sqrt\Delta}.
}
\tag{A2}
\]

A rectangle of side lengths \(2s,2t\) has area \(4st\), hence uniformly in centers \(z_1,z_2\),

\[
\boxed{
P\{|⟨X,u\rangle-z_1|\le s,
|⟨X,v\rangle-z_2|\le t\}
\le
\frac{16eK_2^4}{\tau^2\sqrt\Delta}\,st.
}
\tag{A3}
\]

No moment assumption enters `(A1)`–`(A3)`.

# 10. Exact row-set overlap entropy

The remaining pair question is concentrated in low overlap. Its combinatorics can be quantified exactly.

Let

\[
N_m/m\to\gamma>1,
\qquad
s_m=m-1.
\]

Fix one \(s_m\)-subset \(S\subset[N_m]\). For another \(s_m\)-subset \(T\), put

\[
q=|S\cap T|.
\]

The exact count at overlap \(q\) is

\[
\boxed{
\#\{T:|S\cap T|=q\}
=
\binom{s_m}{q}
\binom{N_m-s_m}{s_m-q}.
}
\tag{C1}
\]

Let

\[
H(x)=-x\log x-(1-x)\log(1-x),
\]

and for feasible

\[
\alpha\in[\alpha_{\min},1],
\qquad
\alpha_{\min}=\max\{0,2-\gamma\},
\]

define

\[
\boxed{
g_\gamma(\alpha)
=H(\alpha)
+(\gamma-1)
H\left(\frac{1-\alpha}{\gamma-1}\right).
}
\tag{C2}
\]

Stirling gives, for \(q/m\to\alpha\),

\[
\frac1m\log\#\{T:|S\cap T|=q\}
\to g_\gamma(\alpha).
\tag{C3}
\]

The total number of \(T\)'s has exponent

\[
\boxed{
\frac1m\log\binom{N_m}{m-1}
\to h(\gamma).
}
\tag{C4}
\]

A direct derivative computation gives

\[
g_\gamma'(\alpha)
=
\log
\frac{(1-\alpha)^2}{\alpha(\gamma-2+\alpha)},
\]

so the unique maximizer is

\[
\boxed{\alpha_*=1/\gamma.}
\tag{C5}
\]

Thus the typical pair shares a linear fraction \(m/\gamma\) of its rows.

## `P13-PAIR-OVERLAP-ENTROPY-24` — NEW / PROVED

Fix

\[
\alpha_{\min}<c<1/\gamma.
\]

Then

\[
\boxed{
\frac{
\#\{T:|S\cap T|\le cm\}
}{
\binom{N_m}{m-1}
}
\le
\exp\{-I_\gamma(c)m+o(m)\},
}
\tag{C6}
\]

where

\[
\boxed{
I_\gamma(c)=h(\gamma)-g_\gamma(c)>0.
}
\tag{C7}
\]

This is uniform in the fixed set \(S\).

### Phase-retrieval ratio

At \(\gamma=2\),

\[
g_2(c)=2H(c),
\]

so

\[
\boxed{I_2(c)=\log4-2H(c).}
\tag{C8}
\]

As \(c\downarrow0\),

\[
I_2(c)\uparrow\log4.
\tag{C9}
\]

Thus the low-overlap row-set sector can have almost the entire pair entropy removed at the real phase-retrieval ratio.
