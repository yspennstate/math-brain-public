# 4. New explicit fourth-moment anti-concentration lemma

## `P13-B4-UAC-34` — PROVED

Let `xi'` be an iid copy of `xi` and put

\[
Z=\xi-\xi'.
\]

Under

\[
E\xi=0,\qquad E\xi^2=1,\qquad E\xi^4\le B,
\]

we have

\[
EZ^2=2
\]

and, using independence and centering,

\[
EZ^4
=2E\xi^4+6(E\xi^2)^2
\le2B+6.
\]

Apply Paley--Zygmund to `Y=Z^2` at one half of its mean:

\[
P\{|Z|\ge1\}
=P\{Y\ge \tfrac12EY\}
\ge
\frac{(1-1/2)^2(EY)^2}{EY^2}
\ge
\frac1{2B+6}.
\tag{4.1}
\]

Now fix `z` and put

\[
p=P\{|\xi-z|<1/2\}.
\]

If two iid copies both lie in this interval, then `|xi-xi'|<1`; hence

\[
p^2
\le P\{|Z|<1\}
\le1-\frac1{2B+6}.
\]

Therefore

\[
\boxed{
Q_\xi(1/2)
:=\sup_zP\{|\xi-z|<1/2\}
\le
b_B:=\sqrt{1-\frac1{2B+6}}<1.
}
\tag{4.2}
\]

This constant is explicit and uniform over every law in the fourth-moment class.

### Why the quantifier matters

- **levelwise finite fourth moment:** `B=B_m` may diverge, so `(4.2)` degenerates and gives no common UAC constants;
- **uniformly bounded fourth moment:** one fixed `B` supplies one fixed pair `(a,b)=(1/2,b_B)` for the entire triangular family.

This is exactly the distinction needed by the primary distance theorem below.

# 5. Current primary-source verification and hypothesis matching

This run rechecked the current primary statements rather than importing a status label.

## 5.1 Fernandez rectangular distance theorem

Manuel Fernandez V., *A distance theorem for inhomogenous random rectangular matrices*, arXiv:2408.06309.

The theorem applies to an `n x (n-d)` random matrix `M` with independent uniformly anti-concentrated entries and an expected Hilbert--Schmidt-square ceiling `K n(n-d)`, together with an independent random vector `X` whose entries satisfy the same UAC condition and a second-moment condition. For

\[
1\le d\le\lambda n/\log n,
\]

it gives

\[
\boxed{
P\{\operatorname{dist}(X,\operatorname{span}M)\le t\sqrt d\}
\le(Ct)^d+e^{-cn}
}
\tag{5.1}
\]

with constants depending only on the fixed anti-concentration/second-moment parameters.

For P13 under uniform fourth moment:

- `(4.2)` gives the fixed UAC pair `(1/2,b_B)`;
- each entry has second moment one;
- `E||M||_{HS}^2=n(n-d)`, so the Hilbert--Schmidt parameter is exactly `K=1`;
- the held-out original column is independent of the other original columns.

Thus every imported hypothesis is verified.

## 5.2 Dabagia--Fernandez rectangular least singular value theorem

Max Dabagia and Manuel Fernandez, *The smallest singular value of inhomogenous random rectangular matrices*, arXiv:2408.14389.

Its current primary statement gives, for an `N x n` matrix with independent mean-zero variance-one entries and a common bounded `2+beta` moment,

\[
P\{\sigma_n(A)\le\varepsilon(\sqrt{N+1}-\sqrt n)\}
\le
(C\varepsilon)^{N-n+1}+e^{-cN},
\tag{5.2}
\]

where `c,C` depend only on `beta` and the moment ceiling. In the present problem take

\[
\beta=2,
\qquad
E|\xi|^{2+\beta}=E\xi^4\le B.
\]

The iid mean-zero variance-one candidate matrix has independent entries and isotropic columns, so all hypotheses are satisfied.

Important constant discipline: the theorem supplies **some** `c_B,C_B>0`; its statement does not provide a lower bound on `c_B` strong enough to compare with `h(gamma)`. I keep that rate opaque instead of inventing a favorable constant.

## 5.3 Polavarapu--Fernandez intermediate singular values

Achintya Raya Polavarapu and Manuel Fernandez V., *Intermediate Singular Values of Random Matrices under Second-Moment and Anti-Concentration Assumptions*, arXiv:2608.30722.

For a square `n x n` matrix with independent centered variance-one entries and fixed UAC constants `(a,b)`, for every fixed `delta in (0,1)` it gives

\[
P\left\{
 s_{n+1-l}(A)>Ct\frac l{\sqrt n}
\right\}
\le
\exp[-c\min\{tl,n\}],
\qquad
t\ge1,
\quad
1\le l\le(1-\delta)n.
\tag{5.3}
\]

No moment beyond variance is assumed. This is used only in the P14 peer lemma audited below, not in the new P13 proof.

# 6. Fixed-candidate actual random-normal anti-resonance

Fix a candidate row set

\[
T\subset[N_m],
\qquad
|T|=n=m+r_m=m+k_m-1,
\]

and a column index `j in [m]`.

Let

\[
M_{T,j}=(A_T)_{-j}\in\mathbb R^{n\times(m-1)}.
\]

Since

\[
m-1=n-k_m,
\]

this is exactly an `n x (n-k_m)` matrix. Let

\[
H_{T,j}=\operatorname{span}(M_{T,j})
\]

and let

\[
X_{T,j}=C_{T,j}\in\mathbb R^n
\]

be the omitted original column.

Because original columns are independent, `X_{T,j}` is independent of `M_{T,j}`. Both have iid entries with the common UAC pair from `(4.2)`, and

\[
E\|M_{T,j}\|_{HS}^2=n(m-1)=n(n-k_m).
\]

Since

\[
k_m\log m=o(m)
\]

and `n~m`, for every fixed `lambda_B>0`, eventually

\[
k_m\le\lambda_B n/\log n.
\]

Therefore the Fernandez distance theorem applies with `d=k_m` and gives

\[
\boxed{
P\{\operatorname{dist}(X_{T,j},H_{T,j})\le t\sqrt{k_m}\}
\le
(C_Bt)^{k_m}+e^{-c_Bn}.
}
\tag{6.1}
\]

This proves `P13-B4-FIXEDCANDIDATE-DISTANCE-34`.

## 6.1 Conditional geometry corollary

Let

\[
p_H(t)
=
P_X\{\operatorname{dist}(X,H)\le t\sqrt{k_m}\mid H\}.
\]

Averaging over the random leave-one-out span gives exactly the left side of `(6.1)`. Hence for every `eta>0`, Markov gives

\[
P_H\{p_H(t)>\eta\}
\le
\frac{(C_Bt)^{k_m}+e^{-c_Bn}}{\eta}.
\tag{6.2}
\]

So the **actual frozen random plane** is anti-resonant for a typical fixed candidate; the previous Walsh plane is a genuine deterministic obstruction but not a typical-geometry theorem.

Equation `(6.2)` is deliberately not advertised as uniform over all exponentially many candidates.

# 7. Fixed-candidate least singular value and the entropy calculation

## 7.1 Negative second moment route, valid also for `k_m=1`

For a full-column-rank `n x m` matrix `B=[C_1,...,C_m]`, the negative-second-moment identity is

\[
\sum_{i=1}^m\sigma_i(B)^{-2}
=
\sum_{j=1}^m
\operatorname{dist}(C_j,\operatorname{span}\{C_\ell:\ell\ne j\})^{-2}.
\tag{7.1}
\]

If `sigma_m(B)<=tau`, then the left side is at least `tau^{-2}`, so for some column `j`,

\[
\operatorname{dist}(C_j,H_j)
\le\sqrt m\,\tau.
\tag{7.2}
\]

If `B` is rank-deficient, one of its columns already lies in the span of the others, so `(7.2)` still holds with distance zero. Thus no absolute-continuity assumption is needed for this implication.

Apply `(6.1)` with

\[
t=\tau\sqrt{m/k_m}.
\]

Union over `j=1,...,m` gives

\[
\boxed{
P\{\sigma_m(A_T)\le\tau\}
\le
m\left(C_B\tau\sqrt{\frac m{k_m}}\right)^{k_m}
+
m e^{-c_Bn}.
}
\tag{7.3}
\]

This proves `P13-B4-FIXEDCANDIDATE-LSV-34` uniformly through the square-candidate case `k_m=1`.

## 7.2 Direct sharper rectangular theorem for `k_m>=2`

When `k_m>=2`, the candidate has strictly more rows than columns. In `(5.2)` take

\[
N=n=m+k_m-1,
\qquad
n_{\rm col}=m.
\]

Then

\[
N-n_{\rm col}+1=k_m
\]

and the natural edge scale is

\[
\Delta_{m,k}
:=\sqrt{N+1}-\sqrt{n_{\rm col}}
=
\sqrt{m+k_m}-\sqrt m
=
\frac{k_m}{\sqrt{m+k_m}+\sqrt m}.
\]

Therefore

\[
\boxed{
P\{\sigma_m(A_T)\le\tau\}
\le
\left(C'_B\frac{\tau}{\Delta_{m,k}}
\right)^{k_m}
+e^{-c'_Bn}.
}
\tag{7.4}
\]

Since `k_m=o(m)`,

\[
\log\Delta_{m,k}
=
\log k_m-\tfrac12\log m+O(1),
\]

and multiplying this normalization loss by `k_m` costs only `O(k_m log m)=o(m)`.

## 7.3 Candidate entropy and the solved main term

Let

\[
\tau_m
=
\exp\left[-\frac{(h(\gamma)+\varepsilon)m}{k_m}\right].
\tag{7.5}
\]

Because `k_m=o(m)` and `N_m/m->gamma`, Stirling gives

\[
\log\binom{N_m}{m+r_m}
=h(\gamma)m+o(m).
\tag{7.6}
\]

Using `(7.3)`, the logarithm of the candidate count times its first term is

\[
\begin{aligned}
&h(\gamma)m+o(m)
+\log m
+k_m\log C_B
+\frac{k_m}{2}\log\frac m{k_m}
+k_m\log\tau_m\\
&=
-\varepsilon m+o(m),
\end{aligned}
\]

because `k_m log m=o(m)`. Hence

\[
\boxed{
\binom{N_m}{m+r_m}
\,m\left(C_B\tau_m\sqrt{\frac m{k_m}}\right)^{k_m}
\to0.
}
\tag{7.7}
\]

This is `P13-B4-LOWER-ENTROPY-MAINTERM-34`.

It is the exact power the deterministic flat-lattice theorem showed could not hold uniformly over all frozen planes. The primary distance theorem recovers it because the plane is itself random.

## 7.4 The exact remaining lower-side rate debt

The additive structural term contributes under the same raw union bound

\[
\binom{N_m}{m+r_m}m e^{-c_Bn}
=
\exp[(h(\gamma)-c_B)m+o(m)].
\tag{7.8}
\]

The imported theorem does not state that `c_B>h(gamma)`. Its constants can deteriorate with the UAC parameter `b_B`, and I have no source certificate for a stronger rate.

Thus:

### `P13-B4-LOWER-EXTREME-RATE-34` — CONDITIONAL

The full lower extreme follows if either

1. one proves `c_B>h(gamma)` for the structural term at the relevant fourth-moment/UAC constants; or
2. one replaces the raw candidate union by a **global structural certificate** showing that the `e^{-c_Bm}` failure is shared/correlated across candidates and need not be paid `exp(h(gamma)m)` times; or
3. one proves a tunable structural error `e^{-A m}` with `A>h(gamma)` while retaining the `t^{k_m}` main term.

No one of these is asserted in the current primary theorem statement.
