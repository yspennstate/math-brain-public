# 4. Analytic starting point for \(L^p\): finite convolution smoothing

Fix

\[
1<p<\infty,
\qquad
p^*=\frac p{p-1},
\qquad
n_p=\lceil p^*\rceil\ge2.
\tag{4.1}
\]

Let \(f\) be a probability density with

\[
\|f\|_p\le K_p.
\]

Set

\[
q_p=\frac{n_p}{n_p-1}.
\]

Because \(n_p\ge p^*\) and \(x\mapsto x/(x-1)\) is decreasing,

\[
q_p\le p.
\]

Interpolate between \(L^1\) and \(L^p\).  Since

\[
\frac1{q_p}
=1-\frac1{n_p}
=1-\frac{\theta}{p^*},
\]

we have

\[
\theta=\frac{p^*}{n_p}\le1,
\]

and therefore

\[
\boxed{
\|f\|_{q_p}
\le
K_p^{p^*/n_p}.
}
\tag{4.2}
\]

Generalized Young gives, because

\[
\frac{n_p}{q_p}=n_p-1,
\]

## `P13-LP-CONV-SMOOTH-26` — NEW / PROVED

\[
\boxed{
\|f^{*n_p}\|_\infty
\le
K_p^{p^*}.
}
\tag{4.3}
\]

This is the first key threshold fact: **any fixed \(L^p\) gain above \(L^1\) becomes a bounded density after a fixed number of convolutions depending only on \(p\)**.

# 5. New Fourier-power theorem under \(L^p\)

Let

\[
\phi(t)=Ee^{it\xi}.
\]

The density in `(4.3)` is the density of the sum of \(n_p\) iid copies of \(\xi\), whose characteristic function is \(\phi^{n_p}\).

Bobkov--Götze Proposition 5.3 states, in dimension one, that for a random variable with density maximum \(M\) and characteristic function \(\psi\), for every integer \(\ell\ge1\),

\[
\frac1{2\pi}
\int_{\mathbb R}|\psi(t)|^{2\ell}\,dt
\le
\left(\frac e{2\ell}\right)^{1/2}M.
\]

Apply it to the \(n_p\)-fold sum and use `(4.3)`:

\[
\boxed{
\int_{\mathbb R}
|\phi(t)|^{2n_p\ell}\,dt
\le
2\pi K_p^{p^*}
\sqrt{\frac e{2\ell}}.
}
\tag{5.1}
\]

For every real exponent \(r\ge2n_p\), this implies

## `P13-LP-FOURIER-POWER-26` — NEW / PROVED

\[
\boxed{
\int_{\mathbb R}|\phi(t)|^r\,dt
\le
\frac{
2\pi\sqrt{2e n_p}\,K_p^{p^*}
}{\sqrt r}.
}
\tag{5.2}
\]

Proof of the interpolation-free extension:

- if \(2n_p\le r<4n_p\), then \(|\phi|^r\le|\phi|^{2n_p}\), and `(5.1)` with \(\ell=1\) is at most the right side of `(5.2)`;
- if \(r\ge4n_p\), take \(\ell=\lfloor r/(2n_p)\rfloor\ge r/(4n_p)\), use \(|\phi|^r\le|\phi|^{2n_p\ell}\), and apply `(5.1)`.

No moment, centering, or variance hypothesis is used in Sections 4--5.

Consistency check: for \(p=2\), \(p^*=2\), \(n_p=2\), and `(5.2)` becomes

\[
\int|\phi|^r
\le
\frac{4\pi\sqrt e\,K_2^2}{\sqrt r},
\qquad r\ge4,
\]

exactly the earlier real \(L^2\) Fourier-power constant.

\[

\[

\qquad
\|b_j\|=1.
\]

Then

\[
\sum_j\lambda_j b_jb_j^\top=I_d.
\]

Assume

\[
\boxed{
\max_j\lambda_j
\le
\theta_p:=\frac1{2n_p}.
}
\tag{6.1}
\]

For

\[
F_j(s)
=|\phi_j(\sqrt{\lambda_j}s)|^{1/\lambda_j},

the geometric rank-one Brascamp--Lieb inequality gives

\[
\int_{\mathbb R^d}|\Phi_A(t)|dt
\le
\prod_j
\left(
\int_{\mathbb R}F_j(s)ds
\right)^{\lambda_j}.

By `(6.1)`,

\[
1/\lambda_j\ge2n_p,

\[

&=
\lambda_j^{-1/2}

\\
&\le
\lambda_j^{-1/2}
\left[
2\pi\sqrt{2en_p}K_p^{p^*}\sqrt{\lambda_j}

2\pi\sqrt{2en_p}K_p^{p^*}.

\tag{10.1}

\[

\tag{10.2}

\tag{10.3}

\[

\le
