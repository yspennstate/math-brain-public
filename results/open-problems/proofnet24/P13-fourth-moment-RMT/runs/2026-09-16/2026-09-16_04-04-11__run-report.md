# 5. Independent derivation of disjoint-pair amplification

Let \(A\in\mathbb R^{N\times m}\) have iid entries distributed as \(\xi\), let \(n=m+r\), and let

\[
L=\lfloor m/2\rfloor.
\]

For \(\ell=1,\dots,L\), define

\[
x_\ell=\frac{e_{2\ell-1}-e_{2\ell}}{\sqrt2}.
\]

Fix \(b>0\) and \(\epsilon>0\). Choose \(z\) so that

\[
P\{|\xi-z|\le b\}\ge Q_\xi(b)-\epsilon.
\]

For each row \(i\), let \(E_{i,\ell}\) be the event that both entries in columns \(2\ell-1,2\ell\) lie in this ball. Then

\[
P(E_{i,\ell})\ge (Q_\xi(b)-\epsilon)^2.
\]

For fixed \(\ell\), the number \(S_\ell\) of successful rows stochastically dominates \(\operatorname{Bin}(N,(Q_\xi(b)-\epsilon)^2)\). Distinct \(S_\ell\)'s are independent because they depend on disjoint complete matrix columns.

If \(S_\ell\ge n\), select \(n\) successful rows. On each selected row,

\[
|(A_Tx_\ell)_i|
\le\sqrt2\,b,
\]

so

\[
\|A_Tx_\ell\|_2\le\sqrt{2n}\,b
\quad\Longrightarrow\quad
M_{m,r}(A)\le\sqrt{2n}\,b.
\]

Letting \(\epsilon\downarrow0\), using continuity of the finite binomial tail in its success parameter, gives

\[
\boxed{
P\{M_{m,r}(A)\le\sqrt{2n}\,b\}
\ge
1-
\left[
1-B_{N,n}(Q_\xi(b)^2)
\right]^L.
}
\tag{5.1}
\]

No centering, variance, moment, density, operator norm, delocalization, or arithmetic input appears in `(5.1)`.

# 6. Binomial moderate-deviation bracket — independent audit proof

Write

\[
B_{N,n}(q)=P\{\operatorname{Bin}(N,q)\ge n\},
\qquad
\beta=\frac nN,
\]

and assume

\[
\beta\in[\beta_-,\beta_+]\Subset(0,1),
\qquad
0<q\le\beta.
\]

Define binary relative entropy

\[
D(\beta\|q)
=
\beta\log\frac\beta q
+(1-\beta)\log\frac{1-\beta}{1-q}.
\]

## 6.1 Upper bound

Chernoff optimization gives immediately

\[
B_{N,n}(q)\le e^{-ND(\beta\|q)}.
\tag{6.1}
\]

## 6.2 Threshold mass

At \(n=N\beta\),

\[
P_q\{X=n\}
=
\Big[\binom Nn\beta^n(1-\beta)^{N-n}\Big]
 e^{-ND(\beta\|q)}.
\]

Uniform Stirling over the compact \(\beta\)-interval gives

\[
P_q\{X=n\}
\ge c_0N^{-1/2}e^{-ND(\beta\|q)}.
\tag{6.2}
\]

## 6.3 Recovering the moderate-window factor

Put \(d=\beta-q\).

If \(d\ge\beta_-/4\), then

\[
1+\sqrt N\,d\asymp\sqrt N,
\]

and `(6.2)` already yields the desired lower bound.

Now suppose \(d<\beta_-/4\). Then \(q\) stays in a compact subinterval of \((0,1)\). Let

\[
\epsilon=d+N^{-1/2},
\qquad
J=\left\lfloor\frac{c_1}{\epsilon}\right\rfloor
\]

for a sufficiently small \(c_1=c_1(\beta_-,\beta_+)\). Write \(p_j=P\{X=n+j\}\). The exact adjacent ratio is

\[
\frac{p_{j+1}}{p_j}
=
\frac{N-n-j}{n+j+1}\frac q{1-q}.
\tag{6.3}
\]

For \(0\le j\le J\), one has \(j/N\le C\epsilon\), and a uniform Taylor/compactness estimate around \((q,j/N)=(\beta,0)\) gives

\[
\log\frac{p_{j+1}}{p_j}\ge-C\epsilon.
\tag{6.4}
\]

Therefore

\[
p_j\ge c_2p_0
\qquad(0\le j\le J).
\]

Summing and using `(6.2)` gives

\[
B_{N,n}(q)
\ge
c\,
\frac{e^{-ND(\beta\|q)}}{1+\sqrt N(\beta-q)}.
\tag{6.5}
\]

Combining `(6.1)` and `(6.5)` proves

\[
\boxed{
 c\frac{e^{-ND(\beta\|q)}}{1+\sqrt N(\beta-q)}
 \le B_{N,n}(q)
 \le e^{-ND(\beta\|q)}.
}
\tag{6.6}
\]

Endpoint checks:

- \(q=\beta\): denominator is one, giving a constant-order lower bound, as required;
- fixed separation \(\beta-q\asymp1\): the denominator is \(\asymp\sqrt N\), matching the single threshold-mass prefactor;
- \(q\downarrow0\): \(D(\beta\|q)\to\infty\), so no contradiction arises.

This independently validates `P12-BINOMIAL-MODERATE-BRACKET-40`.

# 8. New fourth-moment extremal theorem for an atom

We now quantify exactly how much fourth moment a large scalar cluster costs.

## Theorem `P13-ATOM4-EXTREMAL-39`

Let \(X\) be centered and variance one. If

\[
P\{X=a\}=p
\]

for some \(p>1/2\), then

\[
\boxed{
EX^4\ge
\frac{p^2}{1-p}+\frac{(1-p)^2}{p}.
}
\tag{8.1}
\]

For \(p\le1/2\), Jensen gives the sharp universal lower bound \(EX^4\ge1\). Thus the sharp atom-mass function is

\[
J(p)=
\begin{cases}
1,&0<p\le1/2,\\[4pt]
\dfrac{p^2}{1-p}+\dfrac{(1-p)^2}{p},&1/2<p<1.
\end{cases}
\tag{8.2}
\]

### Proof

Let \(q=1-p\). Conditional on \(X\ne a\), write

\[
b=E[X\mid X\ne a],
\qquad
c=E[X^2\mid X\ne a].
\]

Centering gives

\[
b=-\frac{pa}{q}.
\tag{8.3}
\]

Variance one gives

\[
c=\frac{1-pa^2}{q}.
\tag{8.4}
\]

Since \(c\ge b^2\),

\[
1\ge pa^2+q b^2
=pa^2+\frac{p^2a^2}{q}
=\frac{p}{q}a^2,
\]

hence

\[
a^2\le\frac qp.
\tag{8.5}
\]

Jensen on the complement gives

\[
E[X^4\mid X\ne a]\ge c^2.
\]

Set \(u=a^2\). Then

\[
EX^4
\ge
p u^2+\frac{(1-pu)^2}{q}
=:F_p(u),
\qquad
0\le u\le q/p.
\tag{8.6}
\]

A direct derivative calculation gives

\[
F_p'(u)=\frac{2p}{q}(u-1).
\]

If \(p>1/2\), then \(q/p<1\), so \(F_p\) decreases throughout the feasible interval and is minimized at \(u=q/p\). Substituting yields `(8.1)`.

Equality forces both conditional pieces to be deterministic and gives exactly the centered standardized two-point law with masses \(p,q\). For \(p\le1/2\), the fourth-moment minimum under variance one is the Jensen value one, attained for balanced Rademacher; such a law contains an atom of mass \(1/2\ge p\). This proves sharpness of `(8.2)`.

Finally, for \(p>1/2\),

\[
J'(p)=\frac{2p-1}{p^2(1-p)^2}>0,
\tag{8.7}
\]

so the cost is strictly increasing with the atom mass in the relevant regime.

P\{|X_m-z_m|\le\rho_m\}\ge p_m,
\qquad
p_m\to p\in(0,1).
\tag{9.1}
\]

Then, in the extended sense,

\[
\boxed{
\liminf_m EX_m^4\ge J(p).
}
\tag{9.2}
\]

### Proof

If the left side is infinite there is nothing to prove. Otherwise pass to a subsequence on which the liminf is finite; along a further tail,

\[
\sup_mEX_m^4<\infty.
\tag{9.3}
\]

Variance one gives tightness. Also the cluster centers are bounded: eventually \(p_m\ge p/2\), and on the cluster event

\[
|X_m|\ge(|z_m|-\rho_m)_+,
\]

so

\[
1=EX_m^2
\ge
p_m(|z_m|-\rho_m)_+^2.
\]

After a subsequence, \(z_m\to z\) and \(X_m\Rightarrow X\).

The uniform fourth-moment bound makes \(X_m^2\) uniformly integrable, hence

\[
EX=0,
\qquad
EX^2=1.
\tag{9.4}
\]

For every fixed \(\varepsilon>0\), eventually

\[
[z_m-\rho_m,z_m+\rho_m]
\subset[z-\varepsilon,z+\varepsilon].
\]

By the closed-set side of Portmanteau,

\[
P\{X\in[z-\varepsilon,z+\varepsilon]\}
\ge
\limsup_mP\{|X_m-z_m|\le\rho_m\}
\ge p.
\]

Letting \(\varepsilon\downarrow0\),

\[
P\{X=z\}\ge p.
\tag{9.5}
\]

Lower semicontinuity of the fourth moment under weak convergence gives

\[
EX^4\le\liminf_mEX_m^4.
\]

If \(p\le1/2\), Jensen gives \(EX^4\ge1=J(p)\). If \(p>1/2\), the atom in `(9.5)`, monotonicity `(8.7)`, and `P13-ATOM4-EXTREMAL-39` give \(EX^4\ge J(p)\). This proves `(9.2)`.

This theorem is exactly what is needed to prevent an exponentially narrow smooth bump from hiding the fourth-moment cost of a large cluster.
