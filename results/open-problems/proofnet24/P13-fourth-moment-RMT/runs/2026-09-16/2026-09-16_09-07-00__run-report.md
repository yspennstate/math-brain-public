# 4. Current primary RLogLCD source and exact definitions

The current primary source was freshly inspected from the PDF of Manuel Fernandez V, *A distance theorem for inhomogenous random rectangular matrices*, arXiv:2408.06309v2, dated 25 July 2025 / PDF build 28 July 2025.

## 4.1 Theorem 1.1 hypotheses

For `A in R^{n x (n-d)}`, the theorem assumes:

- independent entries;
- a uniform unit-scale anti-concentration bound;
- an expected Hilbert--Schmidt bound;
- an independent vector `X` with independent uniformly anti-concentrated entries and a second-moment bound;
- `1<=d<=lambda n/log n`.

It proves

\[
\mathcal L(P_{H^\perp}X,t\sqrt d)
\le(Ct)^d+e^{-cn}.
\tag{4.1}
\]

Thus the current fixed-candidate distance theorem does not require a realized subgaussian operator-norm tail.

## 4.2 LogLCD and RLogLCD

Fernandez defines

\[
\operatorname{LogLCD}_{L,u}(v)
:=
\inf\left\{
\theta>0:
\operatorname{dist}(\theta v,\mathbb Z^n)
<
L\sqrt{\log_+\!\left(\frac{u\|\theta v\|_2}{L}\right)}
\right\}.
\tag{4.2}
\]

For a random vector `X`, the Randomized Logarithmic LCD uses an independent symmetrization

\[
\overline X=X-X'
\]

and is

\[
\operatorname{RLogLCD}^{X}_{L,u}(v)
:=
\inf\left\{
\theta>0:
E\operatorname{dist}^2
\bigl(\theta(v\star\overline X),\mathbb Z^n\bigr)
<
L^2\log_+\!\left(\frac{u\|\theta v\|_2}{L}\right)
\right\}.
\tag{4.3}
\]

Theorem 6.4 then proves, for incompressible random null normals and `L` between constants times `sqrt(d)`, an exponentially large lower bound of the form

\[
\operatorname{RLogLCD}^{X}_{L,u}(x)
>
 c_1\sqrt d\,e^{c_2n/d}
\tag{4.4}
\]

except on an `e^{-c_3n}` event.

The inspected proof confirms that incompressibility supplies only an **initial** deterministic RLogLCD bound. The exponential boost is obtained from the fact that the normal is orthogonal to many independent random vectors, via lattice-like nets and tensorized small-ball estimates. Proposition 6.2 is the net/level-set bottleneck.

This distinction is exactly what the new two-point theorem makes concrete.

# 5. New theorem: exact two-point RLogLCD identity

We prove `P13-TWOPOINT-RLOG-IDENTITY-44`.

Let `xi` be a centered variance-one two-point law. Write its probabilities as

\[
P\{\xi=a\}=p,
\qquad
P\{\xi=b\}=1-p=q,
\qquad
r=pq.
\tag{5.1}
\]

Centering and variance one force, up to swapping the two atoms,

\[
a=\sqrt{\frac qp},
\qquad
b=-\sqrt{\frac pq}.
\tag{5.2}
\]

Hence the atom gap is

\[
\Delta:=a-b
=
\sqrt{\frac qp}+\sqrt{\frac pq}
=
\frac1{\sqrt{pq}}
=
\frac1{\sqrt r}.
\tag{5.3}
\]

Let `xi'` be an independent copy and put

\[
\overline\xi=\xi-\xi'.
\]

Then exactly

\[
P\{\overline\xi=0\}=p^2+q^2=1-2r,
\qquad
P\{\overline\xi=\Delta\}=r,
\qquad
P\{\overline\xi=-\Delta\}=r.
\tag{5.4}
\]

For `X=(xi_1,...,xi_n)`, `v in R^n`, and any `theta>0`, the squared distance to the integer lattice separates coordinatewise. Since distance to `Z` is even,

\[
\begin{aligned}
E\operatorname{dist}^2
\bigl(\theta(v\star\overline X),\mathbb Z^n\bigr)
&=
\sum_{i=1}^n
E\operatorname{dist}^2(\theta v_i\overline\xi_i,\mathbb Z)\\
&=
2r\sum_{i=1}^n
\operatorname{dist}^2\!\left(\frac{\theta}{\sqrt r}v_i,\mathbb Z\right)\\
&=
\boxed{
2r\,
\operatorname{dist}^2
\!\left(\frac{\theta}{\sqrt r}v,\mathbb Z^n\right).
}
\end{aligned}
\tag{5.5}
\]

Set

\[
s=\frac\theta{\sqrt r}.
\]

The RLogLCD condition `(4.3)` becomes

\[
\operatorname{dist}^2(sv,\mathbb Z^n)
<
\frac{L^2}{2r}
\log_+\!\left(
\frac{u s\sqrt r\|v\|_2}{L}
\right).
\tag{5.6}
\]

Define

\[
L_*:=\frac L{\sqrt{2r}},
\qquad
u_*:=\frac u{\sqrt2}.
\tag{5.7}
\]

Then

\[
\frac{u_*}{L_*}
=
\frac{u\sqrt r}{L},
\tag{5.8}
\]

so `(5.6)` is precisely the squared form of the ordinary LogLCD condition

\[
\operatorname{dist}(sv,\mathbb Z^n)
<
L_*\sqrt{
\log_+\!\left(\frac{u_*\|sv\|_2}{L_*}\right)
}.
\tag{5.9}
\]

Taking infima and recalling `theta=s sqrt(r)` yields

\[
\boxed{
\operatorname{RLogLCD}^{X}_{L,u}(v)
=
\sqrt r\,
\operatorname{LogLCD}_{L/\sqrt{2r},\,u/\sqrt2}(v).
}
\tag{5.10}
\]

This proves `(0.6)`.

### Balanced Rademacher specialization

For `p=q=1/2`,

\[
r=1/4,
\qquad
\overline\xi\in\{0,\pm2\},
\]

with probabilities `1/2,1/4,1/4`. Formula `(5.10)` becomes

\[
\boxed{
\operatorname{RLogLCD}^{\rm Rad}_{L,u}(v)
=
\frac12
\operatorname{LogLCD}_{\sqrt2L,\,u/\sqrt2}(v).
}
\tag{5.11}
\]

No approximation, CLT, moment comparison, or asymptotic limit occurs in this identity.

# 6. New no-go: classical spread cannot imply exponential RLogLCD

We prove `P13-RAD-SPREAD-RLOG-NOGO-44`.

Let

\[
v_0=\frac1{\sqrt n}(1,\ldots,1).
\tag{6.1}
\]

For ordinary LogLCD, take `s=sqrt(n)`. Then

\[
sv_0=(1,\ldots,1)\in\mathbb Z^n,
\]

so

\[
\operatorname{dist}(sv_0,\mathbb Z^n)=0.
\tag{6.2}
\]

If

\[
\frac{u\sqrt n}{2L}>1,
\tag{6.3}
\]

then the logarithm in the Rademacher-specialized LogLCD condition is strictly positive. Hence `(6.2)` is a strict admissible inequality, and `(5.11)` gives

\[
\operatorname{RLogLCD}^{\rm Rad}_{L,u}(v_0)
\le\frac{\sqrt n}{2}.
\tag{6.4}
\]

Now fix any `delta in (0,1)` and let `J` contain `delta n` coordinates, ignoring integer rounding. The norm of the projection of `v_0` onto `J` is `sqrt(delta)`. The closest **unit** vector supported on `J` is the normalized projection, so its squared distance from `v_0` is

\[
(1-\sqrt\delta)^2+(1-\delta)
=2-2\sqrt\delta.
\tag{6.5}
\]

Therefore

\[
\boxed{
\operatorname{dist}
\bigl(v_0,
\operatorname{Sparse}(\delta n)\cap S^{n-1}
\bigr)
=
\sqrt{2-2\sqrt\delta}.
}
\tag{6.6}
\]

In particular, for any fixed

\[
0<\rho<\sqrt{2-2\sqrt\delta},
\]

`v_0` is `(delta,rho)`-incompressible, and all `n` of its coordinates have the ideal spread magnitude `1/sqrt(n)`.

Balanced Rademacher has

\[
E\xi=0,
\qquad
E\xi^2=1,
\qquad
E\xi^4=1,
\tag{6.7}
\]

so for every `1<gamma<2` it lies strictly below `B_exact(gamma)`.

Consequently:

\[
\boxed{
\begin{array}{c}
\text{uniform B4 + fixed classical incompressibility + linear spread}\\
\text{does not deterministically force large RLogLCD.}
\end{array}
}
\tag{6.8}
\]

This is not a counterexample to the source exponent and not a counterexample to Fernandez Theorem 6.4. The flat vector is deterministic, whereas Theorem 6.4 exploits the additional random condition that a normal is orthogonal to many independent random columns. Rather, `(6.8)` proves that the P12/P13 classical spread module cannot by itself replace the law-adapted random-kernel RLogLCD argument.

In the P13 moderate-surplus regime, `d=k_m` satisfies

\[
k_m\log m=o(m).
\tag{6.9}
\]

For `L asymp sqrt(d)`, condition `(6.3)` holds eventually and Fernandez's target scale `sqrt(d)e^{c n/d}` is vastly larger than the deterministic `O(sqrt n)` witness `(6.4)`. Thus the exponential boost must be probabilistic.

# 7. New quantitative resonant cap

We prove `P13-RAD-RLOG-RESONANT-CAP-44`.

Continue with balanced Rademacher and `v_0` from `(6.1)`. Put

\[
\theta_0=\frac{\sqrt n}{2}.
\tag{7.1}
\]

For every coordinate and every realization of the symmetrized Rademacher variable

\[
\overline\xi_i\in\{0,\pm2\},
\]

we have

\[
\theta_0(v_0)_i\overline\xi_i
\in\{0,\pm1\}
\subset\mathbb Z.
\tag{7.2}
\]

For any other `v in S^{n-1}`, distance to the lattice is at most distance to this explicit integer point. Therefore

\[
\begin{aligned}
\operatorname{dist}^2
\bigl(\theta_0(v\star\overline X),\mathbb Z^n\bigr)
&\le
\theta_0^2
\sum_{i=1}^n
(v_i-(v_0)_i)^2\overline\xi_i^2.
\end{aligned}
\tag{7.3}
\]

Taking expectations and using

\[
E\overline\xi_i^2=2
\]

gives

\[
\boxed{
E\operatorname{dist}^2
\bigl(\theta_0(v\star\overline X),\mathbb Z^n\bigr)
\le
\frac n2\|v-v_0\|_2^2.
}
\tag{7.4}
\]

At `theta_0`, the RLogLCD right-hand side is

\[
L^2\log_+\!\left(\frac{u\sqrt n}{2L}\right).
\tag{7.5}
\]

Thus, when the logarithm is positive, every vector in the explicit cap

\[
\|v-v_0\|_2^2
<
\frac{2L^2}{n}
\log\!\left(\frac{u\sqrt n}{2L}\right)
\tag{7.6}
\]

satisfies
