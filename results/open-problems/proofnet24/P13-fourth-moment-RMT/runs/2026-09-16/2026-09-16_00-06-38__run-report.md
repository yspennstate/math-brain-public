# 6. New theorem B — optimized artificial-jitter projection small ball

## `P13-OPTJITTER-COISOMETRY-35` — PROVED

For a real scalar law `xi`, define
\[
Q_\xi(\delta)=\sup_{z\in\mathbb R}P\{|\xi-z|\le\delta\}.
\]
Let `X=(xi_1,...,xi_n)` have iid coordinates with law `xi`. Let `L in R^{k x n}` satisfy `LL^T=I_k`. Fix `a>1/sqrt(3)`, `delta>0`, `t>=0`, and `z in R^k`. Then
\[
\boxed{
P\{\|LX-z\|_2\le t\sqrt k\}
\le
\frac1{1-1/(3a^2)}
\left[
\sqrt{\pi e}\,
Q_\xi(\delta)
\left(\frac t\delta+a\right)
\right]^k.
}
\]

No centering, moment, tail, density, arithmetic, or leverage hypothesis is used.

### Proof

Let `U_1,...,U_n` be iid `Unif[-delta,delta]`, independent of `X`. Each coordinate of `X+U` has density
\[
g(y)=\frac{P\{X\in[y-\delta,y+\delta]\}}{2\delta},
\qquad
\|g\|_\infty\le\frac{Q_\xi(\delta)}{2\delta}.
\]
By `P13-LPP-PROJECTION-DENSITY-35`,
\[
\|f_{L(X+U)}\|_\infty
\le
\left(
\frac{Q_\xi(\delta)}{\sqrt2\,\delta}
\right)^k.
\]
Also
\[
E\|LU\|_2^2
=
\frac{\delta^2}{3}\operatorname{tr}(LL^\top)
=
\frac{k\delta^2}{3}.
\]
Hence Markov gives
\[
P\{\|LU\|_2\le a\delta\sqrt k\}
\ge
p_a:=1-\frac1{3a^2}>0.
\]
The original small-ball event depends only on `X`, so it is independent of this good-noise event. Their intersection implies
\[
\|L(X+U)-z\|_2
\le
(t+a\delta)\sqrt k.
\]
The `k`-ball volume estimate
\[
\operatorname{vol}(B_2^k(R))
\le
\left(\sqrt{2\pi e}\,\frac R{\sqrt k}\right)^k
\]
therefore gives
\[
p_a P\{\|LX-z\|\le t\sqrt k\}
\le
\left[
\sqrt{\pi e}\,
Q_\xi(\delta)
\left(\frac t\delta+a\right)
\right]^k.
\]
This is the claim.

### Optimized profile

Define
\[
\boxed{
\Psi_{\xi,a}(t)
:=
\inf_{\delta>0}
Q_\xi(\delta)
\left(\frac t\delta+a\right).
}
\]
Then
\[
P\{\|LX-z\|\le t\sqrt k\}
\le
p_a^{-1}
[\sqrt{\pi e}\,\Psi_{\xi,a}(t)]^k.
\]

At `a=1`, this improves the newest P12 real constant from
`(3/2)[e sqrt(pi) Q(delta)(1+t/delta)]^k`
to
\[
\boxed{
\frac32
[\sqrt{\pi e}\,Q(\delta)(1+t/\delta)]^k.
}
\]

K\sqrt m\,r.
\]
But `||y||>=1-r`, and the normalized sparse vector `y/||y||` obeys the global sparse lower bound, so
\[
\|A_{-j}^\top y\|_2
\ge
(1-r)c_0\sqrt m.
\]
Choosing, for example,
\[
r\le\min\{1/4,c_0/(4K)\}
\]
contradicts the two inequalities. This proves the theorem.

### What this theorem does and does not close

It globalizes the **compressible-normal component** of the fixed-candidate structural event throughout the strictly subcritical fourth-moment regime, with arbitrary target confidence, and does so without paying candidate entropy.

It does **not** yet globalize the incompressible low-randomized-LCD / lattice-structured component of Fernandez's distance theorem. The current Fernandez primary proof explicitly obtains `e^{-cn}` first from compressible-null avoidance and again from the randomized-logarithmic-LCD structure theorem. The new result removes the former as a candidate-by-candidate debt below `B_exact`; the latter remains.

The confidence-dependent radius is not an accidental weakness. Uniform fourth moment over arbitrary triangular arrays gives operator-norm **tightness**, not a uniform fixed-constant tail tending to zero without additional assumptions. A fixed-law Bai–Yin theorem can be stronger, but is not needed or imported into this triangular result.
