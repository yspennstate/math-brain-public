# 7. Uniform fourth moment gives an explicit unit-scale concentration gap

This is retained from earlier P13 work but re-derived here because it supplies the exact constant used by the new theorem.

Let `xi,xi'` be iid, centered, variance one, with

\[
E\xi^4\le B.
\]

Put

\[
Z=\xi-\xi'.
\]

Then

\[
EZ^2=2,
\qquad
EZ^4=2E\xi^4+6\le2B+6.
\]

Apply Paley--Zygmund to `W=Z^2` with parameter `1/2`:

\[
P\{|Z|\ge1\}
=P\{W\ge\tfrac12EW\}
\ge
\frac{(1-1/2)^2(EW)^2}{EW^2}
\ge
\frac1{2B+6}.
\tag{7.1}
\]

Define the interval-length-one concentration function

\[
Q_1(\xi)=\sup_xP\{\xi\in(x,x+1]\}.
\]

If both iid copies lie in the same interval `(x,x+1]`, then `|Z|<1`.  Therefore

\[
Q_1(\xi)^2
\le
P\{|Z|<1\}
\le
1-\frac1{2B+6}.
\]

Hence

\[
\boxed{
Q_1(\xi)
\le
b_B:=\sqrt{1-\frac1{2B+6}}<1.
}
\tag{7.2}
\]

This is a uniform constant for a triangular family only when the fourth moments are uniformly bounded.  Merely having a finite fourth moment at each level does not yield one fixed `b<1`.

# 8. New theorem A — global dense bounded-height integer relations

## `P13-GLOBAL-DENSE-INTEGER-RELATION-37` — PROVED

### 8.1 Statement

Let

\[
A_m\in\mathbb R^{N_m\times m}
\]

have iid entries with law `xi_m`.  Assume that for some fixed `Gamma<infinity` and `b<1`, eventually

\[
N_m\le\Gamma m,
\qquad
Q_1(\xi_m)\le b.
\tag{8.1}
\]

Let

\[
n_m=m+k_m-1,
\qquad
k_m\log m=o(m).
\tag{8.2}
\]

Fix `alpha>0` and an arbitrary target exponent `A_0>0`.  Then there exists

\[
c_*=c_*(b,\Gamma,\alpha,A_0)>0
\]

such that, for all sufficiently large `m`,

\[
\boxed{
P(E_m)\le e^{-A_0m},
}
\tag{8.3}
\]

where `E_m` is the event that there exist a deleted column `j in [m]` and a nonzero integer vector `p in Z^{N_m}` satisfying

\[
\alpha m\le |\operatorname{supp}p|\le n_m,
\tag{8.4}
\]

\[
\|p\|_2\le c_*m,
\tag{8.5}
\]

and

\[
\|A_{m,-j}^{\!T}p\|_\infty\le\frac14.
\tag{8.6}
\]

No centering, variance, moment, density, tail, or operator-norm hypothesis is used in this theorem beyond the fixed unit-scale concentration gap `(8.1)`.

### 8.2 Fixed integer vector: Kolmogorov--Rogozin

Fix `p in Z^{N_m}` with exactly `s` nonzero coordinates.  For every nonzero integer coefficient `p_i`,

\[
Q_1(p_i\xi_m)
=
Q_{1/|p_i|}(\xi_m)
\le
Q_1(\xi_m)
\le b.
\tag{8.7}
\]

Kolmogorov--Rogozin `(6.1)` therefore gives

\[
Q_1\left(\sum_i p_i\xi_i\right)
\le
\frac{C_{\rm KR}}{\sqrt{s(1-b)}}
=:
\frac{C_b}{\sqrt s}.
\tag{8.8}
\]

For a fixed deleted column `j`, the `m-1` coordinates of `A_{-j}^Tp` are independent, because they use distinct original columns.  The interval `[-1/4,1/4]` has length `1/2`, so `(8.8)` implies

\[
P\left\{
\|A_{-j}^{\!T}p\|_\infty\le\frac14
\right\}
\le
\left(\frac{C_b}{\sqrt s}\right)^{m-1}.
\tag{8.9}
\]

This is the decisive global product power.  It comes from the **original independent columns**, not from any projected-coordinate independence claim.

### 8.3 Lattice-point count at fixed support

For a fixed support `S` of size `s`, the number of integer vectors supported in `S` with Euclidean norm at most `D` obeys

\[
\#\{p\in\mathbb Z^S:\ \|p\|_2\le D\}
\le
\left[C_{\rm lat}\left(1+\frac D{\sqrt s}\right)\right]^s
\tag{8.10}
\]

for one universal constant `C_lat`.

Indeed, place the disjoint unit cubes centered at such integer points.  Their union lies in the Euclidean ball of radius `D+sqrt(s)/2`; the standard volume bound

\[
\operatorname{vol}(B_2^s(R))
\le
\left(\frac{CR}{\sqrt s}\right)^s
\]

gives `(8.10)`.

### 8.4 Union bound and exact entropy cancellation

Set `D=c_*m`.  Union over the deleted column, support size, support, and integer point.  By `(8.9)` and `(8.10)`,

\[
P(E_m)
\le
m
\sum_{s=\lceil\alpha m\rceil}^{n_m}
\binom{N_m}{s}
\left[C_{\rm lat}\left(1+\frac{c_*m}{\sqrt s}\right)\right]^s
\left(\frac{C_b}{\sqrt s}\right)^{m-1}.
\tag{8.11}
\]

For `s>=alpha m` and large `m`,

\[
1+\frac{c_*m}{\sqrt s}
\le
2\frac{c_*}{\sqrt\alpha}\sqrt m.
\]

Also

\[
\binom{N_m}{s}\le2^{N_m}\le2^{\Gamma m}.
\]

Put

\[
a_*:=\frac{2C_{\rm lat}c_*}{\sqrt\alpha},
\qquad
b_*:=\frac{C_b}{\sqrt\alpha}.
\]

For large `m`, `a_*sqrt(m)>=1`, and `s<=n_m`; hence `(8.11)` is at most

\[
2m^2\,
2^{\Gamma m}
(a_*\sqrt m)^{n_m}
(b_*m^{-1/2})^{m-1}.
\tag{8.12}
