# 4. New theorem: uniform fourth moment does not recover an exponential operator-norm tail

We now prove `P13-B4-NORMTAIL-NOGO-43`.

Fix

\[
B>1,\qquad L>0,
\]

and define

\[
\theta:=\frac{B-1}{4}>0.
\tag{4.1}
\]

For large `m`, set

\[
a_m:=2L\sqrt m,
\qquad
q_m:=\frac{\theta}{a_m^4}
=\frac{\theta}{16L^4m^2},
\tag{4.2}
\]

and choose `b_m>0` so that the symmetric four-point variable `X_m` with

\[
P\{X_m=\pm a_m\}=q_m/2,
\qquad
P\{X_m=\pm b_m\}=(1-q_m)/2
\tag{4.3}
\]

has variance one. Thus

\[
(1-q_m)b_m^2+q_ma_m^2=1,
\]

or

\[
\boxed{
b_m^2=\frac{1-q_ma_m^2}{1-q_m}.
}
\tag{4.4}
\]

For all sufficiently large `m`, the numerator is positive because

\[
q_ma_m^2=\frac{\theta}{4L^2m}\to0.
\tag{4.5}
\]

The law is symmetric, so `EX_m=0`, and by construction `EX_m^2=1`.

## 4.1 Uniform fourth moment

The fourth moment is

\[
EX_m^4
=(1-q_m)b_m^4+q_ma_m^4
=
\frac{(1-q_ma_m^2)^2}{1-q_m}+\theta.
\tag{4.6}
\]

For large `m`, `a_m^2>=1`, hence

\[
q_ma_m^2\ge q_m.
\]

Therefore

\[
0\le1-q_ma_m^2\le1-q_m,
\]

and

\[
\frac{(1-q_ma_m^2)^2}{1-q_m}
\le1-q_m\le1.
\tag{4.7}
\]

Consequently

\[
\boxed{
EX_m^4\le1+\theta
=\frac{B+3}{4}<B.
}
\tag{4.8}
\]

Thus there is a fixed positive fourth-moment margin.

## 4.2 Smooth the law without losing the moment ceiling

Let `Z` be a fixed symmetric mean-zero `C_c^\infty` variable supported in `[-1,1]`, with

\[
v:=EZ^2<\infty,
\qquad
w:=EZ^4<\infty.
\]

Choose one sufficiently small fixed `eta>0`, depending only on `B` and the chosen bump, so that

\[
\sqrt{1+\eta^2v}<3/2
\tag{4.9}
\]

and the fourth-moment perturbation below remains inside the margin in `(4.8)`.

Put

\[
Y_m=X_m+\eta Z,
\qquad
s:=\sqrt{1+\eta^2v},
\qquad
\xi_m:=Y_m/s.
\tag{4.10}
\]

Then `xi_m` has a `C_c^\infty` density, is centered, and has variance one. Independence and symmetry give

\[
EY_m^4
=EX_m^4+6\eta^2v+\eta^4w.
\tag{4.11}
\]

Hence

\[
E\xi_m^4
=
\frac{EX_m^4+6\eta^2v+\eta^4w}{(1+\eta^2v)^2}.
\tag{4.12}
\]

By `(4.8)` and continuity at `eta=0`, `eta` can be chosen so that the right-hand side is at most `B` for every sufficiently large `m`. Finitely many initial levels can be patched by a sufficiently narrow smooth Rademacher mollification with fourth moment below `B`.

Thus

\[
\sup_mE|\xi_m|^4\le B.
\tag{4.13}
\]

No common compact support is claimed: the spike locations scale as `sqrt(m)`. Each level separately has compact support.

## 4.3 A spike forces a large operator norm

Retain the latent mixture label in `(4.3)`. If a matrix entry chooses the spike component, then before variance normalization its magnitude is at least

\[
a_m-\eta=2L\sqrt m-\eta.
\]

Using `(4.9)`, for all sufficiently large `m`,

\[
\frac{2L\sqrt m-\eta}{s}
\ge L\sqrt m.
\tag{4.14}
\]

Therefore the event that at least one of the `N_m m` entries chooses the spike component implies

\[
\max_{i,j}|A_{ij}|\ge L\sqrt m
\]

and hence

\[
\|A_m\|_{op}\ge L\sqrt m.
\tag{4.15}
\]

The latent spike choices are independent with probability `q_m`, so

\[
P\{\text{at least one spike}\}
=1-(1-q_m)^{N_mm}.
\tag{4.16}
\]

Since `N_m/m -> gamma`,

\[
N_mm q_m
=
\frac{N_m}{m}\frac{\theta}{16L^4}
\longrightarrow
\frac{\gamma\theta}{16L^4}
=
\frac{\gamma(B-1)}{64L^4},
\tag{4.17}
\]

while `q_m ->0`. Therefore

\[
1-(1-q_m)^{N_mm}
\longrightarrow
1-\exp\!\left[-\frac{\gamma(B-1)}{64L^4}\right].
\tag{4.18}
\]

Combining `(4.15)`--`(4.18)` proves `(0.7)`.

QED.

### Exact interpretation

This theorem does **not** say that `||A_m||/sqrt(m)` fails to be tight under a uniform fourth moment. Latała-type expectation bounds are fully consistent with tightness. The theorem says something more specific and exactly relevant to rewriting a subgaussian proof:

\[
\boxed{
\text{uniform fourth moment alone cannot supply a universal }e^{-cm}
\text{ norm-exception event.}
}
\tag{4.19}
\]

The distinction between `O_P(sqrt(m))` and exponentially high-probability `O(sqrt(m))` is essential when exponentially many adaptive objects are present.

# 5. Matching max-entry upper bound

Let any triangular family satisfy

\[
\sup_mE|\xi_m|^4\le B.
\]

For each entry, Markov gives

\[
P\{|\xi_m|>L\sqrt m\}
\le
\frac{B}{L^4m^2}.
\tag{5.1}
\]

A union bound over the `N_m m` entries gives

\[
P\left\{
\max_{i,j}|A_{ij}|>L\sqrt m
\right\}
\le
N_mm\frac{B}{L^4m^2}
=
\frac{B}{L^4}\frac{N_m}{m}.
\tag{5.2}
\]

This proves `(0.8)`.

For large `L`, the lower construction `(0.7)` has probability

\[
1-e^{-\gamma(B-1)/(64L^4)}
\asymp_{B,\gamma}L^{-4},
\]

so the fourth-moment order of the max-entry obstruction is sharp up to constants.

# 6. The spike obstruction is removable by row selection

The previous theorem would be misleading if recorded as a counterexample to `(0.1)`. It is not.

Let `R_m` be the number of rows containing at least one spike-labelled entry in the construction. A fixed row contains a spike with probability

\[
r_m=1-(1-q_m)^m\le mq_m.
\tag{6.1}
\]

Hence

\[
ER_m=N_mr_m
\le N_mm q_m
\longrightarrow
\mu:=\frac{\gamma(B-1)}{64L^4}<\infty.
\tag{6.2}
\]

The candidate size is

\[
n_m=m+k_m-1,
\]

and under the source regime `k_m=o(m)`,

\[
D_m:=N_m-n_m
=(\gamma-1)m+o(m).
\tag{6.3}
\]

Thus `D_m` is linear in `m`. By Markov,

\[
P\{R_m>D_m\}
\le\frac{ER_m}{D_m}
\to0.
\tag{6.4}
\]

On `R_m<=D_m`, at least

\[
N_m-R_m\ge N_m-D_m=n_m
\]

rows contain no spike labels, so there exists a candidate `T` of the required size with no spike row.

Therefore

\[
\boxed{
P\{\exists\ T,\ |T|=n_m,\ T\text{ contains no spike-labelled row}\}
\to1.
}
\tag{6.5}
\]

This proves `P13-B4-SPIKEROW-TRIMMABLE-43`.

### Consequence for proof design

The full `N_m x m` operator norm is too blunt a control variable for the bounded-fourth row-minimum problem. A successful fourth-moment proof may have to exploit one of the following row-aware structures:

1. trim a small number of high-energy rows **before** invoking norm geometry;
2. work with candidate-local Hilbert--Schmidt or regularized Hilbert--Schmidt quantities;
3. use robust small-ball / distance-to-span arguments that require only second-moment input;
4. retain the overlapping-candidate geometry globally instead of assigning a full-matrix norm exception to every candidate.

The new theorem rigorously rules out only the naive transplantation of a subgaussian exponential norm event.

# 7. Relation to the actual RLogLCD bottleneck

The current primary version of Manuel Fernandez's *A distance theorem for inhomogenous random rectangular matrices*, arXiv:2408.06309v2 (25 July 2025), was inspected directly.

Its Theorem 1.1 assumes:

- independent uniformly anti-concentrated entries;
- an expected Hilbert--Schmidt bound on the random spanning matrix;
- an independent vector with a second-moment bound and uniformly anti-concentrated entries;
- codimension `1 <= d <= lambda n/log n`.

It proves

\[
\mathcal L(P_{H^\perp}X,t\sqrt d)
\le(Ct)^d+e^{-cn}.
\tag{7.1}
\]

The paper defines the law-adapted Randomized Logarithmic LCD

\[
\operatorname{RLogLCD}^{X}_{L,u}(v)
=
\inf\left\{
\theta>0:
E\,\operatorname{dist}^2(\theta(X\star v),\mathbb Z^n)
<
L^2\log_+\!\left(\frac{u\|\theta v\|_2}{L}\right)
\right\}.
\tag{7.2}
\]

The current Theorem 6.4 gives, for incompressible null normals and `L` of order `sqrt(d)`, an exponentially large RLogLCD with `e^{-cn}` exceptional probability.

Two points matter for P13.

First, this fixed-candidate theorem does **not** require a subgaussian realized operator-norm tail. Its hypotheses are anti-concentration plus second/Hilbert--Schmidt moment control. Uniform fourth moment already supplies the retained fixed unit-scale anti-concentration constant, and variance normalization gives the expected Hilbert--Schmidt bound. Therefore `P13-B4-NORMTAIL-NOGO-43` does **not** invalidate the fixed-candidate Fernandez route.

Second, Fernandez's `e^{-cn}` structural exception is attached to one random subspace. P13 minimizes over

\[
\binom{N_m}{m+k_m-1}
=
\exp(h(\gamma)m+o(m))
\]

strongly overlapping candidates. Unless the structural event is globalized before candidate selection, the unspecified constant `c` cannot be assumed to beat `h(gamma)`.

The retained P13 work has already globalized compressibility and low-height ordinary lattice relations. The missing lower-side problem is still the **high-height, source-law-adapted RLogLCD level-set mechanism**.

The new norm theorem narrows the route choice on the **upper** side: a bounded-fourth rewrite must not demand the original subgaussian global norm tail as a black box.

# 8. Truncation, Bai--Yin, Lindeberg, small ball, leave-one-out

The requested route comparison is now as follows.

## 8.1 Truncation / replacement

Polynomial or `sqrt(m)`-scale truncation followed by Weyl cannot resolve an exponentially small target directly. In the new construction, removing the spike entries changes the full matrix by operator norm at least `L sqrt(m)` with probability bounded away from zero, whereas the target least singular value is `exp[-Theta(m/k)]`.

The only potentially useful truncation is **row-aware**: discard a small set of contaminated rows and exploit the fact that the minimizing candidate has a linear deletion budget. That is a different argument from global truncation+Weyl.

## 8.2 Bai--Yin-type control

The classical sample-covariance edge theorem of Yin--Bai--Krishnaiah assumes one fixed iid law with finite fourth moment and gives macroscopic almost-sure edge convergence. That is fully compatible with the bounded-fourth program for a fixed law.

It does not imply a uniform triangular-array exponential tail. The new family changes with `m` and places mass `Theta(m^{-2})` at amplitude `Theta(sqrt(m))`; that is invisible to a fixed-law Bai--Yin statement but produces a constant-probability max-entry event over `Theta(m^2)` entries.

Therefore Bai--Yin is a useful fixed-law coarse norm theorem, not a replacement for a subgaussian exceptional probability in the triangular theorem.

## 8.3 Lindeberg

Moment matching / Lindeberg replacement is still unsuitable as the primary source-scale proof. Low moments do not record the narrow-lattice and narrow-cluster resonances already exhibited in retained counterexamples. The new rare-spike family adds a second warning: very rare events spread over `Theta(m^2)` entries can survive at constant matrix probability while contributing only a controlled fourth moment.

## 8.4 Robust small ball and leave-one-out

These remain the viable lower-side route. Uniform fourth moment gives fixed anti-concentration at unit scale; current distance theorems then recover the correct `(Ct)^d` fixed-candidate small-ball power under only second-moment/Hilbert--Schmidt control. The unresolved task is not fixed-candidate least-singular theory but globalizing the structural RLogLCD event across overlapping candidates.
