# 3. Proof of `P25-FIXED-K0-RELATION-COMPRESSION-25`

Let

\[
A=C_r^*(F_2).
\]

Let \(P\) be a projection over \(A\), let \(q\) be an exact finite-support projection over \(\mathbb C F_2\), and assume

\[
[P]=[q]\in K_0(A).
\]

After stabilization there are an auxiliary projection \(E\) and a norm-continuous projection path

\[
P_t,
\qquad
0\le t\le1,
\]

with

\[
P_0=P\oplus E,
\qquad
P_1=q\oplus E.
\tag{3.1}
\]

Let \(A_0\in M_n(\mathbb C F_2)\) be self-adjoint with

\[
\|A_0-P\|<\frac1{256}.
\tag{3.2}
\]

## 3.1 Simultaneous finite-support approximation

Finite matrices over \(\mathbb C F_2\) are norm dense in finite matrices over \(A\).

By uniform continuity of \(P_t\), choose a finite partition

\[
0=t_0<t_1<\cdots<t_m=1
\]

so fine that the path moves arbitrarily little on every subinterval.

Approximate the finitely many node projections \(P_{t_j}\), and the auxiliary projection \(E\), by self-adjoint finite group-ring matrices. At the initial endpoint use the prescribed matrix \(A_0\); at the final endpoint use the exact finite-support projection \(q\). Choose the same finite-support self-adjoint approximation \(e\) to the auxiliary block at both endpoints.

Choose all node approximations and the partition fine enough that linear interpolation between successive nodes remains within \(1/256\) of the original stable projection path.

Because only finitely many group-ring coefficients occur, there is one finite number \(R_0\) such that every matrix on the resulting piecewise-linear path has propagation at most \(R_0\).

Thus for every \(t\), there is a projection \(P'_t\) on the stable path with

\[
\|B_t-P'_t\|<\frac1{256}.
\tag{3.3}
\]

## 3.2 Defect estimate

Write

\[
B_t=P'_t+E_t,
\qquad
\|E_t\|<\gamma:=\frac1{256}.
\]

Since \((P'_t)^2=P'_t\),

\[
B_t^2-B_t
=P'_tE_t+E_tP'_t+E_t^2-E_t.
\]

Therefore

\[
\|B_t^2-B_t\|
\le
3\gamma+\gamma^2
=
\gamma(3+\gamma).
\]

For \(\gamma=1/256\),

\[
\gamma(3+\gamma)
=
\frac{769}{65536}
<
\frac{1024}{65536}
=
\frac1{64}.
\]

This proves `(0.1)`.

### Exact limitation

The lemma produces existence of a finite relation radius \(R_0\) for a fixed relation. It does **not** bound \(R_0\) from the endpoint propagation alone. This limitation is essential and is exactly why the result does not solve moving-class relation complexity.

# 6. Exact limitation: fixed class versus moving class

For a **fixed** limit class, compactness and density produce some finite relation radius \(R_0\). Once \(R_0\) is fixed, P40's distortion tends to one automatically.

For a **moving** class \(x_L\), the required relation radius \(R_L\) may itself diverge. The earlier cyclic and nonamenable P25 counterexamples prove that this can happen at order \(L\) or \(L/\log L\).

Therefore the argument above does **not** imply a general Baum–Connes permanence theorem under marked convergence.

The fixed/moving distinction is

\[
\boxed{
\text{fixed K0 relation}
\Rightarrow
\text{some finite relation radius}
\Rightarrow
\text{eventual transfer},
}
\]

whereas

\[
\boxed{
\text{moving K0 relations}
\not\Rightarrow
\text{uniform finite relation radius}.
}
\]

This remains fully consistent with `P25-LOCAL-CB-CONVERGENCE-NOT-K1-CONTINUITY-CE-24`.

# 9. Adversarial checks and failed routes

## 9.1 Trace locking alone still does not classify K0

The statement

> equal canonical trace implies equal K0 class in \(C_r^*(G_L)\)

is **not** used and is not proved.

P01-P41A gives only the image of the trace map, not injectivity. The present class theorem uses a transported stable relation, not trace cancellation.

## 9.2 No global reduced quotient map

There is no global reduced-C* homomorphism induced by

\[
F_2\twoheadrightarrow C_L*\mathbb Z.
\]

The kernel is nonamenable, as recorded by P18/P25. The present proof evaluates a finite group-ring path coefficientwise and then applies an explicit reduced-norm bound to its defects.

## 9.3 No stage gap is manufactured

The projection

\[
Q_L
=
\mathbf1_{[1/2,\infty)}(p_{N_0}(D_L))
\]

is a reduced-C* low-energy projection selected by the polynomial cutoff.

It need not equal

\[
\mathbf1_{\{0\}}(D_L).
\]

The positive spectrum of \(D_L\) may still enter the low-energy window.

## 9.4 Fixed class does not solve moving relations

The finite relation radius \(R_0\) exists because the limit relation is fixed and the path is compact. There is no uniform estimate for a moving family of classes. The preceding P25 relation-escape examples remain fully active.
