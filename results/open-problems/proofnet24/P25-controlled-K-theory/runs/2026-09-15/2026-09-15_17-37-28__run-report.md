# 3. Majority plateau polynomial — self-contained quantitative form

Fix

\[
0<\delta_0<\delta<M.
\]

Set

\[
t=\frac{\delta+\delta_0}{2},
\qquad
\gamma=\frac{\delta-\delta_0}{2M},
\qquad
z(x)=\frac{t-x}{M}.
\tag{3.1}
\]

For an odd integer `n=2m+1`, define

\[
q_n(x)
=
\sum_{k=m+1}^{n}
\binom nk
\left(\frac{1+z(x)}2\right)^k
\left(\frac{1-z(x)}2\right)^{n-k}.
\tag{3.2}
\]

This is a real polynomial of degree at most `n`.

Put

\[
\varepsilon_n
=
\exp\left(-\frac{n\gamma^2}{2}\right)
=
\exp\left(
-\frac{n(\delta-\delta_0)^2}{8M^2}
\right).
\tag{3.3}
\]

Then

\[
0\le q_n(x)\le1
\qquad(0\le x\le M),
\tag{3.4}
\]

\[
q_n(x)\ge1-\varepsilon_n
\qquad(0\le x\le\delta_0),
\tag{3.5}
\]

and

\[
q_n(x)\le\varepsilon_n
\qquad(\delta\le x\le M).
\tag{3.6}
\]

### Proof of the tail bound

For `x in [0,M]`, put

\[
p(x)=\frac{1+z(x)}2.
\]

Then `p(x) in [0,1]` and `q_n(x)` is the strict-majority probability for `Bin(n,p(x))`.

If `x<=delta_0`, then

\[
p(x)\ge\frac12+\frac\gamma2.
\]

For every `s>0`, Markov's inequality gives, for `X~Bin(n,p)`,

\[
\Pr(X-np\le-n\gamma/2)
\le
\exp(-sn\gamma/2)
\bigl(pe^{-s}+1-p\bigr)^n.
\]

Using the standard convexity estimate

\[
pe^{-s}+1-p
\le
\exp\bigl(-ps+p(1-p)s^2/2\bigr)
\]

and optimizing at the elementary subgaussian scale gives the Hoeffding bound

\[
\Pr(X\le n/2)
\le e^{-n\gamma^2/2}.
\]

The majority failure event is contained in `{X<=n/2}`, yielding `(3.5)`. The case `x>=delta` is symmetric and yields `(3.6)`.

Only the exponential estimate `(3.3)` is used below; no number-theoretic input occurs.

# 4. Abstract rank-sandwich plateau theorem

## `P25-PLATEAU-RANK-SANDWICH-PRINCIPLE-28` — **PROVED**

Let `A_infty` be a unital C*-algebra with faithful finite trace `tau_infty`, and let `A_L` be stage C*-algebras with faithful finite traces `tau_L`. Let

\[
D_\infty=C_\infty^*C_\infty
\in M_v(A_\infty)
\]

be positive and suppose

\[
\sigma(D_\infty)
\subset
\{0\}\cup[\delta,M],
\qquad
0<\delta<M.
\tag{4.1}
\]

Let

\[
\beta
=
(\operatorname{Tr}_v\otimes\tau_\infty)
\bigl(\mathbf1_{\{0\}}(D_\infty)\bigr).
\tag{4.2}
\]

Assume a stage algebraic evaluation sends `D_infty` to a positive `D_L` and, for the chosen odd degree `n`, the following hold.

### H1. Defect norm transport

For

\[
A_\infty=q_n(D_\infty),
\qquad
A_L=q_n(D_L),
\]

there is a finite factor `Lambda_L>=1` such that

\[
\boxed{
\|A_L^2-A_L\|
\le
\Lambda_L
\|A_\infty^2-A_\infty\|.
}
\tag{4.3}
\]

The estimate must hold at matrix size `v`; a completely bounded theorem is a sufficient stable hypothesis.

### H2. Exact local trace transport

\[
\boxed{
(\operatorname{Tr}_v\otimes\tau_L)(A_L)
=
(\operatorname{Tr}_v\otimes\tau_\infty)(A_\infty).
}
\tag{4.4}
\]

### H3. Stage projection trace mesh

There is `h_L>0` such that every reduced-C* projection trace relevant here lies in

\[
h_L\mathbb Z,
\]

and also

\[
\beta\in h_L\mathbb Z.
\tag{4.5}
\]

It is enough that the two numbers in the locking comparison belong to one discrete subgroup of spacing at least `h_L`.

### H4. One-sided true-kernel rank bound

Writing

\[
P_L=\mathbf1_{\{0\}}(D_L)
\]

in the finite von-Neumann closure, assume

\[
\boxed{
(\operatorname{Tr}_v\otimes\tau_L)(P_L)
\ge\beta.
}
\tag{4.6}
\]

No assumption is made that `P_L` initially belongs to `A_L`.

### Quantitative locking conditions

Let `epsilon=epsilon_n` be `(3.3)`. Assume

\[
\boxed{
\Lambda_L\varepsilon<\frac14
}
\tag{4.7}
\]

and

\[
\boxed{
v(1+2\Lambda_L)\varepsilon<h_L.
}
\tag{4.8}
\]

Then:

1. the actual stage kernel projection belongs to `M_v(A_L)`;
2. its trace is exactly `beta`;
3. it equals the rounded plateau cutoff
   \[
   Q_L
   =
   \mathbf1_{[1/2,\infty)}(A_L);
   \]
4. the stage has no spectrum in `(0,delta_0]`;
5. if `beta=0`, then zero is absent from the stage spectrum as well.

Equivalently,

\[
\boxed{
\sigma(D_L)
\subset
\begin{cases}
\{0\}\cup[\delta_0,\infty),&\beta>0,\\[1mm]
[\delta_0,\infty),&\beta=0.
\end{cases}
}
\tag{4.9}
\]

### Proof

Let

\[
P_\infty=\mathbf1_{\{0\}}(D_\infty).
\]

By `(3.5)` at zero and `(3.6)` on the positive parent spectrum,

\[
\boxed{
\|A_\infty-P_\infty\|\le\varepsilon.
}
\tag{4.10}
\]

On the parent kernel, the scalar value of `q_n` lies in `[1-epsilon,1]`; on the positive spectrum it lies in `[0,epsilon]`. Hence

\[
\boxed{
\|A_\infty^2-A_\infty\|\le\varepsilon.
}
\tag{4.11}
\]

By H1,

\[
\eta_L:=\|A_L^2-A_L\|
\le\Lambda_L\varepsilon<\frac14.
\tag{4.12}
\]

Because `A_L` is self-adjoint, its spectrum avoids `1/2`, so

\[
Q_L=\mathbf1_{[1/2,\infty)}(A_L)
\in M_v(A_L)
\]

by continuous functional calculus.

For any self-adjoint `A` with `||A^2-A||<=eta<1/4`, scalar spectral calculus gives

\[
\left\|
\mathbf1_{[1/2,\infty)}(A)-A
\right\|
\le
\frac{1-\sqrt{1-4\eta}}2
\le2\eta.
\tag{4.13}
\]

Therefore

\[
\|Q_L-A_L\|
\le2\Lambda_L\varepsilon.
\tag{4.14}
\]

Using H2 and `(4.10)`,

\[
\begin{aligned}
\left|
(\operatorname{Tr}_v\otimes\tau_L)(Q_L)-\beta
\right|
&\le
v\|Q_L-A_L\|
+
\left|
(\operatorname{Tr}_v\otimes\tau_\infty)(A_\infty-P_\infty)
\right|\\
&\le
v(1+2\Lambda_L)\varepsilon\\
&<h_L.
\end{aligned}
\tag{4.15}
\]

By H3, both traces lie in one lattice of spacing `h_L`, hence

\[
\boxed{
(\operatorname{Tr}_v\otimes\tau_L)(Q_L)=\beta.
}
\tag{4.16}
\]

Since `q_n(0)>=1-epsilon>1/2` under `(4.7)`, the true kernel lies inside the rounded plateau subspace:

\[
P_L\le Q_L.
\tag{4.17}
\]

Thus

\[
(\operatorname{Tr}_v\otimes\tau_L)(P_L)
\le\beta.
\]

H4 gives the reverse inequality, so equality holds. Faithfulness of the finite trace applied to the projection `Q_L-P_L` yields

\[
\boxed{P_L=Q_L.}
\tag{4.18}
\]

In particular `P_L` belongs to the reduced C*-algebra.

Finally, `(3.5)` gives

\[
q_n(x)>1/2
\qquad(0\le x\le\delta_0).
\]

Any positive stage spectral point in this interval would contribute to `Q_L` while being orthogonal to `P_L`, contradicting `(4.18)`. If `beta=0`, then `Q_L=P_L=0`; spectral mapping and `q_n(0)>1/2` also exclude zero itself from the stage spectrum.

This proves `(4.9)`.

### What the theorem does not use

It does **not** require:

- equality of the full parent and stage `K_0` classes;
- a global homomorphism between reduced group C*-algebras;
- strong convergence in place of norm control;
- a stage gap as an input;
- coefficient Baum–Connes.

Only a numerical projection-trace lattice and a one-sided rank inequality are used to identify the actual kernel.

# 5. Polynomial local distortion is enough

## `P25-POLYNOMIAL-CB-DISTORTION-SUFFICES-28` — **PROVED**

The abstract theorem materially weakens the norm theorem needed for **fixed-matrix** spectral permanence.

Let

\[
\kappa
=
\frac{(\delta-\delta_0)^2}{8M^2},
\]

so that

\[
\varepsilon_n=e^{-\kappa n}.
\]

Suppose, along a stage family, that for all odd degrees in a logarithmic window:

\[
\boxed{
\Lambda_L(2n\rho)\le C L^A
}
\tag{5.1}
\]

for fixed `C>=1`, `A>=0`, and that the stage trace mesh satisfies

\[
\boxed{
h_L\ge c_0L^{-B}}
\tag{5.2}
\]

for fixed `c_0>0`, `B>=0`.

Assume also that exact trace transport and the one-sided kernel-rank inequality hold at those degrees.

Choose `n_L` to be the least odd integer above

\[
\boxed{
\frac1\kappa
\max\left\{
A\log L+\log(8C),
(A+B)\log L+
\log\frac{2v(1+2C)}{c_0}
\right\}.
}
\tag{5.3}
\]

Then `n_L=O(log L)` and:

\[
\Lambda_L\varepsilon_{n_L}
\le\frac18,
\tag{5.4}
\]

while

\[
v(1+2\Lambda_L)\varepsilon_{n_L}
\le\frac{h_L}{2}.
\tag{5.5}
\]

Therefore `P25-PLATEAU-RANK-SANDWICH-PRINCIPLE-28` applies and gives the fixed uniform gap `(4.9)`.

### Proof of `(5.5)`

For `L>=1`,

\[
1+2CL^A
\le
(1+2C)L^A.
\]

The second term in `(5.3)` gives

\[
e^{-\kappa n_L}
\le
\frac{c_0}{2v(1+2C)}
L^{-(A+B)}.
\]

Hence

\[
v(1+2\Lambda_L)e^{-\kappa n_L}
\le
\frac{c_0}{2}L^{-B}
\le\frac{h_L}{2}.
\]

The first term in `(5.3)` similarly gives `(5.4)`.

### Strategic consequence

For fixed gapped matrices, the future infinite-monodromy norm target does **not** need

\[
A(R,L)\to1.
\]

A polynomially growing matrix-stable local norm factor on an `O(log L)` support window is enough whenever the trace mesh is polynomially discrete.

This is much weaker than the near-isometric moving-control theorem required for arbitrary quantitative K-relations.

# 7. Positive spectral-edge convergence

## `P25-PERIODIC-MONODROMY-SPECTRAL-EDGE-28` — **PROVED**

Assume `C` is nonzero. Let

\[
g_\infty
=
\min(\sigma(D_\infty)\setminus\{0\})>0.
\]

For sufficiently large `L`, Section 6 shows that the stage zero is isolated or absent. Define

\[
g_L
=
\inf(\sigma(D_L)\setminus\{0\}).
\]

Then

\[
\boxed{g_L\longrightarrow g_\infty.}
\tag{7.1}
\]

### Lower bound

Fix any `delta_0<g_infty`. Apply Section 6 with `delta=g_infty` and any strict upper bound `M>||D_infty||`. Eventually

\[
g_L\ge\delta_0.
\]

Hence

\[
\liminf_{L\to\infty}g_L\ge g_\infty.
\tag{7.2}
\]

### Upper bound from one finite-support approximate eigenvector

For a bounded self-adjoint operator, every spectral point lies in the approximate point spectrum. This can be seen directly: if `D-g` were bounded below, self-adjointness would make its range both closed and dense, hence surjective, contradicting `g in sigma(D)`.

Thus for every `epsilon>0` there is a unit vector `xi` with

\[
\|(D_\infty-g_\infty)\xi\|<\varepsilon/2.
\]

Finite-support vectors are dense in the regular representation, so after a sufficiently small perturbation and renormalization there is a finite-support unit vector, still denoted `xi`, with

\[
\|(D_\infty-g_\infty)\xi\|<\varepsilon.
\tag{7.3}
\]

Only finitely many group elements occur in `xi` and `D_infty xi`.

Every element of `Gamma` has unique normal form

\[
f t^k,
\qquad
f\in F_2.
\]

If such an element maps to the identity in `Gamma_L`, then `k=0` and the free word `f` becomes trivial in `C_L*Z`. For any fixed finite set of nontrivial free words this cannot happen for all sufficiently large `L`; equivalently the cyclic fillings converge marked-locally to the parent on every fixed finite set.

Therefore, for large `L`, the quotient is injective on the finite support needed in `(7.3)`. Transfer the coefficients of `xi` to a stage vector `xi_L`. Then

\[
\|\xi_L\|=1
\]

and, because every multiplication occurring in the residual is recognized exactly,

\[
\boxed{
\|(D_L-g_\infty)\xi_L\|
=
\|(D_\infty-g_\infty)\xi\|
<\varepsilon.
}
\tag{7.4}
\]

For self-adjoint `D_L`,

\[
\operatorname{dist}(g_\infty,\sigma(D_L))
\le\varepsilon.
\]

Taking `epsilon<g_infty/2` ensures the nearby spectral point is positive. Hence

\[
\limsup_{L\to\infty}g_L\le g_\infty.
\tag{7.5}
\]

Combining `(7.2)` and `(7.5)` proves `(7.1)`.

### Scope of the upper-edge argument

This is **not** upper reduced-norm convergence under marked convergence. It transports one fixed finite-support approximate eigenvector at one fixed spectral point. The lower-gap theorem still depends essentially on the separate matrix-stable norm-control channel.

# 12. Categorical distinctions

Every norm, spectrum and kernel conclusion is reduced. The group quotient is used only algebraically on finite group-ring coefficients. No global map

\[

is asserted.

## Norm versus strong convergence

The decisive lower-gap step transports an idempotent defect in reduced operator norm with an explicit matrix-stable constant. Strong/marked convergence alone is insufficient.

## Finite matrices versus von-Neumann projections

`C` and all polynomial cutoffs are finite matrices over group rings. The true stage kernel starts as a von-Neumann spectral projection. The rank sandwich proves that it equals a reduced-C* projection.

No coefficient Baum–Connes theorem is used. P01 remains the scalar coefficient-free problem.

The trace-mesh input is stable `K_0`; the norm theorem is completely bounded and survives arbitrary matrix stabilization. The new plateau theorem itself only needs the finite matrix size of the fixed operator, but its hypotheses are formulated in a stabilization-compatible way.

## Class versus trace

Full `K_0` class equality is not inferred from trace equality. The trace is used only as a discrete numerical locking invariant, combined with an independent kernel-rank lower bound.

## Fixed versus moving control

The new theorem is fixed-matrix. It does not erase the cyclic and nonamenable counterexamples showing that stable K-relations can require propagation growing with the relation depth.
