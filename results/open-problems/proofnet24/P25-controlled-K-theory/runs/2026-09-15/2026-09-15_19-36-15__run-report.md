## 3.3 Haagerup permanence and Higson–Kasparov

The standard a-T-menability permanence theorem says that if

\[
1\to N\to G\to Q\to1
\]

has `N` a-T-menable and `Q` amenable, then `G` is a-T-menable. This is the Haagerup-extension theorem recorded in the Cherix–Cowling–Jolissaint–Julg–Valette framework and used explicitly in the primary literature on a-T-menability of tree groups.

Nigel Higson and Gennadi Kasparov, *E-theory and KK-theory for groups which act properly and isometrically on Hilbert space*, Invent. Math. 144 (2001), 23–74, DOI `10.1007/s002220000118`, proves Baum–Connes with coefficients for a-T-menable groups.

This run uses that theorem only for the auxiliary torsion-free finite-index subgroup `N_{m,L}`. It is **not** substituted for the universal P01 scalar target.

# 4. A general invariant congruence cover

Fix an integer `m>=2`. Put

\[
H_{m,L}
=
\langle x_1,\dots,x_m\mid x_1^L=1\rangle
\cong C_L*F(x_2,\dots,x_m),
\]

and define the triangular automorphism

\[
\alpha_m(x_1)=x_1,
\qquad
\alpha_m(x_j)=x_{j-1}x_j
\quad(2\le j\le m).
\tag{4.1}
\]

It is an automorphism: it is the composition of elementary Nielsen transformations, taken from `j=2` upward in the appropriate composition order.

Let

\[
A_{m,L}=(\mathbb Z/L)^m
\]

with standard basis `e_1,...,e_m`, and define

\[
\pi_{m,L}:H_{m,L}\to A_{m,L},
\qquad
x_j\mapsto e_j.
\tag{4.2}
\]

Define the unipotent automorphism `T` of `A_{m,L}` by

\[
T(e_1)=e_1,
\qquad
T(e_j)=e_{j-1}+e_j.
\tag{4.3}
\]

Its matrix is triangular with diagonal entries `1`, hence

\[
\det T=1\pmod L
\]

and `T` is invertible for every `L`.

Directly on generators,

\[
\boxed{
\pi_{m,L}\circ\alpha_m
=T\circ\pi_{m,L}.
}
\tag{4.4}
\]

Therefore

\[
K_{m,L}:=\ker\pi_{m,L}
\tag{4.5}
\]

is `alpha_m`-invariant and

\[
\boxed{[H_{m,L}:K_{m,L}]=L^m.}
\tag{4.6}
\]

## Torsion-freeness

Every finite-order element of the free product

\[
C_L*F_{m-1}
\]

is conjugate into a factor. The free factor is torsion-free, so every torsion element is conjugate to `x_1^k` for some `k`.

Because the target of `pi` is abelian,

\[
\pi(gx_1^kg^{-1})=k e_1.
\]

The restriction of `pi` to `C_L=<x_1>` is injective. Hence a torsion element in `K_{m,L}` must have `k=0 mod L` and is the identity.

Thus

\[
\boxed{K_{m,L}\text{ is torsion-free}.}
\tag{4.7}
\]

The group `H_{m,L}` is virtually free. A torsion-free subgroup of a virtually free group is free; equivalently one can apply the Kurosh subgroup theorem. Hence

\[
\boxed{K_{m,L}\text{ is a finite-rank free group}.}
\tag{4.8}
\]

Its rank, as a check from Euler characteristic, is

\[
1-L^{m-1}+(m-1)L^m.
\tag{4.9}
\]

Now set

\[
\Gamma_{m,L}=H_{m,L}\rtimes_{\alpha_m}\mathbb Z,
\qquad
N_{m,L}=K_{m,L}\rtimes_{\alpha_m}\mathbb Z.
\tag{4.10}
\]

Since `K_{m,L}` is invariant, `N_{m,L}` is a subgroup. It need not be normal; normality is unnecessary.

Every coset of `N_{m,L}` has a representative in `H_{m,L}` because `t in N_{m,L}`, and two such representatives define the same coset exactly when they differ by `K_{m,L}`. Therefore

\[
\boxed{[\Gamma_{m,L}:N_{m,L}]=L^m.}
\tag{4.11}
\]

This proves:

## `P25-TRIANGULAR-CONGRUENCE-COVER-31` — **PROVED**

Every triangular cyclic-filling stage admits a finite-index torsion-free free-by-cyclic subgroup of explicit index `L^m`, whether or not the stage monodromy is periodic.

# 5. Reduced-C* trace mesh without periodicity

The group `N_{m,L}` is free-by-cyclic:

\[
1\to K_{m,L}\to N_{m,L}\to\mathbb Z\to1.
\]

The free group `K_{m,L}` has the Haagerup property and the quotient `Z` is amenable. By the a-T-menability extension theorem,

\[
N_{m,L}
\]

has the Haagerup property. Higson–Kasparov therefore gives Baum–Connes with coefficients, hence in particular scalar Baum–Connes, for `N_{m,L}`.

The group `N_{m,L}` is torsion-free: an element of finite order maps trivially to `Z` and hence lies in the torsion-free free kernel.

Schick's trace theorem now gives

\[
\boxed{
\tau_*K_0(C_r^*(N_{m,L}))=\mathbb Z.
}
\tag{5.1}
\]

Let

\[
d=L^m=[\Gamma_{m,L}:N_{m,L}].
\]

The finite-index regular representation identifies the left regular representation of `Gamma_{m,L}` with a `d x d` matrix representation over `C_r^*(N_{m,L})`:

\[
\iota_{m,L}:C_r^*(\Gamma_{m,L})
\hookrightarrow
M_d(C_r^*(N_{m,L})).
\tag{5.2}
\]

This is a genuine **reduced** embedding: after choosing coset representatives it is simply the left regular representation rewritten on

\[
\ell^2(\Gamma_{m,L})
\cong
\ell^2(N_{m,L})\otimes\mathbb C^d.
\]

The canonical traces satisfy

\[
\boxed{
(\operatorname{Tr}_d\otimes\tau_{N_{m,L}})(\iota_{m,L}(x))
=d\,\tau_{\Gamma_{m,L}}(x).
}
\tag{5.3}
\]

Therefore, for every matrix projection

\[
q\in M_n(C_r^*(\Gamma_{m,L})),
\]

`iota(q)` is a projection over `C_r^*(N_{m,L})`, so (5.1) and (5.3) give

\[
\boxed{
(\operatorname{Tr}_n\otimes\tau_{\Gamma_{m,L}})(q)
\in
\frac1{L^m}\mathbb Z.
}
\tag{5.4}
\]

This proves:

## `P25-TRIANGULAR-REDUCED-TRACE-MESH-31` — **PROVED**

\[
\boxed{
\tau_*K_0(C_r^*(\Gamma_{m,L}))
\subseteq L^{-m}\mathbb Z.
}
\]

The theorem is a containment, not a claim that the trace image equals the full lattice.

### Regression check: `m=2`

For the linear Nielsen family, (5.4) gives the `L^{-2}Z` mesh already obtained in P25-P29 by the stronger periodic/direct-product argument.

### New case: `m=3`

For P18's quadratic family,

\boxed{
\tau_*K_0(C_r^*(\Gamma_L))

}
\tag{5.5}
\]

\[

\[

\tag{8.1}
\]

\[

for all sufficiently large `L`.
