# 4. Exact quotient word compression

This section proves `P25-TRIANGULAR-CYCLIC-QUOTIENT-WORD-COMPRESSION-38`.

## 4.1 Exact binomial exponent seen by the cyclic retraction

For `j>=1` and `r>=0`, define `E_j(r)` by

\[
\pi(\alpha_m^r(x_j))=x_1^{E_j(r)}.
\]

Then

\[
E_1(r)=1
\]

and, for `j>=2`,

\[
E_j(0)=0,
\qquad
E_j(r+1)=E_{j-1}(r)+E_j(r).
\]

Pascal's identity therefore gives the exact formula

\[
\boxed{
E_j(r)=\binom r{j-1}.
}
\tag{4.1}
\]

This is an equality in the cyclic quotient, not an assertion about the nonabelian word `alpha^r(x_j)` itself.

## 4.2 Recursive certificate

For `s=0`, put

\[
W_{m,0}=e,
\qquad
\ell_m(0)=0.
\]

For `m=1` and `s>=1`, put

\[
W_{1,s}=x_1^s,
\qquad
\ell_1(s)=s.
\]

Now let `m>=2` and `s>=1`. Define

\[
\lambda_m(s)
=
\min\left\{
r\ge m-1:
 r\binom r{m-1}\ge s
\right\}.
\tag{4.2}
\]

Set

\[
r=\lambda_m(s),
\qquad
A=\binom r{m-1},
\qquad
q=\left\lfloor\frac sA\right\rfloor,
\qquad
\nu=s-qA.
\tag{4.3}
\]

Then

\[
0\le\nu<A,
\qquad
q\le r.
\tag{4.4}
\]

Consider

\[
U_{m;r,q}
=t^r x_m^q t^{-r}x_m^{-q}.
\tag{4.5}
\]

The total `t` exponent is zero, so this group element lies in the base subgroup `H`. By `(4.1)`,

\[
\pi(U_{m;r,q})
=x_1^{qA}.
\tag{4.6}
\]

The subgroup generated by `x_1,...,x_{m-1},t` is the depth-`m-1` triangular subgroup. Recursively choose `W_{m-1,nu}` there. Define

\[
\boxed{
W_{m,s}
=U_{m;r,q}W_{m-1,\nu}.
}
\tag{4.7}
\]

Then

\[
\boxed{
\pi(W_{m,s})=x_1^s.
}
\tag{4.8}
\]

Moreover the displayed word gives

\[
|W_{m,s}|_\Gamma
\le
2r+2q+\ell_{m-1}(\nu).
\]

Accordingly define

\[
\boxed{
\ell_m(s)
=2\lambda_m(s)
+2\left\lfloor
\frac{s}{\binom{\lambda_m(s)}{m-1}}
\right\rfloor
+\ell_{m-1}(\nu).
}
\tag{4.9}
\]

Equations `(4.7)`–`(4.9)` are an explicit finite algorithm, not an asymptotic existence statement.

For a negative exponent use `W_{m,|s|}^{-1}`.

## 4.3 Coarse explicit root bound

Put

\[
\mathcal E_m(S)
=\max_{0\le s\le S}\ell_m(s).
\]

For `m>=2`, if

\[
\widehat r
=
\max\left\{
2(m-1),
\left\lceil
\bigl(2^{m-1}(m-1)!s\bigr)^{1/m}
\right\rceil
\right\},
\]

then each factor in the numerator of `binom(widehat r,m-1)` is at least `widehat r/2`, so

\[
\widehat r\binom{\widehat r}{m-1}\ge s.
\]

Hence

\[
\lambda_m(s)\le\widehat r.
\]

Since

\[
(2^{m-1}(m-1)!)^{1/m}<2(m-1),
\]

one gets the convenient coarse bound

\[
\lambda_m(s)
\le5m(s+1)^{1/m}.
\tag{4.10}
\]

Assume inductively

\[
\mathcal E_{m-1}(S)
\le C_{m-1}(S+1)^{1/(m-1)}.
\]

Because

\[
\nu<\binom r{m-1}\le r^{m-1},
\]

we have

\[
\ell_{m-1}(\nu)
\le2C_{m-1}r.
\]

Together with `q<=r`,

\[
\ell_m(s)
\le(4+2C_{m-1})r.
\]

Take

\[
C_1=2,
\qquad
C_m=20mC_{m-1}.
\]

Then

\[
\boxed{
C_m=2\,20^{m-1}m!
}
\]

and

\[
\boxed{
\mathcal E_m(S)\le C_m(S+1)^{1/m}.
}
\]

The constant is deliberately coarse; the exact recursion `(4.9)` is the real certificate.

## Lemma

If

\[

\tag{5.3}
\]

\[
\boxed{

\tag{5.4}

### Proof

Take a simplex with vertices `c_0,...,c_k`. Because its cyclic diameter is at most `s`, write

\[
c_i=c_0x_1^{d_i}
\]

with signed circular residues `|d_i|<=s`. Choose `W_{m,d_i}` from Section 4 and set

\[
g_i=c_0W_{m,d_i}\in H.

Every `g_i` has height zero and

\[
Ng_i=Nc_i.

For all pairs,

\[
d_\Gamma(g_i,g_j)
\le
|W_{m,d_i}|+|W_{m,d_j}|
\le
2\mathcal E_m(s)
\le D.
\]

Thus the `g_i` span a `D`-Rips simplex upstairs, so their `N`-orbits span a simplex in `Y_D`. Equivariance is immediate. ∎

This is where the nonabelian kernel residue becomes useful: quotienting by `N` allows a large cyclic displacement to be represented at root-scale ambient length without falsely claiming an equality in the parent free product.
