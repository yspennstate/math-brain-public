### P25-BERNSTEIN-FILT-02 — PROVED

\[
\boxed{

\le
L^{|\alpha|}\|a\|.

## 8. New P01 theorem: fixed controlled homotopies transfer

Assume
\[
G_j\to G
\]
and all \(G_j\) lie in one fixed \(\mathcal{UE}(k)\).

Let
\[
a(t)=\sum_{w\in W}A_w(t)\otimes w
\]
be a self-adjoint fixed-matrix-size, fixed-finite-support formal path with continuous coefficients. Suppose
\[
\operatorname{dist}
\left(
\frac12,\operatorname{spec}(a_G(t))
\right)
\ge\gamma>0
\qquad
\forall t\in[0,1].
\]

Then for all sufficiently large \(j\),
\[
\boxed{
\operatorname{dist}
\left(
\frac12,\operatorname{spec}(a_{G_j}(t))
\right)
\ge\gamma/2
\quad\forall t.
}
\]

Proof: otherwise choose \(j_\ell,t_\ell\) violating the gap and pass to \(t_\ell\to t_*\). Fixed support gives uniform operator-norm continuity in \(t\), while `P01-P16A` at the fixed time \(t_*\) gives Hausdorff spectral convergence. This contradicts the limit gap.

Therefore
\[
q_j(t)=1_{(1/2,\infty)}(a_{G_j}(t))
\]
is a norm-continuous stage projection path, so
\[
[q_j(0)]=[q_j(1)]
\]
in stage \(K_0\).

Similarly, if a fixed-support path \(b(t)\) satisfies
\[
b_G(t)^*b_G(t)\ge\gamma^2 1
\quad\forall t,
\]
then applying the same argument to \(b(t)^*b(t)\) gives eventual uniform stage invertibility and
\[
[b_{G_j}(0)]=[b_{G_j}(1)]
\]
in stage \(K_1\).

### P25-UE-CONTROLLED-HOMOTOPY-02 — PROVED
Under one fixed uniform-exactness modulus,
\[
\boxed{
\text{every one fixed finite-support \(K_0/K_1\) homotopy
with a positive margin transfers to late stages.}
}
\]

This is an eventual relation theorem, not a canonical cross-stage \(K\)-theory homomorphism. It gives no uniform conclusion if support radius, matrix size, homotopy complexity or inverse margin deteriorates.

- **The stabilized boundary trace is automatically bounded by the \(C^*\)-norm:** false in general; this is why `P25-MORITA-TRACE-CTRL` is explicit.

- **Complete strong marked convergence gives reduced quotient maps:** false.

- **Complete strong convergence transports arbitrary growing-complexity homotopies:** not proved; this run is fixed-support/fixed-matrix-size/positive-margin.

- **Norm convergence without a spectral gap transports kernel projections:** false, e.g. \(\operatorname{diag}(\varepsilon,1)\to\operatorname{diag}(0,1)\).

- **Magnetic amenability solves P01:** false. The \(\mathbb Z^d\) magnetic PV category and the nonamenable marked reduced-group category remain categorically distinct.
