# 3. Proof of `P25-MOBILITY-QUOTIENT-06`

Let

\[
A_t=q(H_t),
\qquad
A_s=q(H_s).
\]

Both are self-adjoint and satisfy

\[
\operatorname{spec}(A_t),\operatorname{spec}(A_s)

## 3.1 Quantitative sign continuity

For an invertible self-adjoint element \(A\), functional calculus gives

\[
\operatorname{sgn}(A)
=
\frac1\pi
\int_0^\infty
\left[
(A-iu)^{-1}+(A+iu)^{-1}
\right]du,
\tag{3.1}
\]

with norm-convergent improper integral in the usual functional-calculus sense.

For either sign,

\[
(A_t\pm iu)^{-1}-(A_s\pm iu)^{-1}
=
(A_t\pm iu)^{-1}(A_s-A_t)(A_s\pm iu)^{-1}.
\]

Because both spectra lie at distance at least

\[
\sqrt{\delta^2+u^2}
\]

from \(\mp iu\),

\[
\|(A_t\pm iu)^{-1}-(A_s\pm iu)^{-1}\|
\le
\frac{\|A_t-A_s\|}{\delta^2+u^2}.
\]

There are two resolvent terms, hence

\[
\begin{aligned}
\|\operatorname{sgn}(A_t)-\operatorname{sgn}(A_s)\|
&\le
\frac2\pi
\|A_t-A_s\|
\int_0^\infty
\frac{du}{\delta^2+u^2}
\\
&=
\frac{\|A_t-A_s\|}{\delta}.
\end{aligned}
\tag{3.2}
\]

Since

\[
\bar P_t=\frac{1-\operatorname{sgn}(A_t)}2,
\]

we obtain

\[
\boxed{
\|\bar P_t-\bar P_s\|
\le
\frac{\|A_t-A_s\|}{2\delta}.
}
\tag{3.3}
\]

The quotient map is contractive, so

\[
\|A_t-A_s\|
\le
\|H_t-H_s\|.
\]

This proves `(MQ1)`.

The scale \(1/(2\delta)\) is sharp already for scalars: take \(A_t=-\delta\), \(A_s=\delta\).  Then the Fermi projections differ by one and \(|A_t-A_s|=2\delta\).

## 3.2 K0 constancy

A norm-continuous projection path is an ordinary projection homotopy.  Hence

\[
\boxed{
[\bar P_t]=[\bar P_s]\in K_0(B)
}
\]

for all \(s,t\).

## 3.3 Lift classes differ only by localized K0

Suppose projections \(P_t,P_s\in M_r(A)\) satisfy

\[
q(P_t)=\bar P_t,
\qquad
q(P_s)=\bar P_s.
\]

Then

\[
q_*([P_t]-[P_s])
=
[\bar P_t]-[\bar P_s]
=0.

If \(\Phi\circ i_*=0\), then

\[
\Phi([P_t])=\Phi([P_s]).
\]

No norm continuity of the chosen lifts \(P_t\) is required.

QED.

### Audit step 1 — finite mesh and self-adjoint approximation

Norm continuity on compact \([0,1]\) gives a partition with

\[
\|P(t_{r+1})-P(t_r)\|\le\eta.
\]

The self-adjoint part of the finite group-ring matrices is dense in the self-adjoint part of the matrix reduced C*-algebra, so choose

\[
p_r=p_r^*,
\qquad
\|p_r-P(t_r)\|\le\eta.
\]

There are finitely many mesh points, so the union of all finite supports has one finite common word radius and one finite support bound.

### Audit step 2 — exact defect constant

Write

\[
p=P+e,
\qquad
e=e^*,
\qquad
\|e\|\le\eta,
\qquad
Q=1-P.
\]

Then

\[
p^2-p
=
Pe+eP-e+e^2.
\]

The linear term has the exact orthogonal block form

\[
Pe+eP-e
=
PeP-QeQ.
\]

The two summands act on orthogonal corners, so

\[
\|PeP-QeQ\|
=
\max\{\|PeP\|,\|QeQ\|\}
\le\eta.
\]

Therefore

\[
\|p^2-p\|
\le
\eta+\eta^2.
\]

At \(\eta=1/16\),

\[
\eta+\eta^2
=
\frac{16}{256}+\frac1{256}
=
\boxed{17/256}.
\]

The claimed constant is exact.

### Audit step 3 — adjacent distance

Triangle inequality gives

\[
\|p_{r+1}-p_r\|
\le
\eta+\eta+\eta
=
\boxed{3/16}.
\]

### Audit step 4 — spectral correction

For self-adjoint \(p\) with

\[
\|p^2-p\|\le t<1/4,
\]

every spectral value \(\lambda\) satisfies

\[
|\lambda(\lambda-1)|\le t.
\]

Hence the interval around \(1/2\) is excluded and

\[
\widehat P=1_{[1/2,\infty)}(p)
\]

is defined.  The nearest-root bound is

\[
\|\widehat P-p\|
\le
\kappa(t)
=
\frac{1-\sqrt{1-4t}}2.
\]

At \(t=17/256\),

\[
\kappa(t)<0.072.
\]

Thus each corrected projection is within

\[
1/16+0.072<0.135<1
\]

of the corresponding original projection \(P(t_r)\), and adjacent corrected projections satisfy

\[
\|\widehat P_{r+1}-\widehat P_r\|
\le
\frac3{16}+2\kappa(17/256)
<0.332<1.
\]

Projections at norm distance below one are unitarily equivalent and connected by a projection homotopy.  Hence the corrected mesh carries the same stable endpoint relation.

# 9. Magnetic consequences and exact scope

## 9.1 What is proved abstractly

Suppose a family of magnetic bulk algebras is organized so that, at each field parameter, there is a localized ideal \(J_B\triangleleft A_B\) and the quotient Hamiltonian has a uniform Fermi gap.  If these ideals fit into one parameter-compatible quotient field and the cut automorphism preserves the relevant ideals, then:

1. the quotient Fermi class is norm-continuous and constant in ordinary K0;
2. finite-propagation Jackson almost-projections represent it with explicit propagation \(O(MR/\delta)\);
3. the quotient PV boundary class is constant by naturality;
4. any bulk or boundary pairing which annihilates the localized ideal is robust against localized Fermi-level crossings.

## 9.2 What is not proved

A standard Anderson/mobility-gap hypothesis is usually formulated through localization estimates, Sobolev algebras, fractional moments, or decay of resolvents/projections.  It is **not automatically equivalent** to the existence of a C*-ideal quotient with a uniform spectral gap.

Therefore this run does not claim a full physical mobility-gap theorem for the P17 manuscript setting.

The next source-level problem is to identify one of the following:

- an invariant localization ideal \(J_B\) for which the quotient has a uniform gap and the Chern/PV pairings factor through the quotient; or
- a Sobolev/localization analogue of the quotient theorem in which the cyclic pairings themselves descend modulo localized crossings even though no useful C*-quotient gap exists.

The counterexample in Section 6 shows why some annihilation/quotient principle is logically necessary.

# 10. Exact categorical distinctions

## Full versus reduced

P01 works in

\[
C_r^*(\Gamma)
\]

for potentially nonamenable marked groups.  There is no automatic reduced quotient map between successive marked groups.

The new mobility theorem uses an **honest C*-quotient**

\[
A\to A/J
\]

inside one extension.  It must not be reinterpreted as a cross-stage map in P01.

For P17/P18, the acting group is \(\mathbb Z^d\), hence amenable, so the twisted full and reduced crossed products agree.  That amenability is specific to the magnetic track.

## Norm versus strong/von Neumann convergence

`P25-MOBILITY-QUOTIENT-06` is an operator-norm theorem.  The Fermi projection continuity estimate uses a **uniform quotient norm gap**.

Strong convergence, pointwise spectral convergence, or von Neumann convergence is insufficient to define the same ordinary K0 homotopy.

P01's trace obstruction likewise requires an actual reduced C*-spectral gap before the kernel projection lies in ordinary reduced K0; a von Neumann kernel projection alone is not enough.

## Finite matrices versus von Neumann projections

The controlled mesh theorems use finite matrix amplifications of reduced C*-algebras.  Matrix size may grow stably, but the elements remain ordinary C*-elements.

The new quotient Fermi projection is an ordinary projection in \(M_r(A/J)\).  No von Neumann projection is substituted.

## Scalar versus coefficient Baum–Connes

P01 targets the coefficient-free/scalar assembly map.

Nothing in this run proves coefficient Baum–Connes for a hard nonamenable group.

The magnetic cocycle-homotopy theorem uses coefficient Baum–Connes only for amenable \(\mathbb Z^d\), where it is known.

## Stable versus unstable K-theory

All K0/K1 conclusions are stable.  No claim is made that representatives are conjugate or homotopic inside one prescribed fixed matrix size.

## Ordinary versus controlled K-theory

The quotient Fermi projection defines an ordinary K0 class.

The Jackson element \(q(a_{n,t})\) is an almost projection with explicit propagation and defect, hence a controlled representative.  Forgetting control and applying the exact cutoff returns precisely \([\bar P_t]\).
