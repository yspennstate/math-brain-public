## 1.1 Operator norm localization

Hiroki Sako's operator-norm-localization framework uses the following quantitative definition for a bounded-geometry metric space \(X\): for every propagation bound \(R\) and every \(0<c<1\), there is \(S\) such that every propagation-\(R\) operator \(a\) has a unit vector \(\eta\) with
\[
\operatorname{diam}(\operatorname{supp}\eta)\le S
\]
and
\[
c\|a\|\le\|a\eta\|.
\]
The key feature is that \(S\) is independent of the operator at the fixed propagation scale.

Primary references checked:

Sako records the equivalence of property A and ONL for discrete bounded-geometry spaces. The theorem below does **not** need that equivalence; it uses only the quantitative ONL definition itself.

# 2. Finite-radius ONL norm-transfer lemma

We first isolate the exact finite-radius statement hidden inside P01-P13A.

Let \(G\) and \(H\) be marked groups on the same marked generating set. Assume their rooted labelled Cayley balls agree through radius \(L\).

Represent formal group-ring matrices by the **right-regular representation** on
\[
\ell^2(G)\otimes\mathbf C^k,
\qquad
\ell^2(H)\otimes\mathbf C^k.
\]

Let
\[
b\in M_k(\mathbf C[F_S])
\]
have propagation at most \(\rho\).

Assume \(H\) satisfies ONL at \((\rho,c)\) with localization radius \(S_H(\rho,c)\): every propagation-\(\rho\) matrix-amplified operator has a unit vector supported on a set of diameter at most \(S_H(\rho,c)\) and capturing at least a \(c\)-fraction of its norm.

### Lemma P25-ONL-UPPER-01 — PROVED

If
\[
\boxed{
L\ge \rho+S_H(\rho,c),
}
\tag{2.1}
\]
then
\[
\boxed{
\|b_H\|
\le
c^{-1}\|b_G\|.
}
\tag{2.2}
\]

### Proof

Choose an ONL witness \(\eta\) in the \(H\)-representation:
\[
\|\eta\|=1,
\qquad
\operatorname{diam}(\operatorname{supp}\eta)\le S_H(\rho,c),
\]
with
\[
c\|b_H\|\le\|b_H\eta\|.
\]

Right convolution commutes with left translations. Left translation is an isometry of the standard left-invariant word metric. Translate \(\eta\) so one support point is \(e\). Then
\[
\operatorname{supp}\eta\subset B_{S_H(\rho,c)}(e).
\]

Since \(b\) has propagation \(\rho\),
\[
\operatorname{supp}(b_H\eta)
\subset
B_{S_H(\rho,c)+\rho}(e).
\]

By (2.1), the marked balls on exactly this radius are identical. Transplant the finitely supported vector coefficient-by-coefficient from \(H\) to \(G\). The input norm and the output norm are exactly preserved:
\[
\|\eta_G\|=1,
\qquad
\|b_H\eta\|=\|b_G\eta_G\|.
\]
Therefore
\[
c\|b_H\|
\le
\|b_G\eta_G\|
\le
\|b_G\|.
\]
This proves (2.2).

### Important scope

This is **one-way upper norm transfer** from a stage to the limit under a finite faithful-radius condition and ONL. It is not a quotient homomorphism between reduced group \(C^*\)-algebras.

# 3. An explicit polynomial resolvent parametrix

Fix a real spectral parameter \(\lambda\) and write

\[
K\ge\|T_G\|.

# 7. P25-ONL-DEGEN-01 — forbidden trace forces localization-radius degeneration

Let
\[
G_i\to G
\]
be marked groups, and let \(L_i\to\infty\) denote radii on which the marked Cayley balls of \(G_i\) and \(G\) agree.

p
=
\tau_G(1_{\{0\}}(D_G)).
\]

\tag{7.1}

\[
\rho_q=(2m-1)R,
\qquad
\rho_r=2mR.
\]
Let
\[
S_i(\rho,c)
\]
denote an ONL localization radius for \(G_i\) at scale \((\rho,c)\), if one exists.

### Theorem P25-ONL-DEGEN-01 — PROVED

Under the above assumptions, the faithful-radius inequality
\[
L_i
\ge
\max\{
\rho_q+S_i(\rho_q,c),
\rho_r+S_i(\rho_r,c)
\}
\tag{7.2}
\]
cannot hold for all sufficiently large \(i\).

Equivalently, for infinitely many \(i\),
\[
\boxed{

S_i(\rho_r,c)
\}
>
L_i-2mR.
}
\tag{7.3}
\]

\[
\boxed{
\limsup_{i\to\infty}
\frac{
\max\{S_i(\rho_q,c),S_i(\rho_r,c)\}

\ge1.

\tag{7.4}

### Proof

Assume (7.2) holds eventually. P25-LOWCLUSTER-ONL-01 gives an actual low-cluster projection

Q_i\in M_k(C_r^*(G_i))

Therefore (7.2) fails infinitely often, giving (7.3). Dividing by \(L_i\to\infty\) gives (7.4).

QED.

P17/P18 involve crossed products by \(\mathbb Z^d\), hence amenability makes full and reduced twisted crossed products coincide.

P01 involves nonamenable groups and marked quotient approximations. There is no canonical reduced quotient map in general.

P25-ONL-RES-01 avoids such a map entirely. It transports one finitely supported ONL witness through an identical marked ball.

The new theorem is an operator-norm/resolvent theorem.

P01's numerical sofic rank-continuity theorem concerns von Neumann dimensions of kernels.

P25-LOWCLUSTER-ONL-01 instead constructs an actual projection in
\[
M_k(C_r^*(G_i)).

That distinction is exactly what allows scalar Baum–Connes trace-range information to be applied.

## 11.4 Scalar versus coefficient Baum–Connes

The P01 trace consequence used here is only the **coefficient-free/scalar** assembly-surjectivity trace theorem.

No coefficient Baum–Connes theorem is silently imported.

## 11.5 Stable versus unstable K-theory

The magnetic PV boundary class and the P01 low-cluster classes are stable \(K\)-classes.

Nothing here asserts that a fixed finite matrix size captures all unstable homotopy information.

**DISPROVED.**

**REJECTED.**

# 16. Bottom line

P01's newest ONL idea can be made quantitative without inventing any reduced quotient map.

For a fixed self-adjoint formal operator \(A\), if
\[
\delta
=
\operatorname{dist}(\lambda,\operatorname{spec}(A_G))>0,
\]
then the explicit degree-\((2m-1)\) polynomial
\[
q_m(t)
=
\frac{t}{K^2}
\sum_{j=0}^{m-1}
\left(1-\frac{t^2}{K^2}\right)^j
\]
has residual
\[
\left(1-\frac{t^2}{K^2}\right)^m.
\]
If the stage's ONL localization radius at the resulting finite propagation scale fits inside the common marked ball, then
\[
\boxed{
\|(A_H-\lambda)^{-1}\|
\le
\frac1{\delta(c-\varepsilon_m)}.
}
\]
With
\[
m
\ge
\frac{K^2}{\delta^2}\log\frac2c,
\]
this becomes
\[
\boxed{
\|(A_H-\lambda)^{-1}\|
\le
\frac2{c\delta}.
}
\]

For a positive limit matrix with isolated zero, this gives an explicit low/high spectral split and an actual reduced low-cluster \(K_0\) projection.
