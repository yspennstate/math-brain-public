# 6. New theorem: exact residual-rank transversality threshold

## `P04-T4-RESIDUAL-TRANSVERSALITY-THRESHOLD-56 = PROVED`

I first prove a deterministic nonempty class of smooth physical residual systems for every `r<=d-1`, then use algebraicity to conclude almost-sure regularity for the actual determinant-volume residual law.

## 6.1 The bad residual-plane set is algebraic

Fix `1<=r<=d-1`. For a plane `P in Gr(r,E)` and a basis `A_1,...,A_r`, define

```text
Phi_P(u)=(u^T A_1 u,...,u^T A_r u),
```

ignoring the harmless common scalar `c_d`.

At a common zero, the spherical gradient of the `j`-th component is `2A_j u`, because `u^T A_j u=0`. Thus `0` fails to be a regular value exactly when there exist

```text
u in RP^(d-1),
[c_1:...:c_r] in RP^(r-1)
```

such that

```text
u^T A_j u = 0  for all j,
sum_j c_j A_j u = 0.
```

These are homogeneous polynomial equations in a frame for `P`, `u`, and `c`. Their incidence variety is projective in the auxiliary variables, so projection to the Grassmannian is Zariski closed. Denote this bad variety by `B_{d,r}`.

It remains to prove `B_{d,r}` is proper.

## 6.2 Explicit full-spark diagonal smooth system

Choose distinct real numbers `t_1,...,t_d` and define barycentric weights

```text
c_i = 1 / product_{l!=i}(t_i-t_l).
```

The Lagrange interpolation identity gives

```text
sum_i c_i t_i^k = 0,    k=0,...,d-2.
```

For `r<=d-1`, define vectors

```text
v_i = c_i (1,t_i,...,t_i^(r-1)) in R^r.
```

Then

```text
sum_i v_i=0,
```

and every `r` of the `v_i` are linearly independent: every corresponding determinant is a nonzero product of the `c_i` and a Vandermonde determinant.

Define traceless diagonal matrices `A_1,...,A_r` by taking the `i`-th diagonal coordinate of `A_j` to be the `j`-th coordinate of `v_i`. They are linearly independent and span an `r`-plane `P`.

The uniform point

```text
u_0=(1,...,1)/sqrt(d)
```

is a common zero because `sum_i v_i=0`.

Now suppose `u` is any common zero and the gradients are dependent. Then for some nonzero `c in R^r`,

```text
(c dot v_i) u_i = 0
```

for every coordinate `i`. Since any `r` vectors `v_i` are independent, a hyperplane `c^perp` contains at most `r-1` of them. Hence `u` has support of size at most `r-1`.

But the common-zero equations are exactly

```text
sum_i u_i^2 v_i = 0.
```

This is a nontrivial positive linear combination of at most `r-1` vectors. Every such subset is linearly independent, a contradiction. Therefore every common zero is regular and this `P` lies outside `B_{d,r}`. Hence `B_{d,r}` is a proper algebraic subset of the Grassmannian.

## 6.3 The smooth system is realizable by genuine physical rows

Let

```text
X={u in S^(d-1): u^T A_j u=0 for j=1,...,r}.
```

I claim

```text
span{h(u):u in X}=P^perp.
```

Containment in `P^perp` is immediate. For the reverse inclusion, suppose `C in E` satisfies `u^T C u=0` for every `u in X`.

All coordinate sign flips of `u_0` lie in `X`. Evaluating the quadratic form of `C` on all sign patterns and using Walsh orthogonality forces every off-diagonal coefficient of `C` to vanish. Thus `C` is diagonal.

Write its diagonal as `c=(c_1,...,c_d)`. For `r<=d-2`, squared coordinates `w_i=u_i^2` near `w_0=(1/d,...,1/d)` fill a relative open subset of the affine slice

```text

sum_i w_i v_i=0.
```

The identity `c dot w=0` on that relative open set implies

```text
c in span{1, columns of V},
```

where `V` has rows `v_i`. Since `C` is traceless and every column of `V` sums to zero, the coefficient of `1` is zero, so `C in P`.

For the boundary case `r=d-1`, `P` already has dimension `d-1`, equal to the whole traceless diagonal subspace, so once the sign-flip argument makes `C` diagonal and traceless, again `C in P`.

Thus the annihilator of `span h(X)` inside `E` is exactly `P`, proving the claim. Choose `m-r` points of `X` whose physical rows form a basis of `P^perp`. Hence the smooth residual plane constructed above is realized by an actual full-rank physical base configuration.

```text
R=||Phi_P(U)||^2,
K=1/R,
v_r=pi^(r/2)/Gamma(r/2+1).
```

Then as `eps down 0`,

```text
mu{R<=eps}
 = integral_{||y||<=sqrt(eps)} g_P(y)dy
 = v_r g_P(0) eps^(r/2)+o(eps^(r/2)).
```

Under determinant selection,

```text
dQ_P/dmu=R/r.
```

Therefore

```text
Q_P{K>L}
 = (1/r) integral_{||y||^2<1/L} ||y||^2 g_P(y)dy
 = [v_r g_P(0)/(r+2)] L^(-(1+r/2))
   + o(L^(-(1+r/2))).
```

Likewise

```text
E_Q K^p
 = (1/r) integral ||y||^(2(1-p)) g_P(y)dy.
```

The radial exponent near zero is `r-1+2(1-p)`, so the integral is finite exactly when

```text
p < alpha_r := 1+r/2.
```

At the endpoint it diverges logarithmically, and

```text
lim_{p up alpha_r}
(alpha_r-p) E_Q K^p
 = v_r g_P(0)/2.
```

Thus, conditionally on the actual residual plane,

```text
E_Q K^p < infinity  iff p<1+r/2
```

almost surely. By Tonelli, the joint selected law has infinite `p`-th reciprocal moment for every `p>=1+r/2`. For `p<1+r/2`, conditional finiteness does not by itself prove annealed uniform integrability; that remains a separate issue.

# 8. Fixed-rank Gaussian coefficient calibration

The preceding theorem identifies the exact finite-dimensional exponent. I now show its quenched coefficient converges to the Gaussian coefficient for every fixed `r`.

## 8.1 Uniform local CLT for low-Jordan deterministic planes

Let `P=span{A_1,...,A_r}` be Frobenius-orthonormal and set

```text
C=sum_j A_j^2,
eta=tr C^2.
```

For `theta in S^(r-1)`, put `A_theta=sum_j theta_j A_j`. Vector Cauchy gives, for every `v`,

```text
||A_theta v||^2 <= sum_j ||A_j v||^2 = v^T C v,
```

so

```text
0 <= A_theta^2 <= C,
tr A_theta^4 <= eta,
||A_theta||op <= eta^(1/4).
```

For `G~N(0,I_d)`, define the Gaussian quadratic vector

```text
Q_P(G)=(G^T A_1 G/sqrt(2),...,G^T A_r G/sqrt(2)).
```

Its characteristic function at `t=rho theta` satisfies

```text
|phi_P(rho theta)|
 <= (1+2 rho^2 sqrt(eta))^(-1/(4 sqrt(eta))).
```

This follows exactly as in the audited rank-two argument: if `a_j` are the squared eigenvalues of `A_theta`, then `sum a_j=1`, `sum a_j^2<=eta`, `a_j<=sqrt(eta)`, and concavity of `log(1+2rho^2 x)` supplies the product bound.

On every fixed `t`-ball, the exact determinant characteristic function has expansion

```text
log phi_P(t) = -||t||^2/2 + O_T(eta^(1/4)).
```

Indeed, the linear trace vanishes and for every `k>=3`,

```text
|tr A_t^k| <= ||A_t||op^(k-2) ||A_t||F^2.
```

For `eta` sufficiently small depending only on fixed `r`, the radial characteristic-function envelope is dominated by one integrable function on `R^r`; for example take `sqrt(eta)<=1/[4(r+2)]` and use monotonicity in `sqrt(eta)` to dominate by

```text
(1+||t||^2/[2(r+2)])^(-(r+2)).
```

Hence dominated convergence in Fourier `L^1` gives the fixed-rank uniform local CLT

```text
sup_{eta(P)<=delta}
|g_P^G(0)-(2pi)^(-r/2)| -> 0
```

as `delta down 0`.

## 8.2 Exact spherical/Gaussian density relation at zero

Write `G=RU`, `R^2~chi_d^2`, independent of `U`, and

```text

```

Then exactly


For `d>2r`,

```text

 = [d(d+2)]^(r/2) 2^-r Gamma(d/2-r)/Gamma(d/2)
```

On a regular low-Jordan plane, P23's fixed-rank small-ball bound gives the domination needed to take the small-ball limit through the radial expectation. Therefore

```text
g_P^G(0) = theta_{d,r} g_P^S(0).
```

Since `theta_{d,r}->1` for fixed `r`, every regular sequence with `eta(P_d)->0` satisfies

```text
g_{P_d}^S(0) -> (2pi)^(-r/2).
```

## 8.3 Application to the actual residual plane

The retained deletion recurrence gives

```text
e_{r-1}=((r-2)/r)e_r+gamma_r,
gamma_r>=0,
```

hence for fixed `r`




in probability.

# 9. New no-go: growing-rank vector total variation

## `P04-T4-GROWINGRANK-VECTOR-TV-NOGO-56 = PROVED`



Size-biasing the physical sphere by `||Phi_P(U)||^2` changes only the measure on the same support `M_P`. This is a rigorous route obstruction, not a disproof of hard-edge universality.
