=\operatorname{tr}(C(P)^2)-\frac{s^2}{d},
\tag{7.1}
\]

and

\[
\delta(P)=\frac12\sum_{i,j=1}^s
\|[A_i,A_j]\|_F^2\ge0.
\tag{7.2}
\]

For any symmetric traceless `A_i,A_j`,

\[
\|L_{A_i}A_j\|_F^2
=
\frac12\left[
\operatorname{tr}(A_i^2A_j^2)
+
\operatorname{tr}(A_iA_jA_iA_j)
\right]
-rac{\delta_{ij}}d.
\tag{7.3}
\]

Let

\[
X=\sum_{i,j}\operatorname{tr}(A_i^2A_j^2)
=\operatorname{tr}(C(P)^2)
=e(P)+\frac{s^2}{d},
\]

\[
Y=\sum_{i,j}\operatorname{tr}(A_iA_jA_iA_j).
\]

The commutator identity gives

\[
\delta(P)=X-Y.
\tag{7.4}
\]

Summing (7.3) and using (7.4),

\[
\boxed{
\sum_{i,j=1}^s\|L_{A_i}A_j\|_F^2
=
e(P)+\frac{s(s-1)}d-\frac12\delta(P).
}
\tag{7.5}
\]

On the other hand,

\[
\mathcal T_s(P)
=
\sum_{i,j=1}^s
\|Q L_{A_i}A_j\|_F^2.
\]

Projection only decreases norm, so (7.5) yields the **pointwise** bound

\[
\boxed{
0\le\mathcal T_s(P)
\le
e(P)+\frac{s(s-1)}d.
}
\tag{7.6}
\]

(The sharper right side from (7.5) also contains `-delta(P)/2`; dropping it is sufficient and keeps positivity explicit.)

Now define

\[
e_s=\mathbb E e(P_s),
\qquad
A_s=\mathbb E\langle a,J_s(P_s)\rangle.
\]

P20's audited bridge (6.8) and (7.6) give

\[
e_s
\le
-\frac{s+2}{d}A_s
\le
3e_s+\frac{2s(s-1)}d.
\tag{7.7}
\]

Equivalently,

\[
\boxed{
\frac d{s+2}e_s
\le
-A_s
\le
\frac{3d}{s+2}e_s
+
\frac{2s(s-1)}{s+2}.
}
\tag{7.8}
\]

For every fixed residual rank `s`, this proves

\[
\boxed{
e_s=O(d^{-1})
\iff
-A_s=O(1).
}
\tag{7.9}
\]

At the live rank two,

\[
\boxed{
\frac d4e_2
\le
-\mathbb E\langle a,J(P_2)\rangle
\le
\frac{3d}{4}e_2+1.
}
\tag{7.10}
\]

Hence a linearly divergent negative affine--Jordan alignment and a persistent order-one Jordan defect are now equivalent at the scale level (up to the explicit additive constant). This does not contradict P20's correction: the converse was absent from the bridge **alone** and is supplied here by the independent leakage estimate (7.6).

### 7.1 Why crude Cauchy on the affine variable is still useless

# 8. New theorem: exact one-delete affine cubic recurrence

## `P04-T4-ONEDELETE-AFFINE-CUBIC-RECURRENCE-51 = PROVED`

This section rewrites the affine--Jordan alignment through a single fresh physical row at every deletion step.

## 8.1 Physical coefficient row and determinant-volume law

Use the unscaled physical traceless row

\[
q(U)=UU^T-\frac1dI\in E,
\qquad U\sim\operatorname{Unif}(S^{d-1}).
\tag{8.1}
\]

Its covariance on `E` is exactly

\[
\mathbb E[q\otimes q]=c_d^{-2}I_E,
\qquad
c_d^2=\frac{d(d+2)}2.
\tag{8.2}
\]

For `k=m-s` iid rows collected in `Y`, the determinant-volume selected law has density proportional to

\[
\det(YY^T)
\]

relative to the product spherical-row law.

## 8.2 One-row extension and exact conditional selected density

Take `k-1` selected base rows `Y_0`. Let their residual projector be `P_0` of rank

\[
r=m-(k-1)=s+1,
\]

and let

\[
a_0=Y_0^T(Y_0Y_0^T)^{-1}{\bf1}.
\]

Draw one fresh physical row `q=q(U)` from the original product law and define

\[
y=P_0q,
\qquad
w=\|y\|_F^2.
\tag{8.3}
\]

The Schur complement gives exactly

\[
\det(YY^T)=\det(Y_0Y_0^T)\,w.
\tag{8.4}
\]

Moreover, by isotropy,

\[
\mathbb E_\mu w
=
\operatorname{tr}(P_0\mathbb E[q\otimes q])
=
\frac r{c_d^2},
\tag{8.5}
\]

which is independent of the base configuration. Therefore:

1. the marginal law of the base is exactly the `(k-1)`-row determinant-volume law;
2. conditionally on the base, the new selected row has density

\[
\boxed{
\frac{d\nu_r}{d\mu}(q\mid Y_0)
=
\frac{c_d^2}{r}\,w.
}
\tag{8.6}
\]

No approximation is involved.

## 8.3 Exact update of the affine interpolant and residual projector

Put

\[
c=\langle a_0,q\rangle,
\qquad
\eta=\frac{1-c}{w},
\qquad
v=\frac y{\sqrt w}.
\tag{8.7}
\]

The minimum-norm affine interpolant satisfying all `k` row constraints is

\[
\boxed{a=a_0+\eta y.}
\tag{8.8}
\]

The new residual projector is

\[
\boxed{P=P_0-v\otimes v.}
\tag{8.9}
\]

Define the single-direction Jordan mark

\[
j(v)=v^2-\frac1dI.
\tag{8.10}
\]

Since the Jordan vector is linear in the coefficient projector,

\[
\boxed{J_s(P)=J_r(P_0)-j(v).}
\tag{8.11}
\]

## 8.4 Three exact conditional expectations

First, using (8.6),

\[
\mathbb E_{\nu_r}[a-a_0\mid Y_0]
=
\frac{c_d^2}{r}
\mathbb E_\mu[(1-c)y].
\]

Now `E y=0`, while

\[
\mathbb E[c\,y]
=P_0\mathbb E[q\otimes q]a_0
=c_d^{-2}P_0a_0=0
\]

because `a_0` lies in the row span, orthogonal to `ran P_0`. Hence

\[
\boxed{
\mathbb E_{\nu_r}[a-a_0\mid Y_0]=0.
}
\tag{8.12}
\]

Second,

\[
\mathbb E_{\nu_r}[v\otimes v\mid Y_0]
=
\frac{c_d^2}{r}
\mathbb E_\mu[y\otimes y]
=
\frac1rP_0.
\tag{8.13}
\]

Applying the linear Jordan map to (8.13),

\[
\boxed{
\mathbb E_{\nu_r}[j(v)\mid Y_0]
=
\frac1rJ_r(P_0).
}
\tag{8.14}
\]

Third, the affine increment has the exact conditional second moment

\[
\|a-a_0\|^2
=\frac{(1-c)^2}{w},
\]

so the selection weight cancels the denominator and gives

\[
\boxed{
\mathbb E_{\nu_r}[\|a-a_0\|^2\mid Y_0]
=
\frac{c_d^2+\|a_0\|^2}{r}.
}
\tag{8.15}
\]

This recovers the known affine-partition growth after averaging, and it is a useful normalization check on the one-delete law.

## 8.5 The affine cubic mark

Expand using (8.8) and (8.11):

\[
\langle a,J_s(P)\rangle
=
\langle a_0,J_r(P_0)\rangle
+
\eta\langle y,J_r(P_0)\rangle
-
\langle a_0,j(v)\rangle
-
\eta\langle y,j(v)\rangle.
\tag{8.16}
\]

By (8.12), the conditional expectation of the second term vanishes. By (8.14), the third term contributes

\[
-\frac1r\langle a_0,J_r(P_0)\rangle.
\]

The only genuinely new term is therefore

\[
\boxed{
M_r(Y_0)
:=
\mathbb E_{\nu_r}
[\eta\langle y,j(v)\rangle\mid Y_0].
}
\tag{8.17}
\]

Since `y` is traceless and `v=y/sqrt(w)`,

\[
\langle y,j(v)\rangle
=
\frac{\operatorname{tr}(y^3)}{w}.
\]

Using the selected density (8.6), this becomes the explicit **one-fresh-row** formula

\[
\boxed{
M_r(Y_0)
=
\frac{c_d^2}{r}
\mathbb E_{q\sim\mu}
\left[
(1-\langle a_0,q\rangle)
\frac{\operatorname{tr}((P_0q)^3)}
{\|P_0q\|_F^2}
\right].
}
\tag{8.18}
\]

The apparent singularity is integrable. Indeed

\[
|\operatorname{tr}(y^3)|
\le
\|y\|_{op}\|y\|_F^2
\le
\|y\|_F^3,
\]

so

\[
\frac{|\operatorname{tr}(y^3)|}{\|y\|_F^2}
\le\|y\|_F,
\]

and for a fixed base `a_0` both `q` and `\langle a_0,q\rangle` are bounded on the sphere. Define the ratio as zero on the zero set if needed.

Taking conditional expectation in (8.16) gives

\[
\boxed{
\mathbb E_{\nu_r}
[\langle a,J_{r-1}(P)\rangle\mid Y_0]
=
\frac{r-1}{r}
\langle a_0,J_r(P_0)\rangle
-
M_r(Y_0).
}
\tag{8.19}
\]

## 8.6 Averaged recurrence and telescoping

Let

\[
A_s
=
\mathbb E_{Q_{m-s}}
\langle a,J_s(P_s)\rangle.
\tag{8.20}
\]

Because the base marginal in Section 8.2 is exactly `Q_{m-r}`, averaging (8.19) gives, with `r=s+1`,

\[
\boxed{
A_s
=
\frac{s}{s+1}A_{s+1}
-
\mathbb E M_{s+1}.
}
\tag{8.21}
\]

At residual rank `m` there are no selected rows, so `a=0` and

\[
A_m=0.
\]

Divide (8.21) by `s` and telescope:

\[
\boxed{
-\frac{A_s}{s}
=
\sum_{r=s+1}^{m}
\frac{\mathbb E M_r}{r-1}.
}
\tag{8.22}
\]

P20's audited Ward bridge (6.8) now becomes

\[
\boxed{
 e_s+2\mathbb E\mathcal T_s
 =
 \frac{s(s+2)}d
 \sum_{r=s+1}^{m}

}
\tag{8.23}
\]

At rank two,

\[
\boxed{

 =
 \frac8d

}
\tag{8.24}
\]

Combining (8.22) with the fixed-rank equivalence (7.9) yields the exact criterion

\[
\boxed{
 e_2=O(d^{-1})
 \iff
 \sum_{r=3}^{m}

}
\tag{8.25}
\]

The sum is **signed**; no unjustified positivity of individual `M_r` is claimed. Its total is nonnegative because it equals `-A_2/2`, but proving `O(1)` requires either law-specific cancellation across ranks or a direct summable estimate that exploits the physical cubic numerator.

This is the new concrete angular obligation.
