# 6. New theorem: determinant-square tilt makes the affine inverse exactly isotropic

## `P04-T4-DETTILT-AFFINE-INVERSE-ISOTROPY-44` — **PROVED**

### 6.1 General statement

Let \(R_1,\dots,R_m\in\mathbb R^m\) be independent identically distributed rows with

\[
E R_i=0,
\qquad
E R_iR_i^T=I_m,
\]

and let \(A\) be the resulting \(m\times m\) matrix. Assume \(A\) is nonsingular almost surely. Define the determinant-square tilted law

\[
\frac{d\mathbb Q}{d\mathbb P}(A)
=
\frac{\det(A)^2}{E\det(A)^2}.
\tag{6.1}
\]

Then

\[
\boxed{E\det(A)^2=m!.}
\tag{6.2}
\]

For every deterministic \(c\in\mathbb R^m\), set

\[
x=A^{-1}c.
\]

Under \(\mathbb Q\),

\[
\boxed{E_{\mathbb Q}x=0,}
\tag{6.3}
\]

and

\[
\boxed{
E_{\mathbb Q}[xx^T]
=
\frac{\|c\|^2}{m}I_m.
}
\tag{6.4}
\]

In particular, for \(c=\mathbf1_m\),

\[
\boxed{
E_{\mathbb Q}\|A^{-1}\mathbf1_m\|^2=m.
}
\tag{6.5}
\]

For the physical harmonic row law (5.1), determinant-square tilt is precisely square-base Gram-volume tilt because \(\det(A^TA)=\det(A)^2\). Thus the actual harmonic affine inverse has the exact volume-biased benchmark

\[
E_{\rm vol}Q_d
=
\frac{(d-1)(d+2)}2
=\frac{d^2+d-2}{2}.
\tag{6.6}
\]

### 6.2 Determinant covariance lemma

For independent centered isotropic rows, expansion over permutations gives the general identity

\[
E\det A_{[:,J]}\det A_{[:,K]}
=k!\det(I_{J,K})
\tag{6.7}
\]

whenever \(J,K\) are ordered \(k\)-element column sets and the matrix has \(k\) independent rows. Indeed, after expanding both determinants, row independence reduces every row factor to a covariance entry. Equation (6.2) is the case \(k=m\), \(J=K=[m]\).

If \(J=[m]\setminus\{j\}\) and \(K=[m]\setminus\{k\}\), then

\[
E\det A_{-i,-j}\det A_{-i,-k}
=(m-1)!\,\delta_{jk}.
\tag{6.8}
\]

### 6.3 Cramer's-rule proof of the affine covariance

Let \(A^{(j)}(c)\) denote \(A\) with column \(j\) replaced by \(c\). Cramer's rule gives

\[
\det(A)x_j=\det A^{(j)}(c).
\tag{6.9}
\]

Expanding the replaced-column determinant,

\[
\det A^{(j)}(c)
=
\sum_{i=1}^m
(-1)^{i+j}c_i\det A_{-i,-j}.
\tag{6.10}
\]

For the tilted second moment,

\[
E_{\mathbb Q}[x_jx_k]
=
\frac1{m!}
E\bigl[\det A^{(j)}(c)\det A^{(k)}(c)\bigr].
\tag{6.11}
\]

Terms with two different deleted rows \(i\ne\ell\) vanish: conditioning on row \(i\), one minor is independent of that row while the other is linear in it, and the row is centered. For \(i=\ell\), (6.8) gives

\[
E\bigl[\det A^{(j)}(c)\det A^{(k)}(c)\bigr]
=
\|c\|^2(m-1)!\delta_{jk}.
\tag{6.12}
\]

Dividing by \(m!\) proves (6.4).

For the first moment,

\[
E_{\mathbb Q}x_j
=
\frac1{m!}E[\det A\det A^{(j)}(c)].
\]

After (6.10), condition on all rows except the deleted row. That row appears linearly only in \(\det A\), so centeredness kills the expectation. This proves (6.3).

### 6.4 Coupled cofactor identity

For \(c=\mathbf1_m\), (6.5) is equivalently the exact ordinary-law polynomial identity

\[
\boxed{
E\left[
\det(A)^2\,
\|A^{-1}\mathbf1_m\|^2
\right]
=
m!\,m.
}
\tag{6.13}
\]

This is important for route design: the determinant and inverse must remain coupled. Splitting them destroys the exact cancellation that turns a singular inverse observable into a finite polynomial moment.

# 7. New theorem: the ordinary harmonic affine inverse has a half-moment hard tail

\[

\]

\tag{7.1}
\]

For every fixed \(d\ge2\) and every \(\alpha\ge1/2\),

\[
\boxed{E Q_d^\alpha=\infty.}
\tag{7.2}
\]

More sharply, condition on the first \(m-1\) rows \(B\). On the full-row-rank event (which has probability one),

\[
\boxed{

\quad\text{for every }\alpha\ge1/2.

\tag{7.3}
\]

There is also a positive conditional one-sided tail coefficient: for almost every such \(B\),

\[
\boxed{
\liminf_{L\to\infty}

P\{Q_d>L\mid B\}>0.

\tag{7.4}
\]

The constant in (7.4) may depend on \(B\); no dimension-uniform lower bound is claimed.

### 7.2 Generic full rank

\[
0=\langle h(u),X\rangle=c_d u^TXu
\]

for every \(u\in S^{d-1}\), so \(X=0\). Hence one can select \(m\) orbit points whose rows form a basis. The determinant as a function on \((S^{d-1})^m\) is therefore a nonzero real-analytic function, and its zero set has product spherical measure zero. The same argument gives full row rank for \(m-1\) rows almost surely.

### 7.3 One-fresh-row representation

Condition on a full-row-rank

\[
B\in\mathbb R^{(m-1)\times m}.
\]

Let \(n\in\mathbb R^m\) be the unit null vector of \(B\), and let

\[
x_0
=
B^T(BB^T)^{-1}\mathbf1_{m-1}.
\tag{7.5}
\]

Then

\[
Bx_0=\mathbf1_{m-1},
\qquad
x_0\perp n.
\]

Identify \(x_0,n\) with traceless symmetric matrices \(X_0,N\in V\), with \(\|N\|_F=1\). Let the last row be \(h(U)\), \(U\sim\mathrm{Unif}(S^{d-1})\), independent of \(B\). Every solution of the first \(m-1\) affine equations is \(x_0+t n\). The final equation gives

\[
t(U)
=
\frac{
1-\langle h(U),x_0\rangle
}{
\langle h(U),n\rangle
}
=
\frac{
1-c_d U^TX_0U
}{
c_d U^TNU
}.
\tag{7.6}
\]

Therefore

\[
\boxed{
Q_d=\|x_0\|^2+t(U)^2.
}
\tag{7.7}
\]

### 7.4 A smooth pole with nonzero numerator must exist

Since \(N\ne0\) is traceless symmetric, it has both a positive and a negative eigenvalue. Thus

\[
q(u):=u^TNu
\]

has a nonempty real null cone.

Put

\[
M:=I-c_dX_0,
\qquad
p(u):=u^TMu.
\tag{7.8}
\]

On the sphere, \(p(u)=1-c_d u^TX_0u\), the numerator in (7.6).

We use the elementary quadratic-null-cone lemma:

> If \(N\) is a nonzero indefinite real symmetric matrix and a real symmetric \(M\) satisfies \(u^TMu=0\) whenever \(u^TNu=0\), then \(M=aN\) for some scalar \(a\).

A direct proof diagonalizes \(N\). Comparing the two null vectors supported on one positive and one negative eigendirection kills the corresponding off-diagonal coefficient and fixes the ratio of the two diagonal coefficients. Using one eigendirection of the opposite sign then kills same-sign off-diagonal coefficients. Kernel directions are handled by adding arbitrary multiples of a kernel vector to a smooth null vector. Thus every coefficient of \(M-aN\) vanishes.

If \(p\) vanished on every smooth point of \(q=0\), continuity would make it vanish on the entire null cone, because singular null points in \(\ker N\) are limits of smooth null points. The lemma would then give \(M=aN\). But

\[
\operatorname{tr}M
=d-c_d\operatorname{tr}X_0
=d,
\]

whereas \(\operatorname{tr}N=0\), a contradiction. Hence there exists

\[
u_0\in S^{d-1}
\]

with

\[
q(u_0)=0,
\qquad
Nu_0\ne0,
\qquad
p(u_0)\ne0.
\tag{7.9}
\]

### 7.5 Local coarea singularity

At a zero of \(q\), the spherical gradient is

\[
\nabla_S q(u)=2Nu.
\]

Thus (7.9) is a regular zero. By the submersion theorem, in a neighborhood of \(u_0\), the scalar \(r=q(u)\) is a smooth transverse coordinate and spherical measure has a smooth positive density in \(dr\,dy\). Shrink the neighborhood so that \(|p(u)|\ge c(B)>0\). Then from (7.6),

\[
|t(u)|
\ge
\frac{c(B)}{c_d|r|}.
\tag{7.10}
\]

Therefore, for \(\alpha\ge1/2\),

\[
E[Q_d^\alpha\mid B]
\ge
C(B)
\int_{-\eta}^{\eta}
|r|^{-2\alpha}\,dr
=
\infty.
\tag{7.11}
\]

This proves (7.3), hence (7.2). The same local chart gives

\[
P\{Q_d>L\mid B\}
\ge
\frac{c_1(B)}{\sqrt L}
\tag{7.12}
\]

for all sufficiently large \(L\), proving (7.4).

### 7.6 Exact consequence for the P22 facet route

P22's sufficient condition (1.2) is a probability statement. Equations (7.2)-(7.4) do **not** disprove it. They prove instead that the tempting route

\[
E Q_d=O(d^2)
\quad\Longrightarrow\quad
Q_d=o_P(d^3)
\]

is impossible for the actual ordinary harmonic law because

\[
\boxed{E Q_d=\infty.}
\tag{7.13}
\]

Any proof of (1.2) must be scale-local: a direct lower-tail theorem for the affine facet distance \(a_d=Q_d^{-1/2}\), a fractional-moment argument below the half-moment threshold if available, or a coupled determinant/cofactor estimate. It cannot be an ordinary first-moment Markov argument.
