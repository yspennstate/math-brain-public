## `P04-T4-SECTOR-REPULSION-38` — **PROVED**

Let

\[
V=\operatorname{Sym}_d^0,
\qquad
m=\frac{(d-1)(d+2)}2,
\]

and

\[
h(u)=c_d\left(uu^\top-\frac1dI\right),
\qquad

Fix a deterministic rank-`s` coefficient projection `P`, with Frobenius-orthonormal matrix basis `A_1,...,A_s`, and define

\[
f_a(u)=\langle h(u),A_a\rangle_F,
\qquad
F_P(u)=\sum_a f_a(u)^2,
\qquad
K_P(u,v)=\sum_a f_a(u)f_a(v),

\[
q_P(u)=F_P(u)/s.
\]

For any physical spherical-harmonic projector `\Pi_\ell` with reproducing kernel `K_\ell`, define the product-sector energy

\[
\boxed{
S_\ell(P)
:=\sum_{a,b=1}^s
\|\Pi_\ell(f_af_b)\|_2^2.
}
\tag{0.1}
\]

Let `U,U'` be conditionally independent draws from `q_P`, and let `Y,Z` be two distinct labeled points from the rank-`s` projection DPP with kernel `K_P`. Then

\[
\boxed{
R_\ell(P)
:=E[K_\ell(U,U')\mid P]
=\frac{\|\Pi_\ell F_P\|_2^2}{s^2},
}
\tag{0.2}
\]

whereas the determinantal pair density

\[
p_{2,P}(u,v)=
\frac{F_P(u)F_P(v)-K_P(u,v)^2}{s(s-1)}
\]

gives

\[
\boxed{
D_\ell(P)
:=E[K_\ell(Y,Z)\mid P]
=
\frac{\|\Pi_\ell F_P\|_2^2-S_\ell(P)}{s(s-1)}.
}
\tag{0.3}
\]

Therefore, for every sector and every deterministic residual plane,

\[
\boxed{
R_\ell(P)-\frac{s-1}{s}D_\ell(P)
=\frac{S_\ell(P)}{s^2}\ge0.
}
\tag{0.4}
\]

This is an exact **repulsion gap**. It identifies precisely what ordinary DPP pair data subtract from independent-replica data.

# 7. Exact polarized degree-two product formula

Let `A,B,H` be traceless symmetric matrices and write

\[
f_A(u)=\langle h(u),A\rangle=c_d\,u^\top Au.
\]

The exact spherical sixth moment gives

\[
\int
(u^\top Au)(u^\top Bu)(u^\top Hu)d\mu(u)
=
\frac{8\operatorname{tr}(ABH)}{d(d+2)(d+4)}.
\tag{7.1}
\]

For symmetric matrices, `tr(ABH)` is symmetric in `A,B,H`; equivalently

\[
\operatorname{tr}(ABH)
=\left\langle
\frac{AB+BA}{2},H
\right\rangle_F.
\]

Because the map `H -> <h(.),H>` is an isometry from `Sym_d^0` onto the physical degree-two harmonic sector, (7.1) yields

\[
\boxed{
\Pi_2(f_Af_B)(u)
=
\gamma_d
\left\langle
h(u),
\frac{AB+BA}{2}-\frac{\operatorname{tr}(AB)}dI
\right\rangle_F,
}
\tag{7.2}
\]

with

\[
\gamma_d
=\frac{4c_d}{d+4},
\qquad
\gamma_d^2=\beta_d.
\]

Hence

\[
\|\Pi_2(f_Af_B)\|_2^2
=
\beta_d
\left\|
\frac{AB+BA}{2}-\frac{\operatorname{tr}(AB)}dI
\right\|_F^2.
\tag{7.3}
\]

Summing (7.3) over an orthonormal basis of `P`, use

\[
\sum_{a,b}
\left\|
\frac{A_aA_b+A_bA_a}{2}
\right\|_F^2
=
\frac{\mathcal A(P)+R(P)}2,
\]

and

\[
\sum_{a,b}\operatorname{tr}(A_aA_b)^2=s.
\]

Thus

\[
S_2(P)
=\beta_d\left[
\frac{\mathcal A(P)+R(P)}2-\frac{s}{d}
\right].
\]

Since

\[
\mathcal A=\frac{s^2}{d}+e,
\qquad
R=\mathcal A-\delta,
\]

this is exactly (0.5).

This derivation is pointwise in `P`; it does not use coefficient-Haar geometry, projected-coordinate independence, or any asymptotic approximation.
