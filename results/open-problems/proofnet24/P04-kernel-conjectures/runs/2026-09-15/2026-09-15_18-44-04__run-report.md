## `P04-T4-HAAR-OVERLAP-SPREAD-40` — **PROVED**

Let
\[
E=\operatorname{Sym}_d^0,
\qquad

\[

\qquad U\sim\operatorname{Haar}(S^{m-1}),
\]
and its reverse volume/DPP deletion chain. Its residual rank-`s` coefficient plane is exactly Haar on `Gr(s,m)`.

Write, for a residual plane `P_s`,
\[
C_s=\sum_{a=1}^s A_a^2,
\qquad
e_s^H=E\operatorname{tr}(C_s^2)-\frac{s^2}{d},
\]
where `A_1,...,A_s` is any Frobenius-orthonormal matrix basis of the plane, and let `N_s` be the deleted Frobenius-unit traceless symmetric matrix in the transition `s -> s-1`.

Define
\[
\gamma_s^H=E\operatorname{tr}(N_s^4)-\frac1d,
\qquad
D_s^H=\frac1d-E\operatorname{tr}(N_s^2N_{s-1}^2).
\]
Then for **every** residual rank,
\[
\boxed{
\gamma_s^H=c_H
:=
\frac{(d-2)(d+4)}{d(d^2+d+2)},
}
\tag{0.1}
\]
so in particular `c_H=1/d+O(d^-2)`. Moreover
\[
\boxed{
 e_s^H
 =
 \frac{s(m-s)}{m-1}c_H,
}
\tag{0.2}
\]
and therefore for every `3<=s<=m`,
\[
\boxed{
D_s^H
=
\frac{c_H}{m-1}
=
\frac{2(d-2)(d+4)}{d(d^2+d-4)(d^2+d+2)}
=
\frac{2}{d^3}+O(d^{-5}).
}
\tag{0.3}
\]
At rank two,
\[
\boxed{
 e_2^H
 =
 2\frac{m-2}{m-1}c_H
 =
 \frac{2(d-2)^2(d+3)(d+4)}
 {d(d^2+d-4)(d^2+d+2)}
 =
 \frac2d+O(d^{-2}).
}
\tag{0.4}
\]

Thus the signed overlap debt of the *correct Haar benchmark* is spread **uniformly over all `Theta(d^2)` residual ranks**. The final linear overlap window contributes only
\[
\boxed{
\sum_{s=3}^{d+1}D_s^H
=
(d-1)\frac{c_H}{m-1}
=O(d^{-2}),
}
\tag{0.5}
\]
while the higher ranks carry
\[
\boxed{
\sum_{s=d+2}^{m}D_s^H
=
\frac{e_2^H}{2}+O(d^{-2})
=
\frac1d+O(d^{-2}).
}
\tag{0.6}
\]

By contrast, in the **positive fourth-mark representation**,
\[
\frac{e_2^H}{2}

\frac{c_H}{(s-1)(s-2)},
\]
the final linear window carries
\[
\boxed{
\sum_{s=3}^{d+1}
\frac{c_H}{(s-1)(s-2)}
=
c_H\left(1-\frac1d\right)
=
\frac1d+O(d^{-2}),
}
\tag{0.7}
\]
and the ranks above `d+1` contribute only `O(d^-2)`.

So **the same good Haar endpoint is final-linear localized in positive fourth-mark coordinates but macroscopically spread in signed overlap coordinates**. This strengthens P22's latest countermodel warning: localization is not merely representation-dependent in a bad model; it is representation-dependent already in the exact coefficient-spherical/Haar benchmark.

\]

## 7.2 Exact fourth-Schatten mark of a Haar coefficient direction

Fix a Frobenius-orthonormal basis `T_1,...,T_m` of `E=Sym_d^0` and write
\[
N=\sum_{\mu=1}^m n_\mu T_\mu,
\qquad
n\sim\operatorname{Haar}(S^{m-1}).
\]
The coefficient fourth moment is
\[
E[n_\mu n_\nu n_\rho n_\sigma]
=
\frac{
\delta_{\mu\nu}\delta_{\rho\sigma}
+\delta_{\mu\rho}\delta_{\nu\sigma}
+\delta_{\mu\sigma}\delta_{\nu\rho}
}{m(m+2)}.
\tag{7.2}
\]

For a traceless-symmetric orthonormal basis, completeness gives
\[
\sum_\mu T_\mu^2=\frac md I.
\tag{7.3}
\]
Also, for symmetric `X`,
\[
\sum_\mu T_\mu X T_\mu
=
\frac{d-2}{2d}X+rac12\operatorname{tr}(X)I.
\tag{7.4}
\]
Hence
\[
\sum_{\mu,\nu}\operatorname{tr}(T_\mu^2T_\nu^2)
=
\frac{m^2}{d},
\tag{7.5}
\]
and, because each `T_nu` is traceless,
\[
\sum_{\mu,\nu}
\operatorname{tr}(T_\mu T_\nu T_\mu T_\nu)
=
\frac{m(d-2)}{2d}.
\tag{7.6}
\]
Contracting (7.2) with `tr(T_mu T_nu T_rho T_sigma)` therefore yields
\[
\begin{aligned}
E\operatorname{tr}(N^4)
&=
\frac{1}{m(m+2)}
\left(
\frac{m^2}{d}
+
\frac{m(d-2)}{2d}
+
\frac{m^2}{d}
\right)\\
&=
\boxed{
\frac{2d^2+3d-6}{d(d^2+d+2)}
}.
\end{aligned}
\tag{7.7}
\]
Here `m=(d^2+d-2)/2` was substituted in the last line.

Thus for every rank `s`,
\[
\gamma_s^H
=
E\operatorname{tr}(N_s^4)-\frac1d
=
\boxed{
\frac{(d-2)(d+4)}{d(d^2+d+2)}
}
=:c_H.
\tag{7.8}
\]
This proves (0.1).

## 7.3 Solve the exact Jordan recurrence

For every residual deletion chain with the exact first-moment identity
\[
E[N_s^2\mid P_s]=\frac{C_s}{s},
\]
the retained Jordan recurrence is
\[
e_{s-1}=\frac{s-2}{s}e_s+\gamma_s.
\tag{7.9}
\]
At full rank, completeness (7.3) gives
\[

\qquad e_m=0.
\tag{7.10}
\]
With the constant source `gamma_s=c_H`, the unique solution of (7.9)–(7.10) is
\[
\boxed{

}
\tag{7.11}
\]
A one-line check is
\[
\frac{s-2}{s}e_s^H+c_H
=
\frac{(s-1)(m-s+1)}{m-1}c_H
=e_{s-1}^H.
\]
This proves (0.2), and `s=2` gives (0.4).

## 7.4 Consecutive-overlap profile

Put
\[
y_s^H=\frac{e_s^H}{s}
=
\frac{m-s}{m-1}c_H.
\]
The exact overlap identity is
\[

\]
Therefore
\[
\boxed{
D_s^H=\frac{c_H}{m-1}
}
\tag{7.12}
\]
for every `3<=s<=m`, proving (0.3).

The final-linear overlap sum has exactly `d-1` terms, hence
\[
\sum_{s=3}^{d+1}D_s^H
=(d-1)\frac{c_H}{m-1}=O(d^{-2}).
\]
The full sum is
\[

=(m-2)\frac{c_H}{m-1}

\frac{e_2^H}{2}
=
\frac1d+O(d^{-2}),
\]
so the complement above rank `d+1` is `1/d+O(d^-2)`. This proves (0.5)–(0.6).
