# 6. New exact innovation/product-sector theorem

## `P04-T4-INNOVATION-JORDAN-DAMPING-39` — **PROVED**

Fix a deterministic rank-`s` residual plane `P`. Let

\[
H_{ab}:=\Pi_2(f_af_b)
\]

as an element of the physical degree-two scalar harmonic Hilbert space. Then

\[
H(P):=\sum_aH_{aa}=\Pi_2F_P,
\qquad
G(P)=\|H(P)\|_2^2.
\]

Under one exact DPP deletion from `P`, sample `U` with density `q_P=F_P/s`, and define the unit coefficient direction

\[
v=\frac{P h(U)}{\sqrt{F_P(U)}}\in S^{s-1}
\]

on the full-measure set `F_P(U)>0`. Put `Q=vv^T`. The exact first-moment deletion identity is

\[
E[vv^\top\mid P]=I_s/s.
\tag{6.1}
\]

Moreover

\[
H(Q)=\sum_{a,b}v_av_bH_{ab},
\]

and P26's innovation variance is

\[
V_s(P)
=E\left[\left\|H(Q)-\frac{H(P)}s\right\|_2^2\middle|P\right].
\tag{6.2}
\]

Choose an orthonormal basis `(psi_r)` of the physical degree-two harmonic space and define symmetric coefficient matrices

\[
(B_r)_{ab}=\langle H_{ab},\psi_r\rangle.
\]

Center them by

\[
\widetilde B_r=B_r-\frac{\operatorname{tr}B_r}sI_s.
\]

Then

\[
V_s(P)
=\sum_rE(v^\top\widetilde B_rv)^2.
\]

For every symmetric matrix `B` and unit vector `v`, Cauchy gives

\[
(v^\top Bv)^2\le\|Bv\|^2=v^\top B^2v.
\]

Using (6.1),

\[
E(v^\top\widetilde B_rv)^2
\le\frac1s\|\widetilde B_r\|_F^2.
\]

Now

\[
\sum_r\|B_r\|_F^2=S_2(P),
\]

while

\[
\sum_r(\operatorname{tr}B_r)^2
=\left\|\sum_aH_{aa}\right\|_2^2
=G(P).
\]

Therefore

\[
\sum_r\|\widetilde B_r\|_F^2
=S_2(P)-G(P)/s,
\]

which proves

\[
\boxed{
V_s(P)
\le
\frac{S_2(P)}s-\frac{G(P)}{s^2}.
}
\tag{6.3}
\]

This is stronger than the crude `V_s<=S_2/s` bound and uses only the exact first-moment isotropy of the DPP deletion direction.

## 6.1 Exact cross-Jordan remainder

The preceding inequality has an exact positive remainder. Complete `v` to an orthonormal coefficient basis

\[
v,M_1,\ldots,M_{s-1}
\]

of `Ran(P)`. In this basis,

\[
\sum_r\|\widetilde B_rv\|^2
=
\left\|H_{vv}-\frac{H(P)}s\right\|_2^2
+
\sum_{j=1}^{s-1}\|H_{vM_j}\|_2^2,
\]

where `H_{vw}=Pi_2(f_vf_w)`. Averaging the left side with (6.1) gives `(S_2-G/s)/s`; averaging the first term gives `V_s(P)`. Hence

\[
\boxed{
V_s(P)
=
\frac{S_2(P)}s-\frac{G(P)}{s^2}
-
E\left[
\sum_{j=1}^{s-1}\|\Pi_2(f_vf_{M_j})\|_2^2
\middle|P
\right].
}
\tag{6.4}
\]

The missing term is not an error term: it is a canonical nonnegative **cross-Jordan damping energy**.

Now perform the next exact deletion. Conditional on `(P,v)`, the next unit deletion direction `w` lies in the surviving `(s-1)`-plane and has first moment

\[
E[ww^\top\mid P,v]=I_{v^\perp}/(s-1).
\]

Since `||Pi_2(f_vf_w)||^2` is quadratic in `w`,

\[
E\left[
\|\Pi_2(f_vf_w)\|_2^2
\middle|P,v
\right]
=
\frac1{s-1}
\sum_{j=1}^{s-1}\|\Pi_2(f_vf_{M_j})\|_2^2.
\]

Thus, along the actual residual chain, if

\[
J_s:=\|\Pi_2(f_{N_s}f_{N_{s-1}})\|_2^2,
\]

then

\[
\boxed{
EV_s
=
\frac{ES_2(P_s)}s-\frac{\beta_de_s}{s^2}
-(s-1)EJ_s.
}
\tag{6.5}
\]

Using (5.3)–(5.4), define

\[
c_d
:=
\frac1d-\frac{d}{4(m-1)}
=
\frac{(d-2)(d+4)}{2d(d^2+d-4)}.
\tag{6.6}
\]

Then (6.5) becomes the exact averaged identity

\[
\boxed{
EV_s
=
\beta_d(s-1)
\left(
\frac{e_s}{s^2}+c_d
\right)
-(s-1)EJ_s.
}
\tag{6.7}
\]

This identifies precisely what must improve beyond the universal first-moment isotropy estimate: the consecutive cross-Jordan energy must nearly saturate the envelope.

### Limitation

# 7. New consecutive-square-overlap telescope

## `P04-T4-CONSECUTIVE-SQUARE-TELESCOPE-39` — **PROVED**

Let

\[

\[

\tag{7.1}

\[

\qquad s\ge3.
\]

\[

=\frac{C(P_{s-1})}{s-1}
=\frac{C(P_s)-N_s^2}{s-1}.
\]

Therefore

\[
X_s
=
\frac1{s-1}

\operatorname{tr}(N_s^2C(P_s))
-

\right].
\tag{7.2}
\]

Using the exact conditional first moment

\[
E[N_s^2\mid P_s]=C(P_s)/s,
\]

we have

\[
E\operatorname{tr}(N_s^2C(P_s))=a_s/s.
\]

Hence
