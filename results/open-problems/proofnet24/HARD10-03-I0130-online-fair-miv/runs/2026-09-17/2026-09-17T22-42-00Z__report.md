## 3. Exact safety reduction for two agents

It suffices to build an adaptive adversary for two agents with exact MIVs

`p_1=p_2=1`.

For agent `i`, at any stopping time let

- `B_i` be the value of the bundle allocated to `i`;
- `R_i=max{v_i(g): g not in A_i}`, with `R_i=0` when no good lies outside `A_i`;
- `V_i` be the value of all goods to `i`.

Define the two-agent PROP1 safety

`s_i := 2(B_i+R_i)-V_i`.

When `V_i>0`, the achieved multiplicative PROP1 factor for agent `i` is exactly

`2(B_i+R_i)/V_i = 1+s_i/V_i`.

Present three initial goods, each valued exactly `1` by both agents.

If one agent receives all three, the other has

`B=0`, `R=1`, `V=3`, hence `s=-1` and factor `2/3`. Since

`2/3 < 445/462`,

the adversary may stop immediately on this branch.

Otherwise the split is `2--1`. Both agents have missed at least one unit-valued good, so from now on `R_i=1` forever as long as all later item values lie in `[0,1]`. The two safeties are then exactly

`(3,1)`.

After relabeling by current safety, the sorted starting state is

`(x,y)=(1,3)`.

For every later good with values `(a,b)` to the current lower-safety and higher-safety agents, respectively, where `0<=a,b<=1`, the safety update is exact:

- if the lower-safety agent receives the good: `(x,y)->(x+a,y-b)`;
- if the higher-safety agent receives the good: `(x,y)->(x-a,y+b)`.

The adversary observes the deterministic allocation and may relabel the two agents by safety before choosing the next pair `(a,b)`. This is allowed by the adaptive-adversary source model.

This two-coordinate linear game is the Bellman state used below.
