## 3. Exact two-agent safety game retained from the previous proof

It suffices for an impossibility upper bound to use two agents and announce exact MIVs `p_1=p_2=1`.

For agent `i`, let

- `B_i` be her received bundle value;
- `R_i=max{v_i(g):g notin A_i}`;
- `V_i` be her total value for all goods seen.

Define safety

`s_i := 2(B_i+R_i)-V_i`.

For `V_i>0`, the achieved two-agent multiplicative PROP1 factor is exactly

`2(B_i+R_i)/V_i = 1+s_i/V_i`.

Present three common unit goods. If one agent receives all three, the other has factor `2/3`, already below every upper endpoint proved in this run. Otherwise the split is `2--1`, both agents have missed a unit good, and every later item will have value at most one, so `R_1=R_2=1` forever. The sorted safety state is then

`(x,y)=(1,3)`, with `x<=y`.

If the adversary values the next good by `(a,b)` for the current lower- and higher-safety agents, respectively, with `0<=a,b<=1`, then the two recipient choices give exactly

`L: (x,y) -> sort(x+a,y-b)`,

`H: (x,y) -> sort(x-a,y+b)`.

Everything below concerns this exact continuous safety game.

## 4. B3 — PROVE SOMETHING STRONGER: move from a grid to the continuous sign game

The useful strengthening is not a larger finite table. Before sorting, the safety update can be written

`s -> s + sigma (a,-b)`,

where `sigma=+1` means the lower-safety agent receives the item and `sigma=-1` means the higher-safety agent receives it. The adversary chooses the vector `(a,-b)` in `[0,1] x [-1,0]`; the deterministic algorithm chooses the sign by choosing the recipient. Sorting only quotients the game by the coordinate-swap symmetry.

Thus the two-agent exact-MIV upper-bound problem contains an exact adaptive online vector-signing game with a one-sided quadrant of legal vectors and an absorbing lower-coordinate boundary. This category change is exact, not analogy: every adversarial vector is literally a legal item valuation pair, and every sign is literally a recipient choice.

### A continuous branch-independent product move

Fix a target safety boundary `-T`, and while both agents are safe define shifted margins

`X=x+T`, `Y=y+T`, so `0<X<=Y`.

Choose

`b=1`, `a=X/Y`.

This is always legal because `0<a<=1`. Before sorting, the two recipient branches satisfy the exact identity

`(X+a)(Y-1) = (X-a)(Y+1) = XY-X/Y`.

So the product `XY` decreases by exactly `X/Y`, **independently of which recipient the algorithm chooses**. This is the cleanest continuous potential discovered in this run.

However it does not by itself prove finite-time capture. If the algorithm always gives the good to the higher-safety agent, then

`Y_{t+1}=Y_t+1`,

`X_{t+1}=X_t(1-1/Y_t)`,

and therefore, as long as `Y_0>1`,

`X_t = X_0 (Y_0-1)/(Y_0+t-1) > 0`

for every finite `t`. The target boundary is approached but never crossed. This precisely identifies why a smooth branch-independent product descent is insufficient: a successful adversary needs a discrete/reflection ratchet, not just a positive potential tending to a limit.

That failure is useful: it directs B12/B19 to the gap reflection rather than another scalar retuning of the Du--Sun construction.

## 5. B12 — FIND WHAT IS CONSERVED: the gap coordinate isolates the ratchet

Write the sorted state as

`(x,x+D)`, `D>=0`.

For an action `(a,b)`, let `c=a+b`. If the higher-safety agent receives the item, sorting is unnecessary and

`H: (x,D) -> (x-a, D+c)`.

If the lower-safety agent receives it, there are two regimes:

- no reflection, `D>=c`:
  `L: (x,D) -> (x+a, D-c)`;
- reflection, `D<c`:
  `L: (x,D) -> (x+D-b, c-D)`.

The key point is that all increments are functions of `D` and `(a,b)` only; the absolute safety level `x` is merely an additive coordinate. The 1,973-node policy from the previous run was therefore obscuring a lower-dimensional structure: a gap process plus accumulated vertical displacement.

### Exact conservation away from reflection

For any **fixed** action `(a,b)` with `a+b>0`, define

`F_{a,b}(x,D) := x + [a/(a+b)] D`.

In the no-reflection regime `D>=a+b`, both recipient branches conserve it exactly:

- under `H`,
  `Delta F = -a + [a/(a+b)](a+b)=0`;
- under `L`,
  `Delta F = +a - [a/(a+b)](a+b)=0`.

Therefore a stationary fixed action cannot create strict descent while the gap stays outside its reflection window. Any finite forcing policy must obtain its net downward motion from at least one of:

1. changing the action ratio `a/(a+b)` as the gap changes; or
2. crossing the reflection surface `D=a+b`.

This gives a precise structural explanation for the state dependence of the certified Bellman policy. It also provides a target for a future symbolic proof: identify a gap-dependent action whose reflection drift makes a single piecewise-linear Lyapunov function decrease under **both** recipient choices.

## 6. B19 — MAKE IT AN ALGORITHM: a four-move reflection macro

The gap description exposes a small algebraic gadget hidden inside the finite policy. Starting from an equal safety state `(z,z)`, consider the alternating actions

`(1,1), (a,1), (1,1), (a,1)`, with `0<=a<=1`.

If at the second, third, and fourth stages the lower-safety agent receives the item, the exact states are

`(z,z)`
` -> (z-1,z+1)`
` -> (z-(1-a),z)`
` -> (z-1,z+a)`
` -> (z-(1-a),z-(1-a))`.

Thus the macro returns to the diagonal while lowering both safeties by exactly `1-a`.

If the algorithm deviates from this designated lower-recipient branch, the immediate lower safety instead drops by either `1+a` or `2-a`. Balancing those two deviation losses gives `a=1/2`, at which the diagonal-return branch drops by `1/2` while a deviation creates an immediate `3/2` downward excursion.

This is **not yet** a complete continuous adversary: an excursion need not already cross the terminal boundary, and the unequal state after a deviation must still be controlled. But it compresses an important part of the Bellman behavior to a four-step exact reflection gadget and explains why alternating full-value and intermediate-value items appears repeatedly in successful finite policies.

The B19 route therefore made real structural progress but did not by itself close the source theorem.
