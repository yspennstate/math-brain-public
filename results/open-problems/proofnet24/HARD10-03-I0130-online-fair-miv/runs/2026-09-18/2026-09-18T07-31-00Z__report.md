## 6. New theorem — weighted fixed-policy parameter stability

### Theorem 6.1

Consider any fixed finite adversarial decision tree `Pi` for the two-agent post-unit exact-MIV construction. Suppose at baseline `delta_0`:

1. every leaf produced by any deterministic allocation algorithm has some agent `i` with
   \[
   z_i^{\delta_0}\le -M;
   \]
2. every root-to-leaf post-unit path satisfies
   \[
   \sum_t\max\{a_t,b_t\}\le S.
   \]

Then for every `epsilon>=0`, running the **same physical valuation/allocation tree** at

\[
\delta_1=\delta_0+\epsilon
\]

forces, at every leaf, some agent `i` with

\[
\boxed{z_i^{\delta_1}\le -M+\epsilon(3+S).}
\]

Consequently, if

\[
\epsilon\le \frac{M}{3+S},
\]

the same finite adaptive adversary forces PROP1 factor at most

\[
1-\delta_1.
\]

### Proof

Fix one allocation-history leaf of `Pi`. The goods presented on that history are exactly the same physical valuation vectors at `delta_0` and `delta_1`; only the *target factor used to test PROP1* changes. Because both agents missed a unit good during the initial `2--1` split and every later value is at most one, `R_i=1` throughout.

For each physical agent `i`, bundle value `B_i`, total value `V_i`, and `R_i` do not depend on `delta`. Therefore

\[
\begin{aligned}
z_i^{\delta_1}-z_i^{\delta_0}
&=\left(2(B_i+1)-(1-\delta_1)V_i\right)
 -\left(2(B_i+1)-(1-\delta_0)V_i\right)\\
&=(\delta_1-\delta_0)V_i\\
&=\epsilon V_i.
\end{aligned}
\]

At that leaf, choose the baseline witness agent `i` guaranteed by assumption 1. The first three common goods contribute exactly `3` to `V_i`. On post-unit good `t`, that same physical agent values the good by either `a_t` or `b_t`, hence by at most `max{a_t,b_t}`. Thus

\[
V_i\le 3+\sum_t\max\{a_t,b_t\}\le 3+S.
\]

Therefore

\[
z_i^{\delta_1}
=z_i^{\delta_0}+\epsilon V_i
\le -M+\epsilon(3+S).
\]

This holds on every leaf, so if `epsilon<=M/(3+S)`, every deterministic online algorithm reaches a finite leaf at which some agent has `z_i^{delta_1}<=0`. By the definition of tilted safety this is exactly PROP1 factor at most `1-delta_1` for that agent. The adversary is adaptive and may stop at that leaf; the algorithm was never told the horizon. QED.

### Why this theorem is stronger than the generic `h`-Lipschitz lift

The previous theorem bounded parameter loss by `h epsilon`, treating every post-unit round as if its sensitivity were one. The fixed-tree theorem charges the actual valuation magnitude `max(a_t,b_t)` along the certified policy path. For the present policy this replaces horizon `145` by exact worst-path post-unit weight `141`.
