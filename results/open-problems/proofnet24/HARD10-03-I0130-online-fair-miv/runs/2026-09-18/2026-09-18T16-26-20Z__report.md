### Theorem 5.1 — finite-horizon unique-tight support propagation

Consider a finite max-min Bellman recursion. Let

\[
s_0\to s_1\to\cdots\to s_k
\]

be a state path such that, at every ancestor `s_j` for `0<=j<k`, there exists an action `A_j` attaining the old Bellman value `V(s_j)` and exactly one recipient branch is tight. Let the tight branch lead to `s_{j+1}`. Let the other branch exceed the old value by exact slack

\[
q_j>0.
\]

Enlarge the legal action family or improve continuation values without decreasing any old Bellman value. If the new value at `s_k` exceeds the old value by `eta_k>0`, then recursively

\[
\eta_j:=V_{\rm new}(s_j)-V_{\rm old}(s_j)
\ge \min\{\eta_{j+1},q_j\},
\]

and hence

\[
\boxed{\eta_0\ge \min\{\eta_k,q_0,q_1,\ldots,q_{k-1}\}>0.}
\]

#### Proof

Fix an ancestor `s_j`. Under the old value function, the selected action has one tight branch of value `V(s_j)` and one nonbinding branch of value `V(s_j)+q_j`. In the enlarged game, Bellman values cannot decrease. Therefore the continuation on the old tight branch is at least `V(s_j)+eta_{j+1}`, while the old nonbinding branch is at least `V(s_j)+q_j`. Evaluating the **same old action** under the enlarged game gives minimum branch value at least

\[
V(s_j)+\min\{\eta_{j+1},q_j\}.
\]

The new Bellman value is the maximum over all legal actions, so it is at least that candidate value. Thus

\[
\eta_j\ge\min\{\eta_{j+1},q_j\}.
\]

Iterating from `j=k-1` to `j=0` gives the displayed bottleneck bound. Since every quantity in the final minimum is strictly positive, root improvement is strict. QED.

This theorem is deliberately limited to the unique-tight case actually needed here. It does not claim the tied/degenerate case.
