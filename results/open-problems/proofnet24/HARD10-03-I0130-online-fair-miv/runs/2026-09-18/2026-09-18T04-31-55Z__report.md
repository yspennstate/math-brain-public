## 4. B15 — BREAK THE SYMMETRY: exact branch monotonicity and a sharper parameter theorem

The finite `Q=24` evidence from the preceding run suggested that restricting to `a<=b` might be globally harmless. I first tried to prove or falsify that continuous canonicalization directly. The useful result is more precise: for any fixed continuation function `g` that is nonincreasing and `1`-Lipschitz, the two Bellman branches have opposing coordinate monotonicities.

Write

\[
H_\delta(a,b;D,g)=\alpha a+g(D+\alpha a+\beta b).
\]

Increasing `a` by `t>=0` raises the direct term by `alpha t` and raises the argument of `g` by the same amount. Since `g` can fall by at most `alpha t`, `H_delta` is nondecreasing in `a`. Increasing `b` only raises the argument, hence `H_delta` is nonincreasing in `b`.

For the low-recipient branch define

\[
\Phi_{D,g}(C)=(C-D)_+ + g(|D-C|).
\]

Then

\[
L_\delta(a,b;D,g)=-\beta a+\Phi_{D,g}(\beta a+\alpha b).
\]

The key elementary fact is that `Phi_{D,g}` is nondecreasing and `1`-Lipschitz. Indeed:

1. for `C<=D`, `Phi(C)=g(D-C)`, so increasing `C` decreases the argument of the nonincreasing `g`, and the change is between `0` and the change in `C`;
2. for `C>=D`, `Phi(C)=C-D+g(C-D)`, whose increment over an interval of length `t` lies in `[0,t]` because the increment of `g` lies in `[-t,0]`;
3. if an interval crosses `D`, writing its two side lengths as `u,v>=0`, the difference is `v+g(v)-g(u)`, which lies in `[0,u+v]` by monotonicity and the `1`-Lipschitz property.

Consequently, increasing `a` by `t` changes `-beta a` by `-beta t` while `Phi` can rise by at most `beta t`, so `L_delta` is nonincreasing in `a`. Increasing `b` increases its `Phi` argument and therefore makes `L_delta` nondecreasing in `b`.

Thus `a` helps the high-recipient branch and hurts the low-recipient branch, while `b` does the opposite. This explains why a naive swap or coordinatewise domination argument cannot by itself prove the observed `a<=b` quotient. The global continuous half-square theorem remains **UNPROVED**.

The same branch structure, however, yields a strictly sharper theorem than the previous `2h` parameter-stability estimate.

### Theorem — one-sided parameter monotonicity and `h`-Lipschitz stability

For `0<=delta<=delta'<=1`, every finite `h`, and every `D>=0`,

\[
\boxed{
0\le G_h^\delta(D)-G_h^{\delta'}(D)
\le h(\delta'-\delta).
}
\]

Equivalently, for arbitrary `delta,delta' in [0,1]`,

\[
\boxed{
|G_h^\delta(D)-G_h^{\delta'}(D)|
\le h|\delta-\delta'|.
}
\]

**Proof.** Put `epsilon=delta'-delta>=0`, so `alpha'=alpha-epsilon` and `beta'=beta+epsilon`.

Fix `D,a,b` and a continuation function `g` that is nonincreasing and `1`-Lipschitz.

For the high branch, its argument changes by

\[
\epsilon(b-a)
\]

and its direct term changes by `-a epsilon`. If `b>=a`, monotonicity/Lipschitzness of `g` shows that the continuation change lies in `[-(b-a)epsilon,0]`, hence

\[
H_{\delta'}-H_\delta\in[-b\epsilon,-a\epsilon].
\]

If `a>b`, the continuation change lies in `[0,(a-b)epsilon]`, hence

\[
H_{\delta'}-H_\delta\in[-a\epsilon,-b\epsilon].
\]

In both cases,

\[
-\epsilon\le H_{\delta'}-H_\delta\le0.
\]

For the low branch, the threshold

\[
C_\delta=\beta a+\alpha b
\]

changes by `epsilon(a-b)`, while the direct term `-beta a` changes by `-a epsilon`. Since the function `Phi_{D,g}` proved above is nondecreasing and `1`-Lipschitz, exactly the same two cases give

\[
L_{\delta'}-L_\delta
\in[-\max\{a,b\}\epsilon,-\min\{a,b\}\epsilon]
\subseteq[-\epsilon,0].
\]

Therefore, at fixed continuation `g`, changing the parameter from `delta` to `delta'` shifts **each** branch by an amount in `[-epsilon,0]`. Taking the minimum of the two branches and then the supremum over actions preserves this one-sided bound.

Now define

\[
E_h=\sup_{D\ge0}\left(G_h^\delta(D)-G_h^{\delta'}(D)\right).
\]

At `h=0` the two value functions are identical. Inductively, compare the `delta` and `delta'` Bellman operators by first changing only the parameter while holding the continuation `G_{h-1}^{delta'}` fixed, which costs at most `epsilon`, and then changing the continuation from `G_{h-1}^{delta'}` to `G_{h-1}^{delta}`, which costs at most `E_{h-1}` because min and sup are nonexpansive in the sup norm. Hence

\[
0\le E_h\le E_{h-1}+\epsilon.
\]

Thus `E_h<=h epsilon`, proving the theorem. QED.

This replaces the preceding factor-`2h` stability estimate for future I0130 work.

## 8. B29 — COMPACTIFY: infinity is a zero-drift boundary, not an ergodic mean-payoff state

Set

\[
r=\psi(D)=\frac{D}{1+D}\in[0,1],
\]

so `r=1` represents `D=+infinity`. For a fixed action put

\[
E=\alpha a+\beta b,
\qquad
C=\beta a+\alpha b.
\]

For `r<1`, define the compactified transitions

\[
R_H(r)=\psi(D+E),
\qquad
R_L(r)=\psi(|D-C|).
\]

Because `0<=C,E<=2`, both extend continuously to

\[
R_H(1)=R_L(1)=1.
\]

The branch costs are

\[
q_H=\alpha a,
\qquad
q_L=-\beta a+(C-D)_+,
\]

and `q_L` extends continuously at infinity as `q_L(1)=-beta a`. Hence the compactified Bellman operator on continuous functions is

\[
(Tf)(r)=\sup_{a,b\in[0,1]}
\min\{q_H(r,a,b)+f(R_H(r)),\ q_L(r,a,b)+f(R_L(r))\}.
\]

It maps `C([0,1])` to itself, is monotone, additively homogeneous, and sup-norm nonexpansive. However its boundary law is exactly

\[
(Tf)(1)
=\sup_{a,b}\min\{\alpha a+f(1),-\beta a+f(1)\}
=f(1),
\]

with the supremum attained at `a=0`. Therefore every continuous additive eigenpair

\[
Tf=f+\rho
\]

must satisfy

\[
\boxed{\rho=0}
\]

by evaluation at `r=1`.

Thus compactification supplies the missing compact state space, but it simultaneously exposes an absorbing zero-drift boundary that prevents a direct positive additive-eigenvalue/ergodic Shapley theorem from proving the desired finite capture. The earlier hoped-for mean-payoff shortcut is therefore structurally blocked unless one first proves recurrence away from infinity or uses a reachability/viability formulation rather than an ergodic average-cost theorem.
