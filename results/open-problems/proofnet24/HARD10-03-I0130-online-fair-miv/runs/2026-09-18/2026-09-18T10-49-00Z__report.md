## 5. B13 — a branchwise robust monovariant

The robust Bellman inequality has a clean pathwise interpretation that avoids treating the recurrence as a black box.

Let `Phi(D)` be any continuation satisfying, for the adversary's chosen action and for both allocation branches `j in {H,L}`,

\[
\Phi(D)\le c_j-\epsilon m+\Phi(D_j).
\]

Let `x` denote the current lower baseline tilted safety and let `S` be cumulative post-unit action load,

\[
S=\sum_{t<\text{current}}m_t.
\]

Define

\[
\boxed{M=x-\Phi(D)+\epsilon S.}
\]

If branch `j` occurs, then `x'=x-c_j` and `S'=S+m`, so

\[
\begin{aligned}
M'-M
&=(x-c_j)-\Phi(D_j)+\epsilon(S+m)
  -\bigl(x-\Phi(D)+\epsilon S\bigr)\\
&=-c_j-\Phi(D_j)+\Phi(D)+\epsilon m\\
&\le0.
\end{aligned}
\]

Thus `M` is branchwise nonincreasing under every response of the deterministic algorithm.

At the initial post-unit state,

\[
x_0=\frac{13}{10},\qquad D_0=2,\qquad S_0=0.
\]

If

\[
\Phi(2)\ge\frac{13}{10}+3\epsilon,
\]

then

\[
M_0\le-3\epsilon.
\]

At a terminal/optional-stop state where the continuation is zero,

\[
x_T+\epsilon S_T\le-3\epsilon,
\]

hence

\[
x_T\le-\epsilon(3+S_T).
\]

Now change the physical target from `delta_0` to

\[
\delta_1=\delta_0+\epsilon.
\]

For the same physical witness agent and same realized valuation/allocation history,

\[
z_i^{\delta_1}=z_i^{\delta_0}+\epsilon V_i.
\]

Because each of the three initial goods has value one and every later good gives that physical agent value at most the path load contribution `max(a_t,b_t)`,

\[
V_i\le3+S_T.
\]

Consequently

\[
z_i^{\delta_1}
\le -\epsilon(3+S_T)+\epsilon V_i
\le0.
\]

Nonpositive target tilted safety is exactly the desired failure of an `alpha=1-delta_1` PROP1 guarantee for that agent.

For a finite-horizon Bellman tree, take `Phi` to be the time-dependent continuation `R_{h-t}`. For a fixed point, it is static. In either case this monovariant is the page-level proof behind the robust-transport construction.

B13 outcome: **complete structural theorem**. It does not itself choose an optimal action set, but it turns any certified robust Bellman inequality into an explicit branchwise proof.
