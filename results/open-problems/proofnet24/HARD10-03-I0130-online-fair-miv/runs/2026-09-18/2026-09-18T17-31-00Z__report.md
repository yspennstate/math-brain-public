## 5. B6 DEFORM — exact tied-face propagation, with deformation as a corollary

The previous B4 theorem handled a selected path on which every old optimal action had exactly one tight recipient branch. The unresolved case is a tied or degenerate Bellman face. A generic perturbation is useful intuition but is not needed for the finite theorem: the exact max-min algebra already gives the correct cone-valued propagation rule.

### Theorem 5.1 — finite tied-face influence recursion

Let an old finite-horizon Bellman state `s` have value

\[
V(s)=\max_{A\in\mathcal A(s)}\min_{j\in J(A)} Q_{A,j},
\]

where

\[
Q_{A,j}=r_{A,j}+V(c_{A,j}).
\]

Let `Opt(s)` be the old optimal actions. For `A in Opt(s)` define exact branch slack

\[
q_{A,j}:=Q_{A,j}-V(s)\ge 0.
\]

Now enlarge the legal action set and/or increase descendant values, without decreasing any old reward or continuation value. Write

\[
\eta(t):=V_{\rm new}(t)-V(t)\ge0.
\]

Then

\[
\boxed{
\eta(s)\ge
\max_{A\in\operatorname{Opt}(s)}
\min_{j\in J(A)}\bigl(q_{A,j}+\eta(c_{A,j})\bigr).
}
\]

#### Proof

Fix an old optimal action `A`. Under the old value function its branch `j` has value

\[
Q_{A,j}=V(s)+q_{A,j}.
\]

Under the enlarged game, evaluating the **same old action** gives branch value at least

\[
V(s)+q_{A,j}+\eta(c_{A,j}),
\]

because old rewards are unchanged and child Bellman values cannot decrease. Its new min-branch value is therefore at least

\[
V(s)+\min_j\bigl(q_{A,j}+\eta(c_{A,j})\bigr).
\]

The new Bellman value maximizes over all legal actions, so it is at least this value for every old optimal `A`. Maximizing the lower bound over `Opt(s)` and subtracting `V(s)` gives the displayed formula. QED.

This theorem contains the previous unique-tight result. If action `A` has one tight branch `j_*` with `q_{A,j_*}=0` and every other branch has slack at least `q>0`, a child improvement `eta` on `j_*` yields parent gain at least `min(eta,q)`.

### Corollary 5.2 — tangent/cone map at a tied face

Suppose the finite Bellman problem is perturbed by a scalar `tau>=0` and all branch values are piecewise affine in `tau`. Let `d(t)` denote the right directional derivative of the continuation value at `tau=0`. Then the one-sided derivative of the Bellman value is

\[
\boxed{
 d(s)=
 \max_{A\in\operatorname{Opt}(s)}
 \min_{j:q_{A,j}=0}d(c_{A,j}),
}
\]

with the corresponding immediate derivative included if the reward itself is perturbed.

To see this, divide the exact branch expression by `tau`. Any nonoptimal action has a fixed old deficit and cannot become maximizing for sufficiently small positive `tau`. Within an old optimal action, any branch with fixed slack `q_{A,j}>0` contributes `q_{A,j}/tau -> +infinity` relative to the tight branches, so only branches with `q_{A,j}=0` can determine the first-order minimum. The outer maximum then selects the best old optimal face. Thus generic tie-breaking deformation converges to the cone-valued rule rather than authorizing an arbitrary tied branch.

This resolves the finite tied-face propagation obligation. It does **not** by itself produce a simultaneous continuous-action dual occupation certificate.

## 6. B18 SAY IT IN ANOTHER LANGUAGE — a tropical influence network

Theorem 5.1 rewrites the root-sensitivity problem as a finite tropical/max-min network.

- A Bellman state is an OR node: it may select any old optimal action.
- An old optimal action is an AND/min hyperedge: every recipient branch can cap the propagated improvement.
- The exact branch slack `q_{A,j}` is an additive capacity on branch `j`.
- A local admitted-action residual is a terminal supply of improvement.

Define the propagation operator

\[
(\mathcal T\eta)(s)
:=\max_{A\in\operatorname{Opt}(s)}
  \min_j\bigl(q_{A,j}+\eta(c_{A,j})\bigr).
\]

At the unperturbed game, every optimal action has at least one zero-slack branch, so `T0=0`. A local improvement enters at one support state and is propagated toward the root by repeated application of this monotone max-min operator. On a unique-tight path, `T` reduces exactly to the previously found bottleneck law: the transported amount is the minimum of the local residual and all nonbinding slacks encountered before the root.

This language explains the old positive-residual/nonmoving counterexample: a large residual at a state outside every effective root-support hyperpath can have zero root influence. The correct separation objective is therefore not raw local residual but a root-weighted/tropical influence quantity.

The present theorem is a finite primal sensitivity certificate. A compact rational LP dual/occupation measure for the **full continuous** action problem is still missing and is not claimed here.
