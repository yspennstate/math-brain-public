## 5. B3 — exact theorem for one globally reusable physical action

The previous run showed a decisive mismatch between a localized perturbation and adding one physical action globally: a single action can improve many Bellman states simultaneously, and those gains can interact before reaching the root. A scalar local residual is therefore not the right object. The correct object is the entire residual vector of one reusable action together with an exact nonlinear propagation functional.

### Theorem 5.1 — exact reusable-action gain recursion

Fix a finite horizon and an old legal action family `A`. Let

\[
V_h(s)
\]

be its optional-stop Bellman value at state `s`. Add one new physical action `z`, available at every state, and let

\[
V'_h(s)
\]

be the enlarged Bellman value. Define the exact gain

\[
\eta_h(s):=V'_h(s)-V_h(s)\ge0.
\]

For any old or new action `a` at state `s`, write its old-continuation branch values as

\[
Q^0_{a,j}(s)
\]

and define branch slack relative to the old Bellman value by

\[
q_{a,j}(s):=Q^0_{a,j}(s)-V_h(s).
\]

Then, with `eta_0=0`,

\[
\boxed{
\eta_h(s)=
\max\left\{
0,
\max_{a\in A\cup\{z\}}
\min_j\bigl(q_{a,j}(s)+\eta_{h-1}(c_{a,j}(s))\bigr)
\right\}.
}
\]

In particular, this is an **exact identity**, not a first-order derivative and not a lower bound.

### Proof

By definition of the enlarged Bellman operator,

\[
V'_h(s)=
\max\left\{
0,
\max_{a\in A\cup\{z\}}
\min_j\left(r_{a,j}(s)+V'_{h-1}(c_{a,j}(s))\right)
\right\},
\]

where `r_{a,j}` is the immediate branch contribution. Substitute

\[
V'_{h-1}=V_{h-1}+\eta_{h-1}.
\]

For each branch,

\[
r_{a,j}(s)+V'_{h-1}(c_{a,j})
=Q^0_{a,j}(s)+\eta_{h-1}(c_{a,j}).
\]

Subtract the state-constant `V_h(s)` from the entire outer maximum. Since

\[
Q^0_{a,j}(s)-V_h(s)=q_{a,j}(s),
\]

we obtain

\[
V'_h(s)-V_h(s)
=
\max\left\{
-V_h(s),
\max_a\min_j(q_{a,j}(s)+\eta_{h-1}(c_{a,j}))
\right\}.
\]

Because the enlarged action family contains the old one, `V'_h(s)>=V_h(s)`, so the left side is nonnegative. Equivalently one may include an explicit zero option, giving the boxed formula. The base case is `eta_0=0`. Induction on `h` proves the identity for every state. QED.
