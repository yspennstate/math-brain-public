## 3. Exact two-agent safety reduction

For an impossibility upper bound it suffices to use two agents and announce exact MIVs

`p_1=p_2=1`.

For agent `i`, write

- `B_i` for her received bundle value;
- `R_i=max{v_i(g): g notin A_i}`;
- `V_i` for her total value for all goods seen;
- `s_i=2(B_i+R_i)-V_i` for her safety.

For `V_i>0`, the achieved two-agent PROP1 factor is exactly

`2(B_i+R_i)/V_i = 1+s_i/V_i`.

Present three common unit-valued goods. If one agent receives all three, the other already has factor `2/3`. Otherwise the split is `2--1`, both agents have missed a unit good, and every later value will be in `[0,1]`; hence `R_1=R_2=1` forever. The sorted safety state is then

`(x,y)=(1,3)`, `x<=y`.

Let

`D=y-x>=0`

be the safety gap. If a later item has value `a` for the current lower-safety agent and `b` for the current higher-safety agent, then with `c=a+b` the two allocation branches are:

- higher-safety recipient:
  `x' = x-a`, `D'=D+c`;
- lower-safety recipient with no reflection, `D>=c`:
  `x'=x+a`, `D'=D-c`;
- lower-safety recipient with reflection, `D<c`:
  `x'=x+D-b`, `D'=c-D`.

The absolute level `x` enters additively. All control geometry is therefore carried by the single coordinate `D`.

## 4. B1 — CHANGE THE CATEGORY: exact one-dimensional gap Bellman game

Instead of treating the certified policy as a generic two-dimensional state table, define for a finite action set `A` and integer horizon `h`:

`G_h(D) :=` the largest decrease of the current lower safety that the adaptive adversary can guarantee within at most `h` further goods, starting with gap `D`, against either recipient choice.

For the exact `1/Q` grid

`A_Q={(a,b): a,b in {0,1/Q,...,1}}`,

the recurrence is

`G_0(D)=0`,

and for `h>=1`,

`G_h(D)=max_(a,b) min{ a+G_(h-1)(D+a+b), L(D;a,b)+G_(h-1)(|D-a-b|) }`,

where

`L(D;a,b) = -a` when `D>=a+b`,

and

`L(D;a,b) = b-D` when `D<a+b`.

The first term is the high-recipient branch: lower safety drops by `a`. The second is the low-recipient branch: outside reflection the lower safety rises by `a` and so its *decrease* is `-a`; inside reflection, the old higher-safety agent becomes the new lower one and the decrease is `b-D`.

A zero-valued good `(0,0)` is legal in the nonnegative valuation model. Consequently the adversary may pad a shorter strategy, and `G_h(D)` is nondecreasing in `h`.

This is an exact category change: the post-unit source game is a one-dimensional deterministic zero-sum gap game plus an additive safety coordinate. No source quantifier or valuation assumption is changed.

## 5. B13 — FIND WHAT ONLY DECREASES: a branchwise Bellman monovariant

The gap recurrence yields an exact time-dependent potential rather than a heuristic invariant. For each remaining horizon `h`, define

`Phi_h(x,D)=x-G_h(D)`.

Suppose `(a,b)` attains the Bellman maximum at `(h,D)`. Let a recipient branch have child gap `D'` and lower-safety decrease `q`, so that the child lower safety is `x-q`. By the Bellman recurrence,

`G_h(D) <= q+G_(h-1)(D')`.

Therefore

`Phi_(h-1)(x-q,D')
 = x-q-G_(h-1)(D')
 <= x-G_h(D)
 = Phi_h(x,D)`.

Thus along **either recipient choice**, the Bellman potential never increases. This is a rigorous branchwise monovariant for the exact discretized adversarial game.

It explains why the previous search for a single stationary linear potential was too restrictive. The correct certificate is naturally horizon-dependent and piecewise linear/discrete in the gap.

## 6. B30 — ONE GAP REGIME AT A TIME: exact reflection/no-reflection glue

The only place where the recurrence changes form is the reflection surface

`D=a+b`.

Outside reflection, the low-recipient branch contributes

`-a + G_(h-1)(D-a-b)`;

inside reflection it contributes

`b-D + G_(h-1)(a+b-D)`.

The high-recipient branch is the same on both sides:

`a+G_(h-1)(D+a+b)`.

So the continuous obstruction is localized sharply: the adversary gains genuine downward leverage only through the reflection term and through switching action ratios as the gap evolves. This recovers the previous fixed-action conservation law as the no-reflection degenerate case and gives an exact gluing equation for a future continuous theorem.
