## 3. Preserved exact safety-gap reduction

For an upper bound it suffices to construct a two-agent adaptive adversary with exact announced MIVs

\[
p_1=p_2=1.
\]

For agent `i`, let

- `B_i` be the value of her allocated bundle;
- `R_i=max{v_i(g):g notin A_i}` be the best unreceived good;
- `V_i` be her total value for all goods seen;
- `s_i=2(B_i+R_i)-V_i` be the ordinary two-agent safety.

Whenever `V_i>0`, her PROP1 factor is exactly

\[
\frac{2(B_i+R_i)}{V_i}=1+\frac{s_i}{V_i}.
\]

Present three common unit-valued goods. If one agent receives all three, the other has `B=0,R=1,V=3`, hence factor `2/3`; that already lies below all upper targets considered here. Otherwise the split is `2--1`. Both agents have missed a unit good, so if every later item value lies in `[0,1]`, then `R_1=R_2=1` forever. The sorted ordinary-safety state is

\[
(x,y)=(1,3),\qquad D=y-x=2.
\]

For a later item valued `a` by the current lower-safety agent and `b` by the current higher-safety agent, put `c=a+b`. If the high-safety agent receives the item, the lower safety decreases by `a` and the gap becomes `D+c`. If the lower-safety agent receives the item and `D>=c`, the lower safety rises by `a` and the gap becomes `D-c`. If `D<c`, the order reflects: the old higher-safety agent becomes the lower one, its safety decrease is `b-D`, and the new gap is `c-D`.

Thus the source game after the three unit goods is exactly a one-dimensional gap-control game plus an additive lower-safety coordinate.

## 4. B6 — DEFORM TO A SOLVED MESH: quantitative mesh stability

The previous run had an exact grid Bellman value but no quantitative theorem comparing the grid operator to the continuous operator. This run supplies that missing bridge.

### 4.1 Continuous target-independent Bellman operator

Let `G_h(D)` be the largest decrease of the current lower ordinary safety that an adaptive adversary can guarantee within at most `h` additional goods, starting from gap `D`, when it may choose arbitrary actions `(a,b) in [0,1]^2`.

Set `G_0(D)=0`. For `h>=1`,

\[
G_h(D)=\sup_{0\le a,b\le1}\min\{H_f(D;a,b),L_f(D;a,b)\},
\]

where `f=G_{h-1}`, `c=a+b`, and

\[
H_f(D;a,b)=a+f(D+c),
\]

\[
L_f(D;a,b)=-a+(c-D)_+ + f(|D-c|).
\]

The second expression is exactly the two low-recipient cases in one formula: for `D>=c` it is `-a+f(D-c)`; for `D<c` it is `b-D+f(c-D)`.

### 4.2 Shape lemma

**Lemma.** For every finite horizon `h`, `G_h` is nonincreasing and 1-Lipschitz on `[0,infinity)`.

**Proof.** The assertion is immediate for `G_0=0`. Suppose `f=G_{h-1}` is nonincreasing and 1-Lipschitz.

The high branch `a+f(D+c)` is visibly nonincreasing and 1-Lipschitz in `D`.

For the low branch define

\[
J_f(t)=t_+ + f(|t|).
\]

For `t<0`, `J_f(t)=f(-t)`; because `f` is nonincreasing 1-Lipschitz, this is nondecreasing and 1-Lipschitz in `t`. For `t>0`, `J_f(t)=t+f(t)`. If `t_2>t_1>=0`, then

\[
-(t_2-t_1)\le f(t_2)-f(t_1)\le0,
\]

so

\[
0\le J_f(t_2)-J_f(t_1)\le t_2-t_1.
\]

Thus `J_f` is nondecreasing and 1-Lipschitz on both half-lines, and the two formulas agree at zero. Therefore

\[
L_f(D;a,b)=-a+J_f(c-D)
\]

is nonincreasing and 1-Lipschitz in `D`. The pointwise minimum of two nonincreasing 1-Lipschitz functions has the same properties, and so does the supremum over `(a,b)`. Induction closes. QED.

The same proof works for the target-aware tilted Bellman game introduced below: the dependence on `D` has the same `t_+ + f(|t|)` form.

### 4.3 Action-mesh error theorem

Let `G_{h,Q}` denote the same Bellman game but with actions restricted to

\[
A_Q=\{0,1/Q,\ldots,1\}^2.
\]

For a lattice state `D in Q^{-1} Z_{>=0}`, action restriction immediately gives

\[
G_{h,Q}(D)\le G_h(D).
\]

Conversely, round a continuous action `(a,b)` coordinatewise to a nearest grid action `(\bar a,\bar b)`, so

\[
|a-\bar a|,|b-\bar b|\le\varepsilon:=\frac1{2Q}.
\]

For the high branch, the immediate decrease changes by at most `epsilon`, the child gap changes by at most `2 epsilon`, and the continuation value is 1-Lipschitz. Hence the branch value changes by at most `3 epsilon`.

For the low branch use the unified expression

\[
-a+J_f(a+b-D).
\]

The `-a` term changes by at most `epsilon`, the argument `a+b-D` changes by at most `2 epsilon`, and `J_f` is 1-Lipschitz. Again the total branch error is at most `3 epsilon`.

Let

\[
e_h:=\sup_{D\in Q^{-1}\mathbb Z_{\ge0}}\bigl(G_h(D)-G_{h,Q}(D)\bigr).
\]

Rounding a continuous maximizing action and then using the induction error for its child states gives

\[
e_h\le e_{h-1}+\frac{3}{2Q},\qquad e_0=0.
\]

Therefore

\[
\boxed{0\le G_h(D)-G_{h,Q}(D)\le \frac{3h}{2Q}}
\]

for every lattice state `D`. An arbitrary continuous state incurs at most one additional state-rounding error `1/(2Q)` by the 1-Lipschitz lemma.

For the tilted `delta`-game below, the same argument yields the slightly more general per-step action-rounding loss

\[
\frac{3+\delta}{2Q},
\]

because the low branch's direct coefficient is `1+delta` while the two action coordinates still contribute total gap error `2 epsilon`. Hence

\[
\boxed{0\le G_h^{\delta}(D)-G_{h,Q}^{\delta}(D)
\le \frac{(3+\delta)h}{2Q}}
\]

on lattice states.

This is a genuine deformation theorem: finite action meshes converge uniformly to every fixed-horizon continuous value function at an explicit `O(h/Q)` rate. It is not used to claim that any particular grid policy is continuous-optimal; a grid policy is already a legal continuous-source adversary because grid actions are a subset of `[0,1]^2`.

## 5. B18 — SAY IT IN ANOTHER LANGUAGE: clipped-midpoint / tropical Bellman form

The ordinary-safety Bellman operator admits a cleaner exact form after a half-gap transform. Define

\[
K_h(D)=G_h(D)+\frac D2.
\]

Parameterize an action by

\[
c=a+b,\qquad d=b-a.
\]

Then `0<=c<=2` and

\[
|d|\le m(c):=\min\{c,2-c\}.
\]

Write

\[
A=K_{h-1}(D+c),\qquad B=K_{h-1}(|D-c|).
\]

A direct substitution gives the two branch values before restoring the common `-D/2` term:

\[
A-\frac d2,\qquad B+\frac d2.
\]

Indeed, for the high-recipient branch

\[
a+G_{h-1}(D+c)
=A-\frac D2-\frac d2,
\]

and both reflected and nonreflected low-recipient cases give

\[
L=B-\frac D2+\frac d2.
\]

Therefore

\[
K_h(D)=\max_{0\le c\le2}\max_{|d|\le m(c)}
\min\left\{A-\frac d2,B+\frac d2\right\}.
\]

The inner optimization is explicit. Without the box constraint it equalizes the branches at `d=A-B`. With clipping,

\[
\boxed{
K_h(D)=\max_{0\le c\le2}
\frac{A+B-\bigl(|A-B|-m(c)\bigr)_+}{2}.
}
\]

This is a max of a clipped midpoint of two translated/reflected copies of the previous value function: a one-dimensional min-plus/tropical form rather than the original two-action Bellman expression.

The shape lemma also says `K_h` is `1/2`-Lipschitz, because for `D_2>D_1`, the increment of `G_h` lies in `[-(D_2-D_1),0]`. Consequently the clipping term is **automatically inactive for every `c<=1`**. To see this, the two arguments of `K` differ by

\[
|(D+c)-|D-c||\le 2c,
\]

so

\[
|A-B|\le c=m(c).
\]

Thus on the entire half of action-scale space `0<=c<=1`,

\[
\boxed{K_h(D)=\max_{0\le c\le1}\frac{K_{h-1}(D+c)+K_{h-1}(|D-c|)}2}
\]

unless an action with `c>1` gives a larger value. The only genuinely clipped regime is therefore `c>1`.

This formulation also proves a finite-horizon piecewise-linear structure theorem. Starting from `K_0(D)=D/2`, suppose `K_{h-1}` is continuous rational piecewise-affine. Partition the `(D,c)` plane by the finitely many preimages of its breakpoints under `D+c` and `|D-c|`, by `D=c`, by `c=1`, and by the sign/clipping inequalities for `A-B`. On each resulting rational polyhedral cell, the objective above is affine. Maximizing an affine function over the one-dimensional `c`-section of each cell gives a piecewise-affine function of `D`, with rational breakpoints. Taking the maximum over finitely many cells preserves finite rational piecewise-linearity. Hence every finite-horizon continuous `K_h`, and therefore `G_h`, is a finite rational piecewise-linear function.

This identifies an exact symbolic object for later work: the unresolved complexity is breakpoint proliferation and the exceptional `c>1` clipped/reflection cells, not an intrinsically infinite-dimensional state space.

## 6. B26 — HUNT THE SPORADIC CASE: tilt the terminal boundary instead of paying a denominator bound

The previous upper bounds first forced ordinary safety negative and then converted a negative safety value into a ratio using the crude estimate `V_i<=m`. That conversion loses a great deal. The tropical/breakpoint viewpoint suggests putting the desired ratio directly into the state coordinate so that hitting zero is already the exact terminal event.

Fix a target

\[
\alpha=1-\delta\in(0,1),
\]

and define the **tilted safety**

\[
z_i:=2(B_i+R_i)-\alpha V_i=s_i+\delta V_i.
\]

Then, exactly,

\[
z_i\le0
\quad\Longleftrightarrow\quad
\frac{2(B_i+R_i)}{V_i}\le\alpha.
\]

No denominator upper bound is needed.

After the same three common unit goods, a `3--0` split already gives factor `2/3`. In a `2--1` split, both agents have `R_i=1` forever for subsequent values in `[0,1]`, and the sorted tilted-safety state is

\[
\left(1+3\delta,\ 3+3\delta\right),
\]

so the gap is still exactly

\[
D=2.
\]

When a later item has values `(a,b)` for the current lower/higher tilted-safety agents, receiving a value `v` changes tilted safety by

\[
2v-\alpha v=(1+\delta)v,
\]

while missing it changes tilted safety by

\[
-\alpha v=-(1-\delta)v.
\]

Therefore the exact one-dimensional target-aware recurrence is as follows. If the high agent receives the good, the current lower tilted safety decreases by

\[
q_H=(1-\delta)a
\]

and the new gap is

\[
D_H=D+(1-\delta)a+(1+\delta)b.
\]

If the low agent receives it, set

\[
C=(1+\delta)a+(1-\delta)b.
\]

For `D>=C`, there is no reflection:

\[
q_L=-(1+\delta)a,\qquad D_L=D-C.
\]

For `D<C`, roles reflect:

\[
q_L=(1-\delta)b-D,\qquad D_L=C-D.
\]

Let `G_h^delta(D)` denote the greatest decrease in the current lower tilted safety that the adversary can force within at most `h` goods. Then

\[
G_h^\delta(D)
=\sup_{a,b\in[0,1]}
\min\{q_H+G_{h-1}^\delta(D_H),\ q_L+G_{h-1}^\delta(D_L)\}.
\]

The exact source target `alpha` is defeated as soon as

\[
G_h^\delta(2)\ge1+3\delta.
\]

This is a much sharper terminal condition than first forcing ordinary safety below a fixed negative constant and only afterward dividing by a worst-case total value.
