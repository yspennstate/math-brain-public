## 3. New theorem: action-weighted pathwise robustness

\[

If the frozen policy has source-threshold gap `G>0` at parameter `P`, then the same policy remains source-valid for every

\[
0\le \eta\le
\frac{G}{S\bigl(76800M_*+230400\bigr)}.
\]

### Proof

For every structural continuous good, the `P` dependence of either immediate branch reward is exactly

\[
-8S\cdot9600\,P\,m_t,
\]

so increasing `P` by `eta` decreases that reward by exactly

\[
76800S\,m_t\eta.
\]

For an old654 action with raw coordinates `(x,y)`, the embedded derivative is `-80S max(x,y)`, which is the same expression after writing `m_t=max(x,y)/960`.

Therefore every fixed root-to-leaf path `pi` loses exactly

\[
76800S\eta\sum_{t\in\pi}m_t
\le 76800S M_*\eta.
\]

The deterministic algorithm chooses branches, so the frozen adversary's guaranteed payoff is the minimum over these path payoffs. Since every path separately loses at most the displayed amount, the minimum loses at most the same uniform amount. The physical source threshold is

\[

and therefore increases by exactly `230400S eta`. Hence the new gap is bounded below by

\[

This is nonnegative on the stated interval. Because the action list, branch dependence, stopping rule, exact announced `p_i`, and finite hidden horizon are unchanged, the resulting witness remains valid in the original Du-Sun source model. `QED`.

This lemma is transferable to finite adversarial dynamic programs more generally: when the parameter enters each edge reward with a state/action-dependent linear coefficient, robustness is controlled by the worst accumulated edge coefficient along a policy path, not by depth times the largest one-step coefficient.
