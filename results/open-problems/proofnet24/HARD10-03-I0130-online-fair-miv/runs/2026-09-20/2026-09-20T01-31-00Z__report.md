## 5. B18(reuse) — full-continuum finite-core-plus-one-scalar reduction for every horizon

Let `F_d(J)` denote the full-continuous at-most-`d` structural Bellman value with the inherited old654 optional-stop continuation `F_0` as terminal handoff. No restriction to the generated rational action columns is made in this section.

The action square gives `0<=v<=3840`. Thus every state `J>=3840` is non-reflected.

Because the inherited old654 handoff has finite certified support, the scalar

\[
C_0:=\sup_{J\ge0}\{F_0(J)+\gamma J\}
\]

is finite. For each depth define

\[
C_d:=\max\left\{C_0,\ \max_{0\le j<3840}\bigl(F_d(j)+\gamma j\bigr)\right\}.
\]

### Tail-envelope theorem

For every finite `d` and every `J>=3840`,

\[
\boxed{F_d(J)\le [C_d-\gamma J]_+},\qquad [x]_+:=\max\{x,0\}.
\]

### Proof

The assertion is immediate for `d=0` from the definition of `C_0`.

Assume it for depth `d-1` and take `J>=3840`. For any continuous action let `q=floor(v)`.

If `q=0`, the low branch keeps the same integer state and has `r_L<=0`, so it cannot exceed the inherited depth-`d-1` value at `J`.

If `q>=1`, the low child is `J-q`. By the lemma above,

\[
r_L\le-\gamma q.
\]

If `J-q<3840`, the definition of `C_{d-1}` gives

\[
F_{d-1}(J-q)\le C_{d-1}-\gamma(J-q).
\]

If `J-q>=3840`, the induction hypothesis gives

\[
F_{d-1}(J-q)\le[C_{d-1}-\gamma(J-q)]_+.
\]

In either case

\[
r_L+F_{d-1}(J-q)\le[C_{d-1}-\gamma J]_+.
\]

The Bellman branch value is a minimum, hence is no larger than this low branch. Maximizing over the entire continuous action square preserves the bound. The optional-stop value `F_0(J)` is also bounded by `[C_0-\gamma J]_+`. Since the at-most-depth values are monotone in `d`, `C_d>=C_{d-1}`, completing the induction.

### Consequence: the infinite state variable is no longer the obstruction

To dominate the full-continuous recursion at depth `d`, it is enough to retain the **3840 reflected states** `J=0,...,3839` plus the single scalar `C_d`; all states `J>=3840` are controlled by the explicit linear envelope above.

\]

Every child of a reflected-core state lies in `0,...,7679`, so core Bellman separation only queries either another one of the 3840 core coordinates or the explicit tail formula. The exact translated ceiling/reflection walls in `(u,v)` remain finite. Therefore each fixed core-plus-scalar iterate has a finite rational-PWA continuous separation problem.

## 7. Transferable lemma for probability workers

The proof in Sections 4–5 is an abstract Lyapunov device worth exporting:

> **Linear-cost tail envelope.** In a max-min dynamic recursion with scalar state `J`, suppose outside a compact reflected set the minimizing player always has a branch that decreases the state by an integer `q>=0` and whose immediate reward is at most `-gamma q`. Then every finite-horizon value outside the compact set is bounded by the positive part of one affine envelope `C_d-gamma J`, where `C_d` is determined solely by the compact-core values and the terminal payoff. Hence the unbounded state space reduces to the compact core plus one scalar envelope level.

This is potentially reusable in regeneration, escape-probability, and random-environment recursions where a one-sided return step carries a cost proportional to distance. It is a proof lemma, not an audit or source claim for those tracks.
