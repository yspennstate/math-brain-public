## 4. B5(reuse) — fixed-policy concavity in the sensitivity parameter

The previous robustness step bounded every path derivative by one uniform worst-case coefficient. That throws away the actual policy structure. Here the policy itself is frozen and its exact parameter dependence is used.

Fix the entire adversary policy selected at `P_0`, including all old654 terminal actions and all 416 generated structural actions. The deterministic online algorithm still chooses the minimizing branch after every presented good.

For every fixed root-to-leaf branch sequence of this frozen adversary, the accumulated payoff is affine in the scalar parameter `P`, because every immediate reward is affine in `P` and all state transitions are fixed by the frozen action geometry. Therefore at any state and any remaining depth the guaranteed frozen-policy payoff is the minimum of finitely many affine functions of `P`.

Hence:

### Lemma — fixed-adversary policy concavity

For a finite adversary policy with branch choices left to the deterministic algorithm, the guaranteed value `V(P)` is concave and piecewise affine in every scalar parameter entering all stage rewards affinely.

A direct backward proof is also immediate. At depth zero the frozen terminal value is obtained by the same finite minimum recursion and is concave. If child values are concave, each branch reward plus child value is concave, and the pointwise minimum of finitely many concave functions is concave. With the adversary action frozen there is no outer maximization to spoil concavity.

Consequently, for `0<=t<=1`,

\[
V(P_0+t)\ge (1-t)V(P_0)+tV(P_0+1).
\]

This is the key replacement for the previous policy-blind Lipschitz estimate.

## 9. Transferable lemma for probability workers

> **Fixed-policy secant lemma for max-min dynamic programs.** Consider a finite-horizon dynamic program in which one player's policy is fixed, the opposing player chooses branches by minimization, and every stage reward is affine in a scalar parameter `theta`. Then every state value under the frozen policy is a concave piecewise-affine function of `theta`. Exact evaluations at `theta_0` and `theta_1` therefore give a rigorous chord lower bound throughout the interval. If the outer/root control can be re-equalized against the chord continuation values while preserving the same transition cell, that re-equalized control yields a certified intermediate-parameter guarantee without recomputing the interior policy.

This is potentially useful in robust-control, branching, and adversarial probability DPs where exact endpoint policies are expensive but finite.
