# Executive update

The exact fixed-population identity remains

\[
B(\lambda)
=
\sum_j
\left[
\frac{\lambda}{\lambda_j+\lambda}
\right]^2r_j^2,
\qquad
r=f^\star-m.
\tag{0.1}
\]

The source shortlist explicitly calls `(0.1)` elementary for a **fixed** mean and a **fixed** kernel and explicitly identifies the harder follow-up as the regime where mean, representation and correction are trained on the same observations.

This run derives an exact finite-dimensional comparison of

\[
\boxed{
\text{zero-mean KRR}
\quad\text{vs}\quad
\text{learned/structured mean + residual KRR}
}
\]

under the same responses.

The central separation is:

1. **spectral mean alignment** controls deterministic bias;
2. **same-response covariance** creates an additional variance penalty;
3. genuine cross-fitting removes that covariance penalty but does **not** remove the variance of the learned mean itself;
4. if the representation/kernel is itself response-dependent, Stein’s identity exposes a second derivative debt from the learned kernel map.

The strongest new exact linear theorem is

## `P15-SAME-RESPONSE-LINEAR-MEAN-22` — PROVED

Condition on a fixed input design. Let

\[
Y=\mu+\varepsilon,
\qquad
E\varepsilon=0,
\qquad
\operatorname{Cov}(\varepsilon)=\Sigma.
\]

Let \(H\) be a fixed linear KRR smoother and put

\[
A=I-H.
\]

Let the learned/structured mean be the same-response linear smoother

\[
m=SY.
\]

Then the zero-mean KRR estimator is

\[
\widehat\mu_0=HY,
\]

whereas the mean-corrected KRR estimator is

\[
\widehat\mu_{\rm same}
=SY+H(Y-SY)
=HY+ASY.
\]

Its exact gain over zero-mean KRR is

\[
\boxed{
\begin{aligned}
G_{\rm same}
:={}&
E\|\widehat\mu_0-\mu\|^2
-
E\|\widehat\mu_{\rm same}-\mu\|^2
\\
={}&
\|A\mu\|^2
-
\|A(I-S)\mu\|^2
\\
&-
2\operatorname{tr}(H\Sigma S^\top A^\top)
-
\operatorname{tr}(AS\Sigma S^\top A^\top).
\end{aligned}
}
\tag{0.2}
\]

No Gaussian assumption is used.

For an independent-copy / cross-fit benchmark \(Y'=\mu+\varepsilon'\), independent of \(Y\) with the same covariance, define

\[
\widehat\mu_{\rm cf}=HY+ASY'.
\]

Then

\[
\boxed{
G_{\rm cf}
=
\|A\mu\|^2
-
\|A(I-S)\mu\|^2
-
\operatorname{tr}(AS\Sigma S^\top A^\top),
}
\tag{0.3}
\]

and therefore

\[
\boxed{
R_{\rm same}-R_{\rm cf}
=
2\operatorname{tr}(H\Sigma S^\top A^\top).
}
\tag{0.4}
\]

Thus cross-fitting removes one exact same-response covariance term. It does not automatically make the learned mean useful because the independent mean still contributes the variance term in `(0.3)`.

For symmetric commuting contractions \(H,S\), isotropic noise \(\Sigma=\sigma^2I\), eigenvalues \(h_j,s_j\in[0,1]\), \(a_j=1-h_j\), and signal coordinates \(\theta_j\),

\[
\boxed{
G_{\rm same}
=
\sum_j
\left[
 a_j^2s_j(2-s_j)\theta_j^2
-
\sigma^2\{2h_ja_js_j+a_j^2s_j^2\}
\right],
}
\tag{0.5}
\]

whereas

\[
\boxed{
G_{\rm cf}
=
\sum_j
 a_j^2s_j
\left[(2-s_j)\theta_j^2-\sigma^2s_j\right].
}
\tag{0.6}
\]

The same-response penalty is exactly

\[
\boxed{
G_{\rm cf}-G_{\rm same}
=
2\sigma^2\sum_jh_ja_js_j.
}
\tag{0.7}
\]

In a nearly interpolating mode \(a_j=1-h_j\downarrow0\) with \(s_j>0\),

\[
\boxed{
G_{{\rm same},j}
=
-2\sigma^2s_ja_j+O(a_j^2),
}
\tag{0.8}
\]

so same-response mean learning is generically harmful at first order in the residual KRR shrinkage gap, even though the bias benefit is only second order.

This is a concrete same-observation mechanism which the elementary identity `(0.1)` cannot see.

A second new theorem gives the nonlinear learned-representation analogue under explicit Gaussian-response hypotheses:

## `P15-HYBRID-VS-KRR-SURE-22` — PROVED / SOURCE-CONDITIONAL

For

\[
Y\sim N(\mu,\sigma^2I),
\]

let the zero-mean kernel estimator be any measurable map

\[
f_0(Y)=H(Y)Y,
\]

and let the mean-corrected estimator be

\[
f_1(Y)=m(Y)+H(Y)(Y-m(Y)).
\]

Put

\[
A(Y)=I-H(Y),
\qquad
g(Y)=A(Y)m(Y).
\]

Whenever \(g\) satisfies Stein’s usual weak differentiability and integrability hypotheses,

\[
\boxed{
E\|f_1-\mu\|^2-E\|f_0-\mu\|^2
=
E\left[
\|g\|^2
-2\langle Y-f_0,g\rangle
+2\sigma^2\operatorname{div}g
\right].
}
\tag{0.9}
\]

Since \(Y-f_0=A(Y)Y\), this is

\[
\boxed{
E\left[
\|A m\|^2
-2\langle AY,Am\rangle
+2\sigma^2\operatorname{div}(Am)
\right].
}
\tag{0.10}
\]

Only the **difference map** \(g=f_1-f_0\) needs the Stein regularity; differentiability of the baseline map itself is not used in the derivation.

If the kernel is response-dependent through a learned representation, the divergence splits exactly as

\[
\boxed{
\operatorname{div}(Am)
=
\operatorname{tr}(A J_m)
+
\sum_{i,j}
\frac{\partial A_{ij}}{\partial Y_i}m_j.
}
\tag{0.11}
\]

The first term is the own-response sensitivity of the learned mean; the second is the response sensitivity of the learned representation/kernel.

Within a stable branch with fixed \(\lambda\), source-normalized KRR has

\[
H=K(K+n\lambda I)^{-1},
\qquad
A=n\lambda(K+n\lambda I)^{-1}.
\]

Writing \(\rho=n\lambda\) and \(R=(K+\rho I)^{-1}\),

\[
A=\rho R,
\qquad
D A[\dot K]
=-\rho R\dot K R.
\]

Therefore

\[
\boxed{
\operatorname{div}(Am)
=
\rho\operatorname{tr}(R J_m)
-
\rho\sum_i
 e_i^\top R
\left(\frac{\partial K}{\partial Y_i}\right)
R m.
}
\tag{0.12}
\]

This is the exact response-reuse debt for a differentiable learned-kernel branch. Hard validation selection is not silently inserted into `(0.12)`; it requires the already-developed hard-margin, soft-selection, LOO, or an extended Stein boundary/search-degree treatment.

# 5. Fixed deterministic mean versus zero-mean KRR

Let \(H\) be any fixed linear smoother and

\[
A=I-H.
\]

Let

\[
Y=\mu+\varepsilon,
\qquad E\varepsilon=0,
\]

with arbitrary covariance.

The zero-mean estimator is

\[
\widehat\mu_0=HY.
\]

For a deterministic mean \(m\), independent of \(Y\), the residual-corrected estimator is

\[
\widehat\mu_m
=
m+H(Y-m)
=HY+Am.
\]

## `P15-FIXED-MEAN-KRR-COMPARE-22` — NEW / PROVED

Let

\[
r=\mu-m.
\]

Then

\[
\boxed{
E\|\widehat\mu_0-\mu\|^2
-
E\|\widehat\mu_m-\mu\|^2
=
\|A\mu\|^2-
\|Ar\|^2.
}
\tag{5.1}
\]

### Proof

The two errors are

\[
\widehat\mu_0-\mu
=H\varepsilon-A\mu,
\]

\[
\widehat\mu_m-\mu
=H\varepsilon-Ar.
\]

The noise term is identical in both estimators and the cross term vanishes because \(E\varepsilon=0\). Subtract the two risks. QED.

### Exact connection to the shortlist

For population KRR,

\[
h_j
=
\frac{\lambda_j}{\lambda_j+\lambda},
\qquad
1-h_j
=
\frac{\lambda}{\lambda_j+\lambda}.
\]

Thus the corrected fixed-mean bias is exactly

\[
\|Ar\|^2
=
\sum_j
\left[
\frac{\lambda}{\lambda_j+\lambda}
\right]^2r_j^2,
\]

which is `(0.1)`.

The true fixed-mean comparison against zero-mean KRR is therefore

\[
\boxed{
G_{\rm fixed}
=
\sum_j
\left[
\frac{\lambda}{\lambda_j+\lambda}
\right]^2
(\mu_j^2-r_j^2).
}
\tag{5.2}
\]

The identity is useful, but it does **not** say that smaller unweighted residual norm implies smaller KRR bias.

# 6. Counterexample: a better fixed mean can worsen KRR

## `P15-BETTER-MEAN-SPECTRAL-CE-22` — NEW / PROVED

Take

\[
H=
\begin{pmatrix}
9/10&0\\
0&1/10
\end{pmatrix},
\qquad
A=I-H=
\begin{pmatrix}
1/10&0\\
0&9/10
\end{pmatrix},
\]

\[
\mu=(1,0)^\top,
\qquad
m=(1/2,1/2)^\top.
\]

The mean is strictly better than zero in ordinary squared norm:

\[
\|\mu-m\|^2=1/2<1=\|\mu\|^2.
\]

But zero-mean KRR has squared bias

\[
\|A\mu\|^2=1/100,
\]

whereas mean-corrected KRR has squared bias

\[
\|A(\mu-m)\|^2
=
(1/20)^2+(9/20)^2
=
41/200.
\]

Thus the “better” mean makes KRR bias worse by the factor

\[
\boxed{20.5}.
\]

This is realizable by positive-ridge KRR. For example, with \(n\lambda=1\), the Gram eigenvalues

\[
\kappa_1=9,
\qquad
\kappa_2=1/9
\]

give exactly the displayed \(H\).

The obstruction is spectral alignment: the mean moves residual energy from a heavily learned mode into a weakly learned mode.

This counterexample is already deterministic and fixed-mean. Same-sample fitting introduces an additional difficulty, not a repair.

# 7. Same-response learned linear mean

Let

\[
Y=\mu+\varepsilon,
\qquad
E\varepsilon=0,
\qquad
\operatorname{Cov}(\varepsilon)=\Sigma.
\]

Let \(H\) be a fixed kernel smoother, \(A=I-H\), and let

\[
m=SY
\]

be a learned linear mean trained on the **same response vector**.

The hybrid estimator is

\[
\widehat\mu_{\rm same}
=SY+H(Y-SY)
=(H+AS)Y.
\]

Put

\[
B=I-S.
\]

Its bias is

\[
E\widehat\mu_{\rm same}-\mu
=-AB\mu.
\]

Its noise operator is

\[
H+AS.
\]

## `P15-SAME-RESPONSE-LINEAR-MEAN-22` — NEW / PROVED

The exact zero-mean-KRR minus hybrid risk difference is `(0.2)`:

\[
\boxed{
\begin{aligned}
G_{\rm same}
={}&
\|A\mu\|^2
-
\|AB\mu\|^2
\\
&-
2\operatorname{tr}(H\Sigma S^\top A^\top)
-
\operatorname{tr}(AS\Sigma S^\top A^\top).
\end{aligned}
}
\tag{7.1}
\]

### Proof

The zero-mean KRR risk is

\[
R_0
=
\|A\mu\|^2
+
\operatorname{tr}(H\Sigma H^\top).
\]

The hybrid risk is

\[
R_{\rm same}
=
\|AB\mu\|^2
+
\operatorname{tr}
[(H+AS)\Sigma(H+AS)^\top].
\]

Expanding the second trace and using symmetry of \(\Sigma\) gives `(7.1)`. QED.

No Gaussianity, asymptotics or candidate independence is used.

# 8. Cross-fitting benchmark and exact covariance penalty

Let

\[
Y'=\mu+\varepsilon'
\]

be an independent copy of \(Y\).

Use \(Y\) for KRR and \(Y'\) to train the mean:

\[
\widehat\mu_{\rm cf}
=HY+ASY'.
\]

Its expectation is the same as the same-response hybrid:

\[
E\widehat\mu_{\rm cf}
=(H+AS)\mu.
\]

But the two noise contributions are independent.

## `P15-CROSSFIT-COVARIANCE-PENALTY-22` — NEW / PROVED

\[
\boxed{
G_{\rm cf}
=
\|A\mu\|^2
-
\|AB\mu\|^2
-
\operatorname{tr}(AS\Sigma S^\top A^\top),
}
\tag{8.1}
\]

and

\[
\boxed{
R_{\rm same}-R_{\rm cf}
=
2\operatorname{tr}(H\Sigma S^\top A^\top).
}
\tag{8.2}
\]

Thus cross-fitting deletes exactly the shared-response covariance term.

For isotropic noise and symmetric positive contractions

\[
0\preceq H\preceq I,
\qquad
S\succeq0,
\]

\[
\operatorname{tr}(HAS)\ge0
\]

because \(HA=H(I-H)\succeq0\). Therefore

\[
\boxed{
R_{\rm cf}\le R_{\rm same}.
}
\tag{8.3}
\]

No commutation between \(H\) and \(S\) is needed for `(8.3)`.

Cross-fitting is therefore a rigorous benchmark for the **dependence penalty**, but it does not guarantee improvement over zero-mean KRR because the independent mean still has its own variance term.

# 9. Spectral bias–variance threshold

Assume now

\[
\Sigma=\sigma^2I
\]

and \(H,S\) are symmetric commuting contractions. Let

\[
H\psi_j=h_j\psi_j,
\qquad
S\psi_j=s_j\psi_j,
\qquad
\mu=\sum_j\theta_j\psi_j,
\]

and set

\[
a_j=1-h_j.
\]

Then `(7.1)` gives

\[
\boxed{
G_{{\rm same},j}
=
 a_j^2s_j(2-s_j)\theta_j^2
-
\sigma^2
[2h_ja_js_j+a_j^2s_j^2].
}
\tag{9.1}
\]

For \(a_js_j>0\), the same-response mean improves this isolated mode iff

\[
\boxed{
\theta_j^2
>
\sigma^2
\frac{2h_j+a_js_j}{a_j(2-s_j)}.
}
\tag{9.2}
\]

Cross-fitting instead gives

\[
\boxed{
G_{{\rm cf},j}
=
 a_j^2s_j
[(2-s_j)\theta_j^2-\sigma^2s_j],
}
\tag{9.3}
\]

so the cross-fit threshold is merely

\[
\boxed{
\theta_j^2
>
\sigma^2\frac{s_j}{2-s_j}.
}
\tag{9.4}
\]

The gap between `(9.2)` and `(9.4)` is exactly the same-response covariance penalty.

## `P15-INTERPOLATING-MODE-OBSTRUCTION-22` — NEW / PROVED

For fixed \(s_j>0\), \(\sigma^2>0\), and bounded signal energy, as

\[
a_j=1-h_j\downarrow0,
\]

\[
\boxed{
G_{{\rm same},j}
=-2\sigma^2s_ja_j+O(a_j^2)<0
}
\tag{9.5}
\]

for all sufficiently small \(a_j\).

Meanwhile

\[
G_{{\rm cf},j}=O(a_j^2).
\]

Thus in a nearly interpolating KRR mode, same-response mean fitting introduces a first-order variance penalty while its spectral bias benefit is only second order.

This is a concrete mechanism by which same-sample mean learning can destroy the naive monotonicity suggested by fixed-mean bias reduction.

# 11. Gaussian nonlinear extension: learned mean and learned representation
