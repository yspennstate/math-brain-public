\[

=

\left[
\frac{\lambda}{\lambda_j+\lambda}
\right]^2r_j^2,
\qquad r=f^\star-m,

# 5. General paired-loss setup

Let `A_s` denote the **entire** size-`s` learning procedure. For a sample `T` it outputs a baseline and corrected predictor

\[
m_T,\qquad m_T+c_T.
\]

All mean training, representation learning, checkpoint selection, kernel/ridge selection, residual-label construction and correction fitting are included in `A_s`.

Let `Z` be a fresh observation and let `ell` be any measurable loss for which the expectations below exist. Define the paired loss difference

\[
\boxed{
d_T(Z)
=
\ell(m_T+c_T,Z)-\ell(m_T,Z).
}
\tag{5.1}

For a realized size-`s` sample `T`, define

\[
\boxed{
\Delta_s(T)=E_Zd_T(Z).
}
\tag{5.2}

Negative `Delta_s(T)` means the correction improves the realized learned predictor in population loss.

Define its algorithm average

\[
\boxed{
\overline\Delta_s=E_T\Delta_s(T).
}
\tag{5.3}

For `S=(Z_1,...,Z_n)`, define the full-pipeline leave-one-out statistic

\[
\boxed{
\widehat\Delta_{\rm loo}(S)
=
\frac1n\sum_{i=1}^n d_{S^{-i}}(Z_i).
}
\tag{5.4}

By exchangeability alone,

\[
\boxed{
E\widehat\Delta_{\rm loo}
=
\overline\Delta_{n-1}.
}
\tag{5.5}

This identity does **not** require Gaussian noise. It concerns ordinary predictive population loss on the same observation law. For squared regression against an unobserved target function `mu`, the prior centered-noise theorem `P15-LOO-POPULATION-GAIN-20` additionally identifies the held-out noisy paired loss with the target-function squared-risk difference.

# 6. Stability quantities

Define the size-`s` paired-loss replacement stability

\[
\boxed{
\beta_s
=
\sup_{T\sim T'}\sup_z
|d_T(z)-d_{T'}(z)|,
}
\tag{6.1
}

where `T~T'` means same size and one observation is replaced.

Define the size-`n` paired-loss deletion stability

\[
\boxed{
\eta_n
=
\sup_{S,i,z}
|d_S(z)-d_{S^{-i}}(z)|.
}
\tag{6.2
}

Define the size-`n-1` evaluation oscillation

\[
\boxed{
a_{n-1}
=
\sup_T\sup_{z,z'}
|d_T(z)-d_T(z')|.
}
\tag{6.3
}

All are properties of the **whole fitted pipeline**, not of KRR alone.

For randomized training, one may condition on a common external random seed and prove the constants uniformly or with a separate high-probability seed event. Independently redrawing optimizer randomness in neighboring datasets measures optimization noise in addition to data sensitivity and is not silently substituted here.

# 7. New theorem — high-probability LOO gain for the realized full-sample learner

## `P15-LOO-FULLSAMPLE-HIGHPROB-21` — NEW / PROVED

Assume the iid sample setup of Section 5 and finite deterministic quantities `(6.1)`--`(6.3)`.

Then for every

\[
0<\delta<1,
\]

with probability at least

\[
1-\delta
\]

over the training sample,

\[
\boxed{
\begin{aligned}
\Delta_n(S)
\le{}&
\widehat\Delta_{\rm loo}(S)
\\
&+
\big[a_{n-1}+(n-1)\beta_{n-1}\big]
\sqrt{\frac{\log(2/\delta)}{2n}}
\\
&+
\eta_n
+
\beta_n
\sqrt{\frac{n\log(2/\delta)}2}.
\end{aligned}
}
\tag{7.1}

Consequently, if the right-hand side of `(7.1)` is negative, then

\[
\boxed{
E_Z\ell(m_S+c_S,Z)
<
E_Z\ell(m_S,Z).
}
\tag{7.2}

This is a one-sample finite-sample population theorem for the **full size-`n` same-observation learned pipeline**.

No independence between the mean, learned representation and correction is inserted.

## Proof

### Step 1: sensitivity of the LOO statistic

Let `S^(j)` replace `Z_j` by an independent value `Z_j'`.

For the `i=j` summand,

\[
S^{-j}=(S^{(j)})^{-j},
\]

so the fitted pipeline is identical and only the evaluation point changes. Thus

\[
|d_{S^{-j}}(Z_j)-d_{S^{-j}}(Z_j')|
\le a_{n-1}.
\tag{7.3}

For every `i != j`, the evaluation point `Z_i` is unchanged, while the two size-`n-1` fitting samples differ by one replacement. Hence

\[
|d_{S^{-i}}(Z_i)-d_{(S^{(j)})^{-i}}(Z_i)|
\le\beta_{n-1}.
\tag{7.4}

Therefore changing one coordinate changes the LOO average by at most

\[
\boxed{
c_{\rm loo}
=
\frac{a_{n-1}+(n-1)\beta_{n-1}}n.
}
\tag{7.5}

McDiarmid's bounded-differences inequality gives, with failure at most `delta/2`,

\[
\overline\Delta_{n-1}
=E\widehat\Delta_{\rm loo}
\le
\widehat\Delta_{\rm loo}
+
[a_{n-1}+(n-1)\beta_{n-1}]
\sqrt{\frac{\log(2/\delta)}{2n}}.
\tag{7.6}

### Step 2: expected size-`n-1` to size-`n` transfer

For every `S` and `i`, deletion stability gives

\[
|\Delta_n(S)-\Delta_{n-1}(S^{-i})|
\le\eta_n.
\]

Taking expectation and averaging `i`,

\[
\boxed{
E\Delta_n(S)
\le
\overline\Delta_{n-1}+\eta_n.
}
\tag{7.7}

### Step 3: concentration of the realized full-sample population gap

If one training coordinate is replaced, then `(6.1)` gives pointwise in fresh `z`

\[
|d_S(z)-d_{S^{(j)}}(z)|\le\beta_n.
\]

Therefore

\[
|\Delta_n(S)-\Delta_n(S^{(j)})|
\le\beta_n.
\tag{7.8}

McDiarmid gives, with failure at most `delta/2`,

\[
\Delta_n(S)
\le
E\Delta_n(S)
+
\beta_n\sqrt{\frac{n\log(2/\delta)}2}.
\tag{7.9}

Combine `(7.6)`--`(7.9)` and union bound.

QED.

# 8. Interpretation and rate regime

The theorem is intentionally a **uniform-stability / exponential-confidence** result.

If

\[
a_{n-1}=O(1),
\qquad
\beta_{n-1},\beta_n,\eta_n=O(n^{-1}),
\]

then for fixed confidence

\[
\boxed{
\Delta_n(S)
\le
\widehat\Delta_{\rm loo}(S)
+O(n^{-1/2}).
}
\tag{8.1}

If the best available uniform replacement stability is only

\[
\beta_n=O(n^{-1/2}),
\]

the last McDiarmid width is generally order one, so `(7.1)` may be vacuous.

This does **not** invalidate the prior P15 average-energy architecture. It clarifies the division of labor:

- `P15-LOO-FULLSAMPLE-HIGHPROB-21` gives a clean exponential tail under strong uniform paired-loss stability;
- `P15-AVG-REPL-LOOGATE-03` and the later outer-Efron--Stein/L2-Green modules remain preferable when only RMS/average stability is available.

The theorem therefore adds a sharp simple route; it does not supersede the weaker-moment route.

# 9. Second-moment LOO concentration

Uniform bounded differences are not the only route.

For replacement coordinate `j`, define

\[
A_j
=
d_{S^{-j}}(Z_j)-d_{S^{-j}}(Z_j'),
\tag{9.1}
\]

and for `i != j`,

\[
B_{ij}
=
d_{S^{-i}}(Z_i)-d_{(S^{(j)})^{-i}}(Z_i).
\tag{9.2}

Put

\[
\boxed{
a_2^2
=
\frac1n\sum_jEA_j^2,
}
\tag{9.3}

\[
\boxed{
b_2^2
=
\frac1{n(n-1)}
\sum_j\sum_{i\ne j}EB_{ij}^2.
}
\tag{9.4}

## `P15-LOO-EFRON-GAIN-21` — NEW / PROVED

\[
\boxed{
\operatorname{Var}(\widehat\Delta_{\rm loo})
\le
\frac{a_2^2+(n-1)^2b_2^2}{n}.
}
\tag{9.5}

Consequently, by one-sided Chebyshev, with probability at least `1-delta`,

\[
\boxed{
\overline\Delta_{n-1}
\le
\widehat\Delta_{\rm loo}
+
\sqrt{
\frac{a_2^2+(n-1)^2b_2^2}{n\delta}
}.
}
\tag{9.6}

### Proof

For `S^(j)` as above,

\[
\widehat\Delta_{\rm loo}(S)
-
\widehat\Delta_{\rm loo}(S^{(j)})
=
\frac1n
\left[
A_j+
\sum_{i\ne j}B_{ij}
\right].
\]

Use

\[
(x+y)^2\le2x^2+2y^2
\]

and

\[
\left(\sum_{i\ne j}B_{ij}\right)^2
\le
(n-1)\sum_{i\ne j}B_{ij}^2.
\]

The Efron--Stein factor `1/2` cancels the factor `2`, yielding exactly `(9.5)`.

QED.

This theorem needs only second moments of the actual paired-loss perturbations, but its confidence dependence is polynomial. A full realized size-`n` version additionally requires concentration of `Delta_n(S)` itself; uniform `beta_n` in Section 7 is one route, while prior P15 outer-stability machinery supplies others.

# 10. Squared-loss specialization — exact stability currency

For squared vector-output loss define

\[
d(m,c;z)
=
\|y-m(x)-c(x)\|^2
-
\|y-m(x)\|^2.
\tag{10.1}

Consider two fitted systems

\[
m'=m+u,
\qquad
c'=c+v.
\]

Put

\[
q=y-m-c.
\]

Direct expansion gives the exact identity

\[
\boxed{
\begin{aligned}
d(m',c';z)-d(m,c;z)
={}&
-2\langle q,v\rangle
+2\langle u,c\rangle
\\
&+2\langle u,v\rangle
+\|v\|^2.
\end{aligned}
}
\tag{10.2}

Thus if uniformly over the relevant fitted systems and query points

\[
\|q\|\le Q,
\qquad
\|c\|\le C,
\tag{10.3}

and a neighboring fit satisfies

\[
\|u\|\le e_m,
\qquad
\|v\|\le e_c,
\tag{10.4}

then

## `P15-PAIRLOSS-STABILITY-21` — NEW / PROVED

\[
\boxed{
|d(m',c';z)-d(m,c;z)|
\le
2Qe_c
+2Ce_m
+2e_me_c
+e_c^2.
}
\tag{10.5}

Moreover

\[
d(m,c;z)
=
-2\langle q,c\rangle-\|c\|^2,
\]

so

\[
|d(m,c;z)|
\le
2QC+C^2,
\tag{10.6}

and one may take

\[
\boxed{
a_{n-1}\le4QC+2C^2.}
\tag{10.7}

This is the exact interface from prior P15 prediction stability into the new LOO theorem.

For example:

- fixed-positive-ridge KRR supplies `e_c=O(n^{-1})` for the fixed-kernel/fixed-label component under the established bounded-kernel assumptions;
- learned residual labels and learned representations contribute through their actual operator/RHS perturbation budgets;
- AdamW/refiner prediction changes contribute to `e_m` through the finite-horizon/L2-Green modules;
- hard branch stability can make selector contribution zero under a margin;
- soft selection supplies an explicit additional prediction difference;
- OOF/full-data channel drift must be included rather than discarded.

No independence is created by the specialization.

# 12. Counterexample — LOO expectation does not imply one-run LOO gain without stability

## `P15-LOO-NOSTABILITY-CE-21` — NEW / PROVED

Let

\[
X_1,\ldots,X_n
\stackrel{\rm iid}{\sim}\operatorname{Rad}(\pm1),
\]

with `n` even, and take deterministic labels

\[
Y_i\equiv1.
\]

For any odd-size training sample `T`, define

\[
h(T)=\operatorname{sign}\left(\sum_{z\in T}x(z)\right)\in\{-1,+1\}.
\]

Use baseline prediction

\[
m_T\equiv0.
\]

Define the corrected constant predictor by

\[
m_T+c_T
=
\begin{cases}
1,&h(T)=-1,\\
1+\sqrt2,&h(T)=+1.
\end{cases}
\tag{12.1}

The baseline squared loss is always `1`.

If `h(T)=-1`, corrected loss is zero, so paired difference is `-1`.

If `h(T)=+1`, corrected loss is `2`, so paired difference is `+1`.

Hence

\[
\boxed{d_T(z)=h(T)}
\tag{12.2}

for every evaluation point `z`.

Because an odd Rademacher sum has a symmetric nonzero sign,

\[
\overline\Delta_{n-1}=Eh(T)=0.
\tag{12.3}

Now compute the LOO statistic on an even-size sample. Let

\[
T_n=\sum_{j=1}^nX_j.
\]

If `T_n>=2`, then for every `i`,

\[
T_n-X_i>0,
\]

so every LOO fitted sign is `+1` and

\[
\widehat\Delta_{\rm loo}=+1.
\]

If `T_n<=-2`, every LOO fitted sign is `-1` and

\[
\widehat\Delta_{\rm loo}=-1.
\]

If `T_n=0`, exactly half the leave-one-out signs are positive and half negative, so

\[
\widehat\Delta_{\rm loo}=0.
\]

Therefore

\[
\boxed{
P\{|\widehat\Delta_{\rm loo}|=1\}
=1-P\{T_n=0\}
\longrightarrow1.
}
\tag{12.4}

Yet

\[
\boxed{E\widehat\Delta_{\rm loo}=0.}
\]

Thus the realized LOO average fails to concentrate at all despite bounded deterministic labels and bounded predictions.

The instability is exactly at the majority boundary: replacing one training feature can flip the selected correction from perfect to harmful, changing the paired loss by `2`.

\[
\boxed{
\text{the unbiased LOO population identity does not imply a one-run gain certificate without algorithmic stability or another concentration mechanism.}
}
