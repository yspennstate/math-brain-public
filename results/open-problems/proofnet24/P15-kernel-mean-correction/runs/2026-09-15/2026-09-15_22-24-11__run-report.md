# 0. Executive result

P15 remains **OPEN**.

The fixed-population identity remains exactly

\[
B(\lambda)
=
\sum_j
\left[
\frac{\lambda}{\lambda_j+\lambda}
\right]^2 r_j^2,
\qquad
r=f^\star-m,
\]

for a **fixed** mean and a **fixed** population kernel operator. It is not promoted to a theorem about a mean, representation, selection rule and correction trained on the same observations.

This run proves a new full-dataset ghost/cross-fit identity that is deliberately more general than the preceding fixed-kernel calculations. It permits the baseline and correction increment to be arbitrary measurable learning procedures, so the mean, representation, hyperparameters, stack and correction may all depend on the same sample.

Let

\[
S=(Z_1,\ldots,Z_n),
\qquad
S'=(Z'_1,\ldots,Z'_n)
\]

be independent iid training samples, let `b_S` be the uncorrected baseline predictor (for P15, zero-mean KRR or the corresponding uncorrected kernel pipeline), let `f_S` be the corrected predictor, and define the learned correction increment

\[
g_S=f_S-b_S.
\]

For a fresh test pair `Z=(U,Y)` independent of both samples, compare

\[
f_{\rm same}=b_S+g_S
\]

with the independent whole-pipeline ghost/cross-fit benchmark

\[
f_{\rm ghost}=b_S+g_{S'}.
\]

Then for squared loss,

\[
\boxed{
R_{\rm same}-R_{\rm ghost}
=
E\left\langle
b_S(U)-b_{S'}(U),
\,g_S(U)-g_{S'}(U)
\right\rangle.
}
\tag{0.1}
\]

This is `P15-SAMEOBS-GHOST-COVARIANCE-31 — PROVED`. It requires only finite second moments and iid sampling. There is no Gaussian-noise assumption, no fixed-representation assumption, and no independence between the learned mean, learned representation and learned correction inside `S`.

If `S^{(i)}` replaces one row by an independent copy and

\[
\beta_b^2
=
\frac1n\sum_i
E\|b_S-b_{S^{(i)}}\|_{L^2(P_U)}^2,
\qquad
\beta_g^2
=
\frac1n\sum_i
E\|g_S-g_{S^{(i)}}\|_{L^2(P_U)}^2,
\]

Hilbert-space Efron--Stein gives the finite-sample transfer bound

\[
\boxed{
|R_{\rm same}-R_{\rm ghost}|
\le n\beta_b\beta_g.
}
\tag{0.2}
\]

Consequently, if an independent/cross-fitted benchmark has gain

\[
G_{\rm ghost}
:=R(b_S)-R(b_S+g_{S'})
\ge\gamma>0
\]

and

\[
n\beta_b\beta_g<\gamma,
\]

then

\[
\boxed{
G_{\rm same}
:=R(b_S)-R(b_S+g_S)
\ge
\gamma-n\beta_b\beta_g>0.
}
\tag{0.3}
\]

This is a genuine finite-sample **same-observation expected-population comparison theorem**. It is not the elementary population spectral identity above.

For the manuscript's actual unsquared mean-relative metric, a stronger one-sided transfer is possible because the norm loss is prediction-Lipschitz. Define

\[
\|h\|_{w,2}^2
=
E_Z\frac{\|h(U)\|_2^2}{\|Y\|_2^2}
\]

whenever finite, and

\[
(\beta_{g,w})^2
=
\frac1n\sum_i
E\|g_S-g_{S^{(i)}}\|_{w,2}^2.
\]

Then

\[
\boxed{
|R_{\rm rel,same}-R_{\rm rel,ghost}|
\le
\sqrt n\,\beta_{g,w}.
}
\tag{0.4}
\]

Thus a ghost/cross-fit mean-relative gain larger than `sqrt(n) beta_{g,w}` transfers to the actual same-sample pipeline. This theorem allows arbitrary learned representations and selection inside `g_S`; it does not require baseline stability. If the weighted second moment is unavailable because outputs can approach zero, the already-proved P15 truncation/small-output machinery must be used instead. No positive output-norm floor is invented for the mechanics source.

The run also specializes the ghost identity to a fixed realized KRR kernel and additive response noise. # 3. Full-dataset ghost benchmark: exact covariance identity

## `P15-SAMEOBS-GHOST-COVARIANCE-31` — PROVED

Let

\[
S=(Z_1,\ldots,Z_n),
\qquad
S'=(Z'_1,\ldots,Z'_n)
\]

be independent iid copies from the training law, and let `Z=(U,Y)` be a fresh independent test pair.

Let

\[
b_S: \mathcal U\to\mathbb R^q
\]

be **any** learned baseline and let

\[
f_S=b_S+g_S
\]

be **any** corrected procedure. The maps may include arbitrary same-sample neural fitting, feature learning, checkpoint selection, validation rules, kernel/ridge selection, stacking and residual KRR. Only the final predictions and second moments are used below.

Define the same-sample and whole-sample ghost predictors

\[
f_{\rm same}=b_S+g_S,
\qquad
f_{\rm ghost}=b_S+g_{S'}.
\]

For squared population loss define

\[
R_{\rm same}
=E\|Y-b_S(U)-g_S(U)\|^2,
\]

\[
R_{\rm ghost}
=E\|Y-b_S(U)-g_{S'}(U)\|^2.
\]

Then

\[
\boxed{
R_{\rm same}-R_{\rm ghost}
=
E\left\langle
b_S(U)-b_{S'}(U),
\,g_S(U)-g_{S'}(U)
\right\rangle.
}
\tag{3.1}
\]

### Proof

Expand the two risks. Since `g_S` and `g_{S'}` have the same marginal law,

\[
E\|g_S(U)\|^2
=
E\|g_{S'}(U)\|^2.
\]

Since the fresh target is independent of both training samples and the two correction increments have the same marginal law,

\[
E\langle Y,g_S(U)\rangle
=
E\langle Y,g_{S'}(U)\rangle.
\]

Therefore

\[
R_{\rm same}-R_{\rm ghost}
=
2\left(
E\langle b_S,g_S\rangle
-
E\langle b_S,g_{S'}\rangle
\right).
\tag{3.2}
\]

By exchangeability of `S,S'`,

\[
E\langle b_{S'},g_{S'}\rangle
=E\langle b_S,g_S\rangle
\]

and

\[
E\langle b_{S'},g_S\rangle
=E\langle b_S,g_{S'}\rangle.
\]

Thus

\[
E\langle b_S-b_{S'},g_S-g_{S'}\rangle
=2\left(
E\langle b_S,g_S\rangle
-E\langle b_S,g_{S'}\rangle
\right),
\]

which is `(3.1)`.

### Interpretation

The same-sample versus ghost gap is exactly a **training-sample covariance between the uncorrected baseline and the learned correction increment**. It has no universal sign. Cross-fitting removes this covariance by construction; reuse may hurt or help.

Unlike the fixed-population bias identity, `(3.1)` is a theorem about complete data-dependent learners. Unlike the earlier fixed-design linear-mean calculations, it does not require the representation to be fixed.

# 4. Replacement-stability transfer for the full learned pipeline

## `P15-GHOST-REPLACEMENT-TRANSFER-31` — PROVED

Let `S^{(i)}` replace the `i`th observation of `S` by an independent copy. Work in

\[
\mathcal H=L^2(P_U;\mathbb R^q).
\]

Define

\[
a_i^2
=E\|b_S-b_{S^{(i)}}\|_{\mathcal H}^2,
\qquad
c_i^2
=E\|g_S-g_{S^{(i)}}\|_{\mathcal H}^2,
\]

and

\[
\beta_b^2=\frac1n\sum_i a_i^2,
\qquad
\beta_g^2=\frac1n\sum_i c_i^2.
\]

Hilbert-space Efron--Stein gives

\[
E\|b_S-b_{S'}\|_{\mathcal H}^2
=2E\|b_S-Eb_S\|_{\mathcal H}^2
\le
\sum_i a_i^2,
\tag{4.1}
\]

and likewise

\[
E\|g_S-g_{S'}\|_{\mathcal H}^2
\le
\sum_i c_i^2.
\tag{4.2}
\]

Applying Cauchy--Schwarz to `(3.1)` therefore yields

\[
\boxed{
|R_{\rm same}-R_{\rm ghost}|
\le
\sqrt{\sum_i a_i^2}
\sqrt{\sum_i c_i^2}
\le
n\beta_b\beta_g.
}
\tag{4.3}
\]

No uniform stability, differentiability, convexity or fixed representation is assumed. The cost is that this is an expectation-level finite-sample theorem and the debt is expressed in the actual full-pipeline replacement energies.

### Same-sample improvement certificate

Let

\[
G_{\rm ghost}
=R(b_S)-R(b_S+g_{S'}),
\qquad
G_{\rm same}
=R(b_S)-R(b_S+g_S).
\]

Then

\[
G_{\rm same}
=
G_{\rm ghost}-(R_{\rm same}-R_{\rm ghost}).
\]

Hence:

## `P15-CROSSFIT-TO-SAME-CERT-31` — PROVED

If

\[
G_{\rm ghost}\ge\gamma>0
\]

and

\[
n\beta_b\beta_g<\gamma,
\]

then

\[
\boxed{G_{\rm same}>0.}
\tag{4.4}
\]

This is the cleanest general answer obtained so far to the user's target: an independent/cross-fitted gain margin transfers to the fully reused learned pipeline once the exact dependence debt is smaller than the margin.

It does **not** claim that the source currently satisfies the needed numerical inequality. Measuring the replacement energies remains a source obligation.

# 9. Representation dependence: what the new theorem does and does not solve

The full-dataset identity `(3.1)` already permits a response-trained representation because `b_S` and `g_S` are arbitrary full learning procedures. Thus its replacement-stability transfer is valid at the **algorithm output level** without conditioning on a learned representation.
