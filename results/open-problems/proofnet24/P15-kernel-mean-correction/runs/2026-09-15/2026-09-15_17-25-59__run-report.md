## `P15-ANISOCOV-THREELEVEL-26` — NEW / PROVED

The fixed / cross-fit / same-response hierarchy extends to arbitrary response covariance \(\Sigma\), but the ordering between cross-fit and same-response estimators does **not** survive automatically.

For a fixed symmetric KRR smoother \(0\preceq H\preceq I\), \(A=I-H\), deterministic symmetric PSD structured-mean smoother \(S\), and

\[
Y=\mu+\varepsilon,
\qquad
E\varepsilon=0,
\qquad
\operatorname{Cov}(\varepsilon)=\Sigma\succeq0,
\]

the exact gains over zero-mean KRR are

\[
\boxed{
G_{\rm det}
=
\|A\mu\|^2-\|A(I-S)\mu\|^2,
}
\]

\[
\boxed{
G_{\rm cf}
=
G_{\rm det}
-
\operatorname{tr}(AS\Sigma SA),
}
\]

and

\[
\boxed{
G_{\rm same}
=
G_{\rm cf}
-
2\operatorname{tr}(HA S\Sigma).
}
\]

Thus

\[
\boxed{
G_{\rm det}\ge G_{\rm cf}
}
\]

always, but

\[
\boxed{
G_{\rm cf}-G_{\rm same}
=
2\operatorname{tr}(HA S\Sigma)
}
\]

has no universal sign for arbitrary anisotropic \(\Sigma\).

If \(\Sigma\) commutes with \(H\), then \(A,H,\Sigma\) commute and

\[
AH\Sigma\succeq0.
\]

For \(S\succeq0\),

\[
\operatorname{tr}(HA S\Sigma)
=
\operatorname{tr}((AH\Sigma)S)
\ge0,
\]

so the inherited ordering

\[
\boxed{
G_{\rm det}\ge G_{\rm cf}\ge G_{\rm same}
}
\]

holds under the strictly weaker condition `[Sigma,H]=0`, not only \(\Sigma=\sigma^2I\).

## `P15-ANISOCOV-CROSSFIT-REVERSAL-CE-26` — NEW / PROVED COUNTEREXAMPLE

Cross-fitting is an independence benchmark, but it is **not** universally risk-dominating under arbitrary anisotropic covariance.

In pure noise \(\mu=0\), take

\[
H=
\begin{pmatrix}
1/2&0\\
0&0
\end{pmatrix},
\qquad
A=
\begin{pmatrix}
1/2&0\\
0&1
\end{pmatrix},
\]

\[
u=\frac1{\sqrt2}(1,1)^\top,
\qquad
P=uu^\top,
\qquad
v=(-1,2)^\top,
\qquad
\Sigma=vv^\top,
\]

and use the same PSD mean smoother \(S=sP\) with \(s=1/2\).

Then

\[
\operatorname{tr}(HAP\Sigma)=-\frac18,
\qquad
\operatorname{tr}(AP\Sigma PA)=\frac5{16}.
\]

Therefore

\[
\boxed{
G_{\rm cf}
=-\frac5{64}<0,
}
\]

while

\[
\boxed{
G_{\rm same}
=
-2s\left(-\frac18\right)
-s^2\frac5{16}
=
\frac3{64}>0.
}
\]

The baseline risk is \(1/4\), the cross-fit risk is \(21/64\), and the same-response risk is \(13/64\).

Thus the same-response covariance interaction can be harmful, zero, or favorable. Calling it a universal “tax” is justified only under an explicit sign hypothesis such as isotropic noise or `[Sigma,H]=0` with \(S\succeq0\).

## `P15-SOURCE-OOF-CENTERING-LEAK-26` — NEW / PROVED

The source's four-fold “out-of-fold” KRR conditioning channel is not fully response-excluding because its default pooled target-centering statistic uses **all 19000 fitting responses**, including the 4750 responses in the held-out fold.

For one fold, let

\[
F=\text{14250 kernel-fitting rows},
\qquad
H=\text{4750 held-out rows},
\qquad
N=19000.
\]

Set

\[
A_F=K_{FF}+|F|\lambda I,
\qquad
P_H=K_{HF}A_F^{-1},
\qquad
b_H=\mathbf1_H-P_H\mathbf1_F.
\]

For vector-valued targets, write \(\mu_F,\mu_H,\mu_P\) for fold-fit, held-out-fold and pooled row means. The centered KRR field is

\[
\widehat Y_H(\mu)
=
P_HY_F+b_H\mu^\top.
\]

Therefore the source supplement's exact identity is

\[
\boxed{
\widehat Y_H^{F}
-
\widehat Y_H^{P}
=
b_H(\mu_F-\mu_P)^\top
=
\frac{|H|}{N}
b_H(\mu_F-\mu_H)^\top.
}
\]

Because \(|H|/N=1/4\) in the source four-fold design,

\[
\boxed{
\widehat Y_H^{F}-\widehat Y_H^{P}
=
\frac14 b_H(\mu_F-\mu_H)^\top.
}
\]

Conditional on \(X\) and \(Y_F\), the pooled field has the exact own-fold response decomposition

\[
\boxed{
\widehat Y_H^{P}
=
\underbrace{
P_HY_F
+
\frac{|F|}{N}b_H\mu_F^\top
}_{\text{independent of }Y_H}
+
\underbrace{
\frac1N b_H\mathbf1_H^\top Y_H
}_{\text{own-fold response leakage}}.
}
\]

Thus the own-fold response operator is

\[
\boxed{
L_H
=
\frac1N b_H\mathbf1_H^\top,
}
\]

which has rank at most one and

\[
\boxed{
\|L_H\|_{\rm op}
=
\|L_H\|_F
=
\frac{\sqrt{|H|}}{N}\|b_H\|_2.
}
\]

Replacing one held-out response row \(Y_i\), \(i\in H\), changes the **entire held-out KRR field** by exactly

\[
\boxed{
\Delta\widehat Y_H^P
=
\frac1N b_H(\Delta Y_i)^\top.
}
\]

Fold-local centering has zero own-fold response sensitivity at the KRR-channel stage.

Across all four folds, the direct own-fold leakage operator is block diagonal after fold ordering and has row-space rank at most four:

\[
\boxed{
\operatorname{rank}(L_{\rm own})\le4.
}
\]

This gives a source-exact, low-rank dependence channel that can be measured from the four existing KRR factorizations. It does **not** imply that the full refiner/stack/correction pipeline is cross-fitted: neural training, validation selection, and correction refitting introduce additional dependence already tracked by inherited P15 stability modules.

The source supplement independently reruns the whole downstream mechanics pipeline with fold-local centering and reports pooled versus fold-local final errors indistinguishable at the quoted scale; that is useful empirical evidence, not a theorem that the leakage operator is universally negligible.

The highest-value source-specific next measurement is therefore no longer vague: compute the four vectors \(b_H\), their norms and traces, and the frozen-refiner directional response along the corresponding four leakage directions.

# 5. Exact anisotropic three-level theorem

We now prove the main statistical extension.

Fix a design. Consider one scalar response coordinate; vector-output versions follow by block covariance / summing coordinates.

Let

\[
Y=\mu+\varepsilon,
\qquad
E\varepsilon=0,
\qquad
\operatorname{Cov}(\varepsilon)=\Sigma\succeq0.
\]

Let

\[
H=H^\top,
\qquad
0\preceq H\preceq I,
\qquad
A=I-H.
\]

Let

\[
S=S^\top\succeq0
\]

be deterministic.

The zero-mean KRR benchmark is

\[
f_0=HY.
\]

Define three structured means followed by the same residual smoother \(H\).

### Oracle fixed mean

\[
m_{\rm det}=S\mu,
\qquad
f_{\rm det}
=S\mu+H(Y-S\mu)
=HY+AS\mu.
\]

### Cross-fit mean

Let

\[
Y'=\mu+\varepsilon',
\]

where \(\varepsilon'\) is independent of \(\varepsilon\) and has covariance \(\Sigma\). Put

\[
m_{\rm cf}=SY',
\qquad
f_{\rm cf}=HY+ASY'.
\]

### Same-response mean

\[
m_{\rm same}=SY,
\qquad
f_{\rm same}=HY+ASY.
\]

All three have common mean prediction

\[
H\mu+AS\mu
=
\mu-A(I-S)\mu.
\]

Hence their common squared bias is

\[
\|A(I-S)\mu\|^2,
\]

while zero-mean KRR has squared bias

\[
\|A\mu\|^2.
\]

Define baseline-minus-hybrid risk gain

\[
G
=
E\|f_0-\mu\|^2
-
E\|f-\mu\|^2.
\]

The exact gains are

\[
\boxed{
G_{\rm det}
=
\|A\mu\|^2
-
\|A(I-S)\mu\|^2,
}
\tag{5.1}
\]

\[
\boxed{
G_{\rm cf}
=
G_{\rm det}
-
V_\Sigma(S),
}
\tag{5.2}

\[
\boxed{
G_{\rm same}
=
G_{\rm det}

V_\Sigma(S)
-
2T_\Sigma(S),

\tag{5.3}

where

\[
\boxed{
V_\Sigma(S)

\|AS\Sigma^{1/2}\|_F^2
\ge0,

\tag{5.4}
\]

and

\[
\boxed{
T_\Sigma(S)
=
\operatorname{tr}(HA S\Sigma).
}
\tag{5.5}
\]

### Proof

The zero-mean KRR risk is

\[
R_0
=
\|A\mu\|^2
+
\operatorname{tr}(H\Sigma H).
\]

For the deterministic mean, the noise remains \(H\varepsilon\), so only the bias changes, proving `(5.1)`.

For the cross-fit mean,

\[
f_{\rm cf}-\mu
=
-A(I-S)\mu
+
H\varepsilon
+
AS\varepsilon'.
\]

The two noise terms are independent and centered. Therefore

\[
E\|H\varepsilon+AS\varepsilon'\|^2
=
\operatorname{tr}(H\Sigma H)
+
\operatorname{tr}(AS\Sigma SA),
\]

which proves `(5.2)`.

For the same-response mean,

\[
f_{\rm same}-\mu
=
-A(I-S)\mu
+
(H+AS)\varepsilon.
\]

Expand the variance:

\[
\begin{aligned}
E\|(H+AS)\varepsilon\|^2
={}&
\operatorname{tr}(H\Sigma H)
+
\operatorname{tr}(AS\Sigma SA)
\\
&+
\operatorname{tr}(H\Sigma SA)
+
\operatorname{tr}(AS\Sigma H).
\end{aligned}
\]

The two cross traces are equal because they are transposes of each other, and by cyclicity both equal

\[
\operatorname{tr}(HA S\Sigma).
\]

This proves `(5.3)`.

QED.
