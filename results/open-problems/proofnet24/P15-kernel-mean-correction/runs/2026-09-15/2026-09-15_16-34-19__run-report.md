# 0. Executive update

The source population identity remains

\[
B(\lambda)
=
\sum_j
\left[
\frac{\lambda}{\lambda_j+\lambda}
\right]^2r_j^2,
\qquad
r=f^\star-m.
\]

The source shortlist itself says this is elementary for a **fixed** mean and a **fixed** kernel. It is not a theorem for a mean, representation, residual labels, model selector and kernel correction trained from overlapping observations.

The preceding P15 run solved the commuting fixed-design linear benchmark mode by mode. If zero-mean KRR has shrinkage `h`, `a=1-h`, the same-response mean multiplier is `s`, the signal coefficient is `theta`, and response noise has variance `sigma^2`, then

\[
G_{\rm same}(s)
=
a^2s(2-s)\theta^2
-
\sigma^2\bigl(2has+a^2s^2\bigr),
\]

so a nonzero same-response mean is beneficial iff

\[
\frac{\theta^2}{\sigma^2}
>
\frac{h}{1-h}.
\]

This run removes the commuting hypothesis and obtains a finite-dimensional **subspace oracle**.

The principal new result is:

## `P15-NONCOMMUTING-SUBSPACE-ORACLE-25` — NEW / PROVED

Condition on a fixed design and let

\[
Y=\mu+\varepsilon,
\qquad
E\varepsilon=0,
\qquad
\operatorname{Cov}(\varepsilon)=\sigma^2I_N.
\]

Let a fixed symmetric KRR smoother satisfy

\[
0\preceq H\prec I,
\qquad
A=I-H.
\]

Let `P` be any orthogonal projector, **not required to commute with** `H`, and fit the structured mean from the **same response vector** by

\[
m_s(Y)=sPY,
\qquad
0\le s\le1.
\]

The zero-mean KRR baseline and hybrid are

\[
f_0=HY,
\qquad
f_s=sPY+H(Y-sPY)
=HY+sAPY.
\]

Define positive gain as

\[
G_P(s)
:=
E\|f_0-\mu\|^2
-
E\|f_s-\mu\|^2.
\]

Then exactly

\[
\boxed{
G_P(s)=2sL(P)-s^2D(P),
}
\tag{0.1}
\]

where

\[
\boxed{
L(P)
=
\mu^\top A^2P\mu
-
\sigma^2\operatorname{tr}(AHP),
}
\tag{0.2}
\]

and

\[
\boxed{
D(P)
=
\mu^\top PA^2P\mu
+
\sigma^2\operatorname{tr}(PA^2)
=
\|AP\mu\|^2+\sigma^2\|AP\|_F^2.
}
\tag{0.3}
\]

For every nonzero `P`, `D(P)>0` when `H\prec I`. Hence

\[
\boxed{
 s_P^*
 =
 \min\left\{1,\frac{[L(P)]_+}{D(P)}\right\},
}
\tag{0.4}
\]

and a nonzero amount of the same-response mean helps **iff**

\[
\boxed{L(P)>0.}
\tag{0.5}
\]

Thus the first-order same-response acceptance score is the symmetric matrix

\[
\boxed{
Q
=
\frac12\Bigl[
\mu(A^2\mu)^\top
+(A^2\mu)\mu^\top
\Bigr]
-
\sigma^2AH,
}
\tag{0.6}
\]

because

\[
L(P)=\operatorname{tr}(PQ).
\]

Consequences:

1. a beneficial **rank-one** same-response mean exists iff
   \[
   \boxed{\lambda_{\max}(Q)>0;}
   \]
2. among rank-`r` orthogonal mean subspaces, the largest infinitesimal gain is governed by the top `r` eigenvalues of `Q` via Ky Fan;
3. the negative operator
   \[
   \boxed{\sigma^2AH}
   \]
   is the exact noncommuting same-response covariance tax.

When `P` is a KRR eigenprojector, `(0.2)` reduces exactly to the preceding scalar threshold. So this theorem is a genuine noncommuting extension, not a new notation for the commuting result.

A second exact result gives a closed generalized-eigenvalue threshold.

## `P15-GENEIG-SAMEOBS-25` — NEW / PROVED

Assume for this paragraph that

\[
0\prec H\prec I,
\]

so

\[
J:=AH\succ0.
\]

Set

\[
b=A^2\mu,
\qquad
p=J^{-1/2}\mu,
\qquad
q=J^{-1/2}b.
\]

Then a beneficial rank-one same-response mean direction exists iff

\[
\boxed{
\sigma^2
<
\frac{
\langle p,q\rangle+\|p\|\|q\|
}{2}.
}
\tag{0.7}
\]

This follows because congruence by `J^{-1/2}` turns `(0.6)` into

\[
\frac12(pq^\top+qp^\top)-\sigma^2I,
\]

whose largest eigenvalue is

\[
\frac{
\langle p,q\rangle+\|p\|\|q\|
}{2}.
\]

In one KRR eigenmode this is precisely

\[
\theta^2/\sigma^2>h/(1-h).
\]

For a specified candidate mean subspace `U` with orthonormal basis `V`, the same result holds after restricting

\[
J_U=V^\top J V,
\qquad
\mu_U=V^\top\mu,
\qquad
b_U=V^\top A^2\mu.
\]

This produces an exact low-dimensional certificate for a structured mean family that is rotated relative to the kernel eigenbasis.

The third new theorem makes the fixed-mean/cross-fit/same-response hierarchy explicit.

## `P15-THREELEVEL-MEAN-HIERARCHY-25` — NEW / PROVED

Let `S=S^\top\succeq0` be any deterministic linear smoother; it need not commute with `H`.

Compare three mean constructions:

1. **oracle fixed mean:** `m_det=S\mu`;
2. **cross-fit mean:** `m_cf=SY'`, where `Y'=\mu+\varepsilon'` has independent noise;
3. **same-response mean:** `m_same=SY`.

All are followed by the same residual KRR smoother `H`.

Then their gains over zero-mean KRR satisfy

\[
\boxed{
G_{\rm det}
=
\|A\mu\|^2-\|A(I-S)\mu\|^2,
}
\tag{0.8}
\]

\[
\boxed{
G_{\rm cf}
=
G_{\rm det}
-
\sigma^2\|AS\|_F^2,
}
\tag{0.9}
\]

and

\[
\boxed{
G_{\rm same}
=
G_{\rm cf}
-
2\sigma^2\operatorname{tr}(AHS).
}
\tag{0.10}
\]

Since `AH\succeq0` and `S\succeq0`,

\[
\operatorname{tr}(AHS)\ge0.
\]

Therefore

\[
\boxed{
G_{\rm det}
\ge
G_{\rm cf}
\ge
G_{\rm same}.
}
\tag{0.11}
\]

This is the precise bridge from the elementary fixed-mean spectral identity to actual learned means:

- the fixed deterministic mean pays **no mean-estimation variance**;
- cross-fitting pays the quadratic mean-estimation term `sigma^2||AS||_F^2`;
- same-response fitting pays an additional **linear covariance tax** `2 sigma^2 tr(AHS)`.

The hierarchy requires the natural positive-semidefinite smoother assumption on `S`. For signed/non-self-adjoint response maps the cross term need not have a fixed sign.

A new explicit counterexample makes the noncommuting obstruction concrete.

## `P15-DATADEP-RANKONE-QUADRATIC-25` — NEW / PROVED

Let `H(Y)` be an arbitrary measurable response-dependent smoother, representing a kernel/feature map learned from the same responses, and set

\[
A(Y)=I-H(Y).
\]

For a fixed direction `v`, use the same-response rank-one mean

\[
m_s(Y)=s vv^\top Y.
\]

Define

\[
Z_v(Y)=A(Y)v(v^\top Y),
\qquad
 e_0(Y)=H(Y)Y-\mu.
\]

Without Gaussianity, differentiability, or independence,

\[
\boxed{
G_v^{\rm dep}(s)
=2sL_v^{\rm dep}-s^2D_v^{\rm dep},
}
\tag{0.12}
\]

where

\[
\boxed{
L_v^{\rm dep}
=-E\langle e_0(Y),Z_v(Y)\rangle,
\qquad
D_v^{\rm dep}=E\|Z_v(Y)\|^2.
}
\tag{0.13}
\]

Writing `Y=mu+epsilon` only as an algebraic decomposition,

\[
\boxed{
\begin{aligned}
L_v^{\rm dep}
={}&
E\Big[
(v^\top Y)\langle A(Y)\mu,A(Y)v\rangle
\Big]
\\
&-
E\Big[
(v^\top Y)\langle H(Y)\varepsilon,A(Y)v\rangle
\Big].
\end{aligned}
}
\tag{0.14}
\]

The second expectation is the exact same-response **representation-plus-mean covariance debt**. For fixed `H`, `(0.14)` collapses to `(0.2)`. For response-dependent `H(Y)`, cross-fitting the mean alone does **not** generally remove this term, because the representation/kernel itself still carries response information.

This is the precise source-facing warning for learned features: full independence requires cross-fitting **every response-dependent route**, not just the mean output.

The report also gives a stability transfer for a learned representation close to a fixed reference.

## `P15-REP-OPPERTURB-TRANSFER-25` — NEW / PROVED

Let `H_0` be a fixed reference smoother, `A_0=I-H_0`, and let `H(Y)` be any response-dependent smoother. For the same structured mean `SY`, compare

\[
(m_0,c_0)
=(H_0Y,A_0SY)
\]

to

\[
(m,c)
=(H(Y)Y,[I-H(Y)]SY).
\]

Put

\[
e_m^2=E\|(H-H_0)Y\|^2,
\qquad
 e_c^2=E\|(H-H_0)SY\|^2,
\]

\[
Q_0^2=E\|\mu-m_0-c_0\|^2,
\qquad
C_0^2=E\|c_0\|^2.
\]

Then the inherited exact gain-perturbation identity gives

\[
\boxed{
G_H
\ge
G_{H_0}
-
\left[
2Q_0e_c+2C_0e_m+2e_me_c+e_c^2
\right].
}
\tag{0.15}
\]

No independence or differentiability of `H(Y)` is used.

If almost surely

\[
\|H(Y)-H_0\|_{\rm op}\le\eta,
\qquad
\|S\|_{\rm op}\le1,
\]

and

\[
Y_2=(E\|Y\|^2)^{1/2},
\]

then

\[
\boxed{
G_H
\ge
G_{H_0}
-
2\eta Y_2(Q_0+C_0)
-
3\eta^2Y_2^2.
}
\tag{0.16}
\]

Thus a fixed-representation gain theorem survives same-response representation learning whenever the operator-perturbation debt is smaller than the gain margin. This result remains valid for hard/non-differentiable representation selection; only the prediction/operator distance is used.

The current high-dimensional target is therefore sharper than a generic empirical spectral law:

\[
\boxed{
\text{derive a deterministic equivalent for the restricted generalized gain score }Q
\text{ jointly with the learned mean subspace.}
}
\]

An ordinary Marchenko--Pastur law or a KRR test-risk deterministic equivalent does not by itself encode the response-covariance tax.

# 6. Three-level hierarchy: fixed mean, cross-fit mean, same-response mean

Let `S=S^T\succeq0` be deterministic.

Three conceptually different objects must not be conflated.

## 6.1 Fixed oracle mean

Take

\[
m_{\rm det}=S\mu.
\]

The hybrid is

\[
f_{\rm det}
=H Y+A S\mu.
\]

Its noise is still exactly `H epsilon`; only the bias changes.

Therefore

\[
\boxed{
G_{\rm det}
=
\|A\mu\|^2
-
\|A(I-S)\mu\|^2.
}
\tag{6.1}
\]

This is the finite-dimensional analogue of the elementary fixed-population bias comparison.

## 6.2 Cross-fit mean

Let

\[
Y'=\mu+\varepsilon'
\]

with `epsilon'` independent of `epsilon` and having the same covariance.

Take

\[
m_{\rm cf}=S Y'.
\]

Then

\[
f_{\rm cf}
=HY+ASY'.
\]

The signal/bias is the same as in `(6.1)`, but the mean now contributes independent estimation noise.

Hence

\[
\boxed{
G_{\rm cf}
=
G_{\rm det}
-
\sigma^2\operatorname{tr}(ASS^\top A)
=
G_{\rm det}-\sigma^2\|AS\|_F^2.
}
\tag{6.2}
\]

## 6.3 Same-response mean

Take

\[
m_{\rm same}=SY.
\]

Now the hybrid noise is

\[
(H+AS)\varepsilon.
\]

Expanding its covariance gives

\[
\boxed{
G_{\rm same}
=
G_{\rm cf}
-
2\sigma^2\operatorname{tr}(HS^\top A).
}
\tag{6.3}
\]

For `S=S^T\succeq0`, use cyclicity and the fact that `A` commutes with `H`:

\[
\operatorname{tr}(HS A)
=
\operatorname{tr}(AH S)
\ge0.
\]

Therefore:
