\[
B(\lambda)
=
\sum_j
\left[\frac{\lambda}{\lambda_j+\lambda}\right]^2r_j^2,

The strongest source-facing advance this run is an exact localization of one concrete same-response dependence channel in the released mechanics pipeline.

# 5. Raw OOF KRR channel: exact cross-fit boundary

Fix one OOF fold.

Let:

- `H` be the held-out fold, size `h`;
- `F` be its fitting complement, size `f=N-h`;
- `Y_H in R^(h x q)` and `Y_F in R^(f x q)` be response matrices;
- `P_H=K_HF(K_FF+f lambda I)^(-1)`;
- `b_H=1_H-P_H1_F`.

For any centering vector `mu in R^q`, the centered KRR prediction is

\[
Z_H(\mu)=P_HY_F+b_H\mu^\top.
\]

Define

\[
\mu_F=\frac1f{\bf1}_F^\top Y_F,
\qquad
\mu_H=\frac1h{\bf1}_H^\top Y_H,
\qquad
\mu_P=\frac1N({\bf1}_F^\top Y_F+{\bf1}_H^\top Y_H).
\]

Then

\[
Z_H^{\rm local}=P_HY_F+b_H\mu_F^\top,
\]

while

\[
Z_H^{\rm pool}=P_HY_F+b_H\mu_P^\top.
\]

## `P15-SOURCE-KRR-CHANNEL-CROSSFIT-28` — NEW / PROVED

Conditional on the split/design/kernel quantities and on `Y_F`, the fold-local KRR field is independent of `Y_H` under row-independent responses:

\[
D_{Y_H}Z_H^{\rm local}=0.
\]

By contrast,

\[
\boxed{
D_{Y_H}Z_H^{\rm pool}
=
\frac1N (b_H{\bf1}_H^\top)\otimes I_q.
}
\tag{5.1}
\]

In block form, for every held-out row `i` and every prediction row `j` in the same fold,

\[
\boxed{
\frac{\partial z_j^{\rm pool}}{\partial y_i}
=
\frac{b_j}{N}I_q.
}
\tag{5.2}
\]

In particular the own-row block is

\[
\boxed{
\frac{\partial z_i^{\rm pool}}{\partial y_i}
=
\frac{b_i}{N}I_q.
}
\tag{5.3}
\]

### Proof

Only `mu_P` contains `Y_H`, and

\[
D_{Y_H}\mu_P
=
\frac1N {\bf1}_H^\top\otimes I_q.
\]

Substitution gives (5.1)–(5.3).

For local centering, `mu_F` and the KRR fit use only `Y_F`, hence the derivative is zero.

QED.

### Finite-second-moment covariance consequence

Assume explicitly

\[
Y_i=M_i+\varepsilon_i,
\]

with row-independent centered noise and common output covariance

\[
\operatorname{Cov}(\varepsilon_i)=\Omega.
\]

Conditional on `Y_F` and the design,

\[
\boxed{
\operatorname{Cov}(\varepsilon_i,z_j^{\rm pool})
=
\frac{b_j}{N}\Omega,
}
\tag{5.4}
\]

whereas

\[
\boxed{
\operatorname{Cov}(\varepsilon_i,z_j^{\rm local})=0.
}
\tag{5.5}
\]

No Gaussianity is needed for this covariance identity.

### Interpretation

The historical source phrase “OOF KRR” is correct about **kernel weights** but incomplete as a response-independence statement because pooled centering reintroduces the held-out responses through one fold aggregate.

Fold-local centering repairs this raw KRR-channel dependence exactly.

It does **not** make the final trained refiner cross-fitted, because the refiner parameters are still trained using those rows as supervised targets. That separate optimizer/target pathway remains in the ledger.

# 6. New exact four-fold contrast reduction

The previous run represented the direct pooled-centering dependence by four fold sums, giving an ambient `4q` aggregate dimension.

For the actual **pooled-versus-fold-local centering intervention**, one full q-dimensional direction cancels.

Consider `k` equal folds `H_1,...,H_k`, each of size

\[
h=N/k.
\]

Let

\[
\mu_\ell
=
\frac1h{\bf1}_{H_\ell}^\top Y_{H_\ell}
\]

be fold `ell`'s target mean and

\[
\mu_P
=
\frac1k\sum_{r=1}^k\mu_r
\]

be the pooled mean.

The fitting complement of fold `ell` contains the other `k-1` folds, so

\[
\mu_{F_\ell}
=
\frac1{k-1}\sum_{r\ne\ell}\mu_r.
\]

Define the centering contrast

\[
a_\ell
:=
\mu_P-\mu_{F_\ell}.
\]

A direct simplification gives

\[
\boxed{
a_\ell
=
\frac{\mu_\ell-\mu_P}{k-1}.
}
\tag{6.1}
\]

Consequently

\[
\boxed{
\sum_{\ell=1}^k a_\ell=0.
}
\tag{6.2}
\]

For fold `ell`, the pooled-minus-local OOF field is exactly

\[
\boxed{
\Delta Z_{H_\ell}
:=
Z_{H_\ell}^{\rm pool}-Z_{H_\ell}^{\rm local}
=
b_\ell a_\ell^\top.
}
\tag{6.3}
\]

## `P15-SOURCE-CENTERING-CONTRAST-RANK-28` — NEW / PROVED

Define the centering-intervention subspace

\[
\mathcal S_{\rm ctr}
=
\left\{
Z:
Z_{H_\ell}=b_\ell a_\ell^\top,
\quad
\sum_{\ell=1}^k a_\ell=0
\right\}.
\]

Then

\[
\boxed{
\dim\mathcal S_{\rm ctr}
\le
(k-1)q.
}
\tag{6.4}
\]

For the source,

\[
k=4,
\qquad
q=1681,
\]

hence

\[
\boxed{
\dim\mathcal S_{\rm ctr}
\le
3q
=
5043.
}
\tag{6.5}
\]

As a linear response-to-intervention map in the full `Nq` response space, the rank fraction is therefore at most

\[
\boxed{
\frac{3q}{Nq}
=
\frac3{19000}
\approx1.58\times10^{-4}.
}
\tag{6.6}
\]

This is stronger than the previous `4q` aggregate accounting for the **intervention difference**.

### Matrix proof

Let fold sums be

\[
s_\ell={\bf1}_{H_\ell}^\top Y_{H_\ell}=h\mu_\ell.
\]

Stack `s=(s_1,...,s_k)`.

Then

\[
a
=
\frac1{N(k-1)}
\left[
(kI_k-{\bf1}{\bf1}^\top)\otimes I_q
\right]s.
\]

The matrix

\[
kI_k-{\bf1}{\bf1}^\top
\]

has eigenvalue zero in the common-shift direction `1` and eigenvalue `k` on its orthogonal complement. Its rank is `k-1`.

Multiplication by the fold row factors `b_ell` cannot increase rank. This proves (6.4).

QED.

### Important distinction

- The **direct pooled own-response leakage** can use four fold aggregates and has vectorized rank at most `4q`.
- The **pooled-versus-fold-local centering intervention** is invariant to a common target shift and therefore has rank at most `3q` for four folds.

Both statements are correct; they answer different questions.

\[

\Delta a_r=\frac{\delta}{N},

\tag{7.1}

\boxed{

=-\frac{\delta}{N(k-1)}.

\tag{7.2}

\[
\boxed{

\tag{7.4}

# 9. Frozen/branch-stable downstream transfer on the exact contrast subspace

A global Lipschitz bound for the entire neural pipeline is usually much too pessimistic.

The source centering intervention only moves the OOF field in `S_ctr`.

Let

\[
\Psi_Y: Z\mapsto \text{downstream prediction}
\]

be the complete downstream procedure with responses/targets `Y`, split, random seeds, and all non-OOF inputs held fixed.

`Psi_Y` may include:

- the refiner network;
- optimizer iterations;
- affine stacking;
- residual construction;
- final KRR refitting;

provided we are considering a fixed deterministic execution branch or an otherwise stable finite map.

Define the interpolation

\[
Z_t
=
Z^{\rm local}+t\Delta Z,
\qquad
0\le t\le1,
\]

where

\[
\Delta Z=Z^{\rm pool}-Z^{\rm local}\in\mathcal S_{\rm ctr}.
\]

## `P15-SOURCE-CENTERING-PATH-TRANSFER-28` — NEW / PROVED

If `Psi_Y` is continuously differentiable along this path, then

\[
\boxed{
\Psi_Y(Z^{\rm pool})-
\Psi_Y(Z^{\rm local})
=
\int_0^1
D\Psi_Y(Z_t)[\Delta Z]\,dt.
}
\tag{9.1}
\]

Consequently, defining the **centering-subspace derivative ceiling**

\[
L_{\rm ctr}
:=
\sup_{0\le t\le1}
\left\|
D\Psi_Y(Z_t)|_{\mathcal S_{\rm ctr}}
\right\|_{\rm op},
\]

we have

\[
\boxed{
\|\Psi_Y(Z^{\rm pool})-
\Psi_Y(Z^{\rm local})\|
\le
L_{\rm ctr}
\|Z^{\rm pool}-Z^{\rm local}\|_F.
}
\tag{9.2}
\]

### Why this is materially stronger than a global network norm

The derivative is only required on a subspace of dimension at most

\[
3q=5043
\]

for the source, rather than on all

\[
Nq
=
19,000\times1681
\]

OOF-field coordinates.

Moreover the actual source intervention is one fixed vector `Delta Z` in that subspace. For a retrospective source certificate, the sharpest finite-difference test is simply the directional secant

\[
\frac{
\|\Psi_Y(Z^{\rm pool})-\Psi_Y(Z^{\rm local})\|
}{
\|Z^{\rm pool}-Z^{\rm local}\|_F
},
\]

which the existing paired centering campaign partially observes at the final metric level.

### Hard-selection boundary

If a checkpoint/kernel/stack selector jumps along the path, ordinary differentiability fails. Then (9.1) cannot be used across the jump without a branch/jump term.

\[
M_j=F_\theta(x_j,z_j),
\]

where `z_j in R^q` is the KRR field for row `j` and `theta` is frozen.

For one fold, let

\[
J_j
=
D_zF_\theta(x_j,z_j)
\]

be the `q x q` input-field Jacobian.

Under pooled centering, replacing one held-out response `y_i` by `y_i+delta` changes every KRR-field row in that fold by

\[
\Delta z_j=\frac{b_j}{N}\delta.
\]

Therefore the infinitesimal frozen-refiner response is

\[
\boxed{
D_{y_i}M_j
=
\frac{b_j}{N}J_j.
}
\tag{10.1}
\]

Define

\[
G_H
:=
\frac1h
\sum_{j\in H}
 b_j^2J_j^\top J_j.
\]

Then for a response perturbation direction `delta`, the exact row-RMS infinitesimal feature-path energy is

\[
\boxed{
\frac1h
