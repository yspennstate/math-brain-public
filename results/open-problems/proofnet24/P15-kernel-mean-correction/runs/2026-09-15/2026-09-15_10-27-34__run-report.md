## Executive update

The fixed-population identity

\[
B(\lambda)
=
\sum_j
\left(\frac{\lambda}{\lambda_j+\lambda}\right)^2r_j^2,
\qquad r=f^\star-m,
\]

remains exact and elementary for a **fixed** mean and a **fixed** population kernel operator.  It is not a theorem about a learned mean, learned representation and residual correction fitted from the same observations.

This run adds an exact same-sample theorem under an explicit Gaussian-response benchmark and an exact linear-smoother theorem under only second moments.

The main new identity is:

> if \(Y=\mu+\varepsilon\), \(\varepsilon\sim N(0,\sigma^2I)\), and the full same-sample correction map \(c(Y)\) is Stein-admissible, then for an arbitrary learned mean \(m(Y)\),
> \[
> \boxed{
> E\|m(Y)+c(Y)-\mu\|^2-E\|m(Y)-\mu\|^2
> =E\big[\|c\|^2-2\langle Y-m,c\rangle+2\sigma^2\operatorname{div}c\big].
> }
> \]

The divergence term is the exact **same-sample degrees-of-freedom charge**.  It vanishes for a genuinely coordinate-cross-fitted correction, but it is generally nonzero when the correction is fitted on the same responses.

For a fixed KRR smoother \(H\) and a deterministic mean, the theorem reduces spectrally to

\[
\boxed{
\Gamma
=\sum_j h_j(2-h_j)d_j^2-\sigma^2\sum_j h_j^2,
}
\]

where \(\Gamma\) is baseline risk minus corrected risk and \(d_j\) are residual-signal coefficients.  With

\[
h_j=\frac{\lambda_j}{\lambda_j+\lambda},
\]

the first term is exactly the bias reduction behind the shortlist identity, while the second term is the variance cost missing from that elementary identity.

For a structured **same-response learned linear mean** with eigenvalue \(s_j\) and a commuting correction eigenvalue \(h_j\), the exact gain is

\[
\boxed{
\Gamma
=\sum_j h_j(2-h_j)(1-s_j)^2\theta_j^2
-\sigma^2\sum_j\Big[2s_jh_j(1-s_j)+h_j^2(1-s_j)^2\Big].
}
\]

This is a direct finite-dimensional comparison of corrected versus uncorrected estimators when both use the same observations.

A pure-noise counterexample shows why the extra term is necessary: a learned mean \(m(Y)=aY\), \(0<a<1\), followed by correction \(c(Y)=(1-a)Y\) fits the training responses perfectly and has positive naive residual gain on every nonzero sample, yet its true risk is strictly worse than that of the mean alone.

This theorem is **conditional for the source application** because the accessible structural-mechanics manuscript does not state an additive Gaussian response-noise model.  It is a rigorous benchmark and a route for noisy/operator-observation variants, not a claimed theorem for the deterministic simulator data.  Fresh-X population generalization still requires the already-developed paired-audit / leave-one-out / replacement-stability transfer.

# 5. New theorem — exact same-sample Gaussian correction identity

Consider a fixed-design Gaussian sequence model

\[
\boxed{
Y=\mu+\varepsilon,
\qquad
\varepsilon\sim N(0,\sigma^2I_N).
}
\tag{S0}

Here \(N\) may flatten all training output coordinates.  Let

\[
m:\mathbb R^N\to\mathbb R^N
\]

be an arbitrary learned mean map and let

\[
c:\mathbb R^N\to\mathbb R^N
\]

be the **full learned correction map**.  Both may use exactly the same observations \(Y\).

Assume only enough integrability for the risks below and assume \(c\) satisfies a standard Stein regularity condition: for example each coordinate is continuous and almost differentiable with integrable diagonal derivative, or a weakly differentiable version for which Stein's identity is valid.

No differentiability of \(m\) is needed for the main identity.

Define

\[
R_0
=
E\|m(Y)-\mu\|^2,
\]

\[
R_1
=
E\|m(Y)+c(Y)-\mu\|^2.
\]

## `P15-SURE-GAIN-19` — NEW / PROVED

\[
\boxed{
R_1-R_0
=
E\left[
\|c(Y)\|^2
-2\langle Y-m(Y),c(Y)\rangle
+2\sigma^2\operatorname{div}c(Y)
\right].
}
\tag{S1}

Equivalently, with the naive same-sample residual gain

\[
G_{\rm res}(Y)
=
2\langle Y-m(Y),c(Y)\rangle-\|c(Y)\|^2,
\]

the **true expected correction gain** is

\[
\boxed{
R_0-R_1
=
E G_{\rm res}(Y)
-
2\sigma^2E\operatorname{div}c(Y).
}
\tag{S2}

### Proof

Expand:

\[
R_1-R_0
=
E\left[
2\langle m(Y)-\mu,c(Y)\rangle
+
\|c(Y)\|^2
\right].
\]

Let

\[
r(Y)=Y-m(Y).
\]

Since

\[
m(Y)-\mu
=
\varepsilon-r(Y),
\]

we obtain

\[
R_1-R_0
=
E\left[
\|c\|^2
-2\langle r,c\rangle
+2\langle\varepsilon,c(Y)\rangle
\right].
\]

Stein's identity gives

\[
E\langle\varepsilon,c(Y)\rangle
=
\sigma^2E\operatorname{div}c(Y).
\]

Substitute.  QED.

### Interpretation

The elementary residual training gain

\[
2\langle Y-m,c\rangle-\|c\|^2
\]

is **optimistic** when the correction uses the same noisy responses.  The exact charge is

\[
2\sigma^2\operatorname{div}c.
\]

This is a same-sample theorem: the mean and correction need not be independent, and the mean can itself be an arbitrary nonlinear learned estimator of \(Y\).

### Known-covariance extension

If

\[
\varepsilon\sim N(0,\Sigma),
\]

the same proof gives

\[
\boxed{
R_1-R_0
=
E\left[
\|c\|^2
-2\langle Y-m,c\rangle
+2\operatorname{tr}(\Sigma J_c(Y))
\right].
}
\tag{S3}

provided the multivariate Stein identity is valid for \(c\).

# 6. Cross-fitting benchmark — the optimism charge disappears

The Gaussian assumption is unnecessary for the clean cross-fitted benchmark.

Let the response vector be block-indexed by training observation,

\[
Y_i=\mu_i+\varepsilon_i,
\]

where the noise blocks \(\varepsilon_i\) are independent, centered and square-integrable.

Let \(m(Y)\) be arbitrary.  Suppose the correction coordinate/block \(c_i\) is measurable with respect to all data **except the response block \(Y_i\)**.  Crucially, every stage that could leak \(Y_i\) into \(c_i\)—mean fitting used to make correction labels, representation learning, kernel selection, correction fitting—must obey the exclusion.

## `P15-CROSSFIT-GAIN-19` — NEW / PROVED

\[
\boxed{
E\|m+c-\mu\|^2-E\|m-\mu\|^2
=
E\left[
\|c\|^2-2\langle Y-m,c\rangle
\right].
}
\tag{CF1}

### Proof

The earlier expansion gives

\[
R_1-R_0
=
E\left[
\|c\|^2-2\langle Y-m,c\rangle
+2\sum_i\langle\varepsilon_i,c_i\rangle
\right].
\]

By construction \(c_i\) is measurable with respect to variables independent of the centered \(\varepsilon_i\), so

\[
E\langle\varepsilon_i,c_i\rangle=0.
\]

Sum over \(i\).  QED.

### Meaning

Cross-fitting is not automatically beneficial, but it removes the own-response optimism term.  The gain sign is still

\[
E[2\langle Y-m,c\rangle-\|c\|^2]>0.
\]

This formalizes cross-fitting as a benchmark rather than a monotonic-improvement theorem.

# 7. Fixed and learned linear smoothers — exact finite-dimensional risk comparison

The next theorem does not need Gaussian noise, only a conditional second moment.

Assume

\[
Y=\mu+\varepsilon,
\qquad
E\varepsilon=0,
\qquad
E\varepsilon\varepsilon^\top=\sigma^2I_N.
\]

Let the same-response structured mean be

\[
m(Y)=SY
\]

for a deterministic matrix \(S\) conditional on the design/features, and let the correction be

\[
c(Y)=H(I-S)Y,
\]

where \(H\) is another deterministic linear smoother conditional on the design/features.

Define

\[
B=I-S,
\qquad
A=S+HB.
\]

The final estimator is \(AY\).

## `P15-LINEAR-SMOOTHER-GAIN-19` — NEW / PROVED

The risk gain of the corrected estimator over the learned mean is exactly

\[
\boxed{
\Gamma
:=
E\|SY-\mu\|^2
-
E\|AY-\mu\|^2
}
\]

with

\[
\boxed{
\Gamma
=
\|B\mu\|^2
-
\|(I-H)B\mu\|^2
-
\sigma^2\left[
2\operatorname{tr}(HBS^\top)
+
\operatorname{tr}(HBB^\top H^\top)
\right].
}
\tag{L1}

### Proof

The baseline bias is

\[
(S-I)\mu=-B\mu,
\]

and the final bias is

\[
(A-I)\mu
=-(I-H)B\mu.
\]

The baseline variance is

\[
\sigma^2\operatorname{tr}(SS^\top),
\]

and the final variance is

\[
\sigma^2\operatorname{tr}(AA^\top).
\]

Since

\[
A=S+HB,
\]

\[
\operatorname{tr}(AA^\top-SS^\top)
=
2\operatorname{tr}(HBS^\top)
+
\operatorname{tr}(HBB^\top H^\top).
\]

Subtract final risk from baseline risk.  QED.

## Commuting spectral corollary

Suppose \(S,H\) are symmetric and commute.  In their common eigenbasis let

\[
S\psi_j=s_j\psi_j,
\qquad
H\psi_j=h_j\psi_j,
\qquad
\mu=\sum_j\theta_j\psi_j.
\]

Then

\[
\boxed{
\Gamma
=
\sum_j
h_j(2-h_j)(1-s_j)^2\theta_j^2
-
\sigma^2
\sum_j
\left[
2s_jh_j(1-s_j)
+h_j^2(1-s_j)^2
\right].
}
\tag{L2}

For \(0\le s_j,h_j\le1\), the first sum is bias reduction and the second is the exact same-response variance inflation.

This is a finite-dimensional theorem for a structured mean and correction using the **same responses**.

# 8. Exact connection to the population eigenbasis identity and source normalization

First take a deterministic fixed mean \(m_0\).  Translate the problem to residual responses

\[
Y-m_0=d+\varepsilon,
\qquad
d=\mu-m_0.
\]

This is the \(S=0\) case of `(L2)`:

\[
\boxed{
\Gamma
=
\sum_jh_j(2-h_j)d_j^2
-
\sigma^2\sum_jh_j^2.
}
\tag{K1}

For population KRR,

\[
h_j
=
\frac{\lambda_j}{\lambda_j+\lambda},
\qquad
1-h_j
=
\frac{\lambda}{\lambda_j+\lambda}.
\]

Therefore the corrected squared bias is

\[
\sum_j(1-h_j)^2d_j^2
=
\boxed{
\sum_j
\left[
\frac{\lambda}{\lambda_j+\lambda}
\right]^2d_j^2,
}
\]

which is exactly the shortlist identity.

But the complete noisy risk also contains

\[
\boxed{
\sigma^2\sum_jh_j^2.
}
\]

Thus the population bias identity explains only one side of the gain comparison.

The source uses

\[
(K+n\lambda I)^{-1}.
\]

The training-point KRR hat matrix is

\[
H_K
=K(K+n\lambda I)^{-1}.

\[

# 9. Learned representation / data-dependent kernel derivative debt

The SURE theorem also identifies the additional debt created when the correction smoother itself depends smoothly on the responses.

Let

\[
r(Y)=Y-m(Y),
\qquad
c(Y)=H(Y)r(Y).
\]

Assume the required derivatives exist and are Stein-integrable.  Let

\[
(J_m)_{ji}=\frac{\partial m_j}{\partial y_i},
\]

and define

\[
(d_H)_j
=
\sum_i
\frac{\partial H_{ij}}{\partial y_i}.
\]

## `P15-DATADEP-SMOOTHER-DIV-19` — NEW / PROVED

\[
\boxed{
\operatorname{div}c
=
\operatorname{tr}\big(H(I-J_m)\big)
+
\langle d_H,r\rangle.
}
\tag{D1}

### Proof

For

\[
c_i=\sum_jH_{ij}r_j,
\]

\[
\frac{\partial c_i}{\partial y_i}
=
\sum_j
\frac{\partial H_{ij}}{\partial y_i}r_j
+
\sum_jH_{ij}
\left(
\delta_{ij}
-
\frac{\partial m_j}{\partial y_i}
\right).
\]

Sum over \(i\).  QED.

Thus the same-sample correction tax contains two distinct channels:

1. the residual-response sensitivity through \(I-J_m\);
2. the learned-kernel/representation sensitivity through \(d_H\).

For fixed \(H\), the second term vanishes.

This is a rigorous formulation of the source concern that mean, representation and correction are estimated from the same observations.

# 10. Counterexample: perfect training residual fit can worsen true risk

## `P15-SURE-OVERFIT-CE-19` — NEW / PROVED

Take pure noise

\[
\mu=0,
\qquad
Y=\varepsilon,
\qquad
E\|Y\|^2=N\sigma^2.
\]

Fix

\[
0<a<1.
\]

Use the same responses to define the learned mean

\[
m(Y)=aY
\]

and correction

\[
c(Y)=(1-a)Y.
\]

Then

\[
m(Y)+c(Y)=Y,
\]

so the corrected estimator interpolates the noisy training responses perfectly.

The naive residual gain is

\[
2\langle Y-m,c\rangle-\|c\|^2
=(1-a)^2\|Y\|^2>0
\]

for every nonzero realization.

But the true risks are

\[
R_0=a^2N\sigma^2,
\qquad
R_1=N\sigma^2,
\]

so

\[
\boxed{
R_1-R_0
=(1-a^2)N\sigma^2>0.
}
\]

The correction is strictly harmful.

The SURE charge is

\[
2\sigma^2\operatorname{div}c
=2\sigma^2(1-a)N,
\]

and exactly reconciles the apparently positive training residual gain with the negative true gain.

Therefore:

\[
\boxed{
\text{training residual improvement, even perfect interpolation, does not imply same-sample risk improvement.}
}
\]

This counterexample has both the mean and correction fitted from the same response vector.

# 11. Computational divergence audit

For a differentiable correction map, the divergence can be estimated without forming its full Jacobian.

Let

\[
J_c(y)=D c(y),
\]

and let

\[
z\sim N(0,I_N)
\]

independently of the data.

## `P15-HUTCHINSON-DIV-19` — NEW / PROVED

Conditionally on \(y\),

\[
\boxed{
E_z[z^\top J_c(y)z]
=
\operatorname{tr}J_c(y).
}
\tag{H1}

Moreover,

\[
\boxed{
\operatorname{Var}_z(z^\top J_cz)
=
2\|\operatorname{sym}J_c\|_F^2.
}
\tag{H2}

For \(M\) independent Gaussian probes the average has variance

\[
\boxed{
\frac{2}{M}\|\operatorname{sym}J_c\|_F^2.
}
\tag{H3}

### Proof

Since

\[
z^\top J_cz
=z^\top\operatorname{sym}(J_c)z,
\]

the standard Gaussian quadratic-form identities give expectation \(\operatorname{tr}J_c\) and variance \(2\|\operatorname{sym}J_c\|_F^2\).  QED.

This makes the SURE charge computationally approachable through Jacobian-vector products / algorithmic differentiation for a smooth fixed branch.

It does **not** by itself give a high-probability risk certificate from one noisy response vector.  That requires an additional SURE-variance theorem or an independent audit block.

# 12. Hard selection and Stein regularity — primary-literature audit

The imported Gaussian integration-by-parts step was checked against the current literature record.

- C. Stein, **Estimation of the mean of a multivariate normal distribution**, *Annals of Statistics* 9 (1981), 1135--1151, is the classical source.
- Bellec and Zhang, **Second order Stein: SURE for SURE and other applications in high-dimensional inference**, arXiv:1811.04121, explicitly states Stein's formula for functions with integrable gradient and develops SURE under square-integrable gradient conditions.
- Ryan Tibshirani, **Degrees of Freedom and Model Search** (2015), states the standard continuity/almost-differentiability route to Stein's degrees-of-freedom formula and explicitly explains that discontinuous procedures such as hard thresholding fall outside the ordinary formula and require an extension/search-degrees-of-freedom term.

Therefore `P15-SURE-GAIN-19` is **not** silently applied through the source's hard checkpoint/kernel/ridge selection.

Valid routes are:

1. condition on a fixed branch and prove the branch does not switch;
2. use the existing P15 soft-selector theorem so the selected map is differentiable when the candidates are;
3. use an extended Stein theorem with the required jump/boundary terms;
4. avoid SURE and retain the already-proved honest paired-audit / recycle-transfer theorem.

\le
L\sum_{d=1}^{L-1}P_d.
\]

This proves the first displayed inequality with the stated constant.

For each lag,

\[
P_d-N_d
=c_{T-d,d}-c_{1,d},
\]

and both endpoint correlations lie in \([0,1]\), so

\[
N_d\ge P_d-1.
\]

Summing over \(d=1,\ldots,L-1\) gives

\[
\sum_dN_d
\ge
\sum_dP_d-(L-1),
\]

and the first inequality gives the second.

No independence assumption is used; the argument is deterministic and preserves reuse of the same matrix.

### Verdict

\texttt{P16-SYNC-RESET-DEBT-21: PROVED / PASS.}
}
\]

The constant \(L\) is conservative—one may keep \(L-d\) witness multiplicities—but the stated result is correct.

The fixed-population eigenbasis identity explains a **bias** effect and remains correct:

\[
B(\lambda)
=
\sum_j
\left[
\frac{\lambda}{\lambda_j+\lambda}
\right]^2r_j^2.

This run proves exactly what that identity misses in a noisy same-sample setting.

For an arbitrary learned mean and a correction trained on the same Gaussian responses,

\[
\boxed{

=
\text{residual training gain}
-
2\sigma^2E\operatorname{div}c.
}
\]

For fixed KRR this becomes

\[
\boxed{
\text{bias reduction}
-
\text{variance inflation}.
}
\]

For a same-response structured linear mean and KRR correction, the complete eigenmode comparison is `(L2)`.

The new pure-noise counterexample proves that even perfect residual interpolation can be harmful when the mean and correction share the observations.

Cross-fitting removes the own-response optimism term exactly, but it still does not guarantee positive gain.

The source application remains conditional because additive Gaussian label noise is not an accessible source hypothesis.  No such hypothesis is invented.

The live P15 theorem architecture is now sharper:

\[

or, for the deterministic source pipeline,

Both routes preserve the central requirement: mean, representation and correction may use the same observations, but their dependence must be paid for explicitly rather than silently removed.
