# Executive update

The fixed-population identity

\[
B(\lambda)
=
\sum_j
\left(\frac{\lambda}{\lambda_j+\lambda}\right)^2r_j^2,
\qquad r=f^\star-m,
\]

remains exact and elementary for a **fixed** mean and a **fixed** population kernel operator. It is not a theorem about a learned mean, learned representation and residual correction fitted from the same observations.

The preceding P15 run proved an exact fixed-design Gaussian same-sample identity:

\[
E\|m(Y)+c(Y)-\mu\|^2-E\|m(Y)-\mu\|^2
=
E\big[\|c\|^2-2\langle Y-m,c\rangle+2\sigma^2\operatorname{div}c\big],
\]

so the naive same-sample residual gain must pay a degrees-of-freedom charge. It also proved the exact same-response linear-smoother gain, including the variance inflation missing from the elementary population bias identity.

The principal open item named there was `P15-SURE-POPULATION-BRIDGE-20`: convert the fixed-training-design identity into a **fresh-input population generalization theorem** under explicit same-observation dependence.

This run closes that theorem under a clean random-design Gaussian-response benchmark and proves a parallel cross-fitted leave-one-out theorem that does not require Gaussian noise.

The main exact identity is:

> replace training observation `i` by an independent copy, but evaluate both the original and replaced learned pipelines at the **old** input `X_i`. Then the fresh-input population risk difference equals the expected fixed-design SURE quantity plus the expected replace-one change of the paired corrected-minus-baseline loss at those old inputs.

The replacement term is then bounded by the same prediction-space quantities developed earlier in P15.

Thus, if

\[
\widehat\Delta_{\rm SURE}
=
\frac1n
\left[
\|c_S(X)\|^2
-2\langle Y-m_S(X),c_S(X)\rangle
+2\sigma^2\operatorname{div}_Y c_S(X)
\right],
\]

then

\[
\boxed{
\Delta_{\rm pop}
:=
E\big[R_{\rm pop}(m_S+c_S)-R_{\rm pop}(m_S)\big]
=
E\widehat\Delta_{\rm SURE}
+
\mathfrak G_n,
}
\]

where `\mathfrak G_n` is an exact random-design replacement/generalization term. No independence between the mean, representation and correction is inserted.

Moreover, writing `M_rep` and `C_rep` for the old-input RMS replace-one changes of the learned mean and correction,

\[
\boxed{
|\mathfrak G_n|
\le
2Q\,C_{\rm rep}
+2C\,M_{\rm rep}
+2M_{\rm rep}C_{\rm rep}
+C_{\rm rep}^2,
}
\]

where `Q` is the RMS corrected target residual on the training-design points and `C` is the RMS correction norm.

Therefore the same-sample correction improves **fresh-input population squared risk** whenever

\[
\boxed{
E\widehat\Delta_{\rm SURE}
+
2Q\,C_{\rm rep}
+2C\,M_{\rm rep}
+2M_{\rm rep}C_{\rm rep}
+C_{\rm rep}^2
<0.
}
\]

This is `P15-SURE-REPLACEONE-BRIDGE-20`.

A parallel theorem, `P15-LOO-POPULATION-GAIN-20`, shows that a genuinely leave-one-out/cross-fitted paired residual-gain statistic is an **unbiased estimator of the fresh-input population gain for the size-`n-1` pipeline** under only centered independent response noise (including the deterministic/noiseless case). Full-sample gain is then obtained from the same prediction-space stability debt.

A new counterexample proves that no fixed-training-design theorem can imply fresh-input generalization without design/algorithm stability: a correction can be perfect on every training input yet deliberately wrong almost everywhere off sample.

The source structural-mechanics application remains conditional for the SURE route because the accessible manuscript does not posit additive Gaussian response noise. For that deterministic simulator source, the cross-fitted/paired-audit plus stability route remains the correct source-facing theorem architecture.

# 5. Random-design model for the population bridge

Let

\[
Z_i=(X_i,Y_i),
\qquad i=1,\ldots,n,
\]

be iid.

Assume the regression model

\[
\boxed{
Y_i=\mu(X_i)+\varepsilon_i,
\qquad
\varepsilon_i\mid X_{1:n}\stackrel{\rm iid}{\sim}N(0,\sigma^2I_q).
}
\tag{RD0}

Here `q` is the output dimension. Conditional on the design `X=(X_1,...,X_n)`, flatten all `nq` response coordinates when applying Stein's identity.

Let the learning algorithm output

\[
m_S:\mathcal X\to\mathbb R^q,
\qquad
c_S:\mathcal X\to\mathbb R^q.
\]

The mean, representation/kernel, hyperparameters and correction may all use the same full sample `S`.

Conditional on `X`, assume only that the full training-point correction map

\[
Y\mapsto
C_X(Y)
:=
(c_S(X_1),\ldots,c_S(X_n))
\in\mathbb R^{nq}
\]

satisfies a valid Stein regularity condition and the required integrability. The baseline mean map need not be differentiable for the identity below.

Hard discontinuous checkpoint/kernel selection is **not** silently included. Valid routes remain:

- freeze a branch by a margin theorem;
- use soft selection;
- use an extended Stein formula with jump/search terms;
- or use the distribution-free LOO/paired-audit route in Sections 9--10.

Define the target-function squared-risk difference at a point `x`:

\[
\boxed{
L_S(x)
=
\|m_S(x)+c_S(x)-\mu(x)\|^2
-
\|m_S(x)-\mu(x)\|^2.
}
\tag{RD1}

The fresh-input population difference is

\[
\boxed{
\Delta_{\rm pop}
=
E_{S,X_0}L_S(X_0),
}
\tag{RD2}

where `X_0` is an independent fresh input.

Negative `\Delta_pop` means that correction improves population risk.

# 6. Fixed-design SURE quantity

Define the training-design SURE statistic

\[
\boxed{
\widehat\Delta_{\rm SURE}(S)
=
\frac1n
\left[
\sum_{i=1}^n\|c_S(X_i)\|^2
-2\sum_{i=1}^n
\langle Y_i-m_S(X_i),c_S(X_i)\rangle
+2\sigma^2\operatorname{div}_Y C_X(Y)
\right].
}
\tag{S0}

By `P15-SURE-GAIN-19`, conditional on the design,

\[
\boxed{
E[\widehat\Delta_{\rm SURE}\mid X]
=
E\left[
\frac1n\sum_{i=1}^nL_S(X_i)
\middle|X
\right].
}
\tag{S1}

Thus `E \widehat Delta_SURE` is the expected **training-design target-risk difference**.

The only remaining issue is whether training-design evaluation represents fresh-input evaluation for this data-dependent pipeline.

# 7. Exact replace-one population bridge

Let

\[
Z_i'=(X_i',Y_i')
\]

be an independent copy of `Z_i`, independent of everything else, and define

\[
S^{(i)}
=
(Z_1,\ldots,Z_{i-1},Z_i',Z_{i+1},\ldots,Z_n).
\]

The key observation is:

- `S^(i)` has exactly the same law as `S`;
- the old input `X_i` is independent of `S^(i)`.

Therefore, for every `i`,

\[
E L_{S^{(i)}}(X_i)
=
E L_S(X_0)
=
\Delta_{\rm pop}.
\tag{B0}

## `P15-SURE-REPLACEONE-BRIDGE-20` — NEW / PROVED

Define

\[
\boxed{
\mathfrak G_n
=
\frac1n
\sum_{i=1}^n
E\left[
L_{S^{(i)}}(X_i)-L_S(X_i)
\right].
}
\tag{B1}

Then

\[
\boxed{
\Delta_{\rm pop}
=
E\widehat\Delta_{\rm SURE}
+
\mathfrak G_n.
}
\tag{B2}

### Proof

By `(B0)`,

\[
\Delta_{\rm pop}
=
\frac1n\sum_iE L_{S^{(i)}}(X_i).
\]

Add and subtract

\[
\frac1n\sum_iE L_S(X_i).
\]

By `(S1)` after averaging over `X`,

\[
\frac1n\sum_iE L_S(X_i)
=
E\widehat\Delta_{\rm SURE}.
\]

The remainder is exactly `(B1)`. QED.

### Meaning

The random-design population gap is not an unspecified “generalization error.” It is an exact **replace-one old-input paired-loss difference**.

This is the natural random-design companion to the fixed-design same-response degrees-of-freedom identity.

# 8. Prediction-space bound for the design/replacement debt

For each replacement corner define, at the **old** input `X_i`,

\[
u_i
=
m_{S^{(i)}}(X_i)-m_S(X_i),
\tag{D0}
\]

\[
v_i
=
c_{S^{(i)}}(X_i)-c_S(X_i).
\tag{D1}
\]

Put

\[
q_i
=
\mu(X_i)-m_S(X_i)-c_S(X_i),
\tag{D2}
\]

\[
c_i=c_S(X_i).
\tag{D3}
\]

The exact quadratic algebra gives

\[
\boxed{
\begin{aligned}
L_{S^{(i)}}(X_i)-L_S(X_i)
={}&
-2\langle q_i,v_i\rangle
+2\langle u_i,c_i\rangle
\\
&+2\langle u_i,v_i\rangle
+\|v_i\|^2.
\end{aligned}
}
\tag{D4}

This is the same coupled gain-perturbation identity proved earlier for audit recycling, now applied to a replace-one/random-design bridge.

Define the RMS quantities

\[
Q_n^2
=
E\frac1n\sum_i\|q_i\|^2,
\qquad
C_n^2
=
E\frac1n\sum_i\|c_i\|^2,
\tag{D5}
\]

\[
M_{n,\rm rep@old}^2
=
E\frac1n\sum_i\|u_i\|^2,
\tag{D6}
\]

\[
C_{n,\rm rep@old}^2
=
E\frac1n\sum_i\|v_i\|^2.
\tag{D7}
\]

## `P15-POPULATION-STABILITY-DEBT-20` — NEW / PROVED

\[
\boxed{
|\mathfrak G_n|
\le
2Q_nC_{n,\rm rep@old}
+2C_nM_{n,\rm rep@old}
+2M_{n,\rm rep@old}C_{n,\rm rep@old}
+C_{n,\rm rep@old}^2.
}
\tag{D8}

### Proof

Average `(D4)` over `i` and all randomness. Apply Cauchy--Schwarz in the product probability/normalized-index space to each bilinear term. The final `v_i` square averages exactly to `C_{n,rep@old}^2`. QED.

Combining `(B2)` and `(D8)` gives:

## `P15-SURE-POPULATION-BRIDGE-20` — NEW / PROVED

\[
\boxed{
\begin{aligned}
\Delta_{\rm pop}
\le{}&
E\widehat\Delta_{\rm SURE}
+2Q_nC_{n,\rm rep@old}
+2C_nM_{n,\rm rep@old}
\\
&+2M_{n,\rm rep@old}C_{n,\rm rep@old}
+C_{n,\rm rep@old}^2.
\end{aligned}
}
\tag{D9}

Therefore the same-observation learned correction strictly improves fresh-input population squared risk whenever the right-hand side of `(D9)` is negative.

No independence among learned mean, learned representation and learned correction is assumed.

The dependence is paid in two explicit currencies:

1. **same-response optimism:** the Stein divergence already inside `E Delta_SURE`;
2. **random-design generalization:** the replace-one prediction debt in `(D8)`.

This is the clean theorem targeted by the previous P15 run.

# 9. Cross-fitting / leave-one-out benchmark without Gaussian noise

The source structural-mechanics outputs appear to be deterministic simulator outputs, so an exact distribution-free benchmark is important.

Assume only

\[
Y_i=\mu(X_i)+\varepsilon_i,
\qquad
E[\varepsilon_i\mid X_i]=0,
\]

with independent observations and finite second moments. The noiseless case `epsilon_i=0` is included.

For each `i`, train the **entire** baseline/correction pipeline on

\[
S^{-i}.
\]

This exclusion must cover every path by which `Y_i` could enter the correction:

- mean fitting;
- representation learning;
- residual-label formation;
- kernel/ridge/checkpoint selection;
- correction fitting.

Define the held-out paired squared-loss difference

\[
\boxed{
D_i^{\rm loo}
=
\|Y_i-m_{S^{-i}}(X_i)-c_{S^{-i}}(X_i)\|^2
-
\|Y_i-m_{S^{-i}}(X_i)\|^2.
}
\tag{L0}

Let

\[
\Delta_{n-1}^{\rm pop}
=
E_{T,X_0}
\left[
\|m_T(X_0)+c_T(X_0)-\mu(X_0)\|^2
-
\|m_T(X_0)-\mu(X_0)\|^2
\right],
\]

where `T` is an iid sample of size `n-1`.

## `P15-LOO-POPULATION-GAIN-20` — NEW / PROVED

\[
\boxed{
E\left[
\frac1n\sum_{i=1}^nD_i^{\rm loo}
\right]
=
\Delta_{n-1}^{\rm pop}.
}
\tag{L1}

### Proof

Condition on `S^{-i}` and `X_i`. The two fitted predictors are fixed and independent of the centered held-out noise `epsilon_i`. Expanding the two squared losses, the common noise variance cancels and the cross term has conditional mean zero. Therefore

\[
E[D_i^{\rm loo}\mid S^{-i},X_i]
=
L_{S^{-i}}(X_i).
\]

Since `X_i` is independent of `S^{-i}` and has the fresh-input law,

\[
E L_{S^{-i}}(X_i)
=
\Delta_{n-1}^{\rm pop}.
\]

Average over `i`. QED.

### Full-sample transfer

The exact prior gain-perturbation theorem gives, for a uniformly random `I`,

\[
\Gamma(m_S,c_S)
\ge
\Gamma(m_{S^{-I}},c_{S^{-I}})
-
\left[
2Q_-e_c+2C_-e_m+2e_me_c+e_c^2
\right],
\]

with fresh-input prediction distances between the size-`n` and size-`n-1` pipelines. After expectation, a positive leave-one-out gain transfers to the full-sample pipeline whenever it dominates this stability debt.

This is the source-faithful cross-fitting benchmark: no Gaussian response model is needed, but the pipeline exclusion must be genuine.

# 10. Counterexample — fixed-training-design gain need not generalize

## `P15-TRAIN-DESIGN-POPULATION-CE-20` — NEW / PROVED

Let

\[
X\sim\operatorname{Unif}[0,1],
\qquad
\mu(x)\equiv1,
\]

with deterministic/noiseless responses.

Use baseline

\[
m_S(x)\equiv0.
\]

For a training sample with distinct inputs, define the correction

\[
\boxed{
c_S(x)=
\begin{cases}
1,&x\in\{X_1,\ldots,X_n\},\\
-1,&\text{otherwise}.
\end{cases}}
\tag{CE1}

On every training input,

\[
m_S(X_i)+c_S(X_i)=1=\mu(X_i),
\]

so the corrected training-design target risk is zero while the baseline risk is one. The empirical/fixed-design correction gain is therefore exactly `+1` per point.

For an independent fresh input `X_0`, continuity of the input law gives

\[
P\{X_0\in\{X_1,\ldots,X_n\}\}=0.
\]

Thus almost surely

\[
c_S(X_0)=-1,
\]

and the corrected fresh-input squared error is

\[
(-1-1)^2=4,
\]

whereas the baseline error is `1`.

Hence

\[
\boxed{
\Delta_{\rm training}=-1,
\qquad
\Delta_{\rm pop}=+3.
}
\]

The correction is perfect on the training design and strictly harmful on the population.

The replace-one bridge detects the pathology sharply. Replacing observation `i` removes the old point `X_i` from the memorized set almost surely, so

\[
c_{S^{(i)}}(X_i)-c_S(X_i)=-2.
\]

The old-input replacement stability debt is order one, not small.

Therefore:

\[
\boxed{
\text{fixed-design SURE/training gain cannot imply fresh-input population gain without design/algorithm stability.}
}

This counterexample is noiseless and requires no Gaussian/Stein caveat.

# 11. KRR / learned-representation specialization

The population bridge is algorithm-agnostic, but the existing P15 KRR modules make it concrete.

For a fixed kernel at positive ridge, the source-correct empirical smoother is

\[
H_X=K(K+n\lambda I)^{-1}.
\]

If the baseline mean is deterministic conditional on the design, the training-point correction is linear in the residual responses and

\[
\operatorname{div}_Y C_X(Y)=q\operatorname{tr}(H_X)
\]

for `q` independent output coordinates using the same scalar smoother.

Thus the fixed-design SURE term becomes an explicit residual-fit-minus-effective-dimension criterion.

If the mean or representation is learned from the same responses, the prior theorem

\[
