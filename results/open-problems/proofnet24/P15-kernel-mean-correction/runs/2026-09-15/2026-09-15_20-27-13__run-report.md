## `P15-SOURCE-CENTERING-SINGULAR-29` — PROVED

For the historical four-fold pooled-centering defect in the released mechanics pipeline, the preceding run localized the pooled-versus-fold-local OOF intervention to the fold-contrast subspace. This run computes the **entire nonzero singular spectrum** of that raw response-to-intervention map.

For `k` equal folds of size `h=N/k`, write

\[
b_\ell
=
\mathbf1_{H_\ell}
-
K_{H_\ell F_\ell}
(K_{F_\ell F_\ell}+|F_\ell|\lambda I)^{-1}
\mathbf1_{F_\ell},
\]

\[
d_\ell=\|b_\ell\|_2^2,
\qquad
D=\operatorname{diag}(d_1,\ldots,d_k),
\qquad
P=I_k-\frac1k\mathbf1\mathbf1^T.
\]

Let `T_ctr` map the full response array to the pooled-minus-fold-local OOF KRR field, with all kernel matrices fixed. Then the nonzero **squared** singular values in one output coordinate are exactly the nonzero eigenvalues of

\[
\boxed{
\frac{1}{h(k-1)^2}PDP.
}
\]

For `q` output coordinates each singular value is repeated `q` times. Therefore, with

\[
\rho_\ell=\frac{\|b_\ell\|_2}{\sqrt h},
\]

\[
\boxed{
\|T_{\rm ctr}\|_{\rm op}
=
\frac1{k-1}
\sqrt{
\lambda_{\max}
\left(
P\,\operatorname{diag}(\rho_1^2,\ldots,\rho_k^2)\,P
\right)
}.
}
\]

The preceding bound

\[
\|T_{\rm ctr}\|_{\rm op}
\le
\frac{\max_\ell\rho_\ell}{k-1}
\]

is thus a direct corollary, not the sharp object.

For the actual source,

\[
k=4,
\qquad
h=4750,
\qquad
N=19000,
\qquad
q=1681,
\]

so only the four scalars `S2_l=||b_l||^2` are needed to determine the exact raw-channel operator norm from a `4 x 4` eigenproblem.

## `P15-KRR-MEAN-PERTURB-FILTER-29` — PROVED

For a fixed Gram matrix and ridge, residual KRR exactly filters any change in the mean on the training design. Put

\[
H=K(K+n\lambda I)^{-1},
\qquad
A=I-H=n\lambda(K+n\lambda I)^{-1}.
\]

If training responses `Y` are fixed and a mean vector `M` is changed to `M+D`, while the residual KRR correction is refit consistently, then the corrected fitted values change by

\[
\boxed{
F(M+D)-F(M)=AD.
}
\]

Hence

\[
\boxed{
\|F(M+D)-F(M)\|_F\le\|D\|_F,
}
\]

and in a Gram eigenmode with eigenvalue `kappa_j`, the mean perturbation is attenuated by exactly

\[
\boxed{
\frac{n\lambda}{\kappa_j+n\lambda}.
}
\]

This is a genuine same-data deterministic statement; it requires no independence between a learned mean and the responses.

But it is only a **training-design** filtering theorem. At a fresh point `u`,

\[
\boxed{
\Delta f(u)
=
D(u)
-k(u,X)(K+n\lambda I)^{-1}D(X).
}
\]

There is no universal contraction without a relation between `D(u)` and `D(X)`.

## `P15-TRAINFILTER-NOT-POP-CE-29` — DISPROVED route

Take any fixed training design and choose two learned means whose difference vanishes on every training input but is nonzero at a fresh input `u`. Then residual KRR sees identical residual labels and the two fitted training predictors are identical, yet the deployed predictors differ by the full off-design mean difference at `u`.

Therefore

\[
\boxed{
\text{strong training-design residualization stability does not imply fresh-input stability.}
}
\]

This is the exact obstruction that the inherited leave-one-out / replace-one population bridge is designed to pay for.

# 4. Proof of the exact centering singular spectrum

This section proves `P15-SOURCE-CENTERING-SINGULAR-29` and `P15-SOURCE-CENTERING-HS-29`.

Work first in one scalar output coordinate. Let the `k` equal folds have size `h`, so `N=kh`.

Define the fold-mean operator

\[
M:\mathbb R^N\to\mathbb R^k,
\qquad
(My)_\ell
=
\frac1h\mathbf1_{H_\ell}^Ty.
\]

The rows of `M` have disjoint support and squared norm `1/h`, so

\[
\boxed{MM^T=\frac1h I_k.}
\tag{4.1}
\]

Let

\[
P=I_k-\frac1k\mathbf1\mathbf1^T,
\qquad
C=\frac1{k-1}P.
\]

The equal-fold pooled-minus-complement contrasts are exactly

\[
a=CMy.
\]

Define the embedding

\[
E:\mathbb R^k\to\mathbb R^N,
\qquad
(Ea)|_{H_\ell}=b_\ell a_\ell.
\]

Because fold blocks are disjoint,

\[
\boxed{E^TE=D=\operatorname{diag}(d_1,\ldots,d_k),
\qquad d_\ell=\|b_\ell\|^2.}
\tag{4.2}
\]

The scalar centering map is

\[
T=ECM.
\]

By (4.1), write `M=h^{-1/2}U` with `UU^T=I_k`. Right multiplication by this co-isometry adds only zero singular values. Hence the nonzero squared singular values of `T` equal those of `h^{-1/2}EC`, namely the eigenvalues of

\[
\frac1h C^TE^TEC
=
\boxed{
\frac{1}{h(k-1)^2}PDP.
}
\tag{4.3}
\]

This proves the spectrum claim.

Since `D=h diag(rho_l^2)`, equation (4.3) gives the exact operator norm stated in Section 0.

For the scalar Hilbert--Schmidt norm,

\[
\begin{aligned}
\|T\|_{HS}^2
&=
\frac{1}{h(k-1)^2}\operatorname{tr}(PDP)\\
&=
\frac{1}{h(k-1)^2}\operatorname{tr}(DP)\\
&=
\frac{1}{h(k-1)^2}
\left(1-\frac1k\right)\sum_\ell d_\ell\\
&=
\frac{\sum_\ell d_\ell}{N(k-1)}.
\end{aligned}
\tag{4.4}
\]

For `q` output coordinates the vectorized map is the scalar map tensored with `I_q`, so every singular value repeats `q` times. Multiplying (4.4) by `q` proves the full-vector Hilbert--Schmidt formula.

### Sanity checks performed

Independent finite-dimensional numerical checks were run for `k=3,4,5` with random row factors. Direct SVD of the explicit `N x N` map agreed with the eigenvalues of (4.3) to machine precision (`~10^-16`), and the direct Frobenius norm agreed with the trace formula to machine precision.

No numerical experiment is used as evidence for the theorem; it is only an algebra check.

# 5. Unequal-fold repair

The preceding report stated the contrast theorem only for equal folds because that is the exact source configuration. The algebra is more general.

Let fold sizes be `h_l`, total `N`, and fold means `mu_l`. Then

\[
\mu_P
=
\frac1N\sum_rh_r\mu_r,
\]

while

\[
\mu_{F_\ell}
=
\frac{N\mu_P-h_\ell\mu_\ell}{N-h_\ell}.
\]

Subtracting gives

\[
\boxed{
a_\ell
:=
\mu_P-\mu_{F_\ell}
=
\frac{h_\ell}{N-h_\ell}(\mu_\ell-\mu_P).
}
\tag{5.1}
\]

Multiplying by `N-h_l` and summing,

\[
\sum_\ell(N-h_\ell)a_\ell
=
\sum_\ell h_\ell\mu_\ell
-
N\mu_P
=0.
\tag{5.2}
\]

Thus the contrast tuple belongs to a codimension-`q` linear subspace of `(R^q)^k`, proving the `(k-1)q` dimension bound without equal fold sizes.

Now replace one response in fold `r` by `+delta`. Then

\[
\Delta\mu_r=\frac{\delta}{h_r},
\qquad
\Delta\mu_P=\frac\delta N.
\]

For `l=r`, (5.1) gives

\[
\Delta a_r
=
\frac{h_r}{N-h_r}
\left(
\frac{\delta}{h_r}-\frac\delta N
\right)
=
\boxed{\frac\delta N}.
\]

For `l ne r`, only the pooled mean changes, hence

\[
\boxed{
\Delta a_\ell
=-\frac{h_\ell}{N(N-h_\ell)}\delta.
}
\]

Direct numerical checks on irregular fold sizes `(3,5,7)` and `(2,4,5,9)` reproduced both (5.2) and the replacement law to machine precision.

# 6. Exact Efron--Stein consequence for the historical channel

For equal folds the preceding report already proved that replacing a response in fold `r` by a difference `delta` changes the pooled/local intervention by squared Frobenius amount

\[
\|\Delta_r(\Delta Z)\|_F^2
=
\frac{\|\delta\|^2}{N^2}
\left[
S_{2,r}
+
\frac1{(k-1)^2}
\sum_{\ell\ne r}S_{2,\ell}
\right].
\tag{6.1}
\]

Let a scalar downstream statistic `Phi` obey

\[
|\Phi(Z)-\Phi(Z')|
\le
L_{ctr}\|Z-Z'\|_F
\]

whenever `Z-Z'` lies in the centering-contrast subspace.

Under the explicit independent-copy response benchmark,

\[
E\|Y_i-Y_i'\|^2=2\operatorname{tr}\Omega.
\]

Efron--Stein gives

\[
\operatorname{Var}\Phi
\le
\frac12\sum_{i=1}^N
E(\Phi-\Phi^{(i)})^2.
\]

There are `h=N/k` rows in each fold. Summing the coefficient in (6.1) over all replaced rows,

\[
\begin{aligned}
&\sum_{r=1}^k
\frac{h}{N^2}
\left[
S_{2,r}
+
\frac1{(k-1)^2}
\sum_{\ell\ne r}S_{2,\ell}
\right]\\
&\qquad=
\frac{\sum_\ell S_{2,\ell}}{N(k-1)}.
\end{aligned}
\]

The factor `1/2` in Efron--Stein cancels the factor `2` in the independent-copy response difference, proving

\[
\boxed{
\operatorname{Var}\Phi
\le
L_{ctr}^2\operatorname{tr}\Omega
\frac{\sum_\ell S_{2,\ell}}{N(k-1)}.
}
\tag{6.2}
\]

This is more source-faithful than paying a full ambient network Lipschitz constant, because only `L_ctr` on the exact intervention subspace appears.

It assumes a stochastic independent-row response model and a fixed downstream Lipschitz map on the specified subspace. The actual source also retrains the refiner, reselects checkpoints/stacks/kernel choices, and uses deterministic simulator labels. Those debts remain explicit.

# 7. Exact KRR residualization filter and its population obstruction

Fix the design and kernel. Let

\[
H=K(K+n\lambda I)^{-1},
\qquad
A=I-H.
\]

Given training responses `Y` and a training-row mean matrix `M`, residual KRR fits

\[
F(M)
=
M+H(Y-M)
=
HY+AM.
\tag{7.1}
\]

Thus for any perturbation `D`, even one chosen after observing the same responses,

\[
\boxed{F(M+D)-F(M)=AD.}
\tag{7.2}
\]

Because a positive-semidefinite Gram matrix has KRR multipliers

\[
h_j=\frac{\kappa_j}{\kappa_j+n\lambda}\in[0,1),
\]

`A` has multipliers

\[
a_j=1-h_j=\frac{n\lambda}{\kappa_j+n\lambda}\in(0,1].
\]

So (7.2) is a contraction in Frobenius/Euclidean norm and sharply suppresses mean changes in high-kernel-eigenvalue modes.

This identity is fully compatible with the earlier same-response risk theorems: it is a realized training-design identity, whereas the earlier covariance terms arise when taking noisy-response population risk.

At a fresh point `u`, however,

\[
F_m(u)=m(u)+k(u,X)(K+n\lambda I)^{-1}(Y-m(X)).
\]

Therefore a mean perturbation `D` gives

\[
\boxed{
\Delta F(u)
=
D(u)-k(u,X)(K+n\lambda I)^{-1}D(X).
}
\tag{7.3}
\]

If `D(X)=0` but `D(u)\ne0`, the training fitted values do not change at all while the fresh prediction changes by `D(u)`. Hence no training-only contraction argument can replace the inherited fresh-input stability / leave-one-out bridge.

This is especially relevant for the source OOF/full-data refiner mismatch: a small intervention on the observed OOF field can be strongly attenuated by a subsequent fixed KRR correction on training rows, yet that alone gives no theorem for a new query unless the refiner/mean perturbation is controlled off-design.

# 8. Relation to the same-response spectral risk program

All preceding exact same-response results remain intact.

For a fixed symmetric KRR smoother `H`, `A=I-H`, and a linear same-response structured mean `SY`, the inherited finite-design risk identity under centered noise covariance `Sigma` is

\[
\begin{aligned}
G_{same}
={}&
\|A\mu\|^2-\|A(I-S)\mu\|^2\\
&-2\operatorname{tr}(H\Sigma S^TA^T)
-\operatorname{tr}(AS\Sigma S^TA^T).
\end{aligned}
\]

Under isotropic noise and commuting `H,S`, mode `j` has exact gain

\[
G_{same,j}
=(1-h_j)^2s_j(2-s_j)\theta_j^2
-\sigma^2
\left[
2h_j(1-h_j)s_j+(1-h_j)^2s_j^2
\right].
\]

The exact same-response activity threshold is

\[
\frac{\theta_j^2}{\sigma^2}
>
\frac{h_j}{1-h_j}
=
\frac{\kappa_j}{n\lambda}.
\]

This remains distinct from the fixed-population bias identity.

The inherited counterexamples also remain active:

- a correction can have positive same-sample residual-fit gain while increasing true noisy risk;
- a mean can reduce ordinary residual norm while moving residual energy into kernel-weak modes and increasing KRR bias;
- a cross-fit-beneficial mean can become harmful under same-response reuse;
- under anisotropic response covariance the same-response covariance interaction need not have a fixed sign;
- fixed-training-design gain need not transfer to fresh-input population gain without replacement stability.

The new Section 7 theorem adds a complementary no-go:

- **training-design residualization contraction need not transfer to fresh inputs.**

# 9. Cross-fitting and leave-one-out benchmark retained

For the **entire** learning pipeline, train without observation `i`, including mean fitting, representation learning, residual construction, model selection, and correction fitting. The paired held-out correction difference is

\[

=
\ell(m_{-i}+c_{-i},Z_i)
-
\ell(m_{-i},Z_i).

\[

\Delta_{n-1}^{pop}.

### Audited statement

Let `H` be an `(m+1) x m` matrix with iid centered rows, sufficient integrability, and full column rank almost surely. Define the Gram-volume-biased law

\[
\frac{dQ}{dP}(H)
=
\frac{\det(H^TH)}{E_P\det(H^TH)}.
\]

Let `v` be a unit vector spanning `ker(H^T)`. P04 claims

\[
\boxed{E_Q(\mathbf1^Tv)^2=1.}
\]

### Independent derivation

For each row index `i`, define the signed maximal cofactor

\[
c_i=(-1)^{i+1}\det(H_{-i}),
\]

where `H_{-i}` is the square matrix obtained by deleting row `i`.

The cofactor vector satisfies

\[
H^Tc=0.
\]

Cauchy--Binet gives

\[
\boxed{
\|c\|^2
=
\sum_i c_i^2
=
\det(H^TH).
}
\]

Thus, up to an irrelevant global sign,

\[
v=c/\|c\|.
\]

Under the tilted law,

\[
E_Q(\mathbf1^Tv)^2
=
\frac{E_P(\sum_i c_i)^2}{E_P\sum_i c_i^2}.
\tag{12.1}
\]

For `i ne j`, condition on every row except row `i`. The cofactor `c_i` deletes row `i`, so it is measurable under this conditioning. The cofactor `c_j` includes row `i` in a determinant and is therefore a linear functional of that row with coefficients fixed under the conditioning. Since the row is centered,

\[
E[c_j\mid \{h_r:r\ne i\}]=0.
\]

Hence

\[
E[c_ic_j]=0,
\qquad i\ne j.
\]

Therefore

\[
E(\sum_i c_i)^2
=
\sum_iEc_i^2
=
E\det(H^TH).
\]

Substitution into (12.1) gives exactly `1`.

### Scope check

No Gaussianity, isotropy, or rotational invariance is used. The hypotheses actually needed by this proof are:

- iid is stronger than necessary; row-wise centering plus the required conditional/product structure suffices for the cross-term cancellation;
- integrability sufficient for the displayed expectations;
- full column rank almost surely so the normalized null vector is defined.

The P04 claim states these conditions. The proof and constant are correct.
