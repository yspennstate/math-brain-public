For one spectral mode, let

\[

\[

\[

\[
\boxed{

\frac{\kappa}{n\lambda}

# 5. Exact nonlinear covariance identity for a same-response mean

The inherited linear-smoother theorem can be generalized algebraically without Gaussianity and without differentiability.

Let the fixed-design response be

\[
Y=\mu+\varepsilon,
\qquad
E\varepsilon=0.
\]

Allow a possibly response-dependent smoother

\[
H=H(Y)
\]

and define

\[
A(Y)=I-H(Y).
\]

Let

\[
M=M(Y)
\]

be any learned/structured mean built from the same response vector.

Define the zero-mean kernel predictor

\[
f_0(Y)=H(Y)Y
\]

and the mean-corrected hybrid

\[
\begin{aligned}
f_1(Y)
&=
M(Y)+H(Y)(Y-M(Y))
\\
&=
H(Y)Y+A(Y)M(Y).
\end{aligned}
\tag{5.1}
\]

Use squared Euclidean risk.

## `P15-DATADEP-HYBRID-COV-ID-24` — NEW / PROVED

The exact zero-mean-KRR minus hybrid risk gain is

\[
\boxed{
\begin{aligned}
G
:={}&
E\|f_0(Y)-\mu\|^2
-
E\|f_1(Y)-\mu\|^2
\\
={}&
2E\langle A(Y)\mu,A(Y)M(Y)\rangle
-
E\|A(Y)M(Y)\|^2
\\
&-
2E\langle
H(Y)\varepsilon,
A(Y)M(Y)
\rangle.
\end{aligned}
}
\tag{5.2}
\]

### Proof

Pathwise,

\[
f_0-\mu
=
H(\mu+\varepsilon)-\mu
=
-A\mu+H\varepsilon.
\]

Also

\[
f_1-\mu
=
(f_0-\mu)+AM.
\]

Therefore

\[
\begin{aligned}
G
&=
-\,
2E\langle
f_0-\mu,
AM
\rangle
-
E\|AM\|^2
\\
&=
2E\langle A\mu,AM\rangle
-
2E\langle H\varepsilon,AM\rangle
-
E\|AM\|^2.
\end{aligned}
\]

QED.

### Interpretation

The first two terms are the structured-mean gain one would see if the kernel/mean object were independent of the current response noise.

The final term

\[
\boxed{
2E\langle H\varepsilon,AM\rangle
}
\tag{5.3}
\]

is the exact same-response covariance term.

If \(H\) itself depends on \(Y\), that dependence remains inside `(5.2)`.

Thus cross-fitting **only the mean** does not automatically remove all sample-reuse effects when the learned representation/kernel also depends on the same responses.

This is precisely why a source-faithful cross-fit benchmark must exclude the held-out response from every path through:

- neural mean training;
- feature/representation learning;
- checkpoint selection;
- kernel/ridge selection;
- correction fitting.

No Gaussian assumption is used by `(5.2)`.

# 6. Ghost/cross-fit mean comparison when the kernel smoother is fixed

Now assume

H

Let

\[

Construct a ghost mean

\[

\]

## `P15-GHOST-MEAN-TAX-24` — NEW / PROVED

Let

\[
G_{\rm same}
\]

be the gain using \(M\), and let

\[
G_{\rm ghost}
\]

be the gain using \(M^\perp\).

Then

\[
\boxed{
G_{\rm same}
-
G_{\rm ghost}
=
-2E\langle
H\varepsilon,
AM
\rangle.
}
\tag{6.1}
\]

### Proof

\[
E\langle A\mu,AM^\perp\rangle

\[

# 8. New spectral oracle theorem

Assume now:

\[

\[

\[
\boxed{

\right].
}
\tag{8.1}

Rearrange:

\[
\boxed{
G_{{\rm same},j}(s)
=
2a
\left[
a\theta^2-\sigma^2h
\right]s
-
a^2(\theta^2+\sigma^2)s^2.

\tag{8.2}
\]

This is a concave quadratic on

\[
0\le s\le1.

## `P15-SAMEOBS-SPECTRAL-ORACLE-24` — NEW / PROVED

For

\[
a=1-h>0,
\]

the exact maximizing same-response mean multiplier is

\[
\boxed{
s_{\rm same}^\star
=
\frac{
[a\theta^2-\sigma^2h]_+
}{
a(\theta^2+\sigma^2)
}.
}
\tag{8.3}
\]

It always lies in \([0,1)\).

The maximal modewise gain is

\[
\boxed{
G_{\rm same}^\star
=
\frac{
[a\theta^2-\sigma^2h]_+^2
}{
\theta^2+\sigma^2
}.
}
\tag{8.4}
\]

Consequently, a nonzero same-response structured mean can improve the zero-mean KRR mode **if and only if**

\[
\boxed{
a\theta^2
>
\sigma^2h.
}
\tag{8.5}
\]

Equivalently,

\[
\boxed{
\frac{\theta^2}{\sigma^2}
>
\frac{h}{1-h}.
}
\tag{8.6}
\]

### Proof

The derivative of `(8.2)` is

\[
2a[a\theta^2-\sigma^2h]
-
2a^2(\theta^2+\sigma^2)s.

\[
a\theta^2\le\sigma^2h,

the derivative at zero is nonpositive, and strict concavity makes

\[
s^\star=0.

\[
a\theta^2>\sigma^2h,

the stationary point is `(8.3)`.

To check it is below one,

\[
a\theta^2-\sigma^2h
<
a(\theta^2+\sigma^2)
\]

is equivalent to

\[
-h<a,
\]

which follows from

\[
a+h=1.
\]

Substituting the quadratic maximizer gives `(8.4)`.

QED.
