# Executive update

The fixed-population identity

\[
B(\lambda)
=
\sum_j
\left[
\frac{\lambda}{\lambda_j+\lambda}
\right]^2r_j^2,
\qquad r=f^\star-m,
\]

remains exact and elementary for a **fixed** mean and **fixed** population kernel. It is not a theorem about a mean, representation, validation selector and correction trained from the same observations.

The latest P15 run proved expectation-level fresh-input bridges:

1. under an explicit Gaussian-response model, same-response SURE plus an exact old-input replace-one term equals the training-algorithm-averaged fresh-input population difference;
2. under centered independent response noise, including deterministic labels, a genuinely full-pipeline leave-one-out paired loss is unbiased for the fresh-input population difference of the size-`n-1` learner.

This run upgrades both directions to **one-sample high-probability certificates under explicit algorithmic stability**.

The principal source-facing theorem is

## `P15-LOO-FULLSAMPLE-HIGHPROB-21` — NEW / PROVED

For the entire learned pipeline, define

\[
d_T(z)=\ell(m_T+c_T,z)-\ell(m_T,z)
\]

and

\[
\widehat\Delta_{\rm loo}(S)
=
\frac1n\sum_{i=1}^n d_{S^{-i}}(Z_i).
\]

\[
\Delta_n(S)=E_Zd_S(Z)
\]

be the realized full-sample population corrected-minus-baseline loss difference. If the paired-loss map has evaluation oscillation `a_{n-1}`, size-`s` one-row replacement stability `beta_s`, and size-`n` deletion stability `eta_n`, then for every `0<delta<1`, with probability at least `1-delta`,

\[
\boxed{
\begin{aligned}
\Delta_n(S)
\le{}&
\widehat\Delta_{\rm loo}(S)
\\
&+
\big[a_{n-1}+(n-1)\beta_{n-1}\big]

\tag{E1}

A negative right-hand side certifies strict population improvement of the **realized full-sample same-observation learner**.

\[

# 7. `P15-LOO-FULLSAMPLE-HIGHPROB-21` — proof

Let `S^(j)` replace `Z_j` by `Z_j'`.

For the `i=j` LOO term,

\[
S^{-j}=(S^{(j)})^{-j},
\]

so the fitted pipeline is identical and only the evaluation point changes. Its contribution changes by at most `a_{n-1}`.

For each `i != j`, the evaluation point is unchanged and the two size-`n-1` fitting samples differ by exactly one replacement, so the summand changes by at most `beta_{n-1}`.

Therefore changing one coordinate changes the LOO average by at most

\[
\boxed{
c_{\rm loo}
=
\frac{a_{n-1}+(n-1)\beta_{n-1}}n.
}
\tag{7.1}

McDiarmid gives, with failure at most `delta/2`,

\[
\overline\Delta_{n-1}
\le
\widehat\Delta_{\rm loo}
+
[a_{n-1}+(n-1)\beta_{n-1}]
\sqrt{\frac{\log(2/\delta)}{2n}}.
\tag{7.2}

Deletion stability implies

\[
|\Delta_n(S)-\Delta_{n-1}(S^{-i})|
\le\eta_n,
\]

hence after expectation

\[
\boxed{
E\Delta_n(S)
\le
\overline\Delta_{n-1}+\eta_n.
}
\tag{7.3}

Finally, replacement stability gives

\[
|\Delta_n(S)-\Delta_n(S^{(j)})|
\le\beta_n.
\]

A second McDiarmid application gives, with failure at most `delta/2`,

\[
\Delta_n(S)
\le
E\Delta_n(S)
+
\beta_n\sqrt{\frac{n\log(2/\delta)}2}.
\tag{7.4}

Combine `(7.2)`--`(7.4)` and union bound to obtain `(E1)`.

QED.

### Rate interpretation

If

\[
a_{n-1}=O(1),
\qquad
\beta_{n-1},\beta_n,\eta_n=O(n^{-1}),
\]

then the total confidence/transfer width is `O(n^-1/2)` at fixed confidence.

If only uniform `beta_n=O(n^-1/2)` is available, the final McDiarmid term is order one and the theorem may be vacuous. The inherited average-energy/Efron--Stein gate remains the correct weaker-stability route.

# 8. Second-moment LOO route

For coordinate replacement `j`, define

\[
A_j=d_{S^{-j}}(Z_j)-d_{S^{-j}}(Z_j'),
\]

and for `i != j`,

\[
B_{ij}=d_{S^{-i}}(Z_i)-d_{(S^{(j)})^{-i}}(Z_i).
\]

Put

\[
a_2^2=\frac1n\sum_jEA_j^2,
\]

\[
b_2^2
=
\frac1{n(n-1)}\sum_j\sum_{i\ne j}EB_{ij}^2.
\]

## `P15-LOO-EFRON-GAIN-21` — NEW / PROVED

\[
\boxed{
\operatorname{Var}(\widehat\Delta_{\rm loo})
\le
\frac{a_2^2+(n-1)^2b_2^2}{n}.
}
\tag{8.1}

Consequently, with probability at least `1-delta`,

\[
\boxed{
\overline\Delta_{n-1}
\le
\widehat\Delta_{\rm loo}
+
\sqrt{\frac{a_2^2+(n-1)^2b_2^2}{n\delta}}.
}
\tag{8.2}

### Proof

For each `j`,

\[
\widehat\Delta_{\rm loo}(S)-\widehat\Delta_{\rm loo}(S^{(j)})
=
\frac1n\left[A_j+\sum_{i\ne j}B_{ij}\right].
\]

Use

\[
(x+y)^2\le2x^2+2y^2
\]

and

\[
\left(\sum_{i\ne j}B_{ij}\right)^2
\le(n-1)\sum_{i\ne j}B_{ij}^2.
\]

The Efron--Stein factor `1/2` cancels the factor `2`, giving `(8.1)`. Apply one-sided Chebyshev for `(8.2)`.

QED.

This route uses only second moments of the actual paired-loss perturbations and has polynomial confidence dependence.

# 9. `P15-PAIRLOSS-STABILITY-21` — exact squared-loss specialization

For

\[
d(m,c;z)
=
\|y-m(x)-c(x)\|^2-
\|y-m(x)\|^2,

\[
m'=m+u,
\qquad c'=c+v,
\qquad q=y-m-c.

\[
\boxed{
\begin{aligned}
d(m',c';z)-d(m,c;z)

-2\langle q,v\rangle
+2\langle u,c\rangle
\\
&+2\langle u,v\rangle
+\|v\|^2.
\end{aligned}

\tag{9.1}

\[
\|q\|\le Q,
\quad
\|c\|\le C,
\quad
\|u\|\le e_m,

# 11. `P15-LOO-NOSTABILITY-CE-21` — new counterexample

Let

\[
X_1,\ldots,X_n\stackrel{\rm iid}{\sim}\operatorname{Rad}(\pm1)
\]

with even `n`, and deterministic labels `Y_i=1`.

For every odd-size training sample `T`, define

\[
h(T)=\operatorname{sign}\sum_{z\in T}x(z).
\]

Use baseline `m_T=0` and corrected constant predictor

\[
m_T+c_T
=
\begin{cases}
1,&h(T)=-1,\\
1+\sqrt2,&h(T)=+1.
\end{cases}
\]

The baseline squared loss is `1`.

- `h=-1`: corrected loss `0`, paired difference `-1`;
- `h=+1`: corrected loss `2`, paired difference `+1`.

Hence

\[
\boxed{d_T(z)=h(T)}
\]

for every evaluation point.

An odd Rademacher sum has symmetric nonzero sign, so

\[
\overline\Delta_{n-1}=0.
\]

For the even-size full sample, put

\[
T_n=\sum_jX_j.
\]

If `T_n>=2`, every leave-one-out majority is positive and

\[
\widehat\Delta_{\rm loo}=+1.
\]

If `T_n<=-2`, every leave-one-out majority is negative and

\[
\widehat\Delta_{\rm loo}=-1.
\]

If `T_n=0`, half the LOO signs are positive and half negative, so the average is zero. Therefore

\[
\boxed{
P\{|\widehat\Delta_{\rm loo}|=1\}
=1-P\{T_n=0\}
\to1,
}
\]

while

\[
E\widehat\Delta_{\rm loo}=0.
\]

Thus the expected LOO identity alone gives no one-run sign certificate. The missing quantity is exactly algorithmic stability near the majority branch boundary.
