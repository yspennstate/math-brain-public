# 0. Exact target and executive result

The fixed-population identity remains

\[
\boxed{
B(\lambda)
=
\sum_j
\left[\frac{\lambda}{\lambda_j+\lambda}\right]^2 r_j^2,
\qquad
r=f^\star-m.
}
\tag{0.1}
\]

This is retained only for a **fixed mean** `m` and a **fixed population kernel operator**. The recovered kernel-learning shortlist literally says that `(0.1)` is “elementary, not a new conjecture” and that the harder follow-up is to establish comparable prediction guarantees when the **mean, representation, and correction are trained on the same observations**. Nothing in this report relabels `(0.1)` as a same-sample theorem.

P15 remains **OPEN**, but this run makes a substantive source-facing advance.

The previous run proved that complete-pipeline deletion distances can conservatively replace unavailable independent simulator replicas. Its remaining algebraic source debt was that an actual leave-fold retrain changes several KRR objects at once:

1. the number of fitting rows, hence the source ridge matrix changes from `K+n lambda I` to `K_- + m lambda_- I`;
2. the learned training-row mean changes;
3. the deployed mean changes at a fresh query;
4. the learned representation / Gram matrix changes;
5. the fresh query kernel vector changes;
6. validation-selected ridge/kernel parameters can change.

This run resolves that algebra exactly for one residual-KRR stage and, crucially, does so in the manuscript’s actual `M_tr` versus `m_full` formulation rather than pretending the training-row mean is the restriction of one cross-fitted function.

## Main new package

### `P15-SOURCE-MEAN-INCREMENT-38` — **PROVED**

For one realized sample, one realized kernel/representation and one realized training-row mean matrix `M`, compare zero-mean KRR

\[
b_n(u)=k(u,X)(K+n\lambda I)^{-1}Y
\]

with source-style mean-corrected residual KRR

\[
f_n(u)
=
m_n(u)
+k(u,X)(K+n\lambda I)^{-1}(Y-M).
\]

Here `M` may be the actual mixed training-row mean `M_tr`; it need **not** equal `m_n(X)` and no independence from the sample is assumed. Then pathwise

\[
\boxed{
g_n(u):=f_n(u)-b_n(u)
=
m_n(u)-k(u,X)(K+n\lambda I)^{-1}M.
}
\tag{0.2}
\]

This is the exact learned-mean increment relative to uncorrected KRR for the **same realized correction kernel**. It is not a risk-sign theorem.

### `P15-SAMEOBS-MEAN-DELETE-EXACT-38` — **PROVED**

Delete a block `H` of `r` observations, retain `T` of size `m=n-r`, and allow the deleted retrain to have a different learned representation, fresh query vector, training-row mean, deployed mean and ridge value. Then the exact prediction movement

\[
g_n(u)-g_-(u)
\]

splits into **six explicit channels**:

1. direct deployed-mean movement;
2. omitted-row conditional-leverage movement;
3. the mandatory source normalization / ridge-selection shift `n lambda -> m lambda_-`;
4. retained training-row mean movement;
5. fresh-query representation movement;
6. retained Gram-matrix representation movement.

The exact formula is proved in Section 4.

### `P15-KRR-DELETE-REP-RESOLVENT-38` — **PROVED**

The last two representation channels have an exact finite resolvent identity, including the fresh kernel vector. Thus this run preserves the earlier counterexample that Gram stability alone is not enough.

### `P15-SOURCENORM-NEUMANN-38` — **PROVED**

If the same numerical ridge `lambda>0` is used before and after deleting `r` rows, then

\[
K_{TT}+m\lambda I
=
(K_{TT}+n\lambda I)-r\lambda I.
\]

The inverse has the convergent exact series

\[
\boxed{
(K_{TT}+m\lambda I)^{-1}
=
\sum_{j=0}^{\infty}
(r\lambda)^j
(K_{TT}+n\lambda I)^{-(j+1)},
}
\tag{0.3}
\]

with operator-norm tail after order `J`

\[
\boxed{
\left\|
(K_{TT}+m\lambda I)^{-1}
-
\sum_{j=0}^{J}
(r\lambda)^j
(K_{TT}+n\lambda I)^{-(j+1)}
\right\|_{\rm op}
\le
\frac1{n\lambda}
\frac{(r/n)^{J+1}}{1-r/n}.
}
\tag{0.4}
\]

For the actual four-fold source deletion, `r/n=4750/19000=1/4`. The source-normalization correction is therefore stable but **not zero**.

### `P15-MEAN-KRR-DELETION-CERT-38` — **PROVED**

Combining the exact six-channel movement with the preceding run’s direct mean-relative deletion theorem gives a finite-sample sign certificate comparing the fully same-observation learned-mean correction against the full uncorrected KRR baseline. If the deleted-correction hybrid gain exceeds the exact/upper-bounded movement budget, then the same-observation corrected learner improves mean-relative risk. No sample independence, Gaussian response model or differentiability is needed.

### `P15-HYBRID-ARRAY-CONTRACT-38` — **PROVED**

The source experiment does **not** need a separately trained “hybrid” model. Four prediction arrays suffice for each deletion:

- full baseline `B_n`;
- full corrected predictor `F_n`;
- deleted baseline `B_-`;
- deleted corrected predictor `F_-`.

Since

\[
G_n=F_n-B_n,
\qquad
G_-=F_--B_-,
\]

the hybrid required by the theorem is exactly

\[
\boxed{
H=B_n+G_-
=F_-+(B_n-B_-).
}
\tag{0.5}
\]

The correction movement is likewise

\[
\boxed{
G_n-G_-
=(F_n-F_-)-(B_n-B_-).
}
\tag{0.6}
\]

Thus the currently missing source object is reduced to a concrete prediction-array contract.

### `P15-FIXED-RHO-DELETION-CE-38` — **DISPROVED route / exact counterexample**

A standard fixed-matrix-shift ridge deletion shortcut is not source-exact if it silently keeps `rho=n lambda` fixed while deleting rows. With `n=2`, `m=1`, `K=I_2`, `lambda=1`, response `(1,0)` and query at the retained first point,

\[
\widehat f_n=\frac13,
\qquad
\widehat f_{m,\text{source}}=\frac12,
\]

whereas a fixed-`rho=2` deletion formula returns `1/3` and falsely reports zero movement. The source code itself multiplies the ridge by the current fitting count, so this normalization issue is real.

# 4. Exact same-observation learned-mean deletion calculus

This section is deterministic finite-dimensional algebra. No iid assumption, Gaussian response model, differentiability or optimization convexity is used.

## 4.1 Full realized system

Fix one realized fitting sample of size `n` and one realized correction kernel/representation. Let

\[
K\in\mathbb R^{n\times n},
\qquad
k(u)\in\mathbb R^n,
\qquad
\lambda>0,
\]

and let

\[
A=K+n\lambda I.
\tag{4.1}
\]

Let `Y` be the output matrix and let

\[
M\in\mathbb R^{n\times q}
\]

be the **actual training-row mean matrix used in the correction labels**. In the final source this is `M_tr`; no assumption is made that `M=m_n(X)` for a single query-time function.

Let `m_n(u)` denote the deployed mean at a query.

The uncorrected zero-mean KRR predictor using this same realized kernel is

\[
b_n(u)=k(u)^\top A^{-1}Y.
\tag{4.2}
\]

The source-style residual correction is

\[
f_n(u)=m_n(u)+k(u)^\top A^{-1}(Y-M).
\tag{4.3}
\]

Subtracting `(4.2)` from `(4.3)` gives

\[
\boxed{
 g_n(u):=f_n(u)-b_n(u)
 =m_n(u)-k(u)^\top A^{-1}M.
}
\tag{4.4}
\]

This proves `P15-SOURCE-MEAN-INCREMENT-38`.

### Scope of `(4.4)`

- `m_n`, `M`, `K`, `k` and `lambda` may all have been learned/selected from the same observations.
- `M` may be the source’s mixed OOF/in-sample training-row matrix.
- No sample independence is used.
- `(4.4)` compares mean-corrected versus zero-mean KRR **using the same realized correction kernel**. If the comparator uses a different representation/kernel by construction, the more general arbitrary-system resolvent theorems from earlier P15 runs remain the correct comparator.
- `(4.4)` says nothing by itself about the sign of fresh risk.

## 4.2 Delete a block and permit every source-relevant KRR object to move

Delete a nonempty block `H` of size

\[
r=|H|,
\]

and retain

\[
T=H^c,
\qquad
m=|T|=n-r.
\]

Partition the full Gram matrix, query vector, training-row mean and the coefficient matrix

\[
\eta=A^{-1}M
\tag{4.5}
\]

according to `T,H`.

Thus

\[
K=
\begin{pmatrix}
K_{TT}&K_{TH}\\
K_{HT}&K_{HH}
\end{pmatrix},
\quad
k=
\binom{k_T}{k_H},
\quad
M=
\binom{M_T}{M_H},
\quad
\eta=
\binom{\eta_T}{\eta_H}.
\]

Now allow the actual deleted retrain to have:

- selected ridge `lambda_->0`;
- retained learned Gram matrix `K^-`;
- fresh query vector `k^-`;
- deleted-system training-row mean matrix `M^-` on the retained rows;
- deleted-system deployed mean `m_-(u)`.

Define the full-representation / deleted-ridge reference matrix

\[
B_0
=
K_{TT}+m\lambda_- I,
\tag{4.6}
\]

and the actual deleted matrix

\[
B_-
=
K^-+m\lambda_- I.
\tag{4.7}
\]

Define

\[
D_M=M^- - M_T,
\tag{4.8}
\]

\[
\Delta K=K^- - K_{TT},
\qquad
\Delta k=k^- - k_T,
\tag{4.9}
\]

and the exact ridge/sample-size shift

\[
\boxed{
\delta\rho=n\lambda-m\lambda_-.
}
\tag{4.10}
\]

The deleted mean-correction increment relative to its own zero-mean KRR baseline is

\[
g_-(u)
=
m_-(u)-(k^-)^\top B_-^{-1}M^-.
\tag{4.11}
\]

## 4.3 First identity: deleted reference coefficients

The retained block of the full normal equations is

\[
M_T
=
(K_{TT}+n\lambda I)\eta_T
+K_{TH}\eta_H.
\tag{4.12}
\]

Using `(4.6)` and `(4.10)`,

\[
K_{TT}+n\lambda I
=
B_0+\delta\rho I.
\]

Therefore

\[
M^-
=
B_0\eta_T
+K_{TH}\eta_H
+\delta\rho\eta_T
+D_M.
\tag{4.13}
\]

Hence

\[
\boxed{
B_0^{-1}M^-
=
\eta_T
+B_0^{-1}
\left(
K_{TH}\eta_H
+\delta\rho\eta_T
+D_M
\right).
}
\tag{4.14}
\]

## 4.4 Second identity: full versus reference-deleted filtered mean

Define

\[
q_n(u)=k^\top\eta,
\qquad
q_-^0(u)=k_T^\top B_0^{-1}M^-.
\]

Using `(4.14)`,

\[
\boxed{
\begin{aligned}
q_n(u)-q_-^0(u)
={}&
\left[
 k_H^\top
-k_T^\top B_0^{-1}K_{TH}
\right]\eta_H
\\
&-
\delta\rho\,
 k_T^\top B_0^{-1}\eta_T
-
 k_T^\top B_0^{-1}D_M.
\end{aligned}
}
\tag{4.15}
\]

The three terms are, respectively:

1. **omitted-row conditional leverage**;
2. **sample-size/ridge-selection normalization**;
3. **retained training-row mean movement**.

## 4.5 Third identity: representation / fresh-query movement

The actual deleted filtered mean is

\[
q_-(u)=(k^-)^\top B_-^{-1}M^-.
\]

The resolvent identity gives

\[
B_-^{-1}-B_0^{-1}
=
-B_-^{-1}\Delta K B_0^{-1}.
\tag{4.16}
\]

Therefore

\[
\boxed{
\begin{aligned}
q_-(u)-q_-^0(u)
={}&
(\Delta k)^\top B_-^{-1}M^-
\\
&-
k_T^\top B_-^{-1}\Delta K B_0^{-1}M^-.
\end{aligned}
}
\tag{4.17}
\]

This is `P15-KRR-DELETE-REP-RESOLVENT-38`.

The first term is the **fresh-query-vector** movement. The second is retained **Gram movement**. This is why a training-Gram-only stability theorem cannot control fresh prediction.

## 4.6 Exact six-channel theorem

From

\[
g_n=m_n-q_n,
\qquad
g_-=m_- -q_-,
\]

and `(4.15)`--`(4.17)`,

\[
\boxed{
\begin{aligned}
g_n(u)-g_-(u)
={}&
\underbrace{m_n(u)-m_-(u)}_{\text{deployed mean}}
\\
&-
\underbrace{
\left[
 k_H^\top-k_T^\top B_0^{-1}K_{TH}
\right]\eta_H
}_{\text{omitted rows}}
\\
&+
\underbrace{
\delta\rho\,
 k_T^\top B_0^{-1}\eta_T
}_{\text{sample-size / ridge selection}}
\\
&+
\underbrace{
 k_T^\top B_0^{-1}D_M
}_{\text{training-row mean movement}}
\\
&+
\underbrace{
(\Delta k)^\top B_-^{-1}M^-
}_{\text{fresh-query representation}}
\\
&-
\underbrace{
 k_T^\top B_-^{-1}\Delta K B_0^{-1}M^-
}_{\text{retained Gram representation}}.
\end{aligned}
}
\tag{4.18}
\]

This proves

\[
\boxed{\texttt{P15-SAMEOBS-MEAN-DELETE-EXACT-38}.}
\]

### Why `(4.18)` is source-faithful

It never replaces `M_tr` by `m_full(X)`. It allows the deleted retrain to change both objects separately. It also permits the learned representation and selected ridge value to change under deletion.

The only stage-level structural assumption is that, **within each realized system**, the zero-mean KRR baseline and its residual mean correction use the same correction kernel. If the user instead compares the final corrected system to a completely different raw-input KRR member, the earlier arbitrary-system representation/resolvent theorem must be used around that additional comparator change.

# 5. Deterministic norm bounds and the direct sign certificate

## 5.1 Coercive bound at positive deleted ridge

Since `K^-` and `K_TT` are positive semidefinite and `lambda_->0`,

\[
\|B_-^{-1}\|_{\rm op}
\le
\frac1{m\lambda_-},
\qquad
\|B_0^{-1}\|_{\rm op}
\le
\frac1{m\lambda_-}.
\tag{5.1}
\]

Therefore `(4.18)` yields

\[
\boxed{
\begin{aligned}
\|g_n(u)-g_-(u)\|_2
\le{}&
\|m_n(u)-m_-(u)\|_2
\\
&+
\left(
\|k_H\|_2
+
\frac{\|k_T\|_2\,\|K_{TH}\|_{\rm op}}
     {m\lambda_-}
\right)
\|\eta_H\|_F
\\
&+
\frac{|\delta\rho|\,\|k_T\|_2}{m\lambda_-}
\|\eta_T\|_F
\\
&+
\frac{\|k_T\|_2}{m\lambda_-}
\|D_M\|_F
\\
&+
\left[
\frac{\|\Delta k\|_2}{m\lambda_-}
+
\frac{\|k_T\|_2\,\|\Delta K\|_{\rm op}}
     {(m\lambda_-)^2}
\right]
\|M^-\|_F.
\end{aligned}
}

## 5.2 Direct mean-relative same-observation comparison

For the manuscript loss

\[

=
\frac{\|y-f(u)\|_2}{\|y\|_2},
\]

the norm is 1-Lipschitz in prediction after weighting by `1/||y||`.

\[

\]

\[

\[
\ell_{\rm rel}(f_n;u,y)
\le
\ell_{\rm rel}(h_-;u,y)
+
\frac{\|g_n(u)-g_-(u)\|_2}{\|y\|_2}.

\[
\boxed{
\Gamma_{\rm same}^{\rm rel}
\ge
\Gamma_{-,\rm hyb}^{\rm rel}
-

# 6. Source normalization is a real leave-fold term

## 6.1 Same numerical ridge before and after deletion

Suppose

\[

\[
\delta\rho
=n\lambda-m\lambda

\tag{6.1}

\[

The source-deleted matrix is

\[

Because

\[
A_T\succeq n\lambda I,

\|r\lambda A_T^{-1}\|_{\rm op}
\le
\frac rn
<1.
\tag{6.2}

\[
\begin{aligned}
B_0^{-1}
&=
(I-r\lambda A_T^{-1})^{-1}A_T^{-1}

\sum_{j=0}^\infty
(r\lambda)^jA_T^{-(j+1)}.
