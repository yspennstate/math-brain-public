# 4. Ridge-whitened resolvent perturbation

## `P15-RIDGEWHITENED-RESOLVENT-46 — PROVED`

Let `K,K_tilde` be symmetric positive-semidefinite `n x n` matrices and let `lambda,lambda_tilde>0`. Put

`H = K + lambda I`,

`H_tilde = K_tilde + lambda_tilde I`,

`F = H_tilde-H = (K_tilde-K)+(lambda_tilde-lambda)I`.

Define the dimensionless relative perturbation

`S = H^{-1/2} F H^{-1/2}`,

`delta = ||S||_op`.

Assume

`delta < 1`.

Then

`H_tilde = H^{1/2}(I+S)H^{1/2}`

and

`H_tilde^{-1} = H^{-1/2}(I+S)^{-1}H^{-1/2}`.

Since the spectrum of `S` lies in `[-delta,delta]`,

`||(I+S)^{-1}||_op <= 1/(1-delta)`.

Moreover

`H^{1/2}(H_tilde^{-1}-H^{-1})H^{1/2}`
` = (I+S)^{-1}-I`
` = -(I+S)^{-1}S`,

so

`||H^{1/2}(H_tilde^{-1}-H^{-1})H^{1/2}||_op`
` <= delta/(1-delta)`.

This is the basic relative resolvent estimate. Unlike the ordinary absolute bound

`||H_tilde^{-1}-H^{-1}|| <= ||F||/(lambda lambda_tilde)`,

it is scale-adaptive: perturbations along well-conditioned/high-eigenvalue directions are discounted by `H^{-1/2}`.

### Prediction form

Let response matrix `Y` have arbitrary output dimension. For a query `u`, let `k(u)` and `k_tilde(u)` be the two query vectors and define

`Delta k(u)=k_tilde(u)-k(u)`,

`q(u)=||H^{-1/2}k(u)||_2`,

`d(u)=||H^{-1/2}Delta k(u)||_2`,

`y=||H^{-1/2}Y||_F`.

Then

`b(u)=k(u)^T H^{-1}Y`,

`b_tilde(u)=k_tilde(u)^T H_tilde^{-1}Y`

satisfy

`||b_tilde(u)-b(u)||_2`
` <= y [ d(u) + delta q(u) ]/(1-delta).`   `(4.1)`

### Proof of `(4.1)`

Write

`b_tilde-b`
` = Delta k^T H_tilde^{-1}Y`
` + k^T(H_tilde^{-1}-H^{-1})Y`.

The first term equals

`(H^{-1/2}Delta k)^T (I+S)^{-1}(H^{-1/2}Y)`

and is at most

`d y/(1-delta)`.

The second equals

`(H^{-1/2}k)^T [(I+S)^{-1}-I](H^{-1/2}Y)`

and is at most

`q y delta/(1-delta)`.

No probabilistic hypothesis appears. `K_tilde`, `k_tilde`, `lambda_tilde`, and `Y` may all have been produced from the same responses.

### Ridge selection is included rather than ignored

The perturbation object is

`F=(K_tilde-K)+(lambda_tilde-lambda)I`.

Thus changing the selected ridge is exactly part of the relative stability debt. A finite validation grid does not make this term vanish automatically.

# 5. Arbitrary learned mean: source-facing same-observation theorem

The July source mean is neural/stacked rather than a KRR mean. We therefore derive the ridge-whitened theorem directly for an arbitrary realized training-row/query-time mean.

For the reference system define

`b(u)=k(u)^T H^{-1}Y`,

`f(u)=m(u)+k(u)^T H^{-1}(Y-M)`.

Here `M` is the matrix of mean values actually subtracted on the fitting rows. It need not equal the restriction of the deployed query-time map `m`; this deliberately accommodates the source's OOF/in-sample mixture.

The correction increment relative to zero-mean KRR with the same kernel is exactly

`g(u)=f(u)-b(u)=m(u)-k(u)^T H^{-1}M.`   `(5.1)`

Define the tilded system analogously with `K_tilde,k_tilde,lambda_tilde,m_tilde,M_tilde` on the same `n` response rows `Y`.

Let `delta,q,d,y` be as in Section 4 and define

`a = ||H^{-1/2}M||_F`,

`z = ||H^{-1/2}(M_tilde-M)||_F`,

`e_m(u)=||m_tilde(u)-m(u)||_2`.

## `P15-RIDGEWHITENED-SOURCE-MEAN-46 — PROVED`

For every query `u`,

`||g_tilde(u)-g(u)||_2`
` <= e_m(u)`
` + a [d(u)+delta q(u)]/(1-delta)`
` + [q(u)+d(u)] z/(1-delta).`   `(5.2)`

### Proof

From `(5.1)`,

`g_tilde-g`
` = (m_tilde-m)`
` - [ k_tilde^T H_tilde^{-1}M_tilde - k^T H^{-1}M ].`

Insert and subtract `k_tilde^T H_tilde^{-1}M`:

`k_tilde^T H_tilde^{-1}M_tilde-k^T H^{-1}M`
` = [k_tilde^T H_tilde^{-1}M-k^T H^{-1}M]`
` + k_tilde^T H_tilde^{-1}(M_tilde-M).`

The first bracket is exactly the prediction perturbation `(4.1)` with `Y` replaced by `M`, hence at most

`a[d+delta q]/(1-delta)`.

For the second term,

`||H^{-1/2}k_tilde|| <= q+d`,

and

`||k_tilde^T H_tilde^{-1}(M_tilde-M)||`
` <= (q+d) z/(1-delta)`.

Adding `e_m` proves `(5.2)`.

### Interpretation

The three terms are distinct and observable in principle:

1. deployed query-time mean movement `e_m`;
2. representation/ridge movement acting on the old training-row mean labels `M`;
3. training-row mean-label movement `M_tilde-M` transported through the new correction.

This is more source-faithful than pretending that one cross-fitted function simultaneously generates all training rows and all query-time means.

# 8. Specialized double-KRR relative theorem

The previous runs solved the frozen same-response model in which a KRR mean is learned from the responses and residual KRR is then fitted to the **same responses**. The new relative geometry gives a sharper representation-transfer theorem for that benchmark.

Fix ridges `lambda,mu>0`. For one Gram matrix `K`, define

`R_lambda=(K+lambda I)^(-1)`,

`R_mu=(K+mu I)^(-1)`.

The zero-mean KRR comparator is

`b(u)=k(u)^T R_lambda Y`.

The KRR mean is `k^T R_mu Y`; the residual labels are

`Y-K R_mu Y = mu R_mu Y`.

Hence the same-response corrected predictor is exactly

`f(u)=k(u)^T [ R_mu + mu R_lambda R_mu ] Y`.   `(8.1)`

Let the second representation use `K_tilde,k_tilde` with the same ridges and responses. Put

`r=min(lambda,mu)`,

`H=K+rI`,

`S=H^{-1/2}(K_tilde-K)H^{-1/2}`,

`delta=||S||<1`,

`q=||H^{-1/2}k||`,

`d=||H^{-1/2}(k_tilde-k)||`,

`y=||H^{-1/2}Y||_F`.

## `P15-RIDGEWHITENED-DOUBLEKRR-46 — PROVED`

For every query,

`||b_tilde-b|| <= y[d+delta q]/(1-delta)`.   `(8.2)`

Moreover

`||f_tilde-f||`
` <= y { [d+delta q]/(1-delta)`
` + [mu/(r(1-delta)^2)] [ d + delta(2-delta)q ] }.`   `(8.3)`

### Proof of the product term

For any `c>=r`, write

`M_c = I + (c-r)H^{-1}`.

Then

`R_c = H^{-1/2} M_c^{-1} H^{-1/2}`

and

`R_c_tilde = H^{-1/2}(M_c+S)^{-1}H^{-1/2}`.

Because `M_c>=I`,

`||M_c^{-1}||<=1`,

`||(M_c+S)^{-1}||<=1/(1-delta)`,

and

`||(M_c+S)^{-1}-M_c^{-1}||<=delta/(1-delta)`.

The product obeys

`R_lambda R_mu`
` = H^{-1/2} M_lambda^{-1} H^{-1} M_mu^{-1} H^{-1/2}`.

For the tilded product the two `M^{-1}` factors are replaced by `(M+S)^{-1}`. Since `||H^{-1}||<=1/r`, the query-movement part is at most

`d y/[r(1-delta)^2]`.

For the operator movement, telescope the two middle factors. The first difference costs

`delta/[r(1-delta)^2]`

and the second

`delta/[r(1-delta)]`.

Their sum is

`delta(2-delta)/[r(1-delta)^2]`.

Multiplying by `q y` and then by `mu` proves the second term of `(8.3)`.

### Same-observation margin transfer

For either root squared risk or the mean-relative metric, a positive reference double-KRR gain survives whenever the corresponding integral of the movement debt from `(8.2)--(8.3)` is smaller than the reference margin.

This theorem is again pathwise: `K_tilde,k_tilde` may have been trained from exactly the same responses later reused by the mean and residual correction.

# 9. Effective dimension and spectral interpretation

The new theorem interfaces cleanly with the kernel spectral quantities studied in current KRR/RFRR theory.

Assume the **normalized** kernel convention and a diagonal bound

`k0(u,u) <= kappa^2`.

Let `K=K_raw/n` and `k(u)=k_raw(X,u)/n`. Define

`Q = E[k(U)k(U)^T]`.

The standard RKHS covariance inequality gives, in normalized coordinates,

`Q <= (kappa^2/n) K`.   `(9.1)`

For `H_r=K+rI`, define the ridge leverage

`q_r(U)=||H_r^{-1/2}k(U)||`.

Then

`E q_r(U)^2`
` = tr(H_r^{-1}Q)`
` <= (kappa^2/n) tr[H_r^{-1}K]`
` = kappa^2 d_eff(r)/n`,   `(9.2)`

where

`d_eff(r)=tr[K(K+rI)^(-1)]`.

Thus

`||q_r||_L2 <= kappa sqrt(d_eff(r)/n)`.   `(9.3)`

This is substantially sharper than the crude pointwise estimate `||k||/sqrt(r)` when `d_eff(r)<<n`.

If

`D_r^2 = E ||H_r^{-1/2}(k_tilde(U)-k(U))||^2`,

then `(4.1)` gives the integrated bound

`||b_tilde-b||_L2`
` <= y_r [ D_r + delta_r kappa sqrt(d_eff(r)/n) ]/(1-delta_r)`,   `(9.4)`

where

`y_r=||H_r^{-1/2}Y||_F`.

## `P15-RIDGEWHITENED-EFFDIM-46 — PROVED`

Equation `(9.4)` is the effective-dimension version of the learned-representation transfer theorem.

### Interaction with the preceding finite-width feature theorem

The previous run proved, for a normalized dot-product feature kernel and bounded cumulative first-layer path,

`||K_T-K_0||_op <= E_T`,

`sqrt(n)||k_T(u)-k_0(u)|| <= E_T`.

The crude implications are

`delta_r <= E_T/r`,

`D_r <= E_T/sqrt(n r)`.

If the feature path has `E_T=O_P(n^-1/2)`, response RMS is bounded, and

`d_eff(r_n)=O_P(n^zeta)`,

then the Gram-relative part of `(9.4)` has worst-case order

`O_P( n^((zeta-1)/2) r_n^(-3/2) )`,

while the direct query-movement part has order `O_P(n^-1/2 r_n^-1)`.

For a ridge sequence `r_n ~ n^-a`, a sufficient worst-case condition for the baseline representation movement to vanish is

`a < 1/2` and `3a + zeta < 1`.   `(9.5)`

For bounded effective dimension (`zeta=0`), this permits `a<1/3`, sharper than the `a<1/4` condition produced by the previous pointwise `1/r^2` bound. This is a **sufficient transfer rate**, not a claim of universal sharpness.

For the double-KRR theorem an additional factor `mu/r` appears; when the two ridge scales remain comparable, the same rate applies up to constants. If `mu/r` diverges, the condition must be strengthened accordingly.

This gives a concrete high-dimensional bridge from learned-feature movement to spectral effective dimension rather than relying only on training-Gram ESD convergence.

# 10. Exact counterexample: absolute closeness can hide a mean-relative sign flip

## `P15-SHRINKINGRIDGE-MEANREL-SIGNFLIP-46 — DISPROVED route`

A tempting statement is:

> If two learned kernels and their fresh-query vectors converge in absolute norm, then the sign of the same-observation mean-correction gain must eventually agree.

This is false when the ridge scale shrinks at the same time.

Let

`X,U iid in {-1,+1}`

be Rademachers. The deterministic target is

`G(u)=17/40 + u`.

There is one training observation, with response

`Y=17/40 + X`.

For every `eps>0` and amplitude parameter `a>0`, use the valid linear kernel

`k_a(u,v)=a eps u v`.

Thus the one-point training Gram is

`K_a=[a eps]`

and the fresh-query kernel scalar is

`k_a(U,X)=a eps U X`.

Use correction ridge

`lambda=3 eps`

and KRR-mean ridge

`mu=eps/2`.

The zero-mean KRR comparator is

`b_a(U)=h_a U X Y`,

with

`h_a=a/(a+3)`.

The same-response KRR-mean-plus-residual-KRR predictor is

`f_a(U)=t_a U X Y`,

where the exact double-KRR filter gives

`t_a = a(a+3+1/2)/[(a+1/2)(a+3)]`.

For `a=1`,

`h_1=1/4`,

`t_1=3/4`.

A direct enumeration of the four pairs `(X,U)` gives

`R_rel(b_1)=911/1311`,

`R_rel(f_1)=1797/3496`,

and therefore

`Gamma_rel(1)=1897/10488 > 0`.   `(10.1)`

For `a=2`,

`h_2=2/5`,

`t_2=22/25`.

The same four-case enumeration gives

`R_rel(b_2)=671/1311`,

`R_rel(f_2)=33853/65550`,

so

`Gamma_rel(2)=-101/21850 < 0`.   `(10.2)`

Thus the structured mean plus residual correction helps for `a=1` and hurts for `a=2`, even though the mean and correction in both systems are trained on the **same deterministic response**.

Yet

`||K_2-K_1||_op = eps -> 0`

and, for every `(U,X)`,

`|k_2(U,X)-k_1(U,X)| = eps -> 0`.

Absolute Gram/query convergence therefore does not preserve the gain sign.

The ridge-relative geometry correctly detects the problem. For the mean ridge `mu=eps/2`, the reference matrix is

`H_mu = eps + eps/2 = 3eps/2`,

while the Gram perturbation is `eps`; hence

`delta_mu = eps/(3eps/2)=2/3`,

which does **not** tend to zero.

The counterexample is noiseless in the source sense: `Y=G(X)` exactly. The sign reversal comes from deterministic misspecification of the linear kernel, which cannot represent the constant component `17/40`, together with same-response reuse and a collapsing ridge scale.

This strengthens the inherited warning that training-Gram convergence alone is not enough: even simultaneous absolute Gram **and** query convergence is insufficient unless it is measured relative to the inverse problem's ridge/spectral scale.

### Why this theorem is useful at the July ridge grid

The historical grid includes `lambda=10^-7`. An absolute bound containing `1/lambda^2` can be vacuous even when the prediction is stable because perturbations along high-eigenvalue directions are over-penalized. The dimensionless quantity

`delta = ||(K+n lambda I)^(-1/2) [Delta K + n Delta lambda I] (K+n lambda I)^(-1/2)||`

measures exactly whether the learned/selected system is close **relative to the regularized inverse problem**.

This quantity can be estimated by generalized eigenvalue / power iteration without forming an explicit inverse. The query terms require triangular solves with the same Cholesky factor already used by KRR. Thus the new certificate is computationally aligned with the source solver.

`Feature Learning in Linear-Width Two-Layer Networks: Two vs. One Step of Gradient Descent` studies two-layer networks where hidden width `N`, sample size `n`, and input dimension grow proportionally. The paper uses first-layer step sizes
