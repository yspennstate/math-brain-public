# 0. Executive result

P15 remains **OPEN**, but this run converts the preceding Bernoulli-refresh interpolation into an exact **fixed-cardinality overlap calculus**. This is closer to practical cross-fitting/retraining experiments because one can replace exactly `r` complete observations, preserve the sample size, preserve fold/validation roles, and compare two learners with a controlled exact overlap.

The fixed-population identity remains strictly in its original scope:

\[
\boxed{
B(\lambda)=\sum_j\left[\frac{\lambda}{\lambda_j+\lambda}\right]^2r_j^2,
\qquad r=f^\star-m.
}
\tag{0.1}
\]

It is a fixed-mean, fixed-kernel population ridge-bias identity and is **not** promoted to a theorem for a mean, representation, or correction learned from the same observations.

Let the iid training sample be

\[
S=(Z_1,\ldots,Z_n),
\]

where for the deterministic structural-mechanics source the correct observation is the complete pair

\[
Z_i=(U_i,G(U_i)).
\]

Write the uncorrected complete learner as `B_S`, and the corrected learner as

\[
F_S=B_S+G_S,
\]

where `G_S` is the **entire correction increment relative to the uncorrected learner**. Thus `G_S` may contain a neural mean, learned representation, optimizer/checkpoint effects, validation-selected stacking, kernel-family/ridge selection, and residual KRR. No differentiability or fixed-representation assumption is imposed in the main results below.

For an integer `r in {0,...,n}`, choose a set `R subset [n]` uniformly among the `r`-subsets, independently of the data, and replace exactly those coordinates by iid copies `Z_i'`. Denote the resulting sample by

\[
S^{\langle r\rangle}.
\]

Thus `r=0` is full same-observation reuse and `r=n` is the independent ghost. Put `m=n-r` for the exact number of retained observations.

If

\[
B-EB=\sum_{A\ne\varnothing}B_A,
\qquad
G-EG=\sum_{A\ne\varnothing}G_A
\]

are the Hilbert-valued Hoeffding decompositions, define

\[
c_A=E\langle B_A,G_A\rangle,
\qquad
e_A(F)=E\|F_A\|^2.
\]

For an interaction of order `k=|A|`, the probability that all of its coordinates survive the exact-`r` refresh is

\[
\boxed{
\theta_{r,k}
=
\frac{\binom{n-k}{r}}{\binom nr}
=
\frac{(n-r)_k}{(n)_k}
=
\frac{\binom{m}{k}}{\binom nk},
}
\tag{0.2}
\]

with the convention `theta_{r,k}=0` for `k>m`.

The first new theorem is:

## `P15-FIXEDOVERLAP-DIAGONALIZATION-36` — PROVED

For arbitrary square-integrable Hilbert-valued learners,

\[
\boxed{
E\langle B_S-EB,\,G_{S^{\langle r\rangle}}-EG\rangle
=
\sum_A\theta_{r,|A|}c_A,
}
\tag{0.3}
\]

and

\[
\boxed{
D_r^{\rm fix}(F)
:=E\|F_S-F_{S^{\langle r\rangle}}\|^2
=
2\sum_A(1-\theta_{r,|A|})e_A(F).
}
\tag{0.4}
\]

For fresh squared risk

\[
R_r^{\rm fix}
:=
E\|Y-B_S(U)-G_{S^{\langle r\rangle}}(U)\|^2,
\]

one has

\[
\boxed{
R_r^{\rm fix}-R_{\rm ghost}
=
2\sum_A\theta_{r,|A|}c_A,
}
\tag{0.5}
\]

and therefore

\[
\boxed{
R_{\rm same}-R_r^{\rm fix}
=
H_r^{\rm fix}(B,G)
:=
2\sum_A(1-\theta_{r,|A|})c_A.
}
\tag{0.6}
\]

Equivalently,

\[
H_r^{\rm fix}(B,G)
=
E\langle B_S-B_{S^{\langle r\rangle}},
          G_S-G_{S^{\langle r\rangle}}\rangle.
\tag{0.7}
\]

Hence, if `Gamma_r=R(B)-R_r^fix`, then

\[
\boxed{
\Gamma_{\rm same}
=
\Gamma_r-H_r^{\rm fix}(B,G),
}
\tag{0.8}
\]

and by Cauchy--Schwarz

\[
\boxed{
\Gamma_{\rm same}
\ge
\Gamma_r-
\sqrt{D_r^{\rm fix}(B)D_r^{\rm fix}(G)}.
}
\tag{0.9}
\]

This is an exact finite-sample same-observation theorem. It permits the mean, representation, optimization, selection, and correction to use the **same sample**; all of that dependence is absorbed into `B_S,G_S`.

The second main theorem makes the fixed-overlap path experimentally useful.

## `P15-FIXEDOVERLAP-BINOMIAL-INVERSION-36` — PROVED

Aggregate the interaction covariances by order,

\[
c_k=\sum_{|A|=k}c_A.
\]

Let

\[
Q_m
:=
\frac12\left(R_{n-m}^{\rm fix}-R_n^{\rm fix}\right),
\qquad m=0,1,\ldots,n.
\tag{0.10}
\]

Then

\[
\boxed{
Q_m
=
\sum_{k=1}^m
\frac{\binom mk}{\binom nk}c_k.
}
\tag{0.11}
\]

This triangular system has the exact binomial inverse

\[
\boxed{
 c_k
=
\binom nk
\sum_{m=0}^k
(-1)^{k-m}\binom km Q_m.
}
\tag{0.12}
\]

In particular,

\[
\boxed{c_1=nQ_1,}
\tag{0.13}
\]

\[
\boxed{c_2=\binom n2(Q_2-2Q_1),}
\tag{0.14}
\]

and

\[
\boxed{c_3=\binom n3(Q_3-3Q_2+3Q_1).}
\tag{0.15}
\]

Thus the low-order same-observation interaction spectrum can be recovered exactly from fixed-overlap replica risks near the independent-ghost endpoint, without explicitly enumerating every one-, two-, or three-coordinate mixed replacement tensor.

There is an analogous inversion for self-energy. If

\[
e_k(F)=\sum_{|A|=k}e_A(F),
\qquad
V(F):=E\|F_S-F_{S'}\|^2=2\sum_{k\ge1}e_k(F),
\]

then

\[
W_m(F)
:=
\frac12\left[V(F)-D_{n-m}^{\rm fix}(F)\right]
=
\sum_{k=1}^m
\frac{\binom mk}{\binom nk}e_k(F),
\tag{0.16}
\]

and therefore

\[
\boxed{
 e_k(F)
=
\binom nk
\sum_{m=0}^k(-1)^{k-m}\binom km W_m(F).
}
\tag{0.17}
\]

This identifies a concrete two-replica route to the interaction spectrum that a high-dimensional random-feature theorem could target.

The third main result is a shape theorem for the self-distance path.

## `P15-FIXEDOVERLAP-CONCAVITY-36` — PROVED

For every nonempty interaction `A` of size `k`, define the hit probability

\[
h_{r,k}=1-\theta_{r,k}
=P\{R\cap A\ne\varnothing\}.
\]

Then `r -> h_{r,k}` is nondecreasing and discretely concave. Indeed,

\[
\boxed{
 h_{r+1,k}-h_{r,k}
=
\theta_{r,k}\frac{k}{n-r}
=
\frac{k(n-r-1)_{k-1}}{(n)_k},
}
\tag{0.18}
\]

which decreases in `r`. Hence `r -> D_r^fix(F)` is nondecreasing and discretely concave.

More directly, because a fixed nonempty interaction is hit with probability at least the chance of hitting any one designated coordinate and at most the union bound over its coordinates,

\[
\frac rn
\le
h_{r,k}
\le
\frac{rk}{n}.
\tag{0.19}
\]

Therefore

\[
\boxed{
V(F)
\le
\frac nrD_r^{\rm fix}(F)
\le
D_1^{\rm repl}(F),
\qquad r\ge1,
}
\tag{0.20}
\]

where

\[
D_1^{\rm repl}(F)
:=
\sum_{i=1}^nE\|F_S-F_{S^{(i)}}\|^2
=
2\sum_A|A|e_A(F).
\]

So an exact-`r` block refresh supplies a valid full-ghost stability certificate, and it can be strictly tighter than the first-order Efron budget.

For the source's actual unsquared mean-relative metric, let

\[
\|h\|_{w,2}^2
=
E_{U,Y}\frac{\|h(U)\|^2}{\|Y\|^2}
\]

whenever finite, and define `D_r^{fix,w}(G)` analogously. Then:

## `P15-FIXEDOVERLAP-MEANREL-36` — PROVED

\[
\boxed{
|R_{\rm rel,same}-R_{\rm rel,r}^{\rm fix}|
\le
\sqrt{D_r^{\rm fix,w}(G)}.
}
\tag{0.21}
\]

Consequently, if the exact-`r` overlap benchmark beats uncorrected KRR by mean-relative margin `Gamma_rel,r`, then the actual same-observation corrected learner also beats it whenever

\[
\boxed{
\Gamma_{\rm rel,r}>\sqrt{D_r^{\rm fix,w}(G)}.
}
\tag{0.22}
\]

Moreover,

\[
\boxed{
V_G^w
:=E\|G_S-G_{S'}\|_{w,2}^2
\le
\frac nrD_r^{\rm fix,w}(G)
\le
D_1^{w,{\rm repl}}(G).
}
\tag{0.23}
\]

As in prior runs, source use of this weighted Hilbert norm is **CONDITIONAL** because the manuscript supplies no positive population lower bound on `||G(U)||`. The already-proved truncation/small-output route remains the correct fallback; no denominator lower bound is invented.

A role-preserving version is also exact.

## `P15-STRATIFIED-FIXEDOVERLAP-36` — PROVED

Partition the sample positions into fixed algorithmic roles `g=1,...,J`, of sizes `n_g`. In role `g`, replace exactly `r_g` coordinates, uniformly without replacement and independently across roles. For an interaction `A`, put `a_g=|A cap I_g|`. Its survival coefficient is

\[
\boxed{
\Theta_A
=
\prod_{g=1}^J
\frac{(n_g-r_g)_{a_g}}{(n_g)_{a_g}}.
}
\tag{0.24}
\]

Every formula `(0.3)`--`(0.9)` remains valid with `theta` replaced by `Theta_A`. If

\[
p_*:=\min_g r_g/n_g>0,
\]

then every nonempty interaction is hit with probability at least `p_*`, so

\[
\boxed{
E\|F_S-F_{S'}\|^2
\le
\frac{D_{\mathbf r}^{\rm strat}(F)}{p_*}.
}
\tag{0.25}
\]

If one data-dependent role has `r_g=0`, interactions supported entirely inside that role are invisible and no full-ghost certificate follows. This point is directly relevant to the mechanics source: a source-faithful experiment must refresh a positive fraction of the **validation rows as well as fitting/fold rows** if it is intended to certify the whole selected pipeline. Merely refreshing fitting rows cannot price validation-selected stacking/kernel/ridge interactions.

The fixed-cardinality and preceding Bernoulli paths are related but not identical.

## `P15-FIXED-v-BERNOULLI-36` — PROVED

Take `p=r/n`, `q=1-p`, and compare exact-`r` refreshing with independent Bernoulli refreshing at rate `p`. For interaction order `k`,

\[
\theta_{r,k}
=
\prod_{j=0}^{k-1}\frac{n-r-j}{n-j}
\le
q^k.
\tag{0.26}
\]

Therefore the exact-count design decorrelates every higher-order interaction at least as strongly as the Bernoulli design with the same marginal refresh rate:

\[
\boxed{
D_r^{\rm fix}(F)\ge D_p^{\rm Bern}(F).
}
\tag{0.27}
\]

There is **no universal risk ordering**, because risk uses the signed coefficients `c_A` rather than the nonnegative energies `e_A`.

For low interaction order there is a finite-`n` equivalence. If `k<=m=n-r`, then

\[
0\le
q^k-\theta_{r,k}
\le
\frac{p q^{k-1}k(k-1)}{2(n-k+1)}.
\tag{0.28}
\]

Hence, if both learners have Hoeffding degree at most `d<=m`, putting

\[
\varepsilon_{n,d,p}
=
\frac{p d(d-1)}{2(n-d+1)},
\]

one gets

\[
\boxed{
0\le D_r^{\rm fix}(F)-D_p^{\rm Bern}(F)
\le
\varepsilon_{n,d,p}\,V(F),
}
\tag{0.29}
\]

and

\[
\boxed{
|R_r^{\rm fix}-R_p^{\rm Bern}|
\le
2\varepsilon_{n,d,p}
\sqrt{\operatorname{Var}_{\mathcal H}(B)
      \operatorname{Var}_{\mathcal H}(G)}.
}
\tag{0.30}
\]

Thus for bounded interaction degree `d=o(sqrt(n))`, fixed-cardinality and Bernoulli overlap deterministic equivalents are asymptotically interchangeable at fixed `p`, while high-order interactions remain a separate tail obligation.

The signed risk path has an exact monotonicity criterion.

## `P15-OVERLAP-MONOTONICITY-36` — PROVED

Let

\[
c_k=\sum_{|A|=k}c_A.
\]

For Bernoulli refresh,

\[
R_p^{\rm Bern}
=
R_{\rm ghost}+2\sum_{k=1}^n c_k(1-p)^k,
\]

so

\[
\boxed{
\frac{d}{dp}R_p^{\rm Bern}
=-2\sum_{k=1}^n k(1-p)^{k-1}c_k.
}
\tag{0.31}
\]

For fixed-count refresh,

\[
\boxed{
R_{r+1}^{\rm fix}-R_r^{\rm fix}
=
-2\sum_{k\ge1}
\theta_{r,k}\frac{k}{n-r}c_k.
}
\tag{0.32}
\]

Therefore:

- if all `c_k>=0`, increasing independence monotonically **reduces** squared risk;
- if all `c_k<=0`, increasing independence monotonically **increases** squared risk;
- with mixed signs, neither direction is universal.

There is a finite-sample sufficient certificate using the inherited Efron interaction slacks

\[
\mathfrak s(B)=\sum_{k\ge2}(k-1)e_k(B),
\qquad
\mathfrak s(G)=\sum_{k\ge2}(k-1)e_k(G).
\]

Writing `c_1` for the singleton interaction covariance, for `q=1-p`,

\[
\left|
\sum_{k\ge2}kq^{k-1}c_k
\right|
\le
2q\sqrt{\mathfrak s(B)\mathfrak s(G)}.
\tag{0.33}
\]

Hence if

\[
\boxed{
c_1>2\sqrt{\mathfrak s(B)\mathfrak s(G)},}
\tag{0.34}
\]

Bernoulli cross-fitting is monotone risk-improving over the entire path, while the reverse strict inequality

\[
\boxed{
c_1<-2\sqrt{\mathfrak s(B)\mathfrak s(G)}}
\tag{0.35}
\]

makes it monotone risk-worsening. More locally, `2q sqrt(s_B s_G)` is the exact sufficient remainder budget at overlap `q`.

The singleton coefficient itself has a simple fixed-overlap identification:

\[
\boxed{
 c_1
=
\frac n2\left(R_{n-1}^{\rm fix}-R_n^{\rm fix}\right).
}
\tag{0.36}
\]

Thus the direction of the path near the independent ghost can be measured without computing gradients or differentiating a selected neural pipeline.

The previous nonmonotonicity counterexample becomes even sharper under exact-count overlap.

Let `Z_1,Z_2` be iid Rademacher, let the fresh scalar target be deterministic `t` with

\[
t^2=51/10,
\]

and define

\[
B=Z_1+Z_1Z_2,
\qquad
G=t+Z_1-2Z_1Z_2.
\]

The uncorrected risk is

\[
R(B)=71/10=7.1.
\]

The interaction-order covariances are

\[
c_1=1,
\qquad
c_2=-2,
\]

and the independent ghost risk is `R_2^fix=7`. Therefore

\[
R_0^{\rm fix}=7+2(c_1+c_2)=5,
\]

while refreshing **exactly one** of the two training observations gives

\[
R_1^{\rm fix}
=7+2\left(\frac12c_1+0\cdot c_2\right)
=8.
\]

So

\[
\boxed{
R_0^{\rm fix}=5<7.1,
\qquad
R_2^{\rm fix}=7<7.1,
\qquad
R_1^{\rm fix}=8>7.1.
}
\tag{0.37}
\]

Both full reuse and full independence improve on the uncorrected learner, but the 50%-overlap learner is strictly worse than all of them. Thus **fixed-size cross-fitting/refreshing is not a monotone interpolation either**.

For the fixed-design stochastic-response KRR benchmark, the new fixed-count theory collapses exactly to the first interaction order. If

\[
B(u)=k(u,X)(K+n\lambda I)^{-1}Y

with design, kernel and ridge fixed and only independent response rows random, `B` is additive in the responses. Therefore only `c_1` can match the baseline in the Hoeffding covariance, and

\[
\boxed{
R_r^{\rm fix}-R_{\rm ghost}
=
2\left(1-\frac rn\right)c_1,
}
\tag{0.38}
\]

so

\[
\boxed{
R_{\rm same}-R_r^{\rm fix}
=
\frac rn(R_{\rm same}-R_{\rm ghost}).

\tag{0.39}

This is a useful exact benchmark but **does not describe the deterministic mechanics source under complete-pair replacement**, because changing `U_i` changes the learned mean, representation, Gram matrix, fresh query vector and selected branch.

# 4. Proof of `P15-FIXEDOVERLAP-DIAGONALIZATION-36`

Let `O=[n]\setminus R` be the retained index set, `|O|=m=n-r`. Conditional on `O`, the mixed sample uses `Z_i` for `i in O` and an independent copy `Z_i'` for `i notin O`.

For Hoeffding components `B_A,G_C`, if `A != C`, choose a coordinate in the symmetric difference. One factor depends on that coordinate through a centered Hoeffding component while the other factor does not depend on the same original variable; integrating that coordinate gives zero. Hence only `A=C` can contribute.

For `A=C`, if any coordinate of `A` is refreshed, the corresponding coordinate in `G_A(S^{<r>})` is an independent copy. Centering in that coordinate again makes the cross expectation zero. If every coordinate in `A` is retained, the two components use the same arguments and contribute exactly `c_A`. Therefore

\[
E\langle B_A(S),G_A(S^{\langle r\rangle})\rangle
=P\{A\subset O\}c_A
=\theta_{r,|A|}c_A.
\]

Summing over interactions proves `(0.3)`.

Because `S` and `S^{<r>}` have the same marginal law,

\[
E\|F_S-F_{S^{\langle r\rangle}}\|^2
=2E\|F-EF\|^2
-2E\langle F_S-EF,F_{S^{\langle r\rangle}}-EF\rangle,
\]

which gives `(0.4)`.

For fresh squared risk, all terms involving only the fresh test pair or only one learner marginal are independent of `r`; the only changing term is the baseline/correction covariance. Hence `(0.5)` and `(0.6)`. Applying the same decomposition jointly to `B` and `G` gives `(0.7)`, and Hilbert-space Cauchy--Schwarz gives `(0.9)`.

No step assumes that the algorithm is smooth, linear, kernel-only, or representation-independent.

# 5. Proof of the binomial inversion

With `m=n-r`, `(0.5)` gives

\[
Q_m
=
\sum_{k=1}^m
\frac{(m)_k}{(n)_k}c_k
=
\sum_{k=1}^m
\frac{\binom mk}{\binom nk}c_k.
\]

Set

\[
a_k=c_k/\binom nk.
\]

Then

\[
Q_m=\sum_{k=0}^m\binom mk a_k,
\qquad a_0=0.
\]

Ordinary binomial inversion gives

\[
a_k
=
\sum_{m=0}^k(-1)^{k-m}\binom km Q_m,
\]

which is `(0.12)`. The self-energy formula is identical after replacing `c_k` by `e_k(F)` and replacing cross covariance by the surviving self covariance.

A practical implication is that low-order interaction coefficients can be identified from a small collection of **fixed-overlap replica experiments**, rather than by explicitly computing every subset-specific finite difference. Statistical efficiency of such an estimator is a separate question and remains open for the source.

# 6. Exact-count versus Bernoulli overlap

At equal marginal refresh rate `p=r/n`, `q=1-p`, the Bernoulli path retains every coordinate independently and therefore preserves a `k`-way interaction with probability `q^k`. Exact-count refreshing preserves it with

\[
\theta_{r,k}
=
\prod_{j=0}^{k-1}\frac{qn-j}{n-j}.
\]

Every nonzero factor is at most `q`, so `theta_{r,k}<=q^k`. This proves `(0.27)`.

For `k<=m`, write

\[
a_j=\frac{qn-j}{n-j}.
\]

Then

\[
q-a_j=\frac{pj}{n-j}.
\]

A telescoping product inequality, using `0<=a_j<=q`, gives

\[
0\le q^k-\prod_{j=0}^{k-1}a_j
\le
q^{k-1}\sum_{j=0}^{k-1}(q-a_j)
\le
\frac{p q^{k-1}k(k-1)}{2(n-k+1)}.
\]

This proves `(0.28)` and the bounded-degree corollaries `(0.29)`--`(0.30)` by summing energies/covariances and using Cauchy--Schwarz.

This calculation is useful in high dimension: the Bernoulli overlap path from the preceding run and the fixed-count path here differ only by a finite-population correction of order `k^2/n` at interaction order `k`.

# 9. Current primary-literature checks

Fresh literature checks were made for hypotheses relevant to the high-dimensional route.

1. **Misiakiewicz--Saeed, non-asymptotic KRR deterministic equivalents.** Their theory concerns KRR with iid data under explicit spectral and concentration properties of the kernel eigendecomposition; the deterministic approximation depends on the kernel spectrum and target alignment. It does not supply a theorem for an arbitrary response-trained representation/mean/selection pipeline.

2. **Defilippis--Loureiro--Misiakiewicz, random-feature ridge deterministic equivalents.** Their dimension-free RFRR result assumes a feature-concentration property and yields test-error equivalents depending on feature-map eigenvalues. Again, it is not a same-observation learned-feature theorem.

3. **Moniri--Hassani (May 2026), two-step feature learning in linear-width two-layer networks.** This is especially relevant because it explicitly distinguishes independent versus reused batches and proves that batch reuse can reveal target directions that independent batches cannot in their controlled two-step model. It independently supports the P15 conclusion that sample reuse has no universal penalty sign. But the paper analyzes a specified early-training regime, not the source's arbitrary multi-epoch learned mean/representation/selection pipeline.

4. Current cross-fitting literature continues to use sample splitting to remove own-observation effects in nuisance estimation, but its guarantees are tied to specific orthogonal estimating equations or stability assumptions. Those results do not imply that predictive risk must improve monotonically as overlap decreases. The exact counterexamples in P15 therefore do not conflict with standard cross-fitting theory; they address a different predictive-risk functional without an orthogonality structure that forces a sign.

The high-dimensional open problem should consequently be stated as a **two-replica learned-feature overlap deterministic equivalent**: two complete training pipelines share exactly a fraction `q` of their iid observations, and one must compute the resulting baseline/correction cross covariance or prediction self-distance, including learned feature and selection effects. Ordinary one-replica Gram laws are insufficient.

\qquad \lambda\ge q>0,

## Independent derivation

Any eigenray with positive multiplier has a representative `x>=0`. Let `S=supp(x)`, `|S|=s`; then the ray conditions are exactly

\[
W_{SS}x_S=\lambda x_S,
\qquad
W_{S^c,S}x_S\le0.
\]

With probability one, every principal Gaussian block has simple real eigenvalues and no eigenvector has a zero coordinate. For a fixed real eigenvalue of `W_SS`, diagonal sign conjugation of the Ginibre block acts transitively on the `2^(s-1)` eigenvector sign classes modulo global sign while preserving the eigenvalue. Therefore the expected fraction whose eigenvector is sign-definite is exactly `2^{-(s-1)}`.

\[
2^{-(s-1)}2^{-(N-s)}=2^{-(N-1)}
\]

per support. Scaling `W_SS=sqrt(alpha/N) G_s` sends the threshold `lambda>=q` to the Ginibre threshold `q sqrt(N/alpha)`. Summing over the `binom Ns` supports proves the claim.

# 11. Counterexamples and failed routes retained

The following routes remain **DISPROVED / REPAIRED** and must not silently re-enter the argument:

1. **Naive monotonic improvement:** fitting a structured mean and then KRR on the same responses does not universally improve over uncorrected KRR.
2. **Universal same-response covariance tax:** under anisotropic covariance the same-response covariance interaction can have either sign.
3. **Cross-fitting always dominates same-sample reuse:** explicit finite-sample and fresh-input counterexamples reverse the sign.
4. **More cross-fitting monotonically helps:** both Bernoulli and now exact-count overlap have explicit nonmonotone risk paths.
5. **OOF kernel weights imply a fully cross-fitted refiner:** false when pooled target centering or downstream supervised refitting reintroduces own-row response dependence.
6. **Full vectorized source leakage rank at most four:** repaired; only row-space rank is at most four, while the vectorized rank can be up to `4q`; the pooled/local contrast subspace is at most `3q`.
7. **Unconstrained generalized-eigen oracle remains exact under `0<=s<=1`:** false; the amplitude cap can bind.
8. **Training-design KRR contraction implies fresh-input stability:** false off design.
9. **Training Gram stability alone controls learned-representation prediction stability:** false; the fresh kernel vector can move by order one with identical training Gram matrix.
10. **Signed one-row replacement sum equals the total reuse debt for arbitrary pipelines:** false in the presence of higher-order interactions; Efron/Hoeffding slack is required.
11. **Pair-subtraction is automatically conservative for mean-relative transfer:** false; a pure three-way interaction gives a counterexample.
12. **Fixed-cardinality refresh is automatically monotone:** newly disproved by `(0.37)`.

These failures are constraints on any future high-dimensional theorem: its hypotheses must visibly kill or control the interaction mechanisms exhibited by the counterexamples.

# 13. Tests and adversarial checks

The new identities were checked algebraically in the following edge cases.

### `r=0`

`theta_{0,k}=1`, so `D_0^fix=0`, `R_0^fix=R_same`, and `H_0=0`.

### `r=n`

`theta_{n,k}=0` for every nonempty interaction, so `D_n^fix=V`, `R_n^fix=R_ghost`, and `H_n=R_same-R_ghost`.

### Order one

`theta_{r,1}=(n-r)/n=q`, exactly matching Bernoulli refresh. Hence fixed-count and Bernoulli overlap are identical whenever the relevant baseline/correction covariance is purely first order.

### Pure order two, `n=2`

At `r=1`, the order-two survival coefficient is zero while the order-one coefficient is `1/2`. This reproduces the exact nonmonotone counterexample `(0.37)` and confirms that without-replacement refresh suppresses higher interactions more strongly than Bernoulli refresh.

### Concavity

For `k=1`, the increments in `(0.18)` are constant `1/n`; for `k>=2` they strictly decrease until the interaction is certainly hit. Thus no sign error is hidden in the discrete-concavity argument.

### Finite-population comparison

At `k=1`, `(0.28)` has zero right side and exact equality `theta=q`. At fixed `k>=2` with `n->infinity`, the difference between `theta` and `q^k` is `O(k^2/n)`, consistent with sampling with versus without replacement.
