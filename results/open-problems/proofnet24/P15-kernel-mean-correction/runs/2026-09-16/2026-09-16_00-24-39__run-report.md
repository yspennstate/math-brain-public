# 0. Executive result

P15 remains **OPEN**, but this run sharpens the central same-observation comparison in a way that is both exact and source-relevant.

The previous run proved the coordinate-aligned replacement upper bound

\[
|R_{\rm same}-R_{\rm ghost}|
\le \sum_{i=1}^n a_i c_i,
\]

for arbitrary learned baseline and correction, even when the mean, representation, kernel, ridge parameter, checkpoint, stack, and correction are all learned or selected from the same observations.

This run identifies the **exact signed object** hidden behind that bound and quantifies precisely when replace-one effects recover the true reuse debt.

The strongest new claims are:

- `P15-HOEFFDING-REUSE-DECOMP-33 = PROVED`;
- `P15-SIGNED-PAIR-REPLACEMENT-33 = PROVED`;
- `P15-EFRON-SLACK-REUSE-33 = PROVED`;
- `P15-GHOST-SLACK-IMPROVEMENT-CERT-33 = PROVED`;
- `P15-FIXEDLINEAR-PAIR-EXACT-33 = PROVED`;
- `P15-PAIRREPLACE-SIGNFLIP-CE-33 = PROVED / COUNTEREXAMPLE`;
- `P15-SECONDORDER-SLACK-33 = PROVED`;
- `P15-BLOCK-EXCHANGE-PAIR-33 = PROVED`;
- `P15-RF-EFRONSLACK-REDUCTION-33 = PROVED REDUCTION / deterministic-equivalent step still CONDITIONAL`;
- `P15-AUDIT-P16-QUENCHED-INFO-33 = PASS`.

The principal exact identity is the Hilbert-valued Hoeffding/ANOVA decomposition

\[
\boxed{
R_{\rm same}-R_{\rm ghost}
=
2\sum_{\varnothing\neq A\subset[n]}
E\langle B_A,G_A\rangle .
}
\]

Here `B_A,G_A` are matching sample-interaction components of the uncorrected baseline and correction increment.

For independent replace-one copies `S^(i)`, define

\[
C_i
=
E\left\langle
B(S)-B(S^{(i)}),
G(S)-G(S^{(i)})
\right\rangle.
\]

Then

\[
\boxed{
C_i
=
2\sum_{A\ni i}E\langle B_A,G_A\rangle.
}
\]

Therefore the signed replace-one sum is generally **not** the exact reuse debt: an interaction involving `k` observations is counted `k` times rather than once. The discrepancy is controlled exactly by Efron--Stein interaction slack. Put

\[
\mathfrak s(F)
=
\frac12\sum_i E\|F(S)-F(S^{(i)})\|^2
-
E\|F-EF\|^2.
\]

Then

\[
\boxed{
\left|
(R_{\rm same}-R_{\rm ghost})-\sum_i C_i
\right|
\le
2\sqrt{\mathfrak s(B)\mathfrak s(G)}.
}
\]

Thus a ghost/cross-sample improvement margin can be transferred to the fully same-observation learner using **signed paired replacement effects plus a higher-order interaction penalty**, rather than the preceding absolute stability product.

This is strictly stronger when the learner is close to additive in the observations. In particular, for a fixed-design, fixed-kernel, fixed-ridge zero-mean KRR baseline, the baseline is linear in the response rows and has zero higher-order Hoeffding slack. Then

\[
\boxed{
R_{\rm same}-R_{\rm ghost}
=
\sum_i C_i
}
\]

**exactly**, even if the learned mean/correction is nonlinear in all response rows.

The source structural-mechanics simulator is deterministic conditional on its input, so that fixed-design stochastic-response specialization is retained only as a benchmark. The full product-sample theorem above, which replaces the complete pair `(U_i,G(U_i))`, is the correct source-level theorem.

A sharp counterexample shows why the slack is necessary. With two iid Rademacher observations,

\[
B=Z_1+Z_1Z_2,\qquad
G=Z_1-\frac34Z_1Z_2,
\]

the true reuse debt is

\[
R_{\rm same}-R_{\rm ghost}=\frac12>0,
\]

but

\[
C_1+C_2=-1<0.
\]

The signed replace-one sum has the **opposite sign**. Here

\[
\mathfrak s(B)=1,\qquad
\mathfrak s(G)=\frac9{16},
\]

and the new inequality is attained with equality:

\[
\left|\frac12-(-1)\right|
=
\frac32
=
2\sqrt{1\cdot\frac9{16}}.
\]

This directly falsifies the tempting route “measure signed replace-one cross-effects and call their sum the same-sample covariance debt” when both stages contain higher-order sample interactions, as response-trained representations and hard selected pipelines generally do.

The fixed-population identity remains in its correct scope:

\[
\boxed{
B(\lambda)
=
\sum_j
\left[
\frac{\lambda}{\lambda_j+\lambda}
\right]^2r_j^2,
\qquad
r=f^\star-m.
}
\]

It is spectral calculus for a fixed mean and fixed kernel. It is **not** relabeled as a theorem about learning the mean, representation, and correction from the same observations.

# 4. Comparison object and ghost benchmark

Let

\[
S=(Z_1,\dots,Z_n)
\]

be independent training observations and let `S'` be an independent iid copy.

Let `H=L^2(P_U;R^q)` be the Hilbert space of fresh-input prediction fields. The fresh target is independent of `S,S'`.

Write

\[
B=B(S)\in\mathcal H
\]

for the **uncorrected baseline learner** and

\[
F(S)=B(S)+G(S)
\]

for the corrected learner, where `G(S)` is the total prediction increment caused by the learned mean/correction pipeline relative to that baseline.

This formulation permits all of the following inside `B` and `G`:

- a neural mean trained on the same observations;
- response-trained features;
- hard validation-selected checkpoint/kernel/ridge parameters;
- stacking;
- raw-input KRR;
- deep-feature KRR;
- the full final correction.

For the representation-aware KRR comparison from the preceding run, one may take

\[
B_S(u)
=
B_S^{\rm KRR}(u)Y_S,
\qquad
B_S^{\rm KRR}(u)
=
k_S(u,X_S)(K_S+n\lambda_SI)^{-1},
\]

and

\[
G_S(u)
=
m_S(u)-B_S^{\rm KRR}(u)m_S(X_S).
\]

This is the same realized learned representation and selected ridge rule in the baseline and corrected predictor.

Define expected squared fresh risk

\[
R(H)=E\|Y^{\rm new}-H(U)\|^2.
\]

The same-sample and independent-ghost corrected risks are

\[
R_{\rm same}=R(B(S)+G(S)),
\]

\[
R_{\rm ghost}=R(B(S)+G(S')).
\]

The ghost object is an idealized independent-sample benchmark. It is not silently identified with practical `K`-fold cross-fitting, although cross-fitting is one way to reduce analogous dependence.

The inherited exact identity is

\[
\boxed{
D_{\rm reuse}
:=
R_{\rm same}-R_{\rm ghost}
=
E\langle B-B',G-G'\rangle_{\mathcal H}
=
2E\langle B-EB,G-EG\rangle_{\mathcal H}.
}
\tag{4.1}
\]

This run decomposes `(4.1)` exactly by sample interaction order.

# 5. `P15-HOEFFDING-REUSE-DECOMP-33` — exact interaction decomposition

## 5.1 Hilbert-valued Hoeffding decomposition

For every square-integrable `H`-valued function `F(S)`, the product structure of `S` gives the orthogonal Hoeffding decomposition

\[
F
=
EF+\sum_{\varnothing\neq A\subset[n]}F_A,
\tag{5.1}
\]

where `F_A` depends only on `Z_A=(Z_i)_{i in A}` and has zero conditional mean in every coordinate belonging to `A`.

For `A != C`,

\[
E\langle F_A,H_C\rangle_{\mathcal H}=0.
\tag{5.2}
\]

Apply this simultaneously to

\[
B=EB+\sum_{A\ne\varnothing}B_A,
\qquad
G=EG+\sum_{A\ne\varnothing}G_A.
\]

## 5.2 Exact reuse identity

By `(4.1)` and orthogonality,

\[
\begin{aligned}
D_{\rm reuse}
&=
2E\left\langle
\sum_A B_A,\sum_C G_C
\right\rangle\\
&=
\boxed{
2\sum_{\varnothing\neq A\subset[n]}
E\langle B_A,G_A\rangle.
}
\end{aligned}
\tag{5.3}
\]

This proves:

## `P15-HOEFFDING-REUSE-DECOMP-33` — PROVED

Same-observation reuse debt is generated **only by matching sample-interaction subsets** of the baseline and correction. Baseline sensitivity to one collection of observations and correction sensitivity to a disjoint interaction collection do not contribute to the exact covariance debt.

This strictly refines the preceding coordinate-aligned absolute stability view.

## 5.3 Interpretation

- `|A|=1`: first-order observation influence;
- `|A|=2`: pair interaction;
- larger `|A|`: higher-order algorithmic interaction induced by representation learning, optimization, stacking, selection, residual fitting, and their combinations.

A fully additive learner has only singleton components. A nonlinear learned representation can create higher-order terms even when the final KRR solve is linear conditional on that representation.

# 6. `P15-SIGNED-PAIR-REPLACEMENT-33` — exact replace-one formula

For each `i`, let `Z_i'` be an independent copy and let

\[
S^{(i)}
=
(Z_1,\dots,Z_{i-1},Z_i',Z_{i+1},\dots,Z_n).
\]

Define

\[
\Delta_iF
=
F(S)-F(S^{(i)}).
\tag{6.1}
\]

The signed paired replacement cross-effect is

\[
C_i
=
E\langle\Delta_iB,\Delta_iG\rangle_{\mathcal H}.
\tag{6.2}
\]

## 6.1 Exact formula

A Hoeffding component `F_A` is unchanged by replacement `i` if `i notin A`. If `i in A`, zero conditional mean in coordinate `i` gives the usual factor two.

Equivalently, expanding a paired replacement directly,

\[
E\langle\Delta_iB,\Delta_iG\rangle
=
2\Big(
E\langle B,G\rangle
-
E\langle B(S),G(S^{(i)})\rangle
\Big),
\]

and the mixed term retains precisely the matching Hoeffding components not containing `i`.

Therefore

\[
\boxed{
C_i
=
2\sum_{A\ni i}
E\langle B_A,G_A\rangle.
}
\tag{6.3}
\]

Summing over `i`,

\[
\boxed{
\sum_{i=1}^n C_i
=
2\sum_{A\ne\varnothing}
|A|\,E\langle B_A,G_A\rangle.
}
\tag{6.4}
\]

Compare `(6.4)` with the true debt `(5.3)`. The signed replacement sum overcounts a `k`-way interaction by factor `k`.

That observation is the starting point for the exact slack theorem.

# 7. `P15-EFRON-SLACK-REUSE-33` — exact higher-order correction

For a square-integrable Hilbert-valued learner `F(S)`, define its Efron--Stein slack

\[
\boxed{
\mathfrak s(F)
=
\frac12\sum_{i=1}^n
E\|\Delta_iF\|_{\mathcal H}^2
-
E\|F-EF\|_{\mathcal H}^2.
}
\tag{7.1}
\]

Efron--Stein gives `s(F)>=0`. Here the Hoeffding decomposition identifies it exactly.

Indeed,

\[
\frac12\sum_iE\|\Delta_iF\|^2
=
\sum_A |A|\,E\|F_A\|^2,
\]

whereas

\[
E\|F-EF\|^2
=
\sum_A E\|F_A\|^2.
\]

Hence

\[
\boxed{
\mathfrak s(F)
=
\sum_{A\ne\varnothing}
(|A|-1)E\|F_A\|^2.
}
\tag{7.2}
\]

Thus the Efron--Stein gap is exactly the energy in higher-order sample interactions, weighted by interaction order minus one.

Subtract `(5.3)` from `(6.4)`:

\[
\sum_iC_i-D_{\rm reuse}
=
2\sum_A(|A|-1)E\langle B_A,G_A\rangle.
\tag{7.3}
\]

Cauchy--Schwarz over the weighted interaction index gives

\[
\boxed{
\left|
D_{\rm reuse}-\sum_iC_i
\right|
\le
2\sqrt{\mathfrak s(B)\mathfrak s(G)}.
}
\tag{7.4}
\]

This is `P15-EFRON-SLACK-REUSE-33`.

## 7.1 Stronger than the preceding absolute product

The previous coordinate-aligned theorem gave

\[
|D_{\rm reuse}|
\le
\sum_i
\sqrt{E\|\Delta_iB\|^2}
\sqrt{E\|\Delta_iG\|^2}.
\tag{7.5}
\]

That remains valid and useful when only magnitudes are known.

The new result is potentially much sharper because it preserves the **sign** of the paired first-order cross-effects and pays a separate, explicit penalty only for higher-order interaction.

## 7.2 Improvement certificate

Let

\[
\Gamma_{\rm ghost}
=
R(B)-R_{\rm ghost}
\]

be the improvement of the independent-ghost corrected learner over the uncorrected baseline. Since

\[
\Gamma_{\rm same}
=
R(B)-R_{\rm same}
=
\Gamma_{\rm ghost}-D_{\rm reuse},
\]

`(7.4)` gives

\[
\boxed{
\Gamma_{\rm same}
\ge
\Gamma_{\rm ghost}
-
\sum_i C_i
-
2\sqrt{\mathfrak s(B)\mathfrak s(G)}.
}
\tag{7.6}
\]

Therefore:

## `P15-GHOST-SLACK-IMPROVEMENT-CERT-33` — PROVED

If

\[
\Gamma_{\rm ghost}
>
\sum_i C_i
+
2\sqrt{\mathfrak s(B)\mathfrak s(G)},
\tag{7.7}
\]

then the **fully same-observation corrected learner has strictly smaller expected fresh squared risk than the uncorrected learner**.

No fixed-representation, linear-mean, Gaussian-noise, or differentiability assumption is required for `(7.7)`. The only structural assumption is the product-sample model needed for Hoeffding/replace-one decomposition.

For the deterministic mechanics source, `Z_i=(U_i,G(U_i))` is the complete input/output pair. This is the relevant replacement unit.

# 8. `P15-FIXEDLINEAR-PAIR-EXACT-33` — exactness for fixed-response-linear KRR baseline

The higher-order correction disappears when one side of the covariance is additive in the observations.

## 8.1 General additive baseline

Suppose, conditional on exogenous information `X`,

\[
B
=
B_0+\sum_{i=1}^n L_i(Y_i)
\tag{8.1}
\]

for independent response rows `Y_i`, with fixed linear maps `L_i`.

Then `B_A=0` for every `|A|>=2`, so

\[
\mathfrak s(B)=0.
\]

Consequently `(7.4)` becomes the exact identity

\[
\boxed{
D_{\rm reuse}
=
\sum_{i=1}^n
E\langle\Delta_iB,\Delta_iG\rangle.
}
\tag{8.2}
\]

The correction `G` may remain an arbitrary nonlinear function of all responses.

## 8.2 Fixed-design KRR specialization

Conditional on fixed `X,K,lambda`,

\[
B(u)
=
k(u,X)(K+n\lambda I)^{-1}Y.
\tag{8.3}
\]

Write

\[
c(u)
=
(K+n\lambda I)^{-1}k(X,u).
\]

Then

\[
B(u)=\sum_i c_i(u)Y_i,
\]

so `(8.2)` applies exactly.

This is a stronger benchmark than merely upper-bounding the same-response debt by KRR leverage times mean stability.

If response row `i` is replaced independently,

\[
\Delta_iB(u)
=
c_i(u)(Y_i-Y_i').
\tag{8.4}
\]

If the centered row noise has covariance `Omega`, then

\[
E\|\Delta_iB\|_{\mathcal H}^2
=
2\,\operatorname{tr}\Omega\,
E_U c_i(U)^2.
\tag{8.5}
\]

Thus, with

\[
\gamma_i^2
=
E\|\Delta_iG\|_{\mathcal H}^2,
\]

Cauchy gives

\[
|D_{\rm reuse}|
\le
\sqrt{2\,\operatorname{tr}\Omega}
\sum_i
\|c_i\|_{L^2(P_U)}\gamma_i.
\tag{8.6}
\]

A second Cauchy step and the inherited exact power/leverage identity

\[
n\lambda\,\|c(U)\|_2^2
=
P_\lambda(U)^2-\widetilde P_\lambda(U)^2
\tag{8.7}
\]

recover the earlier global fixed-kernel leverage bound.

# 9. `P15-PAIRREPLACE-SIGNFLIP-CE-33` — signed replacement can have the wrong sign

\[

\qquad

\tag{9.1}

Both have mean zero.

The matching Hoeffding components are:

\[
B_{\{1\}}=Z_1,
\qquad
B_{\{1,2\}}=Z_1Z_2,
\]

\[
G_{\{1\}}=Z_1,
\qquad
G_{\{1,2\}}=-\frac34Z_1Z_2.

Therefore

\[

\]

and the true reuse debt is

\[
\boxed{

=
2E(BG)
=
\frac12>0.
}
\tag{9.2}
\]

For coordinate 1, `(6.3)` gives

\[
C_1
=
2\left(1-\frac34\right)
=
\frac12.

For coordinate 2, only the interaction term appears:

\[
C_2
=
2\left(-\frac34\right)
=
-\frac32.
\]

Hence

\[
\boxed{
C_1+C_2=-1<0,
}
\tag{9.3}
\]

which has the opposite sign from `(9.2)`.

The slacks are

\[
\mathfrak s(B)=1,
\qquad
\mathfrak s(G)=\frac9{16}.
\]

The theorem `(7.4)` is attained exactly:

\[
\left|
\frac12-(-1)
\right|
=
\frac32
=

\tag{9.4}

# 10. `P15-SECONDORDER-SLACK-33` — pair replacements certify the interaction slack

The exact Efron slack in `(7.1)` is a population quantity. It can itself be upper-bounded by second-order replacement probes.

For distinct `i,j`, define the double replacement difference

\[
\Delta_{ij}^{(2)}F
=
F
-
F^{(i)}
-
F^{(j)}
+
F^{(ij)},
\tag{10.1}
\]

where `F^(ij)` replaces both observations independently.

A Hoeffding component survives `(10.1)` iff it contains both `i` and `j`. Two independent replacement differences double its `L^2` energy twice, hence

\[
\boxed{
E\|\Delta_{ij}^{(2)}F\|^2
=
4\sum_{A\supset\{i,j\}}
E\|F_A\|^2.
}
\tag{10.2}
\]

Sum over `i<j`:

\[
\frac14
\sum_{i<j}E\|\Delta_{ij}^{(2)}F\|^2
=
\sum_A
\binom{|A|}{2}
E\|F_A\|^2.
\tag{10.3}
\]

Since

\[
\binom{k}{2}\ge k-1
\qquad(k\ge2),
\]

`(7.2)` implies

\[
\boxed{
\mathfrak s(F)
\le
\frac14
\sum_{i<j}
E\|\Delta_{ij}^{(2)}F\|^2.
}
\tag{10.4}
\]

Therefore `(7.4)` yields the completely replacement-based certificate

\[
\boxed{
\left|
D_{\rm reuse}-\sum_i C_i
\right|
\le
\frac12
\sqrt{
\left(
\sum_{i<j}E\|\Delta_{ij}^{(2)}B\|^2
\right)
\left(
\sum_{i<j}E\|\Delta_{ij}^{(2)}G\|^2
\right)
}.
}
\tag{10.5}
\]

Equality in `(10.4)` holds when the learner contains only interactions of order at most two.

This is `P15-SECONDORDER-SLACK-33`.

# 11. Block exchangeability and the high-dimensional reduction

## 11.1 `P15-BLOCK-EXCHANGE-PAIR-33`

Suppose the observations are partitioned into fixed roles

\[
[n]=I_1\sqcup\cdots\sqcup I_R
\]

and the joint data law plus learning algorithm are permutation-equivariant within each block.

Then the expectation

\[
C_i=E\langle\Delta_iB,\Delta_iG\rangle
\]

is constant for `i` in the same block. Denote it `C_r`.

Therefore

\[
\boxed{
\sum_iC_i
=
\sum_{r=1}^R |I_r|\,C_r,
}
\tag{11.1}
\]

and `(7.4)` becomes

\[
\boxed{
\left|
D_{\rm reuse}
-
\sum_r |I_r|C_r
\right|
\le
2\sqrt{\mathfrak s(B)\mathfrak s(G)}.
}
\tag{11.2}
\]

This is exact under the stated equivariance hypothesis.

For a fully exchangeable learner,

\[
\boxed{
|D_{\rm reuse}-nC_1|
\le
2\sqrt{\mathfrak s(B)\mathfrak s(G)}.
}
\tag{11.3}
\]

## 11.2 Source qualification

The mechanics pipeline has structurally distinct roles:

- fitting rows;
- fixed OOF fold identities for the refiner;
- validation/model-selection rows;
- later full-data refit.

Within a frozen fold/split, an ideal permutation-equivariant training algorithm would admit a small number of role-specific `C_r`'s.

The actual AdamW trajectory, minibatch order, random seed, checkpoint selection, and downstream hard selection can break exact pathwise equivariance. Therefore **numerical source use of `(11.1)` is CONDITIONAL** until the randomization/symmetrization convention is specified or the role-specific expectation is estimated directly.

## 11.3 `P15-RF-EFRONSLACK-REDUCTION-33`

In a high-dimensional exchangeable sequence, if

\[

\[

\boxed{

\tag{11.4}

1. one signed replace-one cross-effect;
2. the higher-order Efron interaction slacks.

A random-feature theorem sufficient for P15 would need to control these objects **for the trained algorithm**, including response-dependent representation and selection movement. Existing fixed/random-feature KRR deterministic equivalents do not supply arbitrary optimizer-induced Efron slack.
