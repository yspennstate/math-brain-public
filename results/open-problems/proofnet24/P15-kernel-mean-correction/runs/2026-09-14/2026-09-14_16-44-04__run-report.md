# 4. New target: a stable leave-one-out safe gate

Let

\[
S=(Z_1,\ldots,Z_n),
\qquad
Z_i=(U_i,G(U_i)),
\]

be iid deployment-distribution observations.

The learning algorithm is allowed to contain the entire historical pipeline:

\[
m_T,\qquad c_T.

A leave-one-out fit \(T=S^{-i}\) must exclude observation \(i\) from **every stage that can use that observation**.

# 5. Stability assumptions

Assume deterministic envelope bounds, simultaneously for every relevant \(T\),

\[
\boxed{
\|G(u)-m_T(u)\|\le E,
\qquad
\|c_T(u)\|\le C
\quad
\forall u.
}
\tag{5.1}
\]

Assume uniform deletion stability:

for every size-\(n\) sample \(T\) and every deletion \(T^{-i}\),

\[
\boxed{
\sup_u
\|m_T(u)-m_{T^{-i}}(u)\|
\le
\eta_m,
}
\tag{5.2}
\]

\[
\boxed{
\sup_u
\|c_T(u)-c_{T^{-i}}(u)\|
\le
\eta_c.
}
\tag{5.3}
\]

Define

\[
\boxed{
\gamma_A
=
C\eta_m+E\eta_c,
}
\tag{5.4}
\]

\[
\boxed{
\gamma_V
=
2C\eta_c.
}
\tag{5.5}
\]

For the alignment functional

\[
\ell_T(z)
=
\langle G(u)-m_T(u),c_T(u)\rangle,
\tag{5.6}
\]

(5.2)–(5.3) imply

\[
|\ell_T(z)-\ell_{T^{-i}}(z)|
\le
\gamma_A.
\tag{5.7}
\]

For

\[
v_T(z)
=
\|c_T(u)\|^2,
\tag{5.8}
\]

they imply

\[
|v_T(z)-v_{T^{-i}}(z)|
\le
\gamma_V.
\tag{5.9}
\]

Two samples of the same size \(n\) or \(n-1\) that differ in one observation can be compared through their common deletion/union, so their corresponding functionals differ by at most

\[
2\gamma_A
\]

and

\[
2\gamma_V.
\]

This is the only place where full-pipeline leave-one-out stability enters.

# 6. Leave-one-out estimators

For the full-data deployed model define

\[
A_S
=
\mathbb E_Z \ell_S(Z),
\qquad
V_S
=
\mathbb E_Z v_S(Z).
\tag{6.1}
\]

Define leave-one-out estimators

\[
\boxed{
\widehat A_{\rm loo}
=
\frac1n
\sum_{i=1}^n
\ell_{S^{-i}}(Z_i),
}
\tag{6.2}
\]

\[
\boxed{
\widehat V_{\rm loo}
=
\frac1n
\sum_{i=1}^n
v_{S^{-i}}(Z_i).
}
\tag{6.3}
\]

For each \(i\),

\[
Z_i
\perp S^{-i},
\]

so the held-out evaluation is honest relative to its corresponding leave-one-out fit.

The terms are nevertheless strongly dependent across \(i\); they are **not** treated as iid.

# 8. Bounded differences for the full-fit-minus-LOO gap

Define

\[
F_A(S)
=
A_S-\widehat A_{\rm loo},
\tag{8.1}
\]

\[
F_V(S)
=
V_S-\widehat V_{\rm loo}.
\tag{8.2}
\]

Replace one observation \(Z_k\) by \(Z_k'\).

### 8.1 Alignment gap

The full-fit population term changes by at most

\[
2\gamma_A.
\]

For the leave-one-out sum:

- at index \(k\), the fitted function is unchanged because the changed point is deleted; only the evaluation point changes. Since
  \[
  |\ell_T(z)|\le EC,
  \]
  this term changes by at most
  \[
  2EC;
  \]
- for every \(j\ne k\), the two size-\((n-1)\) training sets differ in one observation, so the term changes by at most
  \[
  2\gamma_A.
  \]

Hence one-coordinate replacement changes \(F_A\) by at most

\[
\boxed{
c_A
=
\left(4-\frac2n\right)\gamma_A
+
\frac{2EC}{n}.
}
\tag{8.3}
\]

### 8.2 Correction-energy gap

The full-fit population term changes by at most

\[
2\gamma_V.
\]

At the held-out index \(k\),

\[
0\le v_T(z)\le C^2,
\]

so the evaluation change is at most \(C^2\).

For \(j\ne k\), each term changes by at most \(2\gamma_V\).

Thus

\[
\boxed{
c_V
=
\left(4-\frac2n\right)\gamma_V
+
\frac{C^2}{n}.
}
\tag{8.4}
\]

These are exact deterministic bounded-difference constants under (5.1)–(5.3).

# 13. Counterexample P15-LOO-CE-04 — LOO is not automatically safe

The stability hypothesis is essential.

Let the input space contain one point, let the scalar target be

\[
G\equiv1,
\]

and let the baseline mean be

\[
m_T\equiv0.
\]

Define an intentionally unstable learning algorithm by sample-size parity:

\[
c_T
=
\begin{cases}
1,
&
|T|\text{ odd},
\\
3,
&
|T|\text{ even}.
\end{cases}
\]

Take \(n\) even.

The full-data correction is

\[
c_S=3.
\]

Baseline risk:

\[
\mathcal R_S(0)=1.
\]

Full unit-correction risk:

\[
\mathcal R_S(1)
=
(1-3)^2
=
4.
\]

So the full correction is harmful.

But every leave-one-out sample has size \(n-1\), which is odd, so

\[
c_{S^{-i}}=1.
\]

Every leave-one-out evaluation gives

\[
\widehat A_{\rm loo}=1,
\qquad
\widehat V_{\rm loo}=1,
\]

which naively suggests perfect unit-amplitude improvement.

Thus:

\[
\boxed{
\text{LOO evaluation without a stability bridge can certify the wrong sign for the full-data model.}
}
\tag{P15-LOO-CE-04}
\]

The example is deterministic, noiseless and kernel-free. The issue is purely learner instability.

P15-LOOGATE-01 avoids the failure because here

\[
\eta_c=2,
\]

so its confidence penalty is deliberately noninformative.

# 14. How this interfaces with the current manuscript

The theorem can be applied in two ways.

### Option A — literal leave-one-out refits

For each fitting row \(i\):

1. remove row \(i\) from every stage that can use it;
2. retrain/recompute the neural mean or the relevant approximation to it;
3. rebuild the learned feature representation if it depends on the removed row;
4. rerun the selected kernel-correction fit under the prescribed selection protocol;
5. evaluate
   \[
   m_{S^{-i}}(U_i),
   \qquad
   c_{S^{-i}}(U_i).
   \]

This gives the honest LOO statistics (6.2)–(6.3).

The theorem then requires an independent argument or empirical upper certificate for

\[
\eta_m,\eta_c.
\]

### Option B — use existing fold structure as a benchmark

The manuscript already uses foldwise kernel predictions in the refiner.

That is not automatically the same as complete leave-one-out of the whole pipeline, but it provides a computational benchmark for the magnitude of full-fit/fold-fit discrepancies.

P15-STAB-03 and P15-GAIN-03 remain the correct tools for converting observed spectral/query defects into a full-fit guarantee.

### Important selection caveat

If the held-out observation is used in kernel/ridge selection, checkpoint selection, representation tuning or any other stage, then its evaluation is not leave-one-out in the theorem's sense.

The observation must be absent from every stage whose output affects \(m_{S^{-i}}\) or \(c_{S^{-i}}\).

Primary source:

Colin McDiarmid,  
*On the method of bounded differences*,  
Surveys in Combinatorics 1989, London Mathematical Society Lecture Note Series 141, pp. 148–188.

The theorem applies because \(F_A(S)\) and \(F_V(S)\) are deterministic functions of independent observations and Sections 8.1–8.2 give explicit per-coordinate replacement bounds.

The stability/leave-one-out architecture is consistent with the classical primary stability paper:

Olivier Bousquet and André Elisseeff,  
*Stability and Generalization*,  
JMLR 2 (2002), 499–526.

That paper explicitly relates leave-one-out error, expected error and uniform stability for regularized learners.

No result from Bousquet–Elisseeff is required for the proof above; the proof derives the constants directly.

# 23. Bottom line

The elementary population formula

\[
B(\lambda)
=
\sum_j
\left(
\frac{\lambda}{\lambda_j+\lambda}
\right)^2r_j^2
\]

still does **not** prove same-sample gain.

The new rigorous statement is:

\[
\boxed{
\text{same-sample learned mean/representation/correction}
+
\text{uniform full-pipeline deletion stability}
+
\text{honest LOO predictions}
}
\]

\[
\boxed{
\Longrightarrow
\text{finite-sample high-probability non-worsening scalar-gated population risk}
}
\]

for the actual full-data deployed model.

The stability penalty is explicit:

\[
O\left(
n^{-1/2}
+
\sqrt n\,\eta_m
+
\sqrt n\,\eta_c
\right).
\]

The parity counterexample shows that the stability bridge is mathematically necessary: leave-one-out evaluation alone can have the wrong sign for the full fit.

This is the strongest no-new-label same-sample certification theorem currently in the P15 chain.
