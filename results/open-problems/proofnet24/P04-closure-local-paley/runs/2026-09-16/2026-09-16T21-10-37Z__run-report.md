## 3. Retained exact setup: the edge-fixed theta dual

Let `H=G_{p,2}` on vertex set `V_2`. In the clique-bounding theta convention,

\[
\vartheta(\overline H)
=
\max\{\langle J,X\rangle:
X\succeq0,
\operatorname{Tr}X=1,
X_{ij}=0\text{ for distinct nonedges }ij\notin E(H)\}.
\tag{3.1}
\]

If a symmetric matrix `B` obeys

\[
B_{ii}=1,
\qquad
B_{ij}=1\quad(ij\in E(H)),
\tag{3.2}
\]

then `J-B` is supported only on distinct nonedges of `H`. Hence every feasible `X` in (3.1) satisfies

\[
\langle J,X\rangle
=
\langle B,X\rangle
\le
\lambda_{\max}(B)\operatorname{Tr}X
=
\lambda_{\max}(B).
\tag{3.3}
\]

Therefore

\[
\boxed{\vartheta(\overline H)\le\lambda_{\max}(B).}
\tag{3.4}
\]

This weak-duality direction is all that the finite certificates below require.

## 4. Move #15 — BREAK THE SYMMETRY: exact proof that genuine breaking cannot help

The previous run found the anharmonic `S_3` action on `V_2`, generated by

\[
r(x)=1-x,
\qquad
s(x)=x^{-1}.
\tag{4.1}
\]

Both maps preserve `V_2` and graph adjacency.

The natural #15 experiment is to ask whether a non-`S_3`-invariant edge-fixed dual can beat all invariant ones. It cannot.

### Proposition `P04-I0101-S3-AVERAGING-WLOG-04`

Let `\mathcal B_H` be all real symmetric matrices satisfying (3.2). For every `B in \mathcal B_H`, define

\[
\overline B
=
\frac1{6}\sum_{g\in S_3}P_g^T B P_g.
\tag{4.2}
\]

Then

\[
\overline B\in\mathcal B_H,
\qquad
\lambda_{\max}(\overline B)\le\lambda_{\max}(B).
\tag{4.3}
\]

Consequently, minimizing the spectral certificate (3.4) loses nothing by restricting to `S_3`-invariant matrices.

### Proof

Every `P_g` is a permutation matrix for a graph automorphism, so each conjugate `P_g^T B P_g` still has diagonal entries one and edge entries one. Their average therefore lies in `\mathcal B_H`.

The function `B -> lambda_max(B)` is convex and invariant under orthogonal conjugation. Thus

\[
\lambda_{\max}(\overline B)
\le
\frac16\sum_g\lambda_{\max}(P_g^T B P_g)
=
\lambda_{\max}(B).
\]

QED.

This is a precise failed route: **true graph-symmetry breaking is dominated by averaging**. The useful refinement is not to break `S_3`; it is to allow different weights on its many pair orbits, including the exceptional vertex orbits classified in the preceding run.

This averaging fact is standard convex/Semidefinite-program symmetry reduction; novelty is not claimed.

## 5. Move #5 — ADD A PARAMETER AND DIFFERENTIATE: active-sector descent rather than coefficient fitting

For an affine matrix path

\[
B(s)=B_0+sD,
\tag{5.1}
\]

Rayleigh's variational principle gives an exact diagnostic for whether a proposed arithmetic feature is a useful descent direction.

### Lemma `P04-I0101-TOP-EIGEN-DIRECTIONAL-04`

If the top eigenvalue of `B_0` is simple with normalized eigenvector `v`, then

\[
\left.\frac{d}{ds}\lambda_{\max}(B_0+sD)\right|_{s=0}
=v^TDv.
\tag{5.2}
\]

If its top eigenspace is `E` with orthonormal basis matrix `V`, then the right derivative is

\[
\left.\frac{d}{ds^+}\lambda_{\max}(B_0+sD)\right|_{s=0}
=
\lambda_{\max}(V^TDV).
\tag{5.3}
\]

### Proof

The function is

\[
\lambda_{\max}(B_0+sD)
=
\max_{\|u\|=1}u^T(B_0+sD)u.
\]

For a unique maximizing line at `s=0`, the envelope derivative is `v^TDv`, giving (5.2). With a degenerate active eigenspace, the first-order maximization is over unit vectors in `E`, giving the largest eigenvalue of the compression `V^TDV`. QED.

I used this as a research diagnostic, not as a new finite metric: start from the low-feature constant/degree-aware families from the previous runs, examine the active top sector, and only add directions that descend there. Floating scouting showed that the useful corrections are not exhausted by the scalar degree/elliptic-trace coordinate. This led to the full invariant pair-orbit search below. Those floating scouts are **not** certificates and are not added to the metric.

## 6. Move #24 — FIND THE EXTREMAL OBJECT: the full S3 pair-orbit dual

By Proposition 4.1 an extremal edge-fixed spectral dual may be assumed `S_3` invariant. Such a matrix is completely determined, beyond the fixed diagonal and edge entries, by one number for each `S_3` orbit of unordered nonedge pairs.

This is the correct finite extremal object: not a constant on all nonedges, and not a low-degree polynomial in the vertex degrees, but an orbit kernel on

\[
\binom{V_2}{2}_{\mathrm{nonedge}}/S_3.
\tag{6.1}
\]

At a fixed prime this is a convex spectral optimization problem. I used floating eigenvalue optimization only to **propose** rational orbit weights. Once the weights were frozen, all theorem claims below were rechecked from scratch in exact integer arithmetic; no floating eigenvalue is part of either proof.

The cost of this route is now also explicit: the number of pair orbits grows quadratically with `p`. At `p=1201` there are already 3770 independent nonedge pair orbits. Thus full orbit optimization is excellent for finite frontier movement but, by itself, is not an asymptotic proof of (2.1). The new asymptotic question is how to compress these orbit weights into a fixed arithmetic kernel.

## 11. Exact remaining source obstruction

The source problem is still the eventual all-prime statement (2.1). The finite orbit method only shows that there is ample feasible spectral room at selected primes.

A source-level proof would need a prime-uniform construction `B_p` with

\[

\qquad
B_{ij}=1\text{ on edges},
\qquad
\lambda_{\max}(B_p)\le\frac23\sqrt p
\tag{11.1}
\]

for every sufficiently large admissible prime, with the nonedge entries given by a fixed explicit arithmetic rule rather than `Theta(p^2)` independently optimized pair-orbit values.

The preceding run found that the first inhomogeneous one-vertex coordinate is the Legendre elliptic Frobenius trace. The present run shows that a one-vertex coordinate is not the whole story: a highly successful finite dual uses genuinely pair-dependent orbit information.

The simplest useful next question is therefore:

\[

\tag{11.2}
\]

That is a compression problem, not another prime-by-prime certificate problem.
