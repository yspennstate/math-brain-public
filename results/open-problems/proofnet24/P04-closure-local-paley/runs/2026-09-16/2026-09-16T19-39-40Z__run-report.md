## 3. Exact graph normalization retained

\tag{3.1}

\[

\tag{3.3}

r^2=s^2=(rs)^3=1,

The edge-fixed theta dual lemma from the previous run will be used again:

### Lemma 3.1 — edge-fixed spectral certificate

Let `H` be a finite graph. If a real symmetric matrix `B` satisfies

\[
B_{ii}=1,\qquad B_{ij}=1\quad(ij\in E(H)),
\tag{3.6}
\]

then

\[
\boxed{\vartheta(\overline H)\le\lambda_{\max}(B).}
\tag{3.7}
\]

### Proof

In the clique-bounding primal normalization,

\[
\vartheta(\overline H)
=\max\{\langle J,X\rangle:\operatorname{Tr}X=1,\ X\succeq0,\ X_{ij}=0\text{ on distinct nonedges of }H\}.
\]

For feasible `X`, the matrix `J-B` is supported only on distinct nonedges, so

\[
\langle J,X\rangle=\langle B,X\rangle
\le\lambda_{\max}(B)\operatorname{Tr}X
=\lambda_{\max}(B).
\]

Take the maximum. QED.

## 4. Move #21 — ask who else has this shape: vertex degrees are Legendre elliptic traces

The first new idea was to stop treating the localized graph's degree irregularity as nuisance and identify the arithmetic object that generates it.

For `x in V_2`, define the cubic quadratic-character sum

\[
S_x:=\sum_{t\in\mathbb F_p}\chi\bigl(t(t-1)(t-x)\bigr).
\tag{4.1}
\]

### Theorem 4.1 — exact localized-degree / elliptic-trace identity

For every admissible prime `p` and every `x in V_2`, the degree `d(x)` in `G_{p,2}` satisfies

\[
\boxed{
 d(x)=\frac{p-15+S_x}{8}.
}
\tag{4.2}
\]

Equivalently, for the Legendre elliptic curve

\[
E_x:\quad y^2=t(t-1)(t-x),
\tag{4.3}
\]

with Frobenius trace

\[
a_p(E_x)=p+1-\#E_x(\mathbb F_p),
\tag{4.4}
\]

we have

\[
\boxed{
 d(x)=\frac{p-15-a_p(E_x)}8.
}
\tag{4.5}
\]

### Proof

For all `y in F_p`, the exact vertex indicator is

\[
1_{V_2}(y)
=\frac14(1+\chi(y))(1+\chi(y-1))
-\frac12\mathbf 1_{y=0}
-\frac12\mathbf 1_{y=1}.
\tag{4.6}
\]

For fixed `x in V_2`, adjacency to `x` away from `y=x` is represented by

\[
\frac{1+\chi(y-x)}2.
\]

Thus

\[
d(x)
=\sum_y1_{V_2}(y)\frac{1+\chi(y-x)}2-\frac12,
\tag{4.7}
\]

where the final `1/2` removes the artificial self contribution at `y=x`.

Expanding the first term of (4.6) in (4.7) gives

\[
\frac18\sum_y
(1+\chi(y))(1+\chi(y-1))(1+\chi(y-x)).
\tag{4.8}
\]

The three linear character sums vanish. Each of the three pair sums over distinct shifts equals `-1`. The triple term is `S_x`. Therefore (4.8) equals

\[
\frac{p-3+S_x}{8}.
\tag{4.9}
\]

The endpoint correction at `y=0` is

\[
-\frac14(1+\chi(-x))=-\frac12,
\]

because `x in V_2` and `chi(-1)=1`. The endpoint correction at `y=1` is likewise

\[
-\frac14(1+\chi(1-x))=-\frac12.
\]

Finally subtract the self term `1/2` from (4.7). Hence

\[
d(x)=\frac{p-3+S_x}{8}-1-\frac12
=\frac{p-15+S_x}{8},
\]

proving (4.2).

For (4.5), each affine `t` contributes `1+chi(t(t-1)(t-x))` points above it, and the smooth projective model has one point at infinity. Therefore

\[
\#E_x(\mathbb F_p)=p+1+S_x,
\]

so `a_p(E_x)=-S_x`. Substitute into (4.2). QED.

### Corollary 4.2 — exact row-sum coordinate of the localized Paley character matrix

Let `C` be the `n x n` symmetric matrix indexed by `V_2`, with

\[
C_{xx}=0,\qquad C_{xy}=\chi(x-y)\quad(x\ne y).
\tag{4.10}
\]

Then

\[
\boxed{
(C\mathbf 1)_x=\frac{S_x-6}{4}
=-\frac{a_p(E_x)+6}{4}.
}
\tag{4.11}
\]

### Proof

Among the `n-1` other vertices, `d(x)` entries equal `+1` and the other `n-1-d(x)` equal `-1`, so

\[
(C\mathbf 1)_x=2d(x)-(n-1).
\]

Using (4.2) and `n=(p-5)/4` gives exactly `(S_x-6)/4`. QED.

This is the useful bridge: the first inhomogeneous row-sum mode of the localized Paley matrix is not arbitrary. It is exactly an elliptic Frobenius-trace vector.

Hasse's bound immediately gives

\[
|S_x|=|a_p(E_x)|\le2\sqrt p,
\]

and hence

\[
d(x)=\frac p8+O(\sqrt p),
\]

with an explicit fluctuation window. That by itself is much too weak for (2.1), but it identifies a low-rank arithmetic coordinate on which a dual certificate may profitably depend.

## 5. Move #25 — count the same thing twice: exact S3 orbit census

The previous run established the `S_3` action but only used the special case `p=149`, where every orbit happened to have size six. For asymptotics and for the next exact prime, the exceptional orbits must be classified rather than ignored.

Write

\[
\epsilon_2(p)=\mathbf 1_{p\equiv1\pmod8},
\qquad
\epsilon_3(p)=\mathbf 1_{p\equiv1\pmod{12}}.
\tag{5.1}
\]

### Theorem 5.1 — complete orbit sizes for the anharmonic S3 action on V2

For every prime `p == 1 mod 4`, the action generated by `r(x)=1-x` and `s(x)=x^{-1}` has:

- exactly one orbit of size `3`, namely
  \[
  \{1/2,-1,2\},
  \]
  if and only if `p == 1 mod 8`;
- exactly one orbit of size `2`, namely the two roots of
  \[
  x^2-x+1=0,
  \]
  if and only if `p == 1 mod 12`;
- all remaining orbits of size `6`.

Consequently the number `q_p` of regular size-six orbits is

\[
\boxed{
q_p=\frac{n-3\epsilon_2(p)-2\epsilon_3(p)}6,
\qquad n=\frac{p-5}{4},
}
\tag{5.2}
\]

and the total number of orbits is

\[
\boxed{
q_p+\epsilon_2(p)+\epsilon_3(p)
=\frac{n+3\epsilon_2(p)+4\epsilon_3(p)}6.
}
\tag{5.3}
\]

### Proof

Every nontrivial stabilizer in `S_3` contains either a transposition or a 3-cycle.

The three transpositions have fixed points `1/2`, `-1`, and `2`, respectively. These three points form one `S_3` orbit. Each belongs to `V_2` exactly when `chi(2)=1`: for example `2 in V_2` iff `chi(2)=1`, while `-1` and `1/2` give the same condition because `chi(-1)=1`. For prime `p == 1 mod 4`, the supplementary law for `2` gives `chi(2)=1` exactly when `p == 1 mod 8`. Each such point has stabilizer of order `2`, so the orbit has size `3`.

A 3-cycle has fixed points satisfying

\[
x^2-x+1=0.
\tag{5.4}
\]

For `p>3`, this has two roots precisely when `-3` is a square, equivalently for the present congruence class when `p == 1 mod 12`. For either root, (5.4) gives `x-1=x^2`; moreover the root has multiplicative order `6`. Since `12 | p-1`, a primitive sixth root is itself a square in `F_p^*`; hence `chi(x)=chi(x-1)=1`, so both roots lie in `V_2`. Their stabilizer has order `3`, yielding one orbit of size `2`.

There are no other nontrivial stabilizers in `S_3`, so every other orbit has size `6`. Subtract the exceptional orbit sizes from `n` to get (5.2); adding the orbit counts gives (5.3). QED.

At the new exact prime `p=257`,

\[
257\equiv1\pmod8,
\qquad
257\equiv5\pmod{12},
\]

so `epsilon_2=1`, `epsilon_3=0`, `n=63`, and

\[
q_{257}=10.
\]

Thus the exact orbit multiset is

\[
\boxed{3,6,6,6,6,6,6,6,6,6,6},
\]

which the archived checker verifies independently by direct orbit enumeration.

This count is useful because it tells an invariant theta reduction exactly how many regular-representation blocks and exceptional induced blocks occur at every admissible prime; one does not need to rediscover the orbit structure numerically prime by prime.

## 6. Move #18 — another language: finite-group Fourier / matrix-valued Delsarte blocks

The graph is not a Cayley graph after two localization steps, so the one-localization cyclic LP does not survive. But the previous `S_3` symmetry gives a smaller, noncommutative Fourier language.

Let the regular part of `V_2` consist of `q=q_p` free `S_3` orbits. Choose one representative in each orbit. Then, as an `S_3`-set,

\[
V_{\mathrm{reg}}\cong\{1,\ldots,q\}\times S_3.
\tag{6.1}
\]

Any kernel `K` invariant under simultaneous left translation satisfies

\[
K((a,g),(b,h))=k_{ab}(g^{-1}h)
\tag{6.2}
\]

for functions `k_{ab}:S_3->R`, with the Hermitian symmetry

\[
k_{ba}(u^{-1})=k_{ab}(u).
\tag{6.3}
\]

Fourier transform on `S_3` decomposes the regular representation as

\[
\mathbb R[S_3]
\cong\mathbf 1\oplus\mathrm{sgn}\oplus2\,\mathrm{std}.
\tag{6.4}
\]

Therefore an invariant symmetric operator on `q` regular orbits block-diagonalizes into multiplicity blocks of dimensions

\[
\boxed{q,\quad q,\quad 2q}
\tag{6.5}
\]

for the trivial, sign, and standard representations (the standard representation has dimension `2`, with the multiplicity block tensored by the identity on the representation space).

The exceptional size-three and size-two orbits from Theorem 5.1 contribute the corresponding induced-representation/stabilizer pieces. They are only `O(1)` extra dimensions for each prime; the regular blocks are the asymptotically growing part.

This is standard finite-group SDP symmetry reduction in the sense of Vallentin and DeCorte--de Laat--Vallentin, not a novelty claim. Its role here is diagnostic. It converts the raw `n x n` dual PSD constraint into three matrix-valued arithmetic sectors of scale roughly `p/24`, plus bounded exceptional sectors. Thus:

- symmetry alone does **not** solve the problem; the blocks still grow linearly with `p`;
- however, any future asymptotic dual can be designed sector by sector rather than entry by entry;
- the elliptic-trace degree mode from Section 4 lives in the trivial sector and suggests the first nonconstant correction to the previous constant-nonedge ansatz.

This is the conceptual route that led to the exact p=257 certificate below.

## 8. Why the new certificate is more informative than merely another prime

The finite movement matters mainly because it falsifies the idea that the p=149 certificate's success was tied to a constant value on all nonedges. The new certificate uses a low-rank arithmetic statistic with a source-independent meaning:

\[
\delta_x
=d(x)-\overline d
\quad\leftrightarrow\quad
\text{Legendre elliptic Frobenius trace }a_p(E_x).
\]

The nonedge correction (7.6) is a quadratic kernel in these trace coordinates. In matrix language it belongs to the span generated by

\[
\mathbf1,\quad\delta,\quad\delta^{\circ2},
\]

through constant, rank-one, and symmetrized rank-two feature terms, but only on the nonedge support required by the theta dual. It therefore attacks the trivial-sector row-sum inhomogeneity identified exactly in Corollary 4.2.

This points to a principled asymptotic program rather than blind prime-by-prime rational fitting:

1. separate the invariant theta dual into `S_3` Fourier sectors;
2. correct the trivial sector using explicit elliptic trace features;
3. identify the next arithmetic coordinates needed in the sign and standard sectors;
4. prove a uniform upper spectral bound for the resulting block kernels by character-sum or trace-function methods.

The present run completes only step 2 at one new exact prime. It does **not** establish that the four rational coefficients in (7.6) work for all primes, or that any bounded-degree function of the elliptic trace suffices asymptotically.
