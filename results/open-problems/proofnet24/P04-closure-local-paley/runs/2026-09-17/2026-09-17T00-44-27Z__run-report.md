## 5. B13 — FIND WHAT ONLY INCREASES: an exact excess-energy monovariant

Define the squared distance from B_k to the spectral cap by

\[
e_k:=d_F(B_k,\mathcal C_t)^2=\|Z_k\|_F^2.
\]

The point B_k-Z_k lies in C_t. From (4.1),

\[
B_{k+1}-(B_k-Z_k)=M\circ Z_k.
\]

Therefore, merely by testing this particular point of C_t when computing the next distance,

\[
\begin{aligned}
e_{k+1}
&=d_F(B_{k+1},\mathcal C_t)^2\\
&\le \|M\circ Z_k\|_F^2.
\end{aligned}
\]

Because M and N are complementary disjoint 0/1 masks,

\[
\|Z_k\|_F^2=\|M\circ Z_k\|_F^2+\|N\circ Z_k\|_F^2.
\]

Hence the exact descent inequality is

\[
\boxed{
 e_{k+1}\le e_k-\|N\circ Z_k\|_F^2.
}
\tag{5.1}
\]

Consequences requiring no feasibility assumption are

\[
\boxed{e_{k+1}\le e_k}
\]

and, for every K,

\[
\boxed{
\sum_{k=0}^{K-1}\|N\circ Z_k\|_F^2
\le e_0-e_K\le e_0.
}
\tag{5.2}
\]

Thus the accumulated decrease `e_0-e_K` is a bounded nondecreasing quantity, while `e_k` is a monovariant and

\[
N\circ Z_k\to0
\quad\text{in Frobenius norm.}
\tag{5.3}
\]

This is the first route this run that actually isolates what the iteration is forced to do even when the source target t is infeasible. It does **not** prove e_k->0: a persistent excess supported on fixed coordinates is exactly the obstruction explored next.

## 6. B23 — assume the proposer is wrong: an exact Frobenius-gap refutation margin

Instead of presuming feasibility at the source threshold, define the Euclidean separation

\[
\delta_t:=\operatorname{dist}_F(\mathcal E,\mathcal C_t)
=\inf_{B\in\mathcal E}\|(B-tI)_+\|_F.
\tag{6.1}
\]

This quantity detects infeasibility quantitatively.

### 6.1 Exact dual formula

For every real symmetric Y,

\[
\|Y_+\|_F
=\max\{\langle Y,X\rangle:X\succeq0,\ \|X\|_F\le1\}.
\tag{6.2}
\]

Apply Fenchel duality to the continuous support function in (6.2) restricted to the nonempty affine space E. Write a point of E as a fixed matrix with value 1 on diagonal/edge coordinates plus an arbitrary symmetric matrix supported on distinct nonedges. Minimization over those free entries is finite exactly when

\[
N\circ X=0.
\]

On that constraint the fixed-coordinate inner product is simply <J,X>. Strong Fenchel duality applies because the positive-part norm is finite and continuous everywhere. Therefore

\[
\boxed{
\delta_t
=
\max\left\{
\langle J,X\rangle-t\operatorname{Tr}X:
X\succeq0,\ N\circ X=0,\ \|X\|_F\le1
\right\}.
}
\tag{6.3}
\]

Since X=0 is allowed, the value is nonnegative. Normalizing every nonzero PSD X by its trace gives the equivalent theta-primal form

\[
\boxed{
\delta_t
=
\max_{\substack{X\succeq0,\ N\circ X=0,\\ \operatorname{Tr}X=1}}
\frac{(\langle J,X\rangle-t)_+}{\|X\|_F}.
}
\tag{6.4}
\]

The standard strict-feasibility/strong-duality facts for the Lovasz-theta SDP then make the quantifier exact:

\[
\boxed{
\delta_t=0\iff t\ge\vartheta(\overline G),
\qquad
\delta_t>0\iff t<\vartheta(\overline G).
}
\tag{6.5}
\]

At the source threshold `t_p=(2/3)sqrt(p)`, an actual refutation of the eventual conjecture is therefore equivalent to finding infinitely many admissible p with

\[
\boxed{\delta_{t_p}>0.}
\tag{6.6}
\]

This respects the source quantifier: one finite bad prime would not refute the conjecture, and no uniform positive lower bound on delta is asserted.

### 6.2 What the alternating-projection orbit must do if the threshold is false

If delta_t>0 then every B_k in E satisfies

\[
\|Z_k\|_F\ge\delta_t.
\]

By (5.3), meanwhile, `N o Z_k -> 0`. Consequently, if the orbit `(B_k)` is bounded, compactness gives a subsequence `B_{k_j}->B_infty`; continuity of the positive-part map gives `Z_{k_j}->Z_infty`, where

\[
\|Z_\infty\|_F\ge\delta_t>0,
\qquad
N\circ Z_\infty=0.

Equation (4.1) then makes B_infty a fixed point of the alternating-projection map. As proved in the previous run, normalizing this nonzero Z_infty supplies a primal theta witness strictly above t.

Thus the negation-first search has an exact dichotomy:

## 7. B28 — replace FOR ALL by TYPICAL: Paley conference delocalization versus obstruction

The free-coordinate residual has an exact formula that exposes a typical/exceptional dichotomy.

Let Z be any PSD matrix indexed by V_2 and put W=Z o Z. By the Schur product theorem, W is PSD. Because `N=(J-I-C)/2`,

\[
\begin{aligned}
\|N\circ Z\|_F^2
&=\langle N,Z\circ Z\rangle\\
&=\frac12\left(
\|Z\|_F^2-\|\operatorname{diag}Z\|_2^2
-\langle C,W\rangle
\right).
\end{aligned}
\tag{7.1}
\]

The localized C is a principal block of the full Paley conference matrix `C_tilde`, with

\[
\widetilde C^2=pI-J.
\]

Hence lambda_max(C)<=sqrt(p). Since W is PSD,

\[
\langle C,W\rangle
\le \sqrt p\operatorname{Tr}W
=\sqrt p\|\operatorname{diag}Z\|_2^2.
\]

Substituting into (7.1) gives the exact lower bound

\[
\boxed{
\|N\circ Z\|_F^2
\ge
\frac12\left(
\|Z\|_F^2-(1+\sqrt p)\|\operatorname{diag}Z\|_2^2
\right).
}
\tag{7.2}
\]

Define the diagonal concentration ratio

\[
\kappa(Z):=
\frac{\|\operatorname{diag}Z\|_2^2}{\|Z\|_F^2}
\qquad (Z\ne0).
\]

If, along an iteration, for some fixed epsilon>0,

\[
\kappa(Z_k)\le\frac{1-\varepsilon}{1+\sqrt p},
\tag{7.3}
\]

then (7.2) and (5.1) imply the uniform one-step contraction

\[
\boxed{
 e_{k+1}\le\left(1-\frac\varepsilon2\right)e_k.
}
\tag{7.4}
\]

This is a rigorous sufficient condition, not an assertion that all excess matrices satisfy it.

For a rank-one excess `Z=lambda uu^T` with ||u||_2=1, kappa is exactly

\[
\kappa(Z)=\sum_i u_i^4,
\]

the inverse-participation ratio. Condition (7.3) therefore asks for effective support on the order of sqrt(p), not complete flatness on all m~p/4 coordinates.

### 7.1 Any exact obstruction must be exceptional in a quantified sense

If a nonzero PSD Z satisfies the fixed-coordinate obstruction condition

\[
N\circ Z=0,
\]

then (7.2) forces

\[
\boxed{
\kappa(Z)\ge\frac1{1+\sqrt p}.
}
\tag{7.5}
\]

To express this without assuming rank one, define

\[
\mu(Z):=\frac{m\max_i Z_{ii}}{\operatorname{Tr}Z},
\qquad
r_2(Z):=\frac{(\operatorname{Tr}Z)^2}{\|Z\|_F^2}.
\]

Here r_2 is the trace/Frobenius effective rank. Since

\[
\|\operatorname{diag}Z\|_2^2
\le (\max_i Z_{ii})\operatorname{Tr}Z,
\]

we have

\[
\kappa(Z)\le\frac{\mu(Z)r_2(Z)}m.
\]

Combining with (7.5), every nonzero exact fixed-point/primal obstruction must obey

\[
\boxed{
\mu(Z)r_2(Z)
\ge\frac{m}{1+\sqrt p}
\sim\frac14\sqrt p.
}
\tag{7.6}
\]

So an obstruction cannot simultaneously have bounded diagonal coherence and `r_2=o(sqrt(p))`. Equivalently, if its coherence stays O(1), it must have effective rank Omega(sqrt(p)); if it has low effective rank, it must become increasingly coherent. This is the concrete meaning of “typical versus exceptional” obtained this run.

What remains missing is an arithmetic theorem showing that the spectral excess generated from a canonical start avoids this exceptional class for all sufficiently large p, or else an explicit exceptional family showing that it does not.
