# 3. B18 — change language: a positive weighted complement is a zero-holding reversible Markov chain

Let `H` be an arbitrary graph on `n` vertices and put `G=\overline H`. Use the theta-dual convention already fixed in P04:

\[
\vartheta(\overline H)
=\min\{\lambda_{\max}(B): B=B^\top,\ B_{ii}=1,\ B_{ij}=1\text{ for }ij\in E(H)\}.
\tag{3.1}
\]

Thus every feasible `B` may be written

\[
B=J-A,
\tag{3.2}
\]

where `A` has zero diagonal and is supported on `E(G)`; if the free entries of `B` are nonpositive, then `A` is entrywise nonnegative on the complement.

The four largest archived exact P04 certificates (`p=4013,4021,4049,4057`) all have every free `B` entry strictly negative. That finite observation does not prove that positive complement weights suffice asymptotically, but it motivates attacking the following stronger positive-cone problem.

## Theorem `P04-I0101-POSITIVE-MARKOV-S3-REDUCTION-30` — PROVED / STRUCTURAL-PARTIAL

Let `H` have `n` vertices and let `0<t<n`. Suppose there is a matrix `P` satisfying

\[
P=P^\top,\qquad P\mathbf 1=\mathbf1,\qquad P_{ii}=0,\qquad P_{ij}\ge0,
\tag{3.3}
\]

with

\[
P_{ij}=0\quad\text{whenever }ij\notin E(\overline H),
\tag{3.4}
\]

and

\[
P\succeq -\delta I,
\qquad
\delta=\frac{t}{n-t}.
\tag{3.5}
\]

Then

\[
\boxed{\vartheta(\overline H)\le t.}
\tag{3.6}
\]

Equivalently, within the cone of entrywise nonnegative complement weights having constant row sum `n-t`, it is enough and necessary for the associated certificate to require a weighted complement adjacency `A` with

\[
A\mathbf1=(n-t)\mathbf1,
\qquad
\lambda_{\min}(A)\ge -t.
\tag{3.7}
\]

### Proof

Set

\[
A=(n-t)P,
\qquad B=J-A.
\tag{3.8}
\]

Because `P` has zero diagonal and vanishes on `E(H)`, `B_{ii}=1` and `B_{ij}=1` on every edge of `H`, so `B` is feasible in (3.1). Its slack at level `t` is

\[
tI-B=tI+(n-t)P-J.
\tag{3.9}
\]

Since `P` is symmetric stochastic, `\mathbf1` is an eigenvector with eigenvalue one and `\mathbf1^\perp` is invariant. On `\operatorname{span}\{\mathbf1\}` the matrix in (3.9) has eigenvalue

\[
t+(n-t)-n=0.
\tag{3.10}
\]

On `\mathbf1^\perp`, the `J` term vanishes, so (3.9) restricts to

\[
tI+(n-t)P\succeq0
\tag{3.11}
\]

exactly by (3.5). Hence `tI-B\succeq0`, therefore `\lambda_{\max}(B)\le t`, proving (3.6).

Conversely, if a nonnegative complement-supported `A` satisfies `A\mathbf1=(n-t)\mathbf1`, define `P=A/(n-t)`. Then `P` satisfies (3.3)--(3.4), and for `B=J-A`, the restriction of `tI-B` to `\mathbf1^\perp` is `tI+A`. Therefore `tI-B\succeq0` if and only if `\lambda_{\min}(A)\ge -t`, equivalently `P\succeq-[t/(n-t)]I`. This proves the constant-row positive-cone equivalence. `\square`

### Source specialization

For `H=G_{p,2}` we have

\[
n=\frac{p-5}{4},
\qquad
t_p=\frac23\sqrt p.
\tag{3.12}
\]

The Markov lower-edge threshold becomes exactly

\[
\boxed{
\delta_p
=\frac{t_p}{n-t_p}
=\frac{8\sqrt p}{3p-8\sqrt p-15}
\sim\frac{8}{3\sqrt p}.
}
\tag{3.13}
\]

Thus the source conjecture would follow from the **stronger** statement:

This is a one-sided lower-edge design problem. Unlike usual fastest-mixing Markov-chain work, no upper SLEM condition is required; only the negative edge matters for the theta certificate.

# 4. B27 — swap the quantifier: average first, then solve the clean family in three Fourier sectors

The theorem above deliberately asks for one structured object `P_p` for each prime, rather than separately optimizing every free theta-dual entry. This stronger quantifier buys exact symmetry reduction.

Let `Gamma <= Aut(H)`. If `P` is feasible in (3.3)--(3.5), then

\[
\overline P
=\frac1{|\Gamma|}\sum_{g\in\Gamma}U_g P U_g^{-1}
\tag{4.1}
\]

is still symmetric, stochastic, entrywise nonnegative, complement-supported, zero-diagonal, and satisfies `\overline P+\delta I\succeq0`. Therefore one may assume an optimal positive Markov certificate is automorphism-invariant.

Now restrict to the clean infinite family

\[
p\equiv5\pmod{24},
\tag{4.2}
\]

where prior P04 work proved that the anharmonic `S_3` action on `V(G_{p,2})` is free. Put

\[
m=\frac{p-5}{24},
\tag{4.3}
\]

choose orbit representatives `x_1,...,x_m`, and identify the vertex set with `{1,...,m} x S_3`.

Every `S_3`-equivariant transition matrix has the form

\[
P_{(a,h),(b,k)}=w_{ab}(h^{-1}k)
\tag{4.4}
\]

for six-channel kernels `w_{ab}:S_3\to\mathbb R_{\ge0}`. The exact constraints are

\[
w_{ba}(g^{-1})=w_{ab}(g),
\tag{4.5}
\]

\[
\sum_{b=1}^m\sum_{g\in S_3}w_{ab}(g)=1
\quad(a=1,\ldots,m),
\tag{4.6}
\]

and

\[
w_{ab}(g)=0
\quad\text{unless }x_a\text{ and }g x_b\text{ are distinct nonadjacent vertices of }H.
\tag{4.7}
\]

Let `1`, `sgn`, and `std` be the three irreducible real representations of `S_3`, of dimensions `1,1,2`. Define

\[
Q_{ab}=\sum_g w_{ab}(g),
\qquad
S_{ab}=\sum_g \operatorname{sgn}(g)w_{ab}(g),
\tag{4.8}
\]

and the `2m x 2m` block matrix

\[
R_{ab}=\sum_g w_{ab}(g)\rho_{\rm std}(g).
\tag{4.9}
\]

Fourier transformation of the regular representation gives the exact orthogonal decomposition

\[
\boxed{
P\simeq Q\oplus S\oplus(I_2\otimes R).
}
\tag{4.10}
\]

The dimensions are `m+m+2(2m)=6m`, as required. Hence

\[
\boxed{
P+\delta I\succeq0
\iff
Q+\delta I_m\succeq0,
\quad S+\delta I_m\succeq0,
\quad R+\delta I_{2m}\succeq0.
}
\tag{4.11}
\]

Equation (4.11) is the exact clean-family target: choose **nonnegative six-channel transition weights** satisfying the arithmetic support masks (4.7), while keeping all three `S_3` Fourier blocks above `-delta_p`.

This interfaces directly with prior P04 work rather than replacing it. The level-4 theorem already expresses all six adjacency/nonadjacency channel signs by fixed-degree quadratic trace functions, and the twisted-trace filter already prevents exponential `6^k` channel proliferation. The present theorem supplies the missing positive/stochastic optimization object on which those arithmetic identities can act.

# 5. B25 — count the same quantity twice: closed walks versus three Fourier sectors

For every positive integer `k`, the decomposition (4.10) gives the exact trace identity

\[
\boxed{
\operatorname{Tr}(P^k)
=\operatorname{tr}(Q^k)
+\operatorname{tr}(S^k)
+2\operatorname{tr}(R^k).
}
\tag{5.1}
\]

On the other hand, because `P` is a transition matrix supported on complement edges,

\[
\operatorname{Tr}(P^k)
=
\sum_{v_0,\ldots,v_{k-1}}
P_{v_0v_1}P_{v_1v_2}\cdots P_{v_{k-1}v_0},
\tag{5.2}
\]

which is the total weight of closed `k`-step complement walks. Equations (5.1) and (5.2) are the requested double count: a probabilistic/Green-function object downstairs equals three exact representation-sector moments upstairs.

The useful scaling is not `P` itself. Put

\[
X_p=\sqrt p\left(P_p-\frac1nJ\right).
\tag{5.3}
\]

Because `P_p` is symmetric stochastic, `J/n` is its stationary projection. On `\mathbf1^\perp`, the eigenvalues of `X_p` are exactly `\sqrt p` times the nontrivial eigenvalues of `P_p`. Thus the source threshold (3.13) becomes the **constant** lower-edge condition

\[
\boxed{
\lambda_{\min}(X_p)\ge-c_p,
\qquad
c_p=\sqrt p\,\delta_p
=\frac{8p}{3p-8\sqrt p-15}
\longrightarrow\frac83.
}
\tag{5.4}
\]

This normalization matters. Direct moments of `P_p` would have to resolve an `O(p^{-1/2})` edge in a space of dimension `Theta(p)`, forcing growing moment depth anyway. Centering and multiplying by `sqrt(p)` puts the desired lower edge at the fixed constant `-8/3+o(1)`, making logarithmic-degree polynomial/high-moment filters conceptually compatible with the target.

For an arithmetic choice of the six kernels `w_{ab}(g)`, (5.1) can then be combined with the already-proved level-4 lift and twisted trace filter: each selected sector moment can be represented using only the six closing `S_3` twists, with the fixed-degree Kummer channel factors exposed **before** taking absolute values. This is exactly where cancellation was lost in the earlier block-by-block and Frobenius arguments.

No growing-moment bound is proved here. The remaining problem is to find an explicit positive arithmetic weighting and then prove a one-sided extreme-edge estimate for the centered walk operator (5.3).
