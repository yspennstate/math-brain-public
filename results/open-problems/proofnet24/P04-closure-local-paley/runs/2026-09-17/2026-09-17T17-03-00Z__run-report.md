## 4. B5/B12 analytic route: differentiate the selected-sector resolvent and isolate an exact dissipation budget

Before the finite computation, I also pushed the previous max-determinant ODE in the assigned B5/B12 directions.

Let `C_z` be the unique maximum-determinant correlation completion for a graph H, with edge correlations `-z`, and let

\[
P_z=C_z^{-1},\qquad P_z'=-Z_z,\qquad C_z'=C_zZ_zC_z.
\]

All these canonical matrices commute with the anharmonic S3 action for `H=G_{p,2}`. Decompose their multiplicity operators into the three real irreducible S3 sectors

\[
\rho\in\{\mathbf 1,\operatorname{sgn},\operatorname{std}\},
\qquad d_\rho\in\{1,1,2\}.
\]

Write the corresponding multiplicity blocks as `C_rho`, `P_rho`, `Z_rho`.

### 4.1 B12 exact nonnegative sector budget

The previously proved global dissipation is

\[
\mathcal M_H'(z)=\operatorname{Tr}(Z_zC_zZ_zC_z).
\]

Because the matrices are S3-equivariant,

\[
\boxed{
\mathcal M_H'(z)
=D_{\mathbf1}(z)+D_{\mathrm{sgn}}(z)+2D_{\mathrm{std}}(z),
}
\tag{4.1}
\]

where

\[
\boxed{
D_\rho(z)
:=\operatorname{tr}(Z_\rho C_\rho Z_\rho C_\rho)
=\|C_\rho^{1/2}Z_\rho C_\rho^{1/2}\|_F^2
\ge0.
}
\tag{4.2}
\]

By the previous S3 twisted-trace filter, each sector contribution is also exactly

\[
\boxed{
D_\rho(z)=\frac16\sum_{g\in S_3}\chi_\rho(g)
\operatorname{Tr}\!\left(U_g Z_zC_zZ_zC_z\right).
}
\tag{4.3}
\]

So the maxdet evolution has an exact Pythagorean-style nonnegative dissipation budget by representation sector. This is useful structure, but it is not a new source theorem and I do not register a new structural claim ID for it.

There is a second exact balance. Since

\[
\mathcal M_H(z)=\frac{\operatorname{Tr}P_z-|V|}{z}
\]

and `P_z'=-Z_z`, differentiation gives

\[
\boxed{
-\operatorname{Tr}Z_z
=\mathcal M_H(z)+z\mathcal M_H'(z)\ge0.
}
\tag{4.4}
\]

Equivalently,

\[
-\left(\operatorname{tr}Z_{\mathbf1}
+\operatorname{tr}Z_{\mathrm{sgn}}
+2\operatorname{tr}Z_{\mathrm{std}}\right)
=\mathcal M_H+z(D_{\mathbf1}+D_{\mathrm{sgn}}+2D_{\mathrm{std}}).
\tag{4.5}
\]

**Failure mode:** these identities conserve/control only the *sum*. They do not force an individual sign or an upper bound for the trivial-sector contribution. Hence B12 finds an exact budget, but not the missing source-scale one-sided control.

### 4.2 B5 selected-sector resolvent derivative

For a sector rho and complex `w` off the spectrum, define

\[
R_\rho(w,z)=(wI-P_\rho(z))^{-1}.
\]

Since `P_rho'=-Z_rho`, ordinary inverse differentiation gives

\[
\boxed{
\partial_z\operatorname{tr}R_\rho(w,z)
=-\operatorname{tr}\bigl(R_\rho Z_\rho R_\rho\bigr).
}
\tag{4.6}
\]

Applying the exact character filter to the full-space resolvent `R=(wI-P_z)^{-1}` gives

\[
\boxed{
\partial_z\operatorname{tr}R_\rho(w,z)
=-\frac16\sum_{g\in S_3}\chi_\rho(g)
\operatorname{Tr}\!\bigl(U_gRZ_zR\bigr).
}
\tag{4.7}
\]

This is exactly the kind of six-term, sector-selective differentiated resolvent sought in the previous run: no `6^k` channel explosion appears.

**Failure mode:** `Z_rho` is not known to be positive or negative semidefinite, so (4.6)-(4.7) have no usable one-sided sign. The remaining analytic obligation is therefore very specific: prove arithmetic signed cancellation or sign control for these six twisted traces, or a deterministic upper bound on the trivial-sector resolvent/dissipation that survives to

\[
z_*(p)=\frac{3}{2\sqrt p-3}.
\]

This route did not close the source statement during this run, but it identifies the exact missing input rather than producing another unstructured lemma.
