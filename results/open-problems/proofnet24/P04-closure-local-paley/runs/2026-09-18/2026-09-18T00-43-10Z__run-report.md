## 3. New structural claim

### P04-I0101-LEVEL4-MARKOV-BLOWUP-34 = PROVED / STRUCTURAL-PARTIAL

For a finite simple graph `K=(V,E)`, let

\[
\mathcal P(K)=\{P:\ P=P^\top,\ P\ge0\text{ entrywise},\ P\mathbf1=\mathbf1,\ P_{ii}=0,
\ P_{ij}=0\text{ for }ij\notin E\}.
\]

When this set is nonempty, define

\[
\mu(K):=\max_{P\in\mathcal P(K)}\lambda_{\min}(P).
\]

For an integer `k>=1`, let `K^(k)` be the balanced independent `k`-blowup of `K`: each vertex is replaced by `k` independent clones and each base edge by a complete bipartite `K_{k,k}` between the two clone fibers.

**Theorem 34 (balanced-blowup invariance).**

1. `mathcal P(K)` is nonempty iff `mathcal P(K^(k))` is nonempty.
2. Whenever these sets are nonempty,
   \[
   \boxed{\mu(K^{(k)})=\mu(K).}
   \]
3. Compression from the blowup cannot decrease the least eigenvalue.
4. Averaging any blowup-feasible chain over independent permutations of each clone fiber cannot decrease its least eigenvalue and produces the uniform lift of its compression. Therefore breaking clone symmetry cannot improve this one-sided Markov objective.
5. For uniformly lifted symmetric operators the scalar Green/resolvent mass transfers exactly, with the natural factor `k`.

### Proof

Let `N=|V|`, label blowup vertices `(i,a)` with `a in {1,...,k}`, and define the isometry

\[
W:\mathbb R^N\to\mathbb R^{kN},\qquad
(Wf)_{(i,a)}=\frac{f_i}{\sqrt k}.
\]

Thus `W^T W=I` and `WW^T` is orthogonal projection onto the subspace of vectors constant on each clone fiber.

#### Compression

Let `Ptilde in mathcal P(K^(k))` and set

\[
P=W^\top\widetilde P W.
\]

Symmetry and entrywise nonnegativity are immediate. Also

\[
W\mathbf1_N=\frac1{\sqrt k}\mathbf1_{kN},
\]
so

\[
P\mathbf1_N
=W^\top\widetilde P W\mathbf1_N
=\frac1{\sqrt k}W^\top\mathbf1_{kN}
=\mathbf1_N.
\]

If `i=j`, every entry of the `(i,i)` fiber block of `Ptilde` is zero because a balanced independent blowup has no edges inside a clone fiber; hence `P_ii=0`. If `ij` is not an edge of `K`, the entire `(i,j)` block is zero, so `P_ij=0`. Therefore `P in mathcal P(K)`.

For every unit vector `f in R^N`, `Wf` is a unit vector, hence

\[
f^\top P f=(Wf)^\top\widetilde P(Wf)\ge\lambda_{\min}(\widetilde P).
\]

Taking the minimum over `f` gives

\[
\boxed{\lambda_{\min}(W^\top\widetilde P W)\ge\lambda_{\min}(\widetilde P).}
\]

This is the B13 monotonicity: least eigenvalue can only improve under fiber compression.

#### Uniform lift

Conversely, for `P in mathcal P(K)` set

\[
\widetilde P=W P W^\top.
\]

The `(i,j)` clone block has every entry equal to `P_ij/k`. Thus it is symmetric, entrywise nonnegative, supported exactly above base edges, has no within-fiber entries, and each clone row sums to

\[
\sum_j k\frac{P_{ij}}k=1.
\]

So `Ptilde in mathcal P(K^(k))`.

On `im(W)`, `Ptilde` is unitarily equivalent to `P`; on `im(W)^perp` it is zero. Hence

\[
\operatorname{spec}(\widetilde P)=\operatorname{spec}(P)\cup\{0\}^{(k-1)N}.
\]

Any feasible `P` is symmetric stochastic with zero diagonal, so `tr(P)=0` while `1` is an eigenvalue. For `N>1`, at least one eigenvalue is strictly negative. Therefore

\[
\lambda_{\min}(\widetilde P)=\lambda_{\min}(P).
\]

The compression inequality gives `mu(K^(k))<=mu(K)` and the uniform lift gives the reverse inequality. Thus

\[
\boxed{\mu(K^{(k)})=\mu(K).}
\]

The same two constructions prove feasibility equivalence. (For the degenerate one-vertex case both zero-diagonal stochastic feasible sets are empty, so no optimization value is asserted.)

#### Fiber averaging

Let `G=(S_k)^N` act by independently permuting clones inside each fiber. The blowup graph and `mathcal P(K^(k))` are invariant under this action. Since `lambda_min` is concave,

\[
\lambda_{\min}\left(\frac1{|G|}\sum_{g\in G}U_g\widetilde P U_g^\top\right)
\ge
\frac1{|G|}\sum_{g\in G}\lambda_{\min}(U_g\widetilde P U_g^\top)
=
\lambda_{\min}(\widetilde P).
\]

Every averaged `(i,j)` block is constant. If `P=W^T Ptilde W` is the compression, direct summation shows the averaged block entry is `P_ij/k`, hence the averaged matrix is exactly `W P W^T`. Thus clone-symmetry breaking cannot improve `mu`.

#### Resolvent/Green transfer

For any symmetric base operator `A` and its uniform lift `Atilde=WAW^T`, the orthogonal decomposition `im(W) plus im(W)^perp` gives, for `z>0` with `zI+A` invertible,

\[
\boxed{
(zI+\widetilde A)^{-1}
=W(zI+A)^{-1}W^\top+\frac1z(I-WW^\top).
}
\]

Since `1_{kN}=sqrt(k) W 1_N`,

\[
\boxed{
\frac1k\,\mathbf1_{kN}^\top(zI+\widetilde A)^{-1}\mathbf1_{kN}
=
\mathbf1_N^\top(zI+A)^{-1}\mathbf1_N.
}
\]

So the uniform lift preserves the scalar Green function relevant to the earlier positive weighted-complement resolvent formulation, after exactly the expected factor `k`.

This completes the proof of Theorem 34.

## 4. Exact P04 specialization

Let

\[
K_p:=\overline{G_{p,2}}
\]

on the localized vertex set `V_p`, and define the level-4 lifted graph `Ktilde_p` on `D_p^(4)` by

\[

\]

Because the established level-4 map `x:D_p^(4)->V_p` is exactly 4-to-1, because `q(t,s)=chi(x(t)-x(s))`, and because `q=0` for points in one deck fiber, `Ktilde_p` is exactly the balanced independent 4-blowup `K_p^(4)`.

Therefore Theorem 34 gives the exact identity

\[
\boxed{\mu(\widetilde K_p)=\mu(K_p)}
\]

whenever the positive-Markov feasible set is nonempty, and feasibility itself is equivalent upstairs and downstairs.

The prior positive-Markov reduction says that, with

\[
n=\frac{p-5}{4},\qquad
t_p=\frac23\sqrt p,\qquad
\delta_p=\frac{t_p}{n-t_p}
=\frac{8\sqrt p}{3p-8\sqrt p-15},

the source bound follows if there exists `P_p in mathcal P(K_p)` with

\[
\lambda_{\min}(P_p)\ge-\delta_p.

Here `D_p^(4)` has `p-5` points, i.e. it is `P^1(F_p)` minus exactly six points, and the support is the explicit quartic trace-function condition
