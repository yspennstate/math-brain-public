## 2. Setup and notation

Work over the binary alphabet `{0,1}`. For a pattern `r` write

- `n(r)=|r|`,
- `v(r)=#var(r)`,
- `c_a(r)` for the number of literal occurrences of terminal `a`, `a in {0,1}`,
- `c(r)=c_0(r)+c_1(r)`,
- if variable `x` occurs `k_x(r)` times, define its repeat surplus
  `rho(r)=sum_x (k_x(r)-1)`.

Then

`|r| = c(r)+v(r)+rho(r)`

and therefore Luo's measure can be rewritten exactly as

`mu(r)=2|r|-v(r)=|r|+c(r)+rho(r)`.                    (2.1)

For an inclusion candidate put

`n=|p|`, `m=|q|`, `d=n-m`.

The preceding report proved that equal-length strict inclusion always has `mu(p)>mu(q)`, so any bad pair must have `d>0`. Also, from `mu(p)<=mu(q)` one has

`v(p)-v(q) >= 2d`.                                   (2.2)

The requested moves this run were #5 (parameterize by `d` and occurrence profile), #11 (dualize to minimum-slice cover constraints), and #24 (classify the extremal length-10 profiles before any finite search). The next two claims are the resulting symbolic obstruction.

## 3. Constant monotonicity under pattern-language inclusion

### Claim P20-LUO-CONSTANT-MONOTONICITY-03 — PROVED / P20 SELF-CHECK

If `L(p) subseteq L(q)` over the binary alphabet, then, separately for each terminal,

`c_0(q) <= c_0(p)` and `c_1(q) <= c_1(p)`.             (3.1)

#### Proof

Fix a terminal `a` and let `b` be the other binary terminal. Form the minimum-length word `w in L(p)` by substituting the one-letter word `b` for every variable of `p`. Then every occurrence of `a` in `w` comes from a literal `a` already present in `p`, so

`#_a(w)=c_a(p)`.

If `L(p) subseteq L(q)`, then `w in L(q)`. Every word generated by `q` contains all literal `a` occurrences of `q`, regardless of how its variables are substituted. Hence

`#_a(w) >= c_a(q)`.

Therefore `c_a(p)>=c_a(q)`. Applying this for `a=0,1` gives (3.1). QED.

Combining (2.1) with a prospective bad inequality `mu(p)<=mu(q)` gives

`rho(q)-rho(p) >= d + c(p)-c(q)`.                     (3.2)

By (3.1), `c(p)>=c(q)`, so every bad pair necessarily satisfies

`rho(q) >= rho(p)+d >= d`.                            (3.3)

This is stronger than the raw variable-deficit condition because a shorter containing pattern must pay at least the entire length gap in repeated-variable surplus, not in constants.

## 4. Minimum-slice coefficient obstruction

For a pattern `r` and an integer `N`, let

`M_N(r)=L(r) intersect {0,1}^N`.

For `|p|=n`, the minimum slice `M_n(p)` is obtained by one-bit substitutions of every variable and has exactly

`|M_n(p)|=2^{v(p)}`.                                  (4.1)

Now let `|q|=m=n-d`. Suppose its distinct variables have occurrence multiplicities

`k_1,...,k_v`, where `v=v(q)`.

A substitution of `q` has output length exactly `n=m+d` iff the image length of variable `i` is `1+e_i` with integers `e_i>=0` satisfying

`sum_i k_i e_i = d`.                                  (4.2)

For a fixed feasible vector `e`, the number of binary content assignments is exactly

`2^{v+sum_i e_i}`.

Different length vectors may generate overlapping output words, so summing these assignments gives an upper bound. Define

`F_q(d) = sum_{e>=0: sum k_i e_i=d} 2^{sum e_i}`

or equivalently

`F_q(d) = [z^d] prod_i (1-2 z^{k_i})^{-1}`.           (4.3)

Then

`|M_n(q)| <= 2^{v(q)} F_q(d)`.                        (4.4)

Consequently, if `M_n(p) subseteq M_n(q)` and the bad-measure condition (2.2) holds, then

`4^d <= 2^{v(p)-v(q)} <= F_q(d)`.                    (4.5)

This is the requested occurrence-profile obstruction: before checking any actual words, a shorter `q` must have enough coefficient mass in (4.3) to cover the entire Boolean equality cube of `p`.

A coarse all-length corollary is also useful. In every feasible vector of (4.2), `sum e_i<=d`, so each summand in (4.3) is at most `2^d`; the number of nonnegative `v`-vectors with sum at most `d` is `binom(v+d,d)`. Thus

`F_q(d) <= 2^d binom(v(q)+d,d)`.                      (4.6)

Every bad pair therefore satisfies the necessary numerical condition

`binom(v(q)+d,d) >= 2^d`.                             (4.7)

No undecidable language-inclusion claim enters (4.1)--(4.7); these are exact necessary consequences of an inclusion.

## 5. Length 10: all gaps `d>=3` are eliminated analytically

Set `|p|=10`. Equal length `d=0` was handled for every length in the preceding report. It remains `d=1,...,9`.

### 5.1 Gaps `d>=4`

From (2.2), since `v(p)<=10`,

`v(q)<=10-2d`.                                       (5.1)

If `d=4`, then `v(q)<=2`. Equations (4.6)--(4.7) would require

`16 <= binom(v(q)+4,4) <= binom(6,4)=15`,

a contradiction.

If `d>=5`, then (5.1) gives `v(q)<=0`. But a pattern with no variables generates only one word of its own fixed length and has empty length-10 slice when `|q|<10`, so it cannot contain `M_10(p)`. Thus `d>=4` is impossible.

### 5.2 The only coefficient-extremal `d=3` profile

Now `d=3`, so `|q|=7` and `v(q)<=4`. Let `s_j` be the number of variables of `q` occurring exactly `j` times. Directly from (4.3),

`F_q(3) = 8 binom(s_1+2,3) + 4 s_1 s_2 + 2 s_3`.     (5.2)

A bad pair needs `F_q(3)>=4^3=64` by (4.5), and `rho(q)>=3` by (3.3).

- If `v(q)<=2`, the coefficient is maximized when both variables are singleton at degree 3, giving at most `8 binom(4,3)=32<64`.
- If `v(q)=3` and `rho(q)>=3`, at most two variables are singleton; when `s_1=2`, the third variable must occur at least four times, and (5.2) gives at most `32`. Fewer singletons only lower the value.
- Hence `v(q)=4`. Since `|q|=7` and `7=c(q)+v(q)+rho(q)`, condition `rho(q)>=3` forces exactly `c(q)=0`, `rho(q)=3`. The only occurrence partitions of seven positions into four positive parts are

  `(1,1,1,4)`, `(1,1,2,3)`, `(1,2,2,2)`.

  Formula (5.2) gives respectively

  `80`, `42`, `20`.

Therefore the **only** `d=3` occurrence profile surviving the numerical cube-size obstruction is

`(1,1,1,4)`, with no constants.                        (5.3)

But (2.2) now forces `v(p)>=4+6=10`, hence `p` has ten distinct variables and

`M_10(p)={0,1}^{10}`.                                  (5.4)

It remains to show that a pattern `q` with profile (5.3) cannot generate every length-10 binary word.

Let `x` be the variable occurring four times and let the other three variables be singletons. Because `d=3<4`, equation (4.2) forces the image of `x` to have length exactly one. Consider the alternating word

`w=0101010101`.

If two consecutive occurrences of `x` in the pattern had no singleton variable between them, their one-letter images would land at adjacent positions of `w`, which have opposite bits; impossible because all occurrences of `x` must be the same bit. Thus each of the three gaps between the four successive `x` occurrences must contain at least one of the three singleton variables. There are exactly three singleton occurrences total, so, up to their names, the pattern order must be

`x y x z x u x`,                                      (5.5)

with no singleton before the first or after the last `x`.

For the four copies of the same one-bit `x` to land on positions of the same parity in the alternating word, each of `|Y|,|Z|,|U|` must be odd: the distance between starts of consecutive `x` images is `1+|Y|`, then `1+|Z|`, then `1+|U|`, and each distance must be even. On the other hand, total output length ten gives

`|Y|+|Z|+|U| = 10-4 = 6`,

which is even, whereas a sum of three positive odd integers is odd. Contradiction.

Therefore no `d=3` bad pair exists.

This completes the analytic reduction for `|p|=10`: only the gaps `d=1,2` require finite checking.
