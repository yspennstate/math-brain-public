## 3. Method #17 — affine-cover literature: useful diagnosis, not a black box

The proposed transfer to finite-field covering theory was checked before coding.

Jamison's 1977 finite-field coset-cover theorem, in the standard later restatement, determines the minimum number of codimension-`d` affine subspaces needed to cover all nonzero points while avoiding the origin. For `F_2^s` this is `2^d-1+(s-d)`. Alon--Furedi-type grid-cover theorems similarly become especially strong when one specified Boolean point is left uncovered. Khare's 2009 work gives sharp generic bounds for unions of fixed-codimension subspaces.

Those hypotheses do **not** directly match the LUO slice problem. Fixed image-length pieces of `M_n(q)` may contain the same point, may contain the origin after translation, and need to cover the entire `p` equality cube rather than all-but-one point. Generic affine covers of a whole vector space can meet the ordinary cardinality lower bound much more closely. Therefore importing Jamison/Alon--Furedi as a black box does not supply the needed all-length contradiction.

The useful conclusion is negative but structural: the missing gain has to use that LUO pieces are **equality-block subspaces coming from contiguous variable images**, not arbitrary affine subspaces. This led to the partition-cube reformulation below.

## 4. P20-LUO-PARTITION-CUBE-06 — exact minimum-slice geometry

**Claim (PROVED / P20 SELF-CHECK).** For a binary pattern `p` of length `n`, its minimum-length slice

`M_n(p):=L(p) ∩ {0,1}^n`

is exactly a partition cube

`C(b;B_1,...,B_v) = { b OR union_{j in J} B_j : J subseteq [v] }`,

where:

- `b` is the set of coordinates occupied by literal `1` in `p`;
- `B_1,...,B_v` are pairwise-disjoint nonempty coordinate sets, one for each variable, namely its occurrence positions;
- all coordinates outside `b union B_1 union ... union B_v` are literal `0`.

Conversely, every such datum defines a pattern with that minimum slice.

**Proof.** At output length `n=|p|`, every variable image has length exactly one. Assigning bit `0` or `1` to variable `x_j` therefore sets all coordinates in its occurrence set `B_j` to that bit. Literal-1 coordinates form the fixed base `b`; literal-0 coordinates stay zero. Hence every minimum word has exactly the displayed form, and every choice of subset `J` is obtained by assigning bit `1` precisely to variables in `J`. Conversely, put one variable symbol on each block `B_j`, literal `1` on `b`, and literal `0` elsewhere. This realizes the stated cube. QED.

A second simple observation makes the q-side search exact. If a bad pair has `v(p)>v(q)+2d`, freeze any `v(p)-(v(q)+2d)` variables of `p` to literal `0` in the minimum slice.
