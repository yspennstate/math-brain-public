## 4. #18 SAY IT IN ANOTHER LANGUAGE — exact half-cycle reformulation

Write

`m = 2h+1`, so `h=(m-1)/2`.

Let `X=x`, `k=|X|`, and let `I` be a cyclic interval of length `h`. Put `a=|I cap X|`. Since `|I|=h<m/2`,

`|I triangle X| = h + k - 2a`,

so the source inequality for this `I` is exactly

`h+k-2a < h`, i.e. `a > k/2`.

Thus a short half-cycle witnesses the conjecture precisely when it contains **strictly more than half of all points of X**.

For the complementary long interval `W=I^c`, note that the complement of a proper cyclic interval is again a cyclic interval and

`I^c triangle X = I triangle X^c`

(after complementing both sets in the symmetric difference). Therefore a length-`h+1` witness for `X` is equivalent to a length-`h` interval `I` containing strictly more than half of the points of `X^c`.

So the whole conjecture reduces to:

> For one of `X` and `X^c`, find a length-`h` cyclic interval containing strictly more than half of that set.

Because `m` is odd, exactly one of `|X|` and `|X^c|` is odd.

## 5. #24 FIND THE EXTREMAL OBJECT — parity plus averaging is decisive

Let `Y` be whichever of `X` and `X^c` has odd cardinality, and write

`s = |Y|`.

Since `X` is nonempty and proper, `1 <= s < m`, and `s` is odd.

For every `t in Z_m`, let

`I_t = {t,t+1,...,t+h-1}`

be the cyclic interval of length `h` starting at `t`. There are exactly `m` such intervals. Every point of `Z_m` lies in exactly `h` of them, hence the exact double count

`sum_t |I_t cap Y| = h s = s(m-1)/2`.

Now compare this with the largest integer not exceeding `s/2`, namely `(s-1)/2`. Because `s<m`,

`h s - m(s-1)/2`

`= [s(m-1)-m(s-1)]/2`

`= (m-s)/2 > 0`.

Therefore it is impossible that every `|I_t cap Y| <= (s-1)/2`. Hence some length-`h` interval `I` satisfies

`|I cap Y| >= (s+1)/2 > s/2`.

This is the extremal object: an almost-semicircle containing a strict majority of the odd-cardinality side.

## 6. #2 ATTACK THE NEGATION FIRST — contradiction proof of the exact conjecture

The previous double count can be read directly as a negation attack. Assume the source conjecture fails for some odd `m=2h+1` and nonempty proper `X`.

Choose the odd-cardinality side `Y in {X,X^c}` and let `s=|Y|`.

If every length-`h` interval contained at most `(s-1)/2` points of `Y`, summing over all `m` intervals would give

`h s <= m(s-1)/2`.

Substituting `h=(m-1)/2` gives

`s(m-1) <= m(s-1)`,

hence `m <= s`, contradicting `s<m`.

So there is a length-`h` cyclic interval `I` with `a:=|I cap Y|>s/2`.

There are two cases.

### Case 1: `Y=X`

Take `W=I`. Then `|W|=h`, so `min(|W|,m-|W|)=h`, and

`|W triangle X| = h+s-2a < h`.

Thus `W` is a source-valid witness.

### Case 2: `Y=X^c`

Take `W=I^c`, which is a cyclic interval of length `h+1`. Since `X=Y^c`,

`W triangle X = I^c triangle Y^c = I triangle Y`.

Hence

`|W triangle X| = |I triangle Y| = h+s-2a < h`.

Also

`min(|W|,m-|W|)=min(h+1,h)=h`.

Again `W` is a source-valid witness.

This proves the source statement for every odd `m` and every nonempty proper `X subset Z_m`.

The proof actually gives the stronger prescribed-length conclusion:

- if `|X|` is odd, a witness exists with `|W|=(m-1)/2`;
- if `|X|` is even, a witness exists with `|W|=(m+1)/2`.

For `m=1` there is no nonempty proper `X`, so the statement is vacuous if that degenerate odd value is admitted; odd cycles themselves begin at `m=3`.
