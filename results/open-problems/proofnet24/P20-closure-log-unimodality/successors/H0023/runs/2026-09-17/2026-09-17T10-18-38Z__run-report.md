## 4. Moves #11, #19, #24 — dualize the center, make the algorithm, find its smallest obstruction

Write

`L := log n/loglog n`.

Fix constants

`0 < eps < 1`,  `0 < delta < eps`,

and suppose

`k=(1+eps+o(1))L`,  `m=n/(k+1)`,  `p=(1+eps)log n/n`,

while the proposed two-ended prefix stage uses depth `d` from each side with

`2d=(1+delta+o(1))L`.

Suppose an adaptive prefix algorithm constructs `2m` pairwise vertex-disjoint `d`-edge prefixes, one from every terminal in `a` and `b`. Let `W` contain the `2m` final frontier vertices together with every vertex unused by the committed prefix interiors. Then exactly

`|W| = n - 2dm = m(k+1-2d)`.

A central completion would have to be a spanning collection of `m` paths inside `G[W]`, each of length

`ell = k-2d`,

joining the left and right frontiers according to the requested permutation.

The natural deferred-randomness implementation leaves all edges with both endpoints in `W` unexposed during the prefix stage. More generally, assume only the following precise condition:

> Conditional on the prefix-stage history and the resulting random set `W`, the edge indicators of `G[W]` remain independent Bernoulli(`p`).

This is exactly the property one gets from a non-anticipating exposure in which internal edges of the final remainder are never queried.

### Claim `P20-H0023-DEFERRED-CENTER-ISOLATION-BARRIER-03`

**PROVED / P20 SELF-CHECK / METHOD BARRIER ONLY.**

Under the conditions above, conditional on every prefix-stage history satisfying the deferred-center condition, with probability `1-o(1)` the graph `G[W]` contains

`n^(1-eps+delta+o(1))`

isolated vertices. Consequently no spanning central path system on `W` exists. In particular, for every fixed `0<eps<1`, a proof architecture that spends at least one critical-depth unit on two-sided prefixes and then asks an **independent fresh induced remainder** to supply the center cannot establish source Conjecture 1.6 at its minimum depth.

This is a method barrier, not a source counterexample: a successful construction may choose the residual vertices using information about their internal edges, or may interleave prefix and center routing so that no fresh induced center is ever required.

### Proof

Set `N=|W|`. Since `n=m(k+1)`, the displayed parameter choices give

`N/n = 1 - 2d/(k+1) = (eps-delta)/(1+eps) + o(1)`.

Hence

`pN = (eps-delta+o(1)) log n`.

Conditional on the prefix-stage history, `G[W]` is `G(N,p)`. Let `Z` be its number of isolated vertices and put

`q=(1-p)^(N-1)`.

Then

`E[Z | history] = Nq`.

Because `p^2 N=o(1)`,

`q = exp(-pN+o(1)) = n^(-(eps-delta)+o(1))`,

and therefore

`mu := E[Z | history] = n^(1-eps+delta+o(1)) -> infinity`.

For distinct `u,v in W`,

`P(u,v both isolated | history) = (1-p)^(2N-3) = q^2/(1-p)`.

Thus

`Var(Z | history) <= mu + (p/(1-p)) mu^2`,

so

`Var(Z | history)/mu^2 <= 1/mu + p/(1-p) = o(1)`.

Chebyshev gives

`Z=(1+o_p(1))mu`,

uniformly conditional on every admissible prefix history. In particular `Z>0` whp. A spanning central path system has positive selected degree at every vertex of `W`, so an isolated vertex is impossible. QED.

No exact checker was created: this is an asymptotic analytic statement with a complete proof on the page.

## 5. Move #11 — the dual obstruction is already the singleton constraint

Ignoring pair labels and acyclicity makes central completion easier: a valid central path system would in particular contain a degree-constrained spanning subgraph of `G[W]` with selected degree `1` at every frontier and selected degree `2` at every nonfrontier residual vertex. This is an `f`-factor / `b`-matching relaxation.

The full Tutte/Hall-type dual has many cut and parity constraints, but the deferred-center calculation shows that one need not reach them: the **singleton capacity constraint** is already violated by polynomially many isolated residual vertices. So the smallest dual obstruction to the decoupled algorithm is not a complicated Hall set; it is one vertex.

This is useful because it distinguishes two tasks that were conflated in the previous heuristic:

1. prefix entropy can cure the source's full-path *spread* concentration;
2. but a spanning independent center must itself sit above its local degree/isolation threshold.

At the intended split those requirements point in opposite directions.

## 6. Move #19 — why the naive adaptive two-ended algorithm fails, and what survives

The intended algorithm was:

1. grow mobile disjoint prefixes from both `a` and `b` using roughly one critical-depth unit in total;
2. preserve all edges internal to the leftover set as deferred randomness;
3. use the leftover induced random graph to join the frontiers in a short central stage.

The barrier theorem shows that Step 2 is fatal for `eps<1`. If the total prefix depth is `(1+delta)L`, then the leftover fraction is

`beta=(eps-delta)/(1+eps)+o(1)`,

so the full source density induces effective mean degree

`p|W|=(eps-delta+o(1))log n < log |W|`.

No way of splitting the source's total edge probability among independent sprinklings repairs this, because the theorem used the **entire** `p=(1+eps)log n/n` inside `W`.

The surviving algorithmic lesson is that a sharp proof must not freeze an edge-independent residual core after the prefixes. The residual choice must depend on internal connectivity, or the path construction must be interleaved globally so that center vertices are consumed while routing is built.

This is exactly where the 1996 Broder–Frieze–Suen–Upfal strategy becomes relevant: they do not reserve a small fresh induced center. Instead they use flow to randomize adversarial endpoints and then route random pairs through the evolving graph, deleting used vertices. Their theorem reaches the same `n loglog n/log n` pair-count **order** above the connectivity threshold. What it lacks for H0023 is the sharp capacity constant, exact common length `k`, and the requirement to use every vertex. Porting this technique is therefore a materially new route, not another optimization of the source's two-half proof.
