### 3.1 The easiest local obstruction disappears at the conjectured density

A spanning linking system forces every nonterminal vertex to have graph degree at least two: every such vertex is internal on one of the spanning paths. At

`p=(1+eps) log n/n`,

however,

`P(delta(G)<=1)`

is already `o(1)`. Indeed, by a union bound over vertices,

`P(delta(G)<=1)
 <= n[(1-p)^(n-1) + (n-1)p(1-p)^(n-2)]

Thus the degree-0/1 obstruction cannot refute Conjecture 1.6 for any fixed source `eps>0`.

Endpoint singleton/Hall obstructions have the same qualitative problem: each fixed terminal sees order `log n` neighbors while `m=n/(k+1)=o(n)`, so the most immediate endpoint-neighborhood defects are far above their threshold. I did not promote a full Hall theorem here because it is unnecessary for the negative-search conclusion and would be a separate lemma without metric movement.

### 3.2 The fixed-matching first moment points in the *positive* direction

For a fixed prescribed matching between two endpoint `m`-tuples, where `n=(k+1)m`, the exact number of spanning `(a,b;k)` path systems in the complete graph is

`(n-2m)!`,

and every such path system contains `n-m` edges. Therefore for `G(n,p)`

`E X = (n-2m)! p^(n-m)`.

At source depth

`k=(1+eps+o(1)) log n/log log n`

## 4. Move #6 — a rigorous barrier for the source's current two-stage reduction

The deformation of the source proof reveals a sharper fact: the constant-factor loss in Lemma 3.2 is not removable merely by tightening constants inside the same two-spanning-stage architecture.

### Claim `P20-H0023-HALF-SPLIT-BARRIER-01` — PROVED / P20 SELF-CHECK / METHOD BARRIER ONLY

Fix constants `C>0` and `alpha in (0,1)`. Let `N -> infinity`, let

`d=(alpha+o(1)) log N/log log N`,  `m=N/(d+1)`,

with the divisibility condition understood, and fix disjoint ordered `m`-tuples `x,y`. If

`p <= C log N/N`,

then

`P(G(N,p) contains a spanning (x,y;d)-path system)
 <= exp(-(1/alpha-1+o(1)) N log log N)`.

In particular this probability tends to zero superpolynomially.

### Proof

Let `X` count spanning `(x,y;d)` path systems. The `N-2m` internal vertices can be assigned, in order, to the `m` prescribed paths in exactly `(N-2m)!` ways, and each path system uses `md=N-m` edges. Hence

`E X=(N-2m)! p^(N-m)`.

Using `(N-2m)! <= N^(N-2m)` and `p<=C log N/N`, we get

`log E X
 <= (N-2m)log N +(N-m)(log C + log log N - log N)`

`= -m log N +(N-m)log log N + O(N)`.

Since

`m=N/(d+1)=(1/alpha+o(1)) N log log N/log N`,

we have

`m log N=(1/alpha+o(1))N log log N`.

Therefore

`log E X <= -(1/alpha-1+o(1))N log log N`.

Markov's inequality gives the stated probability bound. QED.

### Consequence for the actual source reduction

Now fix a source parameter `eta in (0,1)` and consider the hardest admissible depth scale

`k=(1+eta+o(1)) log n/log log n`.

In source Lemma 3.2, each of the two auxiliary vertex sets has

`N_i=(1/2+o(1))n`,

while the required spanning path-system depth is

`d_i=(1/2+o(1))k`.

Since `log N_i/log log N_i=(1+o(1))log n/log log n`, this gives

`d_i=((1+eta)/2+o(1)) log N_i/log log N_i`.

Because `(1+eta)/2<1`, the claim applies. The conjectured source density satisfies

`p=(1+eta)log n/n = O(log N_i/N_i)`,

## 5. Move #30 — localize the scale, and a new route suggested by the barrier

The source's difficult `psi=1` construction already makes a one-sided prefix of depth

`d=(1-o(1)) log n/log log n`.

The barrier above explains why concatenating two such spanning mechanisms costs roughly two critical depths. At the source target, there is only one critical depth available.

A different local calculation suggests where that factor of two might be recovered. If one can expose **flexible prefix families from both ends** to depth about

`(1/2) log n/log log n`,

then the natural branching scale `np=Theta(log n)` gives about

`(log n)^d = n^(1/2+o(1))`

potential endpoint choices per side at the heuristic single-pair level. Two such flexible endpoint families have product size `n^(1+o(1))`, so the expected number of random cross edges between them is of order

`p n = Theta(log n)`.

This is exactly the arithmetic needed to meet a prescribed pair in total length about `log n/log log n`, rather than spending one full critical depth before beginning the completion step.

This is **not yet a theorem**: the hard obligations are simultaneous vertex-disjointness for `m~n log log n/log n` paths, preserving enough spread after conditioning, and — most importantly — realizing every endpoint permutation in the same graph. But the calculation identifies a genuinely different route: a two-sided flexible-prefix / central-matching construction, not a constant optimization of the source's one-sided prefix plus Lemma 3.2 split.

A second lesson is that naive union bounding over all `m!` permutations is structurally wrong. Global defects such as low-degree vertices have only polynomially small failure probability at this density even though they simultaneously obstruct every permutation; any eventual proof must first certify a global resilient host event and only then obtain permutation-uniform routing inside that host event.

**Outcome of #30:** the source proof loses the sharp constant at a precisely identified scale. The next route should spend the single available critical depth symmetrically, or otherwise encode permutation switching throughout the paths rather than in two separate spanning stages.
