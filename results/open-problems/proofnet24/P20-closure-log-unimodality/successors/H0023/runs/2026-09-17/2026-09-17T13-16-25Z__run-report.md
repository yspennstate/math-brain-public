## 4. #23 — exact path-hypergraph reduction

### Claim `P20-H0023-PATH-HYPERGRAPH-REDUCTION-05`

**Status:** `PROVED / P20 SELF-CHECK / FIXED-PERMUTATION EXACT REDUCTION ONLY`.

Fix an admissible source instance `(n,k,m,a,b)` with `n=(k+1)m`, fix one permutation `pi in S_m`, and let

`W := [n] \ ( {a_1,...,a_m} union {b_1,...,b_m} )`,

so

`N := |W| = n-2m = m(k-1)`.

Define the **path-certificate multihypergraph** `H_pi(G)` as follows.

- Vertex set: the disjoint union `[m] disjoint-union W`.
- Uniformity: `k`.
- For every label `i in [m]` and every ordered `(k-1)`-tuple `(x_1,...,x_{k-1})` of distinct vertices of `W`, if

`a_i x_1, x_1 x_2, ..., x_{k-2} x_{k-1}, x_{k-1} b_{pi(i)}`

are all edges of `G`, insert a hyperedge

`{i,x_1,...,x_{k-1}}`

and retain the ordered tuple as its certificate. Different graph-path orders giving the same underlying vertex set are parallel hyperedges. Parallel copies are harmless for matching existence: a matching can use at most one of them, and each copy carries the graph-path order needed below.

Then:

> `G` contains a spanning `(a,pi(b);k)`-path system **if and only if** `H_pi(G)` has a perfect matching.

#### Proof

If `G` has the required spanning path system, write the path joining `a_i` to `b_{pi(i)}` as

`a_i, x^i_1, ..., x^i_{k-1}, b_{pi(i)}`.

Its internal vertices lie in `W`, are distinct, and produce a certified hyperedge

`e_i={i,x^i_1,...,x^i_{k-1}}`.

The graph paths are vertex-disjoint, so the hyperedges `e_i` are disjoint. The path system is spanning, hence its internal vertices partition `W`; the labels `1,...,m` are obviously also covered exactly once. Thus `{e_i:i in [m]}` is a perfect matching of `H_pi(G)`.

Conversely, suppose `M` is a perfect matching of `H_pi(G)`. The hypergraph has

`|[m] disjoint-union W| = m+N = m+m(k-1)=mk`

vertices and every hyperedge has size `k`, so a perfect matching has exactly `m` hyperedges. Every hyperedge contains exactly one label, and perfectness covers all `m` labels, so for each `i` exactly one selected hyperedge has label `i`. Use its retained ordered certificate to recover a length-`k` graph path from `a_i` to `b_{pi(i)}`. Since matching hyperedges are vertex-disjoint, the recovered graph paths have disjoint internal vertices; the terminal tuples were disjoint by the source hypothesis. Since the matching covers every vertex of `W`, these paths together cover all `n` graph vertices. Hence they form a spanning `(a,pi(b);k)`-path system. □

This reduction simultaneously enforces endpoint pairing, exact common length, vertex-disjointness, and spanning use of every vertex. There is no common static layer, no separate interface leg, and no external residual core.

## 5. Exact first-moment regularity and codegree hierarchy

The reduction has a source-specific identity which is absent from a generic path packing problem.

Let `(N)_r=N(N-1)...(N-r+1)` and set

`mu := (N)_{k-1} p^k`.

For `G~G(n,p)`, degrees/codegrees below count path certificates, i.e. multiplicity in `H_pi(G)`.

### 5.1 Vertex degrees are exactly balanced in expectation

For a label `i`, choosing the ordered internal tuple gives

`E deg(i) = (N)_{k-1} p^k = mu`.

For an internal vertex `x in W`, choose the terminal label (`m` choices), the position of `x` among the `k-1` internal positions (`k-1` choices), and the remaining ordered internal vertices. Hence

`E deg(x) = m(k-1)(N-1)_{k-2} p^k`.

Using the exact source balance `N=m(k-1)`, this equals

`(N)_{k-1}p^k = mu`.

Thus the two very different vertex classes have **the same expected degree exactly**, not merely asymptotically.

### 5.2 Pair codegrees are tiny relative to the degree scale

For distinct labels `i != j`, the codegree is identically zero because every path hyperedge contains exactly one label.

For a label `i` and internal `x`,

`E codeg(i,x) = (k-1)(N-1)_{k-2}p^k = mu/m`.

For distinct internal vertices `x,y`,

`E codeg(x,y) = m(k-1)(k-2)(N-2)_{k-3}p^k`

and therefore, again using `N=m(k-1)`,

`E codeg(x,y) = mu * (k-2)/(N-1)`.

At the minimum source depth, `m=(1+o(1))n/k`, so every nonzero expected pair-codegree/degree ratio is `O(k/n)=n^{-1+o(1)}`.

### 5.3 Higher internal codegrees have an exact formula

For any fixed set `S subset W` of `r>=1` internal vertices,

`E codeg(S) = m (k-1)_r (N-r)_{k-1-r} p^k`

and therefore

`E codeg(S)/mu = (k-2)_{r-1}/(N-1)_{r-1}`.

If one additionally fixes a label `i`, then

`E codeg({i} union S)/mu = (k-1)_r/(N)_r`.

So at the level of exact first moments the entire certificate hypergraph has the codegree decay one would hope for in a nibble/perfect-matching problem.

### 5.4 Boundary-scale degree size

At

`k=(1+eps+o(1)) log n/loglog n`, `p=(1+eps)log n/n`,

we have `N=n(1-o(1))` and `k^2/N=o(1)`, so

`log mu = log((N)_{k-1}) + k log p`

`= -log n + k loglog n + k log(1+eps) + O(1)`

`= (eps+o(1)) log n`.

Hence

`mu = n^{eps+o(1)}`.

This is the central positive signal of the run: at the sharp source boundary, the fixed-permutation path hypergraph is **polynomial-degree and first-moment balanced**, while its expected pair-codegrees are smaller by `n^{1-o(1)}`.

What is *not* proved: concentration of all these random degrees/codegrees around their expectations. The hyperedges are strongly dependent because path certificates share underlying graph edges. No almost-regularity theorem is claimed here.

## 6. #17 — compare with threshold Hamilton absorption and hypergraph nibble theory

### 6.1 Why the strongest nearby graph absorbers still do not port directly

Espig-Frieze-Krivelevich prove that, for an arbitrary fixed perfect matching `M`, the random graph process hits a Hamilton cycle containing `M` exactly when the random-edge graph loses its isolated vertices. This is strong evidence that threshold-scale randomness can absorb forced spanning structure. It still omits the H0023 features that matter here: the matching edges need not occur in a prescribed cyclic order, and the gaps between them need not all equal `k`.

A still more current comparison is Draganić-Krivelevich, *Efficient Hamilton covers and linear arboricity of random graphs*, arXiv:2607.14881v1 (16 July 2026). Their threshold-range proof explicitly gives each intermediate linear forest a **private linear-sized reservoir** and then routes its endpoints through that reserved random set to complete a Hamilton cycle. This is precisely what H0023's saturated identity `m(k+1)=n` forbids: there is no linear outside reservoir to reserve. Their result therefore supports the diagnosis that H0023 needs absorption distributed among the candidate routes themselves rather than a final external reservoir.

### 6.2 Why a standard Pippenger/Rödl black box cannot yet be invoked

The path-hypergraph moments suggest a nibble. But the source uniformity is

`k = Theta(log n/loglog n) -> infinity`.

The modern Gould-Kelly 2025 nibble paper states its comparison theorems with constant hierarchies such as

`1/D << 1/K, 1/k, delta, gamma < 1`

and, for Vu's theorem,

`1/D << 1/A << 1/k <= 1`.

These are fixed-uniformity asymptotic statements; they do **not** supply a black-box theorem uniform for `k=Theta(log n/loglog n)`.

Older Grable/Kostochka-Rödl/Vu bounds are highly suggestive: nearly regular hypergraphs with sufficiently small codegrees admit very large matchings, and their published formulas expose the same favorable `D/codegree` ratios seen above. But available statements hide constants/thresholds as functions of `k` or explicitly fix `k`. I therefore do not apply them to H0023 without a quantitative growing-uniformity proof.

This identifies a concrete mathematical port, not just an analogy: establish the needed concentration for `H_pi(G)` and run a **quantitative growing-uniformity nibble** whose constants remain valid for `k~log n/loglog n`.

## 7. #22 — the smallest absorber compatible with all four barriers

The preceding failures say what the absorber cannot be:

- not another spanning half;
- not fixed common layers;
- not a fresh residual induced graph;
- not a separate diffuse interface/central leg;
- not a private linear outside reservoir.

In the path-hypergraph language the smallest plausible absorber is instead an **augmenting switch**: a bounded or slowly growing collection of currently chosen path-hyperedges is replaced by a same-cardinality collection of alternative path-hyperedges so that the covered vertex set changes in a prescribed small way while all endpoint labels remain covered exactly once.

This is exactly the kind of distributed object recent hypergraph matching work calls an augmenting structure/star, but here it must live in a path-generated, growing-uniformity, dependent random multihypergraph. Such switches use the enormous redundancy `mu=n^{eps+o(1)}` *along the already existing route system*, rather than saving a geometrically separate reservoir.

This is the first architecture found by P20 that obeys all four existing barriers by construction. It is still incomplete for three precise reasons:

1. **Random regularity:** prove with probability `1-o(1)` that all relevant path-hypergraph vertex degrees are `(1+o(1))mu` and the complete codegree hierarchy is suitably small, despite path-overlap dependence.
2. **Growing-uniformity nibble:** obtain an almost-perfect matching with quantitative estimates valid for `k=Theta(log n/loglog n)`; the standard black boxes recovered in the literature hold with fixed `k` hierarchies.
3. **Perfect completion:** turn almost-perfect into perfect at full saturation using internal path switches. Threshold Hamilton proofs usually reserve a linear external set, which is unavailable here.

Even after solving all three for a fixed `pi`, the source's simultaneous `for every pi in S_m` quantifier remains. The previous symmetry bridge would then give `1-o(1)` density of realizable permutations on a typical graph, not all of `S_m`.
