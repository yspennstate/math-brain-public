## 3. Move #14 — the group acting is `S_m`, and fixed stages do not carry enough permutation entropy

The preceding run showed that splitting the source into two spanning half-problems loses the first-moment depth threshold. I next asked whether the factor two could be removed by replacing those halves with a **high-arity static permutation network**: choose one common ordered layering of the vertices and let each layer transition implement many possible perfect matchings. The answer is no at the source minimum-depth scale, for a stronger entropy reason.

### Claim `P20-H0023-STATIC-LAYER-ENTROPY-BARRIER-02`

**PROVED / P20 SELF-CHECK / METHOD BARRIER ONLY.**

Fix `eps>0` and suppose

`k=(1+eps+o(1)) log n/log log n`,  `m=n/(k+1)`,

and

`p=(1+eps) log n/n`.

Let `G~G(n,p)`. With high probability, the following holds **simultaneously for every ordered equipartition**

`[n]=V_0 disjoint union V_1 disjoint union ... disjoint union V_k`,  `|V_t|=m`.

Let `R(V_0,...,V_k)` be the set of endpoint permutations in `S_m` realizable by `m` vertex-disjoint **layer-respecting** paths, each path using exactly one vertex from each `V_t` in order. Then

`log |R(V_0,...,V_k)| <= (1+o(1)) n log log log n`,

uniformly over all such equipartitions. In contrast,

`log(m!) = (1/(1+eps)+o(1)) n log log n`.

Consequently, whp **no common fixed layer partition, even one chosen after seeing `G`, can itself be a rearrangeable `(m x m)` permutation network for the H0023 terminal scale**.

This does **not** refute Conjecture 1.6: in a genuine linking system, the depth layers may depend on the target permutation `sigma`. The claim only rules out architectures in which all permutations share one common depth partition.

### Proof

Fix an ordered equipartition `Pi=(V_0,...,V_k)`. For `t=1,...,k`, write

`e_t=e_G(V_{t-1},V_t)`

and

`X_Pi=sum_t e_t`.

There are exactly

`M = k m^2`

possible edges joining consecutive layers, so

`X_Pi ~ Bin(M,p)`

with mean

`mu = p k m^2`.

At the source minimum-depth scale,

`mu = (1+o(1)) n log log n`.

Indeed `m=n/(k+1)` and `k=(1+eps+o(1))log n/log log n`, hence

`p k m^2 = (1+eps)log n/n * k n^2/(k+1)^2 = (1+o(1)) n log log n`.

The number of ordered equipartitions is at most `(k+1)^n`, since dropping the equal-size restriction only increases the count. Thus

`log #(equipartitions) <= n log(k+1) = (1+o(1)) n log log n`.

For a fixed `Pi`, the standard binomial Chernoff bound gives

`P(X_Pi >= 4 mu) <= exp(-(4 log 4 - 3) mu)`.

Since `4 log 4 - 3 > 1`, a union bound over all ordered equipartitions yields

`P(exists Pi: X_Pi >= 4 mu) <= exp(-(4 log 4 - 4 + o(1)) n log log n)=o(1)`.

Hence, whp, every ordered equipartition satisfies

`X_Pi <= 4 mu`.

Now fix such a partition. A layer-respecting spanning path system chooses, at each transition `t`, a perfect matching of the bipartite graph `G[V_{t-1},V_t]`. Let `N_t` be the number of such perfect matchings. If the left degrees are `d_1,...,d_m`, then every perfect matching is in particular a choice of one neighbor for each left vertex, so

`N_t <= product_i d_i <= (e_t/m)^m`

by AM-GM. Every sequence of layer matchings determines at most one endpoint permutation, so

`|R(V_0,...,V_k)| <= product_t N_t`

`<= product_t (e_t/m)^m`

`<= ((sum_t e_t)/(k m))^(mk)`

again by AM-GM across the `k` transition layers. On the uniform high-probability event above,

`|R(V_0,...,V_k)| <= (4 mu/(k m))^(mk) = (4 p m)^(mk)`.

But

`p m = (1+eps)log n/(k+1) = (1+o(1)) log log n`

and

`m k = n-m = (1-o(1))n`.

Therefore

`log |R(V_0,...,V_k)| <= (1+o(1)) n log log log n`.

Finally, Stirling's formula and

`m=(1+o(1)) n log log n/((1+eps)log n)`

give

`log(m!)=(1+o(1))m log m=(1/(1+eps)+o(1))n log log n`.

Since `log log log n=o(log log n)`, for all sufficiently large `n` we have `|R|<m!`. Thus no fixed equipartition can realize every permutation. QED.

No checker was created: this is an asymptotic theorem with a complete analytic proof.

## 4. Move #18 — say H0023 as a random rearrangeable connector, not a sorting network

The group-theoretic theorem above changes the useful language.

A fixed layered rearrangeable network has a set `M_t subset S_m` of matching permutations available at stage `t`; its routable endpoint permutations lie in the product set

`M_1 M_2 ... M_k`.

The proof above is exactly a capacity bound on this product:

`|M_1 ... M_k| <= product_t |M_t| <= (4 p m)^(mk)`

whp for every common equipartition. At the source scale `pm~log log n`, a fixed stage carries only `log log log n` bits per channel, whereas the full group `S_m` requires about `log m~log n` bits per channel in total. Across `k~log n/log log n` stages this is still short by the factor

`log log n / log log log n`.

Equivalently, a deterministic layered architecture with stage-average branching at most `D` can realize at most `D^(mk)` permutations. To cover `S_m` it needs

`D >= (m!)^(1/(mk)) = m^(1/k+o(1)) = (log n)^(1/(1+eps)+o(1))`,

whereas a typical fixed transition layer in the source random graph has average degree only

`pm=(1+o(1))log log n`.

This explains why simply replacing the source's two halves by a high-radix Beneš/Clos-style **static** switching fabric cannot recover the conjectured depth. The successful object, if Conjecture 1.6 is true, must be a **mobile-layer connector**: different target permutations must be allowed to use substantially different depth partitions of the same random graph.

This is compatible with the source's own observation that fixed AKS/sorting-network constructions cannot reach depth `o(log n)`, but the mechanism here is different: even a random high-arity fixed layering at the H0023 density has too little permutation entropy.

## 5. Move #20 — inspect the source spread calculation at half depth

The static-layer barrier does **not** kill the two-sided flexible-prefix idea from the preceding run. In fact, rereading the exact source spread calculation isolates where two-sided flexibility helps and where the real missing lemma moves.

In source Lemma 3.11, if a fragment `S` contains `r` full completion paths, Claim 3.13 contributes the factor

`(rho/(log n)^d)^r`

(up to the source's `psi=1` notation and subpolynomial `rho`), while the factorial ratio in Claim 3.12 costs approximately an `n^r` factor. This is precisely why the source chooses

`(log n)^d = n exp(-o(log n))`,

namely `d=(1-o(1))log n/log log n`: one-sided prefix flexibility must almost cancel one full power of `n` for each full fragment path.

Now suppose, only as a target architecture, that one could build a **joint two-sided prefix family** with left and right depths both `d`, branching alphabet `B=Theta(log n)`, total family size on the scale `B^(2dm)`, and fixed-endpoint multiplicity at most

`rho^(2r) B^(2d(m-r))`

for `r` prescribed left/right prefix pairs, with `rho=n^{o(1)}`. The exact analogue of the source's full-fragment factor would then be

`(rho^2/B^(2d))^r`.

If

`2d=(1+delta+o(1)) log n/log log n`

for any fixed `delta>0`, then

`B^(2d)=n^(1+delta+o(1))`.

Therefore the `n^r` factorial concentration that defeats short one-sided prefixes would be overpaid by

`n^(-delta r+o(r))`.

So the **full-path fragment exponent itself is not the obstruction** to a two-sided construction. For any `0<delta<eps`, the source depth budget

`k=(1+eps+o(1))log n/log log n`

leaves a central depth of

`(eps-delta+o(1))log n/log log n`

after spending `(1+delta)` critical-depth units on the two flexible sides.

This calculation is conditional, not a theorem about `G(n,p)`: what is missing is the construction of one large **joint** family of left/right prefixes that are vertex-disjoint within each pair, nearly exhaust the vertices, retain the required endpoint-multiplicity bound, and leave enough unexposed randomness for the center. The static-layer theorem says this joint family cannot be obtained by first freezing common layers.

### A second exact budget constraint from Theorem 2.15

The source's spread theorem also explains its huge density constants. If a probability measure is `q`-spread on a family whose every member has `L` edges, then summing one-edge marginals gives the universal lower bound

`L = sum_e P(e in F) <= binom(n,2) q`,

hence

`q >= L/binom(n,2)`.

If the proposed central completion has depth

`ell=(alpha+o(1))log n/log log n`,

then with the source value `m~n log log n/((1+eps)log n)` it contains

`L=(alpha/(1+eps)+o(1))n`

edges, so necessarily

`q >= (2alpha/(1+eps)+o(1))/n`.

Theorem 2.15 requires `p_center > 96 q log ell(F)`, so even an ideally spread central family forces, at the leading `log n/n` scale,

`p_center >= (192 alpha/(1+eps)+o(1)) log n/n`.

This does **not** rule out the route: it says the central depth `alpha` must be chosen as a sufficiently small fraction of the source slack `eps` if one wants to keep a positive-density near-threshold prefix exposure. It also explains structurally why the source's actual `q=87/n` couples to a very large sprinkling constant.

**Outcome of #20:** the source's one-sided spread inequality really does identify the full-path fragment as the critical concentration, but two-sided prefix entropy can repair that exponent. The remaining barriers are (i) constructing the joint mobile prefix family near the connectivity constant without freezing layers, and (ii) budgeting the small central depth/density so that the spread theorem's constant can fit inside the source `eps` slack.
