## 3. New theorem: the special Paley column can always be removed by projective switching

The previous run searched only finite Paley columns. This run closes the resulting scope question exactly: for every proper column subset, inclusion of the special column creates no new principal-spectrum type.

Let `P^1(F_p)=F_p union {infinity}` and choose canonical homogeneous representatives

\[
v_x=(x,1)\quad(x\in F_p),\qquad v_\infty=(1,0).
\]

For distinct projective points define

\[
C_{P,Q}=\chi(\det(v_P,v_Q)),\qquad C_{P,P}=0.
\tag{3.1}
\]

Since `p congruent 1 mod 4`, `chi(-1)=1`; hence `C` is symmetric. For finite points `x,y`, equation (3.1) gives `C_{x,y}=chi(x-y)`, while `C_{infinity,x}=1`. Therefore the full Paley-ETF Gram matrix is

\[
G=I+\frac1{\sqrt p}C.
\tag{3.2}
\]

### Proposition C28-PROJ-01
For every `A in SL_2(F_p)`, the induced projective permutation `g` satisfies

\[
C_{gP,gQ}=s(P)s(Q)C_{P,Q}
\tag{3.3}
\]

for signs `s(P) in {+1,-1}` depending on the chosen canonical representatives. Consequently every principal matrix `C_S` is signed-permutation similar to `C_{gS}` and has the same spectrum.

Moreover, for every proper subset `S subsetneq P^1(F_p)`, there is `g in PSL_2(F_p)` for which `gS subset F_p`. Hence every proper Paley-ETF column submatrix has exactly the same singular values as a submatrix using finite columns only.

### Proof
Take `A in SL_2(F_p)`. For each projective point P there is a nonzero scalar `lambda_P` such that the canonical representative of `gP` is

\[
v_{gP}=\lambda_P A v_P.
\]

Because `det A=1`,

\[
\det(v_{gP},v_{gQ})
=\lambda_P\lambda_Q\det(v_P,v_Q).
\]

Applying the quadratic character gives (3.3) with `s(P)=chi(lambda_P)`. Thus, after ordering the points, `C_{gS}=D P C_S P^T D` for a permutation P and a diagonal sign matrix D; spectra are identical.

If `S` is proper, choose `z notin S`. The action of `SL_2(F_p)` on the projective line is transitive, so choose A sending z to infinity. Then infinity is not in `gS`, hence `gS subset F_p`. Applying (3.2) shows the corresponding Gram principal matrices and column condition numbers are identical. QED.

This is important operationally: the p=73 finite-column search did not silently omit a worse class created by the extra identity-basis column. Searching finite subsets is, up to Paley projective switching, globally sufficient for every source-relevant size `m<p+1`.

## 5. New reduction for multiplicative-subgroup candidates

The previous report proposed multiplicative subgroups/cosets as an algebraic route. This run derives the exact spectral formula.

Let `H <= F_p^*` be a multiplicative subgroup contained in the quadratic residues, with `|H|=m`. Let

\[
A_H=(\chi(x-y))_{x,y\in H},
\]

with zero diagonal. Since every `x in H` is a square,

\[
\chi(x-y)=\chi(1-y/x).
\]

Thus `A_H` is a convolution operator on the finite abelian group H with kernel

\[
k(t)=\chi(1-t),\qquad t\in H,
\]

where `k(1)=0` automatically.

For each multiplicative character `psi` of H, the vector `v_psi(x)=psi(x)` is an eigenvector with exact eigenvalue

\[
\boxed{\lambda_\psi=\sum_{t\in H}\chi(1-t)\psi(t).}
\tag{5.1}
\]

The kernel satisfies `k(t^{-1})=k(t)` because H consists of squares and `chi(-1)=1`, so these eigenvalues are real, as required by symmetry.

Let `d=(p-1)/m`, choose a character `theta` of `F_p^*` of order d with `H=ker theta`, and extend psi to a multiplicative character `tilde psi` of `F_p^*`. Using

\[
1_H(t)=\frac1d\sum_{j=0}^{d-1}\theta(t)^j,
\]

we obtain the Jacobi-sum formula

\[
\boxed{
\lambda_\psi=
\frac1d\sum_{j=0}^{d-1}
J(\widetilde\psi\,\theta^j,\chi),
}
\tag{5.2}
\]

with the standard zero extension of multiplicative characters. Formula (5.2) turns the proposed subgroup route into a finite average of exact cyclotomic/Jacobi sums. A negative asymptotic route would need these averages to approach `-sqrt(p)` at source-scale subgroup sizes; a positive route would need a uniform exclusion from that edge.

Parseval gives the useful exact consistency identity

\[
\sum_{\psi\in\widehat H}\lambda_\psi^2=m(m-1),
\tag{5.3}
\]

because the convolution kernel has one zero entry and `m-1` entries of modulus one. This explains the typical `sqrt(m)` spectral scale but, by itself, does not exclude a rare eigenvalue of order `sqrt(p)` when `m>sqrt(p)`.
