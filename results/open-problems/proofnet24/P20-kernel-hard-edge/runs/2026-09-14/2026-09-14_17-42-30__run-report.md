# 8. Rare-event negative-moment obstruction

The actual quadratic-feature rows are iid as vectors in \(\mathbb R^p\).

The square matrix \(Z\) is invertible almost surely.

Indeed, if the feature rows failed to span \(\mathbb R^p\) for every choice of \(p\) inputs, there would be a nonzero
\[

\[

Thus the determinant polynomial is not identically zero, and Gaussian input continuity gives
\[

almost surely.

- removing finitely many bottom hard-edge modes;
- truncating the inverse;

This sharpens the interpretation of the existing P20 `H2` obligation.

The negative-moment issue is structural, not a missing estimate.
