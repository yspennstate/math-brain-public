# 3. Independent audit of P04's exterior-design theorem

## `P20-AUDIT-P04-VOLUME-EXTERIOR-49`

**AUDIT_FOR:** P04 Target 4  
**Source path:** `proofnet24/P04-kernel-conjectures/runs/2026-09-15/2026-09-15_20-42-46__run-report.md`

Let

\[
H\in\mathbb R^{n\times m},
\qquad n=m+r,
\]

have iid centered rows, full column rank almost surely, and finite nonzero determinant expectation. Put

\[
D=\det(H^\top H),
\qquad
\frac{dQ}{dP}=\frac D{E_PD},
\]

and let

\[
K=I-H(H^\top H)^{-1}H^\top
\]

be the rank-`r` projector onto `ker(H^T)`.

P04 claims that for every `0<=j<=r`,

\[
E_Q[\wedge^jK]
=
\frac{\binom rj}{\binom nj}I.
\tag{3.1}
\]

### 3.1 Independent Pluecker derivation

Let the columns of `H` be `g_1,...,g_m in R^n` and define

\[
\eta=g_1\wedge\cdots\wedge g_m.
\]

Then

\[
\|\eta\|^2=D.
\]

Fix an orientation and put

\[
\Omega=\frac{*\eta}{\sqrt D}
\in\wedge^r\mathbb R^n.
\]

This is the unit decomposable `r`-vector spanning `wedge^r ker(H^T)`. For an `r`-set `R`,

\[
\Omega_R
=
\varepsilon_R
\frac{\det H_{R^c}}{\sqrt D}.
\tag{3.2}
\]

For `j`-sets `I,J`, contraction of the rank-one exterior projector `|Omega><Omega|` over `r-j` coordinates gives

\[
\langle e_I,(\wedge^jK)e_J\rangle
=
\sum_L
\epsilon(I,L)\epsilon(J,L)
\Omega_{I\cup L}\Omega_{J\cup L},
\tag{3.3}
\]

where `L` ranges over `(r-j)`-sets disjoint from `I union J`.

Multiplying by `D`,

\[
D\langle e_I,(\wedge^jK)e_J\rangle
=
\sum_L\pm
\det(H_{(I\cup L)^c})
\det(H_{(J\cup L)^c}).
\tag{3.4}
\]

### 3.2 Off-diagonal cancellation

If `I != J`, choose `a in I\setminus J`. In every nonzero term of (3.4), row `a` is absent from the first determinant and present linearly in the second. Conditional on all rows except `h_a`, the first determinant is fixed and the second is linear in the centered fresh row `h_a`. Hence the expectation of every term is zero.

Thus

\[
E_P\!\left[
D\langle e_I,(\wedge^jK)e_J\rangle
\right]=0,
\qquad I\ne J.
\tag{3.5}
\]

No isotropy or Gaussianity is used.

### 3.3 Diagonal normalization

For `I=J`, equation (3.4) is a sum of squares. There are

\[
\binom{n-j}{r-j}
\]

terms. By iid row exchangeability every square `m x m` minor has the same expectation, say `delta_m`. Cauchy--Binet gives

\[
E_PD
=
\binom nm\delta_m
=
\binom nr\delta_m.
\tag{3.6}
\]

Therefore

\[
E_Q\langle e_I,(\wedge^jK)e_I\rangle
=
\frac{\binom{n-j}{r-j}}{\binom nr}
=
\frac{\binom rj}{\binom nj}.
\tag{3.7}
\]

Together with (3.5), this proves (3.1).

### 3.4 Audit of P04's quadratic-alternating consequence

P04 also says that every deterministic quadratic alternating diagnostic is already Haar at this first-moment level. That consequence is correct. Since `wedge^j K` is itself an orthogonal projection,

\[
(\wedge^jK)^2=\wedge^jK.
\]

For a deterministic linear map `T` on `wedge^j R^n`,

\[
\begin{aligned}
\|T(\wedge^jK)\|_{HS}^2
&=\operatorname{Tr}\!\left[
(\wedge^jK)T^*T(\wedge^jK)
\right]\\
&=\operatorname{Tr}\!\left[T^*T(\wedge^jK)\right].
\end{aligned}
\]

Thus its expectation depends only on `E_Q wedge^jK`, which is exactly (3.1).

### Audit conclusion

The theorem and the stated alternating-sector obstruction are correct under the stated iid-centering/full-rank/integrability hypotheses.

# 4. New theorem: expose one genuinely fresh harmonic row

The preceding Hotelling formulation uses

\[
\bar h
\quad\text{and}\quad
H_c^TH_c,
\]

which are dependent functions of all rows. This section removes that dependence from the **input randomness** by a leave-one-row representation.

Let

\[
H=\begin{bmatrix}A\\h^\top\end{bmatrix},
\]

where `A` consists of the first `m` iid harmonic rows and `h` is the last one. Thus

\[
A\perp h
\]

exactly. The harmonic orbit spans `E`, and the row law is continuous on that spanning algebraic orbit, so `A` is invertible almost surely.

Define

\[
z=A^{-\top}h,
\qquad
r^2=\|z\|^2,
\qquad
\beta=\mathbf1_m^\top z.
\tag{4.1}
\]

## `P20-FRESH-ROW-INVERSE-RATIO-49`

### 4.1 Exact null vector

Since

\[
A^Tz=h,
\]

we have

\[
H^T\binom{-z}{1}
=-A^Tz+h=0.
\]

Therefore the unit left null vector is

\[
\boxed{
v=
\frac{(-z,1)}{\sqrt{1+r^2}}
}
\tag{4.2}
\]

up to global sign, and

\[
\boxed{
s:=\mathbf1_p^Tv
=
\frac{1-\beta}{\sqrt{1+r^2}}.
}
\tag{4.3}
\]

This already converts the ordinary source-alignment problem into a ratio built from a **fresh harmonic row `h` conditional on the square base matrix `A`**.

### 4.2 Determinant formula for the uncentered Gram matrix

Cauchy--Binet gives

\[
\det(H^TH)
=
\sum_{i=1}^{p}\det(H_{-i})^2.
\]

Deleting the last row gives `det(A)^2`. If row `i<=m` of `A` is replaced by `h`, multilinearity and

\[
h=A^Tz=\sum_{j=1}^m z_j a_j
\]

show that the resulting determinant has magnitude `|z_i det A|`. Hence

\[
\boxed{
\det(H^TH)
=
\det(A)^2(1+r^2).
}
\tag{4.4}
\]

### 4.3 Determinant formula for the centered Gram matrix

Let

\[
Y=A-\mathbf1_m h^T.
\]

Its rows are the differences `a_i-h`. The centered scatter of the `p=m+1` points can be written

\[
C=H_c^TH_c
=Y^T\left(I_m-\frac1p\mathbf1_m\mathbf1_m^T\right)Y.
\tag{4.5}
\]

The middle matrix has eigenvalue `1/p` on the constant direction and eigenvalue `1` on its orthogonal complement, so

\[
\det\left(I_m-\frac1p\mathbf1\mathbf1^T\right)=\frac1p.
\]

The matrix determinant lemma gives

\[
\det Y
=
\det A\,(1-h^TA^{-1}\mathbf1)
=
\det A\,(1-\beta).
\]

Therefore

\[
\boxed{
\det C
=
\frac{\det(A)^2}{p}(1-\beta)^2.
}
\tag{4.6}
\]

### 4.4 Exact fresh-row Hotelling ratio

Since

\[
H^TH=C+p\bar h\bar h^T,
\]

the determinant lemma also gives

\[
\frac{\det(H^TH)}{\det C}
=1+p\bar h^TC^{-1}\bar h.
\tag{4.7}
\]

Substituting (4.4) and (4.6),

\[
1+pq_d
=
\frac{p(1+r^2)}{(1-\beta)^2},
\]

hence

\[
\boxed{
q_d
=
\frac{1+r^2}{(1-\beta)^2}-\frac1p.
}
\tag{4.8}
\]

Combining with (4.3),

\[
\boxed{
s^2
=
\frac{(1-\beta)^2}{1+r^2}
=
\frac{p}{1+pq_d}.
}
\tag{4.9}
\]

Thus the previous Hotelling identity is independently recovered, but now in a form where the only newly sampled object after freezing `A` is the genuinely fresh harmonic row `h`.

### 4.5 Why this is not a cosmetic rewrite

Conditional on `A`,

\[
\beta
=
\mathbf1^TA^{-T}h
\]

is one linear functional of the fresh degree-two harmonic row, while

\[
r^2
=h^TA^{-1}A^{-T}h

is a coupled positive quadratic form of the same fresh row. The numerator and denominator dependence is exact and must remain coupled. This is precisely the configuration in which a P13-style freeze-geometry-first attack is legitimate; the dependent centered pair `(bar h,C)` obscured that feature.
