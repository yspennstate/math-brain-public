# 4. New theorem: determinant-tilted inverse is an all-exterior second-order design

## `P20-DETTILT-INVERSE-EXTERIOR-52` — **PROVED**

This generalizes P22's entrywise inverse 2-design to every exterior degree.

Let `A` be an `m x m` random matrix with independent centered isotropic rows in `R^m`, assume `A` is nonsingular almost surely, and define determinant-square tilt

\[
\frac{dQ}{dP}(A)=\frac{\det(A)^2}{m!}.
\tag{4.1}
\]

The normalizer is `m!` by the determinant expansion and row isotropy.

Put `B=A^{-1}`. Let `I,K,J,L` be `q`-subsets of `[m]`, `1<=q<=m-1`. Then

\[
\boxed{
E_Q\big[\det B_{I,J}\,\det B_{K,L}\big]
=\frac{1}{(m)_q}\,\mathbf 1_{I=K}\mathbf 1_{J=L},
}
\tag{4.2}
\]

where `(m)_q=m!/(m-q)!`.

### Proof

Jacobi's complementary-minor identity gives

\[
\det B_{I,J}
=(-1)^{\Sigma I+\Sigma J}
\frac{\det A_{J^c,I^c}}{\det A}.
\tag{4.3}
\]

Multiplying two copies and inserting (4.1) cancels the inverse determinant pointwise:

\[
E_Q[\det B_{I,J}\det B_{K,L}]
=\frac{\pm1}{m!}
E[\det A_{J^c,I^c}\det A_{L^c,K^c}].
\tag{4.4}
\]

If `J != L`, choose a row index in `J triangle L`. One complementary minor omits that row while the other contains it linearly. Conditioning on all remaining rows and using centeredness makes (4.4) zero.

If `J=L`, both minors use the same `m-q` independent centered isotropic rows. The standard determinant covariance expansion gives

\[
E[\det A_{J^c,I^c}\det A_{J^c,K^c}]
=(m-q)!\det(I_{I^c,K^c}).
\tag{4.5}
\]

For equal-size coordinate subsets this determinant is `1` if `I=K` and `0` otherwise. The surviving Jacobi sign is then `+1`. Dividing by `m!` proves (4.2).

Equivalently, the compound matrix `wedge^q B` has exactly isotropic vectorized covariance:

\[
\boxed{
E_Q\,\mathrm{vec}(\wedge^qB)\mathrm{vec}(\wedge^qB)^T
=\frac1{(m)_q}I.
}
\tag{4.6}
\]

For `q=1` this is precisely P22's theorem. For a fixed `q`-subset `J`, if `b_j` denotes column `j` of `B` and

\[
W_J=\bigwedge_{j\in J}b_j,
\tag{4.7}
\]

then summing (4.2) over exterior coordinate subsets gives

\[
\boxed{
E_Q\|W_J\|^2=\frac{\binom mq}{(m)_q}=\frac1{q!}.
}
\tag{4.8}
\]

This uses only row centeredness, isotropy, independence, and nonsingularity. It is not a Gaussian or rotational-invariance identity.

# 5. New theorem: the adaptive residual plane is exactly an inverse-column plane

## `P20-INVERSE-WEDGE-RESIDUAL-52` — **PROVED**

Use the same setup as Section 4. Fix a `q`-subset `J` and let `S=J^c`. Under the full square determinant-tilted law `Q`, define

\[
V_J=\operatorname{span}\{b_j:j\in J\}.
\tag{5.1}
\]

Because `AB=I`, every row of `A_S` annihilates every `b_j`, `j in J`. The `q` inverse columns are linearly independent, hence

\[
\boxed{
V_J=\ker A_S.
}
\tag{5.2}
\]

Now integrate out the `q` rows indexed by `J`. Let

\[
D_S=\det(A_SA_S^T).
\]

Conditional on the base rows `A_S`, let `P` be projection onto `ker A_S`, and let `K` be the `q x q` residual Gram matrix of the omitted fresh rows after projection by `P`. Gram determinant factorization gives

\[
\det(A)^2=D_S\det K.
\tag{5.3}
\]

Since the fresh rows are isotropic in the rank-`q` residual space,

\[
E[\det K\mid A_S]=q!.
\tag{5.4}
\]

Therefore the marginal density of the base under `Q` is

\[
\frac{q!D_S}{m!}
=\frac{D_S}{(m)_{m-q}},
\tag{5.5}
\]

which is exactly the `(m-q)`-row Gram-volume law.

Thus:

\[
\boxed{
\operatorname{span}\{b_j:j\in J\}
\text{ under full square determinant tilt}
\stackrel d=
\text{the actual rank-}q\text{ residual plane of the volume/DPP chain}.
}
\tag{5.6}
\]

This is an exact finite-dimensional identity, not an asymptotic approximation.

### Harmonic specialization at rank two

For the square pure-harmonic base in coefficient space `E=Sym_d^0`, take `q=2`. Let

under determinant-square tilt. Then `P^{inv}_{ij}` has exactly the actual rank-two residual-plane law. Hence

This is much stronger than entrywise covariance isotropy and much more specific than generic normal-vector delocalization.

# 6. New theorem: inverse-wedge radius is exactly decorrelated from every first exterior quadratic observable

## `P20-INVERSE-WEDGE-RADIUS-DIRECTION-52` — **PROVED**

Continue Section 5. Write

\[
W_J=\rho\,\Omega,
\qquad
\rho=\|W_J\|,
\qquad
\|\Omega\|=1,
\qquad
\Pi=|\Omega\rangle\langle\Omega|.
\tag{6.1}
\]

The simple `q`-vector `Omega` represents the residual `q`-plane.

Choose orthogonal coefficient coordinates adapted to `Row(A_S)\oplus\ker A_S`. In these coordinates the omitted-row residual matrix is a square `q x q` matrix `R` with

\[
K=RR^T.
\]

Solving `Ab_j=e_j` for `j in J` shows that the inverse columns have residual-coordinate matrix `R^{-1}`. Hence

\[
\boxed{
\rho^2=\det(B_J^TB_J)=\frac1{\det K}.
}
\tag{6.2}
\]

Conditional on the base, the omitted rows under full determinant tilt have density `det K/q!` relative to their product law. Therefore

\[
\boxed{
E_Q[\rho^2\mid A_S]=\frac1{q!}.
}
\tag{6.3}
\]

More generally, for `0<=theta<=1`,

\[
E_Q[\rho^{2\theta}\mid A_S]
=\frac1{q!}E[(\det K)^{1-\theta}\mid A_S]
\le(q!)^{-\theta}
\tag{6.4}
\]

by concavity, and in particular

\[
P_Q\{\rho^2>L\mid A_S\}\le\frac1{q!L}.
\tag{6.5}
\]

Now (4.2) says for fixed `J`

\[
E_Q[\rho^2\Pi]=\frac1{(m)_q}I_{\wedge^qE}.
\tag{6.6}
\]

Independently, the volume residual-plane first exterior moment can be computed directly from Pluecker cofactors of the `m-q` base rows:

\[
E_Q\Pi=\frac1{\binom mq}I_{\wedge^qE}.
\tag{6.7}
\]

Since

\[
\frac1{q!}\frac1{\binom mq}=\frac1{(m)_q},
\]

we obtain the exact centered identity

\[
\boxed{
E_Q\left[\left(\rho^2-\frac1{q!}\right)\Pi\right]=0.
}
\tag{6.8}
\]

Equivalently, for every deterministic linear map `T:wedge^q E -> K`,

\[
E_Q[\rho^2\|T\Omega\|^2]
=E_Q\rho^2\,E_Q\|T\Omega\|^2
=\frac1{(m)_q}\|T\|_{HS}^2.
\tag{6.9}
\]

This is **decorrelation, not independence**.

### Rank-two adversarial consequence

At `q=2`,

\[
E_Q\rho^2=\frac12,
\qquad
P_Q\{\rho^2>L\mid A_{J^c}\}\le\frac1{2L}.
\tag{6.10}
\]

Every quadratic alternating/Hodge diagnostic of the inverse-column plane is already exactly Haar at first-projector level even after multiplication by the inverse-wedge magnitude `rho^2`.

Therefore the missing order-`1/d` Jordan defect cannot be hidden in a first exterior moment or in first-order correlation between the inverse-wedge radius and an alternating quadratic observable.

The reason this does **not** prove `e_2=O(1/d)` is structural: `P_2` is recovered quadratically from `Pi`, and

is a quadratic functional of the coefficient projector `P_2`, hence a **second projective moment** of the simple exterior direction. First exterior-projector design, even with (6.8), is one moment too weak.

This gives a precise replacement for the vague statement “the symmetric sector is still open.”

# 7. New theorem: exact positive Jordan-budget localization to ranks `s=O(d)`

## `P20-JORDAN-BUDGET-LOCALIZATION-52` — **PROVED**

Recall the exact recurrence

\[
e_{s-1}=\frac{s-2}{s}e_s+\gamma_s,
\qquad
gamma_s=E\operatorname{tr}(N_s^4)-\frac1d,
\tag{7.1}
\]

and `e_m=0` for the full coefficient space.

Iterating (7.1) down to rank two gives

\[
\boxed{
e_2
=\sum_{s=3}^{m}
\frac{2\gamma_s}{(s-1)(s-2)}.
}
\tag{7.2}
\]

Indeed, the coefficient with which `gamma_s` reaches `e_2` is

\[
\prod_{r=3}^{s-1}\frac{r-2}{r}
=\frac{2}{(s-1)(s-2)}.
\tag{7.3}
\]

For every Frobenius-unit real symmetric matrix `N`, if its eigenvalues are `lambda_i`, then

\[
\sum_i\lambda_i^4\ge\frac1d\left(\sum_i\lambda_i^2\right)^2=\frac1d,
\]

and trivially `sum lambda_i^4<=1`. Hence

\[
\boxed{0\le\gamma_s\le1-\frac1d.}
\tag{7.4}
\]

For every cutoff `S`, the contribution of ranks above `S` obeys

\[
0\le
\sum_{s=S+1}^{m}
\frac{2\gamma_s}{(s-1)(s-2)}
\le
2\sum_{s=S+1}^{m}
\left(\frac1{s-2}-\frac1{s-1}\right)
\le\frac{2}{S-1}.
\tag{7.5}
\]

Choosing `S=d` yields

\[
\boxed{
e_2
=
\sum_{s=3}^{d}
\frac{2\gamma_s}{(s-1)(s-2)}
+O(d^{-1}),
}
\tag{7.6}
\]

with a nonnegative remainder bounded deterministically by `2/(d-1)`.

Therefore

\[
\boxed{
e_2=O(d^{-1})
\iff
\sum_{s=3}^{d}
\frac{2\gamma_s}{(s-1)(s-2)}=O(d^{-1}).
}
\tag{7.7}
\]

This is the exact final-window theorem sought implicitly in several previous runs: **all residual ranks larger than order `d` are harmless without any delocalization estimate at all.**

For the coefficient-Haar benchmark, (3.9) gives `gamma_s^H=c_H~1/d` at every rank, and (7.2) reproduces `e_2^H=2/d+O(d^{-2})`.

A stronger sufficient condition is

\[
\sup_{3\le s\le d}\gamma_s\le\frac Cd,
\tag{7.8}
\]

but (7.7), not (7.8), is the exact required target. A proof may exploit weighted cancellation/localization across ranks; pointwise Haar closeness at every `s` is not logically necessary.

# 8. What mechanism for a different law survives?

This run eliminates two more candidate mechanisms as standalone explanations.

First, a large inverse-column wedge magnitude is not enough. Under determinant tilt its first moment is exactly `1/q!`, its conditional tail is universally `<=1/(q!L)`, and its correlation with every first exterior quadratic observable is exactly zero after centering.

Second, a high-rank fourth-mark defect is not enough. Even `gamma_s` of order one at ranks `s>>d` contributes only `O(1/d)` in total to `e_2` because of the exact weights in (7.2). This is relevant because the physical-orbit deletion at the very top ranks can indeed have a large fourth mark; that fact by itself is harmless for the endpoint.

The strongest still-plausible different-law mechanism is now narrower:

\[
\boxed{
\text{an anomalous symmetric/projective second moment of the final }s\lesssim d
\text{ adaptive residual planes,}
}
\tag{8.1}
\]

possibly amplified downstream by ordinary-volume transfer, growing bottom-frame/secular coupling, or failure of the needed rare-event uniform integrability.

No such defect is proved to survive asymptotically.
