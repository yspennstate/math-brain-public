\operatorname{tr}(q^3)
=\frac{(d-1)(d-2)}{d^2}.
\tag{5.2}
\]

Since

\[
\frac{c_d^2}{m}
=\frac{d}{d-1},
\]

(3.12) gives

\[
\boxed{
M_m
=
\frac{c_d^2}{m}
\frac{\operatorname{tr}(q^3)}{\|q\|^2}
=
\frac{d-2}{d-1}.
}
\tag{5.3}
\]

Thus `M_m -> 1`. This rigorously falsifies two tempting shortcuts:

- the physical marks do **not** vanish by an oddness symmetry;
- there is no uniform estimate `M_r=O(1/d)` valid over all ranks.

The weighted contribution of this top mark is nevertheless only `O(m^{-1})=O(d^{-2})`.

## 5.3 Exact Cauchy bridge to the retained Jordan deletion mark

### `P20-ONEDELETE-MARK-GAMMA-BOUND-58` — PROVED

In the one-delete step write

\[
\Delta a:=a-a_0=\alpha v,
\qquad
\alpha=\frac{1-c}{\sqrt w}.
\tag{5.4}
\]

Then, from (3.11),

\[
M_r=E[\alpha\operatorname{tr}(v^3)]
\tag{5.5}
\]

after averaging both the selected base and the selected fresh row.

By (3.9), and the exact affine second moment for the base residual rank `r`,

\[
E\|a_0\|^2
=c_d^2\frac{m-r}{r+1},
\]

so

\[
\boxed{
E\alpha^2
=E\|\Delta a\|^2
=\frac{c_d^2(m+1)}{r(r+1)}.
}
\tag{5.6}
\]

Because `v` is a unit-Frobenius traceless symmetric matrix,

\[
\operatorname{tr}(v^3)
=\langle v,v^2-I/d\rangle,
\]

and therefore

\[
(\operatorname{tr}v^3)^2
\le
\|v^2-I/d\|_F^2
=
\operatorname{tr}(v^4)-\frac1d.
\tag{5.7}
\]

Let

\[
\gamma_r
:=E\operatorname{tr}(v^4)-\frac1d.
\tag{5.8}
\]

This is exactly the retained positive one-delete Jordan mark in the reverse recurrence

\[
e_{r-1}=\frac{r-2}{r}e_r+\gamma_r.
\tag{5.9}
\]

Cauchy--Schwarz in (5.5) and (5.6)--(5.8) gives

\[
\boxed{
|E M_r|
\le
\sqrt{\frac{c_d^2(m+1)}{r(r+1)}\gamma_r}.
}
\tag{5.10}
\]

No independence between the affine increment and the deleted direction is assumed.

## 5.4 Macroscopic-rank tail localization

### `P20-ONEDELETE-MARK-MACROTAIL-58` — PROVED

For any unit-Frobenius symmetric `v`,

\[
\operatorname{tr}(v^4)\le(\operatorname{tr}v^2)^2=1,
\]

so `0<=gamma_r<=1-1/d<1`. Consequently (5.10) gives, for `R>=3`,

\[
\begin{aligned}
\sum_{r=R}^m\frac{|E M_r|}{r-1}
&\le
c_d\sqrt{m+1}
\sum_{r=R}^m
\frac1{(r-1)\sqrt{r(r+1)}}\\
&\le
c_d\sqrt{m+1}
\sum_{r=R}^m\frac1{r(r-1)}\\
&\le
\frac{c_d\sqrt{m+1}}{R-1}.
\end{aligned}
\tag{5.11}
\]

Since

\[
m+1=p=\frac{d(d+1)}2,
\]

\[
\boxed{
c_d\sqrt{m+1}
=\frac d2\sqrt{(d+1)(d+2)}.}
\tag{5.12}
\]

Therefore

\[
\boxed{
\sum_{r=R}^m\frac{|E M_r|}{r-1}
\le
\frac{d\sqrt{(d+1)(d+2)}}{2(R-1)}.
}
\tag{5.13}
\]

If `R=ceil(theta m)` with fixed `theta>0`, the right side is `O_theta(1)`. Hence the upper macroscopic fraction of the deletion chain can never be responsible for failure of the criterion (0.6).

This is an **absolute-value** statement, stronger than merely saying the signed macroscopic tail is bounded. It does not reach `R=O(d)`: at that scale the bound is still order `d`.

# 6. A law-specific sphere integration-by-parts bound inside one mark

## `P20-ONEDELETE-SPHERE-CROSS-58` — PROVED

The Gaussian mark vanishes because residual and row-span coordinates are independent. For the physical row they are dependent. The next question is whether that dependence can be quantified without replacing the row by a Gaussian vector.

Fix a deterministic orthogonal projector `P` on `E` and put

\[
y(U)=Pq(U),
\qquad
\Phi_P(U)
=
\begin{cases}
\dfrac{\operatorname{tr}(y(U)^3)}{\|y(U)\|_F^2},&y(U)\ne0,\\[6pt]
0,&y(U)=0.
\end{cases}
\tag{6.1}
\]

For `y neq 0`, the Euclidean gradient in coefficient space of

\[
\phi(y)=\frac{\operatorname{tr}(y^3)}{\|y\|_F^2}
\]

is

\[
\nabla\phi(y)
=
\frac{3\Pi_E(y^2)}{\|y\|^2}
-
\frac{2\operatorname{tr}(y^3)y}{\|y\|^4}.
\tag{6.2}
\]

The inequalities

\[
\|\Pi_E(y^2)\|_F\le\|y\|_F^2,
\qquad
|\operatorname{tr}(y^3)|\le\|y\|_F^3
\]

give

\[
\boxed{\|\nabla\phi(y)\|_F\le5.}
\tag{6.3}
\]

Since `phi` is homogeneous of degree one and `|phi(y)|<=||y||`, it extends continuously at zero and is globally Lipschitz with the same universal bound. For a unit tangent vector `xi perpendicular U`,

\[
D_\xi q=U\xi^T+\xi U^T,
\qquad
\|D_\xi q\|_F=\sqrt2.
\]

Thus the spherical gradient obeys

\[
\boxed{\|\nabla_S\Phi_P(U)\|\le5\sqrt2}
\tag{6.4}
\]

in the weak sense everywhere and classically off the zero set.

Now let `a in E` be deterministic and define

\[
c_a(U)=\langle a,q(U)\rangle=U^TaU.
\]

This is a degree-two traceless spherical harmonic, hence

\[
-\Delta_S c_a=2d\,c_a.
\tag{6.5}
\]

Its exact variance from (2.5) is

\[
E c_a^2=\frac{\|a\|_F^2}{c_d^2},
\]

so the Dirichlet energy is

\[
E\|\nabla_Sc_a\|^2
=2d\frac{\|a\|_F^2}{c_d^2}.
\tag{6.6}
\]

Sphere integration by parts, followed by Cauchy--Schwarz and (6.4), yields

\[
\begin{aligned}
|E[c_a\Phi_P]|
&=\frac1{2d}
|E\langle\nabla_Sc_a,\nabla_S\Phi_P\rangle|\\
&\le
\frac1{2d}
\sqrt{\frac{2d}{c_d^2}}\|a\|_F\,5\sqrt2\\
&=
\boxed{\frac{5\|a\|_F}{c_d\sqrt d}}.
\end{aligned}
\tag{6.7}
\]

This estimate is physical-orbit-specific and uses the exact spherical Laplacian eigenvalue. It is not a covariance-only statement.

For the conditional mark (3.12), the uncentered piece also satisfies

\[
|E\Phi_P|
\le\sqrt{E\|Pq\|^2}
=\frac{\sqrt r}{c_d}.
\tag{6.8}
\]

Therefore, for a frozen residual rank-`r` base,

\[
\boxed{
|M_r(P,a)|
\le
\frac{c_d}{\sqrt r}
+
\frac{5c_d}{r\sqrt d}\|a\|_F.
}
\tag{6.9}
\]

Averaging and using the exact base affine second moment gives

\[
\boxed{
|E M_r|
\le
\frac{c_d}{\sqrt r}
+
\frac{5c_d^2}{r\sqrt d}
\sqrt{\frac{m-r}{r+1}}.
}
\tag{6.10}
\]

This is not yet strong enough to sum (0.6) uniformly down to residual rank `O(d)`; in particular the first term is compatible with an absolute tail of order `d/sqrt R`. The result is useful because it isolates the remaining obstruction: the dangerous part is not arbitrary row-span/residual dependence, but the **signed mean of the homogeneous cubic ratio itself**, together with the residual affine coupling after the degree-two integration-by-parts gain.
