# 4. New theorem: microscopic local density CLT for a quadratic feature projection

## `P20-QUADRATIC-LOCAL-DENSITY-56` — PROVED

Let `A` be any real symmetric `d x d` matrix with

\[
\|A\|_F^2=\operatorname{tr}A^2=1.
\]

Let its eigenvalues be `lambda_1,...,lambda_d`, and define

\[
\rho(A)=\max_j|\lambda_j|=\|A\|_{op},
\qquad
\beta_3(A)=\sum_j|\lambda_j|^3.
\]

Let `g~N(0,I_d)` and define the exact centered quadratic feature projection

\[
Q_A=\frac{g^TAg-\operatorname{tr}A}{\sqrt2}
=\frac1{\sqrt2}\sum_{j=1}^d\lambda_j(g_j^2-1).
\tag{4.1}
\]

Then there exist universal constants `rho_0>0` and `C<infinity` such that whenever `rho(A)<=rho_0`, `Q_A` has a continuously differentiable density `f_A` satisfying

\[
\boxed{
\|f_A-\varphi\|_\infty
+\|f_A'-\varphi'\|_\infty
\le C\beta_3(A),
}
\tag{4.2}
\]

where

\[
\varphi(x)=\frac1{\sqrt{2\pi}}e^{-x^2/2}.
\]

Since

\[
\beta_3(A)
\le
\left(\sum_j\lambda_j^2\right)^{1/2}
\left(\sum_j\lambda_j^4\right)^{1/2}
=\sqrt{\operatorname{tr}A^4}
\tag{4.3}
\]

and also `beta_3(A)<=rho(A)`, either fourth-Schatten control or operator delocalization gives a rate.

The density estimate implies the genuinely microscopic interval theorem

\[
\boxed{
\sup_{u\in\mathbb R}
\left|
P\{|Q_A-u|\le\varepsilon\}
-
\int_{u-\varepsilon}^{u+\varepsilon}\varphi(x)dx
\right|
\le C\varepsilon\beta_3(A)
}
\tag{4.4}
\]

for every `eps>0`, and therefore, for `0<eps<=1`,

\[
\boxed{
\sup_u
\left|
\frac{P\{|Q_A-u|\le\varepsilon\}}{2\varepsilon}
-\varphi(u)
\right|
\le C\bigl(\beta_3(A)+\varepsilon\bigr).
}
\tag{4.5}
\]

The essential point is that the approximation error in (4.4) is proportional to the **length of the interval**. Thus it remains useful when `eps` is much smaller than any global Berry--Esseen error.

## 4.1 Exact characteristic function

For one standard Gaussian coordinate,

\[
E\exp\left(
\frac{it\lambda}{\sqrt2}(g^2-1)
\right)
=e^{-it\lambda/\sqrt2}
(1-i\sqrt2\,t\lambda)^{-1/2}.
\]

Hence

\[
\psi_A(t):=Ee^{itQ_A}
=\prod_j
 e^{-it\lambda_j/\sqrt2}
(1-i\sqrt2\,t\lambda_j)^{-1/2}.
\tag{4.6}
\]

The centering phase cancels the linear term in the logarithm **coordinate by coordinate**, so no tracelessness hypothesis is needed. Expanding the logarithm,

\[
\log\psi_A(t)
=-\frac{t^2}{2}+R_A(t),
\]

with

\[
R_A(t)
=
\sum_{r=3}^{\infty}
\frac{(i\sqrt2\,t)^r}{2r}
\sum_j\lambda_j^r.
\tag{4.7}
\]

Whenever `|t|rho(A)` is sufficiently small,

\[
\boxed{
|R_A(t)|\le C|t|^3\beta_3(A).
}
\tag{4.8}
\]

## 4.2 A global characteristic-function envelope

The exact modulus is

\[

=\prod_j(1+2t^2\lambda_j^2)^{-1/4}.
\tag{4.9}
\]

For `|t|rho<=1/4`, `log(1+x)>=x/2` for the relevant `x=2t^2 lambda_j^2`, hence

\[
\boxed{|\psi_A(t)|\le e^{-ct^2}.}
\tag{4.10}
\]

For arbitrary `t`, use concavity of `x -> log(1+2t^2x)` on `[0,rho^2]`. Since the function vanishes at zero,

\[
\log(1+2t^2\lambda_j^2)
\ge
\frac{\lambda_j^2}{\rho^2}
\log(1+2t^2\rho^2).
\]

Summing and using `sum lambda_j^2=1`,

\[
\boxed{
|\psi_A(t)|
\le
(1+2t^2\rho^2)^{-1/(4\rho^2)}.
}
\tag{4.11}
\]

This tail estimate is much stronger than a fixed-power decay when `rho` is small: the effective exponent is of order `rho^-2`.

## 4.3 Fourier `L^1` comparison

Assume `0<rho<=rho_0`, with `rho_0` chosen universally small, and put

\[
T=\frac1{10}\rho^{-1/3}.
\]

On `|t|<=T`, (4.8) gives

\[
|R_A(t)|\le C\beta_3T^3\le C\rho T^3\le C/1000,
\]

so after shrinking the numerical constant if necessary,

\[
|e^{R_A(t)}-1|\le C|R_A(t)|.
\]

Therefore

\[
|\psi_A(t)-e^{-t^2/2}|
\le
C\beta_3|t|^3e^{-ct^2},
\qquad |t|\le T.
\tag{4.12}
\]

Integrating (4.12), with or without one extra factor `|t|`, yields

\[
\int_{|t|\le T}(1+|t|)
|\psi_A(t)-e^{-t^2/2}|dt
\le C\beta_3.
\tag{4.13}
\]

On the middle range `T<|t|<=1/(4rho)`, (4.10) and the Gaussian bound give

\[
\int_{T<|t|\le1/(4\rho)}(1+|t|)
\bigl(|\psi_A(t)|+e^{-t^2/2}\bigr)dt
\le Ce^{-cT^2}
\le C\beta_3
\tag{4.14}
\]

for all sufficiently small `rho`; the last inequality uses the super-polynomial decay `e^{-c rho^{-2/3}}` and `beta_3<=rho` only to normalize the harmless extreme case.

Finally, on `|t|>1/(4rho)`, (4.11) gives, after `s=rho t`,

\[
\int_{|t|>1/(4\rho)}(1+|t|)|\psi_A(t)|dt
\le
C\rho^{-2}
\int_{1/4}^{\infty}(1+s)
(1+2s^2)^{-1/(4\rho^2)}ds
\le Ce^{-c/\rho^2}
\le C\beta_3.
\tag{4.15}
\]

The Gaussian tail is even smaller. Combining (4.13)--(4.15),

\[
\boxed{
\int_{\mathbb R}(1+|t|)
|\psi_A(t)-e^{-t^2/2}|dt
\le C\beta_3(A).
}
\tag{4.16}
\]

In particular `psi_A` and `t psi_A` are integrable, so Fourier inversion gives a `C^1` density and

\[
\|f_A-\varphi\|_\infty
\le\frac1{2\pi}\int|\psi_A-e^{-t^2/2}|dt,
\]

\[
\|f_A'-\varphi'\|_\infty
\le\frac1{2\pi}\int|t|\,|\psi_A-e^{-t^2/2}|dt.
\]

This proves (4.2).

Integrating `f_A-varphi` over an interval of length `2eps` proves (4.4), and the bounded derivative of the Gaussian density gives (4.5).

### Endpoint caveat

A traceless rank-two form can have a logarithmic density singularity at zero; this is exactly the phenomenon already seen in the P04/P20 inverse-tail analysis. The theorem is therefore a **delocalized-normal** statement, not a universal quadratic-form density bound.

# 5. Gaussianity is equivalent to spectral delocalization

## `P20-QUADRATIC-NORMAL-IFF-56` — PROVED

Let `A_d` be deterministic real symmetric matrices with

\[
\|A_d\|_F=1.
\]

Then the following are equivalent:

\[
\boxed{
Q_{A_d}\Rightarrow N(0,1),
}
\tag{5.1}
\]

\[
\boxed{
\|A_d\|_{op}\to0,
}
\tag{5.2}
\]

\[
\boxed{
\operatorname{tr}(A_d^4)\to0.
}
\tag{5.3}
\]

## 5.1 Sufficiency

If `||A_d||_op->0`, then `beta_3(A_d)<=||A_d||_op->0`. For all large `d`, the hypotheses of `P20-QUADRATIC-LOCAL-DENSITY-56` hold, and (4.2) gives uniform convergence of densities to the standard Gaussian density. Hence (5.1).

Since

\[
\|A\|_{op}^4\le\operatorname{tr}A^4
\le\|A\|_{op}^2\operatorname{tr}A^2
=\|A\|_{op}^2,
\]

(5.2) and (5.3) are equivalent.

## 5.2 Necessity from the exact fourth cumulant

For the centered Gaussian quadratic form (4.1), the cumulants are explicit. For every integer `r>=2`,

\[
\kappa_r(Q_A)
=2^{r/2-1}(r-1)!\,\operatorname{tr}(A^r).
\]

In particular

\[
\kappa_2=1,
\qquad
\kappa_4=12\operatorname{tr}(A^4).
\]

Thus

\[
\boxed{
EQ_A^4=3+12\operatorname{tr}(A^4).
}
\tag{5.4}
\]

The eighth moments of `Q_A` are uniformly bounded over all unit-Frobenius `A`: every cumulant of order `2,...,8` is bounded because `|tr(A^r)|<=sum|lambda_j|^r<=1`, and the eighth moment is a universal polynomial in these cumulants. Therefore `{Q_A^4}` is uniformly integrable.

If `Q_{A_d}=>N(0,1)`, uniform integrability forces `EQ_{A_d}^4->3`. By (5.4), `tr(A_d^4)->0`, proving necessity.

### Adversarial interpretation

A positive-probability family of adaptive normals with a nonvanishing spectral spike cannot have Gaussian fresh-row quadratic projections. More precisely, if along a subsequence

\[
\|A_d\|_{op}\ge c>0,
\]

then

\[
EQ_{A_d}^4\ge3+12c^4,
\]

so the conditional one-row law is bounded away from Gaussian in fourth moment. This is a mathematically exact candidate mechanism for a different hard-edge law. The present work does **not** prove that such spiky adaptive normals occur in the actual model.

# 6. Exact distance-to-span local certificate

## `P20-DISTANCE-TO-SPAN-LOCAL-56` — PROVED

Let `Z_1,...,Z_p` be the independent quadratic-feature rows. Fix an index `i` and let `S_i` be the span of the other `p-1` rows in coefficient space. On the almost-sure full-rank event for those rows, let `c_i` be a measurable unit vector spanning `S_i^perp`, and let `A_i in Sym_d` be its Frobenius-unit matrix representative under (2.1).

Because row `i` is independent of all other rows, `A_i` is independent of the fresh Gaussian vector `x_i`. Exactly,

\[
\boxed{
\operatorname{dist}(Z_i,S_i)
=
\left|
\frac{x_i^TA_ix_i-\operatorname{tr}A_i}{\sqrt2}
\right|
=|Q_{A_i}|.
}
\tag{6.1}
\]

Therefore, conditionally on `Z_{-i}`, whenever `rho(A_i)<=rho_0`, for every `0<eps<=1`,

\[
\boxed{
\left|
\frac{
P\{\operatorname{dist}(Z_i,S_i)\le\varepsilon\mid Z_{-i}\}
}{2\varepsilon}
-\frac1{\sqrt{2\pi}}
\right|
\le
C\left(\beta_3(A_i)+\varepsilon\right).
}
\tag{6.2}
\]

Since `beta_3(A_i)<=sqrt(tr A_i^4)`, the fourth-Schatten statistic of the adaptive normal is enough to calibrate the **microscopic density at zero**.

This is materially stronger than a conditional Kolmogorov CLT. A Berry--Esseen estimate of size, say, `d^-1/2` gives only an absolute CDF error `d^-1/2`, which is useless for an interval whose probability is much smaller. In contrast, (6.2) says that the error in a window of width `eps` is `O(eps beta_3)`, so the relative density error remains small even for very tiny `eps`.

## 6.1 What this does and does not solve at the hard edge

For an iid Gaussian matrix, conditional row-to-span distance is exactly `|N(0,1)|`. Equation (6.2) proves that a delocalized quadratic-feature normal has the same **one-row local density constant** to relative error `O(beta_3)`.

However, the square hard edge is not determined by one distance marginal. The `p` leave-one-out normals are strongly dependent, normalized inverse vectors couple numerator and denominator, and a rowwise replacement can amplify rare bad-normal events. P12's newest disjoint-pair amplification theorem is a useful warning in a different iid-entry model: many individually negligible mechanisms can become globally relevant.

Thus the present theorem closes the following scalar implication:

\[
\boxed{
\text{adaptive normal spectral delocalization}
\Longrightarrow
\text{Gaussian microscopic one-row small-ball density}.
}
\]

It does **not** prove:

- that all adaptive normals are delocalized with the rare-event strength needed for a `p`-step replacement;
- that inverse-normal weights are uniformly integrable;
- that a one-row density comparison controls the growing bottom singular frame;
- that the secular equation is stable at the final `p^-2` eigenvalue scale.

Those obligations remain open.

# 7. New no-go theorem: the equivariant linear Ward sector is one-dimensional

## `P20-LINEAR-EQUIVARIANT-WARD-UNIQUENESS-56` — PROVED

Let

\[
E=\operatorname{Sym}_d^0,
\qquad d\ge3,
\]

with `O(d)` acting by conjugation. Let

\[
\mathcal X:\operatorname{Sym}^2(E)\to E
\]

be a linear `O(d)`-equivariant map. Then there is a scalar `alpha` such that for every `A,B in E`,

\[
\boxed{
\mathcal X(A\odot B)
=\alpha\,\Pi_E\frac{AB+BA}{2}.
}
\tag{7.1}
\]

Equivalently, for every orthogonal projector `P` on `E` with Frobenius-orthonormal range basis `A_1,...,A_s`,

\[
\boxed{
\mathcal X(P)
=\alpha'
\left(
\sum_{a=1}^sA_a^2-\frac{s}{d}I
\right)
=\alpha'J_s(P).
}
\tag{7.2}
\]

Thus the Jordan vector is, up to scale, the **unique equivariant coefficient-space vector observable linear in the projector**.

## 7.1 Elementary proof without external invariant theory

Define the homogeneous quadratic map

\[
Q(A)=\mathcal X(A\odot A).
\]

It is `O(d)`-equivariant:

\[
Q(OAO^T)=OQ(A)O^T.
\]

First take diagonal

\[
A=\operatorname{diag}(a_1,\ldots,a_d),
\qquad
\sum_i a_i=0.
\]

Every diagonal sign matrix `D=diag(plus/minus 1)` fixes `A` under conjugation. Hence equivariance gives

\[
Q(A)=DQ(A)D
\]

for all sign choices. The only symmetric matrices fixed by every such sign conjugation are diagonal, so `Q(A)` is diagonal.

Now permutation matrices act by permuting the coordinates. Therefore the diagonal entries of `Q(A)` form an `S_d`-equivariant homogeneous quadratic polynomial map on the trace-zero hyperplane. For coordinate `i`, the only quadratic permutation-covariant terms are, before imposing `sum a_i=0`, linear combinations of

\[
a_i^2,
\qquad
a_i\sum_j a_j,
\qquad
\sum_j a_j^2,
\qquad
\left(\sum_j a_j\right)^2.
\]

On the trace-zero hyperplane this reduces to

\[
Q(A)_{ii}=c_1a_i^2+c_2\sum_j a_j^2.
\]

Because the output lies in `E`, its trace vanishes. Thus

\[
0=\sum_iQ(A)_{ii}
=(c_1+dc_2)\sum_j a_j^2,
\]

so `c_2=-c_1/d`. Hence for diagonal trace-zero `A`,

\[
Q(A)=c_1\left(A^2-\frac{\operatorname{tr}A^2}{d}I\right)
=c_1\Pi_E(A^2).
\tag{7.3}
\]

Every real symmetric `A` is orthogonally diagonalizable, so equivariance extends (7.3) to every `A in E`.

Finally polarize the quadratic map:

\[
\mathcal X(A\odot B)
=\frac14\left[Q(A+B)-Q(A-B)\right].
\]

Using (7.3),

\[
\mathcal X(A\odot B)
=\frac{c_1}{2}\Pi_E(AB+BA),
\]

which is (7.1).

For a projector

\[
P=\sum_{a=1}^sA_a\odot A_a,
\]

linearity gives

\[
\mathcal X(P)
=c_1\sum_a\Pi_E(A_a^2)
=c_1\left(\sum_aA_a^2-\frac{s}{d}I\right),
\]

proving (7.2).

## 7.2 Consequence for the P04 Ward program

P04's newest Ward flow produces an `E`-valued score and tests it against the rank-two Jordan vector `J(P)`. The audit in Section 3 shows that this linear test cancels `e(P)=||J(P)||^2` exactly.

The uniqueness theorem proves that there is no second, inequivalent **equivariant linear-in-projector `E`-valued test** waiting to be tried. Any such test is a scalar multiple of `J(P)` and reproduces the same cancellation.

Therefore the next invariant Ward attack must leave this one-dimensional sector. Admissible next tests include nonlinear projective observables such as

\[
\Pi_E(J(P)^2),
\]

or the fresh quartic statistic

\[
\|P h(U)\|^4,
\]

but not another equivariant map linear in `P`.

This is a route-exhaustion theorem, not a proof that every possible non-equivariant or higher-order Ward identity fails.
