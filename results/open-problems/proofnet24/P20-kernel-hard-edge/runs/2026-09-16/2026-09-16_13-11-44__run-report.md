# 8. Uniform frozen-base alpha<2 is impossible

## `P20-UNIFORM-TWOLEVEL-ALPHA32-NOGO-65`

For any fixed `d>=4` and `alpha>=3/2`, there is no finite constant `C(d,alpha)` such that

```text
E[K_i^alpha | B] <= C(d,alpha)
```

for every full physical `(m-3)`-row base `B`.

The explicit `B_*` above already has infinite conditional moment.

There is a stronger local statement. Let `B_n` be any sequence of full bases converging to `B_*`. Full row rank is open, so such sequences may stay entirely inside the full-base stratum. The residual projectors satisfy

```text
P_{B_n} -> P_{B_*}
```

in operator norm. For product-spherical almost every `(u,v)`, the two-row area at `B_*` is nonzero, and the determinant-weighted integrand

```text
F_B(u,v)
 =(1/6) ||b||^2 dist(a,span b)^(2(1-alpha))
```

is continuous in `B` at that `(u,v)`. Hence

```text
F_{B_n}(u,v) -> F_{B_*}(u,v)
```

for almost every pair. Fatou gives

```text
integral F_{B_*}
 <= liminf_n integral F_{B_n}.
```

The left side is infinite for every `alpha>=3/2`. Therefore

```text
boxed:
liminf_{B->B_*, B full} E[K_i^alpha | B] = infinity.
```

So the frozen-base moment is **not locally bounded** near this perfectly full physical base.

This rigorously rejects the following route:

> freeze the `(m-3)`-row base, prove an `alpha<2` conditional two-row bound uniformly over all full physical bases, then average the result.

The failure starts exactly at `alpha=3/2`, matching the generic de-selection endpoint that has repeatedly appeared in P04/P20/P23.
