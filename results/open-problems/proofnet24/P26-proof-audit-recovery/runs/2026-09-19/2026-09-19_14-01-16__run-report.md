## 5. Independent exact finite core

For a graph `G` and a nonempty vertex set `A`, let `C_A(z)` be the connected spanning-subgraph polynomial of `G[A]`, with the exponent of `z` recording the number of selected edges. Fix a root `r in A`. Every selected-edge spanning subgraph of `G[A]` has a unique connected component `B` containing `r`, hence

\[
C_A(z)
=(1+z)^{e(A)}-
\sum_{\substack{B\subsetneq A\\r\in B}}
C_B(z)(1+z)^{e(A\setminus B)}.
\]

This recurrence uses integer arithmetic only. If `s,t` are the terminals, every split state has a unique `s`-component `A` not containing `t`, so the split generating polynomial is

\[
F_G(z)=
\sum_{\substack{A\subset V\\s\in A,\ t\notin A}}
C_A(z)C_{V\setminus A}(z).
\]

Writing `F_G(z)=sum_j N_j(G) z^j`, the coefficient `N_j(G)` is exactly the number of successful `j`-edge split subgraphs.
