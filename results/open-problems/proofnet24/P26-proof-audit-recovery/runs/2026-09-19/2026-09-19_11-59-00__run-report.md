## 2. Source and literature boundary, date-checked 2026-09-19

Primary source:

The proof relies on three classical all-terminal-reliability inputs, all of which I independently checked against current bibliographic records:

1. Petingi--Saccoman--Schoppmann, *Uniformly least reliable graphs*, Networks 27 (1996), 125--131: uniformly least reliable graphs are characterized in the dense range `e >= (n-1)(n-2)/2 + 1`. At `e=C(n,2)-3`, the extremal graph is `K_n` with a 3-edge star deleted.
2. Satyanarayana--Schoppmann--Suffel, *A reliability-improving graph transformation with applications to network reliability*, Networks 22 (1992), 209--216, DOI `10.1002/net.3230220206`: deleting `r` independent edges from `K_n` gives strictly greater all-terminal reliability than every other graph with the same order and size for `0<p<1`; here only `r=3` is used.
3. Kelmans compression / swing-surgery monotonicity: compression cannot increase all-terminal reliability. Kahl, Discrete Applied Mathematics 292 (2021), 108--116, DOI `10.1016/j.dam.2020.12.025`, records the modern formulation and the classical monotonicity.

These mechanisms are prior art. The audit makes no novelty claim for them.

## 3. Independent reconstruction of the split/all-terminal bridge

Fix terminals `s,t`. If `X` does not contain the edge `st`, then partition the connected states of `X+st` according to whether `X` was already connected or whether `st` is operational and joins exactly two components separating `s` and `t`. This gives the exact identity

`Rel(X+st;p) = Rel(X;p) + p SR_X^{s,t}(p)`.        (1)

Thus split reliability is exactly the all-terminal Birnbaum importance of the missing terminal edge in the host `X+st`.

The terminal-edge swap reduction also survives independently. If a graph `G` contains `st` and misses an edge `e`, put `G'=G-st+e`. Couple the random states of all common edges. Whenever `G` realizes a split state, either `G'` already realizes the same split state or the only obstruction is that the new edge `e` crosses the split cut; conditioning on failure of `e` restores the split. Therefore

`SR_{G'}(p) >= SR_G(p)` for all `p in [0,1]`.

At density `C(n,2)-3` and `n>=6`, deleting three edges from `K_n` cannot disconnect the graph, so this swap remains inside the source class. Hence an optimum may be assumed to have `st` missing.

## 5. Independent proof of the max-minus-three theorem

Write the all-terminal reliabilities

- `a = Rel(K_n - P_2^adj)`;
- `i = Rel(K_n - 2K_2)`;
- `S = Rel(K_n - K_{1,3})`;
- `T = Rel(K_n - K_3)`;
- `P = Rel(K_n - P_4)`;
- `Q = Rel(K_n - (P_3 union K_2))`;
- `J = Rel(K_n - 3K_2)`.

Using (1), the seven split reliabilities satisfy

`p SR_A = a-S`,
`p SR_B = a-T`,
`p SR_C = i-P`,
`p SR_D = a-P`,
`p SR_E = i-Q`,
`p SR_F = a-Q`,
`p SR_G = i-J`.                                     (5)

The classical inputs give (4), (3), and

`P <= J`.                                            (6)

For the adjacent-host types,

`p(SR_A-SR_B)=T-S >=0`,
`p(SR_A-SR_D)=P-S >=0`,
`p(SR_A-SR_F)=Q-S >=0`.                             (7)

For the independent-host types, substitute the exact switch identity (2):

`p(SR_A-SR_C)`
`=(a-S)-(i-P)`
`=(P-S)-q(P-S)`
`=p(P-S) >=0`;                                      (8)

`p(SR_A-SR_E)`
`=(Q-S)-q(P-S)`
`=(Q-P)+p(P-S) >=0`;                                (9)

`p(SR_A-SR_G)`
`=(J-S)-q(P-S)`
`=(J-P)+p(P-S) >=0`.                               (10)

Thus the type A graph

`A_n=K_n-{st,su,sv}`

weakly dominates all seven terminal-missing types for every `0<p<1`. The initial terminal-edge swap extends this to every graph in `T_{n,M-3}`. Endpoints are zero, so

`SR_{A_n}(p) >= SR_G(p)` for all `G in T_{n,M-3}` and all `p in [0,1]`.

Therefore the owner's theorem is mathematically correct for every `n>=6`; its source-new content begins at `n>=8`.

## 6. Method #11 — DUALIZE: a four-gap cone certificate

The proof becomes particularly transparent after dualizing the seven split comparisons into four primitive nonnegative all-terminal gaps. Define

`d_T = T-S >=0`,
`d_P = P-S >=0`,
`d_Q = Q-P >=0`,
`d_J = J-P >=0`.

Then equations (7)--(10) are exactly

`p(SR_A-SR_B)=d_T`,
`p(SR_A-SR_D)=d_P`,
`p(SR_A-SR_F)=d_P+d_Q`,
`p(SR_A-SR_C)=p d_P`,
`p(SR_A-SR_E)=d_Q+p d_P`,
`p(SR_A-SR_G)=d_J+p d_P`.

Every desired comparison is therefore a nonnegative conical combination of four primitive ATR gaps with coefficients in `{1,p}`. This is an independent proof certificate for the sign pattern: there is no hidden cancellation left to control once the switch identity has been established.

This also exposes exactly which classical ingredients are essential. The star ULRG theorem supplies `d_T,d_P>=0`; compression supplies `d_Q>=0`; independent-edge deletion maximality supplies `d_J>=0`. The split theorem is a linear image of this four-generator positive cone.
