## 2. Exact source scope

The primary source is Pablo Romero, *Characterization of locally most split reliable graphs*, Theoretical Computer Science 1047 (2025), 115327, DOI `10.1016/j.tcs.2025.115327`, arXiv:`2503.15453`.

For a connected simple two-terminal graph `G in T_{n,m}`, Romero defines

`SR_G(p) = sum_j N_j(G) p^j (1-p)^(m-j)`,

where `N_j(G)` counts spanning split subgraphs with exactly two components, one containing each terminal. The source's Theorem 10 identifies the locally most split reliable class with the split-equivalence class of the diameter-terminal balloon `G_{n,m}`. Its Theorem 12 proves nonexistence only for

`n >= 7, n <= m <= C(n-3,2)+3`,

and the closing paragraph leaves open

`n >= 7, C(n-3,2)+4 <= m <= C(n,2)-2`.

For `n=8` this unresolved range is exactly `m=14,...,26`. Brown--McMullin's earlier finite classification covers `n<=7`. ## 3. Method #2 — ATTACK THE NEGATION FIRST

I tried to break the package at its three literal interfaces: source reduction, finite graph universe, and coefficient interpretation.

### 3.1 Source reduction

A uniform maximizer is automatically locally most split reliable. Romero Theorem 10 says every locally most split reliable graph in `T_{n,m}` is split-equivalent to the diameter-terminal balloon. Therefore, in a nonexistence case, it is enough to find one competitor beating the balloon polynomial somewhere. This is exactly the reduction R06 uses for `m=14,...,19`; it does not assume uniqueness of the graph itself.

### 3.2 Two-terminal isomorphism scope

Romero permits an isomorphism to preserve the terminal set either pointwise or by swapping the two terminals. The dense checker fixes terminals `0,1` pointwise and quotients only by `S_6` on the other six vertices. This quotient is finer than the source quotient, so it can duplicate source classes but cannot omit one. Thus an exhaustive pointwise-terminal check is source-safe.

### 3.3 Split coefficient semantics

For a fixed `m`, every selected edge set with `j` operational edges has probability `p^j(1-p)^(m-j)`. Hence coefficientwise inequalities `N_j(B)>=N_j(H)` imply `SR_B(p)>=SR_H(p)` for every `p in [0,1]`. No hidden binomial coefficient is missing: `N_j` itself counts the individual edge subsets.

No source-scope, terminal-symmetry, coefficient-normalization, or endpoint counterexample survived.

`(1+z)^{e(S)} = sum_{T subseteq S, r in T} C_T(z)(1+z)^{e(S\T)}`.

This identity is correct: an arbitrary selected-edge subgraph of `G[S]` has a unique root component `T`; all crossing edges are absent and the edge set inside `S\T` is arbitrary. A split subgraph has a unique component `S` containing terminal `s` but not `t`, so

`F_G(z)=sum_{S: s in S, t notin S} C_S(z) C_{V\S}(z)=sum_j N_j(G)z^j`.

## 6. Method #11 — DUALIZE
