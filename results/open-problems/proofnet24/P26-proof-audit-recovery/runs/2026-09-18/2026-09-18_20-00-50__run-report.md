## 4. #2 ATTACK THE NEGATION FIRST — convention and boundary falsification attempts

I first tried to break the theorem at the places where finite-field Fourier identities most often hide a convention error.

### 4.1 The zero-frequency cases

The proof factors `(FLF)_{a,b}` into two Gauss sums at frequencies proportional to `a-b` and `a+b`. If `a=b` or `a=-b`, one frequency is zero. The corresponding sum is

\[
\sum_{u\in\mathbb F_p}\chi(u)=0.
\]

The claimed right-hand side is simultaneously

\[
L_{a,b}=\chi(a^2-b^2)=\chi(0)=0.
\]

Thus the boundary cases are not being smuggled through a formula valid only for nonzero frequencies.

### 4.2 Dependence on the additive character

Replacing the basic additive character by `psi_c(u)=psi(cu)` with `c!=0` multiplies each one-dimensional quadratic Gauss sum by `chi(c)`. There are two such factors, so the product is unchanged. The identity therefore does not depend on a hidden choice of primitive additive character.

### 4.3 The factor `2`

The change of variables

\[
u=x-y,\qquad v=x+y
\]

uses division by two. Here `p=1 (mod 4)` is an odd prime, so this map is invertible. No characteristic-two exception lies inside the claim.

### 4.4 The sign of the Gauss square

For a quadratic character,

\[
G^2=\chi(-1)p.
\]

The hypothesis `p=1 (mod 4)` gives `chi(-1)=1`, exactly the sign required by the asserted self-duality. For `p=3 (mod 4)` the same calculation would produce the opposite sign, so the congruence assumption is structurally doing real work.

### 4.5 Localization boundary

At `p=5`, the formula `|D_p|=(p-5)/2` gives an empty split domain. Claim 18 only asserts the projector noncommutation for `p>=13`, so there is no hidden `p=5` strict-inequality defect. At `p=13`, `|D_p|=4`, so `P_D` is already nonzero and proper and the noncommutation argument applies.

These falsification attempts found no literal-scope counterexample.

## 5. Independent reconstruction of the full proof

Let

\[
G=\sum_{u\in\mathbb F_p}\chi(u)\psi(u)
\]

be the quadratic Gauss sum. For every `c!=0`, changing variables gives

\[
\sum_u\chi(u)\psi(cu)=\chi(c)G,
\]

and for `c=0` the sum is zero. Since `p=1 (mod 4)`,

\[
G^2=p.
\]

Now

\[
(FLF)_{a,b}
=\frac1p\sum_{x,y}\chi(x^2-y^2)\psi(-ax-by).
\]

Use the invertible change `u=x-y`, `v=x+y`. Then `x^2-y^2=uv` and

\[
-ax-by=-\frac{a-b}{2}u-\frac{a+b}{2}v.
\]

Therefore

\[
\begin{aligned}
(FLF)_{a,b}
&=\frac1p
\left(\sum_u\chi(u)\psi\!\left(-\frac{a-b}{2}u\right)\right)
\left(\sum_v\chi(v)\psi\!\left(-\frac{a+b}{2}v\right)\right)\\
&=\frac{G^2}{p}\,
\chi\!\left(-\frac{a-b}{2}\right)
\chi\!\left(-\frac{a+b}{2}\right)
\end{aligned}
\]

when both frequencies are nonzero, while the already-checked zero-frequency cases vanish on both sides. Because `G^2=p`, `chi(-1)=1`, and `chi(4)=1`, the last expression is

\[
\chi((a-b)(a+b))=\chi(a^2-b^2)=L_{a,b}.
\]

Hence

\[
\boxed{FLF=L}.
\]

Next, `L(-x,y)=L(x,y)=L(x,-y)`, so

\[
RL=L=LR.
\]

The normalized finite Fourier transform satisfies `F^2=R`. Left-multiplying `FLF=L` by `F` gives

\[
F^2LF=FL,
\]

and therefore, using `RL=L`,

\[
LF=FL.
\]

If `f` is odd, then `Rf=-f`, and

\[
Lf=LRf=-Lf,
\]

so `Lf=0`. On the even subspace `R=I`, hence `F^2=I`, which yields the claimed `F=+1/-1` decomposition of the parent operator.

Finally, `P_D` is diagonal with entries `d_x in {0,1}`. Every Fourier entry is nonzero. If `P_DF=FP_D`, then entrywise

\[
d_aF_{a,x}=F_{a,x}d_x
\]

for all `a,x`. Since `F_{a,x}!=0`, this forces `d_a=d_x` for all `a,x`, so `P_D` would be either zero or identity. For `p>=13`,

\[
|D_p|=\frac{p-5}{2}
\]

is strictly between `0` and `p`, contradiction. Thus

\[
\boxed{P_DF\ne FP_D}.
\]

This independently reconstructs every mathematical assertion in Claim 18.

## 6. #14 FIND THE GROUP ACTING — the symmetry that survives localization

The owner report emphasizes that additive Fourier symmetry is destroyed by the second localization. There is, however, a smaller exact symmetry that survives, and identifying it is useful for checking the theorem's geometry.

The split set is invariant under reflection:

\[
z\in D_p\iff -z\in D_p,
\]

because its defining condition depends only on `z^2`. Therefore

\[
P_DR=RP_D.
\]

So the localization does **not** destroy the clone-exchange `C_2` action. Since `L` is even in each coordinate, the compressed kernel

\[
P_DLP_D
\]

still annihilates the odd clone sector. What fails is the much larger additive-Fourier diagonalization: `P_D` preserves parity but does not preserve the Fourier eigenspaces.

This separates two facts that can otherwise be conflated:

- the `z<->-z` fiber symmetry is exact after localization;
- the metaplectic/Fourier symmetry of the parent kernel is not.

That distinction is consistent with the two-clone lift formula for `A^uparrow` and supplies an independent structural check on the owner's interpretation.

## 7. #20 FIND WHY THE ALGORITHM FAILS — exact size of the Fourier-symmetry defect

The owner's failure certificate says only `P_DF != FP_D`. The same calculation yields a stronger exact quantitative obstruction.

Let `P` be **any** diagonal `0/1` projector of rank `d` on `C^{F_p}`. Because every normalized Fourier entry has squared modulus `1/p`,

\[
(PF-FP)_{a,x}=(d_a-d_x)F_{a,x}.
\]

The ordered pairs `(a,x)` for which `d_a!=d_x` are exactly

\[
2d(p-d).
\]

Hence

\[
\boxed{
\|PF-FP\|_F^2=\frac{2d(p-d)}{p}.
}
\tag{7.1}
\]

For the actual split localization, `d=(p-5)/2`, so

\[
\boxed{
\|P_DF-FP_D\|_F^2
=\frac{p^2-25}{2p}.
}
\tag{7.2}
\]

In particular the defect is macroscopic, of order `p` in squared Hilbert--Schmidt norm. Since a `p x p` matrix satisfies `||A||_F <= sqrt(p)||A||_op`, this also gives

\[
\boxed{
\|P_DF-FP_D\|_{op}
\ge
\sqrt{\frac{p^2-25}{2p^2}}
=\frac1{\sqrt2}\sqrt{1-\frac{25}{p^2}}.
}
\tag{7.3}
\]

Thus the localization projector is not even asymptotically commuting with the Fourier transform in operator norm. The failure of the naive bounded-symbol algorithm is therefore robust: one cannot recover the source operator by treating second localization as a small perturbation of a Fourier-invariant parent.
