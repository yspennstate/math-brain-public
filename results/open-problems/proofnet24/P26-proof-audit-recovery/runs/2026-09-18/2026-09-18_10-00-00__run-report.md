## 3. Exact source scope, checked directly

The current arXiv PDF is still **v2 dated 7 July 2014**. On p. 25, Problem 3 asks: if `(G,mu)` is a measured group, `H<G` acts ergodically on the Poisson boundary, and `d` is a left `G`-invariant metric on `G/H`, is

\[
\lim_{n\to\infty}
\frac1n\sum_{k=1}^n
\int_G d(gH,H)\,d\mu^{*k}(g)=0?
\tag{P3}
\]

The source defines a measured group by requiring `supp(mu)` to generate `G` as a semigroup. Its ordinary drift earlier in the paper uses the single-time normalization

\[
\ell_d(\mu)=\lim_n \frac1n\int_G d(g,e)\,d\mu^{*n}(g).
\]

Thus the extra Cesàro sum of **unnormalized** distances in `(P3)` is genuinely what the current v2 prints; this audit does not silently replace it with a differently normalized intended question.

## 4. Independent source-level refutation

The simplest owner counterexample is correct end to end.

Take

\[
G=\mathbb Z,\qquad H=\{0\},\qquad
\mu=\tfrac12(\delta_{-1}+\delta_{1}),
\qquad d(aH,bH)=|a-b|.
\]

The support `{−1,+1}` semigroup-generates `Z`, so this is a measured group in the source sense. The metric is left invariant and has finite first `mu`-moment.

Every bounded `mu`-harmonic function `f` satisfies

\[
f(n)=\frac{f(n-1)+f(n+1)}2,
\]

so all first differences are equal and boundedness forces `f` to be constant. Hence the Poisson boundary is trivial. The subgroup `H={0}` therefore acts ergodically on it.

If `S_k` is the simple symmetric walk, then the source integral is `E|S_k|`. For every odd `k`, `S_k` is odd and therefore `|S_k|>=1` almost surely. Consequently

\[
\frac1n\sum_{k=1}^n E|S_k|
\ge \frac{\lceil n/2\rceil}{n},
\]

and hence

\[
\liminf_{n\to\infty}
\frac1n\sum_{k=1}^n E|S_k|
\ge\frac12>0.
\]

This is a complete counterexample satisfying the printed hypotheses. It does not depend on a finite quotient, nonsymmetric increments, a nonintegrable metric, or a nontrivial-boundary loophole.

## 5. Method #3 — prove something stronger: a sharper universal obstruction

R19's latest theorem is also valid: on every nontrivial quotient and every invariant metric, a single support atom already forces a positive lower gap. I independently found a stronger and cleaner bounded-truncation version which strictly improves the constant and removes the need to optimize a near/far split.

Let `(G,mu)` be any countable measured group, `H<G` proper, and `d` any left `G`-invariant metric on `X=G/H`. Put `o=H` and

\[
A_n:=\frac1n\sum_{k=1}^n
\int_G d(gH,H)\,d\mu^{*k}(g).
\]

For `r>0` define the one-step tail mass

\[
q_r:=\mu\{g\in G:d(gH,H)\ge r\}.
\]

Because `supp(mu)` semigroup-generates `G` and `H` is proper, some support element lies outside `H`; therefore `q_r>0` for some `r>0`.

**Stronger theorem.** For every such `r` and every `n>=1`,

\[
\boxed{
A_n\ge
\frac{r}{1+q_r}
\left(q_r-\frac{1-q_r}{n}\right)
}
\tag{1}
\]

whenever the right side is positive (and otherwise the inequality is vacuous because `A_n>=0`). In particular,

\[
\boxed{
\liminf_{n\to\infty}A_n
\ge \frac{r q_r}{1+q_r}>0.
}
\tag{2}
\]

### Complete proof

Define the bounded truncation

\[
f_r(x):=\min\{d(x,o),r\},\qquad 0\le f_r\le r.
\]

If `t` satisfies `d(to,o)>=r`, left invariance and the triangle inequality give

\[
d(tx,o)
\ge d(to,o)-d(tx,to)
=d(to,o)-d(x,o)
\ge r-d(x,o).
\]

If `d(x,o)<=r`, this implies `f_r(tx)>=r-f_r(x)`; if `d(x,o)>r`, the right side is zero, so the same inequality remains true. Thus

\[
f_r(tx)\ge r-f_r(x)
\quad\text{for every }t\text{ with }d(to,o)\ge r.
\tag{3}
\]

Let

\[
m_k:=\int_G f_r(gH)\,d\mu^{*k}(g).
\]

Using `mu^{*(k+1)}=mu*mu^{*k}` and retaining only the set of increments in (3),

\[
m_{k+1}
\ge q_r(r-m_k).
\tag{4}
\]

Write

\[
b_n:=\frac1n\sum_{k=1}^n m_k.
\]

Summing (4) for `k=1,...,n` gives

\[
\sum_{k=1}^n m_{k+1}
\ge n q_r r-q_r n b_n.
\tag{5}
\]

But

\[
\sum_{k=1}^n m_{k+1}
=n b_n+m_{n+1}-m_1.
\]

Since `m_{n+1}<=r` and already at time one

\[
m_1\ge q_r r,
\]

we have

\[
\sum_{k=1}^n m_{k+1}
\le n b_n+r(1-q_r).
\tag{6}
\]

Combining (5) and (6),

\[
n b_n+r(1-q_r)
\ge n q_r r-q_r n b_n,
\]

hence

\[
b_n\ge
\frac{r}{1+q_r}
\left(q_r-\frac{1-q_r}{n}\right).
\]

Finally `f_r(x)<=d(x,o)`, so `A_n>=b_n`, proving (1); taking `liminf` proves (2). If an untruncated source moment is infinite, `A_n=+infinity` only makes the conclusion easier. ∎

For a single support atom `s` of mass `p` at distance `r`, `q_r>=p`, and even the weaker substitution `q_r=p` yields the asymptotic gap `pr/(1+p)`, which is strictly stronger than R19's `pr/(1+sqrt(p))^2`. For the symmetric `Z` counterexample, `q_1=1`, so (2) gives the exact robust lower gap `1/2` already obtained by parity.

This strengthening is audit diagnosis, not a new owned package and not another metric point.

## 6. Method #18 — say it in another language

The printed quantity is the first moment of a **Cesàro occupation measure** on the quotient. The bounded function `f_r=d(o,.) wedge r` is a dual witness: if the Cesàro first moment were tending to zero, then almost all occupation mass would have to sit arbitrarily close to `o`. But semigroup generation guarantees positive one-step mass `q_r` which moves `o` at least distance `r`, and left invariance means the same increment pushes every near-`o` point away by the triangle inequality. The one-step balance (4) prevents the Cesàro occupation from concentrating at `o`.

In this language Poisson-boundary ergodicity is not merely unused by one example; it is irrelevant to the obstruction on every proper quotient. The failure happens at the level of a bounded radial test function before harmonic-boundary machinery enters.

## 7. Method #20 — find why the expected proof algorithm fails

The source motivates Problem 3 as a homogeneous-space extension of Karlsson--Ledrappier drift, but the displayed functional is not the ordinary drift scale. Ordinary drift asks about

\[
\frac1n E[d(X_nH,H)],
\]

whereas `(P3)` asks for the arithmetic mean of the **raw** distances

\[
\frac1n\sum_{k=1}^n E[d(X_kH,H)].
\]

The bounded-truncation recurrence shows that on any proper quotient the raw-distance Cesàro average cannot approach zero at all: a fixed positive one-step displacement leaves a positive balance. Thus a proof strategy that starts with Poisson-boundary ergodicity is trying to solve the wrong obstruction; the normalization fails first.

This is a diagnosis of the literal v2 formula only. It is **not** a claim that Björklund intended this normalization, nor a claim that a corrected single-time or time-normalized homogeneous-space statement is false.
