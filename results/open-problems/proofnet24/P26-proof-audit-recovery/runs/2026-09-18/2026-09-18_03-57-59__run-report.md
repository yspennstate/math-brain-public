## 3. Independent proof of the Markov-to-theta implication

Use the standard theta-dual normalization frozen by P04:

\[
\vartheta(\overline H)
=
\min\{\lambda_{\max}(B):
B=B^T,\ B_{ii}=1,\ B_{ij}=1\text{ for }ij\in E(H)\}.
\]

Suppose `P` satisfies the theorem hypotheses and put

\[
A=(n-t)P,\qquad B=J-A.
\]

Because `P_ii=0`, `B_ii=1`. Because `P` is supported only on edges of `\overline H`, we have `A_ij=0` for `ij in E(H)`, so `B_ij=1` on every edge of `H`. Hence `B` is a feasible theta-dual matrix.

At level `t`,

\[
tI-B=tI+(n-t)P-J.
\]

Symmetry and stochasticity give `P 1=1` and invariance of `1^perp`. On `span{1}` the displayed matrix has eigenvalue

\[
t+(n-t)-n=0.
\]

On `1^perp`, `J` vanishes, so the same matrix restricts to

\[
tI+(n-t)P.
\]

The hypothesis `P >= -t/(n-t) I` makes this restriction positive semidefinite. Therefore `tI-B>=0`, so `lambda_max(B)<=t` and hence `theta(overline H)<=t`.

Conversely, inside the stated positive constant-row cone, let `A>=0` be symmetric, complement-supported, zero-diagonal, and satisfy

\[
A1=(n-t)1.
\]

Then `P=A/(n-t)` is symmetric stochastic with the required support. For `B=J-A`, exactly the same orthogonal decomposition shows

\[
tI-B\succeq0
\iff
tI+A\succeq0\ \text{on }1^\perp
\iff
\lambda_{\min}(A)\ge-t.
\]

The eigenvalue on `span{1}` is again exactly zero. Thus the claimed equivalence is correct **within the frozen positive constant-row cone**.

For `H=G_{p,2}`,

\[
n=\frac{p-5}{4},\qquad t_p=\frac23\sqrt p,
\]

so direct algebra gives

\[
\delta_p=\frac{t_p}{n-t_p}
=\frac{8\sqrt p}{3p-8\sqrt p-15}
\sim\frac{8}{3\sqrt p}.
\]

This specialization is correct whenever `0<t_p<n`, which is automatic in the eventual large-prime regime relevant to the source.

## 4. Method #3 — prove a stronger representation statement

Rather than merely accepting the displayed `S_3` blocks, I proved the finite-group statement from which they follow.

Let a finite group `Gamma` act freely on a finite vertex set with `m` orbits, and let `P` commute with the induced permutation action. After choosing one representative per orbit, identify the vertex set with `[m] x Gamma`. Equivariance implies

\[
P_{(a,h),(b,k)}=w_{ab}(h^{-1}k)
\]

for kernels `w_ab:Gamma -> C`. Symmetry is exactly

\[
w_{ba}(g^{-1})=\overline{w_{ab}(g)}.
\]

Apply the group Fourier transform on the regular coordinate. For each unitary irreducible representation `rho` of dimension `d_rho`, define the `m d_rho` by `m d_rho` matrix with blocks

\[
\widehat P_\rho(a,b)=\sum_{g\in\Gamma}w_{ab}(g)\rho(g),
\]

up to the harmless inverse convention of the Fourier transform. Peter-Weyl/regular-representation decomposition gives

\[
P\simeq
\bigoplus_{\rho\in\widehat\Gamma}
I_{d_\rho}\otimes\widehat P_\rho.
\]

The symmetry relation makes each `widehat P_rho` Hermitian (with the corresponding inverse convention). Consequently

\[
P+\delta I\succeq0
\iff
\widehat P_\rho+\delta I\succeq0
\quad\text{for every irreducible }\rho.
\]

This is strictly stronger than the `S_3` formula and confirms that the owner reduction is a special case of the exact regular-representation decomposition, not a dimension-count coincidence.

For `Gamma=S_3`, the real irreducibles have dimensions `1,1,2`: trivial, sign, and standard. Thus the six-dimensional regular representation is

\[
1\oplus\mathrm{sgn}\oplus\mathrm{std}\oplus\mathrm{std}.
\]

With `m` free orbits this yields one `m x m` trivial block `Q`, one `m x m` sign block `S`, and one `2m x 2m` standard block `R` with multiplicity two:

\[
P\simeq Q\oplus S\oplus(I_2\otimes R).
\]

The dimensions add to

\[
m+m+2(2m)=6m.
\]

Therefore

\[
P+\delta I\succeq0
\iff
Q+\delta I_m\succeq0,
\quad
S+\delta I_m\succeq0,
\quad
R+\delta I_{2m}\succeq0.
\]

The inverse-vs-noninverse Fourier convention only transposes/unitarily conjugates the representation blocks and cannot change the spectral condition. This removes a potential convention-level ambiguity in the owner formula.

## 5. Automorphism averaging survives independently

If `Gamma <= Aut(H)` and `P` is feasible, then for every `g`,

\[
U_gPU_g^{-1}
\]

is again symmetric, stochastic, nonnegative, zero-diagonal and complement-supported. Also

\[
U_g(P+\delta I)U_g^{-1}\succeq0.
\]

The feasible set is convex, so averaging over `Gamma` preserves every constraint. Hence one may search for a `Gamma`-invariant positive Markov certificate without loss **inside this positive Markov subproblem**.

This is exactly the premise needed before the free-`S_3` Fourier reduction. It does not assert that averaging turns an arbitrary theta-dual optimum into a positive Markov certificate; positivity and the constant-row condition remain extra restrictions.

## 7. Method #20 — find why the positive-Markov algorithm can fail

The theorem must not be read as an equivalence with the full theta SDP. A three-vertex exact obstruction makes the distinction explicit.

Let the allowed support graph be the path `K=P_3` with edges `12` and `23`, and let `H=overline K`. A symmetric, zero-diagonal matrix supported on `K` has the form

\[
P=
\begin{pmatrix}
0&a&0\\
a&0&b\\
0&b&0
\end{pmatrix}.
\]

Stochasticity forces from row 1 `a=1`, from row 3 `b=1`, but then row 2 has sum `a+b=2`, contradicting the required row sum one. Thus the positive zero-holding Markov feasible set on `P_3` is empty.

Nevertheless

\[
\vartheta(P_3)=2:
\]

indeed `alpha(P_3)=2`, while the complement is an edge plus an isolated vertex and has chromatic number two, so the Lovasz sandwich gives `2 <= theta(P_3) <= 2`.

Taking `n=3`, `t=2`, the original theta inequality is therefore true while the positive-Markov sufficient route has no feasible point. This exact diagnostic proves that the theorem's phrase “within the constant-row positive complement cone” is essential. It also explains what the next P04 route must solve: existence of a sufficiently good fractional/symmetric zero-holding chain on the localized complement, not merely a generic theta certificate.

The simplest scalar-edge weighting can fail even earlier: unless the complement graph is regular, a single constant edge weight cannot satisfy the constant-row condition. Thus a successful chain for the irregular two-localization genuinely needs orbit-dependent/global balancing, consistent with the owner report's diagnosis.
