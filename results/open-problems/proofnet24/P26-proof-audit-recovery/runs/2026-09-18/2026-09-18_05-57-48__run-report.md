## 4. Frozen T14 statement

Let

\[
D=\bigcup_{j=1}^m [a_j,b_j]
\]

be a finite union of pairwise disjoint nondegenerate compact intervals with positive gaps, and let

\[
\mathcal F_D=\{(-u,x):u>0,\ x/\sqrt u\in D\}\cup\{(0,0)\}.
\]

Write

\[
\lambda_j=\lambda_0(a_j,b_j),\qquad
\lambda_*(D)=\min_j\lambda_j.
\]

T14 asserts:

1. if `lambda_*(D)>1`, every FBM fails eventual confinement to `F_D`;
2. if `lambda_*(D)<1`, some decomposable FBM is eventually confined to `F_D` almost surely;
3. if some component contains zero and has exponent `<1`, some decomposable FBM is pointwise confined to `F_D` for all negative times.

The critical equality case is not classified.

## 5. Method #27 — swap the quantifiers and remove the random-branch ambiguity

The most natural proof says a continuous normalized tail eventually “chooses a component.” I rewrote this to avoid any hidden measurable-selection step.

Put

\[
y(u)=X_{-u}/\sqrt u.
\]

For each deterministic component `I_j=[a_j,b_j]`, define

\[
E_j=\{\exists R<\infty\ \forall u\ge R:\ y(u)\in I_j\}.
\]

Because `[R,infinity)` is connected and `y` is continuous, if the tail lies in the finite disconnected set `D`, its image lies in one component. Hence the eventual-confinement event is exactly

\[
E=\bigcup_{j=1}^m E_j.
\]

This finite deterministic union is cleaner than first introducing a random selected branch. If `lambda_*(D)>1`, then every `lambda_j>1`. For fixed `j`, continuity of the source exponent permits a small endpoint enlargement

\[
[a_j-\delta,b_j+\delta]
\]

whose exponent is still `>1`. On `E_j`, one has simultaneously `liminf y >=a_j` and `limsup y<=b_j`, while source Theorem 4.3(i) on the enlarged interval forces escape beyond at least one enlarged endpoint. Thus `P(E_j)=0` for each `j`, hence `P(E)=0`.

For the existence direction, choose `j` with `lambda_j<1`. Shrink to

\[
[a_j+\varepsilon,b_j-\varepsilon]
\]

while preserving exponent `<1`. Source Theorem 4.3(ii) gives a decomposable FBM with liminf/limsup inside the shrunken interval. The strict margin converts those asymptotic inequalities into eventual exact membership in the original component. T14(ii) follows.

If a winning component contains zero and has exponent `<1`, source Theorem 4.3(iii) applied directly to that component gives the pointwise all-negative-time clause T14(iii).

This proof independently confirms all three frozen clauses and makes their quantifier structure explicit.

### #18 SAY IT IN ANOTHER LANGUAGE

Under the Lamperti transform

\[
Y_s=e^{-s/2}B_{e^s},
\]

ordinary Brownian motion becomes stationary OU motion and a static normalized fan becomes killing outside the fixed set `D`. On a finite disconnected union,

\[
H_0^1(D)=\bigoplus_j H_0^1((a_j,b_j)),
\]

so the killed OU generator is a direct sum and its spectral bottom is

\[
\lambda_0(D)=\min_j\lambda_0(a_j,b_j)=\lambda_*(D).
\]

The topology and the spectrum therefore tell the same story: a continuous tail selects one connected component, and the direct-sum operator selects the least expensive component. This is the conceptual reason convexifying the domain is wrong.

For the canonical far interval `[5,6]`, the OU ground-state transform gives, for an interval of length one,

\[
\lambda_0(5,6)
\ge \frac{5^2}{8}-\frac14
=\frac{23}{8}>1.
\]

By reflection the same holds on `[-6,-5]`. But the convex hull `[-6,6]` strictly contains the critical interval `[-1,1]`, so strict domain monotonicity gives

\[
\lambda_0(-6,6)<1.

Thus convexification can literally reverse the strict-phase verdict.
