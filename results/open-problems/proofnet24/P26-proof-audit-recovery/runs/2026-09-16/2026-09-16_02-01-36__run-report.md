# 2. Exact retained Target-4 setup

Let

`E=Sym_d^0`,

`m=(d-1)(d+2)/2`,

and

`h(u)=sqrt(d(d+2)/2) (u u^T-I/d)`.

Then

`||h(u)||_F^2=m`,

`E[h(U) tensor h(U)]=I_E`.

For a deterministic rank-`q` coefficient plane `P` with Frobenius-orthonormal basis `A_1,...,A_q`, put

`V_P(u)=(<A_1,h(u)>,...,<A_q,h(u)>)`.

For iid `U_1,...,U_q`, let `Y` be the `q x q` matrix with rows `V_P(U_j)^T`, and let

`W=det Y`,

`K=Y Y^T`,

`R=(det K)^(-1)=W^(-2)`.

Isotropy gives

`E W^2=q!`.

Hence the determinant-selected conditional law is

`dQ_P=(W^2/q!) dmu^q`,

and the exact de-selection likelihood is

`Lambda=dmu^q/dQ_P=q! R=q!/W^2`.

For the deletion process, with residual rank `s`, define

`C(P_s)=sum_{a=1}^s A_a^2`,

`e(P_s)=tr C(P_s)^2-s^2/d`.

`e_{s-1}=((s-2)/s)e_s+gamma_s`,

Consequently

`e_2=sum_{s=3}^m 2 gamma_s/((s-1)(s-2))`.

Ranks above `d` cost only `O(1/d)` under the universal bound `gamma_s<=1-1/d`; the live positive budget is localized to the final linear ranks.

# 4. New deterministic cap on the Jordan defect

## `P26-T4-JORDAN-DEFECT-CAP-15` — PROVED

Let `P` be any rank-`s` coefficient plane in `Sym_d^0` with Frobenius-orthonormal symmetric basis `A_1,...,A_s`. Put

`C=C(P)=sum_a A_a^2`.

Each `A_a^2` is positive semidefinite, hence

`C>=0`.

Moreover

`tr C=sum_a tr(A_a^2)=sum_a ||A_a||_F^2=s`.

If the eigenvalues of `C` are `lambda_1,...,lambda_d>=0`, then

`sum_i lambda_i=s`.

Cauchy-Schwarz gives

`tr C^2=sum_i lambda_i^2 >= s^2/d`.

At the other extreme, positivity gives

`sum_i lambda_i^2 <= (sum_i lambda_i)^2=s^2`.

Therefore pointwise

`0 <= e(P)=tr C^2-s^2/d <= s^2(1-1/d)`.

For rank two,

`0 <= X_d:=e(P_2) <= 4(1-1/d) < 4`.

This elementary bound is useful because it converts the expectation endpoint into an exact finite dyadic tail budget without any integrability assumptions.

# 5. New exact dyadic-tail equivalence for the angular endpoint

## `P26-T4-JORDAN-DYADIC-TAIL-15` — PROVED

Let

`X_d=e(P_2)`

under the actual adaptive rank-two residual-plane law, and let

`e_2=E X_d`.

By Section 4, `0<=X_d<4`.

Set

`K_d=floor(log_2(4d))`

so

`2^K_d/d <= 4 < 2^(K_d+1)/d`.

Define the weighted tail sum

`S_d=sum_{k=0}^{K_d} 2^k P{X_d>2^k/d}`.

Then

`(S_d-1)/(2d) <= e_2 <= (1+S_d)/d`.      (5.1)

### 5.1 Upper bound

Use the layer-cake identity

`e_2=int_0^4 P{X_d>t} dt`.

The interval `[0,1/d]` contributes at most `1/d`.

For `0<=k<K_d`, monotonicity of the tail gives

`int_{2^k/d}^{2^(k+1)/d} P{X_d>t} dt
 <= (2^k/d) P{X_d>2^k/d}`.

The final interval has length

`4-2^K_d/d < 2^K_d/d`,

so it contributes at most

`(2^K_d/d) P{X_d>2^K_d/d}`.

Summing gives

`e_2 <= (1+S_d)/d`.

### 5.2 Lower bound

Again by monotonicity, for `0<=k<K_d`,

`int_{2^k/d}^{2^(k+1)/d} P{X_d>t} dt
 >= (2^k/d) P{X_d>2^(k+1)/d}`.

Therefore

`e_2
 >= (1/d) sum_{k=0}^{K_d-1} 2^k P{X_d>2^(k+1)/d}`

` = (1/(2d)) sum_{j=1}^{K_d} 2^j P{X_d>2^j/d}`

` >= (S_d-1)/(2d)`,

because the omitted `k=0` term in `S_d` is at most one.

This proves (5.1).

### 5.3 Exact consequence

The immediate angular endpoint is equivalent to

`e_2=O(1/d)  iff  S_d=O(1)`.

Thus one does not need full Grassmannian convergence or a total-variation Haar theorem. But a merely qualitative statement such as

`P{X_d>epsilon}->0` for every fixed `epsilon>0`

would still be too weak: it does not control the weighted tail cascade at thresholds `2^k/d` as `k` ranges over order `log d` scales.

This identifies a concrete positive target for future runs:

`sum_{k<=log_2(4d)} 2^k P{e(P_2)>2^k/d}=O(1)`.

No cancellation can hide inside this formulation.

# 6. New theorem: generic fractional de-selection necessarily loses the `1/d` rate

## `P26-T4-FRACTIONAL-RATE-LOSS-15` — PROVED

Let `Q` and `mu` be probability measures with

`dmu=L dQ`,

`E_Q L=1`,

and for some `p>1`,

`||L||_{L^p(Q)}<=M`.

Let

`q=p/(p-1)`,

`theta=1/q=(p-1)/p`.

For every measurable `F` satisfying `0<=F<=B`,

`E_mu F <= M B^(1/p) (E_Q F)^theta`.      (6.1)

### Proof

Holder gives

`E_mu F=E_Q[L F] <= ||L||_p ||F||_q`.

Since `0<=F<=B`,

`F^q <= B^(q-1) F`.

Hence

`||F||_q
 <= B^((q-1)/q) (E_Q F)^(1/q)
 = B^(1/p) (E_Q F)^theta`.

Substitution proves (6.1).

## `P26-T4-GENERIC-DESELECTION-RATE-NOGO-15` — PROVED / sharp route certificate

The power `theta=(p-1)/p` in (6.1) cannot be improved from an `L^p` likelihood bound alone.

### Two-point construction

Fix `0<delta<=1/2` and let `Q(E)=delta` on a two-point probability space. Set `a=1/2` and define

`L=a delta^(-1/p)` on `E`,

and

`L=b_delta=(1-a delta^theta)/(1-delta)` on `E^c`.

Then `L>=0` and `E_Q L=1`.

Also

`E_Q L^p
 = a^p + (1-delta) b_delta^p`.

For `delta<=1/2`, `b_delta<=2`, so `||L||_p` is bounded by a constant depending only on `p`, uniformly as `delta->0`.

Take

`F=B 1_E`.

Then

`E_Q F=B delta`,

while

`E_mu F=E_Q[L F]=a B delta^theta`.

Thus the exponent `theta` is attained, up to a fixed constant, by a family with uniformly bounded `L^p` norm. No better generic power transfer can follow from the likelihood moment alone.

### Application to the current harmonic de-selection theorem

P04/P26 give a dimension-free fixed-rank likelihood bound for every

`1<p<5/4`.

Therefore generic Holder transfer has exponent only

`theta=(p-1)/p<1/5`.

If a bounded selected final-row observable had expectation `O(d^-1)`, this information alone would imply at best

`O(d^-theta)`,

with `theta<1/5`, not `O(d^-1)`.

Even if one could make the likelihood bound dimension-free for every

`p<3/2`,

the generic exponent would remain only

`theta<1/3`.

Hence merely enlarging the fractional moment window toward the exact `3/2` integrability threshold cannot, by itself, preserve the rate required by the Jordan endpoint.

### Crucial qualification: the base-plane marginal is unchanged

This no-go must not be overapplied.

P23's exact determinant de-selection theorem says that multiplying by the inverse determinant likelihood makes the final `q` rows fresh and independent of the residual plane **while leaving the residual-plane/base marginal unchanged**.

Therefore, for a base-only observable `G(P)`, one has exactly

`E_selected G(P)=E_deselected G(P)`.

In particular, `X_d=e(P_2)` itself suffers **no** Holder rate loss under exact de-selection.

The route obstruction proved here is narrower and more useful: if one introduces a generic final-row witness `F(P,U,V)` and tries to transfer its `O(1/d)` selected expectation using only an `L^p` likelihood estimate, the required rate is generically lost. A successful final-row representation must therefore preserve additional algebraic cancellation, or one must attack the base-plane defect/tails directly.

### Independent factorization

Split the full determinant-square-tilted harmonic matrix into a base block and final `q` rows. Conditional on the base, the determinant square factors as

`det(base Gram) * det K`,

where `K` is the Gram matrix of the final `q` rows projected to the residual `q`-plane.

For every deterministic residual `q`-plane, isotropy gives

`E_fresh det K=q!`.

Therefore integrating the final rows from the original selected law multiplies the base density by the constant `q!`, independent of the base plane. The base marginal is consequently proportional only to the original base determinant factor.

Multiplying the selected joint density by

`q!/(det K)`

cancels the final determinant factor. Conditional on the base, the final rows become iid fresh rows, and integrating them again contributes one. The base marginal is exactly the same as before.

Thus every integrable base-only observable has identical expectation before and after exact de-selection, while the final rows have been made fresh. This verifies P23's claim and justifies the qualification in Section 6.

# 9. Route implications and failed-route ledger

## 9.1 What is newly ruled out

A tempting next step after obtaining `L^p` likelihood control is:

1. prove an `O(1/d)` estimate for some bounded selected final-row witness;
2. de-select by Holder;
