## 3. Exact outside-source statement

The source is:

Takahiro Hasebe, Yuki Ueda and Jiun-Chau Wang, *Log-unimodality for free positive multiplicative Brownian motion*, arXiv:2009.13848 (submitted 2020), journal version *Colloquium Mathematicum* 169 (2022), 209–226, Problem 4.11.

The relevant source notion is **free multiplicative strong log-unimodality**. For a probability law \(\mu\) on \((0,\infty)\), strong log-unimodality asks whether

\[
\mu\boxtimes\nu
\]

is log-unimodal for every log-unimodal \(\nu\).

Source Problem 4.11 asks, in substance, whether the free positive multiplicative Brownian law \(\sigma_t\) fails this strong property for **every** \(t>0\).

The source's own Theorem 4.9 proves only a small-time failure statement; it does not itself cover all \(t>0\). Thus a source-matching proof must produce, for each \(t>0\), a log-unimodal witness \(\nu_t\) such that

\[
\sigma_t\boxtimes\nu_t
\]

is not log-unimodal.

The key source criterion is Lemma 4.1. For fixed \(t>0\), if \(\sigma_t\boxtimes\nu\) is log-unimodal, then for every

\[
a\in(0,1/t)
\]

the source level equation

\[
\frac{r}{c_{a\pi t}}
\frac{d(\lambda_{a\pi t}\circledast\nu^{-1})}{dr}(r)
=
\frac{a\pi}{\sin(a\pi t)}
\tag{3.1}
\]

has at most two positive solutions \(r\). Here \(\circledast\) denotes classical multiplicative convolution and

\[
\lambda_b(dr)
=
\frac{c_b}{1-2r\cos b+r^2}\,dr,
\qquad
c_b=\frac{\sin b}{\pi-b},
\qquad 0<b<\pi.
\tag{3.2}
\]

Therefore a source-literal counterexample can be certified by producing one admissible \(a\) for which (3.1) has four positive roots.

## 5. Independent derivation of the C007 witness profile

Fix

\[
0<b<\pi.
\]

From (3.2), pass to logarithmic coordinates \(r=e^x\). Because \(dr=e^x dx\), the log-density of \(\lambda_b\) is

\[
h_b(x)
=
\frac{c_b e^x}{1-2e^x\cos b+e^{2x}}.
\]

Using

\[
1-2e^x\cos b+e^{2x}
=2e^x(\cosh x-\cos b),
\]
we get exactly

\[
\boxed{
 h_b(x)=\frac{c_b}{2(\cosh x-\cos b)}.
}
\tag{5.1}
\]

Set

\[
A_b=\frac{\pi}{\pi-b}
\tag{5.2}
\]

and define the normalized kernel

\[
K_b(v)
:=
\frac{b}{A_b}h_b(bv).
\]

Since

\[
\frac{1}{A_b}c_b
=
\frac{\pi-b}{\pi}\frac{\sin b}{\pi-b}
=
\frac{\sin b}{\pi},
\]
we obtain

\[
\boxed{
K_b(v)
=
\frac{b\sin b}{2\pi(\cosh(bv)-\cos b)}.
}
\tag{5.3}
\]

Now fix parameters

\[
\ell>0,
\qquad p\in[0,1].
\]

Define the witness on the logarithmic line by

\[
\boxed{
\log_*\nu_{b,p,\ell}
=
p\,\delta_0
+
\frac{1-p}{\ell b}
\mathbf 1_{[-\ell b,0]}(y)\,dy.
}
\tag{5.4}
\]

This is a probability measure. Its absolutely continuous density is zero on \(( -\infty,-\ell b)\), constant on \([-\ell b,0]\), and zero on \((0,\infty)\), with its only atom at the endpoint \(0\). Thus the distribution is unimodal on the logarithmic line with mode \(0\). Hence \(\nu_{b,p,\ell}\) is log-unimodal on \((0,\infty)\), with multiplicative mode \(1\).

Under inversion, \(\log_*\nu^{-1}\) is

\[
p\,\delta_0
+
\frac{1-p}{\ell b}\mathbf 1_{[0,\ell b]}(u)\,du.
\tag{5.5}
\]

Classical multiplicative convolution becomes ordinary additive convolution after the logarithm. Therefore the log-density \(q\) of

\[
\lambda_b\circledast\nu^{-1}
\]

is

\[
q(x)
=
p h_b(x)
+
\frac{1-p}{\ell b}
\int_0^{\ell b}h_b(x-u)\,du.
\tag{5.6}
\]

Evaluate at \(x=by\) and substitute \(u=bs\):

\[
q(by)
=
p h_b(by)
+
\frac{1-p}{\ell}
\int_0^{\ell}h_b(b(y-s))\,ds.
\]

Multiply by \(b/A_b\). With \(v=y-s\),

\[
\boxed{
S(y)
:=
\frac{b}{A_b}q(by)
=
pK_b(y)
+
\frac{1-p}{\ell}
\int_{y-\ell}^{y}K_b(v)\,dv.
}
\tag{5.7}
\]

This is the exact normalized profile used below.

## 7. Kernel monotonicity in b

R18 requires a comparison of \(K_b\) to a fixed kernel at \(B=1/10\) and to the \(b\downarrow0\) limit. I independently rederive it.

Write

\[
K_b(v)=\frac{1}{2\pi G_v(b)},
\qquad
G_v(b)
=
\frac{\cosh(bv)-\cos b}{b\sin b}.
\tag{7.1}
\]

Split

\[
G_v(b)
=
\frac{\cosh(bv)-1}{b^2}\frac b{\sin b}
+
\frac{1-\cos b}{b\sin b}.
\]

Using

\[
\frac{1-\cos b}{\sin b}=	an\frac b2,
\]
this is

\[
\boxed{
G_v(b)
=
\frac{\cosh(bv)-1}{b^2}\frac b{\sin b}
+
\frac{\tan(b/2)}b.
}
\tag{7.2}
\]

For fixed \(v\), the first factor can be written

\[
\frac{\cosh(bv)-1}{b^2}
=
v^2\frac{\cosh(bv)-1}{(bv)^2},
\]
with the continuous value \(v^2/2\) at \(v=0\). The function

\[
\phi(x)=\frac{\cosh x-1}{x^2}
\]
for \(x>0\) has derivative

\[
\phi'(x)
=
\frac{x\sinh x-2(\cosh x-1)}{x^3}.
\]
Let

\[
g(x)=x\sinh x-2(\cosh x-1).
\]
Then

\[
g'(x)=x\cosh x-\sinh x,
\qquad
 g''(x)=x\sinh x\ge0,
\]
and \(g(0)=g'(0)=0\). Hence \(g(x)\ge0\), so \(\phi\) is nondecreasing for \(x\ge0\). Since \(\phi\) is even, \(\phi(bv)\) is nondecreasing in \(b>0\) for either sign of \(v\).

Next,

\[
\left(\frac b{\sin b}\right)'
=
\frac{\sin b-b\cos b}{\sin^2 b}.
\]
The numerator vanishes at zero and has derivative \(b\sin b>0\) on \((0,\pi)\), so \(b/\sin b\) is increasing.

Finally, with \(x=b/2\), \(\tan x/x\) is increasing on \((0,\pi/2)\): the numerator of its derivative is

\[
x\sec^2x-\tan x,
\]
whose derivative is \(2x\sec^2x\tan x>0\) and which vanishes at zero. Therefore \(\tan(b/2)/b\) is increasing.

Every term in (7.2) is therefore nondecreasing in \(b\), so \(G_v(b)\) is nondecreasing and

\[
\boxed{0<b_1<b_2<\pi\implies K_{b_1}(v)\ge K_{b_2}(v).}
\tag{7.3}
\]

The small-\(b\) limit follows by Taylor expansion:

\[
\sin b\sim b,
\quad
\cosh(bv)-\cos b
\sim\frac{b^2(v^2+1)}2.
\]
Hence

\[
\boxed{
K_0(v):=\lim_{b\downarrow0}K_b(v)
=
\frac1{\pi(1+v^2)}.
}
\tag{7.4}
\]

Therefore

\[
\boxed{K_b(v)\le K_0(v).}
\tag{7.5}
\]

No sign issue occurs for negative \(v\): the kernel is even in \(v\), and the monotonicity argument depends only on \(|v|\).
