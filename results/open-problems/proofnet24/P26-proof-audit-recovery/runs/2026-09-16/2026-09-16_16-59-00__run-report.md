## 3. Weak metric duality: independently rederived

Let `G=(V,E)` be any finite reversible chain with stationary law `pi` and unoriented edge conductances

\[
c_{xy}=\pi_xP(x,y)=\pi_yP(y,x).
\]

A feasible all-pairs flow may be decomposed by source: for each `a`, let `f^a` route demand from `a` to destination law `pi`, so its divergence is

\[
\operatorname{div} f^a(v)=\delta_a(v)-\pi(v).
\]

Let nonnegative edge lengths `ell_e` satisfy

\[
\sum_{e\in E}c_e\ell_e\le1.
\]

For fixed source `a`, define the 1-Lipschitz potential in the `ell`-metric

\[
\phi_a(v)=-d_\ell(a,v).
\]

Then for each edge `e={x,y}`,

\[
|\phi_a(x)-\phi_a(y)|\le\ell_e.
\]

Summation by parts against the divergence gives

\[
\sum_e f^a(e)\bigl(\phi_a(x_e)-\phi_a(y_e)\bigr)
=
\sum_v\phi_a(v)(\delta_a(v)-\pi(v))
=
\sum_v\pi(v)d_\ell(a,v),
\]

because `phi_a(a)=0`. Taking absolute values edgewise yields

\[
\sum_v\pi(v)d_\ell(a,v)
\le
\sum_e |f^a(e)|\ell_e.
\]

Multiply by `pi(a)` and sum in `a`. If the normalized edge congestion of the original flow is `psi(f)`, then its total absolute routed mass through edge `e` is at most `psi(f)c_e`. Hence

\[
\sum_{a,b}\pi(a)\pi(b)d_\ell(a,b)
\le
\psi(f)\sum_ec_e\ell_e
\le\psi(f).
\]

Taking the infimum over feasible flows gives the weak dual bound used by C31:

\[
F(G)\ge \sum_{a,b}\pi(a)\pi(b)d_\ell(a,b).
\tag{3.1}
\]

This argument needs only weak duality; it does not assume equality with the LP dual.

Verdict on this dependency: **PASS**.

## 4. Cone construction and exact stationary normalization

Fix integer `s>=4`, set

\[
d=s^2,\qquad r=s,
\]

and choose a connected `d`-regular bipartite Ramanujan graph `H` of sufficiently large order `n`. Form the cone

\[
G=K_1\vee H
\]

with hub `h`.

The cone has `n` spokes and `nd/2` base edges, hence

\[
|E(G)|=\frac{n(d+2)}2.
\]

For simple random walk, every unoriented edge has conductance

\[
c_e=\frac1{2|E(G)|}=\frac1{n(d+2)}.
\]

The hub has degree `n`, each base vertex degree `d+1`, so

\[
\pi_h=\frac1{d+2},\qquad
\pi_v=\frac{d+1}{n(d+2)}\quad(v\in H),
\]

and the total stationary mass on the base is

\[
M_H:=\pi(H)=\frac{d+1}{d+2}.
\]

Verdict: **PASS**.

## 5. Exact dual length budget and cone distances

Assign every spoke length

\[
x:=\frac{r(d+2)}{d+r}
\]

and every base edge length

\[
y:=\frac{2(d+2)}{d+r}.
\]

Then

\[
2x=ry.
\]

The budget is exact:

\[
\sum_ec_e\ell_e
=
\frac{nx+(nd/2)y}{n(d+2)}
=
\frac{x+(d/2)y}{d+2}
=1.
\]

For a base vertex `v`, `d_ell(h,v)=x`. For base vertices `u,v`, a base path of `k` edges costs `ky`; the two-spoke route through the hub costs `2x=ry`. Therefore

\[
d_\ell(u,v)=y\min\{d_H(u,v),r\}.
\tag{5.1}
\]

No shorter mixed path exists: any path that uses the hub already pays the two spoke cost `2x`, and a hub-free path is a path in `H`.

Verdict: **PASS**.

## 6. Ball-growth lower bound

For a `d`-regular graph, the number of vertices within graph distance `<r` from a fixed vertex is at most

\[
B(d,r):=1+d\sum_{j=0}^{r-2}(d-1)^j.
\]

Choose the Ramanujan member with

\[
n\ge2B(d,r).
\]

For independent uniform base vertices `U,V`, conditioned on `U`, at most `B(d,r)` choices of `V` satisfy `d_H(U,V)<r`. Hence

\[
\Pr\{d_H(U,V)\ge r\}\ge\frac12
\]

and therefore

\[
\mathbb E\min\{d_H(U,V),r\}\ge\frac r2.
\tag{6.1}
\]

Verdict: **PASS**.

## 8. Cone spectrum and relaxation time

Let `A_H` have a base-mean-zero eigenvector `v` with eigenvalue `mu`. Extending `v` by zero at the hub gives a cone transition eigenvector with eigenvalue

\[
\frac{\mu}{d+1}.
\]

On the two-dimensional subspace constant on the base plus the hub coordinate, the transition matrix has eigenvalues

\[
1,\qquad -\frac1{d+1}.
\]

Since `H` is bipartite Ramanujan, every nontrivial adjacency eigenvalue satisfies

\[
|\mu|\le2\sqrt{d-1}.
\]

Thus

\[
\lambda_2(G)\le\frac{2\sqrt{d-1}}{d+1}
<\frac{2s}{s^2+1},
\]

using `d=s^2`. Consequently

\[
\tau_{\rm rel}(G)
=\frac1{1-\lambda_2(G)}
<
\frac1{1-2s/(s^2+1)}.
\tag{8.1}
\]

The external existence input is adequate: MSS gives an infinite 2-lift family for every degree `d>2`. Connectedness is compatible with the chosen family because a disconnected 2-lift of a connected `d`-regular base would create a new adjacency eigenvalue `d`, while the selected MSS new eigenvalues obey `|lambda_new|<=2sqrt(d-1)<d`; hence the selected iterated lifts remain connected. Their orders double, so a member satisfying `n>=2B(d,r)` exists.

Verdict: **PASS**.

Combining (7.1) and (8.1), with `d=s^2` and `r=s`, yields the strict lower bound

\[
\frac{F(G)}{\tau_{\rm rel}(G)D(G)}

\frac{(s-1)^2(s^2+3)}{2(s+1)(s^2+2)}.
\tag{9.1}

\[
L_s-\frac{s-3}{2}
