# 2. Exact rank-two de-selection setup

Let

`E = Sym_d^0`,

`m = (d-1)(d+2)/2`,

and define the normalized physical degree-two harmonic row

`h(u) = sqrt(d(d+2)/2) * (u u^T - I/d)`,

for `u` uniform on `S^(d-1)`.

Then

`||h(u)||_F^2 = m`

and

`E[h(U) tensor h(U)] = I_E`.

Fix any deterministic rank-two coefficient plane `P` with Frobenius-orthonormal basis `A_1,A_2`. Define

`f_i(u) = <A_i,h(u)>`,

`y(u) = (f_1(u),f_2(u))`,

and for independent `U,V`

`W_P(U,V) = det[y(U),y(V)]`

`           = f_1(U) f_2(V) - f_2(U) f_1(V)`.

Because `y(U)` is centered isotropic in `R^2`,

`E W_P(U,V)^2 = 2`.

The determinant-selected conditional law is therefore

`d Q_P = (W_P^2/2) d(mu x mu)`.

The squared inverse-wedge radius is

`R_P = 1/W_P^2`.

P23's exact de-selection density is

`L_P = d(mu x mu)/dQ_P = 2 R_P = 2/W_P^2`.

The problem addressed in this run is: how far above first moment can `R_P` or `L_P` be integrated uniformly over dimension and residual plane?

# 3. Primary-source hypothesis check for the anti-concentration input

The proof below uses the Carbery-Wright polynomial anti-concentration theorem.

Bibliographic metadata was checked for:

Anthony Carbery and James Wright, `Distributional and L^q norm inequalities for polynomials over convex bodies in R^n`, Mathematical Research Letters 8(3), 233-248 (2001).

The exact form needed here is the standard Theorem-8 restatement:

for a log-concave probability measure `mu` on `R^N`, every real polynomial `Q` of degree at most `k`, and every `a>0`,

`(int Q^2 dmu)^(1/(2k)) * mu{|Q|<=a} <= c k a^(1/k)`,

where `c` is absolute.

The standard Gaussian measure is log-concave. We use the theorem only for degree `k=2` and a quadratic polynomial whose `L^2` norm is computed exactly below.

The journal metadata and the exact theorem statement/hypotheses were cross-checked against independent published restatements. No stronger imported assertion is used.

# 4. Uniform negative moment for one physical quadratic harmonic

## `P26-T4-QUADRATIC-HARMONIC-NEGATIVE-MOMENT-14` — PROVED

Let `d>=2`. For every traceless symmetric `A` with

`||A||_F = 1`,

put

`Z_A(U) = <A,h(U)>`.

Then for every fixed

`0 < beta < 1/2`,

there is a finite constant `C_beta`, depending only on `beta`, such that

`sup_{d>=2} sup_A E |Z_A(U)|^(-beta) <= C_beta`.      (4.1)

### 4.1 Gaussian quadratic lift

Let `G~N(0,I_d)` and write

`G = R U`,

where `R=||G||` and `U` is uniform on the sphere, independent of `R`.

Define

`Q_A(G)=G^T A G`.

Since `tr A=0` and `||A||_F=1`, the exact Gaussian quadratic-form identity gives

`E Q_A(G)^2 = 2 tr(A^2) + (tr A)^2 = 2`.      (4.2)

Carbery-Wright with `k=2` therefore gives an absolute `C_0` such that

`P{|Q_A(G)|<=t} <= C_0 sqrt(t)`      (4.3)

for every `t>0`, uniformly in `d` and `A`.

### 4.2 Integrating the small-ball estimate

For `0<beta<1/2`, layer-cake gives

`E |Q_A|^(-beta)`

` = 1 + beta int_0^1 t^(-beta-1) P{|Q_A|<t} dt`

` <= 1 + C_0 beta int_0^1 t^(-beta-1/2) dt`

` = 1 + C_0 beta/(1/2-beta)`.

Write the resulting dimension-free bound as

`K_beta = 1 + C_0 beta/(1/2-beta)`.      (4.4)

### 4.3 Returning to the sphere

Put

`c_d = sqrt(d(d+2)/2)`.

Because `tr A=0`,

`Z_A(U) = c_d U^T A U`.

Hence

`Q_A(G) = (R^2/c_d) Z_A(U)`.

By independence of `R` and `U`,

`E |Q_A|^(-beta)`

` = c_d^beta E R^(-2beta) E |Z_A(U)|^(-beta)`.      (4.5)

Since `x -> x^(-beta)` is convex on `(0,infinity)` and `E R^2=d`,

`E R^(-2beta) = E (R^2)^(-beta) >= d^(-beta)`.      (4.6)

Also

`c_d/d = sqrt((d+2)/(2d)) >= 1/sqrt(2)`.

Combining (4.4)-(4.6),

`E |Z_A(U)|^(-beta) <= 2^(beta/2) K_beta`.      (4.7)

This proves (4.1).

### Scope

The exponent `1/2` arises from degree-two polynomial anti-concentration. The theorem does not assert finiteness at `beta=1/2`, and no claim of sharpness for every physical harmonic matrix `A` is needed here.

# 5. Uniform negative moment for the rank-two determinant

## `P26-T4-RANK2-WEDGE-NEGATIVE-MOMENT-14` — PROVED

For every fixed `0<beta<1/2`, there is `C'_beta<infinity` such that

`sup_{d>=2} sup_{rank(P)=2} E |W_P(U,V)|^(-beta) <= C'_beta`.      (5.1)

### Proof

Fix `u` with `y(u) != 0`. Define

`A_u = [f_1(u) A_2 - f_2(u) A_1] / ||y(u)||`.

Because `A_1,A_2` are Frobenius orthonormal,

`||A_u||_F=1`,

and `A_u` is traceless symmetric. Moreover

`W_P(u,V) = ||y(u)|| <A_u,h(V)>`.      (5.2)

The exceptional set `y(u)=0` has spherical measure zero: already `f_1` is a nonzero real polynomial on the sphere, so its zero set has measure zero.

Conditioning on `U=u` and applying Section 4,

`E_V[|W_P(u,V)|^(-beta)]`

` <= C_beta ||y(u)||^(-beta)`.      (5.3)

Since

`||y(u)|| >= |f_1(u)|`,

another application of Section 4 gives

`E ||y(U)||^(-beta)`

` <= E |f_1(U)|^(-beta)`

` <= C_beta`.      (5.4)

Integrating (5.3) and using (5.4),

`E |W_P(U,V)|^(-beta) <= C_beta^2`.      (5.5)

This proves (5.1), uniformly in both dimension and deterministic rank-two plane.

# 6. Fractional L^p theorem for exact de-selection

## `P26-T4-DESELECTION-FRACTIONAL-LP-14` — PROVED

For every fixed

`1 < alpha < 5/4`,

there is `M_alpha<infinity` such that for every dimension and every deterministic harmonic rank-two residual plane,

`E_{Q_P} R_P^alpha <= M_alpha`,      (6.1)

and

`E_{Q_P} L_P^alpha <= 2^alpha M_alpha`.      (6.2)

The constants are uniform in `d` and `P`.

### Proof

By definition

`dQ_P = (W_P^2/2) d(mu x mu)`

and

`R_P = 1/W_P^2`.

Therefore

`E_{Q_P} R_P^alpha`

` = (1/2) E_{mu x mu} |W_P|^(2-2alpha)`

` = (1/2) E_{mu x mu} |W_P|^(-2(alpha-1))`.      (6.3)

Set

`beta = 2(alpha-1)`.

The condition `alpha<5/4` is exactly `beta<1/2`, so Section 5 applies and proves (6.1). Since `L_P=2R_P`, (6.2) follows.

Because the bound is uniform in deterministic `P`, conditioning and then averaging also gives the same fractional-moment estimate for the actual random adaptive rank-two residual plane under the full determinant-tilted harmonic law.

P20 had first-moment/concavity control through `alpha<=1`. This theorem strictly enlarges the controlled range to every `alpha<5/4`.

P04 proves that for every fixed residual plane,

`E_Q R_P^alpha = infinity`

for every `alpha>=3/2`.

Therefore the only unresolved moment interval is now

`5/4 <= alpha < 3/2`.      (6.4)

No claim is made inside that gap.

# 7. Quantitative bounded/truncated de-selection

## `P26-T4-TRUNCATED-DESELECTION-14` — PROVED

Fix any

`0 < eta < 1/4`.

Let

`alpha=1+eta`.

By Section 6 there is a uniform finite `C_eta` such that

`E_Q L^(1+eta) <= C_eta`.      (7.1)

Consequently, for every `T>=1`,

`E_Q[L 1_{L>T}] <= C_eta T^(-eta)`.      (7.2)

Let `Phi` be any bounded measurable function of the selected final two rows and the residual plane, with

`||Phi||_infinity <= M`.

Since exact de-selection is `E_fresh Phi = E_Q[L Phi]`,

`|E_fresh Phi - E_Q[(L wedge T) Phi]|`

` <= M C_eta T^(-eta)`.      (7.3)

Define

`m_T = E_Q(L wedge T)`

and the normalized truncated law `Q_T` by

`dQ_T/dQ = (L wedge T)/m_T`.

Then

`1-m_T <= C_eta T^(-eta)`,

and a second triangle estimate gives

`|E_fresh Phi - E_{Q_T} Phi|`

` <= 2 M C_eta T^(-eta)`.      (7.4)

Thus bounded observables can be transferred from exact fresh final rows to a bounded-density truncation of the actual determinant-selected law with a dimension-free polynomial tail error.

### What this does and does not buy for `e_2`

For the P23 fresh-probe polynomial

`Phi(P,U,V) = F_P(U) K_2(U,V) F_P(V)`,

one has the crude pointwise bounds

`0<=F_P<=m`

and

`|K_2(U,V)|<=m`,

so

`|Phi|<=m^3`.

Since `m` is order `d^2`, the naive sup norm is order `d^6`. If one takes `T=d^B`, then (7.3) gives a transfer error bounded by order

`d^(6-B eta)`.

Thus any `B eta>7` would make the naive truncation error `o(1/d)`.

This observation is only a scale calculation. It does not control the selected truncated expectation. P23 already proves that the untruncated bare polynomial expansion is circular. The remaining useful theorem must estimate the selected truncated Jordan/projective covariance by exploiting the actual harmonic law.

Claim: `P04-T4-INVERSE-WEDGE-THREEHALF-DIVERGENCE-46`.
Verdict: PASS.

### Independent derivation

Let `P` be a deterministic rank-`q` plane in `Sym_d^0` with orthonormal basis `A_1,...,A_q`. Let

`y_P(u)=(<A_1,h(u)>,...,<A_q,h(u)>)`

and let

`W_P(u_1,...,u_q)=det[y_P(u_1),...,y_P(u_q)]`.

The coherent harmonic orbit spans `Sym_d^0`: if a traceless symmetric matrix `A` is orthogonal to `h(u)` for every unit `u`, then `u^T A u=0` for every unit `u`, hence `A=0`.

Therefore the evaluation vectors span `R^q`. Choose `u_1^0,...,u_{q-1}^0` so their evaluation vectors are linearly independent. Let `c` be a nonzero vector orthogonal to their span and put

`A_c=sum_a c_a A_a`.

Then `A_c` is a nonzero traceless symmetric matrix. Hence it has a positive eigenvalue `lambda_+` and a negative eigenvalue `lambda_-`. With corresponding unit eigenvectors `e_+,e_-`, choose a unit vector `u_0` in their span so that

`u_0^T A_c u_0=0`.

Because both coefficients are nonzero and both eigenvalues are nonzero on the chosen two-dimensional spectral subspace,

`A_c u_0 != 0`.

Freeze the first `q-1` determinant columns at `u_i^0`. The determinant as a function of the last sphere variable is a nonzero constant multiple of

`g(u)=<A_c,h(u)> = c_d u^T A_c u`.

At `u_0`, `g(u_0)=0`, while the spherical tangent gradient is

`grad_S g(u_0)=2 c_d A_c u_0 != 0`,

because the radial correction is proportional to `u_0^T A_c u_0=0`.

Thus the full determinant `W_P` has a regular zero. By the implicit function theorem there are local coordinates `(t,z)` with

`t=W_P`

and product-spherical measure comparable to Lebesgue measure.

Under determinant selection,

`E_Q R^alpha = (1/q!) int |W_P|^(2(1-alpha)) dmu^q`.

At a regular zero this contains the one-dimensional integral

`int_{-eps}^{eps} |t|^(-2(alpha-1)) dt`,

which diverges exactly when

`2(alpha-1)>=1`,

i.e. `alpha>=3/2`.

This independently verifies the P04 claim. It is a narrow audit of that theorem, not a complete audit of Target 4.
