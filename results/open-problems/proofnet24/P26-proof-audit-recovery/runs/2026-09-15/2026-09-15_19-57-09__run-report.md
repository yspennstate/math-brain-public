Let the harmonic row be `h(u) in E`, normalized by

`integral h(u) tensor h(u) dmu(u) = I_E`.

For a rank-`s` residual projector `P`, define

`F_P(u) = ||P h(u)||^2`.

# 4. `P26-T4-COMMUTATOR-REVERSE-MARTINGALE-09`

## Statement

For the actual harmonic deletion chain,

`E[delta(P_{s-1}) | P_s] = ((s-2)/s) delta(P_s)`.

Consequently

`delta(P_s) / [s(s-1)]`

is an exact reverse martingale, and

`E delta(P_s) = d s(s-1) / [2(m-1)]`.

## Proof

Fix a rank-`s` projector `P` and a selected unit line `N`. Complete `N` to an orthonormal basis of `Ran(P)`:

`N, B_1,...,B_{s-1}`.

After deletion,

`P' = P - N tensor N`

has basis `B_1,...,B_{s-1}`. Split the commutator energy into retained-retained and selected-retained pairs. Pointwise,

`delta(P) = delta(P') + kappa_P(N)`,

where

`kappa_P(N) = sum_{i=1}^{s-1} ||[N,B_i]||_F^2`.

This is quadratic in `N`. Using the exact conditional covariance `E[N tensor N | P]=P/s`,

`E[kappa_P(N) | P]`

`= (1/s) sum_{j=1}^s sum_{a=1}^s ||[A_j,A_a]||_F^2`

`= (2/s) delta(P)`.

Therefore

`E[delta(P') | P]`

`= delta(P) - (2/s) delta(P)`

`= ((s-2)/s) delta(P)`.

Dividing by `(s-1)(s-2)` gives

`E[ delta(P_{s-1}) / ((s-1)(s-2)) | P_s ]`

`= delta(P_s)/[s(s-1)]`.

So the normalized commutator energy is an exact reverse martingale.

## Full-rank anchor

Let `T_1,...,T_m` be a Frobenius-orthonormal basis of `E`. The corrected traceless-symmetric completeness identity is

`sum_mu T_mu X T_mu = ((d-2)/(2d)) X + (1/2) tr(X) I`.

For traceless unit `N`,

`sum_mu tr(N T_mu N T_mu) = (d-2)/(2d)`.

Also isotropy gives

`sum_mu T_mu^2 = (m/d) I`.

Hence

`sum_mu ||[N,T_mu]||_F^2`

`= 2 sum_mu tr(N^2 T_mu^2) - 2 sum_mu tr(N T_mu N T_mu)`

`= 2m/d - (d-2)/d`

`= d`.

Therefore at full rank

`delta(I_E)`

`= (1/2) sum_a sum_b ||[T_a,T_b]||_F^2`

`= (1/2) m d`.

The reverse-martingale expectation is therefore

`E delta(P_s) / [s(s-1)]`

`= delta(I_E)/[m(m-1)]`

`= d/[2(m-1)]`,

or

`boxed: E delta(P_s) = d s(s-1)/[2(m-1)]`.

This shows that the entire expected commutator/alternating sector follows the Haar benchmark exactly at every residual rank.

# 6. `P26-T4-FOURTHMARK-INNOVATION-IDENTITY-09`

The earlier P26 deletion theorem gives

`E[H(Q) | P] = H(P)/s`.

Define the conditional Hilbert-space innovation

`W(P) = E[ || H(Q) - H(P)/s ||_2^2 | P ]`.

`W(P)`

`= E[||H(Q)||_2^2 | P] - ||E[H(Q)|P]||_2^2`.

This identity is useful because the fourth mark itself contains a benchmark floor, whereas `W(P)` is a genuine nonnegative innovation. It is exactly the symmetric degree-two component which remains after the predictable part of the selected line is removed.

# 7. `P26-T4-CHI2-DOOB-DECOMPOSITION-09`

## Statement

For each residual rank `s >= 3`,

`E[chi(P_{s-1}) | P_s] - chi(P_s)`

`= 2 alpha_d / [s^2 (s-1)^2]`

`  * { s(s-1) + 2 delta(P_s) + 6[s^2 gamma(P_s)-e(P_s)] }`

and therefore, using the innovation identity,

`boxed:`

`E[chi(P_{s-1}) | P_s] - chi(P_s)`

`= 2 alpha_d / [s^2 (s-1)^2]`

`  * { s(s-1) + 2 delta(P_s) + (6 s^2 / beta_d) W(P_s) }`.

Every term is nonnegative, so `chi(P_s)` is a strict reverse submartingale under deletion. In particular,

`E[chi(P_{s-1}) | P_s]`

`>= chi(P_s) + 2 alpha_d/[s(s-1)]`.

## Algebra

The exact static identity is

`chi(P) = alpha_d[(s+2)/s + 12/d + (12e-4delta)/s^2] - 1`.

For `P'=P_{s-1}`, use the recurrences

`E e'|P = ((s-2)/s)e + gamma`

and

`E delta'|P = ((s-2)/s)delta`.

The rank-only contribution is

`(s+1)/(s-1) - (s+2)/s`

`= 2/[s(s-1)]`.

The symmetric `e/gamma` contribution is

`12{ [((s-2)/s)e + gamma]/(s-1)^2 - e/s^2 }`.

Putting over the common denominator `s^2(s-1)^2`, the coefficient of `e` is

`s(s-2) - (s-1)^2 = -1`.

Thus this contribution equals

`12[s^2 gamma - e]/[s^2(s-1)^2]`.

The commutator contribution is

`-4[((s-2)/s)delta]/(s-1)^2 + 4delta/s^2`.

Again over `s^2(s-1)^2`, its numerator is

`-4s(s-2)delta + 4(s-1)^2 delta = 4delta`.

Therefore

`E chi' - chi`

`= alpha_d { 2/[s(s-1)]`

`+ 12[s^2 gamma-e]/[s^2(s-1)^2]`

`+ 4delta/[s^2(s-1)^2] }`,

which factors exactly as claimed.

The decomposition has a direct interpretation:

- `s(s-1)` is the unavoidable deterministic rank-loss floor;
- `2 delta(P)` is the alternating / commutator sector;
- `(6s^2/beta_d) W(P)` is the symmetric physical degree-two innovation.

No cancellation between these terms is needed or available: all three are nonnegative.

# 9. `P26-T4-CHI2-PATH-DECOMPOSITION-09`

Start at full rank. Since the full harmonic frame density is uniform,

The deterministic term contributes

`2 alpha_d sum_{s=3}^m 1/[s(s-1)]`.

`sum_{s=3}^m 1/[s(s-1)] = 1/2 - 1/m`.

`alpha_d(1-2/m)`.

## 9.2 Alternating / commutator contribution

The expected commutator drift is

`4 alpha_d E delta(P_s)/[s^2(s-1)^2]`.

`alpha_d d/(m-1) * (1-2/m)`.

`alpha_d(1-2/m)(1+d/(m-1))`.

`boxed: B_{d,2} = d(d-2)(d+3)/[(d+6)(d^2+d-4)]`.
