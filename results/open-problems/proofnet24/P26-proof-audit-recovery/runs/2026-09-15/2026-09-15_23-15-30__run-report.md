# 3. Independent leave-two-out derivation

Let H be written as two fresh rows plus a frozen base:

H = [ X_1^T ; X_2^T ; B ],

where H has size (m+1) by m and B has size (m-1) by m.

Assume almost surely:

rank(H)=m,
rank(B)=m-1,
and the fresh normal coordinates defined below are nonzero.

Freeze B. Let q be a unit vector spanning ker(B), and put

P = I - q q^T.

Define

L = (B B^T)^(-1) B.

Then

B^T L = P,
L q = 0.

For one fresh row X define

x = q^T X,
s = 1/x,
a = L X / x,
A0 = s^2 + ||a||^2.

For X_i write x_i, s_i, a_i, A_i.

## 3.1 Exact null vector

Consider the row-index vector

c = ( s_1, -s_2, -(a_1-a_2) ).

Here the last block has length m-1.

Compute

H^T c = s_1 X_1 - s_2 X_2 - B^T(a_1-a_2).

Because

B^T a_i = B^T L X_i / x_i = P X_i / x_i = P(s_i X_i),

we get

H^T c = (I-P)(s_1 X_1 - s_2 X_2).

Since I-P = q q^T and

q^T(s_1 X_1 - s_2 X_2) = 1 - 1 = 0,

we obtain

H^T c = 0.

The left nullspace is one-dimensional, so its orthogonal projector is

K = c c^T / ||c||^2.

The squared norm is

D := ||c||^2
   = s_1^2 + s_2^2 + ||a_1-a_2||^2
   = A_1 + A_2 - 2 <a_1,a_2>.

Therefore

K_12 = - s_1 s_2 / D.                                    (3.1)

This independently recovers the exact P20 leave-two-out formula.

# 4. Laplace/tensor-square sign proof

The only delicate issue is integrability near x_i=q^T X_i=0. Formal expansion alone is not enough.

Since D>0,

1/D = integral from 0 to infinity of exp(-tD) dt.

Also

exp(-tD)
= exp[-t(A_1+A_2)] exp[2t<a_1,a_2>].

Expand the second factor:

exp[2t<a_1,a_2>]
= sum over k>=0 of (2t)^k/k! times <a_1,a_2>^k.

## 4.1 Absolute domination

The absolute value of the full series integrand is bounded by

|s_1 s_2| exp[-t(A_1+A_2)] exp[2t |<a_1,a_2>|].

Because

||a_1||^2 + ||a_2||^2 - 2|<a_1,a_2>| >= 0,

we have

A_1+A_2-2|<a_1,a_2>| >= s_1^2+s_2^2.

Hence

|s_1 s_2| exp[-t(A_1+A_2)] exp[2t |<a_1,a_2>|]
<= |s_1 s_2| exp[-t(s_1^2+s_2^2)].

Integrating gives

integral_0^infinity |s_1 s_2| exp[-t(s_1^2+s_2^2)] dt
= |s_1 s_2|/(s_1^2+s_2^2)
<= 1/2.                                                     (4.1)

This is a pointwise, uniform, integrable bound. It justifies the required series/integral/expectation interchange without any inverse moment assumption on q^T X.

## 4.2 Conditional iid factorization

For every fixed t>0 and k>=0, exponential damping makes the relevant tensor expectation finite. Conditional on B, X_1 and X_2 are iid. Therefore

E[ s_1 s_2 exp{-t(A_1+A_2)} <a_1,a_2>^k | B ]

is equal to

|| E_X[ s exp(-t A0) a^(tensor k) | B ] ||^2,

which is nonnegative.

Substitute this into (3.1). Absolute domination from (4.1) gives

E[K_12 | B]
= - integral_0^infinity sum_{k>=0} (2t)^k/k!
    || E_X[ s exp(-t A0) a^(tensor k) | B ] ||^2 dt
<= 0.                                                       (4.2)

Averaging over B yields

E K_12 <= 0.

Row exchangeability gives the same inequality for every off-diagonal pair.

## 4.3 Equality case under central row-sign symmetry

If X and -X have the same law, then

s -> -s,
a -> a,
A0 -> A0.

Every conditional tensor expectation in (4.2) is then zero. Hence

E K_ij = 0 for i != j.

This recovers the isotropic expected-projector benchmark for centrally sign-symmetric iid rows.

# 9. Route boundary: source sign does not close the Jordan sector

The new theorem lives in row-index space. The open e_2 quantity lives in the symmetric physical product sector of the coefficient-space deletion chain.

A self-contained invariant counter-benchmark shows why coefficient isotropy is not enough.

For d>=3 define the traceless Frobenius-unit matrix

D_d = diag( sqrt[(d-1)/d],
            -1/sqrt[d(d-1)], ...,
            -1/sqrt[d(d-1)] ).

Then

tr(D_d)=0,
||D_d||_F=1.

Let Q be Haar orthogonal and put

N = Q D_d Q^T.

The law is O(d)-conjugation invariant in Sym_d^0. Its coefficient covariance is isotropic:

E[N tensor N] = I/m,

because an O(d)-invariant bilinear form on the traceless symmetric representation is a scalar multiple of the Frobenius form, and the covariance trace equals E||N||_F^2=1.

tr(N^4)=tr(D_d^4)

Therefore first projector moments, coefficient isotropy, or static O(d)-invariance cannot by themselves prove the Jordan endpoint. A successful proof must use the actual adaptive volume-deletion transition or an equivalent coupled rank-three symmetric amplitude identity.
