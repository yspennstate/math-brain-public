## Exact setting for the ordinary-law source problem

Let

`m = (d-1)(d+2)/2`,

and let

`n = m+1 = d(d+1)/2`.

Let `h_1,...,h_n` be the normalized traceless quadratic harmonic feature rows in `R^m`, so

`E h_i = 0`,

`E h_i h_i^T = I_m`.

Put the full row matrix

`H = [h_1^T; ... ; h_n^T]`.

Write

`mu = n^-1 sum_i h_i`,

`C = sum_i (h_i-mu)(h_i-mu)^T`,

and

`q = mu^T C^-1 mu`.

For generic harmonic samples these matrices have the expected ranks almost surely; all deterministic identities below are stated on the full-rank event. The exceptional set is algebraic and has zero spherical product measure because the quadratic feature family spans its ambient harmonic space.

P20's target is

`d q -> infinity in probability`.

Equivalently, if `v` is the unit vector spanning `ker(H^T)` and `s = 1^T v`, then

`s^2 = n/(1+n q)`.

Thus the same target is `s = o_P(sqrt(d))`.

## `P26-T4-FRESH-FACET-HOTELLING-10` — PROVED

Delete the last row and write

`H_- = [h_1^T; ... ; h_m^T]`,

`mu_- = m^-1 sum_{i=1}^m h_i`,

`C_- = sum_{i=1}^m (h_i-mu_-)(h_i-mu_-)^T`.

Because there are `m` points in `R^m`, `C_-` has rank `m-1` generically. Let `w` be a unit vector spanning `ker(C_-)`.

Since `C_-` is a sum of positive rank-one matrices,

`(h_i-mu_-)^T w = 0` for every `i <= m`.

Hence all old rows have one common facet-normal coordinate

`a = mu_-^T w = h_i^T w` for `i <= m`.

Let `P_perp = I - w w^T` and define

`r = P_perp mu_-`.

Let `A` denote the restriction of `C_-` to `w^perp`; thus `A` is positive definite on the `(m-1)`-dimensional transverse space.

Now expose the genuinely fresh final row

`x = h_n`.

Write

`X = x^T w`,

`x_perp = P_perp x`,

`b = X-a`,

`z = x_perp-r`,

and

`c = m/n`.

The standard one-point centered-scatter update is exact:

`C = C_- + c (x-mu_-)(x-mu_-)^T`.

In the orthogonal decomposition `R w + w^perp`, this becomes

`C = [[c b^2, c b z^T], [c b z, A+c z z^T]]`.

Let

`G_- = H_-^T H_-`.

Then the following three determinant identities are exact:

1. `det(C) = c b^2 det(A)`.
2. `det(G_-) = m a^2 det(A)`.
3. If `L = x^T G_-^-1 x`, then `det(H^T H) = det(G_-)(1+L)`.

Proof of the first identity: put `t=z^T A^-1 z`. By the matrix determinant lemma,

`det(A+c z z^T) = det(A)(1+c t)`.

The Schur complement of that block is

`c b^2/(1+c t)`.

The factors cancel, giving `det(C)=c b^2 det(A)`.

Proof of the second identity: in the same decomposition,

`G_- = [[m a^2, m a r^T], [m a r, A+m r r^T]]`.

Applying the matrix determinant lemma and its Schur complement gives

`det(G_-) = m a^2 det(A)`.

For the full sample,

`H^T H = C + n mu mu^T`,

so the determinant lemma also gives

`det(H^T H) = det(C)(1+n q)`.

Equating the two factorizations of `det(H^T H)` gives the exact fresh-facet Hotelling identity

`1+n q = n a^2 (1+L) / b^2`,

or equivalently

`q + 1/n = a^2 (1+L)/(X-a)^2`.

This keeps the fresh scalar denominator and the inherited inverse leverage coupled exactly; no false independence has been introduced.

## Independent recovery of P20's null-vector formula

Let `v` be the unit vector spanning `ker(H^T)` and put `s=1^T v`.

Because `H_- w = a 1_m`, the full null relation projected onto `w` gives

`a(s-v_n) + X v_n = 0`.

Thus

`b v_n = -a s`,

so

`a^2/b^2 = v_n^2/s^2`.

Also the full row leverage of row `n` is

`x^T (H^T H)^-1 x = 1-v_n^2`.

Sherman-Morrison therefore gives

`L/(1+L)=1-v_n^2`,

hence

`1+L = 1/v_n^2`.

Substituting into the fresh-facet identity gives

`q+1/n = 1/s^2`,

that is

`s^2 = n/(1+n q)`.

This independently rederives the exact core of `P20-ORDINARY-ALIGNMENT-HOTELLING-48`.

For the full uncentered degree-at-most-two feature matrix `F`, whose trace direction is `e_0=I/sqrt(d)`, the same null relation gives

`F^T v = (s/sqrt(d)) e_0`.

Therefore

`F^-T e_0 = (sqrt(d)/s) v`,

and hence

`|s|/sqrt(d) = 1/||F^-T e_0||`.

So `P26-AUDIT-P20-ORDINARY-ALIGNMENT-10 = PASS`.

This is an audit of the exact linear-algebraic alignment certificate, not an audit or closure of P20's still-open lower-tail theorem.

## `P26-T4-FRESH-FACET-TRANSVERSE-10` — PROVED

Define

`u = r^T A^-1 r`.

Direct block inversion gives

`G_-^-1 = [[(1+m u)/(m a^2), -r^T A^-1/a], [-A^-1 r/a, A^-1]]`.

Consequently

`a^2 L = X^2/m + T`,

where the nonnegative transverse term is

`T = || A^-1/2 (a x_perp - X r) ||^2`.

Insert this into the fresh-facet identity. The scalar algebra

`(a^2 + X^2/m)/(X-a)^2 - 1/n`

simplifies exactly to

`(m a + X)^2 / [m n (X-a)^2]`.

Therefore

`q = S + R`,

with

`S = (m a + X)^2 / [m n (X-a)^2] >= 0`,

and

`R = || A^-1/2 (a x_perp - X r) ||^2 / (X-a)^2 >= 0`.

This is the exact fresh-facet normal/transverse decomposition.

The new point is not merely positivity. The scalar part is the entire contribution obtainable from the one-dimensional Cauchy estimate along the facet normal, while `R` is the genuinely transverse inverse-covariance debt.

## Exact conditional mean of the transverse numerator

Condition on the first `m` rows. The fresh harmonic row satisfies

`E_x X^2 = 1`,

`E_x x_perp x_perp^T = P_perp`,

`E_x[X x_perp]=0`.

Therefore

`E_x T = a^2 tr(A^-1) + r^T A^-1 r`.

The block inverse formula also gives

`a^2 tr(G_-^-1) = 1/m + a^2 tr(A^-1) + r^T A^-1 r`.

Hence if

`Theta = a^2 tr(G_-^-1) - 1/m`,

then

`Theta >= 0`

and

`E_x T = Theta`.

This isolates a new inherited facet-hardness statistic: the fresh row sees the square-sample inverse trace after removal of the trivial one-dimensional normal floor.

Equivalently, since `H_- w=a 1_m`,

`a^2 = 1 / [1_m^T (H_- H_-^T)^-1 1_m]`.

Thus

`a^2 tr(G_-^-1)`

is the inverse-trace mass divided by the inverse quadratic form in the deterministic all-ones row direction. The ordinary alignment problem is therefore sensitive to an inverse-isotropy ratio, not merely to the size of the sample mean.

## `P26-T4-MANY-FACET-TRANSVERSE-MASS-10` — PROVED

The previous decomposition can be performed after deleting any row `k` from the full `(m+1) x m` matrix.

For each `k`, let

`a_k, X_k, b_k, A_k, r_k, S_k, R_k`

be the corresponding quantities, with row `k` treated as the fresh row.

Then deterministically

`q = S_k + R_k`

for every `k`.

Let `v` be the unit full left-null vector and `s=1^T v` as above. The relation

`b_k v_k = -a_k s`

holds for every `k`.

Also

`m a_k + X_k = n a_k + b_k`.

Therefore

`(m a_k + X_k)/b_k = 1 - n v_k/s`.

The scalar sector is thus

`S_k = (s-n v_k)^2 / (m n s^2)`.

Summing over `k` and using

`sum_k v_k = s`,

`sum_k v_k^2 = 1`,

we obtain

`sum_k (s-n v_k)^2 = n(n-s^2)`.

Since

`q = (n-s^2)/(n s^2)`,

it follows exactly that

`(1/n) sum_k S_k = q/m`.

Therefore

`(1/n) sum_k R_k = ((m-1)/m) q`.

This is the strongest structural conclusion of the run.

For the full ordinary harmonic sample, the one-dimensional facet-normal sector carries exactly a `1/m` fraction of the Hotelling statistic after leave-one-out averaging. The transverse inverse-covariance sector carries exactly the remaining `(m-1)/m` fraction.

Since `m` is of order `d^2`, essentially all of the Hotelling statistic is transverse at the scale relevant to Target 4.

## `P26-T4-FACET-NORMAL-NOGO-10` — PROVED as a route obstruction

The elementary inverse-metric Cauchy inequality gives

`L >= X^2/(m a^2)`.

Substituting this alone into the fresh-facet identity yields exactly the scalar lower bound

`q >= S`.

But the many-facet identity proves

`average_k S_k = q/m`.

Thus a proof strategy that keeps only the facet-normal Cauchy component loses a factor `m`, asymptotically of order `d^2`.

At the required target scale `q >> 1/d`, this loss is fatal. Any successful fresh-row argument must control the transverse term `R`, or an equivalent quantity, rather than only the scalar altitude `X-a` and the facet-normal projection.

This is a route no-go, not a counterexample to the target theorem.

## `P26-T4-FRESH-FACET-PZ-BRIDGE-10` — PROVED

There is nevertheless a useful one-step lower-tail bridge for the transverse numerator.

Condition on the old sample. Write

`T = x^T M x`

for the positive semidefinite matrix `M` induced by

`A^-1/2 (a P_perp - r w^T)`.

Then

`tr(M)=Theta`.

For any unit vector `y` in harmonic feature space, `Y=y^T x` is a normalized degree-two spherical harmonic. If `B_y` is its traceless symmetric coefficient matrix with Frobenius norm one, then

`Y = sqrt(d(d+2)/2) U^T B_y U`.

A direct Gaussian radial calculation gives a uniform fourth-moment bound. If `G` is standard Gaussian and `U=G/||G||`, then for `tr(B_y)=0`, `tr(B_y^2)=1`,

`E (G^T B_y G)^4 = 48 tr(B_y^4) + 12 <= 60`.

Since

`E ||G||^8 = d(d+2)(d+4)(d+6)`,

we get

`E Y^4 <= 15 d(d+2)/[(d+4)(d+6)] < 15`.

Diagonalizing `M` and applying Cauchy-Schwarz to mixed fourth moments gives

`E_x T^2 <= 15 Theta^2`.

Paley-Zygmund therefore yields

`P_x{ T >= Theta/2 | H_- } >= 1/60`.

Also `E_x X^2=1`, so

`P_x{|X| > sqrt(120) | H_-} <= 1/120`.

Hence, on any old-sample event `|a| <= A`,

`P_x{ q >= Theta / [2(A+sqrt(120))^2] | H_- } >= 1/120`.

This does not close the desired convergence in probability: it provides only a uniform positive conditional probability. It does, however, prove that the correct new quantity is `Theta` together with amplification across many leave-one-out facets. The obstruction is no longer hidden in a scalar denominator.

## Narrow independent audit of P04's exterior-design theorem

Claim audited:

`P04-T4-VOLUME-NULL-EXTERIOR-DESIGN-42`.

Let `H` be `n x m`, `n=m+r`, with independent centered rows, and let

`D = det(H^T H)`.

Let `K` be the orthogonal projector onto `ker(H^T)`. Under the volume-biased law with density proportional to `D`, P04 claims

`E_Q[ wedge^j K ] = [binom(r,j)/binom(n,j)] I`

for every `0 <= j <= r`.

Independent derivation:

- The complementary-minor / Plucker formula writes each entry of `D wedge^j K` as a sum of products of complementary `m x m` row minors of `H`.
- If `I != J`, choose an index in the symmetric difference of the two exterior coordinate sets. In each complementary-minor product that row occurs in exactly one factor and therefore linearly. Conditioning on all other independent rows, centeredness kills the expectation.
- Thus every off-diagonal exterior-coordinate expectation is zero.
- Row exchangeability makes all diagonal expectations equal.
- Pointwise, because `K` is a rank-`r` orthogonal projection,
  `tr(wedge^j K)=binom(r,j)`.
- There are `binom(n,j)` diagonal exterior coordinates, so each normalized diagonal expectation equals `binom(r,j)/binom(n,j)`.

Therefore

`P26-AUDIT-P04-VOLUME-EXTERIOR-DESIGN-10 = PASS`.

This audit is narrow. It does not turn the ordinary-law hard edge into a volume-biased theorem and does not close Target 4.

## What failed / what is now ruled out

### Failed route 1: use only the fresh scalar altitude

The decomposition shows this retains only `S`. Averaged over all facets it is exactly `q/m`, so it discards almost all of the target statistic.

### Failed route 2: use only one-dimensional inverse Cauchy

The inequality `L >= X^2/(m a^2)` recovers exactly the scalar sector and nothing transverse. It therefore has the same `1/m` loss.

### Failed route 3: use the conditional mean of `T` as if it were a high-probability estimate

The fourth-moment argument gives a fixed positive conditional probability, not probability tending to one. A single fresh-row Paley-Zygmund step cannot by itself prove `d q -> infinity` in probability.

### Failed route 4: infer Target 4 from volume-biased null isotropy

P04's exterior-design theorem is correct, but it lives under the determinant tilt. The target here is the ordinary iid law. No inverse-volume transfer is supplied by the exterior-design identity.

## Next exact attack

The highest-value source-branch problem is now sharper than `d q -> infinity` stated in raw form.

For each leave-one-out facet define

`Theta_k = a_k^2 tr(G_-k^-1) - 1/m`.

The fresh transverse numerator has conditional mean `Theta_k`, while the realized transverse contribution is

`R_k = T_k/(X_k-a_k)^2`.

The exact many-facet identity says

`average_k R_k = (m-1)q/m`.

Therefore a useful next theorem would control the aggregate transverse realization directly, not a single scalar pivot. Two concrete routes remain:

1. derive a full-sample identity or lower bound for `sum_k R_k` in terms of a stable inverse-isotropy statistic and exploit exchangeability across many facets;
2. derive a high-effective-rank concentration theorem for `T_k=x_k^T M_k x_k`, with a separate low-effective-rank analysis that keeps its correlation with `X_k-a_k`.

If this source branch stalls, the independent angular branch remains the final-linear innovation target from the previous P26 checkpoint:

`sum_{s=3}^{d+1} E W(P_s)/(s-1)^2 = O(d^-1)`.
