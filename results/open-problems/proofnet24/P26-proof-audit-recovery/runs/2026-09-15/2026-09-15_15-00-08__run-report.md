# 7. Rank-two specialization and exact chi-square floor

Set `s=2`. Since

\[
m-1=\frac{d^2+d-4}{2},
\]

formula (0.6) simplifies to

\[
\boxed{
B_{d,2}
=
\frac{d(d-2)(d+3)}{(d+6)(d^2+d-4)}.
}
\tag{7.1}
\]

For `d>=3`, this is positive. Its large-`d` expansion is

\[
B_{d,2}
=1-\frac6d+\frac{34}{d^2}-\frac{202}{d^3}+O(d^{-4}).
\tag{7.2}
\]

The three sector identities become

\[
\boxed{
E\|q_{P_2}-1\|_2^2
=B_{d,2}+3\alpha_d e_2,
}
\tag{7.3}
\]

\[
\boxed{
E\|\Pi_2(q_{P_2}-1)\|_2^2
=\beta_d e_2,
\qquad
\beta_d:=\frac{2d(d+2)}{(d+4)^2},
}
\tag{7.4}
\]

\[
\boxed{
E\|\Pi_4(q_{P_2}-1)\|_2^2
=B_{d,2}+\eta_d e_2,
}
\tag{7.5}
\]

with

\[
\boxed{
\eta_d:=\frac{d^2(d+2)}{(d+4)^2(d+6)}.
}
\tag{7.6}
\]

The coefficient asymptotics are

\[
\beta_d=2-\frac{12}{d}+\frac{64}{d^2}+O(d^{-3}),
\]

\[
\eta_d=1-\frac{12}{d}+\frac{104}{d^2}+O(d^{-3}),
\]

\[
3\alpha_d=3-\frac{24}{d}+\frac{168}{d^2}+O(d^{-3}).
\]

Because `e_2>=0`, (7.3) and (7.5) produce exact lower floors:

\[
E\|q_{P_2}-1\|_2^2\ge B_{d,2},
\]

\[
E\|\Pi_4(q_{P_2}-1)\|_2^2\ge B_{d,2}.
\]

Moreover all three coefficients multiplying `e_2` are bounded above and below by positive constants for large `d`. Therefore (0.13) follows.

This is the strongest mathematical result of the run.
