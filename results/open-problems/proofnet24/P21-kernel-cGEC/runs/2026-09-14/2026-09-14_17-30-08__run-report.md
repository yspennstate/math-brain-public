\[
a_i,z_{i1},z_{i2}\stackrel{\rm iid}{\sim}N(0,I_d),

\[
t_i=\xi^\top a_i,
\qquad
\|\xi\|_2=1.

\[
\sigma\in C_b^3(\mathbb R)

# 3. Matched two-view Gaussian surrogate

Let
\[
U=Z+\Delta V,
\qquad
U_j=Z+\Delta V_j,
\]
for independent standard Gaussian scalars.

Because \(\sigma\) is odd,
\[
\mu_0=E\sigma(U)=0.
\]

Define
\[
\mu_e
=
E[Z\sigma(U)]
=
E\sigma'(U),
\tag{3.1}
\]
\[
\mu_b
=
E[V\sigma(U)]
=
\Delta E\sigma'(U),
\tag{3.2}
\]
\[
\mu_2^2
=
E[\sigma(U_1)\sigma(U_2)]
-
\mu_e^2,
\tag{3.3}
\]
\[
\mu_3^2
=
E[\sigma(U)^2]
-
E[\sigma(U_1)\sigma(U_2)]
-
\mu_b^2.
\tag{3.4}
\]

The matched surrogate rows are
\[
\boxed{
x_{ij}^{G}
=
\mu_eF^\top a_i
+
\mu_bF^\top z_{ij}
+
\mu_2 b_i
+
\mu_3p_{ij},
}
\tag{3.5}
\]
where
\[
b_i,p_{i1},p_{i2}\stackrel{\rm iid}{\sim}N(0,I_m),
\]
and **the same \(b_i\) is used in both views of original sample \(i\)**.

This shared term is mandatory. Replacing the two augmented rows separately would destroy the correct correlation.

For completeness, Hermite expansion proves that the residual variances are nonnegative. Put
\[
v=1+\Delta^2,
\qquad
\rho=v^{-1},
\]
and
\[
\sigma(\sqrt v\,Y)
=
\sum_{k\ {\rm odd}}a_kh_k(Y).
\]
Then
\[
a_1=\sqrt v\,\mu_e,
\]
and
\[
\mu_2^2
=
\sum_{\substack{k\ge3\\k\ {\rm odd}}}
a_k^2\rho^k
\ge0,
\tag{3.6}
\]
\[
\mu_3^2
=
\sum_{\substack{k\ge3\\k\ {\rm odd}}}
a_k^2(1-\rho^k)
\ge0.
\tag{3.7}
\]

# 4. Exact rank-two leave-one-original-sample identity

Fix a hybrid in which every original-sample block except block \(i\) is already specified.

Remove both rows of block \(i\).

Let
\[
H_-
=
\lambda I
+
\frac1N X_-^\top X_-,
\tag{4.1}
\]
and let \(w_-\) minimize the leave-block objective.

Write
\[
X_i=
\begin{pmatrix}
x_{i1}^\top\\
x_{i2}^\top
\end{pmatrix},
\]
\[
e
=
t_i\mathbf1_2-X_iw_-,
\tag{4.2}
\]
and
\[
Q
=
\frac1N
X_iH_-^{-1}X_i^\top.
\tag{4.3}
\]

Completing the square and applying rank-two Woodbury gives exactly
\[
\boxed{
L_i^*
=
L_-^*
+
\frac1{2N}
e^\top(I_2+Q)^{-1}e.
}
\tag{4.4}
\]

A direct low-dimensional numerical check in this run reproduced (4.4) to machine precision for independent random examples, with residuals below \(5\times10^{-17}\).

The local statistic is therefore
\[
\Psi(t,u,Q)
=
(t\mathbf1_2-u)^\top(I_2+Q)^{-1}(t\mathbf1_2-u),
\tag{4.5}
\]
where
\[
u_a=x_{ia}^\top w_-.
\]

The full \(2\times2\) leverage matrix \(Q\) must be controlled before a logit comparison is useful.

# 5. Conditional covariance and teacher matching

Condition on \(F\) and on the leave-block base.

On the standard Gaussian-feature event,
\[
\|F\|_{\rm op}=O(1),
\tag{5.1}
\]
\[
\max_r
\bigl|\|f_r\|-1\bigr|
=
O\!\left(\sqrt{\frac{\log d}{d}}\right),
\tag{5.2}
\]
\[
\max_{r\ne s}
|f_r^\top f_s|
=
O\!\left(\sqrt{\frac{\log d}{d}}\right).
\tag{5.3}
\]

For two feature coordinates \(r\ne s\), Price expansion in their Gaussian covariance gives
\[
E[\sigma(X_r)\sigma(X_s)]
=
\text{matched linear term}
+
O(|f_r^\top f_s|^3).
\tag{5.4}
\]

Why there is no quadratic term:

- oddness of \(\sigma\) implies \(\sigma''\) is odd;
- at zero covariance the two coordinates are independent centered Gaussians;
- therefore the second Price coefficient contains
  \[
  E\sigma''(G_1)\,E\sigma''(G_2)=0.
  \]

Bounded \(\sigma'''\) controls the cubic remainder.

The linear coefficient and diagonal terms are exactly what the surrogate coefficients in Section 3 match, up to the small column-norm deviations in (5.2).

Schur/Gershgorin or the factorized Gram form then gives
\[
\boxed{
\max_{a,b\le2}
\|C_{ab}^{A}-C_{ab}^{G}\|_{\rm op}
\le
\varepsilon_d,
}
\tag{5.5}
\]
where
\[
\boxed{
\varepsilon_d
=
C
\frac{(\log d)^{3/2}}{\sqrt d}.
}
\tag{5.6}
\]

The teacher-feature vector also matches.

Gaussian integration by parts gives, coordinatewise,
\[
E[t_i x_{ia,r}^{A}]
=
(\xi^\top f_r)
E\sigma'\!\left(
\sqrt{1+\Delta^2}\,\|f_r\|Z
\right),
\]
while the Gaussian surrogate has coefficient
\[
\mu_e(\xi^\top f_r).
\]

Therefore
\[
\boxed{
\|c_a^{A}-c_a^{G}\|_2
=
O\!\left(
\sqrt{\frac{\log d}{d}}
\right).
}
\tag{5.7}
\]

# 6. The literal uniform correlated-Stein theorem is false

A stronger statement one might try to prove is:

> conditional on an arbitrary bounded leave-block vector \(w\), the full triple
> \[
> (t,u_1,u_2)
> \]
> has a Gaussian weak limit uniformly over \(w\).

This is false.

Take
\[
\sigma=\tanh,
\qquad
w=e_1.
\]
Then
\[
u_1^{A}
=
\tanh(f_1^\top(a+\Delta z_1))
\]
is supported in \([-1,1]\), while the matched Gaussian surrogate logit is a nondegenerate Gaussian random variable.

A bounded smooth test supported outside \([-1,1]\) separates the laws by a fixed amount.

Thus:
\[
\boxed{
\text{uniform full-logit Gaussianity over arbitrary bounded }w
\text{ is false.}
}
\tag{6.1}
\]

For squared ridge this is harmless.

After leverage freezing, the current block statistic is a quadratic polynomial in
\[
(t,u_1,u_2).
\]

The only moments needed are
\[
Et^2=1,
\]
\[
E[tu_a]=c_a^\top w_-,
\]
\[
E[u_au_b]=w_-^\top C_{ab}w_-.
\]

Consequently every fixed quadratic polynomial \(Q_2\) satisfies
\[
\boxed{
\left|
E_AQ_2(t,u_1,u_2)
-
E_GQ_2(t,u_1,u_2)
\right|
\le
C_{Q_2}
\varepsilon_d
(1+\|w_-\|^2).
}
\tag{6.2}
\]

This is the correct restricted replacement for a full correlated Stein CLT.

# 7. Leverage freezing

For
\[
q_{ab}
=
\frac1N
x_{ia}^\top H_-^{-1}x_{ib},
\]
the current block is independent of \(H_-\).

For actual rows, differentiate with respect to the underlying Gaussian vectors \(a_i,z_{i1},z_{i2}\).

The feature Jacobian obeys
\[
\|D x_{ia}\|_{\rm op}
\le
\|\sigma'\|_\infty\|F\|_{\rm op}
=
O(1).
\]

Since
\[
\|H_-^{-1}\|_{\rm op}\le\lambda^{-1}
\]
and
\[
E\|x_{ia}\|^2=O(m),
\]
the gradient scale is
\[
\|\nabla q_{ab}\|
\le
C
\frac{\sqrt m}{N\lambda}
=
O(d^{-1/2}).
\tag{7.1}
\]

The same estimate holds for the Gaussian surrogate, including its residual Gaussian coordinates.

Gaussian Poincaré therefore gives
\[
\boxed{
\operatorname{Var}
(q_{ab}\mid\mathcal F_-)
=
O(d^{-1}).
}
\tag{7.2}
\]

For conditional means,
\[
E[q_{ab}\mid\mathcal F_-]
=
\frac1N
\operatorname{Tr}(H_-^{-1}C_{ab}),
\]
so
\[
\boxed{
|\bar q_{ab}^{A}-\bar q_{ab}^{G}|
\le
\frac{m}{N\lambda}
\|C_{ab}^{A}-C_{ab}^{G}\|_{\rm op}
=
O(\varepsilon_d).
}
\tag{7.3}
\]

Because \(Q\) is \(2\times2\), (7.2) controls its full Frobenius fluctuation.

Also
\[
Q\succeq0,
\qquad
\|(I_2+Q)^{-1}\|_{\rm op}\le1.
\]

Ridge coercivity gives the hybrid-uniform moment bound
\[
\boxed{
\sup_d E\|w_-\|^4<\infty.
}
\tag{7.4}
\]

Indeed the optimum is no worse than \(w=0\):
\[
\frac\lambda2\|w_-\|^2
\le
\frac1{2N}\|y_-\|^2,
\]
and the duplicated Gaussian teacher labels have bounded moments.

Freezing \(Q\), moving the frozen mean from actual to Gaussian, and applying (6.2) therefore yields
\[
\boxed{
\left|
E_i\Psi_A
-
E_i\Psi_G
\right|
\le
C
\varepsilon_d
(1+\|w_-\|^2).
}
\tag{7.5}
\]

The \(O(d^{-1/2})\) leverage fluctuation is smaller than the displayed \(\varepsilon_d\).

# 8. Total training replacement error

Order the \(n\) original-sample blocks and replace them one whole block at a time.

At each step the two compared hybrids have the same leave-block base.

By (4.4) and (7.5), the conditional expected optimized-value discrepancy from one block is
\[
O\!\left(
\frac{\varepsilon_d}{N}
\right).
\tag{8.1}
\]

There are
\[
n=N/2
\]
blocks.

Hence
\[
\boxed{
\left|
E L_A^*
-
E L_G^*
\right|
\le
C\varepsilon_d.
}
\tag{P21-OBJ-MEAN-05}
\]

This expectation-level theorem is a small strengthening of the previous bounded-smooth-distribution statement.

For a bounded \(C^2\) test \(\varphi\), Taylor expansion of
\[
\varphi(L_-^*+\delta)
\]
adds a per-block \(O(N^{-2})\) remainder because the block increment is \(O(N^{-1})\) in \(L^2\).

Therefore
\[
\boxed{
\left|
E\varphi(L_A^*)
-
E\varphi(L_G^*)
\right|
\le
C_\varphi
\left(
\varepsilon_d+N^{-1}
\right).
}
\tag{8.2}
\]

This is the P04/P21 block-Lindeberg rate.

The naive alternative
\[
n\,\varepsilon_d
\]
is simply a normalization mistake: it forgets the factor \(1/(2N)\) in the optimized increment.

# 11. Proportional ghost test block

Introduce
\[
M=\lfloor\kappa d\rfloor
\]
fresh clean test examples independent of training.

Let
\[
\widehat R_M(w)
=
\frac1M
\sum_{r=1}^M
(t_r^0-(x_r^0)^\top w)^2.
\tag{11.1}
\]

For a training/test hybrid define
\[
\boxed{
\Phi(\tau)
=
\min_w
\left\{
L_{\rm train}(w)
+
\frac\tau2
\widehat R_M(w)
\right\}.
}
\tag{11.2}
\]

A single unnormalized clean test row cannot be used at fixed positive and negative \(\tau\): its rank-one Hessian has norm \(\Theta(d)\).

The normalized proportional block has covariance operator \(O(1)\).

Uniformly over rowwise actual/Gaussian test hybrids,
\[
\left\|
\frac1M X_0^\top X_0
\right\|_{\rm op}
\le
C_0
\tag{11.3}
\]
with exponentially high probability.

Also
\[
\max_{r\le M}
\frac{\|x_r^0\|^2}{M}
\le
C_1
\tag{11.4}
\]
with probability tending to one.

Choose
\[
h_0
\le
\min\left\{
\frac{\lambda}{2C_0},
\frac{\lambda}{4C_1}
\right\}.
\tag{11.5}
\]

\[
|\tau|\le h_0,
\]
the perturbed Hessian obeys
\[
\boxed{
H_\tau
=
\lambda I
+
\frac1N X_{\rm tr}^\top X_{\rm tr}
+
\tau\frac1M X_0^\top X_0
\succeq
\frac\lambda2 I.
}
\tag{11.6}
\]

This includes negative \(\tau\).

# 12. Exact test-row replacement

Remove one ghost row \(r\).

Let
\[
H_{-r,\tau}
\]
be the leave-row Hessian and
\[

=

(x_r^0)^\top
H_{-r,\tau}^{-1}
x_r^0.
\tag{12.1}

For \(\tau<0\), removing the negative rank-one term increases the Hessian.

\[
H_{-r,\tau}\succeq\lambda I/2.

\[
\boxed{

\tag{12.2}
\]

\[
\boxed{
\Phi_r(\tau)-\Phi_{-r}(\tau)
=
\frac{\tau}{2M}
\frac{e_r^2}{1+\tau Q_r}.
}
\tag{12.3}
\]

Conditional leverage variance is
\[
\operatorname{Var}(Q_r)
=
O(d^{-1}).
\tag{12.4}
\]

\[
O(\varepsilon_d^{(0)}).
\tag{12.5}
