# 15. P21-GHOST-STAB-04 — uniform two-sided stability

## 15.1 Test empirical covariance is \(O(1)\)

For actual clean rows, for every deterministic \(w\),

\[

=
\sum_r
w_r\sigma(f_r^\top a^0).

\[

\operatorname{diag}(\sigma'(F^\top a^0))
w.

\[
\|\nabla_a(w^\top x^{0,A})\|
\le
\|F\|_{\rm op}
\|\sigma'\|_\infty
\|w\|.

Since \(\sigma\) is odd and the input Gaussian is symmetric, the linear form is centered. Gaussian concentration therefore makes every unit-direction projection uniformly subgaussian.

A standard sphere-net argument for independent subgaussian rows with
\[
M/m\to\kappa/\beta>0

gives

\[
\boxed{
\left\|
\frac1M
(X_0^A)^\top X_0^A
\right\|_{\rm op}
\le
C_0

\tag{15.1}

with probability \(1-e^{-c d}\), for a constant depending only on the fixed asymptotic ratios, \(\sigma\), and the good-\(F\) constants.

The clean Gaussian surrogate has covariance operator \(O(1)\), so the same bound holds.

It also holds uniformly for rowwise actual/Gaussian hybrids because the directional subgaussian constant is common.

## 15.2 Row leverage scale

\[
\frac{\|x_r^{0,A}\|^2}{M}
\le

For clean Gaussian surrogate rows, a Gaussian norm tail plus \(M\asymp m\asymp d\) gives

\max_{r\le M}

\le

The same holds on rowwise hybrids.

## 15.3 Strong convexity for negative \(\tau\)

For \(\tau\ge0\), this is immediate; the point is the uniform negative-\(\tau\) bound.

for every \(|\tau|\le h_0\).

# 17. Derivative and stability bounds

The covariance bounds and

\nabla\widehat R_M(w_\tau).
