# 2. Exact model and normalization

Let

\[
N=2n,\qquad \frac nd\to\alpha>0,\qquad \frac md\to\beta>0,
\]

and let

\[
F=[f_1,\ldots,f_m]\in\mathbb R^{d\times m},\qquad F_{ab}\stackrel{\rm iid}{\sim}N(0,1/d).
\]

For original sample \(i\),

\[
a_i,z_{i1},z_{i2}\stackrel{\rm iid}{\sim}N(0,I_d),\qquad t_i=\xi^\top a_i,\qquad \|\xi\|=1.
\]

The two actual augmented rows are

\[
x_{ij}^A=\sigma\!\left(F^\top(a_i+\Delta z_{ij})\right),\qquad j=1,2.
\]

The exact objective is

\[
\boxed{
L_A(w)=\frac1{4n}\sum_{i=1}^n\sum_{j=1}^2\left(t_i-(x_{ij}^A)^\top w\right)^2+\frac\lambda2\|w\|^2
=\frac1{2N}\|y-X_Aw\|^2+\frac\lambda2\|w\|^2.
}
\tag{2.1}
\]

The matched two-view Gaussian surrogate has the inherited form

\[
\boxed{
x_{ij}^G=\mu_eF^\top a_i+\mu_bF^\top z_{ij}+\mu_2b_i+\mu_3p_{ij},

\tag{2.2}

where the same \(a_i\) and the same \(b_i\) are shared by both views, while \(z_{ij},p_{ij}\) are private. The replacement unit is one whole original-sample block.

For clean testing,

\[

\boxed{x^{0,G}=\nu_1F^\top a^0+\nu_2g^0.}

# 3. Hermite covariance structure

For centered jointly Gaussian \(X,Y\) with variances in a fixed positive compact interval and covariance \(c\), oddness of \(\sigma\) eliminates all even Hermite levels. Writing

\[
a(q)=q^{-1/2}E[G\sigma(\sqrt q\,G)],
\]

one has

\[
\boxed{
E[\sigma(X)\sigma(Y)]=a(q_X)a(q_Y)c+O_\sigma(|c|^3).
}
\tag{3.1}
\]

For feature columns the off-diagonal covariance is a fixed multiple of

\[
g_{rs}=f_r^\top f_s.
\]

The covariance mismatch therefore consists of a first-order Gram-structured term, a diagonal variance correction due to \(\|f_r\|^2\ne1\), and an off-diagonal cubic remainder dominated entrywise by \(C|g_{rs}|^3\).

# 4. `P21-HADAMARD-CUBE-10`

Define

\[
S_r=\sum_{s\ne r}|f_r^\top f_s|^3.
\]

Condition on \(f_r\). Then for \(s\ne r\),

\[
f_r^\top f_s\stackrel{\rm iid}{=}\frac{\|f_r\|}{\sqrt d}Z_s,\qquad Z_s\sim N(0,1),
\]

so

\[
\boxed{
S_r=\frac{\|f_r\|^3}{d^{3/2}}\sum_{s\ne r}|Z_s|^3.
}
\tag{4.1}
\]

Fix any polynomial failure exponent \(K\), set

\[
L_d=\sqrt{8(K+4)\log d},\qquad Y_s=|Z_s|^3\mathbf 1_{\{|Z_s|\le L_d\}}.
\]

Then \(0\le Y_s\le L_d^3\), \(EY_s\le E|Z|^3\), and \(EY_s^2\le E|Z|^6\). Scalar Bernstein yields, for \(m\asymp d\),

\[
P\left\{\sum_{s\ne r}Y_s>2E|Z|^3\,m\right\}
\le\exp\left[-c\frac d{(\log d)^{3/2}}\right].
\]

Also

\[
P\{\max_{s\ne r}|Z_s|>L_d\}\le 2m e^{-L_d^2/2}\le Cd^{-4K-15},
\]

and \(P\{\|f_r\|>2\}\le e^{-cd}\). Union-bounding over \(m=O(d)\) rows gives, with probability \(1-o(d^{-K})\),

\[
\boxed{
\max_rS_r\le C_\beta\frac m{d^{3/2}}\le\frac{C_\beta}{\sqrt d}.
}
\tag{4.2}
\]

If a symmetric zero-diagonal matrix \(R\) obeys \(|R_{rs}|\le C|g_{rs}|^3\), then

\[
\|R\|_{\rm op}\le\||R|\|_{\infty\to\infty}\le C\max_rS_r,
\]

hence

\[
\boxed{\|R\|_{\rm op}=O_{\mathbb P}(d^{-1/2}).}
\tag{4.3}
\]

This removes the old maximum-coherence loss \(m\max_{r\ne s}|g_{rs}|^3=O((\log d)^{3/2}/\sqrt d)\).

# 5. `P21-COV-RATE-10`

Let

\[
\delta_F=\max_r|\|f_r\|^2-1|.
\]

On the standard Gaussian-feature event,

\[
\delta_F=O\!\left(\sqrt{\frac{\log d}{d}}\right),\qquad \|F^\top F\|_{\rm op}=O(1).
\tag{5.1}

The first Hermite coefficient is smooth in the column variance. If \(D_a\) is the resulting diagonal coefficient matrix and \(\mu_a I\) its population matched value,

\[
\|D_a-\mu_aI\|\le C_\sigma\delta_F.

Therefore the first-order Gram contribution satisfies

\[
\|D_a(F^\top F)D_b-\mu_a\mu_bF^\top F\|\le C_\sigma\delta_F.

The diagonal same-view/cross-view variance mismatch is also \(O(\delta_F)\), and the cubic off-diagonal remainder is \(O(d^{-1/2})\) by (4.3). Thus

\[
\boxed{
\max_{a,b\in\{1,2\}}\|C_{ab}^A-C_{ab}^G\|_{\rm op}
\le C_\sigma(\delta_F+d^{-1/2})

\tag{5.2}

The teacher-feature cross-vector mismatch obeys the same scale:

\[
\boxed{\|c_a^A-c_a^G\|=O_{\mathbb P}(\sqrt{\log d/d}).}
\tag{5.3}
\]

Define

\[
\varepsilon_d^\sharp=C_\sigma\sqrt{\frac{\log d}{d}}.

# 6. Exact leave-block identity and leverage freezing

Delete both augmented rows of one original sample. Let

\[
H_-=\lambda I+\frac1N X_-^\top X_-,
\]

let \(w_-\) be the leave-block optimizer, and write

\[
X_i=\begin{pmatrix}x_{i1}^\top\\x_{i2}^\top\end{pmatrix},\qquad
e=t_i\mathbf 1_2-X_iw_-,\qquad
Q=\frac1N X_iH_-^{-1}X_i^\top.
\]

Then the rank-two Woodbury identity is exactly

\[
\boxed{
L_i^\star-L_-^\star=\frac1{2N}e^\top(I_2+Q)^{-1}e.
}
\tag{6.1}
\]

At real training parameter, \(Q\succeq0\), so \(\|(I_2+Q)^{-1}\|\le1\).

Conditional Gaussian Poincaré gives for every leverage entry

\[
\operatorname{Var}(q_{ab}\mid\mathcal F_-)=O(m/N^2)=O(d^{-1}),
\]

hence

\[
\boxed{E[\|Q-EQ\|_{\rm op}^2\mid\mathcal F_-]=O(d^{-1}).}
\tag{6.2}
\]

The residual has

\[
\left(E[\|e\|^4\mid\mathcal F_-]\right)^{1/2}\le C(1+\|w_-\|^2).
\tag{6.3}
\]

Therefore leverage freezing costs

\[
\boxed{O(d^{-1/2})(1+\|w_-\|^2).}
\tag{6.4}
\]

No independence between the two views is used.

# 7. Frozen block comparison and total replacement error

Let \(\bar Q_M=E[Q_M\mid\mathcal F_-]\), \(M\in\{A,G\}\). Every entry satisfies

\[
\bar q_{ab}^M=\frac1N\operatorname{Tr}(H_-^{-1}C_{ba}^M).
\]

Thus

\[
\|\bar Q_A-\bar Q_G\|\le C\varepsilon_d^\sharp.
\tag{7.1}
\]

After freezing \(Q\), the local expectation is quadratic in \((t,u_1,u_2)\), with \(u_a=x_{ia}^\top w_-\), and depends only on

\[
Et^2,\qquad E[tu_a],\qquad E[u_au_b].
\]

By (5.2)–(5.3),

\[
\left\|E_A[e_Ae_A^\top]-E_G[e_Ge_G^\top]\right\|
\le C\varepsilon_d^\sharp(1+\|w_-\|^2).
\tag{7.2}
\]

Hence the frozen actual/surrogate block discrepancy is

\[
O(\varepsilon_d^\sharp(1+\|w_-\|^2)),
\]

and restoring leverage adds (6.4). Ridge coercivity gives \(\sup_dE\|w_-\|^4<\infty\).

Therefore one original-sample replacement costs

\[
\boxed{
O\left(\frac{\varepsilon_d^\sharp+d^{-1/2}}{N}\right)
}
\tag{7.3}
\]

in expected optimized value. Since there are \(n=N/2\) original-sample blocks,

\[
\boxed{
|EL_A^\star-EL_G^\star|
\le C(\varepsilon_d^\sharp+d^{-1/2})
\le C\sqrt{\frac{\log d}{d}}
\to0.
}
\tag{7.4}
\]

For \(\varphi\in C_b^2\), one-block Taylor remainders are \(O(\|\varphi''\|_\infty N^{-2})\), so

\[
\boxed{
|E\varphi(L_A^\star)-E\varphi(L_G^\star)|
\le C\|\varphi'\|_\infty\sqrt{\frac{\log d}{d}}
+C\|\varphi''\|_\infty N^{-1}.
}
\tag{7.5}
\]

The naive total \(n\varepsilon_d\) is dimensionally wrong because it omits the exact \(1/(2N)\) Woodbury prefactor.

# 8. `P21-GHOST-DISK-10`: complex analytic envelope

The clean-test proof uses an independent matched Gaussian ghost block of size \(M\asymp d\). Let

\[
S_0=M^{-1}X_0^\top X_0,\qquad r_0^{\rm vec}=M^{-1}X_0^\top t_0.
\]

For one training hybrid, couple the ghost loss with a complex parameter \(z\). The leave-block Hessian is

\[
H_-(z)=H_-+zS_0.
\]

On the ghost covariance event \(\|S_0\|\le C_0\), choose initially

\[
r_1=\frac\lambda{4C_0}.
\]

For \(|z|\le r_1\),

\[
H_-(z)=H_-(I+zH_-^{-1}S_0),
\]

and \(\|zH_-^{-1}S_0\|\le1/4\). Hence

\[
\boxed{\|H_-(z)^{-1}\|\le 4/(3\lambda)<2/\lambda.}
\tag{8.1}
\]

The same Neumann argument applies to the full current-block Hessian

\[
H_i(z)=H_i(0)+zS_0,
\]

so

\[
\boxed{\|H_i(z)^{-1}\|\le2/\lambda.}
\tag{8.2}
\]

Let \(U=X_i/\sqrt N\) and

\[
Q_z=UH_-(z)^{-1}U^\top.
\]

The algebraic Woodbury identity over \(\mathbb C\) gives

\[
\boxed{(I_2+Q_z)^{-1}=I_2-UH_i(z)^{-1}U^\top.}
\tag{8.3}
\]

Therefore

\[
\|(I_2+Q_z)^{-1}\|\le1+\frac2\lambda\|U\|^2.
\tag{8.4}
\]

For the actual bounded activation, \(\|U\|^2=O(1)\) deterministically; for the Gaussian surrogate, every fixed moment of \(\|U\|\) is uniformly bounded.

At \(z=0\), \(\bar Q_0\succeq0\) and \(\|(I+\bar Q_0)^{-1}\|\le1\). The inverse identity yields

\[
\|\bar Q_z-\bar Q_0\|\le C|z|.
\]

After shrinking to a fixed deterministic radius \(r_0>0\),

\[
\boxed{
\sup_{|z|\le r_0}\|(I+\bar Q_z)^{-1}\|\le2.
}
\tag{8.5}
\]

The conditional Poincaré estimate remains uniform on the disk because the only Hessian input in the Jacobian is the inverse bound:

\[
\boxed{
E[\|Q_z-\bar Q_z\|_F^2\mid\mathcal F_-]\le Cd^{-1},\qquad |z|\le r_0.
}
\tag{8.6}
\]

The complex leave-block optimizer satisfies

\[
w_-(z)-w_-(0)
=-zH_-(z)^{-1}(S_0w_-(0)-r_0^{\rm vec}),
\tag{8.7}
\]

so ridge coercivity and independent ghost moments imply

\[
\sup_{|z|\le r_0}E\|w_-(z)\|^4<\infty.
\tag{8.8}
\]

Thus the whole block comparison is uniform on the complex disk:

\[
\boxed{
\sup_{|z|\le r_0}|E\Phi_A(z)-E\Phi_G(z)|\le C\varepsilon_d^\sharp.
}
\tag{8.9}
\]

This is the needed clarification: for complex \(z\), \(Q_z\) is not Hermitian PSD, so the real-axis bound \(\|(I+Q)^{-1}\|\le1\) is unavailable. Woodbury plus fixed-disk invertibility is the correct replacement.
