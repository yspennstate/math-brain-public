# 5. Why a literal uniform correlated-Gaussian logit CLT is false

Take

\[
\sigma=\tanh
\]

and an arbitrary leave-block coefficient vector

\[
w=e_1.
\]

Then an actual logit is

\[
u_1^A
=
\tanh(f_1^\top(a+\Delta z_1)),
\]

which is supported in \([-1,1]\).

The matched Gaussian logit is nondegenerate Gaussian.

Therefore no probability metric which metrizes weak convergence can satisfy a uniform Gaussian approximation over every bounded \(w\).

So the correct restricted theorem is not a full-logit cGEC.

For squared ridge, once the leverage matrix is frozen, the block statistic is quadratic in

\[
(t,u_1,u_2),
\]

and only first/second moments are needed.

This is why the restricted theorem survives even though the strongest naive Stein statement is false.
