# 6. Exact residual covariance at arbitrary feature-column norm

Fix \(q>0\). Let \(G_0,G_1,G_2\) be iid standard Gaussians and define

\[
X_j(q)=\sqrt q\,(G_0+\Delta G_j),
\qquad
Y_j(q)=\sigma(X_j(q)).
\tag{6.1}
\]

Equivalently, with

\[
H_j=\frac{G_0+\Delta G_j}{s},
\]

the pair \((H_1,H_2)\) is standard bivariate Gaussian with correlation

\[
\operatorname{Corr}(H_1,H_2)=\rho_\Delta=s^{-2},
\]

and

\[
Y_j(q)=\sigma(s\sqrt q\,H_j).
\]

Define the same-view second moment

\[
V(q)=E[\sigma(s\sqrt q\,G)^2]
=\sum_{\substack{k\ge1\\k\ {\rm odd}}}a_k(q)^2.
\tag{6.2}
\]

The linear projection on \((G_0,G_j)\) has coefficients

\[
E[G_0Y_j(q)]
=\sqrt q\,\kappa(q),
\]

\[
E[G_jY_j(q)]
=\Delta\sqrt q\,\kappa(q),
\]

by Gaussian Stein. Thus the total first-Hermite variance is

\[
q(1+\Delta^2)\kappa(q)^2
=s^2q\kappa(q)^2
=a_1(q)^2.
\]

Define the higher-Hermite same-view residual variance

\[
\boxed{
\eta(q)
:=
V(q)-s^2q\kappa(q)^2
=
\sum_{\substack{k\ge3\\k\ {\rm odd}}}a_k(q)^2.
}
\tag{6.3}
\]

For the two views, Mehler's identity gives

\[
C(q)
:=E[Y_1(q)Y_2(q)]
=
\sum_{\substack{k\ge1\\k\ {\rm odd}}}
a_k(q)^2\rho_\Delta^k.
\tag{6.4}
\]

The \(k=1\) term is

\[
a_1(q)^2\rho_\Delta
=s^2q\kappa(q)^2s^{-2}
=q\kappa(q)^2,
\]

which is exactly the covariance of the shared first-order term \(\kappa(q)\sqrt q G_0\). Hence define the higher-Hermite shared residual covariance

\[
\boxed{
\gamma(q)
:=
C(q)-q\kappa(q)^2
=
\sum_{\substack{k\ge3\\k\ {\rm odd}}}
a_k(q)^2\rho_\Delta^k.
}
\tag{6.5}
\]

Since \(0<\rho_\Delta<1\), termwise positivity gives

\[
\boxed{
0\le\gamma(q)\le\eta(q)
\qquad(q>0).
}
\tag{6.6}
\]

Thus the exact same-coordinate higher-Hermite residual covariance matrix of the two actual views is

\[
\boxed{
\begin{pmatrix}
\eta(q)&\gamma(q)\\
\gamma(q)&\eta(q)
\end{pmatrix}.
}
\tag{6.7}
\]

At \(q=1\), this is represented exactly by a shared Gaussian residual of variance \(\mu_2^2=\gamma(1)\) and private Gaussian residuals of variance \(\mu_3^2=\eta(1)-\gamma(1)\).

# 7. `P21-FINITE-COLUMN-RESIDUAL-CERT-24` — PROVED

The inherited activation assumption used throughout P21 is bounded odd \(C^3\) with bounded first three derivatives. On the compact interval

\[
I=[1/2,3/2],
\]

the functions \(V,\kappa,C,\eta,\gamma\) are Lipschitz with constants depending only on \(\sigma\) and fixed \(\Delta\).

Indeed, differentiation under the Gaussian expectation is justified by bounded derivatives. With \(a(q)=s\sqrt q\),

\[
V'(q)
=
\frac{s}{\sqrt q}
E[
G\,\sigma(a(q)G)\sigma'(a(q)G)
],
\tag{7.1}
\]

\[
\kappa'(q)
=
\frac{s}{2\sqrt q}
E[
G\,\sigma''(a(q)G)
].
\tag{7.2}
\]

If \((G_1,G_2)\) is standard bivariate Gaussian with correlation \(\rho_\Delta\), then

\[
\begin{aligned}
C'(q)
=
\frac{s}{2\sqrt q}E[&
G_1\sigma'(a(q)G_1)\sigma(a(q)G_2)
\\
&+G_2\sigma(a(q)G_1)\sigma'(a(q)G_2)
].
\end{aligned}
\tag{7.3}
\]

All three derivatives are uniformly bounded on \(I\). Therefore the derivatives of

\[
\eta(q)=V(q)-s^2q\kappa(q)^2
\]

and

\[
\gamma(q)=C(q)-q\kappa(q)^2
\]

are uniformly bounded on \(I\), so

\[
|\eta(q)-\eta(1)|+|\gamma(q)-\gamma(1)|
\le
C|q-1|
\qquad(q\in I).
\tag{7.4}
\]

Outside \(I\), both residual covariances are uniformly bounded because the Hermite formulas give

\[
0\le\gamma(q)\le\eta(q)\le V(q)\le\|\sigma\|_\infty^2.
\]

For \(q_r=\|f_r\|^2\sim\chi_d^2/d\), the complement of \(I\) has exponentially small probability. Combining this with `(3.1)` gives

\[
\boxed{
E|\eta(q_r)-\eta(1)|^2
+
E|\gamma(q_r)-\gamma(1)|^2
\le
\frac Cd,
}
\tag{7.5}
\]

and

\[
\boxed{
E|\eta(q_r)-\eta(1)|^4
+
E|\gamma(q_r)-\gamma(1)|^4
\le
\frac C{d^2}.
}
\tag{7.6}
\]

This proves `P21-FINITE-COLUMN-RESIDUAL-CERT-24`.

# 8. `P21-RESIDUAL-SQRT-LIP-NOGO-24` — rejected proof route

A tempting route is to define finite-column residual coefficients

\[
\mu_2(q)=\sqrt{\gamma(q)},
\qquad
\mu_3(q)=\sqrt{\eta(q)-\gamma(q)},
\]

and then attempt to prove

\[
|\mu_j(q)-\mu_j(1)|\le C|q-1|.
\]

This is not justified without a quantitative lower bound away from zero on the residual variances. The square-root map is not Lipschitz at zero, and degenerate residual sectors are possible (for example the private residual disappears when the two views coincide).

The cGEC block theorem does not need coefficient-level square-root Lipschitzness. It only needs **covariance-level** matching. Therefore the proof correctly works with \(\eta(q)\) and \(\gamma(q)\) directly.

This route is retained as a rejected unnecessary strengthening rather than silently assumed.
