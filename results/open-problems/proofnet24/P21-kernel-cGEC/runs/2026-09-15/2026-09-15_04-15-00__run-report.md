# 7. A deterministic smoothing lemma for \(W_1\)

Let \(X,Y\) be real random variables with

\[
E X^2+E Y^2\le M_2.
\]

Assume that for every bounded \(C^2\) test function \(\psi\),

\[
\left|
E\psi(X)-E\psi(Y)
\right|
\le
a\|\psi'\|_\infty
+
b\|\psi''\|_\infty
+
\delta\|\psi\|_\infty.
\tag{7.1}
\]

Then for every \(R>0\) and \(\eta>0\),

\[
\boxed{
W_1(\mathcal L(X),\mathcal L(Y))
\le
a
+
C\frac b\eta
+
C\eta
+
C\frac{M_2}{R}
+
C\delta R.
}
\tag{7.2}
\]

### Proof

By Kantorovich--Rubinstein duality it is enough to consider a real 1-Lipschitz function \(\phi\) with

\[
\phi(0)=0.
\]

Then

\[
|\phi(x)|\le|x|.
\]

Clip the **value** at level \(R\):

\[
\phi_R(x)
=
[-R]\vee\phi(x)\wedge R.
\]

Then \(\phi_R\) remains 1-Lipschitz and

\[
\|\phi_R\|_\infty\le R.
\]

Moreover,

\[
|\phi(x)-\phi_R(x)|
\le
(|x|-R)_+.
\]

Since

\[
(|x|-R)_+
\le
\frac{x^2}{R},
\]

\[
E|\phi(X)-\phi_R(X)|
+
E|\phi(Y)-\phi_R(Y)|
\le
\frac{M_2}{R}.
\tag{7.3}
\]

Now mollify in the argument with a standard Gaussian \(Z\):

\[
\phi_{R,\eta}(x)
=
E_Z[\phi_R(x+\eta Z)].
\]

Because \(\phi_R\) is 1-Lipschitz,

\[
\|\phi_{R,\eta}'\|_\infty\le1,
\]

\[
\boxed{
\|\phi_{R,\eta}''\|_\infty
\le
C\eta^{-1},
}
\tag{7.4}
\]

and

\[
\|\phi_{R,\eta}\|_\infty\le R.
\]

Also

\[
\sup_x
|\phi_{R,\eta}(x)-\phi_R(x)|
\le
\eta E|Z|
\le
C\eta.
\tag{7.5}
\]

Apply (7.1) to \(\phi_{R,\eta}\), then use (7.3)--(7.5).

This gives (7.2).

QED.
