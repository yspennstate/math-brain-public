# 6. Wasserstein interpolation lemma

Let \(X,Y\) be real random variables.

Assume

\[
W_1(\mathcal L(X),\mathcal L(Y))
\le\delta
\]

and, for some fixed \(q>p\ge1\),

\[
E|X|^q+E|Y|^q\le M_q.
\]

Then:

## `P21-WASS-INTERP-17` — PROVED

\[
\boxed{
W_p(
\mathcal L(X),
\mathcal L(Y)
)
\le
C_{p,q,M_q}
\delta^{\theta},
}
\tag{6.1}
\]

where

\[
\boxed{
\theta
=
\frac{q-p}{p(q-1)}.
}
\tag{6.2}
\]

### Proof

On \(\mathbb R\), an optimal \(W_1\) coupling exists for finite first moments.

Let \((\widetilde X,\widetilde Y)\) be such a coupling and set

\[
D=|\widetilde X-\widetilde Y|.
\]

Then

\[
\|D\|_1
=
W_1(
\mathcal L(X),
\mathcal L(Y)
)
\le\delta.
\]

For every coupling,

\[
E D^q
\le
2^{q-1}
\left(
E|X|^q+E|Y|^q
\right)
\le
2^{q-1}M_q.
\]

Hence

\[
\|D\|_q\le C_qM_q^{1/q}.
\]

Real interpolation of \(L^r\) norms gives

\[
\|D\|_p
\le
\|D\|_1^\theta
\|D\|_q^{1-\theta},
\]

where

\[
\frac1p
=
\frac{\theta}{1}
+
\frac{1-\theta}{q}.
\]

Solving gives (6.2).

Since \(W_p\) is the infimum of the \(L^p\) coupling cost,

\[
W_p
\le
\|D\|_p.
\]

This proves (6.1).

QED.
