# 6. A fixed-\(p\) block-martingale lemma

This is the main new probabilistic step.

\[

\]

\[

Let \(B_i'\) be an independent copy and let \(Z^{(i)}\) denote \(Z\) with only \(B_i\) replaced by \(B_i'\).

Assume, for one fixed \(p\ge2\),

\[
\boxed{
\|Z-Z^{(i)}\|_{L^p}
\le
b_i.
}
\tag{6.1}

Let

\[
\mathcal G_i
=
\sigma(F,B_1,\ldots,B_i)

\[

\[

=
E[
Z-Z^{(i)}
\mid
\mathcal G_i

\[
\|D_i\|_p
\le
b_i.
\tag{6.2}

The scalar Burkholder inequality gives

\[
\left\|
\sum_{i=1}^nD_i
\right\|_p

\left(
\sum_{i=1}^nD_i^2

\sum_iD_i^2
\right\|_{p/2}

\tag{6.4}
