# 3. Exact restricted Target-1 model and normalization

Let

`F=[f_1,...,f_m] in R^(d x m)`,

with iid entries `N(0,1/d)`. Assume

`n/d -> alpha>0`, `m/d -> beta>0`.

For original sample `i`, let

`a_i, z_i1, z_i2 ~ iid N(0,I_d)`,

`t_i = xi^T a_i`, `||xi||=1`.

The actual rows are

`x_ij^A = sigma(F^T(a_i + Delta z_ij))`, `j=1,2`.

The matched Gaussian rows are

`x_ij^G = mu_e F^T a_i + mu_b F^T z_ij + mu_2 b_i + mu_3 p_ij`,

with `a_i,b_i` shared across the two views and `z_ij,p_ij` view-private.

There are exactly

`N=2n`

augmented rows. The objective is

`L_M(w) = (1/(2N)) sum_{i=1}^n sum_{j=1}^2 (t_i - (x_ij^M)^T w)^2 + (lambda/2)||w||^2`,

for `M=A` or `G`.

The Lindeberg replacement unit is therefore the entire original-sample block

`(t_i, x_i1, x_i2)`.

Deleting both current rows gives

`H_- = lambda I + (1/N) X_-^T X_-`,

`B = H_-^(-1)`,

with

`||B||op <= 1/lambda`.

Let `w_-` be the leave-block optimizer and define

`X_i = [x_i1^T ; x_i2^T] in R^(2 x m)`,

`e_i = t_i 1_2 - X_i w_-`,

`L_i* - L_-* = (1/(2N)) e_i^T (I_2+Q_i)^(-1) e_i`.

This formula is pathwise. It already contains the decisive `1/N` normalization.

# 4. New theorem `P21-HERMITE-RADIAL-BLOCK-45`

## 4.1 Statement

Put

`tau = sqrt(1+Delta^2)`.

For each feature column write

`f_r = R_r theta_r`,

where `R_r=||f_r||` and `theta_r` is uniform on `S^(d-1)`, independent of `R_r`.

Let `G~N(0,1)` and define

`kappa(r) = E sigma'(tau r G)`,

`mu = kappa(1)`.

For every leave-original-sample hybrid, with leave optimizer `w` satisfying the inherited ridge delocalization

`sup_r E|w_r|^4 <= C d^(-2)`

and `E||w||^4<=C`, the actual and matched-Gaussian current blocks satisfy, uniformly for view indices `a,b in {1,2}`,

`E | w^T (Sigma_A^(ab)-Sigma_G^(ab)) w | <= C d^(-1/2)`,

and

`E | Cov_A(t, x_a^T w |F,w) - Cov_G(t,x_a^T w|F,w) | <= C d^(-1/2)`.

Moreover, if a second leave-environment vector `v` obeys

`sup_r E|v_r|^4 <= C d^(-2)`, `E||v||^4<=C`,

then the same estimate holds bilinearly:

`E | w^T (Sigma_A^(ab)-Sigma_G^(ab)) v | <= C d^(-1/2)`

and for the teacher cross term with `v`.

Here `Sigma_M^(ab)=E[x_a^M (x_b^M)^T | F, leave environment]`.

The proof below is exact enough to display every dimension factor.

## 4.2 Hermite expansion at the random feature radius

Let `h_k` be the orthonormal probabilists' Hermite polynomials and define

`c_k(r)=E[sigma(tau r G) h_k(G)]`.

Oddness of `sigma` gives

`c_k(r)=0` for every even `k`.

Gaussian integration by parts gives

`c_1(r)=E[G sigma(tau rG)] = tau r kappa(r)`.

For two distinct feature columns `r!=s`, let

`rho_rs = theta_r^T theta_s`.

For one view, the standardized Gaussian preactivation correlation is exactly `rho_rs`. Across the two views, only the shared `a_i` contributes to the cross covariance, so the standardized correlation is exactly

`rho_rs/tau^2`.

Mehler's formula therefore gives, for `r!=s`,

`Sigma_A^same(r,s) = sum_{k odd>=1} c_k(R_r)c_k(R_s) rho_rs^k`,

`Sigma_A^cross(r,s) = sum_{k odd>=1} c_k(R_r)c_k(R_s) (rho_rs/tau^2)^k`.

The `k=1` pieces are exactly

`tau^2 kappa(R_r)kappa(R_s) f_r^T f_s`

for the same view, and

`kappa(R_r)kappa(R_s) f_r^T f_s`

for different views.

The source Gaussian coefficients satisfy, by Stein,

`mu_e = mu`, `mu_b = Delta mu`,

so `mu_e^2+mu_b^2=tau^2 mu^2`.

Thus the Gaussian surrogate has the corresponding linear covariance pieces

`tau^2 mu^2 F^T F`

and

`mu^2 F^T F`.

## 4.3 Exact cubic off-diagonal Hermite debt

Let `H_off` denote the sum of Hermite orders `k>=3`, with zero diagonal.

Parseval and boundedness of `sigma` give

`sum_k c_k(r)^2 <= ||sigma||_infty^2`.

Hence, for either same-view or cross-view covariance,

`|H_off(r,s)| <= ||sigma||_infty^2 |rho_rs|^3`, `r!=s`.

For independent uniform directions on the sphere, rotational invariance gives the exact sixth moment

`E rho_rs^6 = 15/[d(d+2)(d+4)]`.

Therefore

`E ||H_off||F^2 <= C m(m-1) d^(-3) = O(d^(-1))`

because `m=Theta(d)`.

This is the first decisive dimension audit. There are `Theta(d^2)` off-diagonal feature pairs, but oddness removes Hermite order two and the first unmatched term is cubic. Squaring before summing produces the exact `d^2 * d^(-3)=d^(-1)` balance.

A naive pair count without the cubic Hermite structure would lose this factor and can falsely suggest an order-one or divergent error.

## 4.4 Random-radius debt

Let

`S=F^T F`,

`D_kappa = diag(kappa(R_1),...,kappa(R_m))`,

`D_delta = D_kappa - mu I`.

Because `sigma''` is bounded,

`|kappa(r)-mu| <= C |r-1|`.

For a Gaussian feature column, `R_r^2=(1/d) chi_d^2`, and therefore

`E|R_r-1|^2=O(d^(-1))`,

`E|R_r-1|^4=O(d^(-2))`.

Consequently

`E|kappa(R_r)-mu|^2=O(d^(-1))`,

`E|kappa(R_r)-mu|^4=O(d^(-2))`.

The exact linear covariance mismatch is

`tau^2(D_kappa S D_kappa - mu^2 S)`

for the same view, and

`D_kappa S D_kappa - mu^2 S`

for the cross view.

Expand

`D_kappa S D_kappa - mu^2 S`

as

`mu(D_delta S + S D_delta) + D_delta S D_delta`.

The diagonal Hermite remainder must also be retained. Define

`h_same(r) = E sigma(tau rG)^2 - tau^2 r^2 kappa(r)^2`,

and, for independent standard `Z,V1,V2`,

`h_cross(r) = E[sigma(r(Z+Delta V1)) sigma(r(Z+Delta V2))] - r^2 kappa(r)^2`.

The matched Gaussian residual variances/covariances are exactly `h_same(1)` and `h_cross(1)`. Bounded `sigma,sigma',sigma''` imply a polynomial Lipschitz bound

`|h(r)-h(1)| <= C(1+r)|r-1|`,

so

`E|h(R_r)-h(1)|^2 = O(d^(-1))`.

Putting the pieces together gives the exact matrix decomposition

`DeltaSigma = a[D_kappa S D_kappa - mu^2 S] + H_off + diag(h(R_r)-h(1))`,

where `a=tau^2` for the same view and `a=1` for the cross view, with the corresponding `h`.

## 4.5 Why the Frobenius norm alone is not the target estimate

The radial matrix term is generally only `O_L2(1)` in Frobenius norm:

`E||D_delta S||F^2 = O(1)`.

Thus a global covariance-matrix universality statement at `d^(-1/2)` Frobenius scale is neither available nor needed.

The optimized block sees only low-dimensional projections of this matrix, and ridge delocalization supplies the missing factor.

Indeed,

`E||D_delta w||^2`

is bounded by

`sum_r (E|w_r|^4)^(1/2) (E|kappa(R_r)-mu|^4)^(1/2) = O(d^(-1))`.

Since `||S||op=O_Lq(1)` for each fixed `q`, and `E||w||^4<=C`, Cauchy-Schwarz gives

`E|w^T D_delta S w| = O(d^(-1/2))`,

`E|w^T S D_delta w| = O(d^(-1/2))`,

and

`E|w^T D_delta S D_delta w| = O(d^(-1))`.

For the diagonal radial remainder,

`E |sum_r w_r^2 [h(R_r)-h(1)]|`

is at most

`sum_r (E|w_r|^4)^(1/2) (E|h(R_r)-h(1)|^2)^(1/2)`

which is

`m * O(d^(-1)) * O(d^(-1/2)) = O(d^(-1/2))`.

For the cubic Hermite remainder,

`|w^T H_off w| <= ||w||^2 ||H_off||F`,

so

`E|w^T H_off w| = O(d^(-1/2))`.

This proves the quadratic feature covariance assertion.

## 4.6 Teacher-feature covariance

For one actual feature coordinate, Gaussian Stein in the shared `a_i` gives exactly

`E[t sigma(f_r^T(a+Delta z)) |F] = (xi^T f_r) kappa(R_r)`.

The matched Gaussian covariance is

`mu (xi^T f_r)`.

Hence the projected teacher mismatch is

`xi^T F D_delta w`.

By Cauchy-Schwarz,

`E|xi^T F D_delta w| <= (E||F^T xi||^2)^(1/2) (E||D_delta w||^2)^(1/2) = O(d^(-1/2))`.

This treats the teacher scalar jointly with the two views. It is not a marginal-only feature comparison.

## 4.7 Bilinear extension

If `v` has the same coordinate fourth-moment delocalization as `w`, then

`E||D_delta v||^2=O(d^(-1))`.

The linear radial terms are therefore `O(d^(-1/2))` in `w^T DeltaSigma v`.

For the diagonal remainder,

`E|w_r v_r [h(R_r)-h(1)]|`

is at most

`(E w_r^2 v_r^2)^(1/2) (E|h(R_r)-h(1)|^2)^(1/2)`.

Since

`E w_r^2 v_r^2 <= (Ew_r^4 Ev_r^4)^(1/2)=O(d^(-2))`,

each coordinate costs `O(d^(-3/2))`, and the `m=Theta(d)` sum is `O(d^(-1/2))`.

The cubic Hermite remainder is again bounded by its Frobenius norm and bounded fourth moments of `||w||,||v||`.

This proves `P21-HERMITE-RADIAL-BLOCK-45`.

# 5. New theorem `P21-LEVERAGE-MEAN-MATCH-45`

The optimized-value increment depends on the random two-by-two leverage

`Q=(1/N) X B X^T`.

This section proves that the actual and surrogate leverage means match at `O(d^(-1/2))`, and that each leverage freezes around its own conditional mean at the same scale.

## 5.1 Mean leverage matching

Condition on the leave-block environment, including `F` and `B`. For view indices `a,b`,

`barQ_ab^M = E[Q_ab^M | leave] = (1/N) Tr(B Sigma_M^(ab))`.

From the decomposition in Section 4,

`E||Sigma_A^(ab)-Sigma_G^(ab)||F^2 = O(1)`.

The potentially largest part is the radial linear matrix, whose Frobenius norm is only order one; the diagonal remainder is order one in squared Frobenius norm; the cubic Hermite remainder is smaller, `O(d^(-1))` in squared Frobenius norm.

Using `||B||op<=lambda^(-1)` and `m=Theta(d)`,

`|(1/N)Tr(B DeltaSigma)| <= [sqrt(m)/(N lambda)] ||DeltaSigma||F`.

Thus

`E|barQ_ab^A-barQ_ab^G| = O(d^(-1/2))`.

This is a useful separation of scales: covariance matrices need not be `d^(-1/2)`-close in Frobenius norm, yet the normalized ridge leverage means are.

## 5.2 Joint leverage freezing and the real dimension factor

For an actual current block,

`Q_ab=(1/N) x_a^T B x_b`.

Differentiate jointly with respect to the **entire shared current Gaussian latent** `(a,z_1,z_2)`. Because `sigma'` is bounded,

`||F||op=O_Lq(1)`,

`||B||op<=lambda^(-1)`,

and for bounded activation `||x_a||<=||sigma||infty sqrt(m)`, one gets

`||grad Q_ab|| <= C ||F||op sqrt(m)/N`.

The derivative with respect to the shared `a` is taken once and includes both views; it is not duplicated as if the views were independent.

Gaussian Poincare therefore gives

`E|Q_ab-barQ_ab|^2 = O(m/N^2)=O(d^(-1))`.

The surrogate block has the same bound when its shared and private Gaussian sources are differentiated jointly.

Since `Q` is positive semidefinite,

`A(Q)=(I_2+Q)^(-1)`

satisfies

`||A(Q)||op<=1`

and the resolvent identity gives

`||A(Q)-A(Q0)||op <= ||Q-Q0||op`.

Thus

`E||A(Q)-A(barQ)||F^2=O(d^(-1))`.

No `dm`, `m`, or `m^2` derivative loss appears. The true gradient scale is `sqrt(m)/N=O(d^(-1/2))`.

## 5.3 Freezing the residual statistic

Let

`e=t 1_2-Xw`.

Conditional on `F,w`, each actual projection `w^T sigma(F^T(a+Delta z))` is a centered Gaussian-Lipschitz function with Lipschitz constant

`<= C ||F||op ||w||`.

The Gaussian surrogate projection is Gaussian with bounded conditional variance. Hence

`E||e||^4 <= C`

uniformly along the hybrid chain.

Cauchy-Schwarz yields

`E| e^T[A(Q)-A(barQ)]e | = O(d^(-1/2))`.

The actual and surrogate frozen inverse leverages differ by `O(d^(-1/2))` because their mean `Q` matrices do. For a frozen deterministic two-by-two matrix `Abar`,

`E[e^T Abar e | leave] = Tr(Abar C_e)`,

where `C_e=E[e e^T|leave]`.

Section 4 gives

`E||C_e^A-C_e^G||F = O(d^(-1/2))`.

Therefore

`| E[e_A^T A(Q_A)e_A] - E[e_G^T A(Q_G)e_G] | = O(d^(-1/2))`.

This proves `P21-LEVERAGE-MEAN-MATCH-45`.

# 6. New theorem `P21-TOTAL-BLOCK-ALT-45`

Insert the exact Woodbury normalization only after the unscaled block comparison has been proved.

The pathwise increment is

`Delta_i = (1/(2N)) e_i^T(I_2+Q_i)^(-1)e_i`.

Section 5 proves that the actual/Gaussian difference of the unscaled bracket has conditional mean `O(d^(-1/2))`. Hence

`one original-sample replacement = O(1/(N sqrt(d)))`.

There are exactly

`n=N/2`

original-sample blocks. Therefore

`TOTAL first-order replacement debt`

is

`n * O(1/(N sqrt(d))) = O(d^(-1/2))`.

This is the required total, not a per-block number.

For a bounded-`C^2` outer test function of the optimized value, the block increment itself has second moment `O(N^(-2))`, because `||A||<=1` and the residual has bounded fourth moment. Hence the complete second-order Taylor debt is

`n * O(N^(-2)) = O(d^(-1))`.

Consequently the bounded-`C^2` law distance between the actual and correctly matched Gaussian optimized values is `O(d^(-1/2))`; the expectation statement follows by the inherited moment/truncation argument.

This independently re-certifies P04 claim `T1-TOTAL-BLOCK-LINDEBERG`.

The normalization lesson is exact:

- `O(d^(-1/2))` is the **unscaled block covariance/statistic mismatch**;
- it must first be multiplied by the objective factor `1/N`;
- only then may the `n=N/2` blocks be summed.

The incorrect arithmetic `n * O(d^(-1/2))` is not the P04 theorem and would diverge.

# 7. Separate clean-test theorem: `P21-CLEAN-HERMITE-BLOCK-45`

## 7.1 Independent matched clean ghost block

and define

The inherited theorem `P21-GHOST-DIRECTION-COL4-20` gives uniformly

and bounded moments of `||v||`.

Thus the bilinear part of `P21-HERMITE-RADIAL-BLOCK-45` applies to `(w,v)`.

## 7.2 Exact one-training-block clean-risk increment

The rank-two optimizer update is

`delta w = (1/N) B X^T A e`,

# 10. Block Lindeberg versus interpolation versus resolvents

## 10.1 Whole-block Lindeberg — preferred for the exact target

The rank-two whole-original-sample Lindeberg route is the cleanest because:

- the exact `1/N` optimized-value normalization appears pathwise before any asymptotics;
- the leave-block optimizer and inverse Hessian are independent of the current original-sample latent conditional on `F`;
- after leverage freezing the target statistic is quadratic in the three-dimensional block `(t,u_1,u_2)`;
- exact teacher Stein and exact two-view Hermite covariance matching are therefore sufficient.

There is no need to prove a strong joint CLT for the feature vector itself.

## 10.2 Source-latent interpolation — valid in principle, inefficient here

A smooth interpolation of the current nonlinear source block would differentiate the rank-two inverse leverage and reproduce the same fixed-rank stability estimates, while also introducing higher derivative terms of `sigma` and the optimizer response. A coordinate-by-coordinate interpolation is worse: it risks paying feature multiplicities before the Hermite cancellation is visible.

The Hermite-radial calculation is effectively the exact covariance-level interpolation certificate specialized to the only moments the quadratic target uses.

## 10.3 Resolvents — local and indispensable, global universality unnecessary

Resolvents are essential locally:

- `B=H_-^(-1)` gives `||B||<=lambda^(-1)`;
- rank-two Woodbury gives the exact block increment;
- `A(Q)=(I_2+Q)^(-1)` is one-Lipschitz in `Q` on the positive semidefinite cone.

A global nonlinear Gram resolvent universality theorem is not needed. In fact the radial covariance matrix mismatch can remain order one in Frobenius norm, while every normalized/probed scalar entering the objective and clean risk is `O(d^(-1/2))`.

## 10.4 Why a naive strong CLT is the wrong target

Retained P21 counterexamples already show:

- one actual `tanh` feature coordinate is bounded while the matched Gaussian coordinate has Gaussian tails, so coordinatewise total-variation Gaussianization is false;
- the actual plus/minus view coordinates can be uncorrelated but dependent, whereas the matched Gaussian plus/minus coordinates are conditionally independent.

The present proof succeeds precisely because the optimized quadratic target uses only a fixed collection of low-order teacher/two-view moments after rank-two stability. It does not require those false stronger statements.
