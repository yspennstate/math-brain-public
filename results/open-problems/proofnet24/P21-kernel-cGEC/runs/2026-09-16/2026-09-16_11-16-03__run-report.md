# 4. New theorem `P21-SURROGATE-HERMITE-PSD-47`

This theorem proves directly that the source residual variances `mu_2^2` and `mu_3^2` are nonnegative and identifies exactly what chaos they contain.

## 4.1 Hermite setup

Put

`tau=sqrt(1+Delta^2)`,

and let `G~N(0,1)`. Define the one-dimensional activation

`psi(G)=sigma(tau G)`.

Because `sigma` is bounded, `psi` belongs to `L^2(N(0,1))`. Expand it in the orthonormal probabilists' Hermite basis:

`psi(G) = sum_{k>=0} c_k h_k(G)`,

where

`c_k=E[psi(G) h_k(G)]`.

Oddness of `sigma` implies

`c_k=0` for every even `k`, including `c_0=0`.

Let

`V=E sigma(z+Delta v)^2 = sum_{k odd} c_k^2`.

For two views

`U_1=z+Delta v_1`,

`U_2=z+Delta v_2`,

the standardized pair

`G_j=U_j/tau`

has correlation

`rho=1/tau^2`.

Because `Delta>0`, `0<rho<1`.

Mehler's formula gives the exact two-view covariance

`C:=E[sigma(U_1)sigma(U_2)] = sum_{k odd} c_k^2 rho^k`.

## 4.2 First-chaos coefficient

Gaussian integration by parts gives

`c_1 = E[G sigma(tau G)] = tau E sigma'(tau G)`.

For the source coefficients, joint Gaussian Stein gives

`mu_e=E[z sigma(z+Delta v)] = E sigma'(z+Delta v)`,

`mu_b=E[v sigma(z+Delta v)] = Delta E sigma'(z+Delta v)`.

Therefore

`c_1=tau mu_e`,

and

`mu_b=Delta mu_e`.

Since `rho=1/tau^2`,

`mu_e^2 = c_1^2 rho`.

Also

`mu_b^2 = Delta^2 mu_e^2 = c_1^2 (1-rho)`.

## 4.3 Exact nonnegative residual formulas

Because `mu_0=0`, the source definition gives

`mu_2^2=C-mu_e^2`.

Substituting the Hermite expansion and cancelling the `k=1` term,

`mu_2^2 = sum_{k odd, k>=3} c_k^2 rho^k >= 0`.

Likewise,

`mu_3^2=V-C-mu_b^2`.

Now

`V-C = c_1^2(1-rho) + sum_{k odd, k>=3} c_k^2(1-rho^k)`.

The first term is exactly `mu_b^2`, hence

`mu_3^2 = sum_{k odd, k>=3} c_k^2 (1-rho^k) >= 0`.

Thus the two residual square roots in the source Gaussian formulation are not merely formally defined. They are exact nonnegative higher-odd-chaos energies.

The decomposition also yields the exact identities

`mu_e^2+mu_2^2 = C`,

`mu_b^2+mu_3^2 = V-C`.

Interpretation:

- `mu_e` is the shared first chaos carried by the original latent;
- `mu_b` is the private first chaos carried by the augmentation noise;
- `mu_2` is the shared higher odd chaos;
- `mu_3` is the private higher odd chaos.

This proves `P21-SURROGATE-HERMITE-PSD-47`.

# 5. New theorem `P21-SURROGATE-GAUSSIAN-UNIQUENESS-47`

The source residual split is uniquely forced, up to irrelevant signs, by first-chaos matching plus the two-view second moments.

Consider any centered linear Gaussian pair of the source dependence form

`q_j = a A + b Z_j + c B + d P_j`, `j=1,2`,

where

- `A,B` are shared standard Gaussians;
- `Z_1,Z_2,P_1,P_2` are private iid standard Gaussians;
- all six sources are independent except for the explicit sharing.

Suppose the shared original-latent first-chaos coefficient and private augmentation first-chaos coefficient are required to match the nonlinear feature:

`a=mu_e`,

`b=mu_b`.

Suppose also that the Gaussian pair must match the ideal-radius same-view and cross-view second moments:

`Var(q_j)=V`,

`Cov(q_1,q_2)=C`.

Then

`Cov(q_1,q_2)=a^2+c^2=C`,

so

`c^2=C-mu_e^2=mu_2^2`.

Also

`Var(q_j)=a^2+b^2+c^2+d^2=V`.

Using `a^2+c^2=C`,

`d^2=V-C-b^2=mu_3^2`.

Therefore any Gaussian surrogate with the source sharing pattern and the correct first-chaos coefficients is forced to have

`|c|=mu_2`,

`|d|=mu_3`.

The signs of `c,d` do not matter because `B,P_j` are symmetric Gaussian sources. Hence the law is unique.

This is a precise reason the shared `b_i` term cannot be deleted or made view-private. Doing so would set the higher-chaos shared variance to zero and would fail to match `C` whenever `mu_2^2>0`.

For `tanh` and every fixed `Delta>0`, higher odd Hermite energy is nonzero, so the residual decomposition is nontrivial.

This proves `P21-SURROGATE-GAUSSIAN-UNIQUENESS-47`.

# 6. New theorem `P21-PARITY-CHANNEL-MATCH-47`

The two-view covariance is clearest in the plus/minus basis.

Define

`X_+=(X_1+X_2)/sqrt(2)`,

`X_-=(X_1-X_2)/sqrt(2)`.

For one ideal-radius nonlinear coordinate,

`Var(X_1)=Var(X_2)=V`,

`Cov(X_1,X_2)=C`.

Therefore exactly

`Var(X_+)=V+C`,

`Var(X_-)=V-C`,

`Cov(X_+,X_-)=0`.

If the teacher scalar is the shared Gaussian source `z` in this one-dimensional calculation, then

`Cov(z,X_1)=Cov(z,X_2)=mu_e`.

Hence

`Cov(z,X_+)=sqrt(2) mu_e`,

`Cov(z,X_-)=0`.

Now transform the matched Gaussian pair. Using the source decomposition,

`q_+ = sqrt(2) mu_e A + sqrt(2) mu_2 B + mu_b (Z_1+Z_2)/sqrt(2) + mu_3(P_1+P_2)/sqrt(2)`,

`q_- = mu_b (Z_1-Z_2)/sqrt(2) + mu_3(P_1-P_2)/sqrt(2)`.

Thus

`Var(q_+) = 2(mu_e^2+mu_2^2) + (mu_b^2+mu_3^2)`

`           = 2C + (V-C) = V+C`,

while

`Var(q_-)=mu_b^2+mu_3^2=V-C`.

The shared sources cancel exactly from the minus channel, so

`Cov(A,q_-)=0`,

while

`Cov(A,q_+)=sqrt(2) mu_e`.

Thus the actual and Gaussian pairs have exactly the same ideal-radius second moments jointly with the teacher scalar in the parity basis.

Crucially, this does **not** say the nonlinear plus/minus variables are independent. Earlier P21 work rigorously disproved that stronger statement. The Gaussian surrogate has independent parity channels because it is jointly Gaussian; the nonlinear pair generally has dependent but uncorrelated parity channels. The squared-ridge target only needs the second-moment content after rank-two leverage freezing, which is why the weaker exact matching is sufficient.

## 12.2 Moment-space interpolation

## 12.3 Resolvents
