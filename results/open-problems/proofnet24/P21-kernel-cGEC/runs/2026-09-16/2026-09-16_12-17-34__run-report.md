# 4. `P21-FINITEF-HERMITE-SCHUR-48` — exact finite-feature matrix factorization

This section is the main new theorem of the run.

## 4.1 Radius/direction decomposition

Write the Gaussian feature columns as

```text
f_r = R_r theta_r,
R_r = ||f_r||,
||theta_r||=1,
r=1,...,m.
```

For iid `N(0,I_d/d)` columns:

- `R_r^2 = chi_d^2/d`;
- `theta_r` is uniform on the unit sphere;
- radius and direction are independent;
- the columns are independent.

Define

```text
tau = sqrt(1+Delta^2),
rho = 1/tau^2.
```

Conditional on `F`, define standardized logits

```text
G_jr = f_r^T(a+Delta z_j)/(tau R_r).
```

Then each `G_jr` is standard normal and, with

```text
Theta_rs = theta_r^T theta_s,
```

we have exactly

```text
Corr(G_jr,G_js | F)   = Theta_rs,
Corr(G_1r,G_2s | F)   = rho Theta_rs.
```

The second identity is the algebraic footprint of the shared latent `a`: the private noises disappear from the cross-view covariance.

## 4.2 Radius-dependent Hermite coefficients

Let `{h_k}` be the orthonormal probabilists' Hermite basis in `L^2(N(0,1))`. For each radius `r>0`, expand

```text
sigma(tau r G) = sum_{k>=0} c_k(r) h_k(G).
```

Because `sigma` is odd,

```text
c_k(r)=0 for every even k.
```

For realized feature radius `R_r`, write

```text
c_{k,r}=c_k(R_r),
D_k=diag(c_{k,1},...,c_{k,m}).
```

Mehler's identity gives, entry by entry,

```text
E[x_1r x_1s | F]
 = sum_{k odd} c_{k,r} c_{k,s} Theta_rs^k,
```

and

```text
E[x_1r x_2s | F]
 = sum_{k odd} c_{k,r} c_{k,s} (rho Theta_rs)^k.
```

Therefore, as exact `m x m` matrices,

```text
Sigma_same
 = sum_{k odd} D_k Theta^{circ k} D_k,
```

```text
Sigma_cross
 = sum_{k odd} rho^k D_k Theta^{circ k} D_k.
```

Here `Theta^{circ k}` is the entrywise `k`th power.

## 4.3 Exact PSD structure

`Theta` is a correlation Gram matrix and hence positive semidefinite. By repeated Schur product,

```text
Theta^{circ k} is PSD for every positive integer k.
```

Consequently every matrix

```text
D_k Theta^{circ k} D_k
```

is PSD, even though `D_k` can have signed diagonal entries.

Thus `Sigma_same` and `Sigma_cross` are sums of explicit PSD chaos sectors. More importantly, the view-parity covariance matrices are

```text
Sigma_plus  = Sigma_same + Sigma_cross
            = sum_{k odd}(1+rho^k) D_k Theta^{circ k} D_k,
```

```text
Sigma_minus = Sigma_same - Sigma_cross
            = sum_{k odd}(1-rho^k) D_k Theta^{circ k} D_k.
```

Both are manifestly PSD. This gives an exact finite-`d`, finite-`m` explanation of the plus/minus covariance structure without asserting nonlinear plus/minus independence.

## 4.4 Exact teacher coupling

Define

```text
kappa(r)=E sigma'(tau r G).
```

Gaussian integration by parts gives

```text
c_1(r)=tau r kappa(r).
```

For the unit linear teacher `t=xi^T a`, joint Gaussian regression yields

```text
E[t x_jr | F]
 = Cov(t,G_jr|F) * E[G sigma(tau R_r G)]
 = [(xi^T f_r)/(tau R_r)] * c_1(R_r)
 = (xi^T f_r) kappa(R_r).
```

Thus the exact teacher-feature covariance vector is

```text
g_A = D_kappa F^T xi,
D_kappa=diag(kappa(R_1),...,kappa(R_m)).
```

The teacher-minus covariance vanishes exactly and the teacher-plus covariance is `sqrt(2) g_A`.

This proves `P21-FINITEF-HERMITE-SCHUR-48`.

# 5. `P21-COVARIANCE-DEBT-DECOMPOSITION-48` — exact actual/surrogate split

The finite-feature factorization allows the actual-minus-surrogate mismatch to be written without a generic CLT.

## 5.1 Unit-radius source constants

Put

```text
mu = kappa(1).
```

For odd activation the source first-chaos coefficients satisfy

```text
mu_e = mu,
mu_b = Delta mu.
```

Define the radius-dependent same-view and cross-view variances

```text
V(r)=E sigma(tau r G)^2,
```

```text
C(r)=E[sigma(tau r G_1) sigma(tau r G_2)],
Corr(G_1,G_2)=rho.
```

At unit radius write `V=V(1)`, `C=C(1)`.

The predecessor's exact Hermite certificate gives

```text
mu_2^2 = C - mu^2,
mu_3^2 = V - C - Delta^2 mu^2,
```

and hence

```text
mu_2^2+mu_3^2 = V - tau^2 mu^2.
```

## 5.2 First chaos in matrix form

Let

```text
S=F^T F,
D=diag(kappa(R_1),...,kappa(R_m)).
```

Because `c_1(R_r)=tau R_r kappa(R_r)`, the exact first-chaos same-view matrix is

```text
tau^2 D S D.
```

The exact first-chaos cross-view matrix is

```text
D S D,
```

because the factor `rho=tau^-2` cancels `tau^2`.

Define the scalar residual functions

```text
a(r)=V(r)-tau^2 r^2 kappa(r)^2,
```

```text
b(r)=C(r)-r^2 kappa(r)^2.
```

Let `H_same` and `H_cross` be the higher-chaos matrices with **zero diagonal** and, for `r != s`,

```text
(H_same)_rs
 = sum_{k>=3, k odd} c_k(R_r)c_k(R_s) Theta_rs^k,
```

```text
(H_cross)_rs
 = sum_{k>=3, k odd} rho^k c_k(R_r)c_k(R_s) Theta_rs^k.
```

Then the actual covariances are exactly

```text
Sigma_A^same
 = tau^2 D S D
 + diag(a(R_r))
 + H_same,
```

```text
Sigma_A^cross
 = D S D
 + diag(b(R_r))
 + H_cross.
```

The matched Gaussian covariances are exactly

```text
Sigma_G^same
 = tau^2 mu^2 S + a(1) I,
```

```text
Sigma_G^cross
 = mu^2 S + b(1) I.
```

Therefore, if

```text
M_rad = D S D - mu^2 S,
```

then

```text
DeltaSigma_same
 = tau^2 M_rad
 + diag(a(R_r)-a(1))
 + H_same,
```

```text
DeltaSigma_cross
 = M_rad
 + diag(b(R_r)-b(1))
 + H_cross.
```

This is an **exact identity**, not an asymptotic expansion.

# 6. Dimension audit of every covariance debt

## 6.1 Entire higher-odd-chaos off-diagonal tail is `O_L2(d^-1/2)`

Let `M0=||sigma||_infty`. Parseval gives, for every radius,

```text
sum_k c_k(r)^2 = E sigma(tau r G)^2 <= M0^2.
```

For `r != s`, since `|Theta_rs|<=1`, Cauchy-Schwarz gives

```text
|(H_same)_rs|
 <= |Theta_rs|^3
    [sum_{k>=3} c_k(R_r)^2]^(1/2)
    [sum_{k>=3} c_k(R_s)^2]^(1/2)
 <= M0^2 |Theta_rs|^3.
```

Similarly,

```text
|(H_cross)_rs| <= M0^2 rho^3 |Theta_rs|^3.
```

For independent uniform directions on `S^{d-1}`,

```text
E Theta_rs^6 = 15/[d(d+2)(d+4)].
```

Therefore

```text
E||H_same||_F^2
 <= M0^4 m(m-1) 15/[d(d+2)(d+4)]
 = O(d^-1),
```

because `m/d -> beta`.

Hence

```text
||H_same||_F = O_L2(d^-1/2),
||H_cross||_F = O_L2(d^-1/2).
```

This controls **all** odd Hermite orders `k>=3` simultaneously. The `m^2` pair count has been displayed explicitly and is exactly compensated by the sixth angular moment. A proof that bounds each feature pair by `O(d^-1/2)` before exploiting the cubic Hermite power would lose a fatal dimension factor.

## 6.2 Radial covariance debt is only `O_L2(1)` in Frobenius norm

Set

```text
delta_r = kappa(R_r)-mu.
```

Bounded `sigma''` implies `kappa` is Lipschitz. Gaussian radius concentration gives, for every fixed `q`,

```text
E|R_r-1|^q = O(d^-q/2),
E|delta_r|^q = O(d^-q/2).
```

Expand

```text
M_rad
 = mu(D_delta S + S D_delta)
 + D_delta S D_delta,
```

where `D_delta=diag(delta_r)`.

For `r != s`, write `S_rs=R_r R_s Theta_rs`. Radius/direction independence gives

```text
E |(M_rad)_rs|^2 = O(d^-2).
```

There are `m(m-1)=Theta(d^2)` such entries, so the off-diagonal Frobenius-square contribution is only `O(1)`, not `o(1)`.

For `r=s`,

```text
(M_rad)_rr = R_r^2 [kappa(R_r)^2-mu^2],
```

whose square has expectation `O(d^-1)`. Summing `m=Theta(d)` diagonal entries again gives `O(1)`.

Thus

```text
E||M_rad||_F^2 = O(1).
```

The functions `a(r)` and `b(r)` are locally Lipschitz with polynomially bounded derivatives under the present bounded-smooth activation assumptions. The Gaussian radius moments therefore give

```text
E sum_r |a(R_r)-a(1)|^2 = O(1),
E sum_r |b(R_r)-b(1)|^2 = O(1).
```

So the complete radial part of `DeltaSigma` has Frobenius scale `O_L2(1)`.

**Consequence.** A naive claim of global covariance-matrix Frobenius convergence at rate `d^-1/2` is false as a proof strategy. The theorem needs only normalized/probed covariance functionals, where ridge structure supplies the missing factor.

## 6.3 Delocalized ridge probes recover `d^-1/2`

The inherited ridge-coordinate theorem gives, uniformly along the whole-original-sample hybrid chain,

```text
sup_r E|w_r|^4 <= C d^-2.
```

The clean ghost/sensitivity direction `v` satisfies the same type of bound when it is used below.

First,

```text
E||D_delta w||^2
 = sum_r E[delta_r^2 w_r^2]
 <= sum_r (E delta_r^4)^(1/2)(E w_r^4)^(1/2)
 = m * O(d^-1)*O(d^-1)
 = O(d^-1).
```

No independence between `w_r` and the feature radius is used.

Therefore, using `||S||_op=O_Lq(1)` and bounded Euclidean moments of the ridge probes,

```text
E|w^T M_rad v| = O(d^-1/2).
```

Indeed,

```text
w^T M_rad v
 = mu[(D_delta w)^T S v + w^T S(D_delta v)]
   + (D_delta w)^T S(D_delta v).
```

The first two terms cost one `D_delta` factor and are `O(d^-1/2)`; the last has two such factors and is smaller.

For the diagonal radial terms, if `q_r=a(R_r)-a(1)` or `b(R_r)-b(1)`, then `E q_r^4=O(d^-2)`. Hence

```text
E||diag(q)w||^2
 <= sum_r (E q_r^4)^(1/2)(E w_r^4)^(1/2)
 = O(d^-1),
```

and therefore

```text
E|w^T diag(q) v| = O(d^-1/2).
```

Finally, for the higher-chaos part,

```text
|w^T H v| <= ||w|| ||v|| ||H||_F,
```

so the `O_L2(d^-1/2)` Frobenius theorem already suffices without coordinate delocalization.

Combining the three pieces proves

```text
E|w^T (Sigma_A^{ab}-Sigma_G^{ab}) v| = O(d^-1/2)
```

for every same/cross pair `a,b` relevant to the training or clean block.

This is `P21-PROBED-COVARIANCE-MATCH-48`.

## 6.4 Teacher-vector mismatch is `O_L2(d^-1/2)`

The actual teacher-feature covariance vector is

```text
g_A,r=(xi^T f_r) kappa(R_r),
```

whereas the surrogate uses

```text
g_G,r=mu (xi^T f_r).
```

Thus

```text
(g_A-g_G)_r = delta_r (xi^T f_r).
```


# 9. Block Lindeberg vs moment interpolation vs resolvents

The three useful mechanisms now have sharply separated jobs.

## 9.1 Whole-block Lindeberg

This is the **global telescope**. It is mandatory that the replacement unit be one original sample containing both augmentations and the shared teacher latent. Its exact prefactor is inherited from the rank-two optimized-value formula.

Strength: it preserves the dependence architecture and makes total error bookkeeping transparent.

Failure mode: replacing views separately destroys the cross-view covariance at order one.

## 9.2 Finite-dimensional moment interpolation

After leverage freezing, the optimized block depends only on fixed-dimensional matrices and moments. For example, for

```text
A_s=(I+Q_s)^-1,
```

and residual covariance `C_s`,

```text
d/ds Tr(A_s C_s)
 = Tr(A_s DeltaC)
   - Tr(A_s DeltaQ A_s C_s).
```

No ambient dimension appears after the endpoint moment estimates have been proved.

Strength: avoids a strong joint CLT and keeps the final comparison dimension-free.

Failure mode: interpolating the raw `dm` Gaussian source coordinates before exploiting Hermite cancellation can pay fatal multiplicities.

## 9.3 Resolvents / Woodbury

The rank-two Woodbury identity is the exact local stability engine. The map

```text
Q -> (I+Q)^-1
```

has dimension-free Lipschitz control on the PSD cone.

Strength: exact optimizer update and fixed-rank stability.

Failure mode: a global nonlinear Gram universality theorem is much stronger than necessary and sees the `O(1)` radial Frobenius debt that the target functional suppresses.

## 9.4 Why a naive CLT is not the proof

The exact Schur-Hermite theorem shows that the actual nonlinear block retains all odd chaos orders. A single `tanh` feature coordinate remains a positive total-variation distance from its Gaussian surrogate, and actual plus/minus channels need not be independent. What becomes universal is the **ridge-target functional after finite-rank stabilization and delocalized probing**, not the raw feature coordinate law.
