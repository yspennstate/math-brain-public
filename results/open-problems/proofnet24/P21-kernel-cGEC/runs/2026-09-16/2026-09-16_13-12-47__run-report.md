## 4.2 Exchange-symmetry lemma

Let

```text
J = [[0,1],[1,0]]
```

be the view-swap matrix. Conditional on the leave-block environment and `F`, the current law is invariant under simultaneous exchange of views `1 <-> 2`. Therefore, for every current-block random matrix/vector functional transformed covariantly by view exchange, its conditional mean commutes with `J`.

A real `2 x 2` matrix commuting with `J` has the form

```text
[[a,b],[b,a]].
```

Let

```text
U=(1/sqrt(2))*[[1,1],[1,-1]].
```

Then every such matrix is diagonalized by the **same** orthogonal parity transform `U`.

In particular, define conditional frozen moments

```text
Qbar = E[Q | leave,F],
C    = E[e e^T | leave,F].
```

Both commute with `J`, so

```text
U^T Qbar U = diag(q_+,q_-),
U^T C    U = diag(c_+,c_-).
```

Because `Qbar` and `C` are positive semidefinite,

```text
q_+,q_-,c_+,c_- >= 0.
```

The parity residuals are

```text
e_+ = sqrt(2)t-u_+,
e_- = -u_-,
```

where

```text
u_+ = ((x_1+x_2)/sqrt(2))^T w_-,
u_- = ((x_1-x_2)/sqrt(2))^T w_-.
```

Hence

```text
c_+ = E[e_+^2 | leave,F],
c_- = E[e_-^2 | leave,F].
```

## 5.1 Ridge coercivity gives leave-block optimizer moments

For every hybrid position, the leave-block ridge minimizer satisfies

```text
(lambda/2)||w_-||^2 <= L_-(0).
```

The zero predictor has loss equal to a normalized average of squared teacher labels. Since `t_k=xi^T a_k ~ N(0,1)` and each original label is duplicated across its two augmentation rows,

```text
L_-(0)
 <= (1/N) sum_{k != i} t_k^2.
```

All fixed moments of this normalized chi-square average are dimension-uniform. Therefore, for every fixed `p`,

```text
E||w_-||^(2p) <= C_p(lambda).
```

This holds uniformly along the whole-original-sample actual/Gaussian hybrid chain.

## 5.2 Actual nonlinear projection has dimension-free fourth moment

Fix the leave environment and `F`. For one current view define

```text
u(a,z)=w_-^T sigma(F^T(a+Delta z)).
```

Because the current Gaussian pair `(a,z)` is centered and `sigma` is odd,

```text
E[nu | leave,F]=0.
```

Its gradients are

```text
grad_a nu
 = F (w_- .* sigma'(F^T(a+Delta z))),

grad_z nu
 = Delta F (w_- .* sigma'(F^T(a+Delta z))).
```

Thus, in the full joint Gaussian source,

```text
||grad_(a,z) nu||
 <= sqrt(1+Delta^2)
    ||F||_op ||sigma'||_infty ||w_-||.
```

Gaussian concentration / Gaussian log-Sobolev therefore gives the conditional fourth-moment estimate

```text
E[|nu|^4 | leave,F]
 <= C_Delta ||sigma'||_infty^4
    ||F||_op^4 ||w_-||^4.
```

For a `d x m` Gaussian feature matrix with entries `N(0,1/d)` and `m/d -> beta`, fixed moments of `||F||_op` are uniformly bounded. Combining with ridge coercivity gives

```text
E|nu|^4 <= C.
```

There is no factor `m`: the gradient norm is taken before summing feature coordinates.

The teacher scalar satisfies `E|t|^4=3`. Hence, for each residual coordinate

```text
e_j=t-u_j,
```

and for the two-vector residual,

```text
E||e||^4 <= C.
```

## 5.3 Matched Gaussian projection has the same fourth-moment scale

Conditional on `leave,F`,

```text

```

is centered Gaussian. Its conditional variance is bounded by

```text
Var(u_j^G | leave,F)
 <= C_Delta,sigma
    (||F||_op^2+1)||w_-||^2.
```

Thus

```text
E[|u_j^G|^4 | leave,F]
 = 3 Var(u_j^G | leave,F)^2,
```

and again

```text
E||e^G||^4 <= C.
```

The current two views remain correlated through the shared `a_i,b_i`; no independence is used in this bound.

Thus the frozen training theorem requires only

```text
E[t u_+],
E[u_+^2],
E[u_-^2],
```

plus the two leverage means `q_±`.

The teacher-feature term is jointly compared using Gaussian Stein:

```text
E[t sigma(f_r^T(a+Delta z)) | F]
 = (xi^T f_r) kappa(||f_r||),
```

not by treating the teacher scalar as independent of the logit.

For feature-feature covariance, the exact finite-`F` Hermite-Schur decomposition from the predecessor gives, conditional on `F`, same-view and cross-view matrices

```text
Sigma_same  = sum_{k odd} D_k Theta^{circ k} D_k,
Sigma_cross = sum_{k odd} rho^k D_k Theta^{circ k} D_k,
```

with `rho=(1+Delta^2)^(-1)`.

Oddness removes every even chaos. After matching the first chaos, the off-diagonal remainder starts at cubic angular order. The exact sixth spherical moment

```text
E Theta_rs^6 = 15/[d(d+2)(d+4)]
```

pays for all `m^2=Theta(d^2)` feature pairs and gives higher-chaos Frobenius scale `O(d^-1/2)`. The radius debt is only `O(1)` globally in Frobenius norm, but normalized traces and the ridge/ghost coordinate fourth-moment bounds recover `O(d^-1/2)` on every target functional needed here.

This is the correct high-dimensional comparison. A raw coordinatewise CLT is both stronger than necessary and false in total variation for bounded activations such as `tanh`.

# 9. Block Lindeberg vs scalar interpolation vs resolvents

## Whole-block Lindeberg

Role: global telescope across original samples.

Correct replacement unit: both augmentations plus their shared teacher/original latent.

Exact cost:

```text
O(1/(N sqrt d)) per original sample,
O(d^-1/2) after n=N/2 samples.
```

Failure mode: viewwise replacement destroys order-one cross-view covariance.

## Parity/moment interpolation

Role: compare the frozen fixed-dimensional functional after endpoint moments are controlled.

This run sharpens the matrix interpolation further: exchange symmetry diagonalizes the entire problem into two scalar channels

```text
c_s/(1+q_s)
```

for training and

```text
2m_s/(1+q_s)+r_s c_s/(1+q_s)^2
```

for clean risk.

Strength: no ambient dimension appears in the final derivative bounds.

Failure mode: interpolating `dm` raw Gaussian source coordinates before Hermite cancellation pays feature multiplicities too early.

## Resolvent/Woodbury

Role: exact local optimizer stability and leverage freezing.

The rank-two Woodbury identity produces the exact increment; the resolvent identity

```text
A(Q)-A(Q0)=-A(Q)(Q-Q0)A(Q0)
```

provides dimension-free stability on the PSD cone.

Failure mode: proving a global nonlinear-Gram universality theorem is unnecessary and encounters the `O(1)` radial Frobenius debt.

## Why naive CLTs fail as a proof explanation

A single bounded nonlinear feature coordinate remains non-Gaussian at order one; actual plus/minus coordinates can be uncorrelated but dependent. The theorem is target-functional universality after fixed-rank stabilization, not raw feature-law universality.

## Re-derivation

P19 considers iid bounded pairs with

```text
||x_i||<=R,
||y_i||<=Y,
```

and empirical ridge moments

```text
A_N=(1/N)sum_i x_i x_i^*,
B_N=(1/N)sum_i y_i x_i^*.
```

For `Z_i^A=x_i x_i^*`,

```text
||Z_i^A||_F <= R^2,
E||A_N-A||_F^2 <= R^4/N.
```

Replacing one sample changes `A_N` by Frobenius norm at most `2R^2/N`. McDiarmid therefore gives

```text
P{||A_N-A||_F >= E||A_N-A||_F+t}
 <= exp[-N t^2/(2R^4)].
```

Taking

```text
t=R^2 sqrt(2 log(2/delta)/N)
```

and using `E||A_N-A||_F<=R^2/sqrt(N)` yields exactly the claimed

```text
||A_N-A||_F
 <= (R^2/sqrt N)[1+sqrt(2 log(2/delta))]
```

with failure probability `delta/2`. The same argument gives

```text
||B_N-B||_F
 <= (YR/sqrt N)[1+sqrt(2 log(2/delta))]
```

with the other `delta/2`.

The normal equations are

```text
C_N=B_N(A_N+lambda I)^(-1),
C_*=B(A+lambda I)^(-1).
```

Because `A_N,A` are PSD,

```text
||(A_N+lambda I)^(-1)||_op,
||(A+lambda I)^(-1)||_op <= 1/lambda.
```

The resolvent identity gives

```text
||(A_N+lambda I)^(-1)-(A+lambda I)^(-1)||_op
 <= ||A_N-A||_F/lambda^2.
```

Also `||B||_F<=YR`. Hence

```text
||C_N-C_*||_F
 <= [YR/(lambda sqrt N)]
    [1+R^2/lambda]
    [1+sqrt(2 log(2/delta))].
```

This matches P19 exactly. No independence between labels and covariates beyond iid pairs is inserted.

# 12. Preserved failed routes and new dimension audit

The following failures remain active and are not silently recycled:

1. **Viewwise replacement is invalid.** The two views share `a_i` and the surrogate also shares `b_i`; cross-view leverage is changed at order one if the block is split.
2. **Raw `n * O(d^-1/2)` accumulation is invalid.** The `O(d^-1/2)` quantity is an unscaled block bracket, and the exact optimized-value factor `1/(2N)` must be inserted first.
3. **Teacher/logit independence is false.** The teacher scalar and current feature projection share `a_i`; the relevant covariance is handled jointly by Gaussian Stein.
4. **Coordinatewise total-variation Gaussianization is false for bounded activations such as `tanh`.** The actual coordinate is bounded while the matched Gaussian coordinate has tails.
5. **Actual plus/minus independence is false in general.** Exchange symmetry gives zero mixed second moment, not product factorization.
6. **Global covariance Frobenius universality is stronger than needed and generally fails at the target rate.** Feature-radius fluctuations leave an `O(1)` Frobenius debt; normalized traces and delocalized probes recover the needed `O(d^-1/2)` target-functional scale.
7. **Ambient-coordinate interpolation before cancellation is dangerous.** Differentiating `dm` source coordinates separately can expose spurious `m`, `m^2`, or `dm` factors. The correct order is Hermite cancellation / operator norm / fixed-rank reduction first.
8. **A generic Hessian-operator `O(d^-1/2)` route for nonquadratic extensions is false under only current `L^4` delocalization.** The contracted Hessian-gradient quantity is the correct higher-order object.
9. **Generic nonquadratic quadraticization does not have an `O(N^-2)` per-block remainder.** The preserved explicit cubic counterexample has `N^-3/2` one-block scale.

This run adds a positive counterpart to item 2: the exact squared-increment estimate shows that the bounded-`C^2` Taylor debt really is `O(d^-1)` and does not hide an optimizer-dimension factor.

# 14. Exact remaining mathematical lemma and next attack

The exact requested squared-ridge theorem has no remaining mathematical dependency in this track. The formal gate is one outside audit, which P21 cannot manufacture by self-auditing again.

The next useful mathematical attack therefore remains the smooth strongly convex nonquadratic extension. The most concrete unresolved lemma is a **pathwise two-view influence bound**: if

```text
w_{tau,s}=grad F_-^*(tau X_i^T s/N),
0<=tau<=1,
```

prove a dimension-uniform cross-hat estimate of the form

```text
E sup_{tau in [0,1], ||s||<=S}
  sum_a |x_a^T H(w_{tau,s})^(-1) X_i^T s/N|^4
 <= C_S/N.
```

The basepoint version is already proved. The adaptive path is difficult because the inverse Hessian now depends on the fresh current block. The correct route should combine:

1. leave-one-original-sample conditioning;
2. feature-coordinate deletion before squaring;
3. the already-proved ridge coordinate moment hierarchy;
4. contracted Hessian-gradient Stein control rather than a raw Hessian operator norm;
5. parity-resolvent scalarization after fixed-rank stabilization.

The present exact quadratic theorem avoids this debt because its leave objective has constant Hessian.
