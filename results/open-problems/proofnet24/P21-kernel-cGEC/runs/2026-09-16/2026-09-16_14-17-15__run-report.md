# 5. New theorem: resolvent freezing without residual/leverage decoupling

## `P21-RESOLVENT-FREEZING-WITHOUT-DECOUPLING-50 — PROVED`

The point of this theorem is to avoid a subtle but unnecessary independence claim. The residual vector `e` and the leverage matrix `Q` are functions of the **same current two-view block** and therefore are not independent. One can freeze `Q` without decoupling them.

Condition on the complete leave-block environment `F_-` (including `F`, all previous hybrid blocks, and the leave optimizer). For either current-block law `M in {A,G}`, define

\[
\bar Q_M
=E[Q_M\mid\mathcal F_-],
\qquad
C_M
=E[e_Me_M^\top\mid\mathcal F_-],
\qquad
A_M^0=(I_2+\bar Q_M)^{-1}.
\]

Also put

\[
\eta_{Q,M}
=
\left(E[\|Q_M-\bar Q_M\|_{op}^2\mid\mathcal F_-]\right)^{1/2},
\]

\[
\eta_{e,M}
=
\left(E[\|e_M\|^4\mid\mathcal F_-]\right)^{1/2}.
\]

Then

\[
\boxed{
\left|
E[e_M^\top A(Q_M)e_M\mid\mathcal F_-]
-
\operatorname{Tr}(A_M^0C_M)
\right|
\le
\eta_{Q,M}\eta_{e,M}.
}
\tag{5.1}
\]

### Proof

The resolvent identity gives

\[
A(Q)-A(\bar Q)
=
A(Q)(\bar Q-Q)A(\bar Q).
\]

Because both matrices are PSD before adding the identity,

\[
\|A(Q)-A(\bar Q)\|_{op}
\le
\|Q-\bar Q\|_{op}.
\]

Therefore, pathwise,

\[
\left|
e^\top[A(Q)-A(\bar Q)]e
\right|
\le
\|Q-\bar Q\|_{op}\,\|e\|^2.
\]

Taking conditional expectation and Cauchy--Schwarz yields (5.1). The frozen term is exact:

\[
E[e^\top A(\bar Q)e\mid\mathcal F_-]
=
\operatorname{Tr}\!\left(A(\bar Q)E[ee^\top\mid\mathcal F_-]\right).
\]

No independence between `e` and `Q` was invoked. QED.

## 5.1 Actual-block leverage fluctuation has the correct dimension

For the actual block,

\[

Write

\[

\qquad

The current Gaussian source is the **joint** vector `(a,z_1,z_2)`. In particular, the derivative with respect to the shared `a` acts on both views simultaneously.

For a single view,

\[
D_{s_j}x_j
=
\operatorname{diag}(\sigma'(F^\top s_j))F^\top.
\]

Hence every source-gradient contribution to `Q_ab` is bounded by

\[
\frac1N
\|F\|_{op}\|\sigma'\|_\infty
\|B\|_{op}\max(\|x_1\|,\|x_2\|),
\]

up to a constant depending only on `Delta` and on whether `a=b`. Since `sigma` is bounded,

\[
\|x_j\|\le\sqrt m\,\|\sigma\|_\infty.
\]

Therefore

\[
\boxed{
\|\nabla_{a,z_1,z_2}Q_{ab}\|
\le
C_{\Delta,\sigma,\lambda}
\frac{\sqrt m}{N}\|F\|_{op}.
}
\tag{5.2}
\]

For a `d x m` Gaussian matrix with entries of variance `1/d` and `m/d -> beta`, fixed moments of `||F||_op` are bounded. Gaussian Poincare therefore gives

\[
E\|Q_A-\bar Q_A\|_F^2
\le
C\frac m{N^2}
=
O(d^{-1}).
\tag{5.3}
\]

Because the matrix is only `2 x 2`, the same bound holds for the operator norm.

There is no hidden factor `d`, `m`, `dm`, or `m^2`: the entire current shared latent is differentiated as one Gaussian block, and the only dimension factor is `sqrt(m)/N = Theta(d^-1/2)`.

\[

\frac1N x_a^\top K_0x_b.
\]

If `||S_0||_op=O(1)` in the clean event/moment regime, then

\[
\|K_0\|_{op}
\le
\lambda^{-2}\|S_0\|_{op}.
\]

The same joint-current-block derivative calculation as in (5.2) gives

\[
\|\nabla R_{ab}\|
\le
C\frac{\sqrt m}{N}\|F\|_{op}
=
O_P(d^{-1/2}),
\tag{8.3}
\]

and Gaussian Poincare gives

\[
E\|R-\bar R\|_F^2=O(d^{-1}).
\tag{8.4}
\]

Together with the inherited ghost-direction moments for `v_-`, fixed moments of `e,h,R`, and (5.3)--(5.4), the right side of (8.2) is

\[
O(d^{-1/2}).
\tag{8.5}
\]

This explicitly justifies **joint** `A,R` stability; freezing `A` while silently treating `R` as deterministic would be incomplete.

## 8.2 Frozen clean endpoint comparison is dimension-free

Define

\[
\Psi(Q,R,C,M)
=
2\operatorname{Tr}((I+Q)^{-1}M)
+
\operatorname{Tr}((I+Q)^{-1}R(I+Q)^{-1}C).
\]

On PSD `Q` with bounded endpoint norms of `R,C,M`, its Fréchet derivatives satisfy dimension-free bounds because `||(I+Q)^-1|| <= 1`. In particular,

\[
|\Delta\Psi|
\le
C_0
\left(
\|\Delta Q\|_{op}
+
\|\Delta R\|_{op}
+
\|\Delta C\|_*
+
\|\Delta M\|_*
\right),
\tag{8.6}
\]

where `C_0` depends only on bounded endpoint moments, not on `d` or `m`.

The inherited joint teacher/two-view Hermite--Stein estimates and clean ghost-direction bounds give each endpoint difference on the right side of (8.6) at scale `O(d^-1/2)`. Therefore the complete **unscaled clean numerator** discrepancy is

\[
O(d^{-1/2}).
\tag{8.7}
\]

Using the exact `1/N` factor in (8.1), one training-block replacement contributes

\[
O((N\sqrt d)^{-1}),
\]

and all `n=N/2` training replacements contribute

\[
\boxed{O(d^{-1/2}).}
\tag{8.8}
\]

The corresponding second-order increment debt is `O(d^-1)` by the same `E Gamma_i^2 <= C/N^2` argument.

## 8.3 Fresh independent clean-test block

After the training-chain comparison, take a genuinely fresh clean test latent `a^0`, independent of all training blocks. Conditional on the trained weight and `F`, consider

\[
t^0=\xi^\top a^0,
\qquad
u_A^0=w^\top\sigma(F^\top a^0).
\]

The joint derivative bound is

\[
\|\nabla_{a^0}(t^0,u_A^0)\|
\le
1+\|F\|_{op}\|\sigma'\|_\infty\|w\|,
\tag{8.9}
\]

which has fixed moments under ridge. More importantly for squared risk, only the joint second moments are needed. Exact Gaussian Stein handles `E[t^0u_A^0]`, while the same odd-Hermite expansion handles `E[(u_A^0)^2]`; the matched clean Gaussian block has the same leading moments and the residual radius/higher-chaos debt is `O(d^-1/2)` after the inherited ghost-direction delocalization.

Thus the independent population clean endpoint contributes another `O(d^-1/2)` comparison term. If prediction risk is estimated with `M` iid clean test samples, fourth moments are bounded and ordinary independent-sample concentration contributes

\[
O(M^{-1/2}).
\]

Hence

\[
\boxed{
|R_{\rm clean,A}-R_{\rm clean,G}|
=
O(d^{-1/2})+O(M^{-1/2}),
}
\tag{8.10}
\]

and for `M asymp d` the complete clean-test transfer is `O(d^-1/2)`.

# 9. Comparison of proof routes and dimension/dependence audit

## 9.1 Whole-block Lindeberg

**Best route for the exact target.** The current two rows are replaced together. The exact Woodbury increment automatically supplies the required `1/(2N)` scale. The total arithmetic is transparent and the leave environment is independent of the full current shared latent.

## 9.2 Finite-dimensional interpolation

After freezing, interpolation of the `2 x 2` endpoint moment objects is legitimate and dimension-free. The preceding P21 moment-space proof and the derivative bound (8.6) are examples.

What is not legitimate is interpolating all `m` feature coordinates or all `d+m` Gaussian sources separately **before** exploiting odd-Hermite cancellation and normalized traces. That route can pay `m`, `d`, `dm`, or `m^2` multiplicities and swamp the `d^-1/2` target.

## 9.3 Resolvents

The rank-two Woodbury identity is exact. The new contribution in this run is that resolvent freezing uses only

\[
\|(I+Q)^{-1}-(I+\bar Q)^{-1}\|
\le
\|Q-\bar Q\|,
\]

and therefore does not need independence of `Q` and `e`. For clean risk, the same idea freezes `Q` and `R` jointly.

## 9.4 Why a naive CLT is the wrong proof target

Several stronger statements are false or unnecessary:

1. A single `tanh` feature coordinate is bounded, while the covariance-matched surrogate coordinate has Gaussian tails. Coordinatewise total-variation Gaussianization therefore cannot hold.
2. The actual plus/minus nonlinear channels have zero covariance by exchange symmetry but need not be independent.
3. The common original latent generates an order-one two-view correlation. Replacing views independently changes the exact off-diagonal rank-two leverage at order one.
4. Global covariance Frobenius matching is too strong because random feature-column radii can leave an `O(1)` Frobenius debt. The proof succeeds after a normalized trace or delocalized probe, where the missing `d^-1/2` factor appears.
5. A raw per-block `O(d^-1/2)` bracket error is not summable over `n=Theta(d)` blocks. The exact `1/(2N)` optimized-value factor must be inserted first.

The new theorem (5.1) sharpens the conceptual message: for the quadratic target, it is enough to have leverage concentration, residual fourth moments, and correctly matched frozen second moments. A full block CLT is stronger than necessary.
