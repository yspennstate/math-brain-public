## 5.1 Actual nonlinear coordinate

Condition on

- all training latents in the leave-block data;
- all feature columns except \(f_r\);
- all other randomness in the hybrid.

Then \(r^{(-r)}\) is fixed and the \(r\)-th actual design column is generated by

\[
f_r=d^{-1/2}g_r,
\qquad g_r\sim N(0,I_d).
\]

Let \(U\) be the matrix of leave-block noisy input rows \(a_i+\Delta z_{ij}\). Define

\[
G_r(g_r)=N^{-1}x_r(g_r)^\top r^{(-r)}.
\]

Oddness of \(\sigma\) gives

\[
G_r(-g_r)=-G_r(g_r),
\]

so the conditional mean is zero.

Its gradient is

\[
\nabla_{g_r}G_r
=
\frac1{N\sqrt d}
U^\top\left(r^{(-r)}\odot\sigma'(Ug_r/\sqrt d)\right).
\]

Therefore

\[
\boxed{
\|\nabla_{g_r}G_r\|
\le
\frac{K_1}{N\sqrt d}\|U\|_{op}\|r^{(-r)}\|.
}
\tag{5.2}
\]

The paired latent matrix has the exact decomposition \(U=RA+\Delta Z\) with \(\|R\|=\sqrt2\). Since \(n\asymp d\),

\[
P\{\|U\|_{op}>C\sqrt d\}\le e^{-cd}
\tag{5.3}
\]

for a sufficiently large constant \(C\).

Ridge energy gives, deterministically,

\[
\frac1N\|r^{(-r)}\|^2
\le
\frac1N\|y\|^2.
\tag{5.4}
\]

The repeated unit linear-teacher labels have Gaussian chi-square concentration, so

\[
P\{\|r^{(-r)}\|>C\sqrt N\}\le e^{-cd}
\tag{5.5}
\]

uniformly in \(r\).

On the common event `(5.3)`--`(5.5)`, `(5.2)` gives

\[
\operatorname{Lip}(G_r)\le C d^{-1/2}.
\]

Gaussian concentration yields

\[
P\{|G_r|>t\mid\mathcal G_{-r}\}
\le
2e^{-cdt^2}.
\tag{5.6}
\]

Using \(S_r\ge\lambda\),

\[
P\{|w_r|>t\}
\le
2e^{-c_\lambda dt^2}+e^{-cd}.
\tag{5.7}

For a source-Gaussian row, the \(r\)-th design column is a centered linear Gaussian combination of the fresh coordinate sources

# 7. Malliavin-Stein interpolation proof

This section proves `(0.2)` without assuming a prepackaged multivariate CLT.

For a centered smooth scalar Gaussian functional \(V=f(G)\), write

\[
\Gamma(V)
=\langle DV,-DL^{-1}V\rangle,
\]

where \(L\) is the Ornstein-Uhlenbeck generator. Then

\[
E\Gamma(V)=EV^2.
\tag{7.1}
\]

The standard finite-dimensional second-order Poincare inequality of Chatterjee / Nourdin--Peccati--Reinert implies

\[
\boxed{
\|\Gamma(V)-EV^2\|_{L^2}
\le
C
\left(E\|\nabla V\|^4\right)^{1/4}
\left(E\|\nabla^2V\|_{op}^4\right)^{1/4}.
}
\tag{7.2}
\]

Apply `(7.2)` to every scalar projection \(V=\theta\cdot Y\). The deterministic conditional bounds `(6.3)`--`(6.6)` yield

\[
\|\Gamma(\theta\cdot Y)-\operatorname{Var}(\theta\cdot Y)\|_2
\le
C A(F,w)B(F,w).
\tag{7.3}
\]

For coordinates \(Y_a,Y_b\), define

\[
\Gamma_{ab}
=\langle DY_a,-DL^{-1}Y_b\rangle,
\qquad
\Gamma^s_{ab}=\frac{\Gamma_{ab}+\Gamma_{ba}}2.
\]

Polarization of `(7.3)` using \(Y_a\), \(Y_b\), and \(Y_a+Y_b\) gives, because the dimension is fixed at three,

\[
\boxed{
\sum_{a,b=1}^3
E\left|\Gamma^s_{ab}-\Sigma_{ab}\right|
\le
C A(F,w)B(F,w).
}
\tag{7.4}
\]

Now let \(Z\sim N(0,\Sigma)\) be independent of the Gaussian source \(G\) and define

\[
Y_s=\sqrt s\,Y+\sqrt{1-s}\,Z,
\qquad 0\le s\le1.
\]

For \(\Phi\in C_b^2(\mathbb R^3)\), differentiate

\[
\Psi(s)=E\Phi(Y_s).
\]

Gaussian integration by parts in \(Z\), together with Malliavin integration by parts in the current latent \(G\), gives

\[
\boxed{
\Psi'(s)
=
\frac12
\sum_{a,b=1}^3
E\left[
\partial_{ab}\Phi(Y_s)
(\Gamma^s_{ab}-\Sigma_{ab})
\right].
}
\tag{7.5}
\]

The apparent \(s^{-1/2}\) and \((1-s)^{-1/2}\) factors cancel against the chain-rule factors produced by the two integrations by parts. Integrating `(7.5)` from \(0\) to \(1\) and using `(7.4)` proves

\[
\left|
E\Phi(Y)-E\Phi(Z)
\right|
\le
C\|\nabla^2\Phi\|_\infty A(F,w)B(F,w),
\]

which is `(0.2)`.

### Why this route is dependence-correct

The entire current Gaussian latent \((a,z_1,z_2)\) is differentiated jointly. The teacher coordinate \(t=\xi^\top a\) lives inside the same vector. No attempt is made to regard \(u_1,u_2,t\) as independent or to replace feature coordinates independently.

# 8. Fourth cumulant certificate

For a centered scalar \(V=Y_\theta\), the Stein identity with test \(v\mapsto v^3\) gives

\[
EV^4
=3E[V^2\Gamma(V)].
\]

Writing \(s^2=EV^2\),

\[
\kappa_4(V)
=EV^4-3s^4
=3E\left[V^2(\Gamma(V)-s^2)\right].
\tag{8.1}
\]

By Cauchy--Schwarz,

\[
|\kappa_4(V)|
\le
3(EV^4)^{1/2}
\|\Gamma(V)-s^2\|_2.
\tag{8.2}
\]

Because \(V\) is a centered \(A(F,w)\)-Lipschitz function of a standard Gaussian vector, Gaussian concentration gives

\[
(EV^4)^{1/4}\le C A(F,w).
\tag{8.3}
\]

Combining `(7.3)`, `(8.2)`, `(8.3)` yields

\[
\boxed{
|\kappa_4(Y_\theta)|
\le
C A(F,w)^3B(F,w),
}
\]

uniformly over \(\|\theta\|=1\). This proves `(0.5)`.

Ridge coercivity gives \(\|w_-\|_2=O_P(1)\), standard Gaussian random-matrix bounds give \(\|F\|_{op}=O_P(1)\), and `(0.1)` gives the maximum-coordinate scale. Hence `(0.6)` follows.

### Exact limitation

The target

\[

\]

without the logarithm is **not proved here**. Claiming it from per-coordinate fourth moments would be invalid: \(E|w_r|^4\le Cd^{-2}\) does not by itself give a log-free almost-sure or high-probability maximum.
