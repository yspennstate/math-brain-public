## 0.2 Main new theorem: fixed-codimension Hotelling identity

P20's newest report isolates the ordinary-law source alignment in the codimension-one harmonic angular problem through a rank-one Hotelling statistic. This run proves the deterministic fixed-codimension form.

### `P23-T4-FIXED-CODIM-HOTELLING-30` — PROVED

Let `H` be any real `n x m` matrix of full column rank with

```text
n = m + r,      r >= 1.
```

Let

```text
J = 11^T/n,
H_c = (I-J)H,
bar h = H^T 1 / n,
C = H_c^T H_c,
```

and assume `C` is invertible. Let

```text
K = I_n - H(H^T H)^(-1)H^T
```

be the orthogonal projector onto the left nullspace `ker(H^T)`, which has rank `r`.

Then, with

```text
t = bar h^T C^(-1) bar h,
```

one has the exact identity

```text
1^T K 1 = n / (1 + n t).                 (H30.1)
```

For `r=1`, writing `K=vv^T`, this is exactly P20's new formula

```text
(1^T v)^2 = n / (1+n t).
```

If `H` is standard Gaussian, then `K` is a Haar rank-`r` projection in `R^n`, so

```text
(1^T K 1)/n ~ Beta(r/2,m/2),             (H30.2)
```

and therefore

```text
n t ~ BetaPrime(m/2,r/2).                 (H30.3)
```

Thus the ordinary source-alignment debt for fixed codimension has an exact one-scalar inverse-covariance form.

In the P04 radial source problem, where the source coordinate mean satisfies `mu_d^2 ~ 2/d` and `n ~ d^2/2`, the squared conditional mean shift in an orthonormal left-null frame is


which by (H30.1) is equivalent to


This generalizes the newest P20 rank-one criterion without imposing coefficient `l_infinity` delocalization.

## 0.3 Main new theorem: Gaussian Gram-volume tilt is globally asymptotically singular

P04 and P20 repeatedly isolate the transfer from the Gram-volume-biased angular law back to the ordinary iid angular law as a negative-determinant / inverse-volume obstacle. A tempting route is to seek a globally tame likelihood ratio and transfer volume-law estimates by total variation or Hölder.

This run proves that such a global strategy is benchmark-incompatible even for the easiest Gaussian matrix, where the relevant nullspace orientation is actually **unchanged exactly** by the volume tilt.

### `P23-T4-GAUSSIAN-VOLUME-TILT-SINGULARITY-30` — PROVED

Fix an integer `r>=1`. Let

```text
H_m in R^{(m+r) x m}
```

have iid `N(0,1)` entries under the ordinary law `P_m`. Set

```text
D_m = det(H_m^T H_m),
M_m = E_{P_m} D_m,
dQ_m/dP_m = D_m/M_m,
R_m = dP_m/dQ_m = M_m/D_m.
```

Then:

1. **Exact Bartlett factorization.** There are independent variables

```text
X_l ~ chi^2_{r+l},   l=1,...,m,
```

such that under `P_m`

```text
D_m = product_{l=1}^m X_l,
M_m = product_{l=1}^m (r+l).
```

Under the volume law `Q_m`, the factors stay independent and are exactly

```text
X_l^(Q) ~ chi^2_{r+l+2}.
```

2. **Exact likelihood moments.** For fixed `q>1`, put `a=q-1` and `x_l=(r+l)/2`. If

```text
1 < q < (r+3)/2,
```

then

```text
E_Q R_m^q
 = product_{l=1}^m [ x_l^a Gamma(x_l-a)/Gamma(x_l) ].       (V30.1)
```

If `q >= (r+3)/2`, the moment is infinite because the smallest chi-square degree already has a divergent negative moment.

For every fixed admissible `q`, NIST DLMF gamma-ratio asymptotics give

```text
E_Q R_m^q = C_{r,q} m^{q(q-1)} (1+o(1)),                    (V30.2)
```

for a finite constant `0<C_{r,q}<infinity`.

In particular, when `r=1`, the `L^2(Q)` likelihood moment is already infinite.

3. **Log-likelihood separation.** Under `P_m`,

```text
E_P log R_m = log m + O_r(1),
Var_P(log R_m) = 2 log m + O_r(1).                           (V30.3)
```

Under `Q_m`,

```text
E_Q log R_m = -log m + O_r(1),
Var_Q(log R_m) = 2 log m + O_r(1).                           (V30.4)
```

Consequently, by Chebyshev,

```text
log R_m / log m -> +1   in P_m-probability,
log R_m / log m -> -1   in Q_m-probability.                 (V30.5)
```

4. **Asymptotic mutual singularity in total variation.** Let

```text
A_m = {R_m > 1}.
```

Then

```text
P_m(A_m) -> 1,
Q_m(A_m) -> 0,
```

so

```text
||P_m-Q_m||_TV -> 1.                                        (V30.6)
```

Moreover the two relative entropies both diverge logarithmically:

```text
D_KL(P_m||Q_m) = log m + O_r(1),
D_KL(Q_m||P_m) = log m + O_r(1).                             (V30.7)
```

5. **But nullspace orientation is exactly unchanged.** Under `P_m`, the Gaussian polar/SVD decomposition makes the column-space Stiefel factor Haar and independent of the singular values. Since `D_m` depends only on the singular values, volume tilting changes only their law. Therefore the left-nullspace projector

```text
K_m = I - H_m(H_m^T H_m)^(-1)H_m^T
```

has **exactly the same Haar rank-`r` distribution under `P_m` and `Q_m`**.

In particular, for the alignment observable

```text
A_m = 1^T K_m 1,
```

one has under both laws

```text
A_m/(m+r) ~ Beta(r/2,m/2),
E A_m = r.                                                   (V30.8)
```

This is the central structural conclusion:

> The ordinary and volume-biased Gaussian matrix laws become globally maximally separated in total variation, while the exact nullspace-orientation observable relevant to the radial source is unchanged in distribution.

Therefore global law closeness is not merely unnecessary; it is false even in the benchmark where the desired orientation transfer is exact.

# 4. Proof of `P23-T4-FIXED-CODIM-HOTELLING-30`

Write

```text
H = H_c + 1 bar h^T,
```

where `H_c^T 1=0`. Hence

```text
H^T H = C + n bar h bar h^T,
H^T 1 = n bar h.
```

By definition,

```text
1^T K 1
 = n - (H^T1)^T (H^T H)^(-1)(H^T1)
 = n - n^2 bar h^T(C+n bar h bar h^T)^(-1)bar h.
```

Set

```text
t=bar h^T C^(-1)bar h.
```

Sherman-Morrison gives

```text
bar h^T(C+n bar h bar h^T)^(-1)bar h
 = t/(1+n t).
```

Therefore

```text
1^T K1
 = n - n^2 t/(1+n t)
 = n/(1+n t).
```

This proves (H30.1).

If `H` is standard Gaussian, its column space is Haar in the Grassmannian and the rank-`r` left-null projector `K` is Haar and independent of the singular values. For any fixed vector of norm `sqrt(n)`, the squared norm of its projection onto a Haar `r`-plane divided by `n` has law

```text
Beta(r/2,(n-r)/2)=Beta(r/2,m/2).
```

Thus (H30.2) follows. Since

```text
(1^T K1)/n = 1/(1+n t),
```

standard beta/beta-prime algebra gives (H30.3).

For the P04 radial source, conditional on `H` the mean of its projection onto the nullspace is `mu_d V^T1`, where `VV^T=K`. Its squared norm is

```text
mu_d^2 1^TK1.
```

Because `mu_d^2 ~ 2/d` and `n asymp d^2`, vanishing of this term is equivalent to `1^TK1=o_P(d)`. From (H30.1),

```text
(1^TK1)/d = (n/d)/(1+n t).
```

Since `n/d asymp d`, this tends to zero iff `n t / d -> infinity`, equivalently `d t -> infinity`. This proves (H30.4).

# 5. Proof of Gaussian volume-tilt singularity

Let

```text
n=m+r,
H in R^{n x m}
```

be iid standard Gaussian.

## 5.1 Bartlett decomposition and exact tilted factors

For a real Wishart `W=H^T H`, Bartlett decomposition gives

```text
D=det W = product_{l=1}^m X_l,
X_l independent, X_l ~ chi^2_{r+l}.
```

Set

```text
nu_l=r+l.
```

Since `E X_l=nu_l`,

```text
M=E D = product_l nu_l.
```

The volume density factors:

```text
dQ/dP = product_l (X_l/nu_l).
```

Therefore under `Q` the factors remain independent. Size-biasing a `chi^2_nu` density by `x/nu` produces exactly `chi^2_{nu+2}`. Hence

```text
X_l under Q ~ chi^2_{nu_l+2}.
```

## 5.2 Exact `L^q(Q)` likelihood moment

The reverse likelihood is

```text
R=M/D.
```

For `q>1`, put `a=q-1`. Then

```text
E_Q R^q
 = M^{q-1} E_P D^{1-q}
 = product_l [ nu_l^a E X_l^{-a} ].
```

For `X~chi^2_nu`,

```text
E X^{-a}
 = 2^{-a} Gamma(nu/2-a)/Gamma(nu/2)
```

provided `a<nu/2`; otherwise it diverges.

Writing `x_l=nu_l/2`,

```text
E_Q R^q
 = product_l x_l^a Gamma(x_l-a)/Gamma(x_l).
```

The smallest degree is `nu_1=r+1`, so the moment is finite precisely when

```text
q-1 < (r+1)/2,
```

that is

```text
q < (r+3)/2.
```

This proves the exact existence threshold in (V30.1).

By the DLMF gamma-ratio expansion (3.1), for fixed admissible `q`,

```text
x_l^a Gamma(x_l-a)/Gamma(x_l)
 = 1 + a(a+1)/(2x_l) + O(x_l^{-2})
 = 1 + q(q-1)/(r+l) + O((r+l)^{-2}).
```

Taking logarithms,

```text
log E_Q R^q
 = q(q-1) sum_{l=1}^m 1/(r+l) + O_r,q(1)
 = q(q-1) log m + O_r,q(1).
```

The error after subtracting the harmonic term is summable, so the normalized product converges to a finite positive constant `C_{r,q}`. This proves (V30.2).

## 5.3 Log likelihood under the ordinary law

Under `P`,

```text
log R
 = sum_l [log nu_l - log X_l].
```

For `X~chi^2_nu`,

```text
E log X = log 2 + psi(nu/2),
Var(log X)=psi'(nu/2).
```

Thus

```text
E_P log R
 = sum_l [log nu_l - log2 - psi(nu_l/2)].
```

Using (3.2), with `x=nu/2`,

```text
log nu-log2-psi(nu/2)
 = log x-psi(x)
 = 1/(2x)+O(x^{-2})
 = 1/nu+O(nu^{-2}).
```

Hence

```text
E_P log R = log m + O_r(1).
```

Using (3.3),

```text
Var_P(log R)
 = sum_l psi'(nu_l/2)
 = 2 log m + O_r(1).
```

This proves (V30.3).

## 5.4 Log likelihood under the volume law

Under `Q`, `X_l~chi^2_{nu_l+2}`, so

```text
E_Q log R
 = sum_l [log nu_l-log2-psi(nu_l/2+1)].
```

The exact recurrence

```text
psi(x+1)=psi(x)+1/x
```

shows that the `Q` summand is the `P` summand minus `2/nu_l`. Therefore

```text
E_Q log R = -log m + O_r(1).
```

Similarly,

```text
Var_Q(log R)
 = sum_l psi'(nu_l/2+1)
 = 2 log m + O_r(1),
```

using the trigamma asymptotic. This proves (V30.4).

Because the variance is only order `log m` while the mean has magnitude `log m`, Chebyshev yields (V30.5).

Taking `A_m={logR>0}` gives

```text
P(A_m)->1,
Q(A_m)->0,
```

so total variation tends to one. The two KL statements are exactly the two signed log-likelihood means. This proves (V30.6)–(V30.7).

## 5.5 Yet orientation is unchanged exactly

Under the ordinary Gaussian law, write the polar decomposition

```text
H=U W^{1/2},
```

where `U` is Haar on the Stiefel manifold of orthonormal `m`-frames in `R^{m+r}`, `W=H^TH` is Wishart, and `U` and `W` are independent.

The volume likelihood is `det(W)/E det(W)`, a function of `W` alone. Therefore the tilt leaves the complete law of `U` unchanged.

The left-null projector is

```text
K=I-UU^T,
```

so its complete law is identical under `P` and `Q`. It is Haar of rank `r`. The beta alignment law (V30.8) follows.

This finishes the theorem.

# 6. Why this matters for the harmonic hard edge

The current P04/P20 architecture has two separate open pieces:

1. the volume-biased angular/Jordan amplitude problem;
2. transfer from volume-biased identities to the ordinary iid angular law, especially inverse-volume rare-event control.

The Gaussian theorem above clarifies the second piece.

A global comparison of `P` and `Q` is the wrong target. Even for Gaussian rows:

```text
TV(P,Q) -> 1,
KL(P||Q) ~ log m,
KL(Q||P) ~ log m,
```

while the entire nullspace projector has exactly the same law.

Thus a proof should seek **observable-specific transfer** rather than global measure closeness. Promising forms include:

- conditioning on singular values and using an orientation theorem;
- exact cofactor cancellations for the target observable;
- localized rank-three comparison preserving numerator/denominator coupling;
- benchmark-centered comparison of a single inverse quadratic form;
- a signed likelihood identity in which the large global determinant tilt cancels.

The theorem also gives a warning about moment methods. For codimension one, the reverse volume likelihood is not even in `L^2(Q)`. Therefore a Cauchy-Schwarz transfer of rare events from volume law to ordinary law is not available in the Gaussian benchmark.

This is a route-falsification result, not a proof that ordinary harmonic transfer is impossible.

# 7. Fixed-`q` Hölder no-go

Let `E_m` be any event for which the only volume-law information is

```text
Q(E_m) <= C m^{-1/2}.
```

For fixed admissible `q>1`, Hölder gives

```text
P(E_m)
 = E_Q[R 1_E]
 <= (E_Q R^q)^{1/q} Q(E)^{1-1/q}.
```

By (V30.2),

```text
(E_QR^q)^{1/q}
 = Theta(m^{q-1}).
```

The event factor is at best

```text
O(m^{-(q-1)/(2q)}).
```

Thus the bound scales as
