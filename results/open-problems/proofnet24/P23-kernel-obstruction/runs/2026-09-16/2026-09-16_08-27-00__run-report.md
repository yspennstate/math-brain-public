# 7. New proof: pass from every fixed finite range to the bilateral architecture

This is the theorem-sized step not present in the preceding run.

Fix `r>1` and `x in [1/r,1]`. The bilateral series

\[

\]

converges absolutely. We need a uniform deterministic comparison with `E_{A,B}`.

## 7.1 Lower-index tail

Because the denominator of `phi_r` is at least one,

\[
0\le\phi_r(y)\le(r-1)y.
\]

Therefore

\[
\sum_{j<-A}\phi_r(r^jx)
\le
(r-1)x\sum_{j=-\infty}^{-A-1}r^j
=xr^{-A}
\le r^{-A}.
\tag{7.1}
\]

Also

\[
0\le g(r^{-A}x)\le r^{-A}x\le r^{-A}.
\tag{7.2}
\]

## 7.2 Upper-index tail

For every `y>0`,

\[
(1+y)^2\ge y^2,
\qquad
(1+ry)^2\ge r^2y^2.
\]

Thus

\[
\phi_r(y)
\le
\frac{r-1}{r^2y^3}.
\]

Since `x>=1/r`,

\[
\phi_r(r^jx)
\le
(r-1)r\,r^{-3j}.
\]

Hence

\[
\sum_{j\ge B}\phi_r(r^jx)
\le
\frac{(r-1)r}{1-r^{-3}}\,r^{-3B}.
\tag{7.3}
\]

Combining (7.1)--(7.3),

\[
\boxed{
\sup_{x\in[1/r,1]}
|E_{A,B}(r,x)-S_r(x)|
\le
2r^{-A}
+
\frac{(r-1)r}{1-r^{-3}}r^{-3B}.
}
\tag{7.4}
\]

Thus `E_{A,B}->S_r` uniformly as `A,B->infinity`.

## 7.3 Correct order of limits

Let a subsequence realize the global liminf of `E_XV(X)/sigma^2`. Extract a phase-convergent subsubsequence `x_d->x`. For **every fixed** pair `A,B`, equation (6.8) gives

\[

:=\liminf E_X\frac{V(X)}{\sigma^2}
\ge E_{A,B}(r_*,x).
\]

The same number `L` is therefore at least the limit over deterministic `A,B`. By (7.4),

\[

Since `x in [1/r_*,1]`,

\[

Every subsequence realizing the liminf admits such a phase subsubsequence, so

\[
\boxed{

\tag{7.5}

This proves `P23-T3-ANNEALED-BILATERAL-43`.
