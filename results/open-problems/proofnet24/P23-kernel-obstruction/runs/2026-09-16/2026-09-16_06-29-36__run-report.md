# 6. New theorem: exact reverse-tail positivity and `O(d)`-window localization

## `P23-T4-SIGNED-ONEDELETE-OD-WINDOW-40 = PROVED`

The proof has three short exact steps.

## 6.1 Jordan deletion recurrence

At a deletion step from residual rank `r` to `r-1`, write the selected unit Frobenius deleted direction as `v`. Put

\[
j(v)=v^2-\frac1dI.
\]

The residual Jordan vector updates exactly as

\[
J_{r-1}=J_r-j(v).
\tag{6.1}
\]

The selected-direction second moment is

\[
E[v\otimes v\mid P_r]=\frac1rP_r,
\tag{6.2}
\]

so by linearity of the Jordan map,

\[
E[j(v)\mid P_r]=\frac1rJ_r.
\tag{6.3}
\]

Therefore

\[
\begin{aligned}
E[\|J_{r-1}\|^2\mid P_r]
&=\|J_r\|^2
-2\left\langle J_r,E[j(v)\mid P_r]\right\rangle
+E\|j(v)\|^2\\
&=\frac{r-2}{r}\|J_r\|^2
+E\left[\operatorname{tr}(v^4)-\frac1d\mid P_r\right].
\end{aligned}
\]

Define

\[
\gamma_r
:=E\operatorname{tr}(v^4)-\frac1d.
\tag{6.4}
\]

Averaging gives

\[
\boxed{
 e_{r-1}=\frac{r-2}{r}e_r+\gamma_r.
}
\tag{6.5}
\]

Since `v` is Frobenius-unit,

\[
\operatorname{tr}(v^4)\ge\frac1d
\]

by Cauchy on the eigenvalues, and

\[
\operatorname{tr}(v^4)\le(\operatorname{tr}v^2)^2=1.
\]

Thus

\[
\boxed{0\le\gamma_r\le1-\frac1d.}
\tag{6.6}
\]

At full residual rank `m`, `P_m=I_E`. The full traceless-symmetric coefficient space is isotropic, hence `J_m=0` and

\[
e_m=0.
\tag{6.7}
\]

## 6.2 Exact telescoping formula and universal `e_s` bound

Divide (6.5), with `r=s+1`, by `s(s-1)`:

\[
\frac{e_s}{s(s-1)}
=
\frac{e_{s+1}}{s(s+1)}
+
\frac{\gamma_{s+1}}{s(s-1)}.
\]

Telescoping to `m` and using (6.7) gives

\[
\boxed{
 e_s
=s(s-1)
\sum_{r=s+1}^{m}
\frac{\gamma_r}{(r-1)(r-2)}.
}
\tag{6.8}
\]

Using (6.6),

\[
\begin{aligned}
e_s
&\le
s(s-1)\left(1-\frac1d\right)
\sum_{r=s+1}^{m}
\frac1{(r-1)(r-2)}\\
&=
s(s-1)\left(1-\frac1d\right)
\left(\frac1{s-1}-\frac1{m-1}\right).
\end{aligned}
\]

Hence the finite-dimensional bound

\[
\boxed{
0\le e_s
\le
s\left(1-\frac1d\right)
\frac{m-s}{m-1}.
}
\tag{6.9}
\]

In particular `e_s<=s` for every residual rank.

# 8. New no-go theorem: mixed affine/linear partition identities cancel `A_s`

## `P23-T4-AFFINE-LINEAR-MIXED-PARTITION-BLINDNESS-40 = PROVED`

This section is independent of the physical sphere flow and applies to any centered iid row law with finite second moment.

## 8.1 Expected squared volume depends only on the second moment

Let `x_1,...,x_k in R^m` be iid with second moment matrix

\[
M=E[x x^T].
\]

For the `k x m` row matrix `X`, Cauchy--Binet gives

\[
\det(XX^T)
=
\sum_{|S|=k}\det(X_S)^2.
\]

For each coordinate set `S`, expanding the two determinants and using row independence gives

\[
E\det(X_S)^2=k!\det(M_S).
\]

Hence

\[
\boxed{
E\det(XX^T)
=k!\,e_k(M),
}
\tag{8.1}
\]

where `e_k(M)` is the sum of `k x k` principal minors. No Gaussianity or spherical symmetry is used.

## 8.2 Two-parameter deformation

Let the original row law be centered. Fix a self-adjoint operator `H` on coefficient space and a vector `D`. For a sample `Y`, set

\[

\tag{8.2}
\]

\[

\tag{8.3}
\]

because the original mean is zero. By (8.1), the partition function

\[
Z(\epsilon,t)
=E\det(Y_{\epsilon,t}Y_{\epsilon,t}^T)

is even in `t` for every `epsilon`. Therefore

\[
\boxed{
\partial_\epsilon\partial_t Z(0,0)=0.
}
\tag{8.4}
\]

## 8.3 Pointwise mixed derivative under determinant selection

At `(epsilon,t)=(0,0)`, put

\[
G=YY^T,
\qquad
Q=Y^TG^{-1}Y,
\qquad
P=I-Q,
\qquad

\[
\partial_t\log\det(Y_{0,t}Y_{0,t}^T)\big|_{t=0}

\tag{8.5}

The linear deformation derivative is

\[
\partial_\epsilon\log\det(Y_{\epsilon,0}Y_{\epsilon,0}^T)\big|_{\epsilon=0}
=2\operatorname{tr}(QH).
\tag{8.6}
\]

Differentiate the affine interpolant under `Y -> Y(I+epsilon H)`:

\[
a_\epsilon
=(I+\epsilon H)^TY^T
\left[Y(I+\epsilon H)(I+\epsilon H)^TY^T\right]^{-1}{\bf1}.

For self-adjoint `H`,

\[
\boxed{

\[

\tag{8.8}
\]

## 8.4 Jordan specialization is a pointwise tautology

Now specialize to the traceless-symmetric coefficient space `E=Sym_d^0`. Let `{T_gamma}` be an orthonormal basis and define

\[
L_C(B)=\Pi_E\frac{CB+BC}{2}.
\]

For each `gamma`, put

\[
H=L_{T_\gamma},\qquad D=T_\gamma.
\]

The exact completeness identities are

\[
\sum_\gamma L_{T_\gamma}(PT_\gamma)=J(P),
\qquad
\sum_\gamma L_{T_\gamma}T_\gamma=0.
\tag{8.9}
\]

Since `I-2Q=2P-I`, the sum of the first terms in (8.8) is

\[
\begin{aligned}
\sum_\gamma
\langle(2P-I)L_{T_\gamma}a,T_\gamma\rangle

\langle a,L_{T_\gamma}(PT_\gamma)\rangle\\
&=2\langle a,J(P)\rangle.
\end{aligned}
\tag{8.10}

\[
\operatorname{tr}(Q L_{T_\gamma})
=-\langle J(P),T_\gamma\rangle,

and the sum of the second terms in (8.8) is

\[
-2\langle a,J(P)\rangle.
\tag{8.11}

Equations (8.10)--(8.11) cancel **pointwise**.
