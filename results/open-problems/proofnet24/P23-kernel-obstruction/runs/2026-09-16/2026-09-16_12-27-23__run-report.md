# 5. Exact denominator U-statistic structure

## `P23-T3-DENOMINATOR-DEGENERATE-U-STAT-47 = PROVED`

The preceding scalar Jensen step throws away the random denominator. The previous run proposed checking whether its covariance carries useful first-order information. Here the denominator is analyzed exactly.

## 5.1 Spectral-kernel notation

Let

```text
Pi_s(x,y) = sum_{j=1}^{N_s} phi_{s,j}(x) phi_{s,j}(y).
```

The addition theorem and orthonormality give, for every fixed `x`,

```text
Pi_s(x,x)=N_s,
Integral Pi_s(x,y) Pi_t(x,y) dmu(y)
 = 1_{s=t} N_s.
```

Choose deterministic weights

```text
0 <= mu_s <= lambda_s,   s<=L,
```

and define

```text
m(x,y)=sum_{s<=L} mu_s Pi_s(x,y),
b(x,y)=sum_{s>L} lambda_s Pi_s(x,y).
```

Put

```text
a    = sum_{s<=L} N_s mu_s,
zeta = sum_{s<=L} N_s mu_s^2,
tau  = sum_{s>L} N_s lambda_s.
```

Then, for every `x`,

```text
m(x,x)=a,
b(x,x)=tau,
Integral m(x,y)^2 dmu(y)=zeta,
Integral m(x,y)b(x,y) dmu(y)=0.
```

The last identity is exact low/high harmonic orthogonality.

## 5.2 Rewrite the random denominator as a pair statistic

For iid `X_1,...,X_n`, let

```text
M_ij=m(X_i,X_j),
B_ij=b(X_i,X_j).
```

The pathwise denominator in the generalized subkernel certificate is

```text
S = Tr(M^2)+Tr(BM)
  = sum_{i,j} H(X_i,X_j),
```

with

```text
H(x,y)=m(x,y)[m(x,y)+b(x,y)].
```

The diagonal is deterministic:

```text
H(x,x)=a(a+tau).
```

For independent `Y`, conditional on `x`,

```text
E_Y H(x,Y)
 = Integral m(x,y)^2 dmu(y)
   + Integral m(x,y)b(x,y)dmu(y)
 = zeta.
```

Crucially, this conditional mean is independent of `x`.

Therefore

```text
E S = n a(a+tau) + n(n-1) zeta
    = n[a(a+tau)+(n-1)zeta].
```

## 5.3 Exact variance; all one-index overlaps cancel

Write

```text
S-E S
 = 2 sum_{1<=i<j<=n} [H(X_i,X_j)-zeta].
```

Two terms indexed by disjoint unordered pairs are independent. If two distinct pairs share exactly one index, for example `(1,2)` and `(1,3)`, then

```text
E[(H(X_1,X_2)-zeta)(H(X_1,X_3)-zeta) | X_1]
 = [E(H(X_1,X_2)-zeta | X_1)]^2
 = 0.
```

Hence there are no covariance contributions from the `Theta(n^3)` shared-index configurations. Only identical unordered pairs survive. Thus

```text
Var(S)
 = 4 C(n,2) Var(H(X,Y))
 = 2 n(n-1)[E H(X,Y)^2-zeta^2].
```

This is exact in every dimension and for every deterministic spectral weight choice.

## 5.4 A uniform second-moment bound

The kernel

```text
c(x,y):=m(x,y)+b(x,y)
```

is PSD and has constant diagonal `a+tau`. Every PSD kernel satisfies the two-point Cauchy bound

```text
|c(x,y)|^2 <= c(x,x)c(y,y)=(a+tau)^2.
```

Therefore

```text
H(x,y)^2
 = m(x,y)^2 c(x,y)^2
 <= (a+tau)^2 m(x,y)^2.
```

Averaging over independent `X,Y` gives

```text
E H(X,Y)^2 <= (a+tau)^2 zeta.
```

Consequently

```text
Var(S)
 <= 2 n(n-1)(a+tau)^2 zeta,
```

and

```text
Var(S)/(E S)^2
 <= [2(n-1)/n] (a+tau)^2 zeta
    / [a(a+tau)+(n-1)zeta]^2.
```

No concentration theorem is invoked; this is an exact U-statistic variance calculation plus a PSD kernel inequality.
