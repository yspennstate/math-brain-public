## 2. Harmonic data

Put \(a=h^{-2}\). On \(S^{d-1}\),
\[
K_h(x,y)=e^{-a}e^{a x\cdot y}.
\]

The degree-\(s\) harmonic multiplicity is
\[
N_{d,s}
=
\binom{d+s-1}{s}-\binom{d+s-3}{s-2}.
\]

The cumulative dimension is
\[
\boxed{
D_{d,L}
=
\binom{d+L-1}{L}
+
\binom{d+L-2}{L-1}.
}
\]

The adjacent ratio is
\[
\boxed{
R_{d,L}
=
\frac{(d+L-1)(d+2L+1)}
{(L+1)(d+2L-1)}.
}
\]

The Gaussian-kernel Mercer eigenvalue is
\[
\lambda_{d,s}
=
e^{-a}\Gamma(d/2)(2/a)^{d/2-1}I_{s+d/2-1}(a),
\]
and positivity of the Bessel series yields
\[
\boxed{
\frac{\lambda_{d,s+1}}{\lambda_{d,s}}
\le \frac{a}{d+2s}.
}
\]

For \(L\asymp d\),
\[
\boxed{
\frac{\tau_{>L}}{\lambda_{d,L}}
=
O_h(D_{d,L}/d).
}
\tag{2.1}
\]

## 3. Exact risk/leverage reduction

Let
\[
K_s=\lambda_s\Phi_s\Phi_s^\top,
\qquad
t_s=\operatorname{Tr}(K^{-1}K_s),
\qquad
q_s=\operatorname{Tr}(K^{-1}K_sK^{-1}).
\]

Then
\[
\boxed{
\frac{V(X)}{\sigma^2}
=
\sum_s\lambda_sq_s.

\tag{3.1}
\]

For every degree,
\[
t_s^2\le nN_s\lambda_sq_s.
\]

Thus for a finite harmonic window \(B\),
\[

\tag{3.2}

\[

## 6. Pathwise leverage theorem

Let
\[
A_{\le L}=\sum_{s\le L}K_s=\Phi\Lambda\Phi^\top,
\qquad
B_{>L}=K-A_{\le L}.
\]

Since \(\lambda_s\ge\lambda_{d,L}\) for \(s\le L\),
\[
A_{\le L}\succeq \lambda_{d,L}\Phi\Phi^\top.
\]

Hence \(A_{\le L}\) has at least \(r_\eta\) eigenvalues
\[
\kappa_j\ge n\eta\lambda_{d,L}.
\]

For a corresponding eigenvector \(u_j\), inverse Rayleigh gives
\[
\kappa_j u_j^\top K^{-1}u_j
\ge
1-\frac{u_j^\top B_{>L}u_j}
{n\eta\lambda_{d,L}}.
\]

Summing,
\[
T_{\le L}:=\operatorname{Tr}(K^{-1}A_{\le L})
\ge
r_\eta
-
\frac{\operatorname{Tr}B_{>L}}
{n\eta\lambda_{d,L}}.
\]

The addition theorem makes the tail diagonal constant, so
\[
\operatorname{Tr}B_{>L}=n\tau_{>L}
\]
pathwise. Therefore
\[
\boxed{
T_{\le L}
\ge
\frac{D^2(1-\eta)^2}
{\|S-I\|_F^2+D(1-\eta)^2}
-
\frac{\tau_{>L}}
{\eta\lambda_{d,L}}.
}
\tag{P23-PATH-LEV-04}
\]

This is the key new presentation: the earlier expected-leverage theorem follows by Jensen, but the pathwise form also permits probability bounds.
