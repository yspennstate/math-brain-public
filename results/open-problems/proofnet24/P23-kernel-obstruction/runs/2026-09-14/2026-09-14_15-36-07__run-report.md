## 4. New lemma P23-L4 — mean-constrained spectral counting

The previous P23 finite-block theorem bounded the number of small eigenvalues of the empirical feature covariance using only
\[
\|S-I\|_F^2.
\]
It did not exploit the exact deterministic trace
\[
\operatorname{Tr}S=D.
\]

That trace gives a strictly stronger count.

### Lemma P23-L4 — PROVED

Let \(S\succeq0\) be a \(D\times D\) matrix satisfying
\[
\operatorname{Tr}S=D.
\]
For \(0<\eta<1\), let
\[
r_\eta
=
\#\{\lambda_i(S)\ge\eta\}.
\]
Put
\[
V=\|S-I\|_F^2.
\]
Then pathwise
\[
\boxed{
r_\eta
\ge
\frac{D^2(1-\eta)^2}
{V+D(1-\eta)^2}.
}
\tag{4.1}
\]

Consequently, if \(S\) is random,
\[
\boxed{
E r_\eta
\ge
\frac{D^2(1-\eta)^2}
{E V+D(1-\eta)^2}.
}
\tag{4.2}
\]

### Proof

Write the eigenvalues as \(s_1,\ldots,s_D\). Let
\[
A=\{i:s_i<\eta\},
\qquad
m=|A|=D-r_\eta.
\]
Define the total deficit on the small-eigenvalue set
\[
\Delta
=
\sum_{i\in A}(1-s_i).
\]
Since \(s_i<\eta\),
\[
\Delta\ge m(1-\eta).
\]

Because
\[
\sum_i(s_i-1)=0,
\]
the complementary set carries total excess \(\Delta\):
\[
\sum_{i\notin A}(s_i-1)=\Delta.
\]

Cauchy gives
\[
\sum_{i\in A}(s_i-1)^2
\ge
\frac{\Delta^2}{m},
\]
and
\[
\sum_{i\notin A}(s_i-1)^2
\ge
\frac{\Delta^2}{r_\eta}.
\]
Hence
\[
V
\ge
\Delta^2
\left(
\frac1m+\frac1{r_\eta}
\right)
=
\Delta^2\frac{D}{mr_\eta}.
\]
Using \(\Delta\ge m(1-\eta)\),
\[
V
\ge
\frac{mD(1-\eta)^2}{r_\eta}.
\]
Since \(m=D-r_\eta\), rearrangement gives (4.1).

The function
\[
v\mapsto
\frac{D^2(1-\eta)^2}{v+D(1-\eta)^2}
\]
is convex, so Jensen proves (4.2).

This is a deterministic moment problem; no random-matrix theorem is involved.

## 5. Improved finite-block leverage theorem

Suppose a positive Mercer kernel contains \(D\) orthonormal eigenfunctions
\(\psi_1,\ldots,\psi_D\) with

\[
\lambda_j\ge\lambda_*>0
\]
and constant diagonal
\[
\sum_{j=1}^D\psi_j(x)^2=D.
\]

Let
\[
\Phi_{ij}=\psi_j(X_i),
\qquad
\Lambda=\operatorname{diag}(\lambda_1,\ldots,\lambda_D),
\]
\[
A=\Phi\Lambda\Phi^\top,
\qquad
B=K-A\succeq0,
\]
and let
\[
\tau=\sum_{j>D}\lambda_j
\]
be the omitted Mercer trace.

Set
\[
S=\frac1n\Phi^\top\Phi.
\]
The constant diagonal gives two exact identities:
\[
\boxed{
\operatorname{Tr}S=D
\quad\text{pathwise},
}
\tag{5.1}
\]
and
\[
\boxed{
E\|S-I\|_F^2
=
\frac{D(D-1)}n.
}
\tag{5.2}
\]

By P23-L4,
\[
\boxed{
E r_\eta
\ge
\frac{D(1-\eta)^2}
{(1-\eta)^2+(D-1)/n}.
}
\tag{5.3}
\]

Since
\[
A\succeq\lambda_*\Phi\Phi^\top,
\]
\(A\) has at least \(r_\eta\) eigenvalues
\[
\kappa_i\ge n\eta\lambda_*.
\]

Let \(u_i\) be corresponding eigenvectors and set
\[
T=\operatorname{Tr}(K^{-1}A).
\]
For \(K=A+B\), inverse Rayleigh gives
\[
(u_i^\top Ku_i)(u_i^\top K^{-1}u_i)\ge1,
\]
hence
\[
\kappa_i u_i^\top K^{-1}u_i
\ge
\frac{\kappa_i}
{\kappa_i+u_i^\top Bu_i}
\ge
1-
\frac{u_i^\top Bu_i}
{n\eta\lambda_*}.
\]
Summing,
\[
T
\ge
r_\eta
-
\frac{\operatorname{Tr}B}
{n\eta\lambda_*}.
\]
Since
\[
E\operatorname{Tr}B=n\tau,
\]
\[
\boxed{
ET
\ge
\frac{D(1-\eta)^2}
{(1-\eta)^2+(D-1)/n}
-
\frac{\tau}{\eta\lambda_*}.
}
\tag{5.4}
\]

The old P23-L3 bound had first term
\[
D-\frac{D(D-1)}{n(1-\eta)^2}.
\]
The new rational expression is strictly stronger.

### Risk conversion

For each retained eigenfunction define
\[
\phi_j=(\psi_j(X_1),\ldots,\psi_j(X_n))^\top,
\]
\[
v_j=\lambda_jK^{-1}\phi_j,
\qquad
\ell_j=\phi_j^\top v_j.
\]
Then
\[
\sum_{j=1}^D\ell_j=T,
\]
while
\[
E\|\phi_j\|^2=n.
\]
Cauchy gives
\[
(E\ell_j)^2
\le
n\,E\|v_j\|^2.
\]
Therefore
\[
\boxed{
E\mathcal E_{n,d}
\ge
\frac{\sigma^2}{nD}(ET)^2.
}
\tag{5.5}
\]

No lower singular-value estimate and no independence between \(A\) and \(B\) is used.
