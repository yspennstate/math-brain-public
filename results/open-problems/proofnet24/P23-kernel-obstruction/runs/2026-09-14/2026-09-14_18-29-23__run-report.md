# 4. Re-derivation of the feature Frobenius identity

\qquad
\Phi\in\mathbb R^{n\times D}

\[

The spherical addition theorem gives
\[
\|\Phi(X_i,\cdot)\|_2^2=D

for every sample point.

\[
\boxed{
\operatorname{Tr}S=D
}
\tag{4.1}
\]
pathwise.

Also
\[
\operatorname{Tr}(S^2)
=
\frac1{n^2}
\sum_{i,j=1}^{n}
\langle\phi(X_i),\phi(X_j)\rangle^2.

For \(i=j\), the summand is \(D^2\).

\[

\frac{nD^2+n(n-1)D}{n^2}

\tag{4.2}

No concentration theorem is used.

# 11. Why this does not prove a probability-\(1\) obstruction

The only random input used to control the empirical cumulative feature block is
\[
EW_d
=
D(D-1)/n.
\]

Markov turns this into a fixed-confidence event:
\[
W_d\le M EW_d
\]
with probability
\[
1-1/M.
\]

To obtain
\[
\Pr\{V(X)\ge c\sigma^2\}\to1
\]
for one fixed \(c>0\), one needs concentration or at least tight upper tails for
\[
W_d/n
\]
at the critical degree.

That becomes a fourth-order spherical-harmonic/U-statistic problem.

The present proof does not assume such concentration.

This distinction is deliberate.

P20's Gaussian hard-edge benchmark is a separate example in which a correct annealed quantity coexists with large conditional fluctuations.
