## 3. Required HARD10 stuck handoff

### (a) Exact blocking statement

After the complete order-nine certificate, Cocks's published fixed-graph unit-to-positive-weight upgrade, P14's exact two-cut reduction, and the three-terminal transfer reductions, the first unresolved local ten-vertex obstruction is a singleton component behind a three-separator, equivalently a degree-three vertex attached to terminals `x,y,z`.

One exact formulation from the predecessor is the two-point triangle decomposition. Let `mu_-` and `mu_+` be the two nine-vertex positive-weight terminal-triangle measures produced by the exact quadrature of the degree-three star. For a physical edge pair `e,f`, the missing inequality is

\[
\boxed{
\lambda(1-\lambda)
(p_e^- - p_e^+)(p_f^- - p_f^+)
\le
-(1-\lambda)\operatorname{Cov}_-(e,f)
-\lambda\operatorname{Cov}_+(e,f).
}
\tag{3.1}
\]

Each endpoint covariance on the right is nonpositive by the order-nine positive-weight theorem, but the environmental covariance term on the left is nonnegative because both marginals decrease with the common triangle field. Endpoint Rayleigh signs alone therefore do not control the mixture.

P14's equivalent normalized three-terminal form is

\[
\Delta(h)=q_0+q_1h+q_2h^2,
\qquad h=\frac1{16},
\qquad q_0,q_2\ge0,
\tag{3.2}
\]

with the mixed coefficient `q1` uncontrolled.

## 6. First successor probe — method #18: say cover time in another language

Let `G` be a finite connected graph, start the walk at `i`, let

\[
T_v=\inf\{t\ge0:X_t=v\},
\qquad
C=\max_{v\in V}T_v.
\]

For nonempty `S subseteq V\setminus\{i\}`, write

\[
T_S=\min_{v\in S}T_v,
\]

the first hitting time of the set `S`.

### Proposition I0028-INCLUSION-EXCLUSION-01

For every finite connected graph,

\[
\boxed{
\mathbb E_i C
=
\sum_{\varnothing\ne S\subseteq V\setminus\{i\}}
(-1)^{|S|+1}\,\mathbb E_i T_S.
}
\tag{6.1}
\]

### Proof

For each integer `t>=0`,

\[
\mathbf 1_{\{C>t\}}
=
\mathbf 1_{\bigcup_{v\ne i}\{T_v>t\}}.
\]

Apply ordinary inclusion–exclusion to the union. For a nonempty set `S`,

\[
\bigcap_{v\in S}\{T_v>t\}
=
\{T_S>t\}.
\]

Therefore

\[
\mathbf 1_{\{C>t\}}
=
\sum_{\varnothing\ne S\subseteq V\setminus\{i\}}
(-1)^{|S|+1}\mathbf 1_{\{T_S>t\}}.
\]

Sum over `t>=0` and use `E Y=sum_{t>=0}P(Y>t)` for nonnegative integer-valued `Y`. The sum over `S` is finite, so expectation and the finite inclusion–exclusion sum may be interchanged. QED.

Each individual `E_i T_S` is computable in polynomial time by solving a linear system with `S` absorbing. The source difficulty is therefore not the complexity of one hitting-time computation; it is the exponentially large alternating aggregation in (6.1).

This language exposes a concrete deterministic target: exploit structure in the alternating transform rather than simulate paths.

## 7. Method #23: assume the obvious truncation is wrong and break it exactly

A natural deterministic attempt is fixed-order Bonferroni truncation of (6.1), because for fixed order `k` it requires only `O(n^k)` hitting-time computations. Complete graphs show that this route cannot be a source PTAS.

Take `G=K_n`, start at `i`, and put `m=n-1`. For a set `S` of size `s` not containing `i`, every step taken while outside `S` hits `S` with probability `s/m`. Hence

\[
\mathbb E_iT_S=\frac{m}{s}.
\tag{7.1}
\]

Substituting into (6.1) gives

\[
\mathbb E_iC
=m\sum_{s=1}^{m}(-1)^{s+1}\binom ms\frac1s.
\tag{7.2}
\]

The classical binomial-harmonic identity

\[
\sum_{s=1}^{m}(-1)^{s+1}\binom ms\frac1s=H_m
\tag{7.3}
\]

follows by integrating

\[
\frac{1-(1-x)^m}{x}
\]

from `0` to `1`. Thus

\[
\mathbb E_iC=mH_m,
\tag{7.4}
\]

as expected from the coupon-collector description.

Let the fixed-order partial sum be

\[
B_k(m)=m\sum_{s=1}^{k}(-1)^{s+1}\binom ms\frac1s.
\tag{7.5}
\]

For fixed `k`, the final term has degree `k+1` in `m`, while all previous terms have degree at most `k`. Therefore

\[
B_k(m)
=
(-1)^{k+1}\frac{m^{k+1}}{k\,k!}+O(m^k).
\tag{7.6}
\]

Consequences:

- for every fixed even `k>=2`, `B_k(m)<0` for all sufficiently large `m`, so the corresponding lower Bonferroni bound is asymptotically useless;
- for every fixed odd `k>=1`,

\[
\frac{B_k(m)}{mH_m}\to\infty,
\tag{7.7}
\]

so the corresponding upper bound is not a multiplicative approximation.

Hence:

\[
\boxed{\text{No fixed-order inclusion–exclusion / Bonferroni truncation can solve Open Problem 6.35, even on }K_n.}
\tag{7.8}
\]

This is a proof about a proposed route, **not** a refutation of Aldous–Fill 6.35. In fact `K_n` itself is easy. The point is that any successful deterministic scheme must capture exponentially many cancellations in (6.1) implicitly rather than by a bounded subset order.

No finite checker is needed for (7.8): it is a symbolic all-`n` argument written in full above. No code-only artifact was created.

## 8. Method #10: derandomize the source's own Monte-Carlo picture

The source itself says a fixed-relative-error estimate is available by Monte Carlo. A deterministic PTAS can therefore be viewed as a derandomization problem rather than only as an exact-summation problem.

A walk prefix of length `T` can be processed by a deterministic state machine whose state is

\[
(X_t,\;V_t),
\]

where `X_t` is the current vertex and `V_t subseteq V` is the visited set. The update of `V_t` is monotone. The event `C<=T` is exactly acceptance by this structured branching program. Its width is at most

\[
n2^n,
\]

but its state transition has special graph-walk and monotone-set structure.

Universal polynomial upper bounds on graph cover time and the usual submultiplicative tail argument allow the expectation to be approximated from cover probabilities up to a polynomial horizon `T=poly(n,log(1/epsilon))`, with inverse-polynomial additive accuracy per tail probability sufficient after summation. Thus a sufficiently strong explicit pseudorandom generator / deterministic approximate counter for these **monotone visited-set random-walk branching programs** would imply a source-level approximation algorithm.

Generic space-bounded derandomization does not immediately settle the question: storing the visited set uses `Theta(n)` bits, and standard generic PRGs at that space scale do not give an `O(log n)` seed whose full enumeration is polynomial. What the source problem asks for may therefore be phrased as exploiting the additional graph-walk/monotone structure to beat generic space-bounded derandomization.

This route is exploratory. The next run should either:

1. make the reduction quantitative with an explicit tail horizon and error budget, then search the PRG / approximate-counting literature for this exact structured branching-program class; or
2. prove that an apparently natural limited-independence / bounded-subset derandomizer fails on a source-valid graph family, thereby isolating what extra pseudorandomness is needed.

The complete-graph calculation above already shows that simply replacing the path distribution by a bounded-order inclusion–exclusion surrogate cannot work.
