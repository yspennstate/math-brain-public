## 2. B2 — ATTACK THE NEGATION FIRST

### 2.1 Counterexample architecture tested

The first attempted way to refute Problem 2.8 was to build a rapidly mixing bounded-degree Ising sequence from heterogeneous disconnected components (or weakly interacting blocks) whose equilibration scales are separated enough to smear the total-variation transition. This is a natural attack because generic Markov-chain product-condition counterexamples often combine modes with incompatible time scales.

The disconnected version does **not** create a new obstruction once each block has a uniform non-equilibrium tensorization estimate. More precisely, the argument below shows that a product of blocks inherits the same dynamic approximate-tensorization constant, and Pedrotti–Salez then gives a uniformly narrow window. Thus a successful block counterexample must already contain a block whose time-marginal dependence becomes badly non-product-like; varying component sizes alone is not enough.

### 2.2 Product-stability lemma for the candidate obstruction

Let a probability measure `mu` on `{−1,+1}^V` satisfy the variance approximate-tensorization inequality

\[
\operatorname{Var}_{\mu}(f)
\le C_{\rm AT}(\mu)
\sum_{i\in V}
\mathbb E_{\mu}\!\left[
\operatorname{Var}_{\mu}(f\mid X_{V\setminus\{i\}})
\right].
\tag{AT}
\]

Suppose `V` is partitioned into independent blocks `V_1,...,V_m` and

\[
\mu=\bigotimes_{r=1}^m \mu_r,
\qquad
C_{\rm AT}(\mu_r)\le C
\quad\text{for every }r.
\]

Then

\[
C_{\rm AT}(\mu)\le C.
\tag{2.1}
\]

**Proof.** Variance tensorization across independent blocks gives

\[
\operatorname{Var}_{\mu}(f)
\le
\sum_{r=1}^m
\mathbb E_{\mu}
\operatorname{Var}\!\left(
 f\mid X_{V\setminus V_r}
\right).
\]

Condition on all coordinates outside `V_r`. The conditional law inside `V_r` is exactly `mu_r`, so applying `(AT)` in block `r` gives

\[
\operatorname{Var}\!\left(
 f\mid X_{V\setminus V_r}
\right)
\le C
\sum_{i\in V_r}
\mathbb E\!\left[
\operatorname{Var}(f\mid X_{V\setminus\{i\}})
\,
\middle|\,X_{V\setminus V_r}
\right].
\]

Averaging and summing over `r` yields `(2.1)`. `□`

For a disconnected Ising graph and a deterministic initial spin configuration, the Glauber generator is a sum of independent block generators and the time marginal factorizes blockwise. Therefore this lemma applies at every time. Consequently, any attempted no-cutoff example based only on putting already-well-behaved rapidly mixing blocks side by side cannot work through scale heterogeneity alone: it must force at least one block's **non-equilibrium** approximate-tensorization constant to diverge on the relevant window.

This is not a source theorem, but it removes one tempting counterexample architecture and identifies what a genuine counterexample would need to do.

## 3. B18 — SAY IT IN ANOTHER LANGUAGE

The strongest useful outcome of this run is an exact reduction from the Pedrotti–Salez local Poincare criterion to a time-marginal approximate-tensorization problem. This is elementary but materially sharper than saying “bound `gamma_star`”: it isolates a concrete spin-system inequality that can plausibly interact with spectral independence.

### 3.1 Setup

Consider any finite-spin Gibbs sampler on `{−1,+1}^V` with Salez's continuous-time flip generator

\[
Lf(x)=\sum_{i\in V} c_i(x)\bigl(f(x^i)-f(x)\bigr),
\tag{3.1}
\]

where `x^i` is obtained by flipping spin `i`. For the Gibbs/heat-bath implementation,

\[
c_i(x)=\frac{\pi(x^i)}{\pi(x)+\pi(x^i)}.
\tag{3.2}
\]

Let

\[
a:=\inf_{x,i} c_i(x).
\tag{3.3}
\]

For a fixed bounded-degree Ising parameter in the rapid-mixing phase, `a` is bounded away from zero uniformly in `n`, because flipping one spin changes only a bounded number of bounded-strength interactions.

The carré du champ of `(3.1)` is

\[
\Gamma f(x)
=\frac12\sum_{i\in V}
 c_i(x)\bigl(f(x^i)-f(x)\bigr)^2.
\tag{3.4}
\]

Let `mu` be any probability law on the cube (in the application, `mu=mu_t^x`, the law at time `t` from deterministic start `x`).

### 3.2 Dynamic tensorization-to-local-Poincare lemma

**Lemma.** If `mu` satisfies `(AT)` with constant `C`, then its Pedrotti–Salez local Poincare constant for the original Ising Glauber carré du champ satisfies

\[
\boxed{
\gamma(\mu)\ge \frac{2a}{C}.
}
\tag{3.5}
\]

**Proof.** From `(3.4)` and `c_i(x)\ge a`,

\[
\int\Gamma f\,d\mu
\ge
\frac a2
\sum_i
\mathbb E_\mu
\bigl(f(X^i)-f(X)\bigr)^2.
\tag{3.6}
\]

Fix coordinate `i` and condition on `Y=X_{V\setminus\{i\}}=y`. Write

\[
f_+(y)=f(y,+1),\qquad f_-(y)=f(y,-1),
\]

and

\[
q(y)=\mu(X_i=+1\mid Y=y).
\]

The squared flip difference does not depend on the current value of `X_i`, hence

\[
\mathbb E_\mu\!\left[
(f(X^i)-f(X))^2\mid Y=y
\right]
=
(f_+(y)-f_-(y))^2.
\tag{3.7}
\]

On the other hand,

\[
\operatorname{Var}_\mu(f\mid Y=y)
=q(y)(1-q(y))(f_+(y)-f_-(y))^2
\le \frac14(f_+(y)-f_-(y))^2.
\tag{3.8}
\]

Combining `(3.7)` and `(3.8)` and averaging over `Y` gives

\[
\mathbb E_\mu(f(X^i)-f(X))^2
\ge
4\,\mathbb E_\mu\operatorname{Var}_\mu
(f\mid X_{V\setminus\{i\}}).
\tag{3.9}
\]

Insert `(3.9)` into `(3.6)`:

\[
\int\Gamma f\,d\mu
\ge
2a
\sum_i
\mathbb E_\mu\operatorname{Var}_\mu
(f\mid X_{V\setminus\{i\}}).
\tag{3.10}
\]

Finally `(AT)` implies

\[
\int\Gamma f\,d\mu
\ge \frac{2a}{C}\operatorname{Var}_\mu(f),
\]

which is precisely `(3.5)`. `□`

No finite checker is relevant here; this is a direct symbolic proof.

### 3.3 Consequence for the cutoff problem

For each deterministic start `x`, let `mu_t^x` be the time-`t` law and let

\[
I_x(\varepsilon)=
[t_{\rm mix}^{(x)}(1-\varepsilon),
 t_{\rm mix}^{(x)}(\varepsilon)].
\]

Assume that, uniformly in the starting state `x` and in `t in I_x(epsilon)`,

\[
C_{\rm AT}(\mu_t^x)\le C_n.
\tag{3.11}
\]

Then `(3.5)` gives a restricted local Poincare lower bound

\[
\gamma_{\varepsilon}^{(x)}
\ge \frac{2a_n}{C_n}.
\tag{3.12}
\]

Pedrotti–Salez Theorem 1 plus their Remark 2 therefore yields for every initial state

\[
t_{\rm mix}^{(x)}(\varepsilon)
-
 t_{\rm mix}^{(x)}(1-\varepsilon)
\le
\frac{3C_n}{4a_n}
\log\frac1\varepsilon.
\tag{3.13}
\]

Because the right-hand side is uniform in `x`, the same bound holds for the worst-case window: choose a state attaining (or approximating, in the finite state space attaining) the worst-case `t_mix(epsilon)` and use `t_mix^*(1-epsilon) >= t_mix^(x)(1-epsilon)`.

Thus a sufficient route to the full source problem is:

\[
\boxed{
C_{\rm AT}(\mu_t^x)
=o\!\bigl(a_n\,t_{\rm mix}^{\star}(\varepsilon)\bigr)
\text{ uniformly on the mixing window.}
}
\tag{3.14}
\]

In the standard bounded-degree fixed-parameter rapid-mixing regime, `a_n >= a > 0` and the natural continuous-time mixing scale is logarithmic in the number of spins, so the particularly clean target is

\[
C_{\rm AT}(\mu_t^x)=o(\log n),
\tag{3.15}
\]

while a uniform `O(1)` bound would give an `O(1)` cutoff window.

This is **PARTIAL**. It does not prove `(3.11)` in the full tree-uniqueness regime. Its value is that it replaces the abstract non-equilibrium Poincare blocker by a concrete time-marginal variance-factorization problem, exactly the language in which equilibrium spectral-independence technology already operates.

### 3.4 Why equilibrium spectral independence is not yet enough

The rapid-mixing theorems in the tree-uniqueness regime obtain equilibrium functional inequalities from spectral independence/entropy factorization of the Gibbs law `pi` and its pinnings. The measure needed in `(3.11)` is not `pi`; it is the **non-equilibrium time marginal** `mu_t^x`.

A proof therefore needs one of the following genuinely new bridges:

1. show that the time marginals `mu_t^x` themselves satisfy a uniform/sublogarithmic approximate-tensorization inequality through the mixing window;
2. prove a dynamic spectral-independence statement for `mu_t^x` and convert it to `(AT)`;
3. bypass full `(AT)` and prove the Pedrotti–Salez restricted local Poincare inequality directly on the mixing window.

Equilibrium spectral independence by itself supplies none of these implications.

### 3.5 Exact covariance evolution and why the naive dynamic-SI closure falls back to high temperature

For the standard heat-bath normalization, write

\[
m_i(\sigma)=\mathbb E_\pi[\sigma_i\mid \sigma_{V\setminus\{i\}}].
\]

Then

\[
L\sigma_i=m_i(\sigma)-\sigma_i.
\]

For distinct `i,j`, if `C_{ij}(t)=Cov_{\mu_t}(\sigma_i,\sigma_j)`, direct differentiation gives the exact identity

\[
\boxed{
\frac{d}{dt}C_{ij}(t)
=-2C_{ij}(t)
+\operatorname{Cov}_{\mu_t}(m_i(\sigma),\sigma_j)
+\operatorname{Cov}_{\mu_t}(\sigma_i,m_j(\sigma)).
}
\tag{3.16}
\]

The obvious attempt is to dominate the two new covariance terms by a static influence/Dobrushin matrix using coordinate Lipschitz constants of `m_i`. This closes only when the corresponding influence operator is contractive in an absolute norm — essentially the classical high-temperature/Dobrushin type region, i.e. precisely where cutoff technology is already available. The full tree-uniqueness range requires exploiting cancellation, cavity/nonbacktracking structure, or a different norm; an absolute-value covariance closure throws away the information that spectral independence uses to go beyond Dobrushin.

This explains concretely why “differentiate the influence matrix” is not, by itself, the missing proof.

## 5. Failed / rejected routes this run

1. **Disconnected heterogeneous components as an automatic no-cutoff construction.** Rejected as a standalone mechanism: dynamic approximate tensorization tensorizes over independent blocks. Such a counterexample must already contain a block with a diverging non-equilibrium tensorization/local-Poincare obstruction.

2. **Use equilibrium spectral independence directly in Pedrotti–Salez.** Invalid: `gamma(mu_t)` is a Poincare constant for the evolving law, not for equilibrium. A bridge from equilibrium SI to non-equilibrium factorization is exactly what is missing.

3. **Close the time-dependent covariance equation by absolute Dobrushin influences.** This re-enters the already-solved high-temperature region and loses the cancellation/cavity structure needed to reach tree uniqueness.

4. **Claim the July 2026 local-product theorem solves Problem 2.8.** Rejected by direct re-reading. The theorem supplies a universal cutoff criterion, but its Ising application stated in the paper is via positive curvature/high temperature, not the entire rapidly-mixing bounded-degree regime.
