### Original source, rechecked 2026-09-17

Aldous–Fill, *Reversible Markov Chains and Random Walks on Graphs*, Chapter 6 §6.8.3, says immediately before Open Problem 6.35:

> “Consider the question of getting a numerical value for `E_i C` (up to error factor `1±epsilon`, for fixed `epsilon`) for random walk on a `n`-vertex graph.”

The main scope facts remain:

2. Chlamtac–Feige (2005), DOI `10.1016/j.tcs.2005.03.042`, improve the fixed-start factor to `O(log n (log log n)^2)` and show a `c(n)` max-start approximation yields `O(c(n) log n)` for general fixed start.

## 3. B5 — add one discount parameter: the whole PTAS reduces to one transform value

The new parameter is a geometric discount `z=1-h` close to one.

For fixed start `i`, define the probability generating transform

\[
G_i(z):=E_i[z^C],\qquad 0<z<1.
\tag{3.1}
\]

The derivative at one formally satisfies `G_i'(1)=E_iC`. Computing a derivative by taking `z` extremely close to one would normally be numerically dangerous. The cover-time tail bound gives enough moment control to choose an **inverse-polynomial** distance from one and make the deformation quantitative.

### Lemma I0028-SECOND-MOMENT-02

For every connected simple graph,

\[
\boxed{E_i[C^2]\le 24U^2,\qquad U=2m(n-1).}
\tag{3.2}
\]

#### Proof

Put

\[
Y=\left\lceil\frac{C}{2U}\right\rceil.
\]

By (2.1), for every integer `j>=0`,

\[
P(Y>j)=P(C>2Uj)\le 2^{-j}.
\]

For a positive integer-valued random variable,

\[
E[Y^2]
=
\sum_{j\ge0}\big((j+1)^2-j^2\big)P(Y>j).
\]

Hence

\[
E[Y^2]
\le
\sum_{j\ge0}(2j+1)2^{-j}
=6.
\]

Since `C<=2UY`,

\[
E[C^2]\le4U^2E[Y^2]\le24U^2.
\]

QED.

### Lemma I0028-DISCOUNT-BIAS-02

For every integer `c>=0` and `0<h<1`,

\[
\boxed{
 c-\frac h2c^2
\le
\frac{1-(1-h)^c}{h}
\le c.
}
\tag{3.3}
\]

#### Proof

The upper bound is Bernoulli's inequality:

\[
1-(1-h)^c\le ch.
\]

For the lower bound, view `1-(1-h)^c` as the probability that at least one of `c` independent events of probability `h` occurs. The second Bonferroni inequality gives

\[
1-(1-h)^c
\ge
ch-\binom c2h^2
\ge
ch-\frac{c^2h^2}{2}.
\]

Divide by `h`. QED.

### Proposition I0028-ONE-DISCOUNT-REDUCTION-02

Let `G` be a connected simple graph with `n>=2` vertices, `m` edges, fixed start `i`, and

\[
L=n-1,
\qquad
U=2m(n-1).
\]

Fix `0<epsilon<=1` and set

\[
\boxed{
h=\frac{\epsilon L}{48U^2},
\qquad
z=1-h.
}
\tag{3.4}
\]

Then

\[
\boxed{
0
\le
E_iC-\frac{1-G_i(z)}h
\le
\frac{\epsilon L}{4}
\le
\frac{\epsilon}{4}E_iC.
}
\tag{3.5}
\]

Consequently, it is sufficient to deterministically approximate the **single value** `G_i(1-h)` to additive accuracy

\[
\boxed{
\delta
=
\frac{\epsilon hL}{4}
=
\frac{\epsilon^2L^2}{192U^2}.
}
\tag{3.6}
\]

Indeed, if `|\widehat G-G_i(z)|<=delta`, then

\[
\widehat\mu_i:=\frac{1-\widehat G}{h}
\]

satisfies

\[
|\widehat\mu_i-E_iC|
\le
\frac\epsilon2E_iC
<
\epsilon E_iC.
\tag{3.7}
\]

For fixed `epsilon`, both `1/h` and `1/delta` are polynomial in `n` because `U< n^3`.

#### Proof

Apply (3.3) pointwise at `c=C`, take expectation, and use (3.2):

\[
0
\le
E_iC-\frac{1-E_i[(1-h)^C]}h
\le
\frac h2E_i[C^2]
\le
12hU^2
=
\frac{\epsilon L}{4}.
\]

Since every cover requires at least `L=n-1` steps,

\[
E_iC\ge L,
\]

which yields the final inequality in (3.5).

The oracle error contributes

\[
\left|
\frac{1-\widehat G}{h}
-
\frac{1-G_i(z)}h
\right|
\le
\frac\delta h
=
\frac{\epsilon L}{4}
\le
\frac\epsilon4E_iC.
\]

Adding this to the discount bias proves (3.7). Finally `m<=n(n-1)/2`, so `U=2m(n-1)<n^3`, and the prescribed inverse accuracies are polynomially bounded. QED.

### What B5 changes

The preceding run needed polynomially many additive estimates of finite-horizon survival probabilities. Proposition 3.3 compresses that requirement to **one rational point of one generating function**.

This does not solve the source problem: the unresolved task is now to approximate `G_i(1-h)` deterministically. But it is a strictly narrower primitive than reconstructing a useful portion of the full cover-time distribution.

## 4. B29 — add a cemetery state: the transform is one cover-before-killing probability

The discount has a pathwise interpretation that removes the appearance of numerical differentiation.

Let `K` be independent of the walk and satisfy

\[
P(K\ge c)=z^c=(1-h)^c,
\qquad c=0,1,2,\ldots.
\tag{4.1}
\]

Equivalently, after each step the walk is killed with probability `h`, independently of the past; `K` is the number of successfully survived steps before the cemetery state is entered.

Conditioning on `C` gives

\[
P_i(C\le K\mid C)=z^C.
\]

Therefore

\[
\boxed{
G_i(z)=P_i(C\le K),
\qquad
Q_i(h):=1-G_i(1-h)=P_i(K<C).
}
\tag{4.2}
\]

So Proposition 3.3 can be stated without transforms:

> At the single inverse-polynomial killing rate `h=epsilon(n-1)/(48U^2)`, deterministic approximation of the probability that the walk is killed before it covers the graph is enough to approximate the expected cover time.

In fact (3.5) says

\[
\mu_i-\frac{\epsilon L}{4}
\le
\frac{Q_i(h)}h
\le
\mu_i,
\qquad \mu_i=E_iC.
\tag{4.3}
\]

Because `epsilon<=1` and `mu_i>=L`,

\[
Q_i(h)
\ge
h\left(\mu_i-\frac{\epsilon L}{4}\right)
\ge
\frac34hL.
\tag{4.4}
\]

Thus the relevant rare-event probability is **not exponentially small**: the explicit lower bound is inverse-polynomial. A deterministic relative approximation to `Q_i(h)` is therefore enough as well.

For example, if

\[
|\widehat Q-Q_i(h)|\le\frac\epsilon2Q_i(h),
\]

then

\[
\widehat\mu_i=\widehat Q/h
\]

has total relative error at most `3epsilon/4` by combining the `epsilon/4` deformation bias with the `epsilon/2` relative oracle error.

### Why the cemetery formulation is useful

It changes the derandomization target from

“estimate a stopping-time expectation”

to

“estimate one absorbing-event probability in a walk with one added cemetery state.”

The killed trajectory has expected lifetime `1/h=poly(n,1/epsilon)`. A randomized estimator is immediate; the open content is deterministic approximate counting of this particular absorption-before-coverage event.

This is exactly the kind of boundary point that B29 is meant to expose: instead of trying to carry the infinite tail of `C`, compactify the walk by an independent cemetery state, choose the killing rate so the first-order response still remembers `E_iC`, and quantify the curvature error by a second moment.

## 5. B25 — double-count the killed failure event: exact intersection oracle, exponential Möbius aggregation

The cemetery formulation makes the remaining combinatorial obstruction unusually explicit.

Let

\[
W=V\setminus\{i\}.
\]

For `v in W`, let `T_v` be its first hitting time and define

\[
A_v=\{K<T_v\},
\]

the event that killing occurs before vertex `v` is ever visited.

The walk is killed before cover exactly when at least one target vertex is still missing, so

\[
\boxed{
Q_i(h)=P_i\left(\bigcup_{v\in W}A_v\right).
}
\tag{5.1}
\]

For nonempty `S subseteq W`, let

\[
T_S=\min_{v\in S}T_v.
\]

Then

\[
\bigcap_{v\in S}A_v
=
\{K<T_S\},
\]

and conditioning on `T_S` gives the exact intersection probability

\[
\boxed{
P_i\left(\bigcap_{v\in S}A_v\right)
=1-E_i[z^{T_S}].
}
\tag{5.2}
\]

Hence ordinary inclusion–exclusion yields

\[
\boxed{
Q_i(h)
=
\sum_{\varnothing\ne S\subseteq W}
(-1)^{|S|+1}
\left(1-E_i[z^{T_S}]\right).
}
\tag{5.3}
\]

Since

\[
\sum_{\varnothing\ne S\subseteq W}(-1)^{|S|+1}=1,
\]

this is equivalently the transform identity

\[
\boxed{
G_i(z)
=
\sum_{\varnothing\ne S\subseteq W}
(-1)^{|S|+1}E_i[z^{T_S}].
}
\tag{5.4}
\]

### Every intersection term is polynomial-time computable

Fix `S`. Define

\[
f_S(x)=E_x[z^{T_S}].
\]

Then

\[
f_S(x)=1\quad(x\in S)
\tag{5.5}
\]

and for `x notin S`, one step of the walk gives

\[
\boxed{
f_S(x)=z\sum_yP(x,y)f_S(y).
}
\tag{5.6}
\]

For rational `z` and the rational transition matrix of simple random walk, (5.5)–(5.6) is an `n`-state rational linear system. Thus any specified intersection in (5.3) is computable in polynomial time by exact rational linear algebra.

This creates a sharp reformulation:

\[
\boxed{
\begin{array}{c}
\text{I0028 reduces to deterministic relative approximation of one union}\
\text{of }n-1\text{ events whose every requested intersection probability}\
\text{has a polynomial-time exact resolvent oracle.}
\end{array}}
\tag{5.7}
\]

The unresolved issue is not a difficult individual hitting probability; it is the Boolean-lattice aggregation.

### Relation to prior work; no false novelty claim

This subset Möbius structure is not new. Ohwa (2010) explicitly presents cover-time distribution identities as Möbius inversion, building on Ohwa–Shirai (2008). Feige–Rabinovich §2.6 explicitly explored approximate inclusion–exclusion for the per-time failure events `F_s[v|t]` and observed that exact inclusion–exclusion has `2^n` intersections; their generic approximate-inclusion–exclusion route did not yield the desired polynomial-time high-accuracy cover-time algorithm.

The genuinely new-to-this-track point is narrower: **one inverse-polynomial geometric killing rate suffices**, so one can attack a single integrated union probability rather than approximate the cover-time distribution at many horizons.

### Exact symbolic computation is still too strong

The full transform has power-series expansion

\[
G_i(z)=\sum_{t\ge n-1}P_i(C=t)z^t.
\tag{5.8}
\]

Therefore its first nonzero coefficient is

\[
[z^{n-1}]G_i(z)=P_i(C=n-1).
\tag{5.9}
\]

The preceding report already proved that `P_i(C=n-1)` is the weighted sum of Hamiltonian paths starting at `i` (and, on a regular graph, equals the number of such paths divided by `d^{n-1}`). Thus an exact symbolic formula for the entire transform would expose hard-looking Hamiltonian information immediately.

This is **not** a #P-hardness claim for approximating the single near-one value in Proposition 3.3. The low-degree coefficient may be irrelevant to inverse-polynomial additive accuracy at `z=1-h`. The conclusion is only that seeking a complete exact rational-function collapse is solving a much stronger problem than the source requires.

### A useful failure boundary inherited from Feige–Rabinovich

Feige–Rabinovich's approximate-inclusion–exclusion discussion is a warning against merely taking the first `k` subset levels. Generic Bonferroni information can require growing `k`; the predecessor already exhibited a concrete complete-graph failure of every fixed-order truncation for the mean. Integrating in geometric time changes the object, but does not by itself prove that a fixed number of intersection levels controls (5.3).

So the next successful route must use additional **random-walk structure** of the family `A_v`, not generic union approximation alone.
