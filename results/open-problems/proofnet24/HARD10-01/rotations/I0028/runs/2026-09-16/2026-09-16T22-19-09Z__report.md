### 2.1 What Aldous–Fill actually asks

Section 6.8.3 says, immediately before Open Problem 6.35:

It then states Open Problem 6.35:

> Can `E_i C` be deterministically calculated in a polynomial (in `n`) number of steps?

The source itself then explains the obvious exact state-space obstruction: adding the already-visited subset produces an `n x 2^(n-1)` state chain.

Accordingly, this track retains the admitted **fixed-start** fixed-relative-error interpretation. I do not replace `E_i C` by the maximum over starting vertices.

### 2.2 The Ding–Lee–Peres `O(1)` theorem is max-start, not literal fixed-start `E_i C`

The dispatch claim/admission described Ding–Lee–Peres (2012) as giving a deterministic `O(1)` approximation for the general source problem. Re-reading the primary paper shows that this is too broad for the frozen I0028 scope.

Ding, Lee and Peres, *Cover times, blanket times, and majorizing measures*, Annals of Mathematics 175 (2012), define

\[
t_{\rm cov}(G)=\max_{v\in V} E_v\tau_{\rm cov}.
\]

Their computational Question 1.2 explicitly asks for a deterministic constant-factor approximation to this **maximum-start** parameter, and Theorems 1.2/1.5 resolve that max-start question through `gamma_2`.

Primary PDF:

<https://annals.math.princeton.edu/wp-content/uploads/annals-v175-n3-p08-p.pdf>

Thus DLP does not by itself give a constant-factor algorithm for the literal Aldous–Fill quantity `E_i C` with an arbitrary specified start `i`.

This distinction is not cosmetic. Feige–Rabinovich (2003) specifically emphasize that the starting vertex is part of the input and exhibit graphs on which changing the start changes the expected cover time by as much as

\[
\Theta\!\left(\frac{n^{3/2}}{\sqrt{\log n}}\right).
\]

Source:

Uriel Feige and Yuri Rabinovich, *Deterministic Approximation of the Cover Time*, Random Structures & Algorithms 23 (2003), 1–22, DOI `10.1002/rsa.10083`.

Chlamtac–Feige (2005) give the source-relevant comparison explicitly: from any `c(n)`-approximation for the **maximum** cover time, they obtain only an

\[
O(c(n)\log n)
\]

approximation for the general fixed-start cover time. They also improve the then-current direct fixed-start algorithm to

\[
O(\log n(\log\log n)^2).
\]

Source:

Eden Chlamtac and Uriel Feige, *Improved approximation of the minimum cover time*, Theoretical Computer Science 341 (2005), 22–38, DOI `10.1016/j.tcs.2005.03.042`.

Combining their transfer with DLP's max-start `O(1)` theorem yields an **`O(log n)` fixed-start approximation**, not a source-matching universal constant factor.

Therefore the current I0028 ledger should not use DLP's `O(1)` theorem as a finite value of `A_gen`. Under the already-frozen metric, `A_gen` remains **UNMEASURED** rather than being assigned an unsupported constant.

This is a scope correction to the dispatch prose, not a claim that DLP is wrong. DLP genuinely solves the max-start constant-factor question that they formulate and attribute to earlier work; it is simply a different quantity from literal fixed-start `E_i C` in Aldous–Fill §6.8.3.

### 2.3 Restricted PTAS results also do not close the frozen source

Feige–Zeitouni give a deterministic approximation scheme on trees. Meka's Gaussian-process PTAS, combined with Ding's asymptotic cover-time/GFF theorem, yields a PTAS for a bounded-degree/well-separated max-start cover-time regime; Meka explicitly defines cover time in that application as the expectation from the **worst possible vertex**. These are important restricted results but neither is the unrestricted fixed-start source target.

Fresh bounded searches through 2026 found no deterministic `(1±epsilon)` algorithm for arbitrary fixed-start `E_i C`. A recent August 2026 paper by Ian Meng Si, *Nonlocality of Cover-Time Changes Under Edge Addition* (arXiv:2608.27474), studies exact **fixed-start** cover-time response formulas under edge insertion, but does not provide the source-matching deterministic PTAS. This is bounded negative evidence, not a novelty certificate.

## 3. B21 — who else has the branching-program shape?

The predecessor represented a length-`T` walk using the obvious state

\[
(X_t,V_t),
\]

where `V_t` is the set of vertices visited so far. This has width on the order of

\[
n2^{n-1}.
\]

I searched the current derandomization literature for exactly this kind of structured branching program rather than assuming that generic logspace machinery applies efficiently.

### 3.1 Regular ROBPs: seed length still sees the exponential width

Braverman–Rao–Raz–Yehudayoff give an `epsilon`-PRG for regular read-once branching programs of length `T` and width `w` with seed length

\[
O\bigl((\log w+\log\log T+\log(1/\epsilon))\log T\bigr).
\]

For the direct cover-state program, `log w = Theta(n)`. Even when `T=poly(n)`, enumerating all seeds is therefore superpolynomial. The generic width-sensitive theorem does not yield the desired deterministic polynomial-time approximation.

Reference: Braverman, Rao, Raz, Yehudayoff, *Pseudorandom Generators for Regular Branching Programs*, SIAM J. Comput. 43 (2014), 973–986, DOI `10.1137/120875673`.

### 3.2 “Monotone ROBP” is not the same as “the visited set only grows”

Doron–Meka–Reingold–Tal–Vadhan (APPROX/RANDOM 2021) obtain a near-logarithmic/optimal-logarithmic seed for **constant-width monotone ROBPs**. Their monotonicity means that states at each time can be totally ordered so that same-labelled transitions do not cross; equivalently each fixed-input transition is a monotone map in that total order.

The cover process has a different monotonicity: `V_t` grows by **set inclusion**, a high-dimensional partial order, while the current position changes inside that set. No total ordering with the required noncrossing transition property has been proved, and the width is exponential anyway. Therefore their theorem is a useful neighbour, but not a black-box solution.

Reference: Doron, Meka, Reingold, Tal, Vadhan, *Pseudorandom Generators for Read-Once Monotone Branching Programs*, APPROX/RANDOM 2021 / ECCC TR21-018.

### 3.3 The 2025–2026 frontier confirms that generic ROBP derandomization is still a hard problem

Cheng–Wu, *Weighted Pseudorandom Generators for Read-Once Branching Programs via Weighted Pseudorandom Reductions*, SODA 2026, explicitly frames improved ROBP derandomization as progress toward the fundamental `BPL ?= L` problem and gives improved seed bounds, not a general optimal-log seed that would make the cover-state enumeration polynomial.

Reference: SODA 2026, DOI `10.1137/1.9781611978971.124`; ECCC TR25-027.

A useful conceptual compression is possible: given a complete random-choice tape describing a trajectory, the predicate “does this trajectory cover `G` by time `T`?” can be checked with small workspace by looping over target vertices and re-simulating the trajectory for each target instead of storing the full visited set. But this uses **re-reading the random tape**; it is no longer the same read-once program. Generic pseudorandomness for logspace is itself a major derandomization frontier. Thus the visited-set space blowup can be traded for a read-many/random-tape issue, but not eliminated for free.

**B21 outcome:** there is genuine adjacent machinery, but the exact obstacle is now sharper: exploit the *random-walk transition structure plus an all-vertices coverage predicate*, rather than trying to apply a generic constant-width or regular-ROBP PRG.

## 4. B20 — why the obvious exact finite-horizon route already contains hard combinatorics

A deterministic expectation algorithm based on

1. compute every finite-horizon cover probability exactly, then
2. sum the tail

looks tempting after the predecessor's inclusion-exclusion identity. The earliest possible horizon already shows why exact horizon evaluation is not the right subroutine.

### Proposition I0028-MIN-HORIZON-HP-01

Let `G=(V,E)` be a connected finite simple graph with `n=|V|`, let the walk start at `i`, and let `C` be its cover time. Let `HP_i(G)` be the set of oriented Hamiltonian paths

\[
(v_0,v_1,\ldots,v_{n-1})
\]

in `G` with `v_0=i`. Then

\[
\boxed{
P_i(C\le n-1)
=
\sum_{(v_0,\ldots,v_{n-1})\in HP_i(G)}
\prod_{k=0}^{n-2}\frac{1}{\deg(v_k)}.
}
\tag{4.1}
\]

In particular, if `G` is `d`-regular and `H_i(G)=|HP_i(G)|`, then

\[
\boxed{
P_i(C\le n-1)=\frac{H_i(G)}{d^{n-1}}.
}
\tag{4.2}
\]

### Proof

A walk has exactly `n` visited positions at times `0,1,...,n-1`. Since `G` has `n` vertices, covering by time `n-1` is possible if and only if those `n` positions are all distinct. Such a trajectory is exactly an oriented Hamiltonian path starting at `i`.

For a fixed path `(v_0,...,v_{n-1})`, the simple random walk follows it with probability

\[
\prod_{k=0}^{n-2}\frac1{\deg(v_k)}.
\]

Distinct Hamiltonian paths give disjoint trajectory events, so summing their probabilities proves (4.1). If every degree is `d`, each path has probability `d^{-(n-1)}`, giving (4.2). QED.

This is **not** promoted to a complexity-hardness theorem. Although Hamiltonian-path counting is visible in the exact formula, this run did not establish an approximation-preserving reduction from a counting problem to the fixed-relative-error expected-cover-time problem. In particular, the earliest-horizon mass can be exponentially small and therefore irrelevant to a relative approximation of the mean. The correct lesson is narrower: **exact horizon probabilities are unnecessarily strong subroutines for the source PTAS.**

An independent exact-arithmetic self-check was executed on `P4`, `C4`, `K4`, `K3,3`, and `K1,3`. It compares direct enumeration of every length-`n-1` random-walk trajectory against the weighted Hamiltonian-path sum and, on regular examples, the simplified formula (4.2). ## 5. B30 — reduce the source PTAS to one finite-horizon additive-counting primitive

The previous section says exact horizon probabilities are too ambitious. The right question is how accurately they actually need to be known.

The following reduction gives a concrete answer.

### Proposition I0028-HORIZON-ORACLE-REDUCTION-01

Let `G` be a connected simple graph with `n>=2` vertices and `m` edges, and fix a start vertex `i`. Put

\[
\mu_i=E_i C,
\qquad
U=2m(n-1).
\]

Suppose there is a deterministic algorithm which, for any integer horizon `t<=T` and additive accuracy `delta>0`, computes a number `q_t` satisfying

\[
|q_t-P_i(C>t)|\le\delta
\tag{5.1}
\]

in time polynomial in `n`, `t`, and `1/delta` (for fixed source error parameter `epsilon`). Then `mu_i` admits a deterministic polynomial-time `(1±epsilon)` approximation.

More explicitly, define

\[
K=\left\lceil
\log_2\frac{8U}{\epsilon(n-1)}
\right\rceil,
\qquad
T=2UK-1,
\tag{5.2}
\]

and

\[
\delta=\frac{\epsilon(n-1)}{2(T+1)}.
\tag{5.3}
\]

Then

\[
\widehat\mu_i=\sum_{t=0}^{T}q_t
\]

satisfies

\[
|\widehat\mu_i-\mu_i|\le \epsilon\mu_i.
\tag{5.4}
\]

### Proof

The standard spanning-tree/commute-time bound gives, uniformly over every start vertex `x`,

\[
E_x C\le U=2m(n-1).
\tag{5.5}
\]

Now condition on the entire walk history at any deterministic time `s` on the event that the graph has not yet been covered. If the current vertex is `x` and some vertices have already been visited, the time needed to visit only the still-unvisited vertices is pathwise no larger than the time a fresh walk from `x` needs to cover **all** vertices. Hence its conditional expectation is at most `U`.

Markov's inequality therefore gives

\[
P(C>s+2U\mid \mathcal F_s,\ C>s)\le\frac12.
\tag{5.6}
\]

Iterating at the deterministic block endpoints yields

\[
P_i(C>2Uj)\le 2^{-j}
\qquad(j\ge0).
\tag{5.7}
\]

Since the tail probability is decreasing, the omitted tail after `2UK` is bounded by

\[
\begin{aligned}
\sum_{t=2UK}^{\infty}P_i(C>t)
&\le
2U\sum_{j=K}^{\infty}2^{-j}\\
&=4U2^{-K}\\
&\le \frac{\epsilon(n-1)}2.
\end{aligned}
\tag{5.8}
\]

Also every cover requires at least `n-1` steps, so

\[
\mu_i\ge n-1.
\tag{5.9}
\]

The error in the retained finite sum is, by (5.1) and (5.3), at most

\[
(T+1)\delta=\frac{\epsilon(n-1)}2.
\tag{5.10}
\]

Combining (5.8)–(5.10) gives total absolute error at most

\[
\epsilon(n-1)\le\epsilon\mu_i,
\]

which is (5.4). Finally, `U<n^3`, `K=O(log(n/epsilon))`, and therefore `T` and `1/delta` are polynomial in `n` for every fixed `epsilon`. QED.

### Why this matters

This reduction turns the broad source problem into a very specific derandomization target:

> **Finite-horizon primitive.** Deterministically approximate the probability that one simple random-walk trajectory has failed to cover `G` by a given polynomial horizon `t`, to inverse-polynomial additive error.

That primitive is substantially weaker than exact visited-set dynamic programming and ignores exponentially tiny early-horizon phenomena such as (4.1) when they do not affect the mean at relative scale.

It also explains how a PRG would be used if one can exploit the special structure. A polynomial horizon and inverse-polynomial additive error only require a pseudorandom sample space of polynomial size, equivalently a seed of `O(log n)` bits for fixed `epsilon`. Generic logspace/ROBP PRGs do not presently give that for the cover predicate in the needed unrestricted setting; finding a cover-specific generator or deterministic approximate counter is therefore a genuinely source-relevant attack rather than an attempt to solve the full `n2^n` dynamic program.

**B30 outcome:** the remaining obligation is now one well-defined additive counting problem at one horizon. The expectation gluing itself costs only polynomially many such calls and introduces no exponential loss.

## 6. What failed, what survived, and the next attack

### Failed / non-load-bearing routes this run

1. **Treat DLP's `O(1)` approximation as source-matching.** False scope: DLP's `t_cov` maximizes over starts; literal Aldous–Fill 6.35 fixes `i`.
2. **Apply generic regular-ROBP PRGs to the visited-set state.** Width is exponential, so the seed length still has an `Omega(n)`-scale dependence and exhaustive seed enumeration is not polynomial.
3. **Invoke “monotone branching program” because `V_t` grows monotonically.** The literature's monotonicity is a total-order/noncrossing-transition property, not set inclusion.
4. **Compute exact finite-horizon cover probabilities.** Proposition (4.1) shows that even the first possible cover horizon already contains weighted Hamiltonian-path enumeration. Exactness is stronger than the source needs.

### Surviving route

The source PTAS follows from deterministic inverse-polynomial additive approximation to the finite-horizon noncoverage probability `P_i(C>t)` for `t=poly(n)` by Proposition I0028-HORIZON-ORACLE-REDUCTION-01.

The most promising next step is to exploit the event's **two simultaneous structures**:

- the trajectory is generated by local random-walk transitions, not arbitrary random bits;
- acceptance is an all-target coverage predicate which can be checked by repeatedly re-simulating one trajectory, avoiding an explicit `2^n` visited-set memory if the random tape can be revisited/recomputed.

A generic derandomization of arbitrary logspace is too broad. The next run should look for a pseudorandom object tailored to undirected random walks that supports **multi-target / cover-event tests**, or prove a source-valid obstruction to such a route.
