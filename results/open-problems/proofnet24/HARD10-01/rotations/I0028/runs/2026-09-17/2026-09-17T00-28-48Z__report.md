## 2. Dated literature check and the exact historical failure we must not rediscover

### 2.1 Feige–Rabinovich already studied the two most tempting routes

Uriel Feige and Yuri Rabinovich, *Deterministic Approximation of the Cover Time*, Random Structures & Algorithms 23 (2003), 1–22, DOI `10.1002/rsa.10083`, give a deterministic polylogarithmic approximation for an arbitrary specified starting vertex.

The full paper is especially relevant here because its Section 2 already records two failures which match our current obstruction:

1. **Derandomization.** They observe that simulation of the random walk itself is log-space, but maintaining the set of vertices visited so far appears to require linear space. They explicitly leave open whether a space-bounded pseudorandom generator can nevertheless approximate cover time.

2. **Approximate inclusion–exclusion.** They let the events be “vertex `v` has not been visited by horizon `t`.” Every intersection probability is computable by a hitting-set calculation. Generic approximate inclusion–exclusion requires intersections up to about `sqrt(n)` to get a very small relative error, yielding an `n^{O(sqrt(n))}` algorithm. They explicitly speculate that the special Markov-chain origin of these event probabilities might permit substantially better approximation.

This is prior art. The present killed-walk formulation is a time-compressed version of the same subset aggregation obstruction; it is **not** a rediscovery to be marketed as a new inclusion–exclusion method.

### 2.2 Ding–Lee–Peres does not supply the frozen fixed-start PTAS

Jian Ding, James R. Lee and Yuval Peres, *Cover times, blanket times, and majorizing measures*, Annals of Mathematics 175 (2012), define

`tcov(G) = max_v E_v tau_cov`

and give a deterministic polynomial-time `O(1)` approximation for this max-start graph parameter. Their paper describes this as answering a question of Aldous–Fill, but the theorem is a constant-factor theorem for `tcov(G)`, not a deterministic `(1±epsilon)` algorithm for every specified-start `E_i C`.

This distinction is essential here because Feige–Rabinovich exhibit graphs on which changing the starting vertex changes expected cover time by a factor of order

`n^(3/2) / sqrt(log n)`.

Consequently a start-insensitive max-start approximation cannot simply be reused as a constant-factor approximation for arbitrary specified start.

### 2.3 Nearest positive PTAS results checked

Uriel Feige and Ofer Zeitouni, *Deterministic approximation for the cover time of trees* (2009), give a deterministic PTAS for trees, with the starting vertex as input. Their dynamic program uses, for each rooted subtree, probabilities of the form

`P_i(t) = probability the subtree rooted at i is covered before its parent edge has been traversed t times`.

The unique parent edge is what turns the interaction with the rest of the graph into a one-dimensional excursion counter.

Raghu Meka's PTAS for Gaussian suprema, combined with Ding's cover-time work, yields a PTAS for bounded-degree graphs. This remains a proper subclass and does not settle unrestricted specified-start cover time.

A bounded fresh search through 2026-09-17 did not locate a deterministic `(1±epsilon)` algorithm for unrestricted specified-start cover time. This is dated negative evidence only, not a novelty certificate.

## 4. B17 — the killed formulation is exactly an approximate-OR / factorial-moment problem

This is the clearest outcome of the run.

Let

\[
M:=\#\{v\in V\setminus\{i\}:K<T_v\},
\]

the number of non-start vertices still unvisited at killing time. Then

\[
Q_i(h)=P(M\ge1).
\tag{4.1}
\]

For `k>=1`, define the aggregate `k`-fold intersection sum

\[
B_k:=\sum_{\substack{S\subseteq V\setminus\{i\}\\ |S|=k}}q(S).
\tag{4.2}
\]

### Exact identity

\[
\boxed{B_k=E\binom{M}{k}.}
\tag{4.3}
\]

#### Proof

For a fixed killed trajectory, exactly `M` of the events `{A_v}` occur. The number of `k`-subsets `S` for which all events in `S` occur is therefore `binom(M,k)`. Summing the indicators of those intersections over all `|S|=k` and then taking expectation gives (4.3). QED.

There is also an exact discounted-horizon form. Because

\[
q(S)=P(K<T_S)=h\sum_{t\ge0}z^tP(T_S>t),
\tag{4.4}
\]

we have

\[
B_k
=
h\sum_{t\ge0}z^t
\sum_{|S|=k}P(T_S>t).
\tag{4.5}
\]

Thus geometric killing has compressed Feige–Rabinovich's time index into one resolvent value, but it has **not** compressed the Boolean-lattice/subset index.

### Why generic approximate inclusion–exclusion still fails algorithmically

The quantity `P(M>=1)` is the OR predicate applied to `n-1` event indicators. Linial–Nisan / Kahn–Linial–Samorodnitsky approximate inclusion–exclusion, and later formulations such as Sherstov's approximate-degree analysis, show that generic control from low-order intersections requires degree on the scale `sqrt(n)` (with additional logarithmic dependence for inverse-polynomial additive error).

In this track `Q_i(h)` can itself be only inverse-polynomial, so a relative approximation requires inverse-polynomial additive error. A generic low-degree OR approximant therefore does not give a constant-degree or polylog-degree solution in the worst case.

Even worse, the current exact oracle computes an individual `q(S)` in polynomial time but does not compute the aggregate `B_k` without summing over `binom(n-1,k)` target sets. At `k` of order `sqrt(n)` this reproduces the historical `n^{O(sqrt(n))}` barrier.

This gives a precise statement of what a successful Markov-specific argument must add. At least one of the following genuinely new compressions is needed:

1. compute the aggregate factorial moments `B_k=E binom(M,k)` for `k` as large as about `sqrt(n)` without enumerating all target subsets;
2. prove a special structural property of the killed vacant-set distribution forcing a much lower-degree approximation of `1_{M>=1}` than generic event systems allow; or
3. bypass factorial moments and construct a deterministic cover-specific pseudorandom generator / approximate counter for the killed walk.

No route recovered so far supplies any of these three ingredients.

### A tempting linear-algebra shortcut that does not presently close

For a fixed target set `S`, if `P_{V\setminus S}` denotes the transition matrix restricted to states outside `S`, then

\[
q(S)=h\,e_i^T(I-zP_{V\setminus S})^{-1}{\bf1}.
\tag{4.6}
\]

The hope was that summing (4.6) over all `|S|=k` might collapse to a coefficient of a characteristic polynomial or a sum of principal minors. The obstacle is that (4.6) is a **ratio** of principal-minor expressions (via Cramer's rule), with a denominator depending on `S`; standard characteristic-polynomial identities sum determinants/minors, not these varying resolvent ratios. I did not find a valid determinant collapse in the bounded literature search. This remains an idea, not a theorem or impossibility result.

## 5. B11 — dual/start-potential information is real but too coarse by itself

For reversible chains the difference time

\[
D(u,v)=H(u,v)-H(v,u)
\]

is additive and therefore behaves like a scalar potential difference. Feige–Rabinovich use the resulting difference order to build a deterministic start-sensitive approximation.

The direct potential-order route does not approach a PTAS. Their own Section 2.3 records that on the path, the Hamiltonian hitting-time path induced by the difference order is of order `n^3`, while the actual cover time is only of order `n^2`; their main algorithm has to refine this ordering substantially.

Nor does the simpler start-sensitive statistic

\[
\max_v H(i,v)
\]

suffice. Their “key” graph has

\[
\max_v H(p_0,v)=O(n^2)
\]

but

\[
E_{p_0}C=\Theta(n^3/\log n),
\]

a gap of order `n/log n`.

The key graph is informative for the present killed-union formulation: its cover delay is controlled by the event that *some* tooth remains unvisited when the walk first reaches the clique. First moments of individual missing-tooth indicators are small enough to conceal the event, while their correlations determine the union probability. That is exactly the kind of higher-order dependence which a hitting-time potential alone does not encode.

**B11 outcome:** a start-sensitive potential can organize vertices and hitting times, but any PTAS route must add a genuinely high-order “how many targets remain unseen together?” statistic. The dual scalar alone is not the missing invariant.

## 6. B24 — stress tests for the missing statistic

The useful extremal lesson is that highly symmetric examples are too easy for the proposed subset aggregation, whereas asymmetric bottleneck/coupon structures are the real test.

### 6.1 Complete graph: good for falsifying fixed truncations, bad as a hardness proxy

The predecessor handoff already proved that fixed-order Bonferroni truncation fails multiplicatively on `K_n`. But `K_n` is so symmetric that all `q(S)` depend only on `|S|`; hence every aggregate `B_k` is available from one representative intersection. It cannot expose the true computational cost of summing non-isomorphic target sets.

### 6.2 Path: exposes loss in the difference-order Hamiltonian surrogate

As noted above, the Feige–Rabinovich difference-order Hamiltonian route is `Theta(n^3)` on a path while the cover time is `Theta(n^2)`. Thus a potential-derived ordering can lose a factor of order `n` even on a tree.

### 6.3 Clique-plus-path: exposes the starting-state problem

Feige–Rabinovich's clique joined to a path of length about `sqrt(n log n)` gives starts whose expected cover times differ by

\[
\Theta\!\left(\frac{n^{3/2}}{\sqrt{\log n}}\right).
\]

This is why a graph-only/max-start GFF parameter cannot by itself solve the specified-start source target.

### 6.4 The key graph: the best current stress test for the killed-union oracle

The key graph consists of a long path with many attached teeth, followed by a large clique. From the far path endpoint, all individual hitting times are only `O(n^2)`, but cover time is `Theta(n^3/log n)` because the walk can enter the clique while a tooth remains unseen and then pays `Theta(n^3)` to return to it. Feige–Rabinovich analyze the first two moments of the number of uncovered teeth.

For the present route this suggests the correct extremal object is **not** a graph maximizing cover time. It is a graph in which `M`, the number of vertices unvisited at the geometric killing time, has a small mean but a delicate nonzero probability. Such examples directly stress any proposed moment truncation or independence approximation.

I did not find a new source-valid counterexample to Aldous–Fill; all examples above diagnose algorithms, not the source statement.
