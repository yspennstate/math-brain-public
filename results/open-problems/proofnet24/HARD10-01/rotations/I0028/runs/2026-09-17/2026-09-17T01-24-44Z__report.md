## 2. Required stuck analysis

### (a) Exact statement that blocks

The strongest reduction already established by the predecessor I0028 reports is:

for

\[
L=n-1,\qquad U=2m(n-1),\qquad
h=\frac{\varepsilon L}{48U^2},
\]

with an independent geometric killing time `K`, it is enough to approximate

\[
\boxed{
Q_i(h)=\Pr_i(K<C)=1-\mathbb E_i[(1-h)^C]
}
\tag{2.1}
\]

to relative `1±O(epsilon)` deterministically in polynomial time. At this `h`, `Q_i(h)` is inverse-polynomially bounded below.

Equivalently, for `A_v={K<T_v}`,

\[
Q_i(h)=\Pr_i\Bigl(\bigcup_{v\ne i} A_v\Bigr),
\]

while every intersection

\[
q(S)=\Pr_i\Bigl(\bigcap_{v\in S}A_v\Bigr)
=1-\mathbb E_i[(1-h)^{T_S}]
\]

is individually polynomial-time computable by an `n`-state killed hitting-time linear system.

So the source-level blocker is still:

\[
\boxed{
\text{compress the exponentially large target-subset / visited-set information enough to approximate (2.1).}
}
\tag{2.2}
\]

The present recovery asks whether the Feige–Zeitouni tree PTAS tells us *what the first missing interface variable is* when one cycle is introduced.

### (b) Routes already tried and why each failed

The recovered I0028 history now contains the following genuinely distinct failed/incomplete routes.

1. **Exact inclusion–exclusion over target sets.** Every term is easy, but there are exponentially many terms.

2. **Fixed-order Bonferroni truncation.** Already disproved multiplicatively on `K_n`; every fixed truncation is asymptotically unusable.

3. **Generic approximate inclusion–exclusion / approximate OR.** The aggregate moments are `B_k=E binom(M,k)` for killed vacant-set size `M`; generic control requires order about `sqrt(n)` and individual intersection queries do not aggregate efficiently, reproducing an `n^{O(sqrt(n))}` barrier.

4. **Generic branching-program derandomization.** The visited set costs linear space / exponential width. Available width-sensitive PRGs do not directly give a polynomial deterministic enumeration, and their notion of monotone ROBP does not match monotone growth of a visited subset.

5. **One-discount geometric killing.** This is a useful reduction, but it compresses the time index only; it does not compress the target-subset index.

6. **Resolvent / determinant aggregation.** `q(S)` is a killed resolvent entry with an `S`-dependent denominator. Standard principal-minor / characteristic-polynomial identities sum determinants, not the required varying ratios. No valid collapse was found.

7. **Hitting-time difference potential / scalar order.** Start-sensitive and useful for coarse approximation, but Feige–Rabinovich examples show one-point hitting information misses high-order “some target remains unseen” dependence.

8. **GFF / majorizing-measure route.** It gives the celebrated deterministic constant-factor result for max-start `t_cov`; no recovered theorem turns it into the frozen specified-start fixed-relative-error target.

9. **Tree dynamic programming.** This is the nearest success, but its separator is a single edge. The present run identifies exactly how a single added cycle destroys that one-edge interface.

### (c) What a successful proof must contain that no recovered route contains

A proof through the tree-DP lane needs a **composable bounded-interface summary** for a component that can be entered through two terminals. It must do all of the following, none of which has yet been supplied together:

1. retain enough information to predict component coverage under repeated two-terminal excursions;
2. compose summaries when two such components are joined in series / around a cycle;
3. truncate the excursion counts at a polynomial bound with a uniform tail estimate;
4. control finite-precision error under repeated composition;
5. recover specified-start cover time, not only cover-and-return;
6. keep the state dimension bounded independently of component size.

The new diagnostics below show that “just count how many times the component was entered” is already too small, and even “count entrances by terminal” is too small: **exit type matters**.

### (d) Simplest special case still unproved

The simplest topological class immediately beyond the Feige–Zeitouni theorem is:

\[
\boxed{\text{connected unicyclic graphs (a single cycle with rooted trees attached).}}
\tag{2.3}
\]

I did not locate a deterministic specified-start cover-time PTAS for this class in the bounded literature search. A source-valid theorem for unicyclic graphs would remain PARTIAL, but it is the right recovery laboratory because it isolates exactly one extra portal.

### (e) Nearest solved problem and the ingredient it has

Feige–Zeitouni's tree PTAS roots the tree and, for a subtree `T_i`, defines a scalar vector

\[
P_i(t)=\Pr(\text{`T_i` is covered before the unique parent edge is entered `t` times}).
\]

For children `u_j`, fixing their entry counts `t_j` makes the child-subtree coverage events independent, yielding their recurrence

\[
P_i(t)=\sum_{t_1,\ldots,t_d}
Q_i(t_1,\ldots,t_d;t)\prod_j P_j(t_j).
\]

The **unique parent edge / one portal** is the key resource. Feige–Zeitouni then truncate at polynomial `N`, binarize high-degree branching, and control precision.

A unicyclic graph has separator size two along the cut-open cycle. The exact missing analogue is a fixed-dimensional **two-terminal excursion kernel**.

## 3. B6 — deform a tree by adding exactly one edge

Let `G` be unicyclic. Delete one cycle edge `{a,b}`. The result is a spanning tree `T`; root it at `a`. All subtrees not intersecting the unique `a-b` path of `T` retain the Feige–Zeitouni one-portal structure unchanged.

Only components on the `a-b` spine are qualitatively new: they may be reached through their ordinary tree parent side **or** through the deleted edge and the far end of the spine. So a single added cycle changes the separator from one portal to two.

### Smallest diagnostic: the triangle already breaks the one-counter state

Take triangle `a-b-c-a`. Delete `a-c` and regard `a-b-c` as the rooted tree with parent edge `a-b` for the component `{b,c}`.

In the tree, before the first directed traversal `a->b`, the component `{b,c}` cannot have been covered. In the triangle, it can be covered through the second portal `a->c` before `a->b` is ever used.

If `q` is the probability, starting at `a`, of covering `{b,c}` before the first `a->b`, then

\[
q=\frac12\left(\frac12+\frac12q\right),
\]

so

\[
\boxed{q=\frac13.}
\tag{3.1}
\]

Thus the tree state “number of parent-edge entries so far” is not merely inconvenient; it ceases to determine the relevant coverage probability as soon as one cycle is added.

This is a diagnostic, not a source theorem.

## 4. B26 — a sporadic exact witness shows that exit type matters

A natural repair would be to keep two counters: number of entries through the left terminal and number through the right terminal. The smallest useful exact example shows that this still discards information.

Consider the two-terminal tree-shaped component

`L - u - v - R`

with a pendant leaf `y` attached to `v`. Start one internal episode by the forced step `L->u`, and stop the episode on the first hit of the boundary `{L,R}`. Ask whether `y` was seen.

The exact absorbing probabilities are

\[
\Pr(L,\ y\text{ unseen})=\frac35,
\qquad
\Pr(R,\ y\text{ unseen})=\frac15,
\]

\[
\Pr(L,\ y\text{ seen})=\frac1{15},
\qquad
\Pr(R,\ y\text{ seen})=\frac2{15}.
\]

Hence

\[
\boxed{
\Pr(y\text{ seen}\mid\text{exit }L)=\frac1{10}
\neq
\frac25=\Pr(y\text{ seen}\mid\text{exit }R).
}
\tag{4.1}
\]

So an entry count alone, even tagged by entry terminal, cannot describe the component's coverage law. The ordered entrance/exit type carries real information.

## 5. B19 — the first plausible algorithmic state is an excursion-type kernel

The diagnostics suggest the following candidate state for a two-terminal component `H` with terminals `L,R`.

Decompose the walk inside `H` into maximal internal excursions between successive terminal hits. Every episode has one of four ordered boundary types

\[
LL,\quad LR,\quad RL,\quad RR.
\]

Let

\[
\mathbf n=(n_{LL},n_{LR},n_{RL},n_{RR}).
\]

By the strong Markov property, once the ordered terminal types of the internal episodes are fixed, their internal paths are independent with type-specific laws. Episodes of the same ordered type are identically distributed. Therefore, for the **local** question “has the interior of `H` been covered by this collection of episodes?”, permutation within each type is irrelevant; the four counts are the first plausible bounded-dimensional replacement for Feige–Zeitouni's one counter.

This observation is elementary and is **not** being promoted as a completed recurrence or new theorem. The hard part is composition.

A usable two-terminal analogue would need objects schematically like

\[
\mathcal C_H(\mathbf n)
=
\Pr(\text{interior of }H\text{ covered after an episode multiset of type counts }\mathbf n),
\tag{5.1}
\]

plus a boundary-transfer kernel describing how child/gadget episode counts are generated when a larger two-terminal component is traversed.

If all four counts could be truncated at a polynomial `N`, the raw interface table would have `O(N^4)` states, still polynomial. Flow conservation may reduce the effective dimension further because `n_{LR}-n_{RL}` is constrained by the starting and ending boundary, but I do not use that as a proved complexity reduction here.

### Why this is not yet an algorithm

Five gaps remain before even the unicyclic restricted theorem can be claimed:

1. derive an exact compositional recurrence for `C_H` and the transfer kernel under series composition;
2. show that the four counts, together with current boundary, are globally sufficient when the exterior chooses the episode sequence;
3. prove a polynomial truncation bound uniform over all unicyclic components;
4. propagate rounding error through the recurrence;
5. convert the resulting cover-and-return or killed-cover statistic into specified-start cover time with relative error.

The exact witness in §4 is useful because it rules out a tempting under-specified DP before substantial code is written.

## 6. A second equivalent picture: cycle trace plus tree service blocks

A unicyclic graph can also be represented as its unique cycle, with a rooted tree attached at each cycle vertex.

At a cycle vertex `c`, the walk may make several excursions into attached trees before it next chooses one of the two cycle edges. For a simple unweighted graph, conditional on eventually taking a cycle edge, left and right are equiprobable, and the side chosen is independent of the sequence of attached-tree excursions preceding that departure. Thus the trace on cycle vertices is itself simple random walk on the cycle, while each cycle visit carries a random “service block” in its attached rooted tree.

This is exactly where the Feige–Zeitouni machinery still applies: the attached forest at one cycle root has a one-portal interface to that root and can be summarized by a scalar service-completion distribution indexed by the number of cycle departures/returns.

But the global cycle trace has a **vector of local times**, one coordinate per cycle vertex. Conditioning on that vector would make the attached-tree service events factor, yet storing the whole vector is again high dimensional. The two-terminal excursion-kernel view in §5 is therefore not an arbitrary invention; it is the local object needed to compress these correlated cycle local times when the cycle is cut into pieces.

This is the clearest new route found in the recovery run.
