## 4. B20 — try to break the regular-tree finite-horizon ceiling first

### 4.1 The candidate to attack

The previous run suggested that the natural exponential branching ceiling is

`b_* = min{Delta-1, lambda^2/4}`.

A tempting strengthening would be the pointwise finite-horizon formula

`N_k^NB(v) <= (lambda^2/4)^k`.                              (4.1)

Before proving any universal theorem, B20 asks for the smallest irregular layered counterexample.

### 4.2 Exact endpoint-amplified layered tree

Fix integers `m>=1` and `k>=2`. Construct a rooted spherically symmetric tree of depth `k` with branching numbers

`r_0 = 2m^2`,

`r_i = m^2` for `1<=i<=k-2`,

`r_{k-1}=2m^2`.

The normalized radial adjacency matrix is the weighted path on levels `0,...,k` with edge weights

`sqrt(2)m, m, ..., m, sqrt(2)m`.

The determinant calculation in Section 6 below shows that this weighted path has top eigenvalue exactly

`lambda = 2m`.

Because the tree is spherically symmetric, its positive Perron eigenvector is invariant under every rooted level automorphism and is therefore radial. Hence the adjacency spectral radius of the whole tree is also exactly `2m`.

The number of depth-`k` descendants of the root is

`N_k^NB(root)`
`= r_0 r_1 ... r_{k-1}`
`= (2m^2)^2 (m^2)^(k-2)`
`= 4m^(2k)`
`= lambda^(2k) / 4^(k-1)`.                                (4.2)

Thus (4.1) is false by an exact factor four. The issue is not an asymptotic branching rate but a finite-horizon boundary amplification: the first and last layer can each carry a factor two while the interior rate remains `lambda^2/4`.

This is a useful B20 failure: it rules out the overstrong no-prefactor formula before it is promoted.

### 4.3 What survived the attack

The example strongly suggests the corrected finite-horizon target

`N_k^NB(v) <= lambda^(2k)/4^(k-1) = 4(lambda^2/4)^k`.        (4.3)

Section 6 proves (4.3) exactly for every finite graph and every root. The same layered trees attain equality whenever the indicated branching numbers are integral. Hence the factor four in (4.3) is not an artifact of the proof.

**B20 outcome:** the naive strict ceiling is refuted, but the corrected product ceiling survives and is exactly sharp.

## 5. The path-tree reduction behind B11

Let `G` be a finite simple graph, let `lambda=lambda(G)`, fix a vertex `v`, and fix `k>=1`.

Write

`s_i := N_i^NB(v)`

for the number of length-`i` nonbacktracking walks starting at `v`, with `s_0=1`.

If `s_k=0`, every inequality below is trivial. Assume `s_k>0`, so `s_i>0` for `0<=i<=k`.

### 5.1 The truncated nonbacktracking path tree

Define `T=T(v,k)` as follows. A vertex of `T` is a nonbacktracking walk

`omega=(v=v_0,v_1,...,v_i)`

in `G` of length `0<=i<=k`. A walk is adjacent in `T` to its one-edge extension and to its prefix. This is a rooted tree with root the length-zero walk `(v)`. Its level `i` has exactly `s_i` vertices.

There is a natural projection

`pi:T -> G`

sending each nonbacktracking walk to its endpoint. This is the usual truncated path-tree/universal-cover projection.

### 5.2 Spectral radius of the path tree is at most the host spectral radius

Let `o` be the root of `T`. For every `ell>=0`, projection maps every length-`2ell` closed walk in `T` from `o` to a length-`2ell` closed walk in `G` from `v`.

This map is injective: a walk in `G` starting at `v` has at most one lift to the path tree starting at `o`; equivalently, the current path-tree vertex is the nonbacktracking reduction stack of the projected walk.

Therefore

`(A_T^(2ell))_{oo} <= (A_G^(2ell))_{vv} <= lambda^(2ell)`.  (5.1)

Since `T` is finite and connected and its Perron eigenvector is strictly positive at `o`,

`lim_{ell->infinity} ((A_T^(2ell))_{oo})^(1/(2ell)) = rho(T)`.

Taking `2ell`-th roots in (5.1) gives

`rho(T) <= lambda`.                                         (5.2)

This is the key category change hidden inside B11: a finite-horizon nonbacktracking problem on an arbitrary graph becomes an ordinary adjacency-spectral problem on a finite tree.

### 5.3 Compress to one weighted coordinate per level

For `0<=i<=k`, let

`f_i = 1_{level i}/sqrt(s_i)`.

These vectors are orthonormal in `l^2(V(T))`. Let `Q` be the compression of `A_T` to their span.

Every vertex at level `i+1` has exactly one parent, so the number of edges between levels `i` and `i+1` is exactly `s_{i+1}`. Hence

`<f_i,A_T f_{i+1}> = s_{i+1}/sqrt(s_i s_{i+1})`
`                      = sqrt(s_{i+1}/s_i)`.

Thus `Q` is the `(k+1)`-vertex weighted path with off-diagonal weights

`a_i := sqrt(s_{i+1}/s_i)`, `0<=i<=k-1`.                   (5.3)

As a compression of a symmetric matrix,

`rho(Q)=||Q|| <= ||A_T|| = rho(T) <= lambda`.               (5.4)

Finally, the telescoping product gives

`s_k = product_{i=0}^{k-1} a_i^2`.                          (5.5)

The whole graph extremal problem has therefore reduced to a one-dimensional weighted-path product maximization.

## 6. B11 — dualize the finite-horizon problem and solve it exactly

### Theorem 6.1 — weighted-path product inequality

Let `Q` be a weighted path with `k` positive edge weights

`a_0,...,a_{k-1}`

and suppose `rho(Q)<=Lambda`, where `Lambda>0`. Then

`product_{i=0}^{k-1} a_i^2 <= Lambda^(2k)/4^(k-1)`.          (6.1)

This constant is sharp.

### Proof

For `j=0,1,...,k+1`, let `Q_j` denote the leading `j x j` principal weighted path and define

`D_j := det(Lambda I_j - Q_j)`.

Use `D_0=1` and `D_1=Lambda`.

Because all weights are positive, every proper leading principal path has strictly smaller Perron root than the full path. Hence, for `1<=j<=k`,

`D_j>0`,

while

`D_{k+1}>=0`

because `Lambda>=rho(Q)`.

The tridiagonal determinant recurrence is

`D_{j+1} = Lambda D_j - a_{j-1}^2 D_{j-1}`                 (6.2)

for `1<=j<=k`.

Define

`t_j := D_j/(Lambda D_{j-1})`, `1<=j<=k+1`.

Then

`t_1=1`,

`0<t_j<=1` for `2<=j<=k`,

and

`0<=t_{k+1}<1`.

Dividing (6.2) by `Lambda D_j` gives

`t_{j+1}=1-a_{j-1}^2/(Lambda^2 t_j)`,

so equivalently

`a_{j-1}^2/Lambda^2 = t_j(1-t_{j+1})`.                     (6.3)

Multiply (6.3) over `j=1,...,k`. Since `t_1=1`,

`product_i a_i^2 / Lambda^(2k)`
`= (1-t_{k+1}) product_{j=2}^k t_j(1-t_j)`.

Now

`1-t_{k+1}<=1`

and for every `x in [0,1]`,

`x(1-x)<=1/4`.

Therefore

`product_i a_i^2 / Lambda^(2k) <= 4^(-(k-1))`,

which proves (6.1). `□`

### Equality structure

Equality in the spectral-only optimization is achieved by

`t_2=...=t_k=1/2`, `t_{k+1}=0`.

Then

`a_0^2=a_{k-1}^2=Lambda^2/2`,

and every interior

`a_i^2=Lambda^2/4`.

This is exactly the endpoint-amplified layered tree from B20 when the weights can be realized as square roots of integer branching ratios.

### Corollary 6.2 — sharp pointwise finite-horizon nonbacktracking bound

For every finite graph `G`, every vertex `v`, and every `k>=1`,

`N_k^NB(v) <= lambda(G)^(2k)/4^(k-1)`.                      (6.4)

#### Proof

Apply Theorem 6.1 to the compressed path `Q` from Section 5 and use (5.4)-(5.5). `□`

There is also the trivial degree bound

`N_k^NB(v) <= Delta(G)(Delta(G)-1)^(k-1)`.                  (6.5)

Combining (6.4)-(6.5),

`N_k^NB(v)`
`<= min{ Delta(Delta-1)^(k-1), lambda^(2k)/4^(k-1) }`.      (6.6)

Thus the previous run's regular-tree exponential ceiling was correct:

`limsup_k (N_k^NB(v))^(1/k)`
`<= min{Delta-1,lambda^2/4}`                                (6.7)

whenever a growing family permits the indicated finite horizons. But (6.4) shows the exact finite-horizon boundary factor that the regular interior model missed.

**B11 outcome:** SUCCESS on the deterministic subproblem `BOUND(k)`. This is substantial PARTIAL progress but does not move `C_sub` because a component-size theorem also needs a multiplicity/packing mechanism and matching lower families.

## 7. B30 — one scale at a time: convert the pointwise theorem into an all-regime distance envelope

The source's proof of the general `O(sqrt(n))` theorem counts paths. The new pointwise result can be inserted on the *other* side of the same idea: it controls how many vertices a ball of a given radius can contain under the two source parameters.

Let

`B_j(Delta,lambda)`
`:= min{ Delta(Delta-1)^(j-1), lambda^(2j)/4^(j-1) }`        (7.1)

for `j>=1`, and define

`M_r(Delta,lambda) := 1 + sum_{j=1}^{r-1} B_j(Delta,lambda)` (7.2)

for `r>=1`.

### Lemma 7.1 — deterministic ball bound

For every `v in V(G)`,

`|{x: dist_G(v,x)<r}| <= M_r(Delta,lambda)`.                 (7.3)

#### Proof

Every vertex at graph distance exactly `j` from `v` has a simple path of length `j` from `v`. A simple path is nonbacktracking, and distinct endpoints require distinct such paths. Hence the size of the distance-`j` sphere is at most `N_j^NB(v)`. Apply (6.6) and sum. `□`

### Theorem 7.2 — long-distance-pair upper envelope

Let `G` have `n` vertices, maximum degree `Delta`, and spectral radius `lambda`. Let

`p <= (1-epsilon)/lambda`

with fixed `epsilon in (0,1)`. Then for every integer `r>=1` and every `s>=2 M_r(Delta,lambda)`,

`P(|C_max(G_p)| >= s)`
`<= 2 n (1-epsilon)^r / (epsilon s^2)`.                     (7.4)

#### Proof

Let `X_r` be the number of **oriented simple paths** of length at least `r` in `G_p`.

For every `j>=r`, the number of oriented simple paths of length `j` in `G` is at most the number of oriented walks of length `j`, namely

`1^T A^j 1 <= ||1||_2 ||A^j 1||_2 <= n lambda^j`.

Each such simple path survives percolation with probability `p^j`. Therefore

`E X_r`
`<= sum_{j=r}^{n-1} p^j n lambda^j`
`<= n sum_{j=r}^infinity (1-epsilon)^j`
`= n(1-epsilon)^r/epsilon`.                                 (7.5)

Now suppose `G_p` contains a component `C` with `|C|>=s`. For each `x in C`, Lemma 7.1 bounds the number of vertices of `C` at distance `<r` from `x` by `M_r`. Hence the number of ordered pairs `(x,y) in C^2` satisfying `dist_C(x,y)>=r` is at least

`|C|(|C|-M_r)`
`>= s^2/2`,                                                 (7.6)

where the last inequality uses `s>=2M_r`.

For each such ordered pair choose one shortest oriented path in `C`. Distinct ordered endpoint pairs give distinct oriented paths, so

`X_r >= s^2/2`.

Markov's inequality and (7.5) imply (7.4). `□`

### Source-valid typical-size corollary

For every fixed failure probability `delta>0`, define

`S_r(delta) := max{ 2M_r(Delta,lambda), sqrt(2n(1-epsilon)^r/(epsilon delta)) }`.  (7.7)

Then

`P(|C_max| >= S_r(delta)) <= delta`.                         (7.8)

Optimizing (7.7) over `r` gives an explicit all-regime upper envelope involving only the source parameters `(n,Delta,lambda,epsilon)`.

This **does not answer Question 5.2**, because no matching lower construction is proved for this envelope and in important high-degree regimes the source's existing refined theorem is much better. But it is a rigorous bridge from the new transient-growth theorem to component size.

### Fixed-parameter interpretation

Let

`g := min{Delta-1,lambda^2/4}`.

When `Delta,lambda` are fixed and `g>1`, (7.1) implies `M_r=O(g^r)`. Balancing the two terms in (7.7) yields a polynomial exponent strictly below `1/2`:

`|C_max| <= n^(theta+o(1))` typically,

where

`theta = log g / (2 log g - log(1-epsilon)) < 1/2`.          (7.9)

This is consistent with, and gives an explicit version of, the source's observation that fixed spectral radius permits an `n^(1/2-delta)` improvement. It is not claimed as a new resolution of that source remark.

## 8. B30 second localized wedge — a complete close-to-regular logarithmic theorem

The source highlights graphs with `Delta` close to `lambda` as an interesting special case. The elementary maximum-degree branching comparison completely handles the uniformly close regime where the source parameter keeps the forward degree strictly subcritical.

### Proposition 8.1 — uniform degree-subcritical tail

Suppose

`p(Delta-1) <= 1-eta`                                       (8.1)

for some `eta in (0,1]`. Then there is an absolute constant `C` such that for every vertex `v` and every `s>=2`,

`P(|C(v)|>=s) <= C exp(-eta^2(s-2)/4)`.                     (8.2)

Consequently

`|C_max| = O(eta^(-2) log n)` a.a.s.                        (8.3)

whenever `eta` is bounded away from zero.

#### Proof

Breadth-first exploration from `v` is stochastically dominated by a Galton--Watson queue whose root offspring is

`Y ~ Bin(Delta,p)`

and whose subsequent offspring variables are iid

`X_i ~ Bin(Delta-1,p)`.

Set `theta=eta/2<=1/2`. Since `e^theta-1<=theta+theta^2` for `0<=theta<=1`,

`q := E exp(theta(X_i-1))`
`= e^(-theta)(1+p(e^theta-1))^(Delta-1)`
`<= exp[-theta + p(Delta-1)(e^theta-1)]`
`<= exp[-eta theta + (1-eta)theta^2]`
`<= exp(-eta^2/4)`.                                         (8.4)

Also

`p Delta = p(Delta-1)+p <= 2`,

so

`E exp(theta Y)`
`<= exp[p Delta(e^theta-1)]`
`<= exp[2(theta+theta^2)]`
`<= exp(3/2)`.                                              (8.5)

If the exploration has at least `s` vertices, then after the root and `s-2` subsequent queue removals the dominating queue is still nonempty, so

`Y + sum_{i=1}^{s-2}(X_i-1) >= 1`.

Exponential Markov, (8.4), and (8.5) give

`P(|C(v)|>=s)`
`<= e^(-theta) E[e^(theta Y)] q^(s-2)`
`<= e^(3/2) exp[-eta^2(s-2)/4]`,

which is (8.2) with `C=e^(3/2)`. A union bound over `n` roots gives (8.3). `□`

### Corollary 8.2 — explicit close-regular wedge at the source probability

Under the source condition

`p <= (1-epsilon)/lambda`,

if

`(1-epsilon)(Delta-1)/lambda <= 1-eta`,                     (8.6)

then `|C_max|=O_eta(log n)` a.a.s.

In particular, if

`Delta <= (1+delta)lambda`

for a fixed

`delta < epsilon/(1-epsilon)`,

then one may take

`eta >= epsilon-(1-epsilon)delta >0`,

up to the harmless `1/lambda` improvement from `Delta-1`, and therefore

`|C_max|=O_{epsilon,delta}(log n)` a.a.s.                   (8.7)

This is a restricted wedge only and does not move `C_sub`. The mechanism is standard branching-process domination; no novelty is claimed for it.

**B30 outcome:** complete source-valid control in the strict close-regular wedge, plus the all-regime upper family (7.7); the hard intermediate regimes remain unmatched.

## 9. What this run changes conceptually

The previous report left two uncertainties:

1. could irregular layering beat the regular-tree `lambda^2/4` finite-horizon base? and
2. if not, how can that transient-growth control be connected back to component size?

This run answers both at a useful but incomplete level.

### 9.1 Finite-horizon extremal problem is solved

Irregular layering **can** beat the naive no-prefactor formula at the endpoints, but cannot beat the corrected product law:

`N_k^NB(v) <= 4(lambda^2/4)^k`.

The factor four is exactly attainable by endpoint-amplified layered trees.

Thus the deterministic exponential base really is

`min{Delta-1,lambda^2/4}`.

### 9.2 The remaining source obstruction is multiplicity, not rootwise growth

A single root's finite-horizon branching profile is now controlled sharply. That is still insufficient for Question 5.2.

Complete bipartite graphs show why: many roots can participate in the same shallow high-degree architecture, and component size can be amplified by the **number and overlap pattern of high-growth launch regions**, producing logarithmic factors that a pointwise root profile does not see.

The next missing object should therefore be a **profile of how many vertices can simultaneously have near-extremal finite-horizon growth**, rather than another improvement to the per-root inequality.

A first trivial aggregate constraint is

`sum_v N_k^NB(v) <= 1^T A^k 1 <= n lambda^k`,               (9.1)

because nonbacktracking walks are ordinary walks. The challenge is to combine (9.1), the sharp pointwise cap (6.4), and overlap information strongly enough to control component tails and to match the complete-bipartite and tree lower families.

This is now a more precise obstacle than the previous generic phrase “transient branching plus multiplicity”.
