### Route 1 — intake induced-subgraph spectral envelope

The intake attempt `G0010-A001` proposed, heuristically, a largest-component scale governed by the induced subgraph closest to criticality, schematically

**Failure.** The first G0010 run used finite complete regular rooted trees. ### Route 2 — one global finite Hashimoto/nonbacktracking spectral radius

A natural response to Route 1 is to replace adjacency spectrum by nonbacktracking spectrum.

**Failure.** On every finite tree the nonbacktracking matrix is nilpotent, so its spectral radius is zero, while the same tree can support exponentially growing nonbacktracking generations for `Theta(log n)` steps. The asymptotic radius again forgets finite-horizon transient growth.

**Failure as a source solution.** The bound is sharp for a single root but ignores how many roots attain near-extremal growth and whether their descendants are new vertices or repeated collisions onto the same exceptional set. Largest-component extremes require both amplification and multiplicity.

## 6. (c) What a full proof must contain that no current route contains

Every successful source-level upper theorem now appears to need a mechanism with **four simultaneous layers**.

First, it needs a multiscale state space that distinguishes at least growth and collision type. A possible schematic state is not a single vertex statistic but a class such as

\[
\mathsf T_{k,a,b}
=\{v:N_k(v)\asymp a,\ E_k(v)\asymp b\},
\]

with states refined enough to separate tree-like from hub-cloud behavior.

Second, it needs a deterministic transition budget, derived only from `(Delta,lambda)`, on how much open exploration mass can pass from one exceptional state into another. Existing moment bounds control the row mass or the count of exceptional rows, but not the exceptional-to-exceptional **matrix**.

Third, it needs a total-progeny or stopping-time inequality for that adversarial coarse exploration. The bound has to remain valid when the host graph contains short cycles and massive endpoint collisions. In a prescribed random-kernel model, a multitype Galton--Watson process supplies this automatically; in arbitrary deterministic `G`, no such independent type kernel is given.

Fourth, it needs an extreme-value/packing step converting the one-seed tail into the largest component over all possible seeds without losing the source's multiplicity factors. This is where the complete-bipartite `log` effect lives, while the tree regime instead spends the budget on depth.

No route so far contains all four ingredients. The previous work supplies pieces of the first and fourth layers and sharp scalar budgets for the second, but not the transition kernel itself.

## 10. (e) Nearest solved problem and the ingredient it has that G0010 lacks

**Selected nearest solved analogue:** Turova 2013, general subcritical inhomogeneous random graphs with a prescribed type kernel.

Its decisive ingredient is an **honest multitype branching kernel** whose total-progeny distribution can be analyzed. The kernel simultaneously encodes:

- how common each type is;
- how strongly one type connects to another;
- whether a generation's mass is dispersed among many endpoint types or concentrated;
- the reproduction law along an exploration trajectory.

G0010 has only `Delta` and `lambda`. Those scalars constrain row sizes, spectral energy, and exceptional-root counts, but do not directly specify an exceptional-to-exceptional transition kernel. The three ordinary G0010 runs now provide explicit reasons this information cannot be replaced by any of the obvious marginals.

Therefore the ingredient to port is **not** Turova's final generating-function formula. It is the intermediate step: identify a coarse type kernel and prove that component exploration is dominated by a process whose kernel is controlled by the source parameters.

For the selected biregular special case, the natural coarse type space should begin with two sides plus a dyadic codegree/collision class.
