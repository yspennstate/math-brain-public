## 3. New proof-strengthening: direct weak duality from the source definition

The first C31 proof cited the previously archived exact reduction to a stationary product-demand multicommodity LP. That reduction is useful, but for the **lower bound** needed to refute 4.49(ii) it is unnecessary. The following direct lemma starts from Aldous–Fill's actual `psi` definition and removes the most delicate normalization dependency from the candidate proof.

### Lemma C31-AF449-DIRECT-WEAK-DUALITY

Let `G` be a finite reversible discrete-time chain with undirected conductances

`c_{uv}=pi_u p_uv=pi_v p_vu`.

Let `f=(f^(a))` be any Aldous–Fill family of unit flows from `a` to `pi`, so

`div f^(a)=delta_a-pi`.

For any nonnegative edge lengths `ell_e` satisfying

`sum_e c_e ell_e <= 1`,

let `d_ell` be the induced shortest-path metric. Then

`psi(f) >= sum_{a,b} pi_a pi_b d_ell(a,b)`.

Consequently

`inf_f psi(f) >= sup_{ell>=0, sum c_e ell_e<=1} E_{pi x pi} d_ell(X,Y)`.

### Proof

Fix `a` and orient every physical edge arbitrarily once. Put

`phi_a(v)=-d_ell(a,v)`.

For every edge `e={u,v}`, shortest-path Lipschitzness gives

`|phi_a(u)-phi_a(v)| <= ell_e`.

With `div f^(a)=delta_a-pi`, discrete summation by parts yields

`sum_v phi_a(v) div f^(a)(v)
 = sum_e f_e^(a)(phi_a(u_e)-phi_a(v_e))`.

The left side is

`phi_a(a)-sum_b pi_b phi_a(b)
 = sum_b pi_b d_ell(a,b)`.

Taking absolute values edge-by-edge therefore gives

`sum_b pi_b d_ell(a,b) <= sum_e ell_e |f_e^(a)|`.

Multiply by `pi_a` and sum over `a`:

`sum_{a,b} pi_a pi_b d_ell(a,b)
 <= sum_e ell_e sum_a pi_a |f_e^(a)|`.

By the source definition of `psi`, for every physical edge

`sum_a pi_a |f_e^(a)| <= psi(f) c_e`.

Hence

`E d_ell(X,Y)
 <= psi(f) sum_e c_e ell_e
 <= psi(f)`.

This holds for every admissible flow family `f` and every feasible length vector `ell`, proving the lemma. QED.

### Consequence

The Ramanujan-cone counterexample needs only this **weak duality**. It no longer depends on exact equivalence to a decomposed all-pairs product-demand LP. In particular, any concern about path-decomposition or cancellation conventions in that stronger equivalence cannot invalidate the lower-bound certificate used here.

## 4. Re-audit of the Ramanujan-cone family

Fix integer `s>=4`, let

`d=s^2`, `r=s`,

and choose a connected `d`-regular bipartite Ramanujan graph `H` of sufficiently large order `n`. Since the MSS family has unbounded orders at each fixed degree, choose

`n >= 2 B(d,r)`,

where

`B(d,r)=1+d sum_{j=0}^{r-2}(d-1)^j`

bounds the number of vertices within distance `<r` of any fixed vertex. Thus for independent uniform base vertices `U,V`,

`P(d_H(U,V)>=r)>=1/2`,

so

`E min(d_H(U,V),r) >= r/2`.

Form the cone `G=K_1 vee H`. Then

- `D(G)=2`;
- `pi_h=1/(d+2)` and the base has total stationary mass `(d+1)/(d+2)`;
- every nontrivial positive base adjacency eigenvalue is at most `2 sqrt(d-1)`, so
  `lambda_2(P_G) <= 2 sqrt(d-1)/(d+1) < 2s/(s^2+1)`;
- therefore
  `tau_rel < 1/(1-2s/(s^2+1))`.

Use the feasible edge lengths

`x=r(d+2)/(d+r)` on every spoke,

`y=2(d+2)/(d+r)` on every base edge.

They satisfy `2x=ry` and

`n x + (nd/2)y = n(d+2)=2|E(G)|`,

so for simple random walk, where each physical-edge conductance is `1/(2|E|)`, the direct weak-duality constraint is exactly saturated.

For two base vertices the weighted shortest path is

`d_ell(u,v)=y min(d_H(u,v),r)`.

Therefore direct weak duality gives

`F(G) >= r(d+1)(d+3)/((d+2)(d+r))`.

Combining with the relaxation-time bound and `D=2`,

`F/(tau_rel D) > L_s`,

where

`L_s=((s-1)^2(s^2+3))/(2(s+1)(s^2+2))`.

The first-run report used the sufficient comparison `L_s>s/8`. The exact identity is considerably sharper:

`L_s-(s-3)/2 = (5s^2-2s+9)/(2(s+1)(s^2+2)) > 0`.

Hence

`F/(tau_rel D) > (s-3)/2`.

For any proposed universal constant `K`, choosing an integer `s>2K+3` and then a sufficiently large member of the degree-`s^2` MSS family gives

`F/(tau_rel D)>K`.

Thus the source inequality with diameter replacing `log n` cannot hold with any universal constant.

This is a proof-strengthening and cleaner quantifier resolution, not new metric movement: the metric was already `UNBOUNDED`.
