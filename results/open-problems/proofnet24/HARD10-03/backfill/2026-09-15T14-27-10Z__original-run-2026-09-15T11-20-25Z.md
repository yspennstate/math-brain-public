## 1. Ordered r-tag configuration spaces

Let \(P=\pi_\beta\). For fixed integer \(r\ge1\), define
\[
\mathcal C_r^{(d)}
=
\{(x_1,\dots,x_r)\in(\mathbb Z^d)^r:x_i\ne x_j\text{ for }i\ne j\}.
\]
The chronological ordered \(r\)-tag interchange process is the symmetric continuous-time walk on this graph induced by nearest-neighbor transpositions. Denote its heat kernel by
\[
Q_t^{(r)}(\mathbf x,\mathbf y).
\]
For fixed \(r,d\ge2\), \(\mathcal C_r^{(d)}\) is roughly isometric to \(\mathbb Z^{rd}\): inclusion gives one distance inequality; in dimension at least two, finitely many labeled particles can be routed one at a time with bounded detours around occupied sites; collision configurations in the full product are within bounded distance, depending on fixed \(r,d\), of collision-free configurations. The graph has bounded degree for fixed \(r,d\).

Using Delmotte's Gaussian heat-kernel theorem and rough-isometry stability, the original report invoked, for each fixed \(r,d\), constants \(C_{r,d},c_{r,d}\) such that
\[
Q_t^{(r)}(\mathbf x,\mathbf y)
\le
C_{r,d}t^{-rd/2}
\exp\left[-c_{r,d}\frac{\operatorname{dist}(\mathbf x,\mathbf y)^2}{t}\right],
\qquad t\ge1.
\tag{BF-HK-r}
\]
No uniformity in \(r\) was claimed.

## 2. Exact fixed-r orbit-segment kernel identity

Suppose
\[
x_0=0,x_1,\dots,x_r
\]
are pairwise distinct. Then the event
\[
P^j0=x_j,\qquad 1\le j\le r,
\]
is exactly the event that the \(r\) tagged labels initially at
\[
(x_0,x_1,\dots,x_{r-1})
\]
end after time \(\beta\) at
\[
(x_1,x_2,\dots,x_r).
\]
Therefore:

### BF-R1 — PROVED

\[
\boxed{
\mathbb P(P^j0=x_j\text{ for }1\le j\le r)
=
Q_\beta^{(r)}
((x_0,\dots,x_{r-1}),(x_1,\dots,x_r)).
}
\tag{BF-R1}
\]

In particular, on the sector \(L_\beta(0)>r\),
\[
\boxed{
\mathbb P(P^r0=x,L>r)
=
\sum_{\substack{x_1,\dots,x_{r-1}\text{ distinct}\\
0,x_1,\dots,x_{r-1},x\text{ distinct}}}
Q_\beta^{(r)}
((0,x_1,\dots,x_{r-1}),(x_1,\dots,x_{r-1},x)).
}
\tag{BF-R1-long}
\]

This identity is purely combinatorial and exactly respects reuse of the same permutation slab.

## 3. Fixed-r Gaussian bound on the long-cycle sector

For the start/end pair in BF-R1-long, the product displacement vector is
\[
(x_1-x_0,x_2-x_1,\dots,x-x_{r-1}).
\]
Rough isometry gives, for fixed \(r,d\),
\[
\operatorname{dist}_{\mathcal C_r}^2
\ge
c_{r,d}\sum_{j=1}^r|x_j-x_{j-1}|^2-C_{r,d}.
\]
Combine this with BF-HK-r, drop the distinctness restriction for an upper bound, and sum over \(x_1,\dots,x_{r-1}\). A discrete Gaussian convolution yields
\[
\sum_{x_1,\dots,x_{r-1}}
\exp\left[-c\frac{\sum_{j=1}^r|x_j-x_{j-1}|^2}{\beta}\right]
\le
C_{r,d}\beta^{(r-1)d/2}
\exp\left[-c_{r,d}\frac{|x|^2}{\beta}\right].
\]
Hence:

### BF-R2 — PROVED

For fixed \(r,d\),
\[
\boxed{
\mathbb P(P^r0=x,L>r)
\le
C_{r,d}\beta^{-d/2}
\exp(-c_{r,d}|x|^2/\beta).
}
\tag{BF-R2}
\]

## 4. Exact finite-cycle kernel identity

Fix \(\ell\ge2\) and pairwise distinct vertices
\[
x_0=0,x_1,\dots,x_{\ell-1}.
\]
The event that these form exactly the root cycle in the given order is the simultaneous mapping
\[
P(x_j)=x_{j+1}\quad(0\le j\le\ell-2),
\qquad
P(x_{\ell-1})=x_0.
\]
Thus:

### BF-R3 — PROVED

\[
\boxed{
\mathbb P(0\to x_1\to\cdots\to x_{\ell-1}\to0)
=
Q_\beta^{(\ell)}
((x_0,\dots,x_{\ell-1}),(x_1,\dots,x_{\ell-1},x_0)).
}
\tag{BF-R3}
\]
Therefore
\[
\boxed{
\mathbb P(L=\ell)
=
\sum_{\substack{x_1,\dots,x_{\ell-1}\text{ distinct}\\x_j\ne0}}
Q_\beta^{(\ell)}
((0,x_1,\dots,x_{\ell-1}),(x_1,\dots,x_{\ell-1},0)).
}
\tag{BF-R3-cycle}
\]
For \(\ell=1\), \(\mathbb P(L=1)=p_\beta(0,0)\).

## 5. Fixed-short-cycle estimate

Apply BF-HK-r to BF-R3-cycle. The displacement list is the closed polygon increment sequence
\[
(x_1-x_0,\dots,x_{\ell-1}-x_{\ell-2},x_0-x_{\ell-1}).
\]
Summing over \(\ell-1\) free vertices leaves one residual \(d\)-dimensional Gaussian factor.

### BF-R4 — PROVED

For each fixed \(\ell\ge1\) and fixed \(d\ge2\),
\[
\boxed{
\mathbb P(L_\beta(0)=\ell)
\le C_{\ell,d}\beta^{-d/2}.
}
\tag{BF-R4}
\]
Consequently, for every fixed \(K\),
\[
\boxed{
\mathbb P(L_\beta(0)\le K)
\le C_{K,d}\beta^{-d/2}.
}
\tag{BF-R4K}
\]
In \(d=3\),
\[
\mathbb P(L_\beta(0)\le K)
\le C_K\beta^{-3/2}
\qquad(K\text{ fixed}),
\]
which sharpens the archived pre-first-interaction \(O(K\beta^{-1/2})\) estimate when \(K\) is fixed.

## 6. Full fixed-r endpoint bound including short cycles

Fix \(r\). Decompose according to \(L>r\) and \(L=\ell\le r\). On \(L=\ell\),
\[
P^r0=P^{r\bmod\ell}0.
\]
If \(r\bmod\ell=0\), the endpoint is zero and BF-R4 bounds the mass. If \(j=r\bmod\ell\in\{1,\dots,\ell-1\}\), fix the \(j\)-th cycle vertex to equal \(x\) in BF-R3-cycle. There are now only \(\ell-2\) free cycle vertices; the Gaussian polygon sum is at most the weaker \(\beta^{-d/2}\) target.

### BF-R5 — PROVED

For every fixed \(r\ge1\), fixed \(d\ge2\), and \(\beta\ge1\),
\[
\boxed{
\mathbb P(P^r0=x)
\le C_{r,d}\beta^{-d/2}
\exp(-c_{r,d}|x|^2/\beta).
}
\tag{BF-R5}
\]
In \(d=3\), \(\sup_x\mathbb P(P^r0=x)\le C_r\beta^{-3/2}\) for every fixed \(r\).

Using the cyclic phase-invariance identity backfilled from the 09:26 run, every fixed orbit lag therefore has same-phase adjacency occupation
\[
\mathbb E\int_0^\beta
\mathbf1_{\{|\pi_s(P^r0)-\pi_s0|_1=1\}}ds
\le C_{r,d}\beta^{1-d/2}.
\]
In \(d=3\), this is \(O_r(\beta^{-1/2})\).

## 7. Exact unresolved issue identified in original run

The fixed-r theorem is not sufficient because the constants \(C_{r,d},c_{r,d}\) from rough-isometry heat-kernel theory may deteriorate badly with \(r\). The full conjecture is about \(r\to\infty\) at one fixed large \(\beta\), so one cannot sum BF-R4 over all cycle lengths.

The original report isolated the decisive uniform target
\[
\mathbb P(L_\beta(0)=\ell)
\stackrel{?}{\le}
C(\ell\beta)^{-3/2}
\qquad(d=3),
\tag{BF-UNIF}
\]
with a universal constant \(C\). Such a bound would imply
\[
\mathbb P(L<\infty)
\le C\beta^{-3/2}\sum_{\ell\ge1}\ell^{-3/2}
=C\zeta(3/2)\beta^{-3/2}<1
\]
for all sufficiently large \(\beta\), proving the full theorem without monotonicity.
