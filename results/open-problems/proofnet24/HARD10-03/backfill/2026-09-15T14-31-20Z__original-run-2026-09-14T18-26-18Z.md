## 1. Clean finite cycles are very rare

Call a finite root cycle of length \(q\) **clean** if, on the half-open interval \([0,q\beta)\), the cyclic-time walk has no same-phase near-contact with an earlier period in the over-approximate sense used to define the first interaction time. The closing equality at \(q\beta\) is allowed.

On this clean event the cyclic-time walk agrees with the independent driver \(X\) throughout \([0,q\beta)\). A Poisson mark exactly at deterministic time \(q\beta\) has probability zero. Hence if the clean cycle closes,
\[
W(q\beta)=0
\]
implies
\[
X(q\beta)=0.
\]
Therefore
\[
\{L_\beta(0)=q\text{ and clean}\}
\subseteq
\{X(q\beta)=0\}.
\]
The events on the left are disjoint in \(q\), so for every \(d>2\),
\[
\boxed{
\mathbb P(L_\beta(0)<\infty\text{ and clean})
\le
\sum_{q\ge1}p_{q\beta}(0),
}
\tag{BF-CLEAN}
\]
where \(p_t(0)=\mathbb P(X(t)=0)\).

For the rate-one-per-edge continuous-time walk in dimension three, the coordinates are independent differences of rate-one Poisson processes, so
\[
p_t(0)
=
\left[e^{-2t}I_0(2t)\right]^3,
\]
where \(I_0\) is the modified Bessel function. The standard large-\(t\) asymptotic
\[
e^{-2t}I_0(2t)
=(4\pi t)^{-1/2}(1+O(t^{-1}))
\]
gives
\[
\sum_{q\ge1}p_{q\beta}(0)
=
\frac{\zeta(3/2)}{(4\pi\beta)^{3/2}}
+O(\beta^{-5/2}).
\]
Thus
\[
\boxed{
\mathbb P(L_\beta(0)<\infty\text{ and clean})
=O(\beta^{-3/2}).
}
\tag{BF-CLEAN-3D}
\]

Interpretation: a hypothetical all-finite phase at large \(\beta\) cannot be explained primarily by ordinary SRW-type clean returns. With probability \(1-O(\beta^{-3/2})\), any finite root cycle would have to undergo a non-closing same-phase entanglement before it eventually closes.

This does not prove infinite cycles, because entangled finite cycles remain uncontrolled.

## 2. Long-lag first interactions are additionally suppressed

The sliding-window proof of the first-interaction bound can be localized in lag. For integers \(1\le R\le K\), let \(A_{R,K}\) be the event that before time \(K\beta\), and before any earlier cyclic correction matters, a same-phase near-contact is witnessed at lag \(r\ge R\).

For the independent driver, the same compensation argument gives
\[
\mathbb P(A_{R,K})
\le
C_d\beta^{-d/2}\sum_{r=R}^K r^{-d/2}
+
C_d\beta^{1-d/2}
\sum_{r=R}^{K-1}(K-r)r^{-d/2}.
\]
Since for \(d>2\),
\[
\sum_{r\ge R}r^{-d/2}
\le C_dR^{1-d/2},
\]
one gets
\[
\boxed{
\mathbb P(A_{R,K})
\le
C_dK\beta^{1-d/2}R^{1-d/2}.
}
\tag{BF-LAG}
\]
In dimension three,
\[
\boxed{
\mathbb P(A_{R,K})
\le
C\frac{K}{\sqrt{\beta R}}.
}
\tag{BF-LAG-3D}
\]
For the first-block scale \(K=\beta^{1/2-\varepsilon}\) and cutoff \(R=\beta^\delta\),
\[
\mathbb P(A_{R,K})
\le C\beta^{-\varepsilon-\delta/2}.
\]
Thus the **first** cyclic defect is not only sparse at large \(\beta\); large period-lag defects are additionally suppressed.

This estimate is pre-first-interaction only. After a cyclic correction occurs, the walk no longer equals the independent driver, so BF-LAG cannot be iterated without a new post-entanglement argument.

## 3. Original conditional cluster idea

The two bounds suggested a schematic renewal/cluster route. The independent-driver first-defect lag kernel in \(d=3\) has scale
\[
a_r\asymp \beta^{-1/2}r^{-3/2},
\]
whose \(\ell^1\) norm is \(O(\beta^{-1/2})\). The clean-closing kernel has scale
\[
b_q\asymp \beta^{-3/2}q^{-3/2},
\]
whose \(\ell^1\) norm is \(O(\beta^{-3/2})\).

If one could prove a **post-interaction cluster-exit domination** saying that each finite entanglement cluster recruits additional same-phase strands with total kernel mass at most \(C\beta^{-1/2}\), uniformly over the exposed admissible history, then a geometric expansion would heuristically give
\[
\mathbb P(L<\infty)
\lesssim
\|b\|_1\sum_{m\ge0}\|a\|_1^m
\le
\frac{C\beta^{-3/2}}{1-C\beta^{-1/2}},
\]
which would solve the large-\(\beta\) theorem.

The cluster-exit domination was **not proved**. It was identified as the load-bearing missing lemma.
