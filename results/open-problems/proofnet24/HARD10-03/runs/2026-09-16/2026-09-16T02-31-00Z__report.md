\[

\mathbb P\bigl(0\text{ lies in an infinite cycle of }\pi_\beta\bigr)>0.

# 3. NEW-L47 — heat-content exact-set bound

Let

\[
P:=\pi_\beta,
\qquad
A\subset\mathbb Z^3\text{ finite},
\qquad
0\in A,
\qquad
m:=|A|.
\]

As in NEW-L44, color exactly the labels initially in `A` red. The red occupied set evolves as symmetric exclusion, and

\[
\{C_P(0)=A\}\subseteq\{P(A)=A\}.
\tag{3.1}
\]

For `x in A` define the red one-site marginal

\[
r_x
:=
\mathbb P^A(\eta_\beta(x)=1)
=
\sum_{a\in A}p_\beta(a,x).
\tag{3.2}
\]

Strong-Rayleigh negative association gives

\[
\mathbb P(C_P(0)=A)
\le
\mathbb P(P(A)=A)
\le
\prod_{x\in A}r_x.
\tag{3.3}
\]

Define the heat content

\[
H_A(t)
:=
\langle 1_A,P_t1_A\rangle
=
\sum_{a,x\in A}p_t(a,x),
\tag{3.4}
\]

where `P_t=e^{-tL}` is the one-particle continuous-time simple-random-walk semigroup with

\[
(Lf)(x)=\sum_{y:\,|x-y|_1=1}(f(x)-f(y)).
\]

Since

\[
\sum_{x\in A}r_x=H_A(\beta),
\]

AM-GM immediately improves the pointwise-marginal product to

\[
\boxed{
\mathbb P(C_P(0)=A)
\le
\left(\frac{H_A(\beta)}{m}\right)^m.
}
\tag{3.5}
\]

This is already useful because it records **average heat retention of the whole candidate cycle set**, rather than replacing every entry by the worst-case diagonal return `q_beta`.

## 3.1 Self-contained discrete Nash estimate

For finitely supported `g:Z^3->R`, let

\[
\mathcal E(g,g)=\langle g,Lg\rangle.
\]

The standard Nash inequality is

\[
\boxed{
\|g\|_2^{10/3}
\le
C_N\,\|g\|_1^{4/3}\,\mathcal E(g,g).
}
\tag{3.6}
\]

A short Fourier proof is as follows. On `[-pi,pi]^3`,

\[
\widehat{Lg}(\theta)=\lambda(\theta)\hat g(\theta),
\qquad
\lambda(\theta)=2\sum_{j=1}^3(1-\cos\theta_j),
\]

and `lambda(theta)>=c|theta|^2` on the Brillouin zone. Split Parseval at radius `R<=1`. The low-frequency part is at most `C R^3 ||g||_1^2`, since `|hat g|<=||g||_1`; the high-frequency part is at most `C R^{-2} E(g,g)`. Optimizing `R^5` against `E(g,g)/||g||_1^2` gives (3.6) when the optimizer is at most one. If the formal optimizer exceeds one, then `E(g,g)>||g||_1^2>=||g||_2^2`, and (3.6) follows after enlarging the constant. Thus (3.6) holds uniformly.

Now put

\[
g_t=P_{t/2}1_A.
\]

Then mass preservation and positivity give

\[
\|g_t\|_1=m,
\qquad
\|g_t\|_2^2=H_A(t).
\]

Moreover

\[
H_A'(t)
=-\mathcal E(g_t,g_t).
\tag{3.7}
\]

Applying (3.6),

\[
-H_A'(t)
\ge
C_N^{-1}H_A(t)^{5/3}m^{-4/3}.
\tag{3.8}
\]

Since `H_A(0)=m`, integration yields an absolute `c_N>0` such that

\[
H_A(t)^{-2/3}
\ge
m^{-2/3}+c_N t m^{-4/3},
\]

or equivalently

\[
\boxed{
\frac{H_A(t)}m
\le
\left(1+c_N t m^{-2/3}\right)^{-3/2}.
}
\tag{3.9}
\]

Combining (3.5) and (3.9) gives the main theorem.

## Theorem NEW-L47 — PROVED

For every finite deterministic `A subset Z^3` with `0 in A`, `m=|A|`, and every `beta>0`,

\[
\boxed{
\mathbb P\bigl(C_{\pi_\beta}(0)=A\bigr)
\le
\left(1+c_N\beta m^{-2/3}\right)^{-3m/2}.
}
\tag{3.10}
\]

Together with NEW-L44, one may use the better of

\[
(mq_\beta)^m
\quad\text{and}\quad
\left(1+c_N\beta m^{-2/3}\right)^{-3m/2}.
\tag{3.11}
\]

### Large-set regime

If `m >= C beta^{3/2}` with `C` sufficiently large, then `u=c_N beta m^{-2/3}<=1`; using `log(1+u)>=u/2`,

\[
\boxed{
\mathbb P(C_{\pi_\beta}(0)=A)
\le
\exp\{-c\beta m^{1/3}\}.
}
\tag{3.12}
\]

Thus even a very large **prescribed** finite cycle vertex set has stretched-exponentially small probability in its volume. This is geometry-independent: no diameter, connectedness, or regular shape is assumed for `A`.

### Important limitation

(3.10) is an exact-set estimate, not a cycle-length tail. There are infinitely many `m`-point subsets of `Z^3`, and the bound deliberately forgets the connected permutation mechanism needed to make a remote set into one cycle. Therefore summing (3.10) over all `A` is invalid/infinite and does not prove the target theorem. The remaining problem is still to extract a **spatially summable connected weight**.

# 4. NEW-L48 — connected two-cycle extraction by combining exclusion and determinant signs

The previous checkpoint identified precisely why the raw invariant-set upper bound is not spatially summable: for `A={u,v}` with `|u-v|` huge, `P(P(A)=A)` includes the disconnected event that both labels essentially return separately. Here that disconnected term can be cancelled exactly.

Work first on a finite transitive graph (or a torus), and then pass to `Z^3` through the already archived finite-volume/local-limit transfer. Let

\[
K=p_\beta
\]

be the one-particle kernel. Fix distinct vertices `u,v` and put

\[
q=K(u,u)=K(v,v),
\qquad
p=K(u,v)=K(v,u).
\]

Let

* `F_{u,v}` be the event `P(u)=u` and `P(v)=v`;
* `T_{u,v}` be the event `P(u)=v` and `P(v)=u`, i.e. `{u,v}` is a two-cycle.

The invariant-set event for the two red labels is the disjoint union

\[
\{P(\{u,v\})=\{u,v\}\}=F_{u,v}\sqcup T_{u,v}.
\tag{4.1}
\]

Strong-Rayleigh negative association gives

\[
\mathbb P(F_{u,v})+\mathbb P(T_{u,v})
\le
(q+p)^2.
\tag{4.2}
\]

Now use only the **safe diagonal** determinant identity. In

\[
\mathbb E\det(I-D_aP)=\det(I-D_aK),
\]

set all diagonal variables except `a_u,a_v` to zero and compare the coefficient of `a_u a_v`. On the permutation side, two singleton cycles contribute `+1`, a two-cycle contributes `-1`, and every configuration in which `{u,v}` is not invariant contributes zero. On the kernel side the coefficient is `det K[{u,v},{u,v}]`. Therefore

\[
\boxed{
\mathbb P(F_{u,v})-\mathbb P(T_{u,v})
=q^2-p^2.
}
\tag{4.3}
\]

Subtracting (4.3) from (4.2),

\[
2\mathbb P(T_{u,v})
\le
(q+p)^2-(q^2-p^2)
=2p(q+p).
\]

Hence

\[
\boxed{
\mathbb P\bigl(\{u,v\}\text{ is a two-cycle of }\pi_\beta\bigr)
\le
p_\beta(u,v)\bigl(q_\beta+p_\beta(u,v)\bigr)
\le
2q_\beta p_\beta(u,v).
}
\tag{4.4}
\]

This is the desired connected correction: the non-summable `q_beta^2` disconnected return term has disappeared, leaving an off-diagonal heat-kernel factor.

Summing over `v != u`,

\[
\boxed{
\mathbb P(L_\beta(u)=2)
\le
2q_\beta\sum_{v\ne u}p_\beta(u,v)
=2q_\beta(1-q_\beta)
\le 2q_\beta.
}
\tag{4.5}
\]

In `d=3`,

\[
q_\beta\sim(4\pi\beta)^{-3/2},
\]

so (4.5) is `O(beta^{-3/2})`.

### What is new here

Fixed cycle length two was already covered by the archived fixed-number tagged-particle theorem, so (4.5) is not a new asymptotic order. The new structural point is the **mechanism**: a positive exclusion-return upper bound plus a fermionic/signed determinant coefficient cancels the disconnected contribution and produces a spatially summable connected heat-kernel factor. This is exactly the type of cancellation that the post-NEW-L46 program needs for general cycle sizes.

For a general finite `A`, the same diagonal determinant coefficient gives the exact parity identity

\[
\boxed{
\mathbb E\left[
\operatorname{sgn}(P|_A)\,\mathbf1_{\{P(A)=A\}}
\right]
=\det K[A,A].
}
\tag{4.6}
\]

Equivalently, the determinant separates even from odd invariant returns. For `|A|=2` this completely isolates the connected two-cycle after combining with the unsigned return probability. For `|A|>=3`, parity alone is insufficient to isolate the one-cycle sector; additional character/cycle-index information is required. This explains precisely where the two-point success stops.

# 5. A sharp reformulation of the Green-domination candidate

The 22:18 checkpoint introduced the conjectural inequality

\[
\mathbb P(C_P(u)\subseteq S)
\stackrel{?}{\le}
[R_S]_{uu},
\qquad
R_S=K_S(I-K_S)^{-1},
\tag{5.1}
\]

for finite proper `S`. If true on increasing boxes in `Z^3`, this would immediately imply

\[
\mathbb P(L_\beta(0)<\infty)
\le
\sum_{m\ge1}p_{m\beta}(0,0)
=O(\beta^{-3/2}),
\]

and hence solve the full conjecture for all sufficiently large `beta`.

The safe diagonal identities already archived give a useful exact equivalence. Let

\[
N_S(P)=\#\{\text{permutation cycles wholly contained in }S\},
\]

\[
D_S=\det(I-K_S)
=\mathbb P(N_S=0),
\tag{5.2}
\]

and let

\[
p_{\rm one}
=
\mathbb P(C_P(u)\subseteq S,\ N_S=1).
\]

The diagonal anchor identity gives

\[
\boxed{
p_{\rm one}=D_S[R_S]_{uu}.
}
\tag{5.3}
\]

Therefore (5.1) is **equivalent** to

\[
\boxed{
\mathbb P(N_S=1\mid C_P(u)\subseteq S)
\ge
\mathbb P(N_S=0).
}
\tag{5.4}
\]

In words: conditioned on the anchor cycle being contained in `S`, the probability that there is **no additional** complete cycle in `S` should be at least the unconditional probability that there is no complete cycle at all.

This is now a concrete negative-correlation statement between complete-cycle formation events. It is still **CONJECTURAL**. The strongly-Rayleigh theorem applies to exclusion occupancy fields, not directly to the random family of complete permutation cycles, so NEW-L44 does not prove (5.4).

The reformulation is nevertheless useful because it identifies exactly what a proof of Green domination must establish, and separates it from the previously withdrawn off-diagonal determinant interpretation.

# 6. Killed shortcut: termwise first-return domination is false

A natural attempt to prove (5.1) would be to decompose the root closure by cycle length and try the termwise comparison

\[
\mathbb P(L_P(u)=m,\ C_P(u)\subseteq S)
\stackrel{?}{\le}
(K_S^m)_{uu}
\tag{6.1}
\]

for every `m`. This is false.

An exact finite-state calculation on the unit-rate interchange process on the four-cycle `C4`, at `beta=1`, with

\[
S=\{0,1,3\},\qquad u=0,\qquad m=2,
\]

gives

\[
\mathbb P(L_P(0)=2,\ C_P(0)\subseteq S)
=0.22476336347782824,
\]

whereas

\[
(K_S^2)_{00}
=0.22430586295714260.
\]

Thus the ratio is approximately

\[
1.0020396280090684>1.
\]

So even if the aggregate Green-domination inequality (5.1) is true, it cannot be obtained by simply dominating each cycle length by the corresponding killed one-particle return term. This is consistent with the earlier lesson that representation-theoretic cancellations across lengths/sectors are essential.

# 8. Next attack

The highest-value next step is now sharply defined by NEW-L48.

For an `m`-point candidate set `A`, the raw strongly-Rayleigh return bound contains disconnected self-return contributions that are not spatially summable. The diagonal determinant coefficient supplies the parity-signed invariant return. For `m=2`, unsigned return plus parity is enough to cancel the disconnected term exactly and expose one off-diagonal heat-kernel factor.

For `m>=3`, the one-cycle sector should be extracted from a richer family of invariant-return observables. Two concrete routes are:

1. **Partition-lattice / multicolor return expansion.** For each partition `pi` of `A`, study the event that every block of `pi` is invariant. Möbius inversion on the partition lattice isolates the event that `P|_A` has one cycle. The technical target is an upper bound for these block-invariant return probabilities that preserves enough sign/cancellation to leave a tree of off-diagonal heat kernels.
2. **Character/hook extraction.** Combine the positive exclusion-return bound with the already archived Alon–Kozma/hook character identities. The target is not a termwise absolute bound (already known to fail), but a grouped bound whose connected part is controlled by a tree-graph sum such as
   \[
   q_\beta\sum_{T\text{ tree on }A}\prod_{(x,y)\in T}p_{c_T\beta}(x,y)
   \]
   or another spatially summable convolution kernel.

A successful connected bound whose total mass over all finite `A containing 0` is `O(beta^{-3/2})` would close the full theorem. NEW-L47 supplies strong control of very large prescribed sets; NEW-L48 shows concretely how disconnected mass can cancel at the first nontrivial cycle size.
