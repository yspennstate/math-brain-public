# 2. Source statement and current literature check

Elboim--Sly define the interchange process by putting an independent **rate-one Poisson clock on every edge**; at each ring the particles at the edge endpoints interchange. Their displayed conjecture reads:

- in `d=2`, all cycles are finite almost surely for every beta>0;
- in `d>=3`, for every beta>beta_c the permutation contains infinite cycles almost surely.

Their Theorem 1 proves the large-beta assertion only for `d>=5`. Their cyclic-time walk is

\[
W(k\beta+s)=\pi_s\pi_\beta^k(0),
\qquad 0\le s<\beta,
\]

so the chronological tagged-particle path on one physical period is not the permutation-cycle orbit. No monotonicity in beta is used below.

Sources checked on 16 September 2026:

1. Dor Elboim and Allan Sly, *Infinite cycles in the interchange process in five dimensions*, arXiv:2211.17023. This is the current source for the displayed conjecture, rate convention, and `d>=5` theorem. https://arxiv.org/abs/2211.17023
2. Alan Hammond, *Infinite cycles in the random stirring model on trees*, arXiv:1202.1319, and *Sharp phase transition in the random stirring model on trees*, arXiv:1202.1322. These use rooted/regular-tree unique-path and descendant-subtree structure, absent on Z^3. https://arxiv.org/abs/1202.1319 and https://arxiv.org/abs/1202.1322
3. Jakob E. Björnberg and Daniel Ueltschi, *Critical parameter of random loop model on trees*, arXiv:1608.08473. Interchange is a special case, but the theorem is on regular trees of large degree and its recursion is tree-specific. https://arxiv.org/abs/1608.08473
4. Bálint Tóth, *Improved lower bound on the thermodynamic pressure of the spin 1/2 Heisenberg ferromagnet*, Lett. Math. Phys. 28 (1993), 75--84, DOI 10.1007/BF00739568.

A bounded current search found no primary-source theorem closing the unweighted nearest-neighbor `d=3` statement. Tree/loop-model results remain methodological references only; no tree theorem is transferred to Z^3 without its hypotheses.

# 4. B25: a finite-k strengthening by counting block changes twice

This route does not improve the asymptotic metric, but it yields a sharper finite-k theorem and exposes exactly where the asymptotic constant comes from.

Fix a realized permutation in `V(B)`. Read the root cycle cyclically and record only the block label of each cycle vertex. Let `A` be the number of places at which this cyclic block word changes labels. Because all `k>=2` blocks are visited,

\[
A\ge k.
\tag{4.1}
\]

Color the `k` blocks independently red/blue with probability `1/2`. Let `M` be the number of color changes along the cyclic block word, and let `N` be the **global** number of red-to-blue permutation arrows. On the root cycle the number of red-to-blue color changes equals the number of blue-to-red color changes, hence equals `M/2`; therefore

\[
N\ge M/2.
\tag{4.2}
\]

Every one of the `A` block changes is bichromatic with probability `1/2`, so

\[
\mathbb E_\xi M=A/2,
\qquad
\mathbb E_\xi N\ge A/4\ge k/4.
\tag{4.3}
\]

Now take `m` independent fair block colorings. For coloring `r`, write `N_r` for the global red-to-blue arrow count and `\mu_r` for the corresponding one-color exclusion mean. For `a=v/m`, Jensen applied conditionally to a configuration in `V(B)` gives

\[
\mathbb E_{\xi_1,\ldots,\xi_m}
\exp\left(a\sum_{r=1}^mN_r\right)
\ge \exp(vk/4).
\tag{4.4}
\]

For fixed colorings, Holder and the already hypothesis-checked one-color strong-Rayleigh estimate give

\[
\mathbb E_\pi
\exp\left(\frac vm\sum_{r=1}^mN_r\right)
\le
\exp\left((e^v-1)\frac1m\sum_{r=1}^m\mu_r\right).
\tag{4.5}
\]

For a fair block cut,

\[
\mathbb E_\xi\mu_r=\mathcal H_\beta(\mathcal B)/4.
\tag{4.6}
\]

The variables `\mu_r` are bounded for fixed deterministic blocks, so the law of large numbers plus dominated convergence allows `m->infinity` in (4.5). Combining (4.4)--(4.6) yields:

## NEW-L102 — finite-k block-change replica bound

For every `v>=0`,

\[
\boxed{
\mathbb P(\mathcal V(\mathcal B))
\le
\exp\left\{-\frac{vk}{4}
+\frac{e^v-1}{4}\mathcal H_\beta(\mathcal B)\right\}.
}
\tag{4.7}
\]

Under the unchanged heat hypothesis (3.1), the optimal value satisfies

\[
e^{v_*}=4e\frac{k}{k-1},
\tag{4.8}
\]

and the natural-log exponent is

\[
E_k
=\frac{k}{4}\log\left(4e\frac{k}{k-1}\right)
-\frac{k}{4}
+\frac{k-1}{16e}.
\tag{4.9}
\]

Dividing by `k-1` and sending `k->infinity`,

\[
\frac{E_k}{k-1}
\longrightarrow
\frac{\log2}{2}+\frac1{16e}.
\tag{4.10}
\]

Thus NEW-L102 strictly sharpens the finite-k prefactor/exponent but **does not move** the frozen polynomial exponent after the scale map (3.2). It is not reported as metric movement.

# 5. B24: the extremal connected block word kills a hoped-for combinatorial improvement

A natural hope was that replacing a spanning tree by the entire connected block-transition graph might produce an exponentially stronger random-cut lower moment. This is false at the level of connectivity alone.

Take the cyclic block word

\[
1,2,\ldots,k,1,
\tag{5.1}
\]

so its transition graph is the simple cycle `C_k`. For a fair red/blue coloring let `M` be the number of bichromatic edges of this block cycle and let `N=M/2` be its red-to-blue transition count. Put `t=e^{v/2}`. The exact transfer-matrix computation is

\[
\mathbb E_\xi e^{vN}
=2^{-k}\left[(1+t)^k+(1-t)^k\right].
\tag{5.2}
\]

Indeed, the color-pair transfer matrix is

\[
\begin{pmatrix}1&t\\ t&1\end{pmatrix},
\]

whose eigenvalues are `1+t` and `1-t`; taking its `k`th trace and dividing by `2^k` gives (5.2).

Hence

\[
\lim_{k\to\infty}\frac1k
\log\mathbb E_\xi e^{vN}
=
\log\frac{1+e^{v/2}}2.
\tag{5.3}
\]

The spanning-tree lower moment used in the earlier method has exponential rate exactly the same quantity. Therefore:

## Barrier B24

Among arguments that use only the fact that the block-transition graph is connected, replacing the spanning tree by the full transition graph cannot yield a uniformly larger exponential random-cut moment: the simple cyclic block word (5.1) is an explicit extremal obstruction.

This is a counterexample to the **proposed transfer step**, not a counterexample to Tóth's conjecture and not a proof that (3.3) is the true optimal leakage exponent. Additional geometric information about the heat weights or physical block arrangement could still improve the metric.

# 7. Quantitative strengthening of the already archived finite-torus transfer

This section does **not** re-prove the qualitative `HARD10-03-L5` as a new claim. L5 already states that positive fixed-time torus mass on any cycle threshold `a_m->infinity` implies an infinite cycle on Z^3. What is new here is an explicit coupling error, useful for a future finite-box theorem with numerical constants.

Let `P_beta` denote interchange on Z^3 and `P_beta^(m)` interchange on the cubic torus `T_m^3`, both with rate one on each unoriented nearest-neighbor edge. Let `L_beta(0)` and `L_{m,beta}(0)` be the corresponding root cycle lengths.

Fix `K>=1`, and put

\[
R_{m,K}=\left\lfloor\frac{m}{8(K+1)}\right\rfloor.
\tag{7.1}
\]

Assume `R_{m,K}>=1`.

For a rate-one-per-edge tagged particle `X`, each coordinate is the difference of two independent rate-one Poisson processes. For `0<theta<=1`,

\[
\exp\{\theta X_t^{(i)}-2t(\cosh\theta-1)\}
\]

is a positive martingale and `cosh theta-1<=theta^2`. Doob's inequality and the choice

\[
\theta=\min\{R/(4\beta),1\}
\]

give

\[
\mathbb P\left(\sup_{0\le t\le\beta}|X_t^{(i)}|\ge R\right)
\le
2\exp\left[-\min\left\{\frac{R^2}{8\beta},\frac R2\right\}\right].
\tag{7.2}
\]

Union over the three coordinates yields

\[
q_\beta(R)
:=\mathbb P\left(\sup_{0\le t\le\beta}\|X_t\|_\infty\ge R\right)
\le
6\exp\left[-\min\left\{\frac{R^2}{8\beta},\frac R2\right\}\right].
\tag{7.3}
\]

The archived point-shift stationarity `HARD10-03-L3` implies that the chronological beta-period path starting from each successive orbit anchor `P_beta^j(0)` has the same maximal-displacement marginal as the root tagged path. Hence a union bound over the first `K` periods gives

\[
\mathbb P\left(
\text{some one of the first K chronological period-paths leaves its radius-R neighborhood}
\right)
\le K q_\beta(R).
\tag{7.4}
\]

On the complementary event the `j`th anchor is within `jR` in `l_infinity` norm of the origin and the full `j`th period-path lies within `(j+1)R`. With `R=R_{m,K}`, all clocks needed to determine the first `K` orbit iterates lie in an ordinary lattice box that embeds injectively into the torus. Couple those local Poisson clocks identically in Z^3 and `T_m^3`.

Therefore:

## NEW-L103 — explicit fixed-K torus/lattice coupling error

For every fixed `beta>0`, `K>=1`, and `m` with `R_{m,K}>=1`,

\[
\boxed{
\left|
\mathbb P_{T_m^3}(L_{m,\beta}(0)>K)
-
\mathbb P_{\mathbb Z^3}(L_\beta(0)>K)
\right|
\le
6K\exp\left[-\min\left\{
\frac{R_{m,K}^2}{8\beta},\frac{R_{m,K}}2
\right\}\right].
}
\tag{7.5}
\]

The event `{L>K}` is determined by the first `K` period endpoints, so the coupling above suffices. No chronological path is confused with a permutation cycle; chronological paths are only the local mechanism used to determine those endpoints.

### Macroscopic finite-box milestone implies the source infinite-volume statement

Define the finite-torus macroscopic vertex mass

\[
D_{m,\beta}(a)
:=\frac1{m^3}\#\{x\in T_m^3:L_{m,\beta}(x)\ge a\}.
\tag{7.6}
\]

Translation invariance gives the exact identity

\[
\mathbb E D_{m,\beta}(a)
=
\mathbb P(L_{m,\beta}(0)\ge a).
\tag{7.7}
\]

Consequently, if at one fixed beta there are `delta>0`, `eta>0`, and an unbounded sequence `m_j` such that

\[
\mathbb E D_{m_j,\beta}(\delta m_j^3)\ge\eta,
\tag{7.8}
\]

then for every fixed `K`, (7.5)--(7.8) give

\[
\mathbb P_{\mathbb Z^3}(L_\beta(0)>K)\ge\eta
\]

in the `j->infinity` limit. Continuity from above yields

\[
\boxed{
\mathbb P_{\mathbb Z^3}(L_\beta(0)=\infty)\ge\eta.
}
\tag{7.9}
\]

More generally, if

\[
\mathbb P(D_{m_j,\beta}(\delta m_j^3)\ge\eta)\ge\rho,
\]

then `E D>=eta rho` and (7.9) holds with `eta rho`.

Thus a source-matching positive-density macroscopic-cycle theorem on the torus is more than enough, and the finite-volume/infinite-volume passage now has the explicit error (7.5).

If a future finite-box theorem establishes (7.8) for every `beta>=beta_0` with an explicit finite `beta_0` (allowing `delta,eta` to depend on beta), applying NEW-L103 pointwise in beta proves Tóth's `d=3` existence assertion for every `beta>=beta_0` **without any monotonicity assumption**.

This run does **not** prove such a finite-box theorem and therefore does **not** produce an unconditional source-level beta_0. The H-direction remains PARTIAL exactly at that obligation.
