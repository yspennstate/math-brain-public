# 3. NEW-L93 — fresh phase-window endpoint and path escape bounds

The previous fresh-buffer theorem was formulated for a whole period of duration `beta`. For a restart construction, one wants to preserve only a short **phase window** of the cyclic slab.

Fix a deterministic interval

\[
I=[s,s+T]\subset[0,\beta],\qquad T\ge1.
\]

Let `F` be any admissible history that has revealed arbitrary clock information outside a finite buffer `U` during `I`, and possibly arbitrary information at other physical times, but has revealed **no clock on any edge incident to `U` during `I`**. Let `x` be `F`-measurable and lie in a finite core `S subset U`. Write

\[
b=\operatorname{dist}(S,U^c)
\]

and

\[
\varepsilon_{T,b}
:=
\sup_{z\in S}\mathbb P_z(\tau_{U^c}\le T)
\]

for ordinary continuous-time nearest-neighbor SRW with rate one in each of the six directions.

Let `W_I` denote the interchange map generated only by clocks in `I`.

## Lemma 3.1 — conditional endpoint anti-concentration

For every `F`-measurable finite target set `A`,

\[
\boxed{
\mathbb P\bigl(W_I(x)\in A\mid\mathscr F\bigr)
\le C|A|T^{-3/2}+\varepsilon_{T,b}.
}
\tag{3.1}
\]

### Proof

Up to its first exit from `U`, the tagged particle starting at `x` sees untouched rate-one clocks on all incident edges and is therefore exactly ordinary continuous-time SRW. Couple it to an unrestricted SRW `X` until that exit. Then

\[
\begin{aligned}
\mathbb P(W_I(x)\in A\mid\mathscr F)
&\le
\mathbb P(X_T\in A)+\mathbb P_x(\tau_{U^c}\le T)\\
&\le |A|\sup_y p_T(x,y)+\varepsilon_{T,b}.
\end{aligned}
\]

For completeness, the one-dimensional coordinate kernel has Fourier representation

\[
p_T^{(1)}(a,b)
=\frac1{2\pi}\int_{-\pi}^{\pi}
 e^{-2T(1-\cos\theta)}e^{-i\theta(b-a)}\,d\theta.
\]

Using `1-cos(theta)>=c theta^2` on `[-pi,pi]` gives

\[
\sup_{a,b}p_T^{(1)}(a,b)\le CT^{-1/2}.
\]

The three coordinates are independent, hence

\[
\sup_{x,y}p_T(x,y)\le CT^{-3/2}.
\]

This proves (3.1). `square`

## Lemma 3.2 — conditional fresh-tube path escape

If the Euclidean ball `B_2(x,r)` is contained in `U`, then

\[
\boxed{
\mathbb P\left(
\sup_{0\le u\le T}|X_u-x|_2\ge r
\mid\mathscr F
\right)
\le
C\exp\left[-c\frac{r^2}{T+r}\right].
}
\tag{3.2}
\]

Consequently the same bound controls the probability that the interchange strand exits `B_2(x,r)` during the fresh window.

### Proof

For one coordinate,

\[
X_t^{(i)}-X_0^{(i)}=N_+(t)-N_-(t)
\]

with independent rate-one Poisson processes, so for every `theta>0`,

\[
M_t(\theta)
:=
\exp\left\{
\theta(X_t^{(i)}-X_0^{(i)})
-2t(\cosh\theta-1)
\right\}
\]

is a positive martingale. Doob's maximal inequality gives

\[
\mathbb P\left(\sup_{u\le T}(X_u^{(i)}-X_0^{(i)})\ge a\right)
\le
\inf_{\theta>0}
\exp\{-\theta a+2T(\cosh\theta-1)\}.
\]

Choosing the exact optimizer `sinh(theta)=a/(2T)` and using the standard elementary lower bound on the resulting Bennett rate gives

\[
\le \exp\left[-c\frac{a^2}{T+a}\right].
\]

Apply this to both signs and three coordinates, with `a=r/sqrt(3)`. This proves (3.2). `square`

### Local-escape form

If an `F`-measurable old spatial set `A_old` is disjoint from `B_2(x,r)`, then the fresh strand can hit `A_old` during `I` only after leaving that ball. Therefore

\[
\boxed{
\mathbb P\left(
\text{fresh strand from }x\text{ hits }A_{old}\text{ during }I
\mid\mathscr F
\right)
\le
C\exp\left[-c\frac{r^2}{T+r}\right].
}
\tag{3.3}
\]

This is a **path** local-escape estimate, not merely an endpoint bound.

# 4. NEW-L94 — exact phase split and an adaptive cyclic restart lemma

Take the deterministic early phase window

\[
I=[0,T].
\]

Let

\[
W:=\Phi_{0,T},
\qquad
Q:=\Phi_{T,\beta},
\]

where `Phi` denotes the Harris interchange flow. Then

\[
\boxed{P:=\pi_\beta=Q\circ W,}
\tag{4.1}
\]

and `W` and `Q` are independent because they use disjoint physical-time Poisson increments.

Condition on the entire random map `Q`. This is safe for the present one-window argument: it is measurable with respect to the complement time interval and is independent of every clock in `I`. No claim is made that other phase windows remain fresh after this conditioning.

Let

\[
a_0=0,\qquad a_{j+1}=P(a_j)=Q(W(a_j)).
\tag{4.2}
\]

Suppose that at stage `j`, based on `Q` and previously revealed `I`-window clocks, an `r`-ball

\[
U_j=B_2(a_j,r)
\]

has an incident-edge space-time region in `I` disjoint from every region revealed earlier. Reveal the complete `I`-clock configuration on edges incident to `U_j`. This is a finite admissible no-peeking exposure.

On the event that the `W`-strand from `a_j` stays inside `U_j`, `W(a_j)` is determined by this newly revealed region, and then `a_{j+1}=Q(W(a_j))` is determined because `Q` is conditioned.

Let `A_j` be any finite history-measurable set of same-phase target vertices. Since `Q` is a bijection,

\[
a_{j+1}\in A_j
\Longleftrightarrow
W(a_j)\in Q^{-1}(A_j).
\]

The preimage has exactly `|A_j|` vertices. Lemma 3.1 therefore gives the restart estimate

\[
\boxed{
\mathbb P\bigl(
 a_{j+1}\in A_j
\mid\mathscr F_j,Q
\bigr)
\le
C|A_j|T^{-3/2}
+arepsilon_{T,r},
}
\tag{4.3}
\]

where the exit term absorbs targets whose `Q`-preimages lie outside the fresh ball.

For the old-anchor set

\[
A_j=\{a_0,\ldots,a_j\},
\]

this gives

\[
\boxed{
\mathbb P\bigl(
 a_{j+1}\in\{a_0,\ldots,a_j\}
\mid\mathscr F_j,Q
\bigr)
\le
C(j+1)T^{-3/2}
+arepsilon_{T,r}.
}
\tag{4.4}
\]

Iterated conditioning, with no independence assumption between stages, gives the following restricted progression bound. If stages `0,...,n-1` are all certified fresh before exposure, then

\[
\boxed{
\mathbb P\bigl(
\text{some listed-anchor recruitment by stage }n
\bigr)
\le
Cn^2T^{-3/2}+n\varepsilon_{T,r}.
}
\tag{4.5}
\]

Likewise, if the previously exposed `I`-window strand cloud lies outside `B_2(a_j,r)`, then Lemma 3.2 gives a pathwise return-to-old-cloud bound

\[
\boxed{
\mathbb P\bigl(
\text{the new }I\text{-strand hits the old }I\text{-strand cloud}
\mid\mathscr F_j,Q
\bigr)
\le
C\exp\left[-c\frac{r^2}{T+r}\right].
}
\tag{4.6}
\]

### What NEW-L94 actually buys

This is the missing **partially fresh phase-tube** analogue of the older whole-period fresh-buffer lemma. Arbitrary entanglement may be hidden in the complement map `Q`; the new randomness injected at the chosen phase is still ordinary SRW inside a fresh tube, and the next same-phase endpoint is an arbitrary fixed bijective image under `Q`. The only price for returning to a listed same-phase set is the cardinality factor in (4.3).

It is not a monotonicity statement, and it does not make successive cycle arrows independent.

# 5. NEW-L95 — polynomially many certified fresh phase tubes on the actual cyclic orbit

NEW-L94 is conditional on having geometrically fresh balls. The short-driver packing theorem `NEW-L86` supplies such balls for a substantial initial part of the **actual** permutation orbit.

Fix

\[
0<\delta<1/12.
\]

Set, with harmless integer rounding,

\[
n=\beta^{1/2-3\delta},
\qquad
r=\beta^{1/3-\delta},
\qquad
T=\beta^{2/3-3\delta}.
\tag{5.1}
\]

For sufficiently large `beta`, `1<=T<beta` and `r<<T`.

Apply `NEW-L86` with horizon `H=n` and its separation parameter equal to `2r`. Then

\[
\begin{aligned}
\mathbb P\left(
\min_{0\le i<j\le n}|a_i-a_j|_2\le4r
\right)
&\le
C\left(
\frac{n}{\sqrt\beta}
+
\frac{n(2r)^3}{\beta^{3/2}}
\right)\\
&\le C\left(\beta^{-3\delta}+\beta^{-6\delta}\right)\\
&\le C\beta^{-3\delta}.
\end{aligned}
\tag{5.2}
\]

On the complement, the balls `B_2(a_j,r)` have disjoint incident-edge neighborhoods for all sufficiently large `beta` (the factor `4` leaves a fixed lattice-edge margin).

Now run the adaptive one-window exploration of Section 4. Stop at the first anchor whose `r`-ball overlaps a previously revealed `I`-region, or at the first fresh strand that exits its own ball. Before this stopping time, every newly selected tube is untouched, so Lemma 3.2 applies conditionally at every stage.

For the scale choice (5.1),

\[
\frac{r^2}{T+r}\ge c\beta^\delta
\tag{5.3}
\]

for all sufficiently large `beta`. Hence, by iterated conditioning,

\[
\mathbb P(\text{a tube exit occurs before a geometric overlap by stage }n)
\le
Cn e^{-c\beta^\delta}.
\tag{5.4}
\]

Combining (5.2) and (5.4) proves:

## Theorem NEW-L95 — PROVED

For every fixed `delta in (0,1/12)`, with probability at least

\[
\boxed{
1-C\beta^{-3\delta}
-C\beta^{1/2-3\delta}e^{-c\beta^\delta},
}
\tag{5.5}
\]

the first

\[
n=\lfloor\beta^{1/2-3\delta}\rfloor
\]

cyclic iterates `a_j=pi_beta^j(0)` admit a bona fide admissible exploration of the **same physical phase window** `[0,T]`, with

\[
T=\beta^{2/3-3\delta},
\]

inside pairwise disjoint spatial tubes of radius

\[
r=\beta^{1/3-\delta},
\]

such that every phase-window strand remains inside its own tube.

In particular, on this event the early-phase chronological strand pieces belonging to distinct cyclic iterates are mutually spatially disjoint, and when tube `j` is first selected its `I`-clock configuration is genuinely independent fresh Poisson randomness conditional on all earlier tube exposures and on the complement map `Q`.

This is stronger than merely saying that the same-phase endpoints are separated: it certifies **unrevealed space-time volume around the actual cyclic exploration**.

For the same parameters,

n^2T^{-3/2}

\beta^{-1+\frac92\delta}

\boxed{\beta^{-3\delta/2}}.

# 6. Arbitrary deterministic phase window

The same construction works for a deterministic phase interval

\[
I=[s,s+T]\subset[0,\beta]
\]

without wrapping. Starting at phase `s`, the one-period map is

\[
P_s=\Phi_{0,s}\circ\Phi_{s,\beta},
\]

which is conjugate to `P=pi_beta`. Factoring at `s+T`,

\[
P_s
=
\underbrace{\left(\Phi_{0,s}\circ\Phi_{s+T,\beta}\right)}_{Q_s}
\circ
\underbrace{\Phi_{s,s+T}}_{W_s}.
\tag{6.1}
\]

The two factors use disjoint time increments and are independent. The archived exact phase-rotation/re-rooting identity shows that the rooted geometry of the same-cycle anchors at deterministic phase `s` has the same law as at phase zero. Therefore `NEW-L95` holds, with the same exponents and constants up to harmless fixed geometric factors, for every deterministic nonwrapping phase window.

This phase flexibility matters for future restart attempts, but the present theorem only certifies one such window at a time.

# 7. Critical limitation: one fresh window is not yet an infinite renewal

There is a subtle but load-bearing limitation.

In Section 4 we conditioned on the entire complement map `Q` in order to isolate one phase window `W`. That is mathematically legitimate because `Q` and `W` are independent. However, after conditioning on `Q`, one cannot then declare a second subwindow contained in the complement to be fresh: `Q` is a function of its clocks. Thus `NEW-L94/95` **do not** justify iterating fresh phase windows around the whole time circle by repeatedly reusing the same conditioning argument.

This is exactly where a false proof could accidentally enter.

Likewise, the certificate lasts for only

\[
n=\beta^{1/2-o(1)}
\]

cyclic iterates at fixed `beta`; it does not provide an unbounded number of restarts. The full conjecture requires a mechanism that can renew after the first entanglement without consuming all remaining phase randomness.

The new theorem nevertheless removes one earlier ambiguity: the geometric endpoint packing from the driver coupling can indeed be upgraded to **actual no-peeking fresh space-time tubes** for a polynomial cyclic prefix. The remaining difficulty is renewal, not the first tube construction.

# 8. Failed/ruled-out shortcuts in this iteration

1. **Condition on one complement map and then reuse its subwindows as fresh.** Invalid; conditioning on `Q` generally biases every clock used to construct `Q`.
2. **Treat (5.7) as an all-time cycle-length estimate.** Invalid; it controls only the certified finite prefix.
3. **Replace the cyclic orbit by a chronological SRW.** Not done; SRW is used only inside a newly certified fresh phase tube.
4. **Assume different tube stages are independent.** Not needed; all cumulative bounds use iterated conditional estimates.
5. **Infer infinite cycles from finite capacity/local-mass geometry alone.** Still invalid because same-slab candidate selection is anticipative.

# 10. Next attack

The next target should be a **localized complement-following lemma** that avoids conditioning on the entire map `Q`.

Concretely, after exposing one fresh phase tube and obtaining its endpoint `y=W(a_j)`, follow only the single `Q`-trajectory needed to compute `Q(y)`, revealing the minimum edge-time information along that trajectory. Prove that, with high conditional probability, this localized complement exposure leaves a positive-density family of other deterministic phase windows and spatial buffers untouched. If that can be quantified, one can rotate to a new phase window after entanglement and apply `NEW-L93/94` again without the circular “condition on all of Q” step.

A sufficient quantitative version would show that one restart consumes only `o(beta)` physical phase measure and only `o(r^3)` fresh spatial volume near a positive fraction of future anchors. Combined with the cycle-wide Frostman/capacity geometry from `NEW-L90/91`, this could turn the present one-window certificate into a genuine renewal scheme.

A second route is to retain a fixed phase window forever and prove that the set of already revealed tube centers remains sparse enough that the cycle-wide local-mass bound forces infinitely many future anchors outside their union. The obstacle is discovering those future anchors without first revealing contaminated `W`-regions.
