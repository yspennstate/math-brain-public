# 3. Coarse block notation

Let

\[
P:=\pi_\beta.
\]

Fix pairwise disjoint, nonempty, deterministic finite sets

\[
\mathcal B=(B_1,\dots,B_k),\qquad k\ge2,
\]

and put

\[
U=\bigcup_{i=1}^k B_i.
\]

Assume `0 in U`. Define the root-cycle block-visitation event

\[
\mathcal V(\mathcal B)
=
\left\{
C_P(0)\subseteq U,
\quad
C_P(0)\cap B_i\ne\varnothing\ \text{for every }i
\right\}.
\tag{3.1}
\]

Thus `V(B)` does **not** prescribe the exact vertex set or length of the root cycle. It sums over every possible cycle contained in `U` that visits every prescribed block.

Let `p_beta(x,y)` be the one-particle heat kernel and define the total one-period cross heat between distinct blocks

\[
\boxed{
\mathcal H_\beta(\mathcal B)
:=
\sum_{i\ne j}
\sum_{x\in B_i}\sum_{y\in B_j}
p_\beta(x,y).
}
\tag{3.2}
\]

This quantity is deterministic and depends only on one-particle random walk.

# 4. NEW-L52 — k-uniform first-moment connected-block bound

For a realization of `P`, define

\[
X_{\mathcal B}(P)
=
\#\{x\in U:\ x\in B_i,\ P(x)\in B_j\text{ for some }i\ne j\}.
\tag{4.1}
\]

On `V(B)`, look only at the mapping arrows belonging to the root cycle. Collapse each visited vertex to its block index. The resulting directed block-transition multigraph is

1. connected as an undirected graph, because one permutation cycle visits all `k` blocks;
2. balanced at every block, because a directed cycle enters a block as many times as it exits it.

A connected balanced directed multigraph on `k>=2` vertices has at least `k` directed edges: every vertex has positive outdegree. Therefore, pathwise,

\[
\boxed{
\mathbf1_{\mathcal V(\mathcal B)}
\le
\frac1k X_{\mathcal B}(P).
}
\tag{4.2}
\]

Taking expectation and using

\[
\mathbb P(P(x)=y)=p_\beta(x,y)
\]

gives the first new theorem.

## Theorem NEW-L52 — PROVED

For every pairwise disjoint finite block family `B=(B_1,...,B_k)`, `k>=2`,

\[
\boxed{
\mathbb P\bigl(\mathcal V(\mathcal B)\bigr)
\le
\min\left\{1,\frac{\mathcal H_\beta(\mathcal B)}{k}\right\}.
}
\tag{4.3}
\]

### Why this is different from NEW-L51

NEW-L51 selected `k` particular cross-block mapping arrows and bounded their simultaneous occurrence using the ordered `k`-tag kernel. Equation (4.3) instead sums *all* cross arrows before taking expectation. It has no `C_k` or `c_k`, no many-particle heat kernel, and remains meaningful for arbitrary `k`.

The price is that (4.3) does not retain the extra closed-loop return factor by itself. The next section obtains an exponential-in-`k` improvement whenever the average cross heat is small.

# 5. NEW-L53 — uniform exponential connected-block bound from a random cut

The key idea is to turn connectedness of the final-cycle block graph into a **linear number of crossings of one random binary cut**, and then use one-color exclusion negative dependence. This avoids the uncontrolled `k`-tag constants entirely.

Independently of the interchange process, color the block indices

\[
\xi_i\in\{0,1\},\qquad i=1,\dots,k,
\]

i.i.d. Bernoulli `1/2`. For a coloring `xi`, put

\[
R_\xi=\bigcup_{i:\xi_i=1}B_i,
\qquad
D_\xi=\bigcup_{i:\xi_i=0}B_i.
\tag{5.1}
\]

For a permutation realization define

\[
N_\xi(P)
=
\#\{x\in R_\xi:P(x)\in D_\xi\}.
\tag{5.2}
\]

This counts **all** labels crossing from the red union to the blue union, not only root-cycle labels.

## 5.1 Deterministic random-cut lemma

Fix a realization in `V(B)`. The root-cycle block graph is connected. Choose any deterministic spanning tree `T(P)` of its undirected support, for example the lexicographically first spanning tree.

Let

\[
Z_\xi
=
\#\{\{i,j\}\in T(P):\xi_i\ne\xi_j\}.
\]

Conditional on the permutation realization, the tree is fixed. For independent vertex bits on a tree, the edge-disagreement indicators are themselves independent Bernoulli `1/2`: root color together with the edge XORs is a bijective parametrization of all vertex colorings. Hence

\[
Z_\xi\sim\operatorname{Bin}(k-1,1/2).
\tag{5.3}
\]

Let `n=k-1`. By Paley--Zygmund,

\[
\begin{aligned}
\mathbb P_\xi(Z_\xi\ge n/4)
&\ge
\frac14\frac{(\mathbb EZ_\xi)^2}{\mathbb EZ_\xi^2}\\
&=
\frac14\frac{n^2/4}{n(n+1)/4}
=
\frac{n}{4(n+1)}
\ge\frac18.
\end{aligned}
\tag{5.4}
\]

Each bichromatic tree edge is supported by at least one actual root-cycle mapping arrow crossing the binary cut. Distinct tree edges are distinct block pairs, hence give distinct crossing arrows. Because the root cycle is a directed cycle contained in `U`, the number of its arrows from `R_xi` to `D_xi` equals the number from `D_xi` to `R_xi`. Therefore

\[
N_\xi(P)
\ge
\frac12 Z_\xi.
\tag{5.5}
\]

Define

\[
r_k:=\left\lceil\frac{k-1}{8}\right\rceil.
\tag{5.6}
\]

Equations (5.4)--(5.5) imply the pathwise averaged statement

\[
\boxed{
\mathbf1_{\mathcal V(\mathcal B)}
\le
8\,\mathbb E_\xi
\mathbf1_{\{N_\xi(P)\ge r_k\}}.
}
\tag{5.7}
\]

No probabilistic property of interchange has been used yet.

## 5.2 Strong-Rayleigh tail for a fixed cut

Fix the coloring `xi`. Color exactly the labels initially in `R_xi` red. Their occupied set at time `beta` evolves as symmetric exclusion started from the deterministic set `R_xi`. The variable `N_xi(P)` is exactly

\[
N_\xi
=
\sum_{y\in D_\xi}\eta_\beta(y),
\tag{5.8}
\]

the number of red exclusion particles in the blue union at time `beta`.

By Borcea--Brändén--Liggett, the final occupation indicators are negatively associated. For `theta>=0`, iterating negative association over the singleton coordinates gives

\[
\begin{aligned}
\mathbb E e^{\theta N_\xi}
&=
\mathbb E\prod_{y\in D_\xi}e^{\theta\eta_\beta(y)}\\
&\le
\prod_{y\in D_\xi}
\mathbb E e^{\theta\eta_\beta(y)}\\
&=
\prod_{y\in D_\xi}
\left[1+(e^\theta-1)\rho_y\right]\\
&\le
\exp\left[(e^\theta-1)\mu_\xi\right],
\end{aligned}
\tag{5.9}
\]

where

\[
\rho_y
=
\sum_{x\in R_\xi}p_\beta(x,y),
\qquad
\mu_\xi
=
\sum_{x\in R_\xi}\sum_{y\in D_\xi}p_\beta(x,y).
\tag{5.10}
\]

The usual Chernoff optimization therefore yields, for every integer `r>=1`,

\[
\boxed{
\mathbb P(N_\xi\ge r)
\le
\left(\frac{e\mu_\xi}{r}\right)^r,
}
\tag{5.11}
\]

with the understanding that the right side may exceed one, in which case the trivial bound one is better.

Since every term in `mu_xi` is among the directed inter-block terms in (3.2),

\[
\mu_\xi\le\mathcal H_\beta(\mathcal B).
\tag{5.12}
\]

Combining (5.7), (5.11), and (5.12) proves:

## Theorem NEW-L53 — PROVED

For every pairwise disjoint finite block family `B=(B_1,...,B_k)`, `k>=2`, with `r_k=ceil((k-1)/8)`,

\[
\boxed{
\mathbb P\bigl(\mathcal V(\mathcal B)\bigr)
\le
\min\left\{
1,
\frac{\mathcal H_\beta(\mathcal B)}{k},
8\left(
\frac{e\,\mathcal H_\beta(\mathcal B)}{r_k}
\right)^{r_k}
\right\}.
}
\tag{5.13}
\]

In particular, if

\[
\mathcal H_\beta(\mathcal B)
\le
\frac{k-1}{16e},
\tag{5.14}
\]

then `r_k >= (k-1)/8`, so

\[
\frac{e\mathcal H_\beta}{r_k}\le\frac12,
\]

and hence

\[
\boxed{
\mathbb P\bigl(\mathcal V(\mathcal B)\bigr)
\le
8\,2^{-r_k}
\le
8\,2^{-(k-1)/8}.
}
\tag{5.15}
\]

This is an exponential-in-`k` connected-sector estimate with **no particle-number-dependent heat-kernel constant**.

# 6. Spatial corollary in d=3

For continuous-time nearest-neighbor random walk on `Z^3`, the standard Gaussian heat-kernel upper bound gives, for `beta>=1`,

\[
p_\beta(x,y)
\le
C\beta^{-3/2}
\exp\left(-c|x-y|^2/\beta\right).
\tag{6.1}
\]

Suppose the blocks satisfy

\[
\operatorname{dist}(B_i,B_j)\ge R
\qquad(i\ne j).
\tag{6.2}
\]

Writing

\[
m=|U|=\sum_i|B_i|,
\]

we obtain

\[
\boxed{
\mathcal H_\beta(\mathcal B)
\le
C\beta^{-3/2}e^{-cR^2/\beta}
\sum_{i\ne j}|B_i||B_j|
\le
C m^2\beta^{-3/2}e^{-cR^2/\beta}.
}
\tag{6.3}
\]

If additionally `|B_i|<=v` for every block, then `m<=kv` and

\[
\mathcal H_\beta(\mathcal B)
\le
C k^2v^2\beta^{-3/2}e^{-cR^2/\beta}.
\tag{6.4}
\]

Consequently, whenever

\[
C k v^2\beta^{-3/2}e^{-cR^2/\beta}
\le c_0
\tag{6.5}
\]

for a sufficiently small absolute `c_0`, NEW-L53 gives

\[
\boxed{
\mathbb P\left(
C_{\pi_\beta}(0)\subseteq\bigcup_{i=1}^kB_i,
\quad
C_{\pi_\beta}(0)\cap B_i\ne\varnothing\ \forall i
\right)
\le
8\,2^{-(k-1)/8}.
}
\tag{6.6}
\]

Thus a finite root cycle cannot, with appreciable probability, be confined to and simultaneously visit a large number of mutually low-communication blocks. This statement has already summed over all possible exact cycle vertex sets and cycle lengths inside their union.

### Geometry-independent form

Pairwise Euclidean separation is only a sufficient condition. The actual theorem uses the exact one-period cross heat `H_beta(B)`. Therefore it also applies to irregular or anisotropic block families whenever their one-particle communication over time `beta` is small.

# 7. NEW-L54 — conditional no-peeking version

The argument survives the finite adaptive no-peeking framework archived in `NEW-L46`.

Condition on an admissible exploration history `F`. Let the disjoint finite blocks `B_i` be `F`-measurable and let

\[
K^\mathscr F_\beta(x,y)
=
\mathbb P(P(x)=y\mid\mathscr F)
\]

be the conditional one-particle kernel. Define

\[
\mathcal H^\mathscr F(\mathcal B)
=
\sum_{i\ne j}
\sum_{x\in B_i,y\in B_j}
K^\mathscr F_\beta(x,y).
\tag{7.1}
\]

The deterministic block-graph and random-coloring arguments are unchanged after conditioning. Archived `NEW-L46` proved that under admissible no-peeking conditioning, the final red occupation law remains strongly Rayleigh: unrevealed pieces are symmetric-exclusion evolutions and revealed rings act as deterministic coordinate permutations. Therefore the same negative-association MGF bound applies with the conditional marginals.

## Theorem NEW-L54 — PROVED

Almost surely with respect to every admissible finite no-peeking history,

\[
\boxed{
\mathbb P\bigl(\mathcal V(\mathcal B)\mid\mathscr F\bigr)
\le
\min\left\{
1,
\frac{\mathcal H^\mathscr F(\mathcal B)}{k},
8\left(
\frac{e\mathcal H^\mathscr F(\mathcal B)}{r_k}
\right)^{r_k}
\right\}.
}
\tag{7.2}
\]

In particular, if

\[
\mathcal H^\mathscr F(\mathcal B)
\le\frac{k-1}{16e},
\]

then the conditional probability is at most

\[
8\,2^{-(k-1)/8}.
\tag{7.3}
\]

This gives a potentially useful multiscale form: after an admissible exploration, any proposed trap consisting of many remaining blocks with small conditional one-period communication has exponentially small conditional probability of containing a root cycle that visits all of them.

# 8. Relation to the previous unicyclic-witness bottleneck

The preceding checkpoint identified the correct connected witness geometry: `k` blocks require at least `k` cross-block arrows, not merely a `k-1`-edge tree. The quantitative problem was that following `k` specific arrows invokes a `k`-tag heat kernel with constants that may deteriorate with `k`.

NEW-L53 takes a different route:

1. use only a spanning tree of the actual connected block support;
2. apply an independent random binary coloring to that tree;
3. with uniformly positive coloring probability, force order `k` arrows across **one binary cut**;
4. forget the labels of those arrows and view the whole selected side as one red exclusion species;
5. use strong-Rayleigh negative association to obtain a Poisson-binomial Chernoff tail involving only one-particle heat flow.

The resulting estimate is uniform in `k`. It therefore resolves the specific growth-of-`C_k` obstruction **in the sparse inter-block communication regime**.

What it does **not** do is preserve the closed-loop `p_{k beta}(0,0)` factor for strongly communicating blocks. If `H_beta(B)` is order `k` with a large constant, (5.13) becomes ineffective. Thus this is not yet the uniform twisted-trace inequality needed to finish the conjecture.

# 9. What remains after this run

The new result rules out, exponentially in the number of blocks, finite-cycle traps that decompose into many blocks with sufficiently small one-period cross heat. The hard surviving geometry is therefore more specific:

> a long finite cycle can evade NEW-L53 only if, under every useful coarse partition of its confinement region, it travels through a chain or cluster of blocks whose aggregate one-period heat communication is not small.

In geometric language, the remaining candidate cycles must be **coarsely heat-connected** at time scale `beta`; widely fragmented cycle supports are now strongly suppressed without any fixed-particle-number constant.

Two next attacks are now natural.

1. **Heat-connected animal counting.** Partition a large confinement region into diffusive/subdiffusive cells and show that supports for which every recursive cut has large `beta`-heat communication have much smaller geometric entropy than arbitrary finite subsets. Combine that entropy bound with archived NEW-L47 exact-set heat-content suppression.
2. **Recursive conditional cuts.** Use NEW-L54 during an admissible cyclic exploration. Whenever the unexplored possible trap fragments into many low-communication components, close it with (7.2); otherwise exploit the existence of a quantitatively large heat bridge to force spatial progress. This is closer in spirit to a three-dimensional substitute for the local-escape step in Elboim--Sly.

A full proof still requires controlling the second, heat-connected regime. No monotonicity or chronological-path/cycle identification has been introduced.
