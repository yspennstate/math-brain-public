# 3. The red-particle reduction

Fix a deterministic finite set

\[
A\subset\mathbb Z^3,
\qquad 0\in A,
\qquad |A|=\ell.
\]

Color the labels initially sitting at the vertices of `A` red and all other labels white. Under interchange, the red occupied set evolves exactly as the symmetric exclusion process started from the deterministic configuration `A`.

Write

\[
P:=\pi_\beta.
\]

At time `beta`, the red occupied set is exactly

\[
P(A):=\{P(a):a\in A\}.
\]

If the permutation cycle through `0` has **exact vertex set** `A`, then `P` maps `A` onto itself. Therefore

\[
\boxed{
\{C_P(0)=A\}\subseteq\{P(A)=A\}.
}
\tag{3.1}
\]

This elementary implication is the key. It replaces the earlier determinant argument, which could isolate the root cycle only when it was the unique complete cycle in the test set, by an exclusion event that is insensitive to how many unrelated permutation cycles occur elsewhere.

Let

\[
p_\beta(x,y)
:=\mathbb P_x(X_\beta=y)
\]

be the one-particle continuous-time simple-random-walk kernel with the same convention as the interchange process: every nearest-neighbor edge rings at rate one. Put

\[
q_\beta:=p_\beta(0,0).
\tag{3.2}
\]

For the red exclusion process,

\[
\mathbb E^A\eta_\beta(x)
=
\sum_{a\in A}p_\beta(a,x).
\tag{3.3}
\]

By symmetry, the semigroup property and Cauchy--Schwarz,

\[
p_\beta(a,x)
\le
\sqrt{p_\beta(a,a)p_\beta(x,x)}
=q_\beta
\tag{3.4}
\]

on the transitive lattice. Hence

\[
\mathbb E^A\eta_\beta(x)
\le \ell q_\beta.
\tag{3.5}
\]

# 4. NEW-L44 — exact-set root-cycle bound from exclusion negative dependence

## Theorem NEW-L44 — PROVED

For every finite deterministic `A subset Z^3` with `0 in A` and `|A|=ell`,

\[
\boxed{
\mathbb P\bigl(C_{\pi_\beta}(0)=A\bigr)
\le
(\ell q_\beta)^\ell.
}
\tag{4.1}
\]

### Proof

By (3.1),

\[
\mathbb P(C_P(0)=A)
\le
\mathbb P(P(A)=A).
\]

The event `P(A)=A` says precisely that every site of `A` is occupied by a red particle at time `beta`. Since there are exactly `ell` red particles, requiring all `ell` sites in `A` to be red is equivalent to return of the red occupied set to `A`.

Borcea--Brändén--Liggett negative association for symmetric exclusion started from deterministic `A` gives

\[
\mathbb P(P(A)=A)
\le
\prod_{x\in A}\mathbb P^A(\eta_\beta(x)=1).
\]

Using (3.3)--(3.5), every factor is at most `ell q_beta`, so

\[
\mathbb P(C_P(0)=A)
\le
(\ell q_\beta)^\ell.
\]

This proves (4.1). `square`

### Remarks

1. The bound is useful when `ell q_beta<1`; otherwise it remains correct but can exceed one.
2. No permutation-cycle independence is asserted. The negative dependence belongs to the red **exclusion occupancy field**, an exact projection of the interchange process.
3. Unrelated complete cycles, mediator labels, and all cyclic dependencies are allowed. The event `C_P(0)=A` is bounded only through the necessary invariant-set event `P(A)=A`.

# 5. NEW-L45 — full root-cycle confinement in any small diffusive-volume set

Let `S subset Z^3` be a deterministic finite set containing `0`, and write

\[
s:=|S|.
\]

The events `{C_P(0)=A}` are disjoint as `A` ranges over finite subsets of `S` containing `0`. Hence NEW-L44 gives

\[
\mathbb P(C_P(0)\subseteq S)
\le
\sum_{\ell=1}^{s}
\binom{s-1}{\ell-1}
(\ell q_\beta)^\ell.
\tag{5.1}
\]

For `ell>=2`, use

\[
\binom{s-1}{\ell-1}
\le
\left(\frac{es}{\ell-1}\right)^{\ell-1}
\]

and

\[
\left(\frac{\ell}{\ell-1}\right)^{\ell-1}\le e.
\]

It follows that

\[
\binom{s-1}{\ell-1}(\ell q_\beta)^\ell
\le
q_\beta\,\ell\,(e^2s q_\beta)^{\ell-1}.
\tag{5.2}
\]

The same right-hand form gives the singleton term at `ell=1`. Therefore, whenever

\[
a:=e^2s q_\beta<1,
\]

we may extend the finite sum to infinity and obtain

\[
\boxed{
\mathbb P(C_P(0)\subseteq S)
\le
\frac{q_\beta}{(1-e^2s q_\beta)^2}.
}
\tag{5.3}
\]

This proves:

## Theorem NEW-L45 — PROVED

For every deterministic finite `S subset Z^3` containing `0`, if

\[
e^2|S|p_\beta(0,0)<1,
\]

then

\[
\boxed{
\mathbb P\bigl(C_{\pi_\beta}(0)\subseteq S\bigr)
\le
\frac{p_\beta(0,0)}
{\bigl(1-e^2|S|p_\beta(0,0)\bigr)^2}.
}
\tag{5.4}
\]

In particular, if

\[
e^2|S|p_\beta(0,0)\le\frac12,
\]

then

\[
\boxed{
\mathbb P(C_{\pi_\beta}(0)\subseteq S)
\le 4p_\beta(0,0).
}
\tag{5.5}
\]

This is a bound for the **actual root permutation cycle**, with no condition that it be the only complete cycle in `S`.

# 6. Consequence in d=3: exact diffusive-volume confinement is O(beta^{-3/2})

For the rate-one-per-nearest-neighbor-edge walk on `Z^3`, the local central limit theorem gives

\[
q_\beta=p_\beta(0,0)
=
(4\pi\beta)^{-3/2}(1+o(1)).
\tag{6.1}
\]

Thus there are absolute constants `c,C,beta_1>0` such that for every `beta>=beta_1` and every deterministic finite `S` containing `0` with

\[
|S|\le c\beta^{3/2},
\tag{6.2}
\]

we have

\[
\boxed{
\mathbb P\bigl(C_{\pi_\beta}(0)\subseteq S\bigr)
\le C\beta^{-3/2}.
}
\tag{6.3}
\]

This reaches the **full diffusive volume scale** `beta^{3/2}`. It materially improves the previous archived deterministic-ball result `NEW-L37`, which gave the same `O(beta^{-3/2})` probability only for subdiffusive radii `beta^{1/2-epsilon}` after choosing a fixed tagged-particle order depending on `epsilon`.

For example, for any fixed norm and a sufficiently small fixed `rho>0`, the ball

\[
B_{\rho\sqrt\beta}
\]

has volume at most `c beta^{3/2}`, and therefore

\[
\boxed{
\mathbb P\left(
C_{\pi_\beta}(0)
\subseteq B_{\rho\sqrt\beta}
\right)
\le C\beta^{-3/2}.
}
\tag{6.4}
\]

Thus any finite root cycle carrying non-negligible probability at large `beta` must escape every sufficiently small fixed-multiple diffusive ball. This is a stronger spatial obstruction than previously archived.

### Important limitation

The constant `rho` in (6.4) must be sufficiently small for this argument. NEW-L45 does not control a set whose volume is an arbitrarily large multiple of `beta^{3/2}`, and it does not rule out a finite cycle that wanders through many diffusive cells before closing.

# 7. NEW-L46 — conditional strongly-Rayleigh confinement after admissible no-peeking exposure

The exclusion argument also survives the finite adaptive no-peeking framework archived in `NEW-L28`.

Work first on a finite graph. Condition on an admissible finite exploration history `F` of edge-time Poisson regions. After conditioning:

1. revealed Poisson marks are deterministic transpositions;
2. unrevealed edge-time regions carry independent Poisson processes with the original rates;
3. a chosen initial red set `A` evolves by a composition of symmetric exclusion evolutions on unrevealed edge-time pieces and deterministic coordinate transpositions.

A deterministic occupied set is strongly Rayleigh. Borcea--Brändén--Liggett Proposition 5.1 proves preservation under every symmetric exclusion semigroup; their single-edge proof is the partial-symmetrization operation, and Trotter products give simultaneous edges. A deterministic transposition merely permutes variables in the generating polynomial and therefore preserves real stability. Time-dependent active edge sets are obtained by finite time partitions and weak limits. Consequently, conditional on every admissible finite history `F`, the final red occupied-set law remains strongly Rayleigh and hence negatively associated.

Let

\[
K^\mathscr F(a,x)
:=\mathbb P(P(a)=x\mid\mathscr F)
\tag{7.1}
\]

be the conditional one-particle kernel. Let `S` be `F`-measurable, finite, with an anchor `u in S`, and put

\[
\alpha_S^\mathscr F
:=
\sup_{a,x\in S}K^\mathscr F(a,x).
\tag{7.2}
\]

For a fixed `F`-measurable set `A subset S`, `u in A`, `|A|=ell`, conditional negative association gives

\[
\mathbb P(C_P(u)=A\mid\mathscr F)
\le
\mathbb P(P(A)=A\mid\mathscr F)
\le
\prod_{x\in A}
\sum_{a\in A}K^\mathscr F(a,x)
\le
(\ell\alpha_S^\mathscr F)^\ell.
\tag{7.3}
\]

Summing over `A subset S` exactly as in Section 5 gives:

## Theorem NEW-L46 — PROVED in the finite admissible-exploration framework

If

\[
e^2|S|\alpha_S^\mathscr F<1,
\]

then almost surely in the admissible exploration history,

\[
\boxed{
\mathbb P(C_P(u)\subseteq S\mid\mathscr F)
\le
\frac{\alpha_S^\mathscr F}
{(1-e^2|S|\alpha_S^\mathscr F)^2}.
}
\tag{7.4}
\]

This is the conditional analogue of NEW-L45.

### Fresh buffered corollary

Archived `NEW-L26` provides the following setting. Put a finite test block `S` inside a buffer `U`, expose arbitrary exterior clocks while leaving clocks incident to `U` fresh, and let

\[
b=\operatorname{dist}(S,U^c),
\qquad
\varepsilon_{\beta,b}
=
\sup_{x\in S}\mathbb P_x(\tau_{U^c}\le\beta).
\]

Then uniformly over the allowed exterior history,

\[
K^\mathscr F(a,x)
\le
p_\beta(a,x)+\varepsilon_{\beta,b}
\le
q_\beta+\varepsilon_{\beta,b}
\qquad(a,x\in S).
\tag{7.5}
\]

Choose a logarithmically enlarged diffusive buffer

\[
b=A\sqrt{\beta\log\beta}
\]

with `A` sufficiently large. The standard random-walk deviation estimate gives

\[
\varepsilon_{\beta,b}=O(\beta^{-3/2}),
\]

so

\[
\alpha_S^\mathscr F=O(\beta^{-3/2})
\tag{7.6}
\]

uniformly in the admissible exterior history. Therefore there are fixed `c,C>0` such that for all large `beta`, whenever

\[
|S|\le c\beta^{3/2},
\]

we have the quenched full-cycle estimate

\[
\boxed{
\sup_{\text{admissible exterior histories}}
\mathbb P(C_P(u)\subseteq S\mid\mathscr F)
\le
C\beta^{-3/2}.
}
\tag{7.7}
\]

This removes the **unique-complete-cycle condition** from the earlier archived local anchor estimate. It is the main conditional improvement of this run.

### Scope of NEW-L46

The theorem is stated for the finite admissible no-peeking framework already archived in NEW-L28. Passing an arbitrary infinite adaptive exploration to a limit would require a separate localization/tightness argument. The fresh-block corollary only claims the finite/local form needed by a finite-stage multiscale exploration.

# 8. Why this does not yet prove the full conjecture

A tempting next step would be to sum NEW-L44 over **all** finite sets `A` containing the origin. That does not work. The invariant-set upper bound deliberately forgets that `A` must be a *single* permutation cycle.

For example, if `A={0,x}` with `|x|` very large compared with `sqrt(beta)`, then

\[
\mathbb P(P(A)=A)
\]

has a contribution where both red particles return close to their own starting sites. The negative-association bound tends to approximately

\[
q_\beta^2
\]

as `|x|` tends to infinity. Summing this crude invariant-set bound over infinitely many choices of `x` diverges, even though the true probability that `0` and a very distant `x` form the same two-cycle is tiny.

So the new argument controls **local volume** extremely well but loses the connectedness/single-cycle requirement at large spatial separation. This is a real obstruction, not a proof artifact that can be removed by simply summing (4.1).

This also explains how the result fits with `COUNTEREXAMPLE-L43`: cycle connectivity may be assembled by mediator labels outside the final cycle, so connectedness cannot be represented merely by direct chronological contacts among labels in `A`.

# 9. New candidate route: connected exclusion return / Möbius cancellation

The exact next algebraic target is now sharper.

For finite `A`, define the red-set return probability

\[
R_\beta(A)
:=
\mathbb P(P(A)=A).
\tag{9.1}
\]

NEW-L44 uses only

\[
\mathbb P(C_0=A)\le R_\beta(A),
\]

which is too crude for widely separated `A` because `R_beta(A)` includes configurations in which `A` decomposes into many independent permutation cycles.

The needed object is a **connected part** of the set-return kernel which cancels those disconnected returns. There are two compatible ways to search for it:

1. a Möbius/cluster expansion over partitions of `A`, extracting the contribution in which the restriction of `P` to `A` is one cycle;
2. the already archived diagonal determinant cluster hierarchy, now combined with strong-Rayleigh inequalities to control the absolute size of higher connected corrections.

A successful estimate of the schematic form

\[
\mathbb P(C_0=A)
\le
\text{connected kernel weight}(A)
\]

with a tree-graph bound would be valuable because spatially separated vertices would then have to be linked by heat-kernel factors rather than each paying only its local return probability `q_beta`.

In `d=3`, a summable tree or loop weight carrying one net factor on the order of `beta^{-3/2}` could plausibly yield

\[
\sum_{A\ni0,\,A\text{ finite}}
\mathbb P(C_0=A)<1
\]

for large `beta`, which would prove the target. No such connected bound is proved in this report.

A geometric version of the same next step is to tile space into small diffusive-volume cells. NEW-L45 says closure inside one cell costs `O(beta^{-3/2})`; NEW-L46 says this remains true in a fresh cell after admissible exterior exposure. One must then prove that a finite cycle traversing many cells pays a summable inter-cell return/recruitment cost. The mediator counterexample rules out charging only direct same-cycle chronological contacts, so any such multiscale proof must count the mediator structure as well.
