# 3. NEW-L80 — fragmentation-sensitive one-period heat leakage

NEW-L77 used one global Riesz rearrangement and therefore discarded whether `A` is one diffusive cluster or many mutually separated clusters. The present step retains that information.

Fix the constants from the near-diagonal heat-kernel lower bound used in NEW-L77. Thus for all sufficiently large `beta` there are absolute `a,c_0>0` such that

\[
|z|_2\le a\sqrt\beta
\quad\Longrightarrow\quad
p_\beta(0,z)\ge c_0\beta^{-3/2}.
\tag{3.1}
\]

As in NEW-L77, put

\[
r:=a\sqrt\beta/4,
\]

and for `x in Z^3` write `Q_x=x+[-1/2,1/2)^3`. For a finite `A`, let

\[
\Omega_A=\bigcup_{x\in A}Q_x.
\]

After increasing the absolute lower threshold on `beta`, if `u in Q_x`, `v in Q_y`, and `|u-v|_2<=r`, then `|x-y|_2<=a\sqrt\beta`, so

\[
\mu_\beta(A)
\ge
c\beta^{-3/2} I_r(\Omega_A),
\qquad
I_r(\Omega):=
\int_\Omega\int_{\Omega^c}1_{\{|u-v|_2\le r\}}\,dv\,du.
\tag{3.2}
\]

## 3.1 Canonical diffusive-connectivity components

Define a graph on `A` by connecting distinct `x,y in A` whenever

\[
|x-y|_2\le 3r.
\tag{3.3}
\]

Let its connected components be

\[
A_1,\ldots,A_m,
\qquad
n_i:=|A_i|.
\]

If `i!=j`, then every lattice-center pair `x in A_i`, `y in A_j` has `|x-y|_2>3r`. Therefore, once `beta` is large enough that `r>sqrt(3)`, every `u in Q_x`, `v in Q_y` satisfies

\[
|u-v|_2>|x-y|_2-\sqrt3>r.
\tag{3.4}
\]

Thus the compactly supported kernel `1_{|u-v|<=r}` has **zero interaction between different component unions**

\[
\Omega_i:=\bigcup_{x\in A_i}Q_x.
\]

Consequently the nonlocal perimeter is exactly additive:

\[
\boxed{
I_r(\Omega_A)=\sum_{i=1}^m I_r(\Omega_i).
}
\tag{3.5}
\]

To check the direction carefully: for `u in Omega_i`, replacing `Omega_A^c` by `Omega_i^c` only adds the other `Omega_j`; by (3.4) all those added pairs have kernel value zero, so the integral is unchanged.

## 3.2 Apply nonlocal isoperimetry componentwise

The radial-kernel rearrangement calculation from NEW-L77 applies separately to each `Omega_i` of volume `n_i`:

\[
I_r(\Omega_i)
\ge
c\min\{n_i r^3,n_i^{2/3}r^4\}.
\tag{3.6}
\]

Insert `r asymp sqrt(beta)` into (3.2), (3.5), (3.6). This proves:

### Theorem NEW-L80 — PROVED

There are absolute `c>0`, `beta_0<infinity` such that for every `beta>=beta_0` and every finite nonempty `A subset Z^3`, if `A_1,...,A_m` are its connected components for the diffusive-range graph (3.3), then

\[
\boxed{
\mu_\beta(A)
\ge
c\sum_{i=1}^m
\min\{n_i,\sqrt\beta\,n_i^{2/3}\}.
}
\tag{3.7}
\]

Define the fragmentation profile

\[
\Phi_\beta(A)
:=
\sum_{i=1}^m
\min\{n_i,\sqrt\beta\,n_i^{2/3}\}.
\tag{3.8}
\]

Then simply

\[
\boxed{\mu_\beta(A)\ge c\Phi_\beta(A).}
\tag{3.9}
\]

NEW-L77 is recovered after forgetting the component profile. NEW-L80 is strictly stronger for a set consisting of several well-separated macroscopic pieces.

# 4. NEW-L81 — exact-support penalty with fragmentation gain

Combining NEW-L80 with the already proved strong-Rayleigh invariant-set estimate gives immediately:

### Theorem NEW-L81 — PROVED

For every sufficiently large `beta`, every deterministic finite nonempty `A subset Z^3`, and every `u in A`,

\[
\boxed{
\mathbb P(C_{\pi_\beta}(u)=A)
\le
\exp\{-c\Phi_\beta(A)\}.
}
\tag{4.1}
\]

The same bound holds for `P(pi_beta(A)=A)`.

This retains an explicit cost from every mutually diffusive-separated component rather than collapsing the support to its total volume.

## 4.1 Maximum-component corollary

Let

\[
M_\beta(A):=\max_i n_i.
\]

For every `n_i<=M`,

\[
\min\{n_i,\sqrt\beta n_i^{2/3}\}
=
n_i\min\{1,\sqrt\beta n_i^{-1/3}\}
\ge
n_i\min\{1,\sqrt\beta M^{-1/3}\}.
\]

Summing gives

\[
\Phi_\beta(A)
\ge
|A|\min\{1,\sqrt\beta M_\beta(A)^{-1/3}\}.
\tag{4.2}
\]

Hence

\[
\boxed{
\mathbb P(C_{\pi_\beta}(u)=A)
\le
\exp\left\{
-c|A|\min\bigl(1,\sqrt\beta M_\beta(A)^{-1/3}\bigr)
\right\}.
}
\tag{4.3}
\]

In particular, if every diffusive component of `A` has size at most `K beta^{3/2}`, then

\[
\boxed{
\mathbb P(C_{\pi_\beta}(u)=A)
\le
\exp\{-cK^{-1/3}|A|\}.
}
\tag{4.4}
\]

So **any fixed support fragmented into at-most-`K`-diffusive-volume pieces has a true volume-order closure penalty**, even when its total volume is arbitrarily large.

This is stronger than the global NEW-L78 large-volume penalty `exp(-c sqrt(beta) n^{2/3})` for fragmented sets.

# 5. NEW-L82 — inverse theorem: low leakage forces giant diffusive clusters

NEW-L80 can be inverted into a deterministic structure theorem.

Fix `eta in (0,1]` and set

\[
M_\eta:=\beta^{3/2}\eta^{-3}.
\tag{5.1}
\]

Let

\[
S_\eta(A)
:=
\sum_{i:n_i\le M_\eta} n_i
\]

be the mass lying in diffusive-connectivity components no larger than `M_eta`.

For `n_i<=M_eta`,

\[
\sqrt\beta n_i^{-1/3}
\ge
\sqrt\beta M_\eta^{-1/3}
=\eta.
\]

Therefore each such component contributes at least `eta n_i` to `Phi_beta(A)`. NEW-L80 yields

\[
\boxed{
\mu_\beta(A)\ge c\eta S_\eta(A).
}
\tag{5.2}
\]

Equivalently, if

\[
\mu_\beta(A)\le\delta |A|,
\tag{5.3}
\]

then

\[
\boxed{
\frac{S_\eta(A)}{|A|}
\le
C\frac\delta\eta.
}
\tag{5.4}
\]

Choosing `eta=sqrt(delta)` gives the transparent form

\[
\boxed{
\mu_\beta(A)\le\delta|A|
\quad\Longrightarrow\quad
\text{all but at most }C\sqrt\delta\text{ of the mass lies in components of size }
>\beta^{3/2}\delta^{-3/2}.
}
\tag{5.5}
\]

Thus a support can have anomalously small one-period heat leakage only if almost all of its mass is swallowed by **enormous diffusive-connectivity components**. A dust of many moderate diffusive chunks cannot be heat-stable.

This is a deterministic geometric statement, not a probabilistic typicality assertion about the unknown final cycle.

# 6. NEW-L83 — fresh-slab instability sees the full fragmentation profile

Return to the independent-slab setup of NEW-L76. Let `P,R` be independent time-`beta` interchange permutations, `Q=R o P`, and on `{L_P(0)<infinity}` write

\[
C=C_P(0),\qquad L=|C|.
\]

After conditioning on the first slab, `C` is deterministic relative to the fresh second slab. Therefore NEW-L80 applies directly to the second-slab leakage of this random first-slab support.

NEW-L76 and NEW-L80 give:

### Theorem NEW-L83 — PROVED

\[
\boxed{
\mathbb P\bigl(
L_P(0)<\infty,\ C_{R\circ P}(0)\not\subseteq C_P(0)
\bigr)
\ge
c\,\mathbb E\left[
1_{\{L_P(0)<\infty\}}
\frac{\Phi_\beta(C_P(0))}{L_P(0)}
\right].
}
\tag{6.1}
\]

In particular, from (4.2), for every deterministic `M>=1`,

\[
\boxed{
\mathbb P\bigl(
L_P<\infty,\ C_{R\circ P}(0)\not\subseteq C_P(0)
\bigr)
\ge
c\min\{1,\sqrt\beta M^{-1/3}\}
\,\mathbb P\bigl(
L_P<\infty,\ M_\beta(C_P(0))\le M
\bigr).
}
\tag{6.2}
\]

Taking `M=K beta^{3/2}` gives

\[
\boxed{
\mathbb P\bigl(
L_P<\infty,\ C_{R\circ P}(0)\not\subseteq C_P(0)
\bigr)
\ge
cK^{-1/3}
\mathbb P\bigl(
L_P<\infty,\ M_\beta(C_P(0))\le K\beta^{3/2}
\bigr).
}
\tag{6.3}
\]

So if a finite first-slab cycle is assembled only from components of at most a fixed multiple of diffusive volume, an independent extra slab has a uniformly positive probability (after root averaging) to force the new root cycle outside the old support.

No cycle-length monotonicity is asserted: the new cycle may simultaneously lose old vertices.

# 7. Why this matters and what still blocks the full theorem

The previous checkpoint had a global support penalty. NEW-L80–83 identify a sharper structural fork for a hypothetical all-finite phase:

1. **Fragmented finite supports.** If the final finite support breaks into many pieces whose diffusive-connectivity components are at most `K beta^{3/2}`, then exact closure pays a volume-order penalty `exp(-cK^{-1/3}|A|)`, and an independent fresh slab changes the support with probability bounded below by a constant times `K^{-1/3}`.
2. **Heat-stable finite supports.** If leakage per vertex is very small, NEW-L82 says almost all mass must lie in components much larger than diffusive volume. Thus any putative stable finite-cycle phase is forced toward gigantic `sqrt(beta)`-connected clusters rather than a cloud of separated mesoscopic islands.

This is useful because the earlier all-finite Fejér/capacity checkpoints forced the cycle to be spatially spread, while NEW-L82 says low heat leakage forces that spread to be mediated by very large diffusive-connected pieces. The remaining proof problem is to show that such enormous pieces cannot simultaneously satisfy the primitive one-cycle condition at all large prescribed `beta`, or to turn the fresh-slab support changes into irreversible progress of a genuine Lyapunov quantity.

The present theorem still does **not** solve the entropy problem by itself. Even the volume-order bound (4.4) is for a fixed deterministic support. Summing over all spatially arbitrary supports remains invalid because the invariant-set relaxation forgets the primitive-return/mediator structure. The earlier explicit mediator counterexample remains relevant.

### Next attack

The highest-value next step is now a two-case no-peeking exploration theorem:

* stop when the current candidate trap fragments into moderate diffusive components, and use the conditional/fresh-slab leakage penalty;
* otherwise exploit the forced giant `sqrt(beta)`-connected component to build a controlled-entropy chain of diffusive boxes and combine it with the previously proved mapping-arrow/Fejér bounds.

A second route is to iterate (6.1) while tracking Green capacity or a low-frequency cycle form factor rather than raw cycle size. Raw size is unusable because cycle membership is nonmonotone under added time.
