# 4. NEW-L98 — exponential-moment random-cut theorem

### Theorem NEW-L98 — PROVED

For every `k>=2`, every deterministic disjoint block family `B`, every `u>=1`, and `n=k-1`,

\[
\boxed{
\mathbf P(\mathcal V(\mathcal B))
\le
\left[
\frac{2}{1+u}
\exp\!\left(
\frac{(u^2-1)\Lambda_\beta(\mathcal B)}{n}
\right)
\right]^n.
}
\tag{4.1}
\]

### Proof

Fix a permutation realization in `V(B)`. Form the block-transition graph of the root cycle: vertices are the visited blocks `1,...,k`, and an undirected pair `{i,j}` is present if at least one root-cycle permutation arrow has endpoints in `B_i` and `B_j`. Because the root cycle visits every block, this graph is connected. Choose a spanning tree `T` by a fixed deterministic tie-breaking rule.

Now independently color the `k` blocks red/blue with fair iid bits. Let `Z` be the number of bichromatic edges of `T`. Conditional on the permutation, `T` is fixed. On a tree, root color together with the edge XORs is a bijective parametrization of all vertex colorings. Therefore the `n=k-1` edge XORs are independent fair bits and

\[
Z\sim\operatorname{Bin}(n,1/2),
\qquad
\mathbf E_\xi u^Z
=\left(\frac{1+u}{2}\right)^n.
\tag{4.2}
\]

For the cut `xi`, let `R_xi` be the union of red blocks and `B_xi` the union of blue blocks, and define the **global** red-to-blue assignment count

\[
N_\xi
=\#\{x\in R_\xi:\pi_\beta(x)\in B_\xi\}.
\]

Every bichromatic tree edge has at least one root-cycle arrow crossing the color cut, so the total number of color-changing arrows on the root cycle is at least `Z`. On a directed cycle, red-to-blue and blue-to-red transitions occur equally often. Hence the root-cycle red-to-blue count is at least `Z/2`, and therefore the global count satisfies

\[
N_\xi\ge Z/2.
\tag{4.3}
\]

Set `t=u^2>=1`. From (4.2)--(4.3), pathwise on `V(B)`,

\[
\mathbf E_\xi t^{N_\xi}
\ge
\mathbf E_\xi u^Z
=\left(\frac{1+u}{2}\right)^n.
\tag{4.4}
\]

For a **fixed** cut `xi`, color the labels initially in `R_xi` red. Their occupied set at time `beta` is symmetric exclusion started from a deterministic set. The already hypothesis-checked strongly-Rayleigh preservation theorem for symmetric exclusion implies negative association of the target-site occupancies `eta_y(beta)`, `y in B_xi`. Since

\[
N_\xi=\sum_{y\in B_\xi}\eta_y(\beta),
\]

negative association and `t>=1` give

\[
\begin{aligned}
\mathbf E_\pi t^{N_\xi}
&=\mathbf E_\pi\prod_{y\in B_\xi}
\left(1+(t-1)\eta_y(\beta)\right)\\
&\le
\prod_{y\in B_\xi}
\left(1+(t-1)\mathbf E\eta_y(\beta)\right)\\
&\le
\exp\{(t-1)\mu_\xi\},
\end{aligned}
\tag{4.5}
\]

where

\[
\mu_\xi
=
\sum_{x\in R_\xi,y\in B_\xi}p_\beta(x,y)
\le\Lambda_\beta(\mathcal B).
\tag{4.6}
\]

Average (4.4) over the interchange realization and use (4.5)--(4.6), uniformly in the fixed coloring:

\[
\mathbf P(\mathcal V)
\left(\frac{1+u}{2}\right)^n
\le
\mathbf E_{\pi,\xi}t^{N_\xi}
\le
\exp\{(u^2-1)\Lambda_\beta\}.
\]

Rearrangement proves (4.1). `square`
