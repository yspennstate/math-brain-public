# Executive result

The sharp bounded-density arbitrary-finite-variance P14 theorem remains **OPEN**:

\[
\boxed{
E[(1-\rho^2)^{-1/2}\mid D]
\le 1+\frac{C_\xi}{D},
\qquad D\ge3.
}
\tag{P14-FULL-FV}
\]

The bounded-density finite-variance high-correlation / anti-alignment edge remains a separate proved `O_\xi(D^{-1})` module.  The open bulk theorem remains

\[
\boxed{R_D:=E[\rho^2\mid D]\le C_\xi/D.}
\tag{P14-QUAD-FV}
\]

The latest P14 report reduced the sharp reveal square to the signed sibling/common-tail quantity

\[
V_{d+1}(P)
=\frac12E\left\|
T_d^P(U,U')+
\frac{UU^\top-U'U'^\top}{d}
\right\|_F^2,
\tag{E0}
\]

where `P` is a frozen rank-`d+1` residual parent, `U,U'` are two iid genuinely fresh sibling directions, and `T_d^P` averages the final null-line projector difference through the **same** `d-1` future original rows.  An averaged bound `E_P V_{d+1}(P)\lesssim_\xi d^{-2}` would imply the sharp reveal square and hence the quadratic theorem.

This run adds three exact results and one route correction.

## `P14-SIBLING-CHECKPOINT-FACTOR-25` — NEW / PROVED

The common future can be stopped at **any** residual rank `r+1`, `1<=r<=d`, without breaking the sibling coupling.  Let `R` be the random rank-`r+1` residual projector produced by the first `d-r` common-future rows.  It is independent of `U,U'` after the frozen parent `P` is fixed.  Put

\[
q_R(u)=\frac{Ru}{\|Ru\|}.
\]

Let

\[
\mathcal E_d^P(u,u')
:=T_d^P(u,u')+
\frac{uu^\top-u'u'^\top}{d}
\]

and define analogously the rank-`r+1` inner sibling error

\[
\mathcal E_r^R(q,q')
:=T_r^R(q,q')+
\frac{qq^\top-q'q'^\top}{r},
\]

where `T_r^R` averages the remaining `r-1` common-future rows inside `R`.

Define the checkpoint normalized-projection frame

\[
A_{r|d}^P(u)
:=E_R[q_R(u)q_R(u)^\top\mid u,P],
\]

and

\[
H_{r|d}^P(u)
:=\frac1rA_{r|d}^P(u)-\frac1d uu^\top.
\]

Then **exactly**

\[
\boxed{
\mathcal E_d^P(u,u')
=
E_R\!\left[
\mathcal E_r^R(q_R(u),q_R(u'))
\mid u,u',P
\right]
-
\left[
H_{r|d}^P(u)-H_{r|d}^P(u')
\right].
}
\tag{E1}
\]

This is a source-faithful multiscale factorization of the signed sibling error.  It keeps all common-future dependence exactly and never declares projected coordinates independent.

At `r=1` the inner error is identically zero, because in a rank-two checkpoint the line perpendicular to a sibling direction has projector `R-qq^T`.  Therefore

\[
\boxed{
V_{d+1}(P)
=
\operatorname{Var}_U
\left(
A_{1|d}^P(U)-\frac1dUU^\top
\right).
}
\tag{E2}
\]

So the original sibling theorem is exactly a **full-future conditional normalized-projection-frame variance theorem**.  This is not a new bound, but it identifies the endpoint object without any inverse determinant or likelihood ratio.

## `P14-HAAR-CHECKPOINT-AFFINE-25` — NEW / PROVED

Suppose, only for calibration, that the rank-`r+1` checkpoint `R` is Haar in `Ran(P)` and independent of fixed `u`.  Then

\[
\boxed{
E_R[q_R(u)q_R(u)^\top]
=
\frac rd\,uu^\top
+
\frac{d-r}{d(d+1)}P.
}
\tag{E3}
\]

Consequently

\[
\boxed{
H_{r|d}^P(u)
=
\frac{d-r}{r d(d+1)}P,
}
\tag{E4}
\]

which is independent of `u`.  Hence the **entire outer checkpoint sibling difference vanishes exactly at every Haar checkpoint rank**, not only at the final rank-two plane.

This gives a multiscale explanation of the Gaussian/Haar cancellation: at every stopping rank, the normalized projection of a fixed sibling into the Haar checkpoint has precisely the affine coefficient `r/d` needed to transport the geometric term.

## `P14-SIBLING-CHECKPOINT-L2-25` — NEW / PROVED

Let

\[
W_{r|d}(P)
:=
\operatorname{Var}_U H_{r|d}^P(U).
\]

For every `epsilon>0`, `(E1)` gives

\[
\boxed{
V_{d+1}(P)
\le
(1+\varepsilon)
E_R V_{r+1}(R)
+
(1+\varepsilon^{-1})W_{r|d}(P).
}
\tag{E5}
\]

In particular

\[
V_{d+1}(P)
\le2E_RV_{r+1}(R)+2W_{r|d}(P).

The inequality is deliberately recorded as a **diagnostic**, not a closure theorem.  Jensen loses the global `d`-scale if the two terms are bounded separately.  The exact identity `(E1)`, not `(E5)`, is therefore the primary object: a sharp proof may have to preserve cancellation between the inner rank-`r` sibling error and the checkpoint-frame term.

## `P14-HAAR-LASTROW-ES-NOGO-25` — NEW / PROVED

The concrete one-future-row Efron--Stein subtarget proposed in the preceding P14 report is **false if interpreted as a uniform small-influence bound before integrating the final rank-three block**.

Work in the exact Gaussian/Haar calibration at residual rank three.  Fix

\[
q=e_1,
\qquad q'=e_2,
\]

and let `V` be Haar on `S^2`.  The last future row leaves the rank-two plane `H=V^\perp`.  Define

\[
\Phi(V)
=
\Lambda_{V^\perp}(e_1)
-
\Lambda_{V^\perp}(e_2)
+
\frac{e_1e_1^\top-e_2e_2^\top}{2}.
\]

Haar common-tail cancellation gives `E\Phi(V)=0`.  Nevertheless

\[
\boxed{
E\|\Phi(V)\|_F^2
=
2\log2-\frac12.
}
\tag{E7}
\]

Thus, for an iid replacement `V'`,

\[
\boxed{
\frac12E\|\Phi(V)-\Phi(V')\|_F^2
=
2\log2-\frac12
\approx0.88629.
}
\tag{E8}
\]

The final-row exchangeable replacement sensitivity is therefore of **constant order even when the final signed expectation is exactly zero**.

This rigorously kills any route that tries to prove the `d^{-2}` sibling theorem by assigning every future row a uniformly small squared replacement influence and summing those influences before the terminal rank-three cancellation is exposed.

The correct replacement architecture must integrate at least the final rank-three block first, or compare conditional **expectations** in a way that retains the exact rank-three cancellation.  Raw samplewise last-row Efron--Stein is miscalibrated.

# 5. Proof of `P14-SIBLING-CHECKPOINT-FACTOR-25`

Fix `1<=r<=d`.

Write the common future rows as

\[
X_1,\ldots,X_{d-1}.
\]

Expose only the first

\[
d-r
\]

of them.  Let `R` denote the residual orthogonal projector inside `Ran(P)` after these rows are imposed.  Under the continuous bounded-density hypotheses all relevant ranks are maximal almost surely, hence

\[
\operatorname{rank}R=r+1.
\]

Because the rows defining `R` are part of the future block, `R` is independent of the sibling rows `U,U'` conditional on `P`.

For a sibling direction `u`, define

\[
q_R(u)=\frac{Ru}{\|Ru\|}.
\tag{5.1}
\]

On the null event `Ru=0`, define the direction arbitrarily; under the source density assumptions it has probability zero.

## 5.1 Why the projection is source-faithful

If the sibling direction came from an original row `X`, then

\[
U=\frac{PX}{\|PX\|}.
\]

Since `R<=P`,

\[
\frac{RU}{\|RU\|}
=
\frac{RX}{\|RX\|}.
\tag{5.2}
\]

Thus, conditional on `R`, the checkpoint sibling direction is exactly the ordinary normalized projection of a genuinely fresh original product row into `R`.  No projected-coordinate iid assumption is introduced.

## 5.2 Remaining tail inside the checkpoint

There remain exactly

\[
r-1
\]

common-future rows.  For unit `q,q' in Ran(R)`, let

\[
T_r^R(q,q')
\]

be the expected final line-projector difference generated by those remaining rows.

Every line surviving all original common-future rows lies in `Ran(R)`.  Its sibling orthogonality constraint against `u` is equivalent to orthogonality against `Ru`, hence against `q_R(u)`.  Therefore conditioning on the checkpoint gives the exact tower identity

\[
\boxed{
T_d^P(u,u')
=
E_R[
T_r^R(q_R(u),q_R(u'))
\mid u,u',P
].
}
\tag{5.3}
\]

Define

\[
\mathcal E_d^P(u,u')
=T_d^P(u,u')+
\frac{uu^\top-u'u'^\top}{d}
\]

and

\[
\mathcal E_r^R(q,q')
=T_r^R(q,q')+
\frac{qq^\top-q'q'^\top}{r}.
\]

Also define

\[
A_{r|d}^P(u)
=E_R[q_R(u)q_R(u)^\top\mid u,P],
\]

\[
H_{r|d}^P(u)
=\frac1rA_{r|d}^P(u)-\frac1d uu^\top.
\]

Using `(5.3)`,

\[
\begin{aligned}
E_R[\mathcal E_r^R(q_R(u),q_R(u'))]
&=T_d^P(u,u')
+\frac1r
\left[
A_{r|d}^P(u)-A_{r|d}^P(u')
\right].
\end{aligned}
\]

Rearranging proves `(E1)`.

## 5.3 Rank-two endpoint

When `r=1`, the checkpoint `R` has rank two and no future rows remain.  The unique line inside `R` perpendicular to unit `q` has projector

\[
R-qq^\top.
\]

Hence

\[
T_1^R(q,q')
=-(qq^\top-q'q'^\top)
\]

and therefore

\[
\boxed{\mathcal E_1^R(q,q')=0.}
\tag{5.4}
\]

Thus

\[
\mathcal E_d^P(u,u')
=-[H_{1|d}^P(u)-H_{1|d}^P(u')].
\]

Taking half the iid sibling square gives `(E2)`.

QED.

# 6. Proof of `P14-HAAR-CHECKPOINT-AFFINE-25`

Let the parent `P` have rank

\[
n=d+1,
\]

and let `R` be Haar of rank

\[
s=r+1
\]

inside `Ran(P)`.  Fix unit `u in Ran(P)` and put

\[
q=Ru/\|Ru\|.
\]

By invariance under the orthogonal stabilizer of `u`,

\[
E[qq^\top]
=\alpha uu^\top+\beta(P-uu^\top)
\tag{6.1}
\]

for scalars `alpha,beta`.

Now

\[
u^\top qq^\top u
=(u\cdot q)^2
=u^\top Ru.
\]

For a Haar rank-`s` projector,

\[
E[u^\top Ru]=s/n=(r+1)/(d+1).
\]

Therefore

\[
\alpha=\frac{r+1}{d+1}.
\]

Taking traces in `(6.1)` gives

\[
\alpha+d\beta=1,
\]

so

\[
\beta
=\frac{d-r}{d(d+1)}.
\]

Finally

\[
\alpha-\beta
=\frac rd.
\]

Hence

\[
E[qq^\top]
=\frac rd uu^\top
+\frac{d-r}{d(d+1)}P,
\]

which is `(E3)`.  Divide by `r` and subtract `uu^T/d` to obtain `(E4)`.

Therefore

\[
H_{r|d}^P(u)-H_{r|d}^P(u')=0
\]

for every fixed pair `u,u'` under a Haar checkpoint.

QED.

# 7. Proof of `P14-SIBLING-CHECKPOINT-L2-25`

Let

\[
A(U,U')
=E_R[
\mathcal E_r^R(q_R(U),q_R(U'))
\mid U,U',P
],
\]

and

\[
B(U,U')
=H_{r|d}^P(U)-H_{r|d}^P(U').
\]

Then `(E1)` says

\[
\mathcal E_d^P=A-B.
\]

For every `epsilon>0`,

\[
\|A-B\|_F^2
\le
(1+\varepsilon)\|A\|_F^2
+(1+\varepsilon^{-1})\|B\|_F^2.
\tag{7.1}
\]

Conditional Jensen gives

\[
E_{U,U'}\|A\|_F^2
\le
E_{R,U,U'}
\|\mathcal E_r^R(q_R(U),q_R(U'))\|_F^2.
\]

By `(5.2)`, conditional on `R`, the directions `q_R(U),q_R(U')` are iid ordinary fresh directions in `R`.  Therefore

\[
E_{U,U'}\|A\|_F^2
\le
2E_RV_{r+1}(R).
\tag{7.2}
\]

Also

\[
\frac12E_{U,U'}\|B\|_F^2
=
\operatorname{Var}_U H_{r|d}^P(U)
=W_{r|d}(P).
\tag{7.3}
\]

Multiply `(7.1)` by `1/2` and use `(7.2)`--`(7.3)` to obtain `(E5)`.  Setting `epsilon=1` gives `(E6)`.

At `r=1`, `(5.4)` gives the exact equality `V_{d+1}=W_{1|d}` instead of the lossy inequality.

QED.

# 8. Proof of `P14-HAAR-LASTROW-ES-NOGO-25`

Work in `R^3`.  Set

\[
q=e_1,
\qquad q'=e_2,
\qquad
G=e_1e_1^\top-e_2e_2^\top.
\]

Let

\[
V=(X,Y,Z)
\]

be Haar on `S^2`, and let

\[
H=V^\perp.
\]

Except on null events where `V` is parallel to a sibling direction,

\[
\Lambda_H(e_1)
\]

is the rank-one projector onto the line spanned by

\[
V\times e_1,
\]

and similarly for `e_2`.

Define the raw sibling difference

\[
D(V)
=\Lambda_H(e_1)-\Lambda_H(e_2).
\]

The exact Haar common-tail formula at child rank `d=2` gives

\[
ED(V)=-G/2.
\]

Thus

\[
\Phi(V)=D(V)+G/2
\]

has mean zero.

## 8.1 Squared line overlap

Let `L_1,L_2` be unit vectors along the two lines.  Then

\[
\|D(V)\|_F^2
=2[1-(L_1\cdot L_2)^2].
\tag{8.1}
\]

The vector identity

\[
(a\times b)\cdot(a\times c)
=(a\cdot a)(b\cdot c)-(a\cdot b)(a\cdot c)
\]

gives

\[
(L_1\cdot L_2)^2
=
\frac{X^2Y^2}{(1-X^2)(1-Y^2)}.
\tag{8.2}
\]

Condition on `Z=z`.  Write

\[
X=\sqrt{1-z^2}\cos\theta,
\qquad
Y=\sqrt{1-z^2}\sin\theta,
\]

with `theta` uniform.  Put

\[
k=1-z^2.
\]

Then the denominator in `(8.2)` is

\[
(1-k\cos^2\theta)(1-k\sin^2\theta)
=z^2+\frac{k^2}{4}\sin^2(2\theta),
\]

while the numerator is the second term alone.  Hence

\[
(L_1\cdot L_2)^2
=1-
\frac{z^2}{z^2+(k^2/4)\sin^2(2\theta)}.
\]

Use the standard elementary integral

\[
\frac1{2\pi}\int_0^{2\pi}
\frac{d\theta}{a+b\sin^2(2\theta)}
=\frac1{\sqrt{a(a+b)}}
\]

for `a>0`.  Since

\[
z^2+\frac{(1-z^2)^2}{4}
=\frac{(1+z^2)^2}{4},
\]

we obtain

\[
E[(L_1\cdot L_2)^2\mid Z=z]
=1-\frac{2|z|}{1+z^2}.
\tag{8.3}
\]

For Haar `S^2`, `Z` is uniform on `[-1,1]`.  Therefore

\[
\begin{aligned}
E(L_1\cdot L_2)^2
&=\int_0^1
\left(1-\frac{2z}{1+z^2}\right)dz\\
&=1-\log2.
\end{aligned}
\tag{8.4}
\]

Substitute into `(8.1)`:

\[
\boxed{
E\|D(V)\|_F^2=2\log2.
}
\tag{8.5}
\]

Because

\[
\|ED(V)\|_F^2
=\|G/2\|_F^2
=1/2,
\]

we conclude

\[
\boxed{
E\|\Phi(V)\|_F^2
=2\log2-1/2.
}
\]

This is `(E7)`.

For iid `V,V'`, the Hilbert-space exchangeable-pair identity gives

\[
\frac12E\|\Phi(V)-\Phi(V')\|_F^2
=\operatorname{Var}\Phi(V)
=2\log2-1/2,
\]

which is `(E8)`.

QED.
