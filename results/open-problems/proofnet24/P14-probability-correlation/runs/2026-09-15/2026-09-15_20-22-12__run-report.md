# 7. `P14-ACG-OPERATOR-27` — PROVED

Let

\[
\Sigma\succ0
\]

be an `r x r` positive-definite matrix.

Let

\[
\theta
\]

be Haar on `S^{r-1}` and define

\[
x
=
\frac{
\Sigma^{-1/2}\theta
}{
\sqrt{\theta^\top\Sigma^{-1}\theta}
}.
\tag{7.1}
\]

Then

\[
\boxed{
\left\|
E[xx^\top]
\right\|_{\rm op}
\le
4\,
\frac{
\lambda_{\max}(\Sigma^{-1})
}{
\operatorname{tr}(\Sigma^{-1})
}.
}
\tag{7.2}
\]

Consequently,

\[
\boxed{
\left\|
E[xx^\top]
\right\|_{\rm op}
\le
4\,
\frac{
\operatorname{tr}\Sigma
}{
r^2\lambda_{\min}\Sigma
}.
}
\tag{7.3}
\]

This is an elementary angular-central-Gaussian operator bound.

## Proof

Diagonalize

\[
A=\Sigma^{-1}
=
\operatorname{diag}(a_1,\ldots,a_r),
\qquad
a_i>0.
\]

Write

\[
a_*=\max_i a_i,
\qquad
T=\sum_i a_i.
\]

Using

\[
\theta
\stackrel d=
\frac g{\|g\|},
\qquad
g_i\stackrel{\rm iid}\sim N(0,1),
\]

the common factor `||g||` cancels and

\[
E[xx^\top]
\]

is diagonal in the eigenbasis of `A`, with diagonal entries

\[
k_i
=
E
\frac{
a_i g_i^2
}{
\sum_j a_jg_j^2
}.
\tag{7.4}
\]

If

\[
a_*/T\ge1/4,
\]

then trivially

\[
k_i\le1
\le
4a_*/T.
\tag{7.5}
\]

Assume now

\[
a_*/T<1/4.
\]

For fixed `i`, put

\[
S_i
=
\sum_{j\ne i}a_jg_j^2,
\qquad
T_i
=
T-a_i.
\]

Then

\[
T_i\ge\frac34T
\]

and

\[
\max_{j\ne i}a_j
\le
a_*
<
\frac T4
\le
\frac{T_i}{3}.
\tag{7.6}
\]

Since the denominator in `(7.4)` dominates `S_i`,

\[
k_i
\le
a_i E[g_i^2]\,E[S_i^{-1}]
=
a_iE[S_i^{-1}].
\tag{7.7}
\]

Normalize

\[
b_j=a_j/T_i
\quad(j\ne i).
\]

Then

\[
\sum b_j=1,
\qquad
\max b_j\le1/3.
\]

The Laplace formula gives

\[
E\left[
\left(
\sum b_jg_j^2
\right)^{-1}
\right]
=
\int_0^\infty
\prod_j
(1+2tb_j)^{-1/2}
\,dt.
\tag{7.8}
\]

Among vectors `b` with sum one and each coordinate at most `1/3`, the vector

\[
(1/3,1/3,1/3,0,\ldots)
\]

majorizes every other such vector. Since

\[
x\mapsto\log(1+2tx)
\]

is concave,

\[
\prod_j(1+2tb_j)
\ge
(1+2t/3)^3.
\tag{7.9}
\]

Therefore

\[
E\left[
\left(
\sum b_jg_j^2
\right)^{-1}
\right]
\le
\int_0^\infty
(1+2t/3)^{-3/2}\,dt
=
3.
\]

Scaling back,

\[
E[S_i^{-1}]
\le
\frac3{T_i}.
\]

Hence

\[
k_i
\le
\frac{3a_i}{T_i}
\le
\frac{4a_*}{T}.
\]

Together with `(7.5)` this proves `(7.2)`.

Finally,

\[
\operatorname{tr}(\Sigma^{-1})
\ge
\frac{r^2}{\operatorname{tr}\Sigma}
\]

by Cauchy--Schwarz, while

\[
\lambda_{\max}(\Sigma^{-1})
=
\frac1{\lambda_{\min}\Sigma}.
\]

This gives `(7.3)`.
