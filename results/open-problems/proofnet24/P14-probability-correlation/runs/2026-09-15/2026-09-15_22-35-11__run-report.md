# 5. New primary source: finite-variance intermediate singular values

A current literature search found a directly relevant 2026 preprint not used in earlier P14 runs:

**Achintya Raya Polavarapu and Manuel Fernandez V**, *Intermediate Singular Values of Random Matrices under Second-Moment and Anti-Concentration Assumptions*, arXiv:2608.30722, submitted 2026-08-31.

Its stated square-matrix theorem is:

Let `M=(xi_ij)` be an `n x n` random matrix with independent real entries satisfying

\[
E\xi_{ij}=0,
\qquad
E\xi_{ij}^2=1,
\qquad
\sup_zP(|\xi_{ij}-z|<a)\le b
\]

for fixed `a>0`, `b<1`. For each fixed `delta in (0,1)` there are `c,C>0`, depending only on `a,b,delta`, such that

\[
\boxed{
P\left\{
 s_{n+1-l}(M)>Ct\frac l{\sqrt n}
\right\}
\le
\exp[-c\min\{tl,n\}]
}
\]

for every `t>=1` and `1<=l<=(1-delta)n`.

No moment beyond variance is assumed.

The P14 scalar density hypothesis supplies its anti-concentration assumption. If `||f_xi||_infinity<=K`, choose

\[
a_0=(4K)^{-1}.
\]

Then for every `z`,

\[
P(|\xi-z|<a_0)\le 2Ka_0=1/2.
\]

Thus the theorem applies with constants depending only on `K`.

The paper's abstract also records a rectangular analogue, but **this run does not need to import it**. The proof below reduces the relevant tall matrix to the square theorem by adding two independent source columns.

# 6. Exact deleted-column regression identity

## `P14-DELETEDCOLUMN-COHERENCE-29` — PROVED

Put

\[
p=m-3.
\]

Let

\[
A\in\mathbb R^{p\times(p+3)}
\]

have iid source entries, and let

\[
R=I-A^T(AA^T)^{-1}A
\]

be its rank-three kernel projector. Bounded density implies full row rank almost surely.

By coordinate exchangeability,

\[
E\kappa(R)
=(p+3)E R_{11}^2.
\tag{6.1}
\]

Delete column one:

\[
A=[a\;B],
\]

where

\[
a\in\mathbb R^p,
\qquad
B\in\mathbb R^{p\times(p+2)}.
\]

The column `a` is a genuinely fresh iid product vector independent of `B`.

Set

\[
M=BB^T,
\qquad
q=a^TM^{-1}a.
\]

Since

\[
AA^T=M+aa^T,
\]

Sherman–Morrison gives

\[
a^T(AA^T)^{-1}a
=
\frac q{1+q}.
\]

Therefore

\[
\boxed{
R_{11}
=1-a^T(AA^T)^{-1}a
=
\frac1{1+q}.
}
\tag{6.2}
\]

This is exact and source-faithful: the only random vector left after conditioning on `B` is the deleted original product column `a`.

A numerical algebra smoke check with Gaussian matrices at `p=3,5,10` gave agreement between the two sides of `(6.2)` to `3.1e-16`; this is only a diagnostic, not part of the proof.

# 7. Five-dimensional amplified-subspace estimate

## `P14-FIVEDIM-INVERSEGRAM-CAP-29` — PROVED

Condition on `B` and write the eigenvalues of

\[
M=BB^T
\]

in increasing order:

\[
0<\lambda_1\le\cdots\le\lambda_p.
\]

Let `E_5` be the span of eigenvectors for `lambda_1,...,lambda_5`, and write

\[
s=\sqrt{\lambda_5}.
\]

Equivalently, `s` is the fifth-smallest positive singular value of `B^T`.

Because

\[
M^{-1}\succeq s^{-2}P_{E_5},
\]

we have

\[
q=a^TM^{-1}a
\ge s^{-2}\|P_{E_5}a\|^2.
\]

Hence

\[
R_{11}^2
\le
\left(1+\frac{\|P_{E_5}a\|^2}{s^2}\right)^{-2}.
\tag{7.1}
\]

Now use the Livshyts–Paouris–Pivovarov marginal-density theorem on the genuinely fresh product vector `a`. Its five-dimensional orthogonal projection

\[
Z=P_{E_5}a
\]

has joint density bounded by

\[
L_5\le 2^{5/2}K^5.
\tag{7.2}
\]

No independence of the five projected coordinates is asserted or needed.

For `0<s<=1`, split at `||Z||=1`. On the unit ball,

\[
\begin{aligned}
E\left[
\left(1+\|Z\|^2/s^2\right)^{-2};\|Z\|\le1
\right]
&\le
L_5\int_{\|z\|\le1}
\left(1+\|z\|^2/s^2\right)^{-2}dz.
\end{aligned}
\]

In five dimensions, split the radial integral at `r=s`:

- for `0<=r<=s`, the contribution is `O(s^5)<=O(s^4)`;
- for `s<r<=1`, use `(1+r^2/s^2)^(-2)<=s^4/r^4`; the radial measure is `c_5 r^4 dr`, so the contribution is `O(s^4)`.

Outside the unit ball,

\[
\left(1+\|Z\|^2/s^2\right)^{-2}
\le s^4.
\]

Thus

\[
E\left(1+\|Z\|^2/s^2\right)^{-2}
\le C_Ks^4,
\qquad 0<s\le1.
\]

For `s>1`, the expectation is at most one. Combining with `(7.1)`,

\[
\boxed{
E[R_{11}^2\mid B]
\le
\min\{1,C_Ks^4\}.
}
\tag{7.3}
\]

This is the key exponent. Three projected dimensions would only give an `s^3` bound; four give an `s^4 log(1/s)` border; five dimensions give the clean `s^4` gain while using only a fixed-dimensional density ceiling and no higher source moment.

# 8. Square-completion bridge to the fifth positive singular value

## `P14-SQUARECOMPLETION-INTERMEDIATESV-29` — PROVED

Let

\[
N=p+2=m-1
\]

and set

\[
X=B^T\in\mathbb R^{N\times(N-2)}.
\]

Append an independent `N x 2` matrix `C` with iid copies of the **same source law**, and define the square matrix

\[
Y=[X\;C]\in\mathbb R^{N\times N}.
\]

Then

\[
XX^T\preceq YY^T.
\]

Let eigenvalues be ordered increasingly. Since `X` has exactly two zero left-Gram eigenvalues almost surely, its fifth-smallest positive singular value satisfies

\[
(s_5^+(X))^2
=\lambda_7^{\uparrow}(XX^T).
\]

PSD monotonicity gives

\[
\lambda_7^{\uparrow}(XX^T)
\le
\lambda_7^{\uparrow}(YY^T).
\]

The right side is the square of the seventh-smallest singular value of `Y`, i.e.

\[
\boxed{
s_5^+(B^T)
\le s_{N-6}(Y).
}
\tag{8.1}
\]

Apply the Polavarapu–Fernandez theorem to the square matrix `Y` with `l=7` and, say, `delta=1/2`. For all sufficiently large `N`,

\[
P\left\{
s_{N-6}(Y)>C_Kt/\sqrt N
\right\}
\le
\exp[-c_K\min\{t,N\}],
\qquad t\ge1,
\tag{8.2}
\]

where the fixed factor `7` is absorbed into `C_K,c_K`.

We need no fourth moment of `s_{N-6}`. Because `(7.3)` is bounded by one, integrate only the truncated fourth power.

Let

\[
h(u)=\min\{1,C_Ku^4\}.
\]

The region `u<=C_K'/sqrt N` contributes `O_K(N^{-2})`. On the interval from that scale up to the fixed saturation point of `h`, `(8.2)` gives exponential decay in `u sqrt N`. Therefore, after the change of variables `x=u sqrt N`,

\[
\int u^3P\{s_{N-6}(Y)>u\}\,du
\lesssim_K
N^{-2}\int_1^\infty x^3e^{-c_Kx}dx.
\]

The probability of crossing the fixed saturation point is `e^{-c_K sqrt N}`. Hence

\[
\boxed{
E\min\{1,C_K(s_5^+(B^T))^4\}
\le \frac{C_K'}{N^2}.
}
\tag{8.3}
\]

Small dimensions are absorbed by enlarging the constant.

This step is deliberately formulated with a truncated fourth power. Under finite variance there is no justification for assuming an untruncated fourth moment of the matrix singular value, and none is needed.
