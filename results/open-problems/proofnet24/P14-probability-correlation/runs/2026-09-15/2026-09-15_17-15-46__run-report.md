# 2. Exact random objects, conditioning, and dimension regime

Take two \((m-1)\)-row subsets \(S,T\) from the same iid original row pool. Define

\[
D=m-|S\cap T|,
\qquad
A=S\cap T,
\qquad
B=S\setminus T,
\qquad
C=T\setminus S.
\]

Then

\[
|A|=m-D,
\qquad
|B|=|C|=D-1.
\]

Condition **first** on the actual realized original shared rows \(A\).

Let

\[
E_A=\operatorname{span}(A)^\perp,
\qquad
\dim E_A=D,
\]

and choose an isometry

\[
Q_A:\mathbb R^D\to E_A.
\]

For one genuinely fresh original iid-coordinate row \(X\),

\[
Y=Q_A^\top X,
\qquad
EY=0,
\qquad
EYY^\top=I_D.
\]

The coordinates of \(Y\) are generally dependent.

The two private residual matrices

\[
BQ_A,
\qquad
CQ_A
\]

are conditionally independent only because the corresponding **original private row blocks** are disjoint and fresh.

Let their unit null directions be \(v,w\), and put

\[
\rho^2=(v\cdot w)^2.
\]

Define

\[
M_A=E[vv^\top\mid A].
\]

Then conditional independence gives

\[
\boxed{
E[\rho^2\mid A]
=
\operatorname{tr}(M_A^2).
}
\tag{2.1}
\]

The \(D\)-stratified averaged quantity is

\[
\boxed{
R_D
=
E_A\operatorname{tr}(M_A^2).
}
\tag{2.2}
\]

The stronger realized-apex theorem

\[
\operatorname{tr}(M_A^2)\lesssim_\xi D^{-1}
\]

would imply `(T1)` but is stronger than the averaged target.

The exact Haar benchmark is

\[
1-\rho^2
\sim
\operatorname{Beta}\!\left(\frac{D-1}{2},\frac12\right).
\]

# 4. Inherited fresh-frame criterion

For an iid-coordinate original row \(X\in\mathbb R^m\) and a deterministic rank-\(d\) orthoprojector \(P\), define

\[
\mathcal R_\xi(P)
=
E\frac{PXX^\top P}{X^\top PX}.
\]

The preceding canonical run proved, under

\[
E\xi=0,
\qquad
E\xi^2=1,
\qquad
\|f_\xi\|_\infty<\infty,
\]

that

\[
\eta_d^*
=
\sup_{m\ge d,P}
\|d\mathcal R_\xi(P)-P\|_{\rm op}
\longrightarrow0.
\tag{4.1}
\]

It then derived the almost-Haar Hardy recursion

\[
J_d
\le
\frac{d}{d+1-\eta_d^*}J_{d-1}
+
O\!\left(\frac{\eta_d^*}{d^2}\right),
\tag{4.2}
\]

and hence the sufficient condition

\[
\sum_d\frac{\eta_d^*}{d}<\infty
\quad\Longrightarrow\quad
J_D=O_\xi(D^{-1}).
\tag{4.3}
\]

The previous run correctly left `(4.3)` as conditional.

The present theorem shows that the hypothesis in `(4.3)` fails for some fixed smooth bounded-density finite-variance laws.

# 5. Positive contrast: coordinate-projector defects are harmonically summable

Let \(\xi_1,\ldots,\xi_d\) be iid copies of a centered variance-one scalar law, and put

\[
S_d=\sum_{i=1}^d\xi_i^2.
\]

Assume \(S_d>0\) almost surely, as holds in the source bounded-density setting.

For the coordinate rank-\(d\) projector, let

\[
R_d
=
E\frac{XX^\top}{S_d}.
\]

By exchangeability,

\[
(R_d)_{ii}=\frac1d.
\]

All off-diagonal entries are equal; write

\[
\beta_d
=
E\frac{\xi_1\xi_2}{S_d}.
\]

Define

\[
\phi(t)=E e^{-t\xi^2},
\qquad
a(t)=E[\xi e^{-t\xi^2}].
\]

Because

\[
\frac1{S_d}
=
\int_0^\infty e^{-tS_d}\,dt
\]

and

\[
E\frac{|\xi_1\xi_2|}{S_d}\le\frac12,
\]

Fubini is legitimate and gives

\[
\boxed{
\beta_d
=
\int_0^\infty
a(t)^2\phi(t)^{d-2}\,dt
\ge0.
}
\tag{5.1}
\]

The eigenvalues of \(dR_d-I_d\) are

\[
d(d-1)\beta_d
\]

in the all-ones direction and

\[
-d\beta_d
\]

with multiplicity \(d-1\). Hence

\[
\boxed{
\eta_d^{\rm coord}
=
d(d-1)\beta_d.
}
\tag{5.2}
\]

Summing and using Tonelli,

\[
\begin{aligned}
\sum_{d=2}^\infty\frac{\eta_d^{\rm coord}}d
&=
\sum_{d=2}^\infty(d-1)\beta_d
\\
&=
\int_0^\infty
a(t)^2
\sum_{d=2}^\infty(d-1)\phi(t)^{d-2}
\,dt
\\
&=
\boxed{
\int_0^\infty
\frac{a(t)^2}{(1-\phi(t))^2}\,dt.
}
\tag{5.3}
\end{aligned}
\]

It remains to show the integral is finite.

Since \(E\xi^2=1\),

\[
1-\phi(t)\sim t
\qquad(t\downarrow0).
\]

Choose \(t_0>0\) such that

\[
1-\phi(t)\ge t/2,
\qquad
0<t\le t_0.
\tag{5.4}
\]

Because \(E\xi=0\),

\[
a(t)
=
-E[\xi(1-e^{-t\xi^2})].
\]

Let \(\eta\) be an independent copy. Define

\[
J(x,y)
=
\int_0^\infty
\frac{(1-e^{-tx})(1-e^{-ty})}{t^2}\,dt.
\]

If \(0<x\le y\), splitting at \(1/y\) and \(1/x\) gives

\[
J(x,y)
\le
x+x\log(y/x)+x.
\]

Since

\[
2+\log q\le2\sqrt q,
\qquad q\ge1,
\]

\[
\boxed{
J(x,y)\le2\sqrt{xy}.
}
\tag{5.5}
\]

Therefore

\[
\begin{aligned}
\int_0^\infty\frac{a(t)^2}{t^2}\,dt
&\le
E\left[
|\xi\eta|J(\xi^2,\eta^2)
\right]
\\
&\le
2E[\xi^2\eta^2]
=
2.
\end{aligned}
\tag{5.6}
\]

For the large-\(t\) part,

\[
\begin{aligned}
\int_0^\infty a(t)^2\,dt
&\le
E\frac{|\xi\eta|}{\xi^2+\eta^2}
\\
&\le
\frac12.
\end{aligned}
\tag{5.7}
\]

Using `(5.4)` on \((0,t_0]\) and the monotonicity of \(\phi\) on \([t_0,\infty)\), `(5.3)` is finite.

Thus:

## `P14-COORDINATE-FRAME-HARMONIC-23` — PROVED

\[
\boxed{
\sum_{d=2}^{\infty}\frac{\eta_d^{\rm coord}}d<\infty.
}
\tag{5.8}
\]

For a symmetric scalar law,

\[
a(t)\equiv0,
\]

so in fact every coordinate defect is exactly zero.

This makes the counterexample below more informative: it uses a symmetric law, and all of the nonsummable defect comes from tilted deterministic subspaces.

# 6. Construction of a fixed smooth bounded-density law

Fix large numerical constants

\[
K_0\ge100,
\qquad
L\ge1000.
\]

Let

\[
\varepsilon_n=2^{-n-10}.
\]

We recursively choose rapidly increasing amplitudes \(R_n\).

For every scalar coordinate introduce independent symmetric Bernoulli spike variables

\[
\zeta_n\in\{-1,0,1\},
\qquad
P(\zeta_n=\pm1)=p_n/2,
\qquad
P(\zeta_n=0)=1-p_n,
\]

where

\[
\boxed{
p_n=\frac{\varepsilon_n}{R_n^2}.
}
\tag{6.1}
\]

Let all \(\zeta_n\)'s be independent, and let \(G\sim N(0,1)\) be independent. Define

\[
\widetilde\xi
=
G+\sum_{n\ge1}R_n\zeta_n.
\tag{6.2}
\]

Since

\[
\sum_n p_n
\le
\sum_n\varepsilon_n
<\infty,
\]

Borel--Cantelli implies that only finitely many \(\zeta_n\)'s are nonzero almost surely, so `(6.2)` is well-defined.

Moreover,

\[
E\widetilde\xi=0
\]

and

\[
E\widetilde\xi^2
=
1+\sum_n p_nR_n^2
=
1+\sum_n\varepsilon_n
<\infty.
\tag{6.3}
\]

The law is symmetric.

Because \(\widetilde\xi=G+Z\) for a random shift \(Z\), its density is a Gaussian mixture

\[
f_{\widetilde\xi}(x)=E\varphi(x-Z),
\]

hence

\[
\|f_{\widetilde\xi}\|_\infty
\le
(2\pi)^{-1/2},
\]

and all derivatives are bounded mixtures of Gaussian derivatives. Thus

\[
f_{\widetilde\xi}\in C^\infty.
\]

Finally set

\[
\xi
=
\frac{\widetilde\xi}
{\sqrt{E\widetilde\xi^2}}.
\]

Then \(\xi\) is centered, variance one, \(C^\infty\), and bounded-density.

The normalized projection ratio

\[
\frac{PXX^\top P}{X^\top PX}
\]

is invariant under a common scalar rescaling of all coordinates, so all frame defects for \(\xi\) and \(\widetilde\xi\) are identical. We therefore work below with \(\widetilde\xi\).

# 7. Recursive choice of scales

For each \(n\), let

\[
Y_{<n}
=
G+\sum_{j<n}R_j\zeta_j.
\]

This is a fixed symmetric law with finite moments of every order.

Put

\[
\sigma_n^2=EY_{<n}^2,
\qquad
\mu_{4,n}=EY_{<n}^4.
\]

For an average of \(k\) iid copies,

\[
\overline Y_k
=
k^{-1/2}\sum_{j=1}^kY_{<n,j},
\]

the exact fourth-moment formula gives

\[
E\overline Y_k^4
=
3\left(1-\frac1k\right)\sigma_n^4
+
\frac{\mu_{4,n}}k
\le
3\sigma_n^4+\mu_{4,n}.
\tag{7.1}
\]

Therefore there is a finite constant \(Q_n\), depending only on lower levels \(j<n\), such that every raw or \(k\)-averaged lower-level coordinate satisfies

\[
\operatorname{Var}(Z^2)
\le
Q_n\sigma_n^4.
\tag{7.2}
\]

Choose an even integer \(D_n\) larger than the preceding interval endpoint and so large that

\[
C\sqrt{\frac{Q_n}{D_n}}
\le
\frac{\varepsilon_n}{100L},
\tag{7.3}
\]

where \(C\) is the absolute constant used in Section 10 below.

Now choose \(R_n\) so large that, with

\[
U_n=\frac{R_n^2}{4LK_0},
\tag{7.4}
\]

all of the following hold:

\[
U_n\ge4D_n,
\tag{7.5}
\]

\[
\log(U_n/D_n)
\ge
\frac{100L}{\varepsilon_n},
\tag{7.6}
\]

and, for every \(j<n\),

\[
R_j^2p_n
=
R_j^2\frac{\varepsilon_n}{R_n^2}
\le
2^{-(n-j)}
\frac{\varepsilon_j}{10^6}.
\tag{7.7}
\]

This is possible because increasing \(R_n\) decreases \(p_n\) and increases \(U_n\).

Summing `(7.7)` over future levels gives, after the full construction,

\[
\boxed{
R_n^2\sum_{m>n}p_m
\le
\frac{\varepsilon_n}{10^6}.
}
\tag{7.8}
\]

The intervals

\[
I_n=[D_n,U_n]
\]

are disjoint by construction.

# 8. Adversarial rank-\(d\) projector

Fix \(n\), and let \(d\) be any even integer in \(I_n\).

Write

\[
r=d/2
\]

and choose

\[
\boxed{
k
=
\left\lfloor
\frac{R_n^2}{Ld}
\right\rfloor.
}
\tag{8.1}
\]

Because \(d\le U_n\),

\[
\frac{R_n^2}{Ld}\ge4K_0,
\]

so \(k\ge K_0\) and

\[
Ld
\le
\frac{R_n^2}{k}
\le
2Ld.
\tag{8.2}
\]

Take ambient dimension

\[
m=r(1+k).
\]

Choose a rank-\(d\) orthoprojector \(P\) whose orthonormal basis consists of:

- \(r\) singleton coordinate vectors \(e_1,\ldots,e_r\);
- \(r\) disjoint block-average vectors
  \[
  w_i
  =
  k^{-1/2}\sum_{j\in B_i}e_j,
  \qquad
  |B_i|=k,
  \]
  with all \(B_i\)'s disjoint from each other and from the singleton coordinates.

For an iid-coordinate vector \(X\), the projected coordinates in this basis are independent:

\[
A_i\stackrel d=\widetilde\xi,
\qquad
B_i
=
k^{-1/2}\sum_{j=1}^k\widetilde\xi_{ij},
\]

with disjoint original-coordinate supports.

Put

\[
U=\sum_{i=1}^rA_i^2,
\qquad
V=\sum_{i=1}^rB_i^2,
\qquad
H=\frac{V-U}{V+U}.
\tag{8.3}
\]

Because the scalar law is symmetric, the normalized covariance matrix

\[
\mathcal R_{\widetilde\xi}(P)
\]

is diagonal in the displayed basis. Let its common singleton eigenvalue be \(r_A\) and its common block-average eigenvalue be \(r_B\).

Then

\[
r r_A+r r_B=1
\]

and

\[
EH
=
r(r_B-r_A)
=
d r_B-1.
\tag{8.4}
\]

Consequently

\[
\boxed{
\eta_d^*
\ge
|EH|.
}
\tag{8.5}
\]

It remains to show that \(EH\) is of order \(\varepsilon_n/L\) throughout \(I_n\).

# 9. The rare block-spike event

The projector uses

\[
N_A=r
\]

raw scalar slots and

\[
N_B=rk
\]

scalar slots inside block averages.

By `(8.1)`,

\[
N_Bp_n
=
rk\frac{\varepsilon_n}{R_n^2}.
\]

Using \(k\le R_n^2/(Ld)\) and \(k\ge R_n^2/(Ld)-1\), together with \(R_n^2/(Ld)\ge4K_0\),

\[
\boxed{
\frac{\varepsilon_n}{3L}
\le
N_Bp_n
\le
\frac{\varepsilon_n}{2L}.
}
\tag{9.1}
\]

Also,

\[
\boxed{
N_Ap_n
\le
\frac{\varepsilon_n}{8LK_0}.
}
\tag{9.2}
\]

The total number of scalar slots satisfies

\[
N=N_A+N_B\le \frac{R_n^2}{L}.
\]

Thus `(7.8)` gives

\[
\boxed{
N\sum_{m>n}p_m
\le
\frac{\varepsilon_n}{10^6L}.
}
\tag{9.3}
\]

Let \(E_B\) be the event that:

1. exactly one level-\(n\) spike occurs among the \(N_B\) block-average scalar slots;
2. no other level-\(n\) spike occurs anywhere;
3. no level \(m>n\) spike occurs anywhere.

Lower-level spikes \(m<n\) are unrestricted.

Independence of the spike indicators gives

\[
P(E_B)
=
N_Bp_n(1-p_n)^{N-1}
\prod_{m>n}(1-p_m)^N.
\]

Using `(9.1)`--`(9.3)` and taking the fixed constants \(L,K_0\) large,

\[
\boxed{
P(E_B)
\ge
\frac{\varepsilon_n}{4L}.
}
\tag{9.4}
\]

# 10. On \(E_B\), the block energy dominates

Condition on \(E_B\).

The unique affected block coordinate has the form

\[
B_*
=
\pm\frac{R_n}{\sqrt k}
+
R_*,
\]

where \(R_*\) is the normalized average of \(k\) independent lower-level variables \(Y_{<n}\). Hence

\[
ER_*^2=\sigma_n^2.
\]

By Chebyshev and `(8.2)`,

\[
P\left\{
|R_*|>\frac{R_n}{2\sqrt k}
\Bigm|E_B
\right\}
\le
\frac{4k\sigma_n^2}{R_n^2}
\le
\frac{4\sigma_n^2}{Ld}.
\tag{10.1}
\]

On the complementary event,

\[
B_*^2
\ge
\frac{R_n^2}{4k}
\ge
\frac{Ld}{4}.
\tag{10.2}
\]

The raw coordinates contain only lower-level variables on \(E_B\), so

\[
E[U\mid E_B]
=
r\sigma_n^2.
\]

Thus

\[
P\left\{
U>\frac{Ld}{12}
\Bigm|E_B
\right\}
\le
\frac{6\sigma_n^2}{L}.
\tag{10.3}
\]

The variances \(\sigma_n^2\) are uniformly bounded by

\[
1+\sum_j\varepsilon_j<2.
\]

Choose \(L\) once and for all sufficiently large. Combining `(10.1)`--`(10.3)`, with conditional probability at least \(0.95\),

\[
V\ge B_*^2\ge Ld/4,
\qquad
U\le Ld/12.
\]

On this event,

\[
H
=
\frac{V-U}{V+U}
\ge
\frac12.
\]

Since always \(-1\le H\le1\),

\[
\boxed{
E[H\mid E_B]\ge\frac25.
}
\tag{10.4}
\]

# 11. The no-high-spike baseline is nearly balanced

Let \(E_0\) be the event that no spike of level \(m\ge n\) occurs in any scalar slot.

Conditional on \(E_0\), all scalar coordinates are iid copies of the fixed lower-level law \(Y_{<n}\).

The raw and block-average groups have the same second moment:

\[
E[U\mid E_0]
=
E[V\mid E_0]
=
r\sigma_n^2.
\]

By `(7.1)`--`(7.2)`,

\[
\operatorname{Var}(V-U\mid E_0)
\le
C r Q_n\sigma_n^4
\]

and

\[
\operatorname{Var}(U+V\mid E_0)
\le
C r Q_n\sigma_n^4.
\]

On

\[
U+V\ge r\sigma_n^2,
\]

\[
|H|
\le
