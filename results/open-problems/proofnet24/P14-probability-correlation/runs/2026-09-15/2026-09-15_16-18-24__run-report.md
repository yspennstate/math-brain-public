\[

# 5. `P14-FRESH-PROJECTION-TWOSIDED-FRAME-22`

Assume

\[
E\xi=0,
\qquad
E\xi^2=1,
\qquad
\|f_\xi\|_\infty\le K.

For an iid-coordinate \(X\in\mathbb R^m\) and rank-\(d\) orthoprojector \(P\), define

\[
\mathcal R_\xi(P)
=
E\frac{PXX^\top P}{X^\top PX}.
\]

Define the intrinsic defect

\[
\boxed{
\eta_d^*
=
\sup_{\substack{m\ge d\\P^2=P=P^\top\\\operatorname{rank}P=d}}
\|d\mathcal R_\xi(P)-P\|_{\rm op}.
}
\tag{5.1}
\]

## Theorem

\[
\boxed{\eta_d^*\to0.}
\tag{5.2}
\]

### Proof

Fix unit \(z\in\operatorname{Ran}P\). Put

\[
N=(z^\top X)^2,
\qquad
W=X^\top PX.
\]

Then

\[
z^\top\mathcal R_\xi(P)z=E[N/W],
\qquad
N\le W,
\qquad
EN=1.
\]

The previous P14 run proved uniformly over \(m,P,z\):

1. the family \(N\) is uniformly integrable;
2. for every fixed \(\delta>0\),
   \[
   P(|W/d-1|>\delta)\to0.
   \]

The lower frame follows from

\[
E[N/W]
\ge
\frac1{(1+\delta)d}
E[N1_{\{W\le(1+\delta)d\}}],
\]

then UI and the uniform WLLN.

For the upper frame, use the Livshyts–Paouris–Pivovarov marginal-density theorem. The density of \(PX\) on its \(d\)-dimensional range is at most

\[
2^{d/2}K^d.
\]

Let

\[
\bar K=\max\{1,K\},
\qquad
\alpha_K=(16\pi e\bar K^2)^{-1}.
\]

Since

\[
\operatorname{vol}B_2^d(\sqrt{\alpha_Kd})
\le(2\pi e\alpha_K)^{d/2},
\]

\[
\boxed{
P(W<\alpha_Kd)\le2^{-d}.
}
\tag{5.3}
\]

Now split \(E[N/W]\) over

\[
W\ge(1-\delta)d,
\qquad
\alpha_Kd\le W<(1-\delta)d,
\qquad
W<\alpha_Kd.
\]

The three terms are at most respectively

\[
\frac1{(1-\delta)d},
\]

\[
\frac1{\alpha_Kd}
E[N1_{\{W<(1-\delta)d\}}],
\]

and, because \(N/W\le1\),

\[
2^{-d}.
\]

The middle expectation tends to zero uniformly by UI plus the WLLN. Let \(\delta\downarrow0\) diagonally. Thus

\[
\sup_{m,P,z}|dE[N/W]-1|\to0.
\]

Taking the supremum over \(z\) proves `(5.2)`.

Hence for every frozen adaptive residual parent,

\[
\boxed{
\frac{1-\eta_d^*}{d}F
\preceq
S_F
\preceq
\frac{1+\eta_d^*}{d}F.
}
\tag{5.4}
\]

The application is valid because \(F\) corresponds to the original-space projector \(Q_AFQ_A^\top\) and the row used after freezing it is a genuinely fresh original product row.

QED.

# 8. `P14-FRAME-HARDY-RECURRENCE-22`

# 9. `P14-FRAME-HARDY-CRITERION-22`

\[

Then

\[

=

\le

\le

\tag{9.1}

\le

\tag{9.2}

\tag{9.4}

QED.

# 10. Exact sibling common-tail rank-two representation

Freeze a rank-\((d+1)\) ordinary parent \(P\). Let two iid genuinely fresh original rows produce normalized removed directions \(u,u'\), and sibling children

\[
F_u=P-uu^\top,
\qquad
F_{u'}=P-u'u'^\top.
\]

Use the same additional \(d-1\) genuinely fresh future original rows for both sibling tails. Let \(H\) be their two-dimensional orthogonal complement inside the parent.

Then the two final null lines are

\[
H\cap u^\perp,
\qquad
H\cap (u')^\perp.
\]

For fixed rank-two projector \(P_H\),

\[
\boxed{
\Lambda_H(u)
=
P_H
-
\frac{P_Huu^\top P_H}{u^\top P_Hu}.
}
\tag{10.1}
\]

The plane \(H\) is independent of \(u,u'\) after the parent is frozen, and

\[
M_{F_u}=E_H\Lambda_H(u).
\]

Therefore

\[
\boxed{
C_d(F_u)-C_d(F_{u'})
=
E_H[\Lambda_H(u)-\Lambda_H(u')]
+
\frac{uu^\top-u'u'^\top}{d}.
}
\tag{10.2}
\]

If

\[
a=P_Hu,
\qquad
b=P_Hu',
\]

then

\[
\boxed{
\|\Lambda_H(u)-\Lambda_H(u')\|_F^2
=
2\left(
1-\frac{(a\cdot b)^2}{\|a\|^2\|b\|^2}
\right).
}
\tag{10.3}
\]

This is exact. It places the sibling first-difference problem inside the already-developed rank-two cap geometry. It is not yet a bound because the projection denominators are endpoint-critical.
