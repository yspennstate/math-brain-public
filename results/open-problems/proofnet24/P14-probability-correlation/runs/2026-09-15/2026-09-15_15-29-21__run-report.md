## `P14-FRESH-PROJECTION-FRAME-FV-21` — NEW / PROVED

Let \(\xi\) be the fixed centered variance-one scalar row law, and let
\(X=(\xi_1,\ldots,\xi_m)\) have iid coordinates.  For every rank-\(d\) orthogonal projector \(P\) define

\[
\mathcal R_\xi(P)
=
E\left[
\frac{PXX^\top P}{X^\top PX}
\right].
\]

Under the bounded-density P14 hypotheses the denominator is nonzero almost surely.  There is a constant \(c_\xi>0\), depending only on the fixed scalar law, such that uniformly over every ambient dimension \(m\), every \(1\le d\le m\), and every rank-\(d\) orthogonal projector \(P\),

\[
\boxed{
\mathcal R_\xi(P)
\succeq
\frac{c_\xi}{d}P.
}
\tag{0.4}
\]

More strongly, there is a deterministic sequence

\[
\varepsilon_d(\xi)\downarrow0

such that uniformly in \(m\ge d\) and \(P\),

\[
\boxed{
\mathcal R_\xi(P)
\succeq
\frac{1-\varepsilon_d(\xi)}{d}P.

\tag{0.5}

No moment above two is used.  The proof uses only:

## `P14-SUPPORT-COERCIVITY-SHARP-21` — NEW / PROVED

The \(1/d\) order in `(0.6)` is sharp even if the matrix field is trace zero.

Let \(U\) be uniform on the coordinate axes \(e_1,\ldots,e_d\), so \(E UU^\top=I/d\).  Fix a nonzero vector \(h=(h_1,\ldots,h_d)\) with \(\sum h_i=0\).  For \(U=e_i\), define the diagonal trace-zero matrix \(A_i\) by

\[
(A_i)_{ii}=0,
\qquad
(A_i)_{jj}=h_j+\frac{h_i}{d-1}
\quad (j\ne i).
\]

Then \(A_ie_i=0\) and

\[
E\|A_I\|_F^2
=
\frac{d-2}{d-1}\|h\|_2^2,
\]

\[
\|EA_I\|_F^2
=
\left(\frac{d-2}{d-1}\right)^2\|h\|_2^2,
\]

so

\[
\boxed{
\frac{E\|A_I-EA_I\|_F^2}
{E\|A_I\|_F^2}
=
\frac1{d-1}.
}
\tag{0.10}
\]

Therefore no argument using only isotropy of the removed direction and the support condition can replace the Haar-order \(1/d\) influence coefficient by a dimension-free constant.

## `P14-LINEARFORM-UI-21` — PROVED

The family

\[
\{Z_a^2:
m\ge1,\ \|a\|_2=1\}
\]

is uniformly integrable.

### Proof

Fix \(T\ge1\).  Write

\[
\zeta
=
\xi\,1_{\{|\xi|\le T\}}
-
E[\xi\,1_{\{|\xi|\le T\}}],
\]

\[
\eta=\xi-\zeta.
\]

Both are centered.  Put

\[
\delta_T=E\eta^2.
\]

Since \(E\xi^2<\infty\),

\[
\delta_T\to0.
\]

Also

\[
|\zeta|\le2T,
\qquad
E\zeta^2\le1.
\]

For

\[
S_a=\sum a_j\zeta_j,
\qquad
R_a=\sum a_j\eta_j,
\]

we have

\[
Z_a=S_a+R_a,
\]

\[
ER_a^2\le\delta_T.
\]

Independence and centering give the uniform fourth-moment bound

\[
ES_a^4
\le
3+4T^2
=:C_T.
\]

For \(K>0\),

\[
E[Z_a^2\,1_{\{|Z_a|>K\}}]
\le
2E[S_a^2\,1_{\{|Z_a|>K\}}]
+
2ER_a^2.
\]

If \(|Z_a|>K\), then either \(|S_a|>K/2\) or \(|R_a|>K/2\).  Therefore

\[
E[S_a^2\,1_{\{|Z_a|>K\}}]
\le
\frac{4C_T}{K^2}
+
\frac{2\sqrt{C_T\delta_T}}{K}.
\]

Hence

\[
\sup_{m,a}
E[Z_a^2\,1_{\{|Z_a|>K\}}]
\le
\frac{8C_T}{K^2}
+
\frac{4\sqrt{C_T\delta_T}}{K}
+
2\delta_T.
\]

First choose \(T\) so that \(\delta_T\) is small, then \(K\) large.  This proves uniform integrability.

QED.
