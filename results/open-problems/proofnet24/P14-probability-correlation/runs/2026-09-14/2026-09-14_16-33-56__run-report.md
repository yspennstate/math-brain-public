\qquad

\]
Then
\[
q^\top R_Eq
=
\mathbb E\frac ZS,
\qquad
\mathbb EZ=1.
\]

Set
\[
a_k=\sqrt{d_k},
\]
and define
\[
G_k=\{S\le(1+a_k)k\}.

By Markov,
\[
\Pr(G_k^c)
=
\Pr\{|S-k|>a_kk\}
\le
\frac{d_k}{a_k}
=
a_k.

Hence
\[
\mathbb E[Z1_{G_k^c}]
\le

\[
S\le(1+a_k)k.

\[
\begin{aligned}
q^\top R_Eq

# 4. New theorem P14-BULK-MOD — a sharp summable-modulus criterion

### Theorem P14-BULK-MOD — PROVED

Assume one fixed centered variance-one coordinate law, absolutely continuous so that the sequential dimension drops occur almost surely.

Let \(d_k,\omega,\varepsilon_k\) be defined by (2.1), (2.4), (3.1).

Assume
\[
\boxed{
\sum_{k=3}^{\infty}
\frac{\varepsilon_k}{k}
<
\infty.
}
\tag{4.1}
\]

Then there exists a law-dependent finite constant \(C_\xi\) such that, for every ambient dimension \(m\), every deterministic \(D\)-dimensional subspace \(E\), and every \(D\ge3\), if \(D-1\) independent fresh original product rows are intersected sequentially with \(E\), the final random line projector \(P_{\rm fin}\) satisfies
\[
\boxed{
\mathbb E P_{\rm fin}
\preceq
\frac{C_\xi}{D}P_E.
}
\tag{4.2}
\]

Consequently, in the P14 shared-apex geometry, uniformly in every realized full-rank apex \(A\),
\[
\boxed{
M_A
=
\mathbb E[vv^\top\mid A]
\preceq
\frac{C_\xi}{D}I_D,
}
\tag{4.3}
\]
and
\[
\boxed{
\mathbb E[(v\cdot w)^2\mid A]
=
\operatorname{tr}(M_A^2)
\le
\frac{C_\xi}{D}.
}
\tag{P14-BULK-MOD}
\]

### Proof

Let
\[
E_D=E
\]
and recursively
\[
E_{k-1}=E_k\cap X_k^\perp,
\qquad
k=D,D-1,\ldots,2,
\]
for fresh independent original product rows.

Let \(P_k\) denote the projector onto \(E_k\). Conditional on the past, \(E_k\) is deterministic and \(X_k\) is fresh. If
\[
u_k=\frac{P_kX_k}{\|P_kX_k\|},
\]
then
\[
P_{k-1}=P_k-u_ku_k^\top.
\]

By (3.2),
\[
\mathbb E[u_ku_k^\top\mid E_k]
\succeq
\frac{1-\varepsilon_k}{k}P_k.
\]
Hence
\[
\mathbb E[P_{k-1}\mid E_k]
\preceq
\left(
1-\frac{1-\varepsilon_k}{k}
\right)P_k
=
\frac{k-1+\varepsilon_k}{k}P_k.
\tag{4.4}
\]

Fix \(k_0\ge3\). Iterating down to \(k_0\),
\[
\mathbb EP_{k_0}
\preceq
\prod_{k=k_0+1}^{D}
\frac{k-1+\varepsilon_k}{k}
\,P_E.
\]

Factor the Haar-scale telescoping product:
\[
\prod_{k=k_0+1}^{D}
\frac{k-1+\varepsilon_k}{k}
=
\frac{k_0}{D}
\prod_{k=k_0+1}^{D}
\left(
1+\frac{\varepsilon_k}{k-1}
\right).
\]
Therefore
\[
\mathbb EP_{k_0}
\preceq
\frac{k_0}{D}
\exp\left(
\sum_{k=k_0+1}^{D}
\frac{\varepsilon_k}{k-1}
\right)P_E.
\tag{4.5}
\]

Under (4.1), the exponential factor is uniformly bounded in \(D\).

Since the final line is a subspace of \(E_{k_0}\),
\[
P_{\rm fin}\preceq P_{k_0}
\]
pathwise. Therefore
\[
\mathbb EP_{\rm fin}
\preceq
\frac{C_\xi}{D}P_E.
\]

Now condition on the P14 shared block \(A\). The private rows remain fresh original product rows; the projected coordinate dependence is irrelevant because the sequential update is written in the original ambient space. Thus (4.3) holds uniformly in \(A\).

Finally
\[
\operatorname{tr}M_A=1
\]
and
\[
M_A\succeq0.
\]
So
\[
\operatorname{tr}(M_A^2)
\le
\|M_A\|_{\rm op}\operatorname{tr}M_A
\le
\frac{C_\xi}{D}.
\]

QED.

# 12. Strict extension beyond every \(2+\delta\) moment theorem

P14-FULL-SLOG is not merely a reformulation of the old \(2+\delta\) theorem.

Fix
\[
0<\gamma<1.
\]

One may choose a smooth symmetric bounded density whose large-\(|x|\) tail behaves like
\[
\boxed{
f(x)
\asymp
\frac{
\exp[-c(\log |x|)^\gamma]
}{
|x|^3
}
}
\tag{12.1}
\]
and then recenter/rescale to variance one.

Its second-moment tail satisfies
\[
\Delta(L)
=
\int_{|x|>L}x^2f(x)\,dx
\le
C
\exp[-c'(\log L)^\gamma].
\]

Thus (6.1) holds.

But for every \(\delta>0\),
\[
\int |x|^{2+\delta}f(x)\,dx
\asymp
\int^\infty
e^{\delta t-c t^\gamma}\,dt
=
\infty,
\qquad
t=\log x.
\]

Hence:
\[
\boxed{
\text{P14-FULL-SLOG contains fixed laws with no finite }2+\delta
\text{ moment for any }\delta>0.
}
\tag{12.2}
\]

This is a genuine extension of the verified moment regime.

# 13. Why this does not yet prove arbitrary finite variance

Finite variance permits much slower second-moment tails.

For example, a smooth symmetric law can be arranged with
\[
f(x)
\asymp
\frac{
1
}{
|x|^3
\log |x|
(\log\log |x|)^2
}
\]
for large \(|x|\).

Then
\[
\Delta(L)
\asymp
\frac{1}{\log\log L}.
\]

This still gives finite variance, but the generic P12/P24 modulus bounds can decay so slowly that the available estimate on
\[
\varepsilon_k
\]
does not force
\[
\sum_k\varepsilon_k/k<\infty.
\]

This is **not** a counterexample to P14-FULL-FV.

It is a counterexample to the claim that the present generic finite-variance modulus estimate automatically closes the sharp sequential product.

The distinction is important:

\[
\boxed{
\text{arbitrary finite variance remains mathematically open.}
}
\]

On every top-half stage, conditionally on the past,
