The active P1/P14 model is as follows. The ambient row dimension is `m`. After fixing the apex, choose two distinct `(m-1)`-subsets `S,T` of the remaining `2m-2` row indices and put

`D = m - |S ∩ T|`.

Write

`A = S ∩ T`, `B = S \ T`, `C = T \ S`.

Then `|A|=m-D` and `|B|=|C|=D-1`. For the realized shared rows `A`, let `E_A = span(A)^\perp` and let `Q_A : R^D -> E_A ⊂ R^m` be an isometric embedding (an `m x D` matrix with orthonormal columns). The original null normals of the `(m-1) x m` row submatrices indexed by `S` and `T` are exactly

`u_S = Q_A v`, `u_T = Q_A w`,

where `v,w` are the one-dimensional null directions of the independent residual matrices

`U = B Q_A ∈ R^{(D-1) x D}`, `V = C Q_A ∈ R^{(D-1) x D}`.

Conditional on the shared rows `A`, the two residual matrices are independent and have iid rows with law `Q_A^T X`, where `X` is one original iid-coordinate row. The angle is preserved:

`rho_ST^2 = <u_S,u_T>^2 = <v,w>^2`.

The current theorem target is, for ordinary overlap strata `D>=3`,

`E[(1-rho_ST^2)^(-1/2) | D] <= 1 + C/D + eta_m(D)`

with an error adequate for the fixed-apex second moment. The prior state split this into:

1. **quadratic angular decorrelation:** `E[rho_ST^2|D] = O(1/D)` (more generally an even-moment hierarchy);
2. **high-correlation / no-near-parallel control:** enough control as `|rho_ST| -> 1` to integrate the singular kernel.

The Gaussian benchmark is exact: for independent Haar lines in `R^D`,
`Y=1-rho^2 ~ Beta((D-1)/2,1/2)` and

`E[Y^(-1/2)] = Gamma(D/2) Gamma((D-2)/2) / Gamma((D-1)/2)^2 = 1+O(1/D)`.

The persistent state already proved the conditional residual-line coordinate reduction and identified
`M_A=E[v v^T|A]`, with
`E[(v·w)^2|A]=tr(M_A^2)`.
Thus the quadratic piece is exactly an averaged conditional covariance-isotropy problem.

Assumptions for the theorem proved below: the coordinate law `xi` is centered, variance one, has Lebesgue density bounded by `K`, and is subgaussian with `psi_2` norm at most `kappa`. This is exactly the bounded-density subgaussian route for which the single-normal delocalization input is already available.

## 1. New result: the high-correlation edge can be closed directly

### Proposition P14-EDGE (PROVED)

Under the assumptions above, there is a constant `C0=C0(K,kappa)` such that, for every `D>=3`, every full-rank realization of the shared block `A`, and every `0<eps<=1/2`,

`P(1-(v·w)^2 <= eps | A) <= [ C0 sqrt(eps log(e/eps)) ]^(D-1)`

after enlarging `C0` harmlessly so the right side is at least the exponentially small operator-norm remainder. The same bound holds after conditioning only on the overlap stratum `D`.

This is a genuine no-near-parallel estimate. It has the correct dimensional exponent `(D-1)/2` in `eps`, up to a logarithmic factor inside the base. In particular it is strong enough to make the singular kernel integrable uniformly for every `D>=3`.

### Proof

Fix `A`. Condition further on `B`, hence on the residual null unit vector `v` of `U=BQ_A`. The private block `C` is still independent of `(A,B)`.

Write the rows of `V=CQ_A` as `c_1,...,c_{D-1}`. Let `w` be a unit null vector of `V`. Set

`Y = 1-(v·w)^2`.

Choose the sign/orientation of `w` arbitrarily; only the square matters. Decompose

`v = (v·w) w + sqrt(Y) z`

with `z ⟂ w`, `||z||=1`. Since `Vw=0`,

`Vv = sqrt(Y) Vz`.

Therefore, on `{Y<=eps}`,

`||Vv||_2 <= sqrt(eps) ||V||_op`.                                              (1)

This converts near-parallel null lines into a small-ball event for the vector of `D-1` scalar projections `Vv`.

#### Uniform density of each scalar projection

Conditional on `A,v`, each coordinate of `Vv` is

`<c_i,v> = <X_i,Q_A v>`,

where `Q_A v` is a deterministic unit vector in `R^m` and the `X_i` have iid coordinates with density bounded by `K`.

The sharp marginal-density theorem for product measures (Livshyts–Paouris–Pivovarov, arXiv:1507.07949, Israel J. Math. 216 (2016)) implies a uniform one-dimensional density bound

`|| density(<X_i,Q_A v>) ||_∞ <= K1`

with `K1 <= sqrt(2) K` after scaling from the normalized `||f_i||_∞<=1` statement. The `D-1` rows are independent, so the joint density of `Vv ∈ R^(D-1)` is at most `K1^(D-1)`.

Consequently, for every `R>0`, writing `n=D-1`,

`P(||Vv||_2 <= R | A,v)
 <= K1^n Vol(B_2^n(R))
 <= [ C K1 R/sqrt(n) ]^n`.                                                     (2)

#### Operator norm tail

For fixed `A`, each row `Q_A^T X_i` is isotropic in `R^D` because `Q_A^T Q_A=I_D` and `Cov(X_i)=I_m`. It is also uniformly subgaussian: for every `a∈S^{D-1}`,

`<Q_A^T X_i,a> = <X_i,Q_A a>`

is a unit-coefficient linear combination of independent `kappa`-subgaussian coordinates. Hence the row subgaussian norm is bounded only in terms of `kappa`, uniformly in `A`.

The standard independent-isotropic-subgaussian row matrix bound therefore gives constants `C2,c2>0` depending only on `kappa` such that

`P( ||V||_op > C2(sqrt(D)+t) | A ) <= 2 exp(-c2 t^2)`.                         (3)

For a given `eps`, choose

`t = L sqrt(D log(e/eps))`

with fixed `L=L(kappa)` large enough. Then (3) is at most `2 eps^(2D)` after increasing `L`, while the threshold in (1) is at most

`C3 sqrt(D eps log(e/eps))`.

Using (2), `n=D-1`, and `sqrt(D/n)<=sqrt(3/2)` for `D>=3`,

`P(Y<=eps | A,v)
 <= [ C4 K sqrt(eps log(e/eps)) ]^(D-1) + 2 eps^(2D)`.

The last term is absorbed into the first after increasing `C0`. The estimate is uniform in `v` and in the realized shared block `A`, so averaging first over `B` and then over `A` proves the proposition. QED.

### Why this is useful

The previous research state suggested converting near-parallel residual lines to a small-singular-value/determinant event of a coupled projected matrix. The proposition above is sharper structurally: a full least-singular-value theorem is not needed for the edge. Near-parallelity already forces the `D-1` independent scalar projections in `Vv` to be jointly small, and the bounded-density product-measure marginal theorem supplies the exact dimensional power.

The logarithm enters only through the high-probability control of `||V||_op`. It is harmless for integrability.

## 2. Corollary: the singular edge contributes at most O(1/D)

Let `Y=1-rho^2` and let

`F_D(y)=P(Y<=y | D)`.

By P14-EDGE, for small enough fixed `y_* = y_*(K,kappa)>0`,

`F_D(y) <= [ C0 sqrt(y log(e/y)) ]^(D-1),   0<y<=y_*`,                       (4)

and `C0 sqrt(y_* log(e/y_*))<1/2`.

Integration by parts gives

`E[Y^(-1/2) 1_{Y<=y_*}|D]
 = y_*^(-1/2)F_D(y_*)
   + (1/2) ∫_0^{y_*} y^(-3/2) F_D(y) dy`.                                    (5)

For `D=3`, the integrand is bounded by a constant multiple of
`y^(-1/2) log(e/y)`, which is integrable at zero. For larger `D`, (4) gains additional powers of `y^(1/2)`; choosing `y_*` as above yields exponential decay in `D` after a routine incomplete-gamma/Laplace bound. Thus there is `C5=C5(K,kappa)` such that

`E[Y^(-1/2) 1_{Y<=y_*}|D] <= C5/D,   D>=3`.                                  (6)

This closes the genuinely singular near-one edge.

On the complementary region `Y>y_*`, equivalently `rho^2 < 1-y_*`, the function
`x -> (1-x)^(-1/2)` has a bounded secant slope on `[0,1-y_*]`; hence

`(1-rho^2)^(-1/2) <= 1 + B_* rho^2`

there, with `B_*=B_*(y_*)<∞`. Combining with (6),

`E[(1-rho^2)^(-1/2)|D]
 <= 1 + B_* E[rho^2|D] + C5/D`.                                               (7)

Therefore the entire D-stratified kernel theorem is now reduced, in the bounded-density subgaussian regime, to a **single remaining theorem**:

`E[rho_ST^2 | D] <= C6/D,   D>=3`.                                            (8)

Equivalently, using the prior conditional covariance identity,

`E_A[ tr(M_A^2) | D ] <= C6/D`,                                               (9)

where `M_A=E[vv^T|A]`.

The previous separate "high-correlation tail" obligation is no longer needed in this regime.

## 3. A second useful criterion: L2 angular density would solve both pieces at once

This is not yet proved for the residual null-line law, but the following deterministic probability lemma is proved and gives a clean alternative target.

Let `nu` be any even probability measure on `S^{D-1}` with density `h` with respect to normalized Haar measure `sigma`, and let `v,w` be iid from `nu`. Put `C2=||h||_2^2` and `M=E[vv^T]`.

### Lemma P14-L2 (PROVED)

1. `tr(M^2) <= 1/D + 2(C2-1)/(D(D+2))`.
2. For every `0<=t<1`,
   `P(|v·w|>=t) <= C2 P_Haar(|g·g'|>=t)`.
3. Consequently,
   `E[(1-(v·w)^2)^(-1/2)]
    <= 1 + C2 (B_D-1)`,
   where
   `B_D = Gamma(D/2)Gamma((D-2)/2)/Gamma((D-1)/2)^2`.
   In particular `B_D=1+O(1/D)`, so a dimension-free bound on `C2` implies the full target.

Proof of (1): write `B=M-I/D`. Since `tr B=0`,

`tr(B^2) = ∫(h-1) theta^T B theta d sigma(theta)`.

Cauchy–Schwarz and the spherical quadratic-form identity

`∫(theta^T B theta)^2 d sigma = 2 tr(B^2)/(D(D+2))`

give

`tr(B^2) <= 2||h-1||_2^2/[D(D+2)]`.

Since `||h-1||_2^2=C2-1`, (1) follows.

Proof of (2): let `T_t` be the spherical integral operator with kernel
`1_{|x·y|>=t}`. Its row and column integrals both equal the Haar cap probability `p_D(t)`, so Schur's test gives `||T_t||_{2->2}<=p_D(t)`. Hence

`P(|v·w|>=t)=<h,T_t h> <= C2 p_D(t)`.

For (3), use the layer-cake representation of the increasing function
`g(t)=(1-t^2)^(-1/2)` and (2). QED.

This shows that an averaged conditional chi-square/Renyi-2 bound
`E_A ||h_A||_2^2 = O(1)` would prove not merely (8) but the entire singular-kernel estimate. I do not yet know whether such an `L2` angular-density estimate is easier than (9); importantly, it should not be assumed. It is now a precise alternative target.

## 4. Literature check

- Nguyen–Vu, *Normal vector of a random hyperplane*, arXiv:1604.04897 / IMRN 2018, proves strong Haar-like/delocalization properties for normal vectors of iid-entry random hyperplanes. This supports the already-recorded single-normal input but does not directly give the conditional shared-row pair theorem because, after conditioning on `A`, the coordinates of `Q_A^T X` are dependent.
- Livshyts–Paouris–Pivovarov, arXiv:1507.07949, proves sharp bounds on marginal densities of product measures. Its one-dimensional case is exactly the uniform density input used in P14-EDGE.
- Juškevičius–Lee, arXiv:1503.09190, gives a rearrangement/small-ball framework for sums of independent bounded-density variables and is consistent with the same projection-density step.
- Mendelson–Paouris, JEMS 16 (2014), treats singular values for matrices with iid rows under moment/support hypotheses. It is useful context for projected-row matrices but its spectral-edge theorem is not by itself the required near-zero angular tail.
- Rudelson–Vershynin's 2009 optimal rectangular smallest-singular-value theorem assumes iid subgaussian entries. It must **not** be applied verbatim to `BQ_A` or `CQ_A`, because conditioning on `A` makes the projected row coordinates dependent. The new proof avoids that invalid shortcut.

## 7. Best next attack

The next run should focus exclusively on the quadratic part, not the edge.

The cleanest formulation is:

> Given `A` with `dim E_A=D`, let `nu_A` be the null-line law of a `(D-1)xD` matrix with iid rows `Q_A^T X`, and `M_A=∫ vv^T dnu_A(v)`. Prove
> `E_A tr(M_A^2) <= C/D`.

Three routes deserve simultaneous pressure:

1. **Conditional covariance / determinant-density route.** Use the linear Blaschke–Petkantschin formula: the angular density of the null line is proportional to the hyperplane-section determinant functional
   `Phi_A(theta)=∫_{(theta^\perp)^(D-1)} |det(y_1,...,y_{D-1})| ∏ f_A(y_i) dy_i`.
   Seek an averaged second-harmonic or `L2` estimate for `Phi_A/∫Phi_A`.

2. **Resampling/exchangeable-pair route.** Interpret `M_A=E[u_Su_S^T|A]` as the conditional expectation of a single iid-entry null-normal projector after revealing `m-D` rows. Bound the Hilbert–Schmidt norm of this posterior projector via row-resampling/noise-sensitivity rather than pointwise angular density.

3. **Moment comparison route.** Adapt Nguyen–Vu's normality-of-linear-functionals argument to the shared-row pair observable directly. It is important to compare `E[(v·w)^2|D]` rather than trying to prove total-variation Haar universality of `nu_A`, which is far stronger than needed.

The new edge proposition means that success on any one of these routes closes the bounded-density subgaussian D-stratified pair theorem.
