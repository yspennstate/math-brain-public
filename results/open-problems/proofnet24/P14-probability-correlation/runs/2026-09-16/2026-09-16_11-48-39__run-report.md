# 5. `P14-COORDINATE-LEVERAGE-ALLMOMENTS-42` — PROVED

This is the main analytic input.

## 5.1 Statement

Fix an integer `q>=1`. Let `r>=q`, put

`n=r-q`,

let

`A in R^(n x r)`

have iid entries with the P14 scalar law, and define

`R=Proj(ker A)`.

For each coordinate `i`, put

`ell_i=R_ii`.

Then for every fixed `p<infinity`,

`boxed: sup_(r>=q) sup_i E (r ell_i)^p <= C_(p,q,K).`       (5.1)

The constant is source-dependent only through the density ceiling and the fixed anti-concentration constants implied by it. No moment above two is used.

## 5.2 Leave-one-coordinate formula

Fix `i` and permute columns so it is first. Write

`A=[x  B]`,

where

`x in R^n`

is the distinguished iid source column and

`B in R^(n x (n+q-1))`

contains the other columns. The vectors `x` and `B` are independent.

Bounded density gives full row rank almost surely. Put

`G=BB^T`.

Sherman--Morrison gives the exact leverage formula

`boxed: ell_i = 1/(1+x^T G^(-1) x).`                    (5.2)

This formula uses a genuinely independent original source column; there is no projected-coordinate independence claim.

## 5.3 A fixed-dimensional hard-edge window

Fix an integer `h`, to be chosen later depending only on the desired moment `p` and on `q`. Let

`sigma_h(B)`

be the `h`-th smallest singular value of `B`, and let `E_h` be the span of the corresponding `h` left singular vectors.

On `E_h`,

`G^(-1) >= sigma_h(B)^(-2) I`.

Hence, for `1<=y<=r`, the event

`r ell_i >= y`

implies by `(5.2)`

`x^T G^(-1)x <= r/y`

and therefore

`boxed: ||Proj_(E_h) x|| <= sigma_h(B) sqrt(r/y).`        (5.3)

The dimension `h` is fixed while `r` grows.

## 5.4 Transfer the hard edge to a genuine square iid matrix

Split

`B=[B_0  C]`,

where `B_0` is an `n x n` iid square submatrix and `C` has `q-1` columns. Then

`BB^T=B_0B_0^T+CC^T`,

and `rank(CC^T)<=q-1`.

For eigenvalues written in increasing order, rank-`(q-1)` interlacing gives

`boxed: sigma_h(B) <= sigma_(h+q-1)(B_0)`                 (5.4)

whenever `h+q-1<=n`.

This is the key device that avoids importing a high moment of a rectangular singular value. Only a square iid matrix is fed into the current primary intermediate-singular-value theorem.

## 5.5 Current primary hard-edge upper tail

The scalar density ceiling implies a fixed one-dimensional anti-concentration hypothesis. For example, with

`a=1/(4K)`,

`sup_z P(|xi-z|<a) <= 1/2`.

Polavarapu--Fernandez, arXiv:2608.30722 (submitted 2026-08-31), prove for an `n x n` matrix with independent centered variance-one entries and fixed one-dimensional anti-concentration that, for every fixed `delta>0`,

`P(s_(n+1-l) > C t l/sqrt(n))`
`<= exp[-c min{t l,n}]`,

for `t>=1` and `1<=l<=(1-delta)n`.

Take `l=h+q-1`, fixed. Combining with `(5.4)`, for all sufficiently large `n`,

`P{sigma_h(B) > C_(h,q,K) t/sqrt(n)}`
`<= exp[-c_(h,q,K) min{t,n}]`.                         (5.5)

Importantly, `(5.5)` is a probability estimate. We never integrate a high power of `sigma_h(B)`, which could be illegal for a heavy-tailed source.

## 5.6 Fixed-dimensional projected density

Conditional on `B`, the subspace `E_h` is deterministic and `x` remains a product vector with one-dimensional density ceiling `K`.

Livshyts--Paouris--Pivovarov, arXiv:1507.07949, prove that every `h`-dimensional orthogonal marginal of a product density whose factors are bounded by one has density bounded by `2^(h/2)`. After scaling the density ceiling to `K`, this gives

`||f_(Proj_(E_h)x)||_infinity <= 2^(h/2) K^h`.           (5.6)

This is a joint projected-density statement. It does **not** make the projected coordinates independent.

Therefore for every radius `u>0`,

`P{||Proj_(E_h)x|| <= u | B}`
`<= C_(h,K) u^h`.                                         (5.7)

## 5.7 Polynomial tail for normalized leverage

On the good event in `(5.5)`, `(5.3)` and `(5.7)` yield

`P{r ell_i >= y | B}`
`<= C_(h,q,K) t^h y^(-h/2)`

because `r/n=(n+q)/n` is bounded for large `n`.

Choose

`t=A log(e+y)`

with `A` fixed large enough. For `1<=y<=r`, the bad event from `(5.5)` is then bounded by `C y^(-M)` for any prescribed fixed `M` after increasing `A`; if the exponential tail saturates at `exp(-cn)`, that term is still `O(y^-M)` because `y<=r=n+q`.

Thus

`boxed:`

`P{r ell_i >= y}`
`<= C_(h,q,K,M) [log(e+y)]^h y^(-h/2) + C y^(-M),`        (5.8)

uniformly for `1<=y<=r`.

For a prescribed fixed moment `p`, choose

`h>2p`

and `M>p`. Integrating

`E(r ell_i)^p = p integral_0^r y^(p-1) P(r ell_i>=y) dy`

proves `(5.1)`.

The finitely many small dimensions excluded by `h+q-1<=(1-delta)n` are absorbed into the constant because `0<=ell_i<=1`.

### Why finite variance is enough

There are only two uses of the source law beyond independence:

1. centered variance one plus fixed anti-concentration for the Polavarapu--Fernandez probability tail;
2. bounded scalar density for the fixed-dimensional marginal-density small ball.

The hard-edge bad event is paid probabilistically. No expectation of a singular-value power and no raw fourth source moment appears.

# 6. `P14-COORDINATE-FIXEDQ-PLUCKER-L2-42` — PROVED

Fix `1<=d<=q` and continue the setup of Section 5 with coordinate parent `P=I_r`.

The parent degree-`d` DPP is uniform on `d`-subsets, while

`pi_R^(d)(S)=det(R_S)/C(q,d)`.

Hence

`A_q^(d)(I_r,R)`
`= [C(r,d)/C(q,d)^2] sum_(|S|=d) det(R_S)^2.             (6.1)

Because each principal block `R_S` is positive semidefinite, Hadamard gives

`0<=det(R_S)<= product_(i in S) ell_i`.                   (6.2)

By Holder and `(5.1)` with moment `2d`,

`E product_(i in S) ell_i^2`
`<= product_(i in S) [E ell_i^(2d)]^(1/d)`
`<= C_(q,d,K) r^(-2d).`                                  (6.3)

There are `C(r,d)=O_d(r^d)` subsets. Therefore

`E sum_(|S|=d) det(R_S)^2 <= C r^(-d)`.                  (6.4)

Multiplying by the prefactor `C(r,d)/C(q,d)^2=O_(q,d)(r^d)` in `(6.1)` yields

`boxed: E A_q^(d)(I_r,R) <= C_(q,d,K).`                  (6.5)

This proves the theorem.

# 8. `P14-PAIR-CHOLESKY-SCALAR-PEEL-42` — PROVED

The coordinate theorem above identifies the desired hard-edge mechanism. The next question is how much of that mechanism survives for an arbitrary adaptive parent. The pair survival admits an exact scalar factorization.

Fix a rank-`r` parent projector `P` and an ordered parent-supported coordinate pair

`S=(i,j)`

with `P_S` positive definite. Choose the upper-triangular Cholesky factor

`P_S=R_S^T R_S`,

and define the orthonormal marked frame

`U=P E_S R_S^(-1)`.

Then

`U^T U=I_2`.

Let `V` be an orthonormal basis of

`Ran(P) intersect span(U)^perp`.

For vectors in `Ran(P)`, orthogonality to `P e_i,P e_j` is equivalent to vanishing in coordinates `i,j`, hence

`V_S=0`.

## 8.1 Original-coordinate innovation is triangular

For a genuinely fresh original source row `X`, put

`c=U^T X`,
`d=V^T X`.

Because

`U^T X`
`=R_S^(-T)[P_S X_S + P_(S,S^c) X_(S^c)]`
`=R_S X_S + R_S^(-T) P_(S,S^c) X_(S^c)`,                (8.1)

and `V_S=0`, the complement coefficient `d` depends only on `X_(S^c)`.

Write

`R_S=[[a,b],[0,c0]]`,

with `a,c0>0`. Then, conditional on the unmarked original coordinates,

`c_1 = a xi_i + b xi_j + shift_1`,

`c_2 = c0 xi_j + shift_2`.                                (8.2)

After conditioning additionally on `xi_j`, the first marked coefficient still contains the genuinely independent source scalar `xi_i` with density ceiling `K/a`. This is an exact original-coordinate statement, not a projected-iid substitution.

## 8.2 Determinant peel

Expose `n=r-3` genuinely fresh future rows. In the frozen frame `[U,V]`, write their coefficient matrix as

`B=[c_1  c_2  D]`,

where now `c_1,c_2` denote the two `n`-vectors of marked coefficients and

`D in R^(n x (n+1))`.

Put

`G=DD^T`.

Almost surely `G` is invertible. The inherited pair survival identity is

`tau_S=det((R_3)_S)/det(P_S)`
`=det(G)/det(G+c_2c_2^T+c_1c_1^T).`                      (8.3)

Apply the matrix determinant lemma twice. Define

`s_2 = det(G)/det(G+c_2c_2^T)`
`    = 1/(1+c_2^T G^(-1)c_2)`,

and, with `H=G+c_2c_2^T`,

`s_1 = det(H)/det(H+c_1c_1^T)`
`    = 1/(1+c_1^T H^(-1)c_1)`.

Then

`boxed: tau_S=s_1 s_2.`                                      (8.4)

## 8.3 Each factor is literally a nullspace coordinate leverage

Let

`M_2=[D  c_2]`.

Its nullspace has rank two. The diagonal leverage of the newly appended coordinate `c_2` in `Proj(ker M_2)` is

`1-c_2^T(M_2M_2^T)^(-1)c_2`
`=1/(1+c_2^T G^(-1)c_2)`
`=s_2`.

Likewise, append `c_1` and put

`M_3=[D  c_2  c_1]`.

The new-coordinate leverage in its rank-three nullspace is exactly

`s_1`.

Thus the parent-pair volume survival is the product of a rank-two and a rank-three **scalar coordinate-leverage survival**.

This factorization is basis/order dependent at the level of the two factors, but their product is the invariant pair survival.

## 8.4 Normalized form

At a rank-`r` parent, the normalized pair likelihood is

`W_2=[C(r,2)/3] tau_S`
`=[r/3 * s_1] * [(r-1)/2 * s_2].`                         (8.5)

This is the exact scalar analogue of the previously proved sequential leverage-Palm factorization of the pair DPP likelihood.

The new benefit is that `(8.2)` identifies where one original scalar innovation survives after the pair geometry is frozen.

# 9. `P14-UNIFORM-FROZEN-GRAM-NOGO-42` — PROVED route-kill

The scalar peel might tempt one to condition on the whole complementary Gram matrix and seek, uniformly in that matrix,

`E[s_1^2 | H, shifts] <= C/r^2`.

This is false even abstractly.

Take any dimension `n` and the deterministic Gram matrix

`H=L I_n`.

Then

`s_1=1/(1+||c_1||^2/L)`.

For a centered variance-one product column, `E||c_1||^2=n` up to the fixed Cholesky scaling/translation terms. Let `L/n -> infinity`. Then

`s_1 -> 1`

in probability, and by bounded convergence

`E s_1^2 ->1`.

Therefore no `O(r^-2)` scalar-survival second-moment bound can hold uniformly over a frozen complementary Gram geometry.

# 10. Why the coordinate proof does not automatically solve the adaptive parent

The exact row-volume graph chart from the preceding P14 report remains the right source-faithful coordinate system. If the already exposed parent row matrix is `A_0`, sample a row-volume basis `T`, let `U=T^c`, put

`H=A_(0,T)^(-1) A_(0,U)`,

and represent parent-kernel vectors by

`z=(-Hy,y)`.

The parent metric in chart coordinates is

`G_0=I+H^T H`.

For a genuinely fresh original row,

`Y=X_U-X_T H`.

Conditional on `X_T`, the chart coordinates `Y_j`, `j in U`, are independent translations of the original scalar law, each retaining density ceiling `K`.

This is useful, but two obstacles prevent a black-box transplantation of Section 5.

## 10.1 Translation destroys the centered singular-value input

Conditionally, the complement matrix is an independent-entry matrix plus a deterministic translation matrix. The Polavarapu--Fernandez theorem used above assumes centered variance-one entries. Its upper hard-edge estimate is not shift-uniform: adding a large deterministic full-rank matrix can raise all small singular values.

The translation matrix in the adaptive chart can have rank comparable to the future-row dimension. Therefore the square hard-edge theorem cannot simply be applied after conditioning on the parent chart.

## 10.2 Whitening destroys conditional product structure

The Euclidean parent metric is `G_0`, not the identity. Whitening by `G_0^(-1/2)` restores an orthonormal parent frame but mixes the conditionally independent chart coordinates. The resulting projected row has dependent coordinates, exactly as in the original source warning.

Hence the coordinate theorem proves the correct local mechanism but also identifies the precise adaptive obstruction: one needs a hard-edge/cap estimate that keeps the generalized metric and the translated-product innovation coupled, rather than centering or whitening them separately.
