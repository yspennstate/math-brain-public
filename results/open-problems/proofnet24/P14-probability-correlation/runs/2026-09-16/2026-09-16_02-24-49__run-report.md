# 5. `P14-DUALSUPPORT-GRAM-EXACT-33` — PROVED

P24 uses only the smallest eigenvalue of the two-vector Gram matrix. For the physical Hoeffding field one can keep the full Gram inverse and obtain an exact decomposition.

Fix one realization \(U,V\) with \(|U\cdot V|<1\). Set

\[
c=U\cdot V,
\qquad
\rho=|c|,
\qquad
\sigma=\operatorname{sign}(c).
\]

Let

\[
A=[U\ V],
\qquad
G=A^\top A=
\begin{pmatrix}
1&c\\
c&1
\end{pmatrix}.
\]

The orthogonal projector onto \(S=\operatorname{span}(U,V)\) is

\[
\Pi_{U,V}=AG^{-1}A^\top.
\]

Because \(H=H_{U,V}\) is self-adjoint,

\[
\|H\Pi_{U,V}\|_F^2
=
\operatorname{tr}(H^2\Pi_{U,V})
=
\operatorname{tr}(G^{-1}A^\top H^2A).
\]

Using (4.3),

\[
\|HU\|^2=\|K_VU\|^2,
\qquad
\|HV\|^2=\|K_UV\|^2,
\]

and

\[
\langle HU,HV\rangle
=
\langle K_VU,K_UV\rangle.
\]

Since

\[
G^{-1}
=\frac1{1-c^2}
\begin{pmatrix}
1&-c\\
-c&1
\end{pmatrix},
\]

we get the exact identity

\[
\boxed{
\|H\|_F^2
=
\|H(I-\Pi_{U,V})\|_F^2
+
\frac{
\|K_VU\|^2+\|K_UV\|^2
-2c\langle K_VU,K_UV\rangle
}{1-c^2}.
}
\tag{5.1}
\]

This is already a source-faithful q=3-type formula: the near-collinearity denominator is inseparable from a centered physical numerator.

For a more revealing form orient the second line by \(V'=\sigma V\), so \(U\cdot V'=\rho\). Define

\[
s=\frac{U+V'}{\sqrt{2(1+\rho)}},
\qquad
 t=\frac{U-V'}{\sqrt{2(1-\rho)}}.
\]

Then \(s,t\) are orthonormal and

\[
\|HU\|^2+\|HV\|^2
=(1+\rho)\|Hs\|^2+(1-\rho)\|Ht\|^2.
\tag{5.2}
\]

Therefore

\[
\begin{aligned}
\|H\|_F^2
-&\frac{\|HU\|^2+\|HV\|^2}{1+\rho}
\\
&=
\|H(I-\Pi_{U,V})\|_F^2
+
\frac{2\rho}{1+\rho}\|Ht\|^2.
\end{aligned}
\tag{5.3}
\]

By (4.3),

\[
Ht
=
\frac{-K_VU+\sigma K_UV}{\sqrt{2(1-\rho)}}.
\]

Hence

\[
\boxed{
\mathfrak s(U,V)
:=
\|H\|_F^2
-
\frac{\|K_UV\|^2+\|K_VU\|^2}{1+\rho}
}
\tag{5.4}
\]

has the exact nonnegative representation

\[
\boxed{
\mathfrak s(U,V)
=
\|H(I-\Pi_{U,V})\|_F^2
+
\frac{\rho}{1-\rho^2}
\|K_VU-\sigma K_UV\|^2.
}
\tag{5.5}
\]

Because the fresh projected directions have an absolutely continuous joint law in every rank \(n\ge2\), \(\rho=1\) has probability zero. One may also read (5.5) by lower-semicontinuous limit at the collinear endpoint.

### Consequence

P24's denominator \((1+\rho)^{-1}\) is not the end of the geometry. The amount lost by the minimum-eigenvalue bound is itself a physical energy. Near \(\rho=1\), its singular coefficient is coupled to

# 7. `P14-SHARP-COMPENSATED-DEFECT-CRITERION-33` — PROVED

# 8. `P14-ASYMPTOTIC-FACTOR2-NOGO-33` — PROVED / ROUTE-KILL

The asymptotic factor-two coefficient does not by itself rule out a logarithmic drift.

Fix any \(c>0\). For all sufficiently large \(n\), define

\[
R_n=c\frac{\log n}{n}.
\tag{8.1}
\]

Choose \(N\) so large that \(c\log N>1\). On the finite prefix \(1\le n<N\), redefine \(R_n\) monotonically so that

\[
R_1=1,
\qquad
R_n\ge\frac1n,
\qquad
R_{N-1}\ge R_N.
\]

For example, the finite prefix may be taken as the monotone envelope of \(1/n\) and the endpoint value \(R_N\). This finite adjustment does not affect any asymptotic statement below.

Set

\[
q_n=R_{n-1}-R_n\ge0.
\tag{8.2}
\]

For large \(n\), with \(g(x)=\log x/x\), the mean-value theorem gives

\[
q_n
=c\,[g(n-1)-g(n)]
=
-cg'(\xi_n)
=
 c\frac{\log\xi_n-1}{\xi_n^2}
\tag{8.3}
\]

for some \(\xi_n\in(n-1,n)\). Hence

\[
\boxed{
q_n
\sim
c\frac{\log n}{n^2}.
}
\tag{8.4}
\]

Similarly,

\[
\frac{q_{n-1}}{q_n}
=
1+\frac2n+O\!\left(\frac1{n\log n}\right),
\tag{8.5}
\]

so if

\[
\gamma_n=\frac{q_{n-1}}{q_n}-1,
\]

then

\[
\boxed{
\gamma_n=\frac2n(1-o(1)).
}
\tag{8.6}
\]

Thus the sequence satisfies exactly the asymptotic contraction scale proved by P24, as well as positivity, monotone purity, the rank-\(n\) lower bound \(R_n\ge1/n\), and \(R_n\to0\). Yet

\[
\boxed{
n^2q_n\sim c\log n\to\infty,
\qquad
nR_n\sim c\log n\to\infty.
}
\tag{8.7}
\]

Equivalently,

\[
p_n=(n+1)(n+2)q_n\asymp\log n.
\]

Therefore any proof that stops at

\[
\gamma_n=\frac2n(1-o(1))
\]

cannot yield the sharp constant-order reveal theorem or the sharp \(1/n\) purity theorem by recurrence algebra alone.

The obstruction is not hypothetical: in the integrating-factor identity (6.6), a logarithmic drift corresponds exactly to an uncompensated harmonic bill

\[
n(n+1)(2d_n-s_n)\asymp\frac1n.
\]

That is the precise debt the next theorem must remove.
