# 5. `P14-CHART-FIRSTMARGINAL-HYPERGEOMETRIC-44` — PROVED

## 5.1 Statement

Assume `m>=5`.  Retain the parent row-volume law `nu_A(T)` and chart tilt `Z_T` from the previous run.  For a fixed coordinate pair `S` with `p_S>0`, the parent conditional chart law is

\[
P(T\mid S)
=
\frac{\nu_A(T)}{p_S},
\qquad
T\subset S^c.
\tag{5.1}
\]

Define

\[
a_S:=E[Z_T\mid S]
\tag{5.2}
\]

and

\[
A_S:=p_Sa_S
=
\sum_{T\subset S^c}\nu_A(T)Z_T.
\tag{5.3}
\]

Set

\[
t_S=\operatorname{tr}(R_S),
\qquad
d_S=\det(R_S),
\]

and

\[
\alpha_0
=
\frac{(r-3)(r-4)}{(m-3)(m-4)},
\qquad
\alpha_1
=
\frac{r-3}{m-3}.
\tag{5.4}
\]

Then pathwise,

\[
\boxed{
A_S
=
\alpha_0
+(\alpha_1-\alpha_0)t_S
+(1-2\alpha_1+\alpha_0)d_S.
}
\tag{5.5}
\]

Equivalently, since `s=m-r`,

\[
\boxed{
A_S
=
\frac{
(r-3)(r-4)
+s(r-3)t_S
+s(s-1)d_S
}{(m-3)(m-4)}.
}
\tag{5.6}
\]

Moreover

\[
\boxed{
\sum_{|S|=2}A_S=\binom r2.
}
\tag{5.7}
\]

Thus

\[
\mu(S):=\frac{A_S}{\binom r2}
\tag{5.8}
\]

is a probability law and

\[
\boxed{
\frac{d\mu}{d\pi_P}(S)=a_S=E[Z_T\mid S].
}
\tag{5.9}
\]

The raw chart tilt, after the first physically meaningful marginalization, is therefore an **explicit hypergeometric thinning likelihood** controlled by child singleton and pair DPP statistics.

## 5.2 Proof

Use the exact nested child row-basis coupling from the previous run.  Let

\[
W\subset[m],
\qquad |W|=m-3,
\]

be a row-volume basis of the stacked child row matrix, and after `W` is chosen select `T` uniformly from the `s`-subsets of `W`.

\[
P(T)=\nu_A(T)Z_T.
\tag{5.10}
\]

Hence `(5.3)` has the immediate probabilistic meaning

\[
\boxed{
A_S=P\{T\cap S=\varnothing\}.
}
\tag{5.11}
\]

Let

\[
C=W^c.
\]

Then `|C|=3`, and by projection-complement/Cauchy--Binet, `C` is exactly the rank-three coordinate projection-DPP with kernel `R`.

Put

\[
J=|C\cap S|\in\{0,1,2\}.
\]

Since `|W|=m-3`, conditional on `J` the number of points of `S` lying in `W` is `2-J`.  Therefore a uniform `s`-subset `T` of `W` avoids `S` with probabilities

\[
P(T\cap S=\varnothing\mid J=0)
=
\frac{\binom{m-5}{s}}{\binom{m-3}{s}}
=\alpha_0,
\]

\[
P(T\cap S=\varnothing\mid J=1)
=
\frac{\binom{m-4}{s}}{\binom{m-3}{s}}
=\alpha_1,
\]

and

\[
P(T\cap S=\varnothing\mid J=2)=1.
\tag{5.12}
\]

For a projection-DPP,

\[
P(J=2)=d_S,
\qquad
EJ=t_S.
\]

Thus

\[
P(J=1)=t_S-2d_S,
\qquad
P(J=0)=1-t_S+d_S.
\tag{5.13}
\]

Substituting `(5.12)--(5.13)` into `(5.11)` gives `(5.5)`.

Elementary algebra yields

\[
\alpha_1-\alpha_0
=
\frac{s(r-3)}{(m-3)(m-4)},
\]

and

\[
1-2\alpha_1+\alpha_0
=
\frac{s(s-1)}{(m-3)(m-4)},

which gives `(5.6)`.

Finally, under `(5.10)`, every realized `T` has complement of size `r`, hence exactly `C(r,2)` coordinate pairs disjoint from it.  Summing `(5.11)` over `S` gives `(5.7)` directly.

No probability approximation and no source-law assumption enters this theorem.

# 7. `P14-ANNEALED-PAIR-ROWTHINNING-QUOTIENT-44` — PROVED

## 7.1 Annealed row exchangeability

Fix `r>=3` and put

\[
s=m-r,
\qquad
n=r-3,
\qquad
N=s+n=m-3.
\]

In the actual reveal construction, the first `s` iid original rows form the parent and the next `n` iid original rows complete the child.

Equivalently **for annealed expectations**, let

\[
B\in\mathbb R^{N\times m}
\]

have all `N=m-3` iid original rows, choose

\[
I\subset[N],
\qquad |I|=s,
\]

uniformly and independently of the row values, set

\[
A_0=B_I,
\]

and define

\[
P=\operatorname{Proj}(\ker A_0),
\qquad
R=\operatorname{Proj}(\ker B).
\]

This replacement is exact by exchangeability of the original iid rows: averaging over the deterministic first-`s` choice equals averaging over a uniform `s`-subset.

## 7.2 Freeze a coordinate pair before any projection

By iid-coordinate exchangeability it is enough in the annealed energy to take

\[
S=\{1,2\}.
\]

Write the full child matrix in **original coordinates** as

\[
B=[C\; Z],
\]

where

\[
C=B_S\in\mathbb R^{N\times2},
\qquad
Z=B_{S^c}\in\mathbb R^{N\times(m-2)}.
\]

The two columns of `C` are independent iid source columns and are independent of `Z`.  No projected coordinate is introduced.

Put

\[
H=ZZ^T.
\]

Because `Z` is an `(m-3) x (m-2)` matrix with independent continuous entries, `H` is positive definite almost surely.

For the parent row subset, define

\[
C_I=C[I,:],
\qquad
Z_I=Z[I,:],
\qquad
H_I=Z_I Z_I^T.
\]

Again `H_I` is positive definite almost surely.

## 7.3 Exact Jacobi / matrix-determinant identity

For any full-row-rank matrix `M`, with null projector `Q`, the generalized Jacobi identity gives

\[
\det(Q_S)
=
\frac{\det(M_{S^c}M_{S^c}^T)}{\det(MM^T)}.
\tag{7.1}
\]

Apply `(7.1)` first to the child `B`:

\[
\det(R_S)
=
\frac{\det H}{\det(H+CC^T)}.
\]

The matrix determinant lemma gives

\[
\boxed{
\det(R_S)
=
\det(I_2+C^TH^{-1}C)^{-1}.
}
\tag{7.2}
\]

Apply the same identity to the parent `A_0=B_I`:

\[
\boxed{
\det(P_S)
=
\det(I_2+C_I^TH_I^{-1}C_I)^{-1}.
}
\tag{7.3}
\]

Therefore the physical pair summand has the exact quotient form

\[
\boxed{
Q_{m,r}(I;C,Z)
:=
\frac{\det(R_S)^2}{\det(P_S)}
=
\frac{
\det(I_2+C_I^TH_I^{-1}C_I)
}{
\det(I_2+C^TH^{-1}C)^2
}.
}
\tag{7.4}
\]

This is an identity, not an upper bound.

\[

## 9.2 One-row parent

Take a one-row parent

\[

\]

so `r=m-1`, and fix `S={1,2}`.  By the one-row Jacobi formula,

\[

=
\frac{U}{U+V},
\tag{9.1}
\]

where

\[
U=\sum_{k=3}^m\xi_k^2,
\qquad
V=\xi_1^2+\xi_2^2.
\]

The variables `U` and `V` are independent, and `U>0` almost surely.

Then

\[
p_S^{-2}
=\left(1+\frac VU\right)^2
\ge
\frac{\xi_1^4}{U^2}.
\]

Conditioning on every finite positive value of `U`,

\[
E_{\xi_1}\frac{\xi_1^4}{U^2}=\infty.
\]

Therefore

\[
\boxed{E p_S^{-2}=\infty.}
\tag{9.2}

On the other hand, if `m>=5`, then the unmarked vector has dimension `m-2>2`.  Its joint density is bounded, and

\[

\]

because near the origin

\[
\int_{\|x\|\le1}\|x\|^{-2}\,dx<\infty
\]

in dimension greater than two, while outside the unit ball the integrand is at most one.  Since `EV=2`,

\[
\boxed{
E p_S^{-1}
=1+2E U^{-1}<\infty.
}
\tag{9.3}
\]

Thus the exact endpoint is already visible in the simplest parent:

\[
\boxed{p_S^{-1}\in L^1\quad\text{but}\quad p_S^{-1}\notin L^2.}
\tag{9.4}
