# 4. `P14-PARENT-PALM-PROJECTED-NULLLINE-35` — PROVED

Fix **any realized rank-`r` parent projector**

\[
P=P^T=P^2,
\qquad \operatorname{rank}P=r\ge2,
\]

that is measurable with respect to the already exposed original rows. All future original rows remain iid and independent of this history.

Write

\[
p_i=P_{ii}.
\]

Sample a coordinate `I`, conditional on `P`, by the parent-leverage law

\[
\boxed{
P\{I=i\mid P\}=\frac{p_i}{r}.
}
\tag{4.1}
\]

This choice is made **before** revealing future rows, so it does not destroy freshness.

On `{p_I>0}`, define

\[
f_0=\frac{Pe_I}{\sqrt{p_I}}\in\operatorname{Ran}P.
\tag{4.2}
\]

Complete `f_0` to an orthonormal basis

\[
f_0,f_1,\ldots,f_{r-1}
\]

of `Ran(P)` in a way measurable with respect to `(P,I)`.

Let

\[
F=[f_0\ \cdots\ f_{r-1}]\in\mathbb R^{m\times r}.
\]

For each of the remaining `r-1` genuinely fresh original rows `X_j`, define its parent coordinates

\[
W_j=F^TX_j\in\mathbb R^r.
\]

Then conditional on `(P,I)` the rows `W_j` are iid copies of the orthogonal projection of a fresh original product row onto this **frozen** frame. They are centered and isotropic:

\[
EW_j=0,
\qquad
E[W_jW_j^T]=I_r,
\]

but their coordinates need not be independent.

Let `u` be a unit null vector of the `(r-1) x r` matrix `W` with rows `W_j^T`. The ambient terminal line is

\[
z=Fu
\]

up to sign. Since `Pz=z`,

\[
\langle f_0,z\rangle
=
\frac{\langle Pe_I,z\rangle}{\sqrt{p_I}}
=
\frac{z_I}{\sqrt{p_I}}.
\]

But `\langle f_0,z\rangle=u_0`. Therefore

\[
\boxed{
 u_0^2=\frac{z_I^2}{p_I}.
}
\tag{4.3}
\]

This is an exact equality of the adaptive P14 object with a distinguished coordinate of a fresh projected null line.

### Why the conditioning is source-faithful

The crucial order is:

1. freeze the actual parent history;
2. choose `I` from `(4.1)`, using only the parent;
3. freeze the frame `F`;
4. only then reveal the remaining original rows.

Thus the future rows are genuinely fresh. The frame may be highly adaptive, but the adaptive information is entirely in `F`; no independence is claimed among coordinates of `F^TX_j`.

# 5. `P14-ONECOORDINATE-PEELING-35` — PROVED

The preceding representation has a useful exact coordinate decomposition.

Fix `(P,I=i)` and write

\[
p=p_i.
\]

The first parent basis vector is

\[
f_0=\frac{Pe_i}{\sqrt p}.
\]

Its `i`th coordinate equals

\[
(f_0)_i
=\frac{P_{ii}}{\sqrt p}
=\sqrt p.
\]

If `p<1`, define

\[
g_0
=\frac{f_0-\sqrt p\,e_i}{\sqrt{1-p}}.
\tag{5.1}
\]

Then `g_0` is a unit vector supported on the coordinates other than `i`.

Now take any `f\in Ran(P)` orthogonal to `f_0`. Since `f=Pf`,

\[
f_i
=\langle e_i,f\rangle
=\langle Pe_i,f\rangle
=\sqrt p\,\langle f_0,f\rangle
=0.
\]

Hence the remaining basis vectors `f_1,...,f_{r-1}` can all be chosen with zero `i`th coordinate. Moreover they are orthogonal to `g_0`.

Write one fresh original row as

\[
X=(\xi_i,X_{-i}).
\]

Set

\[
\eta=\langle X_{-i},g_0\rangle,
\qquad
c_j=\langle X_{-i},f_j\rangle,
\quad 1\le j\le r-1.
\]

Then the projected row is exactly

\[
\boxed{
F^TX
=
\left(
\sqrt p\,\xi_i+\sqrt{1-p}\,\eta,
\ c_1,\ldots,c_{r-1}
\right).
}
\tag{5.2}
\]

Because the original coordinates are iid, `xi_i` is independent of the vector

\[
(\eta,c_1,\ldots,c_{r-1}).
\]

The latter is the orthogonal projection of `X_{-i}` onto the orthonormal family

\[
g_0,f_1,\ldots,f_{r-1}
\]

in the coordinate complement. It is centered and isotropic but generally has dependent coordinates.

For `p=1`, `(5.2)` reduces to `delta=xi_i` and the same formula by continuity.

## Gaussian calibration

If the source is standard Gaussian, orthogonal invariance makes

\[
\eta,c_1,\ldots,c_{r-1}
\]

independent standard Gaussians, also independent of `xi_i`. Therefore

\[
\sqrt p\,\xi_i+\sqrt{1-p}\,\eta
\]

is standard Gaussian and independent of `c`. Thus the full row `(5.2)` is exactly `N(0,I_r)` for every `p` and every adaptive parent. This recovers the Haar terminal null line pointwise in the parent geometry.

The decomposition therefore isolates the non-Gaussian obstruction very precisely: the special scalar coordinate has truly independent noise of amplitude `sqrt(p)`, while the remaining amplitude `sqrt(1-p)` is carried by the coupled projected block and cannot be discarded when `p` is small.

# 6. Parent Palm versus terminal-energy Palm

Continue with a fixed parent `P` and terminal line `z`.

For every `i` with `p_i>0`, define

\[
X_i=\frac{z_i^2}{p_i}\in[0,1].
\tag{6.1}
\]

Under the parent-leverage Palm coordinate `(4.1)`,

\[
\begin{aligned}
E_I[X_I\mid P,z]
&=\sum_i\frac{p_i}{r}\frac{z_i^2}{p_i}\\
&=\frac1r\sum_i z_i^2\\
&=\frac1r.
\end{aligned}
\]

Hence

\[
\boxed{
E[X_I\mid P]=1/r.
}
\tag{6.2}
\]

Now compare this with the **terminal-energy Palm** coordinate of P24, whose conditional law is

\[
P_*\{I=i\mid P,z\}=z_i^2.
\tag{6.3}
\]

Relative to the parent-leverage Palm law,

\[
\frac{dP_*}{dP_{\rm par}}(I)
=
\frac{z_I^2}{p_I/r}
=
\boxed{rX_I}.
\tag{6.4}
\]

Thus the terminal-energy Palm law is exactly the `X`-size-biased version of the source-faithful parent Palm law.

For every bounded measurable `f`,

\[
\boxed{
E_*f(X)=rE_{\rm par}[Xf(X)].
}
\tag{6.5}
\]

This is `P14-PARENT-TERMINAL-PALM-SIZEBIAS-35`.

## Recovery of the P24 coverage variable

Y=\frac{p_I-z_I^2}{z_I^2}.

By `(6.1)`,

\boxed{

# 7. Exact Rényi moments under the parent Palm law

\[
J_a(P)
=

\tag{7.1}

\frac{z_i^{2a}}{p_i^{a-1}}

# 8. `P14-RENYI-INTERPOLATION-35` — PROVED

Let `1<=b<=a`. By log-convexity of moments of the nonnegative variable `X`,

\[
E X^b
\le
(E X)^{(a-b)/(a-1)}
(E X^a)^{(b-1)/(a-1)}.
\]

Using `(6.2)` and `(7.2)`,

\[
\begin{aligned}
J_b(P)
&=rE X^b\\
&\le
r
\left(\frac1r\right)^{(a-b)/(a-1)}
\left(\frac{J_a(P)}r\right)^{(b-1)/(a-1)}.
\end{aligned}
\]

The powers of `r` cancel exactly, giving

\[
\boxed{
J_b(P)
\le
J_a(P)^{(b-1)/(a-1)}.
}
\tag{8.1}
\]

The most useful special case is

\[
\boxed{
J_2(P)\le\sqrt{J_3(P)}.
}
\tag{8.2}
\]

No asymptotics, cap estimate, or moment assumption on the source is used in this interpolation; it is a deterministic probability inequality once the parent-Palm representation is formed.

## Annealed version

For ordinary rank-`r` random parents,

\[
E_PJ_2(P)
\le
E_P\sqrt{J_3(P)}
\le
\sqrt{E_PJ_3(P)}.
\tag{8.3}
\]

Thus an annealed `O(r^{-2})` theorem for `J_3` is already enough for an annealed `O(r^{-1})` theorem for `J_2`.

# 9. `P14-SIXTHMOMENT-CLOSURE-35` — PROVED

The preceding interpolation gives the first half immediately:

\[
E_PJ_3(P)\le\frac C{r^2}
\quad\Longrightarrow\quad
E_PJ_2(P)\le\frac{\sqrt C}{r}.
\tag{9.1}
\]

There is also a direct coverage-tail implication.

Under the terminal-energy Palm law, by `(6.5)` and `(6.6)`,

\[
\begin{aligned}
P_*\{Y\le s\mid P\}
&=P_*\left\{X\ge\frac1{1+s}\,\middle|\,P\right\}\\
&=rE_{\rm par}\left[
X\mathbf1\left\{X\ge\frac1{1+s}\right\}\middle|P
\right].
\end{aligned}
\]

For any `a>1`, if `t=(1+s)^{-1}`, then

\[
X\mathbf1_{X\ge t}
\le t^{1-a}X^a.
\]

Therefore

\[
\boxed{
P_*\{Y\le s\mid P\}
\le
(1+s)^{a-1}J_a(P).
}
\tag{9.2}
\]

Taking `a=3`,

\[
\boxed{
P_*\{Y\le s\mid P\}
\le
(1+s)^2J_3(P).
}
\tag{9.3}
\]

Hence if

\[
J_3(P)\le C/r^2,
\]

then

\[
P_*\{Y\le s\mid P\}
\le
C\min\left\{1,\left(\frac{1+s}{r}\right)^2\right\}.
\tag{9.4}
\]

This is exactly P24's relative-coverage criterion with exponent `alpha=2>1`; its layer-cake theorem then gives

\[
J_2(P)=E_*(1+Y)^{-1}\le C'/r.

The same argument works after ordinary-parent averaging.

# 10. Exact Haar calibration

\sim

\sim

\tag{10.2}

J_2^{\rm Haar}(P)=\frac3{r+2}.

This is exactly `Theta(r^{-2})`, so the sixth-moment closure criterion has the correct Haar scale.

which has the required exponent two, though not the exact beta-tail constant.

Write the future `(r-1) x r` matrix as

\[
W=[\delta\mid C],
\]

where rowwise

\[
\delta=\sqrt p\,\xi+\sqrt{1-p}\,\eta.
\]

Conditional on all non-`i` future coordinates, the vector `eta` and the matrix `C` are fixed, while the entries of the vector `xi` are iid with density ceiling `K`.

If `C` is nonsingular, the distinguished null coordinate is

\[
X=\frac1{1+\|C^{-1}\delta\|^2}.
\tag{11.1}
\]

Let `sigma_q(C)` be the `q`th smallest singular value of `C`, and project `delta` onto the `q` left singular directions corresponding to the smallest singular values. The projected `q`-vector of `sqrt(p) xi` has joint density at most

\[
2^{q/2}K^q p^{-q/2}
\]

by the Livshyts--Paouris--Pivovarov marginal-density theorem applied to the independent scalar vector `xi` and scaling by `sqrt p`.

Therefore the standard volume estimate gives, for `s>0`,

\[
\boxed{
P\{\|C^{-1}\delta\|^2\le s
\mid C,\eta,P,I\}
\le
\min\left\{1,
C_{q,K}p^{-q/2}\sigma_q(C)^q s^{q/2}
\right\}.
}
\tag{11.2}
\]

This is a correct conditional small-ball bound. But under the parent-Palm weight, its small-ball branch carries

\[
p\cdot p^{-q/2}=p^{1-q/2}.
\]

For every `q>2` this is a negative power of parent leverage. In Haar-scale adaptive parents, typical individual leverages are small, so `(11.2)` is grossly nonuniform. At `q=2` the leverage singularity disappears but the small-ball exponent is exactly the logarithmic endpoint.

The Gaussian calibration explains the loss: when `p` is small, the discarded term `sqrt(1-p) eta` supplies almost all of the correct Gaussian noise. Treating only `sqrt p xi` throws away the very mechanism that keeps the row isotropic.

Therefore the following route is rejected:

\[
\boxed{
\text{freeze all non-special coordinates, use only the scalar }\sqrt p\xi,
\text{ and sum the resulting cap bound absolutely.}
}
\]

The correct next proof must keep the `(eta,c)` geometry coupled to the hard edge / q=3 numerator.
