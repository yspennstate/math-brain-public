# 5. `P14-ESCORT-KDPP-SURVIVAL-LIFT-39` — PROVED

`a_i=q_i/p_i`,

`F_q=sum_i a_i q_i`.

Let `1<=k<=q-1`. On pairs `(i,S)` with `i in S`, `|S|=k`, define

`Pi_(q,k)(i,S)`

By Section 4.1 this is a probability law. Its distinguished-coordinate marginal is exactly the P24 squared-likelihood escort:

`P{I=i}=a_i q_i/F_q=q_i^2/(p_iF_q)=nu_q(i)`.           (5.2)

Now put

`R'=R-vv^T`,

`q_i'=R'_ii`,

`s_i=q_i'/q_i=1-v_i^2/q_i=1-<w_i,v>^2`.               (5.3)

For a positive-volume `S`, define

`tau_S=det(R'_S)/det(R_S)`.                              (5.4)

Because

`R'_S=R_S-v_Sv_S^T`,

`tau_S=1-v_S^T R_S^(-1)v_S`.                            (5.5)

Let

`W_S=span{R e_j:j in S}`

inside `Ran(R)` and

`L_S=Ran(R) intersect W_S^perp`.

`v_S^T R_S^(-1)v_S=||Proj_(W_S)v||^2`,

`boxed: tau_S=||Proj_(L_S)v||^2`,                       (5.6)

and `dim L_S=q-k`. In particular `0<=tau_S<=1`.

Apply the fixed-coordinate minor identity again to the child projector `R'`, which has rank `q-1`:

`sum_{|S|=k, i in S} det(R'_S)`
`=C(q-2,k-1) q_i'`.                                    (5.7)

`E_(Pi_(q,k))[s_I tau_S]`

`= [1/(C(q-1,k-1)F_q)]`

# 6. `P14-VOLUME-COMPLEMENT-ISOTROPY-39` — PROVED

The DPP complement in Section 5 has an exact first-moment law.

Conditional on `I=i`, the factor `a_i` cancels from (5.1), so `S\{i}` is ordinary volume sampling from the residual tight frame `b_j` in `w_i^perp`.

We use the following deterministic fact.

Let vectors `b_j` form a tight frame in `R^n`, so `sum_j b_jb_j^T=I_n`. Sample an `ell`-subset `T` with probability proportional to

`det(B_T^T B_T)`.

Then

`boxed: E Proj_span(B_T)=(ell/n)I_n`,

and hence

`boxed: E Proj_span(B_T)^perp=((n-ell)/n)I_n`.          (6.1)

A short proof is by differentiating Cauchy-Binet. For any `y`, the sum over `T` of

`det(B_T^T B_T) <y,Proj_span(B_T)y>`

is the first derivative at zero of the `ell`-th elementary symmetric polynomial after the rank-one perturbation `I_n+t yy^T`; it equals

`C(n-1,ell-1)||y||^2`.

Divide by the normalization `C(n,ell)`.

Here `n=q-1` and `ell=k-1`. Thus, in the ambient realization inside `Ran(R)`,

`boxed: E[Proj_(L_S)|I=i,R]`
`       = [(q-k)/(q-1)] (R-w_iw_i^T).`                (6.2)

Since `w_i perp L_S`, for fixed `v`

`E[tau_S|I=i,R,v]`
`= [(q-k)/(q-1)] (1-<w_i,v>^2)`
`= [(q-k)/(q-1)] s_i.                                  (6.3)

Equation (6.3) is consistent with (5.8) and is useful for calibration. It is also a warning: averaging the complement before doing source-row analysis returns the old escort square exactly.

`boxed: Pi_(q,2)(i,j)`

Write

`alpha_i=<w_i,v>`, `alpha_j=<w_j,v>`.

`tau_ij=det(R'_{ij})/det(R_{ij})`

# 9. What the new lift does and does not solve

The main gain is architectural.

Before this run the sharp diagonal mark was an escort-biased same-coordinate square

`E_nu(1-x)^2`.

After this run the same scalar can be represented, for any chosen `k`, through a volume-sampled coordinate geometry whose determinant is carried in the sampling law itself.

Two consequences matter.

1. **Anti-alignment numerator is native.** For `k=2`, the law is weighted by `q_iq_j-R_ij^2`, so the apparent cap denominator cancels exactly before expectation. This is the same numerator-preservation discipline required by the physical off-diagonal sibling theorem.

What is **not** solved is the sharp signed sum. Volume-complement isotropy alone is tautological for this purpose: averaging `S` first gives (6.3) and returns the original escort square. Therefore one must exploit the low-dimensional complement **before** averaging it.

This is `P14-DPP-ISOTROPY-TAUTOLOGY-NOGO-39` — **PROVED route-kill**:

> volume-sampling first-moment isotropy, by itself, cannot sharpen the P14 Rayleigh bound; any successful use of (7.5) must condition on the DPP complement and compare the genuinely fresh source row there before the volume sample is integrated out.

This is not a counterexample to P14.
