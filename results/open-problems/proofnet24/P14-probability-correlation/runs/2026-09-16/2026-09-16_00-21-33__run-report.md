# 5. `P14-ALLRANK-BOUNDED-CHECKPOINT-31` — PROVED

Fix any

\[
1\le r\le d.
\]

Expose `d-r` of the common-future rows among `X_2,...,X_d`. Their orthogonal complement inside `Ran(P)` is a random rank-`r+1` projector `R`. Conditional on `P`, this checkpoint is independent of the distinguished original row `X_1`.

There remain `r-1` future original rows, which we denote

\[
Y_2,\ldots,Y_r.
\]

For the distinguished row put

\[
q_R(U)
=\frac{RU}{\|RU\|}
=\frac{RX_1}{\|RX_1\|}.
\tag{5.1}
\]

The second equality is crucial: because `R<=P`, the checkpoint direction is still generated by the same **genuinely fresh original product row**. No projected-coordinate independence is introduced.

Let

\[
\Lambda_R(X_1,Y_2,\ldots,Y_r)
\]

be the final rank-one projector in `Ran(R)` orthogonal to the projections of these `r` fresh original rows. Define the all-rank checkpoint block

\[
\boxed{
\mathcal K_R^{(r)}
=
\Lambda_R-\frac{R}{r}.
}
\tag{5.2}
\]

## 5.1 Symmetry and pathwise boundedness

The final line depends only on the unordered span of the `r` projected rows. Therefore `mathcal K_R^{(r)}` is symmetric in

\[
X_1,Y_2,\ldots,Y_r.
\]

On the final line its eigenvalue is

\[
1-\frac1r=\frac{r-1}{r},
\]

and on the other `r` dimensions of `Ran(R)` its eigenvalue is `-1/r`. Hence

\[
\boxed{
\|\mathcal K_R^{(r)}\|_F^2
=
\frac{(r-1)^2+r}{r^2}
=
1-\frac1r+\frac1{r^2}
\le1.
}
\tag{5.3}
\]

Also

\[
\boxed{\operatorname{tr}\mathcal K_R^{(r)}=-1/r.}
\tag{5.4}
\]

Thus **every checkpoint rank admits a bounded symmetric block observable**. The earlier rank-three kernel is exactly the case `r=2`, where `(5.3)` gives `3/4`.

## 5.2 First-order block projection equals the local raw reveal

For a fixed checkpoint `R`, let

\[
M_R
=
E[\Lambda_R\mid R]
\]

be the null-line covariance generated by `r` fresh original rows in `Ran(R)`. Given the first checkpoint direction `q`, let

\[
M_{R,q}
=
E[\Lambda_R\mid R,q]
\]

where only the remaining `r-1` rows are averaged.

Define the first-order Hoeffding projection of the bounded block:

\[
\boxed{
h_R^{(r)}(q)=M_{R,q}-M_R.}
\tag{5.5}
\]

The constant `-R/r` in `(5.2)` cancels from this centered first-order projection.

By the tower property and checkpoint independence,

\[
M_{P,U}
=
E_R[M_{R,q_R(U)}\mid P,U],
\]

while

\[
M_P=E_R[M_R\mid P].
\]

Therefore

\[
\boxed{
M_{P,U}-M_P
=
E_R[h_R^{(r)}(q_R(U))\mid P,U].
}
\tag{5.6}
\]

This is an exact all-rank raw-reveal representation.

## 5.3 The inherited sibling-anisotropy checkpoint identity also collapses at every rank

Let

\[
C_r(F_q)=M_{R,q}-\frac{R-qq^\top}{r}
\]

be the rank-`r` child anisotropy inside the rank-`r+1` checkpoint. Since

\[
M_{R,q}-\frac{R}{r}
=E[\mathcal K_R^{(r)}\mid q,R],
\]

we have

\[
C_r(F_q)
=E[\mathcal K_R^{(r)}\mid q,R]+rac{qq^\top}{r}.
\tag{5.7}
\]

Insert `(5.7)` into the inherited checkpoint factorization

\[
\mathcal E_d^P(u,u')
=
E_R[\mathcal E_r^R(q_R(u),q_R(u'))]
-
\left(H_{r|d}^P(u)-H_{r|d}^P(u')\right),
\]

where

\[
H_{r|d}^P(u)=\frac1rE_R[q_R(u)q_R(u)^\top]-\frac{uu^\top}{d}.
\]

The checkpoint projector terms cancel exactly. Define

\[
\boxed{
\Psi_{d,r}^P(u)
=
E_{R,Y_2,\ldots,Y_r}
[\mathcal K_R^{(r)}\mid P,U=u]
+
\frac{uu^\top}{d}.
}
\tag{5.8}
\]

Then

\[
\boxed{
\mathcal E_d^P(u,u')
=
\Psi_{d,r}^P(u)-\Psi_{d,r}^P(u').
}
\tag{5.9}
\]

At `r=2`, `(5.8)` is the previous rank-three span cancellation. At `r=d`, `R=P` and `Psi_{d,d}^P(u)` is exactly the child anisotropy `C_d(P-uu^T)`. At `r=1`, the endpoint is the rank-two full-future normalized-projection representation.

### Consequence

# 8. `P14-TRACEZERO-SUPPORT-REFINED-31` — PROVED

The adjacent checkpoint field in `(7.3)` has extra structure not used by the earlier support-coercivity theorem: it is trace zero. This permits an exact refinement.

Let `H` be an `n`-dimensional real Hilbert space, `n>=2`. Let `V` be a random unit vector and let `A(V)` be a self-adjoint random matrix such that

\[
A(V)V=0,
\qquad
\operatorname{tr}A(V)=0.
\tag{8.1}
\]

Put

\[
K=EA(V),
\qquad
S=E[VV^\top].
\]

Then `tr K=0`. For `K!=0`, define

\[
\boxed{
\Gamma_V(K)
=
\frac{
2\operatorname{tr}(K^2S)
-
\frac{n-2}{n-1}
E(V^\top K V)^2
}{\|K\|_F^2}.
}
\tag{8.2}
\]

## Theorem

\[
\boxed{
E\|A-K\|_F^2
\ge
\Gamma_V(K)
E\|A\|_F^2.
}
\tag{8.3}
\]

If `K=0`, the variance equals `E||A||_F^2`.

### Proof

Let

\[
P_V=I-VV^\top.
\]

Because `A=P_VAP_V` and `tr A=0`, only the trace-zero part of the compression of `K` to `V^\perp` contributes to the Frobenius pairing. Define

\[
B_V
=
P_V K P_V
-
\frac{\operatorname{tr}(P_VKP_V)}{n-1}P_V.
\tag{8.4}
\]

Then

\[
\|K\|_F^2
=E\langle A,K\rangle_F
=E\langle A,B_V\rangle_F.
\tag{8.5}
\]

Since `tr K=0`,

\[
\operatorname{tr}(P_VKP_V)=-V^\top K V.
\]

Also

\[
\|P_VKP_V\|_F^2
=
\|K\|_F^2
-2\|KV\|^2
+(V^\top K V)^2.
\]

Removing the scalar trace component in dimension `n-1` yields

\[
\boxed{
\|B_V\|_F^2
=
\|K\|_F^2
-2\|KV\|^2
+
\frac{n-2}{n-1}(V^\top K V)^2.
}
\tag{8.6}
\]

Averaging `(8.6)`,

\[
E\|B_V\|_F^2
=(1-\Gamma_V(K))\|K\|_F^2.
\]

Cauchy-Schwarz in `(8.5)` gives

\[
\|K\|_F^4
\le
E\|A\|_F^2\,
E\|B_V\|_F^2
=
(1-\Gamma_V(K))
E\|A\|_F^2\|K\|_F^2.
\]

Cancel `||K||_F^2` and subtract from `E||A||_F^2` to obtain `(8.3)`.

The coefficient is automatically in `[0,1]`: nonnegativity follows from `(V^T K V)^2<=||KV||^2`, and the upper bound follows from `E||B_V||^2>=0`.

QED.

## 8.1 Generic frame lower bound

If

\[
S\succeq \lambda I_H,
\]

then

\[
\operatorname{tr}(K^2S)\ge\lambda\|K\|_F^2,
\]

and

\[
E(V^\top K V)^2\le E\|KV\|^2.
\]

Therefore

\[
\boxed{
\Gamma_V(K)
\ge
\frac{n}{n-1}\lambda.
}
\tag{8.7}
\]

This slightly sharpens the previous support-only coefficient `lambda` but is still only a one-unit `1/n` gain.

## 8.2 Exact Haar benchmark

If `V` is Haar on `S^{n-1}`, then for every trace-zero symmetric `K`,

\[
S=I/n,
\]

and

\[
E(V^\top K V)^2
=
\frac{2}{n(n+2)}\|K\|_F^2.
\]

Hence

\[
\boxed{
\Gamma_{\rm Haar}(n)
=
\frac{2n}{(n-1)(n+2)}.
}
\tag{8.8}
\]

This is asymptotic to `2/n`, not `1/n`.

# 9. `P14-ADJACENT-COERCIVE-CONTRACTION-31` — PROVED

Take the adjacent checkpoint in Section 7. Thus the parent `P` has rank

\[
n=d+1,
\]

and one fresh future direction `V` is exposed, leaving

\[
R=P-VV^\top
\]

of rank `d`.

For fixed distinguished `U`, define

\[
A_U(V)
=
h_R^{(d-1)}(q_R(U))
=
M_{R,q_R(U)}-M_R.
\tag{9.1}
\]

Both covariance matrices have trace one and are supported in `R`, so

\[
\operatorname{tr}A_U(V)=0,
\qquad
A_U(V)V=0.
\tag{9.2}
\]

Its `V`-mean is exactly

\[
K_U=E_VA_U(V)=M_{P,U}-M_P.
\tag{9.3}
\]

Thus the refined support theorem applies inside the exact curvature identity.

## 9.1 Uniform finite-variance contraction

The inherited fresh-projection-frame theorem gives, for the normalized projected direction of a genuinely fresh original source row in every frozen rank-`n` parent,

\[
E[VV^\top\mid P]
\succeq
\lambda_n P,
\]

with a nonasymptotic

\[
\lambda_n\ge c_\xi/n
\]

and an asymptotically Haar-sharp lower bound

\[
\lambda_n\ge\frac{1-\varepsilon_n(\xi)}{n},
\qquad
\varepsilon_n(\xi)\to0.
\tag{9.4}
\]

Using `(8.7)` in `(7.3)` before apex averaging gives pointwise in every realized parent:

\[
\boxed{
Q_n(P)
\le
\left(1-rac{n}{n-1}\lambda_n\right)
E_V Q_{n-1}(P-VV^\top).
}
\tag{9.5}
\]

In particular,

\[
Q_n(P)
\le
\left(1-rac{1-\varepsilon_n(\xi)}{n-1}\right)
E_V Q_{n-1}(P-VV^\top).
\tag{9.6}
\]

This is a source-faithful multiplicative contraction requiring only the actual fresh original row.

It is **not sharp enough** to solve P14: its harmonic exponent is one.

## 9.2 Haar factor-of-two calibration

If the fresh direction `V` is Haar in the parent, `(8.8)` gives instead

\[
\boxed{
Q_n(P)
\le
\left(
1-rac{2n}{(n-1)(n+2)}
\right)
E_VQ_{n-1}(P-VV^\top).
}
\tag{9.7}
\]

The factor simplifies to

\[
1-rac{2n}{(n-1)(n+2)}
=
\frac{(n-2)(n+1)}{(n-1)(n+2)}.
\tag{9.8}
\]

Therefore

\[
\prod_{n=3}^{N}
\frac{(n-2)(n+1)}{(n-1)(n+2)}
=
\boxed{
\frac{4}{(N-1)(N+2)}.
}
\tag{9.9}
\]

Starting from the trivial rank-two reveal bound, the refined trace-zero support mechanism alone therefore produces the **sharp `N^{-2}` order** in the Haar angular model.

For the actual fully Gaussian null-line chain the exact reveal is

\[
Q_n^{\rm G}=\frac1{(n-1)n},
\]

and the exact adjacent ratio is

\[
\frac{Q_n^{\rm G}}{Q_{n-1}^{\rm G}}
=
\frac{n-2}{n}
=1-\frac2n.
\]

Thus `(9.7)` has the correct factor-two harmonic mechanism, though not the exact Gaussian constant.

### Interpretation

The earlier support theorem captures only one `1/n` unit because it controls the compression of an arbitrary supported matrix field. The trace-zero refinement shows where the second unit can come from: one must control the angular quadratic leakage

\[
E(V^\top K V)^2.
\]

For Haar directions this leakage is exactly `2||K||_F^2/[n(n+2)]`, which is one order smaller than the frame term `tr(K^2S)=||K||_F^2/n`.

Under arbitrary finite variance, controlling this leakage with a summable Haar-scale error is precisely the hard part. Generic finite-variance CLT rates are unavailable, and the prior support-coercivity sharpness example shows that support geometry alone cannot supply the missing factor.

### 10.1 Mixed almost-square line

Let `M` be `N x (N+1)` with independent centered variance-one scalar entries and a common density ceiling `L`, and let `U` be its unit null line. For fixed integer `p>=2`, P24 claims

\[
E|U_i|^{2p}\le C_{p,L}N^{-p},
\qquad
E\|U\|_{2p}^{2p}\le C_{p,L}N^{1-p}.
\tag{10.1}
\]

Independent check:

1. Delete column `i`, writing `M=[B_i|c_i]`. The exact graph identity gives
   \[
   |U_i|^{2p}=(1+\|B_i^{-1}c_i\|^2)^{-p}.
   \]
2. Freeze `B_i`. Project the genuinely fresh deleted column `c_i` onto the left singular vectors corresponding to the `q=2p+1` smallest singular values. Then
   \[
   \|B_i^{-1}c_i\|^2\ge \|Z\|^2/s_q(B_i)^2.
   \]
3. Livshyts--Paouris--Pivovarov give the joint projected-density ceiling `2^{q/2}L^q`; no projected-coordinate independence is used.
4. Since `q>2p`, the radial integral is subcritical and gives
   \[
   E[|U_i|^{2p}\mid B_i]
   \le C_{p,L}\min\{1,s_q(B_i)^{2p}\}.
   \]
5. Polavarapu--Fernandez give, for fixed `q`,
   \[
   P\{s_q(B_i)>Ct/\sqrt N\}\le e^{-ct}
   \]
   on the whole integration range needed here. Integrating the truncated `2p`-moment gives `O(N^{-p})`.
6. Sum over the `N+1` coordinates to obtain `(10.1)`.

All indexing and truncation are correct. No untruncated high singular-value moment and no source moment above two is used.

# 11. Fresh primary-source verification

## 11.1 Polavarapu--Fernandez, arXiv:2608.30722

Achintya Raya Polavarapu and Manuel Fernandez, *Intermediate Singular Values of Random Matrices under Second-Moment and Anti-Concentration Assumptions*, submitted 2026-08-31.

For an `n x n` matrix with independent, not necessarily identically distributed, real entries satisfying

\[
E\xi_{ij}=0,
\qquad
E\xi_{ij}^2=1,
\qquad
\sup_zP(|\xi_{ij}-z|<a)\le b<1,
\]

the theorem states

\[
P\left\{
s_{n+1-l}(A)>Ct\frac l{\sqrt n}
\right\}
\le
\exp[-c\min\{tl,n\}]
\]

for `t>=1` and `1<=l<=(1-delta)n`, with constants depending only on `a,b,delta`. No moment above variance is assumed.

A scalar density ceiling gives a fixed anti-concentration pair directly.

## 11.2 Livshyts--Paouris--Pivovarov, arXiv:1507.07949

Galyna Livshyts, Grigoris Paouris, Peter Pivovarov, *On sharp bounds for marginal densities of product measures*.

If a product density has one-dimensional factors bounded by one, every `k`-dimensional orthogonal marginal density is bounded by `2^{k/2}`. Scaling a common scalar ceiling `L` gives `2^{k/2}L^k`.

This is a theorem about the **joint density of a projected fresh product vector**. It does not assert that projected coordinates are independent.
