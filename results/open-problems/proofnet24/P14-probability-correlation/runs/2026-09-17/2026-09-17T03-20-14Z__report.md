## 3. Move #15 — BREAK THE SYMMETRY: exact anisotropic star–mesh defect

The preceding report used equal spokes too early. This run keeps the three apex directions separate.

Let `G` have an apex `v` of degree three with neighbors `x,y,z`. Give the spokes `vx,vy,vz` positive weights `a,b,c`. Put `H=G-v`. For any fixed old-edge event (none, `e`, `f`, or `ef`), classify forests of `H` by the connectivity partition induced on `x,y,z`:

- `D`: all three terminals separate;
- `P`: `x~y`, with `z` separate;
- `Q`: `x~z`, with `y` separate;
- `S`: `y~z`, with `x` separate;
- `T`: all three terminals connected.

### Claim `P14-ANISOTROPIC-STAR-MESH-DEFECT-61` — PROVED

Set

\[
r=1+a+b+c,
\qquad
u=\frac{ab}{r},\quad \mu=\frac{ac}{r},\quad \omega=\frac{bc}{r}.
\]

Let `TRIANGLE(nu,mu,omega)` denote the same terminal-state functional after adding a virtual triangle `xy,xz,yz` with those weights. Then, coefficientwise for **every** old-edge event,

\[
\boxed{
\operatorname{STAR}(a,b,c)
=
r\,\operatorname{TRIANGLE}\!\left(\frac{ab}{r},\frac{ac}{r},\frac{bc}{r}\right)
+\frac{abc}{r}\,D.
}
\tag{3.1}
\]

#### Proof

For a forest already in state `D`, every subset of the three spokes is acyclic, hence

\[
S_D=(1+a)(1+b)(1+c).
\]

In state `P`, choosing both `vx` and `vy` closes a cycle, while `vz` remains independent of that prohibition, so

\[
S_P=(1+c)(1+a+b).
\]

Similarly,

\[
S_Q=(1+b)(1+a+c),\qquad
S_S=(1+a)(1+b+c),\qquad
S_T=1+a+b+c=r.
\tag{3.2}
\]

For a virtual triangle with weights `(u,m,w)`, its transfer coefficients are

\[
T_D=1+u+m+w+um+uw+mw,
\]

\[
T_P=1+m+w,\quad
T_Q=1+u+w,\quad
T_S=1+u+m,\quad
T_T=1.
\tag{3.3}
\]

Insert `u=ab/r`, `m=ac/r`, `w=bc/r`. For `P,Q,S,T`, direct expansion gives `S_X=rT_X`. For `D`,

\[
\begin{aligned}
S_D-rT_D
&=\bigl(r+ab+ac+bc+abc\bigr)
 -\left(r+ab+ac+bc+\frac{abc(a+b+c)}r\right)\\
&=\frac{abc}{r}.
\end{aligned}
\]

This proves (3.1). The argument applies identically after imposing any old-edge derivative/event, so it is coefficientwise in the old variables. QED.

### Unit specialization

For the source problem `a=b=c=1`, `r=4` and the virtual triangle has edge weight `1/4`. Hence

\[
\boxed{
\operatorname{STAR}
=4\,\operatorname{TRIANGLE}(1/4,1/4,1/4)+\frac14 D.
}
\tag{3.4}
\]

This is sharper than the preceding binary-mixture representation: it identifies the exact star–mesh approximation and isolates **one positive defect term**, supported only on the all-separated terminal state.

## 4. Move #30 — one direction at a time: the defect is purely mixed second-order curvature

Let

\[

\]

be the forest polynomial of `H` with the three virtual terminal edges added. Because a forest polynomial is multiaffine in every edge variable, changing only one virtual edge field is exactly affine:

\[
(1-\theta)F(u_0,m,w)+\theta F(u_1,m,w)
=F((1-\theta)u_0+\theta u_1,m,w).
\tag{4.1}
\]

So there is **no one-direction mixture obstruction at all**. The first obstruction necessarily appears only when two terminal directions vary together.

From the terminal-state formula (3.3),

\[
\boxed{F_{um}=F_{uw}=F_{mw}=D,\qquad F_{umw}=0.}
\tag{4.2}

Thus the star–mesh defect in (3.1) is exactly the mixed second-order curvature of the terminal triangle polynomial. This gives a much more precise answer to the preceding “common environment” blocker: first-order response is harmless; the entire degree-three difficulty is a two-direction interaction in the all-separated state.

### Claim `P14-UNIT-ENVIRONMENT-NA-OBSTRUCTION-61` — PROVED route obstruction

A tempting proof would represent the normalized unit star `STAR/4` as an average of ordinary **unit** triangle-subgraphs and hope that a pairwise negatively associated environment allows one to inherit the known unit graph theorem. That route is impossible.

Let `X_1,X_2,X_3 in {0,1}` indicate which of the three unit virtual triangle edges are present in a random available subgraph. Matching the three `P,Q,S` transfer coefficients of `STAR/4` forces

\[
\mathbb E X_1=\mathbb E X_2=\mathbb E X_3=\frac14.
\tag{4.3}

Matching the `D` coefficient forces

\[
\sum_{i<j}\mathbb E[X_iX_j]=\frac14.
\tag{4.4}

Therefore every exact availability representation satisfies

\[
\boxed{
\sum_{i<j}\operatorname{Cov}(X_i,X_j)

\tag{4.5}

## 5. Move #19 — MAKE IT AN ALGORITHM: the defect is an ordinary contraction on at most seven vertices

The good news is that the defect `D` is not an exotic terminal statistic.

Let

\[
S=\{vx,vy,vz\}.
\]

The three spokes form an independent set in the graphic matroid. For any old-edge set `R subset E(H)`,

\[
R\text{ has terminals }x,y,z\text{ all separate in }H
\iff R\cup S\text{ is a forest in }G.
\]

By the definition of matroid contraction, this means exactly

\[
\boxed{D(\mathbf y)=I_{M(G)/S}(\mathbf y).}
\tag{5.1}
\]

Graphically, contracting all three spokes identifies `v,x,y,z`. If `G` has ten vertices, the contracted graphic matroid therefore has at most **seven vertices**.

Contraction can create loops and parallel classes. This causes no gap in applying Erickson’s `n<=7` all-positive-weight theorem:

- loops never occur in a forest and can be deleted;
- a parallel class, for target edges outside the class, compresses to one edge whose weight is the sum of the positive parallel weights;
- if the target pair itself lies in one parallel class, the two edges never co-occur, so `I_{ef}=0` and the Rayleigh gap is trivially nonnegative.

Therefore the defect term is already in a **proved all-weight Rayleigh class**.

For a ten-vertex source graph, `Delta_K>=0` is now unconditional by the seven-vertex all-weight theorem. Thus the degree-three old/old problem has been reduced to exactly two terms:
