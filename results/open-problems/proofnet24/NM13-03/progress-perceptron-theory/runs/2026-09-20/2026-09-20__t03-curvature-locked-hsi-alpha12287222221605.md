## 2. New generic theorem — two-sided curvature locks the Stein kernel

Let `nu` have a positive one-dimensional density

`p(x)=Z^{-1} exp[-W(x)]`

with mean `mu`, and assume `W'` is absolutely continuous, the integrations below are justified, and

`0 < lambda <= W''(x) <= Lambda < infinity`

for almost every `x`. Define the canonical Stein kernel

`tau(x)=p(x)^{-1} int_x^infinity (y-mu)p(y)dy`.

The identity `E_nu tau = Var_nu(X)=:v` follows by taking the Stein test function `h(x)=x-mu`.

### Theorem NM03-T03-CURVATURE-LOCKED-STEIN

Under the hypotheses above,

`boxed: 1/Lambda <= tau(x) <= 1/lambda`                         (2.1)

for every `x` at which the density is positive. Consequently

`boxed: Var_nu(tau) <= (1/lambda-v)(v-1/Lambda)`.              (2.2)

In the Gaussian-tilt normalization

`dnu/dgamma = exp(phi)/Z`, `gamma=N(0,1)`,

if `phi` is concave and

`0 <= -phi'' <= K`,

then `lambda=1`, `Lambda=1+K`. Put

`ell=1/(1+K)`, `delta=1-v`.

For the standardized variable `Y=(X-mu)/sqrt(v)` with Stein kernel `T=tau/v`, its Stein discrepancy satisfies

`boxed: S^2:=E(T-1)^2 <= delta(v-ell)/v^2`.                    (2.3)

This strictly improves the preceding generic bound `S^2<=delta/v` whenever `ell>0`, `delta>0`, and the law is non-Gaussian.

### Proof of the pointwise two-sided Stein bound

Since `p'=-W'p` and the tails vanish,

`p(x)=int_x^infinity W'(y)p(y)dy`.

For the upper bound, define

`g_lambda(y)=W'(y)-lambda(y-mu)`.

Then `g_lambda' = W''-lambda >=0`, so `g_lambda` is increasing, and

`E g_lambda(X)=E W'(X)-lambda E(X-mu)=0`.

Therefore every tail integral of `g_lambda` is nonnegative. Indeed an increasing zero-mean function crosses from nonpositive to nonnegative, and before the crossing its tail is minus a nonpositive initial integral, while after the crossing the tail is directly nonnegative. Hence

`(tau(x)-1/lambda)p(x)`
` = -(1/lambda) int_x^infinity g_lambda(y)p(y)dy <=0`.

Thus `tau<=1/lambda`.

For the lower bound define

`g_Lambda(y)=W'(y)-Lambda(y-mu)`.

Now `g_Lambda'<=0`, so it is decreasing and again has mean zero. Every tail integral is therefore nonpositive. The same subtraction gives

`(tau(x)-1/Lambda)p(x)`
` = -(1/Lambda) int_x^infinity g_Lambda(y)p(y)dy >=0`,

hence `tau>=1/Lambda`. This proves (2.1).

Since a random variable `Z` supported on `[a,b]` satisfies

`Var(Z)<= (b-EZ)(EZ-a)`

by `E[(Z-a)(b-Z)]>=0`, applying this to `Z=tau`, `a=1/Lambda`, `b=1/lambda`, and `E tau=v` proves (2.2). In the Gaussian-tilt case `lambda=1`, `Lambda=1+K`, so

`Var(tau)<=delta(v-ell)`.

Standardization divides the Stein kernel by `v`, yielding (2.3). QED.

## 3. Curvature-locked HSI entropy cage

Retain the preceding exact matching-Gaussian decomposition. Let

`G=N(mu,v)`,

`psi(delta)=-delta-log(1-delta)`.

`D(nu||gamma)=[mu^2+psi(delta)]/2 + D(nu||G)`.

`D(Y||gamma) <= (S^2/2) log(1+I(Y||gamma)/S^2)`.

For `Y=(X-mu)/sqrt(v)`, `I(Y||gamma)=v I_G`. Since

`s -> s log(1+I/s)`

is increasing for `s>0`, inserting (2.3) gives the new correction

`C_curv = delta(v-ell)/(2v^2)`
`         * log(1 + v^3 I_G/[delta(v-ell)])`.                 (3.1)

Therefore

`boxed:`
`D(nu||G) <= min {`
`  1/2 log(1+v I_G),`

`}`                                                               (3.2)

with the continuous zero convention if `delta=0` or `v=ell`. The third term is never worse than the preceding Stein-HSI term because its allowed Stein discrepancy is smaller.

This is the new comparison/feasibility lemma used below.
