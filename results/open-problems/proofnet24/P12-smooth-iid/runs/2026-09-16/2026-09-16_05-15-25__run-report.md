\tag{0.10}

## `P12-COLLISION-KL-CRITICAL-42` — NEW / PROVED

Assume \(N_m/m\to\gamma>1\), \(n_m=m+k_m-1\), \(\beta_m=n_m/N_m\), and along a subsequence
\[
q_m\uparrow\beta_m,
\qquad
\chi_m
:=
\frac{r_m-q_m^2}{q_m(1-q_m)}
\to\chi\in[0,1].
\]
Then
\[
\boxed{
I_{q_m,r_m}(\beta_m)
=
\frac{2}{1+\chi}
D(\beta_m\|q_m)\,[1+o(1)].
}
\tag{0.12}
\]
Consequently the all-pairs polynomial multiplicity coefficient is
\[
\boxed{
a(\chi)
=
\min\left\{
2,\,
\frac{1+\chi}{2\chi}
\right\},
}
\tag{0.13}
\]
with the convention \(a(0)=2\). If for some fixed \(\eta>0\)
\[
N_mD(\beta_m\|q_m)
\le
(a(\chi)-\eta)\log m,
\tag{0.14}
\]
then
\[
\boxed{
P\left\{
M_{m,r_m}(A_m)
\le
\sqrt{\frac{n_m}{2}}\,\rho_m
\right\}
\to1.
}
\tag{0.15}
\]

a(\chi)
=
\min\left\{

1+\frac1{2p}
\right\}.

At \(p=\gamma^{-1/2}\), this is exactly
\[
\min\left\{2,1+\frac{\sqrt\gamma}{2}\right\},

the coefficient proved in the preceding run.

## `P12-SAMECLUSTER-HYPERGRAPH-NOGO-42` — NEW / DISPROVED ROUTE

A same-ball \(s\)-column cluster with \(s\ge3\) cannot create a new instability mechanism beyond coordinate pairs. If on at least \(n\) rows all \(s\) entries lie in one radius-\(b\) ball, then on the same rows **every constituent pair** differs by at most \(2b\). Hence one constituent coordinate-difference direction already gives
\[
M_{m,r}(A)\le\sqrt{2n}\,b.
\]
Counting \(\binom ms\) such hyperedges therefore creates a large artificial multiplicity: one successful pair spawns many successful higher hyperedges. The correct next sparse-relation problem must involve genuinely different cluster centers / coefficient patterns, or the actual adaptive high-height null normals; simply increasing the size of a common cluster is not a new route.

# 3. Exact variance normalization

For every scalar \(\sigma\),
\[
\boxed{
M_{m,r}(\sigma A)=|\sigma|M_{m,r}(A).
}
\tag{3.1}
\]
Therefore a fixed nonzero variance scale contributes only
\[
\frac1m\log|\sigma|\to0
\]
to the fixed-surplus statistic.

For the moderate-surplus statistic with \(k_m=r_m+1\), triangular scaling by \(\sigma_m\) contributes exactly
\[
\frac{k_m}{m}\log|\sigma_m|.
\]
Hence the exact exponent-neutral condition is
\[
\boxed{
\frac{k_m}{m}|\log\sigma_m|\to0.
}
\tag{3.2}
\]
Scaling does not remove a nonzero mean.

This distinction remains important below: the collision and row-selection theorems do not require centering, whereas the fourth-moment comparison uses centered variance-one normalization.

# 5. Proof of the collision matching theorem

Let
\[
q=P\{|\xi-\xi'|\le\rho\}.
\]
For a coordinate pair \(e=\{a,b\}\), define
\[
C_e
=
\#\{1\le i\le N:|A_{ia}-A_{ib}|\le\rho\}.
\]
Because rows are iid,
\[
C_e\sim\operatorname{Bin}(N,q).
\]

On \(C_e\ge n\), choose any \(n\) successful rows \(T\) and the unit vector
\[
x_e=\frac{e_a-e_b}{\sqrt2}.
\]
Then
\[
\|(A_T)x_e\|_2^2
=
\frac12
\sum_{i\in T}|A_{ia}-A_{ib}|^2
\le
\frac n2\rho^2.
\]
Hence
\[
\sigma_m(A_T)
\le
\sqrt{\frac n2}\rho,
\]
and therefore
\[
M_{m,r}(A)
\le
\sqrt{\frac n2}\rho.
\tag{5.1}
\]

Now take the disjoint column pairs
\[
\{1,2\},\{3,4\},\ldots.
\]
Their events \(\{C_e\ge n\}\) are independent because they depend on disjoint complete matrix columns. Each has probability \(B_{N,n}(q)\). Thus
\[
P\{\text{some matching pair succeeds}\}
=
1-[1-B_{N,n}(q)]^{\lfloor m/2\rfloor},
\]
and (0.7) follows.

This proof is exact and field-independent.

# 6. Proof of the all-pairs collision theorem

Let \(\mathcal E\) be the \(M_2=\binom m2\) coordinate pairs and define
\[
Z=\sum_{e\in\mathcal E}{\bf1}_{\{C_e\ge n\}}.
\]
Then
\[
EZ=M_2B,
\qquad B=B_{N,n}(q).
\tag{6.1}
\]

Two distinct pair events are independent if their column pairs are disjoint. Two unordered edges sharing one column are counted by
\[
3\binom m3.
\]
Let their joint success probability be \(J\). Then
\[
EZ^2
\le
M_2B+M_2^2B^2+6\binom m3J.
\tag{6.2}
\]
Paley--Zygmund at level zero gives
\[
P\{Z>0\}
\ge
\frac{(EZ)^2}{EZ^2},
\]
which is exactly (0.9).

For a representative overlapping pair \(\{1,2\},\{1,3\}\), define on one row
\[
U={\bf1}_{\{|\xi_1-\xi_2|\le\rho\}},
\qquad
V={\bf1}_{\{|\xi_1-\xi_3|\le\rho\}}.
\]
Then
\[
P(U=1)=P(V=1)=q,
\qquad
P(U=V=1)=r.
\]
Therefore
\[
E e^{\lambda(U+V)}
=
1-2q+r+2(q-r)e^\lambda+re^{2\lambda}.
\tag{6.3}
\]
Across rows the pairs \((U_i,V_i)\) are iid. Hence for every \(\lambda\ge0\),
\[
P\left\{
\sum U_i\ge n,\ \sum V_i\ge n
\right\}
\le
\exp\left[
-2\lambda n
+N\log Ee^{\lambda(U+V)}
\right].
\]
Optimizing gives (0.10)--(0.11).

The representation (0.5) follows by conditioning on \(\xi_1\). Jensen yields \(r\ge q^2\), while \(0\le g_\rho\le1\) gives
\[
\operatorname{Var}(g_\rho(\xi))
\le
q(1-q),
\]
so \(\chi\in[0,1]\).

Write
\[

\qquad

\qquad
\chi=\frac{r-q^2}{v}.
\]
For \(S=U+V\),
\[

and
\[

=2v+2(r-q^2)
=2v(1+\chi).
\tag{7.1}

Let
\[
K(\lambda)=\log Ee^{\lambda S}.
\]
Uniformly with \(q\) in a compact subset of \((0,1)\),
\[

=
2q\lambda
+v(1+\chi)\lambda^2
+O(\lambda^3).
\tag{7.2}
\]
Therefore
\[
2\beta\lambda-K(\lambda)
=
2d\lambda
-v(1+\chi)\lambda^2
+O(\lambda^3).

The maximizing tilt is
\[
\lambda_*

\frac{d}{v(1+\chi)}+O(d^2),

so
\[
I_{q,r}(\beta)
=
\frac{d^2}{v(1+\chi)}+O(d^3).
\tag{7.3}
\]
Meanwhile
\[
D(\beta\|q)
=
\frac{d^2}{2v}+O(d^3).
\tag{7.4}
\]
Thus
\[
\frac{I_{q,r}(\beta)}{D(\beta\|q)}
\to
\frac{2}{1+\chi},
\]
which proves (0.12).

Now suppose
\[
ND(\beta\|q)=a\log m+o(\log m).

\[
B_{N,n}(q)=m^{-a+o(1)}
\tag{7.5}

in the critical regime. Hence
\[
M_2B=m^{2-a+o(1)},

so the first-moment requirement is \(a<2\).

For the shared-column term,
\[
J\le m^{-aR+o(1)},
\qquad

Therefore
\[
\frac{m^3J}{m^4B^2}
