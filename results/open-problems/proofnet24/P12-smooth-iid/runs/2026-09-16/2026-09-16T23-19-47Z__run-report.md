## 4. NEW-METHOD #8 — discretize the three-tier upper proof

The inherited proof can be written as a finite state update rather than as a diffuse collection of pair lemmas.

At a successful marked-row stage, let

- `M_j` = current survivor count;
- `E_j` = medium-pair edge count;
- `B_j` = bad-pair edge count;
- `p` = one-survivor hit scale.

For the complex branch, `p=s^2` and the inherited update is

\[
M_{j+1}\gtrsim s^2M_j,
\qquad
E_{j+1}\lesssim m^6s^4E_j,
\qquad
B_{j+1}\lesssim s^2B_j.
\tag{4.1}
\]

For the real branch, `p=s` and the inherited update is

\[
M_{j+1}\gtrsim sM_j,
\qquad
E_{j+1}\lesssim m^3s^2E_j,
\qquad
B_{j+1}\lesssim sB_j.
\tag{4.2}
\]

Thus both fields have the same abstract state machine: for fixed constants `c,C>0`,

\[
\boxed{
M'\ge cpM,
\qquad
E'\le C m^a p^2 E,
\qquad
B'\le CpB,
}
\tag{4.3}
\]

with `a=6` in the complex branch and `a=3` in the real branch.

This is not a new probabilistic theorem. It is an exact rewrite of the existing stage inequalities. Its advantage is auditability: the medium channel differs from ideal pair thinning only by a polynomial factor, whereas the bad channel loses one power of `p` relative to independent pair thinning. That missing power is exactly where an order-`m` cost can accumulate.

**Outcome:** the upper proof's bookkeeping reduces to one survivor variable and two normalized pair variables.

## 6. NEW-METHOD #10 — derandomize the marked-row selection interface

The constructive proof does not need auxiliary randomness to choose its marked rows. It can be presented as a deterministic algorithm operating on a fixed ordered reservoir of fresh iid rows.

At stage `j`, the current survivor graph and every tested normal are `F_{j-1}`-measurable. Keep that state fixed while scanning unused original rows in their deterministic order. For each fresh row `X_l`, evaluate the deterministic stage-success predicate supplied by the one- and two-normal estimates. Select the **first** row that succeeds; only then update the state and proceed to stage `j+1`.

The only probabilistic contract needed is a uniform conditional success floor

\[
P(I_l=1\mid\mathcal F_{l-1})\ge\rho>0
\tag{6.1}
\]

while the state is waiting for its next success. The probe row remains independent of the frozen past. No independence among the adaptive indicators themselves is asserted or needed.

For any `theta>0`, iterated conditioning gives

\[
E\exp\!\left(-\theta\sum_{l=1}^{L}I_l\right)
\le
(1-\rho+\rho e^{-\theta})^L.
\tag{6.2}
\]

Consequently

\[
P\left\{\sum_{l=1}^{L}I_l<k\right\}
\le
 e^{\theta k}(1-\rho+\rho e^{-\theta})^L.
\tag{6.3}
\]

With a linear reservoir `L=delta m` and `k=o(m)`, choose fixed `theta>0`; the right side is `e^{-c m}` for some `c>0`. Therefore the deterministic first-success procedure supplies the required `k` successful marked rows with exponentially high probability.

This is a proof-interface clarification, not a new least-singular-value theorem. It removes a possible ambiguity: the upper argument requires **predictability + fresh original rows**, not a second randomized selection layer and not independence of the success indicators.

**Outcome:** P26 can audit the adaptive row-selection step as a deterministic measurable algorithm plus the single conditional contract (6.1).
