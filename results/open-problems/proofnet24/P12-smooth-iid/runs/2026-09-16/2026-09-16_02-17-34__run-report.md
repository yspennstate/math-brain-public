# 4. Exact row-selection lower tail

Let \(A\in\mathbb F^{N\times m}\) have iid rows \(R_1,\ldots,R_N\), and let
\[
n=m+r=m+k-1\le N.
\]
Fix a deterministic unit vector \(x\in\mathbb F^m\) and put
\[
q_x(a)=P\{|R_1x|\le a\}.
\tag{4.1}
\]
Let
\[
C_x(a)=\#\{i\le N:|R_i x|\le a\}.
\]
By original-row independence,
\[
C_x(a)\sim\operatorname{Bin}(N,q_x(a)).
\tag{4.2}
\]
On the event \(C_x(a)\ge n\), choose any set \(T\) of \(n\) successful rows. Then
\[
\|A_Tx\|_2^2
=\sum_{i\in T}|R_ix|^2
\le na^2.
\tag{4.3}
\]
Since \(\|x\|_2=1\),
\[
\sigma_m(A_T)\le\sqrt n\,a.
\tag{4.4}
\]
Taking the minimum over candidate row sets,
\[
M_{m,r}^{\mathbb F}(A)\le\sqrt n\,a.
\tag{4.5}
\]
Hence
\[
P\{M_{m,r}^{\mathbb F}(A)\le\sqrt n\,a\}
\ge B_{N,n}(q_x(a)).
\tag{4.6}
\]
The map \(q\mapsto B_{N,n}(q)\) is continuous and increasing. Choose a sequence of unit vectors \(x_j\) for which \(q_{x_j}(a)\uparrow\mathcal A_m(a)\). Taking the supremum in `(4.6)` proves `(0.4)`.

This proof is identical in the real and complex fields. It uses the original row product structure only to obtain independence **between rows**; it does not treat projected coordinates as independent.
