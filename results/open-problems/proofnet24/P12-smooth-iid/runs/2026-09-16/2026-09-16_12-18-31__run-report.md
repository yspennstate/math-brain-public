## 2.3 Exact variance normalization

For every scalar `sigma`, singular-value homogeneity gives

\[
\boxed{
M_{m,r}(\sigma A)=|\sigma|M_{m,r}(A).
}
\tag{2.1}
\]

For nonzero triangular scales `sigma_m` and `k_m=r_m+1`,

\[
\frac{k_m}{m}\log M_{m,r_m}(\sigma_mA_m)
=
\frac{k_m}{m}\log M_{m,r_m}(A_m)
+
\frac{k_m}{m}\log|\sigma_m|.
\tag{2.2}

Hence a rescaling is exponent-neutral exactly under

\[
\boxed{
\frac{k_m}{m}|\log|\sigma_m||\to0.

\tag{2.3}

For a fixed variance `sigma^2>0`, `(2.3)` is automatic because `k_m=o(m)` in the moderate-surplus regime. For varying variance it is not automatic. Scaling changes the mean by multiplication and **does not center a noncentered law**.

# 5. `P12-GLOBAL-REGHS-CANDIDATES-49` — full proof

This is the main new argument.

## 5.1 Statement

Let

\[
A_m=(R_1,\ldots,R_{N_m})^T\in\mathbb F^{N_m\times m},
\qquad
\mathbb F\in\{\mathbb R,\mathbb C\},
\]

have independent identically distributed rows satisfying

\[
E\|R_i\|_2^2=m.
\tag{5.1}
\]

Assume for all large `m`

\[
\frac{N_m}{n_m}\le\Gamma_+<\infty,
\qquad
n_m=m+k_m-1.
\tag{5.2}
\]

Fix `kappa>e`. Then there are constants `H=H(kappa,Gamma_+)` and `c=c(kappa,Gamma_+)>0` such that, except on an event of probability at most `e^{-c n_m}`, all of the following hold simultaneously:

- every row set `T subset [N_m]` with `|T|=n_m`;
- every deleted coordinate `j in [m]`;
- every matrix obtained from `(A_m)_{T,-j}^T` by deleting any subset of its coordinate rows;

has

\[
\boxed{
\mathcal B_\kappa(B)\le Hmn_m.
}
\tag{5.3}
\]

The result is field-independent and uses no centering, density, fourth moment, tail, smoothness, arithmetic, or operator norm.

## 5.2 One global weight vector

Define

\[
Y_i:=\frac{\|R_i\|_2^2}{m},
\qquad EY_i=1.
\tag{5.4}
\]

Choose a fixed truncation height `H>1` and set

\[
\alpha_i
:=
\min\left\{1,\sqrt{\frac H{Y_i}}\right\},
\tag{5.5}
\]

with the convention `alpha_i=1` when `Y_i=0`. Put

\[
W_i:=-\log\alpha_i
=\frac12\log_+\frac{Y_i}{H}.
\tag{5.6}
\]

Two deterministic facts are immediate:

\[
\alpha_i^2\|R_i\|_2^2
\le Hm,
\tag{5.7}
\]

and

\[
\prod_{i\in T}\alpha_i
=
\exp\left[-\sum_{i\in T}W_i\right].
\tag{5.8}
\]

## 5.3 Exponential control from only the second moment

Although `Y_i` may be arbitrarily heavy-tailed, `W_i` is logarithmic. In fact

\[
e^{2W_i}
=
\max\left\{1,\frac{Y_i}{H}\right\}
\le
1+\frac{Y_i}{H}.
\]

Therefore

\[
Ee^{2W_i}\le1+\frac1H.
\tag{5.9}
\]

By Chernoff,

\[
\begin{aligned}
P\left\{\sum_{i=1}^{N_m}W_i>n_m\log\kappa\right\}
&\le
\exp[-2n_m\log\kappa]
\left(1+\frac1H\right)^{N_m}\\
&\le
\exp\left[
-2n_m\log\kappa
+\Gamma_+n_m\log(1+H^{-1})
\right].
\end{aligned}
\tag{5.10}
\]

Choose `H` so large that

\[
\Gamma_+\log(1+H^{-1})\le\log\kappa.
\tag{5.11}
\]

Then

\[
P\left\{\sum_iW_i>n_m\log\kappa\right\}
\le
\kappa^{-n_m}.
\tag{5.12}
\]

This is the shared good event `G_m`.

## 5.4 Every candidate is controlled on the same event

On `G_m`, for any `T` with `|T|=n_m`,

\[
\sum_{i\in T}W_i
\le
\sum_{i=1}^{N_m}W_i
\le
n_m\log\kappa.
\]

Hence

\[
\prod_{i\in T}\alpha_i\ge\kappa^{-n_m},
\tag{5.13}
\]

so the restricted weight vector belongs to `Omega_kappa` in Fernandez's Definition 5.5.

Let

\[
B=(A_m)_{T,-j}^T.
\]

Its columns are precisely the selected original rows with coordinate `j` removed. Therefore

\[
\|R_i^{(-j)}\|_2\le\|R_i\|_2.
\]

Using the restricted global weights in the variational definition `(4.1)`,

\[
\begin{aligned}
\mathcal B_\kappa(B)
&\le
\sum_{i\in T}\alpha_i^2\|R_i^{(-j)}\|_2^2\\
&\le
\sum_{i\in T}\alpha_i^2\|R_i\|_2^2\\
&\le
Hmn_m.
\end{aligned}
\tag{5.14}
\]

This proves `(5.3)` for every candidate and every deleted coordinate at once.

If coordinate rows are further deleted from `B`, all column norms can only decrease, so the same weights continue to prove `(5.3)`. This monotonicity is exactly what is needed for the `Q_i` and `Q_i|Y` matrices appearing in the recursion in Fernandez Theorem 6.4.

## 5.5 Why this is stronger than a global operator-norm truncation

A rare row with enormous norm is not discarded. It receives a small weight

\[
\alpha_i\asymp \|R_i\|_2^{-1}
\]

and costs only

\[
W_i\asymp\log\|R_i\|_2.
\]

The second moment is enough to make the **sum of logarithmic costs** exponentially controlled. This is fully compatible with P13's retained rare-spike theorem showing that uniform fourth moment does not give an exponentially reliable full operator-norm bound.

Status of `P12-GLOBAL-REGHS-CANDIDATES-49`: **PROVED**.

# 6. Deterministic replacement of the Fernandez per-candidate HS failure

Let `B` be any matrix in the candidate recursion. By `(5.14)`,

\[
\mathcal B_3(B)\le Hmn_m.
\tag{6.1}
\]

Fernandez Lemma 5.6 therefore gives, for a resolution parameter `epsilon'`,

\[
\|B(x-y)\|_2
\le
\epsilon'\sqrt{\frac{Hmn_m}{n_m}}
=
\epsilon'\sqrt{Hm}.
\tag{6.2}
\]

Because the row dimension of the candidate transpose is `m-1 asymp m`, choosing

\[
\epsilon'=c_H\epsilon
