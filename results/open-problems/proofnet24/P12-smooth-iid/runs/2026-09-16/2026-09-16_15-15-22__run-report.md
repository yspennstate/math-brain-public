# 5. Exact variance-normalization argument

For any scalar `sigma != 0` and every row index set `T`,

\[
\sigma_{\min}((\sigma A)_T)
=|\sigma|\,\sigma_{\min}(A_T).
\]

Taking the minimum over candidate row sets gives the exact identity

\[
\boxed{
M_{m,r}(\sigma A)=|\sigma|M_{m,r}(A).
}
\tag{5.1}
\]

For a fixed law with variance `sigma^2>0`, replacing `xi` by `xi/sigma` therefore changes `m^{-1}\log M` only by `m^{-1}\log|sigma|`, which vanishes.

For a triangular variance scale `sigma_m`, the moderate-surplus statistic changes by

\[
\frac{k_m}{m}\log|\sigma_m|.
\]

Therefore the exact exponent-neutral condition is

\[
\boxed{
\frac{k_m}{m}|\log|\sigma_m||\to0.
}
\tag{5.2}
\]

This condition is both sufficient and, at the level of a scale-uniform exponent statement, exactly what scalar normalization contributes. It says nothing about centering: a nonzero mean is not removed by multiplying by a scalar.

There is one additional bookkeeping point that belongs in the corrected theorem statement. If `Y=xi/sigma` in real dimension `d_F`, then its density scales by `|sigma|^{d_F}`, hence

\[
\boxed{
\|(f_Y)^{*q}\|_\infty
=|\sigma|^{d_{\mathbb F}}
\|f_\xi^{*q}\|_\infty.
}
\tag{5.3}
\]

Thus the clean triangular theorem is stated after variance normalization and requires the uniform finite-convolution ceiling after that normalization. There is no hidden assumption that normalization preserves a fixed density ceiling for free.
