# 3. Exact variance normalization

For every scalar `sigma`, singular values scale homogeneously, hence

\[
\boxed{M_{m,r}(\sigma A)=|\sigma|M_{m,r}(A).}
\tag{3.1}
\]

For a fixed nonzero variance scale this changes `m^{-1}log M` by `o(1)`.

For triangular scales `sigma_m`, with `k_m=r_m+1`, the normalized moderate-surplus statistic changes by

\[
\frac{k_m}{m}\log|\sigma_m|.
\]

Thus the exact exponent-neutral condition is

\[
\boxed{\frac{k_m}{m}|\log\sigma_m|\to0.}
\tag{3.2}
\]

Scaling does **not** remove a nonzero mean. A fourth-moment budget before normalization should therefore be formulated through the invariant standardized centered quantity

\[
\frac{E|\xi_m-E\xi_m|^4}{(\operatorname{Var}\xi_m)^2}.
\]

The bounded-fourth results below are stated after centering and variance-one normalization.

# 7. Fourth moment supplies the Fernandez unit-scale UAC hypothesis

Let `xi` be centered real with

\[
E\xi^2=1,
\qquad E\xi^4\le B.
\]

Let `xi'` be an independent copy and put `Z=xi-xi'`. Then

\[
EZ^2=2,
\qquad
EZ^4=2E\xi^4+6(E\xi^2)^2\le2B+6.
\tag{7.1}
\]

Apply Paley--Zygmund to `Z^2` at one half of its mean:

\[
\mathbb P\{|Z|\ge1\}
\ge
\frac{(1-1/2)^2(EZ^2)^2}{EZ^4}
\ge
\frac1{2B+6}.
\tag{7.2}
\]

Define the open-ball concentration function

\[
Q_\xi^{<}(r)=\sup_z\mathbb P\{|\xi-z|<r\}.
\]

If two independent copies both lie in the same radius-`1/2` open ball, then `|Z|<1`. Hence

\[
(Q_\xi^{<}(1/2))^2
\le
1-\frac1{2B+6},
\]

so

\[
\boxed{
Q_\xi^{<}(1/2)
\le
b_B:=\sqrt{1-\frac1{2B+6}}<1.
}
\tag{7.3}
\]

For

\[
Y=2\xi,
\]

we have the exact Fernandez radius-one UAC bound

\[
\sup_z\mathbb P\{|Y-z|<1\}\le b_B.
\tag{7.4}
\]

For an `m x (m-d)` matrix of `Y` entries,

\[
E\|A\|_{HS}^2=4m(m-d),
\]

so the Hilbert--Schmidt assumption holds with a fixed `K=4`. A generic probe row has `E||Y||_2^2=4m`, which is far below the allowed `O(m^2)` second-moment ceiling for all large `m`.

Finally RLogLCD scales exactly. For any scalar `c>0`,

\[
\boxed{
\operatorname{RLogLCD}^{cX}_{L,u}(v)
=
\frac1c
\operatorname{RLogLCD}^{X}_{L,u/c}(v).
}
\tag{7.5}
\]

Indeed, with `s=c theta`, the lattice-distance term becomes the one for `X` at parameter `s`, while

\[
\log_+\left(\frac{u\theta\|v\|}{L}\right)
=
\log_+\left(\frac{(u/c)s\|v\|}{L}\right).
\]

Thus applying Fernandez to `Y=2X` gives an equivalent high-RLogLCD statement for the original normalized law after replacing `u` by `u/2` and multiplying the lower bound by two.

# 8. Candidate entropy: `P12-CANDIDATE-ENTROPY-H-47`

Let

\[
N_m/m\to\Gamma>1,
\qquad
D_m=O(m/\log m).
\]

Then

\[
\boxed{
\log\left(
\sum_{d=1}^{D_m}\binom{N_m}{m-d}
\right)
=h(\Gamma)m+o(m).
}
\tag{8.1}
\]

Proof: uniformly for `1<=d<=D_m`,

\[
\frac{m-d}{m}=1+o(1).
\]

Uniform Stirling gives

\[
\frac1m\log\binom{N_m}{m-d}
=
\frac{N_m}{m}
H\left(\frac{m-d}{N_m}\right)+o(1),
\]

where `H(p)=-p log p-(1-p)log(1-p)`. By uniform continuity on a compact subinterval of `(0,1)`,

\[
\frac{N_m}{m}
H\left(\frac{m-d}{N_m}\right)
\to
\Gamma H(1/\Gamma)
=h(\Gamma)
\]

uniformly over the stated `d` range. The number of `d` values is only polynomial, so its logarithm is `o(m)`. A single term, say `d=1`, gives the matching lower bound. This proves `(8.1)`.

The appearance of the **same entropy `h(Gamma)`** as in the least-singular-value source exponent is therefore exact, not heuristic.
