# 4. Proof of `P12-POWERCONC-LOG-UI-37`

Assume
\[
N_m/m\to\gamma>1,
\qquad
k_m\log m=o(m),
\]
and `(0.6)`--`(0.7)`.

Set
\[
n_m=m+k_m-1,
\qquad
Z_m=-\frac{k_m}{m}\log M_{m,r_m}^{\mathbb F}.
\]

We prove positive-tail uniform integrability and then control the opposite logarithmic tail.

## 4.1 Positive logarithmic tail

For \(u>0\), put
\[
\tau=e^{-um/k_m},
\qquad
t=\sqrt{\frac m{k_m}}e^{-um/k_m}.
\tag{4.1}
\]
Then
\[
\{Z_m\ge u\}
=
\{M_{m,r_m}^{\mathbb F}\le\tau\}.
\]

For every fixed sufficiently large \(u\), and then all sufficiently large \(m\), we have \(t\le1\). Applying `(3.1)` or `(3.2)` and `(0.6)` gives
\[
P\{Z_m\ge u\}
\le
C_0m\binom{N_m}{n_m}
(C_{\mathbb F}A_m)^ {k_m}
\left(
\sqrt{\frac m{k_m}}
\,e^{-um/k_m}
\right)^{\alpha k_m}.
\tag{4.2}
\]

Equivalently,
\[
\log P\{Z_m\ge u\}
\le
-\alpha um
+
\log C_0+\log m+\log\binom{N_m}{n_m}
+k_m\log(C_{\mathbb F}A_m)
+
\frac{\alpha k_m}{2}\log\frac m{k_m}.
\tag{4.3}
\]

Now
\[
\log\binom{N_m}{n_m}
=h(\gamma)m+o(m),
\tag{4.4}
\]
and
\[
k_m\log A_m=o(m),
\qquad
k_m\log m=o(m).
\]
Therefore there is a deterministic sequence \(a_m\to h(\gamma)\) such that
\[
P\{Z_m\ge u\}
\le
\min\{1,\exp[(a_m-\alpha u)m]\}
\tag{4.5}
\]
whenever the concentration estimate is invoked at \(t\le1\).

Choose \(m_0\) so that
\[
a_m\le h(\gamma)+1
\qquad(m\ge m_0),
\]
and set
\[
R_0=\frac{2(h(\gamma)+1)}\alpha.
\tag{4.6}
\]
For every \(m\ge m_0\) and every \(u\ge R_0\),
\[
P\{Z_m\ge u\}
\le
\exp\left[-\frac{\alpha}{2}um\right].
\tag{4.7}
\]
The same exponential-in-\(u\) tail holds individually for each of the finitely many \(m<m_0\), because `(4.2)` has a finite prefactor and the term \(e^{-\alpha um}\) dominates as \(u\to\infty\).

Fix any \(s\ge1\). Tail integration gives
\[
E[(Z_m^+)^s\mathbf1_{\{Z_m>R\}}]
=
R^sP\{Z_m>R\}
+
\int_R^\infty s u^{s-1}P\{Z_m>u\}\,du.
\tag{4.8}
\]
Using `(4.7)` for \(m\ge m_0\), and the finite-set bounds for \(m<m_0\), the right side tends to zero uniformly in \(m\) as \(R\to\infty\). Hence
\[
\boxed{
\{(Z_m^+)^s\}_m\text{ is uniformly integrable.}
}
\tag{4.9}
\]

This step is where the new scalar-Lévy extreme bound has a payoff beyond convergence in probability: the candidate entropy costs only \(h(\gamma)m+o(m)\), while any fixed positive scalar concentration dimension \(\alpha\) produces an arbitrarily strong tail once \(u\) is large.

## 4.2 Opposite logarithmic tail

The event \(Z_m<0\) means \(M_{m,r_m}>1\). Choose any deterministic candidate row set \(T_0\) of size \(n_m\). Then
\[
M_{m,r_m}
\le
\sigma_m((A_m)_{T_0})
\le
\|(A_m)_{T_0}\|_F.
\tag{4.10}
\]
Therefore
\[
Z_m^-
\le
\frac{k_m}{m}
\log^+\|(A_m)_{T_0}\|_F.
\tag{4.11}
\]

Let
\[
W_m=\|(A_m)_{T_0}\|_F.
\]
Under the uniform second-moment ceiling,
\[
EW_m^2\le C_2n_mm=O(m^2).
\tag{4.12}
\]
Put
\[
L_m=\log(1+W_m).
\]
For \(x\ge\log2\), Markov gives
\[
P\{L_m>x\}
=P\{W_m>e^x-1\}
\le
4EW_m^2e^{-2x}
\le
C m^2e^{-2x}.
\tag{4.13}
\]
Splitting the tail integral at \(x\asymp\log m\) yields, for every fixed \(s\ge1\),
\[
EL_m^s=O_s((\log m)^s).
\tag{4.14}
\]
Consequently, by `(4.11)`,
\[
E(Z_m^-)^s
\le
\left(\frac{k_m}{m}\right)^s
O_s((\log m)^s)
\to0
\tag{4.15}
\]
because \(k_m\log m=o(m)\).

Thus
\[
\boxed{E(Z_m^-)^s\to0.}
\tag{4.16}
\]

## 4.3 Upgrade from probability to \(L^s\)

Assume now
\[
Z_m\to_{\mathbb P}c>0.
\]
Then
\[
Z_m^+\to_{\mathbb P}c.
\]
By `(4.9)`, \(\{|Z_m^+-c|^s\}\) is uniformly integrable, so Vitali's theorem gives
\[
E|Z_m^+-c|^s\to0.
\tag{4.17}
\]
Using
\[
|Z_m-c|
\le
|Z_m^+-c|+Z_m^-,
\]
`(4.16)` and `(4.17)` imply
\[
\boxed{E|Z_m-c|^s\to0.}
\]

This proves `P12-POWERCONC-LOG-UI-37`.

# 5. Fixed finite convolution supplies the required scalar power law

\le

\[

\le

\[
Q_\xi^{\mathbb C}(t)^q
\le

\tag{5.4}

\frac1{2B+6}.
\tag{8.4}
\]

For any \(z\in\mathbb R\), put
\[
p=P\{|\xi-z|<1/2\}.
\]
If both iid copies lie in that interval, then \(|\xi-\xi'|<1\). Hence
\[
p^2
\le
P\{|Z|<1\}
\le
1-\frac1{2B+6}.
\tag{8.5}
\]
Taking square roots and then the supremum over \(z\) proves `(8.1)`.

Every quantifier and constant checks. The strict/open endpoint causes no problem because the implication “both copies in the open radius-\(1/2\) interval \(\Rightarrow |Z|<1\)” is exact.

The claim gives one common UAC pair from a **uniform** fourth-moment ceiling, but only at a fixed macroscopic radius. It does not imply source-scale scalar concentration, and therefore it does not contradict the narrow-lattice counterexamples or the need for actual random-subspace geometry in P13's fixed-candidate theorem.
