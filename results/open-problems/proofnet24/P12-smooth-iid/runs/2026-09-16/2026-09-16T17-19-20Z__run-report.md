# 5. Move #20 — FIND WHY THE ALGORITHM FAILS

The constructive upper extreme can be viewed as an algorithm.

1. Build a large family of base `(m-1)`-row hyperplanes from a base iid row pool.
2. Keep useful normals.
3. Classify pairs as ordinary / medium / bad by geometry already determined by the base pool.
4. Feed unused original iid rows one at a time.
5. At each row, retain normals whose scalar product with the fresh row is at most `s`.
6. Continue until `k_m` marked rows have succeeded.

The obvious failure mode is a filtration violation: if the current normal may depend on the row used to test it, then the microscopic laws become false.

## 5.1 Exact adversarial quantifier counterexample

Let `X` be any random row in `F^m`, `m>=2`, with `P{X=0}<1`. There is a measurable rule choosing a unit `u(X)` orthogonal to `X` on `X!=0` (fix any deterministic unit vector on the zero event). Then

\[
\boxed{
P\{|\langle X,u(X)\rangle|\le s\}=1
\quad\text{for every }s>0.
}
\tag{5.1}
\]

Thus a deterministic-uniform estimate

\[
\sup_{u\in\mathcal U}
P\{|\langle X,u\rangle|\le s\}
\le Cs^{d_F}
\tag{5.2}
\]

does **not** imply `(5.2)` after replacing `u` by an arbitrary `X`-measurable choice. This counterexample is distribution-independent and shows exactly what any valid staging proof must prevent.

## 5.2 The canonical P12 proof survives this attack

The actual staging record is

`proofnet24/P12-smooth-iid/runs/2026-09-15/2026-09-15_13-33-07__run-report.md`,

creation commit `7bdfb3784cf1f65b96782b26bd744f819d6fa590`, blob `ec89bf94e512d1b17134813d75f8c9392a3d4cc4`.

Its filtration is safe in the needed direction:

- the base family and pair graph are functions of the base pool;
- after stage `j-1`, the current survivor family is measurable with respect to the base pool plus the already exposed marked rows;
- the next unused marked row is an original iid row disjoint from all that data;
- one-normal and pair estimates are uniform for every deterministic current normal/pair, so they apply conditionally on the past.

The correct quantifier is therefore

\[
\boxed{
\forall\,\mathcal F_{j-1}\text{-measurable }u,
\quad
P\{ |\langle X_j,u\rangle|\le s\mid\mathcal F_{j-1}\}
\asymp s^{d_F},
}
\tag{5.3}
\]

where `X_j` is independent of `F_{j-1}`. It is **not** “there exists one event on which every possible adaptive `u` obeys a small-ball law.”

The same distinction applies to pairs. Once the current pair `(u,v)` is frozen by the past, the next marked row is fresh; the pair small-ball law is then applied conditionally with deterministic pair geometry.

This is the most important end-to-end audit point for P26/P11. An audit that checks the scalar density estimate but not the filtration is incomplete.
