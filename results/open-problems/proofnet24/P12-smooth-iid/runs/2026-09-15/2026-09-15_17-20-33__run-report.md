## Advance A — exact endpoint obstruction for triangular families

A universal triangular theorem with only

- smooth absolute continuity at each level,
- centered variance one,
- uniform compact support,
- uniform subgaussian tails,
- uniformly bounded moments of every order,

but **without one uniform microscopic density/anti-concentration condition**, is false.

The new mechanism is elementary and sharp: if one coordinate law places mass \(p>\gamma^{-1/2}\) in a ball of radius \(a_m\), then with high probability there are enough rows on which the first two matrix columns both lie in that ball. Selecting those rows makes columns 1 and 2 almost equal.

This gives:

\[
P\{|\xi_m-z_m|\le a_m\}\ge p,

\[

M_{m,r_m}(A_m)
\le
\sqrt{2(m+r_m)}\,a_m
\right\}
\to1

\[

\[

This theorem needs no density assumption.

Let \(\mathbb F=\mathbb R\) or \(\mathbb C\).

\[
\boxed{

}
\tag{4.1}
\]

Assume

\[
\boxed{
\gamma p^2>1.
}
\tag{4.2}
\]

Let

\[
C_m
=
\#\left\{
1\le i\le N_m:
|A_{i1}-z_m|\le a_m,\ 
|A_{i2}-z_m|\le a_m
\right\}.
\]

The two coordinates in one row are independent, so

\[
C_m
\succeq
\operatorname{Bin}(N_m,p^2)
\]

in the exact sense that the defining row event has probability at least \(p^2\).

Because

\[
k_m\log m=o(m)
\]

implies \(k_m=o(m)\),

\[
\frac{m+r_m}{N_m}
=
\frac{m+k_m-1}{N_m}
\to
\frac1\gamma
<
p^2.
\]

A binomial Chernoff bound gives some \(c=c(\gamma,p)>0\) such that

\[
\boxed{
P\{C_m<m+r_m\}
\le e^{-cm}
}
\tag{4.3}
\]

for all large \(m\).

On the event

\[
C_m\ge m+r_m,
\]

choose a row set \(T\) of size \(m+r_m\) among these rows.

Let

\[
x
=
\frac{e_1-e_2}{\sqrt2}.
\]

For every selected row,

\[
|(A_Tx)_i|
=
\frac{|A_{i1}-A_{i2}|}{\sqrt2}
\le
\sqrt2\,a_m.
\]

Therefore

\[
\|A_Tx\|_2
\le
\sqrt{2(m+r_m)}\,a_m.
\]

Since \(\|x\|_2=1\),

\[
\sigma_m(A_T)
\le
\sqrt{2(m+r_m)}\,a_m.
\]

Hence:

# 5. New smooth compactly-supported triangular counterexample

The preceding obstruction can occur even when every entry law is smooth, bounded and subgaussian at the **tail** level.

Fix \(\gamma>1\).

Choose

\[
p\in(\gamma^{-1/2},1).
\tag{5.1}
\]

Let \(d_{\mathbb F}=1\) in the real field and \(d_{\mathbb F}=2\) in the complex field.

Choose two centered \(C^\infty\), compactly supported probability densities:

\[
\psi_0,\psi_1
\]

on \(\mathbb F\), both supported in the unit ball, with positive second moments

\[
v_0=E|U|^2>0,
\qquad
v_1=E|V|^2>0.
\]

Let

\[
\delta_m=e^{-m^2}.
\tag{5.2}
\]

Define

\[
a_m^2
=
\frac{
1-p\delta_m^2v_0
}{
(1-p)v_1
}.
\tag{5.3}
\]

For all sufficiently large \(m\), \(a_m\) is real, positive, and bounded above and below by fixed constants.

Define the entry law by the mixture

\[
\xi_m
=
\begin{cases}
\delta_m U,&\text{with probability }p,\\
a_m V,&\text{with probability }1-p.
\end{cases}
\tag{5.4}
\]

Its density is

\[
f_m(x)
=
p\,\delta_m^{-d_{\mathbb F}}
\psi_0(x/\delta_m)
+
(1-p)\,a_m^{-d_{\mathbb F}}
\psi_1(x/a_m).
\tag{5.5}
\]

## Exact properties

### Centering

Both components are centered, so

\[
E\xi_m=0.
\]

### Variance

By `(5.3)`,

\[
E|\xi_m|^2
=
p\delta_m^2v_0
+
(1-p)a_m^2v_1
=
1.
\tag{5.6}
\]

### Smooth absolute continuity

Each \(f_m\) is \(C^\infty\) and compactly supported.

### Uniform compact support

Because \(a_m=O(1)\), there is fixed \(R<\infty\) with

\[
|\xi_m|\le R
\]

almost surely for every large \(m\).

Hence the family has:

- one uniform subgaussian norm;
- uniformly bounded moments of every order;
- in particular one uniform fourth-moment bound.

### Missing property

The density ceiling is not uniform:

\[
\|f_m\|_\infty
\gtrsim
\delta_m^{-d_{\mathbb F}}
=
e^{d_{\mathbb F}m^2}.
\]

No fixed finite-convolution ceiling can remain uniform either, because the all-central mixture component remains concentrated at scale \(\delta_m\).

### Microscopic mass

The central component is supported in

\[
B(0,\delta_m),
\]

so

\[
P\{|\xi_m|\le\delta_m\}\ge p.
\]

Apply Section 4.

## `P12-SMOOTH-NARROWSPIKE-TRIANGULAR-CE-30` — NEW / PROVED

For either field,

\[
\boxed{
P\left\{
M_{m,r_m}(A_m)
\le
\sqrt{2(m+r_m)}\,e^{-m^2}
\right\}
\to1.

\tag{5.7}

Consequently,

\tag{5.8}

in the high-probability upper-bound sense; the identical conclusion holds for the complex statistic.

A **uniform microscopic density/smoothing/anti-concentration hypothesis is genuinely necessary** for triangular-family universality.
