## 4. B11 — dualize: the correct rank-62 objective is clique-cover hardness

For every two-distance eigenspace representation used here, adjacent graph vertices are at the shorter distance and nonadjacent vertices are at the diameter. Consequently

`B(S) = theta(G[S]) = chi(complement(G[S]))`,

where `theta` is vertex clique-cover number. A dimension-62 spectral embedding can move `U_B` only if the resulting near graph has `theta >= 64`.

The B1 examples show why point count and spectral rank are not enough:

### 5.1 Exact geometry

Let `A` be the adjacency matrix of `G_2(4)` with eigenvalues `100,20,-4`, and let `E` be the orthogonal projector onto its 65-dimensional `20`-eigenspace `C`. The spectral projector is

`E = (A + 4 I - J/4)/24`.

Thus

`E_ii=5/32`, `E_ij=1/32` for `i~j`, and `E_ij=-1/96` for `i !~ j`.

The original two squared distances are therefore `1/4` on graph edges and the diameter `1/3` on nonedges.

Let `P=<u1,u2,u3>` be the exact three-dimensional eigenspace witness from the first I0123 run and `Z` its 128-coordinate union support. The surviving 288 core points span `P^perp cap C`. For a deleted source `i in Z`, put

`x_i = E e_i`, `v_i = proj_{P^perp cap C}(x_i)`, `q_i=||v_i||^2`.

With `w_i=(u1(i),u2(i),u3(i))` and the exact Gram matrix

`G = [[64,32,48],[32,64,0],[48,0,96]]`,

we have

`q_i = E_ii - w_i^T G^{-1} w_i`,

and for two deleted sources

`r_ij=<v_i,v_j> = E_ij - w_i^T G^{-1} w_j`.

The exact reconstruction gives only two source norm classes:

- `q_i=25/192` for 64 sources;
- `q_i=13/96` for 64 sources.

Define the phantom `y_i=mu_i v_i`, where `mu_i>0` makes every phantom-to-core distance corresponding to a source nonedge exactly the old diameter. The defining equation is

`q_i mu_i^2 + mu_i/48 = 17/96`.

Hence

- if `q_i=25/192`, `mu_i=(-2+sqrt(854))/25`;
- if `q_i=13/96`, `mu_i=(-1+sqrt(222))/13`.

For a surviving core vertex `j`, all three `u_a(j)` vanish, so `<v_i,x_j>=<x_i,x_j>=E_ij`. Therefore

`||y_i-x_j||^2 = 1/3` if `i !~ j`,

`||y_i-x_j||^2 = 1/3 - mu_i/12 < 1/3` if `i~j`.

So the safe phantom-core adjacency is **exactly the original source adjacency**.

`D_ij=||y_i-y_j||^2 = q_i mu_i^2 + q_j mu_j^2 - 2 r_ij mu_i mu_j`.
