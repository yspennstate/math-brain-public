The preceding run proved a Holder boundary-stability theorem with threshold beta=1/2 for perturbations that vanish on every infinite fringe tree. The next question is whether the power law is an artefact of choosing a Holder modulus. It should not be: the tree geometry supplies an exact Kraft simplex, so the right condition ought to be a general modulus-of-continuity criterion.

## B8 — discretize the boundary geometry

For a finite full binary tree with leaf depths `d_i`, put `a_i=2^{-d_i}`. Kraft gives `sum_i a_i=1`. If a boundary-vanishing functional `g` has an increasing concave modulus `omega`, then comparison of leaf rerooting `T_i` with an infinite one-ended extension gives

`|g(T_i)| <= omega(2 a_i)`

(up to the fixed radius-convention constant already isolated in the preceding run). Jensen should therefore give the deterministic estimate

`n^{-1/2} sum_i |g(T_i)| <= sqrt(n) omega(2/n)`.

This reduces the entire perturbation problem to a finite simplex inequality; no probabilistic property of DTCS(n) is used.

## B24 — find the extremal object

For `n=2^h`, the perfect balanced tree has all Kraft weights `a_i=1/n`. If `rho(T)` is the local-distance-to-boundary gauge `2^{-h(T)-1}` (zero on infinite one-ended trees), then `rho` is Lipschitz up to a universal local-metric convention constant. Concavity implies `|omega(rho(S))-omega(rho(T))| <= omega(|rho(S)-rho(T)|)`. Thus `g_omega=omega(rho)` is an admissible boundary-vanishing perturbation with the same modulus up to constants, and on the balanced tree

`n^{-1/2} sum_i g_omega(T_i) = sqrt(n) omega(1/(2n))`.

So the upper bound should be sharp up to absolute constants. The universal deterministic stability condition should be equivalent to

`sqrt(n) omega(1/n) -> 0`.

For strictly concave `omega`, equality in the relaxed Jensen problem forces equal Kraft weights, so the balanced tree is the unique power-of-two extremizer at the weight level.

## Expected strengthening

If the proof closes, state the result for the class `G_omega` of boundary-vanishing functionals with concave modulus `omega`:

`A_n(omega) := sup_{|L(T)|=n} sup_{g in G_omega} n^{-1/2}|sum_i g(T_i)|`.

Prove

`A_n(omega) <= sqrt(n) omega(2/n) <= 2 sqrt(n) omega(1/n)`,

and along `n=2^h`, construct `g_omega` and the balanced tree giving

`A_n(omega) >= sqrt(n) omega(1/(2n)) >= (1/2) sqrt(n) omega(1/n)`.

Hence `A_n(omega)->0` iff `sqrt(n) omega(1/n)->0` (constants adjusted only for the local-metric boundary convention).

This refines the Holder threshold at its critical exponent. For example,

`omega_gamma(t)=sqrt(t)*(log(e/t))^{-gamma}`

is uniformly stable exactly for `gamma>0`; `gamma=0` is critical and `gamma<0` is unstable. The historical P0342 perturbation decays only polynomially in root distance, equivalently logarithmically in local distance, so it lies far on the unstable side.
