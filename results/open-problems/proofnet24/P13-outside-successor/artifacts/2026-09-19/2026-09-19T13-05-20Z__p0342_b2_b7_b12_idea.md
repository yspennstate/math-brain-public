## Idea before proof/code

The preceding run left the `alpha=1/2` member of the perturbation family at a second-moment obstruction: it proved the finite normalized sum cannot have the same Gaussian limit, but did not identify the actual limit. Attack the negation directly: perhaps the critical global perturbation somehow gets swallowed by the local orientation noise and a Gaussian survives.

Let

- `N_3(n)` be the number of size-3 clades in `DTCS(n)`;
- `Z_n=sum_i Psi(T_i^(n))`, so after exposing the unoriented clade scaffold, `Z_n` is a sum of `N_3(n)` independent Rademacher orientation signs;
- `X_n=Z_n/sqrt(n)`;
- `B_n` be the root-split threshold event from the frozen global perturbation, with `p_n=P(B_n=1)->1/2`;
- at `alpha=1/2`, `Y_n=B_n-p_n`.

The exact conditional characteristic function is

`E[exp(i t X_n) | G_n] = cos(t/sqrt(n))^(N_3(n))`,

where `G_n` contains the whole unoriented split scaffold and hence `B_n`.

Use Brandenberger--Chin--Mossel's published fixed-clade count estimates to get

`N_3(n)/n -> lambda_3 = 3/(2 pi^2)` in probability:

`E N_3(n)=n a(n,3)/3`, `a(n,3)->a(3)=9/(2 pi^2)`, and `Var N_3(n)=O(n)`.

Then for each fixed `t`,

`cos(t/sqrt(n))^(N_3(n)) -> exp(-lambda_3 t^2/2)`

in probability and in `L^1`. Therefore the orientation sum is not merely asymptotically Gaussian: its conditional characteristic function becomes deterministic. This should imply the factorization

`E[U_n exp(i t X_n)] - exp(-lambda_3 t^2/2) E[U_n] -> 0`

for every bounded `G_n`-measurable `U_n`. In particular `X_n` becomes asymptotically independent of the root-split statistic.

Since `Y_n=B_n-p_n => S/2` with `S` a symmetric Rademacher, the joint characteristic function should converge to

`exp(-lambda_3 t^2/2) cos(u/2)`,

hence

`(X_n,Y_n) => (G,S/2)` independently,

and at the critical exponent

`W_n^(1/2) => G+S/2`,

an explicit two-Gaussian symmetric mixture with characteristic function

`exp(-lambda_3 t^2/2) cos(t/2)`.

This is manifestly non-Gaussian because its characteristic function vanishes at `t=pi`, whereas a Gaussian characteristic function never vanishes.

The same calculation should close the entire family sharply: for `alpha>1/2`, the global term is `o(1)`, so `W_n^(alpha)=>G`; for `alpha<1/2`, retain the preceding non-tightness argument. Thus the square-root boundary is a true three-regime phase transition, not merely a one-sided obstruction.

Method accounting:

- **B2 ATTACK THE NEGATION FIRST:** test whether the critical perturbation can still wash out into a Gaussian; the exact characteristic function should refute this and identify the limit.
- **B7 TAKE THE LIMIT:** take the random conditional Rademacher characteristic function all the way to its deterministic Gaussian limit.
- **B12 FIND WHAT IS CONSERVED:** exploit the independent left/right orientation signs after conditioning on the entire unoriented scaffold; this symmetry is the mechanism that forces asymptotic independence from any bounded scaffold statistic.
