## 4. B8 — finite dominating quotient for the height-3 feasible residual DP

### Idea before code

The exact height-3 child state space has `17,206` canonical states, so a direct three-child outer DP is prohibitive. I therefore tried to prove a useful upper bound on `beta_3` by replacing each concrete child state by a small abstract class and deliberately allowing extra transitions. If the abstraction contains every concrete action and only adds possibilities, its optimal residual value is an upper bound on the true feasible residual value. A value below `3/4` would have been useful finite evidence and, more importantly, a candidate state quotient for an inductive theorem.

The tested class map keeps:

1. terminal sign `T+` / `T-`, or for a nonterminal state;
2. exact intrinsic unresolved rank;
3. one posterior bit: `q<1/2` versus `q>=1/2`;
4. one normalized residual-value bit: `W_3/D_3<1/2` versus `>=1/2`.

This gives exactly **68 abstract child classes**.

For each nonterminal class, the abstract legal action set is the union of the mapped successor-class pairs of all concrete actions from all members of the class. At an abstract terminal outer-majority state, the residual reward for a class is the maximum concrete `W_3/D_3` among its members.

### Theorem 4.1 — soundness of the union-action abstraction

Let `phi` map concrete height-3 child states to the 68 classes above. Let `\bar B` be the abstract three-child Bellman value obtained by (i) allowing the union of all mapped concrete actions inside each class and (ii) taking the maximum concrete residual reward inside each class at stopping. Then for every concrete three-child state `t`,

`B_3(t)/D_3 <= \bar B(phi(t))`.

In particular,

`beta_3 <= \bar B(phi(o_3),phi(o_3),phi(o_3))`.

#### Proof

Order outer states by total unresolved leaf rank. The outer decision process is acyclic because every legal query strictly decreases this rank.

At a concrete terminal state, the outer majority has been certified and the reward is `W_3(s_J)/D_3` for its residual child `s_J`. By definition, the abstract reward of `phi(s_J)` is the maximum of `W_3(s)/D_3` over concrete members of that class, hence is at least the concrete reward.

Assume the domination holds for every strict successor of a nonterminal concrete outer state `t`. A concrete legal action queries one child state `s` and has concrete successors `t^+` and `t^-`. By construction, the mapped successor-class pair `(phi(s^+),phi(s^-))` is one of the actions permitted from abstract class `phi(s)`. Thus the abstract Bellman maximization may choose the mapped concrete action. Applying the induction hypothesis to the two successors gives

`(B_3(t^+) + B_3(t^-))/(2D_3) <= (\bar B(phi(t^+)) + \bar B(phi(t^-)))/2 <= \bar B(phi(t))`.

Taking the maximum over concrete actions proves the induction step. The root claim follows. QED.

## 6. B29 — compactification, a rigorous impossibility theorem, and a surviving 3/2-Hölder candidate

### 6.1 Define normalized progress

Set

`P_h(s) = 1 - W_h(s)/D_h = (D_h - V_h(s) + A_h(s))/D_h`.

A pointwise lower barrier on `P_h` in terms of posterior magnitude would convert the exact terminal identity

`E[R m_J] = -1/2`

into an expectation bound on the residual `W_h(S_J)`.

### 6.2 Theorem 6.1 — no positive height-uniform linear posterior barrier exists

There is no constant `C>0` such that

`P_h(s) >= C |m_h(s)|`

for every height `h` and every child state `s`.

#### Proof

Let `s_h^+` be the state obtained from the untouched height-`h` tree after revealing one fixed leaf to be `+`.

By recursive-majority symmetry, the posterior root magnetization after revealing one leaf is the product of the one-level influences along its ancestor path, hence

`|m_h(s_h^+)| = 2^{-h}`.

At the untouched root all leaves are symmetric and every first query is Bellman-optimal. Therefore its first-query regret is zero, so `A_h(s_h^+)=0`. Sign symmetry makes the `+` and `-` first-query continuation values equal, and the Bellman equation at the untouched root gives

`V_h(s_h^+) = D_h - 1`.

Consequently

`P_h(s_h^+) = 1/D_h`.

If a uniform linear barrier with constant `C>0` existed, then

`1/D_h >= C 2^{-h}`,

so

`C <= 2^h/D_h`.

The standard O'Donnell--Servedio / Fourier lower bound gives `D_h >= (9/4)^h`. Hence

`C <= (8/9)^h`

for every `h`, forcing `C=0`, a contradiction. QED.

This is a genuine arbitrary-height obstruction: any successful compactification must be sublinear near `m=0`.

### 6.3 A 3/2-Hölder candidate survives every exact state through height 3

The exponent suggested by the root-adjacent scaling is `3/2`. I therefore tested the concrete inequality

`P_h(s) >= (3/4) |m_h(s)|^(3/2)`                         (H)

on **every canonical child state** for `h=1,2,3`.

To avoid floating point and square roots, the checker verifies the equivalent exact rational inequality

`16 P_h(s)^2 >= 9 |m_h(s)|^3`

with `P_h(s)>=0`.

It passes for all states through height 3. Among nonterminal states with nonzero `m`, the exact minima of

`P_h(s)^2 / |m_h(s)|^3`

are

- `h=1`: `32/25`, coefficient `sqrt(32/25)=1.1313708498...`;
- `h=2`: `18386944/22841291`, coefficient `0.8972107186...`;
- `h=3`: `147634018423616307200/227725810949378078473`, coefficient `0.8051690855...`.

Terminal states have coefficient exactly 1. Thus the proposed constant `3/4` has positive finite-height margin through the complete `h=3` state space.

This is **finite evidence only**. It is not promoted to an arbitrary-height theorem.

### 6.4 Why (H), if proved, would move the source metric

Assume (H) held for every `h` and every child state. Then

`W_h(s)/D_h <= 1 - (3/4)|m_h(s)|^(3/2)`.

For any legal outer policy, the inherited exact terminal moment identity is `E[R m_J]=-1/2`. Since `|R m_J|=|m_J|` and `x -> |x|^(3/2)` is convex,

`E |m_J|^(3/2) >= |E[R m_J]|^(3/2) = 2^(-3/2)`.

Therefore every outer policy would satisfy

`E W_h(S_J)/D_h <= 1 - (3/4)2^(-3/2)`

and hence

`beta_h <= 1 - 3/(8 sqrt(2)) = 0.7348349570550446783... < 3/4`.

The feasible-residual recursion would become

`D_{h+1} >= (2 + 3/(8 sqrt(2))) D_h`,

with base

`2 + 3/(8 sqrt(2)) = 2.2651650429449553216... > 9/4`.

This would imply the strictly better source upper bound

`sigma <= 1 - log_3(2 + 3/(8 sqrt(2))) = 0.25574506005755426...`,

an improvement of about `0.00611444708536063` over the present upper endpoint.

Again: this paragraph is **conditional**. The source metric does not move in this run because (H) is not proved for arbitrary height.

### 6.5 A simple local supersolution proof of (H) is false

The obvious route is to rewrite (H) as a lower bound on the shortest-path regret `A_h`. Define

`G_h(s)=V_h(s)-D_h+(3/4)D_h |m_h(s)|^(3/2)`.

Then (H) is `A_h(s)>=G_h(s)`. Since `A_h` is a shortest-path sum of nonnegative Bellman regrets, a sufficient local proof would require every legal edge `s -> s'` to satisfy

`G_h(s')-G_h(s) <= r_h(edge)`.

This local condition already fails at height 1. Take

`s=(+,-,u)`.

Here `m=0`, `V=1`, `A=0`, `D_1=5/2`, so

`G_1(s)=-3/2`.

Querying the final unresolved leaf is Bellman-optimal, hence has regret zero, and reaches a terminal state with

`G_1(terminal)=-5/8`.

Thus

`G_1(terminal)-G_1(s)=7/8 > 0 = regret`.

So the surviving global inequality cannot be established by a one-edge potential monotonicity argument with this scalar state. It must use multi-step path geometry and/or the missing orientation resource identified by B20.

**B29 conclusion.** The linear compactification is rigorously impossible; the `3/2`-Hölder barrier is a sharply formulated surviving candidate, verified exactly through every height-3 state, but its simplest local induction fails.
