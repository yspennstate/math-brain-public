## 5. B3 — a complete power-profile transfer theorem

### NEW-I0001-L2 — scalar Schur power-transfer lemma

Fix `0 <= theta < 2`. Suppose that for all sufficiently small `u>0`,

\[
c_0u^{-\theta}\le L(u)\le C_0u^{-\theta}.
\tag{5.1}
\]

Then, for all sufficiently small `a>0`,

\[
\boxed{
(\mathcal T L)(a)\asymp a^{-1+\theta/2}.
}
\tag{5.2}
\]

Moreover, suppose a source-valid Manhattan variational comparison has been proved with

\[
R(\lambda)
\ge c\int_{|r|\le r_0}
\frac{dr}{\lambda+r^2+r^2(\mathcal T L)(\sqrt\lambda+|r|)}.
\tag{5.3}
\]

Then

\[
\boxed{
R(\lambda)\ge c_\theta\lambda^{-1/4-\theta/8}
}
\tag{5.4}
\]

for all sufficiently small `lambda`.

### Proof of (5.2)

Put

\[
b:=a^{1+\theta/2}.
\]

For the lower bound, integrate only over `0 <= beta <= b`. Since `b<=a` for small `a`, `a+beta \asymp a`; using the upper side of (5.1),

\[
a^2+\beta^2L(a+\beta)
\le C\left(a^2+\beta^2a^{-\theta}\right)
\le Ca^2
\]

throughout this interval. Therefore

\[
(\mathcal T L)(a)
\ge c\frac{b}{a^2}
=c a^{-1+\theta/2}.
\tag{5.5}
\]

For the upper bound split the integral at `beta=a`. On `0<=beta<=a`, the lower side of (5.1) gives

\[
a^2+\beta^2L(a+\beta)
\ge c\left(a^2+a^{-\theta}\beta^2\right),
\]

and the substitution `beta=a^(1+theta/2)s` yields

\[
\int_0^a\frac{d\beta}{a^2+a^{-\theta}\beta^2}
\le C a^{-1+\theta/2}.
\tag{5.6}
\]

On `a<=beta<=beta_0`, `a+beta\asymp beta`, so

\[
a^2+\beta^2L(a+\beta)\ge c\beta^{2-\theta}.
\]

Hence the tail is bounded by

\[
C\int_a^{\beta_0}\beta^{\theta-2}d\beta.
\]

If `theta<1` this is `O(a^{-1+theta})`; if `theta=1` it is `O(log(1/a))`; if `1<theta<2` it is `O(1)`. In every case it is `O(a^{-1+theta/2})`. Combining with (5.6) proves (5.2).

### Proof of (5.4)

Choose

\[
w_\lambda:=c_*\lambda^{3/4-\theta/8}.
\tag{5.7}
\]

Because `theta<2`, `3/4-theta/8>1/2`, so `w_lambda=o(sqrt(lambda))`. Thus for `|r|<=w_lambda`,

\[
a:=\sqrt\lambda+|r|\asymp\sqrt\lambda,
\]

and (5.2) gives

\[
(\mathcal T L)(a)\le C\lambda^{-1/2+\theta/4}.
\]

Consequently

\[
r^2(\mathcal T L)(a)
\le Cc_*^2
\lambda^{3/2-\theta/4}
\lambda^{-1/2+\theta/4}
\le Cc_*^2\lambda,
\]

while `r^2=o(lambda)`. Choosing `c_*` sufficiently small and restricting (5.3) to this interval gives

\[
R(\lambda)
\ge c\frac{w_\lambda}{\lambda}
=c\lambda^{-1/4-\theta/8}.
\]

This proves NEW-I0001-L2. `□`

## 8. Counterexample search before promotion: scalar closure is not automatic

The exact Schur identity from the previous run contains the self-energy

\[

\]

\[

\qquad

\[

\tag{8.1}

The off-diagonal term is nonzero. Therefore the actual Manhattan proof cannot simply replace the operator-valued continued fraction by the scalar recursion (6.1).
