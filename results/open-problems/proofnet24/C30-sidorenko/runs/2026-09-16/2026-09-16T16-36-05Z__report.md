## 3. Exact finite inequality

For a simple host `G` on `n` vertices with `m` edges, the frozen graph has

\[
v(H)=10,\qquad e(H)=15.
\]

The source inequality is exactly

\[
\frac{\operatorname{hom}(H,G)}{n^{10}}
\ge
\left(\frac{2m}{n^2}\right)^{15}.
\]

Clearing denominators gives the integer defect

\[
D_n(G)=\operatorname{hom}(H,G)n^{20}-(2m)^{15}.
\tag{3.1}
\]

Thus a finite simple-host counterexample is exactly a graph with `D_n(G)<0`. Every pass/fail decision in this run uses integer arithmetic.

For `n=10`, the normalized comparison ratio is

\[
R(G)=\frac{t(H,G)}{t(K_2,G)^{15}}
=\frac{\operatorname{hom}(H,G)10^{20}}{(2m)^{15}}.
\tag{3.2}
\]

## 4. Exact homomorphism-count formula

For host vertices `a,b,c`, write

\[
C(a,b,c)=|N(a)\cap N(b)\cap N(c)|.
\]

Label the five vertices on one side of `H` cyclically by the images `a,b,c,d,e`. In `K_{5,5}\setminus C_{10}`, each vertex on the opposite side misses one consecutive pair on this 5-cycle and is adjacent to the remaining three vertices. Once `a,b,c,d,e` are fixed, the five opposite-side images can therefore be chosen independently in

\[
C(c,d,e),\ C(d,e,a),\ C(e,a,b),\ C(a,b,c),\ C(b,c,d)
\]

ways. Summing over the first side gives the exact identity

\[
\operatorname{hom}(H,G)
=
\sum_{a,b,c,d,e}
C(c,d,e)C(d,e,a)C(e,a,b)C(a,b,c)C(b,c,d).
\tag{4.1}
\]

The checker evaluates the same integer contraction with the `c`-sum regrouped for speed. On 256 deterministic order-ten canonical classes it also evaluates (4.1) directly and obtains exact agreement in all cases.

## 5. Complete enumeration theorem through order ten

This run does not rely on a sampled or partial graph list.

### 5.1 Exact canonical code

A graph is encoded by its lower-triangular adjacency bit string. The canonicalizer starts from vertex degrees, repeatedly refines by the exact vector of neighbor counts into the current color classes, gives stable color classes canonical lexicographic IDs, exhaustively enumerates every permutation inside each final class, and returns the least adjacency code among those relabelings.

This is an exact isomorphism canonical code. Every isomorphism preserves the initial degrees and each subsequent refinement signature, hence preserves the canonically ordered stable classes. The exhaustive within-class search therefore includes the relabeling induced by every isomorphism. Conversely, equality of returned adjacency codes exhibits explicit relabelings to the same labeled graph and hence implies isomorphism.

### 5.2 Independent Burnside counts

For `n` vertices, let `o_2(σ)` denote the number of orbits of a permutation `σ in S_n` on unordered vertex pairs. Burnside's lemma gives

\[
U(n)=\frac1{n!}\sum_{\sigma\in S_n}2^{o_2(\sigma)}.
\tag{5.1}
\]

The checker evaluates (5.1) exactly by iterating every permutation for `n=7,8,9,10` and obtains

\[
U(7)=1044,\quad U(8)=12346,\quad U(9)=274668,\quad
\boxed{U(10)=12005168}.
\tag{5.2}
\]

This Burnside computation is logically independent of the one-vertex augmentation count.

### 5.4 Surjective one-vertex augmentation

**Lemma C30-AUGMENT-10.** If `S_n` contains one representative of every isomorphism class of simple `n`-vertex graphs, then attaching one new vertex to each of the `2^n` subsets of every graph in `S_n` produces at least one representative of every `(n+1)`-vertex isomorphism class.

**Proof.** Let `G` be any graph on `n+1` vertices and delete any vertex `v`. By completeness, `G-v` is isomorphic to some `Q in S_n`. Transport the neighborhood of `v` through that isomorphism. The augmentation attaching the new vertex to exactly that transported subset reconstructs a graph isomorphic to `G`. QED.

\[

\]

raw order-eight extensions and 12,346 canonical classes,

\[
12346\cdot2^8=3160576
\]

raw order-nine extensions and 274,668 canonical classes, and finally

\[
274668\cdot2^9=\boxed{140630016}
\]

raw order-ten extensions.

The order-ten canonical codes are inserted into an exact 64-bit open-addressing set. Hashing affects only storage location: equality comparisons are on the complete canonical code, so there is no probabilistic collision criterion. The resulting number of distinct codes is exactly

\[

\]

which equals the independent Burnside count `U(10)`. Surjectivity of augmentation plus equality with the total isomorphism-class count proves that the checker has exactly one representative of every simple graph on ten vertices.
