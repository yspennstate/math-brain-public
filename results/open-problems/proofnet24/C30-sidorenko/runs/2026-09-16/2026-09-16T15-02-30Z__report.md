## 4. Complete enumeration theorem at order nine

The main metric-moving claim is a proved complete enumeration, not a sample.

### 4.1 Exact canonical code

A graph is encoded by the lower-triangular adjacency bit string. The checker begins with degree colors, performs exact one-dimensional Weisfeiler–Leman refinement, assigns stable color IDs by lexicographically sorting the complete refinement signatures, and then exhaustively enumerates every permutation inside each stable color class. It takes the least adjacency bit code among those relabelings.

This is an exact canonical code:

1. graph isomorphisms preserve degrees and each subsequent refinement signature, hence preserve the stable color classes and their canonically sorted IDs;
2. every relabeling within those classes is explicitly enumerated;
3. the returned code is the adjacency code of an actual relabeling of the input.

Therefore isomorphic inputs return the same minimum, and equal returned minima imply isomorphism.

### 4.2 Independent Burnside counts

The checker independently evaluates Burnside's lemma for the induced action of every vertex permutation on unordered pairs. It obtains exactly

\[
U(7)=1044,\qquad U(8)=12346,\qquad U(9)=274668.
\tag{4.1}
\]

The 1,044 supplied order-seven adjacency codes are canonicalized and found to give 1,044 distinct canonical classes. Since this equals the independent Burnside count, they constitute a complete order-seven base. The data were extracted from the standard order-seven atlas, but completeness does not rely on trusting the atlas count: the checker certifies distinctness plus equality with Burnside.

### 4.3 Surjective one-vertex augmentation

The order-eight and order-nine generation uses the same elementary completeness argument.

**Lemma C30-AUGMENT-09.** If `S_n` contains one representative of every isomorphism class of simple `n`-vertex graphs, then attaching a new vertex to every one of the `2^n` possible subsets of vertices of every graph in `S_n` yields at least one representative of every `(n+1)`-vertex isomorphism class.

**Proof.** Let `G` be an arbitrary graph on `n+1` vertices and delete any vertex `v`. The deletion graph `G-v` is isomorphic to some member `Q` of `S_n`. Transport the neighborhood of `v` through that isomorphism. Attaching a new vertex to precisely that transported subset of `V(Q)` reconstructs a graph isomorphic to `G`. QED.

Applying the lemma to the certified order-seven base gives

`1044 * 2^7 = 133632`

raw order-eight extensions. Exact canonical reduction gives 12,346 classes, exactly matching `U(8)`.

Applying it again gives

`12346 * 2^8 = 3,160,576`

raw order-nine extensions. Exact canonical reduction gives

\[
\boxed{274668}
\]

distinct classes, exactly matching the independent Burnside count `U(9)`.

Therefore the checker contains exactly one canonical representative of every simple graph on nine vertices.

## 5. Exact homomorphism check for all 274,668 hosts

\[
C(a,b,c)=|N(a)\cap N(b)\cap N(c)|.
\]

The prior C30 report proved

\[
\operatorname{hom}(H,G)
=
\sum_{a,b,c,d,e}
C(c,d,e)C(d,e,a)C(e,a,b)C(a,b,c)C(b,c,d),

It then computes `D_9(G)` from (3.1) with exact integer arithmetic for every one of the 274,668 canonical order-nine hosts. The result is
