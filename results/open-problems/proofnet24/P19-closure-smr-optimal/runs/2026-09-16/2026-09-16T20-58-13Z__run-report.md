## `P19-I0068-SAME-DOMAIN-TRANSFER-04 — KNOWN / DERIVED COROLLARY`

Then `(A,0)` has stochastic maximal `L^p`-regularity on `(0,T)` in the source couple `(X_0,X_1)`.

This is not claimed as a new theorem: it is the source survey's Remark 3.16 / proof mechanism specialized to a time-independent `R`-sectorial target, together with Portal–Veraar Theorem 3.9 and Weis' deterministic theorem. I record the complete derivation because it identifies the exact missing object for Problem 2.

### Proof

Because `A_0` has a bounded `H^infinity` calculus of angle `<pi/2`, the source Theorem 3.14 gives

\[
A_0\in \mathrm{SMR}(p,0,T).
\tag{4.1}
\]

Moreover the bounded functional calculus gives the standard square-root/complex-interpolation identity

\[
D(A_0^{1/2})=[X_0,D(A_0)]_{1/2}=[X_0,X_1]_{1/2}=:X_{1/2}.
\tag{4.2}
\]

Since scalar `L^q` is UMD and `A` is `R`-sectorial of angle `<pi/2`, Weis' theorem gives deterministic maximal `L^p`-regularity of `A` on `(0,T)`:

\[
A\in \mathrm{DMR}(p,0,T).
\tag{4.3}
\]

By definition of the graph norm, `A:X_1->X_0` is bounded. Thus the constant-in-time coefficient `A(t,omega)=A` satisfies the operator boundedness hypothesis in Portal–Veraar's Theorem 3.9. Equations (4.1) and (4.2) provide that theorem's reference-operator hypothesis, while (4.3) provides its deterministic maximal-regularity hypothesis. Theorem 3.9 therefore yields

\[
A\in \mathrm{SMR}(p,0,T).

This is precisely stochastic maximal `L^p`-regularity of `(A,0)` on the source couple. QED.

# 6. Move #29 — add the point at infinity

The inherited finite-block route becomes more precise when one tracks the Banach couple, not merely each finite matrix.

Let `A_d` act on scalar `ell^q_d`, `q>2`. Every individual finite-dimensional operator is bounded and has `D(A_d)=ell^q_d` as a set, so a finite instance cannot expose the infinite-domain obstruction by set equality alone. The issue is whether the **reference constants remain uniform as `d->infinity`**.

Equip the target domain with its graph norm

\[
\|x\|_{A_d}=\|x\|_q+\|A_dx\|_q.
\]

The most naive reference `A_{0,d}=I` has graph norm `2\|x\|_q`. Since the operator norm is attained in finite dimension,

\[
\sup_{x\ne0}\frac{\|x\|_{A_d}}{2\|x\|_q}
=\frac{1+\|A_d\|_{q\to q}}{2}.
\tag{6.1}
\]

Hence the identity reference is not a dimension-free/common-couple model whenever `\|A_d\|` diverges. This is not a counterexample — one may choose a better reference — but it explains why “take `I` because every finite domain equals the whole space” is not a uniform argument.

The equally naive Hilbertisation has an explicit dimension loss. For `q>2` and `x in R^d`,

\[
\|x\|_q\le \|x\|_2\le d^{1/2-1/q}\|x\|_q.
\tag{6.2}
\]

Both endpoint constants for the identity comparison are sharp (coordinate vector and all-ones vector). Therefore transferring the Hilbert-space theorem through the identity identification `ell^q_d <-> ell^2_d` does not provide a dimension-free bound.

Combining this with `P19-I0068-FINITE-BLOCK-LIFT-03`, the honest finite-dimensional negative target is now more constrained:

\[
\sup_d R_\theta(A_d)<\infty,
\qquad
C_{\mathrm{SMR},p}(A_d)\to\infty,
\tag{6.3}
\]

**and** any attempted same-domain reference scheme must lose uniform control somewhere (reference SMR constant, square-root/interpolation equivalence, graph-norm comparison, or the deterministic transference constants). A sequence of individually well-behaved finite matrices is not enough; the obstruction must live at the point at infinity.

### `P19-AUDIT-P20-D0010-CEILING-20 — PASS` (component scope)

Normalize the bounded support to `[0,1]` and take the tight lower-mean boundary `E[Y]=1/n`. If the law is `n`-completely mixable, there exist identically distributed nonnegative random variables `Y_1,...,Y_n` with that marginal and

\[
\sum_{i=1}^nY_i=1\quad\text{a.s.}
\]

Fix `x in (0,1]` and put

\[
N_x=\#\{i:Y_i>x\}.
\]

For every outcome,

\[
xN_x<\sum_{i:Y_i>x}Y_i\le1.
\]

Hence `N_x<1/x`; since `N_x` is integer,

\[
N_x\le \lceil1/x\rceil-1.
\]

Taking expectations and using only equality of the marginals,

\[
n\,P(Y_1>x)=E[N_x]\le \lceil1/x\rceil-1.
\]

Thus the marginal distribution function satisfies

\[
\boxed{
F(x)\ge1-\frac{\lceil1/x\rceil-1}{n}.
}
\tag{8.1}
\]

After undoing the affine normalization this is exactly the ceiling inequality recorded in P20's D0010 claim. No exchangeability assumption is required; identical marginals suffice for the expectation identity. Verdict **PASS** for this necessary-condition component only. It is not a sufficiency theorem, does not move P20's new `J_boundary` metric, and is not an end-to-end audit of Wang Open Problem 10.
