# 4. Move #1 — CHANGE THE CATEGORY: domains become operator ranges

The preceding report isolated the existence of a same-domain `H^infinity` reference as a sufficient bridge. This run changes category: instead of searching directly among unbounded generators, encode the graph domain as the range of one bounded resolvent and ask whether that bounded operator can be **right-normalized** into a good functional-calculus operator.

Fix a sectorial `A` and `lambda>0`, and write

\[
K=(\lambda+A)^{-1}:X\longrightarrow X.
\]

Then `K` is bounded, injective, has dense range, and

\[
\operatorname{Ran}K=D(A).
\]

If `X_1=D(A)` is equipped with the graph norm, then

\[
K:X\longrightarrow X_1
\]

is an isomorphism of Banach spaces.

## `P19-I0068-RANGE-NORMALIZATION-05 — PROVED / structural equivalence`

An invertible closed reference `A_0` with

\[
D(A_0)=D(A)
\]

with equivalent graph norm is equivalent to choosing a bounded invertible `S in GL(X)` and putting

\[
A_0^{-1}=KS.
\tag{4.1}
\]

Consequently the same-domain `H^infinity`-reference problem can be phrased as:

\[
\boxed{\text{find }S\in GL(X)\text{ such that }KS\text{ is the inverse of an }H^\infty\text{-sectorial operator}.}
\tag{4.2}
\]

### Proof

Suppose first that `A_0` is invertible, `D(A_0)=X_1` as a Banach space with equivalent graph norm, and put `C=A_0^{-1}`. Then both

\[
K:X\to X_1,
\qquad
C:X\to X_1
\]

are bounded Banach-space isomorphisms. Therefore

\[
S:=K^{-1}C\in GL(X),
\]

and `C=KS`, proving (4.1).

Conversely, if `S in GL(X)` and `C=KS`, then `C:X->X_1` is again a Banach-space isomorphism. Hence `A_0=C^{-1}` is closed and invertible with domain

\[
D(A_0)=\operatorname{Ran}C=\operatorname{Ran}K=D(A),
\]

and the `A_0` graph norm is equivalent to the original `A` graph norm because both are transported from the same `X` norm through the bounded isomorphisms `C` and `K`. If in addition `C^{-1}` has bounded `H^infinity` calculus of the required angle, this is exactly a qualifying same-domain reference. QED.

On a Hilbert space this reformulation immediately exposes the classical mechanism: the left polar decomposition

\[
K=P V,\qquad P=(KK^*)^{1/2}>0,\quad V\text{ unitary},
\]

gives the right normalizer `S=V^*`, hence `KS=P` is positive. The Hilbert proof is therefore an exact **operator-range normalization** statement, not a mysterious property of `A` itself.

# 5. Move #19 — MAKE IT AN ALGORITHM: bounded finite blocks can all be normalized

The range formulation suggests a constructive algorithm on scalar `ell^q`: polar-normalize each finite reducing block, and ask whether the normalizers remain uniformly bounded in the ambient `ell^q` norm.

## `P19-I0068-BOUNDED-BLOCK-RSECTORIAL-IFF-05 — PROVED / PARTIAL source theorem`

Fix `q in (2,infinity)`, `p in (2,infinity)`, a finite time interval `(0,T)`, and

\[
X=\Big(\bigoplus_{n\ge1}\mathbb C^{d_n}\Big)_{\ell^q},
\qquad
D:=\sup_n d_n<\infty.
\]

Let

\[
A=\bigoplus_{n\ge1}A_n
\]

be the closed direct-sum realization of finite-dimensional coordinate-block operators, sectorial of angle `<pi/2`. Then, in this uniformly bounded-block class,

\[
\boxed{
A\in\mathrm{SMR}_p(0,T)
\quad\Longleftrightarrow\quad
A\text{ is }R\text{-sectorial of angle}<\pi/2.
}
\tag{5.1}
\]

In particular every `R`-sectorial operator in this class admits an explicit same-domain reference `A_0` with bounded `H^infinity` calculus of angle zero.

This is a restricted scalar-`L^q` characterization. It does **not** solve Agresti–Veraar Problem 2 for arbitrary operators, and publication novelty is unverified.

### Proof: sufficiency

Assume `A` is `R`-sectorial of angle `<pi/2`. Choose `lambda>0` and set

\[
K=(\lambda+A)^{-1}=\bigoplus_n K_n.
\]

Every `K_n` is an invertible matrix. Take its **left Euclidean polar decomposition**

\[
K_n=P_nV_n,
\qquad
P_n=(K_nK_n^*)^{1/2}>0,
\qquad
V_n\text{ unitary}.
\tag{5.2}
\]

For every unitary `U` on `C^d` and every `q>2`, norm comparison gives

\[
\|Ux\|_q\le \|Ux\|_2=\|x\|_2
\le d^{\frac12-\frac1q}\|x\|_q.
\tag{5.3}
\]

The same estimate holds for `U^{-1}`. Therefore, with

\[
a:=\frac12-\frac1q>0,
\qquad
S_n:=V_n^*,
\qquad
S:=\bigoplus_n S_n,
\]

we have

\[
\|S\|,\ \|S^{-1}\|\le D^a.
\tag{5.4}
\]

Hence `S in GL(X)` and

\[
C:=KS=\bigoplus_n P_n.
\tag{5.5}
\]

Now diagonalize each positive matrix:

\[
P_n=Q_n\Delta_nQ_n^*,
\]

with `Q_n` unitary and `Delta_n` positive diagonal. Put

\[
Q=\bigoplus_nQ_n,
\qquad
\Delta=\bigoplus_n\Delta_n.
\]

Again by (5.3),

\[
\|Q\|,\ \|Q^{-1}\|\le D^a.
\tag{5.6}
\]

The operator `Delta` is a positive diagonal multiplier on scalar `ell^q`. Coordinatewise functional calculus gives, for every bounded holomorphic `f` on a sector containing the positive axis,

\[
\|f(\Delta)\|\le \|f\|_\infty.
\tag{5.7}
\]

Since

\[
C=Q\Delta Q^{-1},
\]

`C` has bounded `H^infinity` calculus of angle zero, with the explicit similarity bound

\[
\|f(C)\|
\le D^{2a}\|f\|_\infty
=D^{1-2/q}\|f\|_\infty.
\tag{5.8}
\]

Define

\[
A_0:=C^{-1}=Q\Delta^{-1}Q^{-1}.
\tag{5.9}
\]

The diagonal operator `Delta^{-1}` is positive sectorial of angle zero with coordinatewise bounded `H^infinity` calculus, so (5.8) gives the same property for `A_0`. Moreover

\[
D(A_0)=\operatorname{Ran}C
=\operatorname{Ran}K
=D(A).
\tag{5.10}
\]

The graph norms are equivalent: `K:X->D(A)` is an isomorphism for the `A` graph norm, and `C=KS` differs from `K` only by the bounded invertible operator `S`. Thus `C:X->D(A)` is also an isomorphism, which is precisely equivalence of the `A_0` and `A` graph norms.

Because `A` is `R`-sectorial on scalar `ell^q`, Weis' theorem gives deterministic maximal `L^p`-regularity. The reference `A_0` has bounded `H^infinity` calculus and the same domain, so source Theorem 3.14 supplies SMR for `A_0`, while the standard square-root interpolation identity supplies the common half-domain required by Portal–Veraar Theorem 3.9. The same-domain transference result therefore yields

\[
A\in\mathrm{SMR}_p(0,T).
\]

This proves sufficiency.

### Proof: necessity

If `A in SMR_p`, source Remark 3.10 gives deterministic maximal `L^p`-regularity. Scalar `ell^q` is UMD, so Weis' characterization gives `R`-sectoriality of angle `<pi/2`. This direction does not use the block assumption. Combining with the sufficiency proof gives (5.1). QED.

### What the algorithm actually does

Given the resolvent blocks `K_n`, the construction is explicit:

1. compute `P_n=(K_nK_n^*)^{1/2}` and the polar unitary `V_n`;
2. right-normalize by `S_n=V_n^*`;
3. diagonalize `P_n` by a unitary `Q_n`;
4. assemble the global reference `A_0=(\oplus P_n)^{-1}`.

The only genuinely infinite-dimensional issue is **uniformity of the blockwise change-of-basis constants**. Bounded block size supplies it automatically.

# 6. Move #27 — SWAP THE QUANTIFIERS: find the failure to glue

The original same-domain question has the form

\[
\forall A\quad \exists A_0(A)\quad\text{with a good common domain/calculus}.
\]

The block algorithm swaps this to a uniform local statement:

\[
\forall D<\infty\quad
\exists C(q,D)<\infty\quad
\forall n\text{ with }d_n\le D,
\quad\text{choose the polar normalizer with norm}\le C(q,D).
\]

For every fixed `D` the construction succeeds simultaneously, and hence glues globally. The exact distortion visible in the proof is

\[
D^{1/2-1/q}
\]

per unitary change of basis, and at most

\[
D^{1-2/q}
\]

for the diagonalizing similarity in the `H^infinity` calculus estimate.

This identifies a concrete obstruction to extending the proof to arbitrary block sizes: if `d_n -> infinity`, generic Euclidean polar factors need not be uniformly bounded in `ell^q`. That is a **failure of this proof mechanism**, not a proof that a same-domain reference fails to exist. An arbitrary-operator counterexample would have to make this distortion unavoidable, while a positive proof would need to exploit `R`-sectorial structure to choose better normalizers than the raw Euclidean polar factors.

This is the new route produced by the run. It also sharpens the inherited finite-block-lift strategy: a useful negative family should not merely have growing SMR constants; it should exhibit a dimension-free `R`-sectorial bound together with an obstruction to every uniformly conditioned right-normalization of its resolvent range into a good `H^infinity` model.
