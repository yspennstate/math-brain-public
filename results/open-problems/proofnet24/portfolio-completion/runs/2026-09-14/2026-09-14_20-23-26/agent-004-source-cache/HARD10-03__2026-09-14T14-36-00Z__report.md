# HARD10-03 — Tóth interchange infinite cycles on Z^3

SOLUTION STATUS: PARTIAL

## Exact target
Put independent rate-one Poisson transposition clocks on every unoriented nearest-neighbor edge of Z^3, and let pi_beta be the time-beta permutation. The target is

exists beta_0<infinity such that for every beta>beta_0,
P(0 belongs to an infinite cycle of pi_beta)>0.

Elboim–Sly, arXiv:2211.17023v3 (2 Feb 2024), prove the corresponding large-beta theorem for d>=5, not d=3, and explicitly warn that monotonicity in beta is unavailable. El Alami–Pete–Timár, arXiv:2512.18435, prove indistinguishability properties of infinite interchange cycles conditional on their existence, not d=3 existence. A bounded 14 Sep 2026 literature search found no later d=3 resolution.

## 1. Infinite-volume construction and cycle versus chronological path
The Harris graphical construction is well defined because a tagged particle has total jump rate 6 and hence finitely many jumps on bounded physical-time intervals. Following marks backward gives the inverse, so pi_beta is a.s. a bijection.

A single chronological particle path t -> pi_t(0), 0<=t<=beta, is a continuous-time simple random walk. The permutation-cycle orbit is different: it reuses the same [0,beta] Poisson slab forever. The cyclic-time walk is

W(k beta+s)=pi_s pi_beta^k(0),  k in Z, 0<=s<beta,

hence W(k beta)=pi_beta^k(0). If the origin cycle has finite length L, then W(L beta)=0 and the cyclic walk repeats thereafter.

## 2. Driver representation
Let X(t) be continuous-time nearest-neighbor simple random walk, rate one to each neighbor. Elboim–Sly construct W from X so that W takes the same jumps except when a proposed jump enters same-phase history (suppressed) or a same-phase history jump forces a jump.

Define

tau_int = inf{t>=beta: exists k>=1, k beta<=t, ||W(t)-W(t-k beta)||_infty<=1}.

Before tau_int, W=X.

## 3. HARD10-03-L1 — PROVED: first synchronized interaction bound
For every fixed d>=3 there is C_d<infinity such that for all beta>=1 and integers K>=1,

P(tau_int<=K beta) <= C_d K beta^(1-d/2).

In d=3,

P(tau_int<=K beta) <= C K/sqrt(beta).

Consequently, if L_beta(0) is the origin cycle length, with infinity allowed,

P(L_beta(0)<=K) <= C K/sqrt(beta),

so for every epsilon>0,
P(L_beta(0)<=beta^(1/2-epsilon)) -> 0 as beta->infinity.

### Proof
For the driver X,

sup_x P(X(t)=x) <= C_d t^(-d/2), t>=1,

and therefore for every fixed finite box B_R,

sup_y P(X(t) in y+B_R) <= C_{d,R} t^(-d/2).

Before first interaction W=X. For lag r>=1 put

D_r(t)=X(t)-X(t-r beta),  t>=r beta.

If tau_int<=K beta, some D_r, 1<=r<=K, enters B_1 during [r beta,K beta]. For each fixed t, D_r(t) has law X(r beta). The process D_r changes only when the upper endpoint crosses a jump of X or the lower endpoint crosses a jump of X; each mechanism has rate 2d. If D_r enters B_1, then it either begins in B_1 or immediately before an endpoint change lies in B_2.

Poisson compensation gives, for upper-endpoint changes,

E N_r^(+) <= C_d (K-r) beta (r beta)^(-d/2).

For lower-endpoint changes, if a jump J occurs at physical time s, the pre-change difference at t=s+r beta is

X(s+r beta^-)-X(s^-)=J+[X(s+r beta^-)-X(s)],

where the future increment after s is independent of J and the past. Thus the same shifted heat-kernel bound gives

E N_r^(-) <= C_d (K-r) beta (r beta)^(-d/2).

Also P(D_r(r beta) in B_1)<=C_d(r beta)^(-d/2). Hence

P(tau_int<=K beta)
 <= C_d beta^(-d/2) sum_{r<=K} r^(-d/2)
  + C_d beta^(1-d/2) sum_{r<K}(K-r)r^(-d/2).

Since sum r^(-d/2)<infinity for d>2, this is at most C_d K beta^(1-d/2).

If L_beta(0)=q<infinity, then W(q beta)=W(0), so interaction has occurred by q beta. This proves the cycle-length bound.

Adversarial check: the delicate lower-endpoint compensation is valid by the displayed decomposition; simultaneous endpoint jumps have probability zero. No unverified infinite-variance or local-limit estimate is used.

## 4. HARD10-03-L2 — PROVED: finite-window iid approximation
Let Z_j=pi_beta^j(0)=W(j beta), and let S_j=X(j beta). The driver coupling yields

d_TV(Law(Z_0,...,Z_K),Law(S_0,...,S_K)) <= C_d K beta^(1-d/2).

For cycle increments Delta_j=Z_{j+1}-Z_j and p_beta=Law(X(beta)),

d_TV(Law(Delta_0,...,Delta_{K-1}),p_beta^{tensor K}) <= C_d K beta^(1-d/2).

Indeed, on {tau_int>K beta}, W and X coincide over the whole interval.

## 5. HARD10-03-L3 — PROVED NEW: point-shift stationarity
Let theta_x denote spatial translation normalized by

(theta_x pi)(y)=pi(y+x)-x,

and define the point-shift

T omega = theta_{pi_beta(0)} omega.

Then T preserves the Poisson interchange law. Consequently

T^k omega = theta_{pi_beta^k(0)} omega,

and

Delta_k = pi_beta^{k+1}(0)-pi_beta^k(0)
        = pi_beta(0) o T^k

is stationary in k. Every Delta_k has exactly the beta-time one-particle SRW displacement law, so in d=3

E Delta_k=0,  E|Delta_k|_2^2=6 beta.

### Proof
For bounded measurable f define the translation-covariant mass transport

M(omega,u,v)=1_{pi_beta(u)=v} f(theta_v omega).

The mass-transport principle gives

E sum_v M(omega,0,v)=E sum_u M(omega,u,0).

The left side is E f(T omega). Since pi_beta is a bijection, exactly one u maps to 0, so the right side is E f(omega). Thus T is measure preserving. Translation covariance of pi_beta gives the iterate identity and stationarity.

Combining L2 with stationarity, for every starting index j,

d_TV(Law(Delta_j,...,Delta_{j+K-1}),p_beta^{tensor K}) <= C_d K beta^(1-d/2).

Thus every o(sqrt(beta)) consecutive window in d=3 is asymptotically iid as beta->infinity. This is only local: a huge finite cycle can impose a global bridge constraint invisible on every such window.

## 6. HARD10-03-L4 — PROVED NEW: inverse cycle-length / spectral atom bound
Let L=L_beta(0), with 1/infinity=0, and c_beta=E[1/L]. Then in d=3,

c_beta <= C (1+log beta)/sqrt(beta)

for all sufficiently large beta.

### Proof
Let F(m)=P(L<=m). L1 gives

F(m)<=min(1,a m),   a=C_0/sqrt(beta).

Summation by parts gives the exact identity

E[1/L]=sum_{m>=1} F(m)/(m(m+1)).

For a<=1 and M=floor(1/a),

c_beta
 <= a sum_{m=1}^M 1/(m+1) + sum_{m>M}1/(m(m+1))
 <= a log(M+1)+1/(M+1)
 <= a(1+log(2/a)),

which yields the claimed bound.

### Spectral interpretation
Let U_pi be the unitary permutation operator on l^2(Z^3), and let mu_beta be the annealed spectral measure at delta_0. Then

int z^k mu_beta(dz)=P(pi_beta^k(0)=0).

For finite cycle length L the sample spectral measure is uniform on the L-th roots of unity; for an infinite orbit it is Haar measure. Therefore

mu_beta({1}) = E[1/L] = c_beta.

Equivalently,

c_beta = lim_{N->infinity} (1/N) sum_{k=0}^{N-1} P(pi_beta^k(0)=0).

Adding iid continuous vertex marks and choosing the minimum-mark vertex from each finite cycle shows that c_beta is also the spatial intensity of finite cycles, one representative per cycle.

This does not prove infinite cycles at fixed beta: all cycles could in principle be finite but enormous, making E[1/L] arbitrarily small while P(L<infinity)=1.

## 7. HARD10-03-L5 — PROVED NEW: finite-torus-to-Z^3 transfer
Let T_N^3=(Z/NZ)^3 and L_{N,beta}(0) be the origin cycle length at the same fixed beta. Suppose there are delta>0 and a_N->infinity such that

liminf_{N->infinity} P_{T_N^3}(L_{N,beta}(0)>=a_N) >= delta.

Then

P_{Z^3}(L_beta(0)=infinity) >= delta.

### Proof
Fix M. The event L_beta(0)>M is decided by exposing the first M cyclic periods, a finite time horizon M beta. A Poisson jump-count/deviation bound makes the probability that this exploration exits a Euclidean box of radius R tend to zero as R->infinity, uniformly for tori with N>2R. Hence the torus and lattice graphical constructions can be coupled to agree on the full exploration with probability tending to one, so

P_{T_N^3}(L_{N,beta}(0)>M) -> P_{Z^3}(L_beta(0)>M).

For N large, a_N>M, and the assumed lower bound gives P_{Z^3}(L_beta(0)>M)>=delta. Let M->infinity and use continuity from above.

Thus any fixed-time d=3 finite-torus theorem putting positive vertex mass in cycle lengths diverging with N—macroscopic cycles are far more than necessary—would solve the infinite-volume target at that beta.

Ioffe–Tóth, arXiv:1909.06188 / J. Stat. Phys. 180 (2020), establish Poisson–Dirichlet behavior for stationary/equilibrium random stirring on the torus, not the fixed finite beta process started from the identity required here.

## 8. Structural synthesis
The retained exact facts are:

1. Before the first same-phase defect, the cyclic walk is honest SRW, and a K-period first defect costs O(K/sqrt(beta)) in d=3.
2. Orbit increments are stationary, each marginal is exactly SRW(beta), and every o(sqrt(beta)) consecutive window is asymptotically iid.
3. The finite-cycle count intensity / spectral atom E(1/L) is O((log beta)/sqrt(beta)).
4. Diverging finite-torus cycle lengths with positive probability transfer rigorously to infinite cycles in Z^3.

The obstruction is global: if typical cycles were all finite at a large fixed beta, they would have to be huge and enforce a long-range bridge constraint invisible on all o(sqrt(beta)) windows.

## 9. CONDITIONAL route: sparse-defect CLT
Write

S_n=pi_beta^n(0)=sum_{j=0}^{n-1} Delta_j.

If for sufficiently large fixed beta one proves a nondegenerate functional CLT

S_floor(nt)/sqrt(n) => Sigma_beta^(1/2) B_t,  Sigma_beta>0,

then P(L<infinity)<1: if L<infinity a.s., every sample orbit is periodic and bounded, hence S_n/sqrt(n)->0 a.s.

A natural sufficient theorem is that interaction blocks have intensity O(beta^-1/2), finite-mean clusters, summable dependence, and subdiffusive cumulative correction. The independent-driver kernel suggested by L1 is

K_beta(r) ~ beta^-1/2 r^-3/2,

which is summable in r in dimension three. L1 is the first-scale input, but no uniform conditional control after an interaction is yet proved.

## 10. Failed / killed shortcuts
- No monotonicity in beta may be assumed.
- Chronological SRW transience is not cycle transience.
- Requiring no interactions forever cannot work: the driver predicts O(beta^-1/2) same-phase defect hazard per period.
- Stationary-torus PD(1) is the wrong time regime.
- Indistinguishability results are conditional on existence.
- Small cycle-count intensity E(1/L) does not control the finite-cycle vertex density P(L<infinity).
- Finite-torus numerics alone are insufficient, but L5 now gives the exact transfer theorem if a rigorous positive diverging-cycle fraction is obtained.
