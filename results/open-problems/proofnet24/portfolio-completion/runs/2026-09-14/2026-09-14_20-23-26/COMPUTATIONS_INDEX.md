# Computation and certificate index

This page indexes the code and outputs attached after recovery. [Earlier computations](computations/) and [the rational solver instructions](SOLVER_USAGE.md) remain available. Full reports state their mathematical hypotheses and explain which finite calculations support which arguments.

All post-disconnection execution was in the available JavaScript V8 code-mode runtime. BigInt arithmetic is exact; floating-point diagnostics are labeled. No new Python, Node CLI, or proof-assistant execution is claimed after the workspace became unavailable. Several ordinary `.js` programs can be run with the report's documented Node command, but the recorded execution environment remains V8.

Files ending in `.exec.js` or `.tool.js`, and the original 084 cell, retain code-mode globals such as `store`, `load` and `text`. They preserve the actual executed source; they require those bindings or adaptation to run elsewhere. Their archived outputs are not a claim that every cell is an independent Node program. The 087 comparison cell also retains its source-state dependency. Archival followups copied existing source/output; they did not launch new agents or rerun checks.
