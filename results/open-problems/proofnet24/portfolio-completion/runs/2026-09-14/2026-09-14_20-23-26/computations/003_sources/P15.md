# 3. Exact same-sample risk geometry

Condition on the entire fitted pipeline.

Let

\[
m_S:\mathcal X\to\mathbb R^q
\]

be the full-data deployed mean and

\[
c_S:\mathcal X\to\mathbb R^q
\]

the full-data deployed correction.

Define

\[
e_S(U)=G(U)-m_S(U).
\]

For a scalar gate

\[
0\le\theta\le1,
\]

define

\[
\mathcal R_S(\theta)
=
E_U\|e_S(U)-\theta c_S(U)\|^2.
\]

Exactly,

\[
\boxed{
\mathcal R_S(\theta)
=
\mathcal R_S(0)
-
2\theta A_S
+
\theta^2V_S,
}
\tag{3.1}
\]

where

\[
\boxed{
A_S
=
E_U\langle e_S(U),c_S(U)\rangle,
}
\tag{3.2}
\]

\[
\boxed{
V_S
=
E_U\|c_S(U)\|^2.
}
\tag{3.3}
\]

The unit-amplitude correction improves squared population risk exactly when

\[
2A_S>V_S.
\]

Nothing in the fixed-population bias identity (1.3) determines the sign of this adaptive quantity.

The oracle clipped scalar gate

\[
\theta_S^\star
=
\Pi_{[0,1]}(A_S/V_S)
\]

when \(V_S>0\) never worsens squared population risk.

The statistical problem is to estimate enough of \(A_S,V_S\) without an untouched labeled block.

# 4. Full-pipeline leave-one-out setup

Let

\[
S=(Z_1,\ldots,Z_n),
\qquad
Z_i=(U_i,G(U_i))
\]

be iid deployment-distribution observations.

The learning algorithm may include:

- neural-mean fitting;
- learned representation construction;
- kernel/ridge/scale selection;
- stacking;
- residual-label construction;
- final residual KRR.

For every training set \(T\) of size \(n,n-1\), or \(n-2\), let the entire algorithm output

\[
m_T,\qquad c_T.
\]

The appearance of size \(n-2\) fits is not cosmetic. It is needed below to compare two size-\((n-1)\) leave-one-out fits which differ by one observation through their common deletion.

Any auxiliary randomness or a genuinely disjoint validation set may be conditioned on throughout.

A leave-one-out fit \(S^{-i}\) must exclude \(Z_i\) from **every stage that can use \(Z_i\)**. If \(Z_i\) participates in kernel/ridge tuning or representation training, merely removing it from the final linear solve is not enough.

Define

\[
\ell_T(z)
=
\langle
G(u)-m_T(u),
c_T(u)
\rangle,
\tag{4.1}
\]

\[
v_T(z)
=
\|c_T(u)\|^2.
\tag{4.2}
\]

Then

\[
A_T=E_Z\ell_T(Z),
\qquad
V_T=E_Zv_T(Z).
\]

The honest leave-one-out statistics are

\[
\boxed{
\widehat A_{\rm loo}
=
\frac1n
\sum_{i=1}^n
\ell_{S^{-i}}(Z_i),
}
\tag{4.3}
\]

\[
\boxed{
\widehat V_{\rm loo}
=
\frac1n
\sum_{i=1}^n
v_{S^{-i}}(Z_i).
}
\tag{4.4}
\]

For each \(i\),

\[
Z_i\perp S^{-i},
\]

but the \(n\) terms are not mutually independent.

# 5. New abstraction: RMS functional deletion stability

The previous theorem assumed a deterministic sup-norm bound on how much the entire fitted functions changed after deleting one row.

The new theorem needs only integrated \(L^2\) control of the **two risk-relevant scalar functionals**.

Assume that for every relevant training set \(T\) of size \(n\) or \(n-1\), and every one-point deletion \(T^{-i}\),

\[
\boxed{
\|\ell_T-\ell_{T^{-i}}\|_{L^2(\mu)}
\le
\gamma_A,
}
\tag{5.1}
\]

\[
\boxed{
\|v_T-v_{T^{-i}}\|_{L^2(\mu)}
\le
\gamma_V.
}
\tag{5.2}
\]

Assume also uniform second-moment envelopes

\[
\boxed{
\|\ell_T\|_{L^2(\mu)}
\le
B_A,
\qquad
\|v_T\|_{L^2(\mu)}
\le
B_V.
}
\tag{5.3}
\]

These conditions are strictly weaker than pointwise deletion stability.

They permit large pointwise changes on a small deployment-probability set, as long as the risk-relevant \(L^2\) energy remains controlled.

Two samples of the same size differing in one observation have a common deletion. Therefore (5.1)–(5.2) imply the one-replacement bounds

\[
\|\ell_T-\ell_{T'}\|_2
\le
2\gamma_A,
\tag{5.4}
\]

\[
\|v_T-v_{T'}\|_2
\le
2\gamma_V.
\tag{5.5}
\]

E\,\ell_{S^{-i}}(Z_i)
=

Also,

\[
|A_S-A_{S^{-i}}|
\le
\|\ell_S-\ell_{S^{-i}}\|_{L^1}
\le
\gamma_A.

Therefore

\[
\boxed{
\left|
E\left[
A_S-\widehat A_{\rm loo}
\right]
\right|
\le
\gamma_A.
}
\tag{6.1}
\]

Similarly,

\[
\boxed{
\left|
E\left[
V_S-\widehat V_{\rm loo}
\right]
\right|
\le
\gamma_V.
}
\tag{6.2}
\]

No independence among the leave-one-out fits is used.

# 7. Efron–Stein variance calculation

Define

\[
F_A(S)
=
A_S-\widehat A_{\rm loo},
\tag{7.1}
\]

\[
F_V(S)
=
V_S-\widehat V_{\rm loo}.
\tag{7.2}
\]

Let \(S^{(k)}\) replace \(Z_k\) by an independent copy \(Z_k'\).

We bound the mean square change of \(F_A\) under that replacement.

## 7.1 Full-fit population term

The full size-\(n\) fits on \(S\) and \(S^{(k)}\) differ in one observation and have common deletion \(S^{-k}\). Hence

\[
|A_S-A_{S^{(k)}}|
\le
2\gamma_A.
\tag{7.3}
\]

## 7.2 Held-out LOO term at \(k\)

The fit is the same on both sides:

\[
S^{-k}=(S^{(k)})^{-k}.
\]

Only the evaluation point changes. Conditional on this fit,

\[
E\left[
\left(
\ell_{S^{-k}}(Z_k)
-
\ell_{S^{-k}}(Z_k')
\right)^2
\mid
S^{-k}
\right]
\le
4B_A^2.
\tag{7.4}
\]

## 7.3 Other LOO terms

Fix \(j\ne k\).

The size-\((n-1)\) training sets

\[
S^{-j}
\]

and

\[
(S^{(k)})^{-j}
\]

differ in exactly one row and have a common size-\((n-2)\) deletion.

Hence

\[
\|
\ell_{S^{-j}}
-
\ell_{(S^{(k)})^{-j}}
\|_2
\le
2\gamma_A.
\tag{7.5}
\]

Crucially, \(Z_j\) is absent from both fits. Thus \(Z_j\) is independent of the functions in (7.5), and

\[
E
\left[
\left(
\ell_{S^{-j}}(Z_j)
-
\ell_{(S^{(k)})^{-j}}(Z_j)
\right)^2
\right]
\le
4\gamma_A^2.
\tag{7.6}
\]

This is the dependence-preserving step. The LOO summands are not declared independent; only the specific held-out point \(Z_j\) is used as an honest evaluation point for the two fits which omit it.

## 7.4 Replacement sensitivity of \(F_A\)

Using

\[
(a+b+c)^2
\le
3(a^2+b^2+c^2)
\]

and

\[
\left(
\sum_{j\ne k}x_j
\right)^2
\le
(n-1)\sum_{j\ne k}x_j^2,
\]

we obtain

\[
\boxed{
E\left[
F_A(S)-F_A(S^{(k)})
\right]^2
\le
24\gamma_A^2
+
\frac{12B_A^2}{n^2}.
}
\tag{7.7}
\]

The Efron–Stein inequality therefore gives

\[
\boxed{
\operatorname{Var}(F_A)
\le
12n\gamma_A^2
+
\frac{6B_A^2}{n}.
}
\tag{7.8}
\]

Exactly the same argument yields

\[
\boxed{
\operatorname{Var}(F_V)
\le
12n\gamma_V^2
+
\frac{6B_V^2}{n}.
}
\tag{7.9}
\]

No deterministic sup-norm change bound appears in (7.8)–(7.9).

Under (5.1)–(5.3), with probability at least

\[

over the original same sample \(S\),

\[
\boxed{

\ge
L_{\rm rms},
\qquad

\le

\boxed{

# 9. Proof of P15-RMS-LOOGATE-02

By (6.1),

\[
E F_A\ge-\gamma_A.
\]

By (7.8) and Chebyshev,

\[
P\left\{
F_A-EF_A
<
-
\sqrt{
\frac{
2\operatorname{Var}(F_A)
}{\delta}
}
\right\}
\le
\frac{\delta}{2}.
\]

Using (7.8),

\[
\sqrt{
\frac{
2\operatorname{Var}(F_A)
}{\delta}
}
\le
\sqrt{
\frac{
24n\gamma_A^2+12B_A^2/n
}{\delta}
}.
\]

Thus with failure probability at most \(\delta/2\),

\[
A_S
\ge
\widehat A_{\rm loo}
-
\varepsilon_A^{\rm rms}.
\]

Likewise, by (6.2), (7.9) and Chebyshev, with failure probability at most \(\delta/2\),

\[
V_S
\le
\widehat V_{\rm loo}
+
\varepsilon_V^{\rm rms}.
\]

A union bound gives (8.6).

Now use the exact quadratic risk identity:

\[
\mathcal R_S(0)-\mathcal R_S(\theta)
=
2\theta A_S-\theta^2V_S.
\]

On the good event,

\[
2\theta A_S-\theta^2V_S
\ge
2\theta L_{\rm rms}
-
\theta^2U_{\rm rms}.
\]

The right side is a concave quadratic on \([0,1]\), whose maximizer is exactly (8.5). This proves (8.7) and the theorem.

# 10. Pipeline specialization: \(L^2\) deletion stability of mean and correction

The abstract theorem is directly implied by the RMS quantities proposed in the previous P15 report.

Assume deterministic output envelopes, for every relevant \(T\),

\[
\boxed{
\|G(u)-m_T(u)\|
\le
E,
\qquad
\|c_T(u)\|
\le
C
\quad
\forall u.
}
\tag{10.1}
\]

But replace the old **supremum deletion stability** by only

\[
\boxed{
\|m_T-m_{T^{-i}}\|_{L^2(\mu)}
\le
\eta_m,
}
\tag{10.2}
\]

\[
\boxed{
\|c_T-c_{T^{-i}}\|_{L^2(\mu)}
\le
\eta_c.
}
\tag{10.3}
\]

Then

\[
\ell_T-\ell_{T^{-i}}
=
\langle
m_{T^{-i}}-m_T,
c_T
\rangle
+
\langle
G-m_{T^{-i}},
c_T-c_{T^{-i}}
\rangle,
\]

so

\[
\boxed{
\gamma_A
\le
C\eta_m+E\eta_c.
}
\tag{10.4}
\]

Also,

\[
v_T-v_{T^{-i}}
=
\langle
c_T-c_{T^{-i}},
c_T+c_{T^{-i}}
\rangle,
\]

hence

\[
\boxed{
\gamma_V
\le
2C\eta_c.
}
\tag{10.5}
\]

Moreover,

\[
B_A\le EC,
\qquad
B_V\le C^2.
\tag{10.6}
\]

Therefore P15-RMS-LOOGATE-02 applies.

For the \(V\) term one can exploit the stronger pointwise range

\[
0\le v_T\le C^2.
\]

The held-out replacement in Section 7.2 then changes \(v_T\) by at most \(C^2\), not \(2C^2\). This improves (8.2) to

\[
\boxed{
\varepsilon_{V,\infty/L^2}^{\rm rms}
=
\gamma_V
+
\sqrt{
\frac{
24n\gamma_V^2
+
3C^4/n
}{
\delta
}
}.
}
\tag{10.7}
\]

For \(A\),

\[
\boxed{
\varepsilon_{A,\infty/L^2}^{\rm rms}
=
\gamma_A
+
\sqrt{
\frac{
24n\gamma_A^2
+
12E^2C^2/n
}{
\delta
}
}.
}
\tag{10.8}
\]

This is the promised theorem with exactly the integrated quantities

\[
E_U\|m_S(U)-m_{S^{-i}}(U)\|^2,
\]

\[
E_U\|c_S(U)-c_{S^{-i}}(U)\|^2.
\]

The pointwise assumption is now only an output envelope, not a stability assumption.

# 11. All-integrated \(L^4\) variant

The global envelopes in (10.1) can also be removed if one is willing to control fourth moments.

Assume uniformly over relevant \(T\),

\[
\|G-m_T\|_{L^4(\mu)}
\le
E_4,
\qquad
\|c_T\|_{L^4(\mu)}
\le
C_4,
\tag{11.1}
\]

and deletion stability in \(L^4\):

\[
\|m_T-m_{T^{-i}}\|_{L^4(\mu)}
\le
\eta_{m,4},
\tag{11.2}
\]

\[
\|c_T-c_{T^{-i}}\|_{L^4(\mu)}
\le
\eta_{c,4}.
\tag{11.3}
\]

Hölder gives

\[
\boxed{
\gamma_A
\le
C_4\eta_{m,4}
+
E_4\eta_{c,4},
}
\tag{11.4}
\]

\[
\boxed{
\gamma_V
\le
2C_4\eta_{c,4},
}
\tag{11.5}
\]

and

\[
\boxed{
B_A\le E_4C_4,
\qquad
B_V\le C_4^2.
}
\tag{11.6}
\]

Therefore the abstract theorem applies without any global pointwise envelope.

This variant is useful when neural outputs are naturally controlled in moments but not uniformly over the whole input domain.

# 12. Rates and the price of weaker stability

Suppose \(B_A,B_V=O(1)\) and

\[
\gamma_A,\gamma_V=O(1/n).
\]

At fixed confidence level,

\[
\boxed{
\varepsilon_A^{\rm rms},
\varepsilon_V^{\rm rms}
=
O(n^{-1/2}).
}
\tag{12.1}
\]

More generally, the certificate is consistent if

\[
\boxed{
\sqrt n\,\gamma_A\to0,
\qquad
\sqrt n\,\gamma_V\to0.
}
\tag{12.2}
\]

Under the bounded-output specialization this follows from

\[
\sqrt n\,(\eta_m+\eta_c)\to0.
\]

The tradeoff versus `P15-LOOGATE-01` is exact:

- **Uniform sup deletion stability** gives exponential McDiarmid tails and confidence width proportional to
  \[
  \sqrt{\log(1/\delta)}.
  \]
- **RMS functional stability** gives the same \(n^{-1/2}\) scale under \(O(1/n)\) stability but, with only second moments, the present proof pays
  \[
  \delta^{-1/2}.
  \]

This is not a proof artifact that should be hidden. The new theorem weakens the stability norm at the price of a weaker confidence tail.

For a finite family of \(H\) candidates, a naive union bound with this Chebyshev certificate scales the confidence widths like \(\sqrt{H/\delta}\), not \(\sqrt{\log H}\). Recovering a logarithmic multiplicity price under integrated stability is a separate concentration problem.

# 13. Relation to P15-STAB-03 and learned representations

The new theorem was designed to connect to the earlier ridge-preconditioned stability machinery.

For two realized KRR systems, P15-STAB-03 controls correction differences through the relative Gram perturbation

\[
F
=
A^{-1/2}(A'-A)A^{-1/2},
\]

with residual-weighted spectral energy

\[
\boxed{
\delta_A^2
=
\operatorname{tr}
\left[
R^\top A^{-1/2}
F^2(I+F)^{-1}
A^{-1/2}R
\right],
}
\tag{13.1}
\]

and query-map defect

\[
\boxed{
\delta_q^2
=

# 16. Counterexamples and sharp warnings

### Population eigenbasis bias

**INSUFFICIENT.**

Equation (1.3) is a fixed-operator bias calculation. It contains no adaptive same-sample alignment \(A_S\).

### Training residual decrease

**INSUFFICIENT / FALSE AS A GENERALIZATION GUARANTEE.**

A learner can reduce its training residual while moving error to high-probability unseen inputs.

### Cross-fitting alone

**INSUFFICIENT.**

It removes one dependence path but does not imply

\[
A_S>0
\]

or

\[
2A_S>V_S.
\]

### Leave-one-out evaluation alone

**DISPROVED.**

The existing parity counterexample has a full-data harmful correction but leave-one-out fits which appear perfectly beneficial.

### RMS stability with no moment control

**INSUFFICIENT for the present high-probability theorem.**

The Efron–Stein calculation also needs finite second moments of \(\ell_T\) and \(v_T\). Since

\[
v_T=\|c_T\|^2,
\]

this is naturally a fourth-moment condition on the correction if no pointwise envelope is available.

### Integrated stability gives exponential confidence automatically

**FALSE.**

With only the second-moment control used here, the direct certificate has polynomial confidence dependence \(\delta^{-1/2}\), not a McDiarmid \(\sqrt{\log(1/\delta)}\) dependence.

### Finite-grid selection remains logarithmic under the new theorem

**NOT PROVED.**

A naive union bound with Chebyshev costs \(\sqrt H\), not \(\sqrt{\log H}\).

### Small absolute Gram perturbation at tiny ridge

**REJECTED.**

The correct stability quantity remains ridge-preconditioned, as in P15-STAB-03.

### Squared-risk safety settles the manuscript's headline metric

**FALSE.**

The manuscript reports mean relative \(L^2\) error, which is unsquared. The present theorem is a squared-population-risk theorem. A separate theorem or direct paired certification is needed for exact ordering of the reported metric.
