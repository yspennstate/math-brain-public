# Agent 020: the half-averaging endpoint for four-type strictly non-Volterra QSOs

Timestamp: 2026-09-14T21:11:09Z. Track: QSO Problem 11, endpoint averaged dynamics.

**Status: PROVED by the argument below, subject to independent audit.** For every four-type strictly non-Volterra quadratic stochastic operator, the half-averaging map is a strict ordinary `l1` contraction on its third image. The contraction factor can be chosen uniformly over all admissible operators. Consequently every half-averaged orbit converges geometrically to the unique fixed point, and a single finite iterate, also independent of the coefficients, is a strict contraction of the entire simplex.

The factor and the finite iterate are proved to exist; no numerical value for either is claimed. This report settles the previously unresolved endpoint in Agent 008, Section 9. It makes no claim about raw iteration, larger averaging parameters, or worldwide novelty.

No subagents were spawned, GitHub writes performed, shared manuscripts edited, or third parties contacted. The assigned report is the only file written by this worker. No computational experiment or external literature search was needed for the proof.

## 1. Exact statement

Let
\[
\Delta_3=\{x\in\mathbb R_+^4:\textstyle\sum_i x_i=1\},
\qquad V_{P,k}(x)=\sum_{i,j=1}^4 P_{ij,k}x_ix_j,
\]
where
\[
P_{ij,k}=P_{ji,k}\ge0,\qquad \sum_kP_{ij,k}=1,
\qquad P_{ij,k}=0\quad\text{if }k\in\{i,j\}.
\tag{1}
\]
Write
\[
T_P=\tfrac12(I+V_P),\qquad S_P=T_P^3(\Delta_3).
\]

**Theorem.** There is a constant \(\rho\in(0,1)\), independent of \(P\), such that
\[
\|T_Pu-T_Pv\|_1\le\rho\|u-v\|_1
\qquad(u,v\in S_P).
\tag{2}
\]
The set \(S_P\) is nonempty, compact, and invariant under \(T_P\). Thus \(V_P\) has exactly one fixed point \(p_P\) in the whole simplex, and for all \(x\in\Delta_3\) and \(n\ge3\),
\[
\|T_P^nx-p_P\|_1\le 2\rho^{n-3}.
\tag{3}
\]
There is also an integer \(N\), independent of \(P\), for which \(T_P^N\) is a strict `l1` contraction of \(\Delta_3\). More precisely, any integer \(k\ge0\) satisfying \(\rho^k<2/3\) gives
\[
\|T_P^{k+3}x-T_P^{k+3}y\|_1
\le\tfrac32\rho^k\|x-y\|_1
\qquad(x,y\in\Delta_3).
\tag{4}
\]

The proof accommodates zero coefficients and boundary fixed points. It does not assume that an image set is convex.

## 2. The two-step cap, rechecked

Put
\[
q=\frac{49}{128}<\frac12,
\qquad K_q=\{x\in\Delta_3:x_i\le q\text{ for every }i\}.
\]
We rederive Agent 008's endpoint cap so that the present theorem has an explicit dependency chain.

Fix a coordinate \(r\), and abbreviate \(s=x_r\), \(v=V_{P,r}(x)\), \(y=T_Px\). Condition (1) implies
\[
0\le v\le(1-s)^2,\qquad y_r=(s+v)/2,\qquad y_i\ge x_i/2.
\]
The defect in the scalar upper bound obeys
\[
\begin{aligned}
(1-y_r)^2-V_{P,r}(y)
&=\sum_{i,j\ne r}(1-P_{ij,r})y_iy_j\\
&\ge\tfrac14\sum_{i,j\ne r}(1-P_{ij,r})x_ix_j\\
&=\tfrac14[(1-s)^2-v].
\end{aligned}
\]
For \(f(t)=\tfrac12t+\tfrac12(1-t)^2\), therefore,
\[
(T_P^2x)_r\le f((s+v)/2)-\tfrac18[(1-s)^2-v]
=\frac{3+(2s-1)v+v^2}{8}.
\tag{5}
\]
The last expression is convex in \(v\). Its two endpoint values on
\([0,(1-s)^2]\) are
\[
\frac38,\qquad \frac{3+s^2(1-s)^2}{8}\le\frac{49}{128}.
\]
Hence
\[
T_P^2(\Delta_3)\subseteq K_q.
\tag{6}
\]
Images of any self-map are nested:
\(T_P^{n+1}(\Delta_3)=T_P^n(T_P\Delta_3)\subseteq T_P^n(\Delta_3)\).
Thus \(S_P\subseteq K_q\), and every midpoint of two points of \(S_P\) also belongs to \(K_q\).

## 3. Support stabilization and the midpoint issue

For a nonempty set of types \(D\), define
\[
F_P(D)=D\cup\{r:P_{ij,r}>0\text{ for some }i,j\in D\}.
\]
Nonnegativity and the retained identity term give the exact identity
\[
\operatorname{supp}(T_Px)=F_P(\operatorname{supp}x).
\tag{7}
\]
In particular supports grow monotonically. If one step leaves a support unchanged, all later steps do too. If the support of \(T_P^3x\) were not stable, the supports at steps 0, 1, 2, 3, and 4 would all be strictly increasing, requiring at least five types. Thus
\[
\operatorname{supp}(T_P^3x)\text{ is stable under }F_P.
\tag{8}
\]

A stable support cannot have one type: the diagonal parent pair must produce a different type. It cannot have two types \(i,j\): the mixed pair \(i,j\) must produce a type outside that pair. Therefore each support in (8) has at least three types.

If a stable support is a triple \(D\) missing type \(r\), then
\[
P_{ij,r}=0\qquad(i,j\in D).
\tag{9}
\]
Indeed any positive such coefficient would add \(r\) to the support. Thus the face supported on \(D\) is invariant. In particular each mixed pair of distinct members of \(D\) produces its third member with probability one.

Now take \(u,v\in S_P\) and \(m=(u+v)/2\). Its support is exactly the union of their supports. If this union is all four types, \(m\) is interior. If it is proper, each of the two sets has at least three members, so both are the **same invariant triple**. In that case \(\operatorname{supp}m\) is that invariant triple and satisfies (9).

This resolves a genuine union-of-support issue: unions of invariant supports are not being declared invariant in general. The conclusion here follows because there are only four types and each support has at least three members.

## 4. All ambient pairs of columns overlap

Define
\[
A_P(m)_{ri}=\sum_aP_{ai,r}m_a.
\tag{10}
\]
This is nonnegative, column-stochastic, and has zero diagonal. For a column-stochastic matrix \(A\), write
\[
\delta(A)=\frac12\max_{i,j}\|Ae_i-Ae_j\|_1
=1-\min_{i,j}\sum_r\min(A_{ri},A_{rj}).
\tag{11}
\]
Thus \(\delta(A)<1\) exactly when every pair of columns has positive overlap.

**Lemma.** If \(m\) is a midpoint of two points of \(S_P\), then
\[
\delta(A_P(m))<1.
\tag{12}
\]

**Proof.** First consider two distinct types \(i,j\) with \(m_i,m_j>0\). Symmetry in (1) implies, coordinatewise,
\[
A_P(m)_{ri}\ge m_jP_{ij,r},\qquad
A_P(m)_{rj}\ge m_iP_{ij,r}.
\]
Consequently
\[
\sum_r\min(A_P(m)_{ri},A_P(m)_{rj})
\ge\min(m_i,m_j)\sum_rP_{ij,r}
=\min(m_i,m_j)>0.
\tag{13}
\]
This handles every column pair when \(m\) has full support.

If \(m\) has proper support, Section 3 gives an invariant triple
\(D=\{j,k,\ell\}\) and a single missing type \(r\). Active-active pairs are already handled by (13). For the remaining pair, consisting of column \(r\) and an arbitrary active column \(j\), invariance and strict non-Volterra offspring rules give
\[
P_{\ell j,k}=P_{kj,\ell}=1,
\qquad
A_P(m)_{kj}\ge m_\ell>0,
\qquad A_P(m)_{\ell j}\ge m_k>0.
\tag{14}
\]
The parent pair \(j,r\) can produce only \(k\) or \(\ell\), so
\[
A_P(m)_{kr}+A_P(m)_{\ell r}
\ge m_j(P_{jr,k}+P_{jr,\ell})=m_j>0.
\tag{15}
\]
At least one of these two entries of column \(r\) is positive, while both corresponding entries of column \(j\) are positive by (14). Hence the columns overlap. This covers every ambient column pair, including the one involving the absent type. Equation (11) proves (12). \(\square\)

The last case is essential: proving overlap only for columns indexed by positive coordinates would suffice for some feasible secants but would not justify a uniform bound on the entire zero-sum tangent space.

## 5. A refined cut bound for the half-average

For any equal-column-sum matrix \(B\), its induced `l1` norm on
\(E=\{z:\sum_i z_i=0\}\) equals
\[
\delta_E(B)=\frac12\max_{i,j}\|Be_i-Be_j\|_1
=\max_{G\subseteq\{1,2,3,4\},\,i,j}
\sum_{r\in G}(B_{ri}-B_{rj}).
\tag{16}
\]
The first equality follows by decomposing a zero-sum vector into a convex combination of differences of coordinate vectors, with total weight \(\|z\|_1/2\). The second follows because each column difference has sum zero.

Set \(A=A_P(m)\) and \(B=\tfrac12 I+A\). Its column sum is \(3/2\), which does not invalidate (16). For a cut \(G\), the expression to bound is
\[
\tfrac12(\mathbf1_G(i)-\mathbf1_G(j))+D_A(G;i,j),
\quad D_A(G;i,j)=\sum_{r\in G}(A_{ri}-A_{rj}).
\]
Assuming \(m\in K_q\), the exhaustive bounds are:

| Cut case | Bound |
| --- | --- |
| Both indices in \(G\), or both outside | \(D_A\le\delta(A)\) |
| \(i\notin G,\ j\in G\) | \(-1/2+D_A\le1/2\) |
| \(i\in G,\ j\notin G,\ |G|=1\) | \(1/2-A_{ij}\le1/2\) |
| \(i\in G,\ j\notin G,\ |G|=3\) | \(1/2-A_{ji}\le1/2\) |
| \(i\in G,\ j\notin G,\ |G|=2\) | \(1/2+\max(m_i,m_j)\le1/2+q\) |

Empty and full cuts, and \(i=j\), contribute zero. For completeness, the last row follows from the four-type transfer calculation. Write \(G=\{i,k\}\), \(G^c=\{j,\ell\}\), and
\(p_{ab}=\sum_{r\in G}P_{ab,r}\). Then
\(p_{ki}=0\), \(p_{\ell j}=1\), and \(p_{ij}=p_{ji}\), so
\[
\begin{aligned}
D_A(G;i,j)
&=m_i(p_{ii}-p_{ij})+m_j(p_{ij}-p_{jj})
-m_kp_{kj}+m_\ell(p_{\ell i}-1)\\
&\le m_i(1-p_{ij})+m_jp_{ij}
\le\max(m_i,m_j).
\end{aligned}
\]
It follows that
\[
\boxed{\quad
\delta_E(\tfrac12I+A_P(m))
\le\max\{\tfrac12+q,\delta(A_P(m))\}.
\quad}
\tag{17}
\]
For the midpoints under consideration, (12), (6), and \(1/2+q=113/128<1\) show that the right side is strictly below one.

## 6. Compactness gives a uniform strict factor

Let \(\mathcal P\) be the set of all coefficient arrays satisfying (1). It is a nonempty compact subset of a finite-dimensional Euclidean space: symmetry and the forbidden coefficients are closed linear restrictions, the coefficients are nonnegative, and their specified sums equal one.

The function
\[
d(P,x,y)=\delta\!\left(A_P\!\left(
\frac{T_P^3x+T_P^3y}{2}\right)\right)
\tag{18}
\]
is continuous on the compact set \(\mathcal P\times\Delta_3\times\Delta_3\). This follows directly from the polynomial formulas for \(T_P\) and \(A_P\), and the finite maximum formula in (11). Section 4 proves \(d(P,x,y)<1\) at **every** point of that compact domain, including degenerate coefficient arrays and boundary starting points. Therefore its attained maximum satisfies
\[
\sigma=\max_{P,x,y}d(P,x,y)<1.
\tag{19}
\]
This strict conclusion uses compactness of the original parameterized domain; it does not incorrectly assume that the stratum of full-support points is closed.

Define
\[
\boxed{\qquad\rho=\max\{113/128,\sigma\}<1.\qquad}
\tag{20}
\]
For \(u,v\in S_P\), parent symmetry gives exact quadratic polarization:
\[
T_Pu-T_Pv=
\left(\tfrac12 I+A_P((u+v)/2)\right)(u-v).
\tag{21}
\]
Since \(u-v\in E\), equations (17)--(21) prove the uniform contraction (2).

## 7. Convergence, uniqueness, and a globally contracting iterate

Continuity of \(T_P^3\) makes \(S_P\) nonempty and compact, hence complete in the inherited metric. Nested images give
\(T_P(S_P)=T_P^4(\Delta_3)\subseteq S_P\).
Banach's contraction theorem applied to (2) supplies its unique fixed point \(p_P\). Since \(T_Pz=z\) is equivalent to \(V_Pz=z\), this is a fixed point of \(V_P\). Any fixed point in the whole simplex belongs to \(S_P\), because \(z=T_P^3z\); hence there are no additional fixed points outside \(S_P\).

Every initial point enters \(S_P\) after three steps. Applying (2) repeatedly and using the simplex diameter bound \(\|a-b\|_1\le2\) proves (3).

For the finite-iterate assertion, first observe that
\[
(T_Px)_i\le f(x_i)\le\max\{f(0),f(1)\}=1/2,
\]
so \(T_P\Delta_3\subseteq K_{1/2}\). The cut proof above with \(q=1/2\) and \(\delta(A)\le1\) shows that \(T_P\) is nonexpansive on \(K_{1/2}\). On the whole simplex it is at most \(3/2\)-Lipschitz: the nonnegative matrix in (21) has every column sum equal to \(3/2\), so its full `l1` operator norm is \(3/2\). It follows that
\[
\|T_P^3x-T_P^3y\|_1\le\|T_Px-T_Py\|_1
\le\tfrac32\|x-y\|_1.
\]
Combine this with \(k\) applications of (2) to obtain (4). As \(\rho<1\), a common finite \(k\) with \(\rho^k<2/3\) exists. No numerical claim about its size is made.

## 8. Why the cap alone did not prove a uniform norm gap

Here is an exact obstruction to replacing the image condition by an arbitrary point of \(K_q\) when bounding the entire tangent space. Let
\(m=(1/3,1/3,1/3,0)\), and use the following deterministic offspring choices:

| Parent pair | Offspring |
| --- | --- |
| 11 | 4 |
| 12 | 4 |
| 13 | 4 |
| 14 | 2 |
| 22 | 1 |
| 23 | 1 |
| 24 | 3 |
| 33 | 1 |
| 34 | 2 |
| 44 | 1 |

All rules satisfy (1). Direct substitution gives
\[
Ae_1=e_4,\qquad Ae_4=(0,2/3,1/3,0),
\]
and
\[
(\tfrac12I+A)(e_1-e_4)=(1/2,-2/3,-1/3,1/2).
\]
The last vector has `l1` norm 2, so the induced norm on \(E\) equals 1, by the upper bound at \(m\in K_q\). The support triple of \(m\) is not invariant: for example, parent pair 11 produces the missing type 4. Thus this midpoint is excluded by Section 3.

Also, \(e_1-e_4\) is not the difference direction of a nontrivial symmetric pair of simplex points with midpoint \(m\), because the fourth coordinate of \(m\) is zero. Consequently this example is an obstruction to an **ambient matrix norm** argument based only on the cap; it is not claimed to refute strict distance decrease for actual feasible pairs in that cap. The proof above handles the stronger ambient estimate by using the invariant image.
