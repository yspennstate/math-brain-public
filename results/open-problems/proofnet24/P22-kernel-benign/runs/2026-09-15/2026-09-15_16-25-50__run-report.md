# 12. New universal bound on one-step degree-two innovation

The preceding exact telescope still leaves a sum over all residual ranks. The key new observation is that each rank-one deletion has a dimension-free degree-two mark.

For a rank-one coefficient projector Q=w w^T, let N=T(w) be the corresponding traceless symmetric d by d matrix. The coefficient/matrix identification is Frobenius-isometric, so

tr(N^2)=1.

The rank-one Christoffel/Jordan formula gives

e(Q)=tr(N^4)-1/d

and

G(Q)=beta_d e(Q).

Let lambda_1,...,lambda_d be the real eigenvalues of N. Since Sum lambda_i^2=1,

Sum lambda_i^4 >= (Sum lambda_i^2)^2/d = 1/d

Sum lambda_i^4 <= (Sum lambda_i^2)^2 = 1.

0 <= e(Q) <= 1-1/d,

0 <= V_s(P) <= E[G(Q_s)|P_s=P]
