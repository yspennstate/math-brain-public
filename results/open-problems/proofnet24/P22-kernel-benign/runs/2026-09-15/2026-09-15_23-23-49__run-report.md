## 16. New theorem: determinant-tilted inverse matrix is an exact second-order design

### `P22-T4-DETTILT-INVERSE-2DESIGN-36` — PROVED

Continue the general square iid centered isotropic setup of Section 14, and write

`B=A^(-1)`.

I now compute the full bilinear covariance of inverse entries, not only the same-right-hand-side covariance.

For row/RHS indices i,l and output/column indices j,k, Cramer's formula gives on the almost-sure full-rank event

`det(A)^2 B_(j i) B_(k l)`

` = (-1)^(i+j+l+k) det A_(-i,-j) det A_(-l,-k)`.

Under determinant-square tilt,

`E_Q[B_(j i) B_(k l)]`

` = 1/m! * (-1)^(i+j+l+k)`

`   * E[det A_(-i,-j) det A_(-l,-k)]`.

If `i != l`, condition on row i. The first minor does not contain row i, while the second minor is linear in that centered row. The conditional expectation is zero.

If `i=l`, both minors use the same m-1 independent centered isotropic rows. The standard determinant covariance identity gives

`E[det A_(-i,-j) det A_(-i,-k)]`

` = (m-1)! det(I_(J,K))`,

where `J=[m]\{j}` and `K=[m]\{k}`. The identity submatrix has determinant one for j=k and rank at most m-2 for j not equal to k. Hence

`E[det A_(-i,-j) det A_(-i,-k)] = (m-1)! delta_(j k)`.

The surviving sign is one. Dividing by m! proves the exact entrywise formula

`E_Q[B_(j i) B_(k l)] = delta_(j k) delta_(i l)/m`.

The same one-row conditioning argument gives `E_Q B_(j i)=0`.

Therefore

`E_Q vec(B) vec(B)^T = (1/m) I_(m^2)`.

This statement uses only:

1. iid rows;
2. row centeredness;
3. row covariance I_m;
4. almost-sure nonsingularity so the inverse/cofactor cancellation is pointwise valid.

No row rotational invariance, independent coordinates, Gaussianity, spherical symmetry, bounded moments beyond second order, or asymptotic argument is used.

### 16.1 Bilinear right-hand-side identity

`E_Q[(B c)(B d)^T]_(j k)`

`E_Q[(B c)(B d)^T] = (c^T d/m) I_m`.

`E_Q <B c,B d> = c^T d`.

`E_Q[B C B^T] = (tr C/m) I_m`

for every deterministic m by m matrix C, with no symmetry assumption on C.

`E_Q[B^T D B] = (tr D/m) I_m`

for every deterministic D.

Choosing C=D=I gives

`E_Q[B B^T] = I_m`,

`E_Q[B^T B] = I_m`,
