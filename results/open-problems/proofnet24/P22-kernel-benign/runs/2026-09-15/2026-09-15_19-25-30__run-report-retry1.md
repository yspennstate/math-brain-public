# 2. Critical harmonic dimensions

Put

`R = 2^ℓ`, `d = 2^R`, `n = d^R`, `k = R + ℓ - 1`.

The exact degree-s spherical-harmonic multiplicity is

`N_(d,s) = C(d+s-1,s) - C(d+s-3,s-2)`

`= (2s+d-2)(s+d-3)! / [s!(d-2)!]`.

At the actual growing critical degree k,

`N_(d,k)/n = d^(δ_*+o(1))`,

`D_<k/n = d^(-(1-δ_*)+o(1))`,

with

`δ_* = 1/log(2) - 1 = 0.4426950408...`,

`1-δ_* = 0.5573049592...`.

Both signs are bounded away from zero.

Uniformity is explicit: k = O(log d) and k²/d -> 0. Thus the factorial/multiplicity expansion is genuinely valid at growing degree; no fixed-degree asymptotic is extrapolated to k.

# 3. Exact Gaussian-kernel Mercer spectrum

Set a = h^(-2). On the unit sphere,

`K_h(x,y) = exp(-a) exp(a x·y)`.

The exact degree-s Mercer eigenvalue is

`λ_(d,s) = exp(-a) Σ_(r>=0) a^(s+2r) / [2^r r! d(d+2)...(d+2(s+r)-2)]`.

Equivalently,

`λ_(d,s) = exp(-a) Γ(d/2) (2/a)^(d/2-1) I_(s+d/2-1)(a)`.

NIST DLMF 10.25.2 gives the positive modified-Bessel power series. Every summand is positive for the present positive real a, so termwise comparison gives the whole-tail inequality

`λ_(d,s+1) <= [a/(d+2s)] λ_(d,s)`.

This is uniform in s, including the growing critical degree.

No fixed-s Mercer asymptotic is used at k.

Primary source checked: NIST DLMF §10.25(ii), equation 10.25.2, `https://dlmf.nist.gov/10.25`.

# 4. Growing-degree spherical hypercontractivity

For every pure degree-s spherical harmonic Y_s and p >= 2,

`||Y_s||_p <= (p-1)^(s/2) ||Y_s||_2`.

Derivation:

1. Homogeneously lift to Gaussian space: `F_s(g) = ||g||^s Y_s(g/||g||)`.
2. F_s is a homogeneous degree-s harmonic polynomial and lies in the s-th homogeneous Wiener chaos.
3. Nelson/Gross Ornstein-Uhlenbeck hypercontractivity gives `||F_s||_p <= (p-1)^(s/2)||F_s||_2`.
4. Write g = R U with R independent of U. Then `||F_s||_p = ||R^s||_p ||Y_s||_p` and similarly at p=2.
5. Since p >= 2, `||R^s||_p >= ||R^s||_2`, so division gives the spherical estimate with no extra degree factor.

There is no hidden C_s.

Status: PROVED / retained.

# 5. Infinite harmonic tail and Rosenthal

Define trace masses `τ_s = N_s λ_(d,s)` and normalize the tail kernel above degree k. The exact Mercer ratio yields the factorial estimate

`τ_(k+r)/τ_k <= C_h a^r k!/(k+r)!`.

At moment order q = R, after the hypercontractive cost the consecutive tail ratio is O(R^(-1/2)). Hence the normalized tail kernel r_T obeys

`||r_T(X,z)||_(2R) <= C_h (2R)^(k/2)/sqrt(N_k)`,

`||r_T(X,z)^2||_2 <= C_h 3^k/N_k`,

`||r_T(X,z)^2||_R <= C_h (2R)^k/N_k`.

For fixed z apply scalar Rosenthal to independent centered summands `Y_i = r_T(X_i,z)^2 - E r_T(X_i,z)^2`. A deliberately conservative C p constant is enough. At p = R, after the column maximum and normalization, the two dangerous relative terms are

`d R 3^k / sqrt(n) = d^(-R/2+O(1)) -> 0`,

`R d^2 (2R)^k / n = d^(-R+ℓ+O(1)) -> 0`.

A stronger imported theorem is available: Osekowski's Hilbert-valued Burkholder-Rosenthal constant satisfies C_p = O(p/log p); independent scalar mean-zero summands are a special case. Thus the coarser O(p) budget is safe.

Primary boundary checked: Adam Osekowski, “A Note on the Burkholder-Rosenthal Inequality,” Bulletin of the Polish Academy of Sciences Mathematics 60(2), 2012, 177–185.

# 8. Low block and matrix Chernoff

`||Ψ(X_i)||² = D`,

`Ψ^T Ψ = n(I + o_op(1))`.

# 11. Fixed-degree signal bias and realized risk

`λ_(d,q_0) >= c_(h,q_0) d^(-q_0)`.

`||fhat_(T,sig)||_2² <= C_(h,q_0) B² d^(2q_0)/(n N_k) -> 0`.

# 14. New exact constant-mark calculus

## `P22-T4-CONSTANT-MARK-CALCULUS-32` — PROVED

Consider any reverse rank-one deletion chain on Sym_d^0 with residual ranks m,m-1,... satisfying:

- exact deletion mean `E[Q_s | P_s] = P_s/s`;
- Jordan recurrence `e_(s-1) = [(s-2)/s] e_s + γ_s`;
- full-rank boundary e_m = 0;
- rank-independent fourth-mark excess `γ_s = c >= 0`.

Both the coefficient-spherical/Haar benchmark and the known dynamic-orthobasis surrogate satisfy these assumptions, with different c.

### 14.1 Jordan defect

The exact recurrence solution is

`e_s(c) = [s(m-s)/(m-1)] c`.

At rank two,

`e_2(c) = 2[(m-2)/(m-1)] c`.

### 14.2 Consecutive-square overlap

P26's Volterra transform gives

`D_s = c/(s-1) - c Σ_(t=s+1)^m 1/[(t-1)(t-2)]`.

The sum telescopes, yielding

`D_s(c) = c/(m-1)`

at every rank.

For cutoff L,

`Σ_(s=3)^L D_s(c) = [(L-2)c]/(m-1)`.

### 14.3 Positive fourth-mark budget

The exact endpoint representation is

`e_2 = 2 Σ_(s=3)^m γ_s/[(s-1)(s-2)]`.

For constant source,

`F_L(c) := 2 Σ_(s=3)^L c/[(s-1)(s-2)] = 2c[1-1/(L-1)]`.

At L=m, F_m(c)=e_2(c) exactly.

### 14.4 Degree-two martingale innovation

P26's exact identity is

`E V_s / β_d = γ_s - e_s/s²`,

where `β_d = 8d(d+2)/(d+4)²`.

Insert the constant-source Jordan profile:

`I_s(c) := E V_s/β_d = c m(s-1) / [s(m-1)]`.

Therefore the normalized innovation accumulated through rank L is

`A_L(c) := Σ_(s=3)^L E V_s/[β_d(s-1)²]`

`= c [m/(m-1)] [1/2 - 1/L]`.

At L=m, A_m(c)=e_2(c)/4, exactly matching the quadratic-variation telescope.

These are exact finite-dimensional identities.
