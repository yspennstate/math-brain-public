## 4. Full proof of `P24-AV-P3-NO-UNIFORM-RIGHT-EXTRAPOLATION-60`

Fix arbitrary real exponents

`2 <= p < r < infinity`.

Choose any number `q` strictly between them; for definiteness set

`q := (p+r)/2`.

Define

`beta^2 := 2/(q-1)`.

Because `q>2`,

`0 < beta^2 < 2`.

Thus the pair

`A=Lambda`, `B=beta Lambda^(1/2)`

is source-admissible in the same Gelfand triple. Its variational `L^2` coercivity identity is

`<Lambda v,v> - (1/2)||beta Lambda^(1/2)v||_2^2`

`= (1-beta^2/2) ||v||_(H^1)^2`

with strictly positive margin

`1-beta^2/2 = 1 - 1/(q-1) = (q-2)/(q-1)`.

By construction,

`p_c(beta) = 1 + 2/beta^2 = q`.

Since `p<q`, the inherited positive theorem gives

`(A,B) in SMR^bullet_{p,0}`.

For `p=2` this is Theorem 3.17; for `p>2` it is the Bellman theorem followed by source Proposition 3.18.

Since `r>q=p_c(beta)`, the inherited deterministic-additive-noise pulse theorem gives

`(A,B) notin SMR_{r,0}`.

Bullet membership implies base membership, so

`(A,B) notin SMR^bullet_{r,0}`.

This proves the theorem.

### 4.1 No pair-independent right-neighborhood

Fix `p>=2` and `delta>0`. Apply the theorem with `r=p+delta`. Then a source-admissible pair belongs to `SMR^bullet_{p,0}` but fails already at `p+delta`.

Therefore there is no function `delta(p)>0`, depending only on the starting exponent and the source class, for which

`(A,B) in SMR^bullet_{p,0}`

would force

`(A,B) in SMR^bullet_{r,0}` for every `r in (p,p+delta(p)]`.

This strictly strengthens the earlier `p=2` no-uniform-higher-exponent result.

### 4.2 The obstruction is quantitative, not merely the L2 boundary

For `p>2`, the construction has

`1-beta^2/2 = (q-2)/(q-1) > (p-2)/(p-1) > 0`,

because `x -> (x-2)/(x-1)` is increasing for `x>2` and `q>p`.

So for a fixed `p>2`, the right-extrapolation radius can collapse to zero while the ordinary `L^2` variational coercivity margin stays uniformly bounded below by the positive `p`-dependent constant `(p-2)/(p-1)`.

The exact family also identifies the quantity that *does* collapse at the base exponent:

`r_*(beta)-p`

`= 1 + 2/beta^2 - p`

`= [2-beta^2(p-1)]/beta^2`

`= sigma_p(beta)/beta^2`.

Thus, in this family, the distance to the next failure exponent is exactly the stochastic-parabolicity slack at exponent `p`, normalized by `beta^2`. Any positive general extrapolation theorem must therefore depend on quantitative information not contained in the bare membership statement alone — for example a maximal-regularity constant, a coercivity/parabolicity margin, or another coefficient-sensitive parameter. This is an obstruction statement, not a conjectured sufficient condition.

## 11. Exact proposed proof algorithm and its failure point

A natural extrapolation algorithm based only on the premise of Problem 3 would be:

1. input `p` and a pair known only to satisfy `(A,B) in SMR^bullet_{p,0}`;
2. select a positive radius `delta(p)` independent of the particular pair;
3. conclude `SMR^bullet_{r,0}` for `p<r<=p+delta(p)`;
4. iterate if desired.

The theorem of Section 4 kills this algorithm exactly at step 2. Given any proposed positive `delta(p)`, choose `q in (p,p+delta(p))` and `beta^2=2/(q-1)`. The resulting pair is in the bullet class at `p` but fails base SMR from `q` onward. No pair-independent positive `delta(p)` can therefore be extracted from qualitative membership alone.

What the construction does **not** kill is an algorithm whose radius also depends on quantitative pair data. In the explicit family the exact available radius is

`r_*(beta)-p = sigma_p(beta)/beta^2`.

A source-level positive theorem would need an analogue of such a quantitative slack, or information strong enough to control it.
