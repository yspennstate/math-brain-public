# 4. Move #14 — FIND THE GROUP ACTING: translations split the problem into spectral shells

The torus translation group commutes with both `Lambda` and `Lambda^(1/2)`. Each real nonzero Fourier shell

`E_n = span{cos(nx), sin(nx)}`

is invariant, and `Lambda` acts there as a scalar multiple of the identity. The shell multiplicity is two on the real torus, but the argument below works for **arbitrary Hilbert multiplicity**.

This is the right quotient of the symmetry: before asking how distinct frequencies interact, decide the exact stochastic input/output problem when the deterministic generator is scalar on a Hilbert space.

## Theorem `P24-AV-P3-SPECTRAL-SHELL-EXACT-63`

Let `H` be a real Hilbert space, let `beta>=0`, and assume `beta^2<2`. Fix

`2 <= p < p_c(beta):=1+2/beta^2`.

For `L>0`, let `T_L` map an arbitrary progressively measurable `H`-valued input `Y` to the zero-initial solution `Z` of

`dZ_s = -Z_s ds + (beta Z_s + Y_s)dW_s`, `Z_0=0`,          (4.1)

where `W` is one real Brownian motion. Then

`||T_L||_(Lp(Omega x [0,L];H) -> Lp(Omega x [0,L];H)) <= R_*(p,beta)`

for every `L`, where

`R_*(p,beta)=1/[sqrt(2/(p-1))-beta]`.                     (4.2)

Moreover

`sup_(L>0) ||T_L|| = R_*(p,beta)`.                         (4.3)

Thus the exact uniform-horizon constant is independent of `dim H`.

### Proof — upper bound

Write

`I = E integral_0^L ||Z_s||^p ds`,

`J = E integral_0^L ||Y_s||^p ds`.

For `p=2`, apply Itô directly to `||Z||^2`. For `p>2`, first localize and apply Itô to the smooth regularization

`phi_epsilon(z)=(||z||^2+epsilon)^(p/2)`

and then let `epsilon` decrease to zero. The localization removes any integrability circularity; after the estimate below, monotone/Fatou passage removes the stopping. This is standard finite-energy Hilbert-valued Itô calculus and no coordinate dimension enters.

For `z,h in H`,

`D^2 ||z||^p[h,h]`

` = p ||z||^(p-2)||h||^2 + p(p-2)||z||^(p-4)<z,h>^2`

` <= p(p-1)||z||^(p-2)||h||^2`.                           (4.4)

Using `h=beta z+y`, Itô's formula and (4.4) give, after expectation,

`E||Z_L||^p + p delta I`

` <= p(p-1) beta E integral ||Z||^(p-1)||Y|| ds`

`    + [p(p-1)/2] E integral ||Z||^(p-2)||Y||^2 ds`,      (4.5)

where

`delta = 1 - beta^2(p-1)/2 > 0`.                         (4.6)

Indeed, the drift contributes `-p||Z||^p`; the `beta^2||Z||^2` part of the quadratic variation contributes at most `[p(p-1)/2] beta^2 ||Z||^p`; and

`||beta Z+Y||^2 <= beta^2||Z||^2 + 2 beta ||Z|| ||Y|| + ||Y||^2`.

Drop the nonnegative terminal term from the left of (4.5), divide by `p`, and use Hölder:

`delta I <= (p-1) beta I^((p-1)/p)J^(1/p)`

`          + (p-1)/2 I^((p-2)/p)J^(2/p)`.                (4.7)

If `J=0`, uniqueness gives `Z=0`. If `I,J>0`, set

`R=(I/J)^(1/p)`.

Then

`delta R^2 <= (p-1)beta R + (p-1)/2`.                    (4.8)

The positive root of the quadratic equality is exactly

`R_*(p,beta)`.

To verify this algebraically, put `q=sqrt(2/(p-1))`. Then

`delta=1-beta^2/q^2=(q^2-beta^2)/q^2`,

and the positive quadratic root equals

`[(p-1)beta+sqrt(2(p-1))]/(2 delta)`

` = 1/(q-beta)`.

Thus `R<=R_*`, proving the upper bound for every Hilbert dimension.

### Proof — sharpness

Fix any unit vector `e in H` and restrict all inputs and solutions to the line `R e`. On `[0,1]` use the deterministic seed input `Y_s=h e`, `h!=0`. Let `c_p=E||Z_1||^p>0`. Positivity follows, for example, because the seed equation has positive second moment and hence is not almost surely zero.

For `s>1`, set

`Y_s = alpha_* Z_s`,

where

`alpha_* = sqrt(2/(p-1))-beta>0`.                         (4.9)

This is progressive: construct the seeded state first, continue it with the closed scalar SDE, then define `Y` from the already adapted state. The closed multiplicative coefficient is

`beta+alpha_* = sqrt(2/(p-1))`,

so the exact scalar `p`-moment exponent is zero. Hence

`E||Z_s||^p=c_p` for all `s>=1`.                          (4.10)

Therefore, for `L>1`,

`E integral_0^L ||Z_s||^p ds >= c_p(L-1)`,

while

`E integral_0^L ||Y_s||^p ds = |h|^p + alpha_*^p c_p(L-1)`.   (4.11)

The resulting norm ratio tends to `1/alpha_*=R_*` as `L->infinity`. Combined with the upper bound, this proves (4.3). QED.

### Source consequence for a fixed torus shell

Let `E_lambda` be any eigenspace of `Lambda` with eigenvalue `lambda`, and let `u(t)` and `g(t)` take values in that shell. Put

`s=lambda t`,

`Z_s=sqrt(lambda) u(s/lambda)`,

`Y_s=g(s/lambda)`,

with Brownian rescaling `Wtilde_s=sqrt(lambda)W_(s/lambda)`. Then the shell equation is exactly (4.1), and the source norms scale by the same factor:

`integral_0^T ||u(t)||_(H^1)^p dt`

` = lambda^(-1) integral_0^(lambda T) ||Z_s||_(L^2)^p ds`,

`integral_0^T ||g(t)||_(L^2)^p dt`

` = lambda^(-1) integral_0^(lambda T) ||Y_s||_(L^2)^p ds`.    (4.12)

Thus the shell bound is dimension-free and independent of the multiplicity of `E_lambda`. On the torus, `lambda_n T -> infinity` along high frequencies, so the scalar constant `R_*` is already asymptotically attained inside **one** shell. The real two-dimensional `+n/-n` degeneracy cannot create the extra factor between `R_*` and the Bellman upper bound.

This is the main mathematical progress of this run.

# 5. Move #15 — BREAK THE SYMMETRY ON PURPOSE: what an equivariant feedback cannot do

The shell theorem says multiplicity alone is harmless. The next possibility is to use a feedback that mixes symmetry sectors. Before doing so, identify exactly what is impossible if the feedback still respects translations.

Consider transformed stochastic input feedback

`Y=KZ`,

where `K` is bounded, self-adjoint on real `L^2(T)`, and commutes with every torus translation. On each nonzero real Fourier shell `E_n`, translations act as all planar rotations. A real self-adjoint operator commuting with every such rotation must be scalar on that shell:

`K|_(E_n)=k_n I`.                                         (5.1)

Proof: the full commutant of planar rotations is `{aI+bJ}` with `J` the quarter-turn; self-adjointness forces `b=0`. The constant mode is already one-dimensional. Moreover

`sup_n |k_n| <= ||K||`.                                   (5.2)

After shell rescaling, the closed multiplicative coefficient on mode `n` is `beta+k_n`. Its exact homogeneous `p`-moment exponent is

`Gamma_n = (p/2)[(p-1)(beta+k_n)^2-2]`.                   (5.3)

## Claim `P24-AV-P3-EQUIVARIANT-FEEDBACK-THRESHOLD-63`

If

`||K|| < alpha_*(p,beta)=sqrt(2/(p-1))-beta`,             (5.4)

then every individual Fourier shell has strictly negative `p`-moment exponent under the closed feedback.

Indeed,

`|beta+k_n| <= beta+|k_n| <= beta+||K|| < sqrt(2/(p-1))`,

which makes (5.3) negative. Therefore any self-adjoint translation-equivariant linear feedback that neutralizes even one shell must obey

`||K|| >= alpha_*`.                                       (5.5)

At equality, taking one `k_n=alpha_*` recovers the previously found scalar neutral feedback, so the threshold is sharp for this algorithmic class.

**Scope discipline.** This does not prove that every translation-equivariant feedback gives the full optimal SMR constant, and it says nothing about arbitrary nonlinear progressive inputs. It proves only that the established **single-shell feedback counterexample algorithm cannot be made cheaper by equivariant mode-dependent linear control**. A better lower-bound mechanism must either break translation symmetry or couple unequal spectral scales before the one-shell reduction.

# 6. Move #28 — TYPICAL VERSUS ALL: symmetry averaging destroys the bad behavior

A tempting next step would be: take a symmetry-breaking feedback `K`, average its translates, obtain an equivariant feedback `Kbar`, and hope convexity preserves any instability or large response. That route is false.

## `P24-AV-P3-SYMMETRY-AVERAGING-NOGO-63`

Already on one real two-dimensional Fourier shell, there are four translation-conjugate feedback matrices, each with a growing closed-loop direction at `p=2`, whose arithmetic average is zero and whose averaged closed loop is strictly decaying.

### Exact construction

On a real shell identify translations with planar rotations. Let

`K_0 = [[1,0],[0,-1]]`.

At rotation angles `0, pi/4, pi/2, 3pi/4`, the conjugates are

`K_0 = [[1,0],[0,-1]]`,

`K_1 = [[0,1],[1,0]]`,

`K_2 = [[-1,0],[0,1]]`,

`K_3 = [[0,-1],[-1,0]]`.

Each is an orthogonal self-adjoint involution of norm one, and

`K_0+K_1+K_2+K_3=0`.                                     (6.1)

Take the frozen coefficient `beta=1` and the shell-scaled closed equation after a seed,

`dZ=-Z ds + (I+K_j)Z dW`.                                (6.2)

Each `K_j` has a unit eigenvector `v_j` of eigenvalue `+1`. Along that ray, `(I+K_j)v_j=2v_j`, so the `p=2` moment exponent is

`-2 + 2^2 = 2 > 0`.                                      (6.3)

Thus every conjugate feedback has a growing direction.

The averaged feedback is zero. Its closed equation is

`dZ=-Z ds + Z dW`,

whose `p=2` moment exponent is

`-2 + 1^2 = -1 < 0`.                                     (6.4)

So feedback averaging reverses the sign of the closed-loop growth exponent. There is no convexity principle allowing one to replace a symmetry-breaking bad feedback by its group average while preserving badness.

This is a **route kill only**. It is not a source SMR counterexample: in (6.2) the input is `Y=K_j Z`, so the source input norm is charged at the same scale as the state. The example disproves only the proposed symmetry-averaging reduction.

## 7. What changed conceptually: the remaining constant gap is genuinely cross-scale

Before this run, the Bellman upper bound exceeded the scalar high-frequency lower bound by `sqrt(p/2)`. It was possible that the discrepancy came from vector-valued multiplicity even at one eigenvalue, since the torus real eigenspaces have multiplicity two and the common Brownian driver couples coordinates.

The shell theorem rules that out exactly:

- arbitrary Hilbert multiplicity at one scalar generator has uniform-horizon norm exactly `R_*`;
- a translation-equivariant self-adjoint feedback cannot neutralize a shell at lower operator cost than `alpha_*`;
- but symmetry averaging of a genuinely symmetry-breaking feedback is invalid because growth is nonconvex in the feedback.

Therefore any strict inequality

`C^g_(p,beta)(T) > R_*(p,beta)`                          (7.1)

for the full frozen pair would have to exploit **unequal spectral scales**, with an input that couples shells before one reduces to the scalar generator. This is a substantially narrower obstruction than “multimode dependence.”

The simplest still-unresolved finite core is now a two-shell shared-Brownian model with unequal eigenvalues:

`dZ_1 = -lambda_1 Z_1 dt + sqrt(lambda_1)(beta Z_1+Y_1)dW`,

`dZ_2 = -lambda_2 Z_2 dt + sqrt(lambda_2)(beta Z_2+Y_2)dW`,  (7.2)

with progressive `Y=(Y_1,Y_2)` allowed to mix the two states and `lambda_1 != lambda_2`. Equal eigenvalues are settled by the new Hilbert-shell theorem. Diagonal/equivariant feedback is settled by (5.5). The unresolved possibility is a genuinely off-diagonal, cross-scale progressive control.

This finite two-scale system is the correct handoff object if P24 rotates after the six-run rule.
