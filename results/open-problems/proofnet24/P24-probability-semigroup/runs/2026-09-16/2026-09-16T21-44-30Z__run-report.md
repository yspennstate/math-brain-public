# 4. Move #5 — add the feedback parameter and locate the neutral point

Fix `beta>0` and

`2 < p < p_c(beta) := 1+2/beta^2`.

After the standard high-frequency rescaling, one source eigenmode obeys

`dZ_s = -Z_s ds + (beta Z_s + Y_s) dW_s`, `Z_0=0`.      (4.1)

Define

`delta_(p,beta) = 1 - beta^2(p-1)/2 > 0`.             (4.2)

For a constant feedback `Y=alpha Z`, the closed multiplicative coefficient is `beta+alpha`, and the exact `p`-moment Lyapunov exponent is

`Gamma_(p,beta)(alpha) = (p/2)[(p-1)(beta+alpha)^2 - 2]`.   (4.3)

The old counterexample route failed precisely because `alpha_*` is positive below the endpoint. But as `p` approaches `p_c(beta)`, `alpha_*` tends to zero. That vanishing input price is the sharp near-endpoint blow-up mechanism.

# 5. Scalar upper bound in the general beta family

Let `Y` be arbitrary progressive with finite `L^p(Omega x (0,L))` norm, and let `Z` solve (4.1). Put

`I = E integral_0^L |Z_s|^p ds`,

`J = E integral_0^L |Y_s|^p ds`.

For bounded inputs/localized solutions, Ito's formula gives

`E|Z_L|^p + p delta_(p,beta) I`

` = p(p-1) beta E integral |Z|^(p-2) ZY ds`

`   + [p(p-1)/2] E integral |Z|^(p-2) |Y|^2 ds`.      (5.1)

Dropping the nonnegative terminal term, taking absolute values in the cross term, and applying Holder gives

`delta_(p,beta) I`

` <= (p-1) beta I^((p-1)/p) J^(1/p)`

`    + (p-1)/2 I^((p-2)/p) J^(2/p)`.                 (5.2)

If `I,J>0`, set `R=(I/J)^(1/p)`. Then

`delta_(p,beta) R^2 <= (p-1) beta R + (p-1)/2`.       (5.3)

The positive root is exactly

`R_*(p,beta) = 1 / [sqrt(2/(p-1)) - beta] = 1/alpha_*(p,beta)`.  (5.4)

Indeed substituting (5.4) into the quadratic gives equality. Standard truncation/localization removes the bounded-input assumption. Therefore for every horizon `L`,

`||Z||_Lp <= R_*(p,beta) ||Y||_Lp`.                   (5.5)

For `beta=1`, rationalizing gives the older scalar constant

`R_*(p,1) = [(p-1)+sqrt(2(p-1))]/(3-p)`.             (5.6)

So the old scalar upper bound already had the exact candidate constant; what remained was sharpness.

`dZ_s = -Z_s ds + (beta Z_s + h)dW_s`, `Z_0=0`,

`d/ds E Z_s^2 = -(2-beta^2) E Z_s^2 + h^2`,

so for `beta^2<2`,

`E Z_1^2 = h^2 [1-exp(-(2-beta^2))]/(2-beta^2) > 0`.  (6.4)

For `s>1`, let

`Y_s = alpha_* Z_s`,

`E|Z_s|^p = c_p` for every `s>=1`.                    (6.6)

Hence, for `L>1`,

`E integral_0^L |Z_s|^p ds >= c_p(L-1)`,

while

`E integral_0^L |Y_s|^p ds = |h|^p + alpha_*^p c_p(L-1)`.   (6.7)

Therefore

`||T_L||^p >= c_p(L-1) / [|h|^p+alpha_*^p c_p(L-1)]`,

and letting `L -> infinity` gives

`sup_L ||T_L|| >= 1/alpha_* = R_*`.                  (6.8)

# 9. Why the old counterexample algorithm fails — now quantitatively exact

The explicit proposed counterexample algorithm below the endpoint is:

1. seed one high Fourier mode for a short scaled time;
2. feed back `Y=alpha Z`;
3. choose `alpha` large enough that the `p`-moment no longer decays;
4. hope long-time growth makes output/input diverge.

The exact failure is now completely quantified. Step 3 requires

`alpha >= alpha_*(p,beta)`.

At equality the state moment is conserved, but the input is exactly `alpha_* Z`; hence the response/input ratio tends only to

`1/alpha_*`,

which is finite for every fixed subcritical `p`. Taking `alpha>alpha_*` creates exponential growth but still charges the input proportionally to the state, so the ratio stays at most `1/alpha`. This route can diverge only when `alpha_* -> 0`, i.e. as `p` approaches the true endpoint.

Therefore the construction is not a source-admissible counterexample for any `p<r_*`; it is instead the asymptotically extremal witness for deterioration of the SMR constant.
