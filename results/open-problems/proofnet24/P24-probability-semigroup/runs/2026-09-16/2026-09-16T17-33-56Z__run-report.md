# 4. Successful replacement: semigroup Bellman functional

The successful idea keeps all stochastic objects adapted and moves the smoothing into a deterministic auxiliary semigroup variable.

Let `A` be positive self-adjoint on real Hilbert `H`, `C=A^(1/2)`, and `S_s=exp(-sA)`. Work first after a finite spectral projection so ordinary finite-dimensional Ito calculus applies. For `p>2`, define

`Psi_p(x) := integral_0^infinity || C S_s x ||^p ds`.

For an eigenvector with `A x = lambda x`,

`Psi_p(x) = (1/p) lambda^(p/2-1) |x|^p`.

Thus `Psi_p` is tuned to the trace/interpolation scale rather than raw Hilbert energy.

Write

`z_s = C S_s x`, and `Q_s h = C S_s h`.

The first two derivatives on a finite spectral subspace are

`D Psi_p(x) h = p integral ||z_s||^(p-2) <z_s,Q_s h> ds`,

and

`D2 Psi_p(x)[h,h]`
` = p integral ||z_s||^(p-2) ||Q_s h||^2 ds`
` + p(p-2) integral ||z_s||^(p-4) <z_s,Q_s h>^2 ds`.

For `p>2`, this extends continuously at `x=0`, and `D2 Psi_p(x)` is positive semidefinite.

## 4.1 Drift telescope

Since `z_s' = -A z_s`,

`d/ds ||z_s||^p = -p ||z_s||^(p-2) <z_s,A z_s>`.

Also `Q_s(Ax)=A z_s`. Therefore

`D Psi_p(x)[-Ax] = integral_0^infinity d/ds ||z_s||^p ds = -||Cx||^p`,

because `S_s` decays exponentially and `z_0=Cx`.

So the deterministic drift produces the desired `X_1` norm with coefficient exactly one.

## 4.2 Multiplicative-noise Hessian and the sharp coefficient

For the critical direction `h=Cx`, commutation gives

`Q_s(Cx) = C z_s`.

Define

`I1 = integral ||z_s||^(p-2) ||C z_s||^2 ds`.

Because

`-d/ds ||z_s||^p = p ||z_s||^(p-2) ||C z_s||^2`,

we have

`I1 = (1/p)||Cx||^p`.

For the directional second term, Cauchy--Schwarz gives

`I2 = integral ||z_s||^(p-4) <z_s,Cz_s>^2 ds <= I1`.

Hence

`D2 Psi_p(x)[Cx,Cx] <= (p-1)||Cx||^p`.

For multiplicative coefficient `beta C`,

`D2 Psi_p(x)[beta Cx,beta Cx] <= beta^2 (p-1)||Cx||^p`.

The factor `beta^2(p-1)` is exactly the one-mode stochastic-parabolicity threshold from the already-certified counterexample.

## 4.3 Additive-noise Hessian without spectral dimension loss

For arbitrary `y in H`, the Hessian formula and Cauchy give

`D2 Psi_p(x)[y,y]`
` <= p(p-1) integral ||C S_s x||^(p-2) ||C S_s y||^2 ds`.

Since `S_s` is a contraction commuting with `C`,

`||C S_s x|| <= ||Cx||`.

Self-adjointness gives the exact square-function identity

`integral_0^infinity || C S_s y ||^2 ds`
` = integral_0^infinity <A exp(-2sA)y,y> ds`
` = (1/2)||y||^2`.

Therefore

`D2 Psi_p(x)[y,y] <= [p(p-1)/2] ||Cx||^(p-2) ||y||^2`.

This is the dimension-free step missing from the previous coordinatewise argument. The Hilbert square function is summed before any modewise `ell^p` comparison.

## 4.4 Cross term and exact subcritical condition

For any positive-semidefinite quadratic form `Q` and every `epsilon>0`,

`Q(u+v) <= (1+epsilon)Q(u) + (1+1/epsilon)Q(v)`.

Applying this to `Q(h)=D2 Psi_p(x)[h,h]`, `u=beta Cx`, `v=y` gives

`D2 Psi_p(x)[beta Cx+y,beta Cx+y]`
` <= (1+epsilon) beta^2(p-1)||Cx||^p`
` + (1+1/epsilon)[p(p-1)/2]||Cx||^(p-2)||y||^2`.

Now let `X` solve the source equation with `f=0`:

`dX_t + A X_t dt = ( beta C X_t + Y_t ) dW_t`, with `X_a=0`.

The source p=2 variational theorem supplies the unique strong solution for the fixed `beta^2<2`; on every finite source interval, `Y in Lp` is also in `L2` because `p>2`.

Let `P_N = 1_[0,N](A)` be nested finite-rank spectral projections and define `X_N=P_N X`, `Y_N=P_N Y`. Because the projections commute with `A` and `C`, the pair `(X_N,Y_N)` satisfies the finite-dimensional projected equation.

Apply finite-dimensional Ito's formula to `Psi_p(X_N)`, stopped at the source stopping time and a standard localizer for the martingale. Take expectation and then remove the localizer by Fatou. The terminal Bellman functional is nonnegative.

Set

`I_N = E integral_a^tau ||C X_N||^p dt`,
`J   = E integral_a^tau ||Y||^p dt`.

The preceding identities give

`[ 1 - (1+epsilon) beta^2(p-1)/2 ] I_N`
` <= [p(p-1)/4](1+1/epsilon)`
`    * E integral ||C X_N||^(p-2)||Y_N||^2 dt`.

Holder on the finite probability-time measure and `||Y_N||<=||Y||` yield

`E integral ||C X_N||^(p-2)||Y_N||^2`
` <= I_N^((p-2)/p) J^(2/p)`.

Thus if and only if the present absorption scheme is strictly subcritical,

`beta^2(p-1) < 2`,

we may choose

`0 < epsilon < 2/[beta^2(p-1)] - 1`.

Then

`I_N^(1/p) <= C_{p,beta,epsilon} J^(1/p)`,

with exact constant

`C_{p,beta,epsilon}^2`
` = p(p-1)(1+1/epsilon) / { 2[ 2-beta^2(p-1)(1+epsilon) ] }`.

Optimizing gives

`epsilon_* = sqrt( 2/[beta^2(p-1)] ) - 1`,

and therefore

`C_{p,beta}^2`
` = p(p-1) / { 2[ sqrt(2)-|beta|sqrt(p-1) ]^2 }`.

For the frozen `beta=1` pair:

`C_p^2 = p(p-1) / { 2[ sqrt(2)-sqrt(p-1) ]^2 }`, for `2<p<3`.

This constant diverges as `p` approaches the exact critical endpoint, consistent with the negative endpoint theorem.

## 4.5 Infinite-spectrum passage

For nested spectral projections,

`||C P_N X||^2` increases pointwise to `||CX||^2`.

Monotone convergence therefore gives

`E integral_a^tau ||CX_t||^p dt <= C_{p,beta}^p E integral_a^tau ||Y_t||^p dt`.

The constant is independent of spectral rank, start time, and stopping time. In the torus scale, `||CX||_2=||X||_{H^1}` and `X_{1/2}=L^2`, so this is exactly Definition 3.7's `f=0` estimate.

No independent-frequency noise, anticipative future kernel, coordinatewise `ell^p -> ell^2` gluing, or dimension-dependent constant has been used.
