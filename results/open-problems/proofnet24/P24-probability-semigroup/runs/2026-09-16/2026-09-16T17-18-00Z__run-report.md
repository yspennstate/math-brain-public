# 3. Move 2 — attack the negation first

The previous negative certificate uses deterministic forcing and becomes finite below `p=3`. This run tried a genuinely adapted feedback construction, because adaptedness is the only remaining place a subcritical counterexample could hide.

## 3.1 Scalar canonical equation

On one eigenmode `A phi=lambda phi`, equation (2.3) is equivalent to

\[
dZ_t=-\lambda Z_t\,dt+\sqrt\lambda\,(Z_t+Y_t)\,dW_t,
\qquad Z_0=0.
\tag{3.1}
\]

A tempting feedback is `Y=alpha Z` after a short deterministic seed has made `Z` nonzero. On the feedback interval the closed equation is

\[
dZ_t=-\lambda Z_t\,dt+(1+\alpha)\sqrt\lambda Z_t\,dW_t.
\]

Its exact `p`th-moment Lyapunov exponent is

\[
\Gamma_p(\alpha)
=\lambda p\left[-1+\frac{p-1}{2}(1+\alpha)^2\right].
\tag{3.2}
\]

For every fixed `2<p<3`, choosing

\[
\alpha>\alpha_c(p):=\sqrt{\frac2{p-1}}-1>0
\tag{3.3}
\]

makes the state grow exponentially in `p`th moment. This initially looks like a subcritical counterexample.

It fails for an exact reason: the input itself is `Y=alpha Z`, so on the growing interval

\[
\frac{\int E|Z|^p}{\int E|Y|^p}=\alpha^{-p},
\qquad
\frac{\|Z\|_{L^p}}{\|Y\|_{L^p}}=\alpha^{-1}.
\tag{3.4}
\]

The growth cannot make the response/input ratio diverge at fixed `p`, because growth requires the strictly positive feedback cost (3.3). At the critical feedback the same conclusion holds with linear time growth. The seed contribution becomes negligible on long intervals but does not change (3.4).

This is a useful failed construction: a scalar adapted input can destabilize the homogeneous dynamics below `3`, but the SMR norm charges exactly the feedback used to do so.

## 3.2 Stronger scalar no-counterexample theorem

The failure above is not specific to linear feedback. In fact the scalar adapted resolvent is bounded for **every** progressive source below `3`.

### Theorem `P24-AV-P3-SCALAR-ADAPTED-57` — PROVED

Let `lambda>0`, `2<p<3`, and let `Y` be progressively measurable with

\[
E\int_0^T|Y_t|^pdt<\infty.
\]

Let `Z` solve (3.1). Then

\[
\boxed{
\|Z\|_{L^p(\Omega\times(0,T))}
\le C_p^{\rm sc}
\|Y\|_{L^p(\Omega\times(0,T))},
}
\tag{3.5}
\]

uniformly in `lambda>0` and `T>0`, where

\[
\boxed{
C_p^{\rm sc}
=\frac{(p-1)+\sqrt{2(p-1)}}{3-p}.
}
\tag{3.6}
\]

#### Proof

First take bounded progressive `Y` and localize the solution. Itô's formula for `|Z|^p` gives, after expectation,

\[
\begin{aligned}
E|Z_T|^p
+\frac{p(3-p)}2\lambda
E\int_0^T|Z|^pdt
={}&p(p-1)\lambda E\int_0^T|Z|^{p-2}ZY\,dt\\
&+\frac{p(p-1)}2\lambda E\int_0^T|Z|^{p-2}|Y|^2dt.
\end{aligned}
\tag{3.7}
\]

The martingale term has mean zero after localization. Drop the nonnegative terminal term and bound the cross term by absolute value. Set

\[
I=E\int_0^T|Z|^pdt,\qquad
J=E\int_0^T|Y|^pdt.
\]

Hölder gives

\[
E\int|Z|^{p-1}|Y|
\le I^{(p-1)/p}J^{1/p},
\]
\[
E\int|Z|^{p-2}|Y|^2
\le I^{(p-2)/p}J^{2/p}.
\]

Hence

\[
(3-p)I
\le2(p-1)I^{(p-1)/p}J^{1/p}
+(p-1)I^{(p-2)/p}J^{2/p}.
\tag{3.8}
\]

If `I,J>0`, let `R=(I/J)^{1/p}` and divide by `I^{(p-2)/p}J^{2/p}`. Then

\[
(3-p)R^2\le2(p-1)R+(p-1).
\tag{3.9}
\]

The positive root of the quadratic is exactly (3.6), proving (3.5). The cases `I=0` or `J=0` are immediate. Removing the localization and bounded-source assumption follows by truncation, Fatou, and standard finite-dimensional SDE stability. `square`

The coefficient `p(3-p)/2` is the same threshold seen in the deterministic pulse and in Brzeźniak--Veraar's homogeneous theorem. In particular, **there is no one-mode source-admissible counterexample for any `2<p<3`**.

The only remaining negation route is genuinely infinite-dimensional: an adapted source would have to exploit many spectral time scales at once. No such counterexample was found in this run.

# 4. Move 19 — make the positive proof an algorithm

The proof algorithm is now explicit.

1. Spectrally truncate `A` to `M` eigenmodes.
2. Apply the scalar theorem to every coordinate. The constant is uniform in every eigenvalue.
3. Glue the coordinate estimates in the Hilbert norm.
4. Send `M -> infinity`.

Steps 1--3 can be completed rigorously. Step 4 is exactly where the present method fails.

## 4.1 Finite-spectrum theorem

### Theorem `P24-AV-P3-FINITE-SPECTRUM-57` — PROVED

Let

\[
A_M=\operatorname{diag}(\lambda_1,\ldots,\lambda_M),
\qquad \lambda_j>0,
\]

on `R^M`, with one **common scalar Brownian motion** in all coordinates, and let

\[
dZ=-A_MZ\,dt+A_M^{1/2}(Z+Y)\,dW,
\qquad Z_0=0.
\tag{4.1}
\]

For every `2<p<3` and every progressive `Y in L^p(Omega x (0,T);R^M)`, one has

\[
\boxed{
\|Z\|_{L^p(\Omega\times(0,T);\ell^2_M)}
\le M^{1/2-1/p}C_p^{\rm sc}
\|Y\|_{L^p(\Omega\times(0,T);\ell^2_M)}.
}
\tag{4.2}
\]

The constant is independent of `T` and of all eigenvalues `lambda_j`.

#### Proof

For each coordinate, Theorem (3.5) gives

\[
\int E|Z_j|^p\le (C_p^{\rm sc})^p\int E|Y_j|^p.
\]

The fact that all coordinates use the same Brownian motion causes no problem here: each coordinate process and source is still progressive for that same filtration, and the scalar proof never assumes independence across coordinates.

For `p>=2`, pointwise

\[
\left(\sum_{j=1}^M|Z_j|^2\right)^{p/2}
\le M^{p/2-1}\sum_{j=1}^M|Z_j|^p,
\]

while

\[
\sum_{j=1}^M|Y_j|^p
\le\left(\sum_{j=1}^M|Y_j|^2\right)^{p/2}.
\]

Integrate and take the `p`th root to obtain (4.2). `square`

## 4.2 The previously open two-mode case is now closed

For

\[
A_L=\operatorname{diag}(1,L),\qquad L\ge1,
\]

the previous report asked whether

\[
\sup_{L\ge1}\|(I-K_{A_L})^{-1}K_{A_L}\|_{L^p_{\rm prog}(\mathbb R^2)\to L^p_{\rm prog}(\mathbb R^2)}<\infty.
\]

Theorem (4.2) gives the explicit answer

\[
\boxed{
\sup_{L\ge1}\|(I-K_{A_L})^{-1}K_{A_L}\|
\le 2^{1/2-1/p}C_p^{\rm sc}<\infty,
\qquad 2<p<3.
}
\tag{4.3}
\]

So unequal time scales plus a common Brownian driver do **not** create a two-mode obstruction. The prior stuck report's sentence calling this case unproved is superseded by (4.3).

This remains a restricted finite-dimensional theorem, hence **PARTIAL** for the source question.

# 5. Move 20 — find exactly why the algorithm fails

The failure is now one line and it is structural to this algorithm:

\[
\boxed{M^{1/2-1/p}.}
\]

For every fixed `p>2`, this factor tends to infinity with `M`. It comes from replacing the Hilbert square sum by separately estimated scalar `L^p` norms.

The static inequality

\[
\|x\|_2^p\le M^{p/2-1}\|x\|_p^p
\tag{5.1}
\]

is sharp for the vector `(1,...,1)`. Therefore **an argument that uses only coordinatewise scalar estimates followed by this deterministic norm comparison cannot produce a dimension-free theorem**.

This is not a counterexample to `(DG_p)`. The two norm-comparison inequalities used in the proof need not be simultaneously extremized by a genuine adapted solution/input pair, and the common Brownian structure may contain additional square-function cancellation. The conclusion is narrower and exact:

> The scalarize-then-glue algorithm fails at `M -> infinity`; any proof of `r_*=3` must exploit a genuinely Hilbert/spectral mechanism before separating the modes.

That is the precise obstruction the previous report was missing.

# 6. A new route suggested by the failure: keep the common-noise stochastic flow intact

Although it does not close `(DG_p)`, the homogeneous stochastic flow exposes the correct threshold without scalarizing modes.

For the frozen pair the homogeneous propagator is

\[
\Phi(t,s)
=\exp\left[-\frac32A(t-s)+A^{1/2}(W_t-W_s)\right].
\tag{6.1}
\]

Put `tau=t-s` and `G=(W_t-W_s)/sqrt(tau)`. By the spectral theorem,

\[
\|\Phi(t,s)\|_{H\to H}
\le \sup_{q\ge0}\exp\{-\tfrac32q^2+qG\}
=\exp\{(G_+)^2/6\}.
\tag{6.2}
\]

Therefore

\[
E\|\Phi(t,s)\|^p<\infty
\quad\Longleftrightarrow\quad p<3.
\tag{6.3}
\]

This recovers the endpoint from a **single common-noise operator norm**, not from individual eigenmodes.

However, it is not yet a proof of SMR. A naive variation-of-constants kernel `Phi(t,s)` depends on the future increment `W_t-W_s`, so inserting it directly into an Itô integral against `g_s dW_s` is anticipative. Taking a spectral supremum before parabolic cancellation also creates the nonintegrable `tau^{-1}` singularity at one derivative. These are the two exact missing ingredients:

1. a filtration-respecting rearrangement of the inhomogeneous stochastic term;
2. preservation of the spectral square-function cancellation before taking operator norms.

A useful equivalent language is the ordered Wiener-chaos/Hermite expansion of the resolvent. Iterating `K_A` gives nested Itô integrals whose semigroup factors collapse to the earliest time. Summing the **future** iterated integrals formally reconstructs the exponential in (6.1). This strongly suggests a decoupled-future/Hermite route: keep the earliest source value adapted, decouple only later Brownian increments, and estimate the resulting spectral square function before resumming. This is the next attack; no theorem is claimed here.

## 7.1 Brzeźniak--Veraar 2012 — exact homogeneous threshold, but no arbitrary adapted inhomogeneity

Brzeźniak and Veraar, *Is the stochastic parabolicity condition dependent on p and q?*, Electron. J. Probab. 17 (2012), study

\[
dU+AU\,dt=2BU\,dW,
\]

with `A=C^*C`, `C` skew-adjoint and `B=alpha C+beta|C|`. Their Theorem 3.6 gives homogeneous `L^p` well-posedness under

\[
2\alpha^2+2\beta^2(p-1)<1.
\]

For the frozen pair, after complexification take `C=iA^{1/2}`, `alpha=0`, `beta=1/2`; the condition is exactly `p<3`. Their theorem therefore perfectly matches the homogeneous threshold but does not quantify over arbitrary progressive `g` as Agresti--Veraar Definition 3.7 does. It cannot by itself prove `(DG_p)`.

## 7.2 Gnann--Hoogendijk--Veraar 2024 — p-coercivity sees the same threshold, but the norm is different

The 2024 paper *Higher order moments for SPDE with monotone nonlinearities* introduces a `p`-dependent coercivity condition. Its Theorem 2.4 gives, for the variational exponent `alpha=2`, an estimate of the form

\[
E\sup_{t\le T}\|u(t)\|_H^p
+
E\left(\int_0^T\|u(t)\|_V^2dt\right)^{p/2}<\infty.
\tag{7.1}
\]

Its own optimality example uses the same Brzeźniak--Veraar mechanism. For the frozen linear pair the `p`-dependent coercivity is favorable precisely below `3`.

But (7.1) is an `L^p_\Omega L^2_t(V)` energy estimate. Source SMR requires

\[
E\int_0^T\|u(t)\|_V^pdt<\infty,
\tag{7.2}
\]

that is `L^p_\Omega L^p_t(V)` in this unweighted setting. For `p>2`, (7.1) does **not** imply (7.2). Thus this highly relevant theorem is an auxiliary energy result, not a solution of Problem 3 and not a proof that `r_*=3`.

This directly guards against the prohibited mistake of replacing the source question by a stricter or merely different sufficient condition.

## 7.3 Bechtel--Veraar and later SMR literature

The current Bechtel--Veraar self-adjoint variational extrapolation theorem remains the legitimate source of `r_*>2`; it gives only some `p_0>2`, not the sharp value `3` for this pair.

# 8. Method comparison

- **Semigroup / ordered-chaos interpolation:** strongest live route. It preserves the exact Gaussian threshold and can in principle retain the square-function structure across all spectral scales.
- **Martingale/Bellman energy:** scalar proof succeeds sharply, but direct Hilbert energy either loses the full `D(A)` norm or differentiates the source. Needs a new spectral Bellman functional, not another scalar Young inequality.
- **Exchangeable pairs / Stein:** poor fit here. The noise is already Gaussian; the difficulty is adapted operator inversion, not Gaussian approximation.
- **Transportation / functional inequalities:** may control finite-dimensional Gaussian functionals but presently does not repair the filtration or one-half-derivative issue.
- **Coupling/decoupling:** promising only if used surgically: keep `Y_s` with the past filtration and decouple the strictly future Wiener chaos. Replacing the whole common Brownian driver by independent mode noises would change the problem and is forbidden.
