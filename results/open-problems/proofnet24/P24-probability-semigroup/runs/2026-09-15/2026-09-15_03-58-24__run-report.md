# 4. Proof

The proof has three layers.

## 4.1 Global CLT and local PPP already decouple

The preceding P24 theorem applies with the moving external center \(b_p\to b\).

For every compactly supported continuous \(h\ge0\) and every \(t\in\mathbb R\),

\[
E\left[
e^{itL_p-\langle h,\Pi_p\rangle}
\mid\mathcal E
\right]
\]

factors asymptotically into:

\[
\exp\left(
-\frac12t^2\sigma_{\mathcal E}^2
\right)
\]

times

\[
\exp\left[
\rho f(b)
\int
(e^{-h(\eta)}-1)\,d\eta
\right].
\]

Hence

\[
\boxed{
(L_p,\Pi_p)
\Longrightarrow
(G,\Pi),
}
\tag{4.1}
\]

with conditional independence.

No pointwise regularity of \(g\) at \(b\) is needed.

## 4.2 The full random Gibbs weight converges despite the infinite spatial window

Fix \(R<\infty\).

On \([-R,R]\), local uniform convergence gives

\[
\int_{[-R,R]}
k_p\,d\Pi_p
\Longrightarrow
\int_{[-R,R]}
k\,d\Pi.
\]

The tail is uniformly negligible in \(L^1\).

Indeed,

\[
\begin{aligned}
E\left[
\int_{|\eta|>R}
k_p(\eta)\Pi_p(d\eta)
\mid\mathcal E
\right]
&=
p
\int
k_p\left(
\frac{z-b_p}{s_p}
\right)
\mathbf 1_{\{|z-b_p|>Rs_p\}}
f(z)\,dz
\\
&=
ps_p
\int_{|\eta|>R}
k_p(\eta)
f(b_p+s_p\eta)\,d\eta
\\
&\le
ps_p\,
\|f\|_\infty
\int_{|\eta|>R}
K(\eta)\,d\eta.
\end{aligned}
\tag{4.2}
\]

Because

\[
ps_p\to\rho
\]

and

\[
K\in L^1,
\]

the right side vanishes as \(R\to\infty\), uniformly for large \(p\).

The same estimate applies to bounded continuous test functions multiplied by \(k_p\).

Therefore jointly with `(4.1)`,

\[
\boxed{
S_p
=
\int k_p\,d\Pi_p
\Longrightarrow
S
=
\int k\,d\Pi.
}
\tag{4.3}
\]

Since \(k>0\) everywhere and a homogeneous Poisson process on \(\mathbb R\) has infinitely many atoms almost surely,

\[
\boxed{
0<S<\infty
\quad\text{a.s.}
}
\tag{4.4}
\]

Finiteness follows also from

\[
E[S\mid\mathcal E]
=
\rho f(b)\int k<\infty.
\]

## 4.3 Normalized Gibbs sampling is a continuous local operation after tail control

Define the random probability measure

\[
\mu_p(d\eta)
=
\frac{
k_p(\eta)\Pi_p(d\eta)
}{
S_p
}.
\]

The same compact-plus-tail argument shows

\[
\boxed{
\mu_p
\Longrightarrow
\mu(d\eta)
=
\frac{
k(\eta)\Pi(d\eta)
}{
S
}
}
\tag{4.5}
\]

weakly, jointly with \((L_p,\Pi_p)\).

Adjoin an independent

\[
U\sim{\rm Unif}(0,1).
\]

Generate \(\eta_p^\star\) from \(\mu_p\) using \(U\), and generate \(\eta^\star\) from \(\mu\) using the same \(U\).

Because the limiting Poisson process is simple and \(U\) almost surely avoids every atom of the cumulative selection distribution, the sampling map is almost surely continuous after the preceding tail truncation.

Hence

\[
\eta_p^\star\Longrightarrow\eta^\star.
\]

For a simple locally finite point measure, translating by the selected atom is also almost surely continuous in the vague topology for every compactly supported test functional whose boundary carries no atom.

Thus

\[
\Pi_p^\star
\Longrightarrow
\Pi^\star.
\]

Finally, the entire selected local object is a measurable randomized function of the limiting Poisson process and the auxiliary \(U\).

Since

\[
G\perp\!\!\!\perp\Pi\mid\mathcal E
\]

and \(U\) is independent,

\[
G
\perp\!\!\!\perp
(\Pi,S,\eta^\star,\Pi^\star)
\mid\mathcal E.
\]

QED.
