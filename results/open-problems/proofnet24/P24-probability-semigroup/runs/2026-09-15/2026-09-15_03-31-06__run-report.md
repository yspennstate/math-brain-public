# 3. Abstract moving-center theorem

Let \(\mathcal E\) be an external environment.

Condition on \(\mathcal E\).

Let

\[
Z_1,Z_2,\ldots
\]

be iid with density \(f\).

Let

\[
b=b(\mathcal E).
\]

For every \(p\), let

\[
h_p=h_{p,\mathcal E}
\]

be a centered measurable function:

\[
\int h_p(z)f(z)\,dz=0.
\]

Assume:

## (M1) Hilbert convergence

There exists

\[
h\in L^2(f)
\]

such that

\[
\boxed{
\|h_p-h\|_{L^2(f)}\to0.
}
\tag{M1}
\]

## (M2) Local \(C^1\) smoothing

For some fixed \(\delta>0\), define

\[
M_p
=
\sup_{|z-b|\le\delta}|h_p(z)|,
\]

\[
L_p
=
\sup_{|z-b|\le\delta}|h_p'(z)|.
\]

Assume

\[
\boxed{
M_p=o(\sqrt p),
\qquad
L_p=o(p).
}
\tag{M2}
\]

## (M3) Local density regularity

The density \(f\) is bounded and continuous at \(b\).

## (M4) Microscopic scale

Let

\[
s_p\downarrow0,
\qquad
\boxed{
p s_p\to\rho\in(0,\infty).
}
\tag{M4}
\]

Define the global CLT statistic

\[
G_p
=
\frac1{\sqrt p}
\sum_{i=1}^p
h_p(Z_i),
\]

the self-centered location

\[
\boxed{
C_p
=
b+\frac1p
\sum_{i=1}^p
h_p(Z_i)
=
b+\frac{G_p}{\sqrt p},
}
\tag{3.1}
\]

and the microscopic point process around that **data-dependent** center:

\[
\boxed{
\Pi_p^{\rm mov}
=
\sum_{i=1}^p
\delta_{(Z_i-C_p)/s_p}.
}
\tag{3.2}
\]

Conditionally on \(\mathcal E\),

\boxed{

# 4. Proof of `P24-SMOOTH-MOVING-CENTER-POISSON-11`

The triangular-array CLT follows immediately from `(M1)`.

Indeed,

\[
\frac1{\sqrt p}
\sum_{i=1}^p
(h_p-h)(Z_i)
\]

has conditional variance

\[
\|h_p-h\|_2^2\to0,
\]

while

\[
p^{-1/2}\sum_i h(Z_i)
\]

satisfies the ordinary \(L^2\) CLT.

The only nontrivial issue is the local point process around the self-centered location.

We prove a mixed factorial-moment identity.

Fix:

- \(k\ge1\);
- \(t\in\mathbb R\);
- a continuous compactly supported
  \[
  \Phi:\mathbb R^k\to\mathbb R.
  \]

Define

\[
Y_{i,p}
=
\frac{Z_i-C_p}{s_p}.
\]

Consider

\[
\mathcal M_{p,k}
=
E\left[
e^{itG_p}
\sum_{i_1,\ldots,i_k}^{\ne}
\Phi(
Y_{i_1,p},\ldots,Y_{i_k,p}
)
\right].
\]

By exchangeability it is enough to use indices \(1,\ldots,k\).

Write

\[
R_p
=
\sum_{j=k+1}^p h_p(Z_j),
\qquad
c_p
=
b+\frac{R_p}{p}.
\]

The remaining \(k\) selected coordinates contribute

\[
H_p(z_1,\ldots,z_k)
=
\sum_{r=1}^k h_p(z_r).
\]

Then

\[
C_p
=
c_p+\frac{H_p}{p}.
\]

Condition on the remaining sample.

On the high-probability event

\[
|R_p|\le A\sqrt p,
\]

we have

\[
|c_p-b|\le A/\sqrt p.
\]

For the selected \(k\) points put

\[
z_r=c_p+s_p x_r.
\]

Their final self-centered coordinates are

\[
\frac{z_r-C_p}{s_p}
=
x_r
-
\frac{H_p(c_p+s_px_1,\ldots,c_p+s_px_k)}
{p s_p}.
\]

Define the map

\[
\boxed{
T_p(x)
=
x
-
\gamma_p H_p(x)\mathbf 1,
\qquad
\gamma_p=(p s_p)^{-1}.
}
\tag{4.1}
\]

Here \(\mathbf 1=(1,\ldots,1)\).

Its Jacobian matrix is

\[
DT_p
=
I
-
\frac1p
\mathbf 1
\begin{pmatrix}
h_p'(z_1)&\cdots&h_p'(z_k)
\end{pmatrix}.
\]

The matrix determinant lemma gives

\[
\boxed{
\det DT_p
=
1-\frac1p\sum_{r=1}^kh_p'(z_r).
}
\tag{4.2}
\]

By `(M2)`,

\[
\sup|\det DT_p-1|
\le
kL_p/p
\to0.
\]

For large \(p\),

\[
kL_p/p<1/2.
\]

The same bound proves injectivity on the relevant region.

Indeed, if

\[
T_p(x)=T_p(x'),
\]

all coordinate differences are equal to a common scalar \(d\), and

\[
|d|
\le
\frac{kL_p}{p}|d|,
\]

so \(d=0\).

The selected coordinates that contribute to compactly supported \(\Phi\) remain in the local density neighborhood.

To see this, if \(T_p(x)\) lies in a fixed compact set,

\[
|x|
\lesssim
1+\gamma_p kM_p.
\]

Hence

\[
|s_px|
\lesssim
s_p+M_p/p.
\]

By `(M2)`,

\[
M_p/p=o(p^{-1/2}),
\]

and by `(M4)`,

\[
s_p=O(p^{-1}).
\]

Thus

\[
z_r=b+O(p^{-1/2})
\]

uniformly on the contributing region.

Therefore

\[
f(z_r)\to f(b)
\]

uniformly.

Also

\[
\frac{H_p}{\sqrt p}
\le
\frac{kM_p}{\sqrt p}
\to0.
\]

So the selected \(k\) observations contribute negligibly to the global characteristic factor

\[
e^{itG_p}.
\]

Changing variables from \(x\) to

\[
y=T_p(x),
\]

the Jacobian tends uniformly to one and the product density tends uniformly to \(f(b)^k\).

Consequently, conditionally on the remaining sample,

\[
\begin{aligned}
&(p)_k
s_p^k
\int
e^{itH_p/\sqrt p}
\Phi(T_p(x))
\prod_{r=1}^k
f(c_p+s_px_r)\,dx
\\
&\qquad\longrightarrow
(\rho f(b))^k
\int_{\mathbb R^k}
\Phi(y)\,dy.
\end{aligned}
\tag{4.3}
\]

The limit does not depend on the remaining empirical sum.

Meanwhile

\[
\frac{R_p}{\sqrt p}
\Longrightarrow
N(0,\|h\|_2^2).
\]

Hence

\[
\boxed{
\mathcal M_{p,k}
\longrightarrow
e^{-t^2\|h\|_2^2/2}
(\rho f(b))^k
\int\Phi.
}
\tag{4.4}
\]

These are exactly the mixed factorial moment measures of:

- a centered Gaussian \(G\);
- an independent homogeneous PPP of intensity \(\rho f(b)\).

For completeness, one can recover the mixed characteristic-Laplace functional directly.

For a nonnegative compactly supported \(g\), expand

\[
e^{-\langle g,\Pi_p^{\rm mov}\rangle}
=
\prod_i
\left[
1-
\left(
1-e^{-g(Y_{i,p})}
\right)
\right]
\]

into its finite factorial series.

The factorial moments above are uniformly bounded by \(C^k\), so the series is dominated by \(e^C\).

Termwise passage to the limit yields

\[
\boxed{
\begin{aligned}
&E[
e^{itG_p-\langle g,\Pi_p^{\rm mov}\rangle}
\mid\mathcal E
]
\\
&\quad\longrightarrow
\exp\left(
-\frac{t^2\|h\|_2^2}{2}
\right)
\exp\left[
\rho f(b)
\int
(e^{-g(\eta)}-1)\,d\eta
\right].
\end{aligned}
}
\tag{4.5}
\]

The transform factors.

This proves conditional independence.

QED.
