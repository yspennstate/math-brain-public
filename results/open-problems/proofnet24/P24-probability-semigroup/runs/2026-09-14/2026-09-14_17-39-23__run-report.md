# 12. New theorem P24-XI-LAMPERTI-NONERGODIC

The previous P24 run listed unconditional strong mixing as a possible next theorem. It is false.

First observe that

\[
A=\varphi(G)^{-1/2}
\]

is nondegenerate and

\[
E[A^2]
=
E[\varphi(G)^{-1}]
=
\infty.
\tag{12.1}
\]

On the other hand,

\[
0<
E[Z_0^2]
=
\sigma_T^2\sqrt\lambda\,
E[J(\mathcal B)]
<
\infty,
\tag{12.2}
\]

because

\[
0<J(\mathcal B)\le4/\sqrt\pi
\]

pathwise.

For every fixed \(a>0\), let \(\mu_a\) be the stationary law of

\[
aZ.
\]

These laws are distinct, because their one-time second moments are

\[
a^2E[Z_0^2].
\]

The law \(\mu\) of \(\mathcal L\) is the nontrivial stationary scale mixture

\[
\boxed{
\mu
=
\int \mu_a\,\nu_A(da).
}
\tag{12.3}
\]

To avoid invoking an abstract ergodic-decomposition theorem, use the elementary extremality argument.

Suppose a stationary probability law \(\mu\) were ergodic and

\[
\mu=p\nu_1+(1-p)\nu_2,
\qquad
0<p<1,
\]

with \(\nu_1,\nu_2\) stationary.

Then

\[
h=\frac{d\nu_1}{d\mu}
\]

exists and is shift-invariant \(\mu\)-a.s. Stationary ergodicity forces every invariant integrable function to be constant, so \(h=1\) a.s. and \(\nu_1=\mu\). Similarly \(\nu_2=\mu\).

But (12.3) admits a genuinely nontrivial split. For example choose a bounded interval \(E\) in the range of \(A\) with

\[
0<P(A\in E)<1.
\]

The conditional mixture on \(E\) has finite one-time second moment, while the complementary mixture has infinite one-time second moment because (12.1) holds and \(E\) is bounded. Hence the two stationary component laws are distinct.

Therefore:

### Theorem P24-XI-LAMPERTI-NONERGODIC — PROVED

\[
\boxed{
\mathcal L
\text{ is not ergodic under logarithmic time shifts.}
}
\tag{P24-XI-LAMPERTI-NONERGODIC}
\]

In particular,

\[
\boxed{
\mathcal L
\text{ is not strongly mixing.}
}
\tag{12.4}
\]

Indeed strong mixing implies ergodicity: for a shift-invariant event \(E\),

\[
P(E)
=
P(E\cap\theta_tE)
\to
P(E)^2,
\]

so \(P(E)\in\{0,1\}\).

### Corrected interpretation

P11's theorem

\[
|\operatorname{Cov}_{\mathcal W}
(\mathcal L_s,\mathcal L_t
\mid
G,\mathcal B)|
\lesssim
\varphi(G)^{-1}
e^{-\eta|t-s|}
\]

is a conditional Gaussian-channel decorrelation theorem.

It cannot be upgraded to unconditional strong mixing because the common random scale \(A\) survives at every logarithmic time.

The correct future mixing target is the scale-free stationary core

\[
\boxed{
Z_t=\sqrt{\varphi(G)}\,\mathcal L_t.
}
\]
