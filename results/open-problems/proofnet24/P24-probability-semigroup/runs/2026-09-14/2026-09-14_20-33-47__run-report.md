This section is new.

Let

\]

Put
\[
\boxed{
A_j
=
E\|M_j\|_F^2.

\tag{5.2}

By row exchangeability, if two copies of the null projector share exactly \(j\) original rows and otherwise use independent completions, then
\[
\boxed{
A_j
=
R_{m-j}.
}
\tag{5.3}
\]

This follows because, conditionally on the shared rows,
\[
E[\operatorname{tr}(\Pi'\Pi'')\mid\mathcal F_j]
=
\|M_j\|_F^2.
\]

## 5.1 Orthogonal reveal increments

Define
\[
\Delta_j
=
E\|M_j-M_{j-1}\|_F^2,
\qquad
1\le j\le n.
\tag{5.4}
\]

Since \(M_j\) is a Hilbert-space martingale,
\[
M_{j-1}
=
E[M_j\mid\mathcal F_{j-1}],
\]
and the martingale difference is orthogonal in \(L^2\) to \(\mathcal F_{j-1}\).

Therefore
\[
\boxed{
A_j-A_{j-1}
=
\Delta_j
\ge0.
}
\tag{5.5}
\]

Hence
\[
\boxed{
A_j
=
A_0+\sum_{\ell=1}^j\Delta_\ell.
}
\tag{5.6}
\]

This is the exact “purity reveal” decomposition.

# 7. Why the loss is genuinely local in the noise scale

The old sequential proof naturally produces the partial accumulated defect
\[
\sum_{k\le D}
\frac{\varepsilon_k}{k}.
\]

A naive semigroup bound could replace \(D\) by its worst possible value \(m\), leading to the useless factor
\[
\Lambda_\xi(m)
\]
even when only a small fraction of rows is refreshed.

The new theorem instead shows that the relevant scale is
\[
x_{m,\theta}
=
1+(m-1)(1-\theta).
\]

This is exactly the expected residual dimension under the row-noise coupling.

Thus:

- if \(1-\theta\asymp1\), then \(x\asymp m\);
- if \(1-\theta\asymp D/m\), then \(x\asymp D\);
- if \(1-\theta\ll1/m\), then \(x=O(1)\).

The anisotropy debt is never charged beyond the scale actually seen by the Bernoulli noise.

This is the main new semigroup insight.
