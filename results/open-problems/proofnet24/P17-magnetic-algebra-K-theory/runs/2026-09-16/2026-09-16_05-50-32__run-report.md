# 5. Proof of `P17-M45-SPARSE-HERMITIAN-LINEARIZATION-INERTIA-41`

Let the singular values of `B\in M_N(\mathbb C)` be

\[
s_1,\ldots,s_N\ge0.
\]

Choose a singular-value decomposition

\[
B=U\Sigma V^*,
\qquad
\Sigma=\operatorname{diag}(s_1,\ldots,s_N).
\]

The block unitary `diag(V,U)` conjugates

\[
\mathcal H(B)=
\begin{pmatrix}0&B^*\\B&0\end{pmatrix}
\]

to

\[
\begin{pmatrix}0&\Sigma\\\Sigma&0\end{pmatrix}.
\]

After the fixed unitary change of basis

\[
\frac1{\sqrt2}
\begin{pmatrix}I&I\\I&-I\end{pmatrix},
\]

this becomes

\[
\operatorname{diag}(\Sigma,-\Sigma).
\]

Hence

\[
\sigma(\mathcal H(B))=\{+s_j,-s_j:1\le j\le N\}
\]

with multiplicity.

For `t>0`, the shifted eigenvalues are

\[
s_j-t,
\qquad
-s_j-t.
\]

The second member is always negative. The first is negative exactly when `s_j<t`. Thus, when `t` is not itself a singular value,

\[
\nu_-(\mathcal H(B)-tI)
=N+\#\{j:s_j<t\},
\]

which is `(M45.1)`.

If `0<t_-<t_+` and neither endpoint is a singular value, subtract the two counts:

\[
\nu_-(\mathcal H(B)-t_+I)
-
\nu_-(\mathcal H(B)-t_-I)
=
\#\{j:t_-<s_j<t_+\}.
\tag{5.1}
\]

Endpoint nonsingularity excludes equality with either endpoint, so equality of the two inertias is equivalent to absence of singular values in the **closed** interval `[t_-,t_+]`. This proves `(M45.2)`.

### Why this is sharper for the present certificate

The Gram criterion

\[
B^*B-t^2I
\]

has eigenvalues `s_j^2-t^2`. It is algebraically correct, but the condition scale near a small singular value is squared, and sparse multiplication can create extra fill. The linearization criterion uses the same nearest-neighbor sparse graph as the physical doubled Hamiltonian and compares directly at energy `t`.

No numerical-analysis theorem beyond unitary equivalence and Sylvester inertia is hidden here.

# 6. Proof of `P17-M45-CYCLIC-BLOCK-SCHUR-INERTIA-41`

## 6.1 Exact block-cyclic form

Order the doubled cell by first coordinate

\[
n_1=0,1,\ldots,L-1,
\qquad L=306,
\]

and inside each layer by

\[
n_2=0,1,\ldots,m-1,
\qquad m=148.
\]

Equation `(4.3)` has only four nearest-neighbor directions. Therefore

\[
M_t=\widetilde H-tI
\]

has block form

\[
M_t=
\begin{pmatrix}
D_0&E_0^*&0&\cdots&Q^*\\
E_0&D_1&E_1^*&\ddots&0\\
0&E_1&D_2&\ddots&\vdots\\
\vdots&\ddots&\ddots&\ddots&E_{L-2}^*\\
Q&0&\cdots&E_{L-2}&D_{L-1}
\end{pmatrix}.
\tag{6.1}
\]

Here:

- `D_j` is the vertical `148 x 148` magnetic cyclic Jacobi block at horizontal layer `j`, minus `tI`;
- `E_j` is the horizontal hopping from layer `j` to `j+1`; in the natural Landau/Floquet gauges it is a nonzero scalar multiple of `I_m` because `t_1` depends only on `n_1`;
- `Q=qI_m`, `q\ne0`, is the chosen horizontal wrap coupling, including the first-direction Bloch phase.

The nonzero statement follows because every source hopping weight `(4.2)` is strictly positive; Bloch factors have unit modulus.

Delete `Q` and `Q^*` and call the open-chain matrix `T`. Let

\[
U:\mathbb C^{2m}\to\mathbb C^{Lm}
\]

be the isometric coordinate embedding into the first and last layer. Then

\[
M_t=T+UWU^*,
\tag{6.2}
\]

where

\[
W=
\begin{pmatrix}
0&\bar qI_m\\qI_m&0
\end{pmatrix}.
\tag{6.3}
\]

The eigenvalues of `W` are `+|q|` and `-|q|`, each with multiplicity `m`. Hence `W` is invertible and

\[
\nu_+(W^{-1})=\nu_-(W^{-1})=m.
\tag{6.4}
\]

## 6.2 Open-chain block `LDL^*`

Suppose the successive Schur pivots

\[
S_0=D_0,
\qquad
S_j=D_j-E_{j-1}S_{j-1}^{-1}E_{j-1}^*
\tag{6.5}
\]

are nonsingular. Standard block Gaussian elimination by congruence yields

\[
T=L\,\operatorname{diag}(S_0,S_1,\ldots,S_{L-1})L^*
\tag{6.6}
\]

for a block unit lower-triangular `L`. By Sylvester's law of inertia,

\[
\nu_-(T)=\sum_{j=0}^{L-1}\nu_-(S_j).
\tag{6.7}
\]

The same factorization solves `TY=U` with only `2m` right-hand sides. Since only the first and last block rows of `Y` are required for

\[
U^*Y=U^*T^{-1}U,
\]

the full inverse is never constructed.

## 6.3 Cyclic wrap correction

Assume now only that `T` is nonsingular. Consider the bordered Hermitian matrix

\[
\mathcal K=
\begin{pmatrix}
T&U\\
U^*&-W^{-1}
\end{pmatrix}.
\tag{6.8}
\]

Take the Schur complement first with respect to `-W^{-1}`. Since

\[
(-W^{-1})^{-1}=-W,
\]

the complement is

\[
T-U(-W)U^*=T+UWU^*=M_t.
\]

Haynsworth/Sylvester inertia additivity therefore gives

\[
\nu_-(\mathcal K)
=
\nu_-(-W^{-1})+\nu_-(M_t).
\tag{6.9}
\]

Now take the Schur complement first with respect to `T`. The complement is

\[
-W^{-1}-U^*T^{-1}U=-R,
\]

where

\[
R=W^{-1}+U^*T^{-1}U.
\]

Thus

\[
\nu_-(\mathcal K)
=
\nu_-(T)+\nu_-(-R)
=
\nu_-(T)+\nu_+(R).
\tag{6.10}
\]

Equating `(6.9)` and `(6.10)` and using `(6.4)` gives

\[
\nu_-(M_t)
=
\nu_-(T)+\nu_+(R)-m,
\]

which is `(M45.4)`.

The determinant identity follows from the matrix determinant lemma:

\[
\begin{aligned}
\det(T+UWU^*)
&=\det T\,\det(I+WU^*T^{-1}U)\\
&=\det T\,\det W\,
\det(W^{-1}+U^*T^{-1}U).
\end{aligned}
\]

This proves `(M45.5)`.

### Literature check

The inertia-additivity principle is classical. The original primary reference is E. V. Haynsworth, _Determination of the inertia of a partitioned Hermitian matrix_, Linear Algebra and its Applications 1 (1968), 73–81, DOI `10.1016/0024-3795(68)90050-5`. The theorem above is nevertheless derived directly from two Schur complements of `(6.8)`, so the P17 argument does not depend on an unverified black-box numerical theorem.
