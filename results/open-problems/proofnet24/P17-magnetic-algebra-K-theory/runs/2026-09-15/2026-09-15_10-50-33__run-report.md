# 2. Exact manuscript problem and source Hamiltonian hypotheses

Primary source:
Emil Prodan and Yitzchak Shmalo,
**The K-Theoretic Bulk-Boundary Principle for Dynamically Patterned Resonators**,
arXiv:1805.10629v1,
https://arxiv.org/html/1805.10629v1

The abstract states that the paper starts from a dynamical system \((\Omega,G)\), specializes to \(G=\mathbb Z^d\), adopts Bellissard's \(C^*\)-algebraic formalism for coupled resonators, and uses standard K-theory connecting maps to derive conditions for topological boundary modes after halving the sample.

The historical manuscript problem recovered in earlier P17 reports is the topological identification of the dynamically generated pattern space with the hull: continuity of the map from the dynamical space into the topology on pattern space was the missing step. This run does not reopen that settled source theorem.

The source-facing issue relevant here is instead the physical Hamiltonian class.

The source gives
\[
H(\mathcal P)
=
\sum_{p,p'\in\mathcal P}
h_{p,p'}(\mathcal P)
\otimes
|p\rangle\langle p'|.
\]

Its physical constraints are explicit:

- the hopping matrices are functions of the entire pattern;
- these functions depend continuously on the pattern;
- the hopping becomes less significant as \(|p-p'|\) increases.

Example 2.5 takes the exact exponential model
\[
h_{p,p'}=e^{-\beta|p-p'|}.
\]

Remark 2.6 says that when this is negligible beyond a fixed geometric radius one obtains a finite-range Hamiltonian.

More importantly for the present theorem, §2.2 assumes a canonical \(\mathbb Z^d\)-labeling such that any finite-range physical Hamiltonian in Euclidean space becomes finite-range in the label difference:
\[
H(\mathcal P)
=
\sum_{n,m\in\mathbb Z^d}^{n-m\in K'}
h_{n,m}(\mathcal P)\otimes|n\rangle\langle m|.
\]

§2.3 then gives the covariant canonical form
\[
H(\mathcal P)
=
\sum_{q\in K'}
\sum_{n\in\mathbb Z^d}
h_q(\mathcal P-p_n)
\otimes
|n\rangle\langle n|S_q.
\]

Therefore the source's finite-range class is literally a finite crossed-product Fourier polynomial. This is the class for which the M25 criterion is automatic.

The source's Example 4.3.3 is
\[
p_n
=
n
+
r\big(\sin(n_1\theta_1+\omega_1)-\sin\omega_1\big)e_1
+
r\big(\sin(n_2\theta_2+\omega_2)-\sin\omega_2\big)e_2,
\qquad
r<\frac12.
\]
It is a bounded deformation of the lattice and is used below to verify the exact untruncated exponential hopping model.

# 4. Standard Hilbert-module Toeplitz representation

Use the regular Hilbert \(D_B\)-module

\mathscr E

P_+=1_{\{0,1,2,\ldots\}}(X),

J:\mathscr E_+=P_+\mathscr E\hookrightarrow\mathscr E

W=J^*H_BP_-.

\tag{4.1}

# 5. First normal moment implies boundary trace class

Expand
\[
H_B=\sum_{k\in\mathbb Z}h_kV^k.
\]

For a fixed normal shift \(k>0\), there are exactly \(k\) pairs of normal layers which cross from the negative half-space to the nonnegative half-space.

The cross-boundary block of \(h_kV^k\) therefore has at most \(k\) nonzero normal matrix units, each with coefficient norm \(\|h_k\|\) (up to the isometric automorphism \(\alpha_B\)).

Pass to the semifinite von Neumann representation induced by \(\mathcal T_{D,\mu}\). A rank-one normal matrix unit tensored with \(a\in D_B\) has \(L^1\)-norm
\[
\mathcal T_{D,\mu}(|a|)
\le
\|a\|.
\]

Hence
\[
\boxed{
\|W\|_{L^1}
\le
\sum_{k>0}k\,\|h_k\|
\le
\sum_{k\in\mathbb Z}|k|\,\|h_k\|
<\infty.
}
\tag{5.1}
\]

Thus the boundary defect is \(L^1\) in the natural plus/full linking semifinite algebra.

This estimate is exact enough for finite range but also survives infinite hopping tails.

---

# 6. Resolvent defect identity

Let
\[
R(z)=(z-H_B)^{-1},
\qquad
R_+(z)=(z-\widehat H_B)^{-1}.
\]

A direct calculation gives
\[
(z-\widehat H_B)J^*R(z)J
=
1+J^*H_BP_-R(z)J.
\]

Therefore
\[
\boxed{
R_+(z)-J^*R(z)J
=
-
R_+(z)\,W\,R(z)J.
}
\tag{6.1}
\]

This is an identity of bounded operators wherever both resolvents exist.

Let
\[
K=\operatorname{supp}(g)\Subset I
\]
and
\[
\delta=\operatorname{dist}(K,\operatorname{Spec}(H_B))>0.
\]

For \(z=x+iy\) with \(x\) in a sufficiently small fixed neighborhood of \(K\),
\[
\|R(z)\|\le C_\delta,
\]
while
\[
\|R_+(z)\|\le |y|^{-1}.
\]

Because \(L^1\) is a two-sided ideal for bounded operators,
\[
\boxed{
\|R_+(z)-J^*R(z)J\|_{L^1}
\le
C_\delta
\,|y|^{-1}
\,\|W\|_{L^1}.
}
\tag{6.2}
\]

No Combes–Thomas estimate is required for this theorem.

That is an important simplification relative to the more restrictive finite-range route.

# 7. Gap functional calculus produces an edge trace-class operator

Choose an almost-analytic extension \(\widetilde g\) supported in the fixed bulk gap neighborhood and satisfying, for arbitrarily large \(M\),
\[
|\bar\partial\widetilde g(x+iy)|
\le
C_M|y|^M.
\]

Helffer–Sjöstrand gives
\[
g(\widehat H_B)
=
\frac1\pi
\int_{\mathbb C}
\bar\partial\widetilde g(z)
R_+(z)\,d^2z.
\]

Since
\[
g(H_B)=0
\]
because \(\operatorname{supp}(g)\) lies in the bulk gap,
\[
J^*g(H_B)J=0.
\]

Subtracting the zero bulk term and using (6.1),
\[
\boxed{
g(\widehat H_B)
=
\frac1\pi
\int_{\mathbb C}
\bar\partial\widetilde g(z)
\big(
R_+(z)-J^*R(z)J
\big)\,d^2z.
}
\tag{7.1}
\]

Using (6.2),
\[
\|g(\widehat H_B)\|_{L^1}
\le
C
\|W\|_{L^1}
\int_{|y|\le1}|y|^{M-1}\,dx\,dy
<\infty
\]
for \(M\ge1\).

Thus
\[
\boxed{
g(\widehat H_B)
\in
L^1(\widehat{\mathcal T}_{\mu,B}).
}
\tag{7.2}
\]

This is the first assertion of M25.2.

# 8. Tangential current factor

\[
\sum_k\|\nabla_jh_k\|<\infty.

Therefore the Fourier series
\[
\nabla_jH_B
=
\sum_k(\nabla_jh_k)V^k

\[
\nabla_jH_B\in M_N(A_B).

Compression gives a bounded
\[
\nabla_j\widehat H_B
=
J^*(\nabla_jH_B)J.

Since \(L^1\) is a two-sided ideal,
\[
\boxed{
g(\widehat H_B)\nabla_j\widehat H_B
\in
L^1(\widehat{\mathcal T}_{\mu,B}).
}
\tag{8.1}
\]

Hence the physical edge-current functional of M24 is automatically defined.

# 11. Exact source finite-range corollary

The source paper's canonical-label hypothesis says that a finite physical hopping range becomes a finite label hopping range.

Thus for a finite-range source Hamiltonian, only finitely many full Fourier coefficients
\[
h_q\in M_N(C(\Omega))
\]
occur.

After decomposing \(q=(q_\parallel,k)\) relative to the boundary cut, the outer coefficients \(h_k\in M_N(D_B)\) are finite tangential Fourier polynomials and only finitely many \(k\)'s occur.

Consequently
\[
\sum_k(1+|k|)\|h_k\|<\infty
\]
and
\[
\sum_k\|\nabla_jh_k\|<\infty.
\]

Therefore:

### `P17-M25-SOURCE-FINITE-RANGE-COROLLARY-17` — PROVED

Every finite-range physical Hamiltonian satisfying the exact Prodan–Shmalo canonical-label assumptions has a half-space compression for which the P17 M24 edge-current theorem is automatically defined.

Magnetic Peierls phases do not change the conclusion: they only change crossed-product phases/automorphisms and do not enlarge Fourier support or coefficient norms.

# 12. Exact exponential hopping on the lattice-perturbation working example

The source's Example 2.5 is
\[

The two-dimensional working pattern Example 4.3.3 is
\[

=

+

+
r(\sin(n_2\theta_2+\omega_2)-\sin\omega_2)e_2,
\qquad

For \(q=n-m\),
\[
\|p_n-p_m\|_2
\ge
\|q\|_2
-
2r\sqrt2.
\]

Therefore
\[
e^{-\beta\|p_n-p_m\|}
\le
e^{2\sqrt2\,\beta r}
e^{-\beta\|q\|_2}.
\]

Let \(a_q(\omega)\) denote the corresponding crossed-product coefficient. Then uniformly in \(\omega\),
\[
\|a_q\|
\le
C e^{-\beta\|q\|_2}.
\]

For the cut normal to \(e_2\), group the coefficients according to \(k=q_2\):
\[
h_k
=
\sum_{q_1\in\mathbb Z}
a_{(q_1,k)}U_1^{q_1}.
\]

Hence
\[
\|h_k\|
\le
\sum_{q_1}
C e^{-\beta\sqrt{q_1^2+k^2}},
\]
and
\[
\|\nabla_1h_k\|
\le
2\pi
\sum_{q_1}
|q_1|
C e^{-\beta\sqrt{q_1^2+k^2}}.
\]

Therefore
\[
\sum_k(1+|k|)\|h_k\|<\infty,
\qquad
\sum_k\|\nabla_1h_k\|<\infty.
\]

Thus:

### `P17-M25-SOURCE-EXPONENTIAL-43.3-17` — PROVED

For the exact, untruncated exponential hopping model of source Example 2.5 placed on source working pattern 4.3.3, the M25 first-normal-moment hypotheses hold. Consequently the canonical half-space edge current is trace-defined and equals the bulk Hall/Chern pairing whenever the bulk gap is open.
