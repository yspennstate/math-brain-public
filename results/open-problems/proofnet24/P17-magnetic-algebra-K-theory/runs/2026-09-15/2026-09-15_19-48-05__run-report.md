# 5. General separated evanescent Gram theorem

We now prove the analytic input needed for the public source element.

## 5.1 Statement

Let

\[
P=\{p_n:n\in I\}\subset\mathbb R^D
\]

be countable and uniformly separated:

\[
|p_n-p_m|\ge\delta>0
\qquad(n\ne m).
\tag{5.1}
\]

For `beta>0`, define initially on finitely supported vectors

\[
(K_Pc)_n
=\sum_m k_\beta(p_n-p_m)c_m,
\qquad
k_\beta(x)=e^{-\beta|x|}.
\tag{5.2}
\]

Then `K_P` extends to a bounded operator on `ell^2(I)` and there is a constant

\[
c_{\beta,\delta,D}>0
\]

depending only on `beta,delta,D` such that

\[
\boxed{K_P\ge c_{\beta,\delta,D}I.}
\tag{5.3}
\]

In particular `K_P` is boundedly invertible.

## 5.2 Boundedness

Uniform separation gives a uniform packing bound. For a fixed `p_n`, the balls

\[
B(p_m,\delta/2)
\]

are pairwise disjoint. Comparing volumes in successive annuli gives a dimension-only constant `C_D` such that the number of points with

\[
j\delta\le|p_m-p_n|<(j+1)\delta
\]

is at most

\[
C_D(j+1)^{D-1}.
\]

Hence

\[
\sup_n\sum_m e^{-\beta|p_n-p_m|}
\le
1+C_D\sum_{j\ge0}(j+1)^{D-1}e^{-\beta j\delta}
<\infty.
\tag{5.4}
\]

The Schur test proves boundedness.

## 5.3 Fourier transform of the evanescent kernel

With convention

\[
\widehat f(\xi)=\int_{\mathbb R^D}e^{-ix\cdot\xi}f(x)\,dx,
\]

one has

\[
\boxed{
\widehat{k_\beta}(\xi)
=
C_D'\,
\frac{\beta}{(\beta^2+|\xi|^2)^{(D+1)/2}},
}
\tag{5.5}
\]

where

\[
C_D'=2^D\pi^{(D-1)/2}\Gamma\!\left(\frac{D+1}{2}\right)>0.
\]

Thus the Fourier transform is strictly positive everywhere and decays only polynomially of order `D+1`.

## 5.4 Compactly supported comparison kernel

Choose any nonzero

\[
\eta\in C_c^\infty(B(0,\delta/4))
\]

and set

\[
\widetilde\eta(x)=\overline{\eta(-x)},
\qquad
\phi=\eta*\widetilde\eta.
\tag{5.6}
\]

Then

\[
\operatorname{supp}\phi\subset B(0,\delta/2),
\qquad
\phi(0)=\|\eta\|_2^2,
\qquad
\widehat\phi=|\widehat\eta|^2.
\tag{5.7}
\]

Because `hat eta` is Schwartz while `hat k_beta` has only polynomial decay,

\[
M_{\eta,\beta}
:=
\sup_{\xi\in\mathbb R^D}
\frac{|\widehat\eta(\xi)|^2}
{\widehat{k_\beta}(\xi)}
<\infty.
\tag{5.8}
\]

Since `eta` is nonzero, `M_{eta,beta}>0`. Put

\[
\varepsilon=\frac1{M_{\eta,\beta}}>0.
\tag{5.9}
\]

Then pointwise in Fourier space,

\[
\widehat{k_\beta}(\xi)
\ge
\varepsilon|\widehat\eta(\xi)|^2.
\tag{5.10}
\]

## 5.5 Lower Riesz bound

Let `c` be finitely supported. Fourier inversion gives

\[
\begin{aligned}
\langle c,K_Pc\rangle
&=\sum_{n,m}\overline{c_n}c_m
k_\beta(p_n-p_m)\\
&=(2\pi)^{-D}
\int_{\mathbb R^D}
\widehat{k_\beta}(\xi)
\left|\sum_nc_ne^{ip_n\cdot\xi}\right|^2d\xi.
\end{aligned}
\tag{5.11}
\]

Using `(5.10)`,

\[
\langle c,K_Pc\rangle
\ge
\varepsilon(2\pi)^{-D}
\int
|\widehat\eta(\xi)|^2
\left|\sum_nc_ne^{ip_n\cdot\xi}\right|^2d\xi.
\tag{5.12}
\]

By Fourier inversion again, the right side is

\[
\varepsilon
\sum_{n,m}\overline{c_n}c_m\phi(p_n-p_m).
\tag{5.13}
\]

If `n!=m`, separation `(5.1)` and the support condition in `(5.7)` give

\[
\phi(p_n-p_m)=0.
\]

Therefore

\[
\boxed{
\langle c,K_Pc\rangle
\ge
\varepsilon\|\eta\|_2^2
\sum_n|c_n|^2.
}
\tag{5.14}
\]

Thus one may take the fully explicit variational certificate

\[
\boxed{
c_{\beta,\delta,D}
=
\frac{\|\eta\|_2^2}
{\displaystyle
\sup_\xi
|\widehat\eta(\xi)|^2/\widehat{k_\beta}(\xi)}
>0
}
\tag{5.15}
\]

for any chosen nonzero smooth bump supported in `B(0,delta/4)`.

Density extends `(5.14)` to all of `ell^2(I)`. This proves

`P17-M35-SEPARATED-EVANESCENT-RIESZ-31`.
