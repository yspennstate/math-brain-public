# 5. New theorem: positivity of the public all-hopping evanescent Hamiltonian

## `P17-M34-PUBLIC-EVANESCENT-POSITIVITY-30` — PROVED at zero magnetic field

Let `P={p_n}` be any source Euclidean point pattern for which the public all-hopping operator is bounded, and let

\[
K_{nm}=e^{-\beta|p_n-p_m|},
\qquad \beta>0.
\]

Then the matrix kernel `K` is positive semidefinite. Hence the corresponding zero-field source Hamiltonian is positive.

### Proof

Use the elementary subordination identity

\[
\boxed{
 e^{-\beta r}
 =
 \frac{\beta}{2\sqrt\pi}
 \int_0^\infty
 t^{-3/2}
 e^{-\beta^2/(4t)}
 e^{-tr^2}
 \,dt.
}
\tag{5.1}
\]

For each `t>0`, the Gaussian Euclidean kernel

\[
(x,y)\mapsto e^{-t|x-y|^2}
\]

is positive definite. Therefore, for every finitely supported vector `(c_n)`,

\[
\sum_{n,m}\overline{c_n}c_m e^{-t|p_n-p_m|^2}\ge0.
\]

Multiply by the positive weight in `(5.1)` and integrate to obtain

\[
\sum_{n,m}\overline{c_n}c_m e^{-\beta|p_n-p_m|}\ge0.
\tag{5.2}
\]

Thus every physical regular representation of the public zero-field Hamiltonian is positive. The source transformation-group crossed product is amenable, so the regular family is faithful. Hence

\[
\boxed{h_{\rm full}\ge0.}
\]

Since `w_0=1`,

\[
\boxed{h_{\rm full}-1\ge-1.}
\tag{5.3}
\]

QED.

### Scope
