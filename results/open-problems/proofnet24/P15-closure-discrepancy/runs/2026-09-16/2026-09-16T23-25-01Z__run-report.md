The last run used one common finite-dimensional triple `(M,C_1,...,C_m)` on every spectral scale. The first new route was to allow the matrices, and even the Lyapunov function, to vary from scale to scale while keeping only uniform constants. For the concrete `d=2`, `p=4` family with `V(x,y)=(x^2+y^2)^2`, the stochastic generator condition is positivity of a rational homogeneous binary quartic. After projectivization this is a one-variable quartic nonnegativity problem. Thus a proposed rational coefficient family can be certified exactly by a finite symbolic pipeline (expansion, projective chart, exact critical-point/root isolation or an SOS certificate) rather than by numerical sampling.

### Move #29 — add the point at infinity

Homogeneity means coercivity lives naturally on real projective space. In dimension two, the chart `t=y/x` plus the point `x=0` compactifies all directions. A strict positive margin on this compact set is therefore structurally stable. I quantified that stability around the previous noncommuting example by an explicit operator-norm ball.

## 4. Main theorem: heterogeneous Lyapunov blocks

### Claim `P15-I0066-HETEROGENEOUS-LYAPUNOV-05B — PROVED / SAME METRIC FAMILY`

Fix `p>=2`, finite `d,m`, and positive scales `lambda_k>=lambda_0>0`. Let

`X_0 = ell^p(N;R^d)`,

with scales

`||x||_{X_1}^p = sum_k lambda_k^p |x_k|^p`,

`||x||_{X_{1/2}}^p = sum_k lambda_k^(p/2) |x_k|^p`.

For every `k`, let `M_k,C_{1,k},...,C_{m,k}` be real `d x d` matrices, uniformly bounded in `k`. Assume there are `C^2` functions `V_k:R^d->R_+` and constants `c_0,C_0,C_1,C_2,c_*>0`, independent of `k`, such that for all `y`:

1. `c_0 |y|^p <= V_k(y) <= C_0 |y|^p`;
2. `|DV_k(y)| <= C_1 |y|^(p-1)`;
3. `|D^2V_k(y)| <= C_2 |y|^(p-2)` (with the natural bounded interpretation at zero when `p=2`);
4. the uniform stochastic generator inequality

`DV_k(y)[M_k y] - (1/2) sum_{j=1}^m D^2V_k(y)[C_{j,k}y,C_{j,k}y] >= c_* |y|^p`.

Define

`(Au)_k = lambda_k M_k u_k`,

`(B_j u)_k = lambda_k^(1/2) C_{j,k} u_k`.

Then the pair `(A,B)` has the corresponding **base stochastic maximal `L^p`-regularity estimate** on every finite horizon for arbitrary progressive drift forcing `f in L^p(X_0)` and finite-dimensional noise forcing `g in L^p(gamma(R^m,X_{1/2}))`, uniformly over the source's allowed starting times and bounded stopping times. No commutation among `M_k,C_{j,k}` and no smallness of the global `B` norm is assumed.

### Proof

First truncate to coordinates `k<=N`. This is a finite-dimensional linear SDE, hence has the usual strong adapted solution. Apply Ito's formula to

`E_N(u) = sum_{k<=N} lambda_k^(p-1) V_k(u_k)`.

For the homogeneous drift and multiplicative noise, the `k`th finite-variation contribution is

`-lambda_k^p { DV_k(u_k)[M_k u_k] - (1/2) sum_j D^2V_k(u_k)[C_{j,k}u_k,C_{j,k}u_k] } dt`,

which is at most

`-c_* lambda_k^p |u_k|^p dt`.

Write `G_k=(sum_j |g_{j,k}|^2)^(1/2)`. Uniform derivative bounds and uniform matrix bounds reduce the three forcing contributions to fixed multiples of

`lambda^(p-1)|u|^(p-1)|f|`,

`lambda^(p-1/2)|u|^(p-1)G`,

`lambda^(p-1)|u|^(p-2)G^2`.

For every sufficiently small `epsilon>0`, Young's inequality gives, with constants independent of `k,N`,

`lambda^(p-1)|u|^(p-1)|f| <= epsilon lambda^p|u|^p + C_epsilon |f|^p`,

`lambda^(p-1/2)|u|^(p-1)G <= epsilon lambda^p|u|^p + C_epsilon lambda^(p/2)G^p`,

`lambda^(p-1)|u|^(p-2)G^2 <= epsilon lambda^p|u|^p + C_epsilon lambda^(p/2)G^p`.

Choose `epsilon` so the sum of absorbed terms is strictly below `c_*`. Localize the martingale term and take expectations. The martingale expectation vanishes; then remove localization by monotone/Fatou arguments using the resulting uniform bound. This yields

`E int ||u_N||_{X_1}^p <= C E int (||f_N||_{X_0}^p + ||g_N||_{gamma(R^m,X_{1/2})}^p)`

with `C` independent of `N`. For finite `m,d`, the gamma norm on the block `ell^p` scale is equivalent, with constants depending only on `p,m,d`, to the coordinate expression based on `G_k`, so the right-hand side is exactly at the source data scale up to fixed equivalence constants.

For `N>M`, the difference `u_N-u_M` lives only on tail coordinates and solves the same block-diagonal equation with tail data `f_N-f_M`, `g_N-g_M`. The same estimate therefore makes `(u_N)` Cauchy in `L^p(Omega x time;X_1)`. Since `B:X_1->gamma(R^m,X_{1/2})` is bounded under the uniform `C_{j,k}` bound, the stochastic terms converge as well (BDG plus the embedding needed for the strong formulation). The limit is an adapted strong solution and inherits the estimate by lower semicontinuity. Applying the estimate to the difference of two solutions with zero data gives uniqueness. The proof is unchanged after a bounded stopping time because all estimates are obtained on the stopped finite-dimensional equations with constants independent of the stopping time.

This establishes the claim. It is a strict *scope strengthening* of family 5, but not a new mechanism; accordingly `C_nonzero` stays at 5.

## 5. Quantitative robustness: an explicit noncommuting open ball

For `p=4`, take `V(z)=|z|^4`. Then

`DV(z)[Mz] = 4|z|^2 z.Mz`,

and

`(1/2)D^2V(z)[Cz,Cz] = 4(z.Cz)^2 + 2|z|^2|Cz|^2`.

Let the baseline be

`M_0=diag(2,3)`,

`C_{1,0}=J=[[0,-1],[1,0]]`,

`C_{2,0}=(1/2)D`, `D=diag(1,-1)`.

The previous exact identity is

`Q_0(z) >= (9/2)|z|^4`.

Now perturb by matrices `Delta M,E_1,E_2` satisfying

`||Delta M||_2, ||E_1||_2, ||E_2||_2 <= delta`.

The drift loss is at most `4 delta |z|^4`. For

`N_C(z)=4(z.Cz)^2+2|z|^2|Cz|^2`,

direct expansion and Cauchy-Schwarz give

`|N_{C+E}(z)-N_C(z)| <= (12||C||_2 delta+6delta^2)|z|^4`.

At `delta=1/8`, using `||C_{1,0}||=1`, `||C_{2,0}||=1/2`, the total worst-case loss is exactly

`4(1/8) + [12(1)(1/8)+6(1/8)^2] + [12(1/2)(1/8)+6(1/8)^2] = 47/16`.

Therefore every such perturbed triple satisfies the **uniform strict margin**

`Q(z) >= (9/2-47/16)|z|^4 = (25/16)|z|^4`.

Consequently 05B applies even if a different admissible triple is chosen at every scale `k`. This produces a full operator-norm product neighborhood of critical-order, nonzero multiplicative-noise examples rather than a single exact matrix tuple.

An exact endpoint stress test is

`M_1=diag(17/8,23/8)`,

`C_{1,1}=(7/8)J`,

`C_{2,1}=(5/8)D`.

Every matrix is exactly distance `1/8` from its baseline counterpart. Exact expansion gives

and

`Q_1-(25/16)(x^2+y^2)^2=(49x^4+246x^2y^2+97y^4)/16 >=0`.

Moreover

`[C_{1,1},C_{2,1}] = [[0,35/32],[35/32,0]] != 0`,

so the certified ball is not merely a commuting degeneration.

## 6. Exact projective certification algorithm

For rational `2 x 2` matrices at `p=4`, compute the homogeneous rational quartic

`q(x,y)=DV(x,y)[M(x,y)]-(1/2)sum_j D^2V(x,y)[C_j(x,y),C_j(x,y)]`.

For a proposed rational margin `c`, set

`r_c(x,y)=q(x,y)-c(x^2+y^2)^2`.

Because `r_c` is homogeneous of degree four, global nonnegativity is equivalent to:

1. `h_c(t)=r_c(1,t)>=0` for all real `t`;
2. the projective point at infinity, equivalently the coefficient of `y^4`, is nonnegative.

Thus exact certification reduces to a univariate rational quartic. One can decide it by exact Sturm/root isolation applied to the derivative and evaluation at all real critical points/end behavior, or use a binary-quartic SOS representation when convenient. This is an algorithmic packaging of classical polynomial positivity/Lyapunov methods, **not a novelty claim**.

For the baseline at its sharp displayed margin `9/2`,

`h_0(t)=4t^4+8t^2`.

For the endpoint at the certified robust margin `25/16`,

`h_1(t)=(97/16)t^4+(123/8)t^2+49/16`,

which is strictly positive on the entire projective line.
