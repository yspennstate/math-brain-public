## 4. Orthogonal Brownian-coordinate randomization is exactly neutral

### Claim `P15-I0066-NOISE-ROTATION-INVARIANCE-06A` — PROVED / ROUTE NO-GO / NO METRIC CREDIT

Let `B_1,...,B_m` be operators for which the stochastic equation is defined, let `O=(O_{jk}) in O(m)`, and set

\[
\widetilde B_j=\sum_{k=1}^m O_{jk}B_k,
\qquad
\widetilde W_j=\sum_{\ell=1}^m O_{j\ell}W_\ell.
\]

Then

\[
\sum_{j=1}^m \widetilde B_j u\,d\widetilde W_j
=
\sum_{k=1}^m B_k u\,dW_k.
\tag{4.1}
\]

Indeed,

\[
\begin{aligned}
\sum_j\widetilde B_j u\,d\widetilde W_j
&=\sum_{j,k,\ell}O_{jk}O_{j\ell}B_ku\,dW_\ell\\
&=\sum_{k,\ell}(O^TO)_{k\ell}B_ku\,dW_\ell
=\sum_k B_ku\,dW_k.
\end{aligned}
\]

Thus deterministic orthogonal randomization of the Brownian basis is merely a change of coordinates.

More generally, for every symmetric bilinear form `H` (in particular `H=D^2V(x)`),

\[
\boxed{
\sum_{j=1}^m H(\widetilde B_jx,\widetilde B_jx)
=
\sum_{k=1}^m H(B_kx,B_kx).
}
\tag{4.2}
\]

The proof is the same contraction:

\[
\sum_{j,k,\ell}O_{jk}O_{j\ell}H(B_kx,B_\ell x)
=
\sum_k H(B_kx,B_kx).
\]

In a Hilbert space, (4.2) includes

\[
\sum_j\widetilde B_j^*\widetilde B_j
=
\sum_k B_k^*B_k.
\tag{4.3}
\]

Therefore an averaging/search scheme that changes only the orthonormal Brownian coordinate system cannot lower the total Itô Hessian debt or stochastic-parabolicity quadratic form. This kills one seemingly natural randomization route exactly; it does **not** say that all probabilistic constructions are useless.

## 5. Derandomized sparse critical blocks: “typical good scales” are not enough

### 5.1 Deterministic source-valid pair

Let

\[
H=\ell^2(\mathbb N_0),\qquad Ae_n=2^n e_n,
\]

with

\[
X_0=H,\qquad X_1=D(A),\qquad X_{1/2}=D(A^{1/2}).
\]

For `k>=1`, define

\[
M_k:=2^{k^2},\qquad
I_k:=\{M_k,M_k+1,\ldots,M_k+k-1\}.
\]

These edge blocks are disjoint. Put

\[
c_n:=\mathbf 1_{\bigcup_{k\ge1}I_k}(n),
\qquad
Be_n=c_n\,2^{n/2}e_{n+1}.
\tag{5.1}
\]

This is a bounded leading-order noise map `B:X_1 -> X_{1/2}` because

\[
\|Bx\|_{X_{1/2}}^2
=
2\sum_n c_n^2\,2^{2n}|x_n|^2
\le 2\|Ax\|_H^2.
\tag{5.2}
\]

The critical edges have natural density zero. If `M_k <= N < M_{k+1}`, then

\[
\#\{n\le N:c_n=1\}
\le \sum_{j=1}^k j=\frac{k(k+1)}2,
\]

while `N>=M_k=2^{k^2}`. Hence

\[
\frac1{N+1}\#\{n\le N:c_n=1\}
\le \frac{k(k+1)}{2\,2^{k^2}}\longrightarrow0.
\tag{5.3}
\]

Thus `c_n=0` on a density-one set of scales.

### 5.2 Claim and proof

### Claim `P15-I0066-ZERO-DENSITY-CRITICAL-BLOCKS-06B` — PROVED / SOURCE-VALID OBSTRUCTION / NO METRIC CREDIT

For the deterministic pair `(A,B)` in (5.1), base stochastic maximal `L^2`-regularity fails on `[0,1]`, even though the critical noise edges have natural density zero.

**Proof.** Fix one block `I_k` and abbreviate

\[
M=M_k,\quad L=k,\quad \lambda_0=2^M,
\quad \lambda_j=2^{M+j}=2^j\lambda_0.
\]

Take zero drift forcing and the deterministic stochastic forcing

\[
g(t)\equiv e_M,
\qquad 0\le t\le1.
\tag{5.4}
\]

Because the edges immediately outside the block vanish, the coordinates `M,...,M+L` form an isolated one-way chain for this input. Let

\[
v_j(t):=\mathbb E|u_{M+j}(t)|^2,
\qquad
w_j(t):=\lambda_j^2v_j(t).
\]

The first coordinate is exactly

\[
v_0(t)=\frac{1-e^{-2\lambda_0t}}{2\lambda_0}.
\tag{5.5}
\]

For `j>=1`, Itô isometry gives

\[
v_j(t)
=\lambda_{j-1}\int_0^t
 e^{-2\lambda_j(t-s)}v_{j-1}(s)\,ds.
\tag{5.6}
\]

Every `v_j` is nondecreasing. Inductively, if `v_{j-1}` is nondecreasing, then

\[
v_j(t)
\le \frac{\lambda_{j-1}}{2\lambda_j}v_{j-1}(t)
=\frac14v_{j-1}(t),
\]

and therefore, using the differential form of (5.6),

\[
v_j'(t)
=-2\lambda_jv_j(t)+\lambda_{j-1}v_{j-1}(t)\ge0.
\]

Now set

\[
\delta_j:=\frac{j}{2\lambda_j}.
\]

Restricting (5.6) to the final interval `[t-\delta_j,t]` and using monotonicity yields

\[
\begin{aligned}
w_j(t)
&\ge \lambda_j^2\lambda_{j-1}
 v_{j-1}(t-\delta_j)
 \int_{t-\delta_j}^t e^{-2\lambda_j(t-s)}ds\\
&=(1-e^{-j})w_{j-1}(t-\delta_j),
\end{aligned}
\tag{5.7}
\]

where the last identity uses `\lambda_j=2\lambda_{j-1}`.

The total delay is uniformly tiny:

\[
\sum_{j=1}^{\infty}\delta_j
=\frac1{2\lambda_0}\sum_{j=1}^{\infty}\frac{j}{2^j}
=\frac1{\lambda_0}.
\tag{5.8}
\]

For `0<a<=1/2`, `\log(1-a)>=-2a`. Since `e^{-j}<1/2`,

\[
\prod_{j=1}^{\infty}(1-e^{-j})
\ge
\exp\!\left(-2\sum_{j=1}^{\infty}e^{-j}\right)
=
\exp\!\left(-\frac2{e-1}\right)
=:P_*>0.
\tag{5.9}
\]

If `t>=2/\lambda_0`, then after all delays in (5.7) the base time remains at least `1/\lambda_0`. Hence from (5.5)--(5.9), for every `0<=j<=L`,

\[
w_j(t)
\ge
P_*\,\frac{\lambda_0}{2}(1-e^{-2})
=:c_*\lambda_0.
\tag{5.10}
\]

(The case `j=0` is even stronger; taking the common lower bound is convenient.) Since `\lambda_0=2^{M_k}>=4`, the interval `[2/\lambda_0,1]` has length at least `1/2`. Therefore

\[
\begin{aligned}
\mathbb E\int_0^1\|Au(t)\|_H^2dt
&\ge \sum_{j=0}^{L}\int_{2/\lambda_0}^1w_j(t)dt\\
&\ge \frac{c_*}{2}(L+1)\lambda_0.
\end{aligned}
\tag{5.11}
\]

On the other hand the input norm is exactly

\[
\int_0^1\|g(t)\|_{X_{1/2}}^2dt=\lambda_0.
\tag{5.12}
\]

If `(A,B)` had base `SMR_{2,0}` on `[0,1]` with constant `C`, Definition 3.7 would force the ratio of (5.11) to (5.12) to be at most `C^2`, uniformly in `k`. But `L=k -> infinity`, so (5.11) forces

\[
C^2\ge \frac{c_*}{2}(k+1)\longrightarrow\infty,
\]

a contradiction. Therefore `(A,B)` does not have base stochastic maximal `L^2`-regularity. `\square`

### 5.3 What this does and does not say

This is not a counterexample to Agresti–Veraar Problem 1; that problem asks for useful sufficient conditions, not for a false universal assertion. It is a route obstruction:

> replacing a uniform structural condition by “the bad leading-order scales have density zero” is insufficient, even for a deterministic diagonal generator and one-dimensional Brownian noise.

The obstruction is the **unbounded length of rare critical blocks**, not their density. Any sufficient criterion modeled on scale averages must therefore control long products / block amplification / an appropriate cocycle, not only a typical or averaged local coefficient.

Move #10 is the key scope correction: rather than enlarge the source problem to random operator coefficients, the rare-bad-event intuition was derandomized into the fixed deterministic pair (5.1).
