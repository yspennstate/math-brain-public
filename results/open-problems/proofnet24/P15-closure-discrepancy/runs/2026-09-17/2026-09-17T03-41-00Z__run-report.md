## 4. Main result: exact counterexample to the schematic candidate

### Claim `P15-I0066-UNITARY-QUADRATIC-DATA-NOGO-06C` — PROVED / ROUTE OBSTRUCTION / NO METRIC CREDIT

There exist a separable Hilbert space `H`, a positive self-adjoint operator `A>=4I`, and a unitary `C` such that, with

\[
B=C A^{1/2},
\]

all of the following hold:

1. `B:D(A)->D(A^{1/2})` is bounded;
2. the candidate (3.1) holds for every `x in D(A^{1/2})` with `delta=1`;
3. form-wise on `D(A^{1/2})`, `B^*B=A`, exactly as for the commuting pair `B_0=A^{1/2}`;
4. nevertheless `(A,B)` **fails base `SMR_{2,0}`** on `[0,1]`.

Thus the naive H-level quadratic coercivity data in the stuck-report candidate is insufficient. A correct condition must see the placement of the noise relative to the `A`-scale — for this example, at least information comparable to (3.2) or an equivalent joint square-function/cocycle invariant.

### Construction

Let

\[
H=\bigoplus_{m\ge1}\mathbb R^{m+1}
\]

with orthonormal basis `e_{m,i}`, `0<=i<=m`. Put

\[
L_m=4^{m^2},\qquad
\lambda_{m,i}=L_m4^i,
\]

and define

\[
A e_{m,i}=\lambda_{m,i}e_{m,i}.
\tag{4.1}
\]

On each block let `C` be the cyclic permutation

\[
C e_{m,i}=e_{m,i+1}\quad(i<m),
\qquad
C e_{m,m}=e_{m,0}.
\tag{4.2}
\]

The direct sum `C` is unitary.

### 4.1 `B` has exactly the required half-order boundedness

For `x in D(A)`,

\[
A^{1/2} Bx
=A^{1/2} C A^{1/2}x
=(A^{1/2}CA^{-1/2})Ax.
\]

On every upward block edge the squared weight of `A^{1/2}CA^{-1/2}` is

\[
\frac{\lambda_{m,i+1}}{\lambda_{m,i}}=4,
\]

while on the wrap edge it is `4^{-m}`. Hence

\[
\boxed{\|A^{1/2}CA^{-1/2}\|=2}
\]

and therefore

\[
\|Bx\|_{X_{1/2}}\le2\|Ax\|_H.
\]

So this is a legitimate critical-order source pair, not an ill-defined unbounded noise.

### 4.2 The candidate inequality is uniformly satisfied

Since `C` is unitary,

\[
\|C A^{1/2}x\|^2=\|A^{1/2}x\|^2,
\]

and therefore

\[
2\|A^{1/2}x\|^2-\|C A^{1/2}x\|^2
=\|A^{1/2}x\|^2.
\tag{4.3}
\]

Thus (3.1) holds with `delta=1`, uniformly over all blocks. Likewise

\[
B^*B=A^{1/2}C^*CA^{1/2}=A
\]

as an H-form.

### 4.3 Source-valid forcing produces unbounded full-order gain

Fix a block `m`. Use zero initial data, `f=0`, and deterministic additive noise

\[
g^{(m)}(t)=e_{m,0},\qquad 0\le t\le1.
\tag{4.4}
\]

The solution remains inside this finite block. Suppress the block index and write `lambda_i=L_m4^i`. Let

\[
v_i(t)=\mathbb E|u_i(t)|^2,
\qquad
w_i(t)=\lambda_i^2v_i(t).
\]

All means vanish. Itô's formula gives the exact cooperative second-moment system

\[
v_0'=-2\lambda_0v_0+\lambda_m v_m+1,
\tag{4.5}
\]

and, for `1<=i<=m`,

\[
v_i'=-2\lambda_i v_i+\lambda_{i-1}v_{i-1}.
\tag{4.6}
\]

Its coefficient matrix is Metzler, so with zero initial condition the semigroup is positive and every `v_i(t)` is nondecreasing.

From (4.5), dropping the nonnegative feedback term,

\[
v_0(t)\ge \frac{1-e^{-2\lambda_0t}}{2\lambda_0}.
\]

Set

\[
T_0=\frac1{2\lambda_0},
\qquad
a=\frac{1-e^{-1}}2.
\]

Then

\[
w_0(t)\ge a\lambda_0\qquad(t\ge T_0).
\tag{4.7}
\]

For `i>=1`, variation of constants and monotonicity give, with

\[
\delta_i=\frac{i}{2\lambda_i},
\]

\[
\begin{aligned}
v_i(t)
&=\lambda_{i-1}\int_0^t e^{-2\lambda_i(t-s)}v_{i-1}(s)\,ds\\
&\ge \frac{\lambda_{i-1}}{2\lambda_i}(1-e^{-i})
 v_{i-1}(t-\delta_i).
\end{aligned}
\]

Multiplying by `lambda_i^2` and using `lambda_i/lambda_{i-1}=4`,

\[
\boxed{
w_i(t)\ge2(1-e^{-i})w_{i-1}(t-\delta_i).
}
\tag{4.8}
\]

Let

\[
P_m=\prod_{j=1}^m(1-e^{-j}).
\]

Because `e^{-j}<1/2` and `log(1-x)>=-2x` on this range,

\[
P_m\ge P_\infty
\ge \exp\!\left(-\frac2{e-1}\right)>0.
\tag{4.9}
\]

The total delay is uniformly tiny:

\[
T_0+\sum_{i=1}^m\delta_i
\le \frac1{2L_m}\left(1+\sum_{i\ge1}\frac{i}{4^i}\right)
=\frac{13}{18L_m}
\le\frac{13}{72}<\frac14.
\tag{4.10}
\]

Iterating (4.8), for every `t in [1/4,1]`,

\[
w_m(t)\ge aP_\infty\,2^m L_m.
\tag{4.11}
\]

Hence

\[
\mathbb E\int_0^1\|Au(t)\|^2dt
\ge \frac34 aP_\infty\,2^m L_m.
\tag{4.12}
\]

But the source input norm is exactly

\[
\int_0^1\|g^{(m)}(t)\|_{X_{1/2}}^2dt
=\|A^{1/2}e_{m,0}\|^2
=L_m.
\tag{4.13}
\]

The output/input ratio therefore grows at least like a positive constant times `2^m`. No uniform base-SMR estimate can hold. This proves the claim.

There is no conflict with the source's `p=2` variational theorem: (4.3) is the wrong H-level normalization for the present `X_0=H, X_1=D(A)` scale. The source-scale quantity sees `A^{1/2}B`, equivalently the relative conjugation (3.2), which is precisely where the example amplifies.
