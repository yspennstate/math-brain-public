## 4. B18 — say the boundary in another language: finite-alternative escape integrability

Let `T` be a nonnegative a.s.-finite capacity with survival function

\[
\bar F(t)=P(T>t),\qquad t\ge0,
\]

and let

\[
M_h=\min(T_1,\ldots,T_h)
\]

for iid copies `T_i`. Then the layer-cake identity gives exactly

\[
E M_h=\int_0^\infty \bar F(t)^h\,dt.
\tag{4.1}
\]

More generally, for `p>0`,

\[
E M_h^p=p\int_0^\infty t^{p-1}\bar F(t)^h\,dt.
\tag{4.2}
\]

Thus P11's quantity

\[
r_*(G)=\inf\{h\ge1:E M_h<\infty\}
\]

is exactly a **finite-alternative escape-integrability index**: it asks how many independent alternatives are required before their best capacity has finite mean.

This language has a classical path-FPP ancestor. Classical FPP uses a minimum of finitely many incident edge weights in its moment hypotheses: modern statements of the Kesten/Cox--Durrett shape theory use `E min(t_1,...,t_{2d})<infinity` for the local escape obstruction, with stronger minimum-moment forms appearing in uniform/full-shape formulations. That is not a maximal-flow theorem and does not subsume 07R; the surface distinction is that an anchored local cut can manufacture as many independent shell alternatives as a fixed deterministic slab height permits.

## 5. B13 — exact monotone tail functional

The preceding integral formulation suggests a simpler quantity that detects exactly whether `r_*` is finite.

For each integer `h>=1`, define the **tail escape amplitude**

\[
A_h(G)=\sup_{t\ge1} t\,\bar F(t)^h\in[0,\infty].
\tag{5.1}
\]

### Claim `P11-I0062-TAIL-ESCAPE-EQUIVALENCE-09` — PROVED / STRUCTURAL, NO METRIC MOVEMENT

For every nonnegative a.s.-finite capacity law:

1. if `E M_h<infinity`, then
   \[
   t\bar F(t)^h\to0;
   \tag{5.2}
   \]
   in particular `A_h(G)<infinity`;
2. if `A_h(G)<infinity` for some `h`, then `E M_m<infinity` for every integer `m>h`;
3. consequently
   \[
   \boxed{
   r_*(G)<\infty
   \iff
   A_h(G)<\infty\text{ for some finite }h,
   }
   \tag{5.3}
   \]
   and equivalently
   \[
   \boxed{
   r_*(G)=\infty
   \iff
   A_h(G)=\infty\text{ for every finite }h.
   }
   \tag{5.4}
   \]

#### Proof

Assume `E M_h<infinity`. Since `bar F` is nonincreasing,

\[
\int_{t/2}^{t}\bar F(u)^h\,du
\ge \frac t2\bar F(t)^h.
\]

The left side tends to zero as `t->infinity` because `bar F^h` is integrable. Hence (5.2) follows.

Conversely suppose `A_h(G)=C<infinity`. For `t>=1`,

\[
\bar F(t)^h\le C/t.
\]

For any integer `m>h`,

\[
\bar F(t)^m
=\bigl(\bar F(t)^h\bigr)^{m/h}
\le C^{m/h}t^{-m/h}.
\]

Because `m/h>1`, the last function is integrable on `[1,infinity)`, while `bar F^m<=1` on `[0,1]`. Thus (4.1) gives `E M_m<infinity`.

If `r_*<infinity`, part 1 gives a finite amplitude at `h=r_*`. If some amplitude is finite, part 2 gives finite `r_*`. Negating this equivalence gives (5.4). QED.

### Monotonicity

If `G_1` is stochastically lighter than `G_2`, i.e.

\[
\bar F_1(t)\le\bar F_2(t)\quad\forall t,
\]

then

\[
A_h(G_1)\le A_h(G_2)\quad\forall h
\]

and therefore `r_*(G_1)<=r_*(G_2)`. This is the monotone quantity sought in B13: heavier tails can only make the finite-alternative escape index worse.

## 6. A simpler universal proof of the retained `r_*=infinity` obstruction

Claim09 turns the earlier obstruction into a one-line threshold selection plus the same independent-column concentration used by the source counterexamples. This is a **proof simplification of retained claim05**, not a new source verdict.

Assume `r_*(G)=infinity`. By (5.4), for every integer `r>=1`,

\[
\sup_{a\ge1} a\bar F(a)^r=\infty.
\]

Choose `a_r` so that

\[
a_r\bar F(a_r)^r\ge4r.
\tag{6.1}
\]

Write

\[
p_r=\bar F(a_r)^r>0.
\]

Choose integers `N_r` recursively increasing so fast that

\[
N_r\ge e^{r^2},
\qquad
(N_r+1)^2p_r\ge2^r.
\tag{6.2}
\]

Define the deterministic height function

\[
m(k,l)=\max\{1,\max\{r:N_r\le\min(k,l)\}\}.
\tag{6.3}
\]

Then `m(N_r,N_r)=r`, `m(k,l)->infinity`, and (6.2) implies

\[
m(k,l)\le\sqrt{\log \min(k,l)}
\]

up to the harmless integer endpoint convention. In particular, after ordering the horizontal sides as in Kesten's statement, for `delta=1/2`,

\[
k^{-1/2}\log m(k,l)\to0.
\tag{6.4}
\]

So (6.3) lies safely inside the corrected Kesten height regime.

In the box with base `N_r x N_r` and height `r`, there are `(N_r+1)^2` pairwise edge-disjoint vertical columns. Call a column high when all of its `r` vertical edges exceed `a_r`. The high-column indicators are independent Bernoulli variables with success probability `p_r`. If `Y_r` is their number and

\[
\mu_r=E Y_r=(N_r+1)^2p_r,
\]

then by (6.2), `mu_r>=2^r`, and Chebyshev gives

\[
P(Y_r<\mu_r/2)\le4/\mu_r\le4/2^r.
\tag{6.5}
\]

The error probabilities are summable. Borel--Cantelli therefore gives `Y_r>=mu_r/2` eventually almost surely. Sending `a_r` units up every high edge-disjoint column gives an admissible flow; equivalently, every cut must intersect every such column in a distinct edge of capacity at least `a_r`. Therefore eventually almost surely,

\[
\frac{\Phi_r}{N_r^2}
\ge
\frac{a_rY_r}{N_r^2}
\ge
\frac{a_r\mu_r}{2N_r^2}
\ge
\frac{a_rp_r}{2}
\ge2r.
\tag{6.6}
\]

Hence

\[
\limsup_{r\to\infty}\frac{\Phi_r}{N_r^2}=+\infty
\quad\text{a.s.}
\tag{6.7}
\]

This gives a direct high-column proof of the universal-sequence obstruction whenever `r_*=infinity`. In particular, when the source positivity assumption `F(0)<p^*` is also imposed, such a law cannot satisfy a universal corrected-Kesten finite limit theorem with no replacement tail hypothesis.

## 7. B6 — deform across the boundary explicitly

Consider the two-parameter continuous-tail family

\[
\bar F_{\alpha,\beta}(t)
=(1+t)^{-\alpha}[\log(e+t)]^{-\beta},
\qquad \alpha,\beta\ge0,
\tag{7.1}
\]

excluding the degenerate pair `(alpha,beta)=(0,0)`. It is a valid decreasing survival function with `F(0)=0` and finite values a.s.

For every integer `h>=1`, (4.1) and the integral test give

\[
E M_h<\infty
\iff
\alpha h>1
\quad\text{or}\quad
\bigl(\alpha h=1\text{ and }\beta h>1\bigr).
\tag{7.2}
\]

Thus:

- if `alpha=0` and `beta>0`, then `r_*=infinity` for every such pure-log tail;
- if `alpha>0`, then `r_*<infinity`, with the endpoint decided exactly by (7.2).

The previous continuous source witness `bar F(t)=1/log(e+t)` is the case `(alpha,beta)=(0,1)`.

The same family displays the high-column mechanism directly. At fixed height `h`, threshold `a` contributes the scale

\[
a\bar F_{\alpha,\beta}(a)^h
\asymp
a^{1-\alpha h}(\log a)^{-\beta h}.
\tag{7.3}
\]

For `alpha=0`, (7.3) tends to infinity for every finite `h`, exactly matching (5.4). For `alpha>0` and any `h>1/alpha`, (7.3) tends to zero. More generally, part 1 of Claim09 shows that once some finite `h` has `E M_h<infinity`, the threshold-column contribution must vanish:

\[
a\bar F(a)^h\to0.
\tag{7.4}
\]
