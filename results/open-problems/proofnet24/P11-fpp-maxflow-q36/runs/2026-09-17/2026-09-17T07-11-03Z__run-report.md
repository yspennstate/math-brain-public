## 5. Repair idea: use *more* disjoint shells to manufacture `L^p`, `p>1`

The previous shell lemma used exactly `r=r_*(G)` disjoint shells and extracted only an integrable minimum. That was unnecessarily weak.

Let

\[
f(t)=\Pr(T>t).
\]

Since `r=r_*(G)<infinity`,

\[
I_r:=\int_0^\infty f(t)^r\,dt
=E\min(T_1,\ldots,T_r)<\infty.
\tag{5.1}
\]

Because `f` is nonincreasing, for every `u>0`,

\[
\frac u2 f(u)^r
\le \int_{u/2}^{u}f(v)^r\,dv
\le I_r,
\]

hence

\[
\boxed{f(u)^r\le\frac{2I_r}{u}.}
\tag{5.2}
\]

Now fix a finite source base `A`, choose any integer `q>r`, and choose `q` pairwise edge-disjoint graph-distance boundary shells around `V(A)` at fixed radii below a sufficiently large deterministic height `H`. Let `S_1,\ldots,S_q` be their capacities and

\[
Z_{A,q}=\min_{1\le j\le q}S_j.
\]

If shell `j` has at most `N` edges, then

\[
\Pr(S_j>t)\le N\,f(t/N),
\]

and disjointness plus iid capacities gives

\[
\Pr(Z_{A,q}>t)
\le N^q f(t/N)^q.
\tag{5.3}
\]

Using (5.2), for large `t`,

\[
f(t/N)^q
=\bigl(f(t/N)^r\bigr)^{q/r}
\le C_{A,q}\,t^{-q/r}.
\tag{5.4}
\]

Therefore for every exponent

\[
1<p<q/r,
\]

we have

\[
\begin{aligned}
E Z_{A,q}^p
&=p\int_0^\infty t^{p-1}\Pr(Z_{A,q}>t)\,dt\\
&<\infty,
\end{aligned}
\tag{5.5}
\]

because the large-`t` integrand is `O(t^{p-1-q/r})` and `p<q/r`.

Taking

\[
q=2r,\qquad p=3/2,
\]

we obtain a universal convenient exponent. Once `H` exceeds a deterministic shell depth `H_0(r,A)`, every shell is a valid source-to-top cut and therefore

\[
\boxed{
\Psi_H(A)\le Z_{A,2r},
\qquad
E\Psi_H(A)^{3/2}<\infty.
}
\tag{5.6}
\]

For each fixed block `pA_0`, the constant in (5.6) can depend on `p`, which is harmless: the rectangular ergodic theorem below is applied one fixed block size at a time. The exponent `3/2` is uniform.

This is the missing ingredient no earlier route contained. The finite-`r_*` criterion does not imply raw `L log L`; instead, the geometry provides arbitrarily many independent *surface alternatives*, and their minimum upgrades the optimized cut itself into `L^p`, `p>1`.
