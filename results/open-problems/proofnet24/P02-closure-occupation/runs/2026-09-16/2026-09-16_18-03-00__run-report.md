# 5. New exact falsification: unsigned Wick matching fails

## `P02-OCC-D4-UNSIGNED-WICK-MATCHING-NOGO = DISPROVED AS A METHOD CLAIM`

C3's compiler is a **signed** perfect-matching expansion because it is a determinant. The most literal Wick-style strengthening would erase the permutation sign and sum the same matching monomials as a permanent.

That stronger claim is false even for a four-state reversible chain.

Take

\[
P=
\begin{pmatrix}
1/2&1/2&0&0\\
1/2&0&1/2&0\\
0&1/2&0&1/2\\
0&0&1/2&1/2
\end{pmatrix}.
\tag{5.1}
\]

This matrix is symmetric, irreducible, and aperiodic, so

\[
\pi=(1/4,1/4,1/4,1/4).
\]

The exact fundamental matrix in the C3 normalization is

\[
Z=
\begin{pmatrix}
7/4&1/4&-3/4&-5/4\\
1/4&3/4&-1/4&-3/4\\
-3/4&-1/4&3/4&1/4\\
-5/4&-3/4&1/4&7/4
\end{pmatrix}.
\tag{5.2}
\]

Use the exact four-mark source example with

\[
i=0,\qquad j=1,\qquad A=\{k,l\}=\{2,3\}.
\]

The C3 denominator and numerator are

\[
D=
\begin{pmatrix}
Z_{22}&Z_{32}&-\pi_2\\
Z_{23}&Z_{33}&-\pi_3\\
1&1&0
\end{pmatrix},
\tag{5.3}
\]

\[
N=
\begin{pmatrix}
Z_{22}&Z_{32}&-\pi_2&Z_{02}\\
Z_{23}&Z_{33}&-\pi_3&Z_{03}\\
1&1&0&1\\
Z_{21}&Z_{31}&-\pi_1&Z_{01}
\end{pmatrix}.
\tag{5.4}
\]

Exact Gaussian elimination gives

\[
\det D=\frac12,
\qquad
\det N=1,
\qquad
\frac{\det N}{\det D}=2.
\tag{5.5}
\]

Now compute the occupation directly. Before hitting `{2,3}`, the transient submatrix on `{0,1}` is

\[
Q=
\begin{pmatrix}
1/2&1/2\\
1/2&0
\end{pmatrix},
\]

so

\[
(I-Q)^{-1}
=
\begin{pmatrix}
4&2\\
2&2
\end{pmatrix}.
\]

Therefore

\[
E_0(\#\text{ visits to }1\text{ before }T_{\{2,3\}})=2,
\tag{5.6}
\]

exactly matching the signed determinant formula.

But erasing permutation signs gives the permanents

\[
\operatorname{per}D=-\frac34,
\qquad
\operatorname{per}N=-\frac1{32},
\]

hence

\[
\boxed{
\frac{\operatorname{per}N}{\operatorname{per}D}=\frac1{24}\ne2.
}
\tag{5.7}
\]

So the same C3 auxiliary matching graph **cannot** be made into a literal unsigned Wick sum merely by forgetting determinant parity.

There is also a structural reason simple vertex/edge sign gauges cannot fix this. Multiplying each row `r` and each column `c` of an `m x m` matrix by fixed signs changes every permutation monomial by the same common factor

\[
\Bigl(\prod_r\epsilon_r\Bigr)
\Bigl(\prod_c\eta_c\Bigr),
\]

independent of the permutation. Hence row/column gauge choices do not alter *relative* permutation parity. For `m>=2`, determinant signs cannot be globally converted into permanent signs by such a gauge.

### What D4 does and does not show

D4 does **not** refute Aldous--Fill's open problem. The source never says the desired diagram rule must be unsigned. It shows only that one particularly literal Wick analogy fails for the current C3 graph.

The useful conclusion is narrower:

\[
\boxed{
\text{any source-faithful completion of C3 must retain orientation/sign data,
 or use a genuinely different combinatorial representation.}
}
\tag{5.8}
\]

This is a real falsification, not a renamed known formula.
