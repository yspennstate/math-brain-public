## 6. Move #7 — take the convergent-scale limit: exact phase-zero block identity

Put

`F(t)=1_[0,1/2)(t)-1_[1/2,1)(t)`

and write its cocycle

`F_N(x)=sum_{r=0}^{N-1} F(x+r theta)`.

Let `p_k/q_k` be the continued-fraction convergents and

`Delta_k=q_k theta-p_k`.

Because `q_0=1`, `q_1=a_1` is odd, and

`q_{k+1}=a_{k+1}q_k+q_{k-1}`

with every later `a_{k+1}` even, induction gives

`q_k` odd for every `k`.

### Lemma 6.1 (exact source-phase block identity)

For all sufficiently large `k`, and every integer

`1 <= m <= a_{k+1}/4`, 

one has

`F_{m q_k}(0)=1+(m-1) s_k`,

where

`s_k=sgn(Delta_k) in {+1,-1}`.

In particular, for integers `a,a' >=1` in that range,

`F_{a q_k}(0)-F_{a' q_k}(0)=s_k(a-a')`.

### Proof

Fix `q=q_k`, `p=p_k`, `Delta=Delta_k`. Continued fractions give

`|Delta|=||q theta|| <= 1/q_{k+1}`,

and

`q_{k+1}=a_{k+1}q+q_{k-1} > a_{k+1}q`.

Split the first `m q` orbit points into blocks `j q+r`, with

`0<=j<m`, `0<=r<q`.

For `1<=r<q`, compare `(j q+r)theta` with the rational grid point `r p/q`. Modulo one,

`(j q+r)theta - r p/q = (j+r/q)Delta`.

Hence

`|(j+r/q)Delta| < m/q_{k+1} <= 1/(4q)`.

Because `q` is odd, every nonzero rational grid point `r p/q mod 1` is at distance at least `1/(2q)` from the discontinuity set `{0,1/2}`: multiplication by `p` permutes the nonzero residues modulo `q`, and no odd-denominator grid point equals `1/2`. Therefore the perturbation above cannot cross either discontinuity. Thus for every fixed block `j`, the `q-1` terms with `r!=0` have exactly the same signs as the nonzero rational grid.

Among the residues `1,...,q-1`, exactly `(q-1)/2` lie in `(0,1/2)` and `(q-1)/2` in `(1/2,1)`. Their `F`-sum is therefore zero.

It remains only the `r=0` term. For `j=0`, it is `F(0)=+1`. For `j>=1`,

`j q theta = j Delta (mod 1)`

and

`j|Delta|<m/q_{k+1}<1/2`.

Hence this term is `+1` if `Delta>0` and `-1` if `Delta<0`, namely `s_k`.

The first block therefore sums to `1`, every later block sums to `s_k`, and

`F_{m q}(0)=1+(m-1)s_k`.

Subtracting two such identities with `a,a'>=1` gives the last formula. QED.

### Why this is the right replacement for Brémont's a.e.-phase event

Brémont's Borel–Cantelli good event forces exact linearity

`F_{m q_k}(x)=m F_{q_k}(x)`.

At `x=0`, that exact formula can fail when `s_k=-1`; indeed the source point lies on a discontinuity. The phase-zero identity above is different but just as useful: **differences** of block cocycles are exactly linear in the block number once both block numbers are positive. Brémont's dispersion argument only needs such differences.

This is Move #20's answer to “why the old algorithm fails”: the source phase is a boundary point, so the a.e. good-block event is the wrong invariant. The correct object is the difference identity after peeling off the first boundary block.

## 7. Move #30 — one arithmetic scale at a time: deterministic dispersion lower bound

`N_k=a_1+...+a_k`.

`1000 N_k <= m_k <= a_{k+1}/4`.

for every phase `x` (the total variation of the square wave is 2 in Brémont's convention).

`ell=a q_k+b`, `ell'=a' q_k+b'`

with

`m/2 < a < m`, `1 <= a' < m/4`, `0<=b,b'<q_k`,

where

`100 N_k <= m <= m_k`.

`F_ell(0)-F_ell'(0)
 = s_k(a-a') + F_b(a q_k theta)-F_b'(a' q_k theta)`.

Therefore

`|F_ell(0)-F_ell'(0)| >= |a-a'|-4N_k >= m/5`

for large `k`.

Brémont's positive-side dispersion is

`phi_+^2(n)=n^2 + sum_{-n<=r<s<=n, rs>=0} (G_s-G_r)^2`,

## 8. Full transience summation

Brémont Corollary 3.7(3) says that it suffices to prove

`sum_{n>=1} 1/phi_+(n) < infinity`.                                (8.1)

Since `phi_+` is increasing, for all large `K`, group integers by convergent scales:

`sum_{n>=K} 1/phi_+(n)
 <= sum_{k>=K} sum_{1<=m<=a_{k+1}} q_k/phi_+(m q_k)`.

Split the inner sum into

`U_k : 1<=m<=100N_k`,
`V_k : 100N_k<m<=m_k`,
`W_k : m_k<m<=a_{k+1}`.

### 8.1 Middle range `V_k`

From (7.1),

`V_k <= C sum_{m>100N_k} 1/m^2 <= C/N_k <= C/a_k`.

Because `a_k` grows at least geometrically (indeed much faster),

`sum_k V_k < infinity`.

### 8.2 Large range `W_k`

Brémont Lemma 3.8 gives the scale comparison

`phi_+(m q_k) >= c sqrt(m/m_k) phi_+(m_k q_k)`

for `m>=m_k` in the relevant range. Applying (7.1) at `m_k`,

`phi_+(m q_k) >= c sqrt(m/m_k) m_k^2 q_k
                = c sqrt(m) m_k^(3/2) q_k`.

Therefore

`W_k <= C sum_{m_k<m<=a_{k+1}} 1/(sqrt(m) m_k^(3/2))
     <= C sqrt(a_{k+1})/m_k^(3/2)
     <= C a_{k+1}^{1/2-3 beta/2}`.

Since `beta>2/3`, the exponent is negative; super-geometric growth makes

`sum_k W_k < infinity`.

### 8.3 Small range `U_k`

Use Lemma 3.8 to propagate the previous-scale middle-range estimate (7.1) from `m_{k-1}q_{k-1}` to `m q_k`. Brémont's deterministic comparison gives

`phi_+(m q_k)
 >= c sqrt( m q_k/(m_{k-1}q_{k-1}) ) phi_+(m_{k-1}q_{k-1})`.

By (7.1) at scale `k-1`,

`phi_+(m_{k-1}q_{k-1}) >= c m_{k-1}^2 q_{k-1}`.

Now

`m_{k-1}=a_k^beta`,
`q_k >= a_k q_{k-1}`,

so

`phi_+(m q_k) >= c sqrt(m) a_k^(3 beta/2 - 1/2) q_k`.

Consequently

`U_k <= C sum_{1<=m<=100N_k}
              1/(sqrt(m) a_k^(3 beta/2-1/2))
     <= C sqrt(N_k)/a_k^(3 beta/2-1/2)
     <= C a_k^(1-3 beta/2)`.

Again `beta>2/3`, so the exponent is negative and

`sum_k U_k < infinity`.

Combining the three ranges proves (8.1). Brémont Corollary 3.7(3) therefore gives transience of the exact source-phase walk. QED.
