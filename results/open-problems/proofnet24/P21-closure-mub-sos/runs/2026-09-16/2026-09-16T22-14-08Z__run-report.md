# 4. Move #15 first: why merely breaking the phase symmetry does not fix the parity obstruction

Write the convergents of

`alpha=[0;a_1,a_2,...]`

as `p_k/q_k` and set

`Delta_k=q_k alpha-p_k`.

The previous P21 proof assumed every `q_k` odd. The obvious next move is to perturb the phase away from the discontinuity at zero and hope the odd/even distinction disappears. It does not: even denominator blocks have a structural half-period cancellation.

## Lemma 4.1 (stable convergent blocks, both parities)

There is an absolute constant `c_*=1/64` such that, for every sufficiently large `k`, for every integer

`1 <= j <= floor(c_* a_{k+1})`,

and every `0<=r<q_k`, the sign vector

`F(j q_k alpha + r alpha)`

is independent of `j` after the two rational-grid boundary residues are treated explicitly. Its block sum is

`B_k = sgn(Delta_k)` if `q_k` is odd,

and

`B_k = 0` if `q_k` is even.

### Proof

Put `q=q_k`, `p=p_k`, `Delta=Delta_k`. Modulo one,

`(j q+r)alpha = r p/q + (j+r/q)Delta`.

Continued fractions give

`|Delta| < 1/q_{k+1}`

and

`q_{k+1}>a_{k+1}q`.

Thus, for `j<=a_{k+1}/64`,

`|(j+r/q)Delta| < (a_{k+1}/64+1)/q_{k+1} < 1/(16q)`

for all large `k`.

Every rational-grid residue that is not exactly in `{0,1/2}` is at distance at least `1/(2q)` from that discontinuity set. Hence none of those signs can change under the displayed perturbation.

If `q` is odd, the rational grid has exactly one boundary residue, `r=0`; the other `q-1` residues cancel in pairs under `t -> t+1/2` at the counting level, with `(q-1)/2` on each side of `1/2`. For `j>=1`, the boundary point is `j Delta`, whose sign under `F` is `sgn(Delta)`. Hence every later stable block has sum `B_k=sgn(Delta_k)`.

If `q` is even, coprimality forces `p` odd. There are exactly two boundary residues: `r=0`, mapping to `0`, and `r=q/2`, mapping to `1/2`. Their perturbed locations are

`j Delta`

and

`1/2 + (j+1/2)Delta`.

For `Delta>0` they contribute `+1` and `-1`; for `Delta<0` they contribute `-1` and `+1`. All nonboundary residues cancel in half-period pairs. Therefore the stable block sum is exactly `B_k=0`.

The same small-perturbation argument shows the full sign vector, not only its sum, is independent of the stable block index `j`. QED.

### Consequence for Move #15

The even-`q_k` loss of block drift is **not** an artifact of the singular source point `x=0`. It is the exact half-period antisymmetry

`F(t+1/2)=-F(t)`

on an even rational grid. A small generic phase perturbation still gives zero stable block sum. Therefore “break the phase symmetry” does not remove the obstruction. One must exploit **internal variation inside the zero-sum block**.

Outcome of Move #15: **the naive route fails, but the failure identifies the right stronger invariant — block-profile variance rather than block mean.**

# 5. Move #3: prove a stronger profile theorem instead of forcing nonzero drift

For a length-`q_k` sign block, let `H_k(r)` denote the running partial sum through the first `r` entries of that block. Define its standard deviation

`sigma_k^2 = (1/q_k) sum_{r=0}^{q_k-1} (H_k(r)-bar H_k)^2`.

The first source block and every later stable block can differ at at most the rational-grid boundary entries; the argument below is applied directly inside each relevant block, so no comparison assumption is needed.

The key point is that even when a `q_k`-block has total sum zero, it contains many lower-scale odd-denominator blocks whose cumulative profile has macroscopic spread.

## Lemma 5.1 (nested odd-denominator profile spread)

For all sufficiently large `k` there is an absolute `c>0` such that the running profile in every stable `q_k`-block, and also in the initial source `q_k`-block, satisfies

- if `q_{k-1}` is odd, `sigma_k >= c a_k`;
- if `q_{k-1}` is even, `sigma_k >= c a_{k-1}`.

In particular, if `q_k` is even then consecutive-denominator coprimality forces `q_{k-1}` odd, and hence

`sigma_k >= c a_k`.

### Proof, case 1: `Q=q_{k-1}` odd

Write

`q_k=a_k Q+q_{k-2}`.

Inside a `q_k` block, split the first

`L=floor(a_k/64)`

complete `Q`-subblocks after the first possible boundary subblock. For an orbit point in the `t`th such subblock,

`x + (tQ+r)alpha = r p_{k-1}/Q + x + (t+r/Q)Delta_{k-1}` modulo one,

where the starting offset `x` is either zero (initial source block) or a stable `j Delta_k`.

For the selected range, continued-fraction estimates give

`|x|+(L+1)|Delta_{k-1}| < 1/(16Q)`

for all sufficiently large `k`: use `|Delta_{k-1}|<1/q_k`, `q_k>a_k Q`, `|Delta_k|<1/q_{k+1}`, and the fixed `1/64` margin.

Because `Q` is odd, Lemma 4.1's rational-grid argument applies at this nested scale. From the second selected `Q`-subblock onward, all `Q`-subblock sign vectors are identical and each has total sum `+1` or `-1`. The possible tiny starting offset has the opposite-sign, smaller continued-fraction error folded into the first selected block and does not change the sign for `t>=1`, since consecutive convergent errors alternate sign and

`|Delta_k|<|Delta_{k-1}|`.

Consequently, on the product set

`1<=t<=L`, `0<=r<Q`,

the running prefix has the form

`C + t s + h(r)`,

with `s in {+1,-1}`.

Under the uniform measure on this product set,

`Var(C+t s+h(r)) = Var(t)+Var(h(r)) >= c L^2`.

The product set occupies a fixed positive proportion of the `q_k` positions because

`LQ/q_k >= c_0>0`

for all large `k`. For any subset, the sum of squared deviations from the global mean dominates the sum of squared deviations from the subset mean. Hence the full block variance is at least a fixed proportion of the displayed product variance. Therefore

`sigma_k >= c L >= c a_k`.

### Proof, case 2: `Q=q_{k-1}` even

Then `R=q_{k-2}` is odd, because consecutive denominators are coprime.

By Lemma 4.1 at denominator `Q`, every selected stable `Q`-subblock has total sum zero and the same sign vector. It remains to prove that this zero-sum vector has large *internal* spread.

Write

`Q=a_{k-1}R+q_{k-3}`

and split one such `Q`-block into

`L'=floor(a_{k-1}/64)`

complete `R`-subblocks after the first boundary subblock. The starting offset of the chosen `Q`-block has magnitude `O(1/q_k)`. Standard convergent inequalities give

`|Delta_{k-2}| > 1/(q_{k-1}+q_{k-2})`

and

`|Delta_{k-1}|+|Delta_k| = O(1/q_k) = o(|Delta_{k-2}|)`.

Also

`(L'+1)|Delta_{k-2}| < 1/(16R)`

for all large `k`, since `|Delta_{k-2}|<1/Q` and `Q>a_{k-1}R`.

Thus the odd-`R` rational-grid argument applies: the selected `R`-subblocks are identical and have total sum `+1` or `-1`. Exactly as in case 1, their product profile has variance at least `c (L')^2`. Therefore one stable `Q`-block has internal profile standard deviation at least

`c a_{k-1}`.

Now repeat that same zero-sum `Q`-profile across a fixed positive proportion of the `q_k` block. Because each `Q`-block has total sum zero, repetition does not shift the within-block profile. Summing the within-copy squared deviations gives

`sigma_k >= c a_{k-1}`.

This proves both cases. QED.

### Exact variance identity used above

No probabilistic approximation is hidden in the profile argument. For real numbers `z_1,...,z_N`,

`sum_{i<j} (z_i-z_j)^2 = N sum_i (z_i-bar z)^2`.

This identity is the bridge from an internal block standard deviation to Brémont's pairwise dispersion.

# 7. Main theorem — parity-free phase-zero transience criterion

## Theorem 7.1 (`P21-I0004-PHASEZERO-PARITYFREE-SUPERGROWTH-63`)

Let

`alpha=[0;a_1,a_2,...]`

be irrational, with convergent denominators `q_k`. Assume:

1. there are `delta>1` and `k_0` such that

   `a_{k+1} >= a_k^delta`

   for every `k>=k_0`;

2. the even-denominator scales satisfy

   `sum_{k: q_k even} log(2+a_{k+1})/a_k < infinity`.       (7.1)

Then the exact Bou-Rabee–Peres phase-zero deterministic orientation walk is transient.

No parity condition is imposed on the partial quotients or on the denominator sequence.

### Proof

Brémont Corollary 3.7(3), specialized to the source square-wave environment, says it suffices to prove

`sum_{n>=1} 1/phi_+(n) < infinity`.                         (7.2)

As in Brémont's Proposition 3.3 proof and the preceding P21 run, monotonicity of `phi_+` and the convergent-scale partition reduce (up to absolute endpoint constants) to

`sum_k sum_{1<=m<=a_{k+1}} q_k/phi_+(m q_k)`.              (7.3)

We estimate each scale according to the parity of `q_k`.

### 7.1 Even `q_k`

For `1<=m<=M_k=floor(a_{k+1}/64)`, (6.1), including the separately absorbed `m=1,2` cases, gives

`q_k/phi_+(m q_k) <= C/(m a_k)`.

Hence the stable part contributes at most

`C log(2+a_{k+1})/a_k`.                                   (7.4)

For `m>=M_k`, Brémont Lemma 3.8 gives the deterministic scale comparison

`phi_+(m q_k)
 >= c sqrt(m/M_k) phi_+(M_k q_k)`.

Using (6.1) at `M_k`,

`phi_+(m q_k)
 >= c q_k a_k sqrt(m M_k)`.

Therefore the remaining constant-factor tail `M_k<m<=a_{k+1}` is bounded by

`C/(a_k sqrt(M_k)) sum_{m=M_k}^{a_{k+1}} m^(-1/2)
 <= C/a_k`.                                                (7.5)

The sum of (7.4) over even-denominator scales converges by hypothesis (7.1); the additional `sum 1/a_k` converges because the super-power recursion forces `a_k` to grow faster than geometrically.

### 7.2 Odd `q_k`

For the stable range, (6.2) yields

`q_k/phi_+(m q_k)
 <= C/[m sqrt(m^2+a_{k-1}^2)]`.

The elementary split at `m=a_{k-1}` gives

`sum_{m<=M_k} 1/[m sqrt(m^2+a_{k-1}^2)]
 <= C log(e+a_{k-1})/a_{k-1}.`                             (7.6)

At `m=M_k`, the drift term alone in (6.2) gives

`phi_+(M_k q_k)>=c M_k^2 q_k`.

Lemma 3.8 therefore bounds the tail by

`C sqrt(a_{k+1})/M_k^(3/2) <= C/a_{k+1}`.                 (7.7)

Under `a_{k+1}>=a_k^delta` with `delta>1`, both

`sum_k log(e+a_{k-1})/a_{k-1}`

and

`sum_k 1/a_{k+1}`

converge. Indeed, after some index `a_k>1`, iterating the logarithmic inequality

`log a_{k+1} >= delta log a_k`

makes `a_k` at least doubly exponential in `k` on the logarithmic scale.

Combining the even and odd scale estimates proves (7.3), hence (7.2). Brémont Corollary 3.7(3) gives transience of the exact source-phase walk. QED.

# 8. What is still missing

The full Bou-Rabee–Peres problem is **not** closed.

The remaining difficult regime is visible directly in (7.1): at even-denominator scales, the stable block has exactly zero drift, so the present argument obtains only

`phi_+(m q_k) >= c m q_k a_k`.

If `a_{k+1}` is astronomically larger than `a_k`, the harmonic accumulation

`log a_{k+1}/a_k`

need not be summable. Failure of that sufficient condition is **not** evidence of recurrence.

A proof covering all super-growing continued fractions would need one of the following genuinely new ingredients:

- a lower bound showing that an even-`q_k` block contains internal spread much larger than `a_k` when `a_{k+1}` is huge;
- a cross-block mechanism not captured by the repeated zero-sum profile;
- or a different recurrence/transience criterion that can exploit cancellation between scales rather than summing `1/phi_+` absolutely.

The simplest still-unproved special case is therefore a deliberately sparse parity-obstructed sequence with even `q_k` infinitely often and super-exponential jumps so large that

`sum_{k:q_k even} log(2+a_{k+1})/a_k = infinity`.

The nearest solved problem in the literature remains Brémont's 2021 Proposition 3.3. Its proof has nonzero convergent-block drift on all large scales because its parity hypotheses force every `q_k` odd; that is exactly what the difficult even scales lack.
