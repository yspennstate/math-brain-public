# BP's minimum-rate recursion uses true count suprema

The minimum-rate recurrence is valid even when a computed upper table is not monotone. The monotonicity needed in its proof belongs to the true residual means.

Fix n,d, with d≥2. Let c=(c0,…,c_(n−1)) have a positive prefix followed by zeros, c0≥1. Define T(c) as the supremum expected unidirectional hitting time of slab n over all finite initially infected sets C_k in slab k with |C_k|=c_k. This supremum includes disconnected sets. Each mean is finite and bounded by n: use one initially infected vertex in slab0 and its n-edge straight path, adding independent dummy clocks where vertices are already infected.

Whenever c+e_k is a valid positive-prefix state, T(c+e_k)≤T(c). Indeed remove one infected vertex in slab k from any configuration of counts c+e_k. It leaves a valid finite configuration of counts c. Couple the infections by the same edge clocks. Infection from the larger initial set hits the target no later. Taking suprema preserves the inequality. No assertion about approximate table entries appears here.

Write V_k=T(c+e_k) for a permitted increment, and let l_k be the isoperimetric lower rate from C002. An impossible increment has rate0 and contributes0. The target killing rate is b=c_(n−1). For any fixed geometric initial configuration C, exponential memorylessness and the first-event decomposition give

    (b+sum r_k(C)) E_C[τ] ≤ 1+sum r_k(C) V_k.

All rates are integers between0 and 2(d−1)c_k+c_(k−1), with c_(-1)=0. Thus only finitely many rate tuples occur. Choose configurations whose means approach the finite supremum T(c). An infinite subsequence has a fixed rate tuple r. Passing to the limit gives

    (b+sum r_k) T(c) ≤ 1+sum r_k V_k.

Since V_k≤T(c) and r_k≥l_k,

    b T(c) ≤ 1+sum r_k(V_k−T(c))
            ≤ 1+sum l_k(V_k−T(c)).

Hence

    T(c) ≤ [1+sum l_k T(c+e_k)]/[b+sum l_k].

The denominator is positive because l0≥2(d−1)>0. This is BP equation(9) in two slabs and its Section3.3 extension; the appendix on printed pp10-11 uses the same count monotonicity. Allowing all finite configurations avoids an unnecessary claim that there are finitely many geometric configurations or that a geometric supremum is attained.

If U(c+e_k)≥T(c+e_k), positivity of the coefficients gives

    [1+sum l_k U(c+e_k)]/[b+sum l_k] ≥ T(c).

Therefore finite backward induction can use the minimum-rate recurrence directly with genuine face upper bounds, and every upward arithmetic rounding preserves validity. The numerical U values need not be monotone. The box-max certificate C002 remains valid but is more conservative because it does not use the true supremum monotonicity.

Face bounds and outward arithmetic are exactly as in C002v2. At any later-coordinate face discard slab0 and use the previously certified tail model, a valid domination for arbitrary finite initial configurations. At the first-coordinate face use the minimum of disjoint straight Gamma paths or its rigorous rational upper enclosure. Backward induction is on the finite sum of remaining count increments to a box face. It supplies the complete truncation bound.

The key unpaid checks are independent review of the monotone initial-set coupling and the finite rate-tuple limit. Matching finite arithmetic does not replace these checks. Status: proof (unaudited). This verifies the published recursion; no novel recurrence is claimed.
