## Reconstruct the two imported manuscripts

From the repository root:

```bash
python publications/researchgate/assemble.py publications/researchgate/414266816-entropy-singularity
python publications/researchgate/assemble.py publications/researchgate/407239961-matrix-spencer
```

Each command verifies every part's Git blob SHA, the total byte count, the complete Git blob SHA and the complete SHA-256, then creates `main.tex` inside that manuscript folder. An existing different `main.tex` is never overwritten. Parts must be **concatenated in manifest order**, not separately included with LaTeX `\\input`, because a part may end inside an environment.
