## 1. One-coordinate bathtub equality and exact deficit

Let `h:R->[0,1]` be measurable and consider

`M(h)=sup { int f h : 0<=f<=1, int f=1 }`.

Choose a threshold `a` satisfying

`|{h>a}| <= 1 <= |{h>=a}|`

(with the usual extended interpretation in a flat part), and choose a measurable set `E` of measure one such that

`{h>a} subset E subset {h>=a}`.

Then for every admissible `f`,

```text
M(h)-int f h
 = int_E (1-f)(h-a)
   + int_{E^c} f(a-h).
```

Both terms are nonnegative.

### Proof

The bathtub principle gives `M(h)=int_E h`. Since `int 1_E=int f=1`,

`int (1_E-f)a=0`.

Therefore

`M(h)-int f h = int (1_E-f)(h-a)`.

Split over `E` and `E^c`. By the threshold choice, `h-a>=0` on `E` and `a-h>=0` on `E^c`, giving the displayed identity.

### Equality classification

Equality holds if and only if, modulo null sets,

```text
f=1 on {h>a},
f=0 on {h<a},
```

while any remaining mass may be placed arbitrarily with values in `[0,1]` on the tie set `{h=a}`. Thus the only non-indicator degeneracy is exactly a flat score level.

### Quantitative stability

For every `delta>0`, if

`Def_h(f)=M(h)-int f h`,

then

```text
int_{h>=a+delta} (1-f)
 + int_{h<=a-delta} f
 <= Def_h(f)/delta.
```

In particular, if the threshold is separated by a gap `delta` away from a null tie set, then

`||f-1_E||_1 <= 2 Def_h(f)/delta`.

No compactness or regularity of `h` is required.

## 2. Simultaneous stability for a near-extremizing product law

Let

`T(f_1,...,f_n)=int K(x) prod_i f_i(x_i) dx`, `0<=K<=1`,

and let `M=sup T` over `0<=f_i<=1`, `int f_i=1`.

Suppose a product tuple satisfies `T(f_1,...,f_n)>=M-epsilon`. For each coordinate `i`, freeze all other factors and define the exact section score

`h_i(t)=int K(x_1,...,t,...,x_n) prod_{j!=i} f_j(x_j) dx_{-i}`.

Let `M_i=sup_{0<=g<=1,int g=1} int g h_i`. Since replacing only coordinate `i` is an admissible global competitor,

`M_i<=M`,

and hence

`0<=M_i-int f_i h_i <= epsilon`.

Applying the one-coordinate deficit identity gives, for every `delta>0`,

```text
int_{h_i>=a_i+delta}(1-f_i)
 + int_{h_i<=a_i-delta} f_i
 <= epsilon/delta
```

simultaneously for every coordinate `i`, where `a_i` is any bathtub threshold for `h_i`.

Thus every near-extremizing product law is forced to be close, outside thin score-tie regions, to a coordinatewise threshold product set. This is a source-weighted stability statement: the weight is the actual shell-section score generated by the other coordinates, not a surrogate norm.

## 3. Application to the quadratic shell problem

Take

`K(x)=1_{Q(x) in I}`.

The main report proves that the full bounded-density conjecture is equivalent to a dimension-free shell-volume inequality on products `E_1 x ... x E_n`, `|E_i|=1`. The stability theorem adds:

> If a bounded-density product law nearly maximizes the small-ball probability for a fixed `(Q,I)`, then in each physical coordinate it differs from a bathtub threshold set only where the exact conditional shell probability is close to its threshold.

Consequently a hypothetical near-counterexample cannot rely on a diffuse fractional density except on genuine score-tie plateaus. This makes finite-union indicator models not merely dense for the supremum, but structurally representative of all near-extremizers away from degenerate tie levels.
