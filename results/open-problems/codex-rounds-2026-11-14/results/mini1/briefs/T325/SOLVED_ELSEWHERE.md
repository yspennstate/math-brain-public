# Substantial restricted advances; full T325 not established

Checked 14 November 2026. These papers predate the supplied November 2026 status, but were missing from its account of training beyond one layer. This file triggers the requested stop on finding substantial advances; its filename does not mean the full problem is solved.

1. Khashayar Gatmiry, Nikunj Saunshi, Sashank J. Reddi, Stefanie Jegelka, Sanjiv Kumar, *Can Looped Transformers Learn to Implement Multi-step Gradient Descent for In-context Learning?* ICML 2024, PMLR 235:15130–15152; [arXiv:2410.08292](https://arxiv.org/abs/2410.08292), [full text v1](https://arxiv.org/html/2410.08292v1), [proceedings](https://proceedings.mlr.press/v235/gatmiry24b.html).

   Theorem 3.3 states population gradient-flow convergence to small prediction loss for an L-loop linear transformer with a shared trainable block A, u=0, and identity population covariance. Its loss threshold vanishes as the prompt length grows with fixed dimension and depth. Theorem 3.2 characterizes global optimizers by a preconditioner approaching inverse population covariance. The implemented algorithm is multi-step preconditioned gradient descent. Other parameter blocks are prescribed; this does not establish convergence when all layer parameters are independently randomly initialized. Appendix A.1 supplies untied-layer recursions, not the missing general training theorem. The displayed time constant needs correction; see LOG.md.

2. Jianhao Huang, Zixuan Wang, Jason D. Lee, *Transformers Learn to Implement Multi-step Gradient Descent with Chain of Thought*, [arXiv:2502.21212](https://arxiv.org/abs/2502.21212), [full text v1](https://arxiv.org/html/2502.21212v1).

   Theorem 4.1 and its formal Appendix C version analyze population gradient flow for in-context weight prediction with supervised intermediate gradient-descent steps. Assumption 4.1 imposes sparse blocks, simultaneously diagonalizable symmetric initial matrices, eigenvalue sign restrictions, and a frozen scalar. Training learns autoregressive multi-step gradient descent. Appendix A.3 also gives an improved looped-model analysis, Theorem A.1, with bounded initial A and sample size at least order d L² log² d. Its displayed loss floor and the proof differ by a factor d; do not use the sharper floor without resolving that discrepancy. The CoT objective differs from the original final-query objective.

3. Yuxuan Cai, Yuan Cao, *Transformers with CoT Discover Heavy-Ball Acceleration Through Training*, [arXiv:2610.31089](https://arxiv.org/abs/2610.31089), [full text v2](https://arxiv.org/html/2610.31089v2), revised 31 October 2026.

   Theorem 3.3 proves convergence of two-stage population gradient flow: gradient-descent-teacher training, then trajectory supervision by true regression weights. Later CoT iterates approximate a time-varying Heavy-Ball method. Assumptions 3.1–3.2 require a prescribed sparse initialization, a frozen block, T of order (log d)^(1/4), proportional n and d with d/n ≤ 0.1, and a further dimension requirement depending on accuracy. The architecture uses linear attention. This is a recent training-and-algorithm identification result, but changes both the architecture and supervision relative to T325.

The status should acknowledge convergence results for restricted weight-shared linear models and supervised CoT models. The unrestricted multi-layer softmax or independently initialized untied-linear version was not resolved by the sources inspected. No proof of that claim of absence is possible from this bounded search, and none is intended.
