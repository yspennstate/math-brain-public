## New November item

Yan Ru Pei, *Closing the identification step in the GFF limit: Uniqueness of the zero-slope six-vertex phase for −1 ≤ Δ < 1/2*, November 2026, 33 pages. [Record, dated 11 November](https://hexagonmath.org/2611.00291v1); [paper](https://hexagonmath.org/pdf/2611.00291v1). Identifier **hexagon:2611.00291v1**, not an arXiv identifier; no arXiv identifier is supplied by this record.

Theorem 1.2 states uniqueness of the translation-ergodic zero-slope gradient Gibbs measure for 1 < c ≤ 2; Corollary 1.3 states uniqueness of the translation-invariant free-energy minimiser. Corollary 1.6 identifies the auxiliary near-balanced state with the balanced plane state for √2 ≤ c < 2, conditional on its existence (O1) and free-energy minimality (O2). The paper explicitly leaves the proofs of O1 and O2 unchecked (p. 28). These are reported results, not proofs audited here.

## Full-range claim requiring audit

OpenAI, *The Gaussian free field limit of the balanced six-vertex model with variance multiplier 1/arcsin(c/2)*, 23 September 2026, 93 pages. [Opened manuscript](https://mathcommunity.github.io/oai-math-revised/papers/The-Gaussian-free-field-limit-of-the-balanced-six-vertex-model-with-variance-multiplier-1-over-arcsin-c-over-2-September-23-2026/The-Gaussian-free-field-limit-of-the-balanced-six-vertex-model-with-variance-multiplier-1-over-arcsin-c-over-2-September-23-2026.pdf). The title page lists the author as OpenAI. No arXiv identifier is given there.

Theorem 1.1 claims GFF convergence for every 0 < c ≤ 2 for its prescribed iterated balanced-torus plane state, with unit height jumps and Green kernel −log|x−y|/(2π). It gives squared multiplier 2/arccos(Δ) = 1/arcsin(c/2). Proposition 4.3, pp. 36–38, contains the state-identification argument addressed by the November item. The full manuscript has not been checked here.
