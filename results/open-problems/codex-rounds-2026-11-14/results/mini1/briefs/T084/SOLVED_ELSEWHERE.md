# Substantial advance found; general problem remains open

Ying Cao and Houshan Fu, *Negative edge correlation in complete bipartite
graphs*, arXiv:2610.36749v1 [math.CO], submitted 27 October 2026.

- [arXiv record](https://arxiv.org/abs/2610.36749)
- [Paper PDF](https://arxiv.org/pdf/2610.36749)
- [Paper HTML](https://arxiv.org/html/2610.36749v1)

Theorem 1.1 proves strict pairwise negative correlation for the uniform
forest measure on every complete bipartite graph K_{m,n}, m,n >= 2.
Theorem 1.2 proves the same statement for the uniform measure on connected
spanning subgraphs of these graphs. Both cover every distinct edge pair,
including disjoint edges, with no asymptotic restriction on the part sizes.
These statements appear on page 2 of the PDF.

The forest definition on page 1 includes every acyclic edge subset,
including the empty subset; it does not require maximality or connectivity.
Thus it matches the forest measure in T084. When either part has size one,
both correlation differences are zero.

This is an additional infinite graph family omitted from the supplied
status, with a submission later than the September/early-October results
listed there. It triggers the instruction to stop on a substantial advance.
The filename follows that instruction; it does not mean that the
general-graph conjecture has been solved. Neither arbitrary edge weights,
the full q < 1 conjecture, nor negative association follows from the two
theorems stated above.

The abstract, HTML, and PDF theorem statements were cross-checked. This
session did not independently audit the entire proof.
