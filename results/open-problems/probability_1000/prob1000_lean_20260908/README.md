## The Lean files

Built against Lean 4.33.1 and Mathlib as pinned by `google-deepmind/formal-conjectures`
(the clone at `~/erdos_fc`, reached through the `formal-conjectures` symlink in
`erdos_problems_bench_2026_09_07`). To rebuild, copy the file into `Prob1000/` inside that
clone and run

    ~/.elan/bin/lake env lean Prob1000/P0208.lean

Each file ends in `#print axioms` calls; all report only `propext`, `Classical.choice`,
`Quot.sound`. No `sorry`, no `native_decide`, no `axiom`, no `unsafe`.

| file | problem | what is formalised |
|---|---|---|
| `P0208.lean` | Aldous-Fill Open Problem 7.27 | nine theorems: the harmonic equation for the hitting-time solution, the twin value, the maximum `floor(m^2/4)`, the cycle sum `6*S = m(m^2-1)`, tau0, and the two asymptotic identities |
| `P0340.lean` | Aldous-Janson Open Problem 14 | four theorems: height <= leaves - 1, the depth-shift identity, **drawn length <= total leaf depth** (the step that refutes the conjectured rate), and drawn = sum of internal heights + height |

What is deliberately NOT formalised, in both cases, is the probabilistic input - uniqueness
of the solution to `(I-P)h = 1`, the tensor eigenvalue computation, and Aldous-Janson's own
published Theorem 3. Those are standard or cited, and were checked numerically instead.

## The scripts

Plain Python, no arguments, each prints its own table.

| script | what it checks |
|---|---|
| `p0208_check.py` | exact hitting times, tau\*, tau0, tau2 on `C_m[K2-bar]` at m = 5,7,9,11,15,21 against the five claimed formulas |
| `arc_transitive.py` | arc-transitivity of `C_m[K2-bar]`: builds the subgroup generated by rotation, reflection and one fibre swap, checks its order is `2^m * 2m` and that the orbit of one arc is all `8m` arcs |
| `dtcs.py` | simulates DTCS(n) and measures drawn length / n against `log^4 n` |
| `clades.py` | clade-size counts against the paper's own `(n/m) a(n,m)`, and `E[h(T_m)]/log^2 m` |
| `p0193.py` | the four-root property for `nu = (delta_{1/10}+delta_{10})/2` at t from 5pi to 1e5, plus the uniform bounds over R |
| `ctl2.py` | both-sided control: Theorem 4.4 cases give at most 2 roots (positive control) |
| `p0189.py` | the clock/shift nilpotency `(U+V)^q = 0` and the operator norms |
| `p0266e.py` | the instrument test for the `x^2` capacity scaling of BES(4) small-ball hitting |

Two of these carry scars worth keeping. `ctl2.py` scans R on a grid and therefore
under-reports roots at large t, because the R that matters approaches pi; solve for R
instead. `p0266e.py` exists because an earlier version probed balls smaller than one
simulation step and produced a falling `P/x^2` that looked like a refutation of the
capacity scaling and was only the step size.
