## 1. Setup

A component with fibre A ⊆ {±1}^r (spanning; in-field K = ℝ or odd F_p), decomposed by a block tree T: each block B has private sign coordinates Q_B (the Q_B partition the r coordinates, Σ|Q_B| = r) and incoming boundary W_B, a tuple of sign forms that are functions of the private coordinates of B's ancestors. Per-block conditional defect L_B := |Q_B| − H(Q_B | W_B), entropies w.r.t. uniform measure on A. Each block's certificate produces a residual space R_B (spanned by its selector residuals) with the block's own quotient bound relative to a paid space R_<^B ⊆ span W_B.

## 2. Proposition T1 (paid-once filtration; proved)

Fix ANY linear order B_1, …, B_m of the blocks that respects the tree (ancestors before descendants). Define the filtration V_0 = 0, V_i = R_{B_1} + ⋯ + R_{B_i}, and give each block the arising paid space

  R_<^{B_i} := V_{i−1} ∩ span W_{B_i}.

Then:

(T1a) [rank telescoping, no absorption clause]
  dim(R_{B_1} + ⋯ + R_{B_m}) = Σ_i dim( (R_{B_i} + V_{i−1}) / V_{i−1} ) ≤ Σ_i dim( (R_{B_i} + R_<^{B_i}) / R_<^{B_i} ).

Proof. The equality is the dimension filtration. For the inequality: quotienting by the larger space V_{i−1} ⊇ R_<^{B_i} can only shrink the image of R_{B_i}; concretely, the surjection (R_{B_i}+R_<^{B_i})/R_<^{B_i} → (R_{B_i}+V_{i−1})/V_{i−1} induced by inclusion-then-quotient is well defined because R_<^{B_i} ⊆ V_{i−1}. ∎

Remark: (T1a) needs only R_<^{B_i} ⊆ V_{i−1}, which holds by construction. No condition of the form R_B ∩ span W_B ⊆ R_<^B is used anywhere. Every direction is counted exactly once, at the step that first generates it; a "boundary residual paid again at every descendant" cannot occur under this bookkeeping because a direction, once inside some V_i, is inside every later modulus.

(T1b) [defect telescoping — **hypothesis made explicit 06:2x by `telescope_self_referee.md`, and discharged there**: the proof needs the BLOCK-LEVEL "boundary-depends-on" relation to be ACYCLIC, so that some order makes every W_B measurable w.r.t. earlier privates. If two blocks each appeared in the other's boundary, no order would work and the chain-rule step would be unavailable. It discharges structurally: the dossier's blocks are strongly connected components, and the condensation of any digraph by its SCCs is a DAG — so a topological order always exists. **The packet's decomposition into SCCs is therefore not only a way of isolating the hard case; it is what licenses this chain rule at the tree level.**]  Σ_B L_B ≤ ℓ(A) = r − log₂|A|.

Proof. Order blocks ancestors-first. W_B is a function of ancestor privates, so σ(W_B) ⊆ σ(Q_{B_1}, …, Q_{B_{i−1}}), hence H(Q_{B_i} | W_{B_i}) ≥ H(Q_{B_i} | Q_{B_1}, …, Q_{B_{i−1}}). Summing and using the chain rule, Σ H(Q_{B_i}|W_{B_i}) ≥ H(Q_{B_1}, …, Q_{B_m}) = log₂|A|. So Σ L_B = r − Σ H(Q_{B_i}|W_{B_i}) ≤ r − log₂|A|. ∎

(T1c) [conditional aggregation] If every block admits a certificate with
  dim( (R_B + R_<^B) / R_<^B ) ≤ γ · L_B   for the ARISING R_<^B of (T1a)'s filtration,
then dim(Σ_B R_B) ≤ γ · ℓ(A). If additionally the composition step of §4 holds, d_cb(A) ≤ γ·ℓ(A) + (composition overhead). The coefficient γ may be a uniform sequence γ_n (per the transfer lane's W1, any γ_n = o(log n) suffices at the endpoint interface, source-checked against S1 tags (25)/(27a)).

## 3. What this changes about the two obstructions

(3a) The m=1 interval obstruction (S14 §7, eq (63)–(64): L_{Q|W} → 0 with one direction remaining; "no inequality dim((R+R_<)/R_<) ≤ C·L_{Q|W} can hold with an absolute C") is a statement UNIFORM IN R_< — its proof takes R_< = 0. Under (T1a)'s bookkeeping, a tiny block processed after its boundary directions have entered the filtration receives R_<^B large, and S14's own "exact absorbed alternative" (basis {A,B₀,B₁,B₂}, both edge forms to B₁ — p.199: zero new rank once the two boundary residuals are pre-paid) is precisely the certificate for that arising R_<. The obstruction therefore relocates: the question is whether the PROCESSING ORDER can always be chosen so that defect-poor blocks come late enough that their directions are already generated. This is a combinatorial question about the block tree (which directions does the union of earlier residuals contain?), not an entropy question.

(3b) The NAE-star obstruction (S9 §5: with R_< = 0 every basis/selector leaks ≥ 1 pure boundary direction, forced) similarly binds only early-processed stars. A star processed after siblings/ancestors have generated span{x_i+z_i}-type directions can have its leak absorbed by R_<^B. Whether the FIRST blocks of the order (which necessarily see small V_{i−1}) can always be chosen defect-rich is the same combinatorial question as (3a).

(3c) Consistency check against the packet (why they still needed absorption): the packet's target (41) demands a bound for EVERY R_< ⊆ span W (the theorem quantifies over the ancestor-paid space, because their recursion fixes the tree order top-down and the paid space handed to a child is whatever the ancestors happened to produce — not the full filtration including siblings and cousins). (T1a) says the aggregation is free to use the richer paid space V_{i−1} (all previously processed blocks, not only ancestors). The dossier's sentence "the same boundary direction can be charged at every descendant" is TRUE under ancestor-only bookkeeping and FALSE under filtration bookkeeping. I could not find, in the dossier's reproduced text, any obstacle to filtration bookkeeping at the rank-sum level; if the lost telescope file used ancestor-only R_<, T1 is a genuine strengthening of the aggregation step. ## 4. THE GAP: composition into a d_cb certificate

d_cb(A) requires ONE coordinate basis drawn from the full dual of A and selectors assigning EVERY full-dual form a signed basis representative, all residuals in ONE common space R (dossier p.7). T1 bounds dim(Σ_B R_B) where R_B are per-block residuals in per-block bases. The unproved glue:

(G1) The per-block bases (W_B, Q_B-selectors) must assemble into one global coordinate basis of the component. The packet's own machinery suggests this is the intended mechanism (boundary-only forms passed to the parent, p.8; the triangular witness exchange (28) shows basis surgery is available). REFINEMENT after reading S14 §8 (00:3x): the composable kind is the "boundary-containing selector basis" — S14's own phrase for the interval bases ("Cutting the cycle to an interval preserves an exact boundary-containing selector basis," p.199) — i.e. each block's basis contains its boundary forms, so assembly is: root boundary + the union of private parts, each block receiving its boundary from the parent's already-assembled portion. MEMBERSHIP in the full dual is then automatic for the two form types actually used: sign coordinates (±1-valued on all of A trivially) and exchanged witness forms Y_s (±1-valued on A by definition as constraint forms). The independence induction, written out (00:4x — G1 is now PROVED):

Setup: blocks B with private coordinate sets Q_B partitioning [r]; each block contributes |Q_B| basis forms P_B, each ±1-valued on A, of one of two kinds: (a) the coordinates of Q_B themselves, or (b) the (28)-exchanged family — witness forms h_s (triangular with nonzero diagonal on the block's pivot coordinates, by (28)'s proof) plus literal coordinates for non-pivots. In both kinds, each f ∈ P_B decomposes as f = h_f + g_f with supp h_f ⊆ Q_B, supp g_f ⊆ (ancestor privates), and the private parts {h_f : f ∈ P_B} form a basis of K^{Q_B} (kind (a): the standard basis; kind (b): block-triangular with nonzero diagonal after ordering pivots first).

Claim: F = ⋃_B P_B (|F| = Σ|Q_B| = r) is linearly independent over K, hence a coordinate basis of the component drawn from the full dual.

Proof. Suppose Σ_f λ_f f = 0 with some λ ≠ 0. Choose a block B* carrying a nonzero coefficient such that NO descendant of B* carries one (possible: the nonzero-coefficient blocks form a finite set in the tree order). Project the relation onto the coordinates Q_{B*}. Contributions: (i) forms of B* itself — their private parts h_f, supported exactly on Q_{B*}; (ii) forms of ancestors of B* — support ⊆ (own privates) ∪ (their ancestors' privates), and Q_{B*} is a DESCENDANT's private set, hence untouched: contribution zero; (iii) forms of blocks incomparable to B* — support ⊆ (own privates) ∪ (their ancestors' privates), and B* is not among their ancestors: contribution zero; (iv) descendants of B* — coefficient zero by choice of B*. So the projection reads Σ_{f ∈ P_{B*}} λ_f h_f = 0, forcing λ_f = 0 for all f ∈ P_{B*} by the per-block private-part basis property — contradiction. ∎

Full-dual membership: every form in F is ±1-valued on A (coordinates trivially; exchanged witnesses are constraint forms of A by definition), so F is a coordinate basis drawn from the full dual, exactly what d_cb's definition (p.7) requires. G1 is CLOSED. The live gap is G2 alone: assigning selectors to every remaining full-dual form, in particular the cross-block ones — the place where connector content must genuinely reappear.

(G2) Every full-dual form of A (not only the blocks' private forms) must receive a selector. RESOLUTION SHAPE (00:5x, from S14 §1 + connector consequence 1, extraction lines 11981–12100): on the solved family the full dual is D_n = {A, B_i, C_i = A+B_i+B_{i+1}}, and the packet's cuts are DESIGNED so cross-block forms localize — cutting the cycle turns the shared endpoint coordinates into boundary, so a cut-straddling C_i has one leg in W and lives inside a single block's (Q_B ∪ W_B), where that block's explicit certificate (interval theorem, eq (3): boundary-preserving basis, R_m ∩ span W = 0) already selects it. Connector consequence 1 states the benign-sharing condition: "whenever the only shared cycle coordinate is the homogenizing root (additional disjoint ancestor coordinates are harmless)."

So define: a block decomposition is **admissible** iff every full-dual form of the component is supported inside some single block's (Q_B ∪ W_B). Then:
- For admissible decompositions, G2 CLOSES: per-block certificates cover all full-dual forms, and G1's basis carries the selectors. The telescope (T1) + G1 + admissibility give the full conditional aggregation.
- For an IRREDUCIBLE core (no nontrivial admissible decomposition — which is what "singleton-layer strongly connected cyclic component" plausibly means operationally), G2 is VACUOUS: the component is one block and there are no cross-block forms. The difficulty is then entirely block-internal — the original Layer-II target, as it must be (no free lunch).

## 5.6 The amortized target (A), stated and verified on the cycle (01:1x)

**Target (A).** For the component's admissible block tree there exist a tree-respecting processing order, per-block basis/selector certificates, and a uniform γ (absolute, or γ_n = o(log n) per transfer-W1) with
  Σ_i dim( (R_{B_i} + R_<^i) / R_<^i ) ≤ γ · Σ_i L_{B_i},
with the ARISING paid spaces R_<^i = V_{i−1} ∩ span W_{B_i} of T1a. By T1a the left side dominates the assembled residual rank, by T1b Σ L_{B_i} ≤ ℓ, and with G1 + admissibility the assembly is a d_cb certificate: (A) ⟹ d_cb(A) ≤ γ·ℓ. This is the per-block statement that SURVIVES the §5.5 falsifier: it permits individual blocks over budget as long as the sum lands, and it permits coarsening.

**Exact verification on the rooted NAE n-cycle** (the solved family; all ingredients from S14):
Cut the cycle at k ≥ 1 pairwise non-adjacent vertices. Block tree: root block B₀ = {homogenizing root A} ∪ {the k cut vertices} — it owns NO constraint forms (cuts non-adjacent ⇒ no C_i lives on (A, cuts) alone), so its certificate is empty: rank cost 0, while its defect L₀ = (k+1) − H(A, cuts) ≥ 0 is BANKED. Children: k intervals with boundary (A, two cut vertices) ∈ ancestor privates ✓ and m_i interior privates, Σ m_i = n − k. Each uses S14's explicit certificate (eq (3)): cost ⌈(m_i+1)/3⌉ with R_m ∩ span W = 0 — so the arising-R_< quotients equal dim R_m regardless of processing order, and absorption is trivially satisfied (zero boundary intersection).
Totals: cost = Σ ⌈(m_i+1)/3⌉; at k = 1 this is ⌈n/3⌉ EXACTLY (one interval, m = n−1), matching the packet's optimal d_cb(A_n); general k gives ≤ n/3 + k. Defect side: Σ L ≤ ℓ(A_n) = n − log₂ L_n ≈ (1 − log₂ φ)n. Ratio → 1/(3(1−log₂φ)) ≈ 1.09 at k = o(n) — the packet's own asymptotic constant, now reproduced through the amortized bookkeeping. Per-block, each interval also satisfies its own C_int·L_interval bound (eq (4), m ≥ 2), so (A) holds here with γ = C_int ≈ 2.95 blockwise and ≈ 1.09 in aggregate.

**The mechanism exposed:** the root/spine block absorbs shared coordinates at zero rank cost while banking positive defect — coarsening converts the unit-block failure (§5.5) into spine-banked budget. On the open dense cores, (A) directs the search toward decompositions with defect-banking spines, not toward per-block uniformity.
