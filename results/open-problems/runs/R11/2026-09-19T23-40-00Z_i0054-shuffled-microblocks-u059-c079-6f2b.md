# 4. The general shuffled-microblock model

For each `N`, fix a deterministic partition of the ambient positions

\[
[N]=B_{N,1}\sqcup\cdots\sqcup B_{N,r_N},
\qquad |B_{N,a}|=s_{N,a},
\qquad \sum_a s_{N,a}=N.
\]

At harmonic-grid mark

\[
x_j=\frac jN,\qquad j=1,\dots,N-1,
\]

an active nonsingleton clade carries a proposal clock of rate

\[
\lambda_{N,j}
=\frac{N}{2j(N-j)}
=\frac{1}{2N x_j(1-x_j)}.
\tag{4.1}
\]

When this clock rings:

1. draw a fresh uniform permutation `sigma` of the ambient labels `[N]`;
2. independently for each deterministic microblock `B_{N,a}`, draw
   \[
   Z_a\sim\operatorname{Bernoulli}(x_j);
   \]
3. color ambient label `ell` by the color `Z_a` of the microblock containing the shuffled position `sigma^{-1}(ell)`;
4. if both colors occur among the labels of the active clade, split into the two color classes; otherwise nothing changes.

Every child clade receives fresh independent clocks, permutations and block colors. The total proposal intensity of a clade is finite and exactly

\[
\sum_{j=1}^{N-1}\lambda_{N,j}
=H_{N-1}.
\tag{4.2}
\]

Define the two-sample collision parameter

\[
\boxed{
\kappa_N
:=
\frac{\sum_a s_{N,a}(s_{N,a}-1)}{N(N-1)}.
}
\tag{4.3}
\]

This is exactly the probability that two distinct uniformly sampled ambient positions lie in the same microblock.

# 5. U059 — sharp shuffled-microblock CTCS criterion

## Theorem U059

For the shuffled-microblock harmonic-grid hierarchy above, the following are equivalent:

1. every fixed finite visible restriction has generator converging to the CTCS generator;
2. the two-label restriction converges to CTCS;
3. `kappa_N -> 0`.

Moreover, if a specified unordered split `A | A^c` of an `m`-label visible block has both sides nonempty, then

\[
\boxed{
\left|
q_N^{\rm micro}(A\mid A^c)
-q_N^{\rm iid}(A\mid A^c)
\right|
\le
\binom m2\kappa_N\frac{N-1}{N},
}
\tag{5.1}
\]

where `q_N^iid` is the iid harmonic-grid paintbox rate. For two visible labels there is the exact identity

\[
\boxed{
q_N^{\rm micro}(1\mid1)
=
\frac{N-1}{N}(1-\kappa_N).
}
\tag{5.2}
\]

If

\[
b_N:=\max_a s_{N,a},
\]

then

\[
\boxed{
\kappa_N\to0
\quad\Longleftrightarrow\quad
\frac{b_N}{N}\to0.
}
\tag{5.3}
\]

Thus the exact structural condition is that the largest deterministic dependence cell be `o(N)`.

## Proof

Fix an `m`-label visible block and expose the fresh uniform permutation. Let `C` be the event that at least two visible labels land in the same microblock.

For any fixed visible pair, the collision probability is exactly `kappa_N`; hence the union bound gives

\[
\mathbb P(C)
\le
\binom m2\kappa_N.
\tag{5.4}
\]

Conditional on `C^c`, all visible labels occupy different microblocks. Since the microblock colors are independent Bernoulli(`x`), the visible color vector is then **exactly** iid Bernoulli(`x`). Thus the microblock and iid split probabilities coincide on `C^c`.

Consider a specified nontrivial unordered split `A | A^c`. At a mark with bias `x`, any realization of this split requires at least one red and one blue color. In the microblock model, if `r_A,r_B>=1` are the numbers of distinct microblocks occupied by the two sides, its conditional split probability, when it is feasible, is

\[
x^{r_A}(1-x)^{r_B}
+(1-x)^{r_A}x^{r_B}
\le 2x(1-x).
\tag{5.5}
\]

The same bound holds for the iid split probability. Since the probabilities agree on `C^c`, their unconditional difference obeys

\[
|p_N^{\rm micro}(A\mid A^c;x)-p_N^{\rm iid}(A\mid A^c;x)|
\le
2x(1-x)\mathbb P(C)
\le
2x(1-x)\binom m2\kappa_N.
\tag{5.6}
\]

Now multiply by (4.1). The singular beta-grid factor cancels exactly:

\[
\lambda_{N,j}\,2x_j(1-x_j)=\frac1N.
\]

Summing over the `N-1` harmonic marks proves (5.1).

For the iid comparator, if `|A|=i`, `|A^c|=r` with `i+r=m`, then

\[
\begin{aligned}
q_N^{\rm iid}(i,r)
&=\sum_{j=1}^{N-1}\frac{1}{2N x_j(1-x_j)}
\left[x_j^i(1-x_j)^r+x_j^r(1-x_j)^i\right]\\
&=\frac1N\sum_{j=1}^{N-1}
 x_j^{i-1}(1-x_j)^{r-1},
\end{aligned}
\tag{5.7}
\]

where the second equality uses the symmetry `j <-> N-j`. This is a Riemann sum, so

\[
q_N^{\rm iid}(i,r)
\longrightarrow
\int_0^1x^{i-1}(1-x)^{r-1}\,dx
=
B(i,r)
=
\frac{(i-1)!(r-1)!}{(i+r-1)!},
\tag{5.8}
\]

which is exactly the CTCS rate of that specified unordered split. Hence `kappa_N -> 0`, together with (5.1), proves convergence of every fixed generator coordinate.

For two labels, a proposal separates them exactly when they land in different microblocks and those two blocks receive different colors. The shuffle collision probability is `kappa_N`, so at bias `x`

\[
P(\text{separate})=(1-\kappa_N)2x(1-x).
\]

After summing the clock rates,

\[
q_N^{\rm micro}(1\mid1)
=(1-\kappa_N)\sum_{j=1}^{N-1}\frac1N
=
\frac{N-1}{N}(1-\kappa_N),
\]

which is (5.2). The CTCS pair rate is `B(1,1)=1`, so pair convergence forces `kappa_N -> 0`. This proves necessity.

Finally put

\[
S_{2,N}=\sum_a s_{N,a}^2.
\]

Then

\[
b_N^2\le S_{2,N}\le b_NN,
\tag{5.9}
\]

while

\[
\kappa_N=\frac{S_{2,N}-N}{N(N-1)}.
\tag{5.10}
\]

If `b_N/N -> 0`, then

\[
0\le\kappa_N\le\frac{b_N-1}{N-1}\to0.
\]

Conversely, if `kappa_N -> 0`, then

\[
\frac{S_{2,N}}{N^2}
=
\frac1N+\kappa_N\frac{N-1}{N}	o0,
\]

and the left inequality in (5.9) forces `b_N/N -> 0`. This proves (5.3) and U059. `square`

## 6.1 Exact visible lumping

A hidden-only split may replace the full carrier clade by a child carrying the same visible block, but that child restarts the same independent clock/permutation/color mechanism. Thus hidden-only transitions remain inside a lump and do not change future visible hazards. The projection to `[k]` is therefore itself a finite-state CTMC with generator determined by the specified visible split rates above.
