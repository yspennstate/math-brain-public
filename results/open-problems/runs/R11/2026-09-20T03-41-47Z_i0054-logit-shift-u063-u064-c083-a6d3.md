\[
q_\theta(i,j)=B(i,j)-\Delta_\theta(i,j),

\left[(1-v)^{i-1}v^j+(1-v)^{j-1}v^i\right]dv.
\tag{4.1}

\[
R_{i,j}(\theta):=\frac{q_\theta(i,j)}{B(i,j)}.

# 5. U064 — translation invariance in log-odds coordinates

The CTCS paintbox/dislocation element on `x in (0,1)` is

\[
\frac{dx}{2x(1-x)}.
\tag{5.1}
\]

Put

\[
y=\log\frac{x}{1-x}.
\]

Then

\[
dy=\frac{dx}{x(1-x)},
\tag{5.2}
\]

so (5.1) becomes simply

\[
\frac12\,dy.
\tag{5.3}
\]

It is therefore invariant under every translation `y -> y + log c`, `c>0`. In the original coordinate this is the fractional-linear odds map

\[
\boxed{
T_c(x)=\frac{cx}{1-x+cx}
=\frac{cx}{1+(c-1)x}.
}
\tag{5.4}
\]

Writing `p=T_c(x)`, differentiation gives

\[
\frac{dp}{dx}=\frac{c}{(1+(c-1)x)^2},
\]

while

\[
p(1-p)=\frac{cx(1-x)}{(1+(c-1)x)^2}.
\]

Hence the exact invariant-measure identity is

\[
\boxed{
\frac{dp}{p(1-p)}=rac{dx}{x(1-x)}.
}
\tag{5.5}
\]

This identity is the whole continuum mechanism behind the new discrete model.

# 6. The discrete odds-shift hierarchy

Fix a constant `c>0`. For each `N>=2`, every active nonsingleton clade carries independent proposal clocks indexed by

\[
s=1,\ldots,N-1.
\]

Let

\[
x_s=\frac{s}{N},
\qquad
\lambda_{N,s}
=\frac{N}{2s(N-s)}
=\frac{1}{2N x_s(1-x_s)}.
\tag{6.1}
\]

At a ring of clock `s`, color each label of the active clade independently red with probability

\[
\boxed{
p_{N,s}=T_c(x_s)
=\frac{cs}{N-s+cs},
}
\tag{6.2}
\]

and blue otherwise. Split if both colors occur; otherwise the proposal is null. All colors and clocks for descendants are fresh and independent.

This is a finite discrete sampling rule. For integer `c`, one may say it without transformed coordinates: at mark `s`, each leaf samples independently with replacement from an urn containing `cs` red tokens and `N-s` blue tokens.

The raw proposal normalization is unchanged:

\[
\sum_{s=1}^{N-1}\lambda_{N,s}=H_{N-1}.
\tag{6.3}
\]

Because `0<p_{N,s}<1`, every specified nontrivial split has positive rate.

## 7. Exact finite split rate and continuum limit

Fix a specified unordered split `A|B` with

\[
|A|=i\ge1,
\qquad
|B|=j\ge1.
\]

At mark `s`, the two color orientations have total probability

\[
p_{N,s}^i(1-p_{N,s})^j
+p_{N,s}^j(1-p_{N,s})^i.
\]

Substituting (6.1)--(6.2) gives the exact finite rate

\[
\boxed{
q_{N,c}(i,j)
=\frac1N\sum_{s=1}^{N-1}F_{c;i,j}(s/N),
}
\tag{7.1}
\]

where

\[
F_{c;i,j}(x)
=
\frac{
 c^i x^{i-1}(1-x)^{j-1}
 +c^j x^{j-1}(1-x)^{i-1}
}{2(1+(c-1)x)^{i+j}}.
\tag{7.2}
\]

For fixed `c,i,j`, this function extends to a `C^1` function on `[0,1]`. Therefore the Riemann sum satisfies

\[
q_{N,c}(i,j)
=\int_0^1F_{c;i,j}(x)\,dx+O_{c,i,j}(N^{-1}).
\tag{7.3}
\]

Now set `p=T_c(x)`. Using (5.5),

\[
\begin{aligned}
\int_0^1F_{c;i,j}(x)\,dx
&=\frac12\int_0^1
\left[p^{i-1}(1-p)^{j-1}+p^{j-1}(1-p)^{i-1}\right]dp\\
&=B(i,j).
\end{aligned}
\tag{7.4}
\]

Thus

\[
\boxed{
q_{N,c}(i,j)=B(i,j)+O_{c,i,j}(N^{-1})
}
\tag{7.5}
\]

for every fixed specified split.

The important point is that `c` need **not** converge to `1`. A fixed finite distortion of every discrete split bias is completely absorbed by translation invariance of the limiting log-odds measure.

# 8. Complete path convergence, not a marginal limit

Fix `k` and a finite horizon `T`.

### 8.1 Hidden labels lump exactly

At every proposal, colors of the visible labels are iid Bernoulli with parameter `p_{N,s}` and do not depend on the hidden labels. If all visible labels in a carrier receive the same color but hidden labels create a genuine full-tree split, the visible labels simply move together into one descendant carrier. Descendant clocks and colors are fresh and have the same law. By exponential memorylessness, such hidden-only events do not change the future visible hazard law.

Therefore the restriction to `[k]` is itself a finite-state continuous-time Markov chain whose block-split rates are exactly (7.1).

### 8.2 Generator convergence

There are only finitely many partitions of `[k]`, and from any state only finitely many specified block splits. By (7.5), every corresponding generator entry differs from the CTCS generator by `O_{k,c}(1/N)`. Hence for the generator matrices `Q_{N,c}^{[k]}` and `Q_{CTCS}^{[k]}`,

\[
\max_\pi
\sum_{\pi'\ne\pi}
\left|
Q_{N,c}^{[k]}(\pi,\pi')
-Q_{CTCS}^{[k]}(\pi,\pi')
\right|
\le \frac{C_{k,c}}{N}
\tag{8.1}
\]

for all sufficiently large `N`.

### 8.3 Uniformization / path coupling

Choose one dominating jump rate for the two finite-state chains for all large `N`. Couple their uniformized jump proposals maximally at each Poisson epoch. The disagreement hazard is bounded by the row `L^1` generator discrepancy in (8.1). Consequently

\[
\boxed{
\left\|
\mathcal L(\Pi_{N,c}^{[k]}|_{[0,T]})
-
\mathcal L(\Pi_{CTCS}^{[k]}|_{[0,T]})
\right\|_{TV}
\le
1-e^{-TC_{k,c}/N}
\le \frac{TC_{k,c}}{N}
\to0.
}
\tag{8.2}
\]

Thus the **whole partition-valued path** on each fixed finite restriction converges in total variation. In particular,

\[
\Pi_{N,c}^{[k]}\Rightarrow\Pi_{CTCS}^{[k]}
\quad\text{in finite-state }J_1,
\]

and consistency gives convergence in R11's frozen summable projective finite-restriction topology:

\[
\boxed{
\Pi_{N,c}\Rightarrow\Pi_{CTCS(\infty)}.
}
\tag{8.3}
\]

This proves U064 for every fixed `c>0`.
