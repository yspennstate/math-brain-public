## 3. Move #4 — prove the natural unthinned one-locus attempt fails, completely

The previous run ended with the question whether C021's artificial rare block-observation coin can be removed. The first thing to do is not to tune another scale, but to test the most literal removal.

Consider a mutation-free neutral Moran allele-count excursion

\[
K_t\in\{0,1,\ldots,N\},\qquad K_0=1,
\]

absorbed at `0` or `N`, with

\[
P(k,k+1)=P(k,k-1)=\frac{k(N-k)}{N^2}.
\tag{3.1}
\]

At **every** raw Moran step, before the reproduction update, sample four distinct population sites for a four-label tree block. If the sample is nonmonochromatic, split the block by its two colors and stop. If absorption occurs first, that excursion gives no split. Repeating fresh excursions after absorption does not change the conditional shape law of the first successful split.

I prove that this natural unthinned model cannot have the CTCS root law.

### 3.1 Balanced splits vanish

At allele count `k`, the probability of a balanced `2|2` sample is

\[
s_{22,N}(k)
=
\frac{\binom{k}{2}\binom{N-k}{2}}{\binom N4}.
\tag{3.2}
\]

For `N>=5`,

\[
s_{22,N}(k)\le \frac{48k^2}{N^2}.
\tag{3.3}
\]

The Green occupation identity for the mutation-free Moran chain started from one mutant is exact:

\[
\boxed{\mathbb E_1 L_k=\frac Nk,\qquad 1\le k\le N-1.}
\tag{3.4}
\]

Indeed the embedded simple symmetric gambler's-ruin chain visits `k` an expected `2(N-k)/N` times, and one visit holds for mean `N^2/[2k(N-k)]` raw Moran steps.

Fix `K<N`. Before the count hits `{0,K}`, the expected number of balanced-sample opportunities is at most

\[
\sum_{k=1}^{K-1}\frac Nk\,s_{22,N}(k)
\le
\frac{48}{N}\sum_{k=1}^{K-1}k
<
\frac{24K^2}{N}.
\tag{3.5}
\]

The neutral gambler's-ruin probability of hitting `K` before `0`, starting from `1`, is `1/K`. Hence

\[
\boxed{
P(\hbox{a balanced split before absorption})
\le
\frac{24K^2}{N}+\frac1K.
}
\tag{3.6}
\]

Taking `K=floor(N^{1/3})` (or any `K->infinity`, `K^2/N->0`) makes the right side tend to zero.

### 3.2 A split itself remains order one

At `k=1`, a four-site sample is nonmonochromatic exactly when it contains the unique mutant, so

\[
r_N=\frac4N.
\]

The count leaves state `1` in one raw Moran update with probability

\[
m_N=\frac{2(N-1)}{N^2}.
\]

Sampling and reproduction randomness are independent. Therefore the probability of splitting before the count first leaves state `1` is

\[
\frac{r_N}{r_N+(1-r_N)m_N}
\ge \frac23,
\tag{3.7}
\]

and tends to `2/3`. Thus the probability of some split in an excursion is bounded away from zero, while the probability of a balanced split tends to zero. Consequently

\[
P(2|2\mid \hbox{a split occurs})\longrightarrow0.
\tag{3.8}
\]

For CTCS(4), there are four `1|3` supports of rate `B(1,3)=1/3` and three `2|2` supports of rate `B(2,2)=1/6`; hence

\[
P_{\rm CTCS}(2|2\hbox{ at root})=\frac{3(1/6)}{4(1/3)+3(1/6)}
=\boxed{\frac3{11}}.
\tag{3.9}
\]

So the unthinned one-locus route fails already at the first four-leaf root shape. This is a source-relevant no-go theorem, not a failure of a stronger invented statement.

## 4. Move #17 — the number `2 sqrt(2)-2` identifies the obstruction

Exact/numerical solution of the finite killed Moran equations suggested that the probability of **any** split in the preceding four-label excursion approaches

\[
0.82842712\ldots=2\sqrt2-2.
\]

That number is not accidental. Localize the Moran count to fixed states `1,...,K` and accelerate raw time by `N`. For fixed `k`,

- upward events occur at rate `k+o(1)`;
- downward events occur at rate `k+o(1)`;
- a nonmonochromatic `b`-sample occurs at rate `bk+o(1)`.

Thus the localized limit is critical linear birth--death branching with birth rate `1` per particle, death rate `1` per particle, and killing rate `b` per particle.

Let `u_b` be the probability that one initial particle becomes extinct before any kill. Branching gives

\[
u_b=\frac{1+u_b^2}{b+2}.
\tag{4.1}
\]

The admissible smaller root is

\[
u_b=\frac{b+2-\sqrt{b^2+4b}}2.
\tag{4.2}
\]

For `b=4`,

\[
u_4=3-2\sqrt2,
\qquad
1-u_4=2\sqrt2-2.
\tag{4.3}
\]

The localization is rigorous: for each fixed `K`, the finite killed generators converge; the probability of reaching `K` from one mutant before neutral extinction is at most `1/K`, and killing can only reduce it. First let `N->infinity` at fixed `K`, then `K->infinity`. Hence

\[
\boxed{
P(\hbox{some unthinned four-label split in one excursion})
\to 2\sqrt2-2.
}
\tag{4.4}
\]

This explains *why* the previous no-go is sharp in mechanism: unthinned observation sees the critical branching boundary layer before the allele frequency reaches the `O(N)` regime needed to create a balanced split.

## 6. C022 — an infinite-locus free-recombination Moran hierarchy

For every tree/population size `N`, set

\[
\alpha_N=N^{-2},\qquad
\mu_N=\frac{\alpha_N}{N+2\alpha_N},
\qquad
\Delta_N=\alpha_N=N^{-2}.
\tag{6.1}
\]

There are `N` population sites and countably many loci `ell=1,2,...`. At each locus independently, run the neutral two-allele Moran chain used in C021:

1. choose a parent population site uniformly;
2. copy its allele and flip it with probability `mu_N`;
3. choose a victim site uniformly and replace its allele.

All loci evolve independently and are started independently in their exact stationary exchangeable law. At one locus the stationary red-count law is

\[
\pi_{N,\alpha}(s)
=
\binom Ns\frac{(\alpha)_s(\alpha)_{N-s}}{(2\alpha)_N}.
\tag{6.2}
\]

Interpretation: this is an idealized **free-recombination / independently assorting gene-copy limit**, not a claim that a literal shared biological pedigree makes unlinked loci independent.

Fix once and for all an injection

\[
\Lambda_N:
\mathbb N_0\times
\{B\subset[N]:|B|\ge2\}
\longrightarrow\mathbb N.
\tag{6.3}
\]

For example, use any Cantor pairing of raw time `r` with the binary code of `B`.

At raw hierarchy generation `r`, **every** current nonsingleton tree block `B` is observed; there is no activation coin. Block `B` reads the never-before-read locus

\[
\ell=\Lambda_N(r,B).
\]

Choose a uniform injection `phi_B:B -> [N]`, independently for different current blocks conditional on the locus configurations. Color each tree label by the allele at its assigned population site at locus `ell`. If both colors occur, split `B` into the two color classes; if monochromatic, do nothing. Then advance the locus population processes by one raw generation. Give one raw hierarchy generation physical duration `Delta_N`.

Because `(r,B)` is never assigned the same locus twice, every tree observation sees an independent stationary locus even though the whole infinite genome persists. Several different blocks may split in the same raw hierarchy generation, but that will have probability `O_k(alpha_N^2)` on each fixed `[k]`.

The model is completely discrete: raw time, population sites, loci, alleles and tree splits are all discrete. It is not obtained from CTCS by relabeling or deterministic branch-length rescaling.

## 7. Exact one-step split law

Fix a visible block `C` of size `b=i+j` and a specified unordered split `A|A^c`, `|A|=i`.

Conditional on a locus having `s` red sites, uniform injection without replacement gives

\[
r_{N,s}(i,j)
=
\frac{
(s)_{\underline i}(N-s)_{\underline j}
+
(s)_{\underline j}(N-s)_{\underline i}
}{
(N)_{\underline b}
}.
\tag{7.1}
\]

Averaging under the beta-binomial stationary law gives exactly

\[
\boxed{
p_N(i,j)
=
\mathbb E_\pi r_{N,J}(i,j)
=
\frac{2(\alpha_N)_i(\alpha_N)_j}{(2\alpha_N)_b}.
}
\tag{7.2}
\]

Divide by `Delta_N B(i,j)=alpha_N B(i,j)`. Exactly,

\[
\frac{p_N(i,j)}{\alpha_N B(i,j)}
=
\frac{
\prod_{r=1}^{i-1}(1+\alpha_N/r)
\prod_{r=1}^{j-1}(1+\alpha_N/r)
}{
\prod_{r=1}^{b-1}(1+2\alpha_N/r)
}.
\tag{7.3}
\]

For each fixed `b`, this finite product is `1+O_b(alpha_N)`. Therefore

\[
\boxed{
p_N(i,j)
=
\Delta_N B(i,j)+O_b(\Delta_N^2).
}
\tag{7.4}
\]

This is the CTCS generator at first order with **no temporal rare-observation coin**. The rare event is now intrinsic: at low mutation, a stationary locus is almost monochromatic, and a proper split appears with probability `Theta(alpha_N)`.

## 8. Exact restriction consistency in law

Take any hidden current tree block `B` and a visible subset `C\subset B`.

The restriction of a uniform injection `B -> [N]` to `C` is a uniform injection `C -> [N]`. If a hidden split is invisible on `C`, exactly one hidden child continues to carry every label of `C`. At the next raw time that carrier block reads a new locus. Since every `(time,block)` uses a distinct independent stationary locus, changing the hidden carrier's identity cannot bias its future visible split law.

Distinct visible carrier blocks read distinct loci and hence have independent conditional observations. Thus the restricted `[k]` chain has the same transition law whether or not the other `N-k` tree labels are retained. No hidden-label averaging lemma is needed.

## 9. Full finite-restriction path convergence

Fix `k` and a partition state `rho` of `[k]`.

For any specified proper split of any current block, (7.4) gives the desired CTCS rate with per-step error `O_k(Delta_N^2)`. There are only finitely many possible specified splits on `[k]`.

A current block has total proper-split probability `O_k(Delta_N)`. Different current blocks use independent loci, so the probability that two or more visible blocks split in the same raw generation is `O_k(Delta_N^2)`.

Consequently, uniformly over every partition state `rho`,

\[
\boxed{
\left\|
P_N^{(k)}(\rho,\cdot)
-
\left(I+\Delta_N Q_{\rm CTCS}^{(k)}\right)(\rho,\cdot)
\right\|_{\rm TV}
\le C_k\Delta_N^2.
}
\tag{9.1}
\]

On a fixed physical interval `[0,T]` there are at most `ceil(T/Delta_N)` raw steps. Iterating a maximal coupling therefore gives

\[
P(\hbox{coupling failure before }T)
\le
C_{k,T}\Delta_N
\longrightarrow0.
\tag{9.2}
\]

For the comparison Euler chain, if the current partition has total CTCS exit rate `lambda(rho)`, the number of raw steps to the next jump is geometric with parameter

\[
\Delta_N\lambda(\rho)+O_k(\Delta_N^2),
\]

so the physical holding time converges to `Exp(lambda(rho))`. Conditional jump probabilities converge to the normalized CTCS generator. A `k`-label fragmentation has at most `k-1` proper visible refinements, so the complete jump-state / holding-time sequence converges.

Hence

\[
\boxed{
\widehat\Pi_N^{[k]}
\Longrightarrow
\Pi_{\rm CTCS}^{[k]}
\quad\text{in Skorokhod }J_1
}
\tag{9.3}

for every fixed `k`.

Use the same projective metric retained throughout R11,

\[
d_{\rm proj}(\omega,\eta)
=
\sum_{k\ge1}2^{-k}
\left(1\wedge d_{J_1,k}(\omega^{[k]},\eta^{[k]})\right).
\tag{9.4}
\]

Finite-restriction convergence plus the deterministic projective tail bound gives

\[
\boxed{
\widehat\Pi_N
