## 4.1 Exact continuum generator for every branch count

The multiplication map

\[
y\mapsto b_Ny\pmod L
\]

is `b_N`-to-one and preserves Lebesgue measure on `[0,L)`. Outside `[0,L)` the map is the identity. Therefore, for every nonnegative/integrable `g`,

\[
\int_{\mathbb R}g(S_N(y))\,dy
=
\int_{\mathbb R}g(y)\,dy.
\tag{4.7}
\]

Using

\[
dx=x(1-x)\,dy,
\tag{4.8}
\]

we obtain, exactly for every `N`,

\[
\begin{aligned}
\int_0^1F_{N;i,j}(x)\,dx
&=\frac12\int_{\mathbb R}
\left[
\sigma(S_Ny)^i(1-\sigma(S_Ny))^j
+\sigma(S_Ny)^j(1-\sigma(S_Ny))^i
\right]dy\\
&=\frac12\int_{\mathbb R}
\left[
\sigma(y)^i(1-\sigma(y))^j
+\sigma(y)^j(1-\sigma(y))^i

&=B(i,j)\\
&=\frac{(i-1)!(j-1)!}{(i+j-1)!}.
\end{aligned}
\tag{4.9}

So only harmonic-grid aliasing remains.
