# Method #5 — ADD A PARAMETER

The previous run's weighted Cayley skeleton suggested asking whether the CTCS compiler is isolated. It is not.

Let `z^C_{m,s}` be the Cayley expected number of oriented edge-sides of size `s`, and let `z^B_{m,s}` be the corresponding random-BST profile derived below. For `theta in [0,1]`, choose a Cayley skeleton with probability `theta` and a BST skeleton with probability `1-theta` each time a block is refreshed. Then

\[
z^{(\theta)}_{m,s}
 = \theta z^C_{m,s}+(1-\theta)z^B_{m,s}.
\]

There is an exact size-only correction

\[
w^{(\theta)}_m(s)
 = \frac{m}{s(m-s)z^{(\theta)}_{m,s}},                 \tag{5.1}
\]

and consequently `z^(theta) w^(theta) = m/[s(m-s)]` for every `theta`. Moreover

\[
\partial_\theta w^{(\theta)}_m(s)
 =-w^{(\theta)}_m(s)
   \frac{z^C_{m,s}-z^B_{m,s}}{z^{(\theta)}_{m,s}}.     \tag{5.2}
\]

Since a reciprocal of a positive convex combination is bounded by the larger endpoint reciprocal after the common numerator is restored,

\[
w^{(\theta)}_m(s)
\le \max\{w^C_m(s),w^B_m(s)\}<\frac32.
\]

Thus the entire interpolation satisfies U001 with the same `delta_N=N^{-3}` scale. This is useful evidence that the mechanism is a genuine universality class, not a single isolated finite model. **I do not inflate the metric by counting every theta as a separate model class.** The metric gain below is only the new BST endpoint class.

# New model C008 — weighted random binary-search-tree multi-cut hierarchy

For a block `B` of size `m`, construct a random binary search tree on keys `1,...,m` from a uniformly random insertion permutation, and then apply an independent uniform bijection from those keys to the labels of `B`. This final relabelling makes the labelled skeleton exchangeable while preserving the classical random-BST shape distribution.

For a parent-child edge let `s` be the number of vertices in the child fringe subtree. Because the weight below is symmetric in `s` and `m-s`, it is a well-defined physical-edge weight independent of which side is named first.

For every global size `N`, put

\[
\delta_N=N^{-3}.
\]

At every raw generation, independently for every current nonsingleton block: draw a **fresh** exchangeably relabelled BST, mark each edge independently with probability `delta_N w_m^{BST}(s_e)`, delete all marked edges, and use the connected components as the child blocks. ## Exact BST oriented-edge profile

Let `A_{m,s}` be the expected number of non-root BST vertices whose fringe subtree has exactly `s` vertices. For `1<=s<m`,

\[
\boxed{
A_{m,s}=\frac{2(m+1)}{(s+1)(s+2)}.
}                                                       \tag{C8.1}
\]

Here is a self-contained proof. The root rank is uniform in `{1,...,m}`. With `A_{s,s}=1`, for `m>s`, conditioning on the left and right root-subtree sizes gives

\[
A_{m,s}=\frac{2}{m}\sum_{r=s}^{m-1}A_{r,s}.             \tag{C8.2}
\]

The first nontrivial value is `A_{s+1,s}=2/(s+1)`. Subtracting the recurrence at successive `m` gives

\[
(m+1)A_{m+1,s}=(m+2)A_{m,s},
\]

and telescoping from `m=s+1` yields (C8.1).

Every physical edge contributes two oriented sides. Therefore the expected number of oriented edge-sides of size `s` is

\[
\boxed{
z^{BST}_{m,s}
 =A_{m,s}+A_{m,m-s}
 =2(m+1)\left[
 \frac{1}{(s+1)(s+2)}+
 \frac{1}{(m-s+1)(m-s+2)}\right].
}                                                       \tag{C8.3}
\]

Define

\[
\boxed{
w_m^{BST}(s)
 =\frac{m}{s(m-s)z^{BST}_{m,s}}.
}                                                       \tag{C8.4}
\]

Then (U1) is immediate:

\[
z^{BST}_{m,s}w_m^{BST}(s)=\frac{m}{s(m-s)}.
\]

## Uniform realized-weight bound

Put `b=m-s`. Since for every integer `s>=1`,

\[
(s+1)(s+2)\le 6s^2,
\]

(C8.3) implies

\[
z^{BST}_{m,s}
\ge \frac{m+1}{3}\left(\frac1{s^2}+\frac1{b^2}\right).
\]

Hence

\[
w_m^{BST}(s)
\le
\frac{3m}{(m+1)(b/s+s/b)}
\le \frac{3m}{2(m+1)}<\frac32.                         \tag{C8.5}

Every `m`-vertex BST has `m-1` physical edges, so every realized skeleton satisfies

# Method #11 — DUALIZE: coherent split-rate arrays are moment measures

The weighted-skeleton formula becomes much clearer on the dual side.

Consider a nonnegative split-rate array `r_{m,i}`, `1<=i<m`, satisfying the sampling-consistency/Pascal relation

\[
r_{m-1,i}=r_{m,i}+r_{m,i+1},                           \tag{D.1}
\]

and symmetry `r_{m,i}=r_{m,m-i}`. Define the moment sequence

\[
a_n:=r_{n+2,n+1},\qquad n\ge0.
\]

Repeated use of (D.1) gives

\[
r_{m,i}
 =\sum_{j=0}^{m-i-1}(-1)^j
   \binom{m-i-1}{j}a_{i-1+j}.                           \tag{D.2}
\]

Nonnegativity of every `r_{m,i}` is exactly complete monotonicity of `(a_n)`. By the Hausdorff moment theorem there is a unique finite measure `mu` on `[0,1]` such that

\[
\boxed{
r_{m,i}
 =\int_0^1 x^{i-1}(1-x)^{m-i-1}\,\mu(dx).}
                                                               \tag{D.3}
\]

Symmetry of the rate array is equivalent to symmetry of `mu` under `x -> 1-x`.

For CTCS,

\[
r_{m,i}=B(i,m-i),
\]

so

\[
a_n=B(n+1,1)=\frac1{n+1},
\]

and the unique dual measure is simply

\[
\boxed{\mu(dx)=dx.}                                    \tag{D.4}
\]

This is not presented as a new fragmentation theorem. Dislocation-measure representations of consistent/regenerative fragmentation trees are classical. What is useful here is the interpretation: U001's target expected side profile is precisely a finite discrete compiler for **Lebesgue dislocation mass** in the beta-kernel coordinates.

# Method #24 — FIND THE EXTREMAL OBJECT: the naive extremality conjecture fails

The dualization answers the extremal question cleanly. The cone of nonnegative symmetric coherent rate arrays is isomorphic to the cone of finite symmetric measures on `[0,1]`. Its extremal rays correspond to single orbits of the reflection `x <-> 1-x`: `delta_{1/2}` at the fixed point and, for `0<=x<1/2`, the symmetric orbit measure `delta_x+delta_{1-x}` up to scale.

Lebesgue measure is not an extremal ray. Therefore the CTCS beta kernel is **not extremal in the natural coherent-rate cone**. This route does not produce uniqueness of CTCS and should not be pursued as an extremal characterization.

There is, however, a useful narrower uniqueness statement. Once an exchangeable skeleton law is fixed and its expected oriented side-size profile `z_{m,s}>0` is fixed, if the correction is required to depend only on side size, then the exact U001 condition forces uniquely

\[
\boxed{
w_m(s)=\frac{m}{s(m-s)z_{m,s}}.}                 \tag{D.5}
\]

So the CTCS compiler is non-extremal globally but has a unique size-only correction on each fixed skeleton family. This explains why the Cayley, BST, path, and RRT weights look different while all encode the same beta kernel.
