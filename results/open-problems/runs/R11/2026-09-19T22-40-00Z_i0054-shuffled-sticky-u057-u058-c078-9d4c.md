# 4. U057 — sharp fixed-order persistence basin

## Theorem U057

For the fixed ambient-order sticky Markov harmonic-grid hierarchy, convergence of every fixed finite restriction to the CTCS generator occurs if and only if

\[
\boxed{\varepsilon_N\to0.}
\]

More quantitatively, for any specified unordered visible split `A | B` of an `m`-label carrier,

\[
\left|
q^{\rm fixed}_{N,\varepsilon}(A\mid B)
-q^{\rm iid}_{N}(A\mid B)
\right|
\le
(m-1)\varepsilon\frac{N-1}{N}.
\tag{4.1}
\]

Here `q_N^iid` is the iid harmonic-grid model, whose specified `i | (m-i)` rate converges to

\[
B(i,m-i)
=\int_0^1 x^{i-1}(1-x)^{m-i-1}\,dx
=\frac{(i-1)!(m-i-1)!}{(m-1)!}.
\tag{4.2}
\]

### Proof

Fix visible ambient positions

\[
r_1<\cdots<r_m,
\qquad
d_s=r_{s+1}-r_s,
\qquad
\rho_s=\varepsilon^{d_s}.
\]

Because

\[
K^d=\rho I+(1-\rho)\Pi,
\]

where `Pi` has both rows equal to `pi_x`, the transition across a gap `d_s` is

\[
P(Y_{r_{s+1}}=b\mid Y_{r_s}=a)
=(1-\rho_s)\pi_x(b)+\rho_s\mathbf1_{\{a=b\}}.
\tag{4.3}
\]

Take a nonconstant oriented color pattern

\[
y=(y_1,\dots,y_m)\in\{0,1\}^m.
\]

Let `s_*` be its first color change. The stationary initial factor together with the transition at this first color change contains exactly

\[
\pi_x(y_1)\,(1-\rho_{s_*})\pi_x(1-y_1),
\]

so in particular it contains the factor `x(1-x)`. Divide the whole pattern probability by `x(1-x)`. Every remaining transition factor is in `[0,1]` and is affine in one `rho_s`; replacing one `rho_s` by zero changes the quotient by at most `rho_s`. Telescoping over the gaps gives

\[
\left|P_\varepsilon(y)-P_0(y)\right|
\le
x(1-x)\sum_{s=1}^{m-1}\rho_s.
\tag{4.4}
\]

Since each `d_s>=1`,

\[
\sum_s\rho_s\le(m-1)\varepsilon.
\tag{4.5}
\]

A specified **unordered** split has the two complementary orientations `y` and `1-y`; therefore at harmonic mark `x_j`

\[
|p_{\varepsilon,j}(A\mid B)-p_{0,j}(A\mid B)|
\le
2(m-1)\varepsilon x_j(1-x_j).
\tag{4.6}
\]

Multiplying by

\[
\lambda_{N,j}=rac1{2N x_j(1-x_j)}
\]

cancels the singular beta-grid denominator exactly. Summing `j=1,...,N-1` proves (4.1).

Thus `epsilon_N->0` is sufficient because the iid harmonic-grid generator converges coordinatewise to the CTCS beta-split generator.

For necessity, take two **adjacent** visible labels. At each mark their probability of different colors is exactly

\[
2x(1-x)(1-\varepsilon_N).
\]

Hence their exact split rate is

\[
\boxed{
q_N(1\mid1)
=\frac{N-1}{N}(1-\varepsilon_N).
}
\tag{4.7}
\]

The CTCS pair rate is `B(1,1)=1`. Therefore generator convergence forces `epsilon_N->0`. This completes U057. `square`

### Interpretation

The `H_{N-1}` loss in U056 came from taking a markwise total-variation bound before exploiting that every nontrivial color pattern already contains an `x(1-x)` factor. The harmonic singularity cancels against that factor. Fixed-order persistence may decay arbitrarily slowly; it need not be `o(1/log N)`.

# 5. U058 — shuffled high-persistence Markov compiler

Now change the discrete model, rather than merely sharpening C077.

For every active clade and every ringing harmonic-grid clock `j`, independently:

1. draw a fresh uniform permutation `sigma` of the ambient labels `[N]`;
2. draw a fresh stationary binary Markov chain `Y_1,...,Y_N` with stationary bias `x_j=j/N` and persistence `epsilon_N`;
3. color ambient label `ell` by
   \[
   Y_{\sigma^{-1}(\ell)};
   \]
4. if both colors occur in the active clade, split it into the two color classes; otherwise nothing changes.

Every child restarts independent clocks and uses fresh permutations / fields.

Define the exact mean two-position persistence

\[
\boxed{
A_N(\varepsilon)
:=
\frac{2}{N(N-1)}
\sum_{d=1}^{N-1}(N-d)\varepsilon^d.
}
\tag{5.1}
\]

Equivalently, if `U,V` are uniformly sampled distinct positions in `[N]`, then

\[
A_N(\varepsilon)=E\,\varepsilon^{|U-V|}.
\tag{5.2}
\]

## Theorem U058

For the shuffled sticky-Markov harmonic-grid hierarchy, the following are equivalent:

1. every fixed finite restriction has generator converging to the CTCS generator;
2. the two-label restriction converges to CTCS;
3. `A_N(epsilon_N)->0`;
4. `N(1-epsilon_N)->infinity`.

Moreover, for any specified unordered `i | (m-i)` split,

\[
\boxed{
\left|
q^{\rm shuf}_{N,\varepsilon}(A\mid B)
-q^{\rm iid}_{N}(A\mid B)
\right|
\le
\binom m2 A_N(\varepsilon)\frac{N-1}{N}.
}
\tag{5.3}
\]

### Proof: finite-dimensional pattern comparison

Fix `m` visible labels. Under a fresh uniform ambient permutation, their ordered positions

\[
s_1<\cdots<s_m
\]

are a uniformly random `m`-subset of `[N]`.

Conditional on those positions, the U057 pattern argument gives for every nonconstant oriented color pattern `y`

\[
|P_\varepsilon(y\mid s)-P_0(y)|
\le
x(1-x)
\sum_{r=1}^{m-1}
\varepsilon^{s_{r+1}-s_r}.
\tag{5.4}
\]

The adjacent-gap sum is bounded by the sum over **all** visible pairs:

\[
\sum_{r=1}^{m-1}
\varepsilon^{s_{r+1}-s_r}
\le
\sum_{1\le a<b\le m}
\varepsilon^{|s_b-s_a|}.
\tag{5.5}
\]

By exchangeability of the random positions, each visible pair has the same position law as a uniformly chosen distinct ambient pair. Therefore

\[
E\sum_{a<b}
\varepsilon^{|s_b-s_a|}
=
\binom m2 A_N(\varepsilon).
\tag{5.6}
\]

Adding the complementary orientation of a specified unordered split gives the markwise bound

\[
|p^{\rm shuf}_{\varepsilon,j}(A\mid B)-p^{\rm iid}_{j}(A\mid B)|
\le
2x_j(1-x_j)inom m2 A_N(\varepsilon).
\tag{5.7}
\]

Again multiplying by `lambda_{N,j}=1/[2N x_j(1-x_j)]` cancels the beta singularity. Summing over `j=1,...,N-1` proves (5.3).

Since the iid harmonic-grid rate converges to (4.2), `A_N(epsilon_N)->0` implies every fixed specified split rate converges to CTCS.

### Proof: exact pair diagnostic

For two visible labels, the position distance is exactly the random variable in (5.2). Conditional on distance `d`, the Markov-chain color-disagreement probability is

\[
2x(1-x)(1-\varepsilon^d).
\]

Averaging over the random shuffle and over the harmonic marks gives the exact identity

\[
\boxed{
q_N^{\rm shuf}(1\mid1)
=
\frac{N-1}{N}
\left(1-A_N(\varepsilon_N)\right).
}
\tag{5.8}
\]

Since the CTCS pair rate is one, pair convergence is equivalent to `A_N(epsilon_N)->0`. Thus the full criterion is already visible at two labels.

### Proof: `A_N -> 0` iff the correlation length is `o(N)`

Write

\[
\delta_N=1-\varepsilon_N.
\]

For the sufficient direction, extend the weighted geometric series:

\[
A_N(\varepsilon)
\le
\frac{2}{N-1}
\sum_{d\ge1}\varepsilon^d
=
\frac{2\varepsilon}{(N-1)(1-\varepsilon)}
\le
\frac{2}{(N-1)(1-\varepsilon)}.
\tag{5.9}
\]

Hence

\[
N(1-\varepsilon_N)\to\infty
\quad\Longrightarrow\quad
A_N(\varepsilon_N)\to0.
\tag{5.10}
\]

Conversely suppose along a subsequence

\[
N(1-\varepsilon_N)\le C.
\]

For all sufficiently large `N`, `delta_N<=C/N<1/2`. For `1<=d<=N/2`,

\[
\varepsilon_N^d
=(1-\delta_N)^d
\ge
\exp(-2\delta_N d)
\ge e^{-C}.
\tag{5.11}
\]

Also `N-d>=N/2`, so from the first `floor(N/2)` terms in (5.1),

\[
A_N(\varepsilon_N)
\ge
\frac{2}{N(N-1)}
\left\lfloor\frac N2\right\rfloor
\frac N2 e^{-C},
\tag{5.12}
\]

which is bounded away from zero along that subsequence. Therefore

\[
\boxed{
A_N(\varepsilon_N)\to0
\quad\Longleftrightarrow\quad
N(1-\varepsilon_N)\to\infty.
}
\tag{5.13}
\]

This proves U058. `square`

## 6.1 Exact Markov projection of finite restrictions

Fix visible labels `[k]`. Each proposal on each full clade draws a fresh ambient permutation and a fresh Markov field, independently of all previous proposals and of hidden-label history.

If a proposal changes the visible partition, its hazard depends only on the currently co-located visible labels and the global `N` proposal law. If a proposal splits hidden labels but leaves all visible labels in one child, that visible carrier restarts fresh clocks and fresh proposal randomness. By the memorylessness of the independent Poisson clocks, this invisible reset leaves exactly the same future visible hazard law.

Therefore the projection to `[k]` is itself a time-homogeneous finite-state continuous-time Markov chain; there is no hidden field state carried from one proposal to the next.

Its off-diagonal generator entries are finite sums of specified split rates. U058 gives entrywise convergence of this finite generator to the CTCS(`[k]`) generator. Row sums then converge as well.

Choose a uniformization rate larger than all exit rates for the limiting chain and, for all sufficiently large `N`, for the approximating chains. Couple the common Poisson event clock and use maximal coupling of the discrete transition kernels. Because the finite generator matrices converge entrywise, the one-step mismatch probability tends to zero. On every fixed time interval `[0,T]`, the expected number of uniformized events is finite, so

\[
\boxed{
\left\|
\mathcal L(\Pi_{N,078}^{[k]}|_{[0,T]})
-
\mathcal L(\Pi_{\rm CTCS}^{[k]}|_{[0,T]})
\right\|_{\rm TV}
\longrightarrow0.

\tag{6.3}
\]

In particular,

\[
\Pi_{N,078}^{[k]}
\Rightarrow
\Pi_{\rm CTCS}^{[k]}
\quad\text{in }J_1
\tag{6.4}

for every fixed `k`.

The finite restrictions are consistent. Using R11's frozen summable projective metric on restriction-path coordinates, finite-coordinate convergence plus the summable tail gives

\[
\boxed{

\Pi_{\rm CTCS(\infty)}.

\tag{6.5}

Thus C078 supplies the complete required limit, not a marginal approximation.

# 8. Method #29 — the persistence point at infinity

The sharp criterion suggests a natural compactification. Suppose

\[
N(1-\varepsilon_N)\to c\in[0,\infty).
\tag{8.1}
\]

For pair persistence, write `d/N -> s`. The exact Riemann-sum limit from (5.1) is

\[
A_N(\varepsilon_N)
\longrightarrow
A(c)
:=2\int_0^1(1-s)e^{-cs}\,ds.
\tag{8.2}
\]

For `c>0`,

\[
\boxed{
A(c)=\frac{2(c-1+e^{-c})}{c^2},
}
\tag{8.3}
\]

with continuous value `A(0)=1`. Hence the two-label split rate has the boundary limit

\[
\boxed{
q_c(1\mid1)=1-A(c).
}
\tag{8.4}
\]

For every finite `c`, `A(c)>0`, so this pair rate is strictly smaller than the CTCS value one. CTCS is therefore the `c=infinity` boundary point of this persistence scaling.

This run does **not** claim a full finite-`c` fragmentation-process limit. Equation (8.4) is a proved obstruction/diagnostic showing that U058's threshold is sharp already at two labels.
