## 3. Move #8 — discretize the Dirichlet-multinomial population all the way down to an urn

The previous run showed that a broad Kingman-domain ancestral chain is enough for CTCS after rare lineage marking. A natural next step was to avoid even a continuously sampled random environment.

Fix population size `N`. One forward generation is generated by the following entirely discrete algorithm.

1. There are `N` parent colors `1,...,N`, initially one urn ball of each color.
2. For offspring positions `1,...,N`, draw one urn ball uniformly.
3. Assign the current offspring to the drawn parent color.
4. Return the drawn ball and add one additional ball of that same color.
5. After `N` offspring have been assigned, discard the urn and restart from one ball of each parent color in the next generation.

This is the symmetric Dirichlet-multinomial Cannings model with parameter one, but no latent continuous Dirichlet vector is needed for the construction.

If `r` sampled ancestral lineages are traced one generation backward, exchangeability of the offspring slots implies that their parent labels have the law of the first `r` Pólya draws. Let `\pi` be a fixed set partition of `[r]` into `b` blocks of sizes `k_1,...,k_b`; `\pi` records which lineages chose the same parent. Then

\[
\boxed{
\Pr_N(\Pi=\pi)
=
\frac{(N)_b\prod_{\ell=1}^b k_\ell!}
     {N^{\overline r}},
}
\tag{3.1}
\]

where

\[
(N)_b=N(N-1)\cdots(N-b+1),
\qquad
N^{\overline r}=N(N+1)\cdots(N+r-1).
\]

### Proof of (3.1)

Choose the `b` distinct parent colors injectively in `(N)_b` ways. Once the color of a block is fixed, the multiplicative reinforcement factors contributed by its `k_\ell` appearances are

\[
1\cdot2\cdots k_\ell=k_\ell!,
\]

while the successive total urn masses are `N,N+1,...,N+r-1`. Multiplying gives (3.1). This is an exact finite formula, not an asymptotic representation.

For two specified lineages,

\[
\boxed{c_N:=\Pr(1\sim2)=\frac{2}{N+1}.}
\tag{3.2}
\]

For a specified pair to merge while the other `r-2` lineages all choose distinct parents different from that pair's parent, (3.1) gives

\[
\boxed{
 p^{(1)}_{N,r}
 =\frac{2(N)_{r-1}}{N^{\overline r}}
 =c_N+O_r(c_N^2).
}
\tag{3.3}
\]

The no-collision probability is

\[
\Pr(\text{all distinct})=\frac{(N)_r}{N^{\overline r}}.
\tag{3.4}
\]

Every other nontrivial event contains either a block of size at least three or at least two collision blocks. By (3.1), for fixed `r` each such partition has probability `O_r(N^{-2})=O_r(c_N^2)`, and there are only finitely many partitions of `[r]`. Therefore the transient ancestral partition kernel satisfies

\[
\boxed{
K_{N,r}=I+c_NG_r+O_r(c_N^2),
}
\tag{3.5}
\]

where `G_r` is Kingman's finite-sample generator, normalized so that each specified pair merges at rate one.

The exact checker independently enumerates the set partitions and the underlying sequential urn assignments and verifies (3.1)--(3.4) on a finite exact grid.

## 4. Move #19 — make the population compiler an explicit hierarchy algorithm

Define **C017, the Pólya-Cannings mutation-refinement hierarchy**, as follows.

For global population size `N`, set

\[
\delta_N=\frac1N,
\qquad
c_N=\frac{2}{N+1},
\qquad
u_N:=\frac{\delta_Nc_N}{2}
       =\frac{1}{N(N+1)}.
\tag{4.1}
\]

For every current nonsingleton hierarchy block `B`, independently in every raw hierarchy generation:

1. place the labels of `B` at distinct offspring positions in a fresh size-`N` Pólya-Cannings population;
2. trace their ancestry backward through independent Pólya-Cannings generations until their MRCA;
3. **before each parental-allocation step**, independently mark every currently active ancestral lineage with probability `\nu_N`;
4. a mark on a lineage carries the subset `S\subset B` of present labels descended from that lineage;
5. at the MRCA, refine `B` by the common refinement of all marked bipartitions `S\mid B\setminus S`; trivial marks are ignored;
6. if there is no nontrivial marked split, leave `B` unchanged;
7. use independent genealogies for distinct current hierarchy blocks and for later raw hierarchy generations.

One raw hierarchy generation has physical duration `\delta_N`.

This is a finite, purely discrete algorithm. Because more than one lineage can be marked in one genealogy, finite C017 can have multifurcating refinement vertices. Because one Pólya generation can have triple or simultaneous ancestral mergers, its finite ancestry is not Wright--Fisher C016 in disguise.

## 5. Complete application of U005: whole-path convergence

### 5.1 Exchangeability and exact sampling consistency

The forward Pólya offspring sequence is exchangeable. Sampling any `r` offspring positions therefore gives exactly the same parent-partition law as the first `r` urn draws, namely (3.1), independent of how many unobserved offspring positions were present. Each generation is reset independently. Hence the backward ancestral chain is exchangeable and sampling-consistent at the process level.

The Bernoulli marks are attached independently to visible ancestral lineages. Restricting a genealogy to any visible subset simply deletes invisible ancestral material; marks on visible lineages retain the same Bernoulli law. Thus U005's hidden-label condition is satisfied exactly, not only after averaging.

### 5.2 Kingman first-order kernel

Equation (3.5) is precisely U005's first hypothesis with

\[
c_N=\frac{2}{N+1}\downarrow0.
\]

For completeness, the first-order coefficient is not inferred from a vague domain-of-attraction theorem: (3.1)--(3.4) give the coefficient directly, and all simultaneous/triple-merger states have `O_r(c_N^2)` probability for each fixed sample size.

### 5.3 Second moment of total ancestral opportunity count

Let `T_{N,m}` be the number of backward generations until the MRCA of a fixed `m`-sample, and let

\[
J_{N,m}
=\sum_{t<T_{N,m}}R_t
\]

be the total number of active-lineage opportunities, where `R_t\le m` is the number of active sample ancestors in generation `t`.

Whenever at least two lineages remain, choose any fixed two of them. Their parent colors coincide in the next generation with probability exactly `c_N`. Therefore the waiting time until **some** lineage-count decrease is stochastically dominated by a geometric random variable of parameter `c_N`. There can be at most `m-1` strict decreases before the MRCA. Consequently `T_{N,m}` is stochastically dominated by a sum `S` of `q=m-1` geometric(`c_N`) variables. Since

\[
\mathbb ES^2
=
\frac{q^2+q(1-c_N)}{c_N^2}
\le
\frac{q(q+1)}{c_N^2},
\]

and `J_{N,m}\le mT_{N,m}`,

\[
\boxed{
c_N^2\,\mathbb EJ_{N,m}^2
\le m^2(m-1)m=O_m(1).
}
\tag{5.1}
\]

This is U005's second-moment hypothesis.

By (4.1), the mark probability is exactly U005's prescribed

\[
\nu_N=\frac{\delta_Nc_N}{2},
\qquad \delta_N\downarrow0.

\tag{5.2}

\tag{5.3}
