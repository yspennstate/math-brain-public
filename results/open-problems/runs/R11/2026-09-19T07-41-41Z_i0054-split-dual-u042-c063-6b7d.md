## 2. Move #2 first — refute full-environment discrepancy as a necessary condition

U041 controls a local matrix discrepancy. A tempting strengthening would require the *underlying proposal/environment law* itself to approach the iid paintbox locally in total variation. That is false, and it is false maximally.

Fix `N>=2`, a Bernoulli parameter `x in (0,1)`, and write

\[
\beta_x(z)=x^{|z|}(1-x)^{N-|z|},\qquad z\in\{0,1\}^N,
\]

\[
M_x=\max\{x,1-x\},\qquad
R_{N,x}(z)=M_x^{-N}\prod_{r=1}^N(z_r-x).
\tag{2.1}
\]

Since `|z_r-x|<=M_x`, `|R_{N,x}(z)|<=1`. For `sigma in {+1,-1}` define

\[
\boxed{
\mu^{\sigma}_{N,x}(z)
=\beta_x(z)\bigl(1+\sigma R_{N,x}(z)\bigr).
}
\tag{2.2}
\]

This is a probability law: it is nonnegative and

\[
E_{\beta_x}R_{N,x}
=M_x^{-N}\prod_{r=1}^NE(Z_r-x)=0.
\]

Now marginalize any proper coordinate set `S subsetneq [N]`. At least one coordinate `r notin S` is summed out, and the perturbation disappears because

\[
\sum_{z_r\in\{0,1\}}\beta_x(z_r)(z_r-x)=0.
\]

Hence

\[
\boxed{
(\mu^{\sigma}_{N,x})_S=\beta_x^{\otimes S}
\quad\text{for every }S\subsetneq[N].
}
\tag{2.3}
\]

At `x=1/2`, however, `R_{N,1/2}(z)` is the full parity character. The `+` and `-` laws live on opposite parity classes. Therefore

\[
\|\mu^+_{N,1/2}-\mu^-_{N,1/2}\|_{TV}=1,
\qquad
\|\mu^+_{N,1/2}-\beta_{1/2}\|_{TV}=1/2.
\tag{2.4}
\]

Thus the environment can oscillate between **mutually singular laws** while every proper finite restriction is exactly iid. Full-environment TV discrepancy is not the right invariant for the CTCS limit. The correct quotient is by the binary split tests actually visible to the partition generator.

This negative result is what led to U042 rather than another stronger version of U041.

## 4. Move #24 — the extremal partition gives the sharp constant

A block of size `b` has exactly

\[

\tag{4.1}
\]

unordered nontrivial binary splits. If a partition of `[k]` has block sizes `b_1,...,b_m`, the number of outgoing one-block split transitions is

\[

\tag{4.2}
\]

For positive `a,b`,

\[
(2^{a-1}-1)+(2^{b-1}-1)
\le 2^{a+b-1}-1.
\]

Repeated merging therefore shows that the extremal state is the one-block partition:

\[
\boxed{
S_k:=\max_{\pi\in P_k}\#\{\text{outgoing binary splits from }\pi\}
=2^{k-1}-1.
}
\tag{4.3}
\]

Let

\[
d_{\pi,B,A}
=\bar a_{N,r}(\pi;B,A)-\beta(|A|,|B\setminus A|).
\]

The off-diagonal row differences are these `d` values, while generator row sums force the diagonal difference to be `-sum d`. Hence

\[
\sum_{\pi'}
|\bar A_{N,r}(\pi,\pi')-Q_k(\pi,\pi')|
\le
\sum|d|+\left|\sum d\right|
\le 2S_kD_{N,k}(T).
\tag{4.4}

Conversely every split discrepancy is itself one off-diagonal matrix entry, so

\[
D_{N,k}(T)

\tag{4.5}

Combining,

\[
\boxed{

\le

2(2^{k-1}-1)D_{N,k}(T),

\tag{4.6}

where

The constant `2(2^{k-1}-1)` is sharp as a universal row-norm comparison: at the one-block state, perturb every outgoing split rate by the same positive `epsilon`. Then the off-diagonal absolute sum is `S_k epsilon`, the diagonal changes by `-S_k epsilon`, and the row norm is exactly `2S_k epsilon`.
