# Method #21 — ASK WHO ELSE HAS THIS SHAPE

The beta function in the CTCS particular-split rate already occurs in a classical object: the Bolthausen-Sznitman coalescent, after increasing the merger size by one.

This suggests an **anchor-deletion transform**. Take a merger block `M` containing a distinguished anchor `a`; delete `a` from that merger block and reinterpret the remaining set `M\{a}` as one child of a binary split, with its complement as the other child.

For a general exchangeable coalescent with specified-`k` merger rates `lambda_{m,k}`, the infinitesimal particular split rate produced by this transform is

\[
\mathcal A\lambda(m,i)
 =
 \frac{m-i}{m}\lambda_{m,i+1}
 +
 \frac{i}{m}\lambda_{m,m-i+1}.
\tag{21.2}
\]

Indeed, for a target unordered split `A | A^c`, `|A|=i`:

- if the uniform anchor `a` lies in `A^c`, the required merger is `A \cup {a}`, of size `i+1`;
- if `a` lies in `A`, the required merger is `A^c \cup {a}`, of size `m-i+1`.

For the Bolthausen-Sznitman kernel, (21.1) and beta symmetry give

\[
\boxed{
\mathcal A\lambda_{\rm BS}(m,i)=B(i,m-i),
}
\tag{21.3}
\]

which is exactly the CTCS(infinity) restriction generator for a particular binary split.

The rest of the run makes (21.3) into a genuinely finite discrete tree model, rather than merely a generator identity.

# New model C009 — random-recursive-tree anchor-lift hierarchy

Fix a global size `N` and put

\[
p_N=N^{-3}.
\tag{C9.1}
\]

Start with the block `[N]`. At each raw generation, independently for every current nonsingleton block `B` of size `m`:

1. Draw a fresh random recursive tree on structural vertices `1,...,m`: vertex `v>=2` attaches to one of `1,...,v-1` uniformly.
2. Apply an independent uniform bijection from the structural vertices to the labels in `B`. This makes the rooted labelled skeleton exchangeable.
3. Independently mark every one of its `m-1` edges with probability `p_N`.
4. Put the marked edges in an independent uniform random order. Process them by the classical **lift** operation: if a marked parent-child edge is still present, merge all labels currently carried by the child descendant subtree into the parent node and delete those descendant vertices. A later marked edge whose endpoint has already disappeared is inert.
5. Choose an independent uniform anchor label `a in B`. Let `M_a` be the coalescent block containing `a` after all effective lifts.
6. If `M_a={a}`, leave `B` unchanged. Otherwise replace `B` by the two unordered children
   \[
   M_a\setminus\{a\},
   \qquad
   B\setminus(M_a\setminus\{a\}).
   \]
7. One raw generation has physical duration `p_N`.

The output refinement is **always binary**, even though the internal micro-coalescent can make multiple mergers. Descendant blocks repeat the same rule independently in later generations.

Call the accelerated partition path

\[
\widehat\Pi_N(t)=\Pi_N(\lfloor t/p_N\rfloor).
\]

This is a finite discrete random-tree algorithm based on a standard unweighted RRT; unlike C005/C007/C008 there is no component-size edge weight chosen to invert a split profile.

# Method #7 — TAKE THE LIMIT

## 1. Exact one-edge merger coefficient from the RRT

Let `Z_{m,s}` be the number of RRT edges whose child descendant fringe subtree has size `s`. The standard insertion recurrence, already proved in R11-C005 and independently rechecked here, gives

\[
\boxed{
\mathbb E Z_{m,s}=\frac{m}{s(s+1)},\qquad1\le s<m.
}
\tag{C9.2}
\]

A lift across such an edge merges the `s` descendant vertices together with their parent, hence produces a merger set of size

\[
k=s+1.
\]

After the independent uniform relabelling, a fixed structural `k`-vertex merger set is a uniform `k`-subset of the `m` labels. Therefore the expected number of one-edge lifts producing a **specified** merger set `M`, `|M|=k`, is

\[
\frac{m}{(k-1)k\binom mk}
 =
\frac{(k-2)!(m-k)!}{(m-1)!}
 =
\boxed{B(k-1,m-k+1)}.
\tag{C9.3}
\]

Thus the one-edge RRT lift recovers the Bolthausen-Sznitman specified-merger coefficient directly, without using the continuous-time coalescent theorem as a black box.

## 2. Anchor transform gives the exact CTCS full-block split coefficient

Fix a particular unordered split `A | A^c` of a full `m`-label block, with `|A|=i`.

If the anchor is in `A^c`, equation (C9.3) says that the merger `A \cup {a}` has coefficient `B(i,m-i)`. If the anchor is in `A`, the merger `A^c \cup {a}` has coefficient `B(m-i,i)`.

Averaging over the uniform anchor gives

\[
\begin{aligned}
q_m(A|A^c)
&=
\frac{m-i}{m}B(i,m-i)
+
\frac{i}{m}B(m-i,i)\\
&=
\boxed{B(i,m-i)}.
\end{aligned}
\tag{C9.4}
\]

This is exactly the CTCS particular-split rate.

## 3. Restriction through hidden labels remains exact to first order

Now fix `k` sampled labels. Suppose one current visible sampled block `C`, `|C|=b`, lies inside a hidden full block `B`, `|B|=m>=b`.

For a particular visible split `A | C\A`, `|A|=i`, sum (C9.4) over hidden sides `S` satisfying `S\cap C=A`. If `|S|=s`, there are

\[
\binom{m-b}{s-i}
\]

such hidden choices. Hence the first-order visible rate is

\[
\begin{aligned}
\sum_{s=i}^{m-b+i}
\binom{m-b}{s-i}B(s,m-s)
&=
\int_0^1
t^{i-1}(1-t)^{b-i-1}
\sum_{\ell=0}^{m-b}\binom{m-b}{\ell}
t^\ell(1-t)^{m-b-\ell}\,dt\\
&=
\boxed{B(i,b-i)}.
\end{aligned}
\tag{C9.5}
\]

This is the beta-binomial identity, with `ell=s-i`. The essential point is that the hidden size `m` cancels completely.

Therefore, conditioned on the complete hidden history, the first-order generator seen by any fixed finite restriction is the CTCS generator.

## 4. Uniform error estimate

Across all hidden blocks that contain at least one of the fixed `k` sampled labels, the total number of RRT edges is at most `N`.

The probability that at least two of these relevant edges are marked in one raw generation is bounded by

\[
\binom N2 p_N^2.
\tag{C9.6}
\]

On the one-mark event, the factor requiring all other relevant edges to be unmarked differs from one by at most `Np_N`. Since the total CTCS exit rate on the fixed `k`-state space is bounded by a constant depending only on `k`, equations (C9.4)--(C9.6) give, uniformly over hidden histories,

\[
\boxed{
\Pr(\rho\to\rho'\mid\mathcal F)
=
p_N Q^{(k)}(\rho,\rho')
+
O_k(p_N^2N^2)
}
\tag{C9.7}
\]

for every single CTCS transition, with the same row-total order for all non-Euler behavior.

Let

\[
K_N=I+p_NQ^{(k)}.
\]

Conditional maximal coupling of one raw restricted step to `K_N` fails with probability `O_k(p_N^2N^2)`. On a bounded physical interval `[0,T]` there are `O(T/p_N)` raw steps, so

\[
\Pr(\text{coupling fails before }T)
\le
O_k(Tp_NN^2).
\tag{C9.8}
\]

With `p_N=N^{-3}`,

\[
p_NN^2=N^{-1}\to0.
\tag{C9.9}
\]

## 5. Euler chain to the CTCS restriction

At a nonabsorbing visible state `rho`, let

\[
\lambda(\rho)=-Q^{(k)}(\rho,\rho).
\]

In the Euler chain `K_N`, the number of raw steps to the next jump is geometric with parameter `p_N\lambda(\rho)`. Hence its physical holding time converges to

\[
\operatorname{Exp}(\lambda(\rho)).
\]

Conditioned on jumping, the next state has exactly

\[
Q^{(k)}(\rho,\rho')/\lambda(\rho).
\]

A fragmentation of `k` labels makes at most `k-1` visible jumps before absorption. Coupling successive holding times and jump choices therefore gives

\[
\boxed{
\widehat\Pi_N^{[k]}
\Longrightarrow
\Pi_{\rm CTCS}^{[k]}
}
\tag{C9.10}
\]

in Skorokhod `J_1`.

## 6. Whole exchangeable-partition path

Use the retained projective metric

\[
d_{\rm proj}(\omega,\eta)
=
\sum_{k\ge1}2^{-k}
\left(1\wedge d_{J_1,k}

Given `epsilon>0`, choose `K` so the deterministic coordinate tail above `K` is below `epsilon/2`; the coupling of the `[K]` restriction simultaneously couples every smaller restriction. Equation (C9.10) then gives

\[
\boxed{

# Method #13 — FIND WHAT ONLY INCREASES / DECREASES

The potentially dangerous part of the algorithm is processing more than one marked RRT edge in a generation. The useful monovariant is the **number of active RRT vertices** during the micro-coalescent.

Every effective lift deletes at least one active vertex and never creates a new one. Thus the active-vertex count strictly decreases at every effective lift. In particular:

1. an interaction between lifts cannot create a first-order cycle or resurrect an edge;
2. any difference between the true micro-coalescent and its one-edge linearization is supported on the event that at least two original edges were marked;
3. (C9.6) therefore controls *all* nonlinear same-generation interactions, including nested marked edges.

This is why no detailed classification of two-edge configurations is needed for the asymptotic proof. The cumulative bad-event budget over physical time `[0,T]` is monotone and bounded by `O(Tp_NN^2)=O(T/N)`.

Outcome of Method #13: the multi-lift complication is genuinely second order; the exact first-order anchor transform survives without hidden interaction terms.
