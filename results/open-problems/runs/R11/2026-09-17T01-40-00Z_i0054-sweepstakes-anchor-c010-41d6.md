# Method #4 — prove one sweep opportunity completely before building a hierarchy

Fix a global population size `N >= 2` and define

\[
\pi_N(k):=\frac{N}{(N-1)k(k-1)},\qquad 2\le k\le N.
\tag{4.1}
\]

The telescoping identity

\[
\sum_{k=2}^N\frac1{k(k-1)}=1-\frac1N
\]

shows that `pi_N` is a probability distribution.

Consider a current hidden fragmentation block `B` of size `m <= N`. One **active sweep opportunity** is:

1. draw `K ~ pi_N`;
2. draw a uniform `K`-subset `S` of the ambient label set `[N]`;
3. inside `B`, merge all labels in `S cap B` into one auxiliary block if at least two are hit;
4. choose a uniform anchor `a in B`;
5. if the anchor's auxiliary merger block is a singleton, make no fragmentation split; otherwise, if that merger block is `M_a`, output the binary split
   \[
   M_a\setminus\{a\}\ \big|\ B\setminus(M_a\setminus\{a\}).
   \]

The exact one-opportunity law already contains the CTCS beta kernel.

## Lemma 1: exact hidden-block merger law

Fix a particular subset `T subset B` with `|T|=r>=2`. Conditional on one active opportunity,

\[
\boxed{
\Pr(S\cap B=T)=\frac1{N-1}B(r-1,m-r+1).
}
\tag{4.2}
\]

**Proof.** If the sweep contains `x` ambient labels outside `B`, then `K=r+x`; hence

\[
\Pr(S\cap B=T)
=\sum_{x=0}^{N-m}
\pi_N(r+x)\frac{\binom{N-m}{x}}{\binom N{r+x}}.
\]

For every `2<=k<=N`,

\[
\frac{\pi_N(k)}{\binom Nk}
=\frac1{N-1}B(k-1,N-k+1).
\tag{4.3}
\]

Insert the beta integral into the sum:

\[
\begin{aligned}
\Pr(S\cap B=T)
&=\frac1{N-1}\int_0^1
 t^{r-2}(1-t)^{m-r}
 \sum_{x=0}^{N-m}\binom{N-m}{x}t^x(1-t)^{N-m-x}\,dt\\
&=\frac1{N-1}\int_0^1t^{r-2}(1-t)^{m-r}\,dt\\
&=\frac1{N-1}B(r-1,m-r+1).
\end{aligned}
\]
This proves (4.2).  QED.

## Lemma 2: exact anchor-deletion split law

Fix a particular unordered split `A | A^c` of the full hidden block `B`, where `|A|=i`. Conditional on one active opportunity,

\[
\boxed{
\Pr(\text{output }A|A^c)=\frac1{N-1}B(i,m-i).
}
\tag{4.4}
\]

**Proof.** If the anchor lies in `A^c`, the required sweep intersection is `T=A union {a}`, of size `i+1`; Lemma 1 gives coefficient `(N-1)^{-1}B(i,m-i)`. There are `m-i` possible anchors, each with probability `1/m`. If the anchor lies in `A`, the required merger is `A^c union {a}` and beta symmetry gives the same coefficient. Therefore

\[
\frac{m-i}{m}\frac{B(i,m-i)}{N-1}
+\frac{i}{m}\frac{B(m-i,i)}{N-1}
=\frac{B(i,m-i)}{N-1}.
\]
QED.

## Lemma 3: restriction through hidden labels is exactly consistent

Let a visible sampled block `C` of size `b` lie inside a hidden block `B` of size `m>=b`, and let `A subset C`, `|A|=i`, be a target visible side. Conditional on one active opportunity, the probability of inducing the particular visible split `A | C\A` is

\[
\boxed{
\frac1{N-1}B(i,b-i),
}
\tag{4.5}
\]

independent of the hidden size `m`.

**Proof.** For an oriented hidden side `U` with `U cap C=A` and `|U|=s`, there are `binom(m-b,s-i)` choices. Each relevant unordered hidden split is represented exactly once by orienting the side whose intersection with `C` is `A`. Thus Lemma 2 gives

\[
\frac1{N-1}
\sum_{s=i}^{m-b+i}\binom{m-b}{s-i}B(s,m-s).
\]

Insert the beta integral and write `x=s-i`:

\[
\begin{aligned}
\sum_s\binom{m-b}{s-i}B(s,m-s)
&=\int_0^1t^{i-1}(1-t)^{b-i-1}
\sum_{x=0}^{m-b}\binom{m-b}{x}t^x(1-t)^{m-b-x}\,dt\\
&=B(i,b-i).
\end{aligned}
\]
This proves (4.5). QED.

The exact CTCS(infinity) restriction generator assigns the particular split `A|C\A` rate `B(i,b-i)`. Thus one active Schweinsberg-sized sweep plus anchor deletion is an exact discrete beta-kernel compiler, up to the deterministic factor `1/(N-1)`.

# Method #9 — randomize sparsely: the C010 finite discrete model

The one-opportunity compiler by itself is too close to an Eulerized binary CTCS sampler to be a persuasive new finite model. I therefore use **two independent sweep opportunities per block per raw generation**, allowing genuine finite nonlinear interaction between the two population events while keeping that interaction asymptotically rare.

For each `N`, put

\[
p_N:=\frac1{2N^2}.
\tag{9.1}
\]

At every raw generation and independently for every current nonsingleton fragmentation block `B`:

1. start an auxiliary partition of `B` into singletons;
2. for each of two independent opportunities `j=1,2`, activate it with probability `p_N`;
3. if opportunity `j` is active, draw `K_j ~ pi_N`, draw a uniform `K_j`-subset `S_j subset [N]`, and merge all current auxiliary blocks that intersect `S_j cap B` (if fewer than two labels are hit, this does nothing);
4. after both opportunities, choose a uniform anchor `a in B`; let `M_a` be its auxiliary connected/merger component;
5. if `M_a={a}`, leave `B` unchanged; otherwise replace `B` by the two unordered children
   \[
   M_a\setminus\{a\},\qquad B\setminus(M_a\setminus\{a\}).
   \]
6. descendant fragmentation blocks repeat independently at later raw generations.

The output is **always binary**, but when both sweep opportunities are active their merger hyperedges can overlap before anchor deletion. This is a finite interaction absent from the one-event Eulerized kernel.

Give one raw generation physical duration

\[
\boxed{
\Delta_N:=\frac{2p_N}{N-1}=\frac1{N^2(N-1)}.
}
\tag{9.2}
\]

Call the accelerated partition path

\[
\widehat\Pi_N(t):=\Pi_N(\lfloor t/\Delta_N\rfloor).
\]

# Method #30 — identify the exact scale at which nonlinear sweep interactions vanish

The scaling condition is transparent. Two opportunities are simultaneously active in one hidden block with probability `p_N^2`. Relative to one unit of physical time, the nonlinear interaction error therefore has size

\[
\frac{p_N^2}{\Delta_N}
=\frac{p_N(N-1)}2.
\tag{30.1}
\]

Thus the entire proof below works for the broader regime

\[
\boxed{p_NN\to0.}
\tag{30.2}
\]

The concrete choice `p_N=1/(2N^2)` gives

\[
\frac{p_N^2}{\Delta_N}
=\frac{N-1}{4N^2}<\frac1{4N}\to0.
\tag{30.3}
\]

At the borderline `p_N asymp c/N`, this proof route no longer suppresses the two-active interaction relative to the physical time scale. I record that as the exact obstruction of this argument, not as a theorem that no CTCS limit can hold at that scale.

## Theorem C010

For the paired sweepstakes-anchor hierarchy above with `p_N=1/(2N^2)` and `Delta_N=1/[N^2(N-1)]`,

\[
\boxed{
\widehat\Pi_N\Longrightarrow\Pi_{\rm CTCS(\infty)}
}
\tag{C10.1}
\]

in the projective finite-restriction Skorokhod topology. In particular, for every fixed `k`,

\[
\widehat\Pi_N^{[k]}\Longrightarrow\Pi_{\rm CTCS}^{[k]}
\]

in Skorokhod `J_1`, and the compatible collection of all finite restrictions converges to the complete exchangeable-partition genealogy encoding CTCS(infinity).

### Proof

Fix `k`. Condition on the complete hidden `N`-label fragmentation history at the beginning of a raw generation. Every visible block `C` in the current restriction `rho` is the intersection of `[k]` with a unique hidden block `B`.

Consider a target transition `rho -> rho'` consisting of one particular CTCS split `A | C\A` inside one visible block, with `|C|=b` and `|A|=i`.

For the relevant hidden block, the event that **exactly one** of its two opportunities is active has probability

\[
2p_N(1-p_N).
\]

Conditional on exactly one active opportunity, Lemma 3 gives the target visible split probability

\[
\frac{1}{N-1}B(i,b-i).
\]

Hence its exactly-one-active contribution is

\[
\frac{2p_N(1-p_N)}{N-1}B(i,b-i)
=\Delta_N(1-p_N)B(i,b-i).
\tag{C10.2}
\]

If both opportunities in that hidden block are active, their total probability is `p_N^2`; whatever nonlinear merger they create can therefore alter any particular visible transition probability by at most `p_N^2`.

There are at most `k` hidden blocks touching `[k]`. Different hidden blocks update independently. A visible split in one block has probability `O_k(Delta_N)` uniformly in the hidden block size by Lemma 3; simultaneous visible changes in two distinct visible blocks are therefore `O_k(Delta_N^2)`. Multiplying (C10.2) by the probability that all other visible blocks stay fixed changes it only by `O_k(Delta_N^2)`. Since `p_N Delta_N <= p_N^2` and `Delta_N^2 <= p_N^2` for large `N`, we obtain uniformly over all hidden histories

\[
\boxed{
\Pr(\rho\to\rho'\mid\mathcal F_N)
=\Delta_NQ^{(k)}(\rho,\rho')+O_k(p_N^2)
}
\tag{C10.3}
\]

for every single CTCS transition. The total probability of transitions not present in the CTCS Euler kernel is also `O_k(p_N^2)`, and the diagonal estimate follows by row summation because the finite partition state space is fixed once `k` is fixed. Therefore, in total variation uniformly over hidden histories,

\[
\boxed{
P_N^{(k)}(\rho,\cdot)
=igl(I+\Delta_NQ^{(k)}\bigr)(\rho,\cdot)+O_k(p_N^2).
}
\tag{C10.4}
\]

For all sufficiently large `N`, `I+Delta_N Q^{(k)}` is a stochastic matrix because the fixed finite-state CTCS exit rates are bounded and `Delta_N -> 0`. Couple each raw restricted step maximally to this Euler chain, conditionally on the complete hidden history. On a physical interval `[0,T]` there are at most `T/Delta_N+1` raw steps, so the union bound gives

\[
\Pr(\text{coupling fails before }T)
\le C_k(T+1)\frac{p_N^2}{\Delta_N}
=O_k(T/N)\to0
\tag{C10.5}
\]

by (30.3).

It remains to identify the Euler limit. At a nonabsorbing partition state `rho`, let

\[
\lambda(\rho):=-Q^{(k)}(\rho,\rho).
\]

In the Euler chain, the number `G_N` of raw steps before the next jump is geometric with success probability `Delta_N lambda(rho)`. Thus, for every `t>=0`,

\[
\Pr(\Delta_NG_N>t)
=(1-\Delta_N\lambda(\rho))^{\lfloor t/\Delta_N\rfloor}
\longrightarrow e^{-\lambda(\rho)t},
\]

so

\[
\Delta_NG_N\Longrightarrow {\rm Exp}(\lambda(\rho)).
\]

Conditioned on a jump, the next state is exactly

\[
\frac{Q^{(k)}(\rho,\rho')}{\lambda(\rho)}.
\]

A fragmentation of `k` labels can make at most `k-1` visible jumps before reaching singletons. Therefore successive holding times and jump destinations can be coupled, one jump at a time, to those of the CTCS restriction. This proves

\[
\boxed{
\widehat\Pi_N^{[k]}\Longrightarrow\Pi_{\rm CTCS}^{[k]}
}
\tag{C10.6}
\]

in `J_1` on every bounded time interval, hence in the standard local Skorokhod topology on `[0,infinity)`.

Finally use the same explicit projective metric retained throughout R11:

\[
d_{\rm proj}(\omega,\eta)
=\sum_{k\ge1}2^{-k}
\left(1\wedge d_{J_1,k}(\omega^{[k]},\eta^{[k]})\right).
\tag{C10.7}
\]

Given `epsilon>0`, choose `K` so the deterministic coordinate tail `sum_{k>K}2^{-k}<epsilon/2`. Couple the `[K]` restrictions by the preceding construction; this simultaneously couples every smaller restriction. Their contribution to (C10.7) converges to zero in probability, while the remaining tail is deterministically below `epsilon/2`. Hence the full consistent partition paths converge in distribution in `d_proj`, proving (C10.1). Pair-separation times in the partition process are the branchpoint heights, so the full labelled genealogy is recovered. This is the source's CTCS(infinity) exchangeable-partition object, not a weaker marginal limit. QED.
