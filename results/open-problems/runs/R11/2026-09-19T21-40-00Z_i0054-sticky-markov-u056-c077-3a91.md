## 2. Starting point: harmonic-grid marks, but dependent colors

For each `N >= 2`, set

\[
x_j=\frac jN,\qquad 1\le j\le N-1,
\]

and give each current nonsingleton block an independent Poisson clock of type `j` with rate

\[
\lambda_{N,j}=\frac{N}{2j(N-j)}.
\tag{2.1}
\]

As in C001,

\[
\sum_{j=1}^{N-1}\lambda_{N,j}
=H_{N-1}.
\tag{2.2}
\]

The change is at a clock ring. Instead of iid Bernoulli(`x_j`) colors, draw a fresh stationary binary Markov field

\[
Y_1,\ldots,Y_N\in\{0,1\}
\]

along the ambient label order. Its stationary law is

\[
\pi_x(1)=x,\qquad \pi_x(0)=1-x,
\]

and its one-step transition kernel is

\[
K_{x,\varepsilon}(a,b)
=(1-\varepsilon)\pi_x(b)+\varepsilon\mathbf 1_{\{a=b\}}.
\tag{2.3}
\]

For a current block `B`, split `B` into its two `Y`-color classes when both are nonempty; otherwise the mark is invisible. Different rings and different blocks use fresh independent fields.

U056 allows any deterministic persistence schedule `0 <= eps_N < 1` satisfying

\[
\boxed{\varepsilon_N H_{N-1}\longrightarrow0.}
\tag{2.4}
\]

C077 takes the concrete choice

\[
\boxed{\varepsilon_N=1/N.}
\tag{2.5}
\]

This is a finite discrete random hierarchy on `[N]`; every visible split is binary, while branch times are the Poisson split times as in CTCS.

## 3. Method #1 — CHANGE THE CATEGORY: iid paintboxes to a one-dimensional Markov random field

Write `Pi` for the rank-one stochastic matrix with both rows equal to `pi_x`. Then

\[
K=\varepsilon I+(1-\varepsilon)\Pi,
\qquad
\Pi^2=\Pi,
\qquad
I\Pi=\Pi I=\Pi.
\]

Therefore, for every integer `d>=1`,

\[
\boxed{
K^d=\varepsilon^d I+(1-\varepsilon^d)\Pi.
}
\tag{3.1}
\]

The color dependence is genuine at finite N, but its entire memory across a label gap of length `d` is the single scalar `eps^d`.

This moves the construction out of the independent-paintbox category while preserving an exact tractable coupling to it.

## 4. Method #13 — FIND WHAT ONLY DECREASES: the memory coefficient contracts with label distance

Fix visible ambient labels

\[
r_1<r_2<\cdots<r_m.
\]

Because of (3.1), the transition from `Y_{r_q}` to `Y_{r_{q+1}}` can be generated by the following refresh representation, where

\[
d_q=r_{q+1}-r_q:
\]

- with probability `1-eps^{d_q}`, redraw from `pi_x`;
- with probability `eps^{d_q}`, retain the preceding state.

Couple this to iid Bernoulli(`x`) colors `Z_1,...,Z_m`: start with `Y_{r_1}=Z_1`, and whenever the Markov chain refreshes use the same fresh `pi_x` sample as `Z_{q+1}`. A discrepancy can only be introduced at a nonrefresh step. Hence

\[
\boxed{
\left\|
\mathcal L(Y_{r_1},\ldots,Y_{r_m})-
\pi_x^{\otimes m}
\right\|_{\rm TV}
\le
\sum_{q=1}^{m-1}\varepsilon^{d_q}
\le(m-1)\varepsilon.
}
\tag{4.1}
\]

This bound is uniform in the bias `x` and in the actual visible labels.

Now let `V` be a visible block, `|V|=m`, and let `A|V\A` be a specified unordered nontrivial split, `|A|=i`. Let

\[
q^{\rm SM}_{N}(V,A)
\]

be its C077/U056 split rate and let

\[
q^{\rm iid}_{N}(m,i)
\]

be the C001 harmonic-grid iid-paintbox split rate. Applying (4.1) to the split event at every grid mark and summing the mark intensities gives

\[
\boxed{
\left|
q^{\rm SM}_{N}(V,A)-q^{\rm iid}_{N}(m,i)
\right|
\le
(m-1)\varepsilon_N H_{N-1}.
}
\tag{4.2}
\]

The iid comparator is exactly

\[
q^{\rm iid}_{N}(m,i)
=
\frac1N\sum_{j=1}^{N-1}
\left(\frac jN\right)^{i-1}
\left(1-\frac jN\right)^{m-i-1}.
\tag{4.3}
\]

For fixed `m,i`, this is an ordinary Riemann sum, so

\[
q^{\rm iid}_{N}(m,i)
\longrightarrow
\int_0^1x^{i-1}(1-x)^{m-i-1}\,dx
=B(i,m-i).
\tag{4.4}
\]

Combining (2.4), (4.2), and (4.4),

\[
\boxed{
q^{\rm SM}_{N}(V,A)
\longrightarrow B(i,m-i)
}
\tag{4.5}
\]

for every fixed visible block and specified split.

The point is that the raw mark intensity grows like `log N`; one must kill the spatial dependence faster than `1/H_N`, not merely have `eps_N -> 0`. The exact contraction (3.1) identifies the correct sufficient scale.

## 5. Method #27 — SWAP THE QUANTIFIERS: one persistence schedule works for every fixed restriction

The construction chooses the single sequence `eps_N` first; there is no `k`-dependent tuning. Fix any `k`. Define

\[
a_{N,k}
=
\max_{2\le m\le k}\max_{1\le i<m}
\left|q^{\rm iid}_{N}(m,i)-B(i,m-i)\right|.

Because this maximum is over finitely many Riemann sums,

\[
a_{N,k}\to0.

By (4.2), every specified split coordinate occurring in the `[k]` restriction has error at most

\[
\boxed{
r_{N,k}=a_{N,k}+(k-1)\varepsilon_N H_{N-1}\to0.
}
\tag{5.1}
\]

Thus the same global schedule simultaneously fools **every** fixed finite restriction.

## 6. Exact lumping of hidden labels

A possible concern is that the dependent ambient coloring could leave hidden state after restriction. It does not, because each mark uses a fresh Markov field.

Suppose a full block contains a visible subset `V`. If a full split is invisible on `V`, then all labels of `V` lie in one daughter. That daughter starts fresh Poisson clocks and every future clock ring draws a fresh ambient Markov field with the same global-N law. The visible split hazard therefore does not depend on which hidden labels happen to share the carrier block.

Consequently the restriction to `[k]` is itself a time-homogeneous finite-state CTMC on partitions of `[k]`. It need not be exchangeable at finite N — its rates can depend on the actual visible label positions — but its generator has the explicit coordinates (4.5).

Different visible blocks lie in different full blocks and therefore have independent future clocks, exactly as required for the fragmentation generator.

\tag{7.1}

\tag{7.2}

\[
M_k r_{N,k}/\Lambda_k.

\[
\boxed{

\mathcal L(\Pi_N^{[k]}|_{[0,T]})-
