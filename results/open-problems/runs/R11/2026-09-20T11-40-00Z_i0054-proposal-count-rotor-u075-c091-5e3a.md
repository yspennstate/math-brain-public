## 4. What the three new-method moves did

### #10 — DERANDOMIZE

U073 drew a fresh uniform phase `J in Z/d_N` at every active proposal. I tried to replace those independent draws by a deterministic rotor. The successful version uses **no extra dither randomness at all**: the rotor advances on every already-existing harmonic proposal mark.

### #22 — READ THE FAILURES

Two naive derandomizations fail for a structural reason.

1. If the rotor advances only on active proposals, the active proposal rate is `W_N -> log 2`. A fixed time interval therefore contains only `O(1)` active marks, so a rotor with `d_N -> infinity` never samples its cycle.
2. If one chooses one random initial phase and then advances deterministically only at active marks, each marginal phase is uniform but the phases remain almost frozen over any fixed number of active marks as `d_N -> infinity`. This leaves persistent temporal correlations instead of the fresh-dither dynamics.

The failure points directly to the missing resource: **many null/inactive raw proposals**. The total harmonic proposal rate is `H_{N-1}~log N`, much larger than the active-window rate.

### #28 — REPLACE FOR ALL WITH TYPICAL

The phase does not need to be equidistributed at every deterministic raw time. It only needs to be nearly uniform at the **typical times when an active proposal occurs**. Between such times there are geometrically many all-purpose harmonic proposals. Modulo a slowly growing rotor length, that geometric waiting count is almost uniform. This converts the failed pointwise scan requirement into a successful typical-event statement.

# 6. The proposal-count rotor model

Fix an integer `d_N>=2`. Every current nonsingleton clade carries a phase

\[
R\in\mathbb Z/d_N\mathbb Z.
\]

The root starts with `R=0`.

Each clade has the ordinary independent harmonic proposal clocks (5.3). At **every** proposal, active or inactive, first update deterministically

\[
R\leftarrow R+1\pmod{d_N}.
\tag{6.1}
\]

Then:

- if `s notin S_N`, color each label independently red with the source bias
  \[
  p_{N,s}=x_s;
  \tag{6.2}
  \]
- if `s in S_N`, color each label independently red with
  \[
  p_{N,s,R}
  =
  \sigma\!\left(
     L\left\{b_N\alpha_{N,s}+\frac{R}{d_N}\right\}
  \right).
  \tag{6.3}
  \]

If both colors occur, split the clade into its two color classes.

**Phase inheritance:** both children inherit the updated parent phase `R`. Their future proposal clocks are fresh and independent, as usual.

This inheritance rule is essential. It makes an invisible hidden-only split indistinguishable on a fixed restriction from a null visible proposal: the phase has already advanced once, the visible carrier inherits that same phase, and Poisson memorylessness replaces the clocks by fresh clocks of the same law.

The model is exchangeable in labels because every coloring is iid conditional on the mark and phase.

# 7. Exact geometric-modulo lemma

Consider one carrier lineage and ignore colors for the moment. Superpose all harmonic proposal clocks. Proposal marks are iid with

\[
\Pr(S=s)=\frac{\lambda_{N,s}}{H_{N-1}}.
\tag{7.1}
\]

A mark is active with probability `q_N` from (5.7). Let `K` be the number of all raw proposals from one active mark to the next, counting the terminal active proposal. Then

\[
\Pr(K=m)=q(1-q)^{m-1},\qquad m\ge1,
\tag{7.2}
\]

with `q=q_N`.

Moreover, `K` is independent of the terminal active mark `s`: for `s in S_N`,

\[
\Pr(K=m,S=s)
=(1-q)^{m-1}\frac{\lambda_{N,s}}{H_{N-1}}
=\Pr(K=m)\frac{\lambda_{N,s}}{W_N}.
\tag{7.3}
\]

Therefore, if the incoming rotor phase is `r`, the next active phase is

\[
r+K\pmod d.
\]

The residue law of `K mod d` is

\[
\mu_{q,d}(j)
=
\frac{q(1-q)^{j-1}}{1-(1-q)^d},
\qquad j=1,\ldots,d.
\tag{7.4}
\]

### Lemma 7.1

If `qd<=1`, then

\[
\boxed{
\|\mu_{q,d}-U_d\|_{\rm TV}\le\frac{qd}{2},
}
\tag{7.5}
\]

where `U_d` is uniform on `Z/dZ`.

### Proof

Put `z=qd`. For every `1<=j<=d`, Bernoulli's inequality gives

\[
(1-q)^{j-1}\ge1-(j-1)q\ge1-z.
\tag{7.6}
\]

Also

\[
1-(1-q)^d
\le dq
\tag{7.7}
\]

and the first two terms of the binomial expansion give

\[
1-(1-q)^d
\ge dq-\binom d2q^2
\ge dq(1-z/2).
\tag{7.8}
\]

Hence, writing `u=1/d`,

\[
1-z
\le
\frac{\mu_{q,d}(j)}{u}
\le
\frac1{1-z/2}.
\tag{7.9}
\]

For `0<=z<=1`,

\[
\frac1{1-z/2}-1=\frac{z}{2-z}\le z.
\]

Thus

\[
|\mu_{q,d}(j)-1/d|\le\frac zd
\]

for every residue. Summing and dividing by two proves (7.5). `square`

The bound is uniform in the incoming phase because translating a probability measure on the cyclic group preserves total variation.

# 9. Fresh dither generator estimate, written here for completeness

Fix a specified unordered split with side sizes `i,j>=1`. Define

\[
H_{i,j}(t)=
\sigma(Lt)^i(1-\sigma(Lt))^j
+
\sigma(Lt)^j(1-\sigma(Lt))^i,
\qquad t\in[0,1).
\tag{9.1}
\]

For an active harmonic mark `s`, the fresh-dither split probability averages

\[
\frac1{d_N}\sum_{r=0}^{d_N-1}
H_{i,j}\!\left(\left\{b_N\alpha_{N,s}+\frac r{d_N}\right\}\right).
\tag{9.2}
\]

For every periodic bounded-variation function `H`, every shift `theta`, and every `d`, the elementary cyclic-grid discrepancy bound gives

\[
\left|
\frac1d\sum_{r=0}^{d-1}H(\{\theta+r/d\})
-
\int_0^1H(t)dt
\right|
\le\frac{\operatorname{Var}_{\mathbb T}(H)}d.
\tag{9.3}
\]

Thus the active split-rate error is `O_{i,j}(1/d_N)`, uniformly in **arbitrary** `b_N`.

The continuum identity is exact because

\[
\frac{dx}{2x(1-x)}=\frac12\,d\ell(x)=\frac L2\,dt.
\tag{9.4}
\]

Consequently the active continuum contribution after uniform phase averaging, plus the unchanged outside contribution, is exactly

\[
B(i,j)=\int_0^1x^{i-1}(1-x)^{j-1}dx
=\frac{(i-1)!(j-1)!}{(i+j-1)!}.
\tag{9.5}
\]

The remaining harmonic-grid rectangle error is `O_{i,j}(N^{-1})`, since all integrands are smooth on the compact active interval and polynomial outside it. Hence for every fixed specified split,

\[
q^{\mathrm{fresh}}_N(i,j)
=B(i,j)+O_{i,j}(d_N^{-1}+N^{-1}).
\tag{9.6}
\]

For a fixed restriction `[k]` there are only finitely many partition states and specified split transitions. Therefore the complete visible generator differs from the CTCS generator by

\[
O_k(d_N^{-1}+N^{-1})
\]

entrywise and in row-sum norm. Standard common uniformization of finite-state continuous-time chains yields, for every finite `T`,

\[
\boxed{
\|\mathcal L(\Pi^{[k]}_{N,\mathrm{fresh}}|_{[0,T]})
-\mathcal L(\Pi^{[k]}_{\rm CTCS}|_{[0,T]})\|_{\rm TV}
\le C_{k,T}(d_N^{-1}+N^{-1}).
}
\tag{9.7}
\]

This is a whole-path estimate, not a one-time distribution estimate.
