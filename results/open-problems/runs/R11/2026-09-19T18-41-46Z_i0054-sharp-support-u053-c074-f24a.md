## 3. The full-translation base model, notation, and the finite generator vector

Retain the arithmetic base from U051/C072. Let

- `d_N` be the least odd prime at least `max(3, ceil(log(N+2)))`;
- `p_N` be the least prime `p >= max(N,d_N+1)` satisfying `p == 2 (mod d_N)`;
- `phi_N(x)=x^(d_N)` on `F_{p_N}`.

Dirichlet gives existence of `p_N`; because `p_N-1 == 1 (mod d_N)`, `gcd(d_N,p_N-1)=1`, so `phi_N` is a permutation. Also `d_N -> infinity`, `p_N -> infinity`, and `d_N=O(log p_N)`.

For a translation `t in F_p`, threshold `u in {1,...,p-1}`, and ambient leaf `ell`, define the binary mask

`M_{t,u}(ell) = 1{ rep((t+ell)^d mod p) < u }`.

C072 runs every `(t,u)` clock at rate

`1/[2u(p-u)]`.

It is convenient to absorb the uniform `1/p` translation average into a per-translation vector. For a finite visible set `V` and an unordered specified split `A|B` of `V`, define

`g_t(A|B) = sum_{u=1}^{p-1} p/[2u(p-u)] * 1{M_{t,u} realizes A|B, in either color orientation}`.

Then the full-translation C072 split rate is exactly

`q_N^full(A|B) = (1/p) sum_{t in F_p} g_t(A|B)`.        (3.1)

For a cutoff `K`, include one coordinate for every unordered nontrivial bipartition of every subset `V subseteq [K]`, `|V|>=2`. The dimension is

`D_K = sum_{m=2}^K binom(K,m)(2^(m-1)-1)`

and direct binomial algebra gives

`D_K = (3^K - 2^(K+1) + 1)/2`.                         (3.2)

Let `G_{N,K}(t) in Q^{D_K}` be the vector of all corresponding `g_t` coordinates and let

`Q_{N,K} = (1/p_N) sum_t G_{N,K}(t)`.                  (3.3)

Every entry is rational.

## 4. U053 — the sharp translation-support theorem

### Theorem U053

Consider the weighted threshold-translation architecture above, with the C072 power-permutation masks. Let `L_N` denote an upper bound on the number of translations carrying positive clock weight.

**(Sufficiency.)** For *every* integer sequence `L_N -> infinity`, there exists a deterministic choice of at most `L_N` active translations and positive rational weights such that the resulting discrete tree has

`Pi_N^[k] => Pi_CTCS^[k]`

in path total variation on every finite time interval, hence in Skorokhod `J_1`, for every fixed `k`; consequently the entire projective partition process converges to `CTCS(infinity)`.

**(Necessity.)** If the number of active translations is bounded along an infinite subsequence, then the model cannot converge to CTCS on all fixed restrictions. Thus, within this architecture, the sharp support condition is simply

`L_N -> infinity`.                                    (4.1)

In particular the `p^(1/2)` barrier suggested by the elementary incomplete-sum proof of C073 is not structural; it is an equal-weight-interval completion artifact.

### Proof: necessity

Fix a visible block of size `k`. For one active translation `t`, the values `phi(t+ell)` on the `k` distinct labels are distinct. They therefore define one total order. Sweeping `u=1,...,p-1` can produce exactly the `k-1` unordered cuts between consecutive ranks in that order and no other bipartitions.

With at most `L` active translations, at most

`L(k-1)`                                                   (4.2)

of the

`2^(k-1)-1`                                                (4.3)

unordered specified root splits can have positive rate.

Suppose `L_N <= L` along an infinite subsequence. Choose fixed `k` with

`2^(k-1)-1 > L(k-1)`.                                    (4.4)

For every `N` in that subsequence at least one specified `k`-split has zero rate. Since the set of specified `k`-splits is finite, one fixed split is absent along a further infinite subsequence. In CTCS every specified `i|(k-i)` split has rate

`B(i,k-i) = (i-1)!(k-i-1)!/(k-1)! > 0`.                 (4.5)

Hence even the first visible root-split law cannot converge along that subsequence. This proves necessity.

### Proof: exact finite-dimensional compression

Fix `N,K`. By (3.3), `Q_{N,K}` belongs to the convex hull of the `p_N` rational vectors `G_{N,K}(t)` in `R^{D_K}`. Caratheodory's theorem therefore gives a representation

`Q_{N,K} = sum_{t in S} lambda_t G_{N,K}(t)`,            (4.6)

with

`lambda_t >= 0`, `sum lambda_t=1`, `|S| <= D_K+1`.      (4.7)

The weights may be taken rational. One clean way to see this is to consider the rational polytope

`P = {lambda >=0 : sum lambda_t=1, sum lambda_t G(t)=Q_{N,K}}`.

It is nonempty because the uniform vector `lambda_t=1/p_N` lies in it. Any basic feasible vertex is rational and has support at most `D_K+1`. Thus no limiting or approximate convex argument is being used here: the finite visible generator is reproduced exactly.

For determinism, order the translations by their standard representatives. Among all nonnegative exact representations choose first one with minimum support; break ties by lexicographic support and then by lexicographic basic feasible weight vector. This is a finite rational rule.

### Proof: arbitrary divergent budget

Given any prescribed `L_N -> infinity`, define

`K_N = max( {1} union {2<=k<=N : D_k+1 <= L_N} )`.       (4.8)

Because every fixed `D_k` is finite and `L_N -> infinity`, we have `K_N -> infinity`.

Apply (4.6) to `K=K_N` and retain only its at most `D_{K_N}+1 <= L_N` translations. For each retained `t` and every threshold `u`, run the clock at rate

`c_N(t,u) = p_N lambda_t/[2u(p_N-u)]`.                   (4.9)

The total proposal rate per active clade is still exactly

`sum_{t,u} c_N(t,u)
 = (sum_t lambda_t) * p_N/2 * sum_{u=1}^{p_N-1} 1/[u(p_N-u)]
 = H_{p_N-1}`,                                           (4.10)

using `sum_u 1/[u(p-u)] = 2H_{p-1}/p`.

At least one `lambda_t` is positive. For any two distinct ambient leaves `x,y`, that retained translation has `phi(t+x) != phi(t+y)` because `phi` is a permutation. Some threshold lies between the two representatives, so the pair has a positive-rate separating proposal. Thus every nonsingleton clade has positive total genuine-split rate, and the finite tree reaches singletons almost surely.

By construction, for **every** subset of `[K_N]` and **every** specified split of that subset, the C074 split rate equals the C072 split rate exactly. Hence the projected partition process on `[K_N]` has exactly the same finite-state CTMC generator as C072, and therefore exactly the same path law.

Fix `k`. Eventually `k<=K_N`, so eventually

`Law(Pi_{N,074}^[k]) = Law(Pi_{N,072}^[k])`             (4.11)

as complete càdlàg partition-valued paths, not merely at one time or at the root.

It remains only to recall why the base C072 restriction tends to CTCS. For fixed visible dimension `m`, eventually `d_N>=m`. A nonzero Fourier mode of the translated power vector has phase

`P_h(t)=sum_j h_j(t+a_j)^(d_N)`.

If this polynomial were constant, vanishing of its top `m` coefficients would give the Vandermonde system `sum_j h_j a_j^r=0`, `r=0,...,m-1`, forcing `h=0`. Thus every nonzero mode is nonconstant. The classical Weil polynomial exponential-sum bound plus Erdos--Turan--Koksma gives fixed-dimensional discrepancy tending to zero because `d_N=O(log p_N)`. Summing threshold-box errors against the harmonic weights yields, for every fixed specified `i|j` split,

`q_{N,072}(i,j) -> B(i,j)`.                              (4.12)

Hidden labels lump out exactly, so each fixed restriction is a finite-state CTMC. Entrywise generator convergence and common-clock uniformization imply path total-variation convergence on every finite time interval. Combining this with (4.11) proves the sufficiency assertion and the full projective `CTCS(infinity)` limit.

This completes U053.

## 8. Prior art and novelty boundary

Tchakaloff-type positive quadrature/discretization theorems are a close general analogue; modern expositions emphasize exact positive discretization on finite-dimensional function spaces. I make **no novelty claim** for Caratheodory, rational polytope vertices/basic feasible solutions, Tchakaloff quadrature, Weil bounds, or Erdos--Turan--Koksma.
