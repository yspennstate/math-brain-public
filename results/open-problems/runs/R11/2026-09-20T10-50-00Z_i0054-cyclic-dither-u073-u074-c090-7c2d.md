# 5. U074 — a deterministic aliasing obstruction

Let

\[
S_N=\{s:1/2\le s/N<4/5\},
\qquad M_N=|S_N|.
\tag{5.1}
\]

For a complexity budget `B`, define

\[
\boxed{
\rho_N(B)=
\min_{1\le b\le B}
\max_{s\in S_N}
\|b\alpha_{N,s}\|_{\mathbb T}.
}
\tag{5.2}
\]

This is nonincreasing in `B`.

## 5.1 Simultaneous Dirichlet collapse

Apply the simultaneous Dirichlet approximation theorem to the `M_N` real numbers `alpha_{N,s}` with approximation parameter `Q=N`.  There is an integer

\[
1\le b_N\le N^{M_N}
\tag{5.3}
\]

such that

\[
\boxed{
\max_{s\in S_N}
\|b_N\alpha_{N,s}\|_{\mathbb T}\le\frac1N.
}
\tag{5.4}
\]

Equivalently,

\[
\rho_N(N^{M_N})\le N^{-1}.
\tag{5.5}
\]

Because `M_N<=N`, this schedule has

\[
b_N\le N^N=\exp(O(N\log N)).
\tag{5.6}
\]

The selected `b_N` necessarily tends to infinity.  Indeed, if a fixed positive integer `b` occurred along an infinite subsequence, take active grid points `s_N/N -> 3/5`.  Then (5.4) would force

\[
b\log_4(3/2)\in\mathbb Z,
\]

which is impossible: `(3/2)^b=4^m` would equate a number having a prime factor `3` to a pure power of `2`.

## 5.2 Compactified seam mixture

Write

\[
t_{N,s}=\{b_N\alpha_{N,s}\}\in[0,1).
\]

By (5.4), every active `t_{N,s}` lies either in `[0,1/N]` or in `[1-1/N,1)`.  Let

\[
W_N=\frac1N\sum_{s\in S_N}A(s/N)
\longrightarrow\int_I A(x)dx=\frac L2,
\tag{5.7}
\]

and let `w_N` be the proportion of this `A`-weight that lies on the first side `[0,1/N]`.  Passing to a subsequence,

\[
w_N\to w\in[0,1].
\tag{5.8}
\]

For every fixed `H_{i,j}`, one-sided continuity gives

\[
\frac1N\sum_{s\in S_N}A(s/N)H_{i,j}(t_{N,s})
\longrightarrow
\frac L2\big[wH_{i,j}(0)+(1-w)H_{i,j}(1-)\big].
\tag{5.9}
\]

If the deterministic hierarchy converged to CTCS for every specified split, the active target from (4.8) would instead be

\[
\frac L2\int_0^1H_{i,j}(t)dt.
\tag{5.10}
\]

So one and the same `w` would have to satisfy

\[
wH_{i,j}(0)+(1-w)H_{i,j}(1-)
=
\int_0^1H_{i,j}(t)dt
\tag{5.11}

for every `i,j`.

## 6.1 Uniform shifted-grid discrepancy lemma

Regard a bounded-variation function `H` on `[0,1)` as a right-continuous function on the circle, allowing a jump at the seam.  For every `d>=1` and every phase `theta`,

\[
\boxed{
\left|
\frac1d\sum_{r=0}^{d-1}H(\{\theta+r/d\})
-
\int_0^1H(t)dt
\right|
\le
\frac{\operatorname{Var}_{\mathbb T}(H)}d.
}
\tag{6.5}
\]

**Proof.**  The `d` sample points are the left endpoints of `d` half-open arcs of length `1/d` that partition the circle.  On one such arc `C`,

\[
\left|
\frac1dH(t_C)-\int_C H(t)dt
\right|
\le
\frac1d\operatorname{Var}_C(H).
\]

Sum over the arcs.  Their variations sum to at most the total circle variation.  This proves (6.5), including the seam jump.  `square`

Each fixed `H_{i,j}` from (4.3) has finite circle variation.  Therefore, **uniformly in `b_N` and in every grid mark `s`**, averaging over the fresh dither gives

\[
\mathbb E_J H_{i,j}(T_{N,s,J})
=
\int_0^1H_{i,j}(t)dt
+O_{i,j}(d_N^{-1}).
\tag{6.6}
\]

## 6.2 Specified split-rate convergence

The active part of the specified `i|j` split rate is

\[
q_N^{\rm act}(i,j)
=
\frac1N\sum_{s\in S_N}
A(s/N)\,
\mathbb E_JH_{i,j}(T_{N,s,J}).
\tag{6.7}
\]

Since `A` is smooth and bounded on `I`, (6.6) gives

\[
q_N^{\rm act}(i,j)
=
\left[\frac1N\sum_{s\in S_N}A(s/N)\right]
\int_0^1H_{i,j}(t)dt
+O_{i,j}(d_N^{-1}).
\tag{6.8}
\]

The bracket is a standard Riemann sum,

\[
\frac1N\sum_{s\in S_N}A(s/N)
=
\int_I A(x)dx+O(N^{-1}).
\tag{6.9}
\]

By (4.8), the main term in (6.8) is exactly the active continuum beta-generator contribution.  Outside `I`, the bias is the identity `p=x_s`, so the ordinary smooth Riemann sum contributes its correct continuum piece with error `O_{i,j}(N^{-1})`.  Therefore

\[
\boxed{
q_N(i,j)=B(i,j)+O_{i,j}(d_N^{-1}+N^{-1})

\tag{6.10}

**uniformly over every integer branch-count sequence `b_N`.**

## 6.3 Exact lumpability of finite visible restrictions

Fix a visible set `[k]`.  Conditional on `(s,J)`, visible leaf colors are iid Bernoulli with parameter (6.4), independent of all hidden labels.  Proposals that change only hidden labels are null events in the visible projection.  When such a hidden-only split changes the ambient clade containing the visible block, the future proposal mechanism for that visible block has the same law because all clocks, dithers and colors are fresh and exponential clocks are memoryless.  Hence the visible projection is exactly lumpable: its transition rate for a specified visible `i|j` split is precisely (6.10), depending only on the visible block and not on its hidden companions.

Thus every fixed `[k]` restriction is a finite-state continuous-time Markov fragmentation chain.  Since there are finitely many possible specified splits, (6.10) gives entrywise generator convergence and a row-sum bound

\[
\|Q_N^{[k]}-Q_{\rm CTCS}^{[k]}\|_{\rm row}
\le C_k(d_N^{-1}+N^{-1}).
\tag{6.11}
\]

\boxed{
\left\|
\mathcal L(\Pi_N^{[k]}|_{[0,T]})-
\mathcal L(\Pi_{\rm CTCS}^{[k]}|_{[0,T]})

\le
