# 6. U077(A): `rho_N -> infinity` is sufficient, uniformly in `b_N`

If such an event creates a new visible carrier, the descendant inherits the same phase and restarts independent clocks with the **same two competing rates** `W_N` and `rho_N`. By the memoryless property, these nuisance interruptions do not change the probability that an active proposal beats the next shadow refresh. Formally, conditioning on any first nuisance event gives the same recursion and yields

\[
\boxed{
q_N:=\Pr(\text{active before any shadow refresh})
=\frac{W_N}{W_N+\rho_N}.

\tag{6.1}
\]

\[
q_N+\epsilon_N.
\tag{6.2}
\]
