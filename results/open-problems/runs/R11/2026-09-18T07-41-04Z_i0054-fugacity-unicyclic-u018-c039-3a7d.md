## 2. Move #9 — randomize the component count, and first test the route where it fails

C038 conditioned the ambient unicyclic pseudoforest to have exactly five components. The new idea is not another integer `R`: remove the conditioning entirely and put a Gibbs fugacity on the number of components.

Let
\[
T(z)=ze^{T(z)}
\]
be the rooted labelled-tree EGF and let
\[
U(z)
=
\frac12\left(
\log\frac1{1-T(z)}-T(z)-\frac{T(z)^2}{2}
\right)
\tag{2.1}
\]
be the connected labelled simple-unicyclic graph EGF.

For a finite simple pseudoforest `G` on `[N]` in which **every** connected component is unicyclic, write `K(G)` for its number of components. For a fugacity `alpha>0`, define the finite discrete law
\[
\boxed{
\mathbb P_{N,\alpha}(G)
=
\frac{\alpha^{K(G)}}{Z_N(\alpha)},
}
\tag{2.2}
\]
where the normalization is over all such labelled graphs. Equivalently: first sample `K` with weights
\[
A_{N,k}\alpha^k,
\qquad
A_{N,k}
=
N![z^N]\frac{U(z)^k}{k!},
\tag{2.3}
\]
then sample uniformly from the `A_{N,k}` graphs with that component count. This is a finite discrete graph law; no infinite paintbox is used to define the finite model.

Its bivariate assembly EGF is
\[
\boxed{
F(z,\alpha)=\exp\{\alpha U(z)\}.
}
\tag{2.4}
\]

### 2.1 Attack the obvious version: fixed positive fugacity fails

The dominant singularity is `rho=e^{-1}`. If
\[
x=1-z/\rho,
\]
then
\[
T(z)=1-\sqrt{2x}+O(x),
\]
and therefore
\[
\boxed{
U(z)=\frac14\log\frac1x+\kappa+O(x^{1/2})
}
\tag{2.5}
\]
for a finite constant `kappa`. Thus the effective logarithmic parameter is
\[
c=\frac{\alpha}{4}.
\]

If `alpha` tends to a fixed positive constant, the visible partition law approaches an Ewens law with fixed positive parameter `c`. After the same two-label normalization used throughout R11, on three visible labels the limiting specified rates are
\[
q_c(1\mid23)=\frac1{c+2},
\qquad
q_c(1\mid2\mid3)=\frac{c}{c+2}.
\tag{2.6}
\]
CTCS requires `1/2` and `0`. Hence **fixed positive fugacity is not a CTCS route**. This failed candidate is useful: it says exactly what must be deformed.

The successful route is the boundary
\[
\alpha_N\downarrow0.
\]

## 3. U018 — a vanishing-fugacity logarithmic-assembly compiler

The argument is useful beyond the single graph class, so I isolate the theorem.

Assume a connected labelled component EGF `C(z)` has a unique dominant singularity `rho>0` and, in a standard Delta-domain, for some `theta>0`, `eta>0`,
\[
C(z)
=
\theta\log\frac1x+\kappa+O(x^\eta),
\qquad
x=1-z/\rho,
\tag{3.1}
\]
and for every fixed `r>=1`,
\[
C^{(r)}(z)
=
\theta\Gamma(r)\rho^{-r}x^{-r}
\left(1+O(x^\eta)\right).
\tag{3.2}
\]

Let `alpha_N>0` be bounded and set
\[
c_N=\theta\alpha_N.
\]
Assume
\[
c_N\to0.
\tag{3.3}
\]

Sample an ambient labelled assembly on `[N]` with component weight `alpha_N`, i.e. EGF
\[
\exp\{\alpha_N C(z)\}.
\]

For a specified visible set partition
\[
\pi=\{B_1,\ldots,B_q\},
\qquad
|B_a|=n_a,
\qquad
b=\sum_an_a,
\]
the exact weight is
\[
A_N^{(\alpha)}(\pi)
=
(N-b)![z^{N-b}]
\alpha_N^q
\left(\prod_{a=1}^q C^{(n_a)}(z)\right)
e^{\alpha_NC(z)},
\tag{3.4}
\]
while the total weight is
\[
A_N^{(\alpha)}
=
N![z^N]e^{\alpha_NC(z)}.
\tag{3.5}
\]

### 3.1 Uniform coefficient estimate as `c_N -> 0`

From (3.1),
\[
e^{\alpha_NC(z)}
=
e^{\alpha_N\kappa}
x^{-c_N}
\left(1+O(\alpha_Nx^\eta)\right).
\tag{3.6}
\]

The main coefficient is exact:
\[
[z^N]x^{-c_N}
=
\rho^{-N}
\frac{\Gamma(N+c_N)}
{\Gamma(c_N)\Gamma(N+1)}.
\tag{3.7}
\]

For `0<c_N<=1/2`, the gamma-ratio estimate is uniform:
\[
\frac{\Gamma(N+c_N)}{\Gamma(N+1)}
=
N^{c_N-1}(1+O(N^{-1})).
\tag{3.8}
\]

The remainder in (3.6) contributes
\[
O\!\left(
\alpha_N\rho^{-N}N^{c_N-\eta-1}
\right).
\]
Relative to the main term this is
\[
O\!\left(
\alpha_N\Gamma(c_N)N^{-\eta}
\right)
=
O(N^{-\eta}),
\tag{3.9}
\]
because `alpha_N=c_N/theta` and `c Gamma(c)` stays bounded at zero. Therefore
\[
\boxed{
[z^N]e^{\alpha_NC(z)}
=
e^{\alpha_N\kappa}
\rho^{-N}
\frac{N^{c_N-1}}{\Gamma(c_N)}
(1+o(1)),
}
\tag{3.10}
\]
uniformly along the vanishing sequence.

For the numerator, (3.2) gives
\[
\alpha_N^q
\left(\prod_aC^{(n_a)}(z)\right)
e^{\alpha_NC(z)}
=
c_N^q
\left(\prod_a\Gamma(n_a)\right)
\rho^{-b}
e^{\alpha_N\kappa}
x^{-b-c_N}(1+O(x^\eta)).
\tag{3.11}
\]
Applying the same coefficient estimate at `N-b`, and using
\[
\frac{(N-b)!}{N!}N^b\to1,
\]
yields the uniform fixed-`b` restriction law
\[
\boxed{
p_N(\pi)
=
c_N^q
\frac{\Gamma(c_N)}{\Gamma(b+c_N)}
\prod_{a=1}^q\Gamma(n_a)
\,(1+o(1)).
}
\tag{3.12}
\]

So every fixed visible restriction is asymptotically Ewens with a parameter that itself tends to zero.

For the specified two-label split,
\[
\boxed{
p_{11,N}
=
\frac{c_N}{1+c_N}(1+o(1)).
}
\tag{3.13}
\]
Normalize by its **exact** value,
\[
\lambda_N=p_{11,N}^{-1}.
\tag{3.14}
\]
Then for a specified `q`-block visible refinement,
\[
\boxed{
\lambda_Np_N(\pi)
=
c_N^{q-2}
\frac{\Gamma(c_N+2)}{\Gamma(b+c_N)}
\prod_a\Gamma(n_a)
\,(1+o(1)).
}
\tag{3.15}
\]

If `q=2`, (3.15) converges to
\[
\frac{\Gamma(n_1)\Gamma(n_2)}{\Gamma(n_1+n_2)}
=
B(n_1,n_2),
\tag{3.16}
\]
the CTCS beta split rate. If `q>=3`, the factor `c_N^{q-2}` sends the rate to zero.

This proves the generator part of:

\[
\boxed{
\texttt{R11-I0054-U018 = PROVED\_AUTHOR\_SIDE}.
}
\]

U018 is deliberately stated with the explicit Delta-domain remainder hypotheses (3.1)--(3.2); I am not claiming every object called "logarithmic" in the literature automatically satisfies the needed uniform form.

## 4. Move #13 — the exact monotone statistic is component fugacity

For fixed `N`, the component count has
\[
\Pr_\alpha(K=k)
=
\frac{A_{N,k}\alpha^k}
{\sum_jA_{N,j}\alpha^j}.
\tag{4.1}
\]

If `alpha_2>alpha_1`, then
\[
\frac{\Pr_{\alpha_2}(K=k)}
{\Pr_{\alpha_1}(K=k)}
=
\text{constant}\cdot
\left(\frac{\alpha_2}{\alpha_1}\right)^k,
\tag{4.2}
\]
which is strictly increasing in `k` on the feasible support. Thus the family is exactly monotone-likelihood-ratio ordered by component count.

Equivalently,
\[
\boxed{
\frac{d}{d\log\alpha}\mathbb E_\alpha K
=
\operatorname{Var}_\alpha(K)>0
}
\tag{4.3}
\]
whenever at least two component counts are feasible.

At the visible tangent level, the corresponding binary-vs-ternary statistic is even simpler. From (3.15),
\[
\frac{q_c(1\mid23)}{q_c(1\mid2\mid3)}
=
\frac1c.
\tag{4.4}
\]
So as the fugacity is decreased, binary dominance increases monotonically to infinity. This is the mechanism that turns a random multi-component graph split into the asymptotically binary CTCS generator.

The exact checker verifies both the finite MLR identity and the exact rational tangent monotonicities.

### 5.1 Definition of C039

Let `G_N` have the finite fugacity law (2.2) with `alpha=alpha_N`. Let
\[
p_{11,N}
=
\Pr\{1,2\text{ are in different components of }G_N\},
\qquad
\lambda_N=p_{11,N}^{-1}.
\tag{5.5}
\]

Define the raw time mesh by
\[
\boxed{
\delta_N
=
\min\{N^{-2},p_{11,N}/2\}.
}
\tag{5.6}
\]
Thus the attempt probability
\[
a_N=\delta_N\lambda_N
\tag{5.7}
\]
is always at most `1/2`, with no appeal to asymptotics.

At each raw step, independently for each current nonsingleton block `B`:

1. attempt with probability `a_N`;
2. on an attempt, draw a fresh independent `G_N`;
3. replace `B` by its nonempty intersections with the connected components of `G_N`;
4. if all labels of `B` lie in one component, the attempt is invisible;
5. children start fresh at the next raw step.

This is **C039, the vanishing-fugacity unicyclic Gibbs-pseudoforest hierarchy**.

### 5.2 Exact hidden-label lumping

A fixed visible block lies in one full carrier. If a full proposal changes hidden labels but keeps all visible labels in one ambient component, the visible state is unchanged and those visible labels pass to one child. The next proposal is independent and has the same law, because proposal and attempt probabilities depend on global `N`, not on carrier size. Distinct visible children subsequently receive independent proposal streams.

Hence every fixed visible restriction is itself exactly Markov. There is no hidden carrier variable in its transition kernel.

\tag{5.11}

With at most `k` visible blocks, the probability contribution from two or more visible attempts in one raw step is
