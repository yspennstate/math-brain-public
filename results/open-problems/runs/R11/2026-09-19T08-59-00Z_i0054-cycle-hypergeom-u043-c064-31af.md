## 2. Move #18 — translate the paintbox into sampling without replacement on a finite cycle

The previous constructions often generated a binary color field first. Here the primitive object is instead a **uniform injection into a discrete circle**, followed by a contiguous arc cut.

Fix the ambient leaf number `N`. For a current block `B subseteq [N]`, choose a uniform injection

\[
\phi:B\hookrightarrow \mathbb Z/N\mathbb Z.
\tag{2.1}
\]

For an arc length `s in {1,...,N-1}`, choose a uniform start `R` and define

\[
I_{R,s}=\{R,R+1,\ldots,R+s-1\}\pmod N.
\tag{2.2}
\]

The proposal cuts the block into

\[
\phi^{-1}(I_{R,s})\quad\text{and}\quad B\setminus\phi^{-1}(I_{R,s}),
\tag{2.3}
\]

ignoring a proposal if one side is empty.

This is hypergeometric / without-replacement sampling rather than an iid Bernoulli paintbox.

### Exact restriction identity

If `V subseteq B` has `k` visible labels, then for every fixed injection `psi:V -> Z/NZ`,

\[
\Pr(\phi|_V=\psi)
=
\frac{(N-k)_{|B|-k}}{(N)_{|B|}}
=
\frac1{(N)_k}.
\tag{2.4}
\]

Thus the marginal injection of the visible labels is exactly uniform and is independent of the number of hidden labels in `B`. This will give exact strong lumpability of every fixed visible restriction.

For a specified unordered visible split `A|C`, with

\[
|A|=i,\qquad |C|=j,\qquad k=i+j,
\]

the probability under a type-`s` proposal is exactly

\[
\boxed{
P_{N,s}(i,j)
=
\frac{(s)_i(N-s)_j+(s)_j(N-s)_i}{(N)_k}.
}
\tag{2.5}
\]

The two terms are the two possible orientations of the unordered split across the arc boundary.

## 3. Move #25 — count the same split twice and recover the CTCS beta rates exactly

Give type `s` the unmodulated proposal intensity

\[
a^0_{N,s}=\frac{N}{2s(N-s)}.
\tag{3.1}
\]

The rate of a specified `i|j` split is then

\[
q_N^0(i,j)
=
\sum_{s=1}^{N-1}a^0_{N,s}P_{N,s}(i,j).
\tag{3.2}
\]

Pair the second orientation at `s` with the first orientation at `N-s`. This gives

\[
q_N^0(i,j)
=
\frac{N}{(N)_k}
\sum_{s=1}^{N-1}
(s-1)_{i-1}(N-s-1)_{j-1}.
\tag{3.3}
\]

Now count the same convolution in binomial language:

\[
(s-1)_{i-1}(N-s-1)_{j-1}
=(i-1)!(j-1)!
\binom{s-1}{i-1}
\binom{N-s-1}{j-1}.
\]

Vandermonde's identity yields

\[
\sum_{s=1}^{N-1}
\binom{s-1}{i-1}
\binom{N-s-1}{j-1}
=
\binom{N-1}{k-1}.
\tag{3.4}
\]

Therefore

\[
\boxed{
q_N^0(i,j)
=
\frac{(i-1)!(j-1)!}{(i+j-1)!}
=B(i,j)
}
\tag{3.5}
\]

**exactly for every `N >= i+j`.** These are precisely the CTCS specified-split rates.

## 4. Move #7 — a persistent microscopic modulation that disappears only in the limit

Let positive weights `w_{N,s}` modify (3.1):

\[
a_{N,s}=\frac{N}{2s(N-s)}w_{N,s}.
\tag{4.1}
\]

Only the symmetrized weights

\[
\bar w_{N,s}=\frac{w_{N,s}+w_{N,N-s}}2
\tag{4.2}
\]

are seen by unordered splits. Put

\[
h_{N,s}=\bar w_{N,s}-1,
\qquad
H_{N,r}=\sum_{s=1}^r h_{N,s},
\qquad
\Delta_N=\max_{1\le r<N}|H_{N,r}|.
\tag{4.3}
\]

The exact specified split rate is

\[
q_N(i,j)
=
\frac{N}{(N)_k}
\sum_{s=1}^{N-1}
\bar w_{N,s}(s-1)_{i-1}(N-s-1)_{j-1}.
\tag{4.4}
\]

### Theorem U043 — bounded-discrepancy cyclic-hypergeometric compiler

For fixed `i,j >= 1`, `k=i+j`, and `N >= 2k`,

\[
\boxed{
|q_N(i,j)-B(i,j)|
\le
(k-1)2^k\frac{\Delta_N}{N}.
}
\tag{4.5}
\]

Consequently, if `Delta_N=o(N)`, every fixed specified split rate converges to the CTCS beta rate.

### Proof

Write

\[
p_s=(s-1)_{i-1}(N-s-1)_{j-1}.
\]

By Abel summation,

\[
\left|\sum_{s=1}^{N-1}h_{N,s}p_s\right|
\le
\Delta_N\left(|p_{N-1}|+
\sum_{s=1}^{N-2}|p_{s+1}-p_s|\right).
\tag{4.6}
\]

The falling-factorial finite-difference identity

\[
(x+1)_r-(x)_r=r(x)_{r-1}
\tag{4.7}
\]

and the product rule give

\[
|p_s|\le N^{k-2},
\qquad
|p_{s+1}-p_s|\le(k-2)N^{k-3}.
\tag{4.8}
\]

Hence the parenthesis in (4.6) is at most `(k-1)N^{k-2}`. Also, for `N>=2k`,

\[
(N)_k\ge(N/2)^k.
\tag{4.9}
\]

Subtracting the exact baseline (3.5) from (4.4) and combining (4.6)--(4.9) proves (4.5). QED.

This theorem is the limit step: the microscopic environment can remain order-one nonuniform forever; CTCS only requires that its cumulative symmetric discrepancy grow sublinearly.
