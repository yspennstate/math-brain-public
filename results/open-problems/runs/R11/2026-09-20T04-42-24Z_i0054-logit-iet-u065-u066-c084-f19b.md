# 4. U065 — rigidity of monotone conserved-coordinate maps

Let `S:R->R` be a bijection preserving Lebesgue measure.

If `S` is increasing, then for every `a<b`,

\[
S((a,b))=(S(a),S(b)),
\]

so measure preservation gives

\[
S(b)-S(a)=b-a.
\]

Hence `S(y)-y` is constant and

\[
\boxed{S(y)=y+c.}
\tag{4.1}
\]

If `S` is decreasing, then

\[
S((a,b))=(S(b),S(a)),
\]

and measure preservation gives

\[
S(a)-S(b)=b-a,
\]

so `S(y)+y` is constant and

\[
\boxed{S(y)=c-y.}
\tag{4.2}
\]

After logistic pullback, (4.1) is exactly an odds multiplier

\[
x\mapsto \frac{e^c x}{1-x+e^c x},
\]

which is U064/C083. Equation (4.2) is the same map followed by the complement `x -> 1-x`; unordered binary split rates are complement-invariant.

### U065 conclusion

Within the conserved logit-coordinate approach, **no monotone measure-preserving bijection yields a genuinely new unordered CTCS compiler beyond the C083 odds-shift family**. To leave that family, one must break monotonicity.

# 5. U066 — a finite logit interval-exchange compiler

Let

\[
\sigma(y)=\frac{e^y}{1+e^y},
\qquad
\ell(x)=\log\frac{x}{1-x}.
\]

Let `S:R->R` be a finite piecewise-translation Lebesgue-measure-preserving bijection which equals the identity outside a compact interval. Define

\[
\tau(x)=\sigma(S(\ell(x))).
\tag{5.1}
\]

For each `N>=2`, every active nonsingleton clade has independent proposal clocks indexed by

\[
s=1,\ldots,N-1
\]

with the source harmonic-grid rates

\[
\lambda_{N,s}
=
\frac{N}{2s(N-s)}
=
\frac{1}{2N x_s(1-x_s)},
\qquad x_s=\frac{s}{N}.
\tag{5.2}
\]

At a ring of clock `s`, independently color each label in the active clade red with probability

\[
p_{N,s}=\tau(x_s),
\tag{5.3}
\]

blue otherwise, and split iff both colors occur. Descendants receive fresh independent clocks and colors.

## 5.1 Exact finite specified split rate

For a specified unordered split `A|B` with

\[
|A|=i\ge1,
\qquad |B|=j\ge1,
\]

the exact finite rate is

\[
q_{N,S}(i,j)
=
\sum_{s=1}^{N-1}\lambda_{N,s}
\left[p_{N,s}^i(1-p_{N,s})^j
+p_{N,s}^j(1-p_{N,s})^i\right].
\tag{5.4}
\]

Equivalently,

\[
q_{N,S}(i,j)
=
\frac1N\sum_{s=1}^{N-1}F_{S;i,j}(s/N),
\tag{5.5}
\]

where

\[
F_{S;i,j}(x)
=
\frac{
 \tau(x)^i(1-\tau(x))^j
 +\tau(x)^j(1-\tau(x))^i
}{2x(1-x)}.
\tag{5.6}
\]

Because `S` has finitely many translation pieces and is the identity in both tails, `F_{S;i,j}` is piecewise smooth with finitely many jumps and bounded endpoint limits. In particular it has finite total variation on `[0,1]`. Therefore the uniform-grid Riemann estimate gives

\[
q_{N,S}(i,j)
=
\int_0^1F_{S;i,j}(x)\,dx
+O_{S,i,j}(N^{-1}).
\tag{5.7}
\]

## 5.2 The continuum integral is exactly CTCS

Put

\[
\Phi_{i,j}(y)
=
\frac12\left[
 \sigma(y)^i(1-\sigma(y))^j
 +\sigma(y)^j(1-\sigma(y))^i
\right].
\tag{5.8}
\]

Since

\[
dx=x(1-x)\,dy,
\]

(5.6) gives

\[
\int_0^1F_{S;i,j}(x)\,dx
=
\int_{\mathbb R}\Phi_{i,j}(S(y))\,dy.
\tag{5.9}
\]

Lebesgue preservation of `S` implies

\[
\int_{\mathbb R}\Phi_{i,j}(S(y))\,dy
=
\int_{\mathbb R}\Phi_{i,j}(y)\,dy.
\tag{5.10}
\]

Returning to `x=\sigma(y)`, the last integral is

\[
\frac12\int_0^1
\left[x^{i-1}(1-x)^{j-1}
+x^{j-1}(1-x)^{i-1}\right]dx
=
B(i,j).
\tag{5.11}
\]

Hence

\[
\boxed{
q_{N,S}(i,j)=B(i,j)+O_{S,i,j}(N^{-1}).
}
\tag{5.12}
\]

This is the exact CTCS specified split rate in the limit.

## 5.3 Complete finite-restriction path convergence

All proposal colors are freshly redrawn, and every descendant receives fresh clocks. If a full split separates only hidden labels while all visible labels remain in one child, that visible carrier restarts with exactly the same future proposal law. Therefore hidden labels lump out and every fixed visible restriction is itself a finite-state CTMC.

Fix `k`. There are only finitely many visible states and finitely many specified binary transitions from them. By (5.12), every entry of the restricted generator differs from the CTCS(`[k]`) generator by `O_{S,k}(1/N)`. Hence the maximum outgoing `l^1` generator discrepancy is at most `C_{S,k}/N` for some finite constant `C_{S,k}`.

Couple the two finite CTMCs by common uniformization. Before their first discrepant transition, the mismatch hazard is at most `C_{S,k}/N`. Thus for every finite `T`,

\[
\boxed{
\left\|
\mathcal L(\Pi_{N,S}^{[k]}|_{[0,T]})
-
\mathcal L(\Pi_{\rm CTCS}^{[k]}|_{[0,T]})
\right\|_{\rm TV}
\le
\min\left\{1,\frac{T C_{S,k}}{N}\right\}
\longrightarrow0.
}
\tag{5.13}
\]

Total-variation convergence of the complete finite-state cadlag path implies finite-restriction Skorokhod `J_1` convergence. Applying the usual finite-coordinate/tail argument in the summable projective metric yields

\[
\boxed{
\Pi_{N,S}\Longrightarrow\Pi_{\operatorname{CTCS}(\infty)}.
}
\tag{5.14}
\]

This proves the required whole-genealogy limit, not a root split, tagged fragment, or fixed-time marginal.
