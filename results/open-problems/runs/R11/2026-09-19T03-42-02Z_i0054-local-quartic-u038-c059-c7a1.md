## 2. Frozen target generator

For a specified unordered binary split of one visible block into nonempty pieces of sizes `i,j`, the CTCS rate is

\[
B(i,j)
=\int_0^1x^{i-1}(1-x)^{j-1}\,dx
=\frac{(i-1)!(j-1)!}{(i+j-1)!}.
\tag{2.1}
\]

The convenient reference model for this run is the harmonic-grid paintbox. For `N>=2`, let

\[
x_u=\frac{u}{N},\qquad 1\le u\le N-1,
\tag{2.2}
\]

and give each current nonsingleton block independent Poisson marks of type `u` with intensity

\[
a_{N,u}
=\frac{1}{2(N-1)x_u(1-x_u)}.
\tag{2.3}
\]

At a reference mark, color every ambient label independently Bernoulli(`x_u`) and split the current block by the two colors whenever both occur. For a specified `i|j` visible split, the rate is

\[
\begin{aligned}
G_N(i,j)
&=\sum_{u=1}^{N-1}a_{N,u}
\{x_u^i(1-x_u)^j+x_u^j(1-x_u)^i\}\\
&=\frac1{N-1}\sum_{u=1}^{N-1}
 x_u^{i-1}(1-x_u)^{j-1},
\end{aligned}
\tag{2.4}
\]

where the second identity pairs `u` with `N-u`. Hence

\[
G_N(i,j)\longrightarrow B(i,j).
\tag{2.5}
\]

In particular,

\[
G_N(1,1)=1
\tag{2.6}
\]

exactly for every `N`.

## 3. Move #3 — prove a stronger local-interaction theorem

Instead of constructing one more approximate-independence example, I allow an arbitrary fixed local interaction order.

Fix an integer `r>=3` and `epsilon in [-1,1]`. At a mark with Bernoulli bias `x`, let `beta_x` be the product Bernoulli law on `{0,1}^N`. Choose an `r`-subset `T` uniformly from `[N]`. Put

\[
m_x=\min(x,1-x),\qquad M_x=\max(x,1-x),
\tag{3.1}
\]

and

\[
R_{x,T}(z)
=\frac{\prod_{t\in T}(z_t-x)}{M_x^r}.
\tag{3.2}
\]

Define the tilted coloring law

\[
\boxed{
\mu_{x,T}(z)=\beta_x(z)\{1+\epsilon R_{x,T}(z)\}.
}
\tag{3.3}
\]

Because `|z_t-x|<=M_x`, we have `|R_{x,T}(z)|<=1`, so (3.3) is nonnegative. Also

\[
E_{\beta_x}R_{x,T}
=M_x^{-r}\prod_{t\in T}E(Z_t-x)=0,
\tag{3.4}
\]

so (3.3) has total mass one. Averaging over uniform `T` makes the law fully leaf-exchangeable.

### Lemma 3.1 — exact low-order marginals

Every marginal on fewer than `r` specified labels is exactly iid Bernoulli(`x`).

**Proof.** Let `L` be the observed label set with `|L|<r`. For every `r`-set `T`, choose `t in T\L`. Marginalizing over coordinate `t` annihilates the perturbation because `E_{\beta_x}(Z_t-x)=0`. Thus the perturbation has zero contribution to every cylinder on `L`. QED.

### Lemma 3.2 — support-dilution bound

Let `E` be any event depending only on `k` specified labels `L`. Let `p_x(E)` denote its probability under the averaged tilted law and `p_x^0(E)` its product-law probability. Then

\[
\boxed{
|p_x(E)-p_x^0(E)|
\le
|\epsilon|\frac{\binom{k}{r}}{\binom{N}{r}}(2m_x)^r,
}
\tag{3.5}
\]

with the convention `binom(k,r)=0` when `k<r`.

**Proof.** A perturbation contributes to an event measurable on `L` only when `T subseteq L`; otherwise a centered factor is integrated out. Conditional on `T subseteq L`,

\[
\left|E_{\beta_x}[1_E R_{x,T}]\right|
\le E_{\beta_x}|R_{x,T}|
=\left(\frac{E|Z-x|}{M_x}\right)^r
=(2m_x)^r.
\tag{3.6}
\]

The chance that uniform `T` lies inside `L` is `binom(k,r)/binom(N,r)`. QED.

For `r>=2`,

\[
(2m_x)^r\le 4m_xM_x=4x(1-x).
\tag{3.7}
\]

Therefore, after multiplying (3.5) by the harmonic-grid mark rates and summing over `u`, every specified `k`-label event has total generator defect at most

\[
\boxed{
2|\epsilon|\frac{\binom{k}{r}}{\binom{N}{r}}.
}
\tag{3.8}
\]

For every fixed `k` and fixed `r`, this tends to zero like `O_k(N^{-r})`.
