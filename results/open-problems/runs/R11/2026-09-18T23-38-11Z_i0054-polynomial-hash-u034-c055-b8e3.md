## 2. Move #6 — deform full randomness down to only the randomness fixed restrictions can see

Start with the easy solvable point: a completely random function from the `N` labels into a large finite field. Thresholding its values gives an ordinary Bernoulli paintbox conditional on the threshold. Such a model is globally exchangeable but uses `Theta(N)` independent field values per proposal.

The deformation is to replace the random lookup table by a random polynomial of degree only

\[
d_N-1,\qquad d_N:=\max\{2,\lfloor\log_2N\rfloor\}.
\tag{2.1}
\]

This destroys global independence drastically. However `d_N -> infinity`, and any fixed set of `k` labels sees **exactly the same law** once `k<=d_N`. Thus the deformation is invisible in every fixed projective coordinate, even though it is very visible at finite `N` on larger label sets.

## 3. U034 — growing local paintbox criterion

For each `N`, let `S_N subset [N]` be a random binary cut and let `K_N -> infinity`. Suppose there is a random variable `X_N in (0,1)` such that, for **every** choice of at most `K_N` distinct labels, conditional on `X_N=x` their membership indicators in `S_N` are independent Bernoulli(`x`). No condition is imposed on joint laws of more than `K_N` labels; in particular `S_N` need not be globally exchangeable.

For a specified visible `i|j` split with `i+j<=K_N`, its one-proposal probability is exactly

\[
P_N(i,j)=E\left[X_N^i(1-X_N)^j+X_N^j(1-X_N)^i\right].
\tag{3.1}
\]

Put

\[
\lambda_N=P_N(1,1)^{-1}
=\frac{1}{2E[X_N(1-X_N)]}
\tag{3.2}
\]

and define the pair-normalized local paintbox measure

\[
\boxed{
\rho_N
=\lambda_N E\left[
X_N(1-X_N)(\delta_{X_N}+\delta_{1-X_N})
\right].
}
\tag{3.3}
\]

Its total mass is exactly one. Moreover, whenever `i+j<=K_N`,

\[
\boxed{
\lambda_NP_N(i,j)
=\int_0^1x^{i-1}(1-x)^{j-1}\rho_N(dx).
}
\tag{3.4}
\]

Hence, because `K_N -> infinity`, the following are equivalent:

1. `rho_N => dx` weakly on `[0,1]`;
2. for every fixed `i,j>=1`, `lambda_N P_N(i,j) -> B(i,j)`;
3. it is enough to check the moment subfamily `j=1` for every fixed `i`.

**Proof.** Equation (3.4) is exact: multiply (3.1) by (3.2), factor one `X_N(1-X_N)`, and use the two reflected atoms in (3.3). Thus weak convergence gives all beta moments. Conversely, `j=1` gives all Hausdorff moments `int x^{i-1} rho_N(dx) -> 1/i`; polynomial density on `[0,1]` identifies Lebesgue measure. Since `K_N -> infinity`, every fixed moment is eventually inside the exact local-paintbox window. QED.

### Process compiler, not just a generator criterion

Use raw physical step length

\[
\delta_N=\min\{N^{-2},\lambda_N^{-3}\}
\tag{3.5}
\]

and let every current nonsingleton block independently attempt a fresh cut with probability

\[
a_N=\delta_N\lambda_N.
\tag{3.6}
\]

At an attempt draw a fresh independent copy of `S_N` and intersect it with the block. For a fixed visible restriction `[k]`, once `k<=K_N`, the full visible proposal is exactly a paintbox conditional on `X_N`; hidden labels therefore do not create residual state. The visible partition alone is a time-homogeneous finite-state Markov chain.

The probability that two visible blocks jump in one raw step is `O_k(a_N^2)`, so after division by the step duration the simultaneous-jump error is

\[
O_k(\delta_N\lambda_N^2).
\tag{3.7}
\]

For every `lambda_N>=1`,

\[
\delta_N\lambda_N^2
=\min\left\{\lambda_N^2/N^2,1/\lambda_N\right\}
\le N^{-2/3}.
\tag{3.8}
\]

Thus if `rho_N=>dx`, the transition matrix on the finite partition space `P_k` is

\[
K_N^{[k]}=I+\delta_NQ_{CTCS}^{[k]}+o_k(\delta_N).
\tag{3.9}
\]

Standard finite-state Euler/uniformization convergence gives

\[
\Pi_N^{[k]}\Longrightarrow\Pi_{CTCS}^{[k]}
\quad\text{in Skorokhod }J_1
\tag{3.10}
\]

for every fixed `k` on every finite time horizon. The first `K` projective coordinates are all functions of the `[K]` path, while the tail of the summable projective metric is at most `sum_{k>K}2^{-k}`. Therefore

\[
\boxed{
\Pi_N\Longrightarrow\Pi_{CTCS(\infty)}
}
\tag{3.11}
\]

in the frozen projective path topology.

This proves U034.

## 4. Move #14 — the coefficient group makes local independence exact

\[

\tag{4.1}
\]

Then draw independent uniform coefficients `A_0,...,A_{d-1} in F_q` and form

\[
P(x)=A_0+A_1x+\cdots+A_{d-1}x^{d-1}.
\tag{4.2}

\[
S_N=\{x\in[N]: \operatorname{rep}(P(x))<U\},
\tag{4.3}

## 6. Move #19 — explicit algorithm and finite non-equivalence

One C055 proposal is the following finite algorithm.

1. Precompute `q_N`, `d_N`, and the rational table `alpha_q(1),...,alpha_q(q-1)`.
2. Draw `U` from that table.
3. Draw `d_N` independent field coefficients.
4. Evaluate the degree-`<d_N` polynomial on the labels in the current block.
5. Split by whether the residue lies below `U`.

The proposal uses only `d_N=O(log N)` random field symbols instead of one fresh independent symbol per leaf. Evaluation on a block is a finite polynomial-time operation. This is the algorithmic meaning of the deformation in Section 2.
