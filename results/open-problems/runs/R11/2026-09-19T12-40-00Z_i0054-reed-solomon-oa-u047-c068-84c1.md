## 3. U047 — exact orthogonal-array CTCS compiler

### Setup

For each `N`, let `q_N` be a prime with `q_N >= N`, let `K_N >= 2`, and suppose `K_N -> infinity`. Let

\[
\mathcal A_N\subset \{0,1,\ldots,q_N-1\}^N
\]

be a finite multiset with the following exact strength-`K_N` orthogonal-array property: for every `b<=K_N`, every `b` distinct columns, and every value vector `y in F_{q_N}^b`, the fraction of rows restricting to `y` is exactly `q_N^{-b}`.

For `u=1,...,q_N-1` put

\[
 x_u=\frac{u}{q_N}.
\tag{3.1}
\]

For each current nonsingleton clade and every pair `(u,a)` with `a in A_N`, run an independent Poisson proposal clock of rate

\[
 c_{N,u,a}
 =\frac{1}{2(q_N-1)|\mathcal A_N|x_u(1-x_u)}.
\tag{3.2}
\]

At a `(u,a)` proposal, color ambient label `ell` red iff `a_ell<u`, blue otherwise, and split the current clade by the two colors when both are present. Descendant clades receive fresh independent copies of the same clock family.

### Theorem U047

If `q_N -> infinity` and `K_N -> infinity`, then for every fixed `k` and finite `T`, the restriction of this hierarchy to `[k]` converges to the `CTCS^[k]` partition path in total variation on `D([0,T],P_k)`. Hence it converges in Skorokhod `J1`, and the projective process converges to `CTCS(infinity)`.

### Proof

Fix `k`. For all sufficiently large `N`, `k<=K_N`. Consider a current visible block `C` and one specified unordered split `A|B` of it, with

\[
 |A|=i,\qquad |B|=j,\qquad i+j\le k.
\]

For a uniformly chosen row of the orthogonal array, the `i+j` visible symbols are exactly iid uniform on `F_q`. Thresholding at `u` therefore gives iid Bernoulli(`x_u`) red indicators. Consequently the probability that the threshold mask realizes the specified **unordered** split is exactly

\[
 x_u^i(1-x_u)^j+x_u^j(1-x_u)^i.
\tag{3.3}
\]

Summing the clocks in (3.2) over all rows gives the conditional rate contribution of threshold `u`:

\[
\frac{1}{2(q-1)}
\left[
 x_u^{i-1}(1-x_u)^{j-1}
 +x_u^{j-1}(1-x_u)^{i-1}
\right].
\tag{3.4}
\]

The grid is invariant under `u -> q-u`, so the two sums in (3.4) are equal. Thus the exact specified split rate is

\[
\boxed{
 G_q(i,j)
 =\frac1{q-1}\sum_{u=1}^{q-1}
 \left(\frac uq\right)^{i-1}
 \left(1-\frac uq\right)^{j-1}.
 }
\tag{3.5}
\]

This is a Riemann sum, so for each fixed `i,j`,

\[
 G_q(i,j)\longrightarrow
 \int_0^1x^{i-1}(1-x)^{j-1}\,dx
 =B(i,j)
 =\frac{(i-1)!(j-1)!}{(i+j-1)!}.
\tag{3.6}
\]

Those are precisely the specified binary-split rates of CTCS. In particular

\[
 G_q(1,1)=1
\tag{3.7}
\]

for every `q`.

The hidden-label issue is exact. Given a visible partition, each visible block lies in one unique full carrier block. The clocks of that carrier depend on the ambient label mask but not on what hidden labels happen to share the carrier. A proposal that gives a nontrivial visible cut is automatically a nontrivial full cut, and its rate is (3.5), independent of the hidden carrier content. Hidden-only cuts merely replace the carrier by a child with a fresh memoryless copy of the same clock family. Therefore full states with the same visible partition have identical rates into every different visible partition class: the projection is strongly lumpable.

Hence for fixed `k`, once `K_N>=k`, the visible process is a finite-state CTMC with generator `Q_{N,k}` whose off-diagonal entries are the `G_{q_N}(i,j)`. Equation (3.6) gives entrywise

\[
 Q_{N,k}\to Q_k^{\rm CTCS}.
\tag{3.8}
\]

Because the state space `P_k` is finite, the maximum row `l1` discrepancy tends to zero and all exit rates are eventually uniformly bounded. Uniformize both chains with one common Poisson clock and maximally couple the one-step kernels. On `[0,T]`, the probability the coupled paths ever differ is bounded by `T/2` times the maximum row `l1` generator discrepancy. It tends to zero. Thus the entire path laws converge in total variation, which implies `J1` convergence.

For the infinite process, all restrictions `[j]`, `j<=K`, are deterministic projections of the `[K]` path. Their joint laws therefore converge for every fixed `K`. The tail of the frozen summable projective metric beyond `K` is deterministically summable. First send `N->infinity`, then `K->infinity`. This proves projective convergence to `CTCS(infinity)`. `square`

### Finite-tree validity

The hierarchy terminates almost surely for every finite `N` provided the OA has strength at least two. For any pair of labels that currently lies in one block, (3.7) says the aggregate rate of proposals separating that pair is exactly one. Hence every nonsingleton block has strictly positive finite exit rate. Every nontrivial jump raises the number of blocks by one, so at most `N-1` nontrivial jumps are possible before the singleton partition is reached. Thus the construction is a genuine finite discrete tree model, not only a compatible collection of finite-dimensional hazards.

## 4. C068 — Reed–Solomon orthogonal-array fragmentation

For the explicit class, set

\[
 q_N=\min\{q\text{ prime}:q\ge N\},
\qquad
 K_N=\min\{N,\max(2,\lfloor\sqrt N\rfloor+1)\}.
\tag{4.1}
\]

Use the distinct field points

\[
 \alpha_\ell=\ell-1\in\mathbb F_{q_N},
 \qquad 1\le\ell\le N.
\tag{4.2}
\]

For every polynomial

\[
 f(z)=c_0+c_1z+\cdots+c_{K_N-1}z^{K_N-1}
 \quad(c_r\in\mathbb F_{q_N}),
\tag{4.3}
\]

form the evaluation word

\[
 a(f)=(f(\alpha_1),\ldots,f(\alpha_N)).
\tag{4.4}
\]

There are exactly `q_N^{K_N}` such rows. On any `b<=K_N` distinct columns, evaluation is a linear map

\[
\mathbb F_q^{K_N}\to\mathbb F_q^b
\]

whose `b x K_N` Vandermonde matrix has rank `b`. Hence every prescribed `b`-tuple has exactly `q^{K_N-b}` polynomial preimages. Thus the rows form an exact strength-`K_N` orthogonal array.

Apply U047, i.e. for every `(u,f)` give each current clade a Poisson proposal clock of rate

\[
\boxed{
\frac{1}{2(q_N-1)q_N^{K_N}x_u(1-x_u)},
\qquad x_u=u/q_N,
}
\tag{4.5}
\]

and cut by the threshold mask

\[
\ell\mapsto\mathbf 1\{\operatorname{rep}(f(\alpha_\ell))<u\}.
\tag{4.6}
\]

Since `q_N>=N->infinity` and `K_N->infinity`, U047 gives

\[
\boxed{
 \Pi_{N,068}^{[k]}\Longrightarrow \Pi_{\rm CTCS}^{[k]}
 \quad\text{in path total variation on every }[0,T],
}
\tag{4.7}
\]

hence in `J1`, for every fixed `k`, followed by

\[
\boxed{
 \Pi_{N,068}\Longrightarrow\Pi_{\rm CTCS(\infty)}
}
\tag{4.8}
\]

in the frozen projective finite-restriction topology.

This construction is finite and fully explicit once `N` is fixed. It is algebraic rather than interval/subordinator based: the microscopic environments are codewords of a finite-field polynomial evaluation code.
