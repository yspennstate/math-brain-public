# 4. U068 — noninvertible bounded-variation logit compiler

Write

\[
\sigma(y)=\frac{e^y}{1+e^y},
\qquad
\ell(x)=\log\frac{x}{1-x}.
\tag{4.1}
\]

For each `N`, let

\[
S_N:\mathbb R\to\mathbb R
\]

be a Borel map satisfying:

1. `S_N` preserves Lebesgue measure, i.e. `(S_N)_*Leb = Leb`;
2. invertibility is **not** required;
3. every `S_N` equals the identity outside one fixed compact interval `[a,b]`.

Define

\[
\tau_N(x)=\sigma(S_N(\ell(x))).
\tag{4.2}
\]

For each finite ambient leaf count `N`, every active nonsingleton clade has independent proposal clocks indexed by

\[
s=1,\ldots,N-1
\]

with rates

\[
\lambda_{N,s}=\frac{N}{2s(N-s)}
=\frac{1}{2N x_s(1-x_s)},
\qquad x_s=\frac{s}{N}.
\tag{4.3}
\]

At a ring of clock `s`, color each label in that clade independently red with probability `tau_N(x_s)` and blue otherwise. Make the split if and only if both colors occur. Descendant clocks and colors are fresh and independent.

Fix a specified unordered visible split `A|B` with

\[
|A|=i\ge1,\qquad |B|=j\ge1.
\]

Its exact rate is

\[
q_N(i,j)
=\sum_{s=1}^{N-1}\lambda_{N,s}
\left[
\tau_N(x_s)^i(1-\tau_N(x_s))^j
+\tau_N(x_s)^j(1-\tau_N(x_s))^i
\right].
\tag{4.4}
\]

Equivalently,

\[
q_N(i,j)=\frac1N\sum_{s=1}^{N-1}F_{N;i,j}(s/N),
\tag{4.5}
\]

where

\[
F_{N;i,j}(x)=
\frac{
\tau_N(x)^i(1-\tau_N(x))^j
+\tau_N(x)^j(1-\tau_N(x))^i
}{2x(1-x)}.
\tag{4.6}
\]

Because `S_N` is the identity near both logit infinities, `F_{N;i,j}` has finite endpoint limits. Assume

\[
\boxed{
\operatorname{Var}(F_{N;i,j})=o(N)
\quad\text{for every fixed }i,j\ge1.
}
\tag{4.7}
\]

Then the hierarchy converges to CTCS(infinity) in the frozen whole-path sense.

## 4.1 Exact continuum generator, with no invertibility

Define

\[
\Phi_{i,j}(y)
=\frac12\left[
\sigma(y)^i(1-\sigma(y))^j
+\sigma(y)^j(1-\sigma(y))^i
\right].
\tag{4.8}
\]

Since `dx=x(1-x)dy`,

\[
\int_0^1F_{N;i,j}(x)\,dx
=
\int_{\mathbb R}\Phi_{i,j}(S_N(y))\,dy.
\tag{4.9}
\]

Measure preservation means precisely that for every nonnegative or integrable `g`,

\[
\int g(S_N(y))\,dy=\int g(y)\,dy.
\]

No inverse map is used. Thus

\[
\int_0^1F_{N;i,j}(x)\,dx
=
\int_{\mathbb R}\Phi_{i,j}(y)\,dy.
\tag{4.10}
\]

Put `p=sigma(y)`. Then `dy=dp/[p(1-p)]`, so

\[
\begin{aligned}
\int_{\mathbb R}\Phi_{i,j}(y)\,dy
&=\frac12\int_0^1
\left[p^{i-1}(1-p)^{j-1}
+p^{j-1}(1-p)^{i-1}\right]dp\\
&=B(i,j)\\
&=\frac{(i-1)!(j-1)!}{(i+j-1)!}.
\end{aligned}
\tag{4.11}
\]

Therefore the continuum specified split rate is **exactly the CTCS rate for every `N` and every admissible `S_N`**, even when `S_N` is many-to-one.

## 4.2 Harmonic-grid error from bounded variation

For any bounded-variation `f` on `[0,1]`, the right-endpoint rectangle rule gives

\[
\left|
\frac1N\sum_{s=1}^{N}f(s/N)-\int_0^1f(x)\,dx
\right|
\le \frac{\operatorname{Var}(f)}{N}.
\tag{4.12}
\]

Removing the `s=N` term changes the sum by `f(1)/N`. Hence

\[
\left|
q_N(i,j)-B(i,j)
\right|
\le
\frac{\operatorname{Var}(F_{N;i,j})+|F_{N;i,j}(1)|}{N}.
\tag{4.13}
\]

The endpoint term is fixed because `S_N` is the identity near `+infinity`. By (4.7),

\[
\boxed{q_N(i,j)\longrightarrow B(i,j)}
\tag{4.14}
\]

for every fixed split type.

## 4.3 Hidden labels lump exactly

Fix visible labels `[k]`. Take two full-tree states having the same visible partition. For a visible block of size `m` and a specified visible split `A|A^c`, the instantaneous rate of that visible transition is exactly `q_N(|A|,m-|A|)`, independent of how many hidden labels share the full clade and independent of their identities. A split affecting only hidden labels leaves exactly one daughter carrying all visible labels, and that daughter restarts with fresh clocks/colors governed by the same deterministic `S_N`.

Thus the projection to `[k]` is strongly lumpable and is itself a finite-state CTMC.

## 4.4 Whole-path total-variation convergence

Let `Q_N^(k)` and `Q_CTCS^(k)` be the visible generators. Since the state space and its possible specified binary transitions are finite for fixed `k`, (4.14) implies

\[
\Delta_{N,k}:=
\max_{\xi}
\sum_{\eta\ne\xi}
|Q_N^{(k)}(\xi,\eta)-Q_{\rm CTCS}^{(k)}(\xi,\eta)|
\longrightarrow0.
\tag{4.15}
\]

Common uniformization, or equivalently maximal coupling of the outgoing rate measures while the chains agree, yields for every finite `T`

\[
\boxed{
\left\|
\mathcal L(\Pi_N^{[k]}|_{[0,T]})
-
\mathcal L(\Pi_{\rm CTCS}^{[k]}|_{[0,T]})
\right\|_{\rm TV}
\le T\Delta_{N,k}\to0.
}
\tag{4.16}
\]

Therefore every fixed finite restriction converges in whole-path TV, hence in finite-state `J_1`. Consistency of restrictions and the usual finite-prefix/tail argument for the summable projective metric then give

\[
\boxed{
\Pi_N\Longrightarrow\Pi_{\operatorname{CTCS}(\infty)}.
}
\tag{4.17}
\]

This proves U068.

# 5. C086 — an iterated dyadic Bernoulli shift in logit space

Set

\[
L=\log4=2\log2.
\tag{5.1}
\]

Define the global map

\[
D(y)=
\begin{cases}
2y\pmod L,&0\le y<L,\\
y,&y\notin[0,L).
\end{cases}
\tag{5.2}
\]

For `N>=4`, set

\[
r_N=\max\left\{1,\left\lfloor\frac{\log_2N}{2}\right\rfloor\right\},
\qquad
b_N=2^{r_N},
\tag{5.3}
\]

and take

\[
S_N=D^{r_N}.
\tag{5.4}
\]

On `[0,L)`,

\[
S_N(y)=b_Ny\pmod L.
\tag{5.5}
\]

This map is `b_N`-to-1 rather than a bijection.

## 5.1 Exact measure preservation

Normalize `t=y/L` on `[0,L)`. Then (5.5) is simply

\[
t\mapsto b_N t\pmod1.
\]

For any measurable `A subset [0,1)`, its preimage is the disjoint union

\[
\bigcup_{r=0}^{b_N-1}\frac{A+r}{b_N}.
\]

Each component has measure `Leb(A)/b_N`, so the total preimage measure is exactly `Leb(A)`. Hence `(S_N)_*Leb=Leb` on `[0,L)`, and the identity extension makes it Lebesgue-measure-preserving on all of `R`.

The exact checker independently verifies this finite-partition identity for powers `b=2,...,256`, many rational intervals, and polynomial moments through degree 17.

## 5.2 Variation bound

The active `x`-interval is the fixed compact set

\[
J=[\sigma(0),\sigma(L)]=[1/2,4/5].
\]

It has `b_N` logit branches. On branch `r`,

\[
S_N(y)=b_Ny-rL,
\qquad
\frac{dS_N}{dy}=b_N.
\tag{5.6}
\]

Write `tau_N=sigma(S_N(ell(x)))`. On branch interiors,

\[
\frac{d\tau_N}{dx}
=
\frac{b_N\tau_N(1-\tau_N)}{x(1-x)}.
\tag{5.7}
\]

Both `x` and `tau_N(x)` lie in `[1/2,4/5]` on `J`. For fixed `i,j`, the function

\[
H_{i,j}(x,z)=
\frac{z^i(1-z)^j+z^j(1-z)^i}{2x(1-x)}
\]

and its first partial derivatives are therefore uniformly bounded on `J x J`. Equations (5.7) and the chain rule imply

\[
|F'_{N;i,j}(x)|\le C_{i,j}(1+b_N)
\]

on every branch interior. Integrating over the fixed total length of `J` gives smooth variation `O_{i,j}(1+b_N)`.

There are `b_N-1` internal branch jumps. Their sizes are uniformly bounded because `H_{i,j}` is bounded on `J x J`, so total jump variation is also `O_{i,j}(b_N)`. Outside `J`, `S_N` is the identity and `F_{N;i,j}` is the fixed beta-polynomial integrand with finite variation. Therefore

\[
\boxed{
\operatorname{Var}(F_{N;i,j})
\le C_{i,j}(1+b_N).
}
\tag{5.8}
\]

By definition of `r_N`, for `N>=4`,

\[
b_N^2\le N,
\]

so

\[
\frac{1+b_N}{N}=O(N^{-1/2})\to0.
\tag{5.9}
\]

U068 applies. Thus C086 has the complete whole-path finite-restriction limit CTCS(infinity).
