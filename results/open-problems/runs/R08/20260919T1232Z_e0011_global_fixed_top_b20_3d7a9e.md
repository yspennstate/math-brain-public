## 7. B25 — the attempted forward double count fails, and why

I also tried to verify the global value by a forward decomposition over exact first-progress times. For each intermediate stage I computed the exact first-hit kernel at common ticks, then took its pointwise minimum over the full entrance class, and finally convolved the seven kernels with the final-stage endpoint kernel.

That envelope is identically zero through tick `40`.

This is not evidence that the backward value is wrong. It exposes a quantifier mistake in the proposed independent count: different entrance descriptors can be worst at different **exact hitting times**, so

\[
\sum_k \min_s a_s(k)
\]

can vanish even when

\[
\min_s\sum_k a_s(k)>0.
\]

The backward recursion uses the latter, source-valid order: for one entrance state it sums all random histories/timings and only then minimizes. Thus B25 failed as an independent checksum, but it produced a useful structural warning: **never commute the boundary minimum with the hitting-time sum**. The exact checker asserts the zero forward envelope, so this failure is preserved rather than hidden.
