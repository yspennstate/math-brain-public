# 3. Move #21 — ASK WHO ELSE HAS THIS SHAPE: recover MZZ's rigorous lower bound

MZZ's pure-noise model has iid

`x_i ~ N(0,I_d)`, `y_i ~ Unif({+1,-1})`, with `y_i` independent of `x_i`,

and seeks `theta in S^{d-1}` satisfying

`y_i <x_i,theta> >= kappa` for every `i<=n`.

Their Theorem 4.3 states that, with `n,d -> infinity` and `n/d -> delta`, if

`delta < delta_lin(kappa) := 1/Phi(kappa)`,

then their convex linear-programming procedure has output norm exactly one with high probability, and hence outputs a genuine `kappa`-margin solution. They separately define the information-theoretic threshold `delta_s(kappa)`; therefore

`delta_s(kappa) >= delta_lin(kappa)=1/Phi(kappa)`.

At `kappa=-1`,

`delta_lin(-1)=1/Phi(-1)=6.30297437506875...`.

This is already far above R14-C178's `2.17196` lower endpoint.

# 4. Move #1 — CHANGE THE CATEGORY: exact model identification and polytope language

There is no normalization mismatch.

Start from the user's problem and put

`theta = x/sqrt(N)`.

Then `||theta||=1` and the constraints become

`<g_a,theta> >= kappa`, `1<=a<=M`.

In the MZZ pure-noise model define

`z_i = y_i x_i`.

Because a centered isotropic Gaussian is invariant under multiplication by an independent Rademacher sign, the rows `z_i` are iid `N(0,I_d)`. Hence

`y_i<x_i,theta> >= kappa`

has exactly the same joint law as

`<g_i,theta> >= kappa`.

Set `d=N`, `n=M=floor(alpha N)`. Then `n/d -> alpha`. Thus MZZ Theorem 4.3 applies directly to the exact R14 source model.

This is also the random-polytope formulation emphasized by MZZ: if `Z` has iid Gaussian rows and

`E_Z={xi: <z_i,xi> <=1 for all i}`, `R_d(E_Z)=max_{xi in E_Z}||xi||`,

then the maximum negative margin is `-1/R_d(E_Z)`. The category change is useful because it makes clear that MZZ's result is not about a discrete-weight or Ising perceptron; it is precisely the same continuous spherical problem.

# 5. Algorithmic versus information-theoretic scope

This distinction matters.

MZZ Theorem 4.3 is an **algorithmic** success theorem, with threshold `delta_lin(kappa)`. I do **not** claim that `delta_lin` is the satisfiability threshold. In fact MZZ emphasize a gap between their algorithmic and information-theoretic thresholds.

However, algorithmic success supplies an actual feasible full-radius vector. Therefore it is a rigorous lower bound on information-theoretic satisfiability:

`delta_lin(kappa) <= delta_s(kappa)`.

This is the only implication imported into R14.
