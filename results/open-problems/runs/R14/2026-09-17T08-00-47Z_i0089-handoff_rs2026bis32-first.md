## 4. Method #18 — SAY IT IN ANOTHER LANGUAGE: exact balanced-Ising reduction

For a `d`-regular graph let

\[
M=|E|=\frac{dn}{2},
\qquad
\Omega_n=\left\{\sigma\in\{-1,+1\}^n:\sum_i\sigma_i=0\right\},
\]

and define the zero-magnetization Ising Hamiltonian

\[
H_G(\sigma)=\sum_{\{i,j\}\in E}\sigma_i\sigma_j.
\]

For every balanced spin configuration,

\[
\mathrm{cut}_G(\sigma)=\frac{M-H_G(\sigma)}2.
\]

Write

\[
M_+(G)=\max_{\Omega_n}H_G,
\qquad
M_-(G)=\min_{\Omega_n}H_G.
\]

Then exactly

\[
\mathrm{MinBis}(G)=\frac{M-M_+(G)}2,
\qquad
\mathrm{MaxBis}(G)=\frac{M-M_-(G)}2,
\]

so (BIS32) is equivalent to

\[
\boxed{
\frac1n\mathbf E\,[M_+(G_d)+M_-(G_d)]\longrightarrow0.
}
\tag{C194.1}
\]

This identifies the source conjecture as a **ferromagnetic/antiferromagnetic zero-magnetization ground-state symmetry**, not merely a relation between two graph optimizations.

There is a useful exact finite-temperature reduction. For `beta>0`, put

\[
P_{n,d}(\beta)
:=
\frac1n\mathbf E\log
\sum_{\sigma\in\Omega_n}e^{\beta H_G(\sigma)}.
\]

The soft-max inequalities give

\[
\left|
\frac{P_{n,d}(\beta)-P_{n,d}(-\beta)}{\beta}
-
\frac1n\mathbf E[M_+(G_d)+M_-(G_d)]
\right|
\le
\frac{\log|\Omega_n|}{\beta n}
\le\frac{\log2}{\beta}.
\tag{C194.2}
\]

Therefore

\[
\boxed{
\text{(BIS32) holds at fixed }d
\iff
\lim_{\beta\to\infty}\limsup_{n\to\infty}
\left|
\frac{P_{n,d}(\beta)-P_{n,d}(-\beta)}{\beta}
\right|=0.
}
\tag{C194}
\]

The implication in each direction follows immediately from (C194.2), taking `n->infinity` and then `beta->infinity`. This is an exact source-model reduction, not a proof that the odd pressure vanishes.

## 5. A new route exposed by #18: exact annealed reflection in the configuration model

The configuration model makes a hidden symmetry completely explicit. Fix one balanced vertex partition. There are

\[
M=\frac{dn}{2}
\]

half-edges on each side. If exactly `k` paired edges cross the partition, then `M-k` must be even, and the exact number of pairings is

\[
N_M(k)
=
\binom Mk^2 k!\,((M-k)-1)!!^2.
\]

Using the double-factorial identity gives

\[
\boxed{
N_M(k)
= M!\binom Mk\,c_{M-k},
\qquad
c_r:=2^{-r}\binom r{r/2}
}
\tag{C195.1}
\]

for even `r=M-k`. If `M` is even, reflection `k<->M-k` preserves admissibility and

\[
\boxed{
\frac{N_M(k)}{N_M(M-k)}
=
\frac{c_{M-k}}{c_k}.
}
\tag{C195.2}
\]

Since the central-binomial probabilities satisfy `c_r=Theta((r+1)^(-1/2))`, the reflected ratio is at worst polynomial in `M`, and it is bounded by constants depending only on `epsilon` whenever `epsilon M <= k <= (1-epsilon)M`. Consequently the **annealed exponential complexity of balanced cuts is exactly reflection-symmetric** about `k=M/2` on the even-`M` subsequence.

Equivalently, for the balanced configuration-model annealed partition function

\[
A_{n,d}(\beta)
:=\frac1n\log\mathbf E_{\rm CM}
\sum_{\sigma\in\Omega_n}e^{\beta H(\sigma)},
\]

(C195.2) gives, uniformly in real `beta`,

\[
|A_{n,d}(\beta)-A_{n,d}(-\beta)|=O\!\left(\frac{\log n}{n}\right)
\tag{C195.3}
\]

when `M` is even. The checker independently verifies the exact pairing formula, its sum to `(2M-1)!!`, and the reflection identity for `2<=M<=12`.

**Scope warning:** C195 is a configuration-model annealed statement. The source is the quenched expectation on **simple** random regular graphs. Conditioning on simplicity and, more importantly, replacing `log E Z` by `E log Z` are genuine obligations. I do not promote C195 to source-level movement.

The conceptual gain is sharp: the first-moment/annealed landscape already has the desired `+beta/-beta` symmetry. The source problem lives in the **difference of quenched corrections**, not in the elementary entropy of balanced cuts.

## 6. Method #5 — ADD A PARAMETER AND DIFFERENTIATE: isolate the missing pressure theorem

Set the annealing gap (in whichever model is being compared) to

\[
\Gamma_{n,d}(\beta)=A_{n,d}(\beta)-P_{n,d}(\beta)\ge0
\]

when both quantities are defined on the same graph ensemble. C195 says the annealed odd part is asymptotically negligible in the configuration model. C194 says the source conjecture asks for the odd part of the **quenched** pressure to be `o(beta)` at zero temperature. Formally this reduces the hard step to proving that the two zero-temperature annealing-gap slopes agree:

\[
\frac{\Gamma_{n,d}(\beta)-\Gamma_{n,d}(-\beta)}{\beta}\longrightarrow0
\quad\text{in the required }n\to\infty,\ \beta\to\infty\text{ order.}
\]

Differentiating the odd pressure gives

\[
\frac{d}{d\beta}\big(P_{n,d}(\beta)-P_{n,d}(-\beta)\big)
=P'_{n,d}(\beta)+P'_{n,d}(-\beta),
\]

so another exact formulation is to control the average ferromagnetic/antiferromagnetic energy mismatch over `[0,beta]`.

This route explains precisely why the most relevant 2025 theorem does not close the problem. Gheissari--Perkins--Yap prove the fixed-magnetization **ferromagnetic** free energy up to the tree reconstruction threshold, and their positive-temperature Zdeborová--Boettcher application pairs the unconstrained antiferromagnet/MaxCut side with zero-magnetization ferromagnet/MinBis. It does not identify the balanced antiferromagnetic pressure `P_{n,d}(-beta)` required by C194, and in any event stops at finite temperature below reconstruction. Dembo--Montanari--Sen recover the desired symmetry after `d->infinity`, but that changes the source order of limits.

Thus a viable new proof route is now much more specific than “use spin glasses”: establish a source-compatible comparison of the **balanced** quenched pressures at `+beta` and `-beta`, first for a fixed `d` (beginning with `d=3`), and then obtain a uniform enough zero-temperature limit. The configuration-model reflection suggests using a two-type interpolation/switching argument whose error measures only the quenched correlation correction.
