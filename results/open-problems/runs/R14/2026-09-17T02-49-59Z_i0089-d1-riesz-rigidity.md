## 4. Proof: Delone bounds and one-point force balance

Write the configuration in increasing order

`... < x_{-1} < x_0 < x_1 < ...`.

Definition 11(i) gives a uniform lower gap bound. Definition 11(ii) gives a uniform upper gap bound: if every ball of radius `R` contains a point, no consecutive gap can exceed `2R`. Hence there are constants

`0 < a_- <= g_i := x_{i+1}-x_i <= a_+ < infinity`

for every `i in Z`.

Fix `i`. Choose a bounded interval `D` containing `x_i` in its interior and no other point of `X`. Apply Definition 11(iii) with `N=n=1`, moving only `x_i` to `y in D`. The chemical-potential term vanishes because the particle number is unchanged. Thus `x_i` is a local minimizer of

`U_i(y) = sum_{j != i} |y-x_j|^{-s}`.

The derivative series is locally uniformly absolutely convergent: the Delone lower bound gives `|x_i-x_j| >= a_- |i-j|`, and `sum_{m>=1} m^{-(s+1)} < infinity`. Therefore `U_i'(x_i)=0` and, with `p=s+1`,

`F_i(x) := sum_{j<i} (x_i-x_j)^(-p) - sum_{j>i} (x_j-x_i)^(-p) = 0`.       (4.1)

Equivalently, for the odd function

`phi(t)=sgn(t)|t|^{-p}`,

`F_i(x)=sum_{j != i} phi(x_i-x_j)=0`.

Only this necessary first-order consequence of the full equilibrium condition is used in the rigidity argument.

## 5. Proof: translate the labels, not the particles

This is the decisive #18 reformulation.

Define the index-shifted sequence

`y_i := x_{i+1}`

and its displacement

`h_i := y_i-x_i = g_i`.

The sequence `y` represents exactly the same unlabeled configuration as `x`, so its force at label `i` is the force of `x` at label `i+1`. Hence

`F_i(y)=F_{i+1}(x)=0=F_i(x)`.

Since

`phi'(t) = -p |t|^{-(p+1)}`

away from zero, the mean-value formula gives, for `i != j`,

`phi(y_i-y_j)-phi(x_i-x_j) = -c_{ij}(h_i-h_j)`,

where

`c_{ij} := p int_0^1 |(1-t)(x_i-x_j)+t(x_{i+1}-x_{j+1})|^{-(p+1)} dt > 0`.     (5.1)

Subtracting the two zero-force identities therefore yields

`sum_{j != i} c_{ij}(h_i-h_j) = 0`     for every `i`.                         (5.2)

The conductances are symmetric: `c_{ij}=c_{ji}`.

The Delone bounds compare every `r`-step distance with `r`. For `r=|i-j|`, both `|x_i-x_j|` and `|x_{i+1}-x_{j+1}|` lie between `a_- r` and `a_+ r`, and they have the same sign before absolute values. Hence their convex interpolation does too, and (5.1) gives the two-sided comparison

`p a_+^{-(s+2)} r^{-(s+2)} <= c_{ij} <= p a_-^{-(s+2)} r^{-(s+2)}`.          (5.3)

In particular every weighted degree `c_i=sum_{j!=i}c_{ij}` is finite and positive.

Thus the bounded gap sequence `h=(h_i)` is harmonic for the irreducible reversible Markov chain

`P(i,j)=c_{ij}/c_i`.

## 6. Proof: the conductance network is recurrent

Let

`E(f) = (1/2) sum_{i,j} c_{ij}(f_i-f_j)^2`

be the Dirichlet energy of a finitely supported function `f`. By (5.3), grouping unordered pairs by `r=j-i>0`,

`E(f) <= C sum_{r>=1} r^{-(s+2)} sum_i (f_{i+r}-f_i)^2`                       (6.1)

for a finite constant `C` depending only on the Delone lower bound and `s`.

For each `r`, Cauchy-Schwarz gives

`(f_{i+r}-f_i)^2 <= r sum_{k=i}^{i+r-1} (f_{k+1}-f_k)^2`.

After summing over `i`, each nearest-neighbor increment occurs in exactly `r` of these intervals, so

`sum_i (f_{i+r}-f_i)^2 <= r^2 sum_k (f_{k+1}-f_k)^2`.                       (6.2)

Combining (6.1)–(6.2),

`E(f) <= C (sum_{r>=1} r^{-s}) sum_k (f_{k+1}-f_k)^2
      = C zeta(s) sum_k (f_{k+1}-f_k)^2`.                                  (6.3)

Here the short-range threshold `s>1` enters exactly through convergence of `zeta(s)`.

Take the triangular cutoff

`f_N(i)=(1-|i|/N)_+`.

Then `f_N(0)=1`, `f_N` has finite support, and

`sum_k (f_N(k+1)-f_N(k))^2 = 2/N`.

Therefore

`E(f_N) <= 2 C zeta(s)/N -> 0`.                                             (6.4)

The capacity of `{0}` in the connected symmetric conductance network is zero, hence the associated Markov chain is recurrent. This is the standard Dirichlet/capacity criterion for recurrence; (6.4) is also an explicit recurrence certificate.

## 7. Proof: recurrent harmonic Liouville theorem forces equal gaps

Because `a_- <= h_i <= a_+`, the harmonic function `h` is bounded. Let `tau_j` be the hitting time of an arbitrary state `j` for the conductance chain started at `i`. Irreducibility plus recurrence gives `tau_j<infinity` almost surely.

Since `h(X_n)` is a bounded martingale, optional stopping at `n wedge tau_j` and dominated convergence give

`h_i = E_i h(X_{n wedge tau_j}) -> E_i h(X_{tau_j}) = h_j`.

Thus `h_i=h_j` for every `i,j`, so every gap is the same number `a>0`. Hence

`X=a Z+tau`.

This proves the structural assertion.

For the scale, the source proves that every Definition-11 equilibrium configuration has intensity `rho(mu)` in (36). An arithmetic progression of spacing `a` has intensity `1/a`. Equation (27) at `d=1`, together with the source's Theorem 36 `e(s)=zeta(s)` for `s>1`, gives

`mu = (1+s) zeta(s) rho^s`.

Therefore

`a = 1/rho(mu) = (((1+s) zeta(s))/mu)^(1/s)`.

The theorem follows. Since the property holds for every `s>1`, the metric satisfies `S_1<=1`; by definition `S_1>=1`, hence `S_1=1`.

## 8. Source-normalization correction exposed by the proof

The literal short-range scale printed in source equation (37) and Conjecture 38 is

`r = mu^(-1/s)`

multiplying a unit-covolume minimizer of (107). In `d=1`, that minimizer is `Z`, so the printed formula would give density `mu^(1/s)`.

But the same paper's exact thermodynamic identities (27) and (36), plus `e(s)=zeta(s)`, give instead

`rho(mu) = [mu / ((1+s) zeta(s))]^(1/s)`.

Since `(1+s)zeta(s)>1` for every `s>1`, these cannot both be correct under the same `mu` normalization. The corrected spacing consistent with the paper's own density identity is

`r_correct = ((1+s) zeta(s))^(1/s) mu^(-1/s)`.

I record this as a **source normalization slip / correction**, not as a claim that the substantive full crystallization conjecture is refuted. The frozen metric deliberately asks only for “a scaled translate of Z,” so this normalization issue does not affect `S_1=1`.
