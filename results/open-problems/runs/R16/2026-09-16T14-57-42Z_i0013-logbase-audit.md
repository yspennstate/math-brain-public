## 4. R16-I0013-C01 — base-2 normalization correction in Matsui Remark 2.4(ii)

**STATUS: PROVED for Matsui's displayed expression.**

**Scope.** This audits the asymptotic algebra in the display quoted above. It does not claim Bradley's theorem itself is wrong, because Bradley's corrected primary text was inaccessible in this run.

Let `d_B>0` denote the literal coefficient multiplying the sum in (2.1). Matsui uses base-2 logarithms, so for
\[
\tau(k)=\frac{\alpha}{\log_2(k\vee2)}
\]
we have, with natural logarithm `ln`,
\[
\frac1{\log_2 k}=\frac{\ln2}{\ln k}.
\]
Therefore
\[
S_n:=\sum_{k=1}^n\frac{\tau(k)}k
=
\alpha\ln2\sum_{k=3}^n\frac1{k\ln k}+O(1).
\tag{4.1}
\]

Since \(x\mapsto 1/(x\ln x)\) is eventually positive decreasing, its sum-integral discrepancy converges. Hence
\[
\sum_{k=3}^n\frac1{k\ln k}
=
\ln\ln n+C+o(1),
\]
and
\[
\boxed{
S_n
=
\alpha\ln2\,\ln\ln n+C_\alpha+o(1).
}
\tag{4.2}
\]

Define
\[
E_n=
\exp\left(-\frac{d_B}{2}S_n\right),
\qquad
L_n=\log_2 n.
\]
Because \(\ln\ln n=\ln L_n+O(1)\),
\[
\boxed{
E_n
=
C_0 L_n^{-d_B\alpha\ln2/2}(1+o(1))
}
\tag{4.3}
\]
for some \(C_0\in(0,\infty)\).

Put
\[
x_n=n^{1/2}E_n.
\]
Then
\[
\log_2x_n
=
\frac12L_n+O(\log L_n),
\]
so
\[
(\log_2x_n)^\gamma
=
2^{-\gamma}L_n^\gamma(1+o(1)).
\tag{4.4}
\]
For \(q(x)=x^2(\log_2^+x)^\gamma\),
\[
\boxed{
q(x_n)
=
C_0^2 2^{-\gamma}
nL_n^{\gamma-d_B\alpha\ln2}(1+o(1)).
}
\tag{4.5}
\]

Thus the displayed Bradley condition has threshold
\[
\boxed{
q(x_n)=o(n)
\iff
\frac{\gamma}{\alpha}<d_B\ln2.
}
\tag{4.6}
\]
At equality, \(q(x_n)/n\) tends to a positive finite constant; above it, the ratio grows as a positive power of \(L_n\).

### Consequence for Matsui's displayed inequality

Remark 2.4(ii) writes, with the same symbol `d`,
\[
\exp\left[-\frac d2\sum_{k=1}^n\frac{\tau(k)}k\right]
\le
(\log_2n)^{-d\alpha/2}.
\tag{4.7}
\]
But (4.3) has exponent \(-d\alpha\ln2/2\), and
\[
0<\ln2<1.
\]
If `d` has the same literal numerical value on both sides, the left side in (4.7) is asymptotically larger by a positive power of \(\log_2n\), so (4.7) cannot hold eventually.

This does **not** invalidate Matsui's qualitative discussion, because `d` is unspecified and the discrepancy can be absorbed by renaming
\[
d_{\rm eff}=d_B\ln2.
\tag{4.8}
\]
The quantitative lesson is narrower and important: if Bradley's literal construction constant is recovered later, it must be transferred to Matsui's global base-2 normalization with this factor unless a prior rescaling of `d` is explicitly present in Bradley/Matsui.
