## 2. Idea before code

The new idea is to stop treating `x^T B^{-1}x=+-1` as an inverse-quadratic concentration event. For each Boolean `x`, diagonal switching turns it into **ordinary singularity of a symmetric 0/1 matrix**. Adding a rank-one parameter then separates exactly the singular 0/1 matrices whose unique kernel direction is affine (`sum v_i != 0`) from those whose dependence is balanced (`sum v_i=0`). The familiar zero-row mechanism becomes exactly the deterministic `2m` solutions `+-B e_j`; subtracting it leaves a clean no-zero-row affine-corank-one probability.

This is not another renamed coupling lemma: it is an exact identity for the full remainder after the trivial richness contribution is removed.

Seidel switching itself is classical. In the usual loopless convention the Seidel matrix is `J-I-2A` and switching is diagonal `+-1` conjugation. Here the random diagonal signs are retained, so the convenient object is a looped `J-2C` version. I make no novelty claim for switching or the matrix-determinant lemma. The combined filtered-remainder reduction below is a candidate new route only; publication novelty is unverified.

## 3. Method #5 — add a rank-one parameter and differentiate

Let `C` be a symmetric `m x m` 0/1 matrix and define

`F_C(t) := det(t J - 2 C)`.

Because `tJ` has rank one,

`F_C(t) = det(-2C) + t * 1^T adj(-2C) 1`.                         (C317.1)

Thus `F_C` is affine in `t`.

### C317 — affine-corank criterion

Assume `C` is singular. Then

`J-2C` is invertible

if and only if

`corank(C)=1` and, for a nonzero `v` spanning `ker C`,

`1^T v != 0`.                                                     (C317.2)

Equivalently, zero is a simple root of the rank-one deformation `F_C(t)` and

`F_C'(0) != 0`.

#### Proof

If `corank(C)>=2`, a rank-one perturbation can increase rank by at most one, so `J-2C` remains singular. Equivalently `adj(C)=0`, hence (C317.1) vanishes identically.

Now suppose `corank(C)=1`, with `ker C=span(v)`. Then `adj(C)=lambda v v^T` for a nonzero scalar `lambda`, so

`1^T adj(C)1 = lambda (1^T v)^2`.

Hence (C317.1) has nonzero slope exactly when `1^T v !=0`.

There is also a direct kernel proof. If `(J-2C)w=0`, then

`Cw = (1/2)(1^T w) 1`.

Pair with `v`: because `v^T C=0`,

`0 = (1/2)(1^T w)(v^T 1)`.

When `v^T1 !=0`, this forces `1^T w=0`; then `Cw=0`, so `w=alpha v`, and again `1^T w=0` forces `alpha=0`. Thus `J-2C` is invertible. Conversely, if `1^T v=0`, then `(J-2C)v=0`. QED.

A useful consequence is stronger than the single point `t=1`: for singular `C`, once (C317.2) holds, `tJ-2C` is invertible for every `t != 0`. The obstruction is exactly transversality of the kernel to the hyperplane `1^perp`.

## 4. Method #18 — switching language and an exact same-dimension count

Let `B` be a symmetric sign `m x m` matrix and `x in {+-1}^m`. Put

`D_x = diag(x)`,

`C_x = (J - D_x B D_x)/2`.

Then `C_x` is a symmetric 0/1 matrix. Since `D_x x = 1`,

`D_x (B - x x^T) D_x = -2 C_x`,

`D_x (B + x x^T) D_x = 2(J-C_x)`.                                 (C317.3)

For invertible `B`, the determinant lemma gives

`x^T B^{-1}x = +1  <=>  C_x is singular`,

`x^T B^{-1}x = -1  <=>  J-C_x is singular`.                       (C317.4)

For a fixed `x`, diagonal conjugation is a bijection on symmetric sign matrices, so when `B` is uniform, `C_x` is a uniform symmetric 0/1 matrix `C_m`. Also

`B invertible  <=>  J-2C_x invertible`.

The two alternatives in (C317.4) cannot both occur for invertible `B`; complementing `C` interchanges them. Summing over all `2^m` Boolean `x` yields the exact expectation identity

`E N(B_m)
 = 2^{m+1} P(C_m singular and J-2C_m invertible)`

` = 2^{m+1} P(corank(C_m)=1 and 1^T ker(C_m) != 0).`               (C317.5)

Here the last notation means that the one-dimensional kernel is not contained in `1^perp`, and follows from C317.2.

Thus run 51's average inverse-quadratic richness is **exactly** the probability of a simple affine dependence in a random symmetric 0/1 matrix.

### Switching-orbit interpretation

Modulo the global sign `x ~ -x`, the matrices `C_x` are the `2^{m-1}` looped Seidel-switching representatives of `B`. Equation (C317.4) says that `N(B)/2` counts representatives for which the 0/1 matrix or its complement is singular. The standard Seidel-switching language is classical; this interpretation is recorded only to expose the geometry of the new filter.

## 5. Exact removal of the trivial `2m` switching solutions

Every invertible sign matrix `B` has the `2m` deterministic richness solutions

`x = +- B e_j`,  `1<=j<=m`,

because

`(B e_j)^T B^{-1}(B e_j)=B_jj in {+-1}`.

They are pairwise distinct because `B` is invertible.

Under the switching map above, these are exactly the representatives where the singular 0/1 side has a zero row:

- if `B_jj=+1`, `x=+-B e_j` makes row/column `j` of `C_x` identically zero;
- if `B_jj=-1`, it makes row/column `j` of `J-C_x` identically zero.

Conversely a zero row in the relevant side forces `x=+-B e_j`.

Define the nontrivial affine-corank remainder event

`E_m^aff = { C_m has corank 1; ker(C_m)=span(v) with 1^T v !=0; C_m has no zero row }`,

and

`r_m := P(E_m^aff)`.

### C318 — exact remainder identity

For uniform symmetric sign `B_m`,

`E[ N(B_m) - 2m 1_{det B_m !=0} ] = 2^{m+1} r_m`.                 (C318.1)

Equivalently,

`E N(B_m) = 2m(1-q_m^sym) + 2^{m+1} r_m`.                         (C318.2)

#### Proof

By C317.5 it suffices to isolate zero-row matrices inside

`{C singular, J-2C invertible}`.

On this event C317.2 already implies `corank(C)=1`. Hence `C` cannot have two zero rows: two zero rows would make two rows of `J-2C` identical. For a fixed row `j`, forcing row/column `j` of a symmetric 0/1 matrix to zero costs exactly `m` independent bits, hence probability `2^{-m}`. After moving `j` first,

`C = [[0,0],[0,D]]`,

and

`J-2C = [[1,1^T],[1,J-2D]]`.

Subtracting the first row/column exactly as in run 51 gives congruence to

`diag(1,-2D)`.

Thus `J-2C` is invertible iff the remaining `(m-1)x(m-1)` symmetric 0/1 matrix `D` is invertible. By run 51's dimension-shift equivalence this has probability `1-q_m^sym`. The zero-row events are disjoint under `J-2C` invertible, so their total probability is

`m 2^{-m}(1-q_m^sym)`.

Multiply by `2^{m+1}` in C317.5. This contributes exactly `2m(1-q_m^sym)`, leaving (C318.1). QED.

This is the sharpest source-relevant reformulation obtained so far: the entire nontrivial average richness is a single **no-zero-row affine corank-one probability**.

Combining C318 with run 51 C316 gives the exact exponential-rate criterion

`q_n^sym = 2^{-n+o(n)}`

if and only if

`r_m <= 2^{-m+o(m)}`.                                             (C318.3)

The lower-order trivial term is already polynomial times `2^{-m}`; no estimate on balanced kernel directions is needed in this filtered formulation.

Notice also what the filter removes. In a 0/1 symmetric matrix, an equality of two rows has kernel vector `e_i-e_j`, whose coordinate sum is zero. Such balanced row-collision mechanisms automatically make `J-2C` singular and never enter `r_m`. The affine filter keeps the zero-row mechanism and excludes this competing balanced mechanism exactly.

## 6. Method #28 — a typical-core transversality richness

C318 is still an event probability. To expose a typical-core statistic, double-count the principal minors of matrices in `E_m^aff`.

For an invertible symmetric 0/1 `d x d` matrix `D`, define

`T(D) := #{ z in {0,1}^d \ {0} :
             z^T D^{-1}z in {0,1},
             1^T D^{-1}z != 1 }`,

and put `T(D)=0` when `D` is singular.

Let `m=d+1`.

### C319 — support-weighted affine child identity

If `C_m` is in `E_m^aff` and `v` spans its kernel, write `s(v)=|supp(v)|`. Then

`E[ s(v) 1_{E_m^aff} ] = m 2^{-m} E T(D_{m-1}).`                  (C319.1)

Since `C_m` has no zero row, `s(v)>=2`; trivially `s(v)<=m`. Therefore

`2^{-m} E T(D_{m-1}) <= r_m
 <= (m/2) 2^{-m} E T(D_{m-1}).`                                   (C319.2)

Consequently

`r_m <= 2^{-m+o(m)}`

if and only if

`E T(D_d)=2^{o(d)}`.                                               (C319.3)

Thus the source conjecture has been reduced again, now to a **transversality richness** that automatically deletes the canonical column-image solutions.

#### Proof

For a symmetric corank-one matrix `C` with kernel vector `v`,

`adj(C)=lambda v v^T`, `lambda !=0`.

Hence the principal minor obtained by deleting coordinate `j` is invertible iff `v_j !=0`. Therefore a matrix in `E_m^aff` is counted exactly `s(v)` times by pairs `(C,j)` with invertible complementary principal minor.

Fix `j=m` and write

`C = [[D,z],[z^T,t]]`,

where `D` is symmetric 0/1 of size `d=m-1`, `z in {0,1}^d`, and `t in {0,1}`. Conditional on `D` being invertible, Schur complementation gives

`C singular <=> t = z^T D^{-1}z`.

Since `t` is a bit, this requires the quadratic value to lie in `{0,1}` and then determines `t` uniquely. A spanning kernel vector is

`v = (-D^{-1}z, 1)`.

Its coordinate sum is nonzero iff

`1 - 1^T D^{-1}z !=0`.

Because `D` is invertible it has no zero row; under the singularity condition the only way the new row is zero is `z=0` (which also forces `t=0`). Hence the no-zero-row condition is exactly `z!=0` in this decomposition.

There are `2^m` equally likely pairs `(z,t)`, and exactly `T(D)` of them work. Thus for a fixed deleted coordinate the probability is `2^{-m} E T(D)`. Summing over `m` coordinates proves (C319.1); `2<=s(v)<=m` gives (C319.2), and polynomial factors do not affect exponential rate, proving (C319.3). QED.

A useful check on the meaning of the linear transversality condition is that every canonical column image `z=D e_j` satisfies

`1^T D^{-1}z = 1`,

so it is excluded from `T(D)` automatically. This is precisely what was missing from the raw quadratic richness `N(B)`.
