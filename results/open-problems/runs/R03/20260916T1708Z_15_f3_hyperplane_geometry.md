## 2. The three new-method moves

### Move #1 — CHANGE THE CATEGORY: real singularity -> finite-field cube geometry

Instead of asking directly whether a real sign matrix is singular, normalize it to a binary matrix as in retained C240 and ask for invertibility over an odd finite field. Real singularity implies singularity modulo every prime, so any lower bound on finite-field invertibility gives a rigorous real-invertibility certificate.

The choice `F_3` exposes a useful exact geometric dichotomy for subspaces generated by Boolean vectors. This route **moves the metric** in Section 5.

### Move #11 — DUALIZE: eliminate higher corank before attacking the hyperplane

The retained sign-to-binary normalization preserves corank exactly, not merely singularity. Combining it with Jain--Sah--Sawhney's published rank-deficiency theorem shows that corank at least two is target-scale negligible. Thus the true sharp obstruction can be treated as a random corank-one hyperplane problem. This succeeds as a reduction; it does not close the source conjecture.

### Move #24 — FIND THE EXTREMAL OBJECT: fat cube hyperplanes / partition subspaces

Voigt--Ziegler identify the expected cube-vertex count of a random spanned hyperplane as an equivalent formulation of the sharp problem, with the `d + binom(d,2)` fat hyperplanes `x_i=0` and `x_i=x_j` giving the conjectured leading term. This is a successful geometric localization, but the remaining non-fat real-hyperplane expectation is still open.

## 3. R03-C242 — Boolean-rich subspaces over F3

**Status: PROVED.**

Let

\[
C_m=\{0,1\}^m\subset\mathbb F_3^m
\]

and let `W <= F_3^m` have dimension `k`.

### Theorem

Either `W` is a partition/Boolean subspace, in which case

\[
|W\cap C_m|=2^k,
\]

or

\[
\boxed{|W\cap C_m|\le \frac34\,2^k.}
\tag{C242.1}
\]

A partition/Boolean subspace means: some ambient coordinates are identically zero, while the remaining coordinates are partitioned into `k` nonempty blocks and all coordinates in each block equal one free variable.

The number of such `k`-subspaces is exactly

\[
\boxed{
N_{m,k}=\sum_{r=k}^m {m\choose r}S(r,k),
}
\tag{C242.2}
\]

where `S(r,k)` is the Stirling number of the second kind.

### Proof

Choose `k` ambient coordinates for which projection `W -> F_3^k` is an isomorphism. In these coordinates, every ambient coordinate restricted to `W` is a linear form

\[
\ell(u)=a_1u_1+\cdots+a_ku_k,
\qquad a_i\in\mathbb F_3.
\]

The cube intersection injects into those `u in {0,1}^k` for which every coordinate form takes a value in `{0,1}`.

First classify a linear form which maps **every** Boolean input to `{0,1}`. Evaluating on `e_i` shows each coefficient is `0` or `1`. If two coefficients were `1`, evaluation on `e_i+e_j` would give `2`, impossible. Hence such a form is either zero or exactly one coordinate projection.

It remains to bound a nonspecial form. Let `s` be its number of nonzero coefficients, `p` the number equal to `1`, and `q` the number equal to `-1=2`. For a uniform Boolean vector `U`, use a primitive cube root `omega`. Each nonzero Bernoulli factor has Fourier magnitude

\[
\left|\frac{1+\omega^{\pm1}}2\right|=\frac12.
\]

Fourier inversion on `F_3` therefore gives

\[
\Pr(\ell(U)=2)
=
\frac13+rac23\,2^{-s}
\cos\!\left(\frac{(p-q)\pi}{3}-\frac{4\pi}{3}\right).
\]

If `s>=3`, this is at least `1/3-(2/3)2^{-3}=1/4`. For `s=2`, the three coefficient patterns are checked directly and again at least one quarter of the four Boolean inputs map to `2`. For `s=1`, coefficient `1` is the excluded special coordinate projection, while coefficient `2` has failure probability `1/2`. Thus every nonspecial form is valid on at most `3/4` of Boolean inputs, proving (C242.1).

If all coordinate forms are special, each ambient coordinate is zero or a copy of one free Boolean variable. Rank `k` forces every variable to occur. Choosing the `r` nonzero ambient coordinates and partitioning them into `k` nonempty equality blocks proves (C242.2). QED.

The checker exhaustively verifies the `3/4` bound for every `F_3` linear form through `k=8`; that is a self-check of the analytic proof, not its logical basis.

At hyperplane dimension `k=m-1`,

\[
N_{m,m-1}
=m+{m\choose2},
\]

and these subspaces are precisely the modular fat hyperplanes `x_i=0` and `x_i=x_j`.

## 4. R03-C243 — explicit all-n odd-prime invertibility recurrence

**Status: PROVED.**

Let `A_m` be an `m x m` iid uniform binary matrix, viewed over `F_3`. Generate its rows sequentially. Let `I_k` be the event that the first `k` rows are independent over `F_3`.

For a partition `k`-subspace, the number of ordered Boolean bases is the number of `k x k` binary matrices invertible over `F_3`. We only need an upper bound. Define

\[
D_k=(2^k-1)(2^k-2)\cdots(2^k-k)
\]

(the distinct-nonzero bound), and for `k<=8` let `R_k` be the retained exact number of real-invertible `k x k` binary matrices. Since `F_3`-invertibility implies nonzero integer determinant,

\[
B_k^{(3)}\le A_k:=\min(D_k,R_k)
\]

for `k<=8`; for larger `k`, set `A_k=D_k`.

The retained exact values used are

\[
R_1=1,\ R_2=6,\ R_3=174,\ R_4=22560,\ R_5=12514320,
\]

\[
R_6=28836612000,\quad
R_7=270345669985440,\quad
R_8=10160459763342013440.
\]

Therefore

\[
U_{m,k}:=\min\!\left(1,\frac{N_{m,k}A_k}{2^{mk}}\right)
\tag{C243.1}
\]

is an upper bound for the probability that the first `k` rows are independent and span a partition subspace.

Set

\[
L_{m,1}=1-2^{-m}.
\]

For `1<=k<m`, put `q_{m,k}=2^{k-m}` and define recursively

\[
\boxed{
L_{m,k+1}
=
\left(1-\frac34q_{m,k}\right)L_{m,k}
-
\frac14q_{m,k}U_{m,k}.
}
\tag{C243.2}
\]

Then

\[
\boxed{
\Pr(A_m\text{ invertible over }\mathbb F_3)\ge L_{m,m}.
}
\tag{C243.3}
\]

### Proof

Condition on `I_k` and let `W` be the current row span. If `W` is not a partition subspace, C242 gives

\[
\Pr(\text{next row}\in W\mid W)\le\frac34q_{m,k}.
\]

If `W` is a partition subspace, its Boolean intersection has exactly `2^k` points, so the corresponding probability is exactly `q_{m,k}`. Thus

\[
\Pr(I_{k+1})
\ge
\left(1-\frac34q\right)\Pr(I_k)
-
\frac14q\Pr(I_k\text{ and }W\text{ partition}).
\]

Use `Pr(I_k)>=L_{m,k}` and the upper bound (C243.1), proving the recurrence.

Finally, `F_3`-invertibility implies nonzero integer determinant, so a binary matrix invertible over `F_3` is invertible over `R`. Retained C240 says sign singularity at order `n` is exactly binary real singularity at order `m=n-1`. Hence, for every `n>=2`,

\[
\boxed{
\Pr(\det B_n=0)\le1-L_{n-1,n-1}.
}
\tag{C243.4}
\]

This is a fully explicit, all-`n` finite-field certificate. It is not asymptotically sharp; its value is that it provides a new rigorous finite remainder envelope and exposes the correct extremal hyperplanes.

## 6. R03-C244 — corank >=2 is target-scale negligible

**Status: PROVED reduction from published theorem.**

The C240 normalization is rank preserving in the exact sense

\[
\operatorname{corank}(B_n)=\operatorname{corank}(A_{n-1}^{0/1}),
\]

because row reduction produces the block matrix `diag(1,-2A)`.

Jain--Sah--Sawhney, *Rank deficiency of random matrices* (arXiv:2103.02467), prove for every fixed `k>=1` that

\[
\lim_{m\to\infty}\frac1m\log_2
\Pr(\operatorname{corank} A_m\ge k)=-k.
\]

Taking `k=2` and `m=n-1`,

\[
\Pr(\operatorname{corank}B_n\ge2)=2^{-2n+o(n)}.
\]

Consequently

\[
\boxed{
2^n\Pr(\operatorname{corank}B_n\ge2)
=2^{-n+o(n)}=o(n^2).
}
\tag{C244}
\]

Thus higher corank cannot contribute to the sharp normalized remainder. The asymptotic obstruction is entirely corank one after the trivial pair mechanisms are removed.

A July 2026 paper of Song--Wang extends rank-deficiency estimates to growing `k=O(sqrt(log n))`; it corroborates the direction but is not needed for C244.

## 7. R03-C245 — Voigt-Ziegler hyperplane recoding of the sharp residual

**Status: KNOWN equivalence + new R03 synthesis; PARTIAL, not closure.**

Voigt--Ziegler define `E(d)` as the expected number of cube vertices in the linear hyperplane spanned by `d-1` random independent binary vectors and prove

\[
P_s(d)
=
\left(2^{-d}E(d)+\frac{d^2}{2^{d+1}}\right)(1+o(1)).
\]

Their Corollary 1.2 makes the sharp binary singularity conjecture equivalent to

\[
\boxed{E(d)\sim d^2/2.}
\tag{C245.1}
\]

The `d+binom(d,2)` fat hyperplanes `x_i=0` and `x_i=x_j` already supply that leading expected contribution.

Under C240, `d=n-1`, so this is the same asymptotic as the assigned sign-matrix target. C244 additionally removes rank at most `d-2` at the sharp `2^{-d}` scale. Hence the unresolved problem may be stated cleanly as:

> show that the expected cube-vertex contribution from **non-fat corank-one hyperplanes** is `o(d^2)`.

The modular C242 theorem is an exact finite-field analogue of this geometry: its full-cube subspaces are precisely partition subspaces, and in codimension one they are exactly the same coordinate/equality hyperplanes; every other modular subspace loses at least a factor `3/4` in cube intersection.

This conceptual match is useful, but the modular sieve has many false-positive finite-field dependencies and therefore does not itself imply (C245.1).
