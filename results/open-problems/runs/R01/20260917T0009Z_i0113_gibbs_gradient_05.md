# 4. Method #4 — a complete Gibbs theorem: spectral L2 contraction of coordinate gradients

The previous report asked for a clean theorem for Gibbs alone before tackling the Metropolis kink. The full pointwise Bakry--Emery sub-commutation remains unproved, but there is a dimension-free, nonperturbative gradient theorem that can be proved exactly.

Fix a positive target law `pi` on `{0,1}^n`. Normalize Salez's Gibbs/heat-bath flip rates so that the uniform target has rate `1/n` per coordinate:

\[
\boxed{
 c_i(x)=\frac{2}{n}\frac{\pi(x^i)}{\pi(x)+\pi(x^i)}.
}
\tag{4.1}
\]

Then

\[
\boxed{c_i(x)+c_i(x^i)=\frac{2}{n}.}
\tag{4.2}
\]

Let

\[
D_i f(x):=f(x^i)-f(x),
\qquad
u_j(x):=\log\frac{\pi(x^j)}{\pi(x)},
\]

and for `i != j` define the target log-odds influence matrix

\[
A_{ij}:=\sup_x|\nu_j(x^i)-\nu_j(x)|,
\qquad A_{ii}:=0.
\tag{4.3}
\]

The mixed discrete Hessian is symmetric in `i,j`, hence `A` is a symmetric nonnegative matrix. Write

\[
\Lambda:=\lambda_{\max}(A).
\tag{4.4}
\]

## R01-I0113-C005 — heat-bath spectral sup-gradient contraction

**STATUS: PROVED.** This is a Gibbs-only theorem and therefore **PARTIAL for Salez Problem 2.7**.

For every function `f` and every `t>=0`,

\[
\boxed{
\left(\sum_{i=1}^n\|D_iP_tf\|_\infty^2\right)^{1/2}
\le
\exp\!\left[-\frac{4-\Lambda}{2n}t\right]
\left(\sum_{i=1}^n\|D_if\|_\infty^2\right)^{1/2}
}
\tag{4.5}
\]

whenever `Lambda<4`. More generally, (4.5) holds with a non-decaying exponential if `Lambda>=4` as the same logarithmic-norm estimate.

### Proof

Write

\[
Lf(x)=\sum_j c_j(x)D_jf(x).
\]

For `i != j`, coordinate flips commute. Splitting the `j=i` term and using (4.2) gives the exact identity

\[
\begin{aligned}
D_iLf(x)
={}&-\frac{2}{n}D_if(x)\\
&+\sum_{j\ne i}c_j(x^i)\bigl[D_if(x^j)-D_if(x)\bigr]\\
&+\sum_{j\ne i}\bigl(c_j(x^i)-c_j(x)\bigr)D_jf(x).
\end{aligned}
\tag{4.6}
\]

Set

\[
h_i(t,x):=D_iP_tf(x),
\qquad
a_i(t):=\sup_x|h_i(t,x)|,
\]

and

\[
b_{ij}:=\sup_x|c_j(x^i)-c_j(x)|,
\qquad b_{ii}:=0.
\tag{4.7}
\]

Because the state space is finite, `a_i(t)` is locally Lipschitz. At a differentiability time choose a state `x` and sign `sigma` with `sigma h_i(t,x)=a_i(t)`. Apply (4.6) to `P_t f`. For every `j != i`,

\[
\sigma\bigl(h_i(t,x^j)-h_i(t,x)\bigr)
\le |h_i(t,x^j)|-a_i(t)\le0,
\]

so the middle line of (4.6) is non-positive at the maximizer. The last line is at most `sum_j b_ij a_j(t)`. Thus, in upper-Dini-derivative form,

\[
\boxed{
D^+a_i(t)\le-\frac2n a_i(t)+\sum_{j\ne i}b_{ij}a_j(t).
}
\tag{4.8}
\]

Let `B=(b_ij)`. Since `-2I/n+B` is a Metzler matrix, the standard comparison theorem and Euclidean logarithmic norm imply

\[
\|a(t)\|_2
\le
\exp\!\left[
\left(-\frac2n+\lambda_{\max}\frac{B+B^T}{2}\right)t
\right]\|a(0)\|_2.
\tag{4.9}
\]

It remains to bound `B` from the target measure. Equation (4.1) rewrites

\[
c_j(x)=\frac{2}{n}\sigma(\nu_j(x)),
\qquad
\sigma(u)=\frac{e^u}{1+e^u}.
\]

Since `|sigma'(u)|<=1/4`,

\[
b_{ij}\le\frac{A_{ij}}{2n}.
\tag{4.10}
\]

Both `(B+B^T)/2` and `A` are symmetric nonnegative matrices, and (4.10) gives entrywise domination

\[
\frac{B+B^T}{2}\le\frac{A}{2n}.
\]

Perron--Frobenius/Rayleigh monotonicity for symmetric nonnegative matrices yields

\[
\lambda_{\max}\!\left(\frac{B+B^T}{2}\right)
\le\frac{\Lambda}{2n}.
\tag{4.11}
\]

Substituting (4.11) into (4.9) proves (4.5). `square`

### Ising specialization

For an Ising target in the convention

\[
\pi(x)\propto\exp\left(\sum_{i<j}J_{ij}x_ix_j+\sum_i h_ix_i\right),
\]

one has

\[
A_{ij}=4|J_{ij}|\quad(i\ne j).
\]

Thus `lambda_max(|J|)<1` is a simple dimension-free sufficient condition for strict contraction in (4.5). This is a route diagnostic, not a cutoff theorem.

### What C005 does **not** prove

The quantity in (4.5) is

\[
\left(\sum_i\sup_x|D_iP_tf(x)|^2\right)^{1/2}.
\]

Pedrotti--Salez needs a **local weighted energy** estimate of the form

\[
\Gamma P_tf(x)\le Ce^{-ct/n}P_t\Gamma f(x).
\tag{4.12}
\]

There is no dimension-free inequality that simply replaces the separate coordinate suprema in (4.5) by the same-state local energy on the right side of (4.12). Maxima for different coordinates may occur at different states. Therefore C005 is a genuine nonperturbative Gibbs advance but does not clear the source blocker.

This identifies the missing upgrade much more sharply: **localize the spectral gradient contraction without paying a factor growing with `n`.**
