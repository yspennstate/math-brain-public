# 4. Method #11 — dualize the Gibbs `Gamma_2` problem exactly

The preceding report left the candidate

\[
\Gamma_2(f)(x)\stackrel{?}{\ge}2\delta_*\Gamma(f)(x),
\qquad
\delta_*:=\min_{y,k}\delta_k(y),
\tag{4.1}
\]

for the source Gibbs/heat-bath rates. Instead of attacking the full function space, this run eliminates every mixed second difference exactly.

Normalize Gibbs rates so the uniform target flips each coordinate at rate `1/n`:

\[
c_i(x)=\frac{2}{n}\frac{\pi(x^i)}{\pi(x)+\pi(x^i)},
\qquad q:=\frac2n.
\tag{4.2}
\]

Then

\[
c_i(x)+c_i(x^i)=q.
\tag{4.3}
\]

At a fixed state `x`, define

\[
a_i:=c_i(x),\qquad g_i:=D_i f(x),\qquad
h_{ij}:=D_iD_jf(x)\quad(i<j),
\]

and for `i != j`

\[
r_{i\mid j}:=c_i(x^j)-a_i,
\qquad
X_{ij}:=a_j r_{i\mid j}.
\tag{4.4}
\]

For each unordered pair set

\[
S_{ij}:=a_jc_i(x^j)+a_ic_j(x^i)>0,
\qquad
D_{ij}:=X_{ij}-X_{ji}.
\tag{4.5}
\]

## R01-I0113-C006 — exact heat-bath two-spin / Schur reduction

**STATUS: PROVED.** This is an algebraic reduction, not a cutoff theorem and not source closure.

For every positive target law on the cube and every function `f`,

\[
\boxed{
\begin{aligned}
\Gamma_2(f)(x)
={}&\sum_i \frac{a_i(3q-2a_i)}4 g_i^2\\
&+\sum_{i<j}\Bigg[
\frac{S_{ij}}4h_{ij}^2
+\frac{D_{ij}}2(g_i-g_j)h_{ij}
+\frac{X_{ij}}4g_i^2
+\frac{X_{ji}}4g_j^2
-\frac{X_{ij}+X_{ji}}2g_ig_j
\Bigg].
\end{aligned}}
\tag{4.6}
\]

Consequently, with

\[
K_{ij}:=\frac{D_{ij}^2}{S_{ij}},
\tag{4.7}
\]

we have the completed-square identity

\[
\boxed{
\Gamma_2(f)(x)-2\delta\Gamma(f)(x)
=\sum_{i<j}\frac{S_{ij}}4
\left(h_{ij}+\frac{D_{ij}}{S_{ij}}(g_i-g_j)\right)^2
+g^TH_x(\delta)g,
}
\tag{4.8}
\]

where the explicit `n x n` symmetric matrix is

\[
\boxed{
\begin{aligned}
H_{ii}
&=\frac{a_i(3q-2a_i)}4
+\frac14\sum_{j\ne i}(X_{ij}-K_{ij})
-\delta a_i,\\
H_{ij}
&=\frac{K_{ij}-X_{ij}-X_{ji}}4
\qquad(i\ne j).
\end{aligned}}
\tag{4.9}
\]

Thus at a fixed state `x`,

\[
\boxed{
\Gamma_2(f)(x)\ge2\delta\Gamma(f)(x)\ \forall f
\quad\Longleftrightarrow\quad
H_x(\delta)\succeq0.
}
\tag{4.10}
\]

### Proof

Start from

\[
\Gamma(f)(x)=\frac12\sum_i a_i g_i^2,
\qquad
\Gamma_2(f)=\frac12L\Gamma(f)-\Gamma(f,Lf).
\]

At `x^k`, the `k`-edge contribution to `Gamma` is `(q-a_k)g_k^2/2` by (4.3), while for `i != k`,

\[
D_if(x^k)=g_i+h_{ik},
\qquad c_i(x^k)=a_i+r_{i\mid k}.
\]

Hence

\[
L\Gamma(f)(x)
=\frac12\sum_k a_k\left[(q-2a_k)g_k^2+
\sum_{i\ne k}\{c_i(x^k)(g_i+h_{ik})^2-a_ig_i^2\}\right].
\tag{4.11}
\]

The exact commutation identity from the preceding run becomes

\[
D_kLf(x)
=-qg_k+\sum_{i\ne k}c_i(x^k)h_{ik}
+\sum_{i\ne k}r_{i\mid k}g_i.
\tag{4.12}
\]

Therefore

\[
\Gamma(f,Lf)(x)
=\frac12\sum_k a_kg_kD_kLf(x).
\tag{4.13}
\]

Insert (4.11)--(4.13), separate one-coordinate terms from unordered pairs `{i,j}`, and collect coefficients. The one-coordinate term is exactly

\[
\frac{a_i(3q-2a_i)}4g_i^2.
\]

For a fixed pair `i<j`, putting `A=c_i(x^j)` and `B=c_j(x^i)` yields

\[
\frac{a_jA+a_iB}{4}h_{ij}^2
+\frac{a_jA-a_iB}{2}(g_i-g_j)h_{ij}
+\frac{a_j(A-a_i)}4g_i^2
+\frac{a_i(B-a_j)}4g_j^2
-\frac{a_j(A-a_i)+a_i(B-a_j)}2g_ig_j,
\]

which is (4.6) because

\[
a_jA-a_iB=X_{ij}-X_{ji}=D_{ij},
\quad
a_jA+a_iB=S_{ij}.
\]

Completing the square in each independent `h_{ij}` subtracts

\[
\frac{D_{ij}^2}{4S_{ij}}(g_i-g_j)^2
=\frac{K_{ij}}4(g_i-g_j)^2,
\]

and subtracting `2 delta Gamma = delta sum_i a_i g_i^2` gives exactly (4.8)--(4.9). At a fixed vertex, the values `g_i` and `h_{ij}` can be assigned independently by specifying `f` on the radius-two cube neighborhood, so minimizing over all `h_{ij}` proves the equivalence (4.10). QED.

### A heat-bath compatibility constraint that the matrix reduction retains

Writing

\[
u=\pi(x),\quad v=\pi(x^i),\quad w=\pi(x^j),\quad z=\pi(x^{ij}),
\]

one gets

\[
r_{i\mid j}
=q\frac{uz-vw}{(w+z)(u+v)},
\qquad
r_{j\mid i}
=q\frac{uz-vw}{(v+z)(u+w)}.
\tag{4.14}
\]

Thus the two cross-rate increments on each square always have the **same sign**. This is extra structure absent from an arbitrary rate matrix and is the most promising ingredient for proving `H_x(delta_*) >= 0` analytically.

The reduction is useful even if (4.1) eventually fails: it turns the full Bakry--Emery question into an explicit local PSD problem with one matrix per state.

# 6. Method #30 — one interaction direction at a time: sharpen C005 for Ising

The preceding C005 theorem used the crude logistic derivative bound and in the Ising specialization gave contraction under `lambda_max(|J|)<1`. The exact heat-bath form yields a sharper and more natural interaction matrix.

Take spins in `{−1,+1}^n` and

\[

\exp\left(\sum_{i<j}J_{ij}x_ix_j+\sum_i h_ix_i\right),
\qquad J=J^T,\quad J_{ii}=0.
\tag{6.1}
\]

Define the local field

\[
H_i(x)=h_i+\sum_{j\ne i}J_{ij}x_j.
\]

With the same Gibbs normalization (4.2),

\[
\boxed{
c_i(x)=\frac1n\bigl(1-x_i\tanh H_i(x)\bigr).}
\tag{6.2}
\]

For `i != j`, flipping coordinate `i` changes `H_j` from `u+J_{ij}x_i` to `u-J_{ij}x_i`. Hence

\[
\sup_x|c_j(x^i)-c_j(x)|
\le\frac1n\sup_u|\tanh(u+J_{ij})-\tanh(u-J_{ij})|
=\frac{2}{n}\tanh|J_{ij}|.
\tag{6.3}
\]

Let `T` be the symmetric nonnegative matrix

\[
T_{ii}=0,
\qquad T_{ij}=\tanh|J_{ij}|.
\tag{6.4}
\]
