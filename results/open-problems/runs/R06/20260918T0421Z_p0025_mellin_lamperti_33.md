# 4. #6 — the tangent cocycle on the full Mellin strip

Run 31 derived the tangent cumulant for `q>0`. The same calculation actually has a larger exact domain.

Let an infinitesimal tangent separation be parametrized in boundary-local-time clock `ell`. For the exterior unit circle the excursion-angle measure used in the tangent projection calculation is

`nu(d alpha)= d alpha / (4 pi sin^2(alpha/2))`,

and the tangent projection multiplier is `|cos alpha|`. Put

`J(alpha)=-log |cos alpha| >= 0`.

The tangent log multiplier can be written

`Z_ell = ell - S_ell`,

where `S` is the driftless subordinator with Lévy measure equal to the image of `nu` under `J`. This representation is legitimate despite infinite excursion activity because

`int J nu(d alpha) < infinity`;

this will equal one below.

For real `q`, define

`Psi(q)= q + int (|cos alpha|^q-1) nu(d alpha)`

whenever the integral is finite. The only singularities relevant to the new term occur where `cos alpha=0`, where `nu` has a bounded density. Hence the exact integrability range is

`q>-1`.

### Proposition 4.1 — exact Mellin-strip cumulant

For every real `q>-1`,

`Psi(q) = q [1 - Gamma((q+1)/2)/(sqrt(pi) Gamma((q+2)/2))].`

Consequently, for every `ell>=0`,

`E exp(q Z_ell) = exp(ell Psi(q)),    q>-1.`

#### Proof

Because `|cos alpha|^q` has period `pi`, pair `alpha` and `alpha+pi`. On `0<alpha<pi`,

`csc^2(alpha/2)+csc^2((alpha+pi)/2)
 = csc^2(alpha/2)+sec^2(alpha/2)
 = 4/sin^2 alpha`.

Therefore

`I(q):=int (|cos alpha|^q-1) nu(d alpha)
      = (1/pi) int_0^pi (|cos alpha|^q-1)/sin^2 alpha d alpha
      = (2/pi) int_0^(pi/2) (cos^q alpha-1)/sin^2 alpha d alpha.`

For `q>-1`, integration by parts is allowed. The boundary term

`-(cos^q alpha-1) cot alpha`

vanishes both at `0` and at `pi/2`; at the latter endpoint it is of order `t^(q+1)-t`. Thus

`I(q)=-(2q/pi) int_0^(pi/2) cos^q alpha d alpha
     =-q Gamma((q+1)/2)/(sqrt(pi) Gamma((q+2)/2)).`

Adding the deterministic curvature term `q` proves the formula. The Lévy exponential formula gives the moment identity. `QED`

The positive-half formula from run 31 is therefore not a separate phenomenon: it is the positive part of a strip extending all the way to, but not including, `q=-1`.

## 4.2 Exact jump tail

The image Lévy measure can be written explicitly. For `u>0`, set `c=e^{-u}` and `a=arccos c`. The event `J>u` is `|cos alpha|<c`. Using the same `alpha,alpha+pi` pairing,

`nu(J>u)
 = (1/pi) int_a^(pi-a) csc^2 alpha d alpha
 = (2/pi) cot a
 = 2 e^{-u}/[pi sqrt(1-e^{-2u})].`

Hence the Lévy density of `S` is

`Pi(du) = [2/pi] e^{-u}(1-e^{-2u})^(-3/2) du,    u>0.`

This makes both ends transparent:

- near zero, the process has infinite jump activity of order `u^(-3/2) du`, but finite variation;
- at infinity the jump tail is exponentially small with exact rate one.

The tail formula also recovers the first two jump moments directly:

`int J nu(d alpha)=int_0^infinity nu(J>u)du=1`,

and

`int J^2 nu(d alpha)=2 int_0^infinity u nu(J>u)du=2 log 2`.

Thus

`E Z_ell=0,    Var(Z_ell)=2 ell log 2`,

agreeing with run 31.

## 4.3 The inverse-moment estimate we were missing

Let `M_ell=e^{Z_ell}` be the tangent multiplicative factor. For every `0<p<1`, Proposition 4.1 gives

`E M_ell^{-p}=exp(ell Psi(-p))<infinity.`

Therefore, for every `h in (0,1)`,

`P(M_ell <= h) <= exp(ell Psi(-p)) h^p.`

This is the exact small-multiplier estimate needed when converting vector linearization to logarithmic linearization. It also identifies the sharp Mellin boundary `p=1`: inverse moments of order one and above are outside the strip.

### A useful compiler from vector error to log error

Suppose for one finite block a normalized nonlinear multiplier `Y_r>0` and tangent multiplier `M` satisfy

`E |Y_r-M| <= C r^eta`

and `E M^{-p}<=C_p` for some `p in (0,1)`. Fix `eps>0`, and let `a_eps=1-e^{-eps}`. If `M>h` and `|Y_r-M|<=a_eps h`, then `|log Y_r-log M|<=eps`. Hence

`P(|log Y_r-log M|>eps)
 <= C_p h^p + C r^eta/(a_eps h).`

With `h=r^(eta/(p+1))`,

`P(|log Y_r-log M|>eps)
 <= C_{eps,p} r^(eta p/(p+1)).`

So any polynomial **L1 vector** linearization immediately yields polynomial **in-probability log** linearization. This does not yet give the conditional first two log moments required below; for those one still needs a uniform tail estimate for the nonlinear multiplier itself. That distinction is important.

# 5. #11 — dualize to a scale function and a direct Lamperti recurrence criterion

## 5.1 Tangent process as a spectrally negative critical Lévy process

The representation

`Z_ell=ell-S_ell`

shows that the tangent log-separation is a bounded-variation spectrally negative Lévy process: deterministic upward speed one, only downward jumps, and exactly zero mean. Its Laplace exponent is `Psi` above.

Let `W` be its zero-scale function, normalized by

`int_0^infinity e^{-q x} W(x) dx = 1/Psi(q),    q>0.`

The standard two-sided exit identity gives, for `A>0`,

`P_0(tau_(+A) < tau_(-A)) = W(A)/W(2A).`

Since

`Psi(q)=(log 2) q^2 + O(q^3)` as `q downarrow 0`,

the standard monotone Tauberian theorem for scale functions gives

`W(x) ~ x/(log 2)` as `x->infinity`,

and therefore

`W(A)/W(2A) -> 1/2` as `A->infinity`.

This is a useful way to state the criticality: on large logarithmic bands the tangent process is asymptotically fair in the scale-function sense even though its individual jumps are one-sided. This scale-function observation is standard Lévy-process machinery, not a novelty claim.

## 5.2 A self-contained recurrence compiler for the nonlinear log distance

The source question would follow from a much weaker estimate than a pathwise coupling to the tangent process for all time.

Consider any adapted real process `U_n` with finite increments

`xi_(n+1)=U_(n+1)-U_n`.

Think of `U_n=-log |X-Y|` sampled after fixed blocks of boundary local time. Assume that there are constants `u0,C,eta,v,delta>0` such that, whenever `U_n>=u0`, almost surely

`(R1)   E[xi_(n+1) | F_n] <= C exp(-eta U_n),`

`(R2)   E[xi_(n+1)^2 | F_n] >= v,`

`(R3)   E[|xi_(n+1)|^(2+delta) | F_n] <= C.`

Then `U_n` cannot converge to `+infinity`.

### Proposition 5.1 — proof

Set `delta0=min(delta,1)`. Choose a large level `L`. For `u` large let `V(u)=log u`; below `L` extend `V` to a bounded nondecreasing function, with the extension chosen smoothly on a fixed compact interval. Only the large-`u` formula matters before the lower stopping time.

Fix `u` large and condition on `U_n=u`. Write `xi=xi_(n+1)` and

`A={|xi|<=u/2}`.

On `A`, the elementary Taylor inequality, valid for `|t|<=1/2`,

`log(1+t) <= t - t^2/2 + C_delta |t|^(2+delta0)`

gives

`V(u+xi)-V(u)
 <= xi/u - xi^2/(2u^2) + C |xi|^(2+delta0)/u^(2+delta0).`

On the positive tail `xi>u/2`,

`V(u+xi)-V(u) <= C (|xi|/u)^(2+delta0)`;

on the negative tail `xi<-u/2`, monotonicity of the clipped extension gives no positive contribution once `L` is fixed and `u` is large.

The tail correction to the first moment satisfies

`E[|xi| 1_(A^c) | F_n] <= C u^(-(1+delta))`,

and the tail correction to the second moment satisfies

`E[xi^2 1_(A^c) | F_n] <= C u^(-delta)`

by (R3). Hence (R2) implies, for all sufficiently large `u`,

`E[xi^2 1_A | F_n] >= v/2`.

Combining these estimates with (R1),

`E[V(U_(n+1))-V(U_n) | F_n]
 <= C e^(-eta u)/u - v/(4u^2) + O(u^(-2-delta0))
 <= -c/u^2`

for all large enough `u` and some `c>0`.

Now take `L` in that large regime and let

`tau_L=inf{n:U_n<=L},    tau_M=inf{n:U_n>=M}`.

After replacing `V` by `max(0,log(u/L))` below the working region, the stopped process is a nonnegative supermartingale up to `tau_L wedge tau_M`. Applying optional stopping first at a bounded time and then Fatou's lemma gives, for `L<u<M`,

`P_u(tau_M<tau_L) <= V(u)/log(M/L).`

Letting `M->infinity` shows that the probability of escaping to `+infinity` before returning to `(-infinity,L]` is zero. If `U_n->+infinity`, then for some deterministic `N` it eventually stays above `L` and reaches arbitrarily large `M`; taking a countable union over `N` contradicts the preceding bound. Thus

`P(U_n->+infinity)=0`. `QED`

### Why this is almost source-closing

Cranston--Le Jan prove finite-time noncoalescence in the exterior disc, so `U=-log|X-Y|` is finite at every finite time. The exterior planar reflected Brownian motion returns to the circle indefinitely, so the boundary-local-time clock supplies arbitrarily many finite blocks.

Consequently, if the actual synchronous pair can be sampled in fixed local-time blocks so that (R1)--(R3) hold uniformly over the remaining angular/position state when the separation is small, Proposition 5.1 gives

`U_n not-> +infinity`,

hence the pair distance fails to converge to zero and, in fact along the sampled times has a positive limsup. That would answer Burdzy 5(ii) affirmatively (indeed more strongly than the requested positive-probability conclusion, subject to the exact source quantifier on the fixed starting pair).

# 6. #30 — isolate spatial infinity in one local-time block

The main formal reason Burdzy's 2009 quantitative differentiability theorem cannot simply be quoted is that its setup is a smooth **bounded** domain. The exterior disc is unbounded. But in two dimensions the radial tail of one excursion can be computed exactly.

Let `H^x` be the exterior unit-disc Brownian excursion law from `x` on the circle, in the standard normal-derivative normalization. For `R>1` and a Brownian motion started at radius `1+eps`, the annulus harmonic function gives

`P_(1+eps)(tau_R < tau_1) = log(1+eps)/log R.`

Therefore the normal-derivative excursion normalization gives

`H^x(tau_R < zeta)=1/log R.`

If the exit system is written in another fixed local-time normalization, the right side is multiplied by one fixed convention constant; the `1/log R` dependence is unchanged.

During a local-time block of length `b`, the exit-system formula therefore yields

`P(some excursion reaches radius R during the block) <= C b/log R`,

with `C=1` in the preceding normal-derivative normalization.

Now choose, for current separation `r`,

`R(r)=exp(r^(-gamma)),    gamma>0.`

Then

`P(block reaches radius R(r)) <= C b r^gamma.`

This is the first quantitative statement in the R06 route that isolates the entire spatial-infinity obstruction at a freely chosen polynomial failure probability. It says that a one-block proof may be carried out inside an enormous but finite radius with probability `1-O(r^gamma)`.

What it does **not** say is that the constants in Burdzy's bounded-domain estimates remain uniform if one caps the domain at radius `R(r)`. Importing those constants without checking their dependence would be invalid. The right next step is to localize the proof itself to the unit-circle boundary and use the displayed tail only to discard the rare far excursions.

# 7. How the three pieces fit Burdzy's 2009 estimate

Burdzy's 2009 bounded-domain differentiability proof contains a quantitative one-block error estimate of the form

`E Xi <= C eps^(4/3) |log eps|`

and then, for suitable exponents `1<beta1<4/3` and `0<beta2<4/3-beta1`, a polynomial bad-event estimate of the form

`P(Xi > C eps^beta1) <= C eps^beta2`,

followed by a geometric-scale Borel--Cantelli argument. The paper explicitly assumes a smooth bounded domain, so these are **prior-art rates in a different global setup**, not an exterior-disc theorem.

If an exterior-disc analogue can be proved uniformly over the compact angular state for one fixed boundary-local-time block, the rates are already more than strong enough for the present target:

- the vector error after dividing by the initial separation is `o(1)` at a polynomial rate;
- Proposition 4.1 supplies tangent inverse moments of every order `<1`, converting that vector approximation into polynomial log approximation away from a controlled rare small-multiplier event;
- Section 6 discards excursions reaching `exp(r^-gamma)` with polynomial probability;
- the tangent block has zero mean, variance `2 b log 2`, and exponential moments on the negative-log side up to order `<1`;
- a sufficiently uniform moment version of the block approximation then yields (R1)--(R3), and Proposition 5.1 rules out convergence of the separation to zero.

This is now a concrete proof program with a single quantitative bottleneck rather than a vague recurrence heuristic.

## 7.1 Exact remaining estimate

A source-closing estimate would be the following. Let `r=|X-Y|`, let `U=-log r`, and sample after a fixed amount `b>0` of a suitable pair/local-time clock. There should exist `eta,delta,C,v>0`, uniform over all admissible angular/midpoint states once `r` is sufficiently small, such that for the nonlinear log increment `Delta U`,

`E[Delta U | state] <= C r^eta,`

`E[(Delta U)^2 | state] >= v,`

`E[|Delta U|^(2+delta) | state] <= C.`

Because `r^eta=e^{-eta U}`, this is exactly (R1)--(R3).

The first inequality is the hardest one. Convergence in probability to the centered tangent increment is not enough: rare very strong contractions can contribute to the mean. The negative-Mellin strip proved in Section 4 controls the tangent rare event, but one still needs a corresponding nonlinear inverse-tail bound or a stopped/truncated argument that retains the Lamperti drift estimate.
