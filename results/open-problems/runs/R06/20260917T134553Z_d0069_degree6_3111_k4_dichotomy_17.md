### Theorem R06-D0069-T4

Let `G` be an infinite, connected, loopless, vertex-transitive `6`-regular multigraph. Assume that at every vertex the parallel-edge multiplicities are

\[
\boxed{[3,1,1,1]};
\]

that is, each vertex has one neighbour joined by three parallel edges and three further neighbours joined by one edge each. Parallel edge copies count as distinct SAW choices exactly as in Grimmett--Li. Then

\[
\boxed{\mu(G)\ge \sqrt 5.}
\]

This proves one admissible unresolved `Delta=6` subclass of the source question. It does **not** prove the full source question.

The proof below is a dichotomy on the simple skeleton. The point of methods #15 and #21 is that the obstruction to the scalar weighted-blue argument from run 16 is exactly a classical minimum-cut/K4 phenomenon; when the skeleton has no K4, finite edge connectivity is strong enough to recover the original Grimmett--Li condition-Pi route, and when K4s do occur, they form a finite gadget system whose critical transfer mass is strictly greater than one.

## 3. Skeleton and the invariant factorization

Replace each parallel class of `G` by one simple edge. Call the resulting graph `H`.

Because the local multiplicity pattern is `[3,1,1,1]`, `H` is infinite, connected, simple, vertex-transitive and `4`-regular. Let

- `T` be the set of skeleton edges whose class has multiplicity `3` in `G`;
- `S` be the set of skeleton edges whose class has multiplicity `1`.

Multiplicity is graph-theoretically invariant, so every automorphism of `G` preserves `T` and `S`. Each vertex has exactly one incident `T` edge and three incident `S` edges. Thus

\[
T\text{ is a perfect matching of }H,
\qquad
S\text{ is a spanning cubic factor.}
\tag{3.1}
\]

For a finite vertex set `A`, write

\[
a(A)=|\delta_H(A)\cap T|,
\qquad
b(A)=|\delta_H(A)\cap S|.
\]

The cut in the multigraph `G` has exactly

\[
|\delta_G(A)|=3a(A)+b(A)
\tag{3.2}
\]

edge copies.

There is also a parity invariant. Since `T` is 1-regular and `S` is 3-regular,

\[
a(A)\equiv |A|\pmod2,
\qquad
b(A)\equiv3|A|\equiv |A|\pmod2.
\tag{3.3}
\]

Hence

\[
\boxed{a(A)\equiv b(A)\pmod2,\qquad a(A)+b(A)\text{ is even}.}
\tag{3.4}
\]

This small invariant is what kills the apparent size-five boundary case.

## 4. Literature-shaped dichotomy: minimum cuts versus K4 blocks

A standard theorem of Tindell on regular vertex-transitive graphs says, in the form needed here, that a nontrivial minimum edge cut of cardinality `d` in a connected `d`-regular vertex-transitive simple graph forces a system of imprimitivity whose blocks have size `d` and induce `K_d`'s. Equivalently for our `4`-regular skeleton: if a finite nontrivial side of an edge cut has boundary `4`, then `H` has a `K4` block system. The usual proof is the finite-cut atom/submodularity argument; only the cut side is finite, so the same argument applies to the finite-side edge-connectivity setting of an infinite locally finite transitive graph.

This is not claimed as new. It is the classical super-edge-connectivity/minimum-cut mechanism that run 16's scalar LP certificate had not used.

We therefore split into two cases.

## 5. Case I: the skeleton contains no K4

For a connected vertex-transitive simple `4`-regular graph, the finite-side edge connectivity is `4`; this is the same Babai--Watkins/Mader input used by Grimmett--Li in their proof of Theorem 4.1(a).

Take a nonempty finite `A subset V(H)`.

If `|A|=1`, then exactly one `T` edge and three `S` edges leave `A`, so by (3.2)

\[
|\delta_G(A)|=3+3=6.
\tag{5.1}
\]

Now suppose `|A|>=2`. Since `H` has no `K4`, the minimum-cut theorem above rules out

\[
|\delta_H(A)|=a(A)+b(A)=4.
\]

By (3.4), this skeleton cut size is even. Therefore

\[
a(A)+b(A)\ge6.
\tag{5.2}
\]

Using (3.2),

\[
|\delta_G(A)|=3a(A)+b(A)\ge a(A)+b(A)\ge6.
\tag{5.3}
\]

The six edges incident with a single vertex form a finite-side cut of size six, so

\[
\boxed{\lambda_f(G)=6.}
\tag{5.4}
\]

At this point the remainder is exactly the graph-theoretic part of Grimmett--Li's Theorem 4.1(a) proof and does not use simplicity once `lambda_f=Delta` is available: contract the complement of a large ball, apply finite Menger to obtain six pairwise edge-disjoint long SAWs from the root, and use local finiteness/compactness to pass to six pairwise edge-disjoint infinite SAWs. Grimmett--Li observe that this implies condition `Pi`. Their Theorem 4.3 then yields

\[
\mu(G)\ge\sqrt{6-1}=\sqrt5.
\tag{5.5}
\]

Thus the theorem holds whenever `H` contains no `K4`.

### Why this really escapes run 16's barrier

Run 16 proved that a multiplicity-only two-state `h`-transform cannot certify `[3,1,1,1]` at `r=sqrt5` using only the scalar blue count. The present proof does not contradict that barrier. It adds an independent global invariant: **finite-cut structure**. In the K4-free case that invariant upgrades the multigraph's finite-side edge connectivity all the way to six and bypasses the scalar weighted-blue LP entirely.

## 6. Case II: the skeleton contains K4

Assume `H` contains a clique `K` on four vertices. Since `H` is 4-regular, every vertex of `K` has three edges inside `K` and exactly one skeleton edge leaving it. Hence

\[
|\delta_H(K)|=4,
\]

a nontrivial minimum cut. Tindell's minimum-cut theorem gives a vertex partition

\[
\mathcal B=\{B_i\}
\tag{6.1}
\]

into induced `K4` blocks. The transitive automorphism group inherited from `G` permutes these blocks transitively.

Moreover, the setwise stabilizer of a block is transitive on its four vertices: if `u,v` lie in the same block, take an automorphism sending `u` to `v`; it sends the unique K4 block containing `u` to the unique block containing `v`, hence stabilizes that block.

Because the stabilizer also preserves the invariant matching `T`, the statement

> the unique `T` edge at a vertex stays inside its K4 block

has the same truth value at all four vertices. There are therefore exactly two block types.

### Type A: all T edges are external

Then every internal edge of the K4 is a singleton `S` edge, while the unique external edge at each port is a triple `T` class.

### Type B: all T edges are internal

Then the internal `T` edges form a perfect matching of the K4, all other internal K4 edges are singleton `S` edges, and every external edge is singleton.

There is no mixed case.

Contract every K4 block to one macro-vertex. The resulting block graph is infinite, connected and locally finite, so it contains an infinite simple ray

\[
B_0,B_1,B_2,\ldots.
\tag{6.2}
\]

At an intermediate block, the entering and exiting external edges use distinct ports because every K4 vertex has exactly one external skeleton edge.

We now sum, rather than select, all internally self-avoiding routes through each block. This is method #15: the exceptional high-symmetry configuration is not an annoyance to exclude; it carries enough finite transfer mass to prove the theorem directly.

## 7. Exact K4 transfer at the critical point

Put

\[
z=\frac1{\sqrt5}.
\tag{7.1}
\]

A skeleton path with edge multiplicities `m_1,...,m_l` corresponds to `prod m_i` edge-copy-distinct G-paths, so its contribution to the critical SAW generating function is

\[
(\prod_i m_i)z^l.
\]

Between two distinct ports `a,b` of a K4 there are exactly five vertex-simple internal paths:

- one path of length `1`;
- two paths of length `2`;
- two paths of length `3`.

We include the outgoing external edge to the next block in the block transfer factor.

### 7.1 Type A block

All six internal K4 edges have multiplicity one and the outgoing external edge has multiplicity three. Therefore the total transfer mass is

\[
M_A
=3z\,(z+2z^2+2z^3)
=3z^2+6z^3+6z^4.
\]

At `z=1/sqrt5`,

\[
\boxed{
M_A=\frac{21}{25}+\frac{6\sqrt5}{25}>1.
}
\tag{7.2}
\]

### 7.2 Type B block, matched ports

Suppose the entry and exit ports form one of the internal triple matching edges. The five internal simple paths have total weighted mass

\[
3z+2z^2+6z^3.
\]

The outgoing external edge is singleton, so

\[
\boxed{
M_{B,\mathrm{match}}
=z(3z+2z^2+6z^3)
=\frac{21}{25}+\frac{2\sqrt5}{25}>1.
}
\tag{7.3}
\]

### 7.3 Type B block, unmatched ports

If the two ports are not a T-matched pair, the five internal simple paths have total weighted mass

\[
z+6z^2+10z^3.
\]

Thus

\[
\boxed{
M_{B,\mathrm{unmatch}}
=z(z+6z^2+10z^3)
=\frac35+\frac{6\sqrt5}{25}>1.
}
\tag{7.4}
\]

The smallest of the three transfer factors is `M_{B,match}`. Its strict inequality above is exactly

\[
\frac{21}{25}+\frac{2\sqrt5}{25}>1
\iff 2\sqrt5>4
\iff20>16.
\tag{7.5}
\]

Set

\[
M_*:=\frac{21}{25}+\frac{2\sqrt5}{25}>1.
\tag{7.6}
\]

## 8. Concatenating the block transfers

Fix the block ray (6.2). For each traversed block, independently choose one of its five simple internal entry-to-exit paths, and choose the appropriate edge copy whenever a triple class is used.

Because the macro-ray never repeats a block and each internal route is vertex-simple, every concatenation is a genuine vertex-self-avoiding walk in `G`. Different internal path / edge-copy choices are distinct SAWs. The critical mass factorizes block-by-block, and after `k` full block traversals the total mass is at least

\[
c_0 M_*^k
\tag{8.1}
\]

for a fixed positive initial factor `c_0` independent of `k`.

Since `M_*>1`, these critical masses do not tend to zero; in fact they grow exponentially in the number of blocks. Consequently

\[
\sum_{n\ge0}\sigma_n(G)z^n=\infty
\qquad\text{at }z=1/\sqrt5.
\tag{8.2}
\]

Hence the radius of convergence is at most `1/sqrt5`, so

\[
\boxed{\mu(G)\ge\sqrt5.}
\tag{8.3}
\]

This proves Theorem R06-D0069-T4 in the K4 case and completes the dichotomy.

In fact the transfer factors are strictly greater than one, so by continuity this K4-block branch gives a strict inequality `mu(G)>sqrt5`; the theorem records only the source-matching lower bound.
