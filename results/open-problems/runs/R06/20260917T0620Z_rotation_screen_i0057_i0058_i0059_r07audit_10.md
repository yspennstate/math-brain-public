## 9. Independent audit of newest R07 package — I0077-R07-T14

Newest neighboring report read:

Source: Burdzy–Scheutzow, *Forward Brownian Motion*, Problem 7.8. R07's metric moved `12 -> 13` by introducing **finite disconnected parabolic fans**. For

\[
D=\bigcup_{j=1}^m[a_j,b_j],
\qquad
\mathcal F_D=\{(-u,x):u>0,\ x/\sqrt u\in D\}\cup\{(0,0)\},
\]

write `lambda_j=lambda_0(a_j,b_j)` and `lambda_*(D)=min_j lambda_j`. T14 claims:

1. if `lambda_*(D)>1`, no FBM is eventually confined to the fan;
2. if `lambda_*(D)<1`, some decomposable FBM is eventually confined to the fan a.s.;
3. if a component contains zero and has `lambda_j<1`, some decomposable FBM is pointwise confined to the fan for all negative times.

I checked the proof at the actual theorem scope.

### T14(i): PASS

On an eventual-confinement event, the normalized path

\[
y(u)=X_{-u}/\sqrt u
\]

is continuous on a connected half-line. Since `D` is a **finite disjoint union** of compact intervals with positive gaps, the tail image must lie in a single component. A deterministic component has positive-probability confinement on a subevent. Because its principal OU eigenvalue is strictly above 1, continuity under a small endpoint enlargement keeps it above 1. Source Theorem 4.3(i) on that enlarged interval forces a limsup/liminf escape, contradicting confinement in the original component. The strict enlargement is the correct way to avoid the endpoint-equality loophole.

### T14(ii): PASS

Choose a component with `lambda_j<1`. By endpoint continuity, shrink it to

\[
[a_j+\varepsilon,b_j-\varepsilon]
\]

while retaining

\[
\lambda_0(a_j+\varepsilon,b_j-\varepsilon)<1.
\]

Source Theorem 4.3(ii) then gives a decomposable FBM with

\[
\liminf y\ge a_j+\varepsilon,
\qquad
\limsup y\le b_j-\varepsilon.
\]

The strict margin implies eventual membership in `[a_j,b_j]`, hence in `D`. This is stronger than merely using the source theorem on the closed original component and is exactly the missing step needed for eventual exact membership.

### T14(iii): PASS

If one component contains zero and has eigenvalue below 1, source Theorem 4.3(iii) applied directly to that component gives pointwise confinement for all negative times, and the component is contained in the fan.
