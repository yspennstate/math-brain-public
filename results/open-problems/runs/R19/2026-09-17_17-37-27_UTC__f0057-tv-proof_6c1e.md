## 6. New proof mechanism

The complete argument is written in

`artifacts/R19/2026-09-17_17-37-27_UTC__f0057_full_proof_6c1e.md`

created at commit

`1b1359e095f7c267ade551b20a38d0a44647a2d4`

and read back at that exact commit.

The proof has three main moves.

### 6.1 #8 DISCRETIZE — arbitrary TV sets become finitely many count problems

For fixed `j`, write

\[
P_n=\mathcal L(Y_{(j)}),\qquad
Q_n=\mathcal L(\zeta_{n,(j)}),
\]

where `zeta_n` is the source's independent reference law (`xi` or tuned `xi^(n)`). Let

\[
S_n=\{k:P_n\{k\}>Q_n\{k\}\}.
\]

Then

\[
d_{\rm TV}(P_n,Q_n)=P_n(S_n)-Q_n(S_n).
\]

For any `delta>0`, use the same heavy-singleton/thin-interval partition architecture as Janson's `j=1` proof. It has `O(1/delta)` blocks, every nonsingleton `J` has `Q_n(J)<=delta`, and singleton discrepancies are uniformly `o(1)` because Janson already proves `d_K(P_n,Q_n)->0` for every fixed `j`.

On a nonsingleton block `J=[a,b]`, split

\[
A_n=S_n\cap J,\qquad
C_n=J\setminus S_n,\qquad
B_n^+=[b+1,\infty).
\]

Membership of the `j`-th order statistic is now controlled by the finite count triple `(N_A,N_C,N_B)`.

### 6.2 #10 DERANDOMIZE — one global cutoff controls every moving interval

Janson's proof supplies a cutoff `B_n` with

\[
P(Y_{(1)}>B_n)=o(1),
\qquad
nP(\zeta_n>B_n)=o(1),
\]

and a uniform fixed-coordinate local ratio below `B_n`.

I prove a uniform factorial-moment lemma: for any fixed number of pairwise disjoint **moving** sets below `B_n`, every fixed joint falling-factorial moment of their conditioned occupancy counts equals the corresponding iid factorial moment times `1+o(1)`, uniformly over the moving sets. Hence whenever their scaled iid probabilities converge, the whole count vector converges to independent Poisson variables.

The critical repair is that replacing every moving set by its truncation at `B_n` changes **all** conditioned count events only on the single global event `{Y_(1)>B_n}` and changes **all** iid count events only on `{max_i zeta_i>B_n}`. Both are `o(1)`. Thus there is no interval-dependent cutoff error to accumulate. This closes `P30H-F001`.

### 6.3 #23 DO WHAT THE PROPOSER DID NOT EXPECT — asymmetric rank-j sandwich

For a tail-good block, set scaled intensities

\[
\alpha_n=nP(\zeta_n\in A_n),
\quad
\gamma_n=nP(\zeta_n\in C_n),
\quad
\beta_n=nP(\zeta_n\in B_n^+).
\]

After subsequence extraction they converge to `(alpha,gamma,beta)`, and the three conditioned/iid counts converge to independent Poissons

\[
X\sim\mathrm{Po}(\alpha),\quad
Z\sim\mathrm{Po}(\gamma),\quad
R\sim\mathrm{Po}(\beta).
\]

If the block is `D`-good, then `alpha+gamma+beta<=D`. Since the iid event

\[
\{R=0,\ X+Z=j\}
\]

forces the `j`-th largest value into `J`, thinness gives

\[
\alpha+\gamma
\le
\eta_j(D,\delta)
:=\bigl(j!e^D\delta\bigr)^{1/j}.
\]

Rather than copy the maximum proof, use the exact implications:

- `Y_(j) in A_n` implies for some `r<j`:
  \[
  N_B=r,\quad N_A\ge1,\quad N_A+N_C\ge j-r;
  \]
- for the iid sample,
  \[
  \bar N_B=r,\quad \bar N_C=0,\quad \bar N_A\ge j-r
  \]
  implies `zeta_(j) in A_n`.

The Poisson gap is bounded by

\[
2\alpha\gamma\le2\eta_j(D,\delta)\gamma.
\]

Summing good blocks costs at most

\[
2D\eta_j(D,\delta).
\]

For bad blocks, let `J_*=[a_*,b_*]` be the rightmost bad nonsingleton block. Its own mass costs at most `delta+o(1)`. Every earlier bad block lies below `a_*`, so its total positive contribution is bounded by

\[
P(Y_{(j)}<a_*)
\le
P(\mathrm{Bin}(n,p_n)\le j-1)+o(1),
\qquad np_n>D.
\]

For fixed `j` and large enough `D`, Chernoff gives a uniform bound `<=e^{-D/8}+o(1)`.

Therefore

\[
\boxed{
\limsup_{n\to\infty}d_{\rm TV}(Y_{(j)},\zeta_{n,(j)})
\le
2D\bigl(j!e^D\delta\bigr)^{1/j}
+\delta+e^{-D/8}.
}
\]

For fixed `D`, let `delta downarrow 0`; then let `D to infinity`. This proves

\[
\boxed{d_{\rm TV}(Y_{(j)},\zeta_{n,(j)})\to0}
\]

for every fixed `j`.

The same proof covers the source's fixed-law and tuned `xi^(n)` formulations because the only source inputs are exactly the cutoff, Kolmogorov convergence, and uniform local-ratio estimates already established by Janson in the corresponding theorem/proof.
