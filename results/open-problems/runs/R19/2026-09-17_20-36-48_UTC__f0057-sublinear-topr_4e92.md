### Theorem S

Under the main fixed-law assumptions of Janson's Theorem 19.7, for **every** integer sequence

\[
1\le r_n=o(n),
\]

\[
\boxed{
 d_{\rm TV}\!\left(
 \mathcal L(Y_{(1)},\ldots,Y_{(r_n)}),
 \mathcal L(\xi_{(1)},\ldots,\xi_{(r_n)})
 \right)\to0.
}
\]

The same statement holds for the source's exactly tuned `xi^(n)` formulation, comparing with the top `r_n` order statistics of the tuned iid sample.

I do **not** claim in this run that the growing-dimensional theorem transfers to fixed `xi` under the separate weaker source clause `m/n=lambda+o(1/log n)`: the source proves that transfer for fixed `j`, but a growing vector would require a quantitative tuned-versus-untuned product-tail comparison.

### Proof mechanism

Choose

\[
D_n=\sqrt{n(r_n+1)},
\]

so `r_n=o(D_n)` and `D_n=o(n)`. Let `h_n` be the largest integer with

\[
nP(Z_{n,1}\ge h_n)\ge D_n.
\]

The source maximum cutoff implies `h_n<=U_n`, while `D_n/n->0` and unbounded support imply `h_n->infinity`.

Expose the labelled tail cloud

\[
T_n=[h_n,U_n],\qquad
\eta_n=\{(i,Z_{n,i}):Z_{n,i}\in T_n\}.
\]

Let `a_n=P(Z in T_n)`, `M_n=E[Z 1_T]`, and let `mu_n^c` be the mean of the complement law `p_n(. | Z notin T_n)`. For the cloud size `N_n` and total `W_n`, define the residual displacement

\[
\Delta_n=(m_n-W_n)-(n-N_n)\mu_n^c.
\]

The new invariant is the exact identity

\[
\boxed{E\Delta_n=m_n-n\mu_n.}
\]

Indeed `(1-a_n)mu_n^c=mu_n-M_n`, so the entire expected removed tail mass cancels. Moreover,

\[
\operatorname{Var}(\Delta_n)
\le nE[(Z_{n,1}-\mu_n^c)^2 1_{T_n}]=o(n),
\]

because `h_n->infinity` and the source has finite second moment / uniform square integrability. Hence

\[
\Delta_n=o_p(\sqrt n).
\]

Also `N_n/n->0` in probability because `a_n->0`.

Condition on the **exact labelled cloud** `nu`. The remaining coordinates are iid from the complement law, so the cloud likelihood ratio is exactly

\[
L_n(\nu)
=
\frac{P_{p_n^c}(S_{n-q(\nu)}=m_n-s(\nu))}
     {P_{p_n}(S_n=m_n)}.
\]

Choose a probability-`1-o(1)` typical set on which `q(\nu)=o(n)` and the residual centering error is `o(sqrt n)`. The complement law converges back to the source law, has the same eventual lattice span, the same positive limiting variance and remains uniformly square-integrable. Janson's Remark 14.2 therefore gives

\[
\sup_{\nu\in A_n}|L_n(\nu)-1|\to0.
\]

This uniformity needs no new quantitative local CLT: if it failed, a violating sequence of typical clouds itself defines a triangular-array subsequence satisfying Remark 14.2, a contradiction.

Since `E_P L_n=1`, likelihood-ratio convergence on a `P`-probability `1-o(1)` set already implies full tail-cloud TV:

\[
d_{TV}(\mathcal L(\eta_n\mid S_n=m_n),\mathcal L(\eta_n))\to0.
\]

Finally the iid cloud count has mean

\[
nP(h_n\le Z\le U_n)\ge D_n-o(1)\gg r_n,
\]

so it contains at least `r_n` atoms with probability `1-o(1)`; cloud TV transfers the same event to the conditioned model. On the source maximum-good event, the first `r_n` order statistics are a deterministic function of the tail cloud. Data processing for TV finishes the proof.

This removes `U_n` entirely from the allowable rank scale.
