# 4. Method #11: dualize the one-sided source proofs into a quadratic extraction statement

The key deterministic bridge is new to the R19 package but elementary.

## R19-I0110-C013 — uniform structural flattening implies ELE-U

Let `p_N` be a probability on `N` states and `s_N<=p_N` a structurally specified subprobability. Suppose that for some `B_N` and `delta_N->0`,

\[
|B_N|=o(N),
\qquad
\sup_{y\notin B_N}|Ns_N(y)-1|\le\delta_N.
\tag{4.1}
\]

Set `r_N=s_N 1_{B_N^c}` and `m_N=sum_y r_N(y)`. Then `m_N->1` and the ELE defect tends to zero.

**Proof.** Put `b_N=|B_N|/N`. From (4.1),

\[
(1-b_N)(1-\delta_N)\le m_N\le(1-b_N)(1+\delta_N),
\]

so `m_N->1`. Since `pi_N=1/N`,

\[
D_N=\frac1N\sum_y(Nr_N(y)-m_N)^2.
\]

On `B_N^c`, each summand is at most `(delta_N+|1-m_N|)^2`; on `B_N`, it equals `m_N^2`. Therefore

\[
D_N\le(\delta_N+|1-m_N|)^2+b_Nm_N^2\to0.
\]

`QED`

If a preliminary source step reaches a good root `z` with probability `1-o(1)`, and every root has a retained kernel `s_z` satisfying the same uniform bound, then the mixture also satisfies ELE-U. Indeed, with `v_z=s_z-m_z pi`, convexity gives

\[
\left\|\sum_z a_zv_z\right\|_{L^2(\pi^{-1})}^2
\le\sum_z a_z\|v_z\|_{L^2(\pi^{-1})}^2.
\tag{4.2}
\]

The point of C013 is that the last two source papers already contain almost all the required flattening argument; they only use the **lower** side because a TV deficit estimate is enough for their published purpose.

\Pr(|X-EX|>\epsilon)
