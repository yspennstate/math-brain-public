## 5. R10-GH-C003 — exact edge-scan transfer matrix

**Status: PROVED finite theorem.**

For every \(n\) for which the finite state computation terminates, the edge-scan transfer below returns the exact LR crossing probability \(p_n\). This run certifies n=1,...,9.

### State space

Wire every left-boundary vertex in \(L_n\) to one deterministic source. The \(n\) vertical bonds lying wholly on the left boundary then become irrelevant: after wiring, their states cannot change the LR event, and summing them out multiplies favorable and total configuration counts by the same \(2^n\).

At any stage the frontier contains \(w=n+1\) slots, one per row. A state is the connectivity partition of these frontier vertices induced by already exposed open bonds, with the source-connected block distinguished by label 0. Other component labels are canonicalized in first-occurrence order.

### One-column edge scan

Suppose a column is being transferred from the old frontier to the new frontier. Process rows \(j=0,\ldots,n\).

First expose the horizontal bond from old vertex \(j\) to new vertex \(j\).

- If it is **open**, the frontier slot can be reinterpreted as the new vertex and keeps the old component label. This is exact because no later edge can use the forgotten old vertex except through this open bond, so old and new are the same boundary component for future connectivity.
- If it is **closed**, the old vertex is forgotten and the new vertex starts as a singleton component. If the forgotten old vertex was the last source-connected frontier vertex, discard the branch: all future unexposed bonds lie strictly to the right, so the source can never reconnect.

After row \(j>0\)'s horizontal bond, expose the vertical bond between the already-created new vertices \(j-1\) and \(j\). The closed branch leaves the partition unchanged and the open branch merges their blocks. If either block is source-connected, the merged block is source-connected.

Canonicalization only renames non-source blocks and therefore preserves exact connectivity information.

### Why this processes every relevant bond exactly once

For each of the \(2n\) column transitions, the scan exposes
\[
(n+1)+n=2n+1
\]
random bonds: \(n+1\) horizontal bonds entering the new column and \(n\) vertical bonds inside it. Hence the total is
\[
E_n=2n(2n+1)=4n^2+2n.
\]
The original \(2n\times n\) rectangular grid has \(4n^2+3n\) bonds; the missing \(n\) are exactly the already-summed left-boundary vertical bonds.

Every original configuration therefore maps to exactly one sequence of transfer branches after the left-boundary factor is removed, and conversely every transfer sequence specifies the states of all \(E_n\) relevant bonds.

### Correctness at the final frontier

At every intermediate step, deleting a state with no source-connected frontier vertex is exact because all future bonds are on the unexposed side of the frontier.

After the \(2n\)-th column transition, the frontier *is* the right boundary \(R_n\). Hence a state survives exactly when at least one right-boundary vertex is connected to the wired left source. Therefore
\[
\boxed{
p_n=\frac{N_n}{2^{\,2n(2n+1)}},
}
\]
where \(N_n\) is the integer sum of multiplicities of the surviving final states.

No Monte Carlo or floating-point decision enters this computation.

The new checker does not merely reproduce its own output. For n=1,...,6 it compares its reduced rational values against the exact fractions archived by the preceding, structurally different column-mask transfer matrix. All six match exactly.

This is a strong finite self-check of the new transition representation, though it is not an independent human audit.
