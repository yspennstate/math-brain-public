## 3. Frozen metric, boundary discretisation, and Cardy normalisation

Fix
\[
R=[0,2]\times[0,1],\qquad \delta=1/n,\quad n\in\mathbb N.
\]
Let
\[
V_n=\{(i/n,j/n):0\le i\le 2n,\ 0\le j\le n\}
\]
and include every nearest-neighbour square-lattice edge contained in R. Each bond is open independently with probability 1/2. Let `LR_n` be the event that an open path joins the left vertex boundary
\[
L_n=\{0\}\times\{0,1/n,\ldots,1\}
\]
to the right vertex boundary
\[
R_n=\{2\}\times\{0,1/n,\ldots,1\}.
\]
Write
\[
p_n=\mathbb P_{1/2}(LR_n).
\]

For the continuum 2:1 rectangle, use the conventional elliptic cross-ratio \(\eta_2\in(0,1)\) determined by
\[
\frac{K(1-\eta_2)}{K(\eta_2)}=2.
\]
The standard Landen duplication identity gives
\[
\eta_2=17-12\sqrt2
=0.02943725152285941437973530948\ldots .
\]
Cardy's horizontal-crossing prediction is
\[
C_2=\mathcal C(\eta_2)
=\frac{3\Gamma(2/3)}{\Gamma(1/3)^2}
\eta_2^{1/3}
{}_2F_1\!\left(\frac13,\frac23;\frac43;\eta_2\right)
\]
with numerical self-check
\[
C_2=0.17564689380065523912935850094662299397\ldots .
\]
The numerical decimal is only a self-check; the metric is defined using the exact symbolic constant above.

## 4. R10-GH-C001 — exact frontier transfer matrix for n <= 6

**Status: PROVED finite theorem.**

For each n=1,...,6, the archived checker computes \(p_n\) exactly by an integer transfer matrix over connectivity partitions of one vertical lattice column.

### Proof of the transfer representation

Wire all n+1 left-boundary vertices to one deterministic source. The n vertical bonds lying entirely in the left boundary can then be omitted: after wiring, their states cannot change `LR_n`, and summing them out multiplies favourable and total configuration counts by the same factor \(2^n\).

Reveal columns from left to right. A frontier state after one revealed column is the partition of its n+1 vertices induced by the revealed open bonds, with every source-connected block given a distinguished label 0. When the next column is exposed there are exactly
\[
(n+1)+n=2n+1
\]
new random bonds: n+1 horizontal bonds joining old to new frontier vertices and n vertical bonds within the new column. For every one of their \(2^{2n+1}\) open/closed assignments, union-find updates the partition and then forgets the old frontier.

If after forgetting the old frontier no new vertex is source-connected, the state may be deleted exactly: all future bonds lie strictly to the right, so the source can never reconnect. Otherwise canonicalise the surviving partition. Repeat through the 2n column transitions.

Thus the DP processes exactly
\[
2n(2n+1)=4n^2+2n
\]
random bonds, i.e. all \(4n^2+3n\) bonds of the original grid except the n irrelevant wired-boundary vertical bonds. At the final column, a state survives if and only if some right-boundary vertex is connected to the source. Therefore
\[
p_n=\frac{N_n}{2^{2n(2n+1)}}
\]
where \(N_n\) is the exact integer sum of final-state multiplicities. This is not Monte Carlo.

As a separate base check, for n=1 the original un-wired seven-edge graph has all 128 bond configurations enumerated by brute-force BFS; exactly 64 cross.

## 5. R10-GH-C002 — an all-mesh certified error envelope

**Status: PROVED.**

For every n>=1 define
\[
\ell_n=1-(1-2^{-2n})^{n+1}.
\]
There are n+1 horizontal rows. The event that all 2n horizontal bonds of a fixed row are open has probability \(2^{-2n}\); these row events use disjoint bond sets, and each gives an LR crossing. Hence
\[
\ell_n\le p_n.
\]

For each of the 2n vertical cuts between consecutive lattice columns, an LR crossing must use at least one of the n+1 horizontal bonds crossing that cut. The 2n cut edge sets are disjoint, so
\[
p_n\le u_n:=(1-2^{-(n+1)})^{2n}.
\]

Therefore the following is a certified absolute-error bound on every mesh in the frozen sequence:
\[
\boxed{
 b(1/n)=
 \begin{cases}
 |p_n-C_2|,&1\le n\le6,\\[1mm]
 \max\{|\ell_n-C_2|,|u_n-C_2|\},&n\ge7.
 \end{cases}}
\tag{R10-metric}
\]
For n<=6 this is the exact error itself, hence cannot be improved without changing the target constant or discretisation.

The bound is deliberately not an asymptotic solution. Indeed \(\ell_n\to0\) and \(u_n\to1\), so the coarse tail envelope tends to
\[
1-C_2=0.82435310619934476087064149905\ldots,
\]
not to zero. The exact values n=1,...,6 decrease strongly, but six finite values are not a convergence proof.

The clean target is a quantitative observable/interpolation theorem of the following form. Construct a square-lattice observable \(F_\delta\) and a continuum Cardy observable F such that, on the 2:1 rectangle,
\[
\|\bar\partial_\delta F_\delta\|_{\ell^1(\text{cells})}
+\|F_\delta-F\|_{\partial R}
\le \varepsilon(\delta),\qquad \varepsilon(\delta)\downarrow0,
\]
and prove a discrete stability estimate converting this directly into
\[
|p_\delta-C_2|\le C\varepsilon(\delta).

The historical C0017 record shows why merely re-proving a zero contour sum is insufficient: one needs a quantitative defect whose **global cell sum tends to zero** plus uniqueness/stability of the boundary-value problem.
