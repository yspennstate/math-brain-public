### Lemma C037-A (cap-4 local-deficiency lemma)

For any word `w` of `r=2` or `r=3` minimal match pairs,

\[
\operatorname{LCS}(P(w))>r
\quad\Longleftrightarrow\quad
\operatorname{LCS}(P(\tau_4 w))>r,
\tag{C037.1}
\]

where `tau_4` is applied to every offset and leaves terminal bits unchanged.

### Proof

`P(tau_4 w)` is obtained from `P(w)` by deleting symbols inside individual homogeneous runs whose offset magnitude exceeds four. Hence every common subsequence of the capped pair is also a common subsequence of the original pair.

Conversely, if the original block is deficient, it has a common subsequence of length at least `r+1<=4`. Fix a witness of exactly `r+1` symbols. Inside any one homogeneous run of either generated string, that witness uses at most four positions total. Replacing a longer run by four copies of the same symbol therefore leaves enough positions in the same factor segment, in the same order, to realize the witness. Do this independently for every long run. The same length-`r+1` witness survives in the capped pair. This proves (C037.1). QED.

This is the key finite reduction. In particular, Lueker's clipped `l=+7` and `l=-7` tail labels are uniform for the local-deficiency test: every actual offset in a tail has the same cap `+4` or `-4`.

The same argument gives the general principle: to decide whether an `r`-factor block has LCS at least `r+1`, no homogeneous run needs more than `r+1` copies. That will be the natural entry point for length-four local obstructions later.
