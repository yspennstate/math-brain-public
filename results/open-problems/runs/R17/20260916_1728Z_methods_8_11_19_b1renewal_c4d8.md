# 2. Recovered bounded-span object

R17-C006/C007 define, for `n=rm`, a dependence-preserving bounded-span score `Q_{m,B}(x,y)`: split the source into `r` consecutive blocks of length `m`, allow each selected source block to use one ordered disjoint target interval of length at most `B` (arbitrary target gaps may be skipped), and maximize the sum of the blockwise LCS scores.

The proved uniform truncation theorem is

\[
0\le LCS(x,y)-Q_{m,B}(x,y)
\le m\Big\lfloor\frac{n}{B+1}\Big\rfloor,
\]

and the asymptotic shape constant

\[
q_{m,B}=\lim_{r\to\infty}
\frac{\mathbb E Q_{m,B}(X_1^{rm},Y_1^{rm})}{rm}
\]

satisfies

\[
q_{m,B}\le\gamma_2\le q_{m,B}+\frac{m}{B+1}.
\]

The previous stuck report identified `q_{2,1}` as the simplest strict special case that any proposed transfer architecture ought to close before attempting metric-relevant larger `B`.

# 3. Move 8 — discretize the correct `B=1` process

For `B=1`, each source block can contribute at most one point. A length-`m` binary block has only three relevant alphabet states:

\[
\{0\},\qquad \{1\},\qquad \{0,1\}.
\]

Their iid probabilities are

\[
P(\{0\})=P(\{1\})=2^{-m},
\qquad
P(\{0,1\})=1-2^{1-m}.
\]

This is an exact discretization of the bounded-span primal, not a Bernoulli-cell replacement. The source block itself remains the true random string block; the reduction is valid only because a singleton target interval scores one iff its bit lies in the block’s alphabet.

The useful finite process is a renewal construction on a single infinite iid target stream. For source blocks `X^(1),X^(2),...`, define greedily

\[
T_0=0,
\qquad
T_j=\min\{t>T_{j-1}:Y_t\in\operatorname{alph}(X^{(j)})\},
\]

and waiting times

\[
W_j=T_j-T_{j-1}.
\]

Because `T_{j-1}` is a stopping time for the iid target stream and `X^(j)` is independent of the past, the post-`T_{j-1}` target is fresh iid. Therefore the `W_j` are iid with the exact mixture law

\[
W=1\quad\text{with probability }1-2^{1-m},
\]

and, with probability `2^{1-m}`, the block is constant and

\[
P(W=k\mid\text{constant})=2^{-k},\qquad k\ge1.
\]

This stopping-time use of independence is legitimate; it does not assert independence of the full rectangular match array.

**Outcome of move 8: SUCCESS on the smallest strict bounded-span model.** The global boundary profile collapses to an iid one-dimensional renewal process for `B=1`.

# 4. Move 11 — an exact capacity dual for `B=1`

Every admissible `B=1` packing uses each of the `r` source blocks at most once and each used block contributes at most one. Hence pathwise

\[
\boxed{Q_{m,1}(x,y)\le r.}
\tag{D1}
\]

This is the exact source-block capacity dual: assigning unit dual price to each source block and zero additional price to target capacity certifies objective at most `r` for every admissible noncrossing packing.

No stationary approximation enters `(D1)`.

**Outcome of move 11: SUCCESS, but only for `B=1`.** It gives the exact asymptotic upper half of the special case and also explains why this case can saturate trivially when target supply is abundant.

# 5. Move 19 — greedy algorithm plus exact finite-to-infinite error

Run the greedy construction from Section 3 on an infinite target extension. If

\[
S_r:=W_1+\cdots+W_r\le mr,
\]

then all `r` source blocks are assigned to legal singleton target intervals inside the first `mr` target symbols, so

\[
Q_{m,1}=r.
\]

For `1<x<2`, the exact probability generating function is

\[
\mathbb E[x^W]
=(1-c_m)x+c_m\frac{x}{2-x},
\qquad c_m=2^{1-m}.
\]

Choose the rational point

\[
x=\frac43.
\]

Then

\[
\rho_m:=\mathbb E\left[x^{W-m}\right]
=\left(\frac34\right)^{m-1}\left(1+2^{-m}\right).
\]

For every `m>=2`,

\[
0<\rho_m\le\frac34\cdot\frac54=\frac{15}{16}<1.
\]

Markov’s inequality gives the exact exponential failure estimate

\[
P(S_r>mr)
\le \mathbb E[x^{S_r-mr}]
=\rho_m^r.
\tag{A1}
\]

Since `Q_{m,1}=r` on the success event and `0<=Q_{m,1}<=r` always,

\[
\mathbb E Q_{m,1}
\ge r\,P(S_r\le mr)
\ge r(1-\rho_m^r).
\]

Combining this with `(D1)` and dividing by `mr` yields the complete finite-size certificate

\[
\boxed{
0\le
\frac1m-
\frac{\mathbb E Q_{m,1}(X_1^{mr},Y_1^{mr})}{mr}
\le
\frac{\rho_m^r}{m},
\qquad
\rho_m=\left(\frac34\right)^{m-1}(1+2^{-m}).
}
\tag{C008.1}
\]

Taking `r->infinity` gives

\[
\boxed{q_{m,1}=\frac1m\qquad\text{for every integer }m\ge2.}
\tag{C008.2}
\]

This proof does not need the prior Fekete existence theorem; the two-sided finite-size estimate itself gives the limit.

For the special case named in the stuck report,

\[
\boxed{q_{2,1}=\frac12},
\qquad
\rho_2=\frac{15}{16}.
\]

**Outcome of move 19: SUCCESS on the selected recovery target.** The smallest strict bounded-span shape constant is exactly evaluated, with an explicit exponential finite-to-infinite error.
