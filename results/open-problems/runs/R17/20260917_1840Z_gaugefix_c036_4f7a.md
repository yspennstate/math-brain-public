## 4. #14 FIND THE GROUP ACTING — the missing object is a Z/2 gauge cocycle

The failure is cleanly expressed as a group-action problem.

Let `J` be simultaneous complement of both binary histories. The archived canonical machine stores one representative from each orbit under

\[
G=\{1,J\}\cong\mathbb Z/2\mathbb Z.
\]

For a quotient state `q` and stored label `a=(c,l)`, write

\[
q\xrightarrow{a,f}q',\qquad f\in\{0,1\},
\]

where `f=1` means the unquotiented successor was complemented by `J` to obtain the stored representative `q'`.

If the physical history differs from the current representative by gauge `g`, then the physical terminal bit represented by stored `c` is

\[
c_{\rm phys}=c\oplus g,
\]

and after the transition the gauge becomes

\[
g'=g\oplus f.
\tag{C036.1}
\]

The forbidden-word language used in C035 is invariant under **one simultaneous complement of all terminal bits in the word**, but it is not invariant under complementing only the suffix after a quotient gauge change. Therefore a DFA memory containing earlier terminal-bit information has to be transported by `J^f` after every quotient transition.

This is not removable by assigning a fixed gauge to each quotient state. The exact checker finds, already in the reachable `h=2` quotient graph, an odd-flip self-loop. If there were a state potential `phi(q)` with

\[
f(q,a)=\phi(q)\oplus\phi(q'),
\]

then on a self-loop the right side would be zero, contradicting the observed `f=1`. Hence the flip cocycle is not a state coboundary. **Transition-level gauge metadata is genuinely necessary.**

This explains precisely why the old stripped transition table was sufficient for the original complement-invariant Perron calculation but insufficient once R17 attached memory that remembers terminal-bit relations across transitions.

### Why (C036.2) restores physical correctness

Assume inductively that memory `m` is the physical forbidden-word memory recoded into the current source representative's gauge.
