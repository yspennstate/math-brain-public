## 3. R17-C001 — rectangular-cycle dependence of the true match field

**Status: PROVED.**

Let \(X_1,X_2,Y_1,Y_2\) be independent fair bits and

\[
M_{ij}=1_{\{X_i=Y_j\}}.
\]

Then deterministically

\[
\boxed{
M_{11}\oplus M_{12}\oplus M_{21}\oplus M_{22}=0.
}
\tag{C001.1}
\]

### Proof

For bits, in \(\mathbf F_2\),

\[
M_{ij}=1\oplus X_i\oplus Y_j.
\]

XORing the four rectangle corners cancels the four constant ones and gives each of \(X_1,X_2,Y_1,Y_2\) exactly twice, hence zero.

The map from the 16 equiprobable underlying quadruples \((X_1,X_2,Y_1,Y_2)\) to the match rectangle therefore has image contained in the eight even-parity patterns. Global complementation of all four underlying bits leaves the match rectangle unchanged and is the only two-element kernel, so all eight even-parity patterns occur, each with probability \(1/8\).

Any three corners are uniform on \(\{0,1\}^3\): after specifying three corner values, the parity relation fixes the fourth and exactly two globally complementary underlying bit assignments realize the rectangle. Hence any three corners are independent Bernoulli\((1/2)\), but the fourth corner is determined by the first three.

In particular,

\[
\boxed{
P(M_{11}=M_{12}=M_{21}=M_{22}=1)=\frac18,
}
\]

whereas an independent Bernoulli-matching model would give \(1/16\).

This is the exact guardrail against importing integrability/independence from the Bernoulli matching model. It also explains why tests involving at most three match cells can look deceptively independent.

## 4. R17-C002 — no exact transition from any fixed k-local suffix-boundary state

**Status: PROVED for every integer \(k\ge1\).**

For deterministic source \(U\) and target \(Y\), define target-prefix and source-prefix boundary increments

\[
h_j(U,Y)=LCS(U,Y_1^j)-LCS(U,Y_1^{j-1}),
\]

\[
v_i(U,Y)=LCS(U_1^i,Y)-LCS(U_1^{i-1},Y).
\]

For fixed \(k\), define the deliberately strong local boundary state

\[
S_k(U,Y)
=
\bigl(
LCS(U,Y),
U_{\text{last }k},
Y_{\text{last }k},
v_{\text{last }k},
h_{\text{last }k}
\bigr).
\tag{C002.1}
\]

This state already remembers the total score, the last \(k\) raw letters of both strings, and the last \(k\) boundary-increment bits in both directions.

### Theorem

For every \(k\ge1\), there are \((U,Y^A,Y^B)\) with

\[
S_k(U,Y^A)=S_k(U,Y^B),
\]

but, after appending the same source bit \(1\),

\[
\boxed{
S_k(U1,Y^A)\ne S_k(U1,Y^B).
}
\tag{C002.2}
\]

Hence no deterministic transition function of \((S_k,\text{new source bit})\) can reproduce the exact LCS boundary dynamics for all binary strings.

### Proof

Fix \(k\ge1\) and set

\[
U=0^k,
\qquad
Y^A=010^k,
\qquad
Y^B=10^{k+1}.
\]

Both targets contain \(k+1\) zeros, so

\[
LCS(U,Y^A)=LCS(U,Y^B)=k.
\]

Every one of the \(k\) source zeros can be matched, so the source-prefix increment suffix is

\[
v_{\text{last }k}=1^k
\]

in both environments. The last \(k\) raw source letters and last \(k\) raw target letters are both \(0^k\).

For target-prefix increments, the full row against \(Y^A\) is

\[
h^A=(1,0,1^{k-1},0),
\]

because the initial zero raises the score, the following one does not, the next \(k-1\) useful zeros raise it to \(k\), and the final zero is capped by source length. Against \(Y^B\),

\[
h^B=(0,1^k,0).
\]

Their last \(k\) entries are identical:

\[
h^A_{\text{last }k}=h^B_{\text{last }k}=1^{k-1}0.
\]

Thus

\[
\boxed{
S_k(U,Y^A)=S_k(U,Y^B)
=(k,0^k,0^k,1^k,1^{k-1}0).
}
\tag{C002.3}
\]

Append the same source bit \(1\).

If \(k=1\), then

\[
LCS(01,010)=2,
\qquad
LCS(01,100)=1,
\]

so the next states differ already in total score.

Assume \(k\ge2\). In both environments the new total score is still \(k\): matching all \(k\) zeros gives score \(k\), while using the final source \(1\) cannot improve beyond that for these target orders. But the target-prefix increment suffixes now differ. Directly from the zero/one order,

\[
h(U1,Y^A)_{\text{last }k}
=0\,1^{k-2}0,
\]

whereas

\[
h(U1,Y^B)_{\text{last }k}
=1^{k-1}0.
\]

Therefore \(S_k(U1,Y^A)\ne S_k(U1,Y^B)\) for all \(k\ge2\) as well. This proves C002.

### Scope

C002 kills a broad class of **fixed suffix-local boundary Markovizations**, even after giving them the total LCS score, raw suffixes on both strings, and both boundary increment suffixes. It does **not** rule out finite carriers that encode nonlocal positional/seaweed information.

## 5. R17-C003 — unavoidable iid prediction-error floor for this truncation class

**Status: PROVED.**

Fix \(k\ge1\). Let

- \(U\sim\mathrm{Unif}\{0,1\}^k\),
- \(Y\sim\mathrm{Unif}\{0,1\}^{k+2}\),
- \(X\sim\mathrm{Bernoulli}(1/2)\),

independently. Let \(\Phi\) be any deterministic predictor that, from only

\[
(S_k(U,Y),X),
\]

tries to output the exact next state \(S_k(UX,Y)\).

Then

\[
\boxed{
P\bigl(\Phi(S_k(U,Y),X)\ne S_k(UX,Y)\bigr)
\ge 2^{-2k-2}.
}
\tag{C003.1}
\]

### Proof

Use the C002 witness worlds

\[
(U,Y,X)=(0^k,010^k,1)
\]

and

\[
(U,Y,X)=(0^k,10^{k+1},1).
\]

They have the same predictor input \((S_k,X)\) but different exact outputs. Each world has iid probability

\[
2^{-k}2^{-(k+2)}2^{-1}=2^{-2k-3}.
\]

A deterministic predictor must therefore fail on at least one of these two equally likely worlds, contributing error at least \(2^{-2k-3}\).

Now complement every source and target bit and append \(X=0\). Complementation preserves all LCS values and boundary-increment bits while complementing the raw suffixes, producing a second ambiguous predictor input disjoint from the first, again with error contribution at least \(2^{-2k-3}\).

Summing the two disjoint contributions proves

\[
2\cdot2^{-2k-3}=2^{-2k-2}.
\]

### Interpretation

C003 is a **lower obstruction**, not the desired truncation theorem. A useful finite-state method still needs a uniform **upper** error bound \(\varepsilon_k\to0\), preferably for a richer nonlocal carrier. C003 says that, for the state class C002, such an upper bound cannot beat the displayed witness floor.

## 8. Uniform truncation obligation

**R17-O004 — OPEN.** Find a richer finite carrier \(C_k\) and a computable transition kernel together with a rigorous uniform tail

\[
\boxed{
\sup_n P(\text{exact next/current observable differs from its }C_k\text{ truncation})
\le \varepsilon_k,
\qquad
\varepsilon_k\downarrow0,
}
\tag{O004.1}
\]

strong enough to produce matching finite primal/dual bounds on \(\gamma_2\).

C003 shows that the particular state \(S_k\) cannot have an exact transition and that any deterministic next-state predictor from it has iid error at least \(2^{-2k-2}\) in the witness dimensions. That lower bound is compatible with an exponentially small *upper* truncation error, but does not prove one.

A concrete next state to test is not “more suffix bits,” but the last \(k\) **frontier transition positions** (or seaweed endpoints) together with the current boundary word. Define an influence depth \(D\) as the furthest-back frontier whose position can change when one new source symbol is appended. The needed theorem would be a uniform tail

\[
P(D>k)\le \varepsilon_k
\]

with explicit \(\varepsilon_k\). Exact finite DP can falsify proposed formulas, but simulation alone will not certify O004.
