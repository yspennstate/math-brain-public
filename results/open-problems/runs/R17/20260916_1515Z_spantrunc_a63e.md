## 4. R17-C006 — bounded-span block packing with exact dynamic programming

**Status: PROVED. Novelty not claimed.** This is an auxiliary truncation theorem for the source problem, not a new outside conjecture.

Fix deterministic binary strings `x,y` of equal length

\[
n=rm,
\]

and split the source into consecutive length-`m` blocks

\[
x=x^{(1)}\cdots x^{(r)}.
\]

Fix an integer span cap `B>=1`.

### Definition of the bounded-span primal score

An admissible packing chooses a subset `J` of source-block indices and, for each `j in J`, a nonempty consecutive target interval

\[
I_j=(s_j,t_j]\subseteq\{1,\ldots,n\}
\]

such that

\[
1\le |I_j|=t_j-s_j\le B
\]

and the chosen target intervals respect source-block order and are disjoint:

\[
j<k,\ j,k\in J\quad\Longrightarrow\quad t_j\le s_k.
\]

Target symbols between selected intervals may be skipped. Define

\[
\boxed{
Q_{m,B}(x,y)
:=
\max_{\text{admissible packings}}
\sum_{j\in J}LCS(x^{(j)},y_{I_j}).
}
\tag{C006.1}
\]

Every term uses the **actual** LCS of an actual source block against an actual target substring. No independent match-cell approximation is introduced.

### Exact finite DP

Let `D_{j,t}` be the best bounded-span packing score using the first `j` source blocks and target prefix `y_1...y_t`. Then

\[
D_{0,t}=D_{j,0}=0,
\]

and

\[
\boxed{
D_{j,t}
=
\max\left\{
D_{j,t-1},\;
D_{j-1,t},\;
\max_{1\le \ell\le\min(B,t)}
\left(D_{j-1,t-\ell}+LCS(x^{(j)},y_{t-\ell+1}^{t})\right)
\right\}.
}
\tag{C006.2}
\]

In particular,

\[
Q_{m,B}(x,y)=D_{r,n}.
\]

#### Proof of the recurrence

Take an optimal packing in the state `(j,t)`.

- If target position `t` is after the last selected interval, the score is already attainable in `(j,t-1)`.
- If source block `j` is inactive, the score is attainable in `(j-1,t)`.
- Otherwise block `j` is active. After deleting any target gap after its interval (already covered by the first case), its interval ends at `t`, has some length `1<=ell<=min(B,t)`, and all earlier selected source blocks use target positions at most `t-ell`. Its score is therefore bounded by the corresponding third term.

Conversely each displayed term constructs a valid packing, so equality holds. `□`

### Deterministic two-sided truncation theorem

For every deterministic pair `x,y`,

\[
\boxed{
0\le LCS(x,y)-Q_{m,B}(x,y)
\le
m\left\lfloor\frac{n}{B+1}\right\rfloor.
}
\tag{C006.3}
\]

#### Proof: lower side `Q<=LCS`

Fix any admissible packing. In each selected source block choose a common subsequence attaining

\[
LCS(x^{(j)},y_{I_j}).
\]

The source blocks are ordered and the target intervals are ordered and disjoint. Concatenating these blockwise subsequences therefore gives a common subsequence of the full `x,y`. Hence every admissible packing has score at most `LCS(x,y)`, proving

\[
Q_{m,B}(x,y)\le LCS(x,y).
\]

#### Proof: upper side

Use the exact R17-C004 decomposition. Choose an optimal target composition

\[
b_1+\cdots+b_r=n
\]

with consecutive target chunks `y^(j)` such that

\[
LCS(x,y)=\sum_{j=1}^{r}LCS(x^{(j)},y^{(j)}).
\]

Call a block **long** when `b_j>B`. If `J_long` is the number of long blocks, then

\[
(B+1)J_{\rm long}
\le
\sum_{j:\,b_j>B}b_j
\le n,
\]

so

\[
J_{\rm long}\le\left\lfloor\frac{n}{B+1}\right\rfloor.
\]

Drop every long block from the optimal C004 decomposition. Every remaining target chunk has length at most `B`; these short chunks, with the long chunks treated as skipped target gaps and their source blocks inactive, form an admissible packing for `Q_{m,B}`. Therefore

\[
\sum_{j:\,b_j\le B}LCS(x^{(j)},y^{(j)})
\le Q_{m,B}(x,y).
\]

Each dropped long source block contributes at most its source length `m`. Thus

\[
LCS(x,y)
\le Q_{m,B}(x,y)+mJ_{\rm long}
\le Q_{m,B}(x,y)+m\left\lfloor\frac{n}{B+1}\right\rfloor.
\]

This proves C006.3. `□`

### Exact self-check

The run checker:

- compares the DP recurrence against an independent brute-force interval-packing enumerator on small cases;
- exhaustively checks `Q<=LCS<=Q+m floor(n/(B+1))` on 50,368 `(x,y,m,B)` instances;
- verifies `Q=LCS` whenever the tested cap satisfies `B>=n`.

The largest observed finite test gap was `4`; every case satisfied the stated deterministic certificate exactly.

## 5. R17-C007 — bounded-span shape constant and uniform asymptotic error

**Status: PROVED. Novelty not claimed.**

For fixed integers `m>=1`, `B>=1`, let independent fair binary strings have common length `rm` and define

\[
A_r^{(m,B)}
:=
\mathbb E\,Q_{m,B}(X_1^{rm},Y_1^{rm}).
\]

Then

\[
\boxed{
A_{r+s}^{(m,B)}\ge A_r^{(m,B)}+A_s^{(m,B)}.
}
\tag{C007.1}
\]

### Proof

For deterministic pairs `(x_1,y_1)` and `(x_2,y_2)` of lengths `rm` and `sm`, concatenate an optimal bounded-span packing from the first pair with an optimal packing from the second pair, shifting every target interval in the second packing by `rm`. This is an admissible packing of the concatenated pair, so

\[
Q_{m,B}(x_1x_2,y_1y_2)
\ge
Q_{m,B}(x_1,y_1)+Q_{m,B}(x_2,y_2).
\]

The concatenated iid pairs have the correct iid law at length `(r+s)m`; taking expectations proves C007.1. `□`

Since `0<=A_r<=rm`, Fekete's lemma applies. Therefore the bounded-span shape constant

\[
\boxed{
q_{m,B}
:=
\lim_{r\to\infty}
\frac{A_r^{(m,B)}}{rm}
=
\sup_{r\ge1}\frac{A_r^{(m,B)}}{rm}
}
\tag{C007.2}
\]

exists.

Now average C006.3, divide by `n=rm`, and let `r->infinity`. The Chvátal–Sankoff limit along multiples of `m` is `gamma_2`, giving

\[
\boxed{
q_{m,B}
\le
\gamma_2
\le
q_{m,B}+\frac{m}{B+1}.
}
\tag{C007.3}
\]

Equivalently,

\[
\boxed{
0\le\gamma_2-q_{m,B}\le\frac{m}{B+1}.
}
\tag{C007.4}
\]

Because the admissible packing family increases with `B`, `q_{m,B}` is nondecreasing in `B`. C007.4 therefore yields the dependence-preserving primal hierarchy

\[
\boxed{
q_{m,B}\uparrow\gamma_2
\quad(B\to\infty),
\qquad
\gamma_2=\sup_{B\ge1}q_{m,B},
}
\tag{C007.5}
\]

with an explicit deterministic convergence rate `m/(B+1)`.

### Scope: why this is not closure

C007 is precisely the kind of **uniform truncation theorem** requested by the track, but it does not explicitly evaluate `q_{m,B}`. The DP C006.2 is finite-range in target span yet its full asymptotic boundary profile still grows with the two-dimensional dynamic program. Therefore C007.5 is not treated as an exact solution; it is a controlled hierarchy whose finite-state/max-plus evaluation remains the obligation.

The checker independently verifies deterministic concatenation superadditivity on 640 exact binary instances.
