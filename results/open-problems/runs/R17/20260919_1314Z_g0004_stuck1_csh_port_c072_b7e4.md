## 2. Exact blocker required by Section I

C071 reduced the full source problem to the threshold/downshadow quantity. For a finite percolation instance, let

\[
S(\omega)=\{b\in B:o\leftrightarrow b\},\qquad C=\{S\ne\varnothing\},
\]

and for a decreasing set `F` with `C^c subset F` put

\[
\operatorname{Sh}_b(F)=\downarrow(F\cap C_b),
\qquad C_b=\{o\leftrightarrow b\}.
\]

The exact statement that blocks the full source is

\[
\boxed{
T_*(\delta):=
\sup_{G,p,o,B}
\sup_{\substack{F\downarrow,\ C^c\subseteq F\\
\mu(\operatorname{Sh}_b(F))\le\delta\ \forall b}}
\frac{\mu(F\cap C)}{\mu(C)}
\xrightarrow[\delta\downarrow0]{}0.
}
\]

C071 proved that this threshold statement is equivalent, at the qualitative level, to `R_*(epsilon)->0`. No current route proves the displayed dimension-free limit.

The dual form from C070 is the same obstruction viewed from the other side: uniformly over every finite instance one needs a fractional selector `alpha`, supported on currently connected boundary vertices and satisfying `sum_b alpha_b=1` on `C`, for which

\[
\sum_b H_\varepsilon(\alpha_b)=o(\mu(C)).
\]

The missing content is a connectivity-specific way to get this without paying either the number of edges or the number of boundary vertices.

## 3. Method #1 — CHANGE THE CATEGORY

### Previous category

C071 lived on the Boolean edge cube. It converted the problem into rare downshadows and then studied boundary edges of a bad downset `F`. This gave a clean local dichotomy, but it left two quantities with no dimension-free control:

1. a rare downset may have very large total influence;
2. one connectivity-pivotal edge may create many boundary contacts at once.

Thus the Boolean-lattice category makes the obstruction look like an influence/fanout problem, but does not itself supply the missing conserved structure.

### New category for recovery

The pinned Kozma--Nitzan proof suggests moving from **edge-boundary accounting** to **conditioned cluster covariance plus relay peeling**.

Its core object is not a downset boundary. Fix an owner `x`, an avoided set `Y`, decoys `z_1,...,z_l`, observers `u,v`, condition on `x not<-> Y`, and form covariances

\[
\kappa_f(w)
=
\operatorname{Cov}\bigl(f(\mathcal C_x),\mathbf 1_{\{w\in\mathcal C_x\}}\mid x\not\leftrightarrow Y\bigr)
\]

for an increasing function of the owner's cluster. A recursively corrected slack is then compared between the two observers. The important structural feature is that when one relay is peeled, every correction term can be rewritten as another instance of the **same hierarchy** with a new owner/avoided set and fewer decoys.

That is precisely the kind of closure C071 lacked. The natural G0004 recovery question is therefore not "can total influence be bounded?" but:

> Can Flammant's boundary-indexed increasing observables be embedded in a conditioned hierarchy whose class is closed when relays are peeled?

The obstruction is immediately sharper than before. The formal hierarchy accepts one increasing functional of a single open cluster. Flammant permits a family `f_b(omega)=P(E_b|pi=omega)` that may depend on the entire edge configuration and changes with the boundary label `b`. Conditioning on an exact explored cluster also forces its boundary edges closed, so simply replacing `f_b(omega)` by `E[f_b | C_b]` does not obviously preserve the needed monotonicity. A successful port has to enlarge the hierarchy while preserving closure under exploration; merely rewriting `f_b` as a conditional expectation is not enough.

No new theorem is asserted here. This is the category change chosen for the recovery.

## 4. Method #12 — FIND WHAT IS CONSERVED

The first three G0004 runs looked for conserved **mass**: selector mass, first-relay mass, or a unit charge assigned to connected boundary vertices. The exact selector dual makes this natural, but C070 showed why monotone selector mass cannot be conserved in a useful way even on stars.

Reading the conditioned-slack proof changes the candidate invariant. What is conserved there is not a scalar mass but a **proof shape**:

> after exposing an avoided cluster or removing a relay, the error term is again a conditioned covariance margin of the same type, with the same later transfer constants.

The pinned proof uses a world decomposition plus telescoping to preserve this shape. In the relay induction, a removed relay becomes a decoy rather than disappearing, which prevents a union-bound loss in `|A|`.

For G0004 the analogous invariant would have to carry, in addition, a boundary-indexed bad-event observable. A minimal closed state would likely need at least

\[
(\text{owner},\ \text{avoided set},\ \text{ordered remaining relays},\ \text{active observable/label state}).
\]

The key conservation test for the next run is: after peeling one relay and conditioning on the explored world, can every correction be represented by another state of this same form **without summing over all boundary labels**?

This is where every previous R17 architecture breaks:

- ordinary FKG forgets which relay generated the correction;
- the independent-arm proof has a canonical coordinate label, which a general graph edge lacks;
- Boolean-boundary charging produces an edge pivotal with potentially many new labels;
- a monotone selector cannot preserve unit mass under unions of contacts.

The conditioned-slack architecture solves exactly the analogous "many relays" problem by preserving the correction's type. The recovery should therefore test **closure of an enriched hierarchy**, not search for another scalar potential.

Again, this is a structural diagnosis, not a new mathematical claim.

## 5. Method #22 — READ THE FAILURES, NOT THE SUCCESSES

The useful failures are now unusually specific.

### Failure 1: arbitrary increasing-event replacement

Flammant's source gives a counterexample if the connectivity events `{o<->b}` themselves are replaced by arbitrary increasing events. So positive association alone cannot prove the result; the proof must use cluster/connectivity structure.

### Failure 2: planar DFS does not globalize

The source's solved outer-face planar case uses a left-first depth-first exploration and a partial FKG inequality adapted to monotonicity up to a stopping time. That proof has a canonical planar ordering. In a general graph, cycles allow exploration order to change without a comparable monotone change in the connected boundary set. C070 already identified this as a genuine recursion obstruction, not a presentation issue.

### Failure 3: monotone selector

The R7-02 monotone partition-of-unity route fails already on a two-edge star. On an m-star, monotonicity forces total selector mass at the all-open configuration to be at least m. So no proof based on a dimension-free monotone selector can work.

### Failure 4: edge-link charging

The independent-arm proof works because coordinate `i` has one canonical boundary label. In a graph, an edge may simultaneously connect many boundary points. C071's downshadow boundary dichotomy therefore pays either total rare-set influence or connectivity-pivotal fanout, neither of which is dimension-free.

### Nearest solved composition problem: additive gluing

The pinned `formal-math` artifact attacks the same high-level failure--many possible relay points--but does not iterate ordinary FKG. Its README says the new conditioned slack hierarchy is combined with:

- van den Berg--Haeggstrom--Kahn conditional correlation inequalities;
- the Ahlswede--Daykin four-functions theorem;
- Gladkov's decision-tree Harris--Kleitman inequality;
- an induction in which a removed relay is retained as a decoy.

The result is additive gluing with **no `|A|` loss**. That is the nearest solved mechanism to the exact obstruction in G0004.

What it lacks for Flammant is equally clear: additive gluing has one common target event of the form `{a<->b}` across all relays `a`. G0004 allows a different arbitrary increasing observable for every boundary vertex and those observables need not be functions of one cluster. Thus the recovery target is a **label-dependent / observable-dependent conditioned slack hierarchy**.

## 6. The five mandatory stuck items

### (a) Exact blocking statement

The displayed `T_*(delta)->0` downshadow limit in Section 2 is the exact blocker.

### (b) Routes tried and precise failure of each

1. **Singleton/FKG and bounded-contact union bound (inherited R7-02):** gives `R <= epsilon E[|S| | C]`; loses the unbounded contact count.
2. **Monotone selector (inherited R7-02):** impossible even on stars; monotone mass grows with the number of contacts.
3. **Automorphism symmetrization (C069):** exact and useful for finite symmetric families, but only reduces variables; it gives no dimension-free estimate over all graphs.
4. **Exact star optimization (C069):** proves stars have sharp `epsilon log(1/epsilon)` behavior; therefore stars are not the obstruction, but arbitrary cyclic graphs remain.
5. **Fractional-selector minimax and downset LP dual (C070):** exact reformulation, but there is no known universal selector whose total discrepancy is `o(P(C))`.
6. **Independent heterogeneous arms (C070):** gives a quantitative modulus because each Boolean coordinate has one boundary label; the canonical-label property fails for graph edges.
7. **Root-neighborhood star domination (C070):** arbitrary interior decoration is harmless when every root neighbor is already in the boundary; it does not reach boundaries beyond a nontrivial interior layer.
8. **Downshadow/union-closed formulation (C071):** contact support is union-closed, but existence of intermediate contacts gives no quantitative lower mass. The Boolean boundary dichotomy incurs uncontrolled total influence or pivotal fanout.
9. **Single-articulation parallel modules (C071):** handles arbitrary one-terminal modules after one articulation, but cycles coupling several terminals across modules are excluded.
10. **Planar outer-face exploration (source):** succeeds because planarity supplies a monotone exploration order; the ordering is not available on arbitrary graphs.
11. **Ordinary repeated FKG / one-relay-at-a-time gluing:** the newly inspected additive-gluing proof confirms this is the wrong abstraction; successful gluing requires conditioned correction terms that remain inside a closed hierarchy.

### (c) What a proof must contain that no route so far contains

A full proof must provide a **dimension-free recursion closed under cluster exploration** which simultaneously remembers:

- the current relay/contact geometry;
- the boundary label whose high-probability event is being charged;
- the residual correction terms generated by previously peeled relays;
- enough monotonicity to apply positive/negative correlation inequalities after conditioning.

Equivalently, it must turn the pointwise per-boundary rarity

\[
\mu(\operatorname{Sh}_b(F))\le\delta\qquad(\forall b)
\]

into a global estimate on `mu(F cap C)` **without summing over b or over edges**. Previous R17 routes have one of these ingredients, but none has a state space closed under the required peeling operation.

### (d) Simplest special case still unproved in the R17 record

The recovery will first isolate the following source-valid subclass:

> arbitrary finite graphs and unbounded boundary sets, but each conditional success probability is a boundary-dependent increasing functional of that boundary vertex's open cluster alone,
> \[
> f_b(\omega)=F_b(\mathcal C_b(\omega)),
> \qquad F_b\text{ increasing in cluster inclusion},
> \qquad \mathbb E[1-f_b]\le\varepsilon.
> \]

This is not covered by the star, independent-arm, root-neighborhood, or one-articulation theorems. It is deliberately chosen because it is the smallest setting in which the formal conditioned-slack machinery is structurally relevant while still permitting different observables `F_b` for different relays. The common-observable and fixed-boundary-size degeneracies are not the target.

### (e) Nearest solved problem and the missing ingredient

Nearest solved-looking problem: Kozma--Nitzan Conjecture 3 / uniform additive many-relay gluing, in pinned `anthropics/formal-math` commit `795efb86...`, mechanically checked but not independently refereed.

What its proof has that G0004 currently lacks: a conditioned covariance hierarchy whose correction terms are closed under relay deletion, because every relay is judged against one common connectivity target / one cluster functional.

What G0004 adds: a **different arbitrary increasing observable at each boundary point**, possibly depending on the entire configuration. Peeling a relay can therefore change both the geometry and which observable is active. The existing hierarchy does not, as stated, carry that label-dependent observable state.
