# 6. Move 17 — look for the numbers somewhere else

I searched for exact constants and algorithms in adjacent LCS models rather than continuing to squeeze the same machine blindly.

The most relevant exact adjacent model is Bukh--Cox, *Periodic words, common subsequences and frogs*. For a fixed periodic word `W` and an independent random word, their frog dynamics computes a constant `gamma_W` efficiently; their public code gives exact/effective periodic-word constants. This is a genuine interacting-particle representation, but it is **not** the random-random Chvátal--Sankoff model.

A natural comparison attempt fails directionally. Let `W` have length `m`, and split a random target of length `rm` into `r` iid blocks. Concatenating blockwise common subsequences gives
\[
\gamma_W(1)
\ge
\frac1m\mathbf E_R LCS(W,R_m).
\]
Averaging over a uniform random `W` gives
\[
\mathbf E_W\gamma_W(1)
\ge
\frac{\mathbf E L_m}{m}.
\]
But random-random LCS superadditivity gives only
\[
\frac{\mathbf E L_m}{m}\le\gamma_2.
\]
These two inequalities do **not** compare `E_W gamma_W(1)` with `gamma_2` in either direction. Thus frog-dynamics exactness does not automatically transfer to a rigorous endpoint for the random-random constant. A new comparison theorem would be required.

This failed route is retained because it clarifies why importing an exact particle process from a nearby LCS model would repeat the same category error as independent Bernoulli matching.
