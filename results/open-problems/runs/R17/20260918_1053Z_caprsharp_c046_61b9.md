### #12 FIND WHAT IS CONSERVED

For a minimal-match factor `(c,l)`, write `b=1-c`. Its generated physical pair is
\[
(l\ge0):\quad (b^l c,\ c),
\qquad
(l<0):\quad (c,\ b^{-l}c).
\]
The crucial conserved structure is not hook length. It is the **shared terminal word**
\[
c_1c_2\cdots c_r,
\]
which occurs in both generated strings, one designated terminal per factor. Every homogeneous hook run is immediately followed by its own terminal `c_i`. This terminal skeleton repairs exactly the exceptional case in which a length-`r+1` witness tries to use more than `r` copies from one homogeneous hook.

## 3. The new theorem: cap r, not r+1

For an `r`-factor word `w=((c_1,l_1),\ldots,(c_r,l_r))`, let `P(w)=(A(w),B(w))` be the generated physical string pair under the factor rule above. Define
\[
\tau_r(l)=\operatorname{sgn}(l)\min\{|l|,r\}.
\]
Apply `tau_r` to every signed hook in the word.

**Theorem (sharp cap-r deficiency invariance).** For every `r>=1`,
\[
\boxed{
\operatorname{LCS}(P(w))>r
\iff
\operatorname{LCS}(P(\tau_r w))>r.
}
\]
For every `r>=2`, the threshold `r` is sharp: replacing `r` by `r-1` is false in general.

### Proof

The backward implication is immediate. Each capped factor string is a subsequence of its uncapped factor string, hence both components of `P(tau_r w)` are subsequences of the corresponding components of `P(w)`. Therefore any common subsequence surviving the cap also exists before the cap.

For the forward implication, assume `LCS(P(w))>r` and choose a common subsequence `W` of length exactly `r+1`.

First suppose that, in each of the two physical strings, `W` uses at most `r` selected positions from every individual homogeneous hook run. Every hook run consists of copies of one symbol. If a run is longer than `r`, move the selected positions used by `W` into the first `r` copies retained by the cap, preserving their internal order. Do this independently in every run. Terminal positions are unchanged. The factor order is unchanged, so the resulting selected positions realize the same word `W` in both capped strings. Hence `LCS(P(tau_r w))>=r+1`.

It remains to consider the exceptional case. Since `|W|=r+1`, using more than `r` positions from one homogeneous run means that **all** symbols of `W` are the same bit; write
\[
W=b^{r+1}.
\]
Thus each original physical string contains at least `r+1` occurrences of `b`. After capping every hook at `r`, each capped string still contains at least `r` occurrences of `b`: a cap operation can reduce a single long homogeneous run to `r`, but cannot reduce a string that originally had at least `r+1` copies of `b` below `r` copies in total.

If both capped strings contain at least `r+1` copies of `b`, then `b^{r+1}` itself survives and we are done. Suppose instead that one capped string, say `A'`, contains exactly `r` copies of `b`.

For the count to have fallen below `r+1`, `A` must contain a `b`-hook of original length greater than `r`; that hook alone contributes exactly `r` copies after capping. Since the total in `A'` is exactly `r`, there are no other `b` occurrences in `A'`: no other `b`-hook and, crucially, no terminal with value `b`. Therefore every designated terminal bit equals
\[
c_i=1-b=:c.
\]
The long capped hook in `A'` is followed immediately by its own designated terminal `c`, so `A'` contains the subsequence
\[
b^r c.
\]
The designated terminal sequence is the same in both strings. Hence `B'` also has no terminal `b`; all of its `b` occurrences lie in hooks. As noted above, `B'` contains at least `r` copies of `b`. All hook letters in the factor word occur before the final designated terminal `c_r=c`, so by taking any `r` hook copies of `b` and then that final terminal, `B'` also contains
\[
b^r c.
\]
Thus `b^r c` is a common subsequence of length `r+1` in the capped pair. This proves `LCS(P(tau_r w))>r`. The argument is symmetric if the capped string with exactly `r` copies is `B'`. This completes the equivalence. ∎

### Sharpness

Fix `r>=2`, take `c_1=\cdots=c_r=0`, and choose hooks
\[
l_1=r+1,\quad l_2=\cdots=l_{r-1}=0,\quad l_r=-(r+1).
\]
Before capping,
\[
A=1^{r+1}0^r,
\qquad
B=0^{r-1}1^{r+1}0,
\]
and `1^{r+1}0` is a common subsequence of length `r+2`.

After capping at `r`,
\[
A_r=1^r0^r,
\qquad
B_r=0^{r-1}1^r0,
\]
and `1^r0` is a common subsequence of length `r+1`, so the word remains deficient.

After capping at `r-1`,
\[
A_{r-1}=1^{r-1}0^r,
\qquad
B_{r-1}=0^{r-1}1^{r-1}0.
\]
Any common subsequence that uses a zero from the initial `0^{r-1}` block of `B_{r-1}` cannot subsequently match a one, because every one in `A_{r-1}` occurs before every zero; such a subsequence has length at most `r`, all zeros. A common subsequence that starts in the middle `1^{r-1}` block has at most `r-1` ones and then the final zero, again length at most `r`. Equality is attained, e.g. by `1^{r-1}0`. Hence
\[
\operatorname{LCS}(A_{r-1},B_{r-1})=r.
\]
So cap `r-1` fails, proving sharpness. ∎
