## 2. Recovery idea: do not replace the strong canonical machine; intersect it with one exact forbidden-factor memory

C030 proved the elementary context-monotonicity fact behind the present construction. If a list `J` of minimal match pairs has

\[
\Delta(J):=\operatorname{LCS}(P(J))-|J|>0,
\]
then for arbitrary lists `A,B`,

\[
\Delta(A\|J\|B)\ge \Delta(J).
\tag{C033.1}
\]

The proof is direct: take an LCS of the pair generated by `J`, prepend the designated terminal matches of the factors in `A`, and append those in `B`. Therefore an order-`ell` collation of a pair whose LCS is exactly `ell` cannot contain a deficient contiguous factor.

C031 found an exact deficient factor already accepted by Lueker's true dependent-string canonical `h=8` machine:

\[
(c,+2)(c,-2).
\]

For `c=0` the two labels generate

\[
\binom{1100}{0110}.
\]

Its list order is two, while its exact LCS is three (for example `110` is common). Reversing the two labels swaps the two strings, and changing `c` complements both strings. Hence all four words

\[
\boxed{
(c,+2)(c,-2),\qquad(c,-2)(c,+2),\qquad c\in\{0,1\}
}
\tag{C033.2}
\]

have deficiency one.

This yields a coverage-preserving strict refinement of the canonical machine: remember only whether the immediately preceding label was one of the four signed `|l|=2` hooks, and reject exactly when the next label is the opposite hook with the same `c`.

### Lemma C033.1 — the five-memory product still covers every string pair

Let `M_8` be Lueker's canonical history-eight covering machine and let `M_8^Delta` be the product machine described above. Then `M_8^Delta` is a covering machine.

**Proof.** Fix an arbitrary string pair `P` and let `ell=LCS(P)`. The canonical covering construction supplies an accepted canonical collation of `P` with exactly `ell` minimal-match factors (followed, in Lueker's standard decomposition, by the null remainder). If its accepted factor list contained one of the four words (C033.2), that length-two sublist would have deficiency one. Applying (C033.1) to the surrounding factors would produce a common subsequence of `P` of length at least `ell+1`, contradicting the definition of `ell`. Thus the canonical covering list avoids every forbidden word in (C033.2), so it is also accepted by `M_8^Delta`. QED.

No independent-Bernoulli matching approximation appears here; the base transition system is exactly the dependent two-string canonical DP/backtracking machine.
