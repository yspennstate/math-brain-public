## 2. Source facts used, and the C029 obstruction

Lueker's Definition 3.12 says that a sequence `M_h` efficiently covers the string-pair space when it covers it and additionally:

1. factorial acceptance: acceptance of `L || L'` implies acceptance of both `L` and `L'`;
2. injectivity through history `h`: no string pair of size at most `h` is generated by two distinct accepted lists of minimal match pairs.

His Theorem 3.13 says that if the sequence efficiently covers and every `M_h` is regular, then the upper bounds converge to the true `gamma_k` as `h -> infinity` (with the quantitative rate proved there).

Lueker's Section 3.3.2 attempts to obtain these hypotheses from scalar domination. Its Conjecture 3.19 asserts, for `k=2`, that a string pair cannot be generated by two distinct undominated lists of minimal match pairs. C029 produced the exact minimal counterexample

\[
P=\binom{110110}{0010110},
\]

whose two order-four lists have the same scalar reverse key `(13,10,7,4)`. Importantly,

\[
\operatorname{LCS}(P)=5>4.
\]

That strict inequality is the clue used here.

## 3. #13 — the monotone quantity is LCS deficiency

Let

\[
L=(p_1,\ldots,p_r)
\]

be a list of minimal match pairs, and let `P(L)` be the string pair obtained by concatenating its top strings and its bottom strings. Since each minimal match pair contributes its essential final match, concatenating those `r` matches gives a common subsequence of length `r`. Hence

\[
\operatorname{lcs}(P(L))\ge r.
\]

Define the **deficiency surplus**

\[
\boxed{\Delta(L)=\operatorname{lcs}(P(L))-|L|\ge0.}
\tag{C030.1}
\]

Call `L` **deficient** if `Delta(L)>0`.

The useful fact is that deficiency cannot be repaired by putting context around the list.

### Lemma C030.1 — deficiency is a context monovariant

For arbitrary lists `A,L,B` of minimal match pairs,

\[
\boxed{\Delta(A\|L\|B)\ge \Delta(L).}
\tag{C030.2}
\]

**Proof.** Take a longest common subsequence of the pair generated by `L`, of length `lcs(P(L))`. Before it concatenate the designated final-character matches of every factor of `A`, and after it concatenate the designated final-character matches of every factor of `B`. The three blocks occupy disjoint, correctly ordered coordinate intervals, so the result is a common subsequence of `P(A||L||B)` of length

\[
|A|+\operatorname{lcs}(P(L))+|B|.
\]

Subtracting `|A|+|L|+|B|` gives (C030.2). QED.

In particular, no contiguous sublist of the minimal-match list belonging to a genuine order-`ell=lcs(P)` collation can be deficient: otherwise the whole collation would contain more than `ell` common matches.

This is the exact mechanism C029 exposed. Its colliding order-four lists are not merely awkward; they are impossible as saturated LCS decompositions because their surplus is one.

## 4. #3 — strengthen the domination key until injectivity is automatic

For a list `L=(p_1,...,p_r)` generating a string pair, write

\[
(i_t,j_t)
\]

for the cut coordinates after the first `t` factors. Lueker's scalar domination key remembers only `i_t+j_t`. Define instead the **coordinate-refined reverse key**

\[
\boxed{
K^\sharp(L)=
\bigl((i_r+j_r,i_r-j_r),\ldots,(i_1+j_1,i_1-j_1)\bigr),
}
\tag{C030.3}
\]

ordered lexicographically, first in `i+j` and then in `i-j` at each cut.

This refines Lueker's scalar reverse key but remembers enough to reconstruct every cut, because

\[
i_t=\frac{(i_t+j_t)+(i_t-j_t)}2,
\qquad
j_t=\frac{(i_t+j_t)-(i_t-j_t)}2.
\tag{C030.4}
\]

Therefore:

### Lemma C030.2 — refined-key injectivity

If two same-order lists of minimal match pairs generate the same string pair and have the same `K^sharp`, then the lists are identical.

**Proof.** Equality of the keys gives equality of every cut coordinate by (C030.4). Since the generated full top/bottom strings are fixed, the factors are exactly the substrings between consecutive equal cuts. QED.

Call a list `L` **sharp-dominated** if there exists a distinct same-order list `L'` of minimal match pairs generating the same string pair with

\[
K^\sharp(L')<K^\sharp(L).
\]

The refined order is compatible with replacement inside a larger list.

### Lemma C030.3 — local sharp domination survives context

If `L'` sharp-dominates `L`, then for every pair of context lists `A,B`,

\[
A\|L'\|B
\]

has smaller global refined key than

\[
A\|L\|B.
\]

**Proof.** The cuts belonging to `B` are unchanged because `L` and `L'` generate the same substring pair and therefore have the same endpoint displacement. In the reverse key, all those later cuts agree. Inside the replaced block, global `(i+j,i-j)` coordinates are obtained from local ones by adding the same fixed pair determined by the start of the block. Lexicographic comparison is invariant under that common translation, so the first differing block cut is smaller for `L'`. QED.

## 5. #19 — the repaired finite-state algorithm

Call a list **bad** if it is either

1. deficient, or
2. sharp-dominated.

For a history parameter `h`, let `D_h^sharp` be the set of bad lists of total string-pair size at most `h` that contain no bad proper contiguous sublist. This set is finite for every finite alphabet and fixed `h`.

Define `M_h^sharp` to read lists of minimal match pairs and reject exactly when an element of `D_h^sharp` occurs as a contiguous sublist. Equivalently, it is the standard finite forbidden-pattern automaton for `D_h^sharp`.

The point is that both hypotheses in Definition 3.12 can now be proved, not conjectured.

### Theorem C030.4 — efficient coverage for every finite alphabet

For every finite alphabet with at least two symbols, the sequence

\[
(M_h^\sharp)_{h\ge1}
\]

covers the full string-pair space and efficiently covers it in the sense of Lueker Definition 3.12.

**Proof of coverage.** Fix a string pair `P` and put `ell=lcs(P)`. Lueker's domination discussion records that there exists a scalar-undominated collation of order `ell`, and the first `ell` string pairs in such a collation are minimal match pairs. Among the scalar-undominated order-`ell` collations choose one, `C`, with lexicographically smallest refined key `K^sharp`; let `L` be its list of first `ell` minimal pairs.

No contiguous sublist `J` of `L` is deficient. If it were, Lemma C030.1 would splice an extra match into the order-`ell` collation and give a common subsequence of `P` of length larger than `ell`, a contradiction.

No contiguous sublist `J` of `L` is sharp-dominated either. If `J'` were a same-order replacement generating the same subpair with smaller refined key, Lemma C030.3 would replace `J` by `J'` and produce an order-`ell` collation `C'` with smaller refined key. Its scalar key is no larger than that of `C`, because the refined order first compares precisely the scalar `i+j` coordinates. It cannot have strictly smaller scalar key, since `C` is scalar-undominated. Hence it has the same scalar key and is also scalar-undominated; but then `C'` contradicts the choice of `C` as refined-key-minimal among scalar-undominated order-`ell` collations.

Thus `L` contains no bad contiguous sublist, so `M_h^sharp` accepts it for every `h`. Therefore the sequence covers every `P`.

**Definition 3.12(1).** The language accepted by `M_h^sharp` is factorial: rejection is exactly the occurrence of a forbidden contiguous sublist. Hence if `L||L'` is accepted, then `L` and `L'` are accepted.

**Definition 3.12(2).** Suppose a pair `P` of size at most `h` were generated by two distinct accepted lists `L,L'`. An accepted list of size at most `h` cannot itself be bad: if it were bad, finite descent under proper contiguous sublists would produce a minimally bad sublist belonging to `D_h^sharp`, forcing rejection.

Thus both `L` and `L'` are nondeficient. Since their designated endpoint matches give common subsequences of lengths `|L|` and `|L'|`, nondeficiency implies

\[
|L|=\operatorname{lcs}(P)=|L'|.
\]

They therefore have the same order. Lemma C030.2 says their refined keys are distinct. Whichever key is larger makes that list sharp-dominated by the smaller one, contradicting acceptance. Hence two such lists cannot exist. QED.

## 6. Regularity without Lueker's padding lemma

C029 made it important not to assume any preservation property of scalar-undominated lists. There is a simpler reset argument that avoids it entirely.

For fixed `h`, choose two alphabet symbols `0,1` and the minimal match pair

\[
q_h=\binom{0}{1^h0}.
\tag{C030.5}
\]

Its total size is `h+2>h`. It is a minimal match pair: its LCS is one, its final symbols agree, and deleting either final zero destroys the only common match.

No member of `D_h^sharp` can contain `q_h`, because every member has total size at most `h` whereas the single symbol `q_h` already has size `h+2`.

Realize `M_h^sharp` as the usual prefix automaton for the finite forbidden set `D_h^sharp` (symbols not appearing in any forbidden word form one undistinguished `other` class). From any nonrejecting state, reading `q_h` destroys every partial forbidden-pattern suffix and returns the automaton to the start state. Reading `q_h` at the start state leaves it there. Hence:

### Lemma C030.5 — regularity

Every `M_h^sharp` is regular in the sense of Lueker Definition 3.9.

No analogue of the false Conjecture 3.19 and no padding-preservation assertion is needed.
