## 2. #3 PROVE SOMETHING STRONGER — the general cap theorem

For a minimal-match-pair label `(c,l)`, with `c in {0,1}`, write
\[
M(c,l)=
\begin{cases}
((1-c)^l c,\;c),&l\ge0,\\
(c,\;(1-c)^{-l}c),&l<0.
\end{cases}
\]
For a word `w=(a_1,...,a_r)` of such labels, let `P(w)` be the pair of strings obtained by concatenating the corresponding top and bottom factors. Call `w` **deficient** if
\[
\operatorname{LCS}(P(w))>r.
\]

C037 proved only the `r<=3`, cap-4 instance. The stronger statement needed here is uniform in block length.

### Lemma C038-A (cap-`r+1` theorem)

For every `r>=1`, define
\[
\tau_{r+1}(l)=\operatorname{sgn}(l)\min\{|l|,r+1\},
\qquad \tau_{r+1}(0)=0.
\]
Then for every `r`-factor word `w`,
\[
\operatorname{LCS}(P(w))>r
\quad\Longleftrightarrow\quad
\operatorname{LCS}(P(\tau_{r+1}w))>r.
\tag{C038.1}
\]

### Proof

The capped pair is obtained from the original pair by deleting symbols inside individual homogeneous runs, so every common subsequence of the capped pair is also a common subsequence of the original pair.

Conversely, suppose the original block is deficient. Choose from it a common subsequence of exactly `r+1` symbols. In any one homogeneous run belonging to any one factor, this witness uses at most `r+1` positions. Replacing a longer run by exactly `r+1` copies of the same bit therefore leaves enough positions, in the same factor segment and in the same order, to realize every selected symbol from that run. Perform this replacement independently in every factor. The same witness survives in the capped pair. Hence the capped block is deficient. QED.

of size 22. In particular, every actual offset represented by Lueker's `l=+7` tail has cap `+5`, and every actual offset represented by `l=-7` has cap `-5`; no probabilistic tail approximation is being made.
