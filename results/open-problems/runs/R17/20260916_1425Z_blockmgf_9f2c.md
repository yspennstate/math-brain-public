## 4. R17-C004 — exact source-block / target-composition decomposition

**Status: PROVED. Novelty not claimed.** This is an independently derived optimal-substructure identity and may overlap classical LCS partition arguments.

Fix deterministic strings \(x,y\) of equal length
\[
n=rm.
\]
Split only the source string into consecutive length-\(m\) blocks
\[
x=x^{(1)}x^{(2)}\cdots x^{(r)}.
\]

For every weak composition
\[
\mathbf b=(b_1,\ldots,b_r)\in\mathbb Z_{\ge0}^r,
\qquad
\sum_{j=1}^r b_j=n,
\]
let
\[
0=t_0\le t_1\le\cdots\le t_r=n,\qquad
t_j=\sum_{i\le j}b_i,
\]
and define the corresponding consecutive target chunks
\[
y^{(j)}=y_{t_{j-1}+1}^{t_j}.
\]

Then
\[
\boxed{
LCS(x,y)
=
\max_{\substack{b_1+\cdots+b_r=n\\ b_j\ge0}}
\sum_{j=1}^r LCS(x^{(j)},y^{(j)}).
}
\tag{C004}
\]

### Proof

**Lower bound on the left-hand side.**
Fix any composition \(\mathbf b\). For each \(j\), choose a common subsequence of
\(x^{(j)}\) and \(y^{(j)}\) of length
\[
LCS(x^{(j)},y^{(j)}).
\]
The source blocks occur consecutively and in increasing order, and so do the target chunks. Concatenating these \(r\) common subsequences therefore gives a common subsequence of the full \(x,y\). Hence
\[
LCS(x,y)\ge
\sum_jLCS(x^{(j)},y^{(j)}).
\]
Taking the maximum over compositions gives the first inequality.

**Upper bound on the left-hand side.**
Fix one longest common subsequence of \(x,y\), represented by increasing matched pairs
\[
(i_1,j_1),\ldots,(i_\ell,j_\ell),
\qquad
\ell=LCS(x,y).
\]
For \(1\le q<r\), define
\[
t_q=\max\bigl(\{j_a:i_a\le qm\}\cup\{0\}\bigr),
\]
and put \(t_0=0,t_r=n\). Then \(t_q\) is nondecreasing. Every match whose source index lies in block \(q\),
\[
(q-1)m<i_a\le qm,
\]
has target index
\[
t_{q-1}<j_a\le t_q:
\]
the lower inequality follows because all matches from an earlier source block precede it in target order, and the upper inequality is the definition of \(t_q\).

Thus the number of matches contributed by source block \(q\) is at most
\[
LCS(x^{(q)},y_{t_{q-1}+1}^{t_q}).
\]
Summing over \(q\) shows that this particular global LCS has length at most the right side of (C004) for the induced composition. Therefore the maximum on the right is at least \(LCS(x,y)\). Combined with the first inequality, equality follows. \(\square\)

The exact checker verifies C004 on 8,512 binary string pairs across
\[
(m,r)\in\{(1,3),(2,2),(2,3),(3,2)\}.
\]

## 5. R17-C005 — annealed block-MGF upper bound with uniform truncation

**Status: PROVED.** The numerical instance is noncompetitive with Lueker; its role is a safe, reproducible finite upper-bound framework with an explicit infinite-length truncation certificate.

Let
\[
Z_{m,b}=LCS(X_1^m,Y_1^b)
\]
for independent iid fair binary strings of the indicated lengths. For \(s>1\), define
\[
M_{m,b}(s)=\mathbb E\,s^{Z_{m,b}},
\qquad
\Phi_m(z,s)=\sum_{b=0}^{\infty}z^bM_{m,b}(s),
\quad 0<z<1.
\]
Since \(Z_{m,b}\le m\),
\[
M_{m,b}(s)\le s^m,
\]
so \(\Phi_m(z,s)<\infty\) for every \(0<z<1\).

Then
\[
\boxed{
\gamma_2
\le
U_m(s,z)
:=
\frac{-\log z+\frac1m\log\Phi_m(z,s)}
{\log s}.
}
\tag{C005.1}
\]

### Proof

Take \(n=rm\). By C004,
\[
L_n
=
\max_{\mathbf b:\,\sum b_j=n}
\sum_{j=1}^r
LCS(X^{(j)},Y^{(j)}_{\mathbf b}),
\]
where for a fixed composition the \(r\) source/target block pairs are disjoint.

Because \(s>1\),
\[
s^{L_n}
=
\max_{\mathbf b}
s^{\sum_j LCS(X^{(j)},Y^{(j)}_{\mathbf b})}
\le
\sum_{\mathbf b:\,\sum b_j=n}
s^{\sum_j LCS(X^{(j)},Y^{(j)}_{\mathbf b})}.
\]
For a **fixed** composition, the \(r\) block pairs use disjoint iid source blocks and disjoint iid target chunks, hence are independent. Taking expectation therefore gives
\[
\mathbb E s^{L_n}
\le
\sum_{\mathbf b:\,\sum b_j=n}
\prod_{j=1}^r M_{m,b_j}(s).
\]
The right side is exactly the coefficient
\[
[z^n]\Phi_m(z,s)^r.
\]
All coefficients are nonnegative, so for every \(z\in(0,1)\),
\[
[z^n]\Phi_m(z,s)^r
\le
z^{-n}\Phi_m(z,s)^r.
\]
Thus
\[
\mathbb E s^{L_n}
\le
z^{-n}\Phi_m(z,s)^r.
\]

By Jensen's inequality for the convex function \(x\mapsto s^x\),
\[
s^{\mathbb E L_n}\le\mathbb E s^{L_n}.
\]
Taking logarithms, using \(r=n/m\), and dividing by \(n\),
\[
\frac{\mathbb E L_n}{n}
\le
\frac{-\log z+\frac1m\log\Phi_m(z,s)}{\log s}.
\]
The Chvátal–Sankoff limit exists along the full sequence, hence also along multiples of \(m\). Letting \(r\to\infty\) proves (C005.1). \(\square\)

### Uniform finite-\(B\) truncation

Define
\[
P_B(z,s)
=
\sum_{b=0}^{B}z^bM_{m,b}(s).
\]
The uncomputed tail obeys the deterministic uniform bound
\[
0\le
\Phi_m(z,s)-P_B(z,s)
\le
R_B(z,s)
:=
\frac{s^m z^{B+1}}{1-z}.
\tag{C005.2}
\]
Therefore
\[
\boxed{
\gamma_2
\le
U_{m,B}^{+}(s,z)
:=
\frac{-\log z+\frac1m\log(P_B+R_B)}
{\log s}.
}
\tag{C005.3}
\]

If
\[
U_{m,B}^{0}
=
\frac{-\log z+\frac1m\log P_B}{\log s},
\]
then
\[
0\le U_{m,B}^{+}-U_{m,B}^{0}
=
\frac{\log(1+R_B/P_B)}{m\log s}
\le
\boxed{
\frac{R_B}{mP_B\log s}.
}
\tag{C005.4}
\]
This is an explicit \(n\)-uniform error caused solely by truncating the infinite target-chunk length sum.
