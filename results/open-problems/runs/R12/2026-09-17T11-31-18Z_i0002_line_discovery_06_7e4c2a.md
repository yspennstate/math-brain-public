## 3. Run compression of the exact source walk

Let

\[
A_1,A_2,\ldots\in\{H,V\}
\]

be the coordinate choices of the embedded walk. In the exact source model these are iid fair bits and are independent of the line orientations.

A maximal horizontal run consists of \(G\ge1\) consecutive \(H\)'s followed by a \(V\). Conditional on entering the run,

\[
\boxed{\mathbb P(G=k)=2^{-k},\qquad k=1,2,\ldots.}
\tag{3.1}
\]

The analogous statement holds for vertical runs. These geometric run lengths come entirely from the fresh axis-choice sequence and are independent of the static line environment.

During a horizontal run the row is fixed. If the run starts at horizontal coordinate \(x\), and the orientation of the current row is \(\sigma\in\{-1,1\}\), then the following vertical run begins on column

\[
x+\sigma G.
\tag{3.2}

This elementary compression is the basis of the new theorem.

## 4. Method #15 — break symmetry first: one-coordinate discovery hazard

Let \(C\subset\mathbb Z\) be the set of columns already used by earlier vertical runs and let \(|C|=c\). Consider a complete horizontal run beginning at column \(x\). Enlarge the conditioning sigma-field, if necessary, by revealing the current row orientation \(\sigma\) before revealing the fresh run length \(G\). This does not change the law of \(G\), because axis choices are independent of the environment.

The following vertical run reuses an old column exactly if

\[
x+\sigma G\in C.
\]

For fixed \(x,\sigma,C\), the set

\[
K=\{k\ge1:x+\sigma k\in C\}
\]

contains at most \(c\) positive integers. Therefore

\[
\begin{aligned}
\mathbb P(x+\sigma G\in C\mid\text{past},\sigma)
&=\sum_{k\in K}2^{-k}\\
&\le \sum_{k=1}^{c}2^{-k}
=1-2^{-c}.
\end{aligned}
\]

Hence the exact source walk satisfies the predictable discovery bound

\[
\boxed{
\mathbb P(\text{next vertical run uses a new column}\mid\text{past})
\ge 2^{-c}.
}
\tag{D1}
\]

The same argument, with coordinates exchanged, gives

\[
\boxed{
\mathbb P(\text{next horizontal run uses a new row}\mid\text{past})
\ge 2^{-r}
}
\tag{D2}
\]

when \(r\) horizontal rows have previously been used.

These estimates are uniform over the entire adaptive trajectory. No independence between the discovered-line process and the environment is assumed.

## 5. Method #19 — make it an algorithm: exact adaptive binomial domination

Enumerate the \(H\to V\) transitions of the infinite axis-choice sequence. Let \(D_j^V\) be the **total** number of distinct vertical columns used up through the first \(j\) such transitions, including column \(0\) if an initial vertical run occurred before the first \(H\to V\) transition. Thus \(D_0^V\in\{0,1\}\).

Fix an integer \(c\ge0\) and put

\[
p_c:=2^{-c}.
\]

While \(D_{j-1}^V\le c\), (D1) says that the conditional probability of a new-column discovery at transition \(j\) is at least \(p_c\). Introduce independent uniforms \(U_j\) and realize the actual discovery indicator with its conditional success probability \(q_j\ge p_c\) until \(c+1\) distinct columns have been reached. The auxiliary Bernoulli variables

\[
B_j:=\mathbf 1_{\{U_j\le p_c\}}
\]

are iid Bernoulli\((p_c)\), and before the discovery process exits \(\{0,1,\ldots,c\}\), every \(B_j=1\) forces an actual discovery. Since a possible initial vertical column only starts the actual process ahead, the event \(D_m^V\le c\) implies \(\sum_{j=1}^mB_j\le c\). Consequently

\[
\boxed{
\mathbb P(D_m^V\le c)
\le
\mathbb P\bigl(\operatorname{Bin}(m,2^{-c})\le c\bigr).
}
\tag{D3}
\]

The same domination holds for horizontal-row discoveries.

This is the exact algorithm requested by method #19: at each coordinate switch, compare one adaptive source-model discovery trial with a fixed Bernoulli coin whose parameter depends only on the chosen barrier \(c\).

## 6. The number of discovery opportunities by deterministic time

For \(1\le j\le n-1\), define

\[
\Delta_j=\mathbf1_{\{A_j\ne A_{j+1}\}}.
\]

Because the map

\[
(A_1,A_2,\ldots,A_n)
\longleftrightarrow
(A_1,\Delta_1,\ldots,\Delta_{n-1})
\]

is a bijection of \(\{H,V\}^n\), and the original axis word is uniform, the variables

\[
\Delta_1,\ldots,\Delta_{n-1}
\]

are iid Bernoulli\((1/2)\). Thus the total number of axis switches is exactly

\[
S_n:=\sum_{j=1}^{n-1}\Delta_j
\sim\operatorname{Bin}(n-1,1/2).
\tag{6.1}
\]

The \(H\to V\) and \(V\to H\) switches alternate, so their counts differ by at most one. Therefore on

\[
S_n\ge\frac{n-1}{4}
\]

each direction has at least

\[
m_n:=\left\lfloor\frac{n-1}{8}\right\rfloor
\tag{6.2}
\]

discovery opportunities. A standard multiplicative Chernoff bound gives

\[
\boxed{
\mathbb P\left(S_n<\frac{n-1}{4}\right)
\le \exp\left(-\frac{n-1}{16}\right).
}
\tag{6.3}
\]

## 7. Method #3 — prove something stronger: a uniform line-discovery theorem

Let

- \(L_n^V\) be the number of distinct vertical columns on which at least one vertical step has occurred by embedded time \(n\);
- \(L_n^H\) be the number of distinct horizontal rows on which at least one horizontal step has occurred by embedded time \(n\).

### Theorem C17 — adaptive line-discovery bound

For every \(n\ge18\) and integer \(c\ge0\) satisfying

\[
c\le \frac12 m_n2^{-c},
\qquad
m_n=\left\lfloor\frac{n-1}{8}\right\rfloor,
\tag{7.1}
\]

one has

\[
\boxed{
\mathbb P(L_n^V\le c)
\le
\exp\left(-\frac{n-1}{16}\right)
+
\exp\left(-\frac{m_n2^{-c}}8\right),
}
\tag{C17-V}
\]

and symmetrically

\[
\boxed{
\mathbb P(L_n^H\le c)
\le
\exp\left(-\frac{n-1}{16}\right)
+
\exp\left(-\frac{m_n2^{-c}}8\right).
}
\tag{C17-H}
\]

Hence

\[
\boxed{
\mathbb P\bigl(\min\{L_n^H,L_n^V\}\le c\bigr)
\le
2\exp\left(-\frac{n-1}{16}\right)
+
2\exp\left(-\frac{m_n2^{-c}}8\right).
}
\tag{C17}
\]

#### Proof

If fewer than \(m_n\) \(H\to V\) transitions occur by time \(n\), then (6.3) accounts for the exceptional axis words. Otherwise the first \(m_n\) \(H\to V\) transitions have all occurred by time \(n\), so

\[
\{L_n^V\le c\}\subseteq\{D_{m_n}^V\le c\}.
\]

By (D3), the latter probability is at most

\[
\mathbb P(B\le c),
\qquad B\sim\operatorname{Bin}(m_n,2^{-c}).
\]

Its mean is \(\mu=m_n2^{-c}\). Under (7.1), \(c\le\mu/2\). Therefore

\[
\mathbb P(B\le c)
\le\mathbb P(B\le\mu/2)
\le e^{-\mu/8}
\]

by the multiplicative Chernoff bound with lower-tail parameter \(1/2\). This proves C17-V. C17-H follows by exchanging coordinates, and the union bound gives C17. ∎

This theorem is stronger than the single high-reuse estimate sought in STUCK RECOVERY 2: it controls the entire source path, with no return conditioning, no quenched/annealed switch, and no modified orientation law.

## 8. Near-logarithmic line range with an explicit power \(>1\)

Put

\[
L=\log_2 n
\]

and, for an integer \(K\ge5\), define

\[
c_{n,K}
:=\left\lfloor
L-\log_2L-K
\right\rfloor.
\tag{8.1}
\]

Whenever \(c_{n,K}\ge0\),

\[
2^{-c_{n,K}}
\ge \frac{2^K L}{n}.
\tag{8.2}
\]

For \(n\ge18\), \(m_n\ge n/16\), hence

\[
m_n2^{-c_{n,K}}
\ge 2^{K-4}L.
\tag{8.3}
\]

Since \(K\ge5\), condition (7.1) holds because \(c_{n,K}\le L\le2^{K-5}L\). Substituting (8.3) into C17 yields the explicit corollary

\[
\boxed{
\mathbb P\bigl(
\min\{L_n^H,L_n^V\}\le c_{n,K}
\bigr)
\le
2e^{-(n-1)/16}
+2n^{-a_K},
}
\tag{C18}
\]

where

\[
\boxed{
a_K=\frac{2^{K-7}}{\log 2}.}
\tag{8.4}
\]

Thus, by increasing \(K\) only by an **additive constant** in the line-count threshold, the failure probability can be given an arbitrarily high fixed polynomial exponent.

\log_2n-\log_2\log_2n-7
