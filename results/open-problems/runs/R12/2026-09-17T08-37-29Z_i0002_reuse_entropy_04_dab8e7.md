## 3. Method #6 — deform to the solved endpoint, and compute the exact path likelihood

Work first with the embedded discrete chain. Define the `q=0` partial endpoint as follows: horizontal lines keep their iid static fair orientations; after the walk chooses the vertical axis, its vertical direction is a fresh independent fair sign. Thus each step chooses the axis with probability `1/2`; horizontal direction is static scenery and vertical direction is refreshed. This is the `q=0` endpoint of the earlier interpolation `G_q=S+A_H+qA_V`. It belongs to the randomly oriented-lattice class treated by the 2011 local-limit theorem, with finite-variance skeleton and scenery, hence return exponent `5/4`.

For a fixed nearest-neighbor path

\[
\gamma=(z_0=0,z_1,\ldots,z_n),
\]

let

- `H(γ)` = number of horizontal steps;
- `V(γ)` = number of vertical steps, so `H+V=n`;
- `h(γ)` = number of distinct horizontal rows on which `γ` takes at least one horizontal step;
- `v(γ)` = number of distinct vertical columns on which `γ` takes at least one vertical step.

Call `γ` horizontally consistent if all horizontal traversals of each used row point in the same direction, and vertically consistent analogously.

### Proposition C06 — exact full/partial path-weight ratio

For every fixed path `γ`, its annealed probability under the `q=0` partial embedded walk is

\[
P_0(\gamma)
=
\mathbf 1_{\{\gamma\text{ horizontally consistent}\}}
\,2^{-n-h(\gamma)-V(\gamma)}.
\tag{C06a}
\]

Its annealed probability under the exact full Manhattan embedded walk is

\[
P_1(\gamma)
=
\mathbf 1_{\{\gamma\text{ horizontally and vertically consistent}\}}
\,2^{-n-h(\gamma)-v(\gamma)}.
\tag{C06b}
\]

Hence, on every fully line-consistent path,

\[
\boxed{
\frac{P_1(\gamma)}{P_0(\gamma)}
=2^{V(\gamma)-v(\gamma)}.
}
\tag{C06c}
\]

#### Proof

Under both models, prescribing the horizontal/vertical choice sequence costs `2^{-n}`. In the partial model, the `h(γ)` used horizontal-row signs must match, costing `2^{-h(γ)}`, while each of the `V(γ)` independently refreshed vertical directions costs another factor `1/2`. This gives C06a. In the full model, each used horizontal row and vertical column carries only one static fair sign; consistency is necessary and, when it holds, the environment cost is exactly `2^{-h(γ)-v(γ)}`. This gives C06b and C06c. ∎

The factor

\[
R_V(\gamma):=V(\gamma)-v(\gamma)
\]

is exactly the number of vertical traversals beyond the first traversal of each used column. Thus the positive change-of-measure reward is an **exponential in vertical line reuse**, not a small perturbation.

### A closed-path witness showing exponential amplification

Take a rectangular loop: move `m` horizontal steps right along one row, `k` vertical steps up on one column, `m` horizontal steps left on the new row, and `k` vertical steps down on the original column. This path is fully line-consistent, has

\[
n=2m+2k,\qquad h=2,\qquad v=2,\qquad V=2k,
\]

and therefore

\[
\boxed{
P_1(\gamma)/P_0(\gamma)=2^{2k-2}.
}
\tag{C07}
\]

Taking `k` proportional to `n` makes the pathwise density ratio exponential in `n` even **inside the return event**. Consequently there is no polynomial `n^theta` pathwise domination of the full return-path measure by the partial return-path measure.

This does not disprove the aggregate S1 inequality: many partial paths may compensate for the amplified full paths. It proves only that S1, if true, must use cancellations/counting across large families of paths rather than a pointwise Radon--Nikodym bound.

## 4. The complete one-column deformation kernel

The same calculation can be kept at an intermediate persistence parameter `q`. Suppose a fixed vertical column is traversed `r` times, of which `k` prescribed traversals point upward and `r-k` downward. Relative to the `q=0` fresh-direction probability, annealing the single static column sign gives the exact amplification

\[
\boxed{
A_{r,k}(q)
=\frac12\Big[(1+q)^k(1-q)^{r-k}
+(1-q)^k(1+q)^{r-k}\Big].
}
\tag{C08}
\]

At `q=0`, `A_{r,k}(0)=1`. At `q=1`,

\[
A_{r,k}(1)=
\begin{cases}
2^{r-1},&k=0\text{ or }k=r,\\
0,&0<k<r.
\end{cases}
\tag{C09}
\]

Thus increasing persistence does two opposite things: it annihilates direction-inconsistent line histories, while exponentially amplifying the consistent histories. This is the path-level version of the sign battle seen previously in the Schur complement and in the non-wordwise Bernstein coefficients.

Expanding C08 in `q`, only even powers occur and the coefficients are even Krawtchouk polynomials in `k`. This suggests that the correct transfer object is not a positive density bound but an **orthogonal-polynomial cancellation over direction counts on reused lines**.

## 5. Method #9 — randomize the scenery: exact Renyi-cost obstruction

The preceding recovery proposed introducing independent resampling as a comparison device. C06 shows why fully resampling repeated line directions is too expensive. The obstruction is already exact on one line.

Let `Q_0` be the law of `r` fresh fair signs `(d_1,...,d_r)`. Let `Q_1` choose one fair sign and repeat it `r` times. Then the density `L=dQ_1/dQ_0` is

\[
L(d)=2^{r-1}
\]

on the two constant sign strings and zero on every other string. Hence for every `s>1`,

\[
\boxed{
E_{Q_0}[L^s]
=2^{(s-1)(r-1)}
}
\tag{C10}
\]

and the order-`s` Renyi divergence is exactly

\[
\boxed{
D_s(Q_1\Vert Q_0)=(r-1)\log 2.
}
\tag{C11}
\]

Therefore any Holder/Cauchy--Schwarz comparison that replaces a repeated static line by fresh independent signs pays an exponential factor in that line's local reuse `r`. A global total-variation, `L^s`, or naive information-theoretic decoupling cannot deliver the desired `t^{1/8}` cost when the relevant local times are polynomial in `t`.

This is important because repeated line use is not a nuisance that can simply be truncated away: in the partially oriented RWRS mechanism, large occupation local times are exactly what create the superdiffusive `n^{3/4}` horizontal scale and the `n^{-5/4}` two-dimensional return exponent. Freshening every repeated sign destroys the mechanism one wants to transfer.

**Conclusion of #9:** auxiliary randomization must be sparse/oscillatory. It cannot be a positive change of measure that globally replaces static reuse by independent reuse.

## 6. Method #17 — nearest literature and what survives the feedback

I searched specifically for a theorem that would tolerate scenery/skeleton dependence rather than merely weak dependence inside the scenery.

1. Castell--Guillotin-Plantard--Pene--Schapira's local-limit theorem gives the `n^{-5/4}` return law for the partially oriented finite-variance model. Its proof exploits a product characteristic function conditional on an orientation-independent one-dimensional skeleton/local-time field.
2. Guillotin-Plantard--Prieur's *Limit theorem for random walk in weakly dependent random scenery* permits dependence **within the scenery**, but still assumes that the scenery is independent of the underlying random walk. It therefore does not address the full Manhattan feedback.
3. Lee--Peres--Smart's martingale small-ball theorem gives Gaussian-order small-ball bounds for martingales with bounded increments and controlled conditional variance. Peres--Schapira--Sousi's martingale-defocusing work handles a self-interacting walk using a martingale dispersion principle. These results show that adaptivity itself is not always fatal, but the Manhattan position is not a standalone martingale after static-line information is reused: the already-revealed line signs create a predictable feedback drift. A martingale small-ball estimate for only the fresh-sign component does not prevent the predictable remainder from cancelling it.

No bounded search located a ready-made local-limit/anti-concentration theorem that allows the **weights in a recurrent scenery sum to be chosen adaptively using the same scenery** while preserving a polynomial improvement of the needed magnitude.
