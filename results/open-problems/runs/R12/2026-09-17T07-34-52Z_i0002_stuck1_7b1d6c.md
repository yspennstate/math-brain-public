## 3. (b) Every substantive route tried and why it failed

### Route R1 — existing Green/Nash/smoothing inequalities

The source gives an integrable annealed Green bound, the deterministic-orientation Nash estimate of order `t^{-1}`, and a first-derivative smoothing estimate of order `t^{-3/2}`. R12's first I0002 run built a nonnegative smooth scalar countermodel obeying the analogous three inequalities while having spikes of order `t^{-1}` along an infinite sequence. Hence those scalar inequalities alone cannot force any power `beta>1`. A source solution needs additional Manhattan-specific structure.

### Route R2 — exact loop-polymer weighting

For an annealed path, environment averaging gives a hard line-consistency constraint and a factor `2^{-L(gamma)}` for the number of used horizontal rows / vertical columns. When two consistent pieces share lines, compatible reuse creates an attractive factor `2^J`; conflicts kill the pair. This is exact, but the interaction is not sign-definite in a way that yields a local-limit power. Counting line reuse alone does not reveal the cancellation needed for a return upper bound.

### Route R3 — opposite-environment collision / coupled RWRS language

Time reversal gives an exact collision representation of the full return probability using one walk in `omega` and one in `-omega`. Relative displacement can be written as row/column scenery signs weighted by occupation counts. In the partially oriented model the skeleton local times are independent of the scenery, so Fourier conditioning factorizes. In the full model the occupation weights themselves depend on the two static sceneries. The crucial product characteristic-function step therefore disappears.

### Route R4 — environment-noise spectral parity

The second I0002 run wrote the source return as

\[
\overline p_{2s}(0,0)=K_s(1)\,\mathbb E[(-1)^{D_s}],
\]

where `D_s` is the normalized Walsh spectral degree of the endpoint kernel and `K_s(1)` is a collision norm. This shows that an extra power can come from parity mixing. But influence growth or a large mean degree does not control parity bias: a law supported on even degrees can have arbitrarily large mean and parity bias one. No quantitative mod-two mixing theorem for this endpoint spectrum was obtained.

### Route R5 — deform to the solved partially oriented endpoint

The interpolation `G_q=S+A_H+qA_V`, `q in [0,1]`, has `q=0` at the solved partially oriented endpoint and `q=1` at the source model. Duhamel differentiation is exact, but no sign emerges: the horizontal skew term already couples the parity sectors. A generic theorem that adding skew drift decreases return is false even in finite Eulerian examples, so generic nonreversibility monotonicity cannot be invoked.

### Route R6 — D4 symmetry and Bernstein positivity

The preceding run reduced the annealed embedded return to a symmetric polynomial `Q_n(a^2,b^2)` and proposed the sufficient all-degree Bernstein positivity

\[
F_{2m}(1,q)=\sum_{j=0}^m c_{m,j}(1-q^2)^j,\qquad c_{m,j}\ge0.
\]

Exact arithmetic verifies it for `2m<=8`. But the conditional axis word `HVVHVV` has return `(1+q^2)^2/16`, increasing with `q`; hence positivity is not wordwise. Any proof must group different axis-choice words and exhibit cancellation at the orbit/family level. No such grouping is known.

### Route R7 — parity-sector resolvent duality

The `J_H x J_V` parity decomposition gives a positive self-adjoint compiler, but after the second Schur complement the source vector sees

\[
D_{00}(q)-q^2 ZD_{11}(q)^{-1}Z^*.
\]

The direct `+q^2` dissipation is offset by the negative feedback rebate through the `11` sector. Thus the exact operator formulation identifies the sign battle but does not give the needed Loewner monotonicity. Bounding the feedback by the direct term with a strict polynomial margin is exactly the unresolved step, not a corollary of positivity.

## 4. Method #20 — what the failed algorithms are missing

The three superficially different promising algorithms all fail for the same structural reason:

1. the partially oriented Fourier/local-time proof wants to condition on an orientation-independent skeleton;
2. the path-polynomial proof wants to keep axis words separate;
3. the parity-sector resolvent proof wants the direct dissipative channel to dominate feedback.

In the full model, static line reuse creates **feedback across the decomposition**. The path chooses future line occupations using the same orientations whose characteristic function one is trying to average. Algebraically, that feedback appears as cross-word cancellations in the Bernstein polynomial and as the `ZD_{11}^{-1}Z^*` Schur term. Any successful route must neutralize this feedback quantitatively; introducing another representation without doing so merely moves the same obstruction.

## 5. Method #22 — nearest solved problem and what its proof has that this problem lacks

The nearest solved problem is the partially oriented random lattice treated by Castell--Guillotin-Plantard--Pene--Schapira, whose local limit theorem gives annealed return probability of order `n^{-5/4}`. The source paper itself highlights why that model is tractable: with only horizontal lines statically oriented, the vertical coordinate is a lazy simple random walk independent of the line orientations. Conditional on its local times `N_n(y)`, the horizontal displacement is a random-walk-in-random-scenery sum and Fourier inversion produces a product of scenery characteristic functions,

\[
\prod_y \phi_\xi(\theta N_n(y)).
\]

The proof can then split small and medium/large Fourier frequencies and use the occupation profile independently of the scenery.

The full Manhattan model lacks exactly this separation. Both coordinate occupation profiles depend on the other family of static line signs, so conditioning on the path skeleton reveals information about the scenery instead of freezing an independent weight field. The full problem therefore needs a **decoupling statement with a quantitative polynomial cost**, not merely a re-use of the RWRS local-limit theorem.

The other nearby solved transfer, P03's doubly periodic classification, gets recurrence from a finite-state Markov-additive reduction and a periodic local limit theorem. Its finite periodic type space removes the random-scenery feedback rather than controlling it, so it does not supply the missing iid decoupling mechanism.
