## 4. #2 ATTACK THE NEGATION FIRST — the source's printed off-critical factor fails in its exact Bethe model

The source defines, in Section 6,

\[
\xi=(1-\rho_*)^{-1}
\]

for the subcritical regime. Theorem 6.2 then prints the off-critical assertion

\[
\mathbb P(|S|=n)\sim C n^{-3/2} e^{-n/\xi}.
\tag{4.1}
\]

But Proposition 9.1 gives an exact source model on the `d`-regular Bethe lattice: with

\[
b=d-1\ge 2,
\qquad X\sim\mathrm{Bin}(b,p),
\qquad \rho=bp<1,
\]

the failed cluster is exactly the one-type Galton--Watson tree with offspring `X`.

Let `T` be its total progeny. Dwass's formula gives, **exactly for every `n>=1`**,

\[
\boxed{
\mathbb P(T=n)
=\frac1n\binom{bn}{n-1}p^{n-1}(1-p)^{(b-1)n+1}.
}
\tag{4.2}
\]

Write `q=1-p`. Since

\[
\binom{bn}{n-1}=\binom{bn}{n}\frac{n}{(b-1)n+1},
\]

Stirling's formula yields the exact exponential rate and prefactor

\[
\boxed{
\mathbb P(T=n)
\sim C_b(p)n^{-3/2}e^{-nI_b(p)},
}
\tag{4.3}
\]

with

\[
\boxed{
I_b(p)
=-\log A_b(p),
\qquad
A_b(p)=\frac{b^b}{(b-1)^{b-1}}p(1-p)^{b-1},
}
\tag{4.4}
\]

and

\[
\boxed{
C_b(p)
=\sqrt{\frac{b}{2\pi(b-1)}}\frac{1-p}{p(b-1)}.
}
\tag{4.5}
\]

The source's factor (4.1) would instead force exponential rate

\[
\xi^{-1}=1-bp.
\]

These are not the same rate.

There is an even shorter ratio proof. From (4.2),

\[
\frac{\mathbb P(T=n+1)}{\mathbb P(T=n)}
=
\frac{p(1-p)^{b-1}}{n+1}
\frac{\prod_{j=1}^{b}(bn+j)}{\prod_{j=2}^{b}((b-1)n+j)},
\]

hence

\[
\boxed{
\lim_{n\to\infty}
\frac{\mathbb P(T=n+1)}{\mathbb P(T=n)}
=A_b(p).
}
\tag{4.6}
\]

Any asymptotic of the printed form `C n^{-3/2} exp(-n/xi)` would force the ratio limit `exp(-1/xi)` instead.

### Exact rational witness

Take the source's exact `d=3` Bethe subclass (`b=2`) and `p=1/4`. Then

\[
\rho=\frac12,
\qquad \xi=2,
\]

and (4.2) simplifies to

\[
\mathbb P(T=n)
=\frac{3}{n+1}\binom{2n}{n}\left(\frac3{16}\right)^n.
\]

Therefore

\[
\boxed{
\frac{\mathbb P(T=n+1)}{\mathbb P(T=n)}
=\frac{3(2n+1)}{8(n+2)}
\longrightarrow \frac34.
}
\tag{4.7}
\]

The printed factor would force `exp(-1/2)`. Elementary exact separation needs no floating point: `exp(1/2)>1+1/2=3/2`, so `exp(-1/2)<2/3<3/4`.

Thus the off-critical exponential factor printed in source Theorem 6.2 is **false even in the source's exact Bethe model**. This does **not** refute H0006, which is an open programme rather than a numerical conjecture; it changes the scale that H0006 has to study.

## 6. #5 ADD A PARAMETER — the real near-critical cutoff is quadratic in `xi`

Parameterize the distance to criticality by

\[
\varepsilon=1-\rho=1-bp,
\qquad
p=\frac{1-\varepsilon}{b},
\qquad
\xi=\varepsilon^{-1}.
\]

Then (4.4) becomes

\[
A_b(\varepsilon)
=(1-\varepsilon)
\left(1+\frac{\varepsilon}{b-1}\right)^{b-1},
\]

so

\[
I_b(\varepsilon)
=-\log(1-\varepsilon)
-(b-1)\log\left(1+\frac{\varepsilon}{b-1}\right).
\tag{6.1}
\]

Expanding at `epsilon=0`, the linear terms cancel:

\[
\boxed{
I_b(\varepsilon)
=\frac{b}{2(b-1)}\varepsilon^2+O(\varepsilon^3).
}
\tag{6.2}
\]

Hence the actual total-progeny exponential cutoff length is

\[
\boxed{
I_b(\varepsilon)^{-1}
\sim \frac{2(b-1)}{b}\,\xi^2,
\qquad \xi\to\infty.
}
\tag{6.3}
\]

This separates two quantities that the source text currently conflates:

- `xi=(1-rho)^{-1}` is indeed the exact **mean total progeny** in the one-type Bethe process;
- the **large-total-progeny exponential cutoff** is of order `xi^2`, not `xi`.

For `b=2`, this is especially transparent:

\[
A_2(\varepsilon)=1-\varepsilon^2,
\qquad
I_2(\varepsilon)=-\log(1-\varepsilon^2)
=\varepsilon^2+O(\varepsilon^4).
\]

Thus the discrepancy persists arbitrarily close to criticality; it is not an artifact of the numerical witness `p=1/4`.

## 7. #30 ONE SCALE AT A TIME — explicit finite-size scaling function on the Bethe layer

Now let the external finite-size parameter be `N`, and take a near-critical Bethe sequence

\[
\varepsilon_N=1-bp_N,
\qquad
\sqrt N\,\varepsilon_N\longrightarrow \lambda\in[0,\infty).
\tag{7.1}
\]

Let `T_N` denote total progeny of `GW(Bin(b,p_N))`. For every fixed `x>0`, put `m_N=floor(xN)`. Applying (4.3) with `p=p_N` and using (6.2),

\[
C_b(p_N)\to c_b:=\sqrt{\frac{b}{2\pi(b-1)}},
\]

and

\[
m_N I_b(\varepsilon_N)
\longrightarrow
\frac{b}{2(b-1)}\lambda^2x.
\]

Since `m_N/N -> x`, this gives the explicit finite-size scaling law

\[
\boxed{
N^{3/2}\,
\mathbb P(T_N=\lfloor xN\rfloor)
\longrightarrow
c_b x^{-3/2}
\exp\!\left[-\frac{b}{2(b-1)}\lambda^2x\right].
}
\tag{7.2}
\]

The proof is uniform on compact `x`-intervals bounded away from zero: the central-binomial Stirling remainder is uniform there, `p_N` stays in a compact neighborhood of `1/b`, and (6.2) is uniform for `epsilon_N -> 0`.

Equation (7.2) gives a clean trichotomy:

- `sqrt(N)(1-rho_N) -> 0`: the critical `N^{-3/2}` law survives at macroscopic cluster sizes;
- `sqrt(N)(1-rho_N) -> lambda in (0,infinity)`: a nontrivial Gaussian-in-`lambda` crossover appears;
- `sqrt(N)(1-rho_N) -> infinity`: macroscopic total progeny is exponentially suppressed on the scale `N(1-rho_N)^2`.

Equivalently, **finite size `N` competes with the branching total-progeny cutoff when**

\[
\boxed{
\xi_N\asymp \sqrt N,
}
\tag{7.3}
\]

not when `xi_N asymp N`.

For the binary-forward Bethe case `b=2`, (7.2) reduces to the particularly simple formula

\[
\boxed{
N^{3/2}\,
\mathbb P(T_N=\lfloor xN\rfloor)
\longrightarrow
\frac{1}{\sqrt\pi}\,x^{-3/2}e^{-\lambda^2x}.
}
\tag{7.4}
\]

This proves layer 1 of the frozen H0006 metric.
