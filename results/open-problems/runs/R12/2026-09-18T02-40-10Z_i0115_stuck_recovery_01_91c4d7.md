## 4. Section-I(b): every route tried and why each failed

### Route 1 — Poisson-line fragmentation skeleton

The first I0115 run used arriving random lines to build an exact finite-state partition process on labels. Its split rates are Crofton integrals and the complete partition law is a matrix exponential. It is similarity covariant and projectively consistent.

**Failure:** it is only an abstract fragmentation skeleton. It does not embed a route system in the plane and hence is not a SIRSN. It supplies the kind of explicit finite-dimensional law wanted by the source but misses the network axioms.

### Route 2 — finite separator hubs

Using the first `m` separating lines, choosing a good-angle pair, and intersecting them cures the local inverse-angle singularity for `m>=3`; the preceding run derived finite expected local stretch.

**Failure:** the hub is pair-specific. Turning it into a finite polygonal route leaves order-distance private chord segments for a positive density of Poisson endpoint pairs, which forces infinite main-road intensity `p(1)`. Local stretch is not the SIRSN bottleneck; route sharing is.

### Route 3 — delayed `m`-hit fragmentation

The natural attempt was to delay a split until `m` separating lines have appeared.

**Failure:** pairwise delaying preserves label deletion but loses transitivity, so it is not a partition. Blockwise delaying restores partitions but loses projective deletion consistency. The two desirable properties are incompatible for that local counting rule.

### Route 4 — one stationary dyadic hierarchy

A single nested global tree automatically gives compatible coalescing routes and an explicit hierarchy.

**Failure:** the first common-ancestor scale has a `distance/scale` tail. The center-tree route length is proportional to that scale, so the mean route length diverges logarithmically.

### Route 5 — best of two independent dyadic hierarchies

Taking the smaller common-ancestor scale squares the critical tail. The previous run obtained an exact finite expectation and uniform finite mean-stretch comparison.

**Failure:** choosing the better tree separately for each endpoint pair breaks the SIRSN two-meeting-points compatibility axiom. An exact rational witness is archived in the preceding report.

### Route 6 — globally weighted overlay of two hierarchies

The surviving repair is to put both trees into one weighted graph/metric and define every route as a unique geodesic, rather than handshake per pair.

**Failure so far:** the global geodesic decision is nonlocal. A fine edge can be useful because of a remote connector at a much larger scale. No finite stopping rule has been found that decides the next route segment from local state. Without such locality, neither `p(1)` nor a finite-dimensional route law closes. This candidate is therefore only a design direction, not a theorem.

### Route 7 — use the existing Kahn Poisson-road SIRSN directly

This route solves the hardest axiomatic part immediately: Kahn already gives a genuine SIRSN; the random metric gives global route compatibility, and later work gives uniqueness/confluence/local road structure.

**Failure:** the fixed-pair geodesic remains an infinite multiscale object approaching both endpoints through roads of arbitrarily small speed. The known proofs establish existence, metric comparison, confluence, and local structure, but do not furnish the canonical stopping/regeneration kernel needed for an explicit full path law.

## 5. Section-I(c): what a proof must contain that no route so far contains

A source-moving proof needs all of the following in the *same construction*.

1. **One global metric or route system.** Compatibility must be structural, not checked pair-by-pair.
2. **Infinite multiscale endpoint access.** Every finite-depth access rule seen so far either has divergent mean length or produces too much private road. The successful SIRSN geometry has to share roads before leaving fixed endpoint neighborhoods.
3. **Finite main-road intensity.** The construction needs a direct mechanism preventing arbitrarily many fine edges from surviving in the interiors of long routes.
4. **A canonical regenerative state for a fixed finite endpoint set.** There must be a measurable first event/cut/bottleneck whose law is explicit and such that, conditional on that state, the unexplored environment decomposes into independent or explicitly coupled pieces of the same type.
5. **An explicit transition kernel and termination/limit theorem.** Iterating the regenerative state must actually determine the whole route/subnetwork law; existence of cut points alone is not enough.
6. **Projective consistency for larger `k`.** Once the two-point case exists, the same global environment must couple all finite endpoint sets. A family of separately sampled pair laws does not count.

The current toy models have item 4 but fail 1--3. The Kahn model has 1--3 and much of the geometry behind 6, but no explicit item-4 regeneration kernel has been recovered. That mismatch is the real obstruction.

## 8. The three thinking moves this run

### #2 ATTACK THE NEGATION FIRST

I tried to make the surviving two-tree/global-overlay idea fail outright, because a clean impossibility would save further construction work.

The strongest plausible negative statement is: "any overlay that allows cross-tree switching at arbitrarily fine scales must have infinite `p(1)` or infinite mean route length." The preceding examples support this intuition, but the route does not close. A weighted global geodesic can suppress most fine-scale switches, so there is no monotone lower bound from edge availability to edge usage. Conversely, making cross-tree connectors rare enough to control `p(1)` may recreate the one-tree padding divergence. No theorem follows without a quantitative geodesic-use estimate that is currently absent.

**Outcome:** the negation attack identifies the tradeoff but does not refute the overlay family. No claim promoted.

### #6 DEFORM TO A POINT YOU CAN SOLVE

The natural deformation is

`one tree -> two-tree per-pair minimum -> weighted two-tree global overlay -> Poisson-road metric`.

The endpoints are well understood: the first has explicit law but infinite mean route length; the second cures mean length but breaks compatibility; Kahn's endpoint is a genuine SIRSN. What fails is continuity of the relevant properties. Route choice changes discontinuously when a single connector becomes competitive, and `p(1)` is a global union-of-routes quantity, so neither finite mean stretch nor finite main-road intensity is stable under an obvious interpolation parameter.

**Outcome:** deformation is useful as a conceptual map but does not transport a theorem across the family. No claim promoted.

### #20 FIND WHY THE ALGORITHM FAILS

The obvious algorithm for an explicit route law is: reveal enough environment near the endpoints to determine the next shared road/cut point, recurse on the remaining problem, and multiply/compose explicit transition kernels.

The precise failure is now clear: the proposed "next road" is not yet a **stopping-set functional** of the Poisson environment. Whether a candidate road lies on the global geodesic can depend on faster roads arbitrarily far away, so revealing a bounded local region does not isolate an independent unexplored Poisson complement. Without a stopping-set/regeneration theorem, the recursion is circular.

**Outcome:** this is the most informative failure of the three. The missing theorem is not another length estimate; it is a canonical regeneration statement for the global geodesic.
