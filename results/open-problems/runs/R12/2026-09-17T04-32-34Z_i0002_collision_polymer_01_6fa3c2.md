## 2. Current source and literature check

The current primary source is still arXiv:2609.07621v1, submitted 7 September 2026; no later arXiv version was recovered in the bounded search on 17 September 2026.

The source model is: each horizontal and vertical line of `Z^2` receives an independent fair orientation; at each discrete step the walker chooses horizontal or vertical with probability `1/2` and moves one unit in that line's orientation. The continuous-time version jumps along each of its two outgoing edges at rate one. The source defines

\[
\overline p_t(0,0)=\mathbb E p_t^\omega(0,0).
\]

Theorem 1.2 proves

\[
\int_0^\infty \overline p_t(0,0)\,dt\le 2048.
\]

Proposition 6.2 proves, for every deterministic orientation,

\[
p_t^\omega(x,y)\le \frac{2}{t+2},
\]

and for `f(t)=\overline p_t(0,0)`,

\[
|f'(t)|\le \frac{2}{\sqrt t(1+t/4)}\le 8t^{-3/2}.
\]

Problem 2 asks whether

\[
\boxed{\overline p_t(0,0)=O(t^{-\beta})\text{ for some }\beta>1.}
\]

The paper notes Redner's `4/3` prediction. It also records that in the partially oriented model the annealed return probability is of order `n^{-5/4}` (Castell--Guillotin-Plantard--Pene--Schapira), while in the full Manhattan model the two coordinates are mutually coupled and the random-scenery separation used there is unavailable.

## 3. Method #2 — attack the negation first

I first tried to see whether the desired power could fail because the source's already-proved scalar estimates permit arbitrarily sparse `t^{-1}` spikes. They do. This does **not** refute the Manhattan conjecture; it rigorously refutes a tempting proof strategy that only massages Theorem 1.2 and Proposition 6.2.

### X01 — exact scalar no-go for Green + Nash + first-derivative smoothing

There exists a nonnegative `C^1` function `F:(0,infinity)->[0,infinity)` satisfying simultaneously

\[
\int_0^\infty F(t)\,dt<1,
\qquad
F(t)\le \frac{2}{t+2},
\qquad
|F'(t)|\le 8t^{-3/2},
\]

but such that for **every** `beta>1`,

\[
F(t)\ne O(t^{-\beta}).
\]

#### Proof

Let

\[
\psi(u)=
\begin{cases}
(1-u^2)^2,& |u|\le1,\\
0,& |u|>1.
\end{cases}
\]

Then `psi` is nonnegative and `C^1`, `psi(0)=1`, `||psi||_infty=1`, and

\[
\|\psi'\|_\infty=\frac{8}{3\sqrt3}<2.
\]

For `j>=1` set

\[
t_j=16^j,\qquad w_j=4^j=\sqrt{t_j},
\]

and define

\[
F(t)=\sum_{j\ge1}\frac1{t_j}\psi\!\left(\frac{t-t_j}{w_j}\right).
\]

The supports `[t_j-w_j,t_j+w_j]` are disjoint. On the `j`th support, `w_j<=t_j/4`, hence `t<=5t_j/4`, so

\[
F(t)\le t_j^{-1}\le \frac2{t+2}.
\]

Also

\[
|F'(t)|\le 2t_j^{-3/2}\le 8t^{-3/2}.
\]

Moreover

\[
\int_0^\infty F(t)\,dt
=\left(\int_{-1}^1(1-u^2)^2du\right)\sum_{j\ge1}t_j^{-1/2}
=\frac{16}{15}\sum_{j\ge1}4^{-j}
=\frac{16}{45}<1.
\]

But `F(t_j)=t_j^{-1}`. Therefore for every `beta>1`,

\[
t_j^{\beta}F(t_j)=t_j^{\beta-1}\to\infty.
\]

QED.

**Interpretation.** The three scalar facts currently proved in the source -- finite Green mass, the universal `O(t^{-1})` Nash bound, and the `O(t^{-3/2})` derivative bound -- cannot by themselves imply Problem 2. A successful proof must use additional structure of the Manhattan semigroup/environment, not a purely scalar Tauberian rearrangement of those estimates. The construction is not claimed to satisfy a Markov-semigroup representation; that extra structure is exactly what remains available to exploit.

I also looked for an actual source counterexample mechanism. The obvious recurrent-box / alternating-orientation traps do not look polynomially competitive: keeping a diffusive walk recurrent-like to time `t` inside a box needs box scale about `sqrt(t)`, while prescribing the required line orientations costs exponentially in that scale. Repeated finite directed cycles instead incur exponential axis-choice cost. I found no credible `t^{-1+o(1)}` annealed lower mechanism, so the source remains OPEN rather than REFUTED.

## 4. Method #18 — say it in another language: an exact loop-polymer expansion

The discrete-time annealed return probability has an exact combinatorial representation that does not appear in the previous R12 history.

For a nearest-neighbor path

\[
\gamma=(z_0,z_1,\ldots,z_n),\qquad z_0=0,
\]

let `H(gamma)` be the set of horizontal rows on which `gamma` makes at least one horizontal step and `V(gamma)` the set of vertical columns on which it makes at least one vertical step. Put

\[
L(\gamma)=|H(\gamma)|+|V(\gamma)|.
\]

Call `gamma` **line-consistent** if all horizontal traversals on any fixed row have the same sign and all vertical traversals on any fixed column have the same sign. Let `C(gamma)` be its consistency indicator.

### C01 — exact annealed path weight

For every finite nearest-neighbor path `gamma` of length `n`,

\[
\boxed{
\mathbb P_{\rm ann}(X_0=z_0,\ldots,X_n=z_n)
=2^{-n}\,C(\gamma)\,2^{-L(\gamma)}.
}
\tag{C01}
\]

Consequently

\[
\boxed{
\overline p_n(0,0)
=2^{-n}\sum_{\gamma:0\to0,\ |\gamma|=n}
C(\gamma)2^{-L(\gamma)}.
}
\tag{C01a}
\]

The source's rate-two Poisson clock then gives exactly

\[
\boxed{
\overline p_t(0,0)
=e^{-2t}\sum_{n\ge0}\frac{(2t)^n}{n!}\overline p_n(0,0).
}
\tag{C01b}
\]

#### Proof

The horizontal/vertical choices along a prescribed path have probability `2^{-n}`. If the path requests both directions on the same oriented line, its environment probability is zero. If it is line-consistent, each used horizontal row and vertical column prescribes exactly one independent fair orientation bit. There are `L(gamma)` such bits, so the environment probability is `2^{-L(gamma)}`. Summing over closed paths gives C01a. Poissonization is the source's own continuous/discrete-time relation. QED.

This changes the problem into a weighted enumeration of line-consistent closed walks: orientation entropy penalizes every newly used line by a factor `1/2`, while reuse of a line is free once its direction has been paid for.

### C02 — exact concatenation interaction: line reuse is an attractive polymer reward

For a line-consistent path `gamma`, write `sigma_gamma` for the required orientation signature on its used lines and

\[
w(\gamma)=2^{-|\gamma|}2^{-L(\gamma)}.
\]

Let `alpha` and `beta` be individually line-consistent and concatenable. Put

\[
J(\alpha,\beta)=|\mathcal L(\alpha)\cap\mathcal L(\beta)|,
\qquad
\mathcal L=H\cup V.
\]

If their required directions disagree on a shared line, `alpha beta` has zero annealed weight. If all shared requirements agree, then

\[
\boxed{
w(\alpha\circ\beta)
=w(\alpha)w(\beta)\,2^{J(\alpha,\beta)}.
}
\tag{C02}
\]

Indeed, compatibility gives

\[
L(\alpha\circ\beta)=L(\alpha)+L(\beta)-J(\alpha,\beta).
\]

Thus splitting a loop at one time scale yields an exact **hard-conflict + attractive-overlap** polymer interaction: shared lines with matching orientation receive a factor `2` each; a shared line with conflicting orientation kills the pair.

Equivalently, if the environment were independently refreshed at the splitting time, the two path segments would carry the product weight `w(alpha)w(beta)`. The actual static environment is obtained by multiplying that refreshed weight by

\[
2^{J(\alpha,\beta)}\mathbf 1_{\{\sigma_\alpha=\sigma_\beta\text{ on the overlap}\}}.
\]

This identity identifies a concrete gluing variable rather than a vague dependence obstruction. Any path-space proof must understand the shared-line overlap `J` and the sign-compatibility event together.

## 5. A second language that looks more promising: opposite-drift collisions

The source generator can be written `G_omega=S+A_omega`, with `S` self-adjoint and `A_omega` skew-adjoint. Reversing every line orientation sends `A_omega` to `-A_omega`, hence

\[
G_\omega^*=G_{-\omega}.
\]

### C03 — exact forward/backward overlap identity

For every `s>=0`,

\[
\boxed{
\overline p_{2s}(0,0)
=\mathbb E\sum_{z\in\mathbb Z^2}
 p_s^\omega(0,z)p_s^{-\omega}(0,z).
}
\tag{C03}
\]

#### Proof

For fixed `omega`, the adjoint identity gives

\[
p_s^\omega(z,0)=p_s^{-\omega}(0,z).
\]

Chapman--Kolmogorov therefore gives

\[
p_{2s}^\omega(0,0)
=\sum_z p_s^\omega(0,z)p_s^\omega(z,0)
=\sum_z p_s^\omega(0,z)p_s^{-\omega}(0,z).
\]

Average over `omega`. QED.

So Problem 2 is **exactly** a collision local-limit problem for two conditionally independent walkers started at the origin, one evolving in `omega` and the other in the globally reversed environment `-omega`:

\[
\boxed{
\overline p_{2s}(0,0)
=\mathbb P_{\rm ann}(X_s^+=X_s^-).
}
\tag{C03a}
\]

This pair representation exposes a structural feature hidden in the scalar Green function. Let `D_s=X_s^+-X_s^-`. If the two particles are at the same site `(x,y)`, then

- either horizontal clock of the two particles changes `D` by **the same vector** `omega(y,1)e_1`, so the total rate of that relative jump is `2`;
- either vertical clock changes `D` by **the same vector** `omega(x,2)e_2`, again at total rate `2`.

Thus at a collision there are no instantaneous relative jumps in the opposite horizontal or vertical directions. The diagonal is locally one-sided for the relative motion. More generally, while the particles occupy the same row, both horizontal clocks move the horizontal relative coordinate in the same row-orientation direction; the analogous statement holds on a shared column.

This makes a pair/relative-coordinate local-limit attack materially different from another scalar Tauberian attempt.

## 6. Method #30 — one scale / one direction: isolate a fresh common-line episode

The pair process admits a clean one-line calculation.

Suppose the two particles have just entered the same horizontal row `y` and, relative to the explored sigma-field, the orientation `omega(y,1)` is still fresh. Until the first vertical jump of either particle, horizontal events occur at combined rate `2` and vertical separation events at combined rate `2`. Therefore the number `K` of horizontal relative jumps made before the row is left satisfies

\[
\boxed{\mathbb P(K=k)=2^{-(k+1)},\qquad k=0,1,2,\ldots}
\tag{C04}
\]

and all `K` jumps have the same sign. The resulting horizontal relative burst is

\[
\boxed{K\,\omega(y,1)e_1.}
\tag{C04a}
\]

The sign is an independent fair bit when the common row is fresh. The vertical statement is identical.

This exact calculation is useful mainly because of what it says **does not** create the anomaly: fresh common lines alone give symmetric geometric bursts with finite variance. A chain built only from fresh-line episodes would be diffusive at the embedded level and would naturally lead to a two-dimensional `t^{-1}` local-limit scale, not a power strictly above one. The superdiffusive/local-limit improvement must therefore exploit **reuse of the same line orientation across separated episodes**, i.e. an occupation/local-time amplification mechanism of random-scenery type.

There is a corresponding exact pathwise identity. Let `N_y^+(s)` and `N_y^-(s)` count horizontal jumps made up to time `s` by the `omega` and `-omega` walkers, respectively, while on row `y`. Then

\[
\boxed{
D_s^{(1)}
=\sum_{y\in\mathbb Z}\omega(y,1)\,[N_y^+(s)+N_y^-(s)].
}
\tag{C05}
\]

Likewise, if `M_x^+,M_x^-` are the vertical jump counts on column `x`,

\[
\boxed{
D_s^{(2)}
=\sum_{x\in\mathbb Z}\omega(x,2)\,[M_x^+(s)+M_x^-(s)].
}
\tag{C05a}
\]

The coefficients are nonnegative occupation counts. This is the exact full-Manhattan analogue of a random-walk-in-random-scenery sum, but with a decisive complication: the occupation fields themselves depend on both scenery families. In the partially oriented model, the undirected coordinate produces a local-time field independent of the horizontal scenery, which is why the Castell--Guillotin-Plantard--Pene--Schapira characteristic-function factorization works. Here the factorization is not legal without a new decoupling mechanism.

This is the most concrete route produced in this run: prove an anti-concentration theorem for the mutually coupled scenery sums C05/C05a, or interpolate them to a decoupled local-time field while controlling the error.

## 8. Nearest solved shape and precise missing ingredient

The closest solved return-probability theorem is the partially oriented lattice local limit theorem of Castell--Guillotin-Plantard--Pene--Schapira (Annals of Probability 2011), which yields order `n^{-5/4}`. Their Fourier argument exploits a representation in which one coordinate's local times are generated independently of the scenery signs; conditional characteristic functions then factor over visited levels.

The current source itself emphasizes that this separation fails for the full Manhattan model because each coordinate controls which scenery the other coordinate subsequently samples.

C05/C05a now make the missing ingredient exact: one needs to recover enough **approximate independence between scenery signs and their occupation weights** to obtain a Littlewood--Offord / characteristic-function gain, without falsely conditioning on occupation fields that already encode those signs.

A useful next sufficient target is an interpolation/decoupling estimate for one scenery family. Schematically, if `\widetilde\omega(y,1)` is an independent copy while the occupation field in C05 is kept from the original pair process, compare

\[
\sum_y \omega(y,1)L_y
\quad\text{with}\quad
\sum_y \widetilde\omega(y,1)L_y,
\qquad L_y=N_y^++N_y^-.
\]

The decoupled object has conditional characteristic function

\[
\prod_y \cos(\theta L_y),
\]

and is amenable to the random-scenery local-limit technology. The hard question is to control the replacement error created by the feedback of horizontal signs into the vertical occupation field.
