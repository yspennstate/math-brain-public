# 4. Required stuck report

## (a) Exact blocking statement

Write

\[
Y_n:=T(0,nx)-ET(0,nx),\qquad s_p(n):=\|Y_n\|_p.
\]

The exact source obstruction is

\[
\boxed{
\exists\delta>0:\quad
\limsup_{n\to\infty}\frac{\log s_{2+\delta}(n)}{\log n}
\le
\liminf_{n\to\infty}\frac{\log s_2(n)}{\log n}.
}
\tag{BLOCK}
\]

The reverse inequality is automatic from `s_(2+delta)(n) >= s_2(n)` and liminf/limsup ordering, so (BLOCK) is exactly what is missing.

The first I0060 report decomposed the same obstruction into two nonnegative defects,

\[
\overline\chi_{2+\delta}-\underline\chi_2
=
(\overline\chi_2-\underline\chi_2)
+
(\overline\chi_{2+\delta}-\overline\chi_2).
\]

Thus a proof must simultaneously prevent **cross-scale oscillation** of the `L^2` fluctuation exponent and prevent a **moment-order exponent gap** above `p=2`.

## (b) Routes tried and the precise reason each failed

### Route 1 — entropy differentiation in the moment order

The first I0060 run recovered the exact identity

\[
\frac{d}{dp}\log\|Y_n\|_p
=
\frac{1}{p^2}
\frac{\operatorname{Ent}(|Y_n|^p)}{E|Y_n|^p}.
\]

It gives a concrete route to the moment-order defect: an `o(log n)` integrated entropy cost over `p in [2,2+delta]` would imply `s_(2+delta)(n)/s_2(n)=n^{o(1)}`. **Failure:** even perfect same-scale moment comparison says nothing by itself about whether `log s_2(n)/log n` has one limiting exponent.

### Route 2 — same-scale concentration

The first run also tested the strongest abstract version of this hope: a sequence can have exactly Gaussian standardized laws at every `n`, hence constant `L^q/L^2` ratios, while its standard-deviation exponent alternates between two powers along subsequences. **Failure:** same-scale concentration controls the moment defect but cannot rule out cross-scale oscillation.

### Route 3 — generic additivity/subadditivity/mixing

The second I0060 run constructed a bounded positive stationary strongly-mixing exactly additive process whose fluctuation scale oscillates between prescribed powers. **Failure:** positivity, bounded increments, stationarity, strong mixing and exact additivity are still too weak. Any proof of Q17 must exploit spatial FPP geometry, not generic subadditive-process technology alone.

### Route 4 — independent refresh / geodesic chaos

The third run derived the exact refresh-regret identity

\[
E[T_0(\pi_t)-T_0]
=t\big(mE|\pi_0|-ET_n\big),
\]

and showed the coefficient is of order `n` for nondegenerate ordinary FPP. At the Ahlberg--Deijfen--Sfragara chaos scale `t ~ Var(T_n)/n`, the old-environment regret is therefore of order `Var(T_n)`, not of order `sqrt(Var(T_n))`. **Failure:** independent refresh can create chaotic/multiple-valley paths, but the selection drift is intrinsically too large to turn those paths directly into standard-deviation-scale competitors.

### Route 5 — remove refresh drift by a same-marginal martingale coupling

The third run observed that if same-law square-integrable `X,Y` satisfy `E[X|Y]=Y`, then `X=Y` almost surely. **Failure:** there is no nontrivial one-edge same-marginal perturbation with zero conditional regression drift. Any drift cancellation must be collective/non-product or avoid path-level zero drift entirely.

### Route 6 — noise-spectral interaction degree

For integer-supported FPP the third run used the exact dynamical covariance/co-influence formalism to rewrite the `L^2` scale through

\[
D_n:=\frac{K_n(0)}{\operatorname{Var}T_n}\asymp\frac{n}{\operatorname{Var}T_n},
\]

so existence of the `L^2` polynomial exponent is equivalent to convergence of `\log D_n/\log n`. **Failure:** this is a clean reformulation, but no FPP-specific quasi-multiplicativity, subadditivity, or monotonicity in `n` for `D_n` has been proved. Rewriting the oscillation does not eliminate it.

These failures are complementary rather than redundant: Routes 1--2 fail across scales, Route 3 proves generic process structure cannot fix that, Routes 4--5 kill the most obvious FPP-specific perturbative mechanism, and Route 6 identifies the missing scale-regularity statement without proving it.

## (c) What a proof must contain that no route so far contains

Method **#27 (swap the quantifiers)** isolates the missing mechanism sharply. Let

\[
\alpha:=\underline\chi_2.
\]

By definition, for every `epsilon>0` there are infinitely many **good scales** `n_j` with

\[
s_2(n_j)\le n_j^{\alpha+\epsilon}.
\]

But Q17 requires an **eventual all-scales** bound for some `q=2+delta>2`,

\[
s_q(m)\le m^{\alpha+o(1)}
\qquad\text{for every sufficiently large }m.
\]

Nothing tried so far propagates information from an arbitrarily sparse liminf subsequence to all later scales. The missing proof must therefore contain a genuine **good-scale propagation / regular-variation mechanism** tied to FPP geometry.

A useful successful mechanism would have to do both of the following, or replace them by one stronger statement:

1. **cross-scale regularity:** an inequality on standard deviations, variances, or the noise-spectral scale that forbids polynomial oscillation between nearby/macroscopic scales (for example a quasi-multiplicative scale comparison strong enough to force a single logarithmic exponent); and
2. **moment stability:** a source-valid estimate showing `s_q(n)/s_2(n)=n^{o(1)}` for at least one fixed `q>2`.

The central point is that neither item alone is enough. This is the ingredient absent from all six previous routes.
