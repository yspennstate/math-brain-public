## 3. Method #1 — change category: convex aggregation becomes number partitioning

The first new class is arbitrary-dimensional and has no dominance assumption.

### Theorem R12-D0011-C03 — arbitrary weighted symmetric two-point margins always have a least aggregate

Let

\[
F_i=\tfrac12\delta_{a_i}+\tfrac12\delta_{b_i},\qquad a_i<b_i,
\qquad i=1,\ldots,n,
\]

with arbitrary `n>=1`, arbitrary atom locations, and arbitrary positive gaps

\[
w_i=b_i-a_i>0.
\]

Then the aggregation set contains a convex-order smallest element.

Put

\[
A=\sum_i a_i,\qquad W=\sum_i w_i,\qquad m=A+\frac W2,
\]

and define the partition discrepancy

\[
\boxed{
\delta(w)=\min_{I\subseteq[n]}
\left|A+\sum_{i\in I}w_i-m\right|
=\frac12\min_{\varepsilon_i\in\{\pm1\}}
\left|\sum_i\varepsilon_iw_i\right|.
}
\tag{3.1}
\]

Choose a subset `I_*` attaining the minimum. Let the binary vector `B` equal `1_{I_*}` with probability `1/2` and its coordinatewise complement with probability `1/2`. Every coordinate is therefore fair Bernoulli, so this is an admissible coupling of the prescribed margins. Its sum satisfies

\[
\boxed{S_*=m-\delta(w)\text{ or }m+\delta(w),\quad\text{each with probability }1/2.}
\tag{3.2}
\]

If `delta=0`, this is the constant `m` and is trivially convex-order smallest. If `delta>0`, the following elementary gap lemma proves optimality.

### Gap lemma

If `X` has mean `m` and

\[
|X-m|\ge d>0\quad\text{a.s.},
\]

then the fair two-point variable `Y` on `{m-d,m+d}` satisfies

\[
Y\le_{cx}X.
\]

**Proof.** For any convex `phi`, let `ell` be the affine secant through

`(m-d,phi(m-d))` and `(m+d,phi(m+d))`.

By monotonicity of secant slopes for a convex function,

\[
\phi(x)\ge\ell(x)
\quad\text{for }x\le m-d\text{ or }x\ge m+d.
\]

Hence

\[
E\phi(X)\ge E\ell(X)=\ell(EX)=\ell(m)
=\frac{\phi(m-d)+\phi(m+d)}2=E\phi(Y).
\]

This holds for every convex `phi`. `square`

### Completion of Theorem C03

Every admissible aggregate `S` takes values in the fixed subset-sum spectrum

\[
\Lambda=A+\left\{\sum_{i\in I}w_i:I\subseteq[n]\right\}.
\]

All admissible aggregates have mean `m`, and by definition of `delta(w)`, every `s in Lambda` satisfies `|s-m|>=delta(w)`. The gap lemma therefore gives

\[
\boxed{S_*\le_{cx}S\quad\text{for every admissible coupling }S.}
\]

Thus a least aggregate always exists. Its **aggregate law is unique**: if another aggregate law were least, it would be below `S_*`, while `S_*` is below it, forcing equality in distribution.

There is also an exact joint-mixability criterion inside this class:

\[
\boxed{
\text{a constant aggregate exists}
\iff \delta(w)=0
\iff \exists\varepsilon\in\{\pm1\}^n:
\sum_i\varepsilon_iw_i=0.
}
\tag{3.3}
\]

So the convex-order problem for fair two-point margins compiles exactly to the number-partitioning discrepancy, even when no exact partition exists.

This is strictly beyond the unweighted symmetric-Bernoulli result found in the current literature: all atom gaps here may be different and no dominance relation is imposed.

## 4. Method #22 — read the failure and force it inside genuinely two-point margins

The source's standard no-smallest example uses three-point margins. I looked for the same incompatibility mechanism using only Bernoulli/two-point margins and found a completely exact parametric family.

### Theorem R12-D0011-C04 — an infinite five-Bernoulli family with an exact existence iff

Let

\[
S=5B_1+8B_2+4B_3+7B_4+6B_5,
\]

where the Bernoulli marginals are

\[
\boxed{
(p_1,p_2,p_3,p_4,p_5)
=\left(r,\frac45,\frac7{10},\frac3{10},\frac12\right),
\qquad 0\le r\le\frac15.
}
\tag{4.1}
\]

Then the aggregation set contains a convex-order smallest element **if and only if**

\[
\boxed{r=0.}
\tag{4.2}
\]

Thus every `0<r<=1/5` gives a source-valid no-smallest example with **only two-point margins**.

### 4.1 Two exact stop-loss dual certificates

For every binary vector `b in {0,1}^5`, exact enumeration verifies the pointwise inequalities

\[
(S(b)-15)_+
\ge -7+b_1+4b_2+3b_3+3b_4+3b_5,
\tag{4.3}
\]

and

\[
(S(b)-17)_+
\ge -3+2b_2+b_3+b_4+b_5.
\tag{4.4}
\]

Therefore every admissible coupling satisfies

\[
E(S-15)_+\ge \frac7{10}+r,
\qquad
E(S-17)_+\ge \frac1{10}.
\tag{4.5}
\]

Both bounds are sharp for every `0<=r<=1/5`.

Define states

\[
\begin{aligned}
A&=00111,&B&=01001,&C&=01010,\\
D&=01100,&E&=01101,&F&=10101,&G&=11100.
\end{aligned}
\]

For the threshold `15`, the coupling supported on `(A,B,C,D,E,F)` with masses

\[
\left(\frac15-r,\frac15-r,\frac1{10}+r,
\frac25-r,\frac1{10}+r,r\right)
\tag{4.6}
\]

has exactly the margins (4.1) and attains `7/10+r`.

For the threshold `17`, the coupling supported on `(A,B,C,D,E,G)` with masses

\[
\left(\frac15,\frac15,\frac1{10},
\frac25-r,\frac1{10},r\right)
\tag{4.7}
\]

has the same margins and attains `1/10`.

All displayed masses are nonnegative on the full interval `0<=r<=1/5`.

### 4.2 Why the two minima cannot be glued when r>0

The exact tight set of (4.3) is

\[
\{A,B,C,D,E,F\},
\]

whereas the exact tight set of (4.4) is

\[
\{A,B,C,D,E,G\}.
\]

Their intersection is exactly

\[
\boxed{\{A,B,C,D,E\},}
\tag{4.8}
\]

and every state in (4.8) has `b_1=0`.

Suppose a convex-order least aggregate existed for some `r>0`. It would have to minimize **both** convex stop-loss functions `(x-15)_+` and `(x-17)_+`. Since (4.3) and (4.4) are pointwise inequalities with nonnegative slack and their lower bounds are attained, any optimizer of each objective must be supported on that objective's tight set. A simultaneous optimizer would therefore be supported on (4.8), forcing

\[
P(B_1=1)=0,
\]

contrary to `p_1=r>0`. Hence no least element exists for every `r in (0,1/5]`.

This is exactly the source's incompatible-hinge mechanism, but compressed into five Bernoulli margins with rational weights and an infinite parameter interval.

### 4.3 Existence at r=0

When `r=0`, `B_1` is deterministic and can be deleted. For weights `(8,4,7,6)` and probabilities `(4/5,7/10,3/10,1/2)`, define the coupling

\[
\begin{array}{c|ccccc}
(b_2,b_3,b_4,b_5)&0111&1001&1010&1100&1101\\ \hline
q_*&1/5&1/5&1/10&2/5&1/10.
\end{array}
\tag{4.9}
\]

Its aggregate has support contained in `[12,18]`. Every competitor has the same mean. For thresholds `t<=12`,

\[
E(S-t)_+\ge E(S-t)=ES-t=E(S_*-t)_+,
\]

and for `t>=18`, `E(S_*-t)_+=0`.

The only nontrivial subset-sum breakpoints between them are `13,14,15,17`. Exact pointwise affine minorants at these four thresholds are

\[
\begin{array}{c|l}
13&-11+7b_2+4b_3+6b_4+5b_5,\\
14&-10+6b_2+4b_3+5b_4+4b_5,\\
15&-7+4b_2+3b_3+3b_4+3b_5,\\
17&-3+2b_2+b_3+b_4+b_5.
\end{array}
\tag{4.10}
\]

The coupling (4.9) attains all four dual lower bounds. Since every stop-loss transform is linear between consecutive points of the common finite subset-sum spectrum, (4.9) minimizes `E(S-t)_+` for **every real t**. Equal means plus the stop-loss criterion gives

\[
S_*\le_{cx}S
\]

for every competitor. Hence a least aggregate exists at `r=0`, completing the iff proof (4.2).
