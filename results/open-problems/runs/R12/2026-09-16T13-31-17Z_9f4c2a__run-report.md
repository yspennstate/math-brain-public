## 3. Exact Kunisky--Yu normalization and dual

Write

    J = K_{<=2}(G) = {empty} union V(G) union E(G),

and for each clique U of size at most 4 let y_U be its squarefree pseudomoment, with y_empty=1. Kunisky--Yu's compressed degree-four moment matrix is indexed by J and has

    M(y)_{S,T} = y_{S union T}

when S union T is a clique, with all non-clique unions forced to zero. The primal is

    U4(G) = SOS4(G)
          = max sum_i y_{ {i} }
            subject to M(y) >= 0, y_empty=1.

This is exactly their equations (8), (10), and (13) after moment-matrix compression.

For each clique U, |U|<=4, define the union-incidence matrix A_U on J by

    (A_U)_{S,T} = 1_{S union T = U}.

Then

    M(y) = A_empty + sum_{U != empty} y_U A_U.

A conic dual in the same normalization is

    minimize Z_{empty,empty}
    subject to Z >= 0,
               <A_{ {i} }, Z> = -1             for all vertices i,
               <A_U, Z> = 0                    for all clique U, 2<=|U|<=4.

Indeed, for every primal-feasible y and dual-feasible Z,

    0 <= <Z,M(y)>
       = Z_{empty,empty} - sum_i y_i.

So every such Z is an upper-bound certificate for U4(G). The sign and factor normalization in the singleton constraint are important: because A_{ {i} } has the entries (empty,i),(i,empty),(i,i), it reads

    2 Z_{empty,i} + Z_{i,i} = -1.

The compressed primal satisfies Slater: choose an actual probability distribution placing positive mass on every clique state of size <=2. The evaluation functions indexed by J are linearly independent on those clique states (triangular under inclusion), so their Gram moment matrix is positive definite. Thus the usual finite-dimensional SDP strong-duality conclusion is available, although only weak duality is needed for the explicit certificates below.

## 4. R12-C01 — exact square-root primal/dual baseline

**Status: PROVED / BASELINE RECOVERY.**  No literature-novelty claim is made.

For the Paley graph G_p, p≡1 mod 4 prime, put r=sqrt(p), let A be its adjacency matrix, and Abar=J-I-A the complement adjacency matrix. Paley strong regularity gives degree d=(p-1)/2 and nontrivial adjacency eigenvalues (-1±r)/2.

The degree-two primal has the symmetric feasible point

    y_i = 1/r,
    Y = (1/r) I + 2/[r(1+r)] A.

The Schur complement on the all-ones direction and the two nontrivial Paley eigenspaces has eigenvalues

    0, 0, 2/(1+r),

so the moment matrix is PSD and its objective is p/r=r.

For the degree-four dual, use only the `empty + vertex` block and set every edge-indexed row and column to zero:

    Z_00 = r,
    Z_0i = Z_i0 = -1,
    Z_ii = 1,
    Z_ij = 0                         if {i,j} is a Paley edge,
    Z_ij = 2/(1+r)                  if {i,j} is a nonedge.

The bottom vertex block is

    B = I + 2/(1+r) Abar.

Its eigenvalues are

    r                  on 1,
    0                  on one Paley nontrivial eigenspace,
    2r/(1+r)           on the other.

The cross vector -1 lies in the all-ones eigenspace, and the Schur complement is exactly

    r - p/r = 0.

Hence Z is PSD. The singleton union constraint is `-2+1=-1`; for an edge union U={i,j}, all edge-indexed rows/columns are zero and the only surviving terms are 2Z_ij=0. All size-3 and size-4 union constraints vanish automatically. Therefore

    U4(p) <= sqrt(p)

for every admissible prime p.

The frozen metric is now rigorously instantiated as

    a = 1/2, C = 1, p0 = 5.

This is not progress beyond the literature exponent; it is the first exact metric baseline recovered under the revised R12 contract. Kunisky--Yu's lower bound Omega(p^(1/3)) is retained as the barrier: no universal upper exponent below 1/3 is possible.

## 5. R12-X01 — vertex-only degree-four duals cannot break sqrt(p)

**Status: PROVED ROUTE OBSTRUCTION.**

Consider the family of degree-four dual certificates whose rows and columns indexed by edges are identically zero. In this family the only nontrivial constraints are exactly the degree-two dual constraints on the `empty+V` block. Thus the restricted dual optimum is the degree-two optimum

    SOS2(G_p) = theta(overline{G_p}) = sqrt(p).

The previous explicit primal/dual pair certifies equality. Therefore any successful degree-four certificate must use genuinely nonzero edge-indexed dual blocks. A vertex-only spectral ansatz, no matter how it is tuned inside that restricted support, cannot improve the exponent 1/2.

This was the first certificate-family counterexample check required by the first-run protocol.

## 6. R12-X02 — exact K3 counterexample to edge-conditioning a degree-four pseudoexpectation

**Status: PROVED COUNTEREXAMPLE TO A PROPOSED TRANSFER LEMMA.**

A tempting route is: condition a degree-four clique pseudoexpectation on a 2-clique/edge, then regard the conditional object as a degree-two pseudoexpectation on the common neighborhood. This is false in general.

Take G=K3 and a permutation-symmetric squarefree moment sequence

    y_empty = 1,
    y_i = 1/2,
    y_ij = 1/5,
    y_123 = -1/100.

Index the degree-four moment matrix by

    empty, 1,2,3,12,13,23

with M_{S,T}=y_{S union T}. Its exact leading principal minors in that order are

    1,
    1/4,
    3/50,
    27/2000,
    297/500000,
    1701/80000000,
    321489/1000000000000.

They are all strictly positive. By Sylvester's criterion M is positive definite, and because K3 has no nonedge constraints, this is a valid degree-four clique pseudoexpectation.

Now condition formally on the edge {1,2}. The candidate degree-two moment matrix on x_3 is

    (1/y_12) [[y_12,y_123],[y_123,y_123]],

whose x_3 diagonal is

    y_123/y_12 = -1/20.

It is not PSD. Therefore edge-conditioning is invalid at degree four.

The exact reason is degree accounting. Vertex conditioning works because for a linear q,

    E~[x_v q^2] = E~[(x_v q)^2],

which has degree at most 4. Edge conditioning would require controlling E~[x_e q^2] with x_e=x_ix_j; rewriting it as a square would need degree 6. This obstruction is exact, not numerical.

The archived exact checker verifies the full 7x7 positive-definiteness certificate and the negative normalized conditional diagonal.

## 7. R12-C02 — valid vertex-localization compiler

**Status: PROVED.**  This is a general graph lemma proved in this run; no claim of literature novelty is made.

For every finite graph G,

    SOS4(G) <= 1 + max_{v in V(G)} SOS2(G[N(v)])
             = 1 + max_v theta(overline{G[N(v)]}).

### Proof

Let E~ be any feasible degree-four clique pseudoexpectation. Put

    y_v = E~ x_v,
    y_uv = E~ x_u x_v,
    T = sum_v y_v,
    s_v = sum_{u in N(v)} y_uv.

If y_v>0, define on degree-at-most-two polynomials in the neighbor variables

    E_v[f] = E~[x_v f]/y_v.

For every linear q in variables from N(v),

    E_v[q^2]
      = E~[x_v q^2]/y_v
      = E~[(x_v q)^2]/y_v >= 0,

using x_v^2=x_v and degree at most four. Normalization and the Boolean/nonedge relations are inherited. Thus E_v is a feasible degree-two clique pseudoexpectation on G[N(v)], with objective s_v/y_v. Therefore

    s_v <= theta(overline{G[N(v)]}) y_v.

If y_v=0, PSD of the global moment matrix forces the row/column indexed by {v} to vanish, so s_v=0 and the same inequality holds.

Let

    Theta = max_v theta(overline{G[N(v)]}).

Summing gives

    2 sum_{uv in E} y_uv = sum_v s_v <= Theta T.

The principal `empty+V` block of the global moment matrix is PSD. Its Schur/Cauchy inequality against the all-ones vector gives

    T^2 <= 1^T Y 1
        = T + 2 sum_{uv in E} y_uv
        <= T(1+Theta).

For T>0, divide by T to obtain T<=1+Theta; T=0 is trivial. Taking the supremum over feasible E~ proves the claim. QED.

For Paley vertex transitivity,

    U4(p) <= 1 + theta(overline{G_{p,1}}),

where G_{p,1} is the one-localization/neighborhood graph appearing in Randomstrasse Conjecture 26.

## 8. R12-X03 — scalar one-localization information is structurally too weak

**Status: PROVED ROUTE OBSTRUCTION using a published lower bound.**

The previous lemma alone cannot establish Conjecture 28. Wang--Shen--Kobzar Theorem 3.3 gives, at hierarchy level t=1 and localization degree a=1,

    L1(G_{p,1}) = SOS2(G_{p,1}) = theta(overline{G_{p,1}})
               >= (1/2) sqrt(p) + O(1).

Thus the scalar upper bound supplied by C02,

    B_p = 1 + theta(overline{G_{p,1}}),

is itself Omega(sqrt(p)). This does **not** prove U4(p)=Omega(sqrt(p)); it proves only that a route which compresses every vertex-conditioned degree-two pseudoexpectation to its scalar objective loses too much information to prove a polynomial improvement.

In particular, importing R20's eventual answer to Conjecture 26, even if theta(overline{G_{p,1}}) ~ sqrt(p/2), would improve only the constant in this scalar compiler and not the exponent. R12 therefore does not duplicate R20's localization computation.

## 9. R12-C03 — affine symmetrization isolates the missing compatibility information

**Status: PROVED REDUCTION.**

Average any degree-four Paley pseudoexpectation over the affine automorphisms

    x -> a x + b,

where a is a nonzero quadratic residue. Convexity preserves feasibility and the objective. Hence, without loss for the optimum, all singleton moments equal a common alpha and all edge moments equal a common beta.

Let d=(p-1)/2. For every vertex v with alpha>0, the valid conditioned degree-two pseudoexpectation from C02 has local objective

    L = d beta / alpha.

The global `empty+V` PSD inequality becomes

    (p alpha)^2 <= p alpha + p d beta,

or, writing T=p alpha,

    T <= 1 + L.

Thus a square-root-sized degree-four objective necessarily produces square-root-sized vertex-conditioned theta pseudoexpectations. But they are not arbitrary local theta witnesses: they must be **simultaneously compatible** because they come from one global degree-four moment matrix.

For every Paley triangle {u,v,w}, the pair moment of u,w inside the v-conditioned pseudoexpectation is exactly

    y_{uvw}/alpha,

and the analogous conditionings at u and w use the same global triangle moment. At the next level, edge-edge entries are coupled by shared 4-clique moments. The entire edge-indexed PSD block imposes additional global compatibility absent from the scalar theta values.

This identifies the next source-matching target:

> bound the objective of a simultaneously compatible affine family of local theta pseudoexpectations, using triangle/4-clique consistency plus the global edge-edge PSD block.

A polynomial improvement must exploit this compatibility (or an equivalent genuinely degree-four structure); C01/X03 show that vertex-only and scalarized-localization arguments cannot do it.

## 13. Next attack

The next attack should stay inside the exact degree-four SDP and exploit the compatibility discarded by C02.

First decompose the affine-invariant edge-indexed block under the stabilizer of a vertex/edge. The Paley affine group makes singleton and edge moments scalar, but triangle moments split into finitely described multiplicative-character orbits. The goal is to write the PSD constraints in those orbit coordinates and search for a dual multiplier that penalizes a high local objective **simultaneously across all vertices**. This is the natural place for character-sum estimates: unlike the dead vertex-only certificate, the edge-edge block contains triangle and 4-clique incidence matrices whose nontrivial spectra may exhibit cancellation.

Before any asymptotic claim, the first finite task in the next run should be an exact symmetry-reduced SDP/certificate for small admissible primes (e.g. p=5,13,17), compared against the full compressed degree-four formulation. Any proposed analytic dual family must be exactly checked there and rejected immediately if it violates a union constraint or PSD.

A second route, if the orbit dual collapses back to sqrt(p), is to prove a no-go theorem for all duals lying in the adjacency algebra generated by the empty/vertex/edge Paley association matrices. Such a theorem would sharply locate the need for higher character-orbit information.
