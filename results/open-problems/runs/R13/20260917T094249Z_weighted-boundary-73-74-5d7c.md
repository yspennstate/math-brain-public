The arbitrary ambient-dimension statement is rewritten as the exact finite witness-cover dual already used in the `n=4` theorem, but now with a **weighted coordinate-energy budget** instead of the symmetric bound `E_j<=1/3`.

For an oriented witness block `B` and diagonal
\[
\Lambda=\operatorname{diag}(\lambda_1,\ldots,\lambda_4),
\qquad \lambda_j>0,\quad\sum_j\lambda_j=1,

\[
v_U=\sum_{s\in U}t_s,

\[
L_B(\lambda)=

\[
r_B^T\Lambda r_B\ge L_B(\lambda).
\tag{3.4}

Thus the finite task is to choose a diagonal dual weight for each oriented witness pattern that overwhelms its particular weighted energy budget.

## 4. Weighted four-vector certificate

Let `u_1,...,u_4` be arbitrary real vectors in any common Euclidean space and suppose
\[
\|u_j\|_2^2\le C_j.
\tag{4.1}
\]
There are eight Boolean sign classes modulo global negation. Represent them initially by
\[
\mathcal S=\{(1,x_2,x_3,x_4):x_i\in\{\pm1\}\}.
\]

Assume, toward contradiction, that every sign class has discrepancy strictly larger than `sqrt(T)`. For each class choose one coordinate row witnessing this, orient the class so that its row dot-product is positive, group classes choosing the same row into a set-partition block, and divide each distinct selected row by `sqrt(T)`. For every block `B` this gives a row `r_B` satisfying
\[
r_B\cdot t_s>1\qquad(s\in B).
\tag{4.2}
\]
Let
\[
E_j=\sum_B r_{B,j}^2.
\]
Because the selected rows are a subset of all coordinate rows of the four vectors,
\[
E_j\le\frac{C_j}{T}.
\tag{4.3}
\]
There are finitely many strict constraints. Multiply every selected row by one common `eta<1`, sufficiently close to one, so that all constraints become non-strict `>=1` while simultaneously
\[
E_j<\frac{C_j}{T}
\tag{4.4}
\]
for all `j`.

For any diagonal weight `lambda`, summing (3.4) over the blocks gives
\[
\sum_{j=1}^4\lambda_j E_j
=\sum_Br_B^T\Lambda r_B
\ge\sum_B L_B(\lambda).
\tag{4.5}
\]
Therefore the witness pattern is impossible whenever one can find a positive `lambda` with sum one such that
\[
\sum_B L_B(\lambda)
\ge
\frac{\sum_j\lambda_j C_j}{T}.
\tag{4.6}
\]

The finite universe is exactly the same as in the earlier arbitrary-row `K_4^*=sqrt(3)` proof: `4140` set partitions and `75,905` genuine oriented partition configurations. The exact checkers search the same `455` positive rational diagonal weights
\[
\lambda_j=a_j/16,
\qquad a_j\in\mathbb Z_{>0},
\qquad a_1+\cdots+a_4=16.
\tag{4.7}
\]
For every one of the `75,905` oriented configurations, each checker either detects a zero-sum infeasible block or finds a weight satisfying (4.6) by exact rational arithmetic.
