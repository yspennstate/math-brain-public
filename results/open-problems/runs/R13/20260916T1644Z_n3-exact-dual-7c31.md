## 4. Method #30: localize to the four sign classes at n=3

For three columns, signs are relevant only modulo global negation. Use the four tetrahedral representatives

\[
s_1=(1,1,1),\quad s_2=(1,-1,-1),\quad
s_3=(-1,1,-1),\quad s_4=(-1,-1,1).
\]

Write each row of an arbitrary `m x 3` matrix as `r_i in R^3`. If every signing has discrepancy larger than a proposed threshold `K`, each tetrahedral sign class `s_k` has a witness row with

\[
|\langle r_i,s_k\rangle|>K.
\]

Choose one witness per sign class and group sign classes which chose the same row. This produces a partition of `{1,2,3,4}` into witness blocks. After dividing the selected rows by `K` and orienting each constraint, every block vector `r` satisfies

\[
\sigma_k\langle r,s_k\rangle>1
\qquad(k\text{ in that block}).
\]

Thus the arbitrary-row problem has become a finite tetrahedral covering problem.

## 5. Method #11: dualize the tetrahedral covering problem

Let a finite collection of witness rows, one per block, satisfy the non-strict normalized constraints

\[
\sigma_k\langle r^{(B)},s_k\rangle\ge1.
\]

Set the coordinate energy totals

\[
E_j=\sum_B (r^{(B)}_j)^2,
\qquad T=\max(E_1,E_2,E_3).
\]

I prove the exact cover lemma

\[
\boxed{T\ge t_*:=\frac{13-2\sqrt{22}}9.}
\tag{5.1}
\]

There are only four block-size patterns to consider after one elementary reduction.

### 5.1 Any block of size at least three, or a same-oriented pair

Any two distinct tetrahedral vertices agree in exactly one coordinate and differ in the other two, so

\[
s_k+s_\ell=\pm2e_j
\]

for a suitable coordinate `j`. In a block of size at least three, two constraints have the same orientation by pigeonhole. The same is true by assumption for a same-oriented 2-block. Adding those two inequalities gives

\[
|r_j|\ge1,
\]

hence `T>=1>t_*`.

Therefore every potentially extremal 2-block has **opposite** orientations and every block has size at most two.

### 5.2 Four singleton blocks

For a singleton witness,

\[
1\le |\langle r,s_k\rangle|
\le \sqrt3\,\|r\|_2,
\]

so `||r||_2^2>=1/3`. Four singleton witnesses therefore give

\[
E_1+E_2+E_3\ge\frac43,
\]

and hence

\[
T\ge\frac49>t_*.
\]

### 5.3 Two opposite-oriented pair blocks

For a pair `s_k,s_l`, opposite orientations imply

\[
\langle r,s_k-s_l\rangle\ge2.
\]

The difference has exactly two nonzero coordinates, each equal to `+/-2`, so for the corresponding coordinates `p,q`,

\[
(\pm r_p\pm r_q)\ge1,
\qquad
r_p^2+r_q^2\ge\frac12.
\]

The complementary tetrahedral pair differs in the **same** two coordinates. Thus the two witness rows satisfy

\[
E_p+E_q\ge1,
\]

and `T>=1/2>t_*`.

### 5.4 The critical `2+1+1` partition

By signed coordinate permutation symmetry, assume the pair is `{s_3,s_4}` with opposite orientations, and orient the singleton rows separately. Write the singleton witnesses as `u,v` and the pair witness as `w`. The constraints imply

\[
\langle u,s_1\rangle\ge1,
\qquad
\langle v,s_2\rangle\ge1,
\qquad
w_2-w_3\ge1.
\tag{5.2}
\]

Choose the positive coordinate weights

\[
\lambda=\frac{4\sqrt{22}-11}{33},
\qquad
\mu=\frac{1-\lambda}{2},
\qquad
\lambda+2\mu=1.
\]

Let `Lambda=diag(lambda,mu,mu)`. Weighted Cauchy applied to the first two inequalities of (5.2) gives

\[
u^T\Lambda u,\ v^T\Lambda v
\ge
\frac1{1/\lambda+2/\mu}
=\frac1{1/\lambda+4/(1-\lambda)}.
\]

Applied to `w_2-w_3>=1`, it gives

\[
w^T\Lambda w\ge\frac1{2/\mu}=\frac{1-\lambda}{4}.
\]

Therefore

\[
T\ge
\lambda E_1+\mu E_2+\mu E_3
\ge
\frac{2}{1/\lambda+4/(1-\lambda)}
+\frac{1-\lambda}{4}.
\]

For the displayed algebraic `lambda`, exact simplification gives

\[
\frac{2}{1/\lambda+4/(1-\lambda)}
+\frac{1-\lambda}{4}
=
\frac{13-2\sqrt{22}}9=t_*.
\]

This proves (5.1). The exact checker also enumerates all 15 set partitions and all orientations; every non-easy configuration falls into exactly the three residual types above.

## 6. Upper bound for arbitrary m

Put

\[
K_*:=\frac1{\sqrt{t_*}}
=\frac{\sqrt{11}+\sqrt2}{3}.
\]

Suppose, for contradiction, that an admissible arbitrary-row `m x 3` matrix `A` satisfies

\[
\|As_k\|_\infty>K_*
\qquad(k=1,2,3,4).
\]

Choose one strict witness row for each `s_k`, group repeated witnesses into blocks, and divide each selected witness row by `K_*`. Since each original column has squared norm at most one, the selected scaled rows have

\[
T\le\frac1{K_*^2}=t_*.
\]

Every assigned witness inequality is strict. Because there are finitely many assigned inequalities, all selected rows may be multiplied by one common factor `eta<1`, sufficiently close to one, while leaving all normalized witness inequalities at least one. Their three coordinate energy totals then all become at most `eta^2 t_*<t_*`, contradicting the cover lemma.

Hence some tetrahedral sign class, and therefore some Boolean signing, satisfies

\[
\boxed{\|A\varepsilon\|_\infty\le K_*}
\]

for **every** ambient row dimension `m`.

\tag{7.1}

The exact identities

\qquad
2a^2=t_*,

\[
\min_{\varepsilon\in\{\pm1\}^3}\|A_*\varepsilon\|_\infty=K_*.

Combined with the arbitrary-row upper bound, this proves `R13-C06` exactly.
