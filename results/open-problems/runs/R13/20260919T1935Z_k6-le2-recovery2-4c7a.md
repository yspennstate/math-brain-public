## 4. Method #18 — arbitrary bad rows as monotone threshold downsets

Assume for contradiction that an arbitrary real `m x 6` matrix `A`, with every column having Euclidean norm at most one, has

\[
\|A\varepsilon\|_\infty>2
\qquad\text{for every }\varepsilon\in\{\pm1\}^6.
\tag{4.1}
\]

Scale every row by `1/2`; write the resulting rows as `r_i`. Then for every coordinate `j`,

\[
\sum_i r_{ij}^2\le\frac14,
\tag{4.2}
\]

and hence

\[
\sum_i\|r_i\|_2^2\le\frac64=\frac32.
\tag{4.3}
\]

Also every entry satisfies `|r_{ij}|<=1/2`.

Fix one row `r`. Absorb its coordinate signs and write

\[
a_j=|r_j|\in[0,1/2].
\]

For `T subset [6]`, let `s_T` be `-1` on `T` and `+1` off `T`, and define the positively oriented bad family

\[
\mathcal F(a)=\{T\subset[6]:a\cdot s_T>1\}.
\tag{4.4}
\]

Because `a_j>=0`, `F(a)` is a downset. Since `a dot s_{T^c}=-a dot s_T`, at most one member of each complementary pair belongs to `F(a)`. Consequently

\[
b(a):=|\mathcal F(a)|
\]

is exactly the number of antipodal/projective Boolean sign classes on which this row is bad.

If `T,U in F(a)`, then

\[
2<a\cdot(s_T+s_U)
=2\sum_{j\notin T\cup U}a_j-2\sum_{j\in T\cap U}a_j
\le 2\sum_{j\notin T\cup U}a_j
\le 6-|T\cup U|.
\]

Therefore

\[
\boxed{|T\cup U|\le3\qquad(T,U\in\mathcal F(a)).}
\tag{4.5}
\]

So the arbitrary continuous row has been transferred into a finite category: a downset on six coordinates whose maximal members have pairwise union size at most three.
