## #27 SWAP THE QUANTIFIERS: arbitrary rows -> eight witness classes

Modulo global negation, four Boolean coordinates have eight sign classes. Represent them by

\[
\mathcal S=\{(1,x_2,x_3,x_4):x_i\in\{\pm1\}\}.
\]

Assume an admissible arbitrary-row matrix `A` satisfies

\[
\|As\|_\infty>\sqrt3\qquad(s\in\mathcal S).\tag{1}
\]

For every sign class choose one row witnessing (1). Classes selecting the same row form a block of a set partition `P` of the eight classes. Divide each distinct selected row by `sqrt(3)`. Within a block flip representatives if necessary so that

\[
\langle r_B,t_s\rangle>1\qquad(s\in B).\tag{2}
\]

Set

\[
E_j=\sum_{B\in P}r_{B,j}^2,\qquad T=\max_jE_j.
\]

Because selected rows are a subset of the original rows and every original column has squared norm at most one,

\[
T\le1/3.\tag{3}
\]

All inequalities in (2) are strict and finite in number. Multiplying every selected row by one common `eta<1`, sufficiently close to one, preserves them in non-strict form `>=1` and makes `T<1/3`. Therefore it suffices to prove the finite cover lemma:

> For every partition of the eight antipodal sign classes, every orientation choice within each block, and every family of block rows satisfying `r_B dot t_s >= 1`, one has
> \[
> \max_j\sum_Br_{B,j}^2\ge1/3.\tag{4}
> \]

This reduction is exact and removes arbitrary `m`.

## #14 FIND THE GROUP ACTING: block sign symmetry and a diagonal-energy dual

Global reversal inside one block is absorbed by `r_B -> -r_B`, so fix the first orientation of each block. There are `B_8=4140` set partitions and exactly

\[
\sum_{b=1}^8 S(8,b)2^{8-b}=75905\tag{5}
\]

genuine oriented partition configurations.

Choose positive integers

\[
a_1+a_2+a_3+a_4=16,
\qquad \lambda_j=a_j/16,
\qquad \Lambda=\mathrm{diag}(\lambda_1,\ldots,\lambda_4).
\]

There are `C(15,3)=455` such rational weight vectors. For a nonempty subset `U` of one oriented block put

\[
v_U=\sum_{s\in U}t_s.
\]

Summing the block inequalities gives `r_B dot v_U >= |U|`. Weighted Cauchy yields the exact rational bound

\[
r_B^T\Lambda r_B\ge
\frac{|U|^2}{v_U^T\Lambda^{-1}v_U}.\tag{6}
\]

If `v_U=0`, that block is infeasible because the summed constraints would say `0>=|U|`. Define

\[
L_B(\lambda)=\max_{\varnothing\ne U\subseteq B}
\frac{|U|^2}{v_U^T\Lambda^{-1}v_U}.\tag{7}
\]

Since the lambda's sum to one,

\[
T\ge\sum_j\lambda_jE_j
=\sum_Br_B^T\Lambda r_B
\ge\sum_BL_B(\lambda).\tag{8}
\]

Thus an oriented configuration is certified whenever one of the 455 exact rational weight vectors has

\[
\sum_BL_B(\lambda)\ge1/3.\tag{9}
\]

## Sharp lower bound

Let

\[
Q=
\begin{pmatrix}
0&1&-1&-1\\
1&0&-1&1\\
1&-1&0&-1\\
1&1&1&0
\end{pmatrix},
\qquad A_*=Q/\sqrt3.\tag{11}
\]

Every column of `Q` has exactly three nonzero `+/-1` entries, so every column of `A_*` has norm exactly one. For the eight sign classes with first coordinate `+1`, the absolute row-dot vectors of `Q` are

`(1,1,3,1), (1,3,1,1), (1,1,3,1), (3,1,1,1),`

`(3,1,1,1), (1,3,1,1), (1,1,1,3), (1,1,1,3)`.

Hence every Boolean signing has `||Q eps||_infinity=3`, and therefore

\[
\|A_*\varepsilon\|_\infty=\sqrt3
\]

for every signing. Thus `K_4^*>=sqrt(3)`, which with (10) proves R13-C07.
