## 4. R13-C19 — diameter-six convex-mean lemma on the nine-cube

For `T subseteq [9]`, let

\[
s_T\in\{-1,+1\}^9,
\qquad
(s_T)_j=\begin{cases}-1,&j\in T,\\+1,&j\notin T.\end{cases}
\]

### Theorem C19

If `F subseteq 2^[9]` is a nonempty downset of Hamming diameter at most six, then

\[
\boxed{
|F|\,\operatorname{dist}\!\left(0,\operatorname{conv}\{s_T:T\in F\}\right)^2\le192.
}
\tag{4.1}
\]

The constant `192` is sharp for this lemma: a principal six-dimensional subcube has `|F|=64`, and the uniform measure on that cube has sign mean zero in the six active coordinates and `+1` in the other three, hence squared norm `3` and product `64*3=192`.

### 4.1 Downset diameter equals the pairwise-union bound

For a downset,

\[
\operatorname{diam}_H(F)\le6
\quad\Longleftrightarrow\quad
|A\cup B|\le6\quad(A,B\in F).
\tag{4.2}
\]

The reverse implication is immediate from `|A Delta B|<=|A union B|`. For the forward implication, `B\A subseteq B` belongs to `F`, so

\[
|A\cup B|=|A\triangle(B\setminus A)|\le6.
\]

In particular every member has size at most six.

### 4.2 Compression reduces C19 to shifted downsets

If zero belongs to the convex hull, (4.1) is trivial. Otherwise write

\[
d(F)=\operatorname{dist}(0,\operatorname{conv}\{s_T:T\in F\})
=\max_{\|u\|_2=1}\min_{T\in F}u\cdot s_T>0.
\tag{4.3}
\]

An optimizing separator may be chosen coordinatewise nonnegative. If `u_j<0`, then for every `T` containing `j`, downclosure gives `T\setminus{j} in F` and

\[
u\cdot s_{T\setminus\{j\}}=u\cdot s_T+2u_j<u\cdot s_T.
\]

Thus the minimum is already attained among sets omitting `j`. Replacing `u_j` by zero raises that minimum and lowers the norm; after renormalizing, the positive separating margin increases. Hence an optimizer cannot have a negative coordinate.

Permute coordinates so

\[
0\le u_1\le\cdots\le u_9.
\]

Apply the standard left compression `C_{ij}`, `i<j`: if `j in T`, `i notin T`, and `T-j+i` is absent, replace `T` by `T-j+i`. Standard set compression preserves cardinality, heredity/downclosure, and Hamming diameter. Here one can check diameter directly: when one set in a pair is shifted, either the other shifts too, or its shifted mate already occurred in the old family; the new symmetric-difference size is then bounded by an old admissible pair.

Because `u_i<=u_j`, a shifted set has

\[
u(T-j+i)\le u(T),
\]

so

\[
u\cdot s_{T-j+i}
=\sum_k u_k-2u(T-j+i)
\ge\sum_k u_k-2u(T)
=u\cdot s_T.
\]

If the shifted mate already existed, both old points remain. Therefore a compression cannot decrease the separator's minimum. Iterating all left compressions yields a shifted downset `F*` with

\[
|F^*|=|F|,
\qquad
\operatorname{diam}_H(F^*)\le6,
\qquad
d(F^*)\ge d(F).
\tag{4.4}
\]

It is therefore enough to verify (4.1) for shifted downsets.

## 5. Exact finite core: all shifted diameter-six downsets

A shifted downset is an order ideal for two kinds of immediate predecessor operations: deleting an element, and replacing `j` by `i<j` when `i` is absent.

There are exactly

\[
\sum_{k=0}^6\binom9k=466
\]

subsets of `[9]` that can occur under (4.2). The checker orders them first by cardinality, then by the sum of their coordinate indices, then by bit mask. Every deletion and every left-shift predecessor is earlier in this order.

Starting with the forced empty set, the exact recursion does the following for each candidate `S`:

1. branch on excluding `S`;
2. permit inclusion only if every immediate deletion/left-shift predecessor is already present;
3. permit inclusion only if `|A union S|<=6` for every already included `A`.

This is exhaustive: any shifted downset has exactly this predecessor closure, and every forbidden pair is detected when its later member is considered. No floating point is used.

The exact enumeration contains

\[
\boxed{4,677,567}
\]

shifted downsets satisfying (4.2).

## 8. R13-C20 — arbitrary-row nine-column Komlos bound

Let `A` be any real `m x 9` matrix with

\[
\|A_{\cdot j}\|_2\le1
\qquad(j=1,\ldots,9).
\]

Fix one row `r`. Absorb its coordinate signs and write

\[
a_j=|r_j|\in[0,1],
\qquad
S=\|r\|_2^2.
\]

Set

\[
t=\frac{3\sqrt3}{2}.
\tag{8.1}
\]

For `T subseteq[9]` define the positively oriented bad family

\[
F_r=\{T:a\cdot s_T>t\}.
\tag{8.2}
\]

It is a downset. If `T,U in F_r`, then

\[
2t<a\cdot(s_T+s_U).
\]

Coordinates in `T Delta U` cancel, those in `T cap U` contribute nonpositively, and those outside `T union U` contribute at most two each. Hence

\[
2t<a\cdot(s_T+s_U)
\le2(9-|T\cup U|).
\tag{8.3}
\]

Since `t>2`, (8.3) rules out `|T union U|>=7`; therefore `|T union U|<=6`, and C19 applies.

Let `b(r)=|F_r|`. This is exactly the number of antipodal Boolean sign classes spoiled by row `r`: every class with `|r dot epsilon|>t` has exactly one orientation with positive dot product greater than `t`.

If `b(r)>0`, C19 supplies a probability distribution on `F_r` with mean sign vector `c` satisfying

\[
\|c\|_2^2\le\frac{192}{b(r)}.
\]

Every support point satisfies `a dot s_T>t`, so

\[
a\cdot c>t.
\]

Cauchy--Schwarz gives

\[
\frac{27}{4}=t^2
<(a\cdot c)^2
\le S\|c\|_2^2
\le\frac{192S}{b(r)}.
\]

Thus

\[
\boxed{
b(r)<\frac{256}{9}\|r\|_2^2.
}
\tag{8.4}
\]

Rows with `b(r)=0` contribute nothing. If there is at least one bad incidence, summing (8.4) over the positive-incidence rows (and using non-strict zero contributions from the rest) gives

\[
\begin{aligned}
\sum_i b(r_i)
&<\frac{256}{9}\sum_i\|r_i\|_2^2\\
&=\frac{256}{9}\sum_{j=1}^9\|A_{\cdot j}\|_2^2\\
&\le256.
\end{aligned}
\tag{8.5}
\]

If there is no bad incidence, every signing is already good. Otherwise (8.5) is strict. There are exactly

\[
2^{9-1}=256
\]

antipodal Boolean sign classes. Since the total bad-incidence count is an integer `<256`, not every class can be spoiled. Therefore some Boolean signing satisfies every row simultaneously:

\[
\boxed{
\|A\varepsilon\|_\infty\le\frac{3\sqrt3}{2}.
}
\tag{R13-C20}
\]

This is deterministic, arbitrary-row, and fully real Boolean.
