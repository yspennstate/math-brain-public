## 2. What the 2014 proof actually needs

Let `f={v0,w0}` be one added edge and let `P` be a shortest `G`-path from `v0` to `w0`; write `C=P union {f}` for the resulting finite witness cycle. As in Assumption 6.4 of the 2014 proof, it is enough to keep only the `A`-orbit `Af` of this one new edge: strictness for `G+Af` implies strictness for the larger augmentation `G'`.

Define the **finite right-phase property for the witness `C`** to mean that there are finitely many `nu_1,...,nu_s in Gamma` such that

```text
Gamma C  subset  union_{i=1}^s nu_i A C.                      (FP_C)
```

Here `Gamma C={gamma C: gamma in Gamma}` and `nu_i A C={nu_i a C:a in A}` as labelled copies of the witness cycle.

### Lemma 2.1 (finite witness phases suffice)

Under the source hypotheses, `(FP_C)` implies `mu(G)<mu(G')`.

### Proof

Use the 2014 proof of Theorem 3.2 after its Assumption 6.4. Lemmas 6.1--6.3, which create a full-growth family with a positive linear number of occurrences of translated witness cycles, use transitivity of `Gamma`, local finiteness, and the finite witness cycle; they do not use the finite-coset property. The finite-coset property first enters the final proof when the authors split translated copies of `C` into finitely many sets `O_i=nu_i A C` (their equations (6.37) and (6.42)). That is exactly what `(FP_C)` supplies directly.

For completeness, let `R_n` denote the full-growth family in the first branch of their proof, and suppose each `pi in R_n` has at least `a n` witness occurrences. Since `(FP_C)` has `s` phases, at least one phase occurs at least `a n/s` times; taking the union over the finitely many phases and then a subsequence, one fixed `i` carries exponential growth `mu(G)`. For every occurrence in that phase, the witness copy has the form

`gamma_t C = nu_i alpha_t C`,  `alpha_t in A`.

Therefore its new edge is `nu_i alpha_t f`, which is an edge of the single conjugate augmentation `nu_i(G+Af)`. Moreover `nu_i A nu_i^{-1}` acts by automorphisms of this conjugate augmentation. The replacement/surgery counting in the proof of Lemma 6.1 can therefore be performed simultaneously at a positive linear number of well-separated occurrences, exactly as in the published equations following (6.38), yielding the contradiction `mu(G)<mu(nu_i(G+Af))=mu(G+Af)` under the temporary equality assumption. The second branch (their (6.39)--(6.42)) is identical: finite phase pigeonholing is the only additional input. Thus `mu(G)<mu(G+Af)<=mu(G')`.  QED.

This lemma isolates the algebraic issue cleanly: the proof does **not** need global normality as such; it needs finitely many right-`A` phases for one finite witness pattern.

## 3. Method #12 — conserved quantity: the one-sided commensuration index

For `d in Gamma` define

```text
iota_A(d) := [ A : A intersect d A d^{-1} ]  in {1,2,...,infinity}.
```

This is constant on the double coset `A d A`. Indeed, if `d'=a d b` with `a,b in A`, then

`A intersect d' A d'^{-1} = a (A intersect d A d^{-1}) a^{-1}`,

so the index is unchanged. Thus `iota_A` is a genuine phase invariant: multiplying a witness placement on either side by an allowed `A`-move does not change the obstruction.

The key elementary conversion is:

### Lemma 3.1 (left phase to finitely many right phases)

If `iota_A(d)=m<infinity`, then for every finite labelled pattern `C`,

```text
A d C  subset  union_{l=1}^m a_l d A C
```

for suitable `a_1,...,a_m in A`.

### Proof

Let `H=A intersect d A d^{-1}` and write `A=union_l a_l H` in left cosets. If `a=a_l h`, then because `h in d A d^{-1}` there is `b in A` with `h=d b d^{-1}`. Hence

`a d C = a_l h d C = a_l d b C in a_l d A C`.

QED.

This is the exact algebraic move missing from the naive `A d` versus `d A` interchange.

## 4. Method #4 — complete weaker theorem: local commensuration of the finite witness types

The next point uses only quasi-transitivity and local finiteness.

Fix the witness root `v0`. Choose `delta_1,...,delta_r in Gamma` such that the `A`-orbits of vertices are

`V = union_{j=1}^r A delta_j v0`.

Let `K=Stab_Gamma(v0)`. Because `G` is locally finite and `C` is finite, the set of rooted images `{k C:k in K}` is finite: every such image lies in one fixed finite ball about `v0`. Choose `k_1,...,k_t in K` representing these images. Put

`D_C={delta_j k_u: 1<=j<=r, 1<=u<=t}`.

Then every translated witness copy has the form

```text
gamma C = a d C
```

for some `a in A` and `d in D_C`. To see this, choose `j,a` with `gamma v0=a delta_j v0`; then `k=delta_j^{-1}a^{-1}gamma` fixes `v0`, so `kC=k_uC` for some `u`, and `gamma C=a delta_j k_u C`.

Combining this with Lemma 3.1 gives the main partial theorem of this run.

### Theorem 4.1 (finite local commensuration criterion)

In the setting of Grimmett--Li Question 4.10, fix one added-edge witness cycle `C` as above. If

```text
iota_A(d) < infinity   for every d in D_C,                  (LC_C)
```

then

```text
mu(G) < mu(G').
```

### Proof

For each `d in D_C`, Lemma 3.1 covers `A d C` by finitely many sets of the form `nu A C`. Since `D_C` is finite, `Gamma C` is covered by finitely many such right phases, so `(FP_C)` holds. Apply Lemma 2.1. QED.

The hypothesis is deliberately **local**: it asks for finite one-sided commensuration index only for the finitely many double-coset types actually needed to place one witness cycle. It does not ask that `A` be normal, finite-index, or globally commensurated by all of `Gamma`.

### Corollary 4.2 (commensurated-subgroup case)

If `A` is commensurated in `Gamma`, i.e.

```text
[A : A intersect gamma A gamma^{-1}] < infinity
and
[gamma A gamma^{-1} : A intersect gamma A gamma^{-1}] < infinity
```

for every `gamma in Gamma`, then `mu(G)<mu(G')`.

Normal and finite-index subgroups are commensurated, so this recovers the two algebraic mechanisms explicitly listed in source Theorem 4.7. The point is that normality is much stronger than what the surgery proof needs.

### Corollary 4.3 (transitive commensurator)

Let

`Comm_Gamma(A)={gamma in Gamma: A and gamma A gamma^{-1} are commensurable}`.

If `Comm_Gamma(A)` acts transitively on `G`, then `mu(G)<mu(G')`: replace `Gamma` by the transitive subgroup `Comm_Gamma(A)` and apply Corollary 4.2.

This is a clean group-theoretic special case of Question 4.10 distinct in formulation from the source's Question 4.11 stabilizer condition.
