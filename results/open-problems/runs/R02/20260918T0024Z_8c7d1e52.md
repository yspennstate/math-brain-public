### Method #2 — ATTACK THE NEGATION FIRST

I looked for the first structural class beyond the corrected `r_block=5` baseline where a positive edge covariance could occur. The point is not to enumerate arbitrary 10-vertex graphs. Huang's reduction plus one degree count leaves a tiny exact obstruction set.

Let a terminal simple core `H` have `beta(H)<=6` and minimum degree at least 3. Then

`3v/2 <= e = v+beta(H)-1 <= v+5`,

hence `v<=10`.

- If `v=9`, then `e<=14`, again inside their stated 9-vertex / at-most-18-edge verification.

Therefore **the only new terminal cores at `r=6` are connected simple cubic graphs on 10 vertices.** A classical enumeration gives exactly 19 non-isomorphic such graphs. So the negation search reduces to 19 exact finite objects, not blind enumeration.

### Method #24 — FIND THE EXTREMAL OBJECT

The preceding inequality identifies the extremal core automatically: at the boundary `beta=6`, the maximum possible terminal-core order is 10, and equality forces cubicity. This is the sharp finite obstruction to advancing the metric from 5 to 6.

### Method #25 — COUNT THE SAME THING TWICE

For a graph `H`, let

- `Z` = number of forests of `H`,
- `Z_e` = number containing edge `e`,
- `Z_ef` = number containing both distinct edges `e,f`.

Uniform-forest p-NC is exactly the integer Rayleigh inequality

`Z_e Z_f - Z Z_ef >= 0`.

Thus every finite core can be certified with exact integer counting; there is no floating-point or simulation layer.

## 6. The structural theorem obtained this run

**Theorem (R02/P0001, PARTIAL relative to the source).**  
Let `G` be a finite simple graph. Suppose every nontrivial 2-connected block `B` of `G` satisfies

`beta(B)=|E(B)|-|V(B)|+1 <= 6`.

Then the uniform probability measure on forests of `G` has pairwise nonpositive edge correlations.

### Proof

**Step 1: factor over blocks.** Every cycle of a graph is contained in one 2-connected block, and block edge sets are disjoint. Hence an edge subset is acyclic iff its restriction to every block is acyclic. Under the uniform measure, the forest law therefore factors as the product of the uniform forest laws on the blocks (bridge blocks contribute independent fair edge bits). Edge indicators from different blocks have covariance zero. It suffices to treat one nontrivial block.

**Step 2: reduce the block.** Apply Huang Theorem 2.6, iterating when necessary: delete pivotal edges, suppress degree-2 vertices, and simplify parallel edges. Each resulting component has the same or smaller cyclomatic number; suppressing a degree-2 vertex preserves `e-v+1`, while the other operations reduce it. Negative correlation on the original block is equivalent to negative correlation on the final simplified components. Any nontrivial terminal simple component `H` has minimum degree at least 3.

**Step 3: bound the terminal core.** Write `v=|V(H)|`, `e=|E(H)|`. Since `delta(H)>=3`,

`3v/2 <= e`.

Since `beta(H)=e-v+1<=6`,

`e<=v+5`.

Thus `v<=10`.

If `v<=8`, p-NC is among the graphs verified by Grimmett--Winkler. If `v=9`, then `e<=14<=18`, also inside their published verification. If `v=10`, the two inequalities force `e=15`; hence every vertex has degree 3. So `H` is one of the 19 connected simple cubic graphs on 10 vertices. The exact certificate above verifies p-NC for all 19.

Therefore every terminal component is p-NC. Huang's equivalence lifts p-NC back through the simplification to the original block, and the block-product factorization lifts it to `G`. QED.

This moves the fixed metric

**`r_block: 5 -> 6`.**

The source conjecture remains open: arbitrary finite graphs have no bound on block cyclomatic number. This result is therefore **PARTIAL**, not PROVED.
