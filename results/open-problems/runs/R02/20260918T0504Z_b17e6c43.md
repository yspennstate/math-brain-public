## 2. (a) Exact blocking statement

After the three previous D0074 runs, the source-wide residual can be written cleanly as the following missing implication. Fix one added-edge orbit and let `R` be any finite radius large enough to contain its associated local cycle surgery. Let

`lambda_R := limsup_{m -> infinity} b_m(R)^(1/m)`,

where `b_m(R)` is the maximal number of `m`-step base-graph SAWs whose endpoint lies within graph distance `R` of their start.

The unresolved regime is precisely the one not forced by the known finite-coset theorem, the regular-tree theorem, or the previous return-gap criterion:

```text
A\V finite,  A has no known finite-coset reduction,
|Stab_Gamma(v)| = infinity,  [Gamma:A] = infinity,
and lambda_R = mu(G) at every relevant finite surgery radius R

                     ?
                     ==>  mu(G') > mu(G).
```

Equivalently, at the combinatorial level, the missing implication is:

```text
full-growth SAWs have no positive-density family of uniformly bounded
cycle-surgery spans

                     ==>  the resulting macroscopic long-return intervals
                          themselves yield an exponential, bounded-multiplicity
                          family of distinct G'-SAWs.
```

The previous run proves the implication when the long-return pieces have strictly smaller exponential rate (`lambda_R < mu(G)`). It does **not** handle the critical case `lambda_R = mu(G)`, and no current argument converts full-growth long returns into enough independent surgeries.

## 3. (b) Every route tried so far, and the precise point of failure

### Route 1 — use the published finite-coset theorem directly

Solved neighbor: Grimmett--Li's augmentation theorem. The needed finite-coset property gives a finite phase decomposition compatible with the `A`-invariant augmentation. Plain quasi-transitivity only gives finitely many `A`-orbits / double cosets and does not supply the same left-translate phase control. Normality or finite index repairs this. In the genuinely residual infinite-stabilizer / infinite-index case, the elementary conversion fails.

### Route 2 — force finite index from quasi-transitivity

The first D0074 run showed this works when the chosen transitive action has finite vertex stabilizer: finite `A\Gamma/K` with finite `K=Stab_Gamma(v)` implies finite `[Gamma:A]`. Failure is therefore localized to infinite stabilizers. There is no analogous cardinality argument when `K` is infinite.

### Route 3 — attack the residual case on a regular tree

The tree route succeeded rather than failing: first for a free cocompact action and then, in the second run, for arbitrary quasi-transitive `A <= Aut(T_D)`. It cannot simply be ported to a general transitive graph because the key geometric input is unique geodesicity: the intersection of an anchor path with a SAW is connected, so the complementary cycle arc gives a clean local surgery. In a graph with cycles, the anchor path may meet the SAW at several separated time intervals.

### Route 4 — non-backtracking / orbit transfer operator

On trees this yielded a finite-state operator whose closed strongly connected components support full exponential growth, and one oriented edge orbit on the anchor geodesic recurs linearly. On general graphs, orbit coding of local edge types does not remember whether the rest of the finite anchor cycle collides with the SAW far away in SAW time. The missing state is not finite local geometry alone; it includes unbounded temporal collision information.

### Route 5 — local cycle surgery on a general 2-connected transitive base

The previous run assigned to every old edge a bounded actual `A`-cycle in `G'` containing a new edge. This avoids the global `Gamma/A` phase problem locally. If linearly many anchors have uniformly bounded temporal collision span, a conflict-graph extraction gives linearly many compatible surgeries and binomial entropy forces strictness. Failure: a full-growth family may have anchor cycles whose other intersections with the SAW occur arbitrarily far away in SAW time.

### Route 6 — long-return decomposition

Long temporal collision spans imply long subwalks whose endpoints remain within bounded graph distance. A maximal-span greedy decomposition turns these into disjoint long-return intervals. If their exponential growth rate is `lambda_R < mu(G)`, that family is exponentially negligible, so bounded-span anchors must carry full growth. Failure: the source-wide residual may have `lambda_R = mu(G)`. Then the entropy-vs-return count is critical and gives no strict loss.

### Route 7 — fugacity / pressure in the number of new-edge uses

A natural interpolation is the SAW partition function weighted by `t^(# new edges)`. Strictness would follow from positive right pressure at `t=1` or from a positive-density new-edge occupation under a suitable limiting ensemble. Failure: we do not have a canonical infinite-volume SAW Gibbs measure on a general transitive graph that simultaneously preserves the exponential counting rate and controls surgery multiplicity. A flat derivative at the boundary is not excluded by the present arguments.

### Route 8 — Question 4.11 / transitive overgroup repair

The source itself says a suitable transitive overgroup with `Gamma intersect Stab_v <= A` would imply Question 4.10. This is a structural sufficient condition, not a solution of the remaining cases. In the residual situation no argument constructs such an overgroup; the condition effectively reinstates the finite-index/phase mechanism rather than replacing it.

### Route 9 — search for an explicit counterexample in an infinite-stabilizer graph-of-groups model

The natural regular-tree model did not produce a counterexample; it obeys strict augmentation even with arbitrary quasi-transitive actions. No explicit source-valid equality example is currently known to R02. To refute the source one would need an augmentation whose entire new-edge orbit is exponentially invisible to SAWs even though it is quasi-transitive and proper; no finite or symbolic candidate survived the tree test.

## 4. Method #7 — TAKE THE LIMIT: what the limit formulation clarifies, and why it still does not close

The tempting limiting object is a subsequential law of a uniformly chosen long SAW together with its rooted environment, its `A`-orbit phase, and the marked anchor cycles encountered along the walk. If strictness failed, one would want to show that the limiting object sees zero positive-density usable anchors, then derive a contradiction from transitivity/quasi-transitivity.

The obstruction is that **local weak convergence loses time-order information**. A finite anchor cycle can intersect the same long SAW in vertices that are all geometrically close to the anchor but separated by `Theta(n)` units of SAW time. Rooted local convergence sees the bounded ball but not the locations of those vertices in the global ordering of the path. Conversely, a subsequential law of time-indexed paths need not retain the exponential counting entropy `mu(G)` in a way strong enough for a strict pressure comparison.

Thus the useful limiting state space would have to remember, simultaneously:

1. local rooted graph geometry;
2. the bi-infinite (or long finite) linear order induced by the SAW;
3. the `A`-orbit type of every bounded anchor cycle; and
4. enough entropy information to distinguish a full-growth subfamily from an exponentially negligible one.

No canonical compact SAW measure with all four properties is available from the current route. Taking an ordinary local limit therefore reorganizes the obstruction but does not remove it.

## 5. Method #22 — READ THE FAILURES: what the nearest solved proof has that the residual problem lacks

The 2014 proof is the nearest solved problem. Its essential extra resource is a **finite phase space for surgeries**: the finite-coset property lets the proof partition the relevant orbit of a witness cycle into finitely many translates compatible with one common augmentation, then pigeonhole a full-growth family into one phase and apply an entropic replacement argument.

The source review makes the same issue visible in a different form. Theorem 4.7 assumes normality or finite index; Question 4.10 asks to remove it; Question 4.11 asks for a transitive overgroup satisfying a stabilizer condition that would restore the missing uniformity. The preserved intake attempt `D0074-A001` already identified repeated usability of added edges as the barrier. The R02 work sharpened that diagnosis:

- repeated **local presence** of an added-edge orbit is not enough;
- repeated **clean surgery in SAW time** is what matters;
- on a tree clean surgery is automatic from unique geodesicity;
- on a general graph it is automatic only for bounded temporal collision span;
- if long-return intervals are exponentially subdominant, the bad class is negligible;
- exactly at `lambda_R = mu(G)`, neither the finite-phase proof nor the return-gap proof pays for the bad class.

So the missing object is not another local pattern theorem. It is a **critical-return entropy theorem**: either prove that full-growth bounded-distance returns contain enough internal branching to generate new walks after augmentation, or prove that such returns cannot occur at full connective-constant rate in the source class.

## 6. Method #29 — ADD THE POINTS AT INFINITY: boundary attempts and the failure to encode SAW time

The successful tree proof can be interpreted as having a perfect boundary/order structure: two vertices determine a unique geodesic and an anchor cycle cannot weave in and out of the SAW. This suggested compactifying the residual graph by an end boundary, Martin boundary, or another asymptotic boundary.

That helps on multi-ended/tree-like graphs but does not solve the one-ended/subballistic regime. In a one-ended amenable graph the end boundary may be trivial, while random-walk Martin/Furstenberg boundaries encode harmonic escape rather than the combinatorial time order of a self-avoiding path. The source question is about exponential SAW counts, so a random-walk boundary is not automatically the right object.

A more problem-specific compactification is to record each long collision as a chord `[i/n,j/n]` in the time interval `[0,1]`. Along subsequences, collections of such chords have compact limits (as closed subsets / interval laminations after choosing an appropriate topology). This makes the missing dichotomy vivid:

- if a positive density of chords have vanishing span, one returns to bounded-span surgery;
- if positive mass stays at macroscopic span, the limit contains a nontrivial chord structure.

But the second branch is not yet a proof. A dense family of crossing/nested temporal chords may create severe surgery dependencies. What is missing is a deterministic combinatorial theorem saying that every sufficiently large chord family of bounded *graph* diameter but macroscopic *time* span contains either (i) a linearly large compatible surgery subfamily, or (ii) a different structure with an independently countable exponential multiplicity. Without that theorem, compactification only packages the obstruction.

## 7. (c) What a full proof would have to contain that no route so far contains

A successful positive proof now appears to need one of the following genuinely new ingredients.

**Critical-return entropy lemma.** For every fixed `R`, if bounded-distance long returns occur with full SAW exponential rate, extract from them an exponential number of source-distinct, target-valid modifications with inverse multiplicity `exp(o(n))` or at worst `C^k` for `k` selected modifications. This must work without normality, finite index, a height function, ballisticity, or unique geodesics.

**Or: universal return gap.** Prove `lambda_R < mu(G)` for every fixed `R` in every 2-connected transitive graph relevant to Question 4.10. Current SAW theory does not supply this at that generality; proving it would itself be a major statement.

**Or: finite-phase replacement without group normality.** Recover a finite effective surgery phase directly from the pair `(G,A)` even when the original finite-coset property fails. No current double-coset/group-action argument supplies this in the infinite-stabilizer/infinite-index case.

Any route that does not add one of these is currently rearranging the same missing step.

## 9. (e) Nearest solved problem and the ingredient it has

Nearest external solved problem: Grimmett--Li 2014 augmentation theorem / review Theorem 4.7. It proves strictness under the finite-coset mechanism supplied in particular by normal quasi-transitive `A` or finite index. What it has that the residual case lacks is a **finite global phase set that makes a positive-density pattern family simultaneously legal in one augmentation**.

Nearest internal solved subclass: the R02 arbitrary-regular-tree theorem. What it has that a general transitive graph lacks is **unique geodesicity**, which converts local recurrence of one edge orbit into clean, pairwise controllable cycle surgeries without remembering unbounded SAW-time collisions.

Nearest internal partial criterion: the previous run's return-gap condition `lambda_R < mu(G)`. What it has that the remaining case lacks is **strict entropy separation** between long-return pieces and unrestricted SAWs.

Those three comparisons point to the same missing datum: control of long-return temporal dependencies at full exponential growth.
