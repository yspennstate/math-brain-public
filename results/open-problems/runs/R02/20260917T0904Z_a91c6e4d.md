# 5. Method #12 — FIND WHAT IS CONSERVED: an exact parity involution

This run found a simple but global invariant of the folded radius-3 incidence operator. It is recorded as:

\[

\qquad
S=\{x\in G:d_F(x,0)\le3\},
\]

and define the radius-3 convolution/incidence operator

\[
(Tf)(x)=\sum_{s\in S}f(x+s).
\]

Over `F_2`,

\[
\boxed{T^2=I.}
\tag{C008-a}
\]

Consequently, if `c` is the indicator of any set of 12 quotient centers, `g=Tc` is its integer coverage-multiplicity function, and `h=g-1`, then modulo 2

\[
\boxed{Th=\mathbf1+c.}
\tag{C008-b}

In particular, for any genuine cover (`g>=1`), the center set is recovered exactly from the parity pattern of the excess multiplicity:

\[
\boxed{c=\mathbf1+Th\pmod2.}
\tag{C008-c}

This is not a claim that the blocker is solved. It is a new campaign-level global constraint that any exact/SDP/SAT relaxation can retain.

## Proof

The quotient `G` is an elementary abelian 2-group of order `2^11=2048`. A folded radius-3 ball has

\[
|S|=\sum_{j=0}^3\binom{12}{j}=299,
\]

which is odd. In the group algebra `F_2[G]`, put

\[
\sigma=\sum_{s\in S}s.
\]

Because the characteristic is two and every group element satisfies `s^2=e`, the Frobenius identity gives

\[
\sigma^2=\sum_{s\in S}s^2=|S|e=e.
\]

Multiplication by `sigma` is exactly `T`, proving `T^2=I` over `F_2`.

Now reduce the integer identities `g=Tc` and `h=g-1` modulo 2. Since `T1=|S|1=1`,

\[
Th=Tg-T1=T^2c-1=c+1,
\]

which proves (C008-b,c). QED.

The group-algebra/Frobenius mechanism itself is elementary and should be treated as **folklore**, not advertised as a new general theorem. What is new to this campaign is noticing and retaining this exact parity constraint in the `M12` folded-cover blocker. Publication novelty is unverified.
