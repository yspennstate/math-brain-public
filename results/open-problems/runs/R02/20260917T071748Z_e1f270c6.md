## 2. Coding dictionary retained

Encode each sign row `r_i` by a binary word `c_i` and a signing `x` by a binary word `y`. Then

\[
|r_i\cdot x|
=
|n-2d_H(c_i,y)|.
\]

Thus `disc(A)>=d` is equivalent to saying that the antipodal code consisting of the `n` rows and their complements covers the binary cube to radius

\[

\[
V_n(R)=\sum_{j=0}^R\binom nj

quotient points.

## 4. Method #25 — COUNT THE SAME THING TWICE: a rigorous radius-seven sphere horizon

Suppose a sign matrix of order `n` has

\[
\operatorname{disc}(A)\ge n-14.
\]

By the coding dictionary, its `n` folded centers cover the quotient cube to radius seven. Count incidences

\[
(x,c):\quad x\text{ lies in the radius-seven folded ball around }c.
\]

Counting by centers gives exactly

\[
nV_n,
\qquad
V_n=\sum_{j=0}^7\binom nj.
\]

Counting by quotient points, a cover requires at least one incidence at each of `2^{n-1}` points. Hence the necessary condition

\[
\boxed{
nV_n\ge2^{n-1}.
}
\tag{4.1}
\]

At `n=26`, exact arithmetic gives

\[
V_{26}=971712,
\]

so

\[
26V_{26}=25,264,512
<33,554,432=2^{25}.
\]

Thus no order-26 sign matrix can have discrepancy at least `12=n-14`.

The same conclusion holds for **every `n>=26`**, not just `n=26`. Indeed

\[
V_{n+1}=2V_n-\binom n7.
\]

Define

\[
f_n=\frac{nV_n}{2^{n-1}}.
\]

Then

\[
\frac{f_{n+1}}{f_n}
=
\frac{n+1}{n}
\left(1-\frac{\binom n7}{2V_n}\right),
\]

so `f_{n+1}<f_n` is equivalent to

\[
2V_n<(n+1)\binom n7.
\tag{4.2}
\]

For every fixed `j<7`, the ratio

\[
\frac{\binom nj}{\binom n7}
\]

strictly decreases with `n`; hence `V_n/binom(n,7)` decreases. At `n=26`, the exact base inequality is

\[
2V_{26}=1,943,424
<17,760,600
=27\binom{26}{7}.
\]

Therefore (4.2) persists for all `n>=26`, `f_n` is decreasing there, and because `f_{26}<1`, (4.1) fails for every `n>=26`.

So we have the theorem-sized restricted statement

\[
\boxed{
\operatorname{disc}(A)<n-14
\quad\text{for every }A\in\{\pm1\}^{n\times n},\ n\ge26.
}
\tag{C007}
\]

This is a covering-volume consequence and is far weaker than the universal Spencer-scale upper bounds asymptotically; its value here is that it **closes the entire folded-radius-seven scale beyond order 25**.
