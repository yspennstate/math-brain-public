## C. Method #5 — add a fugacity for new edges

Let `F := E(G') \ E(G)`. For `t>0`, define the length-`n` weighted SAW partition function

`Z_n(t) = sum_{omega in SAW_n(G')} t^{N_F(omega)}`,

where `N_F(omega)` is the number of traversed new edges. Put `s=log t` and

`phi_n(s) = (1/n) log Z_n(e^s)`.

Then exactly

`d phi_n / ds = E_{n,s}[N_F]/n`,

where `E_{n,s}` is expectation under the corresponding tilted length-`n` SAW measure. Thus the strict-augmentation problem is a pressure problem: a uniform positive density of new-edge usage on any fixed `s`-interval forces a positive free-energy increase.

For `s<=0`, old `G`-SAWs alone give

`limsup_n phi_n(s) >= log mu(G)`,

while `lim_n phi_n(0)=log mu(G')`. Therefore if the source conclusion failed, `mu(G')=mu(G)`, the limiting upper pressure would be flat throughout `s<=0`. In other words, any counterexample must make the added-edge fugacity asymptotically invisible at exponential scale.

This pressure language did not by itself close the source, because a new edge can be locally available while self-avoidance prevents positive-density insertion. It does, however, identify the exact quantity the surgery algorithm below must force.

## D. Method #19 — deterministic actual-A-cycle surgery in the 2-connected category

The previous report's residual obstruction was temporal: a bounded geometric cycle can meet a long SAW at times separated by an arbitrarily long interval. This run makes that obstruction completely explicit without using any `Gamma/A` phase decomposition.

### D.1. Uniform actual augmented cycle through every old edge

Assume in this section that the transitive base graph `G` is 2-vertex-connected.

Fix one new edge `f in F`. Since `A` acts quasi-transitively on vertices and `G` is locally finite, it has only finitely many orbits on old edges. Choose representatives

`e_1,...,e_r`.

For each `e_j`, the graph `G+f` is still 2-connected. The standard block characterization of 2-connected graphs says that any two edges lie on a common finite simple cycle (equivalently, subdivide both edges and apply the fact that any two vertices of a 2-connected graph lie on a common cycle). Hence there exists a simple cycle

`C_j subset G union {f}`

containing both `e_j` and `f`. It contains exactly one new edge, namely `f`.

Let

`L = max_j |C_j|`.

For every old edge `e` of `G`, choose deterministically `j` and `a in A` with `e=a e_j`, and write

`D(e)=a C_j`.

Then `D(e)` is a cycle in the actual graph `G'`, has length at most `L`, contains `e`, and contains exactly one new edge `a f`. This construction uses only actual `A`-translates; the left/right coset phase obstruction of the 2014 proof does not occur at this stage.

### D.2. The collision-span algorithm

Let

`omega=(omega_0,...,omega_n)`

be a `G`-SAW. For the anchor edge

`e_i={omega_i,omega_{i+1}}`,

take `D_i=D(e_i)`. The set `D_i cap omega` contains at least the two endpoints of `e_i`. Traverse `D_i` cyclically and take the unique arc `Q_i` between two consecutive vertices of `D_i cap omega` that contains the unique new edge of `D_i`. If its endpoints are `omega_{p_i},omega_{q_i}` with `p_i<q_i`, define

`span_i(omega)=q_i-p_i`.

The interior of `Q_i` is disjoint from `omega`, so replacing

`omega[p_i:q_i]`

by `Q_i` produces a valid SAW of `G'` using a new edge. The new arc has length at most `L`. The only possible unbounded cost is the temporal span `q_i-p_i` of the removed old subpath.

For fixed `K`, call anchor `i` **K-short** if `span_i<=K`.

### D.3. Exact short-span criterion

**Proposition D.1 (short-span criterion).** Suppose there exist `K<infinity`, `delta>0`, and infinitely many `n` with families `S_n` of `n`-step `G`-SAWs satisfying

`limsup |S_n|^(1/n)=mu(G)`

and such that every `omega in S_n` has at least `delta n` K-short anchors. Then

`mu(G')>mu(G)`.

**Proof.**

For a K-short anchor `i`, associate the input interval `[p_i,q_i]` and the cycle `D_i`. Put two anchors in conflict if their input intervals overlap in their interiors or their cycles intersect.

There is a uniform bound on the conflict degree. First, if a fixed time `t` is an endpoint of `[p_i,q_i]`, then the anchor edge `e_i` lies in the radius-`L` ball about `omega_t`, because both lie on `D_i`. Since `omega` has distinct vertices and `G` has bounded degree, only a bounded number `M=M(G,L)` of anchors can have `t` as an interval endpoint. Since every K-short interval has length at most `K`, a given short interval overlaps only `O(M K^2)` other short-anchor intervals. Second, if `D_i cap D_j` is nonempty, the anchor edge `e_j` lies in a bounded ball about `e_i`; again local finiteness and self-avoidance give a uniform bound. Thus the conflict graph has maximum degree bounded by a constant `B=B(G,L,K)`.

A greedy independent-set algorithm therefore selects at least

`c_0 n`,  `c_0=delta/(B+1)>0`,

pairwise compatible short anchors. For a selected anchor let

`d_i=|Q_i|-span_i`.

Because `1<=span_i<=K` and `1<=|Q_i|<=L`, there are only finitely many possible integer values of `d_i`. Retaining one value gives at least `c_1 n` compatible anchors, all with the same length change `d`.

Choose `j=floor(eta n)` of them. Simultaneously performing these `j` surgeries is valid because the relevant input intervals and cycles are disjoint, and every output has common length

`m=n+j d`.

Different inputs can in principle yield the same output, so we bound the inverse multiplicity. An output contains exactly the `j` new edges introduced by surgery. For each such edge, the relevant cycle has length at most `L`, and the deleted old segment has length at most `K`. Since `G'` is locally finite and `A` is quasi-transitive, there are only uniformly finitely many geometric cycle templates of length at most `L` through a fixed new edge; and there are at most `Delta^K` old `G`-walks of length at most `K` between candidate endpoints. Thus there is a constant `R<infinity` such that any output with `j` inserted new edges has at most `R^j` preimages `(omega,H)`.

Consequently,

`sigma_m(G') >= |S_n| * binom(floor(c_1 n),j) / R^j`.

Taking logarithms, Stirling's formula gives

`log mu(G') >= [log mu(G) + c_1 H(eta/c_1) - eta log R] / [1+eta d]`

along the full-growth subsequence, where `H(x)=-x log x-(1-x)log(1-x)`. As `eta downarrow 0`,

`H(eta/c_1)/eta -> +infinity`.

Hence for sufficiently small positive `eta`, the entropy term dominates both the finite inverse-multiplicity penalty and the bounded length distortion `eta d log mu(G)`. The right side is strictly greater than `log mu(G)`. Therefore `mu(G')>mu(G)`. QED.

This proposition isolates the genuine obstruction: a hypothetical counterexample in the 2-connected category must force almost all available actual `A`-cycle surgeries to have arbitrarily long temporal span.

## E. Method #27 — swap quantifiers and turn the obstruction into a return exponent

Instead of asking for one fixed local pattern to occur often, quantify the only way Proposition D.1 can fail.

### E.1. Bounded-return exponent

For `R>=1`, let

`b_m(R) = max_x # {m-step G-SAWs xi starting at x : d_G(x,xi_m)<=R}`

and define

`lambda_R = limsup_{m->infinity} b_m(R)^(1/m)`.

For the cycle templates `C_1,...,C_r` above, choose `R` so large that any two vertices of any template are at `G`-distance at most `R` (replace the one new edge by its fixed old `G`-geodesic if desired). Then the endpoints of every anchor interval `[p_i,q_i]` have `G`-distance at most `R`.

### E.2. Long intervals contain a linearly large disjoint return core

There is a uniform endpoint multiplicity `M`: for a fixed time `t`, at most `M` anchor intervals have `t` as one of their endpoints. This is the same bounded-ball argument used above.

Take any collection of long anchors and repeatedly choose an interval of **maximum span**, retain it, and delete all intervals overlapping it. If the retained interval has span `s`, every deleted overlapping interval has span at most `s` and therefore has an endpoint lying in the retained interval. There are `s+1` possible endpoint times and at most `M` anchored intervals per endpoint (up to a harmless factor two for left/right endpoint). Thus at most `C M s` intervals are deleted at that step.

It follows that if at least `alpha n` anchors have span greater than `K`, the greedy output is a pairwise disjoint family of long return intervals with total span

`S >= c alpha n`

for a constant `c=c(G,L)>0`. Every selected interval has length greater than `K` and its endpoints are at `G`-distance at most `R`.

### E.3. Return-gap theorem

**Theorem E.1.** In the setup of Question 4.10, assume additionally that the transitive base `G` is 2-connected and that, for the finite `R` above,

`lambda_R < mu(G)`.

Then

`mu(G')>mu(G)`.

**Proof.** Assume for contradiction `mu(G')=mu(G)=mu`.

Fix `delta=1/2`. For a parameter `K`, split all length-`n` `G`-SAWs into

- `Short_n(K)`: at least `delta n` anchors are K-short;
- `Long_n(K)`: fewer than `delta n` anchors are K-short.

If `Short_n(K)` has exponential growth `mu` along any subsequence, Proposition D.1 gives `mu(G')>mu`, contradiction. It remains to show that for sufficiently large `K`, `Long_n(K)` has exponential growth strictly below `mu`.

Every walk in `Long_n(K)` has at least `(1-delta)n=n/2` anchors of span greater than `K`. By the maximum-span greedy argument, it contains a disjoint family of return intervals, each of length greater than `K`, with total length at least `c n` for a fixed `c>0`.

Choose numbers

`lambda_R < v < mu < u`

with `u` sufficiently close to `mu` that

`u^(1-c) v^c < mu`.

By the definitions of `mu` and `lambda_R`, after increasing constants to cover finitely many small lengths, there are `C_1,C_2<infinity` such that

`sigma_m(G) <= C_1 u^m`,

`b_m(R) <= C_2 v^m`

for every `m>=0`.

Now fix a disjoint interval collection with return lengths `s_1,...,s_j>K`, total `S>=cn`, and complementary gap lengths summing to `n-S`. Ignoring all mutual-avoidance constraints between the pieces only overcounts. The number of `G`-SAWs compatible with this prescribed decomposition is at most

`C^(j+1) u^(n-S) v^S`

for a constant `C`. Since every `s_i>K`, `j<=n/K`.

The number of ways to choose at most `n/K` disjoint intervals in `{0,...,n}` is at most

`sum_{j<=n/K} binom(n+1,2j)`,

whose `n`th-root tends to `1` as `K->infinity`. The factor `C^(j+1)` likewise contributes at most `C^(n/K+1)`, whose `n`th-root tends to `1` as `K->infinity`.

Hence, for sufficiently large fixed `K`, the exponential growth rate of `Long_n(K)` is at most

`(1+o_K(1)) u^(1-c) v^c < mu`.

But the total number of `n`-step `G`-SAWs has exponential growth `mu`. Therefore `Short_n(K)` must have exponential growth `mu` along an infinite subsequence, and Proposition D.1 then implies `mu(G')>mu`, contradiction. QED.

### E.4. Immediate modern-literature corollary

If `G` has exponentially ballistic SAW, namely there exist `eps,t>0` such that

`P_n(d_G(omega_0,omega_n) >= eps n) >= 1-e^{-tn}`

for all large `n`, then for every fixed `R`

`lambda_R <= e^{-t} mu(G) < mu(G)`

(up to the immaterial finite initial range). Therefore Theorem E.1 applies.

Consequently Question 4.10 is affirmative, without normality or finite index, for every **2-connected transitive base graph with exponentially ballistic SAW**.

This includes in particular:

1. every 2-connected transitive graph with infinitely many ends, by Lehner–Lindorfer–Panagiotis (2025), whose abstract gives the exponential probability bound `1-e^{-tn}`;
2. every 2-connected transitive graph satisfying `mu_p<mu_w`, by Panagiotis (2024), who proves exactly such an exponential ballisticity conclusion; in particular this covers the hyperbolic tessellation classes treated there.
