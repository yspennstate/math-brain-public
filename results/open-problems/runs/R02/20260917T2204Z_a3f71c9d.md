## 3. Method #4 — PROVE SOMETHING WEAKER, COMPLETELY

The stuck report asked for one HGR-controlled finite coding stage rather than another informal hierarchy. There is a particularly clean one. It shows that **every finite erasure horizon can already be met on the same four-state alphabet while having exact finite-range independence**.

### Proposition R02-D31-FH — fixed-alphabet finite-horizon bilateral repair

Let `G` be a finite abelian group with `|G|>=2`. Let `(U_i)_{i in Z}` be iid uniform on `G`. Fix an integer `D>=1`, and define the stationary process

\[
X_i=(A_i,B_i):=\bigl(U_i,\ U_{i-D}+U_{i+D}\bigr)\in G^2.
\tag{FH1}
\]

Then:

1. `X` is strictly stationary and finite-state, with alphabet `G^2`.
2. The past `sigma(X_i:i<=0)` and future `sigma(X_i:i>=n)` are independent whenever `n>2D`. Hence
   \[
   \rho_X(n)=0\qquad(n>2D).
   \tag{FH2}
   \]
3. Every interval `I=[a,b]` of length at most `D` is reconstructed **exactly** from its complement:
   \[
   \sigma(X_i:i\in I)\subseteq\sigma(X_j:j\notin I).
   \tag{FH3}
   \]

For `G=F_2`, this is a **four-state** process for every `D`.

#### Proof

Stationarity is immediate because (FH1) is a shift-equivariant finite-radius function of iid variables.

For the mixing assertion, `X_i` depends only on parent variables at indices `i-D,i,i+D`. Therefore the entire past `i<=0` depends only on parent indices `<=D`, whereas the future `i>=n` depends only on parent indices `>=n-D`. These parent sets are disjoint when `n>2D`; iid independence then gives (FH2).

Now let `I=[a,b]` with `b-a+1<=D`, and fix `i in I`. Since `i-D<a` and `i+D>b`, the first component can be recovered from two sites outside `I`:

\[
A_i=U_i=B_{i-D}-A_{i-2D},
\tag{FH4}
\]

because `B_{i-D}=U_{i-2D}+U_i`.

Once all first components are considered, the second component is even more direct:

\[
B_i=A_{i-D}+A_{i+D}.
\tag{FH5}
\]

All coordinates on the right sides of (FH4)–(FH5) lie outside `I`. Thus every `X_i`, `i in I`, is measurable from the exterior, proving (FH3). `□`

### Why this matters and what it does **not** prove

This does **not** solve D0031. For fixed `D`, the process is `2D`-dependent; by Bradley's tail facts, its double tail is trivial, so a nondegenerate instance is not bilaterally deterministic.

What it proves is more diagnostic: **there is no finite-horizon obstruction on alphabet size four.** For every prescribed finite erased-block size, one can satisfy exact reconstruction and even make rho identically zero beyond a finite distance, while keeping the alphabet fixed at four symbols.

Therefore a negative solution to D0031 cannot come from any argument that only inspects a bounded reconstruction horizon. It must use consistency of the reconstruction constraints across **unboundedly many scales in one law**.

### The compactness trap is exact

Let `mu_D` denote the law above for `G=F_2`. If `F subset Z` is any fixed finite set and `D` exceeds the diameter of `F`, then the parent-index sets used by distinct `X_i`, `i in F`, do not overlap. Each `X_i` is itself uniform on `G^2`. Hence for all sufficiently large `D`, the restriction `(X_i)_{i in F}` is exactly iid uniform on `G^2`.

Thus

\[
\mu_D\Longrightarrow \text{iid-uniform on }(G^2)^{\mathbb Z}
\qquad(D\to\infty).
\tag{FH6}
\]

Yet for every fixed `L`, all `mu_D` with `D>=L` repair every interval of length at most `L`. The weak limit is iid and has trivial double tail. The repair maps simply run off to distance `D` and disappear under local weak convergence.

So a naive diagonal compactness argument from increasingly good fixed-alphabet finite approximants is invalid. The all-scale repair property is not closed in the topology seen by cylinder laws.

**#4 outcome:** no fixed-metric movement, but the finite-stage obligation from the stuck report is now solved completely. The real obstacle is simultaneous multiscale packing, not a local HGR-versus-reconstruction contradiction.

## 4. Method #15 — BREAK THE SYMMETRY ON PURPOSE

The previous routes repeatedly failed when a random phase or marker hierarchy was visible to both remote sides. The correct obstruction is stronger than “a common marker is bad”: even a **rare approximately common marker** is fatal to maximal correlation because HGR normalizes variance.

### Lemma R02-D31-RARE — rare synchronized markers force rho near one

Let `A` and `B` be sigma-fields and let events `E in A`, `F in B` satisfy

\[
P(E)=P(F)=p\in(0,1),\qquad P(E\triangle F)\le \varepsilon p.
\]

Then

\[
\boxed{
\rho(A,B)\ge 1-\frac{\varepsilon}{2(1-p)}.
}
\tag{RM1}
\]

#### Proof

Set `r=P(E cap F)`. Since

\[
P(E\triangle F)=2p-2r,
\]

we have `r>=p(1-epsilon/2)`. Using centered indicator functions,

\[
\operatorname{Corr}(1_E,1_F)
=\frac{r-p^2}{p(1-p)}
\ge 1-\frac{\varepsilon}{2(1-p)}.
\]

The maximal correlation is the supremum over such correlations. `□`

### Consequence for marker constructions

Suppose at separations `n_k` the left and right tails each recognize the same level/phase event of probability `p_k`, with **relative** disagreement `o(p_k)`. Even if `p_k->0`, (RM1) gives

\[
\rho(n_k)\to1.
\]

At the same time, the absolute covariance contributed by those indicators is only `O(p_k)`, so this phenomenon is compatible with an alpha-mixing estimate tending to zero. This cleanly isolates why “make the bad markers rarer” can help strong/alpha mixing while doing essentially nothing for HGR.

I do **not** assert that the inaccessible Burton–Denker–Smorodinsky proof contains exactly such marker events. The point is a route criterion: **any** finite-state port of a bilateral marker construction must avoid asymptotically synchronized rare level/phase events, not merely make them sparse.

This strengthens the earlier “global phase gives rho=1” diagnosis. A successful hierarchy needs something like **HGR-blind scale selection**: each side may see local markers, but no normalized rare scale event may be almost the same on both sides.

**#15 outcome:** no source movement; a precise necessary condition replaces the vague instruction “avoid a global phase.”

## 5. Method #21 — ASK WHO ELSE HAS THIS SHAPE

The finite-generator and secret-sharing viewpoints can now be combined into a sharper category.

### 5.1 Stationary erasure coding with a chi-square/HGR constraint

Ornstein–Weiss says exact bilateral reconstruction can be built into a finite generator. In coding language, a bilaterally deterministic finite generator is a **stationary finite-alphabet zero-error erasure code**: every finite erased block is recoverable from arbitrarily remote exterior symbols.

D0031 asks for such a code whose separated one-sided sigma-fields also satisfy

\[
\|T_n\|_{L^2_0\to L^2_0}=\rho(n)\to0,
\]

where `T_n` is the conditional-expectation operator from the past to the future. For finite channels this is exactly the second-singular-value / chi-square strong-data-processing quantity. So the missing object is not an ordinary entropy-efficient code; it is a **zero-error cooperative erasure code with vanishing one-sided chi-square channel norm**.

This is the closest established machinery to the shape of the problem: perfect secret sharing supplies exact joint recovery with little or no one-sided information, while strong-data-processing theory quantifies the `L^2` contraction D0031 needs.

### 5.2 Bradley's tensorization says what would work if infinite layers could be packed

Bradley's Theorem 5.1(b) gives

\[
\rho\left(\bigvee_j A_j,\bigvee_j B_j\right)=\sup_j\rho(A_j,B_j)
\]

for independent layer pairs. This is unusually favorable: HGR does not add across independent layers. It explains why an infinite-layer construction is a natural way to combine many reconstruction scales.

But finite state forbids the naive sitewise lossless packing of countably many independent layer states. This is exactly where Bradley's real-valued construction and the finite-state source question separate.

The remaining architectural possibility is therefore **time/space multiplexing of scales** rather than sitewise stacking. The finite-horizon construction in Section 3 is an exact module for one scale. A final witness would have to reuse a fixed finite alphabet to implement infinitely many such repair scales at sparse locations while satisfying the rare-marker criterion of Section 4.

### 5.3 A concrete next object: a two-scale multiplexing stage

The next finite target should not be another full infinite hierarchy. It should be a stationary finite-alphabet **two-scale** code with all four properties:

1. exact repair of every interval up to the smaller scale;
2. a second, genuinely more remote repair obligation on a positive-density set of intervals;
3. no globally shared phase/scale variable;
4. an exact second-singular-value bound strictly below one across the larger cut.

If even two scales cannot coexist without a rare synchronized marker mode, that obstruction can be attacked finitely. If they can, the resulting gadget is the right unit to iterate.

This formulation is also compatible with the neighboring D0038 handoff's “cut-blind hierarchy” idea, but the D0031 requirement is quantitative HGR contraction rather than exact halfspace independence.

**#21 outcome:** no metric movement; the source is reduced to a much more concrete coding-theoretic interface: fixed-alphabet multiscale erasure repair plus chi-square/HGR contraction, with rare synchronized markers explicitly prohibited.
