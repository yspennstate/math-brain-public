## 4. Mandatory stuck field (b): routes tried and the precise failure of each

The cumulative D0031 route record is now:

1. **Finite quantization of Bradley 1986.** A coordinatewise finite factor preserves or decreases rho, so this would solve the mixing half automatically. Failure: bilateral determinism is not factor-monotone; no finite quantizer preserving Bradley's double-tail reconstruction was found.

2. **One-time-pad / parity secret sharing.** At one finite scale, exact joint reconstruction is compatible with zero HGR between proper share collections. Failure: this proves local compatibility only; it does not supply a stationary infinite process.

3. **Finite-radius factors of beta-mixing parents / primitive finite-state Markov-HMM constructions.** These retain stronger tail-triviality properties incompatible with nondegenerate bilateral determinism. Failure: the candidate class is too regular; any solution must use genuinely nonlocal coding.

4. **One-dimensional finite-field linear/Haar shifts.** Proper closed shift-invariant linear subspaces give finite-order recurrences and periodic long-range common modes; the full shift is iid and has trivial double tail. Failure: scalar linear algebra is too rigid.

5. **A single stationary random phase for periodic parity blocks.** Failure: both remote sides infer the same global phase, giving a common nonconstant variable and hence rho equal to one.

6. **Independent-layer / tensorization idea.** Bradley's rho machinery makes independent layers attractive because HGR of independent joins is controlled by a supremum rather than a sum. Failure: infinitely many layers cannot simply be packed losslessly into one finite site alphabet.

7. **Arbitrary-syndrome additive sharing.** A parent syndrome can be hidden perfectly from every proper subset of shares. Failure: recursively nesting the same additive gadget telescopes to one giant parity check; it creates no genuinely new multiscale structure.

8. **Sparse/rare marker hierarchy.** Failure: rarity controls alpha-type dependence but not HGR if a marker/phase is exactly readable from both sides. A rare shared latent variable still forces rho to one.

9. **Zero-entropy shortcut.** Later literature records the standard fact that finite-alphabet zero-entropy processes are deterministic (the past determines the present, and likewise under time reversal). Thus the nondegenerate zero-entropy class has persistent one-sided common information and cannot furnish rho(n)->0. This is a standard exclusion, not a new R02 claim. Therefore any D0031 witness must live in the positive-entropy bilateral class.

10. **Blind upgrade of Burton–Denker–Smorodinsky alpha-mixing to rho-mixing.** Bradley's survey explicitly records rho-mixing => alpha-mixing and no converse in general. Failure: a probability-of-events mixing estimate does not bound the full conditional-expectation operator norm required by HGR.

The recurring failure is now clear: routes that make reconstruction exact tend to leave a shared coding skeleton visible to both one-sided tails, while routes with robust one-sided decorrelation tend to trivialize the double tail.

## 5. Method #1 — CHANGE THE CATEGORY: finite-generator design on a Bernoulli system

The most useful category change is from “invent a strange stationary sequence” to “design a finite generating partition with two competing operator properties.”

Ornstein–Weiss proved that every ergodic transformation with a finite generator has another finite generator that is bilaterally deterministic. In particular, bilateral finite generators exist even on Bernoulli systems. Bradley's survey stresses, however, that mixing properties of a **specific coordinate process** are not isomorphism invariants in the needed sense.

So D0031 can be viewed as the following design problem:

> Start with a Bernoulli shift and choose a finite bilaterally deterministic generator `P` for which the conditional-expectation operators across the coordinate cut,
> \[
> T_n:L_0^2(\sigma(P_k:k\le0))\to L_0^2(\sigma(P_k:k\ge n)),
> \qquad T_nf=\mathbb E[f\mid\sigma(P_k:k\ge n)],
> \]
> satisfy `||T_n|| -> 0`.

This is not asserted as an equivalent theorem beyond the obvious coding formulation; it is the working category for the next attack. It separates the two jobs cleanly: Ornstein–Weiss supplies an existence mechanism for bilateral finite generators, while D0031 asks for **quantitative HGR control of the generator itself**.

A useful warning from Bradley's adjacent Question 4 is that even rho-mixing of a finite-state coordinate process does not currently collapse automatically to an isomorphism theorem strong enough to solve this by abstract Bernoulli theory. The partition/coding geometry really matters.

**#1 outcome:** no metric movement, but the target is now an HGR-controlled finite-generator problem rather than an unconstrained process search.

## 7. Method #27 — SWAP THE QUANTIFIERS: seek a coding criterion stage-by-stage

Instead of first constructing one global process and then checking infinitely many cuts, swap the order and ask for a reusable finite-stage coding criterion.

A useful positive criterion would have the schematic form:

> for every target scale `R`, every error `epsilon>0`, and every finite block to be protected, produce a finite-alphabet recoding stage that (i) makes that block exactly recoverable from the exterior beyond `R`, while (ii) giving an explicit HGR/operator-norm bound at all cuts whose separation is already protected, and (iii) composes with later stages without increasing the previously certified bounds.

If such stages could be diagonalized **without growing the final site alphabet**, bilateral determinism would follow from satisfying every finite erasure obligation, while rho-mixing would follow from the certified operator norms.

The negative swapped-quantifier version is equally sharp:

> prove that every finite-alphabet bilaterally deterministic generator necessarily leaves, for infinitely many separations, a normalized centered mode whose conditional expectation across the cut has norm bounded away from zero.

The previous secret-sharing examples explain why a naive extraction from “the center is jointly reconstructible” cannot work: joint exterior recovery need not create any function visible to either side separately. A negative proof would have to use **finite alphabet + stationarity + consistency across infinitely many scales**, not bilateral determinism alone.

**#27 outcome:** no metric movement; it identifies the exact compositional object a positive proof needs and the exact common-mode extraction a negative proof needs.
