## 5. Compact-component setup

Let `D` be a nonempty compact subset of `R` and define its parabolic fan

\[
\mathcal F_D
=
\left\{(-u,x):u>0,\ \frac{x}{\sqrt u}\in D\right\}
\cup\{(0,0)\}.
\tag{5.1}
\]

Every connected component of a compact subset of `R` is either a singleton or a nondegenerate closed interval `[a,b]`.

For a nondegenerate interval component `C=[a,b]`, put

\[
\lambda(C)=\lambda_0(a,b).
\tag{5.2}
\]

For a singleton component set formally `lambda(C)=+infinity`; this notation merely records that no nonconstant continuous normalized path can live in that component on a time interval.

An FBM has an a.s. continuous version on all of `R`: on the probability-one event on which every countably many Brownian witness process `B^(n)` has a continuous path and `S_n -> -infinity`, every fixed real time is eventually to the right of some witness, so `X` agrees locally with a translate of a continuous Brownian path. Hence, for `u>0`,

\[
y(u)=X_{-u}/\sqrt u
\tag{5.3}
\]

is continuous.

### T15(i): all components strictly supercritical implies universal impossibility

Assume every nondegenerate interval component `C` of `D` satisfies

\boxed{\lambda(C)>1.}
\tag{6.1}

\[
\boxed{
\mathbb P\left(

No uniform gap above one is required. In particular, this remains true even if `D` has infinitely many interval components with `lambda(C_k) downarrow 1`, provided none is critical or subcritical.

### T15(ii): one subcritical component gives decomposable eventual existence

If `D` has a nondegenerate interval component `C=[a,b]` satisfying

\[
\boxed{\lambda_0(a,b)<1,}
\tag{6.2}

then there exists a decomposable FBM `X` such that

\[
\boxed{
\mathbb P\left(
\exists R<\infty:\ y(u)\in D\ \forall u\ge R
\right)=1.
}
\tag{T15.ii}
\]

### T15(iii): pointwise source clause

## 7. Complete proof of T15

### Lemma 7.1: sufficiently small intervals are supercritical

Fix `M<infinity` and an interval `I=(a,b) subset [-M,M]` of length `L=b-a`. For the OU Dirichlet Rayleigh quotient,

\[
\lambda_0(a,b)
=
\inf_{0\ne f\in H_0^1(I)}
\frac{\frac12\int_I |f'|^2e^{-x^2/2}\,dx}
{\int_I f^2e^{-x^2/2}\,dx}.
\]

Because `e^{-x^2/2}>=e^{-M^2/2}` on `I`, while `e^{-x^2/2}<=1`, and the one-dimensional Dirichlet Poincaré inequality gives `int |f'|^2 >= (pi^2/L^2) int f^2`,

\[
\boxed{
\lambda_0(a,b)
\ge
\frac{\pi^2 e^{-M^2/2}}{2L^2}.
}
\tag{7.1}
\]

Thus every point `c in R` lies strictly inside some rational-endpoint interval `I_c=(p,q)` with `lambda_0(p,q)>1`.

### Proof of T15(i)

Suppose the eventual-confinement event

\[
E=\{\exists R:\ y([R,infinity))\subset D\}
\tag{7.2}
\]

has positive probability. On `E`, the image `y([R,infinity))` is connected because `[R,infinity)` is connected and `y` is continuous. Therefore that image lies in a **single connected component** `C` of `D`.

If `C={c}` is a singleton, choose a rational interval `I=(p,q)` with `p<c<q` and `lambda_0(p,q)>1` using Lemma 7.1. Then on this path `y(u)=c` for all sufficiently large `u`, hence both `liminf y` and `limsup y` lie strictly inside `(p,q)`. Source Theorem 4.3(i) applied to `(p,q)` says that for every FBM one must have `limsup y>=q` or `liminf y<=p` a.s., a contradiction.

If `C=[a,b]` is nondegenerate, hypothesis (6.1) and continuity of the principal eigenvalue under endpoint perturbation give an open interval `J=(a-delta,b+delta)` with rational endpoints after a harmless further adjustment and with

\[
\lambda_0(J)>1.
\tag{7.3}
\]

Confinement to `C` implies `limsup y<=b<sup J` and `liminf y>=a>inf J`, again contradicting Theorem 4.3(i).

To make the random component harmless, note that the family of rational-endpoint intervals `J` with `lambda_0(J)>1` is countable. Every possible supercritical interval component and every possible singleton component is contained strictly inside at least one such `J`. Hence `E` is contained in a countable union of probability-zero source-Theorem-4.3 obstruction events. Therefore `P(E)=0`.

### Proof of T15(ii)

Let `C=[a,b]` be a component with `lambda_0(a,b)<1`. By continuity of `lambda_0`, choose `epsilon>0` such that

\[
a+\epsilon<b-\epsilon,
\qquad
\lambda_0(a+\epsilon,b-\epsilon)<1.
\tag{7.4}
\]

Apply source Theorem 4.3(ii) to the shrunken interval. It gives a decomposable FBM with

\[
\liminf_{u\to\infty} y(u)\ge a+\epsilon,
\qquad
\limsup_{u\to\infty} y(u)\le b-\epsilon
\]

a.s. Hence eventually `a<y(u)<b`, so eventually `y(u) in C subset D`. This proves T15(ii).

### Proof of T15(iii)

If `a<=0<=b` and `lambda_0(a,b)<1`, source Theorem 4.3(iii) gives a decomposable FBM lying in the exact component parabola `a sqrt(u) <= X_{-u} <= b sqrt(u)` for all `u>=0`. Since `C subset D`, the same process lies pointwise in `F_D`. QED.

## 8. New metric family: perfect totally disconnected / fat-Cantor fans

If `K subset R` is compact and totally disconnected, every connected component is a singleton. T15(i) therefore gives the particularly strong corollary

\[
\boxed{
\text{For every compact totally disconnected }K\subset\mathbb R
\text{ and every FBM }X,
\quad
\mathbb P\{\exists R:\ X_{-u}/\sqrt u\in K\ \forall u\ge R\}=0.
}
\tag{T15-Cantor}
\]

This is not merely a finite disconnected fan with a large branch count. A perfect Cantor set has uncountably many singleton components and no interval component at any scale.

### Canonical positive-measure example

Start from `[-6,6]`, length `12`. Fix `epsilon=1`. At stage `n>=1`, from each of the `2^(n-1)` surviving equal-length intervals remove its central open gap of length

\[
\frac{1}{2^{2n-1}}.
\tag{8.1}
\]

The stage-`n` total removal is exactly

\[
2^{n-1}\,2^{-(2n-1)}=2^{-n}.
\tag{8.2}
\]

Thus the total removed length is `sum_{n>=1}2^{-n}=1`, so the residual compact set `K_fat` has Lebesgue measure

\[
\boxed{|K_{fat}|=11.}
\tag{8.3}
\]

Every surviving component interval is split at the next stage and its diameter tends to zero geometrically; consequently `K_fat` is perfect, nowhere dense and totally disconnected. T15-Cantor says that **no FBM can even be eventually confined** to

\[
\mathcal F_{K_{fat}}
=
\{(-u,x):x/\sqrt u\in K_{fat}\}\cup\{(0,0)\}.
\tag{8.4}
\]

The same construction with total removed length `epsilon>0` arbitrarily small gives totally disconnected `K_epsilon subset [-6,6]` with measure `12-epsilon`. Therefore arbitrarily small deletion in one-dimensional Lebesgue measure can change the verdict from source-admissible to universally impossible.

## 9. Method #11 — dualize: components versus the killed domain

The topological proof has a natural OU dual description. Under Lamperti, a parabolic fan with fixed normalized cross-section `D` becomes stationary OU motion killed upon leaving `D`.

For a compact `D`, its interior is a countable disjoint union of open intervals. The Dirichlet form on `D^o` decomposes as the orthogonal direct sum of the interval Dirichlet forms. Run 13 used this for finitely many components. T15 shows what the spectral direct-sum picture misses if one looks only at `D^o`: boundary components and singleton components. Continuity supplies the missing statement. If a confined normalized path lives in a singleton component, it must be constant; a small supercritical rational interval around that point then triggers source Theorem 4.3(i).

For a totally disconnected compact `K`, `K^o` is empty. In the killed-OU language there is no nontrivial open survival component at all; in the pathwise language every connected image is a point. The two sides give the same qualitative conclusion: the effective confinement cost is infinite.
