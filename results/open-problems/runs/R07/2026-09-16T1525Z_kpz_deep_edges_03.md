For every integer `n>=1`, the following four estimates hold:

\ge
\frac{25}{12103686144}\,n,
}
\tag{C08.3}
\]

and, with

\[
\delta_0=10^{-7},
\]

\[
\boxed{
E\#\{e\in\gamma_n:R_e\ge\delta_0\}
\ge
2\cdot10^{-9}n.
}
\tag{C08.4}
\]

Here `e` in the constants denotes Euler's number, not an FPP edge.

### Proof of C08.1: an explicit linear geodesic-length bound

Set

\[
a=\frac1{12e}.
\]

Let `S_n` be the passage time along the straight `n`-edge axis path from `0` to `ne1`; thus `S_n` has the Gamma(`n`,1) law.

Because all edge weights are strictly positive, a finite geodesic is simple. For any integer

\[
\ell\ge66n,
\]

if `L_n>=ell` and `S_n<=a ell`, then the geodesic itself is a self-avoiding path of some length `m>=ell` having passage sum

\[
T_n\le S_n\le a\ell\le am.
\]

Therefore

\[
\{L_n\ge\ell\}
\subseteq
\{S_n>a\ell\}
\cup
\bigcup_{m\ge\ell}
\{\exists\text{ self-avoiding }m\text{-edge path from }0\text{ of cost }\le am\}.
\tag{3.1}
\]

For the first event, the Gamma mgf at `1/2` gives

\[
P(S_n>a\ell)
\le
2^n e^{-a\ell/2}.
\tag{3.2}
\]

For a fixed `m`-edge path, Chernoff with

\[
\lambda=a^{-1}-1>0
\]

gives

\[
P(\Gamma(m,1)\le am)
\le
(ae^{1-a})^m
\le
(ae)^m.
\tag{3.3}
\]

There are at most

\[
4\cdot3^{m-1}
\]

self-avoiding `m`-edge paths from the origin. Since `3ea=1/4`, the union bound gives

\[
P(\exists\text{ such path of length }m)
\le
\frac43\,4^{-m}.
\]

Summing `m>=ell`,

\[
P(\exists\text{ such path of length at least }\ell)
\le
\frac{16}{9}4^{-\ell}.
\tag{3.4}
\]

For the elementary numerical bounds used below, the exponential series gives

\[
e>1+1+\frac12+\frac16=\frac83,
\]

while

\[
e
<\sum_{k=0}^4\frac1{k!}
+\frac1{5!}\sum_{j\ge0}5^{-j}
=\frac{65}{24}+\frac1{96}
=\frac{87}{32}
<\frac{11}{4}.
\tag{3.5}
\]

Hence for `ell>=66n`,

\[
\frac{a\ell}{2}
\ge
\frac{66n}{24e}>n.
\]

Also, for `x>0`, `e^x>=1+x` implies

\[
\frac1{1-e^{-x}}\le1+\frac1x.
\]

Taking `x=1/(24e)` and using `e<11/4`,

\[
\frac1{1-e^{-1/(24e)}}<67.
\tag{3.6}
\]

Now use the tail-sum formula. Equations (3.1)-(3.6) imply

\[
\begin{aligned}
E L_n
&\le66n
+\sum_{\ell\ge66n}2^n e^{-a\ell/2}
+\sum_{\ell\ge66n}\frac{16}{9}4^{-\ell}\\
&<66n+67+1\\
&\le134n,
\end{aligned}
\]

for every `n>=1`. This proves C08.1.

### Proof of C08.2: a self-contained positive linear passage-time lower bound

If

\[
T_n\le an,
\]

then the geodesic has some length `m>=n` and cost at most `an<=am`. The same self-avoiding-path union bound gives

\[
P(T_n\le an)
\le
\sum_{m\ge n}\frac43 4^{-m}
=
\frac{16}{9}4^{-n}
\le
\frac49.
\tag{3.7}
\]

Thus

\[
P(T_n>an)\ge\frac59
\]

and therefore

\[
E T_n
\ge
an\frac59
=
\frac5{108e}n.
\]

This proves C08.2.

### Proof of C08.3: remove very large edge weights, then use Cauchy

For `M>0`, define the large-weight contribution on the geodesic

\[
H_M
=
\sum_{e\in\gamma_n}X_e1_{\{X_e>M\}}.
\]

Condition on all weights except `X_e`, so that the cavity threshold `R_e` is fixed. If `R_e<=M`, the conditional contribution of edge `e` to `H_M` is zero. If `R_e>M`, then by (2.1)

\[
\begin{aligned}
E[X_e1_{\{X_e>M\}}1_{\{e\in\gamma_n\}}\mid X_{\setminus e}]
&=
\int_M^{R_e}x e^{-x}\,dx\\
&\le
(M+1)e^{-M},
\end{aligned}
\]

whereas

\[
P(e\in\gamma_n\mid X_{\setminus e})
=1-e^{-R_e}
\ge1-e^{-M}.
\]

Therefore, with

\[
\alpha_M
=
\frac{(M+1)e^{-M}}{1-e^{-M}},
\]

we have the exact conditional comparison

\[
E[X_e1_{\{X_e>M\}}1_{\{e\in\gamma_n\}}\mid X_{\setminus e}]
\le
\alpha_M
P(e\in\gamma_n\mid X_{\setminus e}).
\tag{3.8}
\]

Summing over edges by Tonelli and using C08.1,

\[
E H_M\le \alpha_M E L_n\le134\alpha_M n.
\tag{3.9}
\]

Take `M=16`. From `e>8/3`,

\[
e^{-16}<(3/8)^{16}<1/2,
\]

so

\[
\alpha_{16}<34(3/8)^{16}.
\]

The exact-arithmetic checker certifies

\[
134\cdot34(3/8)^{16}
<\frac5{594}
<\frac5{216e},
\tag{3.10}
\]

where the last inequality uses `e<11/4`.

Since the geodesic passage sum equals `T_n`, C08.2 and (3.9)-(3.10) give

\[
E\sum_{e\in\gamma_n}X_e1_{\{X_e\le16\}}
\ge
\frac5{216e}n.
\tag{3.11}
\]

Define

\[
A_n=\sum_{e\in\gamma_n}(X_e\wedge1).
\]

For `0<=x<=16`,

\[
x\wedge1\ge x/16,
\]

so (3.11) yields

\[
E A_n\ge\frac5{3456e}n.
\tag{3.12}
\]

Pointwise Cauchy gives

\[
\sum_{e\in\gamma_n}(X_e\wedge1)^2
\ge
\frac{A_n^2}{L_n}.
\tag{3.13}
\]

A second Cauchy inequality across environments gives

\[
(EA_n)^2
=\left(E\left[\frac{A_n}{\sqrt{L_n}}\sqrt{L_n}\right]\right)^2
\le
E\left[\frac{A_n^2}{L_n}\right]E L_n.
\tag{3.14}
\]

Using C08.1 and (3.12)-(3.14),

\[
E\sum_{e\in\gamma_n}(X_e\wedge1)^2
\ge
\frac{25}{134\cdot3456^2e^2}n.
\tag{3.15}
\]

On `e in gamma_n`, (2.1) gives `R_e>X_e` off null ties. Hence

\[
(R_e\wedge1)^2\ge(X_e\wedge1)^2.
\]

Finally `e<11/4` turns (3.15) into the explicit rational estimate

\[
E\sum_{e\in\gamma_n}(R_e\wedge1)^2
\ge
\frac{25}{12103686144}n.
\]

This proves C08.3.

### Proof of C08.4: a fixed positive cavity-depth threshold

For `0<delta<=1`, let

\[
N_\delta
=\#\{e\in\gamma_n:R_e\ge\delta\}.
\]

Pointwise,

\[
\sum_{e\in\gamma_n}(R_e\wedge1)^2
\le
N_\delta+\delta^2L_n,
\tag{3.16}
\]

because a term with `R_e<delta` is at most `delta^2`, while a term with `R_e>=delta` is at most one. Therefore C08.1 and C08.3 imply

\[
E N_\delta
\ge
\left(
\frac{25}{12103686144}-134\delta^2
\right)n.
\tag{3.17}
\]

At

\[
\delta_0=10^{-7},
\]

the exact checker certifies

\[
\frac{25}{12103686144}-134\cdot10^{-14}
>2\cdot10^{-9}.
\]

This proves C08.4. `square`

## 4. R07-GH-C09 — the refresh covariance has a linear initial decay rate

**Label: PROVED consequence. It does not move the variance metric.**

The exact ANOVA identity from C05 gives, initially as an extended nonnegative number,

\[
-C_n'(0+)
=
\sum_eE\,q(R_e),
\qquad
q(r)=1-2re^{-r}-e^{-2r}.
\tag{4.1}
\]

This quantity is actually finite. Indeed, with

\[
p(r)=1-e^{-r},
\]

we have

\[
p(r)-q(r)
=e^{-r}(2r-1+e^{-r})\ge0
\]

because `e^{-r}>=1-r`. Thus

\[
\sum_eE q(R_e)
\le
\sum_eE p(R_e)
=E L_n
\le134n.
\tag{4.2}
\]

Using C06 and then conditioning on the off-edge environment,

\[
\begin{aligned}
-C_n'(0+)
&\ge
\frac1{16e}\sum_eE\left[p(R_e)(R_e\wedge1)^2\right]\\
&=
\frac1{16e}
E\sum_{e\in\gamma_n}(R_e\wedge1)^2.
\end{aligned}
\tag{4.3}
\]

C08.3 and `e<11/4` therefore yield

\[
\boxed{
-C_n'(0+)
\ge
\frac{25}{532562190336}n
>
4\cdot10^{-11}n.
}
\tag{C09}
\]

So the exact noising covariance begins with a rigorously linear decay rate even though the currently known unconditional variance lower bound is only logarithmic.

This identifies the remaining obstruction very sharply: **the missing theorem is quantitative persistence of this depth-weighted overlap for a non-negligible noise window.** A large derivative at `t=0` alone does not lower-bound the area

\[
\operatorname{Var}(T_n)=\int_0^\infty[-C_n'(t)]\,dt
\]

without a lower bound on the width over which the derivative stays large. The Ahlberg-Deijfen-Sfragara chaos scale cannot supply that width here without using the unknown variance circularly.

C08 therefore proves the previous run's simplest depth-truncated special case at `t=0`, but not the positive-noise statement required to improve `b(n)`.
