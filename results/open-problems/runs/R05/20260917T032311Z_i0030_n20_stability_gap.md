Aldous–Fill Proposition 7.29 concerns continuous-time random walk on a distance-regular graph and says that, for fixed graph distance `k`, `q(t,k)/q(t,0)` is nondecreasing in `t`. Open Problem 7.30 then asks whether random walk on an **arc-transitive** graph has some monotonicity property stronger than Corollary 7.3. Corollary 7.3 is the weaker return-dominance inequality for symmetric reversible chains (and its continuous-time analogue).

Frozen R05 answer (unchanged): for every finite simple connected arc-transitive `d`-regular graph, with

\[
P=A/d,\qquad H_t=e^{t(P-I)},
\]

and every arc `x\sim y`,

\[
r_{xy}(t):=\frac{H_t(x,y)}{H_t(x,x)}
\]

is strictly increasing for finite `t>=0`, with `r(0)=0` and `r(t)->1`.

The retained proof remains

\[
a(t)=H_t(x,x),\qquad b(t)=H_t(x,y),\qquad a'(t)=b(t)-a(t),
\]

so

\[
r(t)=\frac{b(t)}{a(t)}=1+(\log a(t))'.
\]

If `L=I-P` and `mu_x` is the local spectral measure, define

\[
d\nu_t(\lambda)=\frac{e^{-t\lambda}}{a(t)}\,d\mu_x(\lambda).
\]

Then

\[
r(t)=1-\mathbb E_{\nu_t}\lambda,
\qquad
r'(t)=\operatorname{Var}_{\nu_t}(\lambda)>0.
\]

## 2. 90% research phase — the Bhatia–Davis defect is an exact stability variable

The previous run proved the spectral-ceiling envelope

\[
r(t)\le U_\Lambda(t)
:=\frac{(\Lambda-1)(e^{\Lambda t}-1)}
        {1+(\Lambda-1)e^{\Lambda t}},
\qquad
\Lambda:=\lambda_{\max}(L),
\tag{2.1}
\]

and identified complete graphs as the all-time extremizers. The high-value question for this run was not another inequality of the same type, but whether the **slack below (2.1)** has an exact structural meaning and a quantitative lower bound.

Put

\[
m(t):=\mathbb E_{\nu_t}\lambda=1-r(t).
\]

### #18 SAY IT IN ANOTHER LANGUAGE — endpoint spectral defect

Define the endpoint/interior spectral defect

\[
\boxed{
J(t):=\mathbb E_{\nu_t}[\lambda(\Lambda-\lambda)].
}
\tag{2.2}
\]

Since

\[
\mathbb E_{\nu_t}\lambda^2
=\Lambda m(t)-J(t),
\]

we have the **exact decomposition**

\[
\boxed{
\operatorname{Var}_{\nu_t}(\lambda)
=m(t)(\Lambda-m(t))-J(t).
}
\tag{2.3}
\]

Thus `J(t)` is exactly the slack in the bounded-variance inequality `Var <= m(Lambda-m)`, not an auxiliary estimate. In probability language, this is the Bhatia–Davis defect for the tilted local spectral law on `[0,Lambda]`. Equality means that the tilted spectral law is supported only at the endpoints `{0,Lambda}`.

For a vertex-transitive graph every nonzero global spectral projector has constant positive diagonal `rank(E)/|V|`, so the local spectral support equals the full spectrum. Therefore, on a source graph,

- `J(t)=0` for all finite `t` iff the graph has only two Laplacian eigenvalues, hence is complete;
- every noncomplete source graph has `J(t)>0` for every finite `t`.

This turns the complete-graph extremality from an equality-case observation into a positive stability variable.

### #13 FIND WHAT ONLY INCREASES — an exact monotone defect flow

Set

\[
z(t):=\frac{\Lambda-m(t)}{m(t)}.
\]

Because `m(0)=L_{xx}=1`,

\[
z(0)=\Lambda-1.
\]

Using `m'(t)=-Var_{nu_t}(lambda)` and (2.3), direct differentiation gives

\[
\boxed{
z'(t)=\Lambda z(t)-\frac{\Lambda J(t)}{m(t)^2}.}
\tag{2.4}
\]

Hence

\[
\boxed{
W(t):=\frac{e^{\Lambda t}}{z(t)}
}
\]

satisfies

\[
\boxed{
\frac{d}{dt}\log W(t)
=\frac{\Lambda J(t)}{m(t)(\Lambda-m(t))}\ge0.
}
\tag{2.5}
\]

For every noncomplete source graph the derivative is strictly positive for every finite `t`; for complete graphs it vanishes identically. Thus `W` is a strict monovariant measuring departure from the complete-graph envelope.

Define the accumulated interior spectral defect

\[
\Omega(t):=
\Lambda\int_0^t
\frac{J(s)}{m(s)(\Lambda-m(s))}\,ds.
\tag{2.6}
\]

Integrating (2.5) gives the **exact identity**

\[
\boxed{
z(t)=(\Lambda-1)e^{\Lambda t-\Omega(t)}.}
\tag{2.7}
\]

Let

\[
Z(t):=(\Lambda-1)e^{\Lambda t}.
\]

Since `r=1-Lambda/(1+z)` and `U_Lambda=1-Lambda/(1+Z)`, (2.7) yields an exact formula for the envelope slack:

\[
\boxed{
U_\Lambda(t)-r(t)
=
\frac{\Lambda Z(t)(1-e^{-\Omega(t)})}
{(1+Z(t))(1+Z(t)e^{-\Omega(t)})}.
}
\tag{2.8}
\]

Thus the entire distance below the complete-graph envelope is the accumulated tilted spectral mass away from the two endpoints.

### #25 COUNT THE SAME THING TWICE — the initial defect and initial slope gap

At `t=0`, the local spectral mean is one. For a simple `d`-regular graph,

\[
\mathbb E_{\mu_x}\lambda^2
=(L^2)_{xx}
=\left(I-\frac{2A}{d}+\frac{A^2}{d^2}\right)_{xx}
=1+\frac1d.
\]

Therefore the same defect has the exact graph-theoretic value

\[
\boxed{
J(0)=\Lambda-1-\frac1d.
}
\tag{2.9}
\]

Writing `theta_min` for the least adjacency eigenvalue,

\[
\boxed{
J(0)=\frac{-\theta_{\min}-1}{d}.
}
\tag{2.10}
\]

The same quantity is also the initial slope gap between the extremal envelope and the source ratio:

\[
U_\Lambda'(0)=\Lambda-1,
\qquad
r'(0)=\operatorname{Var}_{\mu_x}(\lambda)=\frac1d,
\]

so

\[
\boxed{
U_\Lambda'(0)-r'(0)=J(0).
}
\tag{2.11}
\]

For completeness, `J(0)>0` for every connected noncomplete regular graph. Indeed a connected noncomplete graph contains an induced three-vertex path `P_3`; interlacing gives `theta_min <= -sqrt(2)<-1`. Complete graphs have `theta_min=-1` and `J(0)=0`.

## 3. Explicit strict stability gap below the complete-graph envelope

The exact identity above also gives a closed quantitative lower bound on the slack. Since `0<=lambda<=Lambda`,

\[
J(t)
=
\frac{\int \lambda(\Lambda-\lambda)e^{-t\lambda}\,d\mu_x(\lambda)}
     {\int e^{-t\lambda}\,d\mu_x(\lambda)}
\ge e^{-\Lambda t}J(0),
\tag{3.1}
\]

because the denominator is at most one. Also

\[
m(t)(\Lambda-m(t))\le\frac{\Lambda^2}{4}.
\]

Consequently

\[
\boxed{
\Omega(t)\ge
\delta(t):=
\frac{4J(0)}{\Lambda^2}(1-e^{-\Lambda t})
=
\frac{4(\Lambda-1-1/d)}{\Lambda^2}(1-e^{-\Lambda t}).
}
\tag{3.2}
\]

Substituting this into (2.7) yields, for every noncomplete graph in the frozen source class and every `t>0`,

\[
\boxed{
\frac{H_t(x,y)}{H_t(x,x)}
\le
1-
\frac{\Lambda}
{1+(\Lambda-1)e^{\Lambda t-\delta(t)}}
< U_\Lambda(t).
}
\tag{3.3}
\]

Equivalently, the previous envelope has the explicit positive stability gap

\[
\boxed{
U_\Lambda(t)-r(t)
\ge
\frac{\Lambda Z(t)(1-e^{-\delta(t)})}
{(1+Z(t))(1+Z(t)e^{-\delta(t)})},
\quad
Z(t)=(\Lambda-1)e^{\Lambda t}.
}
\tag{3.4}
\]

For complete graphs `J(0)=delta=0` and the bound collapses exactly to equality, as it should.

I label this auxiliary quantitative theorem

`R05-I0030-ENVELOPE-STABILITY-02: PROVED`.

No finite checker is required for the theorem itself: the full symbolic argument is on the page. The only external ingredient in the envelope route is the classical bounded-variance inequality, and (2.3) records its exact slack directly.
