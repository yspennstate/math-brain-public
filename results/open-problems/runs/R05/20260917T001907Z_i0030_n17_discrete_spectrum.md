## 2. Idea before code — where negative spectrum actually enters

The preceding run proved a universal discrete analogue for holding probability `h>=1/2`, where the lazy transition matrix is positive semidefinite. That leaves open the structural question below 1/2.

Let

`S=A/d`, `Q_h=hI+(1-h)S`, `0<h<1`.

For an arc `x~y`, define

`a_m=(Q_h^m)_{xx}`, `b_m=(Q_h^m)_{xy}`, `r_m=b_m/a_m`.

Arc-transitivity gives common diagonal and edge values. The one-step equation is

`a_{m+1}=h a_m+(1-h)b_m`,

so

`r_m = (a_{m+1}/a_m - h)/(1-h)`.                                      (2.1)

Because `h>0`, every `a_m>0`.

## 3. Move #22 — READ THE FAILURES: exact signed Hankel obstruction

The all-pairs MNHD literature warns against over-generalization: Regev--Shinkar found a Cayley graph where the all-pairs ratio fails, while Price, Nica, Kubo--Namba and Liu--Zhang require additional structure for positive results. In the discrete adjacent problem the failure mechanism can be isolated exactly.

Let the distinct eigenvalues of `Q_h` be `q_j`, with spectral projectors `E_j`, and put `alpha_j=(E_j)_{xx}`. Vertex-transitivity makes each projector diagonal constant, hence `alpha_j=rank(E_j)/|V|>0`, and

`a_m = sum_j alpha_j q_j^m`.

Define

`D_m = a_m a_{m+2} - a_{m+1}^2`.

Expanding and pairing `(i,j)` with `(j,i)` gives the exact identity

**R05-I0030-C15 (PROVED):**

`D_m = sum_{i<j} alpha_i alpha_j (q_i-q_j)^2 (q_i q_j)^m`.              (3.1)

By (2.1),

`r_{m+1}-r_m = D_m / ((1-h)a_m a_{m+1})`.                              (3.2)

For every even `m=2k`, each factor `(q_i q_j)^{2k}` is nonnegative. Therefore

`D_{2k} >= 0` for every `k>=0` and every `0<h<1`.                       (3.3)

So a lazy adjacent ratio on an arc-transitive graph can decrease **only** on an odd-index step `r_{2k+1} -> r_{2k+2}`. The previous `h>=1/2` PSD argument was sufficient but not structurally sharp: parity alone protects half the increments for every positive holding probability.

## 4. First odd step — exact local threshold

Let `lambda` be the common number of common neighbors of the two endpoints of an edge. Arc-transitivity makes it edge-independent and `0<=lambda<=d-1`.

Exact return-walk counting gives

`a_1=h`,

`a_2=h^2+(1-h)^2/d`,

`a_3=h^3+3h(1-h)^2/d + lambda(1-h)^3/d^2`,

because `(A^3)_{xx}=d lambda`.

Hence

**R05-I0030-C16 (PROVED):**

`D_1 = (1-h)^2/d^2 * [(d-1-lambda)h^2 + (lambda+2)h - 1]`.             (4.1)

The bracket is strictly increasing on `h>=0`. Its unique positive root is

`h_1(d,lambda)=2/(sqrt(lambda^2+4d)+lambda+2)`.                         (4.2)

Therefore a necessary condition for all-step discrete adjacent monotonicity is `h>=h_1(d,lambda)`. If `h<h_1`, then `D_1<0`, hence `r_2<r_1` immediately. For `K_{d+1}`, where `lambda=d-1`, this becomes `h_1=1/(d+1)`.

This is a theorem about the discrete lazy analogue; it does not alter the frozen continuous-time source target.

## 5. Move #29 — ADD THE POINT AT INFINITY: exact eventual sign

Since `h>0`, `Q_h` is irreducible and aperiodic. Its stationary eigenvalue is `q_0=1`, and all nonstationary eigenvalues have modulus strictly below 1.

Define

`rho_+ = max{q_j: 0<q_j<1}` and `rho_- = max{-q_j: q_j<0}`,

with an absent set interpreted as zero. In (3.1), pairs of two nonstationary eigenvalues are `O(rho^{2m})`, while stationary/nonstationary pairs are `O(rho^m)`. Therefore the latter decide the large odd-step sign.

**R05-I0030-C17 (PROVED):**
- If `rho_+ > rho_-`, then `D_m>0` for every sufficiently large odd m; together with (3.3), the ratio is eventually nondecreasing at every step.
- If `rho_- > rho_+`, then `D_m<0` for every sufficiently large odd m; hence infinitely many late decreases occur.
- If `rho_+=rho_-=rho>0`, the leading odd coefficient is `alpha_+(1-rho)^2 - alpha_-(1+rho)^2`. If nonzero, its sign decides. If it vanishes, the next spectral modulus decides.

Thus “there is negative spectrum” is not the right obstruction. The asymptotic issue is whether the negative edge of the lazy spectrum exceeds the positive edge in modulus, with local spectral weights resolving the tie.

## 6. Move #16 — COMPUTE SMALL CASES: exact C5 phase diagram

For the source-valid arc-transitive graph `C5`, the simple-random-walk spectrum is

`1`, `s=(sqrt(5)-1)/4` with multiplicity 2, and `t=-(sqrt(5)+1)/4` with multiplicity 2.

For `Q_h`, put `p=h+(1-h)s` and `n=h+(1-h)t`. The local spectral weights are `1/5,2/5,2/5`, so (3.1) is exactly

`D_m = (2/25)p^m(1-p)^2 + (2/25)n^m(1-n)^2 + (4/25)(pn)^m(p-n)^2`.      (6.1)

Even m are positive. Exact simplification of the first odd determinant gives

`D_1 = (1-h)^2(h^2+2h-1)/4`.                                           (6.2)

Thus `D_1>=0` iff `h>=sqrt(2)-1`.

This first-step condition is also sufficient for every later odd step. If `n>=0`, every term in (6.1) is nonnegative. If `n=-u<0` and `h>=sqrt(2)-1`, then

`p-u=p+n=(5h-1)/2>0`,

so `0<=u/p<1`. Dividing an odd `D_m` by `(2/25)p^m` shows that both negative correction factors `(u/p)^m` and `u^m` shrink with odd m. Hence the smallest odd determinant is the first one.

Therefore

**R05-I0030-C18a (PROVED):** on `C5`, the full discrete adjacent ratio sequence is nondecreasing at every step iff

`h >= sqrt(2)-1`.

The eventual threshold is lower. Since `p+n=(5h-1)/2`, one has `p>|n|` iff `h>1/5` while `n<0`. C17 then gives eventual increase for `h>1/5` and eventual odd-step decrease for `h<1/5`. At `h=1/5`, `p=-n=1/sqrt(5)` and the leading odd coefficient is exactly `-8 sqrt(5)/125<0`.

Therefore

**R05-I0030-C18b (PROVED):** on `C5`, the ratio is eventually nondecreasing at every step iff

`h > 1/5`.

Exact regimes:
- `0<h<=1/5`: infinitely many late odd-step decreases;
- `1/5<h<sqrt(2)-1`: only finitely many failures, but `r_2<r_1`;
- `sqrt(2)-1<=h<1`: all steps nondecreasing.

This is a sharper answer to the previous run's “how much negative spectrum can be tolerated?” question than the universal sufficient threshold 1/2.
