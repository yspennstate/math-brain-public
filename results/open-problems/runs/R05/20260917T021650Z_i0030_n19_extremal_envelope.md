## 2. 90% research phase: a sharp quantitative envelope

### #11 DUALIZE — replace the graph by an extremal moment problem

Write

\[
m(t):=\mathbb E_{\nu_t}\lambda=1-r(t).
\]

Let

\[
\Lambda:=\lambda_{\max}(L).
\]

For an arc-transitive graph, vertex transitivity makes every nonzero spectral projector have constant positive diagonal `rank(E)/|V|`, so the local spectral support is the full spectrum and `Lambda` really is the endpoint of `mu_x`.

The derivative identity becomes

\[
-m'(t)=\operatorname{Var}_{\nu_t}(\lambda).
\]

Now dualize to the elementary fixed-mean moment extremum on `[0,Lambda]`. Since `lambda^2 <= Lambda lambda`,

\[
\operatorname{Var}(\lambda)
=\mathbb E\lambda^2-m^2
\le \Lambda m-m^2
=m(\Lambda-m).
\tag{2.1}
\]

The extremal measure in (2.1) is supported only at the two endpoints `{0,Lambda}`.

### #5 ADD A PARAMETER — spectral-ceiling interpolation

Set

\[
z(t):=\frac{\Lambda-m(t)}{m(t)}.
\]

Because `m(0)=L_{xx}=1`, we have `z(0)=Lambda-1`. From (2.1),

\[
z'(t)
=\frac{\Lambda\operatorname{Var}_{\nu_t}(\lambda)}{m(t)^2}
\le \Lambda z(t).
\]

Hence

\[
z(t)\le (\Lambda-1)e^{\Lambda t},
\]

so

\[
m(t)\ge
\frac{\Lambda}{1+(\Lambda-1)e^{\Lambda t}}.
\]

Therefore the frozen source ratio satisfies the explicit quantitative strengthening

\[
\boxed{
0\le r_{xy}(t)
\le U_\Lambda(t)
:=\frac{(\Lambda-1)(e^{\Lambda t}-1)}
{1+(\Lambda-1)e^{\Lambda t}}
<1.
}
\tag{2.2}
\]

For normalized graph Laplacians `0<=lambda<=2`. Repeating the same argument with the universal endpoint `2` gives

\[
\boxed{
\frac{H_t(x,y)}{H_t(x,x)}\le \tanh t
\qquad(x\sim y)
}
\tag{2.3}
\]

for every finite simple connected arc-transitive graph under the frozen rate-one convention.

This is not needed to prove the already-retained monotonicity theorem, but it is a source-matching quantitative strengthening of it.

The same proof also gives an averaged statement on every finite connected regular graph: the normalized average over neighbors obeys (2.2)/(2.3), because the identity `a'=average_neighbor-a` survives without edge transitivity. I record this only as an auxiliary consequence, not as a change of the source target.

### #24 FIND THE EXTREMAL OBJECT — complete graphs are exactly sharp

For `K_n`,

\[
\Lambda=\frac{n}{n-1}
\]

and the continuous-time heat kernel gives exactly

\[
r_{K_n}(t)
=\frac{1-e^{-\Lambda t}}
{1+(n-1)e^{-\Lambda t}}
=U_\Lambda(t).
\]

Thus every complete graph saturates the **spectral-ceiling** envelope (2.2) at every time.

Conversely, if an arc-transitive graph attains equality in the moment inequality for an interval of times, its exponentially tilted local spectral measure is supported on `{0,Lambda}`; tilting does not change support, so the original local spectral measure is supported on two points. Vertex transitivity makes every global spectral projector have positive local diagonal, hence the graph itself has only two normalized-Laplacian eigenvalues. A connected simple regular graph with only two adjacency eigenvalues is complete. Thus complete graphs are exactly the all-time extremizers of (2.2).

For the universal envelope (2.3), equality is achieved by `K_2`:

\[
r_{K_2}(t)=\frac{1-e^{-2t}}{1+e^{-2t}}=\tanh t.
\]

No other connected source graph can attain the universal envelope for all positive times. Therefore `K_2` is the sharp universal extremal object.
