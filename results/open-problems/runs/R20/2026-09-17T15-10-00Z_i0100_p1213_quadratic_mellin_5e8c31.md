## 3. #4 PROVE SOMETHING WEAKER, COMPLETELY — exact quadratic balanced-profile certificate

Let `Z=-Z` be a nonzero Fourier set in `Z_n`, let `d=|Z|`, and put
\[
A=\frac nd.
\]
Use the projected-simplex notation already established in R20:
\[
u_x=q^{-1/2}P_Ze_x,\qquad q=d/n,
\]
\[
c_x=\langle u_0,u_x\rangle,
\qquad z_x=u_x-c_xu_0\quad(x\ne0).
\]
The radial constant is
\[
a_Z=\max\left\{-\sum_{x\ne0}y_xc_x:
 y_x\ge0,\ \sum y_x=1,\ \sum y_xz_x=0\right\}.
\tag{3.1}
\]
The harmonic-frame identities are
\[
\sum_{x\ne0}z_x=0,
\qquad
\sum_{x\ne0}c_xz_x=0,
\qquad
\sum_{x\ne0}z_xz_x^T=A I,
\tag{3.2}
\]
\[
\sum_{x\ne0}c_x=-1,
\qquad
\sum_{x\ne0}c_x^2=A-1.
\tag{3.3}
\]
For a coefficient vector `f=(f_x)_{x!=0}`, define
\[
R_f=\sum_{x\ne0}f_xz_x,
\qquad
(\mathcal B_Z f)_x
=f_x-\frac1A\langle R_f,z_x\rangle.
\tag{3.4}
\]
The earlier R20 balance lemma proved that `B_Z f` has exact transverse balance and preserves both total mass and the radial moment `sum c_x f_x`.

Define the quadratic transverse field
\[
\rho_x:=\langle R_Z,z_x\rangle,
\qquad
R_Z:=\sum_{y\ne0}c_y^2z_y.
\tag{3.5}
\]

### Theorem R20-QUADBAL1

For real parameters `s,t`, set
\[
\boxed{
F_{s,t}(x)
=1-s c_x+t\left(c_x^2-\frac{\rho_x}{A}\right),
\qquad x\ne0.
}
\tag{3.6}
\]
If
\[
F_{s,t}(x)\ge0\qquad\text{for every }x\ne0,
\tag{3.7}
\]
then
\[
\boxed{
a_Z\ge
\frac{1+s(A-1)-t C_{3,*}}
{(n-1)+s+t(A-1)},}
\tag{3.8}
\]
where
\[
C_{3,*}:=\sum_{x\ne0}c_x^3.
\]

#### Proof

Take the scalar profile
\[
f_x=1-s c_x+t c_x^2.
\]
By (3.2), `R_1=0` and `R_c=0`, while `R_{c^2}=R_Z`; hence applying (3.4) gives exactly
\[
\mathcal B_Zf=F_{s,t}.
\]
Therefore (3.7) makes `F_{s,t}` a nonnegative transversely balanced vector. The balancing projection preserves mass, so by (3.3)
\[
M:=\sum_{x\ne0}F_{s,t}(x)
=(n-1)+s+t(A-1).
\tag{3.9}
\]
The same projection preserves the radial moment, and therefore
\[
-\sum_{x\ne0}c_xF_{s,t}(x)
=-\sum c_x(1-s c_x+t c_x^2)
=1+s(A-1)-tC_{3,*}.
\tag{3.10}
\]
Normalizing `y=F/M` gives an admissible point of (3.1), and (3.8) follows. QED.

This theorem is intentionally modest: it does not assert that a quadratic profile is asymptotically sharp. It turns the first nonlinear attack into one explicit pointwise positivity problem.

## 4. The new arithmetic object: the quadratic correction is a restricted Mellin transform

The field `rho_x` in (3.5) is not an opaque frame quantity. It has an exact Fourier formula.

Let
\[
m_Z(k)=|\{(a,b)\in Z^2:a+b=k\}|,
\qquad
\bar m_Z=\frac1{|Z|}\sum_{k\in Z}m_Z(k).
\tag{4.1}
\]
Use the unnormalised DFT. Since
\[
\widehat c=A\,1_Z,
\]
we have
\[
\widehat{c^2}(k)=\frac{A^2}{n}m_Z(k).
\tag{4.2}
\]
Also
\[
\rho_x
=\sum_yc_y^2(c_{x-y}-c_xc_y)
=(c^2*c)(x)-c_x\sum_yc_y^3.
\tag{4.3}
\]
Parseval gives
\[
\sum_yc_y^3
=\frac{A^3}{n^2}\sum_{k\in Z}m_Z(k).
\tag{4.4}
\]
Substituting (4.2)--(4.4) yields the exact identity
\[
\boxed{
\widehat\rho(k)
=\frac{A^3}{n}\bigl(m_Z(k)-\bar m_Z\bigr)1_Z(k).
}
\tag{4.5}
\]
Call this `R20-RMELL1`.

For the Paley `N`-half, `|N|=n/2` exactly, so `A=2`. The preceding R20 report proved that for `k in N`, writing `t=alpha^k` and
\[
\mathcal T(t)=\sum_{z\in\mathbb F_p}
\chi(z(z-1)(z-t)),
\]
one has
\[
m_N(k)=\frac n4+\frac{\mathcal T(\alpha^k)-6}{8}.
\tag{4.6}
\]
Therefore (4.5) simplifies sharply to
\[
\boxed{
\widehat\rho(k)
=\frac{\mathcal T(\alpha^k)-\overline{\mathcal T}_N}{n}\,1_N(k),
}
\tag{4.7}
\]
and hence
\[
\boxed{
\rho_x=
\frac1{n^2}
\sum_{k\in N}
\bigl(\mathcal T(\alpha^k)-\overline{\mathcal T}_N\bigr)
 e^{2\pi i kx/n}.
}
\tag{4.8}
\]
So the first nonlinear balancing correction is exactly a **restricted multiplicative Mellin transform of the centered Legendre elliptic trace**.

This is useful because the old factor-`sqrt(2)` certificate depends only on the one-point Jacobi coordinate `c_x`; the first nonlinear repair depends on the joint pair `(c_x,rho_x)`, and (4.8) specifies precisely which second arithmetic observable must be controlled. A Hasse bound term-by-term is too weak for the desired scale; square-root cancellation in the restricted Mellin transform gives the numerically observed `rho_x=O(1/n)` scale. Proving a sharp joint envelope for `(c_x,n rho_x)` is a much narrower target than controlling the full entropy covariance path or proving Paley RIP.

The derivation above is on the page and requires no numerical checker.
