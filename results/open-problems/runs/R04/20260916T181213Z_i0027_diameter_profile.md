## 4. R04-I0027-C2 — diameter-profile full-class upper coefficient

**Status: PROVED mathematically in this report; independent audits pending.**

### Theorem

For finite connected simple unweighted graphs under the Aldous--Fill simple-random-walk convention,

\[
\boxed{
\limsup_{n\to\infty}\frac{M_n}{n^3}
\le \frac{1}{27\sqrt2}
=\frac{\sqrt2}{54}.
}
\tag{C2}
\]

### Proof

Let `G` have `n` vertices, `m` edges, degree sequence `(d_v)`, diameter `d`, and effective resistances `R_{uv}`. The commute-time/random-target identity gives

\[
K(G)=\tau_0(G)
=\frac1{2m}\sum_{u<v}d_ud_vR_{uv}.
\tag{4.1}
\]

Equivalently, the multiplicative degree-Kirchhoff index `R^*(G)` is exactly `2mK(G)`.

First, `R_{uv}<=d` and

\[
\sum_{u<v}d_ud_v
=\frac{(2m)^2-\sum_vd_v^2}{2}
\le 2m^2.
\]

Therefore

\[
\boxed{K(G)\le dm.}
\tag{4.2}
\]

Second, effective resistance is bounded by shortest-path distance, so

\[
2mK(G)
\le \operatorname{Gut}(G).
\tag{4.3}
\]

Apply the diameter-sensitive Mukwembi estimate (3.1):

\[
K(G)
\le \frac{d(n-d)^4}{32m}+O\!\left(\frac{n^4}{m}\right).
\tag{4.4}
\]

Now method **#7** takes the scale limit. Put

\[
\delta_n=d/n,\qquad \alpha_n=m/n^2.
\]

Method **#30** separates the only error-sensitive scale.

If `alpha_n<n^{-1/2}`, then (4.2) gives

\[
K(G)/n^3\le\delta_n\alpha_n\le n^{-1/2}=o(1).
\]

If `alpha_n>=n^{-1/2}`, then the error in (4.4), after division by `n^3`, is

\[
O((\alpha_n n)^{-1})=O(n^{-1/2}),
\]

uniformly. Thus in this regime

\[
\frac{K(G)}{n^3}
\le
\min\left\{
\delta_n\alpha_n,
\frac{\delta_n(1-\delta_n)^4}{32\alpha_n}
\right\}
+o(1).
\tag{4.5}
\]

For positive `A,B`, `min(A,B)<=sqrt(AB)`, hence the dependence on the unknown edge density cancels:

\[
\frac{K(G)}{n^3}
\le
\frac{\delta_n(1-\delta_n)^2}{\sqrt{32}}+o(1).
\tag{4.6}
\]

On `[0,1]`, the function `delta(1-delta)^2` is maximized at `delta=1/3`, where it equals `4/27`. Therefore

\[
\limsup\frac{K(G)}{n^3}
\le
\frac{4/27}{\sqrt{32}}
=\frac1{27\sqrt2}
=\frac{\sqrt2}{54}.
\]

The bounds and error estimates are uniform, so taking the maximum over all connected `n`-vertex graphs is legitimate. This proves C2. QED.

\tag{6.1 OPEN}

\le \frac{\delta(1-\delta)^2}{8}+o(1)
