## 4. Published block-Gaussian input

Peled–Schenker–Shamis–Sodin (PSSS), *On the Wegner Orbital Model*, Theorem 3, Eq. (1.22), states that there is an absolute constant `C_PSSS>0` such that for a deformed block-Gaussian matrix
\[
\widetilde H=H_0\oplus_{j=1}^{K} V_j,
\]
where the independent `V_j` are standard GOE blocks of sizes `m_j` and `H_0` is arbitrary deterministic real symmetric,
\[
\mathbb E\,(\mathcal N(\widetilde H,I))_m
\le
\left(C_{\rm PSSS}\sum_{j=1}^{K}m_j\,|I|\right)^m
\tag{4.1}
\]
for every integer `m>=1`, with `(x)_m=x(x-1)...(x-m+1)`.

Their GOE normalization, Remark 1.5, is
\[
\operatorname{Var}(V_{aa})=2/m_j,\qquad
\operatorname{Var}(V_{ab})=1/m_j\quad(a<b).
\tag{4.2}
\]

The theorem's constant is asserted universal but is not numerically instantiated in the source. I therefore keep it symbolically as `C_PSSS` and do not invent a numerical value.

## 5. R04-FM-C2 — exact embedding into a uniformly scaled deformed block-GOE ensemble

**Status: PROVED, by an explicit covariance decomposition plus published PSSS Theorem 3.**

Assume the frozen metric domain
\[
2W+1\le N.
\tag{5.1}
\]
Set
\[
s=W+1,\qquad
K=\left\lceil\frac{N}{s}\right\rceil,\qquad
q=\left\lfloor\frac{N}{K}\right\rfloor.
\tag{5.2}
\]
Partition the cyclic index set into `K` consecutive (non-wrapping in the chosen representative `0,...,N-1`) blocks `B_j` whose sizes `m_j` differ by at most one. Then
\[
m_j\in\{q,q+1\},\qquad \sum_jm_j=N.
\tag{5.3}
\]
Because `K>=N/(W+1)`,
\[
\max_jm_j=\left\lceil\frac NK\right\rceil\le W+1.
\tag{5.4}
\]
Hence every pair of indices inside one block has circular distance at most `W`; all the corresponding target coordinates have variance exactly `v`.

### 5.1 Exact lower bound on the smallest block

I need a common GOE scale, so the smallest block matters. The following sharp-for-this-proof integer bound holds:
\[
\boxed{q\ge\left\lceil\frac{2W+1}{3}\right\rceil.}
\tag{5.5}
\]

Proof. Write `s=W+1`. If `K=1`, (5.1) forces `s=1`, so the claim is immediate. If `K=2`, then
\[
q=\lfloor N/2\rfloor\ge s-1\ge\lceil(2s-1)/3\rceil.
\]
If `K>=3`, the definition of the ceiling gives the integer inequality
\[
N\ge(K-1)s+1.
\]
Thus
\[
q=\left\lfloor\frac NK\right\rfloor
\ge
s-\left\lceil\frac{s-1}{K}\right\rceil
\ge
s-\left\lceil\frac{s-1}{3}\right\rceil
=
\left\lceil\frac{2s-1}{3}\right\rceil.
\]
Since `2s-1=2W+1`, (5.5) follows. QED.

### 5.2 Exact covariance split

Define the common scale
\[
\boxed{a^2=\frac{q}{2(2W+1)}=\frac{vq}{2}.}
\tag{5.6}
\]
For each block `B_j`, let `V_j` be an independent standard GOE(`m_j`) matrix with normalization (4.2). The scaled block `aV_j` has coordinate variances
\[
\operatorname{Var}(aV_{aa})=\frac{2a^2}{m_j}=v\frac q{m_j}\le v,
\tag{5.7}
\]
\[
\operatorname{Var}(aV_{ab})=\frac{a^2}{m_j}=v\frac q{2m_j}\le v.
\tag{5.8}
\]
Therefore, coordinate by coordinate, subtract these nonnegative variances from the target Gaussian variances inside each block, and put **all** inter-block band coordinates into the remainder. Gaussian variance splitting gives an independent real-symmetric Gaussian matrix `R` such that
\[
\boxed{
H_N\ \stackrel d=\ R+a\bigoplus_{j=1}^{K}V_j.
}
\tag{5.9}
\]
No band edge is added: the GOE blocks use only coordinates already satisfying `d_N(x,y)<=W`; every other target coordinate, including the circular seam, remains in `R`. Thus the exact band dependence and the exact variance `1/(2W+1)` are preserved.

Conditioning on `R` and dividing by `a` gives
\[
\frac{H_N}{a}
=
\frac Ra+\bigoplus_jV_j,
\tag{5.10}
\]
which is exactly the PSSS deformed block-Gaussian form with total block dimension `sum m_j=N`.

## 8. Exact block resolvent reduction

The same decomposition gives a block Schur complement compatible with the metric proof. Fix a block `B_j` and write `B_j^c` for its complement. Conditional on `R` and all GOE blocks except `V_j`,
\[
G_{jj}(z)
=
\left[
aV_j+R_{jj}-zI
-R_{j\bar j}(H_{\bar j\bar j}-z)^{-1}R_{\bar j j}
\right]^{-1}.
\tag{8.1}

Factoring `a`,
\[
\boxed{
G_{jj}(z)
=
a^{-1}[V_j-A_j(z)]^{-1},
}
\tag{8.2}

where `A_j(z)` is independent of `V_j` under the conditioning. This is the exact block-resolvent mechanism behind the PSSS spectral averaging/Minami estimate.

## 9. Adversarial checks and limitations

### 9.1 Why the previous diagonal route was genuinely suboptimal

The previous diagonal-conditioning Minami estimate paid the sup density of one diagonal Gaussian,
\[
\|\rho\|_\infty\asymp\sqrt W,
\]
and therefore yielded an `O(W)=O(sqrt(N))` second moment. The PSSS block theorem regularizes all `Theta(W^2)` independent coordinates of each `Theta(W)` block jointly and removes this loss.

### 9.2 The common GOE strength is asymptotically maximal for this extraction

A standard GOE(`m`) block scaled by `a` has diagonal variance `2a^2/m`. Since the target diagonal variance is `v`, any coordinatewise independent Gaussian remainder requires
\[
2a^2/m\le v.
\]
For `m~W` and `v~1/(2W)`, this forces `a<=1/2+o(1)`. Our balanced block construction has `a->1/2`, so it asymptotically saturates the largest common standard-GOE component available by this simple coordinatewise split.

### 9.3 What this does not give

The uniform factorial moments do not determine:
- the limiting intensity at a deterministic microscopic energy;
- uniqueness of subsequential point-process limits;
- Poisson versus GOE/Sine_1 versus a genuinely interpolating fixed-`c` law;
- the correct transfer operator / sigma-model stochastic limit;
- profile universality beyond the exact box model.

Those are still the core critical-window obligations.
