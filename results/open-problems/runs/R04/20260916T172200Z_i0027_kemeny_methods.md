# 4. R04-I0027-C1 — improved full-class upper coefficient

**Status: PROVED mathematically in this report; audit pending.**

This is the metric-moving result.

Let `G` be a connected simple graph with `n` vertices, `m` edges, degrees `d_u`, graph distances `dist(u,v)`, effective resistances `R_uv`, and Kemeny constant `K(G)=tau_0(G)`.

## 4.1 Exact resistance representation

The commute identity for simple random walk is

\[
E_uT_v+E_vT_u=2mR_{uv}.
\]

Average the random-target identity over the starting state with stationary law `pi_u=d_u/(2m)` and symmetrize. This gives

\[
\boxed{
K(G)=\frac{1}{2m}\sum_{u<v}d_ud_vR_{uv}.
}
\tag{4.1}
\]

Since unit-resistance effective resistance is bounded by shortest-path distance,

\[
R_{uv}\le \operatorname{dist}(u,v),
\]

so with the Gutman index

\[
\operatorname{Gut}(G)
:=\sum_{u<v}d_ud_v\operatorname{dist}(u,v),
\]

we have

\[
\boxed{K(G)\le \operatorname{Gut}(G)/(2m).}
\tag{4.2}
\]

## 4.2 Sparse-side bound

Also `R_uv<=n-1`, and

\[
\sum_{u<v}d_ud_v
=\frac{(2m)^2-\sum_ud_u^2}{2}
\le2m^2.
\]

Therefore

\[
\boxed{K(G)\le(n-1)m.}
\tag{4.3}
\]

This is useful precisely when the graph is sparse on the `n^2` scale.

## 4.3 Dense-side bound from the sharp Gutman-index theorem

Mukwembi, *On the Upper Bound of Gutman Index of Graphs*, MATCH Commun. Math. Comput. Chem. 68 (2012), Theorem 2, proves uniformly over connected `n`-vertex graphs

\[
\boxed{
\operatorname{Gut}(G)
\le \frac{2^4}{5^5}n^5+O(n^4),
}
\tag{4.4}
\]

and the coefficient `2^4/5^5` is best possible for the Gutman index. The PDF typography is important here: it is `2^4/5^5`, not the decimal-looking OCR string `24/55`.

Combining (4.2) and (4.4), write

\[
\alpha_n:=m/n^2.
\]

Then, whenever `alpha_n` is not vanishing too fast,

\[
\frac{K(G)}{n^3}
\le
\frac{2^3}{5^5}\frac1{\alpha_n}
+O\!\left(\frac1{\alpha_n n}\right).
\tag{4.5}
\]

On the other hand, (4.3) gives

\[
\frac{K(G)}{n^3}\le(1-1/n)\alpha_n.
\tag{4.6}
\]

If `alpha_n<n^{-1/2}`, (4.6) is `o(1)`. If `alpha_n>=n^{-1/2}`, the error in (4.5) is `O(n^{-1/2})`. Hence uniformly over all connected `n`-vertex graphs,

\[
\limsup_{n\to\infty}rac1{n^3}\max_GK(G)
\le
\max_{\alpha>0}\min\left\{
\alpha,\frac{2^3}{5^5\alpha}
\right\}.
\]

The two terms cross at

\[
\alpha=\sqrt{\frac8{3125}}
=\frac{2\sqrt{10}}{125}.
\]

Therefore

\[
\boxed{
\limsup_{n\to\infty}\frac1{n^3}\max_G\tau_0(G)
\le
\frac{2\sqrt{10}}{125}
=0.05059644256\ldots
}
\tag{R04-I0027-C1}
\]

This strictly improves the source upper coefficient

\[

# 6. Method #18 — spanning-two-forest / UST language

**Status: KNOWN ingredients, exact derivation here; no novelty claim.**

Let `tau(G)` be the number of spanning trees. The matrix-tree two-forest identity gives

\[
R_{uv}=\frac{F_{uv}}{\tau(G)},
\]

where `F_uv` counts spanning two-forests separating `u` and `v`. Hence (4.1) becomes

\[
\boxed{
K(G)=
\frac1{2m\tau(G)}
\sum_{F=(A,B)}\operatorname{vol}(A)\operatorname{vol}(B).
}
\tag{6.1}
\]

There is an equivalent uniform-spanning-tree form. A spanning two-forest `F=(A,B)` has exactly `|partial A|` possible graph edges that reconnect it into a spanning tree. Double-count the pairs `(T,e)` where `T` is a spanning tree and `e in T`, and weight the deletion cut by `vol(A_e)vol(B_e)/|partial A_e|`. One obtains

\[
\boxed{
K(G)=\frac1{2m}
\mathbb E_{T\sim UST}
\sum_{e\in T}
\frac{\operatorname{vol}(A_e)\operatorname{vol}(B_e)}{|\partial A_e|}.
}
\tag{6.2}
\]

This reformulation exposes the extremal problem as an **average cut-energy problem over the UST**. It also identifies a failure of the obvious route: replacing the average by the single worst cut is too weak. On a balanced barbell, the central bridge alone makes the resulting relaxation larger than the desired `1/54` coefficient by a constant factor; the proof must exploit the distribution of deletion cuts, not only the worst bottleneck.

The 2025 arXiv paper *Scalable and Provable Kemeny Constant Computation on Static and Dynamic Graphs: A 2-Forest Sampling Approach* independently confirms that two-forest/spanning-tree representations are an active known computational language for Kemeny; (6.1)–(6.2) are not presented as a new identity.

# 7. Method #3 — stronger restricted theorem: all fixed clique-tree blowups

**Status: PROVED restricted case; overall source remains PARTIAL. Novelty UNVERIFIED.**

This goes strictly beyond optimizing only a two-clique barbell family.

Fix a finite tree `T`. For each core vertex `i in V(T)`, replace it by a clique `C_i^(n)` with

\[
|C_i^{(n)}|=a_in+o(n),\qquad a_i\ge0.
\]

For each tree edge `e`, connect designated vertices of the endpoint cliques by an internally vertex-disjoint path of length

\[
\ell_e=b_en+o(n),\qquad b_e\ge0,
\]

with no other inter-core edges. Assume

\[
\sum_i a_i+\sum_e b_e=1.
\]

Put

\[
S:=\sum_i a_i^2.
\]

Then

\[
\boxed{
\frac{K(G_n)}{n^3}
\longrightarrow
F_T(a,b)
:=
\frac1S
\sum_{i<j}a_i^2a_j^2d_b(i,j),
}
\tag{7.1}
\]

where

\[
d_b(i,j)=\sum_{e\in P_T(i,j)}b_e.
\]

Equivalently, if deleting `e` splits the core tree and

\[
A_e=\sum_{i\text{ on one side of }e}a_i^2,
\]

then

\[
\boxed{
F_T(a,b)=\frac1S\sum_{e\in T}b_eA_e(S-A_e).
}
\tag{7.2}
\]

### Proof of the asymptotic formula

Each positive core clique has degree-volume

\[
\operatorname{vol}(C_i^{(n)})=a_i^2n^2+o(n^2),
\]

and

\[
2m=S n^2+o(n^2),
\]

because the path edges contribute only `O(n)` edges. For vertices in distinct positive core cliques `i,j`, every inter-core path edge is a bridge in the clique-tree graph, while resistance inside each clique is `O(1/n)`. Therefore

\[
R_{uv}=n\,d_b(i,j)+o(n)
\]

uniformly for core vertices away from the harmless designated endpoints. The contribution to the multiplicative degree-Kirchhoff sum from a pair of distinct cores is therefore

\[
a_i^2a_j^2d_b(i,j)n^5+o(n^5).
\]

Pairs involving at least one path-internal vertex have total degree-volume only `O(n)` on that side and contribute `O(n^4)` to the resistance sum; pairs within a single clique contribute still less at the `n^5` scale because clique resistance is `O(1/n)`. Divide the leading `n^5` term by `2m=S n^2+o(n^2)` to obtain (7.1). Expanding the tree metric edge-by-edge gives (7.2).

### Exact optimization of the fixed clique-tree class

Let

\[
s=\sum_i a_i,
\qquad
B=\sum_e b_e=1-s.
\]

For fixed core masses, (7.2) is linear in `b`, so all macroscopic path budget may be placed on an edge maximizing

\[
A_e(S-A_e)/S.
\]

For such a cut, let

\[
x=\sum_{i\in L}a_i,
\qquad
y=\sum_{i\in R}a_i,
\qquad x+y=s.
\]

Then

\[
A_e\le x^2,
\qquad
S-A_e\le y^2.
\]

Since `AB/(A+B)` is increasing in each positive argument,

\[
\frac{A_e(S-A_e)}S
\le
\frac{x^2y^2}{x^2+y^2}.
\]

At fixed `s`, put `t=xy<=s^2/4`. Then

\[
\frac{x^2y^2}{x^2+y^2}
=
\frac{t^2}{s^2-2t},
\]

which is increasing in `t`. Hence its maximum is at `x=y=s/2` and equals `s^2/8`. Therefore

\[
F_T(a,b)
\le
\frac{(1-s)s^2}{8}
\le
\boxed{\frac1{54}},
\]

where the final maximum occurs at `s=2/3`.

Equality at leading order forces one macroscopic core on each side of the active edge, masses

\[
a_L=a_R=1/3,
\]

and total macroscopic path length

\[
B=1/3.
\]

Thus **within every fixed finite clique-tree blowup family, the asymptotic Kemeny coefficient is at most `1/54`, with equality only in the balanced two-clique/double-kite geometry up to zero-mass decorations.**

The bounded prior-art search located exact barbell optimization (Faught–Kempton–Knudson) and bridge/1-separation formulae, but did not locate this exact fixed clique-tree asymptotic optimization. That is not a novelty certificate.
