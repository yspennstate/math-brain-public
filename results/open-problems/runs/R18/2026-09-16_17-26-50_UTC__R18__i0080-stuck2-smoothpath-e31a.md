## 4. Move 7 — take the limit: compactify the all-time witness path

## 5. Move 27 — swap the quantifiers: can one fixed nu witness every t?

### Stronger target tested

C007 proves

for every t>0 there exists a log-unimodal nu_t such that sigma_t boxtimes nu_t is not log-unimodal.

I tested the strictly stronger quantifier order

there exists one log-unimodal nu such that for every t>0, sigma_t boxtimes nu is not log-unimodal.

This would be aesthetically stronger and would remove all witness-parameter bookkeeping.

### What the retained architecture would require

In inverse-log coordinates, C007's continuous component is essentially a flat density of height about 1/L over a scale L=ell*b, plus an atom whose weight is also scale-dependent. For large t, b approaches a positive constant while ell and hence L grow linearly with t.

A fixed log-unimodal witness on the negative log half-line corresponds, after inversion, to a nonincreasing integrable density r(y) on y>=0 (possibly together with a fixed atom at 0). To imitate the same flat-component mechanism at **every** large scale L, one would need a lower bound of the form

L r(L) >= c > 0

through all sufficiently large L. But then pointwise r(L)>=c/L and therefore

integral_{L0}^infinity r(y) dy >= c integral_{L0}^infinity dy/y = infinity,

contradicting that r is a probability-density component.

### Outcome / exact failure

The direct attempt to freeze **the C007 plateau mechanism itself** into a single witness fails because continuous scale coverage conflicts with integrability. Sparse plateaus at a sequence of scales can be integrable, but then an additional robustness/gluing theorem would be needed to cover every time between those scales. A completely different fixed witness is not ruled out. I therefore record this as a failed stronger route, not an impossibility theorem for all fixed witnesses.

This is useful because it identifies why the t-dependent witness is not merely cosmetic: its density and atom weights genuinely renormalize with the physical scale.

## 6. Move 30 — solve one scale at a time, then glue smoothly

### New idea

The C007 conditions only require

ell>=100,

b^2 = pi*(19/(20 ell))*t <= 1/100.

Instead of the nonsmooth choice ell=max{100,95*pi*t}, choose the single analytic path

ell(t) = 100 + 95*pi*t,
D(t)   = 19/(20 ell(t)),
p(t)   = 8/(5 ell(t)),
b(t)   = sqrt(pi D(t) t),
a(t)   = D(t)/b(t).

Then the key identity is exact:

b(t)^2 = 1/100 - 1/ell(t).

Hence for every finite t>0,

ell(t)>100,
0<b(t)<1/10,
0<p(t)<2/125,
0<D(t)<19/2000.

Also, identically,

t = b(t)^2/(pi D(t)),

a(t)*pi*t = b(t) < pi.

Therefore every hypothesis of the already-proved uniform C007 high/low/high profile theorem holds for every t>0. The same source Lemma 4.1 normalization applies and the same four-crossing argument gives the same source conclusion for every t>0.

Independent check:

Let k_t vanish on (-infinity,0], be C^1 on (0,infinity), have k_t'(v_t)=-q_t<0 at some v_t>0, and satisfy M_t=sup_{u>=v_t}|k_t'(u)|<infinity. Let

mu_* = w_0 delta_0 + sum_{n>=1} exp(-n^4) delta_{-n^2}.

The relative tail satisfies

R_n = sum_{j>n} exp(-j^4)/exp(-n^4)
    <= exp(-4n^3)/(1-exp(-4n^3)) -> 0.

Assume for contradiction that f_t=mu_* * k_t is unimodal with mode m. Choose n so large that

2n-1>v_t,
M_t R_n<q_t/2,
-n^2+v_t<m.

At x_n=-n^2+v_t, all j<n atoms and the atom at 0 are shielded by the one-sided support. The nth atom contributes -q_t exp(-n^4). The j>n derivative tail has absolute value at most M_t sum_{j>n}exp(-j^4). Moreover, the strict gap 2n-1>v_t allows a neighborhood of x_n on which the derivative series is uniformly dominated by M_t times the summable weight tail, so differentiating termwise is justified. Thus

f_t'(x_n) <= exp(-n^4)(-q_t+M_t R_n) < -q_t exp(-n^4)/2 <0.

On a left-of-mode interval where f_t is differentiable, unimodality makes the distribution function convex and hence its density nondecreasing; a negative derivative contradicts that. Finally, `sum exp(-n^4+c n^2)<infinity` for every c>0, so the proposed mu_* has all exponential moments.
