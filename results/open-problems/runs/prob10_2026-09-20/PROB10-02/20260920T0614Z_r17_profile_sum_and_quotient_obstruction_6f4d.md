## 2. Exact dependence-preserving one-defect chain

Fix strip length `m=2w`. A formal strip state is
\[
S=(x;g),\qquad x,g\in\{0,1\}^m.
\]
For a fresh genuine source pair `(u,v)`, set
\[
d_0=0,
\qquad
d_i=(1-g_i)\bigl(d_{i-1}\vee {\bf1}_{\{x_i=v\}}\bigr),
\quad 1\le i\le m,
\tag{2.1}
\]
then
\[
x'=(x_2,\ldots,x_m,u),
\tag{2.2}
\]
\[
g'_i=g_{i+1}+d_{i+1}-d_i\quad(1\le i<m),
\qquad
g'_m=(1-d_m){\bf1}_{\{u=v\}}.
\tag{2.3}
\]
The same `v` appears at every site of (2.1), preserving the true dependence.

A one-defect edge state is `(x,g,j)` with `g_j=0`, representing the ordered pair of fronts
\[
g\le h=g+e_j.
\]
The inherited disagreement-flux theorem says a synchronous update either absorbs this discrepancy or leaves exactly one discrepancy. Thus the nonabsorbed edge states form a finite substochastic kernel `Q_m`. The formal edge-state count is
\[
|E_m|=m2^{2m-1}.
\tag{2.4}
\]

Define the exact survival profile
\[
h_t:=Q_m^t\mathbf1,
\qquad
\alpha_t:=\|h_t\|_\infty.
\tag{2.5}
\]
Thus `h_t(e)` is the exact probability that an edge starting from `e` survives `t` common source updates.

For a burn-in `T`, define as in the preceding R17 report
\[
\lambda_T:=
\max_{e:h_T(e)>0}\frac{(Q_mh_T)(e)}{h_T(e)}.
\tag{2.6}
\]
Then
\[
Q_mh_T\le\lambda_T h_T,
\qquad
h_{T+k}\le \alpha_T\lambda_T^k\mathbf1.
\tag{2.7}
\]
All quantities are exact rationals when evaluated by word counts.

## 3. Attack 1 succeeds: profile-summed finite-time theorem

### Theorem 3.1 — full-profile coupling certificate

Assume `lambda_T<1`. For every strip initial state `s`, every horizon `N`, and the stationary width-`w` average reward `gamma_w`,
\[
\boxed{
\left|\mathbf E_sR_N-N\gamma_w\right|
\le C_m^{\rm prof}(T)
}
\tag{3.1}
\]
where
\[
\boxed{
C_m^{\rm prof}(T)
:=m+
\sum_{t=0}^{T-1}\min\{1,m\alpha_t\}
+
\frac{m\alpha_T}{1-\lambda_T}.
}
\tag{3.2}
\]
When `m alpha_T<1`, (3.2) is strictly no worse than the preceding coarse certificate
\[
m+T+\frac{m\alpha_T}{1-\lambda_T},
\tag{3.3}
\]
and is strictly better whenever `m alpha_t<1` for at least one `t<T`.

### Proof

Couple the strip chain started from `s` to a stationary copy using the same future source pairs. After exactly `m` updates, their raw `x` windows are identical, because both windows consist only of the same appended `u` bits.

For this common raw word, monotonicity in the gradient sandwiches both gradients between the formal extremal fronts `0^m` and `1^m`. Connect those extremal fronts by the monotone Hamming path of exactly `m` single-defect edges. Drive every adjacent pair in this path by the same future source sequence. The inherited one-defect theorem implies that each path edge evolves according to `Q_m` until absorption and can never branch.

For a fixed path edge, the probability of still being alive after `t` further source updates is at most `alpha_t`. No independence among the `m` path edges is required. By the union bound,
\[
\Pr\{\tau_{\rm ext}>t\}
\le\min\{1,m\alpha_t\},
\tag{3.4}
\]
where `tau_ext` is the additional time until all extremal path edges have coalesced. If all path edges have coalesced, the extremal fronts agree, hence the two genuine coupled chains agree as well.

From (2.7), for `k>=0`,
\[
\alpha_{T+k}\le\alpha_T\lambda_T^k.
\tag{3.5}
\]
Therefore
\[
\begin{aligned}
\mathbf E\tau_{\rm ext}
&=\sum_{t\ge0}\Pr\{\tau_{\rm ext}>t\}\\
&\le
\sum_{t=0}^{T-1}\min\{1,m\alpha_t\}
+
\sum_{k\ge0}m\alpha_T\lambda_T^k\\
&=
\sum_{t=0}^{T-1}\min\{1,m\alpha_t\}
+
\frac{m\alpha_T}{1-\lambda_T}.
\end{aligned}
\tag{3.6}
\]
Including the initial `m` raw-window shifts gives expected total coupling time at most (3.2). The one-step reward lies in `[0,1]` and agrees after coalescence, so the absolute difference of the two expected cumulative rewards is bounded by the expected coupling time. The stationary copy contributes exactly `N gamma_w`. This proves (3.1). QED.

The gain is conceptual as well as numerical: the early-time survival profile is exact information and should not be replaced by a flat unit bound merely because a later Collatz potential is used for the tail.

## 5. Attack 2 fails: no very-short universal hazard at the checked widths

A tempting stronger route is to replace the detailed profile by a fixed short-horizon hazard. Define
\[
G_m(0)=E_m,
\]
and recursively
\[
G_m(r+1)=
\{e\in E_m:
\delta_a(e)\in G_m(r)\text{ for all four source letters }a\},
\tag{5.1}
\]
where absorption is not an element of `G_m(r)`. Thus `e in G_m(r)` means the defect survives **every one of the `4^r` source words of length `r`**. In particular, if `G_m(r)` is nonempty then
\[
\alpha_r=1.
\tag{5.2}
