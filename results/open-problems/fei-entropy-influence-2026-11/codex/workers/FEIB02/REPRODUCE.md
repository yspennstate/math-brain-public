# Reproducing the computation

Run from this worker directory. The C code uses GMP; the recorded Mac installation has its headers and libraries under /opt/homebrew. Python uses mpmath, NumPy and matplotlib. Every numerical C program is single-threaded. Run at nice 10 or below, with no more than two numerical workers at once and each process below 3 GiB. The launch environment of this run already had nice 10.

Compile:

```sh
clang -O3 -Wall -Wextra census.c -o census
python3 generate_quantlog.py --check
clang -O3 -Wall -Wextra census_cert.c -o census_cert
clang -O3 -Wall -Wextra -I/opt/homebrew/include -L/opt/homebrew/lib threshold_dense.c -lgmp -o threshold_dense
clang -O3 -Wall -Wextra -I/opt/homebrew/include -L/opt/homebrew/lib parity_dense.c -lgmp -o parity_dense
clang -O3 -dynamiclib -I/opt/homebrew/include -L/opt/homebrew/lib polyconv.c -lgmp -o polyconv.dylib
```

The finite census and integer-only proof checks:

```sh
python3 run_census.py > census_progress.log
python3 run_certificates.py > certificate_final_progress.log
python3 audit_candidates.py > candidates_audit.log
python3 audit.py > audit.log
```

The two dimension-dense structured sweeps:

```sh
python3 run_dense.py > dense_progress.log
python3 run_parity_dense.py > parity_dense_progress.log
```

These runners save each dimension and resume from the last saved complete row. The parity runner rebuilds its exact coefficient matrix, skipping already recorded metric calculations. The matrix is allocated in memory, not on disk. It prints an allocation estimate before starting and records peak RSS at exit. A checkpoint reconstruction is tested by the n=10..16 resume comparison.

The independent structured calculation and searches:

```sh
python3 thresholds.py > thresholds_progress.log
python3 parity_thresholds.py > parity_v3_progress.log
python3 general_search.py > hill_progress.log
python3 search_A.py > hill_A_progress.log
python3 refine_gamma.py > gamma_refinement_progress.log
python3 balanced_search.py > balanced_v2_progress.log
```

General search uses 32 proposals per objective and dimension, after three starts; the separate A search uses 16. The periodic Gamma refinement uses 32 width/phase choices plus its initial witness. Balanced searches use eight paired-coordinate proposals after two starts, with the ratio over I-1 as their objective. These finite budgets do not certify large-dimensional optima. Random seeds and full value vectors are saved in the scripts and output files.


After the dense runs and checks finish:

```sh
python3 make_results.py
python3 plot_results.py
python3 make_report.py
```

The last command refuses to write a final report unless both complete dimension ranges, the integer certificates, principal audit logs, the figure and the measured memory limit are present. Existing result files cause the resumable scripts to skip completed work. Move only this worker's old outputs aside if a fully fresh replay is wanted.

The rigorous finite supremum certificates add:

```sh
python3 generate_interval_log.py > interval_log_generation.log
clang -O3 -Wall -Wextra interval_log_probe.c -o interval_log_probe
clang -O3 -Wall -Wextra census_interval.c -o census_interval
python3 audit_interval_log.py > interval_log_audit.json
python3 run_interval_census.py > interval_census_progress.log
python3 audit_interval_census.py > interval_census_audit.log
python3 certify_suprema.py --verify-only > suprema_certificate_verification.log
```

The last command uses the saved product-checked integer decompositions and proves all extremal ties and 100 decimal places without a factor-search library. For a fresh decomposition build, run certify_suprema.py without --verify-only; SymPy is used to find decompositions, whose products are then checked exactly. suprema_certified.json is the final source of the values in extrema.csv.

The final tightened B envelope constant is regenerated by:

```sh
python3 sharpen_B_envelope.py > B_final_constant_certificate.json
```

This supersedes only the convenient rounded B constants in the earlier constant-check files; it uses the same analytic lemmas and finite seed.
