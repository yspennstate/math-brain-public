T104 (G. Alon, arXiv 2610.22151, Conjecture 1.5, the 2/3 Specht-module conjecture), pair tau = [2,1^(n-2)], sigma = [2,2,1^(n-4)], two-eigenvalue family of the gap-weighted state: is Psi(x) >= 0? 11 Nov 2026, an agent. Continues [[t104_two_eigenvalue_family_psi_split_2026_11_11]] and [[t104_alon_two_thirds_conjecture_n4_proved_dual_form_2026_11_11]].

Answer. Yes for n = 5, 6, 7, 8 (two independent exact computations) and n = 9, 10 (one reader of the ray construction; n = 10 is 21 rays, 3,108,067 monomials, 0 negative, cone_recheck2.py); yes for every n when at most 10 coordinates are nonzero, when m >= 1/(n(n-1)), or when x takes at most three distinct values (the last has one reader). Open (after the later note at the end): n >= 14 with at least fourteen nonzero coordinates, four or more distinct values and m < 1/(n(n-1)). The route "Phi' >= 0 for all n" is dead: Phi' < 0 at n = 14.

How the finite cases go. By symmetry take x_1 >= ... >= x_n, x_1 + x_n >= 0. Then n(n(n-1)S^2 - 1) Psi >= Phi' with S = x_1, and the degree-8 homogenisation H of Phi', written in the extreme rays of that cone (r_j = (n-j repeated j times, -j repeated n-j times) with n - 2j >= 0, and (2j-n) r_i + (n-2i) r_j with n-2i > 0 > n-2j), has no negative coefficient: 1,277 / 2,991 / 75,561 / 125,947 / 2,220,039 monomials at n = 5..9. Found by a Codex prover (sympy), recomputed with integer dictionaries and no shared code (cone_recheck.py; n = 9 takes 355 s on Mac mini 1). Zero only on the star and edge rays.

Zero padding (prover). Psi_n = C_n m - ((n-4) t + 2B), C_n = (n-1)(n^2 + (rho-5) n + 6), rho = 2q - 1, B = p^2, t = 2B - rho; C_n increases and (n-4)/C_n, 1/C_n decrease for n >= 5, so Psi_n(x) >= 0 gives Psi_(n+1)(x, 0) >= 0. A certificate at n covers all vectors with at most n nonzero coordinates.

Why Phi' fails. y = (s, 1 x s, -s, -s), n = s + 3: H = -2 s^2 (s-1)(s+1)^4 (s+3)(s^2 - 11s + 6)(s^2 + 4s - 1), negative from s = 11. At n = 14: Phi' = -357073920/10106041, Psi = 28579680/54043 > 0, m = 11/34 against the bound M = 1/374. The bound m >= M is sharp only when one coordinate carries the largest modulus; with two large coordinates of one sign it loses a factor of a hundred. Rechecked in exact rationals (phi_fails_n14_check.py).

Lesson for the method. A coefficient certificate that passes at n = 5..9 says nothing about n = 14: before writing "one finite computation per n" test the auxiliary bound on families with the extremal coordinate repeated (two-, three-value vectors with integer multiplicities growing with n). The prover found the failure by reducing the minimiser of Phi' to few distinct values and then scanning that family in closed form; I had only tested random points up to n = 12, where Phi' is still nonnegative.

Referee (Codex, same morning) on HOOKS_AND_TWO_ROWS.md and GAP_STATE_FORM.md: identities CORRECT; WRONG: "P(xy) spans V_22 for every x" (n = 4 edge vector: image of dimension 1), the theta interval [0, 0.18] at the n = 5 edge vector (it is [0, 1]), "equality needs every g_k = lam" (all g_k = 0 also); GAP: the covariance state needs normalisation by Z = 1 - 2n kappa/(n-2) and a limit argument where Z = 0; the n = 8 width-two pairs need their own constructions. All corrected in the notes, marked [referee].

Later, 11 Nov 07:3x. Third implementation cone_dense.c (C, 128-bit integers, dense arrays by monomial rank, overflow bound tracked, identity checked at three random points mod 2^61 - 1) with the rays found by brute-force vertex enumeration (rays_enum.py, agrees with the closed formula for n = 5..14) reproduces every count for n = 5..10 and gives n = 11: 38,607,965 nonzero of 38,608,020 monomials, n = 12: 48,903,435 of 48,903,492, and (cone_chunk.c, product formed chunk by chunk, 1,113 s on one core of Mac mini 2) n = 13: 450,977,988 of 450,978,066, all with 0 negative coefficients, zero pure powers only on the star and edge rays. So Psi >= 0 for n = 5..13 and for any n with at most thirteen nonzero coordinates. n = 13 is the last n this certificate can reach (Phi' < 0 at n = 14). n = 11, 12, 13 have one program and one ray derivation behind them. Zero padding is in Lean (an agent, 06_math_research/lean_checks_agent/t104_pad, b78e4e14). A family for every n: x = (a, -tau, -t x k, -b, 0 x j), a = tau + k t + b, 0 <= tau <= t <= b; with tau = z1, t = z1 + z2, b = z1 + z2 + z3 the sextic T^3 Psi has all 27 coefficients nonnegative as polynomials in k - 2 and j (or j - 1 at k = 1), strictly positive except z3^6 (absent, the edge) and z1^6 (factor j, the star); checked exactly against the definition at 300 random points (one_positive_family2.py, one_positive_eq.py). The lesson that carried the method from n = 10 to n = 13: store a homogeneous polynomial densely by multiset rank and form a big product in chunks keyed by the smallest index; the dictionary version needed 1.1 GB at 3 million monomials, the dense one about 1.4 GB at 451 million.
