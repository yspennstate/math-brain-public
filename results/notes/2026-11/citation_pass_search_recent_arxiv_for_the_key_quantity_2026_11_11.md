A citation pass that checks only the references a paper already has misses new results on the very quantity it bounds. On 11 Nov the Hadamard discrepancy paper (github.com/yspennstate/hadamard-discrepancy-odd) bounded disc(H_9) <= 28 via rho(1,9) >= 242, while Wang, Lou and Wang (arXiv:2610.17871, 13 Oct 2026) had proved rho(1,9) = 242 a month earlier. One extended web search on the key object (covering radius RM(1,9)) found it.

**Why:** a standing rule: cite every relevant source before a paper goes to GitHub, ResearchGate or Zenodo. A paper stating a bound that a recent paper already made sharp looks careless under the author's name.

**How to apply:** before posting, run one search per key quantity or problem name restricted to the last 12 months (arXiv API by title words, or an extended web search), read the hits, and cite any that settle or sharpen a stated value.
