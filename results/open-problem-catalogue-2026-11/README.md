# Open-problem catalogue, November 2026

A list of 1,128 open problems in probability, networks and the theory of computation, gathered from problem lists, surveys and papers between 15 and 16 November 2026. Each row gives the source, the section or page where the problem is stated, a short quote from the fetched page, and a dated search for a later solution.

- `CATALOGUE.md` lists the problems by source, one line each, with a link to the source.
- `catalogue.jsonl` holds the full records, one JSON object per line.

Status values: `checked_open` (the quote was found on the fetched page and the search found no accepted solution), `needs_check` (the quote could not be confirmed automatically, usually because it is inside a PDF), `solved_elsewhere` (a paper already settles it; the row cites it in `status_note`), `attempt_in_progress`.

A search that finds nothing does not prove a problem is still open. Before working on a row, read its source and search again.
