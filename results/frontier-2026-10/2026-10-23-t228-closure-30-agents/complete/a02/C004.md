# Target 1 with raw inputs and an explicit Lipschitz feature encoder

Claim T336-w727-C004 v1. Rung: proof (unaudited), subject to recorded checks and dependent on unaudited C002 v1. No Lean certification or independent audit is claimed. This gives a quantitative raw-input subclass of Target 1, rather than assuming exact feature computation outside the size count.

The hardest steps are the explicit residual-MLP encoder and the perturbation budget linking its feature errors to the original GP predictive distribution. The proof does not use a triangle inequality for KL.

## 1. Assumptions and explicit size

Fix integers d,p>=1,n>=0, real s>0, B>=0,R>=0,K>=0,eps>0. The raw domain is X=[0,1]^d. The fixed zero-mean GP prior has kernel k(x,x')=z(x)^T z(x'), where z:X->R^p satisfies ||z(x)||_2<=R and, for each coordinate j,

    |z_j(x)-z_j(x')|<=K ||x-x'||_1.

The observation noise is independent N(0,s). Context labels satisfy |y_i|<=B, and contexts have length t<=n. The target is the predictive law of a new noisy observation. The input encoding supplies only raw coordinates, labels, two binary role flags (context and query), and fixed constants. Zero padding fixes N=n+1 tokens. A padding token has raw coordinates zero and both flags zero; the query has only its query flag set; actual context tokens have only their context flag set. No label is supplied for the query.

Define the following fixed constants:

    S=R+1,
    C_A=n(2R+1),
    C_m=nB[(R+S)/s + S C_A R/s^2],
    C_v=R+S+S^2 C_A/s > 0,
    eta=min(1, sqrt(s eps)/(2(1+C_m)), s sqrt(eps)/(2 C_v), s/(4 C_v)),
    eps0=min(eps/4,1/16),
    m=max(1,ceil(K d sqrt(p)/eta)), J=(m+1)^d, E=3+ceil(log_2 J).

For the solver set

    kappa=1+max(1,n)S^2/s, M=nS^2B/s,
    delta0=min(1/2,s/(2S^2),sqrt(s eps0)/(1+M),s sqrt(eps0)/S^2),
    T=ceil(sqrt(kappa) log(2/delta0)/2).

There is a residual normalized ReLU-attention transformer (Bai et al. Definition 1 and Definition 2) with

    token width D=7p+6+d+Jd+pJ,
    depth L_total=E+T+2=T+5+ceil(log_2 J),
    at most five attention heads per layer,
    tokenwise MLP hidden width at most H=2Jd+pJ+4p+1,

whose Gaussian output satisfies forward KL<=eps uniformly over all these raw-input contexts and queries. A dense parameter upper bound is

    L_total(15D^2+2DH)+2D.

Fixed affine input placement is not counted; all nonlinear feature computation is counted. Every weight is specified below or in C002 v1 and depends only on the fixed prior feature map (through finitely many grid samples) and the displayed bounds, never on observed contexts, query labels, or future data. This is a real-weight size theorem, not a finite-bit complexity theorem or training guarantee.

## 2. Posterior perturbation caused by an approximate feature map

First suppose a map ztilde satisfies sup_x ||ztilde(x)-z(x)||<=eta<=1. Then ||ztilde||<=R+eta<=S. For any fixed admissible context and query, put

    A=sI+sum_i z_i z_i^T, b=sum_i z_i y_i, q=z(x_*),
    Atilde=sI+sum_i ztilde_i ztilde_i^T, btilde=sum_i ztilde_i y_i, qtilde=ztilde(x_*).

Both matrices are symmetric positive definite with inverse operator norm <=1/s. For vectors u,v,

    ||uu^T-vv^T||_op
      =||(u-v)u^T+v(u-v)^T||_op
      <=||u-v|| (||u||+||v||).

Thus

    ||A-Atilde||<=n(2R+eta)eta<=C_A eta,
    ||b-btilde||<=nB eta, ||b||<=nRB,
    ||A^{-1}-Atilde^{-1}||
      =||A^{-1}(Atilde-A)Atilde^{-1}||<=C_A eta/s^2.

The true and perturbed noisy predictive parameters are

    mu=q^T A^{-1}b, v=s+s q^T A^{-1}q,
    mutilde=qtilde^T Atilde^{-1}btilde,
    vtilde=s+s qtilde^T Atilde^{-1}qtilde.

Both variances are >=s. Add and subtract qtilde^T A^{-1}b and qtilde^T Atilde^{-1}b. Cauchy-Schwarz and the preceding bounds give

    |mu-mutilde|
      <=eta nRB/s + S C_A eta nRB/s^2 + S nB eta/s
      =C_m eta.

For the variance, first replace both q factors while retaining A^{-1}, and then replace the inverse. This gives

    |v-vtilde|
      <=s[eta(R+S)/s+S^2 C_A eta/s^2]=C_v eta.

The definition of eta ensures

    |mu-mutilde|<=sqrt(s eps)/2,
    |v-vtilde|<=min(s/4,s sqrt(eps)/2).

No probabilistic context distribution or independence between observed features is needed here.

## 3. A finite-grid cone encoder

Let G={0,1/m,...,1}^d, so |G|=J. For each feature coordinate define

    ztilde_j(x)=min_{a in G}[z_j(a)+K sum_{r=1}^d |x_r-a_r|].

The Lipschitz assumption shows every term in this minimum is >=z_j(x). Choose a nearest grid point coordinate by coordinate; its L1 distance is <=d/(2m). The same Lipschitz bound then gives

    0<=ztilde_j(x)-z_j(x)<=Kd/m.

Consequently ||ztilde(x)-z(x)||<=sqrt(p)Kd/m<=eta. This also holds for K=0, when the error is zero and m=1. In particular |ztilde_j(x)|<=||ztilde(x)||<=S on the whole input cube.

The encoder is exact as an implementation of this finite minimum, including all absolute values. It is not a numerical approximation to the finite minimum.

## 4. Exact tokenwise residual-MLP construction

Use the 7p+4 core registers of C002. Add d registers for raw x, Jd zero-initialized absolute-value registers, pJ zero-initialized cone registers, and two role flags. This is D=7p+6+d+Jd+pJ. Initially the feature registers z_c,z_q are zero. The core constant is one=1; the variance-output register starts at s, and the query/padding label register is zero. Encoder MLP layers preserve raw x, the flags, and all core constants.

Each MLP has the residual form h^+=h+W2 ReLU(W1 h), with a constant register implementing affine biases. All unspecified matrix entries are zero. The attention block in each encoder layer is the identity (all value matrices zero).

Layer 1 uses 2Jd hidden units for ReLU(x_r-a_r) and ReLU(a_r-x_r), for all a in G,r. Their sums are written into the initially zero absolute-value registers, yielding |x_r-a_r| exactly.

Layer 2 uses Jd identity-ReLU units on the nonnegative absolute registers and one unit on the constant one. Its output matrix writes

    F_{j,a}=z_j(a)+K sum_r |x_r-a_r|

into each initially zero cone register. Negative fixed grid values cause no difficulty: they occur in the output matrix applied to the constant unit.

Next compute the minimum independently for each coordinate j by a balanced binary tournament on the J cone registers. A pair of current registers u,v is replaced in the first slot by

    u-ReLU(u-v)=min(u,v),

leaving the other slot unused thereafter. This is one residual MLP unit: W1 reads u-v and W2 subtracts its ReLU from the u register. Distinct pairs at the same level use disjoint output slots. An unpaired register passes unchanged. After ceil(log_2 J) levels one designated cone slot contains ztilde_j(x). Each level uses at most p floor(J/2) units, bounded by pJ. This works for signed cone values and for every J, not only powers of two.

One final gating layer writes the feature registers. For any |f|<=S and binary flag r define

    g(f,r)=ReLU(f+S(r-1))-ReLU(-f+S(r-1)).

If r=1, this equals f; if r=0, both arguments are <=0 and it equals zero. Apply g to every computed feature with the context flag to populate z_c, and with the query flag to populate z_q. The registers start at zero, so the residual connection adds precisely the desired values. This uses 4p units. Query, padding, and context feature routing now matches C002 exactly. Both flags and the raw x registers are preserved throughout.

There are E=3+ceil(log_2 J) MLP encoder layers. The stated H bounds every hidden width. Biases are realized through the constant register, rather than being omitted from the construction. All grid feature values are fixed weights of the known prior; no context-dependent parameter is selected.

## 5. Solver composition and KL budget

Apply C002 v1 to ztilde with feature bound S and accuracy eps0. Its core 7p+4 registers embed in the larger width D; all additional registers are preserved by zero extension of its matrices. The solver uses its one-head broadcast layer, T five-head Chebyshev layers, and four-head readout layer. All solver MLPs are identities. The resulting parameters muhat,vhat obey

    vhat>=s,
    |mutilde-muhat|<=sqrt(s eps0)<=sqrt(s eps)/2,
    |vtilde-vhat|<=s sqrt(eps0)<=min(s/4,s sqrt(eps)/2).

Combine these with Section 2 using ordinary triangle inequalities for scalar errors, not for KL:

    |mu-muhat|<=sqrt(s eps),
    |v-vhat|<=min(s/2,s sqrt(eps)).

Since v,vhat>=s, put h=(v-vhat)/vhat in [-1/2,1/2]. As proved directly in C002 Section 5,

    KL(N(mu,v)||N(muhat,vhat))
      <=(mu-muhat)^2/(2s)+(v-vhat)^2/(2s^2)<=eps.

The depth is E+T+2. There are at most five heads, each with three D-by-D matrices. Counting two D-by-H/H-by-D MLP matrices at every layer, even when they are zero, and a two-coordinate linear readout, gives the stated dense parameter bound.

## 6. What this does and does not settle

This is a quantitative raw-input theorem for every bounded finite-rank GP feature map satisfying the displayed Lipschitz assumption, in every fixed input dimension. It counts the encoder rather than treating it as a free feature oracle. The bound is deliberately explicit and can be very large because J=(m+1)^d.

C003 shows that dropping all raw-feature regularity makes the literal bounded-kernel statement false for continuous Gaussian-output transformers. C004 therefore supplies a precise constructive assumption, while C002 remains the smaller theorem when features are supplied directly.

The finite-grid envelope and ReLU min/max identities are classical elementary constructions, not claims of new approximation theory. The claimed target contribution is their fully costed composition with the accelerated posterior solver and a uniform original-posterior forward-KL budget. C004 remains a proof candidate dependent on C002 until independent review passes both exact versions.
