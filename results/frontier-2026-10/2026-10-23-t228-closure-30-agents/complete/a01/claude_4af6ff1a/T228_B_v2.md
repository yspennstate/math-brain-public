## Setting
- Leaky ReLU: sigma(z) = max(z, beta z) with 0 <= beta < 1.
- Data: a ~ N(0,1) and y = sigma(a x*) + eps, with eps ~ N(0, s^2), s > 0, independent of a.
- Step: x_{k+1} = Psi_k(x_k) = x_k - c sum_{i<=b} sigma'(a_i x_k)(sigma(a_i x_k) - y_i) a_i, where c = eta/b and each
  step uses fresh i.i.d. samples (a_i, y_i), i <= b.
- Derivative: sigma'(z) = 1 for z > 0 and beta for z < 0. The value gamma := sigma'(0) may be any number in [beta, 1].
- Notation: w(a) = 1{a>0} + beta 1{a<0} and S_+ = sum_i w(a_i)^2 a_i^2, S_- = sum_i w(-a_i)^2 a_i^2.
- Slopes: A^+ = 1 - c S_+ and A^- = 1 - c S_-.
- Offsets: Q^+ = c sum_i w(a_i) a_i y_i and Q^- = c sum_i w(-a_i) a_i y_i.

**Theorem.** Assume (S'): E log|A^+| < 0. If gamma > 0, the chain has exactly one stationary law pi. If gamma = 0
(possible only when beta = 0), it has exactly two extremal stationary laws, delta_0 and one law pi on R \ {0}, and the
stationary laws are exactly l delta_0 + (1-l) pi, 0 <= l <= 1. In both cases, with kappa > 0 the
unique positive root of E|1 - c S_+|^kappa = 1,

    t^kappa pi((t, oo)) -> C   and   t^kappa pi((-oo, -t)) -> C,

with the same constant C > 0 for both signs. If (S') fails there is no root and the conclusion fails as stated (for
beta -> 1, target 1's counterexample at b = 2, eta = 100 applies). kappa < 2 holds on a nonempty interval of c for every
b and every beta (section 5).

The index does not depend on the sign of x, and neither does the constant. This holds even though the offsets do
depend on the sign: Q^+ and -Q^- are not equal in law when x* != 0. The dossier's SHAPE paragraph treats the sign as a
Markov modulation that is not independent of the jumps. In fact the multiplier chosen by the sign is independent of
the current state (section 2), so the modulation is harmless.

## 1. The map is piecewise affine
- For x > 0: a_i x > 0 exactly when a_i > 0. So sigma'(a_i x) = w(a_i) and sigma(a_i x) = w(a_i) a_i x, which gives
  Psi(x) = A^+ x + Q^+.
- For x < 0, likewise: Psi(x) = A^- x + Q^-.
- At x = 0: Psi(0) = c gamma sum_i a_i y_i.

So ABB's standing bound (4), sup_x |Psi(x) - Lambda(x)| <= B with Lambda(x) = A^{sgn x} x, holds with
B = max(1, c sum_i |a_i||y_i|), since w <= 1 and gamma <= 1. Since |y_i| <= |x*||a_i| + |eps_i|, B has moments of every
order, and so do A^+ and A^-.

Psi is continuous except at 0. Its one-sided limits there are Q^+ and Q^-, which differ when beta < 1. ABB's assumption
(1) (Psi a.s. continuous) therefore fails at the single point 0; section 4 deals with this.

## 2. The key symmetry
Write N = (a_1..a_b). Then S_- is S_+ evaluated at -N, and -N has the law of N, so A^- has the same law as A^+ =: A.

Let x be independent of the step's data and put m := A^{sgn x} (A^+ when x = 0). For Borel sets D and E,

    P(m in D, x in E) = P(A^+ in D) P(x in E, x >= 0) + P(A^- in D) P(x in E, x < 0) = P(A in D) P(x in E).

So the multiplier the chain actually uses is independent of the current state and has a fixed law, whatever the sign.
The offset q := Q^{sgn x} is not independent of x; nothing below needs it to be.

## 3. Existence, uniqueness and moments
- **Root.** The function h(q) = E|A|^q is finite for all q >= 0, strictly log-convex (A is not a.s. of constant
  modulus), h(0) = 1 and h'(0) = E log|A| < 0. Since P(|A| > 1) > 0, h(q) -> oo. So there is exactly one kappa > 0
  with h(kappa) = 1, and h < 1 on (0, kappa).
- **Drift.** Take p in (0, min(1, kappa)). By section 2 and subadditivity,
  E|Psi(x)|^p <= h(p)|x|^p + E B^p with h(p) < 1. This is Foster's condition for V = 1 + |x|^p.
- **Minorization.** Fix K and C0 = [-K, K].
  - For x in (0, K], use the event E1 = {a_i in [1, 2] for all i}. Given N on E1, Psi(x) is Gaussian with mean
    bounded uniformly in x in C0 and variance c^2 s^2 sum_i a_i^2 >= c^2 s^2 b.
  - For x in [-K, 0), use E2 = {a_i in [-2, -1] for all i}, where w(-a_i) = 1. This gives the same bounds.
  - When gamma > 0, x = 0 is covered by the same events: there Psi(0) is Gaussian with variance at least
    (c gamma s)^2 b.
  - So P(x, .) >= delta Leb(. ∩ C0) for x in C0, and the chain is Lebesgue-irreducible and aperiodic.
  - For beta > 0, P(x, .) has a density for every x != 0 (and for x = 0 when gamma > 0): given N, Q^{sgn x} carries the
    Gaussian term c sum_i w(±a_i) a_i eps_i with variance c^2 s^2 S_± > 0.
  - For beta = 0 it does not. When every a_i has the wrong sign (probability 2^-b), S_± = 0 and Q^± = 0, so Psi(x) = x:
    P(x, .) = 2^-b delta_x + (an absolutely continuous part). Irreducibility and aperiodicity come from the
    minorization and are unaffected.
  - Positive Harris recurrence then gives a unique invariant pi. It is absolutely continuous: write pi = pi_a + pi_s
    (Lebesgue decomposition). Only the atoms delta_x contribute to the singular part of pi P, so pi_s = 2^-b pi_s for
    beta = 0 (and pi_s = 0 directly for beta > 0); hence pi_s = 0. The minorization on every C0 gives full support; in
    particular the support is unbounded and pi({0}) = 0.
- **The case gamma = 0, beta = 0.** Psi(0) = 0, so delta_0 is invariant. From x != 0, P(Psi(x) = 0) = 0 (the atom of
  P(x, .) sits at x, the rest is absolutely continuous), so R \ {0} is absorbing and avoids 0. The argument above, run
  on R \ {0}, gives the second law pi. The state space splits into the two absorbing sets {0} and R \ {0}, each with a
  unique invariant law, so every stationary law is l delta_0 + (1-l) pi and the two are the extremal ones.
- **Moments.** E_pi|x|^r < oo for every r < kappa. Run the chain from x_0 = 1. Section 2 applies at every step
  because the step's data is independent of x_k. So
  - ||x_{k+1}||_r <= h(r)^{1/r} ||x_k||_r + ||B||_r for r >= 1 (Minkowski);
  - E|x_{k+1}|^r <= h(r) E|x_k|^r + E B^r for r < 1.

  Hence sup_k E|x_k|^r < oo. Since x_k converges to pi in total variation, Fatou finishes.

## 4. The tail: ABB Theorem 2.1 and Proposition 8.1, with continuity replaced
**The Cramer matrix.** ABB's matrix (8) has
- p_{--} = E|A^-|^t 1{A^->0} and p_{-+} = E|A^-|^t 1{A^-<0};
- p_{+-} = E|A^+|^t 1{A^+<0} and p_{++} = E|A^+|^t 1{A^+>0}.

Since A^- and A^+ have the same law, this is [[d, o], [o, d]] with d(t) = E|A|^t 1{A>0} and o(t) = E|A|^t 1{A<0}.
- P(A < 0) > 0 (A < 0 whenever S_+ > 1/c, and S_+ is unbounded), so this is the irreducible Case 1.
- rho(t) = d + o = h(t), so (12) is h(kappa) = 1.
- The eigenvectors are u = (1/2, 1/2) and v = (1, 1).
- (13): the moments in section 1.
- (14): the self transitions (A > 0) have positive tilted probability, and on them log A has an absolutely continuous
  part. This holds even for beta = 0, where A = 1 with probability 2^-b: A is continuous on {0 < S_+ < 1/c}, an event of
  positive probability. An absolutely continuous increment lies in a shifted lattice with probability 0, so the lattice
  event has probability < 1.

**Conclusion.** Theorem 2.1 gives the limits (15) for any stationary law, with u_+ C_- = u_- C_+ by (16), so C_+ = C_-.
Proposition 8.1 gives C_+, C_- > 0, because pi has unbounded support.

**Continuity.** ABB's hypothesis (1) (Psi a.s. continuous) fails at x = 0. In the arXiv v2 text (sha256 ec099b50...,
the same file as w688's source) the word "continuous" applied to Psi occurs only at:
- (1) itself, used for "has the Feller property" (line after (2));
- Prop. 9.1, the existence of a stationary law ("is also a Feller chain").

Sections 3-8 (the comparison with the linear system Lambda, the Markov renewal argument, the proofs of Theorem 2.1 and
Proposition 8.1) work with (4), Lip(Lambda_n) and the invariance of nu, for ANY stationary distribution nu. Existence
here comes from section 3 (Harris), not from Feller. So the jump at the single point 0 is never used. REVIEW POINT 1:
check this reading of ABB sections 3-8, in particular that no step uses continuity of Psi (as opposed to Lambda) or the
Feller property.

**Fallback if a reviewer finds continuity used.** Section 2 makes Goldie's implicit renewal theorem (Ann. Appl. Probab.
1991, Thm 2.3, the case P(M < 0) > 0) apply directly, with M = m independent of R ~ pi:
- the two difference integrals are at most E|((mR+q)^+)^k - ((mR)^+)^k|/k, finite by the moments of section 3;
- this gives both limits, equal to the same C >= 0, with no continuity hypothesis;
- only C > 0 would then rest on ABB section 8.

## 5. kappa < 2 on an interval
Let mu = E w(a)^2 a^2 = (1+beta^2)/2 and nu4 = E w(a)^4 a^4 = 3(1+beta^4)/2. Then

    E A^2 = 1 - 2 c b mu + c^2 (b nu4 + b(b-1) mu^2),

so E A^2 > 1 exactly when c > c_0 := 2 mu / (nu4 + (b-1) mu^2).

At c = c_0, Jensen gives E log|A| <= (1/2) log E A^2 = 0, with strict inequality because |A| is not a.s. constant.
E A^2 is a polynomial in c. For E log|1 - cS_+|: S_+ has an atom at 0 only (where the integrand is 0) and otherwise a
density f bounded on compact subsets of (0, oo), so for c in a compact subset of (0, oo), substituting u = cs gives
E log|1 - cS_+| = ∫ log|1 - u| f(u/c) c^-1 du (the atom contributes 0), and dominated convergence (log|1 - u| is locally
integrable, f(u/c)/c is bounded near u = 1 uniformly in c, and log(1 + u) dominates the tail against the moments of
S_+) makes it continuous in c. Both sides are therefore continuous in c, so on (c_0, c_0 + delta) we have (S'), h(2) > 1, and hence kappa < 2. This holds for every
b >= 1 and every beta in [0, 1).
