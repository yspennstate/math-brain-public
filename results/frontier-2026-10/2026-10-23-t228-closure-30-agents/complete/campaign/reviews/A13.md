## Analytic quadrature error, including the cusp

Set \(u=|1-\eta x^2|\) and \(f(x)=u^p e^{-x^2/2}\).
For \(1<p\leq2\), \(f'\) is continuous at
\(x=\eta^{-1/2}\), with value zero there, and is absolutely continuous
on compact intervals. Its second derivative has only an integrable
\(|x-\eta^{-1/2}|^{p-2}\) singularity when \(p<2\).
Away from that point,

\[
|f''(x)|\le e^{-x^2/2}\bigl[
4p(p-1)\eta^2 x^2 u^{p-2}
+2p\eta u^{p-1}
+4p\eta x^2u^{p-1}
+(x^2+1)u^p\bigr].
\]

Write \(b=101/100\) and
\(c_G=\int_0^\infty e^{-x^2/2}\,dx=\sqrt{\pi/2}<13/10\).
For the first term, split at \(t=\eta x^2=2\).
On \(0\le t\le2\), the substitution gives

\[
4p(p-1)\eta^2\int x^2u^{p-2}e^{-x^2/2}dx
\le 2p(p-1)\sqrt\eta\sqrt2
\int_0^2|1-t|^{p-2}dt
=4p\sqrt{2\eta}<12.
\]

On \(t\ge2\), \(u\ge1\), so \(u^{p-2}\le1\); the remaining
contribution is at most \(8b^2c_G\). For the other terms use

\[
u^{p-1}\le1+u\le2+\eta x^2,
\qquad
u^p\le1+u^2\le2+2\eta x^2+\eta^2x^4.
\]

The half-Gaussian moments of orders \(0,2,4,6\) are
\(c_G,c_G,3c_G,15c_G\). Consequently

\[
\begin{aligned}
\int_0^\infty|f''(x)|dx
&<12+8b^2(13/10)+4b(13/10)(2+b)\\
&\quad+8b(13/10)(2+3b)
+(13/10)(4+8b+18b^2)\\
&=\frac{6541351}{50000}=130.82702<140.
\end{aligned}
\]

For a mesh interval \([a,a+\Delta]\), integration by parts twice gives
the trapezoidal error kernel
\((x-a)(a+\Delta-x)/2\), whose maximum is \(\Delta^2/8\).
Absolute continuity above makes this valid even on the interval containing
the cusp. Thus the composite trapezoidal sum on \([0,10]\) obeys

\[
\left|\int_0^{10}f(x)dx-T_\Delta(f)\right|
\le \frac{\Delta^2}{8}\int_0^{10}|f''(x)|dx
<\frac{140\Delta^2}{8}.
\]

The script uses \(\Delta=10^{-4}\), hence 100,001 nodes and an error
allowance of \(1.75\times10^{-7}\) per endpoint. Since
\(\sqrt{2/\pi}<1\), the same allowance bounds the normalized error.
This bound is analytic; it is not an adaptive integrator's estimated error.

## Arithmetic certification and its trust boundary

All quadrature abscissas, learning rates, exponents, and initial
\(u\) and \(x^2/2\) arguments are exact terminating rationals. A
separate Decimal context traps any inexact evaluation of those arguments.
Other basic arithmetic is performed at 40 decimal significant digits with
ROUND_FLOOR for lower endpoints and ROUND_CEILING for upper endpoints.

For positive \(u\), the implementation encloses
\(\log u\), forms \(p\log u-x^2/2\) with directed rounding, and
encloses its exponential. Python documents Decimal `ln` and `exp` as
correctly rounded to nearest, ties to even; each returned value is widened
by one representable number in the required outward direction.
The identity \(\log1=0\) and the value \(0^p=0\) are handled exactly.
The script does not use Decimal's general power function, which has a
weaker documented correctness contract in the C implementation.

Primary arithmetic documentation:
[Python 3.12 Decimal](https://docs.python.org/3.12/library/decimal.html),
especially `Decimal.exp`, `Decimal.ln`, `Decimal.next_minus`,
`Decimal.next_plus`, and the rounding modes.

The normalizer does not use a decimal approximation to pi without a
remainder proof. Sixty exact rational alternating-series terms enclose
each arctangent in
\(\pi=16\arctan(1/5)-4\arctan(1/239)\). The tangent addition identity
checks to exactly one in rational arithmetic; the angle is in
\((0,\pi/2)\). An integer square root then encloses \(\sqrt{2/\pi}\)
on a rational grid with denominator \(10^{60}\), and exact squaring
verifies the resulting bounds.

This is a rigorously enclosed numerical calculation under the documented
Python Decimal arithmetic contract. Its trust base consists of the
analytic estimates in this note, exact Python integer/Fraction operations,
and the stated Decimal operations. It is not a formal proof-assistant
certificate or an independently verified implementation of transcendental
arithmetic. Rerunning at another precision is unnecessary for the claimed
enclosures; the interval computation already includes rounding error.

As a meaningful calibration, the same code encloses the exactly known
Gaussian moment \(h_1(2)=2\) on a coarser mesh before certifying the six
root-bracket endpoints. This checks the integral normalization and mesh
weights against a value not obtained from the quadrature implementation.
The certification path imports no scientific-computing package and uses
no floating-point quadrature or simulation.

## Independent rational fallback: \(1<\alpha_\eta<2\)

Even without running the numerical certificate, the interval in the source
proof follows from short rational inequalities. The Gaussian identity is

\[
\mathbb E|1-A^2|=4\varphi(1)=\frac4{\sqrt{2\pi e}}.
\]

Use \(\pi>157/50\) and \(e>1359/500\). The latter follows from
\(\sum_{k=0}^6 1/k!=1957/720>1359/500\); the Machin enclosure above
also checks the former. Exact rational squaring verifies

\[
\frac{16}{2(157/50)(1359/500)}<(97/100)^2.
\]

Therefore, uniformly for \(\eta\in[99/100,101/100]\),

\[
h_\eta(1)
\le h_1(1)+|\eta-1|\mathbb EA^2
<97/100+1/100=49/50<1.
\]

Also

\[
h_\eta(2)=1-2\eta+3\eta^2
\ge1-2(99/100)+3(99/100)^2
=19603/10000>1,
\]

since \(-2+6\eta>0\) on the interval. Continuity and strict
log-convexity, as established analytically in the source, give the unique
positive root in \((1,2)\). This fallback uses no numerical integration.
