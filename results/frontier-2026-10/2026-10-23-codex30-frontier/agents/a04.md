# Candidate for root: joint two-query GP posterior from kernel attention

**Status and source boundary.** I could not verify any literal Math Brain DNN T336 statement from public search. This is a self-contained *new extension* of Kang–Lee–Cheng, “Transformers Can Learn Posterior Predictive Distributions In-Context,” ICML 2026, [PMLR primary source](https://proceedings.mlr.press/v306/kang26h.html), [full arXiv text](https://arxiv.org/abs/2605.26713), Theorem 3.1 and Appendix C.1. The published theorem has one query and gives its scalar predictive mean and variance using an *unnormalized kernel-attention* head and Richardson iteration; it does not state joint predictive cross-covariances. Do not call this a resolution of T336 without the actual benchmark problem. Their kernel attention may take RBF, linear, or any PSD kernel; this is not an implementation in standard ReLU dot-product attention unless a separate kernel-realization lemma is supplied. A different May 2026 primary paper, [arXiv 2605.08475](https://arxiv.org/abs/2605.08475), constructs a single-head **softmax** Gaussian-KRR point predictor via preconditioned Richardson with `2L+5` blocks, but proves no joint GP covariance.

## Exact candidate theorem

Fix a PSD kernel `k`, Gaussian observation noise variance `s=σ²>0`, training inputs `x_1,...,x_n`, labels `Y`, and **m=2** (or any fixed `m`) ordered query inputs `q_1,...,q_m`. Let `G=K_XX`, `H=K_XQ` (`n×m`), `J=K_QQ` (`m×m`), `A=G+sI`, `a=λ_min(A)>0`, `b=λ_max(A)`, and `η∈(0,1/b]`. Use the exact unnormalized kernel-attention operator and train-source masks of Kang et al. Let `R=I−ηA`, `P_L=η Σ_{t=0}^{L−1} R^t=A^{−1}(I−R^L)`, `ρ=1−ηa∈[0,1)`. One initial multihead kernel-attention block (one head per query), `L` iterative blocks (one vector-valued kernel-attention head per block), and linear readout on query tokens simultaneously give

`m_L = Hᵀ P_L Y`, `C_L=J+sI_m−HᵀP_L H`.

The exact joint predictive distribution of *independent noisy test observations* is `N(m,C)` with `m=HᵀA^{−1}Y`, `C=J+sI_m−HᵀA^{−1}H`. The construction has token dimension `d+3m+2` by one explicit accounting below, and at most `m` attention heads in the read-in block; `m=2` therefore uses 2 heads and width `d+8` (the formula is `d+3m+2`). It delivers all off-diagonal covariance entries, unlike separately computing univariate variances. Moreover

`C_L−C = HᵀA^{−1}R^L H ⪰ 0`,

`||m_L−m||_2 ≤ (||H||_2 ||Y||_2/a)ρ^L`,

`||C_L−C||_op ≤ (||H||_2²/a)ρ^L`.

The covariance is symmetric PSD **at every finite depth**: `C_L ⪰ C ⪰ sI_m`. For distributions,

`TV(N(m,C), N(m_L,C_L)) ≤ [ρ^L/(2a)] sqrt( ||H||_2² ||Y||_2²/s + m ||H||_2^4/(2s²) )`.

Proof of last bound: Gaussian KL with approximate covariance in the second argument. Set `Δ=C_L−C⪰0`, `T=C^{−1/2}ΔC^{−1/2}⪰0`. The covariance part is `Σ_i{(1+t_i)^{−1}−1+log(1+t_i)}≤||T||_F²/2`; the mean part is at most `||m_L−m||²/s`. Thus `KL≤||m_L−m||²/(2s)+||Δ||_F²/(4s²)`. Apply Pinsker and `||Δ||_F≤√m||Δ||_op`.

## Wiring and proof (avoid claiming that mere parallel independent runs suffice)

Initial token `z_i` stores `x_i∈R^d`, label `y_i` (zero in query positions), a query-ID one-hot vector `e_a` at token `q_a` and zero at training tokens, an `m`-channel source vector initially zero, and `(m+1)` iterative-value channels initially zero. Total `d+1+m+m+(m+1)=d+3m+2` coordinates. In the first block, head `a` has source mask selecting only token `q_a`, `K,Q` select `x` coordinates, and its value map sends ID coordinate `a` into source coordinate `a`. Its output at every token `z` is exactly `k(q_a,z)`. In particular, training tokens acquire RHS `H_{ia}`, and query token `q_b` acquires prior covariance `J_{ab}`. Query IDs and RHS coordinates are preserved thereafter.

Each iterative block uses mask selecting exactly the training tokens as sources, with `K,Q` selecting input `x` coordinates and one shared attention head with vector-valued `V`. Its output into the `(m+1)` evolving channels at destination `z` is `η Σ_i k(x_i,z) [y_i−f_i, H_{i1}−g_{1i},...,H_{im}−g_{mi}]`. The residual passes the evolving channels unchanged; the allowed local linear skip `S` subtracts `ηs[f_z,g_{1z},...,g_{mz}]`. Hence for every source RHS `v∈{Y,H_:1,...,H_:m}` and every token `z`, its evolving coordinate obeys precisely Kang et al. Equation (7): `u_{t+1}(z)=(1−ηs)u_t(z)+ηΣ_i k(x_i,z)(v_i−u_t(x_i))`, with zero initial value. Inductively `u_t(z)=k(z,X)P_t v`: if true at `t`, then the coefficient update is `P_{t+1}v=P_tv+η(v−A P_t v)`, giving `P_t=ηΣR^j`. At query `q_b`, the evolving mean is `(HᵀP_tY)_b`, and the `a`th evolving variance-reduction coordinate is `(HᵀP_tH)_{ba}`. A shared linear readout of token `q_b` emits one mean and all `m` covariance entries `source_a(q_b)+s·ID_a(q_b)−g_a(q_b)`. The ID supplies the diagonal Kronecker delta; its absence is an easy mistake.

For weights independent of prompt data, if the diagonal kernel is bounded by `κ_max` and `n≤N`, choose fixed `η=1/(Nκ_max+s)` using `||G||≤tr G≤Nκ_max`, so all claims hold uniformly for this class. This construction assumes fixed ordered query slots and position-dependent binary masks as in the source theorem. It requires the same extra linear skip term used in their attention blocks. For noiseless latent targets, drop `sI_m` in readout and positivity still holds, but the stated TV bound needs a positive lower bound on the exact latent posterior covariance.

## Caveat for assignment selection

The mathematical extension is clean and proof-complete for *kernel attention*, but may be too close to a straightforward multi-RHS corollary to count as a substantial open problem; and it is not a proof in a **normalized ReLU-attention** architecture. If a benchmark question demands an actual ReLU-attention network with explicit head/width/conditioning bounds, the hard missing step is routing `k(q_a,x_i)` and performing kernel matrix-vector products within that specified attention primitive. Do not substitute a kernel-attention head silently. The other paper's softmax Gaussian kernel construction is approximate and introduces MLP arithmetic errors, so its transfer also needs a full error analysis.

**A literal open direction in the primary paper:** Remark 3.2 and Discussion §7 expressly leave a full hierarchical-GP extension for future work: finite mixtures with uncertain kernel/noise hyperparameters, computing componentwise moments in separate heads and posterior mixture weights in an additional readout. For component `h` with prior weight `π_h` and training covariance `A_h=G_h+σ_h²I`, the posterior weight is proportional to `π_h det(A_h)^(−1/2) exp(−YᵀA_h^(−1)Y/2)`. Thus multihead Richardson for per-component mean/variance alone is insufficient: the evidence-dependent log determinant and quadratic form must also be computed. This is a more substantial paper-authored open question than the joint-covariance corollary, but I do not have a full architecture proof for those normalization terms.
