# Joint GP posterior by two-head signed-ReLU Chebyshev attention

This is a self-contained **extension**, not a claim that the literal Math Brain T336 has been solved: a prior scalar-GP Chebyshev construction already produces positive scalar variance at every depth, and the earlier multi-query kernel-attention note (`agents/a04.md`) is also prior context. Kang–Lee–Cheng, [*Transformers Can Learn Posterior Predictive Distributions In-Context*, ICML 2026](https://proceedings.mlr.press/v306/kang26h.html), use kernel attention and Richardson iteration for a scalar posterior. The specific contribution here is a **joint** `m`-query output with cross-covariances, an exact finite-feature **signed ReLU** realization, and a one-sided Chebyshev inverse polynomial certifying the stronger matrix statement `C_L⪰C⪰sI_m` at each chosen finite depth. It assumes unnormalized ReLU attention, fixed train/query source masks, and linear per-token residual/channel mixing; it does not hold as written for softmax, normalized ReLU attention, or arbitrary raw inputs whose feature map is not supplied.

## Statement and polynomial

Give `N` training slots (unused ones padded with feature and label zero), `m` ordered query slots, their features `φ(x)∈R^p` satisfying `||φ(x)||≤R`, scalar labels `Y∈R^N`, and observation-noise variance `s>0`. Put `Φ_X∈R^{N×p}`, `Φ_Q∈R^{m×p}`, `K=Φ_XΦ_Xᵀ`, `H=Φ_XΦ_Qᵀ`, `J=Φ_QΦ_Qᵀ`, `A=K+sI_N`, and `B=[Y,H]∈R^{N×(m+1)}`. The exact noisy-test GP posterior is

`μ=HᵀA^{-1}Y`, `C=J+sI_m−HᵀA^{-1}H ⪰ sI_m`.

For `NR²>0` let `a=s`, `b=s+NR²`, `c=(a+b)/2`, `d=(b−a)/2`, `z=c/d>1`, and `t_j=T_j(z)` (Chebyshev's first-kind polynomial). The network weights use only these public bounds, `m`, and its depth `L≥1`. Define

`q_L(λ)=T_L((c−λ)/d)/t_L`, `δ_L=1/t_L`,

`r_L(λ)=(q_L(λ)+δ_L)/(1+δ_L)=[T_L((c−λ)/d)+1]/[t_L+1]`,

`F_L(λ)=(1−q_L(λ))/λ`, `P_L(λ)=F_L(λ)/(1+δ_L)=(1−r_L(λ))/λ`.

Since `q_L(0)=1`, `F_L` and `P_L` are degree `L−1` polynomials, including at λ=0 by continuity. On `[a,b]`, `0≤r_L(λ)≤ε_L:=2/(t_L+1)<1`. Hence `0⪯P_L(A)⪯A^{-1}`. Writing `κ=b/a` and `θ=(√κ−1)/(√κ+1)`, the exact expression and convenient bound are

`ε_L=4θ^L/(1+θ^L)^2≤4θ^L`.

The output is `μ_L=HᵀP_L(A)Y`, `C_L=J+sI_m−HᵀP_L(A)H`, including every cross-covariance `C_L[b,a]`. The covariance is symmetric and valid for every `L≥1`:

`C_L−C=HᵀA^{-1/2}r_L(A)A^{-1/2}H⪰0`, so `C_L⪰C⪰sI_m`.

Moreover `0⪯C_L−C⪯ε_L HᵀA^{-1}H⪯ε_L J`. Therefore `||C_L−C||_op≤ε_L mR²`, `||C_L−C||_F≤ε_L mR²`, and each entry has magnitude at most `ε_L R²`. Also `||μ_L−μ||_2≤ε_L R√m ||Y||_2/√s` because `HᵀA^{-1}H⪯J`. For noisy test laws, Gaussian KL followed by Pinsker gives

`TV(N(μ,C),N(μ_L,C_L)) ≤ [ε_L/(2√2 s)] √(2mR²||Y||²+m²R⁴)`.

If `|Y_i|≤M`, substitute `||Y||²≤NM²`; otherwise no absolute error uniform over arbitrary unbounded labels is claimed. To attain `ε_L≤η` it suffices that `L≥log(4/η)/log((√κ+1)/(√κ−1))=O(√κ log(1/η))`. For `NR²=0`, training cross-kernel vanishes and a direct query prior readout gives `(0,J+sI_m)`.

## Exact two-head attention primitive

An unnormalized ReLU attention head has output `Σ_{i in source mask} ReLU(Qz·Kz_i)Vz_i`, without softmax or denominator. At destination with feature `u` and sources with feature `v_i` and vector values `w_i`, two heads choose `(Q,K,V)=(u,v_i,w_i)` and `(u,−v_i,w_i)`, with output projection `(+I,−I)`. Their sum **exactly** equals `Σ_i (u·v_i)w_i`, since `ReLU(t)−ReLU(−t)=t`. The heads' key dimension is `p`, and value dimension is at most `m+1`. No multiplication of two channels inside a token is required.

Each token has channels `φ` (`p`), original label `y` (`1`, zero at queries), query ID `e` (`m`, `e_a` at query slot `a` and zero at training), read-in row `h` (`m`, initially zero), and two evolving vectors `x,x_prev` (each `m+1`). This is **`D0=p+4m+3` token coordinates**. If a strictly equal-width two-head implementation requires each head to have key/value dimension `D/2`, pad to the even width `D=2 max{p,m+1,ceil(D0/2)}`; unused coordinates remain zero. Allowing ordinary independent key/value head dimensions, `D0` suffices.

1. **One read-in attention layer (two heads, query slots as sources):** use values `e_a` and the signed-dot-product pair. Its `m`-vector at any destination `z` is `h(z)=Σ_{a=1}^m(φ(z)·φ(q_a))e_a`. Thus `h(x_i)=H[i,:]` and `h(q_b)=J[b,:]`. The same layer's local linear mixer sets `x_1(z)=(y(z),h(z))/c` and `x_0(z)=0`, and preserves `φ,y,e,h`. On training slots, `x_1=B/c`.
2. **For each `j=1,...,L−1`, one iteration layer (two heads, training slots as sources):** values are the current `(m+1)`-vector `x_j(i)`. The signed pair computes `Kx_j` at training destinations. With fixed scalars `β_j=t_{j−1}/t_{j+1}` and `α_j=2t_j/(d t_{j+1})`, local mixing and output projection set

   `x_{j+1}=(1+β_j−α_js)x_j−β_jx_{j−1}+α_j(y,h)−α_jKx_j`, `x_prev←x_j`.

   This is precisely `X_{j+1}=X_j+β_j(X_j−X_{j−1})+α_j(B−AX_j)` at training slots, with `X_0=0`, `X_1=B/c`. The Chebyshev identity `t_{j+1}=2zt_j−t_{j−1}` implies `B−AX_j=q_j(A)B` inductively; therefore `X_j=F_j(A)B`. Query-slot evolving vectors are irrelevant because only training slots source these heads. The current/past vectors and read-in row all fit in `D0`; no temporary or product channels are needed.
3. **One readout attention layer (two heads, training slots as sources):** values are `X_L[i,:]`, and the signed pair produces at query `b` the raw vector `u_b=H[:,b]ᵀX_L`. Set `v_b=u_b/(1+δ_L)` using a fixed output weight. Its first component is `μ_L[b]`, and the remaining `m` components form row `b` of `HᵀP_L(A)H`. A local linear mixer writes into the existing `x` channels the final `(v_b[0],h(q_b)+s e_b−v_b[1:m])`. The query ID supplies exactly the diagonal `sI_m`; each query token thus emits one mean and its complete covariance row. Symmetry follows mathematically from the common polynomial `P_L(A)`.

This uses **`L+1` attention layers, two heads in every layer, `2L+2` heads total**, plus the allowed local linear mixing; `L=1` needs no iteration layer and produces the one-step underinverse `P_1=I/b`. Weights depend on `p,m,N,R,s,L`, never on the actual features or labels. The masking pattern is fixed by train/query slot roles; zero-padded training slots are harmless (`K` has zero rows/columns there, with `sI` on the padding). The feature vectors must be provided as token coordinates or exactly computed by a separate feature embedding; the statement does not construct an arbitrary feature map from raw input.

The residual-square certificate also works: `P_sq(λ)=(1−q_L(λ)^2)/λ` has degree `2L−1` and `0⪯P_sq(A)⪯A^{-1}` since `|q_L|≤δ_L≤1`. Run the above unscaled solver once on `B`, form its residual `R=B−AF_L(A)B=q_L(A)B` with one additional signed-head matrix product, then run it again on `R` and add outputs: `F_L(A)B+F_L(A)R=P_sq(A)B`. This costs `2L−1` training matrix-product layers plus read-in and readout (`2L+1` attention layers total) and extra `m+1`-vector accumulator/RHS channels. Its residual bound is `δ_L²`; the shifted degree-`L−1` construction above is the leaner one-sided certificate.

**Verification:** a NumPy random-feature check with `N=7,p=4,m=3,L=8` matched the layer recurrence to the spectral definition of `P_L(A)B` within `2.7×10⁻¹⁵`; the residual eigenvalues stayed inside `[0,ε_L]` and the approximate covariance excess was PSD up to numerical precision. This checks the algebra, not a claim about trained weights or finite-precision stability of very deep networks.
