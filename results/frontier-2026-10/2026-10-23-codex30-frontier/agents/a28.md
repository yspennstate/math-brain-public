# A28 — quantitative raw-input ReLU encoder for Gaussian GP prediction

This note removes the exact-feature-preprocessing assumption in `agents/a23.md` for inputs in a fixed Euclidean ball. It composes with the **unnormalized**, fixed-source-mask, signed two-head ReLU attention realization in `agents/a21.md`. It does not claim that ordinary softmax or row-normalized attention implements the same kernel matvec. The novelty boundary is modest: this is a constructive quantitative closure of a raw-input gap, not a new universality theorem or a claim of novelty for Chebyshev iteration. All weights below are fixed before seeing the prompt.

## Explicit scalar ReLU gadgets

Write `σ(v)=max(v,0)`. For `M>0` and integer `n≥2`, let `S_{M,n}` be the linear interpolant to `v²` at `v_j=−M+2Mj/n`, `j=0,…,n`. If `s_j=v_j+v_{j+1}` is the secant slope, its **exact** one-hidden-layer ReLU formula is

`S_{M,n}(v)=M²+s_0(v+M)+Σ_{j=1}^{n−1}(s_j−s_{j−1})σ(v−v_j)`.

On `[-M,M]`, `0≤S_{M,n}(v)` and `|S_{M,n}(v)−v²|≤M²/n²` (the maximum quadratic chord error on a cell is `(2M/n)²/4`). Define

`mult_n(u,v)={S_{2,n}(u+v)−S_{2,n}(u−v)}/4`,

`clip(v)=−1+σ(v+1)−σ(v−1)`.

For `u,v∈[-1,1]`, `|mult_n(u,v)−uv|≤2/n²`, and `clip` maps to `[-1,1]`, is 1-Lipschitz, and fixes `uv`. Thus `clip(mult_n(u,v))` is an explicitly two-hidden-layer ReLU multiplication gadget of error at most `2/n²`. No exact multiplication or exponential is assumed in a raw-input token.

For `U≥0`, let `E_{U,n}` be the linear interpolant to `e^{−v}` on `[0,U]` with `n` equal cells (if `U=0`, use the constant one). It has the same hinge formula with secant slopes, lies in `[e^{−U},1]`, and satisfies `|E_{U,n}(v)−e^{−v}|≤U²/(8n²)` because the second derivative is at most one on this interval.

## Encoder theorem, including finite network size

Fix `d≥1`, `ell>0`, `R>0`, integer degree `k≥0`, and accuracy `0<ζ≤1`. Put

`a=R²/ell²`, `D=binom(d+k,k)`, `c_α=a^{|α|/2}/sqrt(α!)`,

`C_{d,k,a}=(Σ_{|α|≤k}c_α²)^{1/2}=(Σ_{j=0}^k(da)^j/j!)^{1/2}≤e^{da/2}`,

`G=ad/2+a²/32+2 max(1,k)`,

`n=max{2,ceil(sqrt(C_{d,k,a}G/ζ))}`.

There is a single, shared, explicitly weighted feedforward ReLU network `F:R^d→R^D` such that, uniformly for `||x||₂≤R`,

`||F(x)−φ_{≤k}(x)||₂≤ζ`, `||F(x)||₂≤1+ζ`, where

`φ_α(x)=exp(−||x||₂²/(2ell²)) x^α/(ell^{|α|}sqrt(α!))`.

In particular, it has at most `H=5+2 max(0,k−1)≤2k+5` hidden ReLU layers, each of width at most `W=2(n+3)(D+d+1)`, followed by an affine `D`-coordinate output layer. A standard fully connected realization can use at most `(H+1)(W+d+D+1)²` scalar parameters, counting zeros, and every weight/bias can be bounded in magnitude by the deliberately loose explicit value

`Q=64[1+R^{−1}+a(d+1)+max(1,a^{k/2})]`.

Here is an exact construction supporting these size claims. Normalize `t=x/R` so `||t||≤1`, put `U=a/2`, and make `ũ=(a/2)Σ_{i=1}^d S_{1,n}(t_i)`. Two ReLU units implement `û=min(U,max(0,ũ))`; then set `ĝ=E_{U,n}(û)`. The first three hidden layers perform, respectively, the square hinges, clipping of `ũ`, and exponential-interpolation hinges. Carry each signed `t_i` between layers as the two rails `(σ(t_i),σ(−t_i))`. Since `u=a||t||²/2∈[0,U]`, nonexpansiveness of clipping and 1-Lipschitzness of `e^{−u}` give

`|ĝ−exp(−u)|≤(ad/2+a²/32)/n²`, and `0≤ĝ≤1`.

For each multi-index `α`, fix once and for all a list of its `|α|` coordinate indices with repetitions. Its degree-zero monomial is one, and its degree-one prefix is a coordinate `t_i`. For rounds `r=2,…,k`, obtain each needed degree-`r` prefix from its preceding prefix and the next `t_i` with `clip(mult_n(·,·))`; carry shorter completed monomials unchanged. Each round uses the multiplication hinges and then the clipping layer. All intermediate values remain in `[-1,1]`. Induction and `|t_i|≤1` give degree-`j` monomial error at most `2(j−1)/n²` (zero for `j=0,1`). Finally one parallel multiplication-and-clipping round combines `ĝ` with each approximate monomial, and the affine output scales it by `c_α`. Consequently its coordinate error is at most `c_α G/n²`; summing squared errors yields `||F−φ||≤C_{d,k,a}G/n²≤ζ`. The final clipping is harmless since the true `ĝ t^α` belongs to `[-1,1]`.

For clarity on the MLP compilation, each `S` uses at most `n−1` hinge units and two signed rails to retain its linear argument. In each parallel multiplication round, at most `2(n−1)D` square hinges are needed; at most `2D` clipping hinges and signed rails for at most `D+d+1` currently live scalars suffice in the next layer. The stated `W` dominates these counts and the first three layers. A rail can be copied through another ReLU layer as `(σ(v),σ(−v))`, with `v` an affine expression in the old rails; hence no unmentioned skip edge is needed. The explicit hinge slopes have magnitude at most four for `S_{2,n}`, slope jumps at most eight, and interpolation slopes at most one for `E_{U,n}`. The normalization `1/R`, norm scalar `a/2`, clipping thresholds `1,U`, and output multipliers `c_α≤max(1,a^{k/2})` all fit the displayed `Q` (including the affine constants resulting from hinge expansions).

When `R=0`, the only admissible raw input is zero: use the constant map `F(0)=(1,0,…,0)` and `k=0`. This degenerate case needs no division by `R` or approximation.

## PSD kernel, KL, and choice of all three accuracy parameters

For every pair in the input ball, set `k_F(x,z)=F(x)·F(z)`. The **same** encoder at all tokens makes every joint train/query Gram matrix PSD, regardless of interpolation errors. Since the exact truncated map has norm at most one, the Cauchy–Schwarz argument and `agents/a23.md` give

`|k_RBF(x,z)−k_F(x,z)|≤δ:=a^{k+1}/(k+1)!+2ζ+ζ²`,

`k_F(x,x)≤r²`, `r=1+ζ`.

Fix `1≤n_context≤N`, `m≥1` ordered query slots, `|y_i|≤B`, and noisy observation variance `s>0` both at training and query. Let `(μ,C)` be the true joint noisy-query Gaussian posterior; let `(μ_F,C_F)` be the exact posterior of `k_F`. Both covariances satisfy `C,C_F⪰sI_m`. With a uniform entrywise kernel error `δ`, the resolvent identity gives, writing `n_context=t` in the following formulas,

`||μ−μ_F||₂≤M_t(r)δ`, `M_t(r)=[t sqrt(m)B/s](1+t r²/s)`,

`||C−C_F||_op≤V_t(r)δ`, `V_t(r)=m(1+t r²/s)²`.

Indeed `||H−H_F||_op≤sqrt(tm)δ`, `||G−G_F||_op≤tδ`, `||J−J_F||_op≤mδ`, `||H||_op,||H_F||_op≤sqrt(tm)r²`, and both inverse norms are at most `1/s`. These bounds allow the feature approximation to be non-Loewner relative to the true RBF kernel; only each individual full Gram needs PSD.

Use the one-sided Chebyshev degree-`L−1` polynomial of `agents/a21.md` with the fixed interval `[s,b]`, `b=s+Nr²`, and its signed two-head implementation. It obeys `0⪯P_L(A_F)⪯A_F^{−1}` and relative residual `e_L≤4q^L`, where `q=(sqrt(b/s)−1)/(sqrt(b/s)+1)`. Its output `μ̂=H_FᵀP_L(A_F)y`, `Ĉ=J_F+sI_m−H_FᵀP_L(A_F)H_F` has `Ĉ⪰C_F⪰sI_m`. Define

`S_t(r)=t sqrt(m)B r²/s`, `U_t(r)=tm r⁴/s`.

The solver errors satisfy `||μ_F−μ̂||₂≤S_t(r)e_L` and `||C_F−Ĉ||_op≤U_t(r)e_L`. Gaussian forward KL, using the whole SPD line segment between `C` and `Ĉ`, is therefore bounded uniformly by

`KL(N(μ,C) || N(μ̂,Ĉ)) ≤ [M_N(r)δ+S_N(r)e_L]²/(2s) + m[V_N(r)δ+U_N(r)e_L]²/(4s²).`     (★)

This is a **direct forward** KL calculation, with no KL triangle inequality and no small-perturbation condition. The predictor also retains all ordered query cross-covariances as a symmetric PSD joint covariance.

For a fully explicit `ε>0` choice independent of the prompt, upper-bound `r` by two in all constants, set

`C_*=[M_N(2)+S_N(2)]²/(2s)+m[V_N(2)+U_N(2)]²/(4s²)`, `h=min{1,sqrt(ε/C_*)}`,

`ν=ceil(max{1,2ea,log₂(2/h)})`, `k=ν−1`, `ζ=h/8`,

then select the encoder grid count `n` displayed above and the attention recurrence depth

`L=max{1,ceil(log(4/h)/log(1/q_2))}`, `q_2=(sqrt((s+4N)/s)−1)/(sqrt((s+4N)/s)+1)`.

The factorial inequality `ν!≥(ν/e)^ν` implies the RBF feature tail `a^ν/ν!≤2^{−ν}≤h/2`; hence `δ≤h/2+2(h/8)+(h/8)²≤49h/64<h`. The actual finite-feature spectrum is inside `[s,s+Nr²]⊆[s,s+4N]`, so using the **fixed** upper bound `b=s+4N` and `q_2` in the two-head Chebyshev layer weights yields `e_L≤h`. Formula (★) then gives `KL≤C_*h²≤ε`. The number of feature coordinates is exactly `D=binom(d+ν−1,ν−1)`; the per-token encoder has the explicit `H,W,Q` bounds above; the attention core has `L+1` layers and two heads per layer, with width `D+4m+3` (or the equal-head padding stated in `agents/a21.md`). Thus the raw-input construction is finite and quantitative, albeit deliberately large: for fixed `d,R/ell,s,N,m,B`, `D=O(log(1/ε)^d)`, `n=O(ζ^{−1/2}e^{da/4}sqrt(ad+a²+k))`, and `L=O(sqrt(1+4N/s)log(1/ε))` as `ε↓0`.

The two-head identity crucially uses `σ(v)−σ(−v)=v` with **unnormalized** source sums. Row division or softmax changes the matvec, so this note does not establish a normalized-attention implementation. Parameter rounding for a finite hypothesis class requires the separate layerwise error recurrence and projected-output KL control in `agents/a24.md`; the exact-arithmetic encoder/attention construction above supplies a concrete continuous approximant for that step, but quantization is not silently included in (★).
