# C08 - Lemma 5.1 critical-value density version

Source: math-open-problems@ec211ba2d77a4a9850168c6af1574ea651feaa7c, short.tex line 398, PDF page 8.

Status: GAP (presentation/version only).

The displayed density formula divides by sqrt(|a||z-v|) while multiplying by the indicator {(z-v)/a>0}. At z=v the denominator is zero and the indicator is zero, so the literal pointwise expression is undefined without a convention.

Repair: state the formula for z != v / almost every z and set p_T(v)=0.

Justification: T=v iff Y=m, and Y has a Lebesgue density, so P(T=v)=0. The repair changes no density measure, small-ball estimate, downstream a.e. domination, or theorem constant.

Independence note: none; this is a one-point density-version issue.
