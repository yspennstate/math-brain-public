## New theorem

If, after conditioning on outside variables and translating affine terms, one has

`Q = a (X+m(Y))^2 + R(Y)`, `a!=0`, `f_X<=1`,

then

`p_Q(t) <= |a|^(-1/2) int |t-s|^(-1/2) p_R(s) ds`.

For any probability density `g in L^3`,

`sup_t int |t-s|^(-1/2)g(s)ds <= 2^(5/2)||g||_3^(3/4)`.

Apply this to a selected symmetric block

`B=[[a,d,e],[d,b,f],[e,f,c]]`, `a!=0`,

with adjacent principal minors `ab-d^2=ac-e^2=0`. Put `r=d/a`, `s=e/a`, `kappa=f-de/a`. Then

`x^T B x = a(x+ry+sz)^2 + 2 kappa yz`,  `det B=-a kappa^2`,

and for arbitrary independent selected-coordinate densities bounded by one, arbitrary dimension, and arbitrary outside couplings,

`||p_Q||_infinity <= 4 ||H||_3^(3/4)/sqrt(|a kappa|) < 15.842/sqrt(|a kappa|)`.

If this selected `3x3` block itself has all eigenvalues of magnitude at least one, then `||B^{-1}||_op<=1`; its explicit inverse forces `|a kappa|>=1/3`, giving the universal subclass bound `<27.44`.
