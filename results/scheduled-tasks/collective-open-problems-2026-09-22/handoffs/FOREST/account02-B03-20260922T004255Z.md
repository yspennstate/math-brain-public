## Exact new 2-separator theorem

Let `G=A union B`, edge-disjoint, `V(A) intersect V(B)={s,t}`. For cross-side marks `e in A`, `f in B`, let `d_i^A,c_i^A` count side forests with marked inclusion state `i` and boundary disconnected/connected, and similarly for B. Then

`M_ij=d_i^A(d_j^B+c_j^B)+c_i^A d_j^B`

and the global Rayleigh numerator factors exactly as

`R_G(e,f)=(d_0^A c_1^A-d_1^A c_0^A)(d_0^B c_1^B-d_1^B c_0^B)`.

Each factor is the ordinary unit Rayleigh numerator between the marked edge and the completed boundary edge `st` on that side (or is automatically nonnegative if the mark itself is `st`). Hence a vertex-minimal simple counterexample cannot have a violating pair split across a proper 2-separation.

For same-side marks `e,f in A`, neither equal to an existing boundary edge, put

`D_B=# disconnected s-t forests of B`, `C_B=# connected s-t forests`, `lambda=C_B/D_B`.

Then exactly

`R_G(e,f)=D_B^2 R_Ahat(e,f)`,

where `Ahat` is A plus a virtual `st` edge of weight `lambda`; if A already contains an unmarked `st` edge, the virtual parallel copy merges into it with total weight `1+lambda`. If one marked edge is the actual boundary edge `st`, the response cancels and `R_G(st,f)=D_B^2 R_A(st,f)`.

Thus the first genuine 2-separator residual is one ordinary same-side pair under one exact induced boundary weight.
