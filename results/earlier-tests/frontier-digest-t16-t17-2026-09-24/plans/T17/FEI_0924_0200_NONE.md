# FEI: research plan (session of 2026-09-24)

**Scope and calibration.** The owner asked for a 20-hour solo push; this plan covers the first ~4–5 hours and ends with a re-plan. FEI is 30 years old; the best general bound (Kelman–Kindler–Lifshitz–Minzer–Safra 2020, random restrictions à la Bourgain–Kalai) loses a log I factor, and the authors say removing it would essentially settle FEI. A full proof in hours is unlikely. Success = (i) a verified reduction to a local or tensorizing inequality, (ii) FEI for a new class — monotone functions first (open to my knowledge; FMEI there already follows from KKL) — or (iii) a precisely documented obstruction. Nothing counts as proved until re-derived line by line and checked numerically; an hourly log in notes.md tags each claim proved / numerically supported / refuted.

**Framework to build on.**
1. *Baseline.* For Boolean f, Pr_{S~f̂²}[i∈S] = Inf_i, so subadditivity gives H ≤ Σ_i h(Inf_i) ≤ I·log(en/I); the whole problem is this log n (strong dependence between the events {i∈S}).
2. *Exact one-coordinate identity.* With f_± the restrictions to x_n = ±1, e_S = f̂(S)², d_S = f̂(S∪{n})², q = e+d = ½(f̂_+² + f̂_-²):

   H(f̂²) = ½[H(f̂_+²)+H(f̂_-²)] + JS(f̂_+², f̂_-²) + Σ_S q_S·h(d_S/q_S),

   with JS ≤ O(Inf_n). The split term is ≤ h(Inf_n) and, up to O(Inf_n), equals Inf_n·E_{T~f̂² | n∈T} log(1 + f̂(T∖n)²/f̂(T)²). Since I(f) = Inf_n + ½[I(f_+)+I(f_-)], any adaptive restriction tree writes both H and I exactly as sums of per-node terms. Hence a sufficient **local condition** (a hypothesis to test, not a result):

   (★) Σ_i [Split_i(f) + JS_i(f)] ≤ C·I(f) for every Boolean f

   (then some coordinate costs ≤ C·Inf_i; restrict on it and recurse). Quick hand checks, to be re-verified numerically: the split term vanishes for Majority (parity of levels) and is O(Inf_i) for Tribes and AND; for non-Boolean spectra w_T ∝ ε^{|T|} this log-ratio is ≈ log(1/ε) per element — exactly how FEI fails for real functions — so Booleanity must enter at this term.
3. *Booleanity tools.* Edge isoperimetry on supp(D_i f) gives E[|S|−1 | i∈S] = I(D_i f)/Inf_i ≥ ½log₂(1/Inf_i), hence H = O(E|S|²): the "rare entry buys a large cluster" mechanism behind Tribes, but with double counting. Also Bonami hypercontractivity/level-k inequalities, KKL/Talagrand, Friedgut's junta theorem.
4. *Benchmarks and templates.* Symmetric functions and read-once decision trees (O'Donnell–Wright–Zhou); O'Donnell–Tan's composition theorem (model for a composition-stable strengthening); Wan–Wright–Wu's compression view (FEI ≈ encoding S in O(I) bits); Hod's lexicographic lower bounds (C > 6: any lemma with a small constant is suspect).

**Order of work.**
- *Hours 0–1.5 — first concrete step.* A numpy fast Walsh–Hadamard lab computing H, I, Inf_i, JS_i, Split_i. Verify the identity to 1e−12 on all 65,536 functions with n = 4. Compute R(f) = Σ_i(Split_i+JS_i)/I(f) and the best-coordinate ratio over: all n ≤ 4; truth-table hill-climbing maximizing R for n = 6–12; Majority, Tribes, AND/OR, address, recursive Maj₃, lexicographic, LTFs, random DNFs, small-grid percolation crossings.
- *Hours 1.5–4 — branch on the data.* If R stays bounded: try to prove (★), monotone f first (D_i f is then a 0/1 indicator, so isoperimetry and hypercontractivity bear directly on E log(1 + f̂(T∖i)²/f̂(T)²)). If (★) fails (history suggests it may): dissect the extremizers and seek a closed-form potential Φ ≥ 0 with Φ(f) − ½[Φ(f_+)+Φ(f_-)] ≤ C·Inf_i − Split_i − JS_i for some i, giving a tensorizing strengthening H + Φ ≤ C·I. Candidates: entropy of the level |S|, level-weighted or Rényi spectral entropies, noise-stability gaps, isoperimetric "cluster" potentials; screen each against the hill-climber before attempting a proof.
- *Hours 4–5.* Write up exact status; re-plan.

**Avoid.**
- Inequalities valid for all real functions (log-Sobolev, entropic uncertainty): FEI fails there (n^{−1/2}Σx_i: ‖f‖₂ = 1, I = 1, H = log n).
- Junta/L²-concentration alone: tail mass ε over many characters can cost ε·n entropy.
- Re-running KKLMS to shave log I without a new ingredient: that is the known crux.
- Level-by-level hypercontractive counting: k·log(n/k) per level is the log n barrier again.
- Brute-force counterexample hunting: small n cannot refute a universal constant; search only filters lemmas.
