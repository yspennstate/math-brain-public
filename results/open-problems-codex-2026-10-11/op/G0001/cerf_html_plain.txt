  // Restore the saved color scheme preference, or
  // enact the browser preference if "automatic", 
  // without expecting DOM load to have completed.
  //
  // Also restore any saved readingmode and ToC display preferences.
  function initializeReadingPreferences() {
    let saved_theme = localStorage.getItem("ar5iv_theme") || "automatic";
    if (saved_theme === "automatic") {
      if (window.matchMedia("(prefers-color-scheme: dark)").matches) {
        saved_theme = "dark";
      }
    }
    if (saved_theme == "dark") {
      document.documentElement.setAttribute("data-theme", "dark");
    } else {
      document.documentElement.setAttribute("data-theme", "light");
    }

    const tocDisplay = localStorage.getItem('arxiv_html_paper_toc_display');
    if (tocDisplay) {
      document.documentElement.setAttribute("data-toc-display", tocDisplay);
    }
    const readingMode = localStorage.getItem('arxiv_html_paper_reading_mode');
    if (readingMode) {
      document.documentElement.setAttribute("data-reading-mode", readingMode);
    }
    // Pre-apply spinout-banner dismissal here, before the banner paints, so it
    // never flashes in only to be hidden later by the deferred arxiv-header.js.
    // Key matches arxiv-header.js: "arxiv-banner-dismissed:" + data-banner-name.
    if (localStorage.getItem('arxiv-banner-dismissed:spinout-nonprofit')) {
      document.documentElement.setAttribute("data-banner-dismissed", "");
    }
  }
  // Run as soon as JS starts, to minimize repainting
  initializeReadingPreferences();

 θ ⁡ ( p c , ℤ d ) = 0 ​ ? \theta(p_{c},{\mathbb{Z}}^{d})=0? 
 
 
 Raphaël Cerf
 
 Note:  
Université Paris-Saclay, CNRS, Laboratoire de mathématiques d’Orsay, 91405, Orsay.
 

 Abstract 
    
 We discuss the famous conjecture
 θ ⁡ ( p c , ℤ d ) = 0 \theta(p_{c},{\mathbb{Z}}^{d})=0 
for the Bernoulli site percolation model on  ℤ d {\mathbb{Z}}^{d}  with  d ≥ 3 d\geq 3 .
We prove that, for  d ≥ 3 d\geq 3 , in the Bernoulli percolation
model on  ℤ d {\mathbb{Z}}^{d} , at the critical point  p c p_{c} , either
there is no infinite cluster or the tail of the finite cluster
distribution is not stretched exponential. 
  
 
 
 1  θ ⁡ ( p c , ℤ d ) = 0 ​ ? \theta(p_{c},{\mathbb{Z}}^{d})=0? 

 
 We consider the Bernoulli site percolation model on  ℤ d {\mathbb{Z}}^{d}  with  d ≥ 3 d\geq 3 .
Each site is declared open with probability  p p 
and closed with probability  1 − p 1-p , and the sites
are independent.
The percolation probability is
 
 

 
 
 θ ⁡ ( p , ℤ d ) = P p ​ ( 0 ⟷ ∞ ) . \theta(p,{\mathbb{Z}}^{d})\,=\,P_{p}\big(0\longleftrightarrow\infty\big)\,. 
 
 
 For a parameter  p p  such that
 θ ⁡ ( p , ℤ d ) = 0 \theta(p,{\mathbb{Z}}^{d})=0 , with probability one,
all the open clusters are finite. On the contrary,
if  θ ⁡ ( p , ℤ d ) > 0 \theta(p,{\mathbb{Z}}^{d})>0 , then, with probability one,
there exists an infinite open cluster.
The critical point of the model is
 
 

 
 
 p c = sup { p ∈ [ 0 , 1 ] : θ ⁡ ( p , ℤ d ) = 0 } . p_{c}\,=\,\sup\,\big\{\,p\in[0,1]:\theta(p,{\mathbb{Z}}^{d})=0\,\big\}\,. 
 
 
 It follows from the classical Peierls argument that  p c p_{c} 
is strictly between  0 0  and  1 1 .
The definition of  p c p_{c}  readily implies that
 θ ⁡ ( p , ℤ d ) = 0 \theta(p,{\mathbb{Z}}^{d})=0  for  p < p c p<p_{c}  and
 θ ⁡ ( p , ℤ d ) > 0 \theta(p,{\mathbb{Z}}^{d})>0  for  p > p c p>p_{c} .
Now, what is the value of
 θ ⁡ ( p c , ℤ d ) \theta(p_{c},{\mathbb{Z}}^{d}) ? 
 
 
 In dimension  2 2 ,
the case of bond percolation
has been settled in 1980 by Kesten
 [ 10 ]  (using also a former result of Harris  [ 9 ]  from 1960) and the case of site percolation
by Russo  [ 12 ]  in 1981.
In 1990,
Hara and Slade  [ 7 ,  8 ] 
proved that
 θ ⁡ ( p c , ℤ d ) = 0 \theta(p_{c},{\mathbb{Z}}^{d})=0 
for  d ≥ 19 d\geq 19 .
In 1991,
Barsky, Grimmett and Newman  [ 1 ,  2 ] 
proved the analogous result
for bond percolation in a  d d -dimensional half-space.
After these fundamental progresses, the situation has been stalled for 25 years.
In 2015,
Damron, Newman and Sidoravicius
 [ 3 ] 
handled the case of a two-dimensional sandwich of thickness two, that is
 ℤ 2 × { 0 , 1 } \mathbb{Z}^{2}\times\{0,1\} .
This result was extended one year later to finite slabs by
Duminil-Copin, Sidoravicius and Tassion  [ 4 ] .
In 2017,
the mean-field behaviour was proved to hold for
 d ≥ 11 d\geq 11 
by Fitzner and van der Hofstad  [ 5 ,  6 ] .
Very recently, Kozma and Nitzan  [ 11 ] 
exhibited an inequality, which, if true, would settle the problem. 
 
 
 The main open question in percolation theory is to prove that
there is no percolation at the critical point in dimension  d = 3 d=3 ,
i.e., that
 θ ⁡ ( p c , ℤ 3 ) = 0 \theta(p_{c},{\mathbb{Z}}^{3})=0 . 
 
 
 Let us state formally this conjecture. 
 
 
 Conjecture 1.1 . 
 
 For any  d ≥ 3 d\geq 3 , we have
 θ ⁡ ( p c , ℤ d ) = 0 \theta(p_{c},{\mathbb{Z}}^{d})=0 .
