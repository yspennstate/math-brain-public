# Literature audit, 13 November 2026

The audit found no theorem proving the requested equality for all fixed 0 < q < 1 on all Z^d, d >= 2. This is a search result, not a proof that no such paper exists. No paper found establishes lattice sharpness for a whole interval immediately below one or for all sufficiently large d. Recent negative-correlation results must not be read as sharpness theorems.

The files in sources/ are full plain-text conversions, with retrieval URLs and SHA-256 hashes in sources/manifest.jsonl.txt. No PDF was written to disk. PDF page numbers below count from 1; manuscript page numbers are identified separately when different from the published edition.

Additional check: Huang–Pemantle–Poudevigne-Auboiron, *Two counterexamples in strong Rayleigh theory*, author-hosted preprint, says the below-one random-cluster model need not be strongly Rayleigh. The web index exposed the abstract; direct download returned HTTP 403, so no theorem number from this paper is used. It cautions against importing the spanning-tree strong-Rayleigh mechanism wholesale. [Author-hosted source](https://www2.math.upenn.edu/~pemantle/papers/Preprints/two-counterexamples.pdf).

Queries included both spellings q<1 / q < 1, “below one”, “sharpness”, “sharp phase transition”, “monotonicity in p”, “negative association”, “negative correlation”, and the requested author/title combinations, with 2017–2026 searches. Later q>=1 planar, slab, long-range and connection-inequality papers were checked by their hypotheses and not counted as below-one results. No abstract was used as a substitute for reading the numbered theorem when a theorem is cited above.

Three q→0 regimes must be distinguished. With activity v=p/(1-p), v=q beta selects forests with weights beta^{|F|}; fixed v selects connected spanning subgraphs of a connected finite graph; v→0 and q/v→0 selects spanning trees. None licenses interchanging the q→0, volume→infinity, and critical-parameter limits.
