# Preserved helper-v1 pilot failure

The first rank-two pilot stopped at exact sum(qbar)==1. A point-mass leaf used integer 1, so its division by integer4 produced a Python float while other leaves used Fraction. No certificate was produced. Helper v2 initializes that point mass with Fraction(1), preserving exact rational averaging. Family, domain, case count and analytic proof are unchanged; the revised frozen helper version precedes the repeated pilot. This was an implementation failure, not a mathematical counterexample or a substantive stagnation attempt.
