# Original-partition affine preprocessing cannot create net funding

All cubes are finite and uniform; write binary inputs, Boolean signs, and
Fourier entropy in bits. Let A be a fixed nonempty proper set of ORIGINAL
coordinates, C its complement, g_u(x_C)=f(u,x_C), and q=2^(-|A|).
Let a(g) be the least influence in the complete finite orbit generated by
invertible affine input maps and output characters. This orbit preserves
the complete squared-spectrum entropy. The minimum exists, including for
constant and inessential functions. Put

    Q_A=sum_{i in A} Inf_i(f),
    rho_A=q sum_u [I(g_u)-a(g_u)],
    L_A=H(f)-q sum_u H(g_u),
    S_A*=q sum_u [K a(g_u)-H(g_u)], D=H(f)-K I(f).

## 1. The entire partition-preserving affine group

Consider any invertible affine map of the form

    x_A=P y_A+b,  x_C=Q y_A+R y_C+c,

with P and R invertible over F2, Q arbitrary, and any output character
chi_d(y), with an optional global sign. Denote the resulting Boolean
function by f'. This is exactly the affine input group preserving the
partition into the original A-fibres, up to permutation of those fibres.
Indeed preservation makes x_A independent of y_C, hence the upper-right
matrix block is zero, and invertibility forces the two diagonal blocks
invertible. Conversely the displayed map has those properties.

For a branch y_A=u the actual complete child is

    g'_u(y_C)=sign(u) chi_{d_C}(y_C)
              g_{P u+b}(R y_C+Q u+c).

Thus g'_u is in the SAME full affine/character orbit as g_{Pu+b}.
Consequently H(g'_u)=H(g_{Pu+b}) and a(g'_u)=a(g_{Pu+b}).
The map u -> Pu+b is a bijection and every ORIGINAL reach remains q.
No Fourier row, component, mixed outside label, or terminal is removed.
Also H(f')=H(f): invertible affine input maps relabel Fourier indices
and phases, and output characters translate the Fourier indices.

There is a stronger rank-level statement. For any complete child g and
g'(y)=sign chi_d(y)g(Ry+c), let m_g(v) be the smaller of the two
directional disagreement probabilities w_g(v),1-w_g(v). Directly from
the actual derivative, w_g'(v) is w_g(Rv) or its complement according
to d dot v. Thus m_g'(v)=m_g(Rv). Every threshold space
V_g(t)=span{v:m_g(v)<=t} is carried bijectively to R^(-1)V_g(t).
For EVERY previously booked parity subspace U, transport it to
U'=R^(-1)U. Then

    rank(V_g'(t)+U')-rank(U')
       =rank(V_g(t)+U)-rank(U)                 (0)

for every real threshold t. Hence even the independent quotient ranks
relative to an existing transported booking are invariant, not just
their integrated minimum-influence cost. This does not permit changing
the booked subspace to obtain a fresh reserve; original bookings must
be transported along with the child. No independence is assumed.

## 2. Exact compensated influence and signed-bank invariance

Set Delta=I(f')-I(f), and form Q'_A,rho'_A,L'_A,S'_A* in the new chart,
querying the SAME ORIGINAL partition. The ordinary Fourier influence
split gives I(f)=Q_A+q sum I(g_u), and likewise for f'. Hence

    L'_A=L_A,  S'_A*=S_A*,
    Q'_A+rho'_A-Delta=Q_A+rho_A.                 (1)

In detail both Q+rho are I(root)-q sum a(child), and the two terminal
minimum-influence averages are equal. This also proves (1) without any
assumption of independent parity directions. It is valid for every real
K, though critical-source applications use K>=0. Since D'=D-K Delta,

    D+S_A* = L_A-K(Q_A+rho_A)
           = L'_A-K(Q'_A+rho'_A-Delta).         (2)

If a proposed preprocessing step supplies apparent extra release
Q'_A+rho'_A-(Q_A+rho_A), it is EXACTLY Delta. Omitting K Delta from
the ledger counts the root influence increase as new funding. When f
is fully affine-minimal, Delta>=0, but that sign does not make the
extra influence free. A strictly improving root change would instead
contradict full affine-minimality. Root output-character centering is
covered by the same identity; it cannot be a free second reserve.

For a concrete chosen list of resets, not necessarily optimal, choose
the conjugate resets on g'_u that produce the same original reset
terminal (up to global sign). The same proof applies with a(g_u)
replaced by that chosen terminal influence. It does NOT apply if one
silently changes the allowed parity set without transporting the resets.
In particular, an arbitrary truncated greedy reset can have a different
release; the full-orbit theorem makes no assertion of its optimality.

## 3. What genuine criticality adds

If f is a positive K-witness of least essential dimension n, then every
proper smaller Boolean function, including EVERY affine image of each
g_u, has H<=K I. Thus S_A*>=0. Equation (2) forces

    L_A >= D+K(Q_A+rho_A), D>0.                (3)

No partition-preserving preprocessing can change either side of this
compensated test. This is a restriction on any proposed critical-source
funding mechanism, not a proof that such a critical witness exists for
any specified K. Physical restriction ratio-criticality by itself only
licenses the unoptimized physical child bank, and does not license
S_A*>=0. The genuine least-dimension hypothesis is the precise extra
line unavailable in the known arbitrary-core pruning failures.

This explains why component pruning cannot be repaired by relabelling
an unchanged original partition. An arbitrary core remains in the same
complete child orbit and its entropy and negative reserve survive.
The present theorem never asserts that pruning preserves Booleanity.
Criticality changes eligibility of the FULL optimized terminal bank;
it does not erase any terminal or create extra rank release.

## 4. Actual all-k guard with positive apparent extra funding

For k>=2 put p=2^-k and take the previous actual family

    F_k=1-A_k+A_k (-1)^(ab+ac+bc+za),

where A_k means all k controls zero, and query ORIGINAL A=(a,b).
Preprocess by x_a=y_a, x_b=y_b, x_c=y_c, x_z=y_z,
x_{control1}=y_{control1}+y_a, with all other controls unchanged.
This is a member of the displayed group: only an outside input depends
on y_A. Every original child is merely translated in control1 by a.
The complete child influence is unchanged by input translation; hence
the actual full child release rho'=rho=p/4.

The original a-influence is p/2: the activated quadratic has balanced
a-derivative. The new a-direction toggles a AND control1. The two
activation slabs are disjoint. On each slab the quadratic differs from
the outside sign1 with probability (1-mean(Q))/2=3/8, since mean(Q)=1/4.
Thus Inf'_a=2p*(3/8)=3p/4. Every other physical direction is unchanged.
So Delta=p/4>0, Q_A=p, Q'_A=5p/4, rho_A=rho'_A=p/4.
The apparent total query-plus-release rises from5p/4 to3p/2; after
subtracting Delta it is EXACTLY5p/4. This is an all-k analytic identity,
not a finite extrapolation. Its SAME compensated margin at K=15/4
is the previous locally paid margin; all terminal debts remain intact.

## 5. Honest boundary

The partition condition is essential, even for an affine-minimal source.
On three bits let f=-1 precisely when x_1=x_2=0 and query A={0}.
Initially the query is irrelevant: L_A=0 and Q_A+rho_A=0, since the
two-variable point defect has full uniform spectrum and affine minimum
influence1. Exchange x_0 and x_1. This changes the ORIGINAL partition.
Root influence is still1 (Delta=0), but the actual queried children are
a literal and a constant, both of affine minimum influence0. Now L=2
and Q+rho=1. Thus extending (1) to arbitrary affine preprocessing is
FALSE. This is a boundary guard, not a genuine positive high-K witness.

FIRST UNSUPPORTED UNIVERSAL LINE: on an actual original proper pair of
every genuine high-K least-dimensional positive witness, force enough
independent low-cost parity rank AFTER restriction to pay L_A from
the SAME complete nonnegative child bank. The rank-release formula is
an exact measuring tool; (1) shows that changing only the chart of the
same partition cannot supply the missing lower bound. A change of the
physical partition is outside this invariance theorem and needs its
own original-coordinate ownership proof. No universal FEI constant is
improved. Full FEI remains OPEN.
