For u=1 exactly one gate owns the selected fresh bit. Divide its new
congestion factor by the old one. Factoring all v=0 terms gives
A=prod(kappa/(kappa+1))^(gamma*s), and the owner contributes
t=[(s+1)^(s+1)/(s^s(kappa+1))]^gamma. With c=1 the old root survives
and there is no rarity ratio. With c>=2, the new rooted tree connects c old
components. Its core bit lies in exactly one component, whose root must be
the surviving root; the other c-1 component roots form a chronological list
at that bit. There are (c-1)! distinct orders. Root rarity changes by
pi_component/prod pi_old. This reconstructs the u=1 coefficient without
independent root averaging or substituting a source SCC for an actual tree.

The new checker uses acyclic parent/attachment maps with exact child-order
factorials, rather than importing A007 code or computing determinant moments.
Every owner map and forest shape on the frozen n<=4 domain is included.
The parent paths recover their actual root, supplying the susceptibility-
weighted rarity factor. The former owned-size root shortcut is not used.

At p=1/2 the source formula specializes to
Psi=(v/2)log(2D'/D)-(1/4)sum_(T!=empty)P_g(T)(log L0+log J1).
Both data sectors have the same p^2 spectral mass. The new proof keeps this
same posterior, normalizer and inherited residual (1/2)R_g. Psi is a
rank-stripped selected-lift correction. Its two data sectors exhaust U=empty
and U={control} for T!=empty; the T=empty control-only sector and all external
rank/reference overhead stay outside Psi, as in the source transfer. A bound
or obstruction for Psi is not automatically a bound or obstruction for the
actual queue-output cost. This distinction is retained in both new results.
