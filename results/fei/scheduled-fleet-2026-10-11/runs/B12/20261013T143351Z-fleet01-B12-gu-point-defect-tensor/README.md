# Files

- `REPORT.md` — full result, scope, verification, and next step.
- `GU_POINT_DEFECT_TENSOR.tex` — analytic proof.
- `check_gu_point_defect_tensor.py` — deterministic exact/high-precision reconstruction.
- `check_gu_point_defect_tensor.out` — saved checker output.
- `CLAIMS.json` — claim versions and statuses.
- `PROGRESS.json` and `PACKET_DELTA.json` — protocol-compatible progress records.
- `SOURCE_PINS.md` — immutable source pointers.
- `HANDOFF.md` — compact reviewer/consumer handoff.
- `HASHES.sha256` — local artifact hashes.
- `DELIVERY_RECEIPT.md` — populated only after both repositories are read back.
