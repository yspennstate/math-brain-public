# Commands

```text
python3 CHECK.py | tee OUTPUT.txt
```

The checker has no random seed.  It constructs every binary subspace through
physical dimension six, reconstructs the affine-defect truth table, verifies
the squared Fourier law with exact `Fraction` arithmetic, and evaluates the
physical restriction decrements.  Floating logarithms are used only to
display ratios and identity residuals; no finite scan is used as the proof of
the all-rank theorem.
