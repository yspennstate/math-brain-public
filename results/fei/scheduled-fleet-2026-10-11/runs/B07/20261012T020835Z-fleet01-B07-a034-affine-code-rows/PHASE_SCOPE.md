# A034 affine-code row scope

- Physical inputs are disjoint, uniform Boolean cubes `X,Y`; no correlated physical law is used.
- The function `f` is genuinely Boolean and has integer `X`-degree at most `d`.
- For each positive `X`-spectral row, the physical row function `a_R(y)` must have constant magnitude `sqrt(p_R)`. Its normalized sign is required to be a constant or an affine-subspace-coset defect.
- Under that checkable condition, the conditional fiber is the genuine Boolean Fourier law of the row sign, not an arbitrary normalized probability vector.
- The entire conditional entropy is bounded by `4 I_Y(f)` using the exact dual-code spectrum and dual-code weight sum. The marginal payment remains the prior phase-energy inequality; it is not discarded or silently reused.
- The class grows with the ambient cube, code dimension, code length, `X`-function, and affine offset. Dense dual codes are allowed; their extra active coordinates only increase influence.
- The condition is stable under dummy variables, affine changes of the `Y` coordinates, constant signs, and multiplication by an `X`-only Boolean factor when the stated `X`-degree bound is updated.
- A separated arbitrary tensor core is rejected unless the core is itself an affine-code defect. The square of every positive-entropy affine-code defect is rejected because its minority density is not a reciprocal power of two. Characters are the only repeatable case and contribute zero entropy.
- Addressing and generic prime gates need not satisfy constant-magnitude rows. The theorem is a proper-class conditional completion, not a universal FEI proof.
- The exact remaining A034 obstacle is to replace the affine-code row hypothesis by a decomposition or stopping rule whose pieces have a nonreused global payment.
