# Primary-source scope comparison

Checked on 2026-10-13.

1. **O'Donnell--Tan, arXiv:1304.1347.**  Their composition theorem assumes
   inner functions on disjoint variable blocks and a suitable biased-FEI
   statement for the outer function.  It supports the distinction between
   exact disjoint tensorization and a broader Boolean composition claim.  It
   does not identify arbitrary invertible physical-coordinate changes with
   the matched form used here, and it supplies no positive-codimension GU
   payment.

2. **Potapov, arXiv:2609.21563 (posted 2026-09-18).**  Potapov proves FEI
   for Boolean plateaued functions with sharp class constant 4 and for
   partially bent functions with sharp class constant 2.  The reviewed root
   has completely flat squared spectrum, so its FEI conclusion
   \(H/I=2\) is already within plateaued-function territory.  The new object
   under review is instead the upper-set restriction charge \(G\), including
   physical-coordinate children.  Potapov's result neither proves nor
   contradicts that GU statement.

Accordingly, no priority claim is made for FEI on the flat-spectrum roots.
The independently accepted content is the explicit canonical-root GU bound
and its disjoint-product consequence.  Shared variables, arbitrary physical
linear changes, and positive-codimension descendants require separate
proofs.
