# Exact payment interface

For rare point-activated input translations on independent selector blocks,

`B_W = sum_j rho_j E_(k_j)`, `M_W = 0`, `I_W = sum_j rho_j 2 k_j 2^(-k_j)`.

Here rho_j is physical translation disagreement of the arbitrary shared core, not a free spectral prior. Each selector-coordinate influence is exactly rho_j 2^(1-k_j). Zero rho costs nothing. Repeated translation vectors are allowed. Disjoint selector blocks are essential to the proof.

`B_W <= 4 I_W` has optimal constant 4 as neighboring disagreement tends to zero. Full entropy is `H(g)+B_W`; the terminal `H(g)` cannot be discarded. A complete-module physical block tree pays each module once and leaves a translated g. Fresh nesting transfers a certified core constant without a depth loss.
