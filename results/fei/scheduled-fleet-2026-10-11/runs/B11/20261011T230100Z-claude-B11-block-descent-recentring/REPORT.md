# complete derivation or exact first unsupported line

R1 (recentred channel bound). For T in C put w_T(a) = (f_a)hat(T) = sum_{U in A} fhat(U u T) chi_U(a). Then P(Y=T | X=a) = w_T(a)^2 and, by Parseval in a, P(Y=T) = E_a w_T^2 = sum_U fhat(U u T)^2 = P(S_C = T). Hence (ln 2) J_A = sum_T Ent(w_T^2), Ent the natural-log entropy functional. For any U0 in A, g = chi_{U0} w_T has g^2 = w_T^2 and ghat(U) = fhat((U symdiff U0) u T). The Gross inequality with U0 = e(T) gives Ent(w_T^2) <= 2 sum_U |U symdiff e(T)| fhat(U u T)^2. Summing over T gives (ln 2) J_A <= 2 E|S_A symdiff e(S_C)| for every map e. Given S_C = T, the expectation of |S_A symdiff e(T)| is sum_{i in A} P(Z_i differs from 1[i in e(T)] | T), minimised by the conditional majority with value sum_i min(p_i(T), 1 - p_i(T)); this gives beta_A. Since h2 is concave with h2(0)=0, h2(1/2)=1, h2(p) >= 2 min(p, 1-p), so 2 beta_A <= sum_{i in A} H(Z_i | S_C). The affine syndrome e0 of A052 and the baseline e = 0 (J_A <= (2/ln2) I_A) are special choices of e.

R2 (critical sources). If f is a dimension-critical C-witness and A is nonempty and proper, the restrictions live on fewer coordinates, so D_C(f) = (L_A - C I_A) + E_a D_C(f_a) <= L_A - C I_A (this is (3.1) of A051). With R1: C I_A + D_C(f) <= H(Z_A | Z_C) + (2/ln2) beta_A. For A = {i}, beta_i is the Bayes error of predicting Z_i from Z_-i. The constant predictor gives beta_i <= min(Inf_i, 1 - Inf_i). For u containing i, E f(x) f(x xor u) = 1 - 2 P(|S n u| odd), so the parity predictor gives beta_i <= eps_u = (1 - |E f f_u|)/2, and Z_i xor parity(Z on u minus i) has entropy h2(eps_u), so H(Z_i | Z_-i) <= h2(eps_u). Hence C Inf_i + D_C <= h2(eps_u) + (2/ln2) eps_u, which is exactly the rank-one statement of A052, and C Inf_i + D_C <= (1 + 1/ln2) H(Z_i | Z_-i). Consequence: in a dimension-critical witness no coordinate has its membership in the spectral sample determined by the rest of the sample (parity substitutions, exact signed translation symmetries and every other deterministic dependence are excluded at once).

R5 (descent principle). Let K >= M_{n-1} and K >= K_desc(n). For nonconstant f on n bits pick a block with I_A > 0 and L_A <= K I_A (one exists by definition of K_desc). Then D_K(f) = (L_A - K I_A) + E_a D_K(f_a) <= 0 because the restrictions have at most n-1 coordinates. So M_n <= max(M_{n-1}, K_desc(n)), M_n <= max over m <= n of K_desc(m), C_* <= sup_n K_desc(n), and K_desc(n) <= K for all n would prove FEI with constant K.

R6 (tensor products). For A inside the coordinates of g, (g x h)_a = g_a x h, entropies add, so L_A(g x h) = L_A(g) and I_A is unchanged; for A equal to all coordinates of g, the restriction is plus or minus h, so L_A = H(g) and I_A = I(g). Hence phi(g x h) <= min(phi(g), phi(h), H(g)/I(g), H(h)/I(h)), and the mediant inequality puts this at or below H(g x h)/I(g x h).

First unsupported line: "there is a finite K with K_desc(n) <= K for every n", equivalently that every Boolean function has a proper block with L_A <= K I_A. By R5 any such K is at least C_* (literature lower bounds exceed 6), while the measured K_desc stays below 4.54 for n <= 5, so the first test cases must be indecomposable (R6), not point-defect-like, and have n >= 6.

# Universal bridge

The bridge that moved is the stopping-tree payment C019 on the way to C000. The channel term every node pays is now (2/ln2) times the conditional Bayes error beta_A instead of (2/ln2) I_A, for every recentring at once (R1), and one-step block descent is an exact sufficient route: FEI with constant K follows from K_desc(n) <= K for all n (R5). On n <= 5 the route loses little: K_desc = 4, 4.4338, 4.5366 (certified) and 4.5088 (evidence), always at point defects, a factor 2, 1.50, 1.33, 1.24 over M_n, and tensor products never obstruct it (R6). What remains is whether K_desc(n) stays bounded; it must climb past C_* somewhere, so the hard cases are indecomposable functions with n >= 6. Computing phi on the compositions that realise the known lower bounds is the shortest next step, because a bounded ratio there is direct evidence for a constant-K descent proof of FEI with no tree bookkeeping, and an unbounded one closes the one-step route in a single computation and sends the work to genuine multi-step stopping trees.
